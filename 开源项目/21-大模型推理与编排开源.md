# 开源项目精选：大模型推理与编排

> 大模型落地的关键环节是"推理服务化"与"Agent 编排"。本文梳理该领域值得关注的开源项目（非排名，按用途归类）。

## 1. 推理与服务化

| 项目 | 用途 | 特点 |
| --- | --- | --- |
| vLLM | 高性能推理 | PagedAttention、连续批处理 |
| TGI (Text Generation Inference) | HF 推理服务 | 优化解码、量化 |
| llama.cpp | 本地/边缘推理 | GGUF、跨平台 |
| Ollama | 本地模型运行 | 一键拉取运行 |
| TensorRT-LLM | NVIDIA GPU 推理 | 极致优化 |
| LMDeploy | 量化+服务 | 高吞吐 |

## 2. 编排与 Agent 框架

| 项目 | 用途 | 特点 |
| --- | --- | --- |
| LangChain | 链式编排 | 生态最大、组件多 |
| LangGraph | 图/状态机编排 | 可控、可持久化 |
| LlamaIndex | 数据/RAG 框架 | 索引与检索强 |
| AutoGen | 多 Agent 对话 | 微软，多智能体 |
| CrewAI | 角色化 Agent | 业务流清晰 |
| Semantic Kernel | 微软 SDK | 多语言集成 |

## 3. 网关与中间件

| 项目 | 用途 |
| --- | --- |
| LiteLLM | 统一多模型 API、路由、限流 |
| Haystack | 生产级 RAG 管道 |

## 4. 选型建议

- **追求性能**：vLLM / TGI 生产服务。
- **本地/边缘**：llama.cpp / Ollama。
- **快速原型**：LangChain + LlamaIndex。
- **可控编排**：LangGraph / AutoGen。
- **多模型管理**：LiteLLM。

## 5. 学习路径

1. 先跑通 vLLM/Ollama 推理。
2. 用 LlamaIndex 做 RAG。
3. 用 LangGraph 编排 Agent。
4. 用 LiteLLM 做网关与限流。
5. 结合业务落地。

## 6. 注意

- 开源版本迭代快，以官方文档为准。
- 生产需关注安全（提示注入、越权工具调用）。
- 合规：模型许可与数据出境。

## 7. 小结

大模型推理与编排生态繁荣：推理侧 vLLM 领跑性能，编排侧 LangChain/LangGraph 提供框架，网关侧 LiteLLM 统一入口。按需组合即可搭建生产级 LLM 应用。
