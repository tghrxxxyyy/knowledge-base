# 安全合规与秘钥管理（开源精选）

> 板块：开源项目 　|　 返回：[README](README.md)
> 覆盖：秘钥、策略、镜像扫描、代码安全、依赖治理。通行开源项目。

## 一、一句话定位

安全左移（Shift Left）：在开发期就做秘钥管理、依赖扫描、镜像扫描、策略校验，而不是上线后救火。安全是工程的一部分，不是附加项。

## 二、秘钥与凭据管理

- **HashiCorp Vault**：集中管理秘钥/证书/动态凭据，支持自动轮换、加密即服务、审计日志。
- **KMS（云厂商）**：信封加密，应用拿明文不出 KMS。
- **Sealed Secrets / External Secrets Operator**：K8s 中安全注入秘钥，避免明文进 Git。
- **原则**：秘钥不入代码、不入镜像、不提交 Git；用环境变量或挂载注入。

## 三、策略与准入控制

- **OPA（Open Policy Agent）**：通用策略引擎，用 Rego 写策略，可做 K8s 准入、API 鉴权、CI 卡点。
- **Kyverno**：K8s 原生策略（YAML 写），准入/审计/生成。
- **场景**：禁止特权容器、强制资源限制、镜像来源白名单。

```rego
# OPA Rego 示例：禁止 latest 镜像
deny[msg] {
  input.request.kind.kind == "Pod"
  image := input.request.object.spec.containers[_].image
  endswith(image, ":latest")
  msg := "禁止使用 latest 镜像"
}
```

## 四、镜像与供应链安全

- **Trivy / Clair / Grype**：扫描镜像/文件系统/依赖的 CVE 漏洞。
- **cosign / Sigstore**：镜像签名与验证，保证来源可信。
- **SBOM（软件物料清单）**：生成 CycloneDX/SPDX，追踪组件与漏洞。
- **CI 卡点**：漏洞超阈值则阻断发布。

## 五、代码安全（SAST/DAST）

- **SonarQube / Semgrep**：静态分析，查注入、硬编码秘钥、危险函数。
- **Bandit（Python）/ FindSecBugs（Java）**：语言专用。
- **DAST**：运行时动态扫描（如 OWASP ZAP）。
- **秘钥扫描**：GitLeaks / TruffleHog 扫历史提交防泄露。

## 六、依赖与供应链治理

- **依赖漏洞**：Dependabot / Renovate 自动升级；SCA 工具（如 Trivy 的 SCA）查传递依赖。
- **锁文件**：package-lock / go.sum / Pipfile.lock 保证可复现。
- **供应链攻击**：校验包签名、最小权限安装、私有代理（npm/PyPI 镜像）。

## 七、身份与访问（IAM）

- **OAuth2 / OIDC**：授权与单点登录。
- **Keycloak**：开源身份提供者，支持 SSO/2FA。
- **最小权限**：角色按需授予，定期回收。

## 八、网络安全

- **mTLS**：服务间双向认证（服务网格默认）。
- **网络策略**：K8s NetworkPolicy 隔离命名空间/服务。
- **WAF**：防护常见 Web 攻击。

## 九、合规要点

- **数据脱敏**：PII（姓名/手机号/身份证）存储加密或脱敏。
- **审计日志**：谁在何时做了什么，不可篡改。
- **留存与删除**：按法规保留与销毁。
- **隐私**：最小化采集，明确告知与同意。

## 十、安全开发实践

1. 威胁建模（STRIDE）在设计阶段。
2. 输入校验与输出编码防注入。
3. 秘钥集中管理 + 自动轮换。
4. CI 集成 SAST + 依赖扫描 + 镜像扫描。
5. 默认拒绝 + 最小权限。
6. 红蓝对抗与定期审计。

## 十一、常见坑

- 秘钥硬编码进代码 → 泄露，必须扫描历史。
- 镜像用 latest → 不可复现且无法校验。
- 只扫不修 → 漏洞清单越积越多。
- 权限过度授予 → 一破全破。
- 合规当作文档而非工程 → 上线即违规。
