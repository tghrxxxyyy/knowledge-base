# 开源项目精选：前端框架与构建新生态

> 前端生态快速演进：框架从 React/Vue 到 Solid/Svelte，构建从 Webpack 到 Vite/Turbopack。本文梳理当前主流开源项目，便于选型。

## 1. 框架

| 项目 | 特点 |
| --- | --- |
| React | 生态最大，函数式+Hooks |
| Vue | 渐进式，模板友好 |
| Svelte/SvelteKit | 编译时，无虚拟 DOM |
| SolidJS | 细粒度响应式，高性能 |
| Angular | 全家桶，企业级 |
| Next.js | React 全栈框架 |
| Nuxt | Vue 全栈框架 |

## 2. 构建工具

| 项目 | 特点 |
| --- | --- |
| Vite | ESM 按需编译，快 |
| Webpack | 老牌，配置全 |
| esbuild | 极速打包（Go） |
| SWC | Rust 编译 |
| Turbopack | Next 增量构建 |
| Rspack | 字节，Webpack 兼容快 |

## 3. 状态与样式

| 项目 | 用途 |
| --- | --- |
| Redux/Zustand | 状态管理 |
| Tailwind CSS | 原子化样式 |
| CSS Modules | 局部样式 |

## 4. 选型建议

- 新项目：Vite + React/Vue。
- 极致性能：Solid / Svelte。
- 全栈：Next.js / Nuxt。
- 构建提速：Rspack 兼容 Webpack。

## 5. 趋势

- 编译时优化（Svelte/Solid）。
- 服务端组件（RSC）。
- 构建 Rust 化（SWC/Rspack/Turbopack）。
- 边缘渲染。

## 6. 学习路径

1. 掌握 React/Vue 基础。
2. 用 Vite 搭建项目。
3. 学状态管理与路由。
4. 了解 Next/Nuxt 全栈。
5. 关注编译时框架。

## 7. 小结

前端框架走向"细粒度响应式 + 编译优化"，构建工具全面提速（Vite/Rspack/Turbopack）。选型看团队与场景，趋势是更快的构建与更优的运行时性能。
