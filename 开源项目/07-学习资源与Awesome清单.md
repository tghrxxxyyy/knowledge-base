## 重点速读

### codecrafters-io/build-your-own-x —— 2026 全站星标第一

build-your-own-x 是一个"教程索引型"仓库，它把网络上优质的「从零实现」教程按主题分门别类：从写自己的操作系统、数据库、容器、Docker、Git、Shell、键值存储、正则表达式引擎，到 React、区块链、BitTorrent 客户端……几乎覆盖了一个工程师好奇心的全部边界。它的核心定位不是教你某个知识点，而是**用"动手造一遍"替代"只读不练"**——因为真正理解一个系统，最好的方式就是把它重新实现一次。

为什么这么火？因为它击中了"学完就忘、看了不会"的普遍痛点。比起啃大部头，跟着教程亲手把 Redis 或 Git 造出来，理解会深刻得多。2026 年它能登顶全站星标第一，正是"做中学（learning by building）"理念被全球开发者集体认同的结果。对新人，它是项目驱动学习的入口；对老手，它是重温底层的清单。

> 口诀：**"读十遍不如造一遍，轮子自己撸才懂。"**

### sindresorhus/awesome —— 元清单的鼻祖

awesome 是"精选清单"这一体裁的开山鼻祖。它本身不堆内容，而是**定义了一套清单规范**，并汇总了各行各业最优质的 Awesome 列表：前端、后端、机器学习、安全、运维、设计……只要你想找某领域的"好东西合集"，几乎都能在 awesome 的某个子清单里找到。它带动了整个 GitHub 的 "awesome-xxx" 命名风潮，成了开源社区的事实标准。

为什么这么火？因为信息过载时代，人最缺的不是资料，而是"经过筛选的高质量资料"。awesome 系列的飞轮效应极强：每个子清单都由对应领域的爱好者维护，质量随社区滚雪球。对学习者，它是"按图索骥"的地图；对本知识库，它也是组织"开源项目"板块的思路来源——把散落的宝藏结构化。

> 口诀：**"清单之王awesome，按类索骥不迷路。"**

### freeCodeCamp/freeCodeCamp —— 把编程课免费送到全世界

freeCodeCamp 是一个非营利组织运营的开源项目，提供从 HTML/CSS、JavaScript、前端框架，到后端、数据库、数据可视化、机器学习等一整套**免费、交互式、带证书的编程课程**。它的学习路径直接在浏览器里写代码、即时校验，学完还能做真实项目、拿认证。累计已惠及数百万人，是无数转行者的第一站。

为什么这么火？因为它把"高质量编程教育"的门槛降到了零：不收钱、不挑背景、中文社区活跃、课程持续更新。对预算有限的学习者，它是改变职业轨迹的跳板；对想系统补基础的人，它的结构化路径也比零散博客更可靠。它和 developer-roadmap（路线图）是"学什么"与"怎么学"的黄金搭档。

> 口诀：**"免费课、浏览器练，零基础也能上前线。"**

### nilbuild/developer-roadmap —— 交互式成长路线图

developer-roadmap（原 kamranahmedse 的著名 roadmaps）以**交互式思维导图**形式，给出前端、后端、DevOps、全栈等方向的"该学什么、按什么顺序学"。每个节点点开都有推荐资源，路线图随技术演进持续更新，是新人规划学习路径、老人查漏补缺的导航仪。

为什么这么火？因为它把"浩如烟海的技术栈"压成一张可读的图，消除了"从哪开始"的焦虑。它与 freeCodeCamp 的线性课程互补：roadmap 告诉你"地图"，freeCodeCamp 提供"上路的具体教材"。对想进云原生/后端的人，它也是通往 K8s、CI/CD 板块的索引。

> 口诀：**"路线图里看全貌，按图学不瞎撞墙。"**

### donnemartin/system-design-primer —— 系统设计面试圣经

system-design-primer 是大规模系统设计的学习与面试准备经典。它系统讲解**可扩展性、负载均衡、缓存、分片、一致性、CAP、消息队列、CDN** 等主题，配大量图示与"如何设计一个短链/微博/限流系统"的范例，还整理了常见面试题与解答框架。

为什么这么火？因为中高级工程师面试几乎必考系统设计，而学校很少教。它把零散的架构知识结构化，既是面试宝典，也是日常做架构设计的速查手册。它与 CS-Notes、tech-interview-handbook 共同构成中文/英文面试资料铁三角。

> 口诀：**"扩缓存、分片均，系统设计它最亲。"**

### awesome-selfhosted/awesome-selfhosted —— 数据主权清单

awesome-selfhosted 汇总了所有**可自托管**的免费软件：从笔记、网盘、密码管理、监控，到 CI、分析、博客、聊天室，几乎覆盖个人与小企业数字生活的全部需求。它的价值在于"把数据与隐私留在自己手里"——替代 SaaS 订阅，自己用 Docker 起一套。

为什么这么火？因为隐私意识与数据主权抬头，越来越多人拒绝把资料交给第三方。它与本知识库的 云原生/K8s、CI/CD 板块天然衔接：用容器与流水线把自托管服务跑稳，正是工程师的特长。对想"自己掌控数字生活"的人，这是必藏清单。

> 口诀：**"自托管、数据留，隐私主权握在手。"**

## 深挖：怎么高效用这些资源（方法论）

| 场景 | 推荐组合 | 用法建议 |
|------|----------|----------|
| 转行/入门 | freeCodeCamp → developer-roadmap → project-based-learning | 课程打底后立刻做项目，别停在"看课" |
| 系统补基础 | ossu/computer-science + CS-Notes + You-Dont-Know-JS | 按 CS 体系逐块补，中文资料做速查 |
| 面试冲刺 | system-design-primer + tech-interview-handbook + CS-Notes | 系统设计刷例题、算法用 TheAlgorithms 复盘 |
| 想深挖原理 | build-your-own-x | 每周挑一个"造一遍"：造 Redis/Git/容器 |
| 查工具/找资料 | awesome 系列 + the-book-of-secret-knowledge | 先看清单再深入，避免信息过载 |
| 数据主权 | awesome-selfhosted | 用 Docker 把常用服务自托管一遍 |

**三条原则**：
1. **按需取用，不收藏即学会**——清单的价值在"找到对的东西"，读起来才算数；
2. **做中学**（build-your-own-x 登顶的原因）：造一个 Redis 胜过读十篇 Redis 博客；
3. **与知识库联动**：清单是"地图"，本库的板块文档是"景点"，二者配合用。
