## 重点速读

### torvalds/linux —— 整个数字世界的地基

Linux 内核由 Linus Torvalds 于 1991 年发布，用 C 写成，遵循宏内核架构（含可加载模块）。它向上提供统一的系统调用抽象，向下适配从嵌入式 ARM 到 x86 超算的几乎所有硬件。今天：Android 手机、全球 90%+ 的公有云服务器、Docker/K8s 的容器底座、你家的路由器与机顶盒——底层都是 Linux。它直接定义了"开源也能做成工业级基石"的范式。

为什么这么火（且长青）？因为它采用极严格的"集市式"协作： thousands of 贡献者通过邮件列表 + Git 提补丁，Linus 本人把关合并；加上 GPL 协议保障了"自由使用且衍生必须开源"的正循环。对工程师，读 Linux 源码是理解进程调度、内存管理、文件系统、网络的终极教材。

> 口诀：**"内核一肩挑软硬，数字世界它立命。"**

### yt-dlp/yt-dlp 与 Genymobile/scrcpy —— 国民级实用的双子星

**yt-dlp** 是 youtube-dl 的高活跃 fork，用 Python 写成，支持数千个站点的音视频提取、字幕下载、格式与画质选择、批量与限速。它把"想要的媒体抓下来"这件事做到了极致易用，且社区更新极快（频抗站点改版）。尽管涉及版权灰区，其工程价值（协议解析、插件化 extractor 架构）值得学习。

**scrcpy** 由 Genymobile（Genymotion 团队）开源，通过 ADB 把安卓屏幕投到电脑并反向控制，延迟极低、无需 root、可无线。它是开发调试、演示、远程协助的刚需工具，C 端渲染 + Java 控制端配合得恰到好处。二者共同说明一个道理：解决"具体又普遍的小痛点"的开源项目，最容易收获海量 Star。

> 口诀：**"yt-dlp 抓媒体、scrcpy 控安卓，痛点戳准星自来。"**

### git/git —— 现代研发的协作底座

Git 同样出自 Linus 之手（2005 年），为管理 Linux 内核而生的分布式版本控制系统。它用"快照 + 内容寻址 + 有向无环图"的模型，让每个开发者都拥有完整历史与离线能力，分支创建近乎零成本。今天 Git 已是事实标准：GitHub/GitLab/CI-CD 全都建立在它之上。

为什么值得关注？因为它是 **CI/CD 板块**（见关联）的前提——没有 Git 的提交/分支/标签模型，就没有流水线触发、PR 评审、GitOps 这些东西。读懂 `.git` 内部对象（blob/tree/commit）与 rebase/merge/cherry-pick 的差异，能让你在"分支混乱、冲突爆炸"时从容脱困。

> 口诀：**"分布式、快照存，协作流水它打底。"**
