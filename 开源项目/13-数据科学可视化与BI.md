## 一、一句话定位

从数据到洞察的链路：Notebook 探索 → 数值/统计计算 → 可视化 → BI 看板。Python 是事实标准生态。

## 二、Notebook 与交互分析

- **Jupyter / JupyterLab**：交互式 Notebook，数据探索标配。
- **Notebook 工程化**：nbconvert 转文档、papermill 参数化执行、nbstripout 去输出便于 Git。
- **协作**：JupyterHub（多用户）、Voila（Notebook 转 Web 应用）。

## 三、数值与数据处理

- **NumPy**：多维数组与向量化运算，几乎所有库底座。
- **Pandas**：DataFrame，清洗/聚合/透视，数据分析主力。
- **Polars**：Rust 写的 DataFrame，比 Pandas 更快、更大。
- **SciPy / StatsModels**：统计与科学计算。

```python
import pandas as pd
df = pd.read_csv("sales.csv")
print(df.groupby("region")["amount"].sum())
print(df.pivot_table(index="month", columns="category", aggfunc="sum"))
```

## 四、机器学习（经典）

- **scikit-learn**：经典 ML（回归/分类/聚类/降维）事实标准。
- **XGBoost / LightGBM / CatBoost**：梯度提升树，表格数据 SOTA。
- **特征工程**：缺失值、编码、归一化、特征选择。

## 六、BI 与看板

- **Superset（Apache）**：开源 BI，拖拽图表、SQL 查询、看板。
- **Metabase**：轻量 BI，业务自助分析友好。
- **Grafana**：时序监控看板（见 [SRE/可观测性三支柱实战](../SRE/可观测性三支柱实战.md)）。
- **Redash**：SQL 到可视化的查询平台。

## 七、实验跟踪与 ML 平台

- **MLflow**：实验记录、模型注册、部署。
- **Weights & Biases / ClearML**：实验管理与协作。
- **DVC**：数据/模型版本控制，类 Git 但管大文件。

## 八、特征与流转

- **Feature Store**：特征统一存储复用（Feast 等），避免训练/线上不一致。
- 训练/服务偏差（train-serving skew）是经典坑。

## 九、常见坑

- Notebook 随手写不工程化 → 难复现、难协作。
- 数据泄漏（label 泄露到特征）→ 离线指标虚高。
- 不划分时间窗 → 用未来数据预测过去。
- 可视化误导（坐标轴截断）→ 结论失真。
- 模型不监控 → 数据漂移后失效。

## 十、学习路径

1. Python + Pandas 做数据清洗。
2. Matplotlib/Seaborn 探索可视化。
3. scikit-learn 跑通建模流程。
4. MLflow 管理实验。
5. Superset/Metabase 做业务看板。
