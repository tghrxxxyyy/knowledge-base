# 边缘智能与端侧架构实战

> 把推理从云端下沉到端侧（手机、IoT、车机）是 latency、隐私、成本三重驱动的趋势。端侧架构要解决模型压缩、异构算力调度、端云协同、离线可用，是"云-边-端"三层架构的关键一环。

## 1. 三层架构

```mermaid
flowchart LR
    C[云:训练/大模型] --> E[边:网关/边缘节点]
    E --> D[端:手机/IoT]
    D -->|本地推理| R[结果]
    D -.|难例回传| C
```

## 2. 关键能力

| 能力 | 说明 |
| --- | --- |
| 模型压缩 | 量化/剪枝/蒸馏适配端侧 |
| 算力调度 | CPU/GPU/NPU 异构选择 |
| 端云协同 | 简单本地、复杂上云 |
| 离线可用 | 无网也能核心功能 |
| 增量更新 | 模型差分下发 |

## 3. 端云协同

- 端侧处理低延迟、隐私敏感任务（人脸解锁、语音唤醒）。
- 云端处理复杂任务（大模型问答、长上下文）。
- 难例/数据按策略回传，持续训练。

## 4. 工程要点

- 模型格式统一（如 ONNX/TFLite）跨端部署。
- 资源受限下控制内存与功耗。
- 模型热更新不中断服务。
- 设备能力探测，按档位选模型。

## 5. 常见坑

| 坑 | 现象 | 对策 |
| --- | --- | --- |
| 端侧太慢 | 卡顿 | 压缩 + NPU |
| 模型大 | 装不下 | 裁剪 |
| 离线崩 | 不可用 | 降级路径 |
| 更新失败 | 黑屏 | 回滚 |
| 功耗高 | 发热 | 调度优化 |

## 6. 面试题

1. 端云协同如何分工？
2. 端侧模型如何压缩？
3. 离线可用怎么保证？
4. 异构算力如何调度？
5. 模型热更新注意什么？

## 7. 小结

边缘智能 = 端侧压缩 + 异构调度 + 端云协同 + 离线降级。核心是"把对的任务放在对的算力上"，用云补端、用端补云。
