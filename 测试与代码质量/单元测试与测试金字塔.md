# 单元测试与测试金字塔

> 板块：测试与代码质量 　|　 返回：[README](README.md)

测试金字塔是软件质量的基础模型：单元测试应占绝大多数（多、快、廉），集成与 E2E 少而精（慢、贵、覆盖关键链路）。本文讲清金字塔、FIRST 原则、AAA 结构、Mock 边界、度量与 TDD，帮助建立可持续的测试体系。

## 一、测试金字塔

```
        /\        UI / E2E（少、慢、贵）
       /  \       集成测试（中）
      /----\      单元测试（多、快、廉）
     /------\
```

### 1.1 比例与含义

- **单元测试 ≥ 70%**：快（毫秒级）、稳定、失败易定位、可随时跑。
- **集成测试**：验证组件协作，覆盖接口/事务/外部依赖边界。
- **E2E**：仅覆盖最高价值用户旅程（登录、下单、支付）。

### 1.2 反模式

- **冰淇淋筒**：大量 E2E、极少单测 → 跑得慢、易碎、反馈迟。
- **沙漏**：单测和 E2E 多、集成少 → 组件间契约问题漏测。
- 正确姿态：底宽、顶尖，金字塔形。

## 二、单元测试原则（FIRST）

- **Fast（快）**：毫秒级，开发者敢随时跑。
- **Isolated（独立）**：不依赖外部（DB/网络/时间），用 mock/double 隔离。
- **Repeatable（可重复）**：重复跑结果一致，不依赖顺序/环境。
- **Self-validating（自验证）**：自动断言结果，不需要人眼看。
- **Timely（及时）**：随代码写，不事后补（补的往往质量差）。

## 三、AAA 结构（Arrange-Act-Assert）

```java
@Test
void should_deduct_stock_when_order_paid() {
    // Arrange：准备输入与依赖
    Order order = new Order(SKU_A, 2);
    // Act：执行被测行为
    order.pay();
    // Assert：验证结果
    assertEquals(0, stock.of(SKU_A));
}
```

好处：结构统一、意图清晰、易读易维护。

## 四、Mock 与边界

### 4.1 何时用 Mock

- 隔离慢/不稳定依赖：数据库、RPC、第三方 API。
- 模拟异常分支：超时、异常、空返回。
- 验证交互：是否调用了某依赖、次数、参数（Mock 的强项）。

### 4.2 何时不用 Mock

- 不要 mock 一切 → 测的是 mock 而非真实逻辑。
- 纯函数/值对象可直接测，无需 mock。
- 过细 mock 会让测试与实现强耦合，一改实现就红。

### 4.3 边界用例

必测边界：空、null、超长字符串、负数、0、最大值、并发、异常路径。边界最易藏 bug。

## 五、命名与可读性

- 测试方法名表达"场景+期望"：`should_xxx_when_yyy`。
- 一个测试聚焦一个行为，断言集中、易定位。
- 用 builder/factory 构造测试数据，避免大段硬编码。

## 六、度量：覆盖率之外

- 行覆盖/分支覆盖是基础，但**不够**：高覆盖可能全是 getter。
- 看**关键路径覆盖**：核心业务逻辑、异常分支是否覆盖。
- **变异测试（Mutation Testing）**：故意改代码（如把 `>` 改 `<`），看测试能否抓到，验证测试有效性。

## 七、稳定性（Flaky）

- 不稳定的单测比没有更糟：团队对红麻木。
- 常见原因：时间依赖（`new Date()`）、并发竞争、共享状态、外部网络。
- 治理：注入时钟、固定随机种子、隔离数据、重试一次 + 标记调查。

## 八、TDD（测试驱动开发）

- 红（写失败测试）→ 绿（最小实现通过）→ 重构（优化不改行为）。
- 适合：复杂逻辑、算法、核心领域规则。
- 不适合：简单 CRUD、UI 层（过度 TDD 反而拖慢）。

## 九、CI 中的定位

- 单测：每次提交必跑（秒级反馈）。
- 失败即阻断合并（Required Check）。
- 覆盖率趋势纳入门禁（新增代码不低于阈值）。

## 十、常见坑

1. **单测调真实 DB/接口** → 慢且不稳定，环境一变就红。
2. **一个测试多断言多分支** → 失败时难定位。
3. **只为覆盖率写无断言测试** → 假绿，毫无价值。
4. **依赖执行顺序** → 并行跑就挂。
5. **mock 过度** → 测的是桩，重构时大量红。
6. **从不重构测试** → 代码演进后测试腐化、越来越慢。
