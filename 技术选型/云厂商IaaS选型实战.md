# 云厂商 IaaS 选型实战

> 选云不是选"谁便宜"，而是选"谁能匹配业务形态、合规要求与团队能力"。IaaS 层面的计算、存储、网络、数据库、安全各自有取舍，需从成本、SLA、生态、锁定风险多维度权衡。

## 1. 选型维度

| 维度 | 关注点 |
| --- | --- |
| 成本 | 实例单价、流量、存储、长期折扣 |
| 地域 | 国内合规、就近延迟、多活 |
| 产品广度 | 是否覆盖业务所需 PaaS |
| SLA | 计算/网络/存储可用性承诺 |
| 锁定风险 | 迁移成本、标准兼容 |
| 生态 | 工具链、市场、文档 |

## 2. 计算形态选择

- **虚拟机（ECS/EC2）**：通用、可控，运维重。
- **容器服务（K8s）**：标准化、弹性好。
- **Serverless**：事件驱动、免运维，有冷启动与限制。
- **裸金属**：高性能、合规隔离需求。

## 3. 网络与合规

- 国内业务需境内资源、ICP/等保合规。
- 跨地域用专线/VPC 对等，延迟与带宽权衡。
- 出海业务就近选区域，注意数据主权。

## 4. 成本优化

```text
成本 = 实例 × 时长 + 流量 + 存储 + 请求
优化：
 - 长期负载买预留/包年折扣
 - 波动负载用弹性 + Spot
 - 闲时降配 / 自动伸缩
 - 流量走内网 / CDN 回源压缩
```

## 5. 常见坑

| 坑 | 现象 | 对策 |
| --- | --- | --- |
| 厂商锁定 | 迁不动 | 抽象 + 标准接口 |
| 流量费用 | 账单爆 | 内网 + 预算告警 |
| 地域错 | 延迟高 | 就近部署 |
| SLA 误读 | 故障无赔 | 看细则 |
| 过度配置 | 浪费 | 监控 + 调优 |

## 6. 面试题

1. 选云首要看什么？
2. 如何降低云成本？
3. 厂商锁定如何规避？
4. 国内合规要注意什么？
5. 预留实例适合什么负载？

## 7. 小结

云 IaaS 选型 = 业务匹配 + 成本结构 + 合规地域 + 锁定风险。核心是"按需选形态、按量控成本、用抽象降低锁定"。
