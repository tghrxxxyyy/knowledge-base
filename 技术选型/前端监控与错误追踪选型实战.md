# 前端监控与错误追踪选型实战

> 前端是"最靠近用户的未知"：用户设备、网络、浏览器千差万别，问题难以复现。前端监控要抓性能、捕获异常、还原现场、量化体验。选型要在埋点 SDK、错误聚合、会话回放、性能分析之间权衡。

## 1. 监控维度

| 维度 | 指标 | 工具关注 |
| --- | --- | --- |
| 错误 | JS 异常、资源加载失败 | 捕获 + 聚合 |
| 性能 | FCP/LCP/CLS、API 耗时 | Web Vitals |
| 行为 | 路由、点击、白屏 | 用户轨迹 |
| 流量 | PV/UV、地域、机型 | 统计 |

## 2. 错误捕获

```javascript
// 全局错误与 Promise 拒绝
window.addEventListener('error', e => report(e.error || e));
window.addEventListener('unhandledrejection', e => report(e.reason));
// 资源加载错误(捕获阶段)
document.addEventListener('error', e => {
  if (e.target.tagName) report({ src: e.target.src });
}, true);
```

- **Source Map**：生产混淆后还原堆栈。
- **聚合**：按错误指纹去重，避免刷屏。
- **上下文**：UA、路由、用户 ID 一并提供。

## 3. 会话回放

- 记录 DOM 变化 / 操作序列，回放排障。
- 注意隐私：脱敏输入、避免录密码。
- 抽样存储，控制成本。

## 4. 性能分析

- 接入 RUM，采集 Web Vitals。
- 慢接口、慢资源下钻定位。
- 与后端链路追踪打通（traceId 透传）。

## 5. 常见坑

| 坑 | 现象 | 对策 |
| --- | --- | --- |
| 堆栈看不懂 | 难定位 | Source Map |
| 错误刷屏 | 噪声 | 指纹聚合 |
| 隐私泄露 | 合规风险 | 脱敏 |
| 性能开销 | 拖慢页面 | 异步 + 采样 |
| 数据孤岛 | 难联动 | 全链路 trace |

## 6. 面试题

1. 前端错误如何全量捕获？
2. Source Map 在生产如何安全用？
3. 会话回放隐私怎么处理？
4. 如何量化前端体验？
5. 前后端链路如何打通？

## 7. 小结

前端监控 = 错误捕获 + 性能 RUM + 会话回放 + 全链路追踪。核心是"把用户侧的黑盒变成可观测、可复现、可量化"。
