# 数据可视化与 BI 系统设计实战

> BI 系统把数据变成"看得懂、能决策"的图表与看板。它要搞定数据接入、建模、查询加速、可视化、权限，难点在**大数据量下的交互查询性能**与**多角色的数据安全**。

## 1. 系统分层

```mermaid
flowchart LR
    S[数据源] --> E[ETL]
    E --> DW[(数仓/湖)]
    DW --> OLAP[(OLAP引擎)]
    OLAP --> V[可视化/看板]
    V --> U[用户]
```

## 2. 核心模块

| 模块 | 关键 |
| --- | --- |
| 数据建模 | 维度/指标、星型模型 |
| 查询加速 | 预聚合、物化视图、列存 |
| 可视化 | 图表库、下钻、联动 |
| 权限 | 行/列级、看板授权 |
| 自助 | 拖拽建模、即席查询 |

## 3. 性能优化

- **预聚合**：常用指标提前算，查询直取结果。
- **列存 + 向量化**：OLAP 引擎（如 ClickHouse）秒级响应。
- **缓存**：看板结果缓存，相似查询命中。
- **查询限制**：超时、返回行数上限防拖垮。

## 4. 权限与安全

- 行级：按组织/区域过滤数据。
- 列级：敏感字段脱敏或隐藏。
- 看板授权：不同角色可见不同看板。
- 导出审计：谁导出了什么可追溯。

## 5. 常见坑

| 坑 | 现象 | 对策 |
| --- | --- | --- |
| 查询慢 | 等半天 | 预聚合 + OLAP |
| 数据泄露 | 越权 | 行列权限 |
| 口径乱 | 数不对 | 统一指标定义 |
| 看板卡 | 渲染慢 | 分页 + 懒加载 |
| 口径漂移 | 前后不一致 | 指标中心 |

## 6. 面试题

1. BI 查询如何加速？
2. 行列级权限如何实现？
3. 指标口径如何统一？
4. 大数据量可视化如何不卡？
5. 自助分析如何防乱查？

## 7. 小结

BI 系统 = 建模 + OLAP 加速 + 可视化 + 行列权限。核心是"让数据快查、口径统一、安全可控"。
