## 序 · 关于这本书

这是一份**个人后端技术知识库**，内容整理自日常学习与有道云笔记导出，并持续补充大模型、大数据、CI/CD 等现代工程专题。

它不像教科书那样按章节线性编排，而更接近一本**活页笔记**——你可以：

- 按**目录（下方分卷）**跳到感兴趣的篇章；
- 顺着**阅读路径**做主题式通读；
- 用 GitHub 的搜索（`t` 键 / 文件查找）直接定位关键词；
- 从任意一篇的「与其他模块的关联」顺藤摸瓜，串起整个知识体系。

本书追求**事无巨细 + 原理通透**：概念配口诀、架构配 Mermaid 图、选型配对比表、上线配生产踩坑（⚠️）。希望它既能当**速查手册**，也能当**系统教材**。
