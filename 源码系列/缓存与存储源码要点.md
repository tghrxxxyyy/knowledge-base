# 缓存与存储源码要点（Redis / MySQL）

> 板块：源码系列 　|　 返回：[README](README.md)

## 一、Redis 要点

- **单线程模型**：命令串行执行，避免锁；I/O 多线程（6.0+）只管网络读写。
- **数据结构**：SDS、跳表（ZSet）、字典（Hash）、压缩列表/列表 pack。
- **持久化**：RDB（快照）+ AOF（追加），混合持久化。
- **过期与淘汰**：惰性删除 + 定期删除；内存满按策略（LRU/LFU）淘汰。
- **集群**：槽位（16384）分片，Gossip 通信。

## 二、MySQL 要点

- **InnoDB**：B+ 树索引、聚簇索引、MVCC、undo/redo log。
- **事务**：ACID，隔离级别（RR 靠 MVCC + 间隙锁）。
- **Buffer Pool**：缓存页，减少磁盘 IO。
- **binlog**：主从复制与 CDC（Canal/Debezium）数据源。
