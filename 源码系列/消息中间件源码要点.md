# 消息中间件源码要点（Kafka / RocketMQ）

> 板块：源码系列 　|　 返回：[README](README.md)

## 一、Kafka 核心

- **顺序写 + 零拷贝**：高吞吐根基。
- **Partition**：并行单元，同 key 落同分区保序。
- **ISR 机制**：leader 与同步副本集合，保证不丢已提交消息。
- **消费位移**：offset 提交（自动/手动），影响「至少一次/恰好一次」。

## 二、RocketMQ 核心

- **CommitLog**：所有消息顺序写，消费队列（ConsumeQueue）作索引。
- **事务消息**：半消息 + 回查，保证本地事务与消息一致。
- **按 Tag 消费**：见用户实践「按 tag 消费」过滤消息。
- **刷盘策略**：同步/异步，权衡可靠与性能。

## 三、共性设计

- 顺序写盘、PageCache、零拷贝（sendfile）。
- 副本与 ACK 保证可靠。
- 消费幂等由业务保证。
