# 算法手撕与编码面试精讲

> 算法面试核心是"思路清晰 + 编码正确 + 复杂度分析"。本文整理高频题型套路与编码注意事项。

## 1. 通用解题框架

1. **澄清**：输入规模、边界、是否允许额外空间。
2. **举例**：小例子验证逻辑。
3. **暴力**：先给朴素解，再优化。
4. **优化**：用合适数据结构/技巧（双指针、哈希、堆、前缀和）。
5. **编码**：注意边界、空输入。
6. **复杂度**：时间/空间分析。
7. **测试**：跑例子、极端 case。

## 2. 高频题型套路

**双指针**
- 快慢指针（链表环、中点）。
- 对撞指针（有序数组两数之和）。
- 滑动窗口（最长无重复子串）。

**哈希表**
- 计数（词频）、查重、O(1) 查找。
- 两数之和：边遍历边存 map。

**二分查找**
- 在有序/单调上二分。
- 注意边界（left<=right、mid 计算防溢出）。

**DFS/BFS**
- DFS：递归/栈，适合路径、回溯。
- BFS：队列，适合最短路径、层序。

**动态规划**
- 定义 dp 状态 → 转移方程 → 初始化 → 遍历顺序。
- 背包、最长子序列、编辑距离。

**堆/优先队列**
- Top K、中位数、合并 K 个有序链表。

**前缀和/差分**
- 区间求和、频次统计。

## 3. 编码陷阱

| 陷阱 | 说明 |
| --- | --- |
| 空输入/单元素 | 提前返回 |
| 整数溢出 | 用 long 或防溢出 |
| 数组越界 | 边界检查 |
| 死循环 | 指针移动条件 |
| 重复元素 | 用 set 或去重 |

## 4. 示例：最长无重复子串

```python
def lengthOfLongestSubstring(s: str) -> int:
    seen = {}
    left = 0
    ans = 0
    for right, ch in enumerate(s):
        if ch in seen and seen[ch] >= left:
            left = seen[ch] + 1
        seen[ch] = right
        ans = max(ans, right - left + 1)
    return ans
```

- 滑动窗口 + 哈希记录上次位置。
- 复杂度 O(n) 时间，O(k) 空间。

## 5. 复杂度分析

- **时间**：循环次数 × 单次操作。
- **空间**：额外数据结构规模。
- 能说明数量级（O(n)、O(n log n)）即可。
