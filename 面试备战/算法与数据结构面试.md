## 一、复杂度速记（开口就答）

| 结构/算法 | 时间 | 空间 | 备注 |
|----------|------|------|------|
| 数组随机访问 | O(1) | O(n) | 连续内存 |
| 哈希表 | 平均 O(1) | O(n) | 最坏 O(n)（冲突链） |
| 二分查找 | O(log n) | O(1) | 必须有序 |
| 堆（优先队列） | 插入/取顶 O(log n) | O(n) | TopK 神器 |
| 快排/归并 | O(n log n) | O(log n)/O(n) | 快排最坏 O(n²) |
| BFS/DFS | O(V+E) | O(V) | 图遍历 |
| 二叉树遍历 | O(n) | O(h) | h=树高 |

> 面试第一句先报复杂度，再写代码——这是专业度的分水岭。

## 二、数组与双指针

| 题型 | 套路 |
|------|------|
| 两数之和 | 哈希表存 `target-nums[i]`（O(n)） |
| 有序数组两数/三数之和 | 双指针收缩 |
| 接雨水/盛水 | 双指针 + 维护左右最大 |
| 滑动窗口（最长子串） | 左右指针 + 哈希/计数维护窗口 |

```java
// 两数之和（O(n)）
Map<Integer,Integer> m = new HashMap<>();
for (int i=0;i<n;i++){
    if (m.containsKey(target-nums[i])) return new int[]{m.get(target-nums[i]), i};
    m.put(nums[i], i);
}
```

## 四、二叉树

| 题型 | 套路 |
|------|------|
| 前/中/后/层序 | 递归 / 队列 BFS |
| 最大深度/路径和 | DFS 回溯 |
| 最近公共祖先 LCA | 后序递归 |
| 二叉搜索树 | 利用 BST 性质（左<根<右） |
| 序列化 | 前序/层序 + 占位符 |

```java
// 最大深度（递归版）
int maxDepth(TreeNode n){ return n==null?0:1+Math.max(maxDepth(n.left),maxDepth(n.right)); }
```

## 五、二分查找（模板）

```java
int lo=0, hi=n-1, ans=-1;
while (lo<=hi){
    int mid=lo+(hi-lo)/2;
    if (check(mid)) { ans=mid; hi=mid-1; }  // 找左边界
    else lo=mid+1;
}
```

- 找左边界：`check` 成立则 `hi=mid-1`；
- 找右边界：`check` 成立则 `lo=mid+1`；
- 易错点：死循环（区间收缩）+ 边界更新。

## 六、动态规划（DP）

| 题型 | 套路 |
|------|------|
| 最长上升子序列 LIS | `dp[i]=max(dp[j]+1)`，或二分贪心 O(n log n) |
| 背包（01/完全） | `dp[i][w]` 状态转移 |
| 编辑距离 | 二维 DP，三操作取最小 |
| 股票买卖 | 状态机 DP（持有/不持有） |

**DP 五步法**：定义状态 → 转移方程 → 初始化 → 遍历顺序 → 压缩空间。
> 面试别硬想最优解，先给暴力（回溯/DFS），再优化成 DP。

## 八、堆与 TopK

- **TopK 大**：最小堆维护 K 个元素；
- **中位数**：双堆（大顶+小顶）；
- **第 K 大**：快排 partition 或堆。

```java
// 前 K 大（最小堆）
PriorityQueue<Integer> pq = new PriorityQueue<>();
for (int x : nums){
    pq.offer(x);
    if (pq.size()>k) pq.poll();
}
```

## 九、回溯与DFS（排列组合子集）

```java
void dfs(int i){
    if (i==n){ res.add(new ArrayList<>(path)); return; }
    // 选
    path.add(nums[i]); dfs(i+1); path.remove(path.size()-1);
    // 不选
    dfs(i+1);
}
```
- 去重：先排序，`if(i>0 && nums[i]==nums[i-1] && !used[i-1]) continue;`
- 剪枝：提前判断非法，减少搜索空间。

## 十、避坑清单

- ❌ 不确认边界（空数组、n=1、负数）→ 先问/先判；
- ❌ 复杂度说不清 → 开口先报；
- ❌ 死循环（二分/快慢指针）→ 画指针移动；
- ❌ 忽略溢出（int 相乘超界）→ 用 long；
- ❌ 不写测试用例 → 至少跑 1 组 happy + 1 组边界。

## 十一、面试高频追问

1. Q：两数之和最优？ A：哈希表 O(n)，空间换时间。
2. Q：二分查找易错点？ A：边界更新防死循环、区间定义一致。
3. Q：DP 怎么想？ A：定义状态→转移→初始化→顺序→空间压缩，先暴力再优化。
4. Q：TopK 用什么？ A：最小堆维护 K 个，O(n log k)。
5. Q：链表判环？ A：Floyd 快慢指针，相遇则有环，再找入口。
6. Q：岛屿数量？ A：遍历 grid，遇 '1' 就 DFS/BFS 标记连通块并计数。
7. Q：回溯去重？ A：排序后 `nums[i]==nums[i-1] && !used[i-1]` 跳过。
8. Q：Dijkstra 适用？ A：边权非负的单源最短路；负权用 Bellman-Ford。
