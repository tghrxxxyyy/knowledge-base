# 前端与全栈面试精讲

> 全栈工程师需兼顾前端工程、浏览器原理与后端协作。本文整理前端高频面试题与核心原理。

## 1. 浏览器与渲染

**Q：从输入 URL 到页面显示经历了什么？**
DNS 解析 → 建立 TCP/TLS → 发送请求 → 解析 HTML 构建 DOM → CSSOM → 渲染树 → 布局 → 绘制 → 合成。

**Q：重排（reflow）与重绘（repaint）？**
- 重排：几何变化（尺寸/位置），代价大。
- 重绘：外观变化（颜色），较轻。
- 优化：批量修改、用 transform/opacity（只合成）。

## 2. JS 事件与异步

**Q：事件循环（Event Loop）？**
宏任务（script/setTimeout/I/O）与微任务（Promise/microtask）队列；每轮先清微任务再取宏任务。

**Q：Promise/async-await 原理？**
Promise 是状态机（pending/fulfilled/rejected）；async 语法糖，await 挂起等待。

**Q：防抖与节流？**
- 防抖：停止触发 N 秒后才执行（搜索框）。
- 节流：每 N 秒最多一次（滚动/resize）。

## 3. 框架（React/Vue）

**Q：React 受控与非受控组件？**
受控：value 由 state 驱动；非受控：用 ref 直接操作 DOM。

**Q：虚拟 DOM 与 Diff？**
用 JS 对象描述 DOM，更新时对比新旧虚拟 DOM，最小化真实 DOM 操作。Diff 按同层、key 复用。

**Q：Vue 响应式原理？**
Object.defineProperty / Proxy 劫持属性，依赖收集（Dep/Watcher），变更触发更新。

**Q：Hooks 为什么不能条件调用？**
依赖调用顺序，条件调用会打乱顺序导致错误。

## 4. 工程化

**Q：Webpack/Vite 区别？**
- Webpack：打包时构建，配置重，HMR 慢。
- Vite：基于 ESM，开发时按需编译，冷启快。

**Q：Tree Shaking？**
依赖 ES Module 静态分析，剔除未使用代码（需 `sideEffects` 标记）。

**Q：常见性能优化？**
代码分割、懒加载、缓存（强缓存/协商）、CDN、图片优化、减少重排。

## 5. 全栈协作

**Q：前后端如何约定接口？**
OpenAPI/Swagger 定义契约；Mock 并行开发；前后端分离部署。

**Q：跨域（CORS）？**
浏览器同源策略限制；服务端返回 `Access-Control-Allow-Origin` 等头；预检 OPTIONS。

**Q：JWT 与 Session 认证？**
- Session：服务端存状态，靠 cookie。
- JWT：无状态 token，含签名，前端携带。

## 6. 实战题

**Q：页面白屏如何排查？**
看 Network（资源是否加载）、Console（报错）、JS 报错、路由配置、构建产物。

**Q：首屏慢如何优化？**
代码分割、SSR/预渲染、资源压缩、关键 CSS 内联、图片懒加载。

**Q：内存泄漏怎么查？**
DevTools Memory 快照对比，找未释放的引用（闭包、事件监听、定时器）。

## 8. 小结

前端面试围绕"浏览器原理、JS 异步、框架机制、工程化、全栈协作"。理解渲染管线与事件循环是底层基础，框架只是其上封装。
