# 金融风控与反欺诈业务模型

> 本文聚焦金融场景下的风控与反欺诈业务建模：信贷风控、交易反欺诈、设备与身份风控、规则+模型+图谱的体系，以及与实时风控（见场景设计实时风控章节）的衔接。内容基于公开行业实践，具体策略参数以业务与合规为准。

## 1. 金融业务的风险类型

- 信用风验：借款人违约（信贷场景）。
- 欺诈风险：盗用、虚假申请、团伙骗贷。
- 交易风险：盗刷、洗钱、套现。
- 操作风险：内部违规、系统错误。
- 合规风险：反洗钱（AML）、KYC 不实。

## 2. 风控的核心目标

- 在"通过率"与"坏账/欺诈率"间找平衡。
- 过度严格：好用户被拒，业务损失。
- 过度宽松：坏用户进入，资损。
- 用风险定价（利率/额度）精细化区分。

## 3. 信贷风控流程

```
申请 → 身份核验(KYC) → 反欺诈筛查 → 信用评分
   → 规则决策(拒/过/转人工) → 授信(额度/利率) → 贷后监控
```

- 贷前：准入、反欺诈、授信。
- 贷中：交易监控、行为变化。
- 贷后：催收、逾期预测。

## 4. 反欺诈体系

- 设备指纹：识别设备唯一性，检测模拟器/农场。
- 身份核验：活体、证件 OCR、人脸比对。
- 行为生物：打字节奏、操作轨迹。
- 关系网络：设备/手机号/地址关联分析。
- 名单：黑/白/灰名单。

## 5. 规则引擎

- 硬规则：命中直接拒绝（如黑名单、异地异常）。
- 软规则：加分/减分，汇总风险分。
- 规则管理：可视化配置、版本、灰度。
- 与实时风控章节的"规则引擎"呼应。

## 6. 信用评分模型

- 逻辑回归/树模型/评分卡：输出违约概率。
- 特征：征信、收入、负债、行为、社交。
- 训练需处理样本不平衡（坏样本少）。
- 模型需可解释（监管与客诉）。

## 7. 图计算与团伙识别

- 把用户/设备/账户作为节点，关系作为边。
- 社群发现：识别欺诈团伙（集群、环路）。
- 中心度：识别中介/核心账号。
- 传播：风险沿关系扩散评分。
- 与图数据库/图计算引擎结合。

## 8. 实时 vs 离线

- 实时：交易/登录瞬间决策（毫秒级），用规则+轻模型。
- 离线：训练模型、回溯案件、策略回测。
- 实时特征需与离线一致（见特征章节）。
- 异步：先放行后核查（弱风险）。

## 9. 特征平台

- 实时特征：滑动窗口计数（近 N 分钟同设备交易数）。
- 离线特征：历史坏账率、稳定属性。
- 特征一致性：训练服务偏斜是常见问题。
- 特征存储：Redis/KV + 数仓。

## 10. 决策流编排

- 名单 → 规则 → 模型 → 风险分 → 决策（通过/拒绝/人工）。
- 可视化决策平台，策略人员自助调整。
- 灰度与回滚：新策略先小流量。

## 11. 人工审核

- 高风险/边界案例转人工。
- 审核有 SLA，影响体验。
- 人工标注反哺模型与规则。
- 审核本身也是成本，需平衡自动化率。

## 12. 贷后管理

- 逾期预测：提前识别可能逾期用户。
- 催收策略：短信、电话、委外分级。
- 行为监控：异常交易、额度挪用。
- 早期干预降低坏账。

## 13. 反洗钱（AML）

- 监测异常资金链路：快进快出、分散转入集中转出。
- 大额与可疑交易报告（按监管要求）。
- 制裁名单筛查。
- 合规是硬性要求，以当地法规为准。

## 14. 对抗演进

- 黑产养号、设备农场、虚假资料。
- 攻防循环：新手法 → 新规则/样本 → 再演进。
- 缩短反馈环：案件到规则/模型的沉淀速度。
- 与实时风控"对抗演进"章节一致。

## 15. 指标

- 通过率、拒绝率、欺诈率、坏账率。
- 误杀率（好用户被拒）。
- 案件确认率、人工审核量。
- 决策延迟 P99。

## 16. 常见踩坑

1. **规则硬编码**：改规则发版慢；应平台化。
2. **特征穿越**：用未来信息训练，线上崩；严格时序。
3. **训练服务偏斜**：线上线下特征口径不一。
4. **过度依赖规则**：漏新型欺诈；模型+图谱补位。
5. **误杀无申诉**：用户体验崩；建解封通道。
6. **忽略团伙**：只看单点，漏掉有组织的骗贷；上图计算。
7. **合规滞后**：AML/ KYC 不合规，法律风险。

## 17. 与支付/账务关系

- 交易反欺诈在支付链路上（见支付清结算章节）。
- 信贷风控在授信链路上（本文）。
- 二者共享设备/身份/名单基础设施。
- 统一风控中台避免重复建设。

## 18. 落地清单

- 身份核验与 KYC。
- 设备指纹与反欺诈规则。
- 信用评分模型（可解释）。
- 图计算识别团伙。
- 实时决策流 + 人工审核。
- 特征平台保证一致。
- 案件回灌与策略迭代。
- 合规（AML/制裁筛查）。

## 19. 小结

金融风控是"规则 + 模型 + 图谱 + 决策流 + 对抗迭代"的体系，信贷与反欺诈共用身份/设备/名单基础设施。铁律：**特征时序正确无穿越、训练服务一致、可解释满足监管、团伙用图计算、误杀有申诉、合规不可缺**。在通过率与资损间找平衡，并用案件快速回灌形成攻防闭环。
