# 生鲜电商业务模型

> 生鲜是电商里履约最难的垂直：短保、易损、时效敏感、非标品多。它的命脉在**供应链（源头/冷链）**与**履约时效（30 分钟达）**，损耗率直接决定毛利。业务模型围绕"鲜"和"快"展开。

## 1. 业务结构

```mermaid
flowchart LR
    S[产地/供应商] --> W[仓:冷链]
    W --> F[前置仓/门店]
    F --> D[即时配送]
    D --> U[用户]
```

## 2. 核心模块

| 模块 | 关键 |
| --- | --- |
| 供应链 | 产地直采、分级、质检 |
| 仓储 | 冷链、批次、效期管理 |
| 履约 | 前置仓拣货、即时配 |
| 损耗 | 动态定价、临期处理 |
| 商品 | 非标品标准化（重量/规格） |

## 3. 时效与损耗

- **前置仓**：贴近社区，缩短最后一公里。
- **动态定价**：临期商品降价，降低损耗。
- **智能补货**：按销量预测补，避免积压/缺货。
- **效期管理**：先进先出，临期预警。

## 4. 履约体验

- 准时达承诺（如 30 分钟/1 小时）。
- 缺货/坏果极速赔，建立信任。
- 会员制提升复购与预测准确度。

## 5. 常见坑

| 坑 | 现象 | 对策 |
| --- | --- | --- |
| 损耗高 | 亏本 | 动态定价 + 预测 |
| 不新鲜 | 差评 | 冷链 + 效期 |
| 配送慢 | 流失 | 前置仓密度 |
| 非标 | 纠纷 | 标准化 + 实拍 |
| 成本高 | 不盈利 | 密度 + 会员 |

## 7. 小结

生鲜电商 = 冷链供应链 + 前置仓履约 + 损耗管控 + 信任赔付。核心是"用时效和新鲜换溢价，用预测和定价压损耗"。
