# 保险业务模型（深扒）

> 保险是金融里「**长周期、强精算、重合规**」的异类：交易不是即时买卖，而是「投保 → 核保 → 承保 → 理赔」的长链条，核心在**风险定价（精算）与反欺诈理赔**。
>
> 配套总览见「[业务模型总览](业务模型总览.md)」；金融一致/合规见「[证券基金交易](证券基金交易业务模型.md)」「[企业服务SaaS](企业服务SaaS业务模型.md)」。

## 二、核心系统架构

### 2.1 产品与费率（精算驱动）
- 产品由**条款 + 费率表 + 责任**配置化定义，新险种尽量不硬编码。
- 费率由精算模型给出，支持因子（年龄/车型/健康）动态计算保费。

### 2.2 核保（风险把关）
- 自动核保：规则引擎（健康告知、职业、历史）实时出结论（通过/加费/拒保）。
- 人工核保：复杂件转核保员，需留痕。

### 2.3 保单生命周期
- 状态机：`投保 → 核保通过 → 已承保 → 已缴费/逾期 → 失效/退保 → 理赔/满期`。
- 长周期：续期缴费、复效、批改（变更被保人/受益人）。

### 2.4 理赔与反欺诈
- 报案 → 查勘/定损 → 理算 → 核赔 → 赔付；医疗险需单证 OCR + 审核。
- 反欺诈：识别团伙骗保、夸大损失，用关系图谱 + 行为模型。

## 六、深挖：核心业务机制

### 6.1 精算定价与费率表

```
保费 = 纯风险保费（预期赔付）+ 附加保费（费用/利润）
纯风险保费 = 损失频率 × 损失强度（由精算模型估计）
```

| 定价要素 | 说明 |
|----------|------|
| 损失频率 | 出险概率（健康/年龄/车型/职业因子） |
| 损失强度 | 单次赔付金额分布（重疾/免赔额） |
| 大数法则 | 样本越大预测越稳，新险种数据不足用行业数据 |
| 费率表 | 因子 × 因子 → 费率，配置化发布，支持定价调整 |

> 工程要点：费率表**配置化 + 版本化**（新费率灰度、旧保单按原费率续保），绝不能硬编码。

### 6.2 自动核保规则引擎

```
投保单 → 规则引擎（健康告知/职业/年龄/历史理赔）
  → 通过 / 加费 / 除外 / 拒保 / 转人工
```

- 规则**可编排、可热更新、可解释**（拒保要给客户理由 → 审计要求）；
- 复杂件转人工核保：人工结论留痕 + 时效 SLA（如 24h）；
- 与风控联动：命中反欺诈名单先拦截。

### 6.3 理赔反欺诈（图谱 + 模型）

| 手段 | 识别什么 | 技术 |
|------|----------|------|
| 规则 | 高频报案、异地就医异常 | 规则引擎 |
| 关系图谱 | 团伙骗保（同一医院/同一代理人关联） | 图数据库 + 社群发现 |
| 行为模型 | 理赔单文本异常、金额分布异常 | ML 模型打分 |
| OCR 核验 | 单据篡改 | OCR + 篡改检测 |

> 前置在**理赔审核环节**而非事后：命中高风险自动转人工重点审核。

## 七、核心指标与数据驱动

| 维度 | 指标 | 说明 |
|------|------|------|
| 经营 | 保费收入、续保率 | 北极星 |
| 定价 | 赔付率、综合成本率（COR） | 精算健康度 |
| 效率 | 自动核保通过率、理赔时效（TAT） | 体验 |
| 风控 | 反欺诈拦截率、漏检率 | 资损 |
| 技术 | 投保流程耗时、系统可用率 | 99.9%+ |

> 保险核心矛盾：**赔付率（少赔）与体验（快赔）的平衡**——自动核保/极速理赔降成本，反欺诈防止被薅穿。

## 八、面试与系统设计视角

1. 设计一个保险产品配置系统：条款 + 费率表 + 责任规则，版本化发布。
2. 长周期保单状态机怎么设计：状态 + 事件 + 校验（禁非法跳变），事件溯源可选。
3. 自动核保怎么实现：规则引擎（可编排热更新）+ 人工兜底。
4. 理赔反欺诈怎么做：规则 + 关系图谱 + 模型三级拦截。
5. 续期缴费怎么保证一致性：扣费幂等 + 对账 + 宽限期状态机。

---

## 九、保险特有坑

- **状态机错乱**：长周期手动改状态 → 事件驱动 + 不可跳变校验。
- **核保规则硬编码**：新险种改代码 → 规则引擎配置化。
- **骗保漏检**：事后才发现 → 反欺诈前置 + 图谱识别团伙。
- **保单数据不一致**：缴费与承保不同步 → 事务/事件最终一致 + 对账。
- **合规缺失**：无审计 → 监管风险，全链路留痕必做。

> 口诀：**"保险长链条：产品配置化，核保规则引擎，保单状态机；理赔反欺诈，图谱先识别，合规全留痕，长周期对账。"**
