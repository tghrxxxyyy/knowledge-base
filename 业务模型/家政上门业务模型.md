# 家政上门业务模型

> 对应 Osterwalder & Pigneur《Business Model Generation》；平台经济（Parker, Van Alstyne & Choudary《平台革命》）运营实践。

> 家政是典型的「人力调度 + 非标服务」本地生活业务：保洁、月嫂、保姆、家电清洗。命脉是供给侧（阿姨）调度与服务质量标准化，两端都难做。它既是双边平台，又是重交付的服务业，平台的核心资产是「稳定且标准化的阿姨供给」。

## 一、背景与挑战

家政是典型的双边平台：一端是高度非标、难以规模化的「人」（阿姨），另一端是对结果敏感、容错低的用户。行业长期受「阿姨短缺、跳单、质量不稳」三座大山困扰，烧钱拉用户却无阿姨接单是常见死法。挑战：(1) **供给侧稀缺**——好阿姨有限，旺季接不了单；(2) **匹配难**——距离、技能、评分、时间窗多重约束；(3) **质量波动**——同一项目不同人做结果不同；(4) **跳单与信任**——绕过平台与财物安全；(5) **培训成本**——标准化意味着持续培训投入；(6) **安全**——入户服务的财物与人身安全风险。

## 二、核心原理

模型围绕「供给侧调度 + 服务标准化 + 信任保险」。供给侧建阿姨池（实名、技能标签、可服务区域、排班）；调度按距离、评分、空闲度综合选优；服务侧以 SOP 清单 + 验收留痕 + 质保返工保证一致；商业上按时长/面积/项目计费，平台抽成 + 保险兜底意外与财物。平台角色是「标准制定者 + 信任中介」，而非单纯流量分发；通过「分成+评价资产」把阿姨黏在体系内，降低跳单。

## 三、形式化与数学基础

调度可建模为带时间窗的人员指派。阿姨 $j$ 对订单 $i$ 的效用：

$$u_{ij} = \alpha \cdot \text{评分}_j - \beta \cdot \text{距离}_{ij} - \gamma \cdot \text{空窗成本}_j$$

目标 $\max \sum_{i,j} u_{ij} x_{ij}$，约束每单恰一人、每人不超工时。单位经济：

$$\text{毛利} = \text{客单价} \times (1 - \text{抽成率}) - \text{履约成本},\quad \text{回收期}=\frac{\text{CAC}}{\text{月毛利}}$$

跳单率 $p$ 直接侵蚀 LTV，需以「平台绑定 + 评价资产」降低；阿姨留存率 $r_a$ 决定供给池健康度，是比 CAC 更先行的指标。设供给满足率 $\eta$，则接单失败损失与 $(1-\eta)$ 成正比。

## 四、代码实现

就近 + 评分选优的简化调度（示意）：

```python
def pick_agent(order_loc, agents, top_score=0.0):
    cands = [a for a in agents if a.free and a.region == order_loc.region]
    if not cands:
        return None
    return max(cands, key=lambda a: 0.6*a.rating - 0.4*distance(order_loc, a.loc))

def check_sop(done_items, required):  # 验收：清单逐项核对
    return set(required).issubset(set(done_items))

def churn_risk(agent):
    # 近期接单下降+被撬单信号
    return agent.off_platform_rate > 0.1 or agent.idle_days > 14
```

## 六、常见误区

- **阿姨短缺**：无供给池运营，旺季崩；需招募 + 培训 + 激励。
- **匹配差**：只看距离忽略技能，客诉；多约束选优。
- **质量波动**：无 SOP，体验飘；清单 + 验收 + 质保。
- **跳单**：无绑定，平台被绕过；评价资产 + 信任机制。
- **安全**：财物损失无兜底；保险 + 实名。
- **重流量轻供给**：烧钱拉用户却无阿姨接单，双边飞轮转不起来。

## 九、演进与趋势

- 智能化调度（实时供需预测 + 动态排班）压低空驶。
- 阿姨职业化与等级体系提升质量与留存。
- 家政+养老/育儿融合拓展场景。
- 保险与信用体系完善降低交易摩擦。
- AI 排班与培训标准化，供给池健康度成为竞争壁垒。

运营落地要点：

- 供给池健康度（阿姨月活、接单率、流失率）应每日监控，劣化即触发招募与激励。
- SOP 验收留痕既是质量抓手，也是纠纷时的举证依据。
- 跳单防控靠「评价资产 + 平台内交易闭环」，让双方都不愿绕开平台。
- 保险与实名是入户服务的底线，应作为接单前置条件而非可选项。

## 十、小结

家政 = 供给侧调度 + 服务标准化 + 信任保险。核心是把「人」这件最难的事做稳——供给池健康度决定业务上限，SOP 与质保决定口碑下限，平台资产沉淀在「标准化阿姨」而非流量，安全与保险是入户服务的底线。
