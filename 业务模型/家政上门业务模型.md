# 家政上门业务模型

> 家政是典型的"人力调度 + 非标服务"本地生活业务：保洁、月嫂、保姆、家电清洗。它的命脉是**供给侧（阿姨）调度**与**服务质量标准化**，两端都难做。

## 1. 业务链路

```mermaid
flowchart LR
    U[用户下单] --> M[匹配阿姨]
    M --> S[上门服务]
    S --> P[验收/评价]
    P --> R[结算/复购]
```

## 2. 供给侧核心

| 要素 | 说明 |
| --- | --- |
| 阿姨池 | 实名、技能标签、可服务区域 |
| 排班 | 时间窗 + 区域就近匹配 |
| 调度 | 距离、评分、空闲度综合选优 |
| 培训 | 服务 SOP 统一标准 |

## 3. 服务标准化

- **服务清单**：每一步做什么、做到什么程度。
- **验收标准**：照片留痕 + 用户确认。
- **质保**：不满意返工/补偿。

## 4. 定价与结算

- 按时长/面积/项目计费。
- 阿姨抽成 + 平台佣金。
- 保险兜底（意外、财物）。

## 5. 常见坑

| 坑 | 现象 | 对策 |
| --- | --- | --- |
| 阿姨短缺 | 接不了单 | 供给池运营 |
| 匹配差 | 远/不熟 | 就近 + 标签 |
| 质量波动 | 客诉 | SOP + 质保 |
| 跳单 | 绕过平台 | 绑定 + 信任 |
| 安全 | 财物损失 | 保险 + 实名 |

## 7. 小结

家政 = 供给侧调度 + 服务标准化 + 信任保险。核心是"把人这件最难的事做稳"，供给侧健康度决定业务上限。
