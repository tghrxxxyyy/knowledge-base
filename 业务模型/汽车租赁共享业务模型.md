# 汽车租赁共享业务模型

> 租车与共享汽车是"重资产 + 高运营"业务：车辆采购、调度、运维、风控环环相扣。核心难点在**资产利用率**与**车况/安全风控**，毛利高度依赖周转。

## 1. 业务结构

```mermaid
flowchart LR
    U[用户] --> B[选车/下单]
    B --> P[取车:网点/送车]
    P --> D[用车]
    D --> R[还车/结算]
    R --> M[整备/清洁]
    M --> B
```

## 2. 核心模块

| 模块 | 关键 |
| --- | --- |
| 车辆管理 | 车型、车牌、保险、年检 |
| 网点调度 | 取还点、车辆调拨 |
| 风控 | 驾照核验、违章、事故 |
| 计费 | 时长 + 里程 + 附加 |
| 运维 | 清洁、加油/电、维修 |

## 3. 资产效率

- **周转率**：单车日均出租时长是生命线。
- **动态调度**：热点区域调车，平衡供需。
- **定价**：闲时低价引流，旺季溢价。

## 4. 风控与安全

- 实名 + 驾照 OCR + 信用核验。
- 行车轨迹监控、电子围栏。
- 保险覆盖车损/三者/盗抢。
- 违章代扣 + 信用约束。

## 5. 常见坑

| 坑 | 现象 | 对策 |
| --- | --- | --- |
| 车辆闲置 | 周转低 | 调度 + 动态价 |
| 车况差 | 客诉 | 整备 SLA |
| 违章扯皮 | 纠纷 | 代扣 + 信用 |
| 事故 | 损失 | 保险 + 监控 |
| 调度失衡 | 无车可用 | 预测调拨 |

## 6. 面试题

1. 如何提升单车周转率？
2. 租车风控怎么做？
3. 车辆调度如何平衡供需？
4. 事故与违章如何闭环？

## 7. 小结

汽车租赁 = 资产管理 + 调度效率 + 风控安全。核心是"让每辆车尽量多转、把风险用保险和信用兜住"。
