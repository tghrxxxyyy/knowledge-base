# 跨境支付与清结算业务模型

> 跨境电商、出海游戏等需要跨境收付款，涉及多币种、外汇、合规与清算网络。本文梳理跨境支付的参与方、资金流与合规要点。

## 1. 参与方

```mermaid
flowchart LR
    B[买家] -->|本币| PSP[收单机构]
    PSP -->|换汇| NET[清算网络]
    NET --> A[商户账户]
    A -->|本币| M[商户]
```

| 角色 | 职责 |
| --- | --- |
| 收单机构 | 在买家所在地收单（本地合规） |
| 卡组织/清算 | Visa/Master/本地清算 |
| 换汇/跨境 | 资金跨境与结售汇 |
| 商户 | 收款方（异地） |

## 2. 资金流与信息流

- **信息流**：订单→收单→授权→清算指令。
- **资金流**：买家本币 → 收单侧 → 跨境清算 → 商户账户（可能涉及换汇）。
- **结算周期**：T+N 结算到商户，受合规与风控影响。

## 3. 关键问题

- **多币种与汇率**：报价币种、结算币种、汇率时点（锁汇/即时）。
- **合规**：反洗钱（AML）、了解你的客户（KYC）、制裁名单筛查。
- **外管与结售汇**：跨境资金流动受外汇管制约束。
- **退款与争议**：跨境退款周期长、手续费高，chargeback 处理复杂。

## 4. 技术挑战

- **风控**：跨境欺诈、盗卡交易识别。
- **对账**：多机构、多币种、多时区对账。
- **合规报送**：交易报送、可疑交易报告。
- **汇率管理**：实时报价与锁汇。

## 5. 常见坑

| 坑 | 风险 | 对策 |
| --- | --- | --- |
| 汇率损失 | 收益缩水 | 锁汇策略 |
| 合规违规 | 处罚 | KYC/AML 全流程 |
| 对账差异 | 财务错 | 自动对账 |
| chargeback | 资损 | 风控+争议处理 |

## 6. 面试题（业务侧）

2. 多币种结算如何管理汇率？
3. 跨境支付合规核心是什么？
4. chargeback 如何处理？

## 7. 小结

跨境支付 = 收单 + 清算 + 换汇 + 合规。复杂度在合规（AML/KYC）与多币种对账，汇率与风控决定最终收益。
