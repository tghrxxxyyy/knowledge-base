# 在线教育业务模型（深扒）

> 在线教育的核心是「**直播课（实时音视频 + 互动） + 内容（录播/题库） + 交易（报名/续费）**」的组合。技术上直播课与「内容直播」同源，题库/学习路径是独有难点。
>
> 配套总览见「[业务模型总览](业务模型总览.md)」；直播/互动见「[内容短视频直播](内容短视频直播业务模型.md)」「[社交IM](社交IM业务模型.md)」。

## 二、核心系统架构

### 2.1 直播课（实时互动）
- 老师推流 → 转码 → **CDN 低延迟分发**；学生端 WebRTC/LL-HLS 收看。
- 互动：举手、连麦、白板、答题，走**长连接 IM**（同社交 IM）。
- **白板/文档同步**：操作指令广播 + 状态对齐，弱网下指令补发。

### 2.2 录播与内容
- 直播自动录制 → 转码多清晰度 → 回放；资料（PPT/PDF）对象存储。
- 播放鉴权：付费课程 URL 带时效 token，防盗链。

### 2.3 题库与学习路径
- 题目结构化（知识点、难度、题型），支持组卷、自适应练习。
- **学习路径**：基于掌握度（掌握/薄弱）推荐下一题/下一课（推荐思路）。

### 2.4 交易
- 单课/套餐/会员/分期；试听→转化→续费漏斗，配合营销（优惠券/拼团）。

## 六、深挖：核心业务机制

### 6.1 白板/文档同步（操作指令 + 状态对齐）

```
白板 = 命令序列(添加/移动/删除/画笔) + 命令序号
广播: 命令带 seq → 各端按 seq 应用 → 弱网补发缺失命令
```

| 方案 | 说明 |
|------|------|
| 状态同步 | 每步传全量状态 → 简单但带宽大 |
| 命令同步（主流） | 传操作指令 + 序号 → 带宽小，需幂等与补发 |
| CRDT/OT | 并发编辑收敛算法 → 多人协作编辑的进阶方案 |

- 断线重连：客户端带 `lastSeq` 拉取缺失命令；
- 教师端优先：学生端只读 + 提交答案（权限分层）。

### 6.2 播放鉴权与防盗链（内容即资产）

```
付费课程 URL = CDN 地址 + 时效 token(signature + expire)
校验链: 播放请求 → 鉴权服务验签 → 返回带时效的播放地址 → CDN 侧校验
```

| 手段 | 防什么 |
|------|--------|
| 时效 token | URL 泄露后限时可用 |
| 防盗链（Referer/UA） | 站外盗播 |
| 视频水印（用户ID） | 盗录后追溯 |
| DRM（进阶） | 高级内容防抓流 |

### 6.3 学习路径（自适应推荐）

```
掌握度评估: 答题正确率 × 知识点难度（IRT/知识图谱）
推荐: 薄弱知识点 → 推对应课程/题目 → 再测 → 更新掌握度（闭环）
```

- 与 [推荐系统设计](../场景设计/推荐系统设计.md) 同源：召回（薄弱知识点相关题）+ 排序（难度适中）+ 重排（不重复）；
- 题库结构化是前提：题目挂知识点 + 难度 + 题型标签。

## 七、核心指标与数据驱动

| 维度 | 指标 | 说明 |
|------|------|------|
| 增长 | 报名转化率、续费率、完课率 | 北极星 |
| 教学 | 掌握度提升、答题正确率 | 效果 |
| 直播 | 首帧时延、卡顿率、互动率 | 体验 |
| 内容 | 回放观看率、防盗链拦截数 | 资产保护 |
| 技术 | 直播并发课数、题库检索时延 | 后端 |

## 八、面试与系统设计视角

1. 设计一个在线课堂：直播 + 白板 + 答题 + 录制回放。
2. 白板同步怎么做：命令序列 + seq 补发（可扩展 OT/CRDT）。
3. 付费视频防盗：时效 token + 防盗链 + 水印。
4. 题库/组卷系统：结构化题目 + 知识点标签 + 自动组卷（难度分布约束）。
5. 学习路径推荐：掌握度评估 + 薄弱知识点推荐闭环。

---

## 九、教育特有坑

- **直播首帧慢**：学生等不起 → 边缘转码 + 预连接。
- **白板不同步**：指令丢失 → 指令序列 + 状态补发。
- **回放盗链**：URL 泄露 → 时效 token + 水印追溯。
- **题库组卷低效**：人工组卷慢 → 结构化 + 自动组卷。
- **续费漏斗断**：试听转化低 → 埋点 + 精准营销触达。

> 口诀：**"教育三块：直播低延迟，内容防盗链，题库结构化；互动走长连，回放带 token，路径靠推荐。"**
