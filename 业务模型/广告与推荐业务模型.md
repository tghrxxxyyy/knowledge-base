# 广告与推荐业务模型

> 本文梳理广告系统（计算广告）与推荐系统的业务建模：广告的参与方与竞价、推荐的数据闭环、核心指标与召回排序架构。内容基于公开工业实践，具体算法与平台规则以业界为准。

## 1. 计算广告的业务模型

### 1.1 参与方

- 广告主（Advertiser）：出钱投广告。
- 媒体/流量方（Publisher/SSP）：提供广告位。
- 用户：浏览/点击/转化。
- 平台（DSP/ADX）：撮合与投放。

### 1.2 关键概念

- 曝光（Impression）：广告被展示。
- 点击（Click）：用户点击。
- 转化（Conversion）：下单/注册等目标行为。
- CPM/CPC/CPA：按千次曝光/点击/转化计费。
- eCPM：预期每千次曝光收入，竞价排序依据。

## 2. 广告竞价机制

### 2.1 RTB 实时竞价

- 用户打开页面 → 广告请求发到 ADX。
- ADX 向多个 DSP 发起竞价（毫秒级）。
- DSP 根据用户画像、出价算 eCPM 返回。
- 价高者得，按二价（次高价+1）结算常见。

### 2.2 出价策略

- 目标：在预算约束下最大化转化/ROI。
- 需预估 CTR（点击率）、CVR（转化率）。
- 自动出价（oCPC/oCPA）按转化目标优化。

## 3. 推荐系统业务模型

### 3.1 目标

- 在合适时机把合适内容/商品推给用户，提升留存/转化。
- 平衡"用户兴趣"与"业务目标"（营收、时长）。

### 3.2 数据闭环

```
用户行为(曝光/点击/购买) → 日志采集
   → 特征工程 → 模型训练
   → 在线推理(召回→排序→重排)
   → 下发 → 新行为 → 闭环
```

### 3.3 召回与排序

- **召回（Recall）**：从海量候选快速筛千级（协同过滤、向量检索、兴趣标签）。
- **排序（Rank）**：对召回结果精排（CTR/CVR 模型）。
- **重排（Re-rank）**：打散、多样性、业务规则、去重。

## 4. 核心指标

### 4.1 广告指标

- CTR = 点击 / 曝光。
- CVR = 转化 / 点击。
- ROI = 收入 / 花费。
- 填充率 = 有广告曝光 / 请求。
- 千次曝光收益（eCPM）。

### 4.2 推荐指标

- 点击率、人均时长、留存率。
- 多样性/新颖性（避免信息茧房）。
- 转化与 GMV 贡献。

## 5. 特征工程

- 用户特征：画像、行为序列、设备、场景。
- 物品特征：类目、标签、统计。
- 上下文：时间、位置、设备。
- 交叉特征：用户×物品交互。
- 序列特征：用户最近行为序列（兴趣演化）。

## 6. 模型演进（思路）

- 传统：LR/GBDT + 特征工程。
- 深度：Embedding + DNN。
- 序列建模：对用户行为序列建模兴趣（如注意力机制思路）。
- 多任务：同时预估 CTR/CVR/时长。
- 强化学习：长程收益（留存）优化（探索与利用）。

## 7. 冷启动

- 新用户：基于注册信息、热门兜底、探索。
- 新物品：少量曝光试探、内容特征补充。
- 探索利用：留部分流量试新内容。

## 8. 评估与实验

- **离线**：AUC、GAUC、NDCG 等。
- **在线**：A/B 实验（分流、显著性检验）。
- ** Guardrail 指标**：防止主指标涨但留存/体验崩。

## 9. 多样性与公平

- 打散避免同质化。
- 控制某一类内容占比。
- 避免歧视性画像（合规）。

## 10. 工程架构

- 在线：低延迟推理（召回服务、排序服务、特征服务）。
- 离线：样本拼接、训练流水线。
- 实时：流式特征更新（Flink）。
- 特征一致性：离线/在线同口径。

## 11. 常见踩坑

1. **离线在线特征不一致**：训练用未来信息或口径不同，线上崩。
2. **只优化 CTR 忽视留存**：标题党短期涨点击长期损体验。
3. **推荐茧房**：只推相似内容，用户疲劳；需多样性。
4. **冷启动无兜底**：新用户/物品无曝光，永远起不来。
5. **A/B 实验设计错**：分流不均、指标噪声，误判胜负。
6. **ctr 预估不准导致出价错**：广告 ROI 失控。

## 12. 广告与推荐的关系

- 二者共用召回/排序技术栈。
- 广告多了"竞价/计费/出价"的商业层。
- 推荐多了"体验/留存"的目标层。
- 信息流中往往融合：自然内容 + 广告混排。

## 13. 建模清单

- 明确业务目标（营收/留存/时长）。
- 设计召回→排序→重排链路。
- 统一特征口径（离线在线）。
- 建 A/B 实验与 Guardrail。
- 冷启动策略。
- 多样性与合规约束。

## 14. 小结

广告与推荐都是"在约束下最大化目标"的匹配系统：广告叠加竞价计费，推荐叠加体验目标。技术核心在召回-排序-重排链路与特征一致性，业务核心在指标设计与实验文化。铁律：**离线在线特征一致、主指标与 Guardrail 同看、冷启动有兜底、避免茧房**，并用 A/B 实验而非拍脑袋验证改动。
