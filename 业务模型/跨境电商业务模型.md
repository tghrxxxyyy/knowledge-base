# 跨境电商业务模型

> 板块：业务模型 　|　 返回：[README](README.md)
> 适用：进口保税、出口铺货、海外仓、独立站。

跨境电商在电商基础上叠加**跨境合规、多币种多税制、国际物流、关税与清关**，复杂度显著更高。

## 一、业务全景

```
海外用户/商家 → 平台(多语言/多币种) → 商品/订单 → 跨境支付(外币结算)
                                              ↓
                                      国际物流/海外仓 → 清关/关税 → 履约
```

| 模块 | 跨境特有挑战 |
|------|--------------|
| 商品 | 多语言、多币种标价、合规类目（禁限售） |
| 订单 | 跨境税费预估、拆单（不同关税区） |
| 支付 | 外币收单、汇率、跨境结算（PayPal/Stripe/本地钱包） |
| 物流 | 头程+尾程、海外仓、清关时效 |
| 税务 | VAT/GST、关税、合规申报 |

## 二、核心领域模型

- **多币种与汇率**：价格以基准币种存，展示按汇率换算；交易时锁定汇率防波动。
- **关税与税费**：下单时预估关税/VAT，清关时实际征收，多退少补。
- **海外仓**：提前备货到目标国仓库，本地发货提速；涉及库存调拨与补货预测。
- **清关**：申报单证（发票/装箱单/HS 编码），合规是生命线。

## 三、支付与结算

- **收单**：支持国际卡、PayPal、本地支付（如 Klarna、Pix）。
- **汇率**：结算时按约定汇率（实时/固定周期），记录锁定汇率对账。
- **资金合规**：跨境资金流动需符合外汇与反洗钱（AML）规定。

## 四、物流模式

| 模式 | 说明 | 时效/成本 |
|------|------|-----------|
| 直邮 | 国内直接发往海外 | 慢、便宜 |
| 海外仓 | 提前备货本地 | 快、需备货资金 |
| 保税仓 | 进口保税备货 | 介于两者之间 |

## 五、合规要点

- **禁限售**：各国品类限制（如食品/药品/仿牌）。
- **数据合规**：GDPR（欧洲用户数据）、本地化存储。
- **税务合规**：VAT 注册与申报、关税归类准确。
- **知识产权**：商标/专利，防侵权下架。

## 六、与国内电商对比

| 维度 | 国内电商 | 跨境电商 |
|------|----------|----------|
| 币种 | 单一 | 多币种+汇率 |
| 物流 | 国内快递 | 国际+清关 |
| 税务 | 国内税 | 关税/VAT/多国税 |
| 合规 | 国内法 | 多司法辖区 |
| 支付 | 微信/支付宝 | 国际卡/本地钱包 |

## 七、常见坑

1. **关税预估错误** → 用户拒收/亏损；精准 HS 编码 + 税费引擎。
2. **汇率波动** → 结算亏损；锁定汇率 + 对冲。
3. **清关单证错** → 扣货罚款；合规审核前置。
4. **海外仓超卖** → 多平台库存未同步；统一库存中心。
5. **数据违规** → 被罚；GDPR/本地化合规。
