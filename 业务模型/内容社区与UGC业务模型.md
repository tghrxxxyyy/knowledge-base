# 内容社区与 UGC 业务模型

> 板块：业务模型 　|　 返回：[README](README.md)
> 覆盖：内容生产/分发/消费闭环、Feed 流、互动、内容安全、增长与变现。

## 一、内容社区的本质

内容社区 = **生产（UGC/PGC）→ 分发（Feed/推荐/搜索）→ 消费（阅读/互动）→ 反馈（数据回流）** 的闭环。核心资产是「内容」与「关系（关注/兴趣）」。增长靠生产激励与分发效率的飞轮。

## 二、核心实体

- **用户（User）**：生产者、消费者、KOL，角色可叠加。
- **内容（Content/Post）**：图文/视频/问答，含元数据（作者、话题、标签、状态）。
- **关系（Relation）**：关注、粉丝、点赞、收藏、评论、转发。
- **话题/标签（Topic/Tag）**：内容的分类与聚合维度。
- **互动（Interaction）**：点赞/评论/收藏/分享/举报。

```text
用户 --关注--> 用户
用户 --发布--> 内容
用户 --互动--> 内容
内容 --归属--> 话题
```

## 三、内容生产

- **发布链路**：草稿 → 审核（机审+人审）→ 发布 → 进入分发池。
- **创作者激励**：流量扶持、现金/积分、等级权益、创作工具（编辑器/模板）。
- **质量门槛**：原创度、低质/标题党识别，优质内容加权。
- **冷启动**：新内容/新作者如何获得首批曝光（见分发冷启动）。

## 四、内容分发（Feed 流）

- **关注流（Timeline）**：按关注关系 + 时间排序，强社交。
- **推荐流（For You）**：兴趣模型排序，弱关系、强发现。详见 [场景设计/推荐系统设计](../场景设计/推荐系统设计.md)。
- **混合流**：关注 + 推荐混排，兼顾社交与发现。
- 分发核心指标：CTR、停留时长、互动率、留存。详见 [场景设计/Feed信息流设计](../场景设计/Feed信息流设计.md)。

## 五、互动与社交图谱

- **关注关系**：见 [场景设计/关注关系与粉丝系统设计](../场景设计/关注关系与粉丝系统设计.md)。
- **评论**：楼中楼、热评排序、权限（关闭评论/仅粉丝）。
- **通知**：互动触发通知，见 [场景设计/通知中心与站内信设计](../场景设计/通知中心与站内信设计.md)。

## 六、内容安全（红线）

- **机审**：文本/图片/视频的违规识别（涉政、色情、暴恐、广告、侵权）。
- **人审**：机审不确定的转人工；申诉复核。
- **举报**：用户举报 → 快速处置 → 反馈。
- **限流/下架**：违规内容降权、屏蔽、删除，作者处罚。
- 安全是社区底线，宁可误杀不可漏放（对明显违规）。

## 七、搜索与发现

- **站内搜索**：标题/标签/作者检索，见 [场景设计/全文搜索与Elasticsearch实战](../场景设计/全文搜索与Elasticsearch实战.md)。
- **话题/榜单**：聚合热点，促进消费与二次生产。

## 八、增长飞轮

```
创作者生产优质内容 → 分发高效触达 → 消费者互动留存
      ↑                                    ↓
   激励反哺创作者 ←──── 数据反馈优化分发 ←───┘
```

- **AARRR**：获取、激活、留存、变现、推荐。UGC 社区尤重留存与创作者留存。
- **冷启动策略**：新用户兴趣引导（选标签）、新内容流量扶持。

## 九、变现模式

- **广告**：信息流广告、品牌合作。
- **内容付费**：付费专栏/课程/打赏/会员。
- **电商/带货**：内容挂车、直播带货。
- **增值服务**：特权、虚拟礼物。
- 变现不能伤体验：广告频次、硬广识别、用户反馈。

## 十、数据指标

- **内容侧**：日发布量、优质率、人均发布。
- **消费侧**：DAU/MAU、时长、互动率、留存曲线。
- **创作者侧**：活跃创作者数、头部/腰尾部分布。
- **健康度**：举报率、违规率、负反馈率。

## 十一、常见建模坑

1. 内容状态机不清晰（草稿/审核中/已发布/下架）→ 状态混乱。
2. 互动计数用单字段 → 高并发写竞争，应计数服务/异步。
3. 关注关系不设计双向索引 → 取粉丝列表慢。
4. 把内容安全当后置 → 违规扩散难收拾，应发布即审。
5. Feed 不区分关注/推荐 → 体验割裂，需混排策略。
6. 创作者激励单一 → 腰尾部流失，生态不健康。

## 十二、与电商/业务模型对比

- 电商以「交易」为核心（见 [业务模型/电商交易业务模型](电商交易业务模型.md)），社区以「内容与关系」为核心。
- 社区常作为电商的引流与信任层（内容种草 → 交易转化）。
- 金融/证券模型以「合规与风控」为核心（见 [业务模型/证券基金交易业务模型](证券基金交易业务模型.md)）。
