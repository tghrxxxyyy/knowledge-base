# 内容社区与 UGC 业务模型

> 板块：业务模型 　|　 返回：[README](README.md)
> 覆盖：内容生产/分发/消费闭环、Feed 流、互动、内容安全、增长与变现。

## 一、内容社区的本质

内容社区 = **生产（UGC/PGC）→ 分发（Feed/推荐/搜索）→ 消费（阅读/互动）→ 反馈（数据回流）** 的闭环。核心资产是「内容」与「关系（关注/兴趣）」。增长靠生产激励与分发效率的飞轮。

```
创作者 ──生产──▶ 内容 ──分发──▶ 消费者
   ▲              │  ▲            │
   │              ▼  │            ▼
   └──激励◀──数据反馈  关系(关注)──互动
```

- **社区 vs 电商**：电商以「交易」为核心（见 [电商交易业务模型](电商交易业务模型.md)）；社区以「内容与关系」为核心，常作为电商的种草/信任层。
- **社区 vs 媒体**：媒体是「一对多广播」，社区强调「多对多互动 + 关系沉淀」。

## 二、核心实体与关系

```
用户 ──关注──▶ 用户        (社交图谱)
用户 ──发布──▶ 内容        (创作)
用户 ──互动──▶ 内容        (点赞/评论/收藏/转发/举报)
内容 ──归属──▶ 话题/标签    (聚合维度)
内容 ──引用──▶ 内容        (转发/合集)
```

| 实体 | 关键属性 | 说明 |
|------|---------|------|
| 用户 User | id, 角色(普通/KOL/MCN), 等级, 标签 | 生产者/消费者可叠加 |
| 内容 Content | id, 作者, 类型(图文/视频/问答/直播), 状态, 话题, 可见性 | 社区核心资产 |
| 关系 Relation | 关注/粉丝/拉黑/互关 | 社交图谱 |
| 互动 Interaction | 类型, 目标, 用户, 时间 | 点赞/评论/收藏/分享/举报 |
| 话题 Topic | 名称, 热度, 聚合内容 | 发现与聚合 |
| 计数 Counter | 点赞数/评论数/收藏数/播放数 | 高并发写，需独立计数服务 |

## 三、内容生产

- **发布链路**：草稿 → 机审 →（人审）→ 发布 → 进入分发池。
- **创作者激励**：
  - 流量扶持（新内容冷启动曝光）；
  - 现金/积分分成、创作激励金；
  - 等级权益（认证、专属工具、活动优先）；
  - 创作工具（富文本/视频编辑/模板/素材）。
- **质量门槛**：原创度检测、标题党/低质识别，优质内容加权。
- **冷启动**：新内容/新作者如何获得首批曝光（见分发冷启动）。
- **多形态**：图文、短视频、长视频、直播、问答、音频——不同形态生产链路与消费场景不同。

## 四、内容分发（Feed 流）

详见 [场景设计/Feed信息流设计](../场景设计/Feed信息流设计.md) 与 [推荐系统设计](../场景设计/推荐系统设计.md)。

| 流类型 | 排序逻辑 | 特点 | 适用 |
|--------|---------|------|------|
| 关注流 Timeline | 关注关系 + 时间 | 强社交、可控 | 微博/朋友圈 |
| 推荐流 For You | 兴趣模型排序 | 弱关系、强发现 | 抖音/今日头条 |
| 混合流 | 关注+推荐混排 | 兼顾社交与发现 | 多数综合社区 |
| 同城/话题流 | 地理/话题聚合 | 局部发现 | 本地生活 |

- 分发核心指标：CTR、停留时长、互动率、留存、负反馈率。
- **冷启动分发**：新内容进「小流量池」测试（如先推 500 人），表现好则放大（漏斗式流量池）。
- **兴趣建模**：用户行为（点击/停留/互动/负反馈）回流训练推荐模型。

## 五、互动与社交图谱

- **关注关系**：双向索引（关注列表 + 粉丝列表），见 [关注关系与粉丝系统设计](../场景设计/关注关系与粉丝系统设计.md)。
- **评论**：楼中楼、热评排序（按时间/热度）、权限（关闭评论/仅粉丝可评）。
- **通知**：互动触发通知，见 [通知中心与站内信设计](../场景设计/通知中心与站内信设计.md)。
- **收藏/转发**：内容二次传播，转发带来新受众（裂变）。
- **计数**：点赞/评论数高并发写，用独立计数服务 + 异步聚合，避免单字段竞争（见 [评论系统设计](../场景设计/评论系统设计：回复、排序与级联.md)）。

## 六、内容安全（红线）

社区底线，**宁可误杀不可漏放（对明显违规）**：

- **机审**：文本（NLP 分类）、图片（CV 识别）、视频（抽帧+ASR）的违规识别（涉政、色情、暴恐、广告、侵权、引流）。
- **人审**：机审不确定/高风险转人工；申诉复核通道。
- **举报**：用户举报 → 快速处置 → 反馈结果。
- **处置**：降权、限流、屏蔽、下架、作者处罚（禁言/封号）。
- **应急响应**：突发热点/群体事件的内容管控与舆情预案。
- **未成年保护**：防沉迷、不良内容隔离。

## 七、搜索与发现

- **站内搜索**：标题/标签/作者/正文检索，见 [全文搜索与Elasticsearch实战](../场景设计/全文搜索与Elasticsearch实战.md)。
- **话题/榜单**：聚合热点，促进消费与二次生产。
- **推荐入口**：猜你喜欢、相关推荐、看了又看——延长消费时长。

## 八、增长飞轮

```
创作者生产优质内容 → 分发高效触达 → 消费者互动留存
      ↑                                    ↓
   激励反哺创作者 ←──── 数据反馈优化分发 ←───┘
```

- **AARRR**：获取、激活、留存、变现、推荐。UGC 社区尤重 **留存** 与 **创作者留存**。
- **冷启动策略**：
  - 新用户：兴趣引导（选标签）、热门内容填充、关注推荐（关注几个 KOL）；
  - 新作者：创作工具降低门槛、流量扶持、新手任务。
- **双边网络效应**：内容多 → 用户多 → 互动多 → 创作者收益高 → 更多内容。

## 九、变现模式

| 模式 | 说明 | 注意 |
|------|------|------|
| 广告 | 信息流广告、品牌合作、开屏 | 频次控制、硬广识别 |
| 内容付费 | 付费专栏/课程/打赏/会员 | 不与免费体验割裂 |
| 电商/带货 | 内容挂车、直播带货 | 供应链与售后 |
| 增值服务 | 特权、虚拟礼物、表情 | 防过度诱导消费 |
| 佣金 | 带货抽成、知识付费分成 | 结算透明 |

- 变现不能伤体验：广告频次、硬广识别、用户反馈闭环。
- 创作者分成透明：结算周期、税率、提现门槛清晰。

## 十、数据指标

| 维度 | 指标 |
|------|------|
| 内容侧 | 日发布量、优质率、人均发布、完播率 |
| 消费侧 | DAU/MAU、时长、互动率、留存曲线、负反馈率 |
| 创作者侧 | 活跃创作者数、头部/腰尾部分布、创作者流失率 |
| 健康度 | 举报率、违规率、审核通过率、申诉率 |

## 十一、常见建模坑

1. 内容状态机不清晰（草稿/审核中/已发布/下架/删除）→ 状态混乱，需明确状态机。
2. 互动计数用单字段 → 高并发写竞争，应独立计数服务/异步聚合。
3. 关注关系不设计双向索引 → 取粉丝列表慢，需关注表+粉丝表。
4. 把内容安全当后置 → 违规扩散难收拾，应发布即审（机审前置）。
5. Feed 不区分关注/推荐 → 体验割裂，需混排策略与权重。
6. 创作者激励单一 → 腰尾部流失，生态不健康，需分层激励。
7. 评论不做树形/权限 → 互动体验差，需楼中楼+权限模型。
8. 推荐不接负反馈 → 越推越窄（信息茧房），需负反馈降权。

## 十二、与其他业务模型对比

- **电商**（[电商交易业务模型](电商交易业务模型.md)）：核心是「交易转化」，社区是引流与信任层（种草→交易）。
- **金融/证券**（[证券基金交易业务模型](证券基金交易业务模型.md)）：核心是「合规与风控」，社区内容受严格合规约束。
- **本地生活**（[本地生活外卖业务模型](本地生活外卖业务模型.md)）：核心是「履约时效」，社区做商家内容与评价。
- **内容短视频直播**（[内容短视频直播业务模型](内容短视频直播业务模型.md)）：社区的生产/分发/变现一体化延伸。
