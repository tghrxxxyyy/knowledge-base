# 汽车与出行后市场业务模型

> 板块：业务模型 　|　 返回：[README](README.md)
> 适用：租车、网约车、加油充电、维修保养、二手车、车险。

汽车/出行后市场连接"车、人、路、服务"，线上线下融合（O2O），重线下履约与资产运营。

## 一、业务全景

| 子域 | 核心 |
|------|------|
| 出行（网约车/租车） | 运力调度、计价、LBS |
| 能源（加油/充电） | 站点网络、聚合支付 |
| 后市场（维保/洗车） | 门店、预约、供应链 |
| 交易（二手车/新车） | 车源、金融、交付 |
| 车险 | 定价、理赔 |

## 二、网约车/租车模型

- **运力调度**：司机/车辆与订单匹配，分区+热力预测调度（见[网约车派单系统设计](../场景设计/网约车派单系统设计.md)）。
- **计价**：起步价+里程+时长+动态调价（高峰溢价）。
- **LBS**：实时位置、电子围栏、绕路检测。
- **资产**：车辆资产运营、维保、残值管理（租车/自营车队）。

## 三、充电/加油

- **站点网络**：充电桩/加油站聚合，实时空闲查询。
- **支付**：聚合支付 + 自动扣费（绑定车牌/账户）。
- **调度**：低电量引导至空闲桩，平衡负载。

## 四、维修保养（O2O）

```
用户预约 → 平台派单/选门店 → 到店服务(工单/配件) → 支付 → 评价/质保
```

- 门店网络 + 技师排班 + 配件供应链。
- 服务标准化（套餐价）降低决策成本。

## 五、二手车

- 车源：个人/商家车源，检测报告（事故/里程）建立信任。
- 金融：分期、置换补贴。
- 交付：过户、物流。

## 六、车险

- 定价：车型/驾驶行为/历史出险（UBI 基于行驶数据定价）。
- 理赔：定损（图像识别）、维修网络。

## 七、与出行业务关系

- 出行（打车）高频引流，后市场（维保/能源）变现。
- 数据闭环：行驶数据反哺保险定价与维保提醒。

## 八、常见坑

1. **运力/车辆调度低效** → 用户等车久；预测+热力调度。
2. **线下履约失控** → 门店服务差；SLA + 评价。
3. **资产利用率低** → 车队空置；动态调度+共享。
4. **计价争议** → 绕路/溢价投诉；轨迹透明+申诉。
5. **车源信任缺失** → 二手车难卖；第三方检测报告。
