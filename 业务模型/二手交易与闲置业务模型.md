# 二手交易与闲置业务模型

> 板块：业务模型 　|　 返回：[README](README.md)
> 适用：闲鱼式 C2C 闲置、回收寄卖、二手电商。

二手交易的核心差异：**非标品、信任机制、定价模糊、履约复杂**。买家怕买到假货，卖家怕被坑，平台要在"信任"上做重投入。

## 一、业务全景

```
卖家(发布闲置) → 平台(审核/定价建议) → 买家(沟通/下单) → 担保交易 → 发货 → 确认收货 → 评价
                          ↓
                    信任基建(实人认证/信用分/担保)
```

| 模块 | 二手特有 |
|------|----------|
| 商品 | 非标、成色描述、图片真实 |
| 定价 | 估价模型、议价、一口价/拍卖 |
| 信任 | 信用分、实人、担保交易、验货 |
| 履约 | 邮寄鉴定（平台验真）、退货率高 |

## 二、核心机制

### 2.1 信任体系

- **实人认证 + 信用分**：降低欺诈。
- **担保交易**：款先托管，确认收货后打款。
- **平台验货（寄卖/回收）**：高价值品先寄到平台鉴定再发买家，解决假货顾虑。
- **评价与纠纷**：公开评价 + 纠纷仲裁。

### 2.2 定价与估价

- **估价模型**：根据品牌/型号/成色/市场行情给出参考价。
- **议价**：C2C 支持砍价、私聊。
- **拍卖/一口价**：不同决策成本。

## 三、履约模式

| 模式 | 说明 |
|------|------|
| C2C 直连 | 买家卖家直接交易，平台担保 |
| 寄卖 | 卖家寄平台，平台代卖 |
| 回收 | 平台/商家直接买断，再转售 |
| 验货担保 | 平台验真后发货，强信任 |

## 四、风控重点

- **欺诈**：假货、到手刀（收货后砍价）、调包。
- **资金**：担保交易防钱货两空。
- **内容**：违禁品（发票/处方/仿牌）审核。

## 五、与一手电商对比

| 维度 | 一手电商 | 二手 |
|------|----------|------|
| 商品 | 标品、新 | 非标、成色不一 |
| 信任 | 品牌/平台背书 | 强依赖信用/验货 |
| 价格 | 明码标价 | 估价+议价 |
| 退货 | 标准化 | 高、复杂 |

## 六、常见坑

1. **无信任机制** → 欺诈横行；信用分+担保+验货。
2. **估价不准** → 买卖双方都嫌亏；行情数据驱动估价。
3. **假货纠纷** → 平台口碑崩；平台验货/鉴定。
4. **到手刀** → 卖家吃亏；担保+评价约束。
5. **退货率高** → 成本高；清晰成色描述+实拍。
