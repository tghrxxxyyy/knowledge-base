# 动态规划状态机高频题解

> 当问题有"多个互斥阶段/状态"时，用状态机视角设计 DP 更清晰。本文讲股票买卖、打家劫舍、不同路径等状态机类 DP。

## 1. DP 通用框架

1. 定义 `dp[i][state]`：前 i 个、处于某状态的最优值。
2. 转移：从上一阶段合法状态转移。
3. 初始化与边界。
4. 遍历顺序。
5. 取终态最优。

## 2. 股票买卖（状态机经典）

以"买卖股票含冷冻期"为例，每天状态：持有(hold)、空仓可买(cooldown 后)、冷冻(sold)。

```python
def maxProfit(prices):
    n=len(prices)
    hold, sold, rest = -prices[0], 0, 0
    for p in prices[1:]:
        hold2 = max(hold, rest - p)
        sold2 = hold + p
        rest2 = max(rest, sold)
        hold, sold, rest = hold2, sold2, rest2
    return max(sold, rest)
```

- 状态间转移即"状态机"。
- k 次交易则加一维 `dp[i][k][state]`。

## 3. 打家劫舍

不能偷相邻：

```python
def rob(nums):
    prev, cur = 0, 0
    for x in nums:
        prev, cur = cur, max(cur, prev+x)
    return cur
```

- `dp[i] = max(dp[i-1], dp[i-2]+nums[i])`。
- 环形：拆成 [0,n-1] 与 [1,n] 两段取 max。

## 4. 不同路径

网格从左上到右下：

```python
def uniquePaths(m,n):
    dp=[1]*n
    for i in range(1,m):
        for j in range(1,n):
            dp[j]+=dp[j-1]
    return dp[n-1]
```

- `dp[i][j] = dp[i-1][j] + dp[i][j-1]`。

## 5. 最长上升子序列（LIS）

```python
def lengthOfLIS(nums):
    tails=[]
    for x in nums:
        i=bisect_left(tails,x)
        if i==len(tails): tails.append(x)
        else: tails[i]=x
    return len(tails)
```

- O(n log n) 贪心 + 二分。

## 6. 编辑距离

`dp[i][j]` = word1 前 i 与 word2 前 j 的最小操作：

```python
dp[i][j] = min(dp[i-1][j]+1, dp[i][j-1]+1, dp[i-1][j-1] + (0 if a==b else 1))
```

## 7. 背包

- 0/1 背包：`dp[i][w]=max(dp[i-1][w], dp[i-1][w-wt]+val)`。
- 完全背包：物品无限，正序遍历。
- 状态压缩：一维数组倒序（0/1）或正序（完全）。

## 9. 优化技巧

- 滚动数组：只依赖前一两行时降维。
- 状态压缩：用位或一维。
- 单调性：用二分/单调队列优化。
