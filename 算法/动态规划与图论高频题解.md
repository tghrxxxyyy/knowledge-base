# 动态规划与图论高频题解

> 本文梳理算法面试与工程中最常出现的动态规划（DP）与图论题型：DP 的建模套路、状态转移、空间优化；图论的遍历、最短路径、拓扑排序、并查集、最小生成树。每个题型给出思路与代码骨架（以通用伪代码/Java 风格呈现），重思想而非死记。

## 1. 动态规划的本质

DP 用于**有重叠子问题 + 最优子结构**的问题：把大问题拆成小问题，小问题结果被复用。

两个关键：

- **状态定义**：dp[i] 或 dp[i][j] 代表什么。
- **转移方程**：如何从子状态推出当前状态。

## 2. DP 五步法

1. 定义状态：dp 数组含义。
2. 状态转移：递推关系。
3. 初始化：边界值。
4. 遍历顺序：确保算当前时已备好子状态。
5. 返回结果：取哪个位置的值。

## 3. 背包问题

### 3.1 0/1 背包

- 问题：n 件物品，容量 W，每件重量 w、价值 v，求最大价值（每件至多选一次）。
- 状态：dp[i][j] = 前 i 件在容量 j 下最大价值。
- 转移：选或不选第 i 件。
- 空间优化：滚动数组，从后往前更新。

```java
for (int i = 1; i <= n; i++)
  for (int j = W; j >= w[i]; j--)
    dp[j] = Math.max(dp[j], dp[j - w[i]] + v[i]);
```

### 3.2 完全背包

- 每件可无限选。
- 区别：内层循环**从前往后**更新（可重复选）。
- 应用：零钱兑换（最少硬币）。

## 4. 线性 DP

### 4.1 最长递增子序列（LIS）

- 状态：dp[i] = 以 i 结尾的 LIS 长度。
- 转移：dp[i] = max(dp[j]+1) 对所有 j<i 且 a[j]<a[i]。
- 优化：用二分维护 tails 数组达 O(n log n)。

### 4.2 最长公共子序列（LCS）

- dp[i][j] = 两串前缀 LCS。
- 相等则 +1，否则取 max(左, 上)。

## 5. 区间 DP

- 状态：dp[i][j] = 区间 [i,j] 的最优值。
- 枚举区间长度、分割点。
- 应用：矩阵连乘、戳气球、字符串回文分割。

## 6. 树形 DP

- 在树上做后序遍历，子节点结果合并到父节点。
- 应用：二叉树最大路径和、打家劫舍（树版）、树的直径。

```text
dfs(node):
  left = dfs(node.left)
  right = dfs(node.right)
  return f(left, right, node.val)
```

## 7. 状压 DP

- 当状态可用二进制位表示（如选/不选、访问过），用整数表示集合。
- 应用：旅行商 TSP（小 n）、棋盘覆盖。
- 复杂度高（2^n），仅适合 n 小。

## 8. 字符串 DP

- 编辑距离：dp[i][j] = 两前缀最少操作数（增/删/改）。
- 最长回文子串：区间 DP 或中心扩展。
- 正则匹配：按 '*' 分类讨论。

## 9. DP 空间优化技巧

- 二维常见可压成一维（背包、LCS 注意遍历方向）。
- 滚动数组复用，注意初始化与覆盖顺序。
- 若只关心结果而非路径，优先压维。

## 10. 图论基础

### 10.1 表示

- 邻接矩阵：O(V^2) 空间，查边 O(1)，适合稠密图。
- 邻接表：O(V+E) 空间，适合稀疏图。

### 10.2 遍历

- **DFS**：栈/递归，适合连通性、环检测、拓扑前序。
- **BFS**：队列，适合最短路（无权）、层序。

## 11. 最短路径

### 11.1 Dijkstra

- 非负权图单源最短路。
- 贪心 + 优先队列，O(E log V)。
- 负权不可用。

### 11.2 Bellman-Ford

- 可处理负权，检测负权环。
- 松弛 V-1 轮，O(VE)。

### 11.3 Floyd-Warshall

- 多源最短路，O(V^3)。
- 适合小图全对最短路。

## 12. 拓扑排序

- 有向无环图（DAG）的线性序，使边方向一致。
- 方法：Kahn（入度为 0 队列）或 DFS 后序反转。
- 应用：任务依赖、编译顺序、课程表。
- 有环则无法拓扑，可检测环。

```text
queue = 所有入度为0的点
while queue非空:
  u = pop; result.add(u)
  for v in u.adj: 入度[v]--; if 0 入队
若 result 长度 < 点数 → 有环
```

## 13. 并查集（Union-Find）

- 维护不相交集合，支持合并与查询根。
- 路径压缩 + 按秩合并，近 O(1) 均摊。
- 应用：连通分量、Kruskal、岛屿数量、朋友圈。

```java
int find(int x){ return parent[x]==x ? x : (parent[x]=find(parent[x])); }
void union(int a,int b){ int ra=find(a),rb=find(b); if(ra!=rb) parent[ra]=rb; }
```

## 14. 最小生成树（MST）

- 连通所有点且边权和最小。
- **Kruskal**：按权排序 + 并查集判环，O(E log E)。
- **Prim**：从点出发扩最小邻边，O(E log V)。
- 应用：网络布线、聚类。

## 15. 强连通分量（SCC）

- Tarjan / Kosaraju 缩点。
- 应用：依赖分析、图简化。

## 16. 二分图与匹配

- 二分图判定：染色法（DFS 两色）。
- 最大匹配：匈牙利算法。
- 应用：任务分配、资源调度。

## 17. 常见易错

1. **DP 初始化错**：边界未设导致全错；仔细想 dp[0] 含义。
2. **遍历顺序反**：背包空间优化时方向错，重复选/漏选。
3. **负数权用 Dijkstra**：结果错误；用 Bellman-Ford。
4. **拓扑未检环**：假设 DAG 实则有环，结果不全。
5. **并查集未路径压缩**：退化为 O(n) 查询，超时。
6. **邻接表 vs 矩阵选错**：稠密图用邻接表浪费，稀疏图用矩阵超内存。

## 18. 刷题策略

- 先掌握模板：背包、LIS、LCS、Dijkstra、拓扑、并查集。
- 每题先定状态，再推转移，最后优化空间。
- 重"建模"而非背答案：同一模型换皮即会。
- 工程视角：这些算法在路由、调度、依赖分析中真实使用。

## 19. 与现实系统

- **最短路径**：地图导航、网络路由（OSPF 用 Dijkstra 思路）。
- **拓扑排序**：任务编排、构建系统依赖。
- **并查集**：连通性、Kruskal 选边。
- **DP**：文本对齐、序列比对、资源分配。

## 20. 小结

DP 的核心是"状态定义 + 转移方程 + 遍历顺序 + 空间优化"，图论的核心是"表示 + 遍历 + 经典算法套用"。二者都重套路而非记忆：掌握背包、LIS、Dijkstra、拓扑、并查集等模板后，大多数变体都是换皮。编码前务必想清状态含义与边界，避免初始化与顺序错误。
