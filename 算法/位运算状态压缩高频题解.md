# 位运算与状态压缩高频题解

> 位运算在算法中有两大用途：一是底层优化（判奇偶、取模、交换、幂 of 2），二是**状态压缩 DP**——当状态维度小（n≤20）时，用整数的二进制位表示集合/状态，把指数级状态压进一个 int/long。

## 1. 常用位运算技巧

```python
n & 1          # 判奇偶
n >> k         # 除以 2^k
n & (n-1)     # 去掉最低位 1（判 2 的幂）
n & (-n)      # 取最低位 1
n ^ (1 << i)  # 翻转第 i 位
(n >> i) & 1  # 取第 i 位
```

- 判 2 的幂：`n > 0 and (n & (n-1)) == 0`。
- 统计 1 的个数：`bin(n).count('1')` 或 `n &= n-1` 循环。
- 单数字（其余成对）：全员异或。

## 2. 状态压缩 DP：旅行商 TSP

```python
# dp[mask][i]: 已访问集合 mask，当前在城市 i 的最小花费
INF = float('inf')
n = len(dist)
dp = [[INF]*n for _ in range(1<<n)]
dp[1][0] = 0
for mask in range(1<<n):
    for i in range(n):
        if not (mask>>i)&1: continue
        for j in range(n):
            if (mask>>j)&1: continue
            dp[mask|(1<<j)][j] = min(
                dp[mask|(1<<j)][j], dp[mask][i] + dist[i][j])
ans = min(dp[(1<<n)-1][i] + dist[i][0] for i in range(n))
```
- `mask` 用 n 位表示已访问城市集合。
- 复杂度 O(n²·2ⁿ)，适用 n≤20。

## 3. 典型场景

| 场景 | 状态 |
| --- | --- |
| 集合枚举 | `for mask in range(1<<n)` |
| 子集遍历 | `sub = mask; while sub: sub=(sub-1)&mask` |
| 棋盘/格子 | 每行状态压成整数 |
| 最小覆盖 | 状态 = 已覆盖集合 |

## 4. 常见坑

- 位运算优先级低，务必加括号。
- 状态维度过大（n>25）直接爆，需换思路。
- 负数的位运算（Python 无限位）要小心，限定 32/64 位。
- 子集遍历别忘了空集/自身。

## 5. 面试要点

1. 如何用位表示集合。
2. 子集遍历的 `sub=(sub-1)&mask` 套路。
3. TSP 状态转移怎么写。
4. 位运算判 2 的幂为什么 `n&(n-1)`。

## 6. 小结

位运算 = 底层技巧 + 状态压缩。当"状态是集合且规模小"时，用整数位表示状态能把 DP 写得既短又高效，是面试区分度高的一类题。
