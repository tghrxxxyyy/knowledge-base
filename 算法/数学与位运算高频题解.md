# 数学与位运算高频题解

> 本文梳理算法面试中的数学与位运算题型：位运算基础、常用技巧、二分答案、概率与排列组合、素数/因数、以及对应的高频例题。重套路与代码骨架，思路优先。

## 1. 位运算基础

- 与 &：同 1 为 1。
- 或 |：有 1 为 1。
- 异或 ^：不同为 1，相同为 0（重要性质多）。
- 取反 ~：按位取反。
- 左移 <<：乘 2 的 n 次。
- 右移 >>：除 2 的 n 次（算术右移补符号位）。

## 2. 异或的妙用

- a ^ a = 0，a ^ 0 = a。
- 交换律、结合律。
- 应用：找落单数（出现一次，其余两次）、交换两数（无需临时变量）、奇偶判断。

### 2.1 落单数

- 数组除一个数出现一次，其余出现两次，全部异或即得答案。
- 因为成对抵消为 0，剩唯一。

```java
int res = 0;
for (int x : arr) res ^= x;
return res;
```

## 3. 单 bit 操作

- 取最低位 1：x & (-x)（补码性质）。
- 消去最低位 1：x & (x-1)。
- 判断 2 的幂：x > 0 && (x & (x-1)) == 0。
- 统计 1 的个数：循环 x &= x-1 计数，或用内置 popcount。

## 4. 二进制状态

- 用整数位表示集合（状压 DP 见 DP 章节）。
- 用一个 int 的第 i 位表示第 i 个元素选/不选。
- 位运算加速集合操作。

## 5. 二分查找

### 5.1 基础

- 在有序数组找目标，O(log n)。
- 循环不变量：维护 [left, right] 含义。
- 防溢出用 mid = left + (right-left)/2。

### 5.2 二分答案

- 答案满足单调性时，二分答案而非二分下标。
- 例：最小速度吃香蕉、分割数组最大值。
- 判定函数 check(mid) 是否可行。

```java
int left = lo, right = hi;
while (left < right) {
    int mid = left + (right - left) / 2;
    if (check(mid)) right = mid; else left = mid + 1;
}
return left;
```

## 6. 二分变体

- 找第一个 >= target（lower_bound）。
- 找最后一个 <= target。
- 旋转数组找最小值（部分有序）。
- 关键是边界与收缩方向。

## 7. 排列组合与回溯

- 全排列：回溯交换元素。
- 组合：选 k 个，递归 + 剪枝。
- 与回溯章节（见 DP/回溯）结合。
- 注意去重（排序后跳相同元素）。

## 8. 概率与期望

- 等概率返回随机数：rand() % n 有偏，需拒绝采样。
- 蓄水池抽样：数据流中等概率取 k 个（见大数据章节）。
- 期望线性：E[X+Y] = E[X]+E[Y]。

## 9. 素数

- 试除到 sqrt(n) 判断素数。
- 埃氏筛：标记倍数，O(n log log n) 出 1..n 素数。
- 应用：因数分解、计数。

```java
boolean[] isPrime = new boolean[n+1];
Arrays.fill(isPrime, true);
for (int i = 2; i*i <= n; i++)
  if (isPrime[i]) for (int j = i*i; j <= n; j += i) isPrime[j] = false;
```

## 10. 最大公约数（GCD）

- 欧几里得：gcd(a,b) = gcd(b, a%b)，b=0 时 a 为答案。
- 应用：化简分数、网格路径互质判断。
- 最小公倍数：a*b/gcd(a,b)（注意溢出）。

## 11. 快速幂

- 计算 a^b % m 用二分幂，O(log b)。
- 偶数平方降次，奇数乘底数。

```java
long pow(long a, long b, long m) {
    long res = 1; a %= m;
    while (b > 0) {
        if ((b & 1) == 1) res = res * a % m;
        a = a * a % m; b >>= 1;
    }
    return res;
}
```

## 12. 数字处理

- 反转整数：逐位取余，注意溢出。
- 回文数：反转一半比较。
- 进制转换：除基取余。
- 各位和、数位 DP（见 DP 章节）。

## 13. 常见题型清单

- 落单/落双数（异或）。
- 2 的幂/比特计数。
- 只出现一次的数（1 次 vs 2 次，或 2 次 vs 3 次需状态机）。
- 二分答案（最小/最大）。
- 旋转数组查找。
- 组合数/排列（回溯）。
- 素数/因数/GCD。
- 快速幂取模。

## 14. 位运算进阶：落双次数

- 数组中两个数各出现一次，其余两次：先全异或得 a^b，取最低不同位分组，再各组异或。
- 利用该位把两数分到不同组，组内抵消。
- 是异或技巧的经典扩展。

## 15. 复杂度与边界

- 位运算 O(1) 单操作，统计 1 用 x&=x-1 为 O(位数)。
- 二分 O(log n)，注意上下界与死循环。
- 幂/素数注意数值范围与溢出（用 long）。

## 16. 常见易错

1. **二分边界乱**：死循环；明确 [left,right] 与收缩。
2. **mid 溢出**：left+right 超 int；用 left+(right-left)/2。
3. **异或当加法**：异或是不进位加，不能替代和；需进位时另算。
4. **2 的幂判断漏 x>0**：0 与负数误判；加正数约束。
5. **快速幂不取模**：溢出得错；每步取模。
6. **忽略负数**：位运算对负数要小心（补码）。

## 17. 与现实系统

- 位图（Bitmap）：用位压缩存储（如用户标签）。
- 权限位掩码：用位表示多个权限组合。
- 一致性哈希：取模位运算（见分布式章节）。
- 布隆过滤器：位数组（见场景设计章节）。

## 18. 刷题策略

- 先掌握异或三性质（a^a=0, a^0=a, 交换）。
- 二分答案套路固定，练 5 题即熟。
- 素数/快速幂背模板。
- 位运算题先看"奇偶性/低位 1/分组"。

## 19. 与 DP 关系

- 状压 DP 用位表示集合（见 DP 章节）。
- 数位 DP 逐位决策。
- 二者共享位运算基础。

## 20. 小结

数学与位运算是算法题的"工具箱"：异或找落单、位操作判 2 的幂、二分答案解最值、快速幂取模、素数筛。套路固定、模板可复用。编码重边界（溢出、死循环、负数）与性质（异或三律、最低位 1）。掌握后能与 DP/回溯/分布式结合，覆盖面广。
