# 图（Graph）

## 〇、本体介绍

**图**：由顶点和边组成，分**有向/无向**、**带权/不带权**。表示法：邻接矩阵（O(V²)，适合稠密）、邻接表（O(V+E)，适合稀疏，工程主流）。

**两大类算法**：
- **遍历**：BFS（层序、最短无权路径、连通块）、DFS（环路检测、拓扑、连通分量）。
- **最短路/生成树**：Dijkstra（正权单源最短路）、Floyd（多源）、Prim/Kruskal（最小生成树，后者用并查集）。

**面试高频**：岛屿数量（DFS/BFS）、拓扑排序、课程表（判 DAG 环）、Dijkstra、连通分量、双向 BFS、A*。

## 一、BFS vs DFS

| 维度 | BFS | DFS |
|------|-----|-----|
| 数据结构 | 队列 | 栈/递归 |
| 用途 | 无权最短路、层序、扩散 | 连通、环、回溯、拓扑 |
| 空间 | 存整层（宽） | 存路径深度（深） |
| 特点 | 首次访问即最短 | 一条路走到底 |

### 1.1 深挖：图遍历的标准骨架（BFS/DFS/双向BFS）

```java
// BFS 骨架：队列 + visited（首次到达即最短距离）
int bfs(List<Integer>[] g, int start) {
    Deque<Integer> q = new ArrayDeque<>();
    boolean[] vis = new boolean[g.length];
    q.offer(start); vis[start] = true;
    int dist = 0;
    while (!q.isEmpty()) {
        for (int size = q.size(); size > 0; size--) {
            int u = q.poll();
            for (int v : g[u]) if (!vis[v]) { vis[v] = true; q.offer(v); }
        }
        dist++;
    }
    return dist;
}

// DFS 骨架（递归）：处理「当前节点」→ 遍历邻居
void dfs(int u, List<Integer>[] g, boolean[] vis) {
    vis[u] = true;
    for (int v : g[u]) if (!vis[v]) dfs(v, g, vis);
}

// 双向 BFS：两个 visited + 两个队列，向中间扩散（深度减半的关键）
int biBfs(List<Integer>[] g, int s, int t) {
    if (s == t) return 0;
    Set<Integer> a = new HashSet<>(), b = new HashSet<>();
    a.add(s); b.add(t);
    int step = 0;
    while (!a.isEmpty() && !b.isEmpty()) {
        if (a.size() > b.size()) { var tmp = a; a = b; b = tmp; } // 扩小的一侧
        Set<Integer> next = new HashSet<>();
        for (int u : a)
            for (int v : g[u])
                if (b.contains(v)) return step + 1;
                else next.add(v);
        a = next; step++;
    }
    return -1;
}
```

> **双向 BFS 复杂度**：单向是 b^d（分支因子^深度），双向是 2·b^(d/2)，**指数级剪枝**。单词接龙（127）必备。

## 二、经典例题

- **岛屿数量（200）**：二维网格，遇 '1' 用 DFS/BFS 标记连通陆地（沉岛法置 '0'）。
- **课程表（207）**：判断能否修完——建图 + 拓扑排序（ Kahn 入度法 或 DFS 三色判环）。
- **拓扑排序（Kahn）**：不断取入度为 0 的节点输出，最后若输出数 < 节点数则有环。
- **Dijkstra（朴素/堆优化）**：dist 数组 + 小顶堆（按距离），每次取最近节点松弛邻边；O((V+E)log V)。负权不可用（用 Bellman-Ford/SPFA）。
- **最小生成树**：Kruskal（边排序 + 并查集，O(E log E)）、Prim（堆，O(E log V)）。
- **单词接龙（127）**：BFS 求最短变换步（无权最短路，状态图）。
- **双向 BFS**：从起点和终点同时 BFS，相遇即最短，大幅剪枝。

### 2.1 深挖：拓扑排序 + Dijkstra 模板

```java
// 拓扑排序（Kahn 入度法）——输出数 < 节点数 ⇒ 有环
int[] topo(List<Integer>[] g, int[] indeg) {
    int n = g.length;
    Deque<Integer> q = new ArrayDeque<>();
    for (int i = 0; i < n; i++) if (indeg[i] == 0) q.offer(i);
    int[] order = new int[n]; int idx = 0;
    while (!q.isEmpty()) {
        int u = q.poll();
        order[idx++] = u;
        for (int v : g[u]) if (--indeg[v] == 0) q.offer(v);
    }
    return idx == n ? order : null;   // null 即有环（课程表 207 的判定）
}

// Dijkstra（堆优化）——小顶堆按「当前最短距离」取节点
int dijkstra(List<int[]>[] g, int n, int s, int t) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[s] = 0;
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]); // {距离, 节点}
    pq.offer(new int[]{0, s});
    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int d = cur[0], u = cur[1];
        if (d > dist[u]) continue;                 // 过期条目（懒删除）
        if (u == t) return d;
        for (int[] e : g[u]) {
            int v = e[0], w = e[1];
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.offer(new int[]{dist[v], v});   // 允许重复入堆（懒删除生效）
            }
        }
    }
    return -1;
}
```

## 三、易错点

- 网格题边界与 visited 标记别忘了，否则死循环/重复访问。
- 拓扑排序判环：输出数 < 节点数 ⇒ 有环（课程表不可完成）。
- Dijkstra 遇负权失效；最短路有负权用 Bellman-Ford。
- 双向 BFS 的 visited 分两侧，相遇条件在扩展时判断。

## 四、图算法选型速查

| 问题 | 算法 | 复杂度 |
|------|------|--------|
| 无权最短路（单源） | BFS | O(V+E) |
| 正权最短路（单源） | Dijkstra + 堆 | O((V+E) log V) |
| 负权最短路 / 判负环 | Bellman-Ford / SPFA | O(VE) / 平均更快 |
| 全源最短路 | Floyd（DP） | O(V³) |
| 最小生成树 | Kruskal（边）/ Prim（点） | O(E log E) / O(E log V) |
| 拓扑排序 / 判 DAG | Kahn 入度 / DFS 三色 | O(V+E) |
| 强连通分量（有向） | Tarjan / Kosaraju | O(V+E) |
| 欧拉路径 | 度条件 + DFS 删边 | O(V+E) |

> **工程记忆**：BFS 最快最简优先；带权正边 Dijkstra；负权 Bellman-Ford；多源 Floyd（V 小）；「判环」「依赖顺序」拓扑；「去重分组」并查集。

## 面试高频问题（30+ 条）

1. **邻接矩阵 vs 邻接表？** 矩阵 O(V²) 查边 O(1) 适合稠密；表 O(V+E) 省空间适合稀疏。
2. **BFS 和 DFS 区别？** BFS 队列、层序、求无权最短路；DFS 递归/栈、连通与环、回溯。
3. **BFS 为什么能求最短路？** 无权图逐层扩展，首次到达即最短。
4. **岛屿数量思路？** 遍历网格，遇陆地 DFS/BFS 沉岛并计数。
5. **课程表怎么判能否完成？** 拓扑排序（Kahn 入度或 DFS 三色），有环则不能。
6. **拓扑排序 Kahn 算法？** 入度 0 入队，出队减邻居入度，输出数 < 节点数则有环。
7. **Dijkstra 原理？** 贪心取最近未确定节点，松弛邻边；堆优化 O((V+E)logV)。
8. **Dijkstra 为什么不能处理负权？** 已确定最短的节点可能因负权被更新，破坏贪心前提。
9. **负权最短路用什么？** Bellman-Ford（O(VE)，可检负环）、SPFA（队列优化，最坏仍 O(VE)）。
10. **最小生成树两种？** Kruskal（边排序+并查集）、Prim（堆从一点扩）。
11. **Kruskal vs Prim 选哪个？** 边少用 Kruskal（O(E log E)），点少用 Prim。
12. **DFS 三色标记？** 白未访问/灰在栈中/黑已完；遇到灰即回边 ⇒ 有环。
13. **双向 BFS 适用？** 起终点已知、状态空间大（如单词接龙），双向扩展减半深度。
14. **图的连通分量？** DFS/BFS 遍历计数，或并查集（加边合并）。
15. **网格题如何防重复访问？** visited 矩阵或原地修改（沉岛）标记。
16. **A* 是什么？** Dijkstra + 启发式（估算到终点距离），优先扩有望方向，更快。
17. **最短路径有几种算法？** BFS(无权)、Dijkstra(正权)、Bellman-Ford(可负)、Floyd(多源)。
18. **Floyd 算法？** 动态规划 O(V³)，dp[k][i][j] 经前 k 点的最短路，多源。
19. **强连通分量（SCC）？** Tarjan/Kosaraju 算法，把有向图缩点成 DAG。
20. **欧拉路径 vs 哈密顿？** 欧拉走遍边一次（度条件）；哈密顿走遍点一次（NP 难）。
21. **图遍历在实战？** 依赖分析、社交关系、PageRank、网络路由都建图。
22. **并查集和 DFS 都能求连通，选谁？** 动态加边用并查集；静态遍历用 DFS 更直观。
23. **判环的三种方法？** DFS 三色（有向）、拓扑出度计数（有向）、并查集 union 冲突（无向）。
24. **有向图与无向图判环区别？** 无向判环用并查集/DFS 见父跳过；有向要区分「在栈中」的灰。
25. **Dijkstra 的堆为什么允许重复入堆？** 懒删除：过期条目 d > dist[u] 直接跳过，代码更简洁。
26. **「拓扑排序结果唯一吗？」** 不唯一；多个入度 0 节点时顺序取决于队列处理次序。
27. **Floyd 为什么可处理负权但不可有负环？** 每轮松弛保证最短，负环会无限变小（判负环用 Bellman-Ford）。
28. **「最小生成树唯一吗？」** 权值可重复时不唯一；所有边权不同则唯一（Kruskal 证明）。
29. **图在微服务里怎么用？** 调用依赖图检环、故障传播分析（熔断依赖关系）。
30. **「稀疏图/稠密图」怎么判断？** E 与 V² 同阶为稠密；稀疏图用邻接表与堆优化算法。
31. **PageRank 和图论关系？** 随机游走 + 马尔可夫链，收敛于特征向量，是带权图迭代。
32. **「有向无环图 DAG」在工程中的典型？** 任务编排（Airflow）、Spark DAG 调度、Git 提交历史。

## 七、最短路全家桶（补充：Bellman-Ford / SPFA / Floyd）

Dijkstra 已在前文给出（复杂度 O((V+E)log V)），下面补齐另外三种最短路，并给出**选型直觉**。

### 7.1 Bellman-Ford（可处理负权，可检负环）

核心思想：**松弛 V-1 轮**，每轮遍历所有边 `if dist[u] + w < dist[v]: dist[v] = dist[u] + w`。

- 为什么是 V-1 轮？任意两点最短路最多经过 V-1 条边（无负环时），每轮至少「确定」一条边，故 V-1 轮必然收敛。
- 第 V 轮若还能继续松弛 ⇒ 说明存在**负环**（最短路无界）。

```java
// Bellman-Ford：返回 null 表示存在负环
int[] bellmanFord(int n, int[][] edges, int s) { // edges: {u, v, w}
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[s] = 0;
    for (int i = 0; i < n - 1; i++) {            // V-1 轮
        boolean changed = false;
        for (int[] e : edges) {
            int u = e[0], v = e[1], w = e[2];
            if (dist[u] != Integer.MAX_VALUE && dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w; changed = true;
            }
        }
        if (!changed) break;                      // 提前收敛，可提前结束
    }
    // 第 V 轮检测负环
    for (int[] e : edges)
        if (dist[e[0]] != Integer.MAX_VALUE && dist[e[0]] + e[2] < dist[e[1]])
            return null;                          // 存在负环
    return dist;
}
```

- **复杂度**：时间 O(VE)、空间 O(V)。边少且需检测负环时首选。
- **踩坑**：松弛 `dist[u] + w` 前必须先判 `dist[u] != INF`，否则 `Integer.MAX_VALUE + w` 会整数溢出变成负数，导致错误松弛。

### 7.2 SPFA（队列优化的 Bellman-Ford）

用队列只把「被松弛成功」的节点入队，避免每轮全量扫描；平均速度快，但**最坏仍 O(VE)**（可被特殊数据卡成指数级，如网格图构造）。

```java
boolean[] inq; int[] cnt;
boolean spfa(int n, List<int[]>[] g, int s, int[] dist) {
    Arrays.fill(dist, Integer.MAX_VALUE);
    inq = new boolean[n]; cnt = new int[n];
    dist[s] = 0; Deque<Integer> q = new ArrayDeque<>();
    q.offer(s); inq[s] = true;
    while (!q.isEmpty()) {
        int u = q.poll(); inq[u] = false;
        for (int[] e : g[u]) {
            int v = e[0], w = e[1];
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                if (!inq[v]) {
                    q.offer(v); inq[v] = true;
                    if (++cnt[v] >= n) return false; // 入队 ≥ n 次 ⇒ 存在负环
                }
            }
        }
    }
    return true;
}
```

> ⚠️ **踩坑**：竞赛/面试中若数据可控，SPFA 常用；但工程上对负权更稳妥用 Bellman-Ford，且**绝大多数「最短路」场景是正权，优先 Dijkstra**。

### 7.3 Floyd（多源最短路，DP 思想）

`dp[k][i][j]` = 只允许经过前 k 个中间点，i→j 的最短距离；状态压缩为一维 `dist[i][j]`。

```java
void floyd(int n, int[][] d) {          // d 初始化为邻接矩阵，不可达为 INF
    for (int k = 0; k < n; k++)
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if (d[i][k] != INF && d[k][j] != INF)
                    d[i][j] = Math.min(d[i][j], d[i][k] + d[k][j]);
}
```

- **复杂度**：O(V³)、空间 O(V²)。**k 必须在最外层**（保证「经过前 k 个点」的 DP 顺序）。
- 可处理负权（只要无负环）；判负环：`d[i][i] < 0`。
- 适用：V 较小（≤200）、需要任意两点距离（如传递闭包、网络延迟矩阵）。

## 八、最小生成树（Kruskal / Prim）

### 8.1 Kruskal（边视角，并查集）

按边权升序扫描，能合并（不形成环）就选入，选满 V-1 条即止。

```java
// 依赖 算法/并查集题解.md 的 DSU（union 返回 boolean 表示是否成功合并）
int kruskal(int n, int[][] edges) {     // edges: {u, v, w}
    Arrays.sort(edges, (a, b) -> a[2] - b[2]);
    DSU dsu = new DSU(n);
    int cost = 0, picked = 0;
    for (int[] e : edges) {
        if (dsu.union(e[0], e[1])) {    // 合并成功 ⇒ 不形成环
            cost += e[2];
            if (++picked == n - 1) break;
        }
    }
    return picked == n - 1 ? cost : -1; // -1 表示图不连通
}
```

- **复杂度**：O(E log E)（排序主导），适合**稀疏图**。

### 8.2 Prim（点视角，堆）

从任一节点出发，用最小堆维护「已选集合到未选节点」的最小边，每次取最近点加入。

```java
int prim(List<int[]>[] g, int n, int s) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    boolean[] vis = new boolean[n];
    dist[s] = 0;
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[1] - b[1]); // {点, w}
    pq.offer(new int[]{s, 0});
    int cost = 0, cnt = 0;
    while (!pq.isEmpty()) {
        int[] cur = pq.poll();
        int u = cur[0], w = cur[1];
        if (vis[u]) continue;           // 懒删除
        vis[u] = true; cost += w; cnt++;
        for (int[] e : g[u]) {
            int v = e[0], nw = e[1];
            if (!vis[v] && nw < dist[v]) { dist[v] = nw; pq.offer(new int[]{v, nw}); }
        }
    }
    return cnt == n ? cost : -1;
}
```

- **复杂度**：O(E log V)。适合**稠密图**（边多时优于 Kruskal 的 E log E）。
- **Kruskal 与 Prim 都是贪心**：Kruskal 贪「全局最小边」、Prim 贪「当前最近点」，交换论证可证最优。

## 九、强连通分量 Tarjan（有向图缩点）

强连通分量（SCC）：有向图中两两可达的最大子图。Tarjan 用 DFS + 栈 + `dfn`/`low`：

- `dfn[u]`：u 的 DFS 序；`low[u]`：u 能回溯到的最早祖先的 dfn。
- 当 `dfn[u] == low[u]` 时，栈中 u 及其上方的节点构成一个 SCC。

```java
int[] dfn, low; int ts, scc; Deque<Integer> stk; boolean[] inStk;
void tarjan(int u, List<Integer>[] g) {
    dfn[u] = low[u] = ++ts; stk.push(u); inStk[u] = true;
    for (int v : g[u]) {
        if (dfn[v] == 0) { tarjan(v, g); low[u] = Math.min(low[u], low[v]); }
        else if (inStk[v]) low[u] = Math.min(low[u], dfn[v]);
    }
    if (dfn[u] == low[u]) {                 // 找到一个 SCC
        scc++;
        while (true) {
            int x = stk.pop(); inStk[x] = false;
            if (x == u) break;
        }
    }
}
```

- **复杂度**：O(V+E)。应用：把有向图**缩点成 DAG**，再用 DAG DP / 拓扑求解（如「受欢迎的牛 105」）。

## 十、A* 算法（带启发式的 Dijkstra）

Dijkstra 按 `g(n)`（起点到 n 的真实距离）取最小；A* 按 `f(n)=g(n)+h(n)` 取最小，其中 `h(n)` 是 n 到终点的**启发式估算**（必须**可采纳 / admissible**，即 h ≤ 真实距离，才能保证最优）。

- 网格地图常用曼哈顿距离 / 欧氏距离作 h。
- 若 h≡0 ⇒ 退化为 Dijkstra；若 h 过大则速度快但不保证最优。

> 工程：「地图导航」「游戏寻路」多用 A*；OSPF 等网络路由用纯 Dijkstra（无合适 h）。

## 十一、边界与踩坑（补充）

- **重边与自环**：邻接表建图时自环边（u==v）在 Dijkstra 中无效但无害；重边取最小即可。
- **dis 初始化 INF 溢出**：松弛 `dist[u]+w` 时若 dist 为 `Integer.MAX_VALUE` 会溢出，先判 `dist[u] != INF`。
- **Floyd 的 k 顺序**：k 必须最外层，否则 DP 语义错误。
- **网格 BFS 的 visited**：四个方向别越界；沉岛法记得 `grid[i][j]='0'` 防止重复访问。
- **拓扑排序多解**：依赖工具（Maven/npm）通常按「确定性顺序」输出，但图论上顺序不唯一。
- **负权陷阱**：Dijkstra 遇负权直接错误，务必先判断边权符号。

## 十二、Go 语言图算法示例（Dijkstra）

```go
package main

// 朴素 O(V²) Dijkstra（适合稠密图，Go 无内置优先队列时可用）
func dijkstra(n int, g [][]int, s int) []int {
    const INF = int(1e9)
    dist := make([]int, n)
    for i := range dist { dist[i] = INF }
    dist[s] = 0
    visited := make([]bool, n)
    for i := 0; i < n; i++ {
        u, best := -1, INF
        for v := 0; v < n; v++ {
            if !visited[v] && dist[v] < best { best, u = dist[v], v }
        }
        if u == -1 { break }
        visited[u] = true
        for v := 0; v < n; v++ {
            if g[u][v] > 0 && !visited[v] && dist[u]+g[u][v] < dist[v] {
                dist[v] = dist[u] + g[u][v]
            }
        }
    }
    return dist
}
```

> Go 没有内置优先队列，稠密图用朴素 O(V²) 取最小即可；稀疏图可基于 `container/heap` 实现二叉堆（如「[堆与优先队列](堆与优先队列.md)」所述）。

## 十三、速记口诀与小结

- **遍历**：BFS 求无权最短路（首次到即最短），DFS 求连通/环/拓扑。
- **最短路**：无权 BFS，正权 Dijkstra，负权 Bellman-Ford/SPFA，多源 Floyd。
- **生成树**：边视角 Kruskal（并查集），点视角 Prim（堆）。
- **有向图**：判环/拓扑 Kahn 或 DFS 三色；缩点 Tarjan。
- **口诀**：「无权 BFS 正 Dijkstra，负权 Bellman 莫忘它；多源 Floyd 三重奏，生成两将 K 与 P。」
