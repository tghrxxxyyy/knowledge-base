# 位运算（Bit Manipulation）

## 〇、本体介绍

**位运算**：直接对整数的二进制位操作，速度极快、空间省。常用：`&`(与)、`|`(或)、`^`(异或)、`~`(取反)、`<<` `>>`(移位)、`>>>`(无符号右移，Java)。

**核心性质**：
- `x ^ x = 0`，`x ^ 0 = x`（异或：相同为0、不同为1，可消重、可交换）。
- `x & -x`（或 `x & (~x+1)`）= 取出最低位的 1（lowbit）。
- `n & (n-1)` 消去最低位 1（判 2 的幂、计数 1 的个数）。
- 无进位加法 = 异或；进位 = 与后左移。

**面试高频**：只出现一次的数字（异或）、2 的幂、汉明重量、位 1 个数、N 皇后位运算、子集枚举、状态压缩 DP、两数之和（不用+/-）、反转位。

---

## 一、必备技巧

- **消最低位 1**：`n &= n-1`，循环直到 0 即得 1 的个数（汉明重量）。
- **lowbit**：`n & -n`，用于树状数组、判奇偶位。
- **取相反数**：`~x + 1`（补码）。
- **交换两数（不用临时）**：`a ^= b; b ^= a; a ^= b;`（仅演示，实际少用）。
- **判断奇偶**：`(n & 1) == 0` 为偶。
- **状态压缩**：用 int/long 的每一位表示一个布尔状态，枚举子集 `for(s=mask; s; s=(s-1)&mask)`。

### 1.1 深挖：位运算速查表（背熟）

| 操作 | 写法 | 用途 |
|------|------|------|
| 判奇偶 | `(x & 1) == 0` | 比 `%2` 快 |
| 乘/除 2 | `x << 1` / `x >> 1` | 注意负数算术右移 |
| 判 2 的幂 | `x > 0 && (x & (x-1)) == 0` | 经典 |
| 最低位 1 | `x & -x` | lowbit，树状数组核心 |
| 消最低位 1 | `x & (x-1)` | 计数/判幂 |
| 取第 k 位 | `(x >> k) & 1` | 状态压缩遍历 |
| 置第 k 位为 1 | `x |= 1 << k` | 状态标记 |
| 清第 k 位为 0 | `x &= ~(1 << k)` | 取消标记 |
| 翻转第 k 位 | `x ^= 1 << k` | 状态切换 |
| 取低 k 位 | `x & ((1 << k) - 1)` | 掩码 |
| 判异号 | `(a ^ b) < 0` | 最高位不同 |
| 最大值交换 | `a ^= b; b ^= a; a ^= b` | 不用临时变量 |

> **优先级警告**：`&`、`|`、`^` 低于 `==`、`!=`、算术运算——写表达式务必加括号（`(x & 1) == 0` 而非 `x & 1 == 0`）。

## 二、经典例题

- **只出现一次的数字（136）**：全部异或，成对抵消，剩唯一。
- **只出现一次的数字 II（137）**：出现 3 次，用两个变量按位累计模 3，或逐位统计。
- **2 的幂（231）**：`n>0 && (n & (n-1))==0`。
- **位 1 的个数（191）**：`n &= n-1` 计数；或用分治 `n = (n&0x5555...)`。
- **两数之和（不用+/-，371）**：递归 `sum = a^b; carry=(a&b)<<1;` 直到 carry=0。
- **子集枚举 / N 皇后位运算**：用位表示列/对角线占用，回溯中 `bits = (col|pie|na) 取反 & full` 得可放位。

### 2.1 深挖：高频题模板

```java
// 136 只出现一次的数字：全体异或
int singleNumber(int[] nums) {
    int r = 0;
    for (int x : nums) r ^= x;
    return r;
}
// 进阶（260）：两个只出现一次的数 → 全体异或得 a^b → 取 lowbit 分组再异或
int[] singleNumberII(int[] nums) {
    int xor = 0;
    for (int x : nums) xor ^= x;
    int low = xor & -xor;              // 分组依据：a、b 在 low 位不同
    int a = 0, b = 0;
    for (int x : nums) {
        if ((x & low) == 0) a ^= x; else b ^= x;
    }
    return new int[]{a, b};
}

// 191 位 1 的个数
int hammingWeight(int n) {
    int c = 0;
    while (n != 0) { n &= n - 1; c++; }   // 循环次数 = 1 的个数
    return c;
}

// 371 两数之和（无 +/-）
int getSum(int a, int b) {
    while (b != 0) {
        int carry = (a & b) << 1;   // 进位
        a = a ^ b;                  // 无进位和
        b = carry;
    }
    return a;
}

// 78 子集枚举（状态压缩，O(2^n·n) 或迭代添加）
for (int mask = 0; mask < (1 << n); mask++) {
    for (int i = 0; i < n; i++)
        if ((mask >> i & 1) == 1) /* 包含第 i 个元素 */;
}
// 子集遍历的「降序枚举」：for (int s = mask; s != 0; s = (s - 1) & mask) 遍历 mask 的所有子集
```

## 三、易错点

- 右移：Java 有符号 `>>` 补符号位，无符号 `>>>` 补 0，负数要用 `>>>`。
- 优先级：位运算低于 `==`，务必加括号。
- 异或交换仅当两个变量引用不同内存，且不适合含重叠的场景。
- `1 << k` 的 1 是 int；k ≥ 31 时溢出，用 `1L << k`。
- 移位运算符右侧取模（`x << 32` 等于 `x << 0`），别被「移动 32 位」迷惑。

## 四、状态压缩 DP 与位运算

- **状态压缩 DP**：用二进制位表示「子集状态」，`dp[mask]` 表示集合状态为 mask 时的最优值。
- 典型题：**旅行商 TSP**、**N 皇后**、**划分为 k 个等和子集（698）**、**每个状态拿/不拿**。
- 常用转移：`dp[mask | (1<<j)] = min(dp[mask] + w)`；子集遍历 `s = (s-1) & mask`。

### 4.1 深挖：N 皇后位运算（回溯加速）

```java
void dfs(int row, int col, int pie, int na, int n) {
    // col：已占列；pie：撇对角线（左上→右下）；na：捺对角线
    if (row == n) { count++; return; }
    int available = (~(col | pie | na)) & ((1 << n) - 1);  // 可放位置（低 n 位）
    while (available != 0) {
        int p = available & -available;                    // 取一个可放位
        dfs(row + 1, col | p, (pie | p) << 1, (na | p) >> 1, n);
        available &= available - 1;                        // 移除该位
    }
}
```

> 位运算版比布尔数组版快一个量级（省循环与数组清零），是「位运算工程价值」的绝佳例证。

## 面试高频问题（30+ 条）

1. **异或核心性质？** `x^x=0`、`x^0=x`、可交换结合；用于消重。
2. **只出现一次的数字？** 全部异或，成对抵消，剩唯一。
3. **出现 3 次只留一个？** 逐位统计模 3，或两变量状态机。
4. **如何数二进制 1 的个数？** `n &= n-1` 循环消最低位 1 计数，或用分治。
5. **`n & (n-1)` 作用？** 消去最低位 1；`==0` 且 n>0 判 2 的幂。
6. **`n & -n` 是什么？** lowbit，取最低位 1（树状数组核心）。
7. **负数怎么表示？** 补码：`~x+1` 为 -x。
8. **`>>` 和 `>>>` 区别？** `>>` 补符号位（算术），`>>>` 补 0（逻辑），负数用 `>>>`。
9. **不用 + 算两数和？** 异或得无进位和，与后左移得进位，递归直到进位 0。
10. **如何不用临时变量交换？** `a^=b;b^=a;a^=b;`（仅演示）。
11. **判断奇偶？** `(n&1)==0` 偶数。
12. **状态压缩是什么？** 用整数位表示布尔集合，如棋盘、子集，节省空间加速。
13. **枚举子集怎么写？** `for(int s=mask; s!=0; s=(s-1)&mask)`。
14. **N 皇后位运算优化？** 用位表示列/撇/捺占用，`bits = ~(col|pie|na) & full` 取可放位。
15. **位运算优先级坑？** 低于比较和加减，必须加括号。
16. **如何反转二进制位（190）？** 逐位取并拼到结果，或用分治交换。
17. **汉明距离（461）？** 两数和异或后数 1 的个数。
18. **如何用位运算取某几位？** `x & mask`，或 `(x>>k) & 1` 取第 k 位。
19. **位运算在实战？** 权限位掩码、布隆过滤器、压缩状态、加密、底层优化。
20. **设置/清除/翻转第 k 位？** 设 `x|=1<<k`；清 `x&=~(1<<k)`；翻 `x^=1<<k`。
21. **判断两整数异号？** `(a^b)<0`（异号则最高位不同）。
22. **位运算 vs 乘除以2？** `x<<1` 乘2、`x>>1` 除2（正数等价，负数注意），更快但可读性差。
23. **两个只出现一次的数字（260）？** 全体异或得 a^b，取 lowbit 分组，两组再异或。
24. **`n & (n-1)` 在「判断是否 2 的幂」外的用途？** 求 1 个数、检测是否「只有一个 1」。
25. **二进制子集降序枚举为什么 `(s-1)&mask`？** 保证 s 递减且始终是 mask 子集，不重不漏。
26. **状态压缩 DP 为什么快？** 用 int 位当集合，转移 O(1) 判存在，替代 HashMap 集合。
27. **ZigZag 编码？** `(n << 1) ^ (n >> 31)`，负数映射到奇数、正数到偶数，省空间（Protobuf）。
28. **如何取相反数？** `~x + 1`（补码）；`-x` 亦可。
29. **bitmap 统计日活原理？** 每天一个 bit，`SETBIT key day 1`，`BITCOUNT` 统计；多天 `BITOP OR`。
30. **位运算做权限判断？** 权限位 `has = (perm & flag) == flag`；加权限 `perm |= flag`。
31. **int 能装多少种子集状态？** 2^31 种（符号位需注意，用无符号技巧或 long）。
32. **用位运算找「第一个 1 的位置」？** `Integer.numberOfTrailingZeros(lowbit)`；工程上 JDK 有现成方法。
