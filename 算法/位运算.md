# 位运算（Bit Manipulation）

## 〇、本体介绍

**位运算**：直接对整数的二进制位操作，速度极快、空间省。常用：`&`(与)、`|`(或)、`^`(异或)、`~`(取反)、`<<` `>>`(移位)、`>>>`(无符号右移，Java)。

**核心性质**：
- `x ^ x = 0`，`x ^ 0 = x`（异或：相同为0、不同为1，可消重、可交换）。
- `x & -x`（或 `x & (~x+1)`）= 取出最低位的 1（lowbit）。
- `n & (n-1)` 消去最低位 1（判 2 的幂、计数 1 的个数）。
- 无进位加法 = 异或；进位 = 与后左移。

**面试高频**：只出现一次的数字（异或）、2 的幂、汉明重量、位 1 个数、N 皇后位运算、子集枚举、状态压缩 DP、两数之和（不用+/-）、反转位。

---

## 一、必备技巧

- **消最低位 1**：`n &= n-1`，循环直到 0 即得 1 的个数（汉明重量）。
- **lowbit**：`n & -n`，用于树状数组、判奇偶位。
- **取相反数**：`~x + 1`（补码）。
- **交换两数（不用临时）**：`a ^= b; b ^= a; a ^= b;`（仅演示，实际少用）。
- **判断奇偶**：`(n & 1) == 0` 为偶。
- **状态压缩**：用 int/long 的每一位表示一个布尔状态，枚举子集 `for(s=mask; s; s=(s-1)&mask)`。

### 1.1 深挖：位运算速查表（背熟）

| 操作 | 写法 | 用途 |
|------|------|------|
| 判奇偶 | `(x & 1) == 0` | 比 `%2` 快 |
| 乘/除 2 | `x << 1` / `x >> 1` | 注意负数算术右移 |
| 判 2 的幂 | `x > 0 && (x & (x-1)) == 0` | 经典 |
| 最低位 1 | `x & -x` | lowbit，树状数组核心 |
| 消最低位 1 | `x & (x-1)` | 计数/判幂 |
| 取第 k 位 | `(x >> k) & 1` | 状态压缩遍历 |
| 置第 k 位为 1 | `x |= 1 << k` | 状态标记 |
| 清第 k 位为 0 | `x &= ~(1 << k)` | 取消标记 |
| 翻转第 k 位 | `x ^= 1 << k` | 状态切换 |
| 取低 k 位 | `x & ((1 << k) - 1)` | 掩码 |
| 判异号 | `(a ^ b) < 0` | 最高位不同 |
| 最大值交换 | `a ^= b; b ^= a; a ^= b` | 不用临时变量 |

> **优先级警告**：`&`、`|`、`^` 低于 `==`、`!=`、算术运算——写表达式务必加括号（`(x & 1) == 0` 而非 `x & 1 == 0`）。

## 二、经典例题

- **只出现一次的数字（136）**：全部异或，成对抵消，剩唯一。
- **只出现一次的数字 II（137）**：出现 3 次，用两个变量按位累计模 3，或逐位统计。
- **2 的幂（231）**：`n>0 && (n & (n-1))==0`。
- **位 1 的个数（191）**：`n &= n-1` 计数；或用分治 `n = (n&0x5555...)`。
- **两数之和（不用+/-，371）**：递归 `sum = a^b; carry=(a&b)<<1;` 直到 carry=0。
- **子集枚举 / N 皇后位运算**：用位表示列/对角线占用，回溯中 `bits = (col|pie|na) 取反 & full` 得可放位。

### 2.1 深挖：高频题模板

```java
// 136 只出现一次的数字：全体异或
int singleNumber(int[] nums) {
    int r = 0;
    for (int x : nums) r ^= x;
    return r;
}
// 进阶（260）：两个只出现一次的数 → 全体异或得 a^b → 取 lowbit 分组再异或
int[] singleNumberII(int[] nums) {
    int xor = 0;
    for (int x : nums) xor ^= x;
    int low = xor & -xor;              // 分组依据：a、b 在 low 位不同
    int a = 0, b = 0;
    for (int x : nums) {
        if ((x & low) == 0) a ^= x; else b ^= x;
    }
    return new int[]{a, b};
}

// 191 位 1 的个数
int hammingWeight(int n) {
    int c = 0;
    while (n != 0) { n &= n - 1; c++; }   // 循环次数 = 1 的个数
    return c;
}

// 371 两数之和（无 +/-）
int getSum(int a, int b) {
    while (b != 0) {
        int carry = (a & b) << 1;   // 进位
        a = a ^ b;                  // 无进位和
        b = carry;
    }
    return a;
}

// 78 子集枚举（状态压缩，O(2^n·n) 或迭代添加）
for (int mask = 0; mask < (1 << n); mask++) {
    for (int i = 0; i < n; i++)
        if ((mask >> i & 1) == 1) /* 包含第 i 个元素 */;
}
// 子集遍历的「降序枚举」：for (int s = mask; s != 0; s = (s - 1) & mask) 遍历 mask 的所有子集
```

## 三、易错点

- 右移：Java 有符号 `>>` 补符号位，无符号 `>>>` 补 0，负数要用 `>>>`。
- 优先级：位运算低于 `==`，务必加括号。
- 异或交换仅当两个变量引用不同内存，且不适合含重叠的场景。
- `1 << k` 的 1 是 int；k ≥ 31 时溢出，用 `1L << k`。
- 移位运算符右侧取模（`x << 32` 等于 `x << 0`），别被「移动 32 位」迷惑。

## 四、状态压缩 DP 与位运算

- **状态压缩 DP**：用二进制位表示「子集状态」，`dp[mask]` 表示集合状态为 mask 时的最优值。
- 典型题：**旅行商 TSP**、**N 皇后**、**划分为 k 个等和子集（698）**、**每个状态拿/不拿**。
- 常用转移：`dp[mask | (1<<j)] = min(dp[mask] + w)`；子集遍历 `s = (s-1) & mask`。

### 4.1 深挖：N 皇后位运算（回溯加速）

```java
void dfs(int row, int col, int pie, int na, int n) {
    // col：已占列；pie：撇对角线（左上→右下）；na：捺对角线
    if (row == n) { count++; return; }
    int available = (~(col | pie | na)) & ((1 << n) - 1);  // 可放位置（低 n 位）
    while (available != 0) {
        int p = available & -available;                    // 取一个可放位
        dfs(row + 1, col | p, (pie | p) << 1, (na | p) >> 1, n);
        available &= available - 1;                        // 移除该位
    }
}
```

> 位运算版比布尔数组版快一个量级（省循环与数组清零），是「位运算工程价值」的绝佳例证。

## 面试高频问题（30+ 条）

1. **异或核心性质？** `x^x=0`、`x^0=x`、可交换结合；用于消重。
2. **只出现一次的数字？** 全部异或，成对抵消，剩唯一。
3. **出现 3 次只留一个？** 逐位统计模 3，或两变量状态机。
4. **如何数二进制 1 的个数？** `n &= n-1` 循环消最低位 1 计数，或用分治。
5. **`n & (n-1)` 作用？** 消去最低位 1；`==0` 且 n>0 判 2 的幂。
6. **`n & -n` 是什么？** lowbit，取最低位 1（树状数组核心）。
7. **负数怎么表示？** 补码：`~x+1` 为 -x。
8. **`>>` 和 `>>>` 区别？** `>>` 补符号位（算术），`>>>` 补 0（逻辑），负数用 `>>>`。
9. **不用 + 算两数和？** 异或得无进位和，与后左移得进位，递归直到进位 0。
10. **如何不用临时变量交换？** `a^=b;b^=a;a^=b;`（仅演示）。
11. **判断奇偶？** `(n&1)==0` 偶数。
12. **状态压缩是什么？** 用整数位表示布尔集合，如棋盘、子集，节省空间加速。
13. **枚举子集怎么写？** `for(int s=mask; s!=0; s=(s-1)&mask)`。
14. **N 皇后位运算优化？** 用位表示列/撇/捺占用，`bits = ~(col|pie|na) & full` 取可放位。
15. **位运算优先级坑？** 低于比较和加减，必须加括号。
16. **如何反转二进制位（190）？** 逐位取并拼到结果，或用分治交换。
17. **汉明距离（461）？** 两数和异或后数 1 的个数。
18. **如何用位运算取某几位？** `x & mask`，或 `(x>>k) & 1` 取第 k 位。
19. **位运算在实战？** 权限位掩码、布隆过滤器、压缩状态、加密、底层优化。
20. **设置/清除/翻转第 k 位？** 设 `x|=1<<k`；清 `x&=~(1<<k)`；翻 `x^=1<<k`。
21. **判断两整数异号？** `(a^b)<0`（异号则最高位不同）。
22. **位运算 vs 乘除以2？** `x<<1` 乘2、`x>>1` 除2（正数等价，负数注意），更快但可读性差。
23. **两个只出现一次的数字（260）？** 全体异或得 a^b，取 lowbit 分组，两组再异或。
24. **`n & (n-1)` 在「判断是否 2 的幂」外的用途？** 求 1 个数、检测是否「只有一个 1」。
25. **二进制子集降序枚举为什么 `(s-1)&mask`？** 保证 s 递减且始终是 mask 子集，不重不漏。
26. **状态压缩 DP 为什么快？** 用 int 位当集合，转移 O(1) 判存在，替代 HashMap 集合。
27. **ZigZag 编码？** `(n << 1) ^ (n >> 31)`，负数映射到奇数、正数到偶数，省空间（Protobuf）。
28. **如何取相反数？** `~x + 1`（补码）；`-x` 亦可。
29. **bitmap 统计日活原理？** 每天一个 bit，`SETBIT key day 1`，`BITCOUNT` 统计；多天 `BITOP OR`。
30. **位运算做权限判断？** 权限位 `has = (perm & flag) == flag`；加权限 `perm |= flag`。
31. **int 能装多少种子集状态？** 2^31 种（符号位需注意，用无符号技巧或 long）。
32. **用位运算找「第一个 1 的位置」？** `Integer.numberOfTrailingZeros(lowbit)`；工程上 JDK 有现成方法。

## 七、位运算逐题精讲（含 Go 实现 + 复杂度）

### 7.1 只出现一次的数字（136）与两个（260）

```go
// 136：全部异或，成对抵消
func singleNumber(nums []int) int {
    r := 0
    for _, x := range nums { r ^= x }
    return r
}
// 时间 O(n)，空间 O(1)

// 260：两个只出现一次 → 全体异或得 a^b，取 lowbit 分组再异或
func singleNumberTwo(nums []int) []int {
    xor := 0
    for _, x := range nums { xor ^= x }
    low := xor & -xor // a、b 在该位不同
    a, b := 0, 0
    for _, x := range nums {
        if x&low == 0 { a ^= x } else { b ^= x }
    }
    return []int{a, b}
}
// 时间 O(n)，空间 O(1)。lowbit 把数组分成两组，各自只含一个"单身"。
```

### 7.2 位 1 的个数（191）与两数和（371）

```go
func hammingWeight(n uint32) int {
    c := 0
    for n != 0 { n &= n - 1; c++ } // 每次消去最低位 1
    return c
}
// 时间 O(k)，k=1 的个数（比逐位扫 32 次快）

func getSum(a, b int) int {
    for b != 0 {
        carry := (a & b) << 1 // 进位
        a ^= b                 // 无进位和
        b = carry
    }
    return a
}
// 时间 O(位宽)，空间 O(1)。无 +/- 实现加法：异或=无进位和，与后左移=进位。
```

### 7.3 子集枚举与 N 皇后位运算

```go
// 枚举所有子集（mask 的每种取值代表一个子集）
for mask := 0; mask < (1 << n); mask++ {
    for i := 0; i < n; i++ {
        if mask>>i&1 == 1 { /* 包含第 i 个元素 */ }
    }
}
// 枚举 mask 的所有非空子集：总次数 = 2^popcount(mask)
for sub := mask; sub > 0; sub = (sub - 1) & mask { /* 处理 sub */ }

// N 皇后（位运算版加速）：col/pie/na 用位记录占用
func totalNQueens(n int) int {
    var count int
    var dfs func(row, col, pie, na int)
    dfs = func(row, col, pie, na int) {
        if row == n { count++; return }
        available := ^(col | pie | na) & ((1 << n) - 1) // 可放位置（低 n 位）
        for available != 0 {
            p := available & -available // 取一个可放位（lowbit）
            dfs(row+1, col|p, (pie|p)<<1, (na|p)>>1)
            available &= available - 1 // 移除该位
        }
    }
    dfs(0, 0, 0, 0)
    return count
}
// 时间 O(N!)（同暴力），但位运算常数极小；空间 O(N)（递归栈）。
```

## 九、工程深挖（真实系统）

### 9.1 权限位掩码（RBAC）

```go
const (
    Read  = 1 << 0 // 1
    Write = 1 << 1 // 2
    Exec  = 1 << 2 // 4
)
func can(p, flag int) bool { return p&flag == flag } // 有该权限?
func grant(p, flag int) int { return p | flag }       // 加权限
func revoke(p, flag int) int { return p &^ flag }      // 取消（Go 的清位: &^）
// 时间 O(1)，空间 O(1)。一个 int 存 31 个布尔权限，省内存、易持久化。
```

### 9.2 雪花 ID（Snowflake）位段拼接

```
63位: 1(符号) | 41(时间戳ms) | 10(机器ID) | 12(序列号)
id = (timestamp << 22) | (machineID << 12) | sequence
```
> 用移位把三段拼进一个 long，全局唯一且有序——位运算在分布式 ID 的教科书应用（见 场景设计/分布式ID生成）。

### 9.3 ZigZag 编码（Protobuf 负整数）

```go
func zigzag(n int32) int32 { return (n << 1) ^ (n >> 31) } // 负数→奇数, 正数→偶数
// 把绝对值小的负数也映射成小正数，使 varint 编码更省字节。
```

### 9.4 Bitmap 统计日活

Redis `SETBIT day uid 1` + `BITCOUNT`；多天 `BITOP OR` 求并集。一个 bit 代表一个用户当日是否活跃，1 亿用户仅 12MB。

## 十、更多易错点（补充）

1. `1 << k` 的 `1` 是 int；k ≥ 31 溢出，用 `1L << k`（Java）或 `uint(1) << k`（Go）。
2. `>>` 算术补符号位、`>>>` 逻辑补 0（Java）；负数要用 `>>>`。
3. 位运算优先级**低于** `==`、`<`、`+`；务必加括号：`(x & 1) == 0` 而非 `x & 1 == 0`。
4. 异或交换仅适用于两个**不同内存**变量；同一变量自异或会变 0。
5. 取反 `~x` 在 Java 是对 int 全位取反（含符号位），结果常为负，注意语义。
6. 移位右侧操作数在 Java 会被 `% 32`（int）或 `% 64`（long）取模，`x << 32` 等于 `x << 0`，别踩坑。
7. 状态压缩枚举子集 `for sub = mask; sub; sub = (sub-1)&mask` 会遍历**所有非空子集**（含 mask 自身），不会漏。

## 十一、速记口诀与小结

> **口诀**：异或消重零，lowbit 取末一；`n&n-1` 消一判幂，`n&-n` 取末；状态用位压，权限用掩码；移位做乘除，ZigZag 省字节；雪花朵段拼，bitmap 记日活；优先级要括号，移位防溢出。

- 面试三连：**性质（异或/lowbit）→ 应用（消重/状态压缩/权限）→ 坑（优先级/溢出/符号）**。

|------|------|------|
| 只出现一次的数字 | ✅ 全体异或 | `x^x=0` |
| 两个只出现一次 | ✅ 异或+lowbit 分组 | `xor & -xor` |
| 出现 3 次留一个 | ✅ 逐位模 3 / 两变量 | 状态机 |

1. 默写 lowbit：`x & -x`；消最低位 1：`x & (x-1)`。

## 十四、位运算组合技巧实战

### 14.1 枚举子集求和（状态压缩 DP 雏形）

```go
// 给定数组，求所有"子集异或和"的种类数 / 最大异或和 —— 用位枚举子集
func subsetXor(nums []int) int {
    maxXor := 0
    for mask := 0; mask < (1 << len(nums)); mask++ {
        xr := 0
        for i := 0; i < len(nums); i++ {
            if mask>>i&1 == 1 { xr ^= nums[i] }
        }
        if xr > maxXor { maxXor = xr }
    }
    return maxXor // n≤20 时可枚举；n 大需线性基（见进阶）
}
// 时间 O(n·2^n)。n 大时"最大子集异或"用线性基（Gaussian 消元思想），O(n·位宽)。
```

### 14.2 位图去重 / 计数（省空间）

```go
// 用 int64 的每一位标记某元素是否出现（值域 ≤64 时极省）
func hasAllBits(set int64, vals []int) bool {
    for _, v := range vals {
        if set&(1<<uint(v)) == 0 { return false } // 第 v 位为 0 → 未出现
    }
    return true
}
// 经典题：判定"字母异位词/全等字符集"（值域 26 用 int32 即可）。
```

### 14.3 高频追问升级表

| 追问 | 回答要点 |
|------|------|
| "如何用位运算判断 2 的幂？" | `n>0 && n&(n-1)==0`（只有一个 1） |
| "lowbit 在哪些结构用到？" | 树状数组、判定奇偶段、笛卡尔树辅助 |
| "异或交换为什么少见？" | 仅演示；引用相同会清零；可读性差 |
| "如何用位做权限增删？" | `\|=` 加、`&^=` 删、`&` 判（见 9.1） |
| "n 很大时最大子集异或？" | 线性基，O(n·32)，非枚举 |
| "ZigZag 为什么省字节？" | 把负数映射成奇数，varint 更短 |

> 进阶提示：**线性基**是位运算在"最大异或"类问题的杀手锏，面试提到即加分（[动态规划](动态规划.md) 的位运算 DP 也常用）。
