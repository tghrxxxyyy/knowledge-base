# 二叉树进阶高频题解

> 二叉树是面试高频中的高频。本文进阶讲解遍历（递归/迭代）、BST 性质、序列化、最近公共祖先、路径和等经典题。

## 1. 三种遍历（递归）

```python
def preorder(n):
    if not n: return
    print(n.val); preorder(n.left); preorder(n.right)
def inorder(n):
    if not n: return
    inorder(n.left); print(n.val); inorder(n.right)
def postorder(n):
    if not n: return
    postorder(n.left); postorder(n.right); print(n.val)
```

## 2. 迭代遍历（栈模拟）

以中序为例：

```python
def inorder_iter(root):
    st, cur, res = [], root, []
    while st or cur:
        while cur: st.append(cur); cur=cur.left
        cur=st.pop(); res.append(cur.val); cur=cur.right
    return res
```

## 3. 层序（BFS）

```python
def level(root):
    if not root: return []
    q, res=[root], []
    while q:
        n=len(q)
        res.append([x.val for x in q])
        for _ in range(n):
            x=q.pop(0)
            if x.left:q.append(x.left)
            if x.right:q.append(x.right)
    return res
```

## 4. BST 性质

- 中序遍历严格递增。
- 左子树 < 根 < 右子树。
- 验证 BST：递归传 (min, max) 边界。

```python
def isValidBST(n, lo=float('-inf'), hi=float('inf')):
    if not n: return True
    if not (lo < n.val < hi): return False
    return isValidBST(n.left, lo, n.val) and isValidBST(n.right, n.val, hi)
```

## 6. 最近公共祖先（LCA）

```python
def lca(root, p, q):
    if not root or root==p or root==q: return root
    l=lca(root.left,p,q); r=lca(root.right,p,q)
    if l and r: return root
    return l or r
```

## 7. 路径与求和

- 路径和（根到叶）：递归累加。
- 路径总和 III（任意起止）：前缀和 + 哈希。
- 最大路径和（可拐弯）：后序返回单侧最大 + 全局更新。

## 8. 翻转/对称/相同

- 翻转：交换左右子树（后序）。
- 对称：递归比较 `left.right == right.left`。
- 相同：结构值都等。

## 10. 复杂度

- 遍历：O(n) 时间，递归 O(h) 栈空间（h=高度）。
- 迭代：O(n) 时间，O(n) 或 O(h) 栈。
