# 高级数据结构高频题解

> 数组/链表/哈希是入门，堆、并查集、线段树、Trie、单调栈才是面试分水岭。它们解决的是"区间查询""动态最值""连通性""前缀匹配"等特定问题。掌握适用场景比背实现更重要。

## 1. 数据结构速查

| 结构 | 解决 | 典型题 |
| --- | --- | --- |
| 堆/优先队列 | 动态 TopK、中位数 | 数据流中位数 |
| 并查集 | 连通性、分组 | 岛屿数量、账号合并 |
| 线段树/树状数组 | 区间和/最值（可改） | 区间求和、逆序对 |
| Trie | 前缀匹配 | 单词搜索、异或最大 |
| 单调栈/队列 | 最近大/小、滑动窗口 | 每日温度、最大矩形 |
| 跳表/SkipList | 有序区间（Redis） | 理解底层 |

## 2. 并查集模板

```python
class DSU:
    def __init__(self, n):
        self.p = list(range(n))
    def find(self, x):
        if self.p[x] != x:
            self.p[x] = self.find(self.p[x])
        return self.p[x]
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra != rb:
            self.p[ra] = rb
            return True
        return False
```
- 路径压缩 + 按秩合并，接近 O(1)。

## 3. 线段树（区间求和）

```python
# 建树 O(n)，查询/更新 O(log n)
def build(node, l, r):
    if l == r: tree[node] = arr[l]
    else:
        m=(l+r)//2
        build(2*node,l,m); build(2*node+1,m+1,r)
        tree[node]=tree[2*node]+tree[2*node+1]
```
- 适合"数组频繁区间操作"。

## 4. 单调栈

```python
# 求每个元素右边第一个更大（每日温度）
st=[]; ans=[0]*len(T)
for i,x in enumerate(T):
    while st and T[st[-1]] < x:
        j=st.pop(); ans[j]=i-j
    st.append(i)
```
- 栈保持单调递增，O(n) 解决"最近更大/更小"。
