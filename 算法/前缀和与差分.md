# 前缀和与差分（Prefix Sum & Difference）

## 〇、本体介绍

**前缀和**：`pre[i] = a[0]+...+a[i-1]`（或 `pre[i]=pre[i-1]+a[i]`），使**任意区间和** `sum(l,r) = pre[r+1]-pre[l]` 从 O(n) 降到 O(1)。一维用于频繁区间查询；二维用于子矩阵和。

**差分**：前缀和的逆运算。`diff[i] = a[i]-a[i-1]`。对区间 `[l,r]` 整体 `+v`，只需 `diff[l]+=v; diff[r+1]-=v`，最后前缀和恢复——把「多次区间加」摊成 O(1) 每次操作，最后 O(n) 还原。

**面试高频**：区间和查询、航班预订统计、矩阵区域和、和为 k 的子数组、偶数长度子数组、矩形面积并（扫描线配合差分思想）。

---

## 一、一维前缀和

```
pre[0]=0; for i: pre[i+1]=pre[i]+a[i];
区间和 sum(l,r) = pre[r+1]-pre[l];  // O(1)
```
注意下标偏移（`pre[i+1]` 对应 `a[i]`），避免 off-by-one。

### 1.1 深挖：前缀和模板与「和 K 子数组」哈希法

```java
// 模板：pre[i] 表示前 i 个元素之和（pre[0]=0，多一位）
int[] pre = new int[n + 1];
for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + a[i];
int sum = pre[r + 1] - pre[l];               // [l, r] 闭区间

// 560 和为 K 的子数组：pre[j] - pre[i] = k ⇔ pre[i] = pre[j] - k
int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> cnt = new HashMap<>();
    cnt.put(0, 1);                            // pre=0 出现 1 次
    int pre = 0, ans = 0;
    for (int x : nums) {
        pre += x;
        ans += cnt.getOrDefault(pre - k, 0);  // 以当前位置结尾的合法区间数
        cnt.merge(pre, 1, Integer::sum);
    }
    return ans;
}
```

> **套路识别**：题目要「子数组/子串的和 = k」「区间和」「前缀相等」时，先想前缀和 + 哈希。负数也没问题（哈希值域不受限）。

## 二、一维差分

```
diff = a 的相邻差; // diff[0]=a[0], diff[i]=a[i]-a[i-1]
区间 [l,r] 加 v: diff[l]+=v; diff[r+1]-=v;
还原: a[i] = a[i-1] + diff[i];
```
适用：多次区间增减后求最终数组。

### 2.1 深挖：差分模板与航班预订（1109）

```java
// 模板：初始化 diff 全 0，多次区间操作，一次还原
int[] diff = new int[n + 1];                  // 多一位容纳 r+1
void add(int l, int r, int v) { diff[l] += v; diff[r + 1] -= v; }
int[] apply(int n) {
    int[] res = new int[n];
    int cur = 0;
    for (int i = 0; i < n; i++) { cur += diff[i]; res[i] = cur; }
    return res;
}

// 1109 航班预订统计：bookings = [first, last, seats]
int[] corpFlightBookings(int[][] bookings, int n) {
    int[] diff = new int[n + 2];
    for (int[] b : bookings) { diff[b[0]] += b[2]; diff[b[1] + 1] -= b[2]; }
    int[] ans = new int[n];
    for (int i = 0; i < n; i++) ans[i] = i == 0 ? diff[1] : ans[i - 1] + diff[i + 1];
    return ans;
}
```

> **差分 vs 暴力**：k 次区间加 → 暴力 O(k·n)；差分 O(k + n)。「大量区间加减 + 一次查询」场景闭眼用差分。

## 三、二维扩展

- **前缀和矩阵**：`pre[i][j] = pre[i-1][j]+pre[i][j-1]-pre[i-1][j-1]+a[i-1][j-1]`，子矩阵和用容斥 `pre[x2][y2]-pre[x1-1][y2]-pre[x2][y1-1]+pre[x1-1][y1-1]`。
- **二维差分**：单格加减扩散到右下矩形，常用于矩阵涂色/覆盖计数。

### 3.1 深挖：二维前缀和与二维差分模板

```java
// 二维前缀和（注意 pre 比 a 各多一位）
int[][] pre = new int[m + 1][n + 1];
for (int i = 1; i <= m; i++)
    for (int j = 1; j <= n; j++)
        pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + grid[i-1][j-1];
// 子矩阵 (r1,c1)-(r2,c2) 和（1-indexed）
int sum = pre[r2][c2] - pre[r1-1][c2] - pre[r2][c1-1] + pre[r1-1][c1-1];

// 二维差分：对子矩阵整体 +v（diff 比 a 各多 2 位防越界）
void add(int r1, int c1, int r2, int c2, int v, int[][] diff) {
    diff[r1][c1] += v;
    diff[r2+1][c1] -= v;
    diff[r1][c2+1] -= v;
    diff[r2+1][c2+1] += v;
}
// 还原：diff[i][j] += diff[i-1][j] + diff[i][j-1] - diff[i-1][j-1]
```

> 记忆：二维容斥「**加 1、减 2、加 1**」——四个角两个正两个负（对角线），写错了整个矩阵就错。

## 四、经典例题

- **和为 K 的子数组（560）**：哈希存前缀和出现次数，`count[pre[i]-k]` 累加（O(n)）。
- **航班预订统计（1109）**：典型差分，区间加座位，最后还原。
- **矩阵区域和（1314）**：二维前缀和。
- **前缀和 + 哈希找 0 和子数组**：pre 相等的两点之间和为 0。

### 4.1 深挖：扫描线与差分思想（进阶）

- **扫描线**：把「二维矩形覆盖」转成事件流——每条竖边是事件（左边界 +1、右边界 -1），纵坐标处差分；用「有序集合/线段树」维护当前覆盖的区间并求面积/周长。
- **本质**：扫描线就是「对 x 轴差分、对 y 轴区间管理」的组合。典型：**矩形面积并（218 天际线 / 850）**、会议室区间重叠。
- 面试价值：从「一维差分」自然引申到「事件差分」，是高频扩展题。

## 五、易错点

- 下标偏移：统一用 `pre[i+1]` 或 `pre[i]`，全程一致。
- 差分还原顺序是「从左到右累加」，别反。
- 二维容斥四个角符号别写错。
- `pre[r+1] - pre[l]` 中的 r+1 越界：pre 长度 = n+1。
- 哈希法求「和为 K」时 `cnt[pre-k]` 要在**更新 cnt 之前**查询（先查再存），否则重复计数。

## 面试高频问题（30+ 条）

1. **前缀和的作用？** 区间和从 O(n) 降到 O(1)，适合多次区间查询。
2. **前缀和怎么写？** `pre[i+1]=pre[i]+a[i]`；区间和 `pre[r+1]-pre[l]`。
3. **常见下标坑？** pre 比 a 多一位（pre[0]=0），注意偏移防 off-by-one。
4. **差分是什么？** 前缀和逆运算，记录相邻差；区间加只改两个端点。
5. **区间 [l,r] 加 v 用差分？** `diff[l]+=v; diff[r+1]-=v;` 再前缀和还原。
6. **为什么用差分？** 把多次区间加从 O(n) 每次降到 O(1)，最后 O(n) 还原。
7. **航班预订统计思路？** 纯差分：每段加座位数，最终前缀和恢复每日座位数。
8. **和为 K 的子数组？** 哈希记前缀和频次，`ans += cnt[pre-k]`（O(n)）。
9. **二维前缀和公式？** 容斥四块：加减交叉。
10. **二维差分用途？** 矩阵整体加减、覆盖计数、涂色。
11. **前缀和能求最长子数组吗？** 能（配哈希找目标差），如和为 k 的最长。
12. **前缀和 vs 线段树？** 前缀和静态/O(1)；线段树支持动态单点改+区间查。
13. **如何找 0 和子数组？** 前缀和相等的两端点之间和为 0。
14. **前缀积（防溢出）？** 类似前缀和，但遇 0 要分段处理。
15. **前缀和在实战？** 统计、滑动窗口加速、图片积分图（Haar）、算法题区间。
16. **差分还原顺序？** 从左到右累加 `a[i]=a[i-1]+diff[i]`。
17. **前缀和能处理负数吗？** 能，求和即可；哈希法对负数同样适用。
18. **区间最大值能用前缀和吗？** 不能（不满足可减性）；用线段树/稀疏表。
19. **扫描线与差分关系？** 扫描线对事件点差分（入+1出-1）求覆盖。
20. **如何用前缀和求中位数/第k？** 不直接；需配合计数/二分。
21. **前缀和空间？** O(n) 额外；可原地（pre 覆盖 a）省空间。
22. **子矩阵和为 k 的个数是多少？** 枚举上下界压成一维 + 哈希前缀和，O(n²) 或 O(n³) 视维度。
23. **前缀和为什么能 O(1) 求区间和？** 减法原理：`sum(l,r) = pre[r+1] - pre[l]`，可减性决定。
24. **「可减性」限制了什么？** 不可减的统计（max/min/gcd）不能用前缀和，需稀疏表/线段树。
25. **哈希+前缀和能处理「异或前缀」吗？** 能，`xor[r+1] ^ xor[l]` 同理（异或也是可逆运算）。
26. **「和为 K」若有负数还 O(n) 吗？** 是，哈希法不依赖非负性。
27. **扫描线求矩形面积思路？** 竖边事件 + 差分 + 区间高度维护，合并相邻段。
28. **天际线（218）思路？** 左右边界事件排序，维护最大高度（大顶堆/平衡树）。
29. **前缀和用于「均等划分/中位数」？** 划分数组使段和相等（前缀集合找另一半）。
30. **差分在「差分数列恢复原数组」外还有？** 区间最值的前缀最值、二次差分（区间等差数列）。
31. **二次差分能做什么？** 区间加等差/等比序列，最终两次前缀和恢复。
32. **前缀和 vs 树状数组 vs 线段树选型？** 只查不改用前缀和；单点改+区间查树状；区间改/查线段树。

## 八、逐题精讲（含 Go 实现 + 复杂度）

### 8.1 和为 K 的子数组（560，哈希版）

```go
func subarraySum(nums []int, k int) int {
    cnt := map[int]int{0: 1} // pre=0 出现 1 次（空前缀）
    pre, ans := 0, 0
    for _, x := range nums {
        pre += x
        ans += cnt[pre-k] // 先查再加，避免把"刚形成的同一起点"重复计入
        cnt[pre]++
    }
    return ans
}
// 时间 O(n)，空间 O(n)。负数也能处理——哈希值域不受限。
```

### 8.2 矩阵区域和（1314，二维前缀和）

```go
func matrixBlockSum(mat [][]int, k int) [][]int {
    m, n := len(mat), len(mat[0])
    pre := make([][]int, m+1)
    for i := range pre { pre[i] = make([]int, n+1) }
    for i := 1; i <= m; i++ {
        for j := 1; j <= n; j++ {
            pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + mat[i-1][j-1]
        }
    }
    ans := make([][]int, m)
    for i := range ans { ans[i] = make([]int, n) }
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            r1, c1 := max(0, i-k), max(0, j-k)
            r2, c2 := min(m-1, i+k), min(n-1, j+k)
            ans[i][j] = pre[r2+1][c2+1] - pre[r1][c2+1] - pre[r2+1][c1] + pre[r1][c1]
        }
    }
    return ans
}
// 时间 O(m*n)，空间 O(m*n)。子矩阵和用"加 2 减 1"容斥（左上、右下两正，交叉两负）。
```

### 8.3 异或前缀（可减的另一种运算）

```go
// 异或也满足"可逆"：xors[r+1] ^ xors[l] = 子数组异或；求"子数组异或=k"同样哈希
func subarrayXor(nums []int, k int) int {
    cnt := map[int]int{0: 1}
    xr, ans := 0, 0
    for _, v := range nums {
        xr ^= v
        ans += cnt[xr^k]
        cnt[xr]++
    }
    return ans
}
// 时间 O(n)，空间 O(n)。线性运算（和、异或）都可"前缀化 + 哈希"。
```

## 十、更多易错点（补充）

1. **前缀和偏移一致性**：全程 `pre[i+1] = pre[i] + a[i]`，区间和 `pre[r+1]-pre[l]`，`pre` 长度 `n+1`。
2. **哈希先查后加**：`ans += cnt[pre-k]` 必须在 `cnt[pre]++` 之前，否则把"以当前为终点、起点也是当前"的空段误计入。
3. **二维容斥符号**：`+pre[r2][c2] - pre[r1-1][c2] - pre[r2][c1-1] + pre[r1-1][c1-1]`，少一个符号整矩阵错。
4. **不可减统计**（max/min/gcd）：不能用前缀和，改用线段树、稀疏表、或"前缀最值数组"（仅对无修改有效）。
5. **溢出**：大数组前缀和用 `long`/`int64`，防 `pre[r+1]-pre[l]` 溢出。
6. **原地省空间**：若不需要保留原数组，可 `a[i] += a[i-1]` 原地变前缀和，省 O(n)。

## 十一、工程案例深挖

### 11.1 积分图（Integral Image）

OpenCV 人脸检测 Haar 特征需要在任意矩形区域快速求和：`II(x,y) = Σ_{x'≤x,y'≤y} i(x',y')`，即二维前缀和。一次计算后任意 Haar 特征（相邻矩形差）都是 O(1)，使实时检测成为可能。这正是 [六、工程应用] 里"积分图"的落地。

### 11.2 数据库预聚合 / 物化视图

OLAP 的 Cube（多维聚合）本质是把"按维度前缀求和"预先算好：查询时直接取对应聚合格，等价于多维前缀和。Prometheus 的 `range query` 区间求和、UV 漏斗分析也都依赖前缀聚合思想。

### 11.3 扫描线（差分思想的升维）

求矩形面积并（850）时，把每个矩形拆成「入边 +1 / 出边 -1」事件，按 x 排序后维护 y 轴的"当前覆盖长度"——这正是**对 x 轴差分、对 y 轴区间管理**。详见 [矩形](矩形.md) 与 [线段树与树状数组](线段树与树状数组.md)。

## 十二、速记口诀与小结

> **口诀**：区间求和前缀和，二维容斥加减叉；区间加减用差分，还原从左往右加；哈希前缀找 K 和，先查后存莫颠倒；异或前缀同此理，不可减者换线段。

- 面试三连：**是否可减（和/异或可，max 不可）→ 是否修改（不修改前缀和，修改 BIT/线段树）→ 偏移一致性**。
- 与 [位运算](位运算.md) 的 lowbit 是"动态前缀和"（树状数组）的引擎。

## 十四、手推示例：前缀和查区间和

以 `a = [2,4,1,5,3]`，查 `[1,3]`（0-indexed 闭区间）：

```
pre[0]=0
pre[1]=2
pre[2]=2+4=6
pre[3]=6+1=7
pre[4]=7+5=12
pre[5]=12+3=15
区间 [1,3] 和 = pre[4]-pre[1] = 12-2 = 10 = 4+1+5 ✅
```

> `pre[i+1]` 对应"前 i 个元素"，区间 `[l,r]` 用 `pre[r+1]-pre[l]`——偏移一致性是前缀和不出错的根。

### 14.1 差分手推（区间 +v 还原）

对 `a=[0,0,0,0,0]` 执行 `add(1,3,+5)`、`add(2,4,+2)`：

```
diff 初始全 0
add(1,3,+5): diff[1]+=5, diff[4]-=5 → diff=[0,5,0,0,-5,0]
add(2,4,+2): diff[2]+=2, diff[5]-=2 → diff=[0,5,2,0,-5,-2]
还原: a[0]=0
     a[1]=0+5=5
     a[2]=5+2=7
     a[3]=7+0=7
     a[4]=7-5=2   (注意 diff[4]=-5 在 i=4 时累加)
     a[5]=2-2=0
结果 a=[0,5,7,7,2,0]，即 [1..3] 段 +5、[2..4] 段 +2 的叠加 ✅
```

|------|------|
| "前缀和能求最长子数组吗？" | 能，配哈希找 `pre[j]-pre[i]==k` 的最长跨度（见 1.1） |
| "区间最大值能用前缀和吗？" | 不能（max 不可减），用线段树/稀疏表 |
| "为什么哈希要'先查后存'？" | 避免把"起点=终点"的空段重复计入（见 1.1） |
| "二维容斥为什么是加减交叉？" | 大矩形减去两个伸出部分、加回被多减的重叠角（含四个角） |
| "异或前缀和有什么用？" | 子数组异或=k 同样哈希（异或可逆，同和） |

> 一句话：**前缀和/差分是"把 O(n) 区间操作压成 O(1)/O(1·改)"的静态利器；不可减的统计请换线段树，要动态修改请换树状数组**。

## 十七、前缀和 / 差分 自测卡

| 自测题 | 用前缀和 / 差分 / 还是别的？ | 理由 |
|------|------|------|
| 多次区间求和查询（不改） | 前缀和 | O(1) 查 |
| 多次区间加、最后查一次 | 差分 | O(k+n) |
| 边加边查区间和 | 树状数组 | 动态 |
| 子数组和 = k | 前缀和 + 哈希 | 先查后存 |
| 子矩阵和 | 二维前缀和 | 容斥 |
| 区间最大值 | 线段树/稀疏表 | max 不可减 |
| 子数组异或 = k | 异或前缀 + 哈希 | 异或可减 |

**手写出题清单（闭卷自测）**：
1. 写出一维前缀和 `pre` 定义与区间和公式，说明偏移为什么用 `pre[i+1]`。
2. 写出差分的 `add` 与 `apply`（`diff[l]+=v; diff[r+1]-=v`），手推一遍（见 十四.1）。
3. 写二维容斥四角公式，指出"哪两个正、哪两个负"。
4. 解释"为什么哈希求 K 和必须先查后存"。

> 自测标准：**偏移一致性、二维容斥符号、哈希先查后存三件事零失误**。
