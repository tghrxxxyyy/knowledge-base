# 二分查找与排序高频题解

二分查找是 O(log n) 的区间收敛技巧，排序是算法基石。
二者在面试与工程中高频出现。本文讲解二分模板、边界处理、变体，以及常见排序算法的取舍。

## 一、二分查找基础

### 1.1 适用前提

- 数据有序（或具备单调性）。
- 能在 O(1) 内判断"目标在左还是右"。

### 1.2 标准模板（左闭右闭）

```text
left = 0, right = n - 1
while left <= right:
    mid = left + (right - left) / 2
    if nums[mid] == target: return mid
    elif nums[mid] < target: left = mid + 1
    else: right = mid - 1
return -1
```

要点：

- 用 `left + (right-left)/2` 防溢出。
- 循环条件 `left <= right` 对应闭区间。
- 收缩时 `mid ± 1` 排除已判断元素。

### 1.3 常见错误

- 死循环：边界收缩不对（如 `left=mid` 不 `+1`）导致不变。
- 整数溢出：直接用 `(left+right)/2` 在大数据时溢出。
- 边界遗漏：没处理空数组或单元素。

## 二、二分变体

### 2.1 查找第一个等于 target 的位置

- 找到后不立即返回，而继续向左收缩（`right = mid - 1`）。
- 最后校验 `left` 是否越界且值相等。

### 2.2 查找第一个大于等于 target 的位置（lower_bound）

- 满足 `nums[mid] >= target` 时记录候选并向左。
- 否则向右。

### 2.3 查找最后一个小于等于 target 的位置（upper_bound-1）

- 满足 `nums[mid] <= target` 时记录候选并向右。
- 否则向左。

### 2.4 在旋转有序数组中查找

- 数组被旋转，仍可用二分：判断哪一半有序。
- 若左半有序且 target 在左半范围 → 收缩左半；否则收缩右半。
- 同理处理右半有序。

### 2.5 搜索插入位置

- 即 lower_bound：返回第一个 ≥ target 的下标。
- 不存在则返回应插入处（即 left）。

## 三、排序基础

### 3.1 排序的评价维度

- 时间复杂度（最好/平均/最坏）。
- 空间复杂度（是否原地）。
- 稳定性（相等元素相对顺序是否保持）。

### 3.2 稳定性含义

- 稳定排序：相等元素前后顺序不变（如归并、插入、冒泡）。
- 不稳定：可能改变（如快排、堆排、选择）。
- 稳定性在"按多关键字排序"时重要。

## 四、常见排序算法

### 4.1 快速排序

- 选基准（pivot），分区使左小右大，递归。
- 平均 O(n log n)，最坏 O(n^2)（已有序且选端点）。
- 优化：随机化 pivot、三数取中、小数组用插入排序。
- 不稳定，原地。

### 4.2 归并排序

- 分治：拆到单元素，再两两有序合并。
- O(n log n) 稳定，需 O(n) 额外空间。
- 适合链表排序与外部排序。

### 4.3 堆排序

- 建大顶堆，反复取堆顶放末尾。
- O(n log n)，原地，不稳定。
- 不擅长部分有序优化。

### 4.4 插入排序

- 逐个将元素插入已排序部分。
- O(n^2)，小规模或近乎有序时高效且稳定。

### 4.5 计数/桶/基数排序

- 非比较排序，O(n + k) 量级。
- 依赖数据范围（计数）或位数（基数）。
- 适合整数、字符串等特定场景。

## 五、Top K 与排序

- 求前 K 小：可用快排 partition（期望 O(n)）或堆 O(n log K)。
- 求中位数：快排 selection 或双堆。

## 六、工程中的排序

- 多数语言内置排序为混合算法（如 TimSort、内省排序）。
- 自定义对象排序需提供比较器，注意比较器一致性（避免异常）。
- 大数据排序用外部排序（分块排序 + 归并）。

## 七、常见陷阱

- 二分边界写错导致死循环或漏解。
- 排序比较器返回不一致（a>b 与 b>a 矛盾）引发异常。
- 对不稳定排序误用稳定性假设。
- 在无序数据上直接二分。

## 八、速记

- 二分三要素：有序、mid 防溢出、边界收缩正确。
- 变体关键：找到后继续收缩或记录候选。
- 快排平均 O(n log n) 但不稳定；归并稳定需额外空间；堆排原地不稳定。
- 稳定性：相等元素顺序是否保持。
- Top K：partition 期望 O(n) 或堆 O(n log K)。
