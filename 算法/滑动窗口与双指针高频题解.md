滑动窗口（Sliding Window）与双指针（Two Pointers）是数组/字符串题目的两大核心套路，覆盖"连续子数组/子串、去重、有序数组、快慢指针"等大量高频题。本文讲清模板、变种与经典题解。

## 一、滑动窗口：解决"连续子区间"问题

### 1.1 适用特征

- 求"最长/最短"的**连续**子数组或子串（如最长无重复子串、最小覆盖子串）。
- 有"窗口内满足条件"的约束（和 ≥ K、含全部字符）。

### 1.2 模板（可变窗口）

```java
int left = 0, right = 0;
Map<Character, Integer> window = new HashMap<>();
int valid = 0;                       // 满足条件的计数
while (right < s.length()) {
    char c = s.charAt(right);
    window.put(c, window.getOrDefault(c,0)+1);  // 扩大窗口
    right++;
    while (窗口不满足条件需收缩) {           // 收缩左边界
        char d = s.charAt(left);
        window.put(d, window.get(d)-1);
        left++;
    }
    // 此时 [left, right) 是一个合法窗口，更新答案
}
```

### 1.3 定长窗口（更简）

窗口长度固定为 k：右移时左边界同步右移即可。

```java
for (int right = 0; right < n; right++) {
    add(nums[right]);
    if (right >= k-1) {
        updateAns();
        remove(nums[right-k+1]);     // 左边界移出
    }
}
```

## 二、经典题 1：最长无重复字符子串（LeetCode 3）

```java
int lengthOfLongestSubstring(String s) {
    int[] last = new int[128];        // 字符最后出现位置
    Arrays.fill(last, -1);
    int left = 0, max = 0;
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        left = Math.max(left, last[c] + 1);  // 遇到重复，左边界跳到上次之后
        last[c] = right;
        max = Math.max(max, right - left + 1);
    }
    return max;
}
```
- 思路：维护"窗口内无重复"，遇到重复字符把左边界跳到上次出现的下一位。
- 复杂度 O(n)，空间 O(字符集)。

## 三、经典题 2：最小覆盖子串（LeetCode 76）

- 目标：在 s 中找包含 t 全部字符的最短子串。
- 用哈希表统计 t 的字符需求 `need`，窗口内 `window` 统计，`valid` 记录已满足的字符种类数。
- 当 `valid == need.size()` 时收缩左边界求最短。

```java
String minWindow(String s, String t) {
    Map<Character,Integer> need=new HashMap(), win=new HashMap();
    for (char c: t.toCharArray()) need.put(c, need.getOrDefault(c,0)+1);
    int left=0, valid=0, start=0, len=Integer.MAX_VALUE;
    for (int right=0; right<s.length(); right++){
        char c=s.charAt(right);
        if (need.containsKey(c)){ win.put(c,win.getOrDefault(c,0)+1);
            if (win.get(c).equals(need.get(c))) valid++; }
        while (valid==need.size()){
            if (right-left+1<len){ len=right-left+1; start=left; }
            char d=s.charAt(left);
            if (need.containsKey(d)){ win.put(d,win.get(d)-1);
                if (win.get(d)<need.get(d)) valid--; }
            left++;
        }
    }
    return len==Integer.MAX_VALUE ? "" : s.substring(start,start+len);
}
```

## 四、双指针：变种与场景

| 变种 | 适用 | 例子 |
|------|------|------|
| 快慢指针 | 链表/数组去重、判环 | 删除有序数组重复项、环形链表 |
| 左右指针 | 有序数组 | 两数之和、盛水容器、反转 |
| 前后指针 | 从两端逼近 | 三数之和、二分边界 |
| 滑动窗口 | 连续子区间 | 见上 |

## 五、经典题 3：移除有序数组重复项（LeetCode 26）

```java
int removeDuplicates(int[] nums) {
    if (nums.length==0) return 0;
    int slow=1;                         // 慢指针指向下一个可写位置
    for (int fast=1; fast<nums.length; fast++){
        if (nums[fast]!=nums[slow-1])   // 与已写入的最后一个不同
            nums[slow++]=nums[fast];
    }
    return slow;                        // 新长度
}
```
- 快慢指针：fast 探路，slow 维护结果区间，O(n) 原地。

## 六、经典题 4：盛最多水的容器（LeetCode 11）

```java
int maxArea(int[] h) {
    int left=0, right=h.length-1, ans=0;
    while (left<right){
        ans=Math.max(ans, Math.min(h[left],h[right])*(right-left));
        if (h[left]<h[right]) left++; else right--;  // 矮的那边移动
    }
    return ans;
}
```
- 贪心：面积由短板决定，移动矮边才有可能增大，O(n)。

## 七、经典题 5：三数之和（LeetCode 15）

```java
List<List<Integer>> threeSum(int[] nums) {
    Arrays.sort(nums);
    List<List<Integer>> res=new ArrayList<>();
    for (int i=0;i<nums.length-2;i++){
        if (i>0 && nums[i]==nums[i-1]) continue;     // 去重
        int l=i+1, r=nums.length-1;
        while (l<r){
            int s=nums[i]+nums[l]+nums[r];
            if (s==0){ res.add(List.of(nums[i],nums[l],nums[r]));
                while(l<r && nums[l]==nums[l+1]) l++;   // 去重
                while(l<r && nums[r]==nums[r-1]) r--;
                l++; r--;
            } else if (s<0) l++; else r--;
        }
    }
    return res;
}
```
- 排序 + 双指针 + 去重，O(n²)。

## 八、滑动窗口常见坑

1. **窗口收缩条件写反** → 死循环或漏解（明确"何时该缩"）。
2. **计数 vs 种类混淆** → valid 用"种类数"而非总数。
3. **左边界更新用 last[c] 而非 last[c]+1 错** → 重复字符未排除。
4. **没去重** → 三数之和输出重复三元组。
5. **定长窗口忘了移除左元素** → 窗口实际变长。
6. **字符集范围** → 用 128 数组比 HashMap 快，但注意 Unicode。
