# 字符串与树高频题解

> 本文聚焦算法面试中另一大类：字符串处理与树结构。覆盖字符串匹配、动态规划在字符串的应用、回文、字典树，以及二叉树/二叉搜索树/堆/红黑树/线段树等树结构的操作与题解。重套路与代码骨架，思路优先。

## 1. 字符串基础

- 字符串本质是字符数组，下标操作 O(1)。
- 常用技巧：双指针、滑动窗口、哈希计数、前缀和/前缀函数。
- 注意边界：空串、单字符、重复字符、Unicode（Java 用 codePoint 更严谨）。

## 2. 双指针

- 用途：反转、回文判断、去重、两数之和（有序）。
- 左右指针向中间收敛。

### 2.1 反转字符串

```java
void reverse(char[] s) {
    int i = 0, j = s.length - 1;
    while (i < j) { char t = s[i]; s[i] = s[j]; s[j] = t; i++; j--; }
}
```

## 3. 滑动窗口

- 维护一个窗口 [left, right]，右扩左缩。
- 适用：最长无重复子串、最小覆盖子串、子串计数。

### 3.1 最长无重复子串

- 用 HashSet 或数组记录窗口内字符。
- 重复则左指针移动到重复字符之后。
- 每次更新最大长度。

```java
int left = 0, max = 0;
Set<Character> set = new HashSet<>();
for (int right = 0; right < s.length(); right++) {
    while (set.contains(s.charAt(right))) { set.remove(s.charAt(left++)); }
    set.add(s.charAt(right));
    max = Math.max(max, right - left + 1);
}
```

## 4. KMP 与前缀函数

- 暴力匹配最坏 O(n*m)。
- KMP 用 next 数组（前缀函数）避免主串指针回退，O(n+m)。
- 面试多数考思想，手写 next 数组易错，需练习。

### 4.1 next 数组含义

- next[i] = 模式串 [0,i] 中最长真前缀等于真后缀的长度。
- 失配时模式串右移 i - next[i]。

## 5. 字符串 DP

- 编辑距离：见 DP 章节。
- 最长回文子串：区间 DP 或中心扩展。
- 正则匹配：按 '*' 分类。

## 6. 回文

- 双指针从两端向中比较。
- 中心扩展：每个位置及间隙为心，向两侧扩。
- Manacher：线性求最长回文（面试少见，了解即可）。

## 7. 字典树（Trie）

- 多叉树，每节点代表一个字符，路径成词。
- 用途：前缀匹配、自动补全、词频统计。

```java
class TrieNode { TrieNode[] children = new TrieNode[26]; boolean isEnd; }
void insert(String w) {
    TrieNode cur = root;
    for (char c : w.toCharArray()) {
        int i = c - 'a';
        if (cur.children[i] == null) cur.children[i] = new TrieNode();
        cur = cur.children[i];
    }
    cur.isEnd = true;
}
```

## 8. 二叉树遍历

- 前序（根左右）、中序（左根右）、后序（左右根）。
- 递归简洁，迭代需栈模拟。
- 层序用队列（BFS）。

```java
void inorder(TreeNode n) {
    if (n == null) return;
    inorder(n.left);
    visit(n.val);
    inorder(n.right);
}
```

## 9. 二叉搜索树（BST）

- 左子树 < 根 < 右子树。
- 中序遍历得到升序序列。
- 查找/插入/删除 O(h)，h 为树高（平衡时 log n）。
- 删除：找前驱/后继替换。

## 10. 堆（优先队列）

- 完全二叉树，用数组存。
- 大顶堆：父 ≥ 子；小顶堆反之。
- 插入/删除 O(log n)。
- 用途：TopK、中位数、调度。

### 10.1 TopK

- 维护大小为 K 的小顶堆，遍历时压入并弹出最小，最终堆内即最大 K 个。
- 优于全排序 O(n log n) 可降为 O(n log K)。

## 11. 红黑树与 AVL（思路）

- 二者是自平衡 BST，保证 O(log n) 操作。
- AVL：严格平衡（左右高差 ≤1），查询快、插入慢。
- 红黑树：弱平衡（黑高平衡），插入删除旋转少，实际常用（如 TreeMap、HashMap 树化）。
- 面试常问区别，不要求手写插入。

## 12. 线段树

- 区间查询与单点/区间更新，O(log n)。
- 结构：每个节点代表一个区间，左右孩子各半。
- 用途：区间和、区间最值、区间赋值。

## 13. 树形 DP（补充）

- 见 DP 章节树形 DP。
- 经典：二叉树最大路径和、打家劫舍 III。
- 后序遍历，子结果合并父。

## 14. 最近公共祖先（LCA）

- BST：利用大小关系二分。
- 普通树：记录父指针 / 转链表相交 / 倍增。
- 递归：左右各找，命中则返回。

## 15. 序列化与反序列化

- 前序/层序 + 空标记（如 #）可唯一还原。
- 用途：存储、网络传输树。

## 16. 高频题清单

- 反转字符串 / 整数反转。
- 最长无重复子串（滑动窗口）。
- 最长回文子串。
- 编辑距离。
- 最长公共子序列（DP）。
- 二叉树各种遍历（递归 + 迭代）。
- 二叉树的层序、之字形、右视图。
- 验证 BST。
- TopK（堆）。
- LCA。
- 字典树实现与前缀统计。

## 17. 编码注意

- 字符串不可变（Java），用 StringBuilder 拼接。
- 下标越界是高频 bug，循环条件仔细。
- 递归注意终止条件与空指针。
- 树题多用递归（简洁），复杂用迭代（避免栈溢出）。

## 18. 复杂度要点

- 双指针/滑动窗口：O(n)。
- KMP：O(n+m)。
- 树遍历：O(n)。
- 堆 TopK：O(n log K)。
- 线段树：O(log n) 每操作。

## 19. 与现实系统

- 字符串匹配：编辑器查找、入侵检测。
- Trie：路由匹配、自动补全、敏感词过滤。
- 堆：任务调度、优先级队列。
- 线段树：区间统计监控。
- BST：索引结构基础。

## 20. 常见易错

1. **滑动窗口左移过度**：应移到重复字符之后而非仅 +1。
2. **回文中心漏间隙**：偶数长度回文中心在两字符间。
3. **BST 验证只比父**：需保证整棵子树边界。
4. **递归改全局变量忘重置**：回溯要恢复。
5. **StringBuilder 误用**：大量 + 拼接字符串 O(n^2)。
6. **空树/单节点未处理**：边界直接返回。

## 21. 刷题策略

- 先掌握双指针、滑动窗口、Trie、堆、遍历模板。
- 遇字符串题先想"双指针 or 滑动窗口 or DP"。
- 遇树题先想"递归遍历 or 层序 or 分治"。
- 背模板不如理解套路，变体即可迁移。

## 22. 小结

字符串与树是算法题的两大常客：字符串靠双指针、滑动窗口、KMP、DP；树靠遍历递归、BST 性质、堆、Trie、线段树。套路固定、模板可复用，掌握后能覆盖绝大多数变体。编码重边界（空、单节点、越界）与复杂度，避免 StringBuilder 误用与递归状态未恢复。
