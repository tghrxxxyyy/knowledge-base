# 堆与栈高频题解

堆（Heap）与栈（Stack）是两类高频数据结构：
栈是后进先出（LIFO），常用于递归、表达式、单调栈；
堆是基于完全二叉树的优先队列，常用于 TOP-K、中位数、调度。
本文讲解栈的单调技巧与堆的经典应用，并给出代码思路。

## 一、栈基础

### 1.1 栈的特性

- 只允许在一端（栈顶）插入和删除。
- 后进先出（LIFO）。
- 操作：push、pop、peek、isEmpty。

### 1.2 栈的应用

- 函数调用栈与递归。
- 括号匹配。
- 表达式求值（中缀转后缀、后缀计算）。
- 撤销/重做（Undo/Redo）。
- 深度优先搜索（DFS）的隐式栈。

### 1.3 括号匹配

思路：遇到左括号入栈，遇到右括号弹出栈顶判断是否匹配。
遍历结束栈应为空。

```text
for ch in s:
    if ch in "({[": push(ch)
    else:
        if stack empty: return false
        top = pop()
        if not match(top, ch): return false
return stack empty
```

### 1.4 单调栈

单调栈维护栈内元素单调递增或递减，用于解决"下一个更大/更小元素"。

- 下一个更大元素：维护单调递减栈，遇到更大元素时弹出并计算。
- 每日温度：找出升温需等待的天数。
- 柱状图最大矩形：以每个柱为高度，找左右第一个更矮的边界。
- 接雨水：利用单调递减栈计算凹陷面积。

核心：

```text
for x in arr:
    while stack not empty and x > stack.top():  # 更大元素场景
        pop and compute
    push(x)
```

## 二、堆基础

### 2.1 堆的性质

- 完全二叉树，用数组存储（下标从 0 开始）。
- 大顶堆：父节点 ≥ 子节点。
- 小顶堆：父节点 ≤ 子节点。
- 堆顶是最大或最小元素，取极值 O(1)。

### 2.2 基本操作

- 插入：放到末尾，向上调整（sift up）。
- 删除堆顶：末尾元素移到堆顶，向下调整（sift down）。
- 建堆：从最后一个非叶子节点向前调整，O(n)。

### 2.3 堆 vs 平衡树

- 堆只保证堆顶极值，不支持有序遍历。
- 堆的插入/删除极值 O(log n)，取极值 O(1)。
- 适合动态维护极值、TOP-K。

## 三、TOP-K 问题

### 3.1 前 K 大元素

思路一：全排序取前 K，O(n log n)。
思路二：用小顶堆维护大小为 K 的堆：
遍历元素，堆不满则入堆；否则若当前元素大于堆顶则替换堆顶。
最终堆内为前 K 大，O(n log K)。

```text
heap = empty min-heap
for x in arr:
    if heap.size < K: heap.push(x)
    elif x > heap.top(): heap.pop(); heap.push(x)
return heap
```

### 3.2 数据流中的第 K 大

用固定大小堆持续维护，新元素到来时按上述规则更新。
支持动态插入并随时查询第 K 大。

### 3.3 前 K 高频元素

- 用哈希表统计频率。
- 对频率用堆取前 K。
- 或桶排序按频率分桶。

## 四、中位数与滑动窗口

### 4.1 数据流中位数

维护两个堆：

- 大顶堆存较小一半。
- 小顶堆存较大一半。

两堆大小差不超过 1。
中位数：大小相等取两堆顶均值，否则取较多那侧堆顶。

### 4.2 滑动窗口最大值

- 单调队列法（双端队列）更优，O(n)。
- 堆法需延迟删除，较复杂。

### 4.3 堆合并（多路归并）

K 个有序链表/数组合并：
用小顶堆存各序列的当前最小元素，每次取堆顶并补入该序列下一个。

## 五、堆在调度中的应用

### 5.1 任务调度

- 按优先级调度：优先级队列（堆）取最高优先级任务。
- CPU 调度、定时器（最早到期任务在堆顶）。

### 5.2 哈夫曼编码

- 每次取频率最小的两个节点合并，用最小堆维护。
- 构建最优前缀码，使总编码长度最小。

### 5.3 Dijkstra 最短路

- 用优先队列（最小堆）取当前距离最小的节点。
- 相比朴素 O(n^2) 更优。

## 六、常见陷阱

- 堆只保证堆顶有序，不要假设整体有序。
- 比较函数方向错（大顶/小顶搞反）导致 TOP-K 结果相反。
- 大数据集用全排序而非堆，浪费性能。
- 单调栈忘记处理栈中剩余元素。

## 七、代码模板要点

- 单调栈：维护单调性，破坏处结算。
- TOP-K：固定大小堆，逆向选择（前 K 大用小顶堆）。
- 双堆中位数：大小平衡 + 堆顶组合。
- 多路归并：各路当前最小入堆。

## 八、速记

- 栈 LIFO：括号匹配、表达式、单调栈求下一个更大/更小。
- 堆：完全二叉树，堆顶极值 O(1)，插入删除 O(log n)。
- TOP-K：固定大小堆，前 K 大用小顶堆、前 K 小用大顶堆。
- 中位数：大顶堆（小半）+ 小顶堆（大半）平衡。
- 多路归并 / Dijkstra / 哈夫曼：优先队列天然契合。
