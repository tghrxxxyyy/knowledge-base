# 字符串（String）

## 〇、本体介绍

字符串处理是面试常客，核心是**模式匹配、编辑距离、回文、子串/子序列、字典树**。Java 字符串不可变（`String`），频繁拼接用 `StringBuilder`；比较内容用 `equals` 而非 `==`。

**面试高频**：KMP（高效匹配）、最长公共前缀、最长回文子串（中心扩展/Manacher）、编辑距离（DP）、最长重复子串、Trie（前缀树）、字符串转整数、括号匹配（栈）、单词拆分。

## 一、KMP 字符串匹配

- **核心**：利用**已匹配部分**的信息，失配时不回退文本指针，只移动模式串——靠 `next[]`（部分匹配表 / 最长公共前后缀）跳过已确定的对齐。
- **next 数组**：`next[i]` = 模式串 `P[0..i]` 的最长公共前后缀长度；匹配时 `j = next[j-1]` 回退。
- 时间 O(n+m)，优于暴力 O(nm)。工程上 `String.indexOf` 用更优的 BM/Sunday，但 KMP 是面试标准答案。

```java
// 构建 next
int[] next = new int[m];
for (int i=1,j=0;i<m;i++){
    while(j>0 && p[i]!=p[j]) j=next[j-1];
    if(p[i]==p[j]) j++;
    next[i]=j;
}
```

### 1.1 深挖：KMP 全流程模板与失配回退图解

```mermaid
graph LR
    T[文本: a b a b c a] --> M{比对到 j=4 失配}
    M -->|文本指针 i 不回退| N[模式串按 next 回退 j=next[3]=2]
    N --> O[从 j=2 继续比对, 利用已匹配的 "ab"]
```

```java
// 完整 KMP：返回文本中模式串首次出现的下标，找不到返回 -1
int kmp(String text, String pat) {
    int n = text.length(), m = pat.length();
    if (m == 0) return 0;
    int[] next = new int[m];
    for (int i = 1, j = 0; i < m; i++) {          // 构建 next（模式自己和自己匹配）
        while (j > 0 && pat.charAt(i) != pat.charAt(j)) j = next[j - 1];
        if (pat.charAt(i) == pat.charAt(j)) j++;
        next[i] = j;
    }
    for (int i = 0, j = 0; i < n; i++) {          // 匹配主流程
        while (j > 0 && text.charAt(i) != pat.charAt(j)) j = next[j - 1];
        if (text.charAt(i) == pat.charAt(j)) j++;
        if (j == m) return i - m + 1;             // 匹配成功
    }
    return -1;
}
```

> 要点：**文本指针 i 永不回退**是 KMP O(n+m) 的关键；`next` 记录「已匹配前缀的后缀中，最长能与模式前缀重合的长度」，失配直接跳。

## 二、回文

- **最长回文子串（5）**：中心扩展（奇偶中心，O(n²) 易写）或 Manacher（O(n) 难写）。
- **验证回文（125）**：双指针跳过非字母数字，忽略大小写。
- **回文子串计数（647）**：中心扩展逐个中心统计。

### 2.1 深挖：中心扩展模板（背熟）

```java
// 647/5：以每个位置为中心（奇数中心 1 个字符、偶数中心 2 个字符）向外扩展
int countPalindromes(String s) {
    int n = s.length(), ans = 0;
    for (int i = 0; i < n; i++) {
        ans += expand(s, i, i);       // 奇数中心
        ans += expand(s, i, i + 1);   // 偶数中心
    }
    return ans;
}
int expand(String s, int l, int r) {
    int cnt = 0;
    while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) {
        cnt++; l--; r++;
    }
    return cnt;
}
```

> Manacher 的 O(n) 关键在于 `p[i]` 复用回文半径 + 镜像对称 `p[mirror]`，面试能讲「回文半径数组 + 最右边界 R 与中心 C」即为满分，实现可不背。

## 三、编辑距离（72，DP）

`dp[i][j]` = `word1[0..i)` 变 `word2[0..j)` 最少操作（增/删/改）。
- 相等：`dp[i][j]=dp[i-1][j-1]`；否则 `1 + min(改, 删, 增)`。
- O(mn)，经典二维 DP 模板。

### 3.1 深挖：编辑距离 DP 表与滚动数组

```java
// 72 编辑距离（滚动数组版，空间 O(n)）
public int minDistance(String w1, String w2) {
    int m = w1.length(), n = w2.length();
    int[] dp = new int[n + 1];
    for (int j = 0; j <= n; j++) dp[j] = j;            // 首行：空串→j 个字符需 j 次插入
    for (int i = 1; i <= m; i++) {
        int prev = dp[0];                               // 保存 dp[i-1][j-1]
        dp[0] = i;                                      // 首列
        for (int j = 1; j <= n; j++) {
            int tmp = dp[j];
            if (w1.charAt(i - 1) == w2.charAt(j - 1))
                dp[j] = prev;                           // 相等 → 直接继承
            else
                dp[j] = 1 + Math.min(Math.min(dp[j], dp[j - 1]), prev); // 改/删/增
            prev = tmp;
        }
    }
    return dp[n];
}
```

> 变体：只求「是否 ≤ k」用**编辑距离 + 剪枝**（Levenshtein 距离在拼写纠错、模糊匹配的工程应用）；「最长公共子序列（LCS）」与编辑距离是同一张 DP 表（只用增/删）。

## 四、Trie（前缀树）

- 每个节点一个大小为字符集的指针数组/Map，沿途建/查。
- 应用：自动补全、词频统计、前缀匹配（如搜索引擎提示）、敏感词过滤。
- 时间 O(L)（L 为词长），与词典规模无关。

### 4.1 深挖：Trie 完整实现与「单词搜索 II」组合题

```java
class Trie {
    Trie[] next = new Trie[26];   // 或 Map<Character, Trie>
    boolean isEnd;
    void insert(String w) {
        Trie cur = this;
        for (char c : w.toCharArray()) {
            if (cur.next[c - 'a'] == null) cur.next[c - 'a'] = new Trie();
            cur = cur.next[c - 'a'];
        }
        cur.isEnd = true;
    }
    boolean search(String w) {
        Trie cur = find(w);
        return cur != null && cur.isEnd;
    }
    boolean startsWith(String p) {
        return find(p) != null;
    }
    Trie find(String s) {
        Trie cur = this;
        for (char c : s.toCharArray()) {
            cur = cur.next[c - 'a'];
            if (cur == null) return null;
        }
        return cur;
    }
}
```

- **Trie vs HashMap 前缀匹配**：HashMap 只能精确匹配，前缀查询要全遍历；Trie 天然按前缀组织。
- 组合题：**单词搜索 II（212）** = 棋盘 DFS + Trie 剪枝（边走边查前缀，不匹配早停）。
- 工程：搜索引擎补全、输入法词库、IP 路由表最长前缀匹配、敏感词 DFA 过滤（AC 自动机是 Trie + 失败指针的进阶）。

## 五、经典例题

- **最长公共前缀（14）**：横向比或纵向比。
- **字符串转整数（8）**：去空格、判符号、溢出（`ans > INT_MAX/10` 防溢出）。

- **最小覆盖子串（76）**：滑动窗口 + 计数。

### 5.1 深挖：最小覆盖子串（滑动窗口 + 计数）模板

```java
// 76 最小覆盖子串
public String minWindow(String s, String t) {
    int[] need = new int[128];
    for (char c : t.toCharArray()) need[c]++;
    int total = t.length();              // 还需匹配的字符数
    int l = 0, minLen = Integer.MAX_VALUE, start = 0;
    for (int r = 0; r < s.length(); r++) {
        char c = s.charAt(r);
        if (need[c] > 0) total--;        // 命中一个需求
        need[c]--;
        while (total == 0) {             // 窗口已覆盖 → 尝试收缩
            if (r - l + 1 < minLen) { minLen = r - l + 1; start = l; }
            char out = s.charAt(l);
            need[out]++;
            if (need[out] > 0) total++;  // 移除的字符是需求的 → 重新缺
            l++;
        }
    }
    return minLen == Integer.MAX_VALUE ? "" : s.substring(start, start + minLen);
}
```

> 滑动窗口套路三问：**右指针何时扩？**（每次移动都扩）；**何时收缩？**（满足条件时）；**窗口内怎么维护？**（计数数组/哈希）。

## 六、易错点

- `==` 比字符串是比引用，内容用 `equals`（Java）。
- 中心扩展回文别漏奇数/偶数两种中心。
- 编辑距离初始化首行首列（空串）。
- 字符串转整数：首尾空格、正负号、溢出判断（用 `long` 兜底或 `ans > (INT_MAX - digit)/10`）。
- KMP 的 next 构建与匹配循环边界别混（i 从 1 开始）。

## 面试高频问题（30+ 条）

1. **String 不可变意味着什么？** 内容不可改，拼接产生新对象；频繁拼接用 StringBuilder。
2. **`==` vs `equals`？** `==` 比引用，String 内容用 equals。
3. **KMP 为什么快？** 失配时用 next 跳过已匹配，文本指针不回退，O(n+m)。
4. **next 数组是什么？** 模式串各前缀的最长公共前后缀长度，用于失配回退。
5. **如何构建 next？** 双指针 i/j，失配 j=next[j-1]，匹配 j++，记录。
6. **为什么工程可能不用 KMP？** indexOf 多用 BM/Sunday（跳更远），但 KMP 面试常考。
7. **最长回文子串怎么求？** 中心扩展（奇偶，O(n²)）或 Manacher（O(n)）。
8. **验证回文？** 双指针跳过非字母数字、忽略大小写。
9. **编辑距离 DP 状态？** dp[i][j] 两前缀互转最少操作，增删改取最小+1。
10. **编辑距离复杂度？** O(mn) 时间与空间（空间可滚动压一维）。
11. **Trie 是什么？** 前缀树，每个节点指向字符子节点，O(L) 查/插。
12. **Trie 应用？** 自动补全、前缀匹配、词频、敏感词过滤。
13. **字符串转整数防溢出？** 边算边判 `ans > INT_MAX/10` 或末位超界。
14. **括号匹配为什么用栈？** 左括号压栈，右括号弹栈配对，最后空即合法。
15. **最长公共前缀？** 纵向逐个字符比，或横向两两比。
16. **最小覆盖子串？** 滑动窗口 + 目标字符计数，收缩到最小。
17. **单词拆分思路？** DP，dp[i] 前 i 字符能否由词典组成。
18. **子串 vs 子序列？** 子串连续、子序列可不连续（LCS 是 DP）。
19. **如何高效判两字符串异位词？** 计数数组/排序比较，或位掩码（仅小写）。
20. **Rabin-Karp 是什么？** 滚动哈希多模式匹配，用于重复子串/ plagiarism。
21. **字符串在实战？** URL 解析、正则、JSON 解析、压缩、编译器词法。
22. **回文子串计数？** 每个中心扩展统计，O(n²)；Manacher O(n)。
23. **Manacher 为什么 O(n)？** 复用回文半径数组 + 镜像对称，避免重复扩展。
24. **LCS 与编辑距离关系？** 同一 DP 表：只用插入/删除即 LCS；改权重可成不同相似度。
25. **AC 自动机是什么？** Trie + fail 指针，一次扫描同时匹配多个模式串。
26. **滑动窗口套路？** 右扩左缩 + 计数维护；先求可行再求最优。
27. **「最长无重复子串（3）」？** 滑动窗口 + 位置映射（或 set），O(n)。
28. **字符串哈希（滚动哈希）用途？** 快速判子串相等、重复子串（O(n) 预处理 O(1) 查询）。
29. **「字符串压缩/行程编码」？** 相邻重复压缩（aab→a2b），注意原长更短才返回。
30. **KMP 的 next 与「最长真前缀后缀」？** next[i] 不含全串（真前后缀），否则匹配自重叠。
31. **「字母异位词分组（49）」？** 排序作 key 或计数数组作 key。
32. **「单词搜索（79）」？** 棋盘 DFS + visited 回溯；与 Trie 组合可解 212（多词剪枝）。

## 九、字符串逐题精讲（含 Go 实现 + 复杂度）

### 9.1 KMP（Go 全量）

```go
func kmp(text, pat string) int {
    m := len(pat)
    if m == 0 { return 0 }
    next := make([]int, m)
    for i, j := 1, 0; i < m; i++ { // 构建 next
        for j > 0 && pat[i] != pat[j] { j = next[j-1] }
        if pat[i] == pat[j] { j++ }
        next[i] = j
    }
    for i, j := 0, 0; i < len(text); i++ { // 匹配
        for j > 0 && text[i] != pat[j] { j = next[j-1] }
        if text[i] == pat[j] { j++ }
        if j == m { return i - m + 1 }
    }
    return -1
}
// 时间 O(n+m)，空间 O(m)。文本指针不回退是关键。
```

### 9.2 最长回文子串（5，中心扩展）

```go
func longestPalindrome(s string) string {
    if len(s) < 2 { return s }
    start, maxLen := 0, 1
    for i := 0; i < len(s); i++ {
        // 奇数中心、偶数中心各扩
        l1, r1 := expand(s, i, i)
        l2, r2 := expand(s, i, i+1)
        if r1-l1+1 > maxLen { start, maxLen = l1, r1-l1+1 }
        if r2-l2+1 > maxLen { start, maxLen = l2, r2-l2+1 }
    }
    return s[start : start+maxLen]
}
func expand(s string, l, r int) (int, int) {
    for l >= 0 && r < len(s) && s[l] == s[r] { l--; r++ }
    return l + 1, r - 1
}
// 时间 O(n²)，空间 O(1)。Manacher 可 O(n)（见前文二）。
```

### 9.3 编辑距离（72，DP）

```go
func minDistance(w1, w2 string) int {
    m, n := len(w1), len(w2)
    dp := make([][]int, m+1)
    for i := range dp { dp[i] = make([]int, n+1) }
    for j := 0; j <= n; j++ { dp[0][j] = j }
    for i := 1; i <= m; i++ { dp[i][0] = i }
    for i := 1; i <= m; i++ {
        for j := 1; j <= n; j++ {
            if w1[i-1] == w2[j-1] { dp[i][j] = dp[i-1][j-1] } else {
                dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) // 改/删/增
            }
        }
    }
    return dp[m][n]
}
// 时间 O(mn)，空间 O(mn)（可滚动压 O(min(m,n))）。
```

### 9.4 最长公共前缀（14）/ Rabin-Karp（28 思路）

```go
func longestCommonPrefix(strs []string) string {
    if len(strs) == 0 { return "" }
    for i := 0; i < len(strs[0]); i++ {
        for j := 1; j < len(strs); j++ {
            if i >= len(strs[j]) || strs[j][i] != strs[0][i] { return strs[0][:i] }
        }
    }
    return strs[0]
}
// 纵向比：逐字符比所有串，O(S)（S=所有串总长）。

// Rabin-Karp：滚动哈希（取模避免溢出），可一次扫多模式；用于重复子串/ plagiarism。
// hash = (hash*base + c) % mod；子串 hash 平移：hash = (hash - s[l]*base^len) % mod。
```

## 十一、工程深挖：AC 自动机 & 滚动哈希

### 11.1 AC 自动机（多模式匹配）

Trie + fail 指针（类似 KMP 在 Trie 上的失配跳转）。一次扫描文本即可匹配所有模式串，复杂度 O(n + 总匹配数)。敏感词过滤 / 内容安全就是它——比"对每个词跑一遍 KMP"快得多（见 安全工程/常见 Web 安全漏洞与防护）。

### 11.2 滚动哈希（Rabin-Karp）

把子串映射成数：`hash(s[l..r]) = (hash(s[l..r-1])*base + s[r]) % mod`。比较子串相等 → 比 hash（O(1)）；配合双哈希防碰撞。用于：重复子串、字符串匹配、 plagiarism 检测。

## 十二、更多易错点（补充）

1. Java 比较内容用 `equals`，`==` 比引用（见前文六）。
2. 中心扩展别漏**奇数/偶数**两种中心（见 9.2）。
3. 编辑距离初始化首行首列（空串 → j 次插入 / i 次删除）。
4. 字符串转整数：`long` 兜底、`ans > (INT_MAX-digit)/10` 防溢出。
5. KMP 的 `next` 构建 `i` 从 1、匹配 `j=next[j-1]` 回退（见 9.1）。
6. Trie 插入/查询注意字符集范围（26 小写 or 全 ASCII）。
7. 最小覆盖子串**先查后加**（need 计数），收缩时移出的字符若是需求则重新缺（见五）。

- 面试三连：**匹配（KMP/AC）→ 相似度（编辑距离/LCS）→ 结构（Trie/滑动窗口）**。
- 与 [滑动窗口](滑动窗口.md)（子串约束）、[动态规划](动态规划.md)（编辑距离/LCS）同构。
