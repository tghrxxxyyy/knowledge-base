# 并查集（题解 / Union-Find）

## 〇、本体介绍

**并查集（Disjoint Set / Union-Find）**：维护「不相交集合」的数据结构，支持两种操作——`find(x)` 找 x 所属集合代表、`union(x,y)` 合并两集合。用于**动态连通性**问题：网络连通、朋友圈、连通分量、最小生成树、岛屿扩展。

**优化**：路径压缩（`find` 时把节点直接挂到根）+ 按秩/大小合并（小树挂大树），使近乎 O(1)（反阿克曼函数 α(n)）。

**面试高频**：岛屿数量（DFS/BFS 也行）、省份数量、冗余连接（判环）、最小生成树（Kruskal）、账户合并、方程满足性（带权并查集）。

---

## 一、标准实现

```java
int[] parent, rank;
void init(int n){ parent = new int[n]; rank = new int[n];
    for(int i=0;i<n;i++) parent[i]=i; }
int find(int x){ while(parent[x]!=x) { parent[x]=parent[parent[x]]; x=parent[x]; } return x; } // 路径压缩
void union(int x,int y){
    int rx=find(x), ry=find(y);
    if(rx==ry) return;
    if(rank[rx]<rank[ry]) parent[rx]=ry;
    else { parent[ry]=rx; if(rank[rx]==rank[ry]) rank[rx]++; } // 按秩合并
}
```

## 二、经典例题

- **省份数量（547）**：每个人初始独立，好友关系合并，最后不同根的数量即省份。
- **岛屿数量（200）**：也可并查集——遍历陆地边把相邻陆地合并，最后根计数（与 DFS 等价）。
- **冗余连接（684）**：给一棵树+一条边形成环，按输入顺序加边，遇到 `find(u)==find(v)` 即环边，返回。
- **账户合并（721）**：邮箱作为元素，同一人的账户邮件互相 union，收集各连通块。
- **等式方程可满足性（990）**：`==` 先合并，`!=` 后检查是否同集，同集则矛盾（带权可做不等式）。
- **Kruskal MST**：边按权排序，能合并（不形成环）就选入，直到选 V-1 条。

---

## 三、带权并查集（进阶）

维护「节点到根的相对权值」，支持**带权关系**推理（如「A 比 B 多 3」）。`find` 时累加路径上的权；`union` 时按关系推导新权。题目：种类并查集（食物链 240）、区间关系。

---

## 四、易错点

- `find` 必须路径压缩且返回根，别返回中间节点。
- 合并先判是否同根，避免自环计数。
- 二维坐标要映射到一维下标（`r*cols+c`）。

## 面试高频问题（20+ 条）

1. **并查集解决哪类问题？** 动态连通性：连通分量、合并集合、判环、最小生成树。
2. **两个核心优化？** 路径压缩（find 扁平化）、按秩/大小合并（小挂大），接近 O(1)。
3. **路径压缩原理？** find 时把沿途节点直接挂到根，降低树高。
4. **按秩合并原理？** 矮树挂到高树，避免退化成链。
5. **时间复杂度？** 带两优化约 O(α(n))，α 是反阿克曼，实际常数级。
6. **岛屿数量用并查集怎么做？** 相邻陆地 union，最后不同根计数（等价 DFS）。
7. **冗余连接怎么找环边？** 顺序加边，find(u)==find(v) 即形成环，返回该边。
8. **省份/朋友圈数量？** 关系合并后统计根节点个数。
9. **Kruskal 为什么用并查集？** 边排序后依次合并，避免成环即选入，至 V-1 条。
10. **账户合并思路？** 邮箱为元素，同人账户互相 union，收集连通块。
11. **等式方程可满足性？** `==` 先并，`!=` 再查同集矛盾。
12. **带权并查集是什么？** 维护节点到根的权值，支持带权关系推理（如食物链）。
13. **二维坐标怎么映射一维？** `idx = r*cols + c`，便于数组下标。
14. **并查集和 DFS 求连通怎么选？** 动态加边选并查集；静态图 DFS 更直观。
15. **初始化 parent[i]=i 含义？** 每个元素自成一个集合（自己是根）。
16. **为什么合并前要 find？** 比较根是否相同，相同则不操作（已连通），不同才挂。
17. **并查集能删元素吗？** 原生难删；可「延时删除」或重建，不常用。
18. **最小生成树并查集 vs Prim？** 并查集配 Kruskal（边视角）；Prim 用堆（点视角）。
19. **连通块计数除了并查集还有什么？** DFS/BFS 遍历计数、Flood Fill。
20. **并查集在实战？** 社交好友、网络分区、Kruskal、图像分割、分布式一致性快照。
21. **路径压缩后 rank 还准确吗？** rank 只是上界估计，不精确也无妨，仅用于合并决策。
22. **如何判断两个元素是否已连通？** `find(x)==find(y)`。
