# 区间与扫描线高频题解

> 区间类问题（合并区间、无重叠最多区间、区间覆盖、区间交集）与扫描线（求区间并集长度、会议室、天际线）是面试高频。核心套路是"排序 + 扫描"，把二维区间降维成一维事件处理。

## 1. 合并区间

```python
def merge(intervals):
    intervals.sort(key=lambda x: x[0])
    res = []
    for s, e in intervals:
        if res and s <= res[-1][1]:
            res[-1][1] = max(res[-1][1], e)
        else:
            res.append([s, e])
    return res
```
- **排序**按左端点；**贪心**合并重叠。
- 复杂度 O(n log n)。

## 2. 最多不重叠区间（区间调度）

```python
def eraseOverlapIntervals(intervals):
    intervals.sort(key=lambda x: x[1])   # 按右端点
    end = float('-inf'); cnt = 0
    for s, e in intervals:
        if s >= end:
            end = e; cnt += 1
    return len(intervals) - cnt
```
- **按右端点贪心**，选结束最早的，留给后面更多空间。

## 3. 扫描线：区间并集长度

```python
def cover_length(intervals):
    events = []
    for s, e in intervals:
        events.append((s, 1))    # 进入 +1
        events.append((e, -1))   # 离开 -1
    events.sort()
    cnt = 0; prev = None; total = 0
    for x, d in events:
        if prev is not None and cnt > 0:
            total += x - prev
        cnt += d; prev = x
    return total
```
- 把每个区间拆成"进入/离开"事件，扫描累加覆盖数。
- 覆盖数 >0 的区段计入长度。

## 4. 高频变体

| 题目 | 套路 |
| --- | --- |
| 会议室 II | 扫描线求最大并发 |
| 天际线 | 扫描线 + 高度堆 |
| 区间交集 | 双指针遍历 |
| 插入区间 | 分段合并 |

## 5. 常见坑

- 排序键选错（左 vs 右）导致贪心失败。
- 端点开闭（闭区间 vs 开区间）边界处理。
- 扫描线事件同坐标时顺序（离开先于进入，避免重复计）。

## 6. 面试要点

1. 区间合并的排序与合并条件。
2. 区间调度为什么按右端点贪心。
3. 扫描线如何把区间转事件。
4. 开闭区间边界如何处理。

## 7. 小结

区间问题 = "先排序、再贪心或扫描"。合并/调度靠排序+贪心，覆盖/并发靠扫描线事件。掌握这两个套路，区间大类基本通吃。
