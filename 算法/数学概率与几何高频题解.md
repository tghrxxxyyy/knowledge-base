## 1. 数论基础

```python
def gcd(a,b):
    while b: a,b=b,a%b
    return a
def lcm(a,b): return a*b//gcd(a,b)
```

- 素数判定：`for i in range(2, int(sqrt(n))+1)` 试除，或埃氏筛。
- 快速幂：`a^b % m`，二进制拆分，O(log b)。

```python
def powmod(a,b,m):
    res=1
    while b:
        if b&1: res=res*a%m
        a=a*a%m; b>>=1
    return res
```

## 3. 随机数

** reservoir sampling（水塘抽样）**：未知长度流中等概率取一个。

```python
import random
def reservoir(stream):
    chosen=None; n=0
    for x in stream:
        n+=1
        if random.randint(1,n)==1: chosen=x
    return chosen
```

- 每个元素留下概率 = 1/n 且后续不被替换，最终均匀。

## 5. 位运算数学题

- 统计 1 的个数：`n & (n-1)` 消去最低位。
- 只出现一次的数（其余两次）：异或。
- 幂 of two：`n>0 and n&(n-1)==0`。

## 6. 概率题

- 条件概率、贝叶斯。
- 期望计算（如掷骰子到 6 的期望步数 = 6）。
- 洗牌（Fisher-Yates）：从后往前随机交换。

```python
def shuffle(a):
    for i in range(len(a)-1,0,-1):
        j=random.randint(0,i); a[i],a[j]=a[j],a[i]
```
