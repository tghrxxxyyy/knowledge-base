# 并查集与图论进阶题解

> 并查集（Union-Find）与图论是面试高频。本文梳理并查集优化、典型应用，以及图的遍历、最短路径、拓扑排序、最小生成树高频题。

## 1. 并查集

```java
class UF {
    int[] parent, rank;
    UF(int n){ parent=new int[n]; rank=new int[n]; for(int i=0;i<n;i++)parent[i]=i; }
    int find(int x){ while(x!=parent[x]){ parent[x]=parent[parent[x]]; x=parent[x]; } return x; }
    void union(int a,int b){
        int ra=find(a), rb=find(b);
        if(ra==rb) return;
        if(rank[ra]<rank[rb]) parent[ra]=rb; else { parent[rb]=ra; if(rank[ra]==rank[rb])rank[ra]++; }
    }
}
```

- **路径压缩**：`parent[x]=parent[parent[x]]`，扁平化。
- **按秩合并**：小树挂大树，降低高度。
- 近 O(1) 单次操作（反阿克曼）。

## 2. 并查集应用

- 连通分量计数、岛屿数量（合并相邻陆地）。
- 朋友圈/账户合并（按邮箱合并）。
- 冗余连接（找成环边）。
- 最小生成树 Kruskal（按边权排序 + 并查集判环）。

## 3. 图的表示

- 邻接矩阵：O(V²)，适合稠密图。
- 邻接表：O(V+E)，适合稀疏图。

## 4. 遍历

- **DFS**：递归/栈，标记 visited，用于环检测、连通块。
- **BFS**：队列，最短路径（无权）、层序。

```python
def bfs(graph, s):
    q, seen = [s], {s}
    while q:
        u = q.pop(0)
        for v in graph[u]:
            if v not in seen: seen.add(v); q.append(v)
```

## 5. 最短路径

- **Dijkstra**：非负权，优先队列，O(E log V)。
- **Bellman-Ford**：可负权，检测负环，O(VE)。
- **Floyd**：多源，O(V³)。
- **A***：带启发式，用于网格寻路。

## 6. 拓扑排序

- 有向无环图（DAG）的线性序，依赖关系。
- Kahn 算法：入度 0 入队，逐步删边。
- 应用：课程表、编译依赖、任务调度。

```python
def topo(n, edges):
    ind = [0]*n; adj=[[] for _ in range(n)]
    for u,v in edges: adj[u].append(v); ind[v]+=1
    q=[i for i in range(n) if ind[i]==0]
    res=[]
    while q:
        u=q.pop(0); res.append(u)
        for v in adj[u]:
            ind[v]-=1
            if ind[v]==0: q.append(v)
    return res if len(res)==n else []
```

## 7. 最小生成树

- **Kruskal**：边排序 + 并查集（见上）。
- **Prim**：从点扩展，优先队列，O(E log V)。

## 9. 复杂度

- 并查集：近 O(1)。

- 拓扑：O(V+E)。
