# 字符串与正则高频题解

> 字符串是面试常客：反转、子串、回文、异位词、正则匹配。套路集中在双指针、滑动窗口、哈希计数、DP、KMP。正则相关题（通配符、正则表达匹配）则考察递归/DP 的状态建模能力。

## 1. 高频套路

| 题型 | 套路 |
| --- | --- |
| 反转/翻转 | 双指针原地 |
| 子串/子序列 | 滑动窗口、DP |
| 异位词/词频 | 哈希计数（定长窗口） |
| 回文 | 中心扩展、DP |
| 正则匹配 | 递归/DP |

## 2. 滑动窗口（无重复最长子串）

```python
def lengthOfLongestSubstring(s):
    seen={}; left=0; best=0
    for right,c in enumerate(s):
        if c in seen and seen[c] >= left:
            left = seen[c] + 1
        seen[c]=right
        best=max(best, right-left+1)
    return best
```

## 3. 异位词子串计数

```python
from collections import Counter
def countAnagrams(s, p):
    pc=Counter(p); need=len(p); res=0
    cc=Counter(); left=0
    for right,c in enumerate(s):
        cc[c]+=1
        if cc[c] <= pc.get(c,0): need-=1
        if right-left+1 > len(p):
            cc[s[left]]-=1; left+=1
        if need==0: res+=1
    return res
```

## 4. 正则/通配符匹配（DP）

```python
def isMatch(s, p):   # p 只含 * 和 ?
    m,n=len(s),len(p)
    dp=[[False]*(n+1) for _ in range(m+1)]
    dp[0][0]=True
    for j in range(1,n+1):
        if p[j-1]=='*': dp[0][j]=dp[0][j-1]
    for i in range(1,m+1):
        for j in range(1,n+1):
            if p[j-1]=='*':
                dp[i][j]=dp[i][j-1] or dp[i-1][j]
            elif p[j-1]=='?' or p[j-1]==s[i-1]:
                dp[i][j]=dp[i-1][j-1]
    return dp[m][n]
```

## 6. 小结

字符串题 = 双指针/滑动窗口 + 哈希计数 + DP。先判题型再选套路，正则类用状态 DP 建模，复杂匹配优先考虑 DP 而非暴力。
