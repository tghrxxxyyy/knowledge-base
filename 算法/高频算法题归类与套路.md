# 高频算法题归类与套路

> 板块：算法 　|　 返回：[README](README.md)

算法题的本质是"识别题型 → 套用套路 → 处理边界"。本文按数据结构与思想归类，给出每类的典型题、通用套路与复杂度要点，帮助面试与实战快速定位解法。

## 一、数组与双指针

### 1.1 典型题

- 两数之和（哈希 O(n)）、三数之和（排序+双指针）。
- 盛最多水的容器（左右指针收缩）。
- 滑动窗口最大子串（维护窗口 + 计数）。
- 有序数组去重、合并两个有序数组。

### 1.2 套路

- 无序找"和为 K"→ 哈希表存 `值→下标`，空间换时间。
- 有序 / 局部单调 → 双指针（左右夹逼）。
- 子数组 / 子串 → 滑动窗口（左右指针 + 状态变量）。

### 1.3 复杂度

- 哈希查 O(1)，整体常可达 O(n)。
- 滑动窗口均摊 O(n)。

## 二、链表

### 2.1 典型题

- 反转链表（迭代/递归）。
- 快慢指针判环（Floyd）、环入口。
- 合并有序链表、找相交节点、找倒数第 K 个。

### 2.2 套路

- **dummy 头节点**：处理头结点变化，返回 `dummy.next`。
- **快慢指针**：快走两步慢走一步，用于找中点/环。
- **递归**：反转等可优雅递归，但注意栈深。

## 三、树与图

### 3.1 二叉树的遍历

- 前/中/后序：递归（终止-本层-下钻）或迭代（栈）。
- 层序：BFS（队列）。

### 3.2 DFS / BFS

- DFS：递归/栈，适合路径、连通性。
- BFS：队列，适合最短路径（无权图）。

### 3.3 图

- 拓扑排序（Kahn / DFS）：判断 DAG、依赖顺序。
- 最短路：Dijkstra（非负权）、Floyd（多源）、A*。
- 并查集：连通分量、最小生成树（Kruskal）。

### 3.4 套路

- 递归三要素：终止条件、本层处理、下钻。
- 回溯：`路径 + 选择列表 + 结束条件 + 撤销选择`。
- 树的递归常返回"子树结果"给父节点聚合。

## 四、动态规划（DP）

### 4.1 典型题

- 背包（0/1、完全）、最长递增子序列（LIS）。
- 编辑距离、最长公共子序列（LCS）。
- 股票买卖、打家劫舍、不同路径（网格）。

### 4.2 套路：四步走

1. **状态定义**：`dp[i]` 或 `dp[i][j]` 表示什么。
2. **转移方程**：如何从子问题推导。
3. **初始化**：边界值（dp[0]、空串）。
4. **遍历顺序**：自底向上 or 记忆化自顶向下。

### 4.3 优化

- 滚动数组压缩空间（一维替代二维）。
- 背包一维需逆序遍历防覆盖。

### 4.4 复杂度

- 状态数 × 转移代价，常为 O(n²) / O(n·W)。

## 五、回溯

### 5.1 典型题

- 全排列、子集、组合总和。
- N 皇后、数独、单词搜索。

### 5.2 模板

```
backtrack(路径, 选择列表):
    if 满足结束条件: 记录结果
    for 每个选择 in 选择列表:
        做选择
        backtrack(新路径, 新选择列表)
        撤销选择
```

### 5.3 剪枝

- 提前判断无效分支（如和超过 target）减少搜索空间。

## 六、二分查找

### 6.1 适用

- 有序数组查找。
- 在"单调函数"上找边界（如第一个 ≥ x 的位置）。
- 答案有界的最值问题（二分答案）。

### 6.2 套路

- `while left < right` 配 `mid = (left+right)/2` 或防溢出写法。
- 收缩时 `left = mid+1` / `right = mid`，区分"找左边界还是右边界"。
- 易错点：死循环（边界更新与 mid 取法不匹配）。

## 七、堆与优先队列

- TopK：固定大小堆（前 K 大用小顶堆）。
- 中位数：大顶+小顶双堆。
- 合并 K 个有序链表：各头入堆。
- Dijkstra：最小堆取最近节点。

## 八、并查集

- 初始化父指针、find（路径压缩）、union（按秩合并）。
- 近乎 O(1) 的连通性查询。
- 岛屿数量、朋友圈、账户合并。

## 九、位运算

- 异或：`a^a=0`、`a^0=a`，用于"只出现一次的数字"。
- 幂次判断：`n & (n-1) == 0`（2 的幂）。
- 状态压缩：用整数位表示集合状态（DP/搜索）。
- 取最低位 1：`n & -n`。

## 十、刷题策略

1. 按类型刷，总结可复用模板（双指针、滑动窗口、回溯、DP）。
2. 先写暴力再优化，明确复杂度瓶颈。
3. 复盘错因：边界、溢出、空输入、复杂度误判。
4. 限时训练：面试重思路表达，而非只写出代码。

## 十一、复杂度速查

| 结构/算法 | 时间 | 说明 |
|-----------|------|------|
| 哈希查 | O(1) | 均摊 |
| 二分 | O(log n) | 有序 |
| 快排/归并 | O(n log n) | 比较排序下界 |
| BFS/DFS | O(V+E) | 图遍历 |
| Dijkstra | O(E log V) | 堆优化 |
| DP | O(状态数×转移) | 因题而异 |
