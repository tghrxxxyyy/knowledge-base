# IEEE754单精度与双精度结构详解

> 对应 Hennessy & Patterson《Computer Architecture》与 Bryant & O'Hallaron《CSAPP》。

## 一、背景与挑战
早期不同厂商用互不兼容的格式表示实数，导致程序移植与数值结果不一致。IEEE 754 标准统一了符号位、阶码与尾数的布局，使浮点结果在符合规则的实现间可复现。

## 二、核心原理
单精度（32 位）划分为 1 位符号 S、8 位偏置阶码 E、23 位尾数（小数）F。双精度（64 位）为 1 位 S、11 位 E、52 位 F。实际数值由编码解释：规格化数的值为 (-1)^S × 2^(E-bias) × (1.F)，其中隐含前导 1。

## 三、形式化与数学基础
单精度偏置 bias = 127，双精度 bias = 1023。规格化数：

    value = (-1)^S * (1 + \sum_{i=1}^{t} f_i 2^{-i}) * 2^{e - bias}

其中 t 为尾数位数（单精度 23，双精度 52），e 为无符号阶码字段值。

## 四、代码实现
```c
#include <stdint.h>
typedef union {
    float f;
    uint32_t u;
} f32;
void decode_f32(float x) {
    f32 v; v.f = x;
    uint32_t s = (v.u >> 31) & 0x1;
    uint32_t e = (v.u >> 23) & 0xFF;
    uint32_t m =  v.u & 0x7FFFFF;
    /* 隐含前导1: 实际尾数 = 1 + m/2^23 (规格化时) */
}
```

## 五、与其他技术对比
定点数表示范围小但无舍入误差且运算快，适合 DSP；浮点数动态范围大，适合科学计算。bf16 牺牲尾数保阶码，适配深度学习的大动态范围需求。

## 六、常见误区
误区一：认为浮点运算满足结合律 (a+b)+c = a+(b+c)，实际不满足。误区二：用 == 比较两个浮点数相等，应比较绝对或相对误差。误区三：认为所有十进制小数可精确表示，实际上 0.1 在二进制下是无限循环。

## 七、与开源书/权威来源对应
CSAPP 第 2 章「Floating Point」给出位级表示与舍入；Hansimov/csapp 仓库含可运行示例；Hennessy & Patterson 讨论浮点流水线与 FMA。

## 九、演进与趋势
从 x87 80 位扩展精度到 SIMD 的标量/打包浮点；bf16 与 tf32 因 AI 训练普及；可复现浮点（IEEE 754-2019 的准静态舍入）受到关注。

## 十、小结
IEEE 754 用符号、偏置阶码与隐含前导 1 的统一布局解决了可移植性问题，但程序员必须理解舍入误差与比较陷阱。
