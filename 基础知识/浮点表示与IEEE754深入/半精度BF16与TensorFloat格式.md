# 半精度BF16与TensorFloat格式

> 对应 ARMv8 手册与 Hennessy & Patterson《Computer Architecture》。

## 一、背景与挑战
深度学习训练与推理需要高吞吐矩阵乘，但 FP32 存储与带宽成本高。BF16 与 TF32 以不同取舍在精度与范围间平衡。

## 二、核心原理
BF16 为 1 位 S、8 位 E、7 位 F（与 FP32 阶码同宽，仅截断尾数），动态范围等同 FP32，适合梯度。TF32 为 1 位 S、8 位 E、10 位 F，用于 Tensor Core 内部累加前截断。

## 三、形式化与数学基础
BF16 范围由 8 位阶码保证 2^{±127} 量级，尾数仅 8 位（含隐含位）精度约 3 位十进制有效数字；FP16 为 5 位阶码易溢出。

## 四、代码实现
```c
#include <stdint.h>
uint16_t fp32_to_bf16(float x) {
    uint32_t u; __builtin_memcpy(&u, &x, 4);
    /* 截断低16位, 舍入可选 */
    return (uint16_t)(u >> 16);
}
```

## 五、与其他技术对比
FP16 精度高但范围窄易溢出；BF16 范围宽精度低；TF32 兼顾两者用于矩阵乘累加；INT8 则需量化。

## 六、常见误区
误以为 BF16 是 FP16 的别名；二者位布局完全不同，BF16 阶码更宽。

## 七、与开源书/权威来源对应
ARMv8 手册定义 BF16 指令；NVIDIA 文档描述 TF32 在 Tensor Core 的角色。

## 九、演进与趋势
混合精度训练以 FP32 主权重、BF16 激活/梯度成主流；硬件原生支持 BF16 矩阵单元普及。

## 十、小结
BF16 以 FP32 同宽阶码换取范围，是深度学习的实用低精度格式，理解其位布局有助于正确转换。
