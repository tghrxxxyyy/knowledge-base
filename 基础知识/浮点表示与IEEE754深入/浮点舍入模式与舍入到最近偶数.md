# 浮点舍入模式与舍入到最近偶数

> 对应 Bryant & O'Hallaron《CSAPP》与 IEEE 754-2008 标准。

## 一、背景与挑战
实数大多无法被有限位浮点数精确表示，必须选择一种确定的舍入策略。不同策略影响数值稳定性、统计偏差与可复现性。

## 二、核心原理
IEEE 754 定义四种舍入方向：向最近偶数（默认 round-to-nearest-even）、向零、向正无穷、向负无穷。向最近偶数在中间值时选择尾数为偶数的结果，避免系统偏差累积。

## 三、形式化与数学基础
设真实值 x，可表示格点间距为 ulp。向最近偶数：

    round(x) = argmin_{y \in F} |y - x|
    若 x 恰在两格点中点，则取尾数最低位为 0 者。

## 四、代码实现
```c
#include <fenv.h>
void set_round(void) {
    fesetround(FE_TONEAREST);   /* 默认: 向最近偶数 */
    /* FE_TOWARDZERO / FE_UPWARD / FE_DOWNWARD */
}
```

## 五、与其他技术对比
向零舍入等价于截断，简单但引入单向偏差；向最近偶数在大量统计计算中将偏差相互抵消，是科学计算首选。

## 六、常见误区
误以为「四舍五入」即标准做法；二进制下中间值取舍用「偶数尾数为准」，不是十进制习惯的「进一」。

## 九、演进与趋势
确定性舍入对可复现科学计算（如气候模型）愈发重要；IEEE 754-2019 引入准静态舍入域。

## 十、小结
舍入到最近偶数是浮点默认策略，核心是消除方向性偏差，理解它才能正确解释浮点误差来源。
