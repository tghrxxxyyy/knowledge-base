# 并发跳表设计

> 对应 youngyangyang04/leetcode-master。

## 一、背景与挑战
多线程下对有序结构读写，平衡树的旋转极难无锁化。跳表因「只改局部指针」成为并发有序容器的首选。

## 二、核心原理
查找无锁遍历；插入用 CAS 逐层挂接并配合「逻辑删除标记」避免读到半插入节点；删除先标记再物理解链，保证并发一致。

## 三、形式化与数学基础
无锁查找 $O(\log n)$；插入最坏需重试 $O(\text{冲突})$ 次 CAS。正确性依赖内存序（acquire/release）与标记节点可见性。

## 四、代码实现
```python
import threading
class ConcurrentSkipList:
    def __init__(self):
        self.head = Node(float("-inf"), 16)
        self.lock = threading.RLock()
    def insert(self, key):
        with self.lock:  # 简化：工程用细粒度/CAS
            update = [None] * len(self.head.forward)
            cur = self.head
            for i in range(len(self.head.forward) - 1, -1, -1):
                while cur.forward[i] and cur.forward[i].key < key:
                    cur = cur.forward[i]
                update[i] = cur

            node = Node(key, lvl)
            for i in range(lvl + 1):
                node.forward[i] = update[i].forward[i]
                update[i].forward[i] = node
```

## 五、与其他技术对比
相比给红黑树加全局锁（吞吐低），跳表可做无锁/分段锁；相比加锁哈希，跳表保留有序与范围查询。

## 六、常见误区
未处理「插入同时进行删除」导致读到悬空；CAS 未配正确内存序出现重排 bug。
