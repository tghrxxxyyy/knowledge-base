# 跳表的插入与删除

> 对应 TheAlgorithms/Python。

## 一、背景与挑战
插入/删除需同时维护各层的 forward 指针，并保证查找路径正确。与链表不同，要记录「每层待更新的前驱」。

## 二、核心原理
插入：自顶向下记录每层最后一个 `< key` 的节点 `update[]`，随机出层数后逐层挂接。删除：同样找到 `update[]`，逐层解链。

## 三、形式化与数学基础
每层更新是 $O(1)$，涉及层数期望 $O(\log n)$，故：
$T_{\rm insert}=T_{\rm delete}=O(\log n)$ 期望。

## 四、代码实现
```python
def insert(head, key):
    update = [None] * len(head.forward)
    cur = head
    for i in range(len(head.forward) - 1, -1, -1):
        while cur.forward[i] and cur.forward[i].key < key:
            cur = cur.forward[i]
        update[i] = cur
    lvl = random_level()
    if lvl >= len(head.forward):
        head.forward += [None] * (lvl + 1 - len(head.forward))
        update += [head] * (lvl + 1 - len(update))
    node = Node(key, lvl)
    for i in range(lvl + 1):
        node.forward[i] = update[i].forward[i]
        update[i].forward[i] = node
```

## 五、与其他技术对比
相比二叉平衡树的旋转，跳表插入只是改指针、无需重组；并发场景下更易做无锁。

## 六、常见误区
插入时层数超过当前最大层却未扩展 `head.forward` 与 `update`；删除后节点仍被高层引用导致悬空。

## 七、与开源书/权威来源对应
TheAlgorithms/Python 的 skip list 实现；Pugh 1990 详述插入删除。

## 八、面试题
写线程安全的跳表插入；删除时如何处理层高下降？

## 九、演进与趋势
无锁 CAS 跳表、持久化跳表是数据库与并发库的研究重点。

## 十、小结
跳表插入/删除只需维护各层 `update` 前驱并改指针，期望 $O(\log n)$，实现简于平衡树。
