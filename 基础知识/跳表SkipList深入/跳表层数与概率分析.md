# 跳表层数与概率分析

> 对应 Pugh 1990 年论文《Skip Lists》中的概率分析，以及 CLRS《Introduction to Algorithms》概率分析与随机关联章节。

## 一、背景与挑战

跳表的性能几乎完全由「层数怎么长出来」决定。如果每个结点的层数都很少，高层索引形同虚设，查找退化成链表扫描；如果层数分布失衡（比如某条路径上密密麻麻都是高层结点），局部查找又会变慢。与 AVL/红黑树靠旋转强制平衡不同，跳表把平衡性外包给随机数：插入时独立抛硬币决定结点高度。于是核心问题变成——**随机化真的能以高概率给出对数层高和对数查找吗？若能，概率 $p$ 取多少最合适？**

工程上还有一层挑战：纯随机意味着最坏情况理论上存在（比如全部结点恰好都是 0 层）。延迟敏感的数据库不能接受「偶尔 $O(n)$」。因此必须同时做两件事：给出期望/高概率分析以证明「几乎总是很快」，再用 `max_level` 之类的截断把最坏界钉死。

面试中，本主题是「随机化算法」的经典样板：几何分布、期望递推、尾界不等式都会被考到。说不清 $p = 1/2$ 为什么合适、说不清 $\log_{1/p} n$ 从哪来，就很难证明自己真懂跳表。

## 二、核心原理

跳表生成层数的标准规则是：新结点先放在第 0 层，然后反复抛一枚「成功概率为 $p$」的硬币；每次成功就再上一层，失败则停止。设结点高度为 $L$（最高层编号），则

$$P(L \ge l) = p^l, \quad P(L = l) = (1-p)\,p^l.$$

这正是成功概率为 $1-p$ 的几何分布。于是：

- 所有结点都在第 0 层；
- 约 $p n$ 个结点在第 1 层；
- 约 $p^2 n$ 个结点在第 2 层；
- 一般地，第 $l$ 层期望有 $p^l n$ 个结点。

第 $l$ 层的期望间距是 $1/p^l$。当 $p = 1/2$ 时层高每升一级、密度减半、间距加倍，非常像「跳步长的二分」。

**为什么这样查找就快？** 查找从最高层开始，每层向右走到不能再走，然后下降。可以证明：从结点 $x$ 出发到达目标的期望代价，与「$x$ 之前有多少个高度超过当前层的结点」有关。直观上，若你在第 $l$ 层，则左右最近的「也出现在第 $l$ 层」的结点期望距离约 $1/p^l$；一次查找在每层期望只试探常数次指针。层数期望 $O(\log_{1/p} n)$，故总代价 $O(\log n)$。

**为什么必须截断层数？** 几何分布无上界。$n$ 个结点的最大高度期望约 $\log_{1/p} n$，但偶尔会出现某个结点特别高。设 `max_level = L_max`，则 $P(L \ge L_{max}) = p^{L_{max}}$，取 $L_{max} = \lceil \log_{1/p} n \rceil + 1$ 时，单结点越界概率约 $p \cdot 1/n$，全体结点都合法的概率很高；即便越界也直接截断到 $L_{max}$，最坏层高有界，空间上界变为 $O(n/(1-p))$。

## 三、形式化与数学基础

**（1）期望层高。** 令 $H$ 为 $n$ 个结点中的最大高度。由 $P(L \ge l) = p^l$ 与独立性，

$$P(H < l) = (1 - p^l)^n.$$

取 $l^* = \log_{1/p} n$，则 $p^{l^*} = 1/n$，$P(H < l^*) = (1 - 1/n)^n \approx e^{-1} \approx 0.37$，即最大层高以常数概率超过 $\log_{1/p} n$ 一点。更精细地，

$$E[H] = \sum_{l \ge 1} P(H \ge l) \le \log_{1/p} n + O\!\left(\frac{1}{1-p}\right).$$

所以「期望最大层高 $\approx \log_{1/p} n$」是准确量级。

**（2）查找期望代价的递推。** 采用 Pugh 的记号：设 $C_k$ 为「从第 $k$ 层出发，沿期望路径找到目标还需向右移动的期望次数」（不计下降）。每向右一步，以概率 $p$ 遇到一个同样在高层的结点（问题规模相关，做尺度变换后），经典结论给出

$$E[\text{向右步数}] = O\!\left(\frac{1}{1-p}\right) \cdot O(\log_{1/p} n).$$

更具体的启发式推导：把查找倒过来看成从目标结点向左「升层」。目标结点高度为 $L$，则查找会在 $0..L$ 每层向左各走一段。第 $l$ 层上，在到达上一个同层结点之前，期望要跨越 $1/p$ 个「只在低层的结点」。因此

$$E[\text{cost}] = \sum_{l=0}^{H} O\!\left(\frac{1}{1-p}\right) = O\!\left(\frac{H}{1-p}\right) = O\!\left(\frac{\log_{1/p} n}{1-p}\right).$$

代入 $p = 1/2$：$\frac{1}{1-p} = 2$，$\log_{1/p} n = \log_2 n$，期望代价约 $2\log_2 n$ 次比较。

**（3）$p$ 的权衡。** 代价 $O\!\left(\frac{\log_{1/p} n}{1-p}\right)$ 与空间 $O\!\left(\frac{n}{1-p}\right)$ 都含 $\frac{1}{1-p}$：$p$ 越大层越多、越稀疏、查找每层走的步数越少但层数变多、指针越多。对固定的「比较次数」目标，$p = 1/2$ 在理论上接近最优区；Redis 的 zset 取 $p = 0.25$，用更多层换取每层更短的横向扫描（对缓存更友好），属于工程常数微调。

**（4）高概率界。** 用 Chernoff 型论证：第 $l$ 层结点数 $X_l \sim \mathrm{Bin}(n, p^l)$，$\mathbb{E}[X_l] = np^l$。当 $l = \log_{1/p} n + c$ 时 $\mathbb{E}[X_l] = p^c$，偏离很大时概率指数衰减。于是以高概率所有层的密度都在常数倍期望之内，查找代价以高概率 $O(\log n)$，而不仅仅是期望。

## 四、代码实现

下面代码模拟层高分布、验证 $E[H] \approx \log_{1/p} n$，并给出带 `max_level` 的随机层数生成器（可嵌入完整跳表）。

```python
import random
import math
from collections import Counter


def random_level(p=0.5, max_level=16):
    """返回结点高度 L, P(L >= l) = p^l，超过 max_level 则截断。"""
    level = 0
    while random.random() < p and level < max_level:
        level += 1
    return level


def sample_max_height(n, p=0.5, trials=200):
    """估计 n 个结点的最大层高期望。"""
    total = 0
    for _ in range(trials):
        total += max(random_level(p, max_level=64) for _ in range(n))
    return total / trials


def empirical_distribution(n, p=0.5, trials=2000):
    """统计单结点高度分布，验证几何分布。"""
    cnt = Counter(random_level(p, max_level=32) for _ in range(trials))
    return {l: cnt[l] / trials for l in sorted(cnt)}


if __name__ == "__main__":
    p = 0.5
    for n in (100, 1000, 10000):
        h = sample_max_height(n, p, trials=50)
        theory = math.log(n, 1 / p)
        print(f"n={n:5d}  E[H]≈{h:.2f}  log_{{1/p}} n≈{theory:.2f}")

    dist = empirical_distribution(1, p=0.5, trials=5000)
    print("高度分布:", {k: round(v, 3) for k, v in dist.items()})
    # 期望：P(L=0)≈0.5, P(L=1)≈0.25, P(L=2)≈0.125, ...
    assert abs(dist[0] - 0.5) < 0.05
    assert abs(dist[1] - 0.25) < 0.05
    print("geometric distribution ok")
```

要点：`random_level` 先保证至少 0 层，再以概率 $p$ 抬升；`max_level` 是硬截断。模拟会看到 $E[H]$ 随 $\log_2 n$ 增长；单结点高度分布接近 $(1-p)p^l$。

## 五、与其他技术对比

| 维度 | 随机跳表 | AVL/红黑树 | 确定性跳表 | B 树 |
|------|----------|------------|------------|------|
| 平衡方式 | 掷硬币 | 旋转/染色 | 层间比例约束 | 分裂合并 |
| 证明难度 | 概率期望/尾界 | 情形分类 | 组合不变量 | 均摊 |
| 最坏层高 | 随机，可截断 | $O(\log n)$ 确定 | $O(\log n)$ 确定 | $O(\log_B n)$ |
| 实现复杂度 | 极低 | 高 | 中 | 高 |
| 并发友好 | 高 | 低 | 中 | 中 |
| 适合场景 | 内存索引、并发容器 | 通用有序表 | 需确定性时 | 磁盘索引 |

与「直接建完全平衡多层索引」相比，随机化免去再平衡代码；与红黑树相比，跳表牺牲确定性换取简单与并发。若业务无法接受任何退化风险，应选平衡树或加截断的跳表。

## 六、常见误区

**误区一：把 $p$ 调得很大（例如 0.9）以为查找更快。** $p$ 大则层数爆炸、每层结点极少，横向扫描变短但纵向下降变长，总指针数 $\frac{n}{1-p}$ 涨到 $10n$，空间与缓存压力巨大。常数最优区在 $0.25 \sim 0.5$。

**误区二：忘记 `max_level`，或把 `max_level` 设成和实际 $n$ 无关的过小值。** 无截断时最坏层高无界；截断过紧（例如 $n=10^6$ 还设 4 层）会让上层索引失效，查找退化为在稀疏层里长距离移动。

**误区三：以为「期望 $O(\log n)$」等于「每次都是 $O(\log n)$」。** 期望界允许极小概率的慢查询。对 P99 延迟敏感，要看高概率界或改用确定性结构。

**误区四：以为各层结点数严格等于 $n/2^l$。** 那是期望。实际是二项分布随机变量，会有波动；跳表不依赖精确密度，只要密度「以高概率接近期望」即可。

**误区五：插入时用固定模式（如每隔 $k$ 个升一层）冒充随机。** 固定模式在有序插入下可能构造出坏形状；真正随机（好的 RNG）才能支撑概率分析。

## 七、与开源书/权威来源对应

1. **Pugh (1990), CACM.** 给出层数几何分布、期望分析与跳表 vs 平衡树的完整论证，是本主题第一来源。
2. **CLRS 第 5 章「概率分析与随机算法」** —— 几何分布、指示器随机变量、期望线性性质，可直接用于跳表证明。
3. **Motwani & Raghavan, Randomized Algorithms.** —— 随机化结构与尾界工具（Chernoff），用于高概率分析。
4. **Redis `zslCreate` / `zslRandomLevel`（`t_zset.c`）** —— 工业取 $p = 0.25$、`ZSKIPLIST_MAXLEVEL = 32` 的实证。

## 八、面试题

**Q1：请推导 $p = 1/2$ 时期望最大层高。**
A：单结点 $P(L \ge l) = 2^{-l}$，$n$ 结点最大层高 $H$ 满足 $P(H < l) = (1 - 2^{-l})^n$。取 $l = \log_2 n$ 时该概率约为 $e^{-1}$，故 $E[H] = \log_2 n + O(1)$。

**Q2：为什么 $p = 1/2$ 常用？$p = 0.25$ 呢？**
A：$p = 1/2$ 时空代价比约 2、层数 $\log_2 n$，理论与常数平衡好。$p = 0.25$ 层数更多（$\log_4 n$ 的基数变为 $\log_{4} n$，实际是 $\log_{1/0.25} n = \log_4 n$ 层量级但每层密度更低），横向跳转少，Redis 这样选是缓存与比较指令的工程权衡。

**Q3：如何从高概率角度说明查找不会退化？**
A：第 $l$ 层结点数是 $\mathrm{Bin}(n, p^l)$，用 Chernoff 界可得密度以高概率落在期望常数倍内，从而查找步数以高概率 $O(\log n)$；再用 `max_level` 消除残留的极端情形。

**Q4：`max_level` 如何根据容量规划？**
A：取 $\lceil \log_{1/p} N_{max} \rceil + 1$。例如 $p = 1/2$、预计 $N_{max} = 2^{20}$，取 21～22 层即可。

## 九、演进与趋势

**缓存行感知的跳表**：把相邻 forward 指针打包进 cache line，或用「节点内多路并排」降低指针跳变带来的缓存失效，这在现代 CPU 上比调 $p$ 更能提吞吐。**确定性跳表**（Munro, Papadakis, Sedgewick）用「层间 $1/f$ 比例」约束结构，提供最坏 $O(\log n)$，牺牲部分插入常数。**自适应 $p$**：根据读写比动态调整晋升概率（读多时更稀疏高层）。**持久化与 LSM**：跳表作为 memtable 时，层数分析还影响 flush 的有序度与空间放大。**并发跳表**中的层高独立性简化了无锁证明：各结点高度独立，CAS 冲突分析更干净。

## 十、小结

跳表层数服从几何分布，第 $l$ 层期望密度 $p^l$，期望最大层高 $\log_{1/p} n$，查找期望代价 $O\!\left(\frac{\log_{1/p} n}{1-p}\right) = O(\log n)$。$p = 1/2$ 是理论与工程的甜点；必须设置 `max_level` 截断以获得确定性空间与最坏层高。随机化把「平衡」从旋转代码里拿走，换成可严格分析的概率保证——这是跳表优雅的根源。
