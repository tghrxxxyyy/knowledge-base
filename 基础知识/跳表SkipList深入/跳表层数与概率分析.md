# 跳表层数与概率分析

> 对应 CLRS。

## 一、背景与挑战
跳表性能完全取决于层数分布。需要证明期望层数与查找长度均为 $O(\log n)$，并给出合理的层上限以避免最坏退化。

## 二、核心原理
插入时反复抛硬币（概率 $p$）决定节点层数，直到失败。节点至少在第 0 层，以概率 $p^l$ 出现在第 $l$ 层。

## 三、形式化与数学基础
节点层数 $L$ 服从几何分布 $P(L\ge l)=p^l$。最大层期望 $E[\max L]\approx \log_{1/p} n$。查找跨越的步数期望值：
$E[{\rm search}]=O(1/p)\cdot O(\log_{1/p} n)=O(\log n)$。

## 四、代码实现
```python
def random_level(p=0.5, max_level=16):
    level = 0
    while random.random() < p and level < max_level:
        level += 1
    return level
```

## 五、与其他技术对比
相比确定性平衡（AVL 旋转），概率法省去维护平衡；代价是最坏 $O(n)$（概率极低），故设 `max_level` 上限。

## 六、常见误区
把 $p$ 取得过大（如 0.9）导致层数爆炸、空间上升；或忘记 `max_level` 上限使极端情况下层数失控。

## 七、与开源书/权威来源对应
Pugh 1990 给出期望分析；CLRS 在概率分析章节讨论类似随机结构。

## 八、面试题
推导查找期望步数；为何 $p=1/2$ 是常用值？

## 九、演进与趋势
分层概率与缓存行对齐结合，优化现代 CPU 下的跳表性能。

## 十、小结
跳表用几何分布决定层数，期望查找 $O(\log n)$；设层上限可杜绝最坏退化。
