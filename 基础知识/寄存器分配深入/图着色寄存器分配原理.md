# 图着色寄存器分配原理

> 对应 Chaitin 1982（图形着色寄存器分配）；Appel 1989（通过图着色分配寄存器）。

## 一、背景与挑战
程序变量数远超物理寄存器，冲突（同时活跃）的变量不能共寄存器。如何把无限虚拟寄存器映射到有限物理寄存器且不冲突，是分配核心。

## 二、核心原理
构建干涉图：节点为变量，边连接同时活跃的变量对。图着色即用 $k$ 种颜色（寄存器）给节点上色使相邻异色。若可 $k$-着色则无溢出；否则选代价最小的节点溢出（spill）到栈。

## 三、形式化与数学基础
干涉图 $G=(V,E)$，着色函数 $c:V\to\{1..k\}$ 满足 $(u,v)\in E\Rightarrow c(u)\neq c(v)$。判定要求色数 $\chi(G)\le k$。溢出代价反比于使用频率：
$$cost(spill\ v) = \frac{uses(v)+defs(v)}{degree(v)}$$
优先溢出低成本节点。

## 四、代码实现
```c
// 简化：度小于 k 可安全着色
while (!nodes.empty()) {
    v = pick(degree < K);     // 可简化
    stack.push(v); remove(v);
}
// 逆序回涂
while (!stack.empty()) color(pop());
```

## 五、与其他技术对比
图着色最优但 NP 难，靠启发式；线性扫描更简单但质量略低；二者常组合（优先分配热变量）。

## 六、常见误区
1. 以为 k 着色总有解——需 spill。
2. 溢出选高代价节点导致大量 load/store。
3. 忽略预着色（ABI 固定寄存器）作为已染色约束。

## 七、与开源书/权威来源对应
Chaitin 1982 (PLDI) 奠基；Appel 1989 完善；Appel《Modern Compiler Implementation》ch11。

## 八、面试题
问：干涉图如何构建？为何图着色是 NP 难？spill 选谁？

## 九、演进与趋势
Briggs 1992 改进溢出模型；现代分配器结合 SSA 与优先级着色，质量逼近最优。

## 十、小结
图着色把寄存器分配化为图论着色，干涉边与 spill 代价共同决定映射质量。
