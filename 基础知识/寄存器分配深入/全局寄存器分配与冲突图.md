# 全局寄存器分配与冲突图

> 对应 Chaitin 1982（图形着色寄存器分配）；Appel 1989。

## 一、背景与挑战
局部分配只看基本块，错失跨块复用寄存器的机会。全局分配需跨越整个函数，处理控制流汇合点的活跃重叠。

## 二、核心原理
在整函数 CFG 上做活跃变量分析，得每个变量的全局存活区间。冲突图边由"任意程序点同时活跃"判定。与局部相比，全局可让不重叠存活的变量共享寄存器，大幅提升密度。

## 三、形式化与数学基础
全局冲突边：
$$E = \{ (u,v) \mid \exists p.\ u\in live(p) \land v\in live(p) \}$$
最大化寄存器复用等价于在可用 $k$ 色下最小化 spill，等价于近似图着色。

## 四、代码实现
```python
# 构建全局干涉图
for p in program_points:
    live = live_at(p)
    for u in live:
        for v in live:
            if u != v: add_edge(u, v)
```

## 五、与其他技术对比
全局分配密度高但分析开销大；局部（每块独立）快却浪费；通常在全局基础上对热块二次优化。

## 六、常见误区
1. 只在块内算冲突——漏掉跨块汇合点重叠。
2. 忽略调用边杀掉调用者保存寄存器，错误保留。
3. 预着色节点（参数寄存器）须作为固定色约束。

## 七、与开源书/权威来源对应

## 八、面试题

## 九、演进与趋势
SSA 形式使冲突图更稀疏，结合优先级着色在现代编译器中稳定产出高质量分配。

## 十、小结
全局分配以整函数冲突图刻画重叠，是密度与质量兼得的寄存器分配基础。
