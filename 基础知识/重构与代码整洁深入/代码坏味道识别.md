# 代码坏味道识别

> 对应 Martin Fowler《Refactoring》第 3 章「Bad Smells in Code」，及 CS-Notes（CyC2018）。

## 一、背景与挑战

坏味道（code smell）是「代码中可能指示更深层次问题的表面征象」——它本身不是 bug，却提示重构机会。识别坏味道是重构的第一步：看不到问题，就无从下手。挑战在于坏味道是**启发式**而非硬规则，同一现象在不同上下文意义不同（重复未必都该抽，短函数未必都好），需要结合意图判断，而非机械套用阈值。

## 二、核心原理

Fowler 归纳约 20 种坏味道，可归为五类：

- **膨胀（Bloaters）**：Long Method、Large Class、Long Parameter List、Primitive Obsession——结构随时间肿大的典型。
- **面向对象滥用**：Switch Statements、Temporary Field、Refused Bequest。
- **变更障碍（Change Preventers）**：Shotgun Surgery（改一处需改多处）、Divergent Change（一变化波及多类）。
- **冗余（Duplicated Code）**：最直观，同逻辑多处复制。
- **耦合（Couplers）**：Message Chains（过长的调用链）、Middle Man（过度委托）、Inappropriate Intimacy。

识别套路：读代码时问「改这里难吗？读这里懂吗？复制出现在几处？」——答案异常处即坏味道候选。

## 三、形式化与数学基础

可用量化指标辅助定位（但仅作信号，非判决）。常见：

- 方法行数 $L_m$：过长指示 Long Method。
- 圈复杂度 $CC = E - N + 2P$（$E$ 边数、$N$ 节点数、$P$ 谓词/连通分量），当 $CC>10$ 视为高风险。
- 重复率 $Dup = \frac{重复代码行}{总代码行}$，越高越可能存在 Duplicated Code。
- 参数个数 $k$：Long Parameter List 的硬信号。

这些指标给出「哪里可能臭」，但「该不该重构」仍取决于语义与变更频率（频繁变更处的坏味道危害更大）。

## 四、代码实现

```python
# Duplicated Code 坏味道：税率逻辑重复
def invoice_us(order):
    return order.qty * order.price * 1.0

def invoice_eu(order):
    return order.qty * order.price * 1.2   # 税率逻辑重复，易不一致

# 重构：提取统一计算，税率作为参数
def invoice(order, tax_rate):
    return order.qty * order.price * tax_rate

# 或用对象封装税率策略
class Region:
    def tax(self): ...
```

```python
# Long Method 信号：圈复杂度高，应拆子函数
def process(order):        # 过长、混合校验/计算/通知
    if not order.items: return False
    total = sum(i.price * i.qty for i in order.items)
    if total <= 0: return False
    notify(order.user)
    return True
```

## 五、与其他技术对比

- **静态分析工具（SonarQube 等）**：给数字、能扫全量，但无法判断意图与业务重要性。
- **人工坏味道识别**：懂意图，但覆盖有限、主观。
- **两者互补**：工具先筛，人再做语义裁决。
- **误当 bug 修**：坏味道是重构信号，不是错误，不应「修」成 hack。

## 六、常见误区

- **误区一：见到重复就抽方法**——忽略语义差异（巧合相似 vs 真重复）。
- **误区二：把坏味道当 bug 直接修**——应重构而非重写，且先有测试。
- **误区三：只看指标不看变更频率**——不常改处的坏味道可暂缓。
- **误区四：追求零坏味道**——过度重构同样增加复杂度，需权衡。

## 九、演进与趋势

IDE 实时高亮坏味道、AI 辅助识别重复与建议重构候选，使识别成本下降；坏味道检测正从「函数级」走向「跨服务 / 架构级」（如循环依赖、过多跨模块调用）。具体能力以工具最新版本为准。

## 十、小结

坏味道是可操作的重构信号，需结合意图与变更频率判断。用指标工具先筛、人工再做语义裁决，是把「闻到臭味」转化为「精准重构」的成熟路径。
