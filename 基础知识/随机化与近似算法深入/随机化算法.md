# 随机化算法

> 对应 Motwani & Raghavan《Randomized Algorithms》(1995) 与 CLRS Ch.5。

## 一、背景与挑战
引入随机性往往能以更简单实现获得更好期望复杂度，或逃脱最坏输入（如快速排序枢纽选择）。

## 二、核心原理
随机算法分两类：蒙特卡洛（可能出错，出错概率可控）与拉斯维加斯（必正确，运行时间随机）。

## 三、形式化 / 数学基础
随机快排期望比较数 $O(n\log n)$；随机化让对手无法构造最坏输入，期望性能对几乎所有输入成立。

## 四、代码实现
```python
import random
def quick_sort(a):
    if len(a) <= 1:
        return a
    pivot = random.choice(a)
    left = [x for x in a if x < pivot]
    mid = [x for x in a if x == pivot]
    right = [x for x in a if x > pivot]
    return quick_sort(left) + mid + quick_sort(right)
```

## 五、与其他技术对比
与确定性算法相比，随机化实现更简、抗最坏输入；代价是结果/时间不确定，需概率保证。

## 六、常见误区
随机源质量差导致可预测；忽略期望与最坏的区别；重复运行未独立。

## 七、与开源书 / 权威来源对应
- Motwani & Raghavan 1995
- CLRS《Introduction to Algorithms》Ch.5

## 八、面试题
「随机化的快排为什么期望 O(n log n)」；随机化选择第 k 大（BFPRT 对比）。

## 九、演进与趋势
随机哈希/跳过表；随机化在分布式与流算法中的核心作用。

## 十、小结
随机化以概率换简洁与鲁棒，理解期望分析与概率保证是使用的根本。
