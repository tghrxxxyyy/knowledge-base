# 蒙特卡洛方法

> 对应 Metropolis & Ulam 1949（Monte Carlo）与随机算法文献。

## 一、背景与挑战
用随机采样估计难以解析的量（积分、概率、优化），允许一定错误概率，误差随样本数下降。

## 二、核心原理
用大数定律：以随机样本均值估计期望。例如用随机点落于图形内的比例估计面积（π 的估计）。

## 三、形式化 / 数学基础
误差约 $O(1/\sqrt N)$（中心极限定理）。估计 $\pi$：单位圆内点数 / 总点数 × 4 ≈ π。
置信区间 $\hat p \pm z_{\alpha/2}\sqrt{\hat p(1-\hat p)/N}$。

## 四、代码实现
```python
import random, math
def estimate_pi(N):
    inside = 0
    for _ in range(N):
        x, y = random.random(), random.random()
        if x*x + y*y <= 1:
            inside += 1
    return 4.0 * inside / N
```

## 五、与其他技术对比
与拉斯维加斯算法相比，蒙特卡洛可能给出近似/错误答案但运行时间确定；与解析法相比，适合高维。

## 六、常见误区
混淆误差与偏差；样本独立性被破坏；误把蒙特卡洛当作必对算法。

## 七、与开源书 / 权威来源对应
- Metropolis & Ulam 1949
- Motwani & Raghavan《Randomized Algorithms》

## 八、面试题
「用随机算法估计 π」；蒙特卡洛 vs 拉斯维加斯区别。

## 九、演进与趋势
马尔可夫链蒙特卡洛（MCMC）；重要性采样降方差。

## 十、小结
蒙特卡洛以随机采样估计量，误差随样本数平方根下降，是高维积分与模拟的利器，但允许错误。
