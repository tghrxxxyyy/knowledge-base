# 蒙特卡洛方法

> 对应 Metropolis & Ulam 1949 "The Monte Carlo Method"（JASA）/ Metropolis et al. 1953（MCMC）/ Motwani & Raghavan《Randomized Algorithms》/ CLRS 第 5 章。

## 一、背景与挑战

很多量在解析上难以计算：高维积分、复杂几何体的体积、金融衍生品的期望收益、统计物理中的配分函数。传统数值方法（梯形法、辛普森法）在 $d$ 维空间需要 $N \sim \varepsilon^{-d/2}$ 量级的网格点，维度稍高就遭遇**维数灾难**。

蒙特卡洛换一个思路：不构造网格，而是**随机采样**。它把确定性的积分问题转化为统计估计问题，误差以 $O(N^{-1/2})$ 收敛——与维度 $d$ **无关**。代价是收敛慢（提高 10 倍精度需 100 倍样本）且结果带随机误差。现代语境下「蒙特卡洛」有两层含义：算法族分类中时间确定但结果可能出错的**蒙特卡洛算法**，以及用采样估计期望的**统计方法**；两者共享同一数学基础。

## 二、核心原理

基本思想是「用样本均值估计总体期望」。设待求量为 $I = \int_\Omega f(x)\,dx = \mathbb{E}[f(X)]$，$X$ 在 $\Omega$ 上均匀分布，则用 $N$ 个独立样本的均值 $\hat{I}_N = \frac{1}{N}\sum_i f(X_i)$ 估计 $I$。要把它用好，需要掌握四类技术：

1. **重要性采样**：从与被积函数形状相近的分布 $q$ 采样，用权重 $f/q$ 修正，可大幅降低方差。
2. **分层与对偶采样**：把采样域分区，或配对使用负相关样本，抵消部分随机波动。
3. **控制变量**：减去一个已知期望的相关量再补回其期望，抵消共同波动。
4. **MCMC 与拟蒙特卡洛**：前者在无法直接采样时构造以目标分布为平稳分布的马尔可夫链（Metropolis–Hastings、Gibbs）；后者用低差异序列（Sobol、Halton）替代伪随机数，在低维光滑问题上可把误差率提升到接近 $O(N^{-1})$。

## 三、形式化与数学基础

设 $f(X)$ 方差为 $\sigma^2 < \infty$、样本独立同分布，则估计量无偏且 $\mathbb{E}[\hat{I}_N] = I$、$\operatorname{Var}(\hat{I}_N) = \sigma^2/N$。于是标准误差为 $\sigma/\sqrt{N}$，误差以 $O(N^{-1/2})$ 收敛；由中心极限定理可得置信水平 $1-\alpha$ 的区间

$$
\hat{I}_N \pm z_{\alpha/2}\,\frac{\hat{\sigma}}{\sqrt{N}}
$$

若要求绝对误差 $\le \varepsilon$，则需 $N \gtrsim (z_{\alpha/2}\sigma/\varepsilon)^2$，即样本数随精度要求**平方增长**。对比梯形法在 $d$ 维光滑函数上的 $O(N^{-2/d})$：当 $d \ge 5$ 时蒙特卡洛反而更优，这就是它统治高维问题的原因。

方差缩减的本质是把 $\sigma^2$ 换成更小的 $\sigma'^2$。以重要性采样为例，估计量变为

$$
\hat{I}_N^{IS} = \frac{1}{N}\sum_{i=1}^N \frac{f(X_i)}{q(X_i)}, \quad X_i \sim q
$$

其方差为 $\int (f^2/q)\,dx - I^2$，当 $q \propto |f|$ 时最小。注意若 $q$ 的尾部比 $f$ 更轻，方差会变为无穷——这是重要性采样最常见的失败模式。

## 四、代码实现

```python
# 估计 pi，并用重要性采样估计正态分布的尾部概率
import random, math

def estimate_pi(n):
    inside = 0
    for _ in range(n):
        x, y = random.random(), random.random()
        if x * x + y * y <= 1.0:      # 落在单位圆内
            inside += 1
    return 4.0 * inside / n           # 正方形面积 1，圆面积 pi/4

def tail_direct(n):
    # 估计 P(Z > 4)，Z ~ N(0,1)：真实值约 3.17e-5，直接采样几乎全落空
    hit = 0
    for _ in range(n):
        if random.gauss(0.0, 1.0) > 4.0:
            hit += 1
    return hit / n

def tail_importance(n, mu=4.0, sigma=1.0):
    # 以均值为 4 的正态为提议分布 q，命中率大幅提升，再按 p/q 加权修正
    total = 0.0
    for _ in range(n):
        x = random.gauss(mu, sigma)
        p = math.exp(-0.5 * x * x) / math.sqrt(2 * math.pi)
        q = math.exp(-0.5 * ((x - mu) / sigma) ** 2) / (sigma * math.sqrt(2 * math.pi))
        total += (p / q) if x > 4.0 else 0.0
    return total / n

if __name__ == "__main__":
    print("pi      =", estimate_pi(200000))
    print("tail dir=", tail_direct(200000))
    print("tail imp=", tail_importance(200000))
```

`tail_direct` 在 20 万样本下几乎必然输出 0，而 `tail_importance` 能在同等样本量下给出有意义的估计——这正体现方差缩减的价值。工程实践中还应对估计量计算样本标准差并给出置信区间。

## 五、与其他技术对比

| 方法 | 误差率 | 对维度的依赖 | 是否随机 | 适用场景 |
| --- | --- | --- | --- | --- |
| 梯形/辛普森法 | $O(N^{-2/d})$ | 强（维数灾难） | 否 | 低维光滑函数 |
| 蒙特卡洛（MC） | $O(N^{-1/2})$ | 无 | 是 | 高维积分、期望估计 |
| 拟蒙特卡洛（QMC） | 近 $O(N^{-1})$ | 弱（低维更优） | 准随机 | 低中维、光滑被积函数 |
| MCMC | 受混合时间影响 | 无 | 是 | 无法直接采样的后验分布 |
| 重要性采样 | 依赖提议分布质量 | 无 | 是 | 稀有事件、尾部概率 |
| 拉斯维加斯算法 | 时间随机、结果必对 | 不适用 | 是 | 组合搜索、精确验证 |

## 六、常见误区

- 「混淆误差与偏差」：无偏估计的误差由方差决定，可量化；有偏估计（如权重归一化引入的偏差）须单独处理。
- 「样本越多越准」：提议分布尾部过轻时方差无穷，增加样本也无法收敛。
- 「伪随机数够用」：低质量生成器的相关性破坏独立性假设，使 $O(N^{-1/2})$ 的误差率失效。
- 「把蒙特卡洛当必对算法」：它给出统计估计，必须报告误差范围而非只报点估计。
- 「MCMC 样本独立」：样本高度自相关，有效样本量远小于总样本数，需做自相关分析或稀疏化。

## 八、面试题

1. **用随机算法估计 $\pi$ 并说明误差来源？** 要点：正方形内均匀撒点，圆内比例乘 4；误差 $O(N^{-1/2})$，来自二项分布方差 $p(1-p)/N$。
2. **蒙特卡洛与拉斯维加斯的区别？** 要点：MC 时间确定、结果可能错；LV 结果必正确、时间随机。二者可组合为「随机构造 + 确定性验证」。
3. **为什么蒙特卡洛在高维上有优势？** 要点：误差率与维度无关（$O(N^{-1/2})$），而网格法为 $O(N^{-2/d})$，$d$ 高时迅速退化。
4. **重要性采样何时失效？** 要点：提议分布尾部比被积函数更轻时权重的二阶矩发散、方差无穷；应选重尾提议分布并检查权重分布。
5. **如何给出结果可信度？** 要点：报告样本标准差与置信区间 $\hat{I} \pm z_{\alpha/2}\hat{\sigma}/\sqrt{N}$；MCMC 需用有效样本量修正。

## 九、演进与趋势

技术演进集中在三个方向：**方差缩减**（重要性采样、控制变量、分层、对偶，以及深度学习的重参数化技巧）、**采样器与混合速度**（HMC/NUTS 在贝叶斯推断中取代朴素 Metropolis）、**计算加速**（GPU 上并行化数百万条独立路径，成为期权定价与粒子输运的标配）。随机化拟蒙特卡洛（RQMC）把低差异序列随机化以获得误差估计，在金融与图形学中被广泛采用。机器学习中的变分推断混合与扩散模型采样，也可归入这一框架。

## 十、小结

蒙特卡洛以随机采样估计难以解析的量，误差以 $O(N^{-1/2})$ 收敛且与维度无关。用好它的关键不在采样次数，而在**方差缩减与误差量化**：选对提议分布、报告置信区间、警惕权重发散，才能把「随机」变成可靠的工程手段。
