# 近似比

> 对应 Vazirani《Approximation Algorithms》与 CLRS Ch.35（近似算法）。

## 一、背景与挑战
NP 难问题难求最优，退而求近似解。近似比衡量近似解与最优解的质量差距。

## 二、核心原理
对最小化问题，近似比 $\rho \ge 1$ 满足 $ALG \le \rho \cdot OPT$；对最大化 $\rho \le 1$ 满足 $ALG \ge \rho\cdot OPT$。

## 三、形式化 / 数学基础
顶点覆盖 2-近似：每条边任选一端，得到的解 ≤ 2·OPT。
集合覆盖贪心近似比 $H(n)=O(\log n)$。
TS  tour 用 MST 近似比 2。

## 四、代码实现
```python
def vertex_cover_2approx(edges, n):
    covered = set()
    cover = set()
    for u, v in edges:
        if u in cover or v in cover:
            continue
        cover.add(u)
        cover.add(v)
    return cover
```

## 五、与其他技术对比
与精确 ILP 相比，近似算法快且保证界；与启发式（无界）相比，近似比给出理论保证。

## 六、常见误区
把启发式误称近似算法（无界）；近似比定义对最小/最大方向混淆；贪心证明错。

## 八、面试题
「顶点覆盖 2-近似」证明；「旅行商在三角不等式下 2-近似」。

## 九、演进与趋势
PTAS/FPTAS（如背包 FPTAS）；不能近似的硬问题（除非 P=NP）。

## 十、小结
近似比提供「解多差」的理论界，是把 NP 难问题工程化求解的核心工具。
