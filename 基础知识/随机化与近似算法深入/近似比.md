# 近似比

> 对应 Vazirani《Approximation Algorithms》/ CLRS 第 35 章（近似算法）/ Christofides 1976（度量 TSP 的 3/2 近似）/ Feige 1998（集合覆盖不可近似性）。

## 一、背景与挑战

大量组合优化问题是 NP 难的：顶点覆盖、集合覆盖、旅行商、装箱、最大割。除非 P = NP，否则不存在多项式时间的精确算法。工程上不能因此停工，于是折中为**近似算法**：在多项式时间内给出一个解，并**证明它与最优解的质量差距有上界**。

关键在于「有上界」这一条。启发式（heuristic）也能快速给出解，但没有任何质量保证——可能离最优任意远。近似比（approximation ratio）就是把这种保证形式化的工具：它把「这个解最多比最优差多少倍」变成一个可证明、可比较、可写进 SLA 的数字。

随之而来的是第三个层次的问题：能近似到什么程度？当近似比的下界被证明无法突破时（如集合覆盖在 P ≠ NP 下不能优于 $\ln n$ 量级），问题的答案从「如何近似」变成「不可能更好」。

## 二、核心原理

近似比的定义按优化方向分两种约定：

- **最小化问题**（如顶点覆盖）：$\rho \ge 1$，满足 $\text{ALG}(I) \le \rho \cdot \text{OPT}(I)$ 对所有实例 $I$ 成立。
- **最大化问题**（如最大割）：$\rho \le 1$，满足 $\text{ALG}(I) \ge \rho \cdot \text{OPT}(I)$。

几个经典结果及其证明直觉：

1. **顶点覆盖 2-近似**：反复取一条未被覆盖的边，把它的两个端点都加入解。这样选出的边的集合构成一个**极大匹配**；由于顶点覆盖必须覆盖每条边（尤其匹配中的边），任何覆盖至少需要匹配大小那么多个顶点，因此 $\text{ALG} = 2|\text{M}| \le 2\,\text{OPT}$。
2. **集合覆盖 $H(n)$ 近似**：贪心每次选择能覆盖最多未覆盖元素的集合。近似比为调和数 $H(n) = 1 + 1/2 + \cdots + 1/n = \ln n + O(1)$。
3. **度量 TSP 的 2-近似**：先求最小生成树（MST），再把树做前序遍历并抄近路（利用三角不等式不增加代价），得到一个哈密顿回路。因为删掉回路任一边得到生成树，故 $\text{MST} \le \text{OPT}$，于是 $\text{ALG} \le 2\,\text{MST} \le 2\,\text{OPT}$。改进版 Christofides 算法用最小权完美匹配处理奇度点，把比降到 $3/2$。

越强的保证需要越复杂的证明与实现，因此工程实践中「近似比 vs 实现成本」本身就是一项权衡。

## 三、形式化与数学基础

近似算法的标准定义：算法 $\mathcal{A}$ 是 $\rho$-近似的，若对一切实例

$$
\text{ALG}_{\mathcal{A}}(I) \le \rho \cdot \text{OPT}(I) \quad (\text{最小化}), \qquad
\text{ALG}_{\mathcal{A}}(I) \ge \rho \cdot \text{OPT}(I) \quad (\text{最大化})
$$

**PTAS**（多项式时间近似方案）指对任意 $\varepsilon > 0$ 存在 $(1+\varepsilon)$-近似算法，运行时间关于 $n$ 为多项式（关于 $1/\varepsilon$ 可以是任意函数，如 $O(n^{1/\varepsilon})$）；**FPTAS** 要求运行时间关于 $n$ 与 $1/\varepsilon$ 都是多项式（如 $O(n^3/\varepsilon)$），背包问题有 FPTAS。

集合覆盖贪心的分析依赖调和数：设最优解大小为 $k$，第 $i$ 轮至少覆盖 $\frac{n_{i}}{k}$ 个新元素（否则最优解无法用 $k$ 个集合覆盖全部），递推得残余元素数的界，最终

$$
H(n) = \sum_{i=1}^{n} \frac{1}{i} = \ln n + \gamma + O(1/n)
$$

其中 $\gamma \approx 0.5772$ 是欧拉常数。这给出贪心算法的近似比 $H(\max|S|)$，且该比无法显著改进——Feige 证明在 P ≠ NP 下集合覆盖不能有 $(1-o(1))\ln n$ 以下的近似算法。

顶点覆盖的 2-近似下界则说明「比值 2」来自极大匹配：设 $M$ 为算法选出的极大匹配，则 $\text{OPT} \ge |M|$ 且 $\text{ALG} = 2|M|$，两者相除即得比值恰为 2 的上界。

## 四、代码实现

```python
# 顶点覆盖 2-近似 与 集合覆盖贪心（调和数近似）
def vertex_cover_2approx(edges, n):
    # 每条边若有端点未被覆盖，则两个端点都选入
    cover = set()
    for u, v in edges:
        if u in cover or v in cover:
            continue
        cover.add(u)
        cover.add(v)
    return cover                      # 大小 <= 2 * OPT，因这些边构成极大匹配

def set_cover_greedy(universe, sets):
    # 每轮选覆盖最多未覆盖元素的集合，近似比 H(n)
    uncovered = set(universe)
    chosen = []
    while uncovered:
        best, gain = None, 0
        for s in sets:
            g = len(s & uncovered)
            if g > gain:
                best, gain = s, g
        if gain == 0:                 # 无法覆盖剩余元素
            break
        chosen.append(best)
        uncovered -= best
    return chosen

if __name__ == "__main__":
    edges = [(0, 1), (1, 2), (2, 3), (3, 4)]
    print("vertex cover:", sorted(vertex_cover_2approx(edges, 5)))
    uni = set(range(1, 9))
    sets = [{1, 2, 3}, {2, 4}, {3, 5, 6}, {4, 6, 7}, {5, 8}, {6, 7, 8}]
    print("set cover   :", set_cover_greedy(uni, sets))
```

顶点覆盖的实现在 5 条边的路径上给出 4 个顶点，而最优只需 2 个（{1,3} 一类）——比值恰好达到 2，说明这个界的紧性。工程上若实例结构特殊（二分图、弦图、树），应改用精确算法而非满足于 2-近似。

## 五、与其他技术对比

| 方法 | 质量保证 | 运行时间 | 实现难度 | 典型问题 |
| --- | --- | --- | --- | --- |
| 常数比近似 | $\rho$ 有界 | 多项式 | 中 | 顶点覆盖、度量 TSP |
| PTAS | $1+\varepsilon$ | 关于 $n$ 多项式 | 高 | 欧氏 TSP、调度 |
| FPTAS | $1+\varepsilon$ | 关于 $n,1/\varepsilon$ 多项式 | 高 | 背包 |
| 贪心启发式（无保证） | 无 | 快 | 低 | 大规模在线决策 |
| 不可近似（除非 P=NP） | 有下界 | —— | —— | 集合覆盖、最大团 |

与局部搜索类启发式相比：近似算法给出的是**对最坏实例也成立**的界，而局部搜索通常只在实测上表现好；两者可组合——用近似算法构造初始解，再用局部搜索改进。

## 六、常见误区

- 「把启发式称作近似算法」：没有可证明比值上界的算法不是近似算法，二者的工程风险完全不同。
- 「搞错最小/最大化方向」：最小化问题的比 $\ge 1$，最大化问题的比 $\le 1$，写反会导致结论错误。
- 「顶点覆盖的 2 倍界来自任意边的贪心」：必须选极大匹配的边并同时取两端，且证明依赖「匹配大小不超过最优覆盖大小」。
- 「$H(n)$ 与 $\log_2 n$ 混用」：调和数是自然对数 $\ln n$ 量级，基数不同会带来常数差异。
- 「认为有 PTAS 就一定实用」：$O(n^{1/\varepsilon})$ 的 PTAS 在 $\varepsilon = 0.01$ 时完全不可用，需看对 $1/\varepsilon$ 的依赖。

## 八、面试题

1. **证明顶点覆盖的 2-近似？** 要点：算法选出的边构成极大匹配 $M$，任何覆盖至少需要 $|M|$ 个顶点（匹配中各边互不相交），算法取 $2|M|$ 个顶点，故比值 $\le 2$。
2. **集合覆盖贪心的近似比怎么来？** 要点：每轮至少覆盖剩余元素的 $1/k$（$k$ 为最优解大小），残余量按几何衰减，累加得调和数 $H(n) = \ln n + O(1)$。
3. **度量 TSP 的 2-近似思路？** 要点：MST 权重不超过最优回路（删一边即得生成树），树的前序遍历抄近路利用三角不等式不增代价，总代价 $\le 2\,\text{MST} \le 2\,\text{OPT}$。
4. **PTAS 与 FPTAS 的区别？** 要点：PTAS 对 $n$ 是多项式、对 $1/\varepsilon$ 可任意；FPTAS 对两者都是多项式，因此更实用，如背包的 FPTAS。
5. **近似比与竞争比有何不同？** 要点：近似比是离线问题中解质量与最优解之比；竞争比是在线算法与最优离线解之比，后者还受「未知未来」约束。

## 九、演进与趋势

理论侧的核心进展来自 PCP 定理与不可近似性：它把「为什么这个问题近似不了」变成可证明的结论，并催生 APX-hardness、唯一游戏猜想等分类框架。算法侧的进展来自线性规划舍入与原始对偶方法，使很多问题获得更优比值（如设施选址、$k$-中位）。工程侧的趋势是把近似算法与大规模求解器结合：用近似算法给分支定界提供紧的初始界，或用随机化舍入把 LP 解转成整数解；同时近似算法被大量用于调度、网络设计与机器学习中的组合子问题。

## 十、小结

近似比是「解有多差」的形式化保证，它把 NP 难问题从不可解变成可控：最小化问题给 $\ge 1$ 的比值上界，最大化问题给 $\le 1$ 的比值下界。判断一个方案是否可靠，关键看它是否有可证明的比值、该比值对 $1/\varepsilon$ 或 $\log n$ 的依赖是否可接受，以及问题本身是否已被证明无法近似得更好。
