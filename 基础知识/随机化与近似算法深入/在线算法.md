# 在线算法

> 对应 Borodin & El-Yaniv《Online Computation and Competitive Analysis》与 CLRS Ch.13 相关。

## 一、背景与挑战
输入逐个到达、必须即时决策且不可反悔（如缓存淘汰、股票买卖）。无法预知未来，用竞争比衡量性能。

## 二、核心原理
竞争比：在线算法代价 / 最优离线代价之上界。经典：页面置换 LRU 与 FIFO 竞争比为 k（缓存大小 k）。

## 三、形式化 / 数学基础
算法 A 竞争比 c：对任意输入，$\frac{cost_A(I)}{cost_{OPT}(I)} \le c$。
缓存 k 页时 LRU 竞争比 $\le k$。

## 四、代码实现
```python
from collections import OrderedDict
class LRU:
    def __init__(self, k):
        self.k = k
        self.cache = OrderedDict()
    def access(self, x):
        if x in self.cache:
            self.cache.move_to_end(x)
        else:
            if len(self.cache) >= self.k:
                self.cache.popitem(last=False)
            self.cache[x] = True
```

## 五、与其他技术对比
与离线算法相比，在线无未来信息、用竞争比评估；与随机算法相比，在线可确定性且有竞争界。

## 六、常见误区
把离线最优当在线可行；竞争比与近似比混淆；未区分可撤销与不可撤销模型。
