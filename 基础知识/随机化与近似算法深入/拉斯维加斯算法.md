# 拉斯维加斯算法

> 对应 随机算法分类（Babai 引入术语）与 Motwani & Raghavan 著作。

## 一、背景与挑战
拉斯维加斯算法总是给出正确结果，但运行时间随机。与蒙特卡洛相反：对，但时间不确定。

## 二、核心原理
典型例子：随机化 quickselect 选枢纽，或随机重试。期望运行时间有界，最坏可能较长但概率低。

## 三、形式化 / 数学基础
若每次成功概率 p，重试期望次数 $1/p$；随机化选择第 k 大期望 $O(n)$。

## 四、代码实现
```python
import random
def quickselect(a, k):
    if len(a) == 1:
        return a[0]
    pivot = random.choice(a)
    left = [x for x in a if x < pivot]
    mid = [x for x in a if x == pivot]
    right = [x for x in a if x > pivot]
    if k < len(left):
        return quickselect(left, k)
    if k < len(left) + len(mid):
        return pivot
    return quickselect(right, k - len(left) - len(mid))
```

## 五、与其他技术对比
与蒙特卡洛相比，结果必正确但时间随机；与确定性 BFPRT（最坏 O(n)）相比，随机版更简单、期望更优。

## 六、常见误区
把它当成近似算法；忽略期望时间分析；把随机快排当拉斯维加斯（快排也是必正确，属 LV）。

## 十、小结
拉斯维加斯算法保证正确、时间随机，是「正确性优先、时间靠概率」的随机范式。
