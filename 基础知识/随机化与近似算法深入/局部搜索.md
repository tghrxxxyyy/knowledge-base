# 局部搜索

> 对应 组合优化局部搜索与元启发式文献（模拟退火、禁忌搜索）。

## 一、背景与挑战
从可行解出发，沿邻域逐步改进，用于 TSP、调度等难问题。易陷局部最优，需要策略跳出。

## 二、核心原理
定义邻域（小幅改动解），按规则（最速下降、随机接受劣解）迭代；模拟退火以概率接受劣解以逃局部最优。

## 三、形式化 / 数学基础
模拟退火接受概率 $P = e^{-\Delta/T}$，$\Delta>0$ 为变劣量，T 为温度随迭代下降。

## 四、代码实现
```python
import random, math
def simulated_annealing(cost, neighbor, s0, iters=10000):
    s = s0
    best = s
    T = 1.0
    for i in range(iters):
        T *= 0.999
        s2 = neighbor(s)
        d = cost(s2) - cost(s)
        if d < 0 or random.random() < math.exp(-d / T):
            s = s2
        if cost(s) < cost(best):
            best = s
    return best
```

## 五、与其他技术对比
与精确算法相比，局部搜索快但无最优保证；与随机重启相比，退火更系统逃离局部最优。

## 六、常见误区
降温过快退化为贪心；邻域定义不当无改进；初温/迭代次数未调参。

## 七、与开源书 / 权威来源对应
- 《Approximation Algorithms》相关启发式章节
- Kirkpatrick, Gelatt, Vecchi 1983（模拟退火）

## 八、面试题
「TSP 启发式」；局部搜索为何可能不最优。

## 九、演进与趋势
禁忌搜索、遗传算法、与机器学习的超参优化结合。

## 十、小结
局部搜索以邻域迭代改进，靠退火/禁忌等机制跳出局部最优，是NP难问题的实用求解法。
