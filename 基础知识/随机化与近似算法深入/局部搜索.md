# 局部搜索

> 对应 Kirkpatrick, Gelatt & Vecchi 1983 "Optimization by Simulated Annealing"（Science）/ Glover 1986（禁忌搜索）/ Lin & Kernighan 1973（TSP 局部搜索）/ Williamson & Shmoys《The Design of Approximation Algorithms》。

## 一、背景与挑战

大量组合优化问题（TSP、车间调度、图着色、装箱、选址）在规模稍大时精确算法就不可行。局部搜索（local search）是一条务实的路线：从一个可行解出发，反复在它的**邻域**内寻找更优解，直到邻域中不存在改进为止。

它的核心困难是**局部最优陷阱**：得到的解在其邻域内无法改进，但距全局最优可能很远。用一个经典反例可以直观理解——TSP 中的 2-opt 邻域只允许「交换两条边的连接方式」，某些局部最优解看似无交叉可消除，却整体比最优回路长得多。

第二个困难是**邻域设计与代价的权衡**：邻域越大越容易跳出局部最优，但每次迭代扫描邻域的开销也越大。第三个困难是**停止与调参**：何时停止、接受准则如何设定、参数（初温、降温率、禁忌长度）如何选择，直接决定实用效果。

## 二、核心原理

局部搜索的统一框架是「邻域 + 接受准则 + 迭代」：定义解空间 $S$ 与邻域函数 $N: S \to 2^S$，从初始解 $s_0$ 出发，每步在 $N(s)$ 中按准则选择下一个解。不同算法只在准则上分道扬镳：

1. **最速下降（Hill Climbing）**：只接受更优解，必然收敛到局部最优，简单但易停滞。
2. **模拟退火（Simulated Annealing, SA）**：以概率接受劣解，概率随「温度」下降而降低。高温阶段近似随机游走以探索，低温阶段近似最速下降以收敛。
3. **禁忌搜索（Tabu Search）**：允许接受劣解，但用禁忌表禁止短期回访最近访问过的解或动作，并用特赦准则（aspiration）在明显改进时打破禁忌。
4. **随机重启（Random Restarts）**：多次从不同初始解运行最速下降，取最好结果。简单有效，是工程上的常见基线。
5. **大邻域搜索（LNS/ALNS）**：每轮「破坏-修复」，用较大动作幅度跳出局部最优，在调度与路径规划中表现突出。

TSP 中常用的邻域是 **2-opt**（反转一段路径，等价于消除两条交叉边）与 **3-opt**，Lin–Kernighan 启发式进一步在变深度的 $k$-opt 中做选择性搜索，是长期最强的经典局部搜索之一。

## 三、形式化与数学基础

模拟退火的接受准则为 Metropolis 形式：当前解 $s$、候选解 $s'$、代价差 $\Delta = c(s') - c(s)$，则

$$
\Pr[\text{接受}] = \begin{cases} 1, & \Delta \le 0 \\ e^{-\Delta / T}, & \Delta > 0 \end{cases}
$$

其理论依据是：若温度按 $T_k \ge \dfrac{c}{\log(1+k)}$ 的速率缓慢下降（对数降温），则算法以概率 1 收敛到全局最优解。但该降温速率极慢，实际工程中改用几何降温 $T_{k+1} = \alpha T_k$（$\alpha$ 常取 0.9~0.999），牺牲理论收敛性换取可用时间。

局部最优的质量也有可证明的界。对度量 TSP，2-opt 局部最优解不含交叉边，可证明其长度不超过最优解的常数倍（经典结论给出 2 倍量级的上界；具体常数与邻域定义、证明前提有关，引用时需核对原文）。这解释了为什么简单邻域在实践中往往已经「够好」。

跳出局部最优的另一种形式化是**精确 $k$-邻域**：若算法在每一步都能找到邻域内最优（而不是首个改进），则所得局部最优的质量更高，但每步代价为 $O(|N(s)|)$ 甚至更高。这构成一个明确的三方权衡：

$$
\text{解质量} \;\longleftrightarrow\; \text{单步代价} \;\longleftrightarrow\; \text{可承受的迭代数}
$$

## 四、代码实现

```python
# 模拟退火求解 TSP（2-opt 邻域）：几何降温 + Metropolis 接受准则
import math, random

def tour_cost(t, d):
    return sum(d[t[i]][t[(i + 1) % len(t)]] for i in range(len(t)))

def two_opt_neighbor(t):
    n = len(t)
    i, j = sorted(random.sample(range(n), 2))     # 反转区间 [i, j]
    return t[:i] + t[i:j + 1][::-1] + t[j + 1:]

def simulated_annealing(d, s0, iters=200000, t0=100.0, alpha=0.9995, seed=1):
    random.seed(seed)                             # 固定种子便于复现实验
    s, best = list(s0), list(s0)
    cs, cbest = tour_cost(s, d), tour_cost(s, d)
    T = t0
    for _ in range(iters):
        s2 = two_opt_neighbor(s)
        c2 = tour_cost(s2, d)
        delta = c2 - cs
        if delta <= 0 or random.random() < math.exp(-delta / T):
            s, cs = s2, c2                        # 接受（含以概率接受劣解）
            if cs < cbest:
                best, cbest = list(s), cs         # 记录历史最优
        T *= alpha                                # 几何降温
    return best, cbest

if __name__ == "__main__":
    n = 8
    d = [[0 if i == j else abs(i - j) * 3 + 1 for j in range(n)] for i in range(n)]
    best, cost = simulated_annealing(d, list(range(n)))
    print("best tour:", best, "cost:", cost)
```

实践要点：`delta <= 0` 分支必须显式判断，否则 `math.exp(-delta/T)` 在 `delta` 为负时返回大于 1 的值，语义虽正确但依赖浮点行为；`tour_cost` 应按增量计算（只重算被改动的两条边）以免成为瓶颈；记录历史最优是必需的，因为退火末期解质量会波动。

## 五、与其他技术对比

| 方法 | 跳出局部最优 | 质量保证 | 调参难度 | 典型场景 |
| --- | --- | --- | --- | --- |
| 最速下降 | 否 | 无 | 低 | 快速基线、嵌入其他算法 |
| 随机重启 | 靠多次运行 | 无 | 低 | 中大规模、实现简单 |
| 模拟退火 | 是（概率接受劣解） | 理论收敛（需对数降温） | 中高 | TSP、布局、调度 |
| 禁忌搜索 | 是（禁忌表） | 无 | 中 | 调度、图着色 |
| 大邻域搜索 | 是（破坏-修复） | 无 | 中 | 车辆路径、排班 |
| 近似算法 | 不适用 | 有近似比 | 低 | 顶点覆盖、度量 TSP |

与近似算法相比：局部搜索通常实测质量更好、适用问题更广，但缺少最坏情况保证；与精确算法相比：它在任意时间预算下都能给出解（anytime 特性），适合在线决策。

## 六、常见误区

- 「降温过快」：初温低或 $\alpha$ 太小会让算法退化为贪心，几乎立刻陷入局部最优。
- 「邻域设计不当」：若邻域无法表达「从当前解到更优解的路径」，再多的迭代也无济于事——邻域设计比调参更关键。
- 「忘记记录历史最优」：退火末期会接受劣解，最终解不一定是过程中见过的最好的解。
- 「把局部最优当作最优」：局部搜索不提供最优性证明，除非问题具有某种凸性/拟阵结构。
- 「忽略代价函数增量计算」：每步全量重算目标函数会让大实例完全不可用，增量求值是工程必需。

## 八、面试题

1. **局部搜索为何可能不最优？** 要点：邻域只覆盖解的局部变化，算法在邻域内无改进即停止，但该解可能远离全局最优，TSP 的 2-opt 局部最优就是经典反例。
2. **模拟退火如何跳出局部最优？** 要点：以 $e^{-\Delta/T}$ 的概率接受劣解，高温时近似随机游走，随 $T$ 下降逐渐收敛为最速下降。
3. **禁忌搜索与模拟退火的区别？** 要点：禁忌搜索用记忆结构（禁忌表）显式禁止近期动作并配特赦准则；SA 用温度控制的概率接受，无显式记忆。
4. **如何为 TSP 设计邻域？** 要点：2-opt（消除交叉边）、3-opt、or-opt（段移动）、LK 变深度搜索；邻域越大质量越好但单步代价越高。
5. **SA 的理论收敛条件是什么，为什么工程上不用？** 要点：需对数降温 $T_k \ge c/\log(1+k)$，收敛极慢；工程改用几何降温，牺牲理论保证换取可用时间。

## 九、演进与趋势

趋势之一是**元启发式的融合与自动化**：大邻域搜索（LNS/ALNS）把邻域选择本身作为学习对象，禁忌与退火混合以兼得记忆与概率探索；趋势之二是**与学习结合**——用机器学习预测好的邻域或初始解，或用神经网络直接产生解（学习型组合优化），目标是把传统求解器从「分钟级」压到「毫秒级」以满足在线场景。工程上，局部搜索更多作为大型求解器（如 MILP 求解器的启发式模块、约束编程）中的子例程，而不是独立使用。

## 十、小结

局部搜索以「邻域迭代改进」为核心，用最速下降快速收敛、用模拟退火或禁忌搜索跳出局部最优，是 NP 难问题最实用的求解路线之一。它的效果主要取决于**邻域设计与接受准则**，而非迭代次数；工程实现必须做增量求值、记录历史最优，并为无保证的解质量预留验证或兜底手段。
