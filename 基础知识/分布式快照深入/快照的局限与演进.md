# 快照的局限与演进

> 对应 Chandy & Lamport 1985（假设 FIFO 通道）与 Fischer et al. 1985（FLP 不可判定性背景）以及现代增量快照研究。

## 一、背景与挑战
经典 CL 算法假设通道 FIFO 且消息可靠。真实系统有非 FIFO、消息丢失、算子动态扩缩容，需要对原算法做扩展或替代。

## 二、核心原理
- 非 FIFO：需用序列号为每条通道定序，才能正确判定“在途”。
- 动态拓扑：节点加入/离开需重新协调 marker 集。
- 大规模：全量快照成本高，转向增量/分区快照。

## 三、形式化与数学基础
非 FIFO 下，通道状态必须按发送序号集合表示 $S_C = \{seq_i\}$，保证接收方能重建因果序。增量快照仅记录状态差 $\Delta S$，恢复时 $S_{t} = S_{t-1} \oplus \Delta S$。

## 四、代码实现
# 增量快照合并
def apply_delta(base, delta):
    s = dict(base)
    for k, dv in delta.items():
        s[k] = dv
    return s

## 五、与其他技术对比
- 对比全量 CL：增量省空间但需基线。
- 对比逻辑复制：逻辑复制关注变更流而非全局状态。

## 六、常见误区
1. 在非 FIFO 通道直接套用 CL。
2. 增量基线丢失导致无法恢复。
