# 两电平自适应分支预测

> 对应 Hennessy & Patterson《Computer Architecture: A Quantitative Approach》第3章分支预测。

## 一、背景与挑战
现代流水线处理器的性能高度依赖控制流连续性。当一条条件分支误预测时，流水线必须清空并重新取指，代价随流水线深度线性增长。静态预测（总是跳转/总是不跳转）在 SPEC 类负载上误预测率常超过 40%，因此必须依赖运行时历史。

## 二、核心原理
Yeh 与 Patt 于 1991 年提出两电平自适应预测：第一级是全局或局部的分支历史寄存器（BHR），第二级是由历史索引的模式历史表（PHT，也称分支历史表 BHT）。预测位（2 bit 饱和计数器）根据"历史模式 → 上一次该模式下是否跳转"进行学习，从而捕捉循环、周期与交替模式。

## 三、形式化与数学基础
设历史长度为 $h$，PHT 表项数为 $2^h$，每个表项是一个 $c$ bit 饱和计数器。平均误预测率为：
$$Mispred = \frac{1}{N}\sum_{i=1}^{N} \mathbb{1}[pred(i) \neq actual(i)]$$
饱和计数器更新：若实际跳转则 $C \leftarrow \min(C+1, 3)$，否则 $C \leftarrow \max(C-1, 0)$。当 $C \ge 2$ 时预测跳转。

## 四、代码实现
```c
// 全局历史寄存器(低位为最近分支)，2bit饱和计数器PHT
unsigned int ghr = 0;
unsigned char pht[4096]; // 12位历史索引

int predict(unsigned int pc) {
    unsigned int idx = (ghr ^ pc) & 0xFFF; // gshare混合
    return pht[idx] >= 2;
}
void update(unsigned int pc, int taken) {
    unsigned int idx = (ghr ^ pc) & 0xFFF;
    if (taken) { if (pht[idx] < 3) pht[idx]++; }
    else       { if (pht[idx] > 0) pht[idx]--; }
    ghr = (ghr << 1) | (taken & 1);
}
```

## 五、与其他技术对比
静态预测无需历史存储但精度低；单级 BHT 忽略历史模式；两电平方法通过历史关联显著提升周期/交替模式命中。相比 TAGE（见后续文档），两电平表项稀疏、对长历史模式覆盖弱。

## 六、常见误区
误以为饱和计数器越多位越好：超过 3 bit 收益极小且增加状态。误以为 gshare 与 gselect 等价：gshare 用异或混合历史与 PC，抗别名冲突更强。误把 BHR 位数当作 PHT 容量，二者独立。

## 七、与开源书/权威来源对应
Hennessy & Patterson 量化方法详述 Yeh-Patt 两电平；CSAPP（Bryant & O'Hallaron）以"分支预测"小节给出运行示例；CyC2018/CS-Notes 有中文图解。

## 八、面试题
问：为什么 2 bit 饱和计数器比 1 bit 更能容忍噪声？答：1 bit 单次错误即翻转，2 bit 需连续两次错误才改变强预测方向，抗抖动。问：全局历史与局部历史的取舍？

## 九、演进与趋势
从两电平演进到 gshare/gselect，再到基于分量几何（TAGE）、感知机（HPerceptron）与 ITTAGE，现代 CPU 预测器已达数十 K 级状态、误预测率个位数。

## 十、小结
两电平自适应通过"历史索引 + 饱和计数器"将运行时模式编码进硬件，是后续所有现代预测器的基石。
