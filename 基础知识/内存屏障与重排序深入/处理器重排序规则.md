# 处理器重排序规则

> 对应 Intel SDM 卷3 Memory Ordering 与 ARMv8 手册。

## 一、背景与挑战
现代 CPU 为吞吐允许访存在遵守内存模型下重排。x86-TSO 与 ARM 弱模型规则不同，程序可移植性依赖抽象内存模型。

## 二、核心原理
x86 允许的唯一重排是「较早的 store 与较晚的 load 重排」（store→load），其余保持。ARM 允许 store→store、load→load、load→store 等多种重排（在屏障前）。

## 三、形式化与数学基础
x86-TSO 允许：
$$L_a \prec_{po} S_b \Rightarrow L_a \text{ 可在 } S_b \text{ 外部可见前完成}$$
ARM 允许更多：若 $a,b$ 间无屏障，则除同地址依赖外均可重排。

## 四、代码实现
```asm
; x86: 这两者可重排（store 后进缓冲，load 先完成）
mov [x], 1     ; store
mov eax, [y]   ; load  可能先观测到 y 的旧值
```

## 五、与其他技术对比
x86-TSO 接近直观、易编程；ARM/POWER 弱模型性能高但需更多屏障/原子。这正是 C++ 抽象的意义。

## 六、常见误区
误认为所有 CPU 都像 x86。把 x86 上「碰巧正确」的代码移植到 ARM 常因缺失屏障而失效。

## 七、与开源书/权威来源对应
Intel SDM 卷3 的「Memory Ordering」表列各类重排；ARMv8 手册的「Barrier Litmus Tests」给出示例。

## 八、面试题
问：x86 允许哪种重排？答：store→load 重排（因 store 进缓冲），其它顺序在 TSO 下保持。

## 九、演进与趋势
RISC-V 也定义自己的弱内存模型（RVWMO），生态正统一到语言级原子语义上。

## 十、小结
处理器重排规则由内存模型规定，x86 与 ARM 差异巨大，跨平台并发必须依赖抽象而非经验。
