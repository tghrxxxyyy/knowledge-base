# 向量时钟的复杂度与优化

> 对应 Lamport 1978（向量时钟代价讨论）与 Almeida et al. 2014（Dotted Version Vectors，紧凑向量时钟优化）。

## 一、背景与挑战
朴素向量时钟大小为 O(N)（N 为节点数），每次消息都带全量向量，在节点数巨大或动态变化时开销显著。如何在保持因果表达力的同时压缩空间？

## 二、核心原理
- 紧凑向量时钟（Compact VC）：只保留“发生过更新”的节点维度，其余用基向量推断。
- Dotted Version Vectors：用单点计数器 + 区间表示，显著减少元数据。
- 剪枝：对长期无更新的维度做 GC 或合并。

## 三、形式化与数学基础
朴素 VC 消息负载 $O(N)$。Dotted VV 在单节点频繁更新的典型工作负载下，负载降为 $O(活跃节点数)$，且维护并发判定的正确性不变。

## 四、代码实现
# 紧凑表示：只存差异维度
def compact(vc, base):
    diff = {i: vc[i] for i in range(len(vc)) if vc[i] != base[i]}
    return diff

## 五、与其他技术对比
- 对比朴素 VC：紧凑版省空间但合并略复杂。
- 对比标量时钟：仍保留因果能力。

## 六、常见误区
1. 过早优化导致因果信息丢失。
2. 忽略动态加节点对维度映射的影响。
