# 值预测与恢复

> 对应 Hennessy & Patterson《Computer Architecture》。

## 一、背景与挑战
部分指令（如指针追踪 load、计数循环）产生高度可预测的值。值预测（value prediction）猜测指令结果以提前解除数据依赖，错误则恢复。

## 二、核心原理
值预测器（如 stride、最后值、上下文表）预测某指令的输出。预测的「值」作为源供后续指令投机使用；当真实结果算出，比对预测，错误则标记链上指令误推测并回滚恢复。

## 三、形式化与数学基础
预测正确率 p 影响收益：

    speedup 正比于 p - recovery_cost*(1-p)

仅高置信度预测才被采纳。

## 四、代码实现
```c
uint64_t last_val[N_PRED];
int predict_value(int id, uint64_t *pred) {
    *pred = last_val[id]; return 1; // 最后值预测
}
void verify(int id, uint64_t real) {
    if (real != last_val[id]) rollback_chain(id);
    last_val[id] = real;
}
```

## 五、与其他技术对比
值预测可打破 RAW 依赖，但预测错误恢复代价高，需高准确率才划算；常用于特定模式（stride、间接跳转目标）。

## 六、常见误区
误以为值预测总有益；低准确率时恢复代价超过收益。误以为可预测任意值。
