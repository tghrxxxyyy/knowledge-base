# Bellman-Ford与负权

> 对应 Sedgewick《Algorithms》与 CLRS 第 24.1 节（单一来源最短路径，含负权）。

## 一、背景与挑战
Dijkstra 依赖「边权非负」这一前提：一旦某个顶点被确定，其最短路就不再变化。但现实中存在负权边（如金融套利中的汇率差、差分约束中的松弛量、路由中的惩罚值），Dijkstra 在负权下会错误地提前确定顶点。Bellman-Ford 不依赖非负性，通过对所有边反复松弛，能在含负权（但无负权环）的图中求出单源最短路，并顺便检测负权环。

一个经典应用是「货币套利」：把汇率取负对数变成边权，若存在一个负权环，沿环交易一圈就能无风险获利。另一应用是差分约束系统（system of difference constraints），它等价于单源最短路，负权环对应「约束无解」。这些都要求算法能处理负权并报告环的存在。

从算法范式看，Bellman-Ford 属于**动态规划**：第 $k$ 轮刻画「至多经过 $k$ 条边的最短距离」，$V-1$ 轮后收敛。这与 Dijkstra 的**贪心**范式形成鲜明对照——贪心依赖「局部最优即全局最优」的不变量（需要非负权），而动态规划只依赖最优子结构，因此对负权（乃至任意实数权）都成立。理解这一范式差异，是记住「为什么负权必须换算法」的关键。

## 二、核心原理
算法维护距离数组 dist，初始 dist[src]=0、其余为无穷。核心操作是「松弛（relax）」：对每条边 (u,v,w)，若 dist[u]+w < dist[v]，则更新 dist[v]。重复对全体边松弛：第 k 轮后，所有「最多经过 k 条边」的最短路已被确定（前提是路径上无环，因为最短路必简单）。共进行 V-1 轮；若第 V 轮仍能松弛，说明存在从源可达的负权环。

注意松弛顺序：Bellman-Ford 对每轮内边的处理顺序不敏感（任意顺序都收敛），这与 Dijkstra 不同。但顺序会影响「提前收敛」的速度——若按拓扑序松弛，可在少于 V-1 轮内完成；不过为通用性，标准实现不假设拓扑序。

一个常见优化是「提前退出」：若某一轮内没有任何 dist 被更新，说明已收敛，可直接结束。对于多数实际图（尤其含负权但结构简单的图），这能把平均复杂度大幅降低，而最坏界仍是 $O(VE)$。

负权环的判定还有「定位环上顶点」的进阶做法：在第 V 轮仍被更新的顶点，必在（或可达）负权环上；从它沿 pred 指针回溯 V 步，即可找到一个必在环上的顶点，再继续回溯即可输出整个环。这在「找出套利路径」这类问题中是必需的最后一步。

## 三、形式化与数学基础
每轮松弛 $O(E)$，共 $V-1$ 轮：
$$T = O(VE)$$
正确性依据：无负权环时，任何最短路都是简单路径，边数至多 $V-1$。第 k 轮后，所有边数 $\le k$ 的最短路收敛。若存在负权环且从源可达，则沿环每绕一圈距离下降，无下界，最短路不存在（值为 $-\infty$）。因此 Bellman-Ford 同时回答了「有无负权环」。更精确地，松弛本质是动态规划：dist_k[v] = 经过 ≤k 条边到 v 的最短距离，递推 $dist_k[v] = \min(dist_{k-1}[v], \min_u \{dist_{k-1}[u]+w(u,v)\})$。

关于「不可达负权环」的严格说明：算法只报「从源可达」的负权环。若负权环与源不连通，从源出发的任何路径都不会经过它，其最短路仍然存在且有限，算法不会误报（因为第 V 轮不会有任何可达顶点被更新）。

差分约束的等价性可形式化如下：约束系统由形如 $x_j - x_i \le w$ 的不等式组成，构造有向边 $i \to j$ 权重 $w$，则系统有解当且仅当图中无负权环；此时 $x_i = dist[src][i]$ 就是一组可行解。

## 四、代码实现
```python
# Bellman-Ford：支持负权，检测负权环
def bellman_ford(edges, n, src):
    dist = [float("inf")] * n
    pred = [-1] * n
    dist[src] = 0
    for _ in range(n - 1):
        for u, v, w in edges:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                pred[v] = u
    # 第 n 轮再松弛一次检测负权环
    for u, v, w in edges:
        if dist[u] + w < dist[v]:
            return None, True, pred     # 存在负权环
    return dist, False, pred
```

加上「提前退出」优化后，实际会快很多：

```python
def bellman_ford_early(edges, n, src):
    dist = [float("inf")] * n
    dist[src] = 0
    for _ in range(n - 1):
        changed = False
        for u, v, w in edges:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                changed = True
        if not changed:                 # 本轮无更新，已收敛
            break
    # 负权环检测逻辑同上
    return dist
```

## 五、与其他技术对比
| 维度 | Bellman-Ford | Dijkstra | SPFA | Floyd |
| --- | --- | --- | --- | --- |
| 负权边 | 支持 | 不支持 | 支持 | 支持 |
| 复杂度 | $O(VE)$ | $O((V+E)\log V)$ | 平均 $O(E)$，最坏 $O(VE)$ | $O(V^3)$ |
| 负权环检测 | 原生 | 无 | 可加计数 | 可 |
| 适用 | 负权/检测环 | 非负权快 | 稀疏负权 | 全源 |
| 单源/全源 | 单源 | 单源 | 单源 | 全源 |
| 边权类型 | 任意实数 | 非负 | 任意实数 | 任意实数 |

SPFA 是 Bellman-Ford 的队列优化版：只把「松弛成功的顶点」的出边入队，避免每轮扫描全部边。它的平均表现远好于 $O(VE)$，但可被特殊构造的数据卡到最坏退化，因此在竞赛与判题场景中不稳定。

## 六、常见误区
1. 以为松弛 V-1 轮后就能处理负权环。V-1 轮只求最短路；负权环需「再多一轮仍能松弛」来判定。
2. 以为负权边一定导致无解。只有「从源可达的负权环」才使最短路无界；不可达的负权环不影响其他点。
3. 在稠密图用 SPFA 求稳。SPFA 最坏仍 $O(VE)$，可被特殊构造卡退化为 Bellman-Ford。
4. 以为边权可以为任意实数。若边权为 NaN/非数值则松弛失效，需先清洗。
5. 混淆「负权边」与「负权环」。前者完全合法，含大量负权边的图仍可正常求解。
6. 忘记检查 `dist[u]` 是否为无穷。若不判断就做 `dist[u] + w`，在某些语言中会产生错误结果（如整数溢出）。
7. 以为 Bellman-Ford 只适用于有向图。无向图中的负权边等价于「双向负权环」，因此无向图含任何负权边都意味着存在负权环。

## 八、面试题
1. 为什么是 V-1 轮松弛？
   要点：最短路为简单路径，边数至多 V-1，第 k 轮确定边数≤k 的最短路。
2. Bellman-Ford 能否处理负权环？如何处理？
   要点：不能求最短路（无界）；但 V-1 轮后再松弛一轮即可检测其存在。
3. 负权环「不可达」时有影响吗？为什么？
   要点：不影响可达点的最短路；只当从源可达时才使最短路无定义。
4. Bellman-Ford 与差分约束系统有何关系？
   要点：差分约束的可行解等价于单源最短路无负权环，负权环即约束矛盾。
5. 如何找出负权环上的具体顶点？
   要点：第 V 轮仍被更新的顶点沿 pred 回溯 V 步，必落在环上，再继续回溯即可输出整个环。
6. 提前退出优化会破坏最坏复杂度保证吗？
   要点：不会，最坏仍是 $O(VE)$，只是平均更快。

## 九、演进与趋势
SPFA（队列优化 Bellman-Ford）平均更快但最坏仍 $O(VE)$；在差分约束系统、套利检测中 Bellman-Ford 是标准工具；Yen 算法、逐次最短路（successive shortest paths）在最小费用流中复用其松弛框架；SLF/LLL 等 SPFA 启发式试图改善平均表现，但无法消除最坏退化。

在工程实践中，Bellman-Ford 也出现在距离向量路由协议的收敛分析中：路由器通过邻居交换距离信息迭代更新，本质上就是分布式的松弛过程，「计数到无穷」问题正对应负权环造成的无界下降。

## 十、小结
Bellman-Ford 以 $V-1$ 轮全边松弛求得含负权的最短路，复杂度 $O(VE)$，并原生支持负权环检测。它是处理负权与验证最短路存在性的基石算法，也是理解差分约束、套利检测与费用流的工具基础。「动态规划 vs 贪心」的范式差异，正是它与 Dijkstra 最本质的分界线。
