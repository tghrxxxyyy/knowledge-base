# 负权环检测

> 对应 CLRS 第 24.1 节（负权环检测）与 Sedgewick《Algorithms》最短路径章。

## 一、背景与挑战
负权环（negative-weight cycle）指环上边权和小于 0。一旦这样的环从源可达，沿环每绕一圈总距离就下降，最短路不存在（值为 $-\infty$），许多依赖最短路的算法会出错甚至死循环。因此在使用最短路径前，必须判定「图中是否存在从源可达的负权环」，并在存在时给出环本身（而非仅布尔值）以便诊断。

这在工程上很重要：路由协议若引入负权环会导致转发环路；套利检测正是「主动寻找负权环」；差分约束系统用「无负权环」判定约束可解。只返回布尔值往往不够，排障需要具体的环路径。

需要区分三种语义层次：一是「源可达的负权环」，影响单源最短路；二是「图中任意位置的负权环」，影响全源最短路与图的良定义性；三是「恰好经过某目标点的负权环」，影响特定查询。三者的判定开销与算法选择都不同，混用会在边界用例上出错。此外还有「零权环」：它不改变距离值，但会让最短路不唯一、路径条数无穷，在要求「最短且最少边」的场景需另行处理。

## 二、核心原理
基于 Bellman-Ford：先跑 $V-1$ 轮全边松弛。若无负权环，此时所有最短路已收敛（不再变化）。再做第 $V$ 轮松弛：若存在某条边仍能松弛，说明有一个顶点被「第 V 次」更新——根据最短路简单路径性质，这只能是因为存在一条经过负权环、长度 $> V-1$ 条边、却更短的路径。由此判定负权环存在。要找出环，可在检测到后从被更新的顶点沿前驱（pred）回溯 V 步，必落入环中（鸽巢原理：V+1 个前驱必含环）。

工程上更常见的是用 SPFA 的「入队次数计数」：若某顶点入队超过 V 次，则必在负权环上或可达负权环，以此提前终止，平均更快。

为什么「$V-1$ 轮」是收敛上界？因为任何不重复顶点的最短路径最多含 $V-1$ 条边；若最短路存在，它必定是简单路径（有负环则绕环更短；有正环则去掉更短；零环可去）。反言之，若某点在第 $V$ 轮仍被改进，则该改进路径至少含 $V$ 条边，由鸽巢必有重复顶点，重复段构成环且权和为负——这就同时给出了「环存在」与「环可在回溯中找到」。回溯的正确性来自前驱链的性质：每轮松弛都把 pred 更新为「当前更短的到来者」，因此收敛后的 pred 链指向真实的最短路径树；被额外更新的点其 pred 链必然穿过负环，从该点走 $V$ 步一定进入环内。

## 三、形式化与数学基础
无负权环时，$V-1$ 轮已使所有 dist 收敛（每轮至少「固定」一条最短路边）。第 $V$ 轮仍更新即证明存在零权或负权环：
$$\exists (u,v,w): \text{after } V-1 \text{ rounds},\; dist[u]+w < dist[v] \implies \text{negative cycle reachable}$$
附加检测 $O(E)$，总复杂度仍为 $O(VE)$。若要从任意顶点（不止源）检测，可加超级源连所有点权 0，或对每点跑 SPFA 入队计数；也可先求强连通分量（SCC），只在含负权边的 SCC 内检测。

形式化表述可更紧凑：记 $d_k(v)$ 为「至多 $k$ 条边的最短距离」。Bellman-Ford 恰好实现 $d_k(v) = \min(d_{k-1}(v), \min_{(u,v,w)}(d_{k-1}(u)+w))$。若图无负环，则 $\lim_k d_k = d_{V-1}$（稳定）；若存在从源可达的负环，则 $d_k$ 在环上顶点处随 $k$ 严格递减且无下界，故 $d_{V-1}$ 永不稳定，检测条件即 $d_V \ne d_{V-1}$。超级源法是「全图检测」的标准归约：新增 $s^*$ 以 0 权连所有顶点，则原图中任一负环都变成从 $s^*$ 可达，单源算法即可覆盖。SCC 加速法的依据是：负环必整体落在某个强连通分量内，故可先缩点只检查含负边的分量，把 $O(VE)$ 中的 $V$ 换成分量规模。

## 四、代码实现
```python
# 负权环检测（返回是否存在 + 环路径）
def find_negative_cycle(edges, n, src):
    dist = [float("inf")] * n
    pred = [-1] * n
    dist[src] = 0
    # 标准 Bellman-Ford：V-1 轮，每轮按任意顺序松弛全部边
    for _ in range(n - 1):
        changed = False
        for u, v, w in edges:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                pred[v] = u
                changed = True
        if not changed:
            return False, None      # 提前退出：已收敛则必无负环
    # 第 V 轮：仍能松弛则存在从源可达的负权环
    for u, v, w in edges:
        if dist[u] != float("inf") and dist[u] + w < dist[v]:
            # 从 v 沿前驱回溯 n 步必落入负环（鸽巢原理）
            x = v
            for _ in range(n):
                x = pred[x]
            cycle = []
            y = x
            while True:
                cycle.append(y)
                y = pred[y]
                if y == x:
                    break
            return True, cycle[::-1]   # 反转为正向顺序便于输出
    return False, None
```

两点实现细节值得注意：其一，松弛时应判断 `dist[u]` 有限，否则 `inf + w` 在浮点语义下仍是 `inf`（不会误判），但若用整数哨兵大值则可能溢出或误判，故显式判断更稳妥；其二，回溯步数取 $n$（即 $V$）足以保证入环，因为前驱链上最多有 $V$ 个不同顶点，走 $V$ 步必然重复。若只需判定存在性，可省略回溯，只返回布尔值以省去 $O(V)$ 构造开销。

## 五、与其他技术对比
| 方法 | 复杂度 | 能否给环 | 适用 | 平均表现 | 备注 |
| --- | --- | --- | --- | --- | --- |
| Bellman-Ford 再松弛 | $O(VE)$ | 可（回溯） | 单源 | 稳定 | 最通用、易实现 |
| SPFA 入队计数 | 平均 $O(E)$ | 可 | 单源 | 最坏退化 | 队列实现，常数小 |
| Floyd-Warshall | $O(V^3)$ | 可 | 全源 | 稳定 | 判 `dist[i][i] < 0` |
| 超级源 + 单源算法 | $O(VE)$ | 可 | 全图 | 稳定 | 全图判环的标准归约 |
| SCC 缩点后检测 | 省常数 | 可 | 全图 | 快 | 只查含负边的分量 |
| Dijkstra | 不适用 | 否 | 仅非负权 | — | 遇负权即失效 |

## 六、常见误区
1. 仅判断 dist 变负就当负权环。dist 为负不代表有环（可能只是负权路径），必须用「还能松弛」判定。
2. 忽略源可达性。不可达的负权环不影响最短路，但某些场景（全图判环）需另处理。
3. 把 SPFA 当万能。最坏构造下 SPFA 退化为 $O(VE)$，与 Bellman-Ford 相同。
4. 以为找到环就能直接修改。环路径用于诊断，修正需从业务层（汇率/约束）入手。
5. 把零权环当作负权环。零权环不改变距离值，判定条件是严格小于（`dist[u] + w < dist[v]`），用 `<=` 会误报。
6. 回溯步数取 $V-1$ 而非 $V$。步数不足可能停在环外，取 $V$ 步才保证入环。
7. 忘记处理多重边与自环。自环权为负即负环；平行边应各自参与松弛，不能只保留最小权。
8. 认为「无负环」就万事大吉。还须确认无零权环（若要求唯一最短路）以及权值溢出边界。

## 八、面试题
1. 如何不仅判定、还找出负权环？
   要点：检测到后再松弛的顶点沿前驱回溯 V 步必落入环。
2. SPFA 如何检测负权环？
   要点：统计顶点入队次数，超过 V 次说明存在负环。
3. 不可达的负权环为何不影响单源最短路？
   要点：最短路只在源可达子图内定义，环不可达则不会被经过。
4. 为什么「再松弛一轮」足够？多轮不行吗？
   要点：V-1 轮已收敛，第 V 轮还能松弛即证明存在 >V-1 条边的更短路径，必含环。
5. Floyd-Warshall 如何判负环？为何只看对角线？
   要点：`dist[i][i] < 0` 表明存在从 $i$ 回到 $i$ 的负权和闭合路径；对角线是所有环的必经交汇点。
6. 如何把「全图判环」归约成单源问题？
   要点：加超级源以 0 权连所有顶点，任意负环即变为源可达，跑一次 Bellman-Ford 即可覆盖全图。

## 九、演进与趋势
在实际路网/金融套利中，常先跑 SPFA 入队计数快速探测；对全图判环可用 SCC 缩点后仅在负权强连通分量内检测；最小费用流用「负环即代表可改进」不断增广（Bellman-Ford/SPFA 找增广路）。

算法工程上还有若干实用改进：用「每轮只松弛上轮被更新顶点的出边」的队列式松弛降低常数；用「按顶点分层 + 位集」加速稠密图；在动态图场景下维护增量负环检测（边权变化后局部重算而非全局重跑）。这些优化的共同点是不改变判定条件本身，只降低到达条件的代价。

## 十、小结
负权环检测在 Bellman-Ford 跑完 $V-1$ 轮后再松弛一轮：仍有边可松弛即存在从源可达的负权环，复杂度 $O(VE)$。沿前驱回溯可还原环本身，是套利检测、差分约束与费用流的基础工具，关键在「用还能松弛而非值为负」来判定。

记忆要点三条：判定看「第 $V$ 轮是否仍能松弛」，定位看「沿 pred 回溯 $V$ 步」，扩到全图看「超级源或 SCC 缩点」。掌握这三点即可覆盖绝大多数工程场景。
