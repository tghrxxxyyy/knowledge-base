# 负权环检测

> 对应 CLRS。

## 一、背景与挑战
负权环使最短路无意义（可无限绕圈减权）。需要判定图中是否存在从源可达的负权环。

## 二、核心原理
在 Bellman-Ford 跑完 $V-1$ 轮后再松弛一轮：若仍有边可松弛，说明存在经过该边的负权环（某点被第 $V$ 次更新）。

## 三、形式化与数学基础
无负环时 $V-1$ 轮已收敛；再一轮仍更新即证明存在零权或负权环：
附加检测 $O(E)$，总 $O(VE)$。

## 四、代码实现
```python
def has_negative_cycle(edges, n, src):
    dist = [float("inf")] * n
    dist[src] = 0
    for _ in range(n - 1):
        for u, v, w in edges:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
    for u, v, w in edges:
        if dist[u] + w < dist[v]:
            return True
    return False
```

## 五、与其他技术对比
相比直接跑 Dijkstra（会错），负权环检测必须用 Bellman-Ford/SPFA；也可用 Floyd 检测任意负环 $O(V^3)$。

## 六、常见误区
只判断 `dist` 变负不等于负环；必须用「还能松弛」判定。未初始化源可达性会漏判不可达负环。

## 七、与开源书/权威来源对应
CLRS 第 24.1 节负权环；Sedgewick《Algorithms》。

## 八、面试题
如何找负权环（而不仅是判定）？SPFA 如何检测？

## 九、演进与趋势
SPFA + 入队次数阈值检测；在套利检测、差分约束中应用。

## 十、小结
负权环检测在 Bellman-Ford 后再松弛一轮，仍有更新即存在负权环，复杂度 $O(VE)$。
