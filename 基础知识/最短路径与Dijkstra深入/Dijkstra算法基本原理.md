# Dijkstra算法基本原理

> 对应 Dijkstra 1959（A Note on Two Problems in Connexion with Graphs）与 CLRS 第 24.3 节（Dijkstra 算法）。

## 一、背景与挑战
单源最短路径是图算法的基石（路由、地图、调度）。Dijkstra 在「边权非负」前提下，用贪心策略每次确定「当前离源最近、且未确定」的顶点，并以其松弛邻居。其精妙之处在于：非负权保证一个顶点一旦被按最小 dist 选出，它的最短路就再也不会被后续更短路径更新——这正是贪心正确的关键。负权会使该不变量失效，故 Dijkstra 不支持负权。

理解 Dijkstra 的关键在于「贪心正确性依赖的不变式」，以及它为何只适用于非负权。这也是它区别于 Bellman-Ford 的本质：Dijkstra 是贪心 + 优先队列，Bellman-Ford 是动态规划 + 全边松弛。

从历史看，Dijkstra 1959 的原始论文同时给出了两个问题：最短路径与最小生成树。二者都用贪心，但「选的依据」不同——最短路按「到源的距离」，生成树按「到已选集合的距离」。这一对照有助于记住为什么同样的贪心框架在两种问题上都成立，却得到不同结果。

## 二、核心原理
维护 dist 数组与「已确定（done）」集合。每轮：在未确定顶点中选 dist 最小者，标记 done，然后对其每条出边做松弛。朴素实现用线性扫描选最小。算法正确性依赖不变式：done 集合中的顶点 dist 已是最优，且不会再被更新。松弛时仅对未确定邻居更新，避免破坏不变量。done 集合本质是「已确定最短路的顶点集」，其规模每轮 +1。

直观例子：源到 A 已确定 dist=3，后续即使发现经 B 到 A 的路径，因边权非负，经 B 也至少 dist[B]+w ≥ 3，不可能更优——这就是贪心安全性的直觉来源。

「不再更新已确定顶点」这条规则在实践中常被省略（例如直接对所有邻居松弛），在无负权时结果仍正确，因为对已确定顶点的松弛不可能成功。但显式跳过它有两点好处：语义清晰、且在实现有 bug（如负权输入）时能更早暴露问题。严格实现建议显式判断。

Dijkstra 还有一个重要性质：它求出的 dist 数组同时构成一棵「最短路径树」（SPT），若记录前驱则任意顶点的最短路径可回溯得到。SPT 与原图的关系是「每条树边满足 dist[v] = dist[u] + w(u,v)」——这个等式可作为实现正确性的自检条件。

## 三、形式化与数学基础
稠密图（邻接矩阵）下，每轮线性扫描选最小 $O(V)$，松弛 $O(V)$，共 $V$ 轮：
$$T = O(V^2)$$
要求边权 $w \ge 0$。贪心正确性证明用「切割性质」：把 done 与未确定分成两集合，跨切割的最小边必属于某最短路；选全局最小 dist 等价于选跨切割最小边。负权会破坏「选出的顶点不再被更新」，故失效。更一般地，Dijkstra 等价于在非负权图上做「按距离递增的 BFS」。

切割性质的严格陈述：设 $S$ 为已确定集合、$V \setminus S$ 为未确定集合，$u^* = \arg\min_{v \notin S} dist[v]$。若存在一条从源到 $u^*$ 的更短路径，则该路径必在某个点 $x \notin S$ 处「首次离开 $S$」，于是 $dist[x] < dist[u^*]$，与 $u^*$ 的最小性矛盾。这一证明只用到「路径前缀距离单调不减」，而这正由 $w \ge 0$ 保证。

复杂度还有另一视角：朴素实现是 $O(V^2 + E)$，堆优化是 $O((V+E)\log V)$。二者的交叉点是 $E \approx V^2 / \log V$，超过该点朴素版更优——这给出「稠密图用朴素、稀疏图用堆」的定量依据。

## 四、代码实现
```python
# 朴素 Dijkstra：邻接矩阵，O(V^2)
def dijkstra_naive(graph, src):
    n = len(graph)
    dist = [float("inf")] * n
    dist[src] = 0
    done = [False] * n
    for _ in range(n):
        # 线性扫描选最小未确定点
        u = -1
        best = float("inf")
        for i in range(n):
            if not done[i] and dist[i] < best:
                best, u = dist[i], i
        if u == -1:
            break
        done[u] = True
        for v in range(n):
            if graph[u][v] > 0 and not done[v]:
                dist[v] = min(dist[v], dist[u] + graph[u][v])
    return dist
```

若需要路径与正确性自检，可同时记录前驱并验证树边等式：

```python
def check_spt(dist, prev, graph, src):
    for v in range(len(dist)):
        if prev[v] != -1:
            u, w = prev[v], graph[prev[v]][v]
            # 最短路径树的性质：dist[v] == dist[u] + w(u, v)
            assert dist[v] == dist[u] + w, f"SPT violated at {v}"
```

## 五、与其他技术对比
| 维度 | 朴素 Dijkstra | 堆优化 Dijkstra | Bellman-Ford | A* |
| --- | --- | --- | --- | --- |
| 复杂度 | $O(V^2)$ | $O((V+E)\log V)$ | $O(VE)$ | $O(E\log V)$ 目标导向 |
| 负权 | 不支持 | 不支持 | 支持 | 不支持 |
| 适合 | 稠密图 | 稀疏图 | 负权/检测环 | 单目标 |
| 负权环检测 | 无 | 无 | 原生 | 无 |
| 启发函数 | 无 | 无 | 无 | 必需（可采纳） |
| 全源扩展 | 跑 V 次 | 跑 V 次 | 跑 V 次 | 不适用 |

Dijkstra 与 Prim 常被对比：二者都用「选最小者」的贪心，但 Prim 的键是「到已有树的最小边权」、目标是覆盖所有顶点（生成树）；Dijkstra 的键是「到源的最短距离」、目标是给出路径代价。同一框架、不同目标函数，是理解贪心算法的经典范例。

## 六、常见误区
1. 存在负权边时仍用 Dijkstra。已确定顶点可能被更短负权路径更新，结果错误。
2. `graph[u][v] > 0` 误判。此判断仅当「0 表示无边」成立；若允许 0 权边需改用 `dist` 比较或无穷大哨兵。
3. 以为 Dijkstra 输出的是「任意两点」最短路。它是单源算法，全源需跑 V 次或改用 Floyd。
4. 以为所有边权都能用。若边权含负数或 NaN，不变量失效/松弛异常。
5. 以为「不跳过 done 顶点」是等价实现。在无负权时结果相同，但有负权时会静默出错，失去可诊断性。
6. 忽略不连通图的情况。源不可达顶点的 dist 保持为无穷，需在输出层显式处理（如标记不可达）。
7. 以为优先队列是必需的。朴素版用一个简单的线性扫描即可，教学与小图场景下更清晰。

## 八、面试题
1. 为什么 Dijkstra 要求边权非负？
   要点：非负保证「按最小 dist 选出即最终确定」，负权破坏该不变量。
2. Dijkstra 与 Prim 的相似与不同？
   要点：都用贪心选最小边；Prim 求最小生成树（按到树距离），Dijkstra 求最短路（按到源距离）。
3. 朴素实现复杂度？何时优于堆优化？
   要点：$O(V^2)$；稠密图（$E \approx V^2$）时优于堆版。
4. 若图中有负权边，Dijkstra 会如何出错？
   要点：已确定顶点可能被经负权边的更短路径更新，但算法不再重算，结果偏大或错。
5. Dijkstra 的输出如何自检？
   要点：验证最短路径树等式 $dist[v] = dist[u] + w(u,v)$，以及 dist[v] 不超过任何邻居的 $dist[u]+w$。
6. 零权边会破坏正确性吗？
   要点：不会，$w \ge 0$ 已包含 0；但邻接矩阵用「>0 表示有边」的写法会误判，需换判据。

## 九、演进与趋势
稀疏图用堆优化；路网寻路用双向 Dijkstra、ALT；目标导向用 A*；并行化有 Δ-stepping；理论最优（非负整数权）用 Dial 桶队列 $O(V+E)$。现代图数据库（如 Neo4j）对 Dijkstra 做双向 + 剪枝以处理大规模图。

在工程中，Dijkstra 还被用于「带约束的最短路」变体：如限制跳数（$k$ 短路）、限制资源消耗（标签修正法），这些变体保留了「按 dist 递增扩展」的骨架，只是扩展对象从顶点变成「顶点 + 资源状态」。

## 十、小结
Dijkstra 以非负权下的贪心「确定最近点」求单源最短路，朴素实现 $O(V^2)$，是图算法基石。其正确性根植于「非负权 ⇒ 选出即确定」的不变量，负权场景须改用 Bellman-Ford 或 SPFA，稠密图可保留朴素版、稀疏图用堆优化。掌握切割性质的证明思路，就真正理解了贪心为什么在这一问题上有效。
