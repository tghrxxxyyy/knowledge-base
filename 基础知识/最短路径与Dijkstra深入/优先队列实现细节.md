# 优先队列实现细节

> 对应 Cormen 等。

## 一、背景与挑战
Dijkstra 的性能与正确性高度依赖优先队列实现：如何处理距离被更新的过期条目。

## 二、核心原理
用 `(dist, node)` 元组入堆；弹出时若 `dist > 当前已知 dist` 说明是过期副本，直接跳过。也可显式 `decrease-key`，但二叉堆通常用懒删除替代。

## 三、形式化与数学基础
懒删除使每个节点最多入堆 `出度` 次，总堆操作 $O(E\log V)$；若支持 `decrease-key` 则可减到 $O(V\log V+E)$。

## 四、代码实现
```python
import heapq
def relax(pq, dist, u, v, w):
    if dist[u] + w < dist[v]:
        dist[v] = dist[u] + w
        heapq.heappush(pq, (dist[v], v))  # 懒删除：旧副本弹出时跳过
```

## 五、与其他技术对比
`decrease-key` 语义清晰但二叉堆实现麻烦；懒删除实现简单、代价是堆更大，实践中更常用。

## 六、常见误区
忘记跳过过期副本导致用旧距离松弛；元组比较在第二键 `node` 上需可比较（这里整数安全）。

## 七、与开源书/权威来源对应
Cormen 等讨论 decrease-key 与懒删除；CLRS 习题。

## 八、面试题
decrease-key 与懒删除的取舍？为什么堆里存 (dist, node)？

## 九、演进与趋势
配对堆、斐波那契堆在特定场景降低理论界；索引堆（支持随机访问）利于 decrease-key。

## 十、小结
优先队列的懒删除是 Dijkstra 工程实现的关键，用过期副本跳过保证正确且简单。
