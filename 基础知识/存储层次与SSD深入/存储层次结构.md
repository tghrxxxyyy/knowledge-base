# 存储层次结构

> 对应 CSAPP 中文笔记 https://github.com/Hansimov/csapp 第6章；OSTEP https://github.com/remzi-arpacidusse/ostep-code ；Tanenbaum《Modern Operating Systems》。

## 一、背景与挑战

速度与容量成反比：寄存器快但小，磁盘大但慢。层次结构用局部性把热数据放快层，平衡成本与性能。

## 二、核心原理

金字塔：寄存器>L1>L2>L3>内存>SSD>HDD>磁带。每层为上层缓存，依据时间/空间局部性。命中则快，缺失向下层取并可能回填。

## 三、形式化 / 数学基础

平均访问时间(两层为例)：

$$AMAT = h \times T_{fast} + (1-h) \times (T_{fast} + T_{slow})$$

$h$ 命中率。容量越大、越靠近通常越慢但命中率越高。

## 四、代码实现

```c
// 顺序访问利用空间局部性，命中缓存层
for (size_t i = 0; i < N; i++)   // 步长1连续
    sum += arr[i];
// 随机大步长则反复 miss
```

## 五、与其他技术对比

- 缓存自动透明；主存需 OS 管理；SSD/HDD 需文件系统。
- 越上层越贵每字节。

## 六、常见误区

- 误以为层次透明无代价：缺失延迟叠加。
- 忽视写策略(直写/写回)影响。

## 八、面试题

- 为何分层次？答：速度/容量/成本权衡，靠局部性。
- AMAT 公式？答：命中快 + 缺失加慢层。

## 九、演进与趋势

NVM(持久内存)插入内存与 SSD 之间，模糊层次。

## 十、小结

存储层次以局部性把性能与成本折中，是系统设计基础。
