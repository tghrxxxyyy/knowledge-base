# 磨损均衡

> 对应 OSTEP https://github.com/remzi-arpacidusse/ostep-code ；闪存可靠性公开资料定性。

## 一、背景与挑战

NAND 每块擦除寿命有限(数百至数千次)。若某些块频繁写(如日志)，会先坏，缩短整盘寿命。磨损均衡(Wear Leveling)均匀化擦除。

## 二、核心原理

动态磨损均衡：把新写尽量分到擦除次数少的块。静态磨损均衡：把只读冷数据从低擦除块搬走，让这些块参与轮换。FTL 记录每块擦除计数并据此分配。

## 三、形式化 / 数学基础

若块 $i$ 擦除次数 $e_i$，目标均衡：

$$\max_i e_i - \min_i e_i \le \epsilon$$

寿命近似：

$$Endurance \approx \frac{BlockEraseMax \times NumBlocks}{WriteAmp \times WritesPerDay}$$

## 四、代码实现

```c
// 磨损均衡：选擦除次数最小的空闲块
uint32_t pick_block() {
    uint32_t best = 0;
    for (b in blocks) if (erase_cnt[b] < erase_cnt[best]) best = b;
    return best;
}
```

## 五、与其他技术对比

- 动态只管热数据；静态处理冷数据更彻底。
- 与 TRIM/GC 协同降低不必要擦除。

## 六、常见误区

- 误以为均衡无代价：冷数据搬移耗写放大。
- 忽视预留空间(over-provisioning)对均衡的帮助。

## 八、面试题

- 磨损均衡目的？答：均摊擦除，延长寿命。
- 静态 vs 动态？答：是否搬冷数据参与轮换。

## 九、演进与趋势

3D TLC/QLC 配合更强均衡与纠错维持可靠性。

## 十、小结

磨损均衡是 SSD 可靠性的关键，靠均匀擦除对抗物理寿命限制。
