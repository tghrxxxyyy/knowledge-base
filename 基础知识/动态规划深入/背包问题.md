# 背包问题

> 对应 CLRS《Introduction to Algorithms》与《算法竞赛入门经典》背包章节。

## 一、背景与挑战
给定 n 件物品（重量 w、价值 v）与容量 C，求最大价值。变体包括 0/1、完全、多重、分组、依赖背包。

## 二、核心原理
0/1 背包：`f[i][j] = max(f[i-1][j], f[i-1][j-w_i] + v_i)`；滚动数组可降为一维，注意完全背包要正序遍历容量。

## 三、形式化 / 数学基础
0/1 背包转移：
$f[j] = \max(f[j],\; f[j-w_i] + v_i),\quad j\leftarrow C \text{ downto } w_i$
完全背包：
$f[j] = \max(f[j],\; f[j-w_i] + v_i),\quad j\leftarrow w_i \text{ to } C$

## 四、代码实现
```python
def knapsack01(w, v, C):
    f = [0] * (C + 1)
    for i in range(len(w)):
        for j in range(C, w[i] - 1, -1):
            f[j] = max(f[j], f[j - w[i]] + v[i])
    return f[C]
```

## 五、与其他技术对比
与贪心（分数背包）不同：0/1 背包不能贪心，必须用 DP；多重背包可用二进制拆分转 0/1。

## 六、常见误区
0/1 背包误用正序遍历（变成完全背包）；容量边界写错；多重背包不拆分直接循环导致错误。

## 八、面试题
「零钱兑换」是最少硬币（完全背包计数/最值）；「分割等和子集」是可行性 0/1 背包。

## 九、演进与趋势
单调队列优化多重背包 O(nC)→O(n log C)；结合 bitset 加速可行性判定。

## 十、小结
背包是 DP 入门范式：掌握一维滚动与遍历方向，即可推广到绝大多数资源分配类问题。
