# 单调优化

> 对应 《算法竞赛进阶指南》（李煜东）单调队列与斜率优化章节，以及 Amato, Blum 等人关于决策单调性的分析与 Li Chao 线段树。

## 一、背景与挑战

形如
$$
dp[i] = \min_{j < i} \big( dp[j] + w(i, j) \big)
$$
的转移，朴素枚举 $j$ 是 $O(n^2)$。当 $n = 10^5$~$10^6$ 时直接爆掉。**单调优化**利用转移代价 $w(i,j)$ 的结构——**决策单调性**或**可斜率分解的凸性**——把每步的「候选 $j$」维护成有序队列/凸壳，摊还 $O(1)$ 或 $O(\log n)$，总复杂度降到 $O(n)$ 或 $O(n \log n)$。

典型场景：
1. **滑动窗口最值**：单调队列维护窗口内最大/最小，$O(n)$。
2. **多重背包单调队列优化**：按容量模重量分组，组内滑动窗口最值，$O(nC)$。
3. **斜率优化（Convex Hull Trick, CHT）**：转移形如 $dp[i] = \min_j (b_j + a_j \cdot x_i)$，用凸壳维护直线族，$O(n)$ 或 $O(n \log n)$。
4. **决策单调性 + 分治**：$w$ 满足四边形不等式，最优决策点单调，分治 $O(n \log n)$。

朴素做法为什么不行？枚举所有 $(i,j)$ 对是 $O(n^2)$；用数据结构暴力查询「最小值」但状态含 $j$ 与 $i$ 的乘积项时无法直接线段树化。关键是发现**最优决策点的单调性**或**转移对 $j$ 是线性的**，才能用队列/凸壳剪掉无效候选。

在工程与面试中，单调队列是「滑动窗口最大值」的标准答案，斜率优化是竞赛进阶常考（打印文章、任务安排、玩具装箱）。读完本篇，你应能写出单调队列、推导斜率形式、识别决策单调性，并知道与线段树/李超线段树优化的边界。

## 二、核心原理

**单调队列（Monotone Queue）**。维护双端队列，队内下标对应值单调递减（求最大）或递增（求最小）。每次新元素 $x$ 进队前弹掉队尾所有比 $x$ 差（小）的元素；队首若滑出窗口则弹掉。队首即窗口最值。每个元素进出队各一次，均摊 $O(1)$。

**斜率优化（CHT）**。转移写成
$$
dp[i] = \min_{j < i} \big( b_j + a_j \cdot x_i \big),
$$
其中 $b_j$ 含 $dp[j]$，$a_j$ 含与 $j$ 有关的系数，$x_i$ 是只与 $i$ 有关的自变量。把候选 $j$ 看成直线 $y = a_j x + b_j$，查询 $x = x_i$ 时的最小值，即在凸壳上二分（或单调队列）找切线。若 $a_j$ 单调，则可用单调队列维护凸壳，$O(n)$；否则用 Li Chao 线段树 $O(n \log n)$。

**决策单调性**。$w$ 满足四边形不等式：$w(a,c) + w(b,d) \le w(a,d) + w(b,c)$ 对 $a \le b \le c \le d$，则最优决策点 $opt[i]$ 关于 $i$ 单调不降。可用分治（solve $(l,r,opt_l,opt_r)$）或单调队列维护决策区间，总 $O(n \log n)$ 或 $O(n)$。

**为什么正确**。
- 单调队列：窗口内若 $j_1 < j_2$ 且 $val[j_1] \le val[j_2]$，则 $j_1$ 永远不比 $j_2$ 差，$j_2$ 可淘汰（后进者更晚滑出）。保持「队内值单调」后，队首必为窗口最优。
- 斜率优化：两条直线 $l_1, l_2$，交点 $x_{12} = (b_2 - b_1)/(a_1 - a_2)$。若 $x_i$ 递增，交点右侧 $l_2$ 更优，左侧 $l_1$ 更优，故凸壳上查询点右移时，队首直线过期即弹出。这要求 $x_i$ 单调或用二分。
- 决策单调性：四边形不等式保证「若 $j$ 在 $i$ 处最优，则在 $i' > i$ 处最优决策点 $\ge j$」，剪掉大段枚举。

**边界条件**。单调队列要存下标（判断窗口越界）而不是值；斜率比较要处理斜率相等与整数除法方向；决策单调性分治要正确传递 $opt$ 区间。

## 三、形式化与数学基础

**滑动窗口最值**。对序列 $a[0..n-1]$、窗口 $k$，维护队列 $q$ 存下标：
1. `while q and a[q[-1]] <= x: q.pop()`（求最大，保留更大的）
2. `q.append(i)`
3. `if q[0] == i - k: q.popleft()`（滑出）
4. `if i >= k-1: ans.append(a[q[0]])`
均摊 $O(n)$，每个下标至多进队出队各一次。

**多重背包单调队列**。转移
$$
dp[c] = \max_{0 \le t \le s,\ tw \le c} \big( dp_{\text{prev}}[c - t w] + t v \big).
$$
令 $c = q w + r$，$t = q - k$，则
$$
dp[q w + r] = \max_{k \in [q-s, q]} \big( dp_{\text{prev}}[k w + r] + (q - k) v \big)
= q v + \max_{k} \big( dp_{\text{prev}}[k w + r] - k v \big).
$$
对固定 $r$，$k$ 递增时用单调队列维护 $dp_{\text{prev}}[k w + r] - k v$ 的窗口最大值，总 $O(n C)$。

**斜率优化推导（典型）**。$dp[i] = \min_{j<i} \big( dp[j] + (sum_i - sum_j)^2 \big)$。展开：
$$
dp[j] + sum_j^2 = 2\,sum_i\cdot sum_j + dp[i] - sum_i^2.
$$
令 $y_j = dp[j] + sum_j^2$，$x_j = sum_j$，则 $y_j = 2\,sum_i \cdot x_j + (\text{constant})$。查询 $x_i = sum_i$、斜率 $k = 2\,sum_i$ 的直线与凸壳的最小截距。若 $sum_i$ 单调（前缀和递增），斜率单调，可用单调队列维护下凸壳，$O(n)$。

**决策单调性分治**。若 $opt[i]$ 单调，用 `solve(l, r, optl, optr)`：取 $mid$，暴力 $j \in [optl, optr]$ 找 $opt[mid]$，递归 `solve(l, mid-1, optl, opt[mid])` 与 `solve(mid+1, r, opt[mid], optr)`。总代价 $O(n \log n)$ 或 $O(n)$（若单层 $O(optr-optl)$）。

**李超线段树**。$a_j$ 不单调时，用线段树每节点存一条「当前区间最优直线」，插入新直线比较中点斜率，查询 $x$ 时走 $O(\log V)$ 路径。总插入 $O(n \log V)$、查询 $O(\log V)$。

**复杂度总结**。单调队列 $O(n)$；斜率优化（单调 $x_i$）$O(n)$；一般 CHT $O(n \log n)$；决策单调分治 $O(n \log n)$；李超树 $O(n \log V)$。

## 四、代码实现

三个完整例子：滑动窗口最大值、多重背包单调队列、斜率优化（玩具装箱/矩形面积型 `dp[i] = min dp[j] + (sum_i-sum_j)^2`）。

```python
"""单调优化：单调队列、多重背包队列优化、斜率优化（CHT）。"""
from __future__ import annotations

from collections import deque


# ---------- 1. 滑动窗口最大值 ----------
def max_sliding_window(nums: list[int], k: int) -> list[int]:
    dq: deque[int] = deque()  # 存下标，对应值单调递减
    out: list[int] = []
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] <= x:
            dq.pop()
        dq.append(i)
        if dq[0] == i - k:
            dq.popleft()
        if i >= k - 1:
            out.append(nums[dq[0]])
    return out


# ---------- 2. 多重背包单调队列优化 ----------
def knapsack_multiple_queue(weights, values, limits, capacity: int) -> int:
    dp = [0] * (capacity + 1)
    for w, v, s in zip(weights, values, limits):
        if w == 0:
            continue
        new_dp = dp[:]
        for r in range(w):
            dq: deque[int] = deque()  # 存候选 q
            q = 0
            while True:
                c = q * w + r
                if c > capacity:
                    break
                # val(q) = dp[c] - q*v，维护递减队列，窗口 [q-s, q]
                val = dp[c] - q * v
                while dq and dp[dq[-1] * w + r] - dq[-1] * v <= val:
                    dq.pop()
                dq.append(q)
                while dq and dq[0] < q - s:
                    dq.popleft()
                best = dp[dq[0] * w + r] + (q - dq[0]) * v
                if best > new_dp[c]:
                    new_dp[c] = best
                q += 1
        dp = new_dp
    return dp[capacity]


# ---------- 3. 斜率优化：dp[i] = min_j (dp[j] + (sum_i - sum_j)^2) ----------
def dp_slope_sum_sq(partial: list[int]) -> int:
    """
    partial: 长度 n 的序列 a，sum_i = a[0]+...+a[i]。
    dp[0] = 0；dp[i] = min_{j<i} dp[j] + (sum_i - sum_j)^2，另允许 j=i 表示单独一段 (sum_i)^2？
    这里实现经典玩具装箱型：dp[i] = min_{0<=j<i} (dp[j] + (S[i]-S[j])^2)，S 为前缀和（含 S[0]=0）。
    """
    n = len(partial)
    S = [0] * (n + 1)
    for i, a in enumerate(partial):
        S[i + 1] = S[i] + a

    dp = [0] * (n + 1)
    # 直线：y = 2*S[i]*x - S[j]^2 + dp[j]，查询 x=S[i] 下的最小
    # 用单调队列维护下凸壳，x_j = S[j] 递增
    dq: deque[int] = deque()  # 存 j

    def slope(j1: int, j2: int) -> float:
        """直线 j1 与 j2 的交点 x 坐标。"""
        # dp[j] + (S[i]-S[j])^2 = dp[j] + S[j]^2 - 2 S[i] S[j] + S[i]^2
        # 即 y_j = 2 S[i] * S[j] - S[j]^2 + dp[j]，最小截距
        # 交点：S[j1], S[j2] 为横坐标
        num = (dp[j1] + S[j1] * S[j1]) - (dp[j2] + S[j2] * S[j2])
        den = 2 * (S[j1] - S[j2])
        return num / den if den != 0 else 0.0

    for i in range(1, n + 1):
        # 弹出队首：若队首直线在 x=S[i] 处不如队首下一条
        while len(dq) >= 2:
            j1, j2 = dq[0], dq[1]
            # 在 x=S[i] 处 j1 是否优于 j2
            f1 = dp[j1] + (S[i] - S[j1]) ** 2
            f2 = dp[j2] + (S[i] - S[j2]) ** 2
            if f1 >= f2:
                dq.popleft()
            else:
                break
        j = dq[0] if dq else i - 1
        dp[i] = dp[j] + (S[i] - S[j]) ** 2

        # 插入 i：维护下凸壳，弹出使凸性破坏的尾部
        while len(dq) >= 2:
            j1, j2 = dq[-2], dq[-1]
            # 交点(j1,j2) >= 交点(j2,i) 则 j2 无用
            x12 = slope(j1, j2)
            x23 = slope(j2, i)
            if x12 >= x23:
                dq.pop()
            else:
                break
        dq.append(i)

    return dp[n]


# ---------- 4. 暴力对照 ----------
def dp_slope_bruteforce(partial: list[int]) -> int:
    n = len(partial)
    S = [0] * (n + 1)
    for i, a in enumerate(partial):
        S[i + 1] = S[i] + a
    dp = [0] * (n + 1)
    for i in range(1, n + 1):
        dp[i] = min(dp[j] + (S[i] - S[j]) ** 2 for j in range(i))
    return dp[n]


if __name__ == "__main__":
    assert max_sliding_window([1, 3, -1, -3, 5, 3, 6, 7], 3) == [3, 3, 5, 5, 6, 7]
    print("window:", max_sliding_window([1, 3, -1, -3, 5, 3, 6, 7], 3))

    a = knapsack_multiple_queue([1, 2, 3], [1, 2, 3], [3, 2, 1], 6)
    print("multiple queue:", a)

    seq = [1, 2, 3, 4]
    fast = dp_slope_sum_sq(seq)
    slow = dp_slope_bruteforce(seq)
    assert fast == slow, (fast, slow)
    print("slope dp:", fast, "brute:", slow)

    seq2 = [5, 1, 8, 3]
    assert dp_slope_sum_sq(seq2) == dp_slope_bruteforce(seq2)
    print("all ok")
```

滑动窗口 `[1,3,-1,-3,5,3,6,7], k=3` 得 `[3,3,5,5,6,7]`。斜率优化与暴力对照一致，验证了凸壳维护的正确性。

## 五、与其他技术对比

| 维度 | 暴力枚举 | 单调队列 | 斜率优化 CHT | 决策单调分治 | 李超线段树 | 线段树优化 |
|------|----------|----------|--------------|--------------|------------|------------|
| 时间 | $O(n^2)$ | $O(n)$ | $O(n)$ / $O(n\log n)$ | $O(n\log n)$ | $O(n\log V)$ | $O(n\log n)$ |
| 前提 | 无 | 窗口/单调 | $j$ 线性、$x_i$ 单调 | 四边形不等式 | 直线族 | 可区间查询 |
| 适用 | 小 $n$ | 滑窗、多重背包 | $(sum_i-sum_j)^2$ 型 | $w$ 满足四边形 | 一般直线 | 区间最值 |
| 常数 | 小 | 极小 | 小 | 中 | 中 | 中大 |

与线段树优化对比：单调队列仅支持固定/单调窗口；线段树能处理任意区间查询但常数大。与分治优化对比：决策单调分治不要求 $j$ 线性，适用更广但 $O(\log n)$ 因子。与凸壳对比：李超树处理 $a_j$ 不单调的情形。

## 六、常见误区

**队列里存值而非下标**。窗口越界无法判断，无法弹出过期元素。后果是窗口最值错误。必须存下标，用 `dq[0] == i - k` 判断滑出。

**斜率比较时未处理整数溢出或相等斜率**。用浮点 `slope()` 在大整数时精度丢失；斜率相等时交点无穷大，弹队逻辑要处理。后果是凸壳破坏、答案错。建议用交叉相乘避免除法：`x12 >= x23` 等价于乘积比较。

**决策单调性分治的 $opt$ 区间传错**。`solve(l,r,optl,optr)` 中 $mid$ 的最优决策点必须在 $[optl,optr]$，递归时区间收窄为 `[optl, opt[mid]]` 与 `[opt[mid], optr]`。后果是漏掉最优决策或复杂度退化。

**斜率优化时 $x_i$ 不单调却用单调队列**。$x_i$（如 $sum_i$）必须单调，否则队首弹出条件失效，要用二分或李超树。后果是答案错。

**多重背包队列窗口宽度错**。窗口应是 $[q-s, q]$，`while dq[0] < q - s: popleft`，$s$ 是限次。后果是超出限制次或漏选。

## 八、面试题

**1. 滑动窗口最大值怎么做？**
参考答案：单调递减双端队列存下标。新元素弹掉队尾更小的；队首若滑出窗口则弹掉；队首即窗口最大。均摊 $O(n)$。注意存下标判断过期，不存值。

**2. 多重背包如何用单调队列优化？**
参考答案：转移 `dp[c] = max(dp_prev[c-tw]+tv)`，按 $c \bmod w$ 分组，组内 $q$ 递增，维护 `dp_prev[k w + r] - k v` 的窗口最大值，窗口宽度为限次 $s$。总 $O(nC)$。

**3. 什么是斜率优化？何时用？**
参考答案：转移形如 $dp[i] = \min_j (b_j + a_j x_i)$ 时，把 $j$ 看成直线 $y=a_j x + b_j$，在凸壳上查询 $x_i$ 处最小截距。$a_j$ 与 $x_i$ 都单调时用单调队列 $O(n)$，否则李超树 $O(n \log n)$。典型：$(sum_i-sum_j)^2$ 型。

**4. 决策单调性是什么？如何用？**
参考答案：$w$ 满足四边形不等式时最优决策点 $opt[i]$ 单调。用分治 `solve(l,r,optl,optr)` 或单调队列维护决策区间，把 $O(n^2)$ 降到 $O(n \log n)$。不要求转移对 $j$ 线性。

## 九、演进与趋势

**李超线段树与动态 CHT**。支持任意顺序插入直线、在线查询，$O(\log V)$，用于 $a_j$ 不单调的斜率优化。

**WQS 二分（凸优化）**。处理「恰好选 $k$ 个」的限制：对选择次数加拉格朗日乘子，二分斜率，$O(n \log V)$。用于「最多 $k$ 次操作」「恰好 $k$ 段」的 DP。

**$(\min, +)$ 卷积与 SMAWK**。代数视角统一最短路、编辑距离、单调优化；SMAWK 在完全单调矩阵上 $O(n)$ 求每行最小值。

**并行与 SIMD**。滑动窗口、前缀最值用 SIMD 批量比较，常数再降。

**学习型凸壳**。用神经网络预测决策点分布，或在大规模推荐/广告出价 DP 中近似斜率优化。

## 十、小结

单调优化把「对每个 $i$ 找最优 $j$」的 $O(n^2)$ 枚举，利用结构性质压到 $O(n)$ 或 $O(n \log n)$：单调队列吃滑动窗口与多重背包，斜率优化吃 $j$ 线性且 $x_i$ 单调的凸壳，决策单调性吃四边形不等式，李超树处理一般直线。核心是识别「候选 $j$ 可被单调淘汰」——窗口滑出、凸壳切线右移、决策点单调。存下标、防溢出、保证单调性前提，是正确实现的三道关。
