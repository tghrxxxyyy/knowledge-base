# 单调优化

> 对应 《算法竞赛进阶指南》单调队列与斜率优化章节。

## 一、背景与挑战
形如 `dp[i] = min_{j<i}(dp[j] + w(i,j))` 的转移，若直接枚举 j 为 O(n^2)。当 w 满足决策单调性或可分化为线性形式时可优化到 O(n)。

## 二、核心原理
单调队列：窗口最值，维护候选 j 随 i 增大而淘汰；斜率优化：把转移写成 `y_j = k_i x_j + b` 用凸壳维护切线。

## 三、形式化 / 数学基础
滑动窗口最大值用双端队列，每个元素进出队各一次 O(n)。
斜率优化中转移 `dp[i] = dp[j] + (sum_i - sum_j)^2` 可化为：
$dp[j] + sum_j^2 = 2\,sum_i\cdot sum_j + dp[i] - sum_i^2$，以 `sum_j` 为横坐标维护下凸壳。

## 四、代码实现
```python
from collections import deque
def max_sliding_window(a, k):
    dq = deque()
    out = []
    for i, x in enumerate(a):
        while dq and a[dq[-1]] <= x:
            dq.pop()
        dq.append(i)
        if dq[0] == i - k:
            dq.popleft()
        if i >= k - 1:
            out.append(a[dq[0]])
    return out
```

## 五、与其他技术对比
与线段树优化 DP 相比，单调队列仅支持固定/单调窗口；分治优化适用于决策点单调但不便于凸壳的情形。

## 六、常见误区
队列里存值而非下标导致无法判窗口越界；斜率比较时未处理整数溢出或相等斜率。

## 十、小结
单调优化本质是把「对每个 i 找最优 j」的结构性质（单调/凸性）利用起来，把 O(n^2) 降到 O(n log n) 或 O(n)。
