# 最优子结构

> 对应 CLRS《Introduction to Algorithms》第 15 章 Dynamic Programming。

## 一、背景与挑战
动态规划（DP）适用于同时具备「最优子结构」与「重叠子问题」的问题。最优化问题的解可由子问题的最优解组合而成，若直接递归会指数爆炸，需要把子问题结果缓存复用。

## 二、核心原理
三步走：定义状态、写出状态转移方程、确定边界与计算顺序。状态通常刻画「做到第 i 个、当前代价/集合为 s」。

## 三、形式化 / 数学基础
最短路中的贝尔曼方程：
$dist[v] = \min_{(u,v)\in E}\big(dist[u] + w(u,v)\big)$
一般价值函数：
$V(s) = \max_{a}\big(R(s,a) + \gamma \sum_{s'} P(s'|s,a)\,V(s')\big)$
若子问题无重叠（如普通分治），则 DP 退化为朴素递归而不节省复杂度。

## 四、代码实现
```python
def fib_dp(n):
    if n < 2:
        return n
    dp = [0, 1]
    for i in range(2, n + 1):
        dp.append(dp[i-1] + dp[i-2])
    return dp[n]
```

## 五、与其他技术对比
与贪心不同：贪心要求局部最优即全局最优（贪心选择性质），DP 允许对全部子结构比较；与分治不同：分治子问题不重叠。

## 六、常见误区
误以为所有「可递归」问题都能 DP：必须存在重叠子问题；状态定义过粗导致转移无法表达；忽略计算顺序使依赖未就绪。

## 九、演进与趋势
从经典表驱动到「记搜（记忆化搜索）」写法；结合位运算、斜率优化的高维优化；与自动机/字符串结合（序列 DP）。

## 十、小结
最优子结构是 DP 的前提，状态定义的优劣直接决定复杂度，先想清楚「状态表示什么」再写转移。
