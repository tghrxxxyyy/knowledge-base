# 最优子结构

> 对应 CLRS《Introduction to Algorithms》第 15 章 Dynamic Programming，以及 Bellman《Dynamic Programming》(1957) 与 Sutton & Barto《Reinforcement Learning: An Introduction》中的 Bellman 方程。

## 一、背景与挑战

动态规划（Dynamic Programming, DP）是把「指数级递归」压成「多项式级填表」的通用方法。它适用的前提有两条常被并列提起：**最优子结构**（Optimal Substructure）与**重叠子问题**（Overlapping Subproblems）。最优子结构说的是：原问题的最优解可以由子问题的最优解组合而成；重叠子问题说的是：朴素递归会反复计算同一批子问题，缓存即可复用。两者缺一，DP 不成立或不省时间。

举一个反例帮助理解边界。**无权最短路径**有最优子结构：$s \to t$ 的最短路若经过 $u$，则 $s \to u$ 与 $u \to t$ 必须都是最短路，否则可拼出更短的 $s \to t$。但**无权最长简单路径**没有最优子结构：最长 $s \to t$ 路径的子段未必是最长的，因为拼接可能重复经过点。若把「最长路径」硬套 DP，得到的是错解。这是面试中区分「会写转移」与「懂适用条件」的关键。

在工程与面试里，最优子结构是「这题能不能 DP」的第一性原理。状态怎么定义、转移怎么写、复杂度怎么估，都建立在「子问题最优能拼出全局最优」之上。读完本篇，你应能判断一个新问题是否具备最优子结构、写出贝尔曼型递推、并知道与贪心/分治的分界线。它也是理解强化学习（价值函数、策略迭代）、最短路、背包、编辑距离等一众算法的统一语言。

## 二、核心原理

**三步走**。经典 DP 解法总可以拆成：
1. **定义状态**：状态 $dp[\cdot]$ 刻画「子问题的最优值」，例如 $dp[i]$ = 前 $i$ 个元素的最优答案，$dp[i][j]$ = 考虑到第 $i$ 个、容量为 $j$ 时的最优。
2. **写出转移**：$dp[s] = \mathrm{opt}_{a \in \mathcal{A}(s)} \{ \mathrm{cost}(s,a) + dp[\mathrm{next}(s,a)] \}$，其中 $\mathrm{opt}$ 是 $\min$ 或 $\max$。
3. **定边界与顺序**：最小规模子问题的值（如 $dp[0]=0$），以及计算顺序（递推顺序或记忆化），保证依赖的子问题先算完。

**最优子结构的形式化**。设原问题 $P$ 的解空间为 $\Omega(P)$，最优值 $f(P) = \mathrm{opt}_{x \in \Omega(P)} g(x)$。若存在分解 $P \to P_1, \ldots, P_k$ 与组合函数 $c$，使得
$$
f(P) = \mathrm{opt}_{a \in \mathcal{A}} c(a, f(P_1), \ldots, f(P_k)),
$$
则称 $P$ 具有最优子结构。注意这里必须是「**最优**值能拼出**最优**值」，而不是「某个解能拼出解」。

**为什么最优子结构成立**。通常用剪贴论证（cut-and-paste）：假设子问题不是最优，把子问题换成更优解，拼出的全局解更优，与原解最优矛盾。最短路、矩阵链乘、背包都能这样证明。反过来，最长简单路径不满足剪贴论证，因为「换成子问题最优解」可能引入重复顶点，不在可行解空间内。

**重叠子问题**。递归树中同一子问题出现多次。例如朴素递归算 Fibonacci 的 $F(5)$ 会重复算 $F(3)$ 多次。DP 用表或记忆化缓存，把指数压成多项式。若子问题不重叠（如归并排序的两侧），记忆化无益，那就是分治而非 DP。

**与贪心的分界**。贪心要求「贪心选择性质」：局部最优选择能导向全局最优，无需枚举所有子结构。DP 允许比较全部选项，更稳健但通常更贵。分数背包可贪心（按性价比），0/1 背包不可贪心，必须 DP。

## 三、形式化与数学基础

**贝尔曼最优性方程**。在最短路/动态规划中，价值函数满足
$$
V(s) = \min_{a \in \mathcal{A}(s)} \Big( R(s,a) + \sum_{s'} P(s' \mid s, a) \, V(s') \Big),
$$
或确定性情形
$$
dist[v] = \min_{(u,v) \in E} \big( dist[u] + w(u,v) \big).
$$
这是 Bellman-Ford、Dijkstra、DP 的共同骨架：当前最优 = 在所有一步动作下「立即代价 + 后续最优」的最优。

**矩阵链乘法**。给定维度 $p_0 \times p_1, p_1 \times p_2, \ldots, p_{n-1} \times p_n$，设 $m[i][j]$ 为乘积 $A_i \cdots A_j$ 的最小标量乘法次数：
$$
m[i][i] = 0, \qquad
m[i][j] = \min_{i \le k < j} \big( m[i][k] + m[k+1][j] + p_{i-1} p_k p_j \big).
$$
最优子结构：最优加括号方式在某个 $k$ 处最后一次乘法，左半与右半必须各自最优。剪贴论证：若左半不是最优，换成更优左半，总代价下降，矛盾。

**0/1 背包**。$dp[i][c]$ 为前 $i$ 件物品、容量 $c$ 的最大价值：
$$
dp[i][c] = \max \big( dp[i-1][c],\ dp[i-1][c - w_i] + v_i \big).
$$
最优子结构：选不选第 $i$ 件的决策下，剩余容量的子问题必须最优。复杂度 $O(nC)$，是伪多项式（$C$ 是数值而非输入长度）。

**Fibonacci 与记忆化**。$F(n) = F(n-1) + F(n-2)$。朴素递归时间 $T(n) = T(n-1)+T(n-2)+O(1) = \Theta(\varphi^n)$；记忆化后每个子问题算一次，时间 $\Theta(n)$、空间 $\Theta(n)$ 或滚动到 $\Theta(1)$。这展示了「重叠子问题」缓存的威力。

**不满足最优子结构的例子**。无权最长简单路径是 NP-hard：若子段用最优替换，可能重复顶点。若强行 DP 只能用状态压缩（枚举点集），复杂度 $O(2^n)$，正是因为它本质是指数的。

## 四、代码实现

下面给出三段代码：记忆化 Fibonacci（展示重叠子问题）、矩阵链乘法（最优子结构标准例）、以及 0/1 背包一维滚动。均可直接运行。

```python
"""最优子结构：记忆化递归、矩阵链乘法、0/1 背包。"""
from __future__ import annotations

from functools import lru_cache


# ---------- 1. 记忆化 Fibonacci：重叠子问题 ----------
@lru_cache(maxsize=None)
def fib(n: int) -> int:
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)


def fib_bottom_up(n: int) -> int:
    if n < 2:
        return n
    a, b = 0, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    return b


# ---------- 2. 矩阵链乘法：最优子结构 ----------
def matrix_chain(p: list[int]) -> tuple[int, list[list[int]]]:
    """p[i-1] x p[i] 是第 i 个矩阵的维度。返回 (最小乘法次数, 决策表)。"""
    n = len(p) - 1  # 矩阵个数
    m = [[0] * (n + 1) for _ in range(n + 1)]
    s = [[0] * (n + 1) for _ in range(n + 1)]  # 最优断点
    for length in range(2, n + 1):             # 区间长度
        for i in range(1, n - length + 2):
            j = i + length - 1
            m[i][j] = float("inf")
            for k in range(i, j):
                cost = m[i][k] + m[k + 1][j] + p[i - 1] * p[k] * p[j]
                if cost < m[i][j]:
                    m[i][j] = cost
                    s[i][j] = k
    return m[1][n], s


def print_optimal_parens(s: list[list[int]], i: int, j: int) -> str:
    if i == j:
        return f"A{i}"
    k = s[i][j]
    left = print_optimal_parens(s, i, k)
    right = print_optimal_parens(s, k + 1, j)
    return f"({left}{right})"


# ---------- 3. 0/1 背包一维滚动 ----------
def knapsack_01(weights: list[int], values: list[int], capacity: int) -> int:
    dp = [0] * (capacity + 1)
    for w, v in zip(weights, values):
        for c in range(capacity, w - 1, -1):   # 倒序保证每件只用一次
            dp[c] = max(dp[c], dp[c - w] + v)
    return dp[capacity]


if __name__ == "__main__":
    assert fib(10) == 55 == fib_bottom_up(10)
    print("fib(30) =", fib(30))

    dims = [10, 30, 5, 60, 25]   # A1=10x30, A2=30x5, A3=5x60, A4=60x25
    cost, s = matrix_chain(dims)
    print("matrix chain min cost:", cost)
    print("parens:", print_optimal_parens(s, 1, len(dims) - 1))
    assert cost == 5250

    w = [2, 3, 4, 5]
    v = [3, 4, 5, 6]
    assert knapsack_01(w, v, 8) == 10  # 选 2+3+5 或 3+5 等，最优 3+5=10? 2+3+5=10
    print("knapsack:", knapsack_01(w, v, 8))
    print("all ok")
```

矩阵链例中 $p = [10,30,5,60,25]$ 的最优加括号是 $((A_1 A_2) A_3) A_4$，代价 5250。背包倒序遍历是 0/1 背包的一维写法关键——正序会变成完全背包。

## 五、与其他技术对比

| 维度 | 递归暴力 | 记忆化 DP | 贪心 | 分治 |
|------|----------|-----------|------|------|
| 前提 | 可递归分解 | 最优子结构 + 重叠子问题 | 贪心选择性质 | 子问题不重叠 |
| 时间 | 常指数 | 多项式 | 通常 $O(n \log n)$ | $O(n \log n)$ 等 |
| 是否比较所有选项 | 是 | 是 | 否，只选局部最优 | 是（分而治之） |
| 例子 | 朴素斐波那契 | 背包、编辑距离 | 活动选择、分数背包 | 归并排序、快速排序 |
| 失败案例 | 超时 | 状态定义错则错 | 0/1 背包会错 | 重叠问题会超时 |

与强化学习对照：贝尔曼方程 $V = \min (R + \gamma P V)$ 正是 DP 在随机决策上的推广；策略迭代/值迭代是 DP 的不动点求解。与暴力搜索对比：DP 把「枚举解」变成「填子问题表」，关键在状态能压缩解空间。

## 六、常见误区

**误以为「可递归」就能 DP**。最长简单路径可递归，但无最优子结构，硬套 DP 得到错解或指数状态。必须先用剪贴论证验证最优子结构。后果是答案错误且难以调试。

**状态定义过粗**。例如背包只存 `dp[i]` 前 $i$ 件的最大价值而不存容量维度，转移无法表达「剩余容量」。后果是状态丢失信息，无法正确转移。状态必须恰好区分「影响未来决策」的信息。

**忽略计算顺序**。二维 DP 行列依赖搞反，或树形 DP 没用后序遍历，导致读到未计算的子问题。后果是运行时用了默认值，答案偏小/偏大。应画依赖图或用记忆化避免顺序问题。

**把「最优子结构」当成「子问题独立」**。子问题可以重叠（这正是 DP 的用武之地），但最优解的组合方式必须正确。把「重叠」误解为「不能 DP」，会错过优化。

**复杂度伪多项式不自知**。0/1 背包 $O(nC)$ 在 $C$ 极大（如 $10^{12}$）时不可行，需用 meet-in-the-middle 或值域 DP 换维度。应同时标注 $n$ 与数值大小。

## 八、面试题

**1. 怎么判断一个问题能否用 DP？**
参考答案：检查两条件——(a) 最优子结构：原问题最优解能由子问题最优解组合（用剪贴论证）；(b) 重叠子问题：朴素递归重复算同一批子问题。满足则定义状态、写转移、定边界。若只有 (a) 无 (b)，可能是分治；若无 (a)，不能 DP。

**2. 最长上升子序列（LIS）的 $O(n^2)$ 与 $O(n \log n)$ 状态差异？**
参考答案：$O(n^2)$ 状态 `dp[i]` = 以 $i$ 结尾的 LIS 长度，转移 `dp[i] = max(dp[j])+1`。$O(n \log n)$ 用 `tails[len]` = 长度为 len 的 LIS 最小结尾，贪心 + 二分替换。状态从「位置结尾」变成「长度结尾」，最优子结构被更紧凑地利用。

**3. 为什么无权最长简单路径没有最优子结构？**
参考答案：最长 $s\to t$ 路径的子段未必最长，因为「换成子段最优」可能引入重复顶点，不在简单路径解空间内。剪贴论证失败。故它是 NP-hard，不能多项式 DP（除非 $2^n$ 状态压缩）。

**4. 0/1 背包一维数组为何要倒序遍历容量？**
参考答案：正序时 `dp[c-w]` 可能已被本轮物品更新，等价于同一物品可放多次（完全背包）。倒序保证 `dp[c-w]` 来自上一轮（前 $i-1$ 件），实现每件最多一次。

## 九、演进与趋势

**记忆化与声明式 DP**。把转移写成 `functools.lru_cache` 或 Datalog/关系型递归，自动缓存与调序；Python `cache`、Julia 的 `@memoize`。

**随机与连续 DP**。贝尔曼方程推广到随机转移（MDP）、连续状态（HJB 方程），在强化学习、控制论、期权定价（Black-Scholes 可由 DP 推导）中是核心。

**代数 DP 与自动机**。字符串 DP 套 AC 自动机、多项式优化（$(\min, +)$ 卷积）把转移变成半环运算，统一了最短路、编辑距离、正则匹配。

**并行与外存 DP**。滚动数组、分层并行、外存分块，用于超大状态空间的科学计算。

**学习型 DP**。用神经网络近似价值函数（DQN、AlphaZero），把状态空间从显式表变成函数逼近，是「最优子结构 + 函数近似」的现代形态。

## 十、小结

最优子结构是 DP 的地基：最优解必须能由子问题最优解组合，剪贴论证是标准验证手段。重叠子问题则决定缓存是否值得。状态定义要恰好区分影响未来的信息，转移写成贝尔曼型，边界与顺序保证依赖就绪。与贪心（只做局部选择）、分治（子问题不重叠）相比，DP 用更宽的前提换来更稳的最优。看懂这一点，背包、矩阵链、编辑距离、强化学习价值迭代就成了同一套语言的不同方言。
