# 网络测量

> 对应 RFC 7799（主动/被动测量术语）；RFC 4656（OWAMP/TWAMP）。

## 一、背景与挑战
要运维和优化网络必须量化其性能（时延、丢包、抖动、带宽、路径）。测量方法需区分主动探测与被动抓取，并理解其偏差。

## 二、核心原理
主动测量：主动发探测包（ping、traceroute、TWAMP）测 RTT/路径/丢包，会占用少量带宽。被动测量：在设备上抓实际流量统计（NetFlow/sFlow），不打扰业务但有采样偏差。往返时延 RTT、单向时延、抖动、瓶颈带宽估算是核心指标。

## 三、形式化 / 数学基础
RTT：$RTT = t_{recv} - t_{send}$（带时间戳回显）。
丢包率：$p = (sent - received)/sent$（同序列号配对）。
抖动（RFC 3550）：$J = J + (|D(i-1,i)| - J)/16$，$D$ 为相邻时延差。
瓶颈带宽估算（packet pair/train）：$B \approx L_{train} / \Delta t_{arrival}$。

## 四、代码实现
```python
import subprocess
# 主动测量：用 ping 测 RTT（解析输出）
out = subprocess.check_output(["ping","-c","10","8.8.8.8"]).decode()
# 提取 rtt min/avg/max/mdev
```

## 五、与其他技术对比
主动测量有侵入但可控、可定位；被动测量无侵入但有采样与隐私问题。对比端到端 vs 路径分段测量（TWAMP 在网元部署）。

## 六、常见误区
误区一：ping 测的是应用层时延。错，是 ICMP 网络层，且可能被限速。误区二：单向时延能轻易测。错，需两端时钟同步（PTP/NTP）。误区三：丢包率 0 即健康。错，可能只是探测包被优先。
