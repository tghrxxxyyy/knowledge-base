# 租约的演进与趋势

> 对应 Gray & Lamport 2006（lease 原始论文）与 Hunt et al. 2010（ZooKeeper 用会话超时近似租约）。

## 一、背景与挑战
经典租约解决单资源独占，但云原生场景需要跨地域、跨服务的精细化授权，催生了多种扩展形态。

## 二、核心原理
现代租约演化为：会话租约（ZK）、fencing token、层级租约（父租约派生子租约）、以及带 CAS 的租约（用版本防重放）。

## 三、形式化与数学基础
层级租约中父租约有效期 T_p 约束子租约 $T_c \le T_p$，保证撤销父租约可级联回收全部子权利。

## 四、代码实现
# fencing token 防御陈旧写
def write_with_token(data, token, last_token):
    if token <= last_token:
        raise StaleWrite
    last_token = token
    apply(data)

## 五、与其他技术对比
- 对比原生锁：fencing 解决“锁释放后陈旧持有者写”问题。
- 对比心跳保活：会话租约更省消息。

## 六、常见误区
1. 以为有 lease 就不需要 fencing。
2. 层级租约撤销未级联。
