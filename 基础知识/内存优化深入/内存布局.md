# 内存布局

> 对应程序内存布局：代码段、数据段、堆、栈、mmap。

## 一、背景与挑战
理解进程虚拟地址空间的布局有助于诊断溢出、碎片、TLB 压力与换页。不同段拥有不同的权限与增长方向。

## 二、核心原理
- 典型布局（低到高）：text（只读可执行）、data/bss、heap（向上增长）、mmap 区、stack（向下增长）。
- 每个进程有独立页表，内核维护 VMA（虚拟内存区域）链表/树。
- 物理内存经分页（page）映射，默认页 4KB，可选大页（2MB/1GB）。
- 写时复制（COW）：fork/共享库只读页共享，写入时复制。

## 三、形式化 / 数学基础
- 虚拟地址拆分（x86-64 4KB 页）：$\text{addr} = [\text{PML4}][\text{PDPT}][\text{PD}][\text{PT}][\text{offset}]$，各 9/9/9/9/12 位。
- 页表项（PTE）含物理帧号 PFN 与标志位（R/W, U/S, P）。
- TLB 命中率影响：缺失代价约数百周期。
- 大页减少 TLB 项数与页表级数，降低缺页。

## 四、代码实现
```c
#include <unistd.h>
#include <stdio.h>
int global;                 // bss
int init = 1;               // data
int main() {
    int stack_var;          // stack
    int *heap = malloc(8);  // heap
    printf("stack:%p heap:%p data:%p\n",
           (void*)&stack_var, (void*)heap, (void*)&init);
    return 0;
}
```

## 五、与其他技术对比
- 栈分配：快、自动回收、大小受限；堆分配：灵活、需管理。
- 大页：减 TLB 缺失但增加碎片与分配粒度。
- mmap 文件：零拷贝读、与堆隔离。

## 六、常见误区
- 认为虚拟地址连续即物理连续（仅大页/特殊分配才保证）。
- 忽略 64 位地址空间虽大但 VMA 元数据有开销。
- 误用栈上大数组导致栈溢出（默认 8MB）。

## 九、演进与趋势
5 级页表支持更大地址；透明大页（THP）自动管理；内存分级（CXL）改变布局假设。

## 十、小结
内存布局决定生命周期与性能特征，理解段、分页、TLB 与 COW 是优化的基础。
