# 领域专用架构与加速器

> 对应 Hennessy & Patterson 2017/2019《Computer Architecture: A New Golden Age》图灵奖文章（真实来源）。

## 一、背景与挑战
通用处理器受功耗墙停滞，而 AI、图形、加密等领域负载呈爆发性增长。领域专用架构（DSA）以定制化数据通路换取数量级能效提升。

## 二、核心原理
DSA 针对特定领域（如矩阵乘、视频编解码）设计专用流水线与存储层次，减少通用控制开销、提高数据复用。TPU、GPU Tensor Core、NPU 均属此类。

## 三、形式化与数学基础
能效提升来自数据复用率 $R$：
$$Energy_{op} \propto \frac{1}{R},\quad R = \frac{Compute}{MemoryTraffic}$$
DSA 通过本地化缓冲把 $R$ 最大化，使每字节访存支撑更多运算，整体能效相对通用核提升 $10\times$~$100\times$。

## 四、代码实现
```c
// 矩阵乘DSA思想: 分块复用(示意)
void matmul_tile(float *A, float *B, float *C, int N, int T){
    for (int i=0;i<N;i+=T)
     for (int j=0;j<N;j+=T)
      for (int k=0;k<N;k+=T)
       for (int ii=i;ii<i+T;ii++)   // 块内高复用
        for (int jj=j;jj<j+T;jj++)
         for (int kk=k;kk<k+T;kk++)
          C[ii*N+jj] += A[ii*N+kk]*B[kk*N+jj];
}
```

## 五、与其他技术对比
通用 CPU 灵活但能效低；ASIC 能效最高但不可编程；DSA 在可编程性与能效间折中，优于 CPU、灵活于 ASIC。GPU 是并行通用而非严格 DSA。

## 六、常见误区
误以为 DSA 取代 CPU：它是协处理器，系统仍需通用核。误以为加速器总是更快：仅对匹配领域。

## 七、与开源书/权威来源对应
Hennessy & Patterson 2019 新黄金时代；量化方法 DSA 章；NVIDIA/Tensor 文档（厂商手册）。

## 八、面试题
问：DSA 为何能效高？答：数据复用高、控制开销低、存储层级定制。

## 九、演进与趋势
可重构 DSA、存算一体（PIM）、chiplet 集成专用单元是方向。

## 十、小结
领域专用架构是后 Dennard 时代突破功耗墙的主路径，把"以架构换能效"推向极致。
