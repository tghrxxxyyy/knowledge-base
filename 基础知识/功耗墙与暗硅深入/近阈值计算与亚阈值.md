# 近阈值计算与亚阈值

> 对应量化方法低功耗设计章与近阈值计算研究文献（如 Borkar 2011 近阈值计算，真实来源）。

## 一、背景与挑战
常规电压下动态功耗 $P\propto V^2$ 仍是瓶颈。近阈值（Near-Threshold，NTC）把 $V_{dd}$ 降到接近阈值电压，极致降功耗，但速度变慢、工艺偏差敏感性上升。

## 二、核心原理
当 $V_{dd}$ 接近 $V_t$，每开关能量骤降，适合"能效优先、延迟不敏感"的负载（传感、推理）。代价是频率大幅下降与 $V_t$ 失配导致良率/可靠性挑战。

## 三、形式化与数学基础
亚阈值电流：
$$I_{sub} \propto e^{\frac{V_{gs}-V_t}{nV_T}}$$
总能耗（含泄漏）在 $V_{dd}\approx V_t$ 附近取得最小能量点（MEP）：
$$\min_{V_{dd}} E_{op}(V_{dd}) = E_{dyn}+E_{leak}$$
但此时延迟最大，需并行弥补吞吐。

## 四、代码实现
```python
# 能量随电压曲线找最小能量点
import math
def energy(v, vt=0.4):
    edyn = 0.5 * v*v            # 正比v^2
    eleak = 0.01 * math.exp((vt - v)/0.05)  # 泄漏随压降低
    return edyn + eleak
best = min([(energy(v), v) for v in [i*0.05 for i in range(10,40)]])
print("最小能量点电压:", best[1])
```

## 五、与其他技术对比
超阈值 DVFS 易用、频率高；NTC 能效极致但慢且受偏差影响；二者可在 chip 内分区（关键路径超阈值、其余近阈值）。

## 六、常见误区
误以为越低电压越省总能量：泄漏反转使过低压反升能耗。误以为 NTC 可直接替代高频核。

## 七、与开源书/权威来源对应
Borkar 2011 近阈值计算；量化方法低功耗章；ISSCC 相关论文。

## 八、面试题
问：为何存在最小能量点而非越低越好？答：过低压泄漏占比上升，总能耗反弹。

## 九、演进与趋势
误差容忍计算、近似计算与 NTC 结合，用于 AI 推理等容错负载。

## 十、小结
近阈值计算以速度为代价换取能效极限，是暗硅时代的重要低功耗技术。
