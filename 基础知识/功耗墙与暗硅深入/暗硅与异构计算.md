# 暗硅与异构计算

> 对应 Venkatesh 等 2010《Dark Silicon and the End of Multicore Scaling》（真实作者年份）与 Hennessy & Patterson 论述。

## 一、背景与挑战
受功耗墙限制，芯片上并非所有晶体管可同时全速开启——剩余部分成为"暗硅"（dark silicon）。单纯堆多同构核受限于可点亮比例，需异构来提升能效。

## 二、核心原理
给定功耗预算，能效高的专用单元（GPU、DSP、ASIC 加速器）每瓦性能远超通用核。把合适任务卸载到专用单元，可在预算内完成更多工作，缓解暗硅。

## 三、形式化与数学基础
总性能受可激活面积约束：
$$Perf \le \sum_{i} \eta_i \cdot A_{i,on},\quad \sum_i P_i \le P_{budget}$$
其中 $\eta_i$ 为单元 $i$ 能效（perf/watt）。异构通过提高 $\eta_{specialized}$ 提升总 Perf。

## 四、代码实现
```python
# 选择能效最高的可用单元(示意)
units = [("CPU", 5), ("GPU", 40), ("ASIC", 200)]  # perf per watt
budget = 50  # 瓦
best = max(units, key=lambda u: u[1])
print("在预算内优先用", best[0], "能效", best[1])
# ASIC能效最高, 适合固任务卸载
```

## 五、与其他技术对比
同构多核受暗硅限制加速比饱和；异构用专用单元提升能效，但编程复杂、硬件灵活度低。chiplet 缓解制造良率。

## 六、常见误区
误以为核越多越好：暗硅限制可点亮数。误以为 ASIC 万能：仅对固定算法高效。

## 七、与开源书/权威来源对应
Venkatesh et al. 2010 Dark Silicon；量化方法异构；ARM Big.LITTLE。

## 八、面试题
问：暗硅为何限制多核扩展？答：功耗预算上限决定可同时激活的核数。

## 九、演进与趋势
领域专用架构（DSA）、可重构逻辑、chiplet 与 3D 堆叠是主流应对。

## 十、小结
暗硅迫使产业从"更多通用核"转向"更聪明的异构"，能效成为第一设计指标。
