# 指针分析与别名分析

> 对应 Aho 等《Compilers》第 12 章（指针分析）；Appel《Modern Compiler Implementation》第 21 章。

## 一、背景与挑战
C 的指针使"a 与 b 是否可能指向同一内存"成为多数优化（如公共子表达式、死存储）能否进行的前提。别名精度直接决定优化安全边界。

## 二、核心原理
别名分析回答：两点 p、q 是否可能指向同一对象。按上下文/流/域敏感度分档。经典 Andersen（含于，流不敏感）与 Steensgaard（并查集，更快但粗）。指针图节点为变量/字段，边为指向关系，经赋值语句传播。

## 三、形式化与数学基础
Andersen 约束传播：
$$p = &x \Rightarrow pts(p)\supseteq \{x\}$$
$$p = q \Rightarrow pts(p)\supseteq pts(q)$$
$$p = *q \Rightarrow \forall o\in pts(q),\ pts(p)\supseteq pts(o)$$
迭代至不动点；别名 $a\sim b \iff pts(a)\cap pts(b)\neq\emptyset$。

## 四、代码实现
```python
# Steensgaard 并查集（快速但粗）
def unify(a, b):
    ra, rb = find(a), find(b)
    if ra != rb: parent[ra] = rb   # 合并指向集
```

## 五、与其他技术对比
Andersen 精确（含于）但 O(n^3)；Steensgaard 近线性但过度合并；流敏感上下文敏感更准但指数爆炸，常用克隆法折中。

## 六、常见误区
1. 把"不同变量名"当"不同对象"——指针可别名。
2. 过度信任 noalias 导致错误优化——需确认无取址逃逸。
3. 把数组下标当独立对象，漏掉数组内别名。
