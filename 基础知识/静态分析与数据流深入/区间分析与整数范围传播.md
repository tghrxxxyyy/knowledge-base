# 区间分析与整数范围传播

> 对应 Aho 等《Compilers》第 9、12 章；Appel《Modern Compiler Implementation》第 21 章。

## 一、背景与挑战
数组下标是否越界、循环能否展开、除零是否可能，都需知道整数变量在某点的取值范围。区间分析以抽象域 $[lo,hi]$ 做轻量数值推理。

## 二、核心原理
每条语句用区间算术传播：加法 $[a,b]+[c,d]=[a+c,b+d]$，乘法取极值组合，除法需防零。汇合取区间并（lo 取 min，hi 取 max）。循环用上宽算子（widening）加速收敛到上近似。

## 三、形式化与数学基础
区间运算：
$$[a,b] \sqcup [c,d] = [\min(a,c), \max(b,d)]$$
$$[a,b] \times [c,d] = [\min(ac,ad,bc,bd), \max(ac,ad,bc,bd)]$$
宽度算子 $x \nabla y$ 在 $x$ 分量超 $y$ 时置 $\top$（±∞），强制终止。

## 四、代码实现
```python
def widen(x, y):
    lo = x.lo if x.lo <= y.lo else -INF
    hi = x.hi if x.hi >= y.hi else +INF
    return Interval(lo, hi)
```

## 五、与其他技术对比
区间域廉价但丢失相关性（不知 a==b）；多面体域（Polyhedra）可表达线性约束但复杂度高，工程上常分级组合。

## 六、常见误区
1. 用区间证明"无溢出"——仅上近似，漏报安全、误报则需细化。
2. 忘记除零使区间塌成 $\top$。
3. 循环无 widening 会不终止或低估上界。

## 九、演进与趋势
抽象解释框架（Cousot）把区间、多面体统一为可组合域，用于航天级认证。

## 十、小结
区间分析用保守数值域做廉价但安全的范围推理，是边界与溢出检查的主力。
