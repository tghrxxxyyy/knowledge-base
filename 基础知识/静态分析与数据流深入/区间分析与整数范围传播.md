# 区间分析与整数范围传播

> 对应 Cousot & Cousot 1977《Abstract Interpretation: A Unified Lattice Model for Static Analysis of Programs by Construction or Approximation of Fixpoints》；Blanchet 等 2003《A Static Analyzer for Large Safety-Critical Software》（Astrée）；Aho 等《Compilers》数据流分析章节。

## 一、背景与挑战
有一类问题需要的不是「变量等于几」，而是「变量在什么范围内」。数组下标是否越界、除以零是否可能、有符号与无符号转换是否溢出、循环能否被向量化、switch 分支能否被裁剪——这些都只要求一个安全的范围上界，而不要求精确值。

区间分析（interval analysis）是为这类问题设计的最轻量数值抽象域：把每个整数变量抽象成区间 $[lo, hi]$，用区间算术传播约束。它牺牲精度（丢失变量间相关性）换取极低的实现与计算成本，因而成为工业级静态分析器中最常用的数值域之一。

挑战有三层：第一，区间算术必须保持**可靠性**（soundness）——结果必须覆盖所有可能真实值，宁可放宽也不能收窄；第二，循环会让区间不断变宽，需要加宽算子保证终止；第三，很多关键性质依赖变量间关系（如 $i < n$ 与 $i \ge 0$），纯区间域无法表达，必须靠分支精化或更强的域补足。

## 二、核心原理
区间域的元素是 $[lo, hi]$（$lo \le hi$，可为 $\pm\infty$），外加两个特殊元素：$\bot$ 表示「不可达/无值」，$\top = [-\infty, +\infty]$ 表示「什么都不知道」。三条基本机制：

- **汇合（join）**：控制流合并取区间的凸包，下界取较小者、上界取较大者。这是精度损失的主要来源：一个分支里 $x \in [0,0]$、另一个分支 $x \in [10,10]$，汇合后是 $[0,10]$，丢掉了「只取两个值」的信息。
- **迁移（transfer）**：对每条语句做区间算术。加减乘按端点组合；除法必须先判断除数区间是否包含 0，若包含则退化；比较运算产生布尔结果并对操作数精化。
- **分支精化（refinement）**：遇到 `if (i < n)` 时，真分支把 $i$ 的上界收紧为 $\min(hi_i, hi_n-1)$，假分支反之。这是让区间分析在循环中真正有用的关键，否则循环变量的界永远收敛不了。

循环处理采用「迭代到不动点 + 加宽/收窄」组合：先用 widening 快速逼近一个不动的上界（可能过宽），再用 narrowing 在有限步内收回部分精度。

## 三、形式化与数学基础
区间域的核心运算（设 $[a,b]$ 与 $[c,d]$ 非空）：
$$[a,b] \sqcup [c,d] = [\min(a,c),\ \max(b,d)], \qquad [a,b] \sqcap [c,d] = [\max(a,c),\ \min(b,d)]$$
$$- [a,b] = [-b,-a], \qquad [a,b] + [c,d] = [a+c,\ b+d], \qquad [a,b] - [c,d] = [a-d,\ b-c]$$
$$[a,b] \times [c,d] = [\min(ac,ad,bc,bd),\ \max(ac,ad,bc,bd)]$$
乘法取四个端点积的极值是区间算术丢失相关性的典型场景：$x - x$ 得到 $[a-b,\ b-a]$ 而不是 $[0,0]$。

除法必须显式处理除零：
$$[a,b] \div [c,d]: \quad 0 \in [c,d] \;\Rightarrow\; \text{结果为 } \top$$
$$0 \notin [c,d] \;\Rightarrow\; \left[\min_{x \in [a,b],\, y \in [c,d]} \frac{x}{y},\ \max_{x \in [a,b],\, y \in [c,d]} \frac{x}{y}\right]$$
加宽算子 $\nabla$ 用于强制终止：当新一轮区间比上一轮更宽时，把变化方向直接推到无穷。
$$[a,b] \;\nabla\; [c,d] = [a', b'], \quad a' = \begin{cases} a & a \le c \\ -\infty & \text{否则}\end{cases},\quad b' = \begin{cases} b & b \ge d \\ +\infty & \text{否则}\end{cases}$$
收窄算子 $\Delta$ 在 widening 之后使用，只允许向内收缩且保持单调，从而在不破坏终止性的前提下提高精度（$a=-\infty$ 时取 $c$，$b=+\infty$ 时取 $d$）。可靠性论证：$\sqcup$、各迁移函数与 $\nabla$ 均单调，且值域高度有限，故迭代序列单调上升必有极限；极限处成立的性质对所有可达状态都成立（抽象解释的可靠性定理，见 Cousot & Cousot 1977）。

## 四、代码实现
一个可直接运行的最小实现，包含 widening 与分支精化。
```python
INF = float("inf")

class Iv:
    def __init__(self, lo, hi):
        self.lo, self.hi = lo, hi
    def __repr__(self):
        return "empty" if self.lo > self.hi else f"[{self.lo}, {self.hi}]"
    def join(self, o):
        if self.lo > self.hi: return o
        if o.lo > o.hi: return self
        return Iv(min(self.lo, o.lo), max(self.hi, o.hi))
    def widen(self, o):
        lo = self.lo if self.lo <= o.lo else -INF
        hi = self.hi if self.hi >= o.hi else INF
        return Iv(lo, hi)

def add(x, y):  return Iv(x.lo + y.lo, x.hi + y.hi)
def mul(x, y):
    cs = [x.lo*y.lo, x.lo*y.hi, x.hi*y.lo, x.hi*y.hi]
    return Iv(min(cs), max(cs))

def refine_lt(x, y, truth):
    # 处理 if (x < y)：真分支收紧 x 的上界，假分支抬高 x 的下界
    if truth:
        return Iv(x.lo, min(x.hi, y.hi - 1)), y
    return Iv(max(x.lo, y.lo), x.hi), y

# 循环 i = 0; while (i < n) { i = i + 1; }  其中 n 已知区间为 [0, 100]
n = Iv(0, 100)
i = Iv(0, 0)
for step in range(50):
    head, _ = refine_lt(i, n, True)        # 真分支：i <= n - 1
    nxt = add(head, Iv(1, 1))
    if nxt.hi <= i.hi and nxt.lo <= i.hi:  # 收敛判据
        i = i.join(nxt)
        break
    i = i.widen(nxt)                       # 强制有限步到达不动点
print("i after loop:", i)                  # 上界应被收紧到 100 附近
```
要点：去掉 widening，上界每轮 +1，收敛轮数与 $n$ 的量级相关，真实程序中不可接受；去掉分支精化，循环条件无法限制 $i$ 的上界，输出会退化成 $\top$。

## 五、与其他技术对比
| 抽象域 | 可表达的关系 | 复杂度（量级） | 精度 | 工程可用性 |
| --- | --- | --- | --- | --- |
| 区间 | 单变量上下界 | 低（端点运算） | 低（丢相关性） | 极高 |
| 同余 | $x \equiv a \pmod m$ | 低 | 与区间互补（奇偶、对齐） | 高 |
| 八边形 | $\pm x \pm y \le c$ | 中（矩阵运算） | 中 | 中 |
| 多面体 | 任意线性不等式 | 高（可能指数） | 高 | 低～中 |
| 符号/枚举 | 具体有限取值 | 低 | 高（仅限小集合） | 中 |

## 六、常见误区
- 认为区间分析能「证明无溢出」。它是上近似，只能证明某些不等式必然成立，无法证明程序完全无错。
- 忘记除零处理。除数区间含 0 时若不退化为 $\top$，会得到错误收窄的区间，导致不安全的优化。
- 不做 widening。循环上下界随迭代单调外扩，迭代可能不终止或需要极多轮。
- 过度使用 widening。直接推到 $\pm\infty$ 会丢掉全部精度，需配合 narrowing 或阈值加宽（在常量、指数等边界处暂停一下）。
- 忽略类型语义。有符号溢出是未定义行为、无符号回绕会破坏区间运算的单调性（如 $255+1$ 回到 $0$），必须按具体类型的值域运算。
- 忽略守卫精化却期待精度。没有分支精化时循环里几乎所有变量都会收敛到 $\top$。
- 混淆 $\bot$ 与 $\top$。$\bot$ 表示不可达、$\top$ 表示信息全失；初始化方向搞反会让分析变得不安全。

## 七、与开源书·权威来源对应
- Cousot & Cousot 1977：抽象解释的统一格模型，给出「抽象域 + 单调迁移 + 加宽」保证可靠性的一般定理。
- Blanchet 等 2003（Astrée）：在大型安全关键软件上实践区间、八边形、多面体等多域组合，说明工程上如何进行域分级与代价控制。
- Aho 等《Compilers》数据流分析章节：给出常量传播与格框架，区间分析可视为该框架在数值域上的推广。
- Muchnick《Advanced Compiler Design and Implementation》：编译器视角的数值分析与边界检查消除，说明区间如何用于优化决策。
- Miné 的数值不变量教程：系统整理区间、八边形、多面体的表达力与复杂度权衡。

## 八、面试题
1. 为什么区间分析是上近似？要点：抽象域无法表达全部具体状态，汇合取凸包、迁移必须放宽，因此结果总是包含真实值集合。
2. widening 的作用是什么？要点：把持续外扩的区间直接推到无穷，保证迭代在有限步到达不动点，代价是精度损失。
3. 为什么还需要 narrowing？要点：widen 得到的不动点可能过宽，narrowing 在保持单调与终止的前提下向内收缩。
4. 区间域的主要精度缺陷是什么？要点：丢失变量间相关性，无法表达 $x=y$、$x-y\le c$ 一类约束，需要八边形或多面体补足。
5. 无符号数为什么会破坏区间运算？要点：回绕破坏单调性与凸性，$[250,255]+[1,1]$ 的真值不是连续区间，需按模语义特殊处理。

## 九、演进与趋势
实践主流是**多域组合**：用区间打底、用同余处理对齐、用八边形捕捉常见线性关系，必要时才升级到多面体，从而在精度与成本间取得平衡。工程趋势包括与 SMT 求解结合的按需精化、在 IR 层（如 LLVM 的值范围分析与标量演化）复用数值域做优化、以及针对内存安全语言的边界与别名联合推理。面向 AI/张量编译的范围分析（消除形状与越界检查）成为新的应用热点。具体实现以官方最新文档为准。

## 十、小结
区间分析用最廉价的数值域回答了「变量在什么范围内」这一大量优化与安全检查共同依赖的问题。它的一切工程细节都围绕三点展开：迁移与汇合必须放宽（可靠）、循环加宽必须终止、分支精化必须补上以恢复可用精度。
