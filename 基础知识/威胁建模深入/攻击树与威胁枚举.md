# 攻击树与威胁枚举

> 对应 Saltzer & Schroeder 1975 "Protection and Authorization" / OWASP。

## 一、背景与挑战
单点威胁易遗漏，攻击树把"攻破目标"拆为子树(AND/OR)，结构化展示攻击者选项与依赖，辅助量化风险与选缓解。

## 二、核心原理
根节点为目标(如"读取他人数据")。OR 子节点表示任一可达即成功；AND 子节点需全部满足。叶子为具体攻击步骤，可附成本/概率。

## 三、形式化与数学基础
OR 节点成功率：
$$ P_{or} = 1 - \prod_i (1-p_i) $$
AND 节点：
$$ P_{and} = \prod_i p_i $$
最小成本路径决定最可能被利用的攻击链。

## 四、代码实现
```python
# 攻击树 OR/AND 求值(示意)
def prob(node):
    if node["type"] == "OR":
        return 1 - math.prod(1 - prob(c) for c in node["children"])
    if node["type"] == "AND":
        return math.prod(prob(c) for c in node["children"])
    return node["p"]   # 叶子概率
```

## 五、与其他技术对比
攻击树偏攻击者视角与逻辑；STRIDE 偏资产/数据流经；二者可结合：用 STRIDE 分类叶子。

## 六、常见误区
概率主观导致结论失真。忽略外部依赖(供应链)节点。建树过细陷入无限分解。

## 七、与开源书/权威来源对应
Saltzer & Schroeder 1975 保护原则；Bruce Schneier 攻击树论文；OWASP。

## 八、面试题

## 九、演进与趋势

## 十、小结
攻击树把威胁分解为可计算的逻辑树，帮助排优先级与量化最易被利用路径。
