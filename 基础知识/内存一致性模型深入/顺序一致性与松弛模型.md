# 顺序一致性与松弛模型

> 对应 Hennessy & Patterson《Computer Architecture: A Quantitative Approach》内存一致性章。

## 一、背景与挑战
多线程程序正确性依赖"一个核的写入何时对其他核可见"。过强的模型（顺序一致性 SC）易于推理但限制硬件优化；过弱则程序员难以推理。

## 二、核心原理
Lamport 的 SC 要求：所有处理器操作在全局单一总顺序上原子生效，且各处理器自身顺序保持。硬件为提升性能引入写缓冲、重排，产生松弛（relaxed）模型（如 TSO、弱内存）。

## 三、形式化与数学基础
SC 要求对执行 $E$，存在全序 $\prec$ 使得每个线程的指令按程序序 $\rightarrow_i$ 落在 $\prec$ 中，且读见到 $\prec$ 中最近写：
$$\forall r: val(r) = w\_of(\max_{\prec}\{w \mid w \xrightarrow{addr} r\})$$

## 四、代码实现
```c
// 顺序一致性下的自旋锁(朴素)
volatile int lock = 0;
void acquire() { while (__atomic_test_and_set(&lock, __ATOMIC_SEQ_CST)) {} }
void release() { __atomic_clear(&lock, __ATOMIC_SEQ_CST); }
// SEQ_CST 保证全局单一顺序
```

## 五、与其他技术对比
SC 易编程但禁止写缓冲/重排，性能差；TSO 仅松弛写-读顺序；弱内存（ARM/POWER）松弛更多，需显式 fence。

## 六、常见误区
误以为 x86 是 SC：它是 TSO，允许 StoreLoad 重排。误以为 C 顺序程序天然线程安全。

## 七、与开源书/权威来源对应
量化方法一致性模型；C++ 标准 memory model；Kleppmann DDA 分布式一致性章。

## 八、面试题
问：SC 与 TSO 关键区别？答：TSO 允许store后读提前看到他人写。

## 九、演进与趋势
语言级内存模型（C++11、Java）将硬件差异抽象为 acquire/release 语义。

## 十、小结
SC 是正确性的黄金标准，松弛模型以可推理的栅栏换性能，是现代多核必须掌握的权衡。
