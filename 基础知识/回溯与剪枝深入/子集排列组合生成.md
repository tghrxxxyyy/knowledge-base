# 子集排列组合生成

> 对应 youngyangyang04/leetcode-master 回溯（子集/组合/排列）与 Sedgewick《Algorithms》组合生成章节。

## 一、背景与挑战
生成所有子集、排列、长度为 $k$ 的组合。需避免重复并控制搜索规模，是许多回溯题的基础构件。

## 二、核心原理
- 子集：每个元素"选/不选"两分支。
- 组合：从 `start` 之后选，避免重复组合。
- 排列：用 `used` 标记已选元素。

## 三、形式化与数学基础
子集数 $2^n$，排列数 $n!$，组合数 $\binom{n}{k}$。组合搜索树每层分支随 `start` 递减，总节点 $O(\binom{n}{k})$。

## 四、代码实现
```python
def subsets(nums):
    res = []
    path = []
    def dfs(i):
        if i == len(nums):
            res.append(list(path))
            return
        path.append(nums[i])
        dfs(i + 1)        # 选
        path.pop()
        dfs(i + 1)        # 不选
    dfs(0)
    return res

def permutations(nums):
    res, used = [], [False] * len(nums)
    path = []
    def dfs():
        if len(path) == len(nums):
            res.append(list(path)); return
        for i in range(len(nums)):
            if used[i]:
                continue
            used[i] = True
            path.append(nums[i])
            dfs()
            path.pop()
            used[i] = False
    dfs()
    return res
```

## 五、与其他技术对比
迭代法（如 `(1<<n)` 枚举）生成子集更快但难扩展约束；回溯易加剪枝。

## 六、常见误区
- 组合忘记 `start` 导致重复（如 [1,2] 与 [2,1]）。
- 排列忘记 `used` 标记。
