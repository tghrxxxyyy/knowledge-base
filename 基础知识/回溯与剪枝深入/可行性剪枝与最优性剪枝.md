# 可行性剪枝与最优性剪枝

> 对应 Skiena《The Algorithm Design Manual》第 7 章与 youngyangyang04/leetcode-master 回溯剪枝专题。

## 一、背景与挑战
裸回溯常超时。剪枝通过提前排除不可能/不优的分支，大幅缩减搜索树，是回溯能用的关键。

## 二、核心原理
- 可行性剪枝：当前部分解已违反约束，立即返回。
- 最优性剪枝：当前代价已不小于已知最优解，停止深入。
二者分别保证"不漏解"与"不搜无用分支"。

## 三、形式化与数学基础
设当前代价 $g$，下界估计 $h$（剩余最小可能代价）。若 $g+h \ge best$ 则剪枝（分支定界）。可行性剪枝对应 $h=+\infty$ 的特例。

## 四、代码实现
```python
best = [float('inf')]

def dfs(depth, cost, items):
    if cost >= best[0]:
        return  # 最优性剪枝
    if depth == len(items):
        best[0] = min(best[0], cost)
        return
    if not feasible(items[depth]):
        return  # 可行性剪枝
    dfs(depth + 1, cost + items[depth], items)
    dfs(depth + 1, cost, items)
```

## 五、与其他技术对比
分支定界（B&B）是剪枝的系统化；IDA* 把 A* 的 $f=g+h$ 剪枝用于迭代加深 DFS。

## 六、常见误区
- 下界 $h$ 估计过大（非 admissible）导致误剪最优解。
- 剪枝写错等号边界，漏掉等于最优的解。

## 七、与开源书/权威来源对应
- Skiena 强调"剪枝是艺术"，依赖问题特定下界。
- leetcode-master 在子集/组合题中演示去重剪枝。

## 九、演进与趋势
对称剪枝、缓存等价状态（记忆化搜索）进一步压缩搜索树。

## 十、小结
剪枝 = 可行性（不合法即停）+ 最优性（不优即停），下界质量决定加速比。
