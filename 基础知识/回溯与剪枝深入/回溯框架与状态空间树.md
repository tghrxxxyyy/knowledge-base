# 回溯框架与状态空间树

> 对应 youngyangyang04/leetcode-master 回溯算法章节与 Skiena《The Algorithm Design Manual》第 7 章。

## 一、背景与挑战
回溯用于求解约束满足与组合搜索问题（N 皇后、数独、排列）。暴力枚举是指数级，必须系统性搜索并尽早剪枝。

## 二、核心原理
把解空间建模为状态空间树：根到叶的路径是一个候选解。DFS 遍历，在节点做"选择—递归—撤销"，并在不满足约束时提前返回。

## 三、形式化与数学基础
设部分解 $P$，约束 $C$。若 $C(P)$ 不成立则剪枝；若 $P$ 完整且满足目标则记录。解空间大小常为上界 $\prod_i d_i$（$d_i$ 为第 $i$ 层分支数）。

## 四、代码实现
```python
def backtrack(state, choices, result, is_valid):
    if is_complete(state):
        result.append(list(state))
        return
    for c in choices(state):
        if not is_valid(state, c):
            continue
        state.append(c)
        backtrack(state, choices, result, is_valid)
        state.pop()  # 撤销选择
```

## 五、与其他技术对比
与 BFS 相比，回溯用递归+撤销省去存储整层节点；与 DP 相比，回溯不求最优子结构，只穷举可行解。

## 六、常见误区
- 忘记撤销选择（状态污染），导致后续分支错误。
- 剪枝条件放得太松，退化为纯暴力。

## 九、演进与趋势
回溯与约束传播结合（如 CSP 求解器）、与启发式排序结合（如 DLL SAT 求解）是现代组合求解核心。

## 十、小结
回溯是"带剪枝的 DFS + 状态撤销"，核心三动作：选择、递归、撤销。
