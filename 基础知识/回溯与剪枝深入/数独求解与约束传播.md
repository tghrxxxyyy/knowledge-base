# 数独求解与约束传播

> 对应 Knuth "Dancing Links"（DLX 精确覆盖）、Skiena《The Algorithm Design Manual》约束满足章节，以及 youngyangyang04/leetcode-master 回溯（解数独）。

## 一、背景与挑战

标准数独在 $9\times 9$ 的棋盘上填入数字 $1$–$9$，要求每行、每列、每个 $3\times 3$ 宫内的数字互不相同。给定一个部分填充的盘面，求任意一个补全（或判定无解）。它是约束满足问题（CSP）最广为人知的实例，也是「裸回溯不够、必须加约束传播与启发式」的典型场景。

挑战首先来自搜索空间。$81$ 个格子、每格最多 $9$ 个取值，平凡上界 $9^{81} \approx 1.98\times 10^{77}$。即使已知某些格子，剩余自由度仍是天文数字。纯回溯「按顺序填下一格」在困难盘面上会指数爆炸：因为很多格子在早期根本无法判定，错误的赋值要走很深才能暴露。

其次，约束是三重复合的：行约束、列列约束、宫约束交织在一起。填一个数字会同时影响 $20$ 个其他格子的候选集。若每次都暴力重算候选，常数巨大；若不传播约束，又会失去最重要的剪枝来源。真正的解法需要：**维护候选集**、**约束传播（前向检验/单元传播）**、**MRV 变量序**、**回溯撤销** 四件套。工程上，数独求解器是 CSP 求解器、编译器寄存器分配、调度排班的缩影；面试里它是「回溯 + 剪枝 + 剪枝的数据结构」综合题。

## 二、核心原理

**模型**。每个空格 $x_{r,c}$ 是一个变量，域为 $\{1,\ldots,9\}$。约束有三组：同一行的九个变量互异，同一列的九个变量互异，同一宫的九个变量互异。初始盘面的数字是已赋值变量。

**候选集与合法性**。对空格 $(r,c)$，候选集为

$$
C(r,c) = \{1,\ldots,9\} \setminus \big(\mathrm{row}(r) \cup \mathrm{col}(c) \cup \mathrm{box}(r,c)\big),
$$

其中 $\mathrm{row}(r)$ 等表示该行/列/宫中已出现的数字集合。$|C(r,c)|=0$ 说明当前部分解不合法（立即剪枝）；$|C(r,c)|=1$ 是「唯一余数」（naked single），可以立即填入——这就是约束传播的最简形式。

**MRV（Minimum Remaining Values）**。不要按行优先顺序填格子，而是每次选择「候选最少」的空格。直觉是「最有约束的变量先赋值」：候选为 $1$ 时直接确定，候选为 $2$ 时很快能试错暴露。MRV 显著减少分支因子，是数独求解效率的关键。

**约束传播 / 前向检验**。每填入一个数字，立即从同行、同列、同宫的候选集中删除该数字。若某个邻居候选集变空，立刻剪枝；若变到只剩一个值，可以再次填入（链式传播）。完整的弧相容（AC-3）更强，但对 $9\times 9$ 数独，MRV + 唯一余数已足够在毫秒级解完绝大多数盘面。

**回溯**。选择 MRV 格子，依次尝试候选值：填入、传播、递归；若失败，撤销填入并恢复候选集。候选集的撤销可以用「变更日志」（记录谁删了什么）或简单地重新计算。为清晰起见，下面的实现采用「每次递归重算候选」的简洁写法，性能对 $9\times 9$ 完全够用。

**正确性不变量**：进入递归时盘面是一个部分相容赋值（无单元冲突）；`candidates` 精确给出合法值；撤销后盘面恢复。只要候选计算完备且剪枝只删非法赋值，就能枚举全部补全。

## 三、形式化与数学基础

变量集 $X = \{x_{r,c} \mid 0\le r,c\le 8\}$，值域 $D=\{1,\ldots,9\}$。约束集为

$$
\mathrm{AllDiff}(x_{r,0},\ldots,x_{r,8}),\quad
\mathrm{AllDiff}(x_{0,c},\ldots,x_{8,c}),\quad
\mathrm{AllDiff}(x_{r,c} \mid (r,c)\in \mathrm{box}_k).
$$

CSP 的解是一个映射 $\sigma: X \to D$ 满足全部约束。求解即搜索这样的 $\sigma$。

剪枝的正确性：若某变量候选集为空，则任何扩展都无法满足 AllDiff，该子树无解，可安全剪掉。MRV 不改变解集，只改变访问顺序，因此不影响完备性。

复杂度上，最坏仍是指数级（数独是 NP 完全问题，Yato & Seta 2003 证明其推广版本的 NP 完全性）。但实际平均情况极快：标准 $9\times 9$ 有解盘面用 MRV + 传播通常在几十到几百次赋值内解决。设 $b$ 为 MRV 下的平均分支因子、$d$ 为深度，则节点数约 $O(b^d)$；MRV 让 $b$ 接近 $1$，传播让 $d$ 显著下降。

与精确覆盖的关系：每个「格子填数字」的决策覆盖 4 类约束（该格、该行该数字、该列该数字、该宫该数字），数独化为 $729$ 行、$324$ 列的 0-1 精确覆盖问题，用 Knuth 的 Dancing Links（DLX）求解。DLX 在最坏情况下同样指数，但常数极低且实现优雅。

## 四、代码实现

回溯 + MRV + 候选集重算版，可直接运行，解 LeetCode 37「解数独」风格盘面（`'.'` 表示空格，原地修改）。

```python
from typing import List, Optional, Tuple


def solve_sudoku(board: List[List[str]]) -> bool:
    """
    就地解数独。board[i][j] 为 '1'..'9' 或 '.'。
    找到一个解返回 True，否则 False。使用 MRV + 候选集剪枝。
    """

    def candidates(r: int, c: int) -> List[str]:
        used = set(board[r][i] for i in range(9))
        used |= set(board[i][c] for i in range(9))
        br, bc = 3 * (r // 3), 3 * (c // 3)
        used |= {board[br + i][bc + j] for i in range(3) for j in range(3)}
        return [str(v) for v in range(1, 10) if str(v) not in used]

    def find_mrv() -> Optional[Tuple[int, int, List[str]]]:
        best = None
        best_len = 10
        for r in range(9):
            for c in range(9):
                if board[r][c] != '.':
                    continue
                cand = candidates(r, c)
                if not cand:
                    return None  # 无候选：当前分支必死
                if len(cand) < best_len:
                    best_len = len(cand)
                    best = (r, c, cand)
                    if best_len == 1:
                        return best
        return best

    cell = find_mrv()
    if cell is None:
        # 要么已经填满（cell is None 且无空格），要么矛盾
        return all(board[r][c] != '.' for r in range(9) for c in range(9))
    r, c, cand = cell
    for v in cand:
        board[r][c] = v
        if solve_sudoku(board):
            return True
        board[r][c] = '.'
    return False


def count_solutions(board: List[List[str]], limit: int = 2) -> int:
    """统计解的个数（超过 limit 即截断），用于判定唯一解/多解。"""
    count = 0

    def candidates(r: int, c: int) -> List[str]:
        used = set(board[r][i] for i in range(9))
        used |= set(board[i][c] for i in range(9))
        br, bc = 3 * (r // 3), 3 * (c // 3)
        used |= {board[br + i][bc + j] for i in range(3) for j in range(3)}
        return [str(v) for v in range(1, 10) if str(v) not in used]

    def dfs() -> None:
        nonlocal count
        if count >= limit:
            return
        target = None
        for r in range(9):
            for c in range(9):
                if board[r][c] == '.':
                    cand = candidates(r, c)
                    if not cand:
                        return
                    if target is None or len(cand) < len(target[2]):
                        target = (r, c, cand)
        if target is None:
            count += 1
            return
        r, c, cand = target
        for v in cand:
            board[r][c] = v
            dfs()
            board[r][c] = '.'
            if count >= limit:
                return

    dfs()
    return count


if __name__ == "__main__":
    board = [
        list("53..7...."),
        list("6..195..."),
        list(".98....6."),
        list("8...6...3"),
        list("4..8.3..1"),
        list("7...2...6"),
        list(".6....28."),
        list("...419..5"),
        list("....8..79"),
    ]
    assert solve_sudoku(board)
    assert all('.' not in row for row in board)
    # 校验行/列/宫互异
    for i in range(9):
        assert len(set(board[i])) == 9
        assert len({board[r][i] for r in range(9)}) == 9
    for br in range(0, 9, 3):
        for bc in range(0, 9, 3):
            block = {board[br + i][bc + j] for i in range(3) for j in range(3)}
            assert len(block) == 9
    print("sudoku solved & verified")
```

若要极致性能，可以把 `candidates` 改为维护 `rows/cols/boxes` 三组位掩码（`used[r]` 第 $v$ 位为 1 表示行 $r$ 已用数字 $v$），候选计算变为 `(~(rows[r] | cols[c] | boxes[b])) & 0x1FF`，与 N 皇后的位运算同源。

## 五、与其他技术对比

| 方法 | 机制 | 速度 | 通用性 | 备注 |
| --- | --- | --- | --- | --- |
| 裸回溯 | 逐格枚举 1–9 | 慢，困难盘面爆炸 | 简单 | 教学用 |
| 回溯 + MRV + 候选 | 启发式 + 剪枝 | 极快（ms 级） | CSP 通用 | 面试推荐 |
| 约束传播（AC-3） | 弧相容削减域 | 常使搜索近多项式 | CSP 标准 | 实现复杂 |
| DLX 精确覆盖 | 建模 + Dancing Links | 极低常数 | 精确覆盖类通用 | Knuth 经典 |
| SAT 求解（CDCL） | 子句学习 | 工业级强 | 逻辑公式通用 | 需编码成 CNF |

DLX 与回溯的取舍：DLX 建模优雅、代码量小（约 50 行），适合做通用精确覆盖；回溯 + MRV 更贴近面试手写，且容易插入领域剪枝。SAT 求解器适合大规模、含额外约束的推广数独。

## 六、常见误区

1. **不恢复 `board[r][c] = '.'`**。回溯失败后忘记清空，盘面被污染，后续分支全部错误。必须与赋值严格配对。
2. **候选集漏掉宫约束**。只检查行和列，得到的解会出现宫内重复。`candidates` 必须同时扫描 $3\times 3$ 块。
3. **把 MRV 写成「第一个空格」**。固定顺序在困难盘面上分支因子接近 9，效率差几个数量级。必须动态选候选最少的格子。
4. **把「无候选」当成「无空格」**。`find_mrv` 返回 `None` 有两种可能：已填满（成功）或某格候选为空（失败）。必须区分，否则会把矛盾状态误报为成功。
5. **就地修改却返回副本**。面试要求「原地修改」时，若最后又 `board = new_board`，调用方看不到结果。递归应始终写回同一个 `board` 对象。

## 八、面试题

**1. 什么是 MRV？为什么能加速数独？**

参考答案：MRV（最小剩余值）指每次选择候选集最小的变量先赋值。候选少的变量最容易确定或最容易暴露失败，能尽早把分支因子压到接近 1，并把失败提前到浅层。对数独，唯一余数（$|C|=1$）甚至可以免分支直接填。

**2. 数独如何用精确覆盖建模？**

参考答案：行对应「在格 $(r,c)$ 填数字 $v$」的 $9\times9\times9=729$ 种决策；列对应 324 条约束（81 格 + 81 行数字 + 81 列数字 + 81 宫数字）。每个决策覆盖 4 列。用 Dancing Links 求精确覆盖即得解。已知数字相当于预先选中对应行。

**3. 如何判定一个数独是否有唯一解？**

参考答案：搜索时统计解的个数，达到 2 就停止。`count_solutions(board, limit=2)` 的返回值若为 1 则唯一，$\ge 2$ 则多解，0 无解。生成题目时通常用此函数保证唯一解。

**4. 约束传播和剪枝有什么区别？**

参考答案：剪枝是「发现子树无解就丢弃」；约束传播是「把约束的效果推到未赋值变量的候选集上」，主动缩小搜索空间。传播越强，搜索越浅。前向检验是最弱传播，AC-3 保证弧相容，更强的还有路径相容、全局约束传播（如 AllDiff 的 Régin 算法）。

## 九、演进与趋势

数独求解器的发展与 CSP/SAT 工程实践深度绑定。现代求解器在回溯之上叠加：冲突驱动子句学习（CDCL）、非时序回溯、随机重启、领域削减传播。MiniZinc、Gecode、OR-Tools 等建模语言让「写出约束即可求解」，数独只是入门示例；真正落地的是排班、物流、芯片布线、配置求解。

硬件侧，位并行与 SIMD 候选传播、GPU 上的大规模并行搜索也在推进。训练侧，用数独类任务评测神经网络的符号推理能力（如 NeuroSAT、逻辑神经网络）是近年热点。无论技术栈如何变化，「候选集 + 传播 + MRV + 回溯」这组核心思想始终是理解一切精确约束求解器的钥匙。

## 十、小结

数独是回溯与约束传播的集大成者：用候选集 $O(1)$ 表达行/列/宫约束，MRV 优先填最有约束的格子，唯一余数与前向检验做链式传播，回溯时严格撤销。裸回溯在 $9^{81}$ 面前毫无胜算，而这套组合能把实际搜索压到几百个节点。掌握它，等于掌握了从 N 皇后到工业级 CSP 求解器的共同骨架。
