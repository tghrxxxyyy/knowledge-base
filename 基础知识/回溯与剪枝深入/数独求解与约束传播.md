# 数独求解与约束传播

> 对应 youngyangyang04/leetcode-master 回溯（解数独）与 Skiena《The Algorithm Design Manual》约束满足。

## 一、背景与挑战
在 $9\times 9$ 格填 1-9，使每行/列/宫无重复。裸回溯慢，需约束传播缩小候选。

## 二、核心原理
MRV（最小剩余值）启发式：优先填候选最少格；每填一格更新同行列宫的候选集。配合回溯撤销。

## 三、形式化与数学基础
变量 $x_{r,c}\in\{1..9\}$，约束为行/列/宫内互异。候选集 $C(r,c)=\{1..9\}\setminus (row(r)\cup col(c)\cup box(r,c))$。

## 四、代码实现
```python
def solve_sudoku(board):
    def find_cell():
        best = None
        for r in range(9):
            for c in range(9):
                if board[r][c] == '.':
                    cand = candidates(r, c)
                    if best is None or len(cand) < len(best[1]):
                        best = ((r, c), cand)
        return best

    def candidates(r, c):
        used = set()
        for i in range(9):
            used.add(board[r][i]); used.add(board[i][c])
        br, bc = (r // 3) * 3, (c // 3) * 3
        for i in range(3):
            for j in range(3):
                used.add(board[br + i][bc + j])
        return [str(v) for v in range(1, 10) if str(v) not in used]

    cell = find_cell()
    if cell is None:
        return True
    (r, c), cand = cell
    for v in cand:
        board[r][c] = v
        if solve_sudoku(board):
            return True
        board[r][c] = '.'
    return False
```

## 五、与其他技术对比
纯回溯指数级；加 MRV 后接近多项式规模，实际极快。Dancing Links（精确覆盖）是更激进的算法。

## 六、常见误区
- 不恢复 `board[r][c]='.'` 导致错误。
- 候选集计算未包含宫约束。
