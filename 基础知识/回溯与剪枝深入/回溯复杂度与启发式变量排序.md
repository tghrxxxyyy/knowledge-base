# 回溯复杂度与启发式变量排序

> 对应 Skiena《The Algorithm Design Manual》第 7 章与 youngyangyang04/leetcode-master 回溯剪枝专题。

## 一、背景与挑战
回溯最坏仍是指数级。变量与值的选择顺序极大影响实际运行时间，需启发式降低搜索树规模。

## 二、核心原理
- 变量排序：先选约束多/候选少的（MRV）。
- 值排序：先试"最可能成功"的值（如最少冲突）。
良好排序能早剪枝、早命中。

## 三、形式化与数学基础
搜索树节点数 $T$ 受分支因子 $b$ 与深度 $d$ 影响：$|T|=O(b^d)$。MRV 通过压低早期 $b$ 来指数级减少 $T$。

## 四、代码实现
```python
def order_values(var, domains, constraints):
    # 最少冲突优先
    return sorted(domains[var],
                  key=lambda v: count_conflicts(var, v, constraints))

def select_variable(vars, domains):
    # MRV：候选最少的变量
    return min(vars, key=lambda x: len(domains[x]))
```

## 五、与其他技术对比
无启发式回溯盲目搜索；带启发式接近人类解题路径，常把指数降到可解。与分支定界结合更佳。

## 六、常见误区
- 启发式仅加速，不改变最坏复杂度，不能替代正确剪枝。
- 值排序错误可能延迟命中，反而变慢。
