# HLC与物理时钟一致性

> 对应 HLC 论文（Kulkarni et al. 2014）与 DDIA 第8章。

## 一、背景与挑战
系统常需「按接近真实时间排序」以支持 TTL 过期、快照读、超时。但物理时钟漂移会让纯物理排序出错。HLC 必须保证「物理部分尽量贴近真实时间」，同时不破坏因果序。

## 二、核心原理
HLC 的 \\(l\\) 字段被约束在 \\([pt-\epsilon, pt+\epsilon]\\) 附近，且单调不降。因果相关的事件必然 \\(l\\) 相同或递增，物理部分不会因 NTP 跳变而倒退（因取 max）。

## 三、形式化与数学基础
对非因果事件 \\(a,b\\)，若 \\(pt(a)<pt(b)\\) 且间隔大于 \\(2\epsilon\\)，则 HLC 仍可保持 \\(l(a)<l(b)\\)。即只要物理间隔超过误差界两倍，HLC 与真实时间顺序一致。

## 四、代码实现
```python
def monotonic_physical(l, pt, eps=50):
    # HLC 物理部分不允许倒退到 pt 以下太远
    return max(l, pt - eps)
```

## 五、与其他技术对比
TrueTime 直接返回 \\([t-\epsilon, t+\epsilon]\\) 区间，提交时等待以保序；HLC 用单值近似并靠计数器兜底因果。

## 六、常见误区
1. 认为 HLC 物理部分等于 NTP 时间：它只是有界近似。
2. 用 HLC 物理部分做精确超时：应使用单调时钟。
3. 忽略 \\(\epsilon\\) 与 NTP 实际精度的匹配。

## 七、与开源书/权威来源对应
HLC 论文定理 1 证明 \\(|l-pt|\le\epsilon\\)；DDIA 强调时钟不可靠性。

## 八、面试题
问：HLC 如何避免物理时间倒退？
答：物理部分取 max(当前值, 本地时间)，单调不降，不受 NTP 回拨影响。

## 九、演进与趋势
将 HLC 与 TrueTime 思想融合（如 bounded uncertainty HLC）是活跃研究方向。

## 十、小结
HLC 物理部分有界且单调，使「近似真实时间排序」在安全前提下可用。
