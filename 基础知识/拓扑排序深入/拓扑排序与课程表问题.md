# 拓扑排序与课程表问题

> 对应 youngyangyang04/leetcode-master 课程表 I/II（LeetCode 207/210）与 CLRS 第 22.4 节（拓扑排序）；问题原型即有向无环图判环与线性扩展。

## 一、背景与挑战

课程表问题是拓扑排序在面试中的"标准化身"：给定课程总数 $n$ 与先修关系列表 `prerequisites`，其中 $[a, b]$ 表示"修 $a$ 前必须先修 $b$"，问能否修完所有课程（LeetCode 207），或给出一种可行的修课顺序（LeetCode 210）。抽象地说，它判定**有向图是否存在拓扑序**，并求出这个序。

难点不在模板，而在建模与边界。先修关系是有向的：`[a, b]` 应建成边 $b \to a$（$b$ 是前置），很多初学者建成 $a \to b$，结果"能修完"的判定整个反过来。更隐蔽的是：先修图可能有多个连通分量、可能有孤立课程（没有任何先修）、可能有重复的先修对、可能有自环（$a$ 的先修是 $a$ 本身）。朴素做法"每次找一门没有未满足先修的课修掉"最坏 $O(n \cdot e)$；用集合 `done` 与循环扫描，数据一大就 TLE。

课程表问题在工程中的位置非常明确：它就是**依赖判定**的最小模型——排课系统、认证路径规划、微服务启动顺序、包安装顺序都同构。面试官通过它考察：能否把文字转成图、入度/DFS 两种写法、环的检测与解释、以及"输出顺序"与"只判定"的代码差异。207 只要布尔值，210 要输出序；若输出空数组表示不可能，这个约定也常被忽略。

## 二、核心原理

把每门课当作顶点 $0 \ldots n-1$；对先修对 $[a, b]$ 建有向边 $b \to a$。于是：

- **能否修完 $\iff$ 图是 DAG $\iff$ 存在拓扑序 $\iff$ Kahn 输出数等于 $n$（或 DFS 无后向边）**；
- **一种修法 = 一个拓扑序**。

**Kahn 机制**：维护每门课的未满足先修数（入度）。初始入度为 0 的课可直接修；修完一门，把它解锁的课入度减一；减到 0 就绪。全部修完则成功。若中途队列空了还有课没修，这些课互相卡在环里。

**DFS 机制**：对每门未访问的课递归探索其后继；三色标记下遇到灰点即后向边（环）。后序逆序得到修课顺序。

**为何等价**：先修约束正是"前驱必须在前"的偏序；线性扩展存在当且仅当约束无环。课程表只是把"模块/任务"换成了"课程"，没有新理论。

**边界与变体**：
- 孤立课程：入度 0，一开始即可修，必须计入结果；
- 重复先修对：$[a,b]$ 出现两次，入度会加两次，删边时也要减两次；若先去重，入度只加一次，实现要自洽；
- 自环 $[a,a]$：永远无法入度归零，正确判为不可能；
- **学期限制（变体）**：每学期最多修 $k$ 门，且必须修完先修才能修后续。此时不能任意拓扑，而要按"就绪层"批量取课，若某层就绪数 $>k$ 则需多学期；这是拓扑分层 + 资源约束的调度问题，不是纯拓扑。
- **字典序最小顺序**：把队列换最小堆（LeetCode 210 若有特殊排序要求）。

**输出约定**：210 在不可能时返回 `[]`，与"合法的空顺序"（$n=0$）歧义，判题时通常 $n\ge 1$；自己写接口最好返回 `None` 或抛异常。

## 三、形式化与数学基础

**判定定理**：令 $G=(V,E)$，$V$ 为课程，$E=\{(b,a)\mid [a,b]\in \text{prerequisites}\}$。则
$$\text{canFinish} \iff G \text{ 无环} \iff \exists \text{ 拓扑序}.$$

**Kahn 计数证明**：算法输出集合 $S$ 满足 $\forall v\in S$ 其前驱已入 $S$，故 $S$ 可按出队序排成合法序。若 $|S|<n$，残余集 $R=V\setminus S$ 在 $G[R]$ 上入度皆 $\ge 1$，故含环，不可能修完。

**DFS 正确性**：$G$ 有环 $\iff$ DFS 出现后向边。若修不完，必有后向边；若无后向边，逆后序满足所有先修约束。

**复杂度**：两种写法都是 $O(n+e)$ 时间，$O(n+e)$ 空间（邻接表 + 入度/颜色）。相对暴力 $O(n\cdot e)$ 是本质改进。

**学期调度变体的形式化**：每学期最多 $k$ 门。令就绪集 $Q_t$ 为当前入度 0 的课程。一种贪心是每学期修 $Q_t$ 中优先级最高（如编号最小）的至多 $k$ 门，再更新入度。学期数下界为
$$\max\left(\left\lceil \frac{n}{k} \right\rceil,\ \text{最长链长度}\right)$$
当 $k\ge \max_t |Q_t|$ 时就是普通拓扑层数（最长链）。带权课程（学分/耗时）则变成资源受限调度，是 NP-hard，需启发式。

**唯一性**：修课顺序唯一 $\iff$ 每一步就绪集大小为 1。否则多解，210 返回任意一种即可。

## 四、代码实现

```python
from collections import deque, defaultdict
import heapq


def can_finish(numCourses, prerequisites):
    """LeetCode 207: 能否修完所有课程"""
    indeg = [0] * numCourses
    adj = [[] for _ in range(numCourses)]
    for a, b in prerequisites:
        # 先修 b 才能 a: b -> a
        adj[b].append(a)
        indeg[a] += 1

    q = deque(i for i in range(numCourses) if indeg[i] == 0)
    seen = 0
    while q:
        u = q.popleft()
        seen += 1
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return seen == numCourses


def find_order(numCourses, prerequisites):
    """LeetCode 210: 返回一种修课顺序，不可能则返回 []"""
    indeg = [0] * numCourses
    adj = [[] for _ in range(numCourses)]
    for a, b in prerequisites:
        adj[b].append(a)
        indeg[a] += 1

    q = deque(i for i in range(numCourses) if indeg[i] == 0)
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order if len(order) == numCourses else []


def find_order_lex_min(numCourses, prerequisites):
    """字典序最小的修课顺序"""
    indeg = [0] * numCourses
    adj = [[] for _ in range(numCourses)]
    for a, b in prerequisites:
        adj[b].append(a)
        indeg[a] += 1

    heap = [i for i in range(numCourses) if indeg[i] == 0]
    heapq.heapify(heap)
    order = []
    while heap:
        u = heapq.heappop(heap)
        order.append(u)
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                heapq.heappush(heap, v)
    return order if len(order) == numCourses else []


def min_semesters(numCourses, prerequisites, k):
    """变体: 每学期最多修 k 门, 返回最少学期数; 不可能返回 -1"""
    indeg = [0] * numCourses
    adj = [[] for _ in range(numCourses)]
    for a, b in prerequisites:
        adj[b].append(a)
        indeg[a] += 1

    q = deque(i for i in range(numCourses) if indeg[i] == 0)
    done = 0
    semesters = 0
    while q:
        # 一学期修至多 k 门
        take = []
        for _ in range(min(k, len(q))):
            take.append(q.popleft())
        semesters += 1
        for u in take:
            done += 1
            for v in adj[u]:
                indeg[v] -= 1
                if indeg[v] == 0:
                    q.append(v)
    return semesters if done == numCourses else -1


if __name__ == "__main__":
    assert can_finish(2, [[1, 0]]) is True
    assert can_finish(2, [[1, 0], [0, 1]]) is False

    order = find_order(4, [[1, 0], [2, 0], [3, 1], [3, 2]])
    assert len(order) == 4
    pos = {c: i for i, c in enumerate(order)}
    assert pos[0] < pos[1] < pos[3]
    assert pos[0] < pos[2] < pos[3]

    assert find_order(2, [[1, 0], [0, 1]]) == []
    assert find_order_lex_min(4, [[1, 0], [2, 0], [3, 1], [3, 2]]) == [0, 1, 2, 3]
    assert min_semesters(4, [[1, 0], [2, 0], [3, 1], [3, 2]], 2) == 3
    assert min_semesters(2, [[1, 0], [0, 1]], 2) == -1
    print("all tests passed")
```

## 五、与其他技术对比

| 维度 | Kahn（本篇主力） | DFS 后序逆序 | 并查集 | BFS 误用（按层看 visited） |
|---|---|---|---|---|
| 判环 | 输出数 $<n$ | 后向边 | 仅无向 | 不可靠 |
| 输出顺序 | 队列/堆可控 | 与出边序相关 | 无 | 无 |
| 学期/资源变体 | 分层批量取课 | 不直观 | 不适用 | 可能错 |
| 常见坑 | 边方向 | 爆栈 | 忽略方向 | 忽略方向 |

取舍：207/210 用 Kahn 最稳；要环路径用 DFS；要字典序用堆；学期限制在 Kahn 分层上取批。并查集适合无向"是否连通/分组"，对有向先后无能为力。

## 六、常见误区

1. **边方向建反**：`[a, b]` 是"先 b 后 a"，边应 $b\to a$。建反后无环判定、顺序全错。后果：明明能修完判为不能。
2. **只从 0 号课程 BFS/DFS**：多分量时漏掉其他课程，`seen < n` 误报有环。
3. **210 用 `[]` 表示失败与合法空课表混淆**：接口设计要区分；返回 `None`/异常更清晰。
4. **学期变体里每学期从全局任意选课**：不按"就绪（入度 0）"约束，会选到先修未完成的课；或忽略 $k$ 限制。
5. **重复先修对入度不一致**：建边加了两次入度，删边只减一次，导致永远不到 0，假环。

## 八、面试题

**1. 课程表为什么等价于拓扑排序？**  
先修关系就是偏序约束"前驱在前"；能修完等价于存在全序满足全部约束，即图是 DAG、存在拓扑序。排一个顺序就是求一个拓扑序。

**2. 若要求输出任意一种顺序，如何改？**  
在 Kahn 中把结果收集为列表；成功时返回该列表，失败返回空。注意检查 `len(order) == n`，否则环上课程被静默丢掉。

**3. 每学期最多修 $k$ 门，最少几学期？**  
按就绪集分层，每学期从入度 0 集合取至多 $k$ 门（可按编号优先），更新入度直到结束。学期数即批次数；下界为 $\max(\lceil n/k\rceil, \text{最长链})$。若 $k$ 无限制，就是最长链（拓扑层数）。

**4. 如何判断修课顺序是否唯一？**  
当且仅当每一步就绪课程集合大小为 1。实现上在 Kahn 里检查每次队列中是否只有一个候选；一旦出现多个候选，后续顺序就有多种合法解。

## 九、演进与趋势

课程表模型延伸出丰富的调度变体：**带学期容量/教室容量**是资源受限调度；**带学分与 GPA 目标**变成约束优化；**并行学期**对应关键路径与最早完成时间；**动态先修**（转学分、免修）要求增量拓扑。工业上，高校排课系统、认证培训路径、在线课程推荐的"前置技能图"都是它的扩展；LeetCode 系列还演化出"重建序列""火星词典""平行课程"等题，底层仍是入度与分层。与图神经网络结合做"先修知识追踪"，是教育数据挖掘方向的新趋势。

## 十、小结

课程表问题就是 DAG 判环与求拓扑序：$[a,b]$ 建边 $b\to a$，Kahn 入度归零即可判"能否修完"并给出顺序；DFS 三色可附带环路径。看清边方向、处理孤立课与重复边，再加分层批量，就能覆盖从 LeetCode 207/210 到学期容量调度的一整类问题。
