# 拓扑排序与课程表问题

> 对应 youngyangyang04/leetcode-master 课程表（拓扑排序）与 CLRS 22.4。

## 一、背景与挑战
给定numCourses与先修关系，判断能否修完（即图是否无环），或给出一种修课顺序。

## 二、核心原理
把课程当节点、先修当边，问题等价于拓扑排序是否存在。能排出全序即无环可修完。

## 三、形式化与数学基础
存在拓扑序 ⟺ 图是 DAG。可用 Kahn 入度法或 DFS 法求解，输出长度等于课程数即成功。

## 四、代码实现
```python
from collections import deque, defaultdict

def can_finish(numCourses, prerequisites):
    indeg = [0] * numCourses
    adj = defaultdict(list)
    for a, b in prerequisites:
        adj[b].append(a)
        indeg[a] += 1
    q = deque(i for i in range(numCourses) if indeg[i] == 0)
    seen = 0
    while q:
        u = q.popleft()
        seen += 1
        for v in adj[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return seen == numCourses
```

## 五、与其他技术对比
并查集不能处理有向依赖；拓扑排序是判定有向无环的标准工具。

## 六、常见误区
- 边方向建反（先修 b 才能 a，则边 b->a）。
- 用无向图思路处理先修（顺序性丢失）。
