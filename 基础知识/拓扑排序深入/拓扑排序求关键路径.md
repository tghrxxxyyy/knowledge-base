# 拓扑排序求关键路径

> 对应 CLRS 第 24 章（DAG 最长路径）与 youngyangyang04/leetcode-master 拓扑排序进阶。

## 一、背景与挑战
项目由任务及依赖组成，每任务有耗时，求最短总工期与关键任务（不能延误的）。即 DAG 上最长路径。

## 二、核心原理
拓扑序下 DP：对每个节点 $u$，$dist[u]=\max_{(v,u)}(dist[v]+w_v)$。最长路径即关键路径，决定总工期。

## 三、形式化与数学基础
$$dist[u] = \max_{v\in pred(u)} (dist[v] + dur[v])$$
总工期 $= \max_u dist[u]$。关键任务构成使等号成立的最长路径。

## 四、代码实现
```python
from collections import defaultdict

def critical_path(n, tasks, edges):
    # tasks: duration per node; edges: (u,v) 依赖 u->v
    adj = defaultdict(list)
    indeg = [0] * n
    for u, v in edges:
        adj[u].append((v, tasks[u]))
        indeg[v] += 1
    from collections import deque
    q = deque(i for i in range(n) if indeg[i] == 0)
    dist = [0] * n
    while q:
        u = q.popleft()
        for v, w in adj[u]:
            dist[v] = max(dist[v], dist[u] + w)
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return max(dist)
```

## 五、与其他技术对比
一般图最长路径 NP-hard，但 DAG 可在拓扑序下线性 DP 求解。

## 六、常见误区
- 用最短路算法直接求最长（需取负或用 max DP）。
- 忘记任务自身耗时 `dur[u]`。
