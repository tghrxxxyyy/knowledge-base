# 多核缓存划分与共享替换

> 对应 Hennessy & Patterson《Computer Architecture: A Quantitative Approach》多核缓存共享章节。

## 一、背景与挑战
多核共享末级缓存（LLC）时，各核工作集相互驱逐，产生"缓存挤占"。公平或性能最优都需要对缓存空间做划分与协同替换。

## 二、核心原理
基于效用（utility）的划分（如 UCP、RCI）按各核在额外缓存上的命中收益分配容量。替换时在共享组内仍可用近似 LRU/DIP，但配额限制了每核可用路数。

## 三、形式化与数学基础
系统总缺失最小化：
$$\min_{q_1..q_n} \sum_{i} Miss_i(q_i),\quad \sum_i q_i = C$$
其中 $q_i$ 为核 $i$ 配额，边际效用 $MU_i = \frac{\partial Miss_i}{\partial q_i}$ 相等时最优（水填充）。

## 四、代码实现
```c
// 水填充式配额分配(离散)
int allocate(int n, int cap, int *miss_cost) {
    int q[8]={0};
    for (int given=0; given<cap; given++) {
        int best=0;
        for (int i=1;i<n;i++)
            if (miss_cost[i] < miss_cost[best]) best=i;
        q[best]++; miss_cost[best]--; // 该核多1路, 边际效用降
    }
    return q[0];
}
```

## 五、与其他技术对比
静态划分（公平均分）简单但浪费；效用驱动动态划分性能更优；与替换策略正交，可在 DIP 之上叠加。

## 六、常见误区
误以为越大共享缓存总是越快：挤占会损害局部性强的核。误把公平等同于性能最优。

## 七、与开源书/权威来源对应
量化方法多核 LLC 与 QoS；Intel 资源调配技术（RDT）手册。

## 八、面试题
问：缓存挤占如何量化与缓解？答：用效用曲线做水填充分配配额。

## 九、演进与趋势
硬件 HM（hit/miss）监控与软件 RDT 协同，实现 NUMA/LLC 感知调度。

## 十、小结
多核下缓存替换从"单组策略"升级为"配额 + 策略"联合优化，核心是效用驱动的划分。
