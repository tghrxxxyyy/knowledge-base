# 基于重用距离的替换

> 对应 Hennessy & Patterson《Computer Architecture: A Quantitative Approach》与 CyC2018/CS-Notes 缓存分析。

## 一、背景与挑战
缺失率并非只由容量决定，更由程序访存的空间-时间局部性结构决定。重用距离（reuse distance）量化"两次访问同一块之间出现的不同块数"，直接映射到所需缓存容量。

## 二、核心原理
对每对相邻同地址访问，计算其间不同地址数 $d$。若 $d \le C$ 则命中，否则缺失。重用距离直方图可预测任意容量下的缺失率，也称栈距离分析（Mattson 算法）。

## 三、形式化与数学基础
给定容量 $C$，命中需 $d \le C$。缺失率：
$$Miss(C) = \frac{1}{N}\sum_{i} \mathbb{1}[d_i > C]$$
栈距离曲线 $Miss(C)$ 是缓存容量规划的核心工具。

## 四、代码实现
```python
# 栈距离算法计算重用距离分布
def reuse_dist(access):
    stack = []
    dist = []
    for x in access:
        if x in stack:
            d = len(stack) - stack.index(x) - 1
            dist.append(d)
            stack.remove(x)
        else:
            dist.append(None)  # 冷缺失
        stack.append(x)
    return dist

print(reuse_dist([1,2,3,1,4,2,3]))
```

## 五、与其他技术对比
重用距离描述"最优可达性"，与具体替换策略无关；LRU 在栈式工作集下恰好达到该下界。相比 MPKI，它给出容量-缺失的连续关系。

## 六、常见误区
误以为重用距离依赖替换策略：它定义于理想 LRU 栈，独立于实际策略。误以为直方图为固定值：随输入规模变化。

## 七、与开源书/权威来源对应
量化方法"栈距离与缺失曲线"；CS-Notes 缓存篇。

## 八、面试题
问：为何 LRU 下重用距离等于命中所需容量？答：LRU 栈属性保证。

## 九、演进与趋势
在线重用距离采样（如 CPU 性能监控）用于指导缓存划分与预取。

## 十、小结
重用距离是连接程序局部性与缓存性能的桥梁，也是评估替换策略的理论基准。
