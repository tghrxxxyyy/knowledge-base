# 非临时存储与非写分配

> 对应 Intel SDM 卷3 中 Non-Temporal 存储（MOVNT）与缓存绕过。

## 一、背景与挑战
流式写入大块数据（如内存拷贝、媒体编码）若常规写分配（write-allocate）会把整行读入缓存再写，污染缓存且浪费带宽。非临时（non-temporal）存储绕过缓存。

## 二、核心原理
MOVNTDQ 等非临时指令直接写内存（write-combining 缓冲），不分配缓存行、不读入。配合预取写（prefetchw）或 SFENCE，适合一次性写、不再马上读的数据。

## 三、形式化与数学基础
常规写分配需先取行（64 字节），再改其中 $b$ 字节。非临时写省去读行：
$$Bytes_{bus} = b \quad (\text{合并后})\quad \text{vs}\quad 64 + b\ (\text{分配写})$$

## 四、代码实现
```c
#include <immintrin.h>
void stream_copy(float* dst, float* src, int n){
    for (int i=0;i<n;i+=4)
        _mm_stream_ps(&dst[i], _mm_load_ps(&src[i])); // 非临时写
    _mm_sfence();
}
```

## 五、与其他技术对比
非临时写减少缓存污染但丧失时间局部性收益；普通写分配利于后续复用。选择取决于数据是否会被很快再读。

## 六、常见误区
误以为非临时存储更快总成立。若写后马上读，绕过缓存反而更慢，因为它不走缓存层次。

## 七、与开源书/权威来源对应
Intel SDM 卷3 的「Non-Temporal Stores」与写合并内存类型；CSAPP 第6章讨论写分配策略与缓存污染。

## 八、面试题
问：何时用流式存储？答：一次性大块写入且后续不立即复用，如 memcpy、媒体编码输出，可避免污染缓存。

## 九、演进与趋势
movnt 家族与 prefetchw、ERMSB 等配合，构成高效内存搬移原语，仍广泛用于高性能库。

## 十、小结
非临时存储以「绕过缓存」换取带宽与污染控制，是流式写场景的关键优化。
