# 非临时存储与非写分配

> 对应 Intel SDM 卷3「Non-Temporal Stores」与 Drepper 2007《What Every Programmer Should Know About Memory》。

## 一、背景与挑战

处理大块流式数据（内存拷贝、编解码输出、稀疏矩阵填充）时，若采用常规的写分配（write-allocate）策略，缓存会把目标缓存行先读入，再就地修改。这些数据通常「写一次、长时间不再读」，却把整个 cache 污染，挤掉了真正有复用价值的行。

非临时（non-temporal, NT）存储正是为此设计：它提示硬件「这份数据不具备时间局部性」，从而绕过缓存层级，直接进入写合并缓冲并尽量少地占用带宽。

## 二、核心原理

x86 提供 `MOVNTDQ`/`MOVNTPS`/`MOVNTI` 等非临时存储指令族，配合需要对齐的 SSE/AVX 访问。写入 NT 存储时：

1. 目标行不进行写分配（no write-allocate），不触发 RFO（Read For Ownership）。
2. 数据进入写合并缓冲（WC buffer），多个 16/32 字节写可在缓冲内聚合成整行后再发往内存。
3. 需要 `SFENCE` 之类的写屏障保证此前 NT 写全局有序后才继续。

代价是：一旦写后马上读，必须回内存取，失去了缓存命中。所以 NT 只用于「流式、一次性」的写。

## 三、形式化与数学基础

设一次写操作修改缓存行内 $b$ 字节，缓存行为 $L=64$ 字节。常规写分配的流量包含「先读行」：

$$Traffic_{WA} = L + b$$

而理想合并后的非临时写只需最终写回：

$$Traffic_{NT} = b \quad(\text{同行多次写被合并})$$

当 $b \ll L$ 且访问连续时，节省比率为：

$$\eta = 1 - \frac{b}{L+b} \approx 1 - \frac{b}{64+b}$$

例如每次写 16 字节，$\eta \approx 1-16/80 = 0.8$，即约节省 80% 的访存流量。

## 四、代码实现

以下示例用 AVX 内建函数做流式拷贝，读用普通加载，写用非临时存储，最后以 `_mm_sfence` 收尾。

```c
#include <immintrin.h>

void stream_copy(float *dst, const float *src, size_t n) {
    size_t i = 0;
    for (; i + 8 <= n; i += 8) {
        __m256 v = _mm256_loadu_ps(src + i);   // 普通读
        _mm256_stream_ps(dst + i, v);          // 非临时写，绕过缓存
    }
    _mm_sfence();                              // 确保 NT 写全局可见
    for (; i < n; ++i) dst[i] = src[i];        // 尾部标量处理
}
```

要点：`_mm256_stream_ps` 通常要求目标地址按向量宽度对齐；混用普通读与 NT 写时若读写区域重叠会破坏语义，必须保证无别名。具体对齐与指令可用性以目标平台官方文档为准。

## 五、与其他技术对比

| 维度 | 写分配（WB） | 非临时写（NT/WC） | 写穿透（WT） |
| --- | --- | --- | --- |
| 是否分配缓存行 | 是 | 否 | 视实现 |
| 是否先读行（RFO） | 是 | 否 | 通常否 |
| 时间局部性收益 | 高 | 无 | 无 |
| 典型场景 | 通用计算 | 流式拷贝 | 设备寄存器 |
| 读回性能 | 快 | 慢（回内存） | 慢 |

## 六、常见误区

- 误区一：NT 存储一定更快。只有当数据不再被读、且写入连续时才有优势，否则等于自断缓存命中的路。
- 误区二：NT 写后立即可见。NT 写进入写合并缓冲，需要 `SFENCE` 才保证全局有序。
- 误区三：NT 可以随便用在小块数据。小块、随机写无法形成行内合并，反而增加指令与屏障开销。
- 误区四：NT 与普通写混用无妨。若读写区域存在别名，硬件不保证语义，必须显式隔离或补屏障。

## 八、面试题

1. 为什么流式拷贝常用 NT 版本？答：避免写分配把整行读入，减少缓存污染与带宽浪费。
2. 非临时存储与写合并缓冲是什么关系？答：NT 写通常进入 WC 缓冲，聚合成整行事务后写回。
3. `SFENCE` 在 NT 代码里起什么作用？答：保证此前的 NT 写在后续操作前全局可见、按序刷出。
4. 什么情况下 NT 反而更慢？答：写后需要立即读取同一数据时，因绕过缓存必须回内存。

## 九、演进与趋势

NT 存储家族与 `prefetchw`、增强型 `REP MOVSB`、AVX-512 的非临时写一起，构成高性能内存搬移原语。现代库在超过大块阈值时自动切换到 NT 路径；在持久内存与异构统一内存语境下，「不经缓存写入」的语义被进一步扩展，具体行为以各厂商官方最新文档为准。

## 十、小结

非临时存储用「放弃时间局部性」换取带宽与缓存洁净度，是流式写场景的关键手段。使用时必须同时满足连续、对齐、写后不读三个条件，并以写屏障保证可见顺序。
