# 布隆过滤器

> 对应 Bloom《Space/Time Trade-offs in Hash Coding with Allowable Errors》(1970)。

## 一、背景与挑战
用极小的位数组 + k 个独立哈希判断元素「是否在集合中」，支持空间高效的存在性查询，允许假阳性、不允许假阴性。

## 二、核心原理
插入：把 k 个哈希位都置 1。查询：k 位全 1 才可能存在；任一位为 0 则必不存在。不存储元素本身。

## 三、形式化 / 数学基础
假阳性率：
$f \approx \left(1 - e^{-kn/m}\right)^k$
最优哈希数 $k = (m/n)\ln 2$ 时最小化 f。

## 四、代码实现
```python
import mmh3
class Bloom:
    def __init__(self, m, k):
        self.bits = bytearray((m + 7) // 8)
        self.m = m
        self.k = k
    def _set(self, i):
        self.bits[i >> 3] |= 1 << (i & 7)
    def _get(self, i):
        return (self.bits[i >> 3] >> (i & 7)) & 1
    def add(self, x):
        for i in range(self.k):
            self._set(mmh3.hash(str(x), i) % self.m)
    def maybe_contains(self, x):
        return all(self._get(mmh3.hash(str(x), i) % self.m) for i in range(self.k))
```

## 五、与其他技术对比
与 HashSet 相比，布隆过滤器省空间但有误判且不可删除；与位数组精确集合相比，它允许假阳性换空间。

## 六、常见误区
误以为可删除元素（会误删他人位）；调参不当假阳性过高；哈希函数相关性导致聚集。

## 十、小结
布隆过滤器以 k 哈希位实现亚线性空间存在性查询，假阳性率公式指导参数选择，代价是不可删除。
