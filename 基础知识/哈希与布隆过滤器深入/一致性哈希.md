# 一致性哈希

> 对应 Karger et al.《Consistent Hashing and Random Trees》(1997) (MIT) 与 Dynamo 论文。

## 一、背景与挑战
分布式缓存中节点增减时，传统取模会导致几乎所有键重新映射。一致性哈希让变动只影响邻近一小部分键。

## 二、核心原理
把哈希空间排成环，节点与键都哈希到环上；键归属为顺时针最近的节点。引入虚拟节点使负载更均衡。

## 三、形式化 / 数学基础
若 n 个真实节点、每节点 v 个虚拟节点，环上共 n·v 个点；单节点失效仅重映射约 $1/n$ 的键。

## 四、代码实现
```python
import bisect
class ConsistentHash:
    def __init__(self, nodes, replicas=100):
        self.ring = []
        self.node_map = {}
        for node in nodes:
            for i in range(replicas):
                key = hash(f"{node}#{i}")
                self.ring.append(key)
                self.node_map[key] = node
        self.ring.sort()
    def get(self, item):
        h = hash(item)
        idx = bisect.bisect_right(self.ring, h) % len(self.ring)
        return self.node_map[self.ring[idx]]
```

## 五、与其他技术对比
与简单 `hash(key) % N` 相比，一致性哈希最小化再平衡范围；虚拟节点解决倾斜。

## 六、常见误区
未加虚拟节点导致分布不均；哈希环实现未处理绕回（取模）；节点上下线未同步视图。

## 九、演进与趋势
带权重虚拟节点；与渲染/一致性协议结合；Jump/ Rendezvous 哈希替代方案。

## 十、小结
一致性哈希用哈希环 + 虚拟节点实现最小扰动再均衡，是分布式键值系统的基石。
