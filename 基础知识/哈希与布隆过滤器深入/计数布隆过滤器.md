# 计数布隆过滤器

> 对应 Fan et al.《Summary Cache for Approximate Query Answering》(2000) (Counting Bloom Filter)。

## 一、背景与挑战
标准布隆过滤器无法安全删除（清位会误伤其他元素）。计数布隆用每槽若干位计数器代替单 bit，支持增减。

## 二、核心原理
每个哈希位对应一个小的计数器（如 4 位）。插入计数器加 1，删除减 1；查询看所有计数器是否均 >0。

## 三、形式化 / 数学基础
计数器宽度 c 位可计到 $2^c-1$；溢出需处理。空间代价约为标准布隆的 c 倍。误删概率随计数宽度下降。

## 四、代码实现
```python
class CountingBloom:
    def __init__(self, m, k, width=4):
        self.c = [0] * m
        self.m = m
        self.k = k
        self.mask = (1 << width) - 1
    def add(self, x):
        for i in range(self.k):
            self.c[hash((x, i)) % self.m] += 1
    def remove(self, x):
        for i in range(self.k):
            self.c[hash((x, i)) % self.m] -= 1
```

## 五、与其他技术对比
相比标准布隆，计数布隆支持删除但占用更多空间且仍有计数溢出/误判；相比精确结构，仍省空间。

## 六、常见误区
计数器溢出未处理；删除不存在元素导致负计数；宽度过小频繁溢出。

## 七、与开源书 / 权威来源对应
- Fan et al. 2000 (SIGCOMM)
- 网络测量综述

## 八、面试题
「如何给布隆过滤器加删除」；设计一个支撑删除的近似集合。

## 九、演进与趋势
d-LEFT Counting Bloom；压缩计数数组；与布隆组合的分层结构。

## 十、小结
计数布隆用计数器换取删除能力，是布隆过滤器在动态集合上的自然扩展。
