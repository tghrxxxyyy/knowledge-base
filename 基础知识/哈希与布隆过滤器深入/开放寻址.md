# 开放寻址

> 对应 CLRS《Introduction to Algorithms》第 11 章 Hash Tables。

## 一、背景与挑战
哈希冲突时，开放寻址在表内探测下一个空槽，无需链表，缓存友好。需设计探测序列并利用装载因子控制性能。

## 二、核心原理
线性探测（步长 1，易聚集）、二次探测（步长平方，避免一次聚集）、双重哈希 $h(k,i)=(h_1(k)+i h_2(k))\bmod m$。

## 三、形式化 / 数学基础
均匀哈希下，装载因子 α 时，不成功查找期望探测数：$1/(1-\alpha)$（线性）；双重哈希约 $-(1/\alpha)\ln(1-\alpha)$。

## 四、代码实现
```python
class OpenAddr:
    def __init__(self, m):
        self.m = m
        self.table = [None] * m
    def h(self, k, i):
        return (hash(k) + i * 1) % self.m
    def put(self, k, v):
        for i in range(self.m):
            idx = self.h(k, i)
            if self.table[idx] is None or self.table[idx][0] == k:
                self.table[idx] = (k, v)
                return
        raise Exception("full")
```

## 五、与其他技术对比
与链地址法相比，开放寻址省指针、缓存好，但删除需墓碑标记；高装载下性能骤降。

## 六、常见误区
删除直接置空导致探测链断裂（用墓碑）；装载因子过高不扩容；双重哈希 h2 与表大小不互质。
