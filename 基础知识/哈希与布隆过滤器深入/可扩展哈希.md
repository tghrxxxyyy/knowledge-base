# 可扩展哈希

> 对应 Fagin et al.《Extendible Hashing — A Fast Access Method for Dynamic Files》(1979)。

## 一、背景与挑战
传统哈希表扩容需整体 rehash。可扩展哈希（Extendible Hashing）通过目录（directory）只分裂溢出的桶，适合数据库外存。

## 二、核心原理
用全局深度 gd 与局部深度 ld。键哈希的前 gd 位索引目录指向桶；桶满且 ld==gd 时目录翻倍（全局分裂），否则仅桶分裂（局部）。

## 三、形式化 / 数学基础
目录大小 $2^{gd}$；每个桶容量 b。仅当桶溢出时按对应位细分，平均只需重定位一个桶的数据。

## 四、代码实现
```python
class ExtendibleHash:
    def __init__(self, b):
        self.b = b
        self.gd = 0
        self.dir = [[]]   # 单个桶起始
    def _bucket_index(self, key):
        h = hash(key)
        return (h >> (32 - self.gd)) & ((1 << self.gd) - 1)
    def insert(self, key):
        i = self._bucket_index(key)
        self.dir[i].append(key)
        if len(self.dir[i]) > self.b:
            self._split(i)
```

## 五、与其他技术对比
与开放寻址/链地址整体扩容相比，可扩展哈希只分裂相关桶，外存友好；实现较复杂。

## 六、常见误区
全局/局部深度混淆；目录翻倍后旧指针未复制；位提取移位方向错误。

## 七、与开源书 / 权威来源对应
- Fagin et al. 1979
- 数据库系统实现教材

## 八、面试题
「数据库索引如何动态扩容」；对比可扩展哈希与线性哈希。

## 九、演进与趋势
线性哈希（Linear Hashing）顺序分裂；与 B+ 树在外存索引中的取舍。

## 十、小结
可扩展哈希用目录 + 局部深度实现增量分裂，避免整体 rehash，是外存动态哈希的经典方案。
