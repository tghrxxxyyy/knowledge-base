# 向量时钟

> 对应 Fidge《Timestamps in Message-Passing Systems》(1988) 与 Mattern 独立提出。

## 一、背景与挑战
Lamport 时钟只能保证因果方向的计数，无法判定“两个事件是否并发”。向量时钟用每个进程一个分量，使因果/并发可精确判断。

## 二、核心原理
系统有 N 个进程，进程 i 维护向量 V[i]。
- 本地事件：V[i] += 1。
- 发送消息：附上当前 V。
- 接收消息(进程 i)：对每个 j，V[j] = max(V[j], 消息 V[j])；然后 V[i] += 1。
比较：
- V <= W 当且仅当所有分量 V[k] <= W[k]。
- V < W 当且仅当 V <= W 且至少一个分量严格小。
- a -> b 当且仅当 V_a < V_b。
- 并发当且仅当既非 <= 也非 >= (即存在 k,l 使 V[k]<W[k] 且 V[l]>W[l])。

## 三、形式化 / 数学基础
向量上的偏序：V ≤ W ⇔ ∀k: V[k] ≤ W[k]。
a 因果先于 b: V_a < V_b。
a 与 b 并发: V_a 与 V_b 不可比(互不小于)。
向量时钟可完整刻画 happens-before 偏序，是因果一致系统的核心工具。

## 四、代码实现
```python
def send(vec, i):
    vec[i] += 1
    return list(vec)  # 附在消息上
def recv(vec, msg_vec, i):
    vec = [max(vec[k], msg_vec[k]) for k in range(len(vec))]
    vec[i] += 1
    return vec

def concurrent(a, b):
    le = all(x <= y for x, y in zip(a, b))
    ge = all(x >= y for x, y in zip(a, b))
    return not (le or ge)
```

## 五、与其他技术对比
- 相比 Lamport 时钟：可区分并发，代价是 O(N) 存储。
- 相比物理时钟：不依赖同步，纯粹因果。

## 六、常见误区
- 误区：向量时钟能给全局全序。只能判定因果/并发，不能全序。
- 误区：分量数固定不变。动态成员需加长/裁剪向量。

## 九、演进与趋势
紧凑向量时钟(Compact Vector Clock)、CRDT 广泛依赖向量时钟判定并发。

## 十、小结
向量时钟用 N 维计数器精确刻画 happens-before，使并发可被识别，是因果一致与 CRDT 的基础。
