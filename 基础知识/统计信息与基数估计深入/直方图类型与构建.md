# 直方图类型与构建

> 对应 PostgreSQL 官方文档「Histogram」与 MySQL 8.0 直方图特性，参考 Garcia-Molina 第12章。

## 一、背景与挑战
单列统计仅靠「distinct 值数」不足以刻画倾斜分布。直方图把列值范围分成桶（bucket）并记录每桶频次，使优化器对范围谓词与倾斜值的基数估计更准。

## 二、核心原理
等宽直方图（equi-width）每桶覆盖相同值域，对密集区域精度差；等高直方图（equi-height / SERIAL）每桶含相同行数，更抗倾斜；MySQL 8.0 采用 Singleton（低频值逐一记录）与 Equi-height 两类。PostgreSQL 用等高直方图配合 most_common_values。

## 三、形式化与数学基础
等高直方图桶边界 $b_0 < b_1 < \dots < b_k$ 满足：
$$ count(b_{i-1} \le x < b_i) \approx \frac{N}{k} $$
对某桶内值 $v$ 的选择性估计：
$$ sel(v) \approx \frac{bucket\_rows}{distinct\_in\_bucket \cdot total\_rows} $$

## 四、代码实现
```sql
-- MySQL 8.0 建直方图
ANALYZE TABLE orders UPDATE HISTOGRAM ON amount WITH 32 BUCKETS;
-- 查看
SELECT * FROM information_schema.COLUMN_STATISTICS;
```

## 五、与其他技术对比
PostgreSQL 的直方图与 MCV（most common values）列表协同处理长尾；MySQL 8.0 直方图对无法建索引的列（如表达式、大文本前缀）特别有用。

## 六、常见误区
认为直方图替代索引——它只辅助估计，不改变访问路径本身。认为桶越多越好——过多桶增加存储与分析开销，且更新成本上升。

## 七、与开源书/权威来源对应
PostgreSQL 文档「Statistics Used by the Planner」；Garcia-Molina 12.5「Histograms」。

## 八、面试题
问：等高与等宽直方图区别？答：等高每桶行数相等抗倾斜，等宽每桶值域相等实现简单但密集区失真。

## 九、演进与趋势
多维直方图（如 2D 直方图、基于采样的近似直方图）处理列间相关性，是提升基数估计的研究热点。

## 十、小结
直方图通过刻画分布弥补单列均值统计不足，是倾斜数据下计划准确的关键。
