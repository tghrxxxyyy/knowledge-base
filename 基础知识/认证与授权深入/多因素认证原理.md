# 多因素认证原理

> 对应 OWASP Authentication Cheat Sheet / Saltzer & Schroeder 1975 认证原则。

## 一、背景与挑战
单因子(口令)易被钓鱼、撞库、爆破。多因素(MFA)结合知识、持有、生物三类中的两类，显著提升账户抗篡改性。

## 二、核心原理
三类因子：Something you know(口令/ PIN)、have(手机/硬件 Token)、are(指纹/人脸)。MFA 要求跨类组合，单因子泄露不致命。TOTP 基于时间窗口共享密钥生成 6 位码。

## 三、形式化与数学基础
破解单因子概率 $p$；两独立因子：
$$ P_{break} = p_1 \times p_2 $$
TOTP 码：
$$ code = HMAC(secret, \lfloor t / 30 \rfloor) \bmod 10^6 $$
30 秒窗口内有效。

## 四、代码实现
```python
# TOTP 简化(需 pyotp/真实 HMAC)
import hmac, hashlib, time, struct
def totp(secret: bytes, t=time.time(), step=30, digits=6):
    c = int(t)//step
    msg = struct.pack(">Q", c)
    h = hmac.new(secret, msg, hashlib.sha1).digest()
    o = h[-1] & 0xf
    code = (struct.unpack(">I", h[o:o+4])[0] & 0x7fffffff) % 10**digits
    return str(code).zfill(digits)
```

## 五、与其他技术对比
SMS OTP 易被 SIM 交换攻击；TOTP 不依赖运营商；FIDO/WebAuthn 用公钥抗钓鱼更优。MFA 与 SSO 正交。

## 六、常见误区
把"两个口令"当两因子(同类)。SMS 视为强因子。MFA 疲劳攻击(反复推送)绕过。

## 七、与开源书/权威来源对应
OWASP Auth Cheat Sheet；RFC 6238(TOTP)；Saltzer & Schroeder 认证原则。

## 八、面试题
三因子类别？TOTP 为何抗重放？FIDO 优势？

## 九、演进与趋势
WebAuthn/Passkeys 无口令密钥；自适应风险认证(行为/设备指纹)。

## 十、小结
MFA 以跨类因子乘积降低破解概率，TOTP 简便、FIDO 抗钓鱼，是现代认证标配。
