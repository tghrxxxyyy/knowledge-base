# 口令存储与慢哈希

> 对应 OWASP Password Storage Cheat Sheet / 《CSAPP》安全章节。

## 一、背景与挑战
明文或弱哈希(MD5/SHA1)存储口令，一旦库泄露攻击者可离线爆破。需加盐慢哈希使离线猜测代价高昂。

## 二、核心原理
每个用户独立随机盐(salt)防止彩虹表；慢哈希(bcrypt/scrypt/Argon2)可调成本(迭代/内存)，故意拖慢单次验证以惩罚批量猜测。Argon2 获 2015 Password Hashing Competition 冠军。

## 三、形式化与数学基础
猜测代价：
$$ Cost = N_{users} \times 2^{entropy} \times t_{hash} $$
慢哈希使 $t_{hash}$ 从微秒级升至数十毫秒级；内存硬(scrypt/Argon2)额外占用 $m$ 内存抑制 GPU/ASIC 并行。

## 四、代码实现
```python
# 使用 Argon2id (需 argon2-cffi)
from argon2 import PasswordHasher
ph = PasswordHasher()
hash = ph.hash("user_password")     # 自动加盐与参数
ok = ph.verify(hash, "user_password")  # 常数时间比较
```

## 五、与其他技术对比
bcrypt 成熟但内存软；scrypt 内存硬；Argon2id 兼顾侧信道抵抗，当前推荐。plain SHA 绝不可用于口令。

## 六、常见误区
自定义哈希("SHA256+MD5")自欺。固定盐或全局盐无效。用快速哈希导致可并行爆破。

## 七、与开源书/权威来源对应
OWASP Password Storage；Argon2 RFC 9106；CSAPP 提及哈希与盐。

## 八、面试题
为何加盐？bcrypt 与 Argon2 区别？慢哈希目的？

## 九、演进与趋势
Argon2id 为默认推荐；服务器 Relief/pepper 进一步保护；无口令(MFA/Passkey)减少口令依赖。

## 十、小结
口令必须用每用户盐+慢哈希(Argon2id)存储，把离线爆破成本提到不现实，是泄露后最后防线。
