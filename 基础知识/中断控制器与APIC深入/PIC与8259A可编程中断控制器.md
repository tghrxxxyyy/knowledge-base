# PIC与8259A可编程中断控制器

> 对应 Intel SDM 卷3 与 Hennessy & Patterson《Computer Architecture》。

## 一、背景与挑战
早期 x86 用 8259A 可编程中断控制器把外部设备中断汇聚到单条 INTR 线。8259A 只支持 8 级（两片级联 15 级），且默认 IRQ 向量冲突、缺乏多处理器亲和，无法适配 SMP 与大量设备。

## 二、核心原理
8259A 通过 ICW/OCW 命令字初始化与屏蔽，将 IRQ 映射到中断向量（出厂默认 0x08-0x0F，常被重映射到 0x20 起以避免与异常冲突）。中断请求经优先级仲裁后向 CPU 发 INTR，CPU 响应后发 INTA 取向量。

## 三、形式化与数学基础
两片级联时从片 INT 连到主片 IR 线 $k$，总可路由中断数为：

$$ N = 8 + (8 - 1) = 15 $$

向量映射为：

$$ V(i) = \text{base} + i,\quad i \in [0,15) $$

## 四、代码实现
重映射主从片的初始化（8259A 风格）：

```c
outb(0x20, 0x11);          // 主片 ICW1：边沿触发、级联
outb(0x21, 0x20);          // ICW2：主片向量基 0x20
outb(0x21, 0x04);          // ICW3：IR2 接从片
outb(0x21, 0x01);          // ICW4：x86 模式
outb(0xA0, 0x11);
outb(0xA1, 0x28);          // 从片向量基 0x28
outb(0xA1, 0x02);
outb(0xA1, 0x01);
```

## 五、与其他技术对比
8259A 简单但级联复杂、向量少、无亲和；APIC 提供每 CPU 本地控制器与 I/O APIC，支持更多中断与路由；MSI 绕过 I/O APIC 直接写 CPU 寄存器，降低延迟。现代 x86 仍保留 8259A 仿真以兼容旧系统。

## 六、常见误区
认为 IRQ 号等于中断向量号，二者需经映射；认为中断优先级由设备物理连线固定，实际可重映射；认为 PIC 已完全消失，实际在单核与兼容性路径仍可见。

## 七、与开源书/权威来源对应
Intel SDM 卷3 第 10 章详述 8259A 与 APIC；Hennessy & Patterson《Computer Architecture》讨论中断硬件；Linux 内核 Documentation/irq/ 描述中断域。

## 八、面试题
8259A 两片级联为何只有 15 条线；为何要重映射向量基；PIC 与 APIC 的核心差异；INTR 与异常的区别。

## 九、演进与趋势
PIC 被 APIC 与 MSI 取代，但固件仍提供仿真；虚拟化中将 PIC 交给 VMM 模拟以支持老旧客户机。

## 十、小结
8259A 是可编程中断控制器的经典实现，用命令字完成初始化与路由，但因向量数与 SMP 限制被 APIC 取代，仍是理解中断硬件演进的起点。
