# 三地址码

> 对应 龙书 第 8 章 与 Appel 第 7 章。

## 一、背景与挑战
三地址码 (TAC) 是接近汇编但每条至多一个运算符的线性 IR。挑战：如何扁平化表达式、临时变量命名、表示控制流（跳转/标号）。

## 二、核心原理
每条指令形如 `x = y op z` 或 `x = op y` 或 `goto L` 或 `if x goto L`。复杂表达式拆成多条，引入临时 `t1, t2...`。

## 三、形式化 / 数学基础
表达式 `a + b * c` 翻译：
`t1 = b * c`
`t2 = a + t1`
一个算子一个临时，操作数至多两个，故"三地址"。

## 四、代码实现
```python
def emit(op, a, b=None):
    if b is None: return f"{tmp()} = {op} {a}"
    return f"{tmp()} = {a} {op} {b}"
# a + b*c -> t1=b*c; t2=a+t1
```

## 五、与其他技术对比
- TAC：线性、易生成、接近目标；无显式控制流图。
- 抽象语法树：结构清晰但需多次遍历。
- SSA：TAC 的升级，变量单次赋值便于分析。

## 六、常见误区
1. 在单条 TAC 写多算子（破坏"三地址"假设）。
2. 混淆标号与变量。
3. 用 TAC 直接做优化而不先建 CFG。

## 十、小结
三地址码把高级表达式压平为单算子指令，是连接 AST 与目标码/SSA 的通用中间表示。
