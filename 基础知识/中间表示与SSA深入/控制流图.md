# 控制流图

> 对应 龙书 第 8.4 节 与 Kennedy & Allen。

## 一、背景与挑战
控制流图 (CFG) 以基本块 (basic block) 为节点、以跳转为边。挑战：正确划分基本块、处理异常/不可达、供数据流分析使用。

## 二、核心原理
基本块：入口进、出口出、内部无分支/汇合。边表示可能流向。`entry`→首块，含 `return` 的块→`exit`。

## 三、形式化 / 数学基础
支配 (dominance)：$d$ 支配 $n$ 若每路径 entry→$n$ 经 $d$（记 $d\ \mathrm{dom}\ n$）。必经点树 (dominator tree) 用于 SSA 构建。后支配同理反向。

## 四、代码实现
```python
def blocks(instrs):
    b, cur = [], []
    for i in instrs:
        if i.is_label() or (cur and instrs[pre].is_branch()):
            if cur: b.append(cur)
            cur = []
        cur.append(i)
    if cur: b.append(cur)
    return b
```

## 五、与其他技术对比
- CFG：显式控制，供优化；TAC 列表：无显式流。
- 依赖图 (DG)：数据流视角；CFG：控制视角。
- 支配树：CFG 的派生结构，SSA 依赖它。

## 六、常见误区
1. 基本块跨越分支目标（应在标号处切分）。
2. 忽视不可达块致优化误判。
3. 把异常边漏掉（Java 需可抛边）。
