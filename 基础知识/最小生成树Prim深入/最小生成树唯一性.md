# 最小生成树唯一性

> 对应 Kozen《The Design and Analysis of Algorithms》MST 唯一性讨论；CLRS 第 23 章习题；次小生成树（严格/非严格）经典论文与竞赛题（如「次小生成树」）。

## 一、背景与挑战

Prim、Kruskal、Boruvka 都给出「一棵」最小生成树，但自然要问：**MST 是不是唯一的？** 若图中存在权相同的多条可替换边，往往有多棵 MST；若所有边权互异，则 MST 必唯一。这个问题不只是理论趣味——它直接影响：

- **方案数统计**：有几棵不同的 MST（$2^{\#等权可替换边}$ 量级）；
- **次小生成树（Second Best MST）**：严格次小、非严格次小的求法；
- **鲁棒性**：当某条边失效时，是否有唯一的备选；
- **竞赛题**：判断 MST 是否唯一、求所有 MST 总权之和、输出任意一棵非唯一 MST。

一个典型错误是「看到有两条等长边就断定不唯一」——等长边未必同时出现在同一环上、未必可互相替换。必须结合**环性质**与**权分组**精确判定。本文给出唯一性定理、判定算法与次小生成树的完整思路。

## 二、核心原理

**唯一性定理。** 下列陈述等价（对连通图 $G$）：

1. $G$ 的 MST 唯一。
2. 对每条非树边 $e$（在任意一棵 MST $T$ 外），$w(e) > \max_{f \in \text{path}_T(u,v)} w(f)$，即 $e$ **严格**大于它在 $T$ 中对应环上的最大边权。
3. 不存在两条等权边 $e_1, e_2$ 使得它们在某个环上、且权都是该环最大。
4. （充分条件）所有边权互异。

**判定思路（按权分组）。** 把边按权从小到大处理，同一权值 $w$ 的边一组。处理到该组时，图中已有部分森林 $F$（权 $<w$ 的边已定）：

- 若组内某条边连接的两端在 $F$ 的同一连通分量中，则该边是「非树边」，其环上最大边权可能就是 $w$；
- 更关键的是：若组内存在边 $(u,v)$ 使 $u,v$ 在加入本组边之前就连通，且本组边中有多条可替换选择，则 MST 不唯一。

**实用判定（简洁正确版）：** 跑 Kruskal，对每条非树边 $(u,v,w)$，用**树上倍增/LCA** 查询路径 $u\to v$ 上的最大边权 $max_e$：

- 若 $w == max_e$，说明可用该非树边替换树边，得到另一棵同权 MST → **不唯一**；
- 若对所有非树边都有 $w > max_e$，则唯一。

复杂度：Kruskal $O(E\log E)$ + 每条非树边 $O(\log V)$ 倍增查询，总 $O(E\log E)$。

**次小生成树。** 设 MST 总权 $W$：

- **非严格次小**：$\min\{w(T'): T' \text{ 是生成树}, w(T')\ge W, T'\neq T\}$，可能 $=W$（当不唯一时）。
- **严格次小**：$>W$ 的最小生成树。

求法：对每条非树边 $e=(u,v)$，用它替换 $T$ 上路径最大边（或严格次大边）得到候选：

$$W' = W + w(e) - \max_{f\in path(u,v)} w(f).$$

取所有候选最小即非严格次小；严格次小则要求 $w(e) > \max$ 或取次大替换，保证 $W'>W$。

**边界条件。** 重边：同端点多条边本身就是替换源；自环不影响；不连通时谈「森林的唯一性」；权相等但不在同一环上不影响唯一性。

## 三、形式化与数学基础

**交换论证（非树边替换）。** 对 MST $T$ 与非树边 $e=(u,v)$，$T+e$ 含唯一环 $C$。若 $\exists f\in C, w(f)=w(e)$，则 $T' = T - f + e$ 仍是 MST 且 $T'\neq T$ → 不唯一。若 $\forall f\in C, w(f)<w(e)$，则任何替换都会使权增大 → $e$ 不能产生另一棵 MST。

**权互异 ⇒ 唯一。** 设边权两两不同。假设有两棵不同 MST $T_1, T_2$，取 $e\in T_1\setminus T_2$，由环性质 $T_2+e$ 的环上存在 $f\notin T_1$ 且 $w(f)=w(e)$ 才能相等替换，与互异矛盾。故唯一。

**非唯一时的方案数。** 若有 $k$ 组「等权可替换边」，每组贡献因子 2（或组合数），方案数为各组乘积。精确计数需枚举权组内连通性，$O(E\log E)$ 可做。

**次小生成树公式。** 设 $M(e) = \max_{f\in path_T(u_e,v_e)} w(f)$，$M_2(e)$ 为路径上严格次大：

$$\text{非严格次小} = \min_{e\notin T} \bigl(W + w(e) - M(e)\bigr),$$
$$\text{严格次小} = \min_{e\notin T} \bigl(W + w(e) - M_2(e)\bigr) \text{ 或 } w(e)>M(e) \text{ 的替换}.$$

**倍增预处理。** 树上 `up[k][v]` 与 `mx[k][v]`、`mx2[k][v]` 记录 $2^k$ 祖先与路径最大/次大边权，查询 $O(\log V)$。

## 四、代码实现

完整可运行的 MST 唯一性判定（Kruskal + 树上倍增查路径最大边）：

```python
import sys
from collections import defaultdict

sys.setrecursionlimit(100000)


def mst_unique(n, edges):
    """
    edges: [(u, v, w), ...] 顶点 0..n-1，图连通
    返回 (是否唯一, MST总权, MST边列表)
    """
    edges = sorted(edges, key=lambda e: e[2])
    parent = list(range(n))
    rank = [0] * n

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    def union(a, b):
        ra, rb = find(a), find(b)
        if ra == rb:
            return False
        if rank[ra] < rank[rb]:
            ra, rb = rb, ra
        parent[rb] = ra
        if rank[ra] == rank[rb]:
            rank[ra] += 1
        return True

    mst = []
    total = 0
    in_tree = set()
    for u, v, w in edges:
        if union(u, v):
            total += w
            mst.append((u, v, w))
            in_tree.add((min(u, v), max(u, v), w))

    if len(mst) != n - 1:
        return False, total, mst  # 不连通，按需处理

    # 建 MST 树
    g = [[] for _ in range(n)]
    for u, v, w in mst:
        g[u].append((v, w))
        g[v].append((u, w))

    LOG = max(1, (n).bit_length())
    up = [[-1] * n for _ in range(LOG)]
    mx = [[-10**18] * n for _ in range(LOG)]
    mx2 = [[-10**18] * n for _ in range(LOG)]
    depth = [0] * n

    def dfs(u, p):
        for v, w in g[u]:
            if v == p:
                continue
            up[0][v] = u
            mx[0][v] = w
            mx2[0][v] = -10**18
            depth[v] = depth[u] + 1
            dfs(v, u)

    dfs(0, -1)
    for k in range(1, LOG):
        for v in range(n):
            if up[k - 1][v] != -1:
                up[k][v] = up[k - 1][up[k - 1][v]]
                # 合并两段路径的最大与严格次大
                a, b = mx[k - 1][v], mx[k - 1][up[k - 1][v]]
                a2, b2 = mx2[k - 1][v], mx2[k - 1][up[k - 1][v]]
                cand = [a, b, a2, b2]
                cand.sort(reverse=True)
                mx[k][v] = cand[0]
                mx2[k][v] = next((x for x in cand[1:] if x != cand[0]), -10**18)

    def path_max2(u, v):
        if depth[u] < depth[v]:
            u, v = v, u
        best = [-10**18, -10**18]

        def upd(x):
            if x > best[0]:
                best[1] = best[0] if best[0] != x else best[1]
                best[0] = x
            elif x != best[0] and x > best[1]:
                best[1] = x

        diff = depth[u] - depth[v]
        bit = 0
        while diff:
            if diff & 1:
                upd(mx[bit][u])
                upd(mx2[bit][u])
                u = up[bit][u]
            diff >>= 1
            bit += 1
        if u == v:
            return best
        for k in range(LOG - 1, -1, -1):
            if up[k][u] != up[k][v]:
                upd(mx[k][u]); upd(mx2[k][u])
                upd(mx[k][v]); upd(mx2[k][v])
                u, v = up[k][u], up[k][v]
        upd(mx[0][u]); upd(mx[0][v])
        return best

    unique = True
    for u, v, w in edges:
        if (min(u, v), max(u, v), w) in in_tree:
            continue
        best = path_max2(u, v)
        if w == best[0]:
            unique = False   # 等权可替换 → 不唯一
            break
    return unique, total, mst


if __name__ == "__main__":
    # 唯一：三角形权 1,2,4
    e1 = [(0, 1, 1), (1, 2, 2), (0, 2, 4)]
    u1, t1, _ = mst_unique(3, e1)
    print(u1, t1)            # True 3
    assert u1 and t1 == 3

    # 不唯一：权 1,1,2 的三角，两条 1 边可换
    e2 = [(0, 1, 1), (1, 2, 1), (0, 2, 2)]
    u2, t2, _ = mst_unique(3, e2)
    print(u2, t2)            # False 2
    assert (not u2) and t2 == 2
```

## 五、与其他技术对比

| 问题 | 方法 | 复杂度 | 说明 |
|------|------|--------|------|
| 判 MST 是否唯一 | Kruskal + 路径最大边 | $O(E\log E)$ | 等权替换即不唯一 |
| 权互异 | 排序去重 | $O(E\log E)$ | 充分非必要 |
| 非严格次小 | 替换路径最大边 | $O(E\log E)$ | 可 $=W$ |
| 严格次小 | 严格次大/约束替换 | $O(E\log E)$ | $>W$ |
| 方案数 | 权组组合计数 | $O(E\log E)$ | 2 的幂次乘积 |
| 所有 MST 枚举 | 回溯 + 等权边 | 指数 | 仅小图 |

与「Kruskal 唯一性」的误区相对：只比较是否存在等长边是不够的，必须验证等长边是否在树上同一路径/环上可替换。

## 六、常见误区

1. **只要有等权边就不唯一。** 错。若等权边不在同一环上、或不能替换树边，MST 仍唯一。必须查非树边与路径最大边是否相等。
2. **用「非树边 $w \ge$ 路径最大」判断不唯一。** $w > \max$ 是合法非树边（正常），只有 $w = \max$ 才产生替换；写成 `>=` 会把唯一误判为不唯一。
3. **忘记重边本身即可替换。** 同端点两条等权边直接给出两棵 MST，判定与次小都要纳入。
4. **次小生成树误用「非严格」结果当「严格」。** 不唯一时非严格次小 $=W$；严格次小必须强制 $>W$，常用「替换严格次大边」或「排除等权替换」。
5. **不连通图谈「唯一 MST」。** 无 MST，只有最小生成森林；唯一性要按各连通分量分别讨论。
6. **倍增合并最大/次大时把相同值当次大。** 需要**严格**次大，否则严格次小会错。

## 八、面试题

**1. MST 何时唯一？如何判定？**
参考答案：对任意非树边 $e$，$w(e)$ 必须严格大于其在树上路径的最大边权；等价不存在等权可替换边。权互异是充分条件。判定：Kruskal 建树 + 倍增查路径最大边，看是否有相等。

**2. 求严格次小生成树。**
参考答案：对每条非树边 $e$，用其替换树上路径的严格次大边（或仅在 $w(e)>\max$ 时替换最大边），候选 $W+w(e)-\text{替换边权}$，取最小且 $>W$。

**3. 有两条权相同的边，MST 一定不唯一吗？**
参考答案：不一定。只有当它们能形成替换（同环、权均为最大）时才不唯一。例如两条等权边分别在不同分支上，仍可能唯一。

**4. 如何统计不同 MST 的棵数？**
参考答案：按权分组，每组内把已连通性视为约束，等权可替换边贡献因子；用组合乘积计数。小图可枚举，大图 $O(E\log E)$ 动态维护。

## 九、演进与趋势

- **次小生成树与 k-MST**：网络设计中要求备份路径，严格次小 MST 是冗余度度量；k-MST、最小瓶颈生成树有广泛应用。
- **鲁棒 MST**：边权不确定（区间权、随机权）下的唯一性与期望 MST，用于网络规划与近似算法。
- **动态唯一性**：边增删时维护 MST 与唯一性标志（HDLT 动态 MST 等），服务在线拓扑。
- **竞赛与教学**：唯一性判定 + 次小 MST 是 NOI/ICPC 高频；训练时与「Kruskal 重构树」「倍增」结合。
- **工程**：数据中心链路规划、光网络拓扑冗余设计需要「唯一 MST 或最小备份」，唯一性与次小是可运维性指标。

## 十、小结

MST 唯一当且仅当不存在等权可替换边（非树边权严格大于路径最大边权）；权互异是常见充分条件。用 Kruskal 建树 + 倍增查路径最大/次大边，可在 $O(E\log E)$ 内判定唯一性并求严格/非严格次小生成树——这是 MST 理论从「求一棵」走向「求稳健性与备选」的关键一步。
