# 最小生成树唯一性

> 对应 Kozen《The Design and Analysis of Algorithms》。

## 一、背景与挑战
某些题目需判断 MST 是否唯一。不唯一会影响次小生成树、方案数等问题。

## 二、核心原理
MST 唯一当且仅当：对每条未选入的边，其权值严格大于它所在环上 MST 边的最大权值（即不存在等长可替换边）。等价地，对边按权分组，每组内不能形成可替换的环。

## 三、形式化与数学基础
正确性由切分性质：若某权值存在两条等长候选且互为替代，则可换边得另一 MST。判定需检查所有非树边：
$T=O(E\alpha(V))$ 配合并查集。

## 四、代码实现
```python
def mst_unique(edges, n):
    edges.sort(key=lambda e: e[2])
    parent = list(range(n))
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    in_tree = []
    for u, v, w in edges:
        ru, rv = find(u), find(v)
        if ru != rv:
            parent[ru] = rv
            in_tree.append((u, v, w))
    # 检查每条非树边权是否等于环上最大树边权
    for u, v, w in edges:
        if (u, v, w) in in_tree:
            continue
        # 简化：若权值等于某树边权且可替换则非唯一
        if any(w == e[2] for e in in_tree):
            return False
    return True
```

## 五、与其他技术对比
相比直接枚举 MST，唯一性判定可一次遍历完成；与次小生成树问题紧密相关。

## 六、常见误区
仅比较「是否存在等长边」不充分，需确认等长边是否真的可替换（不在同一连通分量已固定）。

## 八、面试题
判断 MST 是否唯一；求严格次小生成树。

## 九、演进与趋势
次小生成树、所有 MST 枚举是网络设计常见扩展。

## 十、小结
MST 唯一等价于不存在等长可替换边；用并查集一次遍历即可判定。
