# 对象模型

> 对应 CS-Notes（JVM/Python 对象）与 Crafting Interpreters（Lox 对象）。

## 一、背景与挑战
面向对象语言需高效表示对象、类、方法分派、字段布局。挑战：单/多继承、动态字段、内存布局、与原型/类模型差异。

## 二、核心原理
类模型：每个对象含指向类/原型指针与字段数组；方法存于类（共享）。原型模型（JS/Self）：对象直接含成员，克隆原型。内联缓存加速方法查找。

## 三、形式化 / 数学基础
对象 $o=(class\_ptr, [f_1..f_n])$。方法 查找 $lookup(C, m)$：沿类链直至找到 $m$。字段偏移在类加载时固定，访问 $O(1)$。

## 四、代码实现
```c
typedef struct Obj {
    Class* klass;
    Value fields[];
} Obj;
Value get_field(Obj* o, int slot) { return o->fields[slot]; }
```

## 五、与其他技术对比
- 类模型（Java）：字段偏移固定、共享方法。
- 原型（JS）：灵活、查找链长、靠 IC 加速。
- 字典对象（Python）：属性动态、哈希查找、慢但灵活。

## 六、常见误区
1. 以为对象里存方法（其实存于类，省内存）。
2. 混淆类偏移与实例布局。
3. 动态语言把属性当字段（实为哈希表）。
