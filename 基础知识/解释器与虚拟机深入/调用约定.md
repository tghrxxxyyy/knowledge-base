# 调用约定

> 对应 CS-Notes（JVM/系统调用）与 龙书 第 15 章（活动记录）。

## 一、背景与挑战
调用约定规定参数如何传、栈帧布局、谁保存寄存器、返回如何。挑战：跨语言互操作、递归帧、异常展开、尾调用。

## 二、核心原理
活动记录 (activation record)：返回地址、旧基址、参数、局部变量、被调用者保存寄存器。调用者/被调用者各按约定保存/恢复。

## 三、形式化 / 数学基础
栈帧布局（典型 x86-64 System V）：参数 `%rdi,%rsi,%rdx,%rcx,%r8,%r9` 及栈上；`%rbp` 基址、`%rsp` 栈顶；调用者保存 `%rax` 返回值。

## 四、代码实现
```asm
caller:
    mov rdi, 1        ; 参数1
    call callee       ; 压返回地址, 跳
callee:
    push rbp
    mov rbp, rsp
    ; ... 局部 ...
    pop rbp
    ret
```

## 五、与其他技术对比
- cdecl/sysv/ms：不同寄存器/栈规则。
- 寄存器传参（x86-64）：快于纯栈（x86-32）。
- VM 调用约定：自定帧（如 JVM 解释器帧）。

## 六、常见误区
1. 调用者/被调用者保存寄存器混淆致值丢。
2. 栈未对齐（x86-64 需 16 字节）致崩溃。
3. 忘记返回地址是调用者压的。

## 九、演进与趋势
影子空间 (shadow space)、零成本抽象（Rust）、以及尾调用入 ABI（如 Safari/Wasm）。

## 十、小结
调用约定是"函数如何互连"的合约：活动记录 + 寄存器约定 + 对齐共同保证正确高效的调用，是编译后端与 FFI 的基础。
