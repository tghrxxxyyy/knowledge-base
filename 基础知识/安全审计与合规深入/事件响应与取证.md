# 事件响应与取证

> 对应 NIST SP 800-61 (计算机安全事件处理) / OWASP。

## 一、背景与挑战
入侵发生后，响应慢或处置错会扩大损失、破坏证据。需规范流程保全证据并恢复。

## 二、核心原理
NIST 四阶段：准备→检测分析→遏制/根除/恢复→事后总结。取证需保证证据链完整(哈希校验)、隔离介质、 chronological 时间线重建。

## 三、形式化与数学基础
证据完整性：
$$ H(evidence_{acquired}) = H(original) $$
任何偏差即不可信。MTTR(平均恢复时间)衡量响应效率：
$$ MTTR = \frac{1}{n}\sum (t_{resolve}-t_{detect}) $$

## 四、代码实现
```bash
# 取证: 对内存/磁盘镜像做哈希保全(示意)
sha256sum mem.dump > mem.sha256      # 记录原始哈希
# 仅在副本上分析, 保留原像
cp mem.dump mem.working
# 时间线工具重建事件
```

## 五、与其他技术对比
事件响应偏处置与恢复，取证偏证据保全与归因，二者在遏制阶段交叉。与渗透测试(攻)互补(防)。

## 六、常见误区
直接在受影响主机操作破坏证据。未隔离导致横向扩散。无预案临时慌乱。

## 七、与开源书/权威来源对应
NIST SP 800-61；OWASP Incident Response；常见 SIEM 用于检测。

## 八、面试题

## 九、演进与趋势
SOAR 自动化响应、EDR 端点取证、威胁情报驱动。

## 十、小结
事件响应以规范流程快速遏制恢复，取证靠哈希保全证据链，二者结合既止损又归因。
