# 渗透测试方法论

> 对应 OWASP Testing Guide / OWASP Top 10 / PTES 标准。

## 一、背景与挑战
防御需以攻验防。渗透测试按结构化流程发现真实可利用漏洞，避免盲目扫描或越界违法。

## 二、核心原理
阶段：授权范围界定→ reconnaissance(信息收集)→威胁建模→漏洞扫描与利用→后渗透(提权/横向移动)→报告。OWASP WSTG 覆盖 Web 各层测试(注入、认证、配置)。

## 三、形式化与数学基础
攻击面量化：
$$ A = \bigcup endpoints,\ risk = \sum_{e \in A} Impact(e)\times Likelihood(e) $$
测试覆盖度：
$$ Coverage = \frac{tested}{total\_endpoints} $$

## 四、代码实现
```bash
# 授权范围内的自动化测试(示意, 需书面授权)
# 仅对自有目标运行
nmap -sV --script=http-enum target.internal
# OWASP ZAP 基线扫描
zap-baseline.py -t https://test.target -r report.html
```

## 五、与其他技术对比
渗透测试是时点人工+工具验证；红蓝对抗持续更全面；漏洞扫描是自动化前置。三者递进。

## 六、常见误区
无书面授权即测试违法。只跑工具不人工验证误报。忽略业务逻辑漏洞(非技术)。

## 七、与开源书/权威来源对应
OWASP WSTG；PTES；OWASP Top 10(A03 注入/A01 越权 等)。

## 八、面试题

## 九、演进与趋势
自动化持续渗透、攻击图驱动、合规化测试即服务。

## 十、小结
渗透测试依授权结构化发现可利用漏洞，OWASP 方法论覆盖 Web 全层，是验证防御的有效手段。
