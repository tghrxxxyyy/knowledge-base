# 区间调度与活动选择问题

> 对应 CLRS《Introduction to Algorithms》16.1 节（Activity Selection）与 youngyangyang04/leetcode-master 贪心章节。

## 一、背景与挑战
给定 $n$ 个区间 $[s_i, f_i)$，求互不重叠的最大区间数。这是调度、资源分配的核心模型，朴素枚举为指数级。

## 二、核心原理
按结束时间升序排序，每次选择结束最早且与已选区间不冲突的活动。直觉是：结束越早，留给后续的时间越多。

## 三、形式化与数学基础
设已选集合 $A$，当前考虑活动 $a_k$。贪心选择性质：存在最优解包含 $a_1$（结束最早者）。递推子问题为 $S_k = \{a_i \mid f_i \le s_k\}$。

## 四、代码实现
```python
def max_activities(intervals):
    # intervals: list of (start, end)
    intervals.sort(key=lambda x: x[1])
    count = 0
    last_end = -1
    for s, f in intervals:
        if s >= last_end:
            count += 1
            last_end = f
    return count
```

## 五、与其他技术对比
与按开始时间排序的贪心相比，按结束时间排序才能保证最优；与加权区间调度（需 DP）不同，本问题所有区间权重相等。

## 六、常见误区
- 按开始时间排序后贪心，得到错误结果。
- 把"最大不重叠区间数"与"最少删除使不重叠"混淆（二者答案互补但模型不同）。

## 九、演进与趋势
区间调度扩展到带权重（DP/拟阵）、带机器数（并行机调度），乃至实时系统的 EDF 调度。

## 十、小结
结束时间贪心是区间调度的最优解，关键是理解"早结束留更多余量"的贪心选择性质。
