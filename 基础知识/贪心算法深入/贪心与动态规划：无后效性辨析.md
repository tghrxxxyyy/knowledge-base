# 贪心与动态规划：无后效性辨析

> 对应 Bellman 1962（DP 最优化原理）与 CLRS 第 15、16 章对比。

## 一、背景与挑战
许多优化问题既可用贪心也可用 DP 思路，但只有满足特定性质才能贪心。混淆二者是工程事故根源。

## 二、核心原理
- 贪心：每步决策只依赖当前状态，且一旦决定不可回退。
- DP：决策影响未来子问题，需保留所有子问题最优解供组合。
本质区别在于"无后效性"是否对局部最优成立。

## 三、形式化与数学基础
DP 最优化原理：$f(s)=\min_{a}\{g(a)+f(s'\mid a)\}$。当对任意最优剩余子问题，首步选择固定的贪心动作 $a^*$ 即最优时，可退化为贪心。

## 四、代码实现
```python
# 0-1 背包必须 DP
def knapsack_dp(w, v, cap):
    dp = [0] * (cap + 1)
    for i in range(len(w)):
        for c in range(cap, w[i] - 1, -1):
            dp[c] = max(dp[c], dp[c - w[i]] + v[i])
    return dp[cap]

# 分数背包可贪心（按价值密度）
def fractional_knapsack(items, cap):
    items.sort(key=lambda x: x[1] / x[0], reverse=True)
    gain = 0.0
    for w, v in items:
        if cap >= w:
            gain += v
            cap -= w
        else:
            gain += v * cap / w
            break
    return gain
```

## 五、与其他技术对比
分数背包贪心得最优；0-1 背包必须 DP。区分点在于"能否分割"——可分割带来无后效性。

## 六、常见误区
- 把 0-1 背包当分数背包贪心，导致次优。
- 误以为所有"选或不选"都能贪心。

## 九、演进与趋势

## 十、小结
能否贪心取决于"局部最优能否保证全局最优"；不确定时优先 DP，贪心需证明。
