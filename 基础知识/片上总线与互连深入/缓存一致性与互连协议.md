# 缓存一致性与互连协议

> 对应 Hennessy & Patterson 量化方法一致性互连章（snooping 与 directory）。

## 一、背景与挑战
多核共享内存必须保持一致。总线嗅探（snooping）适合小规模共享总线，目录（directory）适合大规模 NoC/多插槽，二者都依赖互连传递一致性消息。

## 二、核心原理
Snooping：所有核监听总线上的请求，维护 MESI 状态；写需广播 Invalidate。Directory：在目录节点记录每缓存行的拥有者/共享者位图，请求定向发送，避免广播。

## 三、形式化与数学基础
Snooping 广播开销随核数 $N$ 线性：
$$BusTraffic_{snoop} = O(N) \text{ per write}$$
Directory 定向开销：
$$BusTraffic_{dir} = O(Sharers) \le O(N)$$
位图存储开销为 $N$ 位/行。

## 四、代码实现
```c
// 目录处理读请求(简化)
struct dir_e { int owner; int sharers; } dir[MAX_LINE];
void handle_read(int line, int req) {
    if (dir[line].owner != -1) send_invalidate(dir[line].owner);
    dir[line].sharers |= (1 << req);   // 加入共享位图
    send_data(req, line);
}
```

## 五、与其他技术对比
Snooping 实现简单、延迟低，但不可扩展到多跳网络；Directory 可扩展、带宽优，但增加目录存储与间接延迟。

## 六、常见误区
误以为 snooping 总优于 directory：核数大时广播成瓶颈。误以为目录零开销：位图与间接访问有成本。

## 七、与开源书/权威来源对应
量化方法 snooping/directory；6.824 共识与复制类比；OSTEP 同步。

## 八、面试题
问：directory 如何避免广播？答：用位图定向发送失效给已知共享者。

## 九、演进与趋势
可扩展目录（如 scoped/limited）、以及 CXL 一致性扩展跨芯片。

## 十、小结
一致性协议与互连拓扑深度耦合：小规模靠嗅探，大规模靠目录，本质都是"谁有副本、如何失效"的工程权衡。
