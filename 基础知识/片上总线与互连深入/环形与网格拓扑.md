# 环形与网格拓扑

> 对应 Hennessy & Patterson 量化方法拓扑章与 Intel 多核互连（如 Ring/Mesh）分析。

## 一、背景与挑战
多核/多插槽系统的互连拓扑决定延迟、带宽与可扩展性。环形（ring）简单低延迟但带宽随核数饱和；网格（mesh）可扩展但跳数增多。

## 二、核心原理
环形将所有节点串成环，事务沿最短方向绕行，采用"环停止"转发。网格是二维阵列，需路由算法选择路径。二者都在一致域（如 Intel 的 UPI/Ring + 目录）上承载缓存一致性。

## 三、形式化与数学基础
环形最远跳数：
$$H_{ring} = \lfloor N/2 \rfloor$$
网格直径：
$$D_{mesh} = 2(\sqrt{N}-1)$$
聚合带宽：ring 为 $B_{per\_link}\times N/2$，mesh 随边数线性。

## 四、代码实现
```c
// 环形最短方向选择
int ring_dir(int cur, int dst, int N){
    int cw = (dst - cur + N) % N;       // 顺时针跳数
    int ccw = (cur - dst + N) % N;      // 逆时针跳数
    return (cw <= ccw) ? +1 : -1;       // 取近者
}
```

## 五、与其他技术对比
环形延迟低、适合 ≤~20 节点；网格可扩展到数百核但需路由与拥塞控制；交叉开关在极小系统更低延迟。

## 六、常见误区
误以为 ring 带宽无限：共享链路易饱和。误以为 mesh 总是更快：小系统 ring 更优。

## 七、与开源书/权威来源对应
量化方法拓扑与路由；Intel 多核架构白皮书；6.824 网络层类比。

## 八、面试题
问：ring 与 mesh 何时各自更优？答：小核数 ring 延迟低，大核数 mesh 带宽可扩展。

## 九、演进与趋势
混合拓扑（ring+mesh）、3D 堆叠网络降低平均跳数。

## 十、小结
拓扑是互连的骨架，选择需在延迟、带宽、面积间按规模权衡。
