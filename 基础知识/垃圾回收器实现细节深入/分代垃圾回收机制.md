# 分代垃圾回收机制

> 对应 Jones & Lins《Garbage Collection》第 8 章；Wilson 1992（GC 综述）。

## 一、背景与挑战
经验规律（弱分代假说）：多数对象短命。对全堆频繁回收浪费在大量临时对象上。分代 GC 把对象按年龄分区，重点回收年轻代。

## 二、核心原理
堆分年轻代（Eden+Survivor）与老年代。新对象入 Eden，Minor GC 用复制式回收年轻代，存活多次者晋升老年代。老年代用 Mark-Sweep/Compact，频率低。跨代引用由卡表（card table）记录，避免每次扫描老年代。

## 三、形式化与数学基础
弱分代假说：
$$P(存活至年龄\ a+1 \mid 存活至\ a) \ll 1$$
Minor GC 工作量 $\approx O(|Young|) \ll O(|Heap|)$。卡表以 $card[addr/512]$ 标记可能含跨代指针的页。

## 四、代码实现
```c
// 写屏障记录跨代引用
void write(obj *p, obj *child) {
    *field(p) = child;
    if (in_old(p) && in_young(child))
        card_table[((size_t)p) >> 9] = 1; // 标记卡
}
```

## 五、与其他技术对比
分代显著降暂停（多数回收只扫年轻代）；代价是写屏障开销与跨代指针管理；非分代 GC 简单但全堆扫描。

## 六、常见误区
1. 忽略写屏障会漏跨代引用致误回收。
2. 对象过早晋升（premature promotion）占满老年代。
3. 误以为分代解决全部碎片——老年代仍需紧凑。

## 七、与开源书/权威来源对应
Jones & Lins ch8；Wilson 1992；HotSpot G1/ZGC 设计文档。

## 八、面试题
问：弱分代假说？卡表作用？Minor/Major GC 区别？

## 九、演进与趋势
G1 把堆分 region 做可预测停顿；ZGC/Shenandoah 并发压缩把暂停与堆大小解耦。

## 十、小结
分代 GC 借对象年龄分布把回收聚焦于年轻代，以写屏障与卡表维持跨代正确性。
