# 二维树状数组

> 对应 TheAlgorithms/Python。

## 一、背景与挑战
矩阵单点加、矩形区域求和，朴素是 $O(mn)$。二维树状数组把每维都用 lowbit 分解，降到 $O(\log n\log m)$。

## 二、核心原理
`bit[x][y]` 管理以 $(x,y)$ 为右上角的矩形块；更新/查询时两重 lowbit 循环嵌套跳转。

## 三、形式化与数学基础
单次操作两层循环各 $O(\log)$：
$T=O(\log n\cdot\log m)$，空间 $O(nm)$。

## 四、代码实现
```python
class Fenwick2D:
    def __init__(self, n, m):
        self.n = n
        self.m = m
        self.bit = [[0] * (m + 1) for _ in range(n + 1)]
    def add(self, x, y, delta):
        i = x
        while i <= self.n:
            j = y
            while j <= self.m:
                self.bit[i][j] += delta
                j += j & (-j)
            i += i & (-i)
    def query(self, x, y):
        s = 0
        i = x
        while i > 0:
            j = y
            while j > 0:
                s += self.bit[i][j]
                j -= j & (-j)
            i -= i & (-i)
        return s
```

## 五、与其他技术对比
相比二维线段树，二维 BIT 代码短、常数小；缺点同样只支持前缀/单点类操作。

## 六、常见误区
两维都要 1-indexed；矩形求和需四角容斥：`q(x2,y2)-q(x1-1,y2)-q(x2,y1-1)+q(x1-1,y1-1)`。

## 七、与开源书/权威来源对应
TheAlgorithms/Python 的 2D Fenwick 实现；Sedgewick《Algorithms》多维索引。

## 八、面试题
用 2D BIT 做矩阵点加与矩形和；四角容斥公式？

## 九、演进与趋势
与差分结合支持矩形区域加；压缩行/列处理稀疏大矩阵。

## 十、小结
二维树状数组把两维各用 lowbit 分解，矩形统计降到 $O(\log n\log m)$。
