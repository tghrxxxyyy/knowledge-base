# 树状数组区间求和

> 对应 CyC2018/CS-Notes。

## 一、背景与挑战
区间 $[l,r]$ 的和可由两个前缀和相减得到。树状数组把区间求和降到 $O(\log n)$。

## 二、核心原理
`range(l, r) = prefix(r) - prefix(l-1)`。基于单点加维护的前缀和结构，任意区间查询即两次前缀查询。

## 三、形式化与数学基础
每次区间查询两次前缀跳转：
$T=O(\log n)$；单点加亦 $O(\log n)$。

## 四、代码实现
```python
def range_sum(bit, l, r):
    return bit.prefix(r) - bit.prefix(l - 1)
```

## 五、与其他技术对比
相比线段树区间查询，树状数组两次前缀和更短更快；但区间加需改造为双 BIT。

## 六、常见误区
左端点用 `l` 而非 `l-1` 会少算一个元素；下标从 1 起，查询 `l=1` 时 `prefix(0)=0` 正确。

## 八、面试题
用 BIT 实现区间和；如何用两个 BIT 支持区间加区间和？

## 九、演进与趋势
Fenwick 与差分数组结合支持区间修改的区间查询。

## 十、小结
树状数组区间求和即两前缀和之差，单次 $O(\log n)$，是前缀统计的优选。
