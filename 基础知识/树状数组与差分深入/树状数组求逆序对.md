# 树状数组求逆序对

> 对应 CyC2018/CS-Notes。

## 一、背景与挑战
逆序对计数经典问题，朴素 $O(n^2)$。用树状数组配合离散化可 $O(n\log n)$。

## 二、核心原理
从右向左扫描，对每个值查询「已出现且小于它的值的个数」即其贡献的逆序对，再把该值插入 BIT。左小右大即逆序。

## 三、形式化与数学基础
离散化 $O(n\log n)$，扫描 $n$ 次各 $O(\log n)$：
$T=O(n\log n)$，空间 $O(n)$。

## 四、代码实现
```python
def count_inversions(arr):
    sorted_a = sorted(set(arr))
    rank = {v: i + 1 for i, v in enumerate(sorted_a)}
    bit = Fenwick(len(sorted_a))
    inv = 0
    for x in reversed(arr):
        r = rank[x]
        inv += bit.prefix(r - 1)
        bit.add(r, 1)
    return inv
```

## 五、与其他技术对比
相比归并排序 $O(n\log n)$，BIT 写法更直观；归并排序不需离散化但 BIT 易扩展为带权统计。

## 六、常见误区
未离散化大值域会爆数组；`prefix(r-1)` 用 `r-1` 才是不包含自身的更小值数。

## 八、面试题

## 九、演进与趋势
二维逆序对、带权逆序对可用多维 BIT 或 CDQ 分治。

## 十、小结
树状数组从右向左统计小于当前值的已见元素，以 $O(n\log n)$ 求逆序对。
