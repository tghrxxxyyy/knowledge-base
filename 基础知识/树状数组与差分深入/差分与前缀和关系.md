# 差分与前缀和关系

> 对应 Sedgewick《Algorithms》。

## 一、背景与挑战
区间统一加值、再多次查询最终数组，朴素每次 $O(n)$。差分数组把区间加降到 $O(1)$，最后整体前缀和还原。

## 二、核心原理
差分 $d[i]=a[i]-a[i-1]$（约定 $a[-1]=0$）。区间 $[l,r]$ 加 v 只需 `d[l]+=v, d[r+1]-=v`；最终数组即 d 的前缀和。

## 三、形式化与数学基础
区间加 $O(1)$，整体还原 $O(n)$；若配合树状数组维护差分，则单点查询也可 $O(\log n)$：
$T_{\rm add}=O(1)$。

## 四、代码实现
```python
def range_add_diff(d, l, r, v):
    d[l] += v
    if r + 1 < len(d):
        d[r + 1] -= v
def reconstruct(a, d):
    cur = 0
    for i in range(len(a)):
        cur += d[i]
        a[i] = cur
```

## 五、与其他技术对比
相比直接遍历区间，差分把批量加与查询解耦；相比线段树，差分无递归、常数极小但只适合离线/统一还原。

## 六、常见误区
忘记 `d[r+1]-=v` 会让 r 之后的元素也跟着加；边界 `r+1` 越界需判断。

## 七、与开源书/权威来源对应
Sedgewick《Algorithms》差分数组；CyC2018/CS-Notes 差分章节。

## 八、面试题
用差分实现多次区间加后求最终数组；如何在线查询某点？

## 九、演进与趋势
差分与 BIT 结合实现在线区间加、单点/前缀查询。

## 十、小结
差分数组把区间加降为 $O(1)$，与前缀和互为逆运算，是批量修改的利器。
