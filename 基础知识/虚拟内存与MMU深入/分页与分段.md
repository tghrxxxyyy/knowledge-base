# 分页与分段

> 对应 CSAPP 中文笔记 https://github.com/Hansimov/csapp 第9章；OSTEP https://github.com/remzi-arpacidusse/ostep-code ；Silberschatz《Database System Concepts》不涉及，用 Tanenbaum《Modern Operating Systems》。

## 一、背景与挑战

程序需独立、连续、受保护的地址空间，而物理内存碎片化且有限。分段(变长)与分页(定长)是两种抽象。

## 二、核心原理

分段按逻辑段(代码/数据/栈)管理，长度可变，易共享但外部碎片。分页把地址空间切成等大小页(通常4KB)，物理页框任意映射，消除外部碎片，但内部碎片小。现代系统(x86)以分页为主，分段退化。

## 三、形式化 / 数学基础

虚拟地址 = (VPN, offset)。物理地址：

$$PA = PFN(vaddr/VPN) \ll p + (vaddr \bmod 2^p)$$

$p$ 为页内偏移位（4KB → p=12）。

## 四、代码实现

```c
// 观察页大小
#include <unistd.h>
long ps = sysconf(_SC_PAGESIZE);   // 通常 4096
```

## 五、与其他技术对比

- 分段：保护按段、共享自然；碎片与变长管理难。
- 分页：统一、无外部碎片；但共享粒度粗。

## 六、常见误区

- 误以为分页无碎片：有内部碎片(页内浪费)。
- 误以为分段已消失：x86 仍有段寄存器但基址0。

## 八、面试题

- 分页 vs 分段？答：定长无外碎 vs 变长自然共享但有碎片。
- 页内偏移几位？答：4KB 页为12位。

## 九、演进与趋势

多级页表、大页、反向映射与内存去重成主流。

## 十、小结

分页以定长映射统一地址转换，是现代虚存基石。
