# 缺页与访问控制

> 对应 CSAPP 中文笔记 https://github.com/Hansimov/csapp 第9章；OSTEP https://github.com/remzi-arpacidusse/ostep-code ；Tanenbaum《Modern Operating Systems》。

## 一、背景与挑战

访问未映射/无权限页需陷入内核处理；利用这点实现按需调页、写时复制、保护。

## 二、核心原理

PTE 存在位 P=0 或权限不符触发缺页异常。分类：minor(页在内存但未映射，如 COW)、major(需从磁盘读)、非法(段错误)。写时复制(COW)：fork 时父子共享只读页，任一方写才复制。

## 三、形式化 / 数学基础

缺页处理：

$$trap \rightarrow check(reason) \rightarrow
\begin{cases} COW: & copy\ page,\ remap\ RW \\ major: & load\ from\ disk \\ invalid: & SIGSEGV \end{cases}$$

权限位组合：R/W/U/S/X 决定可否访问/写/用户/执行。

## 四、代码实现

```c
// mmap 私有映射 + 写时复制
void *p = mmap(NULL, sz, PROT_READ|PROT_WRITE,
               MAP_PRIVATE|MAP_ANON, -1, 0);
p[0] = 1;   // 首次写触发 COW 复制
```

## 五、与其他技术对比

- minor 缺页快；major 缺页慢(磁盘 I/O)。
- COW 节省复制，延迟到真正写。

## 六、常见误区

- 误以为缺页必慢：minor 很快。
- 误以为 mmap 写立即落盘：MAP_PRIVATE 是 COW。
