# 点与向量

> 对应 O'Rourke《Computational Geometry in C》与 CLRS 计算几何章节。

## 一、背景与挑战
计算几何的基础是点与向量运算：点积、叉积用于判断方向、夹角、共线与面积。

## 二、核心原理
叉积 `cross = x1*y2 - x2*y1` 的符号判断左右转向与有向面积；点积判断夹角与投影；用 `ccw` 判定三点的转向。

## 三、形式化 / 数学基础
$cross(O,A,B) = (A_x-O_x)(B_y-O_y) - (A_y-O_y)(B_x-O_x)$
>0 逆时针，<0 顺时针，=0 共线。两向量夹角余弦 $\cos\theta = \frac{a\cdot b}{|a||b|}$。

## 四、代码实现
```python
class Pt:
    def __init__(self, x, y):
        self.x, self.y = x, y
    def sub(self, o):
        return Pt(self.x - o.x, self.y - o.y)
    def cross(self, o):
        return self.x * o.y - self.y * o.x
    def dot(self, o):
        return self.x * o.x + self.y * o.y
def ccw(a, b, c):
    return (b.x - a.x) * (c.y - a.y) - (b.y - a.y) * (c.x - a.x)
```

## 五、与其他技术对比
与纯距离计算相比，叉积能区分转向；与角度计算相比，叉积避免三角函数、数值更稳。

## 六、常见误区
整数坐标下用 double 引入误差；共线方向判定未考虑等于零；叉积顺序（a×b vs b×a）符号相反。

## 九、演进与趋势
精确几何（有理数/大整数）避免浮点；鲁棒谓词（orientation）。

## 十、小结
点与向量运算（叉积/点积）是几何算法的语言，ccw 判定几乎贯穿所有几何问题。
