# 点与向量

> 对应 O'Rourke《Computational Geometry in C》第 1 章、CLRS《Introduction to Algorithms》第 33 章，以及 de Berg 等《Computational Geometry: Algorithms and Applications》第 1 章的几何基础约定。

## 一、背景与挑战

计算几何的几乎所有算法——凸包、线段相交、多边形面积、点定位、最近点对——最终都会落到同一批原子操作上：向量加减、点积、叉积，以及由叉积符号导出的**方向判定**（orientation / ccw）。可以说，点与向量是几何算法的“汇编指令”：上层算法负责调度扫描线、分治或增量构造，真正判断“这个点在直线的哪一侧”“这三个点是左转还是右转”的，永远是叉积的符号。

朴素做法的问题在于**用角度和距离做判定**。例如判断三点转向时，有人会先算两条边的夹角再比大小，或用 $\arctan$ 求方位角。这在数学上等价，但工程上很糟：三角函数与 `sqrt` 引入浮点误差，误差随运算链累积；更重要的是，判定只需要**符号**，算出具体角度是浪费。叉积 $a_xb_y - a_yb_x$ 一次乘减就能给出符号，整数坐标下甚至是精确整数运算，完全没有舍入误差。

在工程与面试中，点向量是“送分题也是丢分题”。面试官常以“判断点是否在多边形内”“判断两线段是否相交”“求多边形面积”切入，真正考察的是你是否建立了**有向面积 / 转向 / 投影**这三套心智模型，以及是否会处理退化情况（共线、零向量、顺逆时针约定）。GIS、碰撞检测、CAD、机器人路径规划的底层库，无一不把 orientation 谓词当作最底层原语。

## 二、核心原理

**点积（内积）与叉积（外积）分工明确。** 给定二维向量 $a=(a_x,a_y)$、$b=(b_x,b_y)$：

- **点积** $a\cdot b = a_xb_x + a_yb_y = |a||b|\cos\theta$。它回答“投影有多长、夹角是锐是钝”：点积 $>0$ 夹角为锐角，$=0$ 垂直，$<0$ 钝角。点积**不区分左右**，只看夹角大小。
- **叉积** $a\times b = a_xb_y - a_yb_x = |a||b|\sin\theta$。它回答“$b$ 相对 $a$ 是左转还是右转”，符号即方向：$>0$ 逆时针（左转），$<0$ 顺时针（右转），$=0$ 共线。其绝对值等于 $a,b$ 张成的平行四边形有向面积。

**方向谓词 ccw（counter-clockwise）是核心不变量。** 对三点 $A,B,C$：

$$
\mathrm{ccw}(A,B,C) = (B_x-A_x)(C_y-A_y) - (B_y-A_y)(C_x-A_x)
$$

其符号等价于 $\mathrm{cross}(B-A,\ C-A)$。约定：$>0$ 表示 $C$ 在有向直线 $\overrightarrow{AB}$ 的左侧，即 $A\to B\to C$ 逆时针左转。**几乎所有几何正确性证明都建立在 ccw 的符号不变量上**：凸包栈维护的是“栈顶三点始终左转”，线段跨立实验比较的是两端点相对对方所在直线的 ccw 符号。

**边界条件必须显式处理：**

1. **共线（ccw = 0）**：三点共线时“左/右”无意义。多数算法需要单独分支——凸包可能要保留最远端点，线段相交要转为一维投影区间重叠判断。把 `== 0` 与 `> 0` 混为一谈是几何题最常见的 bug 来源。
2. **零向量**：$B=A$ 时 $B-A=0$，叉积恒为 0，会被误判为“共线”。调用前需检查点是否重合，或在算法层约定输入点互异。
3. **坐标顺序与旋向约定**：屏幕坐标系 $y$ 轴向下时，“叉积为正”对应的视觉转向是顺时针，与数学坐标系相反。几何库通常在文档中写明约定，自己实现时更要固定一种并全程贯彻。

**为什么正确：** 叉积公式是二阶行列式 $\det\begin{pmatrix}B_x-A_x & C_x-A_x\\ B_y-A_y & C_y-A_y\end{pmatrix}$，其符号等于从向量 $B-A$ 旋转到 $C-A$ 的有向角的正弦符号。在实数平面上，$\sin\theta$ 的符号与 $\theta\in(-\pi,\pi)$ 的符号一致，故叉积符号精确刻画了转向，且**只依赖代数运算**，无需三角函数。

**工程要点：** 整数坐标一律用 64 位整数存叉积（坐标差乘积可能到 $|coord|^2$ 量级）；大坐标可用 Python 任意精度整数或 C++ `__int128`。浮点坐标下比较符号时应设容差 $\varepsilon$，但更好的做法是改用精确谓词（见后文演进）。

## 三、形式化与数学基础

**有向面积与多边形面积。** 以原点为公共顶点，向量 $a,b$ 张成平行四边形的有向面积为 $a\times b$；三角形 $\triangle OAB$ 有向面积为 $\frac{1}{2}(a\times b)$。推广到多边形 $P = p_0p_1\cdots p_{n-1}$，鞋带公式（shoelace）给出有向面积：

$$
\mathrm{Area}(P) = \frac{1}{2}\sum_{i=0}^{n-1} (x_i y_{i+1} - x_{i+1} y_i),\quad (x_n,y_n)=(x_0,y_0).
$$

证明思路：将多边形三角化为 $\triangle O p_i p_{i+1}$，每个三角形有向面积 $\frac{1}{2}(p_i\times p_{i+1})$，求和时内部贡献相互抵消，只剩边界环绕量。面积为正当且仅当顶点按逆时针排列——这再次说明叉积符号编码了**全局旋向**。

**点积与投影。** 向量 $a$ 在 $b$ 方向的投影长度为

$$
\mathrm{comp}_b a = \frac{a\cdot b}{|b|},\qquad
\cos\theta = \frac{a\cdot b}{|a|\,|b|}.
$$

判断点 $P$ 是否在线段 $AB$ 的投影范围内（线段相交的前置条件）用点积：

$$
0 \le (P-A)\cdot(B-A) \le |B-A|^2.
$$

注意右边用 $|B-A|^2$ 而非 $|B-A|$，可避免开方。

**点在三角形内。** $P$ 在 $\triangle ABC$ 内（含边界）当且仅当三个子三角形旋向一致：

$$
\mathrm{ccw}(A,B,P)\ge 0,\quad \mathrm{ccw}(B,C,P)\ge 0,\quad \mathrm{ccw}(C,A,P)\ge 0
$$

（假设 $A,B,C$ 逆时针；若顺时针则三个不等号同反）。这是因为 $P$ 必须同时落在三条边的“内侧半平面”内。

**数值稳定性。** 浮点叉积 $(b_x-a_x)(c_y-a_y)-(b_y-a_y)(c_x-a_x)$ 中，两次乘法的舍入误差可能使本应为 0 的结果变成 $\pm 10^{-15}$ 量级，符号翻转导致拓扑判定出错。Shewchuk 指出：若坐标是 32 位整数，叉积可用 64 位精确计算；若坐标是 53 位浮点有效位，需自适应精度才能保证 orientation 正确。工程上“先整数、后有理、最后浮点”是稳健谓词的通用策略。

## 四、代码实现

```python
"""点与向量基础：叉积/点积/转向/面积/点在三角形内。"""
from __future__ import annotations
from dataclasses import dataclass
from typing import List, Tuple


@dataclass(frozen=True)
class Vec:
    x: float
    y: float

    def __add__(self, o: "Vec") -> "Vec":
        return Vec(self.x + o.x, self.y + o.y)

    def __sub__(self, o: "Vec") -> "Vec":
        return Vec(self.x - o.x, self.y - o.y)

    def __mul__(self, k: float) -> "Vec":
        return Vec(self.x * k, self.y * k)

    def dot(self, o: "Vec") -> float:
        return self.x * o.x + self.y * o.y

    def cross(self, o: "Vec") -> float:
        """二维叉积：>0 表示 self 到 o 逆时针（左转）。"""
        return self.x * o.y - self.y * o.x

    def norm2(self) -> float:
        return self.x * self.x + self.y * self.y


def ccw(a: Vec, b: Vec, c: Vec) -> float:
    """三点转向：>0 左转(逆时针)，<0 右转，=0 共线。"""
    return (b.x - a.x) * (c.y - a.y) - (b.y - a.y) * (c.x - a.x)


def orient(a: Vec, b: Vec, c: Vec) -> int:
    """稳健方向分类：1 左转 / -1 右转 / 0 共线。"""
    v = ccw(a, b, c)
    if v > 0:
        return 1
    if v < 0:
        return -1
    return 0


def polygon_area(poly: List[Vec]) -> float:
    """鞋带公式，返回有向面积（逆时针为正）。"""
    n = len(poly)
    s = 0.0
    for i in range(n):
        x1, y1 = poly[i].x, poly[i].y
        x2, y2 = poly[(i + 1) % n].x, poly[(i + 1) % n].y
        s += x1 * y2 - x2 * y1
    return s / 2.0


def point_in_triangle(p: Vec, a: Vec, b: Vec, c: Vec) -> bool:
    """含边界。假设 a,b,c 逆时针；顺时针则三者取反。"""
    d1, d2, d3 = orient(a, b, p), orient(b, c, p), orient(c, a, p)
    has_neg = (d1 < 0) or (d2 < 0) or (d3 < 0)
    has_pos = (d1 > 0) or (d2 > 0) or (d3 > 0)
    return not (has_neg and has_pos)


def project_on_segment(p: Vec, a: Vec, b: Vec) -> bool:
    """P 是否落在线段 AB 的投影闭区间内（用点积，不开方）。"""
    ab = b - a
    ap = p - a
    t = ap.dot(ab)
    return 0 <= t <= ab.norm2()


if __name__ == "__main__":
    # 经典用例
    assert orient(Vec(0, 0), Vec(1, 0), Vec(1, 1)) == 1   # 左转
    assert orient(Vec(0, 0), Vec(1, 0), Vec(1, -1)) == -1  # 右转
    assert orient(Vec(0, 0), Vec(1, 1), Vec(2, 2)) == 0    # 共线

    # 单位正方形，逆时针，面积 1
    square = [Vec(0, 0), Vec(1, 0), Vec(1, 1), Vec(0, 1)]
    assert abs(polygon_area(square) - 1.0) < 1e-9
    assert polygon_area(list(reversed(square))) < 0  # 顺时针为负

    # 点在三角形内
    a, b, c = Vec(0, 0), Vec(4, 0), Vec(0, 4)
    assert point_in_triangle(Vec(1, 1), a, b, c)
    assert point_in_triangle(Vec(0, 0), a, b, c)      # 顶点在边界上
    assert not point_in_triangle(Vec(3, 3), a, b, c)

    # 投影判定
    assert project_on_segment(Vec(1, 5), Vec(0, 0), Vec(2, 0))
    assert not project_on_segment(Vec(3, 5), Vec(0, 0), Vec(2, 0))

    # 点积判垂直
    assert Vec(1, 0).dot(Vec(0, 1)) == 0
    print("点与向量：全部用例通过")
```

## 五、与其他技术对比

| 方案 | 判定依据 | 优点 | 缺点 | 适用 |
|------|----------|------|------|------|
| 叉积 / ccw | 有向面积符号 | 无三角函数，整数精确，$O(1)$ | 只给符号不给角度 | 几何判定首选 |
| 角度（atan2） | 方位角差 | 直观，可得具体角 | 慢、有舍入、需处理 $\pm\pi$ | 可视化、航向计算 |
| 距离比较 | 边长平方 | 简单 | 无法区分左右转向 | 只问远近时 |
| 单位向量点积 | $\cos\theta$ | 投影清晰 | 开方/归一化有误差 | 物理、光照 |

取舍结论：**凡是只需要“左/右/共线/锐/钝”这类符号判定，一律用叉积与点积的符号**；只有确实需要角度值时才动三角函数。多边形面积用鞋带公式而非三角剖分，既少分支又少误差。

## 六、常见误区

1. **用浮点坐标直接判 `== 0` 共线。** 后果：本该共线的点被判为微左转，凸包多出“毛刺”顶点，线段相交漏判。正确做法：整数坐标用整数叉积；浮点用容差或精确谓词。
2. **混淆叉积参数顺序。** $a\times b = -b\times a$，写反则所有转向判断整体翻转，凸包方向、点在多边形内都会错。约定统一写成 `cross(b-a, c-a)` 或 `ccw(a,b,c)`，不要混用。
3. **忘记共线分支。** 凸包栈弹出条件写成 `cross <= 0` 或 `cross < 0` 一字之差，结果可能少点或多点；线段相交时共线重叠若不单独处理，会漏掉“T 形贴靠”“部分重叠”。
4. **坐标系旋向约定混乱。** 屏幕坐标 $y$ 向下，视觉左转对应叉积为负；与数学教材的逆时针为正相反。混用两套约定会在 UI 碰撞检测中出现“明明穿过了却不报碰撞”。
5. **零向量与重复点。** $A=B$ 时叉积恒 0，被当成共线；最近点对、凸包输入含重复点时必须先去重或在比较中跳过。

## 八、面试题

**1. 不用三角函数，如何判断点 $C$ 在有向直线 $AB$ 的左侧还是右侧？**
参考答案：算叉积 $\mathrm{ccw}(A,B,C)=(B_x-A_x)(C_y-A_y)-(B_y-A_y)(C_x-A_x)$。$>0$ 在左侧（$A\to B\to C$ 左转），$<0$ 在右侧，$=0$ 共线。整数坐标用 64 位整数计算可完全精确。

**2. 如何判断多边形是顺时针还是逆时针？面积呢？**
参考答案：鞋带公式 $\frac{1}{2}\sum (x_iy_{i+1}-x_{i+1}y_i)$，结果为有向面积：正=逆时针，负=顺时针，绝对值即面积。也可任取相邻三点看 ccw 符号，但鞋带更稳。

**3. 判断点是否在多边形内，有哪些方法？**
参考答案：(a) 射线法：从点向右发射水平射线，统计与边的交点个数，奇数在内；需处理顶点落在射线上的退化。(b) 角度和法：绕点转一圈，角度和为 $\pm 2\pi$ 在内，$0$ 在外。(c) 三角剖分后逐三角形用 ccw 判定。工程上射线法最常用，配合 `ccw` 判交点。

**4. 为什么几何判定不用 `atan2` 比较角度？**
参考答案：三角函数慢且引入舍入；判定只需符号，叉积一次乘减完成；整数坐标下叉积精确而角度必有误差。只有需要真实角度值时才用 `atan2`。

## 九、演进与趋势

**精确谓词与自适应精度。** Shewchuk 的 `orient2d` 会先用浮点快速算，若结果接近 0（不确定）则自动升级到精确运算，兼顾速度与正确性，已成为 CGAL、GEOS 等库的标配。**有理数几何（CGAL::Gmpq）** 用任意精度有理数表示交点坐标，彻底消灭浮点误差，代价是性能下降。

**高维推广。** 三维叉积变为向量积（用于法向、体积），四维以上用行列式与外代数；机器人学中的 SE(2)/SE(3) 位姿也以点积叉积为底层。**SIMD/GPU 加速**：碰撞检测中数以万计的 orientation 谓词可向量化，成为物理引擎热点。

**工程应用。** GIS（PostGIS 的 `ST_Orientation`）、游戏引擎（分离轴定理 SAT 依赖叉积符号）、CAD 布尔运算、自动驾驶点云处理，都以稳健点向量谓词为地基。近年 **Rust 的 `robust` crate**、**JTS/GEOS** 等库把 Shewchuk 谓词带入工业界。

## 十、小结

点与向量的核心是**叉积符号编码转向、点积符号编码夹角、鞋带公式编码环绕面积**。建立“只看符号、整数优先、显式处理共线”这三条纪律，就掌握了几乎全部几何算法的底层原语；后续凸包、线段相交、扫描线无非是把这些原语组织成正确的不变量。
