# 线段相交

> 对应 CLRS《Introduction to Algorithms》第 33 章线段相交、O'Rourke《Computational Geometry in C》，以及 Bentley & Ottmann (1979) 平面扫描求交点论文。

## 一、背景与挑战

判断两条线段是否相交是几何中最基础也最易错的操作之一：碰撞检测要问“两个线框是否碰到”，地图叠置要问“道路与行政区边界是否交叉”，多边形点定位要靠射线与边的交点计数。更进一步，“求出所有 $k$ 个交点”是扫描线、排列（arrangement）、可见性等问题的共同子程序。

朴素做法有两类错误倾向。一类是**只用斜率与截距**：写出 $y=kx+b$ 再联立求解。它在竖直线（斜率无穷）上直接崩溃，处理平行、近平行时数值极不稳定。另一类是**用方向向量参数方程求 $t,u$** 再看是否落在 $[0,1]$：数学上可行，但浮点除法在近平行时会放大误差，且共线重叠（无穷多交点）需要完全独立的分支。真正稳健且简洁的方案是**转向法（orientation-based）**：全部判定退化为叉积符号比较，只在共线时才转到一维区间重叠。

在面试与工程中，线段相交是“几何第一题”。面试官期望你写出跨立实验，说清共线情况，最好还能扩展到“线段是否规范相交（交点严格在内部）”“求交点坐标”“多线段求交”三个层次。工程上它是 SAT 碰撞检测、GIS 叠置、射线追踪求交、CAD 布尔运算的基础谓词，必须处理好端点相接、T 形贴靠、部分重叠这些退化情形。

## 二、核心原理

设线段 $s_1 = \overline{P_1P_2}$，$s_2 = \overline{P_3P_4}$。

**核心不变量：跨立实验（straddle test）。** $s_1$ 与 $s_2$ 相交，当且仅当下面两条同时成立（一般位置，不含共线）：

1. $P_3, P_4$ 分居直线 $P_1P_2$ 两侧，即 $\mathrm{ccw}(P_1,P_2,P_3)$ 与 $\mathrm{ccw}(P_1,P_2,P_4)$ **异号**；
2. $P_1, P_2$ 分居直线 $P_3P_4$ 两侧，即 $\mathrm{ccw}(P_3,P_4,P_1)$ 与 $\mathrm{ccw}(P_3,P_4,P_2)$ **异号**。

为什么正确：若两条直线不平行，必交于一点 $X$。条件 1 说明 $X$ 落在 $P_3P_4$ 的投影内（因为 $P_3,P_4$ 被 $P_1P_2$ 所在直线分开），条件 2 说明 $X$ 落在 $P_1P_2$ 的投影内。两者同时成立即 $X$ 同时在两条线段上。**只检查一条直线是不够的**——反例：两条共面线段所在直线相交，但交点在某条线段的延长线上。

**端点相接（规范/非规范相交）。** 若允许“端点触碰也算相交”，则把“异号”放宽为“异号或零”：$\mathrm{ccw}\cdot\mathrm{ccw} \le 0$，并对四个端点做同样检查。若要求**规范相交**（交点严格在两边内部，不含端点），则必须四个 ccw 全部**严格非零且各自异号**。面试时一定要问清题意。

**共线重叠。** 当四个点共线（所有相关 ccw 为 0）时，二维跨立实验退化，必须转为**一维投影**：把点投影到 $x$（或 $y$，取跨度大的轴）上，判断区间 $[\min(x_1,x_2),\max(x_1,x_2)]$ 与 $[\min(x_3,x_4),\max(x_3,x_4)]$ 是否有交集。区间相交则线段重叠（可能是一个点或一段）。

**求交点坐标。** 一般位置下解参数方程：

$$
P_1 + t(P_2-P_1) = P_3 + u(P_4-P_3),\quad t,u\in[0,1].
$$

用叉积可得免除法形式的 $t$：

$$
t = \frac{(P_3-P_1)\times(P_4-P_3)}{(P_2-P_1)\times(P_4-P_3)},
$$

分母为 0 表示平行。共线时交点不唯一，应返回重叠区间而非一个点。

**批量求交与扫描线。** 两两判定是 $O(n^2)$；Bentley–Ottmann 用事件点调度 + 平衡树维护扫描线上的邻接关系，只比较相邻线段，一般位置下 $O((n+k)\log n)$（$k$ 为交点数）。其正确性依赖“只有扫描线上的**当前邻居**才可能相交”这一状态不变量。

## 三、形式化与数学基础

**跨立实验的形式化。** 定义方向函数

$$
D(a,b,c) = (b_x-a_x)(c_y-a_y) - (b_y-a_y)(c_x-a_x).
$$

记 $d_1 = D(P_1,P_2,P_3)$，$d_2 = D(P_1,P_2,P_4)$，$d_3 = D(P_3,P_4,P_1)$，$d_4 = D(P_3,P_4,P_2)$。

一般位置下，相交 $\iff (d_1 d_2 < 0) \wedge (d_3 d_4 < 0)$。含端点相交 $\iff (d_1 d_2 \le 0) \wedge (d_3 d_4 \le 0)$ 且不全为零的退化情形已被共线分支接管。

**退化分类的完备性。** 四点 ccw 值的零模式划分出互斥情形：

| 模式 | 含义 | 处理 |
|------|------|------|
| $d_1,d_2,d_3,d_4$ 均非零 | 一般位置 | 跨立实验 |
| $d_1=d_2=0$ | $P_3,P_4$ 都在 $P_1P_2$ 上 | 四点共线，一维区间重叠 |
| 恰有一个 $d_i=0$ | 一端点落在对方直线上 | 端点共线，再判投影或直接“触碰” |
| $d_1d_2=0$ 其余非零 | T 形 | 按题意算相交或不相交 |

实现时用符号函数 $\mathrm{sign}(d)$ 把数值归一到 $\{-1,0,1\}$，比较符号对，避免 `<=` 与 `<` 混用。

**区间重叠。** 共线时取投影轴 $\mathrm{axis} = 0$（x）若 $|x_2-x_1| + |x_4-x_3| \ge |y_2-y_1| + |y_4-y_3|$，否则 y。两区间 $[a_1,b_1], [a_2,b_2]$ 重叠当且仅当 $\max(a_1,a_2) \le \min(b_1,b_2)$。

**交点参数 $t$ 的推导。** 由 $P_1 + t\vec{d_1} = P_3 + u\vec{d_2}$，两边叉乘 $\vec{d_2}$：

$$
(P_3-P_1)\times\vec{d_2} = t\,(\vec{d_1}\times\vec{d_2}) \;\Rightarrow\;
t = \frac{(P_3-P_1)\times\vec{d_2}}{\vec{d_1}\times\vec{d_2}}.
$$

分母 $\vec{d_1}\times\vec{d_2}=0$ 当且仅当方向向量平行。相交检查通过后 $t\in[0,1]$，代入即得交点。

**复杂度。** 单次判定 $O(1)$（常数次乘加）。Bentley–Ottmann：事件数 $O(n+k)$，每次堆操作 $O(\log n)$、每次状态树更新 $O(\log n)$，总 $O((n+k)\log n)$；空间 $O(n)$。

## 四、代码实现

```python
"""线段相交：跨立实验 + 共线重叠 + 交点坐标。"""
from __future__ import annotations
from dataclasses import dataclass
from typing import List, Optional, Tuple


@dataclass(frozen=True)
class Pt:
    x: float
    y: float


def cross(a: Pt, b: Pt, c: Pt) -> float:
    """ccw(a,b,c) 有向面积*2：>0 左转，<0 右转，=0 共线。"""
    return (b.x - a.x) * (c.y - a.y) - (b.y - a.y) * (c.x - a.x)


def sign(x: float, eps: float = 0.0) -> int:
    if x > eps:
        return 1
    if x < -eps:
        return -1
    return 0


def on_segment(p: Pt, a: Pt, b: Pt) -> bool:
    """p 与 a,b 共线时，判断 p 是否在线段 ab 的包围盒内。"""
    return (min(a.x, b.x) - 1e-12 <= p.x <= max(a.x, b.x) + 1e-12 and
            min(a.y, b.y) - 1e-12 <= p.y <= max(a.y, b.y) + 1e-12)


def seg_intersect(p1: Pt, p2: Pt, p3: Pt, p4: Pt, proper: bool = False) -> bool:
    """判断线段 p1p2 与 p3p4 是否相交。
    proper=True 时要求规范相交（交点严格在两边内部）。
    """
    d1 = sign(cross(p1, p2, p3))
    d2 = sign(cross(p1, p2, p4))
    d3 = sign(cross(p3, p4, p1))
    d4 = sign(cross(p3, p4, p2))

    # 一般位置：互相跨立
    if d1 * d2 < 0 and d3 * d4 < 0:
        return True

    if proper:
        # 规范相交：必须严格跨立，端点相接不算
        return False

    # 退化：端点/共线触碰
    if d1 == 0 and on_segment(p3, p1, p2):
        return True
    if d2 == 0 and on_segment(p4, p1, p2):
        return True
    if d3 == 0 and on_segment(p1, p3, p4):
        return True
    if d4 == 0 and on_segment(p2, p3, p4):
        return True

    # 四点共线：转为一维区间重叠
    if d1 == 0 and d2 == 0 and d3 == 0 and d4 == 0:
        # 取跨度较大的轴做投影
        if abs(p1.x - p2.x) >= abs(p1.y - p2.y):
            lo1, hi1 = sorted((p1.x, p2.x))
            lo2, hi2 = sorted((p3.x, p4.x))
        else:
            lo1, hi1 = sorted((p1.y, p2.y))
            lo2, hi2 = sorted((p3.y, p4.y))
        return max(lo1, lo2) <= min(hi1, hi2) + 1e-12
    return False


def seg_intersection_point(p1: Pt, p2: Pt, p3: Pt, p4: Pt) -> Optional[Pt]:
    """返回唯一交点；平行/重叠返回 None。"""
    x1, y1 = p1.x, p1.y
    x2, y2 = p2.x, p2.y
    x3, y3 = p3.x, p3.y
    x4, y4 = p4.x, p4.y
    den = (x1 - x2) * (y3 - y4) - (y1 - y2) * (x3 - x4)
    if abs(den) < 1e-15:
        return None  # 平行或共线
    t = ((x1 - x3) * (y3 - y4) - (y1 - y3) * (x3 - x4)) / den
    # u = ((x1 - x2) * (y1 - y3) - (y1 - y2) * (x1 - x3)) / den
    return Pt(x1 + t * (x2 - x1), y1 + t * (y2 - y1))


def count_intersections(segments: List[Tuple[Pt, Pt]]) -> int:
    """两两判定求交点个数（教学用 O(n^2)；大规模用 Bentley-Ottmann）。"""
    n = len(segments)
    cnt = 0
    for i in range(n):
        for j in range(i + 1, n):
            if seg_intersect(segments[i][0], segments[i][1],
                             segments[j][0], segments[j][1]):
                cnt += 1
    return cnt


if __name__ == "__main__":
    # 一般位置相交：十字交叉
    assert seg_intersect(Pt(0, 0), Pt(2, 2), Pt(0, 2), Pt(2, 0))
    # 端点相接
    assert seg_intersect(Pt(0, 0), Pt(1, 1), Pt(1, 1), Pt(2, 0))
    assert not seg_intersect(Pt(0, 0), Pt(1, 1), Pt(1, 1), Pt(2, 0), proper=True)
    # 不相交
    assert not seg_intersect(Pt(0, 0), Pt(1, 1), Pt(0, 2), Pt(1, 2))
    # 所在直线相交，但交点不在线段上
    assert not seg_intersect(Pt(0, 0), Pt(1, 0), Pt(2, -1), Pt(2, 1))
    # 共线重叠
    assert seg_intersect(Pt(0, 0), Pt(2, 0), Pt(1, 0), Pt(3, 0))
    # 共线不重叠
    assert not seg_intersect(Pt(0, 0), Pt(1, 0), Pt(2, 0), Pt(3, 0))
    # T 形：端点在另一线段上
    assert seg_intersect(Pt(0, 0), Pt(2, 0), Pt(1, 0), Pt(1, 2))
    # 交点坐标
    ip = seg_intersection_point(Pt(0, 0), Pt(2, 2), Pt(0, 2), Pt(2, 0))
    assert ip is not None and abs(ip.x - 1) < 1e-9 and abs(ip.y - 1) < 1e-9
    # 平行无交点
    assert seg_intersection_point(Pt(0, 0), Pt(1, 0), Pt(0, 1), Pt(1, 1)) is None

    segs = [
        (Pt(0, 0), Pt(2, 2)),
        (Pt(0, 2), Pt(2, 0)),
        (Pt(0, 1), Pt(2, 1)),
    ]
    assert count_intersections(segs) == 3  # 三条线两两交于中点附近
    print("线段相交：全部用例通过")
```

## 五、与其他技术对比

| 方法 | 思想 | 复杂度 | 优点 | 缺点 |
|------|------|--------|------|------|
| 斜率截距联立 | $y=kx+b$ 求解 | $O(1)$ | 直观 | 竖直线崩溃，数值不稳 |
| 参数方程 $t,u$ | 解 $2\times2$ 线性方程 | $O(1)$ | 可得交点 | 近平行误差大，共线需特判 |
| **转向法 + 跨立** | 叉积符号 | $O(1)$ | 无分支灾难，整数精确 | 共线仍需一维投影 |
| 包围盒预筛 + 转向 | AABB 排除后再判 | 摊还 $O(1)$ | 批量更快 | 预筛本身不充分 |
| Bentley–Ottmann | 扫描线 + 事件堆 | $O((n+k)\log n)$ | 批量最优量级 | 实现复杂，退化多 |

取舍：**两线段判定永远用转向法**；批量求交在 $n$ 很大且交点不多时用扫描线；求交点坐标用叉积形式的 $t$，平行时显式返回。

## 六、常见误区

1. **只检查单侧跨立。** 只验证 $P_3,P_4$ 分居 $P_1P_2$ 两侧，不验证反向，会把“交点在延长线上”的情形误判为相交。后果是碰撞检测误报。
2. **忽略共线重叠。** 四点共线时 ccw 全为 0，若不转一维区间判断，会漏掉重叠段，地图叠置出现空洞。
3. **端点语义不清。** 面试中未确认“端点相接是否算相交”，按规范相交写的 `strict` 代码被当成含端点判定。后果：差一个边界条件，测试全挂。
4. **浮点直接判 `== 0`。** 旋转后的线段本应相接却因误差判定为不相交。整数坐标用整数叉积；浮点用容差，或统一走精确谓词。
5. **用斜率比较平行。** $k_1=k_2$ 在竖直线和近平行时都不可靠。平行应比较叉积 $\vec{d_1}\times\vec{d_2} = 0$。

## 八、面试题

**1. 判断两线段是否相交，如何处理共线？**
参考答案：先算四个 ccw。若都不为零，用互相跨立（异号）判定。若出现零，检查对应端点是否落在线段包围盒上（T 形/端点触碰）。若四点全共线，投影到 x 或 y 轴做区间重叠判断。

**2. 如何求两线段交点？**
参考答案：解参数方程 $P_1+t\vec{d_1}=P_3+u\vec{d_2}$，得 $t=\frac{(P_3-P_1)\times\vec{d_2}}{\vec{d_1}\times\vec{d_2}}$。分母为 0 平行；相交检查通过后 $t\in[0,1]$，代入求点。共线时返回重叠区间而非单点。

**3. 从 $n$ 条线段中找所有交点，复杂度是多少？**
参考答案：两两判定 $O(n^2)$。Bentley–Ottmann 平面扫描 $O((n+k)\log n)$，$k$ 为交点数；维护扫描线上邻接序，事件为端点与交点。

**4. 如何判断点是否在多边形内（用线段相交）？**
参考答案：射线法。从点向右作水平射线，统计与多边形各边的交点个数，奇数在内。需处理射线过顶点、与边共线等退化，通常约定“只计上端点”或做微小扰动。

## 九、演进与趋势

**鲁棒求交与精确几何。** CGAL 的 `do_intersect` / `intersection` 采用自适应精确谓词，返回 `Object` 可能是点或线段，正确处理重叠。**GPU/SIMD 碰撞检测**（物理引擎 Bullet、Box2D）先用 AABB/SAT 粗筛，再用精确线段/凸包判定。

**排列与叠置。** GIS 中 GEOS/JTS 用线段求交 + 平面扫描构建排列，支撑多边形布尔运算（union/intersection）。**运动规划**中机器人轨迹与障碍边的相交查询批量调用此谓词。

**近似与哈希网格。** 游戏里常用均匀网格或 BVH 将候选线段对压到常数，再调用精确判定，把期望复杂度降到近似 $O(n)$。Bentley–Ottmann 仍是理论基准，工程更常用空间索引 + 局部精确判定。

## 十、小结

线段相交的正确姿势是**跨立实验看符号、共线退化看投影、端点语义先约定**。它把二维几何判定压缩成几次叉积，既是后续扫描线、点定位、碰撞检测的基石，也是检验几何代码是否考虑完备性的试金石。
