# 线段相交

> 对应 《计算几何》线段相交判定与 CLRS 计算几何章节。

## 一、背景与挑战
判断两线段是否相交（含端点与共线重叠）。基础判定用于多边形、地图、碰撞检测。

## 二、核心原理
用方向（ccw / 叉积符号）判断点在线段两侧；两线段相交当且仅当彼此跨立（端点分处对方两侧）。共线时再判投影区间重叠。

## 三、形式化 / 数学基础
跨立实验：
$(cross(p3,p4,p1) \cdot cross(p3,p4,p2) < 0)$ 且 $(cross(p1,p2,p3) \cdot cross(p1,p2,p4) < 0)$
共线情形需比较坐标区间。

## 四、代码实现
```python
def on_segment(p, q, r):
    return (min(p[0], r[0]) <= q[0] <= max(p[0], r[0]) and
            min(p[1], r[1]) <= q[1] <= max(p[1], r[1]))
def orientation(p, q, r):
    v = (q[0]-p[0])*(r[1]-p[1]) - (q[1]-p[1])*(r[0]-p[0])
    return 0 if v == 0 else (1 if v > 0 else 2)
def segments_intersect(p1, q1, p2, q2):
    o1, o2, o3, o4 = orientation(p1,q1,p2), orientation(p1,q1,q2), orientation(p2,q2,p1), orientation(p2,q2,q1)
    if o1 != o2 and o3 != o4:
        return True
    if o1 == 0 and on_segment(p1, p2, q1): return True
    if o2 == 0 and on_segment(p1, q2, q1): return True
    if o3 == 0 and on_segment(p2, p1, q2): return True
    if o4 == 0 and on_segment(p2, q1, q2): return True
    return False
```

## 五、与其他技术对比
与仅比包围盒相比，叉积判定精确；与浮点求交相比，定向法避免除法、更稳。

## 六、常见误区
忽略共线重叠情况；方向比较符号搞反；端点恰好在另一线段上未处理。

## 九、演进与趋势

## 十、小结
线段相交靠跨立实验 + 共线特判，用叉积方向避免浮点除法，是几何判定的基本功。
