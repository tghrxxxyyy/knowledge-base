# 凸包算法

> 对应 Graham 1972 与 Andrew 1979（单调链）及 CLRS Ch.33。

## 一、背景与挑战
求包围平面上所有点的最小凸多边形。经典算法：Graham 扫描、Andrew 单调链、QuickHull。

## 二、核心原理
Andrew 单调链：按 x（再 y）排序，先建下凸壳再建上凸壳，用 ccw 保证左转（逆时针）剔除凹点。

## 三、形式化 / 数学基础
排序后 O(n)，核心是维护栈：新点使栈顶两点与新点形成非左转（clockwise）则弹出。总 $O(n\log n)$（排序主导）。

## 四、代码实现
```python
def convex_hull(points):
    pts = sorted(set(points))
    if len(pts) <= 1:
        return pts
    def cross(o, a, b):
        return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])
    lower = []
    for p in pts:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) <= 0:
            lower.pop()
        lower.append(p)
    upper = []
    for p in reversed(pts):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) <= 0:
            upper.pop()
        upper.append(p)
    return lower[:-1] + upper[:-1]
```

## 五、与其他技术对比
与 Graham 扫描相比，Andrew 单调链无需极角排序、实现更稳；QuickHull 平均快但最坏 O(n^2)。

## 六、常见误区
共线点处理（<=0 弹出共线点得紧壳）；排序去重遗漏；上下壳连接重复端点。

## 八、面试题
「凸包面积」；「射击气球（最少发射次数）」常转凸包/贪心。

## 九、演进与趋势
动态凸包（在线加点）；旋转卡壳求直径/最远点对。

## 十、小结
凸包用排序 + 单调栈（链）在 O(n log n) 得到，ccw 符号控制凸性，是最常用的几何基础算法。
