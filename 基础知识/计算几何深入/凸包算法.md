# 凸包算法

> 对应 Graham (1972) 扫描、Andrew (1979) 单调链、Jarvis (1973) 礼包步进，以及 CLRS《Introduction to Algorithms》第 33 章、de Berg 等《Computational Geometry》第 1 章。

## 一、背景与挑战

给定平面上 $n$ 个点，凸包（convex hull）是包含所有点的最小凸多边形，等价于“用橡皮筋套住所有点后绷紧的形状”。它是计算几何的 Hello World，也是大量上层算法的子程序：最远点对必在凸包顶点上、碰撞检测可用凸包替代复杂外形、图像识别取形状轮廓、统计学里做稳健回归与包络分析。

朴素做法是**暴力枚举所有点对作为边**，检查其余点是否全在该边同侧：$O(n^3)$；若先枚举边再扫点是 $O(n^2)$，对 $n=10^5$ 完全不可用。更好的朴素是极角排序后 Graham 扫描，或 $x$ 排序后单调链，把复杂度压到 $O(n\log n)$——这也是理论下界（可证基于比较的凸包与排序同阶）。

工程与面试中，凸包是“必考且容易写残”的题：栈弹出条件写反、共线点处理不一致、排序比较器不满足严格弱序导致 `std::sort` 崩溃，都是经典事故。真正掌握凸包，意味着你理解**极序 / 单调序 + 栈维护局部凸性**这一统一范式，后续旋转卡壳、半平面交、Delaunay 三角化都建立在它之上。

## 二、核心原理

### 1. Graham 扫描：极角排序 + 栈维护

选一个基准点（通常是 $y$ 最小、再 $x$ 最小的点，保证在凸包边界上），把其余点按**相对基准的极角**排序。排序后所有点“绕基准逆时针展开”。维护一个栈，依次插入点：若栈顶两元素与新点形成**非左转**（$\mathrm{ccw} \le 0$，即右转或共线），则弹出栈顶，直到左转为止再压入。

**不变量**：栈中点序列始终构成一条“严格左转”的凸链。每弹出一次都删掉一个凹角顶点；因为极角递增，被弹出的点不会再成为凸包顶点。

**边界条件**：

- **共线点**：若允许凸包边上保留所有共线点，弹出条件写 $\mathrm{ccw} < 0$（只删右转）；若只要极点（严格凸包顶点），写 $\mathrm{ccw} \le 0$。必须与排序的稳定性约定一致。
- **同极角点**：排序时按极角相同则**距基准由近到远**，可保证中途弹出的是近点；或由远到近，再在扫描时跳过近点。
- **点数 $<3$**：直接返回全部点。

### 2. Andrew 单调链（monotone chain）：x 排序 + 上下壳

把所有点按 $(x, y)$ 字典序排序。先从左到右扫描建**下凸壳**（维护右转/左转约定与 Graham 一致），再从右到左建**上凸壳**，拼接即得逆时针凸包。

**优点**：不用求极角（避免 `atan2` 与浮点），比较器只有字典序，对共线、重复点更友好；实现几乎不会写错。**不变量**：下壳栈中相邻三点始终“右拐向上”（相对扫描方向），上壳对称。

### 3. Jarvis 礼包步进（gift wrapping）

从最左点开始，每次用“当前边上极角最大”的点作为下一顶点，$O(nh)$，$h$ 为凸包顶点数。输出敏感（output-sensitive）：当 $h$ 很小时（如 $n=10^6$ 但只有 10 个顶点），可能快于 $O(n\log n)$ 的排序法。

### 4. 为什么正确（单调链）

排序后 $x$ 单调不减。下壳构造过程保证：对栈中任意连续三点 $p_{i-1}, p_i, p_{i+1}$，有 $\mathrm{ccw}(p_{i-1}, p_i, p_{i+1}) > 0$（逆时针左转），即链是凸的；且所有已扫描点都在该链的“上方”（否则早被弹出）。由 $x$ 单调性与凸性，该链恰是凸包下边界。上壳对称，两者拼接覆盖全部边界。

## 三、形式化与数学基础

**复杂度。** Graham / Andrew 均为：排序 $O(n\log n)$ + 扫描每个点至多入栈出栈各一次 $O(n)$，总

$$
T(n) = O(n\log n).
$$

Jarvis 为 $O(nh)$，其中 $h$ 为输出顶点数，$2 \le h \le n$；最坏 $O(n^2)$（点全在凸包上），最好 $O(n)$（$h=O(1)$）。

**下界。** 基于比较模型，凸包至少 $\Omega(n\log n)$：可由凸包顶点顺序还原排序问题（把待排序数映射为凸包上的点，凸包给出循环序）。故 Andrew/Graham 达到了最优阶。

**栈弹出条件的几何意义。** 设栈顶两元素为 $a, b$，新点 $c$。若 $\mathrm{ccw}(a,b,c) \le 0$，则 $c$ 在 $ab$ 的右侧或共线，$b$ 是凹点（或边上冗余点），必须删去。反复弹出直到 $\mathrm{ccw} > 0$，保证局部凸。局部凸 + 有序扫描 ⇒ 全局凸，这是数学归纳的关键一步：假设前 $k$ 点已构成凸链，处理 $p_{k+1}$ 时只可能破坏栈顶的局部凸性，修复后整体仍凸。

**极角排序的等价实现。** 避免 `atan2`，用叉积比较：对基准 $o$，$p \prec q$ 当且仅当 $\mathrm{ccw}(o,p,q) > 0$（$q$ 在 $op$ 左侧，故 $p$ 极角更小）；共线时按距离 $|p-o|^2 < |q-o|^2$。注意这要求比较器满足严格弱序——若共线分支写不全，C++ `sort` 可能触发未定义行为。

**旋转卡壳扩展。** 凸包求出后，最远点对、最小宽度、最小外接矩形均可用双指针在 $O(h)$ 内完成，因为对踵点（antipodal）沿凸包单调移动。

## 四、代码实现

```python
"""凸包：Andrew 单调链 + Graham 扫描。"""
from __future__ import annotations
from dataclasses import dataclass
from typing import List
import math


@dataclass(frozen=True)
class Pt:
    x: float
    y: float


def ccw(a: Pt, b: Pt, c: Pt) -> float:
    """有向面积*2：>0 左转，<0 右转，=0 共线。"""
    return (b.x - a.x) * (c.y - a.y) - (b.y - a.y) * (c.x - a.x)


def dist2(a: Pt, b: Pt) -> float:
    return (a.x - b.x) ** 2 + (a.y - b.y) ** 2


def convex_hull_andrew(points: List[Pt], keep_collinear: bool = False) -> List[Pt]:
    """Andrew 单调链。默认只保留极点；keep_collinear=True 时边上共线点保留。
    返回逆时针凸包顶点（不含重复首点）。
    """
    pts = sorted(set(points), key=lambda p: (p.x, p.y))
    n = len(pts)
    if n <= 1:
        return pts
    # 下壳：维护左转（逆时针）链。<=0 弹出表示删除右转与共线（仅极点）
    def ok(a: Pt, b: Pt, c: Pt) -> bool:
        cr = ccw(a, b, c)
        return cr > 0 if not keep_collinear else cr >= 0

    lower: List[Pt] = []
    for p in pts:
        while len(lower) >= 2 and not ok(lower[-2], lower[-1], p):
            lower.pop()
        lower.append(p)
    upper: List[Pt] = []
    for p in reversed(pts):
        while len(upper) >= 2 and not ok(upper[-2], upper[-1], p):
            upper.pop()
        upper.append(p)
    # 拼接，去掉端点重复
    return lower[:-1] + upper[:-1]


def convex_hull_graham(points: List[Pt], keep_collinear: bool = False) -> List[Pt]:
    """Graham 扫描：选最低点作基准，按极角排序后栈扫描。"""
    pts = list(set(points))
    if len(pts) <= 1:
        return pts
    # 基准：y 最小，再 x 最小
    base = min(pts, key=lambda p: (p.y, p.x))
    pts.remove(base)

    def polar_key(p: Pt):
        # 用叉积排序避免 atan2：这里用 atan2 便于阅读，生产可用叉积比较器
        return (math.atan2(p.y - base.y, p.x - base.x), dist2(base, p))

    pts.sort(key=polar_key)
    # 同极角保留最远点（可选）：若只要极点，扫描时用 <=0 弹出即可

    def ok(a: Pt, b: Pt, c: Pt) -> bool:
        cr = ccw(a, b, c)
        return cr > 0 if not keep_collinear else cr >= 0

    stack = [base]
    for p in pts:
        while len(stack) >= 2 and not ok(stack[-2], stack[-1], p):
            stack.pop()
        stack.append(p)
    return stack


def hull_area(hull: List[Pt]) -> float:
    """凸包（逆时针）面积。"""
    s = 0.0
    n = len(hull)
    for i in range(n):
        x1, y1 = hull[i].x, hull[i].y
        x2, y2 = hull[(i + 1) % n].x, hull[(i + 1) % n].y
        s += x1 * y2 - x2 * y1
    return abs(s) / 2.0


if __name__ == "__main__":
    square = [Pt(0, 0), Pt(1, 0), Pt(1, 1), Pt(0, 1), Pt(0.5, 0.5)]
    h = convex_hull_andrew(square)
    assert len(h) == 4 and abs(hull_area(h) - 1.0) < 1e-9

    # 经典共线边界：三角形 + 边上中点
    tri = [Pt(0, 0), Pt(4, 0), Pt(0, 4), Pt(2, 0)]
    h2 = convex_hull_andrew(tri, keep_collinear=True)
    assert len(h2) == 4  # 保留 (2,0)
    h3 = convex_hull_andrew(tri, keep_collinear=False)
    assert len(h3) == 3

    # Graham 与 Andrew 顶点集合一致
    pts = [Pt(0, 3), Pt(1, 1), Pt(2, 2), Pt(4, 4), Pt(0, 0), Pt(1, 0), Pt(3, 0),
           Pt(3, 3), Pt(2, 1), Pt(4, 1)]
    a = set(convex_hull_andrew(pts))
    g = set(convex_hull_graham(pts))
    assert a == g and len(a) >= 3

    # 随机对拍：凸包面积非负，且所有点在凸包内（用叉积符号）
    import random
    random.seed(0)
    for _ in range(20):
        pts = [Pt(random.randint(0, 50), random.randint(0, 50)) for _ in range(30)]
        pts = list(set(pts))
        h = convex_hull_andrew(pts)
        if len(h) < 3:
            continue
        # 边界上每条边，其余点均在左侧或边上
        m = len(h)
        for i in range(m):
            a, b = h[i], h[(i + 1) % m]
            for p in pts:
                assert ccw(a, b, p) >= -1e-9
    print("凸包算法：全部用例通过")
```

## 五、与其他技术对比

| 算法 | 时间 | 空间 | 特点 | 适用 |
|------|------|------|------|------|
| 暴力枚举边 | $O(n^2)$~$O(n^3)$ | $O(1)$ | 易写 | $n \le 200$ |
| **Graham 扫描** | $O(n\log n)$ | $O(n)$ | 极角排序，教科书经典 | 通用 |
| **Andrew 单调链** | $O(n\log n)$ | $O(n)$ | 字典序，无三角函数，最稳 | **工程首选** |
| Jarvis 礼包 | $O(nh)$ | $O(1)$ | 输出敏感 | $h$ 很小 |
| QuickHull | 期望 $O(n\log n)$ | $O(n)$ | 像快排，最坏 $O(n^2)$ | 高维/期望快 |
| 分治 / 增量 | $O(n\log n)$ | $O(n)$ | 可扩展到高维 | 教学/高维 |

取舍：**二维优先 Andrew**——实现短、无浮点极角、共线好处理。$h$ 极小用 Jarvis。高维（3D+）用增量法或 QuickHull（CGAL）。输出敏感场景避开“必须全排序”的方法。

## 六、常见误区

1. **栈弹出条件写反。** 写成 `ccw < 0` 弹出（应是 `<= 0` 只留极点，或对称约定），结果凸包留下凹点或丢掉极点。后果：面积错、后续最远点对错。
2. **共线处理前后不一致。** 排序按“同极角取最近”，扫描却用 `<=0`，或反过来，导致边上的点时有时无。应文档化约定：只返回极点，还是返回边界所有点。
3. **比较器不是严格弱序。** 极角相等时未比距离，`std::sort` / `list.sort` 在某些输入下崩溃或结果不定。
4. **忘记去重。** 重复点使 `dist=0`，极角未定义，扫描出现除零或退化栈。先 `set` 去重。
5. **点数 $<3$ 仍跑主算法。** $n=2$ 时“凸包”是线段；$n=1$ 是点。应在入口特判，否则面积公式、打印都可能错。

## 八、面试题

**1. 写出求二维凸包的算法，要求 $O(n\log n)$，并说明为何正确。**
参考答案：Andrew 单调链。按 $(x,y)$ 排序，从左到右维护下壳栈，弹出条件为 $\mathrm{ccw} \le 0$（非左转）；再反向建上壳，拼接。正确性：栈保持严格左转的凸链，$x$ 单调保证是下边界，归纳可证局部凸 ⇒ 全局凸。

**2. 凸包边上的共线点要不要保留？**
参考答案：看题。只求极点时弹出条件 `ccw<=0`；要边界全部点则 `ccw<0`，并在同极角排序时按距离保留最远/最近，二选一保持一致。面试要主动说明约定。

**3. 最远点对为什么可以在凸包上求？**
参考答案：任意两点距离是凸函数；若点对中有一点在凸包内部，把它沿远离另一点方向推到边界不会减小距离。故最远点对必在凸包顶点上，可用旋转卡壳 $O(h)$。

**4. $n=10^6$ 但凸包只有 20 个点，选哪个算法？**
参考答案：Jarvis 礼包 $O(nh)$，约 $2\times10^7$ 次操作，优于全排序的 $O(n\log n)$ 常数。若必须排序法，Andrew 仍可接受。

## 九、演进与趋势

**旋转卡壳（rotating calipers）** 在凸包上求直径、宽度、最小外接矩形，$O(h)$。**动态凸包**（如 Overmars 结构）支持插入并维护凸包，$O(\log^2 n)$。**高维凸包**复杂度 $O(n^{\lfloor d/2\rfloor})$，工程用 QuickHull（CGAL、Qhull）。

**GPU 并行凸包**用于点云预处理、自动驾驶障碍物包络。**鲁棒凸包**（CGAL::Convex_hull_2）用精确谓词处理整数/有理坐标，避免浮点凸包出现“缺角”。**与机器学习结合**：凸包用于异常检测（包络外点）、支持向量机的几何解释、形状匹配。

## 十、小结

凸包的精髓是**有序扫描 + 栈维护局部凸性**：Andrew 用 $x$ 序、Graham 用极角序，弹出条件都是“非左转则删凹点”。掌握叉积定向、共线约定与 $O(n\log n)$ 分析，就打通了从基础谓词到旋转卡壳、半平面交的进阶路径。
