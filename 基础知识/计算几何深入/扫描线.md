# 扫描线

> 对应 Bentley & Ottmann (1979) 平面扫描、de Berg 等《Computational Geometry》第 2 章，以及矩形面积并、周长并等经典扫描线应用。

## 一、背景与挑战

平面扫描（plane sweep / line sweep）是计算几何最重要的算法设计范式之一：想象一条竖直直线从左向右扫过平面，沿途只处理“事件点”，并用一个一维结构维护扫描线上的状态。它把二维问题降成一维动态问题，典型应用包括：求矩形面积并、周长并、线段交点（Bentley–Ottmann）、最近点对、多边形划分、可见性、排版与超大规模集成电路（VLSI）布线冲突检测。

朴素做法的失败在于**全局两两检查**。例如求 $n$ 个矩形的面积并：两两求交、容斥，复杂度爆炸且去重极难；求所有线段交点两两判定是 $O(n^2)$。扫描线的洞察是：**大部分事件只影响局部状态**。矩形问题里，离开某个矩形的右边界时，只需从“覆盖集合”里删掉它；线段求交里，只有扫描线上的**相邻线段**才可能下一个相交。用平衡树/堆维护状态，可把复杂度降到 $O((n+k)\log n)$ 或 $O(n\log n)$。

工程与面试中，扫描线是“矩形面积并”这类题的标准答案。面试官考察：事件点如何设计、扫描线状态如何维护、高度方向如何用差分/线段树压缩坐标。工程上它是地图叠置、UI 脏区合并、游戏遮挡剔除、编译器寄存器活跃区间的底层思想。

## 二、核心原理

### 1. 事件点设计

扫描线沿 $x$ 轴推进，事件是“状态发生改变的 $x$ 坐标”：

- **矩形面积并**：每个矩形 $[x_1,x_2]\times[y_1,y_2]$ 产生两个事件：$x_1$ 处 `+1` 插入纵向区间 $[y_1,y_2]$，$x_2$ 处 `-1` 删除。
- **线段求交**：事件为线段左端点（插入）、右端点（删除）、以及新发现的交点（交换相邻线段顺序并报告）。
- **最近点对 / 凸包扫描**：事件为按 $x$ 排序的点，状态维护活跃点集。

事件按 $x$ 优先队列（堆）排序；同一 $x$ 的多个事件需按规则批处理（如先删后插、或按 $y$ 再排序），避免漏交点。

### 2. 扫描线状态结构

状态维护“当前与扫描线相交的对象集合”：

- 矩形覆盖：维护 $y$ 轴上的**覆盖计数**，求“总覆盖长度”。线段树区间加减 + 查询总长，离散化 $y$ 后 $O(\log n)$ 更新。
- 线段求交：维护线段的**上下顺序**（平衡树），只比较相邻线段，发现交点后插入事件。

**不变量**：任意时刻，状态结构恰好描述 $x = x_{\text{cur}}$ 处扫描线与所有活跃对象的交。

### 3. 矩形面积并（经典应用）

1. 离散化所有 $y$ 坐标，得到 $m = O(n)$ 个基本区间。
2. 事件按 $x$ 排序扫描，相邻两事件 $x_i, x_{i+1}$ 之间的贡献为
   $$
   \Delta = (x_{i+1} - x_i) \times \mathrm{coverLen}(y),
   $$
   其中 `coverLen` 是当前覆盖计数 $>0$ 的 $y$ 总长。
3. 累加 $\Delta$ 即得面积。

**边界条件**：$x$ 相同的事件要先全部处理再算宽度；$y$ 离散化时“基本区间”长度是 `ys[i+1]-ys[i]`，线段树节点存区间长度而非点数。

### 4. 为什么正确

扫描线从左到右，矩形在 $x_1$ 进入、$x_2$ 离开，覆盖计数准确描述了每个 $y$ 位置被覆盖的层数。相邻事件之间覆盖模式不变，故用 $(x_{i+1}-x_i)\times$ 当前覆盖长求面积是精确的。线段求交的正确性依赖“相邻交换”：平面上两条线段若相交，则在交点 $x$ 之前它们在扫描线上必然相邻，否则与连续性矛盾。

## 三、形式化与数学基础

**矩形面积并。** 设事件 $x$ 坐标为 $x_0 < x_1 < \cdots < x_{k-1}$，在 $[x_i, x_{i+1})$ 上覆盖函数 $C(y)$ 不变。则

$$
\mathrm{Area} = \sum_{i=0}^{k-2} (x_{i+1} - x_i) \cdot \lambda(\{ y : C(y) > 0 \}),
$$

其中 $\lambda$ 是一维 Lebesgue 测度（覆盖长度）。离散化后 $\lambda$ 用线段树维护 $O(\log n)$。

**复杂度。** 事件 $O(n)$ 个，每次线段树更新 $O(\log n)$，总 $O(n\log n)$；离散化排序 $O(n\log n)$。

**Bentley–Ottmann。** 事件数 $O(n+k)$（$k$ 为交点数），每次堆/平衡树操作 $O(\log n)$，总

$$
O((n+k)\log n).
$$

空间 $O(n)$。退化（三线共点、重合线段）需定义全序打破平局，否则相邻关系不稳定。

**周长并。** 类似扫描，但同时维护覆盖长度与覆盖段数：垂直边贡献 $(x_{i+1}-x_i) \times 2 \times (\text{段数})$，水平边在事件处直接加减。关键是维护“段数”而不仅是总长。

**坐标离散化。** $n$ 个矩形最多 $2n$ 个不同 $y$，压缩到 $[0, 2n)$，线段树规模 $O(n)$。注意维护原始坐标长度数组，查询时还原真实长度。

## 四、代码实现

```python
"""扫描线求矩形面积并（离散化 + 线段树覆盖计数）。"""
from __future__ import annotations
from dataclasses import dataclass
from typing import List


@dataclass
class Rect:
    x1: float
    y1: float
    x2: float
    y2: float

    def __post_init__(self):
        if self.x1 > self.x2:
            self.x1, self.x2 = self.x2, self.x1
        if self.y1 > self.y2:
            self.y1, self.y2 = self.y2, self.y1


class SegTree:
    """区间加减覆盖计数，维护总覆盖长度。ys 为离散化后的 y 坐标。"""

    def __init__(self, ys: List[float]):
        self.ys = ys
        self.n = len(ys) - 1  # 基本区间数
        self.cnt = [0] * (4 * self.n)
        self.length = [0.0] * (4 * self.n)

    def _push_up(self, u: int, l: int, r: int):
        if self.cnt[u] > 0:
            self.length[u] = self.ys[r + 1] - self.ys[l]
        else:
            if l == r:
                self.length[u] = 0.0
            else:
                self.length[u] = self.length[2 * u] + self.length[2 * u + 1]

    def update(self, u: int, l: int, r: int, L: int, R: int, v: int):
        if L <= l and r <= R:
            self.cnt[u] += v
            self._push_up(u, l, r)
            return
        mid = (l + r) // 2
        if L <= mid:
            self.update(2 * u, l, mid, L, R, v)
        if R > mid:
            self.update(2 * u + 1, mid + 1, r, L, R, v)
        self._push_up(u, l, r)

    @property
    def cover_length(self) -> float:
        return self.length[1] if self.n > 0 else 0.0


def rectangle_union_area(rects: List[Rect]) -> float:
    if not rects:
        return 0.0
    ys = sorted({r.y1 for r in rects} | {r.y2 for r in rects})
    y_id = {y: i for i, y in enumerate(ys)}
    events = []
    for r in rects:
        events.append((r.x1, 1, r.y1, r.y2))
        events.append((r.x2, -1, r.y1, r.y2))
    events.sort(key=lambda e: (e[0], e[1]))  # 同 x 先删后插亦可，关键是宽度在批处理后算

    st = SegTree(ys)
    area = 0.0
    i = 0
    m = len(events)
    while i < m:
        x = events[i][0]
        # 处理同一 x 的所有事件
        j = i
        while j < m and events[j][0] == x:
            _, v, y1, y2 = events[j]
            L, R = y_id[y1], y_id[y2] - 1  # 基本区间 [y1,y2) 对应索引
            if L <= R:
                st.update(1, 0, st.n - 1, L, R, v)
            j += 1
        # 与下一个 x 之间的贡献
        if j < m:
            width = events[j][0] - x
            area += width * st.cover_length
        i = j
    return area


def rectangle_union_area_brute(rects: List[Rect]) -> float:
    """暴力：网格采样精确对拍（坐标为有限小数时可用）。"""
    if not rects:
        return 0.0
    xs = sorted({r.x1 for r in rects} | {r.x2 for r in rects})
    ys = sorted({r.y1 for r in rects} | {r.y2 for r in rects})
    area = 0.0
    for i in range(len(xs) - 1):
        for j in range(len(ys) - 1):
            cx = (xs[i] + xs[i + 1]) / 2
            cy = (ys[j] + ys[j + 1]) / 2
            for r in rects:
                if r.x1 <= cx <= r.x2 and r.y1 <= cy <= r.y2:
                    area += (xs[i + 1] - xs[i]) * (ys[j + 1] - ys[j])
                    break
    return area


if __name__ == "__main__":
    # 两个重叠矩形
    r1 = Rect(0, 0, 2, 2)
    r2 = Rect(1, 1, 3, 3)
    assert abs(rectangle_union_area([r1, r2]) - 7.0) < 1e-9

    # 不相接
    assert abs(rectangle_union_area([Rect(0, 0, 1, 1), Rect(2, 0, 3, 1)]) - 2.0) < 1e-9

    # 完全包含
    assert abs(rectangle_union_area([Rect(0, 0, 4, 4), Rect(1, 1, 2, 2)]) - 16.0) < 1e-9

    # 随机对拍
    import random
    random.seed(2)
    for _ in range(15):
        rects = []
        for _ in range(6):
            x1 = random.randint(0, 10)
            y1 = random.randint(0, 10)
            rects.append(Rect(x1, y1, x1 + random.randint(1, 5), y1 + random.randint(1, 5)))
        assert abs(rectangle_union_area(rects) - rectangle_union_area_brute(rects)) < 1e-9

    print("扫描线：全部用例通过")
```

## 五、与其他技术对比

| 方法 | 思想 | 复杂度 | 优点 | 缺点 |
|------|------|--------|------|------|
| 两两容斥 | 矩形对求交 | $O(n^2)$~$O(n^3)$ | 直观 | 去重困难，易错 |
| **扫描线 + 线段树** | 事件驱动，维护覆盖长 | $O(n\log n)$ | 精确、通用 | 实现中等 |
| 树状数组差分 | 前缀和维护 | $O(n\log n)$ | 代码短 | 只适合可差分情形 |
| 分治（按 $x$ 切） | 左右合并 | $O(n\log n)$ | 与最近点对同构 | 合并逻辑复杂 |
| 像素/网格采样 | 暴力覆盖 | $O(n\cdot G)$ | 极简 | 有分辨率误差 |

取舍：**矩形面积/周长并用扫描线 + 线段树**是标准解；动态加删矩形也可用同一结构。线段求交用 Bentley–Ottmann；若交点很多，$O(n^2)$ 两两判定反而更简单。

## 六、常见误区

1. **同 $x$ 事件未批处理。** 逐个处理后立刻算宽度，导致宽度为 0 或覆盖状态瞬时错误。应把同一 $x$ 的增删全部应用后，再与下一 $x$ 算贡献。
2. **线段树存点数而非区间长。** 离散化后基本区间是 `[ys[i], ys[i+1])`，长度是坐标差；存节点下标会得到错误面积。
3. **`R = y_id[y2]` 写成 `y_id[y2]-1` 遗漏或多余。** 矩形纵跨 $[y1,y2)$，对应基本区间索引 $[y_{id}[y1], y_{id}[y2]-1]$；差一即少算一格。
4. **忘记覆盖计数下推/上推的 `cnt>0` 判断。** 父节点被整体覆盖时不能简单加子长度，否则重复计数。`push_up` 必须先看 `cnt[u]>0`。
5. **Bentley–Ottmann 平局未定全序。** 多线段交于同点、端点重合时，相邻关系抖动，漏交点或重复报告。

## 八、面试题

**1. 求 $n$ 个矩形的面积并，怎么做？**
参考答案：扫描线。离散化 $y$，矩形左右边界生成 $+1/-1$ 事件，按 $x$ 扫描；线段树维护覆盖计数与覆盖总长。相邻事件间距 $\times$ 当前覆盖长累加。$O(n\log n)$。

**2. 扫描线状态为什么要用平衡树/线段树？**
参考答案：状态是动态的区间集合，每次事件要做区间加减并查询聚合量（总长、段数）。线段树支持 $O(\log n)$ 更新与查询，否则退化为 $O(n)$ 每事件。

**3. Bentley–Ottmann 为何只比较相邻线段？**
参考答案：扫描线从左向右，两条线段若相交，在交点之前必然在扫描线上相邻。维护全序，只检查邻居并插入交点事件，可避免 $O(n^2)$。

**4. 如何求矩形周长并？**
参考答案：扫描时维护覆盖总长与覆盖段数。垂直方向贡献 $2 \times \text{段数} \times \Delta x$；水平边在事件处按覆盖变化直接加减。关键是段数维护（线段树上记录左/右端覆盖与连续段数）。

## 九、演进与趋势

**广义扫描线**：沿圆、沿多边形边界扫描；拓扑扫描（topological sweep）不显式维护交点，适合超大规模。**与线段树/树状数组结合**成为竞赛“扫描线全家桶”。

**工程应用**：GIS 叠置分析（GEOS 的 overlay）、UI 脏矩形合并、编译器活跃区间（interval graph 着色）、CPU 指令调度窗口、游戏视野遮挡。**GPU 端** 用并行扫描做遮挡剔除与碰撞候选对生成。

**近似与增量**：实时系统用网格 + 局部扫描，牺牲精确性换吞吐。**鲁棒扫描**要求精确谓词处理共点、共线，CGAL 的平面扫描器对此有完整实现。

## 十、小结

扫描线把二维动态几何问题降维成“事件队列 + 一维状态结构”，用局部更新换全局最优复杂度。矩形面积并是入门标杆，Bentley–Ottmann 是理论高峰；掌握事件设计、状态不变量与离散化线段树，就能一通百通地解决叠置、求交、可见性等一大批问题。
