# 扫描线

> 对应 计算几何扫描线方法（Bentley-Ottmann 平面扫描）与几何求交文献。

## 一、背景与挑战
平面扫描（plane sweep）用于求线段交点、最近邻、可见性等。沿某一轴移动垂线，用平衡树维护当前交点状态。

## 二、核心原理
事件点 = 线段端点与交点；扫描线状态结构（如红黑树）维护当前与扫描线相交的线段顺序，相邻线段才可能相交。

## 三、形式化 / 数学基础
Bentley-Ottmann 在一般位置下复杂度 $O((n+k)\log n)$（k 为交点数）；退化（重合/三交一点）需特殊处理。

## 四、代码实现
```python
def segments_intersect(p1, p2, p3, p4):
    def cross(a, b, c):
        return (b[0]-a[0])*(c[1]-a[1]) - (b[1]-a[1])*(c[0]-a[0])
    d1 = cross(p3, p4, p1)
    d2 = cross(p3, p4, p2)
    d3 = cross(p1, p2, p3)
    d4 = cross(p1, p2, p4)
    if ((d1 > 0) != (d2 > 0)) and ((d3 > 0) != (d4 > 0)):
        return True
    return False
```

## 五、与其他技术对比
与两两 O(n^2) 判交相比，扫描线显著减少比较；与网格哈希相比，扫描线保证正确且易处理顺序。

## 六、常见误区
未处理共线/重合退化；状态树未正确交换相邻线段；事件去重遗漏重复交点。

## 八、面试题
「线段相交检测」；「矩形重叠面积」（扫描线 + 区间树）。

## 九、演进与趋势
稳健扫描线处理退化；与 CGAL 库整合。

## 十、小结
几何扫描线用事件 + 状态结构把静态几何问题转为流式处理，是求交/覆盖类问题的通用框架。
