# 几何库

> 对应 CGAL、Boost.Geometry 及《Computational Geometry Algorithms and Applications》。

## 一、背景与挑战
手写几何易因浮点误差与退化输入出错。成熟几何库提供稳健谓词、凸包、布尔运算、Delaunay 等。

## 二、核心原理
核心是「精确几何谓词」（如 orientation 用大整数/有理运算）与「鲁棒构造」，避免 `sqrt`/除法的累积误差。

## 三、形式化 / 数学基础
谓词返回值仅由符号决定，用整数交叉积即可精确判定方向；构造（如交点坐标）才需有理数表示。

## 四、代码实现
```python
from fractions import Fraction
def orientation_exact(a, b, c):
    v = Fraction(b[0]-a[0]) * Fraction(c[1]-a[1]) - Fraction(b[1]-a[1]) * Fraction(c[0]-a[0])
    return 0 if v == 0 else (1 if v > 0 else -1)
# 用精确分数避免浮点误差，适合做稳健谓词
```

## 五、与其他技术对比
与手写 double 相比，几何库/精确算术避免 WA；代价是性能与实现复杂度。

## 六、常见误区
直接用 double 比较相等距离；忽略退化（三点共线、重合点）；自写 EPS 阈值掩盖而非解决问题。

「如何用稳健方式判定点线关系」；EPS 的取舍。

## 九、演进与趋势
任意精度算术（GMP）；GPU 几何；与机器学习结合的点云几何。

## 十、小结
几何库价值在稳健：用精确谓词消除浮点误差，工程与竞赛中实现复杂场景应优先复用而非重写。
