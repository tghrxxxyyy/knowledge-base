# 最近点对

> 对应 CLRS《Introduction to Algorithms》第 33.4 章（分治求最近点对）。

## 一、背景与挑战
平面上 n 个点求距离最小的一对。暴力 O(n^2)，分治法可达 O(n log n)。

## 二、核心原理
按 x 中线分左右，递归得最小距离 δ；仅检查中线两侧 δ 窄带内的点，按 y 排序后每点只比较其后至多 7 个点。

## 三、形式化 / 数学基础
关键事实：δ×2δ 矩形内至多 8 个点使相互距离 ≥ δ，故窄带内每点只需看后继常数个。复杂度 $T(n)=2T(n/2)+O(n)=O(n\log n)$。

## 四、代码实现
```python
import math
def closest_pair(pts):
    pts = sorted(pts)
    def dist(a, b):
        return math.hypot(a[0]-b[0], a[1]-b[1])
    def rec(ys):
        if len(ys) <= 3:
            d = float('inf')
            for i in range(len(ys)):
                for j in range(i+1, len(ys)):
                    d = min(d, dist(ys[i], ys[j]))
            return d, ys
        mid = len(ys) // 2
        d1, _ = rec(ys[:mid])
        d2, _ = rec(ys[mid:])
        d = min(d1, d2)
        strip = [p for p in ys if abs(p[0] - ys[mid][0]) < d]
        strip.sort(key=lambda p: p[1])
        for i in range(len(strip)):
            for j in range(i+1, min(i+8, len(strip))):
                d = min(d, dist(strip[i], strip[j]))
        return d, ys
    return rec(pts)[0]
```

## 五、与其他技术对比
与暴力相比，分治把平方降到 n log n；与 k-d 树相比，分治实现简洁、适合静态点集。

## 六、常见误区
窄带比较上限写错（应为常数个）；未对 y 排序导致退化；坐标未去重（重复点距离 0）。

## 十、小结
最近点对分治靠「中线窄带 + 常数比较」把复杂度降到 O(n log n)，是分治在几何中的典范。
