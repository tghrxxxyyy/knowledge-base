# 最近点对

> 对应 CLRS《Introduction to Algorithms》第 33.4 节（分治求最近点对），以及 Shamos & Hoey (1975) 平面最近点对的分治算法。

## 一、背景与挑战

给定平面上 $n$ 个点，求欧氏距离最小的一对点。这是计算几何最经典的分治范例：暴力两两枚举是 $O(n^2)$，而分治可以把复杂度压到 $O(n\log n)$，接近排序的量级。应用极广——碰撞检测里判断最近障碍、聚类中的层次聚类、无线网络基站干扰分析、点云配准的粗匹配，本质都是“最近点对”或其变体（$k$ 近邻、半径内邻居）。

朴素做法的失败在于**无法利用几何稀疏性**。两点距离近，说明它们在空间上相邻；若先把点按 $x$ 切成左右两半，最近点对要么完全在左半、要么完全在右半、要么跨越中线。前两种递归解决，第三种看似仍要 $O(n^2)$，但**跨越中线的候选其实极少**：只可能出现在中线两侧宽度为 $\delta$ 的窄带内（$\delta$ 是左右递归得到的当前最小距离），且带内每个点只需与其后常数个点比较。这就是分治正确性与效率的核心。

面试中最近点对是“分治 + 几何论证”的标杆题。面试官不仅要看你写出递归骨架，更要看你**证明窄带内每点只比较常数个点**——这一步几何引理（$2\delta\times\delta$ 矩形内至多 4/8 个点）才是真正的考点。工程上，大规模点集常用网格哈希或 k-d 树近似，但分治仍是理解问题结构的标准答案。

## 二、核心原理

### 分治框架

1. 按 $x$ 坐标排序点集，取中位点画竖直线，分成左半 $L$、右半 $R$。
2. 递归求 $d_L = \mathrm{closest}(L)$，$d_R = \mathrm{closest}(R)$，令 $\delta = \min(d_L, d_R)$。
3. **合并**：收集 $x$ 坐标落在 $[x_m - \delta, x_m + \delta]$ 内的点（窄带），按 $y$ 排序，对每个点只与其后 $y$ 距离 $< \delta$ 的点比较，更新 $\delta$。
4. 返回 $\delta$。

**不变量**：递归返回的 $\delta$ 是子集内最近距离；合并后 $\delta$ 是全集最近距离。

**关键几何引理**：考虑窄带内任一点 $p$，只需检查其后 $y$ 坐标差 $< \delta$ 的点。这些点必落在宽 $2\delta$、高 $\delta$ 的矩形内。把该矩形分成两个 $\delta\times\delta$ 正方形，每个正方形内**至多有 4 个点**（若超过，其中两点距离 $< \delta$，与 $\delta$ 是最小距离矛盾；实际每个正方形至多 4 点、相邻两正方形合计至多 8 点，工程上常写“比较后 7 个点”）。

**为什么正确**：设全局最近点对是 $(p,q)$ 跨越中线。则 $|p.x - q.x| \le \delta$（否则 $|p-q| > \delta$，与递归结果矛盾），故 $p,q$ 都在窄带内。若按 $y$ 排序后 $q$ 不在 $p$ 的后续 7 个点中，则 $q$ 与 $p$ 的 $y$ 差超过矩形能容纳的范围，必与引理矛盾。因此检查常数个后继即可保证找到 $(p,q)$。

**边界条件**：

- $n=2$ 直接返回距离；$n=3$ 三对比较。
- 窄带为空时直接返回 $\delta$。
- $y$ 排序可在递归时“顺带维护”（merge 式），避免每层 $O(n\log n)$ 排序导致复杂度退化到 $O(n\log^2 n)$。
- 重复点距离为 0，应直接返回 0。

## 三、形式化与数学基础

**主定理 / 递归式。** 若每层合并 $O(n)$（$y$ 有序可线性合并），则

$$
T(n) = 2T(n/2) + O(n) = O(n\log n).
$$

若每层重新排序窄带，$T(n) = 2T(n/2) + O(n\log n) = O(n\log^2 n)$，常数更大但仍远优于 $O(n^2)$。

**矩形引理。** 设 $\delta$ 是左、右半各自的最近距离。对窄带内一点 $p$，令 $S$ 为 $y$ 坐标在 $[p.y - \delta, p.y + \delta)$ 的点。把 $p$ 右侧（或左侧）的候选区域划入 $\delta\times 2\delta$ 矩形，再二分为两个 $\delta\times\delta$ 正方形。每个正方形内任两点距离 $\ge \delta$，故每个正方形至多 4 个点（可用鸽笼：把正方形均分成 4 个 $(\delta/2)\times(\delta/2)$ 小格，每格至多 1 点）。两正方形合计 $\le 8$ 个点，除去 $p$ 自身，故**比较后 7 个点足够**。

**严格表述**：令点按 $y$ 递增为 $p_1,\dots,p_m$。对 $p_i$，只需检查 $p_{i+1},\dots,p_{i+7}$。若存在 $j>i+7$ 使 $|p_i p_j| < \delta$，则 $p_j$ 必落在上述矩形内，与引理矛盾。

**分治正确性（形式）**：对点集规模 $n$ 归纳。$n\le 3$ 显然。设对左右半成立，$\delta = \min(d_L,d_R)$。若全局最近对同侧，递归已找到；若跨侧，由矩形引理在合并步骤必被检查到。故返回值正确。

**下界**：基于比较模型，最近点对可归约到排序（一维情形即相邻差），故 $\Omega(n\log n)$ 是紧的；分治达到最优阶。

## 四、代码实现

```python
"""分治最近点对，O(n log n)。"""
from __future__ import annotations
from dataclasses import dataclass
from typing import List, Tuple
import math


@dataclass(frozen=True)
class Pt:
    x: float
    y: float


def dist(a: Pt, b: Pt) -> float:
    return math.hypot(a.x - b.x, a.y - b.y)


def _closest_rec(px: List[Pt], py: List[Pt]) -> float:
    """px 按 x 排序，py 按 y 排序，返回最近距离。"""
    n = len(px)
    if n <= 3:
        best = float("inf")
        for i in range(n):
            for j in range(i + 1, n):
                best = min(best, dist(px[i], px[j]))
        return best

    mid = n // 2
    midpoint = px[mid]
    left_x, right_x = px[:mid], px[mid:]
    # 按 x 划分 py，保持 y 有序
    left_y = [p for p in py if p.x <= midpoint.x]
    right_y = [p for p in py if p.x > midpoint.x]
    # 处理 x 相同导致左右不均的情况：若一侧空，强制按数量切分 py
    if not left_y or not right_y:
        left_y, right_y = py[:mid], py[mid:]

    delta = min(_closest_rec(left_x, left_y), _closest_rec(right_x, right_y))

    # 窄带：|x - midpoint.x| < delta
    strip = [p for p in py if abs(p.x - midpoint.x) < delta]
    m = len(strip)
    for i in range(m):
        # 每点只比较其后 7 个 y 更大的点
        for j in range(i + 1, min(i + 8, m)):
            d = dist(strip[i], strip[j])
            if d < delta:
                delta = d
    return delta


def closest_pair(points: List[Pt]) -> float:
    """返回最近点对距离；点数 < 2 返回 inf。重复点距离为 0。"""
    if len(points) < 2:
        return float("inf")
    seen = set()
    for p in points:
        if p in seen:
            return 0.0
        seen.add(p)
    pts = list(seen)
    px = sorted(pts, key=lambda p: (p.x, p.y))
    py = sorted(pts, key=lambda p: (p.y, p.x))
    return _closest_rec(px, py)


def closest_pair_brute(points: List[Pt]) -> float:
    pts = list(set(points))
    n = len(pts)
    best = float("inf")
    for i in range(n):
        for j in range(i + 1, n):
            best = min(best, dist(pts[i], pts[j]))
    return best


if __name__ == "__main__":
    # 经典用例
    pts = [Pt(0, 0), Pt(3, 4), Pt(1, 1), Pt(2, 2), Pt(10, 10)]
    assert abs(closest_pair(pts) - math.sqrt(2)) < 1e-9  # (1,1)-(2,2)

    # 跨中线最近（x=5 两侧各一点）
    pts = [Pt(0, 0), Pt(4.95, 0.0), Pt(5.05, 0.0), Pt(10, 0)]
    assert abs(closest_pair(pts) - 0.1) < 1e-9

    # 重复点
    assert closest_pair([Pt(1, 1), Pt(1, 1), Pt(2, 2)]) == 0.0

    # 随机对拍暴力
    import random
    random.seed(1)
    for _ in range(30):
        pts = [Pt(random.uniform(0, 100), random.uniform(0, 100)) for _ in range(40)]
        pts = list(set(pts))
        if len(pts) < 2:
            continue
        assert abs(closest_pair(pts) - closest_pair_brute(pts)) < 1e-9

    # 网格点：距离应为 1
    grid = [Pt(i, j) for i in range(5) for j in range(5)]
    assert abs(closest_pair(grid) - 1.0) < 1e-9
    print("最近点对：全部用例通过")
```

## 五、与其他技术对比

| 方法 | 时间 | 空间 | 特点 | 适用 |
|------|------|------|------|------|
| 暴力两两 | $O(n^2)$ | $O(1)$ | 易写 | $n \le 2000$ |
| **分治最近点对** | $O(n\log n)$ | $O(n)$ | 精确，经典 | 通用精确解 |
| 排序 + 相邻检查 | 仅一维 $O(n\log n)$ | $O(n)$ | 二维不适用 | 一维 |
| 网格哈希 | 期望 $O(n)$ | $O(n)$ | 需选合适格宽 | 均匀分布 |
| k-d 树查询 | 建树 $O(n\log n)$，查询 $O(\log n)$ 期望 | $O(n)$ | 支持 $k$ 近邻 | 动态/查询型 |
| 暴力 + 空间索引 | 视分布 | $O(n)$ | 实现灵活 | 工程混合 |

取舍：**一次性求全局最近点对用分治**；若还需支持动态插入/多次查询，k-d 树或球树更合适；均匀分布的海量点可用网格哈希期望 $O(n)$。分治的价值在于最坏复杂度确定且带完整正确性证明。

## 六、常见误区

1. **窄带宽度写成 $\delta/2$ 或 $2\delta$。** 宽度必须是 $2\delta$（中线两侧各 $\delta$）；写错会漏掉跨中线最近对。后果：随机数据偶发 Wrong Answer。
2. **每个点比较带内全部点。** 忘记“只比后 7 个 $y$ 邻居”，复杂度退化 $O(n^2)$，大数据超时。
3. **每层对窄带重新全排序。** $O(n\log^2 n)$，常数大。应在递归中维护 $y$ 有序数组，合并时线性归并。
4. **`x <= midpoint.x` 划分不均衡。** 大量相同 $x$ 时一侧为空，递归退化。应按数量切分或按点而不是按坐标比较。
5. **用欧氏距离开方比较。** 比较阶段可用平方距离避免 `sqrt`，最后再开方，更快且少误差。

## 八、面试题

**1. 平面最近点对如何做到 $O(n\log n)$？**
参考答案：按 $x$ 分治，递归求左右最小距离 $\delta$，只检查中线两侧 $\delta$ 窄带内的点。带内按 $y$ 排序后每点比较后 7 个点。主定理 $T(n)=2T(n/2)+O(n)=O(n\log n)$。

**2. 为什么窄带内每点只需比较常数个？**
参考答案：候选点落在 $\delta\times 2\delta$ 矩形，分割为两个 $\delta\times\delta$ 正方形，每个至多 4 个点（两点距离 $\ge \delta$）。故按 $y$ 后最多 7 个后继需要检查。

**3. 若把欧氏距离换成曼哈顿距离，算法还成立吗？**
参考答案：分治框架仍成立，但矩形引理要改：曼哈顿距离下单位“菱形”内点数仍是常数，可类似证明每点只需比较常数个 $y$ 邻居。实现时距离函数换掉即可。

**4. 一维最近点对怎么做？**
参考答案：排序后扫描相邻差，$O(n\log n)$。也可直接用分治，但无需窄带二维扫描。

## 九、演进与趋势

**$k$ 近邻与半径查询**：分治思想推广为“维护当前第 $k$ 小距离的窄带剪枝”，或直接用 k-d 树/球树。**高维最近邻**维数灾难使精确分治不再占优，LSH、HNSW、IVF 等近似最近邻（ANN）成为向量检索主流。

**并行最近点对**：GPU/多核按 $x$ 分块后合并窄带，适合点云预处理。**动态最近对**用 Overmars 式平衡树 + 凸包/分治结构维护。**工程实践**：物理引擎用网格或 BVH 做候选对筛选，再精确求距离；数据库 PostGIS 的 `<->` 距离操作符底层有空间索引支持。

## 十、小结

最近点对的分治解法展示了**递归分解 + 几何剪枝**的经典范式：$\delta$ 窄带把跨中线候选压到常数规模，矩形引理给出严格正确性，主定理给出 $O(n\log n)$。理解这条证明链，比背代码更重要，也是通往高维最近邻与近似检索的跳板。
