# 分支预测深入

> 对应 CSAPP 中文笔记 https://github.com/Hansimov/csapp 第4章；Hennessy & Patterson 第2章。

## 一、背景与挑战

每遇条件分支，流水需知目标 PC 才能取指；等算出不猜则空泡。现代分支误罚可达 10-20 拍，预测准确率直接决定 IPC。

## 二、核心原理

两级自适应预测（Gshare）：用全局历史寄存器(GHR)异或 PC 索引模式历史表(PHT)的 2 位饱和计数器。2 位计数器在连续两次误预测才翻转，抗噪。BTB 缓存最近分支目标地址。

## 三、形式化 / 数学基础

2 位饱和计数器状态机：

$$C \in \{0,1,2,3\},\quad C' = \mathrm{sat}(C + (t - 0.5))$$

其中 $t\in\{0,1\}$ 为实际走向，饱和至 $[0,3]$。准确率：

$$Acc = 1 - MispredictRate$$

Gshare 索引：$index = (GHR \oplus PC_{k}) \bmod 2^{k}$。

## 四、代码实现

```c
// 分支误罚示意：预测失败需清空流水
for (int i = 0; i < n; i++) {
    if (unlikely(cond(i)))   // 预测器若猜错，后面 15 条指令作废
        do_slow(i);
}
```

## 五、与其他技术对比

- 静态预测（向后分支猜命中）最简单；两级自适应显著更准。
- 混合预测器组合多策略进一步提升。

## 六、常见误区

- 误以为 1 位预测够用：对周期模式(01 交替)必错。
- 忽视 BTB 缺失等价于预测失败。

## 八、面试题

- 为何用 2 位计数器？答：抗单次噪声，需连续两次错才翻转。
- Gshare 中 GHR 异或 PC 的作用？答：把全局上下文与局部地址结合，减少别名冲突。

## 九、演进与趋势

TAGE 预测器（多长度历史组合）在现代 CPU 中达 >95% 准确率；神经预测器在研究中。

## 十、小结

分支预测把控制依赖转为投机执行，是深流水宽发射的命脉。
