# 功耗与性能权衡

> 对应 Hennessy & Patterson 第7章；race-to-idle 概念（公开资料定性）。

## 一、背景与挑战

为省能是否应慢做？需比较“慢做低功率长时间”与“快做高功率短时”的总能量，存在最优。

## 二、核心原理

race-to-idle：尽快完成再深睡，往往总能量更低（因静态功耗随时间累积）。但高频率电压使单拍能量升，需找总能耗最小的工作点。性能/能效曲线非单调。

## 三、形式化 / 数学基础

任务能量：

$$E = P(f) \times T(f) = \alpha C V(f)^2 f \times \frac{W}{f} = \alpha C V(f)^2 W$$

因 $T=W/f$，$f$ 约去，能量只随 $V(f)$ 变：越低频电压越低越省能（忽略静态与睡唤醒）。计入静态：

$$E_{tot} = E_{dyn} + P_{static} T(f)$$

过低频因 $T$ 增大反而增能。

## 五、与其他技术对比

- race-to-idle 适静态主导；长尾轻载可低频。
- 与 DVFS 协同找工作点。

## 六、常见误区

- 误以为越低频越省能：静态功耗抵消。
- 忽视睡唤醒代价可能高于计算。

## 八、面试题

- race-to-idle 是什么？答：尽快完成再睡，常比慢做更省能。
- 为何过低频不省？答：时间长致静态功耗累积。

## 九、演进与趋势

每任务能效调度、异构大小核(big.LITTLE)细化权衡。

## 十、小结

功耗-性能权衡是非单调优化，需同时考虑动态与静态及状态切换。
