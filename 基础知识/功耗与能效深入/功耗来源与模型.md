# 功耗来源与模型

> 对应 Hennessy & Patterson 第4、7章；CSAPP 中文笔记 https://github.com/Hansimov/csapp 相关章节。

## 一、背景与挑战

性能提升受功耗与散热约束，需区分动态与静态功耗来源，才能优化能效。

## 二、核心原理

动态功耗来自充放电：$P_{dyn} = \alpha C V^2 f$。静态功耗( leakage)来自亚阈值与栅漏，随工艺缩小占比上升。总功耗：

$$P_{total} = P_{dyn} + P_{static}$$

电压 $V$ 对动态功耗是平方影响，是调频调压主要杠杆。

## 三、形式化 / 数学基础

动态功耗：

$$P_{dyn} = \alpha C V_{dd}^2 f$$

其中 $\alpha$ 活跃因子，$C$ 开关电容，$f$ 频率。能量每操作：

$$E \propto C V_{dd}^2$$

## 五、与其他技术对比

- 动态功耗随频率/电压上升；静态与电压关系弱但随温度上升。
- 降频降电压主要砍动态功耗。

## 六、常见误区

- 误以为降频总省能：若任务更长，静态功耗累积可能反升。
- 忽视漏电流随温度指数上升。

## 八、面试题

- 动态功耗公式？答：$P=\alpha C V^2 f$，电压平方敏感。
- 静态功耗来源？答：亚阈值/栅漏，工艺越小占比越高。

## 九、演进与趋势

近阈值计算、功耗门控降低静态与动态功耗。

## 十、小结

功耗模型揭示电压是关键杠杆，动态与静态来源决定优化方向。
