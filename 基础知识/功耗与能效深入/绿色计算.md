# 绿色计算

> 对应 Hennessy & Patterson 第7章；数据中心 PUE 概念（公开资料定性）。

## 一、背景与挑战

大规模数据中心能耗巨大，电费与碳排成成本与合规压力，需整体提效。

## 二、核心原理

绿色计算从芯片(低功耗设计)、系统(虚拟化整合、DVFS)、机房(高效供电制冷、PUE 接近1)、软件(节能调度、闲时休眠)多层降耗。PUE = 总设施能耗 / IT 设备能耗，越低越好。

## 三、形式化 / 数学基础

$$PUE = \frac{P_{facility}}{P_{IT}} \ge 1$$

IT 实际可用能效：

$$Eff_{useful} = \frac{UsefulWork}{P_{facility}} = \frac{UsefulWork}{P_{IT}} \times \frac{1}{PUE}$$

降 PUE 与提每瓦性能双重收益。

## 四、代码实现

```c
// 闲时合并负载并休眠空节点
if load < low_watermark:
    migrate_jobs(busy_nodes)
    power_down(idle_nodes)   # 进入深 C-state
```

## 五、与其他技术对比

- 芯片层降功耗是根基；机房层降 PUE 放大收益。
- 虚拟化提高利用率即降单位工作能耗。

## 六、常见误区

- 误以为只靠软件：需芯片-系统-机房协同。
- 忽视虚拟化开销抵消部分收益。

## 八、面试题

- PUE 含义？答：设施电/IT电，越近1越高效。
- 绿色计算层次？答：芯片/系统/机房/软件协同。

## 九、演进与趋势

液冷、余热回收、可再生能源与碳感知调度。

## 十、小结

绿色计算是跨层系统工程，PUE 与每瓦性能共同定义可持续效率。
