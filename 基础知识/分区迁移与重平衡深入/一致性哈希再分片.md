# 一致性哈希再分片

> 对应 Karger 1997 与 DeCandia 2007（Dynamo）。

## 一、背景与挑战
再分片（resharding）指改变分区数量或边界以适配集群规模变化。纯一致性哈希在节点增减时自动再分片，但「从 N 到 N+1」时如何平滑、如何避免热点、如何控制数据分布，是重点。

## 二、核心原理
虚拟节点使再分片粒度更细：新增节点时，从现有各节点「偷取」若干 vnode 区间，而非整段大区间，从而负载平滑转移。再分片过程即一系列 vnode 迁移，配合前文迁移流程。

## 三、形式化与数学基础
设每个物理节点有 \\(V\\) 个 vnode，新增第 \\(N+1\\) 节点后，期望从每个旧节点迁移 \\(V/(N+1)\\) 个 vnode，总迁移量约 \\(Total/N\\)（按 key 计），且每旧节点负担均匀。

## 四、代码实现
```python
def add_node(ring, new_node, vnodes):
    for i in range(vnodes):
        hpos = h(new_node + "#" + str(i))
        victim = current_owner(ring, hpos)
        migrate_vnode(victim, new_node, hpos)   # 偷取区间
        ring[hpos] = new_node
```

## 五、与其他技术对比
固定取模再分片需全量重映射；范围分片再分片需分裂或合并；一致性哈希再分片以 vnode 粒度增量进行，扰动最小。

## 六、常见误区
1. 一次性大区间迁移：网络与负载冲击大。
2. vnode 数过少：再分片粒度粗、不均。
3. 再分片期间不限制速率：挤占正常流量。

## 七、与开源书/权威来源对应
Karger 1997 给出再分片理论界；Dynamo 用 vnode 实现平滑再分片；DDIA 第6章讨论。

## 八、面试题
问：vnode 如何改善再分片？
答：把迁移粒度从「整节点区间」降到「小 vnode」，使新节点从多旧节点均匀偷取，负载平滑。

## 九、演进与趋势
自适应 vnode 数随集群规模动态调整，进一步均衡。

## 十、小结
一致性哈希再分片以 vnode 粒度增量偷取，实现平滑、均衡、低扰动的扩缩容。
