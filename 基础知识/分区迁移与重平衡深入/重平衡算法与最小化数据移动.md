# 重平衡算法与最小化数据移动

> 对应 Karger 1997（一致性哈希）与 DeCandia 2007（Dynamo 再均衡）。

## 一、背景与挑战
当集群从 N 扩到 N+1，理想重平衡应只移动「恰好需要迁移」的数据，让各节点负载均衡且迁移总量最小。如何设计算法是核心。

## 二、核心原理
基于一致性哈希的再平衡天然最小化移动：仅新增节点掠夺环上相邻区间。更主动的均衡器可计算各节点负载，挑选「最重分区」迁移到「最轻节点」，用贪心迭代逼近均衡，且每次只动一个分区以控制扰动。

## 三、形式化与数学基础
设节点负载 \\(L_i\\)，目标均衡差 \\(\Delta=\max L_i-\min L_i\\)。每轮选使 \\(\Delta\\) 下降最多的 (partition, target) 对迁移，直到 \\(\Delta<\tau\\)。总迁移量下界由一致性哈希给出约 \\(K/(N+1)\\)。

## 四、代码实现
```python
def rebalance(nodes, partitions):
    moved = 0
    improved = True
    while improved:
        improved = False
        heavy = max(nodes, key=lambda n: n.load)
        light = min(nodes, key=lambda n: n.load)
        if heavy.load - light.load < THRESH:
            break
        p = heavy.pop_heaviest()
        light.add(p); moved += p.size; improved = True
    return moved
```

## 五、与其他技术对比
一致性哈希被动均衡（依赖随机分布）；主动再平衡精确控制负载但需中心调度；二者常结合（vnode 加主动迁移）。

## 六、常见误区
1. 一次性全量重排：迁移风暴，应增量分批。
2. 忽视迁移成本：为微小均衡付出巨大网络代价。
3. 阈值过低导致抖动：应设置滞回（hysteresis）。

## 七、与开源书/权威来源对应
Karger 1997 证明一致性哈希期望迁移界；Dynamo 用主动再平衡补充；DDIA 第6章讲再均衡成本。

## 八、面试题
问：如何最小化扩缩容数据移动？
答：用一致性哈希使仅邻近区间移动，或贪心每次迁移最减重分区，总量约 K/(N+1)。

## 九、演进与趋势
机器学习预测负载做「前瞻性再平衡」，结合异构权重。

## 十、小结
最小化数据移动靠一致性哈希的结构性质与贪心再平衡，在均衡与迁移成本间权衡。
