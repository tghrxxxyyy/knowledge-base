# 子集构造法

> 对应 龙书 第 3.7 节子集构造 (Subset Construction)。

## 一、背景与挑战
从 NFA 构造等价 DFA 的标准算法。挑战：DFA 状态是 NFA 状态集合，最坏情况下数目 $2^{|Q|}$ 指数增长，但对真实词法规格通常不爆。

## 二、核心原理
DFA 每个状态 = NFA 的某个可达状态子集。初态为 $\text{EPS}(\{q_0\})$；对字母 $a$ 的转移映射到 $\text{EPS}(\bigcup\delta(p,a))$。DFA 接受态为含任一 NFA 接受态的子集。

## 三、形式化 / 数学基础
```
DFAStates = { start = EPS({q0}) }
worklist = [start]
while worklist:
    S = worklist.pop()
    for a in Sigma:
        T = EPS( union_{p in S} delta(p,a) )
        if T not in DFAStates:
            DFAStates.add(T); worklist.append(T)
        move[S][a] = T
```

## 四、代码实现
```python
def subset_construct(nfa):
    start = frozenset(eps_closure({nfa.start}, nfa.eps))
    dfa = {start: {}}; wl = [start]
    while wl:
        S = wl.pop()
        for a in nfa.alphabet:
            T = frozenset(eps_closure(
                {p for s in S for p in nfa.delta(s, a)}, nfa.eps))
            if T not in dfa:
                dfa[T] = {}; wl.append(T)
            dfa[S][a] = T
    return dfa
```

## 五、与其他技术对比
- 子集构造：通用、产生最小所需 DFA（再经最小化）。
- Brzozowski 求导法：用正则导数构造，可对等价类更紧凑。
- 直接构造 DFA（如 flex 的表压缩）避免显式 NFA。

## 六、常见误区
1. 漏算 $\epsilon$-闭包导致转移错。
2. 用可变集合（list/set）做 DFA 状态键——必须用 frozenset。
3. 忘记把"含接受态的子集"标为接受态。

## 九、演进与趋势
Hopcroft 最小化 $O(|Q|\log|Q|)$；实践中 lex 直接产出压缩转移表；增量/惰性构造用于按需生成词法器。

## 十、小结
子集构造把 NFA 的"状态集合"语义直接翻译成 DFA，是词法表生成的理论支柱；配合最小化得到最省空间的高速扫描器。
