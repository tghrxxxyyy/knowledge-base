# 掩码与收集散布

> 对应 Intel AVX/AVX-512 与 ARM SVE 指令集（公开手册定性）；Hennessy & Patterson 第4章。

## 一、背景与挑战

真实数据常不规则：需条件执行(掩码)或在非连续地址读写(gather/scatter)。无此能力则退化标量。

## 二、核心原理

掩码(mask)寄存器按位控制哪些通道执行/写回，实现“谓词化 SIMD”，避免分支。gather 从分散地址收集到向量，scatter 反向写散。AVX-512 有 8 个 64 位掩码；SVE 用谓词寄存器。

## 三、形式化 / 数学基础

掩码向量加法：

$$c_i = (mask_i) ? a_i + b_i : c_i$$

gather：$v_i = mem[base + idx_i \times scale]$，scatter 反之。每通道独立地址，需多端口或串行。

## 四、代码实现

```c
// AVX-512 掩码加：只更新 mask 为1的通道
__mmask8 m = _mm512_cmplt_ps_mask(a, thr);
__m512 r = _mm512_mask_add_ps(zero, m, a, b);
```

## 五、与其他技术对比

- 掩码替代分支，减少误预测；但全掩为 0 仍耗算力。
- gather 比连续 load 慢，因多地址转换。

## 六、常见误区

- 误以为 gather 与 load 同速：地址分散需多次访存。
- 忽视全掩无效通道的浪费。

- CSAPP 中文笔记：https://github.com/Hansimov/csapp

## 八、面试题

- 掩码 SIMD 优势？答：谓词化消除分支与误预测。
- gather 为何慢？答：非连续地址，多次 TLB/缓存访问。

## 九、演进与趋势

可伸缩谓词(SVE)与更宽掩码普及，减少数据重排。

## 十、小结

掩码与收集散布让 SIMD 处理不规则数据，是通用向量化的关键补充。
