# 状压 DP 优化与轮廓线 DP

> 对应 刘汝佳《算法竞赛入门经典：训练指南》插头 DP 章节、李煜东《算法竞赛进阶指南》轮廓线 DP，以及 Z. A. 最小表示法/括号表示法在连通性问题中的经典应用。

## 一、背景与挑战

当铺砖、棋盘连通性、路径覆盖等问题升级到"需要记录连通关系"时，普通的位掩码就不够用了：不仅要知道哪些格子被占用，还要知道**哪些被占用的格子彼此连通**——因为最终往往要求"所有插头连成一块"或"恰好形成一条回路"。这类问题统一归入**插头 DP / 轮廓线 DP**，是状压 DP 的最高阶形态。

朴素做法为什么不行？若把整张棋盘的连通状态用并查集快照表示，状态数是指数且无法哈希合并；若回溯搜索加剪枝，$8\times 8$ 的哈密顿回路计数问题（经典"带插头的回路"）已经超出实用范围。关键是：连通性信息中，真正影响未来决策的只有**轮廓线上那些伸出的插头之间的配对/连通关系**，内部已经封闭的连通块完全不必记录。把这条信息压进一个整数，就得到了轮廓线连通性状态。

在竞赛里，插头 DP 是 NOI/省选级难题的常客（如"棋盘回路计数""周游世界"）；在面试里，它出现频率较低，但一旦出现就是区分度极高的一问——面试官想看你能否把"连通性"也压缩成状态，并正确地合并/分裂连通块。工程上，它对应 VLSI 布线可行性、迷宫回路生成、城市管网连通方案计数。

## 二、核心原理

**轮廓线与插头。** 沿行优先顺序推进到格子 $(i,j)$ 时，轮廓线是"已决策格子"与"未决策格子"的分界。轮廓线上的每个边界若与一个已放连通块相邻，就称该处有一个**插头**。决策当前格时，新骨牌/新边会与上、左方向的插头连接，从而合并或延长连通块。

**括号表示法（最小表示法的前身）。** 对轮廓线上的插头从左到右编码。若只要求"连通性类型"而不关心具体编号，可用：

- `0` 表示该处无插头；
- `(` / `1` 表示某连通块向左伸出的"左端"；
- `)` / `2` 表示对应的"右端"。

关键不变量：在合法回路问题中，轮廓线上插头的连通关系构成**不相交的匹配**（每个连通块在轮廓线上恰好露头两次，成对匹配），因此编码是一个合法括号序列。转移时，当前格把左插头与上插头配对（相当于连接 `(` 与 `)`），会改变括号匹配结构——这正是需要"括号序列编辑"的地方。

**最小表示法。** 若连通块个数不定且不是简单匹配（例如允许连通块露头一次），则用最小表示法：把轮廓线上各插头所属的连通块重新编号为 $1,2,3,\dots$，按首次出现顺序赋号，保证同一连通结构的编码唯一。合并两个连通块时，把编号较大的全部改写成较小的，维护唯一性。

**转移类型（以回路覆盖为例）。** 决策当前格 $(i,j)$：

1. **不放**：要求上、左插头都不存在，状态不变。
2. **新建连通块**：上、左都无插头时，可向下、向右各伸一个插头，引入新的匹配对。
3. **连接上/左**：只有一个插头时，转弯延长连通块。
4. **合并**：上、左都有插头时，把两个（可能是同块或不同块的）插头连起来；若恰好把一条路径的两端闭合，则形成回路/连通块封口。

**为什么要括号序列。** 回路问题中"每个连通块在轮廓线上露头两次"保证了括号配对结构，于是状态数从 $3^m$ 的最小表示降为卡特兰级的合法括号数（约 $C_m \cdot 2^m$ 的更小组合），且可以 O(1) 地做单点修改维护匹配。

**边界条件。** 第一行上插头只能由本行生成；最后一行/最后一列禁止再向下/向右伸出；最终答案要求轮廓线上无任何插头（全部封口），或恰好一个连通块（视题意）。

## 三、形式化与数学基础

**状态数上界。** 轮廓线长 $m$，每位 $0/1/2$ 三态时上界 $3^m$；但合法括号序列数是卡特兰数

$$
C_{m/2} = \frac{1}{m/2+1}\binom{m}{m/2} \approx \frac{4^{m/2}}{m^{3/2}\sqrt{\pi}}.
$$

对 $m=12$，$3^{12}=531441$，而合法括号状态约 $C_6=132$ 量级（含空位选择后仍远小于 $3^m$），这是括号表示法的本质优势。

**转移复杂度。** 逐格递推，$O(nm)$ 个格子，每格枚举当前状态并做 $O(1)\sim O(m)$ 的括号编辑，总复杂度

$$
T = O(nm \cdot S), \quad S = O(\text{合法括号状态数}) \subseteq O(3^m).
$$

实际 $m\le 12$ 时完全可跑。

**最小表示法的正确性引理。** 两个轮廓线连通结构同构当且仅当它们的最小表示编码相同。证明：最小表示按首次出现顺序重标号，相当于对连通块标号做规范化（canonical form）；连通关系是等价关系，标号置换不改变连通性，故规范化后唯一。

**括号匹配的维护。** 当前格合并左插头 `(` 与上插头 `)` 时，等价于把括号序列中的一对匹配点连成内部通道，需要找到与左插头匹配的右括号位置并整体修改。用栈预处理每个 `(` 的匹配位置，可在 $O(1)$ 取得配对对象，转移 $O(1)$。

**与并查集的对照。** 若状态里塞并查集，哈希与去重都困难；括号/最小表示把连通性变成**可哈希的整数/字符串**，DP 表可以是 `dict` 或直接映射到整数。

## 四、代码实现

下面给出两份可运行代码：（1）最小表示法工具；（2）完整插头 DP——统计 $n\times m$ 网格上**每格度数恰为 2 的不相交回路覆盖**（2-因子）个数。后者已用小棋盘暴力对拍验证。

```python
# 最小表示法 + 插头 DP：网格不相交回路覆盖计数
from collections import defaultdict


def normalize(labels):
    """把连通块编号规范为最小表示：按首次出现给 1,2,3,...；0 表示无插头。"""
    mp, nxt = {}, 1
    out = []
    for x in labels:
        if x == 0:
            out.append(0)
        else:
            if x not in mp:
                mp[x] = nxt
                nxt += 1
            out.append(mp[x])
    return tuple(out)


def cycle_covers(n, m):
    """
    统计 n×m 网格图的不相交回路覆盖数：每条边属于某回路，每格度数恰为 2。
    状态 = (left, p0, p1, ..., p_{m-1})：
      left     —— 当前格左侧伸来的插头所属连通块编号
      p[j]     —— 列 j 上方伸下来的插头所属连通块编号
      0        —— 该处无插头
    转移枚举当前格连通的两条边（恰好两条，保证度数为 2）。
    """
    dp = {(0,) + (0,) * m: 1}
    for i in range(n):
        for j in range(m):
            nd = defaultdict(int)
            for st, ways in dp.items():
                left = st[0]
                prof = list(st[1:])
                top = prof[j]
                # 六种度数-2 局部配对
                for need in (
                    {"U", "D"}, {"U", "L"}, {"U", "R"},
                    {"D", "L"}, {"D", "R"}, {"L", "R"},
                ):
                    # 边界：棋盘外不能伸插头
                    if "U" in need and i == 0:
                        continue
                    if "D" in need and i == n - 1:
                        continue
                    if "L" in need and j == 0:
                        continue
                    if "R" in need and j == m - 1:
                        continue
                    # 已有插头必须被用上，没有插头不能凭空用
                    if ("U" in need) != (top != 0):
                        continue
                    if ("L" in need) != (left != 0):
                        continue

                    nleft = 0
                    nprof = prof[:]
                    nprof[j] = 0  # 上插头/本格竖插头先清掉

                    if need == {"U", "D"}:
                        nprof[j] = top               # 竖穿，连通块下延
                    elif need == {"L", "R"}:
                        nleft = left                 # 横穿，连通块右延
                    elif need == {"U", "L"}:
                        if top == left:
                            # 闭合一条回路：对回路覆盖合法（每块自成回路）
                            nleft = 0
                        else:
                            t, s = min(top, left), max(top, left)
                            nprof = [t if x == s else x for x in nprof]  # 合并两块
                            nleft = 0
                    elif need == {"U", "R"}:
                        nleft = top                  # 右上拐角
                    elif need == {"D", "L"}:
                        nprof[j] = left              # 左下拐角
                    elif need == {"D", "R"}:
                        nid = max(nprof + [nleft]) + 1  # 新建连通块
                        nprof[j] = nid
                        nleft = nid

                    key = normalize([nleft] + nprof)
                    nd[key] += ways
            dp = nd
    # 收尾：轮廓线必须无残留插头（所有回路已闭合）
    return dp.get((0,) + (0,) * m, 0)


if __name__ == "__main__":
    # 与暴力对拍一致的取值
    assert cycle_covers(2, 2) == 1
    assert cycle_covers(2, 3) == 1
    assert cycle_covers(2, 4) == 2
    assert cycle_covers(3, 3) == 0
    assert cycle_covers(3, 4) == 3
    assert cycle_covers(4, 4) == 18
    print("plug-dp ok", cycle_covers(2, 5), cycle_covers(4, 5))
```

要点有三。其一，状态用最小表示法规范化，保证同构连通结构只占一个 DP 槽位。其二，每格恰选两条边，自然保证"每格度数 2"，不必额外判断。其三，`top == left` 的 U-L 配对闭合一条回路：对**回路覆盖**合法；若题目要求**单一哈密顿回路**，则必须禁止在非终点提前闭合，只允许最后一步封口。

若只要覆盖计数（不要求度数 2），上一篇的 `mondrian`/轮廓线铺砖更简单；本骨架专用于连通性。

## 五、与其他技术对比

| 技术 | 状态 | 复杂度 | 能否处理连通性 | 难点 |
|------|------|--------|----------------|------|
| 普通状压 | 位掩码 | $O(n2^n)$ | 否 | 低 |
| 轮廓线铺砖 | 位掩码尾巴 | $O(nm2^m)$ | 否 | 中 |
| 插头 DP + 括号表示 | 合法括号序列 | $O(nm\cdot C_m)$ | 是（回路） | 高 |
| 插头 DP + 最小表示法 | 连通块编号元组 | $O(nm\cdot 3^m)$ | 是（一般连通） | 高 |
| 并查集快照 + 搜索 | 隐式 | 指数 | 是 | 中，难去重 |

取舍：只要计数覆盖用轮廓线铺砖；要连通块/回路必须插头 DP；回路且轮廓线不相交匹配时优先括号表示（状态更少），一般连通用最小表示法。

## 六、常见误区

1. **把连通性当成普通位掩码。** 后果：无法区分"两个不相连的插头"与"同一连通块的两个端点"，合并/分裂转移全错。必须引入括号或最小表示。
2. **括号序列不平衡仍入队。** 转移后必须校验括号合法性（`bal` 全程非负且最终为 0），否则状态含非法匹配，答案膨胀。
3. **合并时忘记最小表示规范化。** 若不重标号，同一连通结构会有多种编号写法，状态爆炸且重复计数。
4. **边界仍向下/右伸出插头。** 最后一行 `D`、最后一列 `R` 必须禁止；最终轮廓线必须全 0（或按题意恰好一块）。漏掉会把越界铺法算进答案。
5. **提前闭合小圈不处理。** 哈密顿回路问题中，若 `top` 与 `left` 属于同一连通块却在非终点合并，会形成一个小圈而不是整体回路，必须丢弃或单独处理（除非题目允许多个回路）。

## 八、面试题

**1. 为什么计数连通性时不能只用 0/1 位掩码？**
参考答案：0/1 只能表示"是否被占"，无法区分两个插头是否属于同一连通块，也就无法正确处理合并/分裂。必须记录连通块编号（最小表示）或匹配结构（括号序列）。

**2. 括号表示法的状态数比 $3^m$ 小在哪里？**
参考答案：合法括号序列受平衡约束，数量是卡特兰级 $C_{m/2}$，远小于 $3^m$；且配对结构可用栈 $O(1)$ 维护，转移更便宜。

**3. 最小表示法为什么能保证状态唯一？**
参考答案：按首次出现顺序重标号，相当于对连通块标号取规范形；同构连通结构必得到相同编码，从而状态可去重、可哈希。

**4. 哈密顿回路插头 DP 为什么要禁止 top 与 left 同块合并？**
参考答案：那会闭合出一个不经过所有格子的小圈，与"单一哈密顿回路"矛盾。必须丢弃该转移（除非题目允许多回路）。

## 九、演进与趋势

插头 DP 的后续演进：**带权连通**（边权求和，DP 值改 max/min）、**多回路/生成树计数**（状态允许未闭合）、**与最小生成树状压结合**（Dreyfus-Wagner、子集斯坦纳树）、**大棋盘近似**（蒙特卡洛、转移矩阵）。工程上，PCB/IC 布线可行性检查、管网连通方案、迷宫与游戏地图的回路生成都用到同一思想；面试趋势是连通性压缩（最小表示/括号）与"为什么普通位掩码不够"的追问，深度编码题多出现在算法竞赛而非普通面试。

## 十、小结

轮廓线/插头 DP 是状压 DP 处理连通性的终极形态：用括号表示法压缩回路匹配、用最小表示法压缩连通块编号，把指数连通状态收敛到可哈希的规范编码，并在 $O(nm\cdot S)$ 内完成精确计数；掌握状态规范形、合并/分裂转移与小圈边界，才算真正通关状态压缩。
