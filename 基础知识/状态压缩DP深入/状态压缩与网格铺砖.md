# 状态压缩与网格铺砖

> 对应 youngyangyang04/leetcode-master 状态压缩（铺砖/骨牌）与 Bellman 1962 DP 原理。

## 一、背景与挑战
用 1×2 骨牌铺满 m×n 棋盘，求方案数。当 m 较小（≤ 11）可把每列状态压成整数，逐列 DP。

## 二、核心原理
以列为阶段，状态为该列每行被"上方骨牌延伸下来"的占位掩码。枚举当前列摆放方式，推出下一列占位。

## 三、形式化与数学基础
`dp[col][mask]` 表示前 col 列铺完且第 col 列延伸占位为 mask 的方案数。转移：对合法摆放 $p$，$dp[col+1][next]=dp[col][mask]+...$。

## 四、代码实现
```python
def domino_tiling(m, n):
    # m 行(<=11), n 列；逐列 DP
    N = 1 << m
    dp = [0] * N
    dp[0] = 1
    for _ in range(n):
        ndp = [0] * N
        for mask in range(N):
            if dp[mask] == 0:
                continue
            # 枚举当前列摆放（简化：横放用 DFS 生成 next）
            for nxt in compatible(mask, m):
                ndp[nxt] += dp[mask]
        dp = ndp
    return dp[0]

def compatible(mask, m):
    # 占位 mask 下，当前列可生成的所有下一列占位（示意）
    res = [0]
    # 实际需 DFS 填充竖放/横放，此处返回占位为 0 的平凡解示意
    return res
```

## 五、与其他技术对比
轮廓线 DP 处理更大约束；状压按列适合 m 小 n 大。行列式法（Kasteleyn）可 $O(n\log n)$ 求总方案。

## 六、常见误区
- m 太大导致 $2^m$ 爆炸（应 m ≤ 11）。
- 横放骨牌需同时占两列，转移易漏。

## 七、与开源书/权威来源对应

## 九、演进与趋势
轮廓线 DP（插头 DP）把状态压缩到"轮廓线"，处理更一般连通性铺砖。

## 十、小结
网格铺砖用列占位掩码做状压 DP，适合窄棋盘，转移需枚举摆放。
