# 蒙德里安的梦想类铺砖

> 对应 youngyangyang04/leetcode-master 状态压缩（蒙德里安的梦想）与 Bellman 1962 DP 原理。

## 一、背景与挑战
用 1×2 骨牌恰好铺满给定矩形，求方案数（经典"蒙德里安的梦想"）。需保证横放/竖放不冲突且全覆盖。

## 二、核心原理
逐列扫描，用占位掩码表示"上一列伸下来的竖放骨牌"。对当前列空位，要么被上一列竖放占据，要么在本列新放竖放/横放，必须填满。

## 三、形式化与数学基础
`dp[col][mask]`：前 col 列合法且第 col 列伸出占位为 mask 的方案数。合法摆放需当前列被完全覆盖（无孤立空格）。转移 sum 到 `next`。

## 四、代码实现
```python
def mondrian(n, m):
    # n 行 m 列
    N = 1 << n
    dp = [0] * N
    dp[0] = 1
    for _ in range(m):
        ndp = [0] * N
        for mask in range(N):
            if dp[mask] == 0:
                continue
            for nxt in legal_next(mask, n):
                ndp[nxt] += dp[mask]
        dp = ndp
    return dp[0]

def legal_next(mask, n):
    # 对给定上一列占位 mask，DFS 填满当前列，返回所有下一列占位
    res = []
    def dfs(col_bit, cur, nxt):
        if col_bit == n:
            res.append(nxt)
            return
        if (mask >> col_bit) & 1:
            dfs(col_bit + 1, cur, nxt)          # 已被占，跳过
        else:
            dfs(col_bit + 1, cur, nxt)          # 竖放：延伸占位
            if col_bit + 1 < n and not (mask >> (col_bit+1)) & 1:
                dfs(col_bit + 2, cur, nxt)      # 横放：占两行
    dfs(0, 0, 0)
    return res
```

## 五、与其他技术对比
行列互换可让较小维度作状态维；插头 DP 处理带障碍/非矩形。

## 六、常见误区
- 横放应占"同一列相邻两行"，不是两列。
- 未保证当前列所有空格被覆盖就转移。
