# 蒙德里安的梦想类铺砖

> 对应 李煜东《算法竞赛进阶指南》经典例题「蒙德里安的梦想」，以及 P. Kasteleyn 关于格点图完美匹配计数的理论基础。

## 一、背景与挑战

「蒙德里安的梦想」是一道经典的网格状压题：给定 $n \times m$ 的棋盘（通常 $n \le 11$，$m \le 11$，或一维很长），用 $1 \times 2$ 的骨牌（横放或竖放）铺满整个棋盘，求方案数。它得名于荷兰画家蒙德里安（Piet Mondrian）的几何分割风格，但问题本质是**格点图的完美匹配计数**，是轮廓线/逐行状压 DP 的标准练手题。

为什么朴素做法不行？直接 DFS 逐格放骨牌，状态是整张棋盘的占用情况，最坏 $O(2^{nm})$；$n=m=10$ 时完全不可行。更关键的是，铺砖具有**行之间的局部依赖**：决定某一行怎么放时，只需要知道上一行"哪些列还伸出竖放骨牌的尾巴"，不需要知道上一行内部的横向排布细节。若不把"尾巴集合"压成位掩码并设计行间转移，就写不出多项式（对 $m$ 是线性、对 $n$ 是指数）的算法。

在面试与竞赛中，「蒙德里安的梦想」是状压 DP 的"成人礼"：它要求把"局部占用信息"压进 mask、写出行间兼容转移、并处理好边界（最后一行只能消化尾巴）。它的变体——加障碍、加权、允许 L 形三格骨牌、要求连通——频繁出现在 NOI/省选与 LeetCode 竞赛里。工程上，这类"用小块拼满矩形"的问题对应地板/瓷砖铺设、FPGA 资源布局、版面分割的方案计数。

## 二、核心原理

**核心观察：先横后竖。** 骨牌只有两种放法。我们可以约定：**先考虑所有横向骨牌的摆放，再自动补齐竖向骨牌**。理由是：一旦所有横向骨牌位置确定，每一列上未被横向覆盖的格子必然成对地由竖向骨牌补齐（否则无解）。因此方案可以按"每一行的横向占位模式"来枚举。

**行状态与兼容性。** 对第 $i$ 行，用 $m$ 位掩码 `state` 表示该行哪些格子被横向骨牌覆盖（1 表示被本行横放骨牌占住）。合法的 `state` 必须满足：**不包含相邻的 1**？不对——横向骨牌占两个连续格，因此 `state` 中 1 的分布必须由若干不相交的"连续两个 1"组成。换言之，`state` 的二进制表示中，所有 1 必须两两成对且相邻，且对之间不重叠。用预处理枚举所有合法 `state`（$m \le 11$ 时只有几十种）。

**行间兼容。** 设第 $i$ 行状态为 `s1`，第 $i+1$ 行为 `s2`。竖向骨牌连接 $(i,j)$ 与 $(i+1,j)$。约束是：对每一列 $j$，$(i,j)$ 与 $(i+1,j)$ 不能同时被各自的横向骨牌占住——否则该列没有空间放竖牌，且两横牌冲突。更准确的兼容条件需要结合"上一行未覆盖竖牌的位置"。

**经典「蒙德里安」的精确模型（只放 1×2，横竖皆可）。** 按行推进时，状态记录的是**当前行的哪些列已经被"上一行伸下来的竖放骨牌"占住**。对每行枚举"本行横放骨牌的占位" `cur`（合法成对连续 1），然后：

- 上一行伸下来的位（`mask` 中为 1 的列）在本行被占住，不能再放横牌；
- 本行未被 `cur` 覆盖、也未被 `mask` 占住的列，必须向下伸竖牌（这些列在下一行的 `mask` 中为 1）。

于是转移是：`next_mask = (~(mask | cur)) & ((1<<m)-1)`，并且要求 `mask` 与 `cur` 不冲突。最后一行 `next_mask` 必须为 0（不能伸出棋盘）。

**为什么正确。** 不变量：`mask` 恰好表示"需要在当前行被竖牌上端覆盖的列集合"。每行决策（横放占位 + 哪些列向下伸）是完备且不重叠的；任何合法铺砖都可以唯一分解为逐行决策序列，反之亦然。DP 对行数做归纳，计数正确。

**边界与预处理。** 第 0 行的 `mask=0`（上方没有尾巴）；枚举 `cur` 时要求 `cur & mask == 0` 且 `cur` 是合法横放占位。$m \le 11$ 时合法 `cur` 至多约 $F_{m}$（斐波那契级）几十种，可以预处理成列表加速。

**面积奇偶性。** 若 $n m$ 为奇数，方案数为 0，可直接剪掉。

## 三、形式化与数学基础

**合法横放占位数。** 设 $m$ 列的合法 `cur` 数为 $g(m)$。每个 `cur` 由若干长度为 2 的"横牌"与长度为 1 的"空（留给竖牌）"拼成，但空位必须被竖牌或上下行消化，因此实际上 `cur` 是把 $m$ 个位置划分成若干"11"（横牌）与若干"0"（竖牌通道）。递推：

$$
g(0)=1,\quad g(1)=1,\quad g(m) = g(m-2) + g(m-1),
$$

即斐波那契数列（$m=11$ 时 $g=144$ 量级，含全 0）。预处理所有合法 `cur` 的复杂度 $O(g(m)\cdot m)$。

**行间 DP。** 设 $f[i][mask]$ 为处理完前 $i$ 行、当前"伸出到第 $i+1$ 行"的列集合为 `mask` 的方案数。转移：

$$
f[i+1][next] = \sum_{\substack{cur\ \text{合法}\\ cur\,\&\, mask = 0 \\ next = \overline{mask \cup cur}}} f[i][mask].
$$

其中补集限定在 $m$ 位内。最终答案 $f[n][0]$。

**复杂度。** 行数 $n$，每行枚举 $g(m)$ 个 `cur`，状态数 $2^m$，故

$$
T = O(n \cdot g(m) \cdot 2^m), \quad S = O(2^m).
$$

$m=11$ 时 $2^{11}=2048$，$g\approx 144$，$n=11$，约 $3\times 10^6$ 次转移，非常快。注意这里比一般轮廓线 DP 的 $O(nm 2^m)$ 还少一个 $m$，因为 `cur` 预处理把"逐格放横牌"合并了。

**与完美匹配的关系。** $n\times m$ 网格图的完美匹配数 = 该棋盘 $1\times 2$ 骨牌铺法数。对 $2\times m$，答案是斐波那契 $F_{m+1}$；对 $m=1,2$ 等小情形可直接手算验证 DP。

**矩阵加速（进阶）。** 当 $n$ 很大（如 $10^9$）而 $m$ 固定很小，转移与 $i$ 无关，可把 $f[i]$ 看成向量、转移写成 $2^m \times 2^m$ 矩阵，用矩阵快速幂做到 $O(8^m \log n)$（实际只对合法状态子集做 $O(g(m)^3 \log n)$）。这是「蒙德里安」的标准进阶考点。

## 四、代码实现

完整可运行：求 $n\times m$ 棋盘 $1\times 2$ 骨牌铺法数（蒙德里安梦想经典版）。

```python
# 蒙德里安的梦想：n 行 m 列，1x2 骨牌铺满的方案数
# 状态 mask：需要在本行被"上一行伸下来的竖牌"占住的列集合。


def legal_rows(m):
    """枚举一行内合法的横放占位 cur（不相交的连续两个 1，其余为 0）。"""
    res = []

    def dfs(col, cur):
        if col >= m:
            res.append(cur)
            return
        # 该列不放横牌（留给竖牌）
        dfs(col + 1, cur)
        # 该列与下一列放横牌
        if col + 1 < m:
            dfs(col + 2, cur | (3 << col))

    dfs(0, 0)
    return res


def mondrian(n, m):
    """返回 n×m 棋盘 1x2 骨牌铺满方案数（Python 任意精度）。"""
    if (n * m) % 2 == 1:
        return 0
    # 让状态位数尽量小
    if n < m:
        n, m = m, n
    rows = legal_rows(m)
    full = (1 << m) - 1
    from collections import defaultdict
    dp = defaultdict(int)
    dp[0] = 1
    for _ in range(n):
        ndp = defaultdict(int)
        for mask, ways in dp.items():
            for cur in rows:
                if cur & mask:          # 冲突：竖牌与横牌撞车
                    continue
                nxt = (~(mask | cur)) & full   # 剩下的列向下伸竖牌
                ndp[nxt] += ways
        dp = ndp
    return dp[0]


if __name__ == '__main__':
    # 2×n 应为斐波那契
    assert mondrian(2, 2) == 2
    assert mondrian(2, 3) == 3
    assert mondrian(2, 4) == 5
    assert mondrian(2, 5) == 8
    # 3×4 = 11，4×4 = 36（经典值）
    assert mondrian(3, 4) == 11
    assert mondrian(4, 4) == 36
    assert mondrian(3, 3) == 0   # 面积 9 奇数
    print('mondrian ok', mondrian(6, 6), mondrian(8, 8))
```

若需要加速（状态数很大时），可把 `dp` 换成定长列表，并预处理每个 `mask` 的可行 `(cur, nxt)` 转移表：

```python
def precompute_trans(m):
    rows = legal_rows(m)
    full = (1 << m) - 1
    trans = [[] for _ in range(1 << m)]
    for mask in range(1 << m):
        for cur in rows:
            if cur & mask:
                continue
            nxt = (~(mask | cur)) & full
            trans[mask].append(nxt)
    return trans
```

复杂度 $O(n \cdot |trans|)$，比每行重算快一个常数。

## 五、与其他技术对比

| 方法 | 时间 | 备注 |
|------|------|------|
| 逐行状压（本篇） | $O(n\, g(m)\, 2^m)$ | 蒙德里安标准解 |
| 逐格轮廓线 DP | $O(nm\, 2^m)$ | 通用，支持任意骨牌 |
| 生成函数 / 特征多项式 | $O(m^3 \log n)$ | $n$ 巨大时矩阵快速幂 |
| Kasteleyn Pfaffian | $O((nm)^3)$ | 无障碍大棋盘计数 |
| DFS + 剪枝 | 指数 | 仅验证小数据 |

取舍：固定小宽度、大行数用矩阵快速幂；通用骨牌/障碍用逐格轮廓线；标准蒙德里安用逐行横放占位最简洁。

## 六、常见误区

1. **把"合法横放占位"理解成"任意无相邻 1"。** 横牌占两格，占位必须是成对相邻的 1，不是任意独立集。预处理写错，方案数立刻不对。
2. **最后一行忘记要求 `nxt == 0`。** 若仍允许伸出竖牌，会把越界铺法算进去，答案偏大。正确做法是取 `dp[0]` 作为答案，或最后一步只保留 `mask==0` 的转移。
3. **`n < m` 时交换了行列却没换状态位数语义。** 状态位是"列"，交换后 `m` 变成较小者，代码里 `full` 与 `legal_rows` 的参数必须一致用新的 `m`。
4. **面积奇偶不判断。** $nm$ 为奇数直接 0；不判断会在大输入上白跑 DP。
5. **忽略横放占位与 mask 的冲突检查 `cur & mask`。** 漏掉这个 `if`，会允许横牌覆盖已经被竖牌上端占住的格子，结果必然偏大。

## 八、面试题

**1. 请说明「蒙德里安的梦想」的状态定义与转移，并给出复杂度。**
参考答案：`mask` 表示需要在本行被上一行竖牌占住的列集合；枚举本行合法横放占位 `cur`（不相交连续两个 1），要求 `cur & mask == 0`，下一行状态 `nxt = ~(mask|cur) & full`。答案为 $n$ 行后 `mask==0` 的方案数。时间 $O(n\, g(m)\, 2^m)$，空间 $O(2^m)$。

**2. 为什么可以"先枚举横放、竖放自动补齐"？**
参考答案：横放位置一旦确定，每列剩余未覆盖格子必须成对由竖放补齐，否则无解；因此竖放不引入额外自由度，只需保证列方向可配对（这由 mask 转移的合法性自动保证）。

**3. $n=2, m=k$ 时答案是什么？如何用它测试代码？**
参考答案：斐波那契 $F_{k+1}$（$F_1=1,F_2=2,\dots$ 或按约定 $1,2,3,5,8$）。$2\times 2=2$，$2\times 3=3$，$2\times 4=5$，可作为单元测试。

**4. 若 $n=10^9, m=8$，怎么办？**
参考答案：转移与行号无关，把 $f$ 看成 $2^m$ 维向量，构造转移矩阵做矩阵快速幂，时间 $O(8^m \log n)$ 或对合法状态子集 $O(g(m)^3\log n)$。

## 九、演进与趋势

「蒙德里安」之后的常见演进：**矩阵快速幂**求超大 $n$；**加障碍格**（必须转轮廓线逐格 DP）；**允许 L 形三格骨牌**（状态要多记录一格"未配对形状"）；**带权铺砖**（每块骨牌有收益，DP 改 max）；**连通性铺砖**（要求所有骨牌构成连通块，要叠加括号表示法，升级到插头 DP）。工程应用中，版面分割、瓷砖铺设方案计数、FPGA 可布性分析都复用同一套"行间兼容 + 位掩码"的框架。面试趋势稳定在状态定义、转移合法性、$2\times n$ 斐波那契测试与矩阵快速幂追问四点。

## 十、小结

蒙德里安梦想类铺砖用"逐行横放占位 + 竖放尾巴 mask"把方案计数压成 $O(n\, g(m)\, 2^m)$ 的行间 DP；正确性建立在"横放定则竖放补"与 mask 不变量之上，边界要求最后一行无伸出。它是状压 DP 在网格上的经典范式，也是通向轮廓线、插头与矩阵加速的必经之路。
