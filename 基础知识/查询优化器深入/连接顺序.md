# 连接顺序

> 对应 Garcia-Molina《Database Systems: The Complete Book》16.3 连接枚举，以及 CMU 15-445 Join Ordering。

## 一、背景与挑战
$n$ 表连接的可能顺序与方式有阶乘级组合。糟糕的顺序产生巨量中间结果，因此连接顺序（join ordering）是优化器最关键的决策。

## 二、核心原理
基于关系代数等价变换（交换律、结合律）重组连接。常用启发式：先应用选择性高的单表谓词（减基数）、优先小结果集连接、限制为左深树以减小搜索空间。动态规划枚举最优子计划。

## 三、形式化 / 数学基础
左深树数量 $L(n) = \frac{(2n-2)!}{(n-1)!}$。动态规划：`opt(S) = min over s⊂S of cost(opt(s) join opt(S\s))`，复杂度 $O(3^n)$。

## 四、代码实现
```python
def best_join(rels):
    memo = {}
    def dp(subset):
        if len(subset) == 1: return cost(subset[0]), subset[0]
        if subset in memo: return memo[subset]
        best = min((dp(a)[0] + dp(b)[0] + join_cost(a,b), (a,b))
                   for a in splits(subset) for b in [subset-a])
        memo[subset] = best; return best
    return dp(frozenset(rels))
```

## 六、常见误区
1. 小表先连总最优——要看连接后基数而非原大小。
2. 顺序不影响结果——影响性能不影响正确性。
3. 动态规划总能枚举——大查询需剪枝。
