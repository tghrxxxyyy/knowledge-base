# 统计信息

> 对应 Silberschatz《Database System Concepts》13.5 统计与选择率，以及 PostgreSQL ANALYZE 文档。

## 一、背景与挑战
代价模型需要数据分布知识。无统计信息时只能按均匀分布猜测，导致错误计划（如对倾斜列误判选择率）。

## 二、核心原理
统计信息包括：表行数、页数和每列的最值、不同值数（NDV/n_distinct）、空值数，以及直方图（等高或等频）与最常见值（MCV）列表。ANALYZE 采样计算并存入系统目录。

## 三、形式化 / 数学基础
选择率估计 $\sigma = \frac{匹配行}{总行}$。等值谓词在均匀假设下 $\sigma \approx 1/NDV$。范围谓词用直方图桶高累加：$sel = \sum_{b \in range} height(b)$。多谓词独立假设 $\sigma = \prod \sigma_i$。

## 四、代码实现
```sql
-- 收集统计信息
ANALYZE orders;
-- 查看
SELECT attname, n_distinct, most_common_vals
FROM pg_stats WHERE tablename='orders';
```

## 五、与其他技术对比
| 统计 | 开销 | 精度 |
|------|------|------|
| 计数+NDV | 低 | 粗 |
| 直方图 | 中 | 中 |
| 采样近似 | 低 | 受偏斜影响 |

## 六、常见误区
1. 统计越细越好——采样与维护有成本。
2. 自动 ANALYZE 及时——大表可能滞后。
3. 独立假设总成立——相关列会高估/低估。

## 九、演进与趋势

## 十、小结
统计信息是代价模型的输入；直方图与 MCV 处理倾斜，采样控制开销，时效性决定计划质量。
