# 子类型与方差

> 对应 Pierce 第 15 章与 CS-Notes。

## 一、背景与挑战
子类型 $S<:T$ 支持"能用 T 的地方用 S"。方差描述复合类型随参数类型如何保持/反转子类型。挑战：函数类型方差、可变容器的不变性、型变标注。

## 二、核心原理
函数类型逆变参数、协变返回：若 $S_2<:S_1$ 且 $T_1<:T_2$，则 $S_1\to T_1 <: S_2\to T_2$。可变引用通常不变（写会破坏）。

## 三、形式化 / 数学基础
型变记号：$\tau$ 在 $\alpha$ 协变若 $\alpha_1<:\alpha_2\Rightarrow\tau[\alpha_1]<:\tau[\alpha_2]$。
函数：$\dfrac{S_2<:S_1\quad T_1<:T_2}{S_1\to T_1\ <:\ S_2\to T_2}$（参数逆变、结果协变）。

## 四、代码实现
```java
// 协变：生产者用 extends
List<? extends Number> nums = new ArrayList<Integer>();
// 逆变：消费者用 super
List<? super Integer> sink = new ArrayList<Number>();
sink.add(1); // OK
```

## 五、与其他技术对比
- 声明点型变（Scala/Kotlin `out`/`in`）：标注一次。
- 使用点型变（Java `? extends`/`? super`）：每处标注。
- 不变容器（Rust `Vec<T>`）：靠借用检查保证安全。

## 六、常见误区
1. 给可变容器标协变致堆污染。
2. 函数参数当协变（应为逆变）。
3. 混淆声明点/使用点型变。

## 九、演进与趋势
型变推断、流敏感类型（Kotlin 智能转换）、以及 Rust 生命周期即一种型变。

## 十、小结
子类型给出"可替换"语义，方差描述复合类型的替换方向；可变数据强制不变是安全的关键。
