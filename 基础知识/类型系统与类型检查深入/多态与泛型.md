# 多态与泛型

> 对应 Pierce 与 CS-Notes（Java 泛型 / C++ 模板）。

## 一、背景与挑战
多态让同一代码用于多类型。参数多态（泛型）与特设多态（重载）不同。挑战：类型擦除 vs 单态化、型变 (variance)、与子类型的交互。

## 二、核心原理
参数多态：$\forall\alpha.\ \alpha\to\alpha$（恒等函数）。子类型多态：$S<:T$ 时 $S$ 可代 $T$。泛型实例化在编译期单态化（C++/Rust）或运行期擦除（Java）。

## 三、形式化 / 数学基础
型变：$F$ 在参数协变若 $S<:T\Rightarrow F[S]<:F[T]$；逆变若反向；不变若都不。Java 数组协变是历史错误（运行期 `ArrayStoreException`）。

## 四、代码实现
```java
class Box<T> {
    T v;
    Box(T v) { this.v = v; }
}
// 擦除后 Box 的字段为 Object；桥方法保持重载
List<Integer> xs = new ArrayList<>();
// xs.add("s") 编译期即拒绝
```

## 五、与其他技术对比
- C++ 模板：单态化、零开销、代码膨胀。
- Rust 泛型：单态化 + trait bound。
- Java 泛型：类型擦除、只编译期检查、运行期无 `T`。

## 六、常见误区
1. 认为 Java `List<Integer>` 运行期能拿 `Integer.class`（擦除后无）。
2. 以为泛型数组安全（Java 禁止 `new T[]`）。
3. 混淆协变与不变导致堆污染。

## 十、小结
多态分参数与子类型两类；型变与擦除/单态化是工程实现的核心差别，理解它们避免堆污染与性能陷阱。
