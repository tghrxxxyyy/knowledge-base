# 单调队列与滑动窗口最大值

> 对应 youngyangyang04/leetcode-master 单调队列（滑动窗口最大值）与 CyC2018/CS-Notes。

## 一、背景与挑战
对每个长度为 $k$ 的窗口求最大值。暴力每窗扫描 $O(nk)$。单调队列 $O(n)$。

## 二、核心原理
维护一个单调递减双端队列（存下标）。入队时从尾弹出更小值（它们不可能成为后续最大值）；队首超出窗口则出队。

## 三、形式化与数学基础
队列保持"候选最大值"递减。窗口 $[i-k+1,i]$ 的最大值为队首。每元素进出队各一次，均摊 $O(1)$。

## 四、代码实现
```python
from collections import deque

def sliding_max(nums, k):
    dq = deque()
    res = []
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] <= x:
            dq.pop()
        dq.append(i)
        if dq[0] == i - k:
            dq.popleft()
        if i >= k - 1:
            res.append(nums[dq[0]])
    return res
```

## 五、与其他技术对比
堆（优先队列）可求最值但维护 $O(\log k)$ 且难去过期；单调队列 $O(1)$ 均摊且天然处理过期。

## 六、常见误区
- 队列存值不存下标，无法判过期。
- 比较用 `<` 还是 `<=` 影响稳定性，需一致。
