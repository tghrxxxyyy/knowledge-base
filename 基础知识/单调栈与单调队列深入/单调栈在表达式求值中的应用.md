# 单调栈在表达式求值中的应用

> 对应 youngyangyang04/leetcode-master 栈与单调栈（表达式求值/接雨水）与 Sedgewick《Algorithms》。

## 一、背景与挑战

表达式求值是编译器与计算器的核心子问题：给定 `"3+2*2"`、`" 2-1 + 2 "`、带括号的 `"1-(2+3)*4"`，算出数值。它同时是面试高频题（基本计算器 I/II/III、表达式求值、逆波兰表达式），也是工程中公式引擎、规则引擎、SQL 表达式、配置 DSL 的底层。朴素做法是递归下降，手写文法；或用两个栈（数字栈 + 运算符栈）按优先级与结合性逐步结算。难点在于运算符优先级、括号、一元负号、空格，以及「何时结算、结算几个操作数」的时机。

更深一层，表达式求值与「下一个更大元素」共享同一种思想：**当新元素（运算符/柱子）到来时，栈中那些「已被超越/已到边界」的中间结果需要结算弹出**。运算符优先级构成一种「单调性」：遇到优先级更低或相等的运算符，就先结算栈中优先级更高（或相等、且左结合）的运算符，再入栈。这就是「单调栈思想」在表达式求值中的映射——不是栈内元素值单调，而是**优先级单调**，弹栈时机由优先级决定。

接雨水、基本计算器、最大矩形都共享「弹栈结算」这一范式。面试官期待你能把表达式求值说成「优先级单调栈」，而不是孤立地背两个模板。本篇聚焦表达式求值的优先级单调栈实现，并用接雨水展示同一范式在几何问题上的映射。

## 二、核心原理

**表达式求值的双栈法**（Dijkstra Shunting Yard 的简化）：

- **数字栈** `nums`：存放操作数。
- **运算符栈** `ops`：存放运算符，栈中优先级**非严格递增**（或按左结合控制）。

处理规则：

1. 读到数字：解析完整整数，入数字栈。
2. 读到 `(`：直接入运算符栈，等待匹配的 `)`。
3. 读到 `)`：反复弹出运算符并结算，直到遇到 `(`，把 `(` 也弹出。
4. 读到运算符 `o`：当栈顶运算符优先级 $\ge$ 当前 $o$（左结合），先弹出栈顶结算，再把 $o$ 入栈。这样保证高优先级先算。
5. 末尾：清空运算符栈。

**为何这是「单调」**？定义优先级函数 $\mathrm{prio}(o)$，如 `+,-` 为 1，`*,/` 为 2。处理运算符 $o$ 时，弹出所有 $\mathrm{prio}(\text{top}) \ge \mathrm{prio}(o)$ 的栈顶，使栈中优先级随「等待时间」递增。这与单调栈「遇破坏者批量结算」完全同构：破坏者是「低优先级运算符」或「右括号」，结算对象是「优先级更高、尚未算完的运算符」。

**一元负号**：如 `1-(-2)`。遇到负号且前一个 token 是运算符、左括号或空，视为一元，可先 push 0 再减，或单独标记。**括号**：用「遇 `)` 弹到 `(`」实现子表达式隔离，括号内部可看作递归的子问题。

**接雨水（映射）**：单调递增栈遇更高柱时，弹出凹槽底结算水量。设弹出柱 $mid$，左边界 $left$，右边界 $i$，则
$$
\text{water} += (i - left - 1) \times (\min(h_{left}, h_i) - h_{mid}).
$$
这与表达式「遇低优先级结算高优先级」同构：破坏者是更高柱，结算的是被围住的凹槽。

不变量：
- 表达式：栈中运算符优先级非降，等待未来更低/右括号结算。
- 接雨水：栈中柱高非降，等待未来更高柱结算凹处。

边界条件：空表达式返回 0；连续运算符（一元）；除法取整方向（向零取整 vs 向负无穷）；括号不匹配；空格。

## 三、形式化与数学基础

**运算符优先级函数**：
$$
\mathrm{prio}(\text{+}) = \mathrm{prio}(\text{-}) = 1,\quad \mathrm{prio}(\text{*}) = \mathrm{prio}(\text{/}) = 2,\quad \mathrm{prio}(\text{(}) = 0.
$$
左结合：$\mathrm{prio}(\text{top}) \ge \mathrm{prio}(o)$ 时弹出。右结合（如幂 `^`）用严格 `>`。

**双栈正确性（递归/归纳）**。把表达式分解为项的加减，项内部为因子的乘除。数字栈始终保存「已算完的中间结果」，运算符栈保存「尚未结算的低层连接」。每一步结算都作用在最近的操作数上，符合结合性。括号内相当于子表达式独立计算，结果作为一个数字入栈。

**复杂度**。每个 token 处理 $O(1)$ 均摊，总 $O(n)$。栈深 $O(n)$（全是括号或递增优先级）。递归下降法也是 $O(n)$，但双栈无需递归栈。

**接雨水的公式推导**。弹出 $mid$ 时，左右两端 $left$、$i$ 的高度都 $> h_{mid}$，水柱高度受较矮一端限制：
$$
\text{water}_{mid} = (i - left - 1) \times \min(h_{left}, h_i) - (i - left - 1) \times h_{mid}.
$$
注意宽度不包含 $mid$ 自身柱体？实际包含 $mid$ 上方空间，宽度是左右边界间距减 1，即 $i - left - 1$。总水量累加各凹槽。

**均摊**：每个下标最多入栈 1 次、出栈至多 1 次，$O(n)$。这与 NGE 的摊还分析相同。

## 四、代码实现

表达式求值（支持 `+ - * /`、括号、空格、一元负号）与接雨水单调栈解法。

```python
def calculate(s: str) -> int:
    """基本计算器：支持 + - * / () 与空格，一元负号。"""
    def apply(a, b, op):
        if op == '+': return a + b
        if op == '-': return a - b
        if op == '*': return a * b
        if op == '/':
            # 向零取整
            return int(a / b)
        raise ValueError(op)

    def prio(op):
        return 1 if op in '+-' else 2 if op in '*/' else 0

    nums, ops = [], []
    i, n = 0, len(s)
    # 分词：数字 / 运算符 / 括号；一元负号折叠进数字或补 0-
    tokens = []
    j = 0
    while j < n:
        c = s[j]
        if c == ' ':
            j += 1
            continue
        if c.isdigit():
            k = j
            while k < n and s[k].isdigit():
                k += 1
            tokens.append(int(s[j:k]))
            j = k
            continue
        # 一元 +/-：前一 token 是运算符、'(' 或不存在
        if c in '+-' and (not tokens or (isinstance(tokens[-1], str) and tokens[-1] != ')')):
            k = j + 1
            while k < n and s[k] == ' ':
                k += 1
            if c == '-' and k < n and s[k].isdigit():
                # 折叠进数字：-2 -> -2
                m = k
                while m < n and s[m].isdigit():
                    m += 1
                tokens.append(-int(s[k:m]))
                j = m
            elif c == '-':
                # 后面是 '(' 或继续一元：补 0 与减号，等价 0-(...)
                tokens.append(0)
                tokens.append('-')
                j += 1
            else:
                # 一元 +：忽略
                j += 1
            continue
        tokens.append(c)
        j += 1

    for t in tokens:
        if isinstance(t, int):
            nums.append(t)
        elif t == '(':
            ops.append(t)
        elif t == ')':
            while ops and ops[-1] != '(':
                b, a, op = nums.pop(), nums.pop(), ops.pop()
                nums.append(apply(a, b, op))
            ops.pop()  # pop '('
        else:
            while ops and ops[-1] != '(' and prio(ops[-1]) >= prio(t):
                b, a, op = nums.pop(), nums.pop(), ops.pop()
                nums.append(apply(a, b, op))
            ops.append(t)

    while ops:
        b, a, op = nums.pop(), nums.pop(), ops.pop()
        nums.append(apply(a, b, op))
    return nums[-1] if nums else 0


def trap(height):
    """接雨水：单调递增栈，遇更高柱结算凹槽。"""
    stack = []
    water = 0
    for i, h in enumerate(height):
        while stack and h > height[stack[-1]]:
            mid = stack.pop()
            if not stack:
                break
            left = stack[-1]
            width = i - left - 1
            bounded = min(height[left], h) - height[mid]
            water += width * bounded
        stack.append(i)
    return water


if __name__ == "__main__":
    print(calculate("3+2*2"))          # 7
    print(calculate(" 2-1 + 2 "))     # 3
    print(calculate("1-(2+3)*4"))     # -19
    print(calculate("-(2+3)"))        # -5
    print(trap([0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]))  # 6
```

要点：优先级非降弹栈保证高优先级先算；括号用「弹到 `(`」；一元负号若后接数字则直接折叠为负数字面量（`1--2` 得 3），后接 `(` 则补 `0-` 等价改写；接雨水弹栈时必须检查栈空并用 `min(left, cur) - height[mid]`。

## 五、与其他技术对比

| 方法 | 时间 | 空间 | 特点 |
| --- | --- | --- | --- |
| 递归下降 | $O(n)$ | $O(n)$ 递归栈 | 语义清晰，易扩展文法 |
| 双栈（优先级单调） | $O(n)$ | $O(n)$ | 常数小，无递归 |
| Shunting Yard（输出 RPN） | $O(n)$ | $O(n)$ | 转后缀再算，解耦 |
| 逆波兰求值 | $O(n)$ | $O(n)$ | 工程常用两阶段 |
| 解析器生成器（ANTLR） | $O(n)$ | $O(n)$ | 适合完整文法 |

双栈适合「基本计算器」这类约束问题；递归下降与 ANTLR 适合完整语言；Shunting Yard 把解析与求值解耦，便于生成 AST。

## 六、常见误区

1. **弹栈后未检查栈空**（接雨水）：取 `stack[-1]` 越界。要 `if not stack: break`。
2. **忽略一元负号**：`"1-(-2)"` 会被当成二元减号少操作数。需在前一 token 为运算符/左括号/无时补 0 或标记一元。
3. **除法取整方向**：Python `//` 向负无穷，C++/Java 向零。跨语言移植易错，题目常要求向零。
4. **括号不匹配未处理**：`")("` 或缺右括号会让 `ops.pop()` 抛异常或错算。可预先校验括号平衡。
5. **优先级比较不考虑结合性**：幂运算右结合，若用 `>=` 会算成左结合。应区分左结合 `>=` 与右结合 `>`。

## 八、面试题

**1. 接雨水单调栈法与双指针法优劣？**
单调栈 $O(n)$ 单次扫描、$O(n)$ 空间，代码直观；双指针 $O(n)$、$O(1)$ 空间但需要左右最大值递推，思维稍绕。空间敏感用双指针，强调「弹栈结算」用单调栈。

**2. 单调栈如何用于基本计算器？**
把运算符优先级当作单调性：遇低优先级或右括号就结算栈中高优先级，形成优先级单调栈，支持 `+ - * /`、括号与一元负号。

**3. 表达式求值和接雨水的共同点？**
都是「破坏者到来时批量结算栈中等待者」：表达式破坏者是低优先级运算符/`)`，雨水破坏者是更高柱。共享不变量与均摊 $O(n)$。

**4. 如何扩展支持变量与 AST？**
把 Shunting Yard 的输出改为后缀表达式或 AST，再求值；或用递归下降构建 AST。优先级与结合性处理方式不变。

## 九、演进与趋势

表达式求值的双栈思想演化出完整的编译器前端：词法 → 语法分析（递归下降 / LR）→ AST → 求值。现代公式引擎（Excel、规则引擎、SQL 表达式、风控 DSL）都基于此。竞赛中，「基本计算器」系列（I/II/III/IV）考察括号、优先级、一元、函数调用、变量绑定，越来越贴近真实解析器。几何侧，「接雨水」「最大矩形」继续作为单调栈结算范式的代表。趋势是把单调栈思想与扫描线、离线查询、函数式变换结合，处理更复杂的区间结算问题。

## 十、小结

表达式求值的优先级单调栈与接雨水的凹槽单调栈，本质都是「破坏者到来时结算等待者」：优先级或高度构成单调性，弹栈时机即结算时机。掌握这一范式，表达式、几何、区间结算问题都能统一到单调栈的不变量与均摊 $O(n)$ 上。
