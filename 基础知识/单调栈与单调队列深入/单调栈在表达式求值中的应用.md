# 单调栈在表达式求值中的应用

> 对应 youngyangyang04/leetcode-master 栈与单调栈（接雨水/表达式）与 Sedgewick《Algorithms》。

## 一、背景与挑战
表达式求值与"接雨水"等问题需要按优先级/高度处理。单调栈帮助维护待结算的中间结果。

## 二、核心原理
- 表达式：用运算符栈 + 数字栈，遇低优先级先结算（类似单调处理）。
- 接雨水：单调递增栈，遇更高柱时结算凹处蓄水量。

## 三、形式化与数学基础
接雨水：对柱 $i$，左右更矮柱 $L,R$ 形成凹槽，水量 $\sum \min(h_L,h_R)-h_{mid}$。单调栈在弹栈时结算。

## 四、代码实现
```python
def trap(height):
    stack = []
    water = 0
    for i, h in enumerate(height):
        while stack and h > height[stack[-1]]:
            mid = stack.pop()
            if not stack:
                break
            left = stack[-1]
            width = i - left - 1
            bounded = min(height[left], h) - height[mid]
            water += width * bounded
        stack.append(i)
    return water
```

## 五、与其他技术对比
双指针（左右最大）也能 $O(n)$ 求雨水但需额外数组；单调栈单次扫描更紧凑。

## 六、常见误区
- 弹栈后未检查栈空直接取 `left` 会越界。
- 水量用 `min - mid` 而非与 `mid` 比较。
