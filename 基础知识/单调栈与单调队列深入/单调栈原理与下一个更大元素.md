# 单调栈原理与下一个更大元素

> 对应 youngyangyang04/leetcode-master 单调栈章节与 CyC2018/CS-Notes 题解。

## 一、背景与挑战

「下一个更大元素」是单调栈的标准入门题：给定数组，对每个位置 $i$ 找到右侧第一个比它大的元素。暴力做法是双重循环，对每个 $i$ 向右扫描，$O(n^2)$。当 $n$ 达到 $10^5$ 甚至 $10^6$（日志流、股票序列、传感器数据）时，平方级复杂度直接超时。更棘手的是，这类问题在面试和竞赛中极常见：温度序列、股票跨度、每日温度、下一个更大 I/II、柱状图最大矩形、接雨水、最大矩形……它们共享同一内核——**「右边第一个更大/更小」**。如果只会暴力，每道题都要重写一遍平方算法。

朴素优化的直觉是用哈希表缓存，但「右侧第一个」不是等价类关系，无法直接合并；用线段树、稀疏表可以查询区间最值，但要回答「第一个更大」仍需二分 + 区间查询，实现繁琐。单调栈给出惊人的简洁答案：一次扫描、每个元素至多进出栈一次，$O(n)$ 时间、$O(n)$ 空间。它的思想不只是「省掉一层循环」，而是引入了一个新的思考方式：**当元素还在栈里，说明它还没等到答案；新元素若能回答它们，就批量弹出结算**。

在算法体系里，单调栈是「线性结构 + 摊还分析 + 栈的惰性结算」的教科书范例；在工程里，它出现在流式计算（下一个高峰）、股票行情（新高/新低）、编译器局部优化（寄存器分配启发式）等场景。面试官常期望你说清三件事：单调性怎么维护、为什么是均摊 $O(1)$、以及如何变换出「左侧第一个」「循环数组」「更小元素」等变体。

## 二、核心原理

以「下一个更大元素」（Next Greater Element, NGE）为例，维护一个**单调递减栈**（栈底到栈顶递减），栈中存放**下标**（便于回填答案）。

处理 $a[i]$ 时：

1. **破坏者结算**：若栈非空且 $a[\text{stack.top()}] < a[i]$，则 $a[i]$ 就是栈顶元素「右侧第一个更大」——弹出栈顶，写入答案，重复直到栈空或栈顶元素 $\ge a[i]$。
2. **入栈**：把 $i$ 压入栈，等待未来的「破坏者」来回答它。

为什么弹出时一定是「第一个」更大？因为栈是递减的：栈顶是「离当前 $i$ 最近、且尚未被回答」的元素；它右侧到 $i$ 之间的元素都比它小（否则它早被弹出了）。所以 $a[i]$ 是它右侧第一个更大的。

不变量（Invariant）：
- 栈内元素的「下一个更大」都还没出现（它们都在等答案）。
- 栈内下标对应值递减：越靠近栈顶，值越小，离当前扫描位置越近。
- 每个下标只被 push 一次、pop 至多一次，因此总操作 $O(n)$。

边界条件：
- 遍历结束后，栈中残留元素没有右侧更大者，答案为 $-1$（或按题意处理）。
- 求「下一个更小」时，比较符号反过来：栈变递增，遇更小者结算。
- 求「左侧第一个」时，只需在扫描方向上反过来思考，或先反转数组再做 NGE。
- **循环数组**（如「下一个更大 II」）需要把数组虚拟拼接两遍，或下标取模，扫描 $2n$ 次但每个元素只真正入栈一次。

正确性核心：**弹栈的时机 = 答案出现的时刻**。单调性保证被弹出者不可能再等到更近的答案，也保证未来元素不会「误答」更早的元素。

## 三、形式化与数学基础

设数组 $a[0..n-1]$，定义 $nxt(i)$ 为最小的 $j>i$ 使得 $a[j]>a[i]$，若不存在则 $nxt(i)=-1$。

**栈的性质**。用 $S$ 表示栈（从底到顶），$val(S)$ 为对应值。不变量：
$$
val(S_0) > val(S_1) > \dots > val(S_{k-1}),
$$
其中 $S_0$ 是栈底。且任意 $S_k$，其右侧在栈内的元素值都比它小，右侧尚未扫描的元素都可能成为它的答案。

**正确性（归纳）**。处理 $a[i]$ 前，栈中元素是「尚未找到更大元素」的下标集合，且满足递减。弹栈时，$a[i] > a[\text{top}]$ 且 $a[i]$ 在 $\text{top}$ 右侧、中间无更大者（否则 top 早弹出），故 $a[i] = a[nxt(\text{top})]$。弹到不能弹后，把 $i$ 入栈，所有 $a[\text{top}] \ge a[i]$，递减性保持。遍历完后栈中元素 $nxt=-1$。

**复杂度**。每个下标入栈 1 次、出栈至多 1 次，while 总执行次数 $O(n)$，故均摊每步 $O(1)$，总时间 $O(n)$，空间 $O(n)$。注意是**均摊**：单步可能连续弹出 $k$ 个，但总弹出次数被 $n$ 限制。这与「快速排序均摊 $O(n\log n)$」类似，不能误认为最坏单步 $O(1)$。

**与暴力的递推对比**。暴力：
$$
T(n) = \sum_{i=0}^{n-1} O(n-i) = O(n^2).
$$
单调栈：
$$
T(n) = O(n) \text{（push）} + O(n) \text{（pop 总和）} = O(n).
$$
「把每个下标看成资源，消耗一次即完成」是摊还分析的经典图景。

**空间下界**。答案数组本身 $O(n)$，栈在最坏情况下（严格递减数组）也会存 $O(n)$ 个下标，故空间 $O(n)$ 是紧的。若只需「是否存在」布尔量，可以压缩；但标准实现保留答案数组。

## 四、代码实现

下面是标准「下一个更大元素」及其变体：右侧更大、右侧更小、左侧更大、循环数组版。

```python
def next_greater(nums):
    """每个元素右侧第一个更大元素，没有则 -1。单调递减栈（存下标）。"""
    n = len(nums)
    res = [-1] * n
    stack = []
    for i, x in enumerate(nums):
        while stack and nums[stack[-1]] < x:
            top = stack.pop()
            res[top] = x
        stack.append(i)
    return res


def next_smaller(nums):
    """每个元素右侧第一个更小元素。单调递增栈。"""
    n = len(nums)
    res = [-1] * n
    stack = []
    for i, x in enumerate(nums):
        while stack and nums[stack[-1]] > x:
            res[stack.pop()] = x
        stack.append(i)
    return res


def prev_greater(nums):
    """每个元素左侧第一个更大元素。"""
    n = len(nums)
    res = [-1] * n
    stack = []
    for i, x in enumerate(nums):
        while stack and nums[stack[-1]] <= x:
            stack.pop()
        res[i] = nums[stack[-1]] if stack else -1
        stack.append(i)
    return res


def next_greater_circular(nums):
    """循环数组的下一个更大：虚拟拼接两遍。"""
    n = len(nums)
    res = [-1] * n
    stack = []
    for i in range(2 * n):
        x = nums[i % n]
        while stack and nums[stack[-1]] < x:
            res[stack.pop()] = x
        if i < n:
            stack.append(i)
    return res


if __name__ == "__main__":
    a = [2, 1, 2, 4, 3]
    print("NGE :", next_greater(a))          # [4, 2, 4, -1, -1]
    print("NSE :", next_smaller(a))          # [1, -1, -1, 3, -1]
    print("Prev:", prev_greater(a))          # [-1, 2, -1, -1, 4]
    print("Circ:", next_greater_circular([1, 2, 1]))  # [2, -1, 2]
```

代码要点：栈存**下标**而非值，否则无法回填答案位置；比较符号决定递增/递减；循环数组版只在第一轮把下标入栈，第二轮只负责结算，避免重复下标。

## 五、与其他技术对比

| 方法 | 时间 | 空间 | 适用 |
| --- | --- | --- | --- |
| 暴力双循环 | $O(n^2)$ | $O(1)$ | $n \le 10^3$ |
| 单调栈 | $O(n)$ | $O(n)$ | 下一个更大/更小、矩形、雨水 |
| 线段树 / 稀疏表 | $O(n\log n)$ 预处理，$O(\log n)$ 查询 | $O(n\log n)$ | 区间最值、区间计数 |
| 平衡树 / 有序集合 | $O(n\log n)$ | $O(n)$ | 需要第 $k$ 大、插入删除 |
| 双指针 / 前后缀最大 | $O(n)$ | $O(n)$ 或 $O(1)$ | 接雨水、最大水量等特定题 |

单调栈胜在常数小、代码短、专用于「下一个更大/更小」这一族问题；需要任意区间查询时线段树更通用；需要插入删除动态维护时平衡树更合适。

## 六、常见误区

1. **栈存值不存下标**。返回的「更大元素的值」无法定位原下标，在需要输出下标（如每日温度间隔）时出错。
2. **比较符号写反**。求更大用 `<` 弹出（递减栈），求更小用 `>`（递增栈）。符号错会导致答案方向完全颠倒，且难调试。
3. **相等元素处理不当**。求「严格更大」时相等不弹；求「更大或相等」时要弹。题目要什么就是什么，不能想当然。
4. **循环数组忘记虚拟扩展**。只扫一遍会漏掉绕回后的更大元素，导致答案不完整。
5. **误以为单调栈是 $O(n\log n)$ 或最坏 $O(n)$ 单步**。它是均摊 $O(n)$；最坏单步可弹出 $O(n)$，但总弹出次数 $O(n)$。面试时说清「均摊」很加分。

## 八、面试题

**1. 如何用单调栈求「左侧第一个更小元素」？**
把比较改为「栈顶 $\ge$ 当前则弹」的递减栈，在当前元素入栈前读栈顶即为答案；或先反转数组做 NGE 再映射回来。

**2. 为什么每个元素最多进出栈一次？**
入栈一次是因为遍历只 push；出栈至多一次是因为出栈后不再入栈。故总操作 $O(n)$，均摊每步 $O(1)$。

**3. 单调栈和单调队列有什么区别？**
单调栈只在一端进出；单调队列两端进出，用于滑动窗口最值，需要队首过期出队。共同点是都维护单调性，用于「下一个/窗口最值」类问题。

**4. 请证明弹栈时得到的是「第一个」更大者。**
栈递减，栈顶右侧到当前 $i$ 之间元素都更小（否则早弹出），故 $a[i]$ 是栈顶右侧第一个更大的元素。

## 九、演进与趋势

单调栈已从「下一个更大」扩展到几何与二维问题：柱状图最大矩形、最大全 1 子矩阵、接雨水、最大矩形面积的变体，都依赖「单调栈在弹栈时结算答案」的范式。竞赛与面试中，还与贪心、差分、前缀和结合，形成「扫描线 + 单调结构」这一类题型（如扫描线求最大重叠区间、摩天大楼问题）。工程上，流式计算与监控系统用单调栈找「下一个高峰/突破」，股票引擎找「新高」「回撤」，编译器用类似思想做局部表达式优化。近年来 LeetCode 风格题目越来越倾向于「单调栈 + 二次扩展」（例如要求输出区间而非单点），对不变量的理解比背模板更重要。

## 十、小结

单调栈用一条递减（或递增）不变量，把「下一个更大/更小」从 $O(n^2)$ 压到均摊 $O(n)$：栈中元素都在等答案，新元素作为破坏者批量结算。理解不变量、边界与摊还，比记住模板更能迁移到矩形、雨水、贪心与二维扫描的复杂问题。
