# 单调栈原理与下一个更大元素

> 对应 youngyangyang04/leetcode-master 单调栈章节与 CyC2018/CS-Notes 题解。

## 一、背景与挑战
对数组每个元素找"右侧下一个更大/更小元素"，暴力 $O(n^2)$。单调栈利用单调性 $O(n)$。

## 二、核心原理
维护一个单调递减栈（栈底到顶递减）。遍历元素，当遇到更大值，则它是对栈顶元素的"下一个更大"，弹栈并记录；否则入栈。

## 三、形式化与数学基础
栈中元素保持"尚未找到答案"。新元素 $x$ 弹出所有 $<x$ 的栈顶，因这些元素的下一个更大者正是 $x$。每个元素进出栈一次。

## 四、代码实现
```python
def next_greater(nums):
    res = [-1] * len(nums)
    stack = []
    for i, x in enumerate(nums):
        while stack and nums[stack[-1]] < x:
            top = stack.pop()
            res[top] = x
        stack.append(i)
    return res
```

## 五、与其他技术对比
暴力两两比较 $O(n^2)$；单调栈 $O(n)$。哈希/线段树可回答区间最值但此处单调栈更省。

## 六、常见误区
- 栈存值而非下标，导致无法回填答案位置。
- 比较符号写反（求更小元素需用 `>`）。
