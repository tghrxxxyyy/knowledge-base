# 单调栈与柱状图最大矩形

> 对应 youngyangyang04/leetcode-master 单调栈（柱状图最大矩形）与 CyC2018/CS-Notes。

## 一、背景与挑战
给定柱状图高度数组，求能围成的最大矩形面积。暴力枚举左右边界 $O(n^2)$。

## 二、核心原理
以每个柱为高，向左右延伸到"第一个更矮的柱"。用单调递增栈在弹栈时计算以弹出柱为高、宽度为左右更矮柱间距的面积。

## 三、形式化与数学基础
对柱 $i$ 高 $h_i$，左右边界 $L_i,R_i$ 为最近更矮柱。面积 $A_i=h_i\times(R_i-L_i-1)$。最大矩形 $\max_i A_i$。

## 四、代码实现
```python
def largest_rectangle(heights):
    heights = [0] + heights + [0]   # 哨兵简化边界
    stack = []
    best = 0
    for i, h in enumerate(heights):
        while stack and heights[stack[-1]] > h:
            top = stack.pop()
            left = stack[-1] + 1
            width = i - left
            best = max(best, heights[top] * width)
        stack.append(i)
    return best
```

## 五、与其他技术对比
分治（找最低柱）也是 $O(n\log n)$；单调栈 $O(n)$ 且代码更统一。

## 六、常见误区
- 忘记哨兵导致左右边界处理复杂、栈残留。
- 宽度计算用 `i - stack[-1]` 而非 `i - stack[-1] - 1`。
