# 单调栈与柱状图最大矩形

> 对应 youngyangyang04/leetcode-master 单调栈（柱状图最大矩形）与 CyC2018/CS-Notes。

## 一、背景与挑战

柱状图最大矩形是单调栈最经典的「二维」问题：给定 $n$ 个非负整数 $h_0, h_1, \dots, h_{n-1}$ 表示柱子高度，求能围成的最大矩形面积。它出现在图像处理（最大全 1 子矩阵）、直方图分析、几何计算、股票成交量最大矩形等场景。暴力做法是枚举所有左右边界 $[l, r]$，取区间最小高度作高：
$$
\max_{0 \le l \le r < n} (r-l+1) \cdot \min_{l \le i \le r} h_i,
$$
复杂度 $O(n^2)$ 甚至 $O(n^3)$，$n$ 上千就难以接受。

更优的思路是「枚举高」：固定每根柱子 $i$，向左右延伸到「第一个比它矮的柱」，则以 $h_i$ 为高的最大矩形宽度就是这两根更矮柱之间的距离。问题化为：对每个 $i$，求左侧第一个更小 $L_i$ 与右侧第一个更小 $R_i$。这正是单调栈的主场。一次单调递增栈扫描可以在弹栈时同时结算宽度与面积，$O(n)$ 解决。

面试中该题常作为「单调栈应用」的必考题，衍生出「最大全 1 子矩阵」「接雨水」「最大矩形」等。期望答案不只是代码，而是说清「为什么弹栈时结算」「哨兵如何简化边界」「宽度为何是 $i - stack[-1] - 1$」。

## 二、核心原理

核心思想：**以每根柱子的高度作为矩形的高，向左右找到「第一个比它矮」的边界，中间的宽度就是该高能延伸的最大宽度**。这里有一个关键的枚举维度选择：不能「枚举宽度再求区间最小高」——那样对每个区间都要查最小值，退回平方级；必须「枚举高度再求最大宽度」，因为高度一旦固定，宽度就由左右第一根更矮的柱唯一确定，问题瞬间化归为「左右第一个更小」，正好落在单调栈的射程内。这个选择决定了后续所有动作：递增栈、弹栈结算、哨兵，都是必然结果而非灵光一现。

用单调递增栈（栈底到栈顶递增，存下标）扫描：

- 遇到当前高度 $h[i]$ **小于**栈顶对应高度时，栈顶柱 $t = \text{stack.pop()}$ 的右边界就是 $i$（右边第一个更矮），左边界是弹栈后的新栈顶（左边第一个更矮）。
- 矩形面积：$h[t] \times (i - \text{stack.top()} - 1)$。
- 若栈空，说明左边没有更矮柱，左边界为 $-1$；面积宽度为 $i$（含 $t$ 本身）。
- 遇到更高或相等时，直接入栈，等待未来更矮柱结算。

**哨兵技巧**：在 heights 前后各加一个高度 $0$（或 $-1$）。这样所有柱子最终都会被弹出，且左右边界天然存在，无需再处理栈残留与左右边界特判。代码显著简化。

不变量：
- 栈中下标对应高度严格递增（求「第一个更矮」）。
- 栈中元素都尚未找到右边界（还在等更矮柱）。
- 弹栈结算时，弹出者 $t$ 的右边界是 $i$，左边界是弹后栈顶，宽度为两者间距减 1。

边界条件：
- 高度数组为空：返回 0。
- 全部等高：宽度就是 $n$，面积 $h \times n$。
- 有 0 高度：面积为 0，但作为边界参与计算。
- 负数高度：题目一般约束非负；若有负数需特殊处理。

## 三、形式化与数学基础

定义 $L_i$ 为 $i$ 左侧第一个满足 $h_j < h_i$ 的最大下标，若不存在则 $L_i = -1$；$R_i$ 为 $i$ 右侧第一个满足 $h_j < h_i$ 的最小下标，若不存在则 $R_i = n$。则以 $h_i$ 为高的最大矩形面积
$$
A_i = h_i \times (R_i - L_i - 1).
$$
全局答案 $\max_i A_i$。

为什么这个公式对？$i$ 左边到 $L_i$ 之间都 $\ge h_i$，右边到 $R_i$ 之间也都 $\ge h_i$，故 $i$ 可以向左延展到 $L_i+1$、向右延展到 $R_i-1$，宽度 $R_i - L_i - 1$。再宽就会碰到更矮柱，矩形高度必须下降。

**单调栈如何求 $L_i, R_i$**：
- 扫描到 $i$，若 $h[i] < h[\text{stack.top()}]$，则 $R_{\text{stack.top()}} = i$，弹栈。
- 弹出后栈顶即为 $L_{\text{stack.top()}}$（若空则 $-1$）。
- 因为栈递增，栈顶左侧都更小，正好是「第一个更小」。

**复杂度**：每个下标入栈 1 次、弹出至多 1 次，均摊 $O(1)$，总 $O(n)$。

**哨兵的形式化意义**：加入 $h_{-1} = h_n = 0$ 后，对所有 $i \in [0, n-1]$，$L_i$、$R_i$ 都存在于扩展数组中，所有柱子必被结算，无需「扫描完处理栈残留」这一步。

**与分治对比**：分治找最低柱递归左右，$T(n) = 2T(n/2) + O(n) = O(n\log n)$；单调栈 $O(n)$ 更优且实现更统一。

**与接雨水对比**：接雨水是「凹槽」问题，用单调递增栈在遇到更高柱时结算「底面积」；最大矩形是「凸起」问题，用单调递增栈在遇到更矮柱时结算「矩形面积」。两者共享弹栈结算思想，但结算时机相反。

## 四、代码实现

下面是「柱状图最大矩形」的标准单调递增栈解法，附带哨兵与一个「最大全 1 子矩阵」的应用变体。

```python
def largest_rectangle_area(heights):
    """柱状图最大矩形面积。哨兵 0 简化边界。"""
    # 左右哨兵：高度 0，保证所有柱子都会被弹出结算
    hs = [0] + list(heights) + [0]
    stack = []
    best = 0
    for i, h in enumerate(hs):
        while stack and hs[stack[-1]] > h:
            top = stack.pop()
            # top 的右边界是 i，左边界是新的栈顶
            width = i - stack[-1] - 1
            best = max(best, hs[top] * width)
        stack.append(i)
    return best


def maximal_rectangle(matrix):
    """最大全 1 子矩阵面积（0/1 矩阵）。逐行累加高度后调用柱状图算法。"""
    if not matrix or not matrix[0]:
        return 0
    n = len(matrix[0])
    heights = [0] * n
    best = 0
    for row in matrix:
        for j, val in enumerate(row):
            heights[j] = heights[j] + 1 if val == '1' or val == 1 else 0
        best = max(best, largest_rectangle_area(heights))
    return best


if __name__ == "__main__":
    print(largest_rectangle_area([2, 1, 5, 6, 2, 3]))   # 10（5*2 或 6*... -> 10）
    print(largest_rectangle_area([2, 4]))               # 4
    print(largest_rectangle_area([1, 1, 1, 1]))         # 4

    mat = [
        list("10100"),
        list("10111"),
        list("11111"),
        list("10010"),
    ]
    print(maximal_rectangle(mat))                       # 6
```

代码要点：哨兵前后补 0，消除边界判断；宽度是 `i - stack[-1] - 1`，不是 `i - stack[-1]`；弹栈时 `stack[-1]` 是左边界，`i` 是右边界。最大全 1 子矩阵把每一行「向上累加的高度」当作柱状图，逐行调用本算法，$O(mn)$。

## 五、与其他技术对比

| 方法 | 时间 | 空间 | 特点 |
| --- | --- | --- | --- |
| 暴力枚举左右边界 | $O(n^3)$ | $O(1)$ | 直观但慢 |
| 枚举高 + 二分/线段树 | $O(n\log n)$ | $O(n)$ | 可扩展 |
| 分治（找最低柱递归） | $O(n\log n)$ | $O(\log n)$ | 优雅但慢于单调栈 |
| 单调递增栈 + 哨兵 | $O(n)$ | $O(n)$ | 最优，代码简洁 |
| 动态规划（左/右边界数组） | $O(n)$ | $O(n)$ | 两次扫描求边界 |

单调栈是最短且最优的标准解法；DP 版本也 $O(n)$，但需要两次预处理；分治更慢但思维独立。最大全 1 子矩阵则是柱状图算法的直接应用。

## 六、常见误区

1. **忘记哨兵**导致边界处理复杂、栈残留未结算。加前后 0 即可消除。
2. **宽度算错**：应为 `i - stack[-1] - 1`。若写成 `i - stack[-1]` 会多算 1；若漏掉 `-1` 或边界下标会错。
3. **栈存值不存下标**：无法计算宽度。
4. **比较符号写错**：求「第一个更矮」用递增栈，`>` 弹出；若要「第一个更高」则反过来。
5. **最大全 1 子矩阵忘记重置/累加高度**：高度是「向上连续 1 的个数」，遇到 0 要归零，否则会算出跨越 0 的错误矩形。

## 八、面试题

**1. 为什么加哨兵 0 能简化边界？**
前后补高度 0 后，所有柱子都会被更矮的哨兵触发弹出结算，且左右边界自然存在，无需特判栈空、残留、首尾。

**2. 弹栈时为何以「栈顶柱」为高计算？**
弹出者是当前遇到的第一根更矮柱右边的「第一个更高」，其右边界是 $i$，左边界是弹后栈顶，故此时宽度确定，面积可结算。

**3. 请对比单调栈与分治的时间复杂度。**
分治 $O(n\log n)$，单调栈 $O(n)$，且单调栈一次扫描、代码更统一。

**4. 如何扩展到「最大全 1 子矩阵」？**
逐行统计「以该行为底向上连续 1 的高度」，对每行调用柱状图最大矩形算法，取最大值，$O(mn)$。

## 九、演进与趋势

柱状图最大矩形是「单调栈结算」范式的代表，衍生出最大全 1 子矩阵、最大正方形、接雨水、含障碍矩形等系列。竞赛中还与扫描线、差分、二维前缀和结合。工程上，图像分割、直方图均衡、统计报表中「最大同色块」等问题都是其变体。近年面试越来越喜欢「柱状图 + 约束」（如含障碍、宽度限制、分数高），考察对不变量的灵活运用，而非死记模板。

## 十、小结

单调递增栈在弹栈时结算「以弹出柱为高的最大矩形」，哨兵消除边界判断，$O(n)$ 完成柱状图最大矩形。它把「左右第一个更矮」这族问题一次性解决，也是最大全 1 子矩阵等二维问题的基石。
