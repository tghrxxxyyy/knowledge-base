# 延迟弹出与多重集维护

> 对应 youngyangyang04/leetcode-master 单调队列进阶与 CyC2018/CS-Notes 滑动窗口题解。

## 一、背景与挑战
窗口内允许重复值（如"第 k 大"），简单单调队列无法直接处理相等/多值，需要延迟弹出或计数。

## 二、核心原理
用哈希计数记录窗口频率；弹出时若队首计数归零才真正出队。这样队列可容纳重复候选值。

## 三、形式化与数学基础
维护候选集多重集 $M$。比较时仍按值单调，但相等值都保留；出队条件改为 `freq[dq[0]]==0`。

## 四、代码实现
```python
from collections import deque, Counter

def sliding_mode(nums, k):
    dq = deque()
    freq = Counter()
    res = []
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] < x:
            dq.pop()
        dq.append(i)
        freq[x] += 1
        if dq[0] == i - k:
            freq[nums[dq[0]]] -= 1
            if freq[nums[dq[0]]] == 0:
                dq.popleft()
            else:
                # 队首值仍有留存，仅窗口边界移动
                dq.popleft() if False else None
            dq.popleft()  # 重新以新队首为准，简化演示
        if i >= k - 1:
            res.append(nums[dq[0]])
    return res
```

## 五、与其他技术对比
平衡树（multiset）天然支持重复与第 k 大，但单调队列在"仅最值"场景更轻。

## 六、常见误区
- 重复值处理时过早弹出导致答案丢失。
- 频率未及时回退，窗口外值仍计入。

## 十、小结
