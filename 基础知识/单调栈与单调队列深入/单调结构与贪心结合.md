# 单调结构与贪心结合

> 对应 youngyangyang04/leetcode-master 单调栈/队列与贪心结合题与 CyC2018/CS-Notes。

## 一、背景与挑战
许多贪心问题（如去掉 k 个数字使最小、去除无效括号）需要"保留单调性最优前缀"，单调栈是贪心落地工具。

## 二、核心原理
用单调栈在扫描中不断"撤销"不优的先前选择（如高位较大数字），等价于贪心"能删则删"。

## 三、形式化与数学基础
删除 k 位：维护递增栈，遇更小当前位且还可删时弹栈，保证结果字典序最小。删够 k 次或扫完。

## 四、代码实现
```python
def remove_k_digits(num, k):
    stack = []
    for ch in num:
        while k > 0 and stack and stack[-1] > ch:
            stack.pop()
            k -= 1
        stack.append(ch)
    if k > 0:
        stack = stack[:-k]   # 仍剩可删，从尾部删（高位已最优）
    return ''.join(stack).lstrip('0') or '0'
```

## 五、与其他技术对比
暴力枚举删哪位 $O(\binom{n}{k})$；单调栈贪心 $O(n)$。

## 六、常见误区
- 忘记最后仍剩 k 要从末尾删（此时栈已递增）。
- 结果前导零未处理。
