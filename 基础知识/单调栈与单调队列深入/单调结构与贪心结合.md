# 单调结构与贪心结合

> 对应 youngyangyang04/leetcode-master 单调栈/队列与贪心结合题与 CyC2018/CS-Notes。

## 一、背景与挑战

贪心算法的「当前最优」选择一旦做出，常常无法回头；但很多序列问题里，后面的元素会「证明」先前的选择不够好。典型例子是「移掉 K 位数字使结果最小」：`num = "1432219", k = 3`，若第一位选 `1` 后就锁定，结果未必最优；真正的最优需要在扫描中**撤销**前面较大的高位数字。类似地，去除无效括号、股票买卖含手续费的最优序列、拼接最小数字、跳跃游戏里「最远可达」的贪心推进，都要求「保留单调性最优前缀，遇破坏者撤销」。

暴力枚举「删哪 $k$ 位」是 $\binom{n}{k}$ 级组合爆炸；动态规划往往 $O(nk)$，对大 $n$ 不够。单调栈提供了一个漂亮解法：**用单调递增栈维护「当前最优前缀」，遇更小元素就弹掉前面较大的、且还允许删除的元素**，最后若仍剩可删次数，从尾部删除（此时栈已递增，尾部数字是高位贡献最小的）。这把贪心「能删则删」的策略，落地为「栈的撤销机」，$O(n)$ 解决。

「单调结构 = 贪心的执行器」是这一类问题的统一视角：贪心负责「什么是最优策略」，单调栈/队列负责「高效地撤销次优选择、维持候选序」。面试中该题常作为「贪心 + 单调栈」的代表题，衍生出去除重复字母、拼接最小数、最大数、每日温度的贪心解释、跳跃游戏 VI 的单调队列优化 DP 等。期望答案是说清「为什么弹栈能得到字典序最小」「该贪心与下一个更大元素的关系」。

## 二、核心原理

以「移掉 K 位数字」为例，目标是删 $k$ 位后字典序最小。

**贪心策略**：从高位到低位扫描，希望高位尽可能小。当遇到当前数字 `ch` **小于**栈顶时，说明栈顶这个「较高位」是次优选择，应删掉（弹栈），消耗一次删除机会；重复直到栈顶 $\le$ `ch` 或删完 $k$ 次，然后入栈。

为什么这样对？字典序比较：高位决定优先级，高位越小越好。若栈顶大于后面的 `ch`，保留栈顶会使高位变大，删掉它一定更优（且删除栈顶不影响更低位的选择机会）。这就是「能删则删」的贪心，单调递增栈保证已保留的前缀是「当前最小」。

**末尾处理**：扫完后若 $k > 0$，说明序列已递增（无法再用「删掉较大前缀」优化），此时应从**尾部**删掉 $k$ 位（尾部是低位，对字典序影响最小）。

**前导零**：结果需去掉前导零；若全为零返回 `"0"`。

**不变量**：
- 栈中数字从底到顶非降（递增）。
- 弹出次数 $\le k$，每次弹出消耗一次删除。
- 栈内容是「当前最优前缀」的候选。

**与下一个更大元素的关系**：弹栈条件 `stack[-1] > ch` 正是「遇到更小的破坏者，弹掉更大的等待者」，与 NGE 的「遇更大弹更小」对称。单调栈在这里不是求「下一个更大」，而是维护「最优递增序列」。

**边界条件**：
- $k = 0$：返回原串（或去前导零）。
- $k = n$：返回 `"0"`。
- 全相等：任意删 $k$ 位等价，从尾删。
- `num` 含前导零：输入一般无前导零，输出需处理。

## 三、形式化与数学基础

设 $num$ 为长度 $n$ 的数字串，删 $k$ 位后长度 $m = n - k$。目标
$$
\min_{\text{删法}} \text{lex}(s'),
$$
其中 $\text{lex}$ 为字典序。

**贪心正确性（交换论证）**。考虑最优解 $s^*$。从高位向低位比较 $s^*$ 与单调栈结果 $s$，若首次不同位置 $s$ 的数字更小，则 $s$ 不劣于 $s^*$；若相同，递归考虑剩余。单调栈在每个位置选择「删除所有更大前缀直到栈顶 $\le$ 当前」，保证了「当前位尽量小」，这是字典序贪心的最优子结构。

**复杂度**。扫描 $n$ 位，每位至多入栈 1 次、弹出至多 $k$ 次（但总弹出 $\le n$），故 $O(n)$。末尾删 $k$ 位 $O(k)$。总 $O(n)$。

**与 DP 对比**。令 $dp[i][j]$ 为前 $i$ 位删 $j$ 位的最小串，转移
$$
dp[i][j] = \min\big(dp[i-1][j] + num[i],\; dp[i-1][j-1]\big),
$$
时间 $O(nk)$、空间 $O(nk)$，字符串比较另耗 $O(m)$。单调栈把这压到 $O(n)$，因为贪心无需比较全部子问题。

**跳跃游戏 / 最远到达**。类似贪心：维护当前最远 `reach`，遍历中更新 `reach = max(reach, i + nums[i])`，若 `i > reach` 则失败。这是「贪心 + 区间扩张」，与单调队列优化跳跃游戏 VI（`dp[i] = max(dp[j]) + nums[i]`，$j \in [i-k, i-1]$）同族：用单调队列维护窗口最大值，均摊 $O(1)$ 转移。

## 四、代码实现

「移掉 K 位数字」单调栈贪心，附带「去除重复字母」（字典序最小去重）与「跳跃游戏」。

```python
def remove_k_digits(num: str, k: int) -> str:
    """移掉 k 位数字，使剩余数字表示的整数最小（字典序最小）。"""
    stack = []
    for ch in num:
        # 贪心：栈顶大于当前，则删栈顶更优
        while k > 0 and stack and stack[-1] > ch:
            stack.pop()
            k -= 1
        stack.append(ch)
    # 仍可删：从尾部删（高位已最优，删低位）
    if k > 0:
        stack = stack[: len(stack) - k]
    # 去前导零
    result = "".join(stack).lstrip("0")
    return result or "0"


def remove_duplicate_letters(s: str) -> str:
    """每个字母至少保留一个，使结果字典序最小。单调栈 + 贪心。"""
    from collections import Counter
    remain = Counter(s)
    stack = []
    in_stack = set()
    for ch in s:
        remain[ch] -= 1
        if ch in in_stack:
            continue
        # 栈顶字典序大于当前，且栈顶后面还有出现，则可弹出
        while stack and stack[-1] > ch and remain[stack[-1]] > 0:
            removed = stack.pop()
            in_stack.discard(removed)
        stack.append(ch)
        in_stack.add(ch)
    return "".join(stack)


def can_jump(nums) -> bool:
    """跳跃游戏 I：贪心维护最远可达。"""
    reach = 0
    for i, x in enumerate(nums):
        if i > reach:
            return False
        reach = max(reach, i + x)
    return True


if __name__ == "__main__":
    print(remove_k_digits("1432219", 3))   # "1219"
    print(remove_k_digits("10200", 1))    # "200"
    print(remove_k_digits("10", 2))       # "0"
    print(remove_duplicate_letters("bcabc"))   # "abc"
    print(remove_duplicate_letters("cbacdcbc")) # "acdb"
    print(can_jump([2, 3, 1, 1, 4]))      # True
    print(can_jump([3, 2, 1, 0, 4]))      # False
```

要点：删 $k$ 位的 `while` 条件是 `stack[-1] > ch` 且 `k > 0`；末尾从尾删；去重字母需 `remain` 判断「栈顶后面还有」才能弹出，避免丢字母。

## 五、与其他技术对比

| 方法 | 时间 | 空间 | 特点 |
| --- | --- | --- | --- |
| 暴力枚举删法 | $\binom{n}{k} \cdot n$ | $O(n)$ | 仅极小 $n$ |
| 动态规划 | $O(nk \cdot m)$ | $O(nk)$ | 可求最优，但慢 |
| 单调栈贪心 | $O(n)$ | $O(n)$ | 移掉 k 位、去重字典序最小 |
| 贪心 + 单调队列 | $O(n)$ | $O(k)$ | 跳跃游戏 VI、滑动窗口 DP 优化 |
| 排序 / 交换论证 | $O(n\log n)$ | $O(1)$ | 拼接最大数（自定义比较） |

单调栈贪心专治「删/保留使字典序最优」；单调队列优化窗口 DP；拼接最大数用自定义排序。各有适用，单调栈在序列撤销问题上最优雅。

## 六、常见误区

1. **忘记末尾仍可删 $k$ 时从尾删**。此时栈已递增，删尾部（低位）最安全；若从头删会破坏已优化的高位。
2. **结果前导零未处理**。`"10200"` 删 1 位得 `"200"`，不是 `"0200"`。需 `lstrip('0')`，全零返回 `"0"`。
3. **去重字母时弹栈条件漏 `remain[stack[-1]] > 0`**。若栈顶后面没有了，弹出会丢字母，结果不完整。
4. **把「删除次数」与「弹栈次数」混淆**。弹栈一次消耗一次删除；入栈不消耗。条件写反会多删或少删。
5. **误以为贪心在任何删除问题都成立**。若目标是「删 $k$ 位使最大」，则遇更大弹更小，比较方向相反；目标不同，贪心方向不同。

## 八、面试题

**1. 为什么弹栈能得到字典序最小？**
高位决定字典序，栈顶大于后续元素时，删栈顶使高位变小，交换论证保证不劣；单调递增栈保证已保留前缀最优。

**2. 该贪心与「下一个更大元素」的关系？**
都是「遇破坏者弹等待者」：NGE 遇更大弹更小，移掉 k 位遇更小弹更大；共享单调栈的撤销与结算思想。

**3. 为什么最后仍剩 k 要从末尾删？**
扫描结束时栈非降，无法再通过「删较大前缀」优化，只能删低位（尾部）对字典序影响最小。

**4. 去除重复字母为何要 `remain` 计数？**
弹栈前必须确认栈顶字母后面还会出现，否则弹出会丢字母。`remain` 记录剩余出现次数，保证每个字母至少保留一个。

## 九、演进与趋势

「单调结构 = 贪心执行器」的视角延伸到：拼接最小/最大数（自定义排序 + 贪心）、股票含手续费的最优序列（贪心 + 状态机）、跳跃游戏 VI（单调队列优化 DP）、去除无效括号（栈 + 贪心计数）、以及区间调度（按结束时间贪心 + 排序）。竞赛与面试越来越喜欢「贪心正确性证明」（交换论证）与「单调队列优化 DP」的组合，而不仅是模板代码。工程上，任务调度、资源分配、日志压缩、文本编辑器的撤销栈，都体现「维护最优前缀、遇更优撤销」的思想。未来方向包括：多目标贪心的 Pareto 单调结构、在线算法中带延迟撤销的单调队列、以及神经网络调度器中的贪心 + 优先队列。

## 十、小结

单调栈/队列是贪心「撤销次优选择」的执行器：移掉 K 位数字、去重字母、跳跃游戏等问题，都能用「遇破坏者弹等待者、维持最优前缀」统一。掌握交换论证与边界处理（末尾删、前导零、remain 计数），才能在变体题中灵活运用。
