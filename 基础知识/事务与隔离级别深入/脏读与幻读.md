# 脏读与幻读

> 对应 Silberschatz《Database System Concepts》15.5 并发异常，以及 DDIA 中文第 7 章。

## 一、背景与挑战
并发事务交错会产生多种异常：读到未提交数据、同查询两次结果不同、结果集行数变化。这些异常破坏应用语义。

## 二、核心原理
脏读：读到别的事务未提交且可能回滚的写。不可重复读：同一事务内两次读同一行结果不同（他事务提交更新）。幻读：同一查询两次返回不同行集合（他事务插入/删除匹配行）。

## 三、形式化 / 数学基础
以调度 $S$ 上读写冲突定义：脏读含 $w_1(x) \dots r_2(x) \dots a_1$；幻读属谓词冲突，$r_1(P) \dots w_2(\text{满足}P) \dots r_1(P)$ 结果集变化。

## 四、代码实现
```sql
-- 防止脏读：RC 及以上
SET SESSION TRANSACTION ISOLATION LEVEL READ COMMITTED;
-- 防止幻读：串行化或 next-key lock
SELECT * FROM t WHERE k BETWEEN 10 AND 20 FOR UPDATE;
```

## 五、与其他技术对比
| 异常 | 触发 | 防法 |
|------|------|------|
| 脏读 | 读未提交写 | 提交读 |
| 不可重复读 | 他事务更新 | 行锁/快照 |
| 幻读 | 他事务插入 | 范围/谓词锁 |

## 六、常见误区
1. 幻读=不可重复读——幻读针对结果集行数，不可重复读针对单行值。
2. RR 一定防幻读——快照 RR 不防。
3. 加行锁防幻读——需 next-key/间隙锁。

## 九、演进与趋势
SSI 通过检测读写依赖环在无锁下防写倾斜与幻读，成为现代串行化主流。

## 十、小结
三类异常对应不同冲突粒度（未提交写、行更新、谓词插入）；正确选择隔离级别与锁策略才能规避。
