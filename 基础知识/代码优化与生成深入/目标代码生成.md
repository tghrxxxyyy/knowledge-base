# 目标代码生成

> 对应 龙书 第 14 章 与 Appel 第 12 章。

## 一、背景与挑战
把 IR 映射到具体指令集（x86/ARM/RISC-V）。挑战：指令格式、寻址模式、寄存器分配衔接、正确性与性能。

## 二、核心原理
指令选择把 IR 树/SSA 匹配为目标指令；寄存器分配（见前）定寄存器；调度重排以隐藏延迟。最终发射汇编/机器码。

## 三、形式化 / 数学基础
代码生成 = 模板匹配 IR 片段到指令。成本相加最小化。寄存器约束：指令 `$r_d = op\ r_s$` 要求操作数在寄存器。

## 四、代码实现
```python
def gen_add(dst, a, b):
    if isinstance(a, int):
        emit(f"  mov {dst}, {a}")
        emit(f"  add {dst}, {b}")
    else:
        emit(f"  add {dst}, {a}, {b}")
# 简单树重写：每个 IR 节点映射为 1..n 条指令
```

## 五、与其他技术对比
- 树重写（BURG/动态规划）：最优覆盖。
- DAG 覆盖：共享公共子表达式。
- 线性扫描 IR→asm：快、JIT 用。

## 六、常见误区
1. 立即数超指令宽度未拆。
2. 忘记破坏的标志寄存器 (flags) 致后续条件错。
3. 调用约定（参数寄存器/栈对齐）漏遵守。

## 九、演进与趋势

## 十、小结
目标代码生成是 IR 到机器指令的映射：指令选择+BURG 覆盖+寄存器分配+调度共同决定最终质量。
