# 循环优化

> 对应 龙书 第 11 章 与 Kennedy & Allen 第 6 章。

## 一、背景与挑战
循环占多数运行时间，是优化重点。挑战：循环嵌套分析、依赖测试（能否并行/变换）、正确性（尤其浮点/别名）。

## 二、核心原理
- 循环不变代码外提 (LICM)：把不随迭代变的放到前。
- 归纳变量消除：用线性式替代计数。
- 循环展开/分块/交换/反转以优化 cache 与并行。

## 三、形式化 / 数学基础
依赖距离向量：对 `A[i]` 与 `A[i+1]`，距离 1 阻止并行但允许向量化。
循环展开因子 $U$：$i\in[0,n)$ 步 $U$ 复制体。
LICM 条件：表达式所有操作数在循环前已定值且循环内不被重定义。

## 四、代码实现
```c
/* 外提不变: t = a*b 不依赖 i */
int t = a * b;
for (int i = 0; i < n; i++) {
    c[i] = t + d[i];   // a*b 已外提
}
```

## 五、与其他技术对比
- LICM/归纳变量：通用、安全。
- 循环交换/分块：面向 cache/并行，需依赖分析。
- 软件流水线：ILP 调度，VLIW 常用。

## 六、常见误区
1. 在含别名的循环外提（指针可能改）。
2. 浮点重排改变结果（非结合）。
3. 展开过多致代码膨胀/icache  miss。

## 九、演进与趋势
polyhedral 模型自动变换、GPU tiling、以及 ML 调度（如 TVM/AlphaTensor 风格）。

## 十、小结
循环优化靠依赖分析与不变性判定：LICM/归纳变量保安全，交换/分块面向局部性，polyhedral 把这类变换自动化。
