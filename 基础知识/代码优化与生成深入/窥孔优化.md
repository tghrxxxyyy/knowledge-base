# 窥孔优化

> 对应 龙书 第 9.1 / 14 章（窥孔/ peephole）。

## 一、背景与挑战
窥孔优化在局部指令窗口做简单重写：消去冗余 `mov`、合并 `add 0`、跳转到跳转变直。挑战：模式覆盖全、与前后阶段不冲突。

## 二、核心原理
滑动窗口扫描发射后的指令序列，匹配低效模板并替换为等价高效版。典型：冗余 load/store 消除、强度削弱 (`mul 2`→`shl 1`)、跳转链折叠。

## 三、形式化 / 数学基础
等价重写规则示例：
`mov r, r` → 删除；
`add r, 0` → 删除；
`jmp L1; L1: ...` → 删除 `jmp`；
`imul r, r, 2` → `shl r, r, 1`。

## 四、代码实现
```python
def peephole(ins):
    out = []
    for i in ins:
        if out and redundant(out[-1], i):
            continue          # 如 mov r,r
        if i.is_jmp_to_next():
            continue          # 跳到紧接的下一条
        out.append(i)
    return out
```

## 五、与其他技术对比
- 窥孔：最后兜底、简单稳健、易实现。
- IR 层优化：更早、信息多。
- 目标无关 vs 目标相关：窥孔多在目标层。

## 六、常见误区
1. 删 `mov` 未考虑别名/标志位副作用。
2. 强度削弱改浮点语义（乘 2 不恒等于加自身于 NaN/Inf）。
3. 重复扫描未收敛（需迭代）。

## 十、小结
窥孔优化是最后一道局部精炼：用等价重写消去冗余与弱指令；虽简单却在每条真实编译流水线中不可或缺。
