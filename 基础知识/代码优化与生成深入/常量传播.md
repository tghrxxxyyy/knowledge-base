# 常量传播

> 对应 龙书 第 9.4 节 与 Kennedy & Allen。

## 一、背景与挑战
若变量在某点必为常量，则以其值替换并折叠。挑战：条件常量（依分支）、循环中的非常量、与 SSA 的契合。

## 二、核心原理
沿 CFG 传播常量格 (lattice)：$\top$（未知）、具体值、⊤(undefined/⊥)。汇合用 meet：$\bot$ 若冲突，$\top$ 若未知，否则常量。

## 三、形式化 / 数学基础
格元素 $\mathcal{L}=\{\bot\}\cup\mathbb{Z}\cup\{\top\}$。meet：$a\sqcap b=a$ 若 $a=b$，否则 $\bot$。
不变式：若 $OUT[B](x)=c$ 则块 $B$ 出口 $x$ 恒为 $c$。

## 四、代码实现
```python
def cp(block, in_vals):
    out = dict(in_vals)
    for ins in block:
        if ins.is_assign_const():
            out[ins.dst] = ins.const
        elif ins.is_op():
            a, b = out.get(ins.l), out.get(ins.r)
            if isinstance(a, int) and isinstance(b, int):
                out[ins.dst] = eval_op(ins.op, a, b)
            else:
                out[ins.dst] = "TOP"
    return out
```

## 五、与其他技术对比
- 稀疏常量传播（SSA）：沿 def-use，快且精。
- 稠密（CFG 迭代）：实现简但慢。
- 条件常量传播：结合分支条件更准。

## 六、常见误区
1. 在可能非常量的循环出口当常量替换。
2. 忽略 meet 冲突退化为 ⊤。
3. 传播破坏 SSA 单一赋值。
