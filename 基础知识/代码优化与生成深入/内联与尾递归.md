# 内联与尾递归

> 对应 Kennedy & Allen 与 龙书 第 15 章（过程优化）。

## 一、背景与挑战
函数调用有开销（栈、参数）。内联消除调用、暴露跨过程优化；尾递归可被编译器转循环。挑战：代码膨胀、递归相互调用 (mutual)、尾调约定。

## 二、核心原理
内联：用函数体替换调用点，重命名变量避免冲突。尾递归：若递归调用是最后动作且无后续计算，可复用栈帧跳回入口（尾调用消除 TCO）。

## 三、形式化 / 数学基础
尾位置：函数体最后返回处 `return f(...)` 且返回值即为调用结果。
尾递归改写：`f(args)` 在尾位 $\Rightarrow$ 把 `args` 赋参、跳到 `f` 入口（等价 `while True` 循环体）。

## 四、代码实现
```python
def fact(n, acc=1):
    if n == 0: return acc
    return fact(n - 1, acc * n)   # 尾递归
# TCO 等价于:
def fact(n, acc=1):
    while n:
        n, acc = n - 1, acc * n
    return acc
```

## 五、与其他技术对比
- 内联：去调用开销、利后续优化；但膨胀 icache。
- TCO：尾递归无栈增长；非尾递归仍需栈。
- 互尾递归：需尾调用消除支持（Scheme 强制）。

## 六、常见误区
1. 认为所有递归都能尾消除（需真在尾位）。
2. 内联过大函数致膨胀与 miss。
3. 误以为 Python 有 TCO（CPython 无）。

## 十、小结
内联与 TCO 把调用开销压到最低：内联换膨胀换优化机会，尾递归换常数栈；二者都是过程优化的核心手段。
