# 红黑树

> 对应 CLRS《Introduction to Algorithms》第 13 章 Red-Black Trees。

## 一、背景与挑战
二叉搜索树在最坏输入下退化成链表。红黑树通过颜色约束保持「近似平衡」，保证操作 O(log n)，是 C++ map / Java TreeMap 的底层。

## 二、核心原理
五条性质：根黑、红结点孩子必黑、从任一结点到空叶的黑高相同、叶（NIL）为黑、红黑相间。插入/删除后用旋转与重染色修复。

## 三、形式化 / 数学基础
黑高 $bh(x)$ 为到叶路径上的黑结点数；红黑树高度 $\le 2\log_2(n+1)$，故查找、插入、删除均为 $O(\log n)$。

## 四、代码实现
```python
class RBNode:
    def __init__(self, key, red=True):
        self.key = key
        self.red = red
        self.left = self.right = self.parent = None

def left_rotate(root, x):
    y = x.right
    x.right = y.left
    if y.left:
        y.left.parent = x
    y.parent = x.parent
    if not x.parent:
        root = y
    elif x is x.parent.left:
        x.parent.left = y
    else:
        x.parent.right = y
    y.left = x
    x.parent = y
    return root
```

## 五、与其他技术对比
与 AVL 相比，红黑树旋转更少、插入删除更快，查询略慢；与跳表相比，红黑树是确定性平衡。

## 六、常见误区
插入后叔叔为红时只染色不旋转；删除情形（x 双重黑）分支判断错误；NIL 叶子未统一。

## 八、面试题
手写红黑树插入修复；解释为什么高度上界是 2log n。

## 九、演进与趋势
左倾红黑树（LLRB）简化实现；与 B 树等价视角（2-3-4 树）。

## 十、小结
红黑树用颜色约束维持黑高平衡，核心是插入/删除后的 O(1) 类修复 + 旋转，工程中平衡与性能兼得。
