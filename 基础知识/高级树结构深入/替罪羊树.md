# 替罪羊树

> 对应 Galperin & Rivest《Scapegoat Trees》(1993)。

## 一、背景与挑战
一种「惰性平衡」BST：插入/删除不做旋转，仅当某子树过于不平衡时整体重建（拍平后中序重建），均摊 O(log n)。

## 二、核心原理
定义 α 权重平衡：若子树大小 > α · 父大小则触发重建。删除可延迟（标记删除），到失衡时统一重建。

## 三、形式化 / 数学基础
$size(x) \le \alpha \cdot size(parent(x))$ 违反即重建。取 $\alpha \in (0.5, 1)$，如 0.75。重建中序线性、重建后完全平衡。

## 四、代码实现
```python
def flatten(root, out):
    if not root:
        return
    flatten(root.left, out)
    out.append(root.key)
    flatten(root.right, out)

def build_balanced(keys, l, r):
    if l > r:
        return None
    m = (l + r) // 2
    node = Node(keys[m])
    node.left = build_balanced(keys, l, m - 1)
    node.right = build_balanced(keys, m + 1, r)
    return node
```

## 五、与其他技术对比
与 Treap（随机优先级）相比，替罪羊树确定性重建、无随机；与红黑树相比，省去复杂旋转/染色。

## 六、常见误区
α 取值过小导致频繁重建、过大则退化为链表；删除后 size 未正确维护触发条件。

## 七、与开源书 / 权威来源对应
- Galperin & Rivest 1993
- 《算法竞赛》平衡树章节

## 八、面试题
「序列插入后保持平衡」；手写重建逻辑。

## 九、演进与趋势
结合重量平衡与部分重建；与 Treap 混合思路。

## 十、小结
替罪羊树以「偶尔整体重建」换取实现简单，是竞赛中常用的无旋平衡树方案。
