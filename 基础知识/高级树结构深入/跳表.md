# 跳表

> 对应 Pugh《Skip Lists: A Probabilistic Alternative to Balanced Trees》(1990)。

## 一、背景与挑战
用概率性的多层有序链表实现类平衡树的 O(log n) 查找/插入/删除，实现远比红黑树简单，被 Redis zset 采用。

## 二、核心原理
每个结点带若干层前进指针；插入时以概率 p（常 1/2）向上晋升一层。查找从最高层向右再向下。

## 三、形式化 / 数学基础
层数期望 $1/(1-p)$；查找长度期望 $O(\log_{1/p} n)$；空间期望 $O(n/(1-p))$。

## 四、代码实现
```python
import random
class Node:
    def __init__(self, key, level):
        self.key = key
        self.forward = [None] * (level + 1)
def random_level(p=0.5, max_l=16):
    l = 0
    while random.random() < p and l < max_l:
        l += 1
    return l
```

## 五、与其他技术对比
与红黑树相比，跳表代码量小、范围查询友好（链表天然有序）；缺点是概率性、最坏 O(n)。

## 六、常见误区
层高分布未设上限导致极端层数；插入未正确更新各层前驱；删除漏掉高层指针。

## 九、演进与趋势
无锁并发跳表；与 B+ 树在 LSM 存储中的配合。

## 十、小结
跳表以概率分层换取简单而高效的 O(log n) 操作，是工程上红黑树的优秀替代品。
