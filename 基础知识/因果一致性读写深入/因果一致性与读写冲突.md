# 因果一致性与读写冲突

> 对应 Shapiro 2011（CRDT）与 Vogels 2009。

## 一、背景与挑战
并发写必然产生冲突。线性一致通过串行化消解冲突，但代价高。因果一致允许并发，于是需要明确的「冲突合并」策略：既要尊重因果，又要对并发做可预测合并，否则副本发散。

## 二、核心原理
对并发更新应用可交换、可结合、可传播的合并函数（即 CRDT 思想）。因果相关的更新按序应用；并发更新用合并函数（如 LWW、集合并、计数器加）得到确定结果，保证所有副本收敛到同一状态。

## 三、形式化与数学基础
合并算子 \\(\sqcup\\) 需满足：交换律 \\(a\sqcup b=b\sqcup a\\)，结合律 \\((a\sqcup b)\sqcup c=a\sqcup(b\sqcup c)\\)，幂等 \\(a\sqcup a=a\\)。满足即成 CRDT，保证最终收敛。

## 四、代码实现
```python
def merge_registers(a, b):
    return a if (a.ts, a.node) >= (b.ts, b.node) else b  # LWW tie-break by node id

def merge_gcounter(a, b):
    return [max(x, y) for x, y in zip(a, b)]  # 增长计数器
```

## 五、与其他技术对比
悲观锁或 2PC 拒绝并发冲突但降低可用；CRDT 接受并发并用数学合并保收敛；因果一致定义「何时必须有序」，CRDT 定义「并发如何合并」。

## 六、常见误区
1. 认为因果一致自动解决冲突：只对因果有序，并发仍需合并策略。
2. LWW 丢更新：后到但早发生的可能覆盖。
3. 非幂等合并导致发散：必须保证 CRDT 三性质。

## 七、与开源书/权威来源对应
Shapiro 2011 系统给出 CRDT 数学基础；DDIA 第9章讨论冲突与收敛。

## 八、面试题
问：CRDT 收敛的三个代数性质？
答：交换律、结合律、幂等律。

## 九、演进与趋势
CRDT 成为本地优先（local-first）与协作编辑（如 Automerge、Yjs）的核心。

## 十、小结
因果一致解决「有序」，CRDT 解决「并发合并」，二者互补实现无协调收敛。
