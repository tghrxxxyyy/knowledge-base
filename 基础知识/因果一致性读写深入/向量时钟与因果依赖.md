# 向量时钟与因果依赖

> 对应 Lamport 1978 与 Shapiro 2011（CRDT）相关背景。

## 一、背景与挑战
要判断两个事件是否因果相关，单计数器（Lamport 时钟）不够——它只能保证因果到序，不能反推。向量时钟用每个节点的逻辑时间数组精确编码因果：可判定「因果」「并发」。

## 二、核心原理
每个节点 i 维护向量 \\(V[i]\\)，初值全 0。本地事件 \\(V[i]+=1\\)；发消息带自身向量；收消息对每个维度取 max。比较：\\(V\le W\\) 当且仅当 \\(\forall j, V[j]\le W[j]\\)；\\(V<W\\) 且存在 \\(j, V[j]<W[j]\\) 表示因果；否则并发。

## 三、形式化与数学基础
并发定义：\\(V\parallel W \iff \neg(V\le W)\land\neg(W\le V)\\)。这是偏序到向量的经典编码，空间 O(N)，N 为节点数。

## 四、代码实现
```python
def merge(a, b):
    return [max(x, y) for x, y in zip(a, b)]

def happens_before(a, b):
    return all(x <= y for x, y in zip(a, b)) and any(x < y for x, y in zip(a, b))

def concurrent(a, b):
    return not (all(x<=y for x,y in zip(a,b)) or all(y<=x for x,y in zip(a,b)))
```

## 五、与其他技术对比
Lamport 时钟 O(1) 但不可判并发；向量时钟 O(N) 可判因果；HLC O(1) 但仅保因果到全序单向。

## 六、常见误区
1. 认为向量时钟可无限扩展：节点数大时空间或带宽成问题。
2. 忽略节点增删的版本处理：需版本号或稳定 id 映射。
3. 用向量时钟做精确全序：它给的是偏序。

## 七、与开源书/权威来源对应
DDIA 第9章讲向量时钟与因果；Shapiro 2011 用其定义 CRDT 并发。

## 八、面试题
问：如何判断两事件并发？
答：两者向量互不全序（互不 \\(\le\\)）。

## 九、演进与趋势
出现「紧凑向量时钟」「dotted version vectors」降低元数据开销。

## 十、小结
向量时钟以 O(N) 代价精确编码因果偏序，是因果系统的基石。
