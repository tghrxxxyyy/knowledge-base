# 页错误分类

> 对应 CSAPP 第 9 章“缺页异常”与 OSTEP 第 19 章。

## 一、背景与挑战
访问虚拟地址触发 MMU 查页表，若无效或权限不符则产生页错误（page fault）。并非所有页错误都是错误——多数属正常按需调页。

## 二、核心原理
- 重大页错误（major fault）：页不在内存，需从磁盘（文件/swap）读入。
- 次要页错误（minor fault）：页已在内存（如共享页、COW 副本），仅需建立映射。
- 无效访问：地址非法或权限不足，触发 SIGSEGV。

## 三、形式化 / 数学基础
页错误码（x86）位：P（存在位）、W/R（写读）、U/S（用户/内核）。处理器据错误码与 PTE 判定类别：存在位 0 且为合法映射 → 调页；权限错 → segfault。

## 四、代码实现
内核缺页分发（示意）：

```c
vm_fault_t handle_mm_fault(struct vm_area *vma, unsigned long addr, unsigned int flags) {
    if (!pte_present(*pte)) {
        if (pte_none(*pte)) return do_anonymous_page(vma, addr); /* 首次 */
        return do_swap_page(vma, addr);                         /* 换入 */
    }
    if (write_fault && !pte_write(*pte)) return do_wp_page(vma, addr); /* COW */
    return VM_FAULT_SIGSEGV;
}
```

## 五、与其他技术对比
major fault 昂贵（磁盘 IO），minor fault 廉价（仅建映射），segfault 致命。调优关注 major fault 率，而非 fault 总数。

## 六、常见误区
- 把“页错误”等同于“程序崩溃”：多数只是按需调页。
- 认为 COW 写错是 bug：它是写时复制的正常触发。
- 忽略 minor fault 也占一定开销（映射建立）。

## 九、演进与趋势
`MADV_POPULATE`/`MAP_POPULATE` 预建映射降低运行时 fault；大页减少 fault 频率；userfaultfd 让用户态接管缺页。

## 十、小结
页错误分重大/次要/非法三类：前两者是正常的按需内存机制，后者才是段错误；性能分析看 major fault。
