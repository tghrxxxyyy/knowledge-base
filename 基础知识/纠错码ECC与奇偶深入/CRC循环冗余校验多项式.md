# CRC循环冗余校验多项式

> 对应 Kurose & Ross《Computer Networking》与 RFC 791/793。

## 一、背景与挑战
链路层与存储需要检测突发错误。CRC（循环冗余校验）基于有限域 GF(2) 上的多项式除法，能以小开销检测长突发错误。

## 二、核心原理
将待校验比特串视为 GF(2) 多项式，除以生成多项式 G(x)，余数作为 FCS（帧校验序列）。接收端重新除法，余数为 0 则大概率无误。

## 三、形式化与数学基础
发送方计算：

    T(x) = M(x) * x^r + (M(x) * x^r mod G(x))

其中 r 为 G 的阶。检错能力与 G 的选择相关：含 (x+1) 因子可检所有奇数位错；特定长度突发错误可高概率检测。

## 四、代码实现
```c
uint32_t crc32_step(uint32_t crc, uint8_t byte) {
    crc ^= (uint32_t)byte << 24;
    for (int i = 0; i < 8; i++)
        crc = (crc & 0x80000000) ? (crc << 1) ^ 0x04C11DB7 : (crc << 1);
    return crc;
}
```

## 五、与其他技术对比
CRC 长于突发错误检测，优于奇偶；但不纠正错误。校验和（如 TCP）更简单但对某些错误图样弱于 CRC。

## 六、常见误区
误以为 CRC 能纠正错误；它主要检错。误以为任意生成多项式等价，实际阶与因子决定检错能力。

## 七、与开源书/权威来源对应
RFC 791（IP）定义 IPv4 首部校验和；以太网 CRC-32 见相关标准；Kurose & Ross 讲解链路层 FCS。

## 九、演进与趋势
硬件 CRC 指令（如 ARM CRC32、x86 SSE4.2）加速校验；在 NVMe、存储中广泛使用。

## 十、小结
CRC 用 GF(2) 多项式除法提供强突发错误检测，是网络与存储链路层的事实标准检错手段。
