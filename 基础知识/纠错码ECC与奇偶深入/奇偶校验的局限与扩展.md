# 奇偶校验的局限与扩展

> 对应 Tanenbaum《Computer Organization and Design》。

## 一、背景与挑战
奇偶校验是最简单的错误检测手段，但只能覆盖奇数个比特翻转，对偶数个错误完全失效。

## 二、核心原理
偶校验：使数据位加校验位中 1 的个数为偶数；接收端重算，若奇偶性不符则存在奇数个错误。它不定位错误，也不处理偶数个错误。

## 三、形式化与数学基础
设数据位向量 d，校验位 p 满足：

    p = \bigoplus_i d_i  (偶校验使总异或 = 0)

检测能力：所有汉明重量为奇数的错误图样均可检测；偶数重量错误漏检。

## 四、代码实现
```c
uint8_t parity_even(uint8_t x) {
    x ^= x >> 4; x ^= x >> 2; x ^= x >> 1;
    return ~(x & 1) & 1; /* 返回使整体偶校验的位 */
}
```

## 五、与其他技术对比
奇偶校验开销最低但能力最弱；CRC 与海明码提供更强检测/纠正；纵向/横向奇偶（二维奇偶）可检测部分双错。

## 六、常见误区
误以为奇偶校验能检测所有错误；偶数个翻转漏检。误以为它能纠正错误。

## 九、演进与趋势
奇偶校验仍用于低速总线与缓存 tag；强纠错交由 ECC/CRC。

## 十、小结
奇偶校验以极低成本检测奇数错误，但必须配合更强编码应对偶数错误与纠正需求。
