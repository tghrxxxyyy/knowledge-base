# 海明码编码与校验原理

> 对应 Tanenbaum《Computer Organization and Design》与 CLRS。

## 一、背景与挑战
内存与信道传输中比特翻转难以避免。海明码（Hamming code）用少量冗余位实现单比特错误的检测与定位纠正。

## 二、核心原理
在 2^k ≥ m + k + 1 条件下放置 k 个校验位（位于 2 的幂位置），每个校验位覆盖其二进制索引中对应位为 1 的数据位异或和。纠错时重算校验得到错误位置 syndrome。

## 三、形式化与数学基础
对码字比特位置 i（从 1 起），校验位 p_j 覆盖所有满足 (i & 2^{j-1}) != 0 的位置。 Syndrome S：

    S = \bigoplus_{i \in 错误覆盖集} bit_i

若 S != 0，则 S 直接给出出错位索引。

## 四、代码实现
```python
def encode_hamming(data):
    # data: list of bits length m, 返回含校验位的码字
    n = len(data) + (len(data).bit_length()) + 1
    code = [0] * (n + 1)
    j = 0
    for i in range(1, n + 1):
        if (i & (i - 1)) == 0:
            continue
        code[i] = data[j]; j += 1
    for p in range(n.bit_length()):
        idx = 1 << p
        s = 0
        for i in range(1, n + 1):
            if i & idx:
                s ^= code[i]
        code[idx] = s
    return code
```

## 五、与其他技术对比
奇偶校验只能检奇数个错误不能定位；海明码可定位单错；SECDED 在海明码基础上加一位实现双错检测。

## 六、常见误区
误以为海明码可纠正任意两个错误；标准海明码仅纠单错，双错需额外整体奇偶位。

## 九、演进与趋势
海明码演化为现代 ECC 内存的 SECDED 基础，并结合 chipkill 等更强纠错。

## 十、小结
海明码以 2 的幂位置放置校验位，用 syndrome 精确定位单比特错误，是纠错码入门基石。
