# 异或运算的性质与应用

> 对应 youngyangyang04/leetcode-master 位运算（异或）与 Warren《Hacker's Delight》第 2 章。

## 一、背景与挑战
异或 `^` 满足交换律、结合律、自反性，是"无进位加法"。常用于找出现奇数次的元素、交换变量、加密。

## 二、核心原理
- $a\oplus a = 0$
- $a\oplus 0 = a$
- 自反：$(a\oplus b)\oplus a = b$
利用这些性质可在 $O(n)$ 时间、$O(1)$ 空间消元。

## 三、形式化与数学基础
异或在 GF(2) 上是加法。若干数整体异或：$X=\bigoplus_i x_i$。若某数出现两次则抵消，奇数次保留。

## 四、代码实现
```python
def single_number(nums):
    # 仅一个元素出现一次，其余两次
    x = 0
    for v in nums:
        x ^= v
    return x

def swap(a, b):
    a ^= b
    b ^= a
    a ^= b
    return a, b
```

## 五、与其他技术对比
哈希表也可计数但需 $O(n)$ 空间；异或零空间，但仅适用于可被代数抵消的情况。

## 六、常见误区
- 用异或交换同一变量引用（如 `swap(x,x)` 会变 0）。
- 误以为异或可替代任意求和（仅 GF(2)）。

## 九、演进与趋势
异或在纠错码（CRC、Reed-Solomon）与随机数生成中仍是核心。

## 十、小结
异或的自反性与结合性是消元利器，注意引用别名陷阱。
