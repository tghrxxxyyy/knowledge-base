# 位运算在子集枚举中的应用

> 对应 youngyangyang04/leetcode-master 位运算（子集枚举）与 Warren《Hacker's Delight》。

## 一、背景与挑战
枚举一个集合的所有子集（共 $2^n$ 个）或某子集的所有子子集，是状压 DP、暴力剪枝常见需求。

## 二、核心原理
- 枚举所有子集：`for mask in range(1<<n)`。
- 枚举 `sub` 的全体子子集：`sub &= sub-1` 循环直到 0（含自身）。

## 三、形式化与数学基础
子集总数 $2^n$。`sub` 的子子集数为 $2^{|sub|}$，由 `sub = (sub-1) & sup` 递减枚举（sup 为父集）。

## 四、代码实现
```python
def all_subsets(n):
    res = []
    for mask in range(1 << n):
        res.append(mask)
    return res

def subsubsets(sup):
    # 枚举 sup 的所有子子集（含 sup 自身）
    sub = sup
    while True:
        yield sub
        if sub == 0:
            break
        sub = (sub - 1) & sup
```

## 五、与其他技术对比
递归选/不选也能枚举子集，但位掩码写法更紧凑且易与 DP 状态结合。

## 六、常见误区
- `sub = (sub-1) & sup` 循环忘了先处理 `sub=sup`（应先 yield 再递减）。
- 在 `sub==0` 时多枚举一次空集需注意终止条件。
