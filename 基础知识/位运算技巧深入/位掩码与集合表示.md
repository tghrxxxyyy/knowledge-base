# 位掩码与集合表示

> 对应 youngyangyang04/leetcode-master 位运算（状压基础）与 Warren《Hacker's Delight》第 2 章。

## 一、背景与挑战
当集合元素数 ≤ 机器字长（如 ≤ 64），可用一个整数表示子集，集合运算变成位运算，极快且省内存。

## 二、核心原理
元素 $i$ 对应第 $i$ 位。并集 `|`、交集 `&`、差集 `& ~`、成员 `>>i & 1`、遍历 `x & -x` 取元素。

## 三、形式化与数学基础
集合 $S$ 编码为整数 $\sum_{i\in S}2^i$。集合运算对应按位布尔运算，时间复杂度 $O(1)$（字长内）。

## 四、代码实现
```python
def add(s, i):
    return s | (1 << i)

def contains(s, i):
    return (s >> i) & 1 == 1

def union(a, b):
    return a | b

def iterate(s):
    while s:
        low = s & (-s)
        i = low.bit_length() - 1
        yield i
        s ^= low
```

## 五、与其他技术对比
`set` 对象灵活但开销大；位掩码固定上限、运算常数极小，适合状态压缩 DP。

## 六、常见误区
- 元素下标超过字长导致溢出/截断（用 Python 大整数可缓解，但语义上仍应 ≤ 64）。
- 遍历后忘记清除当前位导致死循环。

## 九、演进与趋势

## 十、小结
