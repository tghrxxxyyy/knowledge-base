# 单比特操作：置位、清零、提取、翻转

> 对应 Warren《Hacker's Delight》第 2 章与 youngyangyang04/leetcode-master 位运算专题。

## 一、背景与挑战
底层寄存器、权限标志、位集需要单独修改某一位而不影响其他位。手工移位易错。

## 二、核心原理
- 置位：`x | (1 << k)`
- 清零：`x & ~(1 << k)`
- 翻转：`x ^ (1 << k)`
- 提取第 k 位：`(x >> k) & 1`

## 三、形式化与数学基础
设掩码 $M=1\ll k$。置位 $x\leftarrow x\lor M$；清零 $x\leftarrow x\land \neg M$；第 k 位值 $b_k = \lfloor x/2^k\rfloor \bmod 2$。

## 四、代码实现
```python
def set_bit(x, k):
    return x | (1 << k)

def clear_bit(x, k):
    return x & ~(1 << k)

def flip_bit(x, k):
    return x ^ (1 << k)

def get_bit(x, k):
    return (x >> k) & 1
```

## 五、与其他技术对比
相比用数组存布尔，位集省内存 8 倍以上，且可用整体位运算批量操作。

## 六、常见误区
- 清零用 `~(1<<k)` 时忘记它是按 int 全位取反（Python 无限长，需 `& mask` 限定宽度）。
- 左右移位数超出位宽导致未定义（C/C++）。
