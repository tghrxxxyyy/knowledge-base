# 位运算基础与补码表示

> 对应 Warren《Hacker's Delight》第 2 章与 youngyangyang04/leetcode-master 位运算专题。

## 一、背景与挑战
底层算法、状态压缩、权限位常直接用位运算。误解有符号数与补码会导致溢出与符号扩展错误。

## 二、核心原理
与 `&`、或 `|`、异或 `^`、取反 `~`、左移 `<<`、右移 `>>`。对无符号数右移补 0；对有符号数通常算术右移补符号位。

## 三、形式化与数学基础
补码：$x$ 的 $n$ 位表示为 $x \bmod 2^n$；负数 $-x$ 对应 $2^n - x$。取反加一：$-x = \sim x + 1$。

## 四、代码实现
```python
def is_power_of_two(x):
    # 仅当 x>0 且二进制只有一个 1
    return x > 0 and (x & (x - 1)) == 0

def negate(x):
    return ~x + 1  # 补码取负
```

## 五、与其他技术对比
位运算比乘除法更快（常数级），现代编译器常自动优化；但可读性差，关键路径才用。

## 六、常见误区
- 以为 `>>` 总是逻辑右移（Python 对负数 `>>` 是算术，但 C 中有符号未定义）。
- 左移溢出符号位导致未定义行为（C/C++）。
