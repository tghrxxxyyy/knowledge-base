# 复制回收

> 对应 Jones《GC Handbook》第 3 章（Copying GC / Cheney）。

## 一、背景与挑战
复制式 GC（如 Semispace、Cheney 算法）把存活对象从 from-space 拷到 to-space 并压缩。挑战：只用一半堆、需修正所有指针 (forwarding)。

## 二、核心原理
堆分两半；GC 时只扫描 from-space 存活对象，复制到 to-space 连续布局，留下 forwarding 指针修正引用。结束后交换半空间。

## 三、形式化 / 数学基础
Cheney 广度优先：scan/free 指针。复制 $o$ 得 $o'$ 并写 `forwarding[o]=o'`；更新引用处为 $o'$。存活成本 $\propto$ 存活量而非堆大小（仅复制存活）。

## 四、代码实现
```python
def cheney(roots, from_space):
    to = []; scan = 0
    def forward(o):
        if o.forward is None:
            o.forward = copy_to(o, to); 
        return o.forward
    roots[:] = [forward(r) for r in roots]
    while scan < len(to):
        obj = to[scan]; scan += 1
        for ref in obj.refs: ref = forward(ref)
```

## 五、与其他技术对比
- Copying：无碎片、快（只拷存活）、半空间浪费。
- Mark-Sweep：全堆、碎片。
- Mark-Compact：全堆但压缩、无半空间浪费。

## 六、常见误区
1. 忘记更新所有指向旧对象的指针（forwarding 必做）。
2. 以为复制 GC 用满堆（只用一半）。
3. 大对象复制成本高未设阈值。

## 九、演进与趋势
Appel 式复制（分代 + 大对象进 old gen）、以及 NUMA 感知复制。

## 十、小结
复制回收把存活对象紧凑搬移：以半空间为代价换无碎片与仅存活量复杂度，是分代年轻代的主流选择。
