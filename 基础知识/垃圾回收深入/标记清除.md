# 标记清除

> 对应 Jones《The Garbage Collection Handbook》与 Tanenbaum。

## 一、背景与挑战
标记-清除 (Mark-Sweep) 是最早的追踪式 GC：从根集合标记可达对象，清除未标记者。挑战：碎片、暂停时间、需遍历整个堆。

## 二、核心原理
两阶段：mark 从 GC roots（栈/全局）沿指针可达性标记；sweep 遍历堆回收未标记块并链入空闲表。不移动对象，故产生外部碎片。

## 三、形式化 / 数学基础
可达性：$R\ (\text{roots})\Rightarrow^*$ 可达对象集合 $M$。存活 $L=M$；回收 $H\setminus L$。标记用颜色/标记位。时间 $O(|H|)$。

## 四、代码实现
```python
def gc(roots, heap):
    marked = set()
    work = list(roots)
    while work:
        o = work.pop()
        if o not in marked:
            marked.add(o)
            work.extend(o.refs)
    for o in heap:
        if o not in marked:
            free(o)   # sweep
```

## 五、与其他技术对比
- Mark-Sweep：不移动、碎片多、实现简单。
- Copying：移动、无碎片、用一半空间。
- Mark-Compact：标记后压缩，兼顾二者。

## 六、常见误区
1. 以为标记清除会压缩（不会，留碎片）。
2. 漏根集合（线程局部/寄存器）致误回收。
3. 递归标记栈溢出（应显式栈或指针反转）。

## 九、演进与趋势
位图标记 (bitmap marking)、并发标记、以及惰性清扫 (lazy sweep) 平摊暂停。

## 十、小结
标记清除以"可达性"定义存活：实现最直观，但碎片与全堆遍历是其代价；是理解 GC 的起点。
