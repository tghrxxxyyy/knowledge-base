# 缓存层次结构与AMAT分析

> 对应 Bryant & O'Hallaron《CSAPP》第6章 存储器层次结构 / Hansimov/csapp (GitHub)。

## 一、背景与挑战
现代 CPU 与内存存在两个数量级的速度差。直接访问主存每次约 100ns，而 L1 命中约 1ns。若每条指令都访问主存，CPU 流水线将长期停顿。缓存通过时间与空间局部性隐藏延迟，但多级缓存带来命中率权衡问题。

## 二、核心原理
缓存由 SRAM 构成，按层级 L1/L2/L3 组织，容量递增、速度递减、核内私有到共享。访问时由高速缓存控制器进行标签(tag)、组索引(set index)、块偏移(block offset)匹配。缺失时向下层逐层查找并回写。平均内存访问时间 AMAT 是核心指标。

## 三、形式化与数学基础
单级缓存：
$$ AMAT = T_{hit} + (1 - h) \times T_{miss} $$
其中 $h$ 为命中率，$T_{hit}$ 命中时间，$T_{miss}$ 缺失代价。多级展开：
$$ AMAT = T_{L1} + (1-h_{L1}) \times (T_{L2} + (1-h_{L2}) \times T_{main}) $$
提升命中率比单纯降低 $T_{hit}$ 对 AMAT 影响更显著。

## 四、代码实现
```c
// 顺序访问以利用空间局部性，缓存行 64B 一次载入 16 个 int
#include <stdio.h>
#define N 1024
int a[N][N];
int sum_seq(int n) {
    int s = 0;
    for (int i = 0; i < n; i++)      // 外层行
        for (int j = 0; j < n; j++)
            s += a[i][j];            // 连续内存，命中率高
    return s;
}
```

## 五、与其他技术对比
软件预取把取数提前，但可能污染缓存；增大缓存行减少缺失但加剧伪共享；NUMA 本地内存类比缓存层级。相比纯寄存器重用，缓存是透明的硬件机制，无需改写算法结构。

## 六、常见误区
误以为缓存越大越好：容量增大导致命中时间上升、功耗增加。忽略冷启动缺失与容量缺失、冲突缺失的区别，盲目设大关联度反而降低速度。用指针链表遍历会破坏空间局部性。

## 七、与开源书/权威来源对应
《CSAPP》6.4 缓存通用组织；Hansimov/csapp 提供实验 lab；Hennessy & Patterson《Computer Architecture》第2章给出 AMAT 与平均等待时间公式。

## 八、面试题
AMAT 公式如何推导？为何矩阵按行访问比按列快？L1/L2/L3 命中时间数量级？冲突缺失与容量缺失如何区分？

## 九、演进与趋势
非包容/包容缓存、非均匀缓存访问(NUCA)、Intel 的 L4 eDRAM、以及面向 AI 的大容量末级缓存。硬件预取器越来越智能，但可编程缓存提示仍重要。

## 十、小结
缓存通过局部性隐藏内存延迟，AMAT 量化其收益。优化重点是提升命中率与访问局部性，而非单纯追求容量。
