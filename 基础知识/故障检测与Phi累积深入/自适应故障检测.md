# 自适应故障检测

> 对应 Hayashibara et al. 2004（自适应 Phi FD）与 Chandra & Toueg 1996。

## 一、背景与挑战
固定参数的 FD 难以适配时变网络（昼夜流量、跨区域、容器调度）。自适应 FD 在线调整心跳间隔、统计窗口与阈值，在「快速发现」与「低误判」间动态平衡。

## 二、核心原理
两层自适应：① 网络层——根据 RTT 分布动态设心跳间隔与超时；② 判定层——Phi 检测器持续用最新样本更新 μ 或 σ，使分布贴合当前网络。还可按「误判反馈」调阈值。

## 三、形式化与数学基础
目标最小化代价 \\(C = \alpha\cdot P_{miss} + \beta\cdot P_{false}\\)，其中漏检（真死未发现）与误判（活被判死）权重不同。自适应即在线调整 \\(\sigma\\) 估计与阈值 \\(\Phi_{th}\\) 使 \\(C\\) 最小。

## 四、代码实现
```python
class AdaptiveFD:
    def __init__(self): self.mu=0.0; self.sigma=1.0; self.window=[]
    def on_heartbeat(self, interval):
        self.window.append(interval); self.window=self.window[-100:]
        self.mu=sum(self.window)/len(self.window)
        self.sigma=(sum((x-self.mu)**2 for x in self.window)/len(self.window))**0.5
    def suspicion(self, gap, thr=8): return phi(gap,self.mu,self.sigma)>thr
```

## 五、与其他技术对比
静态 FD 参数固定、易失配；自适应 FD 贴合网络但实现复杂、需防样本污染；Raft 的选举超时随机化也是一种轻量自适应（避免集体重选）。

## 六、常见误区
1. 自适应等于自动万能：异常样本会误导，需鲁棒统计。
2. 调参过激：系统震荡，应平滑。
3. 忽略冷启动：初期样本少，φ 不可信，应设保护期。

## 七、与开源书/权威来源对应
Hayashibara 2004 提自适应 accrual；Raft 用随机化选举超时降低同步重选；DDIA 第8章强调网络时变。

## 八、面试题
问：自适应 FD 调什么？
答：在线更新心跳间隔、统计分布（μ 或 σ）与判定阈值，平衡漏检与误判代价。

## 九、演进与趋势
用在线学习或贝叶斯更新做更精细的分布建模，并向「每链路独立模型」发展。

## 十、小结
自适应故障检测以在线统计贴合时变网络，在发现速度与误判率间动态寻优，是生产级 FD 的必然形态。
