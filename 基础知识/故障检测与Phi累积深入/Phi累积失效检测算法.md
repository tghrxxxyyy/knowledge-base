# Phi累积失效检测算法

> 对应 Hayashibara et al. 2004（Phi Accrual Failure Detector，常被归入 Cassandra 采用）与 Chandra & Toueg 1996。

## 一、背景与挑战
固定超时 FD 在网络抖动时误判率高。Phi 累积检测器改为输出「怀疑程度 φ」：基于历史心跳间隔的分布（均值或方差）计算「当前间隔下节点仍存活的概率对数」，使检测自适应网络状况。

## 二、核心原理
记录心跳到达间隔的样本，维护其均值 \\(\mu\\) 与方差 \\(\sigma^2\\)。给定当前无心跳时长 \\(t\\)，计算
\\[
\Phi(t) = -\log_{10}(1 - F(t))
\\]
其中 \\(F\\) 为正常间隔的累积分布（常用正态分布近似）。\\(\Phi\\) 越大越可疑，超过阈值（如 8 或 10）即判死。

## 三、形式化与数学基础
若间隔近似正态 \\(N(\mu,\sigma^2)\\)，则
\\[
\Phi(t) = -\log_{10}\left(1 - \Phi_{std}\left(\frac{t-\mu}{\sigma}\right)\right)
\\]
其中 \\(\Phi_{std}\\) 为标准正态 CDF。φ=8 表示「按历史分布，当前间隔发生的概率约 \\(10^{-8}\\)」，极强证据。

## 四、代码实现
```python
import math
def phi(t, mu, sigma):
    z = (t - mu) / sigma
    # 标准正态 CDF 近似
    p = 0.5 * (1 + math.erf(z / math.sqrt(2)))
    return -math.log10(1 - p + 1e-15)
```

## 五、与其他技术对比
固定超时是 φ 检测在「σ 趋于 0 且阈值固定」的退化；φ 检测对慢网络更宽容、对真死更敏感，误判率显著低于固定阈值。

## 六、常见误区
1. 阈值设太小：抖动即误判；太大：真死发现慢。
2. 样本含历史异常值：污染 μ 或 σ，应做窗口或截尾。
3. 用单边分布假设于双峰网络：应分时段建模。

## 七、与开源书/权威来源对应
Hayashibara 等人提出 accrual FD；Cassandra 文档描述其 Phi 检测器参数；Chandra & Toueg 1996 提供理论框架。

## 八、面试题
问：φ 值含义？
答：φ = -log10(存活概率)，越大表示按历史分布当前无心跳越异常，越可能已死。

## 九、演进与趋势
自适应窗口、非参数分布（如 ECDF）提升对复杂网络的拟合。

## 十、小结
Phi 累积检测器用统计信心替代固定阈值，在抖动与灵敏间取得更优平衡。
