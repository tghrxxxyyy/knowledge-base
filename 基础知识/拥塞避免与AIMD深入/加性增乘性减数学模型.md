# 加性增乘性减数学模型

> 对应 Chiu & Jain 1989 (AIMD 公平性分析) 与 Kelly 流体模型；参考 Jacobson 1988。

## 一、背景与挑战
为何 AIMD 能让多个竞争流公平共享？可用二维相图与收敛性分析严格证明。

## 二、核心原理
将各流窗口画在相图上：AI 沿 45° 线右上（和增），MD 沿对角线反射（积减）。不动点即公平线 x=y 上的交点。

## 三、形式化与数学基础
两流窗口 (x,y)，瓶颈容量 W：
  AI:  x += a, y += a        (沿 x+y 增)
  MD:  (x,y) -> (bx, by)     (b=0.5, 沿过原点射线缩放)
公平性指数（Jain's index）：
  J = (Σx_i)^2 / (n * Σx_i^2)   in [1/n, 1]
AIMD 使 J 随迭代趋近 1（完全公平）。

## 四、代码实现
# 模拟两流 AIMD 收敛
x, y, W = 1, 1, 20
for _ in range(200):
    if x + y < W:
        x += 1; y += 1            # AI
    else:
        x *= 0.5; y *= 0.5        # MD
print(x, y)                       # 收敛到 ~W/2, W/2

## 五、与其他技术对比
MIMD 在公平线附近震荡不收敛；AIAD 发散。AIMD 是少数收敛到公平的稳定组合。

## 六、常见误区
1. 认为公平点等于最大吞吐——AIMD 牺牲部分利用换公平。
2. RTT 不同的流会偏向小 RTT 流（RTT 不公平）。
