# 主席树可持久化线段树

> 对应 CyC2018/CS-Notes。

## 一、背景与挑战
需要查询「某个历史版本」或「区间第 k 小」时，普通线段树会被覆盖。可持久化（主席树）保留每次修改后的版本。

## 二、核心原理
每次修改只新建被影响路径上的节点，未改动的子树与旧版本共享，从而以 $O(\log n)$ 空间代价复制出一个新根。

## 三、形式化与数学基础
每个版本 $O(\log n)$ 新节点；值域线段树 + 版本根数组可回答静态区间第 k 小：
$T_{\rm build}=O(n\log n),\;T_{\rm query}=O(\log n)$。

## 四、代码实现
```python
class PNode:
    def __init__(self, val=0):
        self.val = val
        self.left = None
        self.right = None
def insert_pst(node, l, r, idx, delta):
    new = PNode(node.val if node else 0)
    if l == r:
        new.val += delta
        return new
    mid = (l + r) // 2
    if idx <= mid:
        new.left = insert_pst(node.left if node else None, l, mid, idx, delta)
        new.right = node.right if node else None
    else:
        new.left = node.left if node else None
        new.right = insert_pst(node.right if node else None, mid + 1, r, idx, delta)
    new.val = (new.left.val if new.left else 0) + (new.right.val if new.right else 0)
    return new
```

## 五、与其他技术对比
相比每版本完整拷贝（$O(n)$），主席树共享未变子树仅 $O(\log n)$。适合离线区间第 k 小。

## 六、常见误区
忘记把未改的子树指针指向旧节点会丢失数据；离散化后值域要映射到排名。

## 八、面试题
用主席树求静态区间第 k 小；为何空间是 $O(n\log n)$？

## 九、演进与趋势
函数式持久化数据结构在版本管理、时空查询中应用广泛。

## 十、小结
主席树通过共享未变子树，以 $O(\log n)$ 代价保留版本，是区间第 k 小等问题的标准解。
