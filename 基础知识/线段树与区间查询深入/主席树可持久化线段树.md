# 主席树可持久化线段树

> 对应 N. S. V. 可持久化数据结构经典思想（Driscoll et al. 1989, *Making Data Structures Persistent*）、区间第 $k$ 小的主席树（Functional Segment Tree）标准解法，以及 OI Wiki「可持久化线段树」条目。

## 一、背景与挑战

有一类问题必须**同时访问历史版本**：数组在时间 $t_1, t_2, \dots$ 被单点修改，需要随时回答"在第 $i$ 个版本的数组上，区间 $[L,R]$ 的第 $k$ 小是谁"。若每次修改都复制整棵线段树，空间 $O(q\cdot n)$，$n,q \approx 10^5$ 时直接爆掉；若只保留最新版本，又回答不了历史查询。

可持久化线段树（主席树，Functional/Persistent Segment Tree）用**节点共享**解决这对矛盾：每次单点更新只新建从根到叶的 $O(\log n)$ 个节点，其余子树与旧版本共享指针。于是版本 $t$ 与版本 $t-1$ 共享几乎所有节点，空间 $O(n + q\log n)$；查询任一版本都是一次 $O(\log n)$ 的普通线段树查询。

区间第 $k$ 小是它的招牌应用：对每个前缀 $1..i$ 建一棵权值线段树 `root[i]`，查询 $[L,R]$ 的第 $k$ 小时，用 `root[R]` 与 `root[L-1]` 两棵权值树"相减"——左子树计数差 `c`，若 $k \le c$ 走左，否则 $k \leftarrow k-c$ 走右。这正是"区间可差分 + 权值计数"的组合。

在面试中，主席树是"如何用 $O(n\log n)$ 空间回答区间第 $k$ 小"的标准答案，常与划分树、归并树对比。在工程里，它对应数据库 MVCC 的多版本索引、审计回放、快照隔离下的区间统计、以及"只追加、需历史"的时序查询。

## 二、核心原理

**版本共享。** 把线段树写成"节点有左右指针"的形式。更新时复制路径上的节点（新节点的左右孩子大多指向旧节点），未修改的子树直接复用旧指针。因此版本 $v$ 的根到叶路径是新的，其余部分与 $v-1$ 物理共享。

**权值线段树视角。** 下标是"值域"，节点存该值域内元素出现次数。插入元素 $x$：沿值域走到叶子 `cnt++`，回溯 pushup（计数求和）。

**前缀版本。** 按 $i=1..n$ 依次把 `a[i]` 插入，得到前缀版本 `root[i]`。`root[i]` 表示 `a[1..i]` 的权值分布。

**区间第 $k$ 小。** 区间 $[L,R]$ 的多重集恰好是 `a[1..R]` 去掉 `a[1..L-1]`。两棵权值树对应相减：

$$
cnt_{[L,R]}(v) = cnt_{root[R]}(v) - cnt_{root[L-1]}(v).
$$

查询递归：当前值域 $[lo,hi]$ 的左子树计数差 $c = cnt(root[R].l) - cnt(root[L-1].l)$；若 $k \le c$ 走左，否则 $k \leftarrow k-c$ 走右。到叶子返回该值。

**为什么正确。** 权值计数可差分；两棵树减出来就是区间计数；二分下钻的每一步都把"第 $k$ 小"缩到更小的值域区间，最终落到唯一叶子。

**边界条件。** `root[0]` 是空树（全 0）；$k$ 超过区间长度时无解；值域先离散化（$n \le 10^5$ 时离散到 $1..n$）或用动态开点值域 $[1, 10^9]$。

**空间。** 每次插入新建 $O(\log n)$ 节点，$n$ 次插入共 $O(n\log n)$ 节点，加 $n+1$ 个根指针。

## 三、形式化与数学基础

**节点共享引理。** 更新一条根到叶路径上新建 $h=O(\log n)$ 个节点，其余 $O(n)$ 节点与旧版本共享。故

$$
S_{\text{total}} = \sum_{i=1}^{n} O(\log n) = O(n\log n).
$$

**查询复杂度。** `root[R]` 与 `root[L-1]` 同步下钻一次，路径长 $O(\log n)$，故

$$
T_{\text{query}} = O(\log n), \quad T_{\text{build}} = O(n\log n), \quad S = O(n\log n).
$$

**与划分树对比。** 划分树预处理 $O(n\log n)$ 空间、$O(\log n)$ 查询，但不支持修改；主席树支持在线插入与历史版本，空间略大但更通用。

**区间第 $k$ 小的正确性归纳。** 设当前值域 $[lo,hi]$，左半 $[lo,mid]$ 在区间内的出现次数为 $c$。若 $k \le c$，则第 $k$ 小必在左半；否则在右半且是右半的第 $k-c$ 小。归纳到叶子即得。 $\square$

**持久化的通用技术。** Driscoll 等人给出节点复制的通用框架：结点复制代价 $O(1)$，路径复制 $O(\log n)$，空间增量 $O(\log n)$/更新。主席树是它在权值统计上的实例。

**区间最值的可持久化。** 若节点存 `mx` 而非 `cnt`，"相减"不成立（max 不可差分）。此时要改用"区间内最大值的二分 + 计数"或主席树维护可差分信息。这是常见追问。

## 四、代码实现

完整可运行的主席树：离散化 + 前缀版本 + 区间第 $k$ 小。

```python
# 主席树（可持久化权值线段树）：区间第 k 小
class PNode:
    __slots__ = ('l', 'r', 'cnt')

    def __init__(self, l=None, r=None, cnt=0):
        self.l = l
        self.r = r
        self.cnt = cnt


class ChairmanTree:
    """静态区间第 k 小：建 n 个前缀版本。值域离散化到 [0, m-1]。"""

    def __init__(self, arr):
        self.n = len(arr)
        self.sorted = sorted(set(arr))
        self.rank = {v: i for i, v in enumerate(self.sorted)}
        self.m = len(self.sorted)
        self.roots = [None] * (self.n + 1)
        self.roots[0] = self._build(0, self.m - 1)
        for i, x in enumerate(arr, 1):
            self.roots[i] = self._update(self.roots[i - 1], 0, self.m - 1, self.rank[x])

    def _build(self, L, R):
        p = PNode()
        if L == R:
            return p
        mid = (L + R) // 2
        p.l = self._build(L, mid)
        p.r = self._build(mid + 1, R)
        return p

    def _update(self, prev, L, R, x):
        """基于 prev 新建版本，在 x 处计数 +1。"""
        p = PNode(prev.l, prev.r, prev.cnt + 1)
        if L == R:
            return p
        mid = (L + R) // 2
        if x <= mid:
            p.l = self._update(prev.l, L, mid, x)
        else:
            p.r = self._update(prev.r, mid + 1, R, x)
        return p

    def kth(self, L, R, k):
        """返回 arr[L..R]（1-based 闭区间）中第 k 小的值。"""
        return self._kth(self.roots[L - 1], self.roots[R], 0, self.m - 1, k)

    def _kth(self, u, v, L, R, k):
        if L == R:
            return self.sorted[L]
        mid = (L + R) // 2
        left_cnt = v.l.cnt - u.l.cnt
        if k <= left_cnt:
            return self._kth(u.l, v.l, L, mid, k)
        return self._kth(u.r, v.r, mid + 1, R, k - left_cnt)


if __name__ == '__main__':
    arr = [5, 2, 6, 3, 1, 4, 2]
    ct = ChairmanTree(arr)
    # 区间 [1,7] 第 1..7 小
    assert [ct.kth(1, 7, i) for i in range(1, 8)] == sorted(arr)
    # 区间 [2,5] = [2,6,3,1] → [1,2,3,6]
    assert ct.kth(2, 5, 1) == 1
    assert ct.kth(2, 5, 2) == 2
    assert ct.kth(2, 5, 3) == 3
    assert ct.kth(2, 5, 4) == 6
    # 区间 [3,3] 只有 6
    assert ct.kth(3, 3, 1) == 6
    print('chairman ok', ct.kth(1, 7, 4))
```

若不用离散化，可把 `_build`/`_update` 的值域换成动态开点的 $[1, 10^9]$，并把 `rank[x]` 换成原值；本质相同。

实现细节：`PNode(prev.l, prev.r, prev.cnt+1)` 是"复制节点并计数 +1"；`_kth` 同时拿 `u=root[L-1]` 与 `v=root[R]`，用 `v.l.cnt - u.l.cnt` 得区间左子树计数。离散化保证 $m \le n$。

## 五、与其他技术对比

| 方法 | 预处理 | 查询 | 修改 | 空间 | 备注 |
|------|--------|------|------|------|------|
| 每次排序 | $O(n\log n)$/查询 | $O(n\log n)$ | 任意 | $O(n)$ | 仅暴力 |
| 划分树 | $O(n\log n)$ | $O(\log n)$ | 不支持 | $O(n\log n)$ | 静态区间第 $k$ 小 |
| 归并树 | $O(n\log n)$ | $O(\log^2 n)$ | 不支持 | $O(n\log n)$ | 二分 + 归并段 |
| 主席树 | $O(n\log n)$ | $O(\log n)$ | 在线单点插入 | $O(n\log n)$ | 支持历史版本 |
| 树状数组 + 二分 | $O(n)$ | $O(\log^2 n)$ | 支持 | $O(n)$ | 离散化后在线 |
| 平衡树套权值 | $O(n\log n)$ | $O(\log^2 n)$ | 支持 | $O(n)$ | 常数大 |

取舍：静态只查用划分树（常数小）；要历史/在线插入用主席树；要任意区间修改用树套树。面试标准答案是主席树。

## 六、常见误区

1. **每次都复制整棵树。** 新建节点只应沿路径 $O(\log n)$ 个；若 `build` 全量复制，空间 $O(n^2)$，完全失去可持久化意义。
2. **区间第 $k$ 小忘记用两个版本相减。** 只用 `root[R]` 会算成前缀第 $k$ 小；必须 `root[R]` 与 `root[L-1]` 同步下钻。
3. **max/sum 直接相减。** `sum` 可差分，`max` 不可。若维护最值，不能套用"两树相减"的模板。
4. **离散化后忘了映射回原值。** `kth` 落到叶子返回的是 `sorted[L]`（原值），不是 rank。
5. **`root[0]` 忘记初始化为空树。** 查询 `L=1` 时会解引用 `None`；必须建一个全 0 的初始根或在 `_kth` 中判空。
6. **`k` 越界不检查。** $k > R-L+1$ 时下钻会踩到空节点或返回错误值。

## 八、面试题

**1. 如何用 $O(n\log n)$ 空间回答多次"区间第 $k$ 小"？**
参考答案：主席树。对每个前缀建可持久化权值线段树 `root[i]`；查询 $[L,R]$ 第 $k$ 小时同步遍历 `root[R]` 与 `root[L-1]`，按左子树计数差二分下钻。

**2. 为什么空间是 $O(n\log n)$ 而不是 $O(n^2)$？**
参考答案：每次单点更新只新建根到叶 $O(\log n)$ 个节点，其余子树与上一版本共享；$n$ 次插入共 $O(n\log n)$ 个节点。

**3. 主席树与划分树的区别？**
参考答案：划分树是静态的，预处理后 $O(\log n)$ 查询但不支持修改；主席树支持在线插入与历史版本，空间略大。两者查询都 $O(\log n)$。

**4. 区间最大值能否用两版本相减？**
参考答案：不能。max 不可差分。可改用（a）带修线段树直接查；（b）主席树维护"值域计数 + 二分判定最大值 $\le x$"；（c）划分树/ST 表。

## 九、演进与趋势

主席树的进阶方向：**可持久化数组**（用主席树下标做版本化数组）、**可持久化 Trie**（区间异或第 $k$ 大）、**可持久化并查集/平衡树**、**线段树分裂合并的可持久化版**、**树套树 + 可持久化**（区间第 $k$ 小带修改）。工程上，MVCC 多版本索引、数据库快照、审计回放、时间旅行查询都用同一"路径复制 + 共享"思想。面试趋势稳定在"区间第 $k$ 小 + 空间分析 + 与划分树对比"。

## 十、小结

主席树用路径复制实现可持久化权值线段树，以 $O(n\log n)$ 空间保留全部前缀版本，借助"两版本计数相减"在 $O(\log n)$ 内回答区间第 $k$ 小；它是可持久化思想在区间统计上的最经典落地，也是划分树、树套树等结构的比较基准。
