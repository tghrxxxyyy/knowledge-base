# 线段树合并

> 对应 youngyangyang04/leetcode-master。

## 一、背景与挑战
在多棵线段树（如树上每个子树一棵权值树）间需要把两棵树信息合并，例如统计子树中某种权值的总数。

## 二、核心原理
递归合并两棵树对应节点：空树直接返回另一棵；都非空则值相加，并递归合并左右子树。常用于 DFS 回溯时把子节点树并入父节点。

## 三、形式化与数学基础
单次合并与公共节点数成正比；在树形结构上总合并代价摊还 $O(n\log U)$：
$T_{\rm total}=O(n\log U)$。

## 四、代码实现
```python
class SegNode:
    def __init__(self):
        self.val = 0
        self.left = None
        self.right = None
def merge_seg(a, b, l, r):
    if not a:
        return b
    if not b:
        return a
    node = SegNode()
    if l == r:
        node.val = a.val + b.val
        return node
    mid = (l + r) // 2
    node.left = merge_seg(a.left, b.left, l, mid)
    node.right = merge_seg(a.right, b.right, mid + 1, r)
    node.val = (node.left.val if node.left else 0) + (node.right.val if node.right else 0)
    return node
```

## 五、与其他技术对比
相比把两树所有元素重新插入一棵，合并复用结构更高效；常用于树上启发式合并的替代。

## 六、常见误区
合并后未释放/丢弃旧节点造成内存泄漏；未正确累加 `val` 导致统计错误。
