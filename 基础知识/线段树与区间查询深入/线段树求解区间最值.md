# 线段树求解区间最值

> 对应 CLRS。

## 一、背景与挑战
RMQ（Range Minimum/Maximum Query）在金融、图像处理中常见。线段树以合并取最值回答区间查询。

## 二、核心原理
内部节点存区间最大（或最小）值，合并即取左右子节点极值。查询时把区间拆成 $O(\log n)$ 个标准节点取极值。

## 三、形式化与数学基础
建树 $O(n)$，单次查询 $O(\log n)$。若只需静态 RMQ，可用稀疏表做到 $O(1)$ 查询、$O(n\log n)$ 预处理。

## 四、代码实现
```python
class MaxSeg:
    def __init__(self, arr):
        self.n = len(arr)
        self.tree = [float("-inf")] * (4 * self.n)
        self._build(arr, 1, 0, self.n - 1)
    def _build(self, arr, node, l, r):
        if l == r:
            self.tree[node] = arr[l]; return
        mid = (l + r) // 2
        self._build(arr, node * 2, l, mid)
        self._build(arr, node * 2 + 1, mid + 1, r)
        self.tree[node] = max(self.tree[node * 2], self.tree[node * 2 + 1])
    def query(self, ql, qr, node=1, l=0, r=None):
        if r is None: r = self.n - 1
        if ql > r or qr < l: return float("-inf")
        if ql <= l and r <= qr: return self.tree[node]
        mid = (l + r) // 2
        return max(self.query(ql, qr, node * 2, l, mid),
                   self.query(ql, qr, node * 2 + 1, mid + 1, r))
```

## 五、与其他技术对比
线段树支持动态修改；稀疏表仅静态但查询 $O(1)$。笛卡尔树把 RMQ 与 LCA 归约，可 $O(1)$ 查询。

## 六、常见误区
空区间返回初值要用 `-inf`（最大）或 `+inf`（最小）；混用会导致错误极值。

## 七、与开源书/权威来源对应
CLRS 第 14 章与 RMQ 讨论；Sedgewick《Algorithms》区间最值。

## 八、面试题
实现动态 RMQ；稀疏表与线段树取舍？

## 九、演进与趋势
与稀疏表、笛卡尔树结合在各场景取最优查询/预处理权衡。

## 十、小结
线段树以极值合并回答 RMQ，动态场景下查询 $O(\log n)$，是区间最值通用方案。
