# 线段树求解区间最值

> 对应 Harel & Tarjan (1984) 关于静态 RMQ 的结构、Bender & Farach-Colton (2000) LCA/RMQ 归约，以及 OI Wiki「ST 表」与线段树对比条目。

## 一、背景与挑战

在所有区间统计里，最值查询出现得最早也最频繁：从教科书上的 RMQ 习题，到监控系统里"最近五分钟最大值"，再到游戏里某个矩形区域内的最高攻击力，本质上都是同一件事。它看似只需要 `max`，却牵出一整套数据结构取舍：静态还是动态、能不能预处理、要不要配合区间修改。

区间最值查询（RMQ, Range Minimum/Maximum Query）是出现频率最高的区间统计之一：股票区间极值、传感器窗口最大值、滑动窗口最值、区间限制下的最近公共祖先（LCA 可归约到 RMQ）都靠它。朴素做法每次扫描区间 $O(n)$，滑动窗口 $O(n)$ 次查询就是 $O(n^2)$。ST 表用倍增做到查询 $O(1)$、预处理 $O(n\log n)$，但**不支持修改**；一旦数组要变，ST 表整表重建 $O(n\log n)$，无法承受。

线段树把 RMQ 做成"可合并信息"的特例：节点存 $[l,r]$ 的最大值，`tree[p] = max(tree[2p], tree[2p+1])`。单点更新 $O(\log n)$，区间查询 $O(\log n)$，并可自然扩展到"区间最值 + 区间加"（懒标记）甚至"区间最值 + 单点修改"的动态场景。它是"静态 RMQ 与动态 RMQ 之间"的标准解。

在面试里，"实现一个可修改的区间最大值结构"是检验线段树是否真正掌握的常见题；追问"和 ST 表比怎么样"则考察取舍判断。工程上，监控系统的滑动窗口极值、游戏战斗数值的区间 buff 上限、风控的窗口峰值检测都依赖动态 RMQ。

## 二、核心原理

**信息定义。** 每个节点存两个值（或只存其一）：区间最大值 `mx`，有时还存最小值 `mn`。合并：

$$
mx[p] = \max(mx[2p],\ mx[2p+1]).
$$

单位元是 $-\infty$（查询无交时返回它，保证 `max` 不受影响）。

**建树与更新。** 与区间和完全同构：叶子写 `arr[l]`，pushup 取 max；单点更新后沿路径 pushup。复杂度 $O(\log n)$。

**查询。** $[L,R]$ 与节点 $[l,r]$ 三种关系：无交返回 $-\infty$；完全包含返回 `mx[p]`；部分相交递归取 max。访问节点 $O(\log n)$ 个。

**区间加 + 区间最值。** 加懒标记 `add`：整段加 $x$ 时 `mx[p] += x`（整体抬升），`lazy[p] += x`；pushdown 时对儿子同样 `mx += x`。这是懒标记在最值上的典型作用，注意**不是** `mx = max(mx, x)`。

**为什么正确。** max 满足结合律与交换律，分段 max 等于整体 max；懒标记抬升不改变区间内元素的相对大小顺序，故 max 同步抬升即可，无需重算。

**与"区间赋值 + 区间最值"。** 赋值 $v$ 直接令 `mx[p] = v`（区间被 $v$ 覆盖，最大值就是 $v$）；下传时子节点 `mx = v` 且清空 add 标记。

**边界。** 单元素区间 max 就是自身；全负数数组时单位元必须是 $-\infty$ 而不是 0；若求"严格次大值"（吉司机线段树），还要额外维护 `se`（严格小于 mx 的最大值）与 `cnt`（mx 个数）。

## 三、形式化与数学基础

**RMQ 与 LCA 归约。** 任意树的 LCA 可在 $O(n)$ 预处理后归约到 $\pm1$-RMQ；RMQ 的动态版本正是线段树。这说明 RMQ 不是孤立问题，而是树上查询的核心构件。

**复杂度。**

$$
T_{\text{build}} = O(n),\quad T_{\text{update}} = O(\log n),\quad T_{\text{query}} = O(\log n),\quad S = O(n).
$$

与 ST 表对比：ST 表 $T_{\text{build}} = O(n \log n)$、$T_{\text{query}} = O(1)$、不可修改。设 $q$ 次操作，线段树总代价 $O((n+q)\log n)$，ST 表在可修改时退化为 $O(q n \log n)$。

**max 懒标记的代数。** 区间加的作用是平移：对多重集 $A$，$A+x = \{a+x\}$，则 $\max(A+x) = \max(A)+x$。故

$$
mx \leftarrow mx + x
$$

正确。对区间赋值 $v$：$\max(\{v\}) = v$。

**严格次大值（吉司机）。** 维护 $mx, se, cnt$，区间加只动 `mx`/`se` 的加法偏移；区间取模时若 $mx < mod$ 剪枝，否则对"值等于 mx 的叶子"暴力，均摊 $O(\log n)$。这是线段树最值的进阶证明，面试偶有提及。

**查询节点数引理。** 与区间和相同：部分相交节点构成两条路径，$O(\log n)$ 个完全包含节点，总访问 $O(\log n)$。

## 四、代码实现

完整可运行：区间最值 + 单点修改 + 区间加（懒标记）。

```python
# 线段树：区间最大值 / 最小值 + 单点修改 + 区间加（懒标记）
NEG_INF = float('-inf')


class MaxSegTree:
    def __init__(self, arr):
        self.n = len(arr)
        self.mx = [NEG_INF] * (4 * self.n)
        self.lazy = [0] * (4 * self.n)
        self._build(arr, 1, 0, self.n - 1)

    def _build(self, arr, p, l, r):
        if l == r:
            self.mx[p] = arr[l]
            return
        mid = (l + r) // 2
        self._build(arr, p * 2, l, mid)
        self._build(arr, p * 2 + 1, mid + 1, r)
        self._pushup(p)

    def _pushup(self, p):
        self.mx[p] = max(self.mx[p * 2], self.mx[p * 2 + 1])

    def _apply_add(self, p, x):
        self.mx[p] += x
        self.lazy[p] += x

    def _pushdown(self, p):
        if self.lazy[p]:
            self._apply_add(p * 2, self.lazy[p])
            self._apply_add(p * 2 + 1, self.lazy[p])
            self.lazy[p] = 0

    def point_set(self, idx, val):
        self._point_set(1, 0, self.n - 1, idx, val)

    def _point_set(self, p, l, r, idx, val):
        if l == r:
            self.mx[p] = val
            self.lazy[p] = 0
            return
        self._pushdown(p)
        mid = (l + r) // 2
        if idx <= mid:
            self._point_set(p * 2, l, mid, idx, val)
        else:
            self._point_set(p * 2 + 1, mid + 1, r, idx, val)
        self._pushup(p)

    def range_add(self, L, R, x):
        self._range_add(1, 0, self.n - 1, L, R, x)

    def _range_add(self, p, l, r, L, R, x):
        if R < l or r < L:
            return
        if L <= l and r <= R:
            self._apply_add(p, x)
            return
        self._pushdown(p)
        mid = (l + r) // 2
        self._range_add(p * 2, l, mid, L, R, x)
        self._range_add(p * 2 + 1, mid + 1, r, L, R, x)
        self._pushup(p)

    def query_max(self, L, R):
        return self._query(1, 0, self.n - 1, L, R)

    def _query(self, p, l, r, L, R):
        if R < l or r < L:
            return NEG_INF
        if L <= l and r <= R:
            return self.mx[p]
        self._pushdown(p)
        mid = (l + r) // 2
        return max(self._query(p * 2, l, mid, L, R),
                   self._query(p * 2 + 1, mid + 1, r, L, R))


class MinMaxSegTree:
    """同时维护区间最小与最大。"""
    def __init__(self, arr):
        self.n = len(arr)
        self.mn = [float('inf')] * (4 * self.n)
        self.mx = [float('-inf')] * (4 * self.n)
        self._build(arr, 1, 0, self.n - 1)

    def _build(self, arr, p, l, r):
        if l == r:
            self.mn[p] = self.mx[p] = arr[l]
            return
        mid = (l + r) // 2
        self._build(arr, p * 2, l, mid)
        self._build(arr, p * 2 + 1, mid + 1, r)
        self._pushup(p)

    def _pushup(self, p):
        self.mn[p] = min(self.mn[p * 2], self.mn[p * 2 + 1])
        self.mx[p] = max(self.mx[p * 2], self.mx[p * 2 + 1])

    def query(self, L, R):
        return self._query(1, 0, self.n - 1, L, R)

    def _query(self, p, l, r, L, R):
        if R < l or r < L:
            return (float('inf'), float('-inf'))
        if L <= l and r <= R:
            return (self.mn[p], self.mx[p])
        mid = (l + r) // 2
        a = self._query(p * 2, l, mid, L, R)
        b = self._query(p * 2 + 1, mid + 1, r, L, R)
        return (min(a[0], b[0]), max(a[1], b[1]))


if __name__ == '__main__':
    arr = [5, 2, 8, 1, 9, 3]
    st = MaxSegTree(arr)
    assert st.query_max(0, 5) == 9
    assert st.query_max(0, 2) == 8
    assert st.query_max(3, 4) == 9
    st.point_set(4, -100)
    assert st.query_max(0, 5) == 8
    st.range_add(0, 2, 10)         # [15, 12, 18]
    assert st.query_max(0, 2) == 18
    assert st.query_max(0, 5) == 18
    mm = MinMaxSegTree([3, -1, 4, 1, 5, 9])
    assert mm.query(1, 4) == (-1, 5)
    assert mm.query(0, 5) == (-1, 9)
    print('range-max ok', st.query_max(0, 5))
```

实现细节：`NEG_INF` 作单位元；区间加用 `_apply_add` 抬升 `mx`；`point_set` 下钻前 pushdown 并清叶子 lazy。

## 五、与其他技术对比

| 结构 | 预处理 | 查询 | 修改 | 备注 |
|------|--------|------|------|------|
| 朴素扫描 | $O(1)$ | $O(n)$ | $O(1)$ | 仅少量查询 |
| ST 表 | $O(n\log n)$ | $O(1)$ | 不支持 | 静态 RMQ 最优 |
| 线段树 | $O(n)$ | $O(\log n)$ | $O(\log n)$ | 动态 RMQ 标配 |
| 树状数组（前缀 max） | $O(n)$ | $O(\log n)$ | $O(\log n)$ | 只支持前缀，不支持任意区间 max |
| 单调队列（滑动窗口） | $O(n)$ | 摊还 $O(1)$ | 不支持 | 固定窗口长 |
| 平衡树 | $O(n)$ | $O(\log n)$ | $O(\log n)$ | 可按值分裂 |

取舍：静态只查询用 ST 表；数组会改用线段树；固定窗口滑动最值用单调队列；要区间 max + 区间加用懒标记线段树。

## 六、常见误区

1. **无交返回 0。** 对 max 查询，数组全负数时答案会被 0 污染成 0。必须返回 $-\infty$（或用 `None` 显式判断）。
2. **区间加时写成 `mx[p] = max(mx[p], x)`。** 这是"区间取 max"语义，不是"区间加"。区间加应 `mx[p] += x`。
3. **求"最大子段和"却以为维护区间 max 就够。** 最大子段和需要维护 `sum, pre, suf, best` 四元组，仅 `max` 不够。
4. **ST 表与线段树混用却不提修改限制。** 面试追问"数组会变吗"必须答清楚；若会变，ST 表不适用。
5. **同时维护 min 与 max 时 pushup 只更新其中一个。** 导致另一指标陈旧。每个 pushup 必须覆盖所有聚合字段。

## 八、面试题

**1. 实现可修改的区间最大值结构。**
参考答案：见 `MaxSegTree`，单点改 $O(\log n)$，查询 $O(\log n)$。`tree[p]=max(左,右)`，无交返回 $-\infty$。

**2. 线段树与 ST 表在 RMQ 上怎么选？**
参考答案：只读查询多用 ST 表（$O(1)$ 查询）；有修改用线段树。混合场景（偶发修改、大量查询）可改用线段树，或分块重建。

**3. 区间加与区间最大值能否同时支持？复杂度？**
参考答案：可以，懒标记区间加时 `mx += x`。每次操作仍 $O(\log n)$，空间 $O(n)$。

**4. 如何求区间最大子段和？**
参考答案：节点维护四元组 `sum, pre, suf, best`。合并：`sum=s1+s2`，`pre=max(s1.pre, s1.sum+s2.pre)`，`suf=max(s2.suf, s2.sum+s1.suf)`，`best=max(s1.best, s2.best, s1.suf+s2.pre)`。单点/区间修改需懒标记同步更新这四个字段。

## 九、演进与趋势

区间最值虽是线段树最简单的可合并信息之一，但它却是许多高阶结构的基石：树链剖分把树上路径拆成区间后查极值；扫描线用区间最值处理轮廓高度；笛卡尔树与单调栈可以在静态场景下替代线段树求最近更大元素。理解最值的合并语义，是走向这些结构的前提。

最值线段树的进阶包括：**吉司机线段树**（区间取模/区间 chmin/chmax 均摊 $O(\log n)$）、**猫树**（静态区间最值 $O(1)$ 查询且可加历史信息）、**线段树分裂合并**处理可重集最值、**树剖 + 最值**做树上路径极值。工程上，监控告警的滑动峰值、游戏技能范围的极值结算、数据库的 ZoneMap/Bloom 之外的段级 min/max 过滤都用同一抽象。面试趋势稳定在"动态 RMQ + 与 ST 表对比 + 最大子段和四元组"三问。

## 十、小结

回顾全文：区间最值的难点不在"取 max"这个动作，而在于如何在支持修改的前提下把查询降到对数级，以及如何与懒标记正确组合。把单位元、pushup 公式、标记作用这三件事写对，动态 RMQ 就稳了。

线段树把 RMQ 变成可合并信息的特例：`mx = max(左, 右)`，单点改与区间查都是 $O(\log n)$，并能与懒标记组合支持区间加抬升；相对 ST 表牺牲常数换来可修改性，是动态区间最值问题的默认答案。
