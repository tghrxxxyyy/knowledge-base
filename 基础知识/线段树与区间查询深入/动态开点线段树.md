# 动态开点线段树

> 对应 TheAlgorithms/Python。

## 一、背景与挑战
值域很大（如 $10^9$）但操作少时，建满线段树浪费内存。动态开点仅在访问到的节点按需创建。

## 二、核心原理
节点初始为空，递归到某区间需要修改时才 `new` 子节点。未建的子树视为全 0（或可结合懒标记）。

## 三、形式化与数学基础
单次操作路径长 $O(\log U)$（$U$ 为值域），总空间 $O(q\log U)$（$q$ 为操作数）：
$T=O(\log U)$ 每次，$S=O(q\log U)$。

## 四、代码实现
```python
class DynNode:
    def __init__(self):
        self.left = None
        self.right = None
        self.val = 0
def update_dyn(node, l, r, idx, val):
    if l == r:
        node.val = val
        return
    mid = (l + r) // 2
    if idx <= mid:
        if not node.left:
            node.left = DynNode()
        update_dyn(node.left, l, mid, idx, val)
    else:
        if not node.right:
            node.right = DynNode()
        update_dyn(node.right, mid + 1, r, idx, val)
    node.val = (node.left.val if node.left else 0) + (node.right.val if node.right else 0)
```

## 五、与其他技术对比
相比满建线段树省内存、适合大值域；相比离散化，省去预处理但常数略高。常与主席树配合。

## 六、常见误区
未判断子节点为空就访问会报错；合并值时要对空子树取 0（或对应单位元）。

## 七、与开源书/权威来源对应
TheAlgorithms/Python 的 segment tree 实现；竞赛讲义动态开点章节。

## 八、面试题
实现值域很大的单点修改区间和；空间复杂度？

## 九、演进与趋势
与可持久化结合实现历史版本查询；与哈希节点替代指针减少开销。

## 十、小结
动态开点线段树按需建节点，把空间从 $O(U)$ 降到 $O(q\log U)$，适合大值域稀疏场景。
