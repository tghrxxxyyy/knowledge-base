# 线段树基本构建与单点更新

> 对应 CyC2018/CS-Notes。

## 一、背景与挑战
频繁对数组做单点修改并查询区间和/最值，朴素数组是 $O(n)$ 查询。线段树以二叉树把区间二分，把单点更新与区间查询都降到 $O(\log n)$。

## 二、核心原理
每个节点管理一个区间；叶子管理单元素；内部节点的值是左右子区间的合并结果。更新时自底向上重新合并受影响路径。

## 三、形式化与数学基础
建树递归 $O(n)$；单点更新只改一条根到叶路径，长度 $O(\log n)$；为容下满二叉树，数组常开 $4n$：
$T_{\rm build}=O(n),\;T_{\rm update}=O(\log n)$。

## 四、代码实现
```python
class SegTree:
    def __init__(self, arr):
        self.n = len(arr)
        self.tree = [0] * (4 * self.n)
        self._build(arr, 1, 0, self.n - 1)
    def _build(self, arr, node, l, r):
        if l == r:
            self.tree[node] = arr[l]
            return
        mid = (l + r) // 2
        self._build(arr, node * 2, l, mid)
        self._build(arr, node * 2 + 1, mid + 1, r)
        self.tree[node] = self.tree[node * 2] + self.tree[node * 2 + 1]
    def update(self, idx, val):
        self._update(1, 0, self.n - 1, idx, val)
    def _update(self, node, l, r, idx, val):
        if l == r:
            self.tree[node] = val
            return
        mid = (l + r) // 2
        if idx <= mid:
            self._update(node * 2, l, mid, idx, val)
        else:
            self._update(node * 2 + 1, mid + 1, r, idx, val)
        self.tree[node] = self.tree[node * 2] + self.tree[node * 2 + 1]
```

## 五、与其他技术对比
相比树状数组，线段树可表达任意可合并信息（不仅前缀和）且区间操作更直观；代价是常数与代码量略大。

## 六、常见误区
数组只开 $2n$ 会越界，应开 $4n$；区间划分把中点归入左或右要一致（这里 mid 归左、mid+1 归右）。
