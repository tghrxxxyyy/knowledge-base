# 线段树基本构建与单点更新

> 对应 Cormen et al.《算法导论》第 4 章分治与第 15 章动态规划思想、Bentley (1977) *Algorithms for the Interval Searching Problem*，以及 OI Wiki / youngyangyang04/leetcode-master 线段树章节。

## 一、背景与挑战

数组区间统计是工程与面试中最常见的数据结构需求之一：日志系统要按时间窗求和、行情系统要查最近 N 笔成交极值、游戏引擎要按坐标段筛碰撞体。朴素数组在单点修改后查询区间和是 $O(n)$，若修改与查询交错进行 $q$ 次，总代价 $O(qn)$，$n,q \approx 10^5$ 时达到 $10^{10}$，直接超时。前缀和可以把查询降到 $O(1)$，但单点修改又退化成 $O(n)$ 重算后缀；树状数组（Fenwick）能同时做到 $O(\log n)$，但它只擅长可差分/可逆的信息（和、异或等），面对"区间最大子段和""区间最值 + 区间赋值"等复合信息就力不从心。

线段树（Segment Tree）用分治把下标区间递归二分：每个节点管理一个子区间，叶子管理单点，内部节点存其左右子区间的**可合并信息**。单点更新只沿一条根到叶的路径重新合并，查询区间时只走 $O(\log n)$ 个"恰当地覆盖查询段"的节点。它把"任意可合并信息 + 单点/区间修改 + 区间查询"统一到 $O(\log n)$，是区间问题的通用骨架。

在面试中，线段树是"能否把问题抽象成可合并信息"的试金石：面试官要你定义节点信息、写清 pushup、说清复杂度与空间 $4n$。在工程中，它出现在时序数据库（按时间窗聚合）、竞赛判题（区间更新与查询）、地图索引、风控规则的滑动窗口统计等场景。本篇先把最基础也最必须打牢的部分讲透：建树、单点更新、区间查询。

## 二、核心原理

**结构。** 把序列下标区间 $[0, n-1]$ 递归二分：根管理 $[0,n-1]$，左子管 $[l, mid]$，右子管 $[mid+1, r]$，直到 $l=r$ 的叶子。为用数组静态存储，约定节点 `p` 的左孩子为 `2p`、右孩子为 `2p+1`（或 0-based 的 `2p+1/2p+2`）。满二叉树在最坏情形需要 $4n$ 空间（见第三节推导）。

**可合并信息。** 每个节点存的不是"它管的那段数组"，而是这段的**聚合值**：区间和、区间最值、区间 GCD、区间矩阵乘积……只要满足结合律，就能由左右孩子合并（pushup）而来：

```text
tree[p] = combine(tree[2p], tree[2p+1])
```

**建树。** 自顶向下递归到叶子写入 `arr[l]`，回溯时 pushup。总节点数 $O(n)$，每个节点合并一次，故 $O(n)$。

**单点更新。** 把 `arr[i]` 改成 `val`：从根出发，按 `i` 落在左半还是右半递归到叶子写入新值；回溯路上对每个祖先重新 pushup。路径长度是树高 $O(\log n)$，故 $O(\log n)$。

**区间查询。** 查询 $[L,R]$ 时，当前节点区间 $[l,r]$ 有三种关系：

1. **无交**：直接返回不影响结果的单位元（区间和是 0，最值是 $-\infty$）。
2. **完全包含**：$[l,r]\subseteq[L,R]$，直接返回 `tree[p]`——不必再下钻，这就是 $O(\log n)$ 的关键。
3. **部分相交**：递归左右，再 combine。

**不变量。** 任意时刻，`tree[p]` 等于其管理区间上当前数组值的聚合结果。更新后沿路径恢复该不变量，查询依赖该不变量。

**为什么正确。** 查询返回的是一组**互不相交**且并集恰为 $[L,R]$ 的节点聚合值再合并；因为 combine 满足结合律，分段聚合等于整段聚合。

## 三、形式化与数学基础

**树高。** 区间每次折半，$n$ 个叶子的二叉树高 $\lceil \log_2 n \rceil + O(1)$，故单点更新与区间查询路径长 $O(\log n)$。

**空间 $4n$ 推导。** 若按"满二叉树"上用连续编号存储，高度为 $h=\lceil \log_2 n\rceil + 1$ 的满二叉树节点数为 $2^h - 1 < 4n$：

$$
2^{\lceil \log_2 n\rceil + 1} \le 2 \cdot 2^{\log_2 n + 1} = 4n.
$$

实际递归建树只用到 $O(n)$ 个节点，但下标编号会"跳空"，故数组必须开 $4n$ 保证不越界。这是面试常问的"为什么不是 $2n$"。

**建树复杂度。** 满二叉树节点数 $O(n)$，每个节点做一次 $O(1)$ 的 combine，故 $T_{\text{build}} = \Theta(n)$。

**查询复杂度。** 定理：对任意查询区间 $[L,R]$，递归访问的"完全包含"节点数不超过 $O(\log n)$，"部分相交"而继续下钻的节点构成两条根到叶的路径。证明要点：每个层最多两个部分相交节点（左路径、右路径各一），其余被截断；层高 $O(\log n)$，故总访问 $O(\log n)$。

$$
T_{\text{query}} = O(\log n), \quad T_{\text{update}} = O(\log n).
$$

**单位元。** 区间和查询的"无交"返回 0（加法单位元）；区间 max 返回 $-\infty$。选错单位元是常见边界错误。

**与其他下界。** 若信息不可逆（如区间众数），线段树节点需存更复杂结构；单点更新仍 $O(\log n)$，但 combine 可能变贵。这是"可合并信息"抽象的价值所在。

## 四、代码实现

完整可运行的线段树：建树、单点更新、区间求和。对经典用例验证。

```python
# 线段树：建树 + 单点更新 + 区间求和
class SegTree:
    def __init__(self, arr):
        self.n = len(arr)
        self.tree = [0] * (4 * self.n)
        self._build(arr, 1, 0, self.n - 1)

    def _build(self, arr, p, l, r):
        if l == r:
            self.tree[p] = arr[l]
            return
        mid = (l + r) // 2
        self._build(arr, p * 2, l, mid)
        self._build(arr, p * 2 + 1, mid + 1, r)
        self._pushup(p)

    def _pushup(self, p):
        self.tree[p] = self.tree[p * 2] + self.tree[p * 2 + 1]

    def update(self, idx, val):
        """把下标 idx 的元素改成 val。"""
        self._update(1, 0, self.n - 1, idx, val)

    def _update(self, p, l, r, idx, val):
        if l == r:
            self.tree[p] = val
            return
        mid = (l + r) // 2
        if idx <= mid:
            self._update(p * 2, l, mid, idx, val)
        else:
            self._update(p * 2 + 1, mid + 1, r, idx, val)
        self._pushup(p)

    def query(self, L, R):
        """返回区间 [L, R] 的和（闭区间，0-based）。"""
        return self._query(1, 0, self.n - 1, L, R)

    def _query(self, p, l, r, L, R):
        if R < l or r < L:          # 无交
            return 0
        if L <= l and r <= R:       # 完全包含
            return self.tree[p]
        mid = (l + r) // 2
        return self._query(p * 2, l, mid, L, R) + self._query(p * 2 + 1, mid + 1, r, L, R)


if __name__ == '__main__':
    arr = [1, 3, 5, 7, 9, 11]
    st = SegTree(arr)
    assert st.query(0, 2) == 1 + 3 + 5
    assert st.query(1, 4) == 3 + 5 + 7 + 9
    assert st.query(0, 5) == sum(arr)
    st.update(2, 100)               # arr[2] = 100
    assert st.query(0, 2) == 1 + 3 + 100
    assert st.query(2, 2) == 100
    st.update(0, -1)
    assert st.query(0, 5) == -1 + 3 + 100 + 7 + 9 + 11
    print('segtree build/update/query ok', st.query(0, 5))
```

实现细节：`_query` 的无交判断写成 `R < l or r < L`；闭区间约定全程一致；`mid = (l+r)//2` 归左、`mid+1` 归右，与建树一致。

## 五、与其他技术对比

| 结构 | 单点更新 | 区间求和 | 任意可合并信息 | 空间 | 代码量 |
|------|----------|----------|----------------|------|--------|
| 朴素数组 | $O(1)$ | $O(n)$ | — | $O(n)$ | 极小 |
| 前缀和 | $O(n)$ | $O(1)$ | 仅可差分 | $O(n)$ | 小 |
| 树状数组 | $O(\log n)$ | $O(\log n)$ | 限于可逆/可差分 | $O(n)$ | 小 |
| 线段树 | $O(\log n)$ | $O(\log n)$ | 任意结合律信息 | $O(4n)$ | 中 |
| 平衡树（Treap） | $O(\log n)$ | $O(\log n)$ | 任意，且支持分裂合并 | $O(n)$ | 大 |
| Sqrt 分块 | $O(\sqrt n)$ | $O(\sqrt n)$ | 灵活 | $O(n)$ | 中 |

取舍：只求和/异或优先树状数组；要区间最值、区间赋值、复合信息（最大子段和）用线段树；要按值分裂、区间翻转用平衡树；数据静态可离线时，ST 表/分块更省。

## 六、常见误区

1. **空间只开 $2n$。** 递归编号在非满树时会跳空，$2n$ 会越界。必须 $4n$（或动态开点/显式计算节点数）。
2. **`mid` 归属前后不一致。** 建树时 `mid` 归左，查询时却写成 `L <= l and r <= R` 之外的半开区间混用，导致边界漏区间或重复计。约定 $[l, mid]$ 与 $[mid+1, r]$ 并全程贯彻。
3. **查询无交时返回 0 当"非法标记"。** 对 max 查询，无交返回 0 会把负数最大值错吞；应返回 $-\infty$ 或显式 `None`。
4. **单点更新写成区间赋值语义。** `update(idx, val)` 是"改成 val"不是"加 val"；若要增量更新，应把叶子写成 `tree[p] += delta` 并相应调整 pushup 语义。
5. **递归不写 `if l == r` 先返回。** 导致无限递归或空区间异常。基线条件必须最先判。

## 八、面试题

**1. 请实现区间求和、单点修改的线段树，并说明复杂度。**
参考答案：见上文 `SegTree`。建树 $O(n)$，更新/查询 $O(\log n)$，空间 $O(n)$（数组开 $4n$）。

**2. 为什么线段树数组要开 $4n$ 而不是 $2n$？**
参考答案：静态编号下满二叉树下标可能跳空。高为 $h=\lceil\log_2 n\rceil+1$ 的满二叉树节点数 $2^h-1<4n$，$2n$ 在退化情形会越界。动态开点或自底向上 zkw 写法可以避免。

**3. 区间查询为什么是 $O(\log n)$？**
参考答案：每次递归在无交时截断、完全包含时直接返回；部分相交的节点构成两条根到叶路径，每层至多两个，共 $O(\log n)$ 个节点被访问。

**4. 线段树与树状数组怎么选？**
参考答案：只做前缀可逆运算（和、异或）且要常数小、代码短，用树状数组；需要任意可合并信息（最值、乘积、最大子段和）或后续要区间懒标记，用线段树。

## 九、演进与趋势

基础单点更新之后的标准演进是：**懒惰标记**支持区间修改；**zkw 线段树**自底向上迭代去掉递归；**动态开点**应对值域 $10^9$；**可持久化**保留历史版本；**线段树合并**处理权值线段树；**李超树、猫树、吉司机线段树**分别处理凸壳、静态历史最值、区间取模。工程上，时序库（Prometheus/InfluxDB 的窗口聚合）、风控滑动窗口、游戏 AOI 的区间索引都以线段树或其变体为核心。面试趋势稳定在"手写区间和 + 单点改"与"解释 $4n$ 与 $O(\log n)$"。

## 十、小结

线段树以区间二分把序列折成一棵聚合树，靠 pushup 维护"节点值 = 子区间聚合"的不变量，使建树 $O(n)$、单点更新与区间查询都是 $O(\log n)$；它是所有区间问题的通用骨架，后续懒标记、动态开点、可持久化都建立在这一套下标约定与 pushup 思想之上。
