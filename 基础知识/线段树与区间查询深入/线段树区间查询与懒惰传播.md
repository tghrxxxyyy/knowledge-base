# 线段树区间查询与懒惰传播

> 对应 Cormen et al.《算法导论》第 15 章动态规划思想、OI Wiki「线段树」懒标记条目，以及 R. E. Tarjan 等关于区间操作数据结构的分析传统。

## 一、背景与挑战

单点更新只能改一个位置，但真实需求往往是**区间修改**：把 $[L,R]$ 每个数加 $x$、乘 $x$、赋值成 $x$，同时还要随时查区间和/最值。若每次区间加都递归到每个叶子，单次 $O(n)$，$q$ 次操作退化到 $O(qn)$，与朴素数组无异。更糟的是，区间赋值与区间加会互相覆盖，错误的更新顺序直接算错结果。

懒惰传播（Lazy Propagation，下称"懒标记"）是线段树能处理区间修改的核心机制：**不下传不急迫的更新，只在节点上挂一个"待下传标记"**；当后续查询/更新需要访问该节点的子区间时，再把标记推给儿子并清空。这样区间加在"整段覆盖"的节点上就地完成，总复杂度仍是 $O(\log n)$。

在面试中，"区间加区间求和"是线段树最高频的考题：它同时考察 pushup、懒标记的下传时机、标记的复合顺序（先加后赋值还是先赋值后加）。在工程里，它对应批量调价、批量打标签、滑动窗口批量增减、游戏里群体 buff 的区间生效等。不会懒标记，线段树就只是一棵静态聚合树，无法覆盖真正的"区间修改 + 区间查询"场景。

## 二、核心原理

**节点上挂什么。** 每个节点除了聚合值 `tree[p]`，还有一个懒标记 `lazy[p]`，表示"这段区间还欠着一次未下传的操作"。对区间加，`lazy[p] = x` 表示该区间每个元素都还没加上 $x$。

**pushdown（下传）时机。** 当需要进入节点 $p$ 的左右子区间时（查询/更新要下钻），必须先把 `lazy[p]` 应用到两个儿子：给儿子的 `tree` 加上应有的贡献、把标记累加到儿子的 `lazy`，然后清空 `lazy[p]`。这就是"下传时机 = 需要访问子区间时"，不是"每次更新都下传"。

**区间加的两种写法。**

1. **整段覆盖**：$[L,R]$ 完全包含节点区间 $[l,r]$ 时，`tree[p] += x * (r-l+1)`，`lazy[p] += x`，直接返回，不递归。
2. **部分相交**：先 pushdown，再递归左右，最后 pushup。

**为什么正确。** 不变量：`tree[p]` 已反映"该节点及祖先所有未下传标记对本区间的累积影响"；`lazy[p]` 只影响子区间尚未生效。pushdown 把不变量扩展到儿子，pushup 保证父亲聚合始终等于子区间的（含未下传标记的）真实聚合。

**区间赋值与区间加复合。** 若两种操作混用，标记顺序不能交换：先赋值再加，等于"赋值后加"；先加再赋值，等于"直接赋值"。通常在节点上存 `setv`（赋值标记）与 `addv`（加标记），规定 **赋值清空加标记**，下传时先传 `setv` 再传 `addv`。

**边界条件。** 叶子的 `lazy` 下传到儿子时要跳过；空区间直接返回；查询无交返回单位元；`lazy` 初始化为 0（或 `None` 表示无标记）。

## 三、形式化与数学基础

**区间加 + 区间和的复杂度。** 每次区间操作最多访问 $O(\log n)$ 个"整段覆盖"节点（记懒标记）并沿两条路径 pushdown/pushup，故

$$
T_{\text{range-update}} = O(\log n), \quad T_{\text{range-query}} = O(\log n).
$$

**证明要点。** 查询访问的节点仍是 $O(\log n)$ 个（第三节已证）；区间修改与查询访问的节点集合结构相同，只是多了 pushdown/pushup 的常数代价。

**lazy 的代数结构。** 设操作集合是幺半群 $(G, \circ, e)$，标记合并用 $\circ$，对聚合值的作用是群作用。区间加的 $G=(\mathbb{Z},+)$，标记合并就是加法；区间赋值的 $G$ 是"赋值运算"，与加法复合时规定赋值吸收加：

$$
(\text{set}_v) \circ (\text{add}_x) = \text{set}_{v+x}, \quad (\text{add}_x) \circ (\text{set}_v) = \text{set}_v.
$$

注意 $\circ$ 不交换，下传顺序必须固定。

**区间加对区间和的贡献。** 给 $[l,r]$ 每个元素加 $x$，该节点区间和增加 $x\cdot (r-l+1)$：

$$
sum \leftarrow sum + x \cdot (r-l+1).
$$

对区间最大值，贡献是 $mx \leftarrow mx + x$（整体抬升）；对区间赋值，贡献是 $sum \leftarrow v \cdot (r-l+1)$。这些"标记作用到聚合值"的公式是写对懒标记的关键。

**空间。** 仍为 $O(4n)$，`lazy` 数组与 `tree` 等长。

## 四、代码实现

完整可运行：区间加 + 区间求和（懒标记），附带验证。

```python
# 线段树 + 懒标记：区间加、区间求和
class LazySegTree:
    def __init__(self, arr):
        self.n = len(arr)
        self.tree = [0] * (4 * self.n)
        self.lazy = [0] * (4 * self.n)
        self._build(arr, 1, 0, self.n - 1)

    def _build(self, arr, p, l, r):
        if l == r:
            self.tree[p] = arr[l]
            return
        mid = (l + r) // 2
        self._build(arr, p * 2, l, mid)
        self._build(arr, p * 2 + 1, mid + 1, r)
        self._pushup(p)

    def _pushup(self, p):
        self.tree[p] = self.tree[p * 2] + self.tree[p * 2 + 1]

    def _apply(self, p, l, r, x):
        """把区间加 x 作用到节点 p。"""
        self.tree[p] += x * (r - l + 1)
        self.lazy[p] += x

    def _pushdown(self, p, l, r):
        if self.lazy[p]:
            mid = (l + r) // 2
            self._apply(p * 2, l, mid, self.lazy[p])
            self._apply(p * 2 + 1, mid + 1, r, self.lazy[p])
            self.lazy[p] = 0

    def range_add(self, L, R, x):
        self._range_add(1, 0, self.n - 1, L, R, x)

    def _range_add(self, p, l, r, L, R, x):
        if R < l or r < L:
            return
        if L <= l and r <= R:
            self._apply(p, l, r, x)
            return
        self._pushdown(p, l, r)
        mid = (l + r) // 2
        self._range_add(p * 2, l, mid, L, R, x)
        self._range_add(p * 2 + 1, mid + 1, r, L, R, x)
        self._pushup(p)

    def query(self, L, R):
        return self._query(1, 0, self.n - 1, L, R)

    def _query(self, p, l, r, L, R):
        if R < l or r < L:
            return 0
        if L <= l and r <= R:
            return self.tree[p]
        self._pushdown(p, l, r)
        mid = (l + r) // 2
        return self._query(p * 2, l, mid, L, R) + self._query(p * 2 + 1, mid + 1, r, L, R)


if __name__ == '__main__':
    arr = [1, 2, 3, 4, 5, 6]
    st = LazySegTree(arr)
    assert st.query(0, 5) == 21
    st.range_add(1, 4, 10)          # [1,2,3,4] += 10
    assert st.query(0, 5) == 21 + 40
    assert st.query(1, 4) == (2 + 3 + 4 + 5) + 40
    st.range_add(0, 2, -3)
    assert st.query(0, 2) == (1 + 2 + 3) + 20 - 9
    assert st.query(5, 5) == 6
    print('lazy ok', st.query(0, 5))
```

若要支持区间加 + 区间赋值，标记需两套，且赋值清空加标记：

```python
# 双标记示意：setv 优先于 add
def apply_set(p, l, r, v):
    tree[p] = v * (r - l + 1)
    setv[p] = v
    addv[p] = 0          # 赋值清空加标记

def apply_add(p, l, r, x):
    tree[p] += x * (r - l + 1)
    if setv[p] is not None:
        setv[p] += x     # 未下传的赋值上直接加
    else:
        addv[p] += x
```

正确性依赖"先处理 setv 再处理 addv"的固定顺序。

## 五、与其他技术对比

| 方法 | 区间加 | 区间求和 | 复合赋值/加 | 常数 | 备注 |
|------|--------|----------|-------------|------|------|
| 朴素 | $O(n)$ | $O(n)$ | 易错 | 小 | 仅教学 |
| 差分数组 + 前缀和 | $O(1)$ | $O(n)$ 重建 | 不能 | 极小 | 离线只改后一次查询 |
| 树状数组（区间加区间和） | $O(\log n)$ | $O(\log n)$ | 不便 | 小 | 两个 BIT |
| 线段树懒标记 | $O(\log n)$ | $O(\log n)$ | 支持 | 中 | 面试主流 |
| 分块 | $O(\sqrt n)$ | $O(\sqrt n)$ | 支持 | 中 | 实现简单 |
| 平衡树 | $O(\log n)$ | $O(\log n)$ | 支持 | 大 | 可分裂合并 |

取舍：只加只求和，树状数组常数更优；要赋值、乘法、最值、最大子段和等复合信息，用懒标记线段树；数据静态且离线，差分最省。

## 六、常见误区

1. **忘记 pushdown 就递归。** 后果：子节点聚合值缺少祖先标记，查询结果偏小；更新也会覆盖掉未下传的信息。凡是下钻，先 pushdown。
2. **`lazy` 下传后忘记清零。** 同一标记被重复应用，数值爆炸。`pushdown` 末尾必须 `self.lazy[p] = 0`。
3. **区间加对区间最值的贡献写错。** max 查询里 `tree[p] += x` 是对的（整体抬升），但若误写成 `tree[p] = max(tree[p], x)` 就完全错了。
4. **赋值与加的复合顺序错误。** 先加后赋值应被赋值吸收；若标记合并可交换地写，会出现"加了本该被覆盖的值"。必须规定 setv 清空 addv。
5. **下传时对叶子也 pushdown。** 浪费且可能数组越界；应写 `if l == r: return` 或在 `_pushdown` 中判断有儿子。
6. **查询无交返回 0 与"合法 0 和"混淆。** 对求和无妨；对 min/max 要返回 $\pm\infty$，否则负数区间会被 0 污染。

## 八、面试题

**1. 实现区间加、区间求和，并说明懒标记何时下传。**
参考答案：见 `LazySegTree`。下传时机是"需要访问子区间时"（`_pushdown` 在递归左右之前调用）；整段覆盖的节点只挂标记不下传。复杂度每次 $O(\log n)$。

**2. 若同时支持区间加与区间赋值，标记怎么设计？**
参考答案：节点存 `setv`（可空）与 `addv`。赋值操作令 `setv=v, addv=0`；加操作若 `setv` 非空则 `setv+=x`，否则 `addv+=x`。下传时先下传 `setv` 再 `addv`，保证覆盖语义正确。

**3. 为什么懒标记不会破坏复杂度？**
参考答案：每个标记只会被下传 $O(\log n)$ 次（沿路径），每次操作访问 $O(\log n)$ 节点；标记总量与操作数同阶，均摊后仍是 $O(\log n)$/操作。

**4. 区间乘、区间加同时存在呢？**
参考答案：标记是线性变换 $x \leftarrow a x + b$，复合即变换合成 $a' = a_2 a_1,\ b' = a_2 b_1 + b_2$；对区间和作用是 $sum \leftarrow a\cdot sum + b\cdot len$。顺序由合成公式决定，不可交换。

## 九、演进与趋势

懒标记之后的演进包括：**双标记/多标记复合**（加乘、赋值加）、**区间开根 + 区间求和**（均摊暴力）、**区间取模**（吉司机线段树维护次大值）、**扫描线 + 懒标记**做矩形面积并、**树链剖分**把树上路径改成若干区间打懒标记。工程上，批量配置下发、活动时间窗的批量生效、地图区域 buff 都用同一机制；趋势是把懒标记抽象成"幺半群作用"，用模板/泛型写一遍复用到所有可合并信息。

## 十、小结

懒惰传播让线段树在 $O(\log n)$ 内完成区间修改与区间查询：整段覆盖的节点挂标记、需要下钻时 pushdown，靠 `tree`/`lazy` 两个不变量保证正确；复合标记必须固定顺序（赋值吸收加），这是写对区间修改类线段树的关键。
