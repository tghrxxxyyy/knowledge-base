# 线段树区间查询与懒惰传播

> 对应 youngyangyang04/leetcode-master。

## 一、背景与挑战
区间加值 + 区间求和若每次下推会退化为 $O(n)$。懒惰传播（lazy propagation）把待下传的修改暂存在节点，访问时再下放。

## 二、核心原理
对完全覆盖当前节点的区间，直接更新节点值并打上 lazy 标记；递归进入子区间前先下放标记，保证子节点值正确。

## 三、形式化与数学基础
每次区间操作只拆分到 $O(\log n)$ 个标准节点，下放也摊还 $O(\log n)$：
$T_{\rm add}=T_{\rm query}=O(\log n)$。

## 四、代码实现
```python
class LazySeg:
    def __init__(self, arr):
        self.n = len(arr)
        self.sum = [0] * (4 * self.n)
        self.lazy = [0] * (4 * self.n)
        self._build(arr, 1, 0, self.n - 1)
    def _build(self, arr, node, l, r):
        if l == r:
            self.sum[node] = arr[l]; return
        mid = (l + r) // 2
        self._build(arr, node * 2, l, mid)
        self._build(arr, node * 2 + 1, mid + 1, r)
        self.sum[node] = self.sum[node * 2] + self.sum[node * 2 + 1]
    def _push(self, node, l, r):
        if self.lazy[node]:
            mid = (l + r) // 2
            self.sum[node * 2] += self.lazy[node] * (mid - l + 1)
            self.sum[node * 2 + 1] += self.lazy[node] * (r - mid)
            self.lazy[node * 2] += self.lazy[node]
            self.lazy[node * 2 + 1] += self.lazy[node]
            self.lazy[node] = 0
    def range_add(self, ql, qr, val, node=1, l=0, r=None):
        if r is None: r = self.n - 1
        if ql > r or qr < l: return
        if ql <= l and r <= qr:
            self.sum[node] += val * (r - l + 1)
            self.lazy[node] += val; return
        self._push(node, l, r)
        mid = (l + r) // 2
        self.range_add(ql, qr, val, node * 2, l, mid)
        self.range_add(ql, qr, val, node * 2 + 1, mid + 1, r)
        self.sum[node] = self.sum[node * 2] + self.sum[node * 2 + 1]
    def range_sum(self, ql, qr, node=1, l=0, r=None):
        if r is None: r = self.n - 1
        if ql > r or qr < l: return 0
        if ql <= l and r <= qr: return self.sum[node]
        self._push(node, l, r)
        mid = (l + r) // 2
        return self.range_sum(ql, qr, node * 2, l, mid) + self.range_sum(ql, qr, node * 2 + 1, mid + 1, r)
```

## 五、与其他技术对比
相比每次整体重建，懒惰标记把区间修改降到对数级；相比树状数组的区间加，线段树更通用（如区间赋值、取模）。

## 六、常见误区
查询路径上忘记 `_push` 导致读到旧值；标记累加而非覆盖时语义要明确（加 vs 赋值）。

## 九、演进与趋势

## 十、小结
懒惰传播把区间修改延迟下放，使线段树区间操作保持 $O(\log n)$。
