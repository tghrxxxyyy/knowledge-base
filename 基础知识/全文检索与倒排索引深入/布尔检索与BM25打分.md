# 布尔检索与BM25打分

> 对应 Kleppmann《Designing Data-Intensive Applications》第 3 章（相关度排序），以及 Garcia-Molina《Database Systems: The Complete Book》第 11 章。

## 一、背景与挑战
布尔检索返回“命中/不命中”，但用户需要按相关度排序的 top-K。BM25 在 TF-IDF 基础上引入饱和度与文档长度归一化，成为现代搜索引擎默认打分。

## 二、核心原理
布尔模型先做 AND/OR/NOT 集合运算得到候选集。BM25 对每篇文档 $d$ 与查询 $q$ 打分：
- 词频经饱和函数（避免长文档刷分）；
- 逆文档频率降权常见词；
- 文档长度归一化抵消长文档偏向。

## 三、形式化与数学基础
BM25 分数：
$$ score(d,q) = \sum_{t \in q} IDF(t) \cdot \frac{tf_t \cdot (k_1+1)}{tf_t + k_1(1-b+b\frac{|d|}{avgdl})} $$
其中
$$ IDF(t) = \ln\frac{N - df_t + 0.5}{df_t + 0.5} + 1 $$
$k_1$ 控制 TF 饱和，$b$ 控制长度归一（常 0.75）。

## 四、代码实现
```python
# BM25 单文档打分（仅示意）
def bm25(tf, df, N, doc_len, avgdl, k1=1.5, b=0.75):
    idf = math.log((N - df + 0.5) / (df + 0.5) + 1)
    denom = tf + k1 * (1 - b + b * doc_len / avgdl)
    return idf * tf * (k1 + 1) / denom
```

## 五、与其他技术对比
TF-IDF 无长度归一与饱和，长文档易偏高；BM25 更稳健。向量空间模型用余弦相似，适用于稠密向量而非稀疏词项。

## 六、常见误区
1) 认为 TF 越高分越高——BM25 饱和限制。
2) 忽略文档长度归一。
3) 混淆 IDF 与打分方向。
