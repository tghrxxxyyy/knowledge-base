# 网络流

> 对应 CLRS《Introduction to Algorithms》第 26 章 Maximum Flow。

## 一、背景与挑战
在有向带容量网络中求从源 s 到汇 t 的最大流量，并可推广到最小割、二分匹配、任务分配。

## 二、核心原理
基于残留网络与增广路：不断在残留图中找 s→t 路径并沿其推送流量，直至无增广路（最大流最小割定理）。

## 三、形式化 / 数学基础
最大流最小割定理：最大流值 = 最小割容量。
Edmonds-Karp：$O(VE^2)$（BFS 最短增广路）。
Dinic：每次用 BFS 分层 + DFS 多路增广，复杂度 $O(V^2E)$（二分图为 $O(\sqrt V\,E)$）。

## 四、代码实现
```python
from collections import deque
def bfs(s, t, level, cap, adj):
    level[:] = [-1] * len(level)
    level[s] = 0
    q = deque([s])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if level[v] < 0 and cap[u][v] > 0:
                level[v] = level[u] + 1
                q.append(v)
    return level[t] >= 0

def dfs(u, t, f, cap, adj, level, it):
    if u == t:
        return f
    while it[u] < len(adj[u]):
        v = adj[u][it[u]]
        if level[v] == level[u] + 1 and cap[u][v] > 0:
            d = dfs(v, t, min(f, cap[u][v]), cap, adj, level, it)
            if d > 0:
                cap[u][v] -= d
                cap[v][u] += d
                return d
        it[u] += 1
    return 0

def dinic(cap, s, t, adj):
    flow = 0
    level = [0] * len(cap)
    while bfs(s, t, level, cap, adj):
        it = [0] * len(cap)
        while True:
            d = dfs(s, t, float('inf'), cap, adj, level, it)
            if d == 0:
                break
            flow += d
    return flow
```

## 五、与其他技术对比
与贪心匹配相比，网络流可建模容量与多源多汇；与匈牙利算法相比，Dinic 在二分图上等价且更快。

## 六、常见误区
残留边忘记加反向边（容量为 0 起始）；DFS 不记录迭代位置导致重复扫描；建图漏源汇。

## 八、面试题
「灌溉花园」「最大员工参与度」等建图题；最小割应用。

## 九、演进与趋势
费用流（SSP / 连续最短路）；动态树（Link-Cut Tree）优化 Dinic 到 O(VE log V)。

## 十、小结
网络流核心是残留网络 + 增广路；Dinic 通过分层与多路增广显著加速，建图能力比模板更重要。
