# 二分图匹配

> 对应 CLRS《Introduction to Algorithms》第 26 章与 Hopcroft-Karp 论文 (1973)。

## 一、背景与挑战
二分图中求最大匹配（最多边数使端点不重复），可解任务分配、课程排课等。

## 二、核心原理
匈牙利算法沿增广路扩展匹配；Hopcroft-Karp 每次用 BFS 找最短增广路分层后多路增广，复杂度更优。

## 三、形式化 / 数学基础
匈牙利（DFS 单边）：$O(VE)$。
Hopcroft-Karp：$O(\sqrt V\, E)$。
最大匹配 = 最小点覆盖（König 定理）。

## 四、代码实现
```python
def hungarian(adj, n, m):
    match = [-1] * m
    def try_k(u, seen):
        for v in adj[u]:
            if seen[v]:
                continue
            seen[v] = True
            if match[v] == -1 or try_k(match[v], seen):
                match[v] = u
                return True
        return False
    res = 0
    for u in range(n):
        seen = [False] * m
        if try_k(u, seen):
            res += 1
    return res
```

## 五、与其他技术对比
与网络流最大流建模相比，匈牙利更省空间；Hopcroft-Karp 在稠密二分图明显更快。

## 六、常见误区
DFS 中 seen 数组每轮必须重置；左右部大小不等时数组越界；误把一般图当二分图（需奇环检测）。

## 十、小结
二分图最大匹配核心是增广路；匈牙利易写，大规模用 Hopcroft-Karp，König 定理关联最小点覆盖。
