# 二分图匹配

> 对应 CLRS《Introduction to Algorithms》第 26 章（二分匹配与最大流）、Hopcroft & Karp (1973) "An $n^{5/2}$ algorithm for maximum matchings in bipartite graphs"，以及 König 定理。

## 一、背景与挑战

二分图 $G=(U\cup V, E)$ 的顶点分为左右两部，边只在部间。匹配 $M\subseteq E$ 是两两不共享端点的边集；最大匹配是边数最多的匹配。问题天然出现在任务分配（工人-任务）、排课（课程-教室）、婚姻/配对、推荐系统、图像特征匹配、数据对齐等场景。面试题如「情侣牵手」「课程表 III」「最大人工岛配对」「机器分配」常可转化为二分匹配或带权匹配。

难点有三。第一，**匹配不是流量问题的特例这么简单**：直接用最大流建模可行，但通用网络流代码重、常数大；面试手写需要更轻的匈牙利算法。第二，**增广路概念易写错**：`seen` 数组的复位时机、左右部大小不等时的下标、迭代加深的层级，都是事故点。第三，**图未必是二分图**：若含奇环，匹配算法不适用，需先二分染色判二分性，或用一般图带花树 Blossom 算法。

与网络流的关系：二分图最大匹配可归约为「源点连左部、右部连汇点、容量 1」的最大流。Dinic 在二分图上的复杂度 $O(\sqrt{V}E)$，与 Hopcroft-Karp 同阶。带权版本（KM 算法）解决最大权匹配，是另一条重要分支。

## 二、核心原理

**增广路（Augmenting Path）**：匹配 $M$ 的增广路是起点终点均未匹配、且边交替「非匹配-匹配」的路径。经典定理（Berge）：$M$ 是最大匹配当且仅当不存在增广路。沿增广路翻转（匹配变非匹配、非匹配变匹配），匹配数加 1。

**匈牙利算法（Hungarian / Kuhn）**：从左部每个未匹配点出发，DFS 找增广路。对 $u\in U$ 尝试每个邻居 $v$：

- 若 $v$ 未匹配，直接配对成功；
- 若 $v$ 已匹配给 $u'$，递归给 $u'$ 换一个对象（找从 $u'$ 出发的增广）。

为避免重复访问陷入死循环，用 `seen` 标记本轮已尝试的右部点。每找到一条增广路，匹配数 +1。复杂度 $O(VE)$（每个左点最多遍历所有边）。

**Hopcroft-Karp**：每次用 BFS 建立分层图（从所有未匹配左点出发，按交替路层数），再用多次 DFS 沿最短增广路**阻塞流**式增广（一条增广路上的点不再被后续 DFS 复用）。每轮把最短增广路长度 +1，总轮数 $O(\sqrt V)$，每轮 $O(E)$，总 $O(\sqrt V E)$。

**König 定理**：二分图中最大匹配数 = 最小点覆盖数。对偶还有：最大独立集 = $|V|$ - 最小点覆盖。最大匹配/最小点覆盖/最大独立集三者互通，是二分图问题转化的核心。

**正确性不变量**：`match[v]` 记录右部点当前配偶；DFS 中 `seen` 保证每个右点每轮最多试一次；增广后匹配数 +1 且仍为合法匹配。Berge 定理保证「无增广路即最大」。

## 三、形式化与数学基础

**Berge 定理**：$M$ 最大 $\iff$ 无增广路。
证明要点：$\Rightarrow$ 若有增广路可翻转得到更大匹配，矛盾；$\Leftarrow$ 若 $M' > M$，考虑对称差 $M\oplus M'$ 的连通分量，必含一条 $M$-增广路，矛盾。

匈牙利复杂度：外层 $|U|$ 次 DFS，每次最坏 $O(E)$，总 $O(VE)$。实际常数小，$V,E\le 2000$ 轻松。

Hopcroft-Karp 复杂度：设最短增广路长 $L$，每轮 $L$ 严格递增。经 $O(\sqrt V)$ 轮后 $L > \sqrt V$，而剩余未匹配点 $\le \sqrt V$，故必达最大。每轮 BFS+多路 DFS 为 $O(E)$，总 $O(\sqrt V E)$。

**König 定理证明思路**：从匈牙利结束后的未匹配左点出发，沿「非匹配-匹配」交替边可达的点集 $Z$，构造最小点覆盖：覆盖 $= (U\setminus Z) \cup (V\cap Z)$。可验证覆盖数等于最大匹配数。

**网络流归约**：源 $s\to U$ 容量 1，$U\to V$ 容量 1（有边则建），$V\to t$ 容量 1。最大流值 = 最大匹配数。Dinic 在单位容量二分图上 $O(\sqrt V E)$。

**带权匹配（KM）**：完全二分图求最大权完美匹配，用顶标（label）维护 $l(u)+l(v)\ge w(u,v)$，匈牙利找增广时调整顶标，复杂度 $O(n^3)$。

## 四、代码实现

匈牙利最大匹配、二分染色判定、以及带权匹配的简化 KM（非完美情形用小技巧处理）均可运行。

```python
from typing import List, Optional, Tuple


def hungarian_maximum_matching(adj: List[List[int]], n: int, m: int) -> Tuple[int, List[int]]:
    """
    匈牙利最大匹配。左部 0..n-1，右部 0..m-1。
    adj[u] = 左点 u 的右邻列表。
    返回 (匹配数, matchR) 其中 matchR[v] = 配对的左点或 -1。
    """
    match_r = [-1] * m  # 右部点 -> 左部点

    def dfs(u: int, seen: List[bool]) -> bool:
        for v in adj[u]:
            if seen[v]:
                continue
            seen[v] = True
            if match_r[v] == -1 or dfs(match_r[v], seen):
                match_r[v] = u
                return True
        return False

    result = 0
    for u in range(n):
        seen = [False] * m
        if dfs(u, seen):
            result += 1
    return result, match_r


def is_bipartite(adj: List[List[int]], n: int) -> Optional[List[int]]:
    """二分染色。返回 0/1 染色数组，非二分图返回 None。"""
    color = [-1] * n
    for s in range(n):
        if color[s] != -1:
            continue
        color[s] = 0
        stack = [s]
        while stack:
            u = stack.pop()
            for v in adj[u]:
                if color[v] == -1:
                    color[v] = color[u] ^ 1
                    stack.append(v)
                elif color[v] == color[u]:
                    return None
    return color


def bipartite_from_graph(adj: List[List[int]], n: int) -> Optional[Tuple[List[List[int]], int, int]]:
    """
    若图为二分图，返回 (左部邻接表, n左, n右)，右部点重新编号。
    否则返回 None。
    """
    color = is_bipartite(adj, n)
    if color is None:
        return None
    left_id = {}
    right_id = {}
    for i in range(n):
        if color[i] == 0:
            left_id[i] = len(left_id)
        else:
            right_id[i] = len(right_id)
    adj_b: List[List[int]] = [[] for _ in range(len(left_id))]
    for u in range(n):
        if color[u] != 0:
            continue
        for v in adj[u]:
            adj_b[left_id[u]].append(right_id[v])
    return adj_b, len(left_id), len(right_id)


def km_maximum_matching(w: List[List[float]]) -> Tuple[float, List[int]]:
    """
    简化 KM：完全二分图最大权完美匹配（n x n）。
    返回 (最大权和, matchL) 其中 matchL[i] = 右点。
    复杂度 O(n^3)。
    """
    n = len(w)
    INF = float('inf')
    lx = [max(row) for row in w]
    ly = [0.0] * n
    match_r = [-1] * n
    match_l = [-1] * n

    def dfs(u: int, vis_l: List[bool], vis_r: List[bool]) -> bool:
        vis_l[u] = True
        for v in range(n):
            if vis_r[v]:
                continue
            # 仅考虑相等子图中的边
            if abs(lx[u] + ly[v] - w[u][v]) > 1e-9:
                continue
            vis_r[v] = True
            if match_r[v] == -1 or dfs(match_r[v], vis_l, vis_r):
                match_r[v] = u
                match_l[u] = v
                return True
        return False

    for u in range(n):
        while True:
            vis_l = [False] * n
            vis_r = [False] * n
            if dfs(u, vis_l, vis_r):
                break
            # 找最小 delta 更新顶标
            delta = INF
            for i in range(n):
                if not vis_l[i]:
                    continue
                for j in range(n):
                    if not vis_r[j]:
                        delta = min(delta, lx[i] + ly[j] - w[i][j])
            for i in range(n):
                if vis_l[i]:
                    lx[i] -= delta
                if vis_r[i]:
                    ly[i] += delta

    total = sum(w[i][match_l[i]] for i in range(n))
    return total, match_l


if __name__ == "__main__":
    # 左 3 右 3，边：0-0,0-1,1-1,2-2  -> 最大匹配 3
    adj = [[0, 1], [1], [2]]
    size, match_r = hungarian_maximum_matching(adj, 3, 3)
    assert size == 3
    assert sorted(match_r) == [0, 1, 2]

    # 更小例：0-0,0-1,1-1 -> 最大匹配 2
    adj2 = [[0, 1], [1]]
    size2, mr2 = hungarian_maximum_matching(adj2, 2, 2)
    assert size2 == 2

    # 二分判定
    assert is_bipartite([[1], [0]], 2) is not None
    assert is_bipartite([[1, 2], [0, 2], [0, 1]], 3) is None  # 三角形

    # KM：3x3 权值
    w = [
        [1.0, 2.0, 3.0],
        [3.0, 2.0, 1.0],
        [2.0, 4.0, 1.0],
    ]
    total, match_l = km_maximum_matching(w)
    assert total == 9.0  # 0->2, 1->0, 2->1  或最优组合
    print("bipartite matching ok, max =", size, "km =", total)
```

## 五、与其他技术对比

| 方法 | 复杂度 | 适用 | 特点 |
| --- | --- | --- | --- |
| 匈牙利（DFS） | $O(VE)$ | 通用二分匹配、面试手写 | 短小、易写、够用 |
| Hopcroft-Karp | $O(\sqrt V E)$ | 大规模二分图 | 分层 + 多路增广 |
| 网络流（Dinic） | $O(\sqrt V E)$（二分） | 带容量、多源多汇、带权 | 通用但代码长 |
| KM | $O(n^3)$ | 带权完美匹配 | 顶标调整 |
| Blossom（带花树） | $O(V^3)$ 级 | 一般图（含奇环） | 实现复杂 |

匈牙利 vs 网络流：纯匹配用匈牙利更省事；一旦有容量、边权、多源多汇，转网络流。Hopcroft-Karp 是匈牙利的「批量最短增广」加速，竞赛大规模图用它。

## 六、常见误区

1. **`seen` 数组只在每次全局重置一次**。必须每个左点 $u$ 开始 DFS 时重新建 `seen`；若共享，会漏掉合法增广（某右点被之前 $u$ 标记后不再尝试）。
2. **左右部大小不等时数组越界**。`match_r` 开 $|V|$（右部）大小；邻接表下标必须是右部重新编号后的 $0..m-1$，不能直接用原始图顶点号。
3. **把非二分图当二分图**。含奇环时匈牙利无意义。必须先二分染色判定，或用 Blossom。
4. **`match_r[v] = u` 与 `match_l[u] = v` 不同步**。若只维护单侧，回溯/输出时会不一致。两侧都维护或只维护 `match_r` 并用它推 `match_l`。
5. **KM 中顶标更新方向错误**。求最大权时 `lx` 初始取行最大、`delta` 更新要保证 $l(u)+l(v)\ge w$ 不被破坏；方向写反会算出错误权值。

## 八、面试题

**1. 情侣牵手 / 最少交换使配对（LeetCode 765）为什么是二分匹配？**

参考答案：可把「夫妻」视为左右部配对问题，或建模为置换的环分解：长度为 $k$ 的环需 $k-1$ 次交换。二分匹配视角把「期望配对」与「实际座位」作两部，最大匹配后剩余未匹配数与交换次数相关。关键洞察是问题的配对结构。

**2. 如何判断一个匹配是最大匹配？**

参考答案：Berge 定理——不存在增广路时即最大。匈牙利算法结束时对每个未匹配左点都尝试过 DFS 且失败，故无增广路，是最大匹配。

**3. König 定理是什么？如何用？**

参考答案：二分图最大匹配数 = 最小点覆盖数。由此，求最小点覆盖可先匈牙利求最大匹配，再从未匹配左点沿交替路可达集合构造覆盖。最大独立集 = 总点数 - 最小点覆盖。常用于「最少监控点覆盖所有边」类题。

**4. 带权二分匹配怎么做？**

参考答案：完全二分图最大权完美匹配用 KM 算法（顶标 + 匈牙利增广，$O(n^3)$）。非完美或稀疏可转最小费用最大流：源点连左、右连汇容量 1，边权取负，跑费用流。

## 九、演进与趋势

匹配理论延伸广泛：**一般图匹配**用 Edmonds Blossom（带花树）处理奇环；**带权匹配**与最小费用流互通；**近似匹配**、**在线匹配**（贪心竞争比 $1-1/e$）用于广告分配、拼车撮合。工程上，推荐系统的召回与排序、劳动力调度、编译器寄存器分配（干涉图着色相关）、脑区连接匹配都用匹配或其变体。

现代求解器把匹配作为约束规划/整数规划的子模块；GPU/并行 Hopcroft-Karp 用于超大二分图（社交推荐）。学习式匹配（GNN 预测配对）是近年热点。掌握匈牙利与增广路，是理解一切匹配与流网络的基础。

## 十、小结

二分图最大匹配的核心是增广路：匈牙利算法沿增广路扩展，$O(VE)$；Hopcroft-Karp 分层多路增广 $O(\sqrt V E)$；König 定理把最大匹配与最小点覆盖对偶。实现关键是 `seen` 每轮重置、两部下标区分、先判二分性。带权用 KM，一般图用 Blossom。匹配又是网络流的特例，理解增广路能同时打通匈牙利与 FF/Dinic 两大体系。
