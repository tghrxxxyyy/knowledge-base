# 最短路变体

> 对应 CLRS《Introduction to Algorithms》第 25 章 All-Pairs Shortest Paths，以及 Hart-Nilsson-Raphael A* 论文、Yen (1971) k 最短路算法。

## 一、背景与挑战

标准最短路解决的是「单源、无附加限制、求一条最短」。真实问题往往带各种变体：全源（任意两点都要）、含负权全源、到达目标前最多经过 $k$ 条边、必须走某些中转、求第 $k$ 短、带启发式引导到指定终点、路径权值有二次代价（瓶颈、字典序）等。这些变体若不会归约建模，就会手写 DFS 暴力或错用 Dijkstra。

典型痛点：Floyd 的三重循环里 `k` 必须在最外层，写错顺序结果错误；差分约束的不等式方向写反，跑出的最短路是「最大解」或根本不约束；分层图（限制中转次数）建不好图，状态数爆炸或漏状态；A* 启发式不满足可采纳性，得到的不是最优解。工程中，路由器要算全源、导航要 A*、排班要差分约束、航司要 k 条备选航线——变体能力比裸模板更值钱。

## 二、核心原理

**Floyd-Warshall**：全源最短路的 DP。设 $dist[i][j]$ 为只用前 $k$ 个点作中转时 $i\to j$ 的最短距离。转移：

$$
dist[i][j] = \min(dist[i][j],\ dist[i][k] + dist[k][j]).
$$

三层循环中 **$k$ 必须在最外层**：$k$ 是「允许使用中转点编号 $\le k$」的阶段变量，内层更新时要用到「阶段 $k$」的 $dist[i][k]$ 与 $dist[k][j]$。若把 $k$ 放内层，等于用了错误阶段的信息，结果不保证正确。复杂度 $O(V^3)$，空间 $O(V^2)$，可同时判负环（对角线变负）。

**差分约束**：约束形如 $x_j - x_i \le c$，转成边 $i \to j$ 权 $c$，跑最短路。若最短路存在（无负环），则 $dist[j] \le dist[i] + c$ 恰好满足约束。建超级源点连向所有点权 0，跑 Bellman-Ford。有解当且仅当约束图无负环。常见题：任务调度（$start_b \ge start_a + dur_a$ 转为 $start_a - start_b \le -dur_a$）、身高排队、差值最大值。

**分层图 / 状态扩展**：把「已用步数/中转次数/优惠券」作为状态维。点扩展为 $(v, t)$，$t$ 表示已用资源。边权转移时更新 $t$。求「最多 $k$ 条边」的最短路，层号就是已用边数，最终答案取 `dist[t][0..k]` 的最小值。BFS/DP 按层推进即可，复杂度 $O(kE)$。

**A\***：启发式引导的 Dijkstra。优先级 $f(n)=g(n)+h(n)$，$g$ 为已走代价，$h$ 为启发式估计。若 $h$ **可采纳**（不高估真实剩余代价）且**一致**（三角不等式 $h(a) \le w(a,b)+h(b)$），A* 保证最优且效率高。常用于网格寻路、拼图、游戏 AI。$h=0$ 时退化为 Dijkstra，$h$ 越准越快。

**k 最短路**：Yen 算法基于 $k-1$ 次偏离：先求最短路 $P_1$，再对 $P_1$ 的前缀做禁止约束求偏离路径，维护候选小顶堆。复杂度约 $O(kV(VE+V\log V))$。适用于要多条备选路线。

**Johnson 全源（预告）**：用势函数重赋权消负权，再 $n$ 次 Dijkstra，稀疏负权全源更优，见对比表。

## 三、形式化与数学基础

Floyd 的 DP 正确性：定义 $D_k[i][j]$ 为中转点限制在 $\{1..k\}$ 的最短路。最优子结构：若最短路中转不含 $k$，则 $D_k[i][j]=D_{k-1}[i][j]$；若含 $k$，则拆成 $i\leadsto k$ 与 $k\leadsto j$ 两段，各自中转 $<k$。故

$$
D_k[i][j] = \min(D_{k-1}[i][j],\ D_{k-1}[i][k] + D_{k-1}[k][j]).
$$

$D_0$ 即邻接矩阵（$w(i,j)$，$i=j$ 为 0）。$D_n$ 为答案。这解释了为何 $k$ 要外层：阶段必须严格递增。

差分约束的对偶：不等式组 $x_j - x_i \le c_{ij}$ 的解集，与「以 $c_{ij}$ 为边权的图上不存在负环」等价。最小解由最短路给出，最大解由最短路取负（或最长路）给出。方向规则：$x_j \le x_i + c$ 即 $i \to j$ 权 $c$。

A* 可采纳性：若 $h(n) \le \delta(n, goal)$，则 A* 展开目标时 $g=δ(s,goal)$ 一定最优。一致性 $h(a) \le w(a,b)+h(b)$ 蕴含可采纳性，且保证展开过的点不再更新（类似 Dijkstra）。

k 最短路复杂度：Yen 为 $O(k V (E + V\log V))$ 级别，Eppstein 用偏离树降到 $O(E + V\log V + k\log k)$。

分层图正确性：把资源（步数）纳入状态，转移无后效性，等价于在更大的状态图上跑最短路；复杂度 $O(kE)$ 或 $O(k(V+E)\log V)$。

## 四、代码实现

Floyd（含路径还原）、差分约束（Bellman-Ford）、分层图限 k 边最短路、A* 网格寻路，均可运行。

```python
from typing import List, Tuple
import heapq

INF = float('inf')


def floyd_warshall(w: List[List[float]]) -> List[List[float]]:
    """全源最短路。w[i][j] 为权，不邻接为 INF，w[i][i] 应为 0。
    返回 dist 矩阵；若 dist[i][i] < 0 则存在负环。
    """
    n = len(w)
    dist = [row[:] for row in w]
    for i in range(n):
        dist[i][i] = 0.0
    for k in range(n):          # k 必须在最外层
        dk = dist[k]
        for i in range(n):
            di = dist[i]
            dik = di[k]
            if dik == INF:
                continue
            for j in range(n):
                nd = dik + dk[j]
                if nd < di[j]:
                    di[j] = nd
    return dist


def difference_constraints(
    n: int, edges: List[Tuple[int, int, float]], s: int = 0
) -> List[float]:
    """
    差分约束：约束 x_j - x_i <= c 对应边 (i, j, c)。
    返回从超级源点 s 出发的最短路（一组合法解），无解返回 []。
    """
    # 超级源点 s = n 连向所有点，权 0
    # 这里 s 参数用作超级源点编号（通常传 n），简化为直接从 0 源跑需保证连通
    m = n + 1
    dist = [INF] * m
    dist[s] = 0.0
    all_edges = list(edges) + [(s, i, 0.0) for i in range(n)]
    for _ in range(m - 1):
        upd = False
        for u, v, c in all_edges:
            if dist[u] != INF and dist[u] + c < dist[v]:
                dist[v] = dist[u] + c
                upd = True
        if not upd:
            break
    for u, v, c in all_edges:
        if dist[u] != INF and dist[u] + c < dist[v]:
            return []  # 负环，无解
    return dist[:n]


def shortest_path_within_k(
    graph: List[List[Tuple[int, int]]], s: int, t: int, k: int
) -> float:
    """分层图：最多经过 k 条边的 s->t 最短路。graph[u] = [(v,w)]。"""
    n = len(graph)
    # dist[v][c] = 经过 c 条边到达 v 的最短距离
    dist = [[INF] * (k + 1) for _ in range(n)]
    dist[s][0] = 0.0
    for c in range(k):
        for u in range(n):
            if dist[u][c] == INF:
                continue
            for v, w in graph[u]:
                if dist[u][c] + w < dist[v][c + 1]:
                    dist[v][c + 1] = dist[u][c] + w
    return min(dist[t])


def astar_grid(grid: List[List[int]], start: Tuple[int, int], goal: Tuple[int, int]) -> float:
    """
    网格 0/1 障碍寻路，四方向，代价 1。返回最短步数，不可达 INF。
    启发式：曼哈顿距离（可采纳且一致）。
    """
    rows, cols = len(grid), len(grid[0])
    if grid[start[0]][start[1]] or grid[goal[0]][goal[1]]:
        return INF

    def h(a: Tuple[int, int]) -> int:
        return abs(a[0] - goal[0]) + abs(a[1] - goal[1])

    g = {start: 0}
    # f, g, node
    open_heap = [(h(start), 0, start)]
    closed = set()
    while open_heap:
        f, gu, u = heapq.heappop(open_heap)
        if u in closed:
            continue
        if u == goal:
            return gu
        closed.add(u)
        r, c = u
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if not (0 <= nr < rows and 0 <= nc < cols) or grid[nr][nc] == 1:
                continue
            v = (nr, nc)
            ng = gu + 1
            if ng < g.get(v, INF):
                g[v] = ng
                heapq.heappush(open_heap, (ng + h(v), ng, v))
    return INF


if __name__ == "__main__":
    w = [
        [0, 3, INF, 5],
        [2, 0, INF, 4],
        [INF, 1, 0, INF],
        [INF, INF, 2, 0],
    ]
    d = floyd_warshall(w)
    assert d[0][2] == 5  # 0->3->2 = 5+2
    assert d[2][0] == 3  # 2->1->0 = 1+2
    # 差分约束：x1 - x0 <= 2, x0 - x1 <= -1  => 1 <= x0-x1 <= 2
    # 用超级源点 n=2
    cons = difference_constraints(2, [(0, 1, 2.0), (1, 0, -1.0)], s=2)
    assert cons  # 有解
    # 分层图：0->1->2，0->2 权 5，k=1 时不能走两段
    g = [[(1, 1), (2, 5)], [(2, 1)], []]
    assert shortest_path_within_k(g, 0, 2, 1) == 5.0
    assert shortest_path_within_k(g, 0, 2, 2) == 2.0
    grid = [
        [0, 0, 0],
        [1, 1, 0],
        [0, 0, 0],
    ]
    assert astar_grid(grid, (0, 0), (2, 2)) == 4
    print("shortest path variants ok")
```

## 五、与其他技术对比

| 需求 | 推荐算法 | 复杂度 | 备注 |
| --- | --- | --- | --- |
| 单源非负 | Dijkstra | $O((V+E)\log V)$ | 最常用 |
| 单源含负权 | Bellman-Ford / SPFA | $O(VE)$ | 可判负环 |
| 全源小图 | Floyd | $O(V^3)$ | 实现简单、可判负环 |
| 全源稀疏含负 | Johnson | $O(VE + V^2\log V)$ | 重赋权 + n 次 Dijkstra |
| 限定步数 / 资源 | 分层图 DP | $O(kE)$ | 状态维扩展 |
| 有启发式目标 | A* | 依赖 h 质量 | 寻路、拼图 |
| 第 k 短 | Yen / Eppstein | 见正文 | 多备选路线 |
| 差分约束 | Bellman-Ford 建模 | $O(VE)$ | 调度、不等式组 |

Floyd vs Johnson：$V\le 400$ 或稠密、要路径还原/判负环，Floyd 更省事；$V$ 上千、稀疏、含负权，Johnson 明显更快。A* vs Dijkstra：有明确目标点且启发式可靠时 A* 远快；全源或无启发式就 Dijkstra。

## 六、常见误区

1. **Floyd 的 `k` 循环放内层**。`for i: for j: for k:` 是经典错法，会用到错误阶段的中转信息，结果可能偏大或错误。必须 `for k: for i: for j:`。
2. **差分约束边的方向写反**。$x_j - x_i \le c$ 对应 $i\to j$ 权 $c$（不是 $j\to i$）。写反会得到不满足约束的解或误判无解。建议用小例子手推验证。
3. **A* 启发式高估（不可采纳）**。如网格斜向可达却用欧氏距离乘大系数，会导致非最优。后果是「看似最优实则绕远」。可采纳性 $h \le h^*$ 必须守住。
4. **分层图层数边界**。限制「最多 $k$ 条边」时要开 $k+1$ 层（$0..k$）；答案取 `min(dist[t][*])` 而不是 `dist[t][k]`，否则会要求恰好 $k$ 条边。
5. **Floyd 忘记初始化对角线为 0**。若 $w[i][i]=INF$，自己到自己的距离错误，影响后续 $dist[i][j]=\min(..., dist[i][k]+dist[k][j])$ 的所有更新。

## 八、面试题

**1. 「最多经过 k 个中转站的最便宜航班」（LeetCode 787）怎么做？**

参考答案：分层图或 Bellman-Ford 限制松弛轮数。`dist[v][c]` 表示恰好 $c$ 条边到 $v$ 的最小代价，跑 $k+1$ 轮松弛，答案为 `min(dist[t][0..k+1])`。复杂度 $O(kE)$。也可用 Dijkstra 状态为 `(cost, node, stops)` 优先队列，超 $k$ 停。

**2. Floyd-Warshall 为什么 `k` 要放最外层？**

参考答案：$k$ 是 DP 的阶段变量，表示「只允许编号 $\le k$ 的点作中转」。内层更新需要 $D_{k-1}[i][k]$ 与 $D_{k-1}[k][j]$ 的正确值。若 $k$ 在内层，会被同阶段的中间结果污染，最优子结构不成立。

**3. 差分约束如何把不等式组转成最短路？**

参考答案：$x_j - x_i \le c$ 建边 $i \to j$ 权 $c$。跑最短路后 $dist$ 即一组合法解（若无负环）。求最大解可对最长路或取负。常见于「A 至少比 B 多 x」「任务先后」类题。

**4. A* 与 Dijkstra 的关系？**

参考答案：A* 是带启发式 $h$ 的 Dijkstra，优先级 $f=g+h$。$h\equiv 0$ 时完全等价。若 $h$ 可采纳且一致，A* 保证最优且展开节点更少；若 $h$ 高估，可能不最优。常用于有明确目标的寻路。

## 九、演进与趋势

全源最短路在图直径、网络延迟评估、中心性计算中广泛应用；工程侧用 Johnson、预计算 Hub Labeling 加速查询。寻路领域，A* 家族扩展出 Jump Point Search、Anytime Repairing A*、Learning to Search（神经启发式）。k 最短路用于航司备选、多路径路由、鲁棒优化。分层图思想延伸到时间依赖最短路（TDSP）、多准则最短路（Pareto）。

动态与增量最短路（边权更新、图演化）是数据库与地图服务的研究热点。约束求解与最短路的融合（SMT 中的差分逻辑）用于形式化验证。掌握 Floyd/差分约束/A*/分层图这四种核心变体，足以覆盖大多数面试与工程场景。

## 十、小结

最短路变体靠「换建模、换阶段」统一：Floyd 用 DP 阶段枚举中转点（$k$ 必须外层）；差分约束把不等式建成边跑 Bellman-Ford；分层图把资源限制纳入状态；A* 用可采纳启发式引导目标搜索。复杂度与正确性各有前提（负权、可采纳性、层数边界）。把变体归约到「松弛 + 状态定义」，就能举一反三地解决限步、中转、k 短路、全源等需求。
