# 最短路变体

> 对应 CLRS《Introduction to Algorithms》Ch.24 与 25（全源最短路）。

## 一、背景与挑战
基础最短路之外的需求：含负权全源（Floyd-Warshall）、启发式 A*、k 短路、差分约束、含中转限制。

## 二、核心原理
Floyd-Warshall 用 DP 枚举中间点；差分约束把 `x_j - x_i <= c` 转为边 `i→j` 权 c 跑最短路；A* 用启发式剪枝。

## 三、形式化 / 数学基础
Floyd：
$dist[i][j] = \min\big(dist[i][j],\, dist[i][k] + dist[k][j]\big)$，复杂度 $O(V^3)$。
差分约束有解当且仅当对应约束图无负环。

## 四、代码实现
```python
def floyd_warshall(d):
    n = len(d)
    for k in range(n):
        for i in range(n):
            for j in range(n):
                if d[i][k] + d[k][j] < d[i][j]:
                    d[i][j] = d[i][k] + d[k][j]
    return d
```

## 五、与其他技术对比
Floyd 适合全源小图；Johnson 用重赋权 + Dijkstra 处理稀疏带负权全源；A* 比 Dijkstra 更快到达目标。

## 六、常见误区
Floyd 中间点 k 必须放最外层；差分约束符号方向写反；A* 启发式不满足可采纳性导致非最优。

## 八、面试题
「房屋染色/任务调度」差分约束；「网络中转次数限制」分层图最短路。

## 九、演进与趋势
k 短路（Yen 算法）；分层图处理状态维；双向 BFS/Dijkstra。

## 十、小结
最短路变体多用 DP（Floyd）或图建模（差分约束）统一处理；分清「全源/单源/启发式」选用不同算法。
