# 最短路径算法

> 对应 CLRS《Introduction to Algorithms》第 24 章 Single-Source Shortest Paths，以及 Dijkstra (1959)、Bellman-Ford 原始论文。

## 一、背景与挑战

最短路问题是图算法的核心基础：从网络路由（OSPF、IS-IS 用 Dijkstra）、地图导航（A*、收缩层级）、社交网络距离、到任务调度中的关键路径与差分约束，几乎一切「代价最小路径」需求最终都会落到最短路算法上。形式上，给定带权有向图 $G=(V,E,w)$ 与源点 $s$，求 $s$ 到每个顶点 $v$ 的最小权值路径；或全源版本求所有点对的最短路。

难点在于边权的多样性。边权非负时，Dijkstra 的贪心是正确的；一旦出现负权，贪心的「已确定距离不再更新」不再成立，必须换成更慢的松弛迭代；若含负环，「最短路」可能无定义（可绕环无限缩短）。另一个工程挑战是规模：点数 $10^6$、边数 $10^7$ 的路网上，算法的常数、堆优化、提前终止、双向搜索都直接影响体验。面试中最常考的是「什么时候用哪个算法、复杂度是多少、负权怎么办、如何判负环」。

## 二、核心原理

**松弛（Relaxation）** 是所有最短路算法的统一动作。对边 $(u,v)$ 权 $w$，若 `dist[v] > dist[u] + w`，则更新 `dist[v] = dist[u] + w`。松弛不断把「经由新路径更短」的信息传播出去。

**Dijkstra**：贪心 + 优先队列。维护 `dist` 与「已确定」集合。每次从未确定点中取 `dist` 最小者 $u$，宣布其距离已最终确定，然后松弛 $u$ 的所有出边。正确性依赖非负权：非负权保证「当前最小的 dist 不可能被后面的点更新得更小」，因此取出即可定死。实现用二叉堆，`heapq` 惰性删除（允许重复入队，取出时若 `d > dist[u]` 则跳过）。

**Bellman-Ford**：容忍负权。对所有边做 $|V|-1$ 轮松弛。第 $k$ 轮结束后，最多经过 $k$ 条边的最短路已确定。$|V|-1$ 轮后若还能松弛，说明存在负环且影响到 $s$ 可达的点。它不需要堆，常数小，但最坏 $O(VE)$，比 Dijkstra 慢。

**SPFA（队列优化 Bellman-Ford）**：用队列维护「dist 变化的点」，只松弛这些点的出边。平均快很多，但最坏仍是 $O(VE)$，竞赛中可被卡成退化数据（因此可靠场合更倾向 Dijkstra 或原始 BF）。

**BFS**：边权全为 $1$（或全相等）时的特例，队列即优先队列，$O(V+E)$。0-1 边权用双端队列（0 边 push_front，1 边 push_back）。

**关键不变量**：Dijkstra 中「已出堆的点 dist 最终确定」；Bellman-Ford 中「第 $k$ 轮后，$k$ 条边内的最短路已算对」。两者都靠松弛的单调性：`dist` 只降不升。

## 三、形式化与数学基础

**三角不等式**：对任意边 $(u,v)$，$\delta(s,v) \le \delta(s,u) + w(u,v)$，其中 $\delta$ 为真实最短距离。松弛就是在维护这个不等式。

**Dijkstra 正确性**（剪贴论证）：设 $u$ 是 `dist` 最小的未确定点。假设 $\delta(s,u) < dist[u]$，则真实最短路径 $s\leadsto u$ 上必有第一条离开已确定集合的边 $(x,y)$，其中 $x$ 已确定、$y$ 未确定。由于 $x$ 已确定，$\delta(s,x)=dist[x]$，于是

$$
\delta(s,y) = \delta(s,x) + w(x,y) = dist[x] + w(x,y) \ge dist[y] \ge dist[u],
$$

与 $u$ 取最小及 $\delta(s,u) < dist[u]$ 矛盾（因为 $\delta(s,y) \le \delta(s,u)$）。故 $dist[u]=\delta(s,u)$。

**Dijkstra 复杂度**：二叉堆 $O((V+E)\log V)$；Fibonacci 堆 $O(E + V\log V)$；稠密图用数组 $O(V^2)$ 更优。惰性删除版本实现简单，最坏入队 $O(E)$ 次。

**Bellman-Ford 正确性**：归纳轮数 $k$。$k=0$ 时无边路径显然。设第 $k$ 轮后所有 $\le k$ 条边的最短路已确定；第 $k+1$ 轮松弛所有边，则 $\le k+1$ 条边的最短路可写成 $\le k$ 条边的最短路再加一条边，被松弛更新。故 $|V|-1$ 轮后（简单路径最多 $|V|-1$ 条边）全部正确。

**负环检测**：第 $|V|$ 轮仍可松弛，说明路径上有点数超过 $|V|$，必然有环，且环权为负。若只要求判负环而不关心距离，可加超级源点连向所有点再跑一次。

**Floyd 预告**：全源最短路可用 $n$ 次 Dijkstra（非负权）或 Floyd-Warshall DP，详见「最短路变体」。

## 四、代码实现

Dijkstra（堆 + 惰性删除）、Bellman-Ford（含负环检测）、SPFA 三件套，可直接运行。

```python
import heapq
from collections import deque
from typing import Dict, List, Optional, Tuple

INF = float('inf')


def dijkstra(graph: List[List[Tuple[int, int]]], s: int) -> List[float]:
    """
    非负权单源最短路。graph[u] = [(v, w), ...]
    返回 dist 列表，不可达为 INF。
    """
    n = len(graph)
    dist = [INF] * n
    dist[s] = 0
    pq = [(0, s)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue  # 惰性删除：过期条目跳过
        for v, w in graph[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist


def dijkstra_with_path(graph: List[List[Tuple[int, int]]], s: int, t: int) -> Tuple[float, List[int]]:
    """返回 (最短距离, 路径)。不可达时路径为空。"""
    n = len(graph)
    dist = [INF] * n
    prev = [-1] * n
    dist[s] = 0
    pq = [(0, s)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        if u == t:
            break  # 提前终止
        for v, w in graph[u]:
            if d + w < dist[v]:
                dist[v] = d + w
                prev[v] = u
                heapq.heappush(pq, (dist[v], v))
    if dist[t] == INF:
        return INF, []
    path = []
    cur = t
    while cur != -1:
        path.append(cur)
        cur = prev[cur]
    path.reverse()
    return dist[t], path


def bellman_ford(n: int, edges: List[Tuple[int, int, int]], s: int) -> Optional[List[float]]:
    """
    边列表 edges = [(u, v, w)]。返回 dist 或 None（s 可达负环）。
    """
    dist = [INF] * n
    dist[s] = 0
    for _ in range(n - 1):
        updated = False
        for u, v, w in edges:
            if dist[u] != INF and dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                updated = True
        if not updated:
            break  # 提前收敛
    # 第 n 轮检测负环
    for u, v, w in edges:
        if dist[u] != INF and dist[u] + w < dist[v]:
            return None  # 负环影响最短路
    return dist


def spfa(n: int, graph: List[List[Tuple[int, int]]], s: int) -> Optional[List[float]]:
    """队列优化 Bellman-Ford。返回 dist 或 None（存在负环）。"""
    dist = [INF] * n
    inq = [False] * n
    cnt = [0] * n  # 入队次数，超过 n 判负环
    dist[s] = 0
    q = deque([s])
    inq[s] = True
    while q:
        u = q.popleft()
        inq[u] = False
        for v, w in graph[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                if not inq[v]:
                    q.append(v)
                    inq[v] = True
                    cnt[v] += 1
                    if cnt[v] > n:
                        return None  # 负环
    return dist


def bfs_shortest(graph: List[List[int]], s: int) -> List[float]:
    """无权图最短路（边权视为 1）。"""
    n = len(graph)
    dist = [-1] * n
    dist[s] = 0
    q = deque([s])
    while q:
        u = q.popleft()
        for v in graph[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)
    return [INF if d < 0 else d for d in dist]


if __name__ == "__main__":
    # 0->1(1), 0->2(4), 1->2(2), 1->3(5), 2->3(1)
    g = [
        [(1, 1), (2, 4)],
        [(2, 2), (3, 5)],
        [(3, 1)],
        [],
    ]
    assert dijkstra(g, 0) == [0, 1, 3, 4]
    d, p = dijkstra_with_path(g, 0, 3)
    assert d == 4 and p == [0, 1, 2, 3]
    edges = [(0, 1, 1), (0, 2, 4), (1, 2, 2), (1, 3, 5), (2, 3, 1)]
    assert bellman_ford(4, edges, 0) == [0, 1, 3, 4]
    # 负权边
    g2 = [[(1, 1)], [(2, -2)], []]
    assert dijkstra(g2, 0)[2] == -1  # 虽能算，但负权下 Dijkstra 不保证正确
    assert bellman_ford(3, [(0, 1, 1), (1, 2, -2)], 0) == [0, 1, -1]
    # 负环
    assert bellman_ford(3, [(0, 1, 1), (1, 2, -5), (2, 1, 2)], 0) is None
    print("shortest paths ok")
```

## 五、与其他技术对比

| 算法 | 边权要求 | 复杂度 | 负权 | 负环检测 | 典型场景 |
| --- | --- | --- | --- | --- | --- |
| BFS | 全为 1 | $O(V+E)$ | 否 | 否 | 无权图、网格步数 |
| 0-1 BFS | 仅 0/1 | $O(V+E)$ | 否 | 否 | 双状态边权 |
| Dijkstra（堆） | 非负 | $O((V+E)\log V)$ | 否 | 否 | 路由、导航、一般带权 |
| Bellman-Ford | 任意 | $O(VE)$ | 是 | 是 | 含负权、差分约束 |
| SPFA | 任意 | 均摊快，最坏 $O(VE)$ | 是 | 是 | 竞赛负权（注意被卡） |
| Floyd | 任意 | $O(V^3)$ | 是 | 是 | 小图全源、路径还原 |
| Johnson | 任意 | $O(VE + V^2\log V)$ | 是 | 是 | 稀疏图全源负权 |

取舍：非负权一律 Dijkstra；要判负环或有负权用 Bellman-Ford（稳）或 SPFA（快但可被卡）；无权/0-1 用 BFS 变体。全源小图用 Floyd，大图非负用 $n$ 次 Dijkstra。

## 六、常见误区

1. **对负权边使用 Dijkstra**。贪心的「取出即确定」不再成立，会算错且不报错。后果是静默错误答案，难以排查。判据：只要可能有负权就别用 Dijkstra。
2. **SPFA 被构造数据卡成 $O(VE)$**。SPFA 平均快，但有专门的卡 SPFA 数据（网格 + 负边回路），竞赛中若时限紧、图可能被构造，应改用 Dijkstra 或原始 Bellman-Ford。
3. **`dist` 用 `INF` 相加溢出**。`INF + w` 若 `INF` 是 `float('inf')` 没问题，但若用 `10**18` 这类大整数，`INF + w` 仍可能被松弛判断误用。松弛前应判断 `dist[u] != INF`。
4. **忘记惰性删除去重导致超时**。堆优化版本每条边可能多次入队，`if d > dist[u]: continue` 不能省；否则退化为大量无效松弛。这不是错误而是性能坑。
5. **负环检测只跑一轮就结束**。Bellman-Ford 必须在 $n-1$ 轮之后再跑一轮才能判负环；提前 `break`（`updated=False`）可以，但负环检测要单独进行。
6. **前驱数组还原路径时起点处理错误**。`prev[s]` 应保持 `-1`，还原循环 `while cur != -1`，否则死循环或路径颠倒。

## 八、面试题

**1. 网络延迟时间（LeetCode 743）：给定有向图与源点 k，求信号传到所有节点的最长时间。**

参考答案：即求 $k$ 到所有点的最短路最大值（边权非负用 Dijkstra）。跑一遍 Dijkstra 后取 `max(dist)`，若有不可达返回 $-1$。复杂度 $O((V+E)\log V)$。

**2. 为什么 Dijkstra 不能处理负权？给出反例。**

参考答案：非负权保证「取出的最小 dist 不再更新」。反例：$s\to a$ 权 $2$，$s\to b$ 权 $3$，$b\to a$ 权 $-2$。先取 $a$ 定为 $2$，但真实 $\delta(s,a)=3+(-2)=1$，已确定错误。必须用 Bellman-Ford。

**3. 如何判断有向图中是否存在从源点可达的负环？**

参考答案：Bellman-Ford 跑 $|V|-1$ 轮后再对所有边松弛一轮，若仍能更新则存在可达负环。或 SPFA 中记录入队次数，某点入队超过 $|V|$ 次判负环。若要判「图中任意负环」，加超级源点连所有点。

**4. 给定带权图，求从 s 到 t 的第 k 短路径？**

参考答案：基础版用 Yen 算法（$k-1$ 次最短路偏离）或 Eppstein 算法；也可用 A* 变体或优先队列保存「到每个点的第 i 短距离」的扩展搜索。面试中常简化为 k=2 的次短路，用维护 `dist1/dist2` 的 Dijkstra 变体。

## 九、演进与趋势

工程最短路远超教科书算法。导航领域用**收缩层级（Contraction Hierarchies）**、**Arc Flags**、**Hub Labeling**，把点对查询压到微秒级，支撑手机地图的实时规划。路由协议中 OSPF/IS-IS 跑 Dijkstra，BGP 在策略层面做路径向量；SDN 里集中式控制器算路径并下发。GPU/并行最短路（delta-stepping、GPU-Dijkstra）用于超大图。

学术侧，负权全源的 Johnson 算法、有向图近似距离或acles、动态图最短路（边插入删除）持续活跃。机器学习与最短路的结合（学习式 A*、神经引导搜索）也在快速发展。掌握经典松弛与贪心证明，是读懂一切工程变体的前提。

## 十、小结

最短路的灵魂是**松弛**：`dist[v] = min(dist[v], dist[u]+w)`。非负权用 Dijkstra（贪心 + 堆，$O((V+E)\log V)$）；含负权用 Bellman-Ford（$|V|-1$ 轮，$O(VE)$）并检测负环；SPFA 是其队列优化但最坏仍 $O(VE)$；无权图 BFS 即可。理解「取出即确定」为何依赖非负权、$|V|-1$ 轮为何足够，比背模板更重要。面试中「网络延迟时间」「便宜航班」等题，本质都是选对算法 + 正确建图。
