# 最短路径算法

> 对应 CLRS《Introduction to Algorithms》第 24 章 Single-Source Shortest Paths。

## 一、背景与挑战
求单源/全源最短路。Dijkstra 要求边权非负；Bellman-Ford 容忍负权并检测负环；SPFA 是其队列优化（最坏仍 O(VE)）。

## 二、核心原理
Dijkstra 每次取当前距离最小的点松弛其邻边（贪心 + 优先队列）；Bellman-Ford 重复松弛所有边 V-1 轮。

## 三、形式化 / 数学基础
Dijkstra 复杂度：$O((V+E)\log V)$（二叉堆）。
Bellman-Ford：
$\forall e=(u,v,w):\; d[v] = \min(d[v],\, d[u] + w)$，迭代 $V-1$ 轮；第 V 轮仍可松弛则有负环。

## 四、代码实现
```python
import heapq
def dijkstra(graph, s):
    n = len(graph)
    dist = [float('inf')] * n
    dist[s] = 0
    pq = [(0, s)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in graph[u]:
            if dist[v] > d + w:
                dist[v] = d + w
                heapq.heappush(pq, (dist[v], v))
    return dist
```

## 五、与其他技术对比
与 BFS 最短路（无权图）相比，Dijkstra 处理带权；A* 加入启发式加速目标导向搜索。

## 六、常见误区
Dijkstra 遇负权失效；SPFA 被构造数据卡成 O(VE)；未用 visited 去重导致重复入队。

## 八、面试题
「网络延迟时间」Dijkstra；「负权最短路/负环检测」Bellman-Ford。

## 九、演进与趋势
0-1 BFS（双端队列）处理 0/1 边权；瓶颈路与次短路；Johnson 全源最短路。

## 十、小结
非负权用 Dijkstra（堆），含负权用 Bellman-Ford/SPFA 并检测负环；理解松弛（relaxation）是核心。
