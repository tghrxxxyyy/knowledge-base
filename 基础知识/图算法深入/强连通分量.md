# 强连通分量

> 对应 Tarjan, "Depth-First Search and Linear Graph Algorithms" (1972)，CLRS《Introduction to Algorithms》第 22.5 节，以及 Kosaraju-Sharir 两趟 DFS 算法。

## 一、背景与挑战

有向图中，若从 $u$ 可达 $v$ 且从 $v$ 可达 $u$，则 $u,v$ 强连通。强连通分量（Strongly Connected Component, SCC）是极大的强连通子图。SCC 是有向图结构分析的基本操作：缩点后得到 DAG，随后可做拓扑排序、DP、传递闭包、可满足性判定。

工程与面试场景极广。编译器用 SCC 检测循环依赖、计算循环不变量；网页分析用 SCC 理解链接结构（枢纽/权威）；社交网络用 SCC 找「相互关注」圈子；2-SAT 可满足性判定完全依赖 SCC（变量与其否定在同一 SCC 则无解）；状态机化简、电路强连通检测也离不开它。面试题如「冗余连接 II」「最大食物链计数」「课程表」变体，常要求先缩点再 DP。

难点在于：有向图不像无向图那样「连通分量就是并查集」。有向可达性不对称，朴素做法是每对点跑 BFS/Floyd，复杂度 $O(V^2)$ 或 $O(V^3)$，大图不可接受。正确算法要求 $O(V+E)$ 一趟或两趟 DFS，核心是识别「哪些点属于同一个环系」。Tarjan 算法用 `dfn`/`low` 与显式栈在线性时间内完成，是必须掌握的经典。

## 二、核心原理

**Tarjan 算法**：一遍 DFS，为每个点维护两个标号：

- `dfn[u]`：DFS 时间戳，第一次访问 $u$ 的序号；
- `low[u]`：$u$ 及其子孙通过「一条返祖边/横叉边」能回到的最小 `dfn`。

初始化 `dfn[u] = low[u] = timer`。对 $u$ 的每个出边 $u\to v$：

1. 若 $v$ 未访问，递归 $v$，回溯时 `low[u] = min(low[u], low[v])`；
2. 若 $v$ 已访问且 $v$ 在栈中（尚未归入 SCC），`low[u] = min(low[u], dfn[v])`（注意用 `dfn[v]` 而非 `low[v]`，因为 $v$ 尚未定归属）。

当 `low[u] == dfn[u]` 时，$u$ 是当前 SCC 的「根」（最低点），从栈中弹出直到 $u$，弹出集合即一个 SCC。

**不变量**：栈中保存的是「已访问但尚未确定 SCC 归属」的点；`low[u]` 始终是「$u$ 出发经子孙 + 至多一条指向栈中的边」能到达的最小时间戳。`low[u] == dfn[u]` 意味着 $u$ 无法通过子孙回到更早的点，因此 $u$ 是 SCC 根，栈顶到 $u$ 恰为一个极大强连通子图。

**Kosaraju 算法**：两趟 DFS。第一趟在原图上做 DFS，按完成时间倒序记录（后序）；第二趟在反图（所有边反向）上按该顺序 DFS，每趟 DFS 触达的点构成一个 SCC。直观理解：第一趟得到「拓扑序的反」，第二趟从「汇点」开始挖 SCC。

**正确性直觉**：SCC 的缩图是 DAG。DAG 有唯一拓扑序，Kosaraju 第一趟得到逆拓扑序，第二趟沿反图从「最后」的 SCC 开始，一次 DFS 恰好覆盖一个 SCC。Tarjan 则用「找环根 + 栈」在线识别。

**边界条件**：孤立点本身是一个 SCC；自环不影响归属；若图可能不连通，必须对每个未访问点启动 DFS。递归深度可能超限，大图需手写栈。

## 三、形式化与数学基础

定义：$u \sim v$ 当且仅当 $u$ 可达 $v$ 且 $v$ 可达 $u$。$\sim$ 是等价关系（自反、对称、传递），等价类即 SCC。缩点图 $G^{SCC}$ 把每个 SCC 收缩为一点，得到 DAG。

**Tarjan 的 `low` 递推**：

$$
low[u] = \min\Big(dfn[u],\ \min_{u\to v,\ v\ \mathrm{unvisited}} low[v],\ \min_{u\to v,\ v\ \mathrm{onstack}} dfn[v]\Big).
$$

对树边用 `low[v]`（继承子孙的可达），对返祖/指向栈中横边用 `dfn[v]`。注意若 $v$ 已访问且不在栈中，说明 $v$ 已属别的 SCC，不影响 $u$ 的 `low`。

**正确性论证**：`low[u]` 表示 $u$ 能到达的最小 `dfn`（限定「经子孙最多一条指向栈中的边」）。若 `low[u] < dfn[u]`，则 $u$ 能回到严格更早的点，$u$ 不是 SCC 根；若 `low[u] == dfn[u]`，则 $u$ 无法回到祖先，栈中 $u$ 之上的点均经 $u$ 可达且可达 $u$（因为它们是 $u$ 的后代且通过栈内边连回），恰为一个 SCC。

**Kosaraju 正确性**：第一趟后序时间的逆序满足「若 SCC $C_1$ 有边指向 $C_2$，则 $C_1$ 在顺序中先于 $C_2$」（DAG 拓扑逆）。第二趟从最后的 SCC 开始在反图上 DFS，只能访问到同一 SCC 的点，故一趟一个 SCC。

**复杂度**：Tarjan 与 Kosaraju 均为 $O(V+E)$（每点每边常数次）。空间 $O(V)$（栈与数组）。Tarjan 一趟即可，常数更小；Kosaraju 需要反图与两趟 DFS，但思路直观、易并行。

**与 2-SAT 的关系**：对每个变量 $x$ 建节点 $x,\neg x$，蕴含式 $a\Rightarrow b$ 建边。$x$ 与 $\neg x$ 在同一 SCC 则无解；否则按 SCC 拓扑逆序赋值即得解。

## 四、代码实现

Tarjan 与 Kosaraju 两个版本，含缩点辅助。

```python
from typing import List


def tarjan_scc(n: int, adj: List[List[int]]) -> List[List[int]]:
    """
    Tarjan 求 SCC。adj[u] 为 u 的出边邻居。
    返回分量列表，每个分量是顶点列表。
    """
    dfn = [0] * n
    low = [0] * n
    on_stack = [False] * n
    stack: List[int] = []
    comps: List[List[int]] = []
    timer = 0

    def dfs(u: int) -> None:
        nonlocal timer
        timer += 1
        dfn[u] = low[u] = timer
        stack.append(u)
        on_stack[u] = True
        for v in adj[u]:
            if dfn[v] == 0:
                dfs(v)
                low[u] = min(low[u], low[v])
            elif on_stack[v]:
                low[u] = min(low[u], dfn[v])
        if low[u] == dfn[u]:
            comp = []
            while True:
                w = stack.pop()
                on_stack[w] = False
                comp.append(w)
                if w == u:
                    break
            comps.append(comp)

    for i in range(n):
        if dfn[i] == 0:
            dfs(i)
    return comps


def kosaraju_scc(n: int, adj: List[List[int]]) -> List[List[int]]:
    """
    Kosaraju：原图 DFS 后序 + 反图 DFS。
    """
    rev = [[] for _ in range(n)]
    for u in range(n):
        for v in adj[u]:
            rev[v].append(u)

    visited = [False] * n
    order: List[int] = []

    def dfs1(u: int) -> None:
        visited[u] = True
        for v in adj[u]:
            if not visited[v]:
                dfs1(v)
        order.append(u)

    for i in range(n):
        if not visited[i]:
            dfs1(i)

    def dfs2(u: int, comp: List[int]) -> None:
        visited[u] = True
        comp.append(u)
        for v in rev[u]:
            if not visited[v]:
                dfs2(v, comp)

    visited = [False] * n
    comps: List[List[int]] = []
    for u in reversed(order):
        if not visited[u]:
            comp: List[int] = []
            dfs2(u, comp)
            comps.append(comp)
    return comps


def condensation(n: int, adj: List[List[int]], comps: List[List[int]]) -> List[List[int]]:
    """缩点：返回 SCC DAG 的邻接表（分量编号为 comps 下标）。"""
    comp_id = [0] * n
    for idx, comp in enumerate(comps):
        for v in comp:
            comp_id[v] = idx
    m = len(comps)
    dag = [set() for _ in range(m)]
    for u in range(n):
        for v in adj[u]:
            if comp_id[u] != comp_id[v]:
                dag[comp_id[u]].add(comp_id[v])
    return [sorted(s) for s in dag]


if __name__ == "__main__":
    # 0->1->2->0, 2->3, 3->4, 4->3
    adj = [
        [1],
        [2],
        [0, 3],
        [4],
        [3],
    ]
    c1 = tarjan_scc(5, adj)
    c2 = kosaraju_scc(5, adj)
    s1 = sorted(sorted(c) for c in c1)
    s2 = sorted(sorted(c) for c in c2)
    assert s1 == s2
    assert [0, 1, 2] in s1
    assert [3, 4] in s1
    print("SCC ok:", c1)
    dag = condensation(5, adj, c1)
    print("condensation:", dag)
```

## 五、与其他技术对比

| 算法 | 趟数 | 需要反图 | 复杂度 | 特点 |
| --- | --- | --- | --- | --- |
| Tarjan | 1 | 否 | $O(V+E)$ | 常数小、在线、手写栈注意递归 |
| Kosaraju | 2 | 是 | $O(V+E)$ | 直观、易并行、常数略大 |
| Path-based SCC | 1 | 否 | $O(V+E)$ | 与 Tarjan 类似、显式栈更清晰 |
| Floyd / 传递闭包 | — | — | $O(V^3)$ | 仅小图，易超时 |

与无向图双连通分量（BCC）对比：BCC 求割点/桥，`low` 定义类似但判据是 `low[v] > dfn[u]`（割边）；SCC 用栈与 `low[u]==dfn[u]`。与并查集对比：并查集适合无向连通性，有向强连通不能用并查集（可达性不对称）。

## 六、常见误区

1. **`low` 更新对返祖边用 `low[v]` 而非 `dfn[v]`**。当 $v$ 在栈中，只能确定 $u$ 可到 $v$ 的 `dfn`；用 `low[v]` 会把尚未确认归属的更早值错误传播，导致 SCC 合并错误（漏分或超大分量）。
2. **忘记 `on_stack` 判据**。已访问但已出栈的点属于别的 SCC，不应更新 `low`。漏判会跨 SCC 污染 `low`，结果把无关分量并成一个。
3. **递归爆栈**。链式图 $V=10^5$ 级 Python 递归会 `RecursionError`。需 `sys.setrecursionlimit` 或改写显式栈。
4. **Kosaraju 第二趟顺序错误**。必须按第一趟完成时间的**逆序**启动 DFS，顺序错了会把多个 SCC 拆散或并成一个。
5. **缩点时漏边或重复边**。SCC DAG 构建要跳过同分量边并去重，否则后续拓扑/DP 会因重边重复计算。

## 八、面试题

**1. 「冗余连接 II」（LeetCode 685）怎么用 SCC？**

参考答案：有向图多一条边导致环或双父。可先判是否有点双父；若有，优先尝试删除两条「候选边」中靠后的，跑 DFS/并查集判环。SCC 视角：若加入后产生非平凡 SCC（规模 $\ge 2$），说明形成环，环上最后加入的边即冗余。缩点 + 判环是通用做法。

**2. 最大食物链计数（NOIP 类）为什么先缩点？**

参考答案：食物网是有向图，缩点后成为 DAG，可在 DAG 上 DP 求最长链或路径计数。同一 SCC 内的点互相可达，若不缩点，简单 DP 会因环而无法定义「上一步」。缩点后 DP 正确且高效。

**3. Tarjan 中 `low[u]` 的含义是什么？何时弹栈？**

参考答案：`low[u]` 是 $u$ 及其子孙经至多一条返祖边能回到的最小 `dfn`。当 `low[u] == dfn[u]` 时 $u$ 是 SCC 根，弹出栈顶到 $u$ 的所有点为一个 SCC。`low` 必须在递归返回后更新，且对栈中邻居用 `dfn[v]`。

**4. 如何用 SCC 判定 2-SAT？**

参考答案：每个变量 $x$ 建 $x$ 与 $\neg x$，每个蕴含式 $a\Rightarrow b$ 建有向边。求 SCC 后，若存在 $x$ 与 $\neg x$ 在同一 SCC，则无解；否则按 SCC 的拓扑逆序，为每个变量赋「所在 SCC 较后的」值即得一解。复杂度 $O(V+E)$。

## 九、演进与趋势

SCC 的工程化延伸包括：外存/磁盘算法（大图装不下内存）、并行 SCC（Boruvka 风格、OpenMP/GPU）、动态 SCC（边插入删除在线维护）。图数据库（Neo4j、TigerGraph）内置 SCC 与社区发现；Web 图（Common Crawl）用 SCC 分析连接结构。2-SAT 广泛用于硬件验证、调度冲突消解、游戏任务依赖。

学术侧，SCC 与图参数化（treewidth）、内核化、近似也有交叉。机器学习图神经网络中，SCC 用于有向图的传播顺序。无论工具如何演进，`dfn/low/栈` 这套经典不变量始终是理解有向图环结构的钥匙。

## 十、小结

强连通分量把有向图化简为 DAG，是拓扑 DP、2-SAT、循环依赖分析的基础。Tarjan 用一趟 DFS 与 `low[u]==dfn[u]` 弹栈在线求出全部 SCC，复杂度 $O(V+E)$；Kosaraju 两趟 DFS（原图后序 + 反图）直观易懂。关键细节：返祖边更新 `low` 用 `dfn[v]`、维护栈内标记、注意递归深度。掌握 SCC，就掌握了有向图「环」这一维结构的通用工具。
