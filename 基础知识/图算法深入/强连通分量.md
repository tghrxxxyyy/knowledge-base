# 强连通分量

> 对应 Tarjan《Depth-First Search and Linear Graph Algorithms》(1972) 与 CLRS Ch.22。

## 一、背景与挑战
将有向图划分为极大强连通子图（SCC），用于缩点把有向图变成 DAG，从而进行拓扑排序类 DP。

## 二、核心原理
Tarjan 用 DFS 编号 dfn 与 low（能回到的最早栈中祖先），当 dfn[u]==low[u] 时弹栈得到一个 SCC；Kosaraju 两次 DFS（原图 + 反图按完成时间）。

## 三、形式化 / 数学基础
$low[u] = \min\big(dfn[u],\,\min_{v\in child} low[v],\,\min_{(u,w)\in back} dfn[w]\big)$
复杂度均为 $O(V+E)$。

## 四、代码实现
```python
def tarjan_scc(n, adj):
    dfn = [0] * n
    low = [0] * n
    on = [False] * n
    st = []
    timer = 0
    comps = []
    def dfs(u):
        nonlocal timer
        timer += 1
        dfn[u] = low[u] = timer
        st.append(u)
        on[u] = True
        for v in adj[u]:
            if dfn[v] == 0:
                dfs(v)
                low[u] = min(low[u], low[v])
            elif on[v]:
                low[u] = min(low[u], dfn[v])
        if low[u] == dfn[u]:
            comp = []
            while True:
                w = st.pop()
                on[w] = False
                comp.append(w)
                if w == u:
                    break
            comps.append(comp)
    for i in range(n):
        if dfn[i] == 0:
            dfs(i)
    return comps
```

## 五、与其他技术对比
与无向图双连通分量（割点/桥）相比，SCC 仅针对有向图；Kosaraju 需反图但思路更直观。

## 六、常见误区
low 更新对返祖边要用 dfn[v] 而非 low[v]；忘记维护栈内标记；递归深度过大需手写栈。

## 十、小结
SCC 把有向图化简为 DAG，Tarjan 一趟 DFS 即可，关键在 low 与栈的正确维护。
