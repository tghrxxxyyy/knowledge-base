# 最小生成树

> 对应 CLRS《Introduction to Algorithms》第 23 章 Minimum Spanning Trees，以及 Kruskal (1956)、Prim (1957) 原始论文、Borůvka 算法。

## 一、背景与挑战

最小生成树（MST）问题：给定连通无向带权图 $G=(V,E,w)$，求一棵生成树（连接全部 $|V|$ 个点、恰好 $|V|-1$ 条边、无环），使总权最小。工程中它无处不在：通信网络布线（电话线、光纤连接全部站点的最小成本）、电网规划、聚类（单链接聚类本质是 MST 边切断）、近似 TSP（MST 前序遍历）、图像分割、VLSI 时钟树。

挑战首先在规模：完全图有 $\binom{n}{2}$ 条边，暴力枚举所有生成树是指数级（Cayley 公式说完全图有 $n^{n-2}$ 棵生成树），不可行。其次，贪心选择必须有严格正确的依据——「局部最小边是否一定属于某个 MST」需要切分性质保证，否则贪心会错。再者，实现细节决定成败：并查集路径压缩与按秩合并影响 Kruskal 的常数；Prim 用堆还是用数组取决于稠密度；图不连通时 MST 不存在，必须检测。

面试中 MST 考频很高：Kruskal/Prim 的复杂度与取舍、切分性质、如何求次小生成树、如何检测「哪些边可以出现在 MST 中」。LeetCode 1584「连接所有点的最小费用」、1135「最低成本联通所有城市」都是标准 MST 题。

## 二、核心原理

MST 的贪心正确性由两条性质支撑：

**切割性质（Cut Property）**：对于图的任意割（把顶点集划分为 $S$ 与 $V\setminus S$），横跨该割的最小权边必然属于某棵 MST。更精确：若 $e$ 是横跨某割的严格最小权边，则 $e$ 在所有 MST 中；若最小不唯一，则至少在一棵 MST 中。

**环性质（Cycle Property）**：环上权值最大的边（严格最大）一定不在任何 MST 中。

**Kruskal**：按边权升序考虑每条边，若两端点尚未连通（用并查集判断），则加入；否则跳过（会形成环，由环性质它不该进）。最终得到 MST。本质是「从小到大贪心，用并查集维护连通性」。

**Prim**：从任意点出发，维护已选点集 $S$。每一步选择连接 $S$ 与 $V\setminus S$ 的最小权边加入（切分性质保证安全），扩张 $S$。用优先队列维护「从 $S$ 到外部的候选边」，实现为「每个点记录 dist 到 $S$ 的最小边权」。

**Borůvka**：每轮对每个连通分量选最小出边，批量合并。轮数 $O(\log V)$，适合并行。

**正确性直觉**：贪心选择安全边（safe edge），归纳保证选中的边集始终可扩展为某棵 MST。并查集/堆只是高效实现「判断连通」「找最小」这两件事。

**不变量**：Kruskal 中并查集维护当前已选边形成的森林，每加入一条边恰合并两个分量，绝不形成环；Prim 中 $S$ 始终是某棵 MST 的顶点集子集（存在一棵 MST 含当前已选边）。

## 三、形式化与数学基础

**切割性质证明**（剪贴）：设 $e=(u,v)$ 是割 $(S, V\setminus S)$ 的最小权边。用反证：假设存在 MST $T$ 不含 $e$。则 $T + e$ 恰含一个环，环上必有另一条边 $e'$ 也横跨该割（因为 $u\in S, v\notin S$）。由 $e$ 最小，$w(e)\le w(e')$。于是 $T - e' + e$ 是生成树且权 $\le w(T)$，故 $e$ 在某个 MST 中。

**Kruskal 正确性归纳**：前 $i$ 条选中的边是某棵 MST 的子集。处理第 $i+1$ 条候选边 $e$ 时，若不连通，$e$ 是当前森林各分量间割的最小边（因为边已按权排序），由切割性质可安全加入。

**复杂度**：
- Kruskal：排序 $O(E\log E)$，并查集操作近 $O(\alpha(V))$，总 $O(E\log E)$（即 $O(E\log V)$，因 $E\le V^2$）。
- Prim（二叉堆）：$O(E\log V)$（每边一次 decrease-key 或惰性入堆）。
- Prim（Fibonacci 堆）：$O(E + V\log V)$，理论最优但常数大。
- Prim（邻接矩阵 + 数组）：$O(V^2)$，稠密图（$E\approx V^2$）时优于堆版本。
- Borůvka：$O(E\log V)$。

MST 的唯一性：若所有边权互异，MST 唯一；否则可能多棵，切割性质中「最小边」要放宽为「属于某个最小割边」。

次小生成树：求 MST 后，对每条非树边，替换树上路径的最大边（或次大边）得到候选，取最小即次小。复杂度 $O(V^2)$ 或 $O(E\log V)$ 带 LCA。

## 四、代码实现

Kruskal（并查集 + 路径压缩）与 Prim（堆）完整实现，含连通性检测与边集还原。

```python
from typing import List, Tuple
import heapq

INF = float('inf')


class DSU:
    def __init__(self, n: int):
        self.p = list(range(n))
        self.rank = [0] * n

    def find(self, x: int) -> int:
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]  # 路径减半
            x = self.p[x]
        return x

    def union(self, a: int, b: int) -> bool:
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False
        if self.rank[ra] < self.rank[rb]:
            ra, rb = rb, ra
        self.p[rb] = ra
        if self.rank[ra] == self.rank[rb]:
            self.rank[ra] += 1
        return True


def kruskal(n: int, edges: List[Tuple[int, int, int]]) -> Tuple[int, List[Tuple[int, int, int]]]:
    """
    edges = [(u, v, w)]。返回 (最小总权, 选中的边列表)。
    若图不连通，总权返回 -1。
    """
    edges_sorted = sorted(edges, key=lambda e: e[2])
    dsu = DSU(n)
    total = 0
    chosen: List[Tuple[int, int, int]] = []
    for u, v, w in edges_sorted:
        if dsu.union(u, v):
            total += w
            chosen.append((u, v, w))
            if len(chosen) == n - 1:
                break
    if len(chosen) != n - 1:
        return -1, []  # 不连通
    return total, chosen


def prim(n: int, graph: List[List[Tuple[int, int]]], start: int = 0) -> Tuple[int, List[Tuple[int, int, int]]]:
    """
    graph[u] = [(v, w), ...]，无向图双向都要建。
    返回 (最小总权, 选中的边列表)。不连通返回 (-1, [])。
    """
    in_mst = [False] * n
    min_e = [INF] * n   # 连到当前 MST 的最小边权
    parent = [-1] * n
    min_e[start] = 0
    pq = [(0, start)]
    total = 0
    chosen: List[Tuple[int, int, int]] = []
    count = 0
    while pq and count < n:
        w, u = heapq.heappop(pq)
        if in_mst[u]:
            continue
        in_mst[u] = True
        count += 1
        if parent[u] != -1:
            total += w
            chosen.append((parent[u], u, w))
        for v, wt in graph[u]:
            if not in_mst[v] and wt < min_e[v]:
                min_e[v] = wt
                parent[v] = u
                heapq.heappush(pq, (wt, v))
    if count != n:
        return -1, []
    return total, chosen


def build_undirected(n: int, edges: List[Tuple[int, int, int]]) -> List[List[Tuple[int, int]]]:
    g = [[] for _ in range(n)]
    for u, v, w in edges:
        g[u].append((v, w))
        g[v].append((u, w))
    return g


if __name__ == "__main__":
    # 标准 4 点例
    edges = [(0, 1, 1), (0, 2, 4), (1, 2, 2), (1, 3, 5), (2, 3, 3)]
    total, chosen = kruskal(4, edges)
    assert total == 6  # 1 + 2 + 3
    g = build_undirected(4, edges)
    total2, chosen2 = prim(4, g, 0)
    assert total2 == 6
    # 不连通
    assert kruskal(3, [(0, 1, 1)])[0] == -1
    print("MST ok, total =", total, "edges:", chosen)
```

## 五、与其他技术对比

| 算法 | 思路 | 复杂度 | 适用 |
| --- | --- | --- | --- |
| Kruskal | 边排序 + 并查集 | $O(E\log E)$ | 稀疏图、边列表输入 |
| Prim（堆） | 点扩展 + 优先队列 | $O(E\log V)$ | 一般无向图 |
| Prim（数组） | 线性找最小 | $O(V^2)$ | 稠密图、$E\sim V^2$ |
| Borůvka | 轮次批量最小出边 | $O(E\log V)$ | 并行、分布式 |
| 瓶颈生成树 | 最小化最大边 | 可用 MST 变体 | 通信延迟上限 |

Kruskal vs Prim：边稀疏且已有边列表时 Kruskal 简单高效；稠密图 Prim 的 $O(V^2)$ 常数更小。Borůvka 轮数 $O(\log V)$，适合并行。与最短路对比：最短路是从源点出发的距离标签，MST 是全局连通的最小代价；二者目标不同，不能互换。

## 六、常见误区

1. **图不连通时仍输出 $n-1$ 条边**。Kruskal 最终 `len(chosen) != n-1` 必须检测，否则返回错误的「部分生成树」或错误总权。Prim 同理 `count != n`。
2. **并查集未做路径压缩 / 按秩合并**。小数据无感，大数据退化为链，Kruskal 变慢。务必实现 `find` 路径压缩。
3. **Prim 的 `min_e` 更新与惰性删除混淆**。堆中会有多条过期边，出堆时必须 `if in_mst[u]: continue`，否则重复加边、总权变大。
4. **无向图只建单向边**。Kruskal 用边列表无此问题；Prim 用邻接表时必须双向建边，否则找不到跨割的连接边。
5. **以为「最小生成树一定是最短路树」**。二者不同：MST 最小化边权和，最短路树最小化根到各点距离和。MST 不保证根到点最短。

## 八、面试题

**1. 连接所有点的最小费用（LeetCode 1584）怎么做？**

参考答案：平面 $n$ 个点，边权为曼哈顿距离，完全图有 $O(n^2)$ 条边，用 Kruskal：生成全部边、排序、并查集合并，总权即答案。复杂度 $O(n^2\log n)$。$n\le 1000$ 可过。

**2. 切分性质是什么？为什么保证贪心正确？**

参考答案：任意割的最小横跨边必属于某棵 MST。证明用反证：若 MST 不含该边，加入形成环，环上必有另一条横跨边，替换后权不增，故该边安全。Kruskal/Prim 每步选的边都是某割的最小边，因此贪心安全。

**3. 如何求次小生成树？**

参考答案：先求 MST 并记下树边。对每条非树边 $(u,v,w)$，找出树上 $u\to v$ 路径的最大边权 $m$，候选值 $w(T) - m + w$。取所有候选最小值。可先 $O(V^2)$ 暴力求路径最大边，或用倍增 LCA 优化到 $O(E\log V)$。

**4. Kruskal 与 Prim 的选择依据？**

参考答案：稀疏图（$E=O(V)$）或边列表现成时用 Kruskal，$O(E\log E)$ 实现简单；稠密图（$E=O(V^2)$）用 Prim 数组版 $O(V^2)$，常数小。实现上 Kruskal 依赖并查集，Prim 依赖堆。

## 九、演进与趋势

MST 的变体与应用持续扩展：**次小生成树**、**最小瓶颈生成树**、**斯坦纳树**（允许引入非给定点，NP 难但有近似）、**最小度生成树**、**动态 MST**（边插入删除在线维护）都是活跃方向。并行与分布式 Borůvka、GPU MST 用于大规模图。聚类中，单链接层次聚类与 MST 一一对应；图像分割用 MST 边权阈值切分。

工程上，通信网络规划（光纤骨干）、电力环网设计、无线传感器网络拓扑控制都用 MST 及其近似变体。求解器侧，MST 是 LP 对偶与拟阵交的入门案例，理解它有助于理解更一般的拟阵贪心。掌握切分性质与两种实现，是图论贪心的必修课。

## 十、小结

最小生成树是贪心的典范：切分性质保证「最小横跨边安全」，Kruskal 按边贪心 + 并查集，Prim 按点扩展 + 堆。复杂度 $O(E\log E)$ / $O(E\log V)$，稠密图用 $O(V^2)$ 数组版。必须检测连通性；次小生成树靠「非树边替换树上最大边」。理解切割性质，比背两个模板更本质——它解释了为什么贪心不会错。
