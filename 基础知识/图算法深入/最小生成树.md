# 最小生成树

> 对应 CLRS《Introduction to Algorithms》第 23 章 Minimum Spanning Trees。

## 一、背景与挑战
在连通无向带权图中求总权最小的生成树。Kruskal 按边排序 + 并查集；Prim 从点出发扩展。

## 二、核心原理
切分性质：横跨任意切分且权值最小的边必在某个 MST 中。Kruskal 贪心选不形成环的最小边；Prim 维护已连点集到外部的最小边。

## 三、形式化 / 数学基础
Kruskal 复杂度：$O(E\log E)$（排序主导）。
Prim（二叉堆）：$O((V+E)\log V)$；稠密图用邻接矩阵 + 线性找最小为 $O(V^2)$。

## 四、代码实现
```python
def kruskal(n, edges):
    parent = list(range(n))
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    edges.sort(key=lambda e: e[2])
    total = 0
    cnt = 0
    for u, v, w in edges:
        ru, rv = find(u), find(v)
        if ru != rv:
            parent[ru] = rv
            total += w
            cnt += 1
    return total if cnt == n - 1 else float('inf')
```

## 五、与其他技术对比
Kruskal 适合稀疏图（按边）；Prim 适合稠密图；二者均基于 MST 的贪心性质。

## 六、常见误区
忽略图不连通时 MST 不存在；并查集未路径压缩导致退化；Prim 中未正确更新最小边。

## 八、面试题

## 九、演进与趋势
次小生成树（替换一条边）；最小瓶颈生成树；斯坦纳树（允许非给定点）。

## 十、小结
MST 依赖切分性质，Kruskal 与 Prim 都是安全的贪心，按边或按点扩展而已。
