# 乱序发射与寄存器重命名

> 对应 Hennessy & Patterson《Computer Architecture》与 ARMv8 手册。

## 一、背景与挑战
程序中的伪相关（WAR、WAW）因寄存器复用而起，即使无真实数据依赖也会阻塞乱序执行。寄存器重命名将逻辑寄存器映射到大量物理寄存器以消除之。

## 二、核心原理
重命名映射表（RAT）把每条指令的目标逻辑寄存器分配一个新物理寄存器；后续读操作引用最新物理号。旧映射在提交（或恢复）时释放，实现物理寄存器回收。

## 三、形式化与数学基础
设逻辑寄存器集合 L，物理集合 P（|P| >> |L|）。映射：

    RAT: L -> P
    释放条件: 当旧物理寄存器不再被后续指令引用且在提交后, 归还空闲池。

## 四、代码实现
```c
int RAT[32], free_list[PHYS];
int alloc_phys() { return free_list[free_head++]; }
void rename(int rd) {
    int p = alloc_phys();
    if (old_owner_valid(RAT[rd])) free_later(RAT[rd]);
    RAT[rd] = p;
}
```

## 五、与其他技术对比
无重命名则 WAR/WAW 靠停顿解决；重命名彻底消除伪相关，代价是物理寄存器管理与映射表。

## 六、常见误区
误以为重命名增加寄存器数量改变语义；仅改变实现映射，程序语义不变。误以为物理寄存器无限。

## 七、与开源书/权威来源对应
Hennessy & Patterson 与 ARMv8 手册（寄存器模型）涉及重命名概念。

1. 重命名如何消除 WAR？答：读写映射到不同物理寄存器。

## 九、演进与趋势
分布式 RAT 与混合重命名（架构+重排）提升频率与容量。

## 十、小结
寄存器重命名是乱序执行的支柱，通过映射消除伪相关，释放指令级并行。
