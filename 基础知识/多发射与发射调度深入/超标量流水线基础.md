# 超标量流水线基础

> 对应 Hennessy & Patterson《Computer Architecture》。

## 一、背景与挑战
单发射每周期仅取指一条指令，IPC 上限为 1。超标量（superscalar）每周期取指、译码并发射多条指令以提升并行度。

## 二、核心原理
前端每周期取多条指令，经译码与重命名后送入多个功能单元（ALU、FPU、Load/Store）。硬件检测指令间数据/结构/控制相关，决定可并行发射的数量。

## 三、形式化与数学基础
理想 IPC 受限于：

    IPC <= min(发射宽度 W, 平均指令级并行 ILP, 1/每指令周期)

实际 IPC << W 因相关与分支。

## 四、代码实现
```verilog
// 概念: 每周期发射 W 条
always_comb begin
    issued = 0;
    for (i = 0; i < W && issued < W; i++)
        if (ready[i] && !struct_hazard[i]) begin
            dispatch(i); issued++;
        end
end
```

## 五、与其他技术对比
标量流水每周期 1 条；超标量多发射；VLIW 将并行调度交给编译器，硬件更简单但依赖软件。

## 六、常见误区
误以为发射宽度等于 IPC；相关、cache 缺失会拉低实际 IPC。误以为超标量一定快于标量。

## 九、演进与趋势
多发射从 2 路到 4-8 路，配合 SMT 提升利用率。

## 十、小结
超标量通过每周期多发射提升 ILP，但受相关性与分支限制，实际 IPC 常低于发射宽度。
