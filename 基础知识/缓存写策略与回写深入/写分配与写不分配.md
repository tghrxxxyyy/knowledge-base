# 写分配与写不分配

> 对应 Hennessy & Patterson《Computer Architecture》。

## 一、背景与挑战
写未命中时，是否先把块调入缓存再写，影响后续命中率与复杂度。写分配（write-allocate）与写不分配（no-write-allocate）解决此问题。

## 二、核心原理
写分配：写未命中时先读入该块（如同读未命中），再在缓存中修改，常配合写回。写不分配：写未命中时直接写下游内存，不调入缓存，常配合写直达。

## 三、形式化与数学基础
空间局部性下，写分配将后续同块写变为命中：

    future_hits_if_allocate = count(同块后续写)

否则每次均为未命中写下游。

## 四、代码实现
```c
void write_alloc_policy(int miss) {
    if (miss) {
        if (WRITE_ALLOCATE) {
            load_block_to_cache(); // 先取块
            update_cache_line();
        } else {
            mem_write_direct();    // 直接写下级
        }
    }
}
```

## 五、与其他技术对比
写分配+写回利于利用局部性；写不分配+写直达实现简单、避免污染缓存。

## 六、常见误区
误以为写分配只能配写回；虽常见但可组合。误以为写不分配永不读块。

## 七、与开源书/权威来源对应
Hennessy & Patterson 讨论写策略组合及其对性能的影响。

## 八、面试题
1. 写分配通常配哪种写策略？答：常配写回。

## 九、演进与趋势
混合策略与智能预取使写分配决策更自适应。

## 十、小结
写未命中是否调块取决于写分配策略，它通常与写回/写直达组合以平衡局部性与带宽。
