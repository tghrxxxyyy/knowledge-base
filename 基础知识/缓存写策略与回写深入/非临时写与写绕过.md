# 非临时写与写绕过

> 对应 Intel SDM 卷1（非临时提示）与 Bryant & O'Hallaron《CSAPP》。

## 一、背景与挑战
流数据（如 memset、矩阵块）只写一次不再读，若仍经过缓存会污染缓存并浪费带宽。非临时（non-temporal）写指示硬件绕过缓存直写下级。

## 二、核心原理
使用弱序/非临时存储指令（如 MOVNTI、_mm_stream_si32），数据直接写入内存（write-combining 缓冲合并），不分配缓存行，避免驱逐有用数据。

## 三、形式化与数学基础
普通写路径：CPU -> L1 -> ... -> 内存（经多级缓存与写回）。非临时写：CPU -> WC buffer -> 内存，绕开缓存层级，对只写一次数据最优。

## 四、代码实现
```c
#include <immintrin.h>
void stream_copy(double *dst, const double *src, int n) {
    for (int i = 0; i < n; i += 4)
        _mm_stream_pd(dst + i, _mm_load_pd(src + i));
    _mm_sfence();  // 保证顺序提交
}
```

## 五、与其他技术对比
普通写污染缓存且需后续写回；非临时写省缓存但需 sfence 保证顺序与可见性。

## 六、常见误区
误以为非临时写更快于所有情况；对会复用的数据反而更慢（无缓存）。误以为不需 fence。

## 七、与开源书/权威来源对应
Intel SDM 卷1 描述 streaming store 与非临时提示；CSAPP 第 6 章讲缓存污染。

## 九、演进与趋势

## 十、小结
非临时写绕过缓存直写内存，适合只写一次的大块数据，显著降低缓存污染。
