# 缓存行状态与脏位

> 对应 Hennessy & Patterson《Computer Architecture》。

## 一、背景与挑战
缓存需记录每行是否有效、是否比内存更新（脏），以决定替换时是否写回以及能否直接丢弃。

## 二、核心原理
典型状态位：valid（有效）、dirty（脏，即已被修改且未写回）、tag 比对。MESI 等一致性协议进一步扩展状态机。脏位为 1 的行被替换时必须先写回。

## 三、形式化与数学基础
替换行 L 时：

    if (L.dirty) write_back(L);
    else discard(L);

一致性下还需广播使其他副本无效。

## 四、代码实现
```c
struct line {
    uint64_t tag;
    uint8_t  valid : 1;
    uint8_t  dirty : 1;
    uint32_t data[16];
};
void evict(struct line *L) {
    if (L->valid && L->dirty) mem_write_back(L);
    L->valid = 0;
}
```

## 五、与其他技术对比
无脏位（写直达）替换无需写回，简单但费带宽；脏位让写回高效但增加状态管理。

## 六、常见误区
误以为脏位为 0 就无需任何操作；仍需考虑多核一致性的无效广播。误以为脏位表示与磁盘一致。

## 九、演进与趋势
与 MESI 状态融合，单行的状态编码更丰富；目录协议替代广播。

## 十、小结
脏位与 valid 位是写回缓存正确性的基础，决定替换时写回还是丢弃。
