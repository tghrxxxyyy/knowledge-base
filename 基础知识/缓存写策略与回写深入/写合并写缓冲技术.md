# 写合并写缓冲技术

> 对应 Hennessy & Patterson《Computer Architecture》与 Intel SDM 卷3。

## 一、背景与挑战
写直达或未命中写会产生大量对下级/内存的访问，延迟高。写缓冲（write buffer）暂存写操作，让 CPU 立即继续，随后合并与提交。

## 二、核心原理
写缓冲是一组条目，CPU 写入后放入缓冲即可返回；硬件按序将缓冲内容写向下级，并可合并相邻地址的写（write merging），减少事务数。

## 三、形式化与数学基础
若相邻写 w1..wk 落入同一块：

    merged_write_count = 1 而非 k

合并率提升有效带宽：

    B_eff = B_peak * merge_ratio

## 四、代码实现
```verilog
// 概念: 写缓冲合并
always_comb begin
    if (wb_full) cpu_stall = 1;
    for (int i=0;i<WB;i++)
        if (wb[i].addr[31:4] == new_addr[31:4]) begin
            wb[i].data |= new_data; merge = 1;
        end
end
```

## 五、与其他技术对比
无写缓冲则 CPU 阻塞于每次写；写缓冲隐藏延迟但需处理读穿透（read-for-ownership）以免读到未提交旧值。

## 六、常见误区
误以为写缓冲能乱序提交；通常需保序或配逻辑保证语义。误以为它解决一致性。

## 七、与开源书/权威来源对应
Intel SDM 卷3 描述写合并（WC）内存类型；Hennessy & Patterson 讲写缓冲。

## 九、演进与趋势
写缓冲与 store queue 融合，支撑乱序执行的提交。

## 十、小结
写缓冲通过暂存与合并隐藏写延迟，是连接快速 CPU 与慢速内存的关键队列。
