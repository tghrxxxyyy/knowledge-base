# 写直达与写回策略对比

> 对应 Hennessy & Patterson《Computer Architecture》。

## 一、背景与挑战
CPU 写内存时，缓存与下一级（或内存）何时更新决定一致性、带宽与复杂性。写直达（write-through）与写回（write-back）是两种基本策略。

## 二、核心原理
写直达：每次写都同时更新缓存与下一级内存，简单且下一级始终最新，但写流量大。写回：仅更新缓存行并置脏位，仅在行被替换时才写回内存，减少带宽但需脏位与复杂替换。

## 三、形式化与数学基础
设写频率为 w，缓存命中率 h，写回仅在替换时写回：

    写直达流量 ≈ w * (命中+未中均写下游)
    写回流量   ≈ w * (1 - h) + 替换写回

写回显著减少下游写次数。

## 四、代码实现
```c
void cache_write(struct line *L, uint64_t tag, uint32_t off, uint32_t val) {
    if (L->tag == tag && L->valid) {
        L->data[off] = val;
        L->dirty = 1;          // 写回: 标记脏
        // 写直达则同时 mem_write(...)
    }
}
```

## 五、与其他技术对比
写直达利于多核一致（内存始终最新）但带宽浪费；写回省带宽但需协议保证其他核看到更新。

## 六、常见误区
误以为写回永不写内存；替换或一致性请求会触发写回。误以为写直达无脏位。

## 九、演进与趋势
现代多级缓存混合使用：L1 常写直达+写分配，下层写回；结合写缓冲。

## 十、小结
写直达简单一致但费带宽，写回省带宽但需脏位与协议，选择取决于层级与目标。
