# 预取与缓存污染权衡

> 对应 Hennessy & Patterson《Computer Architecture: A Quantitative Approach》第5章。

## 一、背景与挑战
预取把额外数据放入有限缓存，若预取数据未被及时使用就被驱逐，会挤掉有用数据，造成「缓存污染」（cache pollution），得不偿失。

## 二、核心原理
权衡取决于预取准确率（prefetch accuracy）与覆盖度（coverage）。理想预取应高准确率、高覆盖、低污染。常用策略：限制预取深度、使用较低层级（如只到 L2）、按需提升（demand-driven uplift）。

## 三、形式化与数学基础
设预取总数 $P$，其中被使用 $U$，有用缓存行被驱逐 $E$。指标：
$$Accuracy = \frac{U}{P},\quad Pollution = \frac{E}{P}$$
目标最大化 $Accuracy$ 同时最小化 $Pollution$。

## 四、代码实现
```c
// 基于使用反馈的节流
if (prefetch_used_recently < THRESHOLD)
    prefetch_depth = max(1, prefetch_depth - 1);
else
    prefetch_depth = min(MAXD, prefetch_depth + 1);
```

## 五、与其他技术对比
预取到 L1 时效最高但污染最大；预取到 L2 更安全但可能仍不够快。分层预取在二者间平衡。

## 六、常见误区
误以为预取不影响命中率。错误预取会显著降低有效命中率，尤其在缓存紧张的工作负载。

## 七、与开源书/权威来源对应
Hennessy & Patterson 第5章讨论预取收益随缓存大小与带宽的变化；CSAPP 第6章强调有限缓存下的局部性权衡。

## 八、面试题
问：如何衡量预取好坏？答：看准确率、覆盖度、以及对整体缓存命中率与带宽占用的净影响，而非单纯预取条数。

## 九、演进与趋势
自适应预取（根据反馈动态调整深度与目标层）与基于机器学习的预取选择成为研究热点。

## 十、小结
预取不是免费午餐，必须在「提前量」与「污染」间精打细算，否则掩盖延迟的收益会被命中率下降抵消。
