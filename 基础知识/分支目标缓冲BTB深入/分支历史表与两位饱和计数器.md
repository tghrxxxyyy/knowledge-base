# 分支历史表与两位饱和计数器

> 对应 Hennessy & Patterson《Computer Architecture: A Quantitative Approach》第3章。

## 一、背景与挑战
仅记录上一次方向的一位移位计数器容易导致抖动（交替分支每次都错）。两位饱和计数器（2-bit saturating counter）通过迟滞（hysteresis）显著降低此类误预测。

## 二、核心原理
每个分支条目维护一个 2-bit 状态机：强不跳、弱不跳、弱跳、强跳。只有连续两次相反结果才翻转预测方向，从而避免单次异常翻转造成误预测。

## 三、形式化与数学基础
状态转移（strongly taken=11，strongly not taken=00）：
$$S_{t+1} = \text{clip}(S_t + r_t,\;0,\;3),\quad r_t=\begin{cases}+1 & \text{taken}\\ -1 & \text{not taken}\end{cases}$$
预测位 $P = S_t[1]$（最高位）。

## 四、代码实现
```c
typedef enum {SN, WN, WT, ST} State;
int predict(State s){ return s >= WT; }
State update(State s, int taken){
    if (taken && s < ST) return s+1;
    if (!taken && s > SN) return s-1;
    return s;
}
```

## 五、与其他技术对比
1-bit 预测器在交替模式上 50% 误判，2-bit 把稳定性提高；更高阶（如局部分支历史 + 模式历史表 PHT）进一步利用相关性。

## 六、常见误区
误认为计数器越宽越好。实验表明 2-bit 已覆盖绝大多数收益，更宽状态机边际收益低且占用更多 BTB 位。

## 七、与开源书/权威来源对应
Hennessy & Patterson 给出 2-bit 预测器在 SPEC 基准上的误预测率对比；CSAPP 第4章以有限状态机描述同样机制。

## 八、面试题
问：为何 2-bit 比 1-bit 好？答：迟滞避免单次翻转误判，对循环末次不跳转等模式尤其有效。

## 九、演进与趋势
从全局历史移位寄存器（GHR）到 TAGE 等基于多个历史长度的几何分布预测器，方向预测精度持续逼近理论上限。

## 十、小结
两位饱和计数器以极小硬件代价获得显著稳定性，是现代方向预测的基础构件。
