# 网络命名空间基础

> 对应 Linux man namespaces(7) 与 network_namespaces(7)；参考 Vonng/ddia（分布式系统隔离思路）。

## 一、背景与挑战
同一内核需要为容器/虚拟化提供独立网络视图（独立 IP、路由、端口）。网络命名空间（netns）提供隔离的网络栈实例。

## 二、核心原理
netns 隔离：网络接口、路由表、iptables、端口号、/proc/net。创建 netns 后，虚拟/物理网卡可被移入，使该 ns 拥有独立对外连接能力。

## 三、形式化与数学基础
隔离维度集合：
  NetNS = { ifaces, routes, rules, iptables, sockets, /proc/net }
进程 p 绑定到 netns n：
  p.netns_id = n  (CLONE_NEWNET)
不同 netns 中端口 80 互不冲突。

## 四、代码实现
# 创建与使用命名空间
ip netns add ns1
ip netns exec ns1 ip link set lo up
ip netns exec ns1 ip addr add 10.0.0.2/24 dev veth0
# C 创建 netns
unshare(CLONE_NEWNET);  // 新网络命名空间

## 五、与其他技术对比
UTS/PID namespace 隔离主机名/进程号，netns 专门隔离网络栈，常与其他 ns 组合成容器。

## 六、常见误区
1. 认为 netns 自动有网络——新建 ns 只有 lo，需手动接线。
2. 混淆 netns 与网络隔离 VLAN——后者是二层，前者是栈实例。
