# 错误聚合与指纹算法

> 对应 OpenTelemetry (observability standard)。

## 一、背景与挑战
同一种异常可能每秒产生成千上万条原始堆栈，直接展示会让工程师淹没，无法识别"几类真正的问题"。

## 二、核心原理
用指纹（fingerprint）把相似错误聚合：基于异常类型、堆栈顶层帧、出错模块计算稳定哈希，归并为有限的问题组。

## 三、形式化与数学基础
设原始错误 e 含 (type, stack)。指纹 f(e) = hash(normalize(type), top_frames(stack, k))。聚合数 = |{f(e)}|，远小于原始条数。

## 四、代码实现
```python
import hashlib
def fingerprint(exc):
    frames = [f.name for f in exc.stack[-3:]]   # 取最近 3 帧
    raw = exc.__class__.__name__ + "|" + "|".join(frames)
    return hashlib.md5(raw.encode()).hexdigest()  # 稳定聚合键
```

## 五、与其他技术对比
相比逐条罗原始异常，聚合展示聚焦问题类别；但归一化过度会合并本应区分的不同根因。

## 六、常见误区
- 用整条堆栈做指纹，行号变化就拆成新组，噪音大。
- 忽略版本差异，把不同版本异常混为一谈。

## 七、与开源书/权威来源对应
OpenTelemetry 的 Exception 记录与问题聚合实践相互衔接。

## 八、面试题
指纹为什么取栈顶而非全栈？过度聚合会有什么问题？

## 九、演进与趋势
结合聚类与语义相似度（堆栈向量化）做更智能的自动归组。

## 十、小结
错误聚合用指纹把海量异常收敛为少量问题，指纹设计决定信噪比。
