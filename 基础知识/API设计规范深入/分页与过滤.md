# 分页与过滤

> 对应 Google API Design Guide "Pagination"、JSON:API 规范。

## 一、背景与挑战
列表接口返回全量数据会拖垮服务与网络；客户端需要可控的翻页、排序与字段过滤。

## 二、核心原理
偏移分页（offset/limit）简单但有重复/漏数据问题；游标分页（cursor）基于有序键更稳定；支持 `fields` 投影、`filter`、`sort` 查询参数。

## 三、形式化 / 数学基础
偏移分页：第 $p$ 页取 $[ (p-1)\cdot s,\ p\cdot s )$。游标分页：以有序键 $k$ 取 $k>cursor$ 的前 $s$ 条，避免插入导致的偏移漂移。

## 四、代码实现
```http
GET /orders?limit=20&cursor=eyJpZCI6MTIzfQ==   # 游标
GET /orders?offset=40&limit=20                  # 偏移
GET /orders?sort=-created_at&fields=id,status
```

## 五、与其他技术对比
偏移法实现易但大数据量慢且不抗压；游标法性能稳定但不可随机跳页；Keyset 分页是游标常见实现。

## 六、常见误区
误区：深分页用大 offset（如 offset=1000000）导致全表扫描。误区：未对排序键建索引。

## 九、演进与趋势

## 十、小结
优先游标分页与索引排序，支持投影减少带宽。
