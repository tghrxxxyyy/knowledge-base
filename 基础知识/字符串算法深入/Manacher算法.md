# Manacher算法

> 对应 Manacher, G. (1975) "Linear Manacher Algorithm"（JACM 相关简报），以及 cp-algorithms / OI-wiki 的最长回文子串线性算法讲解。

## 一、背景与挑战

求一个字符串的**最长回文子串**是经典问题：给定 $S$（长度 $n$），找 $S$ 中连续一段 $S[l..r]$ 使得它正反读相同，且 $r-l+1$ 最大。动态规划解法（枚举中心、向两边扩展或区间 DP）最坏 $O(n^2)$；对 $n=10^6$ 的数据（例如基因序列、日志扫描）会超时。面试里"最长回文子串"几乎是字符串专题必考题，但多数候选人只会写 $O(n^2)$ 的中心扩展，不知道存在确定性 $O(n)$ 的 Manacher 算法。

朴素中心扩展的浪费在于：以每个位置为中心扩展时，大量回文半径被重复计算。例如 `abababa`，以中间的 `a` 为中心的长回文已经覆盖了许多外围小回文的信息，但朴素算法并不利用"已经算过的臂长"。Manacher 的贡献是证明：只要维护**当前已发现回文的最右边界**，就能把大部分中心的臂长直接从对称中心拷贝过来，只在边界之外做真正的扩展；而"扩展失败时右边界单调右移"保证了总复杂度线性。

工程上，最长回文用于 DNA 发夹结构检测、病毒特征回文序列（限制酶识别位点常是回文）、UI 高亮与题库评测。面试中，如果说清 Manacher 的"臂长数组 + 对称拷贝 + 最右边界"三件套，通常直接拉满印象分；说不清只能证明对 $O(n^2)$ 解法熟。

## 二、核心原理

**奇偶统一。** 回文有奇有偶（`aba` 与 `abba`），中心点不同。Manacher 在相邻字符与首尾插入一个不在原串中的哨兵（常用 `#`，更稳妥可用 `$`、`^` 等两个哨兵防越界），把所有回文都变成奇数长度。例如 `abba` → `#a#b#b#a#`，中心在 `#` 上。记变换后串为 $T$，长度 $N=2n+1$，原串任何回文都对应 $T$ 上一个以某下标为对称轴的奇回文。

**臂长数组 $d[i]$。** 定义 $d[i]$ 为以 $T[i]$ 为中心的最长回文的**半径**（含中心），即回文覆盖 $T[i-d[i]+1 ..\; i+d[i]-1]$，长度 $2d[i]-1$。例如 `#a#b#a#` 中以 `b`（下标 3）为中心，$d[3]=3$，覆盖 `#a#b#a#` 全串（在更长串中则对应半径 3）。原串中最长回文长度即 $\max_i (d[i]-1)$（减 1 去掉 `#` 折算：每个半径 $r$ 对应原串约 $r-1$ 个真实字符）。

**三个关键量**：
- $d[i]$：每个中心的臂长；
- $c$：当前使 $i+d[i]$ 最大的中心（对称拷贝的参照点）；
- $r = c + d[c]$：当前已覆盖的最右边界（开区间），即所有已知回文右端点的最大值。

**对称拷贝（核心不变量）**：当求 $d[i]$ 且 $i < r$ 时，取 $i$ 关于 $c$ 的镜像 $i' = 2c - i$。因为 $T[c-(i'-c) ..\; c+(i'-c)]$ 是回文，$i'$ 处的臂长信息在一定范围内可以搬到 $i$：

$$
d[i] = \min\bigl(d[i'],\; r - i\bigr) \quad (\text{当 } i < r).
$$

为什么是 $\min$？镜像臂长 $d[i']$ 给出"可能多大"，$r-i$ 给出"已知回文边界内最多能保证多大"。超出 $r$ 的部分，关于 $c$ 的对称性不再保证字符匹配，必须实测。

**然后扩展**：从 $d[i]$（拷贝来的初值）开始，不断比较 $T[i+d[i]]$ 与 $T[i-d[i]]$，相等则 $d[i]+1$。扩展结束后若 $i + d[i] > r$，更新 $c=i,\; r=i+d[i]$。

**为什么正确**：在 $r$ 边界内，回文的对称性保证镜像区间的字符相等关系可搬运；一旦越过 $r$，没有任何回文覆盖保证，只能比较。这是"利用已证明的对称性，只在未知区域花代价"的标准手法。

**为什么线性**：$r$ 单调不减，每次失败的扩展都发生在 $r$ 右侧且至少使 $r$ 右移 1（扩展成功且更新 $r$ 时），故扩展总次数 $O(N)$；拷贝是 $O(1)$。整体 $O(n)$。

## 三、形式化与数学基础

**变换。** 设原串 $S=s_0\cdots s_{n-1}$，构造

$$
T = \#\, s_0\,\#\, s_1\,\#\, \cdots\, \#\, s_{n-1}\,\#\,,
$$

$N = 2n+1$。$T$ 上任意回文半径 $d$ 对应原串回文长度 $d-1$。

**臂长定义。** $d[i] = \max\{k \ge 1 : T[i-k+1..i+k-1] \text{ 是回文}\}$。覆盖区间 $[i-d[i]+1,\; i+d[i]-1]$。

**对称引理。** 设 $c$ 为中心，$R = c + d[c]$ 为右边界（不含）。对任意 $i \in (c, R)$，令 $i' = 2c-i$。则对 $1 \le k \le R-i$，有 $T[i-k] = T[i+k]$ 的真值与 $T[i'-k]=T[i'+k]$ 的真值一致（由 $T[c-(i'-c)..c+(i'-c)]$ 是回文）。因此 $d[i] \ge \min(d[i'], R-i)$，而当 $k > R-i$ 时无法从对称性推出，需要单独比较。算法取 $d[i]=\min(d[i'], R-i)$ 后再向右扩展，恰好覆盖"未知区域"。

**复杂度。** 设扩展阶段每次 `while` 比较都使 $d[i]$ 加 1。当 $i+d[i]$ 超过旧 $R$ 时更新 $R$。$R$ 从 0 单调增至 $N$，故"成功扩展"总次数 $\le N$；失败即停止，不会空转。因此

$$
T(n) = \sum_i O(\text{扩展次数}_i) = O(N) = O(n).
$$

空间 $O(N)$ 存 $d$。这是**确定性最坏 $O(n)$**，优于 DP/扩展的 $O(n^2)$，也优于二分+哈希的 $O(n\log n)$。

**与回文树（Eertree）的关系。** Manacher 只回答"最长"及每个中心的臂长；若要统计所有回文子串个数或本质不同回文数，可用回文树，节点数 $O(n)$，插入均摊 $O(1)$。Manacher 是"每个中心一个答案"，Eertree 是"每种回文一个节点"。

## 四、代码实现

```python
def manacher(s: str) -> tuple[list[int], str, int]:
    """
    返回 (d, T, max_len_pos)：
      d[i] 为变换串 T 中以下标 i 为中心的臂长（含中心，回文长 2*d[i]-1）
      T 为插入分隔符后的串
      max_len_pos 为最长回文中心在 T 中的下标
    原串最长回文长度 = max(d) - 1
    """
    if s == "":
        return [1], "#", 0  # 空串退化情况
    # 用 ^...$ 包裹可天然防边界，内部用 # 分隔
    T = "#" + "#".join(s) + "#"
    n = len(T)
    d = [1] * n
    c = 0  # 当前右边界对应的中心
    r = 0  # 最右边界（开区间）
    for i in range(n):
        if i < r:
            mirror = 2 * c - i
            d[i] = min(d[mirror], r - i)
        # 向两侧扩展
        while i - d[i] >= 0 and i + d[i] < n and T[i - d[i]] == T[i + d[i]]:
            d[i] += 1
        if i + d[i] > r:
            c, r = i, i + d[i]
    best = max(range(n), key=lambda i: d[i])
    return d, T, best


def longest_palindrome(s: str) -> str:
    if not s:
        return ""
    d, T, pos = manacher(s)
    length = d[pos] - 1  # 原串回文长度
    # 由 T 下标换算回原串起点
    start = (pos - length) // 2
    return s[start:start + length]


if __name__ == "__main__":
    assert longest_palindrome("babad") in ("bab", "aba")
    assert longest_palindrome("cbbd") == "bb"
    assert longest_palindrome("a") == "a"
    assert longest_palindrome("ac") in ("a", "c")
    assert longest_palindrome("abaxabaxabb") == "baxabaxab"
    assert longest_palindrome("forgeeksskeegfor") == "geeksskeeg"
    d, T, _ = manacher("aba")
    # T = "#a#b#a#", 长度 7
    assert len(T) == 7 and max(d) == 4  # 4-1=3 == len("aba")
    print("Manacher ok")
```

## 五、与其他技术对比

| 方法 | 时间 | 空间 | 优点 | 缺点 |
|------|------|------|------|------|
| 中心扩展 | $O(n^2)$ | $O(1)$ | 好写、直观 | 最坏超时 |
| 区间 DP | $O(n^2)$ | $O(n^2)$ | 可顺便求任意区间是否回文 | 空间大 |
| 二分 + 哈希 | $O(n\log n)$ | $O(n)$ | 可扩展到回文判定 | 不是线性，常数大 |
| Manacher | $O(n)$ | $O(n)$ | 确定线性、可得所有中心臂长 | 边界与奇偶处理易写错 |
| 回文树 Eertree | 构建 $O(n)$ | $O(n)$ | 统计所有回文、在线插入 | 实现复杂度高 |

**取舍**：只求最长回文 → Manacher 是最优确定性解；要动态添加字符并维护回文信息 → Eertree；要判断"任意子串是否回文"大范围查询 → 区间 DP 或哈希。面试写中心扩展可拿基础分，写 Manacher 并解释对称性是加分项。

## 六、常见误区

1. **忘记插入分隔符，或分隔符选得与字母集冲突。** 若原串含 `#`，会误判。可用两个不同哨兵，或对字符做映射后用整数数组实现，避免歧义。
2. **镜像公式写成 `2*i - c`。** 正确是 $i' = 2c - i$。写反会拷贝到错误位置，臂长全乱。
3. **拷贝时忘记取 $\min(d[i'],\, r-i)$，直接 $d[i]=d[i']$。** 超出右边界的那部分并无对称性保证，会出现假回文。这是 Manacher 最经典的坑。
4. **回文长度换算错。** 变换串上臂长 $d$ 对应原串长度 $d-1$（因为 `#` 占掉一半）。例如 $T=\texttt{\#a\#b\#a\#}$，$d=4$，原串长 3。写 `d[i]` 或 `2*d[i]-1` 时要清楚问的是变换串还是原串。
5. **认为 Manacher 只能求最长。** 实际可得每个中心的臂长，从而 $O(1)$ 回答"以 $i$ 为中心的最长回文"、枚举所有回文子串；在此之上做线段树可回答区间最长回文。

## 八、面试题

1. **请实现 $O(n)$ 的最长回文子串，并解释为何线性。**  
   参考答案：Manacher，见上文。线性来自右边界 $r$ 单调不减、扩展只在未知区域发生；对称拷贝用 $d[i]=\min(d[i'], r-i)$ 保证不越界。

2. **不加分隔符能否做到 $O(n)$？**  
   参考答案：可以分别维护奇/偶两套臂长（偶回文中心在间隙），逻辑等价于统一后的 Manacher；但分隔符版本更不易写错。

3. **如何求所有回文子串的个数？**  
   参考答案：对每个 $i$，臂长 $d[i]$ 意味着以 $i$ 为中心、半径 $1..d[i]$ 的回文共 $d[i]$ 个（变换串口径），累计 $\sum d[i]$ 再换算即可 $O(n)$ 得到；或建回文树统计。

4. **给定 $q$ 次询问 $S[l..r]$ 是否回文，如何设计？**  
   参考答案：预处理前缀哈希与反串哈希，$O(1)$ 比较 $S[l..r]$ 与反向；或 Manacher 得到中心臂长后，判断区间中心与半径是否覆盖 $[l,r]$。哈希更通用（可处理修改），Manacher 更适合静态最长查询。

## 九、演进与趋势

Manacher 之后，回文问题的演进有三条主线。其一，**回文树（Palindromic Tree / Eertree）** 把"所有本质不同回文子串"组织成树，支持在线插入并统计出现次数，节点数 $O(n)$，在"统计回文子串个数""求第 k 大回文"类问题上取代了单纯 Manacher。其二，**回文自动机与序列回文（带通配、带 gap）**：DNA 分析中寻找允许失配的近似回文，常用哈希二分或 bit-parallel。其三，**工程化**：IDE 括号匹配与回文高亮、编译器字面量优化（回文常量折叠）、恶意代码检测中识别自对称特征码，都会用到线性回文扫描。在算法竞赛里，Manacher 已是常青知识点，衍生应用包括：最小回文分割、回文最小表示、最长双回文子串等。未来与 FM-index、后缀自动机结合处理"带限制的回文查询"，仍是研究与高难度题的交叉点。

## 十、小结

Manacher 通过插入分隔符统一奇偶回文，用臂长数组 $d[i]$ 记录各中心半径，并维护当前最右回文边界 $r$ 与中心 $c$：在边界内对称拷贝 $d[i]=\min(d[i'], r-i)$，只在边界外实测扩展。由于 $r$ 单调右移，总代价 $O(n)$，确定性地解决了最长回文子串问题。吃透"对称性 + 最右边界"这一不变量，不仅能写出线性实现，也能迁移到其他利用已知结构避免重复计算的算法设计中。
