# 字符串哈希

> 对应 《算法竞赛进阶指南》字符串哈希章节（滚动哈希 / Rabin-Karp）。

## 一、背景与挑战
把字符串映射为数值以支持 O(1) 子串比较。常用多项式滚动哈希；关键是选好基数与模以避免冲突。

## 二、核心原理
$h(s) = \sum s_i \cdot b^{n-1-i} \bmod M$。用前缀哈希 + 幂预处理可在 O(1) 取任意子串哈希。常用双模或自然溢出（unsigned long long，模 2^64）。

## 三、形式化 / 数学基础
$h[i] = h[i-1]\cdot b + s_i \pmod M$
子串 $[l,r]$：
$hash(l,r) = h[r] - h[l-1]\cdot b^{r-l+1} \pmod M$
碰撞概率约 $n^2 / M$，双哈希显著降低。

## 四、代码实现
```python
BASE = 91138233
MOD = (1 << 61) - 1
def poly_hash(s):
    h = 0
    for c in s:
        h = (h * BASE + ord(c)) % MOD
    return h

def rolling_hash(s):
    n = len(s)
    h = [0] * (n + 1)
    pw = [1] * (n + 1)
    for i in range(n):
        h[i+1] = (h[i] * BASE + ord(s[i])) % MOD
        pw[i+1] = (pw[i] * BASE) % MOD
    def get(l, r):
        return (h[r+1] - h[l] * pw[r - l + 1]) % MOD
    return get
```

## 五、与其他技术对比
与 KMP/后缀数组相比，哈希写起来最简单但存在（极低）冲突风险；双哈希几乎可视为正确。

## 六、常见误区
自然溢出下负数未转非负；取模后比较未统一符号；单模被构造数据卡（用双模）。

## 九、演进与趋势
多项式哈希 + 二分长度做子串类判定；与后缀数组结果交叉验证。

## 十、小结
字符串哈希用前缀 + 幂做 O(1) 子串比较，选模与双哈希是工程实践要点。
