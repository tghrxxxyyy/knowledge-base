# 后缀自动机

> 对应 A. A. 后缀自动机（SAM）经典构造，Crochemore 等《Text Algorithms》。

## 一、背景与挑战
SAM 是能接受字符串所有子串的最小 DFA，状态数 O(n)，可在线性时间建机并解决子串计数、不同子串数等问题。

## 二、核心原理
在线逐个添加字符，用 last 与 clone 维护 endpos 等价类（后缀链接 link）。每个状态代表一组 endpos 相同的子串集合。

## 三、形式化 / 数学基础
状态数 $\le 2n-1$，转移数 $\le 3n-4$。不同子串总数 = $\sum (len[s] - len[link[s]])$。

## 四、代码实现
```python
class SAM:
    def __init__(self):
        self.size = 1
        self.last = 0
        self.len = [0]
        self.link = [-1]
        self.next = [{}]
    def extend(self, c):
        cur = self.size
        self.size += 1
        self.len.append(self.len[self.last] + 1)
        self.link.append(-1)
        self.next.append({})
        p = self.last
        while p != -1 and c not in self.next[p]:
            self.next[p][c] = cur
            p = self.link[p]
        if p == -1:
            self.link[cur] = 0
        else:
            q = self.next[p][c]
            if self.len[p] + 1 == self.len[q]:
                self.link[cur] = q
            else:
                clone = self.size
                self.size += 1
                self.len.append(self.len[p] + 1)
                self.link.append(self.link[q])
                self.next.append(dict(self.next[q]))
                while p != -1 and self.next[p].get(c) == q:
                    self.next[p][c] = clone
                    p = self.link[p]
                self.link[q] = self.link[cur] = clone
        self.last = cur
```

## 五、与其他技术对比
与后缀数组相比，SAM 可在线构建且空间紧凑；与 Trie 相比，SAM 状态合并了大量子串。

## 六、常见误区
clone 时未复制 next；link 维护顺序错误；不同子串公式用错 `len` 之差。

## 十、小结
SAM 以 O(n) 状态刻画所有子串，核心是 endpos 后缀链接与 clone 维护，是子串问题的强力工具。
