# 后缀自动机

> 对应 Blumer et al. (1985) 关于 DAWG 的工作，以及 Crochemore 等人的子串结构；工程与竞赛讲解以 OI-wiki、cp-algorithms、"Suffix Automaton" by [e-maxx](https://cp-algorithms.com/string/suffix-automaton.html) 与论文 "Suffix Automaton and its Applications"（张培超等综述）为代表。

## 一、背景与挑战

给定字符串 $S$，我们常常需要回答与**所有子串**相关的问题：本质不同子串有多少个？某个模式 $P$ 是否为 $S$ 的子串？$S$ 中某个子串最多出现多少次（endpos 大小）？两个串的最长公共子串？若用后缀数组，静态查询合适，但一旦要求**在线逐字符扩展** $S$，SA 需要重建，代价高。后缀自动机（Suffix Automaton, SAM）正是为"增量构建、子串族压缩表示"而生的最小确定性有限自动机（Minimal DFA）：它识别 $S$ 的所有子串，状态数与转移数均为 $O(n)$，每加入一个字符，均摊 $O(1)$。

朴素做法枚举 $O(n^2)$ 个子串显式存进哈希/字典树，空间时间都爆炸。SAM 的关键洞见是：很多子串共享相同的**出现位置集合**（endpos 集合）。例如在 `ababa` 中，`aba` 与 `ba` 的结束位置集不同，但所有与某状态相关联的子串具有同一个 endpos；这些子串互为后缀关系，可用"长度区间 $[len(link)+1, len]$"一个状态紧凑表示。于是 SAM 的状态数远小于子串数——最坏只有 $2n-1$ 个状态、$3n-4$ 条转移。

工程与面试中，SAM 是"子串计数/出现次数/最长重复"类问题的终极武器：拼写纠错的候选生成、DNA 中重复片段与覆盖深度、敏感词变形检测（利用子串链）、LCS 与最短不公共子串等。面试若能讲清 parent 树（link 树）与 endpos 等价类，属于字符串算法最高档。实现门槛高，需反复手推，是拉开差距的地方。

## 二、核心原理

**endpos 等价类。** 对子串 $t$，定义 $\mathrm{endpos}(t) = \{ i : t \text{ 是 } S[..i] \text{ 的后缀} \}$，即 $t$ 在 $S$ 中每次出现的结束位置集合。对所有子串按 endpos 相等关系分类，每一类用一个状态表示。类中所有子串互为后缀关系（因为结束位置相同，较短者是较长者的后缀），且长度构成连续区间。记状态 $v$ 对应的最长子串长度为 $len[v]$，最短为 $minlen[v]$；通常只存 $len[v]$，$minlen[v] = len[link[v]] + 1$。

**转移。** 状态 $v$ 读入字符 $c$ 走到状态 $u$，当且仅当"该类中最长串 + $c$"仍属于某个子串。转移构成 DAG（从初始状态 $s$ 出发能识别所有子串）。SAM 的最小性保证：识别语言 $Sub(S)$（$S$ 的所有子串）的 DFA 中状态数最少，正是 endpos 等价类的个数。

**parent 链接（suffix link, link 树）。** 状态 $v$ 的 link 指向"其 endpos 集合真包含 $v$ 的 endpos、且是 $v$ 所代表最长串的最长真后缀所属状态"。沿 link 上跳，endpos 集合严格变大，最终到初始状态（其 endpos 可视为所有位置或专用语义）。link 树的子树对应 endpos 的包含关系：$v$ 的 endpos = 其所有后代转移代表的"新终止位置"的并（叶子/复制链的贡献）。因此**出现次数** $= \sum$ 子树叶子贡献，**所有 endpos 大小**可在 link 树上 DP 一次求出。

**在线增量构造。** 每读入字符 $c$，新建状态 `cur`，`len[cur] = len[last] + 1`，然后从 `last` 沿后缀链跳，给跳过的状态补上经由 $c$ 到 `cur` 的转移；遇到已有转移的状态 $p$ 与 $q = trans[p][c]$ 时，需要**克隆**（split）：若 `len[p] + 1 == len[q]`，直接 `link[cur] = q`；否则新建 `clone` 复制 $q$ 的转移与 link，缩短 $len$，把 `link[cur]` 与部分指向 $q$ 的 link 调整为 `clone`。这是 SAM 最精妙也最容易写错的部分。

**不变量**：
1. 每个状态的 $len$ 严格大于其 link 的 $len$；
2. $minlen[v] = len[link[v]] + 1$，类中子串是 $[minlen[v], len[v]]$ 的所有后缀；
3. 转移图无环（按 $len$ 拓扑），状态数 $\le 2n-1$，转移数 $\le 3n-4$。

## 三、形式化与数学基础

**状态数上界。** 直观证明：每加入一个字符新增 1 个状态 `cur`，只有当发生 clone 时才额外新增。可以证明 clone 次数不超过 $n-2$，故

$$
|Q| \le 2n - 1,\qquad |E| \le 3n - 4 \quad (n \ge 3).
$$

经典证明（Crochemore–Hancart）考虑 `last` 沿 link 树的深度变化与每次 clone 消耗的"长度空隙"，最终得到线性界。

**最小 DFA。** 语言 $L = Sub(S)$ 的 Myhill–Nerode 等价类恰为 endpos 等价类：两子串 $u,v$ 右上下文相同 $\iff \mathrm{endpos}(u)=\mathrm{endpos}(v)$（对后缀闭包语言需稍作细化，结论仍成立）。故 SAM 是 $Sub(S)$ 的最小确定性自动机，状态数 $=$ endpos 类个数。

**子串计数。** 状态 $v$ 贡献的本质不同子串数为

$$
len[v] - len[link[v]].
$$

全体求和

$$
\sum_{v \neq s} \bigl(len[v] - len[link[v]]\bigr)
$$

即 $S$ 的本质不同子串总数。推导：类中子串恰是某最长串的后缀中长于 $len[link[v]]$ 的那些，共 $len[v]-len[link[v]]$ 个。

**出现次数。** 设 $cnt[v]$ 为 endpos 大小。构造时令每个 `cur` 的 $cnt=1$，克隆为 0；按 $len$ 从大到小向 link 累加：$cnt[link[v]] \mathrel{+}= cnt[v]$。则任意子串出现次数等于其所在状态的 $cnt$。

**LCS 推论。** 构造 $S_1$ 的 SAM，用 $S_2$ 在其上跑：维护当前状态与匹配长度 $l$，失配沿 link 退，记录全程 $max\,l$，即最长公共子串，$O(|S_2|)$。

## 四、代码实现

```python
class SAM:
    """后缀自动机：在线构建，支持子串判定、出现次数、本质不同子串数。"""

    def __init__(self):
        # 每个状态: next 转移字典, link, len
        self.next: list[dict] = [{}]
        self.link: list[int] = [-1]
        self.len: list[int] = [0]
        self.last = 0
        self.size = 1

    def extend(self, c: str) -> None:
        cur = self.size
        self.size += 1
        self.next.append({})
        self.link.append(0)
        self.len.append(self.len[self.last] + 1)
        p = self.last
        while p != -1 and c not in self.next[p]:
            self.next[p][c] = cur
            p = self.link[p]
        if p == -1:
            self.link[cur] = 0
        else:
            q = self.next[p][c]
            if self.len[p] + 1 == self.len[q]:
                self.link[cur] = q
            else:
                clone = self.size
                self.size += 1
                self.next.append(self.next[q].copy())
                self.link.append(self.link[q])
                self.len.append(self.len[p] + 1)
                while p != -1 and self.next[p].get(c) == q:
                    self.next[p][c] = clone
                    p = self.link[p]
                self.link[q] = self.link[cur] = clone
        self.last = cur

    def build(self, s: str) -> "SAM":
        for ch in s:
            self.extend(ch)
        return self

    def is_substring(self, t: str) -> bool:
        v = 0
        for ch in t:
            if ch not in self.next[v]:
                return False
            v = self.next[v][ch]
        return True

    def count_distinct_substrings(self) -> int:
        return sum(self.len[v] - self.len[self.link[v]]
                   for v in range(1, self.size))

    def occurrence_counts(self, s: str) -> list[int]:
        """返回每个状态的 endpos 大小（出现次数）。"""
        cnt = [0] * self.size
        v = 0
        for ch in s:
            v = self.next[v][ch]
            cnt[v] += 1
        order = sorted(range(self.size), key=lambda x: -self.len[x])
        for v in order:
            if self.link[v] >= 0:
                cnt[self.link[v]] += cnt[v]
        return cnt


def lcs(a: str, b: str) -> str:
    """用 SAM 求 a、b 最长公共子串。"""
    sam = SAM().build(a)
    v, l, best, best_end = 0, 0, 0, 0
    for i, ch in enumerate(b):
        if ch in sam.next[v]:
            v = sam.next[v][ch]
            l += 1
        else:
            while v != -1 and ch not in sam.next[v]:
                v = sam.link[v]
            if v == -1:
                v, l = 0, 0
            else:
                l = sam.len[v] + 1
                v = sam.next[v][ch]
        if l > best:
            best, best_end = l, i
    return b[best_end - best + 1:best_end + 1]


if __name__ == "__main__":
    sam = SAM().build("ababa")
    assert sam.is_substring("aba")
    assert sam.is_substring("bab")
    assert not sam.is_substring("abb")
    assert not sam.is_substring("ababab")
    # ababa 的不同子串: a,b,ab,ba,aba,bab,abab,baba,ababa = 9
    assert sam.count_distinct_substrings() == 9
    assert lcs("abcdef", "zzzcef") == "ef"       # "cef" 并非 "abcdef" 连续子串
    assert lcs("abaxyz", "abxyz") == "xyz"
    assert lcs("abcde", "zbcdz") == "bcd"
    assert lcs("abc", "abc") == "abc"
    print("SAM ok")
```

## 五、与其他技术对比

| 结构 | 构建 | 子串判定 | 不同子串 | 出现次数 | 在线 | 空间 |
|------|------|----------|----------|----------|------|------|
| 后缀自动机 | $O(n)$ | $O(m)$ | $\sum(len-len\circ link)$ | link 树 DP | 是 | $O(n)$ 状态 |
| 后缀数组 + height | $O(n\log n)$/$O(n)$ | $O(m\log n)$ | 公式 | height 窗口 | 否 | $O(n)$ |
| 后缀树 | $O(n)$ | $O(m)$ | 树上路径 | 子树聚合 | 较易 | 常数更大 |
| 字典树（显式子串） | $O(n^2)$ | $O(m)$ | 计数易 | 易 | 是 | 爆炸 |

**取舍**：要在线、要 endpos 语义、要 LCS/子串计数 DP → SAM；要有序枚举、LCP 区间查询、实现更稳妥 → SA；多模式匹配 → AC 自动机（Trie + fail），与 SAM 解决的问题不同。

## 六、常见误区

1. **把 link 当作"失败转移"像 AC 那样每步都跳。** SAM 的匹配是确定性 DFA 转移，只有失配时才沿 link 回退找更短后缀；与 AC 的 fail 同源（都是后缀链），但使用方式不同。
2. **clone 时只复制转移不改 link，或忘了把指向 $q$ 的部分 link/转移改到 clone。** 结果是出现次数错、子串数多算。必须保证 `len[clone]=len[p]+1`，并把 `link[q]=link[cur]=clone`。
3. **统计不同子串时忘记减 $len[link[v]]$。** 每个状态代表一整段长度区间，不是 1 个子串。
4. **出现次数 DP 顺序错。** 必须按 $len$ 从大到小向 link 累加；若按创建顺序或 $len$ 升序，父节点会在子节点累加前先被处理，结果偏小。
5. **认为 SAM 能高效支持删除字符。** SAM 是增量的；撤销需要可持久化或栈式回滚，不是原生能力。

## 八、面试题

1. **SAM 的状态数为什么是 $O(n)$？**  
   参考答案：每个字符新增 `cur`，clone 只在 `len[p]+1 < len[q]` 时发生，可证 clone 总数 $\le n-2$，故状态 $\le 2n-1$；转移 $\le 3n-4$。

2. **如何求 $S$ 的本质不同子串个数？**  
   参考答案：SAM 每个状态 $v\neq s$ 贡献 $len[v]-len[link[v]]$，求和即可；等价于后缀数组的 $n(n+1)/2 - \sum height$。

3. **求两串最长公共子串，只用 SAM？**  
   参考答案：建 $A$ 的 SAM，用 $B$ 沿转移走，失配沿 link 退到仍有转移的祖先并更新当前匹配长度 $l \le len[v]$，全程记录最大 $l$ 对应子串。

4. **如何求 $S$ 中每个子串的出现次数？**  
   参考答案：每个状态代表一族 endpos 相同的子串，出现次数即 endpos 大小。构建时 `cnt[cur]=1`、`cnt[clone]=0`，按 $len$ 降序 `cnt[link[v]] += cnt[v]`。

## 九、演进与趋势

SAM 的研究与工程仍有活跃方向。**广义后缀自动机**把多串建在同一自动机上，用于多文本 LCS、基因多序列共用结构，但要小心"共享 last/结束状态"的语义。**回文自动机、LCT 维护 SAM**、可持久化 SAM 支持历史版本查询。**子串区间与路径覆盖**问题（如最短不公共子串、第 $k$ 小子串）在竞赛持续出现。工程上，SAM 用于敏感词与变体词识别（利用后缀链做模糊命中）、拼写校正的候选枚举、压缩算法中的重复因子分析。与 SAM 互补的是后缀数组/FM-index（静态压缩索引）和 AC 自动机（多模式一次扫描）。面试里 SAM 常作为加分压轴；实际业务中更常见"用库或 SA+哈希"，但懂 SAM 能在结构选择上做出更准判断。

## 十、小结

后缀自动机以 endpos 等价类为状态、后缀链为 parent 树，用 $O(n)$ 状态与均摊 $O(1)$ 增量构造，紧凑表示一个串的全部子串。`len`、`link`、clone 三件事构成其心脏：长度区间给出该状态贡献的子串族，link 树聚合出现次数，clone 保证最小性与线性界。掌握 SAM，就掌握了子串计数、LCS、出现次数等一整类问题的统一框架，也是从"会写算法"走向"理解串结构"的里程碑。
