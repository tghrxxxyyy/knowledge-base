# KMP算法

> 对应 Knuth, Morris, Pratt (1977) 论文 "Fast Pattern Matching in Strings"，以及 CLRS《算法导论》第 32 章（字符串匹配）。

## 一、背景与挑战

字符串匹配是计算机科学中最基础的问题之一：给定主串（文本）$T$（长度 $n$）和模式串 $P$（长度 $m$），要求找出 $P$ 在 $T$ 中所有出现的起始位置。文本编辑器的"查找"、生物信息学中的 DNA 片段比对、网络入侵检测里的特征串扫描，本质上都是这一问题的变体。朴素做法是所谓"暴力匹配"：从 $T$ 的每一个下标 $i$ 出发，逐字符比对 $T[i..i+m-1]$ 与 $P$，一旦失配就整体右移一位重新比对。该做法最坏时间复杂度是 $O(nm)$——例如 $P=\texttt{aaaaa}$、$T=\texttt{aaa}\cdots\texttt{aab}$ 时，几乎每个位置都会比对到模式末尾才失败。当 $n,m$ 达到十万级，且需要对大量模式反复扫描时，平方级复杂度会直接拖垮延迟。

问题的关键观察是：暴力匹配在失配后"忘掉了"已经比对过的字符信息。比如 $T$ 前缀已经与 $P$ 前 $j$ 个字符对齐成功，说明 $T$ 中这段子串等于 $P[0..j-1]$；失配后若把主串指针回退到 $i+1$ 重来，其实丢弃了这段子串内部的自相似结构。KMP（Knuth–Morris–Pratt）的核心思想是**主串指针永不回退**，只允许模式串指针 $j$ 回退；而回退到哪里，由模式串自身的"前后缀重合"信息决定。这需要预处理出 $P$ 的最长真前缀同时也是真后缀的长度表，通常称为前缀函数（prefix function）、$\pi$ 数组、或者国内教材常说的 next 数组。

在工程与面试语境中，KMP 是"线性时间单模式匹配"的代名词。面试官考察的往往不是能否默写代码，而是三点：为什么主串指针不回退、前缀函数的定义与边界（$\pi[0]=0$）、以及失配时 $j$ 应该跳到 $\pi[j-1]$ 还是 $\pi[j]$（不同下标约定下的写法差异常见于各教材，面试时必须说清楚自己的约定）。工程里更常用的可能是库函数或 Sunday/Horspool 这类平均更快的算法，但 KMP 的思想（利用已匹配信息、预处理自相似结构）是后缀数组、AC 自动机 fail 指针、字符串哈希之外几乎所有匹配算法的基石。

## 二、核心原理

先定义模式串 $P$（下标从 $0$ 开始）的**前缀函数** $\pi[i]$：它是满足 $P[0..k-1] = P[i-k+1..i]$ 的最大 $k < i+1$，即子串 $P[0..i]$ 的最长真前缀，同时也是它的真后缀（真 = 不等于自身）。约定 $\pi[0] = 0$，因为单字符子串没有真前缀。例如 $P = \texttt{ababaca}$：

| $i$ | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|-----|---|---|---|---|---|---|---|
| $P[i]$ | a | b | a | b | a | c | a |
| $\pi[i]$ | 0 | 0 | 1 | 2 | 3 | 0 | 1 |

可以看到 $P[0..4]=\texttt{ababa}$ 的最长真前后缀是 $\texttt{aba}$，长度 3，故 $\pi[4]=3$。

**不变量**：在匹配过程中，若当前已匹配 $j$ 个字符（即 $T[i-j..i-1] = P[0..j-1]$），则当 $T[i] \neq P[j]$ 时，我们不能简单地把 $j$ 置 0——因为 $P[0..j-1]$ 内部可能有更短的真前后缀重合。设 $\pi[j-1]=k$，则 $P[0..k-1] = P[j-k..j-1]$。既然 $T[i-j..i-1]$ 既等于 $P[0..j-1]$，它的后缀 $P[j-k..j-1]$ 也就等于前缀 $P[0..k-1]$，于是我们可以把模式向右滑动，使得 $P[0..k-1]$ 直接对齐到 $T$ 中已经匹配过的那段后缀上，接下来只需比较 $T[i]$ 与 $P[k]$。这就是 $j \leftarrow \pi[j-1]$（在 $j>0$ 的前提下）的由来。若回退后仍失配，继续用 $\pi$ 回退，直到 $j=0$；此时若 $T[i]\neq P[0]$，主串指针 $i$ 前进一位。**主串指针 $i$ 单调不减**，这是 $O(n+m)$ 的根源。

$\pi$ 数组自身的构建也是同一套回退逻辑的自匹配：把 $P$ 同时当作文本和模式，对每个 $i$，用"当前匹配长度 $j=\pi[i-1]$"去尝试扩展 $P[i]$，失败则 $j \leftarrow \pi[j-1]$。这样构造是 $O(m)$ 的，因为 $j$ 在整次构造中的总回退次数不超过总增长次数 $m$。

**边界条件**必须小心：(1) $m=0$ 时应返回特殊值或 0，避免下标越界；(2) 求全部出现位置时，报告 $i-m+1$ 后应令 $j \leftarrow \pi[j-1]$ 继续，而不是结束，否则会漏掉重叠出现（如 $P=\texttt{aa}$ 在 $T=\texttt{aaa}$ 中应有两处）；(3) 常见写法 `if pat[i]==pat[j]: j+=1` 前必须先 `while j>0 and ...`，且 $\pi[0]$ 不进入循环，否则会读 `pat[-1]`。

**正确性直觉**：回退后仍然保证 $T$ 中那段后缀与 $P$ 的前缀相等，且 $\pi$ 取的是"最长"真前后缀，所以不会错过任何可能的对齐位置；再结合 $i$ 单调，每个位置被检查常数次，整体线性。

## 三、形式化与数学基础

**前缀函数递推。** 记 $P = p_0 p_1 \cdots p_{m-1}$。定义

$$
\pi[i] = \max\{k : 0 < k \le i,\; p_0\cdots p_{k-1} = p_{i-k+1}\cdots p_i\},
$$

约定 $\pi[0]=0$（空真前缀）。构造时令 $j = \pi[i-1]$，当 $j>0$ 且 $p_i \neq p_j$ 时置 $j = \pi[j-1]$；若 $p_i = p_j$ 则 $\pi[i] = j+1$，否则 $\pi[i]=0$。其正确性由 $\pi$ 的最优子结构保证：$P[0..i]$ 的任何真前后缀长度 $k$ 都满足 $k-1$ 是 $P[0..i-1]$ 的某个真前后缀长度，因此从 $\pi[i-1]$ 出发沿 $\pi$ 链向下找是完备的。

**匹配过程的不变量。** 每一步有 $T[i-j..i-1] = P[0..j-1]$。失配转移 $j \leftarrow \pi[j-1]$ 后该等式仍成立（把公共前后缀"剪掉"再对齐）。由此可证：若 $T$ 在位置 $s$ 有匹配，扫描到 $i=s+m-1$ 时必有 $j=m$。

**时间复杂度。** 构建 $\pi$ 时，变量 $j$ 的总增加次数 $\le m$（每次成功匹配加 1），总减少次数 $\le$ 总增加次数，故内层 while 的总迭代次数 $O(m)$。匹配阶段同理，$j$ 的总变化量 $O(n)$。因此总时间

$$
T(n,m) = O(n + m).
$$

空间为 $O(m)$ 存 $\pi$。相对暴力的 $O(nm)$，在最坏输入下有平方级到线性的本质提升。注意 $O(n+m)$ 是最坏也是平均的上界；对随机文本，Sunday 等算法常数更小，但 KMP 的可预期性（worst-case linear）是它在实时与安全场景（如 IDS 特征匹配）中被采用的理由。

**next 数组的另一约定。** 部分教材把 next 定义为"失配时模式指针应跳到的下标"，即 $\mathrm{next}[j]$ 对应本文的 $\pi[j-1]$（且可能整体偏移 1）。读代码时务必先确认下标基准是 0 还是 1、$\pi$ 存的是前缀长度还是回退下标，这是面试手写翻车的高发点。

## 四、代码实现

```python
def build_pi(pat: str) -> list[int]:
    """构建前缀函数 pi[i] = pat[0..i] 最长相等真前后缀长度。"""
    m = len(pat)
    pi = [0] * m
    j = 0
    for i in range(1, m):
        while j > 0 and pat[i] != pat[j]:
            j = pi[j - 1]
        if pat[i] == pat[j]:
            j += 1
        pi[i] = j
    return pi


def kmp_search(text: str, pat: str) -> list[int]:
    """返回 pat 在 text 中所有出现的起始下标（允许重叠）。"""
    if not pat:
        return []
    pi = build_pi(pat)
    n, m = len(text), len(pat)
    j = 0
    hits = []
    for i in range(n):
        while j > 0 and text[i] != pat[j]:
            j = pi[j - 1]
        if text[i] == pat[j]:
            j += 1
        if j == m:
            hits.append(i - m + 1)
            j = pi[j - 1]  # 继续寻找重叠出现
    return hits


if __name__ == "__main__":
    assert build_pi("ababaca") == [0, 0, 1, 2, 3, 0, 1]
    assert kmp_search("aaaa", "aa") == [0, 1, 2]
    assert kmp_search("ababcababad", "ababa") == [5]
    assert kmp_search("hello", "xyz") == []
    assert kmp_search("", "a") == []
    print("KMP ok")
```

## 五、与其他技术对比

| 算法 | 预处理 | 最坏匹配 | 平均表现 | 额外空间 | 特点 |
|------|--------|----------|----------|----------|------|
| 暴力 | $O(1)$ | $O(nm)$ | $O(n)$ 左右 | $O(1)$ | 实现最简单，短模式/随机文本够用 |
| KMP | $O(m)$ | $O(n+m)$ | $O(n)$ | $O(m)$ | 最坏线性，主串不回退，可做在线匹配 |
| Boyer–Moore | $O(m+\sigma)$ | $O(nm)$（需改进） | $亚线性$，常可跳过多字符 | $O(\sigma)$ | 长模式英文文本极快，坏字符+好后缀 |
| Sunday | $O(m+\sigma)$ | $O(nm)$ | 实践极快 | $O(\sigma)$ | 看模式末尾下一字符，实现短，工程常用 |
| 字符串哈希 | $O(n)$ 预处理 | 依赖模数，可被卡 | $O(n)$ | $O(n)$ | 可回答任意子串相等，需处理冲突 |

**取舍**：模式很长、文本要在线流入、且要求最坏延迟有界时选 KMP；离线批量扫描英文文本可选 BM/Sunday；需要多次"子串是否相等"查询选哈希或后缀数组。KMP 的代码量适中、无哈希冲突风险，是教学与面试的默认答案。

## 六、常见误区

1. **把主串指针也做回退。** 有人写成失配后 $i$ 退回 $i-j+1$，那就退化为暴力，$O(n+m)$ 不再成立。正确做法是 $i$ 永远 $+1$ 或不变，只动 $j$。
2. **$\pi[0]$ 定义错。** 若把 $\pi[0]$ 设为 $-1$ 或 $1$，构建循环的边界全乱，短模式（$m=1$）直接崩。本文约定 $\pi[0]=0$，回退写 `j = pi[j-1]` 时要求 $j>0$。
3. **报告匹配后直接 `j = 0`。** 这样会漏掉重叠匹配。例如 `aaaa` 中找 `aa` 只报 0 位置。应 `j = pi[j-1]`。
4. **混淆 $\pi[i]$ 与"失配跳转下标"。** $\pi[i]$ 是长度；匹配阶段失配时跳到的是 $\pi[j-1]$（新的匹配长度），不是 $\pi[j]$。面试默写前先声明下标约定。
5. **认为 KMP 一定比暴力快。** 对极短模式（$m\le 2\sim 3$）或高度随机文本，预处理与更大的常数可能使 KMP 反而更慢；它的价值在最坏界与稳定的在线行为。

## 八、面试题

1. **为什么 KMP 最坏是 $O(n+m)$？**  
   参考答案：主串指针 $i$ 单调递增，总共 $n$ 步；模式指针 $j$ 的总增量不超过 $n+m$，每次失配回退由 $\pi$ 驱动，回退总量不超过增量总量，故内层 while 总迭代次数线性，整体 $O(n+m)$。

2. **如何求一个串的最长回文前缀 / 如何用 $\pi$ 判断一个串是否为周期串？**  
   参考答案：设 $n=\vert P\vert$，若 $\pi[n-1] > 0$ 且 $n \bmod (n - \pi[n-1]) = 0$，则 $P$ 有最小周期 $t = n - \pi[n-1]$，整个串由 $P[0..t-1]$ 重复构成。例如 `abcabcabc`，$\pi[8]=6$，$t=3$，$9\bmod 3=0$。这是前缀函数最经典的衍生题。

3. **手写 KMP 时如何处理"求所有出现（含重叠）"？**  
   参考答案：匹配成功记录 $i-m+1$ 后令 $j=\pi[j-1]$ 继续扫描，而不是置 0 或退出；并注意 $m=0$ 的空模式约定。

4. **KMP 的前缀函数与 AC 自动机的 fail 指针有何关系？**  
   参考答案：fail 指针是前缀函数在 Trie 上的推广——模式树上节点 $u$ 的 fail 指向"表示 $u$ 对应字符串的最长真后缀"的节点。KMP 只有一个模式，状态链是一条线；AC 自动机把这条线摊成树/图。

## 九、演进与趋势

KMP 本身已是成熟算法，演进主要体现在结构融合与工程替代上。其一，**自动机化解释**：把 $\pi$ 表编译成 DFA，失配不再是回退而是查表跳转，更适合硬件与 SIMD；Sedgewick 教材与许多工业实现采用这一视角。其二，**与多模式结合**：AC 自动机的 fail 指针即 Trie 上的 $\pi$，理解 KMP 是理解 AC 的前提。其三，**周期与 border 的代数应用**：字符串周期分解（如 $P$ 的所有周期构成等差数列）、Lyndon 分解、循环串最小表示法都建立在 border 结构上；2024 年前后在数据压缩（如 DNA 存储、基因组重复片段分析）中仍有直接使用。其四，**工程替代**：文本编辑器与 grep 默认使用 Boyer–Moore 变体或 RE2/Hyperscan 这类高度优化的多模式引擎，KMP 退居教学与"需要严格最坏界"的嵌入式/安全场景。在面试中，KMP 常作为"线性匹配"与"失败函数"的代表题出现，衍生题包括：最小周期、循环节、`strStr` 的多种实现比较、以及"用 KMP 求最短循环节"等。

## 十、小结

KMP 用模式串自身的 border 结构换取了主串指针的单调性，以 $O(m)$ 预处理与 $O(m)$ 空间，把最坏匹配从 $O(nm)$ 降到 $O(n+m)$。掌握的关键在于：$\pi[i]$ 是最长相等真前后缀**长度**、失配回退到 $\pi[j-1]$、匹配成功后继续回退以保留重叠。它既是单模式匹配的标准答案，也是理解 fail 指针、周期结构与更复杂字符串自动机的起点。
