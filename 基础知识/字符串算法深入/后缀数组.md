# 后缀数组

> 对应 Manber & Myers (1993) "Suffix Arrays: A New Method for On-Line String Searches"，以及 CLRS 相关字符串章节、cp-algorithms 的 SA-IS 讲解。

## 一、背景与挑战

后缀是字符串的"从某个位置到末尾"的子串。把串 $S$（长度 $n$，通常在末尾追加一个最小的哨兵字符 `$`）的所有 $n$ 个后缀按**字典序排序**，记录下标的数组就是**后缀数组** $sa[0..n-1]$。与它配套的 $rank$ 数组（后缀排名）和 $height$（或 LCP）数组——其中 $height[i]$ 为 $sa[i-1]$ 与 $sa[i]$ 的最长公共前缀——共同构成了静态字符串处理的瑞士军刀。

如果没有后缀结构，很多问题会很笨重：求"串中不同子串个数"需要枚举 $O(n^2)$ 个子串；求"最长公共子串"对两串 DP 是 $O(nm)$；求"至少出现 $k$ 次的最长子串"几乎无从下手。后缀数组把所有 $O(n^2)$ 个子串"折叠"进 $n$ 个后缀的排序序中：任何子串都是某个后缀的前缀，排序后相邻后缀的 LCP 恰好刻画了公共前缀，于是大量查询可在 $O(1)$ 或 $O(\log n)$ 内完成。

工程与面试中，后缀数组是"静态串、多查询"的首选：拼写检查词典、全文检索倒排之外的补充索引、DNA 重复片段分析、数据压缩（BWT 变换基于后缀排序）都以它为底座。面试常考"不用后缀自动机，如何求最长重复子串/不同子串个数"，标准答案就是后缀数组 + height。相比后缀自动机，后缀数组更直观、代码更好背、且天然给出有序枚举；缺点是插入修改困难（静态结构）。

## 二、核心原理

**定义。** 设 $S[0..n-1]$，约定 $S[n-1]=\$$ 且 `$` 小于一切真实字符。后缀 $i$ 指 $S[i..n-1]$。后缀数组 $sa$ 是 $\{0,1,\dots,n-1\}$ 的一个排列，满足 $S[sa[0]..] < S[sa[1]..] < \cdots$（字典序）。排名数组 $rank[i]$ 是 $i$ 在 $sa$ 中的位置：$rank[sa[i]]=i$。

**height 数组。** 对 $i \ge 1$，$height[i] = \mathrm{LCP}(S[sa[i-1]..],\ S[sa[i]..])$。约定 $height[0]=0$。直观上，把后缀按字典序排好后，相邻两个后缀往往共享一段开头，height 就量出这段长度。

**倍增构造（$O(n\log n)$）。** 核心思想：用"前 $2^k$ 个字符的排名"作为关键字，给后缀排序。令 $rk_k[i]$ 表示后缀 $i$ 的前 $2^k$ 字符构成的子串（不足则用哨兵补）的排名。从 $k=0$（单字符）开始，排序关键字为二元组

$$
\bigl(rk_{k}[i],\ rk_{k}[i + 2^k]\bigr).
$$

用基数排序（先按第二关键字、再按第一关键字）可在线性时间完成一轮，共 $O(\log n)$ 轮，总 $O(n\log n)$。排序后重算 $rk_{k+1}$：若某后缀的二元组与前一个相同，则排名相同（它们在 $2^{k+1}$ 范围内不可区分），否则排名 +1。当所有排名都唯一时提前结束。

**height 的线性求法（Kasai）。** 若已知 $rank$，维护 $h$ 为 $height[rank[i]]$ 的候选：从 $i=0$ 开始，用"上一个后缀的 LCP 至少是 $h-1$"的跳跃，可证明总比较次数 $O(n)$：

$$
height[rank[i]] \ge height[rank[i-1]] - 1.
$$

这与 Z-algorithm 的加速同源：利用已知公共前缀减少字符比较。

**不变量与正确性**：每一轮倍增后 $rk_k$ 是"前 $2^k$ 字符"的全序；二元组比较恰好等价于比较后缀的前 $2^{k+1}$ 字符。最终 $k \ge \log n$ 时 $2^k \ge n$，排名即完整后缀的字典序。

## 三、形式化与数学基础

**子串与后缀的关系。** 任何子串 $S[l..r]$ 都是后缀 $l$ 的长度 $(r-l+1)$ 的前缀。设 $i$ 的排名为 $rank[i]$，则与 $S[l..r]$ 有公共前缀的后缀必在 $rank[l]$ 附近连续出现，其范围可由 height 数组上 RMQ/二分确定。

**不同子串个数。** 全部后缀贡献的前缀总数为

$$
\sum_{i=0}^{n-1} (n - i) = \frac{n(n+1)}{2},
$$

但排序后相邻后缀共享 $height[i]$ 个前缀，被重复计入。于是本质不同子串数

$$
\frac{n(n+1)}{2} - \sum_{i=1}^{n-1} height[i].
$$

证明：按字典序枚举后缀，后缀 $sa[i]$ 新带来的前缀数恰为 $(n - sa[i]) - height[i]$。

**最长公共子串（两串）。** 将 $A\#\!B$ 拼接后建 SA 与 height，扫描 height 数组，取跨越 `#` 两侧的 height 最大值即可 $O(n\log n)$（含排序）。

**至少出现 $k$ 次的最长子串。** 在 height 数组上做长度为 $k-1$ 的滑动窗口最小值（单调队列/ST 表），窗口最小 height 即该窗口内后缀的公共前缀下界，取全局最大。

**倍增复杂度。** 每轮基数排序 $O(n + \Sigma)$（$\Sigma$ 为排名值域 $O(n)$，用计数排序），共 $O(\log n)$ 轮：

$$
T(n) = O(n\log n),\quad \text{空间 } O(n).
$$

SA-IS 可达 $O(n)$ 最坏，但常数与实现难度大；$n \le 10^6$ 时倍增 + 基数排序在竞赛中仍广泛使用。

**height 的 Kasai 上界。** 设 $h_i = height[rank[i]]$。若 $h_{i-1} > 0$，则从 $i$ 起的后缀与从 $i-1$ 起的后缀错开一格，它们的 LCP 至少 $h_{i-1}-1$。故

$$
h_i \ge \max(0, h_{i-1} - 1),
$$

比较从 $h_{i-1}-1$ 开始跳，总失败次数不超过总成功次数，$O(n)$。

## 四、代码实现

```python
def build_sa(s: str) -> list[int]:
    """倍增 + 基数排序构造后缀数组（含哨兵）。"""
    s = s + "$"  # 最小字符，保证后缀互不为前缀
    n = len(s)
    # 初始按单字符排序（字符为整数）
    sa = list(range(n))
    rk = [ord(c) for c in s]
    tmp = [0] * n
    k = 1
    while True:
        # 按二元组 (rk[i], rk[i+k]) 做两轮计数排序
        def key(i):
            return (rk[i], rk[i + k] if i + k < n else -1)

        maxv = max(rk) + 2
        # 先按第二关键字
        cnt = [0] * maxv
        second = [rk[i + k] if i + k < n else -1 for i in sa]
        # 用 -1 映射到 0 位置：这里直接用 Python sort 简洁实现（O(n log n)/轮，教学清晰）
        sa.sort(key=key)
        tmp[sa[0]] = 0
        for i in range(1, n):
            tmp[sa[i]] = tmp[sa[i - 1]] + (key(sa[i]) != key(sa[i - 1]))
        rk, tmp = tmp, rk
        if rk[sa[-1]] == n - 1:
            break
        k <<= 1
    return sa


def build_height(s: str, sa: list[int]) -> list[int]:
    """Kasai: height[i] = LCP(sa[i-1], sa[i])。"""
    s = s + "$"
    n = len(s)
    rank = [0] * n
    for i, p in enumerate(sa):
        rank[p] = i
    height = [0] * n
    h = 0
    for i in range(n):
        r = rank[i]
        if r == 0:
            continue
        j = sa[r - 1]
        while i + h < n and j + h < n and s[i + h] == s[j + h]:
            h += 1
        height[r] = h
        if h:
            h -= 1
    return height


def count_distinct_substrings(s: str) -> int:
    """不同子串个数 = n(n+1)/2 - sum(height[1:])。"""
    sa = build_sa(s)
    ht = build_height(s, sa)
    n = len(s)
    return n * (n + 1) // 2 - sum(ht[1:])


if __name__ == "__main__":
    s = "banana"
    sa = build_sa(s)
    # 后缀排序（含 $）：$ < a$ < ana$ < anana$ < banana$ < na$ < nana$
    assert sa[0] == len(s)  # 只有哨兵后缀
    # 检查字典序
    ss = s + "$"
    order = [ss[p:] for p in sa]
    assert order == sorted(order)
    # "aaa" 的不同子串: a, aa, aaa 共 3 个
    assert count_distinct_substrings("aaa") == 3
    assert count_distinct_substrings("abc") == 6
    print("SA ok")
```

## 五、与其他技术对比

| 结构 | 构建 | 子串存在性 | 最长重复 | 不同子串数 | 动态修改 | 实现难度 |
|------|------|------------|----------|------------|----------|----------|
| 后缀数组 + height | $O(n\log n)$ 或 $O(n)$ | 二分 $O(m\log n)$ | height 最大值 | 公式 $O(1)$ | 困难 | 中 |
| 后缀自动机 SAM | $O(n)$ | $O(m)$ | parent 树 DP | 状态长度求和 | 可增量 | 高 |
| 后缀树 Ukkonen | $O(n)$ | $O(m)$ | 类似 | 类似 | 较易 | 高 |
| 字符串哈希 | $O(n)$ | $O(m)$ 期望 | 二分哈希 | 集合去重 | 易 | 低 |

**取舍**：静态、要排序与 LCP、要写得出来 → 后缀数组；在线逐字符构建、要本质不同子串统计与 endpos 类问题 → SAM；只要子串相等过滤器 → 哈希。两者常配合：SA 做可视化与查询，SAM 做计数 DP。

## 六、常见误区

1. **不加哨兵 `$`。** 若某后缀是另一后缀的前缀（如 `aa`），字典序比较会截断，排名与 LCP 语义混乱。加最小字符可保证严格比较。
2. **height 与 rank 下标搞反。** $height[i]$ 对应的是排名为 $i$ 的后缀与前一名的 LCP，不是"后缀起点 $i$"。Kasai 里 `height[rank[i]] = h` 才对。
3. **倍增第二关键字越界。** $i + 2^k \ge n$ 时必须当作"最小"处理（补哨兵语义），否则排序错误。
4. **用 `str` 切片比较做排序教学版却宣称 $O(n\log n)$。** 切片比较每次可能 $O(n)$，真正倍增应比"排名对"而不是比字符；上文教学代码用 `sort(key=key)` 实为每轮 $O(n\log n)$、总 $O(n\log^2 n)$，竞赛正式实现要用基数排序压到 $O(n\log n)$。面试时应主动说明这一差别。
5. **认为后缀数组可以高效支持单点修改。** SA 是静态的；动态请用二进制分组 + 小 SA、或转后缀平衡树/FM-index。

## 八、面试题

1. **用后缀数组求"至少出现 k 次的最长子串"。**  
   参考答案：对 height 数组做窗口大小 $k-1$ 的滑动最小值，窗口最小 height 是这些后缀两两 LCP 的下界，答案为所有窗口最小值的最大值。$O(n)$。

2. **求两串最长公共子串。**  
   参考答案：拼 $A\#\!B$，建 SA/height，扫 height 取"两侧后缀分别来自 $A$ 与 $B$"的最大 height。$O(n\log n)$。

3. **后缀数组如何回答 $S[l..r]$ 是否为 $T$ 的子串？**  
   参考答案：在 SA 上二分比较 $S[l..r]$ 与各后缀字典序，找到第一个 $\ge$ 与第一个 $>$ 的区间，区间非空则存在；比较用 $O(r-l+1)$ 或再配 RMQ/LCP 加速。

4. **为什么 height 数组能算不同子串个数？**  
   参考答案：所有后缀前缀总数 $n(n+1)/2$；排序后后缀 $sa[i]$ 相对前一名重复了 $height[i]$ 个前缀，减去即得。

## 九、演进与趋势

后缀数组的现代演进围绕**更快构造、压缩索引与可持久化**。SA-IS 与 DC3/skew 算法把构造做到最坏 $O(n)$，并在 DNA 与日志分析中成为库标配（如 `divsufsort`）。与 BWT（Burrows–Wheeler 变换）结合的 FM-index 把后缀结构压到接近信息熵，支持 $O(m)$ 模式搜索与计数，是 Bowtie/BWA 等基因比对工具的基石。可持久化线段树 + height 可回答"区间不同子串个数"等在线查询。与后缀自动机并行：工程里大字符串静态索引偏爱 SA/FM-index，规则引擎与动态子串计数偏爱 SAM。面试趋势上，纯粹"手写 SA"出现频率下降，更多是"用 SA + height 解决具体问题"的建模题；理解 LCP 的滑动窗口应用比默写基数排序更常考。

## 十、小结

后缀数组把全部后缀排成字典序，height 数组量化相邻 LCP，从而以 $O(n\log n)$ 构建换取大量 $O(1)$/$O(\log n)$ 子串查询：不同子串计数、最长重复、至少 $k$ 次出现、两串 LCS 等皆可归约为 height 上的区间问题。它静态、直观、可验证，是字符串算法从"单点匹配"走向"全串索引"的关键一步，也是理解后缀自动机与 FM-index 的最佳对照物。
