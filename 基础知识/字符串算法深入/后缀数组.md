# 后缀数组

> 对应 Manber & Myers 1990 与《Suffix Arrays: A New Method for On-Line String Searches》。

## 一、背景与挑战
后缀数组 sa 是字符串所有后缀按字典序排好的起始下标数组，配合 rank 与 height 可做众多子串问题。

## 二、核心原理
构造方法：倍增（prefix doubling）按长度为 k 的排名排序；height[i] = LCP(sa[i-1], sa[i])，用性质 `height[rank[i]] >= height[rank[i-1]] - 1` 线性求出。

## 三、形式化 / 数学基础
$sa[i]$：第 i 小后缀的起点；$rank[sa[i]] = i$。
$height[i] = LCP(sa[i-1], sa[i])$，相邻 height 之差不超过 1。

## 四、代码实现
```python
def build_sa(s):
    n = len(s)
    sa = list(range(n))
    rank = list(s)
    k = 1
    while k < n:
        sa.sort(key=lambda i: (rank[i], rank[i + k] if i + k < n else -1))
        tmp = [0] * n
        tmp[sa[0]] = 0
        for i in range(1, n):
            tmp[sa[i]] = tmp[sa[i-1]] + (lambda a, b: a != b)(
                (rank[sa[i]], rank[sa[i] + k] if sa[i] + k < n else -1),
                (rank[sa[i-1]], rank[sa[i-1] + k] if sa[i-1] + k < n else -1))
        rank = tmp
        if rank[sa[-1]] == n - 1:
            break
        k <<= 1
    return sa
```

## 五、与其他技术对比
与后缀树相比，后缀数组空间更小（O(n)）、实现简单；与哈希相比，能做基于排名的区间查询。

## 六、常见误区
倍增排序 key 的第二关键字越界处理；height 计算遗漏 -1 偏移；rank 数组更新未用临时数组。
