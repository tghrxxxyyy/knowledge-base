# 一致性哈希原理

> 对应 Karger et al. 1997（Consistent Hashing and Random Trees, MIT）与 Kleppmann DDIA 第6章（分区与副本）。

## 一、背景与挑战
传统哈希 `hash(key) % N` 在节点数 N 变化时，几乎所有 key 的映射都会改变，引发大规模数据迁移。一致性哈希把节点与 key 放到同一哈希环上，仅影响相邻节点，大幅减少再平衡成本。

## 二、核心原理
1. 使用一个哈希函数把节点和 key 都映射到固定范围（如 0~2^32 的环）。
2. key 顺时针找到的第一个节点即为其归属节点。
3. 节点加入/离开只影响其环上相邻区间的 key。

## 三、形式化与数学基础
设环长度为 M，节点数为 N。普通取模下增删节点导致约 $\frac{N-1}{N}$ 的 key 需迁移；一致性哈希下平均仅 $\frac{1}{N}$ 的 key 需要迁移，迁移量从 $O(K)$ 降到 $O(K/N)$。

## 四、代码实现
# 一致性哈希环（无虚拟节点）
class Ring:
    def __init__(self):
        self.nodes = {}   # hash -> node_id

    def add(self, node_id):
        self.nodes[hash(node_id) % (2**32)] = node_id

    def get(self, key):
        h = hash(key) % (2**32)
        for hp in sorted(self.nodes):
            if hp >= h:
                return self.nodes[hp]
        return self.nodes[min(self.nodes)]

## 五、与其他技术对比
- 对比取模哈希：一致性哈希迁移量小得多。
- 对比范围分区：一致性哈希无需手动划分边界。

## 六、常见误区
1. 忽略虚拟节点导致负载不均。
2. 用有偏哈希函数使环上节点聚集。
