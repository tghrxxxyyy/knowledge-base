# 一致性哈希与普通哈希对比

> 对应 Karger et al. 1997（Consistent Hashing）与 Kleppmann DDIA 第6章（数据分区）。

## 一、背景与挑战
当集群规模固定且永不变化时，普通取模哈希简单高效。但现实集群常扩缩容，普通哈希的再平衡代价成为瓶颈，这正是引入一致性哈希的动机。

## 二、核心原理
- 普通哈希：`idx = hash(key) % N`，N 变则全盘重映射。
- 一致性哈希：key 与节点同处环上，仅相邻区间迁移。

## 三、形式化与数学基础
设 key 总数 K、节点数由 N 变 N+1：
- 取模：约 $\frac{N}{N+1} K$ 个 key 迁移。
- 一致性哈希：约 $\frac{1}{N+1} K$ 个 key 迁移。
差距在大规模下可达数十倍。

## 四、代码实现
# 两种映射迁移量示意
def moved_ratio_mod(N):
    return N / (N + 1)

def moved_ratio_ch(N):
    return 1 / (N + 1)

## 五、与其他技术对比
| 方式 | 迁移量 | 适用 |
| 取模 | O(K) | 固定集群 |
| 一致性 | O(K/N) | 动态集群 |

## 六、常见误区
1. 在固定集群上过度使用一致性哈希增加复杂度。
2. 混用两种哈希导致路由不一致。

## 九、演进与趋势
Jump Hash、Maglev Hash 在一致性基础上进一步优化查询与均衡。

## 十、小结
哈希方式的选择取决于集群是否动态，一致性哈希专为弹性伸缩设计。
