# 缓存一致性问题

> 对应 CSAPP 中文笔记 https://github.com/Hansimov/csapp 第6章；Hennessy & Patterson 附录 C；Tanenbaum《Modern Operating Systems》。

## 一、背景与挑战

多核每核私有缓存，同一内存块可能多份副本。某核改写后，其他核读到旧值，产生不一致。需协议保证“单写多读”视图：任何时刻某地址要么一个改写者、要么多个一致读者。

## 二、核心原理

一致性要求：写传播（写须被他核看到）、写串行化（多核对同一地址写有全序）、读可见性（读返回最近写）。两种实现：基于监听(Snooping，总线广播)与基于目录(Directory，显式跟踪共享者)。

## 三、形式化 / 数学基础

一致性可建模为内存操作序列的串行等价：若所有处理器看到同一交错顺序 $S$ 满足程序内依赖，则一致。写串行化意味着对同一地址：

$$\forall p,q:\; order(W_p(a), W_q(a)) \text{ 全局唯一}$$

## 四、代码实现

```c
// 无一致性抽象下，核A写核B可能看不到
volatile int flag = 0;
// core A:
flag = 1;          // 写私有缓存，未回写则 B 看不见
// core B:
while (flag == 0); // 可能死循环，需一致性+内存屏障
```

## 五、与其他技术对比

- 监听简单但总线带宽随核数平方增长；目录扩展到大规模。
- 一致性不保证顺序（需内存模型/屏障补充）。

## 六、常见误区

- 误以为一致即顺序一致：一致性只保证单地址写串行化。
- 把缓存一致性当内存模型：x86 的 TSO 才是顺序约束。

## 八、面试题

- 一致性三大要求？答：写传播、写串行化、读返回最新。
- 监听与目录区别？答：广播 vs 显式共享者跟踪。

## 九、演进与趋势

核数增多推动目录协议与包含/排他策略演进，NUCA 片内网络承载一致性流量。

## 十、小结

一致性是多核正确性的基石，但对性能与带宽代价巨大，需与缓存层级协同设计。
