# 可执行文件加载与进程镜像建立

> 对应 Silberschatz《Operating System Concepts》第 8 章；CSAPP 第 7.9 节。

## 一、背景与挑战
内核不能把磁盘上的字节直接当指令跑，必须按程序头（program header）把段映射到虚拟地址空间，并建立初始栈、堆与寄存器状态。

## 二、核心原理
ELF 的 PT_LOAD 段描述哪段文件内容映射到哪段虚拟地址及权限（r/w/x）。加载器遍历程序头，调用 mmap 建立映射，清零 BSS，设置入口地址与初始栈（argc/argv/envp）。动态可执行先加载 ld.so 作为解释器。

## 三、形式化与数学基础
虚拟地址到文件偏移映射：对段 $[v_{start}, v_{end}]$ 对应文件 $[f_{start}, f_{end}]$，
$$v - v_{start} = f - f_{start},\quad pgoff = \lfloor f_{start}/PAGE \rfloor$$
页面边界对齐到 PAGE（通常 4KiB）。

## 四、代码实现
```c
// 内核加载循环（简化）
for (ph = phdr; ph < phdr + n; ph++)
    if (ph->p_type == PT_LOAD)
        vm_mmap(file, ph->p_vaddr, ph->p_filesz,
                ph->p_flags, ph->p_offset);
memset(ph->p_vaddr + ph->p_filesz, 0,
       ph->p_memsz - ph->p_filesz);  // BSS
```

## 五、与其他技术对比
静态加载一次性映射所有段；按需分页（demand paging）首次访问才调入物理页，启动更快、内存更省。

## 六、常见误区
1. 文件大小等于内存大小——BSS 不占文件空间却占内存。
2. 以为加载即执行——还需动态链接、TLS 初始化。
3. 混淆虚拟地址与文件偏移，二者仅页内相等。

## 九、演进与趋势
load-bias 随机化（ASLR）把基址打乱以抗 ROP；内存映射粒度细化到 2MiB 大页。

## 十、小结
加载是文件段到虚拟空间的受控映射，BSS 清零与入口设置是建立进程态的最后拼图。
