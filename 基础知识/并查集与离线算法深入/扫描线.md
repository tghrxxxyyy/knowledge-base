# 扫描线

> 对应 计算几何与数据结构中的「扫描线 / 线段树」方法（CLRS 计算几何章节亦涉及）。

## 一、背景与挑战
求解矩形面积并、窗口最大值、区间覆盖等问题。扫描线把二维问题沿一轴扫描，用数据结构维护另一轴。

## 二、核心原理
把事件（如矩形左右边界）按扫描方向排序，依次用线段树/BIT 维护当前截面的覆盖长度或最值。

## 三、形式化 / 数学基础
矩形面积并：对每个 x 事件，用线段树维护 y 轴覆盖总长 len，贡献 `len * Δx`。复杂度 $O(n\log n)$。

## 四、代码实现
```python
import heapq
def max_in_sliding_window_using_sweep(nums, k):
    # 等价于扫描线取每个窗口最大（此处用单调队列更优，仅示意事件思想）
    events = [(i, x) for i, x in enumerate(nums)]
    out = []
    dq = []
    for i, x in events:
        while dq and dq[0][0] <= i - k:
            dq.pop(0)
        while dq and dq[-1][1] <= x:
            dq.pop()
        dq.append((i, x))
        if i >= k - 1:
            out.append(dq[0][1])
    return out
```

## 五、与其他技术对比
与暴力枚举每个区间相比，扫描线 + 线段树把 O(n^2) 降到 O(n log n)；与单调队列相比，扫描线更通用。

## 六、常见误区
事件排序关键字错（边界重合时入先于出）；线段树懒标记未下传；离散化后区间映射错。
