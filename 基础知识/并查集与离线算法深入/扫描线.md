# 扫描线

> 对应 计算几何中的平面扫描（Bentley–Ottmann）、CLRS 计算几何章节，以及《算法竞赛进阶指南》扫描线与线段树例题（矩形面积并、天际线）。

## 一、背景与挑战

二维几何问题——矩形面积并、天际线轮廓、区间覆盖总长、矩形周长并、最近点对——若直接暴力，常是 $O(n^2)$ 甚至 $O(n^3)$：每个矩形与其它矩形求交、每个时刻重新计算覆盖。当 $n$ 到 $10^5$，平方级直接不可接受。

**扫描线（sweep line）**的思路是「降维 + 流式维护」：选一个方向（通常横轴 $x$）作为扫描方向，把二维事件变成一维事件流；扫描过程中用一个数据结构（线段树、BIT、堆、单调队列）维护「当前扫描线上的截面状态」。每个事件只引起局部更新，总复杂度降到 $O(n\log n)$ 量级。

它是几何与数据结构交叉的经典范式，也是离线思想的亲兄弟：事件排序就是离线收集，扫描就是一次批处理。工程里扫描线出现在**排版/文字行分割、VLSI 布线、窗口重叠计算、监控区域覆盖、时间区间合并**。面试高频题「矩形面积并」「天际线」「滑动窗口最大值」（其单调队列本质也是扫描线的特例）都指向这一范式。

## 二、核心原理

### 2.1 事件驱动

以「矩形面积并」为例：输入 $n$ 个轴对齐矩形 $[x_1,x_2]\times[y_1,y_2]$。沿 $x$ 扫描，把每个矩形拆成两个事件：

- $x = x_1$：区间 $[y_1,y_2]$ **加入**覆盖；
- $x = x_2$：区间 $[y_1,y_2]$ **移除**覆盖。

把所有事件按 $x$ 排序（同 $x$ 先加后减或先减后加，视题目；面积并一般先加后减避免零宽漏计）。从左到右处理：相邻事件 $x_i, x_{i+1}$ 之间的覆盖长度 $L$（$y$ 轴并集）不变，面积贡献 $L \cdot (x_{i+1} - x_i)$。

### 2.2 截面数据结构

维护「当前 $y$ 轴覆盖总长」是关键。若 $y$ 坐标值域大，先**离散化**：收集所有 $y_1,y_2$，排序去重后映射到 $0..M-1$，用线段树维护每段是否被覆盖、覆盖次数、覆盖长度。

线段树结点维护：

- `cnt`：该区间被加了几次；
- `len`：该区间实际被覆盖的长度（离散化后的段权和）。

加区间时 `cnt += 1`，减区间 `cnt -= 1`；`cnt > 0` 则 `len` 为区间总长，`cnt == 0` 时 `len` 由左右孩子合并。这避免了「懒标记下传」的复杂度，称为**不用下传的覆盖线段树**。

### 2.3 天际线与堆

「天际线」问题：一堆矩形建筑 $(L,H,R)$，求轮廓。事件：左边界 $(L, -H)$ 进入（负号令高度优先），右边界 $(R, H)$ 离开。用最大堆维护当前存活高度，堆顶即当前高度；堆顶变化时产生轮廓点。复杂度 $O(n\log n)$。

### 2.4 不变量与边界

- 事件排序稳定：同坐标时顺序影响零宽区间，需按题意定；
- 离散化后区间是「段」而非「点」：$[y_1,y_2]$ 映射到段编号 $id(y_2)-id(y_1)$，避免点重复；
- 覆盖长度在 `cnt` 回到 0 时要从孩子重新合并，不能沿用旧值；
- 周长并要额外维护「横线贡献」与「竖线贡献」，以及左右覆盖段数。

## 三、形式化与数学基础

**矩形面积并**：事件数 $2n$，排序 $O(n\log n)$；每个事件线段树更新 $O(\log M)$，$M \le 2n$ 为离散化后段数。总：

$$T = O(n\log n).$$

面积：

$$\text{Area} = \sum_{i} L_i \cdot (x_{i+1} - x_i),$$

$L_i$ 为第 $i$ 个 $x$ 间隙的 $y$ 轴覆盖总长。

**覆盖总长递推**（线段树结点）：

$$
\mathrm{len}(p) =
\begin{cases}
\text{span}(p), & \mathrm{cnt}(p) > 0 \\
\mathrm{len}(l)+\mathrm{len}(r), & \mathrm{cnt}(p)=0 \text{ 且非叶子} \\
0, & \mathrm{cnt}(p)=0 \text{ 且叶子}
\end{cases}
$$

其中 $\mathrm{span}(p)$ 是该结点对应离散段的物理总长度。

**天际线**：每个建筑贡献两个事件，堆操作 $O(\log n)$，总 $O(n\log n)$。

**滑动窗口最大值**（单调队列）：每个元素进出队一次，$O(n)$；可视作「长度为 $k$ 的窗口扫过数组」的扫描线，维护窗口内最值。

**正确性**：扫描线把二维测度（面积）分解为「一维测度 × 扫描位移」的积分和；事件之间截面不变，故分段计算精确。

## 四、代码实现

### 4.1 矩形面积并（扫描线 + 覆盖线段树）

```python
class SegCover:
    """覆盖线段树：维护 y 轴覆盖总长（离散化段权）。"""

    def __init__(self, coords):
        # coords: 升序去重坐标，段 i 对应 [coords[i], coords[i+1])
        self.coords = coords
        self.m = len(coords) - 1
        self.cnt = [0] * (4 * self.m)
        self.len = [0] * (4 * self.m)

    def _span(self, l, r):
        return self.coords[r + 1] - self.coords[l]

    def _pull(self, p, l, r):
        if self.cnt[p] > 0:
            self.len[p] = self._span(l, r)
        elif l == r:
            self.len[p] = 0
        else:
            self.len[p] = self.len[p * 2] + self.len[p * 2 + 1]

    def update(self, p, l, r, ql, qr, delta):
        if ql > r or qr < l:
            return
        if ql <= l and r <= qr:
            self.cnt[p] += delta
            self._pull(p, l, r)
            return
        mid = (l + r) // 2
        self.update(p * 2, l, mid, ql, qr, delta)
        self.update(p * 2 + 1, mid + 1, r, ql, qr, delta)
        self._pull(p, l, r)

    def total(self):
        return self.len[1] if self.m > 0 else 0


def rectangle_union_area(rects):
    """rects: [(x1,y1,x2,y2)]，返回面积并。"""
    if not rects:
        return 0
    ys = []
    events = []
    for x1, y1, x2, y2 in rects:
        if x1 >= x2 or y1 >= y2:
            continue
        ys.extend([y1, y2])
        events.append((x1, 1, y1, y2))
        events.append((x2, -1, y1, y2))
    ys = sorted(set(ys))
    yid = {v: i for i, v in enumerate(ys)}
    events.sort(key=lambda e: e[0])
    seg = SegCover(ys)
    area = 0
    i = 0
    while i < len(events):
        x = events[i][0]
        # 先结算上一个间隙
        if i > 0:
            area += seg.total() * (x - prev_x)
        # 处理同一 x 的所有事件
        while i < len(events) and events[i][0] == x:
            _, d, y1, y2 = events[i]
            seg.update(1, 0, seg.m - 1, yid[y1], yid[y2] - 1, d)
            i += 1
        prev_x = x
    return area
```

### 4.2 天际线（堆扫描线）

```python
import heapq


def get_skyline(buildings):
    """buildings: [(L, H, R)]，返回轮廓关键点 [[x, h], ...]。"""
    events = []
    for L, H, R in buildings:
        events.append((L, -H, R))   # 左边界，高度取负便于堆序
        events.append((R, 0, 0))    # 右边界
    events.sort()
    res = [[0, 0]]
    live = [(0, float("inf"))]  # (neg_height, end_x)
    i = 0
    n = len(events)
    while i < n:
        x = events[i][0]
        # 加入所有以 x 为左界的建筑
        while i < n and events[i][0] == x and events[i][1] != 0:
            _, neg_h, R = events[i]
            heapq.heappush(live, (neg_h, R))
            i += 1
        # 移除已结束的
        while live and live[0][1] <= x:
            heapq.heappop(live)
        h = -live[0][0]
        if res[-1][1] != h:
            res.append([x, h])
    return res[1:]


if __name__ == "__main__":
    # 矩形面积并：两个单位正方形重叠 1/4
    # [0,1]x[0,1] 与 [0.5,1.5]x[0,1] 并 = 1.5
    rects = [(0, 0, 1, 1), (0.5, 0, 1.5, 1)]
    # 离散化需要整数 y；用整数坐标示例
    rects = [(0, 0, 2, 2), (1, 0, 3, 2)]
    assert rectangle_union_area(rects) == 6  # [0,3]x[0,2]

    rects2 = [(0, 0, 1, 1), (1, 0, 2, 1), (0, 1, 2, 2)]
    assert rectangle_union_area(rects2) == 4

    bld = [(2, 10, 9), (3, 15, 7), (5, 12, 12), (15, 10, 20), (19, 8, 24)]
    sk = get_skyline(bld)
    # 与经典 LeetCode 218 样例对照
    assert sk == [[2, 10], [3, 15], [7, 12], [12, 0], [15, 10], [20, 8], [24, 0]]
    print("sweep line ok")
```

要点：覆盖线段树用 `cnt` 记录覆盖次数，`_pull` 决定 `len`；天际线用「负高度堆 + 右端点淘汰」。两段代码均可直接跑经典用例。

## 五、与其他技术对比

| 维度 | 扫描线 + 线段树 | 暴力两两求交 | 矩形树/线段树套树 | 单调队列（窗口最值） | 分治最近点对 |
|------|-----------------|--------------|-------------------|----------------------|--------------|
| 复杂度 | $O(n\log n)$ | $O(n^2)$ | $O(n\log^2 n)$ | $O(n)$ | $O(n\log n)$ |
| 实现 | 中 | 低 | 高 | 低 | 中 |
| 适用 | 面积并、天际线、覆盖 | 小 n | 动态二维 | 滑动窗口最值 | 最近点 |
| 是否离线 | 通常是 | — | 可在线 | 在线扫 | 通常是 |

**取舍**：静态几何测度优先扫描线；动态插入删除矩形需要树套树/矩形树；一维窗口最值用单调队列更简。扫描线是「把维数当时间」的统一框架。

## 六、常见误区

**误区一：离散化区间映射错误。** $[y_1,y_2]$ 应覆盖段 `id(y1) .. id(y2)-1`，若写成 `id(y2)` 会多算一段；坐标要去重排序。

**误区二：同 x 事件顺序不当。** 面积并若先减后加，重叠边界会出现零宽或漏计；天际线左界右界顺序影响轮廓点。按题意固定比较键。

**误区三：线段树 `len` 在 `cnt==0` 时未从孩子合并。** 会算出「已退出覆盖但仍记旧长度」，面积偏大。

**误区四：忘记非法矩形（零面积）过滤。** `x1>=x2` 或 `y1>=y2` 应跳过，否则事件错乱。

**误区五：把滑动窗口最值硬套完整扫描线线段树。** 窗口最值用单调队列 $O(n)$ 就够，上树是杀鸡用牛刀。

## 八、面试题

**Q1：矩形面积并怎么做？**
A：按 x 把矩形拆成入/出事件，排序后扫描；线段树维护 y 轴覆盖总长，相邻事件贡献 `len * Δx`。$O(n\log n)$。

**Q2：为什么覆盖线段树不用下传懒标记？**
A：操作是「区间加减覆盖次数」，`cnt` 精确记录；`cnt>0` 则整段被覆盖，`cnt==0` 从孩子合并，无需把 +1 推给叶子。

**Q3：天际线为何用最大堆？**
A：扫描到某 x 时，存活建筑的最大高度就是当前天际线高度；堆顶变化时输出关键点。左右边界事件 + 堆淘汰结束建筑。

**Q4：滑动窗口最大值算扫描线吗？**
A：思想一致（事件流 + 截面维护），但用单调队列 $O(n)$ 更优；扫描线是更一般框架。

## 九、演进与趋势

**平面扫描求交点**（Bentley–Ottmann）维护交点事件堆，$O((n+k)\log n)$。**扫描线 + 持久化线段树**可回答「历史时刻覆盖」。**三维扫描**（体素、矩形盒体积并）难度陡增，常用 CDQ/分治降维。**工程应用**：UI 布局重叠检测、地图切片、监控盲区、编译器行表、排版断行。**GPU/并行扫描线**在图形管线（光栅化）中是底层核心。面试趋势是「事件定义 → 截面结构 → 复杂度」三步走，要求能独立写面积并/天际线。

## 十、小结

扫描线把二维问题沿一维「流式」扫描，事件排序后用线段树/堆维护截面，把平方级暴力降到 $O(n\log n)$。矩形面积并、天际线、覆盖总长都是它的标准应用；不变量在于「事件之间截面不变」与「覆盖次数驱动长度」。掌握扫描线，等于掌握了离线降维的通用模板。
