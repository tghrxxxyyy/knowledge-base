# 按秩合并

> 对应 Tarjan 并查集经典论文与 CLRS Ch.21。

## 一、背景与挑战
若盲目把一棵树挂到另一棵，可能使树退化成链，find 变 O(n)。按秩（高度/大小）合并保证树高对数级。

## 二、核心原理
维护每棵树的秩（高度上界）或大小。合并时把秩小的挂到秩大的根下；秩相等时挂接后秩 +1。

## 三、形式化 / 数学基础
按秩合并下树高 $\le \log_2 n$；与路径压缩共同得到 $O(\alpha(n))$ 均摊。

## 四、代码实现
```python
class DSURank:
    def __init__(self, n):
        self.p = list(range(n))
        self.rank = [0] * n
    def find(self, x):
        if self.p[x] != x:
            self.p[x] = self.find(self.p[x])
        return self.p[x]
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False
        if self.rank[ra] < self.rank[rb]:
            self.p[ra] = rb
        elif self.rank[ra] > self.rank[rb]:
            self.p[rb] = ra
        else:
            self.p[rb] = ra
            self.rank[ra] += 1
        return True
```

## 五、与其他技术对比
仅路径压缩已够快，按秩合并提供最坏保证且便于证明；带权并查集常依赖按秩/大小。

## 六、常见误区
秩与大小混淆更新；合并方向写反使高树更高；递归 find 在极深时栈溢出（可改迭代）。

## 七、与开源书 / 权威来源对应
- CLRS《Introduction to Algorithms》Ch.21
- Tarjan 1975

## 八、面试题
证明按秩合并树高 O(log n)；带权并查集的合并公式。

## 九、演进与趋势
按大小合并（size）更直观；可持久化 DSU 用大小维护。

## 十、小结
按秩合并保证树高对数，与路径压缩共同成就「几乎常数」的并查集，是理论分析与工程实现的基础。
