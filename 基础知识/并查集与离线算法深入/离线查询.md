# 离线查询

> 对应 算法设计中「离线算法」思想与 Tarjan 离线 LCA 论文。

## 一、背景与挑战
某些问题若强制在线（边问边答）复杂度高；把全部询问收集后统一处理，可利用顺序或结构优化（如并查集、排序）。

## 二、核心原理
经典例子：动态连通性询问「第 k 条边加入后是否连通」——把所有边与询问按时间排序，用并查集顺序处理。

## 三、形式化 / 数学基础
离线把 q 个询问与 n 次更新排序后一次扫描，常把在线 O(q·T) 降为 O((n+q)\log(n+q))。

## 四、代码实现
```python
def offline_connectivity(edges, queries):
    # queries: (time, u, v) -> 该时刻后 u,v 是否连通
    order = sorted([('e', i, edges[i]) for i in range(len(edges))]
                   + [('q', t, (u, v)) for t, u, v in queries])
    dsu = DSURank(len(edges) + 10)
    ans = {}
    for typ, t, payload in order:
        if typ == 'e':
            dsu.union(payload[0], payload[1])
        else:
            u, v = payload
            ans[t] = dsu.find(u) == dsu.find(v)
    return ans
```

## 五、与其他技术对比
与在线算法（如 Link-Cut Tree）相比，离线更简单、常数小；但失去实时响应能力。

## 六、常见误区
时间顺序排错导致后效；并查集不支持「撤销」却试图离线删边（需用可持久化/回滚 DSU）。

## 九、演进与趋势
回滚并查集支持离线删边；CDQ 分治处理高维离线。

## 十、小结
离线查询通过集中处理 + 排序/并查集，常把高复杂度的在线问题降维，代价是放弃实时性。
