# 离线查询

> 对应 Tarjan 离线算法思想（《Data Structures and Network Algorithms》相关章节）、《算法竞赛进阶指南》离线章节，以及莫队、整体二分等经典离线技巧。

## 一、背景与挑战

很多问题若**强制在线**——来一个查询必须立刻回答——复杂度会卡在数据结构的下界上。典型例子：动态连通性「第 $k$ 条边加入之后 $u,v$ 是否连通」，若边可以删，在线结构要 Link-Cut Tree，代码难度极高；区间众数、区间逆序对等，若每个询问都独立做，常常是 $O(qn)$ 或 $O(qn\log n)$，直接超时。

**离线算法**换一个问法：先把所有查询**收集齐全**，看清时间顺序、区间关系、可交换性，再一次处理。它牺牲「实时应答」，换取对**顺序与结构**的利用——排序、并查集、树状数组、分治、莫队排序。竞赛与工程批处理中，离线是降维打击的常规武器。

离线的前提是问题允许延迟回答：所有查询在开始前已知（读入完毕再输出）。这在「批量报告」「日志分析」「预计算索引」中天然成立；在线交互题则不行。面试里常考「什么时候能离线」「离线后怎么排序」「为什么并查集能处理动态连通性」，本质是考「把时间维变成结构维」的建模能力。

## 二、核心原理

### 2.1 核心思想

把「查询」与「修改」放在同一条时间线上，重新安排处理顺序，使得：

1. 询问在正确的「状态快照」下被回答（不早不晚）；
2. 每个修改能高效地贡献到多个询问上；
3. 整体复杂度从「每个询问独立做」降到「共享一次扫描/一次结构」。

### 2.2 经典模式一：时间线扫描 + 并查集

问题：给定边序列 $e_1,\ldots,e_m$ 与询问 $(t, u, v)$：在前 $t$ 条边都加入后，$u,v$ 是否连通？

做法：把所有边与询问按「时间」排序，顺序扫过去；遇到边就 `union`，遇到询问就 `find(u) == find(v)`。并查集支持「加边」不支持「删边」，所以这类离线只适合**只加不删**（或删边用回滚 DSU）。

复杂度：排序 $O((m+q)\log(m+q))$，扫描 $O((m+q)\alpha(n))$，远优于每次询问 BFS $O(q(n+m))$。

### 2.3 经典模式二：排序 + 扫描线/树状数组

问题：二维数点、区间内小于 $k$ 的个数、离线第 $k$ 大。把询问按一维排序，用 BIT/线段树维护另一维，一次性回答。

### 2.4 经典模式三：莫队（分块排序）

区间询问 $[l,r]$ 可转移（从 $[l,r]$ 到 $[l\pm 1,r]$ 或 $[l,r\pm 1]$ 代价低）时，把询问按「块号 + 奇偶」排序，左右指针扫，总移动 $O(n\sqrt q)$ 或 $O(n\sqrt n)$。这是「离线排序优化转移」的代表。

### 2.5 边界与适用条件

- 查询必须**提前全部给出**；
- 修改若不可交换（有先后依赖），排序要尊重时间序；
- 需要「删除」时，普通并查集不可用，用**回滚 DSU**（按秩、记栈撤销）或整体二分；
- 询问之间若互相影响（在线交互、自适应查询），不能离线。

## 三、形式化与数学基础

设 $n$ 为元素数，$m$ 为修改数，$q$ 为询问数。

**时间扫描模式**：

$$T = O((m+q)\log(m+q)) + O((m+q)\,\alpha(n)).$$

对比在线逐询问：

$$T_{\text{online}} = O(q \cdot C_{\text{query}}),$$

当 $C_{\text{query}}$ 含 BFS/线段树大常数时，离线可省一个 $n$ 因子。

**莫队**：设块大小 $B = n/\sqrt{q}$，则指针移动

$$O\!\left(qB + \frac{n^2}{B}\right) = O(n\sqrt{q}).$$

当 $q \sim n$ 时为 $O(n\sqrt{n})$，优于 $O(n^2)$ 暴力。

**整体二分（parallel binary search）**：对「询问第 $k$ 大/第 $k$ 小」二分答案值域，把所有询问按 mid 并行判定，用 BIT 统计，递归左右。复杂度 $O((m+q)\log V \log n)$，$V$ 为值域。

**CDQ 分治**（下一篇展开）：三维偏序 $O(n\log^2 n)$，本质是「时间维二分 + 低维结构」。

离线复杂度的共同形式：把 $q$ 次独立代价，摊到一次 $O(n\log n)$ 或 $O(n\sqrt n)$ 的扫描上。

## 四、代码实现

### 4.1 动态连通性（只加边）离线

```python
class DSURank:
    def __init__(self, n):
        self.p = list(range(n))
        self.r = [0] * n

    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]
            x = self.p[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False
        if self.r[ra] < self.r[rb]:
            ra, rb = rb, ra
        self.p[rb] = ra
        if self.r[ra] == self.r[rb]:
            self.r[ra] += 1
        return True


def offline_connectivity(n, edges, queries):
    """edges: [(u,v)] 按加入顺序；queries: [(t,u,v)] 前 t 条边之后连通?"""
    events = []
    for i, (u, v) in enumerate(edges):
        events.append((i + 1, "E", u, v))  # 时间戳 1-based
    for t, u, v in queries:
        events.append((t, "Q", u, v))
    events.sort(key=lambda x: x[0])

    dsu = DSURank(n)
    ei = 0  # 已加入边数
    # 同一时间戳：先加边还是先询问？题目语义「前 t 条之后」→ 询问应在第 t 条之后
    events.sort(key=lambda x: (x[0], 0 if x[1] == "E" else 1))
    ans = {}
    for t, typ, u, v in events:
        if typ == "E":
            dsu.union(u, v)
        else:
            ans[(t, u, v)] = dsu.find(u) == dsu.find(v)
    return ans
```

### 4.2 离线区间和（静态，差分思想）与「区间内小于 k 个数」

```python
def offline_count_less(nums, queries):
    """queries: (l, r, k) 统计 nums[l..r] 中 < k 的个数。离线：按 k 扫 + BIT。"""
    n = len(nums)
    pairs = sorted((v, i) for i, v in enumerate(nums))  # 值从小到大
    # 询问按 k 升序，逐步把 < k 的位置加入 BIT
    bit = [0] * (n + 1)

    def add(i, delta=1):
        i += 1
        while i <= n:
            bit[i] += delta
            i += i & -i

    def prefix(i):
        # nums[0..i] 的和，i 可为 -1
        s = 0
        i += 1
        while i > 0:
            s += bit[i]
            i -= i & -i
        return s

    def range_sum(l, r):
        return prefix(r) - (prefix(l - 1) if l else 0)

    qrs = sorted(enumerate(queries), key=lambda x: x[1][2])
    out = [0] * len(queries)
    j = 0
    for qi, (l, r, k) in qrs:
        while j < n and pairs[j][0] < k:
            add(pairs[j][1])
            j += 1
        out[qi] = range_sum(l, r)
    return out


# ---------- 莫队：区间众数出现次数（简化：区间内不同数个数） ----------
def mo_distinct(nums, queries):
    """queries: (l, r) 返回区间不同数个数。"""
    n = len(nums)
    B = int(n ** 0.5) + 1
    qs = sorted(range(len(queries)),
                key=lambda i: (queries[i][0] // B,
                               queries[i][1] if (queries[i][0] // B) % 2 == 0 else -queries[i][1]))
    cnt = {}
    cur = 0
    ans = [0] * len(queries)
    l, r = 0, -1  # 当前窗口 [l, r] 为空

    def add(i):
        nonlocal cur
        v = nums[i]
        cnt[v] = cnt.get(v, 0) + 1
        if cnt[v] == 1:
            cur += 1

    def remove(i):
        nonlocal cur
        v = nums[i]
        cnt[v] -= 1
        if cnt[v] == 0:
            cur -= 1

    for qi in qs:
        ql, qr = queries[qi]
        while l > ql:
            l -= 1
            add(l)
        while r < qr:
            r += 1
            add(r)
        while l < ql:
            remove(l)
            l += 1
        while r > qr:
            remove(r)
            r -= 1
        ans[qi] = cur
    return ans
```

### 4.3 经典用例

```python
if __name__ == "__main__":
    # 动态连通性
    edges = [(0, 1), (1, 2), (3, 4)]
    queries = [(1, 0, 1), (2, 0, 2), (3, 0, 2), (3, 0, 3)]
    res = offline_connectivity(5, edges, queries)
    assert res[(1, 0, 1)] is True
    assert res[(2, 0, 2)] is True
    assert res[(3, 0, 2)] is True
    assert res[(3, 0, 3)] is False

    # 区间小于 k
    nums = [5, 1, 3, 2, 4]
    qs = [(0, 4, 3), (0, 2, 4), (1, 3, 2)]
    assert offline_count_less(nums, qs) == [2, 2, 0]

    # 莫队不同数
    arr = [1, 2, 1, 3, 2, 1]
    mqs = [(0, 5), (0, 2), (2, 3), (4, 5)]
    assert mo_distinct(arr, mqs) == [3, 2, 2, 2]
    print("offline queries ok")
```

要点：离线连通性必须尊重时间序（先加边再问）；`offline_count_less` 是「排序 + BIT」模式；莫队用分块排序减少指针移动。

## 五、与其他技术对比

| 维度 | 离线（扫描/并查集/莫队） | 在线数据结构 | 在线 LCT | 在线线段树套树 |
|------|--------------------------|--------------|----------|----------------|
| 实时应答 | 否 | 是 | 是 | 是 |
| 实现难度 | 低-中 | 中 | 高 | 高 |
| 典型复杂度 | $O(n\sqrt{n})$ 或 $O(n\log n)$ | $O(\log n)$ 每次 | $O(\log n)$ 每次 | $O(\log^2 n)$ 每次 |
| 支持删边 | 需回滚 | 看结构 | 是 | 是 |
| 适用 | 批处理、竞赛 | 交互、服务端 | 动态树 | 静态高维 |

**取舍**：查询全知、可延迟 → 离线往往代码更短、常数更小；交互/服务端 → 必须在线。竞赛里「先看能否离线」是降低难度的第一刀。

## 六、常见误区

**误区一：时间顺序排错。** 例如「前 $t$ 条边之后」的询问必须在第 $t$ 条边加入后回答；同时间戳先边后问还是先问后边，要按题意确定。

**误区二：需要删边却用普通并查集。** 并查集不支持撤销（路径压缩不可逆）。应改回滚 DSU（禁止压缩、按秩、记栈）或离线二分/分治。

**误区三：莫队块大小随便取。** $B = n/\sqrt{q}$ 附近最优；块太大或太小都会退化。还要奇偶排序减少右指针来回。

**误区四：忘记「询问必须全部读入」。** 离线不能边读边答；流式场景要另选结构。

**误区五：把「离线」当成「近似」。** 离线答案必须精确，只是应答时机延迟；不要混淆离线与随机化/近似算法。

## 八、面试题

**Q1：什么时候可以离线？**
A：所有查询提前已知、允许延迟应答、修改之间顺序可安排（或必须尊重但可排序）时。交互、自适应查询不行。

**Q2：动态连通性如何离线？**
A：边与询问按时间排序，扫过去用并查集加边、遇询问判连通。只加不删时 $O((m+q)\alpha(n))$。

**Q3：莫队为什么比暴力快？**
A：把询问按分块排序，左右指针只做 $O(n\sqrt q)$ 次移动，每次 $O(1)$ 或 $O(\log n)$ 调整答案，避免每个区间重算。

**Q4：离线如何支持删边？**
A：回滚并查集（按秩、记录修改、撤销），或整体二分/线段树分治把删边变成「区间存在」问题。

## 九、演进与趋势

**整体二分**处理带权第 $k$ 大、动态排名；**线段树分治**把时间区间上的边插入/删除分摊到 $O(\log q)$ 节点，配合可撤销 DSU；**莫队带修（树上莫队、回滚莫队）**扩展到树与修改；**离线与 CDQ** 解三维以上偏序。工程里离线思想出现在**批量图分析、日志回放、ETL 报表**：先收集再扫描。面试趋势是「判断能否离线 → 选扫描/莫队/分治 → 复杂度对比」的三段式。

## 十、小结

离线查询把「时间」从约束变成自由度：收集全部询问后排序、扫描、分治，用并查集/BIT/分块把总代价压到一次批量处理。它不支持实时，却在批处理与竞赛中常数小、代码短、可证明。掌握时间序语义、回滚需求与莫队/整体二分模式，是把离线用对的前提。
