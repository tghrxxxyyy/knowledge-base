# 并查集路径压缩

> 对应 Tarjan《Efficiency of a Good But Not Linear Set Union Algorithm》(1975)。

## 一、背景与挑战
并查集（Disjoint Set Union, DSU）维护不相交集合的合并与查询，路径压缩加速 find，使均摊接近常数。

## 二、核心原理
find 时把路径上每个结点直接挂到根，压平树高；union 合并两棵树。配合按秩/大小合并达到近常数。

## 三、形式化 / 数学基础
仅路径压缩的 find 复杂度 $O(\log n)$ 均摊；与按秩合并结合达 $O(\alpha(n))$（反阿克曼函数，实际常数）。

## 四、代码实现
```python
class DSU:
    def __init__(self, n):
        self.p = list(range(n))
    def find(self, x):
        while self.p[x] != x:
            self.p[x] = self.p[self.p[x]]   # 路径压缩（隔代）
            x = self.p[x]
        return x
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra != rb:
            self.p[ra] = rb
            return True
        return False
```

## 五、与其他技术对比
与 DFS 连通性相比，DSU 支持动态合并；与 BFS 相比更适合「加边判环」类问题。

## 六、常见误区
find 未压缩到根导致树退化为链；union 不判同根导致错误合并；未处理自环。

## 九、演进与趋势
可持久化并查集（按秩+主席树）；带权并查集（维护到根的距离/异或）。

## 十、小结
并查集核心是 find + union，路径压缩让查询接近常数，是图连通与等价类问题的利器。
