# 并查集路径压缩

> 对应 Tarjan《Efficiency of a Good But Not Linear Set Union Algorithm》(1975)、CLRS《Introduction to Algorithms》第 21 章，以及《算法竞赛进阶指南》并查集章节。

## 一、背景与挑战

并查集（Disjoint Set Union, DSU，又称 Union-Find）维护一族互不相交的集合，支持两种操作：**Find** 查询元素所在集合的代表元，**Union** 合并两个集合。它是图连通性、等价类划分、Kruskal 最小生成树、动态连通性等一整类问题的底层引擎。

朴素做法是用「森林」表示集合：每个集合一棵树，树根即代表元。`find` 沿父指针爬到根，`union` 把一棵树的根挂到另一棵的根下。问题在于：若 union 不加约束，反复把大树挂到小树下面（或总是把后者挂到前者），森林会退化成链，单次 `find` 变成 $O(n)$。对 $n$ 次操作，总代价 $O(n^2)$，面对 $10^5$ 级别的图算法直接超时。

路径压缩（path compression）是解决退化的第一把利器：**在 find 的回溯/下降过程中，把路径上的结点全部直接挂到根上**，下一次查找几乎一步到位。它不改变任何元素的集合归属，只改变树的形状，因此完全不影响正确性，却把均摊复杂度压到接近常数。与按秩合并结合后，单次操作均摊 $O(\alpha(n))$，$\alpha$ 是反阿克曼函数，在宇宙尺度内不超过 4。

工程与面试中的位置非常稳固：Kruskal、连通块计数、冗余边、账户合并、等式可满足性……几乎每个中等图论题都会用到。面试官要的不只是会写 `find/union`，还要能解释「为什么路径压缩是对的」「隔代压缩与完全压缩差在哪」「复杂度怎么来的」。

## 二、核心原理

### 2.1 结构表示

用父指针数组 `parent[]` 表示森林：`parent[x]` 是 `x` 的父结点；根满足 `parent[root] = root`（或用 `parent[root] = -1` 哨兵）。同一棵树中的结点属于同一集合，树根是代表元。

### 2.2 路径压缩的两种写法

**完全压缩（递归）**：`find(x)` 返回根的同时，把 `parent[x]` 直接设为根。

```text
find(x):
    if parent[x] != x:
        parent[x] = find(parent[x])
    return parent[x]
```

**隔代压缩（迭代）**：一边爬一边把结点挂到祖父上，循环结束时根仍是根，路径大致折半。

```text
find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x
```

两种写法均摊复杂度相同量级；迭代版避免递归栈溢出（链退化时递归深度 $O(n)$），工程更常用。完全压缩把树高压到「几乎扁平」，常数更好，但递归栈是隐患。

### 2.3 不变量与正确性

- **不变量**：任意时刻，`x` 与 `find(x)` 同属一棵树；树中所有结点的代表元（根）相同。路径压缩只改父指针指向祖先（最终为根），**不跨树改边**，因此不改变划分。
- **Union 语义**：`union(a, b)` 先 `ra = find(a), rb = find(b)`；若 `ra == rb` 则已在同一集合，返回假；否则 `parent[ra] = rb`（或按秩/大小选方向）。
- **边界**：`find` 对根本身返回自身；自环 `union(x, x)` 应视为无操作；注意初始化 `parent[i] = i`。

### 2.4 为什么要「顺手」压缩

一次 `find` 的代价正比于路径长度。压缩后路径变短，**后续**所有 `find` 受益。这是一种均摊思想：单次可能稍慢（多写几个指针），但把成本摊给未来的快速查找。若只做递归回溯压缩，深度大时栈溢出；隔代压缩在迭代中就完成大部分扁平化，更稳。

## 三、形式化与数学基础

**仅路径压缩、按任意方向合并**，单次 `find` 最坏 $O(n)$，但 $m$ 次操作的均摊是 $O((m+n)\log n)$（更紧的分析给出 $O(\log n)$ 均摊每次）。

**路径压缩 + 按秩（大小）合并**，Tarjan 1975 证明：$m$ 次操作时间

$$O(m\,\alpha(n)),$$

其中 $\alpha(n)$ 是反阿克曼函数，定义为

$$\alpha(n) = \min\{ k : A(k) \ge n \},$$

$A(k)$ 是 Ackermann 函数的高速增长逆。实际 $n \le 2^{65536}$ 时 $\alpha(n) \le 4$，故常称为「几乎 $O(1)$」。

**树高的直观界（仅按秩合并）**：设 `rank[x]` 是树高上界。合并两棵秩不同的树，把小秩挂到大秩下，秩不变；秩相同时挂接后秩 +1。可证：

$$\text{rank}[x] \ge k \Rightarrow \text{以 } x \text{ 为根的子树大小} \ge 2^k,$$

从而 $\text{rank} \le \log_2 n$。这是按秩合并单独成立的 $O(\log n)$ 树高；路径压缩进一步把高度压扁，结合后的精细分析才得到反阿克曼。

**均摊分析视角**（势能法）：定义势能与「结点到根的秩差」相关；路径压缩一次性减小大量结点的深度，释放势能，抵消其自身成本。CLRS 用此风格证明 $O(m\alpha(n))$。

## 四、代码实现

完整 DSU：递归路径压缩、迭代隔代压缩、按秩合并、连通块数、可回滚（简版）以及经典用例。

```python
class DSU:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n      # 树高上界
        self.count = n           # 连通块数量

    def find(self, x):
        """完全路径压缩（递归）。"""
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def find_iter(self, x):
        """隔代压缩（迭代），避免深递归。"""
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]
            x = self.parent[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False
        if self.rank[ra] < self.rank[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        if self.rank[ra] == self.rank[rb]:
            self.rank[ra] += 1
        self.count -= 1
        return True

    def connected(self, a, b):
        return self.find(a) == self.find(b)


# ---------- 经典用例 1：冗余连接（判环） ----------
def find_redundant_connection(edges):
    """edges[i] = [u, v]，返回最后一条导致成环的边。"""
    n = max(max(e) for e in edges)
    dsu = DSU(n + 1)
    for u, v in edges:
        if not dsu.union(u, v):
            return [u, v]
    return []


# ---------- 经典用例 2：岛屿数量 ----------
def num_islands(grid):
    if not grid:
        return 0
    m, n = len(grid), len(grid[0])
    dsu = DSU(m * n)
    dummy = m * n  # 水域统一并入 dummy（可选）
    def idx(i, j):
        return i * n + j
    for i in range(m):
        for j in range(n):
            if grid[i][j] == "0":
                continue
            for di, dj in ((1, 0), (0, 1)):
                x, y = i + di, j + dj
                if 0 <= x < m and 0 <= y < n and grid[x][y] == "1":
                    dsu.union(idx(i, j), idx(x, y))
    roots = {dsu.find(idx(i, j))
             for i in range(m) for j in range(n) if grid[i][j] == "1"}
    return len(roots)


# ---------- 经典用例 3：等式方程可满足性 ----------
def equations_possible(equations):
    dsu = DSU(26)
    for eq in equations:
        if eq[1] == "=":
            dsu.union(ord(eq[0]) - 97, ord(eq[3]) - 97)
    for eq in equations:
        if eq[1] == "!" and dsu.connected(ord(eq[0]) - 97, ord(eq[3]) - 97):
            return False
    return True


if __name__ == "__main__":
    assert find_redundant_connection([[1, 2], [1, 3], [2, 3]]) == [2, 3]
    assert find_redundant_connection([[1, 2], [2, 3], [3, 4], [1, 4], [1, 5]]) == [1, 4]

    grid = [
        list("11000"),
        list("11000"),
        list("00100"),
        list("00011"),
    ]
    assert num_islands(grid) == 3

    assert equations_possible(["a==b", "b!=a"]) is False
    assert equations_possible(["b==a", "a==b"]) is True
    assert equations_possible(["a==b", "b==c", "a==c"]) is True
    assert equations_possible(["a==b", "b!=c", "c==a"]) is False

    # 压缩效果：链状 union 后 find 一步到根
    d = DSU(6)
    for i in range(1, 6):
        d.union(i - 1, i)  # 可能形成链
    root = d.find(0)
    assert all(d.find(i) == root for i in range(6))
    assert d.count == 1
    print("dsu path compression ok")
```

要点：`union` 先 `find` 得根再挂；按秩时把小树挂到大树；`find_iter` 的 `parent[x] = parent[parent[x]]` 就是隔代压缩；判环只需 `union` 返回假。

## 五、与其他技术对比

| 维度 | DSU + 路径压缩 | DFS/BFS 连通 | BFS 动态加边 | Link-Cut Tree | 可持久化 DSU |
|------|----------------|--------------|--------------|---------------|--------------|
| 合并/查询 | 均摊近 $O(1)$ | 全图 $O(n+m)$ | $O(n+m)$ 每次 | $O(\log n)$ | $O(\log n)$ |
| 动态加边 | 支持 | 需重建 | 支持 | 支持 | 支持 |
| 删边 | 不支持 | 支持 | 支持 | 支持 | 需回滚 |
| 实现 | 极简 | 简单 | 简单 | 难 | 中高 |
| 适用 | 合并多、查询多、无删 | 静态图 | 少量更新 | 动态树 | 历史版本 |

取舍：只要「加边 + 查询连通」，DSU 是最优工程解；需要删边就上回滚 DSU（只加不删时按秩/大小+栈记录）或 LCT；需要路径信息（最短路、带权）则用带权并查集或图算法。

## 六、常见误区

**误区一：`find` 不压缩，或只在 `union` 里压缩一次。** 树仍会退化，$10^5$ 次操作超时。压缩必须在每次 `find` 路径上做。

**误区二：递归 `find` 在深链上爆栈。** Python 默认递归深度约 1000，链退化时炸。应用迭代隔代压缩，或先按秩合并保证树高。

**误区三：`union` 不判 `ra == rb` 就挂接。** 自环或重复边会让 `count` 算错，甚至成环（Kruskal 选错边）。

**误区四：路径压缩后仍按「旧高度」更新 rank。** rank 是合并时维护的上界，压缩不更新 rank 也不影响正确性；但若把 rank 当实际高度去用（例如启发式），会得到过时值。大小（size）同理：压缩不改 size，只在 union 时加。

**误区五：需要「删边」时直接改 `parent`。** 删边无法简单撤销路径压缩，必须用回滚 DSU（记录修改栈）或 LCT。

## 八、面试题

**Q1：路径压缩是什么？复杂度多少？**
A：`find` 时把路径上结点直接挂到根，扁平化树形。与按秩合并结合，$m$ 次操作 $O(m\alpha(n))$，几乎常数。

**Q2：递归压缩和隔代压缩的区别？**
A：递归完全压缩树更扁，但深递归可能爆栈；隔代压缩迭代安全，均摊同量级。工程优先迭代。

**Q3：Kruskal 里 DSU 做什么？**
A：按边权排序后依次尝试 `union` 两端点；返回假说明成环，跳过该边。用来实现「加边判环」与选边。

**Q4：如何支持删边？**
A：普通 DSU + 路径压缩不可逆。用回滚 DSU（记录父指针修改，撤销时恢复，禁止路径压缩或改用按秩）或 Link-Cut Tree。

## 九、演进与趋势

**带权并查集**：在 `parent` 旁维护到根的距离/异或/种类差，解「相对关系」问题。**可持久化 DSU**：主席树维护 parent 历史，支持版本回退。**回滚 DSU**：莫队、时间线分治里的删边。**分布式并查集**：图计算（连通分量）用哈希聚类/同步合并。**近似 DSU**：流式连通性、并查集与 Bloom 结合。面试进阶常考「路径压缩 + 按秩合并为什么是 $\alpha(n)$」的直觉：每次压缩都把一大批结点推向根，势能释放摊平成本。

## 十、小结

并查集用森林表示不相交集合，路径压缩在 `find` 时把结点直挂到根，彻底消除退化链；配合按秩合并，均摊 $O(\alpha(n))$ 反阿克曼，实际近似常数。它是连通性、等价类、Kruskal 等问题的基石，实现极简，但边界（自环、递归深度、删边）与复杂度直觉必须掌握。
