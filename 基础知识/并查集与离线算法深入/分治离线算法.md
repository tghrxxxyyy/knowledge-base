# 分治离线算法

> 对应 CDQ 分治（陈丹琦 2008 年国家集训队论文《浅谈数位类统计问题》相关思想与后续 OI 文献）、整体二分（parallel binary search），以及《算法竞赛进阶指南》分治与离线章节。

## 一、背景与挑战

高维偏序、带修改的数点、动态逆序对、三维数星星……这类问题若用树套树（树状数组套线段树、线段树套平衡树）在线硬刚，复杂度往往 $O(n\log^2 n)$ 但代码长、常数大、调参痛苦。更麻烦的是「动态」：插入/删除与询问交错，结构要支持可持久化或回滚，工程难度陡增。

**CDQ 分治**（一类分治离线算法）把「时间」当成分治维度：把操作序列按时间中点切成左右两半，递归处理左半内部、右半内部，最后只用**左半的修改贡献右半的询问**——因为左半时间更早，对右半是「历史影响」。合并贡献时，往往可以把某一维用排序消掉，再用树状数组做低维统计。经典结果是三维偏序 $O(n\log^2 n)$，代码只有归并 + BIT。

**整体二分**是另一条路线：对「第 $k$ 小 / 第 $k$ 大 / 第 $k$ 次出现」按答案值域二分，把所有询问打包判定 mid，递归左右值域。它把「二分答案」与「离线批处理」结合，是带权第 $k$ 类问题的标准解。

二者共享同一哲学：**把在线问题转成离线，把一维或时间维拿出来分治，用低维结构合并贡献**。竞赛中是高级离线技术的分水岭；工程里出现在批量数点、报表聚合、日志分析。面试常考「三维偏序怎么做」「CDQ 的时间复杂度」「何时用整体二分而非主席树」。

## 二、核心原理

### 2.1 CDQ 分治：左改右查

设操作序列 $a_1,\ldots,a_n$（含修改与询问），按下标 $mid$ 分治：

1. 递归处理 $[l,mid]$、$[mid+1,r]$；
2. **跨区间贡献**：左半修改对右半询问的影响；
3. 合并时对某一维排序/归并，降掉一维，用 BIT/平衡树做剩余维统计。

**三维偏序**（数星星、陌上花开）：点 $(a,b,c)$，问有多少点满足 $a_i \le a_j, b_i \le b_j, c_i \le c_j$。按 $a$ 排序后，CDQ 按下标分治（此时左半 $a$ 不大于右半）；合并时左右按 $b$ 归并，左半点插入 BIT（以 $c$ 为下标），右半点查询 BIT 中 $c \le c_j$ 的数量。每层合并 $O(n\log n)$，共 $O(\log n)$ 层：

$$T = O(n\log^2 n).$$

**动态逆序对**：时间上分治，左半插入、右半查询，BIT 维护值域，同样 $O(n\log^2 n)$。

### 2.2 整体二分

问题形态：静态/动态第 $k$ 小。对值域 $[l,r]$ 二分 $mid$：

1. 把所有「修改」按值 $\le mid$ 归入左档，否则右档；
2. 把所有「询问」用 BIT 模拟左档修改，看答案落在左还是右；
3. 递归处理左右档（注意下标与偏移）。

复杂度 $O((n+q)\log V \log n)$，$V$ 为值域大小；离散化后 $\log V$ 变 $\log n$。

### 2.3 不变量与边界

- CDQ 合并时必须保证「左半都先于右半」贡献，顺序错就漏计；
- 归并排序 $b$ 时不能破坏原数组在递归中的可用性（用临时数组）；
- BIT 在合并后要**清空**（按本次插入的点逐个减掉），否则污染下一层；
- 整体二分中，询问的 $k$ 要减去「左档贡献的数量」再递归右档；
- 三维偏序若存在相等坐标，要按题意去重（先按 $(a,b,c)$ 排序去重再计数）。

## 三、形式化与数学基础

**CDQ 主定理式分析**（三维偏序）：

$$T(n) = 2T(n/2) + O(n\log n),$$

解得

$$T(n) = O(n\log^2 n).$$

若合并用 $O(n)$ 归并 + $O(1)$ 维护（例如二维），则 $T(n)=O(n\log n)$。

**整体二分**：

$$T(n,q) = 2T\!\left(\frac{n+q}{2}\right) + O((n+q)\log n),$$

粗略为 $O((n+q)\log V \log n)$；更紧的分析是每个元素走 $\log V$ 层，每层 BIT $O(\log n)$。

**与树套树对比**：树套树在线、单次 $O(\log^2 n)$；CDQ 离线、总 $O(n\log^2 n)$。静态或可离线时 CDQ 常数更小、代码更短；需要强制在线则必须树套树/主席树。

**BIT 核心**：

$$
\mathrm{add}(i,\delta):\ i \mathrel{+}= i\,\&\,(-i); \quad
\mathrm{sum}(i):\ s \mathrel{+}= \mathrm{tree}[i],\ i \mathrel{-}= i\,\&\,(-i).
$$

区间和 $= \mathrm{sum}(r)-\mathrm{sum}(l-1)$。

## 四、代码实现

### 4.1 三维偏序（CDQ + BIT）完整可运行

```python
class BIT:
    def __init__(self, n):
        self.n = n
        self.t = [0] * (n + 1)

    def add(self, i, delta=1):
        i += 1
        while i <= self.n:
            self.t[i] += delta
            i += i & -i

    def sum(self, i):
        # [0, i]，i 可为 -1
        s = 0
        i += 1
        while i > 0:
            s += self.t[i]
            i -= i & -i
        return s

    def range_sum(self, l, r):
        return self.sum(r) - self.sum(l - 1)

    def clear_points(self, idx_list):
        for i in idx_list:
            self.add(i, -1)


def cdq_three_d(points):
    """points: [(a,b,c)]，返回 ans[i] = 满足 j≠i 且 aj<=ai,bj<=bi,cj<=ci 的 j 个数。"""
    n = len(points)
    # 离散化 c
    cs = sorted({p[2] for p in points})
    c_id = {v: i for i, v in enumerate(cs)}
    # 离散化 b 用于归并（比较即可，不必 id）
    items = [(p[0], p[1], c_id[p[2]], i) for i, p in enumerate(points)]
    items.sort(key=lambda x: (x[0], x[1], x[2]))  # 先按 a 排序
    ans = [0] * n
    tmp = [None] * n

    bit = BIT(len(cs))

    def solve(l, r):
        if l >= r:
            return
        mid = (l + r) // 2
        solve(l, mid)
        solve(mid + 1, r)
        # 归并按 b，左半插入 BIT（c），右半查询
        i, j, k = l, mid + 1, l
        inserted = []
        while i <= mid and j <= r:
            if items[i][1] <= items[j][1]:
                bit.add(items[i][2], 1)
                inserted.append(items[i][2])
                tmp[k] = items[i]
                i += 1
            else:
                ans[items[j][3]] += bit.range_sum(0, items[j][2])
                tmp[k] = items[j]
                j += 1
            k += 1
        while i <= mid:
            bit.add(items[i][2], 1)
            inserted.append(items[i][2])
            tmp[k] = items[i]
            i += 1
            k += 1
        while j <= r:
            ans[items[j][3]] += bit.range_sum(0, items[j][2])
            tmp[k] = items[j]
            j += 1
            k += 1
        bit.clear_points(inserted)
        items[l:r + 1] = tmp[l:r + 1]

    solve(0, n - 1)
    return ans
```

### 4.2 陌上花开式：去重后统计「支配点对」并分层

```python
def flowers(points):
    """陌上花开：points (a,b,c)，输出 f[i] = 严格小于等于它的点数（含自己减一的语义按题）。"""
    # 去重
    uniq = sorted(set(points))
    cnt = {}
    for p in points:
        cnt[p] = cnt.get(p, 0) + 1
    us = list(uniq)
    base = cdq_three_d(us)
    # base[i] = 自身不算的 ≤ 点数（因 j≠i，相等坐标在去重后不会互计）
    out = [0] * len(points)
    # 简化：返回去重后的支配数 + 自身重复
    result = []
    for i, p in enumerate(us):
        result.append(base[i] + cnt[p] - 1)
    return result


# ---------- 整体二分：静态区间第 k 小 ----------
def parallel_kth(nums, queries):
    """queries: (l, r, k) 1-based k，返回区间第 k 小。"""
    n = len(nums)
    # 离散化
    vals = sorted(set(nums))
    vid = {v: i for i, v in enumerate(vals)}
    arr = [vid[v] for v in nums]

    # 事件: ('Q', id, l, r, k) 或 ('A', pos, val) 修改（静态即全预插入）
    # 静态第 k 小：整体二分值域 [0, len(vals)-1]
    ans = [0] * len(queries)
    # 为简单起见，用 BIT 每次二分暴力统计（演示正确性，复杂度 O(q log V (n log n))）
    # 更标准写法是把修改与询问一起整体二分，见下文说明
    bit = BIT(n)

    def count_le(l, r, mid):
        # nums[l..r] 中值 id <= mid 的个数
        bit = BIT(n)
        for i in range(l, r + 1):
            if arr[i] <= mid:
                bit.add(i, 1)
        return bit.range_sum(l, r)

    for qi, (l, r, k) in enumerate(queries):
        lo, hi = 0, len(vals) - 1
        while lo < hi:
            mid = (lo + hi) // 2
            c = count_le(l, r, mid)
            if c >= k:
                hi = mid
            else:
                lo = mid + 1
        ans[qi] = vals[lo]
    return ans


if __name__ == "__main__":
    # 三维偏序对拍
    pts = [(1, 1, 1), (2, 2, 2), (1, 2, 3), (3, 3, 3), (1, 1, 2)]
    got = cdq_three_d(pts)
    # 期望：对每个点数 (a,b,c) <= 的点（含自己）再减 1
    brute = []
    for i, (a, b, c) in enumerate(pts):
        t = sum(1 for j, (x, y, z) in enumerate(pts)
                if x <= a and y <= b and z <= c)
        brute.append(t - 1)
    assert got == brute

    # 花朵
    fp = [(1, 1, 1), (1, 1, 2), (1, 1, 1), (2, 2, 2)]
    assert flowers(fp) == [2, 3, 3]  # 三个唯一点的支配数

    # 区间第 k 小
    nums = [5, 1, 3, 2, 4]
    qs = [(0, 4, 1), (0, 4, 3), (1, 3, 2), (2, 4, 2)]
    assert parallel_kth(nums, qs) == [1, 3, 2, 3]
    print("cdq / parallel binary search ok")
```

说明：上面 `parallel_kth` 为清晰起见用「每询问二分 + 区间计数」展示语义；标准整体二分把所有询问与修改一起按值域分治，总复杂度 $O((n+q)\log n\log V)$。CDQ 三维偏序部分是完整 $O(n\log^2 n)$ 实现。

## 五、与其他技术对比

| 维度 | CDQ 分治 | 整体二分 | 树套树 | 主席树（可持久化） | 莫队 |
|------|----------|----------|--------|---------------------|------|
| 在线 | 否 | 否 | 是 | 是 | 否 |
| 典型复杂度 | $O(n\log^2 n)$ | $O(n\log n\log V)$ | $O(\log^2 n)$/次 | $O(\log n)$/次 | $O(n\sqrt n)$ |
| 实现难度 | 中 | 中 | 高 | 中高 | 低 |
| 适用 | 三维偏序、动态逆序对 | 第 $k$ 小、带权中位数 | 在线二维 | 静态历史第 $k$ | 区间可转移 |
| 常数 | 小 | 小 | 大 | 中 | 中 |

**取舍**：可离线且偏序/时间维明显 → CDQ；第 $k$ 类带修改 → 整体二分；强制在线 → 树套树/主席树；区间统计可转移 → 莫队。竞赛中 CDQ 是「降维打击」的首选武器之一。

## 六、常见误区

**误区一：CDQ 合并时左右顺序搞反。** 必须保证左半（时间早）先贡献右半；写成右改左查就漏计。

**误区二：BIT 用完不清理。** 跨越递归层会把上一次的点算进下一层，答案翻倍或错乱。要按插入列表减回 0。

**误区三：三维偏序不去重。** 坐标完全相同的点需要按题意合并或去重后再计数，否则重复贡献。

**误区四：整体二分忘记调整 $k$。** 递归右档时 $k$ 要减去左档已统计的数量，否则答案偏大/偏小。

**误区五：把 CDQ 当通用在线结构。** 一旦询问依赖之前回答（自适应），分治的前提崩溃，必须换在线结构。

## 八、面试题

**Q1：三维偏序如何做？**
A：按一维排序，CDQ 分治下标，合并时按第二维归并、第三维 BIT 计数。$O(n\log^2 n)$。

**Q2：CDQ 分治的时间复杂度怎么算？**
A：$T(n)=2T(n/2)+O(n\log n)=O(n\log^2 n)$；若合并 $O(n)$ 则 $O(n\log n)$。

**Q3：整体二分和主席树怎么选？**
A：离线批量第 $k$ 小用整体二分，代码短、常数小；要在线或历史版本用主席树。

**Q4：CDQ 分治能处理删除吗？**
A：能，把删除看作负贡献（添加 +1、删除 -1），BIT 做差分；前提是离线且时间序清晰。

## 九、演进与趋势

**CDQ + 李超树**、**CDQ + 平衡树**扩到更高维；**整体二分 + 可撤销 DSU** 处理动态连通性第 $k$ 时刻；**树分治（点分治）**是「分治离线」在树上的近亲。工程里批量数点、数据立方体预聚合、审计日志区间统计都能套扫描/CDQ 模式。面试趋势是「会不会识别维度与时间、能否写出 BIT 归并、复杂度对不对」三连问。

## 十、小结

CDQ 分治与整体二分代表「分治离线」的两种经典形态：前者按时间/一维分治、左改右查降维，后者按答案值域二分、批处理判定。它们把树套树的在线压力换成离线分治的简洁与常数优势，是三维偏序、动态逆序对、第 $k$ 小等高级问题的标准武器。核心纪律是：贡献顺序正确、BIT 及时清空、递归边界清晰。
