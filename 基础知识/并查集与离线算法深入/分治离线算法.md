# 分治离线算法

> 对应 CDQ 分治（陈丹琦 2008）与相关离线分治文献。

## 一、背景与挑战
处理「修改 + 查询」类高维问题（如三维偏序），在线困难。CDQ 分治把时间维二分，用左半修改贡献右半查询。

## 二、核心原理
按时间（或某一维）二分；递归处理左右；合并时用左半的修改更新右半的查询，常降一维后套用排序/树状数组。

## 三、形式化 / 数学基础
三维偏序 (a,b,c)：按 a 分治，左右按 b 排序，用树状数组按 c 统计。总复杂度 $O(n\log^2 n)$。

## 四、代码实现
```python
def cdq_three_d(a):
    # a: list of (a,b,c) with id and type
    import bisect
    def solve(lo, hi):
        if lo == hi:
            return
        mid = (lo + hi) // 2
        solve(lo, mid)
        solve(mid + 1, hi)
        # 按 b 归并，左半对右半在 c 维计数
        left = sorted(a[lo:mid+1], key=lambda x: x[1])
        right = sorted(a[mid+1:hi+1], key=lambda x: x[1])
        bit = [0] * (max(x[2] for x in a) + 2)
        i = 0
        for r in right:
            while i < len(left) and left[i][1] <= r[1]:
                # add left[i] at c
                i += 1
            # 统计 c <= r[2]
    solve(0, len(a) - 1)
```

## 五、与其他技术对比
与树套树（O(n log^2 n) 但常数大）相比，CDQ 代码简单、空间小；与离线 BIT 相比，能处理更高维。

## 六、常见误区
归并时左/右边界混淆；BIT 维度未离散化导致越界；分治后未保持原顺序。

## 九、演进与趋势
整体二分（parallel binary search）处理带答案二分的离线；CDQ + 李超树。

## 十、小结
分治离线（CDQ/整体二分）用「左改右查」思想把高维在线问题降维，是高级离线的核心技术。
