# 寻址模式与指令编码

> 对应 Aho 等《Compilers》第 8 章；Appel《Modern Compiler Implementation》第 8 章。

## 一、背景与挑战
不同 ISA 支持的寻址模式（立即、寄存器、基址+位移、缩放索引）差异巨大，直接决定可生成的指令形态与二进制编码密度。

## 二、核心原理
后端把抽象内存访问 lowering 为具体寻址模式。x86 允许 `[base+index*scale+disp]`，RISC-V 仅基址+立即。编码器据操作数类型与寄存器字段把指令模板填为机器码，处理 ModRM、SIB、重定位。

## 三、形式化与数学基础
有效地址计算：
$$EA = base + index \times scale + displacement$$
编码位域：
$$inst = opcode \ll 32 | modrm \ll 24 | reg \ll 21 | rm \ll 18 | imm$$
具体布局随 ISA 严格定义。

## 四、代码实现
```c
// 编码 add rax, [rbx+8]
emit(0x48);                 // REX.W
emit(0x03);                 // ADD r/m64, r64
emit(0x43);                 // ModRM: mod=01 reg=000 rm=011 (+disp8)
emit(0x08);                 // disp8 = 8
```

## 五、与其他技术对比
CISC 丰富寻址减少指令数但解码复杂；RISC 规整编码利于流水线但需多指令合成复杂地址。

## 六、常见误区
1. 误用 32 位寻址模式访问 64 位地址。
2. 位移溢出（x86 仅 8/32 位 disp）需重Materialization。
3. 忘记 REX 前缀导致寄存器不可编码。

## 七、与开源书/权威来源对应
Appel ch8 指令编码；龙书 ch8；Intel/AMD 手册；RISC-V 规范。

## 八、面试题
问：x86 与 RISC-V 寻址差异？REX 前缀作用？ModRM 含义？

## 九、演进与趋势
可变长编码（x86）持续加压解码器；RISC-V 压缩指令（C 扩展）提升密度。

## 十、小结
寻址模式决定指令表达力，编码器把抽象访问固化为严格位域机器码。
