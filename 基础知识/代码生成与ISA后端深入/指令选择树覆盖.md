# 指令选择树覆盖

> 对应 Aho, Sethi & Ullman《Compilers: Principles, Techniques, and Tools》第 8 章（代码生成）。

## 一、背景与挑战
IR 表达式需映射到目标指令，一条 CISC 指令常等价多步 RTL。如何以最少、最快指令覆盖 IR 树，是指令选择核心。

## 二、核心原理
把 IR 表示为树，目标指令建模为带代价的树片段（tile）。动态规划在树上做最优覆盖：每个节点计算被各 tile 覆盖的最小代价，自底向上选全局最优瓦片集合。复杂寻址模式（如 x86 的 [base+idx*scale+disp]）作为大 tile 减少指令数。

## 三、形式化与数学基础
节点 $n$ 的最小代价：
$$C(n) = \min_{tile\ t\ covers\ n} \left( cost(t) + \sum_{c\in children(t)} C(c) \right)$$
覆盖为瓦片根集合，使总代价最小。

## 四、代码实现
```python
def label(n):
    n.cost = INF
    for tile in tiles_covering(n.op):
        c = tile.cost + sum(label(c) for c in tile.children)
        if c < n.cost: n.cost, n.tile = c, tile
    return n.cost
```

## 五、与其他技术对比
树覆盖适合表达式；DAG 覆盖处理公共子表达式更优；PEG/规则重写（如 LLVM 的 DAG 选择）更灵活但难证最优。

## 六、常见误区
1. 贪心选最大 tile 未必全局最优。
2. 忽略 tile 代价差异（某些 CISC 指令慢于多条 RISC）。
3. 漏掉约束（寄存器类）导致覆盖不可分配。

## 九、演进与趋势
MLIR 用声明式重写规则；全局指令选择（GISel）在更粗粒度并行降低编译时延。

## 十、小结
指令选择是带代价的最优树覆盖，把 IR 映射到最少目标指令集合。
