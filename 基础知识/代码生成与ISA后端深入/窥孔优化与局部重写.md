# 窥孔优化与局部重写

> 对应 Aho 等《Compilers》第 8 章；Appel《Modern Compiler Implementation》第 8 章。

## 一、背景与挑战
即便前面各阶段优化后，相邻指令仍常残留冗余：连续 load 同地址、乘 2 可改移位、jump 到 jump。需局部小窗口规则消去。

## 二、核心原理
窥孔优化在滑动窗口（数条相邻指令）上应用等价重写规则：消去死 store、合并常量、跳转链折叠（jmp L1; L1: jmp L2 -> jmp L2）、代数化简（x+0->x）。可多趟迭代直至不动点。

## 三、形式化与数学基础
重写系统对指令序列 $s$ 应用规则 $r: pattern \to replacement$ 保持语义：
$$\forall s.\ sem(s) = sem(apply(r,s))$$
不动点 $s^* = fixpoint(\{r_i\})(s_0)$，且 $|s^*| \le |s_0|$。

## 四、代码实现
```python
def peephole(insns):
    changed = True
    while changed:
        changed = False
        for i in range(len(insns)-1):
            if (insns[i].op == 'add' and insns[i].imm == 0):
                del insns[i]; changed = True
            elif (insns[i].op == 'jmp' and
                  insns[i+1].label == insns[i].target):
                insns[i].target = insns[i+1].target; changed = True
```

## 五、与其他技术对比
窥孔是局部、廉价的收尾优化；全局 CSE/DCE 处理跨块，二者互补，常在代码发射前做最后清理。

## 六、常见误区
1. 规则不保持语义（如忽略标志位副作用）致错误。
2. 单趟不够，需迭代至不动点。
3. 在含有不可达假设处折叠破坏异常语义。

## 七、与开源书/权威来源对应

## 九、演进与趋势

## 十、小结
窥孔优化以小窗口等价重写做最后打磨，稳健地消除邻近冗余指令。
