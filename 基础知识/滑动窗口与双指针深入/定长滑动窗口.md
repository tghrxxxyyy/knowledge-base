# 定长滑动窗口

> 对应 youngyangyang04/leetcode-master 滑动窗口（固定长度）与 CyC2018/CS-Notes 题解；同主题可见 Sedgewick《Algorithms》中固定尺寸子数组扫描。

## 一、背景与挑战

定长滑动窗口处理的是"窗口大小固定为 $k$"的问题：每个长度为 $k$ 的连续子数组的和、最大值、不同元素个数、是否为某个排列的字母异位词等。它比可变长窗口简单，却在面试与工程里出现频率极高——统计最近 $k$ 天的活跃、滑动平均、子串模式匹配、图像上的固定核卷积、限流里的"最近 60 秒计数"，本质都是同一个模式。

朴素做法对每个起点 $i$ 都重新聚合 $a[i..i+k-1]$，单次 $O(k)$，共 $n-k+1$ 个窗口，总 $O(nk)$；当 $k$ 与 $n$ 同阶时退化为 $O(n^2)$。前缀和可以把"和"类查询压到 $O(1)$，但对于"不同元素个数""最大值""是否为异位词"这类聚合，前缀和并不直接适用，仍需增量维护。

定长窗口的关键洞察是**相邻窗口只差一个元素**：窗口右移一格，旧的左端元素离开、新的右端元素加入，其余 $k-1$ 个不变。因此聚合可以 $O(1)$（或均摊 $O(1)$）增量更新，整体 $O(n)$。这比可变长窗口更机械：不需要判断合法性、不需要内层 while，循环边界清晰，是理解滑窗思想的最佳入口。

工程中的对应场景很多：监控里"最近 N 个点的均值/峰值"、风控里"最近 N 次请求的失败率"、音频处理的滑动 RMS、卷积核的滑动计算。面试中它常作为简单/中等题出现（如 643 子数组最大平均、438 找所有字母异位词），但若能主动谈到"与前缀和、与单调队列的取舍"，会显得扎实。

## 二、核心原理

固定窗口 $W_i = a[i..i+k-1]$（$0$-based，$i = 0..n-k$），相邻窗口满足

$$W_{i+1} = W_i \setminus \{a[i]\} \cup \{a[i+k]\}$$

于是维护一个聚合量 $f_i = g(W_i)$，更新为

$$f_{i+1} = f_i \ominus a[i] \oplus a[i+k]$$

其中 $\oplus$ 是"纳入新元素"，$\ominus$ 是"撤销旧元素"。对求和，$f_{i+1} = f_i - a[i] + a[i+k]$；对频率表，删 `a[i]` 一次、加 `a[i+k]` 一次；对计数类条件（如"是否为异位词"），维护差值表或 `valid` 计数。

**不变量**：处理完第 $i$ 步后，$f$ 恰好等于 $W_i$ 的真实聚合，窗口下标区间为 $[i, i+k-1]$。初始化用 $W_0$ 完整计算一遍（$O(k)$），之后每步 $O(1)$ 增量。

**边界条件**：
- $k \le 0$ 或 $k > n$ 时无有效窗口，返回空/0，必须先检查；
- 初始化 `cur = sum(arr[:k])` 时确认 `arr` 长度；
- 窗口左端为 $i$、右端为 $i+k-1$，右端移出的是 `arr[i]`（当处理窗口 $i \to i+1$），差一错误常见于把移出元素写成 `arr[i+1]` 或 `arr[i-k]`（0-based 循环里应是 `arr[i]` 与 `arr[i+k]`，或等价的 `arr[i-k]` 与 `arr[i]` 若右端为 `i`）；
- 答案数组长度应为 $n-k+1$。

**与可变长窗口的区别**：定长没有"合法/非法"判断与 while 收缩，只有固定的进一出一；复杂度严格 $O(n)$，无需单调性论证。可变长是它的推广，多出"合法性谓词 + 左缩"这一层。也因此，定长窗口几乎不会写错"收缩条件"，翻车点集中在下标差一与初始化越界这两处，属于"细心就能全对"的题型。

**窗口语义的两种常见约定**：一种把 $i$ 当左端，循环范围 $0 \le i \le n-k$，右端是 $i+k-1$，移出 `arr[i]`、移入 `arr[i+k]`；另一种把 $i$ 当右端，循环从 $k-1$ 起，移出 `arr[i-k]`、移入 `arr[i]`。两种都对，但混用必错。团队代码里建议在函数注释里写死一种，例如"下标 $i$ 表示窗口右端"，并用 $k=1$、$k=n$ 两个极端用例守住边界。

**与前缀和的分工**：和类聚合，前缀和 $O(1)$ 查询更直接、且支持任意区间；定长窗口的优势在于统一处理频率、最值、模式匹配等"非可减"聚合，且代码模式固定、易扩展。若问题既要定长窗口又要随机区间查询，可以两者并存：前缀和服务查询，滑窗服务"每个窗口"的序列输出。

## 三、形式化与数学基础

窗口集合 $\{W_i\}_{i=0}^{n-k}$，$W_i = (a_i, a_{i+1}, \ldots, a_{i+k-1})$。

求和聚合：

$$S_i = \sum_{t=0}^{k-1} a_{i+t}$$

递推：

$$S_0 = \sum_{t=0}^{k-1} a_t, \quad S_{i} = S_{i-1} - a_{i-1} + a_{i+k-1} \quad (i \ge 1)$$

由线性性直接验证：

$$S_{i-1} - a_{i-1} + a_{i+k-1} = \sum_{t=0}^{k-1} a_{i-1+t} - a_{i-1} + a_{i+k-1} = \sum_{t=1}^{k-1} a_{i-1+t} + a_{i+k-1} = \sum_{t=0}^{k-1} a_{i+t} = S_i$$

复杂度：初始化 $\Theta(k)$，递推 $\Theta(n-k)$，总 $\Theta(n)$；空间 $\Theta(1)$（和）或 $\Theta(\sigma)$（频率表）。

频率向量版本：记 $c_i[x] = \#\{t : a_{i+t} = x\}$，则

$$c_i[x] = c_{i-1}[x] - [a_{i-1}=x] + [a_{i+k-1}=x]$$

每次更新 $O(1)$。若聚合是"$c$ 中键的个数"（不同元素数），删到 0 时移除键，否则键数会虚高——这是实现细节里的关键不变量。

最大值聚合：$f_i = \max(W_i)$ 不能由 $f_{i-1}$ 与两端点常数时间撤销（max 无逆元），需单调队列：

$$\text{deque 存下标，队首即窗口最大，出队过期下标、弹出被新元素压死的候选}$$

均摊 $O(1)$ 每步，总 $O(n)$，见《单调性与窗口收缩策略》。

滑动平均 $\mu_i = S_i / k$，只是和的线性变换，复杂度相同。

## 四、代码实现

定长窗口求和 / 最大平均（LeetCode 643）：

```python
def max_average_subarray(nums, k):
    n = len(nums)
    if k <= 0 or k > n:
        raise ValueError("invalid k")
    cur = sum(nums[:k])
    best = cur
    for i in range(k, n):
        cur += nums[i] - nums[i - k]   # 进右出左
        best = max(best, cur)
    return best / k


if __name__ == "__main__":
    assert abs(max_average_subarray([1, 12, -5, -6, 50, 3], 4) - 12.75) < 1e-9
    assert abs(max_average_subarray([5], 1) - 5.0) < 1e-9
```

定长窗口 + 频率表：每个窗口的不同元素个数：

```python
def distinct_counts(arr, k):
    from collections import Counter
    n = len(arr)
    if k <= 0 or k > n:
        return []
    freq = Counter(arr[:k])
    res = [len(freq)]
    for i in range(k, n):
        out, inn = arr[i - k], arr[i]
        freq[out] -= 1
        if freq[out] == 0:
            del freq[out]
        freq[inn] += 1
        res.append(len(freq))
    return res


assert distinct_counts([1, 2, 1, 3, 3], 2) == [2, 2, 2, 1]
```

字母异位词检测（LeetCode 438，定长 + 差值计数）：

```python
def find_anagrams(s, p):
    from collections import Counter
    n, k = len(s), len(p)
    if k > n:
        return []
    need, window = Counter(p), Counter()
    res = []
    for i, ch in enumerate(s):
        window[ch] += 1
        if i >= k:
            out = s[i - k]
            window[out] -= 1
            if window[out] == 0:
                del window[out]
        if window == need:
            res.append(i - k + 1)
    return res


assert find_anagrams("cbaebabacd", "abc") == [0, 6]
assert find_anagrams("abab", "ab") == [0, 1, 2]
```

## 五、与其他技术对比

| 方法 | 时间 | 空间 | 能处理的聚合 |
|------|------|------|----------------|
| 朴素每窗重算 | $O(nk)$ | $O(1)$ | 任意 |
| 前缀和 | $O(n)$ 建 / $O(1)$ 查 | $O(n)$ | 可减（和、异或、计数） |
| 定长滑窗（增量） | $O(n)$ | $O(1)$~$O(\sigma)$ | 可增量撤销（和、频率、异位词） |
| 单调队列定长窗 | $O(n)$ | $O(k)$ | max/min |
| 卷积 / FFT | $O(n\log n)$ | $O(n)$ | 多窗口加权和、任意核 |

取舍：只要和/可减聚合且要任意区间 → 前缀和；固定 $k$ 且聚合可增量 → 定长滑窗；窗口最值 → 单调队列；加权核/大量不同核 → FFT。面试里写定长滑窗通常比前缀和更稳，因为它不用处理下标偏移的通用查询。

## 六、常见误区

1. **初始化越界**。`k > n` 或 `k == 0` 未检查，`arr[:k]` 得到短窗口，后续 `arr[i-k]` 越界。后果：崩溃或错误答案。对策：先校验 $1 \le k \le n$，并约定返回值（空列表/0/异常）。
2. **进出元素下标差一**。0-based 循环里 `i` 表示右端时，移出的是 `arr[i-k]`；若写成 `arr[i-k+1]` 或 `arr[i-1]`，频率会漂。后果：从第二个窗口起全错。对策：用 $i$ 为右端的约定并写注释，单测覆盖 $k=1$ 与 $k=n$。
3. **频率表删到 0 未移除键**。`len(freq)` 当不同元素数时会把计数 0 的键算进去。后果：不同元素数偏大。对策：`del freq[x]` 或改用"种类计数器" `num_distinct` 显式维护。
4. **用 `==` 直接比较浮点平均**。判题或业务里浮点相等不可靠。后果：偶发误判。对策：比较和/计数，或容差比较。
5. **把定长模板套到可变长问题**。例如"和不超过 k 的最长子数组"用定长写法只枚举固定 $k$，逻辑错误。后果：漏解。对策：题目出现"最长/最短/所有满足条件"通常可变长；出现"每个长度为 k 的"才是定长。

## 八、面试题

**1. 定长窗口的增量更新公式？**
参考答案：$S_i = S_{i-1} - a_{i-k} + a_i$（$i$ 为右端）。频率表则对移出键减一、移入键加一，删零键。整体 $O(n)$。

**2. 如何求每个窗口的不同元素个数？**
参考答案：频率表 + `del` 零键，答案取 `len(freq)`；或维护 `distinct` 计数，移出时减到 0 就 `distinct--`。$O(n)$ 时间。

**3. 定长窗口求最大值为什么不能直接增量？**
参考答案：max 无逆元，不能由上一窗口最大撤销左端得到（最大可能恰是移出元素）。需单调队列：队首存当前窗口最大候选下标，过期弹出、被压死的候选弹出，均摊 $O(1)$。

**4. 定长窗口与前缀和如何选择？**
参考答案：和/异或/计数等可减聚合且要任意区间查询，用前缀和；固定 $k$ 的频率、模式匹配、非可减但可增量撤销的聚合，用定长滑窗；窗口最值用单调队列。

## 九、演进与趋势

- **单调队列**：把定长窗口最大值（LeetCode 239）做成线性，是"定长滑窗 + 单调结构"的代表。
- **滚动哈希**：固定长度子串匹配用多项式哈希滚动，$O(1)$ 进出，与定长滑窗同构；Rabin-Karp 即典型。
- **流式窗口聚合**：Flink/Spark 的 tumbling/sliding window、Prometheus 的 rate，底层都是定长窗口的增量维护，只是时间维度驱动边界。
- **信号处理**：滑动平均、滑动 RMS、卷积核滑动，是定长窗口的连续化版本；SIMD/GPU 可向量化。
- **与限流/风控结合**：固定时间窗计数（滑动窗口限流）比固定计数器更平滑，工程上常用"分片计数 + 窗口滑动"近似。

## 十、小结

定长滑动窗口利用"相邻窗口只差一进一出"做增量聚合：初始化 $O(k)$，之后每步 $O(1)$，总 $O(n)$。和类用加减、频率类用计数表（记得删零键）、最值用单调队列。先校验 $k$ 的范围，再选对移出/移入下标，就能稳稳拿下这一类题。
