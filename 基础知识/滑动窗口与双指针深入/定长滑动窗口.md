# 定长滑动窗口

> 对应 youngyangyang04/leetcode-master 滑动窗口（固定长度）与 CyC2018/CS-Notes 题解。

## 一、背景与挑战
求每个长度为 $k$ 的连续子数组的某种聚合（最大/和/不同元素数）。定长窗口每次移动只增减一个元素。

## 二、核心原理
右指针逐格右移，左指针同步右移，窗口大小恒为 $k$。维护一个随滑动更新的量（如和、频率表）。

## 三、形式化与数学基础
窗口 $[i-k+1, i]$，聚合 $f(i)=g(\text{window})$。增量更新：$f(i)=f(i-1)-a_{i-k}+a_i$，期望 $O(1)$ 每步。

## 四、代码实现
```python
def max_sliding_sum(arr, k):
    if k <= 0 or k > len(arr):
        return []
    cur = sum(arr[:k])
    res = [cur]
    for i in range(k, len(arr)):
        cur += arr[i] - arr[i - k]
        res.append(cur)
    return res
```

## 五、与其他技术对比
前缀和也能 $O(1)$ 取定长区间和；但定长窗口写法更直观，且易扩展到需要频率表的场景。

## 六、常见误区
- 初始化 `cur` 用 `sum(arr[:k])` 时越界未检查。
- 窗口边界差一错误（应为 `i-k` 而非 `i-k+1`）。

## 十、小结
