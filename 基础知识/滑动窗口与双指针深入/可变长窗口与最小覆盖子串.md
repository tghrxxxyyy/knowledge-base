# 可变长窗口与最小覆盖子串

> 对应 youngyangyang04/leetcode-master 滑动窗口（最小覆盖子串）与 CyC2018/CS-Notes。

## 一、背景与挑战
在字符串 $s$ 中找包含 $t$ 所有字符的最短子串。窗口长度不定，需同时维护"已覆盖"与"还差多少"。

## 二、核心原理
用需求计数 `need` 与目标计数 `window`。右扩直到 `window` 满足 `need`；记录并用左缩尝试更短；满足时持续收缩更新答案。

## 三、形式化与数学基础
设 `valid` 为已满足需求的字符种类数。当 `valid == len(need)` 时窗口合法。目标是 $\min (R-L+1)$ 使合法。

## 四、代码实现
```python
from collections import Counter

def min_window(s, t):
    need = Counter(t)
    window = {}
    valid = 0
    L = 0
    start = 0
    min_len = float('inf')
    for R, ch in enumerate(s):
        window[ch] = window.get(ch, 0) + 1
        if ch in need and window[ch] == need[ch]:
            valid += 1
        while valid == len(need):
            if R - L + 1 < min_len:
                min_len, start = R - L + 1, L
            out = s[L]
            if out in need and window[out] == need[out]:
                valid -= 1
            window[out] -= 1
            L += 1
    return '' if min_len == float('inf') else s[start:start + min_len]
```

## 五、与其他技术对比
暴力枚举起点终点 $O(|s|^2)$；滑动窗口 $O(|s|+|t|)$。二分答案+检查也可行但常数更大。

## 六、常见误区
- 收缩时先移动 L 再更新计数，导致 `valid` 判断错位。
- 只判断字符出现未判断数量（需 `window==need` 计数）。
