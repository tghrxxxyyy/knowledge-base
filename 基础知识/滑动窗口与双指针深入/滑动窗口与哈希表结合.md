# 滑动窗口与哈希表结合

> 对应 youngyangyang04/leetcode-master 滑动窗口（含哈希）与 CyC2018/CS-Notes 题解。

## 一、背景与挑战
当窗口条件涉及"不同元素种类数""某字符最多出现 k 次"等，需实时维护频率表，单靠数值累加不够。

## 二、核心原理
用 `Counter`/`dict` 维护窗口内元素频率，配合 `valid`（满足条件的键数）判断合法性，左右指针移动时增量更新表。

## 三、形式化与数学基础
窗口频率向量 $f\in\mathbb{N}^m$。条件多为对 $f$ 的线性/计数约束，增量更新 $f$ 为 $O(1)$，整体 $O(n)$。

## 四、代码实现
```python
def length_of_longest_substring(s):
    freq = {}
    L = 0
    best = 0
    for R, ch in enumerate(s):
        freq[ch] = freq.get(ch, 0) + 1
        while freq[ch] > 1:           # 出现重复则收缩
            freq[s[L]] -= 1
            L += 1
        best = max(best, R - L + 1)
    return best
```

## 五、与其他技术对比
暴力判重 $O(n^2)$；哈希表窗口 $O(n)$ 且易扩展到"至多 k 个不同字符"等变体。

## 六、常见误区
- 收缩时只移 L 不更新 freq，导致计数失真。
- 用 `set` 而非 `freq` 无法处理"最多出现 k 次"类条件。

## 七、与开源书/权威来源对应

- CS-Notes 滑动窗口题解。

## 九、演进与趋势
频率表窗口与计数树（有序统计）结合可处理动态秩条件。

## 十、小结
哈希频率表让滑动窗口能表达"种类/次数"类约束，是中等题主力。
