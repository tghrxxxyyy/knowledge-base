# 单调性与窗口收缩策略

> 对应 youngyangyang04/leetcode-master 滑动窗口进阶与单调队列/栈专题。

## 一、背景与挑战
当窗口合法性随左右指针单调变化时，收缩策略可确定化；若条件非单调（如"子数组乘积小于 k"），需谨慎处理。

## 二、核心原理
若窗口增大必使条件更难满足（如和超界、种类超界），则 L 单调右移；若增大使条件更易满足，则换用不同策略（如固定 L 找最远 R）。

## 三、形式化与数学基础
设谓词 $P(L,R)$。若 $\forall R'\ge R,\ P(L,R')\Rightarrow P(L,R)$（R 单调易满足），则枚举 R 时 L 不必回退。

## 四、代码实现
```python
def num_subarray_product_less_than_k(nums, k):
    if k <= 1:
        return 0
    L = 0
    prod = 1
    count = 0
    for R in range(len(nums)):
        prod *= nums[R]
        while prod >= k:        # 乘积随 R 增只更大，可单调收缩
            prod /= nums[L]
            L += 1
        count += R - L + 1       # 以 R 结尾的合法窗口数
    return count
```

## 五、与其他技术对比
非单调条件（如中位数约束）无法直接滑动窗口，需平衡树/双堆维护。

## 六、常见误区
- 把乘积当和一样处理（乘积下溢/整数除法误差，用浮点或对数转换）。
- 误用 `>=` 与 `>` 导致漏计。
