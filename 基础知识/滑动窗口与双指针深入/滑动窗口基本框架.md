# 滑动窗口基本框架

> 对应 youngyangyang04/leetcode-master 滑动窗口章节与 CyC2018/CS-Notes 双指针/滑动窗口题解。

## 一、背景与挑战
在数组/字符串上求"满足某条件的连续子段"，暴力枚举两端为 $O(n^2)$。滑动窗口利用单调性降到 $O(n)$。

## 二、核心原理
维护左右指针 $[L,R]$，右移 $R$ 扩大窗口，当不满足条件时右移 $L$ 收缩，使窗口始终合法。每个元素进出各一次。

## 三、形式化与数学基础
若窗口的"合法性"随 $R$ 增而难满足、随 $L$ 增而更易满足（单调），则 $L$ 不会回退，总移动 $O(n)$。

## 四、代码实现
```python
def longest_valid_window(arr, max_sum):
    L = 0
    cur = 0
    best = 0
    for R in range(len(arr)):
        cur += arr[R]
        while cur > max_sum:      # 不合法则收缩
            cur -= arr[L]
            L += 1
        best = max(best, R - L + 1)
    return best
```

## 五、与其他技术对比
前缀和能在 $O(1)$ 求区间和但难处理"含特定字符种类数"等条件；滑动窗口直接维护计数更灵活。

## 六、常见误区
- 收缩条件写反（应在"不合法"时收缩，而非"合法"时）。
- 忘记更新 `best` 的时机（应在合法时）。

## 十、小结
滑动窗口 = 右扩左缩 + 单调性，核心是"合法时记录、非法时收缩"。
