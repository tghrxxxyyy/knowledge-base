# 超标量发射与调度

> 对应 Hennessy & Patterson 量化方法超标量处理器章。

## 一、背景与挑战
单发射每周期取指一条，IPC 上限为 1。超标量每周期发射多条指令，需解决"哪些指令就绪、可并行发射"的问题，核心在调度（dispatch/issue/schedule）。

## 二、核心原理
取指后指令经译码、寄存器重命名、分发到保留站/发射队列，由调度器按就绪情况每周期选多条发射到不同功能单元。按调度时机分顺序发射（in-order issue）与乱序完成（out-of-order completion）。

## 三、形式化与数学基础
理想 IPC 受数据相关与资源约束：
$$IPC \le \min(W, \frac{ILP_{avail}}{1 + DepStall})$$
其中 $W$ 为发射宽度， $ILP_{avail}$ 为指令级并行度。关键路径长度决定下限。

## 四、代码实现
```c
// 每周期从就绪队列选最多W条发射
int schedule(inst_t *queue, int n, int W) {
    int issued = 0;
    for (int i=0; i<n && issued<W; i++) {
        if (queue[i].ready && !queue[i].busy) {
            dispatch(queue[i]); issued++;
        }
    }
    return issued; // 本周期发射数
}
```

## 五、与其他技术对比
顺序发射简单但易因长延迟指令阻塞后续；乱序调度（Tomasulo）填充分支间隙、提升 ILP，但硬件复杂。VLIW 把调度交给编译器。

## 六、常见误区
误以为宽发射直接高 IPC：受 ILP 与前端供给限制。误以为乱序=无序执行：仍按依赖图有序推进。

## 七、与开源书/权威来源对应
量化方法超标量；CSAPP 第4章 Y86 多发射思路；mit-pdos/6.824 无直接但并发相关。

## 八、面试题
问：发射宽度 vs 重命名宽度 vs 提交宽度差异？答：三者可不同，分别受取指/重命名/ROB 约束。

## 九、演进与趋势
宽发射（4-8 宽）配合 SMT、大 ROB，转向面积/功耗受约束的设计。

## 十、小结
发射与调度是超标量发挥 ILP 的核心，乱序调度通过动态相关性解析接近理想并行度。
