# 寄存器重命名原理

> 对应 Hennessy & Patterson 量化方法寄存器重命名章。

## 一、背景与挑战
程序二进制中的有限架构寄存器（如 x86 的 16 个）造成伪相关（WAW/WAR），限制 ILP。重命名把架构寄存器映射到更大的物理寄存器堆，消除伪相关。

## 二、核心原理
维护架构寄存器文件（ARF）到物理寄存器（PRF）的映射表。每条写指令分配新物理寄存器，读指令绑定当前映射。提交时更新 ARF 映射；回滚时恢复映射（checkpoint）。

## 三、形式化与数学基础
设物理寄存器数 $P$，架构寄存器数 $A$。可消除的伪相关上界：
$$Independent = \min(P - A, ROB_{size})$$
当 $P$ 足够大，WAW/WAR 不再阻塞，仅 RAW（真相关）约束并行。

## 四、代码实现
```c
// 重命名映射表与自由表
int map[32];        // 架构->物理
int free_list[128]; int fp;
int alloc_phys() { return free_list[--fp]; }     // 取空闲
void rename(int dst_arch, int *new_p) {
    *new_p = alloc_phys();
    // 写目标映射延后到提交, 此处仅分配
}
void commit(int dst_arch, int phys) {
    free_list[fp++] = map[dst_arch]; // 旧物理回收
    map[dst_arch] = phys;            // 新映射生效
}
```

## 五、与其他技术对比
相比 Tomasulo 的 RS 内嵌存储，物理寄存器堆（PRF）集中存储、省面积。两种实现（RS-based vs PRF-based）均流行。

## 六、常见误区
误以为重命名消除所有相关：仅伪相关，RAW 真相关仍在。误以为架构寄存器数决定并行度。

## 七、与开源书/权威来源对应
量化方法寄存器重命名；CSAPP 寄存器分配类比（编译期）。

## 八、面试题
问：WAW 与 WAR 为何是伪相关？答：仅因共用有限架构名，重命名后可并行。

## 九、演进与趋势
重命名与 ROB/FreeList 协同，支持推测恢复（checkpoint），宽度与 PRF 大小成为设计参数权衡。

## 十、小结
寄存器重命名通过"名→物理"解耦，将 ILP 从架构寄存器数量的枷锁中解放出来。
