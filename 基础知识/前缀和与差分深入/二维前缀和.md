# 二维前缀和

> 对应 youngyangyang04/leetcode-master 二维前缀和与 CyC2018/CS-Notes 矩阵区域和。

## 一、背景与挑战
矩阵任意子矩形求和。朴素 $O(hw)$ 每次，二维前缀和 $O(1)$ 查询。

## 二、核心原理
容斥原理：子矩形和 = 大矩形 - 上 - 左 + 左上。预处理用同样容斥递推。

## 三、形式化与数学基础
$$S[i][j]=S[i-1][j]+S[i][j-1]-S[i-1][j-1]+a[i][j]$$
$$\text{sum}(x_1,y_1,x_2,y_2)=S[x_2][y_2]-S[x_1-1][y_2]-S[x_2][y_1-1]+S[x_1-1][y_1-1]$$

## 四、代码实现
```python
def build_prefix2d(a):
    n, m = len(a), len(a[0])
    s = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + a[i-1][j-1]
    return s

def rect_sum(s, x1, y1, x2, y2):
    return s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1]
```

## 五、与其他技术对比
逐行前缀和也能做但每次 $O(w)$；二维前缀和一次 $O(1)$，适合海量查询。

## 六、常见误区
- 容斥符号写错（应减两次加一次）。
- 边界用 0 行 0 列未初始化。
