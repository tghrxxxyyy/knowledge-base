# 二维前缀和

> 对应 youngyangyang04/leetcode-master 二维前缀和（区域和检索 - 矩阵不可变）、CLRS《Introduction to Algorithms》前缀和推广，以及 CyC2018/CS-Notes 矩阵区域和。

## 一、背景与挑战

矩阵子区域求和是一类高频问题：图像处理里要取任意矩形的亮度/像素和（积分图 integral image）、推荐系统里要对用户-物品评分矩阵的子块做统计、游戏里要判断某个矩形区域的资源总量、竞赛里频繁出现"子矩阵和等于 k 的个数"。朴素做法对每个询问枚举子矩形内所有格子，单次 $O(hw)$；若有大量询问或还要枚举所有子矩形（$O(h^2w^2)$ 个），代价立刻爆炸——例如 $500\times 500$ 的矩阵枚举全部子矩阵就要 $10^{10}$ 量级。

一维前缀和把"区间"压成端点差，二维则要把"矩形"压成角点组合。难点在于：矩形不是一维区间的一条直线，直接套"右端减左端"会多算或漏算重叠区域，必须引入容斥原理（inclusion-exclusion）。这一步是本主题的核心：**减去两个重复扣掉的，再加回一个被多减的**。搞不清容斥符号，公式就会正负颠倒，结果要么偏小要么偏大，而且只在"非全角矩形"上出错，调试非常痛苦。

二维前缀和在工程中的位置也值得强调：OpenCV 的 `integral()`、Viola-Jones 人脸检测的 Haar-like 特征、以及各种"矩形区域 O(1) 查询"的算法，背后都是同一张积分图。面试中它通常作为中等题（LeetCode 304）出现，但"矩形批量更新 + 最终矩阵还原"（与二维差分配合）则是区分度更高的进阶点。

## 二、核心原理

设矩阵 $a$ 为 $n\times m$（1-based），定义二维前缀和 $S[i][j]$ 为以 $(1,1)$ 为左上、$(i,j)$ 为右下的矩形内所有元素之和：

$$S[i][j] = \sum_{x=1}^{i}\sum_{y=1}^{j} a[x][y]$$

同样约定第 0 行、第 0 列全为 0，作为哨兵，避免边界特判。

**预处理递推**：考虑 $(1,1)..(i,j)$ 与 $(1,1)..(i-1,j)$、$(1,1)..(i,j-1)$ 的关系。后两块相加，重叠部分是 $(1,1)..(i-1,j-1)$，它被加了两次，必须减去一次；再加上新增的 $a[i][j]$，于是

$$S[i][j] = S[i-1][j] + S[i][j-1] - S[i-1][j-1] + a[i][j]$$

**查询**：任取子矩形，左上角 $(x_1,y_1)$，右下角 $(x_2,y_2)$。用大矩形减去上方条带和左方条带，再加回被多减的左上角小块：

$$\mathrm{sum}(x_1,y_1,x_2,y_2) = S[x_2][y_2] - S[x_1-1][y_2] - S[x_2][y_1-1] + S[x_1-1][y_1-1]$$

直观记忆："**右下角起，减上减左，加左上**"，即"减二加一"。四个角点必须全部来自 $S$，且减去的两个是"贴边条带"，加回的是两条带的公共交集。

**为什么正确（不变量视角）**：$S[i][j]$ 始终等于 $(1,1)..(i,j)$ 的真实和。归纳初始化：$S[0][*]=S[*][0]=0$ 成立。归纳步：$S[i][j]$ 由两个已知正确的矩形并去重叠，再并上单点 $a[i][j]$，恰好是目标矩形的并集，无遗漏无重复。查询公式是同一容斥的逆用：四个 $S$ 值各覆盖一个以原点为左上的矩形，容斥系数 $+1,-1,-1,+1$ 使得目标子矩形内每个点被计一次、外部被计零次。

**边界条件**：当 $x_1=1$ 或 $y_1=1$ 时，$x_1-1$ 或 $y_1-1$ 为 0，靠全 0 哨兵行/列自然吸收；若不建哨兵，就必须写三个 `if` 分支，极易漏。矩阵为 $1\times 1$、子矩形退化为单点/单行/单列时公式依然成立。

## 三、形式化与数学基础

容斥原理的一般形式：对集合 $A\cup B$，

$$|A\cup B| = |A| + |B| - |A\cap B|$$

子矩形和可以写成四个"原点矩形"的容斥组合。记

$$R(i,j) = [1,i]\times[1,j]$$

目标区域 $T = R(x_2,y_2) \setminus \big(R(x_1-1,y_2)\cup R(x_2,y_1-1)\big) \cup R(x_1-1,y_1-1)$，按容斥展开得系数 $+1,-1,-1,+1$，与查询式一致。

复杂度：预处理每个格子 $O(1)$，共 $\Theta(nm)$ 时间、$\Theta(nm)$ 空间；每次查询 $\Theta(1)$。对比逐行一维前缀和（每行建 $S$，查询时对 $x_1..x_2$ 行各做一次 $O(1)$ 减法），查询是 $O(x_2-x_1+1)$；二维前缀和把查询压到常数，是"海量查询"下的正确选择。

与二维差分的对偶关系（详见本专题差分篇）：若定义

$$D[i][j] = a[i][j] - a[i-1][j] - a[i][j-1] + a[i-1][j-1]$$

则 $S$ 是 $D$ 的二维前缀和，$D$ 是 $S$ 的二维差分。矩形加 $v$ 在 $D$ 上只改 4 个角点：

$$D[x_1][y_1] \mathrel{+}= v,\quad D[x_1][y_2+1] \mathrel{-}= v,\quad D[x_2+1][y_1] \mathrel{-}= v,\quad D[x_2+1][y_2+1] \mathrel{+}= v$$

最后再做一遍二维前缀和即得最终矩阵。这一"四角更新、一次还原"是矩形批量更新的标准解法。

数学上还可以验证线性性：前缀和是线性算子，因此"先加矩阵再建前缀"与"先建前缀再叠加各次更新的前缀"结果一致，这正是差分批量更新能成立的依据。

## 四、代码实现

标准实现（哨兵行列）：

```python
def build_prefix2d(a):
    """a: n x m 的二维列表（0-based）；返回 (n+1) x (m+1) 的前缀和 s"""
    n, m = len(a), len(a[0])
    s = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + a[i-1][j-1]
    return s


def rect_sum(s, x1, y1, x2, y2):
    # 1-based 闭区间，左上 (x1,y1)，右下 (x2,y2)
    return s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1]


if __name__ == "__main__":
    a = [
        [3, 0, 1, 4, 2],
        [5, 6, 3, 2, 1],
        [1, 2, 0, 1, 5],
        [4, 1, 0, 1, 7],
        [1, 0, 3, 0, 5],
    ]
    s = build_prefix2d(a)
    # LeetCode 304 样例为 0-based (2,1,4,3)，换算到本 1-based 接口是 (3,2,5,4)
    assert rect_sum(s, 3, 2, 5, 4) == 8
    assert rect_sum(s, 1, 1, 1, 1) == 3
    assert rect_sum(s, 1, 1, 5, 5) == sum(map(sum, a))
```

变体一：矩形批量更新 + 最终还原（二维差分，与本篇对偶）：

```python
def rect_add_and_restore(n, m, ops):
    """ops: (x1, y1, x2, y2, v)，1-based 闭区间矩形加 v"""
    d = [[0] * (m + 2) for _ in range(n + 2)]
    for x1, y1, x2, y2, v in ops:
        d[x1][y1] += v
        d[x1][y2 + 1] -= v
        d[x2 + 1][y1] -= v
        d[x2 + 1][y2 + 1] += v
    a = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            a[i][j] = d[i][j] + a[i-1][j] + a[i][j-1] - a[i-1][j-1]
    return [row[1:] for row in a[1:]]
```

变体二：统计"元素均为 1 的子矩阵个数"可用前缀和 + 枚举上下的行对，把二维压成一维再双指针；这是把二维问题降维的经典手法。

## 五、与其他技术对比

| 方法 | 预处理 | 单次查询 | 空间 | 适合 |
|------|--------|----------|------|------|
| 朴素枚举 | $O(1)$ | $O(hw)$ | $O(1)$ | 一两次询问 |
| 逐行一维前缀和 | $O(nm)$ | $O(n)$ | $O(nm)$ 或 $O(m)$ | 行数少、查询少 |
| 二维前缀和 | $O(nm)$ | $O(1)$ | $O(nm)$ | 静态矩阵、海量矩形查询 |
| 二维线段树 / 树状数组套 | $O(nm\log n\log m)$ | $O(\log n\log m)$ | 大 | 动态修改 + 查询 |
| 积分图（OpenCV integral） | $O(nm)$ | $O(1)$ | $O(nm)$ | 图像矩形特征、与 CV 生态对接 |

取舍：只读用二维前缀和；有矩形修改且要中途查询用二维 BIT/线段树；只做"改完再看"用二维差分（四角更新）。面试中若候选人能主动写出二维差分与二维前缀和的对偶，通常可视为掌握扎实。

## 六、常见误区

1. **容斥符号写错**。把公式写成 `s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] - s[x1-1][y1-1]` 或少加左上角。后果：仅在子矩形不贴左/上边界时出错，全图查询反而正确，极难发现。对策：用 $1\times1$ 与 $2\times2$ 小矩阵手算验证。
2. **忘记 0 行 0 列哨兵**。`s[i-1][j-1]` 在 $i=1$ 或 $j=1$ 时越界；若用 Python 列表负下标，会静默读到最后一行，产生玄学错误。后果：边界崩溃或答案离谱。对策：永远多开一行一列置 0。
3. **下标 0-based/1-based 混用**。输入 `a[i-1][j-1]` 与查询 `x1-1` 同时出现时最容易错位。后果：差 1 的答案。对策：内部统一 1-based，对外 API 明确说明。
4. **把矩形加当成逐点加去做**。批量更新 $q$ 次若每次 $O(hw)$，总代价 $O(qhw)$，在 $q$ 大时远劣于差分的 $O(q+nm)$。后果：超时。对策：识别"离线批量更新"模式，先写差分再还原。
5. **溢出与类型**。元素与矩阵规模都大时，$S$ 的量级是 $nm\max|a|$，C++ 需 `long long`；Python 自动大整数但 numpy 默认 `int32`/`int64` 仍可能溢出，做工程时要显式指定 dtype。

## 八、面试题

**1. LeetCode 304：二维不可变矩阵，多次子矩形求和。**
参考答案：建 $(n+1)\times(m+1)$ 前缀和，查询用容斥四角公式，$O(1)$。说清 $S[0][*]=S[*][0]=0$ 与"减二加一"。

**2. 推导子矩形和公式的容斥原理。**
参考答案：$S[x_2][y_2]$ 含目标 + 上 + 左 + 左上；减 $S[x_1-1][y_2]$ 去掉上方（含左上），减 $S[x_2][y_1-1]$ 去掉左方（含左上），左上被减两次，故再加 $S[x_1-1][y_1-1]$。

**3. 若要支持"矩形加 v"且最后打印矩阵，怎么做？**
参考答案：二维差分，四角 $O(1)$ 更新，最后做一次二维前缀和还原，总 $O(q+nm)$。若中途要查询，改用二维树状数组/线段树。

**4. 和小于等于 $k$ 的子矩阵个数如何优化？**
参考答案：固定上下边界，把中间各行压成一维数组，问题变为"一维数组中和 $\le k$ 的子数组个数"，用有序前缀和/平衡树/归并计数 $O(m\log m)$，总 $O(n^2 m\log m)$。这是二维降维的经典套路。

## 九、演进与趋势

- **积分图与计算机视觉**：Haar 特征、box filter、引导滤波都依赖 $O(1)$ 矩形和；OpenCV/深度学习前处理里的 `cv2.integral` 是工业级实现。
- **高维前缀和**：三维及以上用于时空统计与位掩码 SOS DP（子集和变换），容斥系数按维数推广为 $(-1)$ 的幂次。
- **与差分、扫描线结合**：矩形批量加、矩形覆盖计数、最大重叠矩形等问题的离线解法，几乎都是"差分/事件 + 前缀还原"。
- **流式与增量积分图**：视频流、时序库中需要增量维护矩形聚合，会出现"滑动积分图"（行/列出队入队时增量更新），与滑动窗口思想合流。
- **GPU 并行二维 scan**：图像批处理中二维前缀和被向量化/并行化，用于体渲染与物理仿真的网格统计。

## 十、小结

二维前缀和靠容斥原理把子矩形和压成四角组合，预处理 $O(nm)$、查询 $O(1)$；牢记"右下起、减上减左、加左上"与全 0 哨兵行列。它与二维差分互为逆运算：只读查询用前缀和，矩形批量更新用差分四角修改再一次性还原，两者配合覆盖绝大多数静态矩阵区间问题。
