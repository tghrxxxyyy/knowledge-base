# 差分与前缀和的逆运算

> 对应 youngyangyang04/leetcode-master 差分章节与 CyC2018/CS-Notes；离散微积分视角参考 Graham/Knuth/Patashnik《Concrete Mathematics》差分与求和算子，以及 CLRS 前缀和/扫描思想。

## 一、背景与挑战

还有一类问题与"区间查询"对偶：**多次区间修改，最后（或中途）看结果**。典型场景：航班预订系统里若干航线段各自增加座位数、拼车问题判断是否超载、刷油漆/涂色覆盖若干区间、日志系统对时间段批量打标、竞赛里"对区间加 1 后求最终数组"。朴素做法每次真正遍历 $[l,r]$ 逐元素加，单次 $O(n)$，$q$ 次 $O(qn)$；$n,q = 10^5$ 时不可接受。

差分（difference array）正是为"批量区间加"而生：把"区间加 $v$"压缩成**端点上两次 $O(1)$ 修改**，全部更新做完后，再做一次前缀和（积分）即可还原整个数组。它与前缀和互为逆运算——前缀和像积分，差分像微分；积分把端点信息摊开成区间，微分把区间变化集中到端点。理解这一对偶，比背 `d[l]+=v; d[r+1]-=v` 更重要：你会明白为什么必须在 $r+1$ 反向抵消、为什么最后要还原、以及何时该用线段树而不是差分。

需要先划清能力边界：差分适合**离线**（或"改完再查"）场景；若要边改边查询任意区间和，就要树状数组/线段树。若修改与查询交错且都频繁，差分重建代价高，不够用。

## 二、核心原理

设原数组 $a[1..n]$，定义差分数组

$$D[i] = a[i] - a[i-1], \quad a[0] = 0$$

即相邻元素之差。反过来，$a$ 是 $D$ 的前缀和：

$$a[i] = \sum_{k=1}^{i} D[k]$$

**区间加的压缩**：要让 $a[l..r]$ 每个元素加 $v$，等价于让差分只在两端变化：
- $D[l] = a[l] - a[l-1]$ 应增加 $v$（$a[l]$ 变大）；
- $D[r+1] = a[r+1] - a[r]$ 应减少 $v$（$a[r]$ 变大而 $a[r+1]$ 不变）；
- 其余 $D[i]$（$i \notin \{l, r+1\}$）的相邻差不变。

于是执行

$$D[l] \mathrel{+}= v, \quad D[r+1] \mathrel{-}= v$$

即可。注意 $r+1$ 可能越界，数组要多开一位，或在 $r=n$ 时跳过反向修改。

**正确性（传播与抵消）**：还原时做前缀和，对 $i \in [l, r]$，求和路径经过 $D[l]$ 的 $+v$，故 $a[i]$ 增加 $v$；对 $i > r$，路径同时经过 $+v$ 与 $-v$，相互抵消，$a[i]$ 不变；对 $i < l$，路径不经过 $D[l]$，亦不变。这正是"增量在区间内传播、区间外抵消"。

**不变量**：任意时刻，$D$ 的前缀和等于当前的 $a$。区间加只改 $D$ 的两个端点，不动中间，因此维护代价 $O(1)$；最后一次性前缀和 $O(n)$ 还原。

可以把 $D$ 想成"地形的坡度"：把一段区间整体抬高，只有进入区间和离开区间那两处坡度会变，区间内部仍是平的。前缀和还原则像沿着坡度走回高度——走过 $+v$ 的台阶后高度整体上移，再走过 $-v$ 的台阶后落回原水平。这个几何图像能帮助记忆"左加右减"，也能解释为什么 $r+1$ 那一步绝不能漏。

再进一步，差分对"区间加"的友好性来自线性：多个区间加的效果等于各自差分标记的叠加，互不干扰。因此可以先把 $q$ 次更新全部累加到 $D$ 上，再做一次前缀和；也可以分批还原（例如每 $\sqrt{q}$ 次更新后重建一次），用少量重复劳动换取"中途也想看一眼"的能力，这是根号分治的雏形。

二维情形（矩形加）同构：$D[x_1][y_1] \mathrel{+}= v$ 等四个角点更新，再二维前缀和还原，详见《二维前缀和》。树上差分则是把端点标记放到路径两端与 LCA 上，最后一次 DFS 前缀还原，把"区间"换成"树上路径"，思想完全一致。

## 三、形式化与数学基础

引入后向差分算子 $\Delta$：

$$\Delta a_i = a_i - a_{i-1}$$

前缀和算子 $S$：

$$(S D)_i = \sum_{k=1}^{i} D_k$$

则有

$$S(\Delta a) = a - a_0 \mathbf{1}, \quad \Delta (S D) = D$$

（取 $a_0 = 0$ 时 $S\Delta = I$）。差分与前缀和在零初值约定下互逆，类似微积分基本定理的离散版：

$$\sum_{i=l}^{r} \Delta a_i = a_r - a_{l-1}$$

区间加在算子语言下：定义向量 $e_l - e_{r+1}$（在 $l$ 置 $+v$、$r+1$ 置 $-v$），则

$$a' = a + v \cdot S(e_l - e_{r+1})$$

而 $S(e_l - e_{r+1})$ 恰是区间 $[l,r]$ 的指示向量。多次更新线性叠加：

$$a_{\text{final}} = a_{\text{init}} + \sum_{t=1}^{q} v_t \cdot S(e_{l_t} - e_{r_t+1}) = S\Big(\Delta a_{\text{init}} + \sum_{t} v_t (e_{l_t} - e_{r_t+1})\Big)$$

这就是"先累积差分、再一次前缀和"的代数依据——线性性允许交换求和与 $S$。

复杂度证明：$q$ 次更新共 $2q$ 次端点操作，$\Theta(q)$；还原一次前缀和 $\Theta(n)$；总 $\Theta(n+q)$，对比朴素 $\Theta(qn)$。空间 $\Theta(n)$。

若在还原过程中需要"当前点值"（如判断是否超容量），可以边做前缀和边扫描，无需额外结构——这是拼车、航班预订类题的标准写法。

## 四、代码实现

基础：区间加 + 最终还原（1-based）：

```python
def range_add_and_restore(n, ops):
    """ops: list of (l, r, v)，1-based 闭区间；返回最终数组"""
    d = [0] * (n + 2)          # 多开一位，容纳 d[r+1]
    for l, r, v in ops:
        d[l] += v
        d[r + 1] -= v
    a = []
    cur = 0
    for i in range(1, n + 1):
        cur += d[i]
        a.append(cur)
    return a


if __name__ == "__main__":
    # n=5，两次更新：[1,3]+2，[2,5]+1 → 期望 [2,3,3,1,1]
    assert range_add_and_restore(5, [(1, 3, 2), (2, 5, 1)]) == [2, 3, 3, 1, 1]
    assert range_add_and_restore(3, [(1, 3, 5)]) == [5, 5, 5]
```

边还原边查询（判断峰值）：

```python
def max_after_ops(n, ops):
    d = [0] * (n + 2)
    for l, r, v in ops:
        d[l] += v
        if r + 1 <= n:
            d[r + 1] -= v
    cur = best = 0
    for i in range(1, n + 1):
        cur += d[i]
        best = max(best, cur)
    return best
```

与前缀和对偶的验证函数（帮助理解逆运算）：

```python
def diff(a):
    """a 0-based，返回差分 d，d[i] = a[i] - a[i-1]（a[-1] 视作 0）"""
    d = []
    prev = 0
    for v in a:
        d.append(v - prev)
        prev = v
    return d

def prefix(d):
    a = []
    cur = 0
    for v in d:
        cur += v
        a.append(cur)
    return a

# prefix(diff(a)) == a
assert prefix(diff([3, 1, 4, 1, 5])) == [3, 1, 4, 1, 5]
```

## 五、与其他技术对比

| 方法 | 单次区间加 | 单次区间查询 | 中途查询 | 总复杂度（q 次加 + 全查） |
|------|------------|--------------|----------|---------------------------|
| 朴素逐元素 | $O(n)$ | $O(n)$ | 支持 | $O(qn)$ |
| 差分 | $O(1)$ | 需还原 $O(n)$ | 弱（要扫描） | $O(n+q)$ |
| 树状数组 | $O(\log n)$ | $O(\log n)$ | 支持 | $O((n+q)\log n)$ |
| 线段树（懒标记） | $O(\log n)$ | $O(\log n)$ | 支持，信息更丰富 | $O((n+q)\log n)$ |
| 扫描线（事件排序） | $O(1)$ 建事件 | 扫描时顺带 | 离线 | $O((n+q)\log q)$（排序） |

取舍：纯"离线批量加 + 最终结果"用差分，代码最短、常数最小；动态改查用树状数组/线段树；坐标稀疏且只需统计事件影响时，扫描线更自然。差分的隐藏优势是**可与前缀和、哈希、双指针组合**，作为预处理第一步。

## 六、常见误区

1. **忘记 `d[r+1] -= v`**。后果：$r$ 之后全部被加 $v$，变成"后缀加"，边界之后全错。对策：口诀"左加右减"，并测 $[1,n]$ 整段加、$[1,1]$ 单点加两种边界。
2. **`r+1` 越界**。C++ 越界是未定义行为，Python 负下标会静默改到末尾。后果：偶发崩溃或玄学答案。对策：`d` 长度开 `n+2`，或条件写 `if r+1 <= n`。
3. **直接把 `d` 当最终数组输出**。差分不是结果，只是"变化率"。后果：输出一串正负交错的端点值。对策：还原前缀和后再使用，并在变量命名上区分 `d` 与 `a`。
4. **下标 1-based / 0-based 混用**。与前缀和同源，`d[l]` 与 `d[l+1]` 差一位。对策：统一约定，API 注释写清闭区间。
5. **该用线段树时硬套差分**。若问题要求"每次操作后立刻查询区间和"，差分每次都要 $O(n)$ 重建，退化成 $O(qn)$。后果：超时。对策：认清离线/在线边界。

## 八、面试题

**1. 差分为何能做到 $O(1)$ 区间加？**
参考答案：区间加只改变 $a[l-1]\to a[l]$ 与 $a[r]\to a[r+1]$ 两处相邻差，故 $D$ 只动两个端点；中间差分不变，保证还原时区间内同增、区间外抵消。

**2. 二维差分如何做矩形加？**
参考答案：四个角点 $D[x_1][y_1]{+}{=}v$，$D[x_1][y_2+1]{-}{=}v$，$D[x_2+1][y_1]{-}{=}v$，$D[x_2+1][y_2+1]{+}{=}v$，最后二维前缀和还原，$O(q+nm)$。

**3. 差分和前缀和的数学关系？**
参考答案：互为逆运算。$\Delta$ 把序列变成相邻差，$S$ 用前缀和还原；零初值下 $S\Delta = I$。区间和 $= S[r]-S[l-1]$，区间加在 $\Delta$ 域只动端点。

**4. 若需要在线查询怎么办？**
参考答案：改用树状数组（单点改/区间和）或带懒标记的线段树（区间改/区间查）；也可根号分治：攒一批差分更新，超过阈值时重建前缀和。

## 九、演进与趋势

- **图像与信号处理**：积分图（前缀和）与差分模板成对出现，box blur、边缘检测（相邻差）都是同一套算子；实时视频里的帧差运动检测，就是"相邻帧做差"这一直觉的工程形态。
- **区间覆盖与扫描线**：差分可以统计"每点被覆盖次数"，配合坐标离散化处理稀疏区间，是几何与线段覆盖题的基础。事件点排序后线性扫，等价于在稀疏坐标上做差分前缀和。
- **树上差分**：把差分搬到树路径上，`path add` 通过端点与 LCA 上的差分标记完成，最后一次 DFS 前缀还原——把一维逆运算推广到树。子树加则是"入点 +v、出点 -v"的 DFS 序差分，同样收束为一次还原。
- **流式增量计算**：实时数仓里"区间修正 + 还原明细"常用差分思想做增量合并；与 LSM/增量视图的"叠加 + 压实"同构。数据库的 delta 合并、物化视图增量维护，都是"先记录变化量，需要时再积分回全量"。
- **与哈希/前缀异或组合**：异或差分（区间异或）同样成立，因为异或是自逆群运算，可处理"区间翻转位"类问题；模意义下的加减亦然，只需注意模逆元存在性。
- **根号分治与块状数组**：当更新与查询交错但可容忍 $\sqrt{n}$ 重建时，差分 + 定期前缀和构成块状数组的核心，是介于"纯差分"与"线段树"之间的折中，在序列题中常能以更短代码过关。

## 十、小结

差分是前缀和的逆运算：区间加只改 $D[l]$ 与 $D[r+1]$ 两个端点，最后做一次前缀和即得最终数组，总代价 $O(n+q)$。牢记"左加右减、多开一位、还原再用"三条纪律，并分清离线批量更新（差分）与在线动态改查（树状数组/线段树）的能力边界。
