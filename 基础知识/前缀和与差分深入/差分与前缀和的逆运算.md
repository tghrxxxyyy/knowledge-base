# 差分与前缀和的逆运算

> 对应 youngyangyang04/leetcode-master 差分章节与 CyC2018/CS-Notes 题解。

## 一、背景与挑战
对数组做多次"区间加 val"后查询最终数组。若每次真改区间 $O(n)$，差分可 $O(1)$ 每改。

## 二、核心原理
差分数组 $D[i]=a[i]-a[i-1]$。区间 $[l,r]$ 加 $v$ 只需 $D[l]+=v,\ D[r+1]-=v$。最后求前缀和还原 $a$。

## 三、形式化与数学基础
差分是前缀和的逆：$\text{prefix}(D)=a$。区间加在差分上只改两个端点，因前缀和时增量在区间内传播、区间外抵消。

## 四、代码实现
```python
def range_add_and_restore(n, ops):
    # ops: list of (l, r, v), 1-based l,r
    d = [0] * (n + 2)
    for l, r, v in ops:
        d[l] += v
        d[r + 1] -= v
    a = [0] * (n + 1)
    for i in range(1, n + 1):
        a[i] = a[i - 1] + d[i]
    return a[1:]
```

## 五、与其他技术对比
线段树区间加 $O(\log n)$ 且支持查询中间状态；差分 $O(1)$ 但只适合"全改完再查"。

## 六、常见误区
- 忘记 `r+1` 越界（数组需多开一位）。
- 把差分当原数组直接用，未还原前缀和。
