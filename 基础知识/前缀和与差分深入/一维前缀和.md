# 一维前缀和

> 对应 youngyangyang04/leetcode-master 前缀和章节与 CyC2018/CS-Notes 前缀和题解。

## 一、背景与挑战
频繁查询数组任意区间和。朴素每次 $O(n)$，前缀和预处理后 $O(1)$。

## 二、核心原理
预处理 $S[i]=\sum_{k=1}^{i}a_k$。区间 $[l,r]$ 和为 $S[r]-S[l-1]$。常用 $S[0]=0$ 统一边界。

## 三、形式化与数学基础
$$S[i]=S[i-1]+a_i,\quad \text{sum}(l,r)=S[r]-S[l-1]$$
前缀和本质是离散积分，区间和是积分差。

## 四、代码实现
```python
def build_prefix(a):
    s = [0] * (len(a) + 1)
    for i, v in enumerate(a):
        s[i + 1] = s[i] + v
    return s

def range_sum(s, l, r):
    # 1-indexed s, 区间 [l, r] 闭区间 (1-based)
    return s[r] - s[l - 1]
```

## 五、与其他技术对比
树状数组/线段树支持动态修改，前缀和仅适合静态数组；但前缀和常数最小。

## 六、常见误区
- 下标偏移错误（用 0-based 数组却按 1-based 公式）。
- 忘记 `S[0]=0` 导致 `l=1` 时越界。
