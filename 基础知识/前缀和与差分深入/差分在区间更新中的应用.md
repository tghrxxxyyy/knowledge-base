# 差分在区间更新中的应用

> 对应 youngyangyang04/leetcode-master 差分（航班预订/拼车）与 CyC2018/CS-Notes。

## 一、背景与挑战
多次区间增量更新后回答每点最终值或判断是否满足容量。差分把每次更新压成 $O(1)$。

## 二、核心原理
每条预约 `(l,r,v)` 在差分上 `d[l]+=v, d[r+1]-=v`；结束后前缀和恢复。判断类问题甚至不用完全恢复。

## 三、形式化与数学基础
最终数组 $a[i]=\sum_{j=1}^{i} d[j]$。区间更新在 $d$ 上仅两端变动，前缀和使增量在区间内均匀传播。

## 四、代码实现
```python
def car_pooling(trips, capacity):
    d = [0] * 1001          # 站点范围已知
    for n, f, t in trips:
        d[f] += n
        d[t] -= n
    cur = 0
    for v in d:
        cur += v
        if cur > capacity:
            return False
    return True
```

## 五、与其他技术对比
扫描线（事件排序）也能做，但差分在坐标稠密时更简洁；线段树适合动态。

## 六、常见误区
- 上下车边界混淆（应在下车点 `t` 减，而非 `t-1`，视题意）。
- 坐标范围未预留导致越界。

## 九、演进与趋势
差分与扫描线是离线区间问题的两大基石，配合排序处理稀疏坐标。

## 十、小结
差分把"批量区间加"转为端点操作，前缀和一次性还原，适合静态更新。
