# 前缀最值与其他前缀变换

> 对应 youngyangyang04/leetcode-master 前缀技巧（前缀异或等）与 CyC2018/CS-Notes；代数视角参考 CLRS 中关于可结合算子与扫描（scan）的讨论。

## 一、背景与挑战

区间和只是前缀思想的一个特例。面试与竞赛中还大量出现：区间最大/最小值、前缀异或、前缀 GCD、字符出现次数向量、前缀乘积、模意义计数……初学者容易把"前缀和"当成唯一形态，遇到"子数组异或等于 k"或"左边第一个比它大的元素"就无从下手；反过来，也有人误以为任何聚合都能像和一样"两个前缀相减"得到区间答案，结果试图用前缀最大值算区间最大值，得到错误结论。

真正统一的视角是代数：设算子 $\oplus$，维护

$$P[i] = a_1 \oplus a_2 \oplus \cdots \oplus a_i$$

若 $\oplus$ 可结合，则 $P$ 可以线性递推；若 $\oplus$ 还有逆元（如加法的相反数、异或的自身），则区间聚合 $a_{l..r} = P[l-1]^{-1} \oplus P[r]$ 可用两次查表得到；若 $\oplus$ 幂等且无逆元（如 max/min），则只能回答"包含端点的"特殊问题，一般区间查询要靠稀疏表/线段树/单调栈。

因此本篇的核心是分清三件事：**哪些算子可以前缀化（可结合即可）**、**哪些可以做"区间还原"（需要逆元或可减性）**、**哪些前缀量只能回答前缀性质而非任意区间**。这是把零散技巧捏成体系的关键，也是面试官考察"是否真正理解"的常用切入点。

工程上的对应物同样丰富：编译器里的前缀累积（类型推断、可用表达式）、GPU scan 原语、位运算状态压缩、CRC/滚动哈希，都是"前缀变换"的实例。

## 二、核心原理

**1. 前缀最大/最小值。** 递推 $M[i] = \max(M[i-1], a_i)$，初值 $M[0] = -\infty$。它回答的问题是"前 $i$ 个元素的最大值"，常用于"左边是否有更大元素""历史最大收益"（`max so far`）。注意 $M$ 无逆元：由 $M[r]$ 与 $M[l-1]$ **不能**推出 $[l,r]$ 的最大值——最大值可能完全落在区间内而两边前缀都不知道它。要查任意区间最大，用 ST 表（$O(n\log n)$ 预处理 $O(1)$ 查询）或单调栈找左右最近更大元素。

**2. 前缀异或。** $X[0]=0$，$X[i] = X[i-1] \oplus a_i$。异或是阿贝尔群运算（自逆），因此

$$a_l \oplus \cdots \oplus a_r = X[r] \oplus X[l-1]$$

于是"子数组异或等于 $k$"完全套用前缀和 + 哈希：$X[r] \oplus X[l-1] = k \iff X[l-1] = X[r] \oplus k$。这是异或题的标准骨架（LeetCode 1371、1442、421 等）。

**3. 前缀 GCD。** $G[i] = \gcd(G[i-1], a_i)$。注意 $\gcd$ 可结合、可交换，但**无逆元**：$\gcd(12,18)=6, \gcd(12,18,5)=1$，无法从 $G[r]$ 与 $G[l-1]$ 反推区间 GCD。区间 GCD 用 ST 表（GCD 幂等，可重叠）或线段树。

**4. 前缀计数向量。** 对字符/类别维护计数 `cnt[c][i]`，区间频次 = 两前缀之差（计数有逆元，可减）。这是"区间内某字符出现次数"的 $O(1)$ 做法，也是很多字符串题的预处理。

**5. 前缀乘积与前缀线性变换。** 乘积有逆元（模意义下需元素可逆）；更一般地，矩阵乘积前缀可用于递推关系的区间合并，是线段树上"信息合并"思想的前缀特例。

不变量：$P[i]$ 永远等于 $a_{1..i}$ 在 $\oplus$ 下的聚合。初始化 $P[0]=$ 算子单位元（加法 0、异或 0、乘法 1、max 的 $-\infty$），归纳递推即可。**单位元选错**是常见 bug，例如前缀最大用 0 而数组全负，或前缀乘积忘了 1。

## 三、形式化与数学基础

设 $(S, \oplus, e)$ 为幺半群：$\oplus$ 可结合，$e$ 为单位元。则前缀

$$P[0] = e, \quad P[i] = P[i-1] \oplus a_i$$

满足

$$P[i] = \bigoplus_{k=1}^{i} a_k$$

由结合律，括号位置不影响结果，故递推良定义。

若 $(S, \oplus)$ 进一步是群（每个元素有逆），则区间聚合

$$\mathrm{agg}(l, r) = P[l-1]^{-1} \oplus P[r]$$

（若 $\oplus$ 交换可写成 $P[r] \oplus P[l-1]^{-1}$）。加法群：$P[r]-P[l-1]$；异或群：$P[r]\oplus P[l-1]$（自逆）；乘法群（模 $p$ 素数）：$P[r]\cdot P[l-1]^{-1}$。

若只有幺半群无逆（$\max, \min, \gcd, \lor, \land$），一般区间聚合不能由两端前缀还原。但存在两类补救：
- **幂等 + 重叠**：$[l,r]$ 的聚合可拆成两个覆盖该区间的前缀/块（ST 表），因幂等 $\max$ 重叠不改变结果；块大小 $O(\log n)$ 或用稀疏表 $O(1)$。
- **单调结构**：$\max$ 具有单调性，可用单调栈找左右约束，或单调队列做滑动窗口最值（$O(n)$）。

复杂度：前缀化本身 $\Theta(n)$ 时间、$\Theta(n)$ 空间；查询 $O(1)$（有逆时）。用位运算表示子集状态时，$P[i]$ 可压缩成整数，空间降到 $O(1)$ 个机器字，但时间不变。

前缀异或 + 哈希的计数公式（与前缀和同构）：

$$\#\{(i,j): i<j,\ X[i] = X[j] \oplus k\} = \sum_j C_j(X[j]\oplus k)$$

其中 $C_j$ 为扫描到 $j$ 时 $X[0..j-1]$ 的频次表。

## 四、代码实现

```python
import math
from collections import defaultdict

def prefix_max(a):
    """前缀最大值，m[i] = max(a[:i])，0-based 长度 n"""
    m = []
    cur = float('-inf')
    for v in a:
        cur = max(cur, v)
        m.append(cur)
    return m


def prefix_xor(a):
    """x[i] = a[0]^...^a[i-1]，x[0]=0，长度 n+1"""
    x = [0]
    for v in a:
        x.append(x[-1] ^ v)
    return x


def count_subarrays_xor_k(nums, k):
    """子数组异或为 k 的个数（前缀异或 + 哈希）"""
    count = {0: 1}
    pref = 0
    ans = 0
    for v in nums:
        pref ^= v
        ans += count.get(pref ^ k, 0)
        count[pref] = count.get(pref, 0) + 1
    return ans


def prefix_gcd(a):
    g = [0]
    for v in a:
        g.append(math.gcd(g[-1], v))
    return g


if __name__ == "__main__":
    assert prefix_max([3, -1, 5, 2]) == [3, 3, 5, 5]
    assert prefix_xor([1, 2, 3]) == [0, 1, 3, 0]
    assert count_subarrays_xor_k([4, 2, 2, 6, 4], 6) == 4
    assert prefix_gcd([12, 18, 30]) == [0, 12, 6, 6]
```

关键变体——用前缀最大求"历史最大差价"（只能买一次）：

```python
def max_profit(prices):
    best = 0
    low = float('inf')
    for p in prices:
        low = min(low, p)            # 前缀最小值
        best = max(best, p - low)    # 当前价 - 历史最低
    return best
```

变体——区间字符频次（计数可减）：

```python
def build_char_count(s):
    # cnt[c][i] = 前 i 个字符中 c 的个数
    cnt = {}
    cur = defaultdict(int)
    cnt[0] = dict(cur)
    for i, ch in enumerate(s, 1):
        cur[ch] += 1
        cnt[i] = dict(cur)
    return cnt

def char_freq(cnt, l, r, c):
    # 1-based [l, r]
    return cnt[r].get(c, 0) - cnt[l-1].get(c, 0)
```

## 五、与其他技术对比

| 聚合 | 可结合 | 有逆 | 前缀可还原区间 | 任意区间查询方案 |
|------|--------|------|----------------|------------------|
| 求和 | 是 | 是 | 是 | 前缀和 |
| 异或 | 是 | 是（自逆） | 是 | 前缀异或 |
| 计数 | 是 | 是 | 是 | 前缀计数之差 |
| 乘积 | 是 | 非零时 | 是 | 前缀乘积 |
| max/min | 是 | 否 | 否 | ST 表 / 线段树 / 单调栈 |
| GCD | 是 | 否 | 否 | ST 表 / 线段树 |
| 中位数/秩 | 否（难） | 否 | 否 | 对顶堆 / 平衡树 / 莫队 |

取舍：有逆算子优先前缀 + 哈希/差分；无逆但幂等用 ST 表；动态修改用线段树；"含秩/中位数"这类非半群约束则跳出前缀框架。面试中能根据算子性质选择结构，比死记某一个模板更关键。

## 六、常见误区

1. **用前缀最大值回答区间最大值**。后果：例如 $a=[5,1,4]$，$M[3]=5$，但 $[2,3]$ 的最大是 4，用 $M$ 相减/相除都得不到。对策：记住"无逆元不可还原"，换 ST 表/单调栈。
2. **单位元选错**。前缀最大用 0 作初值，数组全负时结果错误；前缀乘积忘乘 1；前缀异或忘 0。后果：首元素/全负用例挂掉。对策：写清 $P[0]=e$，并用全负、空数组测试。
3. **前缀异或忘记 `X[0]=0`**。与前缀和漏 $S[0]$ 同理，会漏掉"从头开始异或为 k"的子数组。对策：`count={0:1}` 或 `x=[0]` 起头。
4. **对无逆算子强行写"区间 = 两端之差"**。GCD、OR、AND 都没有逆，差分思路不适用。后果：编译能过但答案错。对策：分类记忆——加/异或/计数可减，max/min/GCD 不可减。
5. **误以为"前缀"一定是求和**。遇到前缀异或、前缀或、前缀 GCD 不敢套框架。后果：多余暴力。对策：抓住"可结合 + 单位元"即可前缀化，再看有没有逆元决定查询能力。

## 八、面试题

**1. 如何统计"子数组异或等于 k"的个数？**
参考答案：前缀异或 $X$，哈希统计 $X[i] = X[j]\oplus k$ 的对数，`count={0:1}`，先查后改，$O(n)$。

**2. 为什么前缀最大不能像前缀和一样求区间最大？**
参考答案：max 无逆元，且前缀最大可能来自区间之外；无法用 $M[r]$ 与 $M[l-1]$ 反推。任意区间最大用 ST 表（幂等可重叠）或线段树。

**3. 前缀和、前缀异或、前缀 GCD，哪些支持区间还原？**
参考答案：和与异或有逆元，支持；GCD 无逆元，不支持。判断标准是算子是否成群（存在逆）。

**4. 滑动窗口最值为什么常用单调队列而不是前缀最值？**
参考答案：窗口是"可变区间"且随右端滑动，前缀最值只能给"从开头到某点"的最值；单调队列在均摊 $O(1)$ 内维护窗口内 max/min，是动态的、可收缩的。

## 九、演进与趋势

- **SOS DP（子集前缀和）**：位掩码上的前缀变换，$F[mask] = \sum_{sub \subseteq mask} A[sub]$，在状压 DP 与子集统计中是标准优化。
- **前缀线性变换/矩阵前缀**：递推关系区间合并、倍增与树上差分常借助"变换可结合"这一性质，本质是幺半群扫描。
- **滚动哈希（rolling hash）**：字符串多项式哈希是"前缀变换 + 模逆"的组合，用于子串比较与模式匹配；需警惕单模哈希冲突，常用双模或 64 位自然溢出。
- **与莫队/分块结合**：可减/可回滚的信息用莫队维护区间频次、区间异或等，把"前缀可减"推广到离线区间查询。
- **硬件扫描原语**：GPU inclusive/exclusive scan、向量化前缀，是幺半群前缀在现代并行体系中的落地。

## 十、小结

前缀思想不限于求和：只要算子可结合就能前缀化，有逆元才能"两端还原区间"，幂等无逆则改走 ST 表/单调结构。把前缀最大、前缀异或、前缀 GCD、前缀计数放进同一张代数地图，就能准确判断每类问题该用前缀、哈希、单调栈还是线段树，避免"把 max 当加法"的经典错误。
