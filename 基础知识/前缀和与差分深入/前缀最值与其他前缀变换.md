# 前缀最值与其他前缀变换

> 对应 youngyangyang04/leetcode-master 前缀技巧与 CyC2018/CS-Notes 题解。

## 一、背景与挑战
除求和外，常需前缀最大值、前缀出现次数、前缀异或等。统一思想是用"可结合前缀算子"。

## 二、核心原理
若算子 $\oplus$ 满足结合/可重复查询，则可维护前缀序列：$P[i]=P[i-1]\oplus a_i$。区间性质取决于算子。

## 三、形式化与数学基础
- 前缀最大：$M[i]=\max(M[i-1], a_i)$
- 前缀异或：$X[i]=X[i-1]\oplus a_i$
异或的前缀差仍可用哈希表做"子数组异或=k"。

## 四、代码实现
```python
def prefix_max(a):
    m = []
    cur = float('-inf')
    for v in a:
        cur = max(cur, v)
        m.append(cur)
    return m

def prefix_xor(a):
    x = [0]
    for v in a:
        x.append(x[-1] ^ v)
    return x
```

## 五、与其他技术对比
前缀最值不可做"区间减"逆运算（无逆），故只适合静态；前缀异或可配合哈希做子数组查询。

## 六、常见误区
- 试图用前缀最值做区间最值（需线段树/稀疏表）。
- 前缀异或忘记初值 0。

## 七、与开源书/权威来源对应
- leetcode-master 前缀异或（存在重复子数组）。
- CS-Notes 前缀变换。

## 九、演进与趋势
前缀变换与莫队、位运算结合，处理异或/频率类区间问题。

## 十、小结
前缀思想不限于求和，凡可结合算子均可前缀化，但查询能力受算子性质限制。
