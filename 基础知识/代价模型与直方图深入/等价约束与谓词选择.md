# 等价约束与谓词选择

> 对应 Gray 等查询优化理论与 PostgreSQL 的「constraint exclusion / equivalence class」，参考 Garcia-Molina 第12章。

## 一、背景与挑战
SQL 中多处出现的同一列（如 JOIN 条件与 WHERE 条件）构成等价类，优化器可借由传递性推导新谓词，从而下推、剪枝分区、改进选择性估计。

## 二、核心原理
优化器收集所有等值条件形成等价类（equivalence class），例如 `a.x = b.y AND b.y = 5` 推出 `a.x = 5`，从而能在表 a 上早过滤。约束排除（constraint exclusion）利用表/分区 CHECK 约束在计划阶段跳过不可能含数据的分区。

## 三、形式化与数学基础
等价类 $E = \{c_1, c_2, \dots\}$ 中任意两列等价：
$$ \forall c_i, c_j \in E,\; c_i \equiv c_j $$
由此生成派生谓词集合，使选择率估计可下推到每个基表，减少中间结果：
$$ card = N \cdot \prod sel(derived\_pred) $$

## 四、代码实现
```sql
-- 分区表约束排除
EXPLAIN SELECT * FROM logs_2024
WHERE partition_key = '2024-03';
-- 仅扫描相关分区
```

## 五、与其他技术对比
PostgreSQL 的 partition pruning 与 constraint exclusion 利用等价约束；MySQL 8.0 分区裁剪类似。OR 条件的等价推导更复杂，部分优化器支持有限。

## 六、常见误区
认为 JOIN 条件只在连接时用——等价推导可把它转成单表过滤。认为函数包裹列不影响下推——如 `WHERE YEAR(d)=2024` 常无法利用 d 索引或剪枝。

## 七、与开源书/权威来源对应
Garcia-Molina 12.4「Transformation of Relational Expressions」；PostgreSQL 文档「Constraint Exclusion」。

## 八、面试题
问：等价类对优化的作用？答：派生新谓词、提前过滤、分区剪枝、改善估计。

## 九、演进与趋势
更通用的约束推理（含范围、包含约束）与机器学习辅助谓词推导提升剪枝率。

## 十、小结
等价约束把分散的等值条件汇成推导力，是谓词下推与剪枝的基础。
