# 后缀数组求解最长重复子串

> 对应 Manber《Suffix Arrays》。

## 一、背景与挑战
最长重复子串（Longest Repeated Substring）指在原串中至少出现两次（不重叠或重叠依定义）的最长子串。暴力枚举子串是 $O(n^3)$，后缀数组 + LCP 可降至线性。

## 二、核心原理
字典序相邻的后缀拥有最长的公共前缀。因此全局最长重复子串必然出现在某对相邻后缀的 LCP 中，只需扫描高度数组取最大值。

## 三、形式化与数学基础
设 $LRS=\max_{1\le i<n} lcp[i]$。因为非相邻后缀的 LCP 不超过其区间内相邻对的 LCP 最小值，最大值一定在相邻处取到：
$T(n)=O(n)$（构造 SA 与 LCP 后线性扫描）。

## 四、代码实现
```python
def longest_repeated_substring(s):
    sa = sa_is(list(map(ord, s)), 255)
    lcp = build_lcp(s, sa)
    best = 0
    start = 0
    for i in range(1, len(s)):
        if lcp[i] > best:
            best = lcp[i]
            start = sa[i]
    return s[start:start + best]
```

## 五、与其他技术对比
相比动态规划 $O(n^2)$ 或后缀自动机，后缀数组法直观且易调试。要求不重叠时可加约束 $|SA[i]-SA[j]|\ge best$。

## 六、常见误区
误以为最大值可能在非相邻后缀间：由 LCP 区间的单调性质，区间最小值不超过相邻最小值，故全局最大必在相邻处。另一误区是忘记返回起点需用 $SA[i]$。
