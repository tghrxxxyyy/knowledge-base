# 后缀数组的倍增构造法

> 对应 Manber《Suffix Arrays》。

## 一、背景与挑战
后缀数组把所有后缀按字典序排序后记录其起始下标。朴素的「排序 n 个后缀」需要 $O(n^2 \log n)$，因为比较一次后缀是 $O(n)$。倍增法用「已经排好长度为 $2^k$ 的前缀」作为键值，把比较降到 $O(1)$，从而高效递推。

## 二、核心原理
第 $k$ 轮用二元组 $(rank[i],\;rank[i+2^k])$ 作为后缀 $i$ 的排序键。当所有键互不相同（即 $rank$ 取值达到 $n-1$）时排序稳定，算法结束。每轮用计数排序或稳定排序，键长翻倍。

## 三、形式化与数学基础
设 $rank_k(i)$ 为后缀 $i$ 在长度 $2^k$ 前缀下的秩。递推关系为：
$rank_{k+1}(i)={\rm argsort}\big(rank_k(i),\,rank_k(i+2^k)\big)$。
排序轮数为 $\lceil\log_2 n\rceil$，每轮 $O(n\log n)$，总复杂度：
$T(n)=O(n\log n)$。

## 四、代码实现
```python
def build_sa(s):
    n = len(s)
    sa = list(range(n))
    rank = list(map(ord, s))
    k = 1
    while k < n:
        sa.sort(key=lambda i: (rank[i], rank[i + k] if i + k < n else -1))
        tmp = [0] * n
        tmp[sa[0]] = 0
        for i in range(1, n):
            prev = (rank[sa[i - 1]], rank[sa[i - 1] + k] if sa[i - 1] + k < n else -1)
            cur = (rank[sa[i]], rank[sa[i] + k] if sa[i] + k < n else -1)
            tmp[sa[i]] = tmp[sa[i - 1]] + (prev < cur)
        rank = tmp
        if rank[sa[-1]] == n - 1:
            break
        k <<= 1
    return sa
```

## 五、与其他技术对比
相比直接快排后缀，倍增法把每轮比较从 $O(n)$ 降到 $O(1)$。相比 SA-IS 的 $O(n)$，倍增法是 $O(n\log n)$，但实现简单、易调试，是竞赛与教学的常用写法。

## 六、常见误区
误以为 `sort` 不稳定也没关系：必须用稳定排序或显式写二元组键，否则同键后缀的相对顺序会错。另一个误区是忘记处理 $i+2^k\ge n$ 的边界，应当用极小值（如 $-1$）补齐。

## 七、与开源书/权威来源对应
Manber《Suffix Arrays》给出后缀数组与排名数组的线性时间思想；CLRS 在「字符串匹配」章节讨论后缀树，倍增法是其实用替代。

## 八、面试题
给定字符串，输出字典序第 k 小的后缀起始位置；或求最长重复子串（配合 LCP）。追问：为什么 $rank$ 收敛到互不相同就停止？

## 九、演进与趋势
现代实现多用 SA-IS 或 DC3 达到线性时间；倍增法因代码短仍是笔试首选。并行化与缓存友好的诱导排序是当前研究热点。

## 十、小结
倍增法以 $O(n\log n)$ 构造后缀数组，核心是用长度翻倍的前缀秩做稳定排序键，是理解后缀数组的基石算法。
