# 监控告警体系与 SLO 实战

可观测性（Observability）由三大支柱构成：日志（Logs）、指标（Metrics）、链路追踪（Traces）。
SLO（Service Level Objective）用量化目标驱动可靠性建设。
本文讲解监控体系、指标类型、SLO/SLI/错误预算、告警设计与 OnCall 实践。

## 一、可观测性三大支柱

### 1.1 日志（Logs）

- 离散的事件记录，描述"发生了什么"。
- 用于排查具体问题、审计。
- 量大、成本高，需采样与分级。

### 1.2 指标（Metrics）

- 可聚合的数值时间序列（如 QPS、RT、错误率）。
- 适合看趋势、设阈值、做告警。
- 比日志更轻量，是监控主力。

### 1.3 链路追踪（Traces）

- 记录一次请求跨服务的完整调用路径与耗时。
- 用于定位慢调用、依赖故障。
- 通过 TraceId 串联各服务 span。

## 二、指标类型

### 2.1 Counter（计数器）

- 只增不减（如请求总数、错误总数）。
- 配合速率（rate）看单位时间增量。

### 2.2 Gauge（仪表）

- 可增可减的瞬时值（如内存、连接数、在线人数）。

### 2.3 Histogram（直方图）

- 把观测值分桶统计（如响应时间分布）。
- 可算 P50/P95/P99 分位。

### 2.4 Summary

- 类似 Histogram，但直接在客户端计算分位数。

## 三、SLI / SLO / SLA

### 3.1 SLI（Service Level Indicator）

- 服务水平的量化指标，如可用性 = 成功请求 / 总请求。
- 必须可测量、可计算。

### 3.2 SLO（Service Level Objective）

- 对 SLI 设定的目标值，如"月度可用性 ≥ 99.9%"。
- 是内部可靠性承诺，驱动工程投入。

### 3.3 错误预算（Error Budget）

- 允许失败的余量：100% - SLO。
- 99.9% 可用性 → 月允许约 43 分钟不可用。
- 预算用尽则冻结变更、优先稳定性。

### 3.4 SLA（Service Level Agreement）

- 对用户的正式合约，常含违约赔偿。
- SLA 通常比内部 SLO 宽松，留缓冲。

## 四、SLO 落地步骤

1. 选关键用户旅程（如"能否下单成功"）。
2. 定义 SLI（成功比例、延迟达标比例）。
3. 设定 SLO 目标（结合业务容忍度）。
4. 计算错误预算，建立看板。
5. 预算消耗速率触发行动（冻结发布/复盘）。

## 五、告警设计

### 5.1 告警原则

- 告警应"可行动"：收到就要处理，避免狼来了。
- 区分严重级别（P0-P3）。
- 告警需指向责任人（OnCall）。

### 5.2 阈值与异常检测

- 静态阈值：RT > 500ms 触发。
- 同比/环比：相对历史突增。
- 多条件组合：错误率上升且 QPS 正常的组合。

### 5.3 告警收敛

- 去重：同一根因不产生大量重复告警。
- 分组：按服务/主机聚合。
- 抑制：已知故障期间抑制衍生告警。
- 静默：维护窗口内临时屏蔽。

### 5.4 告警疲劳

- 过多无意义告警会让 OnCall 麻木。
- 定期清理低价值告警，提高信噪比。

## 六、OnCall 与事故响应

### 6.1 轮换与升级

- 值班轮换，明确主/备。
- 超时未响应自动升级到上级。

### 6.2 事故分级

- 按影响范围与严重度分级。
- 高优先级事故拉群、成立指挥中心。

### 6.3 复盘（Postmortem）

- 事故后无指责复盘，关注系统与流程。
- 记录时间线、根因、影响、改进项。
- 改进项必须跟踪闭环。

## 七、监控体系分层

- 基础设施层：CPU/内存/磁盘/网络。
- 中间件层：缓存/DB/消息队列连接与延迟。
- 应用层：RT/QPS/错误率/GC。
- 业务层：订单量/支付成功率/核心转化。
- 端到端：用户体验（真实用户监控 RUM）。

## 八、常见坑

- 只有日志没有指标，无法定阈值与趋势。
- 告警无分级，全是 P0 等于没有 P0。
- SLO 设得脱离业务，要么形同虚设要么过度紧张。
- 错误预算用完仍疯狂发版，事故频发。
- 复盘变追责，没人敢说真话。

## 九、速记

- 三支柱：Logs（发生了什么）、Metrics（趋势与阈值）、Traces（调用链）。
- 指标：Counter（只增）、Gauge（瞬时）、Histogram（分布/分位）。
- SLI 可测、SLO 目标、错误预算=100%-SLO、SLA 是合约。
- 告警可行动、分级、收敛、防疲劳。
- OnCall 轮换升级 + 无指责复盘，改进项闭环。
