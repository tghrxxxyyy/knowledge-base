# 池化与不变性

> 对应 d2l-zh 池化层章与 LeCun 1998；Simonyan et al., *VGG*, 2014。

## 一、背景与挑战

卷积捕获局部特征但位置敏感；需要逐步降低分辨率、扩大感受野并获得一定平移不变性。

## 二、核心原理

最大池化：$Y_{i,j} = \max_{a,b \in \Omega} X_{i+a,j+b}$；平均池化取均值。步长通常等于窗口，输出尺寸减半。

## 三、数学形式

下采样因子 $S$：$H_{out} = \lfloor H/S \rfloor$。全局池化把 $H\times W\times C$ 压成 $1\times1\times C$，用于分类头前。

## 四、代码实现

```python
pool = nn.MaxPool2d(2, stride=2)
gap = nn.AdaptiveAvgPool2d(1)
```

## 五、与其他对比

- 最大池化保留显著特征、对纹理敏感；平均池化平滑、抗噪。
- 现代架构（ResNet）用 stride=2 卷积替代池化降采样，保留更多信息。

## 六、常见误区

- 池化不引入参数，但会损失空间精度，对需要像素级定位的任务（分割）要谨慎。
- 过度池化导致小目标消失。

## 七、与开源书对应

- d2l-zh 池化章：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 池化带来平移不变性的代价是什么？答：空间分辨率与定位精度下降。

## 九、演进

固定池化 → 可学习下采样 → 带步长卷积 → 注意力式下采样（如 ViT 的 patch 投影）。

## 十、小结

池化是廉价降维与不变性手段，现代网络中逐渐被带步长卷积与注意力取代，但在轻量模型仍常用。
