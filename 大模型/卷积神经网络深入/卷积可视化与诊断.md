# 卷积可视化与诊断

> 对应 Zeiler & Fergus, *Visualizing CNN*, 2014；Olah et al., *Feature Visualization*, 2017。

## 一、背景与挑战

卷积层学了什么不透明，需要可视化与诊断工具理解、调试与去偏。

## 二、核心原理

反卷积/上采样把激活映射回像素空间；显著图（saliency）用梯度 $\partial y/\partial x$ 指示重要像素；特征最大化优化输入使某通道激活最大。

## 三、数学形式

类别显著图：$S_c(x) = |\nabla_x \log p(y=c|x)|$，逐像素衡量敏感度。

## 四、代码实现

```python
x.requires_grad_(True)
logit = model(x)[0, c]
grad = torch.autograd.grad(logit, x)[0]
saliency = grad.abs().max(1)
```

## 五、与其他对比

- 梯度显著图快但仅一阶；积分梯度（Integrated Gradients）缓解饱和问题。
- 特征可视化解释单通道，显著图解释单样本决策。

## 六、常见误区

- 显著图高亮区域不等于因果；对抗扰动可误导显著图。
- 可视化结果依赖优化技巧，可能显示非自然模式。

## 七、与开源书对应

- d2l-zh 中无专门章，参考 annotated-transformer 注意力可视化思路。
- 机制可解释性深入 提供大模型侧对照。

## 八、面试题

- 显著图与特征可视化的区别？答：前者解释单个预测，后者解释某个神经元/通道。

## 九、演进

反卷积 → 显著图 → 积分梯度 → 特征最大化 → 概念激活向量（TCAV）。

## 十、小结

可视化是诊断 CNN 黑箱的基础手段，也是机制可解释性在大模型上的前身。
