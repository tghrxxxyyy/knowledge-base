# 经典架构演进

> 对应 d2l-zh 现代卷积网络章；He et al., *Deep Residual Learning*, 2016 (ResNet)。

## 一、背景与挑战

网络加深后梯度消失/退化，准确率反而下降，需结构创新支撑极深网络。

## 二、核心原理

ResNet 残差块：$y = F(x, \{W_i\}) + x$（恒等 shortcut），使优化目标变为逼近残差 $F$，缓解退化。

## 三、数学形式

层数 $L$：普通网络误差 $\mathcal{E}(L) \ge \mathcal{E}(L-1)$；残差网络可让新增层学恒等映射（$F=0$），保证不退化。

## 四、代码实现

```python
class Block(nn.Module):
    def forward(self, x):
        return self.conv2(self.bn1(self.relu(self.conv1(x)))) + x
```

## 五、与其他对比

- VGG：仅 3×3 堆叠，深至 19 层；ResNet 引入 shortcut 至 152 层。
- DenseNet：跨层稠密连接，复用特征、参数更少但显存更高。

## 六、常见误区

- 误以为更深一定更好；实际需配合归一化、初始化与学习率。
- shortcut 维度不匹配时才用 1×1 投影，否则直接相加。

## 八、面试题

- 残差为什么能训更深？答：恒等捷径提供梯度直通路，残差易学零。

## 九、演进

AlexNet → VGG → GoogLeNet/Inception → ResNet → DenseNet → EfficientNet(复合缩放) → ConvNeXt。

## 十、小结

残差连接是现代深网络的通用组件，也迁移到 Transformer 的残差子层设计。
