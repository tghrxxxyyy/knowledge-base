# 卷积运算与感受野

> 对应 d2l-zh 卷积神经网络章与 LeCun et al., *Gradient-Based Learning*, 1998；Krizhevsky et al., *AlexNet*, 2012。

## 一、背景与挑战

全连接层对图像参数量爆炸且忽略空间局部性。卷积用局部连接 + 权值共享大幅降参并捕获平移不变特征。

## 二、核心原理

二维卷积：对输入 $X$ 与核 $W$，输出 $(X * W)_{i,j} = \sum_a \sum_b X_{i+a,j+b} W_{a,b}$。
输出尺寸（无填充、步长 1）：$H_{out} = H - K + 1$。带填充 $P$ 与步长 $S$：$H_{out} = \lfloor (H - K + 2P)/S \rfloor + 1$。

## 三、数学形式

多通道：输入 $C_{in}$ 通道，输出 $C_{out}$ 通道，每组一个 $K \times K \times C_{in}$ 核，参数量 $= C_{out} \cdot C_{in} \cdot K^2 + C_{out}$（偏置）。

## 四、代码实现

```python
import torch.nn as nn
conv = nn.Conv2d(3, 64, kernel_size=3, padding=1, stride=1)
```

## 五、与其他对比

- 全连接：参数量 $HWC$ 级；卷积：$C_{out}C_{in}K^2$ 级，且与图像分辨率解耦。
- 感受野：第 $l$ 层感受野 $R_l = R_{l-1} + (K_l-1)\prod_{k<l}S_k$，堆叠小核等效大核但参更少。

## 六、常见误区

- 以为 padding=1 永远保尺寸，仅在 stride=1 时成立。
- 忽视通道方向的计算量（FLOPs 随 $C_{in}C_{out}$ 线性增长）。

## 十、小结
