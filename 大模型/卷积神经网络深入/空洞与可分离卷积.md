# 空洞与可分离卷积

> 对应 d2l-zh 与 Yu et al., *Dilated Convolution*, 2016；Howard et al., *MobileNet*, 2017。

## 一、背景与挑战

标准卷积扩大感受野需降分辨率（丢空间信息）；移动端需极低算力。

## 二、核心原理

空洞（膨胀）卷积：在核元素间插入 $r-1$ 个零，等效核大小 $K' = K + (K-1)(r-1)$，不增加参数即扩大感受野。
深度可分离卷积：先逐通道深度卷积（分组数=通道数），再 1×1 逐点卷积。

## 三、数学形式

深度可分离计算量约为标准卷积的 $1/C_{out} + 1/K^2$，MobileNet 借此降 8–9 倍计算。

## 四、代码实现

```python
dw = nn.Conv2d(c, c, 3, padding=1, groups=c)   # 深度卷积
pw = nn.Conv2d(c, c2, 1)                         # 逐点
```

## 五、与其他对比

- 空洞卷积保分辨率扩感受野，但远处像素可能不连续（网格效应）。
- 可分离卷积大幅降参，代价是表达容量下降，需更深或更宽补偿。

## 六、常见误区

- 空洞率过大导致信息稀疏；常用多尺度空洞（如 1/2/4）组合。
- 可分离卷积并非总是最优，大模型仍用标准卷积。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 深度可分离卷积省了多少计算？答：约 $1/C_{out} + 1/K^2$。

## 九、演进

标准卷积 → 分组卷积 → 深度可分离 → 空洞卷积 → 动态卷积/条件卷积。

## 十、小结

空洞与可分离卷积分别以感受野与参数量为核心优化点，是高效视觉网络的关键构件。
