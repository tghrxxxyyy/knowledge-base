# 知识编辑方法

> 对应 Meng et al., *ROME*, 2022；Mitchell et al., *MEMIT*, 2022。

## 一、背景与挑战

需精准改“某事实”（如“埃菲尔铁塔在巴黎”→“在罗马”）而不破坏整体。

## 二、核心原理

- ROME：在因果中介层（MLP）定位事实存储，用秩一更新修改特定关系方向。
- MEMIT：批量编辑，把多事实写入同一层，保持低秩约束。

## 三、数学形式

秩一更新：$\Delta W = C^{-1} (k v^\top - W k k^\top) / (k^\top C^{-1} k)$，修改键值映射。

## 四、代码实现

```python
# ROME 简化：在定位层做闭式秩一更新
W_new = W + cov_inv @ (k @ v - W @ k @ k) / (k @ cov_inv @ k)
```

## 五、与其他对比

- 超参微调（fine-tune）易灾难性遗忘；ROME 更局部。
- 与 权重初始化理论深入 / 机制可解释性深入 共享定位思想。

## 六、常见误区

- 编辑后泛化有限（仅触发词生效，改写难泛化）。
- 多次编辑累积致性能塌缩。

## 八、面试题

- ROME 如何定位事实？答：因果追踪定位到 MLP 中间层存储，闭式秩一更新。

## 九、演进

fine-tune 编辑 → ROME → MEMIT（批量）→ 持续编辑框架。

## 十、小结

知识编辑以局部闭式更新实现精准纠错，是模型维护的轻量手段。
