# 模型编辑与遗忘总览

> 对应 model editing / machine unlearning 综述；llm-course 安全与对齐部分。

## 一、背景与挑战

训练后需修正错误或删除特定知识（如隐私、版权、有害内容），但全量重训昂贵且不可 granular。

## 二、核心原理

- 模型编辑（editing）：局部修改特定事实/行为，尽量不影响其他能力。
- 机器遗忘（unlearning）：移除某子集数据影响，使模型近似“从未学过”。

## 三、数学形式

遗忘目标：产出 $M'$ 使在保留集 $D_r$ 与遗忘集 $D_f$ 上分布近似从 $D_r$ 重训的模型，且 $\mathcal D(M',D_f)\approx \mathcal D(M_{retrain},D_f)$。

## 四、代码实现

```python
# 近似：对遗忘样本加负梯度方向更新
for x in forget_set: model.step(-lr * grad(model, x))
```

## 五、与其他对比

- 全量重训最可靠但贵；近似遗忘便宜但有残留。
- 与 模型版权许可深入 / 数据隐私与联邦深入 衔接（合规需求）。

## 六、常见误区

- 以为删除样本即遗忘；隐式记忆仍可能泄露（成员推断攻击）。
- 局部编辑引发副作用（相邻知识漂移）。

## 七、与开源书对应

## 八、面试题

- 遗忘与重训的区别？答：遗忘用高效近似逼近重训效果，省算力但有残留风险。

## 九、演进

全量重训 → 数据洗牌重训 → 近似遗忘（梯度上升/蒸馏）→ 认证遗忘。

## 十、小结

模型编辑与遗忘是合规与纠错的关键能力，平衡效率与残留风险是核心难题。
