# 效用与保真权衡

> 对应 unlearning 评估度量研究；与 模型评测指标深入 衔接。

## 一、背景与挑战

遗忘常损害模型整体效用（accuracy drop），需量化“遗忘了多少/保留了多少”。

## 二、核心原理

评估三维：遗忘集错误率上升（忘得好）、保留集精度保持（留得住）、模型分布接近重训（不可区分）。

## 三、数学形式

成员推断差距：$\Delta_{MIA}=|P_{mia}(M',D_f)-P_{mia}(M_{retrain},D_f)|$ 越小越不可区分。

## 四、代码实现

```python
forget_err = 1 - acc(model, forget_set)
retain_err = 1 - acc(model, retain_set)
```

## 五、与其他对比

- 重训在三者都最优；近似法在遗忘与保留间权衡。
- 与 泛化理论深入 共享权衡分析框架。

## 六、常见误区

- 只看遗忘集错误率，忽视保留集塌缩。
- 用弱成员推断评估“不可区分”致乐观。

## 八、面试题

- 遗忘评估看哪些指标？答：遗忘集错误、保留集精度、相对重训的不可区分度。

## 九、演进

单指标 → 多维评估 → 认证度量。

## 十、小结

遗忘须三元评估，任何单指标都可能掩盖副作用。
