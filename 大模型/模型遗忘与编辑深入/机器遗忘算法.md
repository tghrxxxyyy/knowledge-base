# 机器遗忘算法

> 对应 Bourtoule et al., *SISA*, 2021；Graves et al., *Amnesic* 等。

## 一、背景与挑战

GDPR 等法规要求“被遗忘权”；需从已训模型中剔除特定用户/样本影响。

## 二、核心原理

- SISA：把训练集分片独立训多子模型，遗忘时仅重训受影响分片。
- 梯度上升/负学习：对遗忘样本反向更新使损失增大。
- 遗忘蒸馏：用保留集蒸馏出近似重训模型。

## 三、数学形式

负梯度更新：$\theta \leftarrow \theta - \eta \nabla_\theta \mathcal L(\theta, D_f)$；多次迭代近似擦除。

## 四、代码实现

```python
for x in forget:
    theta = theta - lr * grad_loss(theta, x)   # 梯度上升
```

## 五、与其他对比

- SISA 查询时聚合分片，遗忘快但训练与存储成本高。
- 近似法便宜但难达“不可区分重训”的强标准。

## 六、常见误区

- 认为梯度上升足够；残留信息可被成员推断恢复。
- 忽视遗忘对保留集精度的连带影响。

## 八、面试题

- SISA 怎么加速遗忘？答：分片独立训练，遗忘只重训相关分片而非全量。

## 九、演进

全量重训 → SISA → 近似梯度法 → 认证遗忘（可证明）。

## 十、小结

机器遗忘在合规驱动下成为刚需，分片与近似是两大主流路线。
