# 多模态对话

> 对应 LLaVA / mPLUG / Qwen-VL 等多模态对话模型；Flamingo 少样本对话。

## 一、背景与挑战

让模型在 multi-turn 中结合图像与历史回答，需处理交错图文与指代。

## 二、核心原理

多模态对话在输入序列中交织图像 token 与文本 token，模型自回归生成回答；常支持多图、上下文指代、以及“指代人/物”的 grounding（边界框）能力。

## 三、数学形式

对话条件生成：

$$p(a_t | I_1..I_k, u_1..u_m, a_{<t})$$

$u$ 为历史话语，$I$ 为图像。

## 四、代码实现

```python
conv = [img_token(i1), "问1", ans1, img_token(i2), "问2"]
resp = model.generate(conv)
```

## 五、与其他对比

- 与 多模态指令数据 共享数据形态。
- 与 视觉问答与推理深入 对照单轮 VQA。

## 六、常见误区

- 多图位置错乱致指代失败。
- 对话历史过长溢出上下文。

## 七、与开源书对应

- datawhalechina/llm-universe：https://github.com/datawhalechina/llm-universe
- mlabonne/llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- 多模态对话难在哪？答：需维持图文交错的上下文与跨轮指代一致性。

## 九、演进

单图单轮 → 多图 → 带 grounding 的对话。

## 十、小结

多模态对话把图像与语言统一进对话流，是助手型应用的核心。
