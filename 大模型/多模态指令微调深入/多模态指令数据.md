# 多模态指令数据

> 对应 Liu et al., *LLaVA*, NeurIPS 2023（用 GPT-4 生成多模态指令数据）；多模态 SFT 数据构建。

## 一、背景与挑战

LLM 指令微调已有成熟范式，但多模态需要“图像-指令-回答”三元数据，获取昂贵。

## 二、核心原理

做法：用强模型（如 GPT-4V）基于图像描述/标注生成多样的指令-回答对（对话、详细描述、复杂推理）；或与纯文本指令数据混合训练以保语言能力。

## 三、数学形式

指令微调似然：

$$\mathcal L = -\sum_t \log p_\theta(a_t | a_{<t}, I, q)$$

$I$ 为图像表示，$q$ 为指令。

## 四、代码实现

```python
samples = build_mm_instructions(images, gpt4v)
train(model, samples + text_only_instructions)
```

## 五、与其他对比

- 与 视觉指令对齐 衔接（数据→对齐）。
- 与 多模态对话 共享数据形态。

## 六、常见误区

- 纯多模态数据训练致语言能力退化，需混合文本。
- 合成数据偏见被模型继承。

## 八、面试题

- 为何要混合文本指令？答：防多模态训练损害原有语言与推理能力，保持通用性。

## 九、演进

人工标注 → GPT-4 合成 → 自博弈扩充。

## 十、小结

多模态指令数据常以强模型合成，混合文本数据是稳定训练的关键。
