# 多模态指令微调方法

> 对应全参 SFT / LoRA；多模态阶段的参数高效微调。

## 一、背景与挑战

多模态微调易灾难遗忘或算力爆炸；需选择冻结策略与微调范围。

## 二、核心原理

两阶段常见：阶段一仅训练视觉-语言投影（对齐），阶段二用 LoRA 微调 LLM 或全参指令微调。LoRA 在注意力/FFN 注入低秩适配，省显存保原权。

## 三、数学形式

LoRA 适配：

$$W' = W_0 + \Delta W = W_0 + BA,\quad B\in\mathbb R^{d\times r}, A\in\mathbb R^{r\times k}$$

$r\ll d$ 为低秩。

## 四、代码实现

```python
model = inject_lora(llm, r=16, target="q,k,v,o")
train(model, mm_instructions, freeze_backbone=True)
```

## 五、与其他对比

- 与 多模态指令数据 衔接（数据→训练）。
- 与 视觉指令对齐 共享阶段划分。

## 六、常见误区

- 阶段一/二数据混用致对齐不稳。
- LoRA 秩过小欠拟合、过大失高效。

## 八、面试题

- 为何两阶段？答：先对齐模态再学指令，避免未对齐直接微调污染 LLM。

## 九、演进

全参 → 冻 LLM 训投影 → LoRA 部分微调。

## 十、小结

多模态指令微调以两阶段+参数高效为主流，平衡对齐与成本。
