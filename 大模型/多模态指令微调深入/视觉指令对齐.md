# 视觉指令对齐

> 对应 LLaVA 阶段一（特征对齐预训练）；视觉-语言投影对齐。

## 一、背景与挑战

CLIP 视觉空间与 LLM 词嵌入空间分布不同，直接拼接效果差，需先对齐。

## 二、核心原理

用“图像-描述”对（如 COCO caption）训练投影层，使图像 token 经投影后落在 LLM 可理解的语义空间，使 LLM 能“读懂”图像 token 并续写描述。

## 三、数学形式

对齐损失（自回归语言建模）：

$$\mathcal L = -\sum_t \log p_\theta(c_t | c_{<t}, h_v)$$

$c$ 为图像描述文本，$h_v$ 为投影后视觉 token。

## 四、代码实现

```python
for img, cap in caption_pairs:
    hv = proj(vision(img))
    loss = lm_loss(llm, hv, cap)
```

## 五、与其他对比

- 与 LLaVA类架构 衔接（实现该架构的对齐阶段）。
- 与 指令微调方法 共享两阶段。

## 六、常见误区

- 跳过对齐直接指令微调，模型读不懂图像。
- 用错文本（非描述）做对齐目标。

## 八、面试题

- 对齐阶段作用？答：把视觉表示映射到 LLM 语义空间，使后续指令微调有效。

## 九、演进

无对齐 → 投影对齐 → Q-Former 瓶颈对齐。

## 十、小结

视觉指令对齐是连接视觉与语言模型的必要前置，常以 caption 对完成。
