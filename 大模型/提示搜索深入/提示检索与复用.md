# 提示检索与复用

> 对应检索式提示（Retrieval-of-Prompts）；与 提示搜索总览 衔接。

## 一、背景与挑战

新任务可借鉴历史相似提示，不必从零设计。

## 二、核心原理

把历史提示（含任务、效果）入库，新任务按语义检索最相关提示作 few-shot 或模板起点。

## 三、数学形式

检索 $p^*=\arg\max_{p\in DB} \cos(e(task), e(p))$$；复用其模板与示例。

## 四、代码实现

```python
sims = embed(task) @ embed(prompts_db).T
top = prompts_db[sims.argmax()]
```

## 五、与其他对比

- 与 语义缓存深入（按查询复用答案）对照（这里复用提示）。
- 与 提示版本与协作（库）共享。

## 六、常见误区

- 检索到相似但任务语义偏差的提示。
- 复用未验证直接上生产。

## 七、与开源书对应

## 八、面试题

- 提示检索与语义缓存区别？答：前者复用提示模板，后者复用答案，对象不同。

## 九、演进

手写 → 检索复用 → 检索+微调模板。

## 十、小结

提示检索把历史经验变资产，新任务快速冷启动。
