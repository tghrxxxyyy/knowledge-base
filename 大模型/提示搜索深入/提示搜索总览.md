# 提示搜索总览

> 对应 Shin et al., *AutoPrompt*, 2020；Deng et al., *RLPrompt*, 2022（自动提示搜索）。

## 一、背景与挑战

人工设计提示耗力且非最优；可从数据中自动搜索高效提示模板。

## 二、核心原理

把提示视为可优化变量，在任务数据上搜索/生成使模型表现最佳的模板（离散或连续）。

## 三、数学形式

目标 $\max_{p\in\mathcal P} \mathbb E_{(x,y)}[\log P_\theta(y\mid p\oplus x)]$；$p$ 可为 token 序列。

## 四、代码实现

```python
best = None
for cand in prompt_candidates:
    s = eval_task(model, cand)
    best = cand if s > best_score else best
```

## 五、与其他对比

- 与 提示版本深入（搜索结果即版本）衔接。
- 与 提示集成深入（多提示搜索）互补。

## 六、常见误区

- 搜索只在训练分布有效、线上泛化差。
- 离散搜索空间过大难穷举。

## 八、面试题

- 自动提示搜索为何有用？答：在数据上优化模板常超人手写，发现非直观有效模式。

## 九、演进

手写 → 离散搜索(AutoPrompt) → 强化/连续提示。

## 十、小结

提示搜索把提示当可优化变量，自动化发现高效模板。
