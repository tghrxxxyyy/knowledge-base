# 提示自动优化搜索

> 对应 Zhou et al., *Automatic Prompt Engineering (APE)*, 2022；RLPrompt, 2022。

## 一、背景与挑战

搜索空间大，需高效优化而非穷举。

## 二、核心原理

用模型生成候选提示、再在验证集评估、选优（可迭代改进，类似 APE 的“生成-评分-选优”）；RL 可优化离散提示。

## 三、数学形式

迭代 $p_{t+1}=mutate(p_t)$ 使 $score(p_{t+1})>score(p_t)$；收敛到局部优。

## 四、代码实现

```python
for _ in range(iters):
    cands = model.generate(prompts=mutate(p))
    p = best(cands, key=eval)
```

## 五、与其他对比

- 与 提示版本评估（评分驱动）互补。
- 与 提示集成深入（搜索多提示再集成）衔接。

## 六、常见误区

- 在验证集过拟合，线上掉点。
- 优化目标与真实业务不一致。
