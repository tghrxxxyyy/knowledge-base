# 提示库构建

> 对应 Prompt Hub / 提示资产管理；提示版本与协作 衔接。

## 一、背景与挑战

提示散落难检索，需结构化库支撑搜索与复用。

## 二、核心原理

每条提示带元数据（任务类型、模型、指标、版本）；嵌入任务描述做语义索引；支持标签与过滤。

## 三、数学形式

库 $DB=\{(p_i, m_i, e_i)\}$；检索谓词 $filter(m)\wedge topk(e)$。

## 四、代码实现

```python
db.add(prompt, meta={"task":"qa","model":"gpt-4o","acc":0.91})
```

## 五、与其他对比

- 与 向量检索算法深入（索引底座）共享。
- 与 提示搜索深入 总览互补。

## 六、常见误区

- 元数据缺失致无法有效过滤。
- 库只增不删，劣质提示污染检索。
