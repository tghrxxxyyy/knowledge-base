# 提示搜索实践

> 对应生产提示优化管线；提示版本深入 / 模型评测指标深入 衔接。

## 一、背景与挑战

搜索需成本可控且有防过拟合护栏。

## 二、核心原理

限定搜索预算（候选数/迭代）；用独立验证集与保留集双重评估；落库为版本并 A/B 验证。

## 三、数学形式

预算 $B=\#cands\times iters$；泛化差 $\Delta_{gen}=score_{val}-score_{holdout}$。

## 四、代码实现

```python
with budget(B):
    best = search_prompts(model, trainset)
assert eval(best, holdout) > baseline
```

## 五、与其他对比

- 与 提示A/B测试（最终验证）衔接。
- 与 提示版本管理（落库）互补。

## 六、常见误区

- 搜索未用保留集，线上翻车。
- 预算失控，搜索成本超收益。

## 八、面试题

- 提示搜索如何防过拟合？答：独立验证+保留集双重评估，限定预算，最终 A/B。

## 九、演进

无护栏 → 验证集 → 验证+保留+预算。

## 十、小结

提示搜索实践靠预算与护栏，平衡收益与过拟合风险。
