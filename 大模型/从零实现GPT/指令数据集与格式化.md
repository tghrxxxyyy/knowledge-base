# 指令数据集与格式化

> 对应 LLMs-from-scratch 第7章。把 SFT 数据拼成模型训练样本。

## 一、核心概念

指令数据通常含 instruction / input / output。需按**对话模板**拼接为单一 token 序列，并标记仅 output 计算 loss（见「指令微调 SFT」文档）。常见模板：

```
### Instruction:
{instruction}
### Input:
{input}
### Response:
{output}
```

需给 output 段加入 EOS 并设 loss mask。

## 二、代码要点

```python
# 拼接后计算 labels，prompt 部分置 -100
full = tok(prompt + response + eos)
labels = [-100]*len(tok(prompt)) + tok(response + eos)
```

## 三、关键要点

- 模板在训练与推理必须一致。
- EOS 标记对话结束。
