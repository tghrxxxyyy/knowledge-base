# 简单分类微调

> 对应 rasbt/LLMs-from-scratch 第6章（Fine-tuning for Classification）、HuggingFace Transformers 文档。

## 一、背景与挑战

除了生成，GPT 底座也能做判别式任务（情感分析、主题分类、 spam 识别）。做法是"取最后位置隐状态 + 线性分类头"。难点：分类头接在哪一层/哪个位置影响效果；是否微调全部参数还是只训头需在数据与显存间权衡；序列截断会丢失尾部关键信息（如结尾的情感词）；与生成式 SFT 的目标函数不同（交叉熵分类 vs 语言建模）；类别不均衡时朴素交叉熵会偏向多数类，需加权或重采样；其六**标签敏感性**，分类头权重初始化与类别顺序可能轻微影响收敛，需固定随机种子对比。

## 二、核心原理

在预训练 GPT 上接一个 `nn.Linear(d_model, n_classes)`。前向时取**最后位置**的隐状态 $h_{T}$（它经自注意力聚合了整条序列信息），送入分类头得 logits，softmax 得类别分布。训练用标准多类交叉熵。小数据可"冻结主干、只训头"；数据稍多则全量微调（或 LoRA）提升上限。Causal mask 下最后位置能看到全部前文，是天然的句子表征。类别不均衡时给损失加类别权重 $w_c$。也可对所有位置做 mean/max 池化得到更稳表征，避免仅依赖尾部 token。

## 三、形式化与数学基础

设输入序列 $x_{1:T}$，GPT 输出隐状态 $H=(h_1,\dots,h_T)\in\mathbb{R}^{T\times d}$。分类头：

$$\hat{y} = \text{softmax}(W_c\,h_T + b_c),\quad W_c\in\mathbb{R}^{n\times d}$$

损失为带类别权重的标签 $y$ 的交叉熵：

$$\mathcal{L}_{\text{cls}} = -w_y\log \hat{y}_y = -w_y\log \frac{\exp(W_c^{(y)} h_T + b_c^{(y)})}{\sum_{k}\exp(W_c^{(k)} h_T + b_c^{(k)})}$$

对比生成式 SFT 的逐位置语言建模损失，分类只在 $[T]$ 一个位置监督。池化变体用 $\bar{h}=\frac{1}{T}\sum_t h_t$ 替代 $h_T$，对长度变化更鲁棒。

## 四、代码实现

```python
import torch.nn as nn
import torch.nn.functional as F

class GPTClassifier(nn.Module):
    def __init__(self, gpt, n_classes, pool="last"):
        super().__init__()
        self.gpt = gpt
        self.head = nn.Linear(gpt.cfg.d_model, n_classes)
        self.pool = pool
    def forward(self, idx):
        h = self.gpt(idx)                       # (B,T,d)
        rep = h[:, -1, :] if self.pool == "last" else h.mean(1)
        return self.head(rep)

# 训练（含类别权重应对不均衡）
weights = torch.tensor([1.0, 3.0])              # 少数类加权
```

## 六、常见误区

- **取错位置**：用首个而非最后位置，信息不全。
- **截断丢尾部**：关键情感词在末尾却被截断。
- **分类头 lr 过大**：主干已好，头震荡。
- **与生成 SFT 混用同一头**：任务头与 LM 头应分开。
- **忽略类别不均衡**：朴素交叉熵偏向多数类。
- **标签顺序随意**：类别重排未固定种子，结果难复现。

## 九、演进与趋势

从"最后位置"走向"池化所有位置"（mean/max pooling）；指令式分类用自然语言标签提升零样本；表征学习（如 SimCSE）与分类头解耦；LoRA/QLoRA 让分类适配在单卡完成；用对比学习预训练句向量再接轻量头成为高效范式，并缓解对尾部 token 的过度依赖。

## 十、小结

分类微调的本质是"GPT 当编码器 + 一个线性头"。最后位置隐状态天然聚合全序列，是接头的天然锚点；冻结还是全量取决于数据规模，类别权重处理不均衡、池化提升鲁棒，是这条派生任务的上手首选。
