# 简单分类微调

> 对应 LLMs-from-scratch 第6章「Fine-tuning for Classification」。在预训练底座上加分类头。

## 一、核心概念

把 GPT 的语言模型头替换为任务特定头（如对情感分类输出 2 类）。做法：取最后位置隐状态 → 线性层 → softmax。仅分类头或小学习率微调全部参数。

```python
class GPTClassifier(nn.Module):
    def __init__(self, gpt, n_classes):
        super().__init__()
        self.gpt = gpt
        self.head = nn.Linear(gpt.cfg.d_model, n_classes)
    def forward(self, idx):
        h = self.gpt(idx)              # (B,T,d)
        return self.head(h[:, -1, :])   # 取最后位置
```

## 二、关键要点

- 「最后位置」承载序列整体信息。
- 分类头 LR 可略大于主干。
