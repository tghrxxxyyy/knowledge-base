# 多头注意力实现

> 对应 rasbt/LLMs-from-scratch 第3章、Vaswani et al. 2017（Attention Is All You Need）。

## 一、背景与挑战

单头注意力只能学到一种"关注模式"，表达能力受限。Transformer 用多头注意力让模型在不同子空间并行关注不同位置关系（如局部句法、长程指代）。从零实现时最大的工程难点是张量维度重排：如何把 `d_model` 高效地拆成 `n_heads × head_dim`，并行计算后再拼回，而不写低效的 Python 循环。另一个常被忽视的点是**注意力分数随序列长度平方增长**的内存占用，长上下文时需配合分块或 FlashAttention。

## 二、核心原理

标准做法：用一次线性层同时算出全部 Q/K/V，再把最后一维 `reshape` 为 `(n_heads, head_dim)`，经 `transpose(1,2)` 把 head 维搬到 batch 维，使每个 head 变成独立"批次"。各 head 独立做缩放点积注意力，输出再 `transpose` 回去、`reshape` 拼接，最后经输出投影 $W^O$。因果掩码保证第 $i$ 个位置只能看 $\le i$ 的位置。注意 `head_dim` 通常取 64（与原始论文一致），`d_model` 须为 `n_heads × head_dim` 的整数倍。

## 三、形式化与数学基础

缩放点积注意力：

$$\text{Attention}(Q,K,V)=\text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

多头注意力把 $Q,K,V$ 沿特征维线性投影 $h$ 次并并行计算：

$$\text{MultiHead}(Q,K,V)=\text{Concat}(\text{head}_1,\dots,\text{head}_h)W^O$$

$$\text{head}_i=\text{Attention}(QW_i^Q,\,KW_i^K,\,VW_i^V)$$

其中 $W_i^Q\in\mathbb{R}^{d_{\text{model}}\times d_k}$，$d_k=d_{\text{model}}/h$。除以 $\sqrt{d_k}$ 是为抵消点积方差随维度增长而爆炸——若不除，softmax 进入饱和区、梯度趋近于零。

## 四、代码实现

```python
import torch
import torch.nn as nn

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_heads, ctx_len, dropout=0.0):
        super().__init__()
        assert d_model % n_heads == 0
        self.d_model, self.n_heads = d_model, n_heads
        self.head_dim = d_model // n_heads
        self.W_qkv = nn.Linear(d_model, 3 * d_model)   # 一次出全部 QKV
        self.W_o   = nn.Linear(d_model, d_model)
        self.drop  = nn.Dropout(dropout)
        self.register_buffer("mask", torch.triu(
            torch.ones(ctx_len, ctx_len), diagonal=1).bool())

    def forward(self, x):
        B, T, _ = x.shape
        qkv = self.W_qkv(x).chunk(3, dim=-1)            # 各 (B,T,d_model)
        q, k, v = [t.view(B, T, self.n_heads, self.head_dim).transpose(1, 2)
                   for t in qkv]                        # 各 (B,h,T,hd)
        scores = (q @ k.transpose(-2, -1)) / self.head_dim ** 0.5
        scores.masked_fill_(self.mask[:T, :T], -torch.inf)
        attn = self.drop(scores.softmax(-1))
        out = (attn @ v).transpose(1, 2).reshape(B, T, self.d_model)
        return self.W_o(out)
```

## 五、与其他技术对比

| 维度 | 单头 | 循环多头 | 一次投影多头 |
|------|------|----------|--------------|
| 并行度 | 低 | 低（Python 循环） | 高（张量并行） |
| 显存 | 少 | 多 | 集中 |
| 效率 | 差 | 差 | 优 |

工程上几乎都用"一次线性出全部 QKV，再 split 到各头"，与循环多头数学等价但更快。推理时还需缓存 K/V（KV-cache）避免重复计算历史位置。

## 六、常见误区

- **`n_heads` 不整除 `d_model`**：`reshape` 失败，应先断言。
- **忘记因果掩码**：训练时未来信息泄漏，推理必崩。
- **$\sqrt{d_k}$ 漏除**：点积过大致 softmax 饱和、梯度消失。
- **head 维未搬 batch 维**：逐头循环实现，速度慢数个数量级。
- **推理未用 KV-cache**：每步重算全序列，复杂度退化到 $O(T^2)$。

## 九、演进与趋势

FlashAttention 把 softmax 与掩码融合进核函数，消除显存瓶颈；分组查询注意力（GQA）与多查询注意力（MQA）在推理时共享 K/V 头以降低 KV-cache；旋转位置编码（RoPE）逐步取代绝对位置嵌入。从零实现可作为理解这些优化的地基，头数配置也随模型规模演变（小模型头少、大模型头多）。

## 十、小结

多头注意力的精髓在"张量重排 + 并行缩放点积 + 因果掩码"。一次投影再 split 的实现既正确又高效，缩放因子保数值稳定，是所有现代 LLM 注意力的共同骨架；推理侧 KV-cache 与 GQA 则是工程落地的关键补充。
