# 多头注意力实现

> 对应 LLMs-from-scratch 第3章。把单头扩展为多头的张量重排技巧。

## 一、核心概念

多头注意力 = 把 `d_model` 拆成 `n_heads × head_dim`，并行算 `n_heads` 个单头注意力，再拼接经 `W^O` 投影。实现关键在于 `view/transpose` 把 голов维度放到 batch 维。

## 二、代码实现

```python
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_heads, ctx_len):
        super().__init__()
        self.heads = nn.ModuleList(
            [CausalSelfAttention(d_model, 1, ctx_len) for _ in range(n_heads)])
        # 实际实现常直接一次 QKV 拆分多头，见上节
    def forward(self, x):
        return torch.cat([h(x) for h in self.heads], dim=-1)
```

> 工程上更常见的是「一次线性出全部 QKV，再 split 到各头」（见上一节实现），两种等价，后者更高效。

## 三、关键要点

- `n_heads` 必须整除 `d_model`。
- 各头共享投影还是独立投影：标准 Transformer 用独立 `W_i^Q/K/V`。
