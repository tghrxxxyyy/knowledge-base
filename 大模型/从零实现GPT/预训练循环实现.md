# 预训练循环实现

> 对应 LLMs-from-scratch 第5章「Pretraining on Unlabeled Data」。完整的训练步。

## 一、核心概念

预训练即标准的自回归交叉熵优化。每步：取 batch → 前向得 logits → `cross_entropy(logits.view(-1,V), targets.view(-1))` → 反向 → 梯度裁剪 → 更新。常用 **梯度裁剪(clip_grad_norm_)** 防止不稳定。

```python
optimizer = torch.optim.AdamW(model.parameters(), lr=3e-4)
for x, y in loader:
    logits = model(x)
    loss = F.cross_entropy(logits.view(-1, V), y.view(-1))
    loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
    optimizer.step(); optimizer.zero_grad()
```

## 二、关键要点

| 项 | 推荐 |
|----|------|
| 优化器 | AdamW |
| LR | 3e-4 (小模型) |
| 梯度裁剪 | 1.0 |
| 精度 | 大模型用 bf16/AMP |

## 三、常见误区

- 忘记 `zero_grad`，梯度累积出错。
- 训练初期未 warmup 导致 loss 尖刺。
