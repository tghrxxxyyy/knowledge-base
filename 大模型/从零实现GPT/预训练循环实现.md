# 预训练循环实现

> 对应 rasbt/LLMs-from-scratch 第5章、Kaplan et al. 2020（Scaling Laws）、Hoffmann et al. 2022（Chinchilla）、Loshchilov & Hutter 2019（AdamW）。

## 一、背景与挑战

预训练是"在海量无标注文本上做自回归交叉熵"的规模化工程。循环本身不复杂，但要让大模型稳定训起来需多项技巧：梯度裁剪防尖刺、学习率 warmup + 余弦衰减、混合精度（bf16/AMP）省显存、梯度累积弥补小 batch。难点在于这些超参与数据规模强耦合，配错即不收敛或浪费算力；分布式下还要处理数据并行、梯度同步与断点续训（checkpointing）；其六**超参耦合**，学习率峰值与有效 batch 大小需随规模同调，否则同样的数据量收敛质量差异巨大。

## 二、核心原理

每步：取 batch → 前向得 logits → `cross_entropy(logits.view(-1,V), targets.view(-1))` → 反向 → `clip_grad_norm_` 防爆炸 → 更新。优化器用 **AdamW**（解耦权重衰减）。学习率先 warmup 若干步再余弦降到接近 0。大模型用 bf16 混合精度，梯度累积把多个 micro-batch 的梯度求和再更新，等效大 batch。断点需同时保存优化器状态与 RNG 种子，保证可复现续训。大规模用 3D 并行（数据/张量/流水线）横向扩展。

## 三、形式化与数学基础

自回归损失对序列 $x_{1:T}$：

$$\mathcal{L} = -\sum_{t=1}^{T}\log P_\theta(x_t\mid x_{<t})$$

AdamW 更新（解耦衰减）：

$$\theta_{t+1} = \theta_t - \eta\left(\frac{\hat{m}_t}{\sqrt{\hat{v}_t}+\epsilon} + \lambda\theta_t\right)$$

其中 $\lambda$ 为权重衰减、$\hat{m}_t,\hat{v}_t$ 为偏置校正的一/二阶矩。Scaling Laws 给出损失随参数量 $N$、数据量 $D$、算力 $C$ 的幂律：$L\propto N^{-\alpha}$；Chinchilla 进一步指出现代训练应让 $N$ 与 $D$ 约等比增长（token 数≈20×参数量），而非盲目堆参数。梯度累积使有效 batch $B_{\text{eff}}=B_{\text{micro}}\times\text{steps}$。

## 四、代码实现

```python
import torch, torch.nn.functional as F

optimizer = torch.optim.AdamW(model.parameters(), lr=3e-4, weight_decay=0.1)
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=total_steps)
for step, (x, y) in enumerate(loader):
    if step < warmup:
        optimizer.param_groups[0]["lr"] = 3e-4 * step / warmup
    with torch.autocast("cuda", dtype=torch.bfloat16):     # 混合精度
        logits = model(x)
        loss = F.cross_entropy(logits.view(-1, V), y.view(-1))
    loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)  # 梯度裁剪
    optimizer.step(); optimizer.zero_grad(); scheduler.step()
    if step % 1000 == 0:
        torch.save({"model": model.state_dict(),
                    "opt": optimizer.state_dict(),
                    "rng": torch.get_rng_state()}, f"ckpt_{step}.pt")
```

## 六、常见误区

- **忘记 `zero_grad`**：梯度跨步累积，参数崩坏。
- **无 warmup**：初期大 lr 致 loss 尖刺难恢复。
- **不裁剪梯度**：偶发大梯度让训练发散。
- **bf16 不设好**：溢出或下溢，需检查 scaler/范围。
- **断点不存 RNG**：续训不可复现，实验难比对。
- **lr 与 batch 不耦合**：只升 batch 不调 lr 峰值，收敛变差。

## 九、演进与趋势

从单卡走向**3D 并行**（数据/张量/流水线，Megatron-DeepSpeed）；优化器状态分片（ZeRO）省显存；长上下文与课程学习；以 Chinchilla 最优配比指导预算分配；稳定性技术（如 QK-LayerNorm、z-loss）进一步平滑训练；复用检查点与「先训小模型外推超参」降低大模型试错成本，并把 lr/batch 作为联合超参联合搜索。

## 十、小结

预训练循环 = "交叉熵 + AdamW + 裁剪 + 学习率调度 + 混合精度"。超参与规模强耦合，遵照 Scaling Laws 与 Chinchilla 配比，配合断点续训、梯度累积与 lr/batch 联合调参，才能把算力转化为实打实的智能，而非烧钱空转。
