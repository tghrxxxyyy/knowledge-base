# 数据集与数据加载

> 对应 LLMs-from-scratch 第2章。构建 `(x, y)` 滑动窗口数据集。

## 一、核心概念

语言建模用「下一个字符/token 预测」：把文本切成长度为 `ctx_len` 的窗口，`x` 为前 `ctx_len-1`，`y` 为后移一位。用 `torch.utils.data.Dataset` 实现 `__getitem__`。

```python
class TextDataset(Dataset):
    def __init__(self, ids, ctx_len):
        self.ids = ids; self.ctx_len = ctx_len
    def __len__(self): return len(self.ids) - self.ctx_len
    def __getitem__(self, i):
        x = torch.tensor(self.ids[i:i+self.ctx_len])
        y = torch.tensor(self.ids[i+1:i+1+self.ctx_len])
        return x, y
```

## 二、关键要点

- 训练/验证按文档切分，避免跨文档泄漏。
- `DataLoader` 的 `batch_size` 与 `ctx_len` 决定显存。

## 三、面试题

- 滑动窗口法在大语料上为何会造成样本高度重叠？
