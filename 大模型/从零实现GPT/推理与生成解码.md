# 推理与生成解码

> 对应 LLMs-from-scratch 第4-5章。贪心/采样生成。

## 一、核心概念

生成即自回归循环：给定前缀，模型输出下一个 token 分布，按策略采样/取最大，拼回前缀，直到 EOS 或达最大长度。常用策略：

- **贪心**：每步取 argmax，确定性但易重复。
- **温度采样**：`p = softmax(logits/T)`，`T>1` 更随机。
- **Top-k / Top-p(核采样)**：截断低概率尾部，保多样且合理。

```python
def generate(model, idx, max_new=50, T=1.0, top_k=None):
    for _ in range(max_new):
        logits = model(idx[:, -ctx_len:])
        logits = logits[:, -1, :] / T
        if top_k:
            kth = torch.topk(logits, top_k).values[:, -1:]
            logits[logits < kth] = -inf
        probs = F.softmax(logits, -1)
        next_id = torch.multinomial(probs, 1)
        idx = torch.cat([idx, next_id], dim=1)
    return idx
```

## 二、关键要点

| 策略 | 多样性 | 质量 |
|------|--------|------|
| 贪心 | 低 | 稳定但重复 |
| T高 | 高 | 可能混乱 |
| Top-p | 中高 | 平衡 |

## 三、常见误区

- 未截断上下文到 `ctx_len` 导致位置越界。
- 温度=0 仍用 multinomial 而非 argmax。
