# 指令微调实现

> 对应 LLMs-from-scratch 第7章。在自建 GPT 上跑 SFT。

## 一、核心概念

SFT 训练流程与预训练几乎一致，区别仅在于数据（指令对）和 **loss mask**（仅回答算损失）。学习率通常比预训练小一个量级。

```python
for batch in sft_loader:
    logits = model(batch["input_ids"])
    loss = F.cross_entropy(
        logits.view(-1, V), batch["labels"].view(-1),
        ignore_index=-100)     # 等价于只对非 -100 计算
    loss.backward(); optimizer.step(); optimizer.zero_grad()
```

## 二、关键要点

| 项 | SFT | 预训练 |
|----|-----|--------|
| 数据 | 指令对 | 原始文本 |
| loss | mask 仅回答 | 全序列 |
| LR | 较小 | 较大 |
