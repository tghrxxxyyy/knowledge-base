# 文本表征与词元化实现

> 对应 rasbt/LLMs-from-scratch 第2章「Working with Text Data」。从字符/子词到张量的完整链路。

## 一、核心概念

从零实现 GPT 的第一步是把文本变成模型可吃的整数 id 序列。两种粒度：

- **字符级**：词汇表=字符集，简单但序列长、建模难。
- **子词级(BPE)**：先用 `tiktoken` 或自训练 BPE 得到词表，再编码。

本书采用字符级做教学演示，但生产用 BPE。关键组件：`Tokenizer`（encode/decode）、`Dataset` 把文本切成 `(input, target)` 窗口。

## 二、代码实现（字符级 tokenizer 示意）

```python
import tiktoken  # 生产用 BPE
enc = tiktoken.get_encoding("gpt2")
text = "Hello, GPT from scratch!"
ids = enc.encode(text)
print(ids, enc.decode(ids))

# 教学：字符级
class CharTokenizer:
    def __init__(self, text):
        chars = sorted(set(text))
        self.stoi = {c:i for i,c in enumerate(chars)}
        self.itos = {i:c for i,c in enumerate(chars)}
    def encode(self, s): return [self.stoi[c] for c in s]
    def decode(self, ids): return "".join(self.itos[i] for i in ids)
```

## 三、关键要点

| 步 | 产出 |
|----|------|
| 原始文本 | 字符串 |
| 分词 | token 序列 |
| 编码 | id 张量 |
| 切片 | (x, y) 窗口 |

## 四、常见误区

- 训练/推理用不同 tokenizer 导致词表错位。
- 解码未处理特殊 token（BOS/EOS/PAD）。
