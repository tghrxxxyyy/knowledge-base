# 注意力复杂度与瓶颈

> 对应 Vaswani et al., *Attention Is All You Need*, 2017；与 KV缓存优化深入 衔接。

## 一、背景与挑战

标准注意力显存与序列长 $N$ 平方相关，长上下文训练/推理成瓶颈；HBM 带宽而非算力常成主要限制。

## 二、核心原理

注意力含 $QK^T$（$N\times N$ 分数）、softmax、与 $V$ 加权；显存峰值在 $N^2$ 分数矩阵，需避免物化。

## 三、数学形式

显存 $O(N^2)$、计算 $O(N^2d)$；softmax 沿行需全行可知，构成 IO 难点。

## 四、代码实现

```python
scores = Q @ K.T / math.sqrt(d)     # O(N^2) 物化
attn = softmax(scores) @ V
```

## 五、与其他对比

- 与 稀疏注意力深入（降计算）互补；
- 与 线性注意力深入（降复杂度）对照。

## 六、常见误区

- 以为降 FLOP 即降延迟，忽视 HBM 带宽；
- 长序列下 $N^2$ 分数矩阵直接 OOM。

## 八、面试题

- 注意力瓶颈是算力还是带宽？答：长序列下常是 HBM 带宽与 $N^2$ 显存。

## 九、演进

标准注意力 → 分块 → FlashAttention → 稀疏/线性。

## 十、小结

注意力主要瓶颈在 $N^2$ 显存与带宽，引出 IO 感知算法。
