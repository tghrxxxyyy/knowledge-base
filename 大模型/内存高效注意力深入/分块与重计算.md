# 分块与重计算

> 对应 Dao et al., 2022（tiling + recomputation）。

## 一、背景与挑战

SRAM 小不能放整张 $QK^T$；需切块且反向不存中间以省显存。

## 二、核心原理

前向分块算输出并只存 $O(N)$ 统计量（非 $N^2$ 分数）；反向重算块内注意力，用 checkpoint 换算力换显存。

## 三、数学形式

存储由 $O(N^2)$ 降到 $O(N)$（输出+行统计量），反向额外 $O(N^2d)$ 重算但峰值低。

## 四、代码实现

```python
ctx.save_for_backward(Q, K, V, Out)   # 仅存必要量
# 反向按块重算 scores
```

## 五、与其他对比

- 与 激活重计算深入（Checkpoint）同思路；
- 与 梯度检查点深入 衔接。

## 六、常见误区

- 重算增加 FLOP 却常降总时延（省 HBM）；
- 块大小未依 SRAM 调致不优。

## 八、面试题

- 为何重算反而更快？答：用少量算力换大幅 HBM 节省，带宽受限下总时延降。

## 九、演进

全存 → 选择性 checkpoint → 算子内重算。

## 十、小结

分块+重计算以算力换带宽，是 FlashAttention 显存优势来源。
