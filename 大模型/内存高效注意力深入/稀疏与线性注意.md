# 稀疏与线性注意力

> 对应 Child et al., *Sparse Transformer*, 2019；Katharopoulos et al., *Linear Attention*, 2020。

## 一、背景与挑战

$o(N^2)$ 对极长序列仍贵；稀疏/线性注意力把复杂度降到 $o(N)$ 或 $O(N\sqrt N)$。

## 二、核心原理

稀疏：限制每 query 只看局部/固定模式（滑窗、stride）；线性：把 softmax 改写为核特征 $QK^T V=\phi(Q)(\phi(K)^T V)$ 先聚合 $K,V$。

## 三、数学形式

线性注意力 $O(Nd^2)$：$\text{out}=\phi(Q)(\phi(K)^T V)$；避免 $N\times N$ 矩阵。

## 四、代码实现

```python
kv = phi(K).T @ V          # 先聚合
out = phi(Q) @ kv
```

## 五、与其他对比

- 比 FlashAttention 更省长序列但近似、质量略降；
- 与 Mamba/状态空间模型深入 同属亚二次路线。

## 六、常见误区

- 线性注意力在检索密集任务弱于 softmax；
- 稀疏模式错配数据致信息丢失。

## 八、面试题

- 线性注意力为何 $O(N)$？答：先聚合 K/V 避免构造 $N^2$ 分数矩阵。

## 九、演进

局部稀疏 → 全局标记 → 线性/SSM。

## 十、小结

稀疏与线性注意力以近似换长序列可扩展性，质量需权衡。
