# 注意力实践与显存优化

> 对应生产长上下文；与 KV缓存优化深入 / 连续批处理深入 衔接。

## 一、背景与挑战

推理时 KV 缓存随批与长度增长成显存主因；需配合 PagedAttention 等。

## 二、核心原理

用 FlashAttention 降训练峰值；推理用分页 KV、MQA/GQA 减少 KV 头数；长序列用分块/窗口注意力。

## 三、数学形式

KV 显存 $O(B\cdot L\cdot n_{kv}\cdot d\cdot 2)$；GQA 把 $n_{kv}$ 从 $n_h$ 降到 $g$ 头。

## 四、代码实现

```python
model.config.num_key_value_heads = 8   # GQA 减少 KV
```

## 五、与其他对比

- 与 量化推理引擎深入（KV 量化）互补；
- 与 预填充解码分离深入 显存分工有关。

## 六、常见误区

- 仅优化注意力忽略 KV 缓存才是推理瓶颈；
- 窗口注意力损全局依赖。
