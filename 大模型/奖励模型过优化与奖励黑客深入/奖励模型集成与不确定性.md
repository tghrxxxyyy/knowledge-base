# 奖励模型集成与不确定性

> 对应 Coste et al., *Reward Model Ensembles Help Mitigate Overoptimization*, ICLR 2024；Eisenstein et al., *Helping or Herding? Reward Model Ensembles Mitigate but do not Eliminate Reward Hacking*, 2023。

## 一、背景与挑战

单个 RM 的误差在分布外是系统性的，优化器会精准命中它的漏洞。直觉的解法是「多问几位裁判」：如果多个独立 RM 一致给高分，那更可能是真的好；如果它们分歧很大，说明进入了不可靠区域，应当保守。

## 二、核心原理

集成提供了两种可用信号：均值（降低方差、平滑单模型漏洞）与分歧（不确定性代理）。据此有三种聚合策略：均值聚合（Mean）、最坏情形（Worst-Case Optimization，取最小值，最保守）、不确定性加权（Uncertainty-Weighted，均值减去方差惩罚）。关键前提是成员之间的误差要有独立性——若所有成员共享同一预训练底座与同一批偏好数据，它们会犯相同的错误（herding），集成只能缓解不能消除。因此提升多样性（不同底座、不同数据切分、不同随机种子与超参）比单纯增加成员数更重要。

## 三、数学形式

设集成成员 $\{r_i\}_{i=1}^M$，令 $\bar r=\frac1M\sum_i r_i$，$s^2=\frac1M\sum_i (r_i-\bar r)^2$，则

$$r_{\text{mean}}=\bar r,\qquad r_{\text{wco}}=\min_i r_i,\qquad r_{\text{uwo}}=\bar r-\lambda\, s^2$$

其中 $\lambda>0$ 为不确定性惩罚系数。若成员误差两两相关系数为 $\rho$，则均值的误差方差为 $\sigma^2\big(\rho+\frac{1-\rho}{M}\big)$——$M\to\infty$ 时仍留有 $\rho\sigma^2$ 的不可约项，这就是集成无法根治奖励黑客的定量原因。

## 四、代码实现

```python
import torch

class RewardEnsemble:
    def __init__(self, models, mode="uwo", lam=1.0):
        self.models, self.mode, self.lam = models, mode, lam

    @torch.no_grad()
    def score(self, x, y):
        rs = torch.stack([m(x, y) for m in self.models], dim=0)   # [M, B]
        mean = rs.mean(0)
        var = rs.var(0, unbiased=False)
        if self.mode == "mean":
            return mean
        if self.mode == "wco":
            return rs.min(0).values                # 最坏情形，最保守
        return mean - self.lam * var               # 不确定性加权

    @torch.no_grad()
    def disagreement(self, x, y):
        rs = torch.stack([m(x, y) for m in self.models], dim=0)
        return rs.std(0)                           # 用作 OOD 预警信号
```

## 五、与其他对比

- 相对增大单个 RM：集成同时提供不确定性信号，而单大模型只给点估计；成本上集成推理更贵。
- 相对 KL 惩罚：KL 限制「走多远」，集成惩罚「走进哪里不可靠」，两者互补。
- 与 过优化缩放律：集成可视为等效降低噪声方差，把拐点右移。

## 六、常见误区

- 只用不同随机种子造集成。多样性不足，误差高度相关，效果有限。
- 无脑用最坏情形聚合。过度保守会让策略几乎不动，收益被抹平。
- 把分歧度当绝对阈值。分歧的尺度随任务变化，应做分位数校准后再用于路由或拒答。

## 八、面试题

- 集成为什么不能完全消除奖励黑客？答：成员误差存在共同成分，均值方差有不可约项 $\rho\sigma^2$，共享底座与数据会导致同向犯错。
- UWO 与 WCO 的取舍？答：WCO 最保守、抑制黑客最强但收益低；UWO 用方差惩罚在收益与保守间可调。

## 九、演进

单 RM → 多种子集成 → 异构底座与数据切分集成 → 不确定性加权与分歧路由 → 与人类回路结合的分层裁判。

## 十、小结

集成把「点估计奖励」升级为「带不确定性的奖励」，是性价比很高的过优化缓解手段，但必须以成员多样性为前提。
