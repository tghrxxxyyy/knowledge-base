# 过优化缩放律

> 对应 Gao, Schulman & Hilton, ICML 2023；与 Kaplan et al., 2020 / Hoffmann et al., 2022 的缩放律方法论同源。

## 一、背景与挑战

如果过优化不可避免，那至少要能预测它：给定 RM 规模、偏好数据量与优化强度，金标奖励在哪里达到峰值？没有这层预测，训练只能靠反复人工评测试错，成本极高。

## 二、核心原理

Gao 等用「合成金标 RM」构造可控实验：先训一个大 RM 当作金标，再用它标注数据训不同规模的代理 RM，然后分别用 best-of-n 与 PPO 优化，观察金标分数随 $\sqrt{\mathrm{KL}}$ 的变化。核心发现有三：曲线形状在两种优化方式下不同（bo-n 近似二次、RL 含对数项）；代理 RM 参数量增大主要降低过优化惩罚系数，即拐点右移、峰值抬高；偏好数据量增加也改善拟合，但作用与 RM 规模不完全等价。这使得「先小规模扫描、再外推大规模拐点」成为可行的工程方法。

## 三、数学形式

以 $d=\sqrt{\mathrm{KL}}$ 为优化强度，金标奖励拟合为

$$R_{\text{bo}n}(d)=d(\alpha_{\text{bo}n}-\beta_{\text{bo}n}d),\qquad R_{\text{RL}}(d)=d(\alpha_{\text{RL}}-\beta_{\text{RL}}\log d)$$

其中系数随代理 RM 参数量 $N$ 呈幂律型变化（$\beta$ 随 $N$ 增大而减小）。bo-n 的峰值位置为 $d^*=\dfrac{\alpha}{2\beta}$，对应最优 KL 预算 $\mathrm{KL}^*=(d^*)^2$；RL 形式的峰值满足 $\alpha_{\text{RL}}-\beta_{\text{RL}}(\log d+1)=0$，即 $d^*=\exp(\alpha_{\text{RL}}/\beta_{\text{RL}}-1)$。

## 四、代码实现

```python
import numpy as np
from scipy.optimize import curve_fit

def bon_form(d, alpha, beta):
    return d * (alpha - beta * d)

def rl_form(d, alpha, beta):
    return d * (alpha - beta * np.log(np.maximum(d, 1e-6)))

def fit_and_predict(kl_points, gold_scores, kind="bon"):
    d = np.sqrt(np.asarray(kl_points, dtype=float))
    f = bon_form if kind == "bon" else rl_form
    (a, b), _ = curve_fit(f, d, np.asarray(gold_scores, dtype=float), p0=[1.0, 0.1])
    d_star = a / (2 * b) if kind == "bon" else np.exp(a / b - 1.0)
    return {"alpha": a, "beta": b, "kl_star": float(d_star ** 2)}
```

## 五、与其他对比

- 与 缩放律相关主题：方法论一致（幂律拟合 + 小规模外推），但因变量是「对齐后的真实质量」。
- 与 奖励模型集成与不确定性：集成相当于降低有效噪声，效果类似增大 RM 规模。
- 与 KL 预算控制：缩放律给出的 $\mathrm{KL}^*$ 就是 KL 预算的理论落点。

## 六、常见误区

- 把论文里的具体系数当作通用常数照搬。系数依赖任务、RM 与基座，必须在自己的设置上重新拟合。
- 只用训练末尾一个点拟合。至少需要覆盖拐点两侧的多个检查点才能定出 $\beta$。
- 用代理奖励当纵轴拟合。纵轴必须是独立金标（人工或更强裁判），否则曲线永远单调上升。

## 八、面试题

- 为什么 best-of-n 与 RL 的过优化曲线形式不同？答：两者对分布的偏移方式不同，bo-n 是从固定分布中选极值，RL 是主动移动分布，故金标衰减项分别近似二次与对数型。
- RM 变大为什么能缓解过优化？答：拟合误差方差下降，过优化惩罚系数减小，拐点右移、峰值抬高，但曲线仍有峰。

## 九、演进

定性观察过优化 → 合成金标可控实验 → 幂律与拐点拟合 → 用缩放律指导 KL 预算与检查点选择。

## 十、小结

过优化缩放律把「什么时候该停」从经验判断变成可拟合、可外推的量化决策，是把 RLHF 工程化的关键一步。
