# 探针可解释

> 见「因果可解释深入/因果可解释总览」与「词嵌入与表示学习」；线性探针。

## 一、背景与挑战

隐层是否编码了某种语言学/语义属性？

## 二、核心原理

训练一个线性分类器（探针）从某层表征预测属性（词性/语义角色/事实）。探针越准，说明该信息越被编码。是分析「表征含什么」的标准工具（见表征质量评估章）。

## 三、数学形式

`acc = classifier(f_l(x), property)`，f_l 为第 l 层表征。

## 四、代码实现

```python
probe = LogisticRegression().fit(layer_repr, prop)
```

## 五、关键要点

- 探针能力≠模型用途（选择性探针问题）。
- 需对照控制任务。

## 六、与其他对比

- 注意力看权重；探针看表征。

## 七、常见误区

- 探针好=模型用此信息——未必。
