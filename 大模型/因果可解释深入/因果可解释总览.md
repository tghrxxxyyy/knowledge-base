# 因果可解释总览

> 对应 d2l-zh 可解释章与「大模型可解释性」；解释「为何这样答」。

## 一、背景与挑战

黑箱模型决策难信，监管与用户都需解释。

## 二、核心原理

可解释两路线：**内在（透明）**设计可解释结构；**事后（post-hoc）**用方法解释已训练模型。因果视角进一步问「若输入变 X，输出会怎样」，比相关性更可靠（见不变风险/信息瓶颈章）。

## 三、关键要点

- 相关性 ≠ 因果。
- 解释需忠实（真反映模型）而非好看。

## 四、代码实现

```python
# 事后解释：特征归因
attr = integrated_gradients(model, input)
```

## 五、与其他对比

| 视角 | 问法 |
|------|------|
| 相关 | 什么相关 |
| 因果 | 改了会怎样 |

## 六、常见误区

- 解释=可信——可能不忠实。
