# 反事实解释

> 见「因果可解释深入/因果可解释总览」；「若…则…」式解释。

## 一、背景与挑战

用户想知「改哪能让结果变」。

## 二、核心原理

反事实解释给出最小输入改动使其输出变化（如「若把‘拒绝’改为‘同意’则获批」）。在 NLP 中用生成式编辑输入、比较输出；比特征归因更直观、可行动。

## 三、关键要点

- 改动需最小且合理。
- 生成式模型易做编辑。

## 四、代码实现

```python
cf = generate_counterfactual(x, target=flip(output))
```

## 五、与其他对比

- 归因说「重要」；反事实说「改这里」。

## 六、常见误区

- 反事实即真因——仍相关近似。
