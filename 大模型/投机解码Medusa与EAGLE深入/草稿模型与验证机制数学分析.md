# 草稿模型与验证机制数学分析

> 对应 Leviathan 2023 & Chen 2023 speculative decoding; Li 2024 EAGLE。

## 一、背景与挑战
投机解码正确性依赖“无偏接受”机制：输出序列分布必须严格等于目标模型自回归分布，否则会引入偏差。

## 二、核心原理
逐位置比较草稿 token x 与目标采样。若草稿 token 被接受则保留；否则以修正分布重采样一个 token 替换，并将后续草稿丢弃，保证每一步分布精确匹配 target。

## 三、形式化与数学基础
修正接受分布：
$ x' \sim \begin{cases} x & \text{if } u < \frac{p_\theta(x)}{q_\phi(x)} \\ \tilde{x} \sim \frac{p_\theta - q_\phi}{1 - \sum q_\phi} & \text{else} \end{cases} $
其中 u 为均匀噪声。该构造使边缘分布等于 p_θ。

## 四、代码实现
```python
def accept(x, p_theta, q_phi, u):
    if u < p_theta[x] / q_phi[x]:
        return x, True
    resid = (p_theta - q_phi).clip(min=0)
    resid = resid / resid.sum()
    return sample(resid), False
```

## 五、与其他技术对比
朴素“取 argmax 一致的”会破坏分布；修正重采样是唯一保证无偏的方式，代价是偶发重采样。

## 六、常见误区
误以为接受就是比较 argmax。比较 argmax 会改变分布，必须按概率比值接受/拒绝。

## 七、与开源书/权威来源对应
Leviathan et al. 2023; Chen et al. 2023 给出形式化无偏证明。实现见 vllm-project/vllm spec decode。

## 八、面试题
问：为什么投机解码输出分布与目标完全一致？
答：拒绝时按 (p-q) 归一化残差重采样，使边际分布恒等于 p_θ。

## 九、演进与趋势
后续工作把树验证、批量重采样统一进采样核，支持更多候选结构而不破坏无偏性。

## 十、小结
验证机制的数学正确性决定投机解码可否安全替换原推理，是整套方法的理论基石。
