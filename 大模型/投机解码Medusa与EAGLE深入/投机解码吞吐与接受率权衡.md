# 投机解码吞吐与接受率权衡

> 对应 Leviathan 2023 speculative decoding; Kwon 2023 vLLM; Cai 2024 Medusa。

## 一、背景与挑战
加速比不是 γ 越大越好：草稿成本、验证树规模、内存随 γ 增长，存在最优 γ* 使端到端延迟最低。

## 二、核心原理
端到端每步延迟 = 草稿成本 + 目标一次前向（含 γ 长度 KV）/ 接受长度。当接受率 α 下降快于 γ 增长，增加 γ 反而变慢。

## 三、形式化与数学基础
设接受长度期望 L = γ·α/(1-α) 近似，单步耗时 T ≈ T_draft·γ + T_target。有效每 token 延迟：
$ \tau = \frac{T_draft \cdot \gamma + T_target}{\gamma \cdot \alpha} $
对 γ 求导取零得最优 γ*。

## 四、代码实现
```python
def optimal_gamma(Td, Tt, alpha):
    # 近似求使 tau 最小的 gamma
    best, bt = 1, 1e9
    for g in range(1, 16):
        tau = (Td * g + Tt) / (g * alpha)
        if tau < bt:
            best, bt = g, tau
    return best
```

## 五、与其他技术对比
与连续批处理正交：投机提升单请求速度，批处理提升集群吞吐，二者可叠加。

## 六、常见误区
误区：GPU 空闲时投机没用。其实带宽受限场景投机收益最大。

## 七、与开源书/权威来源对应
Kwon et al. 2023 vLLM 论文讨论吞吐优化；投机解码见 vllm-project/vllm。

## 八、面试题
问：什么情况下不应开启投机解码？
答：草稿远慢于目标，或 α 极低（分布差异大）时，验证开销压倒收益。

## 九、演进与趋势
自适应 γ、动态树宽度、按层退出等让投机解码在异构负载下自调优。

## 十、小结
投机解码收益由接受率与草稿成本共同决定，需按模型与硬件实测选取 γ。
