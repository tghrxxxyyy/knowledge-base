# 投机解码基本原理与自投机

> 对应 Leviathan 2023 & Chen 2023 speculative decoding; Cai 2024 Medusa; Li 2024 EAGLE。

## 一、背景与挑战
自回归解码逐个 token 生成，每步需一次完整前向，GPU 大量算力浪费在串行依赖上。大模型推理的瓶颈常是内存带宽而非算力，投机解码用“草稿-验证”并行化多步以摊薄延迟。

## 二、核心原理
草稿模型（或小头）一次提出 γ 个候选 token，目标模型并行验证整条序列，平均接受 αγ 个 token。接受数服从几何分布，期望接受步数为 1/(1-α)。当草稿与目标分布接近时 α 高，端到端加速明显。

## 三、形式化与数学基础
记目标分布 p、草稿分布 q，硬件并行度 γ。块效率近似：
$ \text{speedup} \approx \frac{1}{1-\alpha} \cdot \frac{1}{1 + \gamma \cdot c} $
其中 c 为草稿相对目标的成本比。损失函数对草稿：
$ \mathcal{L} = -\sum_{t} \log q_\theta(x_t \mid x_{<t}) $

## 四、代码实现
```python
def speculative_step(x, draft, target, gamma=4):
    proposal = draft.rollout(x, gamma)        # 草稿提出 gamma 个 token
    logits = target.forward(x + proposal)     # 目标一次并行验证
    n_accept = 0
    for i, tok in enumerate(proposal):
        if sample(logits[i]) == tok:
            n_accept = i + 1
        else:
            break
    return n_accept
```

## 五、与其他技术对比
相比 Medusa/EAGLE 等自投机方案，独立草稿模型无需改目标结构但成本更高；自投机复用主干特征，延迟更低但需额外训练头。

## 六、常见误区
误以为投机解码一定加速：当 α 低或 γ 过大时，验证开销反而拖累。草稿模型必须比目标快且分布接近才划算。

## 七、与开源书/权威来源对应
Leviathan et al. 2023 Fast Inference from Transformers via Speculative Decoding；Chen et al. 2023 Accelerating Large Language Model Decoding。代码参考 vllm-project/vllm 的 spec decode。

## 八、面试题
问：投机解码如何保证输出分布与目标模型完全一致？
答：以目标 logits 为基准做接受/拒绝重采样，被拒位置按修正分布重采样，保证无偏。

## 九、演进与趋势
从独立草稿走向 Medusa 多头、EAGLE 树状、以及多令牌预测（MTP）预训练，逐步把“投机”固化进模型结构。

## 十、小结
投机解码以并行验证换取串行延迟，是低成本加速自回归推理的核心范式，自投机是其工程最优形态。
