# 超参优化方法

> 见「自动化机器学习深入/AutoML总览」；Bergstra et al., *TPE*, 2011；Li et al., *Hyperband*, 2017。

## 一、背景与挑战

超参空间大、评估贵，如何高效搜？

## 二、核心原理

- **网格/随机**：简单但低效（随机常优于网格，Bergstra 2012）。
- **贝叶斯优化**：建代理模型（高斯过程）指导采样，样本高效。
- **TPE**：树状 Parzen 估计器，对类别/连续混合有效。
- **Hyperband/ASHA**：多臂_bandit 式早停，资源自适应分配，快。

## 三、数学形式

贝叶斯取 `x = argmax EI(x)`（期望提升）。

## 四、代码实现

```python
import optuna
def obj(t): return train(hparams=t)
optuna.create_study(direction='minimize').optimize(obj, 200)
```

## 五、关键要点

- 贝叶斯/TPE 样本高效。
- Hyperband 适合训练慢场景。

## 六、与其他对比

- 网格浪费；贝叶斯聪明。

## 七、常见误区

- 网格必全——高维失效。
