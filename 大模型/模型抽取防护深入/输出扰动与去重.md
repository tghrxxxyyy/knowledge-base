# 输出扰动与去重

> 对应 Kariyappa & Qureshi 2019《Defending Against Model Extraction Attacks Using Saturated RNN》、Krishna et al. 2020 模型抽取研究，与 mlabonne/llm-course 安全章。

## 一、背景与挑战

模型即服务（MaaS）把能力封装为 API，攻击者可通过高频查询不断收集「输入-输出」对，训练一个行为高度相近的替代模型（extraction attack）。当替代模型在任务表现上逼近原模型，原模型的商业价值与知识产权就被「廉价克隆」。

对抗这种克隆的朴素做法是直接拒答或加噪声，但这会同时伤害正常用户。于是引出核心矛盾：**既要让防御对真实用户几乎无感，又要让攻击者的训练样本足够「不干净」，使其替代模型学不到稳定的决策边界**。输出扰动与去重正是围绕这一矛盾的两类轻量手段。

## 二、核心原理

输出扰动（output perturbation）指在不显著改变语义与可用性的前提下，对返回结果施加微小、随机、可控的变换。典型做法包括：在 logits 上加温度化的微小噪声、对候选集合做随机重排、对数值或格式化输出做轻微抖动、对生成文本做同义替换或标点扰动。其目标是**降低攻击样本之间的逐点一致性**，使替代模型在拟合这些样本时引入额外方差，泛化能力下降。

去重（response deduplication）则针对「同一查询反复探测」：当检测到某输入或语义近邻已被多次请求，直接返回缓存的变体或统一结果，而不是每次都重新采样。它减少了攻击者通过重复采样来「平均掉随机性、还原真实分布」的可能。

二者的共同前提是：扰动幅度必须落在用户不可感知的阈值内，否则防御就变成了体验降级甚至变相拒答。

## 三、形式化与数学基础（含 LaTeX）

设原策略在输入 $x$ 下输出分布为 $p_\theta(y\mid x)$，攻击者的目标经验风险为

$$
\mathcal{L}_{adv}(\phi)=\mathbb{E}_{(x,y)\sim\mathcal{D}_{probe}}\big[-\log p_\phi(y\mid x)\big]
$$

其中 $\mathcal{D}_{probe}$ 由查询得到的「输入-输出」对构成。对输出施加扰动后，攻击者实际观察的是 $\tilde y\sim q(\tilde y\mid y)$，其对应分布为

$$
q_\theta(\tilde y\mid x)=\sum_y p_\theta(y\mid x)\,q(\tilde y\mid y)
$$

若扰动为加性对称噪声且方差 $\sigma^2$ 较小，则替代模型在 $q_\theta$ 上学到的参数 $\hat\phi$ 相对理想 $\phi^*$ 的泛化差距满足

$$
\mathrm{GenGap}\;\ge\;\Omega\!\left(\frac{\sigma^2}{n}\right)
$$

即**扰动方差越大、攻击样本数 $n$ 越少，克隆质量越差**。去重则直接压低有效 $n$，等价于减少可用于拟合的样本量。

import hashlib, random

# 对相似查询做语义近邻缓存键
def dedup_key(text):
    return hashlib.md5(text.strip().lower().encode()).hexdigest()[:12]

cache = {}

def serve(model, x, user):
    key = dedup_key(x)
    if key in cache:
        return cache[key]                      # 去重：返回稳定变体
    y = model.generate(x, temperature=0.7)
    if is_clone_probe(user, x):                # 疑似抽取型查询

    cache[key] = y
    return y

## 五、与其他技术对比

- 与硬拒答相比：拒答直接阻断攻击但牺牲可用；扰动保留服务、仅降质量。
- 与查询限流相比：限流从源头减少样本，扰动在样本层注入噪声，二者互补。
- 与水印相比：水印偏事后溯源举证，扰动偏事前降可利用性。

## 六、常见误区

- 「扰动就是乱改」——幅度失控会伤体验，需以可感知阈值为界。
- 「加噪声就能防」——固定噪声反而可被重复采样平均掉，需随机且不可预测。
- 「去重等于缓存」——纯缓存若命中正常请求会返回过期结果，需区分攻击模式。

## 八、面试题

- 问：输出扰动防抽取的原理是什么？答：在攻击者观察到的分布上注入随机噪声，提升替代模型的泛化差距，使其克隆质量下降，同时保持正常用户无感。
- 问：扰动和限流如何配合？答：限流压低总样本量 $n$，扰动提高单位样本方差，二者乘性放大防御强度。
- 问：为何固定噪声无效？答：攻击者重复采样可平均掉确定性噪声，恢复真实分布。

## 九、演进与趋势

早期是启发式抖动，逐渐发展为**可证明的对抗训练式防御**：把扰动建模为最坏情况分布，训练时让模型在该分布上仍稳定。另一趋势是把扰动与去重、限流、水印组合成**多层防御流水线**，并引入用户分层（付费用户免扰动、匿名探测用户强扰动）。

## 十、小结

输出扰动与去重是「保可用、降可利用性」的轻量防御：用不可平均的随机噪声和语义去重，抬高攻击者克隆模型的代价，应作为限流与水印之外的补充层。
