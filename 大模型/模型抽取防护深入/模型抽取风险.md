# 模型抽取风险

> 对应 llm-course 安全章；见「数据隐私与联邦深入/隐私风险面」。

## 一、背景与挑战

攻击者大量查询 API 复刻模型能力（蒸馏/克隆），损害商业与知识产权。

## 二、核心原理

通过查询-响应对训练替代模型（extraction attack），尤其小模型易被高仿；也含参数/架构推断。

## 三、关键要点

- 大量低成本查询是前提。
- 输出分布泄露风格。

## 四、代码实现

```python
if query_volume(ip) > LIMIT: throttle(ip)
```

## 五、与其他对比

- 数据泄露在内容；抽取在能力。

## 六、常见误区

- 闭源即安全——API 可被查询盗。
