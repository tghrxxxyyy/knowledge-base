# 反馈与偏好采集

> 对应 交互式偏好学习（interactive preference learning）。

## 一、背景与挑战

agent 需要持续知道“人到底想要什么”，但频繁打扰会损害体验。需低摩擦采集。

## 二、核心原理

提供多粒度反馈：显式（评分/纠正）、隐式（采纳/编辑/停留）、主动（在关键分歧处问一个好问题）。把反馈即时转成记忆或微调信号（见轨迹进化章）。

## 三、数学形式

反馈信息量按减少的不确定性衡量：

$$I(f) = H(policy) - H(policy\mid f)$$

优先问信息量最大的分歧点。

## 五、与其他对比

- 与 偏好与反馈学习 共享反馈→策略更新。
- 与 智能体推理成本建模深入 共担打扰成本。

## 六、常见误区

- 一次性大问卷，人填不动。
- 只采显式反馈，浪费隐式信号。

## 八、面试题

- 为何问“一个好问题”？答：单点高信息量提问，以最小打扰换最大纠偏。

## 九、演进

大问卷 → 即时评分 → 主动单点高信息提问。

## 十、小结

反馈采集要低摩擦、高信息，把人的判断高效转成 agent 的认知。
