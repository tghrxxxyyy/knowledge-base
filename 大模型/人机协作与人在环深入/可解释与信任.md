# 可解释性与信任建立

> 对应 可解释 AI（XAI）与 agent 透明度。

## 一、背景与挑战

人不信任“黑箱”agent，尤其在关键决策。缺乏解释会导致要么拒用、要么盲从。

## 二、核心原理

agent 输出应附带可追溯依据：引用来源、展示推理步骤、暴露不确定性。人在环中基于解释做判断而非盲点确认。透明提升采纳率与纠错的及时性。

## 三、数学形式

信任校准：

$$trust = f(accuracy, transparency)$$

高准确但低透明仍难被采纳，二者需并进。

## 四、代码实现

```python
answer, cites, conf = agent.respond(q)
show(cites, conf)  # 人据以判断
```

## 五、与其他对比

- 与 智能体可靠性与失败模式深入 共担“让人理解为何失败”。
- 与 反馈与偏好采集 共享信任驱动的合作。

## 六、常见误区

- 解释是事后包装而非真实依据，反而误导。
- 不确定性从不展示，人误判置信。

## 八、面试题

- 解释为何影响信任？答：人需依据来源与不确定性判断，盲确认风险高。

## 九、演进

无解释 → 最终答案 → 来源+步骤+不确定性。

## 十、小结

可解释是信任的骨架，让人在环中“心中有数”地决策。
