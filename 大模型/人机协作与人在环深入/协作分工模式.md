# 协作分工模式

> 对应 人机协作范式（如 copilot / advisor / autopilot）。

## 一、背景与挑战

不同任务适合不同协作强度：写代码可 copilot，医疗诊断宜 advisor，流水处理可 autopilot。需匹配模式。

## 二、核心原理

三档范式：copilot（人主 agent 辅，连续补全）、advisor（agent 给选项人决策）、autopilot（agent 自主，人监督异常）。按任务可逆性与后果严重度选择。

## 三、数学形式

选择范式由后果严重度 $s$ 与可逆性 $rev$ 决定：

$$mode = \begin{cases} autopilot & s\downarrow, rev\uparrow \\ advisor & s\uparrow \\ copilot & 创造性高 \end{cases}$$

## 四、代码实现

```python
mode = pick_mode(severity=task.sev, reversible=task.rev)
```

## 五、与其他对比

- 与 干预与确认点 共同刻画人机边界。
- 与 多智能体通信协议深入 把人视作一个 agent 节点。

## 六、常见误区

- 对高后果任务用 autopilot。
- 同一模式套所有任务，不匹配。

## 八、面试题

- 如何选协作范式？答：按后果严重度与可逆性，高后果用 advisor/copilot。

## 九、演进

统一全自动 → 固定档位 → 任务自适配范式。

## 十、小结

协作模式要随任务性质而变，没有“一种模式管全部”。
