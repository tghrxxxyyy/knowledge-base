# 长视频理解

> 对应长视频问答/章节化（Ego4D, MovieQA）；长上下文建模趋势。

## 一、背景与挑战

长视频（分钟级）帧数巨大，难以全部编码；关键事件稀疏，需高效记忆与定位。

## 二、核心原理

策略：稀疏采样+关键帧选择、层次化编码（帧→镜头→视频）、外部记忆（如将视频转文本再用 LLM 推理）、或将长视频分窗后用检索定位相关段。

## 三、数学形式

层次池化：

$$h_{shot}=\text{Pool}(h_{frames}),\quad h_{video}=\text{Pool}(h_{shots})$$

最终表示随层次压缩长度。

## 四、代码实现

```python
shots = [encode(frames[i:i+K]) for i in range(0, T, K)]
video_rep = transformer(shots).mean(0)
```

## 五、与其他对比

- 与 时空建模 对照短片段效率。
- 与 长上下文技术（若新增）共享长序列思路。

## 六、常见误区

- 均匀采样漏掉稀疏关键事件。
- 直接堆帧致上下文超长。

## 八、面试题

- 长视频如何降本？答：稀疏采样+层次池化+检索定位，避免全帧编码。

## 九、演进

全帧 → 关键帧 → 层次/记忆化。

## 十、小结

长视频理解靠采样与层次压缩，在成本与覆盖间取舍。
