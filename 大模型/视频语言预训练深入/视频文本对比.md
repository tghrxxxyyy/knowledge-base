# 视频文本对比

> 对应 Xu et al., *VideoCLIP*, 2021；Frozen in Time / CLIP4Clip 等。

## 一、背景与挑战

把 CLIP 图文对比扩展到视频：视频含多帧时序，文本描述常覆盖整段动作，对齐更复杂。

## 二、核心原理

对视频采样多帧经编码器得到视频表示（常时序池化），与文本做对比；可加时序一致性或掩码帧任务。常用片段-文本对（如 HowTo100M）做大规模弱监督。

## 三、数学形式

视频-文本对比与 CLIP 同构：

$$\mathcal L = -\log\frac{e^{s(v,t^+)/\tau}}{\sum_k e^{s(v,t_k)/\tau}}$$

$v$ 为视频池化表示。

## 五、与其他对比

- 与 CLIP架构与训练 同范式，输入由图变视频。
- 与 视频问答与生成 共享表示。

## 六、常见误区

- 简单平均帧忽略动作顺序。
- 文本覆盖整段但模型只看首帧致错位。

## 八、面试题

- 视频对比与图像对比区别？答：需聚合多帧时序信息，且文本常描述动作序列而非单帧。

## 九、演进

图像 CLIP → 帧平均 → 时序注意力池化。

## 十、小结

视频文本对比是视频多模态基础，关键在于时序聚合策略。
