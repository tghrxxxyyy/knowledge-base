# 时空建模

> 对应 Bertasius et al., *TimeSformer*, 2021；Arnab et al., *ViViT*, 2021。

## 一、背景与挑战

如何高效建模空间（帧内）与时间（帧间）依赖，而不爆显存？

## 二、核心原理

视频 Transformer 用分块（patch）把每帧展为 token，再在时空维做注意力。TimeSformer 采用“分治注意力”：先空间后时间，复杂度可控；ViViT 提供多种因子化方案。

## 三、数学形式

时空注意力可分解为：

$$\text{Attn}_{space}(p_i, p_j),\quad \text{Attn}_{time}(p_i^t, p_i^{t'})$$

分解后复杂度由 $O((TN)^2)$ 降至约 $O(TN^2+TN)$。

## 四、代码实现

```python
tokens = patch_embed(frames)              # [T, N, D]
tokens = time_attn(tokens) + space_attn(tokens)
```

## 五、与其他对比

- 与 视频表征学习 共享时间建模目标。
- 与 长视频理解 对照长序列效率。

## 六、常见误区

- 全时空注意力显存爆炸却不因子化。
- 帧采样过稀丢关键动作。

## 八、面试题

- TimeSformer 为何高效？答：分治空间/时间注意力，避免全时空联合注意力的平方复杂度。

## 九、演进

3D-CNN → 因子化注意力 → 时空分离。

## 十、小结

时空建模以因子化注意力平衡表达与效率，是视频 Transformer 核心。
