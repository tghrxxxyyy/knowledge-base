# 视频问答与生成

> 对应 VideoQA 基准（MSVD-QA, MSRVTT-QA）；视频到文本生成（captioning）。

## 一、背景与挑战

视频问答需同时理解视觉内容、时序与问题语义；视频生成（如文本生成视频）更需时序一致性。

## 二、核心原理

VideoQA：编码视频与问题，经融合（注意力/门控）后解码答案。视频生成：以文本为条件用扩散/自回归在视频潜空间生成帧序列，重点保持时序连贯。

## 三、数学形式

答案概率：

$$p(a|v,q)=\text{Decoder}\big(\text{Fuse}(E_v(v), E_q(q))\big)$$

视频生成则建模 $p(v_{1:T}|y)$。

## 四、代码实现

```python
vid = video_encoder(frames)
q = text_encoder(question)
ans = head(fusion(vid, q))
```

## 五、与其他对比

- 与 视觉问答与推理深入 对照静态图 VQA。
- 与 跨模态生成扩散深入 共享生成机制（视频版）。

## 六、常见误区

- 把视频 QA 当图像 QA 忽略时序线索。
- 视频生成忽视帧间一致性致闪烁。

视频问答与生成是视频多模态的高层应用，时序是关键难点。
