# 视频表征学习

> 对应 Feichtenhofer et al., *SlowFast Networks*, 2019；视频自监督（contrastive）趋势。

## 一、背景与挑战

视频比图像多一维时间，计算与建模成本高；如何学到对动作/时序敏感的表示？

## 二、核心原理

两类方法：监督（3D 卷积/SlowFast 双路捕快/慢运动）与自监督（帧间对比、时序顺序预测、掩码帧建模）。视频语言预训练常把视频表征与文本对齐。

## 三、数学形式

帧层次对比（视频内 temporal）：

$$\mathcal L = -\log\frac{e^{s(f_t,f_{t^+})/\tau}}{\sum_{k}e^{s(f_t,f_k)/\tau}}$$

$f_t$ 为第 t 帧表示，$f_{t^+}$ 为同视频邻近帧。

## 四、代码实现

```python
clip_emb = video_encoder(frames)          # [T, D]
txt_emb = text_encoder(caption)
loss = contrastive(clip_emb.mean(0), txt_emb)
```

## 五、与其他对比

- 与 视频文本对比 衔接（视频级对齐）。
- 与 时空建模 共享时间建模。

## 六、常见误区

- 仅取关键帧丢时序信息。
- 把视频当独立图像集合，动作语义丢失。

## 八、面试题

- 视频表征难在哪？答：时间维度带来冗余与计算，且动作语义依赖时序关系建模。

## 九、演进

2D+CNN → 3D → SlowFast → 视频 Transformer。

## 十、小结

视频表征需在空间与时序间平衡，自监督与语言对齐是主流路径。
