# 多模态模型演进

> 对应 Radford et al. 2021 CLIP、Li et al. 2022 BLIP、Liu et al. 2023 LLaVA、DeepSeek 2024 DeepSeek-VL 等；综述参见 mlabonne llm-course。

## 一、背景与挑战

人类感知天然多模态（视觉、语言、听觉），但早期 NLP 与 CV 各自独立发展。让模型同时理解图像与文本，面临三大挑战：(1) 模态表示空间不同，图像是连续像素网格，文本是离散 token；(2) 对齐困难，需建立「图—文」语义对应；(3) 训练数据稀疏，高质量图文对远少于纯文本。多模态模型的演进史，本质是如何把异构模态统一到一个可联合推理的表示空间。

## 二、核心原理

演进大致分三代：

- **双塔对齐（CLIP/ALIGN）**：图像编码器与文本编码器各自独立，通过对比学习把匹配图文拉近、非匹配推远。优点是可扩展、适合检索；缺点是交互晚、难做细粒度融合。
- **融合式多模态（BLIP/Flamingo）**：引入跨模态注意力，让文本 token 直接 attend 到图像特征，支持生成式理解与问答。
- **统一到 LLM（LLaVA 系）**：用视觉编码器（如 ViT）抽取图像特征，经投影层映射到 LLM 的词嵌入空间，再用指令微调让 LLM「看懂图」。这是当前主流范式。

## 三、形式化与数学基础

CLIP 的对比损失在 batch 内构造正负对。设图像特征 $I_i$、文本特征 $T_j$，经温度缩放后相似度为：

$$s_{i,j} = \frac{\exp(\mathrm{sim}(I_i, T_j)/\tau)}{\sum_{k}\exp(\mathrm{sim}(I_i, T_k)/\tau)}$$

对称对比损失为图像侧与文本侧交叉熵之和：

$$\mathcal{L} = \frac{1}{2}\left(\mathrm{CE}(y_i, s_{i,\cdot}) + \mathrm{CE}(y_j, s_{\cdot,j})\right)$$

LLaVA 类模型则把视觉特征投影为视觉 token 序列 $Z_v = W\cdot\mathrm{ViT}(x)$，与文本 token 拼接后由 LLM 自回归生成：

$$p(y\mid x, z) = \prod_t p_\theta(y_t \mid Z_v, y_{<t})$$

## 四、代码实现

以下示意 LLaVA 风格投影与拼接：

```python
import torch
import torch.nn as nn

class VisionProjector(nn.Module):
    def __init__(self, vis_dim=1024, llm_dim=4096):
        super().__init__()
        self.linear = nn.Linear(vis_dim, llm_dim)

    def forward(self, image_feats):          # (B, N_patch, vis_dim)
        return self.linear(image_feats)      # (B, N_patch, llm_dim)

def build_inputs(text_ids, image_tokens, llm):
    emb = llm.get_input_embeddings()
    text_emb = emb(text_ids)
    return torch.cat([image_tokens, text_emb], dim=1)  # 视觉 token 前置
```

## 五、与其他技术对比

| 范式 | 融合时机 | 生成能力 | 代表 |
|------|----------|----------|------|
| 双塔对齐 | 晚期 | 弱 | CLIP、ALIGN |
| 跨注意力融合 | 早期 | 中 | Flamingo、BLIP-2 |
| LLM 统一 | 嵌入级 | 强 | LLaVA、Qwen-VL |

从「双塔」到「LLM 统一」，融合越来越早、生成能力越来越强，代价是训练与推理成本上升。

## 六、常见误区

- 误区一：认为 CLIP 能直接做视觉问答。它本质是检索/对齐模型，需配合生成器。
- 误区二：投影层随便接就行。投影质量直接决定 LLM「看不看得懂图」，常用 MLP 而非单层线性。
- 误区三：忽略分辨率。低分辨率丢细节，高分辨率需动态分辨率或切片策略。

## 九、演进与趋势

(1) 统一生成：Emu、Chameleon 把图像生成也纳入同一词空间，迈向「任意模态进、任意模态出」。(2) 视频/音频融合：2024 年起视频理解（如 LLaVA-Video）与语音对话（如 GPT-4o 风格端到端）成为热点。(3) 原生多模态预训练：从「先预训后对齐」走向从数据层面原生多模态。(4) 高分辨率与文档理解：特殊 tokenizer 支持任意长宽比。

## 十、小结

多模态模型经历了「双塔对齐→跨注意力融合→LLM 统一」三代演进，核心命题始终是跨模态表示对齐与统一推理。LLaVA 范式以视觉编码器+投影+LLM 的组合大幅降低了多模态门槛，未来方向是原生多模态预训练、视频/语音融合与任意模态统一生成。
