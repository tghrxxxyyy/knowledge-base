# 大模型发展时间线

> 综合公开论文与《动手学深度学习》演进脉络，梳理从统计语言模型到 LLM 的关键节点。

## 一、核心概念

大模型演进可概括为四阶段：(1) 统计与神经语言模型(2000s-2013)；(2) Word2Vec/Seq2Seq/RNN(2013-2017)；(3) Transformer 与预训练范式(2017-2019)；(4) 规模化 LLM 与对齐(2019-今)。

## 二、关键里程碑

| 年份 | 工作 | 意义 |
|------|------|------|
| 2013 | Word2Vec | 分布式词向量 |
| 2014 | Seq2Seq/Attention | 编码-解码 |
| 2017 | Transformer | 注意力主导 |
| 2018 | BERT/GPT-1 | 预训练范式 |
| 2019 | GPT-2 | 大规模生成 |
| 2020 | GPT-3 | 少样本/涌现 |
| 2022 | ChatGPT/InstructGPT | RLHF 对齐 |
| 2023 | LLaMA/开源潮 | 平民化 |
| 2024 | o1/R1 | 推理模型 |

## 三、关键要点

- 预训练+微调范式由 BERT/GPT 确立。
- RLHF 让模型「可用」而非仅「能生成」。
- 开源模型(LLaMA 系)极大降低门槛。
