# 大模型发展时间线

> 综合公开论文与《动手学深度学习》(d2l-zh) 演进脉络，梳理从统计语言模型到 LLM 的关键节点；权威来源含 Vaswani et al. 2017、Devlin et al. 2018、Brown et al. 2020。

## 一、背景与挑战

自然语言处理在三十余年间经历了从「统计规律」到「神经表示」再到「规模化预训练」的三次范式跃迁。理解时间线，关键是看清每一次跃迁解决了什么瓶颈：统计模型受困于稀疏性，神经网络受困于表示能力，预训练受困于标注数据成本，而规模化与对齐最终把模型推向通用助手。

## 二、核心原理

大模型演进可概括为四阶段：

1. **统计与神经语言模型（2000s–2013）**：n-gram 靠共现统计， Bengio 等提出神经网络语言模型用稠密向量表示词。
2. **词向量与序列模型（2013–2017）**：Word2Vec、Seq2Seq、注意力机制逐步出现。
3. **Transformer 与预训练范式（2017–2019）**：自注意力取代循环，BERT/GPT 确立「预训练+微调」。
4. **规模化 LLM 与对齐（2019–今）**：GPT-3 展示少样本能力，InstructGPT/ChatGPT 用 RLHF 对齐，o1/R1 开启推理范式。

## 三、形式化与数学基础

语言模型本质是估计词序列概率：

$$P(w_1,\dots,w_T) = \prod_{t=1}^T P(w_t \mid w_1,\dots,w_{t-1})$$

自注意力对每个位置计算查询 $Q$、键 $K$、值 $V$ 的加权：

$$\mathrm{Attention}(Q,K,V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

Scaling Law（Kaplan et al. 2020）刻画损失随参数量 $N$、数据量 $D$、算力 $C$ 的幂律下降：

$$L(N) \propto N^{-\alpha},\quad L(D) \propto D^{-\beta}$$

Chinchilla（Hoffmann et al. 2022）进一步指出参数量与数据量应近似同比例缩放。

## 四、代码实现

用几行示意自注意力（教学版，非优化实现）：

```python
import torch, torch.nn.functional as F

def attention(q, k, v, mask=None):
    d_k = q.size(-1)
    scores = q @ k.transpose(-2, -1) / d_k ** 0.5
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))
    weights = F.softmax(scores, dim=-1)
    return weights @ v
```

## 六、常见误区

- 误区一：认为 Transformer 一出现就「赢了」。其实 BERT/GPT 在 2018 才确立预训练范式，中间隔了一年。
- 误区二：把 GPT-3 当「会聊天」。它是续写模型，ChatGPT 才是对齐后的对话产品。
- 误区三：认为参数量越大越好。Chinchilla 表明数据不足时堆参数收益递减。

## 九、演进与趋势

(1) 从「大」到「巧」：Chinchilla 揭示数据与参数需平衡，训练效率受重视。(2) 从「生成」到「对齐」：RLHF/DPO 让模型可用。(3) 从「快答」到「慢思考」：o1/R1 引入 test-time compute。(4) 开源平民化：LLaMA、Qwen、DeepSeek 拉平能力差距。(5) 多模态与 Agent 成为新前沿。

## 十、小结

大模型时间线是一条「表示学习→架构革新→预训练范式→规模化与对齐」的清晰主线。理解每个节点的瓶颈与解法，比记忆年份更重要；当前正同时沿着推理化、多模态化、开源化三条主线演进。
