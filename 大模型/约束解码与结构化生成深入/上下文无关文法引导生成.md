# 上下文无关文法引导生成

> 对应 Willard & Louf 2023 constrained decoding; Lewis 2020 RAG; Vaswani 2017。

## 一、背景与挑战
复杂结构（程序、查询语言）难以用正则描述。上下文无关文法（CFG）可精确刻画嵌套语法，引导 LLM 生成合规字符串。

## 二、核心原理
把 CFG 编译成下推自动机，维护当前非终结符栈；每步根据栈顶可展开产生式确定合法 token，直至归约为起始符。

## 三、形式化与数学基础
文法 G = (N, T, P, S)。合法前缀集合 L(G)。解码时维护推导栈 σ，转移：
$ \sigma \xrightarrow{x} \sigma' \iff x \in \text{first}(\sigma') $
约束分布同前节 p'(x_t) 定义。

## 四、代码实现
```python
def cfg_step(grammar, stack, logits):
    allowed = grammar.next_tokens(stack)   # 由栈顶产生式推导
    return constrained_logits(logits, allowed)
```

## 五、与其他技术对比
正则适合扁平结构；CFG 表达嵌套与递归，适合代码/SQL。Schema 约束是 CFG 特例。

## 六、常见误区
误区：任何文法都能高效引导。歧义文法会导致状态爆炸，需左因子化与消除左递归。

## 七、与开源书/权威来源对应
Willard & Louf 2023; 工具见 guidance、outlines（社区实现）。参考 huggingface/transformers。

## 八、面试题
问：CFG 引导如何避免死状态？
答：仅在能完整归约到 S 的活前缀上扩展，剪枝不可达分支。

## 九、演进与趋势
增量解析 + 缓存让 CFG 引导接近无约束速度。

## 十、小结
CFG 把语法知识注入采样，使 LLM 稳定产出合法程序与查询。
