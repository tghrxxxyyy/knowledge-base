# 结构化输出落地与工具调用

> 对应 Ouyang 2022 InstructGPT; Zheng 2023 LLM-as-judge; Willard & Louf 2023 constrained decoding。

## 一、背景与挑战
Agent 与函数调用需要模型输出可被程序消费的参数。结构化生成把“自然语言→结构化参数”的解析失败率降至近零。

## 二、核心原理
将工具 JSON Schema 注入约束解码器，生成参数对象；结合系统提示说明语义，模型在合法结构内填值，外层调度直接调用函数。

## 三、形式化与数学基础
函数 f 的 Schema S_f 决定参数空间 P_f。解码约束于 I(S_f)，输出 o in P_f 直接满足 f(o) 调用契约。

## 四、代码实现
```python
def tool_call(model, schema, prompt):
    fsm = build_schema_fsm(schema)         # Schema -> 自动机
    return model.generate(prompt, fsm=fsm) # 约束生成 JSON
```

## 五、与其他技术对比
相比“让模型自己写 JSON 再 try/except”，约束生成首轮即成功，省去重试往返。

## 六、常见误区
误区：有了 Schema 就无需提示。语义说明仍必要，约束只管结构不管取值合理。

## 七、与开源书/权威来源对应
OpenAI function calling 思路；约束见 vllm-project/vllm、huggingface/transformers。参考 Ouyang 2022。

## 八、面试题
问：约束解码如何支持嵌套工具与数组？
答：FSM 对 array/object 递归展开，跟踪下标与字段完成态。

## 九、演进与趋势
模型原生支持结构化输出（如 JSON mode）+ 约束解码双保险，成为标准能力。

## 十、小结
结构化生成是 LLM 落地为可执行系统的关键接口，约束解码提供零失败保障。
