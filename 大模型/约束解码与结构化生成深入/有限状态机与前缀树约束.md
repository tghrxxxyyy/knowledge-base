# 有限状态机与前缀树约束

> 对应 Willard & Louf 2023 constrained decoding; Sennrich 2016 BPE; Kudo & Richardson 2018 SentencePiece。

## 一、背景与挑战
当合法输出是有限集合（如分类标签、固定模板），可用前缀树（trie）或 DFA 精确约束，避免越界与拼写错误。

## 二、核心原理
把候选词集构造成 trie，解码时按已生成前缀沿边下走，仅允许存在子节点的字符，到达叶节点即完成一个合法词。

## 三、形式化与数学基础
trie T 上合法续写：
$ A(w) = \{ c \mid w \cdot c \text{ 是 T 中某路径前缀} \} $
约束分布 p'(c) 同上节遮罩法。

## 四、代码实现
```python
def trie_step(node, logits, vocab):
    allowed = [vocab[c] for c in node.children]
    return constrained_logits(logits, allowed)
```

## 五、与其他技术对比
trie 适合离散候选；文法/正则适合无限结构。三者可组合成混合约束。

## 六、常见误区
误区：trie 与 BPE 冲突。需在子词层面构建 trie，使每个边对应一个 token 而非字符。

## 七、与开源书/权威来源对应
Sennrich 2016 BPE; Kudo & Richardson 2018 SentencePiece。约束实现见 huggingface/transformers。

## 八、面试题
问：如何在子词分词下做精确 trie 约束？
答：把候选序列用目标 tokenizer 编码，在 token 空间建 trie，沿 token 边约束。

## 九、演进与趋势
token 级 trie 与 FSM 缓存复用，使约束开销接近线性。

## 十、小结
前缀树/DFA 是确定集合约束的最简可靠形式，常与高级约束组合。
