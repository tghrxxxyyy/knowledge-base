# 最大更新参数化（μP）

> 对应 Yang et al., *Feature Learning in Infinite Width*, 2021（μP 命名）。

## 一、背景与挑战

标准参数化（SP）下无限宽时隐藏特征冻结不学习；μP 让特征随宽度继续学习，故名为“最大更新”。

## 二、核心原理

μP 对读取层用 $1/\text{width}$ 初始化、隐藏层用 $1/\text{fan\_in}$；学习率上读取层固定、隐藏层随宽度反比，使参数更新量在极限下非零且稳定。

## 三、数学形式

读取层 $W_{out}\sim\mathcal N(0,1/\text{width})$；隐藏更新 $\Delta W_h\propto\eta_h\cdot g/\text{width}$，极限下保持 $O(1)$。

## 四、代码实现

```python
def mup_lr(width, base_width, base_lr):
    return base_lr * (width / base_width)   # 隐藏层缩放
```

## 五、与其他对比

- 比 SP 多“特征持续学习”的能力；
- 与 模型缩放定律深入 互补（超参迁移使 scaling 更稳）。

## 六、常见误区

- 忘记输出层不缩放学习率致训练崩；
- 把 μP 当成通用提速，实际只解决极限定义。
