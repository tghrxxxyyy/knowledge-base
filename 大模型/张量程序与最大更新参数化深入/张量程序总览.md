# 张量程序总览

> 对应 Yang et al., *Tensor Programs*, 2021（μP）；与 最大更新参数化与训练稳定性 衔接。

## 一、背景与挑战

宽模型（width→∞）下不同参数化导致训练动态迥异；μP 让无限宽极限良好定义，使超参可在小模型上迁移到大模型。

## 二、核心原理

张量程序把前向/后向写成张量收缩程序，用 GP 极限推导各张量在 width→∞ 的尺度；μP 固定输入/输出层、隐藏层学习率随宽度缩放，使特征与更新稳定。

## 三、数学形式

无限宽时预激活 $z\sim\mathcal N(0,\Sigma)$；μP 要求 $\text{Var}(W)\sim 1/\text{fan\_in}$ 而学习率 $\eta_h\sim 1/\text{width}$。

## 四、代码实现

```python
# μP 初始化：隐藏层按 fan_in，学习率随宽度线性缩放
nn.init.normal_(W, 0, 1.0 / math.sqrt(fan_in))
lr_hidden = base_lr * (width / base_width)
```

## 五、与其他对比

- 与 NTK 参数化对照：μP 关注“最大更新”而非核；
- 与 标准参数化（SP）对照（见下节）。

## 六、常见误区

- 误以为 μP 仅改初始化，实际还需学习率缩放；
- 在非线性/注意力上直接套用忽略层特异尺度。

## 八、面试题

- μP 解决什么？答：让极限训练动态良定义，使超参跨宽度可迁移。

## 九、演进

NTK 参数化 → μP → 多维度 μP（深度/宽度联合）。

## 十、小结

张量程序提供宽度极限分析框架，μP 是其可迁移超参的工程落地。
