# μP 实践与训练稳定性

> 对应 mup 实践；与 训练不稳定诊断深入 / 数值稳定性深入 衔接。

## 一、背景与挑战

落地 μP 需注意优化器、并行、学习率 warmup 与 base 模型一致性。

## 二、核心原理

用 base 形状驱动；Adam 下 μP 也适用但 RMS 缩放需一致；配合线性 warmup；张量并行时按列/行切分保持尺度不变性。

## 三、数学形式

梯度尺度在并行切分 $W=[W_1;W_2]$ 时每片方差减半，μP 初始化已补偿 $\text{fan\_in}$ 口径。

## 四、代码实现

```python
from mup.optim import MuAdam
opt = MuAdam(model.parameters(), lr=lr_hidden)
```

## 五、与其他对比

- 与 ZeRO深入（见量化推理/分布式）正交；
- 与 数值稳定性深入 共保训练健康。

## 六、常见误区

- 在 base 用不同优化器致迁移失效；
- 忽略 warmup 长度随宽度变化。

## 八、面试题

- μP 与 Adam 兼容？答：兼容，但需保持 RMS 缩放一致并按 μP 设学习率。

## 九、演进

单卡 → 并行 μP → 自动 base 推导。

## 十、小结

μP 实践中需 base 一致、优化器协同与 warmup，方能稳迁移。
