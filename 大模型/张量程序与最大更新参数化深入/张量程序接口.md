# 张量程序接口（t必备）

> 对应 Yang, *Tensor Programs V*, 2022（mup 实践接口）。

## 一、背景与挑战

工程中需统一把模型层标为“标准/读/写”以套用 μP，手工易错。

## 二、核心原理

mup 提供 `set_base_shapes` 与 `infshape`：先建 base 小模型记录形状，再据目标宽度自动重设各层初始化与学习率规则（读取层、隐藏层、嵌入层分类）。

## 三、数学形式

层尺度规则 $s(layer)\in\{1/\text{width},1/\text{fan\_in},1\}$，由其在张量程序中的角色决定。

## 四、代码实现

```python
from mup import set_base_shapes, get_infshape
model = set_base_shapes(model, base_model)
infshape = get_infshape(model)
```

## 五、与其他对比

- 相对手写缩放更不易错；
- 与 分布式训练深入（张量并行）需协同调形状。

## 六、常见误区

- base 与 target 层结构不一致致 shape 映射失败；
- 在已加载权重后调用 set_base_shapes 无效。

## 八、面试题

- 张量程序接口做什么？答：据 base 形状自动把 μP 缩放套到目标模型各层。

## 九、演进

手工规则 → mup 库 → 与编译期 shape 推断融合。

## 十、小结

张量程序接口把 μP 从理论变成可复用工程件。
