# μP 与标准参数化对比

> 对应 Yang, 2021（SP vs μP 实验）。

## 一、背景与挑战

为何不直接用 PyTorch 默认（标准参数化）？需讲清差异与收益。

## 二、核心原理

SP 下隐藏层学习率不随宽度缩，无限宽时特征冻结（NTK 机制）；μP 下特征学习，且最优学习率/初始化不随宽度变，可在小模型上调好直接放大。

## 三、数学形式

SP：$\eta_h$ 常数 → 极限特征冻结；μP：$\eta_h\propto 1/\text{width}$ → 特征更新 $O(1)$。

## 四、代码实现

```python
# SP
lr = 1e-3
# μP
lr = 1e-3 * (width / base_width)
```

## 五、与其他对比

- μP 超参可迁移是核心优势；
- 与 训练超参搜索深入 结合省算力。

## 六、常见误区

- 以为 μP 让小模型训得更好（仅迁移性更好）；
- 混合 SP/μP 层致尺度割裂。

## 八、面试题

- μP 相对 SP 最大好处？答：超参跨宽度可迁移，免大模型重搜。

## 九、演进

理论对照 → 实证迁移 → 工业落地（如大厂预训练）。

## 十、小结

μP 以极限分析换取超参迁移性，显著降低扩模成本。
