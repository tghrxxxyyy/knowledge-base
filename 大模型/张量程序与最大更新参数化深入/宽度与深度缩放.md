# 宽度与深度缩放

> 对应 Yang et al., *Tensor Programs*, 2021；与 模型缩放定律深入 衔接。

## 一、背景与挑战

仅缩放宽度不够，深度/深度×宽度联合极限行为不同，需统一刻画。

## 二、核心原理

μP 主处理宽度；深度缩放需额外控制残差分支尺度 $\sim 1/\sqrt{depth}$ 防深度爆炸；多维度 μP 同时约束二者使超参跨维度迁移。

## 三、数学形式

残差输出 $x_{l+1}=x_l+\frac{1}{\sqrt{L}}\sigma(W_l x_l)$；深度 $L$ 增大时不发散。

## 四、代码实现

```python
x = x + (1.0 / math.sqrt(depth)) * block(x)
```

## 五、与其他对比

- 与 归一化技术深入（如 Pre-LN）共享深度稳定目标；
- 与 μP 宽度缩放正交互补。

## 六、常见误区

- 只做 μP 宽度忽视深度缩放致深层不稳；
- 残差尺度与学习率混淆。

## 八、面试题

- 深度缩放为何要 $1/\sqrt{L}$？答：使残差累加方差随深度有界、防爆炸。

## 九、演进

宽度 μP → 深度 μP → 联合多维 μP。

## 十、小结

宽度与深度缩放共同保证大模型极限训练动态良定义。
