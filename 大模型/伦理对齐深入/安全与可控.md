# 安全与可控对齐

> 对应 Hendrycks et al., *Unsolved Problems in ML Safety*, 2021。

## 一、背景与挑战

模型可能被滥用或产生有害输出；需安全与可控（control）。

## 二、核心原理

安全分类器拦截、拒答红线、红队持续攻防；可控性用 steer 向量/系统提示约束行为边界。

## 三、数学形式

安全概率 $P_{safe}=\sigma(s(x,a))$；$s$ 为安全打分；越界则截断。

## 四、代码实现

```python
if safety_cls(prompt) > thr: return refuse()
```

## 五、与其他对比

- 与 宪法AI深入（无害原则）衔接。
- 与 奖励黑客深入（若新增）对照风险。

## 六、常见误区

- 单层分类器易被对抗样本绕过。
- 过度拒答损可用性。

## 八、面试题

- 安全与实用如何平衡？答：分层防护+校准阈值，避免过拒。

## 九、演进

关键词过滤 → 分类器 → 红队+可控向量。

## 十、小结

安全可控靠分层防护与校准，平衡拒答与可用。
