# 伦理对齐评测实践

> 对应 Weidinger et al., *Taxonomy of Risks*, 2021（伦理风险分类）。

## 一、背景与挑战

伦理风险多维，需系统评测而非单指标。

## 二、核心原理

建伦理风险分类树，逐类构造探针数据集（歧视、隐私、有害），用红队与自动判分度量。

## 三、数学形式

风险率 $R_k=\frac{\#违规_k}{N_k}$；综合 $R=\sum_k \alpha_k R_k$。

## 四、代码实现

```python
for k in risks: report(k, eval_probe(k))
```

## 五、与其他对比

- 与 价值对齐深入（评测）共享方法。
- 与 偏见与去偏深入（歧视维度）衔接。

## 六、常见误区

- 覆盖不全（只测已知风险）。
- 自动判分误判（需人抽验）。
