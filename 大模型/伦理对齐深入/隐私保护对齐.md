# 隐私保护对齐

> 对应 Carlini et al., *The Secret Sharer*, 2021（ memorization 泄漏）；Differential Privacy。

## 一、背景与挑战

模型记忆训练数据，可能泄露个人信息；需隐私对齐。

## 二、核心原理

训练侧用 DP-SGD/机器遗忘；对齐侧拒绝泄露隐私、去标识；评测用成员推断攻击。

## 三、数学形式

DP 保证：$P(M(D)\in S)\le e^\epsilon P(M(D')\in S)+\delta$；$\epsilon$ 控泄漏。

## 四、代码实现

```python
from opacus import PrivacyEngine
pe = PrivacyEngine(model, sample_rate, noise_multiplier=1.0)
```

## 五、与其他对比

- 与 公平性深入（受保护属性）相关。
- 与 价值对齐深入（隐私为价值）衔接。

## 六、常见误区

- 仅提示层拒答不防记忆泄漏。
- DP 过强损能力。

## 八、面试题

- 如何防泄露？答：DP训练+遗忘+拒泄露评测，多层防护。

## 九、演进

提示拒答 → DP训练 → 遗忘+攻击评测。

## 十、小结

隐私对齐需训练与对齐双管，防记忆与泄露。
