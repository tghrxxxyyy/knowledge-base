# 责任与透明对齐

> 对应 EU AI Act 问责要求；模型卡（Model Cards, Mitchell et al., 2019）。

## 一、背景与挑战

黑箱决策难问责；需透明与可追溯机制。

## 二、核心原理

通过提示水印、决策溯源、模型卡披露限制与数据来源；推理侧给可解释理由与置信。

## 三、数学形式

可解释度 $E=\mathbb E[\text{faithful}(reason, a)]$；溯源率覆盖输入链路。

## 四、代码实现

```python
log.decision(ans, prompt, refs, conf)
```

## 五、与其他对比

- 与 长文档切分深入（溯源）共享。
- 与 验证器深入（判分透明）衔接。

## 六、常见误区

- 伪解释（事后编造理由）。
- 透明增加攻击面（提示泄露）。
