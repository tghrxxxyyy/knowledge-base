# 积分梯度（Integrated Gradients）

> 对应 Sundararajan et al., *Axiomatic Attribution for Deep Networks*, 2017.

## 一、背景与挑战

梯度法在饱和区失效；积分梯度满足归因公理（完整性、灵敏度），给出无饱和偏差的归因。

## 二、核心原理

沿从基线 $x'$ 到输入 $x$ 的直线路径积分梯度，把总变化分配到各输入维度。

## 三、数学形式

$IG_i(x)=\left(x_i-x'_i\right)\int_0^1\frac{\partial F(x'+\alpha(x-x'))}{\partial x_i}\,d\alpha$；满足 $\sum_i IG_i=F(x)-F(x')$。

## 四、代码实现

```python
alphas = torch.linspace(0,1,steps=50)
path = x_prime[None] + alphas[:,None,None]*(x-x_prime)[None]
grads = torch.autograd.grad(F(path), path, torch.ones_like(F(path)))[0]
ig = (x-x_prime)*(grads.mean(0))
```

## 五、与其他对比

- 满足完整性，优于朴素梯度；代价是多次前向/反向。
- 与 因果中介分析（更强因果语义）衔接。

## 六、常见误区

- 基线选择影响归因（零向量/中性句需合理）。
- 高维路径积分计算贵。

## 八、面试题

- 积分梯度为何满足完整性？答：沿基线到输入路径积分梯度，由微积分基本定理恰好等于输出差。

## 九、演进

梯度显著图 → 积分梯度 → 路径集成/期望梯度。

## 十、小结

积分梯度以路径积分消除饱和偏差，是满足归因公理的可靠方法。
