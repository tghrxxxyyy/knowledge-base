# 显著图与梯度法

> 对应 Simonyan et al., 2013；Baehrens et al., *How to Explain Individual Classification Decisions*, 2010.

## 一、背景与挑战

最直观的归因是看输入 token 对目标输出的梯度幅度，但朴素梯度噪声大且易饱和。

## 二、核心原理

显著图取 $\left|\frac{\partial F}{\partial x}\right|$ 或 guided/smooth 变体；smoothgrad 对输入加噪多次取平均抑制噪声。

## 三、数学形式

平滑梯度 $\hat g=\frac1N\sum_{k=1}^N \nabla_x F(x+\epsilon_k)$，$\epsilon_k\sim\mathcal N(0,\sigma^2)$。

## 四、代码实现

```python
g = torch.autograd.grad(out, embeds, retain_graph=True)[0].abs()
smooth = sum(torch.autograd.grad(F(embeds+n), embeds)[0].abs()
             for n in [torch.randn_like(embeds)*0.1 for _ in range(50)])/50
```

## 五、与其他对比

- 比积分梯度快但不满足完整性；适合快速扫描。
- 与 激活监控深入（内部激活而非输入梯度）不同视角。

## 六、常见误区

- 仅看幅度忽略符号（正负贡献）。
- 饱和区梯度为零，显著图全黑。

## 八、面试题

- smoothgrad 为何降噪？答：多次加噪平均抵消梯度估计方差，凸显稳定重要区域。

## 九、演进

朴素梯度 → guided backprop → smoothgrad → 积分梯度。

## 十、小结

梯度显著图简单快，但受饱和与噪声限制，常作初步归因手段。
