# 激活修补（Activation Patching）

> 对应 Meng et al., *Locating and Editing Factual Associations*, 2022（ROME）；Geiger et al., *Causal Abstractions*, 2021.

## 一、背景与挑战

仅看梯度不够：要确认某激活“因果地导致”行为，需做干预实验 — 替换激活看行为是否改变。

## 二、核心原理

在干净输入上缓存某层激活，在腐败输入上运行到该层后替换为干净激活（patch），若输出恢复则说明该激活因果负责。

## 三、数学形式

令 $h^{(l)}$ 为层 $l$ 残差流激活，干预 $\tilde h^{(l)}=h_{clean}^{(l)}$ 后 $\hat y=\text{Model}(x_{corrupt};\tilde h^{(l)})$；恢复度度量因果贡献。

## 四、代码实现

```python
clean = run_get_act(model, x_clean)
def patched_hook(mod, inp, out):
    return out + (clean[l] - out)   # 替换第 l 层
with model.layers[l].register_forward_hook(patched_hook):
    out = model(x_corrupt)
```

## 五、与其他对比

- 比积分梯度更具因果性（真正干预）。
- 与 回路分析深入（定位哪些头组成回路）配合。

## 六、常见误区

- 仅 patch 单一位置可能漏掉分布式贡献。
- 残余流 vs 注意力输出选择错层。

## 八、面试题

- 激活修补为何比梯度更可信？答：直接干预并观测行为变化，建立因果而非仅相关性。

## 九、演进

梯度归因 → 单点 patch → 因果中介/路径修补。

## 十、小结

激活修补以干预确立因果，是机制可解释性的核心实验手段。
