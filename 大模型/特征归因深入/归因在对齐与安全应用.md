# 特征归因在对齐与安全中的应用

> 对应 Zou et al., *Representation Engineering*, 2023；Burns et al., *Discovering Latent Knowledge*, 2022.

## 一、背景与挑战

对齐/安全需解释“模型为何输出危险内容”，归因可定位触发危险的输入/内部特征。

## 二、核心原理

用归因定位促发有害输出的 token/激活，再针对性做消融（ablation）或 steering 抑制；也可解释后门触发器。

## 三、数学形式

危险概率变化 $\Delta p=\sum_i A_i\cdot \mathbb I(\text{token}_i\in\text{trigger})$；steering 向量 $v=\bar h_{harm}-\bar h_{safe}$。

## 四、代码实现

```python
harmful_act = cache[trigger_inputs].mean(0)
safe_act = cache[clean_inputs].mean(0)
steer = harmful_act - safe_act
model.layers[l].bias += alpha*steer
```

## 五、与其他对比

- 与 激活监控深入（在线检测危险激活）衔接。
- 与 稀疏自编码器深入（单义特征定位）互补。

## 六、常见误区

- 仅离线归因忽略部署时分布偏移。
- steering 过强损伤正常能力。

## 八、面试题

- 归因如何辅助安全？答：定位危险触发特征并干预（消融/steering），或在线监控对应激活。

## 九、演进

离线解释 → 特征 steering → 实时监控干预。

## 十、小结

特征归因从诊断走向干预，成为对齐与安全的实用工具。
