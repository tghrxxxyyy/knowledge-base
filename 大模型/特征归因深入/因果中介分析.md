# 因果中介分析（Causal Mediation）

> 对应 Vig et al., *Causal Mediation Analysis for Interpreting Neural NLP*, 2020；Pearl, *Causality*, 2009.

## 一、背景与挑战

要分离“直接效应”与“间接效应”（通过中间变量传导），需因果图与反事实干预框架。

## 二、核心原理

定义中介变量 $M$（如某注意力头），估计自然直接效应 NDE 与自然间接效应 NIE，量化各组件贡献。

## 三、数学形式

$NIE=\mathbb E[Y(x,M(x'))]-\mathbb E[Y(x',M(x'))]$；$NDE=\mathbb E[Y(x,M(x'))]-\mathbb E[Y(x',M(x'))]$ 互补分解总效应。

## 四、代码实现

```python
y_base = model(x)
nde = model(x, mediate=M_from(x_prime)) - model(x_prime)
nie = model(x) - model(x, mediate=M_from(x_prime))
```

## 五、与其他对比

- 比单点 patch 给出效应分解（直接/间接）。
- 与 回路分析深入 共享反事实干预范式。

## 六、常见误区

- 混淆相关中介与因果中介（需反事实）。
- 忽略多个中介的串行依赖。

## 八、面试题

- NIE 与 NDE 区别？答：NIE 经中介传导的效应，NDE 不经中介的直接效应，二者分解总效应。

## 九、演进

相关归因 → 反事实 patch → 结构化因果中介。

## 十、小结

因果中介把归因提升为可分解的因果效应，是严谨可解释性的基础。
