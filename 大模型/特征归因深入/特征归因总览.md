# 特征归因总览

> 对应 Simonyan et al., *Deep Inside Convolutional Networks*, 2013；Sundararajan et al., *Axiomatic Attribution for Deep Networks*, 2017.

## 一、背景与挑战

LLM 决策 opaque；特征归因把输出/行为追溯到输入 token 或内部激活，回答“哪些输入/神经元导致该输出”。

## 二、核心原理

分为输入级（token 重要性）与内部级（激活修补、因果中介）。输入级用梯度/扰动度量输入变化对输出的影响；内部级在模型计算图上做干预实验。

## 三、数学形式

归因满足完整性：$\sum_i A_i(x)=F(x)-F(x_{baseline})$；梯度法 $A_i=\frac{\partial F}{\partial x_i}$。

## 四、代码实现

```python
import torch
logit = model(input_ids).logits[0, -1, target]
grads = torch.autograd.grad(logit, embeds, retain_graph=True)[0]
saliency = grads.norm(dim=-1)
```

## 五、与其他对比

- 与 探针分析深入（查“含什么信息”）互补：归因查“导致什么输出”。
- 与 回路分析深入（细粒度因果路径）衔接。

## 六、常见误区

- 梯度饱和/为零时归因失效（需积分梯度）。
- 把相关性当因果（归因非严格因果，需干预验证）。

## 八、面试题

- 为何梯度归因会饱和？答：ReLU/sigmoid 饱和区梯度近零，无法反映真正重要性，需积分梯度。

## 九、演进

显著性图 → 积分梯度 → 激活修补/因果归因。

## 十、小结

特征归因是打开 LLM 黑箱的第一把钥匙，从输入重要性到内部因果逐步深入。
