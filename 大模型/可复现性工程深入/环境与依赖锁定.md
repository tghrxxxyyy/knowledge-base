# 环境与依赖锁定

> 见「可复现性工程深入/可复现性总览」；容器/锁文件。

## 一、背景与挑战

依赖版本漂移导致代码在新环境跑不出。

## 二、核心原理

用 `requirements.txt`/`poetry.lock`/`environment.yml` 锁定版本；更进一步用 Docker 镜像固化 OS+CUDA+库，做到「一次构建处处运行」。GPU 驱动/CUDA 版本也需记录。

## 三、关键要点

- 锁文件比 `>=` 更可靠。
- 容器是最终保障。

## 四、代码实现

```bash
pip freeze > requirements.lock
docker build -t exp:1.0 .
```

## 五、与其他对比

- 锁文件轻；容器全。
