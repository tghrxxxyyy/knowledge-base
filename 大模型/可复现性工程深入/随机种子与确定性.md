# 随机种子与确定性

> 见「可复现性工程深入/可复现性总览」；Python/NumPy/PyTorch 种子。

## 一、背景与挑战

同代码不同次运行结果略异，难定位。

## 二、核心原理

需设定所有随机源：Python `random`、NumPy、PyTorch CPU/GPU、CUDA 卷积确定性。用 `torch.use_deterministic_algorithms(True)` 强制确定性（部分算子变慢或不可用）。分布式需固定 `torch.distributed` 初始化顺序。

## 三、关键要点

- GPU 浮点原子加非确定是主因。
- `cudnn.deterministic=True` 牺牲速度换确定。

## 四、代码实现

```python
import os
os.environ["CUBLAS_WORKSPACE_CONFIG"]=":4096:8"
torch.backends.cudnn.deterministic = True
```

## 五、与其他对比

- 近似复现常见；严格确定需付出速度。
