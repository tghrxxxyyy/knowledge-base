# 实验随机性来源

> 见「可复现性工程深入/随机种子与确定性」；细数非确定来源。

## 一、背景与挑战

知道要可复现，但不知随机从哪来。

## 二、核心原理

主要来源：1) 权重初始化；2) 数据洗牌（shuffle）；3) 数据增强随机性；4) Dropout 随机掩码；5) GPU 并行非确定求和；6) 多线程 DataLoader 顺序；7) 分布式 all-reduce 顺序。需逐一固定。

## 三、关键要点

- 分布式训练顺序需一致。
- 增广随机性常被忽略。

## 四、代码实现

```python
g = torch.Generator(); g.manual_seed(0)
loader = DataLoader(ds, shuffle=True, generator=g)
```

## 五、与其他对比

- 单卡简单；多卡复杂。

## 六、常见误区

- 只看训练随机——推理 Dropout 也随机。
