# 价值观对齐

> 对应 Ouyang et al. 2022 InstructGPT/RLHF、Bai et al. 2022 Constitutional AI（原则式对齐）与 Rafailov et al. 2023 DPO。

## 一、背景与挑战

大模型在预训练语料中习得了来源广泛、立场多样的文本分布，其默认输出未必符合目标市场的法律法规、公序良俗与社会规范。价值观对齐的目标是让模型在回答涉及道德判断、文化习俗、社会争议的问题时，贴合特定地域与人群的规范，同时不输出可能引发冒犯或违规的内容。核心挑战有三：一是规范具有地域与文化差异，全球化预训练模型难以天然适配本地语境；二是规范本身随社会演进而变化，需要持续校准而非一次性对齐；三是过度对齐会损伤模型在正当领域（医学、历史、法律讨论、创意写作）的表达与分析能力，产生「对齐税」（alignment tax）。此外，谁的价值、以何种程序确定，本身就是需要显式决策并记录的问题。

## 二、核心原理

价值观对齐是在通用指令对齐之上叠加「本地化、可审计的偏好」的一层，常见做法有四条路径：

1. 本地化偏好数据：由熟悉目标法域与文化的标注者产出 chosen/rejected 对，直接用于 DPO/PPO 训练。数据需覆盖高频争议场景，并保留「正当回答不应被拒」的对照样本。
2. 原则式约束（宪法 AI 思路）：把价值立场写成自然语言原则集，让模型依据原则自评与修订，既用于推理时护栏，也用于生成自标注偏好数据。
3. 推理期约束：在系统提示中注入立场声明与回答口径，可热更新，但易被越狱绕过，属于「软约束」。
4. 持续监控与回训：用合规评测与偏见基准跟踪价值偏差，发现漂移及时补充数据回训。

它本质上是把「对齐于谁」（alignment to whom）显式化：对齐对象从抽象的「通用人类偏好」细化为「特定社群或法域的规范」，并把规范以可测试的形式固定下来。工程上推荐训练期与推理期结合——训练期塑造倾向，推理期提供可快速调整的兜底。

## 三、形式化与数学基础

在偏好优化框架中，价值观对齐改变的是偏好数据的分布，而非优化目标结构。以 DPO 损失为例：

$$ \mathcal{L}_{\text{DPO}} = -\,\mathbb{E}_{(x,y_w,y_l)\sim\mathcal{D}_{\text{local}}} \left[ \log \sigma\!\left( \beta \log \frac{\pi_\theta(y_w\mid x)}{\pi_{\text{ref}}(y_w\mid x)} - \beta \log \frac{\pi_\theta(y_l\mid x)}{\pi_{\text{ref}}(y_l\mid x)} \right) \right] $$

其中 $\mathcal{D}_{\text{local}}$ 为本地化偏好数据，$\beta$ 控制相对参考策略的偏离强度。若采用带 KL 约束的 RL 形式，目标为：

$$ \max_{\theta}\ \mathbb{E}_{x,y\sim\pi_\theta}\big[r_{\text{local}}(x,y)\big] - \beta\,\mathbb{D}_{\text{KL}}\big(\pi_\theta \,\|\, \pi_{\text{ref}}\big) $$

对齐税可量化为对齐后在通用能力基准上的性能变化：

$$ \Delta_{\text{tax}} = \text{Score}_{\text{general}}(\pi_{\text{ref}}) - \text{Score}_{\text{general}}(\pi_\theta) $$

理想做法是把 $\Delta_{\text{tax}}$ 作为约束项，在价值指标达标的前提下最小化能力损失，而不是单方面追求价值指标最大化。

## 四、代码实现

```python
# 用本地化偏好数据做 DPO 价值观对齐（基于 huggingface/trl，接口以官方最新文档为准）
from trl import DPOConfig, DPOTrainer


def build_local_prefs(raw_pairs, principles):
    # raw_pairs: [(x, y_chosen, y_rejected), ...]，由本地标注者产出
    data = []
    for x, chosen, rejected in raw_pairs:
        if not passes_principles(chosen, principles):
            continue            # 过滤掉与原则冲突的 chosen，避免把错误规范注入模型
        data.append({"prompt": x, "chosen": chosen, "rejected": rejected})
    return data


def align_values(model, ref_model, local_prefs, beta=0.1):
    args = DPOConfig(
        beta=beta,                      # 越小越偏离参考策略，对齐越强、对齐税风险越高
        per_device_train_batch_size=4,
        max_length=2048,
        logging_steps=10,
    )
    trainer = DPOTrainer(
        model=model,
        ref_model=ref_model,
        args=args,
        train_dataset=local_prefs,
    )
    trainer.train()
    return model


# 推理期软约束：可热更新的立场声明（注意：可被越狱，仅为兜底之一）
def with_value_guardrail(system_prompt, principles):
    return system_prompt + "\n回答需遵循以下原则：\n" + "\n".join("- " + p for p in principles)
```

## 五、与其他技术对比

- 通用对齐 vs 本地对齐：通用对齐追求广泛人群满意，本地对齐针对特定法域更精准，但泛化范围收窄，需防止过拟合到本地数据。
- 训练期对齐 vs 推理期约束：训练期改变权重、效果持久但迭代慢；推理期用系统提示灵活可热更，但易被越狱绕过。
- 价值观对齐 vs 安全过滤：前者塑造「应当如何表达」，后者拦截「不许说什么」，二者互补而非替代。
- DPO 式离线对齐 vs PPO 式在线对齐：DPO 简单稳定、无需奖励模型；PPO 上限更高但工程复杂、需防奖励黑客。

## 六、常见误区

- 「一套价值观全球通用」：忽略地域与文化差异，易引发本地违规或冒犯。
- 「对齐一次永久有效」：社会规范与法规在变，需持续校准与回归评测。
- 「价值观对齐无代价」：过度约束会损伤正当领域的分析能力，必须监控对齐税。
- 「原则写得越细越好」：原则过细易相互冲突，过粗则批评空洞，需要分层组织并做冲突消解测试。

## 七、与开源书·权威来源对应

- Ouyang et al. 2022（InstructGPT）：人类反馈对齐的基础范式，确立 SFT + RM + PPO 三段式流程。
- Bai et al. 2022（Constitutional AI）：用原则表达价值立场、实现自标注与自批判对齐。
- Rafailov et al. 2023（DPO）：把 RLHF 转化为闭式偏好优化，降低价值观对齐的工程门槛。
- Lee et al. 2023（RLAIF）：用 AI 反馈替代部分人类标注，可与原则式对齐结合。
- llm-course（mlabonne）：对齐章节对 RLHF/DPO 的工程实践有系统梳理。

## 九、演进与趋势

价值观对齐正从「人工标注偏好」走向「原则可编程、可测试、可审计」：把价值立场写成可自动测试的原则集，用对抗样本验证原则是否被真正遵守；探索在表征层面做可控的方向编辑，实现细粒度、可回滚的价值调整；与宪法 AI、RLAIF 结合降低标注成本；同时把「谁定义规范、如何更新规范」的治理流程制度化，使对齐对象与过程本身可被审计。

## 十、小结

价值观对齐回答的是「模型为谁、依何种规范说话」的问题。它是模型本地化合规与可信落地的关键环节，需要在精准、动态与效用之间持续平衡，并用可测试的指标把规范固化下来。
