# 内容安全体系

> 对应 llm-course 安全章与国内生成式 AI 服务管理办法。

## 一、背景与挑战

生成内容需合法合规，防违法不良信息。

## 二、核心原理

输入审核+生成约束+输出审核+日志留痕，形成「事前-事中-事后」体系，配合人工复核。

## 三、关键要点

- 全链路留痕便于追责。
- 需覆盖多模态。

## 四、代码实现

```python
if not content_safe(q) or not content_safe(out): handle()
```

## 五、与其他对比

- 单点审核漏；体系化稳。

## 六、常见误区

- 模型自己会拒——需外部审核。

## 七、与开源书对应

- llm-course: https://github.com/mlabonne/llm-course
- 生成式AI服务安全基本要求。
