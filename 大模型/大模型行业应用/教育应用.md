# 教育应用

> 对应 dair-ai Prompt Engineering Guide、Wei et al. 2022（Chain-of-Thought Prompting）、HuggingFace Transformers 文档。

## 一、背景与挑战

教育场景强调"学会"而非"得到答案"：解题讲解、个性化练习、作文批改、语言陪练都需要符合教学法（pedagogy）。核心挑战：其一，**防直接给答案**——直接抛结果剥夺思考，违背"脚手架式引导"原则；其二，**错误诊断**，要能识别学生卡点而非只判对错；其三，**分步讲解（CoT）**，复杂题需把推理链显式呈现；其四，**适龄语言**，对小学生与大学生表述应分层；其五，**多模态**，数学公式、几何图、手写体都需理解；其六**动机与情感**，鼓励式反馈比冷冰冰判分更能维持学习意愿；其七**评测难**，需对照标准答案与步骤分，不仅看最终结果对错，还要评估"会不会做"。

## 二、核心原理

教育助手的范式是"引导式对话 + 过程性评价"：

1. **苏格拉底式提问**：模型先反问、给提示，逐步逼近答案，而非一步到位。
2. **思维链讲解**：用 CoT 把解题步骤序列化，便于学生跟随。
3. **错误定位**：对比学生作答与标准解，定位错在概念、计算还是粗心。
4. **个性化循环**：依据历史表现动态调整难度与提示粒度，形成练习闭环。
5. **鼓励性反馈**：在指出错误同时给出正向激励，维持学习动机。

## 三、形式化与数学基础

把"引导"建模为策略优化：教学 agent 在状态 $s$（学生当前理解）下选择动作 $a$（提示/追问），目标是最大化学习收益 $R$：

$$\max_\pi \mathbb{E}\left[\sum_{t} \gamma^t R(s_t, a_t)\right],\quad a_t\sim \pi(\cdot\mid s_t)$$

其中 $\pi$ 为引导策略。CoT 可视为把隐式推理显式展开：

$$P(y\mid x) \approx P(z\mid x)\,P(y\mid x, z),\quad z=\text{推理步骤}$$

即先生成中间步骤 $z$ 再得答案 $y$，提升可解释与正确率。错误诊断可加一个分类头 $g(h)\to\{\text{概念,计算,粗心}\}$。

## 四、代码实现

一个引导式解题提示构造示例：

```python
def tutor_prompt(problem: str, student_ans: str | None, grade: int) -> str:
    base = (f"你是循循善诱的家教，面向{grade}年级学生，不要直接给最终答案；"
            "先给一个提示，再追问让学生思考，语气鼓励。")
    if student_ans is None:
        return f"{base}\n题目：{problem}\n请先给思路提示。"
    return (f"{base}\n题目：{problem}\n学生作答：{student_ans}\n"
            "请诊断错误类型(概念/计算/粗心)并给出下一步提示。")

def diagnose(student_ans, gold):                 # 可选小模型做错误分类
    return "计算" if numeric_close(student_ans, gold) else "概念"
```

## 六、常见误区

- **直接输出答案**：短期"爽"但损害学习，应给脚手架。
- **不分年龄层**：同一套话术对小初高无效。
- **只判对错不诊断**：学生反复错在同一点却无干预。
- **公式图不理解**：纯文本模型读不懂手写/几何，需多模态。
- **负反馈过重**：只纠错不鼓励，打击学习意愿。
- **思维外包**：长期代劳致学生不独立思考，应循序渐进撤提示。

## 九、演进与趋势

从"单题讲解"走向"长期学习伙伴"（记忆学生画像与薄弱点）；多模态理解手写与公式；与课标对齐的自动出题与错因知识图谱；基于强化学习优化引导策略以最大化真实学习增益；家校协同中生成个性化学习报告，并按掌握度动态撤去提示以培养独立解题。

## 十、小结

教育应用的核心矛盾是"给答案"与"教方法"。以引导式提示 + CoT 讲解 + 错误诊断构建脚手架，配合适龄、多模态与鼓励性反馈，并随掌握度逐步撤提示，才能真正把大模型变成"会教"的助手而非"答案机"。
