# 评测与追踪联动

> 对应 vllm-project/vllm 与 EleutherAI/lm-evaluation-harness。

## 一、背景与挑战
评测分数异常时需快速定位是数据、模型还是链路问题，追踪可提供因果。

## 二、核心原理
把每次评测请求也打 trace，分数与 span 关联，支持按失败样本回放链路。

## 三、形式化与数学基础
失败归因概率：
$ P(\text{cause}=c \mid \text{fail}) \propto P(\text{fail} \mid c) P(c) $

## 四、代码实现
```python
def link_eval(trace_id, score):
    store.tag(trace_id, 'eval_score', score)
    if score < 0.5:
        store.flag(trace_id, 'low_score')
```

## 五、与其他技术对比
孤立评测难定位，联动追踪缩短 MTTR。

## 六、常见误区
评测不传 trace 上下文；只存分数不存链路。

## 七、与开源书/权威来源对应
vllm-project/vllm 追踪；EleutherAI harness 提供评测入口。

## 八、面试题

## 九、演进与趋势

## 十、小结
