# 生产环境采样与成本归因

> 对应 vllm-project/vllm 与 Kwon 2023 vLLM。

## 一、背景与挑战
全量 tracing 成本高，需要采样并精确把开销归因到业务与用户。

## 二、核心原理
按路径、用户、错误率动态采样，并把 token 与时延成本分摊到调用方。

## 三、形式化与数学基础
成本归因：
$ \text{cost}(u) = \sum_{s \in \mathrm{spans}(u)} c_{token} \cdot n_s $

## 四、代码实现
```python
def attribute(spans, unit_cost):
    return {u: sum(unit_cost * s['tokens'] for s in spans[u]) for u in spans}
```

## 五、与其他技术对比
全量贵但完整，采样省但需保证关键路径必采。

## 六、常见误区
均匀采样丢失长尾错误；归因忽略缓存命中。

## 七、与开源书/权威来源对应
vllm-project/vllm 的计费指标；Kwon 2023 提升吞吐降低成本。

## 八、面试题
如何设计保证错误必采的采样策略？

## 九、演进与趋势
实时成本看板与配额联动。

## 十、小结
采样与归因让 LLM 运维可量化、可控。
