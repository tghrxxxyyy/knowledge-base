# 对比学习与批内负例

> 对应 Karpukhin et al., 2020；Xiong et al., *Approximate Nearest Negative*, 2020（批内负例）。

## 一、背景与挑战

逐对构造负例昂贵；批内负例（in-batch negatives）把同批其他 query 的正例当作本 query 负例，省显存但引入假负例噪声。

## 二、核心原理

一个 batch 内 $B$ 个 (q,p) 对，对 query $i$ 而言其余 $B-1$ 个 passage 视为负例，构成 $B\times B$ 对比矩阵；训练用 InfoNCE 式对数似然。

## 三、数学形式

$\mathcal L_i = -\log\frac{\exp(s_i^+/\tau)}{\exp(s_i^+/\tau)+\sum_{j\ne i}\exp(s(q_i,p_j)/\tau)}$，温度 $\tau$ 平滑分布。

## 四、代码实现

```python
scores = q_emb @ p_emb.t() / tau
loss = F.cross_entropy(scores, torch.arange(B))
```

## 五、与其他对比

- 比 离线难负例 省算力但需大 batch 增负例数。
- 与 嵌入模型训练深入 共享 InfoNCE 框架。

## 六、常见误区

- 批内假负例（同义 passage 被当负）拉低精度，可用去重缓解。
- 温度 $\tau$ 设太小过自信、太大欠区分。

## 八、面试题

- 批内负例缺点？答：同批其他正例可能是真相关（假负例），需大 batch 与去重。

## 九、演进

逐对负例 → 批内负例 → 去偏批内负例。

## 十、小结

批内负例以低成本放大负例数，是大模型检索训练默认技巧，须防假负例。
