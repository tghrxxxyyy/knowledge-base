# 稠密检索评估与榜单

> 对应 Thakur et al., *BEIR*, 2021（跨域零样本评测）；Nguyen et al., *MS MARCO*, 2016。

## 一、背景与挑战

检索质量须多域验证，避免过拟合单基准；需 Recall@k 与 NDCG@k 双指标。

## 二、核心原理

域内用 MS MARCO 看排序；跨域用 BEIR 18 个数据集看零样本泛化；常以 Recall@100/NDCG@10 报告。

## 三、数学形式

Recall@k $= \frac{|\text{rel}\cap\text{topk}|}{|\text{rel}|}$；$NDCG@k$ 对位置加权（见混合检索评估）。

## 四、代码实现

```python
from pyserini.eval import Evaluate
ndcg = Evaluate.evaluate_run(run, qrels, "ndcg_cut_10")
```

## 五、与其他对比

- 与 检索重排序深入（评估指标）共享。
- 与 混合检索深入（对比单/混合）衔接。

## 六、常见误区

- 只在 MS MARCO 调优忽略 BEIR 泛化。
- 只看 Recall@100 忽略前排精度。

## 八、面试题

- 为何需要 BEIR？答：测跨域零样本泛化，避免只在单一基准过拟合。

## 九、演进

单基准 → BEIR 多域 → 大规模指令检索（MTEB）。

## 十、小结

稠密检索评估须域内+跨域并重，Recall 与 NDCG 互补看召回与排序。
