# 检索模型知识蒸馏

> 对应 Hofstätter et al., *ColBERTv2*, 2021（用交叉编码器蒸馏多向量）；Hinton et al., 2015（蒸馏）。

## 一、背景与挑战

强检索器（交叉编码器/大模型）慢难上线；把其排序知识蒸馏到轻量双塔/多向量学生模型。

## 二、核心原理

用教师（cross-encoder）对 (q,d) 打分为软标签，学生（bi-encoder）以 KL/均方对齐分数；也可用教师召回列表做列表蒸馏。

## 三、数学形式

蒸馏损失 $\mathcal L_{KD}=\sum_{(q,d)}\text{KL}(P_T(\cdot|q)\|P_S(\cdot|q))$；总损失 $\mathcal L=\mathcal L_{CE}+\alpha\mathcal L_{KD}$。

## 四、代码实现

```python
soft = F.softmax(teacher_scores/ T, 0)
loss = kl(F.softmax(stu/ T,0), soft)
```

## 五、与其他对比

- 与 迟交互深入（ColBERTv2 蒸馏）共享。
- 与 检索重排序深入（教师即重排器）衔接。

## 六、常见误区

- 温度 T 不当致软标签信息丢失。
- 只蒸馏分数忽略列表顺序（宜加排序蒸馏）。

## 八、面试题

- 蒸馏检索为何有效？答：教师提供细粒度排序软标签，学生以低延迟逼近其质量。

## 九、演进

交叉编码器 → 蒸馏双塔 → 蒸馏多向量。

## 十、小结

蒸馏把强检索器知识压入轻量模型，是质量-延迟权衡的常用手段。
