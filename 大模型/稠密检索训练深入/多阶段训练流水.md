# 稠密检索多阶段训练

> 对应 Gao & Callan, *COIL*, 2021；Qu et al., *RocketQA*, 2021（迭代式训练）。

## 一、背景与挑战

单阶段训练受初始负例质量限制；多阶段逐步提升难负例与数据规模。

## 二、核心原理

先用随机/批内负例训初版，再以其召回难负例重训，循环；RocketQA 用上一轮召回的难负例+去噪交叉训练提升。

## 三、数学形式

迭代目标 $\mathcal L^{(t)} = \mathcal L(\theta^{(t-1)}\text{ 召回的难负例})$；参数 $\theta^{(t)}$ 递进更新。

## 四、代码实现

```python
for t in range(T):
    hard = mine_hard(model, corpus); model = train(model, hard)
```

## 五、与其他对比

- 与 难负例挖掘 同一思路的循环版。
- 与 检索器训练深入（端到端）对照。

## 六、常见误区

- 迭代过多次致过拟合难负例分布。
- 难负例未去噪引入标注错误。

## 八、面试题

- 多阶段训练好处？答：负例质量随模型提升而提升，逐步逼近难分布。

## 九、演进

单阶段 → 难负例迭代 → 联合去噪。

## 十、小结

多阶段训练以自举式难负例提升检索质量，须防过拟合与噪声。
