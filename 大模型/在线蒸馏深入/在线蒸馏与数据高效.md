# 在线蒸馏与数据高效学习

> 对应 数据高效训练（数据蒸馏 / 课程式软标签）；与 数据高效提示深入 衔接。

## 一、背景与挑战

标注昂贵时，在线蒸馏可用未标注数据通过教师生成软标签做半监督训练，大幅降低对标注的依赖。

## 二、核心原理

教师为无标注样本打软标签（伪标签），学生在线学习；配合一致性正则（同一样本增广后输出一致）提升对小数据的利用率。

## 三、数学形式

无标注样本损失 $\mathcal L_{un}= \mathbb E_{x\sim U}\big[\mathrm{KL}(p_T(x)\|p_S(x))\big]$；总损失为标注 CE 与无标注蒸馏之和。

## 四、代码实现

```python
pseudo = teacher(unlabeled).detach()
loss = ce(student(labeled), y) + lam * kl(student(unlabeled), pseudo)
```

## 五、与其他对比

- 与 数据高效提示深入 殊途同归：都用更少监督达成目标。
- 与 早停与检查点选择深入 配合（少数据易过拟合，需早停）。

## 六、常见误区

- 教师伪标签错误被学生固化（需置信度阈值过滤）。
- 无标注分布偏离致负迁移。

## 八、面试题

- 在线蒸馏如何省标注？答：用教师对无标注数据生成软伪标签，学生半监督学习降低标注需求。

## 九、演进

全监督蒸馏 → 半监督软标签 → 自训练循环。

## 十、小结

在线蒸馏结合伪标签，是把有限标注放大为有效监督的数据高效手段。
