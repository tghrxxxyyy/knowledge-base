# 在线蒸馏与大模型微调

> 对应 蒸馏微调（如 DistilBERT, Sanh et al., 2019）；与 参数高效微调 衔接。

## 一、背景与挑战

把大模型能力迁移到小模型供部署，需在微调阶段用在线蒸馏保留大模型语言/推理能力。

## 二、核心原理

以大模型（如 LLM）为在线教师，对小模型（如小底座或 LoRA 适配后模型）做软标签蒸馏，结合下游任务 CE，使小模型兼顾通用性与任务性。

## 三、数学形式

损失 $\mathcal L = \gamma\, T^2\mathrm{KL}\big(\sigma(z_T/T)\|\sigma(z_S/T)\big)+(1-\gamma)\mathcal L_{task}$；温度 $T$ 拉开暗知识。

## 四、代码实现

```python
with torch.no_grad():
    t_logits = teacher(input_ids).logits
s_logits = student(input_ids).logits
loss = gamma * kl(s_logits/ T, t_logits/ T) * T*T + (1-gamma)*ce(s_logits, labels)
```

## 五、与其他对比

- 与 参数高效微调深入 互补：蒸馏造小模型，PEFT 在原模型内适配。
- 与 数据高效提示深入 同属"低成本获取大模型能力"。

## 六、常见误区

- 教师与学生架构差异过大致对齐困难（中间层匹配可缓解）。
- 过度蒸馏致学生丧失多样性（温度与权重需平衡）。

## 八、面试题

- 蒸馏微调如何保留大模型能力？答：以大模型软标签为监督，把暗知识迁移到小模型，兼顾通用与任务。

## 九、演进

全量蒸馏 → 任务蒸馏 → 阶段式课程蒸馏。

## 十、小结

在线蒸馏微调是把大模型能力高效压缩进小模型的主力范式。
