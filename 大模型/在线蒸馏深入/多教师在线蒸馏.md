# 多教师在线蒸馏

> 对应 You et al., *Large Batch*, 2017（集成教师思想）；集成蒸馏实践。

## 一、背景与挑战

单一教师偏见受限；多教师集成提供多样视角，学生学得更具鲁棒性的表示，但计算成本上升。

## 二、核心原理

多个异构教师各自产生软标签，对学生做平均或加权融合监督；可用门控根据样本动态选教师权重。

## 三、数学形式

融合软标签 $\bar p= \sum_{k=1}^K w_k p^{(k)}$，$w_k\ge0,\sum w_k=1$；学生拟合 $\bar p$ 与硬标签组合损失。

## 四、代码实现

```python
logits = torch.stack([tk(x) for tk in teachers], 0).mean(0)
loss = kl(softmax(student(x)/T), softmax(logits/T))
```

## 五、与其他对比

- 与 模型汤（推理前权重平均）不同，这里是软标签层面的集成。
- 与 权重平均与模型融合深入 共享"集成提升"思想但发生在输出空间。

## 六、常见误区

- 教师间高度相关致集成增益消失（需多样教师）。
- 在线多教师推理成本过高（可异步/降频更新）。

## 八、面试题

- 多教师相对单教师优势？答：集成汇总多样视角，软标签更平滑鲁棒，减轻单教师偏见。

## 九、演进

单教师 → 静态多教师 → 动态门控多教师。

## 十、小结

多教师在线蒸馏以软标签集成提升学生鲁棒性，代价是教师侧的额外算力。
