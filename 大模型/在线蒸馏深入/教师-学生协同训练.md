# 教师-学生协同训练

> 对应 Bucila, Caruana & Niculescu-Mizil, *Model Compression*, 2006；Hinton et al., 2015 在线化。

## 一、背景与挑战

固定预训练教师做离线蒸馏时，教师能力上限固定；协同训练让教师随学生进步而进化，形成正向循环。

## 二、核心原理

教师网络以较慢学习率持续更新，学生每步从最新教师软标签学习，并通过 EMA 或滑动平均保持教师稳定。二者在同一数据流上协同优化。

## 三、数学形式

教师参数 $\theta_T \leftarrow \theta_T - \eta_T \nabla \mathcal L_T$，学生 $\theta_S \leftarrow \theta_S - \eta_S \nabla \mathcal L_{distill}(\theta_S,\theta_T)$；常令 $\theta_T = \text{EMA}(\theta_S)$ 以避免教师抖动。

## 四、代码实现

```python
for x, y in loader:
    t = teacher(x).detach()
    s = student(x)
    loss = kl_soft(s, t) + ce(s, y)
    loss.backward(); opt.step()
    ema.update(student)   # 教师 = 学生 EMA
```

## 五、与其他对比

- 比纯离线蒸馏更省"先训教师"的一次性成本。
- 与 权重平均与模型融合深入（EMA 同时用于平均）相关。

## 六、常见误区

- 教师学习率与学生的比例失调致教师漂移过快。
- 学生直接复制教师噪声（需温度与权重平衡）。

## 八、面试题

- 为何常用 EMA 作为在线教师？答：EMA 平滑学生权重，提供稳定且持续进化的教师，抑制抖动。

## 九、演进

固定教师 → 同步更新教师 → EMA/自蒸馏教师。

## 十、小结

教师-学生协同训练通过持续进化的教师，省去独立预训练并提升蒸馏质量。
