# 在线蒸馏总览

> 对应 Hinton, Vinyals & Dean, *Distilling the Knowledge in a Neural Network*, 2015；与 知识蒸馏 / 模型压缩 衔接。

## 一、背景与挑战

大模型训练需海量数据与算力；蒸馏用教师模型（大模型或集成）的软标签指导小模型，提升小模型泛化并降低对标注量的需求。

## 二、核心原理

在线蒸馏中教师与学生同步训练（教师可为正在进化的自身或同伴），学生同时拟合教师软标签与真实硬标签。软标签经温度 softmax 软化，携带类间相似性（暗知识），信息比 one-hot 更丰富。

## 三、数学形式

软化概率 $p_i=\frac{\exp(z_i/T)}{\sum_j\exp(z_j/T)}$；蒸馏损失为师生软分布 KL 散度：
$\mathcal L=\alpha T^2\,\mathrm{KL}(p_T^{\text{teacher}}\|p_T^{\text{student}})+(1-\alpha)\mathcal L_{CE}(y,p^{\text{student}})$。

## 四、代码实现

```python
soft = F.kl_div(F.log_softmax(s/T,1), F.softmax(t/T,1), reduction="batchmean") * T*T
loss = alpha*soft + (1-alpha)*F.cross_entropy(s, y)
```

## 五、与其他对比

- 与离线蒸馏（固定教师）比，在线教师随训练进化，更适配学生当前能力。
- 与 数据高效提示深入 共享"用更少数据获更好效果"的目标。

## 六、常见误区

- 温度 $T$ 设错：过大引入噪声、过小退化为硬标签。
- 忽视硬标签项致学生偏离真实分布。

## 八、面试题

- 为何软标签优于硬标签？答：软标签编码类间相似性（暗知识），提供比 one-hot 更丰富的梯度信号。

## 九、演进

离线蒸馏 → 在线互相蒸馏 → 自蒸馏 / 无教师蒸馏。

## 十、小结

在线蒸馏用同步演化的教师提供暗知识，是学生模型数据高效且泛化强的训练范式。
