# 互相蒸馏（Deep Mutual Learning）

> 对应 Zhang, Xiang, Tu & Zurada, *Deep Mutual Learning*, 2018；CVPR。

## 一、背景与挑战

多个小模型互相学习可超越各自独立训练，且无需一个强大的固定教师，适合资源受限场景。

## 二、核心原理

并行训练若干学生网络，每步彼此用对方软标签作为监督（双向 KL），相互正则化、弥补各自盲点，最终任一网络均可部署。

## 三、数学形式

对网络 $i,j$，互蒸馏损失 $\mathcal L_{mutual}=\frac12\mathrm{KL}(p_i\|p_j)+\frac12\mathrm{KL}(p_j\|p_i)$；总损失为各自 CE 损失加互蒸馏项。

## 四、代码实现

```python
for net_i, net_j in pairs:
    pi, pj = softmax(net_i(x)/T), softmax(net_j(x)/T)
    loss = ce_i + ce_j + kl(pi, pj.detach()) + kl(pj, pi.detach())
```

## 五、与其他对比

- 与单一教师-学生不同，无强教师假设，对等网络互相提升。
- 与 模型汤 不同：汤是推理前权重融合，互蒸馏是训练期知识交换。

## 六、常见误区

- 网络初始化过相似致收敛到同一极小值（应多样化初始化）。
- 网络数过多致通信与计算开销陡增。

## 八、面试题

- 互蒸馏为何有效？答：多个网络互为正则，彼此暴露盲点，整体泛化优于独立训练。

## 九、演进

单一教师 → 多教师 → 互蒸馏对等学习。

## 十、小结

互相蒸馏以对等网络互监督，免强教师且提升小模型群体泛化。
