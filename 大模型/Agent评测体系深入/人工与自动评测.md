# 人工与自动评测

> 见「Agent评测体系深入/Agent评测总览」与「模型评测深入」；互补。

## 一、背景与挑战

自动指标快但粗，人工准但慢。

## 二、核心原理

自动：规则/程序化检查、LLM-judge（大规模低成本）；人工：复杂任务质量、安全性主观判断。实务以自动为主、人工抽检校准 judge。需防止 LLM-judge 位置/长度偏置。

## 三、关键要点

- judge 需与人工对齐校准。
- 关键任务人工兜底。

## 四、代码实现

```python
auto = llm_judge(batch); sample = human_review(auto.sample(50))
```

## 五、与其他对比

- 自动快粗；人工慢准。

## 六、常见误区

- 全靠 judge——忽略偏置。
