# 端到端轨迹评测

> 见「Agent评测体系深入/Agent评测总览」；整条轨迹质量。

## 一、背景与挑战

即便最终对，过程可能低效/危险。

## 二、核心原理

对轨迹（observation-action 序列）做整体评估：用 LLM-judge 评「步骤合理性、是否冗余、是否违规」；或对照参考轨迹算步骤重叠。兼顾结果与过程。

## 三、关键要点

- 高效（少步）与正确同样重要。
- judge 需防偏置。

## 四、代码实现

```python
traj_score = llm_judge(f"评轨迹质量(1-5): {traj}")
```

## 五、与其他对比

- 成功率看终点；轨迹看路径。

## 六、常见误区

- 终点对即优——过程可能浪费。
