# 鲁棒性评测

> 见「Agent评测体系深入/Agent评测总览」；扰动下表现。

## 一、背景与挑战

同一任务不同表述/噪声，Agent 可能崩。

## 二、核心原理

用扰动测试：指令改写、无关干扰、工具临时失败、环境变化，测成功率下降幅度。鲁棒性 = 扰动后性能 / 基准性能。高鲁棒性才可靠。

## 三、关键要点

- 需系统性扰动集。
- 失败恢复能力关键。

## 四、代码实现

```python
drop = 1 - succ(perturbed) / succ(clean)
```

## 五、与其他对比

- 平均性能掩盖脆弱；鲁棒性暴露。

## 六、常见误区

- 基准高分即稳——扰动即崩。
