# 任务成功率评测

> 见「Agent评测体系深入/Agent评测总览」；最直观指标。

## 一、背景与挑战

「任务做成没」是用户最关心的。

## 二、核心原理

给定可验证任务（有程序化检查/断言），跑 N 次取成功率；区分**严格成功**（全对）与**部分成功**。需统计置信区间（随机性高）。环境需可重置保证公平。

## 三、关键要点

- 多次运行取均值（去随机）。
- 环境可重置是关键。

## 四、代码实现

```python
succ = mean(agent.run(t) == t.expect for _ in range(K))
```

## 五、与其他对比

- 单点准确率不适用多步。

## 六、常见误区

- 一次成败定论——需多次。
