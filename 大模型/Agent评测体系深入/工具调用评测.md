# 工具调用评测

> 见「Agent评测体系深入/Agent评测总览」与「Function_Calling进阶」；调用正确性。

## 一、背景与挑战

Agent 需正确选工具、填参数。

## 二、核心原理

评测：工具选择准确率（选对函数）、参数填充 F1/准确率、调用时序（依赖顺序）、错误处理（失败重试）。可对照工具 schema 验证参数合法性（类型/必填）。

## 三、关键要点

- 参数类型是常见错点。
- 需校验 schema 合法。

## 四、代码实现
