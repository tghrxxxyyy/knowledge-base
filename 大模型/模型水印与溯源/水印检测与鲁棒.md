# 水印检测与鲁棒

> 见「模型水印与溯源/文本水印原理」。

## 一、背景与挑战

用户可能改写、翻译、拼接以去除水印，检测需鲁棒。

## 二、核心原理

用 z-score 检验绿名单词占比是否异常；对改写采用「不变子串水印」或语义水印提升抗攻击性。

## 三、关键要点

- 短文本统计弱、难检测。
- 强改写可破简单水印。

## 四、代码实现

```python
import scipy.stats as st
z = (green_ratio - expect) / (std/sqrt(n))
```

## 五、与其他对比

- 统计水印轻量但脆；语义水印稳但复杂。
