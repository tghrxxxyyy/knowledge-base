# 输出去记忆化

> 见「训练数据质量」与「模型水印与溯源/训练数据版权」。

## 一、背景与挑战

模型可能逐字 regurgitate 训练数据（版权/隐私风险）。

## 二、核心原理

检测输出与训练语料的 n-gram 重叠，超过阈值则拒答/改写；或可训练降低记忆（差分隐私、正则）。

## 三、代码实现

```python
if ngram_overlap(output, corpus) > k: refuse(output)
```

## 四、关键要点

- 长尾/重复数据更易被记住。
- 去重训练可缓解。

## 五、与其他对比

- 水印标记生成；去记忆化防泄露训练内容。

## 六、常见误区

- 温度高就不泄露——仍可能记。

## 七、与开源书对应

- Carlini et al., *Extracting Training Data*, 2021.
- llm-course: https://github.com/mlabonne/llm-course

## 八、面试题

- 如何检测模型是否泄露训练数据？

## 九、演进

无防护 → 重叠检测 → 训练期去记忆。

## 十、小结

去记忆化保护训练数据隐私与版权。
