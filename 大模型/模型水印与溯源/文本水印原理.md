# 文本水印原理

> 对应 llm-course 安全章；Kirchenbauer et al., *A Watermark for LLM*, 2023。

## 一、背景与挑战

辨别「文本是否由 AI 生成」对防滥用、溯源重要。水印在生成时嵌入可检测信号。

## 二、核心原理

常用「绿名单」法：对每 token 根据上下文哈希选一个 token 子集（绿名单），解码时轻微偏置使模型多选绿名单词；检测时统计绿名单占比判是否含水印。

## 三、数学形式

绿名单概率提升：

```
p'(w) = p(w) · (1+δ·1[w∈G(c)]) / Z
```

## 四、代码实现

```python
def green_list(ctx): return set(hash(ctx) % V for _ in range(g))
```

## 五、关键要点

- 水印需统计显著但尽量不损质量。
- 密钥控制绿名单防伪造。

## 六、与其他对比

- 事后检测器（分类器）易误判；水印可证。

## 七、常见误区

- 水印不可去除——改写/翻译可削弱。
