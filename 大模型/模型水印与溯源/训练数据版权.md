# 训练数据版权

> 见「训练数据质量」与「大模型安全与对齐」。

## 一、背景与挑战

训练语料含受版权内容，引发合规与诉讼风险。

## 二、核心原理

通过数据源许可审查、opt-out 机制（如《纽约时报》诉案背景）、合成/授权数据替代、输出去记忆化降低风险。

## 三、关键要点

- 「合理使用」边界因地而异。
- 需记录数据出处与许可。

## 四、代码实现

```python
if not license_ok(src): skip(src)
```

## 五、与其他对比

- 预训练难逐一授权；微调可用授权数据。

## 六、常见误区

- 模型不输出原文就无侵权——风格/事实复用仍有争议。
