# AI 内容溯源

> 见「模型水印与溯源/文本水印原理」与「大模型安全与对齐」。

## 一、背景与挑战

除水印外，还需元数据（C2PA）与训练数据溯源以防深伪与侵权。

## 二、核心原理

内容凭证（C2PA）把生成来源写进文件元数据；训练数据溯源记录语料许可与出处，便于合规。

## 三、关键要点

- 水印在内容内；凭证在元数据。
- 二者互补。

## 四、代码实现

```python
meta = {"model":"llama3","created":ts,"license":"..."}
embed_c2pa(image, meta)
```

## 五、与其他对比

- 水印难删；元数据易被剥离。

## 六、常见误区

- 有元数据即可信——可伪造需签名。
