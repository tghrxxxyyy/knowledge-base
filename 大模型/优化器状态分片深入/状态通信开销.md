# 优化器状态通信开销

> 对应 分布式通信分析；与 数据并行深入 / 梯度累积深入 衔接。

## 一、背景与挑战

分片以额外通信换显存，通信模式决定实际吞吐。

## 二、核心原理

反向时 reduce-scatter 聚合梯度分片；前向/后向前 all-gather 重组参数分片，通信总量 $O(\Phi)$。

## 三、数学形式

每步通信量约 $2\Phi$（reduce-scatter + all-gather）；带宽 $B$ 下耗时 $2\Phi/B$。

## 五、与其他对比

- 与 梯度累积深入：累积减少 step 频率，但通信仍在每微批后向发生。
- 与 ZeRO-3深入 通信最重（参数也分片）。

## 六、常见误区

- 忽视 all-gather 频率，Stage3 通信峰值高。
- 在低速互联上用高 stage 得不偿失。
