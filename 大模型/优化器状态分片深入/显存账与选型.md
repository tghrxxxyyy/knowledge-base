# 显存账与选型

> 对应 训练显存建模；与 混合精度深入 / 优化器状态分片总览深入 衔接。

## 一、背景与挑战

选型需量化各技术对显存的贡献，避免盲目。

## 二、核心原理

显存 = 参数 + 梯度 + 优化器状态 + 激活；分片主要压前三项，激活靠累积/检查点。

## 三、数学形式

fp16 下：参数 $2\Phi$、梯度 $2\Phi$、Adam 状态 $12\Phi$；ZeRO-3 后约 $(2+2+12/N)\Phi$。

## 四、代码实现

```python
mem = (2 + 2 + 12/N) * params_bytes   # 粗估
```

## 五、与其他对比

- 与 混合精度深入 共用 $2\Phi$ 参数假设。
- 与 梯度累积深入 在激活项互相补充。

## 六、常见误区

- 只算参数忽略优化器状态，低估数倍。
- 不分 stage 直接套最大节省公式。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course
- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 为何 Adam 状态是显存大头？答：fp32 副本+m/v 共 12 字节每参数，远超 fp16 参数本身。

## 九、演进

经验估算 → 自动显存剖析 → 编排（分片+累积+检查点）。

## 十、小结

显存账揭示优化器状态为主项，分片技术是扩容训练的关键杠杆。
