# 稀疏训练方法与动态稀疏

> 对应 pytorch/pytorch 与 microsoft/DeepSpeed 的 sparse training 实践。

## 一、背景与挑战

剪枝后再训练成本高；稀疏训练 (sparse training) 在训练过程中就维持稀疏结构，直接学到适应稀疏的权重，节省总算力。

## 二、核心原理

动态稀疏 (dynamic sparse) 周期性地"剪最弱、长新连接"：每步保持固定稀疏度，但允许权重在掩码间迁移（如 RigL 方法），比静态剪枝更优。

## 三、形式化与数学基础

RigL 用梯度信息更新掩码：

$ M^{(t+1)}=\\text{top-}k(|W^{(t)}|\\cup \\nabla\\mathcal L)\\quad \\text{按梯度补强连接} $

保持 $ \\|M\\|_0=k $ 恒定。

## 四、代码实现

```python
import torch

def rigl_step(W, grad, M, k_ratio):
    score = (W.abs() * grad.abs())   # 重要性评分
    thr = torch.quantile(score.flatten(), 1 - k_ratio)
    new_M = (score > thr).float()
    return W * new_M, new_M
# 周期性调用, 维持稀疏度
```

## 五、与其他技术对比

- 静态剪枝简单但次优；动态稀疏更优但需梯度掩码管理。
- 与量化联合 (sparse-quantized) 是端到端压缩方向。

## 六、常见误区

- 动态稀疏实现复杂，掩码更新频率不当会失稳。
- 误以为稀疏训练一定能比稠密更好，实际受稀疏度限制。
