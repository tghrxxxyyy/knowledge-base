# 结构化与非结构化剪枝对比

> 对应 pytorch/pytorch 剪枝教程与 microsoft/DeepSpeed 的稀疏训练实践。

## 一、背景与挑战

模型冗余显著，剪枝可减参提速。但"剪哪些、怎么剪"决定能否被硬件真正加速：非结构化剪枝随意置零，结构化剪枝删整通道/头/层。

## 二、核心原理

非结构化 (unstructured) 按权重幅值逐元素置零，压缩率高但产生随机稀疏，需专用稀疏 kernel 才能加速。结构化 (structured) 去掉整个通道/滤波器，可直接用稠密算子加速，但灵活性低。

## 三、形式化与数学基础

非结构化掩码：

$ M_{ij}=\\mathbb I(|W_{ij}|>\\tau),\\quad W\\leftarrow W\\odot M $

结构化通道剪枝：

$ W_{:,k}\\leftarrow 0 \\ \\text{若}\\ \\|W_{:,k}\\|<\\tau_k $

## 四、代码实现

```python
import torch

def unstructured_prune(W, ratio=0.5):
    flat = W.abs().flatten()
    thr = torch.quantile(flat, ratio)
    mask = (W.abs() > thr).float()
    return W * mask, mask

def channel_prune(W, ratio=0.2):
    norm = W.norm(dim=0)              # 每输出通道范数
    thr = torch.quantile(norm, ratio)
    keep = (norm > thr).float()
    return W * keep[None, :], keep
```

## 五、与其他技术对比

- 非结构化压缩率高但需 2:4/N:M 等硬件友好模式才加速。
- 结构化易加速但可能掉点，需重训恢复。
- 与量化正交，可叠加。

## 六、常见误区

- 以为非结构化剪枝自动提速；实则需稀疏 kernel。
- 一次性剪太多导致无法恢复。
