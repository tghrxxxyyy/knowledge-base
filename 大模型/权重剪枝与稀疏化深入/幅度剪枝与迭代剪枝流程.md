# 幅度剪枝与迭代剪枝流程

> 对应 pytorch/pytorch 的 magnitude pruning 与经典 iterative pruning 流程。

## 一、背景与挑战

一次性剪掉大量权重易损精度。幅度剪枝 (magnitude pruning) 以权重绝对值小即不重要为启发，迭代式逐步剪除并微调更稳。

## 二、核心原理

训练后或训练中，按幅值排序置零最低比例权重，再用少量数据微调恢复精度，循环直至目标稀疏度。即"剪-训-再剪"的迭代范式。

## 三、形式化与数学基础

目标（带掩码）：

$ \\min_{W,M}\\mathcal L(W\\odot M)\\quad \\text{s.t.}\\ \\|M\\|_0\\le k $

迭代更新 $ M^{(t+1)}={\\text{top-}k}(|W^{(t)}|) $，$ W $ 微调。

## 四、代码实现

```python
import torch

def iterative_prune(model, loader, target=0.8, rounds=5):
    for r in range(rounds):
        ratios = torch.linspace(0.0, target, rounds)
        apply_magnitude_mask(model, ratios[r])
        finetune(model, loader, steps=200)   # 短微调恢复
    return model

def apply_magnitude_mask(model, ratio):
    for p in model.parameters():
        if p.dim() > 1:
            thr = torch.quantile(p.abs().flatten(), ratio)
            p.data *= (p.abs() > thr).float()
```

## 五、与其他技术对比

- 相比一次性剪枝，迭代更稳但更贵。
- 与量化叠加可进一步压缩。

## 六、常见误区

- 阈值用全局而非逐层，导致小层被剪光。
- 微调步数不足，精度未恢复即继续剪。
