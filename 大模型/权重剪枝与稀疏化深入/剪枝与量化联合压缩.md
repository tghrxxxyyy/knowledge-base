# 剪枝与量化联合压缩

> 对应 pytorch/pytorch 与 NVIDIA/TensorRT-LLM 的 prune+quantize 联合压缩。

## 一、背景与挑战

剪枝减稀疏、量化减位宽，二者正交。联合使用可叠加收益，但顺序与交互需要设计，否则误差累积。

## 二、核心原理

常见顺序：先剪枝去冗余，再量化压缩剩余权重；也可交替进行。关键是量化误差不应破坏稀疏结构，稀疏也不应放大量化敏感度。

## 三、形式化与数学基础

联合目标：

$ \\min_{W,M,b}\\mathcal L(Q_b(W\\odot M)) $

$ b $ 为位宽、$ M $ 为稀疏掩码，二者共同约束模型规模。

## 四、代码实现

```python
import torch

def prune_then_quant(W, prune_ratio=0.5, bits=4):
    Wp, _ = unstructured_prune(W, prune_ratio)
    finetune_mask(Wp)
    q, s, z = grouped_quant(Wp, bits=bits)   # 见 GPTQ/AWQ 文档
    return q, s, z
# 顺序很重要: 先恢复精度再量化
```

## 五、与其他技术对比

- 单纯量化不改结构；联合压缩率更高。
- SparseGPT 等把剪枝与 GPTQ 量化一起做，效果最佳。

## 六、常见误区

- 量化后再剪枝，破坏已校准的量化参数。
- 忽略稀疏结构对量化 group 的影响。
