# KV缓存与长上下文关系

> 对应长上下文推理；长上下文技术（目录）衔接。

## 一、背景与挑战

上下文越长 KV 越大，推理成本与显存非线性上升。

## 二、核心原理

KV 优化（分页/量化/驱逐）+ 位置编码外推（旋转位置编码深入）共同支撑长上下文。

## 三、数学形式

推理成本 $O(L)$ 显存 + $O(L^2)$ 注意力；KV 优化压第一项，高效注意力压第二项。

## 四、代码实现

```python
# 长上下文组合优化
cache = PagedKVCache(quant=8, max_len=L)
```

## 五、与其他对比

- 与 自回归生成深入（长度外推）互补。
- 与 注意力数学基础 衔接。

## 六、常见误区

- 只优化注意力忽略 KV 显存；二者皆瓶颈。
- 长上下文≠高质量（Lost in the middle）。

## 八、面试题

## 九、演进

短上下文 → 长上下文(KV优化+外推) → 流式无限长。

## 十、小结

KV 缓存优化是长上下文落地的前提，与位置外推并列关键。
