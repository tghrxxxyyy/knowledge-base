# KV缓存量化与压缩

> 对应 KV 量化（INT8/INT4）与稀疏。

## 一、背景与挑战

长序列下 KV 占显存大，量化/压缩可降数倍。

## 二、核心原理

对 K/V 做逐通道或逐 token 量化（常非对称）；或只保留重要 token 的 K/V（驱逐）。

## 三、数学形式

量化 KV 显存 $M' = M\cdot b'/b$（$b'$ 为低位宽）；驱逐保留 top-k 位置。

## 四、代码实现

```python
K_int = quantize(K, bits=8)        # 存 INT8
V_int = quantize(V, bits=8)
```

## 五、与其他对比

- 与 量化感知训练深入 / 模型量化部署实战 共享量化思路（但 KV 是激活）。
- 与 长上下文技术 衔接。

## 六、常见误区

- KV 量化对异常值敏感；需逐通道校准。
- 过度压缩致长程注意力崩。

## 七、与开源书对应

## 八、面试题

- KV 量化为何用非对称？答：激活分布常偏移非对称，非对称保范围更准。

## 九、演进

FP16 KV → INT8 → INT4/驱逐。

## 十、小结

KV 量化/压缩是长序列推理省显存的直接手段，需防质量损失。
