# 分页注意力（PagedAttention）

> 对应 Kwon et al., *vLLM / PagedAttention*, 2023。

## 一、背景与挑战

不同序列长度不一，连续显存分配致碎片与浪费；PagedAttention 借鉴虚拟内存分页。

## 二、核心原理

KV 存于固定大小“页（block）”，逻辑连续、物理可分散，按需分配，消除碎片、提升吞吐。

## 三、数学形式

显存利用率从连续分配的 ~20-40% 提升到 >90%；每请求只付实际长度页。

## 四、代码实现

```python
# 逻辑块号 -> 物理块（类似页表）
physical = page_table[seq_id][logical_block]
```

## 五、与其他对比

- 与 连续批处理深入 协同（vLLM 同时用二者）。
- 与 推理引擎vLLM深度解析（文件）衔接。

## 六、常见误区

- 以为分页只省显存；同时提升吞吐与并发。
- 跨页注意力需正确 gather。

## 八、面试题

- PagedAttention 好处？答：消除 KV 碎片、按需分配，显著提升显存利用率与并发。

## 九、演进

连续缓存 → 分页 → 分块预取。

## 十、小结

PagedAttention 把虚拟内存思想引入 KV 管理，是现代推理引擎标配。
