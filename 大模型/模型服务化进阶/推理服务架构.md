# 推理服务架构

> 对应 vLLM / TRT-LLM / TensorRT 部署实践(见「推理优化/vLLM部署」)。

## 一、核心概念

生产推理服务：负载均衡 → 推理引擎(continuous batching + PagedAttention) → KV Cache 管理 → 输出流式返回。关注吞吐(req/s)、首 token 延迟(TTFT)、每 token 延迟(TPOT)、成本($/1M tokens)。

## 二、关键要点

| 指标 | 含义 |
|------|------|
| TTFT | 首 token 延迟 |
| TPOT | 每 token 延迟 |
| 吞吐 | 并发请求/秒 |
