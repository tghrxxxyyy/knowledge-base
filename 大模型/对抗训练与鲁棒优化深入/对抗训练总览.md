# 对抗训练总览

> 对应 Madry et al., *Towards Deep Learning Models Resistant to Adversarial Attacks*, 2018；与 模型安全与对齐 衔接。

## 一、背景与挑战

模型对输入微小扰动极敏感，对抗样本可致误判；需训练提升鲁棒性。

## 二、核心原理

在每步构造最坏情况扰动（在 $\epsilon$-球内最大化损失），再以此对抗样本做最小化，形成 min-max。

## 三、数学形式

$\min_\theta \mathbb E_{x,y}\big[\max_{\|\delta\|_\infty\le\epsilon}\mathcal L(\theta,x+\delta,y)\big]$。

## 四、代码实现

```python
delta = attack(model, x, y, eps=8/255)
loss = model(x+delta, y)
```

## 五、与其他对比

- 与 标签平滑深入 同属正则但目标不同（鲁棒 vs 校准）。
- 与 数据增强深入 互补（对抗即最强增强）。

## 六、常见误区

- 只在测试时加扰动而训练不加，毫无鲁棒。
- 忽略扰动预算 $\epsilon$ 与实际攻击匹配。

## 九、演进

FGSM 训练 → PGD 训练 → 自适应攻击训练。

## 十、小结

对抗训练以 min-max 构造鲁棒模型，是安全部署的重要防线。
