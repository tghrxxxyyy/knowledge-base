# 对抗训练成本与技巧

> 对应 工程实践；与 梯度累积深入 / 优化器状态分片深入 衔接。

## 一、背景与挑战

每步需额外前向/反向算对抗样本，成本数倍于普通训练，需技巧降负。

## 二、核心原理

用免费对抗（用同一次前向梯度）、少步 PGD、早停攻击、混合精度与分片省显存。

## 三、数学形式

成本约 $C_{adv}\approx (1+K_{pgd})\times C_{std}$；少步与免费对抗压低 $K_{eff}$。

## 四、代码实现

```python
with autocast():
    loss = adv_loss(model, x, y, K=4)
```

## 五、与其他对比

- 与 优化器状态分片深入 同为显存/算力优化手段。
- 与 学习率预热深入 配合稳定对抗训练。

## 六、常见误区

- 攻击步数过低得到假鲁棒。
- 忽略对抗训练更慢、需更长 schedule。

## 八、面试题

- 如何降对抗训练成本？答：免费对抗/少步 PGD、混合精度、与分片并行结合。

## 九、演进

全 PGD → 少步/免费 → 高效攻击训练。

## 十、小结

对抗训练成本靠攻击步数压缩与显存优化控制，方能量产鲁棒模型。
