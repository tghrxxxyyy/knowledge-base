# 梯度裁剪大模型实践

> 对应 LLM 预训练经验；与 混合精度训练深入 / 训练不稳定诊断深入 衔接。

## 一、背景与挑战

大模型（大 LR、大 batch）更易爆炸，裁剪阈值需随规模调。

## 二、核心原理

预训练常设全局范数裁剪（如 1.0）；配合 warmup 在初期更稳。

## 三、数学形式

多卡下梯度已聚合，裁剪阈值按全局范数设；fp32 裁剪再回 fp16。

## 四、代码实现

```python
loss.backward()
torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
opt.step()
```

## 五、与其他对比

- 与 学习率调度深入 / 权重衰减 共组稳定套件。
- 与 梯度累积重计算深入 配合（累积多步后裁剪）。

## 六、常见误区

- 在 fp16 直接裁剪致溢出；应先 fp32。
- 多卡未同步梯度范数致阈值语义漂移。

## 八、面试题

- 大模型为何仍要梯度裁剪？答：大 LR/大 batch 下爆炸风险高，裁剪保稳定。

## 九、演进

固定阈值 → 自适应 → 分层裁剪。

## 十、小结

梯度裁剪是大模型训练的稳定护栏，需配合精度与多卡同步正确实现。
