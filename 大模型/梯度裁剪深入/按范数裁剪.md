# 按范数裁剪

> 对应 clip_grad_norm_。

## 一、背景与挑战

需保持梯度方向同时限制幅度；按范数是主流。

## 二、核心原理

聚合所有参数梯度算全局 $L_2$ 范数，超阈值则整体缩放。

## 三、数学形式

$g_{total} \leftarrow g_{total}\cdot\min(1, \tau/\|g_{total}\|_2)$。

## 四、代码实现

```python
total = torch.nn.utils.clip_grad_norm_(params, max_norm=1.0)
```

## 五、与其他对比

- 保持方向（仅缩放），优于按值（可能扭曲方向）。
- 与 混合精度训练深入 交叉（梯度在 fp32 裁剪更稳）。

## 六、常见误区

- 在 fp16 下裁剪致精度问题；应先上转 fp32。
- 忽略多卡梯度已求平均/求和的范数差异。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 为何用全局范数？答：整体限制更新幅度，保梯度方向不变。

## 九、演进

单参数 → 全局范数 → 分层裁剪。

## 十、小结

按范数裁剪在不改方向下限制步长，是大模型训练稳定关键。
