# 按值裁剪

> 对应 clip_grad_value_。

## 一、背景与挑战

逐元素限制防极端大梯度，但可能扭曲方向。

## 二、核心原理

每个梯度分量截断到 $[-\tau,\tau]$。

## 三、数学形式

$g_i \leftarrow \max(-\tau,\min(\tau,g_i))$。

## 四、代码实现

```python
torch.nn.utils.clip_grad_value_(params, clip_value=0.5)
```

## 五、与其他对比

- 简单但破坏方向；按范数更保方向，故少用。
- 与 数值稳定性深入 衔接。

## 六、常见误区

- 逐元素截断改变梯度方向，可能引入偏置。
- 阈值需按层/参数尺度调整。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 按值裁剪缺点？答：逐元素截断会扭曲梯度方向，引入偏差。

## 九、演进

逐元素 → 逐渐被按范数取代（特定场景仍用）。

## 十、小结

按值裁剪简单但易偏，现代多被按范数取代。
