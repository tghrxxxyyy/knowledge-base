# 自我批评与修正（Self-Critique & Revision）

> 对应 Bai et al., 2022 中 Revision 阶段；与 可验证奖励深入 衔接。

## 一、背景与挑战

模型初答可能含害，需先识别再改写，而非仅靠外部奖励惩罚。

## 二、核心原理

给定回答与宪法条款，模型产出批评（指出违例处），再依据批评生成修订版；修订对构成偏好数据，体现“无害优于有害”。

## 三、数学形式

修订分布 $y_{rev}\sim P_\theta(y|y_{bad},c)$；$c$ 为命中的宪法条款；偏好序 $y_{rev}\succ y_{bad}$。

## 四、代码实现

```python
clause = match_constitution(ans)
crit = llm(f"条款{clause}: 指出问题并改写")
```

## 五、与其他对比

- 与 验证器深入（结果验证）互补：自我批评是生成侧，验证器是判分侧。
- 与 伦理对齐深入 共享条款化伦理。

## 六、常见误区

- 自我批评可能流于形式（模型同意但不改）。
- 批评本身受宪法覆盖度限制。

## 八、面试题

- 自我批评为何有效？答：把隐式无害要求显式化，模型借批判定位问题并改写。

## 九、演进

单轮批评 → 迭代批评 → 批评+检索事实。

## 十、小结

自我批评把“何为无害”转成可操作改写，是宪法AI的数据引擎。
