# 反向去噪过程

> 对应 Ho et al., DDPM, 2020；Song et al., score-based, 2020。

## 一、背景与挑战

已知 $x_t$，需恢复 $x_{t-1}$ 直至 $x_0$；直接建模后验不可解，用神经网络近似。

## 二、核心原理

学习 $\epsilon_\theta(x_t,t)$ 预测所加噪声，反向均值：
$\mu_\theta(x_t,t)=\frac{1}{\sqrt{\alpha_t}}\left(x_t-\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\epsilon_\theta(x_t,t)\right)$，方差常取 $\Sigma_\theta$。

## 三、数学形式

训练目标简化为噪声回归（variance-weighted）：
$\mathcal L_{simple}=\mathbb E_{t,x_0,\epsilon}\left[\|\epsilon-\epsilon_\theta(\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon,t)\|^2\right]$。

## 四、代码实现

```python
noise_pred = model(x_t, t)
loss = (noise_pred - noise).pow(2).mean()
```

## 五、与其他对比

- 等价于学习数据得分 $\nabla_{x_t}\log p_t(x_t)$（score matching）。
- 与自回归相比，扩散一次预测全场噪声，生成并行度高。

## 六、常见误区

- 用错噪声尺度/时间编码导致训练不稳。
- 忽视 $t$ 的条件输入（时间步 embedding 关键）。

## 八、面试题

- 扩散训练目标为何等价于得分匹配？答：去噪网络预测噪声即估计得分方向。

## 九、演进

DDPM → DDIM（确定性加速）→ 潜在扩散（Latent Diffusion）→ 扩散大模型。

## 十、小结

反向去噪用神经网络预测噪声，把复杂生成转化为回归问题，是扩散核心。
