# 采样与加速

> 对应 Song et al., DDIM, 2020；Salimans & Ho, *progressive distillation*, 2022。

## 一、背景与挑战

DDPM 需数百步采样太慢；需在保质量下大幅减少步数。

## 二、核心原理

DDIM：非马尔可夫确定性采样，允许大步跳；
蒸馏：把多步学生模型蒸馏为少步；一致性模型（Consistency Models）直接一步生成。

## 三、数学形式

DDIM 更新含 $\sigma_t$ 项，取 $\sigma_t=0$ 得确定性轨迹，可 $S\ll T$ 步采样。

## 四、代码实现

```python
# DDIM 一步（简化）
pred_x0 = (x_t - sqrt_1m * eps) / sqrt_alpha_bar
x_next = sqrt_alpha_bar_prev * pred_x0 + sqrt_1m_prev * eps
```

## 五、与其他对比

- 少步采样牺牲部分多样性换速度；流式生成仍不及自回归增量。
- 潜在扩散先在压缩潜空间去噪，降低分辨率开销。

## 六、常见误区

- 盲目减步数致结构崩坏；需配合蒸馏或调度。
- 忽视 classifier-free guidance 步数敏感性。

## 八、面试题

- 如何加速扩散采样？答：DDIM 跳步、蒸馏、一致性模型、潜在空间。

## 九、演进

DDPM(1000步) → DDIM → 蒸馏/一致性 → 一步生成。

## 十、小结

采样加速是扩散落地关键，现代方案可把千步压到数步仍保质量。
