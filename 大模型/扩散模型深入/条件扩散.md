# 条件扩散

> 对应 Ho & Salimans, *Classifier-Free Guidance*, 2022；Rombach et al., *Latent Diffusion*, 2022。

## 一、背景与挑战

需按文本/类别/布局控制生成；如何把条件注入噪声预测。

## 二、核心原理

Classifier-Free Guidance（CFG）：同时训条件/无条件模型，推理时
$\tilde\epsilon_\theta = \epsilon_\theta(x_t,\varnothing) + w(\epsilon_\theta(x_t,c)-\epsilon_\theta(x_t,\varnothing))$，$w$ 控保真-多样权衡。

## 三、数学形式

梯度式解释：$\tilde\epsilon$ 沿条件似然梯度方向偏移，增强对齐。

## 四、代码实现

```python
e_uncond = model(x_t, None, t); e_cond = model(x_t, c, t)
e = e_uncond + w * (e_cond - e_uncond)
```

## 五、与其他对比

- 早期 classifier guidance 需额外分类器梯度；CFG 更简洁。
- 与 RAG/控制生成思路相通（检索增强生成前沿 对照）。

## 六、常见误区

- $w$ 过大致饱和、细节失真；需调参。
- 条件 dropout 概率设置不当致 CFG 退化为纯条件。

## 八、面试题

- CFG 为什么有效？答：在条件与无条件预测间插值，强化条件信号。

## 九、演进

classifier guidance → CFG → 交叉注意力条件 → 多条件/布局控制。

## 十、小结

条件扩散通过 CFG 等技术把文本/类别信号注入去噪，是文生图/文生视频核心。
