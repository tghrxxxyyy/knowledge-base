# 训练目标推导

> 对应 Ho et al., 2020；Kingma et al., *Variational Diffusion Models*, 2021（ELBO 视角）。

## 一、背景与挑战

扩散可视为层次 VAE，需从 ELBO 推导出可优化、低方差的简化目标。

## 二、核心原理

证据下界分解出各步 KL：$KL(q(x_{t-1}|x_t,x_0)\|p_\theta(x_{t-1}|x_t))$ 可用闭式高斯 KL，最终只剩噪声回归项。

## 三、数学形式

完整 ELBO $\approx \sum_t \mathbb E\left[\frac{\beta_t^2}{2\sigma_t^2\alpha_t(1-\bar\alpha_t)}\|\epsilon-\epsilon_\theta\|^2\right]$；忽略权重即得 $\mathcal L_{simple}$。

## 四、代码实现

```python
loss = (noise - model(sqrt_alpha_bar*x0 + sqrt_1m*x, t))**2
loss = loss.mean() * w[t]   # 可选加权
```

## 五、与其他对比

- 加权版更理论严谨；简化版实践更稳。
- 与 VAE ELBO 同源于变分推断（变分推断 衔接）。

## 六、常见误区

- 误以为 $\mathcal L_{simple}$ 就是完整 ELBO；它是加权近似。
- 忽略边界项（先验与重建）致轻微偏差。
