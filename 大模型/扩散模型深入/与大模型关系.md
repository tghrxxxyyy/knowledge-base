# 扩散与大模型关系

> 对应多模态生成前沿；llm-course 多模态部分。

## 一、背景与挑战

文本大模型自回归生成离散 token；图像/视频大模型多用扩散生成连续信号，二者如何协同。

## 二、核心原理

- 多模态：LLM 生成文本条件/语义布局，扩散负责像素/帧合成（如 Stable Diffusion + LM）。
- 统一：部分工作把离散 token 与连续扩散统一为“多模态扩散/自回归混合”。

## 三、数学形式

联合建模 $p(\text{text}, \text{image}) = p_\theta(\text{image}|\text{text})p(\text{text})$，前者常扩散、后者常自回归。

## 四、代码实现

```python
# 文本编码作扩散条件
cond = text_encoder(prompt)
image = diffusion_sample(cond)
```

## 五、与其他对比

- 离散生成（token）易对齐语言；连续生成（扩散）保视觉保真。
- 视频理解深入 是判别侧对照，扩散是生成侧。

## 六、常见误区

- 以为扩散能直接“读懂”文本；需文本编码器桥接。
- 混淆生成扩散与判别去噪自编码器。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course
- 多模态深入 / 视频理解深入 衔接。

## 八、面试题

- 文生图为何多用扩散而非自回归？答：连续信号保真高、可并行去噪。

## 九、演进

文本条件扩散 → 多模态统一 → 视频扩散 → 与世界模型结合。

## 十、小结

扩散是大模型多模态生成主力，与自回归文本模型互补构成统一多模态系统。
