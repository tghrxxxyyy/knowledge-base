# 前向扩散过程

> 对应 Sohl-Dickstein et al., 2015；Ho et al., *DDPM*, 2020。

## 一、背景与挑战

希望从噪声生成数据，但直接建模复杂分布难；扩散用逐步加噪把数据变纯噪声，再学逆过程。

## 二、核心原理

前向（固定马尔可夫）：$q(x_t|x_{t-1})=\mathcal N(x_t;\sqrt{1-\beta_t}x_{t-1},\beta_t I)$，累积可得闭式：
$x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon,\ \epsilon\sim\mathcal N(0,I)$。

## 三、数学形式

$\alpha_t=1-\beta_t,\ \bar\alpha_t=\prod_{s=1}^t\alpha_s$。任意 $t$ 可由 $x_0$ 直接采样 $x_t$。

## 四、代码实现

```python
x_t = sqrt_alpha_bar[t] * x0 + sqrt_one_minus[t] * torch.randn_like(x0)
```

## 五、与其他对比

- 前向类似逐步 Langevin 加噪；与 VAE 的随机编码不同，扩散无训练编码器。
- 自回归生成（自回归生成深入）逐 token，扩散在连续空间并行去噪。

## 六、常见误区

- 认为必须逐步加噪；闭式跳步采样即利用累积系数。
- 忽视方差调度 $\beta_t$ 对质量的影响。

## 七、与开源书对应

- llm-course（生成模型部分）：https://github.com/mlabonne/llm-course
- 扩散与自回归对照见 自回归生成深入。

## 八、面试题

- 为什么能直接采样任意 $x_t$？答：高斯线性组合仍高斯，有闭式均值方差。

## 九、演进

吸收态扩散 → DDPM → 改进方差（improved DDPM）→ 扩散大模型。

## 十、小结

前向扩散把数据映射为噪声并提供任意步闭式样本，是反向生成训练的基础。
