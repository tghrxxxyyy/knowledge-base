# 量化尺度与零点校准

> 对应对称/非对称量化校准。

## 一、背景与挑战

尺度（scale）与零点（zero-point）决定量化范围与精度。

## 二、核心原理

对称：$s = \max|x|/(2^{b-1}-1), z=0$；非对称：$s=(\max-\min)/(2^b-1), z=-\lfloor\min/s\rfloor$。

## 三、数学形式

量化 $q=\text{round}(x/s)+z$，反量化 $x'\approx(q-z)s$；校准用训练集统计 min/max（或滑动平均/_percentile）。

## 四、代码实现

```python
s = max(abs(x)).item()/(2**(b-1)-1)
q = torch.round(x/s).clamp(-2**(b-1),2**(b-1)-1)
```

## 五、与其他对比

- 权重常对称、激活常非对称（有偏移）。
- 与 模型量化部署实战 共享校准逻辑。

## 六、常见误区

- 用全数据集 max 致 outlier 主导范围；常用百分位。
- 权重与激活校准方式混淆。

## 八、面试题

- 对称 vs 非对称量化？答：对称以0为中心(z=0)简单，非对称用零点覆盖偏移分布更准。

## 九、演进

min-max → 滑动平均 → 百分位/熵校准。

## 十、小结

尺度与零点校准决定低位量化保真度，是 QAT/PTQ 的共同基础。
