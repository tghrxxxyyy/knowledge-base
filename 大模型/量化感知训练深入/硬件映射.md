# QAT硬件映射

> 对应 Tensor Core / INT8 推理；与 硬件感知训练深入 / 推理引擎深入 衔接。

## 一、背景与挑战

训练出的量化模型需映射到 INT8/INT4 硬件指令才得真实加速。

## 二、核心原理

QAT 输出定点（INT）权重/激活，推理引擎（TensorRT/TVM）用点积指令执行；需保证伪量化与硬件一致。

## 三、数学形式

硬件乘加：$y=\sum q_w q_x$（INT 点积）+ 反量化尺度 $s_w s_x$。

## 四、代码实现

```python
# 导出 INT 权重
w_int = quantize_to_int(W, s_w, z_w)
engine.build(w_int, s_w, s_x)
```

- 与 编译优化与模型格式（目录）衔接（格式如 TensorRT/ONNX）。
- 与 边缘端侧推理深入 衔接。

## 六、常见误区

- 伪量化与硬件舍入规则不一致致精度掉。
- 忽略激活对称/非对称与硬件支持匹配。
