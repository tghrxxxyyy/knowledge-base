# 伪量化节点

> 对应 fake quant 实现与 STE。

## 一、背景与挑战

需在前向引入量化误差、反向仍能回传梯度。

## 二、核心原理

伪量化在前向做量化-反量化（舍入噪声），反向用 STE 把梯度原样传过舍入（舍入梯度≈0，用恒等替代）。

## 三、数学形式

前向 $y=Q(x)$；反向 $\frac{\partial L}{\partial x}\approx \frac{\partial L}{\partial y}$（STE 忽略舍入导数）。

## 四、代码实现

```python
class FakeQuant(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x, s, z, b):
        return (torch.round(x/s+z).clamp(0,2**b-1)-z)*s
    @staticmethod
    def backward(ctx, g): return g, None,None,None
```

## 五、与其他对比

- 与 混合精度训练深入 不同：QAT 目标是低位推理，混合精度为训练稳。
- 与 数值稳定性深入 衔接（舍入误差）。

## 六、常见误区

- STE 在大梯度时误差累积；可用改进 STE。
- 校准尺度 s/z 不当放大噪声。

## 八、面试题

- 为什么用 STE？答：舍入不可导，STE 用恒等近似让梯度流通。

## 九、演进

硬 STE → 软/可微 STE → 学习型量化参数。

## 十、小结

伪量化+STE 是 QAT 的数学核心，让量化噪声可训练适应。
