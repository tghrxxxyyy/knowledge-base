# 量化感知训练总览

> 对应 Jacob et al., *Quantization-Aware Training*, 2018；与 模型量化部署实战 衔接。

## 一、背景与挑战

训练后量化（PTQ）省事但低比特掉点；量化感知训练（QAT）在训练中模拟量化误差，保精度。

## 二、核心原理

前向插入伪量化（fake quant）：权重/激活先量化再反量化回浮点，使网络“看到”量化噪声并适应。

## 三、数学形式

伪量化：$Q(x)=\text{round}(x/s+z)\cdot s - z\cdot s$，其中 $s$ 为尺度、$z$ 为零点；反向用直通估计（STE）传梯度。

## 四、代码实现

```python
q = round(clip(x/s+z, 0, 2^b-1))   # 伪量化
xq = (q - z) * s
dx = grad if |x-something| else 0   # STE
```

## 五、与其他对比

- QAT 精度高于 PTQ（尤其 4-bit 以下），但需训练资源。
- 与 QLoRA（量化底座+LoRA）互补：QAT 量化全模型。

## 六、常见误区

- 以为 QAT 总能无损；极端低位仍掉点。
- 伪量化与真实推理量化实现不一致致偏差。

## 七、与开源书对应

- llm-course 量化：https://github.com/mlabonne/llm-course

## 八、面试题

- QAT 与 PTQ 区别？答：QAT 训练中就模拟量化误差让模型适应，PTQ 训后直接量化。

## 九、演进

PTQ → QAT → 混合精度 QAT（不同层不同位宽）。

## 十、小结

QAT 以训练期模拟量化获得低比特高精度，是极致压缩的关键。
