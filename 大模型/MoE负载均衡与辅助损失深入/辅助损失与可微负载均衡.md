# 辅助损失与可微负载均衡

> 对应 Shazeer 2017 论文；Fedus 2021。

## 一、背景与挑战
辅助损失（auxiliary loss）需在不影响主任务的同时引导负载均衡。设计目标是让路由可微、引导均衡、不过分压制路由。

## 二、核心原理
两种主流损失：
1. Importance loss: $L_\text{imp} = \alpha \cdot N \sum_i (\frac{1}{B}\sum_x g_i(x))^2$，惩罚 $g_i$ 在 batch 上的均值的方差。
2. Load loss: $L_\text{load} = \alpha \cdot N \sum_i (\frac{1}{B}\sum_x \mathbb{1}[i \in \text{top-k}(x)])^2$，惩罚实际负载的方差。

## 三、形式化与数学基础
Importance 是连续可微，Load 是离散梯度需直通估计（STE）。Switch Transformer 实际用 importance + load 加权和。

## 四、代码实现
```python
def aux_loss(scores, topk_idx, n_experts, alpha=0.01):
    importance = scores.sum(0)
    load = torch.bincount(topk_idx.flatten(), minlength=n_experts).float()
    imp_loss = alpha * n_experts * (importance / importance.sum()).pow(2).sum()
    load_loss = alpha * n_experts * (load / load.sum()).pow(2).sum()
    return imp_loss + load_loss
```

## 五、与其他技术对比
- vs Expert Choice 路由（专家选 token）：天然均衡。
- vs 容量因子：硬性截断不均衡，损失更柔和。

## 六、常见误区
- $\alpha$ 过大压制主任务，过小不起作用。常用 $0.01$。
- 监控 $L_\text{aux}$ 与 $L_\text{task}$ 比值。

## 七、与开源书/权威来源对应
- google/switch-transformer。
- huggingface/transformers Mixtral 实现。

## 八、面试题
- importance 和 load 损失区别？答：importance 用路由分数，load 用实际分配。

## 九、演进与趋势
aux loss → Expert Choice → DeepSeek 风格无 aux loss（动态偏置）。

## 十、小结
辅助损失是 MoE 负载均衡的标准做法，需仔细调节系数。
