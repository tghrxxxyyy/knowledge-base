# 对齐与能力的权衡框架

> 对应 Ouyang et al. 2022 InstructGPT 与 Rafailov et al. 2023 DPO。

## 一、背景与挑战

对齐训练的目标（让模型符合人类偏好、安全有用）与保留预训练获得的能力（知识、推理、指令遵循）常此消彼长。研究与实践都需要在「有用性（能力）」与「安全性（对齐）」之间找到帕累托前沿（Pareto frontier）——即在不显著牺牲一方的前提下优化另一方。难点在于：两目标没有统一量纲，难以直接相加；且最优权衡点随应用场景变化（客服要安全优先、科研助手要有用优先）。需要一个可操作的形式化框架，把权衡显式建模为约束优化或加权和，并能量化扫描前沿。

## 二、核心原理

框架把两目标写成可计算形式：
1. **加权和（scalarization）**：把有用性 $U$ 与安全 $S$ 线性组合 $\alpha U+(1-\alpha)S$，扫 $\alpha\in[0,1]$ 得到不同侧重；实现简单但只能覆盖凸前沿。
2. **约束优化**：固定安全下限 $s^*$，最大化有用性：$\max_\theta U(\pi_\theta)\ \text{s.t.}\ S(\pi_\theta)\ge s^*$；能精确刻画非凸前沿上的受约束最优点。
3. **偏好优化即隐式权衡**：DPO 以参考模型 KL 作为能力保持项，以偏好损失作为对齐项，二者在训练中自动平衡；KL 系数相当于隐式 $\alpha$。
4. **多目标评估**：在验证集上分别测 $U,S$，绘制 $(U,S)$ 散点，连成帕累托前沿指导选型。

框架价值在于把「拍脑袋调权重」变成「系统扫描 + 可视化决策」。

## 三、形式化与数学基础

约束形式：

$$ \max_\theta\ \text{Usefulness}(\pi_\theta)\quad \text{s.t.}\quad \text{Safety}(\pi_\theta)\ge s^* $$

加权和形式：

$$ \max_\theta\ \alpha\,\text{Usefulness}(\pi_\theta) + (1-\alpha)\,\text{Safety}(\pi_\theta) $$

DPO 目标隐式含 KL 约束（参考模型 $\pi_{\text{ref}}$ 保能力）：

$$ \mathcal{L}_{\text{DPO}} = -\mathbb{E}\Big[\log\sigma\big(\beta\log\tfrac{\pi_\theta(y_w)}{\pi_{\text{ref}}(y_w)} - \beta\log\tfrac{\pi_\theta(y_l)}{\pi_{\text{ref}}(y_l)}\big)\Big] $$

其中 $\beta$ 越大越靠近参考（能力保持强）。帕累托前沿定义为：不存在另一策略在 $U,S$ 上同时更大。

## 四、代码实现

```python
def tradeoff(useful, safe, alpha=0.5):
    """加权和：alpha 大=偏有用"""
    return alpha * useful + (1 - alpha) * safe

def pareto_front(points):
    """points: [(useful, safe, model), ...] 求帕累托前沿"""
    front = []
    for p in sorted(points, key=lambda x: -x[0]):
        if not front or p[1] > min(q[1] for q in front):
            front.append(p)
    return front

# 扫描 alpha
curve = [(a, tradeoff(u, s, a)) for a in [0, 0.25, 0.5, 0.75, 1.0]]
```

## 五、与其他技术对比

| 方案 | 表达力 | 是否显式权衡 | 适用 |
|------|--------|--------------|------|
| 加权和 | 仅凸前沿 | 部分 | 快速 |
| 约束优化 | 完整前沿 | 是 | 需定安全下限 |
| DPO(KL) | 隐式 | 否（靠β） | 端到端 |
| 多目标进化 | 完整 | 是 | 研究 |

DPO 隐式平衡 KL 与偏好；显式多目标更可控但需更多评估。

## 六、常见误区

- **只优化单一指标**：忽略另一维崩塌（安全达标但变「废物」）。
- **权重静态不调**：不同任务最优 $\alpha$ 不同，应依场景扫描。
- **把加权和当万能**：非凸前沿上会漏掉真实最优点，需用约束式。
- **$U,S$ 量纲混用**：未归一化直接加权，比例失真。

## 九、演进与趋势

- **自适应权重**：训练中随机采样 $\alpha$ 让模型覆盖整条前沿。
- **安全阈值动态调整**：依请求风险实时收紧/放松。
- **联合评测基准**：同时打能力分与安全分的标准化集。
- **多目标偏好学习**：直接在偏好对上做 Pareto 优化。

## 十、小结

对齐与能力权衡需显式建模为约束优化或加权和，并以参考 KL（DPO）或 $\beta$ 隐式平衡。通过扫描 $\alpha$/安全约束、绘制帕累托前沿，可把「调权重」变成可量化决策；避免单目标优化导致另一维崩塌。
