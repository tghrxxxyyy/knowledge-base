# 对齐税与能力退化

> 对应 Ouyang et al. 2022 InstructGPT 与 Askell et al. 2021 指令遵循作为实验室。

## 一、背景与挑战

「对齐税（alignment tax）」指：为提升模型的对齐性（遵循指令、安全、取悦人类）而进行的 SFT/RLHF/DPO 训练，常使模型在预训练阶段获得的通用能力（知识问答、数学推理、代码、长文理解）上出现退化。换言之，模型「更听话了，但变笨了」。这一现象在 InstructGPT 与后续工作中被广泛讨论。其危害是隐性的——对齐后的模型在指令任务上更好，却在标准学术基准上掉点，容易被忽视。挑战在于：能力退化与对齐强度并非线性关系，且退化可能集中在特定能力（如复杂推理）而非均匀；更难的是把退化正确归因——它既可能来自对齐，也可能来自数据质量或超参。

## 二、核心原理

对齐税的来源是「分布偏移」：偏好优化（RLHF/DPO）优化的奖励函数 $r(x,y)$ 只在人类偏好数据覆盖的分布上可靠，优化会推动策略偏离预训练分布 $\pi_{\text{pre}}$；那些不被偏好数据强化、却由预训练习得的能力，因不再被最大化而退化。机制可分解：
1. **奖励黑客 / 分布外漂移**：模型学会「说得好听」而非「做得对」，牺牲真实正确性。
2. **能力被对齐目标掩盖**：安全约束使模型在不确定时保守拒答，表现为「不会做」。
3. **容量竞争**：小模型参数量有限，对齐与能力争夺同一表示空间。
SFT 一般损伤较小（仍在做语言建模），RLHF/DPO 因强分布偏移更易触发对齐税。

退化的「体裁」也有规律：事实性知识（如实体、日期）相对鲁棒，而需要多步推敲的推理（数学、代码）最易被对齐目标压制；此外长上下文与工具调用等新增能力若不在偏好数据中强化，也会在对齐后回落。因此监测对齐税应按能力维度分别设阈值，而非只看总基准——总分持平常掩盖数学或代码项的显著下滑。容量越小，对齐税越明显，因对齐与能力争夺同一有限表示空间。

## 三、形式化与数学基础

以能力基准得分 $B(\pi)\in\mathbb{R}^T$（$T$ 个任务）衡量。对齐前后：

$$ \Delta_B = B(\pi_{\text{align}}) - B(\pi_{\text{SFT}}) $$

当 $\Delta_B < 0$ 即出现退化（对齐税）。RLHF 目标带 KL 时，策略偏移受 $\beta$ 控制：

$$ \pi_{\text{align}} = \arg\max_\pi \mathbb{E}[r] - \beta\, \mathrm{KL}(\pi\|\pi_{\text{ref}}) $$

$\beta\to 0$ 时偏移大、税重；$\beta$ 大则贴近参考、税轻但对齐弱。理论上能力退化上界随 KL 增大而增大。

## 四、代码实现

```python
from lm_eval import evaluator

def capability_drop(base_model, aligned_model, tasks):
    """对比对齐前后在固定基准上的得分差"""
    r1 = evaluator.simple_evaluate(model=base_model, tasks=tasks)
    r2 = evaluator.simple_evaluate(model=aligned_model, tasks=tasks)
    drop = {t: r1["results"][t]["acc"] - r2["results"][t]["acc"]
            for t in tasks}
    return drop

# 示例基准集：知识/推理/代码/数学
tasks = ["mmlu", "hellaswag", "gsm8k", "humaneval"]
print(capability_drop("base-7b", "rlhf-7b", tasks))
```

## 五、与其他阶段对比

| 阶段 | 主要目标 | 能力影响 | 对齐税风险 |
|------|----------|----------|------------|
| 预训练 | 似然最大化 | 建立能力 | 无 |
| SFT | 指令遵循 | 轻微 | 低 |
| RLHF/DPO | 偏好对齐 | 可能退化 | 高 |
| 回放+KL | 对齐+保持 | 缓解 | 低 |

SFT 一般不显著损能力；RLHF/DPO 因分布偏移更易出现对齐税。

## 六、常见误区

- **把退化全归因对齐**：可能是数据质量差或学习率不对，需消融确认。
- **只看总分**：总分持平可能掩盖单项（如数学）崩塌。
- **认为对齐税不可避免**：通过 KL 约束、回放、LoRA 可大幅缓解。
- **忽视评估覆盖**：基准未覆盖的能力退化肉眼不可见。
- **混淆训练顺序效应**：SFT 与 RLHF 顺序不同也会改退化幅度，需对照实验。
- **用单一基准代表能力**：MMLU 持平不代表代码/数学不降，需多维监控。

## 九、演进与趋势

- **对齐与能力联合目标**：把能力损失直接写进奖励，联合优化。
- **回放预训练数据**：训练全程混入原分布，抑制遗忘。
- **能力护栏**：监控关键基准，越界即触发回退/再训练。
- **过程监督**：用逐步奖励减少「说得好听做不对」。
- **能力护栏**：监控关键基准，越界即触发回退或再训练。
- **回放课程化**：训练早期强回放保能力，后期弱化强对齐。
- **联合奖励**：把能力损失直接写进奖励函数，端到端平衡。

## 十、小结

对齐税是对齐训练使通用能力退化的固有代价，根源是偏好优化造成的分布偏移。它可通过 KL 约束、数据回放与 LoRA 缓解，但前提是能用标准化基准量化（$B(\pi_{\text{align}})<B(\pi_{\text{SFT}})$）并正确归因，而非笼统归咎于对齐。
