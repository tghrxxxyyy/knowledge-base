# 能力保持的评估方法

> 对应 EleutherAI/lm-evaluation-harness 与 Gao et al. 2021 LM Evaluation Harness。

## 一、背景与挑战

要判断对齐训练是否「伤了能力」，不能靠主观感受，必须用可复现、标准化的评测量化对齐前后的能力变化。否则团队会在「感觉变笨了」与「其实没事」之间反复拉扯。挑战在于：能力是多维的（知识、推理、代码、数学、长上下文），单项变化易被总分掩盖；且公开榜单可能被训练数据污染，导致「刷分」而非「保持」。需要一套覆盖多维度、分项对比、可统计显著性的评估方法，并能检测「基准过拟合」。

## 二、核心原理

评估流程：
1. **固定基准集**：选定覆盖多维能力的标准基准（MMLU 知识、HellaSwag 常识、GSM8K 数学、HumanEval 代码、ARC 推理等），对齐前后用同一套任务评测，保证可比。
2. **分项对比**：不只看总分，而是逐任务计算对齐后 ($\pi_{\text{align}}$) 与对齐前 ($\pi_{\text{SFT}}$/$\pi_{\text{pre}}$) 的得分差 $\Delta_t$，识别退化集中在哪类能力。
3. **显著性检验**：用多次采样的均值与方差判断 $\Delta$ 是否显著，避免随机波动误报。
4. **去污染核对**：确认评测集未出现在训练数据，防污染虚高。
5. **能力-安全联合评测**：同时测安全合规，避免「保能力却失安全」。

理想状态：对齐后指令任务升、能力基准不显著降（对齐税≈0）。

## 三、形式化与数学基础

以多任务均值刻画对齐税：

$$ \Delta = \frac{1}{T}\sum_{t=1}^{T} \big(B_t(\pi_{\text{align}}) - B_t(\pi_{\text{SFT}})\big) $$

负值即整体对齐税。分项：

$$ \Delta_t = B_t(\pi_{\text{align}}) - B_t(\pi_{\text{SFT}}),\quad t=1,\dots,T $$

显著性：对任务 $t$ 重复 $k$ 次评测得样本 $\{s_{t,j}\}$，检验

$$ H_0: \mu_{\text{align},t} = \mu_{\text{SFT},t},\quad p = \text{t-test}(s_{\text{align}}, s_{\text{SFT}}) $$

$p<\alpha$ 且 $\Delta_t<0$ 判为显著退化。能力-安全联合评分可定义为帕累托点 $(\bar{B}, \bar{S})$。

## 四、代码实现

```python
# 用 lm-evaluation-harness 对齐前后跑同任务集
# python -m lm_eval \
#   --model hf \
#   --model_args pretrained=MODEL \
#   --tasks mmlu,hellaswag,gsm8k,humaneval,arc_challenge \
#   --num_fewshot 5 --seed 0 --output_path results.json

from lm_eval import evaluator

def alignment_tax(base, aligned, tasks):
    r1 = evaluator.simple_evaluate(model=base, tasks=tasks,
                                    num_fewshot=5, seed=0)
    r2 = evaluator.simple_evaluate(model=aligned, tasks=tasks,
                                    num_fewshot=5, seed=0)
    return {t: (r2["results"][t]["acc"] - r1["results"][t]["acc"])
            for t in tasks}
```

## 五、评估方式对比

| 方式 | 可复现 | 成本 | 盲区 | 适用 |
|------|--------|------|------|------|
| 人工评估 | 低 | 高 | 主观 | 体验 |
| 自动基准 | 高 | 低 | 过拟合榜 | 能力量化 |
| 能力-安全联合 | 中 | 中 | 需安全集 | 权衡 |
| 探针/困惑度 | 高 | 低 | 间接 | 遗忘检测 |

人工慢且贵；自动基准可复现但可能过拟合榜单，需配合去污染。

## 六、常见误区

- **只看总分**：总分持平可能掩盖单项（数学）崩塌，必须分项。
- **基准被训练污染**：训练数据含评测题会虚高，需 n-gram 去污染核对。
- **单次评测下结论**：随机种子影响大，应多次取均值与显著性。
- **能力升=对齐成功**：未同时测安全，可能以失安全换能力。

## 九、演进与趋势

- **动态/抗污染基准**：持续更新的题集防刷分。
- **能力-安全联合评测**：单分数同时反映两维。
- **探针式遗忘检测**：用轻量探针监控特定能力是否被遗忘。
- **在线评测**：训练期周期性评测，实时绘能力曲线。

## 十、小结

能力保持的评估需标准化基准与分项对比：用同一任务集对齐前后跑分，计算多任务均值 $\Delta$ 量化对齐税，并以显著性检验与去污染核对保证结论可靠。只盯总分或污染基准都会误判，必须多维、可复现、联合安全。
