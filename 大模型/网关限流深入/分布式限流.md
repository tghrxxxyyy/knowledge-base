# 分布式限流

> 对应 Redis, *Rate Limiting Patterns*（集中计数）；与 网关限流深入 / 优先级调度深入 衔接。

## 一、背景与挑战

网关多实例部署，本地桶无法跨节点全局限流，需共享状态。

## 二、核心原理

用 Redis 原子操作维护全局令牌计数，或采用滑动窗口日志/计数，保证集群总速受控。

## 三、数学形式

全局令牌 $G=\sum_i g_i\le B_{global}$；每个节点取本地份额 $g_i\le B_i$ 并定期同步。

## 四、代码实现

```python
allowed = r.eval(LUA_INCR_EXPIRE, [key], [cost, ttl])
# 原子 incr 并设过期，超阈返回 0
```

## 五、与其他对比

- 与 令牌桶与漏桶（分布式版状态共享）延展。
- 与 多模型路由深入（路由也可按配额）呼应。

## 六、常见误区

- Redis 单点成瓶颈，需分片/本地预热。
- 时钟与网络延迟造成限流抖动。
