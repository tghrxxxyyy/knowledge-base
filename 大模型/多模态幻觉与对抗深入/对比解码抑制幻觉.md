# 对比解码抑制幻觉

> 对应 Leng et al. 2023 「Mitigating Object Hallucinations via Contrastive Decoding」(VCD) 及 contrastive decoding 研究。

## 一、背景与挑战

推理时即可缓解幻觉，无需重训。对比解码通过比较「有图」与「无图/噪声图」下的 logits，抑制仅依赖语言先验的幻觉 token。挑战是构造合适的对照与权重。

## 二、核心原理

VCD 在解码时取原图模型 logits 与对图像加高斯噪声（削弱视觉）的模型 logits 之差，放大视觉依赖 token、抑制语言先验 token：
y_t \sim \mathrm{softmax}(\beta\,(logit_{orig}-logit_{noise}))
从而使生成更依赖真实视觉证据，减少无中生有。

## 三、数学形式

对比逻辑：
\tilde{s}_t = \log p_\theta(y_t\mid x,v) - \alpha \log p_\theta(y_t\mid x, \tilde{v})
其中 \tilde{v} 为噪声图像。最终：
y_t = \arg\max_k \left[ \log p_\theta(k\mid x,v) - \lambda \log p_\theta(k\mid x,\tilde{v}) \right]

## 四、代码实现

```python
import torch

def contrastive_decode(logits_img, logits_noise, lam=0.1):
    score = logits_img - lam * logits_noise
    return torch.argmax(score, dim=-1)
```

## 五、与其他对比

相比 retrain，VCD 即插即用、零训练；相比 greedy 更依赖视觉；可与 CD（文本对比解码）类比但作用在视觉模态。代价是需两次前向。

## 六、常见误区

以为对比解码替代训练；\lambda 过大致输出退化；噪声图像构造不当；忽略两次前向成本。

## 八、面试题

- Q：VCD 原理？答：原图与噪声图 logits 对比，抑语言先验。
- Q：优点？答：推理时即插即用，无需训练。
- Q：代价？答：需两次前向，调 \lambda。

## 九、演进

从 VCD 到更稳的对照构造；与采样策略结合；推广到其它模态幻觉。

## 十、小结

对比解码以推理期低成本方式显著抑制物体幻觉，是与训练期方法互补的实用技术。
