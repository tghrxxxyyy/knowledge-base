# 幻觉评测基准与度量

> 对应 Li 2023 POPE、Rohrbach 2018 CHAIR 及 HallusionBench（Guan et al. 2024）等幻觉基准。

## 一、背景与挑战

幻觉度量需覆盖物体、属性、关系多层面，且兼顾自动与人工。不同基准侧重不同，单一指标易片面。挑战是定义「幻觉」边界、避免语言风格干扰评分。

## 二、核心原理

CHAIR 统计生成描述中物体是否出现在 ground-truth 物体集合中：CHAIR_i 为幻觉物体占比，CHAIR_s 为含幻觉句子占比。POPE 用二元轮询。HallusionBench 考语言先验与视觉线索的平衡，含大量反直觉题。

## 三、数学形式

CHAIR_i = \frac{|\{h\in gen: h\notin GT\}|}{|\{g\in gen\}|}
CHAIR_s = \frac{|\text{sentences with any hallucination}|}{|\text{all sentences}|}
结合 F1（POPE）与准确率形成多维报告。

## 四、代码实现

```python
def chair(gen_objects, gt_objects):
    hal = [o for o in gen_objects if o not in gt_objects]
    return len(hal)/max(1,len(gen_objects))
```

## 五、与其他对比

CHAIR 看生成文本物体命中，POPE 看二元判断，HallusionBench 看先验对抗；三者互补，全面评估需联合报告。

## 六、常见误区

只报 CHAIR 忽略关系幻觉；用自动指标替代人工；未控制生成长度对幻觉率影响；混淆不同基准口径。

## 八、面试题

- Q：CHAIR 指标？答：物体级与句子级幻觉占比。
- Q：HallusionBench 特点？答：对抗语言先验，考视觉依赖。
- Q：为何多基准？答：各覆盖物体/属性/关系不同层面。

## 九、演进

从物体到属性、关系、计数；从自动到 LLM-as-judge；基准持续加难。

## 十、小结

幻觉评测已形成物体、属性、关系多层次基准体系，多维联合报告才能客观衡量 MLLM 事实性。
