# 视觉提示攻击

> 对应 视觉 jailbreak 研究（如 Qi et al. 2023 「Visual Adversarial Examples Jailbreak」、图像中隐藏指令攻击）。

## 一、背景与挑战

攻击者可在图片中嵌入文本指令或叠加视觉图案，诱导 MLLM 执行未授权行为（泄露系统提示、绕过安全策略）。区别于像素扰动，视觉提示更具语义性、可解释且易传播。挑战是防御难、检测难。

## 二、核心原理

两种形式：一是图像内嵌文字（typographic attack），模型把图中文字当指令；二是对抗补丁/触发器，使模型在看到特定图案时进入特定行为模式。攻击利用模型「图像即输入可含指令」的弱隔离。

## 三、数学形式

设系统提示 s，图像含隐藏指令 a，模型条件生成：
p_\theta(y \mid s, x, a) \neq p_\theta(y \mid s, x)
目标是使 a 的指令权重盖过 s 的安全约束。触发器可形式化为补丁 p 使：
\arg\max_y p_\theta(y\mid x\oplus p) = y_{target}

## 四、代码实现

```python
# 防御侧：检测图像中异常文本/指令
def scan_image_text(ocr_text, sys_rules):
    for kw in ["ignore", "system", "instruction"]:
        if kw in ocr_text.lower():
            return True
    return False
```

## 五、与其他对比

相比文本越狱，视觉提示可绕过纯文本护栏；相比像素对抗，更易制作与传播；防御需多模态内容审核与指令隔离。

## 六、常见误区

以为只在文本做安全即可；忽略 OCR 文本也能成指令；混淆艺术字与攻击；未对图像做指令级过滤。

## 八、面试题

- Q：视觉提示攻击形式？答：图像内嵌文字指令 + 对抗补丁触发器。
- Q：为何危险？答：绕过纯文本安全护栏。
- Q：防御思路？答：图像指令检测、多模态审核、系统提示隔离。

## 九、演进

从 typographic 到组合攻击；防御引入视觉护栏与可信执行；红队评测常态化。

## 十、小结

视觉提示攻击暴露了图文指令边界模糊的风险，构建多模态安全需在图像侧也设防。
