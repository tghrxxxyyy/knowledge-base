# 图像对抗扰动

> 对应 对抗样本研究（Szegedy et al. 2014；及多模态对抗攻击如 Zhao et al. 2023 「MMF」）在视觉语言模型的延伸。

## 一、背景与挑战

在图像上添加人眼不可察的扰动，可使分类器或 MLLM 输出错误。对多模态模型，对抗扰动可诱导错误描述、越权指令或绕过安全护栏。挑战在于扰动跨模态迁移性与鲁棒性评测。

## 二、核心原理

以 FGSM/PGD 在输入像素加约束扰动，最大化模型损失（或特定错误目标）。对 VLM，可优化扰动使图像编码特征偏移，导致文本生成偏离事实。攻击面包括图像编码器、对齐层与生成头。

## 三、数学形式

FGSM：\delta = \epsilon\,\mathrm{sign}(\nabla_x L(\theta,x,y))。PGD 迭代：
x^{t+1} = \Pi_{x+\mathcal{S}}\left(x^t + \alpha\,\mathrm{sign}(\nabla_x L)\right)
其中 \mathcal{S} 为 \ell_\infty 球，\Pi 为投影。对 VLM 目标可设为增大生成错误 token 似然。

## 四、代码实现

```python
import torch

def pgd_attack(model, img, label, eps=2/255, steps=5):
    x = img.clone().detach()
    for _ in range(steps):
        x.requires_grad_(True)
        loss = model.loss(model(x), label)
        grad = torch.autograd.grad(loss, x)[0]
        x = (x + eps*torch.sign(grad)).clamp(img-eps, img+eps).detach()
    return x
```

## 五、与其他对比

相比文本越狱，图像扰动更隐蔽、可物理打印；相比传统分类对抗，VLM 攻击影响语言输出更危险。防御需对抗训练与输入净化。

## 六、常见误区

以为视觉扰动不影响语言；忽略 \ell_\infty 约束导致可见；用单步 FGSM 过弱；混淆训练与推理阶段攻击。

## 八、面试题

- Q：PGD 与 FGSM 区别？答：PGD 多步投影迭代，更强。
- Q：对 VLM 攻击目标？答：偏移视觉特征致错误生成。
- Q：如何防御？答：对抗训练、输入净化、特征鲁棒化。

## 九、演进

从数字扰动到物理对抗贴片；从分类到 MLLM 越狱；可认证鲁棒性研究兴起。

## 十、小结

图像对抗扰动揭示了多模态模型的脆弱性，是安全评测与防御不可忽视的攻击面。
