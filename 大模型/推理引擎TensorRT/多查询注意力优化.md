# 多查询与分组查询注意力

> 对应 Shazeer(2019) MQA 与 Ainslie et al.(2023) GQA。

## 一、核心概念

标准 MHA 每头有独立 K/V，KV Cache 大。MQA 所有头共享一组 K/V，GQA 分组共享，显著减小 KV Cache 与显存带宽，提速解码。LLaMA-2/3 采用 GQA。

```
MHA: K,V ∈ ℝ^{h×d}    MQA: K,V ∈ ℝ^{1×d}    GQA: K,V ∈ ℝ^{g×d}, g<h
```

## 二、关键要点

| 类型 | KV 大小 | 质量 |
|------|---------|------|
| MHA | 大 | 高 |
| MQA | 最小 | 略降 |
| GQA | 中 | 接近 MHA |

## 三、与开源书的对应
