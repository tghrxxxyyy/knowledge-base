# 正交与稀疏初始化

> 对应 Saxe et al., 2013（正交初始化）；LeCun et al., 1998（稀疏初始化）。

## 一、背景与挑战

除方差外，权重矩阵的奇异值分布也影响训练动力学：接近正交的权重保持信号范数、减缓相关。

RNN/深层线性网络尤其受益于正交初始化。

## 二、核心原理

正交权重 $W^\top W=I$ 使每层近似等距映射，前向/反向梯度范数不随深度收缩，缓解消失。

稀疏初始化（如随机稀疏连接）减少参数耦合，加快早期学习（LeCun98 的 eclectic 初始化）。

## 三、数学形式

正交条件：$W^\top W=I$，则 $\|Wx\|=\|x\|$；QR 分解或 SVD 可得近似正交随机矩阵。

## 四、代码实现

```python
import torch
W = torch.empty(fan_out, fan_in)
torch.nn.init.orthogonal_(W)
```

## 五、与其他对比

- 与 Xavier/Kaiming 互补：后者控方差、前者控条件数。
- 与 梯度消失机理 衔接，正交保梯度范数。
- 与 RNN 训练（若新增）相关，正交初始化经典用于 RNN。

## 六、常见误区

- 正交初始化忽略方差尺度，仍可能整体偏大/小。
- 把正交用于 1x1 卷积等退化情形无意义。
- 稀疏度过高的连接切断信息通路。

## 八、面试题

- 正交初始化为何稳？答：等距映射保信号/梯度范数，不随深度收缩。
- 它与 Xavier 区别？答：Xavier 控方差，正交控奇异值分布（条件数）。

## 九、演进

随机 → 正交 → 谱归一化（约束最大奇异值）。

## 十、小结

正交初始化从条件数角度稳定训练，与方差初始化互补。
