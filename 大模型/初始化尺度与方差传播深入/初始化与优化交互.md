# 初始化与优化的交互

> 对应 优化-landscape 视角（Dauphin et al., 2014 saddle）；与学习率/归一化协同。

## 一、背景与挑战

初始化不仅决定起点幅值，还影响损失景观的“可导航性”。坏初始化让优化困在鞍部或饱和区。

它与学习率、归一化、优化器共同决定收敛。

## 二、核心原理

良好初始化把激活落在激活函数非饱和区，使梯度非零；配合适中学习率，SGD/Adam 可沿有效方向下降。

归一化（BN/LN）把每层输入拉回稳定分布，显著降低对初始化的敏感度。

## 三、数学形式

优化步有效性 $\propto\|\nabla L\|$；坏初始化使 $\phi'$ 近 0（饱和），梯度消失，步无效。

## 四、代码实现

```python
# 检查首步梯度是否健康
model.apply(init_weights)
logits = model(x); loss = crit(logits, y)
loss.backward()
print([p.grad.abs().mean().item() for p in model.parameters()][:3])
```

## 五、与其他对比

- 与 学习率与发散 衔接，初始化与 LR 共同决定首步。
- 与 归一化层数值稳定性深入 互补，归一化放宽初始化。
- 与 优化器状态数值误差深入 衔接，优化器在初始化之上迭代。

## 六、常见误区

- 认为有归一化就无需好初始化（起点仍影响景观）。
- 学习率过大掩盖初始化问题却引入发散。
- 忽视 Embedding/LM head 的初始化差异。

## 八、面试题

- 初始化如何影响优化景观？答：决定起点是否在饱和区，影响梯度是否存在。
- 归一化后还需好初始化吗？答：需要，归一化降低敏感度但不决定落点。

## 九、演进

固定初始化 → 方差/正交 → 归一化+warmup 协同。

## 十、小结

初始化与优化、归一化协同决定训练起点与可导航性，不可孤立看待。
