# 参数初始化总览

> 对应 Glorot & Bengio, 2010（Xavier）；He et al., 2015（Kaiming）；LeCun et al., 1998（Efficient BackProp）。

## 一、背景与挑战

初始化决定训练起点的信号与梯度幅值。过大会立刻饱和/溢出，过小会消失，二者都使训练难以启动。

目标是让前向激活方差与反向梯度方差在各层间“守恒”。

## 二、核心原理

线性层输出 $y=Wx+b$，若 $x,W$ 独立零均值，则 $\mathrm{Var}(y)=n_{in}\mathrm{Var}(W)\mathrm{Var}(x)$。

据此反解所需权重方差：对称（Xavier）取 $2/(n_{in}+n_{out})$，ReLU 取 $2/n_{in}$（Kaiming）。

## 三、数学形式

前向均衡：$\sigma_w^2=1/n_{in}$；前后向同时均衡（Xavier）：$\sigma_w^2=2/(n_{in}+n_{out})$。

## 四、代码实现

```python
import torch
for m in model.modules():
    if isinstance(m, torch.nn.Linear):
        torch.nn.init.xavier_uniform_(m.weight)
```

## 五、与其他对比

- 与 梯度消失机理 衔接，坏初始化是直接诱因。
- 与 初始化与激活协同 是同一主题的实践展开。
- 与 归一化层数值稳定性深入 互补，归一化放宽初始化敏感度。

## 六、常见误区

- 全零初始化致对称权重、不学习。
- 用相同大常数致神经元饱和。
- 忽视偏置初始化（常置 0，门控/遗忘门例外）。

## 八、面试题

- 为何不能全零初始化？答：对称权重得相同梯度，所有神经元学一样，无表达。
- 初始化与方差守恒关系？答：按层方差守恒反解权重尺度，维持信号不衰减/爆。

## 九、演进

常数/全零 → Xavier → Kaiming → 与归一化协同放宽。

## 十、小结

初始化以方差守恒设定权重尺度，是训练可启动的第一保障。
