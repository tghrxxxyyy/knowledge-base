# 方差传播与激活函数

> 对应 Glorot10、He15 的方差分析；也可参见 Saxe et al., 2013（线性网络动力学）。

## 一、背景与挑战

信号的逐层方差是否守恒，直接决定训练能否健康进行。激活函数的统计特性是方差演化的核心。

理解它才能解释为何某些激活更易训练。

## 二、核心原理

前向：$\mathrm{Var}(y_l)\approx n\sigma_w^2\cdot\mathbb E[\phi(z)^2]\cdot\mathrm{Var}(x)$。不同 $\phi$ 的方差保留率不同。

ReLU 保留 1/2，tanh 在线性区近 1，GELU/SiLU 接近但需查 gain 表修正。

## 三、数学形式

记 $c_\phi=\mathbb E[\phi(\mathcal N(0,1))^2]$，则 $\sigma_w^2=1/(n_{in}\,c_\phi)$ 维持前向方差；框架 gain 即 $\sqrt{c_\phi}$ 倒数修正。

## 四、代码实现

```python
gain = torch.nn.init.calculate_gain("relu")   # 约为 sqrt(2)
torch.nn.init.xavier_uniform_(W, gain=gain)
```

## 五、与其他对比

- 与 Xavier/Kaiming 推导 是同一分析的应用。
- 与 梯度消失机理 衔接，方差不守恒即消失/爆炸。
- 与 归一化层数值稳定性深入 互补，归一化强制方差回 1。

## 六、常见误区

- 忽略激活方差保留率，乱套公式。
- 以为 gain 只对初始化有效（也影响某些归一化）。
- 把 BN 后的方差当作未归一化的自然方差。

## 八、面试题

- 激活如何影响方差传播？答：不同激活的方差保留率 $c_\phi$ 决定权重所需尺度。
- gain 是什么？答：按激活方差保留率修正初始化尺度，使守恒成立。

## 九、演进

手推 → 框架 gain 表 → 数据驱动 LSUV。

## 十、小结

方差传播把初始化、激活、深度统一在一个守恒框架下。
