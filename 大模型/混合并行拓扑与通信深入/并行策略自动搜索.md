# 并行策略自动搜索

> 对应 AutoParallel/Alpa 思路 与 Narayanan 2021 3D 规划。

## 一、背景与挑战
人工选 $t,p,d$ 易次优。自动搜索在给定模型与集群下求解显存可行且通信最小的策略。

## 二、核心原理
将并行规划建模为搜索：枚举算子级切分(DP/TP/PP)、设备放置，用代价模型估算显存峰值与通信量，选 MFU 最高且满足约束的解。

## 三、形式化与数学基础
目标：
$ \\max_{t,p,d} \\mathrm{MFU}(t,p,d) \\;\\mathrm{s.t.}\\; M(t,p,d) \\le M_{\\mathrm{gpu}},\\; t\\cdot p\\cdot d = N $，
搜索空间受整除与拓扑约束剪枝。

## 四、代码实现
```python
# 概念：网格搜索可行并行配置
candidates = []
for t in divisors(hidden_heads):
    for p in divisors(num_layers):
        d = N // (t * p)
        if d >= 1 and mem_ok(t, p, d):
            candidates.append((t, p, d, mfu_est(t, p, d)))
best = max(candidates, key=lambda c: c[3])
```

## 五、与其他技术对比
手动配置依赖经验；Alpa 做 inter/intra-operator 并行自动划分；DeepSpeed 提供固定组合需人工选。

## 六、常见误区
误区一：搜索总优于手调——代价模型不准时反劣。误区二：忽略拓扑——跨节点 TP 被搜出但低效。误区三：只看通信，忽视气泡。

## 七、与开源书/权威来源对应
Narayanan 2021 给出 3D 解析解；Alpa/AutoParallel 论文论述自动搜索。

## 八、面试题
问：自动搜索优化什么？答：在显存约束下最大化 MFU。问：约束有哪些？答：整除、拓扑、显存。

## 九、演进与趋势
学习型代价模型 + 强化学习求解更大搜索空间。

## 十、小结
并行策略搜索把经验性调参变为约束优化，是规模化训练的增效方向。
