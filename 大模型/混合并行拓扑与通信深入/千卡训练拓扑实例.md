# 千卡训练拓扑实例

> 对应 Touvron 2023 (LLaMA) 与 Narayanan 2021 千卡部署。

## 一、背景与挑战
以千卡级集群训练百亿~千亿模型，需将 3D 并行、检查点、容错整体落地。LLaMA 等公开了典型配置。

## 二、核心原理
典型：节点内 8 卡做 TP=8(或 TP=4+PP 组合)，跨节点 PP 切层、DP/ZERO 做数据并行。梯度/激活用重计算与 ZeRO-3 控显存。

## 三、形式化与数学基础
以 $N=1024$、TP=8、PP=4 则 DP=32：
$ M \\approx 13\\Psi/32 + \\Psi/8 + \\mathrm{act}/8 $，
可训约数百亿~千亿参数，每步通信以 IB 上的 ZeRO-3 为主。

## 四、代码实现
```python
# 概念：千卡启动配置
config = {
  "tensor_parallel": 8,     # 节点内
  "pipeline_parallel": 4,   # 跨节点
  "data_parallel": 32,      # ZeRO-3
  "recompute": "selective",
}
```

## 五、与其他技术对比
纯 TP 千卡不现实(跨节点)；纯 DP 显存不足。3D 是 LLaMA/Chinchilla 类训练标准形态。

## 六、常见误区
误区一：直接 TP=1024——跨节点灾难。误区二：忽略重计算——激活爆显存。误区三：PP 气泡可忽略，实际需交错 1F1B。

## 七、与开源书/权威来源对应
Touvron 2023 LLaMA 训练配置；Narayanan 2021 千卡 3D 并行；microsoft/DeepSpeed。

## 八、面试题
问：千卡 TP 选多少？答：节点内 8(或更小)。问：DP 与 ZeRO 关系？答：DP 组用 ZeRO-3 分片。

## 九、演进与趋势
专家并行(MoE)进一步增加并行维；拓扑感知容错降低故障成本。

## 十、小结
千卡训练是 3D 并行 + 重计算 + ZeRO 的集成产物，拓扑须严格匹配硬件层次。
