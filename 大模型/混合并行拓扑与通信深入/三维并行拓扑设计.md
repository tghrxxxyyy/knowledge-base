# 三维并行拓扑设计

> 对应 Narayanan 2021 (Efficient Large-Scale LM Training) 与 Shoeybi 2019。

## 一、背景与挑战
单一并行策略无法兼顾显存、通信与吞吐。3D 并行(DP × PP × TP)将设备组织为三维网格，按层次分配不同并行。

## 二、核心原理
最内层 TP 在节点内高带宽域切矩阵；中层 PP 纵向切层并流水；外层 DP/ZERO 沿数据维复制。总设备 $N = d \\cdot p \\cdot t$，各维职责分离。

## 三、形式化与数学基础
设总 GPU 数 $N$，选取 $t$(TP) 整除节点内卡数，$p$(PP) 整除层数，$d=N/(tp)$。单卡显存：
$ M \\approx (K+1)\\Psi/(d) + \\Psi/t + \\mathrm{act}/t $，
兼顾分片与切分。

## 四、代码实现
```python
# 概念：分配进程网格
import torch.distributed as dist
tp = 8; pp = 4; dp = world_size // (tp * pp)
# 先按 tp 组内 all-reduce，再 pp 跨段，最后 dp 做 ZeRO
rank_tp = rank % tp
rank_pp = (rank // tp) % pp
rank_dp = rank // (tp * pp)
```

## 五、与其他技术对比
仅 DP 受显存限；仅 TP 受头数/隐藏维限；仅 PP 有气泡。3D 组合突破各自上限，是千亿模型标配。

## 六、常见误区
误区一：三维可任意配——受层可被 $p$ 整除、头被 $t$ 整除约束。误区二：DP 与 PP/TP 独立——实际 DP 在 PP/TP 组间做 ZeRO。误区三：维度越多越好，实际通信管理复杂。

## 七、与开源书/权威来源对应
Narayanan 2021 3D 并行；Shoeybi 2019 Megatron；microsoft/DeepSpeed 支持组合。

## 八、面试题
问：3D 并行三维修什么？答：TP 切矩阵(节点内)、PP 切层、DP 做 ZeRO。问：如何选维度？答：按显存/通信/层数约束求解。

## 九、演进与趋势
自动化并行搜索(如 Alpa)求解最优 $t,p,d$ 分配。

## 十、小结
3D 并行通过分层解耦显存与通信，是超大规模训练的工程骨架。
