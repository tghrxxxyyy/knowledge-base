# 标签平滑与蒸馏交互

> 对应 实践观察；与 知识蒸馏深入 / 标签平滑原理深入 衔接。

## 一、背景与挑战

二者都柔化目标，叠加时可能过度平滑或互相抵消，需理解交互。

## 二、核心原理

教师软标签本身已含平滑结构；若再对学生用强标签平滑，可能淹没教师信号或双重正则过强。

## 三、数学形式

组合目标 $q_{mix}=\alpha p_{teacher}^T + (1-\alpha) q_{smooth}$；权重决定主导信号。

## 四、代码实现

```python
target = 0.9*soft_teacher + 0.1*smooth_onehot
```

## 五、与其他对比

- 与 知识蒸馏深入 共享目标构造环节。
- 与 训练数据质量 关注标签本身可信度。

## 六、常见误区

- 两端都强平滑致信号过软、欠拟合。
- 忽视教师已平滑却仍加大学生平滑。

## 八、面试题

- 蒸馏时还要标签平滑吗？答：教师软标签已平滑，通常弱平滑或不加，避免双重过软。

## 九、演进

独立使用 → 组合加权 → 自适应配比。

## 十、小结

二者交互需谨慎配比，教师软标签常已替代部分平滑作用。
