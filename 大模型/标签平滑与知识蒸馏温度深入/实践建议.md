# 标签平滑与蒸馏温度实践建议

> 对应 工程配方；与 调度调参经验深入 / 训练数据质量 衔接。

## 一、背景与挑战

$\epsilon$ 与 $T$ 是敏感超参，需按任务规模设定。

## 二、核心原理

分类常用 $\epsilon=0.1$；蒸馏 $T\in[2,4]$ 起步，配合 $T^2$ 缩放损失，按验证集调。

## 三、数学形式

建议扫描 $\epsilon\in\{0,0.05,0.1,0.2\}$，$T\in\{1,2,4,8\}$ 选最优验证损失。

## 四、代码实现

```python
for eps in [0,0.1]:
    for T in [1,4]:
        train(label_smoothing=eps, distill_T=T)
```

## 五、与其他对比

- 与 学习率调度深入 同属训练配方可调项。
- 与 模型校准深入 共享校准目标。

## 六、常见误区

- 默认 $\epsilon=0.1$ 套所有任务。
- 蒸馏温度与学习率未联合调。
