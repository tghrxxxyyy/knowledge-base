# 标签平滑与知识蒸馏温度总览

> 对应 Szegedy et al., 2016 与 Hinton et al., 2015；与 知识蒸馏深入 / 训练数据质量 衔接。

## 一、背景与挑战

硬标签迫使模型过度自信、泛化差；标签平滑与蒸馏温度都通过软化目标缓解过拟合。

## 二、核心原理

标签平滑把 one-hot 目标掺入均匀噪声；蒸馏温度提高 softmax 熵，暴露类间相似结构。

## 三、数学形式

二者均改造目标分布 $q$；平滑改 $q$，温度改 $p$ 的锐度，目标皆为更柔概率。

## 四、代码实现

```python
crit = torch.nn.CrossEntropyLoss(label_smoothing=0.1)
```

## 五、与其他对比

- 标签平滑改标签，蒸馏温度改教师输出软标签，二者可叠加。
- 与 知识蒸馏深入 主题高度相关。

## 六、常见误区

- 过度平滑致模型欠拟合、类间不可分。
- 混淆二者作用对象（标签 vs 教师输出）。

## 八、面试题

- 标签平滑与蒸馏温度共通点？答：都软化目标分布，降低过自信、提升泛化。

## 九、演进

硬标签 → 标签平滑 → 蒸馏软标签 → 组合使用。

## 十、小结

平滑与温度都是“软化目标”的正则手段，机制与作用对象不同。
