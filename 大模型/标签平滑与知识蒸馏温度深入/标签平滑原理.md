# 标签平滑原理

> 对应 Szegedy et al., *Rethinking Inception*, CVPR 2016；与 训练数据质量 衔接。

## 一、背景与挑战

one-hot 标签假设唯一正确类，迫使模型对错误类输出极小 logit，易过自信与过拟合。

## 二、核心原理

以概率 $\epsilon$ 把目标质量分散到全部类，使模型不对非目标类过度压低，提升校准与泛化。

## 三、数学形式

$q_i = \begin{cases}1-\epsilon+\epsilon/K, & i=y \\ \epsilon/K, & i\neq y\end{cases}$。

## 四、代码实现

```python
def smooth(y, K, eps=0.1):
    q = torch.full((K,), eps/K); q[y] = 1-eps+eps/K; return q
```

## 五、与其他对比

- 与 知识蒸馏深入（软标签来自教师）来源不同但都柔化目标。
- 与 模型校准深入 强相关（改善校准）。

## 六、常见误区

- $\epsilon$ 过大致欠拟合。
- 在标签本身含多真值的任务（如检索）误用会模糊信号。

## 八、面试题

- 标签平滑为何提升泛化？答：避免对非目标类极端压低，学得更校准、更鲁棒的特征。

## 九、演进

hard → 均匀平滑 → 按类别置信度的自适应平滑。

## 十、小结

标签平滑以均匀噪声柔化硬标签，缓解过自信、改善校准。
