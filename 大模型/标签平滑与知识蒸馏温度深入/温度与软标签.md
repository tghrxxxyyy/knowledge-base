# 温度与软标签关系

> 对应 Hinton et al., 2015；与 知识蒸馏与温度深入 衔接。

## 一、背景与挑战

温度 $T$ 直接控制软标签的熵与信息量，选错则蒸馏失效。

## 二、核心原理

$T\to1$ 接近常规 softmax；$T\gg1$ 趋近均匀（信息少）；$T$ 适中保留类间结构又不过于尖锐。

## 三、数学形式

$\lim_{T\to\infty} p_i^T = 1/K$（均匀）；$\lim_{T\to1}$ 为普通 softmax；信息量随 $T$ 先增后减。

## 四、代码实现

```python
soft = torch.softmax(teacher_logits / T, dim=-1)
```

## 五、与其他对比

- 与 标签平滑深入 都影响目标分布熵，但来源不同。
- 与 模型校准深入：温度也用于推理校准（temperature scaling）。

## 六、常见误区

- $T$ 过大软标签近乎均匀，无监督信号。
- 训练/推理温度混用。

## 八、面试题

- 温度如何影响软标签？答：高温展平暴露暗知识，过低则接近硬标签失蒸馏意义。

## 九、演进

固定 T → 自适应 T → 每层不同 T。

## 十、小结

温度是蒸馏的信息旋钮，需权衡暗知识暴露与噪声。
