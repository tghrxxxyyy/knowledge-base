# 知识蒸馏与温度

> 对应 Hinton, Vinyals & Dean, *Distilling*, 2015；与 知识蒸馏深入 衔接。

## 一、背景与挑战

小模型直接从硬标签学难达大模型性能；教师软标签含类间结构信息。

## 二、核心原理

用高温 softmax 放大教师输出的小概率差异（暗知识），学生匹配该软目标，再在推理时回温 1。

## 三、数学形式

$p_i^T = \frac{\exp(z_i/T)}{\sum_j \exp(z_j/T)}$；蒸馏损失匹配 $p^T_{teacher}$ 与 $p^T_{student}$。

## 四、代码实现

```python
logp_s = F.log_softmax(z_s/T, dim=-1)
loss = kl(logp_s, soft_t) * T*T
```

## 五、与其他对比

- 与 标签平滑深入 可叠加：教师软标签+学生侧平滑。
- 与 参数高效微调深入 无关，属压缩范畴。

## 六、常见误区

- 忘记乘 $T^2$ 补偿梯度尺度，温度高时梯度过小。
- 推理时未用 $T=1$ 致分布偏移。

## 八、面试题

- 为何蒸馏要升温？答：高温展平 softmax，放大小类间概率差异（暗知识）供学生学。

## 九、演进

硬标签 → 软标签蒸馏 → 特征/关系蒸馏。

## 十、小结

知识蒸馏借温度提取教师暗知识，是学生模型提质的关键。
