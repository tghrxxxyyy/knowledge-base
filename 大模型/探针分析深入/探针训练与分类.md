# 探针训练与分类

> 对应 Tenney et al., *What do you learn during fine-tuning?*, 2019（edge probing）；Hewitt & Manning, *Structural Probes*, 2019.

## 一、背景与挑战

不同属性（词性、句法、语义角色）在不同层可探测性不同，需系统化训练与评估探针。

## 二、核心原理

设计不同难度的探针任务：简单分类（线性）到结构化（如距离探针预测句法距离）；用留层交叉验证看信息随层演化。

## 三、数学形式

结构探针距离 $\hat d(i,j)=\|W h_i-W h_j\|_2$ 拟合真实句法距离 $d_{ij}$。

## 四、代码实现

```python
probe = nn.Linear(d, n_labels)
opt = torch.optim.Adam(probe.parameters(), lr=1e-3)
for h,y in loader: opt.zero_grad(); probe(h).float().loss(y).backward(); opt.step()
```

## 五、与其他对比

- edge probing 用 span 级表示，比 token 级更贴近下游任务。
- 与 探针可靠性批判（容量控制）呼应。

## 六、常见误区

- 不控制探针容量导致虚高。
- 训练/测试分布不一致（如领域偏移）。

## 八、面试题

- 如何避免探针容量过大？答：用受控容量的线性/极小 MLP，并以随机表示基线对照。

## 九、演进

token 探针 → edge probing → 控制变量比较。

## 十、小结

系统化的探针训练与分层评估，揭示表示中信息的层次结构。
