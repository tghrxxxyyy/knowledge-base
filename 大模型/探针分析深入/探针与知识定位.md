# 探针与知识定位

> 对应 Petroni et al., *Language Models as Knowledge Bases?*, 2019；Burns et al., *Discovering Latent Knowledge*, 2022.

## 一、背景与挑战

LLM 把事实知识存在参数中，探针可用于“读出”模型是否“知道”某事实，而不依赖生成。

## 二、核心原理

在中间层探针预测实体/关系存在性；Burns 等进一步用线性探针在“真/假”表示上做对比读出 latent knowledge（无需标准答案标注）。

## 三、数学形式

真值方向 $v=\bar h_{true}-\bar h_{false}$；对样本 $h$ 判断 $\text{sign}(v^\top h)$ 预测真假。

## 四、代码实现

```python
v = Hs[true].mean(0) - Hs[false].mean(0)
pred = (Hs @ v > 0).long()     # 是否“知道”为真
```

## 五、与其他对比

- 与 线性探针深入（同一线性读出技术）衔接。
- 与 特征归因深入（定位导致输出的特征）互补。

## 六、常见误区

- 探针“知道”不代表模型会在生成中说出来（行为≠知识）。
- 方向向量在不同提示下可能不稳定。

## 八、面试题

- 探针知道 vs 模型说出，区别？答：探针从内部表示读出知识，但解码/生成可能因对齐或格式而不输出。

## 九、演进

事实探针 → latent knowledge 读出 → 引导式解码。

## 十、小结

探针是探测模型“内隐知识”的利器，但需区分知识存在与行为表达。
