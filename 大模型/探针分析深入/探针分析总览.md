# 探针分析总览

> 对应 Alain & Bengio, *Understanding intermediate layers using linear classifiers*, 2016；Belinkov et al., *Analysis Methods in Neural Language Processing*, 2017.

## 一、背景与挑战

想知道“模型内部某层表示是否编码了某语言学/语义属性”，直接看权重不可读，于是训练一个探针分类器在冻结表示上预测该属性。

## 二、核心原理

冻结 LLM 某层输出，在其上训练轻量探针（多为线性）预测属性标签 $y$；探针准确率反映该信息是否线性可恢复。

## 三、数学形式

探针损失 $\mathcal L=\sum_i \ell(g_\phi(h_i), y_i)$，$h_i$ 为层表示；$g_\phi$ 线性时 $g_\phi(h)=Wh+b$。

## 四、代码实现

```python
H = encoder.layers[l](input_ids).detach()   # (N,d)
clf = LogisticRegression().fit(H.cpu(), labels)
acc = clf.score(H.cpu(), labels)
```

## 五、与其他对比

- 与 特征归因深入（归因导致输出的原因）不同：探针查“含什么信息”。
- 与 线性探针深入（探针的线性特例）衔接。

## 六、常见误区

- 高探针准确率不代表模型“用”该信息（只是可恢复）。
- 容量过大的探针可记住噪声，误判信息存在。

## 八、面试题

- 探针高准确率说明什么？答：仅说明该属性在表示中线性可恢复，不代表模型推理时依赖它。

## 九、演进

线性探针 → 控制变量探针 → 信息论探针。

## 十、小结

探针是探测表示内容的经典工具，但需谨慎区分“可恢复”与“被使用”。
