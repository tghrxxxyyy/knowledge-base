# 探针分析实践指南

> 对应 Belinkov, 2022 综述；Rogers et al., *A Primer in BERTology*, 2020.

## 一、背景与挑战

实际做探针研究易踩坑：容量、基线、数据泄漏，需一套可复现流程。

## 二、核心原理

固定表示层 → 选受控容量探针 → 加 control task 基线 → 分层/跨模型对比 → 报告信息量而非仅准确率。

## 三、数学形式

跨层曲线 $a(l)$ 显示信息峰值层；用 $\Delta a(l)=a_{real}(l)-a_{control}(l)$ 找真实信息层。

## 四、代码实现

```python
for l in range(n_layers):
    H = get_hidden(X, l).detach()
    a_real = probe(H, y); a_ctl = probe(H, shuffle(y))
    curve[l] = a_real - a_ctl
```

## 五、与其他对比

- 与 激活监控深入（在线持续探测）衔接。
- 与 稀疏自编码器深入（更细特征级探测）形成层次。

## 六、常见误区

- 仅在一个随机种子下报告。
- 训练测试同分布但探针在无关属性上泄漏。

## 八、面试题

- 给出可靠探针实验的要点？答：受控容量、control 基线、多种子、分层报告信息量。

## 九、演进

手工实验 → 标准化流程 → 自动化探针套件。

## 十、小结

可靠的探针实践依赖容量控制、基线对照与分层报告，方能得出可复现结论。
