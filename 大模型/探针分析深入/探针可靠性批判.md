# 探针可靠性批判

> 对应 Hewitt & Liang, *Designing and Interpreting Probes*, 2019（控制任务基线）；Voita & Titov, *Information-Theoretic Probing*, 2020.

## 一、背景与挑战

高探针准确率可能被误读为“模型用该信息”，但探针也可能从表示中“学习”到标签映射而非信息本就显式存在。

## 二、核心原理

引入控制任务（control task）：在随机表示上训练探针，若仍能高准确则原结论不可靠；用选择性/信息量（如互信息）替代纯准确率。

## 三、数学形式

探针信息量 $I(Y; \hat Y)$ 或控制差 $\Delta_{acc}=acc_{real}-acc_{control}$；仅当 $\Delta$ 显著才说明信息真实存在。

## 四、代码实现

```python
acc_real = probe.fit(H, y).score(H, y)
acc_ctrl = probe.fit(H, shuffle(y)).score(H, shuffle(y))
info = acc_real - acc_ctrl
```

## 五、与其他对比

- 与 线性探针深入（线性容量天然受限、更可信）呼应。
- 与 数据高效学习深入（样本效率）相关。

## 六、常见误区

- 直接报告准确率忽略控制基线。
- 小数据集上探针方差大仍下结论。

## 八、面试题

- 为何需要 control task？答：排除探针靠标签结构而非表示信息取胜，确保结论可靠。

## 九、演进

准确率 → 控制基线 → 信息论指标。

## 十、小结

探针结论必须经控制基线与信息量校准，否则易过度解读。
