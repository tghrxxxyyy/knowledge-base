# 线性探针与非线性探针

> 对应 Alain & Bengio, 2016；Belinkov, *Probing Classifiers*, 2022（综述）.

## 一、背景与挑战

线性探针简单可解释但可能漏掉非线性编码的信息；非线性探针更强但难解释、易过拟合。

## 二、核心原理

线性探针 $g(h)=Wh+b$ 假设信息线性可分离；MLP 探针可捕获非线性边界，但需正则与容量控制以免记住标签。

## 三、数学形式

信息下界：若线性探针准确率 $a_{lin}$，非线性 $a_{mlp}$，二者差反映非线性可恢复信息量 $\Delta=a_{mlp}-a_{lin}$。

## 四、代码实现

```python
linear = nn.Linear(d, k)
mlp    = nn.Sequential(nn.Linear(d, d//2), nn.Tanh(), nn.Linear(d//2, k))
```

## 五、与其他对比

- 与 线性探针深入（专论线性情形）衔接。
- 非线性探针接近 稀疏自编码器深入 的表示几何视角。

## 六、常见误区

- 以为非线性探针更高就说明信息更多（可能过拟合）。
- 不做随机基线对照。

## 八、面试题

- 何时用非线性探针？答：当怀疑信息非线性编码且线性已达上限，并以容量控制+基线确保非过拟合时。

## 九、演进

纯线性 → MLP → 信息论/贝叶斯探针。

## 十、小结

线性与非线性探针互补，容量控制与基线对照是可靠结论的前提。
