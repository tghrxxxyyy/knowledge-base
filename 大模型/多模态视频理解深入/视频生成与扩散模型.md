# 视频生成与扩散模型

> 对应 Ho 2020 的 DDPM 论文与 github huggingface/transformers 项目。

## 一、背景与挑战
视频生成需保证时序一致性与高保真。扩散模型通过逐步去噪生成帧序列，但跨帧一致性是难点。

## 二、核心原理
在潜空间对噪声帧做联合去噪，条件可为文本或首帧。训练目标是预测所加噪声，推理时从纯噪迭代去噪得视频。

## 三、形式化与数学基础
扩散前向：
$ q(x_t|x_{t-1})=\mathcal{N}(x_t;\sqrt{1-\beta_t}x_{t-1},\beta_t I) $
训练损失 $ \mathcal{L}=\mathbb{E}\| \epsilon-\epsilon_\theta(x_t,t) \|^2 $。

## 四、代码实现
```python
import torch

def train_step(model, x0, noise_sched, t):
    noise = torch.randn_like(x0)
    xt = noise_sched.add(x0, noise, t)
    pred = model(xt, t)
    return ((pred - noise) ** 2).mean()

def sample(model, shape, steps):
    x = torch.randn(shape)
    for t in reversed(range(steps)):
        x = model.denoise(x, t)
    return x
```

## 五、与其他技术对比
相比 GAN，扩散训练更稳定、样品质优；代价是推理步数多、速度慢。

## 六、常见误区
忽略时序约束导致闪烁。步数过少质量骤降。
