# 视频文本检索与对比学习

> 对应 github facebookresearch/faiss 项目与 Lewis 2020 的 RAG 论文。

## 一、背景与挑战
用自然语言搜视频需跨模态对齐。目标是把文本查询与匹配视频片段映射到近邻向量空间。

## 二、核心原理
视频与文本分别编码，用对比损失拉近正对、推远负对，使查询向量可在 FAISS 中检索到对应片段。

## 三、形式化与数学基础
对比损失（InfoNCE）：
$ \mathcal{L}=-\log\frac{\exp(v^\top t/\tau)}{\sum_{j}\exp(v^\top t_j/\tau)} $
$ \tau $ 为温度。

## 四、代码实现
```python
import torch

def clip_loss(v, t, tau=0.07):
    logits = v @ t.T / tau
    labels = torch.arange(len(v))
    return torch.nn.functional.cross_entropy(logits, labels)

def search(index, query_vec, k=10):
    d, i = index.search(query_vec.reshape(1, -1), k)
    return i[0], d[0]
```

## 五、与其他技术对比
相比标签分类，对比学习支持开放词汇检索；相比纯文本检索，跨模态更贴合视频语义。

## 六、常见误区
负样本不足导致塌缩。时长对齐错误污染正对。

## 八、面试题
问：温度系数作用？答：调节分布锐度，过小过拟合、过大欠区分。

## 九、演进与趋势
片段级对齐、时序对比与大规模视频语料。

## 十、小结
跨模态对比把视频变成可语言检索的对象。
