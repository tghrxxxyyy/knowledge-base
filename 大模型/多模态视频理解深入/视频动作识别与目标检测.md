# 视频动作识别与目标检测

> 对应 github pytorch/pytorch 项目与 Devlin 2018 的 BERT 论文。

## 一、背景与挑战
动作识别需捕捉人与物体的时空交互。单帧检测不足以判断动作，需结合时序上下文。

## 二、核心原理
对每帧做目标检测得到框与类别，沿时间关联同一目标，再用时序模型聚合其行为序列判定动作类别。

## 三、形式化与数学基础
动作分类可写为：
$ a = \arg\max_c P(c | \{b_t, o_t\}_{t=1}^{T}) $
其中 $ b_t $ 为框，$ o_t $ 为目标特征。

## 四、代码实现
```python
import torch

def track(detections, iou_thr=0.5):
    tracks = []
    for t, dets in enumerate(detections):
        for d in dets:
            matched = False
            for tr in tracks:
                if iou(tr[-1].box, d.box) > iou_thr:
                    tr.append(d); matched = True; break
            if not matched:
                tracks.append([d])
    return tracks

def classify(action_head, track_feats):
    return int(action_head(track_feats).argmax())
```

## 五、与其他技术对比
相比图像分类，动作识别多时序维度；相比光流法，检测加跟踪更鲁棒。

## 六、常见误区
忽略目标遮挡导致跟踪断裂。单帧误检影响全局判断。
