# 视频问答与时空注意力

> 对应 github Dao-AILab/flash-attention 项目与 Dao 2022 的 FlashAttention 论文。

## 一、背景与挑战
视频问答需同时理解画面内容与时序因果。长序列注意力带来显存与速度瓶颈，需高效实现。

## 二、核心原理
将视频帧 patch 与问题 token 拼接，做时空联合注意力；FlashAttention 以分块与重算降低显存，使长视频可训练。

## 三、形式化与数学基础
标准注意力显存 $ O(N^2) $，FlashAttention 通过分块把中间矩阵不落盘，降为 $ O(N) $ 显存，计算不变。

## 四、代码实现
```python
import torch
from flash_attn import flash_attention_qkv

def video_qa(frames_feat, question_feat):
    # frames_feat: (T*P, d); question_feat: (L, d)
    tokens = torch.cat([question_feat, frames_feat], 0)
    out = flash_attention_qkv(tokens, tokens, tokens)
    return out[:question_feat.shape[0]]

def answer(model, pooled, q):
    return model.head(pooled)
```

## 五、与其他技术对比
相比普通注意力，FlashAttention 省显存、更快；相比仅空间注意力，时空联合更利因果推理。

## 六、常见误区
忽视帧顺序打乱时空。问题 token 不参与交互则答非所问。
