# 视频时序建模与帧采样

> 对应 github huggingface/transformers 项目与 Vaswani 2017 的 Transformer 论文。

## 一、背景与挑战
视频帧率高、冗余大，全帧处理算力不可承受。需要稀疏采样与时序聚合，在保信息与控制成本间平衡。

## 二、核心原理
按固定间隔或关键帧策略采样，帧内用视觉编码器提取表征，帧间用时序注意力聚合动态信息，输出视频级表示。

## 三、形式化与数学基础
时序注意力对帧序列 $ \{f_t\} $：
$ h = \mathrm{Attention}(Q_f, K_f, V_f)=\mathrm{softmax}(Q_f K_f^\top/\sqrt d)V_f $

## 四、代码实现
```python
import torch

def sample_frames(video, num=8):
    total = len(video)
    idx = [int(i * total / num) for i in range(num)]
    return [video[i] for i in idx]

def temporal_pool(frame_feats):
    # frame_feats: (T,d)
    q = frame_feats[-1:]
    scores = q @ frame_feats.T
    w = torch.softmax(scores, -1)
    return (w @ frame_feats).squeeze(0)
```

## 五、与其他技术对比
相比 3D 卷积，时序注意力更灵活可捕长程；相比 LSTM，可并行且梯度更稳。

## 六、常见误区
均匀采样错过突变事件。采样过少丢关键动作。

## 七、与开源书/权威来源对应

## 八、面试题
问：为何稀疏采样？答：相邻帧高度冗余，稀疏可降成本并覆盖全长。

## 九、演进与趋势
自适应关键帧、长视频层次建模。

## 十、小结
帧采样加时序聚合是视频理解的基础流水线。
