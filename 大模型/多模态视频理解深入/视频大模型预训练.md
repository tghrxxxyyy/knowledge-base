# 视频大模型预训练

> 对应 github facebookresearch/llama 项目与 Touvron 2023 的 LLaMA 论文。

## 一、背景与挑战
视频数据规模大、标注稀，需自监督预训练学到通用表征，再迁移到下游任务。

## 二、核心原理
以掩码帧建模或对比为预训练目标，在海量视频上训练视觉 Transformer，使其具备时序与世界知识先验。

## 三、形式化与数学基础
掩码帧重建：
$ \mathcal{L}=\sum_{p\in M}\| f_p - \hat f_p \|^2 $
$ M $ 为被掩 patch 集合。

## 四、代码实现
```python
import torch

def mask_patches(tokens, mask_id, p=0.4):
    masked = list(tokens)
    labels = [-100] * len(tokens)
    for i, v in enumerate(tokens):
        if torch.rand(1) < p:
            masked[i] = mask_id
            labels[i] = v
    return masked, labels
```

## 五、与其他技术对比
相比监督预训练，自监督利用无标注视频；相比图像模型，视频模型多时序维度。

## 六、常见误区
掩码率过高学不到结构。分辨率过低丢细节。
