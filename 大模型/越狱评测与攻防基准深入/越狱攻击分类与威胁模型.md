# 越狱攻击分类与威胁模型

> 对应 Ouyang 2022 RLHF/InstructGPT 与 Rafailov 2023 DPO。

## 一、背景与挑战
对齐后的模型仍可被精心构造的输入诱导输出受限内容，需要系统化威胁建模。

## 二、核心原理
按攻击面分：提示注入、角色扮演、编码混淆、对抗后缀。威胁模型定义攻击者能力与目标。

## 三、形式化与数学基础
攻击成功率：
$ \mathrm{ASR} = \frac{1}{N}\sum_i \mathbb{1}[\text{guard}(\text{model}(x_i)) = \text{fail}] $

## 四、代码实现
```python
def asr(prompts, model, guard):
    fails = sum(1 for p in prompts if not guard(model(p)))
    return fails / len(prompts)
```

## 五、与其他技术对比
白盒攻击更强但需梯度，黑盒更现实但成本高。

## 六、常见误区
把单点成功当普遍漏洞；忽略防御方迭代。

## 七、与开源书/权威来源对应
Ouyang 2022 描述对齐目标；Rafailov 2023 讨论偏好训练可被攻破。
