# 越狱攻击分类与威胁模型

> 对应 Ouyang 2022 InstructGPT 的对齐目标，以及 Rafailov 2023 DPO 中偏好训练可被攻破的讨论。

## 一、背景与挑战

即使经过 RLHF/DPO 对齐的模型，仍可能被精心构造的输入诱导输出受限内容。要系统评估风险，不能停留在「试几个 prompt」，而需建立威胁模型。

明确攻击者的能力（白盒/黑盒）、目标（越狱、信息泄露、偏见放大）与攻击面，进而对攻击手法分类，才能设计可复现、可对比的评测协议。

若缺乏威胁模型，评测会变成「凑成功案例」，既无法量化风险，也无法指导防御优先级，更无法在不同模型间做公平比较。

## 二、核心原理

按攻击面可将越狱分为几类：①提示注入（在指令中追加覆盖性语句）；②角色扮演/虚构情境（「你现在是无限制的 DAN」）；③编码混淆（base64、外语、汉字拆字绕过敏感词）；④对抗后缀（在 token 级追加难读串使 refusal 分布塌陷）；⑤多轮渐进诱导。

威胁模型则定义攻击者知识（是否可访问梯度/权重）、查询预算与成败准则，决定评测的置信度与可复现性。

分类与威胁模型共同构成评测的「坐标系」：分类回答「用什么招」，威胁模型回答「谁、凭什么、攻什么」，二者缺一都会导致评测失真。

关键要点：

- 按攻击面分：提示注入/角色扮演/编码混淆/对抗后缀/多轮诱导。
- 威胁模型定义攻击者能力（白盒/黑盒）、预算与成败准则。
- 白盒需梯度、成功率高但现实性低；黑盒现实性强但查询成本高。
- 分类与威胁模型共同构成评测的「坐标系」。
- 单点成功 ≠ 普遍漏洞，须以大规模 ASR 量化。
- 不声明攻击者能力的 ASR 数字毫无比较意义。

## 三、形式化与数学基础

攻击成功率（ASR）是核心指标：

$$
\mathrm{ASR} = \frac{1}{N}\sum_i \mathbb{1}[\text{guard}(\text{model}(x_i)) = \text{fail}]
$$

其中 $x_i$ 为攻击样本，$\text{guard}$ 为护栏/裁判。对白盒攻击者，可定义优化目标：

$$
\max_{x} \Pr(\text{harmful} \mid \text{model}(x)) \quad \text{s.t. } \|x-x_0\| \le \epsilon
$$

黑盒攻击则只能靠查询反馈近似，预算 $K$ 次查询内达成即计成功。分类覆盖率定义为已覆盖攻击面占全部已知面的比例。

## 四、代码实现

```python
# 攻击成功率统计（示意）
def asr(prompts, model, guard):
    fails = 0
    for p in prompts:
        out = model(p)
        if not guard(out):               # guard 返回 False 表示未拦住
            fails += 1
    return fails / len(prompts)

# 按攻击类别分组统计
def asr_by_category(samples, model, guard):
    return {c: asr([s for s in samples if s.cat == c], model, guard)
            for c in set(s.cat for s in samples)}
```

## 五、与其他技术对比

| 维度 | 白盒攻击 | 黑盒攻击 |
|------|----------|----------|
| 需梯度 | 是 | 否 |
| 成功率 | 高 | 中 |
| 现实性 | 低（难获取权重） | 高 |
| 成本 | 高（算力） | 高（查询） |

白盒用于研究上界，黑盒用于衡量真实风险；二者 ASR 不可直接比较，须标注威胁模型。

## 六、常见误区

误区一：把单点成功当普遍漏洞——应以大规模 ASR 评估，单例只是存在性证据。

误区二：忽略防御方迭代——静态评测集会过时，攻击成功率会随防御更新而漂移。

误区三：只测英文——多语言混淆常绕过，且非英语社区风险被低估。

误区四：混淆攻击成功与危害实际发生——需结合后果评估，而非只看模型「说了什么」。

误区五：威胁模型随意设定——不声明攻击者能力，ASR 数字毫无意义。

## 九、演进与趋势

攻击分类从启发式走向体系化（如 JailbreakBench 的 taxonomy）；威胁模型开始纳入多轮、多模态与代理式（agentic）攻击面，评测从单轮文本扩展到工具调用与代码执行。

自动攻击生成器（用 LLM 生成越狱）正与分类法结合，形成「分类→生成→评测→归因」的闭环，使覆盖率可被主动提升而非被动积累。

## 十、小结

威胁模型与攻击分类是越狱评测可信的前提：先明确「谁、用什么能力、攻什么面」，才能用 ASR 等量化指标做可复现对比，并据此排定防御优先级。
