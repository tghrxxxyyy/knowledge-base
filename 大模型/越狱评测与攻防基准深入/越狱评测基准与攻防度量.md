# 越狱评测基准与攻防度量

> 对应 Ouyang 2022 RLHF/InstructGPT 与 Rafailov 2023 DPO。

## 一、背景与挑战
缺少统一基准会导致防御声称无法验证，需要可重复攻击集与评分。

## 二、核心原理
固定攻击语料，对目标模型测量 ASR，并用独立裁判判定是否越界。

## 三、形式化与数学基础
鲁棒准确率：
$ R = 1 - \mathrm{ASR} $

## 四、代码实现
```python
def robustness(prompts, model, judge):
    blocked = sum(1 for p in prompts if judge(model(p)))
    return blocked / len(prompts)
```

## 五、与其他技术对比
自动化基准可回归，但需防攻击集泄漏到训练。

## 六、常见误区
评测集一成不变导致过拟合防御；裁判标准不一致。

## 七、与开源书/权威来源对应
Ouyang 2022 对齐；Rafailov 2023 偏好优化可被攻破。

## 八、面试题
如何防止防御在已知攻击集上过拟合？

## 九、演进与趋势
持续收集新攻击的滚动基准。

## 十、小结
基准的保鲜度决定防御声明的可信度。
