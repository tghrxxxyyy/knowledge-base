# 防御机制与对齐鲁棒性

> 对应 Rafailov 2023 DPO 与 Ouyang 2022 RLHF/InstructGPT。

## 一、背景与挑战
防御要在不损害可用性的前提下抬高攻击成本，需度量效用-安全权衡。

## 二、核心原理
结合系统提示约束、输入过滤、输出护栏与对齐训练提升 refusal 稳健性。

## 三、形式化与数学基础
效用-安全权衡：
$ \mathcal{C} = \alpha \cdot \mathrm{Utility} + (1-\alpha) \cdot R $

## 四、代码实现
```python
def tradeoff(utility, robust, alpha=0.5):
    return alpha * utility + (1 - alpha) * robust
```

## 五、与其他技术对比
训练期对齐更通用，运行期过滤更可控但可绕过。

## 六、常见误区
只追求零 ASR 而崩塌正常能力；防御相互冲突。

## 七、与开源书/权威来源对应
Rafailov 2023 DPO 直接优化偏好；Ouyang 2022 奠定 RLHF。

## 八、面试题
如何量化安全提升带来的效用损失？

## 九、演进与趋势
对抗训练把攻击样本纳入偏好数据。

## 十、小结
防御评测必须同时报告安全与效用。
