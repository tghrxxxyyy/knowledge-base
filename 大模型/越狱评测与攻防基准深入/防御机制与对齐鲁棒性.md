# 防御机制与对齐鲁棒性

> 对应 Rafailov 2023 DPO 直接优化偏好，以及 Ouyang 2022 InstructGPT 奠定的 RLHF 对齐框架。

## 一、背景与挑战

防御越狱不能只追求「拦下所有攻击」，否则会严重损害正常可用性（过度拒绝）。理想防御是在可接受的效用损失下，系统性抬高攻击成本。

因此防御评估必须同时报告「安全性」与「效用」，并以效用-安全权衡为基础做取舍，而非孤立看待 ASR。

只盯安全会制造「什么都不敢说」的模型，只盯效用则形同未防御；二者必须联合优化，并面向真实业务场景定义何为「可接受」。

## 二、核心原理

防御手段分两层：训练期与运行期。训练期通过 RLHF/DPO 把拒绝有害请求的对齐做强，并把红队发现的攻击样本纳入偏好数据（对抗训练）；运行期则叠加系统提示约束、输入过滤（敏感词/困惑度）、输出护栏（分类器拦截）与重试/降级。

两层互补：训练期更通用，运行期更可控但可能被绕过。现代防御强调「纵深」——单层易被击穿，多层叠加才能把攻击成本抬到不划算。

关键要点：

- 防御分训练期（RLHF/DPO + 对抗训练）与运行期（过滤/护栏）。
- 效用-安全权衡要求同时报告安全与效用，而非孤立看 ASR。
- 只追零 ASR 会崩塌正常能力（过度拒绝），真实可用率反而降。
- 多层防御（纵深）比单层更稳健，单层易被针对性击穿。
- 训练期更通用，运行期更可控但可能被混淆绕过。
- 防御需持续迭代，把新攻击样本回流到偏好数据。

## 三、形式化与数学基础

效用-安全权衡目标：

$$
\mathcal{C} = \alpha \cdot \mathrm{Utility} + (1-\alpha) \cdot R
$$

其中 $R$ 为鲁棒性（如 $1-\mathrm{ASR}$），$\alpha\in[0,1]$ 为权重。训练期偏好损失（DPO）为：

$$
\mathcal{L}_{\text{DPO}} = -\mathbb{E}\left[\log\sigma\Big(\beta\log\frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \beta\log\frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)}\Big)\right]
$$

把安全响应 $y_w$ 与越界响应 $y_l$ 纳入，即可在偏好层面提升 refusal 稳健性，同时保留正常能力。

## 四、代码实现

```python
# 效用-安全加权评分（示意）
def tradeoff(utility, robust, alpha=0.5):
    return alpha * utility + (1 - alpha) * robust

# 运行期输入过滤 + 输出护栏
def defend(prompt, model, input_filter, output_guard):
    if input_filter.blocked(prompt):          # 困惑度/敏感词拦截
        return refuse()
    out = model(prompt)
    return out if output_guard.pass_(out) else refuse()
```

## 五、与其他技术对比

| 防御 | 通用性 | 可控性 | 可绕过性 |
|------|--------|--------|----------|
| 训练期对齐 | 高 | 低 | 中 |
| 输入过滤 | 中 | 高 | 高（混淆绕过） |
| 输出护栏 | 中 | 高 | 中 |
| 多层组合 | 高 | 中 | 低 |

单层防御各自有明显短板，组合才能兼顾通用与可控。

## 六、常见误区

误区一：只追求零 ASR——会崩塌正常能力（过度拒绝），真实可用率反而下降。

误区二：防御相互冲突——输入过滤与对齐目标不一致时反而降效，应让各层目标对齐。

误区三：运行期过滤万能——混淆后缀可绕过，须与训练期对齐配合。

误区四：训练一次永久有效——攻击 evolves，需持续迭代，把新样本回流到偏好数据。

误区五：安全与效用可分离优化——二者强耦合，必须联合评估而非各管各的。

## 九、演进与趋势

从「单点护栏」走向「对抗训练 + 多层防御 + 持续回归」；把攻击样本自动回流到偏好数据，使防御与评测在同一个闭环里共同进化。

可证明鲁棒性（如形式化验证 refusal 边界）与自适应防御（按攻击类型动态切换策略）是前沿方向，目标是把安全-效用前沿（Pareto frontier）整体外推。

## 十、小结

防御评测必须同时报告安全与效用，以效用-安全权衡为纲，训练期与运行期多层组合，方能获得可持续的鲁棒性，而非以牺牲可用性为代价换取虚假的安全。
