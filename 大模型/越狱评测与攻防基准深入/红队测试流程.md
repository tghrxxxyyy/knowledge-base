# 红队测试流程

> 对应 Ouyang 2022 RLHF/InstructGPT 与 huggingface/transformers。

## 一、背景与挑战
自动攻击不足以发现语义越狱，需要结构化人工红队流程。

## 二、核心原理
定义目标类别、招募红队成员、记录攻击轨迹、用裁判标注成败并回流数据。

## 三、形式化与数学基础
覆盖率：
$ C = \frac{|\text{tested risk categories}|}{|\text{all categories}|} $

## 四、代码实现
```python
def coverage(tested, total):
    return len(tested) / len(total)
```

## 五、与其他技术对比
人工红队发现长尾，自动攻击规模化，二者互补。

## 六、常见误区
红队只测明显有害；样本不覆盖边缘群体。

## 七、与开源书/权威来源对应
Ouyang 2022 描述红队在人类反馈中的作用；huggingface/transformers 提供实验栈。

## 八、面试题
如何避免红队样本泄露到训练集？

## 九、演进与趋势
人机协作红队与自动发现结合。

## 十、小结
红队是越狱评测中不可替代的定性环节。
