# 红队测试流程

> 对应 Ouyang 2022 InstructGPT 中的人工红队方法，以及 OpenAI GPT-4 System Card 对红队流程的描述。

## 一、背景与挑战

自动化工具有助于规模化发现越狱，但语义层面的对抗（角色扮演、社会工程话术、长上下文诱导）往往超出模板覆盖范围，且模型会随版本迭代不断变化。

仅靠自动攻击会漏掉长尾、隐蔽且依赖语境的失效模式，例如对特定人群的不公平输出、间接诱导的偏见表达。

因此结构化的人工红队（red teaming）仍是越狱评测中不可替代的定性环节——它补充自动化无法捕捉的创造力与边缘群体风险。

人工红队的价值还在于「探索未知攻击面」：人类能基于对世界知识的理解构造出模型设计者未曾预想的绕过方式，这种发散性是当前任何自动化方法难以替代的。

## 二、核心原理

一个成熟的红队流程包含五步：①定义目标风险类别（如非法建议、偏见、泄露）；②招募具有多样背景的红队成员并培训评测准则；③在受控环境中让成员自由或按剧本构造对抗输入，记录完整的攻击轨迹（prompt、模型输出、上下文）；④由独立裁判（人类或模型裁判）标注该次交互是否越界、是否成功；⑤把成功案例连同标签回流到训练/评测集，驱动对齐与防御改进。

关键原则是可复现、可审计、不污染训练集：每一次交互都应能被第三方复现，标注口径需一致，红队样本必须与被测训练集物理隔离。

组织层面，红队通常由独立的安全/对齐团队执行，与被测模型团队「红蓝对抗」，避免自评自测带来的盲区与利益冲突。

## 三、形式化与数学基础

红队对风险空间的覆盖率：

$$
C = \frac{|\mathcal{C}_{\text{tested}}|}{|\mathcal{C}_{\text{all}}|}
$$

其中 $\mathcal{C}$ 为风险类别集合。单次交互的判级由裁判函数给出：

$$
J(x, y) \in \{\text{pass}, \text{fail}, \text{ambiguous}\}
$$

整体红队有效性的抽样估计：在 $N$ 次独立交互中成功越界比例为 $\hat{p}=n_{\text{fail}}/N$，其置信区间由正态近似给出，样本量需满足 $N \ge z^2\hat{p}(1-\hat{p})/e^2$（误差界 $e$）。

当风险类别不均衡时，应按类别分层抽样，使每类的估计误差可控，而非只看总体比例。

## 四、代码实现

```python
# 红队会话记录与覆盖率统计（示意）
def record(session, category, prompt, output, judge):
    verdict = judge(prompt, output)          # pass / fail / ambiguous
    session.append({"cat": category, "p": prompt, "o": output, "v": verdict})
    return verdict

def coverage(sessions, all_categories):
    tested = {s["cat"] for s in sessions}
    return len(tested) / len(all_categories)  # 风险类别覆盖率
```

## 五、与其他技术对比

| 方法 | 规模 | 创造力 | 可复现 | 成本 |
|------|------|--------|--------|------|
| 自动模板攻击 | 大 | 低 | 高 | 低 |
| 自动优化后缀 | 大 | 中 | 高 | 中 |
| 人工红队 | 小 | 高 | 低 | 高 |
| 人机协作 | 中 | 高 | 中 | 中 |

人工红队发现长尾，自动攻击规模化，二者互补：自动负责广度，人工负责深度。

## 六、常见误区

误区一：红队只测明显有害——应覆盖偏见、操纵、泄露等软风险，而非仅关注违法内容。

误区二：样本不覆盖边缘群体——会遗漏对特定人群的不公平失效，导致上线后舆论风险。

误区三：把红队数据直接进训练集——造成数据污染与过拟合，须隔离留存并标记来源。

误区四：一次红队即永久有效——模型迭代后须重复，且攻击手段会随防御演进而变化。

误区五：红队等于「找漏洞越多越好」——应同时评估修复成本与真实危害，避免噪声淹没信号。

## 九、演进与趋势

从「自由探索」走向「目标类别驱动 + 模型辅助生成攻击 + 人类裁决」的人机协作；红队平台将攻击库、裁判与回归测试打通，使定性发现可沉淀为可回归的定量基准。

合成红队（用更强的模型自动生成攻击草稿，人类只做筛选与裁决）正成为降本增效的主流方向，并逐步与自动化攻防循环融合。

评测维度也从「是否越界」细化为「危害等级、可逆性、受众规模」的多维评分，使红队结论更可操作。

## 十、小结

红队是越狱评测中不可替代的定性环节，其价值在于发现自动工具遗漏的长尾与语境化失效，并以前置隔离的数据回流持续强化对齐，是防御闭环中「人」这一关键变量的落地形式。
