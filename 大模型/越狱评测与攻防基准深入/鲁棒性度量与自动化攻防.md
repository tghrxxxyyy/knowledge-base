# 鲁棒性度量与自动化攻防

> 对应 Rafailov 2023 DPO 与 Ouyang 2022 RLHF/InstructGPT。

## 一、背景与挑战
攻防是持续博弈，需要可自动运行的鲁棒性回归与告警。

## 二、核心原理
把攻击生成、目标推理、裁判评分串成循环，每日回归并报告 ASR 漂移。

## 三、形式化与数学基础
ASR 漂移：
$ \Delta = \mathrm{ASR}_{t} - \mathrm{ASR}_{t-1} $

## 四、代码实现
```python
def drift(asr_now, asr_prev):
    return asr_now - asr_prev
```

## 五、与其他技术对比
自动攻防可高频，但需防攻击库污染评测。

## 六、常见误区
只看均值忽略最坏类别；未对误报做人工复核。

## 七、与开源书/权威来源对应
Rafailov 2023 DPO 鲁棒性；Ouyang 2022 对齐框架。

## 八、面试题
如何设定 ASR 回归的告警阈值？

## 九、演进与趋势
攻防即服务与持续红队平台。

## 十、小结
鲁棒性度量应进入日常 CI 而非一次性报告。
