# 提示注入与对抗后缀

> 对应 Ouyang 2022 RLHF/InstructGPT 与 huggingface/transformers。

## 一、背景与挑战
攻击者在正常指令后追加覆盖性语句，或在 token 级追加难读后缀以绕过护栏。

## 二、核心原理
提示注入利用指令优先级混淆；对抗后缀通过梯度优化使 refusal 分布塌陷。

## 三、形式化与数学基础
后缀优化目标：
$ \delta^* = \arg\min_\delta \mathcal{L}(\text{model}(x+\delta), y_{\text{harmful}}) $

## 四、代码实现
```python
def search_suffix(model, x, y, iters=50):
    # 简化: 基于梯度逼近有害后缀
    best = ''
    for _ in range(iters):
        cand = model.grad_step(x, y)
        best = cand
    return best
```

## 五、与其他技术对比
手工注入易检测，优化后缀更隐蔽但需白盒访问。

## 六、常见误区
只测英文后缀；忽略解码参数对成功率影响。

## 七、与开源书/权威来源对应
Ouyang 2022 对齐训练；huggingface/transformers 提供攻击实验基座。

## 八、面试题
为何对抗后缀常不可读却有效？

## 九、演进与趋势
自适应防御对后缀做困惑度过滤。

## 十、小结
两类攻击分别考验语义与统计层面的鲁棒性。
