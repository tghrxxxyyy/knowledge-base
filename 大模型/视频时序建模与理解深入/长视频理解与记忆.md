# 长视频理解与记忆

> 对应 长视频语言模型研究（如 Song et al. 2024 「MovieChat」、长上下文视频 LLM）及记忆机制。

## 一、背景与挑战

电影级长视频含数千帧、多事件、跨场景，远超 LLM 上下文。如何在有限 token  budget 下保持长程一致性、因果与情节记忆，是视频 LLM 前沿难题。

## 二、核心原理

常用分层策略：先分段提特征，再用记忆模块（如可更新状态、摘要 token、检索缓存）跨段聚合。在线方法维护紧凑记忆向量，离线方法先全局摘要再细读。也用长上下文（如 32k/100k）直接喂压缩帧。

## 三、数学形式

分段表征 h_i = E(seg_i)，记忆更新：
m_t = \mathrm{GRU}(m_{t-1}, h_t)\ \text{或}\ m_t = \mathrm{Attn}(q, [m_{t-1}; h_t])
最终回答 y = \mathrm{LLM}(m_T, q)。检索式从缓存 R 取相关段：
r = \mathrm{TopK}_{s\in R}\,\mathrm{sim}(q, s)。

## 四、代码实现

```python
import torch

class MemoryBank:
    def __init__(self, cap=64):
        self.bank = []
        self.cap = cap
    def update(self, h):
        self.bank.append(h)
        if len(self.bank) > self.cap:
            self.bank.pop(0)
    def context(self):
        return torch.stack(self.bank)
```

## 五、与其他对比

相比均匀采样丢长程，记忆法保一致性；相比全帧超长上下文，成本低；检索式可精准取片段但需索引。各法常组合使用。

## 六、常见误区

直接用长上下文忽略压缩损失；记忆无遗忘致噪声累积；分段边界割裂事件；混淆情节记忆与帧特征。

## 八、面试题

- Q：长视频核心难点？答：超长序列、跨段一致性与记忆。
- Q：记忆机制有哪些？答：状态更新、摘要 token、检索缓存。
- Q：为何不直接长上下文？答：成本与压缩损失，仍需聚合。

## 九、演进

从采样到分层记忆；从固定到可学习检索；与 agent 式多轮观察结合。

## 十、小结

长视频理解依赖分段表征与记忆/检索机制，在有限上下文内维持长程一致，是视频大模型走向真实场景的关键。
