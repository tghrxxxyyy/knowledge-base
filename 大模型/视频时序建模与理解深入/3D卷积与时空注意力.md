# 3D卷积与时空注意力

> 对应 Tran et al. 2018 「R(2+1)D」及 视频建模中 3D Conv 与 Transformer 的比较研究。

## 一、背景与挑战

3D 卷积天然捕获时空局部模式，但感受野有限、参数大。时空注意力可建模长程依赖但数据需求高。二者如何取舍与组合，是视频骨干设计的核心权衡。

## 二、核心原理

I3D 把 2D 卷积核扩展为 3D；R(2+1)D 将 3D 卷积拆为空间 2D + 时间 1D，降低参数量并增强非线性。时空注意力（如 ViViT）则显式建模长程。混合架构常以 3D 卷积做底层特征、注意力做高层交互。

## 三、数学形式

3D 卷积：y_{t,x,y}=\sum_{k,l,m} w_{k,l,m}\,x_{t+k,x+l,y+m}。R(2+1)D 分解：
\mathcal{C}_{3D} = \mathcal{C}_{1D}^{time} \circ \mathcal{C}_{2D}^{space}
其参数量由 d\cdot d\cdot t 降为 d\cdot d + t，且中间加非线性。

## 四、代码实现

```python
import torch.nn as nn

class R2Plus1D(nn.Module):
    def __init__(self, c_in, c_out):
        super().__init__()
        self.spatial = nn.Conv3d(c_in, c_out, (1,3,3), padding=(0,1,1))
        self.temporal= nn.Conv3d(c_out, c_out, (3,1,1), padding=(1,0,0))
    def forward(self, x):
        return self.temporal(self.spatial(x))
```

## 五、与其他对比

相比纯 3D Conv，R(2+1)D 更高效；相比纯注意力，卷积归纳偏置强、小数据更稳；混合网络兼顾局部与全局。工业视频分类多用卷积，理解推理渐转 Transformer。

## 六、常见误区

以为 3D 卷积能抓长程，实则感受野有限；混淆 (2+1)D 与伪 3D；忽略时间维 stride 对帧率影响；盲目堆叠致显存爆炸。

## 八、面试题

- Q：R(2+1)D 优势？答：分解 3D 卷积，省参增非线性。
- Q：卷积 vs 注意力？答：卷积局部偏置强、稳；注意力强全局但数据渴。
- Q：何时用 3D 卷积？答：短片段分类、数据有限时。

## 九、演进

从 C3D/I3D 到 R(2+1)D、SlowFast；再到 VideoMAE 纯注意力；混合骨干流行。

## 十、小结

3D 卷积与时空注意力各有适用边界，理解其归纳偏置与计算特性，是设计高效视频理解骨干的基础。
