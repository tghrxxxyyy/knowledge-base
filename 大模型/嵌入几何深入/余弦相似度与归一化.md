# 余弦相似度与归一化

> 对应 d2l-zh；检索与对齐常用；Radford et al., *CLIP*, 2021。

## 一、背景与挑战

向量模长常含无关信息（如句长），用模长比角度更稳定。

## 二、核心原理

余弦相似度只比方向：
```
cos(a,b) = a·b / (||a||·||b||)
```
CLIP 等把图像/文本编码 L2 归一化后做点积即余弦，再用温度缩放对比。归一化消除模长偏置，使相似度落在 [-1,1]。

## 三、数学形式

见上；归一化 `a = a/||a||`。

## 五、关键要点

- 检索/匹配场景几乎都用余弦。
- 未归一化点积会被模长主导。

## 六、与其他对比

- 欧氏含模长；余弦只方向。

## 七、常见误区

- 直接点积当相似——模长噪声大。
