# 嵌入空间几何

> 对应 d2l-zh 表征学习章；Mikolov et al., *word2vec*, 2013；Wang & Isola, *Understanding Contrastive*, 2020。

## 一、背景与挑战

嵌入把离散对象映射为连续向量，其几何结构决定下游可用性。

## 二、核心原理

良好嵌入空间应满足：语义相近点欧氏/余弦距离近；类间可分；各向同性（非塌缩到窄锥）。对比学习用「对齐-均匀性」双指标刻画：对齐（正例对距离小）、均匀（全体在球面上分布均匀）。

## 三、数学形式

对齐 `A = E[||f(x)-f(x')||²]`；均匀性 `U = log E[e^{-2||f(x)-f(y)||}]`（见自监督章）。

## 四、代码实现

```python
sim = F.cosine_similarity(z1, z2)
```

## 五、关键要点

- 各向异性（anisotropy）会使余弦相似度失真，需白化/归一化。
- 维度过高易稀疏，需降维可视化验证。

## 六、与其他对比

- 语义空间非欧几何也可用（双曲线嵌入层级）。

## 七、常见误区

- 距离近=相关——需先确认度量合理。
