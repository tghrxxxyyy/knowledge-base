# 表征解耦

> 对应 β-VAE（Higgins et al., 2017）；Bengio et al., *disentanglement*, 2013。

## 一、背景与挑战

表征各维度若混叠语义，迁移与可解释性差。

## 二、核心原理

解耦（disentanglement）希望每个潜在维度对应一个独立可解释因子（如颜色/形状/姿态）。β-VAE 通过加大 KL 权重 β 强制潜空间各维独立。

## 三、数学形式

β-VAE 目标：`L = E[log p(x|z)] - β·KL(q(z|x)‖p(z))`，β>1 促解耦。

## 四、代码实现

```python
loss = recon - beta * kl(mu, logvar)
```

## 五、关键要点

- 完全解耦难以保证，常是部分解耦。
- 解耦有利迁移与生成控制。

## 六、与其他对比

- 普通 VAE 不强制解耦。

## 七、常见误区

- 解耦必可解释——需验证。
