# 多语言数据配比

> 对应 Chung et al. 2024 "Scaling Instructions to 100+ Languages" 与 multilingual LLM 研究。

## 一、背景与挑战

多语言预训练需平衡高资源(英、汉)与低资源语言。英数据占优会压制其他语言能力，配比不当导致低资源语言坍塌。

## 二、核心原理

常用“温度采样”平滑语言频率：$q_\ell \propto (p_\ell^{nat})^\alpha$。并通过冻结/解冻策略或词汇表扩展保护低资源语言表示。

## 三、数学形式

语言 $\ell$ 采样权重：

$$
q_\ell = \frac{(p_\ell^{nat})^\alpha}{\sum_{\ell'}(p_{\ell'}^{nat})^\alpha}
$$

低资源语言还可通过过采样系数 $r_\ell>1$ 提升：

$$
\tilde{q}_\ell = \frac{r_\ell q_\ell}{\sum_{\ell'} r_{\ell'} q_{\ell'}}
$$

## 四、代码实现

```python
import torch

def lang_mix(p_nat, alpha=0.3, r=None):
    q = torch.tensor(p_nat).pow(alpha)
    if r is not None:
        q = q * torch.tensor(r)
    return (q / q.sum()).tolist()
```

## 五、与其他对比

与单语领域配比类似，但需额外考虑语言代表性坍塌与分词效率(高资源语言 token 更短)。

## 六、常见误区

误区：单纯均匀分配各语言。忽视各语言数据质量与 token 效率差异。

## 八、面试题

- Q：低资源语言如何保护？答：过采样+词汇扩展+可能冻结共享层。
- Q：$\alpha$ 在多语言作用？答：压缩高资源语言占比，抬升低资源。
