# 配比消融与下游评估

> 对应 Gao et al. 2020 "The Pile" 与各大模型数据消融研究。

## 一、背景与挑战

领域权重的微小变化可能显著改变下游能力。如何系统性消融并归因是工程实践难点。

## 二、核心原理

控制变量法：固定其他域，单域权重扫描，记录下游多基准(代码、推理、知识)变化。用数据混合定律拟合敏感度。

## 三、数学形式

对域 $d$ 权重 $q_d$ 的敏感度：

$$
s_d = \frac{\partial \mathcal{L}_{down}}{\partial \log q_d}
$$

若 $s_d>0$ 表示增大该域降低损失(有益)，反之抑制。

## 四、代码实现

```python
def sensitivity(losses, weights):
    import numpy as np
    return np.polyfit(np.log(weights), losses, 1)[0]
```

## 五、与其他对比

相比一次性设定权重，系统性消融能定位“关键域”，避免盲调。

## 六、常见误区

误区：只在单一基准评估。不同基准对配比敏感度方向相反，需多任务权衡。

## 八、面试题

- Q：如何评估配比好坏？答：多下游基准 + 敏感度分析 + 训练曲线。
- Q：为何要扫描而非一次性？答：域间存在权衡，扫描定位帕累托前沿。

## 九、演进

用代理模型预测配比-性能曲面，减少全量训练消融成本。

## 十、小结

配比需以量化消融闭环验证，敏感度分析是指引调参的罗盘。
