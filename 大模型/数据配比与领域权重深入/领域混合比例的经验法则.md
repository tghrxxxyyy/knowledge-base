# 领域混合比例的经验法则

> 对应 Gao et al. 2020 "The Pile: An 800GB Dataset of Diverse Texts", NeurIPS 2020。

## 一、背景与挑战

预训练语料的领域构成(网页、书籍、代码、学术)强烈影响下游能力。如何设定各域权重缺乏统一理论，多依赖经验。

## 二、核心原理

经验法则：(1) 高频通用域(网页)提供语言基础但易冗余；(2) 代码/数学域虽占比小却显著提升推理；(3) 领域权重应与下游任务分布匹配而非与语料自然分布一致。

## 三、数学形式

设域 $d$ 权重 $q_d$，训练步数为 $T$，则域 $d$ 采样概率：

$$
P(d) = \frac{q_d}{\sum_{d'} q_{d'}}
$$

自然分布权重为 $p_d^{nat}$，经验上常对高质量域上采样：

$$
q_d = (p_d^{nat})^\alpha, \quad \alpha<1
$$

$\alpha$ 越小越平滑(接近均匀)。

## 四、代码实现

```python
import torch

def smooth_weights(p_nat, alpha=0.3):
    q = torch.tensor(p_nat).pow(alpha)
    return (q / q.sum()).tolist()
```

## 五、与其他对比

与 DoReMi 自动优化相比，经验法则无需训练代理模型，但需大量人工消融。

## 六、常见误区

误区：直接按自然出现频率配比，导致高质量稀缺域被淹没。

## 八、面试题

- Q：为何代码域占比小却重要？答：代码提升结构化推理与符号能力，边际收益高。
- Q：$\alpha<1$ 的作用？答：平滑自然分布，避免长尾域被忽略。

## 九、演进

从经验法则到数据驱动优化(DoReMi)、再生混合(regenerative mixtures)。

## 十、小结

领域配比需兼顾覆盖与质量，经验法则是起点，自动优化是方向。
