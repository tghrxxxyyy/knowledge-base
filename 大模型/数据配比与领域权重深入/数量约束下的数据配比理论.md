# 数量约束下的数据配比理论

> 对应 Muennighoff et al. 2023 "Scaling Data-Constrained Language Models", NeurIPS 2023。

## 一、背景与挑战

当可用数据总量有限(数据受限 regime)，单纯增加 epoch 会过拟合，但合理重复高质量数据可提升表现。需要理论指导“重复什么、重复多少”。

## 二、核心原理

在数据受限下，重复高质量数据(高困惑度过滤后的难样本)比重复全部数据更有效。存在一个最优重复倍率，超过后边际收益递减并转向过拟合。

## 三、数学形式

设每样本重复 $r$ 次，有效训练量 $N_{eff}=rN$。损失随 $r$ 的经验规律：

$$
\mathcal{L}(r) \approx a \log(rN) + b - c\cdot\max(0, r-r^\star)^2
$$

$a$ 为学习收益系数，$c$ 为过拟合惩罚，$r^\star$ 为最优重复。

## 四、代码实现

```python
def eff_loss(r, N, a, b, c, rstar):
    return a * (r * N).bit_length() + b - c * max(0, r - rstar) ** 2
```

## 五、与其他对比

数据丰富时配比关注领域覆盖；数据受限时配比关注“重复高质数据”而非广度。

## 六、常见误区

误区：数据受限就疯狂重复。需上限，且优先重复经质量过滤的子集。

## 八、面试题

- Q：数据受限最优策略？答：过滤+重复高质量数据，设重复上限。
- Q：重复为何有过拟合拐点？答：分布被局部样本主导，泛化下降。

## 九、演进

从经验重复到“数据混合定律”(data mixing laws)预测不同配比的 scaling 行为。

## 十、小结

数据受限下“质重于量”，重复策略需量化收益与过拟合平衡。
