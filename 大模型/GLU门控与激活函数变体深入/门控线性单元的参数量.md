# 门控线性单元的参数量

> 对应 LLaMA、PaLM 配置文件。

## 一、背景与挑战
GLU 类 FFN 相比 ReLU FFN 多一个 $W$ 矩阵，参数量增加约 50%。如何在保持效果同时控制参数量？

## 二、核心原理
LLaMA 的做法：把 $d_\text{ffn}$ 从 $4d$ 缩到 $\frac{8d}{3}$（约 $2.67d$），保持总参数量与 ReLU FFN 相当。SwiGLU 的有效参数：$3 \cdot d \cdot d_\text{ffn} = 3 \cdot d \cdot 8d/3 = 8d^2$，与 ReLU 的 $2 \cdot d \cdot 4d = 8d^2$ 一致。

## 三、形式化与数学基础
参数对比：ReLU FFN $2 d d_\text{ffn}$，SwiGLU $3 d d_\text{ffn}$。为保持参数量 $8d^2$，$d_\text{ffn}$ 选 $8d/3$。

## 四、代码实现
```python
# LLaMA 风格
d = 4096
d_ff = int(d * 8 / 3)  # 10922，向上取整到 64 倍数
d_ff = ((d_ff + 63) // 64) * 64
```

## 五、与其他技术对比
- vs ReLU：SwiGLU 参数多 50%，但 $d_\text{ffn}$ 可缩小补偿。
- vs GELU：参数差异相同。

## 六、常见误区
- 不缩 $d_\text{ffn}$ 会让模型参数膨胀。
- 缩太小效果下降。

## 七、与开源书/权威来源对应
- meta-llama/llama `model.py`。
- google-research/gemma 配置。

## 八、面试题
- LLaMA $d_\text{ffn}=8d/3$ 怎么来的？答：保持与 ReLU FFN 同等参数量下的最优点。

## 九、演进与趋势
ReLU $4d$ → GELU $4d$ → SwiGLU $8d/3$。

## 十、小结
门控 FFN 需配合 $d_\text{ffn}$ 缩放以保持参数与 ReLU FFN 相当。
