# 门控与稀疏激活的关系

> 对应 Shazeer 2020 与 Mixture-of-Experts 综述。

## 一、背景与挑战
GLU 的 sigmoid 门控输出在 $(0,1)$，看似连续但接近 0 或 1 时实际近似二值。这与稀疏激活有内在联系。

## 二、核心原理
当 $|W_2 x|$ 很大时，$\sigma(W_2 x)$ 接近 0 或 1，GLU 退化为"通过"或"关闭"的二值门。训练中常观察到大量神经元进入饱和态。

## 三、形式化与数学基础
设门控值 $g = \sigma(W_2 x)$，当 $W_2 x > 4$ 时 $g > 0.99$，当 $W_2 x < -4$ 时 $g < 0.01$。这些神经元对当前输入贡献接近 0 或完全贡献，形成隐式稀疏。

## 四、代码实现
```python
# 监控门控激活分布
gates = torch.sigmoid(Wb @ x)
print(f'g<0.01 ratio: {(gates<0.01).float().mean():.3f}')
print(f'g>0.99 ratio: {(gates>0.99).float().mean():.3f}')
```

## 五、与其他技术对比
- vs ReLU：ReLU 是显式稀疏（$g \in \{0, x\}$），GLU 是隐式稀疏。
- vs MoE：MoE 是 token 级路由稀疏，GLU 是特征级门控稀疏。

## 六、常见误区
- 误以为 GLU 总是密集激活；实际大量门控值接近 0。
- 训练初期门控值集中在 0.5 附近（随机初始化），需训练后才能看到稀疏。

## 八、面试题
- GLU 与 MoE 的稀疏有何不同？答：GLU 是逐元素门控，MoE 是逐 token 路由。

## 九、演进与趋势
ReLU 显式稀疏 → GLU 隐式稀疏 → MoE 路由稀疏。

## 十、小结
GLU 的 sigmoid 门控在训练后趋于二值化，形成隐式稀疏激活，是其参数效率的关键。
