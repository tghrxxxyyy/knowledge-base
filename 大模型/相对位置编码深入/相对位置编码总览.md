# 相对位置编码总览

> 对应 Shaw, Uszkoreit, Vaswani, *Self-Attention with Relative Position Representations*, 2018；Dai et al., *Transformer-XL*, 2019。

## 一、背景与挑战

绝对位置编码把位置信息绑死到固定索引，难以表达“两个 token 的相对距离”这一更本质的语序信号，且对更长测试序列的外推差。

## 二、核心原理

相对位置编码不在输入嵌入加位置向量，而是在注意力打分阶段注入“键/查询之间的偏移 $i-j$”的偏置或可学习向量，使模型感知相对距离而非绝对索引。

## 三、数学形式

打分中加入偏置项 $e_{ij}=x_iW_Q(x_jW_K+r_{i-j})^T/\sqrt d$，其中 $r_{i-j}$ 是相对距离 $i-j$ 的表示（可裁剪到上限 $k$）。

## 四、代码实现

```python
rel = relative_embeddings(clamp(i - j, -k, k))   # (n, n, d)
scores = q @ k.transpose(-1,-2) / d**0.5 + rel_bias(i, j)
```

## 五、与其他对比

- 与 绝对位置编码深入 对照：一个注入到分数、一个注入到输入。
- 与 RoPE（见下）相比，此类是“加性偏置”，RoPE 是“旋转乘法”。

## 六、常见误区

- 认为相对编码能自动获得长度外推；仍需裁剪或专门外推手段。
- 把相对距离表与绝对位置表混用致重复编码。

## 八、面试题

- 相对位置编码相比绝对有何优势？答：直接建模 token 间距离，更贴合语序本质，且对偏移更鲁棒。

## 九、演进

绝对正弦/可学习 → Shaw 相对偏置 → Transformer-XL 分桶 → T5 相对偏置 → RoPE。

## 十、小结

相对位置编码把位置信息移到注意力分数中，是后续 RoPE、ALiBi 等现代方案的思想源头。
