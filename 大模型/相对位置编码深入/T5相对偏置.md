# T5 相对位置偏置

> 对应 Raffel et al., *Exploring the Limits of Transfer Learning with a Unified Text-to-Text Transformer (T5)*, 2019。

## 一、背景与挑战

T5 希望对多种任务统一建模，且避免绝对位置带来的外推与任务间不一致。

## 二、核心原理

T5 完全去掉绝对位置嵌入，改为在每层自注意力的分数上加一个“相对位置偏置” $B_{i,j}$（从一张可学习表中查 $i-j$ 得到，距离超 $k$ 归入同一桶），该偏置跨所有层共享、不进入值聚合。

## 三、数学形式

$A_{i,j}= \frac{q_i k_j^T}{\sqrt d} + B_{i-j}$，$B$ 是裁剪后相对距离的查表标量；编码器与解码器各用一张表。

## 四、代码实现

```python
rel = self.rel_bias[clamp(i - j, -k, k)]      # (n, n) 标量偏置
scores = (q @ k.transpose(-1,-2)) / d**0.5 + rel
```

## 五、与其他对比

- 与 Shaw 2018 相比，T5 偏置是标量、不加在值侧、全层共享。
- 与 RoPE 相比，T5 是加性标量偏置，RoPE 是旋转乘法。

## 六、常见误区

- 误以为 T5 无位置信息；位置以偏置形式存在分数里。
- 跨层共享偏置表若随机初始化不当会拖慢收敛。

## 七、与开源书对应

- harvardnlp/annotated-transformer：https://github.com/harvardnlp/annotated-transformer

## 八、面试题

- T5 如何编码位置？答：不加位置嵌入，而在注意力分数加可学习的相对距离偏置表。

## 九、演进

Shaw 向量偏置 → T5 标量共享偏置 → 被广泛沿用（如 T5/UL2）。

## 十、小结

T5 的相对偏置简洁高效，证明了“无输入位置嵌入 + 分数偏置”足以承载语序。
