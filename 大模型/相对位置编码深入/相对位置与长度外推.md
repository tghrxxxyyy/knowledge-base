# 相对位置与长度外推

> 对应 Chen et al., *Extending Context Window of LLMs via Positional Interpolation (PI)*, 2023；以及 NTK-aware 缩放讨论。

## 一、背景与挑战

用相对编码的模型在训练长度外推理时，位置旋转/偏置超出见过范围，注意力退化。

## 二、核心原理

相对编码外推有两类思路：(1) 放大位置频率（NTK-aware scaling）使长序列落在训练分布的扩展区间；(2) 位置插值 PI 把测试位置 $[0,L']$ 线性压缩到训练区间 $[0,L]$，直接落在已训练范围。

## 三、数学形式

PI：测试时用 $R'_{m}=R_{m\cdot L/L'}$（位置除以缩放 $s=L'/L$）；NTK 则对频率 $\theta_i$ 做维度和缩放融合而非简单压缩。

## 四、代码实现

```python
def rope_extend(x, scale=4.0, base=10000.0):
    inv = 1.0 / (base ** (torch.arange(0, dim, 2) / dim)) / scale  # PI 压缩
    ang = torch.outer(torch.arange(x.shape[-2]), inv)
    return apply_rotary(x, torch.cos(ang), torch.sin(ang))
```

## 五、与其他对比

- 与 无限上下文深入（PI/ALiBi）共享同一主题。
- 与 绝对位置编码深入 的外推局限对照。

## 六、常见误区

- 简单外推不重训易致困惑度飙升。
- PI 过度压缩会损失局部精细位置区分。

## 八、面试题

- 位置插值为何能扩展上下文？答：把更长的位置区间压缩回模型已训练的范围，避免超出分布。

## 九、演进

直接外推 → NTK-aware → 位置插值(PI) → 动态 NTK。

## 十、小结

相对编码虽利于外推，但仍需频率缩放/插值才能在远超训练长度时保持质量。
