# 提示缓存命中与计费

> 对应各厂商缓存计费说明（Anthropic/OpenAI）；推理经济成本深入 衔接。

## 一、背景与挑战

需量化命中收益，避免误用反而更贵。

## 二、核心原理

缓存写（miss）按全价且可能收写入费；命中按折扣价（常为 1/10）。只有重复前缀占比高才划算。

## 三、数学形式

单位请求节省 $S = (1-\alpha)C_{full} - \alpha C_{write}$，其中 $\alpha$ 命中率；$\alpha$ 高时 $S>0$。

## 四、代码实现

```python
cost = miss_cnt*C_write + hit_cnt*C_hit + new_tokens*C_gen
```

## 五、与其他对比

- 与 语义缓存深入（命中省整次生成）成本结构不同。
- 与 推理调度深入（批处理）互补降本。

## 六、常见误区

- 低重复场景开缓存反增写入费。
- 忽视 TTL 内未复用即浪费写入成本。

## 八、面试题

- 何时开提示缓存亏？答：前缀重复率低或 TTL 内未复用时，写入费超过命中省下的钱。

## 九、演进

全价 → 命中折扣 → 分层计费。

## 十、小结

提示缓存收益取决于命中率，高重复前缀才显著降本。
