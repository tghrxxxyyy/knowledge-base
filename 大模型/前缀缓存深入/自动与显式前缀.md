# 自动与显式前缀缓存

> 对应 vLLM APC vs SGLang 显式；提示缓存深入（显式）对照。

## 一、背景与挑战

缓存可全自动（按哈希）或显式（标断点），各有适用。

## 二、核心原理

自动：引擎对所有前缀做哈希匹配，零侵入但受块对齐影响。显式：用户声明缓存边界，命中更可控但需改代码。

## 三、数学形式

匹配粒度：自动按块 $B$ token（如 16）对齐；显式按 token 精确前缀 $P$。

## 四、代码实现

```python
# SGLang 显式
with sg.lang() as s:
    s.system("你是有用助手")  # 自动作为前缀缓存
```

## 五、与其他对比

- 与 提示缓存深入（API 显式）对应。
- 与 推理调度深入（调度共享）互补。

## 六、常见误区

- 自动缓存因块不对齐降共享率。
- 显式边界标错致命中失败。

## 七、与开源书对应

## 八、面试题

- 自动与显式前缀缓存区别？答：自动按哈希零侵入、受块对齐影响；显式可控但需标注。

## 九、演进

显式 → 自动 → 混合（自动+提示边界）。

## 十、小结

前缀缓存有自动与显式两类，按控制力与侵入性权衡选择。
