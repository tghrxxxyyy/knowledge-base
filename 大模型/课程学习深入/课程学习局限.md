# 课程学习局限

> 对应 Bengio et al., *Curriculum Learning* (ICML 2009, arXiv:0907.4060)、Kumar et al., *Self-Paced Learning* (NIPS 2012)、Kervadec et al., *Learning for Everything* (PMLR 2019)，以及数据质量侧的 DoReMi (arXiv:2305.10428)、DataComp-LM (github.com/mlfoundations/dclm-baseline)、FineWeb (github.com/huggingface/fineweb)；关联篇章「课程学习原理」「数据配比」「预训练数据清洗」「课程与自步学习」。

## 一、背景与挑战

课程学习（curriculum learning）沿用人类「由易到难」的直觉：先让模型看简单、干净、高置信的样本，再逐步引入困难样本，期望获得更优的泛化与更稳的优化。Bengio et al. 2009 的原始论证是「合理难度排序可以避免早期被病态样本带偏，逐步收紧到更精细的解」。但在实践中，这条假设反复受到挑战：NLP 任务里按句子长度排课程经常**输给随机采样**；机器翻译研究发现课程带来的收益在调好基线后消失；CV 任务上「难度」的定义稍变（loss 排序 vs 置信度排序 vs 长度排序），结论就翻转。

核心挑战有三层。第一，**easy-to-hard 假设有明确的失效场景**：当简单样本无法表征最终决策边界（例如简单样本全是模板化正例、难样本才包含判别性信息）、或损失曲面不存在「由粗到精」的层级结构时，课程反而让模型长期困在简单样本的局部解里，难样本被系统性延后甚至永久忽视。第二，**难度度量本身有偏**：难度是主观构造的（模型置信度、loss、长度、图节点数……），而置信度高的样本未必「基础」——可能是标签泄漏、短路特征或分布偏斜造成的「假简单」，按它排课等于放大偏差。第三，**机会成本与调参负担**：课程引入了排序策略、进度函数（pace function）、起止阈值等额外超参，在同等算力下，把调课程的精力花在数据清洗、配比与学习率上往往收益更高——这正是预训练时代「curated data」路线压过「curriculum trick」的深层原因。

## 二、核心原理

### 2.1 easy-to-hard 假设的失效场景

- **判别信息集中在难样本**：如长尾类别、罕见实体、负例构造复杂的任务，简单样本上模型早就 100% 正确，继续喂只会造成分布偏斜；排序把最有信息量的样本推到训练末期，等价于减少了它们的有效曝光步数。
- **难度与「有用性」不相关甚至负相关**：语音、部分图像分类中，「难」样本可能就是噪声/标注错误，按难度递进等于**故意把训练后期的容量分配给噪声**——此时 curriculum 变成 anti-curriculum。
- **优化器与课程的交互**：Adam 等自适应优化器对梯度尺度不敏感，简单样本主导早期带来的「稳态惯性」比 SGD 时代更强；课程的「热身」收益被 warmup 学习率调度部分替代，两者冗余。
- **预算受限**：课程要走完排序 + 进度曲线，在固定 epoch 下难样本只见得更少；若训练足够久（epoch → ∞），采样顺序的边际收益趋近于 0，很多论文的「课程收益」其实来自更早收敛而非更好的最终解。

### 2.2 难度度量偏差

常见度量及其陷阱：**模型当前 loss / 置信度**——初始置信度高可能因为样本短、标签先验强或存在 spurious cue，perceptual 「简单」≠ 任务基础；**长度 / 尺寸**——与真实难度弱相关，且长度排序会改变批次的计算特征（padding、吞吐）；**人类标注难度**——成本高、不可扩展到预训练规模；**外部模型打分**——引入教师偏差，教师不会的领域整段被判为「难」。此外难度是**动态的**：随训练推进，昨天的难样本今天已变简单，静态排序在后期会失真。因此任何课程上线前都必须做「排序策略 vs 随机」的 A/B，并监控难样本的最终覆盖率。

### 2.3 与预训练数据配比 / curated data 的关系

大模型预训练几乎放弃了「逐 step 排序」式的课程，转向**数据质量与配比**（mixture weighting）路线，两者容易混淆：

- **课程学习**是训练**过程**的调度：什么顺序、什么时刻看什么，本质是 time-varying 的采样分布 $p_t(x)$。
- **配比 / curated data** 是训练**分布**的设计：DoReMi、DataComp-LM、FineWeb-Edu 用代理模型或质量分类器决定各域的静态权重与过滤阈值，优化的是 $p(x)$ 的整体形状，与时刻无关。

实践证据偏向后者：FineWeb-Edu、DCLM 的经验是「筛掉坏数据 + 调好域配比」的收益远大于任何排序技巧；Nemotron/RedPajama 等工作同样把功夫花在去重、质量打分与域混合上。课程思想留下的真正遗产被吸收为**自步学习（self-paced learning）**与**curriculum by uncertainty filtering**：不预设人类排序，而是让模型自己按置信度在线选择样本，并配以「必须覆盖难样本」的约束——这比手工课程更鲁棒，因为它把排序从先验变成了与训练状态联动的反馈控制。

### 2.4 实证批评的要点

对课程学习的批评集中在方法论上：(1) 许多「课程有效」的结论来自**弱基线**——没调随机采样的 batch size、warmup 与数据清洗，基线一强收益即归零；(2) 消融常缺**同等算力对照**，课程方法实际多跑了或早停更久；(3) 可重复性差——排序与进度函数的超参敏感，换随机种子结论就抖动；(4) 外部效度有限——在小模型/合成数据上的收益不能外推到 LLM 预训练。正确的态度不是「课程无用」，而是：**课程是一种需要被验证的归纳偏置（inductive bias），不是免费的正则**；数据分布与质量的收益（curated data）优先级高于采样顺序，顺序调度只在分布固定、预算受限、且已通过 A/B 证明有效时才引入。

## 三、形式化与数学基础

课程学习把经验风险改造为随时间变化的加权风险。设难度度量 $d(x)$、进度函数 $v: [0,1] \to \mathbb{R}$（随训练步 $t/T$ 单调上升，控制已解锁样本的难度上限），则第 $t$ 步的采样分布为：

$$p_t(x) \propto \mathbb{1}\big[d(x) \le v(t/T)\big], \quad \mathcal{L}_t(\theta) = \mathbb{E}_{x \sim p_t}[\ell(\theta; x)]$$

课程的全部超参都藏在 $d(\cdot)$ 与 $v(\cdot)$ 里——这也是其脆弱性的来源：$d$ 排错方向或 $v$ 推进过快/过慢，$\mathcal{L}_t$ 的优化轨迹就偏离随机采样的无偏估计。自步学习把硬指示换成软权重的优化内生选择：

$$\min_{\theta, \mathbf{w}} \sum_{i=1}^{N} w_i \ell(\theta; x_i) + \lambda \sum_{i=1}^{N} w_i, \quad w_i \in [0,1]$$

$\lambda$ 控制「易样本优先」的强度；当 $\lambda \to \infty$ 时退化为只学最易样本（需配覆盖约束防饿死难样本）。对「课程收益消失」的形式化直觉：若训练充分（$T \to \infty$）且优化器能遍历全部样本，任意只是重排采样序列的课程不改变收敛解的期望，收益仅来自有限步预算下的优化路径差异——因此在大算力、多 epoch 的预训练里，课程的边际价值天然趋零。

一个判别「假简单」的思路：若难度度量 $\hat d(x)$ 与真实信息量 $\mathrm{IG}(x)$ 的相关系数 $\rho(\hat d, \mathrm{IG}) \le 0$，则按 $\hat d$ 排序等价于按信息量**逆序**训练，可直接推出负课程（anti-curriculum）。

## 四、代码实现

```python
import math
import numpy as np

# ---------- 1) 可插拔的课程采样器：难度度量 + 线性进度函数 ----------
class CurriculumSampler:
    """按难度分桶，线性解锁；每步保留 random_ratio 比例的全局随机样本兜底。"""
    def __init__(self, difficulties, pace="linear", random_ratio=0.2, seed=42):
        self.d = np.asarray(difficulties, dtype=np.float64)
        self.order = np.argsort(self.d)               # 升序：易样本先解锁
        self.q = np.quantile(self.d, np.linspace(0, 1, 101))  # 100 个难度桶
        self.pace, self.ratio = pace, random_ratio
        self.rng = np.random.default_rng(seed)

    def threshold(self, t: float) -> float:
        # t in [0,1]：训练进度。线性推进；也可换 sqrt（先慢后快）等
        return self.q[min(int(t * 100), 100)]

    def sample(self, t: float, batch_size: int) -> np.ndarray:
        thr = self.threshold(t)
        unlocked = np.where(self.d <= thr)[0]         # 当前解锁的易样本池
        n_rand = int(batch_size * self.ratio)         # 兜底：始终混入全局随机样本
        idx = list(self.rng.choice(unlocked, size=batch_size - n_rand, replace=True))
        idx += list(self.rng.integers(0, len(self.d), size=n_rand))  # 防难样本被饿死
        return np.array(idx)

# ---------- 2) A/B 闸门：课程打不过随机就回退（务必同等算力） ----------
def select_schedule(curve_c, curve_r, min_gain=0.005):
    """curve_*: 验证指标随步数的曲线。课程须稳定优于随机才被采用。"""
    final_gain = curve_c[-1] - curve_r[-1]
    area_gain = np.trapz(curve_c) - np.trapz(curve_r)   # 看整体而非单点
    return "curriculum" if (final_gain > min_gain and area_gain > 0) else "random"

# ---------- 3) 自步学习权重（软课程，随模型置信度内生选择） ----------
def self_paced_weights(losses, lam):
    """loss 低于 lam 的样本获得权重 1，否则 0——简单版自步；实际常用软权重。"""
    return (losses < lam).float()   # 上线前加覆盖约束，防止难样本永久权重为 0

# 生产建议：任何课程策略都必须走 选择闸门(2) 的 A/B，
# 且报告同等算力、多种子的最终指标——否则默认用随机采样。
```

## 六、常见误区

1. **「由易到难总是对的」**：easy-to-hard 是依赖任务结构的归纳偏置；判别信息集中在难样本、或「难度」与信息量负相关时，课程会劣于随机，甚至成为 anti-curriculum。
2. **「模型置信度是客观难度」**：置信度受短路特征、标签泄漏与先验偏斜影响，高置信可能是「假简单」；按它排课会放大偏差，需与长度、人类判断或多模型共识交叉验证。
3. **「课程涨点了就是课程的功劳」**：常见原因是课程改变了有效 warmup、数据曝光次数或早停时机；必须做同等算力 + 强基线（随机采样调好 LR/warmup）+ 多种子的 A/B，否则收益不可归因。
4. **「预训练中的数据配比就是课程学习」**：配比优化的是与时间无关的静态分布 $p(x)$，课程优化的是随步变化的 $p_t(x)$；FineWeb/DCLM 的收益来自质量与配比，不是采样顺序。
5. **「课程可以替代数据清洗」**：不能。噪声样本无论排在哪个阶段都是噪声；把噪声排到后期反而在模型已过拟合简单样本后集中注入污染。清洗永远优先于排序。
6. **「课程能让难样本学得更好」**：进度函数推进过慢或预算不足时，难样本的曝光步数反而更少；若不排除该可能，需监控难样本区间的独立评测分与覆盖次数。

## 八、面试题

1. **课程学习在什么情况下会失效甚至有害？**
   要点：判别信息集中在难样本；难度度量与信息量负相关（噪声被排到最后）；预算不足导致难样本曝光不够；强基线下收益消失（warmup/清洗已覆盖其作用）。
2. **如何设计实验判断「课程收益」是否真实？**
   要点：随机采样强基线 + 同等算力（同 token 数/步数）+ 多随机种子 + 看最终指标与曲线下面积，而非训练中期；对难度度量与进度函数做敏感性分析；结论对超参不稳即不可信。
3. **难度度量常见的偏差来源有哪些？**
   要点：置信度受短路特征/标签泄漏污染；长度与真实难度弱相关；外部教师的领域盲区；难度随训练动态变化而静态排序失真。缓解：多信号融合 + 保留全局随机兜底采样。
4. **课程学习和预训练的数据配比优化有什么区别？**
   要点：课程是时变采样 $p_t(x)$ 的过程调度；配比是静态分布 $p(x)$ 的设计（DoReMi/DCLM/FineWeb 用代理模型调权重与过滤阈值）。大模型证据更支持后者，课程思想被吸收进在线的自步/不确定性过滤。
5. **为什么说自步学习比手工课程更鲁棒？它有什么新风险？**
   要点：SPL 让模型用当前损失内生选样，排序随训练状态更新，不依赖脆弱的人类先验；风险是「假简单」样本被反复选中、难样本饿死，需加覆盖约束（如 random_ratio 兜底或难度下限比例）。
6. **在 LLM 微调/预训练的数据管线里，你如何排优先级？**
   要点：清洗去重（质量）> 域配比（分布）> 采样顺序（课程）；先保证质量与配比，再在 A/B 闸门通过的前提下引入任何排序调度，否则用随机采样。

## 九、演进与趋势

2009 年 Bengio et al. 提出课程学习，2012 年自步学习把「谁来定难度」从人类规则交给模型，2010s 中期 CV/NLP 上出现大量课程应用，同时实证批评开始出现：强基线对照下许多收益无法复现，「课程 vs 随机」的 meta 结论趋于中性。2020 年后，深度学习的资源重心转向大规模预训练，社区用脚投票：把算力花在**数据质量（去重、质量分类器、蒸馏留优）与域配比（DoReMi、DCLM）**上，收益的证据强度远超排序技巧；课程学习的合理内核演化为在线的、模型驱动的样本选择（不确定性过滤、rejection sampling、self-paced weighting）与课程式 RL（如对推理任务由短到长的 CoT 长度课程，仍在局部有效）。当前的成熟观点是：**顺序调度是一种可选的、需验证的优化加速器，数据分布与质量才是主战场**；未来它更可能以「评测驱动的自适应采样」形态存在——根据 held-out 难样本分与覆盖率反馈实时调整采样权重，而不是预写一条人类排定的课程表。

## 十、小结

课程学习的局限并非「由易到难没道理」，而在于三点：easy-to-hard 依赖的任务结构并不普适，判别信息集中的任务上会反向失效；难度度量天然带偏，置信度、长度等代理指标会制造「假简单」，把排序变成偏差放大器；且其收益在强基线、同等算力对照下常常消失——这解释了为什么预训练时代胜利的是 curated data 与配比优化，而非排序技巧。工程上的正确姿势是：**把随机采样当默认，把数据清洗与配比当主优先级，把任何课程策略关进 A/B 闸门**（同算力、多种子、含难样本覆盖监控），通过了才引入；同时保留自步学习这类反馈式调度作为课程思想的更鲁棒继承者。一句话：课程不是银弹，是必须被实验证伪过的归纳偏置。
