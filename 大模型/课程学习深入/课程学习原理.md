# 课程学习原理

> 对应 d2l-zh 与 Bengio et al., *Curriculum Learning*, 2009；见「合成数据与课程学习」。

## 一、背景与挑战

由易到难训练可更快收敛、更优解，类似人类学习。

## 二、核心原理

按难度排序样本，先训简单再逐步加入难样本；难度可用长度、噪声、置信度度量。

## 三、数学形式

难度调度：

```
D(t) = 样本集随训练步 t 由易到难扩展
```

## 四、代码实现

```python
for epoch, subset in enumerate(curriculum): train_on(subset)
```

## 五、关键要点

- 难度度量难定。
- 过难起步易崩。

## 六、与其他对比

- 随机训练无序；课程有序。

## 七、常见误区

- 课程必更好——错误排序反伤。
