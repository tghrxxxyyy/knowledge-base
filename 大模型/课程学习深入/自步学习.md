# 自步学习

> 见「课程学习深入/课程学习原理」。

## 一、背景与挑战

人工定课程主观，能否模型自定？

## 二、核心原理

自步学习（Self-Paced）在损失中加入正则，让模型先学「易且自信」样本，逐步纳入难样本。

## 三、数学形式

```
min_{w,v} Σ_i v_i L_i(w) + f(v; λ),  v_i∈{0,1}
```

## 四、代码实现

```python
v = (loss < lambda).float()  # 简易自步
```

## 五、关键要点

- λ 控制纳入速度。
- 防噪声样本过早。

## 六、与其他对比

- 固定课程静态；自步动态。

## 七、常见误区

- 自步必优——需配合。
