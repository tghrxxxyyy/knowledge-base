# 难度度量

> 见「课程学习深入/课程学习原理」。

## 一、背景与挑战

难度怎么算？不同数据不同法。

## 二、核心原理

文本：句长/词频/句法复杂度；图像：噪声/分辨率；模型：loss/置信度。也可训练难度预测器。

## 三、关键要点

- 度量需与任务相关。
- 可用模型自身 loss 作代理。

## 四、代码实现

```python
diff = sorted(samples, key=lambda s: model.loss(s))
```

## 五、与其他对比

- 启发式快但粗；学习式准但贵。

## 六、常见误区

- 越长越难——未必。
