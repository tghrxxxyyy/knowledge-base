# LLM 课程训练

> 见「课程学习深入/课程学习原理」与「预训练/大规模语料与数据管线」。

## 一、背景与挑战

预训练数据异质，顺序影响收敛与能力。

## 二、核心原理

按数据质量/领域/语言/长度排课程：先用高质量清洗数据，再混入多样/长文本；或按阶段加代码/数学。

## 三、关键要点

- 质量优先于数量。
- 阶段切换需平滑。

## 四、代码实现

```python
stages = [high_quality, diverse, long_context]; train_seq(stages)
```

## 五、与其他对比

- 随机采样简单；课程更稳。

## 六、常见误区

- 课程必加速——配置错反慢。

## 七、与开源书对应

- llm-course: https://github.com/mlabonne/llm-course
- 各预训练报告（如 GPT-4 数据课程）。

## 九、演进

随机 → 质量课程 → 阶段课程。

## 十、小结

课程让预训练更可控。
