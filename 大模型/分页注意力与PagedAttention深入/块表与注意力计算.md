# 块表与注意力计算

> 对应 vLLM 中 PagedAttention 内核（Kwon et al., 2023）。

## 一、背景与挑战

物理块离散后，注意力需按逻辑顺序拼回 K/V，同时保证跨块的因果掩码正确。

## 二、核心原理

每个序列维护块表（逻辑块索引→物理块指针）；注意力内核按逻辑顺序读取各物理块，对 token 位置施加因果掩码，q 与全部历史 k/v 计算。

## 三、数学形式

对第 $i$ 个 query，可见 key 集合为 $\bigcup_{l=0}^{\lceil i/B\rceil} \text{block}(M[l])$，掩码保证仅 $j\le i$ 参与 softmax。

## 四、代码实现

```python
for l in range(logical_len):
    kv = cache[table[l]]
    attn = q @ kv.t() / sqrt(d)
```

## 五、与其他对比

- 与标准连续 KV 注意力数值等价，仅访存模式不同。
- 与 FlashAttention 可叠加（分页 + 分块约简）。

## 六、常见误区

- 跨块边界未接因果掩码致信息泄漏。
- 块表更新与内核执行未同步致脏读。

## 八、面试题

- 分页后注意力为何仍正确？答：块表按逻辑顺序拼回 K/V 并施加因果掩码，结果与连续一致。

## 九、演进

朴素拼接 → 内核级块寻址 → 与 FlashAttention 融合。

## 十、小结

块表是分页注意力的正确性与性能核心，需与因果掩码严格协同。
