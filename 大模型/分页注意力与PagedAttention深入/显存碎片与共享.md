# 显存碎片与共享

> 对应 vLLM 中 copy-on-write 共享（Kwon et al., 2023）。

## 一、背景与挑战

并行采样、beam search 等场景下多序列共享同一前缀，独立缓存会重复占用大量显存。

## 二、核心原理

分页使共享前缀可指向同一组物理块（引用计数）；仅当某序列改写块时才复制（copy-on-write），从而省显存并加速。

## 三、数学形式

写入前引用计数 $r>1$ 时触发复制：分配新块 $b'$，更新该序列块表，原块 $r\gets r-1$。

## 四、代码实现

```python
if block.ref_count > 1:
    new = copy_block(block); table[i] = new
```

## 五、与其他对比

- 连续缓存难以低成本共享前缀。
- 与 权重内存分页与卸载深入 的共享机制目标不同。

## 六、常见误区

- 忽视引用计数泄漏致块永不回收。
- 误以为共享块可随意写（需 cow）。

## 八、面试题

- 共享前缀如何省显存？答：多序列指向同一物理块，写时复制，避免重复缓存。

## 九、演进

无共享 → 引用计数共享 → cow 细粒度。

## 十、小结

分页+引用计数+写时复制，使前缀共享成为高并发场景的显存利器。
