# 多智能体协同的局限与开销

> 对应多 Agent 成本/一致性研究；与 推理经济成本深入 衔接。

## 一、背景与挑战

多 Agent 增延迟与 token 成本，且可能因通信噪声偏离目标；需权衡收益。

## 二、核心原理

成本随 Agent 数与轮次线性增；一致性靠共享状态/裁判；应在收益明显处用，并以终止与缓存控开销。

## 三、数学形式

成本 $C = \sum_{i,t} |m_{i,t}| \cdot c_{tok}$；收益 $\Delta J$ 须 $>\alpha C$ 才值。

## 四、代码实现

```python
if est_cost(agents, rounds) > budget: switch_to_single()
else: run_multi_agent(task)
```

## 六、常见误区

- 认为多 Agent 必胜单 Agent（未必）。
- 无预算护栏致成本失控。
