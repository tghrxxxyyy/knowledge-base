# 反思与自我修正（Reflexion）

> 对应 Shinn et al., *Reflexion: Language Agents with Verbal Reinforcement*, 2023。

## 一、背景与挑战

Agent 一次出错难自我纠正；需基于环境反馈/自评形成记忆并改进后续决策。

## 二、核心原理

Agent 行动后获反馈（执行结果/评测），用语言反思错误写入记忆，下一轮参考避免重犯；无需梯度更新。

## 三、数学形式

记忆 $M_{t+1}=M_t\cup\{\text{reflect}(traj_t, reward)\}$；策略 $\pi(a|s;M)$ 受记忆调制。

## 四、代码实现

```python
for ep in range(E):
    traj, r = run_agent(env, mem)
    mem += reflect(f"错误:{why(traj)}; 下次:{fix(traj)}")
```

## 五、与其他对比

- 与 辩论与协作（外部对抗）对照（此处自省）。
- 与 指令微调数据质量深入（错误样本再利用）可衔接。

## 六、常见误区

- 反思空泛无具体改进行动。
- 记忆无限增长致上下文爆。

## 八、面试题

- Reflexion 为何有效？答：把失败转成语言记忆，后续决策显式规避，类 verbal 强化。

## 九、演进

无反馈 → 奖励信号 → 语言反思记忆。

## 十、小结

反思以语言记忆实现免梯度自我改进，提升 Agent 鲁棒性。
