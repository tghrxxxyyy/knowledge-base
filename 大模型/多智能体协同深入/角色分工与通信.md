# 角色分工与通信协议

> 对应 MetaGPT 的 SOP 角色链（Hong et al., 2023）；Agent 消息协议。

## 一、背景与挑战

无结构多 Agent 对话易混乱；需明确角色职责与标准消息格式保障协作有序。

## 二、核心原理

定义角色（产品经理/工程师/测试）各带系统提示与工具；用结构化消息（含角色、内容、依赖）在共享通道传递；SOP 规定流转顺序。

## 三、数学形式

消息 $m=(role, content, deps)$；状态更新 $S\leftarrow S\cup\{m\}$；流转受有向图约束 $G=(V,E)$。

## 四、代码实现

```python
class DevAgent(Agent):
    def on_msg(self, m):
        if m.role == "PM": return Message("Dev", implement(m.spec))
```

## 五、与其他对比

- 与 指令微调数据质量深入（角色提示）共享角色设计。
- 与 检索增强失效分析深入 无直接关。

## 六、常见误区

- 角色职责重叠致推诿/重复。
- 消息无 schema 致解析脆弱。

## 八、面试题

- 为何要角色 SOP？答：明确职责与流转顺序，避免无序对话与责任模糊。

## 九、演进

自由对话 → 固定角色 → SOP 结构化流转。
