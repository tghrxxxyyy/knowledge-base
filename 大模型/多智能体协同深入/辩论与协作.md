# 辩论与协作（Multi-Agent Debate）

> 对应 Liang et al., *Encouraging Divergent Thinking via Debate*, 2023；多 Agent 辩论提事实性。

## 一、背景与挑战

单模型易自信犯错；多 Agent 互辩可暴露错误、收敛更可靠答案。

## 二、核心原理

多个 Agent 提出观点并相互反驳/论证，裁判或投票汇总；辩论压力降低幻觉、提升推理与事实性。

## 三、数学形式

第 $r$ 轮观点 $a_i^{(r)} = f(a_1^{(r-1)},\dots,a_k^{(r-1)})$；最终 $\hat y = \text{vote/arbiter}(\{a_i^{(R)}\})$。

## 四、代码实现

```python
for r in range(R):
    for ag in agents: ag.respond(debate_history)
verdict = arbiter(debate_history)
```

## 五、与其他对比

- 与 反思与自我修正（单 Agent 反思）对照。
- 与 指令微调数据质量深入 无直接关。

## 六、常见误区

- 同质 Agent 辩论易群体思维。
- 轮数过多增成本且可能发散。

## 八、面试题

- 辩论为何提事实性？答：互驳暴露矛盾与幻觉，压力促更谨慎论证，收敛更可靠答案。

## 九、演进

单答 → 多数投票 → 多轮辩论+裁判。

## 十、小结

多 Agent 辩论以对抗协作提升可靠性，但需异质与终止规则。
