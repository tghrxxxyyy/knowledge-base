# 多智能体协同总览

> 对应 Wu et al., *AutoGen*, 2023；Hong et al., *MetaGPT*, 2023；Park et al., *Generative Agents*, 2023。

## 一、背景与挑战

单 LLM 难胜任长程、多角色、需验证的复杂任务；多智能体通过分工协作提升能力与可靠性。

## 二、核心原理

把任务拆给多个具角色/工具的 Agent，按通信协议交互（对话/消息/共享黑板），由编排器或自组织完成任务。

## 三、数学形式

系统状态 $S_{t+1}=T(S_t, \{a_i\}_{i=1}^k)$；协作收益 $\Delta = J(S_{final})-J(S_{single})$。

## 四、代码实现

```python
from autogen import AssistantAgent, UserProxyAgent
assistant = AssistantAgent("assistant", llm_config=...)
user = UserProxyAgent("user", code_execution_config={})
user.initiate_chat(assistant, message="写并跑一段数据分析代码")
```

## 五、与其他对比

- 与 指令微调数据质量深入（用 Agent 产数据）可互补。
- 与 流式生成与增量解码深入（单 Agent 后端）共享推理。

## 六、常见误区

- 为用而用，简单任务上多 Agent 增成本。
- 无终止条件致无限对话循环。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course
- dair-ai/Prompt-Engineering-Guide：https://github.com/dair-ai/Prompt-Engineering-Guide

## 八、面试题

- 何时用多智能体？答：任务需分工/验证/长程规划时；简单任务单 Agent 更省。

## 九、演进

单提示 → 多角色对话 → 编排框架（AutoGen/MetaGPT）。

## 十、小结

多智能体以分工协作扩展单模型边界，但需控成本与终止。
