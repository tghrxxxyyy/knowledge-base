# 租户级缓存

> 见「推理优化/连续批处理」与「多租户与资源隔离深入/多租户架构」。

## 一、背景与挑战

相同问题多租户重复问，缓存可降本提速，但需防串租户。

## 二、核心原理

语义缓存按租户命名空间存储问答，命中即返；跨租户需显式共享策略。

## 三、关键要点

- 缓存键含租户标识。
- 敏感租户可禁缓存。

## 四、代码实现

```python
key = hash(tenant + q); if key in cache: return cache[key]
```

## 五、与其他对比

- 全局缓存省但串；租户缓存安全。

## 六、常见误区

- 缓存提速即可共享——隐私泄露风险。
