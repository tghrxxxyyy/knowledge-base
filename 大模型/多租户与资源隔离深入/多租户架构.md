# 多租户架构

> 对应 llm-course 部署章与 LLM 服务平台实践。

## 一、背景与挑战

同一服务需服务多用户/客户，隔离与成本分摊是核心。

## 二、核心原理

逻辑隔离（租户 ID/配额）+ 物理隔离（独立实例/命名空间）；共享底座用路由与配额区分，敏感场景用独立部署。

## 三、关键要点

- 隔离强度随合规要求升级。
- 共享推理降本但需防串扰。

## 四、代码实现

```python
if tenant.tier == "dedicated": route_to(isolated_pool)
else: route_to(shared_pool)
```

## 五、与其他对比

| 模式 | 成本 | 隔离 |
|------|------|------|
| 共享 | 低 | 弱 |
| 独占 | 高 | 强 |

## 六、常见误区

- 共享即不安全——逻辑隔离多数够用。
