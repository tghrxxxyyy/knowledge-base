# 配额与计费

> 见「大模型部署成本模型」与「多租户与资源隔离深入/多租户架构」。

## 一、背景与挑战

多租户需按用量计费与控制预算。

## 二、核心原理

按 token/请求/时长计量，分层套餐+超额付费；实时计量写入账单，超预算限流。

## 三、关键要点

- 计量需与推理引擎对齐。
- 缓存命中可不计费或减费。

## 四、代码实现

```python
bill[tenant] += tokens * price_per_1k
```

## 五、与其他对比

- 固定包月简单；按量更公平。

## 六、常见误区

- 只计输出——输入也耗资源。

## 七、与开源书对应

- LiteLLM 计费: https://github.com/BerriAI/litellm
- llm-course: https://github.com/mlabonne/llm-course

## 九、演进

固定 → 按量 → 分层+缓存折减。

## 十、小结

计费让多租户可持续。
