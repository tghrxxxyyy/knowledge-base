# 弹性伸缩

> 见「推理服务深入/动态批处理」与「多租户与资源隔离深入/多租户架构」。

## 一、背景与挑战

流量峰谷大，需自动扩缩容控成本。

## 二、核心原理

按队列长度/延迟指标扩缩副本，冷启动用预热或常驻小池；结合 spot/分时降本。

## 三、关键要点

- 模型加载慢需预热。
- 缩容防中断在途请求。

## 四、代码实现

```python
if queue_len > H: scale_up(); elif queue_len < L: scale_down()
```

## 五、与其他对比

- 固定容量稳但贵；弹性省但抖动。

## 六、常见误区

- 缩容即杀——需优雅退出。

## 七、与开源书对应
