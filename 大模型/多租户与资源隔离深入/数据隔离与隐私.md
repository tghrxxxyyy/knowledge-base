# 数据隔离与隐私

> 见「模型水印与溯源/训练数据版权」与「多租户与资源隔离深入/多租户架构」。

## 一、背景与挑战

租户数据不可串，需隔离与脱敏。

## 二、核心原理

存储分租户命名空间、传输加密、日志脱敏、跨租户检索需鉴权；合规场景数据不出租户域。

## 三、关键要点

- 向量库按租户隔离索引。
- 日志含 PII 需脱敏。

## 四、代码实现

```python
idx = vector_db.namespace(tenant_id); hits = idx.search(q, auth=tenant)
```

## 五、与其他对比

- 共享索引便宜但串扰；隔离安全但贵。

## 六、常见误区

- 隔离=只分库——检索与日志也要隔离。
