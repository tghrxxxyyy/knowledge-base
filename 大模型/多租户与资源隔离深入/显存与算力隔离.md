# 显存与算力隔离

> 见「多租户与资源隔离深入/多租户架构」与「推理优化」。

## 一、背景与挑战

多租户抢 GPU 显存与算力，需公平调度。

## 二、核心原理

用 MPS/MIG（NVIDIA）切分 GPU，配合调度器配额与抢占；推理引擎按租户限流与队列。

## 三、关键要点

- MIG 硬切分显存算力。
- 配额防单租户饿死他人。

## 四、代码实现

```python
# 限制租户并发
sem = {t: Semaphore(quota[t]) for t in tenants}
```

## 五、与其他对比

- 软隔离靠调度；硬隔离靠 MIG。

## 六、常见误区

- 软限制够——恶意租户可击穿。
