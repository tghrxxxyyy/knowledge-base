# 自我训练与蒸馏

> 对应 自蒸馏（self-distillation）/ 自我训练（self-training）提升策略。

## 一、背景与挑战

每次都靠大模型推理成本高。把进化出的好轨迹“蒸馏”进小模型或固化进提示，可降本提效。

## 二、核心原理

用强模型在难任务上产生高质量轨迹，作为训练数据微调小模型；或对高频技能做提示固化。需质量门控（过滤低分轨迹）防止噪声放大。

## 三、数学形式

蒸馏损失：

$$\mathcal L_{KD} = \mathbb E_{(x,y)\sim D_{self}}\big[-\log \pi_{small}(y|x)\big]$$

$D_{self}$ 为自生成高质量集。

## 四、代码实现

```python
data = filter(high_quality, self_trajectories)
small_model.train(data)
```

## 五、与其他对比

- 与 智能体推理成本建模深入 配合降推理费。
- 与 经验回放与复用 共享数据来源。

## 六、常见误区

- 未过滤就把错误轨迹当标签，错误被放大。
- 蒸馏后未重新评估，性能 silently 下降。

## 八、面试题

- 自我训练最大风险？答：自身错误被当成标签反复强化，需严格质量门控。

## 九、演进

提示复用 → 小模型微调 → 持续自蒸馏闭环。

## 十、小结

自我训练把“进化成果”固化进模型，是降本增效的终局手段。
