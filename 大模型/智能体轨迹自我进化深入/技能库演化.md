# 技能库演化

> 对应 Wang et al., *Voyager*, 2023 自动技能库。

## 一、背景与挑战

把每次成功都记成文本会爆炸且难组合。Voyager 把可复用行为抽象为“技能”（带描述的代码），形成可检索、可组合的技能库。

## 二、核心原理

执行成功后，用 LLM 把动作序列提炼为带自然语言描述的技能并存入库；新任务先检索相关技能直接调用或拼装，避免从零探索。技能通过环境自动评估是否入选。

## 三、数学形式

技能入选准则：

$$accept = \mathbb{1}[exec(skill, env)=success]\cdot novel(skill)$$

仅当成功且新颖才入库，防冗余。

## 四、代码实现

```python
if env.run(candidate) == SUCCESS and not lib.contains(candidate):
    lib.add(describe(candidate), candidate)
```

## 五、与其他对比

- 与 分层记忆架构 的最高层（长期知识）同构。
- 与 轨迹自我进化总览 是同一闭环的“技能”侧面。

## 六、常见误区

- 技能描述模糊，检索时匹配错误。
- 技能间依赖未声明，组合时失效。

## 八、面试题

- 技能库为何要求“新颖”才入库？答：避免重复膨胀，保持库紧凑可检索。

## 九、演进

文本记忆 → 代码技能 → 可组合技能图。

## 十、小结

技能库把经验固化为可执行资产，是 agent 从“会做”到“熟练”的关键。
