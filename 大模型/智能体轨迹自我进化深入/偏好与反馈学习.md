# 偏好与反馈学习

> 对应 人类/环境反馈驱动的策略改进（含 RLAIF 思路）。

## 一、背景与挑战

成功≠最优，用户常有隐含偏好（风格、约束、风险偏好）。需把反馈转化为策略更新。

## 二、核心原理

收集显式（人评）或隐式（环境奖励、点击）反馈，构建偏好/奖励信号，用以微调策略或更新记忆中的“该怎么做”规则。轻量做法是在记忆中追加“用户偏好条款”供未来检索。

## 三、数学形式

策略改进方向由反馈梯度给出：

$$\theta_{t+1} = \theta_t + \eta\cdot \nabla_\theta \mathbb E_{f\sim F}[r(f,\pi_\theta)]$$

$F$ 为反馈分布。

## 四、代码实现

```python
prefs = collect_feedback(traj)
memory.append("用户偏好:" + prefs)
```

## 五、与其他对比

- 与 人机协作与人在环深入 共享反馈通道。
- 与 DPO/偏好优化思想一致（在 agent 策略层面）。

## 六、常见误区

- 单次负面反馈过度修正，丢失原有能力。
- 反馈无去偏，少数用户偏好主导。

## 八、面试题

- 反馈学习为何要温和？答：单次反馈可能偏差，需低学习率避免灾难性遗忘。

## 九、演进

无反馈 → 显式微调 → 记忆级偏好+轻量更新。

## 十、小结

反馈学习让 agent 贴合用户，是从“能用”到“好用”的进化。
