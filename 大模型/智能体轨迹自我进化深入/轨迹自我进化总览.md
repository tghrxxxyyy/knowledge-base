# 智能体轨迹自我进化总览

> 对应 Wang et al., *Voyager*, 2023（技能进化）；Shinn et al., *Reflexion*, 2023（记忆进化）。

## 一、背景与挑战

固定策略的智能体每次都从零开始，无法从历史任务中变强。自我进化让经验跨任务累积、复用、精炼。

## 二、核心原理

进化闭环：执行 → 观测结果 → 提炼经验（技能/反思/偏好） → 存入长期记忆 → 未来任务检索复用并改进。Voyager 把成功交互固化为可组合技能；Reflexion 把失败反思沉淀为记忆。

## 三、数学形式

策略随经验迭代：

$$\pi_{t+1} = \text{Improve}(\pi_t,\, \mathcal E_t),\quad \mathcal E_t = \text{Extract}(\text{traj}_t)$$

$\mathcal E_t$ 为第 $t$ 轮提炼的经验。

## 四、代码实现

```python
exp = extractor.summarize(traj, success)
memory.upsert(exp)
plan = planner(reuse=memory.relevant(task))
```

## 五、与其他对比

- 与 长程任务记忆压缩深入 共享经验存储。
- 与 工具调用错误恢复深入 的反思同源。

## 六、常见误区

- 经验未去重，相似技能膨胀致检索噪声。
- 错误经验被固化，越进化越错。

## 八、面试题

- 自我进化与简单缓存区别？答：进化提炼抽象可复用经验并持续改，而非原样存。

## 九、演进

无记忆 → 反思记忆 → 技能库+自动提炼。

## 十、小结

自我进化把“一次性执行”升级为“持续变强”，是 agent 长期价值的引擎。
