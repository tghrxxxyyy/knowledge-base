# 进化评估与防退化

> 对应 持续学习（continual learning）的灾难性遗忘防护。

## 一、背景与挑战

持续进化可能在新任务上变强、却在旧任务上退化（遗忘）。需监控与防护。

## 二、核心原理

维护一套代表性回归测试（旧任务样本），每次进化后跑回归，若旧任务性能掉过阈值则回退或加正则（如经验回放保留旧样本）。记录版本化经验便于回滚。

## 三、数学形式

退化检测：

$$\Delta_{old} = \text{SR}_{old}^{new} - \text{SR}_{old}^{baseline} < -\epsilon \implies \text{revert}$$

## 四、代码实现

```python
if regression(old_tasks) < baseline - EPS:
    rollback(version_prev)
```

## 五、与其他对比

- 与 安全评估基准 同属量化防护。
- 与 校验与回滚 共享回滚思想。

## 六、常见误区

- 只看新任务指标，忽略旧任务 silently 退化。
- 无版本管理，退化后无法回退。

## 八、面试题

- 进化为何要回归测试？答：防止在新任务变强的同时旧能力灾难性遗忘。

## 九、演进

无防护 → 人工抽查 → 自动回归+版本回滚。

## 十、小结

进化必须配回归护栏，否则“越进化越笨”比不进化更糟。
