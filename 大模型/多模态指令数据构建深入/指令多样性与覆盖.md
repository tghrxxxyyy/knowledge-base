# 指令多样性与覆盖

> 对应 指令数据设计研究（如 Wang et al. 2023 「Self-Instruct」在多模态的延伸、以及任务覆盖分析）。

## 一、背景与挑战

指令数据若类型单一（如只有描述），模型能力偏斜。需在任务类型、难度、句式、视觉概念上保持多样性与均衡覆盖，避免过拟合到少数模式。

## 二、核心原理

从任务维度（描述/对话/推理/计数/OCR/空间关系）与视觉维度（物体类别、场景、属性）系统采样，保证均衡。可用聚类把指令聚为簇，控制每簇采样比例；用 LLM 生成题型模板扩充覆盖。

## 三、数学形式

设任务分布 p(task)，目标使其均匀：最小化 \sum_k p_k \log p_k（最大化熵）。约束每簇采样上限：
n_k \le \alpha \cdot N,\quad \sum_k n_k = N
用聚类中心相似度控制多样性：\min \sum_{i\neq j} \mathrm{sim}(q_i,q_j)。

## 四、代码实现

```python
def balance_sample(items, emb, per_cluster=50):
    from collections import defaultdict
    clusters = defaultdict(list)
    for it, e in zip(items, emb):
        clusters[assign(e)].append(it)
    out=[]
    for c in clusters.values():
        out += c[:per_cluster]
    return out
```

## 五、与其他对比

相比随机收集，系统覆盖防偏斜；相比纯规模，多样性常比数量更提效；需与质量过滤平衡，避免为覆盖牺牲质量。

## 六、常见误区

只堆量忽略覆盖；某类过多致偏置；混淆多样与难例；未监控任务分布。

## 八、面试题

- Q：为何重多样性？答：防能力偏斜，广覆盖任务。
- Q：如何度量？答：任务/视觉维度分布熵。
- Q：与质量关系？答：二者需平衡，不唯量。

## 九、演进

从经验配比到自动 curriculum；动态补充弱覆盖题型；与评测缺口闭环。

## 十、小结

指令多样性与覆盖决定了模型能力边界的均衡性，系统采样与分布监控是数据构建的关键工程。
