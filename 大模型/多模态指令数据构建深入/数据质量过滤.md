# 数据质量过滤

> 对应 数据清洗研究（如 BLIP 中 ITM filter 清洗 web 图文、以及指令数据去重/质量打分）。

## 一、背景与挑战

多模态网络数据噪声大（不匹配图文、低质描述、重复）。直接训练引入噪声与幻觉。过滤需权衡保留信息量与剔除噪声，且不能过度依赖强模型。

## 二、核心原理

方法：用预训练 ITM/CLIP 给图文对打分，剔除低匹配；用 perplexity 或指令一致性筛低质文本；去重（语义/字面）；用奖励模型或 GPT 裁判筛指令质量。BLIP 用其 ITM 头作 filter 重标注 web 数据。

## 三、数学形式

过滤阈值：保留 \{ (v,t) \mid s_{ITM}(v,t) > \tau \}。去重以语义相似：
\mathrm{keep}\ x_i \iff \nexists j<i,\ \mathrm{sim}(x_i,x_j)>\theta
质量分 q(x) 由模型给出，保留 q>\gamma。

## 四、代码实现

```python
def filter_pairs(scores, thr=0.5):
    return [i for i,s in enumerate(scores) if s > thr]

def dedup(emb, theta=0.9):
    keep=[]; 
    for i,e in enumerate(emb):
        if all(cos(e,f)<theta for f in keep): keep.append(e)
    return keep
```

## 五、与其他对比

相比全量训练，过滤提升质量与降幻觉；相比人工，模型过滤可规模化；阈值敏感，过严丢多样性。常多信号联合（匹配+去重+质量）。

## 六、常见误区

单一阈值一刀切；过度过滤丢长尾；用弱 filter 反而引入偏置；忽略去重对训练稳定的影响。

## 八、面试题

- Q：为何过滤？答：去噪声低质，减幻觉。
- Q：BLIP 如何做？答：ITM 头打分过滤重标注。
- Q：去重作用？答：防重复过拟合，提多样性。

## 九、演进

从规则过滤到模型打分；从单信号到多信号；自动化质量闭环。

## 十、小结

数据质量过滤是低成本高回报的优化手段，以匹配度、去重与质量分联合筛选，显著提升下游模型表现。
