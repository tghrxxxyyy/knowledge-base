# 多智能体通信评估

> 对应 多 agent 框架基准（如 AgentBench 协作子任务）。

## 一、背景与挑战

多体系统不能只看最终答案，还要看通信效率、一致性与开销。

## 二、核心原理

评估四维度：任务完成率、通信轮数/消息量（效率）、一致性（无矛盾）、成本。理想协议是在低通信下达成高完成率。

## 三、数学形式

通信效率：

$$E = \frac{\text{SuccessRate}}{M_{msgs} + \alpha\cdot C_{cost}}$$

$M_{msgs}$ 为消息总数。

## 四、代码实现

```python
metrics = {"sr": success, "msgs": len(bus), "cost": spent}
```

## 五、与其他对比

- 与 成本评估基准 共用性价比视角。
- 与 智能体可靠性与失败模式深入 共担一致性失败检测。

## 六、常见误区

- 只比完成率，忽略通信成本差异。
- 一致性靠人工抽查，不可规模化。

- 评估多体系统除完成率还需看什么？答：通信效率、一致性与成本。

## 九、演进

结果比对 → 多维度量 → 通信效率优先。

## 十、小结

多体评估须把“通信本身”作为一等指标，否则选错协议。
