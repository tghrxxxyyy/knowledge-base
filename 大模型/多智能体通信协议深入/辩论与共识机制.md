# 辩论与共识机制

> 对应 多 agent 辩论（debate）提升推理质量的研究。

## 一、背景与挑战

单 agent 易确认偏误。让多个视角互相辩驳可暴露漏洞、收敛更稳健答案。

## 二、核心原理

多 agent 各自给出方案并互评，迭代若干轮后由裁判（或投票）形成共识。辩论提升复杂推理与事实正确性，但成本随轮数线性增长。

## 三、数学形式

第 $r$ 轮共识度：

$$c_r = \frac{1}{K}\sum_{i,j} \text{agree}(o_i^{(r)}, o_j^{(r)})$$

$|c_r-c_{r-1}|<\epsilon$ 时停止。

## 四、代码实现

```python
for r in range(ROUNDS):
    outs = [a.debate(outs) for a in agents]
    if converged(outs): break
```

## 五、与其他对比

- 与 规划与反思成本权衡 共用轮数停止准则。
- 与 智能体可靠性与失败模式深入 共担一致性失败。

## 六、常见误区

- 同质 agent 辩论无增益（回音壁）。
- 轮数过多成本失控却未收敛。

## 八、面试题

- 辩论为何能提质量？答：多视角互评暴露单 agent 盲点，收敛更稳。

## 九、演进

单人 → 双人互评 → 多角辩论+裁判。

## 十、小结

辩论以成本为代价换取鲁棒性，适合高 stakes 推理任务。
