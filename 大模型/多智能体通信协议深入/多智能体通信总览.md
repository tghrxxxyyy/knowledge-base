# 多智能体通信协议总览

> 对应 Wu et al., *AutoGen*, 2023；Li et al., *CAMEL*, 2023；Park et al., *Generative Agents*, 2023。

## 一、背景与挑战

单一智能体上下文与能力受限。多智能体通过分工协作解决更复杂任务，但“谁和谁说、说什么、何时停”需要协议约束，否则陷入混乱或死循环。

## 二、核心原理

通信协议定义消息结构（ sender/recipient/role/payload ）、路由方式（点对点/广播/黑板）、终止条件。AutoGen 用可编排的会话，CAMEL 用角色扮演的自动化协作，生成式智能体用环境广播。

## 三、数学形式

一次交互可建模为状态转移：

$$s_{t+1} = T(s_t,\, m_t),\quad m_t\sim \pi_{speaker}(s_t)$$

$\pi_{speaker}$ 决定发言者，$T$ 为环境/状态更新。

## 四、代码实现

```python
msg = agent_a.send("请设计方案", to=agent_b)
reply = agent_b.receive(msg)
```

## 五、与其他对比

- 与 智能体轨迹自我进化深入 共享经验跨体传递。
- 与 人机协作与人在环深入 衔接人类作为一个特殊 agent。

## 六、常见误区

- 无终止条件致无限对话烧钱。
- 广播风暴，所有 agent 都回应每条消息。

## 八、面试题

- 多智能体相比单体的核心难点？答：通信协议与终止/一致性，否则协作变混乱。

## 九、演进

硬编码脚本 → 可编排会话 → 自主协商协议。

## 十、小结

通信协议是多智能体的“交通规则”，决定协作是否可扩展。
