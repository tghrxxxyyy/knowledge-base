# 标签平滑

> 对应 Szegedy et al., *Rethinking Inception*, 2015（label smoothing）；亦见 Müller et al., 2019（校准分析）。

## 一、背景与挑战

硬标签（one-hot）让模型对正确类概率逼 1，易过拟合且校准差。标签平滑把目标从独热软化为均匀分布混合。

它在分类与蒸馏中常用，对数值鲁棒性也有正向作用（避免极端 log 输入）。

## 二、核心原理

目标分布 $q_k=(1-\epsilon)\mathbf 1_{k=y}+\epsilon/K$；损失对 logits 的监督更温和，抑制单一类过度自信。

实现上等价于在交叉熵目标上做凸组合，无需改网络结构。

## 三、数学形式

$\mathcal L=-\sum_k q_k\log p_k$，$q_k=(1-\epsilon)\delta_{ky}+\frac{\epsilon}{K}$，典型 $\epsilon\in[0.1,0.2]$。

## 四、代码实现

```python
import torch.nn as nn
criterion = nn.CrossEntropyLoss(label_smoothing=0.1)
loss = criterion(logits, target)
```

## 五、与其他对比

- 与 交叉熵数值稳定 同属分类损失稳健性，平滑降低极端概率。
- 与 知识蒸馏（若新增）共享“软目标”思想。
- 与 模型校准 相关，平滑提升校准。

## 六、常见误区

- 平滑系数过大模糊真实信号致欠拟合。
- 误以为对所有任务都更好（细粒度/少类需谨慎）。
- 在已用温度蒸馏时重复平滑，目标过软。

## 八、面试题

- 标签平滑为何改善校准？答：目标不再逼概率到 1，模型保留合理不确定性。
- 平滑系数怎么选？答：常用 0.1，依过拟合程度与类别数微调。

## 九、演进

硬标签 → label smoothing → 自蒸馏/温度软目标。

## 十、小结

标签平滑以软目标提升泛化与校准，是廉价且稳健的损失改进。
