# 损失函数的数值下溢与防御

> 对应浮点数值分析（Goldberg, 1991）；深度学习数值稳定性实践。

## 一、背景与挑战

除上溢外，下溢（flush to zero）也会破坏训练：过小概率取 log 得 -Inf，过小梯度被舍入为 0 致更新停滞。

尤其在混合精度、长尾类、极小学习率场景，下溢更易被忽视。

## 二、核心原理

防御：对概率/log 加安全 epsilon 夹紧；用 log 空间运算避免显式概率；避免除以可能为零的量。

框架算子（log_softmax、cross_entropy）已内置夹紧，但自定义损失需手动防护。

## 三、数学形式

$\log(x+\epsilon)$ 防御 $x\to0$；$\mathrm{clamp}(p,\epsilon,1-\epsilon)$ 防概率越界致 $\log$ 为 $\pm\infty$。

## 四、代码实现

```python
p = torch.softmax(logits, -1).clamp(min=1e-8, max=1.0)
loss = -(target * (p + 1e-8).log()).sum(-1).mean()
```

## 五、与其他对比

- 与 对数求和指数技巧 互补：LSE 防上溢、夹紧防下溢。
- 与 混合精度溢出检测深入 衔接，FP16 下溢更频繁。
- 与 优化器状态数值误差深入 不同，这里在损失层。

## 六、常见误区

- epsilon 过大引入偏差掩盖真实信号。
- 只在前向夹紧、反向仍遇 0 梯度。
- 依赖 FP16 存概率，微小值被下溢为 0。

## 八、面试题

- 下溢如何破坏训练？答：概率/梯度被舍为 0，更新停滞或 log 得 -Inf。
- 如何防御？答：log 空间运算 + 安全 epsilon 夹紧，避免显式极小概率。

## 九、演进

无防护 → clamp epsilon → 框架稳定算子内置。

## 十、小结

下溢与上溢同为数值敌方，夹紧与 log 空间运算是标准防线。
