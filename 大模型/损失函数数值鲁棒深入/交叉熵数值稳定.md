# 交叉熵数值稳定

> 对应 Bishop, *Pattern Recognition and ML*, 2006（log-sum-exp 与 softmax 数值稳定）；PyTorch `cross_entropy` 内部实现。

## 一、背景与挑战

直接算 $\log(\mathrm{softmax})$ 易出现两类问题：exp 上溢为 Inf，或对接近 0 的概率取 log 得 -Inf，产生 NaN 梯度。

标准做法是将 log 与 softmax 融合，并做最大值平移，避免中间量溢出。

## 二、核心原理

$\log\frac{e^{z_k}}{\sum_j e^{z_j}}=\frac{z_k-\max_j z_j}{\sum_j e^{z_j-\max_j z_j}}$；减最大值不改变结果却保证指数输入非正，杜绝上溢。

PyTorch 的 `F.cross_entropy` 直接吃 logits（不先 softmax），用稳定 log_softmax 实现。

## 三、数学形式

$\log\mathrm{softmax}(z)_k=z_k-\log\sum_j e^{z_j}=z_k-\max_j z_j-\log\sum_j e^{z_j-\max_j z_j}$。

## 四、代码实现

```python
import torch.nn.functional as F
loss = F.cross_entropy(logits, target)        # 稳定：内部融合 log+softmax
# 等价于 F.nll_loss(F.log_softmax(logits, 1), target)
```

## 五、与其他对比

- 与 对数求和指数技巧 是同一数值技巧在分类损失上的应用。
- 与 注意力数值稳定与溢界深入 中 softmax 溢界同源。
- 与 混合精度溢出检测深入 衔接，FP16 logits 更易溢出。

## 六、常见误区

- 自己先 `softmax` 再 `log` 再 `nll_loss`，引入额外溢出风险。
- 对未裁剪 logits 直接 `exp` 上溢。
- 标签用 one-hot 长向量而非类别索引，内存与数值都差。

## 八、面试题

- 为何 cross_entropy 直接吃 logits？答：融合 log_softmax 并减最大值，避免中间 exp/log 溢出。
- log_softmax 减最大值起什么作用？答：保证指数输入非正，根除数值上溢。

## 九、演进

log(softmax) 分离 → 融合 log_softmax → label smoothing 结合。

## 十、小结

交叉熵的数值稳定靠 log_softmax 的最大值平移，框架已内置，切勿手拆。
