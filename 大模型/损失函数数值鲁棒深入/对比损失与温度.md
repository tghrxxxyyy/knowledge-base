# 对比损失与温度系数

> 对应 Oord et al., *CPC*, 2018（InfoNCE）；Chen et al., *SimCLR*, 2020（温度对比学习）。

## 一、背景与挑战

对比损失用点积相似度与 softmax 在正负样本间拉开距离；温度 $\tau$ 既影响梯度尺度也影响数值范围。

温度过小使 logits 过大，softmax 溢界；过大则对比信号被稀释。

## 二、核心原理

InfoNCE：$ \mathcal L=-\log\frac{e^{s_+/ \tau}}{\sum_j e^{s_j/ \tau}}$，分母含一个正与若干负；温度把相似度缩放到合理区间。

实现需对相似度先除以温度再做稳定 softmax（减最大值）。

## 三、数学形式

$\mathcal L=-\log\frac{\exp(q\cdot k_+/\tau)}{\sum_{j=1}^N\exp(q\cdot k_j/\tau)}$；$\tau$ 控制分布锐度。

## 四、代码实现

```python
logits = q @ k.t() / tau          # 除以温度
labels = torch.arange(q.size(0))
loss = F.cross_entropy(logits, labels)   # 稳定 softmax
```

## 五、与其他对比

- 与 交叉熵数值稳定 同用 logits+交叉熵路径。
- 与 注意力数值稳定与溢界深入 中温度缩放同源（$\tau$ 缩放）。
- 与 嵌入几何深入（若新增）衔接，温度影响相似度几何。

## 六、常见误区

- 温度过小致 logits 溢界、梯度 NaN。
- 负样本数不足，对比目标退化为平凡解。
- 忘记把温度放到 logits 而非单独对概率操作。

## 八、面试题

- 温度起什么作用？答：缩放相似度分布锐度，过小溢界、过大信号弱。
- InfoNCE 为何数值稳？答：走 logits+cross_entropy 的稳定路径，内部减最大值。
