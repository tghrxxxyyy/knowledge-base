# 对数求和指数技巧（log-sum-exp）

> 对应数值优化标准技巧；Bishop, 2006（模式识别中的 log-sum-exp 稳定性）。

## 一、背景与挑战

直接计算 $\log\sum_j e^{z_j}$ 当 $z_j$ 很大时上溢，很小时下溢，二者都破坏后续 log/softmax。

log-sum-exp（LSE）通过减去最大值，把指数输入限制在非正区间，得到数值稳定的结果。

## 二、核心原理

$\mathrm{LSE}(z)=\log\sum_j e^{z_j}=\max_j z_j+\log\sum_j e^{z_j-\max_j z_j}$；第二项所有指数 $\le 1$，不会上溢。

该技巧是 softmax、交叉熵、对比损失的共同底层原语。

## 三、数学形式

对任意常数 $c$：$\log\sum_j e^{z_j}=c+\log\sum_j e^{z_j-c}$；取 $c=\max_j z_j$ 最稳。

梯度即 softmax：$\nabla_{z_k}\mathrm{LSE}(z)=\frac{e^{z_k}}{\sum_j e^{z_j}}$。

## 四、代码实现

```python
import torch
def logsumexp(z):
    m = z.max(dim=-1, keepdim=True).values
    return m + (z - m).exp().sum(-1, keepdim=True).log()
```

## 五、与其他对比

- 与 交叉熵数值稳定 同根：log_softmax 内部即用 LSE。
- 与 注意力数值稳定与溢界深入 中减最大值技巧一致。
- 与 损失函数数值鲁棒深入 总览呼应。

## 六、常见误区

- 不减最大值直接 exp，大 logits 立刻 Inf。
- 在 FP16 中做 LSE，最大值平移后仍可能因尺度丢精度。
- 误以为 LSE 与最大值近似等价（差一个修正项）。

## 八、面试题

- LSE 为何减最大值？答：使指数输入非正，根除数值上溢且保持数学等价。
- LSE 的梯度是什么？答：即 softmax 分布。

## 九、演进

朴素求和 → 最大值平移 LSE → 框架内置稳定算子。

## 十、小结

log-sum-exp 是 softmax/损失稳定的基石技巧，核心是最大值平移。
