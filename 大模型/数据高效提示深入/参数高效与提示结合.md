# 参数高效与提示结合

> 对应 He et al., *Towards a Unified View of PEFT*, 2022；与 参数高效微调深入 衔接。

## 一、背景与挑战

单纯提示或单纯 adapter 各有局限；统一视角下可组合多种 PEFT 以更少数据达更好效果。

## 二、核心原理

提示（输入/前缀）、适配器（Adapter）、LoRA 都可视为"在固定底座上引入低秩/低参旁路"；组合使用可在少数据下互相补强。

## 三、数学形式

统一形式：权重更新 $\Delta W = \sum_k A_k B_k$（低秩），提示提供条件偏置 $b_p$；训练仅优化 $\{A_k,B_k,b_p\}$。

## 四、代码实现

```python
model = get_peft_model(base, LoraConfig(r=8))
model = add_prompt_tuning(model, m=20)   # 提示+LoRA 组合
```

## 五、与其他对比

- 与 数据高效提示深入 总览互补（提示是 PEFT 之一）。
- 与 权重平均与模型融合深入（多 PEFT 合并）衔接。

## 六、常见误区

- 多种 PEFT 叠加致过拟合小数据。
- 忽略各方法学习率差异（应分组优化）。
