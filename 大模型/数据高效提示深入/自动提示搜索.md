# 自动提示搜索（Auto Prompt）

> 对应 Shin et al., *AutoPrompt*, 2020；Zhou et al., *Automatic Prompt Engineering (APE)*, 2023。

## 一、背景与挑战

手工设计提示费时且效果不稳；自动搜索可发现更优离散或连续提示。

## 二、核心原理

AutoPrompt 用梯度信号对候选触发词做替换搜索（masked LM 式）；APE 用大模型生成候选提示并依执行分数择优，迭代改进。

## 三、数学形式

目标 $\max_{p} \mathbb E_{(x,y)}\big[\log P_\theta(y\mid p\oplus x)\big]$；离散搜索以得分增量 $\Delta$ 选替换 token。

## 四、代码实现

```python
candidates = llm.generate(f"写若干候选指令用于任务:{task}")
best = max(candidates, key=lambda p: eval_prompt(p, dev))
```

## 五、与其他对比

- 与 提示微调（连续）不同，自动搜索产出可解释的离散提示。
- 与 少样本提示 配合选最佳示例编排。

## 六、常见误区

- 在过小验证集上搜索致过拟合提示。
- 搜索成本高却仅带来边际提升。

## 八、面试题

- 自动提示相对手工优势？答：在验证集上以搜索/生成择优，避免主观设计偏差，可复现更优。

## 九、演进

手工 → 梯度替换(AutoPrompt) → 大模型生成择优(APE)。

## 十、小结

自动提示搜索把提示设计变为可优化问题，提升数据效率与稳定性。
