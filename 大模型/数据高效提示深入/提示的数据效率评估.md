# 提示的数据效率评估

> 对应 PEFT/提示评测方法；与 模型评测指标深入 衔接。

## 一、背景与挑战

提示方法是否真"数据高效"需量化，而非凭感觉；须控制训练样本量做学习曲线对比。

## 二、核心原理

在训练样本数 $n\in\{16,32,64,...\}$ 上比较提示微调与全微调的下游指标，画学习曲线；数据高效体现在小 $n$ 处差距小甚至反超。

## 三、数学形式

数据效率 $\eta = \frac{\text{score}_{prompt}(n)}{\text{score}_{full}(n)}$；理想在极小 $n$ 即接近 1。

## 四、代码实现

```python
for n in [16, 32, 64, 128]:
    acc = eval(train_prompt(subset(data, n)))
    curve.append((n, acc))
```

## 五、与其他对比

- 与 在线蒸馏深入（同样追求少数据）互补对比。
- 与 早停与检查点选择深入（小数据易过拟合需早停）配合。

## 六、常见误区

- 仅在充足数据上比较，掩盖数据效率差异。
- 验证集与训练集分布不一致致曲线失真。

## 八、面试题

- 如何证明提示数据高效？答：随训练样本数变化画学习曲线，看小样本处与全微调的差距。

## 九、演进

单点对比 → 学习曲线 → 元学习选提示策略。

## 十、小结

提示的数据效率须以学习曲线量化，重点看小样本区间的表现。
