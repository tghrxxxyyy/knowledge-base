# 少样本提示（In-Context Learning）

> 对应 Brown et al., *Language Models are Few-Shot Learners*, 2020（GPT-3）；NeurIPS。

## 一、背景与挑战

传统监督需大量标注；大模型仅凭输入中少量示例即可学会新任务，无需权重更新。

## 二、核心原理

在上下文中给 $k$ 个（输入,输出）示例，模型通过注意力隐式"拟合"这些示范，对末位查询给出答案。示例越多通常越好，但受上下文长度限制。

## 三、数学形式

给定示范集 $D_k=\{(x_i,y_i)\}_{i=1}^k$，预测 $y^*=\arg\max_y P_\theta(y\mid [D_k; x^*])$。

## 四、代码实现

```python
prompt = "\n".join(f"{x}: {y}" for x, y in shots) + f"\n{x_test}:"
out = llm(prompt)
```

## 五、与其他对比

- 与 连续提示微调 不同：ICL 完全不改权重。
- 与 自动提示搜索深入 配合选最优示例集。

## 六、常见误区

- 示例标注错误直接污染输出。
- 示例顺序敏感（位置偏置）需校准。

## 八、面试题

- ICL 为何有效？答：大模型在预训练中学到"从上下文推断模式"的能力，注意力可隐式拟合示范分布。

## 九、演进

零样本 → 单样本 → 少样本 → 思维链少样本。

## 十、小结

少样本提示是零权重更新的数据高效适配，示例质量与编排至关重要。
