# 稀疏注意力总览

> 对应 Beltagy et al., *Longformer*, 2020 与 Zaheer et al., *BigBird*, 2020（把全注意力降为稀疏模式以处理长序列）。

## 一、背景与挑战

标准自注意力对长度 $n$ 复杂度为 $O(n^2)$，长文档/高分辨率上不可行，需结构化稀疏降低开销。

## 二、核心原理

用预定义稀疏模式（窗口、空洞、全局 token）只计算部分 $(i,j)$ 对，将复杂度降到 $O(n\sqrt n)$ 或 $O(nw)$。

## 三、数学形式

全注意力 $A_{ij}=\mathrm{softmax}(q_i^\top k_j)$；稀疏版仅在掩码集合 $S_i$ 上归一：$A_{ij}\propto \exp(q_i^\top k_j)\cdot\mathbf 1[(i,j)\in S]$。

## 四、代码实现

```python
mask = window_mask(L, w) | global_mask  # 组合稀疏模式
attn = softmax(q @ k.T / d ** .5 + mask)
```

## 五、与其他对比

- 与 线性注意力近似方法深入 不同：稀疏保留 softmax 但减对，线性注意力改核近似降复杂度。
- 与 状态空间对偶与Mamba2深入 对照：SSM 另走线性递推路线。

## 六、常见误区

- 稀疏掩码未保证信息全局可达，远距依赖丢失。
- 盲目堆叠窗口致理论复杂度仍偏高。

## 八、面试题

- 稀疏注意力为何能降复杂度？答：只对掩码内的 query-key 对计算，去掉大部分 $O(n^2)$ 项。

## 九、演进

全注意力 → 窗口/空洞 → 全局+局部组合 → 与线性注意力融合。

## 十、小结

稀疏注意力用结构化掩码把 $O(n^2)$ 降到近线性，是长序列经典解法。
