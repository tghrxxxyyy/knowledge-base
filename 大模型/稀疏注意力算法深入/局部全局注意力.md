# 局部与全局注意力组合

> 综合 Longformer/BigBird 设计；与 专家混合路由策略深入 的“全局 token 路由”可类比。

## 一、背景与挑战

纯局部易丢长程；纯全局成本高。需在二者间分配预算，使关键信息被全局关注。

## 二、核心原理

把注意力预算分为局部窗口（多数 token）与全局槽位（少数代表），全局槽位聚合并广播跨段信息。

## 三、数学形式

设全局比例 $\alpha$，全局开销 $O(\alpha n\cdot n)$，总开销 $O(nw+\alpha n^2)$，需令 $\alpha$ 小而信息量大。

## 四、代码实现

```python
g = x[global_idx]            # 全局槽
ctx = attn(x, x, window)     # 局部
x = ctx + attn(x, g)         # 注入全局
```

## 五、与其他对比

- 与 稀疏注意力算法深入 总览一致，是稀疏模式的核心子结构。
- 与 FlashAttention 边际相关：稀疏减少计算量，FlashAttention 优化稠密计算 IO。

## 六、常见误区

- 全局槽位选普通 token，未选语义代表（如段落首/摘要）。
- 局部窗口与全局数量比例失衡致预算浪费。

## 七、与开源书对应

## 八、面试题

- 如何选全局 token？答：选语义代表（段首/特殊符），少量即可桥接长程依赖。

## 九、演进

全全局 → 全局部 → 局部为主全局为辅的预算分配。

## 十、小结

局部+全局组合是稀疏注意力的通用骨架，关键在全局槽位的选择与预算。
