# 成本优化总览

> 对应 LLM 成本结构（算力/显存/带宽）；FinOps 实践。

## 一、背景与挑战

推理成本随规模线性涨，需从模型选型到调度全链路降本。

## 二、核心原理

杠杆：量化降显存、批处理提利用率、缓存省生成、小模型替代、Spot/竞价实例、KV 复用。

## 三、数学形式

单请求成本 $c = \frac{p_{gpu}\cdot t}{B} + c_{token}$；总 $C = \sum c_i$。

## 四、代码实现

```python
cost = gpu_price_per_h * hours / batch_size + tokens * price_per_k
```

## 五、与其他对比

- 与 模型压缩与稀疏量化深入（降显存）衔接。
- 与 推理缓存与命中优化深入（省生成）相关。

## 六、常见误区

- 只追单价忽略利用率（空跑更贵）。
- 小模型省成本却损质量未评估。

## 七、与开源书对应

- mlabonne/llm-course：https://github.com/mlabonne/llm-course
- datawhalechina/llm-universe：https://github.com/datawhalechina/llm-universe

## 八、面试题

- 降本首要杠杆？答：提 GPU 利用率（批处理/连续批），空跑最贵。

## 九、演进

大碗 → 量化 → 批/缓存 → 小模型路由。

## 十、小结

成本优化是利用率+压缩+缓存的系统工程。
