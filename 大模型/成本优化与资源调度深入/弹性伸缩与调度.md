# 弹性伸缩与调度

> 对应 K8s HPA/推理自定义扩缩；队列感知伸缩。

## 一、背景与挑战

流量波峰波谷大，常开满副本浪费，需按负载弹性。

## 二、核心原理

基于并发/队列/延迟的 HPA；冷却防抖动；Spot 实例降单价但可能被回收需冗余。

## 三、数学形式

目标副本 $n = \lceil \frac{\lambda \cdot \bar t}{SLO_{lat}\cdot \mu} \rceil$；按并发/延迟算。

## 四、代码实现

```python
desired = ceil(current_inflight / target_per_replica)
scale_deployment(replicas=desired)
```

## 五、与其他对比

- 与 多副本负载均衡深入（分发）衔接。
- 与 成本优化与资源调度深入 总览互补。

## 六、常见误区

- 伸缩过频致抖动（需冷却）。
- Spot 回收无冗余致中断。
