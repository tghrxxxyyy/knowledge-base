# GPU共享与切分

> 对应 MIG（A100 多实例）、算力切分、时间片复用。

## 一、背景与挑战

小模型占整卡浪费；需把卡切多租户或时分复用提利用率。

## 二、核心原理

MIG 硬隔离成实例（7 份）；算力切分（如 vLLM 多模型时分）；显存隔离防干扰。

## 三、数学形式

卡切 $k$ 份，每份算力 $1/k$；利用率 $u = \frac{\sum load_i}{k}$。

## 四、代码实现

```python
# CUDA MIG：创建 7 个 gi 实例（A100）
nvidia-cuda-mig  # 逻辑切分
```

- 与 成本优化与资源调度深入 总览衔接。

## 六、常见误区

- MIG 实例不可动态合并，规划错难改。
- 切分过小致单实例 OOM。

## 八、面试题

- MIG 利弊？答：硬隔离稳但固定粒度，适合多小模型共卡。

## 九、演进

独占卡 → 时分复用 → MIG 硬隔离。

## 十、小结

GPU 切分提利用率，MIG 适合固定小模型场景。
