# 显存占用分析

> 见「推理经济成本深入/推理成本总览」与「模型量化部署实战」；显存决定能跑多大模型。

## 一、背景与挑战

显存装不下模型就跑不起来，需精算各部分占用。

## 二、核心原理

推理显存 = 权重（参数量×精度字节）+ **KV-cache**（每层 2×batch×seq×hidden×层数×精度）+ 激活/临时缓冲。7B fp16 权重约 14GB；KV-cache 随 batch 与序列长线性增长，长上下文下可超权重。

## 三、数学形式

KV-cache ≈ `2 × B × S × L × H × bytes`（2 为 K,V；B batch, S seq, L layers, H hidden）。

## 四、代码实现

```python
kv_gb = 2 * B * S * L * H * 2 / 1e9   # fp16
```

## 五、关键要点

- 长序列时 KV-cache 主导。
- 量化权重降显存但 KV-cache 也需量化。

## 六、与其他对比

- 权重固定；KV-cache 随负载变。

## 七、常见误区

- 只看权重显存——KV 更长。
