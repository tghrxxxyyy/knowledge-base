# 云与自托管 TCO

> 见「推理经济成本深入/推理成本总览」；部署形态选择。

## 一、背景与挑战

用云 API 还是自建集群？总拥有成本（TCO）决定。

## 二、核心原理

- **云 API**：零运维、按量付费，但长尾高频场景单价高、数据出域。
- **自托管**：前期硬件/电费高，量大后边际成本低、数据可控。
- 决策点：QPS、数据合规、峰值波动。用量大且稳定 → 自托管；波动大/试水 → 云。

## 三、关键要点

- 临界点 QPS 决定盈亏。
- 自托管需运维人力计入。
