# 推理成本总览

> 对应 llm-course 与「大模型部署成本模型」；推理成本是企业落地的核心约束。

## 一、背景与挑战

训练一次性、推理持续烧钱；每请求的成本（latency/throughput/$/1K tokens）决定商业模式是否可行。

## 二、核心原理

推理成本三维度：**延迟（latency）**单请求耗时、**吞吐（throughput）**单位时间请求数、**单价（cost）**硬件+能耗+运维。优化目标是在预算内最大化吞吐、控制延迟。大模型推理瓶颈在显存带宽（权重与 KV-cache 反复读写）。

## 三、关键要点

- 显存带宽是推理第一瓶颈，非算力。
- 批处理与量化是降本两大杠杆。
- 长上下文 KV-cache 显著拉高显存。

## 四、代码实现

```python
# 估算：tokens × (权重+KV) × 访存/带宽
flops = 2 * params * tokens
```

## 五、与其他对比

|------|------|------|
