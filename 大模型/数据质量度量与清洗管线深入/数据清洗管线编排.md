# 数据清洗管线编排

> 对应 huggingface/transformers 与 NVIDIA/TensorRT-LLM。

## 一、背景与挑战
清洗步骤多且彼此依赖，手工脚本难以复用与监控，需要可编排管线。

## 二、核心原理
把各过滤步骤建模为有向无环图，每步可配置、可缓存、可重跑。

## 三、形式化与数学基础
吞吐：
$ \Theta = \frac{|\text{output}|}{\sum_s t_s} $

## 四、代码实现
```python
def pipeline(docs, steps):
    for name, fn in steps:
        docs = fn(docs)
    return docs
```

## 五、与其他技术对比
线性脚本简单但不可重入，DAG 编排支持并行与断点续跑。

## 六、常见误区
步骤顺序不当导致重复计算；未记录每步淘汰率。

## 七、与开源书/权威来源对应
huggingface/transformers 数据工具；NVIDIA/TensorRT-LLM 训练预处理。

## 八、面试题
如何设计可重跑且幂等的数据管线？

## 九、演进与趋势
声明式数据管线与血缘追踪。

## 十、小结
管线化让数据清洗可工程化、可审计。
