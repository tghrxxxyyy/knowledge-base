# 质量分类器与启发式

> 对应 huggingface/transformers 与 karpathy/nanoGPT。

## 一、背景与挑战
规则无法覆盖所有低质模式，需要可学习的质量分类器辅助筛选。

## 二、核心原理
用高质量参考（如书籍、百科）训练二分类器，对语料打分并设定阈值。

## 三、形式化与数学基础
分类边界：
$ \hat{y} = \mathbb{1}[f_\theta(d) > \tau] $

## 四、代码实现
```python
def filter_by_clf(docs, clf, tau=0.7):
    return [d for d in docs if clf(d) > tau]
```

## 五、与其他技术对比
分类器泛化好但可能过拟合参考分布，需与启发式互补。

## 六、常见误区
用单一来源训练致分布偏移；忽视误杀高质量长尾。

## 七、与开源书/权威来源对应
huggingface/transformers 提供训练与推理；karpathy/nanoGPT 数据实践。

## 八、面试题

## 九、演进与趋势
自监督质量信号替代人工标注。

## 十、小结
分类器把质量筛选从规则升级为模型驱动。
