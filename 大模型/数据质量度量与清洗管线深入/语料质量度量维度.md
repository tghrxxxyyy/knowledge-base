# 语料质量度量维度

> 对应 Wenzek et al. 2019《CCNet》、Raffel et al. 2019《Exploring the Limits of Transfer Learning》（C4）、Penedo et al. 2023《The RefinedWeb Dataset》，以及 HuggingFace transformers / datasets 与 karpathy/nanoGPT 的数据实践。

## 一、背景与挑战

预训练的第一杠杆不是模型结构，而是数据。同一套架构，用不同质量的语料训练，能力差距可以达到"换个量级"的程度。但"质量"不是一个可直接观测的量：语料规模以 TB 计，无法人工审阅，必须把它分解成可计算、可聚合、可跨源比较的**度量维度**。

挑战在于：第一，各维度量纲不同（困惑度是 bits，重复率是比例，毒性是概率），直接相加没有意义，需要归一化与标定。第二，维度之间相关：重复文档往往困惑度也低，语言识别置信度低的文本常常是抓取噪声。第三，**单一维度会产生系统性偏差**：只用困惑度筛选，会系统性地偏向常见、简单、模板化的文本，丢掉罕见但高价值的专业内容。第四，不同语言、不同领域应有不同权重，一套全局权重会造成"削足适履"。第五，度量本身有成本，需要在 TB 级语料上可并行执行。

## 二、核心原理

工程上通常把质量拆为六个可计算维度：

1. **流畅性/可预测性**：用参考模型的困惑度或每字符比特数衡量。过高说明噪声、乱码、机器翻译腔；过低（异常低）说明模板化重复内容。
2. **重复度**：文档内 n-gram 重复率、行重复率，以及跨文档的近重复（后者由专门的去重步骤处理）。
3. **信息密度**：实体数量、术语密度、句子长度方差、与停用词比例的对比。信息密度低的文本（如导航页）占 token 但不贡献知识。
4. **语言纯度**：语言识别置信度与单语占比，混语严重的文档对单语模型是噪声。
5. **安全性**：毒性分数、成人/暴力内容分数、隐私实体命中密度。
6. **结构完整性**：长度分布、段落结构、是否有正常的句末标点、HTML 残留比例。

度量之后是**聚合与标定**。可行做法是把各维度分数转换为分位排名（quantile rank）后再加权求和，避免量纲问题：

$$
Q(d) = \sum_k w_k \, \tilde{q}_k(d), \qquad \tilde{q}_k(d) = \mathrm{rank\%}(q_k(d))
$$

随后按来源分别取分位数阈值，保证各源的保留率可控。

## 三、形式化与数学基础

**困惑度维度。** 给定参考语言模型 $p_{\mathrm{ref}}$，文档 $d = (x_1, \dots, x_T)$ 的每 token 交叉熵为

$$
\mathrm{CE}(d) = -\frac{1}{T} \sum_{t=1}^{T} \log_2 p_{\mathrm{ref}}(x_t \mid x_{<t}), \qquad \mathrm{PPL}(d) = 2^{\mathrm{CE}(d)}
$$

为消除长度偏差，实践中常用**每字符比特数（bits-per-character, BPC）**：

$$
\mathrm{BPC}(d) = \frac{\mathrm{CE}(d) \cdot T}{\mathrm{chars}(d)}
$$

CCNet 一类流水线的做法是按困惑度分桶，从不同桶中按不同比例采样，而不是简单砍掉高困惑度部分——因为高困惑度桶里包含大量专业文本。

**重复度维度。** 文档内 n-gram 重复率定义为

$$
\mathrm{Rep}_n(d) = 1 - \frac{|\{g : g \in \mathrm{ngrams}_n(d)\}|}{|\mathrm{ngrams}_n(d)|}
$$

其中分子是不同 n-gram 的类型数，分母是 token 总数。该值为 0 表示完全无重复，接近 1 表示高度模板化。

**信息密度维度。** 可用熵与停用词比例近似：

$$
H(d) = -\sum_{w} \frac{c_w(d)}{|d|} \log \frac{c_w(d)}{|d|}, \qquad \mathrm{StopRatio}(d) = \frac{|\{w : w \in \mathcal{S}\}|}{|d|}
$$

信息密度可构造为 $H(d) \cdot (1 - \mathrm{StopRatio}(d))$：词汇多样且非停用词占比高，说明内容密集。

**聚合。** 分位归一化后加权：

$$
Q(d) = \sum_{k=1}^{K} w_k \, \tilde{q}_k(d), \qquad \sum_k w_k = 1,\ w_k \ge 0
$$

若关心鲁棒性，可用**最小值约束**替代纯加权和，避免某一维度极差却被其他维度补偿：

$$
Q_{\min}(d) = \min_k \tilde{q}_k(d)
$$

最终筛选可用 $Q(d) \ge \tau_Q$ 与 $Q_{\min}(d) \ge \tau_{\min}$ 的合取。

**维度标定。** 权重不应凭直觉设定，可通过对少量人工标注样本做回归或排序学习得到：给定人工质量分 $y_i$ 与维度向量 $\tilde{q}(d_i)$，最小化

$$
\min_w \ \sum_i \left( y_i - w^\top \tilde{q}(d_i) \right)^2 + \lambda \|w\|_2^2
$$

这样权重由数据驱动而非拍脑袋。

## 四、代码实现

```python
# 六个维度的基础度量实现；全部设计为纯函数，便于在 datasets.map 中并行
import math
import re
from collections import Counter

WORD_RE = re.compile(r"\w+", re.UNICODE)
STOPWORDS = set("的 了 是 在 和 有 就 不 也 the a of and to in is it that for on".split())

def basic_metrics(text):
    toks = WORD_RE.findall(text.lower())
    n_tok = max(len(toks), 1)
    n_char = max(len(text), 1)
    counter = Counter(toks)

    # 信息熵（词汇多样性）
    ent = -sum((c / n_tok) * math.log(c / n_tok, 2) for c in counter.values())
    stop_ratio = sum(counter[w] for w in STOPWORDS if w in counter) / n_tok

    # 结构与符号
    sent_end = text.count("。") + text.count(".") + text.count("!") + text.count("？")
    lines = [l for l in text.split("\n") if l.strip()]
    return {
        "n_char": n_char,
        "n_tok": n_tok,
        "entropy": ent,
        "stop_ratio": stop_ratio,
        "type_token_ratio": len(counter) / n_tok,
        "sent_per_char": sent_end / n_char,
        "mean_line_len": (sum(len(l) for l in lines) / max(len(lines), 1)),
    }

def ngram_repeat(text, n=8):
    toks = WORD_RE.findall(text.lower())
    if len(toks) < n:
        return 0.0
    grams = [tuple(toks[i:i + n]) for i in range(len(toks) - n + 1)]
    return 1.0 - len(set(grams)) / len(grams)

def info_density(text):
    m = basic_metrics(text)
    return m["entropy"] * (1.0 - m["stop_ratio"])
```

```python
# 困惑度维度：用小参考模型算每字符比特数，避免长度偏差
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

REF = "Qwen/Qwen2.5-0.5B"          # 小模型即可，仅用于相对排序
ref_tok = AutoTokenizer.from_pretrained(REF)
ref_model = AutoModelForCausalLM.from_pretrained(REF).eval()

@torch.inference_mode()
def bits_per_char(text, max_len=1024):
    ids = ref_tok(text, return_tensors="pt", truncation=True, max_length=max_len)
    T = ids["input_ids"].shape[-1]
    if T < 2:
        return None
    out = ref_model(**ids, labels=ids["input_ids"])
    # HuggingFace 返回的 loss 是平均交叉熵（自然对数底），换算为总 bit
    total_nats = out.loss.item() * (T - 1)
    return (total_nats / math.log(2)) / max(len(text), 1)
```

```python
# 分位归一化 + 加权聚合，解决量纲不一致问题
def quantile_normalize(values):
    order = sorted(range(len(values)), key=lambda i: values[i])
    ranks = [0.0] * len(values)
    for pos, idx in enumerate(order):
        ranks[idx] = pos / max(len(values) - 1, 1)
    return ranks

def aggregate(docs, metric_fns, weights):
    raw = {k: [fn(d) for d in docs] for k, fn in metric_fns.items()}
    norm = {k: quantile_normalize(v) for k, v in raw.items()}
    scores = []
    for i in range(len(docs)):
        scores.append(sum(weights[k] * norm[k][i] for k in weights))
    return scores, norm

metric_fns = {
    "info_density": info_density,
    "repeat": lambda d: -ngram_repeat(d),      # 取负号：重复越低越好
    "length": lambda d: min(len(d) / 3000.0, 1.0),
}
weights = {"info_density": 0.5, "repeat": 0.3, "length": 0.2}
scores, norm = aggregate(corpus[:1000], metric_fns, weights)
```

## 五、与其他技术对比

| 维度 | 计算方式 | 优点 | 局限 |
|------|----------|------|------|
| 困惑度/BPC | 参考模型交叉熵 | 与语言建模目标直接相关 | 偏向模板化文本；需算力 |
| 重复率 | n-gram 类型/总数 | 极廉价，抓模板页 | 抓不住语义重复 |
| 信息密度 | 熵 × (1-停用词比) | 区分干货与水文 | 对诗歌、对话不友好 |
| 语言纯度 | 语言 ID 置信度 | 多语场景必需 | 短文本不可靠 |
| 毒性/安全 | 分类器打分 | 合规必需 | 文化语境敏感，有误判 |
| 结构完整 | 长度、标点、HTML 残留 | 廉价高召回 | 只能去明显垃圾 |

| 聚合方式 | 公式 | 特点 |
|----------|------|------|
| 加权和 | $\sum_k w_k \tilde{q}_k$ | 平滑，允许维度互补 |
| 最小值 | $\min_k \tilde{q}_k$ | 严格，任一维度不达标即淘汰 |
| 级联阈值 | 逐维度硬过滤 | 可解释、可并行、易调试 |
| 学习式融合 | 回归/排序模型 | 数据驱动，需标注 |

## 六、常见误区

- **只用困惑度**：会系统性偏向简单与模板化文本，砍掉专业、罕见、复杂的优质内容。
- **直接相加原始分数**：量纲不同（bits 与比例），结果被大尺度维度主导。
- **权重拍脑袋**：应通过少量人工标注做回归校准，并定期复核。
- **全局统一阈值**：不同来源的分布差异大，应分源取分位数。
- **忽略跨文档重复**：文档内不重复但整篇被转载上万次，仍会放大偏见。
- **把高质量等同于"像百科"**：会损失口语、对话、方言与创意写作能力。
- **度量后不抽样人工复核**：指标与真实质量脱节时不会被发现。

## 七、与开源书·权威来源对应

- Wenzek et al. 2019《CCNet: Extracting High Quality Monolingual Datasets from Web Crawl Data》：按困惑度分桶 + 语言识别的经典流水线，是 BPC 与分桶采样的实践源头。
- Raffel et al. 2019《Exploring the Limits of Transfer Learning》（C4）：系统化启发式规则（句末标点、长度、脏词、"javascript" 等）。
- Brown et al. 2020《Language Models are Few-Shot Learners》（GPT-3）：质量分类器 + 相似度去重的组合实践。
- Penedo et al. 2023《The RefinedWeb Dataset for Falcon LLM》：论证网页数据的质量过滤可替代"必须混合百科/书籍"的成见。
- Rae et al. 2021（Gopher）与 Hoffmann et al. 2022（Chinchilla）：前者给出多维度质量分析，后者强调数据量的算力最优性。
- HuggingFace transformers / datasets：提供语言 ID、困惑度计算与大规模 map/filter 的工程能力；karpathy/nanoGPT 强调在小预算下数据质量优先。

## 九、演进与趋势

度量体系从"单一困惑度"演进到"多维度加权"，再到"模型驱动的质量打分"。趋势上，一是**维度细化**，从事实性、教育价值到推理密度，出现面向能力目标的专用维度；二是**用强模型生成质量标注**，替代部分人工标注并降低成本；三是**度量与配比联动**，质量分直接决定采样权重与重复轮次；四是**跨语言统一标定**，解决非英语语料长期缺乏质量信号的问题；五是**可审计的数据卡片**，把每个维度的分布、阈值与淘汰率记录下来，便于复现与合规审查。

## 十、小结

语料质量不是一个数字，而是一组可计算维度与一套标定方法。可靠的做法是：选取困惑度/BPC、重复率、信息密度、语言纯度、安全性与结构完整性六个维度，统一做分位归一化后加权聚合，并对关键维度附加最小值约束；权重由少量人工标注校准而非凭直觉设定；阈值按来源分别取分位数。最后必须抽样人工复核，确保指标没有与真实质量脱节。
