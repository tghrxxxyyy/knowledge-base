# 语料质量度量维度

> 对应 huggingface/transformers 与 karpathy/nanoGPT。

## 一、背景与挑战
预训练语料规模巨大，质量不均会直接拉低模型能力，需要多维度量。

## 二、核心原理
从重复度、困惑度、毒性、语言纯度、文档长度等维度打分并分桶。

## 三、形式化与数学基础
综合质量分：
$ Q(d) = \sum_k w_k q_k(d), \quad w_k \ge 0 $

## 四、代码实现
```python
def quality(doc, weights, metrics):
    return sum(weights[k] * metrics[k](doc) for k in weights)
```

## 五、与其他技术对比
单一阈值粗糙，多维加权更细但需标定权重。

## 六、常见误区
只用困惑度忽略语义重复；权重拍脑袋。

## 七、与开源书/权威来源对应
huggingface/transformers 提供数据处理工具；karpathy/nanoGPT 强调数据。

## 八、面试题
如何为不同语种设定质量权重？

## 九、演进与趋势
用模型反馈学习质量分类器。

## 十、小结
质量是预训练的第一杠杆。
