# 去重与近重复检测

> 对应 huggingface/transformers 与 EleutherAI/lm-evaluation-harness。

## 一、背景与挑战
海量网页语料存在大量转载与近似复制，会放大偏见并浪费算力。

## 二、核心原理
用 MinHash + LSH 做近似去重，或对文档做 n-gram 相似度阈值过滤。

## 三、形式化与数学基础
Jaccard 相似度：
$ J(A,B) = \frac{|A \cap B|}{|A \cup B|} $

## 四、代码实现
```python
def jaccard(a, b):
    inter = len(a & b)
    union = len(a | b)
    return inter / union
```

## 五、与其他技术对比
精确去重慢，MinHash 近似高效适合海量数据。

## 六、常见误区
只在文档级去重忽略段级重复；阈值过严丢信息。

## 七、与开源书/权威来源对应
huggingface/transformers 数据处理；社群常用 LSH 去重。

## 八、面试题
MinHash 为什么能近似 Jaccard？

## 九、演进与趋势
语义级去重结合嵌入聚类。

## 十、小结
去重是降低冗余与偏差的基础步骤。
