# 数据配比与课程策略

> 对应 Hoffmann et al. 2022《Training Compute-Optimal Large Language Models》（Chinchilla）、Kaplan et al. 2020《Scaling Laws for Neural Language Models》，以及 karpathy/nanoGPT 的数据混合实践与 DoReMi 一类域权重优化工作。

## 一、背景与挑战

预训练语料天然是多源的：网页、书籍、代码、论文、百科、对话、数学、多语。每一类对最终能力的贡献不同，且相互之间存在干扰与稀释——把所有数据均匀混合，往往不如按目标能力调整比例。更麻烦的是，配比与训练动态耦合：同一份数据，放在训练早期与晚期，效果可能完全不同。

挑战具体体现在：第一，**算力预算固定**时，参数量、数据量、配比三者需要联合决策，单看一个维度会得出错误结论。第二，**缺乏可解释的归因手段**：想知道"多加 5% 代码是否提升推理"，代价是一次完整训练，通常需要小规模代理实验（proxy experiments）加缩放律外推。第三，**课程策略难以稳定**：先易后难并不总是更好，过强的课程可能让模型在后期对简单分布欠拟合。第四，**退火阶段（annealing）的高质量数据上采样**是近年才被系统验证的实践，很多团队仍在凭经验调。

## 二、核心原理

**第一层是算力最优分配。** 在算力预算 $C$ 约束下，参数量 $N$ 与训练 token 数 $D$ 需要同步放大。Chinchilla 的核心结论是当时主流模型"参数偏大、数据偏少"，在同等算力下增加数据量能显著降低损失（具体系数以原始论文为准）。

**第二层是域权重（domain weights）。** 设语料划分为 $K$ 个域，配比向量 $\alpha = (\alpha_1, \dots, \alpha_K)$，$\sum_k \alpha_k = 1$，训练分布为混合分布

$$
p_\alpha(x) = \sum_{k=1}^{K} \alpha_k \, p_k(x)
$$

目标是最小化最关心的损失组合。DoReMi 一类方法把这个问题形式化为极小化极大（minimax）：先在均匀配比下训练一个参考模型，再优化域权重，使得在最坏域上的损失相对参考模型的超出量最小：

$$
\min_{\alpha \in \Delta^{K}} \ \max_{k} \ \mathbb{E}_{x \sim p_k} \left[ \ell_{\theta_\alpha}(x) - \ell_{\theta_{\mathrm{ref}}}(x) \right]
$$

直觉是"优先给那些学得最差的域更多权重"。

**第三层是课程与退火。** 常见做法是把训练分为若干阶段，前期用多样性优先的较宽松数据，后期（学习率退火前的一小段）上采样高质量、与目标强相关的数据（如教科书式文本、数学、指令数据），并降低学习率。这一阶段对最终质量的影响常被低估。

**第四层是重复与轮次。** 高质量数据重复 2–4 轮的收益通常大于引入低质新数据，但重复过多会导致记忆与过拟合，需要配合去重与多样性监控。

## 三、形式化与数学基础

缩放律的经验形式：

$$
L(N, D) = E + \frac{A}{N^{\alpha}} + \frac{B}{D^{\beta}}
$$

算力 $C \approx 6ND$。在约束 $6ND = C$ 下最小化 $L$，由拉格朗日法可得最优分配的指数关系：

$$
N^\ast \propto C^{a}, \qquad D^\ast \propto C^{b}, \qquad a = \frac{\beta}{\alpha + \beta},\quad b = \frac{\alpha}{\alpha + \beta}
$$

可见 $a + b = 1$，即算力增长时参数与数据按固定指数比例同步放大。由此可直接回答"给定预算该训多大的模型、喂多少 token"。

域权重的目标可写成约束优化：

$$
\min_{\alpha} \ \mathcal{L}(\alpha) = \sum_{k=1}^{K} \lambda_k \, \mathbb{E}_{x \sim p_k}\left[ \ell_{\theta(\alpha)}(x) \right] \quad \text{s.t.} \quad \sum_k \alpha_k = 1,\ \alpha_k \ge 0
$$

其中 $\lambda_k$ 表达对各域的偏好。若 $\mathcal{L}$ 关于 $\alpha$ 可微，可用指数化参数 $\alpha_k = e^{z_k} / \sum_j e^{z_j}$ 做无约束投影梯度下降；在不可微（需重训）的情形下，则用乘性权重更新或分组相对损失启发式：

$$
\alpha_k^{(t+1)} \propto \alpha_k^{(t)} \cdot \exp\left( \eta \cdot \frac{\ell_k^{(t)} - \bar{\ell}^{(t)}}{\bar{\ell}^{(t)}} \right)
$$

即损失高于平均的域获得更高权重，然后重新归一化。

课程策略可抽象为随时间变化的配比 $\alpha(t)$，其学习效率可近似为

$$
L(T) \approx L_0 - \int_0^T \eta(t) \left\| \nabla_\theta L(\alpha(t)) \right\|^2 dt
$$

这说明课程的价值在于把"高信噪比的梯度"放在影响最大的时刻；退火阶段学习率趋近 0，此时数据分布对最终解的影响相对放大，因此高质量数据上采样收益显著。

重复数据的收益可建模为边际递减：设域 $k$ 重复 $r$ 轮后的有效增益为

$$
g_k(r) = 1 - e^{-\kappa r}
$$

则应在满足 $g'_k(r)/\mathrm{cost}_k$ 相等的分配点上停止增加重复。

## 四、代码实现

```python
# 依据缩放律在给定算力下估算最优参数量与数据量
# 注意：系数以 Hoffmann et al. 2022 原论文为准，此处仅演示结构
def optimal_allocation(compute_flops, a=0.5, b=0.5, k_n=0.1, k_d=20.0):
    # C ~ 6 N D；用 N ~ k_n * C^a, D ~ k_d * C^b 的对数尺度近似
    N = k_n * (compute_flops ** a)
    D = k_d * (compute_flops ** b)
    return N, D

N, D = optimal_allocation(1e22)
print("建议参数量(十亿):", round(N / 1e9, 2), "建议 token 数十亿:", round(D / 1e9, 1))
```

```python
# 按域权重采样：把 token 预算分配到各域，并处理数据不足时的重复
import random

def build_mix(domain_sizes, weights, total_tokens, max_repeat=4, seed=0):
    rng = random.Random(seed)
    # 第一步：按权重分配 token 预算
    budget = {k: int(total_tokens * w) for k, w in weights.items()}
    plan = {}
    for dom, need in budget.items():
        avail = domain_sizes[dom]
        repeat = need / max(avail, 1)
        if repeat > max_repeat:
            # 超出重复上限时，把多余预算按比例回流给权重未饱和的域
            need = int(avail * max_repeat)
        plan[dom] = min(need, int(avail * max_repeat))
    return plan, budget

sizes = {"web": 5_000_000_000, "books": 300_000_000, "code": 500_000_000, "math": 50_000_000}
weights = {"web": 0.60, "books": 0.15, "code": 0.20, "math": 0.05}
plan, budget = build_mix(sizes, weights, total_tokens=1_000_000_000)
print("实际 token 计划:", plan, "期望预算:", budget)
```

```python
# 简化的域权重自适应：损失高于均值的域提高权重，然后归一化
def adapt_weights(losses_by_domain, weights, lr=0.5):
    mean_loss = sum(losses_by_domain.values()) / len(losses_by_domain)
    new = {}
    for k, v in weights.items():
        rel = (losses_by_domain[k] - mean_loss) / max(mean_loss, 1e-9)
        new[k] = v * pow(2.718281828, lr * rel)   # exp(lr * 相对超出量)
    total = sum(new.values())
    return {k: v / total for k, v in new.items()}

w = {"web": 0.6, "code": 0.2, "math": 0.2}
losses = {"web": 2.10, "code": 2.35, "math": 2.80}
for step in range(5):
    w = adapt_weights(losses, w)
print("自适应后配比:", {k: round(v, 3) for k, v in w.items()})
```

## 五、与其他技术对比

| 维度 | 均匀混合 | 人工设定配比 | 自适应/优化配比（DoReMi 一类） |
|------|----------|--------------|--------------------------------|
| 成本 | 无额外成本 | 低（依赖经验） | 高（需多轮代理实验） |
| 目标对齐 | 弱 | 中 | 强 |
| 可解释性 | 强 | 强 | 弱（权重由优化得出） |
| 风险 | 稀释目标域 | 经验偏差 | 过拟合代理实验 |
| 适用阶段 | 冷启动基线 | 快速迭代 | 预算充足的大规模训练 |

| 课程策略 | 做法 | 优点 | 风险 |
|----------|------|------|------|
| 无课程（随机打乱） | 全程同分布 | 简单稳定 | 未利用难度结构 |
| 由易到难 | 先短文本/高质量后复杂 | 收敛快 | 后期简单分布欠拟合 |
| 退火上采样 | 末段换高质量数据 | 性价比高 | 需精确控制阶段比例 |
| 长度/难度课程 | 逐步增加序列长度 | 省算力 | 阶段切换可能损失稳定性 |

## 六、常见误区

- **只看数据量不看质量**：低质数据增加 token 数反而抬升损失，缩放律的前提是数据分布固定且质量可控。
- **配比静态不动**：训练后期的退火阶段调配比，边际收益往往高于前期大改。
- **相信小规模代理实验的绝对值**：代理实验只能给相对排序，绝对损失不可外推。
- **过度重复高质量数据**：重复超过一定轮次会引发记忆与评测污染。
- **把域权重优化当一次性的**：最优配比随模型规模与训练阶段变化，应周期性复核。
- **忽略去重与配比的交互**：未去重时某域"看似数据多"，实际独立样本远少于表面 token 数。
- **课程过强**：难度过滤太激进会导致模型从未见过复杂模式。

## 九、演进与趋势

配比策略从"均匀混合"走向"按能力目标优化"，再走向"随训练动态调整"。趋势上，一是**自动化配比**（以代理实验或在线损失信号驱动权重更新）逐步替代纯人工经验；二是**退火与阶段化训练**被普遍采用，末期数据质量成为拉开差距的关键；三是**合成与蒸馏数据**作为可定制域被纳入配比，缓解长尾领域数据稀缺；四是**数据效率指标**（达到目标损失所需 token 数）成为比"数据量"更核心的度量；五是**配比与评测联动**，用目标能力的验证损失而非全局损失来驱动权重更新。

## 十、小结

数据配比与课程是把"数据质量"转化为"模型能力"的最后一环。核心方法有三条：用缩放律在算力约束下决定参数与数据的总量；用域权重优化决定各来源的占比；用分阶段课程与退火上采样决定数据出现的时机。实践中应先建立均匀混合基线，再用小规模代理实验调整相对权重，并把调整重点放在训练末段；同时始终用去重后的独立样本量而非表面 token 数来计算配比。
