# 数据配比与课程策略

> 对应 Hoffmann 2022 Chinchilla 与 karpathy/nanoGPT。

## 一、背景与挑战
不同领域语料的配比与呈现顺序显著影响最终能力与收敛效率。

## 二、核心原理
按计算预算确定数据量，再对各域做比例采样，并可按训练阶段调整课程。

## 三、形式化与数学基础
Chinchilla 缩放：
$ N \approx 20 C^{0.5}, \quad D \approx 20 C^{0.5} $
N 参数量，D 数据量，C 算力。

## 四、代码实现
```python
def chinchilla(C):
    # C 单位为 FLOPs 的指数
    return 20 * C ** 0.5
```

## 五、与其他技术对比
均匀混合简单但未必最优，领域加权需实验支撑。

## 六、常见误区
盲目追数据量忽略质量；配比静态不调。

## 七、与开源书/权威来源对应
Hoffmann 2022 给出算力-数据-参数关系；karpathy/nanoGPT 数据配比实践。

## 八、面试题
如何在固定预算下分配数据与参数？

## 九、演进与趋势
动态数据课程与在线配比优化。

## 十、小结
配比与课程是把数据质量转化为模型能力的关键。
