# 毒性与隐私过滤

> 对应 Gehman et al. 2020《RealToxicityPrompts: Evaluating Neural Toxic Degeneration in Language Models》、Bender et al. 2021《On the Dangers of Stochastic Parrots》（数据文档与伦理）、Carlini et al. 2021《Extracting Training Data from Large Language Models》（记忆与泄露）、Dodge et al. 2021《Documenting the English Colossal Clean Crawled Corpus》（C4 文档化），以及 HuggingFace transformers 与 presidio 一类 PII 工具。

## 一、背景与挑战

网页语料天然包含仇恨言论、暴力描述、色情内容与诈骗信息；同时大量页面夹带邮箱、电话、身份证号、住址、银行账号等个人敏感信息（PII）。不做处理直接训练，会带来两类后果：一是模型在开放域生成有害内容，二是模型**记忆并复述**训练数据中的隐私片段——后者已被 Carlini 等人的抽取攻击系统验证，属于实打实的合规风险。

挑战在于三个"不确定"：**边界不确定**——什么是有害，随文化、语境、时代变化，医学讨论与仇恨言论在字面上可能很接近；**成本不确定**——对 TB 级语料跑深度分类模型代价高昂；**副作用不确定**——过度过滤会同时删掉关于有害现象的研究、新闻与教育性内容，反而削弱模型理解与反驳有害内容的能力，并加剧对少数群体话语的抹除。

## 二、核心原理

**毒性过滤**通常分三层：

1. **词表/正则层**：黑名单与正则，速度快、可解释，但只能抓显式脏话，且无法处理拼写变体与隐晦表达。
2. **分类模型层**：用标注数据（如 Jigsaw 一类公开毒性标注）训练的分类器输出毒性概率 $p_{\mathrm{tox}}(d)$，再按阈值过滤：

$$
\mathrm{keep}(d) = \mathbb{1}\left[ p_{\mathrm{tox}}(d) < \tau \right]
$$

3. **上下文校正层**：为降低对少数群体相关话题的误判（讨论身份认同本身不是有毒），引入"身份提及"信号做联合判断，或对该子集使用不同阈值。

**隐私过滤**分两条路径：

- **去标识化（redaction）**：识别 PII 后用占位符替换，保留句子结构：

$$
d' = \mathrm{Replace}(d, \mathrm{PII}(d), [\mathrm{MASK}])
$$

- **直接删除**：整篇丢弃 PII 密度过高的文档（如通讯录页、简历聚合页）。

PII 识别手段包括正则（邮箱、电话、身份证、信用卡号的格式特征）、命名实体识别（人名、地名、机构名）以及上下文校验（用 Luhn 算法校验卡号、检查邮箱域名合法性）以降低误报。

**重识别风险**需要单独评估：即使遮蔽了姓名，剩余的准标识符组合（邮编 + 生日 + 性别）仍可能定位到个人。这是单纯替换姓名不足以称为"匿名化"的原因。

## 三、形式化与数学基础

**保留率与误杀的权衡。** 设文档总数 $N$，毒性分数 $s(d)$，阈值 $\tau$ 下保留率为

$$
R(\tau) = \frac{|\{ d : s(d) < \tau \}|}{N}
$$

分类器的两类错误分别为误杀（高质量但被删）与放过（有害但保留）。以 $F_{\mathrm{FN}}(\tau)$ 与 $F_{\mathrm{FP}}(\tau)$ 表示其数量，则目标函数为

$$
\min_{\tau} \ \mathcal{L}(\tau) = c_{\mathrm{over}} \cdot F_{\mathrm{FP}}(\tau) + c_{\mathrm{under}} \cdot F_{\mathrm{FN}}(\tau)
$$

由于放过有害内容的合规代价 $c_{\mathrm{under}}$ 通常远大于误杀代价 $c_{\mathrm{over}}$，最优阈值会显著偏向严格一侧；但 $c_{\mathrm{over}}$ 并非为零，过度过滤会引入分布偏移。

**阈值选择可用 ROC 曲线表达**：设真阳性率 $\mathrm{TPR}$ 与假阳性率 $\mathrm{FPR}$，在代价不对称下最优工作点满足

$$
\frac{d\,\mathrm{TPR}}{d\,\mathrm{FPR}} = \frac{c_{\mathrm{over}} \cdot N_{\mathrm{neg}}}{c_{\mathrm{under}} \cdot N_{\mathrm{pos}}}
$$

即 ROC 曲线上斜率等于该比值处为最优点，而非默认的约登指数点。

**记忆与泄露的风险量化。** 设某敏感片段在训练语料中出现 $k$ 次，模型参数量为 $N$，经验上抽取风险随重复次数与模型容量上升，可形式化为对片段的暴露量（exposure）：

$$
\mathrm{Exposure}(s) = \log_2 \frac{1}{p_\theta(s \mid c)} - \min_{s'} \log_2 \frac{1}{p_\theta(s' \mid c)}
$$

值越大说明该片段相对其他候选异常"容易生成"，即被记忆。去重与降低重复次数 $k$ 是降低暴露量最直接的手段：

$$
\Pr[\text{可抽取}] \ \uparrow \ \text{with} \ k \ \text{and} \ N
$$

**差分隐私视角。** 若训练过程满足 $(\epsilon, \delta)$-差分隐私，则任意单条训练样本对输出分布的影响被约束为

$$
\Pr[\mathcal{M}(D) \in S] \le e^{\epsilon} \Pr[\mathcal{M}(D') \in S] + \delta
$$

其中 $D$ 与 $D'$ 相差一条记录。DP-SGD 通过梯度裁剪与加噪实现该保证，代价是计算开销与一定的效用损失。数据清洗层面的去标识化是"尽力而为"，DP 才是可证明的保证，两者定位不同。

**PII 遮蔽的效用损失**可用占位符比例刻画：

$$
\mathrm{UtilityLoss}(d) = \frac{\mathrm{tokens}(d \cap \mathrm{PII})}{\mathrm{tokens}(d)}
$$

超过一定比例后句子已不可用，应整篇删除而非替换。

## 四、代码实现

```python
# 第一层：正则识别常见 PII，按类型替换为占位符
import re

PII_PATTERNS = {
    # 邮箱：本地部分 + @ + 域名（含多级后缀）
    "EMAIL": re.compile(r"[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}"),
    # 中国大陆手机号（示例规则，实际应以业务地区为准）
    "PHONE_CN": re.compile(r"(?<!\d)1[3-9]\d{9}(?!\d)"),
    # 身份证号：18 位，末位可能为 X
    "ID_CN": re.compile(r"(?<!\d)\d{17}[\dXx](?!\d)"),
    # 银行卡：13-19 位数字，前后不得再接数字，降低误报
    "BANK": re.compile(r"(?<!\d)\d{13,19}(?!\d)"),
    # IPv4
    "IPV4": re.compile(r"(?<!\d)(?:\d{1,3}\.){3}\d{1,3}(?!\d)"),
}

def redact_pii(text, max_mask_ratio=0.1):
    total = max(len(text), 1)
    masked = 0
    for name, pat in PII_PATTERNS.items():
        def _sub(m):
            nonlocal masked
            masked += len(m.group(0))
            return f"[{name}]"
        text = pat.sub(_sub, text)
    # 遮蔽比例过高的文档结构已被破坏，应整篇丢弃
    if masked / total > max_mask_ratio:
        return None
    return text
```

```python
# 第二层：毒性分类器打分，按阈值过滤
import torch
from transformers import AutoTokenizer, AutoModelForSequenceClassification

TOX_MODEL = "unitary/toxic-bert"    # 仅为示意，选型需按语种与场景评估
tox_tok = AutoTokenizer.from_pretrained(TOX_MODEL)
tox_model = AutoModelForSequenceClassification.from_pretrained(TOX_MODEL).eval()

@torch.inference_mode()
def toxicity_scores(texts, batch_size=32, max_len=512):
    scores = []
    for i in range(0, len(texts), batch_size):
        enc = tox_tok(texts[i:i + batch_size], truncation=True,
                      max_length=max_len, padding=True, return_tensors="pt")
        logits = tox_model(**enc).logits
        # 多标签模型取 sigmoid；二分类模型改用 softmax，需按模型卡确认
        scores.extend(torch.sigmoid(logits).max(dim=-1).values.tolist())
    return scores

def keep_non_toxic(texts, tau=0.5):
    scores = toxicity_scores(texts)
    return [t for t, s in zip(texts, scores) if s < tau], scores
```

```python
# 组合：先遮蔽 PII，再过滤毒性，并记录各步淘汰率
def safety_pipeline(docs, tau=0.5):
    stats = {"input": len(docs)}
    redacted, dropped_pii = [], 0
    for d in docs:
        r = redact_pii(d)
        if r is None:
            dropped_pii += 1
        else:
            redacted.append(r)
    kept, scores = keep_non_toxic(redacted, tau=tau)
    stats.update({
        "dropped_by_pii_ratio": dropped_pii,
        "after_redaction": len(redacted),
        "after_toxicity": len(kept),
        "retention": len(kept) / max(stats["input"], 1),
    })
    return kept, stats, scores
```

## 六、常见误区

- **只过滤显式脏话**：隐晦仇恨、暗示性暴力、诈骗话术不会被词表命中，必须靠分类器与人工抽检。
- **过度遮蔽破坏语言自然度**：满屏 `[EMAIL]` 的句子会教会模型生成占位符，应设定遮蔽比例上限并整篇删除超标点。
- **认为替换姓名即匿名化**：邮编 + 生日 + 性别等准标识符组合仍可重识别，需评估组合风险。
- **对少数群体话题一刀切**：同一阈值会导致身份相关讨论被系统性删除，应分集校准阈值。
- **忽略记忆泄露**：过滤有害内容不等于防止隐私复述，去重与降低重复次数才是关键手段。
- **只做一次过滤**：合成数据、用户反馈数据与增量语料都会引入新风险，过滤需持续运行。
- **把数据过滤当万能**：输出侧的安全对齐与内容审核同样必要，二者不能互相替代。

## 七、与开源书·权威来源对应

- Gehman et al. 2020《RealToxicityPrompts》：系统评估语言模型的毒性退化，说明预训练语料中的有害内容会直接转化为生成风险。
- Bender et al. 2021《On the Dangers of Stochastic Parrots》：论证数据规模不等于正当性，强调语料文档化与伦理审查。
- Carlini et al. 2021《Extracting Training Data from Large Language Models》：证明大模型会记忆并复述训练数据，是隐私过滤必要性的直接依据。
- Carlini et al. 2022《The Privacy Onion Effect / Quantifying Memorization》与《Membership Inference》相关工作：给出记忆与重复次数、模型规模关系的量化方法。
- Dodge et al. 2021《Documenting the English Colossal Clean Crawled Corpus》（C4 文档化）：展示如何记录语料来源、过滤步骤与已知偏差，是可审计性的范本。
- Abadi et al. 2016《Deep Learning with Differential Privacy》：DP-SGD 的原始论文，给出可证明隐私保证的训练方法。
- Dwork & Roth《The Algorithmic Foundations of Differential Privacy》与 Sweeney 2002（k- anonymity）：隐私定义与去标识化的经典基础。
- OWASP LLM Top 10：把敏感信息泄露与不安全输出处理列为大模型应用的关键风险项。
- HuggingFace transformers（pipeline("text-classification")）与 presidio 一类 PII 工具：工程实现的常用载体。

## 九、演进与趋势

实践从"黑名单过滤"走向"分类器 + 语境校正"，再走向"数据治理 + 可证明隐私"。趋势上，一是**语境感知过滤**替代纯关键词/句级判断，降低对少数群体话题的误杀；二是**记忆导向的过滤**，按暴露量而非内容类别优先删除高重复敏感片段；三是**差分隐私训练**从研究走向可工程化（尽管效用损失仍是主要障碍）；四是**合成与脱敏数据**用于替代高风险真实数据；五是**可审计成为硬要求**，数据卡片、过滤记录与保留率统计成为交付物的一部分。

## 十、小结

毒性与隐私过滤是合规训练的前置条件，而非可选项。有效的做法是三层组合：正则与词表做廉价高召回的 PII 遮蔽、分类模型做毒性打分并按分集校准阈值、人工抽检持续验证误杀与漏报。同时必须意识到两点边界：遮蔽不等于匿名化（准标识符仍可重识别），过滤有害内容不等于防止记忆泄露（还需去重与 DP）。所有处理步骤都应记录阈值、模型版本与淘汰率，以便审计与复现。
