# 毒性与隐私过滤

> 对应 huggingface/transformers 与 Sennrich 2016 BPE。

## 一、背景与挑战
语料含有害内容与个人敏感信息，需在训练前过滤以防模型记忆泄露。

## 二、核心原理
用毒性分类器筛除有害文档，用正则与实体识别遮蔽邮箱、电话等 PII。

## 三、形式化与数学基础
保留率：
$ R = \frac{|\{d: \text{safe}(d)\}|}{N} $

## 四、代码实现
```python
def keep_safe(docs, toxic_clf, tau=0.5):
    return [d for d in docs if toxic_clf(d) < tau]
```

## 五、与其他技术对比
规则快但有漏，模型准但需算力；常二者结合。

## 六、常见误区
只过滤显式脏话忽略隐含有害；过度遮蔽破坏语言自然度。

## 七、与开源书/权威来源对应
huggingface/transformers 分类管线；Sennrich 2016 讨论清洗与 BPE。

## 八、面试题
如何平衡隐私遮蔽与语料可用性？

## 九、演进与趋势
差分隐私与去标识化结合。

## 十、小结
毒性与隐私过滤是合规训练的前置条件。
