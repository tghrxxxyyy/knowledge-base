# 矩阵乘累加到TensorCore

> 对应 GEMM 在 Tensor Core 的执行（WMMA/CMA 指令）。

## 一、背景与挑战

大模型推理本质是批量 GEMM，需最大化 TC 占用率与吞吐。

## 二、核心原理

矩阵被分块（tile）喂给 TC，多 SM 并行；为使 TC 饱和，需足够大 M/N/K 与良好内存布局（避免 bank 冲突），并配合双缓冲隐藏访存。

## 三、数学形式

吞吐 $=\frac{2MNK}{\text{time}}$；TC 峰值由每周期乘加数与时钟决定，实际受带宽/占用限制。

## 四、代码实现

```python
# Triton/CMA 风格分块
acc += tl.dot(A_tile, B_tile)   # 走 Tensor Core
```

## 五、与其他对比

- 与 Triton内核自动调优深入：Triton 自动生成 TC 代码。
- 与 推理CUDA图优化深入：GEMM 内核可入图。

## 六、常见误区

- 小块 GEMM 占不满 TC（利用率低）。
- 忽视 K 维度对齐到 TC 块尺寸。

## 八、面试题

- 为何要分块喂 TC？答：TC 按固定小矩阵块运算，分块并行才能打满多 SM。

## 九、演进

CUDA Core GEMM → TC GEMM → 稀疏 TC。

## 十、小结

GEMM 到 TC 的分块与占用优化，是推理算力榨取的核心。
