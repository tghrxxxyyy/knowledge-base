# FP16与BF16推理

> 对应混合精度训练/推理（Micikevicius et al., 2018）；BF16 见 NVIDIA Ampere+。

## 一、背景与挑战

FP16 范围窄易溢出/舍入；BF16 指数位同 FP32、动态范围大，更适合易出大值的注意力/归一化。

## 二、核心原理

FP16 为 5 指数位、BF16 为 8 指数位（同 FP32）；推理权重/激活常以 BF16 存算，关键累加/softmax 用 FP32 保稳定。

## 三、数学形式

FP16 动态范围约 $[6e-5, 6e4]$；BF16 约 $[1e-38, 3e38]$；softmax 指数需大范围故宜 FP32。

## 四、代码实现

```python
w_bf16 = w.half() if fp16 else w.to(torch.bfloat16)
attn = (q@k.t()*scale).softmax(-1)
```

## 五、与其他对比

- 与 INT8 相比，BF16 几乎无损、更易部署。
- 与 张量核心与混合精度推理深入 总览：两者为精度选择。

## 六、常见误区

- 全程 FP16 致 softmax/logits 溢出。
- 误以为 BF16 精度高于 FP16（尾数反而更短）。

## 八、面试题

- BF16 相对 FP16 优势？答：指数范围同 FP32，不易溢出，注意力更稳，精度略降。

## 九、演进

FP32 → FP16 → BF16 → FP8。

## 十、小结

BF16 在范围与易用间平衡，是 LLM 推理默认低精度格式。
