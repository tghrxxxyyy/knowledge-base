# 张量核心总览

> 对应 NVIDIA Tensor Cores（Volta 起）与混合精度推理实践。

## 一、背景与挑战

Transformer 推理以矩阵乘为主，FP32 CUDA Core 吞吐不足；Tensor Core 专做乘加矩阵块，需低精度输入换取高吞吐。

## 二、核心原理

Tensor Core 执行 $D=A\times B + C$ 的小矩阵块（如 4x4 或 16x16），输入为 FP16/BF16/INT8，累加用 FP32，单指令多数据大幅提算力密度。

## 三、数学形式

累积 $D_{m,n}=\sum_k A_{m,k}B_{k,n}+C_{m,n}$，块内并行；峰值 $\propto \text{blocks}\times \text{rate}$。

```python
    y = x @ w
```

## 六、常见误区

- 以为 FP32 也能用 TC 加速（多数 TC 需低精度输入）。
- 忽视累加 FP32 防溢出。

## 八、面试题

- Tensor Core 为何快？答：硬件级矩阵块乘加，低精度输入高吞吐、FP32 累加。

## 九、演进

FP16 TC → BF16/INT8 TC → 稀疏 TC。

## 十、小结

Tensor Core 以低精度矩阵块乘加提供推理算力主体，是混合精度基础。
