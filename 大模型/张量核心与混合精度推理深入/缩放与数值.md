# 缩放因子与数值稳定

> 对应混合精度缩放（loss scaling 思路延伸到推理）。

## 一、背景与挑战

低精度下大值溢出、小值舍入，需合适缩放与高精度累加保持数值稳定。

## 二、核心原理

推理通常不训故不需 loss scaling，但 softmax/层归一化/累加器仍用 FP32；量化需标定缩放 $s$ 使可表示范围覆盖张量极值。

## 三、数学形式

标度 $s=\max(|x|)/(2^{b-1}-1)$；累加 $\sum$ 用 FP32 防中点误差累积。

## 四、代码实现

```python
acc = x.float() @ w.float()      # FP32 累加
out = acc.to(dtype)
```

## 五、与其他对比

- 与 FP16/BF16 节：范围问题同源。
- 与 INT8量化节：缩放即量化参数。

## 六、常见误区

- 在 FP16 累加长序列致误差累积。
- 缩放标定用全量统计致 outlier 拉垮分辨率。

## 八、面试题

- 为何累加用 FP32？答：低精度累加误差随项数累积，FP32 保长序列/大矩阵稳定。

## 九、演进

全 FP16 累加 → FP32 累加 → 结合量化标定。

## 十、小结

缩放与高精度累加是混合精度数值稳定的两道保险。
