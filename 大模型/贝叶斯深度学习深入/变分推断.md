# 变分推断

> 见「贝叶斯深度学习深入/贝叶斯神经网络」；Blei et al., *Variational Inference*, 2017。

## 一、背景与挑战

贝叶斯积分难解，变分法用可解分布族逼近后验。

## 二、核心原理

选参数族 `q_φ(w)` 最小化与真实后验的 KL：
```
min_φ KL(q_φ(w) ‖ p(w|D))
```
等价于最大化 ELBO。深度学习中 BBB、VAE 都用此范式。

## 三、数学形式

ELBO = `E_q[log p(D|w)] - KL(q_φ‖p)`。

## 四、代码实现

```python
elbo = loglik - kl_weight * kl(q, prior)
elbo.backward()
```

## 五、关键要点

- 选族决定近似质量。
- 重参数化使可微。

## 六、与其他对比

- MCMC 精确但慢；变分快但近似。

## 七、常见误区

- 变分=精确——只是近似。
