# 贝叶斯深度学习总览

> 对应 d2l-zh；MacKay, *Bayesian Methods*；Neal, *Bayesian Neural Nets*, 1995；Gal, *Uncertainty*, 2016。

## 一、背景与挑战

标准网络只给点预测，无置信度；高风险场景（医疗/自动驾驶）需知道「模型有多不确定」。

## 二、核心原理

贝叶斯视角把权重视为分布 `p(w|D)`，预测时对权重积分：
```
p(y*|x*) = ∫ p(y*|x*, w) p(w|D) dw
```
用后验近似（变分/MC Dropout/集成）获得预测分布与不确定性。

## 三、数学形式

见上积分；后验 `p(w|D) ∝ p(D|w)p(w)`。

## 四、代码实现

```python
# MC Dropout：推理期保留 dropout 多次前向
preds = torch.stack([model(x) for _ in range(T)])
mean, var = preds.mean(0), preds.var(0)
```

## 五、关键要点

-  epistemic（模型）不确定性随数据增多下降；aleatoric（数据）不确定性固有。
- 校准（calibration）指预测置信度与真实准确率一致。

## 六、与其他对比

- 点估计无不确定性；贝叶斯给分布。

## 七、常见误区

- 高 softmax 概率=确定——未校准时不可信。
