# 不确定性校准

> 见「贝叶斯深度学习深入/贝叶斯深度学习总览」；Guo et al., *On Calibration*, 2017。

## 一、背景与挑战

模型输出概率未必反映真实正确率，需校准。

## 二、核心原理

校准指：置信度 p 的样本中有约 p 比例正确。常用 **Platt scaling / Temperature scaling**：在验证集上学一个温度 T 缩放 logits 使 Brier score/ECE 最小。现代大模型常过置信（over-confident），需校准。

## 三、数学形式

ECE = `Σ_b |B_b|/n · |acc(B_b) - conf(B_b)|`。

## 四、代码实现

```python
logits = logits / T  # T 由验证集优化
```

## 五、关键要点

- 大规模预训练模型更需校准。
- 温度缩放简单有效且不损精度。

## 六、与其他对比

- 准确率看对不对；校准看信不信得准。

## 七、常见误区

- 高准确率即校准——未必。
