# 混合检索与倒数排名融合

> 对应 run-llama/llama_index 混合检索器与 Lewis et al. 2020《RAG》。

## 一、背景与挑战
单一检索器各有盲区。混合检索并行运行稀疏与稠密检索，再融合结果以取长补短，无需额外训练重排器即可增效。

## 二、核心原理
对各检索器返回的排名列表做 Reciprocal Rank Fusion（RRF）：每个文档得分按其在各列表中的排名倒数累加。RRF 不依赖原始分数尺度，仅用排名，鲁棒性好。

## 三、形式化与数学基础
RRF 分数：
$\text{RRF}(d) = \sum_{r \in R} \frac{1}{k + \text{rank}_r(d)}$
其中 R 为检索器集合，$\text{rank}_r(d)$ 为文档 d 在第 r 个列表中的排名，k 为常数（常 60）防止头部过权。

## 四、代码实现
```python
def rrf(lists, k=60):
    score = {}
    for lst in lists:               # lst: 文档列表按相关度排序
        for rank, doc in enumerate(lst):
            score[doc] = score.get(doc, 0.0) + 1.0/(k + rank + 1)
    return sorted(score, key=score.get, reverse=True)
```

## 五、与其他技术对比
相比加权分数融合，RRF 免尺度对齐、实现简单；相比交叉编码器重排，它不引入大模型、延迟低，但精细度稍弱，常作为重排前的融合层。

## 六、常见误区
误区一：直接把 BM25 分数与向量分数相加，量纲不同会偏废一方。误区二：k 取 1 使头部过度主导。

## 七、与开源书/权威来源对应

## 九、演进与趋势
融合策略从 RRF 走向可学习加权（如根据查询类型路由），并与重排级联形成多级融合。

## 十、小结
混合检索以低成本显著提升召回稳健性，是生产 RAG 的默认选择。
