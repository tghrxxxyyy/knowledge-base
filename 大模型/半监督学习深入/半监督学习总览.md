# 半监督学习总览

> 对应 d2l-zh 半监督章；Chapelle et al., *Semi-Supervised Learning*, 2006；综述。

## 一、背景与挑战

标注少、无标注多，如何借无标签提升？

## 二、核心原理

假设：**平滑性**（近邻同标签）、**聚类**（同簇同标签）、**流形**（流形上近者同标）。方法：自训练/伪标签、一致性正则、图半监督、生成式（SSLVAE）。

## 三、关键要点

- 无标签须与任务相关。
- 错误伪标签会自我强化（确认偏差）。

## 四、代码实现

```python
pseudo = model(unlabeled).argmax(1)
loss = sup_loss + λ * ce(model(x_u), pseudo.detach())
```
