# 半监督与大模型

> 见「半监督学习深入/半监督学习总览」；大模型预训练即大规模半监督。

## 一、背景与挑战

大模型以海量无标签文本自监督，本质是极致半监督。

## 二、核心原理

预训练（自监督）提供通用表征，少量标注 SFT/微调即适配任务——这正是半监督范式的规模化体现。RLHF 中奖励模型也用少量人类偏好标注 + 大量无标注候选。

## 三、关键要点

- 自监督=无标签预训练。
- SFT/指令数据即少量有标签。
- 伪标签用于蒸馏小模型。

## 四、代码实现

```python
pretrain_lm(corpus_unlabeled)        # 半监督之"半"
sft(model, labeled_instructions)     # 之"监督"
```

## 五、与其他对比

- 经典半监督小规模；大模型超大规模。

## 六、常见误区

- 预训练不需标签——它用自监督标签。
