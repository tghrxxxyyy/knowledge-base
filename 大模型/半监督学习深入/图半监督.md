# 图半监督

> 见「半监督学习深入/半监督学习总览」与「图神经网络深入/图神经网络总览」；Kipf & Welling, *GCN (SSL)*, 2016。

## 一、背景与挑战

节点只有部分有标签，如何传播到全图？

## 二、核心原理

GCN/图卷积天然做标签传播：邻域聚合使相连节点表征相近，半监督仅靠少量标签节点即可使同类节点聚拢。损失仅在有标签节点计算。

## 三、数学形式

`L = Σ_{i∈labeled} CE(f(x_i), y_i)`，表征经多层传播。

## 四、代码实现

```python
out = gcn(x, edge_index)
loss = ce(out[labeled_idx], y[labeled_idx])
```

## 五、关键要点

- 图结构即正则。
- 异配图（相连不同类）失效。

## 六、与其他对比

- 图传播依赖拓扑；一致性靠增广。

## 七、常见误区

- 图半监督万能——异配图不行。
