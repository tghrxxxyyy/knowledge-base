# 一致性正则

> 见「半监督学习深入/半监督学习总览」；Sohn et al., *FixMatch*, 2020；Laine & Aila, *Temporal Ensembling*, 2016。

## 一、背景与挑战

无标签样本无损失信号，如何让模型对其稳定？

## 二、核心原理

对同一样本的不同增广，模型输出应一致（或对齐教师预测）。FixMatch：弱增广预测作伪标签，强增广预测向其对齐，仅高置信保留。核心是「增广不变性」约束。

## 三、数学形式

`L_u = 1( max(q_w) ≥ τ ) · CE(q_w, q_s)`，q 为强弱增广输出。

## 四、代码实现

```python
q_w = model(weak(x)); q_s = model(strong(x))
loss_u = (q_w.max(1) > tau) * ce(q_s, q_w.argmax(1))
```

## 五、关键要点

- 弱增广稳、强增广难，二者对齐有效。
- 阈值 τ 关键。

## 六、与其他对比

- 伪标签用预测；一致性用对齐。

## 七、常见误区

- 增广随意——需保语义。
