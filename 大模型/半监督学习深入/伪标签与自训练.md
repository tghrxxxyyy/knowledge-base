# 伪标签与自训练

> 见「半监督学习深入/半监督学习总览」；Lee, *Pseudo-Label*, 2013；大模型蒸馏常用。

## 一、背景与挑战

如何用模型自身预测扩充标注？

## 二、核心原理

自训练：用当前模型对无标签数据打伪标签（取高置信预测），把它们当真标签加入训练，迭代。配以**置信度阈值/温度锐化**过滤低质伪标签。LLM 蒸馏（如用强模型标注弱模型训练）本质即伪标签。

## 三、数学形式

`ŷ_u = argmax f_θ(x_u)`，仅当 `max p > τ` 采用。

## 四、代码实现

```python
with torch.no_grad():
    pu = softmax(model(xu)/T)
mask = pu.max(1) > tau
loss = ce(model(xu[mask]), pu[mask].argmax(1))
```

## 五、关键要点

- 阈值平衡覆盖与精度。
- 需防确认偏差（错标固化）。

## 六、与其他对比

- 一致性不强加标签；伪标签强加。

## 七、常见误区

- 伪标签越多越好——噪声累积。
