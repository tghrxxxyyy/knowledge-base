# 分词与压缩率

> 工程成本视角。

## 一、背景与挑战

token 数直接决定 API 成本与推理延迟。不同语言/分词器压缩率差异巨大：英文约 4 字符/token，中文约 1.5-2 字符/token(即中文更“贵”)。

## 二、核心原理

压缩率 = 字符数 / token 数。词表覆盖越好的语言压缩率越高。

## 三、关键要点

| 语言 | 约 token/词 |
|------|------------|
| 英文 | ~0.75 词/token |
| 中文 | ~1.5-2 字符/token |
| 代码 | 中等 |

## 四、常见误区

- 误用“字数”估算成本，正确用 token 数。

## 五、与开源书对应

- tiktoken 文档：https://github.com/openai/tiktoken

## 六、面试题

- 为何中文调用大模型成本常高于英文？

## 七、小结

选型与成本评估应以 token 为准，中文场景需特别关注分词效率。
