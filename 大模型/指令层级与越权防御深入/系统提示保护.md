# 系统提示保护

> 对应 Wallace et al., 2024；Chen et al., *StruQ*, 2024。

## 一、背景与挑战

系统提示承载不可违背规则，易被用户消息淹没或覆盖。

## 二、核心原理

训练时构造越权样本（用户假冒系统）做对齐；推理时用分隔符与角色边界强制系统指令占优。

## 三、数学形式

对齐损失加越权惩罚 $\mathcal L=\mathcal L_{task}+\lambda \mathcal L_{priv}$，priv 惩罚误从低层。

## 四、代码实现

```python
loss = task_loss + lam * privilege_viol_loss
```

## 五、与其他对比

- 与 StruQ与分隔防御共享边界。
- 与指令层级总览共享层级。

## 六、常见误区

- 仅推理加分隔不训练仍易越。
- 系统提示含机密致泄露面。

## 八、面试题

- 如何保护系统提示？答：训练越权样本对齐+结构分隔+角色边界强制。

## 九、演进

纯文本 → 对抗训练 → 结构分隔。

## 十、小结

系统提示需训练与结构双重保护方不可越。
