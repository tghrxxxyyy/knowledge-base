# 越权攻击面

> 对应 Perez & Ribeiro, 2022；Greshake et al., *Not What You've Signed*, 2023（工具注入）。

## 一、背景与挑战

提示注入多来自用户文本或 Retrieval/工具返回内容，伪装成系统指令劫持行为。

## 二、核心原理

攻击分直接注入（用户说忽略上文）与间接注入（外部文档含恶意指令）；工具链放大面。

## 三、数学形式

注入成功率 $P(success)=\mathbb 1[\text{model follows } m_{adv}\text{ from } L_{user}]$。

## 四、代码实现

```python
if "ignore previous" in tool_out:
    quarantine(tool_out)
```

## 五、与其他对比

- 与指令层级总览共享层级。
- 与安全与能力权衡深入共享风险面。

## 六、常见误区

- 只防直接注入漏间接注入。
- 黑名单关键词易被绕。

## 八、面试题

- 直接 vs 间接注入？答：直接来自用户输入，间接来自检索/工具返回，后者面更大。

## 九、演进

直接 → 间接 → 多通道组合。

## 十、小结

越权面随工具链扩大，须全链路防御。
