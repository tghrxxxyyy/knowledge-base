# 沙箱与权限隔离

> 对应 Debenedetti et al., *Defending Against Indirect Prompt Injection*, 2024；工具调用隔离实践。

## 一、背景与挑战

工具返回不可信，需隔离其影响域，避免跨工具污染与越权执行。

## 二、核心原理

工具输出视作数据非指令；权限最小化、结果只回传请求方、对敏感操作二次确认。

## 三、数学形式

策略仅允许动作 $a\in A_{perm}(role)$；越权动作概率被截断为 0。

## 四、代码实现

```python
if action not in allowed[role]:
    deny(action)
```

## 五、与其他对比

- 与越权攻击面共享工具注入。
- 与指令层级总览共享权限。

## 六、常见误区

- 工具结果当指令执行。
- 全局权限过大无最小集。

## 八、面试题

- 工具返回为何不可信？答：可被间接注入，须当数据并限权限。

## 九、演进

无隔离 → 权限分级 → 沙箱执行。

## 十、小结

权限最小与隔离是工具链安全底线。
