# 梯度爆炸导致训练发散

> 对应 Pascanu 2013《On the difficulty of training Recurrent Neural Networks》与 pytorch/pytorch `clip_grad_norm_`。

## 一、背景与挑战

深度网络的反向传播是链式法则的连乘。当权重矩阵的谱范数持续大于 1，梯度范数会随层数（或时间步）指数增长，一步更新就把参数抛到损失曲面的极端区域，loss 随即变为 NaN，且往往不可恢复。

与「梯度消失」相反，梯度爆炸的特征是**突发性**：前一步还正常，下一步 grad_norm 骤升数个量级。若没有梯度范数记录，工程师只能看到 loss 突然变 NaN，无法区分是爆炸、溢出还是坏样本，白白丢失定位线索。

## 二、核心原理

梯度爆炸的根源在于反向传播中雅可比矩阵的连乘。若各层雅可比谱半径均值 $\rho > 1$，$L$ 层的梯度幅度约为 $\rho^L$。这让长序列 RNN、极深 Transformer 与不稳定初始化都成为高发场景。

工程上有两类防线：

1. **预防**：归一化（LayerNorm/RMSNorm）、残差连接、合理初始化（如 $\mathcal{N}(0, 1/\sqrt{d})$）、warmup 让早期更新平缓。
2. **兜底**：梯度裁剪（gradient clipping），把更新幅度约束在阈值内，即使梯度爆炸也只造成有界步长。

按范数裁剪与按值裁剪是两种常见形式；实践中按**全局 L2 范数**裁剪更符合几何直觉，因为它约束的是整个更新向量的方向与长度。

## 三、形式化与数学基础

设第 $l$ 层权重为 $W_l$，梯度递推为 $g_l = W_{l+1}^\top g_{l+1} \odot \sigma'(z_l)$，其范数上界满足：

$$
\|g_l\| \le \prod_{k>l} \|W_k\|_2 \cdot \sup|\sigma'| \cdot \|g_{\text{top}}\|
$$

当 $\prod \|W_k\|_2 > 1$ 时随深度指数增长。按全局 L2 范数裁剪：

$$
\|g\|_2 = \sqrt{\sum_i \|g_i\|_2^2},\qquad
g \leftarrow \begin{cases} g, & \|g\|_2 \le C \\ \dfrac{C}{\|g\|_2 + \epsilon}\, g, & \|g\|_2 > C \end{cases}
$$

裁剪后有效步长有界：$\|\Delta\theta\| = \eta\|\hat{g}\| \le \eta C$，即学习率 $\eta$ 与阈值 $C$ 共同决定单步最大位移，把「灾难性跳跃」变成「有界推进」。$\epsilon$ 用于避免除零并使裁剪在阈值附近平滑。

## 四、代码实现

```python
# 监控 + 裁剪：把 grad_norm 作为首要健康指标
import torch

def step_with_clip(model, opt, loss, max_norm=1.0):
    opt.zero_grad()
    loss.backward()

    # 返回裁剪前的总范数，用于监控与告警
    gnorm = torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm)

    if not torch.isfinite(gnorm):
        # 已出现 inf/NaN，跳过本步，避免污染权重
        opt.zero_grad()
        return float("nan"), True

    opt.step()
    return gnorm.item(), False
```

## 五、与其他技术对比

| 手段 | 作用位置 | 是否能根除爆炸 | 代价 |
| --- | --- | --- | --- |
| 梯度裁剪（按范数） | 反向更新端 | 否，仅兜底 | 极小，一次归约 |
| 梯度裁剪（按值） | 反向更新端 | 否，逐元素截断破坏方向 | 极小，但偏离真实梯度 |
| LayerNorm/RMSNorm | 前向 | 抑制尺度漂移 | 少量计算 |
| 残差连接 | 前向/反向 | 缩短梯度路径 | 几乎无 |
| 合理初始化 + warmup | 训练初期 | 降低早期爆炸概率 | 无 |
| 自适应优化器 | 更新端 | 部分缓解 | 需正确配置 |

## 六、常见误区

- **只在事后看 loss**：应持续记录 grad_norm，它是爆炸的先兆指标。
- **裁剪阈值拍脑袋**：$C$ 过小会限制学习、过大等于没裁，应结合 grad_norm 分布设定。
- **认为裁剪能治本**：裁剪只保证有界步长，爆炸的根源（谱半径、初始化）仍需修复。
- **裁剪前不反缩放**：AMP 场景须先 `scaler.unscale_(opt)` 再裁剪，否则阈值语义错误。
- **忽略激活爆炸**：前向激活溢出同样会让反向变 inf，需同时监控激活范围。
- **爆炸与溢出混淆**：grad_norm 先异常大后变 inf 属爆炸；直接 inf 而无放大过程更可能是溢出。

## 八、面试题

- **问：梯度爆炸与数值溢出如何区分？** 答：爆炸表现为 grad_norm 先异常增大数个量级再变 inf；溢出则可能无放大过程直接出现 inf。
- **问：按范数裁剪与按值裁剪的区别？** 答：前者整体缩放、保留更新方向；后者逐元素截断、会改变方向。
- **问：裁剪能替代归一化吗？** 答：不能。归一化从前向抑制尺度漂移，裁剪只在更新端兜底，二者互补。
- **问：AMP 下裁剪要注意什么？** 答：必须先反缩放梯度再裁剪，否则阈值与真实梯度不同量纲。

## 九、演进与趋势

梯度裁剪正与自适应训练结合：AdaClip 等按历史范数动态调整阈值；优化器侧出现「信任域」式更新（如 LAMB、AdaFactor 的更新范数约束）从更新端内建稳定性；大模型普遍采用「RMSNorm + 残差 + warmup + 全局范数裁剪」的标准组合。未来趋势是把爆炸检测集成进训练框架，在 grad_norm 突变时自动降 lr 或回滚到健康检查点，而非等待人工介入。

## 十、小结

梯度爆炸是训练发散的首要原因，其本质是链式连乘的谱半径失控。实践中应以监控 grad_norm 为第一防线、以全局范数裁剪为兜底、以归一化与初始化做根因治理。把 grad_norm 当作与 loss 同等重要的健康指标，才能在发散演化为 NaN 之前及时干预。
