# 梯度爆炸导致训练发散

> 对应 pytorch/pytorch 梯度裁剪与 d2l-ai/d2l-zh 训练稳定性。

## 一、背景与挑战
未受控的梯度爆炸会让参数一步跳到极大值，loss 变 NaN，训练不可恢复。

## 二、核心原理
深层或长序列中梯度范数随深度指数增长；一旦超过数值范围，参数更新幅度失控，损失曲面被抛出。

## 三、形式化与数学基础
$ \|g\| \approx \prod_l \|W_l\| $ 当谱半径 > 1 时指数增长。裁剪把 `||Δθ||` 限在 `ηC`，阻止灾难跳跃。

## 四、代码实现
```python
# 监控并裁剪
gnorm = torch.nn.utils.clip_grad_norm_(params, 1.0)
if not torch.isfinite(gnorm):
    print("grad exploded / non-finite")   # 触发 debug 或跳过
```

## 五、与其他技术对比
归一化（LN/RMSNorm）从前向抑制爆炸；裁剪从更新端兜底，二者缺一不可。

## 六、常见误区
只在事后发现 NaN，未记录 gnorm 曲线，难以判断是爆炸还是溢出。

## 七、与开源书/权威来源对应
d2l-ai/d2l-zh 梯度爆炸章节；pytorch/pytorch `clip_grad_norm_`。

## 八、面试题
问：爆炸与溢出如何区分？答：看 gnorm 是否先异常大（爆炸）还是先出现 inf/NaN（溢出）。

## 九、演进与趋势
自适应裁剪与归一化位置优化持续降低爆炸概率。

## 十、小结
梯度爆炸是发散主因，监控 gnorm 是首要防线。
