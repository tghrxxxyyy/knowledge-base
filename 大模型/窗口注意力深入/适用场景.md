# 窗口注意力适用场景

> 对应视觉任务选型；与大模型视觉应用 衔接。

## 一、背景与挑战

不同任务对分辨率/感受野需求不同，需选注意力粒度。

## 二、核心原理

- 分类：中分辨率，窗口足够。
- 检测/分割：高分辨率密集预测，窗口+层次必备。
- 视频：窗口可推广到时空（时空窗口）。

## 三、数学形式

复杂度随分辨率线性（窗口）vs 平方（全局），决定可处理的最大分辨率。

## 四、代码实现

```python
# 视频：时空窗口
x = window_partition(x, (Mt, Mh, Mw))
```

## 五、与其他对比

- 与 卷积神经网络深入 比，窗口更灵活但需更多数据/正则。
- 与 视觉语言模型深入 衔接（视觉编码器）。

## 六、常见误区

- 小图用过大窗口反失局部性。
- 视频直接套图像窗口忽略时序维度。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 分割任务为何用窗口？答：高分辨率密集预测，窗口线性复杂度可处理。

## 九、演进

图像窗口 → 视频时空窗口 → 通用稀疏注意力。

## 十、小结

窗口注意力在密集/高分辨率视觉任务中几乎是默认选择。
