# 窗口注意力计算复杂度

> 对应复杂度分析；与 注意力数学基础 衔接。

## 一、背景与挑战

量化窗口注意力相对全局的节省，指导窗口大小选择。

## 二、核心原理

全局 $O(N^2 d)$；窗口 $O(N m^2 d)$（$m$ 窗口边长）。当 $m\ll\sqrt N$ 时大幅降。

## 三、数学形式

$N=HW/P^2$，窗口数 $(H/P/m)\times(W/P/m)$，每窗口 $m^2$ 个 token，总 $O(N m^2 d)$。

## 四、代码实现

```python
cost_global = N*N*d
cost_window = N*(m*m)*d
```

## 五、与其他对比

- 高分辨率下窗口优势指数放大。
- 与 轴向注意力深入 同量级但分解方式不同。

## 六、常见误区

- 窗口过小则跨窗口通信成本高（需多层/移位）。
- 忽视 mask 计算开销。

## 七、与开源书对应

## 八、面试题

- 何时窗口注意力优于全局？答：高分辨率（N 大）且局部性足够时。

## 九、演进

细窗口 → 粗窗口 → 动态窗口/稀疏。

## 十、小结

窗口注意力把平方复杂度降为线性乘窗口面积，是视觉 Transformer 可扩展基础。
