# 窗口注意力总览

> 对应 Liu et al., *Swin Transformer*, 2021。

## 一、背景与挑战

全局自注意力 $O(N^2)$ 在高分辨率图像上不可行；窗口注意力限制局部范围降复杂度。

## 二、核心原理

把特征图划分不重叠窗口，仅在窗口内做自注意力；配合移位窗口实现跨窗口通信。

## 三、数学形式

窗口数 $M\times M$（特征图被分块），单窗口 token 数 $m^2$，复杂度由 $O(N^2)$ 降至 $O(N m^2)$。

## 四、代码实现

```python
x = window_partition(x, M)        # (nW, m*m, C)
attn = scaled_dot_product(q, k, v)
x = window_reverse(attn, M, H, W)
```

## 五、与其他对比

- 相对全局注意力省算力但丢长程；移位窗口部分弥补。
- 与 轴向注意力深入 互补（轴向沿单维）。

## 六、常见误区

- 以为窗口注意力是全局的；需在多层堆叠才能获得大感受野。
- 窗口大小 M 固定，分辨率变化需重划分。

## 八、面试题

- 窗口注意力复杂度？答：$O(N m^2)$，m 为窗口边长，远低于全局 $O(N^2)$。

## 九、演进

全局 ViT → 窗口（Swin）→ 层次窗口 + 移位。

## 十、小结

窗口注意力以局部约束换线性级复杂度，是视觉 Transformer 高效化的核心。
