# 局部窗口机制

> 对应 Swin 标准窗口注意力。

## 一、背景与挑战

需在保局部性的同时控计算量，避免全局注意力昂贵。

## 二、核心原理

每个窗口内 token 互相注意；窗口间不交互（首层），靠后续移位或层次下采样打通。

## 三、数学形式

注意力在窗口 $W$ 内：$A_{W}=softmax(Q_W K_W^\top/\sqrt d)V_W$。

## 四、代码实现

```python
for w in windows(x):
    out.append(attn(w))
```

## 五、与其他对比

- 比卷积更灵活（内容相关权重），但缺卷积的平移等变强偏置。
- 与 卷积神经网络深入 对照。

## 六、常见误区

- 单层窗口感受野小；需堆叠或多尺度。
- 边界 token 窗口不对称需 padding 处理。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 窗口注意力为何仍需层次结构？答：单窗口感受野有限，靠下采样/移位扩大。

## 九、演进

固定窗口 → 层次多尺度窗口。

## 十、小结

局部窗口是效率与表达的平衡点，配合层次化获得全局能力。
