# 移位窗口机制

> 对应 Swin 的 shifted window（SW-MSA）。

## 一、背景与挑战

标准窗口间无信息流，限制建模；需低成本跨窗口通信。

## 二、核心原理

相邻层交替使用规则窗口与循环移位后的窗口，使原相邻窗口在新窗口中相遇，实现跨窗口交互。

## 三、数学形式

移位后做 mask 注意力，确保来自不同原窗口的 token 不错误聚合（掩码分区）。

## 四、代码实现

```python
x = torch.roll(x, shifts=(-M//2,-M//2), dims=(1,2))
attn = masked_attn(x, mask)
x = torch.roll(x, shifts=(M//2,M//2), dims=(1,2))
```

## 五、与其他对比

- 相对全局注意力，移位以近零额外成本打通窗口。
- 与 轴向注意力深入 的逐维分解思路不同。

## 六、常见误区

- 移位后必须加 mask，否则跨边界 token 错误交互。
- 忽略 roll 带来的边界处理。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 移位窗口解决什么？答：在不增全局计算下建立跨窗口信息通路。

## 九、演进

规则窗口 → 移位窗口 → 更一般的分区注意力。

## 十、小结

移位窗口以巧妙的滚动+掩码实现廉价跨窗口通信，是 Swin 关键创新。
