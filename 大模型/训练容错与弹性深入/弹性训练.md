# 弹性训练（Elastic Training）

> 对应 弹性训练框架（如 PyTorch Elastic / TorchDistElastic）；与 训练容错与弹性深入 总览衔接。

## 一、背景与挑战

集群资源动态（抢占、扩缩容）下，固定进程组训练会因节点增减失败；弹性训练允许运行中变更 worker 数。

## 二、核心原理

用弹性 rendezvous 动态重组进程组；新增/退出 worker 后从最新检查点恢复并重新分片数据/状态，保持全局一致性。

## 三、数学形式

全局步 $t$ 不变，worker 集合 $W_t$ 可变；数据分片随 $|W_t|$ 重划分，有效批量 $B=|W_t|\times b$ 动态更新 lr。

## 四、代码实现

```python
from torchelastic import elastic_launch
elastic_launch(config, entry_point=train)()   # 支持节点变更多次重启
```

## 五、与其他对比

- 与 资源抢占与再调度深入 是同一能力两面。
- 与 分布式优化器深入（ZeRO 分片需重平衡）协同。

## 六、常见误区

- rendezvous 超时配置过短致频繁重组。
- 弹性后未重分片数据致重复训练。

## 八、面试题

- 弹性训练如何支持扩缩容？答：动态 rendezvous 重组进程组，从检查点恢复并重新分片数据与状态。

## 九、演进

固定集群 → 手动重启 → 自动弹性 rendezvous。

## 十、小结

弹性训练以动态进程组与重分片，适配云上不稳定/可变资源。
