# 资源抢占与再调度

> 对应 云上抢占式实例（spot）训练；与 弹性训练深入 衔接。

## 一、背景与挑战

抢占式/低优先级实例便宜但随时被回收；需在被回收前保存、被释放后快速再调度续训。

## 二、核心原理

监听抢占信号（SIGTERM）触发紧急检查点；调度器在资源可用时重新拉起作业并弹性恢复，尽量无缝接续。

## 三、数学形式

成本节省 $\approx (1-p_{preempt})\cdot c_{spot}$ 相对按需；续训延迟 $=\tau_{ckpt}+\tau_{relaunch}$。

## 四、代码实现

```python
signal.signal(signal.SIGTERM, lambda *_: save_ckpt_and_exit())
```

## 五、与其他对比

- 与 弹性训练深入（节点增减）共用 rendezvous。
- 与 检查点恢复深入（紧急存盘）配合。

## 六、常见误区

- 未处理 SIGTERM 致检查点来不及存。
- 再调度未等最新检查点落盘致恢复旧状态。

## 八、面试题

- 抢占式训练如何不丢进度？答：捕获 SIGTERM 紧急存检查点，资源回来后弹性恢复续训。

## 九、演进

按需常驻 → 抢占+紧急存盘 → 自动再调度续训。

## 十、小结

资源抢占训练靠信号捕获与弹性再调度，以低成本换取可恢复性。
