# 训练容错实践

> 对应 大模型训练运维经验（监控/告警/演练）；与 训练容错与弹性深入 各节综合。

## 一、背景与挑战

理论机制需落到工程：何时存盘、如何探测、如何演练，避免真故障时措手不及。

## 二、核心原理

实践要点：分层检查点频率（频繁轻量+周期全量）、心跳/健康探测、故障注入演练、可观测（loss/梯度范数/硬件指标）告警。

## 三、数学形式

期望进度损失 $\mathbb E[L]\approx p_{fail}\cdot \Delta t_{ckpt}$；降 $\Delta t_{ckpt}$ 减损失但有 I/O 成本权衡。

## 四、代码实现

```python
if loss.isnan() or grad_norm > 1e3:
    alert("训练异常"); rollback_to_ckpt()
```

## 五、与其他对比

- 与 训练不稳定诊断深入（异常检测）共享监控手段。
- 与 检查点恢复深入 / 弹性训练深入 形成闭环。

## 六、常见误区

- 从不演练恢复，真故障才发现检查点坏。
- 告警阈值过松致问题晚发现。

## 八、面试题

- 容错实践关键点？答：合理检查点频率、健康探测、故障演练、可观测告警，形成恢复闭环。

## 九、演进

被动救火 → 主动监控 → 演练+自动恢复。

## 十、小结

容错落到工程需检查点策略、监控与演练三位一体，方能稳定长训。
