# 涌现争议的实践启示

> 对应 Lu et al., *Are Emergent Abilities in LLMs just In-Context Learning?*, ACL 2024；Ganguli et al., FAccT 2022。

## 一、背景与挑战

工程决策不能建立在「再大一点就会涌现」的期待上。需要把争论转化为可执行的评测与选型规则。

## 二、核心原理

实践上把涌现问题替换为三个可操作问题：指标是否有分辨率、收益是否来自上下文学习、扩规模是否比换方法更划算。

- 先做指标与提示的消融，再谈规模：多数「新能力」在强提示与指令微调后已在小模型上部分出现。
- 若收益主要由上下文学习贡献，则优化示例选择与指令格式的性价比远高于扩规模。

## 三、数学形式

选型可写为收益成本比 $\rho=\Delta \mathrm{Metric}/\Delta \mathrm{Cost}$；比较扩规模 $\rho_N$ 与改提示/微调 $\rho_P$，取 $\max(\rho_N,\rho_P)$。

因为 $\Delta \mathrm{Cost}$ 对参数量近似幂律增长，而提示优化成本近常数，$\rho_P$ 往往在早期显著占优。

## 四、代码实现

```python
def pick_lever(gain_scale, cost_scale, gain_prompt, cost_prompt=1.0):
    rho_n = gain_scale / cost_scale
    rho_p = gain_prompt / cost_prompt
    return "scale" if rho_n > rho_p else "prompt_or_sft", round(rho_n, 4), round(rho_p, 4)
print(pick_lever(gain_scale=0.08, cost_scale=10.0, gain_prompt=0.05))
```

## 五、与其他对比

- 与 上下文学习理论深入 衔接：ICL 归因决定优化杠杆放在示例还是参数。
- 与 规模律视角下的能力预测 衔接：用损失-指标映射给出扩规模收益的区间估计。

## 六、常见误区

- 把路线图押在未验证的跳变预期上，忽略提示与数据侧的确定性收益。
- 只在最终模型上评测，缺少小规模阶梯，导致无法判断收益来源。

## 八、面试题

- 涌现争议对工程有何意义？答：把「等涌现」换成指标消融与杠杆比较，决策更稳健。
- 如何验证收益来自上下文学习？答：控制示例数量与质量做消融，观察规模效应是否消失。

## 九、演进

期待跳变 → 指标与提示消融 → ICL 归因 → 以收益成本比驱动选型。

## 十、小结

对工程而言，涌现争议的最大产出是评测纪律：先证明分辨率与归因，再决定是否砸规模。
