# 平滑指标与连续化度量

> 对应 Schaeffer et al., NeurIPS 2023（连续指标建议）；Srivastava et al., *BIG-bench*, TMLR 2023。

## 一、背景与挑战

要让能力曲线可预测、可用于规划，需要对小模型也有分辨率的度量。逐 token 概率类指标即使在随机基线附近仍携带信号。

## 二、核心原理

连续化的思路是把「答对与否」替换为「离正确答案有多远」或「概率有多集中」。

- 概率类：目标序列平均对数似然、Brier 分数、校准误差，均对参数量变化连续响应。
- 距离类：归一化编辑距离、token 级 F1、BLEU 家族；在完全答错时依然区分「几乎对」与「毫无关系」。

## 三、数学形式

平均对数似然 $\ell=\frac{1}{L}\sum_{t=1}^{L}\log p_\theta(y_t\mid y_{<t},x)$；归一化编辑距离 $d=\mathrm{lev}(\hat y,y)/\max(|\hat y|,|y|)$。

前者与预训练损失同尺度、可直接与规模律拟合；后者提供 $[0,1]$ 连续退化度，避免 0/1 判定丢失全部梯度信息。

## 四、代码实现

```python
import torch
def seq_logprob(logits, target):               # logits: [T,V], target: [T]
    lp = torch.log_softmax(logits.float(), dim=-1)
    return lp.gather(-1, target[:, None]).squeeze(-1).mean()
def brier(prob_correct):
    return float(((prob_correct - 1.0) ** 2).mean())
print(brier(torch.tensor([0.3, 0.7, 0.9])))
```

## 五、与其他对比

- 与准确率对照：连续指标可外推但不直接反映产品可用性，两者应同时报告。
- 与 规模律视角下的能力预测 衔接：连续指标是拟合 $L\to$ 任务表现映射的必要输入。

## 六、常见误区

- 只报连续指标而不报准确率，掩盖了「用户真正能否用」的门限现实。
- 用未归一化的编辑距离横比不同长度任务，导致长任务被系统性高估难度。

## 八、面试题

- 为什么用 Brier 而非准确率看小模型？答：Brier 对概率连续敏感，在准确率仍等于随机基线时已能分辨改进。
- 连续指标能否完全替代准确率？答：不能，产品体验往往就是门限式的，需双轨报告。

## 九、演进

准确率单指标 → 概率与距离类连续指标 → 连续指标拟合外推 → 双轨（连续+门限）报告。

## 十、小结

连续化度量让能力曲线重新变得可预测，是把涌现争论落回工程实践的关键工具。
