# 非连续指标与海市蜃楼

> 对应 Schaeffer, Miranda & Koyejo, *Are Emergent Abilities of Large Language Models a Mirage?*, NeurIPS 2023。

## 一、背景与挑战

若度量本身是阶跃或指数压缩的，任何平滑提升的模型族都可能「表现出」涌现。这使得跳变现象无法作为能力相变的独立证据。

## 二、核心原理

该文的核心论证是可证伪的三步：指标决定曲线形状、换指标可让涌现消失、也可人为在非语言模型上制造涌现。

- 非连续指标（精确匹配、多选打分、Exact-string、pass@1）把连续概率改善离散化，放大为门限。
- 作者进一步在与语言无关的模型族上，通过选取非线性度量诱导出同样的「涌现」曲线，说明现象可由度量单独解释。

## 三、数学形式

多选打分为 $\mathbb{1}[\arg\max_c s_c = y]$，是 $s$ 的不连续函数；而 Brier 分数 $\mathrm{BS}=\frac{1}{n}\sum_i (p_i-y_i)^2$ 对 $p$ 连续可微。

因此同一组 $\{p_i(N)\}$ 在前者上呈跳变、在后者上呈平滑曲线；$\frac{\partial \mathrm{Acc}}{\partial p}$ 存在测度零处的爆炸是跳变的数学来源。

## 四、代码实现

```python
import numpy as np
p_true = np.linspace(0.20, 0.60, 40)                 # 正确选项概率随规模平滑上升
choice_acc = (p_true > 0.5).astype(float)            # 多选打分：阶跃
brier = (p_true - 1.0) ** 2                          # Brier：连续
print(choice_acc[18:22], brier[18:22].round(3))
```

## 五、与其他对比

- 与 Wei et al., TMLR 2022 对照：现象描述一致，分歧在于是否需要引入「新能力」这一额外假设。
- 与 评测设计与阈值效应 对照：指标非连续与样本量不足会叠加，共同放大伪跳变。

## 六、常见误区

- 认为该文否认大模型变强；它只否认「跳变即相变」的推断，不否认能力随规模提升。
- 以为换成连续指标就无涌现；部分任务在连续指标下仍有超线性区间，需逐任务检验。

## 八、面试题

- 为什么精确匹配容易造出涌现？答：它是长序列全对的连乘判定，把 token 级线性改善指数放大为门限。
- 如何反驳「涌现是假象」？答：需给出在连续、可外推指标下仍不可预测的跳变实例。

## 九、演进

跳变观察 → 指标批判与可控复现 → 逐任务连续指标复核 → 评测报告规范化。

## 十、小结

非连续指标是涌现叙事最大的混杂因子，任何跳变结论都应先做指标敏感性检验。
