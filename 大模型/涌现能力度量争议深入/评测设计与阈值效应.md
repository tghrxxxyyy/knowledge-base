# 评测设计与阈值效应

> 对应 Srivastava et al., *BIG-bench*, TMLR 2023；Schaeffer et al., NeurIPS 2023（分辨率与样本量讨论）。

## 一、背景与挑战

题量小、基线高、提示敏感、数据污染，任何一项都能在曲线上制造出与涌现难以区分的跳变。评测设计因此是结论可信度的前提。

## 二、核心原理

跳变的可信度取决于统计分辨率：观测差异必须显著大于抽样噪声与提示方差。

- 随机基线抬高门限：四选一任务下 25% 以下的区间几乎不含信息，早期曲线的「平坦」是被基线掩盖。
- 提示与格式方差常与规模效应同量级，必须多提示平均并报告方差。

## 三、数学形式

二项置信区间宽度约 $\pm 1.96\sqrt{p(1-p)/n}$；要分辨 $\Delta p=0.05$，在 $p\approx0.3$ 时需 $n \gtrsim 4\cdot 1.96^2 p(1-p)/\Delta p^2$ 量级的题量。

即样本量不足时，$\Delta p$ 落在噪声内，曲线的「突然抬升」可能只是随机波动的一次上偏。

## 四、代码实现

```python
import math
def wilson(k, n, z=1.96):
    p = k / n; d = 1 + z * z / n
    c = (p + z * z / (2 * n)) / d
    h = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / d
    return round(c - h, 3), round(c + h, 3)
print(wilson(12, 40), wilson(300, 1000))
```

## 五、与其他对比

- 与 非连续指标与海市蜃楼 对照：指标离散化与样本量不足是两个独立却叠加的混杂源。
- 与 模型评测指标类主题衔接：污染检测与多提示平均同属评测卫生要求。

## 六、常见误区

- 用几十道题的子任务宣称涌现，置信区间宽到覆盖整段跳变。
- 只用单一提示模板，把提示工程收益误记为模型规模收益。

## 八、面试题

- 为什么要报置信区间？答：跳变必须显著大于抽样噪声，否则无法与随机波动区分。
- 提示方差如何处理？答：多模板多序采样后取均值与方差，将其纳入结论的不确定性。

## 九、演进

单提示小样本 → 多提示平均与区间报告 → 污染筛查 → 标准化评测协议。

## 十、小结

没有统计分辨率与评测卫生的跳变曲线，不能作为涌现或能力相变的证据。
