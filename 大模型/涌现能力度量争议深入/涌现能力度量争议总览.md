# 涌现能力度量争议总览

> 对应 Wei et al., *Emergent Abilities of Large Language Models*, TMLR 2022；Schaeffer et al., *Are Emergent Abilities of LLMs a Mirage?*, NeurIPS 2023。

## 一、背景与挑战

「涌现」指某任务在小模型上接近随机基线、模型规模跨过某个点后准确率骤然抬升的现象。争议焦点是：这种跳变是模型内部能力的相变，还是评测指标的非连续性制造出的视觉假象。

## 二、核心原理

两派在同一批实验数据上得到不同解释，关键差异是「用什么指标观察同一个模型族」。

- 涌现派：在 BIG-bench 等任务上，精确匹配与多选打分随规模呈折线抬升，小模型区间信息量近零，无法外推预测。
- 假象派：跳变来自指标把连续改善的 per-token 概率压成 0/1 判定；换用连续指标后曲线平滑，且可由小模型外推。

## 三、数学形式

设单 token 正确率随规模平滑提升为 $p(N)=1-\epsilon(N)$，长度 $L$ 的精确匹配准确率为 $\mathrm{Acc}_{EM}(N)=p(N)^{L}=\exp(-L\,\epsilon(N))$。

当 $\epsilon(N)$ 只是平滑幂律下降，$\exp(-L\epsilon)$ 在 $L$ 较大时仍会呈门限式抬升——跳变由指标的指数放大产生，而非能力突变。

## 四、代码实现

```python
import numpy as np
N = np.logspace(7, 11, 40)                     # 参数量扫描
eps = np.clip(3.0 * (N / 1e7) ** -0.12, 0, 1)  # 平滑幂律的 token 错误率
acc_em = (1 - eps) ** 30                       # 30-token 精确匹配：陡峭
acc_tok = 1 - eps                              # 逐 token 指标：平滑
print(acc_em[[0, 20, 39]], acc_tok[[0, 20, 39]])
```

## 五、与其他对比

- 与规模律（Kaplan et al., 2020；Hoffmann et al., 2022）对照：交叉熵损失始终平滑，下游准确率跳变是度量映射的产物。
- 与 上下文学习理论深入 对照：Lu et al., ACL 2024 主张多数「涌现」可归因于上下文学习被更好地激发，而非新增独立能力。

## 六、常见误区

- 把「不可外推」当作相变证据；不可外推也可能只说明该指标对小模型无分辨率。
- 只看单点跳变即下结论，忽略随机基线、题量过小与置信区间造成的伪跳变。

## 八、面试题

- 涌现等于相变吗？答：不必然，先排除指标非连续与评测噪声，才能讨论机制层面的相变。
- 如何判断某能力是真涌现？答：换连续指标、扩大题量、检查是否能由小模型的连续量外推。

## 九、演进

现象命名（2022）→ 指标批判（2023）→ 归因到上下文学习与评测设计（2024）→ 用可预测度量替代跳变叙事。

## 十、小结

涌现之争的核心不是「大模型是否变强」，而是「跳变来自能力还是度量」，答案高度依赖指标选择与评测严谨性。
