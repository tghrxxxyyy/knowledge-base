# 规模律视角下的能力预测

> 对应 Kaplan et al., *Scaling Laws for Neural Language Models*, 2020；Hoffmann et al., *Chinchilla*, 2022；Ganguli et al., *Predictability and Surprise*, FAccT 2022。

## 一、背景与挑战

预训练损失随算力/参数/数据呈稳定幂律，可高精度外推；但下游任务准确率却常表现为不可预测的跳变。两者的张力正是涌现争论的量化核心。

## 二、核心原理

把预测拆成两段：规模到损失是平滑幂律，损失到任务指标是非线性映射，跳变主要来自第二段。

- 第一段可靠：$L(N,D)$ 的幂律在多个数量级上稳定，常用于训练预算规划。
- 第二段是压缩：损失小幅下降经由阈值型映射后被放大为准确率骤升，故「可预测的惊喜」并不矛盾。

## 三、数学形式

$$L(N, D) = \left(\frac{N_c}{N}\right)^{\alpha_N} + \left(\frac{D_c}{D}\right)^{\alpha_D} + L_\infty$$

下游表现常可写作 $\mathrm{Acc}=\sigma\big(k(L_0-L)\big)$，$\sigma$ 为 S 形映射；$k$ 越大跳变越陡，但整体仍由 $L$ 单调决定。

## 四、代码实现

```python
import numpy as np
def loss_law(N, Nc=8.8e13, a=0.076, Linf=1.7):
    return (Nc / N) ** a + Linf
def acc_from_loss(L, L0=2.2, k=12.0):
    return 1.0 / (1.0 + np.exp(-k * (L0 - L)))
N = np.logspace(8, 11, 7)
print(loss_law(N).round(3), acc_from_loss(loss_law(N)).round(3))
```

## 五、与其他对比

- 与 平滑指标与连续化度量 衔接：连续指标让第二段映射可辨识与拟合。
- 与 涌现能力度量争议总览 对照：本视角把争论转化为「映射斜率 $k$ 有多大」的可测问题。

## 六、常见误区

- 直接用幂律外推下游准确率；损失外推可靠不等于任务指标可外推。
- 忽视 Chinchilla 结论中数据与参数需协同放大，只堆参数会偏离幂律预测。

## 八、面试题

- 为什么损失平滑而准确率跳变？答：损失是连续期望，准确率经过阈值映射，小损失改善被放大。
- 如何用规模律预估新任务？答：先拟合损失-指标映射，再用损失幂律外推，并给区间而非点估计。

## 九、演进

损失幂律（2020）→ 数据-参数协同（2022）→ 损失到能力映射建模 → 面向任务的可预测评测。

## 十、小结

规模律把涌现拆成「平滑损失 + 非线性映射」，跳变因此既真实又可预测。
