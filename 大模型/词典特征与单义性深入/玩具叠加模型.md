# 玩具叠加模型

> 对应 Elhage et al., *Toy Models of Superposition*, 2022。

## 一、背景与挑战

叠加如何在可控环境复现？Toy 模型帮我们分离维度、特征数、稀疏度的影响。

## 二、核心原理

构造一个小型 ReLU 自编码器，强制 $n>d$ 个稀疏特征；训练后隐单元不是单义特征，而是特征的叠加组合，复现多义现象并可定量研究。

## 三、数学形式

自编码损失 $\|x - W_{dec}\sigma(W_{enc}x)\|^2$；当 $n>d$ 且特征稀疏时，最优解近似叠加而非独热分配。

## 四、代码实现

```python
def toy_superposition(n, d, sparsity):
    F = randn(d, n); F /= F.norm(0)
    a = (rand(n) < sparsity).float() * randn(n)
    return F @ a
```

## 五、与其他对比

- 与 字典学习与叠加 衔接（SAE 为逆过程）。
- 与 稀疏自编码器特征深入 共享理论。

## 六、常见误区

- 以为 Toy 结论直接迁移大模型；大模型还有注意力/层间耦合。
- 忽略稀疏度是关键前提。

## 八、面试题

- Toy 模型证明什么？答：在 $n>d$ 且稀疏时，模型自发用叠加而非独热，导致多义。

## 九、演进

线性叠加 → 带干扰项 → 何时应叠加的理论界。

## 十、小结

Toy 模型把叠加机制形式化，是可解释性理论的实验田。
