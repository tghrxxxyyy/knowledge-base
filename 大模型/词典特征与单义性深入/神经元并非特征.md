# 神经元并非特征

> 对应 Olah et al., *Interpretability Dreams*, 2020；Elhage et al., 2022。

## 一、背景与挑战

传统"每个神经元是一个特征"的直觉在叠加下失败，需要新的特征本体论。

## 二、核心原理

在叠加下，特征由方向而非神经元承载；多个神经元线性组合才是一个特征，单个神经元是特征的混合投影。因此解释应以"方向/特征"为单位。

## 三、数学形式

特征方向 $u_i$ 满足 $f_i = \langle x, u_i\rangle$；神经元 $j$ 的激活 $x_j = \sum_i a_i u_{i,j}$，为特征的线性混合。

## 四、代码实现

```python
# 用 SAE 解码器列作为特征方向
feat_dirs = sae.decoder.weight.T   # 每列一个特征方向
acts = x @ feat_dirs               # 投影得特征系数
```

## 五、与其他对比

- 与 稀疏自编码器特征深入 衔接（特征方向即解码列）。
- 与 层级表征语义结构深入（探针方向）共享方向视角。

## 六、常见误区

- 仍用最大激活样本给单个神经元贴标签。
- 混淆神经元激活与特征激活。

## 八、面试题

- 为何说神经元不是特征？答：叠加下特征由方向承载，神经元是方向的非正交混合投影。

## 九、演进

神经元特征论 → 方向特征论 → SAE 特征本体。

## 十、小结

把"特征=方向"而非"特征=神经元"是叠加时代的基本范式转变。
