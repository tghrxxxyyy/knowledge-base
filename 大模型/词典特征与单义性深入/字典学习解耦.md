# 字典学习解耦

> 对应 Elhage et al., 2022；Cunningham et al., ICLR 2024。

## 一、背景与挑战

如何从多义叠加中恢复单义特征？字典学习提供数学与工程路径。

## 二、核心原理

用超完备字典（基向量数远超维度）近似激活；稀疏编码假设使每个样本仅少量基激活，从而每个基趋向单义。SAE 即其可微实现。

## 三、数学形式

稀疏编码 $\min_f \|x - D f\|^2 + \lambda\|f\|_0$，SAE 用 L1 松弛 $\|f\|_1$；$D$ 为字典（解码器列）。

## 四、代码实现

```python
from sklearn.decomposition import DictionaryLearning
dl = DictionaryLearning(n_components=k, alpha=lam, fit_algorithm="lars")
F = dl.fit_transform(X)
```

## 五、与其他对比

- 与 稀疏自编码器特征深入 衔接（SAE=可微字典学习）。
- 与 玩具叠加模型 互补（逆运算）。

## 六、常见误区

- 字典越大越好；成本与过拟合风险上升。
- 忽视字典列非正交导致的解释耦合。

## 八、面试题

- 字典学习如何解耦？答：超完备稀疏基让每样本只激活少数基，基趋向单义方向。

## 九、演进

L0 编码 → L1 SAE → 结构化/分层字典。

## 十、小结

字典学习是解耦叠加的标准框架，SAE 是其深度实现。
