# 叠加与单义性总览

> 对应 Elhage et al., *Toy Models of Superposition*, 2022。

## 一、背景与挑战

为何单个神经元常对应多个不相关概念（多义）？叠加假设给出统一解释，并引出单义性目标。

## 二、核心原理

当需表示的特征数超过可用维度，且特征稀疏出现时，模型以"叠加"把多特征线性叠加进同Dimension。于是神经元成为多特征的非正交组合，呈现多义性。

## 三、数学形式

叠加表示 $x = \sum_{i=1}^n a_i f_i$，其中 $f_i$ 为（非正交）特征方向，$a_i$ 为激活；维度 $d < n$。

## 四、代码实现

```python
F = randn(d, n)  # 非正交特征方向（叠加）
x = F @ a        # 叠加后的激活
print("多义神经元?", not orthogonal(F))
```

## 五、与其他对比

- 与 稀疏自编码器特征深入 衔接：SAE 试图从叠加中恢复单义特征。
- 与 层级表征语义结构深入 相关（几何由各向异性体现）。

## 六、常见误区

- 认为"一个神经元一个概念"；叠加下不成立。
- 以为正交化能无损还原；特征方向本身可能相关。

## 八、面试题

- 为何神经元多义？答：特征数超维度时叠加迫使多特征共用神经元，方向非正交致多义。

## 九、演进

观察多义 → 叠加理论 → SAE 解耦实践。

## 十、小结

叠加是模型在有限维度容纳大量特征的策略，也是可解释性主要障碍。
