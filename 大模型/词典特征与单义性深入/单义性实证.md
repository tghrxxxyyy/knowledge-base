# 单义性实证

> 对应 Templeton et al., *Scaling Monosemanticity*, 2024；以及 Gemini 团队 2024 SAE 研究。

## 一、背景与挑战

单义性是否在大模型中真实可达成？跨实验室实证研究给出证据。

## 二、核心原理

在 Claude/Gemini 等大模型上训练 SAE，人工与自动评估显示：大量特征高度单义（如具体实体、情绪、代码语法）；单义率随字典维与模型规模提升，且出现跨语言抽象特征。

## 三、数学形式

单义率 $M(k, S) = \frac{1}{K}\sum_i \mathbb I(C_i > \tau)$，随字典倍数 $k$ 与参数量 $S$ 上升。

## 四、代码实现

```python
for S in [7B, 13B, 70B]:
    m = [monosemanticity(train_sae(S, k)) for k in mults]
    print(S, m)  # 规模越大单义率越高
```

## 五、与其他对比

- 与 稀疏自编码器特征深入（特征分裂）衔接。
- 与 规模与可解释性关系深入 共享证据。

## 六、常见误区

- 误读为"已完全单义"；仍有大量噪声/多义特征。
- 跨模型特征一致性仍有限。
