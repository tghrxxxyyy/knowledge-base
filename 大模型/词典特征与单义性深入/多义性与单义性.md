# 多义性与单义性

> 对应 Olah et al., *Monosemanticity* 系列；Elhage et al., 2022。

## 一、背景与挑战

多义性阻碍解读，单义性（monosemanticity）是目标：每个可解释单元对应单一概念。

## 二、核心原理

多义神经元对多个无关输入均激活；单义单元只对一个概念敏感。叠加使天然多义，字典学习/SAE 可逼近单义。单义化提升可干预性与可信度。

## 三、数学形式

单义度可度量：第 $i$ 单元激活样本的概念一致性 $C_i \in [0,1]$；$C_i$ 高即单义。

## 四、代码实现

```python
def monosemanticity(feat_acts, concepts):
    labels = cluster(feat_acts.topk(50).texts)
    return max_label_share(labels)  # 越高越单义
```

## 五、与其他对比

- 与 稀疏自编码器特征深入（目标单义）同源。
- 与 规模与可解释性关系深入 衔接（规模提升单义）。

## 六、常见误区

- 以为单义是默认状态；默认是叠加多义。
- 把"稀疏激活"等同"单义"。

## 八、面试题

- 多义 vs 单义？答：多义单元响应多概念（叠加所致），单义单元只响应一概念（解耦目标）。

## 九、演进

多义观察 → 单义化方法 → 规模化单义词典。

## 十、小结

单义性是可解释性与可控性的前提，叠加是其主要敌人。
