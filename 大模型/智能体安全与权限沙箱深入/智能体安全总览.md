# 智能体安全与权限沙箱总览

> 对应 Ruan et al., *ToolEmu*, 2023（风险评测）；人类对齐与 agent 安全实践。

## 一、背景与挑战

智能体能调用真实工具（发邮件、改文件、付款），一旦被诱导或出错，后果不可逆。安全与沙箱是“能力解锁”的前提。

## 二、核心原理

纵深防御：最小权限（只给必要工具/范围）、隔离执行（沙箱）、关键操作确认（human-in-the-loop）、行为审计（日志可回溯）。四层叠加降低单点失守影响面。

## 三、数学形式

风险期望：

$$R = \sum_{a} P(a)\cdot I(a)$$

$P$ 为动作发生概率，$I$ 为影响，沙箱旨在把 $I$ 限制在 bounded 范围。

## 五、与其他对比

- 与 工具调用错误恢复深入 共享“副作用管控”。
- 与 人机协作与人在环深入 共享确认节点。

## 六、常见误区

- 沙箱只限算力不限网络，仍可能外泄。
- 权限“图省事”给全量，扩大攻击面。

## 八、面试题

- 为什么最小权限重要？答：限制单点失守的爆炸半径，降低被诱导危害。

## 九、演进

无隔离 → 权限分级 → 沙箱+确认+审计纵深。

## 十、小结

安全是智能体开放能力的“刹车”，纵深防御缺一不可。
