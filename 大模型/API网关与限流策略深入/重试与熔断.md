# 重试与熔断

> 对应韧性模式（重试/熔断/超时）；微服务实践。

## 一、背景与挑战

后端偶发超时/过载，盲目重试会雪崩；需熔断保护。

## 二、核心原理

重试带退避（指数+抖动）；熔断器三态（关/开/半开）按错误率切换，开时快速失败。

## 三、数学形式

退避 $t = b\cdot 2^n + \text{jitter}$；熔断当错误率 $e > e_{th}$ 持续窗口。

## 四、代码实现

```python
for i in range(3):
    try: return call(); except: sleep(2**i + rand())
```

## 五、与其他对比

- 与 API网关总览深入（网关实现重试）衔接。
- 与 大模型监控与告警深入（错误率触发）相关。

## 六、常见误区

- 无退避重试放大拥塞。
- 熔断阈值过低误伤（抖动即开）。

## 八、面试题

- 熔断作用？答：后端持续失败时快速失败，给其恢复时间，防雪崩。

## 九、演进

无重试 → 固定重试 → 退避+熔断。

## 十、小结

重试+熔断是网关韧性基础，退避防放大。
