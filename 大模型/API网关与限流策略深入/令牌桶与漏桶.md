# 令牌桶与漏桶

> 对应两位经典算法（Turner 1986 token bucket；Leaky bucket）。

## 一、背景与挑战

需既控平均速率又兼顾合理突发（如首字预热）。

## 二、核心原理

令牌桶：每请求消耗令牌，空则拒；漏桶：请求入桶以恒定速率流出处理，溢则拒，强制平滑。

## 三、数学形式

令牌桶允许突发至 $B$；长期速率被 $r$ 限制；漏桶输出恒 $r$，队列长 $Q$ 超出即丢。

## 四、代码实现

```python
class LeakyBucket:
    def allow(self): self.q=max(0,self.q-rate*dt)+1; return self.q<=cap
```

## 五、与其他对比

- 与 限流算法深入 同主题，本节深入两桶。
- 与 API网关总览深入 衔接（网关实现）。

## 六、常见误区

- 令牌桶容量设过大等于不限流。
- 漏桶速率过低致正常流量丢弃。

## 八、面试题

- 何时选漏桶？答：需严格平滑输出（如保护下游恒定负载）时。

## 九、演进

单桶 → 多级桶（限流+配额）→ 自适应。

## 十、小结

两桶取舍在突发 vs 平滑，按后端承受力选。
