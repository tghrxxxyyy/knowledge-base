# 限流算法

> 对应限流算法综述（token bucket/leaky bucket）；Gupta 等。

## 一、背景与挑战

突发流量或滥用会压垮推理后端；限流保护可用性。

## 二、核心原理

固定窗口、滑动窗口、令牌桶（允许突发）、漏桶（平滑速率）、计数滑动日志。

## 三、数学形式

令牌桶：令牌以速率 $r$ 生成，容量 $B$；可突发取最多 $B$ 个；漏桶输出恒定 $r$。

## 四、代码实现

```python
def allow(bucket):
    bucket.tokens = min(B, bucket.tokens + r*dt)
    if bucket.tokens >= 1: bucket.tokens -= 1; return True
    return False
```

## 五、与其他对比

- 与 模型服务负载均衡深入（保护后端）衔接。
- 与 成本优化与资源调度深入（限流控成本）相关。

## 六、常见误区

- 固定窗口边界突发双倍（临界突刺）。
- 分布式限流用本地计数失真。

## 八、面试题

- 令牌桶 vs 漏桶？答：令牌桶允许突发、漏桶强制平滑速率。

## 九、演进

固定窗口 → 滑动窗口 → 令牌桶/漏桶 → 分布式。

## 十、小结

限流算法按是否允许突发选择，分布式需集中计数。
