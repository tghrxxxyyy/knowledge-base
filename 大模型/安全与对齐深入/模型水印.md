# 模型水印 Watermarking

> 对应 Kirchenbauer et al. 2023「A Watermark for Large Language Models」与 llm-course mlabonne「Security」章节。

## 一、背景与挑战

随着 AI 生成文本泛滥，区分「机器生成」与「人类撰写」成为溯源、防伪、学术诚信与内容治理的刚需。理想的水印应满足：对人不可见、对机器可检测、对文本质量影响小、且具备一定鲁棒性（抵抗改写）。然而水印与文本质量、抗攻击能力之间存在权衡，强水印易被改写去除，弱水印则难以检测。

## 二、核心原理

最经典的是 Kirchenbauer 等的「绿色列表（green-list）」法：在生成每一步，基于前一个 token 的哈希，将词表划分为绿色列表（约一半 token）与红色列表。解码时，对绿色列表中的 token 施加正向偏置（如加性 logit 偏置 $\delta$ 或采样偏好），使模型倾向于生成绿色 token。由于随机划分，人类自然文本的绿色占比应接近 $50\%$，而带水印文本显著高于该比例，可用统计检验识别。

## 三、形式化与数学基础

设第 $t$ 步绿色列表由哈希函数决定：$G_t = h(x_{t-1}) \bmod 2$。解码时对绿色 token 加偏置：

$$
\tilde{\ell}_i = \ell_i + \delta \cdot \mathbb{1}[i \in G_t], \quad \delta > 0
$$

对生成序列统计绿色 token 占比 $\hat{\gamma} = \frac{1}{n}\sum_{t=1}^n \mathbb{1}[x_t \in G_t]$。在零假设（无水印）下 $\hat{\gamma} \sim \mathcal{N}(1/2, \frac{1}{4n})$，采用 $z$ 检验：

$$
z = \frac{\hat{\gamma} - 1/2}{\sqrt{1/(4n)}}
$$

当 $|z|$ 超过阈值（对应极低 $p$ 值）时判定为 AI 生成。偏置 $\delta$ 越大，$z$ 越显著，但文本多样性与质量下降。

## 四、代码实现

```python
import hashlib
import torch

def green_list(prev_token_id: int, vocab_size: int, gamma: float = 0.5):
    h = int(hashlib.sha256(str(prev_token_id).encode()).hexdigest(), 16)
    # 取哈希作伪随机种子，划分绿色集合
    rng = torch.randperm(vocab_size, generator=torch.Generator().manual_seed(h % (2**31)))
    k = int(vocab_size * gamma)
    return set(rng[:k].tolist())

def watermark_logits(logits, prev_id, vocab_size, delta=2.0):
    gl = green_list(prev_id, vocab_size)
    for i in range(vocab_size):
        if i in gl:
            logits[i] += delta
    return logits
```

## 六、常见误区

- 误区一：水印不可去除。 paraphrase、翻译、重写可显著削弱统计信号。
- 误区二：水印零质量损失。偏置越强，文本越「套路化」、多样性下降。
- 误区三：阴性误报无害。将人类文本误判为 AI 会造成不公，需控制误报率。
- 误区四：水印可替代溯源。水印是辅助手段，仍依赖平台协同与法律约束。

## 九、演进与趋势

从加性偏置走向「无偏置」的上下文水印、基于语义不变性的鲁棒水印，以及与 C2PA 内容凭证结合的端到端溯源。挑战在于：多模型协同生成、强改写攻击、以及跨语言水印的可移植性。

产业落地中，水印常与内容凭证（如 C2PA）结合：生成时写入不可见水印，发布时附带可验证元数据，形成「概率检测 + 确定性凭证」双保险。语义水印（在嵌入空间留痕）对 paraphrase 更鲁棒是活跃方向。需注意误报（人类文本判为 AI）在学术、司法场景后果严重，上线须严格校准阈值并公开检测方法。

- 双保险：水印与内容凭证协同使用。
- 阈值校准：严格控制阴性误报率。
- 公开检测：提供可复现的检测接口。
- 语义水印：提升抗改写鲁棒性。
- 责任边界：水印是辅助而非唯一手段。

## 十、小结

模型水印通过在生成分布中嵌入统计标记实现 AI 文本溯源，绿色列表法简单有效但易被改写去除。工程上需在隐蔽性、鲁棒性与文本质量间权衡，并作为内容治理的辅助而非唯一手段。
