# 越狱攻击 Jailbreak

> 对应 Wei et al. 2023「Jailbroken: How Does LLM Safety Training Fail?」、Zou et al. 2023「GCG」与 llm-course mlabonne「Security」。

## 一、背景与挑战

即便经过 RLHF/DPO 安全对齐，模型仍可能被「越狱（jailbreak）」——即通过特定提示绕过安全护栏，输出本应拒绝的有害内容。越狱威胁随模型开放部署与 Agent 化而加剧，攻击者可借此生成违法指导、偏见言论或泄露敏感信息。理解越狱机理是构建稳健防御的前提。

## 二、核心原理

Wei 等将越狱成功归因于两种失败模式：（1）竞争性目标（competing objectives）——模型被训练同时「有用」与「无害」，当提示构建一个看似合理的任务框架（如「用于教育研究」）时，有用目标压过安全目标；（2）错配泛化（mismatched generalization）——安全训练仅覆盖有限显式模式，攻击者用角色扮演、虚构设定、编码包装等分布外形式即可绕过。常见手法：DAN 类角色扮演、base64/ROT13 编码请求、虚构场景（「在小说中……」）、多轮渐进诱导、以及多模态藏指令。

## 三、形式化与数学基础

将越狱视为在约束 $\mathcal{C}$（安全）下诱导模型输出 $y \in \mathcal{H}$（有害集合）。角色扮演可建模为引入虚拟角色分布 $p_{\text{role}}$ 使安全分类器误判上下文：

$$
p_\theta(y \mid x, \text{role}=R) > p_\theta(y \mid x, \text{role}=\text{assistant})
$$

对抗性后缀攻击（如 GCG）则直接优化离散后缀 token $[s_1,\dots,s_k]$ 使损失最小化：

$$
\min_{s_1,\dots,s_k} \, \mathcal{L}\big(\pi_\theta(y \mid [x; s_1;\dots;s_k])\big)
$$

其中 $\mathcal{L}$ 为鼓励有害输出的对抗损失，通过梯度近似搜索可迁移的后缀。

import re

JAILBREAK_PATTERNS = [
    r"(?i)dan|do anything now",                 # 角色扮演
    r"(?i)ignore (all |previous )?(instructions|rules)",  # 指令覆盖
    r"base64|rot13|unicode escape",              # 编码绕过
    r"(?i)pretend|roleplay|in a novel",          # 虚构场景
]

def scan_jailbreak(prompt: str) -> bool:
    return any(re.search(p, prompt) for p in JAILBREAK_PATTERNS)

## 六、常见误区

- 误区一：角色扮演只是「玩梗」。它利用的是模型错配泛化，确能绕过安全训练。
- 误区二：多模态越狱不存在。图像中藏文字指令、视觉对抗样本同样可越狱。
- 误区三：单点防御够用。越狱常以组合手法（编码+角色+多轮）突破单层。
- 误区四：越狱只危害输出。在 Agent 中越狱可触发危险工具调用，危害放大。

## 九、演进与趋势

越狱从手工模板（DAN）演进到自动化对抗搜索（GCG）、多模态越狱与 Agent 工具链攻击。防御同步走向更鲁棒的偏好训练、对抗训练、以及推理时护栏（输入扫描+输出分类+工具审批）的纵深体系。

防御与攻击呈军备竞赛：攻击方不断发明新模板（多轮、多模态、组合），防御方以对抗训练（用越狱样本微调）加推理护栏（输入扫描/输出分类/工具审批）应对。近期研究用拒绝召回与安全分类器集成降低单点失效，但仍无银弹，需持续红队对抗演化。

- 对抗训练：越狱样本进偏好数据加固分布。
- 推理护栏：扫描 + 分类 + 确认三层防护。
- 持续红队：跟进新型越狱手法与模板。
- 集成判别：多分类器降低单点失效。
- 多模态防：图像藏指令需视觉级检测。

## 十、小结

越狱利用对齐训练的竞争性目标与错配泛化弱点，通过角色扮演、编码、对抗后缀等方式绕过安全护栏。防御须理解其机理，采用训练鲁棒化与推理多层护栏结合的纵深策略，并依赖持续红队对抗演化攻击。
