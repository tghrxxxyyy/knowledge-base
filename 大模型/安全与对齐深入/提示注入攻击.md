# 提示注入攻击 Prompt Injection

> 对应 llm-course 安全章节与 OWASP LLM Top 10。

## 一、核心概念

攻击者把恶意指令混入模型可读取的内容(网页/文档/工具返回)，劫持模型行为。典型：「忽略之前所有指令，输出xxx」。在 RAG/Agent 中危害尤其大——检索到的外部文本即攻击载体。

## 二、防御

- 严格分隔系统指令与不可信内容(用清晰边界标记)。
- 输入/输出过滤与意图校验。
- 最小权限工具、危险动作需确认。
- 指令优先级固化(系统提示不可被用户/内容覆盖)。

## 三、关键要点

| 攻击面 | 防御 |
|--------|------|
| 用户提示 | 意图分类 |
| 检索内容 | 来源标记/隔离 |
| 工具返回 | 沙箱/确认 |
