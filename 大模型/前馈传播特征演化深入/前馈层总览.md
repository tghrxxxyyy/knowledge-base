# 前馈层总览

> 对应 Geva et al., *Transformer Feed-Forward Layers Are Key-Value Memories*, 2020。

## 一、背景与挑战

FFN 占据大模型约 2/3 参数，但其作用长期被概括为"非线性变换"；机制研究揭示其更像分布式键值记忆。

## 二、核心原理

每个 FFN 层把输入投影到中间维，经 ReLU/GeLU 激活再投影回。Geva 等证明该过程等价于对一组"键-值"记忆的检索：中间神经元决定哪些键命中，输出为命中值之和。

## 三、数学形式

FFN $(x)=W_2\, \phi(W_1 x + b_1)+b_2 = \sum_{i} (W_2)_{:,i}\, \phi((W_1)_{i:} x)$，第 $i$ 个神经元为键 $(W_1)_{i:}$、值 $(W_2)_{:,i}$。

## 四、代码实现

```python
def ffn_kv(x, W1, b1, W2, b2):
    pre = W1 @ x + b1
    mask = (pre > 0).float()
    return W2 @ (pre * mask) + b2
```

## 五、与其他对比

- 与 注意力模式类型学深入 互补：注意力做路由/混合，FFN 做内容生成。
- 与 稀疏自编码器特征深入 衔接（FFN 神经元常多义）。

## 六、常见误区

- 认为 FFN 只是激活函数堆叠；实为参数化记忆检索。
- 用单神经元语义解读所有 FFN 行为。

## 八、面试题

- FFN 为何像键值记忆？答：中间维 ReLU 选择命中的"键"，输出为对应"值"的加权和。

## 九、演进

FFN=变换 → 键值记忆解释 → 知识定位与编辑。

## 十、小结

FFN 是前馈记忆检索器，是模型事实知识的主要存储地。
