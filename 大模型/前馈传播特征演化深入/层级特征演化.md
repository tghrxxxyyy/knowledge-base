# 层级特征演化

> 对应 Meng et al., *Rome*, 2022；Tenney et al., 2019 的层级观察。

## 一、背景与挑战

不同层 FFN/注意力承载不同抽象级别的信息；理解演化规律才能定位"在哪层改、在哪层读"。

## 二、核心原理

底层偏句法/局部特征，中层浮现语义/实体，高层组成为关系与推理所需的抽象变量。事实编辑常在中上层 FFN 最有效。

## 三、数学形式

定义层 $l$ 表示 $h^{(l)}$；信息流 $h^{(l+1)} = h^{(l)} + \text{Attn}^{(l)}(h^{(l)}) + \text{FFN}^{(l)}(h^{(l)})$。

## 四、代码实现

```python
acts = {l: [] for l in range(L)}
with capture_layers(model, list(range(L))) as caps:
    model(input)
for l in range(L):
    acts[l] = probe_linear(caps[l], task_label)
```

## 五、与其他对比

- 与 层级表征语义结构深入 共享层级探针。
- 与 因果干预与激活修补深入 衔接（定位因果层）。

## 六、常见误区

- 认为某层专司某功能；实际功能跨层重叠分布。
- 忽略残差直连使底层信息直达高层。

## 八、面试题

- 事实编辑为何常选中层 FFN？答：中上层 FFN 是抽象事实变量主要写入处，且尚未被高层推理过度重写。

## 九、演进

单层观察 → 跨层探针 → 因果层级定位。

## 十、小结

FFN 特征随层从局部到抽象演化，是定位与编辑的指南。
