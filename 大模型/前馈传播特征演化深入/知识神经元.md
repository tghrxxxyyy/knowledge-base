# 知识神经元

> 对应 Dai et al., *Knowledge Neurons in Pretrained Transformers*, 2021。

## 一、背景与挑战

事实知识（如"巴黎是法国首都"）在参数中如何分布？是否存在专门编码特定事实的神经元？

## 二、核心原理

作者通过"基于显著性扰动"识别对某一事实回答贡献最大的 FFN 神经元，称为知识神经元；抑制它们会破坏对应事实，增强则提升回忆。

## 三、数学形式

对事实 $f$ 的归因分数 $I_i = \Delta \text{acc}(f \mid \text{mask}_i)$，其中 $\text{mask}_i$ 屏蔽第 $i$ 个神经元激活。

## 四、代码实现

```python
def knowledge_neurons(model, prompt, fact):
    base = model(prompt)
    scores = []
    for i in range(n_neurons):
        with suppress_neuron(model, i):
            scores.append(accuracy_gain(base, model(prompt), fact))
    return topk(scores, k=10)
```

## 五、与其他对比

- 与 FFN作为键值记忆 视角一致但方法不同（扰动 vs 分解）。
- 与 层级表征语义结构深入 衔接（层间知识分布）。

## 六、常见误区

- 知识仅存于单一神经元；多为分布式、跨层协作。
- 归因分数受基线选择影响。

## 八、面试题

- 什么是知识神经元？答：对特定事实回答贡献显著、抑制后该事实丢失的 FFN 神经元。

## 九、演进

探测 → 因果扰动归因 → 跨模型一致性研究。

## 十、小结

知识神经元把事实知识定位到 FFN 子集，为可编辑模型奠基。
