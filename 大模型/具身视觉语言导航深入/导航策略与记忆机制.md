# 导航策略与记忆机制

> 对应 VLN 中记忆与规划研究（如 recurrent 跨模态记忆、拓扑记忆地图）及大模型规划器。

## 一、背景与挑战

长指令导航需记住已访问节点、避免重复、并对接全局目标。无记忆策略易绕圈、丢失目标。挑战是部分可观、错误累积与长程一致性。

## 二、核心原理

引入记忆模块：拓扑地图（记录访问过的 panorama 与连通性）、轨迹历史编码、或外部记忆 Bank。决策时结合当前观测、指令与记忆，输出动作。LLM 可作高层规划器把指令分解为子目标。

## 三、数学形式

记忆更新 m_t = f(m_{t-1}, v_t)。策略：
a_t \sim \pi(a\mid \mathrm{Enc}(v_t), \mathrm{Attn}(I, m_t))
若用 LLM 规划：子目标 g_k = \mathrm{LLM}(I, \mathrm{progress})，agent 执行至达成 g_k 再取下一子目标。

## 四、代码实现

```python
class NavMemory:
    def __init__(self): self.visited=[]
    def update(self, node): self.visited.append(node)
    def mask(self, candidates):
        return [c for c in candidates if c not in self.visited[-5:]]
```

## 五、与其他对比

相比无记忆贪心，记忆防绕圈、提 SPL；相比全图已知，真实部分可观需在线构建；LLM 规划提升长程但增延迟与不确定性。

## 六、常见误区

忽视重复访问致低效；记忆无限增长致噪声；把全局地图当已知；混淆规划与执行层级。

## 八、面试题

- Q：为何需记忆？答：防绕圈、保长程一致。
- Q：记忆形式？答：拓扑图、轨迹历史、外部 Bank。
- Q：LLM 角色？答：高层子目标规划。

## 九、演进

从 RNN 记忆到拓扑地图；从端到端到 LLM 规划+执行；与 VLA 结合统一。

## 十、小结

记忆与分层规划让导航智能体在部分可观长程任务中保持一致性，是 VLN 成功的工程关键。
