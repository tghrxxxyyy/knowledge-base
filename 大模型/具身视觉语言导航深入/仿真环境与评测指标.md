# 仿真环境与评测指标

> 对应 VLN 评测（Success Rate SR、SPL，Anderson et al. 2018）及 Habitat/VLN-CE 连续环境。

## 一、背景与挑战

公平评测需标准环境与指标。离散 R2R 用 SR/SPL；连续 VLN-CE 需把图导航映射到底层运动。挑战是指标对路径效率敏感、对「接近成功」不敏感，以及跨环境泛化评测。

## 二、核心原理

SR 为是否到达目标邻域；SPL（Success weighted by Path Length）惩罚绕路：
\mathrm{SPL}=\frac{1}{N}\sum_i S_i\frac{L_i^*}{\max(L_i,L_i^*)}
其中 L_i^* 为最短专家路径，L_i 为实际。连续环境另计碰撞率与轨迹平滑度。

## 三、数学形式

S_i=1 若到达目标（距离 < 阈值），否则 0。TL 为实际路径长，OL 为最优长：
\mathrm{SPL}=S_i \cdot \frac{OL}{\max(TL, OL)}
还有 nDTW 衡量路径形状与专家相似度。

## 四、代码实现

```python
def spl(success, traj_len, opt_len):
    if not success: return 0.0
    return opt_len / max(traj_len, opt_len)

def sr(pred_dist, goal_thr=3.0):
    return 1.0 if pred_dist <= goal_thr else 0.0
```

## 五、与其他对比

相比只用准确率，SPL 反映效率；相比纯距离，SR 反映任务完成；nDTW 补形状信息。连续环境需额外运动指标。指标选择影响方法排名。

## 六、常见误区

只看 SR 忽略效率；阈值设错致 SR 虚高；未报告 SPL 致不可比；混淆离散与连续评测口径。

## 八、面试题

- Q：SR 与 SPL？答：SR 成功率，SPL 成功加权路径效率。
- Q：为何要 SPL？答：防止绕路达标。
- Q：连续环境指标？答：加碰撞率、轨迹平滑。

## 九、演进

从 SR/SPL 到 nDTW、SDTW；从离散到连续 VLN-CE 统一评测；零样本泛化基准。

## 十、小结

仿真环境与 SR/SPL 等指标构成了 VLN 研究的共同语言，指标的科学设计直接引导方法进步。
