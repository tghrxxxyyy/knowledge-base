# 指令跟随与3D理解

> 对应 3D 视觉语言研究（如 3D-VLA、视觉语言在 3D 场景的接地与指代）及 VLN 中的指令解析。

## 一、背景与挑战

在 3D 场景中理解「把左边的杯子拿起来」需解析空间关系（左/上/前）、物体指代与可执行动作。挑战是 3D 表征（点云/网格/体素）、遮挡与语言空间绑定的准确性。

## 二、核心原理

将 3D 场景编码为 token（点云采样或体素网格 + 位置编码），与指令做 cross-attention 定位目标区域，输出动作或热图。空间关系通过相对坐标与视角变换显式建模，提升指代准确度。

## 三、数学形式

3D 点集 P=\{p_i\in\mathbb{R}^3\}，特征 f_i=E(p_i)。指令关注度：
g_i = \mathrm{softmax}(q_{instr}\cdot f_i/\sqrt{d})
目标区域得分 s = \sum_i g_i \cdot f_i。动作头：
a = \arg\max \pi(a\mid s, q_{instr})

## 四、代码实现

```python
import torch

def ground_3d(points, instr_vec, dim=64):
    feat = point_encoder(points)              # [N, d]
    attn = torch.softmax(instr_vec @ feat.t()/dim**0.5, -1)
    region = (attn.unsqueeze(-1) * feat).sum(0)
    return region                             # 指令对应的 3D 区域向量
```

## 五、与其他对比

相比 2D 视觉指代，3D 需深度与遮挡处理；相比 VLN 路径，这里更重物体级操作；常结合视频/多视角观测消歧。

## 六、常见误区

忽略视角导致左右混淆；用 2D bbox 代替 3D 定位；混淆指代与导航；未处理遮挡致错目标。
