# 权重量化保护

> 对应 GPTQ、AWQ 低精度权重；量化兼具降本与防护。GPTQ 论文给出 4 比特量化。

## 一、背景与挑战

全精度权重易被直接复用与微调；低精度增加逆向与恢复难度，同时降本。

## 二、核心原理

把 FP16 权重压到 INT8 或 INT4（含缩放因子），逆向需先反量化且精度损失难完全恢复。

## 三、数学形式

量化 $\hat w = round(w/s)\cdot s + z$；反量化近似 $w\approx \hat w$，误差 $\epsilon=\|w-\hat w\|$。

## 四、代码实现

```python
q = quantize(weight, bits=4)   # 压到 4 比特
w_hat = dequantize(q)
```

## 五、与其他对比

- 与 综合成本优化（量化降本）交叉。
- 与 权保护总览（双重角色）衔接。

## 六、常见误区

- 量化无密钥仍可反量化近似恢复。
- 误以为量化等同加密（仍需密钥管理）。

- 量化能替代加密吗？答：不能，量化只增逆向难度，仍需静态加密与密钥保护。
