# 权重提取防护

> 对应模型提取攻击防御（查询限额、水印）；学术上模型提取攻击有系统研究。Papernot 研究提取攻击。

## 一、背景与挑战

攻击者可通过大量查询加蒸馏近似复现模型能力，构成无形资产流失。

## 二、核心原理

限制单用户查询频率与覆盖度、对输出加扰动或水印、监测异常查询模式以识别提取。

## 三、数学形式

查询预算：$Q_{user} \le B$；覆盖率 $cov=\frac{|\text{queries}|}{|\mathcal X|}$ 超阈则限。

## 四、代码实现

```python
if queries[t] > BUDGET:
    raise HTTPError(429)
monitor.coverage(req)
```

## 五、与其他对比

- 与 多租户隔离与配额深入（限额）共享。
- 与 权保护总览（防逆向）衔接。

## 六、常见误区

- 仅限额忽略语义覆盖攻击。
- 输出扰动过强损可用。
