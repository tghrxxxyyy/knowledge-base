# 静态加密存储（At-Rest）

> 对应存储加密（AES-256 / KMS）；云盘与对象存储 SSE。AWS KMS 提供信封加密。

## 一、背景与挑战

权重落盘（仓库、磁盘）若明文，磁盘泄露即资产泄露。

## 二、核心原理

权重文件用 AES-256 加密，密钥由 KMS 管理并定期轮换；访问需授权加密钥。

## 三、数学形式

AES-GCM：$c=E_{AES}(w, k, nonce)$，并附认证标签 $tag$ 防篡改。

## 四、代码实现

```python
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
ct = AESGCM(k).encrypt(nonce, w_bytes, None)
```

## 五、与其他对比

- 与 推理时安全解密（加载）衔接。
- 与 权保护总览（一层）共享。

## 六、常见误区

- 密钥与密文同盘存。
- nonce 复用致 AES-GCM 失效。

## 七、与开源书对应

## 八、面试题

- 静态加密要点？答：AES-256 加 KMS 管密钥，nonce 唯一，密钥与密文分离。

## 九、演进

无 → 对称加密 → KMS 与信封加密。

## 十、小结

静态加密防磁盘泄露，是权重保护第一道锁。
