# 模型加密与权重量化保护总览

> 对应模型资产保护（权重加密、安全推理）；NVIDIA Triton 加加密仓库。Triton 支持加密模型仓库。

## 一、背景与挑战

训练好的大模型是核心资产，面临窃取、篡改、逆向风险；需静态与运行时保护。

## 二、核心原理

静态加密存权重、传输 TLS、加载时解密到受保护内存；量化既可降本也可作保护（低精度难逆向）。

## 三、数学形式

密文 $c=E_k(w)$；解密 $w=D_k(c)$；敌手无 $k$ 难恢复 $w$。

## 四、代码实现

```python
key = kms.get("model-key")
weights = decrypt(load_blob("w.bin.enc"), key)
```

## 五、与其他对比

- 与 静态加密存储 / 推理时安全解密 分述。
- 与 权重量化保护（双重作用）衔接。

## 六、常见误区

- 密钥随代码硬编码。
- 只加密传输不加密静态存储。
