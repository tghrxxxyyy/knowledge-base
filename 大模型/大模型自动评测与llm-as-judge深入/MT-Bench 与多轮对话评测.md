# MT-Bench 与多轮对话评测

> 对应 Zheng 2023 LLM-as-judge (MT-Bench)。

## 一、背景与挑战
单轮问答难以反映模型在多轮上下文、指代与状态保持上的能力，需要结构化多轮基准。

## 二、核心原理
MT-Bench 提供 80 个多轮问题，每轮由裁判按 1-10 分评分，覆盖写作、推理、数学等类别。

## 三、形式化与数学基础
多轮总分取各轮均值：
$ S = \frac{1}{T}\sum_{t=1}^{T} s_t $
其中 $s_t$ 为第 t 轮得分。

## 四、代码实现
```python
def mt_bench_score(turns_scores):
    # turns_scores: 每轮裁判分列表
    return sum(turns_scores) / len(turns_scores)
```

## 五、与其他技术对比
相比 MMLU 等静态题，MT-Bench 更贴近真实助手使用，但依赖裁判质量。

## 六、常见误区
把多轮得分简单相加而忽略轮次权重；未区分首轮与续轮难度。

## 七、与开源书/权威来源对应
Zheng 2023 提出并开源 MT-Bench 评测集与裁判提示。

## 八、面试题
多轮评测为何比单轮更难？如何防止上下文泄漏？

## 九、演进与趋势
扩展到工具调用轮次与长上下文一致性评测。

## 十、小结
MT-Bench 把对话质量纳入自动评测，但仍需人工抽检校验。
