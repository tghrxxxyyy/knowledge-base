# 裁判一致性度量与人工对齐

> 对应 Zheng et al. 2023《Judging LLM-as-a-Judge with MT-Bench and Chatbot Arena》与 Es et al. 2023《RAGAS: Automated Evaluation of Retrieval Augmented Generation》。

## 一、背景与挑战
自动裁判只有在与人类判断高度一致时才具备可用性。一致性未经验证的裁判，会以「客观数字」的外衣放大系统性错误：它可能稳定地偏爱冗长回答，也可能在某个类别上整体判反。因此，一致性问题本质上是「把自动裁判当作测量仪器来做标定」的问题。

实践中的困难有三：一是需要一批带人类标签的样本作为标定基准，而人工标注成本高；二是单一的一致率数字会掩盖分歧的结构（哪些类别、哪种失败模式）；三是裁判会随模型版本、提示、温度变化而漂移，一致性必须持续监控而非一次性验证。

## 二、核心原理
基本流程是：在同一批样本上，分别收集人类标签 $y_i$ 与裁判标签 $\hat{y}_i$，计算一致性指标，并进一步分析分歧样本的分布与失败模式。

指标选择上，百分比一致率直观但会高估——因为即使双方都在随机猜，也可能有一定比例碰巧相同。Cohen's kappa 通过减去随机一致基线修正了这一点。对于分类别、多裁判的情形，可扩展到 Fleiss kappa；对于打分制等有序标签，可用加权 kappa 体现「差一档」与「差很多」的不同严重程度。

分析层面，除了总体指标，还应做分层抽样与混淆矩阵，观察一致率在不同类别、不同难度、不同长度上的差异，把「一致」拆解成可行动的信息。

## 三、形式化与数学基础
定义观测一致率：

$$ p_o = \frac{1}{N}\sum_{i=1}^{N}\mathbb{1}\bigl[y_i = \hat{y}_i\bigr] $$

随机一致率 $p_e$ 由两方的标签边缘分布计算（二分类时 $p_e = p_{human}(1)\,p_{judge}(1) + p_{human}(0)\,p_{judge}(0)$），则：

$$ \kappa = \frac{p_o - p_e}{1 - p_e} $$

$\kappa$ 越大越好，但「多好才算好」没有通用阈值，应结合任务风险与人类标注者之间的一致性水平来判断——若人类彼此的一致率也不高，则不应苛求裁判超过人类自身的一致性上限。

对于有序打分（如 1-5 分），加权 kappa 使用权重矩阵 $w_{ij}$（如线性或二次权重）度量偏离程度：

$$ \kappa_w = 1 - \frac{\sum_{i,j} w_{ij}\,O_{ij}}{\sum_{i,j} w_{ij}\,E_{ij}} $$

其中 $O_{ij}$、$E_{ij}$ 分别为观测与期望的混淆计数。

## 四、代码实现
```python
# 百分比一致率与 Cohen's kappa（二分类版本）
def agreement(y_human, y_judge):
    assert len(y_human) == len(y_judge)
    n = len(y_human)
    po = sum(1 for a, b in zip(y_human, y_judge) if a == b) / n
    # 边缘分布
    ph1 = sum(y_human) / n
    pj1 = sum(y_judge) / n
    pe = ph1 * pj1 + (1 - ph1) * (1 - pj1)
    kappa = (po - pe) / (1 - pe) if pe != 1 else 0.0
    return po, kappa

# 输出分歧样本，供人工复核失败模式
def disagreements(y_human, y_judge, samples):
    return [s for s, a, b in zip(samples, y_human, y_judge) if a != b]
```

## 五、与其他技术对比
| 指标 | 剔除随机基线 | 适用标签类型 | 局限 |
| --- | --- | --- | --- |
| 百分比一致率 | 否 | 任意 | 高估一致性 |
| Cohen's kappa | 是 | 两名标注者、类别标签 | 对边缘分布敏感 |
| Fleiss kappa | 是 | 多名标注者 | 假设标注者同质 |
| 加权 kappa | 是 | 有序标签 | 权重需人为设定 |
| 相关系数（如 ICC） | 部分 | 连续打分 | 不适合类别标签 |

单看准确率会高估，kappa 更严格；分层抽样能暴露类别级不一致；对有序评分则应使用加权形式，避免把「近邻错误」与「严重错误」等量齐观。

## 六、常见误区
误区一：「只在简单样本上报告一致率」。错，容易得到虚高的对齐度。误区二：「只报告总体数字，不报告分歧样本的失败模式」。错，无法指导改进。误区三：「kappa 高就一定好」。错，kappa 受类别不平衡影响，需结合混淆矩阵解读。误区四：「人类标签天然是金标准」。错，人类标注者之间也可能不一致，应报告其内部一致率作为参考上限。误区五：「一次对齐后就不再监控」。错，裁判随版本漂移，需持续跟踪。

## 九、演进与趋势
趋势之一是用人类反馈微调专用裁判模型，把对齐从「事后度量」推进到「训练目标」。趋势之二是把一致性监控自动化、看板化，像跟踪服务健康度一样持续跟踪位置一致率、类别一致率与分歧样本比例。趋势之三是发布分歧可视化与复核工具，让人工把精力集中在真正模糊的样本上，而非均匀抽检。

实践中的一致性报告模板可参考如下结构：

- 规模与抽样：样本总数、分层方式、人类标注者数量与内部一致率。
- 总体指标：百分比一致率与 kappa，附混淆矩阵。
- 分层指标：按类别、难度、长度分桶的一致率对比。
- 分歧分析：典型失败模式举例与占比。
- 结论与行动：是否可用于门禁、需在哪些类别增补人工。

当裁判用于发布门禁时，建议设定「最低一致性门槛 + 关键类别单独门槛」的双重约束，避免总体达标而关键场景失效。

## 十、小结
一致性度量是裁判可信度的硬指标，必须以 kappa 等剔除随机基线的指标为主，辅以分层分析与分歧失败模式归因。它的意义不在于产生一个「好看的数字」，而在于持续回答「这个裁判现在还能不能信、在哪里不可信」。把一致性当作随版本持续监控的健康度指标，是自动评测走向生产可用的必经之路。
