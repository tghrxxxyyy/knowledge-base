# 裁判一致性度量与人工对齐

> 对应 Zheng 2023 LLM-as-judge 与 Es 2023 RAGAS。

## 一、背景与挑战
自动裁判只有在与人类高度一致时才可用，否则会放大错误结论，需要定量对齐报告。

## 二、核心原理
从同一批样本上收集人类与裁判的标签，计算一致性，并分析分歧分布。

## 三、形式化与数学基础
使用百分比一致与 kappa 双重指标：
$ p_o = \frac{1}{N}\sum_i \mathbb{1}[y_i = \hat{y}_i] $
配合 $\kappa$ 排除随机一致。

## 四、代码实现
```python
def agreement(y, yhat):
    # y: 人类标签, yhat: 裁判标签
    match = sum(1 for a, b in zip(y, yhat) if a == b)
    return match / len(y)
```

## 五、与其他技术对比
单看准确率会高估，kappa 更严格；分层抽样能暴露类别级不一致。

## 六、常见误区
只在简单样本上报告一致率；未报告分歧样本的失败模式。
