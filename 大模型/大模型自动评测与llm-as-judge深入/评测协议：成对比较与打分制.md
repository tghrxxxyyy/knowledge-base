# 评测协议：成对比较与打分制

> 对应 Zheng 2023 LLM-as-judge 与 Gao 2021 lm-evaluation-harness。

## 一、背景与挑战
评测协议决定了分数是否可比。pairwise 比较稳健但无法给出绝对分；打分制可比但受量表锚定影响。

## 二、核心原理
pairwise 让裁判选 A/B/平局；打分制让裁判在 1-10 分上给出绝对评分。两者可统一为偏好概率建模。

## 三、形式化与数学基础
把 pairwise 胜者视为伯努利变量，用 Bradley-Terry 模型估计实力：
$ P(A \succ B) = \frac{e^{s_A}}{e^{s_A} + e^{s_B}} $
其中 $s_A, s_B$ 为隐含实力分。

## 四、代码实现
```python
def bradley_terry(sa, sb):
    # 由实力分计算 A 胜出概率
    import math
    return math.exp(sa) / (math.exp(sa) + math.exp(sb))
```

## 五、与其他技术对比
pairwise 对量表漂移鲁棒，打分制便于跨模型排序与阈值告警，但需锚定参考回答。

## 六、常见误区
把打分简单平均而不检查方差；忽略平局率过高意味着区分度不足。

## 七、与开源书/权威来源对应

## 九、演进与趋势

## 十、小结
评测协议需与下游用途匹配，并配合统计聚合以降低随机性。
