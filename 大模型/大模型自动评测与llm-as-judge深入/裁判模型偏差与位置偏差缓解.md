# 裁判模型偏差与位置偏差缓解

> 对应 Zheng 2023 LLM-as-judge 与 Ouyang 2022 RLHF/InstructGPT。

## 一、背景与挑战
裁判常偏向先出现的回答（位置偏差）、更长的回答（长度偏差）以及自身生成的风格（自我偏好偏差）。

## 二、核心原理
通过双向交换顺序、控制长度、以及让裁判在不知道来源的情况下打分来暴露并消除系统性偏差。

## 三、形式化与数学基础
位置偏差可用交换一致率度量：
$ b_{pos} = 1 - \frac{1}{N}\sum_{i=1}^{N} \mathbb{1}[o_i = o_i^{swap}] $
值越低说明位置越影响结果。

## 四、代码实现
```python
def swap_eval(prompt, a, b, model):
    # 两次调用交换位置
    r1 = model.judge(prompt, a, b)
    r2 = model.judge(prompt, b, a)
    return r1, r2
```

## 五、与其他技术对比
相比单轮打分，双向交换成本低且能直接估计偏差上界。

## 六、常见误区
只报告单向结果；未对长度做归一化导致裁判偏好冗长回答。

## 七、与开源书/权威来源对应

## 九、演进与趋势

## 十、小结
