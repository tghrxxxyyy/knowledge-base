# 裁判模型偏差与位置偏差缓解

> 对应 Zheng et al. 2023《Judging LLM-as-a-Judge with MT-Bench and Chatbot Arena》与 Ouyang et al. 2022《Training language models to follow instructions with human feedback》。

## 一、背景与挑战
裁判模型并非中立测量仪。实验反复观察到三类系统性偏差：位置偏差（偏向先出现或后出现的回答）、长度偏差（倾向给更长的回答更高分）、自我偏好偏差（偏好自己或同族模型生成的风格）。这些偏差与回答的真实质量无关，却会系统性地扭曲评测结论。

危害在于：一旦评测分数被用于模型选型、发布门禁或论文结论，偏差就会被固化进决策，形成「分数好看但用户体验没变」，甚至「为了刷分而迎合裁判偏好」的恶性循环。因此，偏差的暴露与缓解不是可选项，而是可信评测的前提。

## 二、核心原理
缓解思路分三类：用实验设计暴露偏差、用提示与协议抵消偏差、用校准与训练抑制偏差。

暴露偏差最有效的手段是「交换实验」：同一对回答，正序评一次、交换位置再评一次。若两次结论一致，说明判断对位置不敏感；若不一致，则位置影响了结果。对长度偏差，可构造「内容相同但长度不同」的对照样本；对自我偏好，可让裁判在不知来源（匿名化、统一风格）的条件下评分。

抵消偏差的常用协议包括：双向交换后取一致结论、对候选顺序随机化、对分数按长度做回归校正、多裁判投票。更根本的做法是用人类偏好数据对裁判做校准或微调，把偏差作为优化目标中的惩罚项。

## 三、形式化与数学基础
设正序判断为 $o_i$，交换顺序后的判断为 $o_i^{swap}$，定义「交换一致率」衡量位置不敏感的程度：

$$ c_{pos} = \frac{1}{N}\sum_{i=1}^{N}\mathbb{1}\bigl[o_i = o_i^{swap}\bigr] $$

位置偏差可用其补度量：

$$ b_{pos} = 1 - c_{pos} $$

$b_{pos}$ 越大说明位置越显著地影响结论。注意在双向交换中，「一致」通常指两次都指向同一被评对象（例如正序选 A、交换后选 B，两者都对应同一回答），需在实现时明确定义映射关系，避免把「一致与否」算错。

长度偏差可用回归刻画：设回答长度为 $L$，评判分数为 $s$，拟合 $s = \alpha L + \beta q + \varepsilon$（$q$ 为潜在质量），$\alpha$ 显著为正即提示长度偏差。缓解可在打分时对 $L$ 做归一化或直接约束裁判「忽略长度与格式」。

## 四、代码实现
```python
# 双向交换评测：量化位置偏差
def swap_eval(question, a, b, model):
    first = model.judge(question, a, b)     # 正序
    second = model.judge(question, b, a)    # 交换
    # 把交换后的结论映射回「原始回答」语义再比较
    return first, second

def position_bias(records):
    # records: 每项含 (first, second)，均已映射到回答身份
    inconsistent = sum(1 for f, s in records if f != s)
    return inconsistent / len(records)     # 越大表示位置偏差越强
```

```text
# 缓解协议（工程实践）
- 候选顺序随机化，避免固定位置被偏好
- 双向交换，只采纳两次一致的结论，分歧转人工
- 统一回答格式、匿名来源，抑制自我偏好与格式偏差
- 多裁判投票，降低单一裁判的偏差
- 按长度做回归校正，或明确指示忽略长度
```

## 五、与其他技术对比
| 偏差缓解手段 | 成本 | 有效性 | 局限 |
| --- | --- | --- | --- |
| 双向交换 | 低（2x 调用） | 直接估计位置偏差 | 分歧样本仍需裁决 |
| 顺序随机化 | 极低 | 消除固定位置优势 | 不解决长度/自我偏好 |
| 长度校正 | 中 | 抑制长度偏差 | 需估计质量，较难 |
| 多裁判投票 | 高 | 降低单裁判偏差 | 成本与延迟上升 |
| 裁判微调/校准 | 很高 | 最根本 | 需高质量人类数据 |

工程上通常组合使用：先用随机化与匿名化消除显性偏差，再用双向交换识别残余位置效应，最后用多裁判或校准处理难以消除的部分。

## 六、常见误区
误区一：「只报告单向结果就够了」。错，不交换顺序无法暴露位置偏差。误区二：「不做长度归一化，认为裁判会自己忽略长度」。错，长度偏差是稳定可复现的。误区三：「交换后两次都选同一个位置就叫一致」。错，这是把位置偏好误读为一致，需先做身份映射再比较。误区四：「缓解偏差会损失信号」。错，合理的交换与校正提升的是与人类判断的对齐度。误区五：「一次校准后永久有效」。错，裁判模型或提示变更后偏差会变化，需持续监控。

## 九、演进与趋势
趋势是从「事后校正」走向「训练时抑制」：用带偏差标注的人类数据微调专用裁判，把偏差作为正则项或对抗目标；同时发展校准后的裁判，使其输出带有不确定性。工程侧则把偏差监控纳入评测流水线，像监控模型指标一样持续跟踪位置一致率、长度相关性等健康度指标。

落地偏差监控时，建议固定产出以下指标随时间的变化曲线：

- 位置一致率：正序与交换序结论一致的比例。
- 长度相关性：裁判分数与回答长度的相关系数。
- 自我偏好度：裁判给自身或同族模型的偏爱幅度（用匿名化对照测量）。
- 格式敏感度：仅改变排版、不改内容时分数变化的幅度。

缓解偏差的优先级建议：

- 先做零成本项：匿名化来源、统一格式、随机化候选顺序。
- 再加低成本项：双向交换、分歧样本转人工。
- 最后投入高成本项：多裁判集成、裁判微调与校准。

## 十、小结
裁判偏差是自动评测可信度的最大威胁，其中位置、长度与自我偏好三类最为常见且可复现。缓解的核心是「用设计暴露偏差、用协议抵消偏差、用校准抑制偏差」：双向交换估计位置效应，匿名化与格式统一抑制自我偏好，回归校正与多裁判处理长度与其他系统偏差。把偏差当作必须量化并持续监控的指标，而非一次性的修补。
