# 自动评测流水线与可复现性

> 对应 Gao 2021 lm-evaluation-harness 与 Zheng 2023 LLM-as-judge。

## 一、背景与挑战
评测结论若不可复现则无意义。需要在固定模型版本、提示、采样参数下重跑整套评测。

## 二、核心原理
把数据集、提示模板、裁判、聚合脚本固化为可版本化配置，每次只变更被评模型。

## 三、形式化与数学基础
对多次运行取均值与置信区间：
$ \bar{s} \pm 1.96 \frac{\sigma}{\sqrt{k}} $
其中 k 为重复次数。

## 四、代码实现
```python
def mean_ci(scores):
    # 返回均值与 95% 置信半宽
    import math, statistics
    m = statistics.mean(scores)
    se = statistics.pstdev(scores) / math.sqrt(len(scores))
    return m, 1.96 * se
```

## 五、与其他技术对比
相比一次性脚本，流水线化能保证偏差可追踪、结果可 diff。

## 六、常见误区
未固定随机种子导致分数漂移；把不同温度下的结果混用比较。
