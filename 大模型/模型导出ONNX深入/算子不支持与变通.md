# 算子不支持与变通

> 对应 PyTorch, *onnx-script / Custom Ops*（可注册自定义算子）；与 模型导出ONNX深入 衔接。

## 一、背景与挑战

部分新/自定义算子无对应 ONNX 标准节点，导出失败或不兼容。

## 二、核心原理

用 `onnxscript` 以 Python 组合标准算子定义新行为，或注册 CustomOp 交给运行时实现；Triton/ORT 均可挂自定义 kernel。

## 三、数学形式

自定义算子 $f_{custom}$ 需满足 $f_{custom}\equiv \text{ORT\_impl}$，否则数值核验失败。

## 四、代码实现

```python
@onnxscript.script()
def MyGelu(x):
    return x * 0.5 * (1 + op.Erf(x / math.sqrt(2)))
```

## 五、与其他对比

- 与 编译部署深入（编译器也需支持算子）呼应。
- 与 ONNX总览（opset 缺失场景）相关。

## 六、常见误区

- 自定义算子只在某引擎实现，换引擎即崩。
- 数值与 PyTorch 不一致未做对齐测试。

## 七、与开源书对应

## 八、面试题

- 算子不支持怎么办？答：用 onnx-script 组合标准算子或注册 CustomOp，并在引擎侧实现。

## 九、演进

报错即改 → onnx-script 表达 → 自定义 kernel 接入。

## 十、小结

算子缺口用脚本化组合或自定义算子补齐，须保证跨引擎一致。
