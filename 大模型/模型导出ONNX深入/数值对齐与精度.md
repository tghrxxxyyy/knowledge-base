# 数值对齐与精度

> 对应 ONNX Runtime, *Quantization Tool & Numeric Validation*；与 模型导出ONNX深入 / 量化编译流水线 衔接。

## 一、背景与挑战

导出/量化后输出与 PyTorch 有偏差，需量化评估与修正。

## 二、核心原理

用相同输入比对 PyTorch 与 ONNX 输出（余弦相似度/MSE），定位偏差算子；必要时提高精度或修正 scale。

## 三、数学形式

误差 $\epsilon=\|y_{torch}-y_{onnx}\|_2$；相似度 $\cos(y_{torch},y_{onnx})$ 应接近 1。

## 四、代码实现

```python
out_t = torch_model(x)
out_o = sess.run(None, {"x": x.numpy()})[0]
print("cos", F.cosine_similarity(out_t, torch.tensor(out_o), 0).item())
```

## 五、与其他对比

- 与 量化编译流水线（量化放大误差）相关。
- 与 ONNX总览（校验模型）呼应。

## 六、常见误区

- 只比最终 logits 忽略中间层漂移。
- 用单样本比对得出错误结论。
