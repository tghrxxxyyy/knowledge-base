# 无限上下文总览

> 对应 Chen et al., *Extending Context Window of LLMs via Positional Interpolation*, 2023；Press et al., *ALiBi*, 2022；Rae et al., *Compressive Transformers*, 2019。

## 一、背景与挑战

预训练上下文长度固定（如 2k/4k），现实任务需处理书籍、代码库、多轮长对话，超出即截断丢信息。

## 二、核心原理

“无限上下文”并非真无限，而是三类技术组合：(1) 位置编码外推/插值扩展训练长度；(2) 记忆压缩/循环缓存处理超长历史；(3) 分块流式注意力避免 $O(n^2)$ 爆炸。

## 三、数学形式

扩展后有效位置 $i' = i/s$（$s$ 缩放）；压缩记忆 $M = \mathrm{Compress}(h_{<t})$；流式状态 $S_t=f(S_{t-1},x_t)$。

## 四、代码实现

```python
# 位置插值扩展

out = model(x, pos_encoding=rope_ext)
```

## 五、与其他对比

- 与 相对位置编码深入（PI/NTK）共享外推主题。
- 与 FlashAttention深入 互补：FA 解决效率，本主题解决长度泛化。

## 六、常见误区

- 以为换大位置就能无限；未重训/插值则分布外。
- 混淆“长上下文”与“真正无限记忆”。

## 八、面试题

- 实现长上下文有哪几条路线？答：位置插值外推、记忆压缩、分块流式注意力。

## 九、演进

固定长度 → 位置外推 → 记忆压缩+流式 → 百万级上下文。

## 十、小结

无限上下文是外推、压缩、流式三项技术的工程整合，而非单一算法。
