# 记忆压缩机制

> 对应 Rae et al., *Compressive Transformers for Long Sequence Modelling*, 2019；以及 recurrent memory（如 Transformer-XL memory）。

## 一、背景与挑战

超长历史无法全部留在注意力窗口，需把远处信息压缩沉淀为长期记忆。

## 二、核心原理

把较早的隐藏状态移出注意力窗口，经一个轻量压缩网络（卷积/池化/瓶颈）降维存入 memory；当前步注意力可同时看近期细粒度与远处压缩记忆，兼顾长程与效率。

## 三、数学形式

$m_t = \mathrm{Compress}(h_{t-k}^{old})$；注意力键集合 $K = [m_t; h_{recent}]$，在压缩记忆与近期状态上做注意力。

## 四、代码实现

```python
mem = compress(old_hidden)              # 压缩远处
K = torch.cat([mem, recent_k], dim=1)  # 长程+近期
out = attend(q, K, V_cat)
```

## 五、与其他对比

- 与 线性注意力深入 的递推状态异曲同工（都在累积历史）。
- 与 流式与分块（下节）互补。

## 六、常见误区

- 压缩过激进丢关键信息；需可学习压缩。
- 记忆与近期窗口尺度不一，注意力失衡。

## 八、面试题

- 记忆压缩如何处理超长上下文？答：把远处隐藏状态压缩沉淀为 memory，注意力兼顾近期与压缩长程。

## 九、演进

固定窗口 → Transformer-XL memory → Compressive Transformer → 可微记忆。

## 十、小结

记忆压缩把长历史沉淀为可检索状态，是逼近“无限上下文”的关键机制。
