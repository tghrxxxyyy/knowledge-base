# 无限上下文实现

> 对应实践：位置插值微调 + KV 缓存 + 分块流式（LLaMA/长上下文开源实现）。

## 一、背景与挑战

要把上述技术组合落地，需要协调位置编码、缓存、批处理与评估。

## 二、核心原理

实现链路：选外推方案（PI/NTK 或 ALiBi）→ 少量长文本微调适配 → 推理用分块+KV 缓存 → 评估用长程检索/合成长任务验证。注意位置与缓存一致性。

## 三、数学形式

有效长度 $L_{eff}=s\cdot L_{train}$（$s$ 为插值缩放）；缓存增量 $KV_{new}$ 追加，$cost=O(n)$ 每步。

## 四、代码实现

```python
model.config.rope_scaling = {"type": "dynamic", "factor": 4.0}  # NTK/dynamic
for chunk in stream(x):
    out = model(chunk, past_key_values=cache); cache = out.past_key_values
```

## 五、与其他对比

- 与 相对位置编码深入（外推）/ FlashAttention深入（效率）共同构成方案。
- 与 稀疏注意力深入 可叠加进一步降成本。

## 六、常见误区

- 只换位置不验证长程检索，实际仍丢远处信息。
- 缓存未做位置对齐导致跨块注意力错误。
