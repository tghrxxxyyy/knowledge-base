# 自适应学习率实践

> 对应大模型训练优化器配方（AdamW + warmup + cosine；β2 调整等）。

## 一、背景与挑战

自适应优化器需配合调度与warmup才稳，否则训练崩或泛化差。

## 二、核心原理

大模型常用 AdamW + 线性 warmup + 余弦衰减；β2 后期调大；分层 LR；权重衰减解耦。

## 三、数学形式

组合更新含 RMS 缩放、动量、解耦衰减与调度乘子 $\eta(t)$。

## 四、代码实现

```python
opt = AdamW(p, lr=1e-3, betas=(0.9,0.95), weight_decay=0.1)
sched = get_cosine_schedule_with_warmup(...)
```

## 五、与其他对比

- 与 权重衰减深入（AdamW）协同。
- 与 梯度噪声深入（LR 调度）关联。

## 六、常见误区

- warmup 过长拖慢、过短不稳。
- 直接套用默认 β 不调后期。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh
- mlabonne/llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- 大模型为何要 warmup？答：初期 Adam 二阶矩估计不稳，warmup 防止大 LR 破坏早期训练。

## 九、演进

固定 LR → warmup → 余弦+分层。

## 十、小结

自适应优化器需调度与 warmup 配合，是现代训练的标准组合。
