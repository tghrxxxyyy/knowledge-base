# 自适应学习率总览

> 对应 Duchi et al., *Adaptive Subgradient Methods (AdaGrad)*, 2011；Kingma & Ba, *Adam*, ICLR 2015。

## 一、背景与挑战

稀疏/异质梯度下统一学习率低效；自适应方法按参数历史梯度缩放步长。

## 二、核心原理

维护梯度二阶矩（或累积平方）估计，用其逐元素归一化更新，使频繁与罕见特征各有合适步长。

## 三、数学形式

通用更新 $\theta_{t+1}=\theta_t-\frac{\eta}{\sqrt{v_t}+\epsilon}\,g_t$，其中 $v_t$ 为历史梯度平方的累积。

## 四、代码实现

```python
v = beta*v + (1-beta)*g*g
theta -= lr*g/(v.sqrt()+eps)
```

## 五、与其他对比

- 与 二阶优化深入 是廉价对角预条件。
- 与 权重衰减深入（AdamW）结合。

## 六、常见误区

- 以为自适应就无需调 LR，warmup 仍关键。
- 忽视 epsilon 对数值与收敛的影响。

## 九、演进

AdaGrad → RMSProp → Adam → 变体。

## 十、小结

自适应学习率以对角预条件提升鲁棒性，是现代优化器基石。
