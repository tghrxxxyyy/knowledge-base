# 少样本与零样本学习

> 见「迁移与元学习深入/少样本与元学习」与「提示工程深入/少样本提示」；Brown et al., *GPT-3*, 2020（in-context）。

## 一、背景与挑战

新类/新任务仅有 1~数例，甚至 0 例，模型需即时适配。

## 二、核心原理

- **零样本**：依赖预训练知识+文本描述直接推断（CLIP/LLM 提示）。
- **少样本（in-context）**：在提示中给若干示例，模型「现学现用」不需梯度更新（GPT-3 展现）。
- **元学习**：在大量任务上训练「快速适应」能力（见元学习章）。

## 三、关键要点

- 大模型 in-context 少样本极强。
- 示例选择/排序影响大（见提示工程）。

## 四、代码实现

```python
prompt = "例1...例2...现问题:" + q
```

## 五、与其他对比

- 微调需梯度；in-context 零梯度。

## 六、常见误区

- 少样本必准——示例质量关键。
