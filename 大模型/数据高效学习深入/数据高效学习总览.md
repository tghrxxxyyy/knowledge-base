# 数据高效学习总览

> 对应 d2l-zh 与 llm-course；综述见 Wang et al., *Data-Efficient Learning*, 2022。

## 一、背景与挑战

高质量标注昂贵、稀缺；如何在有限数据下训练强模型是工业与科研常态。

## 二、核心原理

数据高效学习是 umbrella：含半监督、主动学习、少样本/元学习、数据增广、课程/课程式采样、知识蒸馏等。核心思想：**从更少标注、更多未标注/合成数据中榨取信息**。

## 三、关键要点

- 数据质量 > 数量（尤其预训练后阶段）。
- 增广与合成可低成本扩样。
- 主动学习把标注预算用在刀刃上。

## 五、与其他对比

| 方法 | 数据需求 |
|------|----------|
| 全监督 | 大量标注 |
| 半监督 | 少量标注+大量无标 |
| 主动 | 迭代选标 |
