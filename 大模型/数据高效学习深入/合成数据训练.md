# 合成数据训练

> 见「合成数据与课程学习」与「数据高效学习深入/数据高效学习总览」；大模型预训练常用自生成数据。

## 一、背景与挑战

真实数据触顶且含隐私/版权问题，合成数据可无限扩。

## 二、核心原理

用强模型生成训练样本（蒸馏/自举），如：指令数据由 GPT-4 生成（Self-Instruct）、数学题由模型合成、代码由模型生成。需**过滤与去重**防分布偏移与退化。

## 三、关键要点

- 合成数据可补长尾/难例。
- 循环使用会「模型坍塌」（自我强化偏差）。
- 需真实数据锚定分布。

## 四、代码实现

```python
synthetic = teacher.generate(prompts)
data = filter_quality(synthetic) + real
```

## 五、与其他对比

- 真实贵但稳；合成便宜但需筛。

## 六、常见误区

- 合成可全替代真实——不可。
