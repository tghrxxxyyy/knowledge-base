# 课程与数据混合

> 见「课程学习深入/LLM课程训练」与「数据高效学习深入/数据高效学习总览」。

## 一、背景与挑战

多源数据混合比例显著影响能力与收敛。

## 二、核心原理

按质量/领域/语言加权采样：高质数据高权重，代码/数学分阶段加入，低质降权。可用课程式（先易后难）或 DoReMi 等**数据配比优化**自动学权重。

## 三、关键要点

- 配比不当会「灾难性污染」（低质淹没高质）。
- 训练后期可偏向难/高质数据。

## 四、代码实现

```python
weights = {"web": 0.6, "code": 0.2, "math": 0.2}
sample = multinomial_sample(weights)
```
