# 数据增广策略

> 见「数据高效学习深入/数据高效学习总览」；Cubuk et al., *AutoAugment*, 2019；视觉与文本各自策略。

## 一、背景与挑战

样本有限时过拟合，增广制造「合理变体」扩充分布。

## 二、核心原理

- 图像：翻转/裁剪/色彩/混合（Mixup/CutMix）。
- 文本：同义替换/回译/EDA；LLM 时代用模型生成合成样本。
- 自动增广（AutoAugment/ RandAugment）搜索最优策略。
- 增广须保标签语义（不改变真值）。

## 三、数学形式

Mixup：`x̃ = λx_i + (1-λ)x_j, ỹ = λy_i + (1-λ)y_j`。

## 四、代码实现

```python
lam = beta(0.2, 0.2)
x_mix = lam*x1 + (1-lam)*x2
```

## 五、关键要点

- 增广强度需适配任务。
- 文本增广易改义，需谨慎。

## 六、与其他对比

- 真实数据最稳；合成增广补充。

## 七、常见误区

- 增广越多越好——过强失真。
