# 数据质量与去重

> 见「训练数据质量」与「数据高效学习深入/数据高效学习总览」；Lee et al., *Deduplicating*, 2021。

## 一、背景与挑战

重复/低质数据既浪费算力又损泛化，去重是关键预处理。

## 二、核心原理

- **精确/近邻去重**：基于 hash（MinHash/SimHash）去除重复文档。
- **质量过滤**：按困惑度、启发式规则（如符号比、长度）筛低质。
- **毒性/隐私过滤**：去除有害与个人识别内容。
Lee et al. (2021) 证明去重显著提升 C4 预训练效果。

## 三、关键要点

- 去重可提升样本效率。
- 质量过滤阈值需平衡保留量。

## 四、代码实现

```python
hashes = [minhash(doc) for doc in corpus]
keep = dedupe(hashes)
```

## 五、与其他对比

- 用量多但含重；去重后用得精。

## 六、常见误区

- 数据不重——实际 web 数据重复率极高。
