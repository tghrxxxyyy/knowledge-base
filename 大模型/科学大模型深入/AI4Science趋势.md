# AI4Science 趋势

> 对应 llm-course（mlabonne）科学 AI 章节；AlphaFold3（Abramson et al., 2024, Nature）等科学基础模型；各领域基础模型（MatterGen、ClimateGPT 等）的代表性工作（具体细节以官方最新文档为准）。

## 一、背景与挑战

「AI for Science」指用 AI（尤其大模型）加速自然科学发现。传统科研各学科的建模语言不同（生物用序列、化学用 SMILES、材料用晶体、气候用网格），导致模型割裂、迁移困难。核心挑战：

- 模态异构：文本、序列、结构、图像、图谱表示迥异，难以统一。
- 物理约束强：科学预测必须满足守恒律、对称性、能量最小等先验。
- 数据稀缺且噪声大：高质量标注实验数据远少于互联网文本。
- 可解释与可复现：科学结论需可证伪、可溯源，不能黑箱拍脑袋。

## 二、核心原理

AI4Science 的两条主线：

1. 领域专用基础模型：在单一学科数据上预训练（如蛋白、分子、材料），学到学科「第一性原理」附近的表征。
2. 跨模态统一表征：用共享编码器把文本/序列/结构/图像映射到同一隐空间，通过对比或生成目标对齐，再用统一主干做多任务。

物理先验通过「硬约束」（如等变网络 SE(3)、能量守恒损失）或「软约束」（在损失中加物理正则）融入。统一模型可支撑药物筛选、材料发现、气候模拟、方程求解等。

## 三、形式化与数学基础

跨模态对齐常采用对比损失（InfoNCE）。对配对样本 $(x_i,y_i)$，令 $f,g$ 为两模态编码器，温度 $\tau>0$：

$$ \mathcal{L}=-\sum_i \log \frac{\exp(\langle f(x_i),g(y_i)\rangle/\tau)}{\sum_j \exp(\langle f(x_i),g(y_j)\rangle/\tau)} $$

等变网络要求对变换 $g\in G$（如旋转）满足

$$ \Phi(T_g(x)) = R_g\,\Phi(x) $$

以保证物理对称性不被破坏。

## 四、代码实现

```python
# 跨模态对齐示意（文本-结构对比）
import torch, torch.nn as nn

text_enc = nn.Linear(768, 256)    # 文本编码器输出
struct_enc = nn.Linear(1024, 256)  # 结构编码器输出
tau = 0.07

def contrastive(t, s):
    # 归一化到单位球
    t = nn.functional.normalize(text_enc(t))
    s = nn.functional.normalize(struct_enc(s))
    logits = t @ s.t() / tau
    labels = torch.arange(t.size(0))
    return nn.functional.cross_entropy(logits, labels)
```

## 五、与其他技术对比

| 路线 | 代表性 | 优势 | 风险 |
|------|--------|------|------|
| 单模态专用模型 | AlphaFold、ESM | 深度高 | 难迁移 |
| 多模态统一 | AlphaFold3、通用科学基座 | 通用 | 数据难对齐 |
| 物理驱动（PINN/符号回归） | 物理信息神经网络 | 可解释 | 表达受限 |

融合「数据驱动 + 物理约束」是当前共识。

## 六、常见误区

- 越大越好：科学领域数据质量与物理约束比单纯规模更关键。
- 端到端替代第一性原理：DFT/分子动力学仍是验证基准，AI 是加速而非替代。
- 忽视不确定性：科学预测必须给置信区间，避免幻觉式结论。
- 忽视评测闭环：没有领域基准与可复现验证的「科学模型」只是包装，无法进入真实科研管线。

补充一点：跨模态对齐的失败往往源于「表示空间不对齐」而非「模型容量不足」。实践中常见做法是先用对比学习把不同模态拉到同一语义空间，再联合微调；若直接端到端训练，梯度易被单一主导模态绑架。这一细节决定了统一科学基础模型能否真正跨域迁移。

## 九、演进与趋势

单模态专用模型 → 跨模态对齐 → 统一科学基础模型（一个主干服务多任务）→ 生成—验证闭环（结合模拟/实验）。趋势是「科学基础模型 + 工具调用 + 可复现评测」的科研智能体。值得强调的是，AI4Science 并不追求「用一个模型替代所有学科」，而是在「共享表征底座 + 领域适配器」的折中上演进：底座负责通用的分子/序列/文本语义，适配器承载各学科的第一性原理约束，从而在复用与专业性间取得平衡。落地时团队也常在「数据驱动 vs 物理驱动、通用基座 vs 专用模型、黑箱预测 vs 可解释」三类权衡间取舍：探索性、数据充足的场景优先数据驱动，强约束、安全第一的场景（如核、航天）坚持物理可解释。

在资源受限的科研团队中，优先考虑「复用已有科学基础模型 + 轻量微调/适配器」往往比从头训练更现实，也更容易复现。

评测上，跨模态统一模型不能只看单任务分数，还需引入「分布外泛化」与「物理一致性」指标，防止模型在训练分布内刷分、外推即崩。

## 十、小结

AI4Science 是 LLM 技术向自然科学的高价值延伸。其成败不在规模，而在「模态统一 + 物理约束 + 可复现验证」三者的平衡。
