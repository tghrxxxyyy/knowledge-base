# 蛋白质与生物

> 对应 ESM（Rives et al., 2019/2021, Facebook AI）与 ProtTrans（Elnaggar et al., 2021）蛋白质语言模型；结构预测参考 AlphaFold2（Jumper et al., 2021, Nature）；llm-course（mlabonne）相关章节（具体细节以官方最新文档为准）。

## 一、背景与挑战

蛋白质由 20 种标准氨基酸以肽键连接成序列，其「序列决定结构、结构决定功能」的生物学中心法则，使蛋白质序列天然具备类似自然语言的「语法」：

- 氨基酸在进化中形成强统计规律，特定位置出现特定残基。
- 同源蛋白在序列层面保留可学习信号。
- 突变会改变结构与功能，但多数突变效应难以实验穷举。

挑战在于：湿实验测定结构与功能成本高、通量低，难以覆盖海量突变空间；而语言建模能从无标注序列中自监督学到可迁移表征。

## 二、核心原理

蛋白质语言模型（pLM）将氨基酸序列当作 token 序列做掩码/自回归预训练：

1. 以 UniRef 等大规模蛋白库预训练，学习残基共进化与上下文表征。
2. 用 [MASK] 预测（如 ESM-1b/ESM-2）或自回归（如 ProGen）建模序列分布。
3. 取最后一层隐藏态作为每个残基的表征，或取 [CLS] 做整体表征。

下游可迁移到：突变效应预测（对比野生型/突变表征差异）、结构推断（与折叠模型互补）、功能注释、新蛋白设计。核心直觉是「能在无监督下预测被掩盖残基的模型，已隐式掌握了进化约束」。

## 三、形式化与数学基础

给定序列 $x=(x_1,\dots,x_L)$，$x_i\in\mathcal{V}$（$\mathcal{V}$ 为氨基酸字母表）。掩码语言建模最大化

$$ \max_\theta\, \sum_{i\in M} \log p_\theta(x_i\mid x_{\setminus M}) $$

其中 $M$ 为被掩盖位置集合。突变效应预测常用「伪对数似然比」（PLL）：对野生型 $w$ 与突变体 $m$ 计算

$$ \Delta = \sum_i \log p_\theta(w_i\mid w_{\setminus i}) - \log p_\theta(m_i\mid m_{\setminus i}) $$

$\Delta>0$ 表示突变降低模型似然，通常对应有害突变；该指标与实验测得适应度高度相关。

## 四、代码实现

```python
# 使用 ESM 系列模型获取蛋白序列表征（示意）
# 实际可用 esm 库：from esm import ESM2
from esm.models.esm3 import ESM3
from esm.sdk.api import ESMProtein

def get_repr(sequence: str):
    # 加载预训练模型（以官方最新接口为准）
    model = ESM3.from_pretrained("esm3_sm_open_v1").to("cuda")
    protein = ESMProtein(sequence=sequence)
    # 编码并取最后一帧隐藏态
    res = model.encode(protein)
    return res.embeddings  # [L, d]

# 突变效应：比较伪对数似然
def mutation_effect(model, wt: str, mut: str) -> float:
    return model.log_likelihood(wt) - model.log_likelihood(mut)
```

## 五、与其他技术对比

| 方法 | 输入 | 优势 | 局限 |
|------|------|------|------|
| 比对（BLAST/HMMER） | 序列 | 可解释 | 难预测未见效应 |
| 共进化（GREMLIN） | MSA | 捕捉结构接触 | 需同源多序列 |
| 蛋白质语言模型 | 单序列/库 | 零样本泛化 | 不显式给结构 |
| AlphaFold2 | 序列+MSA | 结构精准 | 不直接给功能 |

pLM 与结构模型互补：前者给功能/进化表征，后者给三维坐标。

## 六、常见误区

- 序列表征等于结构：表征蕴含进化约束，但不等于折叠坐标，需结构模型补全。
- 越大越准：领域数据质量与预训练目标比参数量更关键。
- 单序列模型万能：稀有蛋白缺少同源信号时，MSA 仍重要。

## 九、演进与趋势

从 BLAST 比对 → 共进化/接触图 → 蛋白质语言模型（ESM/ProtTrans）→ 结构与序列联合（ESM-3、AlphaFold3 融合）。趋势是多模态统一：在同一表征空间联合序列、结构、功能与相互作用。在应用侧，pLM 正从「表征工具」走向「生成工具」——直接设计具有目标功能的全新蛋白序列（de novo design），并与湿实验形成「设计—合成—测试—学习」闭环，成为合成生物学与酶工程的新引擎。

在药物发现中，pLM 与结构模型常串联使用：先用语言模型筛选突变、设计序列，再交 AlphaFold/RFdiffusion 验证结构可行性，形成「序列—结构」双向迭代。

## 十、小结

蛋白质语言模型把「进化即预训练信号」落地为可迁移表征，是 AI4Science 在生物领域的标志性应用。它与结构预测互补，正走向序列—结构—功能的统一建模。
