# 蛋白质与生物

> 见「科学大模型深入/科学语言建模」与「多模态深入」。

## 一、背景与挑战

生物序列（蛋白/DNA）是「另一种语言」，LLM 范式可迁移。

## 二、核心原理

ESM 等把氨基酸序列当 token 预训练，学习结构与功能表征，用于突变效应预测、结构推断。

## 三、关键要点

- 同源关系可学习的。
- 与结构模型（AlphaFold）互补。

## 四、代码实现

```python
from esm import ESM2
repr = ESM2("MKTAYIAK...")  # 蛋白序列表征
```

## 五、与其他对比

- 自然语言 LLM 处理文本；生物 LLM 处理序列。

## 六、常见误区

- 序列模型=结构模型——表征≠折叠结构。
