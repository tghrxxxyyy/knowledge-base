# 科学文献问答

> 对应 llm-course（mlabonne）RAG 章节；Lewis et al., 2020（Retrieval-Augmented Generation, RAG）；科学问答代表工作 PaperQA、Semantic Scholar 检索 API（以官方最新文档为准）。

## 一、背景与挑战

科研人员每天面对指数增长的论文，关键需求是从海量文献中精准检索、交叉比对并生成带出处的综述。纯参数化 LLM 在文献问答的痛点：

- 知识截止：训练后新论文不可见。
- 幻觉引用：编造 DOI、作者、结论。
- 公式与图难检索：科学信息不只文本。
- 溯源困难：综述式回答难以逐句对应原文。

因此科学文献问答普遍采用「检索增强 + 严格溯源」而非纯生成。

## 二、核心原理

标准科学 RAG 流水线：

1. 建库：论文解析为段落/公式/图块，分别向量化（文本 embedding、公式语义、图编码）。
2. 检索：用户问题召回 Top-k 相关块，可结合引用图（citation graph）扩展上下文。
3. 生成：LLM 基于检索证据作答，并要求「每段声明标注来源」。
4. 校验：后处理检查引用是否真实存在且与声明语义一致。

高级做法用「假设性文档嵌入（HyDE）」先生成假设答案再检索，或用多轮检索迭代澄清。PaperQA 类系统还引入证据置信度与矛盾检测。

## 三、形式化与数学基础

检索阶段，查询 $q$ 与文档块 $d$ 经编码器得向量 $u,v$，以余弦相似度排序：

$$ s(q,d)=\frac{u^\top v}{\|u\|\|v\|} $$

取 $k$ 个最高分块构成上下文 $C=\{d_{(1)},\dots,d_{(k)}\}$。生成条件概率：

$$ P(a\mid q)=\prod_{t} p_\theta(a_t\mid q, C, a_{<t}) $$

溯源质量定义「引用可支撑率」（见「可复现与基准」），要求 $\rho\to 1$。引用图可用邻接矩阵 $A$，随机游走得分

$$ r = (1-\alpha) (I-\alpha A^\top)^{-1} e $$

扩展相关论文。

## 四、代码实现

```python
# 科学文献 RAG 示意（伪代码）
from sentence_transformers import SentenceTransformer

enc = SentenceTransformer("multi-qa-mpnet-base")
index = load_faiss(paper_chunks)  # 预建向量库

def answer(query: str, k: int = 10):
    qv = enc.encode(query)
    hits = index.search(qv, k)            # 召回相关块
    ctx = "\n".join(h.text for h in hits)
    prompt = f"根据以下文献作答并标注出处:\n{ctx}\n问题:{query}"
    return llm(prompt), [h.citation for h in hits]  # 返回答案与出处
```

## 五、与其他技术对比

| 方案 | 出处 | 时效 | 难点 |
|------|------|------|------|
| 纯 LLM | 无 | 截止 | 幻觉 |
| 通用 RAG | 文本 | 好 | 公式/图缺失 |
| 科学 RAG | 文本+公式+图 | 好 | 多模态检索难 |

科学 RAG 在「多模态证据 + 严格溯源」上更严格。

## 六、常见误区

- 综述模型写即真：生成需逐句核对原文出处。
- 只检索标题/摘要：正文公式与图表常含关键证据。
- 忽略引用图：重要相关工作在引用网络里而非关键词里。

## 九、演进与趋势

关键词检索 → 语义检索 → 多模态科学 RAG（公式+图+引用图）→ 自动综述智能体（检索、比对、发现矛盾、生成可复现报告）。趋势是把「证据置信度」与「矛盾检测」作为一等能力。

## 十、小结

科学文献问答是科研提效关键入口。其可靠性不来自模型本身，而来自「检索增强 + 多模态证据 + 严格溯源」的工程闭环，使答案每条都可被追回到原文。
