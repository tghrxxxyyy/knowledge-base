# 科学文献问答

> 见「RAG深入/总体架构」与「科学大模型深入/科学语言建模」。

## 一、背景与挑战

科研人员需从海量论文精准检索与总结。

## 二、核心原理

论文向量化+RAG，结合引用图与公式理解，提供带出处的问答与综述生成。

## 三、关键要点

- 公式检索需语义+符号。
- 引用溯源防编造。

## 四、代码实现

```python
hits = paper_index.search(q, k=10); ans = llm(q, ctx=hits)
```

## 五、与其他对比

- 通用 RAG 文本；科学 RAG 含公式/图。

## 六、常见误区

- 综述模型写即真——需核对原文。

## 七、与开源书对应

- llm-course: https://github.com/mlabonne/llm-course
