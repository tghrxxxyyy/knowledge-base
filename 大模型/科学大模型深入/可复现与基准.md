# 可复现与基准

> 对应 llm-course（mlabonne）模型评测章节；科学领域基准 PubMedQA、MolBench、SciBench 等；lm-evaluation-harness（EleutherAI）通用评测框架（以官方最新文档为准）。

## 一、背景与挑战

科学结论的生命线是「可复现」，而 LLM 在科学场景最危险的是「流畅地编造」。问题来源：

- 幻觉引用：模型生成看似合理但不存在的论文、公式或数据。
- 评测错位：通用榜单（MMLU 等）高分不代表领域可用。
- 不可复现：缺少固定种子、数据版本与运行环境，结果无法重现。

因此科学 LLM 既要「领域基准」衡量真实能力，也要「引用/证据约束」抑制编造。

## 二、核心原理

两条互补支柱：

1. 领域基准：用学科 QA、性质预测、推导题衡量，而非通用闲聊。例如 PubMedQA（生物医学 QA）、MolBench（分子理解）、SciBench（科学计算题）。
2. 可复现与证据约束：要求输出带可验证引用（citation grounding），用检索增强（RAG）把答案锚定到原文；评测时检查「声明—证据」一致性，并固定随机种子与数据快照。

实践上以 lm-evaluation-harness 标准化跑分、以 RAG 强制溯源，结合人工抽检应对「引用虽真但无关」的软编造。

## 三、形式化与数学基础

定义声明集合 $C=\{c_1,\dots,c_m\}$ 与证据库 $E$。 grounding 质量用「可支撑率」：

$$ \rho = \frac{1}{m}\sum_{i=1}^m \mathbb{I}\big[\exists e\in E: \text{supports}(e, c_i)\big] $$

理想 $\rho\to 1$，即每条声明都能在证据中找到支撑。领域准确率在基准 $B$ 上定义为

$$ \text{Acc}_B = \frac{1}{|B|}\sum_{(q,a)\in B}\mathbb{I}[\text{match}(f(q), a)] $$

其中 $\text{match}$ 可为精确匹配或 LLM-as-judge（需谨慎校准）。

## 四、代码实现

```python
# 检查答案声明是否被证据支撑（示意）
def supported_rate(claims: list[str], evidence: list[str]) -> float:
    ok = 0
    for c in claims:
        # 用检索或 LLM 判断证据是否支撑该声明
        hit = any(retrieval_match(e, c) for e in evidence)
        ok += 1 if hit else 0
    return ok / max(len(claims), 1)
```

## 五、与其他技术对比

| 维度 | 通用评测 | 领域基准 |
|------|----------|----------|
| 覆盖 | 广 | 深 |
| 噪声 | 高 | 低 |
| 编造风险 | 不易暴露 | 直接暴露 |

领域基准更能揭示科学能力，但构建成本高。实践中常采用「分层评测」：先用通用榜快速回归，再用领域基准深入诊断，最后用人工抽检验证引用真实性。此外，可复现评测还强调「环境可追溯」——记录模型版本、随机种子、数据快照与运行命令，使任何结果都能被第三方复现，这正是科学方法论对 ML 评测的基本要求。

## 六、常见误区

- 通用榜高分 = 领域可用：MMLU 上的好表现未必迁移到专业推导。
- 引用存在即可靠：引用可能与声明无关（软编造）需语义校验。
- 一次跑分定优劣：需固定种子多次取均值，报告方差。
- 忽视软编造：引用「存在但无关」比引用「不存在」更隐蔽，需要语义级证据校验。

需要强调的是，可复现不仅关乎评测，也关乎训练：科学 LLM 的训练数据版本、采样温度、随机种子都应随模型权重一并发布，否则即使推理代码公开也无法复现结论。这一「全链路可复现」理念正从科研实践走向工程规范，是领域可信落地的底线。

## 九、演进与趋势

通用基准 → 领域基准 → 「可复现 + 证据约束」评测 → 自动科学评测智能体（生成假设、调用工具验证、写可复现报告）。趋势是把「可复现」作为一等公民嵌入训练与评测全流程。

在训练侧，可复现还要求记录数据清洗脚本、分词器版本与超参快照，否则「开源权重」仍无法复现原结论，科研诚信依赖全链路透明。

领域基准本身也需维护：科学语料随时间更新，基准若冻结过久会「被刷分过拟合」，应定期刷新并公开标注集的收集流程。

## 十、小结

可复现是科学生命线。科学 LLM 的评测不能只看分数，更要看「每条结论是否可溯源、可重现」，领域基准 + 证据约束是抵御编造的双保险。
