# 化学与材料

> 对应 llm-course（mlabonne）化学语言模型章节；RDKit 分子工具库；分子生成代表工作（ChemLLM、MolFormer、GNoME 等，以官方最新文档为准）。

## 一、背景与挑战

化学与材料发现依赖对分子「结构—性质—合成路径」的推理，传统方式面临：

- 化学空间巨大：类药分子估计达 $10^{60}$ 量级，无法穷举。
- 实验验证慢：合成与表征周期长、成本高。
- 表示多样：SMILES、InChI、分子图、3D 坐标各有所长，需统一。

LLM/生成模型可在序列（SMILES）或图（分子图）上建模，预测性质、生成候选、规划逆合成，但必须保证「化学有效性」与「可合成性」。

## 二、核心原理

三类主流范式：

1. 序列式（SMILES/SELFIES）：把分子当字符串，用语言模型自回归生成，SELFIES 保证 100% 语法有效。
2. 图式（GNN/图 Transformer）：直接在分子图上做性质预测与生成，天然表达拓扑。
3. 混合：先用生成模型产出候选，再用物理/经验力场（如 DFT、RDKit 描述符）打分筛选。

关键流程：生成 → 有效性校验（RDKit 解析）→ 性质预测（QSPR/QM）→ 可合成性/逆合成（Retrosynthesis）→ 实验或模拟验证。

## 三、形式化与数学基础

分子可视为图 $G=(V,E)$，原子为节点、键为边。图神经网络聚合邻居消息：

$$ h_v^{(l+1)} = \phi\!\left(h_v^{(l)}, \bigoplus_{u\in\mathcal{N}(v)} \psi(h_v^{(l)}, h_u^{(l)}, e_{uv})\right) $$

性质预测近似 $y\approx f_\theta(G)$。语言建模侧以 SELFIES 为例，字符为语义完整的子结构，构造保证任意采样序列可解析为合法分子，使生成分布 $p_\theta(s)$ 的输出必有效。

## 四、代码实现

```python
# 用 RDKit 校验 SMILES 有效性并抽取描述符
from rdkit import Chem
from rdkit.Chem import Descriptors

def safe_molecule(smiles: str):
    mol = Chem.MolFromSmiles(smiles)
    if mol is None:
        return None  # 无效 SMILES
    # 物理化学描述符
    return {
        "mw": Descriptors.MolWt(mol),
        "logp": Descriptors.MolLogP(mol),
        "valid": True,
    }

# 生成后过滤：仅保留有效且分子量合理的候选
candidates = [safe_molecule(s) for s in generated]
candidates = [c for c in candidates if c and 100 < c["mw"] < 600]
```

## 五、与其他技术对比

| 方法 | 表示 | 优势 | 局限 |
|------|------|------|------|
| QSAR/QSAR | 描述符 | 成熟 | 外推差 |
| 图模型 | 分子图 | 拓扑自然 | 生成难 |
| SMILES-LLM | 字符串 | 易生成 | 需有效性校验 |
| 第一性原理(DFT) | 坐标 | 准确 | 慢 |

生成模型负责「探索」，物理验证负责「把关」。

## 六、常见误区

- 生成 SMILES 即可：必须校验化学有效性与合成可行性，否则是「纸面分子」。
- 忽略 3D：很多性质（手性、构象）依赖三维，纯 SMILES 会丢信息。
- 用通用 LLM 当化学家：缺少领域预训练与工具调用易编造结构。

## 九、演进与趋势

QSAR → 图神经网络 → 分子语言模型（SELFIES）→ 生成—验证闭环 → 材料基础模型（如 GNoME 大规模筛选）。趋势是「生成 + 物理约束 + 主动实验」的自主材料发现。

逆合成规划（retrosynthesis）常与生成模型配套：先由 LLM/图模型提出合成路线，再由专家或规则引擎校验可合成性，形成「生成—校验」闭环。

近年「主动学习」把模型预测与实验室反馈结合，每轮实验聚焦信息量最大的候选，显著减少试错次数，是材料发现从「筛选」走向「导航」的关键。

## 十、小结

化学与材料 LLM 把分子当作可生成、可验证的「语言」，核心价值在于在巨大化学空间中高效探索，并以有效性校验与物理验证守住科学底线。
