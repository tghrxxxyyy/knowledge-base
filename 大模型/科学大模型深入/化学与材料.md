# 化学与材料

> 见「科学大模型深入/科学语言建模」。

## 一、背景与挑战

分子性质预测、逆合成、材料发现需懂化学语法。

## 二、核心原理

用 SMILES/分子图训练模型，预测性质、生成候选分子、规划合成路径；结合物理约束。

## 三、关键要点

- SMILES 有语法，可语言建模。
- 需有效性/可合成性过滤。

## 四、代码实现

```python
mol = Chem.MolFromSmiles(smiles); valid = mol is not None
```

## 五、与其他对比

- 图模型直接；LLM 用 SMILES 序列。

## 六、常见误区

- 生成 SMILES 即可——需化学有效。
