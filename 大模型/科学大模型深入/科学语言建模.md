# 科学语言建模

> 对应 llm-course（mlabonne）科学语言模型章节；Galactica（Taylor et al., 2022, Meta）、Minerva（Lewkowycz et al., 2022, Google）等代表工作；ScienceCorpus 类语料（以官方最新文档为准）。

## 一、背景与挑战

科学文本不同于通用网页：富含 LaTeX 公式、化学式、引用标记、专业符号与严谨推理链。通用 LLM 在科学场景的痛点：

- 公式理解弱：把数学当作纯文本，易在推导中出错。
- 术语歧义：同一符号在不同学科含义不同。
- 幻觉高危：编造公式、定理、引用在科学场景后果严重。
- 推理链断裂：多步推导缺少中间校验。

科学语言建模的目标是预训练出「懂科学表达与推理」的模型。

## 二、核心原理

科学 LM 的关键设计：

1. 语料：混合论文、教材、代码、化学式、数学题解（如 arXiv、PubMed、数学网页）。
2. 分词：对 LaTeX 做结构感知分词，避免把 `\frac{a}{b}` 拆成无意义碎片；化学式按子结构切分。
3. 目标：自回归语言建模为主，可加「引用预测」「公式补全」等辅助任务。
4. 推理增强：链式思维（CoT）、工具调用（计算器、符号运算）弥补纯参数化推理不足。

代表：Galactica 在大规模科学语料预训练，主打文献理解与公式；Minerva 在数学题求解上强化一步步推导与工具使用。

## 三、形式化与数学基础

标准因果 LM 最大化序列对数似然：

$$ \mathcal{L}_{\text{LM}} = -\sum_{t=1}^{T} \log p_\theta(x_t\mid x_{<t}) $$

对 LaTeX 结构，设 tokenizer 把公式解析为语义单元序列 $z_1,\dots,z_K$，希望

$$ p_\theta(z_t\mid z_{<t}) $$

在算子（$\int$、$\sum$、$\frac$）边界处保持语法合法。可在训练时对公式区域加权 $\lambda>1$，使损失

$$ \mathcal{L} = \mathcal{L}_{\text{text}} + \lambda\,\mathcal{L}_{\text{formula}} $$

以提升公式建模权重。

## 四、代码实现

```python
# 加载科学 LM 并做公式感知生成（示意，以 Galactica 接口为准）
from transformers import AutoModelForCausalLM, AutoTokenizer

model = AutoModelForCausalLM.from_pretrained("facebook/galactica-6.7b")
tok = AutoTokenizer.from_pretrained("facebook/galactica-6.7b")

prompt = "证明: 对任意实数 a,b, 有 (a+b)^2 = "
inputs = tok(prompt, return_tensors="pt")
out = model.generate(**inputs, max_new_tokens=128)
print(tok.decode(out[0]))
```

## 五、与其他技术对比

| 模型 | 侧重 | 优势 |
|------|------|------|
| 通用 LLM（GPT 类） | 广 | 通用强 |
| 科学 LM（Galactica） | 科学语料 | 公式/引用更稳 |
| 数学专用（Minerva） | 推导 | 多步推理 |

科学 LM 在深度上优于通用模型，但通用模型的广覆盖仍难替代。

## 六、常见误区

- 科学 LM 输出即正确：仍需回溯原文核对公式与引用。
- 公式当纯文本：不做结构分词会损害推导质量。
- 仅靠参数化推理：复杂数学必须配工具（计算/符号）。

## 九、演进与趋势

通用 LM → 领域科学预训练 → 多模态科学（融合公式/图/结构）→ 带工具的科学智能体（自动推导+检索+验证）。趋势是把「严谨推理 + 证据约束」内建进模型与流程。

训练科学 LM 还需处理「长上下文」：论文常超长，需配合长序列注意力（如 FlashAttention、滑动窗口）与分块预训练策略，否则公式跨页引用会丢失。

评估上，除通用推理题外，应加入「引用准确性」与「公式正确性」专项测试，因为这两项是科学可信度的核心短板。

## 十、小结

科学语言建模把 LaTeX、化学式、引用与严谨推理纳入预训练，是科研加速器。其价值不在替代科学家，而在提升文献理解、推导辅助与假设启发的效率，同时以引用溯源守住可信底线。
