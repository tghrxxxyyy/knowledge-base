# 假设生成与发现

> 对应 llm-course（mlabonne）科学发现章节；Nature「The AI revolution in science」评述；FunSearch（DeepMind, Nature 2024）与 Sakana AI「The AI Scientist」等代表性工作（具体细节以官方最新文档为准）。

## 一、背景与挑战

科学进步的核心是提出可被证伪、可被实验检验的假设。传统假设生成依赖少数资深研究者的直觉与文献积累，存在若干瓶颈：

- 文献爆炸：PubMed 每年新增数百万篇，人类难以穷尽跨领域关联。
- 认知偏差：研究者易沿既有范式思考，错过交叉学科的非显式联系。
- 验证周期长：从设想到实验成本高，候选假设过多时无法逐一试错。

LLM 的出现使「从海量证据中归纳候选假设」成为可能，但挑战在于：模型输出流畅却未必严谨，若缺乏验证闭环，会制造「看似合理」的伪假设。

## 二、核心原理

假设生成的典型闭环为「检索—综合—生成—验证」：

1. 证据检索：从文献库/数据库召回与现象相关的论文、数据与已发表结论。
2. 综合归纳：LLM 将分散证据组织为结构化知识（如变量关系、矛盾点）。
3. 候选生成：基于综合结果提出若干可检验假设，并给出推理链。
4. 验证闭环：借助计算模拟、湿实验或已有基准，筛选并证伪；失败结果反哺下一轮生成。

关键设计是「人机协作」：模型负责广度扩候选，人类负责深度判证伪，避免模型「幻觉式发现」。代表性实践包括用 LLM 总结文献矛盾点以启发新材料假设，以及 FunSearch 以 LLM 生成数学结构、由评估器筛选的进化式框架。

## 三、形式化与数学基础

将证据集记为 $D=\{d_1,\dots,d_n\}$，模型生成假设分布 $p_\theta(h\mid D)$。理想假设需满足可证伪性：存在可观测结果 $o$ 使

$$ P(o\mid h)\neq P(o\mid \neg h) $$

即假设 $h$ 与反设 $\neg h$ 对观测的预测可区分。验证阶段以似然比

$$ \Lambda=\frac{P(o\mid h)}{P(o\mid \neg h)} $$

衡量证据强度；$\Lambda$ 越偏离 1，假设越可被检验。进化式方法（如 FunSearch）将「生成器输出 $h$」与「评分器 $\mathcal{F}(h)$」交替优化，形成 $\max_{h}\mathcal{F}(h)$ 的搜索过程。

## 四、代码实现

```python
# 基于文献片段生成候选假设（示意）
from openai import OpenAI
client = OpenAI()

def propose_hypotheses(findings: str, k: int = 3) -> list[str]:
    # 系统提示约束：可检验、可证伪、给出推理链
    sys = "你是科研助手，只生成可证伪且可被实验检验的假设，并附推理。"
    prompt = f"基于以下发现提出{k}个候选假设:\n{findings}"
    resp = client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "system", "content": sys},
                  {"role": "user", "content": prompt}],
        temperature=0.7,
    )
    return resp.choices[0].message.content.split("\n")
```

## 五、与其他技术对比

| 方式 | 广度 | 严谨性 | 适用 |
|------|------|--------|------|
| 专家直觉 | 低 | 高 | 成熟领域深耕 |
| 文献计量/数据挖掘 | 中 | 中 | 已知关系发现 |
| LLM 假设生成 | 高 | 依赖验证 | 交叉学科启发 |
| 自动化实验（主动学习） | 中 | 高 | 已有假设筛选 |

LLM 的优势在「扩候选」，而非「替代验证」。

## 六、常见误区

- 把「模型输出假设」等同于「科学发现」：发现必须经证伪，生成只是第一步。
- 忽视可证伪性：要求模型产出「无法被检验」的玄学陈述无科学价值。
- 完全自动化：缺少人类领域判定的闭环易放大幻觉。

## 九、演进与趋势

关键词检索 → 文献综述自动化 → LLM 假设生成 → 生成—验证闭环（结合模拟/自动实验）→「AI Scientist」式端到端科研代理。趋势是让模型不仅提假设，还能调用工具自动验证，但仍以人类终审为边界。

## 十、小结

假设生成是 AI4Science 的高价值入口：LLM 负责扩展候选广度，严谨验证闭环决定科学可信度。落地关键是「人机协作 + 可证伪约束 + 验证反馈」。
