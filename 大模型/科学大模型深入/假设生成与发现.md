# 假设生成与发现

> 见「推理与思考模型深入/推理与思考模型」与「科学大模型深入/科学语言建模」。

## 一、背景与挑战

从数据中提出可检验科学假设是创新核心。

## 二、核心原理

用 LLM 综合文献与数据提出候选假设，再用实验/模拟验证，形成「AI 提出-人验证」闭环（如材料/生物发现）。

## 三、关键要点

- 假设需可证伪。
- 人机协作最稳。

## 四、代码实现

```python
hyp = llm(f"基于这些发现提出3个可检验假设:\n{findings}")
```

## 五、与其他对比

- 人提假设慢；AI 扩候选但需验证。
