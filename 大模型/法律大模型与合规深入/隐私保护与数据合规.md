# 隐私保护与数据合规

> 对应 github microsoft/DeepSpeed 项目与 Rasley 2020 的 DeepSpeed ZeRO 论文。

## 一、背景与挑战
法律与医疗等敏感语料训练需防止记忆泄露与成员推断攻击。训练阶段可通过联邦、差分隐私与访问控制降低风险。

## 二、核心原理
ZeRO 把优化器状态分片以降低显存，使在受限环境训练大模型可行；配合差分隐私优化器在梯度加噪，限制单条数据影响。

## 三、形式化与数学基础
差分隐私训练梯度裁剪后加噪：
$ \tilde g = \frac{1}{B}\sum_i \text{clip}(g_i, C) + \mathcal{N}(0, \sigma^2 C^2 I) $
满足 $ (\epsilon,\delta) $-DP 近似。

## 四、代码实现
```python
import torch

def dp_step(grads, clip=1.0, noise=1e-3):
    clipped = []
    for g in grads:
        n = g.norm().item()
        clipped.append(g if n < clip else g * (clip / (n + 1e-9)))
    mean = torch.stack(clipped).mean(0)
    mean = mean + torch.randn_like(mean) * noise
    return mean
```

## 五、与其他技术对比
相比纯访问控制，DP 提供可量化泄露上界；相比全量集中训练，分片与加噪牺牲部分效用换合规。

## 六、常见误区
噪声过小仍可被推断，过大则模型失效。以为分片即匿名是错误认知。
