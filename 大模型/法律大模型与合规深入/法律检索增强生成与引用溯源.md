# 法律检索增强生成与引用溯源

> 对应 Lewis 2020 的 RAG 论文与 github run-llama/llama_index 项目。

## 一、背景与挑战
法律回答必须可查证，凭空生成法条与判例会造成严重误导。RAG 让模型只依据检索到的法规与案例作答，并给出可追溯引用。

## 二、核心原理
把法规、判例切分为带元数据片段建索引。查询时检索相关条款，将片段与问题拼接，要求模型以「依据 + 推理」格式回答并标注来源编号。

## 三、形式化与数学基础
带引用的生成概率：
$ p(y|x)=\prod_t p(y_t | x, c, y_{<t}) \cdot \mathbb{I}(y_t\text{ 有源}) $
其中 $ c $ 为检索片段集合。

## 四、代码实现
```python
def answer_with_cite(model, retrieve, question, k=5):
    ctx = retrieve(question, k)
    prompt = ''
    for i, c in enumerate(ctx):
        prompt += '[%d] %s\n' % (i, c.text)
    prompt += '问题: ' + question + '\n请据上述来源回答并标注序号:'
    return model.generate(prompt), ctx

def cite_check(answer, ctx):
    return all('[%d]' % i in answer for i in range(len(ctx)))
```

## 五、与其他技术对比
相比纯生成，RAG 显著提升事实可追溯性；相比关键词法条检索，它理解语义并综合多源。

## 六、常见误区
检索到过期法条未做时效过滤。引用格式与真实条款不对应。

## 八、面试题
问：法律 RAG 为何必须溯源？答：错误不可追溯将导致执业风险，引用是可信前提。
