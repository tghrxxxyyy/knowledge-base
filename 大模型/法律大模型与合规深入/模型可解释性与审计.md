# 模型可解释性与审计

> 对应 github EleutherAI/lm-evaluation-harness 项目与 Gao 2021 的 lm-eval-harness 论文。

## 一、背景与挑战
法律决策影响重大，模型必须可解释、可审计。需要记录输入来源、推理路径与输出依据，便于事后复盘。

## 二、核心原理
在 RAG 架构下保存每段引用的检索得分与位置，输出时附证据链；用评测框架固化能力边界，定期回归，形成审计日志。

## 三、形式化与数学基础
注意力归因可近似为：
$ a_i = \frac{\exp(q^\top k_i/\sqrt d)}{\sum_j \exp(q^\top k_j/\sqrt d)} $
用于定位输出依赖的输入片段。

## 四、代码实现
```python
def audit_log(prompt, ctx, answer, scores):
    return {
        'prompt': prompt,
        'sources': [c.meta for c in ctx],
        'scores': scores,
        'answer': answer,
    }

def regression(harness, suite):
    results = harness.run(suite)
    return all(results[name] >= thr for name, thr in suite.thresholds.items())
```

## 五、与其他技术对比
相比黑盒部署，可审计系统便于责任认定；代价是存储与流程开销。

## 六、常见误区
把注意力权重当因果解释。审计只看准确率忽略公平性。

## 八、面试题
问：注意力高就代表重要吗？答：注意力是相关性而非因果，需结合扰动实验确认。

## 九、演进与趋势

## 十、小结
可解释与审计是法律大模型可信落地的制度性保障。
