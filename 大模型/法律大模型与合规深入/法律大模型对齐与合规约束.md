# 法律大模型对齐与合规约束

> 对应 Ouyang 2022 的 InstructGPT 论文与 github huggingface/trl 项目。

## 一、背景与挑战
法律场景要求模型拒绝给出确定性法律意见、不泄露客户信息、不鼓励违法行为。需要通过对齐把合规边界内化为模型行为。

## 二、核心原理
用合规指令数据做 SFT，再以偏好数据训练奖励模型，惩罚违规输出。生产环境还可叠加约束解码与关键词护栏，双保险。

## 三、形式化与数学基础
带合规惩罚的目标：
$ \max_\theta \mathbb{E}[r(x,y) - \lambda\, c(x,y)] $
其中 $ c $ 为违规程度，$ \lambda $ 为权重。

## 四、代码实现
```python
def guarded_generate(model, prompt, guard, beta=0.2):
    raw = model.generate(prompt)
    if guard.is_violation(raw):
        return '抱歉，我无法提供该法律意见，请咨询执业律师。'
    return raw

def compliance_reward(resp, rubric):
    score = 0.0
    for rule, ok in rubric.items():
        if ok(resp):
            score += 1.0
    return score
```

## 五、与其他技术对比
对齐让模型学会边界，护栏提供硬保证。仅靠提示词约束易被越狱绕过，需多层防御。

## 六、常见误区
把模型输出当正式法律意见。护栏正则过强会拒答正常咨询。
