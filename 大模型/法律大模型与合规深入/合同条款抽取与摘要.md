# 合同条款抽取与摘要

> 对应 Devlin 2018 的 BERT 论文与 github huggingface/transformers 项目。

## 一、背景与挑战
合同篇幅长、条款嵌套，人工审阅耗时。需要精准抽取当事人、义务、期限、违约责任等结构化字段并生成风险摘要。

## 二、核心原理
把抽取视为序列标注或 span 分类：BERT 编码后对每个 token 或候选片段打标签。摘要则采用抽取式或生成式，突出关键义务与异常条款。

## 三、形式化与数学基础
序列标注逐 token 概率：
$ p(y|x)=\prod_i p(y_i | x) $
span 分类得分 $ s(i,j)=\text{MLP}(h_i, h_j) $。

## 四、代码实现
```python
import torch

def extract_spans(encoder, cls, text_ids, max_len=512):
    h = encoder(text_ids).last_hidden_state
    scores = cls(h)
    preds = scores.argmax(-1)
    return [(i, preds[i].item()) for i in range(len(preds)) if preds[i] != 0]

def summarize(model, clauses, topk=3):
    scored = [(model.score(c), c) for c in clauses]
    scored.sort(reverse=True)
    return [c for _, c in scored[:topk]]
```

## 五、与其他技术对比
相比规则模板，模型可泛化至未见措辞；相比纯生成摘要，抽取式更可控、易审计。

## 六、常见误区
把免责条款当成普通陈述。跨句指代未消歧导致字段错位。
