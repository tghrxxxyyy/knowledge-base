# 成本与效率评估

> 对应 Kapoor et al., *AI Agents That Matter*, 2024（强调成本与准确率的联合评估）。

## 一、背景与挑战

只优化准确率会催生成本失控的方案：反复采样、超长上下文、多智能体辩论都能刷分但不可部署。
把成本纳入评估轴，才能得到工程上有意义的比较。

## 二、核心原理

- 成本口径：输入与输出 token、模型调用次数、工具调用次数、墙钟时延、失败重试开销，应分项统计。
- 帕累托视角：在准确率与成本的二维平面上比较，只有帕累托前沿上的方案值得考虑。
- 预算受限评估：给定固定预算（token 或时延），比较各方案在预算内的最佳表现，比无约束刷分更贴生产。

## 三、数学形式

综合效用可写 $U=\text{Acc}-\lambda\cdot\text{Cost}$，$\lambda$ 由业务上单位成本换算的准确率价值决定。

固定预算 $B$ 下的目标为 $\max \text{Acc}\ \text{s.t.}\ \mathbb E[\text{Cost}]\le B$，这会自然抑制无限采样与超长上下文策略。

## 四、代码实现

```python
def pareto(runs):
    front = []
    for r in sorted(runs, key=lambda x: x["cost"]):
        if not front or r["acc"] > front[-1]["acc"]:      # 成本更高必须准确率更高
            front.append(r)
    return front

def budgeted(agent_factory, tasks, budget):
    best = None
    for cfg in configs():                                  # 采样数、上下文、辩论轮数
        m = evaluate(agent_factory(cfg), tasks)
        if m["avg_tokens"] <= budget and (best is None or m["success"] > best[1]["success"]):
            best = (cfg, m)
    return best
```

## 五、与其他对比

- 与纯准确率排行榜：忽略成本会让重复采样类方案虚假领先。
- 与延迟基准：时延关注用户体验，token 成本关注经济性，二者需分别设阈值。

## 六、常见误区

- 只统计输出 token，忽略多智能体与长上下文导致的输入 token 膨胀（通常是成本主项）。
- 用单次运行的成本代表平均成本，忽略失败重试与长尾。
- 只报总成本不报分项，无法定位是采样数、上下文还是工具调用导致的开销。

## 八、面试题

- 为什么必须做成本联合评估？答：准确率可以用算力无限换取，不设成本轴的比较无法反映可部署性。
- 什么是预算受限评估？答：固定 token 或时延预算，比较各方案在预算内的最佳准确率，直接对应生产约束。

## 九、演进

只报准确率 → 附带 token 统计 → 准确率成本帕累托前沿 → 预算受限评估 → 含长尾与失败重试的全成本核算。

## 十、小结

没有成本轴的智能体评估会误导选型，帕累托前沿与预算受限评估是更诚实的比较方式。
