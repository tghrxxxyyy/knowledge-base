# 轨迹级与结果级指标

> 对应 Zhou et al., *WebArena*, ICLR 2024；Yao et al., *tau-bench*, 2024（规则遵从与一致性评估）。

## 一、背景与挑战

只看最终结果会掩盖过程问题：智能体可能靠碰运气成功，或者虽然成功但绕了大量弯路、触发了违规动作。
生产环境关心过程可控性，因此轨迹级指标与结果级指标同样重要。

## 二、核心原理

- 结果级：任务成功率、部分完成度（子目标完成比例）、答案正确性与忠实度。
- 轨迹级：步数与冗余率、非法或越权动作次数、循环重复率、恢复能力（失败后是否自主纠正）、规则遵从率。
- 稳定性：同一任务多次运行的成功一致性，度量可靠性而非峰值能力。

## 三、数学形式

冗余率 $\text{Red}=1-\frac{T^*}{T}$（$T^*$ 为参考最短步数）；循环率用重复动作签名占比 $\frac{\#\{t: a_t\in a_{<t}\}}{T}$。

稳定性可用同任务多次结果的一致率 $\text{Cons}=\frac{1}{|\mathcal T|}\sum_{t}\mathbb{1}[\text{全部 } m \text{ 次结果一致}]$。

## 四、代码实现

```python
def traj_metrics(traj, ref_steps, rules):
    sigs = [action_sig(a) for a in traj.actions]
    return {"redundancy": max(0.0, 1 - ref_steps / max(1, len(sigs))),
            "loop_rate": sum(s in sigs[:i] for i, s in enumerate(sigs)) / max(1, len(sigs)),
            "illegal": sum(not rules.allow(a) for a in traj.actions),
            "recovered": traj.had_failure and traj.success}
```

## 五、与其他对比

- 与纯结果评测：结果评测简单但无法区分「稳健成功」与「侥幸成功」。
- 与人工过程评审：人工能判断推理合理性，但难以规模化；自动轨迹指标提供可批量的近似。

## 六、常见误区

- 用参考轨迹严格匹配作为过程指标，惩罚合理的不同解法。
- 忽略非法动作次数，安全隐患在成功率上完全不可见。
- 不记录完整轨迹，事后无法归因与回放。

## 八、面试题

- 为什么要看轨迹级指标？答：它能区分稳健成功与侥幸成功，暴露越权、循环与冗余等生产环境关键风险。
- 稳定性怎么量化？答：同任务多次运行的结果一致率，配合 pass@k 区分能力上限与可靠性。

## 九、演进

只看答案 → 加子目标完成度 → 引入步数与非法动作 → 规则遵从与恢复能力 → 稳定性与一致性作为一等指标。

## 十、小结

结果指标衡量能不能做到，轨迹指标衡量做得是否规矩可靠，二者共同定义生产可用性。
