# 评估污染与可复现

> 对应 Kapoor et al., *AI Agents That Matter*, 2024；Jimenez et al., *SWE-bench*, ICLR 2024（环境固定与数据泄漏讨论）。

## 一、背景与挑战

公开基准一旦被广泛使用，其任务与解法很容易进入训练语料，分数虚高而泛化未变。
智能体评测还额外依赖外部环境（网站、数据库、依赖版本），环境漂移会让同一份代码在不同时间得到不同结果。

## 二、核心原理

- 污染检测：用任务文本与解法的 n-gram 或嵌入相似度在训练语料中检索，或用训练截止后的新任务做对照。
- 环境固定：容器镜像固定依赖、快照式数据集、固定随机种子、离线回放网络响应，使评测可复现。
- 结果披露：报告模型版本、提示模板、采样参数、重复次数、环境镜像标识，缺少这些则结论不可比较。

## 三、数学形式

污染可视为测试集与训练集的重叠：$\text{Overlap}=\frac{|D_{\text{test}}\cap D_{\text{train}}|}{|D_{\text{test}}|}$（以近似匹配定义交集）。

用截止日期切分做对照，若 $\text{Acc}_{\text{旧}}-\text{Acc}_{\text{新}}$ 显著大于噪声 $\text{SE}$，则存在污染或分布漂移的证据。

## 四、代码实现

```python
def contamination_probe(model, tasks_before, tasks_after, repeats=3):
    a = evaluate(model, tasks_before, repeats)     # 训练截止前的任务
    b = evaluate(model, tasks_after, repeats)      # 截止后的新任务
    gap = a["success"] - b["success"]
    se = (a["se"] ** 2 + b["se"] ** 2) ** 0.5
    return {"gap": gap, "se": se, "suspicious": gap > 2 * se}
```

## 五、与其他对比

- 与私有测试集：私有集抗污染但不可复现审计；公开集可复现但会被污染，二者需并用。
- 与在线动态基准：持续更新任务可缓解污染，但破坏跨时间可比性，需保留固定子集做纵向对比。

## 六、常见误区

- 只做精确字符串去重，改写过的任务仍然泄漏。
- 不固定环境镜像与依赖版本，几个月后结果无法复现却归因于模型变化。
- 不公开提示与采样参数，导致同名基准的分数互不可比。

## 八、面试题

- 如何检测基准污染？答：用近似匹配在训练语料中检索测试内容，或比较训练截止前后任务的成绩差是否显著超过噪声。
- 可复现评测需要固定什么？答：环境镜像与依赖、数据快照、随机种子、提示模板与采样参数、重复次数，并全部公开。

## 九、演进

裸分数报告 → 精确去重 → 近似污染检测与时间切分对照 → 容器化环境固定 → 完整实验元数据披露与持续更新基准。

## 十、小结

智能体分数只有在无污染且可复现的条件下才有意义，元数据披露与环境固定是基本科研纪律。
