# 多样性与质量平衡

> 对应 Zhou et al., *LIMA*, 2023（少而精胜多大杂）；Chen et al., *AlpaGasus*, 2023（质量优先）。

## 一、背景与挑战

纯追求多样可能纳入低质；纯追求质可能收缩多样；需平衡。

## 二、核心原理

两阶段：先以质量阈值过滤，再在通过集内最大化多样性；或 Pareto 选（质量-覆盖双高）。

## 三、数学形式

选 $S^*=\arg\max_{S} \alpha\cdot Q(S)+(1-\alpha)\cdot Div(S)$ 约束 $|S|\le B$。

## 四、代码实现

```python
pool = [x for x in data if q(x) > tau]
chosen = maximize_diversity(pool, budget=B)
```

## 五、与其他对比

- 与 数据质量过滤与困惑度过滤深入（质量门槛）衔接。
- 与 合成数据陷阱与评估深入（合成量质）相关。

## 六、常见误区

- 先多样后质量，留低质代表。
- 质量阈值过高致多样塌缩。
