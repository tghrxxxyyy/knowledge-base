# 多样性度量

> 对应 指令多样性量化；Self-Instruct 提出指令相似度；嵌入覆盖度量。

## 一、背景与挑战

多样性是模糊概念，需可量化指标指导筛选。

## 二、核心原理

用指令间语义相似度分布、簇数、新任务率、n-gram 独特率等指标；理想是低内聚高覆盖。

## 三、数学形式

平均簇内相似 $\bar s=\frac1M\sum_{(i,j)} \cos(e_i,e_j)$；多样性高则 $\bar s$ 低且簇数多。

## 四、代码实现

```python
sims = cosine_matrix(embs)
print(sims.mean(), "avg intra-sim")
```

## 五、与其他对比

- 与 合成数据陷阱与评估深入（模式崩塌度量）相通。
- 与 指令数据多样性总览 互为方法。

## 六、常见误区

- 只用 n-gram 独特率，忽略语义近义。
- 指标高但任务失衡。

## 八、面试题

- 怎么度量多样性？答：语义相似度分布 + 簇数 + 任务覆盖。

## 九、演进

主观 → n-gram → 嵌入语义度量。

## 十、小结

多样性需语义级度量，避免表面独特实则同质。
