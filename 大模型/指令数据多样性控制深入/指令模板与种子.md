# 指令模板与种子

> 对应 Wang et al., *Self-Instruct*, 2022（175 种子任务）；Taori et al., *Alpaca*, 2023（种子扩展）。

## 一、背景与挑战

无种子难规模化生成多样指令；需少量人工种子引导模型发散。

## 二、核心原理

用少量人工写的高质量种子指令，让模型据此生成新指令与新回复，再过滤；种子覆盖越广，发散越多样。

## 三、数学形式

生成分布 $p(y|x_{seed})$；多样性随种子集合 $\mathcal S$ 的覆盖半径增大。

## 四、代码实现

```python
for seed in seeds:
    new = model.generate(f"仿写一条不同任务的指令:\n{seed}")
```

## 五、与其他对比

- 与 多语种分词与挑战深入 无关，但种子也需多语。
- 与 合成数据陷阱与评估深入（种子防同质）相关。

## 六、常见误区

- 种子太少致生成同质。
- 种子含偏见被放大。
