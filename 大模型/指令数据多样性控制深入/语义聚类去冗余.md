# 语义聚类去冗余

> 对应 指令去冗余研究；Chen et al., *AlpaGasus*, 2023（用 GPT-4 筛高质量）；聚类采样实践。

## 一、背景与挑战

自指令生成大量近重复指令；堆叠冗余降低有效多样性。

## 二、核心原理

对指令嵌入做聚类，每簇抽样保留代表，删除近重复；或以质量分优先选簇内最优。

## 三、数学形式

在簇 $C_k$ 内保留 $x^*_k=\arg\max_{x\in C_k} q(x)$；最终集 $\cup_k\{x^*_k\}$ 保多样性。

## 四、代码实现

```python
for c in clusters:
    keep.append(max(c, key=quality))
```

## 五、与其他对比

- 与 数据去重与精确子串匹配深入（语义级去重）理念同。
- 与 指令数据多样性总览 互补。

## 六、常见误区

- 聚类数 $k$ 过小仍冗余、过大丢覆盖。
- 仅去重不看质量，留簇内最差。

## 八、面试题

- 聚类去冗余做法？答：指令嵌入聚类，每簇取质量最优，保覆盖去重复。

## 九、演进

随机抽 → 聚类抽 → 质量优先采样。

## 十、小结

聚类去冗余在保多样前提下剔除重复，提升有效密度。
