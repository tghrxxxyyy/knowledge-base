# 指令演化与自指令

> 对应 Wang et al., *Self-Instruct*, 2022；Xu et al., *Evol-Instruct (WizardLM)*, 2023（深度/广度演化）。

## 一、背景与挑战

静态指令集有限；可让模型自我演化出更难更多样的指令。

## 二、核心原理

Evol-Instruct：对现有指令做“深度演化”（加约束/推理步）或“广度演化”（换任务类型），生成更难样本，再过滤保留有效者。

## 三、数学形式

演化 $x'=E(x; dir)$，$dir\in\{\text{depth},\text{breadth}\}$；保留若 $q(x')>\tau$ 且 $x'$ 非退化。

## 四、代码实现

```python
for x in instructions:
    harder = llm(f"增加约束使更难: {x}")
```

## 五、与其他对比

- 与 合成数据陷阱与评估深入（演化也需校验）相关。
- 与 指令数据多样性总览 互为扩充手段。

## 六、常见误区

- 演化过难致不可解、无答案。
- 演化循环同质（模型偏好某些模式）。
