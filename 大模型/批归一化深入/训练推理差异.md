# BN 训练推理差异

> 见「批归一化深入/批归一化总览」；BN 的坑。

## 一、背景与挑战

BN 训练用 batch 统计，推理无 batch，如何一致？

## 二、核心原理

推理时用训练期累积的**滑动平均均值/方差**（running stats），而非当前 batch。若推理 batch 统计与训练分布差大（如微调后未更新 stats），精度崩。故推理前需 `model.eval()` 切到运行统计。

## 三、关键要点

- eval 模式切换关键。
- 小样本微调需重算 stats。

## 四、代码实现

```python
model.eval(); with torch.no_grad(): out = model(x)
```

## 五、与其他对比

- 训练动态统计；推理用固定。

## 六、常见误区

- 忘 eval——推理用 batch 统计错。
