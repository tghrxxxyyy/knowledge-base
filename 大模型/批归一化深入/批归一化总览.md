# 批归一化总览

> 对应 d2l-zh 与 Ioffe & Szegedy, *BatchNorm*, 2015；训练稳定神器。

## 一、背景与挑战

内部协变量偏移使每层输入分布漂移，训练慢且不稳。

## 二、核心原理

BatchNorm 在每层激活后按 batch 做标准化（减均值除标准差），再用可学 `γ,β` 缩放平移恢复表达力。使各层输入分布稳定，允许更大学习率、加速收敛、轻微正则。

## 三、数学形式

`y = γ·(x - μ_B)/√(σ_B²+ε) + β`，μ_B,σ_B 为 batch 统计量。

## 四、代码实现

```python
x = nn.BatchNorm2d(C)(x)
```

## 五、关键要点

- 训练用 batch 统计，推理用滑动平均。
- 小 batch 时统计不稳。

## 六、与其他对比

- BN 依赖 batch；LN 不依赖（见归一化深入）。

## 七、常见误区

- BN 即正则——主作用是稳训练。
