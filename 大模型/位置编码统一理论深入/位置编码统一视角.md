# 位置编码统一视角

> 综合 Vaswani 2017、Shaw 2018、Su 2021、Press 2021；本篇给出统一框架。

## 一、背景与挑战

各类位置编码术语繁多，需在一个框架里比较，避免重复造轮子与误用。

## 二、核心原理

统一为“在注意力中注入位置函数 $f(i,j)$”：绝对法 $f$ 依赖 $i$；相对法依赖 $i-j$；RoPE 在旋转中隐含、ALiBi 在偏置中显式。

## 三、数学形式

$a_{ij}= \langle \phi_q(i),\phi_k(j)\rangle + b(i,j)$；不同编码只是 $\phi,\ b$ 的参数化差异，可用角度/距离重述等价。

## 四、代码实现

```python
scores = pos_fn(q, k, i, j)  # 抽象位置函数，可插拔
```

## 五、与其他对比

- 绝对与相对并非正交：RoPE 证明旋转下二者可统一。
- 与 稀疏注意力算法深入 协同：位置编码决定注意力谁该被关注。

## 六、常见误区

- 认为某编码“绝对优于”另一；实际依赖长度分布与任务。
- 统一框架里混淆 $\phi$ 与 $b$ 的角色。

## 八、面试题

- 如何统一理解位置编码？答：都等价于在注意力分数/向量中注入位置函数，仅参数化不同。

## 九、演进

各自为政 → 统一为位置函数框架 → 外推成为主战场（RoPE/ALiBi）。

## 十、小结

把位置编码视为注意力中的可插拔位置函数，能在统一视角下选型与组合。
