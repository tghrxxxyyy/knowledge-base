# 相对位置编码

> 对应 Shaw et al., *Self-Attention with Relative Position Representations*, 2018；以及 T5 的 RPE 偏置。

## 一、背景与挑战

绝对编码对“相对距离”建模间接；许多任务更关心 token 间相对偏移，需把相对位置直接引入注意力。

## 二、核心原理

在注意力分数中加相对偏置 $a_{ij}=q_i^\top k_j + b_{i-j}$，或用相对位置嵌入修改 key/value，使分数依赖偏移 $i-j$。

## 三、数学形式

$a_{ij}= \frac{q_i^\top k_j}{\sqrt d} + w_{i-j}$（可裁剪到最大相对距离 $k$），偏置只依赖相对距离。

## 四、代码实现

```python
bias = relative_bias[i - j + max_rel]  # 查表相对偏置
scores = q @ k.T / d ** .5 + bias
```

## 五、与其他对比

- 比绝对编码更利长度泛化与平移等变。
- 与 RoPE 异曲同工：RoPE 也可视为相对旋转，见 RoPE旋转位置编码。

## 六、常见误区

- 相对距离裁剪阈值设过小，长程依赖丢失。
- 把相对偏置加到 value 而非 score，语义出错。

## 八、面试题

- 相对位置为何利于外推？答：建模偏移量而非绝对位，对未见过的长度更鲁棒。

## 九、演进

绝对 → Shaw 相对偏置 → T5 RPE → 与 RoPE 融合视角。

## 十、小结

相对位置编码把偏移直接引入注意力分数，是外推友好的关键设计。
