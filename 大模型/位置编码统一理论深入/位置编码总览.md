# 位置编码总览

> 对应 Vaswani et al., *Attention Is All You Need*, NeurIPS 2017（原始正弦绝对位置编码）；本主题做统一梳理。

## 一、背景与挑战

自注意力对 token 顺序置换不变，必须注入位置信息；不同编码在长度外推、相对关系建模上取舍不同。

## 二、核心原理

两类主线：绝对位置（给每个位置一个向量）与相对位置（在注意力分数中注入偏移）；二者可在统一框架下互表。

## 三、数学形式

统一记位置函数 $f(i,j)$ 作用于 query-position $i$ 与 key-position $j$；绝对法用 $f(i)=\mathbf p_i$，相对法用 $f(i-j)=\mathbf r_{i-j}$。

## 四、代码实现

```python
x = token_emb + pos_emb  # 绝对位置加性注入
```

## 五、与其他对比

- 绝对编码简单但长度外推弱；相对编码更利泛化。
- 与 RoPE/ALiBi 等下位主题构成完整谱系（见各专篇）。

## 六、常见误区

- 认为位置编码只影响第一层；其实贯穿所有层注意力。
- 混淆“绝对位置向量”与“相对偏置”，二者数学可等价但实现不同。

## 八、面试题

- 为何注意力需要位置编码？答：自注意力置换不变，需外部注入顺序以区分同词不同位。

## 九、演进

正弦绝对 → 可学习绝对 → 相对偏置 → RoPE/ALiBi 统一视角。

## 十、小结

位置编码可统一为注意力中的位置函数，绝对与相对是其两种参数化。
