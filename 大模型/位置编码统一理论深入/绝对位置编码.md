# 绝对位置编码

> 对应 Vaswani et al., 2017 原始 Transformer 的正弦与可学习绝对位置编码。

## 一、背景与挑战

早期直接为每个位置分配固定或可学习向量，加到 token 嵌入上；实现简单但难外推到训练长度之外。

## 二、核心原理

正弦版用不同频率的 sin/cos 生成 $\mathbf p_i$，使位置间呈线性可分且具周期性；可学习版直接优化 $\mathbf p_i$ 查表。

## 三、数学形式

$p_{i,2k}=\sin(i/10000^{2k/d})$，$p_{i,2k+1}=\cos(i/10000^{2k/d})$；可学习版 $\mathbf p_i\in\mathbb R^d$ 为查表参数。

## 四、代码实现

```python
pe = torch.zeros(max_len, d)
i = torch.arange(max_len).unsqueeze(1)
pe[:, 0::2] = torch.sin(i / 10000 ** (torch.arange(0, d, 2) / d))
```

## 五、与其他对比

- 正弦可外推一定长度，可学习版完全不可外推。
- 与 相对位置编码 对照：绝对法位置信息与内容相加，相对法进注意力分数。

## 六、常见误区

- 误以为正弦编码能无限外推；超出训练频率范围仍会退化。
- 把绝对位置加到 Q/K/V 之外的错误位置。

## 八、面试题

- 正弦编码为何用不同频率？答：多频率组合使近邻与远邻都有可分辨且平滑的位置信号。

## 九、演进

可学习绝对 → 正弦绝对 → 被相对/RoPE 取代为主流。

## 十、小结

绝对位置编码实现简单但外推受限，是位置注入的基线方案。
