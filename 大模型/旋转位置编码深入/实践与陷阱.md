# RoPE实践与陷阱

> 对应 LLM 实现经验；与 数值稳定性深入 / 训练不稳定诊断深入 衔接。

## 一、背景与挑战

RoPE 实现细节决定训练稳定与长程质量。

## 二、核心原理

关键点：维度配对、频率基 base、与 FlashAttention 的兼容、外推时的频率重标定。

## 三、数学形式

务必偶数维度配对；位置索引从 0 起；cos/sin 用 float32 算避免精度损失。

## 四、代码实现

```python
cos, sin = emb.cos(), emb.sin()        # (seq, d)
q_e = q*cos + rotate_half(q)*sin
```

## 五、与其他对比

- 与 注意力数学基础 中的位置处理共享。
- 与 混合精度训练深入 交叉：旋转应在较高精度算。

## 六、常见误区

- 维度未配对导致语义错乱。
- base 过小/过大致高频溢出或低频不足。
- 外推未重标定直接拉长位置。

## 七、与开源书对应

- rasbt/LLMs-from-scratch：https://github.com/rasbt/LLMs-from-scratch

## 八、面试题

- 实现 RoPE 最易错处？答：维度配对与频率 base 设置。

## 九、演进

朴素实现 → 融合 kernel（FlashAttention 原生支持）→ 可外推实现。

## 十、小结

RoPE 细节决定成败，配对与频率基是两大要点。
