# RoPE远程衰减性质

> 对应 RoPE 论文对远程衰减的分析；注意力数学基础 衔接。

## 一、背景与挑战

理想位置编码使远距离 token 注意力自然衰减，避免长程噪声。

## 二、核心原理

RoPE 内积随相对距离增大呈余弦振荡并幅度衰减（因不同频率相位差累积），产生内建的远程衰减。

## 三、数学形式

$\cos((m-n)\theta_i)$ 对大 $|m-n|$ 在多维平均下趋于低相关，等效衰减。

## 四、代码实现

```python
# 观察相对位置的注意力先验
rel = (m[:,None]-n[None,:])
score_prior = cos(rel * theta)   # 随 |rel| 振荡衰减
```

## 五、与其他对比

- ALiBi 直接线性衰减偏置；RoPE 衰减来自几何旋转。
- 与 注意力数学基础 中注意力分数尺度对照。

## 六、常见误区

- 误以为 RoPE 保证严格单调衰减；实际是振荡+统计衰减。
- 高频分量仍可能传递长程信号。

## 八、面试题

- RoPE 远程衰减从何而来？答：多维旋转相位差累积导致相关性随距离统计下降。

## 九、演进

理论衰减 → 外推时重标定频率以保衰减特性。

## 十、小结

RoPE 的远程衰减是旋转几何的副产品，利于长序列稳定性。
