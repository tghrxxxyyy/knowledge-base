# RoPE与绝对位置编码对比

> 对应 位置编码对比 目录；多种方案横评。

## 一、背景与挑战

位置编码方案众多，需理解相对/绝对、可外推性差异。

## 二、核心原理

- 绝对（正弦/ViT 可学习）：每个位置独立向量，难表达相对。
- 相对（T5 bias、ALiBi、RoPE）：编码位置差。

## 三、数学形式

绝对：$q_i^\top k_j + a_{i-j}$（bias）vs RoPE：$(R_i q)^\top(R_j k)$。

## 四、代码实现

```python
# 绝对
qk = q @ k.T + pos_bias_abs
# RoPE
qk = (rot(q) @ rot(k).T)
```

## 五、与其他对比

- RoPE 不增参且兼容线性注意力；T5 bias 需扩展表。
- ALiBi 外推简单但表达弱于 RoPE。

## 六、常见误区

- 以为可学习绝对位置能自动学相对；其实弱。
- 不同方案对长度外推能力差异大。

## 七、与开源书对应

- rasbt/LLMs-from-scratch：https://github.com/rasbt/LLMs-from-scratch

## 八、面试题

- 选 RoPE 还是 T5 bias？答：要外推与线性兼容选 RoPE，要简单加偏置选 T5。

## 九、演进

绝对 → 相对 bias → RoPE/ALiBi → 可外推 RoPE。

## 十、小结

RoPE 在相对性、外推、零增参间取得最佳平衡，成主流。
