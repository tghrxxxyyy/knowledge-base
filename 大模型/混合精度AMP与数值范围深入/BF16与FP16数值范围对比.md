# BF16与FP16数值范围对比

> 对应 Xiao 2023 SmoothQuant 与 NVIDIA/TensorRT-LLM 精度说明。

## 一、背景与挑战
理解两种低精度的指数/尾数分配，才能预判溢出、下溢与量化误差场景。

## 二、核心原理
BF16 把指数位扩到 8 位，动态范围与 FP32 一致，代价是尾数仅 7 位、精度较低。FP16 指数 5 位、范围窄但尾数 10 位、相对精度高。

## 三、形式化与数学基础
表示 `(-1)^s · 2^{e-bias} · (1+frac)`。BF16 bias=127、e∈[0,255]；FP16 bias=15、e∈[0,31]。故 BF16 最大 ~3.4e38，FP16 最大 ~6.5e4。

## 四、代码实现
```python
import torch
a = torch.tensor(1e4, dtype=torch.float16)   # 正常
b = torch.tensor(1e30, dtype=torch.float16)  # 溢出 inf
c = torch.tensor(1e30, dtype=torch.bfloat16) # 正常
print(a, b, c)
```

## 五、与其他技术对比
大模型激活易现大值（attention logits），BF16 更安全；FP16 需配合缩放（如 SmoothQuant）。

## 六、常见误区
以为 BF16 精度更高；实际其尾数更短，加法累积误差更大，关键归约应 FP32。

## 七、与开源书/权威来源对应
Xiao 2023 SmoothQuant 处理 FP16 激活溢出；NVIDIA/TensorRT-LLM 默认 BF16 内核。

## 八、面试题
问：为何大模型偏好 BF16？答：范围大，避免注意力 logit 溢出与梯度下溢。

## 九、演进与趋势
FP8 在推理为主，训练仍多以 BF16 为主干。

## 十、小结
范围 vs 精度是低精度选型的核心权衡。
