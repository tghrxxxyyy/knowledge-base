# 混合精度最佳实践与陷阱

> 对应 pytorch/pytorch AMP 指南与 NVIDIA/TensorRT-LLM 训练建议。

## 一、背景与挑战
混合精度能提速 2~3 倍，但错误使用会引入静默精度损失甚至训练发散。

## 二、核心原理
规则：主权重/优化器状态用 FP32；前向/反向用 BF16（首选）或 FP16；归约、softmax、loss 计算保留高精度。

## 三、形式化与数学基础
参数更新：`θ_fp32 ← θ_fp32 - η·g_fp32`。低精度仅用于 `y = W_fp16 x`，反传后梯度立即转 FP32 累加。

## 四、代码实现
```python
# 推荐的 autocast 区域边界
with torch.autocast("cuda", dtype=torch.bfloat16):
    outputs = model(inputs)        # 计算走低精度
loss = outputs.loss                # loss 已是 fp32 标量
loss.backward()                    # 梯度回传
```

## 五、与其他技术对比
全 FP32 稳但慢；全 FP16 快但易崩；混合精度在中间取得平衡。

## 六、常见误区
把 embedding、layernorm 也强制低精度，可能损失显著；建议让 autocast 自动决定或对这些层排除。

## 七、与开源书/权威来源对应
pytorch/pytorch `torch.amp` 最佳实践；NVIDIA/TensorRT-LLM 精度配置。

## 八、面试题
问：哪些操作应保持 FP32？答：归约、softmax 分母、优化器状态、loss。

## 九、演进与趋势
自动精度（automatic mixed precision 2.0）与 FP8 推理加速落地。

## 十、小结
遵守主权重 FP32、计算低精度的原则，可安全获得加速。
