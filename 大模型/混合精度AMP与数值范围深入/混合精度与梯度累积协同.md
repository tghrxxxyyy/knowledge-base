# 混合精度与梯度累积协同

> 对应 microsoft/DeepSpeed 与 pytorch/pytorch 的 autocast + 累积实践。

## 一、背景与挑战
大 batch 需求下，梯度累积与混合精度常并用；二者在缩放与 dtype 转换上需协调，否则精度或正确性受损。

## 二、核心原理
累积期内梯度以低精度累加需谨慎（误差累积）；常见做法是 FP32 主梯度缓冲，或每步 cast 后累加，最后统一 step。

## 三、形式化与数学基础
真实梯度近似 `g ≈ (1/K)Σ_k g_k`，混合精度下 `g_k` 为低精度。为减负累误差，维护 `G_fp32 += g_k.to(fp32)`。

## 四、代码实现
```python
opt.zero_grad()
for i, (x, y) in enumerate(loader):
    with torch.autocast(dtype=torch.bfloat16):
        loss = model(x, y).loss / ACCUM
    scaler.scale(loss).backward()
    if (i + 1) % ACCUM == 0:
        scaler.step(opt); scaler.update(); opt.zero_grad()
```

## 五、与其他技术对比
BF16 下可直接累积低精度（范围安全）；FP16 建议 FP32 累积缓冲以防误差。

## 六、常见误区
忘记把 loss 除以 ACCUM，导致有效 lr 放大 K 倍。

## 七、与开源书/权威来源对应
microsoft/DeepSpeed 梯度累积 + 混合精度文档；pytorch/pytorch AMP 教程。

## 八、面试题
问：累积时为何可除以 K？答：梯度线性，先平均等价于最后平均。

## 九、演进与趋势
ZeRO 与 FP8 进一步降低累积显存。

## 十、小结
混合精度与累积协同需关注 dtype 与缩放，避免隐性误差。
