# 混合精度下的数值溢出

> 对应 pytorch/pytorch AMP 数值实践与 Dao 2022 FlashAttention（arXiv:2205.14135）的数值稳定实现。

## 一、背景与挑战

低精度把数值可表示区间压缩了一个数量级，原本在 FP32 中相安无事的中间量会突然越界。最典型的三类溢出源是：softmax 中的 $\exp$ 上溢、layer norm 下方差的大数平方上溢、以及长归约在低精度累加下的下溢。这些故障常表现为 loss 出现 `inf`/`NaN`、梯度变 `nan` 后污染全部参数。

难点在于「静默性」：单个中间量溢出后，若该位置随后被 mask 掉或未被使用，故障可能不立即显现，而是在训练若干步后才集中爆发，难以定位。

## 二、核心原理

数值稳定的核心思想是**平移不变性与缩放不变性**：

- softmax 对输入整体平移不变：$\mathrm{softmax}(x) = \mathrm{softmax}(x - m)$，取 $m=\max_i x_i$ 可让所有指数输入 $\le 0$，从而 $\exp \le 1$，消除上溢。
- 分母求和可同步减去最大值以避免下溢风险，结果不变。
- FlashAttention 在此之上采用在线（online）softmax，在分块遍历 K/V 时增量维护运行最大值 $m$ 与运行分母 $\ell$，使显存从 $O(S^2)$ 降到 $O(S)$ 且数值稳定。

只要保持这些恒等变换，低精度下仍可获得与 FP32 一致的数学结果（在舍入误差范围内）。

## 三、形式化与数学基础

朴素 softmax 与其稳定形式：

$$ \mathrm{softmax}(x)_i = \frac{e^{x_i}}{\sum_j e^{x_j}} = \frac{e^{x_i - m}}{\sum_j e^{x_j - m}}, \qquad m = \max_j x_j $$

FP16 的 $\exp$ 上溢阈值约为 $x > 11.09$（因 $\ln(65504)\approx 11.09$），FP32 约为 $x > 88.7$。因此减最大值在 FP16 下不是优化而是**必需**。

在线 softmax 的增量更新：维护 $m$、$\ell$，处理新块 $\tilde x$ 时

$$ m' = \max(m, \max \tilde x), \qquad \ell' = e^{\,m - m'}\,\ell + \sum_j e^{\,\tilde x_j - m'} $$

新块贡献拼接时按 $e^{\,m - m'}$ 重缩放历史累加项。该恒等式保证分块计算与整块计算等价。

## 四、代码实现

```python
import torch
import torch.nn.functional as F

def stable_softmax(x, dim=-1):
    # 减最大值：把指数输入压到 <= 0，防止上溢
    m = x.max(dim=dim, keepdim=True).values
    e = torch.exp(x - m)
    return e / e.sum(dim=dim, keepdim=True)

def stable_logsumexp(x, dim=-1):
    m = x.max(dim=dim, keepdim=True).values
    return m.squeeze(dim) + torch.log(torch.exp(x - m).sum(dim=dim))

# 优先使用内置的稳定实现：会走 Flash / Memory-Efficient 内核
out = F.scaled_dot_product_attention(q, k, v, is_causal=True)

# 自定义 kernel 中也要显式稳定，autocast 不会替你处理
with torch.autocast(device_type="cuda", dtype=torch.float16):
    logits = (q @ k.transpose(-2, -1)) / (q.size(-1) ** 0.5)
    attn = stable_softmax(logits)      # 手动减最大值
    y = attn @ v
```

对大数平方敏感的归一化，建议先用 FP32 计算方差统计量再 cast 回低精度。

## 五、与其他技术对比

| 实现 | 显存复杂度 | 溢出风险 | 精度处理 |
| --- | --- | --- | --- |
| 朴素 softmax | $O(S^2)$ 需物化矩阵 | 高，未减最大值即 overflow | 无内建保护 |
| 减最大值 softmax | $O(S^2)$ | 低 | 手工保证平移不变 |
| FlashAttention 在线 softmax | $O(S)$ | 低 | 运行最大值 + 重缩放 |
| 内置 SDPA | $O(S)$ 或 $O(S^2)$ | 低 | 内核内建稳定 |

## 六、常见误区

- 认为 autocast 会自动保证数值稳定：它只做 dtype 分派，自定义算子仍需自己稳定。
- 只在训练后期才出现 NaN 就归因于数据：长归约的下溢同样会在若干步后累积成 NaN。
- 减最大值时用 `mean` 而非 `max`：平移量不足，仍可能上溢。
- 在低精度下计算方差：$\sum (x-\mu)^2$ 的平方项会放大溢出风险，应使用 FP32 统计。
- 忽略 mask 的取最大值语义：对应该被屏蔽的位置取最大值会污染 $m$，需在减最大值前先置为 $-\infty$。

## 七、与开源书·权威来源对应

Dao 2022 FlashAttention 给出在线 softmax 与 IO 感知的稳定实现；pytorch/pytorch 的 `scaled_dot_product_attention` 内置了数值稳定的注意力内核。具体内核选择策略以官方最新文档为准。

## 八、面试题

- 问：softmax 减最大值的作用？答：限制指数输入非正，防上溢且结果不变。
- 问：FP16 下 $\exp$ 何时溢出？答：约 $x>11.09$，因 $\ln(65504)\approx11.09$。
- 问：FlashAttention 如何避免物化 $S\times S$ 矩阵？答：分块 + 在线 softmax，增量维护最大值与分母。
- 问：mask 与减最大值的顺序？答：先 mask 成 $-\infty$ 再取最大值。

## 九、演进与趋势

低精度注意力内核持续改进数值鲁棒性；FP8 注意力与分块归约结合；编译器开始自动插入稳定化变换。具体能力以官方最新文档为准。

## 十、小结

混合精度把溢出阈值大幅压低，数值稳定技巧从「优化」升级为「必需」。记住三个不变量：softmax 平移不变、logsumexp 可减最大值、在线 softmax 按 $e^{m-m'}$ 重缩放。
