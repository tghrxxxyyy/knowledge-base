# 鲁棒训练

> 对应 Madry et al., 2017（对抗训练）；Zhang et al., *TRADES*, 2019。

## 一、背景与挑战

标准训练在扰动下崩；需在保持精度同时提升鲁棒性（存在精度-鲁棒权衡）。

## 二、核心原理

对抗训练最小化最坏情况损失（min-max）：
$\min_\theta \mathbb E_x[\max_{\|\delta\|\le\epsilon} \mathcal L(\theta, x+\delta, y)]$，PGD 作内循环攻击。

## 三、数学形式

TRADES 分离自然与边界损失：$L = L_{nat} + \beta \cdot L_{rob}$（KL 项约束鲁棒）。

## 四、代码实现

```python
xadv = pgd_attack(model, x, y, eps)
loss = ce(model(xadv), y) + beta * ce(model(x), y)
```

## 五、与其他对比

- 对抗训练提升鲁棒但常降自然精度（权衡）。
- 与 大模型安全与对齐 共享“最坏情况”思维。

## 六、常见误区

- 期望对抗训练零成本；精度-鲁棒权衡客观存在。
- 攻击强度不足致鲁棒性虚高。

## 八、面试题

- 对抗训练的本质？答：min-max，训模型对最坏扰动仍正确。

## 九、演进

标准训练 → FGSM 训练 → PGD 对抗训练 → TRADES/权衡优化。

## 十、小结

对抗训练以 min-max 目标换取鲁棒性，是经验鲁棒的主流且可靠方法。
