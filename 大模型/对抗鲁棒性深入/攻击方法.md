# 攻击方法

> 对应 Madry et al., *PGD*, 2017；Carlini & Wagner, 2017（C&W）。

## 一、背景与挑战

单步攻击易被防御，需更强迭代/优化攻击评估真实鲁棒性。

## 二、核心原理

- PGD（投影梯度下降）：$\delta_{t+1} = \Pi_\epsilon(\delta_t + \alpha\,\text{sign}(\nabla_\delta \mathcal L))$，迭代逼近最强扰动。
- C&W：直接优化 $L_2$ 最小扰动使误分类。
- 黑盒：迁移/查询估计梯度。

## 三、数学形式

PGD 目标：$\max_{\|\delta\|_p\le\epsilon} \mathcal L(\theta, x+\delta, y)$；投影保证在球内。

## 四、代码实现

```python
for _ in range(steps):
    delta = (delta + alpha*grad.sign()).clamp(-eps, eps)
```

## 五、与其他对比

- PGD 是强一阶攻击，常作鲁棒训练对手；C&W 求最小扰动更精。
- 与 提示注入防御深入 中的攻击分类对照（文本侧）。

## 六、常见误区

- 以弱攻击评估鲁棒性致乐观误判。
- 忽视 $L_p$ 范数差异（无穷范数≠真实不可察）。
