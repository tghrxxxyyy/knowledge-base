# 对抗样本基础

> 对应 Szegedy et al., 2013；Goodfellow et al., *FGSM*, 2014。

## 一、背景与挑战

对输入加人眼不可察的扰动可使模型高置信误判，揭示模型脆弱性。

## 二、核心原理

对抗样本 $x' = x + \delta$，满足 $\|\delta\|_\infty \le \epsilon$ 且 $f(x')\ne f(x)$。
FGSM 单步：$\delta = \epsilon \cdot \text{sign}(\nabla_x \mathcal L(\theta,x,y))$。

## 三、数学形式

损失对输入的梯度决定最速上升方向；小 $\epsilon$ 下线性假设解释其有效性。

## 四、代码实现

```python
xadv = x + eps * torch.sign(grad_x)   # FGSM
```

## 五、与其他对比

- 大模型也受提示扰动影响（提示注入防御深入 衔接）。
- 与 对抗鲁棒性（本主题）共同构成安全鲁棒面。

## 六、常见误区

- 以为对抗样本是噪声偶然；其是系统性梯度方向。
- 误以为只有图像；文本/代码同样存在（字符级扰动）。
