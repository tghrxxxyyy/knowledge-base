# 认证鲁棒性

> 对应 Cohen et al., *Randomized Smoothing*, 2019；认证防御综述。

## 一、背景与挑战

经验鲁棒可被更强攻击破；认证提供“保证半径内必正确”的可证明界限。

## 二、核心原理

随机平滑：以高斯噪声多次扰动取多数投票得平滑分类器；可推认证半径。
对 $L_2$：半径 $R=\frac{\sigma}{2}(\Phi^{-1}(p_A)-\Phi^{-1}(p_B))$，$p_A$ 为最可能类概率。

## 三、数学形式

若类 A 投票概率 $p_A$ 显著高于次高 $p_B$，则 $\|\delta\|_2 < R$ 内分类不变。

## 四、代码实现

```python
votes = [classify(x + sigma*randn()) for _ in range(N)]
pred = majority(votes); R = sigma/2*(erfinv(2*top1-1)-erfinv(2*top2-1))
```

## 五、与其他对比

- 认证保证但半径小、计算贵（需多次采样）。
- 与 鲁棒训练 互补：后者经验、前者可证明。

## 六、常见误区

- 认证半径小不等于“安全”，仅保证该半径内。
- 忽视采样数不足致半径估计不准。

## 八、面试题

- 随机平滑如何认证？答：多数投票 + 高斯平滑导出可证明鲁棒半径。

## 九、演进

精确认证 → 随机平滑（可扩展）→ 更紧半径方法。

## 十、小结

认证鲁棒以计算代价换取可证明保障，是高安全场景的刚需。
