# 对抗鲁棒性与大模型安全

> 对应 大模型安全与对齐 / 提示注入防御深入 / 越狱防御深入。

## 一、背景与挑战

大模型面对的不是像素扰动，而是文本对抗（越狱、提示注入、token 扰动），本质同属鲁棒性。

## 二、核心原理

- 越狱：构造对抗提示使安全护栏失效（等价于离散空间对抗样本）。
- 提示注入：把恶意指令混入上下文（数据投毒式攻击）。
- 鲁棒训练思想迁移：用红队样本对抗式微调（见 安全红队深入）。

## 三、数学形式

离散对抗：$x'=\arg\max_{x'\in\mathcal X_\epsilon} \mathcal L_{harm}(f(x'))$，受编辑距离/语义约束。

## 四、代码实现

```python
# 红队样本进训练集
train_data += redteam_prompts  # 对抗式微调
```

## 五、与其他对比

- 图像对抗连续可微；文本对抗离散不可微，需离散优化/遗传搜索。
- 与 提示注入防御深入 共享防御目标。

## 六、常见误区

- 以为文本无“扰动”概念；离散对抗同具系统性。
- 仅靠规则过滤，易被同义改写绕过。

## 九、演进

图像对抗 → NLP 对抗 → 大模型越狱/注入 → 对抗式对齐训练。

## 十、小结

大模型安全可视为离散对抗鲁棒性，传统对抗训练思想在红队微调中重生。
