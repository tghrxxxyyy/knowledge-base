# 主动学习与一致性

> 对应 Bianchi et al., 2023；Wang et al., 2023（多数投票）。

## 一、背景与挑战

优先标注高价值/高分歧样本，降总噪声成本。

## 二、核心原理

对 RM 不确定或标注者分歧大样本送人工；多数投票定标，一致低者再标或弃。

## 三、数学形式

采样效用 $U(x)=\max_i \text{Var}(r_i(x))+\text{disagree}(annotators)$。

## 四、代码实现

```python
pool = [x for x in unlabeled if utility(x) > tau]
```

## 五、与其他对比

- 与标注噪声建模共享一致度。
- 与反馈噪声总览共享降噪。

## 六、常见误区

- 只采高分歧漏系统偏见。
- 多数投票固化偏见。
