# 人类反馈噪声鲁棒总览

> 对应 Ouyang et al., *InstructGPT*, 2022；Casper et al., *Robust RLHF*, 2023。

## 一、背景与挑战

人类标注存在分歧、粗心、偏见，噪声偏好若被当真会误导奖励模型与策略。

## 二、核心原理

把标注视为带噪观测，用不确定度建模、加权、集成与去噪训练提升鲁棒性。

## 三、数学形式

观测 $y^{obs}\sim P(y^{true})\cdot(1-\eta)+\text{噪声}\cdot\eta$；$\eta$ 为标错率。

## 四、代码实现

```python
w = (1 - est_noise) * 1.0
```

## 五、与其他对比

- 与奖励模型退化与塌缩深入共享 RM 质量。
- 与多目标偏好聚合深入共享加权。

## 六、常见误区

- 假设标注无噪。
- 均匀加权忽视标注者差异。
