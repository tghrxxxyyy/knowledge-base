# 反馈噪声鲁棒训练实践

> 对应 Ouyang et al., 2022；Casper et al., 2023；Rafailov et al., *DPO*, 2023。

## 一、背景与挑战

生产偏好数据必含噪，需在管线内建鲁棒。

## 二、核心原理

多标+一致过滤、RM 集成、学习率保守、监控验证集真偏好准确率；DPO 同样需去噪加权。

## 三、数学形式

早停当验证真偏好准确率 $acc<\rho_{base}$ 即过拟合噪声。

## 四、代码实现

```python
if val_acc < base_acc - eps:
    stop()
```

## 五、与其他对比

- 与检测与缓解（奖励退化）共享验证。
- 与去噪训练方法共享管线。

## 六、常见误区

- 管线无一致过滤。
- 验证集也含噪致误判。
