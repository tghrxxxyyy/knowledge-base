# 去噪训练方法

> 对应 Casper et al., *Robust Policy Optimization*, 2023；Islam et al., *PAS*, 2023。

## 一、背景与挑战

如何在噪声偏好上训稳 RM 与策略。

## 二、核心原理

RM 集成取均值降方差；裁剪大损失离群对；用置信样本优先训练；DPO 对噪声同样敏感需加权。

## 三、数学形式

稳健损失 $\mathcal L=\sum_i w_i \ell_i$，对高噪声 $i$ 降权或截断。

## 四、代码实现

```python
loss = (w * dpo_loss_per_pair).mean()
```

## 五、与其他对比

- 与 Bradley-Terry噪声共享降噪。
- 与分布偏移退化共享集成。

## 六、常见误区

- 截断过狠损信号。
- 只集成 RM 忽略策略噪声。

## 八、面试题

- 集成如何降噪？答：多 RM 均值抑方差，离群对截断减影响。

## 九、演进

单 RM → 集成 → 加权截断。

## 十、小结

去噪靠加权集成与截断，护住真信号。
