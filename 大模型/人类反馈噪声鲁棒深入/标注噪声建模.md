# 标注噪声建模

> 对应 Wang et al., *Bootstrap / RLHF Noisy*, 2023；Casper et al., 2023。

## 一、背景与挑战

需区分随机噪声与系统性偏见，二者治理不同。

## 二、核心原理

随机噪声靠多标投票降；系统偏见靠去偏重加权或对抗校正；用标注者一致度估可靠度。

## 三、数学形式

有效权重 $w_i\propto 1/(1+\sigma_i^2)$，低一致标注者权低。

## 四、代码实现

```python
w = 1.0 / (1 + annotator_var[i])
```

## 五、与其他对比

- 与 Bradley-Terry噪声共享建模。
- 与多目标偏好聚合深入共享加权。

## 六、常见误区

- 把系统偏见当随机噪声平滑掉。
- 只信多数忽略专家。
