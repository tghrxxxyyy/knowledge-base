# 语言模型校准

> 对应 Kadavath et al., *Language Models (Mostly) Know What They Know*, 2022。

## 一、背景与挑战

LLM 在生成/选择题上的置信度是否可信？研究揭示其“大多知道自己知不知道”。

## 二、核心原理

用“P(真)”式探针：让模型输出“是否正确”的概率，与其实际正确率比对；多数模型能自校准但会过/欠自信于难例。

## 三、数学形式

让模型估计 $P_{\text{true}}$；比较经验 $acc$ vs 该概率；校准误差随任务难度变。

## 四、代码实现

```python
p_true = model(f"陈述: {s}\n上述是否正确? 概率:")
calib_err = ece(p_true, is_correct)
```

## 五、与其他对比

- 与 不确定性估计深入（语义熵等）互补。
- 与 模型校准深入（总览）衔接。

## 六、常见误区

- 以为模型自估概率总是准；难例/分布外会失校。
- 忽略提示词影响校准（如“你确定吗”）。

## 八、面试题

- 问：LLM 知不知道自己不知？答：多数情况能自估正确性，但难例/分布外会过度/不足自信。

## 九、演进

分类校准 → 生成式校准 → 自估探针。

## 十、小结

LLM 具一定自校准能力，但是部署需显式校准与提示设计。
