# 置信度表达与提示校准

> 对应提示式校准（verbalized confidence）；提示工程深入 衔接。

## 一、背景与挑战

如何让模型“说出”可靠置信？表达式置信受提示与格式影响大。

## 二、核心原理

用一致性采样（多次采样一致率高则更可信）、自洽提示、或让其输出概率字面值再校准；提示词设计显著影响校准。

## 三、数学形式

表达置信 $c = \text{mode}(\{c_i\})$ 多次采样；校准后 $\hat c = g(c)$（如温度缩放）。

## 四、代码实现

```python
samples = [model(q) for _ in range(5)]
conf = majority_vote(samples)        # 一致性作置信代理
```

## 五、与其他对比

- 与 不确定性估计深入（一致性/熵）同源。
- 与 提示工程深入（格式影响）共享。

## 六、常见误区

- 字面“我很确定”不等于高正确。
- 一致性高未必正确（系统性偏）。

## 八、面试题

- 问：一致性为何可作置信？答：多次采样结果一致概率高，通常对应模型更确信且更可能正确。

## 九、演进

单样本 → 多采样一致 → 自洽+校准。

## 十、小结

提示式置信需采样与校准配合，字面自信不可轻信。
