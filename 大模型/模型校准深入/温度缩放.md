# 温度缩放校准

> 对应 Guo et al., 2017（Temperature Scaling）。

## 一、背景与挑战

softmax 输出过尖锐（过自信）；温度缩放单一参数软化概率。

## 二、核心原理

用验证集学一个温度 $T>1$ 除 logits 后再 softmax，使校准误差最小；仅 1 参、不改排序。

## 三、数学形式

$\hat p_i = \frac{\exp(z_i/T)}{\sum_j \exp(z_j/T)}$；最优 $T^*=\arg\min_T ECE(\hat p)$。

## 四、代码实现

```python
logits = model(val_x)
T = tune_temperature(logits, val_y)     # 最小化 NLL/ECE
probs = softmax(logits / T)
```

## 五、与其他对比

- 比 Platt/Vector 缩放更简单且常最优（不改排序）。
- 与 模型校准深入（总览）衔接。

## 六、常见误区

- 在训练集调 T 致过拟合校准。
- 误以为 T 改准确率（仅改置信分布）。
