# 模型校准总览

> 对应 Guo et al., *On Calibration of Modern Neural Networks*, 2017；模型校准深入。

## 一、背景与挑战

模型置信度常不反映真实正确率（过自信）；校准让“说 80% 对就对 80%”。

## 二、核心原理

校准衡量预测概率与经验频率一致性；未校准模型高风险场景危险（医疗/自动驾）。常用温度缩放等后处理。

## 三、数学形式

校准误差：$ECE=\sum_{m=1}^M \frac{|B_m|}{n}|acc(B_m)-conf(B_m)|$，分桶比较。

## 四、代码实现

```python
from sklearn.calibration import calibration_curve
frac_pos, mean_pred = calibration_curve(y_true, y_prob, n_bins=10)
```

## 五、与其他对比

- 与 不确定性估计深入（校准是确定性输出）互补。
- 与 模型评测指标深入（准确率≠校准）对照。

## 六、常见误区

- 以为高准确率即校准好。
- 大模型常更不准（过自信）。
