# 模型校准实践与部署

> 对应生产校准流程；模型评测指标深入 衔接。

## 一、背景与挑战

部署前须校准，否则高风险决策误信。

## 二、核心原理

在验证集测 ECE，用温度/向量缩放后处理；对关键应用加拒答阈值（低置信不答）。

## 三、数学形式

拒答策略：若 $\hat p < \tau$ 则拒答；总体风险降，$\tau$ 控覆盖率-准确率。

## 四、代码实现

```python
if max(probs) < tau:
    return "低置信，拒绝回答"
```

## 五、与其他对比

- 与 不确定性估计深入（拒答/弃权）互补。
- 与 安全与对齐深入（拒答安全）共享。

## 六、常见误区

- 阈值固定不顾任务风险。
- 校准集与部署分布异致失效。

## 八、面试题

- 问：校准如何用于安全？答：低置信拒答，把不可靠输出转人工或声明不确定。

## 九、演进

离线校准 → 在线自适应 → 风险感知拒答。

## 十、小结

校准落地靠后处理+拒答阈值，是可信部署一环。
