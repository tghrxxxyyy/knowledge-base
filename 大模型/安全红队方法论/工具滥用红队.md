# 工具滥用红队

> 见「Function_Calling进阶/工具安全防护」与「安全红队方法论/红队方法论总览」。

## 一、背景与挑战

Agent 的工具可被诱导执行危险操作（删库、发信、命令执行）。

## 二、核心原理

模拟攻击：诱导模型调用高危工具、绕过确认、链式组合无害工具达成危害（如通过代码执行读密钥）。

## 三、关键要点

- 需沙箱+权限最小化。
- 多工具组合风险大于单工具。

## 四、代码实现

```python
if agent_decides("rm -rf") and not approved: block()
```

## 五、与其他对比

- 普通越狱攻文本；工具滥用攻「动作」。

## 六、常见误区

- 工具默认可用——应默认拒绝高危。

## 七、与开源书对应

- OWASP LLM: 工具滥用条目。
- llm-universe: https://github.com/datawhalechina/llm-universe

## 八、面试题

- Agent 工具滥用如何防御？

## 九、演进

无防护 → 沙箱 → 权限分级+确认。

## 十、小结

工具红队守住「能做什么」的边界。
