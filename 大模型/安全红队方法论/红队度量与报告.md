# 红队度量与报告

> 见「安全红队方法论/红队方法论总览」与「模型评测指标深入」。

## 一、背景与挑战

红队结果需可量化、可比较、可追踪。

## 二、核心原理

定义攻击成功率（ASR）、危害分级、覆盖率（类×场景），形成风险矩阵与修复优先级报告。

## 三、数学形式

```
ASR = (# successful attacks) / (# total attempts)
```

## 四、代码实现

```python
report = {"jailbreak": asr, "leak": leak_rate, "tool_abuse": ab_rate}
```

## 五、关键要点

- 分级让修复有先后。
- 需复现步骤存档。

## 六、与其他对比

- 性能报告看分；红队报告看风险。

## 七、常见误区

- ASR=0 即安全——可能样本不够。
