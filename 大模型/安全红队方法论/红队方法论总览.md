# 红队方法论总览

> 对应 llm-course 安全章与 OWASP LLM Top 10；Ganguli et al., *Red Teaming*, 2022。

## 一、背景与挑战

上线前需系统发现模型的危害面，红队以对抗方式主动攻击。

## 二、核心原理

方法分：**人工红队**（专家构造攻击）、**自动化红队**（用模型生成对抗提示）、**众包红队**。覆盖有害内容、越狱、数据泄露、工具滥用。

## 三、关键要点

- 红队目标是「找漏洞」非「评性能」。
- 需记录攻击成功率（ASR）。

## 四、代码实现

```python
for attack in attacks:
    if is_harmful(model(attack)): asr += 1
```

## 五、与其他对比

- 评测看能力；红队看风险边界。

## 六、常见误区

- 红队通过=安全——只是当时未攻破。
