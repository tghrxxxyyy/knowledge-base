# 自动化红队

> 见「安全红队方法论/红队方法论总览」与「偏好优化前沿/RLAIF自反馈对齐」。

## 一、背景与挑战

人工红队覆盖有限、成本高，需规模化自动攻击。

## 二、核心原理

用攻击模型基于目标模型反馈迭代生成更强攻击（如 PAIR：攻击者-裁判-目标三角），或用强化搜索找高 ASR 提示。

## 三、关键要点

- 需裁判判定是否越狱。
- 攻击模型也可能被反制。

## 四、代码实现

```python
attack = attacker.improve(target, judge, prev_attack)
```

## 五、与其他对比

- 人工慢但深；自动广但浅。

## 六、常见误区

- 自动攻击即全覆盖——仍有盲区。

## 七、与开源书对应

- PAIR: https://arxiv.org/abs/2310.08419
- llm-course: https://github.com/mlabonne/llm-course

## 八、面试题

- PAIR 中攻击者与裁判如何协作？

## 九、演进

模板库 → 模型生成 → 闭环搜索。

## 十、小结

自动化红队把安全测试规模化。
