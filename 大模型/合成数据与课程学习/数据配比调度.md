# 数据配比调度

> 对应 Xie et al. (2023) DoReMi: Optimizing Data Mixtures Speeds Up Language Model Pretraining；亦见大规模预训练语料调度实践。

## 一、背景与挑战

现代 LLM 预训练语料由多个域（网页、代码、书籍、学术、对话、多语）混合而成，不同域权重直接塑造模型的能力偏向：代码占比高则编码强，学术占比高则推理强。固定人工配比往往依赖经验、次优且难迁移。

更深层挑战是「训练全程并非一成不变」：前期需学通用语言与常识，后期可针对性加难、加专。如何确定各域权重、是否随步数动态调度，是预训练效率与最终能力的关键旋钮。

## 二、核心原理

数据配比调度分静态与动态两类：

1. **静态配比**：按经验或搜索固定域权重 $\lambda_d$，全程不变。
2. **动态调度**：随训练阶段调整权重，典型如后期提升代码/数学比例，强化推理与工具能力。
3. **自动搜索**：用小型代理模型（proxy）快速评估不同域权重下的损失，反推最优配比，再迁移到大模型。

DoReMi 用参考模型（reference model）与目标模型的 KL 散度作域重要度估计，给「代理模型在该域损失下降快」的域更高权重，实现数据高效。

工程上还有「退火式调度」：训练末段逐步降低学习率的同时，把数据混合拉向「与下游评测/目标分布更接近」的配比（如更多指令、更多推理），相当于用最后阶段的数据做轻量对齐预热。这种「预训练尾巴」已被多家实践证实能提升 few-shot 与指令遵循，是配比调度从「能力塑造」延伸到「对齐预热」的体现。

## 三、形式化与数学基础

设域集合 $D=\{d_1,\dots,d_m\}$，混合权重 $\boldsymbol{\lambda}$ 满足 $\sum_d \lambda_d = 1$。代理模型在混合分布下的损失：

$$
\mathcal{L}(\boldsymbol{\lambda}) = \sum_d \lambda_d \, \mathcal{L}_d(\theta)
$$

DoReMi 以参考模型分布 $q_d$ 与目标模型分布 $p_d$ 的域级重要性：

$$
w_d = \frac{\exp\big(-\mathrm{KL}(p_d \Vert q_d)\big)}{\sum_{d'} \exp\big(-\mathrm{KL}(p_{d'} \Vert q_{d'})\big)}
$$

用 $w_d$ 重加权域，使「目标模型相对参考模型进步最大」的域获得更多样本。

## 四、代码实现

基于代理模型扫描域权重的精简流程：

```python
def search_mixture(proxy, domains, steps=200):
    best, best_loss = None, float("inf")
    for _ in range(steps):
        lam = sample_simplex(len(domains))      # 随机配比
        loss = proxy.eval_mixed(lam, domains)   # 评估混合损失
        if loss < best_loss:
            best, best_loss = lam, loss
    return best                                 # 迁移至大模型
```

动态调度则在训练不同 step 区间切换 `lam`。

## 五、与其他技术对比

| 策略 | 是否需要代理 | 计算量 | 效果 | 代表 |
|------|--------------|--------|------|------|
| 人工固定 | 否 | 极低 | 中 | 早期训练 |
| 静态搜索 | 是(小) | 中 | 高 | DoReMi |
| 动态调度 | 可选 | 中 | 高 | 后期提代码 |
| 课程学习 | 否 | 低 | 中-高 | 由易到难 |

## 六、常见误区

- **「配比不重要」**：域权重对能力偏向影响显著，常比单纯加数据更划算。
- **「搜索一次永久有效」**：最优配比随模型规模与训练阶段变化，需重评估。
- **「代码越多越好」**：过度倾斜会牺牲通用语言与常识。
- **混淆静态与动态**：后期提专需动态调度，静态配比难兼顾全程。

## 九、演进与趋势

从人工配比到 DoReMi 式自动搜索，再到与课程学习（由易到难）、与数据去污染联动。前沿方向是「训练-aware」在线配比：根据实时 loss 与能力探针动态调整各域采样概率，并结合合成数据（见「合成数据概述」）补齐稀缺域。

## 十、小结

数据配比调度以低成本撬动大模型能力结构：静态搜索（如 DoReMi）定全局权重，动态调度在后期强化专域。它是预训练工程中投入产出比最高的旋钮之一，应与课程学习协同设计。
