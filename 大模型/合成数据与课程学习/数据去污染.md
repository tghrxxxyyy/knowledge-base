# 数据去污染 Decontamination

> 对应 Lee et al. (2022) Deduplicating Training Data Makes Language Models Better；亦见评测防泄漏（ contamination）实践。

## 一、背景与挑战

大模型预训练语料多爬取自公开互联网，而主流评测基准（如 MMLU、GSM8K、HumanEval）的题目、答案与解析同样大量存在于网上。若训练数据包含与测试集高度重叠的样本，模型等于「提前看过考卷」，报告分数将严重虚高，无法反映真实泛化能力。

去污染（Decontamination）即系统性地从训练集中识别并移除与评测基准重叠的样本。其难点在于：重叠形式多样（整题、改写、答案泄漏、噪声副本），且需在「剔除泄漏」与「保留正常语料」之间平衡，避免误删影响训练。

## 二、核心原理

去污染通常基于相似度匹配，主流手段：

1. **n-gram 重叠**：以 8-gram、13-gram 等长片段作精确或近似匹配，命中即视为污染。
2. **嵌入相似度**：用句子/文档向量计算余弦相似度，超阈值判污染。
3. **答案泄漏检测**：特别检查含标准答案（如 HumanEval 函数签名）的代码片段。

流程为「对基准构造指纹 → 在语料中检索 → 高重叠样本剔除 → 记录剔除比例以备披露」。

## 三、形式化与数学基础

设评测样本为 $q$，语料片段为 $c$。以 $n$-gram 集合 $G_n(\cdot)$ 衡量重叠：

$$
\text{overlap}(q, c) = \frac{|G_n(q) \cap G_n(c)|}{|G_n(q)|}
$$

判定规则为：

$$
\text{contaminated}(c) = \mathbb{1}\left[ \exists q \in \text{Eval},\; \text{overlap}(q,c) \ge \theta \right]
$$

嵌入法用余弦相似度 $s = \cos(\text{emb}(q), \text{emb}(c))$，阈值 $\tau$ 控制灵敏度。污染率：

$$
\rho = \frac{|\{c : \text{contaminated}(c)\}|}{|C|}
$$

## 四、代码实现

8/13-gram 重叠判定的精简实现：

```python
def ngrams(text, n):
    toks = text.split()
    return set(tuple(toks[i:i+n]) for i in range(len(toks)-n+1))

def is_contaminated(corpus_doc, eval_ngrams, n=13, thr=0.8):
    g = ngrams(corpus_doc, n)
    if not g:
        return False
    hit = max(len(g & eg) / len(g) for eg in eval_ngrams)
    return hit >= thr
```

生产需对全基准预计算 n-gram 指纹并做分块检索。

## 五、与其他技术对比

| 方法 | 精度 | 召回 | 成本 | 适用 |
|------|------|------|------|------|
| 8-gram | 高 | 中 | 低 | 短文本 |
| 13-gram | 很高 | 中 | 低 | 长文本/代码 |
| 嵌入相似 | 中 | 高 | 中 | 改写样本 |
| 人工审查 | 最高 | 高 | 极高 | 关键基准 |

## 六、常见误区

- **「只去整题」**：改写、噪声副本与答案泄漏同样构成污染，需多粒度匹配。
- **「去污染影响训练」**：误删正常语料会损害能力，阈值需保守且记录比例。
- **「训练后无需去污染」**：评测前必须复核，否则分数不可信。
- **「去污染=去重」**：去重消除语料内部重复，去污染针对评测泄漏，目标不同。

## 九、演进与趋势

去污染从静态 n-gram 发展到「嵌入+答案指纹+代码签名」多信号融合，并纳入可复现训练 pipeline 的强制步骤。随着合成数据与网络爬取界限模糊，去污染正与数据溯源（provenance）、许可证合规结合，成为负责任发布的标配披露项。

## 十、小结

数据去污染是评测可信度的守门人：用 n-gram/嵌入相似度识别并剔除与基准重叠的样本，防止「考试泄题」式虚高。工程上需平衡召回与误删，并如实披露污染率。
