# 合成数据概述

> 对应 mlabonne llm-course「Synthetic Data」与近期模型自生成数据研究（Self-Instruct、Phi 系列、ReSTEM 等）。

## 一、背景与挑战

高质量人工标注语料的增速远低于大模型训练对数据的吞噬速度，且部分高价值数据（带完整推理链的数学题、可运行代码、稀缺语言语料）天然稀缺、标注昂贵。合成数据（Synthetic Data）指用更强的「教师模型」自动生成训练样本，以缓解标注稀缺、扩充难例覆盖。

但合成数据带来一对核心矛盾：它能把教师的能力「蒸馏」给学生、补齐长尾分布，也可能让模型陷入「自我循环」——学生学教师、教师由学生训练，偏差与错误被反复放大，形成模型熵塌与多样性坍缩。如何扬长避短，是合成数据工程的首要挑战。

## 二、核心原理

合成数据生产通常遵循「教师生成 → 自动验证 → 筛选入库」三步：

1. **生成**：用教师模型按任务模板产出样本，可批量生成指令、推理链、代码或翻译文本。
2. **验证**：用可执行校验（单元测试、符号计算）、强模型打分或规则约束判定样本真伪与质量。
3. **筛选**：以困惑度、奖励模型分数或拒绝采样保留高信噪比子集。

典型用法包括指令数据（Alpaca 用 GPT 系列生成）、数学推理（生成带 CoT 的过程）、代码（生成并运行验证）与多语言（翻译回流）。

值得强调，合成数据的「质量杠杆」远高于「数量杠杆」：Phi 系列证明，少量「教科书级」高精度合成语料，比海量噪声网络文本更能提升推理与代码能力。这意味着合成不是「无脑扩量」，而是用教师模型的归纳偏好去塑造学生的能力结构——其收益取决于教师质量、验证严格度与分布覆盖，而非单纯条数。

## 三、形式化与数学基础

设学生数据为 $D = \{(x_i, y_i)\}$，教师策略为 $\pi_{teacher}$。合成样本来自 $y_i \sim \pi_{teacher}(\cdot \mid x_i)$。学生经 SFT 拟合教师条件分布：

$$
\mathcal{L}_{SFT} = -\sum_{(x,y)\in D} \log \pi_{student}(y \mid x)
$$

当教师存在系统误差 $\epsilon$ 且筛选未剔除时，学生期望偏差被放大约为：

$$
\mathbb{E}[\pi_{student}] \approx \mathbb{E}[\pi_{teacher}] + \beta \cdot \epsilon
$$

其中 $\beta$ 随迭代轮次增长，揭示「自循环」风险。

## 四、代码实现

一个带可执行验证的代码数据合成示例：

```python
def synth_code_task(teacher, verifier, n=1000):
    buf = []
    for _ in range(n):
        prompt = teacher.gen_prompt()          # 生成题面
        code = teacher.gen_code(prompt)        # 生成解答
        if verifier.run(code, prompt):         # 单元测试校验
            buf.append({"prompt": prompt, "code": code})
    return buf
```

关键在 `verifier` 必须独立、可复现，否则筛不出错误样本。

## 五、与其他技术对比

| 用途 | 收益 | 风险 | 缓解手段 |
|------|------|------|----------|
| 指令数据 | 量大易得 | 分布偏移 | 去重+质量过滤 |
| 推理数据 | 补难样本 | 错误传播 | 自动校验+拒绝采样 |
| 蒸馏 | 小模型更强 | 上限受教师限 | 多教师集成 |
| 多语言 | 补低资源 | 翻译腔 | 回译+母语过滤 |

## 六、常见误区

- **「合成数据无限可用」**：无验证的纯生成会快速累积错误，信噪比崩塌。
- **「教师越强学生越像」**：蒸馏存在能力上限，教师短板不可逆传。
- **「可完全替代真实数据」**：真实数据的长尾、噪声与分布对泛化至关重要，合成数据应作为补充。
- **忽视多样性**：模板化生成导致分布坍缩，需主动扰动与去重。

## 九、演进与趋势

从早期 Self-Instruct 的指令自举，到 Phi 系列强调「教科书级」高质量合成语料，再到拒绝采样微调（ReSTEM）反复生成-筛选迭代，合成数据正从「数量驱动」走向「质量与验证驱动」。未来趋势是闭环自博弈、可执行验证与多教师集成，配合严格的数据去污染与配比调度。

## 十、小结

合成数据是大模型时代的「数据倍增器」，价值来自对教师能力的复用与难例补齐，风险来自自我循环与错误传播。落地的金科玉律是：生成要有验证、入库要有筛选、使用要配真实数据。
