# 电路与特征

> 对应 Wang et al., *Interpretability Dream*, 2022（IOI 电路）；Olah 系列。

## 一、背景与挑战

需把“模型如何算答案”拆成可理解子电路与特征，而非整体黑箱。

## 二、核心原理

- 电路（circuit）：注意力头/MLP 间信息流构成可解释计算路径。
- 特征（feature）：单义方向；通过激活最大化/数据集隐写找代表输入。

## 三、数学形式

因果介入：把某头输出置零或替换，观察行为变化以定位其作用（activation patching）。

## 四、代码实现

```python
# 激活替换（patching）
base_out = run(x_clean); patched = run(x_corrupt, hook_replace(head, base_out))
```

## 五、与其他对比

- 与 注意力数学基础 衔接（头的角色）。
- 与 因果可解释深入 共享因果介入方法。

## 六、常见误区

- 过度解读单一头；实际功能常分布、冗余。
- 认为电路可完全静态；随规模可能出现相变。
