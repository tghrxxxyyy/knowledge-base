# 归因与探针

> 对应 Belinkov, *Probing*, 2019；Adebayo et al., *Sanity Check*, 2018。

## 一、背景与挑战

想知某概念是否存在于某层表示，或某输入成分对输出贡献多大。

## 二、核心原理

- 线性探针：在冻结表示上训线性分类器判断某属性是否可线性解码。
- 归因：积分梯度/注意力归因量化输入-输出贡献。
- 因果探针：干预表示验证其因果作用（非仅相关性）。

## 三、数学形式

探针准确率 $acc = \frac1N\sum \mathbb 1[\text{cls}(h_i)=y_i]$；高 acc 表信息存在。

## 四、代码实现

```python
probe = LogisticRegression().fit(H_train, labels)
acc = probe.score(H_test, labels_test)
```

## 五、与其他对比

- 探针只证“信息存在”，不证“被使用”（需因果验证）。
- 与 机制可解释性深入 互补（探针找特征、电路验证作用）。

## 六、常见误区

- 高探针准确率误当因果使用；需 patching 验证。
- 注意力归因被证明可能误导（注意力数学基础）。

## 八、面试题

- 探针的局限？答：仅示信息可解码，不证模型实际利用。

## 九、演进

线性探针 → 结构化探针 → 因果探针。

## 十、小结

探针与归因是量化表示中信息的工具，但须因果验证避免相关性误读。
