# 可解释性谱系

> 对应 Olah et al., *Interpretability*, 2017–2023；Cunningham et al., *SAE*, 2023。

## 一、背景与挑战

大模型决策黑箱，需区分“事后解释”（attribution）与“机制解释”（内部电路）。

## 二、核心原理

- 表征可解释性：理解神经元/方向代表什么特征。
- 机制可解释性：还原计算图（电路），如“间接对象识别”电路。
- 对比：post-hoc（LIME/SHAP）易误导；mechanistic 追求因果忠实。

## 三、数学形式

线性表征假设：特征近似为方向 $v$，激活在 $v$ 上投影 $\langle h, v\rangle$ 表示特征强度。

## 四、代码实现

```python
feat = h @ direction_vec   # 某特征激活
```

## 五、与其他对比

- 与 卷积可视化与诊断 思路同源（可视化神经元），但面向 Transformer。
- 与 因果可解释深入 互补（因果干预验证）。

## 六、常见误区

- 单一神经元常多义（polysemantic），不能直接当特征。
- 注意力权重高 ≠ 重要（注意力数学基础 指出其可平摊）。

## 七、与开源书对应

- llm-course 可解释性：https://github.com/mlabonne/llm-course

## 八、面试题

- mechanistic 与 post-hoc 解释区别？答：前者还原内部因果电路，后者外部近似。

## 九、演进

探针 → 特征可视化 → 电路 → 稀疏自编码器解耦。

## 十、小结

机制可解释性追求忠实还原模型内部计算，是安全对齐的基础科学。
