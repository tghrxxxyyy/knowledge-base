# 幻觉机制

> 对应 幻觉与缓解深入；Maynez et al., 2020；机制可解释性视角。

## 一、背景与挑战

模型生成流畅但不实内容；需从机制层面理解其来源以根治。

## 二、核心原理

- 忠实性缺失：模型优化似然而非事实，倾向“合理但错”。
- 检索缺失：参数记忆不全，未触发正确知识方向（特征未激活）。
- 注意力/复制机制错误：过长上下文致注意力分散（Lost in the middle）。

## 三、数学形式

生成概率 $p(x_t|x_{<t})$ 最大化语料共现，而非事实真值，故似然高≠事实对。

## 四、代码实现

```python
# 检查是否触发知识方向
feat_act = h @ knowledge_direction
if feat_act < thr: warn("可能幻觉")
```

## 五、与其他对比

- 与 检索增强生成前沿 / RAG 深入 衔接（外部证据缓解）。
- 与 因果可解释深入 共享根因分析。

## 六、常见误区

- 以为更大数据必减幻觉；分布偏差仍致编造。
- 仅靠后处理过滤不够，需机制干预。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course
- 幻觉与缓解深入 提供缓解策略。

## 八、面试题

- 从机制看幻觉根源？答：优化目标=似然非事实，知识方向未稳定激活。

## 九、演进

经验缓解 → RAG/自洽 → 机制干预（激活知识方向）。

## 十、小结

幻觉根植于似然目标与知识表示不稳，机制解释指引更根本的缓解。
