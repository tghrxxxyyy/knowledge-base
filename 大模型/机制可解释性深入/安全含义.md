# 机制可解释性与安全

> 对应 安全与对齐深入 / 提示注入防御深入；可解释性赋能对齐。

## 一、背景与挑战

对齐需理解模型“为何”遵从/违背指令；可解释性提供监控与干预手段。

## 二、核心原理

- 监控：用 SAE 特征检测“欺骗/权力寻求”等危险方向。
- 干预：在推理时抑制危险特征方向（steering vectors）。
- 审计：电路分析定位越狱/注入生效路径。

## 三、数学形式

steering：$\tilde h = h + \lambda v_{safe}$，用安全方向 $v_{safe}$ 偏移激活。

## 四、代码实现

```python
h_safe = h + 3.0 * safe_direction
```

## 五、与其他对比

- 与 安全红队深入 / 越狱防御深入 互补（解释+防御）。
- 与 因果可解释深入 共享干预范式。

## 六、常见误区

- 以为可解释性即可保证安全；仍是研究前沿、非银弹。
- steering 过度可能损害能力或产生新失效模式。

## 八、面试题

- 可解释性如何助对齐？答：监测危险特征、干预激活、审计越狱路径。

## 九、演进

事后解释 → 机制监测 → 可扩展监督（宪法 AI 辅助）。

## 十、小结

机制可解释性把安全从“黑箱测试”推进到“内部监测与干预”，是长期对齐希望。
