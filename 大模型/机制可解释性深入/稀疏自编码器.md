# 稀疏自编码器

> 对应 Cunningham et al., *Sparse Autoencoders*, 2023；Huben et al., *SAE*, 2023。

## 一、背景与挑战

神经元多义（一个神经元响应多个不相关概念），难以解释；SAE 学单义特征方向。

## 二、核心原理

对激活 $h$ 训练字典 $A$（列为特征方向）与编码器 $E$：
$h \approx A E(h)$，训练加 $L_1$ 稀疏使每样本仅少数特征激活。

## 三、数学形式

$\min_{A,E} \|h - A E(h)\|^2 + \lambda \|E(h)\|_1$；特征数 $M\gg d$ 提供过完备基。

## 四、代码实现

```python
f = relu(E(h)); recon = A(f)
loss = (h - recon).pow(2).mean() + 1e-3 * f.abs().mean()
```

## 五、与其他对比

- SAE 解耦多义神经元为单义特征；代价是维度爆炸与重建误差。
- 与 嵌入几何深入 衔接（特征方向几何）。

## 六、常见误区

- 误以为 SAE 特征即“真”概念；仍是统计近似。
- 稀疏系数过高仍多义、过低欠拟合。

- 为什么 SAE 能解耦多义？答：过完备基 + L1 稀疏使单方向对应单概念。

## 十、小结

SAE 把纠缠的神经元激活分解为单义特征，是可扩展机制解释的关键工具。
