# 迭代剪枝与重训

> 对应 iterative pruning（Zhu & Gupta, 2017）。

## 一、背景与挑战

一次剪太狠难恢复，需逐步剪+短暂重训（fine-tune）稳定。

## 二、核心原理

循环：剪一小部分 → 重训若干步 → 再剪。最终稀疏度更高且精度损失小。

## 三、数学形式

每轮剪比例 $p$，总轮数 $T$，终稀疏度 $\approx 1-(1-p)^T$。

## 四、代码实现

```python
for _ in range(T):
    mask = update_mask(W, prune_ratio)
    train_one_epoch(model)
```

## 五、与其他对比

- 比一次性剪精度高；但总时间更长。
- 与 训练不稳定诊断深入 衔接（重训稳定）。

## 六、常见误区

- 剪后不重训直接部署致精度崩。
- 每轮剪太多退化为一次性。

## 八、面试题

- 为何迭代剪优于一次剪？答：逐步重训恢复被误剪的重要连接。

## 九、演进

一次性 → 迭代 → 剪枝感知训练（训练中稀疏）。

## 十、小结

迭代剪枝+重训在高压缩下保持精度，是实践标准流程。
