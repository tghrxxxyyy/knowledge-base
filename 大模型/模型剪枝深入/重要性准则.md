# 剪枝重要性准则

> 对应多种重要性度量对比。

## 一、背景与挑战

“重要”定义决定剪后质量，需选合适准则。

## 二、核心原理

常用：幅值、梯度、Hessian（二阶）、Taylor 一阶（$\Delta\mathcal L\approx g_i w_i$）、BN 缩放γ、注意力头敏感度。

## 三、数学形式

Taylor 一阶：$I_i = |w_i \cdot \nabla_{w_i}\mathcal L|$；越大越重要。

## 四、代码实现

```python
imp = (W * W.grad).abs()      # Taylor-1
```

## 五、与其他对比

- 幅值简单但对残差/批归一化不敏感；Taylor/Hessian 更准但贵。
- 与 权重初始化理论深入 衔接（初始化影响幅值分布）。

## 六、常见误区

- 单纯幅值忽略符号/梯度方向。
- 一次全局阈值忽略层间尺度差异。

## 八、面试题

- 为什么 Taylor 准则优于幅值？答：同时考虑权重与梯度，估计剪后对损失影响。

## 九、演进

幅值 → 梯度 → 二阶/Hessian → 自动化准则搜索。

## 十、小结

重要性准则是剪枝质量核心，二阶/Taylor 更准但成本更高。
