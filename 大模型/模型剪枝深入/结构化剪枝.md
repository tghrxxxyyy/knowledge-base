# 结构化剪枝

> 对应通道/头剪枝（Li et al., 2016；Michel et al., 注意力头，2019）。

## 一、背景与挑战

需在不依赖稀疏 kernel 下获得真实加速，故剪整通道/头/层。

## 二、核心原理

按通道 L1 范数、BN 缩放因子（network slimming）或头重要性定结构重要性，整块移除。

## 三、数学形式

通道剪：移除 $\arg\min_c \|W_{:,c}\|$，后续层相应删输入通道，保持形状对齐。

## 四、代码实现

```python
imp = W.abs().sum(dim=(0,2,3))      # 每通道重要性
keep = imp.topk(int(0.8*n))[1]
W = W[:, keep]
```

## 五、与其他对比

- 直接得稠密小模型，部署友好。
- 相比非结构化掉点可能更大，需更细调度。

## 六、常见误区

- 剪通道后不修正后续层输入维度致形状错误。
- 统一比例剪所有层忽略层间敏感度。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 结构化剪枝如何保形状？答：按层配对删输入/输出通道，保持张量对齐。

## 九、演进

均匀剪 → 敏感度逐层 → 自动化（神经架构搜索深入 衔接）。

## 十、小结

结构化剪枝以整块移除获得真实加速，是生产部署首选。
