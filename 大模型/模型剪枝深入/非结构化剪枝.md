# 非结构化剪枝

> 对应 Han 2015 权重剪枝。

## 一、背景与挑战

单个权重冗余多，但剪后矩阵变稀疏，通用硬件难加速。

## 二、核心原理

按权重幅值或梯度/二阶信息（如 Hessian 对角）定重要性，置零小权重。

## 三、数学形式

幅值剪枝：保留 $|W_{ij}|$ 最大的 $k\%$ 权重；二阶（OBD/OBS）用 $\Delta\mathcal L\approx \sum \frac12 H_{ii} \delta_i^2$ 选剪。

## 四、代码实现

```python
thr = torch.quantile(W.abs(), 0.9)
mask = W.abs() > thr
```

## 五、与其他对比

- 压缩率高但需稀疏库（如 cuSPARSE）才提速。
- 与 模型量化部署实战 常串联使用。

## 六、常见误区

- 以为剪完即快；无稀疏 kernel 反而更慢。
- 剪太高不重训致精度断崖。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 非结构化剪枝为何难加速？答：随机稀疏模式通用硬件不友好，需专用库。

## 九、演进

幅值剪 → 二阶信息剪 → 自动稀疏训练。

## 十、小结

非结构化剪枝压缩比高，但落地依赖稀疏计算生态。
