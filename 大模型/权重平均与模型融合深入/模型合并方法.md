# 模型合并方法（Merge / Fusion）

> 对应 Matena & Raffel, *Merging Models*, 2022；ModelSoup/TaskVector 体系。

## 一、背景与挑战

多任务各训一模型部署成本高；在权重空间合并可在单模型内融合多任务能力。

## 二、核心原理

主流：简单平均（汤）、任务向量加权和、以及基于 Fisher/参数重要性的加权（如 Fisher Merging）；亦可用 RegMean 按激活统计合并。

## 三、数学形式

Fisher 合并按对角 Fisher $F_i$ 加权各任务参数偏移：$w=\sum_i F_i \tau_i / \sum_i F_i$，重要参数获更大权重。

## 四、代码实现

```python
merged = base + sum(lam[i] * (ft[i] - base) for i in tasks)
```

## 五、与其他对比

- 与 模型汤 是合并的特例（等权）。
- 与 权重平均与模型融合深入 各节构成完整合并谱系。

## 六、常见误区

- 任务差异大时线性合并互相抵消。
- 忽视各任务数据规模对权重的影响。

## 八、面试题

- 不同合并法怎么选？答：同任务多微调用汤/平均；多任务组合用任务向量或 Fisher 加权。

## 九、演进

平均 → 任务向量 → Fisher/RegMean 加权。

## 十、小结

模型合并在权重空间融合多能力，省去多模型部署，是低成本多任务方案。
