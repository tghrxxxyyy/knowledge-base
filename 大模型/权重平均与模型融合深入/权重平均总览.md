# 权重平均总览（SWA）

> 对应 Izmailov et al., *Averaging Weights Leads to Wider Optima*, 2018（SWA）；ICLR。

## 一、背景与挑战

SGD 收敛于尖锐极小值，泛化与鲁棒性差；对训练后期权重做平均可得更宽、更平的极小值，提升泛化。

## 二、核心原理

 cyclical 学习率下，取最后若干周期（或连续步）的权重算术平均得到 SWA 模型；宽极小值对权重扰动更不敏感，泛化更好。

## 三、数学形式

SWA 权重 $\theta_{SWA}=\frac1T\sum_{t=1}^T \theta_t$；目标等价于在平坦邻域求平均解，降低泛化误差上界。

## 四、代码实现

```python
swa_model = AveragedModel(model)
for data in loader:
    train_step(); ema_sched.step(); swa_model.update_parameters(model)
```

## 五、与其他对比

- 与 EMA 类似但 SWA 在循环学习率峰谷采样，覆盖更广。
- 与 模型汤 不同：SWA 是同一训练轨迹平均，汤是跨独立训练平均。

## 六、常见误区

- 平均过早（未收敛）致偏差大。
- 学习率循环幅度不足，采样点过近无增益。

## 八、面试题

- 权重平均为何提升泛化？答：平均收敛于宽平极小值，对扰动鲁棒，泛化误差更小。

## 九、演进

末步权重 → 周期平均(SWA) → 跨初始化平均。

## 十、小结

权重平均以极低成本（仅存平均）换取更宽最优与更好泛化。
