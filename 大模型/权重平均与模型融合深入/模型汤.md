# 模型汤（Model Soups）

> 对应 Wortsman et al., *Model Soups*, 2022；CVPR。

## 一、背景与挑战

同架构不同超参/数据种子训练多个模型，逐一评估挑优成本高；直接平均权重可超过任一单模型。

## 二、核心原理

对同一预训练初始化、不同微调得到的权重做算术平均（uniform 或 greedily 加权），融合后模型在分布偏移下更鲁棒，且免额外推理成本。

## 三、数学形式

汤权重 $\theta_{soup}=\frac1K\sum_{k=1}^K \theta^{(k)}$；贪婪汤依次加入使验证损失的权重以增量提升。

## 四、代码实现

```python
soup = sum(load(f"ft_{k}.pt") for k in range(K)) / K
torch.save(soup, "soup.pt")
```

## 五、与其他对比

- 与 SWA 不同：汤跨独立微调轨迹，SWA 同轨迹。
- 与 任务算术 区别在于汤是同任务多微调平均。

## 六、常见误区

- 跨差异过大（不同数据/架构）平均致性能崩。
- 未对齐层序/词表直接相加报错或退化。

## 八、面试题

- 模型汤为何有效？答：多微调解位于同一平坦盆地附近，平均更靠中心，泛化与鲁棒性提升。

## 九、演进

单模型 → 均匀汤 → 贪婪汤 → 启发式加权。

## 十、小结

模型汤以权重平均免费提升鲁棒性，是微调后轻量融合利器。
