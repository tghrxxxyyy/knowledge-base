# 任务算术（Task Arithmetic）

> 对应 Ilharco et al., *Editing Models with Task Arithmetic*, 2023；NeurIPS。

## 一、背景与挑战

如何在不重训的前提下，给模型加/减某项能力（如去偏见、加领域知识）？任务向量提供算术语义。

## 二、核心原理

定义任务向量 $\tau=\theta_{ft}-\theta_{base}$；对预训练权重做加减法编辑：$\theta_{new}=\theta_{base}+\lambda\sum_i \tau_i$，可组合多任务、去除不良行为。

## 三、数学形式

编辑后权重 $\theta'=\theta_{pre}+\sum_i \lambda_i(\theta_{ft,i}-\theta_{pre})$；系数 $\lambda_i$ 控各任务贡献，负系数用于遗忘。

## 四、代码实现

```python
task_vec = ft_weights - base_weights
new = base_weights + lam * task_vec
```

## 五、与其他对比

- 与 模型汤 比，任务算术显式用"差向量"并支持加权/负向。
- 与 权重平均与模型融合深入 总览共享权重空间线性假设。

## 六、常见误区

- 任务向量间冲突（负迁移）需调 $\lambda$。
- 基模型与微调模型必须同源同结构。

## 八、面试题

- 任务向量为何可加减？答：微调权重偏移近似位于线性可加的子空间，加减即在能力空间做组合。

## 九、演进

单任务微调 → 任务向量 → 多向量组合/遗忘。

## 十、小结

任务算术把模型编辑变作向量运算，实现低成本能力组合与去除。
