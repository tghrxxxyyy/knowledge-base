# 指数移动平均（EMA）

> 对应 深度训练工程实践（Polyak averaging 思想）；与 在线蒸馏深入 共用。

## 一、背景与挑战

训练过程权重抖动，直接用末步权重评估/部署不稳；EMA 平滑历史权重更稳定。

## 二、核心原理

每步以系数 $\alpha$ 把新权重混入滑动平均：$\theta_{EMA}\leftarrow \alpha\theta_{EMA}+(1-\alpha)\theta$；部署与评估常用 EMA 权重，因其更平滑。

## 三、数学形式

$\theta_t^{EMA}=\alpha\,\theta_{t-1}^{EMA}+(1-\alpha)\theta_t$，典型 $\alpha\in[0.999,0.9999]$；接近 1 则更平滑更慢跟手。

## 四、代码实现

```python
for p, ema_p in zip(model.params(), ema.params()):
    ema_p.mul_(alpha).add_(p, alpha=1-alpha)
```

## 五、与其他对比

- 与 SWA 比，EMA 是单系数滑动平均，无需循环学习率。
- 与 在线蒸馏深入（教师=学生EMA）复用同一机制。

## 六、常见误区

- $\alpha$ 过接近 1 致对新收敛迟钝。
- 评估时忘记切换为 EMA 权重致结果偏差。

## 八、面试题

- EMA 为何常用于部署？答：抑制训练抖动，得到更平滑稳健的权重，评估/推理更稳。

## 九、演进

末步 → 固定窗口平均 → 指数滑动平均。

## 十、小结

EMA 以极小开销平滑权重，是训练与部署间常用桥梁。
