# 稀疏自编码器与特征解耦

> 对应 Cunningham et al., *Sparse Autoencoders Find Highly Interpretable Features*, ICLR 2024；Bricken et al., *Towards Monosemanticity*, 2023；Templeton et al., *Scaling Monosemanticity*, 2024。

## 一、背景与挑战

叠加使神经元多义，直接解释单个维度困难。稀疏自编码器（SAE）把激活重写为超完备字典上的稀疏组合，试图恢复单义特征。

## 二、核心原理

SAE 学一个远大于隐藏维度的字典，并强约束每次只激活少量原子，从而把叠加特征解包。

- 编码器给出稀疏系数，解码器用字典重构原激活；重构误差与稀疏度构成核心权衡。
- 解出的特征常具备可读语义，并可用于干预（放大/抑制某特征观察行为变化）。

## 三、数学形式

$$\min_{W_e,W_d,b}\ \mathbb{E}_x\Big[\big\lVert x-W_d f(x)\big\rVert_2^2+\lambda\big\lVert f(x)\big\rVert_1\Big],\quad f(x)=\mathrm{ReLU}\big(W_e(x-b)\big)$$

$\lambda$ 控制稀疏强度；字典规模 $m\gg d$ 提供超完备性，使叠加方向得以分离。

## 四、代码实现

```python
import torch
class SAE(torch.nn.Module):
    def __init__(self, d, m):
        super().__init__(); self.enc = torch.nn.Linear(d, m); self.dec = torch.nn.Linear(m, d, bias=False)
    def forward(self, x):
        f = torch.relu(self.enc(x)); return self.dec(f), f
sae = SAE(64, 512); xr, f = sae(torch.randn(4, 64))
print(xr.shape, float((f > 0).float().mean()))
```

## 五、与其他对比

- 与 PCA 对照：PCA 求正交低维基，SAE 求超完备稀疏基，更契合叠加假设。
- 与 残差流带宽与叠加 衔接：SAE 正是针对叠加现象设计的解包工具。

## 六、常见误区

- 只看重构损失不看特征可解释性与因果作用，得到「统计上好、解释上空」的字典。
- 忽略死特征与特征分裂问题，字典规模与稀疏系数需联合调参。

## 八、面试题

- SAE 为何要超完备？答：叠加下特征数远超维度，需更多原子才能分离出单义方向。
- 如何评估 SAE 特征质量？答：重构-稀疏权衡 + 人类可读性 + 干预因果效应三方面。

## 九、演进

多义神经元困境 → 稀疏字典学习（2023）→ 规模化与特征目录（2024）→ 特征级干预与审计。

## 十、小结

SAE 把叠加激活解包为稀疏单义特征，是当前特征级可解释性的主流路线。
