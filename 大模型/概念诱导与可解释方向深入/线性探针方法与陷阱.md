# 线性探针方法与陷阱

> 对应 Alain & Bengio, *Understanding Intermediate Layers Using Linear Classifier Probes*, 2017；Hewitt & Liang, *Designing and Interpreting Probes with Control Tasks*, EMNLP 2019。

## 一、背景与挑战

探针用简单分类器从冻结表示中预测某属性，以此判断信息「是否存在于此层」。但探针容量与数据集偏置极易让结论虚高。

## 二、核心原理

规范化的探针实验必须包含容量控制与对照任务，才能区分「表示里有信息」与「探针自己学会了」。

- 控制任务：给同样输入配随机标签，若探针仍能拟合，则说明其容量足以记忆，原结论不可信。
- 选择性指标 = 真任务精度 − 控制任务精度，用于衡量探针结论的可信度。

## 三、数学形式

探针训练 $\min_{w,b}\ \mathbb{E}\big[\ell\big(\sigma(w^\top h+b),\ y\big)\big]$；选择性 $\mathrm{Sel}=\mathrm{Acc}_{task}-\mathrm{Acc}_{control}$。

层间比较应固定探针容量与训练预算，否则曲线差异可能只反映拟合能力差异。

## 四、代码实现

```python
import torch
def train_probe(H, y, steps=200, lr=0.05):
    w = torch.zeros(H.shape[1], requires_grad=True)
    for _ in range(steps):
        loss = torch.nn.functional.binary_cross_entropy_with_logits(H @ w, y)
        loss.backward()
        with torch.no_grad():
            w -= lr * w.grad; w.grad = None
    return w.detach()
```

## 五、与其他对比

- 与因果追踪对照：探针证明可解码性，patching 证明被使用性，结论强度不同。
- 与 概念方向与线性表示假说 衔接：探针权重常被直接当作概念方向使用。

## 六、常见误区

- 用高容量非线性探针得高精度就宣称信息存在，缺少控制任务对照。
- 忽视类别不平衡与数据泄漏，探针学到的是表面统计而非目标属性。

## 八、面试题

- 控制任务的作用？答：以随机标签检测探针容量，避免把探针自身学习能力误当模型表示。
- 探针结论能否支持干预？答：不能直接支持，需用该方向做加性干预验证因果。

## 九、演进

层级探针（2017）→ 控制任务与选择性（2019）→ 探针到干预的联合验证 → 稀疏特征探针。

## 十、小结

探针是最易用也最易被误用的工具，必须报控制任务与容量设置。
