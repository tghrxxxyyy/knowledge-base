# 表示工程与激活引导

> 对应 Zou et al., *Representation Engineering*, 2023；Turner et al., *Activation Addition*, 2023；Li et al., *Inference-Time Intervention*, NeurIPS 2023。

## 一、背景与挑战

若概念以方向编码，就可以在推理时直接给激活加一个向量来控制行为，实现无需微调的即时干预。

## 二、核心原理

流程是「取对比样本 → 求差向量 → 在选定层加性注入 → 评估行为与副作用」。

- 差向量法：用正负提示对的激活均值差作为方向，简单且常有效。
- 干预需选层与选头：ITI 只在与目标属性相关的少数注意力头上注入，副作用更小。

## 三、数学形式

方向 $v=\dfrac{1}{n}\sum_i h^{+}_i-\dfrac{1}{n}\sum_i h^{-}_i$；干预 $h'=h+\alpha\,\dfrac{v}{\lVert v\rVert}$。

强度 $\alpha$ 需在效果与流畅度之间权衡：过大破坏语言建模，过小无行为改变。

## 四、代码实现

```python
import torch
def diff_direction(pos_acts, neg_acts):
    return pos_acts.mean(0) - neg_acts.mean(0)
def make_steer_hook(v, alpha):
    vn = torch.nn.functional.normalize(v, dim=-1)
    def hook(module, inp, out):
        out[0][:, -1, :] += alpha * vn
        return out
    return hook
```

## 五、与其他对比

- 与提示工程对照：激活引导直接改内部状态，控制更强但可迁移性与安全边界更需评估。
- 与微调对照：无需训练、可开关，但缺乏持久性与系统性保证。

## 六、常见误区

- 只测目标行为变化，不测通用能力与流畅度回退。
- 在所有层统一注入，导致副作用叠加；应做层与头的选择性消融。

## 八、面试题

- 激活引导如何构造方向？答：用正负对比样本的激活均值差，并归一化后按强度注入。
- 主要风险？答：副作用与能力回退，需在通用基准与流畅度指标上双向评估。

## 九、演进

概念方向发现 → 加性激活干预（2023）→ 选层选头的精细干预 → 与安全对齐结合的可控生成。

## 十、小结

激活引导把可解释方向变成可用控制手段，但必须以副作用评估为前置条件。
