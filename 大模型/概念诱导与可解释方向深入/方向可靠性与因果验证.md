# 方向可靠性与因果验证

> 对应 Marks & Tegmark, *The Geometry of Truth*, 2023；Gurnee & Tegmark, *Language Models Represent Space and Time*, ICLR 2024。

## 一、背景与挑战

同一概念用不同数据集、不同层、不同方法求出的方向可能不一致，甚至互相矛盾。方向研究因此需要一套可靠性检验。

## 二、核心原理

可靠方向应同时满足可解码、可迁移与可干预三项条件，缺一即需降低结论强度。

- 泛化检验：在训练分布外的数据集上仍能分类，排除数据集特异捷径。
- 因果检验：沿该方向干预应单调改变目标行为，且对无关任务影响小。

## 三、数学形式

一致性可用不同数据集所得方向的余弦相似度 $\cos\big(v^{(A)},v^{(B)}\big)$ 衡量；干预单调性可用 $\partial\,\mathrm{behavior}/\partial\alpha>0$ 检验。

综合可靠性可写作 $R=\min\big(\mathrm{Acc}_{ood},\ \cos\text{-consistency},\ \mathrm{CausalEffect}\big)$ 的多指标下界视角。

## 四、代码实现

```python
import torch
def direction_consistency(v_a, v_b):
    a = torch.nn.functional.normalize(v_a, dim=-1)
    b = torch.nn.functional.normalize(v_b, dim=-1)
    return round(float(a @ b), 4)
print(direction_consistency(torch.randn(32), torch.randn(32)))
```

## 五、与其他对比

- 与探针陷阱对照：控制任务解决容量问题，本节解决跨分布与因果问题。
- 与 内部状态探针检测（幻觉板块）衔接：真值方向的可靠性直接决定检测器可用性。

## 六、常见误区

- 用单一数据集求方向就宣称找到「真值方向」，跨分布往往显著退化。
- 只做单点强度干预，未验证效应随强度单调，可能是偶然扰动。

## 八、面试题

- 如何验证方向可靠？答：跨分布泛化、跨方法一致性、以及沿方向干预的单调因果效应。
- 方向不一致说明什么？答：可能存在多个相关子空间或数据集捷径，需扩大分布再检验。

## 九、演进

单数据集探针 → 跨分布一致性检验 → 干预单调性验证 → 多指标可靠性报告。

## 十、小结

概念方向要可用，必须通过解码、迁移、干预三重检验，否则只是数据集拟合产物。
