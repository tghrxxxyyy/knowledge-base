# 概念方向与线性表示假说

> 对应 Park et al., *The Linear Representation Hypothesis and the Geometry of Large Language Models*, ICML 2024；Elhage et al., *Toy Models of Superposition*, 2022。

## 一、背景与挑战

大量经验表明高层概念在表示空间中近似对应一个方向：沿该方向平移可改变模型对该概念的判断。把这一直觉形式化，是可解释方向研究的起点。

## 二、核心原理

线性表示假说主张概念以线性子空间编码，读出用投影、写入用加法，二者需在不同度量下定义才自洽。

- 读出方向（measurement）与写入方向（intervention）不一定相同，需用因果内积统一。
- 概念方向的存在性与叠加理论相容：稀疏特征以近似正交方向共存，因此单方向可近似隔离一个概念。

## 三、数学形式

概念 $c$ 的读出可写作 $s_c(x)=\langle w_c,\ h(x)\rangle$；干预写作 $h'=h+\alpha\,v_c$，$\alpha$ 控制强度。

在因果内积下 $\langle w_c, v_{c'}\rangle \approx \delta_{cc'}$，即读出方向与非目标概念的写入方向近似正交，从而干预不串扰。

## 四、代码实现

```python
import torch
def steer(h, v_c, alpha=1.0):
    return h + alpha * torch.nn.functional.normalize(v_c, dim=-1)
def readout(h, w_c):
    return float(h @ torch.nn.functional.normalize(w_c, dim=-1))
h = torch.randn(16); v = torch.randn(16)
print(readout(steer(h, v, 2.0), v) - readout(h, v))
```

## 五、与其他对比

- 与非线性探针对照：线性方向可干预、可组合，非线性探针表达力强但难以转成干预。
- 与 稀疏自编码器与特征解耦 衔接：SAE 可视为自动寻找大量单义方向的手段。

## 六、常见误区

- 把「能线性解码」等同于「模型线性使用」；需干预验证方向是否被下游读取。
- 混用读出与写入方向，导致干预串扰到相关概念。

## 八、面试题

- 线性表示假说说什么？答：概念近似以方向/子空间编码，读出用投影、写入用加法。
- 为何要区分读出与写入方向？答：二者在不同度量下定义，混用会导致干预串扰与解释错误。

## 九、演进

词向量类比现象 → 叠加理论（2022）→ 因果内积的形式化（2024）→ 面向干预的方向工程。

## 十、小结

概念方向是可解释性中最实用的抽象，但必须区分解码方向与因果干预方向。
