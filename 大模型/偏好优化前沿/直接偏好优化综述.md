# 直接偏好优化综述

> 见「微调与对齐/DPO原理与实现」与「偏好优化前沿/RRHF与多目标对齐」。

## 一、背景与挑战

DPO 已成最简对齐范式，但其变体众多，需系统认识。

## 二、核心原理

DPO 把「奖励模型+PPO」合并为单阶段分类式损失，直接拉大偏好对概率差；衍生 IPO（防过拟合）、KTO（仅需好坏信号）、ORPO（免参考模型）。

## 三、数学形式

DPO 损失：

```
L = -log σ(β log(π(y_w)/π_ref(y_w)) - β log(π(y_l)/π_ref(y_l)))
```

## 四、代码实现

```python
loss = -F.logsigmoid(beta*(logp_w - ref_w - logp_l + ref_l)).mean()
```

## 五、关键要点

- 省去独立奖励模型与强化循环。
- β 控制偏离参考强度。

## 六、与其他对比

| 方法 | 需奖励模型 | 需参考 |
|------|-----------|--------|
| PPO | 是 | 是 |
| DPO | 否 | 是 |
| KTO | 否 | 是 |
| ORPO | 否 | 否 |

## 七、常见误区

- DPO 不需要任何参考——仍依赖参考模型防崩。
