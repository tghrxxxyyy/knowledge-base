# 知识评测基准

> 对应 Hendrycks et al., *Measuring Massive Multitask Language Understanding* (MMLU), 2021；C-Eval（Huang et al., 2023）、CMMLU（Li et al., 2023）、TruthfulQA（Lin et al., 2022）；参考 HuggingFace 基准集。

## 一、背景与挑战

衡量模型「知道多少」依赖知识类基准，覆盖学科广度、中文知识与事实真实性。核心挑战是**数据污染**：预训练语料常包含这些公开测试题，模型可能「背答案」而非「真理解」，导致分数虚高。此外英文基准无法直接反映中文世界知识，需本地化。如何区分「记忆」与「能力」、如何保证测试集未泄漏，是知识评测的首要问题。

## 二、核心原理

知识基准多为**多选题**（4 选 1），覆盖从小学到专业级学科：MMLU 含 57 个学科（数学、法律、医学等）共约 1.4 万题；C-Eval/CMMLU 聚焦中文考试与多学科；AGIEval 用人类统考（高考、法考、SAT）测「类人考试力」；TruthfulQA 专门测**真实性**——区分「常见误解」与「真实事实」，模型易因习得网络流行谬误而答错。评测常采用 0-shot / few-shot 与 CoT，并做去污染（n-gram/嵌入相似度比对训练语料）。

## 三、形式化与数学基础

多选题准确率：样本 $(q, \{c_1,\dots,c_4\}, y^\star)$，模型选 $\hat y$：

$$\text{Acc} = \frac{1}{N}\sum_{i=1}^{N} \mathbf{1}(\hat y_i = y_i^\star)$$

随机基线为 $1/4=25\%$。去污染用 $n$-gram 重叠率：

$$\rho = \max_{s\in\text{train}}\ \text{overlap}_n(q\oplus y^\star,\ s)$$

若 $\rho>\tau$ 标记污染。TruthfulQA 同时报准确率与「真实率」（truthful%），后者惩罚虽对但靠谬误的回答。CoT 下还需解析「\boxed{}」或末选项以保证可比。

## 四、代码实现

```python
from lm_eval import simple_evaluate
from lm_eval.models.huggingface import HFLM

model = HFLM(pretrained="meta-llama/Llama-3-8B")
results = simple_evaluate(
    model, tasks=["mmlu", "truthfulqa_mc", "cmmlu"],
    num_fewshot=5,
)
print(results["results"])
```

`lm-eval-harness` 统一处理 few-shot 模板、去污染与计分，是社区标准工具。

## 六、常见误区

- 多选题分数高=能力强：可能是污染/记忆，需去污染与 few-shot 对照。
- 忽视中文本地化：英文集测不出中文知识短板。
- 只看准确率不看真实率：TruthfulQA 中「看似对」可能基于谬误。
- 直接用训练语料含的题：必须剔除或隔离。

## 八、面试题

1. 为何知识基准要特别关注数据污染？答：公开题易进训练集，分数虚高，需去污染区分记忆与能力。
2. TruthfulQA 测什么？答：真实性，惩罚基于流行谬误的「看似正确」回答。
3. 中文场景为何用 C-Eval/CMMLU？答：覆盖中文考试与学科知识，避免英文偏差。

## 九、演进与趋势

知识评测从静态多选走向动态、防泄漏（如 MMLU-Pro 增干扰项、LiveBench 用新题）、以及「知识 + 推理」融合评测；中文生态持续补全本地化基准并加强污染检测。

## 十、小结

知识评测基准用多选题量化模型学科广度与真实性，但分数受污染影响大。务必做去污染、用本地化集、并区分准确率与真实率，才能真实反映模型的「知识水位」。
