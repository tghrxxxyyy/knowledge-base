# 长上下文基准

> 对应 *Needle In A Haystack*（Greg Kamradt, 2023）、LongBench（Bai et al., 2023）、∞-Bench（Zhang et al., 2024）；参考 llm-course 长上下文评测章节。

## 一、背景与挑战

标称「支持 32K / 128K / 1M token」的模型，未必真能在任意长度、任意位置精准使用信息。朴素「长文问答」容易靠先验知识蒙混，无法验证模型是否真正读完了整段上下文。评测的核心挑战是：在可控方式下把关键信息埋入长文本，并监测系统对**不同位置、不同长度**信息的召回能力，避免被「标题党式」长度宣传误导。

## 二、核心原理

主流范式是**「大海捞针」（Needle-In-A-Haystack, NIAH）**：构造一段超长 filler 文本（如多篇无关文章拼成），在其中某处插入一句关键事实（「针」），再提问该事实。模型必须定位并回答。系统扫描两个维度：上下文长度（如 1K→128K）与针的位置（头/中/尾/随机）。聚合得到「准确率热力图」，能直观暴露模型的退化区。更贴近真实的则用多任务长文基准（LongBench 含摘要、检索、Few-shot 等）与超长多模态/多语言基准（∞-Bench）。

## 三、形式化与数学基础

设上下文长度集合 $\mathcal{L}$，位置比例 $p\in[0,1]$。对给定 $(L,p)$ 投放针并提问，模型输出 $\hat y$：

$$\text{Acc}(L,p)=\mathbb{E}_{q}\big[\mathbf{1}(\hat y = y^{\star})\big]$$

整体有效长度定义为在阈值 $\alpha$（如 0.9 准确率）下可达的最大长度：

$$L_{\text{eff}} = \max\{L\in\mathcal{L} : \min_p \text{Acc}(L,p) \ge \alpha\}$$

「Lost in the middle」现象即中间 $p\in(0.2,0.8)$ 区间 $\text{Acc}$ 显著低于头尾。

## 四、代码实现

```python
import random

def make_haystack(n_tokens: int, needle: str, position: float):
    filler = "..." * n_tokens           # 占位长文
    idx = int(len(filler) * position)
    return filler[:idx] + "\n" + needle + "\n" + filler[idx:]

def eval_niah(model, lengths, positions, needle_qa):
    for L in lengths:
        for p in positions:
            text = make_haystack(L, needle_qa["needle"], p)
            ans = model.chat(text + "\n" + needle_qa["q"])
            yield L, p, needle_qa["a"] in ans
```

生产评测用 NIAH 框架批量生成矩阵并绘热力图（横轴长度、纵轴位置）。

## 五、与其他基准对比

| 基准 | 任务 | 长度 | 特点 |
|---|---|---|---|
| NIAH | 检索单事实 | 可调 | 位置敏感、直观 |
| LongBench | 多任务长文 | 至 32K | 贴近真实 |
| ∞-Bench | 超长多任务 | 100K+ | 中文/代码 |
| RULER | 合成多能力 | 至 128K | 抗记忆 |

## 六、常见误区

- 只看头尾不测中部：中间常是最弱区（lost in the middle），漏测会高估能力。
- 以为标称长度=有效长度：实际有效长度常明显更短。
- 用模型已知事实当针：测的是记忆而非检索，应随机/虚构。
- 单点采样：需矩阵扫描才可靠。

## 八、面试题

1. 为何长上下文基准要测不同位置信息？答：暴露 lost-in-the-middle，验证任意位置召回而非仅头尾。
2. 有效长度如何定义？答：在指定准确率阈值下模型可达的最大上下文长度。
3. NIAH 的针为何要虚构？答：避免模型靠预训练记忆回答，确保测的是检索。

## 九、演进与趋势

从单点 NIAH 到 RULER（多能力合成）、到 ∞-Bench 超长多语言基准，评测维度从「能否找到」走向「能否聚合/推理长程多事实」。未来将更强调多针、噪声干扰与真实长文档任务。

## 十、小结

长上下文基准用可控的「捞针」矩阵与多任务长文集，揭示模型在长度与位置两个维度上的真实能力。它提醒我们：标称窗口长度 ≠ 有效可用长度，中部信息召回是核心短板。
