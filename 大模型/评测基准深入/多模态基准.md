# 多模态评测基准

> 对应 MMBench（Liu et al., 2023）、MME（Fu et al., 2023）、MMMU（Yue et al., 2023）、DocVQA（Mathew et al., 2021）、MathVista（Lu et al., 2023）；参考 LlamaIndex 多模态检索评估。

## 一、背景与挑战

多模态大模型（VLM）需同时理解图像与文本，能力涵盖感知（识别物体/属性）、OCR、图表理解、跨模态推理。评测挑战在于：纯语言基准无法覆盖视觉；不同任务难度跨度大；且 VLM 易出现**幻觉**（描述图中不存在之物）。如何系统、可复现地量化「看懂图」的能力，并区分感知与高阶推理，是构建基准的核心问题。

## 二、核心原理

多模态基准按能力分层：(1) **感知与基础**：MME、MMBench 用多选题覆盖存在性、计数、颜色、OCR 等；(2) **学科/文档推理**：MMMU 用大学级多学科图文题、DocVQA 用文档扫描图问答、MathVista 用含图数学题；(3) **幻觉评测**：POPE、HallusionBench 用正负样本测模型是否「无中生有」。通常采用封闭选择题 + LLM/人工裁判，或开放生成 + GPT-4 评判，并报告分项雷达图以定位弱项。

## 三、形式化与数学基础

以多选题准确率为主，设样本集 $\mathcal{D}$，模型对图 $I$、题 $q$ 输出选项 $\hat y$：

$$\text{Acc} = \frac{1}{|\mathcal{D}|}\sum_{(I,q,y^\star)\in\mathcal{D}} \mathbf{1}(\hat y = y^\star)$$

幻觉率（如 POPE 二元「图中是否有 X」）用准确率与 F1 衡量正负平衡：

$$\text{F1} = \frac{2PR}{P+R},\quad P=\frac{TP}{TP+FP},\ R=\frac{TP}{TP+FN}$$

开放生成评测常用 LLM-as-judge 给分 $s\in[0,1]$，再求均值；需做人类对齐校验防止裁判偏差。

## 四、代码实现

```python
from datasets import load_dataset

ds = load_dataset("mmmu/MMMU", "all")["validation"]
correct = 0
for item in ds:
    prompt = item["question"]
    img = item["image"]
    ans = vlm.generate(image=img, text=prompt)
    correct += ans.strip().lower() == item["answer"].strip().lower()

print("MMMU acc:", correct / len(ds))
```

工程上常用 VLMEvalKit 统一跑 MMBench/MME/MMMU 并产出分项报告。

## 五、与其他基准对比

## 六、常见误区

- 只报总准确率：掩盖感知强、推理弱的分项差距，应看雷达图。
- 忽视幻觉：高分不一定「诚实」，需 POPE 类测试。
- 中文多模态直接套英文集：需 CMMMU/CMMMU 等本地化基准。
- 用 GPT-4 当裁判无校准：裁判偏好需人工验证。

## 八、面试题

1. 多模态基准为何要测幻觉？答：VLM 易描述图中不存在内容，幻觉率直接关系可信度。
2. MMMU 与 MMBench 区别？答：前者大学级多学科推理、难；后者基础感知全覆盖。
3. 中文场景为何需本地化基准？答：英文集文化/语言偏差大，需 CMMMU 等。

## 九、演进与趋势

从静态图文选择题走向视频、具身、GUI 操作（如 ScreenSpot）、以及「图文+工具」的 agentic 评测；评测方式也从规则匹配转向更稳健的 LLM/多模态裁判与人工对齐。

## 十、小结

多模态基准以分层能力（感知→文档→学科推理→幻觉）系统量化 VLM「看懂图」的水平。构建与选型时应兼顾分项雷达、本地化与幻觉评测，避免被总分掩盖真实短板。
