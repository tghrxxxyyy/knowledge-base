# 对齐与偏好基准

> 对应 Ouyang et al., *InstructGPT / RLHF*（2022）；MT-Bench（Zheng et al., 2023）；AlpacaEval（Dubois et al., 2023）；Chatbot Arena / LMSYS（Chiang et al., 2024）；参考 HHH 原则（Askell et al., 2021）。

## 一、背景与挑战

对齐（Alignment）关注模型是否「有用、无害、诚实」（HHH，Askell et al.）。这与知识/推理基准不同：答案没有唯一标准，需判断「哪个回复更好、更安全」。挑战在于：(1) 偏好主观、维度多（质量、安全、格式）；(2) 人工标注贵且慢；(3) LLM 当裁判有偏差（位置偏好、长度偏好、自家模型偏袒）。基准因此混合「多轮对话质量」「指令遵循」「人类投票 Elo」等多视角。

## 二、核心原理

对齐基准分三类：(1) **多轮对话**：MT-Bench 用 80 个两轮问题（写作、推理、编程等），由 GPT-4 当裁判打 1–10 分，测模型在多轮上下文中的稳定与遵循；(2) **指令遵循**：AlpacaEval 用 805 条指令，比较模型与参考模型（如 GPT-4）的胜率（LC win rate），用 LLM 裁判自动化；(3) **人类投票**：Chatbot Arena 让真实用户盲选两个匿名模型回复，用 **Bradley-Terry Elo** 排全局分。HHH 框架则把「有帮助/无害/诚实」拆成可评维度。

## 三、形式化与数学基础

Elo（Bradley-Terry）模型：模型 $A$ 胜 $B$ 的概率

$$P(A\succ B)=\frac{1}{1+10^{(R_B-R_A)/400}}$$

赛后更新：$R_A' = R_A + K(S_A - E_A)$，其中 $S_A\in\{0,1\}$ 为实际胜、平计 0.5，$E_A=P(A\succ B)$。AlpacaEval 胜率：

$$\text{WinRate} = \frac{1}{N}\sum_{i=1}^{N} \mathbf{1}(\text{judge prefers model over ref on } i)$$

MT-Bench 用两轮平均分并报告「两轮一致性」以检测上下文退化。LLM 裁判需扣除长度/位置偏差，常做 calibration 对照人工标注。

## 四、代码实现

```python
from alpaca_eval import evaluate as alpaca_eval

results = alpaca_eval(
    model_outputs=my_model_responses,     # 与参考同指令集
    reference_outputs="gpt4",             # 基线
    annotators_config="weighted_alpaca_eval_gpt4_turbo",
)
print("length-controlled win rate:", results["win_rate"])
```

MT-Bench 用 `llm_judge` 调用 GPT-4 对每轮打分，再聚合成总分与两轮一致性。

## 五、与其他基准对比

| 基准 | 维度 | 裁判 | 成本 |
|---|---|---|---|
| MT-Bench | 多轮质量 | GPT-4 | 中 |
| AlpacaEval | 指令遵循 | LLM | 低 |
| Chatbot Arena | 真实偏好 | 人类 | 高 |
| HHH | 三原则 | 人工/LLM | 中 |

## 六、常见误区

- 认为 Arena 准确率可替细分：Arena 偏真实但维度粗，需 MT-Bench 补细节。
- 盲信 LLM 裁判：长度/位置偏差需校准，否则偏袒长回复。
- 只测有用忽略无害：安全对齐缺失在部署中更致命。
- 用自家模型当裁判无对照：明显自家偏袒，须独立裁判。

## 八、面试题

1. 为何 Chatbot Arena 用 Elo 而非准确率？答：偏好是相对的，Elo 用大量成对比较排全局分，比单点准确率稳。
2. LLM 裁判为何需校准？答：存在长度/位置偏差与自家偏袒，须对照人工修正。
3. HHH 是什么？答：有用(Helpful)、无害(Harmless)、诚实(Honest)三大对齐维度。

## 九、演进与趋势

对齐评测从静态指令走向「安全红队」（自动对抗攻击）、多语言/多文化对齐、以及过程级偏好（不止终态）。Arena 也衍生 Arena-Hard 等更可控变体，减少噪声与刷分。

## 十、小结

对齐基准衡量模型「是否让人满意且安全」，融合多轮质量（MT-Bench）、指令遵循（AlpacaEval）与人类偏好（Arena Elo）。理解 LLM 裁判的偏差与 HHH 维度，才能客观看待模型的对齐水平。
