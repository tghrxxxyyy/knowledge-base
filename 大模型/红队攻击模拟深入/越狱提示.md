# 越狱提示（Jailbreak）

> 对应 Shen et al., *Jailbreak ChatGPT*, 2023；系统梳理越狱模板。

## 一、背景与挑战

用户用特定话术使模型绕过安全策略产出违禁内容。

## 二、核心原理

常见手法：角色扮演、虚构前提、拆分请求、载荷注入、多语/编码绕检测。

## 三、数学形式

绕过概率近似 $P_{break}=P(f(x')\text{unsafe}|x'=J(x))$，J 为越狱变换。

## 四、代码实现

```python
jail = template.format(payload=harmful_req)
out = target(jail)
```

## 五、与其他对比

- 与 角色与人格对齐深入（角色越狱）共享。
- 与 安全分类器深入（检测越狱）对照。

## 六、常见误区

- 仅防已知模板（新变体层出不穷）。
- 忽视间接/文档内注入。
