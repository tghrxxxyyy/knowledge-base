# 红队评估指标

> 对应攻击成功率（ASR）等；模型评测指标深入 衔接。

## 一、背景与挑战

红队产出需量化，比较不同版本模型 robustness。

## 二、核心原理

用攻击成功率 ASR、覆盖率、危害等级分布；结合 LLM/人工判越界。

## 三、数学形式

$ASR=\frac{\#unsafe}{\#attack}$；越界由 judge 判定 $j(x,out)$。

## 四、代码实现

```python
asr = mean(1 - safe(out) for out in run(attacks))
```

## 五、与其他对比

- 与 模型评测指标深入（通用指标）共享。
- 与 安全分类器误判深入（阈值）对照。

## 六、常见误区

- judge 自带偏置致 ASR 不准。
- 只报 ASR 忽略危害严重度。

## 七、与开源书对应

## 八、面试题

- 如何量化红队效果？答：攻击成功率 ASR+危害分级，配合 judge 判越界。

## 九、演进

人工计数 → ASR → 多维危害度量。

## 十、小结

红队评估靠 ASR 与危害分级，指导安全迭代。
