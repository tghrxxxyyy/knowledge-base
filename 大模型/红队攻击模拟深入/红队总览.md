# 红队攻击模拟总览

> 对应 Ganguli et al., *Red Teaming Language Models*, 2022；系统性发现模型漏洞。

## 一、背景与挑战

模型上线前需主动找失败模式（有害/偏见/泄漏），仅靠评估难覆盖。

## 二、核心原理

红队＝对抗性测试：人工或模型生成攻击提示，试探模型边界，记录失败以改进。

## 三、数学形式

攻击目标：找 $x$ 使 $f(x)\notin \text{Safe}$，覆盖率度量发现比例。

## 四、代码实现

```python
for attack in attacks:
    if not safe(model(attack)): log_failure(attack)
```

## 五、与其他对比

- 与 安全分类器深入（红队测其漏放）衔接。
- 与 角色注入攻击深入（一类攻击）共享。

## 六、常见误区

- 红队只跑一次（需持续）。
- 只测显式有害忽略隐性偏见。

## 八、面试题

- 红队是什么？答：对抗式主动找模型失败/有害模式，用于改进安全。

## 九、演进

人工红队 → 模型红队 → 自动化闭环。

## 十、小结

红队是发现模型风险的核心手段，须持续与多样。
