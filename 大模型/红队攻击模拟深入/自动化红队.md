# 自动化红队

> 对应 Perez et al., *Red Teaming Language Models with Language Models*, 2022；用模型生攻击。

## 一、背景与挑战

人工红队成本高、覆盖有限；用红队模型自动生成多样攻击。

## 二、核心原理

训练/提示一个攻击模型，针对目标模型生成对抗提示，再以是否越界为奖励迭代。

## 三、数学形式

目标 $\max_{x\sim g_\phi} \mathbb 1(f_\theta(x)\text{ unsafe})$，用强化/搜索优化 $g$。

## 四、代码实现

```python
attacks = red_model.generate(target_desc, n=50)
for a in attacks: test(target, a)
```

## 五、与其他对比

- 与 模型提取攻击深入（不同目标）区分。
- 与 红队评估指标深入（成功率）衔接。

## 六、常见误区

- 攻击模型过拟合目标模型。
- 自动生成攻击含有害样本需隔离。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course
- dair-ai/Prompt-Engineering-Guide：https://github.com/dair-ai/Prompt-Engineering-Guide

## 八、面试题

- 自动红队如何工作？答：用攻击模型生成对抗提示，以越界为信号迭代搜索漏洞。

## 九、演进

随机采样 → 模型生成 → 强化搜索。

## 十、小结

自动化红队以模型攻模型，规模化发现漏洞。
