# 学习率调度与泛化关系

> 对应 d2l-ai/d2l-zh 学习率与泛化讨论；Smith & Topin, *Super-Convergence* (2017) 关于噪声与泛化。

## 一、背景与挑战

学习率（LR）不仅是优化速度的旋钮，更深刻影响最终解的「形状」与泛化能力。固定 LR 难以兼顾前期的充分探索与末期的精细收敛；调度曲线的形态决定了优化噪声在时间轴上的分布，从而间接塑造损失 landscape 中解的平坦度。实践中常出现「训练 loss 很低但验证很差」，这往往与 LR 调度末段设计不当有关。

## 二、核心原理

较大 LR 在 SGD 更新中引入优化噪声，有助于逃离尖锐极小、收敛到更平坦的解（flat minima 通常泛化更好）；过小 LR 易陷局部且训练缓慢。调度的作用，是在训练初期保留较大噪声以探索，在末期降低噪声以稳定收敛到平坦区。warmup 与退火共同实现「先探索、后收敛」的噪声轮廓。值得强调：泛化不是 LR 的副产物，而是其直接塑造的对象。

## 三、形式化与数学基础

将带动量的 SGD 更新视为带噪声的离散动力系统：

$$\theta_{t+1}=\theta_t-\eta_t\big(\nabla L(\theta_t)+\xi_t\big)$$

其中 $\xi_t$ 为梯度噪声（含 mini-batch 抽样方差）。LR 调度即噪声方差 $\eta_t^2\sigma^2$ 的时间轮廓：

$$V_t = \eta_t^2\,\mathbb{E}\lVert\xi_t\rVert^2$$

理论表明，解的尖锐度（Hessian 最大特征值 $\lambda_{\max}$）与末期噪声负相关——退火使 $\eta_T\to 0$，末期 $V_T$ 极小，参数停留在平坦盆地。平坦解对参数扰动更鲁棒，故在未见数据上表现更稳定。

## 四、代码实现

```python
import math

# 不同调度下观察最终解的平坦度（示意实验骨架）
def lr_cos(t, T, lr_max=3e-4, lr_min=3e-5):
    return lr_min + 0.5 * (lr_max - lr_min) * (1 + math.cos(math.pi * t / T))

def lr_const(t, T, lr=3e-4):
    return lr

def sharpness(model, eps=1e-3):
    # 邻域敏感度近似尖锐度：扰动后 loss 变化
    base = loss(model)
    return abs(loss(perturb(model, eps)) - base)

# 对比不同调度在验证集上的泛化与尖锐度
for sched in [lr_cos, lr_const]:
    run_training(sched, track_fn=sharpness)   # 记录 val_loss 与尖锐度
```

## 五、与其他技术对比

| 调度 | 噪声轮廓 | 探索性 | 末期收敛 | 泛化倾向 |
| --- | --- | --- | --- | --- |
| 恒定 LR | 不变 | 中 | 弱 | 易陷局部 |
| 阶梯衰减 | 突变 | 低 | 中 | 中 |
| 余弦退火 | 平滑递减 | 高→低 | 强 | 平缓解优 |
| 循环 LR | 周期波动 | 持续 | 中 | 易逃盆地 |

## 六、常见误区

误区一：只追求训练 loss 最低而用极小 LR 收尾——可能得到尖锐解、验证泛化差。误区二：认为 LR 只影响速度——它实质是隐式正则。误区三：忽视 warmup 与退火的配合，单调降 LR 前期反而不稳。误区四：把验证集最优 LR 当作训练全程最优——调度形状同样关键。

## 九、演进与趋势

LR 噪声注入与显式正则（如 SAM 寻找平坦极小）结合；根据验证指标动态调节噪声的「自适应退火」是研究热点；与数据课程联合优化以兼顾收敛与泛化。

### 实践速查

- 默认：大模型预训练优先 cosine + warmup，而非恒定或阶梯衰减。
- 末段：保留非零 $\eta_{\min}$（如峰值 1/10）避免末期更新完全停滞。
- 噪声：warmup 控制初期探索，退火控制末期收敛，二者共同塑形噪声。
- 监控：训练中应跟踪邻域敏感度，判断最终解是否过于尖锐。
- 关联：调度与数据课程、正则相互配合，单看 LR 不够。
- 实验：换调度做对照实验，验证对验证集而非仅训练集的收益。

### 常见问题

- 问：只降 LR 能否提升泛化？答：能，但形状与末值同样关键。
- 问：平坦解为啥泛化好？答：对参数扰动更鲁棒，未见数据上更稳定。

### 关键记忆点

- LR 调度是隐式正则，决定优化噪声的时间分布与解的平坦度。
- 末期平滑退火 + 适中 $\eta_{\min}$ 最利于泛化。
- 看泛化要看验证集而非仅训练 loss 最低。

## 十、小结

调度曲线是隐式正则器，设计时需同时兼顾收敛速度与解的平坦度，而非仅看训练 loss 是否够低。
