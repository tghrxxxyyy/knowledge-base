# 学习率调度与泛化关系

> 对应 d2l-ai/d2l-zh 与 huggingface/transformers 训练脚本经验。

## 一、背景与挑战
学习率不仅是优化速度旋钮，更深刻影响最终解的锐利度与泛化能力。

## 二、核心原理
较大 lr 引入优化噪声，有助逃离尖锐极小、找到平坦解（better generalization）；过小 lr 易陷局部。调度曲线决定噪声的时间分布。

## 三、形式化与数学基础
可将 SGD 更新视作带噪声的离散动力：`θ_{t+1}=θ_t-η(∇L+ξ_t)`，ξ_t 为梯度噪声。lr 调度即噪声方差 `η²σ²` 的时间轮廓。

## 四、代码实现
```python
# 观察不同调度下最终loss的平坦度（示意）
for sched in ["cosine", "linear", "constant"]:
    run_training(sched)   # 记录 val_loss 与邻域敏感度
```

## 五、与其他技术对比
恒定 lr 难以兼顾前期探索与末期收敛；退火式调度在末期降低噪声，收敛到更优平坦区。

## 六、常见误区
只追求训练 loss 最低而用极小 lr 收尾，可能得到尖锐解、验证泛化差。

## 七、与开源书/权威来源对应
d2l-ai/d2l-zh 讨论 lr 与泛化；huggingface/transformers 默认 cosine+warmup。

## 八、面试题
问：lr 调度如何影响泛化？答：通过控制优化噪声时间分布，影响解的平坦度。

## 九、演进与趋势
噪声注入、 cyclical lr 与泛化理论结合是活跃方向。

## 十、小结
调度曲线是隐式正则，设计时需兼顾收敛与泛化。
