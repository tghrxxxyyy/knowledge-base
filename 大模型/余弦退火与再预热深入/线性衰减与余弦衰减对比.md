# 线性衰减与余弦衰减对比

> 对应 d2l-ai/d2l-zh 学习率调度对比与 huggingface/transformers 调度器。

## 一、背景与挑战
选择调度形状影响收敛速度与最终精度，需在实现成本与效果间权衡。

## 二、核心原理
线性衰减以恒定速率下降；余弦衰减在两端慢、中间快，末期更平滑。大模型实践中余弦通常略优。

## 三、形式化与数学基础
线性：`η_t = η_max - (η_max-η_min)·t/T`。余弦：`η_t = η_min + 0.5(η_max-η_min)(1+cos(πt/T))`。

## 四、代码实现
```python
def linear_lr(t, T, lr_max, lr_min):
    return lr_max - (lr_max - lr_min) * t / T

def cosine_lr(t, T, lr_max, lr_min):
    return lr_min + 0.5 * (lr_max - lr_min) * (1 + math.cos(math.pi * t / T))
```

## 五、与其他技术对比
阶梯衰减易实现但粗糙；余弦平滑且泛化好；线性介于两者之间，适合短训练。

## 六、常见误区
认为形状差异无足轻重；在大模型长周期训练中，末期 lr 曲线形状对最终 loss 有可测影响。

## 七、与开源书/权威来源对应
d2l-ai/d2l-zh 给出三种曲线对比；huggingface/transformers 提供 `CosineAnnealing`、`Linear` 等调度。

## 八、面试题
问：余弦相对线性的优势？答：初期与末期更平缓，利于稳定与精细收敛。

## 九、演进与趋势
调度形状正与数据课程、阶段权重联合设计。

## 十、小结
余弦衰减因平滑特性成为大模型主流，线性适合轻量场景。
