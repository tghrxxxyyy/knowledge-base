# 多阶段学习率调度策略

> 对应 microsoft/DeepSpeed 调度配置与 karpathy/nanoGPT 的迭代式 lr。

## 一、背景与挑战
大模型常经历多阶段训练：预训练、继续预训练、领域适配、指令微调，每阶段数据分布与目标不同，需不同 lr 轮廓。

## 二、核心原理
每个阶段独立设定 warmup、峰值 lr、衰减形状，阶段间可重置或继承优化器状态。继续预训练常重新 warmup 到较低峰值。

## 三、形式化与数学基础
阶段 k 的 lr：`η^{(k)}_t = f_k(t; η^{(k)}_max, η^{(k)}_min, T_k)`，f_k 可为余弦或线性，跨阶段不连续切换。

## 四、代码实现
```python
# DeepSpeed 风格多阶段（示意）
sched = {
  "scheduler": {
    "type": "WarmupCosineDecay",
    "params": {"warmup_min_lr": 0, "warmup_max_lr": 3e-4,
               "warmup_num_steps": 2000, "total_num_steps": 100000}
  }
}
```

## 五、与其他技术对比
单一全局调度简单但僵化；多阶段灵活但需更多工程与调参。

## 六、常见误区
阶段切换时未重置 warmup，导致新数据上 lr 过低、学习缓慢。

## 七、与开源书/权威来源对应
microsoft/DeepSpeed 文档提供丰富的 lr 调度配置；karpathy/nanoGPT 中 lr 由 step 函数定义。

## 八、面试题
问：继续预训练为何要重新 warmup？答：数据分布变化，需重新稳定优化轨迹。

## 九、演进与趋势
根据验证指标动态切换阶段的自适应调度正在探索。

## 十、小结
多阶段调度让大模型在不同训练目标间平滑过渡。
