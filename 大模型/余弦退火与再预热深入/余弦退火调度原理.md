# 余弦退火调度原理

> 对应 karpathy/nanoGPT 余弦学习率与 d2l-ai/d2l-zh 学习率调度章节。

## 一、背景与挑战
固定学习率易在损失盆地边缘振荡；阶梯衰减需手工设里程碑。余弦退火以平滑曲线在训练末期把 lr 压到很低，利于精细收敛。

## 二、核心原理
lr 随步数按余弦从 η_max 降到 η_min，形如半周期余弦，前期下降慢、后期趋零，匹配训练由粗到精的需求。

## 三、形式化与数学基础
$ \eta_t = \eta_{min} + \frac{1}{2}(\eta_{max}-\eta_{min})\big(1+\cos(\frac{\pi t}{T})\big) $

其中 T 为总步数，t 为当前步。

## 四、代码实现
```python
import math
def cosine_lr(t, T, lr_max=3e-4, lr_min=3e-5):
    return lr_min + 0.5 * (lr_max - lr_min) * (1 + math.cos(math.pi * t / T))
# t=0 -> lr_max ; t=T -> lr_min
```

## 五、与其他技术对比
阶梯衰减突然跳变，可能破坏收敛轨迹；线性衰减末段下降过快；余弦在末期最平滑，泛化常更好。

## 六、常见误区
把 T 设成 epoch 数而非优化步数，导致 lr 下降节奏与 batch 不匹配。

## 七、与开源书/权威来源对应
karpathy/nanoGPT 使用 `get_lr` 余弦函数；d2l-ai/d2l-zh 第 11 章讲解学习率调度。

## 八、面试题
问：余弦退火为何末期 lr 趋零？答：cos 在 π 处为 -1，使 lr 落到 η_min，精细收敛。

## 九、演进与趋势
余弦 + warmup 已成为大模型预训练标配组合。

## 十、小结
余弦退火以平滑衰减提升末期收敛质量，是大模型训练的默认选择。
