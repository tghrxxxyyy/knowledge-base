# 余弦退火调度原理

> 对应 Loshchilov & Hutter, *SGDR: Stochastic Gradient Descent with Warm Restarts* (2017) 中的余弦衰减；karpathy/nanoGPT `get_lr` 实现；d2l-ai/d2l-zh 学习率调度章节。

## 一、背景与挑战

固定学习率易在损失盆地边缘振荡、难以下探；手工设定的阶梯衰减需要反复调试里程碑，且跳变会破坏收敛轨迹。我们需要一种「平滑、自动、末期趋零」的衰减曲线，匹配训练由粗到精的自然需求。余弦退火正是这一需求的经典答案，已成为大模型预训练的事实标准。

## 二、核心原理

余弦退火（Cosine Annealing）让 LR 随步数按余弦从 $\eta_{\max}$ 平滑降到 $\eta_{\min}$，形如半周期余弦：前期下降慢、中期下降快、末期平缓趋零。这种形态契合训练动力学——初期保留较大步长探索，末期以极小 LR 精细收敛到平坦盆地。常与 warmup 组合，成为大模型预训练默认配置。其「平滑」特性避免了阶梯衰减的突跳对收敛轨迹的扰动。

## 三、形式化与数学基础

设总步数 $T$，当前步 $t$，则：

$$\eta_t = \eta_{\min} + \tfrac{1}{2}(\eta_{\max}-\eta_{\min})\Big(1+\cos\big(\pi\cdot\tfrac{t}{T}\big)\Big)$$

当 $t=0$，$\cos 0=1$，故 $\eta_0=\eta_{\max}$；当 $t=T$，$\cos\pi=-1$，故 $\eta_T=\eta_{\min}$。导数 $\eta'_t\propto -\sin(\pi t/T)$，在两端为 0——即起步温和、收尾平缓，中段下降最快。这保证了训练初期不会被骤降的 LR 限制探索。

## 四、代码实现

```python
import math

def cosine_lr(t, T, lr_max=3e-4, lr_min=3e-5):
    return lr_min + 0.5 * (lr_max - lr_min) * (1 + math.cos(math.pi * t / T))

# t=0 -> lr_max ; t=T -> lr_min
assert abs(cosine_lr(0, 1000) - 3e-4) < 1e-9
assert abs(cosine_lr(1000, 1000) - 3e-5) < 1e-9

# 与 warmup 组合（常见封装）
def get_lr(step, warmup_steps, total_steps, lr_max, lr_min):
    if step < warmup_steps:
        return lr_max * step / warmup_steps
    t = step - warmup_steps
    T = total_steps - warmup_steps
    return cosine_lr(t, T, lr_max, lr_min)
```

## 五、与其他技术对比

| 调度 | 曲线特性 | 末期 LR | 泛化 | 调参负担 |
| --- | --- | --- | --- | --- |
| 阶梯衰减 | 突变阶梯 | 跳变到低 | 中 | 需设里程碑 |
| 线性衰减 | 直线 | 中 | 中 | 低 |
| 余弦退火 | 平滑余弦 | 趋零最平滑 | 较优 | 低 |
| 指数衰减 | 快速下降 | 趋零 | 中 | 需系数 |

## 六、常见误区

误区一：把 $T$ 设成 epoch 数而非优化步数，导致 LR 下降节奏与 batch 不匹配。误区二：误以为「退火=只降不升」——带重启的变体（SGDR）会周期性回升。误区三：忽视 $\eta_{\min}$ 取值——过小可能末段更新停滞，过大则无法精细收敛。误区四：认为余弦必然优于一切——短训练差异未必显著。

## 九、演进与趋势

余弦 + warmup 已成为大模型预训练标配；进一步演化出余弦+线性尾、多段余弦（再预热）、与数据课程联动的衰减形状；部分工作探索「带噪声的余弦」以兼顾末期探索。

### 实践速查

- 公式：记住 $\eta_0=\eta_{\max}$、$\eta_T=\eta_{\min}$，中段下降最快。
- 配 warmup：先线性升温再接余弦，是大模型训练标准形态。
- 末值：设 $\eta_{\min}$ 为峰值约 1/10，避免末期完全停更。
- 步数：T 用优化步数（含所有 micro-batch 累加），非 epoch。
- 校验：在 t=0 与 t=T 打点，确认 LR 确实取到两端极值。
- 变体：需要探索时叠加 SGDR 重启，否则用单次余弦即可。

### 常见问题

- 问：为何末期 LR 趋零？答：cos 在 π 为 -1，LR 落到 $\eta_{\min}$ 精细收敛。
- 问：余弦与阶梯衰减差异？答：余弦平滑无跳变，收敛轨迹更稳。
- 问：T 设错会怎样？答：衰减节奏与训练错位，末期可能未充分退火。

### 关键记忆点

- 余弦公式两端导数为零：起步温和、收尾平缓，中段下降最快。
- 与 warmup 组合是预训练标准形态，缺一不可。
- 打点校验 t=0 与 t=T 的 LR 取到两端极值，防止配置错误。

## 十、小结

余弦退火以平滑衰减提升末期收敛质量，是大模型训练的默认 LR 形态，理解其数学本质有助于合理调参而不盲从默认值。
