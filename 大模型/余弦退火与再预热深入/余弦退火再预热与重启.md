# 余弦退火再预热与重启

> 对应 d2l-ai/d2l-zh 学习率调度与 karpathy/nanoGPT 的迭代式 lr 设计。

## 一、背景与挑战
单次余弦退火把 lr 降到极低后，模型可能陷入尖锐极小值；周期性重启可跳出不优盆地，提升泛化。

## 二、核心原理
SGDR 思想（warm restart）以余弦周期反复把 lr 从低拉回高再降下。在大模型中，也可在多阶段训练（如继续预训练）中再次预热。

## 三、形式化与数学基础
第 i 个周期长度 T_i，余弦：`η_t = η_min + 0.5(η_max-η_min)(1+cos(π·(t-t_i)/T_i))`，周期末重置到 η_max。

## 四、代码实现
```python
def cosine_restart(t, cycle_len, cycle_idx, lr_max, lr_min):
    p = (t % cycle_len) / cycle_len
    return lr_min + 0.5 * (lr_max - lr_min) * (1 + math.cos(math.pi * p))
```

## 五、与其他技术对比
单次余弦简单稳定；多重启探索性更强但可能破坏已学表征，需谨慎用于大模型。

## 六、常见误区
在大模型全量预训练上频繁重启代价高，通常仅在微调或课程式训练中使用。

## 七、与开源书/权威来源对应
d2l-ai/d2l-zh 介绍余弦重启；karpathy/nanoGPT 采用单次余弦配合 warmup。

## 八、面试题
问：重启为何可能帮助泛化？答：周期性高 lr 帮助逃离尖锐极小值。

## 九、演进与趋势
结合阶段式数据课程的多段调度正被采用。

## 十、小结
再预热与重启是增强探索的工具，但大模型上需权衡成本。
