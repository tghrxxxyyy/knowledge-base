# 余弦退火再预热与重启

> 对应 Loshchilov & Hutter, *SGDR: Stochastic Gradient Descent with Warm Restarts* (2017)；karpathy/nanoGPT 迭代式 LR 设计。

## 一、背景与挑战

单次余弦退火把 LR 降到极低后，模型可能收敛到一个尖锐极小或次优盆地，缺乏继续探索的能力。尤其在数据分布复杂时，一次退火容易过早「定格」。如何在不重训的前提下重新激发探索，是提升泛化的重要课题。此外，多阶段训练（继续预训练、领域适配）本身也要求在新阶段重新升温，否则学习会停滞。

## 二、核心原理

带热重启的余弦退火（SGDR）以若干余弦周期反复把 LR 从低值「重启」回高值再降下，每个周期是一个完整的余弦衰减。在大模型实践中，也体现为「多阶段训练」：继续预训练或领域适配时，再次 warmup 到较低峰值再退火。重启的本质是周期性注入优化噪声，帮助跳出局部盆地、探索更平坦的解。与单次退火相比，它在收敛与探索之间反复折返。

## 三、形式化与数学基础

第 $i$ 个周期长度为 $T_i$，周期起点 $t_{i}$，余弦重启公式：

$$\eta_t = \eta_{\min} + \tfrac{1}{2}(\eta_{\max}-\eta_{\min})\Big(1+\cos\big(\pi\cdot\tfrac{t-t_i}{T_i}\big)\Big)$$

周期末 $t=t_i+T_i$ 时 $\eta_t\to\eta_{\min}$，下一周期起点瞬间回到 $\eta_{\max}$（热重启）。周期长度常按几何增长 $T_{i+1}=T_i\times k$（$k>1$），使后期探索更稀疏、收敛更稳。这样噪声注入随时间递减，兼顾探索与稳定。

## 四、代码实现

```python
import math

def cosine_restart(t, cycle_len, lr_max, lr_min=0.0, cycle_idx=0):
    # 周期起点偏移
    local = (t - cycle_idx * cycle_len) % cycle_len
    p = local / cycle_len
    return lr_min + 0.5 * (lr_max - lr_min) * (1 + math.cos(math.pi * p))

# 多阶段训练中的「再预热」：新阶段重新 warmup 到较低峰值
def stage_lr(t, T_warm, T_stage, lr_peak, lr_min):
    if t < T_warm:
        return lr_peak * t / T_warm
    p = (t - T_warm) / (T_stage - T_warm)
    return lr_min + 0.5 * (lr_peak - lr_min) * (1 + math.cos(math.pi * p))
```

## 六、常见误区

误区一：在大模型全量预训练上频繁重启代价极高——通常仅在微调或课程式训练使用。误区二：重启必然更好——若破坏已学表征反而掉点。误区三：周期长度随意——过短重启变噪声、过长失去探索意义。误区四：把「再预热」等同于从零 warmup——继续训练峰值应更低。

## 九、演进与趋势

从固定周期到几何增长周期；与数据课程、阶段式训练目标结合，形成「阶段切换 + 再预热」的现代多段调度；也出现根据验证指标触发的「条件重启」。

### 实践速查

- 微调：SGDR 多重启多用于微调/小模型，全量预训练慎用。
- 周期：周期长度常几何增长，后期重启更稀疏、收敛更稳。
- 再预热：继续预训练用更低峰值重新 warmup，而非从原峰值起。
- 诊断：重启后 loss 突增属正常，关键是能否在周期末回到更低点。
- 成本：每次重启都要重新探索，算力预算需预留。
- 搭配：重启常配合数据课程，新阶段换数据再升温最自然。

### 常见问题

- 问：重启为何可能提升泛化？答：周期性高 LR 帮逃离尖锐极小。
- 问：全量预训练能用吗？答：成本极高，通常只在阶段切换时单独再预热。
- 问：周期怎么定？答：先短后长几何增长，配合验证曲线观察。

### 关键记忆点

- 重启/再预热周期性注入噪声，帮助逃离尖锐极小、探索平坦解。
- 全量预训练慎用频繁重启，成本极高，多在微调/阶段切换使用。
- 周期常几何增长，后期重启更稀疏、收敛更稳。
- 重启不是越多越好，要结合验证曲线与算力预算权衡频率。
- 若重启后无法回到更低 loss，说明周期或峰值配置需下调。

## 十、小结

再预热与重启是增强探索的工具，但大模型上需权衡成本，多用于微调与继续预训练而非全量重训，滥用反而破坏已学表征。
