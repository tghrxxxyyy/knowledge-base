# 视觉编码器选型

> 见「多模态对齐深入/CLIP对比对齐」与「多模态深入」。

## 一、背景与挑战

不同视觉编码器（CLIP-ViT/ConvNeXt/SigLIP）影响多模态上限。

## 二、核心原理

CLIP/ViT 提供语义表征；SigLIP 用 sigmoid 损失更稳定；分辨率与 patch size 影响细粒度。

## 三、关键要点

- 高分辨率利于 OCR/文档。
- 编码器需与投影/LLM 维度匹配。

## 四、代码实现

```python
from transformers import CLIPVisionModel
vis = CLIPVisionModel.from_pretrained("openai/clip-vit-large-patch14-336")
```

## 五、与其他对比

| 编码器 | 特点 |
|--------|------|
| CLIP-ViT | 通用语义 |
| SigLIP | 训练稳、细粒度 |
| InternViT | 高分辨多模态 |

## 六、常见误区

- 编码器越新越好——需与整体管线匹配。
