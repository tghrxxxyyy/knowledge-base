# 多模态幻觉

> 见「幻觉与缓解深入/大模型幻觉概述」与「多模态深入」。

## 一、背景与挑战

多模态模型会「看到不存在的物体」或「答非所问」，称对象幻觉/属性幻觉。

## 二、核心原理

根因：视觉编码与语言生成的错位、训练数据噪声、LLM 语言先验过强压过视觉证据。

## 三、关键要点

- 对象幻觉最常见（编造图中物体）。
- 语言先验（co-occurrence）是主因之一。

## 四、代码实现

```python
# POPE 评测：问「图中是否有X」做二分类
prompt = f"Is there a {obj} in the image? Answer yes/no."
```

## 五、与其他对比

- 文本幻觉靠检索；多模态幻觉需视觉证据对齐。

## 六、常见误区

- 注意力看图就准——语言先验仍可能主导。
