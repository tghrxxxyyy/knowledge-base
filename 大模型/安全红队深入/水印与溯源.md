# 水印与溯源

> 对应 Kirchenbauer et al. 2023 绿色列表水印（GPT 水印）与 C2PA 内容溯源标准。

## 一、背景与挑战

随着 AI 生成文本海量化，如何区分「人写」与「机器写」成为内容治理、学术诚信与虚假信息防控的刚需。水印（Watermark）通过在模型生成时嵌入统计上可检测的微弱信号，使文本即使被转发、改写也仍可被概率性识别；溯源（Provenance）则通过元数据标准（如 C2PA）记录内容的生成工具与链路。挑战在于：水印必须「低损」——不损伤语言质量，同时「鲁棒」——抵得住改写、翻译、摘要等变换；而元数据水印易被直接删除，二者需互补。此外，水印还可能被滥用于内容审查或误伤人类作者，需兼顾公平与隐私。

## 二、核心原理

在实际应用中，水印常与「输出过滤」协同：先用水印标记，再对高风险内容触发二次审核，形成分层治理。水印还可按「嵌入时机」分为「生成时水印（generation-time）」与「事后水印（post-hoc）」：前者在采样阶段实时偏置分布，后者对已生成文本做最小修改注入信号。前者质量损失更小但需模型配合，后者适用任意文本但可能改动语义。主流方法是「绿色列表（green-list）」水印（Kirchenbauer et al.）。在生成每个 token 时，根据前文用哈希函数确定性地划出一部分词表作为绿色列表，并轻微提升这些词的采样概率。由于绿色词的选择依赖于上下文哈希，正常人类文本中绿色词比例约为随机水平，而带水印文本中绿色词比例显著偏高，因此可用统计检验（如 Z 检验）以高置信度判定是否含 AI 水印。其直觉是：在不改变语义主流的前提下，于「低信息量」的选择上悄悄偏移分布。

## 三、形式化与数学基础

设词表 $\mathcal{V}$，给定上下文 $h$ 时确定性划分 $\mathcal{G}(h)\subset\mathcal{V}$（绿色列表）。水印生成将绿色词 logit 加偏置 $\gamma>0$：

$$\tilde{p}(w\mid h) \propto \exp(\log p(w\mid h) + \gamma\cdot\mathbf{1}[w\in\mathcal{G}(h)])$$

检测时对文本 token 序列统计绿色词占比 $g$，在零假设「无 watermark」下 $g\sim\mathcal{B}(N, |\mathcal{G}|/|\mathcal{V}|)$，计算：

$$Z = \frac{g - N\cdot\rho}{\sqrt{N\rho(1-\rho)}},\quad \rho = |\mathcal{G}|/|\mathcal{V}|$$

$|Z|$ 超过阈值即判为 AI 生成。水印强度 $\gamma$ 与绿色列表比例共同决定检测力与质量损失的权衡。

## 四、代码实现

```python
import hashlib, math

def green_list(prev_token: str, vocab: list, frac: float = 0.5):
    h = int(hashlib.md5(prev_token.encode()).hexdigest(), 16)
    k = int(len(vocab) * frac)
    return set(sorted(vocab, key=lambda w: (h ^ hash(w)) % 10**9)[:k])

def score(text_tokens, vocab, frac=0.5):
    N = len(text_tokens) - 1
    g = sum(1 for i in range(1, N + 1)
            if text_tokens[i] in green_list(text_tokens[i-1], vocab, frac))
    rho = frac
    Z = (g - N * rho) / math.sqrt(N * rho * (1 - rho))
    return Z
```

## 五、与其他技术对比

| 方法 | 鲁棒性 | 无损性 | 可删性 |
|------|--------|--------|--------|
| 统计水印 | 抗轻度改写 | 高 | 难删 |
| 元数据(C2PA) | 弱（易删） | 完全 | 易删 |
| 分类器检测 | 中 | 无关 | 不可删 |

统计水印与元数据互补：前者嵌入内容、后者记录链路。

## 六、常见误区

- 认为水印能「百分百识别」：统计检验有误判率，短文本尤其不可靠。
- 以为改写无影响：大幅 paraphrasing 会稀释绿色信号，需更强的上下文水印。
- 把元数据当水印：C2PA 可被一键剥离，必须与内容级水印配合。
- 忽视对正常用户的公平性：水印偏置可能轻微改变分布，需评估偏差。

## 七、与开源书·权威来源对应

- Kirchenbauer et al., *A Watermark for Large Language Models* (2023) 提出绿色列表水印与 Z 检验。
- C2PA（Coalition for Content Provenance and Authenticity）定义内容来源元数据标准。
- 相关开源实现见 watermarker 类项目，以官方最新文档为准。

## 九、演进与趋势

- 从「无状态」绿色列表走向「上下文相关」水印，提升抗改写能力。
- 多模态水印（图像/音频/视频）与文本水印统一进 C2PA 溯源体系。
- watermark 与检测进入标准化讨论，部分 jurisdictions 考虑强制 AI 内容标识。
- 水印强度可调节：高风险场景用强水印（更易检但略损质量），低风险用弱水印。

## 十、小结

水印与溯源是 AI 内容治理的技术支点：统计水印（如绿色列表）嵌入难以剥离的信号，元数据标准记录生成链路，二者互补。其永恒张力是「低损 vs 鲁棒」，需在质量与可检测性间权衡，并警惕误伤与滥用。
