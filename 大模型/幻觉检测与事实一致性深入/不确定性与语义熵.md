# 不确定性与语义熵

> 对应 Kuhn et al., *Semantic Uncertainty*, ICLR 2023；Farquhar et al., *Detecting Hallucinations Using Semantic Entropy*, Nature 2024。

## 一、背景与挑战

token 级熵会把「同义不同表述」误判为不确定，因此不适合直接作为幻觉信号。需要在语义等价类上度量不确定性。

## 二、核心原理

语义熵先把多次采样的答案按语义等价聚类，再在类别层面计算熵，从而剔除表述多样性带来的虚假不确定。

- 聚类判据常用双向蕴含：两答案互相蕴含即视为同一语义类。
- 类内概率求和后计算熵，高语义熵与「编造」高度相关，可作为无参照的检测信号。

## 三、数学形式

$$H_{sem}=-\sum_{k}P\big(C_k\big)\log P\big(C_k\big),\qquad P\big(C_k\big)=\sum_{y\in C_k}p_\theta\big(y\mid x\big)$$

与朴素序列熵 $-\sum_y p(y)\log p(y)$ 相比，聚类合并消除了表面形式的冗余分裂。

## 四、代码实现

```python
import math
def semantic_entropy(samples, probs, equiv_fn):
    clusters = []
    for s, p in zip(samples, probs):
        for c in clusters:
            if equiv_fn(s, c[0]): c[1] += p; break
        else:
            clusters.append([s, p])
    tot = sum(c[1] for c in clusters)
    return round(-sum((c[1] / tot) * math.log(c[1] / tot) for c in clusters), 4)
print(semantic_entropy(["巴黎", "法国巴黎", "里昂"], [0.5, 0.3, 0.2], lambda a, b: a in b or b in a))
```

## 五、与其他对比

- 与 token 熵对照：语义熵对同义改写不敏感，判别力显著更强。
- 与 自一致性采样检测 衔接：两者都基于多采样，前者概率化、后者比对化。

## 六、常见误区

- 用单次生成的 token 熵当幻觉分数，长答案上几乎无判别力。
- 等价判定用字符串匹配替代蕴含模型，导致同义答案被拆成多类而虚高熵值。

## 八、面试题

- 语义熵为何优于序列熵？答：先按语义聚类再算熵，消除同义表述造成的伪不确定性。
- 主要成本？答：需多次采样与蕴含判定，推理开销成倍增加。

## 九、演进

token 熵 → 序列似然 → 语义聚类熵（2023）→ 面向部署的高效近似（2024）。

## 十、小结

语义熵是无需外部证据的强检测信号，代价是多采样与语义等价判定的开销。
