# 内部状态探针检测

> 对应 Azaria & Mitchell, *The Internal State of an LLM Knows When It's Lying*, EMNLP Findings 2023；Burns et al., *Discovering Latent Knowledge Without Supervision*, ICLR 2023。

## 一、背景与挑战

模型有时「知道自己在编」：内部表示中存在与真值相关的信号，而输出层却给出错误答案。利用这一差异可构建白盒检测器。

## 二、核心原理

在隐状态上训练轻量分类器预测陈述真假，或用无监督一致性约束发现潜在真值方向。

- 有监督探针：用带真假标注的陈述集训练线性分类器，跨数据集泛化是主要挑战。
- 无监督路线（CCS）利用「一个陈述与其否定的置信应互补」这一逻辑约束，无需标签即可找出方向。

## 三、数学形式

CCS 目标：$\min_{w}\ \mathbb{E}\Big[\big(p_w(x)+p_w(\bar x)-1\big)^2+\big(\min\{p_w(x),p_w(\bar x)\}\big)^2\Big]$，$p_w(x)=\sigma\big(w^\top h(x)\big)$。

第一项施加一致性（互补），第二项施加置信度（避免退化到常数 0.5）。

## 四、代码实现

```python
import torch
def ccs_loss(w, h_pos, h_neg):
    p1 = torch.sigmoid(h_pos @ w); p0 = torch.sigmoid(h_neg @ w)
    consistency = ((p1 + p0 - 1) ** 2).mean()
    confidence = (torch.min(p1, p0) ** 2).mean()
    return consistency + confidence
w = torch.randn(32, requires_grad=True)
print(float(ccs_loss(w, torch.randn(8, 32), torch.randn(8, 32))))
```

## 五、与其他对比

- 与黑盒方法对照：白盒探针成本低（单次前向）但需模型权限，且跨分布稳健性较弱。
- 与 方向可靠性与因果验证 衔接：真值方向必须通过跨分布与干预检验才可部署。

## 六、常见误区

- 在同分布上取得高 AUC 即宣称「测谎成功」，换领域后常显著退化。
- 忽略探针学到的是「表述可信度」等相关特征，而非真值本身，需控制任务对照。

## 八、面试题

- CCS 为何不需标签？答：利用陈述与否定的置信互补这一逻辑约束作自监督信号。
- 白盒检测的主要限制？答：需模型内部访问权限，且跨分布泛化与因果可靠性需额外验证。

## 九、演进

有监督真值探针（2023）→ 无监督一致性方向（2023）→ 与推理期干预结合 → 跨分布可靠性评估。

## 十、小结

内部状态探针提供低成本白盒幻觉信号，但其可部署性取决于跨分布与因果验证结果。
