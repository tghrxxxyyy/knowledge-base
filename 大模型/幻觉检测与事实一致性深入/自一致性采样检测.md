# 自一致性采样检测

> 对应 Manakul et al., *SelfCheckGPT*, EMNLP 2023；Wang et al., *Self-Consistency Improves Chain of Thought Reasoning*, ICLR 2023。

## 一、背景与挑战

黑盒场景下拿不到 logits，也没有外部证据。此时可用「同一问题多次采样是否互相支持」来近似判断内容是否被模型稳定持有。

## 二、核心原理

核心假设：模型真正掌握的知识在多次采样中稳定复现，编造内容则在采样间发散。

- 实施上把待检句与多个采样答案逐一比对，用蕴含/问答匹配/n-gram 概率等打分并聚合。
- 该方法完全黑盒，不需要 token 概率，适合仅有 API 的部署环境。

## 三、数学形式

句子 $s$ 的不一致分数 $\mathrm{Incons}(s)=\frac{1}{N}\sum_{i=1}^{N}\big(1-\mathrm{sim}\big(s,\ y^{(i)}\big)\big)$，$y^{(i)}$ 为独立采样。

推理类任务的自一致性则取多数投票 $\hat y=\arg\max_{y}\sum_{i}\mathbb{1}\big[y^{(i)}=y\big]$，一致度可作置信代理。

## 四、代码实现

```python
def selfcheck(sentence, samples, entail_fn):
    scores = [1.0 - float(entail_fn(sentence, s)) for s in samples]
    return round(sum(scores) / max(len(scores), 1), 3)
print(selfcheck("巴黎是法国首都", ["法国首都是巴黎", "首都为巴黎"], lambda a, b: 1.0))
```

## 五、与其他对比

- 与语义熵对照：都用多采样，自一致性无需概率、更黑盒，但对判据模型质量更敏感。
- 与检索核查对照：自一致性只测模型内部稳定性，无法发现「稳定但错误」的信念。

## 六、常见误区

- 用低温度采样做一致性检测，样本几乎相同导致检测失效。
- 把一致性当正确性：模型可稳定地持有错误知识，需外部证据兜底。

## 八、面试题

- 自一致性检测的假设？答：真实知识多采样稳定，编造内容发散。
- 何时失效？答：模型稳定持有错误信念，或采样温度过低导致多样性不足。

## 九、演进

多数投票（2023）→ 句级一致性打分（2023）→ 与语义聚类结合 → 与检索核查级联。

## 十、小结

自一致性是最易落地的黑盒检测手段，但只能测稳定性，不能替代事实核查。
