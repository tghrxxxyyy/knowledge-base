# 幻觉检测总览

> 对应 Maynez et al., *On Faithfulness and Factuality in Abstractive Summarization*, ACL 2020；Ji et al., *Survey of Hallucination in NLG*, ACM Computing Surveys 2023。

## 一、背景与挑战

幻觉是生成内容流畅但与来源或世界事实不符。检测困难在于：需要先定义参照系（源文档还是世界知识），再选择可自动化的判据。

## 二、核心原理

按参照系可分为忠实性与事实性两类，二者的检测方法与失败模式不同。

- 忠实性（faithfulness）：以给定源文档为准，判断输出是否可由源支持，适合摘要与 RAG 场景。
- 事实性（factuality）：以世界知识为准，需外部证据检索，闭卷问答只能用不确定性或自一致性代理。

## 三、数学形式

把输出拆成原子断言集合 $\{c_1,\dots,c_n\}$，支持率 $\mathrm{Support}=\frac{1}{n}\sum_i \mathbb{1}\big[\exists\,e\in E:\ e\models c_i\big]$。

幻觉率则为 $1-\mathrm{Support}$；该分解使长文本评估从整体判断变为可加的断言级判断。

## 四、代码实现

```python
def support_rate(claims, verify_fn, evidence):
    hits = [1 if verify_fn(c, evidence) else 0 for c in claims]
    return round(sum(hits) / max(len(hits), 1), 3)
print(support_rate(["A 成立", "B 成立"], lambda c, e: c in e, "A 成立"))
```

## 五、与其他对比

- 与流畅度指标对照：BLEU/ROUGE 与忠实性相关性弱，Maynez et al. 已实证其不足。
- 与 检索证据核查与归因 衔接：事实性检测必须引入外部证据链。

## 六、常见误区

- 混用忠实性与事实性：源文档本身可能有误，此时忠实但不事实。
- 用整段二元标注代替断言级分解，导致部分正确的长文本被粗暴判错。

## 八、面试题

- 忠实性与事实性差别？答：前者以源文档为参照，后者以世界知识为参照，可相互独立。
- 为什么要做断言级分解？答：长文本部分正确普遍存在，断言级支持率更有分辨率。

## 九、演进

n-gram 指标 → 忠实性人工标注与分类器（2020）→ 断言级评估（2023）→ 证据链归因与自动核查。

## 十、小结

幻觉检测的第一步是确定参照系与评估粒度，之后方法选择才有意义。
