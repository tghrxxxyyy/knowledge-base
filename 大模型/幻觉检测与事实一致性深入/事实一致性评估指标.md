# 事实一致性评估指标

> 对应 Kryscinski et al., *FactCC*, EMNLP 2020；Durmus et al., *FEQA*, ACL 2020；Min et al., *FActScore*, EMNLP 2023。

## 一、背景与挑战

n-gram 重叠指标与人工忠实性判断相关性弱。需要以蕴含判断或问答一致为核心的专用指标，并处理长文本的部分正确问题。

## 二、核心原理

三条主流路线各有取舍，实践中常组合使用以覆盖不同错误类型。

- 蕴含式：训练或调用 NLI 模型判断源文档是否蕴含输出句（FactCC 类）。
- 问答式：从输出生成问题，分别在输出与源上作答并比对答案（FEQA/QAGS 类）；断言式（FActScore）则把长文本拆为原子事实逐条核验。

## 三、数学形式

蕴含式分数 $\mathrm{Fact}=\frac{1}{n}\sum_i p_{NLI}\big(\mathrm{entail}\mid d, s_i\big)$；问答式一致率 $\mathrm{QA}=\frac{1}{m}\sum_j \mathbb{1}\big[a_j^{out}=a_j^{src}\big]$。

FActScore 为断言级精确率 $\frac{1}{n}\sum_i \mathbb{1}\big[c_i\ \text{被知识源支持}\big]$，对长文本更有分辨率。

## 四、代码实现

```python
def factscore(claims, support_fn):
    hits = [1 if support_fn(c) else 0 for c in claims]
    return round(sum(hits) / max(len(hits), 1), 3)
def qa_consistency(q_list, ans_out, ans_src):
    same = [1 if a == b else 0 for a, b in zip(ans_out, ans_src)]
    return round(sum(same) / max(len(same), 1), 3)
```

## 五、与其他对比

- 与 ROUGE/BLEU 对照：重叠指标对事实错误几乎不敏感，不能作为忠实性证据。
- 与 LLM 评审对照：LLM 打分覆盖广但有位置与自偏好偏置，需与断言级指标交叉验证。

## 六、常见误区

- 直接用通用 NLI 模型跨域评估，长文档与领域漂移下判别力大幅下降。
- 只报整体分数不报错误类型分布，无法指导具体改进。

## 八、面试题

- 为何 ROUGE 不能测忠实性？答：它只测表面重叠，事实反转往往不改变 n-gram 覆盖。
- FActScore 的核心贡献？答：把长文本拆成原子断言逐条核验，得到有分辨率的精确率。

## 九、演进

重叠指标 → 蕴含与问答式指标（2020）→ 断言级核验（2023）→ 与检索证据链结合的自动核查。

## 十、小结

事实一致性必须用蕴含/问答/断言类指标测量，且需报告错误类型分布。
