# 权重衰减系数调参经验

> 对应 Loshchilov & Hutter 2019 AdamW 与 huggingface/transformers 训练脚本。

## 一、背景与挑战
权重衰减 λ 直接决定模型容量与过拟合程度。λ 太小易过拟合，太大欠拟合且收敛慢。不同规模模型、不同数据量的合适 λ 差异显著。

## 二、核心原理
λ 与学习率 η 以乘积 `(ηλ)` 形式进入参数收缩项，因此当 η 改变时，应同步缩放 λ 以保持等效收缩，即所谓 decoupled 视角下的 λ/η 比例恒定原则。

## 三、形式化与数学基础
等效收缩率约 `ρ = 1 - ηλ`。若把学习率从 η 提到 10η，要保持 ρ 不变需把 λ 降到 λ/10。这正是大模型放大 lr 时常同步减小 wd 的原因。

## 四、代码实现
```python
# 学习率变化时同步调整 wd
base_lr, base_wd = 3e-4, 0.1
new_lr = 6e-4
new_wd = base_wd * (base_lr / new_lr)  # 保持 eta*wd 不变
print(new_wd)  # 0.05
```

## 五、与其他技术对比
数据量越大，可适当增大 λ 防止过拟合；正则化强的模型（如带 dropout）可减小 λ。与早停相比，权重衰减提供平滑的容量控制。

## 六、常见误区
固定 λ 不变而大幅调 lr，导致等效收缩剧烈变化，引发训练后期震荡或过早收缩。

## 七、与开源书/权威来源对应
Loshchilov & Hutter 2019 建议 λ 与 lr 解耦后独立网格搜索；datawhalechina/llm-universe 给出大模型微调常用 0.01~0.1 区间。

## 八、面试题
问：lr 放大 5 倍时 wd 怎么调？答：按 ηλ 乘积守恒，wd 除以 5。

## 九、演进与趋势
自动超参搜索与 λ 调度（如随训练衰减）正被探索，以减少手工调参成本。

## 十、小结
权重衰减的核心是控制 ηλ 乘积，应随学习率策略协同设计。
