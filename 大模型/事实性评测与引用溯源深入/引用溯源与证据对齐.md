# 引用溯源与证据对齐

> 对应 Asai 2023 self-RAG。

## 一、背景与挑战
回答应给出可点击的来源，使每条claim可追溯到具体段落。

## 二、核心原理
生成时要求模型输出引用标记，再把标记映射到检索片段，校验 claim 是否被片段支持。

## 三、形式化与数学基础
对齐得分：
$ A = \frac{1}{|C|}\sum_{c \in C} \max_{e \in E} \text{sim}(c, e) $

## 四、代码实现
```python
def align(claims, evidences, sim):
    return sum(max(sim(c, e) for e in evidences) for c in claims) / len(claims)
```

## 五、与其他技术对比
相比无引用生成，溯源提升可审计性，但要求检索质量高。

## 六、常见误区
引用存在但不相关；用无关段落凑数。

## 七、与开源书/权威来源对应
Asai 2023 提出 self-RAG 自适应检索与引用。

## 八、面试题
如何自动判断一条引用是否真正支持 claim？

## 九、演进与趋势
细粒度句子级对齐与反事实校验。

## 十、小结
证据对齐把可信性从声明变为可验证。
