# 事实性幻觉度量

> 对应 Lewis et al. 2020 RAG、Asai et al. 2023 Self-RAG，及事实性幻觉检测（Hallucination Detection）研究。

## 一、背景与挑战

生成式大模型会产出「看似合理、实则错误」的内容，即幻觉（hallucination）。在知识问答、医疗、法律等高风险场景，幻觉可能造成严重后果。事实性幻觉度量的目标是**把「模型在多大程度上在编造」量化出来**，以便监控、对比与优化。

核心难点：事实性不是二值标签，而是「哪些具体片段不真实」的细粒度问题；且验证需依赖外部知识源或检索结果，本身的可靠性也会影响度量。

## 二、核心原理

主流做法是「原子事实分解 + 支撑判定」：

1. **抽取原子事实**：把一段自由文本拆成最小可验证单元（如「A 在 B 年出生于 C」），而非整段判断。
2. **检索 / 比对**：将每个原子事实与知识源（维基、检索片段、知识图谱）比对，判定 supported / contradicted / unverifiable。
3. **聚合指标**：用被支持比例、被反驳比例、不确定性比例刻画整体事实性。

进一步可区分两类幻觉：**内在幻觉**（与给定上下文矛盾）与**外在幻觉**（缺乏外部事实支撑）。评测常聚焦后者。

## 三、形式化与数学基础

设回答拆为原子事实集合 F，支持的子集 S ⊆ F。幻觉率（hallucination rate）：

$$
H = 1 - \frac{|S|}{|F|}
$$

若还区分「被反驳」集合 C（明确错误）与「不可验证」集合 U，可定义更细指标：

$$
H_{contra} = \frac{|C|}{|F|}, \quad H_{unk} = \frac{|U|}{|F|}
$$

整体事实可信度可加权：

$$
\text{FactScore} = \frac{\sum_{f \in F} w_f \cdot \mathbb{1}[f \in S]}{\sum_{f \in F} w_f}
$$

其中 w_f 可为事实重要性权重（关键实体更高）。

## 四、代码实现

```python
# 原子事实级幻觉率（示意）
def hallucination_rate(facts, supported_ids):
    # facts: 全部原子事实 id 列表
    # supported_ids: 被支撑的事实 id 集合
    if not facts:
        return 0.0
    supported = sum(1 for fid in facts if fid in supported_ids)
    return 1.0 - supported / len(facts)

# 抽取原子事实后用检索器 / 知识库验证
facts = llm_extract_atomic_claims(text)
verified = knowledge_base.verify(facts)   # 返回 supported / contradicted / unknown
h = hallucination_rate(facts, verified.supported_ids)
```

## 五、与其他技术对比

- **整体打分**：快但粗糙，无法定位哪句在编。
- **原子事实级度量**：细粒度、可解释，但依赖抽取与对齐质量。
- **Self-RAG 批判标记**：生成时自评，是「预防式」而非「评测式」事实性保障。
- **RAGAS faithfulness**：从上下文反推支撑，是原子事实度量的一种实现。

## 六、常见误区

- **误区一：检索命中 = 事实正确**——检索到文档不代表该断言被蕴含。
- **误区二：没被证伪 = 真实**——「不可验证」不等于「正确」，应单独计数。
- **误区三：整体高分即安全**——一个关键实体编造可能致命，需重要性加权。
- **误区四：抽取一定准**——劣质抽取会让度量本身失真。

从「人工标注幻觉」走向「原子事实抽取 + 检索 / 知识图谱自动验证 + 重要性加权」；结合 Self-RAG 式生成时自检形成「度量—预防」双保险。具体数据集与基准以官方最新文档为准。

## 十、小结

事实性幻觉度量是可信生成的核心护栏指标。通过原子事实分解与支撑判定，把「编造程度」从模糊感受变成可量化、可定位的数字，是高风险场景落地的必备能力。
