# 事实性幻觉度量

> 对应 Lewis 2020 RAG 与 Asai 2023 self-RAG。

## 一、背景与挑战
生成式模型会编造看似合理但错误的事实，需量化幻觉比例。

## 二、核心原理
将回答拆为原子事实，逐一与知识源或检索结果比对，统计不支持的比例。

## 三、形式化与数学基础
幻觉率：
$ H = 1 - \frac{|\{f: \text{supported}(f)\}|}{|F|} $

## 四、代码实现
```python
def hallucination_rate(facts, supported):
    # supported: 集合, 元素为被支持的 fact id
    return 1 - len(supported) / len(facts)
```

## 五、与其他技术对比
相比整体评分，原子事实级度量更细，但依赖抽取与对齐质量。

## 六、常见误区
把检索命中当作事实正确；忽略模型自造的错误细节。

## 七、与开源书/权威来源对应
Lewis 2020 给出 RAG 框架；Asai 2023 强调按需检索与事实对齐。

## 八、面试题
如何把一段文本自动拆成可验证的原子事实？

## 九、演进与趋势
用检索器与断言分类器联合评估事实性。

## 十、小结
事实性度量是可信生成的核心护栏指标。
