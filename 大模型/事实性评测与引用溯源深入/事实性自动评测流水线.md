# 事实性自动评测流水线

> 对应 Es 2023 RAGAS 与 Lewis 2020 RAG。

## 一、背景与挑战
事实性需高频回归，不能每次人工抽检，需端到端自动流水线。

## 二、核心原理
流水线串联：生成 -> 原子事实抽取 -> 检索比对 -> 指标聚合 -> 告警。

## 三、形式化与数学基础
端到端事实分：
$ Q = \alpha F + (1-\alpha) A $
F 忠实度，A 对齐度。

## 四、代码实现
```python
def fact_pipeline(gen, extract, retrieve, score):
    facts = extract(gen)
    ev = retrieve(facts)
    return score(facts, ev)
```

## 五、与其他技术对比
手工评测准但慢，自动流水线快但需持续校准阈值。

## 六、常见误区
阈值固定不变；未对长尾类别单独监控。

## 七、与开源书/权威来源对应
Es 2023 提供自动 RAG 评测；Lewis 2020 奠基 RAG。

## 八、面试题
如何设定事实性告警阈值以减少误报？

## 九、演进与趋势
实时事实性采样与在线回滚。

## 十、小结
自动事实流水线让可信性可运营。
