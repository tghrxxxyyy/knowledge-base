# 知识边界与拒答评测

> 对应 Asai et al. 2023 Self-RAG、Lewis et al. 2020 RAG，及大模型安全对齐（abstention / 拒答）研究。

## 一、背景与挑战

一个值得信赖的事实系统，不仅要在「知道」时答对，更要在「不知道」时**拒绝编造**。知识边界（knowledge boundary）评测衡量模型能否准确感知自身能力边界：对超出训练知识、涉及未检索到证据、或事实不存在的问题，应优雅拒答（abstain）而非输出看似合理的幻觉。

核心挑战：

- **未回答 vs 不能回答**：模型需区分「我不知道」与「我无法执行」。
- **过度保守**：对所有不确定都拒答会严重损害可用性。
- **语义拒答**：拒答未必用固定模板，可能是「我没有相关信息」等语义表达，正则难以识别。

## 二、核心原理

评测构造两类样本：

1. **不可回答集（unanswerable）**：问题本身无解、事实不存在、或缺少必要证据。
2. **可回答集（answerable）**：标准事实性问题。

统计模型在不可回答集上的**拒答率**，以及在可回答集上的**误拒率**，衡量边界感知的准与全。理想系统是「该答尽答、该拒尽拒」。

进阶做法：用 Self-RAG 式批判标记显式表达「无依据不生成」；用校准（confidence calibration）让模型在低置信时主动 abstain。

## 三、形式化与数学基础

设不可回答问题集合 U，模型对其预测为拒答的记为 A（abstain）。恰当拒答率：

$$
AR = \frac{|\{u \in U : pred(u) \in Abstain\}|}{|U|}
$$

对可回答问题集合 K，误拒率：

$$
FR = \frac{|\{k \in K : pred(k) \in Abstain\}|}{|K|}
$$

一个理想系统在 AR 高（少编造）的同时 FR 低（少误杀）。可引入效用权衡：

$$
Utility = \alpha \cdot AR - (1-\alpha) \cdot FR
$$

语义拒答需先判别：用分类器或 LLM 判定输出是否表达「无足够信息」，再做计数。

## 四、代码实现

```python
# 拒答率评测（示意）
def abstain_rate(preds, unans_mask, is_refusal):
    refused = sum(1 for p, m in zip(preds, unans_mask)
                  if m and is_refusal(p))
    total_unans = sum(1 for m in unans_mask if m)
    return refused / max(1, total_unans)

# 误拒率：可回答问题却被拒
def false_refusal_rate(preds, ans_mask, is_refusal):
    refused = sum(1 for p, m in zip(preds, ans_mask)
                  if m and is_refusal(p))
    total_ans = sum(1 for m in ans_mask if m)
    return refused / max(1, total_ans)
```

## 五、与其他技术对比

- **强制回答（无拒答）**：可用性高但幻觉风险大，高风险场景不可接受。
- **模板硬编码拒答**：规则僵化，易被绕过且误拒多。
- **Self-RAG 批判式 abstain**：在生成时自评依据，边界感知更自然。
- **置信度校准 + 阈值拒答**：连续可控，但需良好校准。

## 六、常见误区

- **误区一：正则匹配拒答模板**——漏掉语义拒绝（「我无法确认…」）。
- **误区二：不区分不知道与不能**——二者语义不同，评测口径要分清。
- **误区三：拒答率越高越好**——过度保守损害可用性，需看误拒率。
- **误区四：仅看不可回答集**——忽略可回答集上的误杀才是真实代价。

## 七、与开源书·权威来源对应

## 九、演进与趋势

从「固定拒答模板」走向「批判标记 + 置信度校准 + 检索证据门控」的细粒度边界控制；将边界感知作为对齐目标融入训练，使模型在不确定时主动求助而非编造。具体方案以官方最新论文为准。

## 十、小结

拒答能力是事实系统安全性的重要组成。知识边界评测以「恰当拒答率 + 误拒率」双指标，刻画模型「知之为知之、不知不编」的能力边界。
