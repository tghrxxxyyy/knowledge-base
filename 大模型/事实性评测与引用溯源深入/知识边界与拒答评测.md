# 知识边界与拒答评测

> 对应 Asai 2023 self-RAG 与 Lewis 2020 RAG。

## 一、背景与挑战
模型在未知问题上应拒答而非编造，需评测其知识边界感知。

## 二、核心原理
构造不可回答或超出知识的问题，统计模型拒绝率与误答率。

## 三、形式化与数学基础
恰当拒答率：
$ \text{AR} = \frac{|\text{correctly refused}|}{|\text{unanswerable}|} $

## 四、代码实现
```python
def abstain_rate(preds, unans_mask):
    refused = sum(1 for p, m in zip(preds, unans_mask) if m and p.is_refusal)
    return refused / max(1, sum(unans_mask))
```

## 五、与其他技术对比
相比强制回答，拒答更安全但需平衡可用性。

## 六、常见误区
用模板匹配判断拒答漏掉语义拒绝；未区分不知道与不能。

## 七、与开源书/权威来源对应
Asai 2023 讨论何时停止生成；Lewis 2020 强调来源。

## 八、面试题
如何区分有益的拒答与过度保守？

## 九、演进与趋势
把边界感知作为对齐目标。

## 十、小结
拒答能力是事实系统安全性的重要组成。
