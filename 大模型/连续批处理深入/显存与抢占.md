# 连续批处理显存与抢占

> 对应 KV 显存约束与抢占策略。

## 一、背景与挑战

并发请求 KV 累积超显存；需抢占或拒收。

## 二、核心原理

按 KV 预算准入；超限时抢占低优先级（换出 KV 到 CPU 或丢弃重算）。

## 三、数学形式

准入条件 $\sum_{i\in R} L_i \le C_{kv}$；抢占代价 = 换出/重算成本。

## 四、代码实现

```python
if used_kv + new_req.kv > C:
    preempt(lowest_priority)
```

## 五、与其他对比

- 与 KV缓存优化深入（分页/驱逐）配合管理显存。
- 与 多租户与资源隔离深入 衔接。

## 六、常见误区

- 抢占策略不当致抖动/重算风暴。
- 忽视跨请求 KV 隔离。

## 八、面试题

- 连续批如何控显存？答：按 KV 预算准入+抢占，配合分页管理。

## 九、演进

硬限流 → 抢占换出 → 弹性。

## 十、小结

显存与抢占是连续批高并发稳定的保障。
