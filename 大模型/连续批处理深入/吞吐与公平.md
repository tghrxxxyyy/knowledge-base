# 连续批处理吞吐与公平

> 对应 SLO 与公平性。

## 一、背景与挑战

高吞吐不能以无限拖长尾为代价；需公平与 SLO。

## 二、核心原理

用令牌桶/加权公平在吞吐与延迟间权衡；大请求拆分或限步。

## 三、数学形式

公平指标：各请求完成时间方差；SLO 达标率。

## 四、代码实现

```python
sched = FairScheduler(weights=tenant_weights)
batch = sched.step()
```

## 五、与其他对比

- 与 多租户与资源隔离深入 共享多租户策略。
- 与 推理服务深入 衔接。

## 六、常见误区

- 只追吞吐忽略尾延迟（p99）。
- 权重设置失衡致小租户饿死。

## 八、面试题

- 吞吐与公平如何权衡？答：加权公平+SLO，限制单请求占比。

## 九、演进

无公平 → 加权公平 → SLO 感知。

## 十、小结

连续批需在吞吐、公平、SLO 间系统权衡。
