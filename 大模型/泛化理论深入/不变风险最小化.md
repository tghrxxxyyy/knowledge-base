# 不变风险最小化

> 见「泛化理论深入/泛化理论总览」；Arjovsky et al., *IRM*, 2019。

## 一、背景与挑战

常规经验风险最小化（ERM）在分布偏移（train/test 分布不同）下易失效。

## 二、核心原理

**IRM** 要求学到「跨环境不变」的表示与分类器：即在所有训练环境（数据来源）上，同一个分类器都最优。迫使模型抓本质因果特征而非表面相关。

## 三、数学形式

```
min_Φ Σ_e R_e(Φ) + λ·‖∇_{w|w=1} R_e(Φ·w)‖²
```
w 为固定为 1 的假分类器，约束其在各环境梯度为零。
