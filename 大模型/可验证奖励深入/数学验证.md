# 数学验证（Math Verification）

> 对应 DeepSeekMath 2024；MATH 数据集（Hendrycks et al., 2021）。

## 一、背景与挑战

数学题答案需符号/数值等价判定，非字符串匹配。

## 二、核心原理

抽取最终答案，用符号等价（sympy）或数值采样判定；配合逐步格式奖励；可加过程校验。

## 三、数学形式

等价 $equiv(a,g)=true\iff \exists$ 化简使 $a-g=0$；$r=\mathbb I[equiv]$。

## 四、代码实现

```python
ok = sympy.simplify(a-g)==0
```

## 五、与其他对比

- 与 验证器深入（PRM 过程判）衔接。
- 与 可验证奖励深入 总览互补。

## 六、常见误区

- 字符串匹配误判等价。
- 忽视单位/近似。

## 八、面试题

- 为何用符号等价？答：避免形式不同但等价被错判。

## 九、演进

字符串 → 数值 → 符号等价。

## 十、小结

数学验证靠符号等价，避免表面匹配错误。
