# 代码验证（Code Execution）

> 对应 Chen et al., *CodeX / Execution*, 2021（HumanEval）；RLHF with unit tests。

## 一、背景与挑战

代码正确性须运行验证，单看文本不准。

## 二、核心原理

生成代码在沙箱执行隐藏单测，通过率即奖励；可加测试覆盖、运行时间约束。

## 三、数学形式

$r=\frac{\#通过测试}{\#总测试}\in[0,1]$；或 $r=\mathbb I[全通过]$。

## 四、代码实现

```python
res = sandbox.run(code, tests)
r = res.passed / len(tests)
```

## 五、与其他对比

- 与 验证器深入（结果验证）衔接。
- 与 可验证奖励深入 总览互补。

## 六、常见误区

- 测试弱致过拟合（仅过给定测）。
- 沙箱安全（代码执行风险）。

## 八、面试题

- 代码奖励为何用执行？答：运行测通过率才是真正确信号。

## 九、演进

文本相似 → 单测 → 沙箱执行+覆盖。

## 十、小结

代码验证靠沙箱执行，奖励即测试通过率。
