# 可验证奖励与偏好奖励对比

> 对应 RLVR vs RLHF 讨论（DeepSeekMath 2024）。

## 一、背景与挑战

选型需看任务可验证性与信号质量。

## 二、核心原理

可验证：信号确定、零标注偏、抗黑客（限可判任务）；偏好：覆盖广但贵、有偏、易黑客。常混合用。

## 三、数学形式

混合 $r=\gamma r_{verif}+(1-\gamma)r_{pref}$；$\gamma$ 按任务定。

## 四、代码实现

```python
r = gamma*verif + (1-gamma)*rm(chosen, rejected)
```

## 五、与其他对比

- 与 奖励模型深入（偏好）对照。
- 与 直接偏好优化深入（DPO）可混用。

## 六、常见误区

- 强行验证不可验证任务。
- 混合权重乱设致信号冲突。

## 八、面试题

- 何时用可验证？答：任务有确定性判据（数学/代码/约束）时优先。

## 九、演进

纯偏好 → 纯验证 → 混合。

## 十、小结

可验证与偏好互补，可验证优先、其余用偏好。
