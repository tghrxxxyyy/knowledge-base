# 可验证奖励总览

> 对应 DeepSeek-AI, *DeepSeekMath*, 2024（提出 RLVR：Reinforcement Learning with Verifiable Rewards）。

## 一、背景与挑战

偏好奖励（RM）易被钻空、标注贵且有偏；对能自动判对的任务（数学/代码）可用可验证奖励。

## 二、核心原理

用确定性校验器给奖励（答案匹配/单测通过），强化学习直接优化；避免奖励模型偏差，信号更可靠。

## 三、数学形式

奖励 $r(x,y)=\mathbb I[\text{verify}(y, x)=true]\in\{0,1\}$；目标 $\max_\pi \mathbb E[r]$。

## 四、代码实现

```python
r = 1.0 if check_answer(y, gold) else 0.0
policy.ppo_step(r)
```

## 五、与其他对比

- 与 奖励模型深入（偏好奖励）对照可靠性。
- 与 验证器深入（校验器）衔接。

## 六、常见误区

- 误以为可验证覆盖所有任务（仅限可判）。
- 校验器漏洞致奖励黑客。

## 七、与开源书对应

## 八、面试题

- 可验证奖励优势？答：信号确定、无 RM 偏、抗奖励黑客。

## 九、演进

RM 奖励 → 规则奖励 → RLVR 规模化。

## 十、小结

可验证奖励以确定性校验替代偏好 RM，更可靠。
