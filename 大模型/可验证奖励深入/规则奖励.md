# 规则奖励（Rule-based Rewards）

> 对应 RLVR 实践（格式+答案规则）；与 直接偏好优化深入 对照。

## 一、背景与挑战

如何把“正确”写成可算奖励。

## 二、核心原理

组合规则：格式分（含推理标签）、最终答案匹配（数值/符号）、约束满足；可加部分分（步骤合法）。

## 三、数学形式

$r=\alpha\cdot\text{fmt}(y)+\beta\cdot\mathbb I[ans(y)=gold]$；$\alpha,\beta$ 权重。

## 四、代码实现

```python
fmt = 0.1 if has_tags(y) else 0
ans = 1.0 if parse(y)==gold else 0
```

## 五、与其他对比

- 与 验证器深入（结果校验）衔接。
- 与 奖励模型深入（软奖励）对照。

## 六、常见误区

- 格式分过主导致灌水。
- 答案解析脆弱（多格式）。

## 八、面试题

- 规则奖励组成？答：格式+答案匹配+约束，可部分分。

## 九、演进

二值 → 多规则 → 软硬结合。

## 十、小结

规则奖励靠可解析格式与答案匹配，设计需稳健。
