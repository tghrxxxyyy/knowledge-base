# 序列并行与激活显存

> 对应 Korthikanti et al., 《Reducing Activation Recomputation in Large Transformer Models》, 2022。

## 一、背景与挑战

Transformer 激活主要来自 LayerNorm 输入、dropout 掩码、注意力 softmax 的 QK/PV，随序列线性。

## 二、核心原理

序列并行让这些激活按序列分片存储，单卡仅 $1/t$；配合选择性重计算进一步降峰显存，使 batch/序列可加大。

## 三、数学形式

峰显存 $M_{peak}\approx \frac{b s h L}{t}\cdot c$（每卡序列分片），重计算降系数 $c$。

## 四、代码实现

```python
act = checkpoint(attention_block, q_shard, k_shard, v_shard,
                 use_reentrant=False)     # 分片内重算
```

## 五、与其他对比

- 与 流水线并行深入 重计算互补。
- 与 张量并行深入 切不同维。

## 六、常见误区

- 只切权重不切激活，长序列仍爆。
- 重算覆盖非序列维无效。

## 八、面试题

- SP 降哪些激活？答：LayerNorm 输入、dropout、注意力 QK/PV 等随序列的激活。

## 九、演进

全序列激活 → 序列分片 → 分片重计算。

## 十、小结

序列并行切序列维激活，是长序列训练显存主解。
