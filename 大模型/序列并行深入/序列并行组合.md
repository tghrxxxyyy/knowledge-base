# 序列并行与张量并行组合

> 对应 Megatron-LM 3D 中 TP+SP；Korthikanti et al., 2022。

## 一、背景与挑战

单独 TP 或 SP 都不能覆盖整层显存，需组合。

## 二、核心原理

同一并行组内同时切权重（TP）与序列（SP）：GEMM 用 TP，归一化/注意力纵向用 SP；二者共享同一通信组，仅一次布局转换。

## 三、数学形式

组大小 $t$，权重切片 $1/t$、序列切片 $1/t$；单卡激活 $O(bshL/t)$。

## 四、代码实现

```python
tp_sp_group = init_group(tp_size, sp_size)   # 同一组
y = tp_sp_linear(x_shard, w_shard, tp_sp_group)
```

## 五、与其他对比

- 是 混合并行深入 的 3D 之一维。
- 与 数据并行深入 正交可叠。

## 六、常见误区

- 把 SP 组与 TP 组设错致布局混乱。
- 通信组重叠未优化。

## 八、面试题

- TP 与 SP 为何同组？答：共享通信组、一次布局转换覆盖权重与序列两维。

## 九、演进

独立 → 同组组合 → 自动融合。

## 十、小结

TP+SP 同组组合覆盖整层，是长序列大模型训练标准配置。
