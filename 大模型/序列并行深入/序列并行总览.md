# 序列并行总览

> 对应 Korthikanti et al., 《Efficient Large-Scale Language Model Training on GPU Clusters Using Megatron-LM》, 2022。

## 一、背景与挑战

长序列下 LayerNorm、Dropout、注意力纵向算子的激活随序列长度线性增，张量并行未覆盖。

## 二、核心原理

序列并行沿序列维切分：这些算子逐卡算序列分片、不需全序列；仅在需全序列处（如某些归约）用 all-gather/reduce-scatter，把激活显存从 $O(s)$ 降到 $O(s/t)$。

## 三、数学形式

激活 $A\propto s h$；序列并行后单卡 $A/t$；通信在归约处一次 $all\_gather$ 或 $reduce\_scatter$。

## 四、代码实现

```python
x_shard = split_seq(x, sp_group)         # 沿序列维切
h = layernorm(x_shard)                    # 逐卡局部
y = reduce_scatter(h, sp_group)           # 归约到序列分片
```

## 五、与其他对比

- 与 张量并行深入 互补覆盖整层（TP 切权重、SP 切序列）。
- 是 长上下文训练关键。

## 六、常见误区

- 误把 SP 当 TP 的一种（二者切不同维）。
- 归约点未合并致多余通信。

## 八、面试题

- 序列并行切什么维？答：沿序列长度维切，覆盖 LayerNorm/Dropout 等纵向算子。

## 九、演进

TP 仅 → TP+SP → 与上下文并行组合。

## 十、小结

序列并行沿序列维切分，专治长序列激活显存爆炸。
