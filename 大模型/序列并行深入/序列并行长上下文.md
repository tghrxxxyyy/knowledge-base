# 序列并行与长上下文

> 对应长上下文训练；Korthikanti et al., 2022；context parallelism。

## 一、背景与挑战

序列长度从 2k 到 32k+ 时激活显存主导，单卡放不下。

## 二、核心原理

序列并行把长序列切到多卡，注意力计算需跨卡取 K/V（context parallelism 用 ring/zigzag 交换），使可训序列随卡数线性扩展。

## 三、数学形式

可训序列 $s_{max}\propto t\cdot s_{card}$；注意力复杂度每卡 $O((s/t)^2)$ 但需 $O(s/t)$ 次 KV 交换。

## 四、代码实现

```python
# ring 自注意力：逐块交换 K/V
for _ in range(sp_size):
    attn_block(q_local, k_remote, v_remote)
    k_remote, v_remote = rotate(k_remote, v_remote, sp_group)
```

## 五、与其他对比

- 与 张量并行深入 组合训超长模型。
- 与 FlashAttention 互补省算力。

## 六、常见误区

- KV 交换未重叠通信致空等。
- 序列分片不均致长尾。

序列并行是长上下文训练显存扩展的核心手段。
