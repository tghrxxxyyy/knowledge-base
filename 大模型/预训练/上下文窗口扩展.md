# 上下文窗口扩展

> 对应 RoPE/ALiBi 外推技术与长上下文训练实践（见本系列「旋转位置编码 RoPE」）。

## 一、核心概念

模型训练时的最大序列长度（如 4096）即上下文窗口。推理或继续训练时超越该长度需**位置外推**：

- **位置插值(PI, kaiokendev/NTK)**：将位置索引线性缩放，使训练范围内外推平滑。
- **NTK-aware 缩放**：非线性地在外推与插值间权衡。
- **YaRN / Dynamic NTK**：改进高频分量处理，长文本更稳。
- **ALiBi**：注意力偏置随距离线性衰减，天然支持外推无需位置编码。

## 二、数学形式（线性位置插值）

若原训练长度 `L`，目标 `L' > L`，对位置 `m`：

```
m' = m · (L / L')      # 把新位置压缩回训练范围
```

NTK 把缩放不均匀分配各频率维度。

## 三、关键要点

| 方法 | 是否需重训 | 外推能力 |
|------|-----------|----------|
| PI/NTK | 轻量继续训练 | 中 |
| YaRN | 轻量 | 强 |
| ALiBi | 否 | 强 |
| RoPE 直接外推 | 否但易崩 | 弱 |
