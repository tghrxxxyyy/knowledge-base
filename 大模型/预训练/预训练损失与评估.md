# 预训练损失与评估

> 对应 d2l-zh「语言模型」评估章节与 llm-course「LLM Scientist」评测章节；困惑度定义源自经典语言模型文献。

## 一、背景与挑战

预训练过程中「模型好不好」不能只看 loss 曲线。我们需要既能量化训练进度的**内在指标**（困惑度/交叉熵），又能反映真实能力的**外在指标**（下游基准、人类偏好）。二者的错位（PPL 低但任务弱，或反之）是评估的核心难点。

挑战：
- 训练集与测试集分布漂移导致 PPL 不可比。
- 下游任务众多，单一指标无法概括。
- 评测集污染（contamination）使分数虚高。
- 训练动态本身包含信息：loss 曲线形状、学习率调度、长程缩放行为都能预示最终能力。

因此评估应是「训练期监控 + 训练后基准 + 污染审计」的闭环，而非只看终点一个数。

值得注意的是，PPL 与下游能力经常发生「错位」：一个新模型可能 PPL 更低却在某些推理基准上更差，因为 PPL 只反映训练/验证域内的分布拟合，而下游任务考验的是分布外泛化与知识正确性。评估设计必须为此留足冗余，不能只盯一个指标。

## 二、核心原理

- **困惑度 PPL**：衡量模型对测试分布的「惊讶度」，$PPL=2^{H}=\exp(H)$，$H$ 为平均交叉熵；越低越流利。
- **训练损失曲线**：应平滑下降并趋于平台；剧烈抖动常因 batch 噪声、LR 不当或数据质量波动。
- **下游零样本/少样本**：真实能力需在基准（如 MMLU、HellaSwag）上验证，PPL 低不保证任务强。
- **评测污染检测**：用 n-gram 重叠检测训练集是否泄露测试样本。
- **多维能力画像**：除准确率外，还应看鲁棒性、公平性、毒性、指令遵循等，避免单点指标误导。
- **校准与置信度**：模型对错误答案的置信度（校准误差）也是重要质量信号，过度自信的错误比「不确定」更危险，应在评估中单独报告。

## 三、形式化与数学基础

对长度为 $T$ 的测试序列，困惑度为：

$$
\text{PPL}= \exp\!\left(-\frac{1}{T}\sum_{t=1}^{T}\log P(x_t\mid x_{<t})\right)=\exp(H)
$$

若以 2 为底，则 $\text{PPL}=2^{H}$，此时 $H$ 为交叉熵比特数。当模型退化到「均匀猜测」$V$ 个 token 时，$\text{PPL}\to V$。

## 四、代码实现

用 Transformers 计算困惑度：

```python
import torch, math
from transformers import AutoModelForCausalLM, AutoTokenizer

model = AutoModelForCausalLM.from_pretrained("gpt2")
tok = AutoTokenizer.from_pretrained("gpt2")
enc = tok("The quick brown fox", return_tensors="pt")
with torch.no_grad():
    loss = model(**enc, labels=enc.input_ids).loss   # 即平均负对数似然
ppl = math.exp(loss.item())
print("PPL =", ppl)
```

## 五、与其他技术对比

| 指标 | 含义 | 局限 |
|------|------|------|
| PPL | 内在流利度 | 不直接等于任务能力 |
| 下游准确率 | 实际能力 | 受污染/分布影响 |
| 损失平台 | 数据/容量瓶颈信号 | 需结合数据判断 |

## 六、常见误区

- **PPL 越低模型越聪明**：PPL 只衡量分布拟合，训练域内的流畅不代表推理/知识正确。
- **跨模型直接比 PPL**：不同词表、不同分词下 token 数不可比，需换算到同粒度。
- **忽视评测污染**：测试题出现在训练数据里，分数虚高。
- **只看最终 loss**：应监控验证 loss 是否过拟合、是否平台。

## 九、演进与趋势

- **从单一 PPL 到多维评测**：能力、鲁棒性、公平、安全并重（如 HELM、OpenCompass）。
- **自动化评测（eval-as-a-service）**：标准化榜单减少人为偏差。
- **污染检测常态化**：发布模型必报污染分析。
- **过程指标**：不仅看终点 loss，也看训练动态与缩放行为。
- **训练期早停与筛选**：用中期 checkpoint 在小基准上的表现预测最终能力，降低全量训练浪费。
- **小模型评测的杠杆**：用 0.1B~1B 代理模型快速筛选数据配比与超参，再把结论迁移到大模型，显著降低评测成本。
- **可复现评测协议**：固定随机种子、提示词模板与解码参数，否则同一模型分数在不同跑批下波动会掩盖真实差异。

## 十、小结

预训练评估是「内在指标（PPL/损失）+ 外在指标（下游基准）+ 污染检测」的组合。PPL 提供训练期直觉但不可越界代表能力；最终能力必须在规范基准上验证。把评估做成闭环，才能在训练早期就发现方向性错误，避免算力打水漂。一个常被忽视的细节是：验证集应与训练集同源但时间窗错开，否则极易因采样式分布重叠而给出过于乐观的估计。具体基准与口径以官方最新文档为准。
