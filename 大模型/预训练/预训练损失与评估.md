# 预训练损失与评估

> 对应 d2l-zh 与 llm-course。困惑度(Perplexity)是语言模型核心内在指标。

## 一、核心概念

- **困惑度(PPL)**：`PPL = exp(-1/N Σ log P(x_t|x_{<t})) = 2^{H}`，越低越好。`H` 为交叉熵比特数。
- **训练损失曲线**：应平滑下降并趋于平台；剧烈抖动常因 batch 噪声或 LR 问题。
- **下游零样本/少样本**：真正能力需在基准上验证，PPL 低不保证任务强。

## 二、数学形式

```
PPL = exp( L_CE ) ，L_CE 为平均交叉熵
```

## 三、关键要点

| 指标 | 含义 |
|------|------|
| PPL | 内在流利度 |
| 下游准确率 | 实际能力 |
| 损失平台 | 数据/容量瓶颈 |

## 四、面试题

- 困惑度与交叉熵的关系？PPL 下降但任务准确率不升可能原因？
