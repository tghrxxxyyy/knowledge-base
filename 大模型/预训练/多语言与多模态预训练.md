# 多语言预训练

> 对应 mT5（Xue et al., 2020）、BLOOM（BigScience, 2022）等多语言工作，以及 CLIP（Radford et al., 2021）、LLaVA（Liu et al., 2023）等多模态工作；亦见 llm-course 与 d2l-zh「多国语」章节。本篇同时覆盖多模态预训练要点。

## 一、背景与挑战

预训练早期聚焦单语（英语）网页文本。当模型要服务全球用户或理解图像/音频时，需要两类扩展：**多语言**（覆盖数百种自然语言）与**多模态**（对齐文本与图像/语音等信号）。

挑战：
- **多语言**：低资源语言 token 稀疏、语料少；高资源语言易「淹没」低资源语言；共享词表下稀有语言子词过长。
- **多模态**：异构信号的表示空间不同，需对齐（alignment）；图文对噪声大；训练目标与纯文本不同。

## 二、核心原理

**多语言预训练**通常共享一个子词词表（SentencePiece/Unigram），在混合多语语料上做 MLM 或 CLM。跨语言迁移源于「共享子词 + 共享参数」使语义在向量空间对齐，从而实现零样本跨语言任务。采样温度 `n_lang^p`（`p<1`）提升低资源语言权重。

**多模态预训练**则构建「编码器-连接器-语言模型」架构：
- 视觉编码器（ViT）提取图像表示；
- 一个投影/连接器（如 MLP、Q-Former）把图像表示映射到 LLM 的词嵌入空间；
- LLM 在「图文对」或「指令」上训练，学会以文本生成回应视觉输入。

## 三、形式化与数学基础

多语言采样：设语言 $l$ 的语料量为 $n_l$，采样概率

$$
P(l)\propto n_l^{\alpha},\quad \alpha<1
$$

$\alpha$ 越小，低资源语言被提权越多。

多模态对比预训练（CLIP 式）最大化正样本图文对相似度、最小化负样本：

$$
\mathcal{L}=-\log\frac{\exp(\langle E_t(t),E_i(i)\rangle/\tau)}{\sum_{j}\exp(\langle E_t(t),E_i(i_j)\rangle/\tau)}
$$

其中 $E_t, E_i$ 分别为文本与图像编码器，$\tau$ 为温度。

## 四、代码实现

多语言分词（SentencePiece / mT5）：

```python
from transformers import AutoTokenizer
tok = AutoTokenizer.from_pretrained("google/mt5-base")
print(tok("Hello 世界 こんにちは", return_tensors="pt").input_ids.shape)
# 共享词表下不同语言共享子词单元，实现跨语言对齐
```

多模态连接器（LLaVA 风格，伪代码）：

```python
image_feats = vision_encoder(images)        # (B, P, d_v)
proj = nn.Linear(d_v, d_llm)
embeds = proj(image_feats)                  # 映射到 LLM 嵌入空间
inputs_embeds = torch.cat([embeds, text_embeds], dim=1)
logits = llm(inputs_embeds=inputs_embeds)
```

## 五、与其他技术对比

| 维度 | 单语预训练 | 多语言预训练 | 多模态预训练 |
|------|-----------|-------------|-------------|
| 数据 | 单语文本 | 多语文本 | 图文/音文对 |
| 词表 | 单语 | 共享子词 | 文本+视觉编码器 |
| 零样本跨语言 | 无 | 有 | 视对齐而定 |
| 主要难点 | 规模 | 语料失衡 | 模态对齐 |

## 六、常见误区

- **以为共享词表自然解决低资源问题**：不调采样权重，低资源语言仍被淹没。
- **多模态=把图像当文本拼进去**：需要专门的连接器与对齐训练，否则 LLM 读不懂图像特征。
- **用纯文本评测多模态模型**：应在图文基准（如 VQA）上验证。
- **忽视多语许可证与隐私合规**：多语爬取数据风险更高。

## 九、演进与趋势

- **多语言走向均衡与本地化**：更强调低资源语言与方言覆盖、文化适配。
- **多模态扩展到视频/音频/3D**：统一的多模态 LLM（任意输入模态）成为热点。
- **原生多模态训练**：从「先文本后对齐」走向训练期即融合多模态信号。
- **多语+多模态联合**：跨语言图文对齐，支撑全球多语视觉理解。

## 十、小结

多语言预训练靠共享词表与采样调权实现跨语言迁移；多模态预训练靠「编码器+连接器+LLM」把异构信号对齐到统一表示空间。两者共同拓展了纯文本 LLM 的边界，但具体架构、词表与训练配比以官方最新文档为准。
