# 大规模语料与数据管线

> 对应 llm-course「LLM Scientist」数据准备章节与《Dive into Deep Learning》预训练数据章节；去重结论见 Lee et al. (2022)。

## 一、背景与挑战

预训练数据规模以 **Tokens** 计而非样本数。现代 7B~70B 模型通常在 1T~15T tokens 量级训练。数据质量与配比往往比单纯堆量更决定最终能力。挑战：

- **规模与覆盖**：需跨网页、书籍、代码、学术、多语等多域。
- **噪声与毒性**：爬虫语料含垃圾、重复、有害与隐私内容。
- **去重**：重复样本导致过拟合与困惑度上升。
- **配比**：不同领域权重影响模型能力偏向（如代码占比提升增强推理）。
- **合规**：许可证、PII 与版权风险。

## 二、核心原理

数据管线是一串**可复现、可审计**的处理阶段：

1. **收集**：Common Crawl / C4 / RefinedWeb / RedPajama（网页），Books3 / Gutenberg（书籍），The Stack / GitHub（代码），arXiv / PubMed（学术）。
2. **去重**：URL 级、文档级（MinHash/SimHash）、子串级。
3. **质量过滤**：启发式（标点比例、符号比、困惑度过滤器）或分类器（如训练质量判别模型）。
4. **毒性/PII 过滤**：去毒、去个人敏感信息。
5. **混合调度**：curriculum 或 domain weighting 控制各域比例。

## 三、形式化与数学基础

数据混合可视为在领域集合 $\mathcal{D}=\{D_1,\dots,D_k\}$ 上定义采样权重 $w_i$（$\sum w_i=1$），每个 batch 按权重抽取：

$$
x\sim \sum_{i=1}^{k} w_i\, p_i(x)
$$

其中 $p_i$ 为第 $i$ 个域的数据分布。优化的目标是使下游综合能力 $M$ 最大：

$$
\max_{\{w_i\}} M\Big(\text{Train}\big(\{w_i\}\big)\Big)
$$

去重对测试困惑度的改善由 Lee et al. 量化：去除重复后模型在保留集上困惑度显著下降、且更不易记忆训练样本。

## 四、代码实现

文档级去重（MinHash + LSH 概要）：

```python
import datasketch

def minhash_doc(text, num_perm=128):
    m = datasketch.MinHash(num_perm=num_perm)
    for ngram in _ngrams(text, 5):     # 以 5-gram 为单位
        m.update(ngram.encode("utf8"))
    return m

# 用 datasketch.MinHashLSH 将相似文档分到同一桶，仅保留代表样本
lsh = datasketch.MinHashLSH(threshold=0.8)
# lsh.insert(key, minhash); lsh.query(minhash) -> 查重
```

实际工业管线（如 RedPajama、RefinedWeb）会以分布式方式做 URL/文档级去重与质量打分。

## 五、与其他技术对比

| 阶段 | 手段 | 失败后果 |
|------|------|----------|
| 收集 | 多源爬取 | 覆盖不足 |
| 去重 | MinHash/SimHash | 过拟合、记忆泄露 |
| 质量过滤 | 启发式/分类器 | 噪声拉低能力 |
| 配比 | 域权重 | 能力偏向失衡 |

## 六、常见误区

- **「越多越好的脏数据」优于精选数据**：质量常比数量更重要，噪声会损害能力。
- **忽视许可证与隐私合规**：PII 泄露与版权纠纷是上线红线。
- **全程不固定 tokenizer**：中途换词表会造成词表错位、数据分布漂移。
- **去重只做 URL 级**：内容搬运站会绕过 URL 去重，需文档级语义去重。

## 九、演进与趋势

- **从「爬全量」到「精选合成」**：越来越多工作用模型对数据打分、筛选甚至合成高质量样本。
- **数据配比自动化**：用小规模实验外推最优域权重。
- **合规前置**：许可证与隐私过滤成为管线第一道关卡。
- **长上下文语料建设**：加入长文档、长代码库以支撑长上下文训练。

## 十、小结

数据管线是预训练的「地基」：收集→去重→质量过滤→毒性/PII 过滤→混合配比，每一步都直接影响最终能力。质量优先于数量、配比决定能力偏向、合规决定能否上线。具体数据集与比例以官方最新文档为准。
