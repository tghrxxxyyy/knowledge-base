# 大规模语料与数据管线

> 对应 llm-course「LLM Scientist」数据准备章节与《Dive into Deep Learning》预训练数据章节。

## 一、核心概念

预训练数据规模常以**Tokens**计（非样本数）。现代 7B~70B 模型通常在 1T~15T tokens 上训练。数据来源：

- 网页文本（Common Crawl / C4 / RefinedWeb / RedPajama）
- 书籍（Books3 / Gutenberg）
- 代码（GitHub / The Stack）
- 学术（arXiv / PubMed）
- 多语/平行语料

数据管线关键步骤：**去重(URL/文档级) → 质量过滤(启发式/分类器) → 毒性/PII 过滤 → 混合比例调度( curriculum/domain weighting )**。

## 二、关键实践

- **重复数据危害**：Lee et al. (2022) 指出 50% 重复可使模型在测试集上过拟合、困惑度上升。
- **数据混合**：不同领域按权重采样（如代码占比提升可增强推理）。
- **分词一致性**：全程同一 tokenizer，避免词表错位。

## 三、关键要点

| 阶段 | 目标 |
|------|------|
| 收集 | 覆盖广 |
| 去重 | 防过拟合 |
| 过滤 | 提质量 |
| 配比 | 控能力偏向 |

## 四、常见误区

- 认为「越多越好的脏数据」优于精选数据——质量常比数量更重要。
- 忽视许可证与隐私合规（PII 泄露风险）。
