# 持续预训练与领域自适应

> 对应 llm-course「Model Fine-tuning」与领域自适应预训练（Gururangan et al., 2020, DAPT/TAPT）；亦见持续学习（catastrophic forgetting）相关文献。

## 一、背景与挑战

通用预训练模型在医疗、法律、金融、代码等垂直领域往往知识不足、术语不熟。直接做 SFT 数据有限且易过拟合。更稳妥的路径是：**在领域语料上继续预训练（continued / domain-adaptive pretraining, DAPT）**，先注入领域知识，再做指令/SFT 对齐。

核心挑战：
- **灾难性遗忘**：继续训练冲淡通用能力。
- **数据配比**：纯领域数据导致分布漂移。
- **学习率与步数**：过大/过长会破坏已学表示。
- **与 SFT 的顺序**：先领域继续预训练还是先 SFT 需权衡。

## 二、核心原理

- **学习率**：通常用较小 LR（如原预训练的 1/10~1/5），使参数在已学最优附近「微调」而非重学。
- **数据 replay 混合**：在领域语料中混入部分通用数据，防止退化与遗忘。
- **两阶段范式**：先领域继续预训练（学知识），再做 SFT/指令微调（学格式与对齐）。
- **TAPT（任务自适应）**：在下游任务无标注文本上继续预训练，进一步贴近任务分布。

## 三、形式化与数学基础

持续预训练可视为在通用最优参数 $\theta^*$ 附近，对领域分布 $\mathcal{D}_{\text{dom}}$ 做进一步最小化：

$$
\theta' = \arg\min_{\theta}\; \mathbb{E}_{x\sim \mathcal{D}_{\text{mix}}}[-\log P_\theta(x)]
$$

其中混合分布

$$
\mathcal{D}_{\text{mix}} = \lambda\,\mathcal{D}_{\text{dom}} + (1-\lambda)\,\mathcal{D}_{\text{gen}}
$$

$\lambda$ 为领域数据占比（如 0.7）。较小的学习率 $\eta\ll\eta_{\text{pre}}$ 保证 $\theta'$ 不远离 $\theta^*$，缓解遗忘。

## 四、代码实现

以 HuggingFace Trainer 做领域继续预训练（要点示意）：

```python
from transformers import Trainer, TrainingArguments, AutoModelForCausalLM

model = AutoModelForCausalLM.from_pretrained("base-model")
args = TrainingArguments(
    learning_rate=2e-5,            # 约为预训练的 1/5~1/10
    per_device_train_batch_size=8,
    num_train_epochs=1,            # 领域语料上轻量过一遍
    gradient_accumulation_steps=4,
)
trainer = Trainer(model=model, args=args, train_dataset=domain_dataset)
trainer.train()                    # 之后再做 SFT
```

## 五、与其他技术对比

| 策略 | 目的 | 风险 |
|------|------|------|
| 小 LR | 防遗忘 | 学得太慢 |
| 数据 replay | 保通用能力 | 领域浓度被稀释 |
| 先 DAPT 后 SFT | 知识+对齐 | 流程更长 |
| 直接 SFT | 快 | 领域知识不足 |

## 六、常见误区

- **只喂领域数据**：缺乏 replay，通用能力退化、分布漂移。
- **用原预训练大 LR**：破坏已学表示，等同重训。
- **把持续预训练当 SFT**：前者学「知识分布」，后者学「任务格式」，目标不同。
- **忽略领域数据质量**：领域脏数据比通用脏数据危害更集中。

## 九、演进与趋势

- **从整模继续训练到参数高效**：用 LoRA/适配器做领域适配，减少遗忘与成本。
- **课程式混合**：先通用后领域，或动态调节 $\lambda$。
- **长上下文领域预训练**：在领域长文档上同时扩展窗口。
- **合成领域数据**：用强模型造领域语料再继续训练。
- **评测驱动的停止**：监控领域基准而非仅看 loss，避免「训过头」导致过拟合领域噪声。

## 十、小结

持续预训练是「通用基座 → 领域知识 → 任务对齐」的关键一环。以小 LR + 数据 replay + 两阶段（DAPT 后 SFT）为主线，可在注入领域知识的同时守住通用能力。具体 LR、步数与配比以官方最新文档与实验为准。实践中建议先用小规模「探针实验」确定 replay 比例与学习率区间，再放量到全量领域语料，避免在宝贵算力上盲目试错。
