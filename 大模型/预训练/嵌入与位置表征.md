# 嵌入与位置表征 Embeddings

> 对应 d2l-zh「词嵌入」与 Transformer 位置编码（Vaswani et al., 2017；RoPE 见 Su et al., 2021）；详见本系列「位置编码」与「旋转位置编码 RoPE」。

## 一、背景与挑战

Transformer 本身是**置换不变**的：打乱输入顺序，注意力输出只按位置重排、语义不变。要让模型感知「词的顺序」，必须把位置信息注入。此外，token 本身需从 id 映射到稠密向量。问题在于：

- 如何把离散 token 变成可学习的连续表示（token embedding）。
- 如何把「顺序」编码进表示（位置表征）。
- 如何在长序列、外推场景下保持位置表征的有效性。

## 二、核心原理

- **Token Embedding**：把 token id 映射为 $d_{\text{model}}$ 维稠密向量，可学习矩阵 $E\in\mathbb{R}^{V\times d}$。
- **位置编码**：叠加顺序信息，形式有绝对（正弦/Vaswani）、可学习绝对、相对偏置、RoPE 等。
- **段/类型嵌入（BERT）**：区分句子 A/B，扩成 `token emb + segment emb + pos emb`。
- **现代大模型**：通常用可学习 token embedding + RoPE（旋转位置，不在 embedding 加绝对位置）。

最终输入表示（以绝对位置为例）：

$$
h_0 = \text{Embedding}(x) + \text{PE}(pos)
$$

## 三、形式化与数学基础

正弦绝对位置编码（Vaswani 2017），对位置 $pos$ 与维度 $i$：

$$
\text{PE}_{(pos,2i)}=\sin\left(\frac{pos}{10000^{2i/d}}\right),\quad
\text{PE}_{(pos,2i+1)}=\cos\left(\frac{pos}{10000^{2i/d}}\right)
$$

RoPE 则把位置信息以旋转矩阵注入查询/键：

$$
q_m=R_{\Theta,m}^d q,\quad k_j=R_{\Theta,j}^d k
$$

其内积仅依赖相对位置 $m-j$，天然支持相对位置与外推改造。

## 四、代码实现

可学习 token embedding + 绝对位置（PyTorch）：

```python
import torch.nn as nn
emb = nn.Embedding(num_embeddings=32000, embedding_dim=4096)
pos = nn.Parameter(torch.zeros(1, 1024, 4096))   # 可学习绝对位置
x = torch.randint(0, 32000, (2, 128))
h = emb(x) + pos[:, :128, :]                       # (2,128,4096)
# RoPE 系模型则改为在 attention 内部对 q,k 做旋转，见 RoPE 文档
```

## 五、与其他技术对比

| 项 | 维度 | 是否可学习 | 说明 |
|----|------|-----------|------|
| token emb | $V\times d$ | 是 | 词表映射 |
| 绝对正弦 PE | $T\times d$ | 否 | 固定频率 |
| 可学习绝对 PE | $T\times d$ | 是 | 受窗口限制 |
| RoPE | 融入 q,k | 否 | 相对、可外推 |

## 六、常见误区

- **Embedding 层参数量**：$V\times d$，词表大时占相当比例，常与大模型输出层共享权重以省参。
- **位置编码加在哪**：RoPE 在 attention 内旋转 q,k；绝对编码常加在输入 embedding 上。
- **以为注意力自带顺序感**：若无位置信号，Transformer 对顺序无感知。
- **外推时绝对可学习 PE 越界**：超出训练长度索引即失效，需用 RoPE/ALiBi 类。

## 九、演进与趋势

- **从绝对到相对/RoPE**：相对位置与外推性成为主流选择。
- **位置与注意力耦合**：RoPE 在 attention 内部施加，减少独立位置向量。
- **长上下文下的位置表征**：NTK/YaRN 等改造均作用在位置表征的频率维度。
- **多模态位置**：图像/视频的 2D/3D 位置编码（如 RoPE 的扩展）成为研究热点。
- **无位置编码的探索**：部分研究尝试用更弱的归纳偏置或学习式相对位置，检验位置信号是否可被数据自身补偿。

## 十、小结

嵌入与位置表征是 Transformer 输入的两端：token embedding 负责「是什么」，位置表征负责「在哪/什么顺序」。现代大模型普遍采用可学习 token embedding + RoPE，兼顾表达力与外推性。具体实现以官方最新文档为准。
