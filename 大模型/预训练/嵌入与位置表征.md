# 嵌入与位置表征 Embeddings

> 对应 d2l-zh「词嵌入」与 Transformer 位置编码（见本系列「位置编码」）。

## 一、核心概念

- **Token Embedding**：把 token id 映射为 `d_model` 维稠密向量，可学习矩阵 `E ∈ ℝ^{V×d}`。
- **位置编码**：叠加顺序信息（绝对/相对/RoPE，见专门文档）。
- **段/类型嵌入**(BERT)：区分句子 A/B。
- **可学习 vs 固定**：现代大模型多用可学习 token embedding + RoPE。

## 二、数学形式

输入表示：

```
h_0 = Embedding(x) + PE(pos)
```

其中 `Embedding(x)_i = E[x_i, :]`。

## 三、代码实现

```python
import torch.nn as nn
emb = nn.Embedding(num_embeddings=32000, embedding_dim=4096)
x = torch.randint(0, 32000, (2, 128))
h = emb(x)                       # (2,128,4096)
# 再加 RoPE 处理后的位置信号（见 RoPE 文档）
```

## 四、关键要点

| 项 | 维度 | 说明 |
|----|------|------|
| token emb | `V×d` | 可学习 |
| pos enc | `T×d` | 顺序 |
| type emb | `2×d` | 句子区分 |
