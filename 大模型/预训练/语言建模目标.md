# 语言建模目标 Language Modeling Objectives

> 对应 d2l-zh「语言模型」与 llm-course「LLM Fundamentals」。预训练目标决定了模型学到的结构知识。

## 一、核心概念

语言模型学习序列的概率分布 `P(x_1,...,x_T)`。两大主流目标：

- **自回归(AR) / 因果语言建模(CLM)**：`P(x_t | x_{<t})`。GPT 系列采用，适合生成。
- **掩码语言建模(MLM)**：随机遮盖部分 token，预测被遮盖者。BERT 采用，适合理解、双向。

## 二、数学形式

自回归对数似然（训练目标，负对数似然）：

```
L = - Σ_t log P(x_t | x_1, ..., x_{t-1}; θ)
```

MLM 目标：

```
L_MLM = - Σ_{i∈masked} log P(x_i | x_{\\masked})
```

## 三、代码实现（自回归损失）

```python
import torch.nn.functional as F
# logits: (B, T, V) 为各位置对下一 token 的预测；labels 为右移一位
loss = F.cross_entropy(logits.view(-1, V), labels.view(-1))
```

## 四、关键要点

| 目标 | 代表 | 方向性 | 典型任务 |
|------|------|--------|----------|
| CLM | GPT | 单向 | 生成 |
| MLM | BERT | 双向 | 分类/NLU |
| Prefix/ULM | T5 | 前缀 | Seq2Seq |

## 五、常见误区

- 把 MLM 用于生成任务，因训练/推理不一致而效果差。
- 自回归评测时未做「teacher forcing → 自回归」的差异处理。
