# 语言建模目标 Language Modeling Objectives

> 对应 d2l-zh「语言模型」与 llm-course「LLM Fundamentals」；目标设计源自 Transformer（Vaswani et al., 2017）、BERT（Devlin et al., 2018）、GPT（Radford et al., 2018）与 T5（Raffel et al., 2019）。

## 一、背景与挑战

预训练目标决定了模型从数据中学到「什么结构」。不同目标塑造不同的归纳偏置：单向生成适合续写，双向理解适合分类，前缀式适合翻译/摘要。选型直接影响下游任务适配方式与微调成本。

核心矛盾：**训练目标 ≠ 最终任务**。自回归训练优化的是「下一个 token」，而用户要的是「正确回答」，二者需要 SFT/RLHF 桥接。

## 二、核心原理

- **自回归 AR / 因果语言建模 CLM**：建模 $P(x_t\mid x_{<t})$，GPT 系列采用，单向、适合生成。
- **掩码语言建模 MLM**：随机遮盖部分 token 后预测，BERT 采用，双向、适合理解。
- **前缀/_seq2seq（T5/ULM）**：输入前缀、输出后缀，统一为「文本到文本」。
- **去噪自编码（BART）**：对输入加噪、重建原文本，兼顾理解与生成。

## 三、形式化与数学基础

自回归负对数似然（训练目标）：

$$
\mathcal{L}_{\text{AR}}=-\sum_{t=1}^{T}\log P_\theta(x_t\mid x_{<t})
$$

掩码语言建模只对遮盖位置求和：

$$
\mathcal{L}_{\text{MLM}}=-\sum_{i\in\mathcal{M}}\log P_\theta(x_i\mid x_{\setminus\mathcal{M}})
$$

困惑度与交叉熵关系（平均交叉熵 $H$）：

$$
\text{PPL}=2^{H}=\exp(H)
$$

## 四、代码实现

自回归损失（因果掩码）：

```python
import torch.nn.functional as F
# logits: (B, T, V) 为各位置对下一 token 的预测；labels 为右移一位
loss = F.cross_entropy(logits.view(-1, V), labels.view(-1))
```

MLM 掩码（以 BERT 风格为例）：

```python
import torch
mask = (torch.rand(input_ids.shape) < 0.15)   # 15% 概率遮盖
labels = input_ids.masked_fill(~mask, -100)   # 仅对遮盖位算损失
input_ids = input_ids.masked_fill(mask, mask_token_id)
```

## 五、与其他技术对比

| 目标 | 代表 | 方向性 | 典型任务 | 可否直接生成 |
|------|------|--------|----------|-------------|
| CLM | GPT | 单向 | 生成/续写 | 可 |
| MLM | BERT | 双向 | 分类/NLU | 否 |
| Prefix/ULM | T5 | 前缀 | Seq2Seq | 可 |
| Denoising | BART | 双向 | 重写/翻译 | 可 |

## 六、常见误区

- **把 MLM 模型直接用于生成**：训练/推理不一致，需改为自回归或 seq2seq。
- **忽视 teacher forcing 与自回归的差异**：训练用真值前缀，推理用自身预测，会暴露分布偏差。
- **以为 CLM 必然「更聪明」**：目标只是预训练信号，最终能力还取决于数据与对齐。
- **困惑度低＝任务强**：PPL 仅衡量分布拟合，不直接等价于下游准确率。

## 九、演进与趋势

- **从「单一目标」到「多目标混合」**：现代预训练常混合 CLM、填空、去噪以提升鲁棒性。
- **指令/对话目标前置**：直接在预训练期融入指令格式（如 FLAN、GPT-3 后的指令化）。
- **目标与对齐统一**：SFT/RLHF 可视为在预训练目标之上的「任务目标」精修。

## 十、小结

语言建模目标塑造了模型的归纳偏置：CLM 偏生成、MLM 偏理解、前缀式偏转换。工程落地时常先用 CLM 做基座，再以 SFT/RLHF 把「预测下一个词」对齐到「完成用户任务」。具体目标组合以官方最新文档为准。
