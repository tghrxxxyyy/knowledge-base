# 混合精度下的优化器状态

> 对应 Micikevicius18（FP32 master/状态）；8-bit Adam（Dettmers et al., 2022）。

## 一、背景与挑战

把动量/二阶矩存为 FP16 可省显存，但因其值跨步累积且常很小，低精度舍入会显著漂移，甚至方向反转。

折中：状态用 FP32（或 8-bit 量化）保存，仅参数/激活用低精度。

## 二、核心原理

标准做法：优化器状态与主权重均 FP32；8-bit 优化器（如 bitsandbytes）对状态做分块量化+动态范围，省显存且控误差。

关键在于量化误差不随步数无界累积（每步去量化-更新-再量化）。

## 三、数学形式

状态更新在 FP32 进行：$m\leftarrow\beta_1 m+(1-\beta_1)g$；仅存储时量化 $\tilde m=Q(m)$。

## 四、代码实现

```python
from bitsandbytes.optim import AdamW8bit
opt = AdamW8bit(model.parameters(), lr=1e-4)   # 8-bit 动量/二阶矩
```

## 五、与其他对比

- 与 master权重 衔接，二者同属优化器侧 FP32 保持。
- 与 混合精度溢出检测深入 总览呼应。
- 与 优化器数值总览 衔接，状态精度是核心变量。

## 六、常见误区

- 把全部状态无脑 FP16，累积漂移。
- 8-bit 状态未块归一化，动态范围错。
- 误以为省显存必损精度（量化可兼得）。

## 八、面试题

- 为何状态不宜直接 FP16？答：长期累积的小量被舍入，方向漂移甚至反转。
- 8-bit 优化器如何保精度？答：块归一化量化 + 每步去量化更新，误差不无界累积。

## 九、演进

全 FP32 状态 → FP32 master → 8-bit 量化状态。

## 十、小结

优化器状态精度是混合精度训练的稳定核心，FP32 或量化保存为首选。
