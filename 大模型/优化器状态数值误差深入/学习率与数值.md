# 学习率与数值误差

> 对应 学习率 warmup（Vaswani17）；LR 与数值稳定的交互。

## 一、背景与挑战

训练初期参数未稳定，过大学习率使更新步长超出合理范围，触发溢出/发散。warmup 通过小步起步平滑过渡。

学习率也与优化器状态误差相互作用：大 LR 放大力误差。

## 二、核心原理

warmup：前若干步线性升 LR 到峰值，再按 schedule 衰减；避免初期大步破坏已较脆弱的数值平衡。

余弦/线性衰减配合，长训更稳定。

## 三、数学形式

$w_{t+1}=w_t-\eta_t\frac{\hat m_t}{\sqrt{\hat v_t}+\epsilon}$；warmup 使 $\eta_t$ 从 $\eta_0\ll\eta_{peak}$ 线性升。

## 四、代码实现

```python
from torch.optim.lr_scheduler import LinearLR, CosineAnnealingLR
sched = LambdaLR(opt, lr_lambda=warmup_lambda)
```

## 五、与其他对比

- 与 优化器状态数值误差深入 总览衔接，LR 放大状态误差。
- 与 梯度爆炸机理 互补，大 LR 加剧爆炸。
- 与 训练发散诊断与恢复深入 衔接，LR 是发散主因之一。

## 六、常见误区

- warmup 过长拖慢、过短仍不稳。
- 峰值 LR 与 batch size 不匹配（线性缩放法则）。
- 衰减到底仍用较大 LR，末段抖动。

## 八、面试题

- 为何要 warmup？答：初期参数不稳，小 LR 防大步溢出/发散，平滑进入主训练。
- LR 如何影响数值误差？答：大 LR 放大优化器状态与梯度的数值误差，易发散。

## 九、演进

常数 LR → step decay → warmup+余弦。

## 十、小结

学习率通过 warmup 与优化器误差耦合，是数值稳定的调度旋钮。
