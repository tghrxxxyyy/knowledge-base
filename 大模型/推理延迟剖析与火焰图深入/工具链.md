# 推理延迟剖析工具链

> 对应 Nsight Systems / Nsight Compute / PyTorch Profiler / 火焰图。

## 一、背景与挑战

工具多、层次不同，需按问题选对工具。

## 二、核心原理

Nsight Systems 看时间线与 GPU/CPU 重叠（系统级）；Nsight Compute 看单 kernel 微架构；PyTorch Profiler 出算子级表与火焰图；perf 出 CPU 火焰图。

## 三、数学形式

无单一公式；以采样/埋点统计耗时分布与相关性。

## 四、代码实现

```python
with torch.profiler.profile() as p:
    generate(req)
print(p.key_averages().table())
```

## 五、与其他对比

- 与 CUDA事件计时：Profiler 内含事件计时更方便。
- 与 Triton内核自动调优深入：ncu 验证调优效果。

## 六、常见误区

- 同时开多 profiler 致相互干扰。
- 在调试/编译态剖析失真。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course
- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 系统级 vs 微架构级工具？答：Nsight Systems 看重叠/时间线，ncu 看单 kernel 细节。

## 九、演进

单工具 → 组合 → 自动化建议。

## 十、小结

按层次选 profiler：系统时间线、微架构、算子表、火焰图组合使用。
