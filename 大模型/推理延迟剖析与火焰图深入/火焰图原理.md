# 火焰图原理

> 对应 Brendan Gregg 火焰图（CPU/GPU 栈采样可视化）。

## 一、背景与挑战

调用栈深、函数多，文本 profiler 难读；需可视化看占比与调用关系。

## 二、核心原理

火焰图横轴为采样耗时占比（未必时间序），纵轴为调用栈深度；栈帧越宽占 CPU/GPU 越久；点击可下钻，看自顶向下热点路径。

## 三、数学形式

帧宽 $\propto \frac{\text{samples}(f)}{\text{total}}$；父子关系由栈层级表达。

## 四、代码实现

```python
# 采集栈 -> 折叠 -> flamegraph.pl
perf script | stackcollapse | flamegraph.pl > f.svg
```

## 五、与其他对比

- 与 推理延迟剖析与火焰图深入 总览：火焰图是核心工具。
- 与 Triton内核自动调优深入：内核级帧看 tile 效率。

## 六、常见误区

- 横轴当时间轴误读顺序。
- 忽略采样频率致小函数漏采。

## 八、面试题

## 九、演进

文本报告 → 折叠栈 → 交互火焰图。

## 十、小结

火焰图以栈宽直观呈现热点，是性能剖析的标准可视化。
