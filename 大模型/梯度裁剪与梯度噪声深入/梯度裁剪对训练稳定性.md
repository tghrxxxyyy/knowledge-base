# 梯度裁剪对训练稳定性

> 对应 pytorch/pytorch `clip_grad_norm_` 与 huggingface/transformers 训练脚本。

## 一、背景与挑战
大模型混合精度下，偶发异常样本会产生超大梯度，直接 step 会破坏参数，甚至产生 NaN。

## 二、核心原理
裁剪作为上限保险，限制任意单步更新幅度，使损失曲面上的轨迹可控，避免灾难性跳跃。

## 三、形式化与数学基础
带裁剪的更新：`Δθ = -η·g·min(1, C/||g||)`，单步 `||Δθ|| ≤ ηC`，上界与梯度本身无关。

## 四、代码实现
```python
from torch.nn.utils import clip_grad_norm_
norm = clip_grad_norm_(model.parameters(), max_norm=1.0)
if not torch.isfinite(norm):
    print("non-finite grad, skip step")   # 或触发 debug
```

## 五、与其他技术对比
与 warmup 配合：warmup 降低早期 lr，裁剪兜底极端梯度，二者共同保障稳定。

## 六、常见误区
认为裁剪后无需监控 norm；其实 norm 是重要健康指标，应记录。

## 七、与开源书/权威来源对应
pytorch/pytorch `torch.nn.utils`；huggingface/transformers 训练循环常启用 `max_grad_norm=1.0`。

## 八、面试题
问：裁剪的步长上界？答：ηC，与梯度幅度脱钩。

## 九、演进与趋势
分层裁剪与基于统计量（如分位数）的自适应阈值在研究中。

## 十、小结
梯度裁剪是工程上性价比极高的稳定手段。
