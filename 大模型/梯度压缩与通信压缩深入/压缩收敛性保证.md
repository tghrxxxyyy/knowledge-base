# 压缩收敛性保证

> 对应 Stich 2018 与 Karimireddy 2019 压缩收敛理论。

## 一、背景与挑战
有损压缩改变梯度统计，担心不收敛或精度下降。需理论界定压缩下的收敛速率与误差界。

## 二、核心原理
在压缩算子满足有界方差/有界误差假设下，配合误差补偿与衰减学习率，SGD/Adam 仍收敛到静止点邻域，偏差由压缩误差上界控制。

## 三、形式化与数学基础
对 $\\mathcal C$ 满足 $\\mathbb E\\|\\mathcal C(g)-g\\|^2 \\le (1-\\delta)\\|g\\|^2$，则有：
$ \\frac{1}{T}\\sum_t \\|\\nabla f\\|^2 \\le O(1/\\sqrt T) + \\delta $，
$\\delta$ 越小偏差越小；EF 进一步压低 $\\delta$。

## 四、代码实现
```python
# 概念：监控压缩误差界
err = (g - compress(g)).norm().item()
if err > threshold:
    use_full_gradient()      # 关键步用全精度保收敛
```

## 五、与其他技术对比
无 EF 的随机压缩需更小学习率；EF + 方差界可达与全精度同阶速率。理论指导实际调参。

## 六、常见误区
误区一：压缩必降精度——有界误差下可控。误区二：学习率不变——通常需略调。误区三：所有压缩同收敛，实际取决于误差界。

## 七、与开源书/权威来源对应
Karimireddy 2019 误差反馈收敛；Stich 2018 SGD 压缩分析；Tang 2021 实证。

## 八、面试题
问：压缩收敛条件？答：有界压缩误差 + EF + 衰减 lr。问：误差界意义？答：决定最终精度邻域半径。

## 九、演进与趋势
非凸情景 tighter 界；与自适应压缩调度结合。

## 十、小结
压缩收敛性由误差界保证，工程上以 EF 与关键步全精度换稳健。
