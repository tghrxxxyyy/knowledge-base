# 梯度稀疏化Top-k

> 对应 Aji 2017 (稀疏梯度通信) 与 Wang 2021  Top-k 实践。

## 一、背景与挑战
梯度中大量分量接近零，全部传输浪费带宽。Top-k 只传绝对值最大的 $k\\%$ 分量及其索引。

## 二、核心原理
每步选梯度中绝对值最大的 $k$ 比例，编码(索引,值)发送；接收方按索引累加到本地梯度，其余分量靠误差补偿后续补传。

## 三、形式化与数学基础
通信量：
$ C = k\\cdot \\Psi \\cdot (b_{\\mathrm{val}} + \\log_2 \\Psi / b_{\\mathrm{idx}}) $，
当 $k=0.1$ 时约省 10 倍带宽；误差补偿 $e \\leftarrow g - \\mathrm{topk}(g)$ 保证最终一致。

## 四、代码实现
```python
import torch
def topk_mask(g, k=0.1):
    n = int(g.numel() * k)
    thr = g.abs().flatten().kthvalue(n).values
    mask = g.abs() >= thr
    return mask, g * mask                  # 仅传非零位置
# 接收方 scatter_add 到本地梯度
```

## 五、与其他技术对比
随机稀疏(random-k)实现更简单但收敛略慢；Top-k 更准但需排序开销。二者均需误差补偿。

## 六、常见误区
误区一：稀疏化无通信——索引也占带宽。误区二：不需误差补偿——否则小梯度永不被更新。误区三：k 越小越好，过小延迟收敛。

## 七、与开源书/权威来源对应
Aji 2017 稀疏通信；Wang 2021 与 microsoft/DeepSpeed 压缩扩展。

## 八、面试题
问：Top-k 省多少？答：约 $1/k$ 倍带宽。问：为何需误差补偿？答：未传分量需累积后续发送。

## 九、演进与趋势
与量化组合(稀疏+低精度)；自适应 $k$ 按层灵敏度调整。

## 十、小结
Top-k 稀疏化以索引+值压缩梯度，配合误差补偿在大模型通信中实用。
