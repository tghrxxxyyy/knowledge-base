# 误差补偿机制

> 对应 Karimireddy 2019 (Error Feedback Fixes SignSGD) 与 Tang 2021。

## 一、背景与挑战
任何有损压缩(量化/稀疏)都会丢弃信息，直接用于 SGD 会偏离真实梯度方向甚至不收敛。误差补偿(EF)修正累积偏差。

## 二、核心原理
本地保存残差 $e$，发送前将 $e$ 加回梯度，接收方用压缩值更新，本地残差更新为未发送部分，下一轮继续补偿，保证长期总和等于真实梯度。

## 三、形式化与数学基础
递推：
$ e_{t+1} = g_t - \\mathcal C(g_t + e_t),\\quad \\tilde g_t = \\mathcal C(g_t + e_t) $，
若压缩算子满足 $\\|\\mathcal C(x)-x\\|\\le \\delta\\|x\\|$，则 EF 保证收敛到邻域。

## 四、代码实现
```python
import torch
ef = torch.zeros_like(param)
def compressed_step(g):
    global ef
    compensated = g + ef
    cg = compress(compensated)          # 量化/稀疏
    ef.copy_(compensated - cg)          # 残差累积
    return cg
```

## 五、与其他技术对比
无 EF 的压缩(如朴素 SIGNSGD)易发散；EF 是压缩训练收敛性的关键组件，被 1-bit Adam 等广泛采用。

## 六、常见误区
误区一：压缩即插即用——无 EF 多数不收敛。误区二：EF 完全消除偏差——仅保证长期一致，单步仍有噪。误区三：EF 占双倍显存，实际仅一份残差。

## 七、与开源书/权威来源对应
Karimireddy 2019 误差反馈理论；Tang 2021 1-bit Adam 应用。

## 八、面试题
问：EF 解决什么？答：有损压缩的方向偏差，保收敛。问：残差更新式？答：$e_{t+1}=g_t-\\mathcal C(g_t+e_t)$。

## 九、演进与趋势
动量化误差补偿、与自适应优化器耦合的理论扩展。

## 十、小结
误差补偿是有损梯度压缩能收敛的基石，几乎所有实用压缩方案均依赖它。
