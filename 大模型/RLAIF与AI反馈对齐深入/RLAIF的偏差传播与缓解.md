# RLAIF的偏差传播与缓解

> 对应 Lee et al. 2023（RLAIF）、Perez et al. 2022（Red Teaming LMs / 奖励模型偏差）与 Zheng et al. 2023（LLM-as-a-Judge 偏差研究）。

## 一、背景与挑战

AI 标注模型携带的价值取向、风格偏好与知识盲区，会在「标注—训练—再生成—再标注」的强化循环中被逐轮放大，形成反馈偏差。与 RLHF 相比，RLAIF 缺少人类这一外部锚点，闭环更紧、纠偏更晚，因此偏差传播的风险更高。典型表现有三：一是风格趋同，策略持续向标注模型偏好的表达方式（更长、更结构化、更多套话）靠拢，牺牲信息密度；二是谄媚（sycophancy），模型学会迎合标注者立场而非陈述事实；三是价值漂移，策略分布逐步远离人类真实偏好，而代理指标仍在上升，因而难以被常规监控发现。

## 二、核心原理

偏差传播的机制可以用闭环反馈理解：策略 $\pi_t$ 生成样本，标注模型 $M$ 给出偏好，训练后得到 $\pi_{t+1}$；若 $M$ 偏好某类风格，则 $\pi_{t+1}$ 会更频繁地生成该风格，下一轮标注又进一步强化它。即使单轮偏差很小，多轮迭代后也会指数累积。

已知的具体偏差源包括：

1. 自偏好（self-preference）：标注模型偏好与自己风格相近的输出；当标注模型与策略同源时最严重。
2. 位置偏差（position bias）：倾向选择呈现位置靠前的候选。
3. 冗长偏好（verbosity bias）：倾向更长的回答，即使信息量相同。
4. 格式与权威偏差：偏好带编号、加粗、引用等「看起来专业」的形式。
5. 知识盲区：标注模型无法识别它自己不知道的错误，导致幻觉被反复强化。

缓解手段对应四条主线：打破同源（用异源或多模型委员会标注）、协议去偏（位置随机化、长度归一化、理由先行）、外部锚定（人类保留集、可验证信号）、以及优化约束（KL 约束、早停、奖励集成）。其中「外部锚定」是根本——没有它，任何内部一致性检查都无法判断方向是否正确。

## 三、形式化与数学基础

设标注模型的偏好分布为 $P_{AI}$，人类真实偏好为 $P_H$，二者存在系统性差异。策略在优化中收敛到最大化 AI 奖励的区域，与人类分布的距离随约束放松而增大：

$$ \mathbb{D}_{\text{KL}}\big(\pi_\theta \,\|\, \pi_H\big) \nearrow \quad \text{as} \quad \beta \to 0 $$

其中 $\beta$ 为 KL 约束系数。单轮偏差放大可用递推近似：设单轮策略向 AI 偏好移动的比例为 $\eta$，则第 $t$ 轮与人类分布的偏差：

$$ \delta_t = (1 - \eta)\,\delta_{t-1} + \eta\,\Delta_{AI,H} \;\Longrightarrow\; \delta_t \to \Delta_{AI,H} \ \ (t \to \infty) $$

即闭环最终收敛到「与人类偏好的固有差距」$\Delta_{AI,H}$，而不是回到人类偏好。这解释了为何必须持续注入人类信号。

监控指标以 AI–人类一致性为核心：

$$ \text{agree}_t = \frac{1}{M}\sum_{i=1}^{M} \mathbb{1}\big[\hat{y}^{AI}_{i,t} = \hat{y}^{H}_i\big] $$

同时监测策略输出分布相对初始检查点的漂移：

$$ \text{drift}_t = \mathbb{D}_{\text{KL}}\big(\pi_t \,\|\, \pi_0\big) $$

两条曲线同时上升且一致性下降，即为偏差失控的明确信号，应触发停止与回滚。

## 四、代码实现

```python
# RLAIF 偏差监控：一致性 + 风格漂移 + 分布距离
import math


def agreement(ai_prefs, human_prefs):
    # AI 偏好与人类偏好在保留集上的一致率，核心外部锚点
    if not human_prefs:
        return None
    same = sum(1 for a, h in zip(ai_prefs, human_prefs) if a == h)
    return same / len(human_prefs)


def style_drift(texts_t, texts_0):
    # 用平均长度比近似风格漂移，捕捉冗长偏好导致的膨胀
    l0 = sum(len(t) for t in texts_0) / max(len(texts_0), 1)
    lt = sum(len(t) for t in texts_t) / max(len(texts_t), 1)
    return lt / max(l0, 1e-9)


def kl_discrete(p, q, eps=1e-12):
    # 离散分布的 KL，用于衡量输出分布相对初始检查点的漂移
    return sum(pi * math.log((pi + eps) / (qi + eps)) for pi, qi in zip(p, q))


def bias_alarm(agree_t, agree_0, drift_t, min_agree=0.7, max_drift=1.5):
    # 一致性显著下降或风格漂移过大时报警并建议停止训练
    return (agree_t is not None and agree_t < min_agree) or drift_t > max_drift
```

## 五、与其他技术对比

- RLAIF vs RLHF 的偏差风险：二者都会过优化，但 RLAIF 缺少人类闭环，偏差更难被发现和纠正。
- 单一标注模型 vs 多模型委员会：委员会降低单一模型的系统性偏差，但可能引入「多数派偏见」，需保证模型来源异构。
- 主观偏好标注 vs 可验证信号：可验证奖励（测试通过、执行正确、检索命中）几乎不存在价值偏差，优先用于可形式化验证的任务。
- 事后校准 vs 过程约束：事后校准（长度去偏、奖励裁剪）治标；过程约束（KL、早停、人类在环）治本。

## 六、常见误区

- 「假设 AI 标注无系统性偏差」：偏差是必然存在的，问题是能否被监测而非是否存在。
- 「只用单一标注模型」：不交叉验证就无法区分「真的更好」与「标注模型更喜欢」。
- 「一致性指标掉一点没关系」：一致性下降是闭环偏离人类偏好的最早信号，应设硬性阈值。
- 「加大 KL 惩罚就万事大吉」：KL 只约束偏离速度，不改变收敛方向，仍需外部锚点。

## 九、演进与趋势

偏差治理正从「事后校准」走向「过程可控、来源异构、信号可验证」：用异构模型委员会与对抗性标注降低系统性偏差；用可验证奖励（单元测试、执行结果、形式化校验）替代主观判断；把人类在环做成自动化路由——仅把低置信、高风险、高分歧样本送人工；并把一致性、漂移、风格指标纳入训练看板，设置自动停止与回滚，使偏差在造成损害前被拦截。

## 十、小结

RLAIF 的偏差必须主动监测与缓解。闭环会稳定收敛到「与人类偏好的固有差距」，因此只有持续注入人类信号与可验证信号，才能让自举对齐保持在正确方向上。
