# 质量与漂移监控

> 对应 LLM 评估与漂移（output drift）；评测体系。

## 一、背景与挑战

模型/数据/提示变更致输出质量漂移，需持续评估而非仅跑一次。

## 二、核心原理

用黄金集定期评分数（faithfulness/正确率）；嵌入分布监测输入漂移；人工抽检校正。

## 三、数学形式

漂移 $d = \text{MMD}(P_{new}, P_{old})$；质量分 $\bar q$ 低于阈值告警。

## 四、代码实现

```python
score = eval_golden(batch)
if score < baseline - 0.05: alert("quality drop")
```

## 五、与其他对比

- 与 模型评测指标深入（若新增）共享评测。
- 与 直接偏好优化深入（质量目标）相关。

## 六、常见误区

- 黄金集陈旧不更新致误报。
- 仅自动分忽略语义退化。

## 七、与开源书对应

- datawhalechina/llm-universe：https://github.com/datawhalechina/llm-universe

## 八、面试题

- 如何发现质量漂移？答：黄金集定期评分+输入分布监测，跌破基线告警。

## 九、演进

一次性评 → 定期评 → 在线漂移检测。

## 十、小结

质量监控靠黄金集与分布漂移，防静默退化。
