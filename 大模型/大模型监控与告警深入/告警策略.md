# 告警策略

> 对应告警工程（SLO/错误预算/告警疲劳）；Google SRE。

## 一、背景与挑战

告警过多致麻木，过少致漏障；需基于 SLO 与错误预算设阈值。

## 二、核心原理

对错误率/延迟/成本设 SLO，超阈值燃尽错误预算才告警；分级（page/ticket）；避免抖动误报（持续窗口）。

## 三、数学形式

错误预算 $B = 1 - SLO$；燃尽率 $r = \frac{obs\_err}{B}\cdot\frac{window}{period}$。

## 四、代码实现

```python
if burn_rate(5m) > 14.4: page("SLO breached")
```

## 五、与其他对比

- 与 API网关与限流深入（限流触发）互补。
- 与 大模型监控与告警深入 总览衔接。

## 六、常见误区

- 阈值过紧致告警疲劳。
- 无分级致 page 泛滥。
