# 经验回放（Experience Replay）

> 对应 Rebuffi et al., 《iCaRL》, 2017；以及 Chaudhry et al., 《A-GEM》, 2018。

## 一、背景与挑战

不存旧数据则无法复习；回放以缓冲区混合新旧数据减缓遗忘。

## 二、核心原理

维护各任务样本缓冲区，每步从缓冲采样与当前数据混合训练；A-GEM 用旧梯度投影约束不伤旧任务。

## 三、数学形式

A-GEM 约束 $\min_\theta \mathcal L_{new}$ s.t. $\langle g_{new}, g_{old}\rangle \ge 0$（$g_{old}$ 旧任务梯度）。

## 四、代码实现

```python
mixed = sample(buffer, n) + new_batch
loss = criterion(model(mixed.x), mixed.y)
```

## 五、与其他对比

- 与 灾难性遗忘总览（回放是一类）共享。
- 与 标签噪声纠正深入（缓冲也可能含错标）衔接。

## 六、常见误区

- 缓冲区太小覆盖不足。
- 隐私/存储限制使回放不可行。

## 八、面试题

- A-GEM 思路？答：用旧任务梯度投影约束新梯度方向，使其不恶化旧任务损失。

## 九、演进

全回放 → 蓄水池采样 → A-GEM/梯度约束。

## 十、小结

经验回放以混合训练复习旧知识，是简单有效的抗遗忘法。
