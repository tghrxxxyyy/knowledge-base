# 提示持续学习（Prompt-based CL）

> 对应 Wang et al., 《DualPrompt》, 2022；以及 L2P, 《Learning to Prompt》, 2022。

## 一、背景与挑战

全参数持续学习成本高；用可学提示前缀隔离任务知识更轻量。

## 二、核心原理

为每个任务学一组 prompt key，推理时按输入选最近 key 的 prompt 前缀，冻结主干，仅训提示。

## 三、数学形式

选键 $k^* = \arg\min_k \|q - key_k\|$，前缀 $P = prompt_{k^*}$ 注入注意力。

## 四、代码实现

```python
key = query_key(x)
prefix = prompt_bank[nearest(key)]
out = model(x, prefix=prefix)
```

## 五、与其他对比

- 与 参数高效微调深入（前缀提示）共享。
- 与 少样本适配深入（提示范式）衔接。

## 六、常见误区

- 提示库冲突致任务混淆。
- key 设计不当选错提示。

## 八、面试题

- 提示持续学习优势？答：仅训轻量提示、主干冻结，参少且天然任务隔离、抗遗忘。

## 九、演进

L2P → DualPrompt → 层次化提示库。

## 十、小结

提示持续学习以可学提示前缀实现轻量抗遗忘，适合大模型场景。
