# 参数隔离与架构方法

> 对应 Rusu et al., 《Progressive Networks》, 2016；以及 Mallya & Lazebnik, 《PackNet》, 2018。

## 一、背景与挑战

共享参数必冲突；隔离参数/子网络可彻底避遗忘但增参数量。

## 二、核心原理

渐进网络为新任务加新列、冻结旧列；PackNet 剪枝后把剩余容量留给新任务；Adapter 路由分任务。

## 三、数学形式

渐进网络 $h^{(k)} = f^{(k)}([h^{(k-1)}, h^{(1..k-1)}])$ 跨列连接旧特征。

## 四、代码实现

```python
for col in old_columns: col.freeze()
new_col = Column()
out = new_col(concat([c(x) for c in all_columns]))
```

## 五、与其他对比

- 与 参数高效微调深入（Adapter 复用）共享架构。
- 与 灾难性遗忘总览（架构类）衔接。

## 六、常见误区

- 每任务加网络参数爆炸。
- 任务数多时路由变难。

## 八、面试题

- PackNet 思路？答：为旧任务剪枝保留重要权重，把空出容量分配给新任务，避冲突。

## 九、演进

渐进网络 → PackNet → 动态路由/子网络。

## 十、小结

参数隔离以架构换零遗忘，代价是参数增长与路由复杂度。
