# 灾难性遗忘评估与基准

> 对应 Hsu et al., 《Continual Learning Benchmarks》, 2018；以及常识/语言持续基准。

## 一、背景与挑战

需统一指标比较抗遗忘方法；仅看平均精度不全。

## 二、核心原理

报告平均精度（AP）、遗忘量（FM）、新旧任务权衡；用 Split-CIFAR/CLINC 等序列基准。

## 三、数学形式

遗忘 $F_t = \max_{t'\le t} A_{t'}(t) - A_t(t)$；前向迁移 $BWT$ 度量。

## 四、代码实现

```python
for t in tasks:
    acc[t] = eval(model, loader[t])
forget = max(acc[0]) - acc[0][-1]
```

## 五、与其他对比

- 与 少样本适配深入（评测严谨）共享方法论。
- 与 模型评测指标深入 衔接。

## 六、常见误区

- 只报最终平均忽略逐任务曲线。
- 任务顺序不同结论变（需多序平均）。

## 八、面试题

- 如何量化遗忘？答：用旧任务精度下降量（FM）与平均精度，并做多任务顺序平均。

## 九、演进

单任务精度 → 遗忘量/迁移 → 标准化序列基准。

## 十、小结

遗忘评估需多指标与多序平均，标准化基准促方法可比。
