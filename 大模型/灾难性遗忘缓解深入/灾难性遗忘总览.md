# 灾难性遗忘缓解总览

> 对应 McCloskey & Cohen, 1989（现象）；French, 1999（综述）；持续学习背景。

## 一、背景与挑战

模型学新任务后旧任务性能骤降；LLM 续训/微调新领域时尤明显。

## 二、核心原理

三大类：回放（存旧数据重训）、正则（约束重要参数）、架构（隔离参数/子网络）。

## 三、数学形式

遗忘度量 $F = \frac{1}{T}\sum_{t} (A_{t}^{init} - A_{t}^{after})$（旧任务精度下降）。

## 四、代码实现

```python
for x, y in replay_buffer + new_data:
    loss = criterion(model(x), y)
    loss.backward()
```

## 五、与其他对比

- 与 经验回放深入（回放法）共享。
- 与 参数高效微调深入（LoRA 减遗忘）衔接。

## 六、常见误区

- 以为大模型不会遗忘（仍会）。
- 只关注新任务忽略旧任务回归。

## 八、面试题

- 灾难性遗忘是什么？答：学新任务致旧任务性能骤降，因参数被新梯度覆盖。

## 九、演进

现象发现 → 回放/正则/架构三路线 → 持续学习系统化。

## 十、小结

灾难性遗忘是持续学习核心问题，回放/正则/架构为三条主线。
