# 正则化方法（EWC/LwF）

> 对应 Kirkpatrick et al., 《EWC》, 2017；以及 Li & Hoiem, 《LwF》, 2017。

## 一、背景与挑战

不存旧数据时需约束重要参数不被大幅改动；需估计参数重要性。

## 二、核心原理

EWC 用 Fisher 信息对角作参数重要度，加惩罚 $\| \theta - \theta_{old}\|^2 \cdot F$；LwF 用旧模型输出作软标签蒸馏。

## 三、数学形式

EWC 惩罚 $\frac{\lambda}{2} \sum_i F_i (\theta_i - \theta_{old,i})^2$，$F_i$ 为 Fisher 对角。

## 四、代码实现

```python
reg = sum(F[i] * (theta[i]-theta_old[i])**2 for i in params)
loss = task_loss + lam * reg
```

## 五、与其他对比

- 与 经验回放深入（不需存数据）互补。
- 与 灾难性遗忘缓解总览（正则类）衔接。

## 六、常见误区

- Fisher 估计不准致约束错。
- 正则过强致新任务学不动。
