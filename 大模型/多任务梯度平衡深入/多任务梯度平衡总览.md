# 多任务梯度平衡总览

> 对应 Ruder, 《An Overview of Multi-Task Learning》, 2017；以及梯度平衡方法综述。

## 一、背景与挑战

多任务联合训练时任务梯度量级/方向冲突，导致某些任务被压制或负迁移。

## 二、核心原理

在共享底层上接任务头；用不确定性、梯度范数或冲突投影来平衡/融合各任务梯度。

## 三、数学形式

总目标 $\min_\theta \sum_t w_t \mathcal L_t(\theta)$；关键在求 $w_t$ 或修正 $g=\sum_t g_t$。

## 四、代码实现

```python
losses = [head_t(model(x)) for t in tasks]
total = sum(w[t] * losses[t] for t in tasks)
total.backward()
```

## 五、与其他对比

- 与 课程在指令微调深入（任务权重）共享。
- 与 多任务在LLM对齐深入 衔接。

## 六、常见误区

- 损失尺度不同直接相加致主导任务。
- 共享层过强致任务干扰。

## 八、面试题

- 多任务难在哪？答：任务梯度量级/方向冲突，简单加权会被大损失任务主导。

## 九、演进

固定权重 → 不确定加权 → 梯度冲突投影。

## 十、小结

多任务梯度平衡解决任务冲突，是联合训练的核心技术。
