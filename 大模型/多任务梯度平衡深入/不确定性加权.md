# 不确定性加权（Uncertainty Weighting）

> 对应 Kendall et al., 《Multi-Task Learning Using Uncertainty》, 2018。

## 一、背景与挑战

手工设任务权重难且脆；应让模型自学习每个任务的最优权重。

## 二、核心原理

为每个任务学一个可训噪声变量 $\sigma_t$，以同方差不确定度自动平衡；任务越不确定权重越小。

## 三、数学形式

损失 $\mathcal L = \sum_t \frac{1}{2\sigma_t^2}\mathcal L_t + \log\sigma_t$，自动调节 $w_t=1/\sigma_t^2$。

## 四、代码实现

```python
log_sigma = nn.Parameter(torch.zeros(T))
loss = sum(exp(-2*log_sigma[t]) * L[t] + log_sigma[t] for t in range(T))
```

## 五、与其他对比

- 与 GradNorm深入（范数平衡）对照。
- 与 多任务梯度平衡总览（属权重类）衔接。

## 六、常见误区

- $\sigma$ 初值不当致某任务权重爆炸。
- 仅适合同方差假设。

## 八、面试题

- 不确定加权原理？答：为每任务学噪声，权重反比于不确定度，自动平衡损失尺度。

## 九、演进

手工权重 → 不确定加权 → 任务特定学习率。

## 十、小结

不确定加权以学得的噪声自动平衡任务，免去手工调权。
