# 切分与嵌入模型匹配

> 对应 chunk size 与嵌入模型适配。

## 一、背景与挑战

嵌入模型有最优输入长度与聚合能力，切分须匹配。

## 二、核心原理

块长在嵌入模型训练长度附近最佳；过长被截断/池化稀释，过短缺上下文。

## 三、数学形式

最优 $c^* \approx \arg\max_c \text{recall}(chunk=c)$ 在验证集上。

## 四、代码实现

```python
for c in [128,256,512,1024]:
    idx = build_index(docs, chunk=c)
    eval(idx)
```

## 五、与其他对比

- 与 向量检索算法深入（向量质量决定召回）相关。
- 与 大模型部署成本模型（目录）衔接（索引规模）。

## 六、常见误区

- 盲目用大块致嵌入稀释。
- 忽略嵌入模型最大长度截断。

## 七、与开源书对应

## 八、面试题

- 块长如何影响嵌入？答：过长稀释语义、过短缺上下文，需匹配模型最优长度。

## 九、演进

经验长度 → 验证集搜索 → 自适应。

## 十、小结

切分须与嵌入模型特性匹配，是召回质量隐形杠杆。
