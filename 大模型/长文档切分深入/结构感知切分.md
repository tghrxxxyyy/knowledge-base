# 结构感知切分

> 对应按 Markdown/标题层级切分。

## 一、背景与挑战

技术文档有清晰层级，无视结构切分破坏逻辑。

## 二、核心原理

按标题层级递归切分，每块保留父级标题作为上下文前缀，保持可追溯。

## 三、数学形式

块 $b_i = \text{parent\_headers} + \text{content}_i$；元数据记录路径。

## 四、代码实现

```python
for sec in parse_md(doc):       # 按 ## 切
    chunks.append(sec.heading + "\n" + sec.body)
```

## 五、与其他对比

- 比固定切分更保逻辑；与 元数据治理血缘深入 衔接（溯源）。
- 与 长文档切分深入 总览互补。

## 六、常见误区

- 标题过长作前缀致噪声。
- 结构解析失败退回无结构切分。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- 结构切分为何加父标题？答：保留层级上下文，提升检索相关与可追溯。

## 九、演进

无结构 → 标题切分 → 多模态结构（表格/图）。

## 十、小结

结构感知切分利用文档层级，提升逻辑一致与溯源。
