# 切分重叠与边界处理

> 对应 overlap 策略与边界一致性。

## 一、背景与挑战

无重叠致跨块信息割裂；重叠过多增冗余与成本。

## 二、核心原理

滑动窗口重叠保留边界上下文；边界处用句级对齐避免断句。

## 三、数学形式

有效步长 $= c - o$；重叠比 $o/c$ 常取 10-20%。

## 四、代码实现

```python
step = size - overlap
chunks = [text[i:i+size] for i in range(0, len(text)-size+1, step)]
```

## 五、与其他对比

- 与 长文档切分深入 总览/语义切分配合。
- 与 检索重排序深入（重叠增候选后重排）衔接。

## 六、常见误区

- 重叠过大致重复文档入上下文。
- 边界断句致块语义不完整。

## 七、与开源书对应

## 八、面试题

- 重叠比多少合适？答：常 10-20%，按文档密度与模型长度调。

## 九、演进

无重叠 → 固定重叠 → 句级对齐重叠。

## 十、小结

重叠与边界处理在保连贯与控冗余间权衡。
