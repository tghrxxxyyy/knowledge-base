# 固定与语义切分

> 对应 chunking 策略对比。

## 一、背景与挑战

固定切分简单但可能断句/断意；语义切分按含义边界更准但复杂。

## 二、核心原理

固定：按 token/字符滑动窗口。语义：用嵌入相似度检测主题边界，在边界切。

## 三、数学形式

语义边界：$i$ 处若 $sim(E(s_i),E(s_{i+1}))<\tau$ 则切分（$\tau$ 阈值）。

## 四、代码实现

```python
# 语义边界检测
sims = cosine(emb[:-1], emb[1:])
bounds = [i for i,s in enumerate(sims) if s<tau]
```

## 五、与其他对比

- 语义切分块长不均，需后处理归一。
- 与 嵌入几何深入（相似度语义）共享。

## 六、常见误区

- 语义阈值全局固定忽略长短段落差异。
- 语义切分计算贵（需嵌每段）。

## 八、面试题

- 语义切分优劣？答：保语义边界更准，但块长不均、成本高。

## 九、演进

固定 → 递归字符 → 语义/结构感知。

## 十、小结

切分策略在简单与语义保真间权衡，常混合使用。
