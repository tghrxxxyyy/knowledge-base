# 长文档切分实践与评估

> 对应生产切分管线；RAG评估与离线评测体系（目录）衔接。

## 一、背景与挑战

切分策略需以检索质量验证，而非凭感觉。

## 二、核心原理

在标注集上扫描块长/重叠/切分类型，选 Recall@k 与答案质量最优组合。

## 三、数学形式

目标 $\max_{c,o,type} \text{Recall}(c,o,type)$ 约束成本。

## 四、代码实现

```python
for cfg in grid: build_index(cfg); report(recall)
```
