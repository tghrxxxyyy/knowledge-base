# 长文档切分总览

> 对应 RAG chunking 策略；与 长文档处理（若新增）/ 检索增强生成前沿 衔接。

## 一、背景与挑战

文档超模型上下文，需切分建索引；切分粒度影响检索精度与上下文连贯。

## 二、核心原理

按固定大小/句子/语义/结构（标题/段落）切分，重叠（overlap）保边界连贯。

## 三、数学形式

块数 $m = \lceil L / (c - o) \rceil$（$c$ 块长，$o$ 重叠）；重叠防信息割裂。

## 四、代码实现

```python
def chunk(text, size=512, overlap=64):
    return [text[i:i+size] for i in range(0, len(text), size-overlap)]
```

## 五、与其他对比

- 与 向量检索算法深入（块数=向量数）强相关。
- 与 混合检索深入 / 查询改写深入 共构 RAG 索引侧。

## 六、常见误区

- 块过大超嵌入模型最优长度致向量质量降。
- 无重叠致句跨块割裂。

## 八、面试题

- 为何要 overlap？答：避免跨块语义割裂，保留边界上下文连贯。

## 九、演进

固定切分 → 语义切分 → 结构感知切分。

## 十、小结

切分粒度与重叠是 RAG 索引质量基础，需匹配嵌入模型。
