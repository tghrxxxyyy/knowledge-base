# 蒸馏与污染

> 对应 模型蒸馏与数据污染研究；Carlini et al., *Dataset Contamination*, 2023（基准泄漏）；Ostermann et al. 分析。

## 一、背景与挑战

合成数据若源自含基准的教师/网络，会造成测试污染，虚高指标。

## 二、核心原理

教师可能在预训练见过测试题；其生成物隐含答案，训练后模型“背答案”。需污染检测（n-gram 重叠、membership）与去污染。

## 三、数学形式

污染度 $C=\max_x J(\text{gen}(x), T_{test})$；当 $C>\epsilon$ 标记并剔除该样本。

## 四、代码实现

```python
if jaccard(gen_text, test_item) > 0.5:
    flag_contamination(gen_text)
```

## 五、与其他对比

- 与 数据去重与精确子串匹配深入（去污染同理）衔接。
- 与 数据版权与合规清洗深入（来源合规）相关。

## 六、常见误区

- 忽视 n-gram 级污染致指标虚高。
- 用教师生成当“新”数据实则同源。

## 八、面试题

- 合成数据污染？答：教师见过基准使生成物含答案，须去污染检测。

## 九、演进

无检测 → n-gram 去污染 → membership 推断。

## 十、小结

合成数据须做污染检测，否则指标不可信。
