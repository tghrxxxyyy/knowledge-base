# 事实性幻觉陷阱

> 对应 合成数据事实性研究；Gunasekar et al., 2023（需事实校对）；Lin et al., *Factual Consistency*, 2022。

## 一、背景与挑战

教师生成内容含编造事实（幻觉），直接用作训练会使模型学“自信地错”。

## 二、核心原理

合成文本流畅但事实可能无依据；需检索增强生成（RAG）校对或人工抽检，再用事实性分类器过滤。

## 三、数学形式

事实准确率 $F=\frac1N\sum I(\text{fact}(y)=\text{truth})$；训练只用 $F(y)>\tau_f$ 的样本。

## 四、代码实现

```python
for item in synthetic:
    if not verify_facts(item):
        drop(item)
```

## 五、与其他对比

- 与 数据质量过滤与困惑度过滤深入（事实过滤）重叠。
- 与 合成数据陷阱与评估深入 总览互补。

## 六、常见误区

- 只过滤流畅度忽略事实性。
- 用同一模型自验事实（循环偏置）。
