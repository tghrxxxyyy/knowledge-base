# 自我认同与模式崩塌

> 对应 Alemohammad et al., *Self-Consuming Generative Models*, 2023（自身消费退化）；Shum et al., *The False Promise of Imitating Pretraining*, 2023。

## 一、背景与挑战

模型用自身生成物训练会“自我认同”，多样性下降、分布坍缩，长期退化。

## 二、核心原理

合成数据分布是真实分布的扭曲估计；反复自举使支撑集收缩，罕见模式消失，模型退化（mode collapse/error feedback）。

## 三、数学形式

迭代分布 $q_{t+1}(x)\approx T_t(q_t)$；若 $T$ 收缩支撑，则 $q_t\to$ 退化点质量，$\mathrm{Supp}(q_t)$ 单调缩小。

## 四、代码实现

```python
for t in range(T):
    data = model.generate(data)   # 用上一代产出训练
    model = train(model, data)
```

## 五、与其他对比

- 与 数据去重与精确子串匹配深入（自举也需去重）相关。
- 与 指令数据多样性控制深入（多样性度量）直接关联。

## 六、常见误区

- 多轮自举不加新真实数据必退化。
- 误以为量能补质。

## 八、面试题

- 自身消费为何退化？答：合成分布是扭曲估计，自举收缩支撑致模式崩塌。

## 九、演进

单代 → 多代自举 → 掺真实数据保支撑。

## 十、小结

自举需掺真实数据维持多样性，避免坍缩。
