# 合成数据评估方法

> 对应 合成数据效用评估；Gudibande et al., *False Promises*, 2023（模仿预训练无效）；Alpaca 评估实践。

## 一、背景与挑战

如何判断合成数据是否真有助？需隔离实验与下游评测。

## 二、核心原理

做“仅合成 vs 真实+合成”对照；看下游基准与多样性指标；警惕基准过拟合（合成来自同教师）。

## 三、数学形式

效用增益 $\Delta = \text{score}(M_{syn}) - \text{score}(M_{base})$；须 $\Delta>0$ 且泛化到分布外。

## 四、代码实现

```python
base = eval(train_on(real))
aug = eval(train_on(real + syn))
print(aug - base)
```

## 五、与其他对比

- 与 指令数据多样性控制深入（多样性也是评估项）共享。
- 与 数据混合比例课程深入（合成占比）相关。

## 六、常见误区

- 用教师出过的题测学生（泄漏）。
- 只看单一基准忽略分布外泛化。
