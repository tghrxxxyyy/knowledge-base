# 合成数据安全与对齐风险

> 对应 合成有害内容研究；Bai et al., *Constitutional AI*, 2022（合成偏好）；Ganguli et al. 红队。

## 一、背景与挑战

合成可规模化偏好/安全数据，但也可能批量生成有毒或越狱样本污染训练。

## 二、核心原理

用 AI 反馈（RLAIF）合成偏好对可省人工；但需安全分类器拦截有毒生成，并避免“奖励黑客”式合成。

## 三、数学形式

安全过滤器 $S(y)\in\{0,1\}$；仅保留 $S(y)=1$ 的合成偏好对用于对齐。

## 四、代码实现

```python
if safety_clf(sample) == 1:
    prefs.append(sample)
```

## 五、与其他对比

- 与 指令数据多样性控制深入（安全也需多样）互补。
- 与 数据版权与合规清洗深入（合规）重叠。

## 六、常见误区

- 批量合成偏好不加安全闸致毒化。
- 用同一模型生成并评判（自证循环）。

## 八、面试题

- 合成安全数据注意？答：须安全过滤，避免批量毒化与自证循环。

## 九、演进

人工偏好 → RLAIF 合成 → 安全闸控合成。

## 十、小结

合成安全数据高效但需安全闸，防毒化与自证。
