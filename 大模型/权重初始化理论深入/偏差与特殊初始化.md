# 偏差与特殊初始化

> 见「权重初始化理论深入/权重初始化理论总览」；不止权重。

## 一、背景与挑战

偏置、门控、embedding 也需讲究初始化。

## 二、核心原理

- **偏置**：通常初始化为 0（除门控如 LSTM 遗忘门初始化为 1 助记忆）。
- **门控（GLU/SwiGLU）**：门权重影响信息流，常配合理初始化。
- **Embedding**：小随机或特定分布，避免全同。
- **残差/归一化**：缩放初始化（DeepNorm/ReZero）助深训。

## 三、关键要点

- 遗忘门置 1 利于长程。
- 门控初始化影响训练早期。

## 四、代码实现

```python
nn.init.ones_(lstm.bias_hh[hidden:2*hidden])  # 遗忘门=1
```

## 五、与其他对比

- 权重重方差；偏置重功能。

- 偏置都设 0——门控需特殊。
