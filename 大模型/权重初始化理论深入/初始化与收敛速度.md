# 初始化与收敛速度

> 见「权重初始化理论深入/权重初始化理论总览」与「优化理论深入」；初始化影响收敛。

## 一、背景与挑战

好初始化让 optimizer 少走弯路。

## 二、核心原理

合适初始化使初始 loss 处梯度信息充足、各层激活健康，SGD/Adam 可快速下降；坏初始化（如全同、过大）导致对称权重/梯度消失，收敛极慢甚至不收敛。预训练权重是「最佳初始化」。

## 三、关键要点

- 初始对称需打破（随机初始化）。
- 预训练即强初始化。

## 四、代码实现

```python
model.load_state_dict(pretrained)   # 最佳初始化
```

## 五、与其他对比

- 随机慢；预训练快。

## 六、常见误区

- 初始化只防崩——也影响速度。
