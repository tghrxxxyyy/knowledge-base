# 正交初始化

> 见「权重初始化理论深入/权重初始化理论总览」；保持激活独立。

## 一、背景与挑战

某些结构（RNN/深层）需更稳的谱性质。

## 二、核心原理

正交初始化使权重矩阵近似正交（W^T W ≈ I），保持激活向量范数与方向稳定、减缓梯度消失/爆炸，特别利于 RNN 长程记忆。通过 QR 分解或 SVD 构造近似正交矩阵。

## 三、数学形式

`W = Q R` 取 `Q` 正交；或 SVD 取 U。

## 四、代码实现

```python
nn.init.orthogonal_(w)
```

## 五、关键要点

- 利于循环/深层稳定。
- 与方差初始化互补。

## 六、与其他对比

- 随机初始化谱散；正交谱稳。

## 七、常见误区

- 正交处处好——CNN 未必需。
