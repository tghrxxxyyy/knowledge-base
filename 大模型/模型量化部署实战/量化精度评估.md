# 量化精度评估

> 见「模型压缩综述」与「模型评测深入」。

## 一、背景与挑战

量化后必须验证精度损失是否在可接受范围，避免「省了显存、废了效果」。

## 二、核心原理

在基准（MMLU/TruthfulQA/领域任务）上对比量化前后指标，并做 perplexity 与人工样例检查。

## 三、数学形式

相对精度保持率：

```
Retention = Metric(quant) / Metric(fp16)
```

## 四、代码实现

```python
def retention(fp, q): return q / fp  # 越接近 1 越好
```

## 五、关键要点

- 通用基准通过 ≠ 业务任务通过，需领域评估。
- 激活异常值（outlier）通道最敏感。

## 六、与其他对比

- 自动化基准快；人工抽样更可信。

## 七、常见误区

- 只看 perplexity——任务级指标更反映可用性。

## 八、与开源书对应

- llm-course 评估章: https://github.com/mlabonne/llm-course
- Hendrycks et al., *MMLU*, 2020.

## 九、面试题

- 量化后该看哪些指标判断可用性？

## 十、演进

单基准 → 多维度（任务/安全/鲁棒）评估。

## 十一、小结

量化必须配评估，否则降本变降质。
