# 量化部署总览

> 对应 llm-course「Quantization」与 rasbt/LLMs-from-scratch 部署章。

## 一、背景与挑战

LLM 权重以 FP16/BF16 存储，7B 模型约 14GB，推理显存与带宽成本高。量化用低比特（INT8/INT4/NF4）表示权重与激活，显著降低资源占用。

## 二、核心原理

量化将浮点张量映射到整数网格：

```
q = round(x / scale) + zero_point
x ≈ (q - zero_point) * scale
```

部署时以低比特计算，必要时反量化。

## 三、数学形式

对称量化：scale = max(|x|) / (2^(b-1)-1)，zero_point=0。

## 四、代码实现

```python
import torch
q = torch.quantize_per_tensor(torch.tensor([1.2,-0.5,3.1]), scale=0.05, zero_point=0, dtype=torch.qint8)
```

## 五、关键要点

- 权重静态量化成熟；激活动态量化更易但精度略低。
- 4-bit 已成端侧/单卡部署主流。

## 六、与其他对比

| 方案 | 比特 | 典型用途 |
|------|------|----------|
| FP16 | 16 | 训练/高精度推理 |
| INT8 | 8 | 服务端加速 |
| INT4/NF4 | 4 | 单卡/端侧 |

## 七、常见误区

- 量化必掉点——4-bit 配合好校准可近无损。
- 忽视反量化开销导致实际更慢。
