# 世界模型总览

> 对应 Ha & Schmidhuber, *World Models*, 2018；LeCun, *A Path Towards Autonomous Machine Intelligence*, 2022。

## 一、背景与挑战

智能体需内部预测环境演化以规划；世界模型学习可迁移的环境动态表示，而非端到端策略。

## 二、核心原理

三组件：感知（VQ-VAE 编码观测到隐状态）、动态（RNN/Transformer 预测下一隐状态）、控制器（在想象中规划）。JEPA 以能量模型学习预测表征。

## 三、数学形式

动态模型 $s_{t+1}=f_\theta(s_t,a_t)+\epsilon$；JEPA 最小化预测与目标的表征距离 $d(z_s,\text{sg}(z_{pred}))$。

## 四、代码实现

```python
s_next = dynamics(s_t, a_t)
loss = mse(s_next, encoder(next_obs))
```

## 五、与其他对比

- 与纯 RL 相比，世界模型支持无环境交互的想象规划。
- 与 视频生成 / 智能体规划 共享预测能力。

## 六、常见误区

- 模型误差在长程预测累积致规划失效。
- 忽视世界模型分布偏移（真实环境偏离训练分布）。
