# 视频预测作为世界模型

> 对应 Villegas et al., *Video Prediction*；Sora 技术报告（Brooks et al., 2024）。

## 一、背景与挑战

视频生成模型隐式编码物理与因果关系，可当作可学习的世界模拟器。

## 二、核心原理

用扩散/自回归在时空块上预测未来帧；作为世界模型时，以动作条件化（action-conditioned）预测可交互演化。

## 三、数学形式

预测分布 $p(x_{t+1:T}|x_{1:t},a_{1:T})$；训练用扩散损失
$\mathcal L=\mathbb E[\|\epsilon-\epsilon_\theta(x_t,t)\|^2]$。

## 四、代码实现

```python
frames = vae.encode(video)
pred = diffuser(frames[:, :k], actions)
```

## 五、与其他对比

- 比显式动态模型更易从数据学，但难精确控制。
- 与 视频生成 / 神经渲染 共享时序生成。

## 六、常见误区

- 视频模型学"表象"而非因果，常不符物理。
- 忽视动作条件化才能成为可控世界模型。

## 八、面试题

- 视频模型能当世界模型吗？答：可近似环境动态，但需动作条件化与因果约束才可控可信。

## 九、演进

像素预测→扩散视频→动作条件世界模拟器。

## 十、小结

视频预测是世界模型的强数据驱动近似，可控性是开放问题。
