# 世界模型中的预测与规划

> 对应 World Models 规划实验；MuZero（Schrittwieser et al., 2020）。

## 一、背景与挑战

在学到的模型内搜索最优动作序列，需要可微/可搜索的规划算法。

## 二、核心原理

CEM/MPPI 在想象轨迹上优化动作；MuZero 用蒙特卡洛树搜索在学得的动态上规划，兼顾模型学习与决策。

## 三、数学形式

规划目标 $\max_{a_{1:H}} \sum_{t}\gamma^t r(s_t,a_t)$，约束于 $s_{t+1}\sim f_\theta(s_t,a_t)$。

## 四、代码实现

```python
best = None
for cand in sample_actions(H):
    traj = imagine(model, cand)
    if score(traj) > best: best = cand
```

## 五、与其他对比

- 与 智能体规划 共享搜索思想，但世界模型提供内部模拟。
- 与 推理时计算 共享"在模型内搜索"范式。

## 六、常见误区

- 模型偏差使规划在真实环境次优。
- 忽视规划深度与算力权衡。
