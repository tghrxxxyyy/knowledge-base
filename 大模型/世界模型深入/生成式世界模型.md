# 生成式世界模型（Dreamer/JEPA）

> 对应 Hafner et al., *DreamerV3*, 2023；Assran et al., *I-JEPA*, 2023。

## 一、背景与挑战

如何学习既紧凑又可用于规划的预测模型，避免像素级预测的脆弱性。

## 二、核心原理

Dreamer 在 RSSM（递归状态空间模型）中想象多步轨迹并用 actor-critic 优化；JEPA 学能量式自监督预测表示，只预测表征而非像素。

## 三、数学形式

RSSM：$h_t=f(h_{t-1},s_{t-1},a_{t-1}), s_t\sim p(s_t|h_t,o_t)$；奖励/价值在想象轨迹上估计。

## 四、代码实现

```python
for _ in range(horizon):
    h = rssm(h, a); s = sample(h)
    a = actor(s); imag_rewards.append(reward(s))
```

## 五、与其他对比

- JEPA 比像素自回归更鲁棒、省算力。
- 与 视频预测模型 / 长上下文 共享序列建模。

## 六、常见误区

- 长程想象轨迹方差爆炸。
- 忽视奖励模型与世界模型联合训练的细节。

## 八、面试题

- JEPA 为何预测表征而非像素？答：表征空间更平滑、任务相关，避免像素级冗余与噪声。

## 九、演进

像素预测→RSSM→I-JEPA 能量模型。

## 十、小结

生成式世界模型把预测压缩到表示空间，使想象规划高效可行。
