# 归一化层总览

> 对应 Ioffe & Szegedy, *Batch Normalization*, 2015；Ba et al., *Layer Normalization*, 2016。

## 一、背景与挑战

内部协变量偏移使每层输入分布随训练漂移，需更小学习率。归一化把激活稳定到零均值单位方差，加速收敛、提升稳定。

不同归一化按“归一化维度”区分：BN 沿批次、LN 沿特征、RMSNorm 只用均方根。

## 二、核心原理

通用形式：$\hat x=(x-\mu)/\sqrt{\sigma^2+\epsilon}$，再仿射 $y=\gamma\hat x+\beta$。

BN 在 N×H×W 上求统计（训练用 batch、推理用滑动平均）；LN 在特征维；RMSNorm 省去减均值、仅除 RMS。

## 三、数学形式

$\hat x_i=\frac{x_i-\mu}{\sqrt{\sigma^2+\epsilon}}$，$\mu=\frac1D\sum x$，$\sigma^2=\frac1D\sum(x-\mu)^2$；$y=\gamma\hat x+\beta$。

## 四、代码实现

```python
import torch.nn as nn
ln = nn.LayerNorm(hidden); bn = nn.BatchNorm1d(hidden)
```

## 五、与其他对比

- 与 初始化尺度与方差传播深入 互补，归一化把方差强制回 1。
- 与 梯度消失机理 衔接，稳定输入缓解消失。
- 与 混合精度实践陷阱 衔接，归一化对低精度敏感应留 FP32。

## 六、常见误区

- 以为归一化可替代好初始化（仅降低敏感度）。
- BN 在微小 batch 下统计不稳。
- 推理/训练 BN 模式切换错误致偏移。

## 八、面试题

- 归一化为何加速收敛？答：把每层输入拉回稳定分布，可用更大学习率、避饱和。
- BN 与 LN 区别？答：BN 沿 batch 维、LN 沿特征维，LN 与 batch 大小无关。

## 九、演进

BN → LN → RMSNorm/Pre-LN Transformer。

## 十、小结

归一化以标准化输入稳定训练，是现代深网标配。
