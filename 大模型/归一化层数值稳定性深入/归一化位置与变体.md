# 归一化位置与变体

> 对应 Xiong et al., *On Layer Normalization in Transformer*, 2020（Pre-LN vs Post-LN）；DeepNorm（Wang et al., 2022）。

## 一、背景与挑战

归一化放在残差分支“内”还是“外”（Pre/Post-LN）显著影响训练稳定性与最终效果。

Post-LN 易不稳需 warmup，Pre-LN 更稳但表达略弱；变体试图兼得。

## 二、核心原理

Post-LN：$x_{l+1}=\mathrm{Norm}(x_l+F(x_l))$；Pre-LN：$x_{l+1}=x_l+\mathrm{Norm}(F(x_l))$。

DeepNorm 以放大残差+缩放初始化兼得稳定与表达；RMSNorm 替换 LN 提速。

## 三、数学形式

Pre-LN 提供梯度恒等项 $+I$；Post-LN 归一化作用于总和，梯度需过 Norm 雅可比。

## 四、代码实现

```python
# Post-LN
h = LayerNorm(x + attn(x))
# Pre-LN
h = x + attn(LayerNorm(x))
```

## 五、与其他对比

- 与 归一化与梯度流 衔接，位置决定梯度通路。
- 与 注意力数值稳定与溢界深入 衔接，注意力子层前后归一化。
- 与 学习率与发散 衔接，Post-LN 需 warmup。

## 六、常见误区

- 照搬 Post-LN 却无 warmup，训练发散。
- 认为 Pre-LN 一定更好（表达可能略弱）。
- 忽视不同变体对初始化/学习率的要求不同。

## 八、面试题

- Pre 与 Post-LN 谁更稳？答：Pre-LN 更稳（恒等梯度通路），Post-LN 需 warmup。
- DeepNorm 思路？答：放大残差+缩放初始化，兼稳定与表达。

## 九、演进

Post-LN+warmup → Pre-LN → DeepNorm/RMSNorm 组合。

## 十、小结

归一化位置是训练稳定性与表达的权衡点，Pre-LN 已成主流起点。
