# 归一化与梯度流

> 对应 Balduzzi et al., *Shattered Gradients*, 2017；与归一化稳定梯度相关。

## 一、背景与挑战

无归一化时梯度在层间相关性“破碎”、幅值失控。归一化通过重参数化改善梯度流的平滑性。

这对深层/残差网络尤其关键。

## 二、核心原理

归一化把每层输入标准化，使反向时梯度不因输入尺度剧烈变化；仿射 $\gamma$ 恢复表达能力。

Pre-LN 中归一化在残差分支外，保证恒等通路梯度不被缩放，训练更稳。

## 三、数学形式

对 $h_{l+1}=\mathrm{Norm}(h_l)+F(h_l)$，归一化使 $\partial h_{l+1}/\partial h_l$ 的条件数受控，梯度幅值随深度变化平缓。

## 四、代码实现

```python
# Pre-LN 残差块
h = x + attn(LayerNorm(x))     # 归一化在分支内、加法在分支外
```

## 五、与其他对比

- 与 梯度消失机理 衔接，归一化是结构性缓解。
- 与 初始化尺度与方差传播深入 互补，二者共同控方差。
- 与 注意力数值稳定与溢界深入 衔接，Pre-LN 稳定注意力堆叠。

## 六、常见误区

- 以为归一化位置无关（Pre/Post-LN 训练动态不同）。
- 把 $\gamma$ 初始过小，压制表达。
- 多层归一化叠加致信号过度平滑。

## 八、面试题

- 归一化如何改善梯度流？答：标准化输入使反向梯度幅值平滑、条件数受控。
- Pre-LN 为何更稳？答：归一化在分支内，恒等通路梯度不被缩放。

## 九、演进

Post-LN → Pre-LN → 归一化位置搜索（如 DeepNorm）。

## 十、小结

归一化通过重参数化平滑梯度流，是深层网络稳定的支柱。
