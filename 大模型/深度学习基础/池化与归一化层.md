# 池化与归一化层

> 对应 d2l-zh 第6章与第7章(BatchNorm)。归一化是现代深度网络稳定训练的关键。

## 一、核心概念

- **池化**：最大/平均池化，降低分辨率、扩大感受野。
- **批量归一化(BatchNorm)**：对每个特征在 batch 维度做标准化，缓解内部协变量偏移。
- **层归一化(LayerNorm)**：对单个样本的特征维度归一化，适用于 RNN/Transformer。
- **实例归一化(IN)/组归一化(GN)**：BN 的变体，适用于小 batch 或风格迁移。

## 二、数学形式

**BatchNorm**(训练)：

```
μ_B = (1/m) Σ x_i
σ_B² = (1/m) Σ (x_i - μ_B)²
x̂_i = (x_i - μ_B) / √(σ_B² + ε)
y_i = γ x̂_i + β
```

推理时用滑动平均的全局统计量。

**LayerNorm**：

```
μ = (1/H) Σ_{j=1}^H x_j,  σ² = (1/H) Σ (x_j - μ)²
x̂_j = (x_j - μ) / √(σ² + ε),  y_j = γ_j x̂_j + β_j
```

## 三、代码实现

```python
import torch.nn as nn
bn = nn.BatchNorm2d(64)
ln = nn.LayerNorm(512)
```

## 四、关键要点

| 归一化 | 归一化维度 | 适用 |
|--------|-----------|------|
| BatchNorm | batch 维 | CNN(大 batch) |
| LayerNorm | 特征维 | Transformer/RNN |
| GroupNorm | 通道分组 | 小 batch |
| InstanceNorm | 单样本单通道 | 风格迁移 |

## 五、常见误区

- BN 训练/推理行为不同，部署忘 `eval()` 致数值漂移。
- Transformer 误用 BN 代替 LN，导致不稳定。
- 把 BN 的 `γ,β` 当成普通权重初始化过激。
