# 卷积神经网络 CNN

> 对应 d2l-zh 第6章「卷积神经网络」；奠基论文为 LeCun et al., *Gradient-Based Learning Applied to Document Recognition*, 1998（LeNet）。CNN 通过局部连接与权值共享，把"平移不变的局部模式"直接编码进网络结构。

## 一、背景与挑战

图像如果当成全连接网络的输入会遇到两座大山。以 224×224×3 的彩色图为例：展平后有约 15 万维，第一层若接 4096 个隐藏单元，光第一层就要 **6 亿多个参数**——不仅慢，还极易过拟合。更要命的是，全连接根本**不理解图像的结构**：它把像素当成无序的号码牌，猫的耳朵挪到图片左下角，在全连接眼里就是彻底不同的输入。

而图像有两个宝贵的先验性质：

1. **局部性**：判断一个像素属于什么，通常只看它周围的小邻域（边缘、纹理、角点都是局部现象）。
2. **平移不变性**：一条横边在图片左上角和右下角是同一种特征，检测它的规则应该完全一样。

CNN 的设计正是把这两条先验"焊"进网络结构：用**局部连接**对应局部性，用**权值共享**对应平移不变性。参数从数亿降到几百万甚至更少，还学得更快、泛化更好。

## 二、核心原理

- **卷积核（kernel/filter）**：一个小矩阵（如 3×3），在输入上按步幅滑动，每个位置做点加运算，输出一个特征值。它就是"局部模式探测器"，浅层学边缘纹理，深层学部件和物体。
- **局部连接**：输出的每个像素只与输入的一小块（感受野）相连，而不是全部输入。
- **权值共享**：同一个卷积核扫完全图，全图用同一套权重——这同时大幅减参数并赋予平移不变性：无论特征出现在哪，同一个核都能检出。
- **通道（channel）**：输入的 RGB 是 3 个通道；输出通常有几十上百个通道，每个通道是一张"某种特征的响应图"（比如"竖直边缘通道"）。
- **填充（padding）**：在四周补零，保住边缘信息并控制输出尺寸；**步幅（stride）**：核每次滑动的距离，大于 1 可降采样。

输出尺寸公式（方形输入边长 n、核 k、填充 p、步幅 s）：

```
out = ⌊(n + 2p - k) / s⌋ + 1
```

**池化（pooling）**：对每个小窗口取最大值（最大池化）或平均值，把特征图缩小一半，带来两点好处：降低计算量、对微小平移更鲁棒（特征挪动一两格，池化后的响应基本不变）。**感受野**指输出一个像素"能看到"的输入范围，堆叠多层后感受野逐渐覆盖全图，网络才能从局部边缘组合出全局语义。

## 三、数学形式（适度）

深度学习习惯上把下面的**互相关**称为"卷积"：

```
Y(i,j) = Σ_a Σ_b X(i+a, j+b) · K(a,b)
```

- `X`：输入（如特征图），`K`：卷积核，`Y`：输出；
- `(i,j)`：输出位置，`(a,b)`：在核内的偏移。

严格数学卷积会把核**翻转**再滑动，深度学习实践中省略翻转（核权重本来就是学出来的，翻不翻无所谓），但业界统称"卷积"。加偏置、多通道求和（输出通道 c 对所有输入通道求和后再加 `b_c`）即为完整的 `Conv2d`。

## 四、代码实现

```python
import torch.nn as nn

# 一个迷你的 LeNet 风格网络 (输入 1x28x28 手写数字)
net = nn.Sequential(
    nn.Conv2d(in_channels=1, out_channels=32, kernel_size=3, padding=1),  # 32 个 3x3 核, 补零保尺寸
    nn.ReLU(),
    nn.MaxPool2d(kernel_size=2, stride=2),     # 边长减半
    nn.Conv2d(32, 64, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(2, 2),
    nn.Flatten(),                              # 特征图展平
    nn.Linear(64 * 7 * 7, 10),                 # 10 类输出
)

# 输出尺寸自查: n=28,k=3,p=1,s=1 -> 28; 再经 2x2 池化 -> 14; 第二轮 -> 7
```

## 五、与其他技术对比

| 模型 | 连接方式 | 参数量 | 平移不变性 | 适合数据 |
|------|---------|--------|-----------|---------|
| 全连接 MLP | 全局稠密 | 极大 | 无 | 表格、固定向量 |
| CNN | 局部+共享 | 小 | 结构内置 | 图像、网格数据 |
| RNN/LSTM | 时序递归 | 中 | — | 序列、文本 |
| Transformer | 全局注意力 | 大 | 需学习 | 文本、大图、多模态 |

图像任务里 CNN 至今是强基线：同等精度下比全连接省参数，比纯 ViT 更省数据；在分割、检测等**像素级**任务上，卷积的局部归纳偏置依然占优。

## 六、常见误区

- **混淆 `kernel_size` 与输出通道数**。前者是核的空间大小（3×3），后者是 `out_channels`，由你指定的滤波器个数决定。
- **以为"卷积 = 数学上的卷积"**。深度学习实现的是互相关，只是沿用了名字。
- **堆了很多层却不检查感受野**。若感受野始终没覆盖全图，网络"看不到"整体，分类头再深也没用。
- **在语义分割里随手加池化**。池化会丢空间分辨率，分割需要精确定位像素，一般用空洞卷积或上采样替代。
- **认为权值共享只为了省参数**。它更大的价值是赋予平移不变性——特征在哪出现都能被同一个核捕捉。
- **忘做输入归一化**。图像像素通常先除以 255 或按数据集均值方差标准化，否则收敛慢、数值不稳。

## 八、面试题

1. **1×1 卷积有什么作用？** 要点：不看空间邻域、只在通道维做线性组合，用于跨通道信息融合与升/降维（如 Network in Network、bottleneck），计算远比 3×3 便宜。
2. **如何计算多层 CNN 的感受野？** 要点：逐层递推 `rf = rf + (k-1) * stride_积`，即上一层感受野加上本层核覆盖的范围（按累计步幅折算）；反向亦可从输出像素追溯输入依赖。
3. **为什么需要 padding？** 要点：不填充时角落像素被卷的次数少、输出比输入小；补零后可保持尺寸、保留边缘信息，便于堆叠层数。
4. **卷积和全连接的关系？** 要点：卷积可以看成权值共享 + 仅局部连接的特殊全连接层，参数量从 `H_out·W_out·C_in·C_out·k·k` 降到 `C_in·C_out·k·k`。

## 九、演进与趋势

CNN 的现代史就是一部"更深、更聪明"的进化史：1998 年 LeNet 五层结构奠定了"卷积-池化-全连接"范式；2012 年 AlexNet 用 GPU、ReLU、Dropout 在 ImageNet 上碾压传统方法，点燃深度学习革命；2014 年 VGG 用一堆 3×3 小核证明"深就有用"，同年 GoogLeNet 用 Inception 多分支提高效率；2015 年 ResNet 的**残差连接**让上百层网络可训练，至今仍是骨干网标配；此后 DenseNet、MobileNet（深度可分离卷积）、EfficientNet 等分别向稠密连接与轻量化演进。2020 年后 Vision Transformer 借注意力在大算力、大数据下登顶，但现代架构是**混血**的：ConvNeXt 用纯卷积追平 ViT，Swin 的窗口注意力实为"卷积思想 + 注意力"，移动端与嵌入式设备上轻量 CNN 仍是主力。

## 十、小结

CNN 的全部魔法浓缩为两句话：**局部连接**让每个输出只关心邻域，**权值共享**让同一套核扫遍全图——参数省了，平移不变性也有了。配合填充与步幅控制尺寸、池化降采样增鲁棒、多层堆叠让感受野从边缘扩展到全图，CNN 用最少的先验、最省的参数把图像理解这件事做成了。从 LeNet 到 ResNet 再到今天的混合架构，卷积作为"局部特征提取器"的角色从未被真正取代，理解它也就理解了视觉模型设计的半部历史。
