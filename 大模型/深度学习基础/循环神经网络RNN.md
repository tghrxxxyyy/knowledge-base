# 循环神经网络 RNN

> 对应 d2l-zh 第9章「循环神经网络」；经典教材可参考 Goodfellow 等《深度学习》第10章。RNN 通过隐状态建模序列的时序依赖，是理解 LSTM、Transformer 的起点。

## 一、背景与挑战

前面学的全连接网络和卷积网络都有一个共同假设：**每个样本彼此独立，且输入的尺寸固定**。一张 224×224 的图片可以展平成固定长度的向量，但很多真实数据不是这样：

- 一句话有长有短，词与词之间有先后顺序；
- 股票行情是一串时间点上的数值，今天的走势和昨天相关；
- 语音、音乐、传感器读数都是典型的**变长序列**。

如果把一句话的每个词都当成独立样本喂给网络，"我吃了饭"和"饭吃了我"在模型眼里就没区别了——词序信息全丢了。如果简单地把整句话拼成一个超长向量输入全连接层，则会带来两个问题：参数量随句子长度爆炸，而且模型根本学不到"前文影响后文"这种**依赖关系**。

RNN 的思路非常自然：处理第 t 个词时，把之前看到的信息压缩成一个**隐状态**（hidden state）带在身上，一边读新词一边更新这份"记忆"。这样无论序列多长，参数量始终不变，还天然保留了顺序。

## 二、核心原理

RNN 在每个时刻 t 维护一个隐状态 `h_t`，它由当前输入 `x_t` 和上一时刻的隐状态 `h_{t-1}` 共同决定：

```
h_t = tanh(W_xh · x_t + W_hh · h_{t-1} + b_h)
o_t = W_ho · h_t + b_o
```

- `x_t`：时刻 t 的输入向量（比如一个词的嵌入）；
- `h_t`：时刻 t 的隐状态，可以理解为"读到目前为止的摘要"；
- `o_t`：时刻 t 的输出（比如预测下一个词的 logits）；
- `W_xh、W_hh、W_ho`：三组权重矩阵，**在所有时刻共享同一套**；
- `b_h、b_o`：偏置项。

共享参数是 RNN 的精髓：不管句子有 5 个词还是 500 个词，需要学的参数都一样多。同一个函数被反复应用在序列的每个位置上，就像一个"循环"，这也是名字的由来。

**训练方式与 BPTT**。把 RNN 沿时间展开后，它就是一个很深的网络（每个时间步一层）。损失通常是每个时刻的预测损失之和，梯度要沿着时间轴反向传播回去，这就是**沿时间反向传播**（Backpropagation Through Time, BPTT）。

**梯度消失与长程依赖**。反向传播到第 k 步时，梯度中包含一串 `W_hh` 的连乘。若其特征值小于 1，连乘会指数级缩小，第 1 步的信号传到第 50 步几乎归零——这就是**梯度消失**。直观地说：模型想学会"开头的主语决定结尾的动词形式"，但相隔太远时，相隔很远的词对当前输出的"影响通道"被磨没了，网络根本得不到有效的学习信号。若特征值大于 1，则会**梯度爆炸**（训练发散，可以用梯度裁剪缓解）。

## 三、数学形式（适度）

沿时间展开后，隐状态是递归定义的：

```
h_t = f(W_xh x_t + W_hh h_{t-1} + b_h)
```

对第 k 步求梯度，链式法则给出：

```
∂h_t/∂h_k = Π_{i=k+1}^{t} (W_hh^T · diag(f'(z_i)))
```

乘积里有 `t-k` 个近似相同的矩阵因子，模长按几何级数放大或缩小。比如 `‖W_hh‖ = 0.5`、激活近似线性时，相隔 50 步的梯度约为 `0.5^50 ≈ 10^{-15}`，实际上等于零。这就是"长程难记"的数学根源。总损失 `L = Σ_t l_t` 的梯度则是各时刻梯度之和，BPTT 只是链式法则在时间维上的系统化应用。

## 四、代码实现

```python
import torch
import torch.nn as nn

# 输入: batch=4, 序列长 T=20, 每个词嵌入 128 维
x = torch.randn(4, 20, 128)

rnn = nn.RNN(input_size=128, hidden_size=256,
             num_layers=2, batch_first=True)
# num_layers=2: 堆叠两层 RNN；batch_first=True 表示输入形状为 (B, T, F)

out, h_n = rnn(x)
# out:  (4, 20, 256) 每个时刻的输出；h_n: (2, 4, 256) 最后时刻的隐状态
print(out.shape, h_n.shape)
```

## 五、与其他技术对比

| 模型 | 长程依赖 | 并行能力 | 参数量 | 典型场景 |
|------|---------|---------|--------|---------|
| 全连接网络 | 无法建模时序 | 完全并行 | 随窗口增长 | 固定长度表格数据 |
| RNN | 短程尚可，长程弱 | 必须逐步串行 | 恒定，较小 | 短序列、流式预测 |
| LSTM/GRU | 明显改善 | 仍串行 | 略多 | 中长序列任务 |
| Transformer | 任意距离直连 | 全并行 | 较大 | 机器翻译、大模型 |

## 六、常见误区

- **误以为 RNN 天然能记住任意长的历史**。受梯度消失限制，普通 RNN 通常只能依赖几十步内的信息。
- **忽视 hidden 在 batch 之间的初始化**。不同样本独立时应把 `h` 清零；同一段长音频按块切分时则应保留，否则会切断上下文。
- **以为循环次数越多越强大**。参数共享意味着容量有限，一味加深层数反而更难训练。
- **把"输出 out"和"最后隐状态 h_n"混为一谈**。做分类常用 `h_n`，做逐时刻标注（如词性标注）则用 `out`。
- **认为 RNN 已经过时所以不用学**。它是理解门控机制、BPTT 和序列建模思想的必经之路。

## 八、面试题

1. **BPTT 和普通反向传播的区别？** 要点：RNN 展开后共享权重，梯度沿时间轴累加回传；序列越长连乘因子越多，故更易梯度消失/爆炸。
2. **为什么 RNN 难以学习长程依赖？** 要点：`W_hh` 连乘导致梯度指数衰减，远处词对当前输出的学习信号趋近于零。
3. **梯度爆炸怎么处理？** 要点：梯度裁剪（按范数截断）、调小学习率；梯度消失则靠 LSTM/GRU 或注意力。
4. **RNN 的参数量和序列长度有关吗？** 要点：无关，权重跨时刻共享，这也是它能处理变长序列的原因。

## 九、演进与趋势

RNN 的演化脉络非常清晰：1990 年代 Elman/Jordan 提出简单 RNN；1997 年 Hochreiter 与 Schmidhuber 提出 LSTM，用门控缓解梯度消失；2014 年 Cho 等提出更轻量的 GRU。同一时期，注意力机制（Attention）被引入机器翻译，人们逐渐发现：与其让信息一步步挤过狭窄的隐状态，不如让每个位置直接"看"任何位置。2017 年 Transformer 问世后，NLP 主战场全面转向注意力架构。不过 RNN 并未消失——2024 年以来状态空间模型（如 Mamba）以线性递归的方式重新杀回长序列建模，可视为"RNN 思想 + 现代工程"的复兴；流式语音、实时字幕等对延迟敏感的场景中，RNN/GRU 因逐帧出结果仍在服役。

## 十、小结

RNN 用一个共享参数的递归公式把历史压缩进隐状态，优雅地解决了变长序列与顺序建模问题。它的核心矛盾在于：信息要跨越很长时间传播，而链式法则的连乘却让梯度（和信息）指数衰减——这就是长程依赖难题。理解了这一点，就理解了为什么后面要发明 LSTM/GRU 的门控，也理解了为什么注意力机制最终绕开了"挤牙膏式"的信息传递。RNN 是序列建模的思想源头，值得打好基础。
