# 反向传播

> 对应 d2l-zh 第4章「自动求导」与第5章「深度学习计算」；历史源头为 Rumelhart, Hinton & Williams, *Nature* 1986。反向传播是链式法则在计算图上的系统化应用，是训练一切神经网络的引擎。

## 一、背景与挑战

训练神经网络的目标说白了就一句话：**找到让损失函数尽量小的参数**。常见做法是梯度下降——沿着损失下降最快的方向（负梯度方向）一小步一小步地挪。所以核心问题是：**损失对几百万甚至上千亿个参数的梯度，怎么高效算出来？**

朴素的思路是"数值差分"：把参数 w 加一个极小的 ε，看损失变了多少，近似得到 `(L(w+ε) - L(w)) / ε`。这招很直观，但代价恐怖：每个参数都要额外跑一次前向传播，模型有 N 个参数就得算 N+1 次，面对亿级参数完全不可行。

反向传播（backpropagation）的洞见在于：网络虽然层数多、结构复杂，但**整体是一个由简单函数嵌套而成的复合函数**。复合函数求导有现成的武器——**链式法则**。把整条链上的局部导数**从后往前乘一遍**，一次反向扫描就能得到所有参数的梯度，成本和前向传播同阶。这是深度学习得以存在的工程基石。

## 二、核心原理

**1. 链式法则**。若 `y = f(u)`、`u = g(x)`，则：

```
∂y/∂x = ∂y/∂u · ∂u/∂x
```

多层只是反复套用：`L ← a³ ← a² ← a¹ ← 输入`，把沿途每一段的局部导数乘起来即可。

**2. 计算图**。前向传播时，框架把每个运算节点（加、乘、矩阵乘、ReLU…）记录成一张**有向无环图**，同时缓存中间结果。反向传播时，梯度从损失节点出发，按拓扑序的**逆序**流回每个节点；每个节点只需知道"我输出的梯度"和"我这一步的局部导数"，两者相乘就传给了上游。这就是**前向记录运算，反向传播梯度**。

**3. 为什么反向比前向划算？** 对每个节点，局部导数的计算量与该步前向大致相当，且每条边只走一次，所以反向传播的时间复杂度与前向传播是**同一阶**（常数倍关系）。深度学习框架（PyTorch 的 autograd、TensorFlow 的 GradientTape）把这套流程全自动化了——你只管用普通 Python 代码搭模型，`loss.backward()` 一行就得到所有梯度。

**4. 梯度消失与爆炸**。深层网络里梯度同样是一串连乘：激活函数导数（如 sigmoid 最大才 0.25）与权重反复相乘，层数一深就指数级缩小（梯度消失），底层根本收不到学习信号；若权重偏大则反向爆炸。这直接决定了实践中的关键选择：**激活函数选 ReLU 系**（正区间导数为 1，不易消失）、**权重合理初始化**、深层网络配**残差连接**。梯度爆炸相对好办，用梯度裁剪就能压住。

## 三、数学形式（适度）

记第 l 层的预激活 `z^l = W^l a^{l-1} + b^l`、激活 `a^l = σ(z^l)`，损失 L。定义**残差** `δ^l = ∂L/∂z^l`，则有著名的逐层回传公式：

```
δ^L = ∇_{a^L} L ⊙ σ'(z^L)                       # 输出层
δ^l = ((W^{l+1})^T δ^{l+1}) ⊙ σ'(z^l)           # 回传一层
∂L/∂W^l = δ^l (a^{l-1})^T                       # 该层权重梯度
∂L/∂b^l = δ^l
```

其中 ⊙ 是逐元素乘，`(W^{l+1})^T` 负责把梯度"送回"上一层。所有符号：`W^l` 是第 l 层权重矩阵，`a^l` 是第 l 层输出，`σ` 是激活函数，`L` 是标量损失。向量/矩阵情形统一用 Jacobian 表述，工程上则由 autograd 按计算图自动完成，初学者不必手推。

## 四、代码实现

```python
import torch

# 最小例子: 手动观察 autograd
x = torch.tensor(2.0, requires_grad=True)   # 可求导的标量
y = x ** 2 + 3 * x + 1
y.backward()                                 # 触发反向传播
print(x.grad)        # dy/dx = 2x + 3 = 7.0

# 真实模型的标准训练步
model = torch.nn.Linear(8, 2)
opt = torch.optim.SGD(model.parameters(), lr=0.1)
inputs = torch.randn(16, 8)
labels = torch.randint(0, 2, (16,))

logits = model(inputs)                       # 前向传播
loss = torch.nn.functional.cross_entropy(logits, labels)
opt.zero_grad()                              # 清空上一步梯度(默认累加!)
loss.backward()                              # 反向传播: 填充 param.grad
opt.step()                                   # 按梯度更新参数
```

## 五、与其他技术对比

| 方法 | 思路 | 每参数成本 | 适用 |
|------|------|-----------|------|
| 数值差分 | 加 ε 看变化 | 一次完整前向 | 小模型验证 |
| 符号求导 | 解析化简公式 | 推导复杂 | 教科书推导 |
| 反向传播 | 链式法则+缓存 | 与前向同阶 | 一切神经网络训练 |
| 前向-mode AD | 对输入方向求导 | 随输入维度增长 | 输入维低的场景 |

深度学习里输入维度极高、参数维度极高，所以**反向模式自动微分**（即工程意义上的反向传播）是唯一实用的选择；数值差分则退居"梯度检查"用途，用来验证 autograd 实现是否正确。

## 六、常见误区

- **多次 `backward` 前忘了 `zero_grad()`**。PyTorch 默认把梯度**累加**到 `.grad` 上，不清零会让本次梯度混入历史值，训练方向错误。
- **对 in-place 操作（如 `relu_()`）用 autograd**。会破坏反向传播需要的中间值，报版本错误。
- **把 `loss.item()` 当张量去 backward**。`.item()` 返回的是 Python 标量，梯度无处可挂，应保留 loss 张量本身调用 `.backward()`。
- **以为模型没梯度就是代码写错了**。有时只是 `requires_grad=False`、参数被冻住，或处在 `torch.no_grad()` 推理上下文里。
- **把梯度消失当成"模型不收敛"的唯一原因**。学习率过大导致的损失震荡、数据未归一化等也会表现得类似，需要分别排查。

## 八、面试题

1. **反向传播的计算复杂度为什么是前向的同阶？** 要点：每个节点反向只处理一次，局部导数开销与该步前向相当，总边数相同，故只是常数倍差异。
2. **梯度消失/爆炸与链式法则什么关系？** 要点：梯度是多层局部导数连乘，导数普遍 <1 则指数衰减（消失），权重偏大则指数放大（爆炸）；对应解法分别是 ReLU/残差/门控 与 梯度裁剪/好初始化。
3. **为什么数值梯度不能直接用来训练？** 要点：每个参数一次额外前向，N 参数需 N+1 次前向，复杂度不可接受，只适合小规模梯度检查。
4. **计算图是什么？动态图和静态图有何区别？** 要点：记录运算依赖的 DAG；PyTorch 动态图每次前向重建、灵活易调试，TensorFlow 1.x 静态图先建后跑、利于部署优化（TF2 已转向动态 eager）。

## 九、演进与趋势

1986 年反向传播让多层感知机第一次能真正训练，掀起了联结主义浪潮；但当时受 sigmoid 梯度消失与算力限制，深层网络仍训不动。2006 年 Hinton 提出逐层预训练，2012 年 AlexNet 用 GPU + ReLU + 更好的初始化把深度学习推入爆发期。此后自动微分逐渐"基础设施化"：Theano 开创符号微分先河，Caffe/TensorFlow/PyTorch 接力，如今 autograd 已是所有框架的标配，开发者几乎不再手推梯度。前沿方向上，前向模式 AD（JAX 等已支持）用于可微分编程与科学计算；高阶导数支撑元学习与对抗训练；40-bit/自适应精度反向传播则在大模型训练中节省显存。

## 十、小结

反向传播 = **链式法则 + 计算图 + 从后往前的一次扫描**。它把"每个参数一个一个数值求导"的噩梦，变成与前向传播同阶的高效计算，是深度学习的底层引擎。理解三个要点即可融会贯通：前向缓存中间值、反向逐节点乘局部导数、连乘结构天然带来梯度消失/爆炸——后者直接解释了为什么我们要选 ReLU、做残差连接、用门控结构。现代框架已把这一切藏进 `loss.backward()`，但理解原理能让你在训练异常时看出问题出在哪一层。
