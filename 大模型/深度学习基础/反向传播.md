# 反向传播

> 对应 d2l-zh 第4章「自动求导」与第5章「深度学习计算」。反向传播是链式法则在计算图上的系统化应用。

## 一、核心概念

反向传播(backpropagation)利用**链式法则**高效计算损失对每个参数的梯度。前向传播构建计算图，反向传播自顶向下传播梯度。

链式法则：

```
若 y = f(u), u = g(x)，则 ∂y/∂x = ∂y/∂u · ∂u/∂x
```

对向量/矩阵情形使用 Jacobian 乘积。

## 二、数学形式

设损失 `L`，最后一层输出 `a^L`，残差 `δ^L = ∇_{a^L} L ⊙ σ'(z^L)`。逐层反向：

```
δ^l = ((W^{l+1})^T δ^{l+1}) ⊙ σ'(z^l)
∂L/∂W^l = δ^l (a^{l-1})^T
```

现代框架(autograd)自动完成上述展开，无需手写。

## 三、代码实现

```python
import torch

x = torch.tensor(2.0, requires_grad=True)
y = x ** 2 + 3 * x + 1
y.backward()
print(x.grad)   # dy/dx = 2x + 3 = 7.0
```

复杂模型同理：`loss.backward()` 后各 `param.grad` 即梯度。

## 四、关键要点

| 概念 | 说明 |
|------|------|
| 计算图 | 前向记录运算 |
| 链式法则 | 梯度分解 |
| autograd | 自动反向 |
| 梯度检查 | 数值差分验证 |

## 五、常见误区

- 多次 `backward` 前未 `zero_grad`，梯度累加导致错误。
- 对 `in-place` 操作使用 autograd 会报版本错误。
- 把 `loss.item()` 误当张量用于反向。
