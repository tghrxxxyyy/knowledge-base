# 正则化与泛化

> 对应 d2l-zh 第 4 章「权重衰减」、第 5 章「Dropout」与训练集/验证集相关小节。目标是提升模型在未见数据上的泛化能力。

## 一、背景与挑战

我们训练模型的目的从来不是“把训练题做对”，而是**在没见过的新题上也做对**——这个能力叫泛化。可深度模型参数动辄上亿，把训练集“背下来”太容易了：训练损失一路降到接近 0，换到验证集误差却不降反升，这就是**过拟合**。好比一个只靠刷题库的学生，题库里的题全会做，换个新题型就懵了。造成过拟合的常见原因有三个：数据太少、模型太大、训练太久。正则化就是一系列“防止背题、逼模型学通法”的手段。即使到了大模型时代，预训练数据海量、模型甚至受益于适度过拟合，这些基本思想依然以新的形式继续生效。

## 二、核心原理

常用手段可以按“从哪下手”分成三类。

**1. 约束权重（让模型简单点）**

- **L2 / 权重衰减**：在损失上加 `λ‖θ‖²`，惩罚过大的参数。直觉是：同样能拟合训练数据的两组权重，模型偏好“更小更平滑”的那组，因为小扰动不会让输出剧烈变化。数学上等价于给参数加了均值为 0 的高斯先验。
- **早停**：监控验证误差，一旦开始上升就停止训练，相当于在“欠拟合—刚好—过拟合”的时间轴上踩刹车。

**2. 扰动模型或数据（让背题变难）**

- **Dropout**：训练时随机把一部分神经元置零，每次迭代相当于训练一个不同的子网络，推理时合起来近似指数级子网络的集成。
- **数据增强**：对图像做翻转裁剪、对文本做同义改写，人工扩充训练分布，直接告诉模型“这种变形答案不变”。

**3. 划清界限（诚实评估）**

数据必须分成**训练集、验证集、测试集**：训练集学参数，验证集选超参和早停，测试集只在最后碰一次。三者混用，指标就是自欺欺人。

## 三、数学形式

带 L2 的目标函数：

```
L_reg(θ) = L(θ) + (λ/2)‖θ‖²
```

对其求梯度后，更新变为 `θ ← (1 − ηλ)θ − η∇L`：每步先按比例把权重缩小一点点，再沿梯度走，所以叫“权重衰减”。λ 越大，约束越强。

Dropout 训练时（以概率 p 丢弃，并做缩放保持期望不变）：

```
y = Dropout(x) / (1 − p)   # inverted dropout
```

推理时**不做 dropout**，直接用原输出，这样训练与推理的数值期望才一致。

## 四、代码实现

```python
import torch
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Dropout(p=0.5),   # 训练时随机置零一半神经元
    nn.Linear(256, 10),
)

# 权重衰减：AdamW 的解耦写法，比普通 Adam + L2 更标准
opt = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-4)

for x, y in train_loader:
    model.train()            # 开启 dropout
    loss = nn.functional.cross_entropy(model(x), y)
    opt.zero_grad(); loss.backward(); opt.step()

model.eval()                 # 推理前务必关闭 dropout
with torch.no_grad():
    acc = (model(x_val).argmax(1) == y_val).float().mean()
```

## 五、与其他技术对比

| 方法 | 作用位置 | 机制 | 优点 | 注意事项 |
|------|----------|------|------|----------|
| L2 / 权重衰减 | 损失函数 | 惩罚大权重 | 简单、通用 | λ 需调；bias/BN 通常不衰减 |
| Dropout | 网络层 | 随机置零神经元 | 近似模型集成 | 推理要 `eval()`；小数据更有效 |
| 早停 | 训练过程 | 验证误差上升即停 | 免调正则强度 | 需要干净的验证集 |
| 数据增强 | 数据 | 扩充样本分布 | 直接提升泛化 | 变换须符合任务先验 |
| 批归一化 | 层间 | 稳定激活分布 | 有间接正则效果 | 大 batch 下收益减弱 |

## 六、常见误区

1. **推理时忘了关 Dropout**：不调用 `model.eval()` 会让输出带随机性，评测结果不稳定——这是新手最常见的坑。
2. **对所有参数一律 weight_decay**：偏置和归一化层的参数通常不该衰减，主流做法只对权重矩阵施加（AdamW 加参数分组）。
3. **正则化越强越好**：过强会把模型“捆死”导致欠拟合，训练误差和验证误差一起变高；λ 和 dropout 率都需要调。
4. **训练好就等于泛化好**：训练误差只说明记住了题；判断泛化必须看独立的验证集，最终结论只看测试集。
5. **数据增强可以随便加**：把猫上下翻转可能变成不像猫的图；增强方式必须符合“标签不变”的假设。
6. **大模型时代这些手段都没用了**：并非如此，权重衰减、dropout、数据去重仍是 LLM 训练里的常规操作，只是强度和形式变了。

## 八、面试题

1. **Dropout 为什么能近似集成学习？**
   要点：每次迭代随机丢弃等价于从指数级子网络中采样一个来训练，权重共享相当于对这些子网络做平均，推理时的等效结构近似模型集成。
2. **L1 和 L2 正则对权重的影响有何不同？**
   要点：L1 倾向产生稀疏权重（部分恰好为 0，可做特征选择），L2 让权重整体变小但一般不为 0；可用等高线与菱形/圆形约束的切点做几何解释。
3. **怎么判断模型过拟合了？该怎么做？**
   要点：训练误差低而验证误差升高；对策包括增数据、加正则、早停、减小模型容量。
4. **为什么训练、验证、测试要分三个集合？**
   要点：训练学参数、验证选超参、测试给最终无偏估计；只分两个会导致选超参的过程间接污染测试指标。
5. **权重衰减和 L2 损失完全等价吗？**
   要点：SGD 下等价；Adam 等自适应优化器下不等价，衰减量会被二阶矩缩放，所以 AdamW 把衰减从梯度中解耦出来。

## 九、演进与趋势

早年经典三件套是 L2、Dropout、数据增强；深度学习中期加入了批归一化（本身带轻微正则效果）、标签平滑和更强的数据增强（AutoAugment、Mixup）。到了大模型时代，正则化的形态发生变化：**数据质量与去重**成了首要正则，海量数据本身抑制过拟合；dropout 在 LLM 预训练中常被调低甚至设为 0；权重衰减仍以 AdamW 的形式标配存在；另一方面，“泛化”的讨论扩展到了涌现能力与上下文学习。变化的是强度与载体，不变的是那条底线——**永远用没见过的数据检验模型**。

## 十、小结

正则化的全部目的只有一个：**把“背题”逼成“学通法”**。L2 让权重变小变稳，Dropout 靠随机丢神经元逼近模型集成，数据增强直接扩充分布，早停在过拟合前刹车；而训练-验证-测试三分是这一切的前提。入门阶段先把“推理关 dropout、验证集选超参、正则别调过头”这三件事做对，再逐步理解它们在大模型训练中以数据质量和 AdamW 等新形式的延续。
