# 正则化与泛化

> 对应 d2l-zh 第4章「权重衰减」与第5章「Dropout」。目标是提升模型在未见数据上的泛化能力。

## 一、核心概念

- **过拟合**：训练误差低、验证误差高。
- **权重衰减(L2)**：损失加 `λ‖θ‖²`，等价于 MAP 高斯先验。
- **Dropout**：训练时以概率 `p` 随机置零神经元输出，等价于集成指数级子网络。
- **早停(early stopping)**：验证误差上升即停。
- **数据增强**：扩充训练分布。

## 二、数学形式

带 L2 的损失：

```
L_reg(θ) = L(θ) + (λ/2) ‖θ‖²
```

梯度更新变为 `θ ← (1-ηλ) θ - η ∇L`，故又称"权重衰减"。

Dropout 训练时缩放：`y = Dropout(x) / (1-p)`（推理时不丢弃，或用 inverted dropout 在前向补偿）。

## 三、代码实现

```python
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Dropout(p=0.5),
    nn.Linear(256, 10),
)
# 优化器加权重衰减
opt = torch.optim.Adam(model.parameters(), lr=1e-3, weight_decay=1e-4)
```

## 四、关键要点

| 方法 | 机制 | 注意 |
|------|------|------|
| L2 | 限制权重大小 | `weight_decay` |
| Dropout | 子网络集成 | 仅训练期 |
| 早停 | 控制容量 | 需验证集 |
| 数据增强 | 扩充分布 | 领域相关 |

## 五、常见误区

- 推理阶段忘记关闭 Dropout（`model.eval()`）。
- `weight_decay` 误用于 bias/BN 参数。
- 认为正则越强越好，过强导致欠拟合。
