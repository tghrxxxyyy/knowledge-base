# LSTM 与 GRU

> 对应 d2l-zh 第9章「长短期记忆网络 (LSTM)」；经典论文为 Hochreiter & Schmidhuber, 1997。门控机制让梯度拥有"高速公路"，缓解 RNN 的梯度消失问题。

## 一、背景与挑战

普通 RNN 的致命弱点上一篇已经讲过：隐状态每一步都被 `tanh` 和矩阵乘法**彻底重写**，梯度沿时间连乘后指数衰减，导致"前文说了什么，后文记不住"。

用一个类比：普通 RNN 像一位**每次都从头整理便签的读者**——新信息一来就把旧摘要覆盖一遍，读到第 50 页时，第 1 页的关键细节早被冲掉了。而我们希望的状态是：**有些信息可以原样长期保留，有些新信息按需写入，还有些内容到需要时才提取出来**。

LSTM（Long Short-Term Memory，长短期记忆网络）正是为此设计：它额外维护一条**细胞状态** `c_t`，像一条贯穿所有时刻的传送带，信息可以在上面近似无损地流动；三个"门"则决定往传送带上放什么、拿掉什么、输出什么。GRU 是后来的简化版，用两个门达到类似效果，参数更少、训练更快。

## 二、核心原理

**LSTM 的三个门**（门的输出是 0~1 的向量，由 sigmoid 产生，表示"通过比例"）：

- **遗忘门** `f_t = σ(W_f · [h_{t-1}, x_t] + b_f)`：决定**丢弃多少旧的细胞状态**。比如读到"新一段话"时，把上一段的主语信息清掉。
- **输入门** `i_t = σ(W_i · [h_{t-1}, x_t] + b_i)` 与**候选记忆** `g̃_t = tanh(W_g · [h_{t-1}, x_t] + b_g)`：前者决定"写不写"，后者是准备写入的新内容。
- **输出门** `o_t = σ(W_o · [h_{t-1}, x_t] + b_o)`：决定**细胞状态的哪些部分暴露给隐状态**，供下一步和当前输出使用。

更新公式：

```
c_t = f_t ⊙ c_{t-1} + i_t ⊙ g̃_t        # 旧记忆按比例保留 + 新记忆按比例写入
h_t = o_t ⊙ tanh(c_t)                   # 输出门过滤后的隐状态
```

**为什么能缓解梯度消失？** 关键在 `c_t = f_t ⊙ c_{t-1} + ...` 这一行：梯度沿时间反传时，会经过一串**逐元素相乘的遗忘门** `f_t`。如果遗忘门学会接近 1（"别删"），梯度就能几乎无损地传回很多步之前——传送带上的信息和梯度都有了"高速公路"。而且加法更新让信息流是**加性**的而非连乘 `W_hh`，衰减慢得多。

**GRU 的两个门**：

- **更新门** `z_t`：控制"旧状态保留多少、新候选写入多少"，一个门同时管 LSTM 的遗忘+输入两件事。
- **重置门** `r_t`：控制"计算新候选时，旧隐状态参与多少"，便于在需要时忘掉无关历史。

## 三、数学形式（适度）

GRU 完整公式（⊙ 表示逐元素乘）：

```
z_t = σ(W_z [h_{t-1}, x_t] + b_z)         # 更新门
r_t = σ(W_r [h_{t-1}, x_t] + b_r)         # 重置门
h̃_t = tanh(W [r_t ⊙ h_{t-1}, x_t] + b)   # 候选隐状态
h_t = (1 - z_t) ⊙ h_{t-1} + z_t ⊙ h̃_t    # 插值混合
```

最后一步是个凸组合：`z_t ≈ 0` 时几乎原样保留旧状态（记忆模式），`z_t ≈ 1` 时用新候选替换（更新模式）。反向传播时，`∂h_t/∂h_{t-1}` 中含有 `(1 - z_t)` 这一加性通路，只要更新门保持较小，梯度就能长距离存活。

参数量对比（设输入维度 n、隐层维度 h，忽略偏置）：RNN 约 `2nh`（两个矩阵）；LSTM 有四个门，约 `4nh`；GRU 三个门，约 `3nh`。

**直觉再总结一遍**：把细胞状态想象成一条流水线上的货箱，遗忘门决定"清掉哪些旧货"，输入门决定"装入哪些新货"，输出门决定"当前从货箱里取什么给下一道工序"。三个开关都是网络根据上下文学出来的软比例，因此模型可以学会"主语出现时记住、句号出现时清空"这类有节奏的记忆策略。

## 四、代码实现

```python
import torch
import torch.nn as nn

x = torch.randn(4, 20, 128)   # (batch=4, T=20, 特征=128)

lstm = nn.LSTM(input_size=128, hidden_size=256, batch_first=True)
out, (h_n, c_n) = lstm(x)     # LSTM 返回隐状态和细胞状态两份"记忆"
print(out.shape, h_n.shape, c_n.shape)   # (4,20,256) (1,4,256) (1,4,256)

gru = nn.GRU(input_size=128, hidden_size=256, batch_first=True)
out2, h2 = gru(x)             # GRU 只有一份隐状态
print(out2.shape, h2.shape)
```

## 五、与其他技术对比

| 模型 | 门数 | 状态 | 参数量 | 长程能力 | 速度 |
|------|------|------|--------|---------|------|
| 简单 RNN | 0 | 单一隐状态 | 最少 | 弱 | 最快 |
| LSTM | 3 | 细胞+隐状态 | 最多 | 强 | 较慢 |
| GRU | 2 | 单一隐状态 | 居中 | 接近 LSTM | 较快 |
| Transformer | — | 显式记忆(KV) | 大 | 最强 | 可并行 |

**何时用谁**：序列不长、追求速度或数据少时，GRU 是稳妥的默认选择；序列较长、需要精细控制记忆与输出（如机器翻译、语音识别的经典配置）时用 LSTM；数据充足且能并行、依赖跨度极大时，优先 Transformer。实践上两者差距往往小于超参影响，**以实验为准**。

## 六、常见误区

- **认为 LSTM 完全解决了长程依赖**。它大幅缓解而非根治，几百上千步的超长序列依然吃力，最终被注意力机制取代。
- **认为 GRU 总是优于 LSTM**。GRU 只是更省参数，效果与任务和调参有关，没有普适胜负。
- **以为三个门是"人工规则"**。门的输出完全由网络自己学出来，sigmoid 只提供 0~1 的软开关语义。
- **忘记 LSTM 有两个状态**。保存/恢复模型时 `h_n` 和 `c_n` 都要带上，只留一个会丢记忆。
- **把 `tanh(c_t)` 忘掉**。细胞状态数值可能越积越大，输出前过一次 `tanh` 把值域拉回 [-1,1]，数值更稳定。

## 八、面试题

1. **LSTM 的遗忘门如何缓解梯度消失？** 要点：细胞状态是加法更新，反传梯度乘一串遗忘门；遗忘门学会≈1 时形成近乎无损的梯度通路，避免 `W_hh` 连乘衰减。
2. **GRU 与 LSTM 的核心差异？** 要点：GRU 两个门、无独立细胞状态、参数更少；更新门合并了 LSTM 的遗忘门与输入门，实验效果通常相当。
3. **为什么门用 sigmoid 而不用别的？** 要点：sigmoid 输出 (0,1)，天然表达"通过比例"，实现软性的可学习开关。
4. **序列很短时该选哪个？** 要点：短序列上三者差别不大，可优先用更简单的 GRU 或普通 RNN，把精力放在调参和数据上。

## 九、演进与趋势

LSTM 在 2010 年代统治了机器翻译、语音识别、文本生成等任务，配合注意力机制取得了第一批突破性成果。2014 年 GRU 以更简的结构成为流行的轻量替代。2017 年之后，Transformer 凭借全并行与更强的长程建模能力成为主流，LSTM 退居"轻量时序模型"的位置。但故事没有结束：忘却门控的极简思路（如 PyTorch 的 LayerNormLSTM）、以及近年状态空间模型（S4、Mamba）用可控的线性动力学实现超长序列建模，都可看作"门控 RNN 精神"的现代回归。在端侧小模型与流式场景中，GRU/LSTM 依然实用。

## 十、小结

LSTM 的核心发明是**细胞状态这条加法传送带 + 三个可学习的软开关**，把"记忆"和"门控"解耦，让梯度和信息都能找到长距离通路；GRU 则证明了更精简的两个门同样有效。记住门的直觉——遗忘门管删、输入门管写、输出门管读——比死记公式更重要。同时要清醒：门控是缓解而非消灭长程难题，当依赖跨度真正变得极大时，注意力机制给出了另一种答案。
