# 梯度下降与学习率

> 对应 d2l-zh 第4章（自适应计算图与自动求导）与优化章节。梯度下降是训练神经网络的通用引擎。

## 一、核心概念

目标是最小化损失 `L(θ)`。参数为 `θ`，梯度 `∇_θ L` 指向损失上升最快方向，故沿负梯度更新：

```
θ ← θ - η ∇_θ L
```

`η` 为学习率，是深度学习中最敏感的超参数。

- **批量大小(Batch)**：全批量梯度下降稳定但慢；随机(SGD)快但噪声大；小批量是实践标准(如 32/64/128)。
- **学习率调度**：固定、阶梯衰减、余弦退火(cosine annealing)、warmup。

## 二、数学形式

**梯度下降更新**：

```
θ_{t+1} = θ_t - η g_t,   g_t = ∇_θ L(θ_t)
```

**带动量的 SGD**(Polyak, 1964)：

```
v_t = γ v_{t-1} + η g_t
θ_{t+1} = θ_t - v_t
```

动量累积历史梯度方向，加速收敛并抑制震荡，`γ≈0.9`。

**Adam**(Kingma & Ba, 2015) 同时估计一阶矩(动量)与二阶矩(自适应学习率)：

```
m_t = β1 m_{t-1} + (1-β1) g_t
v_t = β2 v_{t-1} + (1-β2) g_t²
m̂_t = m_t / (1-β1^t),  v̂_t = v_t / (1-β2^t)
θ_{t+1} = θ_t - η m̂_t / (√v̂_t + ε)
```

默认 `β1=0.9, β2=0.999, ε=1e-8`。

## 三、代码实现

params = [torch.randn(3, requires_grad=True)]
opt = torch.optim.Adam(params, lr=3e-4, betas=(0.9, 0.999))

## 四、关键要点

| 优化器 | 特点 | 典型 η |
|--------|------|--------|
| SGD | 稳定、需调 lr | 1e-2 ~ 1e-1 |
| SGD+Momentum | 加速收敛 | 1e-2 |
| Adam | 自适应、默认首选 | 1e-4 ~ 3e-4 |
| AdamW | 解耦权重衰减 | 1e-4 |

## 五、常见误区

- 学习率过大导致发散，过小导致陷入局部平坦区。
- Adam 中权重衰减应配合 `AdamW`(解耦衰减)，否则效果打折。
- warmup 缺失时大模型训练初期易不稳定。
