# 概率与信息论基础

> 对应 d2l-zh 第3章。深度学习用概率建模不确定性，用信息论度量分布差异。

## 一、核心概念

- **条件概率与贝叶斯**：`P(A|B) = P(A,B)/P(B) = P(B|A)P(A)/P(B)`。贝叶斯推断是生成式模型与校准的基础。
- **期望与方差**：`E[X] = Σ_x x P(x)`，`Var(X) = E[(X-E[X])²]`。
- **熵**：分布 `P` 的香农熵 `H(P) = -Σ_i P(i) log P(i)`，衡量不确定性。
- **KL 散度**：`D_KL(P‖Q) = Σ_i P(i) log(P(i)/Q(i))`，非负、非对称，衡量两分布差异。
- **交叉熵**：`H(P,Q) = -Σ_i P(i) log Q(i) = H(P) + D_KL(P‖Q)`。分类损失即交叉熵。

## 二、数学形式

**最大似然估计(MLE)**：给定样本 `x_1..x_n`，最大化

```
θ* = argmax_θ Π_i p(x_i; θ) = argmax_θ Σ_i log p(x_i; θ)
```

最小化负对数似然等价于最小化经验分布与模型分布的交叉熵。

## 三、代码实现

```python
import torch
import torch.nn.functional as F

logits = torch.tensor([[2.0, 0.5, 0.3], [0.1, 1.5, 0.2]])
target = torch.tensor([0, 1])
loss = F.cross_entropy(logits, target)   # 已含 softmax
print(loss.item())
```

## 四、关键要点

| 量 | 含义 | 用途 |
|----|------|------|
| 熵 H(P) | 不确定性 | 决策阈值 |
| KL | 分布差异 | 蒸馏、正则 |
| 交叉熵 | 分类损失 | 训练目标 |
| MLE | 参数估计 | 似然最大化 |

## 五、常见误区

- 混淆 KL 的对称性：`D_KL(P‖Q) ≠ D_KL(Q‖P)`，二者在变分推断中角色不同。
- 用 `softmax` 后再 `NLLLoss` 与直接用 `cross_entropy` 重复归一化。
