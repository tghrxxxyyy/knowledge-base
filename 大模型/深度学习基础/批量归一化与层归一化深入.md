# 批量归一化与层归一化深入

> 深入对比 BN/LN 在 CNN 与 Transformer 中的角色（d2l-zh 第7章、第11章）。

## 一、核心差异

- **BN**：跨 batch 归一化，依赖 batch 统计，batch 过小或不稳定时误差大。
- **LN**：对单样本特征维归一化，batch 无关，是 Transformer 标配。
- **RMSNorm**(LLaMA 等采用)：省略均值中心化，仅除以 RMS：

```
x̂_i = x_i / √( (1/d) Σ_j x_j² + ε ),  y = γ ⊙ x̂
```

计算更省、数值稳定。

## 二、代码实现

```python
import torch.nn as nn
ln = nn.LayerNorm(4096)
# RMSNorm 需自定义
class RMSNorm(nn.Module):
    def __init__(self, d, eps=1e-6):
        super().__init__()
        self.gamma = nn.Parameter(torch.ones(d))
        self.eps = eps
    def forward(self, x):
        rms = x.pow(2).mean(-1, keepdim=True).add(self.eps).sqrt()
        return self.gamma * (x / rms)
```
