# 线性代数基础

> 深度学习以线性代数为语言。本节内容对应《动手学深度学习》(Dive into Deep Learning, d2l-zh, Zhang et al.) 第2章，给出张量运算与矩阵分解的核心结论。

## 一、核心概念

深度学习中的数据与参数几乎都以**张量(tensor)**形式存在：标量是 0 阶张量，向量是 1 阶，矩阵是 2 阶，更高维的批量数据则是 3 阶及以上。神经网络的前向传播本质是一连串张量线性变换加非线性激活。

- **矩阵乘法**：对 `A ∈ ℝ^{m×k}`、`B ∈ ℝ^{k×n}`，乘积 `C = AB` 满足 `C_{ij} = Σ_k A_{ik} B_{kj}`。注意矩阵乘法**不满足交换律**(`AB ≠ BA`)，但满足结合律。
- **Hadamard 积**：`A ⊙ B` 表示逐元素相乘，要求形状相同。
- **转置**：`(AB)^T = B^T A^T`。
- **范数**：`ℓ_p` 范数 `‖x‖_p = (Σ_i |x_i|^p)^{1/p}`；`ℓ_2` 即欧氏范数，`ℓ_1` 在稀疏正则中常用。

## 二、数学形式

**奇异值分解(SVD)**：任意矩阵 `A ∈ ℝ^{m×n}` 可分解为

```
A = U Σ V^T
```

其中 `U ∈ ℝ^{m×m}`、`V ∈ ℝ^{n×n}` 为正交矩阵，`Σ ∈ ℝ^{m×n}` 为对角矩阵，对角元为奇异值 `σ_i ≥ 0`。SVD 是 PCA 与主成分分析的理论基础。

**Moore-Penrose 伪逆**：当 `A` 不可逆时，`A^+ = V Σ^+ U^T`，其中 `Σ^+` 将非零奇异值取倒数后转置。用于求解最小二乘 `x = A^+ b`。

## 三、代码实现

```python
import torch

A = torch.tensor([[1., 2.], [3., 4.], [5., 6.]])   # 3x2
B = torch.tensor([[0., 1.], [1., 0.]])            # 2x2
print((A @ B).shape)        # 矩阵乘法 -> torch.Size([3, 2])
print((A * B.t()).shape)    # 逐元素需对齐形状

# SVD
U, S, Vt = torch.svd(A)
print(S)                    # 奇异值
recon = U @ torch.diag(S) @ Vt
print(torch.allclose(recon, A, atol=1e-5))   # True
```

## 四、关键要点

| 概念 | 符号 | 作用 |
|------|------|------|
| 矩阵乘法 | `AB` | 线性变换组合 |
| Hadamard 积 | `A ⊙ B` | 逐元素门控(如 LSTM) |
| 转置 | `A^T` | 梯度推导 |
| 范数 | `‖x‖_p` | 正则化、收敛判据 |
| SVD | `UΣV^T` | 降维、稳定求逆 |

## 五、常见误区

1. 把逐元素乘法 `*` 当成矩阵乘法 `@`，导致形状或数值错误。
2. 认为 `AB = BA`，在构造可学习变换时混淆顺序。
3. 在高维张量上直接 `torch.inverse`，应先 `reshape` 为矩阵或使用伪逆。
