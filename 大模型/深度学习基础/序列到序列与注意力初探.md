# 序列到序列与注意力初探

> 对应 d2l-zh 第10章「注意力机制」。注意力机制是现代大模型的基础，本节先建立直觉。

## 一、核心概念

Seq2Seq 用编码器把源序列压成上下文向量，解码器据此生成目标序列。瓶颈：固定维度上下文难以承载长序列全部信息。

**注意力**让解码每步动态"查阅"编码器所有隐状态，按相关性加权：

```
上下文 c = Σ_i α_i h_i,  α_i = softmax(score(q, k_i))
```

`q` 为查询(解码隐状态)，`k_i/h_i` 为键/值(编码器状态)。

## 二、数学形式

加性注意力(Bahdanau)：

```
e_i = v^T tanh(W_q q + W_k k_i)
α_i = softmax(e_i)
```

点积注意力(后续 Transformer 基础)：`score(q,k) = q^T k / √d`。

## 三、代码实现

```python
import torch.nn.functional as F
def attention(q, k, v):
    scores = (q @ k.transpose(-2, -1)) / (k.size(-1) ** 0.5)
    weights = F.softmax(scores, dim=-1)
    return weights @ v, weights
```

## 四、关键要点

| 机制 | 优点 | 局限 |
|------|------|------|
| 固定上下文 | 简单 | 信息瓶颈 |
| 注意力 | 长程、可解释 | 计算 O(n²) |
