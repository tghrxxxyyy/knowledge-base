# 投机验证并行

> 对应投机采样的并行验证；与 内存高效注意力深入（一次前向）衔接。

## 一、背景与挑战

验证需对草稿段/树一次性前向，要求注意力支持多候选共享前缀 KV。

## 二、核心原理

把树展平为带位置/父指针的序列，一次前向得所有节点 logits；按概率沿树选接受路径，拒绝节点重采样。

## 三、数学形式

验证成本 $\approx$ 一次目标前向（序列长 $T$），与逐 token 串行解码比省 $T$ 次小前向。

## 四、代码实现

```python
logits = target.forward(tree_flat, past_kv=tree_kv)
accepted_len = select_path(logits, tree)
```

## 五、与其他对比

- 与 标准自回归（每 token 一次前向）对照；
- 与 连续批处理深入 共享 KV 复用。

## 六、常见误区

- 树展平后 attention mask 错致跨分支污染；
- 重采样实现不等价原分布。

## 七、与开源书对应

- rasbt/LLMs-from-scratch：https://github.com/rasbt/LLMs-from-scratch
- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 验证为何无损？答：沿树按目标分布重采样，保持与自回归同分布。

## 九、演进

串行验证 → 树并行验证 → 近似接受。

## 十、小结

并行验证借一次前向覆盖全树，是提速关键。
