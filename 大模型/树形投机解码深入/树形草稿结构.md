# 树形草稿结构

> 对应 Chen et al., *Accelerating LLM Decoding with Speculative Sampling*, 2023（树验证）。

## 一、背景与挑战

顺序投机每步只一条链，分歧处浪费；树形覆盖多候选分支，提高单次验证命中。

## 二、核心原理

草稿生成一棵树（多分支），目标模型对树所有节点一次注意力前向并行评分，按路径概率贪心选最长被接受前缀路径。

## 三、数学形式

树节点数 $T$；单次验证覆盖 $T$ 候选；接受路径长度期望高于链式 $\gamma$。

## 四、代码实现

```python
tree = draft.build_tree(x, depth=4, branch=3)
paths = target.verify_tree(x, tree)   # 一次前向
```

## 五、与其他对比

- 比 顺序投机 覆盖更广、单次性价比高；
- 与 自草稿 EAGLE深入 共享树。

## 六、常见误区

- 树过大致验证计算反超收益；
- 分支策略错配数据分布。

## 八、面试题

- 树形相对顺序优势？答：单次验证覆盖多分支，提高命中、降草稿轮次。

## 九、演进

链 → 平衡树 → 自适应树。

## 十、小结

树形草稿以分支覆盖提单次验证收益，是投机主流形态。
