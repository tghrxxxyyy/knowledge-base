# 投机解码总览

> 对应 Leviathan et al., *Speculative Decoding*, 2023；与 自回归解码深入 衔接。

## 一、背景与挑战

大模型 decode 自回归串行、每步算少带宽大；小草稿模型并行猜多 token，大模型一次验证提效。

## 二、核心原理

草稿模型（小、快）顺序生成 $\gamma$ 个候选；目标模型（大）对整段一次性并行评分，按接受率保留前缀，拒绝处重采样。

## 三、数学形式

期望接受步长 $E[k]\approx\gamma\cdot\text{accept\_rate}$；加速约 $E[k]/(\text{草稿成本占比})$。

## 四、代码实现

```python
draft = small.generate(x, gamma)
accepted = target.verify(x, draft)      # 并行打分
```

## 五、与其他对比

- 与 树形投机解码（见下）对照（顺序 vs 树）；
- 与 预填充解码分离深入 可在 decode 侧叠加。

## 六、常见误区

- 以为草稿越快越好（质量低也白费）；
- 忽略验证仍受目标模型带宽限制。

## 八、面试题

- 投机解码为何无损？答：验证用目标模型分布重采样，接受与否保持原分布。

## 九、演进

顺序投机 → 树形 → 自草稿（EAGLE）。

## 十、小结

投机解码以草稿并行猜、目标验证，无损提速自回归。
