# 置信阈值与温度

> 见「自训练伪标签深入/自训练总览」；阈值/温度决定伪标签质量。

## 一、背景与挑战

何时采用伪标签？太松引入噪声，太紧样本少。

## 二、核心原理

用温度锐化预测（T<1 使分布更尖）后取 argmax，仅当 `max p > τ` 采用。温度调节置信集中度，τ 控制采用率。也可用**不确定性估计**替代硬阈值。

## 三、数学形式

`ŷ = argmax softmax(z/T)`，采用条件 `max p > τ`。

## 四、代码实现

```python
p = softmax(z / T)
if p.max() > tau: add_pseudo(x, p.argmax())
```

## 五、关键要点

- T 低更确定但更易错。
- τ 需随训练调整（后期可放宽）。

## 六、与其他对比

- 硬阈值简单；不确定性更稳。

## 七、常见误区

- τ 固定不变——应动态。
