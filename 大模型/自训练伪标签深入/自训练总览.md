# 自训练总览

> 见「半监督学习深入/伪标签与自训练」；经典自训练 + 大模型时代的再兴起。

## 一、背景与挑战

标注少、无标多，让模型自己扩标注。

## 二、核心原理

迭代：用当前模型给无标签打伪标签 → 高置信伪标签加入训练集 → 重训。伪标签本质是把模型预测当监督，配合置信过滤避免噪声。是大模型蒸馏（用强模型标弱模型）的核心机制。

## 三、关键要点

- 置信阈值是开关。
- 易确认偏差（错标固化）。

## 四、代码实现

```python
pseudo = model(xu).softmax(-1)
mask = pseudo.max(1) > tau
train = cat([labeled, xu[mask], pseudo[mask].argmax(1)])
```
