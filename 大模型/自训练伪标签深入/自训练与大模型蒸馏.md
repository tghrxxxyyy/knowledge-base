# 自训练与大模型蒸馏

> 见「自训练伪标签深入/自训练总览」与「知识蒸馏深入/大模型蒸馏实践」。

## 一、背景与挑战

用强 LLM 给弱 LLM 造训练数据。

## 二、核心原理

强模型（如 GPT-4 级）对大量 prompt 生成回答作为伪标签，弱模型在其上 SFT——这是现代「模型蒸馏」的核心做法（Alpaca 等）。本质自训练+强教师。

## 三、关键要点

- 教师数据多样性决定学生广度。
- 需过滤教师错误（教师非全对）。

## 四、代码实现

```python
data = [(p, strong_llm(p)) for p in prompts]
weak_sft(data)
```

## 五、与其他对比

- 经典自训练自己教；这里强教弱。

## 六、常见误区

- 教师全对——需筛选。
