# 噪声与确认偏差

> 见「自训练伪标签深入/自训练总览」与「噪声标签学习深入/噪声标签学习总览」。

## 一、背景与挑战

伪标签含错，模型反复学错会固化。

## 二、核心原理

确认偏差（confirmation bias）：早期错误伪标签被纳入，模型越学越信，错误自我强化。缓解：一致性正则（强增广应一致）、多模型投票、只取极高分、定期重生成伪标签。

## 三、关键要点

- 早期伪标签最危险。
- 结合半监督一致性可降噪。

## 四、代码实现

```python
# 仅极高置信 + 一致性
use = (p_w.max()>tau) & (p_s.argmax()==p_w.argmax())
```

## 五、与其他对比

- 真标签无此问题；伪标签需防。

## 六、常见误区

- 自训练无噪声——伪标签即噪声源。
