# 课程式自训练

> 见「自训练伪标签深入/自训练总览」与「课程学习深入/课程学习原理」。

## 一、背景与挑战

一次性用全部伪标签噪声大。

## 二、核心原理

由易到难：先采用高置信伪标签（易样本），随训练推进逐步放宽阈值纳入较难样本，类似课程学习（见课程学习章）。降低早期错误固化。

## 三、关键要点

- 早期严、后期松。
- 与一致性正则结合更稳。

## 四、代码实现

```python
tau = schedule(epoch)   # 随 epoch 下降
```

## 五、与其他对比

- 静态自训练全用；课程更稳。

## 六、常见误区

- 全量伪标签——噪声大。
