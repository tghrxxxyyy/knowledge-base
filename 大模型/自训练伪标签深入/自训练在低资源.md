# 自训练在低资源语言

> 见「自训练伪标签深入/自训练总览」与「多语言与跨语言深入」。

## 一、背景与挑战

低资源语言标注极少，跨语言迁移不够。

## 二、核心原理

用高资源语言模型为低资源生成伪标签/翻译对齐数据，自训练提升低资源能力；或跨语言一致性（同句多语编码应一致）做半监督。

## 三、关键要点

- 跨语言对齐质量决定效果。
- 文化特定任务难迁移。

## 四、代码实现

```python
pseudo = high_resource_model(translate(x, lang))
```

## 五、与其他对比

- 直训弱；伪标签补数据。

## 六、常见误区

- 翻译即等价——语义流失。

## 七、与开源书对应

- llm-course: https://github.com/mlabonne/llm-course
