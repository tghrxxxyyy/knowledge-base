# 激活修补与路径分解

> 对应 Goldowsky-Dill et al., *Localizing Model Behavior with Path Patching*, 2023；Zhang & Nanda, ICLR 2024。

## 一、背景与挑战

整体消融会同时切断组件的全部下游影响，无法分辨「它通过谁起作用」。路径分解把干预粒度细化到组件之间的边。

## 二、核心原理

路径 patch 只把某条「源组件到接收组件」的输入替换为对照运行的值，其余路径保持原状。

- 实施上需两次前向：记录对照运行的激活，再在目标运行中按边替换特定输入。
- 通过遍历接收端可画出组件间的因果图，从而重建电路而非仅列出重要组件。

## 三、数学形式

设组件 $s$ 到接收者 $r$ 的边，路径 patch 效应为 $\Delta_{s\to r}=m\big(x\big)-m\big(x;\ \mathrm{input}_r^{(s)}\leftarrow z_s^{corr}\big)$。

与整头消融 $\Delta_s$ 相比，$\sum_r \Delta_{s\to r}$ 可揭示 $s$ 的影响如何分摊到各下游路径。

## 四、代码实现

```python
def path_patch(run, src, dst, corr_cache):
    def hook(module, inp, out):
        out[:, :, dst] = out[:, :, dst] - run.cache[src] + corr_cache[src]
        return out                                   # 仅替换 src 经此边的输入
    return hook
```

## 五、与其他对比

- 与整头消融对照：路径 patch 分辨路径归属，代价是前向次数与实现复杂度上升。
- 与 归因方法的评估与陷阱 衔接：方向（加噪/去噪）与指标选择同样适用于路径分解。

## 六、常见误区

- 替换时忘记保持其他路径不变，导致效应被其他边污染。
- 在饱和的概率指标上做路径比较，弱路径被系统性低估。

## 八、面试题

- 路径 patch 解决什么？答：把「谁重要」细化为「谁通过哪条路径起作用」，用于重建电路。
- 实施要点？答：缓存对照激活、只替换目标边、用 logit 差等线性指标评估。

## 九、演进

整体消融 → 激活修补 → 路径级分解 → 自动电路发现与方法学规范。

## 十、小结

路径分解是从「重要组件清单」走向「可验证电路图」的必要工具。
