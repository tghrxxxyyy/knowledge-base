# 残差流总览

> 对应 Elhage et al., *A Mathematical Framework for Transformer Circuits*, 2021。

## 一、背景与挑战

把 Transformer 读成「层层变换」难以解释跨层交互。更有解释力的视角是：残差流是一条共享读写总线，各子层向其中加性写入、并从中读出。

## 二、核心原理

由于残差连接是加法，最终 logit 可精确写成所有子层输出贡献之和，这为归因提供了严格的可加基础。

- 写入：每个注意力头与 MLP 把输出加到残差流，相当于向总线广播一条消息。
- 读出：后续子层通过各自权重矩阵在总线上做投影，只取自己关心的子空间。

## 三、数学形式

$$x_{L}=x_{0}+\sum_{l=1}^{L}\Big(\mathrm{Attn}^{(l)}\big(x_{l-1}\big)+\mathrm{MLP}^{(l)}\big(x_{l-1}\big)\Big),\qquad \mathrm{logits}=W_U\,\mathrm{LN}\big(x_L\big)$$

忽略 LayerNorm 的非线性缩放后，logits 对每个子层输出是线性的，故可逐项分解贡献。

## 四、代码实现

```python
import torch
def residual_contributions(x0, block_outs, W_U, ln_scale):
    parts = [x0] + list(block_outs)
    return [W_U @ (p / ln_scale) for p in parts]     # 每个写入项在词表上的贡献
outs = [torch.randn(8) for _ in range(3)]
print(len(residual_contributions(torch.randn(8), outs, torch.randn(5, 8), 1.0)))
```

## 五、与其他对比

- 与逐层表示视角对照：残差流视角保留可加性，能做精确归因而非只看层输出。
- 与 直接贡献分解与logit归因 衔接：可加性正是 DLA 成立的前提。

## 六、常见误区

- 忽略 LayerNorm 的缩放因子，直接把中间向量投到词表造成尺度错误。
- 认为残差流维度可无限承载信息；带宽有限，特征以叠加方式压缩共存。

## 八、面试题

- 为什么把残差流看成总线？答：残差加法使各子层输出并行叠加，读写关系比串行变换更清晰。
- 可加分解的前提是什么？答：忽略或显式处理 LayerNorm 的非线性缩放。

## 九、演进

层堆叠视角 → 残差流总线抽象（2021）→ 直接归因与路径分析 → 叠加与特征分解研究。

## 十、小结

残差流抽象把 Transformer 变成可加系统，是全部贡献分解方法的数学基础。
