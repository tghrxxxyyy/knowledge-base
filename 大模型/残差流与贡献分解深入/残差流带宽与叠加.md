# 残差流带宽与叠加

> 对应 Elhage et al., *Toy Models of Superposition*, 2022。

## 一、背景与挑战

模型要表示的特征数远多于残差流维度。若特征稀疏，模型可以把它们以近似正交的方向压进同一空间，代价是彼此干扰。

## 二、核心原理

叠加是容量受限下的最优编码策略：稀疏性让干扰在多数时刻不同时发生，因此压缩收益大于干扰损失。

- 特征以近似正交而非严格正交的方向共存，读出时产生小幅交叉干扰。
- 这解释了多义神经元：单个基向量上会混合多个不相关特征，直接读神经元难以解释。

## 三、数学形式

由 Johnson-Lindenstrauss 引理，在 $d$ 维中可放入 $m\gg d$ 个方向使两两内积 $|\langle u_i,u_j\rangle|\le\epsilon$，只需 $d=\mathcal{O}\big(\epsilon^{-2}\log m\big)$。

干扰项为 $\hat a_i=a_i+\sum_{j\ne i}a_j\langle u_i,u_j\rangle$，稀疏（多数 $a_j=0$）时误差可控。

## 四、代码实现

```python
import torch
def interference(m, d):
    U = torch.nn.functional.normalize(torch.randn(m, d), dim=-1)
    G = U @ U.t(); G.fill_diagonal_(0)
    return float(G.abs().max()), float(G.abs().mean())
print(interference(2000, 128))
```

## 五、与其他对比

- 与稀疏自编码器对照：SAE 正是为把叠加特征解包成单义方向而设计。
- 与 残差流总览 衔接：带宽有限是理解「为何要叠加」的前提。

## 六、常见误区

- 认为神经元多义是训练缺陷；在容量受限且特征稀疏时，叠加是理性编码。
- 把叠加当作无损压缩；干扰始终存在，只是被稀疏性掩盖。

## 八、面试题

- 什么是叠加？答：用近似正交方向在低维空间编码远多于维度数的稀疏特征。
- 叠加为何导致多义神经元？答：单个基方向上混合多个特征，神经元不再对应单一概念。

## 九、演进

单义神经元假设 → 叠加理论与玩具模型（2022）→ 稀疏字典学习解包 → 特征级可解释性。

## 十、小结

叠加解释了为何直接读神经元难以解释，也指明了用稀疏分解寻找单义特征的方向。
