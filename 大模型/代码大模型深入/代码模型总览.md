# 代码模型总览

> 对应 llm-course 与 StarCoder/CodeLlama 文档；Chen et al., *HumanEval*, 2021。

## 一、背景与挑战

代码生成/补全/修复需求大，专用代码模型在编程任务上优于通用模型。

## 二、核心原理

在海量代码语料（含仓库、issue、文档）上预训练，支持补全、Chat（指令改码）、填充（FIM，中间插入）。评测常用 HumanEval/MBPP。

## 三、关键要点

- FIM 训练使模型能填中间。
- 仓库级上下文提升相关性。

## 四、代码实现

```python
from transformers import AutoModelForCausalLM
m = AutoModelForCausalLM.from_pretrained("bigcode/starcoder2-15b")
```

## 五、与其他对比

| 模型 | 特点 |
|------|------|
| StarCoder | 多语言、FIM |
| CodeLlama | Llama 衍生 |
| DeepSeek-Coder | 长上下文 |
