# 单元测试生成

> 见「代码大模型深入/代码模型总览」与「测试与代码质量」板块。

## 一、背景与挑战

测试编写耗时，模型可自动生成单测提升覆盖。

## 二、核心原理

基于函数/类生成用例，覆盖正常/边界/异常；可结合覆盖率反馈迭代补测。

## 三、关键要点

- 生成需可运行、断言明确。
- 避免「假绿」测试。

## 四、代码实现

```python
tests = llm(f"为以下函数写 pytest 用例:\n{src}")
```

## 五、与其他对比

- 补全写实现；测试生成写验证。

## 六、常见误区

- 生成即覆盖——需跑通且有效。

## 七、与开源书对应

- 测试与代码质量板块。
