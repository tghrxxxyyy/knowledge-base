# 仓库级代码理解

> 见「代码大模型深入/代码模型总览」与「上下文工程深入」。

## 一、背景与挑战

真实任务需跨文件理解（类型、依赖、调用链），单文件上下文不够。

## 二、核心原理

检索仓库相关文件/符号补足上下文，或用长上下文模型直接喂仓库切片；配合 AST/调用图定位。

## 三、关键要点

- 检索比全量喂更高效。
- 需处理 license 与体积。

## 四、代码实现

```python
ctx = retrieve_repo(query, vector_index) + read_defs(symbols)
```

## 五、与其他对比

- 文件级简单；仓库级更准但复杂。

## 六、常见误区

- 长上下文直接丢全仓——超长且贵。
