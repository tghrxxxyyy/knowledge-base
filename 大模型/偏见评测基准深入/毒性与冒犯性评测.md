# 毒性与冒犯性评测

> 对应 huggingface/transformers 与 EleutherAI/lm-evaluation-harness。

## 一、背景与挑战
模型可能输出有害或冒犯内容，需自动毒性分类与率值监控。

## 二、核心原理
用分类器对生成文本打毒性分，统计超阈比例，并在红队Prompt上回归。

## 三、形式化与数学基础
毒性率：
$ T = \frac{1}{N}\sum_i \mathbb{1}[\text{toxic}(x_i) > \tau] $

## 四、代码实现
```python
def tox_rate(texts, clf, tau=0.5):
    return sum(1 for t in texts if clf(t) > tau) / len(texts)
```

## 五、与其他技术对比
分类器快但有误判，人工抽检校准阈值。

## 六、常见误区
阈值过高漏检；忽略上下文依赖的冒犯性。

## 七、与开源书/权威来源对应
huggingface/transformers 提供分类管线；EleutherAI harness 含毒性任务。

## 九、演进与趋势
细粒度危害类别与多语言毒性评测。

毒性评测是安全上线的硬性门槛。
