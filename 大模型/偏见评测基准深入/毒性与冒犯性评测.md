# 毒性与冒犯性评测

> 对应 Gehman et al. 2020（RealToxicityPrompts）、Detoxify / Perspective 类毒性分类器与 EleutherAI/lm-evaluation-harness。

## 一、背景与挑战

大模型在开放生成时可能产生侮辱、仇恨、暴力或自残相关的毒性内容，也可能在看似正常的对话中被诱导输出冒犯性言论。毒性评测的目标是量化「模型有多大概率产出有害文本」，作为安全上线的硬性门槛。挑战在于：毒性高度依赖语境，同一个词在医学讨论、文学引用与辱骂中的性质完全不同；不同平台对「冒犯」的界定标准不同；红队提示会不断演化出新的诱导方式；分类器本身存在偏差，可能对特定群体的语言（如非标准方言、少数族裔常用表达）过判。此外，单纯提高拒答率会掩盖问题——模型可能只是学会了拒答，而非真的降低了有害倾向。

## 二、核心原理

毒性评测通常分三层，逐层加深：

1. 分类器评分：用标注数据训练的多标签毒性分类模型（如基于 Transformer 的分类器）对生成文本打分，输出 0–1 的分数与细粒度类别（仇恨、暴力、骚扰、自残、色情等），统计超阈比例、最大毒性与预期最大毒性。
2. 红队回归：用已知能诱导毒性的提示集反复测试，并按诱导强度分层采样，观察模型在不同强度下的越界情况。
3. 语境化判定：用强模型或人工复核处理边界样本，判断毒性是否由语境正当化（如引用、教育、新闻转述）。

保证结果可信的关键有三：固定分类器版本与阈值（否则跨版本不可比）、多次采样取统计量（生成有随机性）、对分类器本身做公平性审计（检查不同群体语言的过判率差异）。评测应报告曲线而非单点数字，才能反映模型在压力下的鲁棒性。

## 三、形式化与数学基础

对一组生成文本 $\{x_i\}_{i=1}^N$，毒性分类器 $\text{toxic}(\cdot)\in[0,1]$，阈值 $\tau$，毒性率为：

$$ T = \frac{1}{N}\sum_{i=1}^{N} \mathbb{1}\big[\text{toxic}(x_i) > \tau\big] $$

由于单次采样随机性大，常用「多次采样下的预期最大毒性」作为更敏感的指标：

$$ \text{EMT} = \mathbb{E}_{x}\Big[\max_{1\le i \le k} \text{toxic}(x_i)\Big], \quad x_i \sim p_\theta(\cdot \mid \text{prompt}) $$

按红队强度 $k$ 分层采样可得条件毒性率：

$$ T(k) = \frac{1}{N_k}\sum_{i:\,s_i=k} \mathbb{1}\big[\text{toxic}(x_i) > \tau\big] $$

模型鲁棒性用毒性随强度增长的斜率衡量，$\frac{\partial T}{\partial k}$ 越小越稳。若关注安全与可用的联合表现，可引入条件指标：仅在「本应正常回答」的样本上统计误拒，避免用拒答刷低毒性率。

$$ T_{\text{valid}} = \frac{\sum_i \mathbb{1}[\text{toxic}(x_i)>\tau \land \neg \text{refused}(x_i)]}{|\{i: \neg \text{refused}(x_i)\}|} $$

## 四、代码实现

```python
# 毒性评测：分层红队 + 多次采样 + 预期最大毒性
import statistics


def tox_rate(texts, clf, tau=0.5):
    if not texts:
        return 0.0
    return sum(1 for t in texts if clf(t) > tau) / len(texts)


def expected_max_toxicity(prompt, gen, clf, k=25):
    # 同一提示重复采样 k 次，取最大毒性的期望
    maxima = []
    for _ in range(k):
        samples = [gen(prompt) for _ in range(k)]
        maxima.append(max(clf(s) for s in samples))
    return statistics.fmean(maxima)


def tox_by_strength(prompts_by_strength, gen, clf, tau=0.5, repeats=5):
    # prompts_by_strength: {强度等级: [prompt, ...]}
    curve = {}
    for level, prompts in prompts_by_strength.items():
        outs = []
        for p in prompts:
            outs.extend(gen(p) for _ in range(repeats))
        curve[level] = tox_rate(outs, clf, tau)
    return curve   # 观察毒性率随诱导强度的变化斜率


# 公平性审计：比较不同群体语言上的过判率
def overflag_gap(clf, groups_texts, tau=0.5):
    rates = {g: tox_rate(ts, clf, tau) for g, ts in groups_texts.items()}
    return rates, max(rates.values()) - min(rates.values())
```

## 五、与其他技术对比

- 自动分类器 vs 人工标注：分类器快、可回归、可规模化，但有误判；人工用于校准阈值与边界样本，二者互补。
- 单点阈值 vs 分层曲线：单点易被刷分，分层曲线反映压力下的鲁棒性，更有诊断价值。
- 输出毒性 vs 输入诱导：通常评输出，但输入侧诱导强度是解释输出毒性的关键变量，必须一并记录。
- 固定提示 vs 自适应红队：固定提示可复现，自适应红队能发现新弱点，应组合使用。

## 六、常见误区

- 「阈值调高就安全」：阈值越高漏检越多隐性毒性；且不同分类器的分数刻度不可直接比较。
- 「忽略语境依赖」：同一表述在医疗、历史、法律语境下未必有毒，需上下文感知判定。
- 「分类器无偏」：毒性分类器对少数群体语言存在系统性过判，必须做公平性审计。
- 「拒答率上升等于更安全」：模型可能只是学会拒答，应同时在「本应回答」的样本上评估。

## 七、与开源书·权威来源对应

- Gehman et al. 2020（RealToxicityPrompts）：系统揭示提示诱导下模型的毒性倾向，是主流评测数据源。
- Detoxify / Perspective 类分类器：工业级毒性打分实践，提供多类别细粒度分数。
- EleutherAI lm-evaluation-harness：集成 toxicity 等安全任务，支持固定口径的回归评测。
- OWASP Top 10 for LLM Applications：将有害输出列为 LLM 应用的核心风险之一。

## 九、演进与趋势

毒性评测正从「单一分数」走向「细粒度危害类别 + 多语言 + 上下文感知」：类别从笼统的 toxicity 拆分为仇恨、暴力、骚扰、自残等可分别设定阈值的维度；判定从词面匹配走向大模型裁判与人工校准结合；评测对象从单轮生成扩展到多轮对话中的累积冒犯与渐变诱导；同时把分类器的公平性审计纳入常规流程，避免以安全的名义制造新的不公。

## 十、小结

毒性与冒犯性评测是安全上线的硬性门槛。只有固定分类器与阈值、按强度分层采样、同时审计公平性，指标才可信、可回归、可用于发布决策。
