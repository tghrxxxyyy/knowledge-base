# 刻板印象评测与关联测试

> 对应 EleutherAI/lm-evaluation-harness 与 Devlin 2018 BERT。

## 一、背景与挑战
模型会把职业、特质与特定群体不当关联，需显式暴露。

## 二、核心原理
以完形填空形式提示，统计模型补全出刻板词的概率是否显著高于反刻板词。

## 三、形式化与数学基础
关联强度：
$ S = P(\text{stereotype token} | c) - P(\text{anti token} | c) $

## 四、代码实现
```python
def stereotype_gap(model, ctx, stereo, anti):
    ps = model.prob(ctx, stereo)
    pa = model.prob(ctx, anti)
    return ps - pa
```

## 五、与其他技术对比
关联测试比人工标注可规模化，但模板偏差需控制。

## 六、常见误区
把概率差直接当恶意；忽略语境消解。

## 七、与开源书/权威来源对应
EleutherAI harness 提供相关基准任务；Devlin 2018 揭示 BERT 偏差。

## 八、面试题
如何区分语言先验与社会刻板印象？

## 九、演进与趋势
多语言、多群体交叉偏见评测。

## 十、小结
刻板印象评测帮助定位模型偏置来源。
