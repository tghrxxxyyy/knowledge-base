# 社会偏见度量框架

> 对应 EleutherAI/lm-evaluation-harness 与 Devlin 2018 BERT。

## 一、背景与挑战
模型在性别、种族等维度上存在系统性偏好，需标准化度量以跟踪改进。

## 二、核心原理
构造成对填空或选择，比较模型对受保护属性的概率分布差异。

## 三、形式化与数学基础
刻板偏差可用分布距离：
$ D = \mathrm{KL}(P(\cdot|\text{group}_A) \parallel P(\cdot|\text{group}_B)) $

## 四、代码实现
```python
import math
def kl(p, q):
    return sum(p[i] * math.log(p[i] / q[i]) for i in range(len(p)))
```

## 五、与其他技术对比
概率法比单一样本判断更稳健，但依赖模板覆盖度。

## 六、常见误区
只看均值忽略方差；模板措辞本身引入偏差。

## 七、与开源书/权威来源对应
EleutherAI harness 收录偏见类任务；Devlin 2018 揭示表征偏差。

## 八、面试题
如何用无标签数据估计社会偏见？

## 九、演进与趋势
从模板到开放式对话中的偏见探测。

## 十、小结
偏见度量需多维度、可复现，并随模型版本监控。
