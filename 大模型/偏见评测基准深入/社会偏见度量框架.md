# 社会偏见度量框架

> 对应 Caliskan et al. 2017（WEAT）、Nadeem et al. 2021（StereoSet）、Nangia et al. 2020（CrowS-Pairs）与 EleutherAI/lm-evaluation-harness。

## 一、背景与挑战

模型在性别、种族、宗教、年龄、地域、残障等社会维度上可能表现出系统性偏好。若不做标准化度量，就无法在模型迭代中判断改善与否，也无法在模型之间做横向比较。挑战有四：偏见是分布性的，单条输出难以代表整体；不同基准（CrowS-Pairs、StereoSet、WEAT、BBQ）的口径与单位不同，分数不可直接比较；模板措辞、采样随机性、模型版本都会引入方差；此外还需把「语言先验」与「社会刻板」区分开，否则会把常识共现误判为偏见。因此需要统一的框架把分散基准纳入同一报告体系。

## 二、核心原理

社会偏见度量框架统一了三类测量范式：

1. 填空/选择式（StereoSet、CrowS-Pairs、BBQ）：构造语义相近但刻板程度不同的句对或问答，比较模型的概率偏好或选择倾向。可控、可复现，是当前主流。
2. 向量关联式（WEAT/SEAT）：在表征空间测量群体词与属性词的关联强度，速度快、无需解码，适合早期筛查与训练过程监控。
3. 生成式探测：让模型自由生成（人物描写、故事续写、招聘建议），再用分类器、裁判或人工评估偏见倾向，更贴近真实使用但噪声更大。

框架的工程价值在于统一报告：给出每个维度（性别、种族、宗教、年龄等）的偏差分、置信区间、样本量与随版本的演化曲线，并明确标注所用基准版本与判定口径。BBQ（Bias Benchmark for QA）等基准还引入「歧义上下文」设计——在信息不足时模型是否依赖刻板印象作答，这比单纯的概率偏好更能反映实际危害。此外框架应内置质量控制：模板平衡（同一内容正反两种表述）、对照条件（把群体词替换为中性词以分离语言先验）、以及人工抽检校准。

## 三、形式化与数学基础

对群体 $A,B$ 在属性词上的概率分布 $P_A,P_B$，可用 KL 散度刻画分布差异：

$$ D_{\mathrm{KL}}\big(P_A \,\|\, P_B\big) = \sum_{w} P_A(w)\log\frac{P_A(w)}{P_B(w)} $$

KL 不对称且对零概率敏感，实践中常用其对称化形式 Jensen–Shannon 散度：

$$ \mathrm{JS}(P_A, P_B) = \tfrac{1}{2}D_{\mathrm{KL}}(P_A \| M) + \tfrac{1}{2}D_{\mathrm{KL}}(P_B \| M), \quad M = \tfrac{1}{2}(P_A + P_B) $$

更实用的「偏好得分」为准确率形式：

$$ \text{BiasScore} = \frac{1}{N}\sum_{i=1}^{N} \mathbb{1}\big[P(s_i\mid c_i) > P(a_i\mid c_i)\big] $$

越接近 0.5 越中立。由于样本有限，必须给出置信区间；用自助法或二项区间：

$$ \hat{p} \pm z\sqrt{\frac{\hat{p}(1-\hat{p})}{N}} $$

只有当区间完全落在 0.5 一侧时，才可断言存在系统性偏向。框架还应报告跨维度的一致性，例如各维度得分的标准差，用以识别「只在某一维度改善」的表面优化。

## 四、代码实现

```python
# 社会偏见度量：JS 散度 + 偏好得分 + 自助法置信区间
import math
import random
import statistics


def kl_divergence(p, q, eps=1e-12):
    # p, q: 等长非负列表，内部会做平滑与归一
    return sum(pi * math.log((pi + eps) / (qi + eps)) for pi, qi in zip(p, q))


def js_divergence(p, q):
    m = [(a + b) / 2 for a, b in zip(p, q)]
    return 0.5 * kl_divergence(p, m) + 0.5 * kl_divergence(q, m)


def bias_score(gaps):
    # gaps: 每个样本的 (刻板对数概率 - 反刻板对数概率)
    return sum(1 for g in gaps if g > 0) / len(gaps)


def bootstrap_ci(gaps, rounds=1000):
    means = sorted(
        bias_score(random.choices(gaps, k=len(gaps))) for _ in range(rounds)
    )
    return means[int(0.025 * rounds)], means[int(0.975 * rounds)]


def report_by_dimension(results, neutral_baseline=0.5):
    # results: {dimension: [gap, ...]}
    out = {}
    for dim, gaps in results.items():
        score = bias_score(gaps)
        lo, hi = bootstrap_ci(gaps)
        out[dim] = {
            "score": score,
            "ci": (lo, hi),
            "significant": not (lo <= neutral_baseline <= hi),
            "n": len(gaps),
        }
    return out
```

## 五、与其他技术对比

- 概率法 vs 单样本判断：概率聚合更稳健、方差更小，能区分噪声与系统性偏差。
- 填空式 vs 向量式：填空贴近生成行为，是部署前应看的指标；向量式快、无需解码，适合训练期监控。
- 统一框架 vs 孤立基准：框架提供统一口径、置信区间与演化曲线，便于跨版本与跨模型对比。
- 明确上下文（BBQ 式）vs 歧义上下文：歧义条件下的偏差更能反映模型是否会「脑补」刻板信息，危害更直接。

## 六、常见误区

- 「只看均值」：忽略方差与置信区间，小样本下的「偏差」可能纯属噪声。
- 「模板无罪」：模板措辞本身隐含偏向，需做模板平衡与中性对照。
- 「语言先验=社会偏见」：高频共现不等于价值判断，需设计对照条件分离二者。
- 「不同基准分数可直接比」：口径、单位、样本构成不同，跨基准比较需谨慎标注。

## 九、演进与趋势

社会偏见度量正从「静态模板」走向「开放式对话探测 + 交叉身份 + 因果归因」：不仅测「有没有偏差」，还定位「偏差来自数据哪一层」（语料、标注、模板、解码策略）；从单一维度扩展到交叉身份与多语言；把度量指标纳入模型版本监控，使公平性成为可追踪的演进指标；并与去偏方法、红队评测整合进同一套自动化回归流水线。

## 十、小结

社会偏见度量框架把分散的基准统一为可复现、可对比、可监控的多维度报告，并强制要求置信区间与对照实验，是公平性与安全治理的基础设施。
