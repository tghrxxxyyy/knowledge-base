# 多语言偏见评测

> 对应 Bender et al. 2021（论数据鸿沟）、EleutherAI/lm-evaluation-harness 多语言任务与 HuggingFace Transformers 多语言模型实践。

## 一、背景与挑战

多数偏见基准以英语为中心，但大模型是多语言的，低资源语言上的偏差表现往往与英语截然不同。仅用英语度量会高估模型整体的公平性，掩盖语言覆盖的不均衡。挑战有四：一是许多语言缺乏现成的偏见标注数据与成熟的分类器；二是直接用机器翻译把英语模板搬过去会引入伪偏差（翻译腔、语义漂移、代词丢失、敬语体系变形），测到的往往是翻译误差而非模型偏见；三是不同语言背后的社会语境与文化规范本就不同，不能简单套用同一把尺子，某些属性在一种文化中是刻板印象，在另一种中未必成立；四是形态丰富的语言（如黏着语）在 token 化后概率不可直接比较，需要按字符或子词归一化。

## 二、核心原理

多语言偏见评测的核心思路是「同一测量在多种语言上复现并横向比较」：

1. 模板本地化：由母语者或本地化团队撰写贴合该语言社会语境的模板，而不是机械翻译；同时保留一组可跨语言对齐的公共模板用于横向比较。
2. 文化适配：敏感属性与群体划分需按当地语境重新定义，例如亲属称谓、敬语、种姓或部族等在本地语境中更相关。
3. 跨语言一致性：在每种语言 $l$ 上跑同一偏见测试得到 $S_l$，比较语言间差异与方差，识别「英语好但其他语言差」的覆盖缺口。
4. 覆盖度审计：统计哪些语言有足够样本与稳定估计、哪些处于评测盲区，并把盲区作为数据建设的输入。

关键认识是：多语言评测的价值不只是「多测几种语言」，而是揭示模型公平性是否依赖于语言这一变量。若跨语言方差很大，任何单语结论都不具有代表性。

## 三、形式化与数学基础

设语言集合 $L$，在语言 $l$ 上的偏见分数为 $S_l$，跨语言偏差的方差衡量语言间不一致程度：

$$ V = \mathrm{Var}_{l\in L}[\,S_l\,] = \frac{1}{|L|}\sum_{l\in L} (S_l - \bar{S})^2, \quad \bar{S} = \frac{1}{|L|}\sum_{l\in L} S_l $$

$V$ 越大，说明偏见高度依赖语言，英语分数不能代表整体。定义语言覆盖公平性：

$$ C = \frac{1}{|L|}\sum_{l\in L} \mathbb{1}[S_l\ \text{可被稳定估计}] $$

「稳定估计」可操作化为：样本量达到阈值且自助法置信区间宽度小于阈值。$C$ 低表明大量语言处于评测盲区。

由于不同语言的 token 化粒度不同，概率需做长度归一化后再比较：

$$ \hat{P}(y \mid c) = \exp\!\left( \frac{1}{|y|}\sum_{t} \log p(y_t \mid c, y_{<t}) \right) $$

其中 $|y|$ 可用子词数或字符数，跨语言比较时应统一口径并报告所用单位。

## 四、代码实现

```python
# 跨语言偏见分数：长度归一化 + 方差/覆盖度统计
import math
import statistics


def length_norm_logprob(model, ctx, completion):
    # 用单位长度的对数概率，缓解不同语言 token 化粒度差异
    total = model.seq_logprob(ctx, completion)
    return total / max(len(completion), 1)


def lang_bias_score(model, pairs_by_lang):
    # pairs_by_lang: {lang: [(ctx, stereo, anti), ...]}
    scores = {}
    for lang, pairs in pairs_by_lang.items():
        hit = 0
        for ctx, s, a in pairs:
            ps = length_norm_logprob(model, ctx, s)
            pa = length_norm_logprob(model, ctx, a)
            hit += int(ps > pa)
        scores[lang] = hit / len(pairs)   # 接近 0.5 为中立
    return scores


def cross_lingual_summary(scores, min_n=30, max_ci=0.15):
    vals = list(scores.values())
    covered = [v for v in vals if v is not None]
    return {
        "variance": statistics.pvariance(covered),
        "stdev": statistics.pstdev(covered),
        "coverage": len(covered) / len(vals),   # 有稳定估计的语言占比
    }


# 自助法：给出每种语言分数的置信区间，判断差异是否显著
def bootstrap_ci(values, rounds=1000):
    import random
    means = sorted(
        statistics.fmean(random.choices(values, k=len(values))) for _ in range(rounds)
    )
    return means[int(0.025 * rounds)], means[int(0.975 * rounds)]
```

## 五、与其他技术对比

- 单语评测 vs 多语评测：单语掩盖语言间不均衡，多语暴露覆盖缺口与伪偏差。
- 翻译模板 vs 母语模板：翻译模板快、可规模化，但引入语义漂移与伪偏差；母语模板准但成本高，二者宜结合并互相校验。
- 统一标准 vs 本地标准：统一标准便于横向比较，本地标准更贴合文化，需在报告中同时给出。
- 高资源语言 vs 低资源语言：前者可用完整基准，后者常需少量样本 + 人工判读 + 定性结论。

## 六、常见误区

- 「机器翻译模板即可」：翻译会改变语义侧重与语用色彩，产生伪偏差，误导结论。
- 「英语好就等于都好」：跨语言方差大时，英语分数毫无代表性。
- 「忽略语言自身语境」：某些特质在特定文化中并非偏见，套用外部标准会误判。
- 「不同语言概率直接比大小」：token 化粒度不同，必须做长度归一化并统一单位。

## 九、演进与趋势

多语言偏见评测正从「翻译英语基准」走向「原生多语基准 + 本地化标注 + 覆盖度审计」：由母语社区共同构建原生基准；借助跨语言迁移与少量母语样本降低标注成本；把语言覆盖度作为模型卡片的常规披露项；并与多语言安全评测合并，形成统一的「语言 × 风险维度」矩阵，避免公平性建设长期偏科于少数高资源语言。

## 十、小结

偏见评测必须跨越语言边界。用母语化模板、长度归一化与跨语言一致性度量，才能真实反映模型的全球公平性，并暴露评测体系自身的覆盖盲区。
