# 多语言偏见评测

> 对应 EleutherAI/lm-evaluation-harness 与 huggingface/transformers。

## 一、背景与挑战
英语偏见度量不能代表低资源语言，跨语言偏差表现各异。

## 二、核心原理
在多种语言模板上重复同一偏见测试，比较跨语言一致性。

## 三、形式化与数学基础
跨语言偏差方差：
$ V = \mathrm{Var}_{l \in L}[\,S_l\,] $

## 四、代码实现
```python
def cross_lingual(scores_by_lang):
    import statistics
    return statistics.pstdev(list(scores_by_lang.values()))
```

## 五、与其他技术对比
单语评测掩盖语言不均衡，多语评测暴露覆盖缺口。

## 六、常见误区
用机器翻译模板引入伪偏差；忽略语言自身社会语境。

## 七、与开源书/权威来源对应
EleutherAI harness 支持多语任务；huggingface/transformers 多语模型。

## 八、面试题
翻译模板评测的局限是什么？

## 九、演进与趋势
原生多语基准与本地化标注。

## 十、小结
偏见评测必须跨越语言边界。
