# 公平性指标与去偏方法

> 对应 Barocas, Hardt & Narayanan《Fairness and Machine Learning》、Dwork et al. 2012 与 HuggingFace 偏见评估工具链。

## 一、背景与挑战

偏见度量只是第一步，若不能转化为可行动的去偏手段，指标就只是「指责」。公平性要求模型在不同受保护群体上的表现或输出分布不应系统性偏向某一方。挑战有四：一是公平性存在多种互不相容的定义，例如均等赔率与人口均等在基础比率不同时无法同时满足；二是去偏常以整体效用下降为代价，需要透明地报告权衡；三是群体之间存在交叉身份（如「女性 + 少数族裔 + 高龄」），单一维度度量会掩盖最弱势群体的复合偏差；四是语言模型的公平性不像二分类那样有清晰的 $\hat{y}$，需要把「输出分布」「生成倾向」「拒答率差异」纳入指标体系。

## 二、核心原理

公平性指标按信息依赖可分为三类，实践中需组合报告：

1. 群体公平（group fairness）：比较不同群体间的统计指标差异，如统计均等、均等赔率、机会均等。易于度量与审计，是监管沟通的基础口径。
2. 个体公平（individual fairness）：相似个体应被相似对待，需定义任务相关的相似性度量，实现难度高但更贴近直觉。
3. 因果公平（causal fairness）：考察敏感属性是否通过不当因果路径影响结果，用于区分可容许与不可容许的差异。

去偏方法按作用阶段分三层：

- 数据层（预处理）：重加权、重采样、去偏改写、补充代表性不足群体的样本。直接作用于偏差来源，但可能损失信息。
- 训练层（处理中）：在损失中加入公平性约束，如对抗去偏（让表征无法预测敏感属性）或群体均衡正则。更彻底但需重训，成本高。
- 推理层（后处理）：对比解码压低刻板补全概率、输出校准、指令约束。改动小、可快速上线，但不改变模型内部表征。

选择哪一层取决于偏差来源：数据偏差优先数据层，表征偏差优先训练层，输出偏差可用推理层快速缓解。

## 三、形式化与数学基础

以二分类为例，设敏感属性 $a\in\{0,1\}$。均等赔率要求各群体的真阳性率与假阳性率相等：

$$ P(\hat{y}=1 \mid a=0, y=1) \approx P(\hat{y}=1 \mid a=1, y=1) $$

$$ P(\hat{y}=1 \mid a=0, y=0) \approx P(\hat{y}=1 \mid a=1, y=0) $$

人口均等（统计均等）要求预测阳性率与群体无关：

$$ P(\hat{y}=1 \mid a=0) \approx P(\hat{y}=1 \mid a=1) $$

当两群体的真实基础比率不同时，上述二者通常不可兼得，这就是公平性不可能定理的核心含义。训练层的对抗去偏可写成极小极大问题：

$$ \min_{\theta}\ \mathcal{L}_{\text{task}}(\theta) - \lambda \max_{\phi}\ \mathcal{L}_{\text{adv}}(\theta, \phi) $$

其中 $\phi$ 是从表征预测敏感属性的对抗头，$\lambda$ 权衡任务性能与不变性。$\lambda$ 越大，敏感信息被压制越彻底，任务效用通常越低，这条「公平—效用前沿」应显式测绘并对外报告。

## 四、代码实现

```python
# 群体公平指标 + 推理层对比解码去偏（示意）
def group_metrics(groups):
    # groups: {group: {"tp": int, "fn": int, "fp": int, "tn": int}}
    tpr, fpr = {}, {}
    for g, m in groups.items():
        tpr[g] = m["tp"] / max(m["tp"] + m["fn"], 1)
        fpr[g] = m["fp"] / max(m["fp"] + m["tn"], 1)
    return {
        "tpr_gap": max(tpr.values()) - min(tpr.values()),
        "fpr_gap": max(fpr.values()) - min(fpr.values()),
        "tpr": tpr,
        "fpr": fpr,
    }


def contrastive_decode(model, ctx, stereo_token, anti_token, alpha=0.1):
    # 推理层去偏：压低刻板补全的对数几率
    logits = model.logits(ctx)
    logits[stereo_token] -= alpha * abs(logits[stereo_token])
    logits[anti_token] += alpha * abs(logits[anti_token])
    return model.sample_from(logits)


def fairness_utility_frontier(train_fn, lambdas, eval_fn):
    # 测绘公平-效用前沿：不同 lambda 下同时报告公平差距与任务指标
    frontier = []
    for lam in lambdas:
        model = train_fn(fairness_lambda=lam)
        m = eval_fn(model)
        frontier.append({"lambda": lam, "fair_gap": m["gap"], "utility": m["score"]})
    return frontier   # 供业务方按可接受效用挑选 lambda
```

## 五、与其他技术对比

- 后处理 vs 训练期去偏：后处理简单、可解释、改动小；训练期去偏更彻底但要重训、成本高、调参复杂。
- 数据层 vs 表征层：数据层直接但可能损失信息或引入新的采样偏差；表征层细粒度但工程复杂、难解释。
- 单一维度 vs 交叉身份：单一维度易掩盖复合偏差，交叉切分样本量锐减导致方差大，需更大样本或分层建模。
- 群体公平 vs 个体公平：前者易审计易沟通，后者更贴合直觉但依赖相似性定义。

## 六、常见误区

- 「去偏零代价」：公平性通常以整体效用下降为代价，必须报告公平—效用前沿而非单指标。
- 「只看主群体」：忽略交叉身份会放过最弱势群体的复合偏差。
- 「一次去偏永久有效」：模型更新、数据漂移、用户分布变化都会改变公平性，需持续监控。
- 「用训练语料分布当基线」：语料本身含偏见，用它做基线等于自我证明偏见合理，应使用外部规范或真实统计基线。

## 九、演进与趋势

公平性正从「离线指标」走向「在线多目标」：把公平性作为对齐目标中的一项奖励或约束，与有用性、安全性联合优化；用因果视角区分可容许与不可容许的差异，避免机械地抹平所有群体差异；把公平性回归测试纳入 CI/CD，每次模型或数据变更自动跑分；并把指标从分类决策扩展到生成式场景的输出分布、语气与代表性差异。

## 十、小结

公平性是可度量、可行动的工程目标。度量与去偏必须绑定成闭环，在效用与公平之间透明地做权衡，并持续监控而非一次性达标。
