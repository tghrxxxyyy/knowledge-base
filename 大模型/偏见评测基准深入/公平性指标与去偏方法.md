# 公平性指标与去偏方法

> 对应 huggingface/transformers 与 Devlin 2018 BERT。

## 一、背景与挑战
度量之后需可行动的去偏手段，否则指标只是指责。

## 二、核心原理
从数据重加权、对比解码到指令约束，降低受保护属性的条件依赖。

## 三、形式化与数学基础
均等赔率近似：
$ P(\hat{y}=1|a=0) \approx P(\hat{y}=1|a=1) $

## 四、代码实现
```python
def equalized(groups):
    # groups: dict group->positive rate
    rates = [v for v in groups.values()]
    return max(rates) - min(rates)
```

## 五、与其他技术对比
后处理简单可解释，训练期去偏更彻底但成本高。

## 六、常见误区
去偏牺牲整体效用不加报告；忽略交叉身份。

## 七、与开源书/权威来源对应
huggingface/transformers 提供偏见评估工具；Devlin 2018 揭示表征偏差。
