# 性别与职业偏见基准

> 对应 EleutherAI/lm-evaluation-harness 与 Brown 2020 in-context learning。

## 一、背景与挑战
职业描述常默认某一性别，模型延续该偏见影响下游应用公平性。

## 二、核心原理
给定职业提示，测量模型生成代词或姓名的性别分布偏离真实基线的程度。

## 三、形式化与数学基础
公平性差距：
$ \Delta = \sum_g |P(\text{gender}=g|\text{job}) - B_g| $

## 四、代码实现
```python
def gender_gap(pred_dist, base_dist):
    return sum(abs(pred_dist[g] - base_dist[g]) for g in pred_dist)
```

## 五、与其他技术对比
分布法比单例判断更具统计意义。

## 六、常见误区
用不平衡训练分布当合理基线；忽略交互效应。

## 七、与开源书/权威来源对应
EleutherAI harness 收录职业性别任务；Brown 2020 讨论少样本偏差。

## 八、面试题
如何选取无偏的真实基线分布？

## 九、演进与趋势
用去偏数据重加权与指令约束。

## 十、小结
性别职业偏见是可量化并可持续追踪的指标。
