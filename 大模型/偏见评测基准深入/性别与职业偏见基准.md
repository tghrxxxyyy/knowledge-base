# 性别与职业偏见基准

> 对应 Bolukbasi et al. 2016（词嵌入性别偏差）、Brown et al. 2020（GPT-3 中的偏差观察）与 EleutherAI/lm-evaluation-harness 相关任务。

## 一、背景与挑战

职业描述在公开语料中常隐含性别默认（如「护士」偏女性、「工程师」偏男性），大模型延续这一偏向会影响招聘、教育、推荐等下游应用的公平性。若模型在生成代词、人名、示例或职业建议时系统性地把某性别与某职业绑定，既强化刻板印象，也可能在自动化决策中造成实际歧视。挑战有四：需要一个「无偏真实基线」作为比较对象，而训练语料本身含偏见，不能自证；要度量的是分布偏离而非单例；性别不应被简化为二元，非二元与跨性别身份需要被纳入；还要考虑性别与种族、年龄、地域的交叉效应，单一维度会掩盖复合偏差。

## 二、核心原理

性别—职业偏见基准的核心做法是「测量生成分布并与外部基线比较」：

1. 代词/人名探测：给定职业提示（如「这位医生叫…」或「The engineer said that …」），测量模型生成代词（他/她/they）或性别化人名的分布，与真实世界统计基线比较，偏离越远偏见越强。
2. 成对句子测试：比较模型对「职业 + 男性名」与「职业 + 女性名」句子的流畅度或概率偏好，揭示隐性关联。
3. 开放式生成探测：让模型写一段某职业的人物描写或给出职业建议，再统计其中的性别指代分布与能力归因差异。
4. 交叉扩展：在职业提示中加入第二属性（族裔、年龄），观察偏差是否被放大。

方法要点有三：多模板、多措辞重复以降低模板噪声；使用外部基线（人口普查、行业统计、规范目标）而非模型自身分布；同时报告方向（偏向哪一方）与幅度，避免只看绝对值。对中文等代词性别区分较弱的语言，需结合人名、称谓与职业名词的搭配频率设计探测方式。

## 三、形式化与数学基础

设职业 $j$ 下模型输出的性别分布为 $P(g\mid j)$（$g$ 遍历性别类别），外部基线分布为 $B_g$，公平性差距用总变差距离刻画：

$$ \Delta(j) = \frac{1}{2}\sum_{g} \big|\,P(g\mid j) - B_g\,\big| $$

归一化后取值在 $[0,1]$，$\Delta(j)=0$ 表示完全符合基线。对所有职业汇总：

$$ \bar{\Delta} = \frac{1}{|J|}\sum_{j\in J} \Delta(j) $$

也可直接用群体间比率差衡量偏向幅度：

$$ \text{Skew}(j) = P(g_{\text{male}}\mid j) - P(g_{\text{female}}\mid j) $$

由于生成有随机性，应对每个职业多次采样，用自助法给出 $\Delta(j)$ 的置信区间；只有区间不跨 0 时才判定存在显著偏差。此外可用 KL 散度刻画整体分布差异：

$$ D_{\mathrm{KL}}\big(P(\cdot\mid j) \,\|\, B\big) = \sum_g P(g\mid j)\log\frac{P(g\mid j)}{B_g} $$

KL 对尾部事件敏感，适合捕捉「模型几乎从不生成某性别」这类极端情况。

## 四、代码实现

```python
# 性别-职业偏见：分布偏离 + 自助法置信区间
import random
import statistics


def gender_gap(pred_dist, base_dist):
    # 总变差距离（归一化到 0~1），0 表示与基线一致
    return 0.5 * sum(abs(pred_dist[g] - base_dist[g]) for g in pred_dist)


def sample_gender_dist(model, job, templates, repeats=20):
    # 多模板多次采样，聚合得到该职业下的性别分布
    counts = {}
    for tpl in templates:
        for _ in range(repeats):
            g = model.classify_gender(model.generate(tpl.format(job=job)))
            counts[g] = counts.get(g, 0) + 1
    total = sum(counts.values())
    return {g: c / total for g, c in counts.items()}


def occupation_bias(model, occupations, base, templates):
    per_job = {}
    for job in occupations:
        per_job[job] = gender_gap(sample_gender_dist(model, job, templates), base)
    return per_job, statistics.fmean(per_job.values())


def bootstrap_delta(job_dists, base, rounds=1000):
    # 用自助法判断整体偏离是否显著
    vals = sorted(
        statistics.fmean([gender_gap(random.choice(job_dists), base)
                          for _ in job_dists])
        for _ in range(rounds)
    )
    return vals[int(0.025 * rounds)], vals[int(0.975 * rounds)]
```

## 五、与其他技术对比

- 分布法 vs 单例判断：分布法具统计意义，能区分采样噪声与系统性偏差。
- 生成分布 vs 嵌入关联：生成分布更贴近真实使用行为，是上线前应看的指标；嵌入关联适合早期快速筛查与训练期监控。
- 单职业 vs 职业集：单职业结论易偶然，必须在职业集上汇总并报告分布。
- 二元性别 vs 多元性别：二元设定实现简单但会遗漏对非二元身份的系统性抹除，需在词表与基线中显式纳入。

## 六、常见误区

- 「用训练分布当合理基线」：训练语料本身含偏见，用它做基线会自我证明偏见合理。
- 「忽略交叉效应」：仅看性别会放过「女性 + 少数族裔 + 高龄」这类复合偏差。
- 「一次生成定论」：采样随机性大，必须聚合多模板、多次采样并报告区间。
- 「把偏差归零当作目标」：某些职业的真实性别分布本就不均，目标应是匹配合理基线而非机械 50/50。

## 七、与开源书·权威来源对应

## 九、演进与趋势

该基准正从「二元性别 + 单职业 + 英语」走向「多元性别 + 交叉身份 + 多语言 + 开放式生成」：纳入非二元与跨性别身份；结合不同地区与国家的真实职业结构设定本地基线；从代词探测扩展到能力归因、薪资建议、领导力描述等更细的危害维度；并与去偏方法（数据重加权、指令约束、对比解码）形成「测量—干预—再测量」的闭环，纳入模型版本的持续回归。

## 十、小结

性别与职业偏见是可量化、可追踪的公平性指标。通过与外部合理基线比较分布偏离，并报告方向、幅度与置信区间，才能把主观的「有没有偏见」转化为可工程化治理的客观度量。
