# 锐度感知总览

> 对应 Foret et al., *Sharpness-Aware Minimization for Efficiently Improving Generalization*, ICLR 2021。

## 一、背景与挑战

SGD 常收敛到"尖锐"极小值（损失在邻域剧变），此类解对扰动敏感、泛化差；需要显式降低邻域锐度。

## 二、核心原理

锐度感知最小化（SAM）在每个参数点寻找使损失上升最大的最坏扰动 $\varepsilon$，再在该扰动方向上做梯度下降，迫使模型收敛到平坦区域。

## 三、数学形式

极小极大目标 $\min_\theta \max_{\|\varepsilon\|_2\le\rho} \mathcal L(\theta+\varepsilon)$；内层近似解为 $\varepsilon \approx \rho\frac{\nabla_\theta\mathcal L(\theta)}{\|\nabla_\theta\mathcal L(\theta)\|_2}$。

## 四、代码实现

```python
loss = criterion(model(x), y)
loss.backward(create_graph=True)
for p in model.parameters():
    p.grad = rho * p.grad / (p.grad.norm() + 1e-12)
# 扰动后需二次前向以更新真实梯度
```

## 五、与其他对比

- 与 平坦极小值深入 共享"平坦即更好泛化"的假设。
- 与 梯度噪声深入 对照：SAM 主动正则锐度，噪声被动影响锐度。

## 六、常见误区

- $\rho$ 过大破坏收敛、过小几乎无效。
- 误以为 SAM 对所有任务都提点，仅在易陷入锐度的任务明显。

## 八、面试题

- SAM 为何提升泛化？答：抑制邻域锐度，使损失在扰动下稳定，等价于隐式正则使解更平坦。

## 九、演进

锐度概念 → SAM → ASAM（自适应半径） → 与 SGD 噪声结合的研究。

## 十、小结

SAM 以最坏扰动正则，将模型推入平坦区，是简洁实用的泛化提升手段。
