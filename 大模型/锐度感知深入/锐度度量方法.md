# 锐度度量方法

> 对应 Foret et al., 2021 的邻域最大损失；以及 Jiang et al., *Fantastic Generalization Measures*, ICLR 2019。

## 一、背景与挑战

如何定量衡量"锐度"以便诊断与比较，是应用 SAM 的前提。

## 二、核心原理

常用度量：邻域最大损失 $\max_{\|\varepsilon\|\le\rho}\mathcal L(\theta+\varepsilon)$；或 Hessian 最大特征值 $\lambda_{\max}(\nabla^2\mathcal L)$ 代表局部曲率。

## 三、数学形式

局部锐度近似 $\mathcal S(\theta)=\frac{\mathcal L(\theta+\rho\hat v)-\mathcal L(\theta)}{\rho}$，其中 $\hat v$ 为最大特征向量方向。

## 四、代码实现

```python
with torch.no_grad():
    theta2 = theta + rho * v
    sharp = (loss_at(theta2) - loss_at(theta)) / rho
```

## 五、与其他对比

- 与 损失景观深入 的可视化互补。
- 与 二阶优化深入 的特征值计算同源。

## 六、常见误区

- 用非不变度量比较不同模型会误导。
- 小 $\rho$ 下锐度对数值噪声敏感。

## 八、面试题

- 如何度量锐度？答：邻域最大损失或 Hessian 最大特征值，二者刻画局部曲率。

## 九、演进

经验度量 → 谱方法 → 不变度量标准化。

## 十、小结

锐度度量提供量化工具，是理解并调优 SAM 类方法的基础。
