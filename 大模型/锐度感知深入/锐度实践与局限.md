# 锐度感知实践与局限

> 对应大模型训练中 SAM 的实证研究（如 transformers + SAM 报告）。

## 一、背景与挑战

SAM 在大模型上额外内存与计算开销明显，需权衡性价比。

## 二、核心原理

仅在训练早期或特定层施加 SAM；配合梯度累积、混合精度；或仅对注意力/线性层扰动。

## 三、数学形式

有效扰动预算 $\rho_{\text{eff}}=\rho\cdot f(\text{layer\_scale})$，按层分配。

## 四、代码实现

```python
if step < warmup_sam:
    apply_sam(model, rho=0.05)
```

## 五、与其他对比

- 与 梯度噪声深入 都可改善泛化但机制不同。
- 与 自适应学习率深入 常组合使用。

## 六、常见误区

- 全层全周期 SAM 成本过高却未必更优。
- 忽视 `create_graph` 带来的显存翻倍。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh
- mlabonne/llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- 大模型如何用 SAM？答：受限层/周期、配合累积与混合精度，控制显存与成本。

## 九、演进

全模型 → 分层 → 阶段性 SAM。

## 十、小结

SAM 价值明确但成本敏感，大模型需有策略地局部使用。
