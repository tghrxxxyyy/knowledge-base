# 自定义任务接入流程

> 对应 Gao 2021 lm-evaluation-harness (EleutherAI)。

## 一、背景与挑战
业务自有评测集难以用现成任务覆盖，需要低成本接入机制。

## 二、核心原理
实现 Task 子类或编写 YAML + 数据加载器，注册后由 evaluator 统一调度。

## 三、形式化与数学基础
任务接口约束：
$ \text{doc2text}, \text{fewshot\_context}, \text{construct\_requests}, \text{process\_results} $

## 四、代码实现
```python
def process_results(doc, results):
    # 将生成结果转为指标
    pred = results[0]
    return {'acc': int(pred.strip() == doc['answer'])}
```

## 五、与其他技术对比
相比从零写脚本，接入 harness 自动获得缓存、并行与报告。

## 六、常见误区
在 process_results 里做重计算拖慢评测；忽略指标命名冲突。

## 七、与开源书/权威来源对应
Gao 2021 给出任务扩展文档与示例。

## 八、面试题
接入自定义任务需要最小实现哪些方法？

## 九、演进与趋势
声明式任务让非工程师也能贡献评测。

## 十、小结
低摩擦接入是评测框架 adoption 的关键。
