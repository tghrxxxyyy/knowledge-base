# 结果复现与版本固化

> 对应 Gao 2021 lm-evaluation-harness (EleutherAI)。

## 一、背景与挑战
同一模型在不同时间跑出不同分数会削弱结论可信度。

## 二、核心原理
记录 harness 版本、模型哈希、配置哈希、随机种子，形成可重跑的实验指纹。

## 三、形式化与数学基础
实验指纹：
$ F = H(\text{harness} \Vert \text{model} \Vert \text{config} \Vert \text{seed}) $

## 四、代码实现
```python
import hashlib
def fingerprint(cfg):
    return hashlib.sha256(cfg.encode()).hexdigest()[:12]
```

## 五、与其他技术对比
相比口头描述，指纹化让结果可审计、可质疑、可复现。

## 六、常见误区
只记录模型名不记录权重哈希；忽略依赖库版本。

## 七、与开源书/权威来源对应
Gao 2021 鼓励固定版本与配置以复现榜单。

## 八、面试题
如何向审稿人证明你的评测可复现？

## 九、演进与趋势
评测结果上链与可验证缓存成为趋势。

## 十、小结
版本固化是把评测从实验变成工程的前提。
