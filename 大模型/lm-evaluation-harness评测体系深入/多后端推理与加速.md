# 多后端推理与加速

> 对应 Gao 2021 lm-evaluation-harness 与 Kwon 2023 vLLM。

## 一、背景与挑战
大规模评测在单卡上耗时巨大，需要复用高效推理后端。

## 二、核心原理
harness 通过抽象 generate 接口对接 vLLM、HF、本地模型，实现批处理与连续批解码。

## 三、形式化与数学基础
吞吐近似：
$ \text{throughput} \approx \frac{B \cdot L_{gen}}{T} $
其中 B 为批大小，L 为生成长度。

## 四、代码实现
```python
def run_eval(model, tasks, backend='vllm'):
    # 选择后端并批量推理
    engine = load_backend(backend)
    return engine.generate(model, tasks)
```

## 五、与其他技术对比
vLLM 的 PagedAttention 显著提升吞吐，适合千级样本评测。

## 六、常见误区
后端采样参数与原始论文不一致导致分数漂移。

## 七、与开源书/权威来源对应
Gao 2021 支持多后端；Kwon 2023 提出 vLLM 高效服务。

## 八、面试题
评测后端切换为何会影响分数？

## 九、演进与趋势
评测与服务共用同一推理栈以保证一致性。

## 十、小结
后端抽象让评测在成本与保真间取得平衡。
