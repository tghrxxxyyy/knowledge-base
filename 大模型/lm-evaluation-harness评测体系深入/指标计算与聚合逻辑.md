# 指标计算与聚合逻辑

> 对应 Gao 2021 lm-evaluation-harness (EleutherAI)。

## 一、背景与挑战
不同任务指标语义不同（acc、perplexity、BLEU），需要可插拔聚合。

## 二、核心原理
每个 Task 声明 aggregation 函数与 higher_is_better，evaluator 在样本级结果上做规约。

## 三、形式化与数学基础
加权聚合：
$ M = \sum_{t} w_t M_t, \quad \sum_t w_t = 1 $

## 四、代码实现
```python
def weighted(per_task):
    # per_task: [(metric, weight)]
    return sum(m * w for m, w in per_task)
```

## 五、与其他技术对比
harness 把指标与聚合解耦，便于跨任务构建综合榜单。

## 六、常见误区
把不同量纲指标直接平均；未声明 higher_is_better 导致排序反转。

## 七、与开源书/权威来源对应
Gao 2021 详述指标聚合与报告格式。

## 八、面试题
如何为混合任务构建可解释的综合分？

## 九、演进与趋势
指标血缘与不确定性估计被纳入报告。

## 十、小结
聚合逻辑必须透明、可声明，否则综合分失去意义。
