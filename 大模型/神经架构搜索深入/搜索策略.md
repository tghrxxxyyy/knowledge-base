# 搜索策略

> 见「神经架构搜索深入/NAS总览」；Liu et al., *DARTS*, 2018；Pham et al., *ENAS*, 2018。

## 一、背景与挑战

如何高效探索架构空间？

## 二、核心原理

- **RL**（Zoph 2017）：用 RNN 控制器生成架构，奖励为验证精度；有效但贵。
- **进化算法**：种群变异/交叉筛选。
- **可微 DARTS**：把离散选择松弛为 softmax 连续权重 α，与权重联合梯度优化，一次训练得架构——大幅加速。

## 三、数学形式

DARTS 目标 `min_α min_w L_val(w*, α)`，`w*` 为内层最优。

## 四、代码实现

```python
# 软选择算子
out = sum(softmax(alpha[i]) * ops[i](x))
```

## 五、关键要点

- DARTS 快但易塌缩（某算子权重独大）。
- RL/进化更稳但慢。

## 六、与其他对比

- RL 离散慢；DARTS 连续快。

## 七、常见误区

- DARTS 无坑——skip 连接塌缩常见。
