# 科学发现加速

> 见「科学计算大模型深入/科学计算总览」；LLM 加速科研闭环。

## 一、背景与挑战

假说-实验-分析循环慢，LLM 能否提质提速？

## 二、核心原理

用 LLM 做：文献挖掘与综述、假说生成与评分、实验方案设计、结果解释。结合专用科学模型形成「AI 科研助手」。需注意可复现与验证闭环，避免「幻觉假说」。

## 三、关键要点

- 假说需可证伪/可验证。
- 人类专家把关不可缺。

## 四、代码实现

```python
plan = llm(f"为验证假说{H}设计实验步骤")
```
