# 蛋白质与分子大模型

> 见「科学计算大模型深入/科学计算总览」；Jumper et al., *AlphaFold2*, 2021；分子基础模型。

## 一、背景与挑战

蛋白质结构/性质预测传统极难且贵。

## 二、核心原理

- **AlphaFold2**：用进化信息（MSA）+ 注意力预测 3D 结构，近实验精度。
- **分子基础模型**：在海量分子/蛋白序列上预训练，做性质预测、生成（如蛋白质设计语言模型）。
大模型把序列-结构-功能统一建模。

## 三、数学形式

Evoformer 用三角注意力在残基图上推理几何约束。

## 四、代码实现

```python
struct = alphafold.predict(msa)   # 结构预测
```

## 五、关键要点

- 数据（序列/结构）是核心资产。
- 生成需满足生化约束。
