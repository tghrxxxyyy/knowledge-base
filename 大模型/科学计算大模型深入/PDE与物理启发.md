# PDE 与物理启发网络

> 见「科学计算大模型深入/科学计算总览」；PINN / 神经算子。

## 一、背景与挑战

偏微分方程求解在高维/复杂域贵，传统网格法受限。

## 二、核心原理

- **PINN（物理启发神经网络）**：把 PDE 残差作为损失，网络直接学解函数，满足边界/初值。
- **傅里叶神经算子（FNO）**：学习从函数到函数的映射，一次训练可解一族 PDE，推理快。
物理约束使模型可外推。

## 三、数学形式

PINN 损失：`L = L_data + λ·||∂_t u - N(u)||²`（N 为微分算子）。

## 四、代码实现

```python
loss = mse(u, u_obs) + lambda_*pde_residual(u, coords)
```

## 五、关键要点

- 需自动微分算 PDE 残差。
- 高维优势明显。

## 六、与其他对比

- 网格法通用慢；算子法快但需训练。

## 七、常见误区

- PINN 必收敛——硬 PDE 难训。
