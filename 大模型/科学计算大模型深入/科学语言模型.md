# 科学语言模型

> 见「科学计算大模型深入/科学计算总览」；Galactica / Minerva 思路。

## 一、背景与挑战

科学文献/公式/符号密集，通用 LLM 弱。

## 二、核心原理

用科学语料（论文/公式/代码）预训练专门 LLM，提升数学推理与文献理解（如 Minerva 解数学题、Galactica 组织科学知识）。可辅助假说生成、文献综述、方程推导。

## 三、关键要点

- 数学符号需特殊处理。
- 推理需步骤验证。

## 四、代码实现

```python
ans = sci_llm(f"推导薛定谔方程一维解步骤")
```

## 五、与其他对比

- 通用 LLM 弱于专业；专业 LLM 强。

## 六、常见误区

- 科学 LLM 全对——仍会算错。
