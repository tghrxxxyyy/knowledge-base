# 语义分块与边界检测

> 对应 run-llama/llama_index 语义分块器与 huggingface/transformers 句向量编码。

## 一、背景与挑战
固定分块常在句子中间切断，破坏语义。语义分块依据内容相似度动态决定边界，使每块内聚、块间区分明显。

## 二、核心原理
把文本按句切分，计算相邻句向量的余弦距离；当距离超过阈值（或累积距离突变）处切分。也可用小型模型直接预测「是否为块边界」。

## 三、形式化与数学基础
对句子序列 $s_1,\dots,s_n$，距离 $d_i = 1 - \cos(e_i, e_{i+1})$。若 $d_i > \tau$ 或
$\frac{d_i}{\text{median}(d)} > \gamma$
则在该处断块。阈值 $\tau$ 控制块粒度。

## 四、代码实现
```python
def semantic_chunk(sents, emb, tau=0.5):
    blocks, cur = [], [sents[0]]
    for i in range(1, len(sents)):
        if 1 - cos(emb[i-1], emb[i]) > tau:
            blocks.append(" ".join(cur)); cur = [sents[i]]
        else:
            cur.append(sents[i])
    return blocks
```

## 五、与其他技术对比
相比固定/递归分块，语义分块边界更自然、检索更准；代价需句向量计算，且阈值敏感，需按语料校准。

## 六、常见误区
误区一：阈值全局固定，不同章节密度不同应自适应。误区二：仅按句切导致块过碎，需最小/最大长度约束。

## 七、与开源书/权威来源对应

- huggingface/transformers 提供句向量模型。
