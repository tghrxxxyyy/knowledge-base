# 朴素流水线与气泡分析

> 对应 Shoeybi 2019 (Megatron-LM) 与 Narayanan 2021 (高效大规模训练) 论述。

## 一、背景与挑战
模型过大无法单设备容纳时，按层切分到多设备形成流水线。若一次性跑完整个小批量再传递，设备大量空闲形成"气泡"。

## 二、核心原理
朴素流水线(fill-drain)将微型批量顺序流过各 stage：前 $p-1$ 个时间片仅有首个设备工作，末 $p-1$ 片仅有末设备工作，中间为满负载，空闲即气泡。

## 三、形式化与数学基础
设每 stage 单微批耗时 $t$，共 $p$ 个 stage、$m$ 个微批。总时间：
$ T = (m + p - 1) t $，
有效计算 $m p t$，气泡占比 $b = (p-1)/(m+p-1)$。

## 四、代码实现
```python
# 概念示意：各 stage 顺序处理微批(无重叠)
for micro in microbatches:
    if rank > 0:
        act = recv(rank - 1)        # 等上游激活
    out = stage(act if rank > 0 else micro)
    if rank < p - 1:
        send(rank + 1, out)         # 传给下游
```

## 五、与其他技术对比
朴素流水线实现简单但气泡大；GPipe/1F1B 用微批次填充显著降低空闲；张量并行无气泡但受单卡显存约束。

## 六、常见误区
误区一：切分越细越快——受气泡公式，设备数 $p$ 增反而空闲比例升。误区二：气泡只浪费时间——也延迟整体收敛步频。误区三：朴素流水线无通信，实际跨 stage 传激活。

## 七、与开源书/权威来源对应
Shoeybi 2019 给出 pipeline 与 tensor 对比；Narayanan 2021 分析气泡与调度。

## 八、面试题
问：气泡占比公式？答：$b=(p-1)/(m+p-1)$。问：减小气泡办法？答：增微批 $m$ 或用 1F1B。

## 九、演进与趋势
交错 1F1B 将各设备分配多段非连续层，进一步压低气泡至 $(p-1)/(m + p-1/k)$。

## 十、小结
朴素流水线揭示了设备空闲本质，是理解高级调度的起点。
