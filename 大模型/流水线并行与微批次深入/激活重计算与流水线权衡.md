# 激活重计算与流水线权衡

> 对应 Chen 2016 (梯度检查点) 与 Shoeybi 2019 (Megatron) 工程权衡。

## 一、背景与挑战
流水线训练缓存激活占显存，大模型单微批激活可达数十 GB。激活重计算(activation recomputation/checkpointing)用时间换空间。

## 二、核心原理
仅保存每层边界激活，反向时重新前向计算内部激活。设重计算比例 $r$，显存降为约 $(1-r)\\cdot M_{\\mathrm{act}}$，代价是约 $r$ 倍的额外前向算力。

## 三、形式化与数学基础
显存-算力权衡：
$ M'_{\\mathrm{act}} = (1-r) M_{\\mathrm{act}}, \\quad T' = T + r \\cdot T_{\\mathrm{fwd}} $，
典型选每 transformer block 仅存输入，重算内部，省约 60% 激活。

## 四、代码实现
```python
import torch
def block_forward(x, weight, use_recompute=True):
    if use_recompute:
        # 只保存输入，内部重算
        def fn(x):
            return torch.matmul(x, weight)
        return torch.utils.checkpoint.checkpoint(fn, x)
    return torch.matmul(x, weight)
```

## 五、与其他技术对比
与 offload 比，重计算不占带宽仅耗算力；与 1F1B 比，二者正交可同时用。选择性重算(仅大激活层)更优。

## 六、常见误区
误区一：重算免费——增加约 33% 训练时间。误区二：重算影响数值——仅激活重建，梯度等价。误区三：全层重算最优，实际选择性更省。

## 七、与开源书/权威来源对应
Chen 2016 梯度检查点；Shoeybi 2019 在 Megatron 用选择性重算。

## 八、面试题
问：重算换什么？答：用约 33% 额外前向算力换激活显存。问：与 1F1B 关系？答：正交，可叠加。

## 九、演进与趋势
与序列并行结合只重算序列维激活；与 fp8 激活进一步压缩。

## 十、小结
激活重计算是显存扩展的标准杠杆，与流水线/分片协同决定可训练最大模型。
