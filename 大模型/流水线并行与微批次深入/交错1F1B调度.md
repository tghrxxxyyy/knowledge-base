# 交错1F1B调度

> 对应 Narayanan 2021 (Efficient Large-Scale LM Training) 交错调度。

## 一、背景与挑战
标准 1F1B 气泡比 $b=(p-1)/(m+p-1)$。当 stage 数多、微批少时气泡仍显著。交错(interleaved) 1F1B 让每设备负责多段非连续层以削峰。

## 二、核心原理
将 $p$ 个 stage 各再分为 $k$ 段，每设备轮流处理 $k$ 段不同层。微批在设备内于多段间流动，使各设备更早进入双向繁忙，气泡降为 $(p-1)/(m+p-1/k)$。

## 三、形式化与数学基础
气泡比：
$ b_{\\mathrm{inter}} = \\frac{p-1}{m + p - 1/k} \\approx \\frac{p-1}{m} $，
较非交错随 $k$ 增大而减小，代价是每层 all-to-all 式激活通信增为 $k$ 倍。

## 四、代码实现
```python
# 概念：每设备持 k 段非连续层
for i in range(k):
    seg = model_segments[rank * k + i]
    for micro in microbatches:
        a = pipeline_step(seg, a)   # 跨段传递激活
```

## 五、与其他技术对比
非交错 1F1B 通信少但气泡大；交错以 $k$ 倍激活通信换更低气泡，是 Megatron 默认推荐。

## 六、常见误区
误区一：$k$ 越大越好——通信与实现复杂度上升，收益递减。误区二：交错改变数学计算——不，仅调度顺序变。误区三：需特殊优化器，实际仍标准 ZeRO。

## 七、与开源书/权威来源对应
Narayanan 2021 给出交错 1F1B 公式与实测；Shoeybi 2019 Megatron 采用。

## 八、面试题
问：交错如何降气泡？答：每设备多段使双向更早重叠。问：代价？答：激活通信增 $k$ 倍。

## 九、演进与趋势
与张量并行、ZeRO-3 组合成 3D 并行，调度器自动选 $k$。

## 十、小结
交错 1F1B 是大规模训练吞吐优化关键，需在气泡与通信间折中选取 $k$。
