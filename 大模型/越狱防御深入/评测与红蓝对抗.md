# 评测与红蓝对抗

> 见「安全红队方法论/红队方法论总览」与「越狱防御深入/防御层次」。

## 一、背景与挑战

防御效果需量化与对抗验证。

## 二、核心原理

用攻击成功率（ASR）衡量防御前后变化，红蓝对抗持续压测，报告风险趋势。

## 三、关键要点

- ASR 降即防御有效。
- 需覆盖多类攻击。

## 四、代码实现

```python
asr_before = eval(redteam, defend_old); asr_after = eval(redteam, defend_new)
```

## 五、与其他对比

- 主观感受不可靠；量化可比较。

## 六、常见误区

- 一次性评测足够——攻击在演进。
