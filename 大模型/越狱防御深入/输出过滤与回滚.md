# 输出过滤与回滚

> 见「越狱防御深入/防御层次」与「安全与对齐深入」。

## 一、背景与挑战

即便输入过关，输出仍可能有害。

## 二、核心原理

对输出做安全分类、敏感信息检测（PII）、 refusal 诱导；危险则拦截或触发安全回复，并回滚异常。

## 三、关键要点

- 输出过滤是最后闸门。
- 需记录用于改进。

## 四、代码实现

```python
if out_filter.unsafe(out): return safe_refusal()
```

## 五、与其他对比

- 仅输入过滤漏输出风险。

## 六、常见误区

- 输出一定安全——仍需检。

## 七、与开源书对应
