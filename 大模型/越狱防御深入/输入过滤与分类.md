# 输入过滤与分类

> 见「越狱防御深入/防御层次」与「安全与对齐深入/提示注入」。

## 一、背景与挑战

在模型执行前拦截恶意/越狱输入。

## 二、核心原理

用规则+分类器（含越狱检测模型）判别输入风险，命中则拒绝或改写；可用困惑度检测 token 走私（异常乱码）。

## 三、关键要点

- 分类器需持续更新。
- 过严误伤正常。

## 四、代码实现

```python
risk = jailbreak_clf(q); if risk > thr: block(q)
```

## 五、与其他对比

- 规则快但脆；模型准但慢。

## 六、常见误区

- 分类器一劳永逸——需对抗更新。
