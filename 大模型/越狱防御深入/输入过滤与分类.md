# 输入过滤与分类

> 对应 OWASP LLM Top 10（LLM01 提示注入）与 JailbreakBench 分类器；亦见 llm-course（mlabonne）安全章、HuggingFace 文本分类实践。

## 一、背景与挑战

输入过滤是纵深防御最外层的一道闸：在模型执行前对用户输入进行风险判别，命中则拒绝、改写或降权，从而以极低延迟阻断已知攻击，保护后续昂贵的推理与对齐资源。其挑战在于攻击面的多样性——从明文「忽略之前指令」到 Base64/Unicode 混淆、emoji 编码、token 走私（插入异常乱码绕过分词与检测），单靠关键词已远远不够。

另一矛盾是误伤与漏报的权衡：阈值过严会拒绝正常请求（如医疗、安全研究讨论），过松则放行越狱。且攻击者会主动对抗分类器（对抗样本、模板微扰），使静态模型快速失效，要求过滤能力可在线更新。

## 二、核心原理

输入过滤通常由异构组件组合：

1. 规则层：基于正则表达式/词典匹配已知攻击指纹（如特定角色名、注入短语），零延迟、可热更新。
2. 分类器层：微调或提示式越狱检测模型，对语义变体更鲁棒；常以 JailbreakBench 类数据集训练。
3. 困惑度/熵检测：token 走私常在异常字符分布上暴露，用困惑度或字符级异常分数识别（正常文本困惑度低，乱码/编码绕过高）。
4. 改写/净化：对可疑但非恶意输入做脱敏或结构化重写，而非直接拒绝。

多层并行打分，按最高风险决策，并保留可解释标签供监控。

## 三、形式化与数学基础（含 LaTeX）

对输入 $x$，分类器输出风险概率 $r(x)\in[0,1]$，困惑度检测器输出 $ppl(x)$。综合风险可加权融合：

$$
\mathrm{score}(x)=\alpha\, r(x)+(1-\alpha)\,\sigma\!\left(\frac{\mathrm{ppl}(x)-\mu}{\sigma}\right)
$$

其中 $\sigma(\cdot)$ 为 Sigmoid 归一。决策为：

$$
\text{block}(x)=\mathbb{1}\big[\mathrm{score}(x)>\theta\big]
$$

阈值 $\theta$ 由误伤率约束决定：要求假阳性率 $\text{FPR}\le\epsilon$ 下最大化召回，等价于在 ROC 曲线上按业务代价选工作点。

## 四、代码实现

```python
# 输入风险融合评分（结构示意）
def input_risk(text, clf, ppl_model, threshold=0.6):
    r = clf.jailbreak_prob(text)              # 分类器风险
    ppl = ppl_model.perplexity(text)          # 困惑度
    norm = 1 / (1 + math.exp(-(ppl - 50) / 10))
    score = 0.7 * r + 0.3 * norm              # 加权融合
    return score > threshold                  # 超阈值则拦截

# 命中后可选：改写净化而非直接拒绝
def sanitize(text):
    return strip_injection_markers(text)
```

## 五、与其他技术对比

- 规则：快、可解释、零成本，但脆（攻击者换表述即绕）。
- 分类器：对语义变体鲁棒，但需数据与推理开销，且会被对抗样本欺骗。
- 困惑度检测：专治 token 走私/编码绕过，但对自然语言的语义攻击无能为力。
- 三者互补，单一机制均不足以覆盖全攻击面；且都弱于模型内在对齐，仅作为外层快闸。

## 六、常见误区

- 「分类器一劳永逸」：攻击在演化，模型须持续用新红队样本再训练。
- 「关键词足够」：现代越狱大量使用编码/角色扮演，规避字面匹配。
- 「过滤越严越好」：过严误伤正常用户，需按 FPR 约束调阈值。
- 「只在输入端过滤」：输出层仍需兜底，防止过滤被绕过后的泄露。

## 九、演进与趋势

从静态正则走向「检索增强 + 模型」的语义防火墙：用攻击知识库做近邻匹配，结合小模型实时打分；并引入对抗训练使过滤器自身抗微扰。与输出过滤、监控共享标签体系，形成统一安全策略面，支持在线热更新与 A/B 验证。

工程实践要点：
- 过滤器应支持热更新，新攻击模板在监测到后分钟级上线，缩短防御空窗。
- 对过滤决策保留可解释标签（命中规则/分类器分数/困惑度），便于复盘与误伤分析。
- 与监控联动做 A/B：新版本过滤器先在少量流量灰度，确认误伤可控再全量。
语义防火墙的成熟度，直接决定纵深防御第一道闸的可靠性。同时建议对过滤器本身做对抗再训练，使其随攻击演化而不退化。

补充要点：
- 过滤器应支持热更新，新攻击模板分钟级上线缩短空窗。
- 误伤率应作为独立指标监控，而非仅看拦截率。

## 十、小结

输入过滤与分类以规则、分类器、困惑度检测等异构机制在最外层拦截越狱，是低成本、低延迟的第一道闸。其有效性依赖多机制互补、可在线更新与阈值按误伤约束调优，并应与 OWASP、JailbreakBench 等权威基准对齐，作为纵深防御而非孤立场。
