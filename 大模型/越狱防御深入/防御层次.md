# 越狱防御层次

> 对应 llm-course 安全章与 OWASP LLM Top 10；见「安全红队方法论/越狱攻击分类」。

## 一、背景与挑战

越狱手法多变，单点防御易被绕过，需多层。

## 二、核心原理

多层：输入过滤（敏感词/分类器）→ 系统提示加固 → 输出过滤 → 监控回滚。纵深防御。

## 三、关键要点

- 任一层都不应单独信赖。
- 监控补防御盲区。

## 四、代码实现

```python
if input_filter.block(q) or not safe_prompt(p): refuse()
```

## 五、与其他对比

- 单点易破；多层鲁棒。

## 六、常见误区

- 加一句安全提示即够——攻击者换写法。
