# 越狱防御层次

> 对应 OWASP LLM Top 10 与 llm-course（mlabonne）安全章；亦见「安全红队方法论/越狱攻击分类」。

## 一、背景与挑战

越狱手法高度多样：提示注入、角色扮演、编码混淆、多轮渐进、上下文泄露、工具/插件滥用等，单一防线几乎必然被绕过。原因在于每一层技术都有固有盲区——关键词过滤挡不住语义变体，系统提示可被指令覆盖，模型对齐对零日攻击脆弱。因此安全工程的基本共识是纵深防御（defense in depth）：用多层、异构、互补的机制叠加，使攻击者在任一层失败都需付出更高成本，且单点失效不至于整体崩塌。

挑战在于多层之间需协调而非冲突（如输入过滤过严误伤正常请求、输出过滤与产品体验矛盾），并且要可观测、可度量各层贡献，避免「看似多层实则互漏」。

## 二、核心原理

典型纵深防御层次（由外到内）：

1. 输入过滤与分类：规则 + 分类器在模型执行前拦截已知越狱模板、检测 token 走私（异常乱码/困惑度高）。
2. 系统提示加固：强约束、分层指令，引导模型在语义层拒绝越权。
3. 模型内在防御：对齐训练、对抗训练使模型参数层面抗拒有害顺从。
4. 输出过滤与回滚：对生成内容做安全分类、PII 检测，危险则拦截或回退安全回复。
5. 监控与应急响应：线上检测异常模式、告警、热补丁，形成闭环。

各层应「互不单独信赖」，并假设外层可能被绕过，内层必须兜底。

## 三、形式化与数学基础（含 LaTeX）

设单层被绕过概率为 $p_i$，在独立假设下整体被成功越狱的概率为各层均失效之积：

$$
P_{\text{fail}}=\prod_{i=1}^{n} p_i
$$

即使每层单独失效概率 $p_i=0.3$，五层叠加后 $P_{\text{fail}}=0.3^5\approx 0.0024$，显著低于单层。更一般地，考虑层间相关性 $\rho$，可写为：

$$
P_{\text{fail}}=\prod_{i} p_i + \text{correlation\_penalty}(\rho)
$$

即若各层高度相关（如都基于同一分类器），纵深收益会被相关性侵蚀——这解释了为何要采用异构机制（规则/模型/训练/监控）。

## 四、代码实现

```python
# 多层防御编排（结构示意）
def defend(user_query, model):
    if input_filter.block(user_query):        # 第一层：输入过滤
        return safe_refusal()
    if not safe_prompt(system_prompt):         # 第二层：提示完整性校验
        return safe_refusal()
    output = model.generate(user_query)        # 第三层由模型对齐保障
    if out_filter.unsafe(output):              # 第四层：输出过滤
        return safe_refusal()
    monitor.log(user_query, output)            # 第五层：监控闭环
    return output
```

## 五、与其他技术对比

- 单点防御（仅提示或仅过滤）：实现简单但鲁棒性差，攻击者找到缝隙即全面突破。
- 多层纵深：成本高、需协调，但能抵御分布漂移与零日攻击，是生产级部署的必选项。
- 异构多层 vs 同构多层：前者（规则+模型+训练）抗相关性失效，优于复制同类防线。

## 六、常见误区

- 「加一句安全提示就够」：攻击者换写法即可绕过，提示只是软层。
- 「层越多越安全」：若各层同源、强相关，纵深收益被抵消，且维护成本陡增。
- 「只部署输入层」：忽略输出层与监控，模型内在缺陷仍会泄露。
- 「不度量各层贡献」：无法判断哪层是短板，优化无的放矢。

## 九、演进与趋势

从「堆砌过滤器」走向「可观测的防御编排」：用统一策略层描述各层责任与兜底顺序，结合运行时指标动态调权（如攻击高发期临时加严输出层）。未来趋势是自治红队持续压测每一层并自动生成补丁，使纵深防御成为自适应系统。

编排实践建议：
- 明确每层的「责任边界」与「兜底承诺」，避免层间互相假设对方已拦。
- 用统一标签贯穿各层，使一次攻击在五层中都有可观测轨迹。
- 定期做「抽层演练」：临时关闭某层，验证其余层是否真能兜底。
纵深防御的成熟度，不在层数多少，而在层间是否真正互补、可观测、可演练。建议为每个层定义可量化指标，避免「有层无防」的形式主义。

补充要点：
- 各层应独立度量增量贡献，防止形同虚设。
- 抽层演练应定期执行，验证兜底能力而非纸面多层。

## 十、小结

越狱防御层次以纵深、异构、互补的多层机制对抗多样化的越狱手法：输入过滤、提示加固、模型对齐、输出过滤、监控响应环环相扣。其有效性依赖层间独立性与可度量贡献，并应以 OWASP LLM Top 10 为基准设计，而非依赖任何单点方案。
