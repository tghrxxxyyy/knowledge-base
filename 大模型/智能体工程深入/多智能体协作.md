# 多智能体协作 Multi-Agent

> 对应 AutoGen / MetaGPT / CAMEL。

## 一、核心概念

多个角色化 Agent 协作完成复杂任务：规划者、执行者、 critic、工具调用者等。典型模式：

- **辩论/评审**：多 agent 互评提升质量。
- **流水**：角色分工(产品经理→工程师→测试)。
- ** orchestrator**：中心调度分发子任务。

## 二、关键要点

| 模式 | 优势 |
|------|------|
| 分工 | 专长化 |
| 评审 | 纠错 |
| 编排 | 可控 |

## 三、常见误区

- 无脑堆 agent 增加延迟与成本，未必提质。
- 通信协议混乱导致信息丢失。
