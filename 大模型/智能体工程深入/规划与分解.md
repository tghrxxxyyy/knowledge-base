# 规划与任务分解

> Agent 的核心能力之一。

## 一、核心概念

复杂任务需先分解子目标再执行：

- **Plan-and-Execute**：先生成完整计划，再逐步执行（如 Plan-and-Solve）。
- **Tree-of-Thought**：探索多路径(见 ToT)。
- **子目标驱动**：每步设子目标，完成即更新。

## 二、关键要点

| 策略 | 适用 |
|------|------|
| 一次性计划 | 确定任务 |
| 动态重规划 | 不确定环境 |
| ToT | 需探索 |
