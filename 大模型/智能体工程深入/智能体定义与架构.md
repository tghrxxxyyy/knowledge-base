# 智能体定义与架构

> 对应 Agent 工程实践与 ReAct/Reflexion 系列（见 RAG深入 的 ReAct 文档）。

## 一、核心概念

智能体(Agent) = 大模型 + 感知(observation) + 规划(planning) + 记忆(memory) + 行动(action/tools) 的闭环系统，能在环境中迭代达成目标，而非单轮问答。

核心循环：

```
感知 → 规划 → 行动(工具) → 观察 → (反思) → 再规划 ...
```

## 二、架构组件

| 组件 | 作用 |
|------|------|
| LLM 核心 | 推理/决策 |
| 规划器 | 任务分解 |
| 工具集 | 外部能力 |
| 记忆 | 历史/知识 |
| 反思 | 错误修正 |

## 三、关键要点

- Agent 的「智能」来自闭环与工具，而非模型本身。
- 需约束最大步数防失控。
