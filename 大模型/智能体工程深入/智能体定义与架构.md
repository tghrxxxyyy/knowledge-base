# 智能体定义与架构

> 对应 Russell & Norvig 的智能体定义、Yao et al. ReAct（2022）与 Shinn et al. Reflexion（2023）系列；工程实践参考 LangChain Agents 与 llm-course「LLM Engineer / Agents」。属智能体工程深入板块。

## 一、背景与挑战

传统 LLM 应用是「单轮问答」：给 prompt、出文本即结束。但真实任务（订票、写代码、做调研）需要**多步、有状态、能动手**的系统。智能体（Agent）正是把 LLM 从「生成器」升级为「自主行动者」的范式：它感知环境、做决策、调工具、看结果、再决策，直到目标达成。挑战在于：如何组织这些能力，使系统可控、可观测、可终止。

## 二、核心原理

智能体 = 大模型（大脑）+ 若干能力模块的**闭环系统**：

- **感知（Observation）**：读取用户输入、环境状态、工具返回。
- **规划（Planning）**：把目标拆为子目标/步骤。
- **记忆（Memory）**：保存历史与经验（见记忆机制文档）。
- **行动（Action / Tools）**：调用外部能力（搜索、代码、API）。
- **反思（Reflection）**：基于反馈修正策略（见反思文档）。

核心循环（以 ReAct 为原型）：

```
感知 → 规划(Thought) → 行动(Tool) → 观察(Observation) → (反思) → 再规划 ... → 完成
```

Agent 的「智能」并不单纯来自模型权重，而来自**闭环 + 工具 + 记忆**的编排；约束最大步数是防止失控的基本护栏。

## 三、形式化与数学基础

把 Agent 建模为在环境 $\mathcal{E}$ 中运行的策略 $\pi$。在时刻 $t$，它看到轨迹前缀 $\tau_t=(o_1,a_1,\dots,o_t)$，产出下一步动作：

$$
a_t \sim \pi_\theta\big(\cdot \mid \tau_t; \text{memory}_t, \text{plan}_t\big)
$$

环境返回 $o_{t+1}=\mathcal{E}(a_t)$。目标函数为累计奖励（或任务完成度）：

$$
\max_\theta\; \mathbb{E}\Big[\sum_{t} r(o_t,a_t) \;\big|\; \text{终止于 } a_t=\text{Finish}\Big]
$$

强化学习/RLHF 可优化 $\pi_\theta$；而 Reflexion 类方法用语言反思做「无梯度」的策略修正，等价于在记忆中写入经验以改变后续 $\pi$ 的条件分布。

## 四、代码实现

```python
def agent_loop(llm, tools, user_goal, max_steps=15):
    mem, trace = [], [{"role":"user","content": user_goal}]
    for step in range(max_steps):
        out = llm(trace + mem)                  # 感知+记忆+规划
        thought, action = parse_react(out)
        if action.name == "Finish":
            return action.result
        obs = tools[action.name](**action.args) # 行动
        trace.append({"role":"user",
                      "content": f"Observation: {obs}"})  # 观察回填
    return "达到最大步数，未完成任务"
```

## 五、与其他技术对比

| 形态 | 是否多步 | 是否用工具 | 是否记忆 | 自主度 |
|------|---------|-----------|---------|--------|
| 单轮 LLM | 否 | 否 | 否 | 低 |
| 提示链 | 是(固定) | 可选 | 否 | 中 |
| ReAct Agent | 是(动态) | 是 | 可选 | 高 |
| 多智能体 | 是 | 是 | 是 | 高 |

Agent 相比单次调用多了「感知—行动—反思」闭环，能处理需外部信息与迭代的任务。

## 六、常见误区

- 认为「上 Agent 一定更强」：许多任务单轮或提示链更稳更省。
- 不约束最大步数，Agent 陷入循环空转烧钱。
- 工具描述不清，模型误调用或参数错误。
- 忽略可观测性，出错后无法复盘轨迹。

## 九、演进与趋势

Agent 架构从「单循环 ReAct」演进为「多角色协作 + 编排器 + 可控记忆」（见多智能体协作、框架对比）。推理模型（o1/R1）把「思考」内化，减少显式 Thought 文本。协议层出现标准化工具调用（MCP）与 Agent 间通信规范。趋势是「可控自主」：在保持自动化的同时，用权限网关、人类在环与可中断恢复把风险压到可接受范围。

## 十、小结

智能体是把 LLM 升级为自主行动者的闭环系统，由感知、规划、记忆、行动、反思五模块构成，核心是「感知—行动—观察—反思」的持续循环。其智能来自编排而非单纯权重，落地必须用最大步数护栏、清晰工具描述与轨迹可观测来保障可控。它是从「会说话」到「能办事」的关键一跃。
