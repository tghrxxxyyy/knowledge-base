# 反思与自我修正 Reflexion

> 对应 Shinn et al., *Reflexion: Language Agents with Verbal Reinforcement Learning*, 2023（NeurIPS，arXiv:2303.11366）。属智能体工程深入板块。

## 一、背景与挑战

多数 Agent 是「一次性尝试」：失败后就换个输入重跑，却不从失败中**学到经验**。RLHF 等方法虽能强化，但需要梯度更新与训练管线，成本高、迭代慢。Reflexion 提出一种轻量替代：让 Agent 在失败后生成**自然语言反思（reflection）**，存入记忆，下次遇到类似情境时参考，从而「越试越聪明」。挑战在于：反思要真实有用（指出错因与对策），而非空泛复述；且需可靠的「评估信号」判断何时该反思。

## 二、核心原理

Reflexion 在 ReAct 类循环外加一层「反思记忆」：
1. **尝试**：Agent 执行任务，得到轨迹与结果。
2. **评估**：外部环境或自评估给出成功/失败信号（如测试用例、奖励函数）。
3. **反思**：若失败，模型基于轨迹写一段自然语言反思——错在哪、为何错、下次怎么做。
4. **记忆**：反思存入「反思库」，作为后续尝试的额外上下文。
5. **再尝试**：带反思重试，直至成功或达最大轮次。

这是一种**语言级强化学习（verbal RL）**：不更新权重，而是把「经验」写成文本注入上下文，相当于对策略的条件分布做「无梯度」修正。反思质量高度依赖评估信号的可靠性。

## 三、形式化与数学基础

设第 $k$ 次尝试轨迹为 $\tau^{(k)}$，环境给出标量/二值奖励 $r^{(k)}$。当 $r^{(k)}<\tau$ 时生成反思：

$$
m^{(k)} = \text{LLM}\big(\text{反思提示} \oplus \tau^{(k)} \oplus r^{(k)}\big)
$$

记忆累积 $M^{(k)} = M^{(k-1)} \cup \{m^{(k)}\}$，下一轮策略条件化为：

$$
a_t \sim \pi_\theta\big(\cdot \mid \tau_t, M^{(k-1)}\big)
$$

目标等价于用语言经验逼近策略改进：

$$
\pi^{(k+1)} \approx \pi^{(k)} \text{ s.t. } \mathbb{E}[r] \text{ 提升}
$$

与策略梯度不同，Reflexion 的「梯度」是离散文本，无反向传播，因而零训练成本、可随时注入。

```python
def reflexion_loop(agent, env, goal, max_trials=3):
    memory = []                       # 反思记忆
    for t in range(max_trials):
        traj = agent.run(goal, memory)
        reward = env.evaluate(traj)
        if reward >= PASS:
            return traj

            f"任务失败。轨迹：{traj}\n评分：{reward}\n"
            f"请写出一段反思：错因与下次对策（简洁）。")
        memory.append(reflection)     # 经验入库，下次带上
    return f"反思 {max_trials} 轮仍未通过"
```

## 五、与其他技术对比

| 方法 | 是否更新权重 | 成本 | 经验形式 | 适用 |
|------|------------|------|---------|------|
| 重采样 | 否 | 低 | 无 | 随机任务 |
| RLHF/PPO | 是 | 高 | 数值奖励 | 大规模对齐 |
| Reflexion | 否 | 中 | 自然语言 | 需从失败学 |
| 人类反馈 | 否 | 依赖人 | 文本 | 高精度 |

Reflexion 介于「纯重采样」与「训练」之间，用语言经验换得低成本适应。

## 六、常见误区

- 反思写成「我下次会更小心」之类空话，无具体可操作对策。
- 评估信号不可靠（自评过松），导致错误反思被当真理。
- 反思无去重/压缩，记忆膨胀、噪声累积。
- 把反思当训练，误以为模型权重已变——其实仅上下文生效。

## 九、演进与趋势

Reflexion 启发了「自我改进 Agent」谱系：与过程奖励模型结合（对每步反思打分）、与树搜索结合（对失败分支反思后剪枝）、多智能体中「评审角色」专职反思。随推理模型兴起，部分反思被内化进「思考」阶段。前沿方向是把反思蒸馏进长期记忆（见记忆机制），以及与可微优化闭环结合，使语言经验最终也能反哺权重，实现「在线终身学习」。

## 十、小结

Reflexion 用自然语言反思把失败经验写入记忆，使 Agent 无需梯度更新即可「从错误中学习」，是一种零训练成本的轻量强化。其有效性建立在可靠评估信号与高质量、可操作反思之上；落地须防空话反思、记忆膨胀与错误信号。它是连接「单次尝试」与「持续智能体」的关键一环。
