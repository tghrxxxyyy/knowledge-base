# 记忆机制 Memory

> 对应 Agent 记忆设计与 MemGPT 思路。

## 一、核心概念

Agent 记忆分三层：

- **短期记忆**：当前上下文(对话历史)，受窗口限制。
- **长期记忆**：外部存储(向量库/数据库)，检索召回。
- **工作记忆**：中间推理/草稿。

MemGPT 借鉴操作系统分页，把记忆当「内存/磁盘」分层管理，按需换入换出上下文。

```python
# 检索长期记忆
```

## 三、关键要点

- 上下文窗口是稀缺资源，需筛选。
- 记忆格式影响检索质量。
