# 记忆机制 Memory

> 对应 MemGPT（Packer et al., 2023, arXiv:2310.08560）的「分层记忆」思路，以及 Generative Agents（Park et al., 2023）的记忆流设计。属智能体工程深入板块。

## 一、背景与挑战

LLM 的上下文窗口是有限的「工作区」。一个长期运行的 Agent 会面对远超窗口的历史对话、文档与经验，若全部塞入上下文，既昂贵又会被注意力稀释（「中间遗忘」）。记忆机制的目标：在**有限上下文**与**长期知识/经验**之间架桥——决定「什么该记住、何时召回、放哪里、如何淘汰」。

## 二、核心原理

Agent 记忆通常分三层：
1. **短期/工作记忆**：当前上下文（对话历史 + 临时草稿），受窗口硬限制，是模型「正在想」的内容。
2. **长期记忆**：外部持久存储，如向量库（语义检索）、键值库、图数据库，按需召回写入上下文。
3. **情景/反思记忆**：对经验的浓缩（摘要、反思、学到的规则），介于二者之间，降低检索噪声。

MemGPT 借鉴操作系统分页：把上下文当「内存」，外部存储当「磁盘」，由一个「控制器」决定何时把哪段记忆换入/换出，并维护层级指针。Generative Agents 则用「记忆流 + 近因/重要性/相关性」三重打分做召回，使 Agent 行为更具连贯人格。

## 三、形式化与数学基础

设查询时刻上下文预算为 $B$，候选记忆集 $M=\{m_j\}$。召回按综合分数取 Top-$k$ 写入上下文：

$$
s(m_j) = \alpha\,\text{recency}(m_j) + \beta\,\text{importance}(m_j) + \gamma\,\text{relevance}(q,m_j)
$$

其中相关性常用向量余弦相似度 $\text{relevance}=\cos\big(E(q),E(m_j)\big)$，且约束 $\sum_j \text{len}(m_j)\le B$。换入换出可写为：

$$
\text{ctx}_t = \text{select}_{|M'|\le B}\Big(\text{core}(t) \cup M'_{\text{top-}k}\Big)
$$

操作系统式页面置换（FIFO/LRU）对应「最久未用记忆被换出磁盘」，以恒定上下文成本支撑无限历史。

def recall(query, vector_db, k=5, budget=4000):
    q_emb = embed(query)
    hits = vector_db.search(q_emb, k=k)          # 长期记忆语义召回
    packed = core_memory                        # 常驻核心记忆
    for m in sorted(hits, key=lambda x: -x.score):
        if tok_len(packed) + m.tok <= budget:
            packed.append(m.text)                # 换入
        else:
            break
    return packed

## 五、与其他技术对比

| 记忆类型 | 介质 | 检索方式 | 成本 | 典型用途 |
|---------|------|---------|------|---------|
| 短期(上下文) | KV Cache | 全量 | 高/窗口 | 当前会话 |
| 长期(向量) | 向量库 | 语义 | 低/查询 | 知识检索 |
| 反思/摘要 | 文本库 | 关键词+语义 | 低 | 经验复用 |
| 结构化(图/DB) | 数据库 | 精确 | 低 | 关系查询 |

## 六、常见误区

- 把所有历史无差别塞入上下文，既超预算又稀释注意力。
- 只做向量召回忽略「重要性/近因」，导致关键旧记忆被淹没。
- 记忆写入不摘要，存储膨胀且噪声累积。
- 长期记忆与上下文不一致（召回了过期信息），未做时效性标注。
- 把向量库当唯一记忆介质，忽视结构化事实（如用户的明确偏好）应存数据库。
- 反思/摘要链无限增长，缺乏压缩与去重，召回时反而引入矛盾。

## 九、演进与趋势

记忆机制从「向量召回」走向「多模态分层记忆」：图像、工具结果、对话统一入记忆；并用自我反思持续提炼「经验库」。多智能体下出现「共享记忆/黑板（blackboard）」供角色间同步。前沿方向包括可学习的记忆压缩（让模型把记忆蒸馏进少量 token）、以及把记忆作为可微检索与训练闭环的一部分，使 Agent 真正「越用越聪明」。

工程补充：
- **写入即索引**：记忆落库时同步生成嵌入与元数据（时间、类型、重要性），便于多维召回。
- **定期 consolidation**：周期性把零散记忆摘要为「长期事实」，降低检索噪声。
- **隐私边界**：记忆可能含敏感信息，需加密存储与按用户/会话隔离，避免跨用户泄漏。

## 十、小结

记忆机制是 Agent 突破上下文窗口、实现长期连贯行为的关键。三层（短期/长期/反思）分工，借助语义+近因+重要性的召回与操作系统式换入换出，在有限预算下支撑「无限历史」。落地须关注摘要写入、时效性标注与检索质量，避免无差别堆叠导致注意力稀释。
