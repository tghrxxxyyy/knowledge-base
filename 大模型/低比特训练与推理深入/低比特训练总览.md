# 低比特训练总览

> 对应 Micikevicius et al., *Mixed Precision Training*, 2018；Dettmers et al., *8-bit Adam*, 2021。

## 一、背景与挑战

训练比推理更吃显存（权重+梯度+优化器状态），低比特训练可降显存与带宽、提速度。

## 二、核心原理

主权重保持 FP32（master weight），前向/反向用 FP16/BF16；优化器状态可压缩（如 8-bit Adam）；梯度缩放防溢出。

## 三、数学形式

Loss scaling：$L_{scaled}=sL$，反向得 $g_{scaled}=s g$，更新前 $g=g_{scaled}/s$，避免 FP16 下溢。

## 四、代码实现

```python
with torch.cuda.amp.autocast(dtype=torch.bfloat16):
    loss = model(x)
scaler.scale(loss).backward(); scaler.step(opt)
```

## 五、与其他对比

- 与 模型压缩与稀疏量化深入（推理侧）互补，训练侧更敏感。
- 与 训练数值稳定性深入（若新增）共享。

## 六、常见误区

- 误以为 BF16 需 loss scaling；BF16 动态范围大，通常不需。
- 主权重不保留 FP32 致累积误差。

## 八、面试题

- 为何需 master weight？答：FP16 累加误差大，FP32 主权重保更新精度，副本转低比特计算。

## 九、演进

FP32 → FP16 混合 → BF16 → 8bit 优化器/参数。

## 十、小结

低比特训练以 master weight + 低比特计算降成本，BF16 已成主流。
