# 低比特训练数值稳定性

> 对应训练稳定性经验；与 训练不稳定诊断深入 / 数值稳定性深入 衔接。

## 一、背景与挑战

低比特下溢出/舍入累积，致 loss 爆炸或停滞。

## 二、核心原理

用 BF16（大动态）降低溢出；梯度裁剪；保留 FP32 master；延迟缩放稳定 FP8。

## 三、数学形式

梯度裁剪 $\|g\|\leftarrow g\cdot\min(1,\tau/\|g\|)$；防止 $\|g\|>\tau$ 爆炸。

## 四、代码实现

```python
g = clip_grad_norm_(model.parameters(), max_norm=1.0)
opt.step()
```

## 五、与其他对比

- 与 直接偏好优化深入（DPO 数值敏感）共享稳定手段。
- 与 模型压缩与稀疏量化深入 互补。

## 六、常见误区

- BF16 误加 loss scaling 反致不稳。
- 裁剪阈值过大等于没裁。

## 七、与开源书对应

## 八、面试题

- 低比特为何要梯度裁剪？答：低精度放大异常梯度，裁剪防其主导更新致发散。

## 九、演进

无裁剪 → 范数裁剪 → 自适应缩放。

## 十、小结

低比特训练靠动态范围+裁剪+master 权重保稳定。
