# 低比特推理内核

> 对应 Marlin（GPTQ 高效内核）、ExLlama；llama.cpp GGUF 内核。

## 一、背景与挑战

4bit 权重需反量化到 FP16 才能用 Tensor Core，反量化开销可能抵消压缩收益。

## 二、核心原理

专用内核（如 Marlin）在 Tensor Core 上做“乘加即反量化”，按 group 取尺度现场解包 INT4 到 FP16 计算。

## 三、数学形式

输出 $y_i = \sum_j s_g \cdot \text{dequant}(q_{ij}) \cdot x_j$；group g 共享尺度 $s_g$。

## 四、代码实现

```python
# 伪：INT4 权重按 group 解包乘 FP16 激活
acc += dequant(q[g]) * x
```

## 五、与其他对比

- 与 GPTQ/AWQ（算法）不同，这里是硬件落地效率。
- 与 边缘设备部署优化深入（移动内核）衔接。

## 六、常见误区

- 认为量化即加速；无高效内核时反量化成瓶颈。
- group 越小越精但越慢（尺度开销）。

## 八、面试题

- 为何需专用 4bit 内核？答：避免先反量化再计算的中间开销，在乘加中现场解包才真加速。

## 九、演进

通用 GEMM → 反量化内核 → Tensor Core 内解包（Marlin）。

## 十、小结

低比特推理加速依赖专用内核，算法与工程缺一不可。
