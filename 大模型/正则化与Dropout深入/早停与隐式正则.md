# 早停与隐式正则

> 对应早停理论（Caruana et al.）；归一化隐式正则。

## 一、背景与挑战

训练过久易记训练集；早停在验证误差拐点停。

## 二、核心原理

早停等价于 L2 正则的某种形式（权值趋于小），且省算力。
BN/归一化本身带来隐式正则（限制表征容量）。

## 三、数学形式

提前停止的训练轮数 $t^*$ 可视为复杂度控制；BN 的 minibatch 统计量引入噪声式正则。

## 四、代码实现

```python
if val_loss > best + delta: wait+=1
if wait>=patience: break
```

## 五、与其他对比

- 早停与 L2 有等效性但更省；BN 正则常被低估。
- 与 批归一化深入 / 归一化深入 衔接。

## 六、常见误区

- patience 过小致欠训练；过大失早停意义。
- 忽视 BN 在 small batch 下的正则波动。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 早停为何等价于正则？答：限制有效训练步数，约束权重远离初始不远，类似 L2。

## 九、演进

手动早停 → 自动 patience → 与课程学习结合。

## 十、小结

早停与归一化提供高效隐式正则，是大模型训练隐形成分。
