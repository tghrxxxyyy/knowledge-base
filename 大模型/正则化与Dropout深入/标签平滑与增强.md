# 标签平滑与数据增强正则

> 对应 Müller et al., *Label Smoothing*, 2019；数据增强综述。

## 一、背景与挑战

硬标签使模型过自信、校准差；增强扩充数据分布提升鲁棒。

## 二、核心原理

标签平滑：把 one-hot 替换为 $y'=(1-\epsilon)y+\epsilon/K$，抑制过自信、改善校准。
数据增强：对输入做变换（裁剪/色彩/同义词替换/回译）扩样。

## 三、数学形式

平滑交叉熵：$H(y',p)=-\sum_i y'_i\log p_i$。

## 四、代码实现

```python
smooth = (1-eps)*onehot + eps/K
loss = F.cross_entropy(p, smooth)
```

## 五、与其他对比

- 标签平滑改善校准但不一定提精度；常与增强并用。
- 与 数据增强深入（本批）互补。

## 六、常见误区

- 平滑过度致欠拟合。
- 增强过强扭曲语义（尤其文本）。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 标签平滑为何改善校准？答：不再逼模型对错误类概率趋零，输出更柔和可信。

## 九、演进

硬标签 → 平滑 → 自适应平滑（按样本）。

## 十、小结

标签平滑与数据增强是低成本正则，提升校准与鲁棒。
