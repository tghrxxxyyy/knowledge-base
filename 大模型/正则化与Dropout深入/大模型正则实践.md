# 大模型正则化实践

> 对应 LLM 预训练/微调经验；与 参数高效微调深入 / 训练不稳定诊断深入 衔接。

## 一、背景与挑战

大模型易过拟合小数据（微调）或需强正则稳预训练。

## 二、核心原理

预训练：权重衰减(AdamW)+DropPath+数据增强；微调：小 LR+少量 epoch+可能 dropout 关小。

## 三、数学形式

微调常用 $\eta\sim10^{-5}$，epoch 少；配合早停防过拟合。

## 四、代码实现

```python
opt = AdamW(p, lr=2e-5, weight_decay=0.0)   # 微调常减 decay
```

## 五、与其他对比

- 预训练重显式正则；微调重保守更新（小 LR）。
- 与 正则化与Dropout深入 中方法组合。

## 六、常见误区

- 微调沿用预训练大 decay 致欠拟合。
- 关 dropout 但没早停致过拟合。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course
- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 微调为何用小 LR 与弱正则？答：避免破坏预训练知识、防过拟合小数据。

## 九、演进

重正则预训练 → 轻正则微调 → 参数高效+保守更新。

## 十、小结

大模型正则按阶段差异化：预训练强、微调保守，保障稳定与知识保留。
