# 正则化总览

> 对应 Goodfellow et al., *Deep Learning* 第 7 章；深度学习基础。

## 一、背景与挑战

模型容量大易过拟合；正则限制假设空间、提升泛化（泛化理论深入 衔接）。

## 二、核心原理

显式正则：L1/L2（权重衰减）、Dropout 家族、数据增强、标签平滑、早停、BN 隐式正则。

## 三、数学形式

L2 目标：$\min_W \mathcal L + \frac{\lambda}{2}\|W\|_2^2$；L1 用 $\lambda\|W\|_1$ 促稀疏。

## 四、代码实现

```python
opt = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=0.01)
```

## 五、与其他对比

- L2 与 AdamW 的 weight decay 实现不同（解耦）。
- 与 优化理论深入 / 泛化理论深入 共享理论。

## 六、常见误区

- 把 weight_decay 当纯 L2（AdamW 已解耦）。
- Dropout 与 BN 同用需小心（早期冲突）。

## 七、与开源书对应

- d2l-zh 正则章：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- L1 与 L2 区别？答：L1 促稀疏、特征选择；L2 均化权重、抗共线性。

## 九、演进

L2 → Dropout → 数据增强/标签平滑 → 隐式正则（BN/归一化）。

## 十、小结

正则是控制过拟合的核心，需按数据量与架构组合使用。
