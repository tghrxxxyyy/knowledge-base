# 灾难性遗忘机制

> 对应 Kirkpatrick et al., *Overcoming Catastrophic Forgetting in Neural Networks*（EWC）, PNAS 2017；Luo et al., *An Empirical Study of Catastrophic Forgetting in LLMs during Continual Fine-tuning*, 2023。

## 一、背景与挑战

对齐税的主要成分是遗忘：模型在窄分布上继续训练时，与该分布无关的能力会被覆盖。这不是「记忆容量不够」，而是优化动力学的必然结果——梯度只反映当前数据的需求，参数会向对当前任务最优的方向移动，哪怕这会破坏旧任务所依赖的方向。

## 二、核心原理

三种视角。参数视角：旧任务的解位于损失盆地中，新任务梯度把参数推出该盆地；对旧任务重要的参数（损失对其曲率大）被改动时代价最高，这正是 EWC 用 Fisher 信息作为重要度加权惩罚的依据。表示视角：微调改变中间层表示的几何结构，下游读出头（或后续层）依赖的方向被旋转，导致依赖这些方向的能力失效。数据视角：遗忘量与新旧分布差异及训练步数正相关，与新数据规模的关系则呈现「小数据也能造成显著遗忘」的特点，因为少量步数即可移动关键方向。缓解手段按视角对应：参数正则（EWC、L2-SP）、参数隔离（LoRA、冻结层）、数据重放（混入旧分布样本）。

## 三、数学形式

EWC 用对角 Fisher 信息近似旧任务的曲率，给出正则项：

$$\mathcal L=\mathcal L_{\text{new}}(\theta)+\frac{\lambda}{2}\sum_i F_i\big(\theta_i-\theta_i^{\text{old}}\big)^2,\qquad F_i=\mathbb E_{x\sim D_{\text{old}}}\Big[\big(\partial_{\theta_i}\log\pi_\theta(x)\big)^2\Big]$$

$F_i$ 大表示该参数对旧任务重要，应少动。L2-SP 是其 $F_i\equiv 1$ 的特例。重放的效果可理解为直接用旧数据梯度抵消漂移，等价于在联合分布上优化，通常比正则更稳但需保留数据。

## 四、代码实现

```python
import torch

def diagonal_fisher(model, dataloader, n_batches=50):
    fisher = {n: torch.zeros_like(p) for n, p in model.named_parameters() if p.requires_grad}
    for i, batch in enumerate(dataloader):
        if i >= n_batches:
            break
        model.zero_grad()
        lm_loss(model, batch).backward()
        for n, p in model.named_parameters():
            if p.grad is not None:
                fisher[n] += p.grad.detach() ** 2
    return {n: f / n_batches for n, f in fisher.items()}

def ewc_penalty(model, fisher, theta_old, lam=1.0):
    pen = 0.0
    for n, p in model.named_parameters():
        if n in fisher:
            pen = pen + (fisher[n] * (p - theta_old[n]) ** 2).sum()
    return 0.5 * lam * pen
```

## 五、与其他对比

- 相对数据重放：正则不需保留旧数据（隐私友好），但对角 Fisher 近似较粗；重放效果通常更好。
- 相对参数隔离（LoRA）：隔离从结构上限制改动范围，最省事，但表达能力受限于秩。
- 与 微调破坏安全对齐：安全退化是遗忘的一个特例，缓解手段完全通用。

## 六、常见误区

- 认为只训练少量步数就不会遗忘。少量步数即可移动关键方向，必须实测而非假设。
- 把学习率调小当作唯一手段。小学习率延缓遗忘但同时拖慢新任务收敛，性价比低于重放。
- 用同一份数据同时算 Fisher 与做训练。Fisher 应在旧任务分布上估计，否则失去意义。

## 八、面试题

- EWC 的核心思想？答：用 Fisher 信息衡量参数对旧任务的重要度，对重要参数的改动施加更强的二次惩罚。
- 为什么少量微调数据也能造成显著遗忘？答：遗忘取决于参数在关键方向上的位移量，少量步数即可完成该位移，与数据规模不成正比。

## 九、演进

观察到微调后旧能力下降 → 参数正则（EWC / L2-SP） → 数据重放 → 参数隔离（低秩与冻结） → 权重空间合并与插值。

## 十、小结

遗忘是优化动力学的自然结果；治理要在参数（正则/隔离）与数据（重放）两侧同时下手，并以实测遗忘量而非直觉来定强度。
