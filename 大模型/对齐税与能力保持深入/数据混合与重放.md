# 数据混合与重放

> 对应 Ouyang et al., NeurIPS 2022（PPO-ptx 混入预训练梯度）；Luo et al., 2023（持续微调中的遗忘实证）。

## 一、背景与挑战

在缓解对齐税的所有手段里，数据混合最直接也最可靠：既然遗忘源于旧分布没有梯度，那就把旧分布的样本按比例混回训练。难点在于配比——混太少无效，混太多挤占对齐数据、拖慢收敛，且不同能力对配比的敏感度差异很大。

## 二、核心原理

三个设计维度。混什么：预训练语料（保通用语言能力与知识）、通用指令数据（保指令跟随广度）、专项能力数据（保代码、数学等易退化能力）、安全数据（保拒答边界）。混多少：按能力监控结果反推，通常从小比例起步并按遗忘量上调；不同能力的临界比例不同，需分别扫描。怎么混：批内混合（每批都含旧样本，梯度方向持续被约束，最稳）优于阶段交替（先对齐后复习，容易反复震荡）。此外要注意重放数据的质量与去重——重复样本会造成过拟合并浪费预算。工程上建议把配比当作一组可搜索超参，与 $\beta$ 一起纳入扫描，因为二者共同决定取舍点。

## 三、数学形式

混合训练目标为加权多任务损失：

$$\mathcal L(\theta)=\sum_{k} w_k\,\mathbb E_{x\sim D_k}\big[\ell_k(\theta;x)\big],\qquad \sum_k w_k=1$$

其中 $D_k$ 分别为偏好数据、预训练语料、通用指令、专项能力与安全数据。若目标是在能力损失不超过 $\eta$ 的前提下最大化对齐收益，可写成约束优化

$$\max_{w}\ \ \mathrm{Align}(w)\quad\text{s.t.}\quad \mathrm{Tax}(w)\le\eta,\ \ w\ge 0,\ \sum_k w_k=1$$

实践中用小规模网格或贝叶斯搜索在少量步数上代理评估后外推。

## 四、代码实现

```python
import random

def mixed_loader(sources, weights, batch_size=32):
    # 批内混合：每个 batch 按权重从各来源采样，保证梯度持续覆盖旧分布
    keys = list(sources.keys())
    probs = [weights[k] for k in keys]
    while True:
        batch = {k: [] for k in keys}
        for _ in range(batch_size):
            k = random.choices(keys, weights=probs, k=1)[0]
            batch[k].append(next(sources[k]))
        yield {k: v for k, v in batch.items() if v}

def mixed_loss(model, batch, loss_fns, weights):
    total = 0.0
    logs = {}
    for k, items in batch.items():
        l = loss_fns[k](model, items)
        total = total + weights[k] * l
        logs[k] = float(l.detach())
    return total, logs
```

## 五、与其他对比

- 相对 KL 锚定：KL 限制偏移幅度（可能同时限制收益），重放只约束能力方向，对对齐收益的损害更小。
- 相对 EWC 类正则：重放效果通常更好，但需保留旧数据，存在存储与合规成本。
- 与 微调破坏安全对齐：安全重放是本节方法在安全维度的直接应用。

## 六、常见误区

- 用同一个配比应对所有能力。代码与数学等能力对配比更敏感，需单独扫描。
- 重放数据不去重、不控质量，导致模型在少量重复样本上过拟合。
- 只在训练末期加一轮复习。遗忘发生在全程，末期补救效果远逊于批内混合。

## 八、面试题

- 为什么批内混合优于阶段交替？答：批内混合让旧分布梯度在全程持续约束参数方向，阶段交替会在两个目标间来回移动、易震荡且末期补救有限。
- 混合配比如何确定？答：按能力监控结果反推，从小比例起步、分能力扫描，并与 KL 系数联合搜索。

## 九、演进

只用对齐数据 → 末期加复习 → 批内混合预训练梯度（PPO-ptx） → 多来源加权配比搜索 → 与 KL 预算联合优化的取舍点选择。

## 十、小结

数据混合是对齐税最直接的解药：混什么、混多少、怎么混三件事定好，能力保持就从祈祷变成可调参数。
