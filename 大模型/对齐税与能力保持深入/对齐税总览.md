# 对齐税总览

> 对应 Ouyang et al., *InstructGPT*, NeurIPS 2022（alignment tax 与 PPO-ptx）；Askell et al., *A General Language Assistant as a Laboratory for Alignment*, 2021。

## 一、背景与挑战

对齐会让模型更听话、更安全，但也常伴随通用能力下降：少样本任务分数回落、知识型问答变差、生成多样性收窄。InstructGPT 论文把这种代价称为对齐税（alignment tax），并给出了缓解手段——在 PPO 目标里混入预训练梯度（PPO-ptx）。理解对齐税的来源与测量方式，是判断一次对齐是否真正划算的前提。

## 二、核心原理

对齐税的三个来源。第一是分布收窄：偏好优化把概率质量集中到少数「符合偏好」的模式上，多样性与长尾知识的可达性下降。第二是灾难性遗忘：SFT 与偏好优化的数据分布远窄于预训练分布，与对齐目标无关的能力得不到梯度支持而退化。第三是目标冲突：安全与有用在部分输入上直接对立（如敏感但合法的医疗、法律咨询），任何取舍都会在某一侧记账。对应的缓解手段是数据混合与重放、KL 或参数空间锚定、以及模型合并（把对齐模型与基座在权重空间插值）。关键是先测准再优化——很多「对齐税」实际是评测提示格式变化造成的假象。

## 三、数学形式

把对齐税定义为能力基准上的净损失：

$$\mathrm{Tax}=\frac{1}{|\mathcal B|}\sum_{b\in\mathcal B}\frac{S_b(\theta_{\text{base}})-S_b(\theta_{\text{aligned}})}{S_b(\theta_{\text{base}})}$$

其中 $\mathcal B$ 为能力基准集合。带缓解项的训练目标可写为

$$\max_\theta\ \mathbb E\big[r_\phi(x,y)\big]-\beta\,\mathrm{KL}\big(\pi_\theta\|\pi_{ref}\big)+\gamma\,\mathbb E_{x\sim D_{\text{pretrain}}}\big[\log\pi_\theta(x)\big]$$

最后一项即 PPO-ptx 的预训练梯度混合，$\gamma$ 控制能力保持强度，与 $\beta$ 共同决定对齐—能力的取舍点。

## 四、代码实现

```python
def ppo_ptx_step(policy, ref, batch_pref, batch_pretrain, rm, beta=0.02, gamma=27.0):
    # 说明性代码：偏好目标 + KL 惩罚 + 预训练语言建模项
    y = policy.generate(batch_pref["prompt"])
    reward = rm(batch_pref["prompt"], y)
    kl = seq_logp(policy, y) - seq_logp(ref, y)
    rl_obj = (reward - beta * kl).mean()

    lm_obj = -lm_loss(policy, batch_pretrain)         # 预训练语料上的对数似然
    loss = -(rl_obj + gamma * lm_obj)
    loss.backward()
    return {"reward": reward.mean().item(), "kl": kl.mean().item(), "lm": lm_obj.item()}
```

## 五、与其他对比

- 与 奖励模型过优化与奖励黑客深入：过优化常与对齐税同时发生，需在同一批检查点上联合测量。
- 与 微调破坏安全对齐：机制互为镜像——一个是任务微调抹掉安全，一个是对齐抹掉通用能力。
- 与 模型行为可预测性深入：对齐税必须通过规格中的能力条目来监控。

## 六、常见误区

- 用对齐后的对话格式去评基座模型（或反之），把提示格式差异误算成对齐税。
- 只测通用基准不测生成多样性。分布收窄在标准基准上常不可见，却直接影响创作类体验。
- 认为对齐税不可避免因而不测。数据混合与模型合并能显著降低它，前提是先有测量。

## 八、面试题

- 什么是对齐税，来源有哪些？答：对齐带来的通用能力损失，来源为分布收窄、灾难性遗忘与安全—有用目标冲突。
- PPO-ptx 如何缓解对齐税？答：在强化目标中混入预训练语料的语言建模梯度，为通用能力提供持续梯度支持。

## 九、演进

发现对齐后能力回落 → 混入预训练梯度（PPO-ptx） → 数据混合与重放系统化 → 模型合并与权重插值 → 把能力保持写入放行规格。

## 十、小结

对齐税是可测、可缓解的工程量而非宿命；先用统一提示格式测准，再用数据混合与权重插值把它压到可接受区间。
