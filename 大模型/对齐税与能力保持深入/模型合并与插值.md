# 模型合并与插值

> 对应 Wortsman et al., *Model Soups*, ICML 2022；Ilharco et al., *Editing Models with Task Arithmetic*, ICLR 2023；Lin et al., *Mitigating the Alignment Tax of RLHF*, EMNLP 2024。

## 一、背景与挑战

前面的手段都要在训练时决定取舍点，一旦训完就固定了。模型合并提供了训练后的调节能力：在权重空间把对齐模型与基座（或多个专家模型）插值，得到一条连续的取舍曲线，无需重新训练即可选择对齐强度与能力保持的平衡点。

## 二、核心原理

基础观察是线性模式连通性：由同一预训练权重出发微调得到的模型，在权重空间常处于同一损失盆地，直接线性插值不会破坏功能，且插值点往往同时保留两侧的部分特性。由此衍生三种做法。权重平均（soup）：把多个微调模型简单平均，提升鲁棒性与泛化。线性插值：$\theta(\alpha)=(1-\alpha)\theta_{\text{base}}+\alpha\theta_{\text{aligned}}$，$\alpha$ 就是对齐强度旋钮，扫描 $\alpha$ 可画出「对齐收益—能力损失」帕累托前沿。任务算术：把微调增量视为任务向量 $\tau=\theta_{\text{ft}}-\theta_{\text{base}}$，通过加减组合多个能力（如 $\theta_{\text{base}}+\tau_{\text{align}}+\lambda\tau_{\text{code}}$）。前提条件必须强调：所有参与合并的模型须来自同一预训练初始化且结构一致，否则插值无意义。

## 三、数学形式

线性插值与任务算术：

$$\theta(\alpha)=(1-\alpha)\,\theta_{\text{base}}+\alpha\,\theta_{\text{aligned}}=\theta_{\text{base}}+\alpha\,\tau_{\text{align}},\qquad \tau_{\text{align}}=\theta_{\text{aligned}}-\theta_{\text{base}}$$

多任务合并为 $\theta=\theta_{\text{base}}+\sum_k\lambda_k\tau_k$。选择 $\alpha$ 的准则是在能力约束下最大化对齐分：

$$\alpha^\star=\arg\max_\alpha\ \Big\{\mathrm{Align}\big(\theta(\alpha)\big)\ \ \text{s.t.}\ \ \mathrm{Tax}\big(\theta(\alpha)\big)\le\eta\Big\}$$

由于只需前向评测，扫描成本远低于重训。

## 四、代码实现

```python
import torch

def interpolate(state_base, state_aligned, alpha=0.7):
    # 要求两者来自同一预训练初始化且结构一致
    return {k: (1 - alpha) * state_base[k].float() + alpha * state_aligned[k].float()
            for k in state_base}

def task_arithmetic(state_base, task_vectors, coeffs):
    out = {k: v.float().clone() for k, v in state_base.items()}
    for tau, c in zip(task_vectors, coeffs):
        for k in out:
            out[k] += c * tau[k].float()
    return out

def sweep_alpha(state_base, state_aligned, load_fn, eval_align, eval_capability, eta=0.03):
    best = None
    for a in [i / 10 for i in range(11)]:
        m = load_fn(interpolate(state_base, state_aligned, a))
        tax = eval_capability(m)          # 相对基座的能力损失比例
        if tax <= eta:
            score = eval_align(m)
            if best is None or score > best[1]:
                best = (a, score, tax)
    return best                            # (最优 alpha, 对齐分, 能力损失)
```

## 五、与其他对比

- 相对 KL 锚定与数据混合：那两者需在训练时决定取舍，合并可在训练后连续调节，成本极低。
- 相对多目标训练：合并不需要重新训练，但只能在已有模型的连线上取点，表达能力受限。
- 与 微调破坏安全对齐：把安全对齐模型与任务微调模型合并，是恢复安全性的常用低成本手段。

## 六、常见误区

- 合并来自不同预训练初始化的模型。权重不在同一盆地，插值通常直接失效。
- 只看对齐分选 $\alpha$。必须同时报告能力损失，否则等于把旋钮拧回未对齐状态或牺牲能力。
- 忽略非权重状态（分词器、嵌入尺寸、归一化统计量）的一致性，导致合并后行为异常。

## 八、面试题

- 为什么线性插值两个微调模型常常有效？答：同一预训练初始化出发的微调模型通常位于同一损失盆地，具有线性模式连通性，插值点仍是可用解。
- 任务算术如何组合能力？答：把微调增量视为任务向量，按系数加减到基座权重上，实现能力的组合与移除。

## 九、演进

单模型微调 → 多模型权重平均（soup） → 任务向量与任务算术 → 用插值扫描对齐—能力帕累托前沿 → 结构化合并（分层/分模块系数）。

## 十、小结

模型合并把对齐强度变成一个训练后可调的连续旋钮，是缓解对齐税性价比最高的手段，前提是同源初始化与双指标扫描。
