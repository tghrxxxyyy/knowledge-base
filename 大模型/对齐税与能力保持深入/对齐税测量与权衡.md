# 对齐税测量与权衡

> 对应 Ouyang et al., NeurIPS 2022；Askell et al., 2021（HHH 权衡）；Gao et al., ICML 2023（沿 KL 轴的联合评测）。

## 一、背景与挑战

对齐税之所以常被误报，是因为测量过程有大量陷阱：提示格式不统一、评测样本量不足、只测单一维度、检查点选择不当。测不准的结果是决策失真——要么高估代价而不敢对齐，要么低估代价而上线后能力回退被用户发现。

## 二、核心原理

一套可信的测量需要满足五条。第一，格式统一：基座与对齐模型用同一提示模板与同一解码参数评测，或对两者各自最优模板都报告，避免格式差异被算成能力差异。第二，维度完整：通用知识、推理、代码、长文本、生成多样性、校准，逐项报告；只测一两个基准会漏掉主要退化面。第三，沿 KL 轴联合评测：把对齐收益与能力损失画在同一横轴（KL 或插值系数）上，得到帕累托前沿而非孤立两点。第四，样本量与置信区间：按目标分辨率反推样本量，报告区间而非点值。第五，检查点密集打点：对齐收益与能力损失的最优点通常不在同一步，需要用前沿曲线选点。

## 三、数学形式

定义沿偏移轴的联合评价：设 $d$ 为偏移度量（$\sqrt{\mathrm{KL}}$ 或插值系数 $\alpha$），

$$\text{Frontier}=\Big\{\big(\mathrm{Align}(d),\ \mathrm{Tax}(d)\big)\ :\ d\in[0,d_{\max}]\Big\},\qquad \mathrm{Tax}(d)=\frac{1}{|\mathcal B|}\sum_{b}\frac{S_b(0)-S_b(d)}{S_b(0)}$$

选点准则可用带权效用 $\mathcal U(d)=\mathrm{Align}(d)-\kappa\,\mathrm{Tax}(d)$，$\kappa$ 由业务对能力回退的容忍度决定；也可用硬约束形式 $\max_d \mathrm{Align}(d)$ s.t. $\mathrm{Tax}(d)\le\eta$。

## 四、代码实现

```python
import numpy as np

BENCHES = ("knowledge", "reasoning", "code", "long_ctx", "diversity", "calibration")

def measure_tax(base_scores, aligned_scores):
    rel = {b: (base_scores[b] - aligned_scores[b]) / max(base_scores[b], 1e-9) for b in BENCHES}
    return {"per_bench": rel, "tax": float(np.mean(list(rel.values()))),
            "worst_bench": max(rel, key=rel.get)}

def pareto_frontier(points, kappa=1.0, eta=None):
    # points: [(d, align_score, tax)]
    feasible = [p for p in points if (eta is None or p[2] <= eta)]
    if not feasible:
        return None
    return max(feasible, key=lambda p: p[1] - kappa * p[2])

def required_n(p_hat=0.5, half_width=0.015, z=1.96):
    return int(np.ceil(z ** 2 * p_hat * (1 - p_hat) / half_width ** 2))
```

## 五、与其他对比

- 与 过优化缩放律：同样沿 KL 轴组织评测，一个纵轴是金标奖励，一个纵轴是能力损失，应同图对照。
- 与 行为规格与评估：对齐税的阈值应写入放行规格的能力条目。
- 与 模型合并与插值：插值系数提供了最廉价的偏移轴，适合快速画前沿。

## 六、常见误区

- 用对齐模型的对话模板去评基座。这是最常见的高估来源，能造成数个百分点的假性差异。
- 只报平均对齐税。应报最差维度，因为用户感知由最明显的退化决定。
- 只比训练前后两点。没有前沿曲线就无法知道是否存在更好的取舍点。

## 八、面试题

- 测量对齐税最容易出错的地方？答：基座与对齐模型使用了不同提示模板与解码参数，导致格式差异被误算为能力差异。
- 为什么要沿 KL 轴画前沿？答：对齐收益与能力损失的最优取舍点需要在连续偏移轴上选择，孤立两点无法判断是否存在更优检查点或插值系数。

## 九、演进

训练前后两点对比 → 多维基准逐项报告 → 沿 KL 轴/插值轴画帕累托前沿 → 置信区间与硬约束选点 → 纳入发布规格与线上监控。

## 十、小结

对齐税的价值全在测得准：统一格式、覆盖多维、沿偏移轴画前沿、用置信区间选点，才能把对齐做成可控的工程权衡。
