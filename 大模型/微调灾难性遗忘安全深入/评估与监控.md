# 微调遗忘评估与监控

> 对应 Luo et al., 2023；Yildiz et al., *Instability in RLHF*, 2024。

## 一、背景与挑战

需量化微调前后能力与安全变化，及时止损。

## 二、核心原理

在保留集测旧任务准确率与安全率，画学习曲线；越界触发早停或回退。

## 三、数学形式

监控 $\Delta = metric_{post}-metric_{pre}$；$|\Delta|>\delta$ 报警。

## 四、代码实现

```python
if abs(post - pre) > delta:
    alert()
```

## 五、与其他对比

- 与安全能力权衡深入共享评估。
- 与灾难性遗忘总览共享监控。

## 六、常见误区

- 只测任务漏安全。
- 监控滞后未早停。
