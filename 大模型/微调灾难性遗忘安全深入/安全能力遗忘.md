# 安全对齐的遗忘

> 对应 Qi et al., *Fine-tuning Aligned LLMs Compromises Safety*, 2023；Yang et al., *Shadow Alignment*, 2024。

## 一、背景与挑战

仅几百条无害数据微调就可使安全拒绝率骤降，对齐被轻易攻破。

## 二、核心原理

安全是稀疏低概率行为，微调分布若无有害样本则拒绝被冲淡；称为对齐税被擦除。

## 三、数学形式

安全率衰减 $\approx \exp(-\alpha\cdot n_{ft}/n_{safe})$，少量有害占比即大幅降。

## 四、代码实现

```python
if safety_rate(pi_new) < base * 0.9:
    rollback()
```

## 六、常见误区

- 以为无害任务微调也安全。
