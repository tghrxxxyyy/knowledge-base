# 参数高效微调缓解遗忘

> 对应 Hu et al., *LoRA*, 2021；He et al., *Towards Living LLMs*, 2023。

## 一、背景与挑战

全参微调改所有权重更易忘；PEFT 只调增量，保留底座知识。

## 二、核心原理

LoRA 等只训低秩增量 $\Delta W=BA$，底座冻结，新任务与旧知识解耦，遗忘显著降低。

## 三、数学形式

$h=W_0 x+\Delta W x$，其中 $\Delta W=BA$ 且 $rank(B),rank(A)\ll d$。

## 四、代码实现

```python
lora = LoRA(model, r=8)
out = lora(x)
```

## 五、与其他对比

- 与正则与回放共享保旧。
- 与安全能力遗忘共享少样本安全。

## 六、常见误区

- 秩过大退化为全参。
- 多适配器冲突未路由。
