# 正则与回放缓解

> 对应 Kirkpatrick et al., 2017（EWC）；Luo et al., 2023（回放）。

## 一、背景与挑战

如何在不重训全量旧数据下保住旧能力与安全。

## 二、核心原理

EWC 用 Fisher 信息保重要权重；经验回放混合旧样本；知识蒸馏用旧模型软标签约束新模型。

## 三、数学形式

EWC 正则 $\mathcal L_{ewc}=\frac{\lambda}{2}\sum_i F_i(\theta_i-\theta_i^*)^2$ 保重要参数。

## 四、代码实现

```python
reg = lam * (F * (theta - theta_star) ** 2).sum()
```

## 五、与其他对比

- 与参数高效缓解共享保旧。
- 与灾难性遗忘总览共享方法。

## 六、常见误区

- Fisher 用旧数据近似误差大。
- 回放比例不当仍忘。
