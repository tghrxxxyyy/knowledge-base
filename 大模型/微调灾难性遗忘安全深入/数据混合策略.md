# 安全数据混合策略

> 对应 Qi et al., 2023；Ouyang et al., 2022（混合偏好）。

## 一、背景与挑战

下游微调需掺入安全/对齐数据以防退化，比例与来源是关键。

## 二、核心原理

在微调集混入拒绝样本、安全 SFT、原分布回放；比例按遗忘敏感度和任务量调。

## 三、数学形式

混合分布 $p_{mix}=\gamma p_{task}+(1-\gamma)p_{safe}$；$\gamma$ 控遗忘/专精。

## 四、代码实现

```python
mix = concat(task_ds, safe_ds.sample(int(gamma * len(task_ds))))
```

## 五、与其他对比

- 与正则与回放共享保旧。
- 与安全能力遗忘共享混合。

## 六、常见误区

- 安全数据太少无效。
- 太多损任务专精。

## 八、面试题

- 如何定安全混合比？答：按遗忘敏感度与任务量调 $\gamma$，验安全率。

## 九、演进

纯任务 → 固定混合 → 自适应混合。

## 十、小结

数据混合是防遗忘最简单有效杠杆。
