# 幻觉检测与缓解

> 对应 llm-course「Hallucination」、Maynez et al. (2020) 幻觉分类、Manakul et al., *SelfCheckGPT*, 2023，以及 RAG（Lewis et al., 2020）事实性研究。

## 一、背景与挑战

「幻觉（hallucination）」指模型生成看似流畅合理、却与事实或给定上下文不符的内容。它破坏可信度，是医疗、法律、金融等高风险场景落地的头号障碍。幻觉分两类：**事实性幻觉**（与真实世界知识冲突）与**忠实性幻觉**（与所提供的上下文/指令冲突，即「没读懂」）。

核心挑战：① 检测需要外部事实来源，成本与覆盖难兼顾；② 缓解可能牺牲流畅度或创造力；③ 自回归生成本质上「逐词最大化似然」，倾向于生成高概率但未必真实的表述。

## 二、核心原理

**检测**路径：

- **事实一致性检查（Faithfulness）**：将生成内容与检索证据逐项比对，判断是否有「无依据陈述」。
- **SelfCheckGPT**：利用幻觉的「随机性」——同一问题多次采样，若某陈述在各样本中不稳定，则更可能是编造；对一致性低的句子标记风险。
- **外部验证**：用知识图谱、搜索引擎或事实库核对实体/关系。

**缓解**路径按阶段分：

- 生成前：RAG 注入检索证据、提供溯源。
- 生成中：约束解码（如强制引用、受限词表）、事实性奖励对齐。
- 生成后：自检（self-reflection）、后处理核查、引用标注。

## 三、形式化与数学基础

SelfCheckGPT 用多次采样 $y^{(1)},\dots,y^{(k)}$ 估计句子 $s$ 的一致性，简化为「非一致比例」：

$$
\text{Risk}(s) = 1 - \frac{1}{k}\sum_{j=1}^{k} \mathbb{1}[s \text{ 在 } y^{(j)} \text{ 中一致成立}]
$$

事实一致性可用蕴含分数，设生成 $G$ 与证据 $E$，期望 $G$ 被 $E$ 蕴含：

$$
\text{Faith}(G,E) = \frac{1}{|G|}\sum_{s\in G} P(E \models s)
$$

RAG 把生成条件从纯先验 $P(y|x)$ 改为证据条件概率 $P(y|x,e)$，降低偏离事实的先验主导。

## 四、代码实现

SelfCheckGPT 思路示意（多次采样 + 一致性打分）：

```python
from transformers import pipeline

gen = pipeline("text-generation", model="meta-llama/Llama-3-8B")
prompt = "请说明量子纠缠的基本原理。"
samples = [gen(prompt, max_new_tokens=200, do_sample=True,
              temperature=1.0)["generated_text"] for _ in range(5)]

# 用 LLM 裁判比对各样本中同一事实陈述的一致性（示意）
def consistency(statement, samples):
    agree = sum(judge(statement, s) for s in samples)
    return agree / len(samples)     # 低一致性 => 高幻觉风险

risky = [s for s in extract_statements(samples[0]) if consistency(s, samples) < 0.6]
print("疑似幻觉陈述:", risky)
```

## 五、与其他技术对比

| 方法 | 阶段 | 成本 | 局限 |
|------|------|------|------|
| RAG | 生成前 | 中（检索） | 依赖检索质量，不能消除全部 |
| Faithfulness 约束 | 生成中 | 高 | 影响流畅 |
| SelfCheckGPT | 生成后 | 高（多采样） | 慢 |
| 外部验证 | 生成后 | 取决于源 | 覆盖有限 |

## 六、常见误区

- 「RAG 能完全消除幻觉」：不能，检索缺失/错误或模型忽略证据仍会编造。
- 「流畅 = 真实」：高置信表述可能完全虚构。
- 「检测只需一次生成」：SelfCheckGPT 证明需多次采样看稳定性。
- 「对齐后就不会幻觉」：有用性对齐不保证事实正确性。

## 九、演进与趋势

检测从「人工抽样」走向「自动化一致性 + 检索比对 + 事实库校验」；缓解从「后处理核查」前移到「训练阶段事实性对齐」（如事实性奖励、RAFT）。RAG 成为生产标配，并发展出「带引用的生成（citation generation）」「自我反思 + 检索修正」闭环。未来重点在可验证生成（verifiable generation）与幻觉度量的标准化。

## 十、小结

幻觉是生成式模型的核心可信障碍，分事实性与忠实性两类。检测靠一致性（SelfCheckGPT）与事实比对，缓解靠 RAG、对齐约束与后处理核查，但均无法 100% 消除。具体方法、数据集与最新进展以 RAG、SelfCheckGPT 等论文及 llm-course 为准。
