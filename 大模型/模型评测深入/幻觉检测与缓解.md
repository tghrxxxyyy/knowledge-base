# 幻觉检测与缓解

> 对应 llm-course 与事实性研究(SelfCheckGPT 等)。

## 一、核心概念

幻觉 = 模型生成看似合理但事实错误的内容。检测：

- **事实一致性检查**：与检索证据比对(Faithfulness)。
- **SelfCheckGPT**：多次采样看陈述一致性。
- **外部验证**：知识图谱/搜索引擎核对。

缓解：RAG(溯源)、对齐(减少编造)、解码约束、后处理核查。

## 二、关键要点

| 方法 | 阶段 |
|------|------|
| RAG | 生成前 |
| Faithfulness 约束 | 生成中 |
| 自检/核查 | 生成后 |

## 三、面试题

- RAG 为何能缓解幻觉？它能否完全消除？
