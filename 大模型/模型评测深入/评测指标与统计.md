# 评测指标与统计

> 对应 llm-course「Evaluation」、HELM 评测方法论，以及经典 NLP 指标（ROUGE、BLEU、BERTScore）文献。

## 一、背景与挑战

「模型 A 比 B 好」不是一个简单断言，而是一个统计结论。大模型输出是随机采样生成，单次运行、单点指标极易受采样随机性与 prompt 措辞影响，产生误导。工程落地时还需区分「质量指标」与「成本/时延指标」。核心挑战：① 不同任务适用不同指标；② 生成任务缺乏唯一标准答案；③ 单次分数方差大，需统计显著性与置信区间支撑结论。

## 二、核心原理

评测指标分三类：

- **精确匹配类**：EM（Exact Match）、准确率，适用于有标准答案的问答/分类。
- **重叠度类**：ROUGE（面向召回的 n-gram 重叠，摘要常用）、BLEU（面向精度的 n-gram 重叠，翻译常用），把生成文本与参考文本做 n-gram 比对。
- **语义相似类**：BERTScore 用预训练表示计算词级余弦相似再聚合，比 n-gram 更贴近语义。

对生成式任务，常用「多次采样取最好」的 pass@k，或「LLM-as-judge」给整体打分（见相关章节）。

## 三、形式化与数学基础

ROUGE-L 基于最长公共子序列（LCS）的召回：

$$
\text{ROUGE-L} = \frac{(1+\beta^2)R_{\text{lcs}}P_{\text{lcs}}}{R_{\text{lcs}}+\beta^2 P_{\text{lcs}}},\quad
R_{\text{lcs}}=\frac{\text{LCS}(X,Y)}{|Y|},\; P_{\text{lcs}}=\frac{\text{LCS}(X,Y)}{|X|}
$$

BLEU 取 n-gram 精度几何平均再乘简短惩罚 $BP$：

$$
\text{BLEU} = BP\cdot \exp\!\Big(\sum_{n=1}^{N} w_n \log p_n\Big),\quad
BP=\begin{cases}1 & c>r\\ e^{(1-r/c)} & c\le r\end{cases}
$$

置信区间（多次运行均值 $\bar{x}$、标准差 $s$、样本 $m$）：

$$
\bar{x} \pm t_{m-1,0.975}\frac{s}{\sqrt{m}}
$$

两模型差异是否显著，可用配对 Bootstrap 或 McNemar 检验。

## 四、代码实现

用 `evaluate` / `rouge` 计算生成指标：

```python
from rouge_score import rouge_scorer
scorer = rouge_scorer.RougeScorer(["rouge1","rougeL"], use_stemmer=True)
score = scorer.score(reference="深度学习很有用", prediction="深度学习非常有用")
print(score["rougeL"].fmeasure)

# BERTScore 示例
from bert_score import score as bert_score
P, R, F = bert_score([pred], [ref], lang="zh", verbose=False)
print(F.mean().item())
```

## 五、与其他技术对比

| 指标 | 适用 | 优点 | 局限 |
|------|------|------|------|
| EM/Acc | 有标准答案 | 客观 | 无法处理多解 |
| ROUGE/BLEU | 摘要/翻译 | 快、可复现 | 仅 n-gram 重叠，忽略语义 |
| BERTScore | 语义相似 | 语义感知 | 受编码模型偏见影响 |
| LLM-as-judge | 开放生成 | 贴近人类 | 有偏好偏差、成本 |

## 六、常见误区

- 「ROUGE 高等于摘要质量好」：ROUGE 只是词面重叠的弱代理，可能 reward 套话。
- 「一次跑分即可下结论」：采样随机性大，需多次运行 + 置信区间。
- 「BLEU 越高翻译越好」：BLEU 与人工评分相关性有限，且对句式变化不敏感。
- 「单指标足够」：生成任务应多指标 + 人工/裁判结合。

## 九、演进与趋势

指标正从「词面重叠」转向「语义/质量感知」：BERTScore、UNIEval、以及 LLM-as-judge 成为主流；同时强调「统计严谨性」（多次采样、置信区间、bootstrap 显著性）。成本指标（时延、吞吐、token 单价）也被纳入综合评估，与质量指标并列报告。

## 十、小结

评测指标是结论的统计基础：有标准答案用 EM/Acc，生成任务用 ROUGE/BLEU 作快速代理、BERTScore 补语义、LLM 裁判补整体，但都需配合多次采样与置信区间。选指标须与任务匹配，避免单点分数误导。具体实现与最新基准以 HELM、llm-course 及官方库为准。
