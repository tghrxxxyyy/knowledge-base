# 代码能力评测

> 对应 HumanEval / MBPP / LiveCodeBench。

## 一、核心概念

代码评测用「问题→函数签名→多测试用例通过率(pass@k)」衡量。关键：

- **pass@k**：k 次采样至少一次全通过。
- **测试泄漏**：LiveCodeBench 用「竞赛后题」防污染。
- **执行验证**：需 sandbox 运行。

## 二、关键要点

| 指标 | 含义 |
|------|------|
| pass@1 | 一次通过率 |
| pass@k | k 次任一过 |
| 执行率 | 可运行比例 |

## 三、面试题

- 为什么代码评测要 pass@k 而非 pass@1？
