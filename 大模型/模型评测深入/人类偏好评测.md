# 人类偏好评测

> 对应 Ouyang et al., *InstructGPT / RLHF*, 2022；以及 Christiano et al., *Deep RL from Human Preferences*, 2017；Anthropic HH-RLHF 数据集。

## 一、背景与挑战

模型「能力」不等于「人们想要的输出」。两个回答可能都正确，但一个冗长啰嗦、一个简洁贴心，人类明显偏好后者。人类偏好评测正是把「有用、无害、诚实」等主观期望转为可量化信号的过程。它既是 RLHF 中奖励模型（Reward Model）的训练数据来源，也是模型上线前的最终校验。

核心挑战：① 标注者间一致性（inter-annotator agreement）低，主观分歧大；② 文化/群体偏见使「平均偏好」未必普适；③ 标注者疲劳导致质量下降；④ 标注成本高、难规模化。

## 二、核心原理

偏好评测通常呈现同一 prompt 的两个（或更多）回答 $y_A, y_B$，由标注者选择「更优者」，并可选多维度评价：

- **Helpfulness（有用性）**：是否切题、信息充分、可执行。
- **Harmlessness（无害性）**：是否安全、不诱导有害行为。
- **Honesty（诚实性）**：是否真实、不编造、恰当表达不确定。

得到成对偏好数据 $(x, y_w, y_l)$（w=winner, l=loser），用于训练奖励模型（见 RLHF 相关章节），或直接计算「胜率」评估模型。

## 三、形式化与数学基础

奖励模型以 Bradley-Terry 模型拟合人类偏好，对回答 $y_w$（胜）与 $y_l$（负）最大化：

$$
\mathcal{L}_{RM} = -\mathbb{E}_{(x,y_w,y_l)}\big[\log \sigma\big(r_\phi(x,y_w)-r_\phi(x,y_l)\big)\big]
$$

其中 $r_\phi$ 为奖励模型打分，$\sigma$ 为 sigmoid。模型间比较用胜率：

$$
\text{WinRate}(A\text{ vs }B) = \frac{1}{N}\sum_{i=1}^{N}\mathbb{1}[A_i \succ B_i]
$$

多维度需分别评分或加权合成综合偏好。

## 四、代码实现

基于成对偏好计算模型胜率（示意）：

```python
import pandas as pd

df = pd.read_csv("prefs.csv")   # 列: model_a, model_b, winner
def rate(a, b):
    sub = df[(df.model_a==a)&(df.model_b==b)]
    n = len(sub)
    if n == 0: return None
    wins = (sub.winner == "A").sum()
    return wins / n

print("A 对 B 胜率:", rate("modelA", "modelB"))
```

## 五、与其他技术对比

| 评测方式 | 信号来源 | 优点 | 局限 |
|----------|----------|------|------|
| 人类偏好 | 人 | 贴近真实期望 | 贵、慢、有偏 |
| 自动指标 | 规则/模型 | 快、可复现 | 弱代理 |
| LLM 裁判 | 强模型 | 规模化 | 模拟人而非真人 |

## 六、常见误区

- 「单一总分足够」：不同维度（有用/无害/诚实）常冲突，需分开评。
- 「多数偏好即正确」：存在从众、位置/长度偏见，需盲评与校准。
- 「标注者一致即可信」：一致可能源于共同偏见，仍需多样性样本。
- 「偏好可完全自动化」：LLM 裁判只能近似，关键决策仍需人工。

## 九、演进与趋势

从「成对标注 + RLHF」走向「多维度细标 + 红队安全标注」；为降成本，Anthropic 提出 Constitutional AI（用原则 + AI 反馈 RLAIF 减少人类标注）；偏好数据也用于直接对齐（DPO 等，无需显式奖励模型）。同时强调标注者多样性、盲评与偏差审计，提升偏好信号的代表性与公平性。

## 十、小结

人类偏好评测把主观期望转为可量化信号，是 RLHF/对齐的核心数据来源与上线校验。其难点在标注一致性、偏见与成本，需多维度、盲评与校准。最新方法（HH-RLHF、Constitutional AI、DPO）以官方论文与数据集为准。
