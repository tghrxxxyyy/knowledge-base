# 基准数据集综述

> 主流英文/中文基准速查。

## 一、核心概念

| 基准 | 衡量 | 规模 |
|------|------|------|
| MMLU | 多任务知识(57学科) | 14k+ |
| GSM8K | 小学数学推理 | 8.5k |
| HumanEval | 代码生成 | 164 |
| TruthfulQA | 真实性 | 817 |
| HellaSwag | 常识推理 | 10k |
| BBH | 硬 BIG-Bench | 6.5k |
| C-Eval/CMMLU | 中文知识 | 13k/11k |
| MATH | 竞赛数学 | 12k |

## 二、关键要点

- 开源基准易泄露进训练集，需关注「 contamination 」。
- 中文需本地化基准(C-Eval)。
