# 自动化评测框架

> 对应 llm-course 与开源评测工具。

## 一、核心概念

自动化评测流程：加载模型/API → 跑基准 → 解析输出 → 计算指标(精确匹配/ROUGE/BERTScore/LLM裁判)。常用：EleutherAI lm-evaluation-harness、OpenCompass、HELM。

## 二、代码实现（harness 示意）

```bash
# lm-eval
python -m lm_eval --model hf --model_args pretrained=model \
  --tasks gsm8k,mmlu --device cuda:0
```

## 三、关键要点

- 输出需结构化解析(extract answer)再比对。
- LLM 裁判需固定 rubric。
