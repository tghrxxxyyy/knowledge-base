# 注意力复杂度与优化

> 对应 d2l-zh 与 Efficient Transformers 综述(Tay et al., 2022)。

## 一、核心概念

标准自注意力复杂度 `O(n²·d)`（`n` 序列长度）。长序列下内存与计算爆炸，催生大量高效注意力变体：

| 方法 | 复杂度 | 思路 |
|------|--------|------|
| 全注意力 | O(n²) | 精确 |
| 稀疏(Longformer) | O(n·w) | 局部窗口+全局 |
| 线性(Performer) | O(n·d²) | 核近似 |
| 低秩(Linformer) | O(n·k) | 投影降列数 |
| FlashAttention | O(n²) 但 IO 优化 | 减少 HBM 读写 |

## 二、FlashAttention 要点

FlashAttention 不改变数学结果，而是用分块(tiling)与重计算，把中间 `n×n` 注意力矩阵留在 SRAM，大幅降低 GPU 显存带宽瓶颈，是 vLLM/LLaMA 等推理训练的事实标准。

## 三、关键要点

| 优化 | 收益 |
|------|------|
| 稀疏 | 长文档 |
| 核近似 | 线性扩展 |
| Flash | 显存/速度 |
