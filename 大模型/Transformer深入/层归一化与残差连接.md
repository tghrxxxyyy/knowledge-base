# 层归一化与残差连接

> 对应 annotated-transformer 与 d2l-zh。残差 + 归一化是训练超深 Transformer 的基石。

## 一、核心概念

- **残差连接**：`y = x + Sublayer(x)`，让梯度可直达浅层，缓解退化。
- **Post-Norm vs Pre-Norm**：原 Transformer 用 Post-Norm（`x + Sublayer(x)` 后再 LN）；现代大模型多用 **Pre-Norm**（`Sublayer(LN(x))` 再加 `x`），训练更稳定、便于深层堆叠。

```
Post-Norm: x = LN(x + Sublayer(x))
Pre-Norm : x = x + Sublayer(LN(x))
```

## 二、Pre-Norm 的优势

Pre-Norm 使每个子层输入归一化，深层网络梯度范数更平稳，是大模型(如 GPT-3、LLaMA)默认选择。代价是表达力略弱于 Post-Norm，常需更多层。

## 三、代码实现

```python
# Pre-Norm 残差块
def pre_norm_block(x, sublayer, norm):
    return x + sublayer(norm(x))
```

## 四、关键要点

| 方案 | 稳定性 | 表达力 | 使用场景 |
|------|--------|--------|----------|
| Post-Norm | 一般 | 强 | 原 Transformer |
| Pre-Norm | 强 | 略弱 | 大模型主流 |

## 五、常见误区

- annotated-transformer 原文实现用了 Post-Norm，但很多教程误标为 Pre-Norm。
- 残差相加时形状必须一致，维度变化需投影。

## 六、与开源书的对应

- annotated-transformer 注释特别指出其实现与原论文的 Pre/Post-Norm 差异：http://nlp.seas.harvard.edu/annotated-transformer/
- Xiong et al., *On Layer Normalization in the Transformer Architecture*, 2020 (证实 Pre-Norm 更稳).
