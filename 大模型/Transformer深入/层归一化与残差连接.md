# 层归一化与残差连接

> 对应 Vaswani et al. 2017 与 Xiong et al. 2020 On Layer Normalization / annotated-transformer。

## 一、背景与挑战

Transformer 可堆叠到极深，而深层网络常面临梯度消失/爆炸与训练不稳定。两件套——**残差连接**与**层归一化（LayerNorm）**——是让超深网络可训练、可收敛的基石。二者如何配合（放在残差前还是后）直接决定训练动态，也催生了 Pre-Norm 与 Post-Norm 的路线之争。

## 二、核心原理

- **残差连接**：$\mathbf{y} = \mathbf{x} + \text{Sublayer}(\mathbf{x})$。把输入直连到输出，为梯度提供「恒等通路」，缓解退化。
- **层归一化**：对单个样本的特征维做标准化（减均值除标准差再仿射），稳定每层输入分布。
- **位置组合**：
  ```
  Post-Norm: x = LN(x + Sublayer(x))
  Pre-Norm : x = x + Sublayer(LN(x))
  ```

Pre-Norm 使每个子层输入先归一化，深层梯度更平稳，是大模型默认选择；代价是表达力略弱，常靠增加层数补偿。

现代大模型常把 LayerNorm 替换为 **RMSNorm**（Root Mean Square Normalization），它去掉了均值中心化、仅做缩放，计算更省且在大模型上表现相当；位置约定仍固定在 Pre。因此「Pre-Norm + RMSNorm」是当今 decoder-only 模型的事实组合。

## 三、形式化与数学基础

LayerNorm 对向量 $\mathbf{x}\in\mathbb{R}^d$ 计算：

$$
\mu = \frac{1}{d}\sum_{j=1}^{d} x_j,\quad \sigma = \sqrt{\frac{1}{d}\sum_{j=1}^{d}(x_j-\mu)^2+\epsilon}
$$
$$
\text{LayerNorm}(\mathbf{x}) = \gamma\odot\frac{\mathbf{x}-\mu}{\sigma} + \beta
$$

残差反向传播时，设损失对输出的梯度为 $\frac{\partial L}{\partial \mathbf{y}}$，则：

$$
\frac{\partial L}{\partial \mathbf{x}} = \frac{\partial L}{\partial \mathbf{y}}\left(I + \frac{\partial \text{Sublayer}}{\partial \mathbf{x}}\right)
$$

恒等项 $I$ 保证梯度至少能无损回传，这正是深层可训练的关键。

## 四、代码实现

```python
import torch.nn as nn

# Pre-Norm 残差块
def pre_norm_block(x, sublayer, norm):
    return x + sublayer(norm(x))

# 等价地用 nn.Module
class PreNormResidual(nn.Module):
    def __init__(self, d, sublayer):
        super().__init__()
        self.norm = nn.LayerNorm(d)
        self.sublayer = sublayer
    def forward(self, x, **kw):
        return x + self.sublayer(self.norm(x))
```

## 六、常见误区

- annotated-transformer 原文实现实为 Post-Norm，但很多教程误标为 Pre-Norm，阅读源码需对照。
- 残差相加时形状必须一致，维度变化需用投影（如 $1\times1$ 卷积或线性层）对齐。
- 把 LayerNorm 与 BatchNorm 混用场景；序列建模中 BatchNorm 因变长与小批而不稳定，LayerNorm/RMSNorm 更合适。

## 九、演进与趋势

归一化从 LayerNorm 演进为计算更省的 RMSNorm（去掉均值中心化），并固定为 Pre 位置；进一步出现 DeepNorm（缩放残差以稳定极深网络）、把归一化移入注意力内部等变体。核心是「用最小代价换最大稳定」。

## 十、小结

残差连接提供梯度恒等通路，层归一化稳定每层分布，二者组合使超深 Transformer 可训练。Pre-Norm（及 RMSNorm）因更优的稳定性成为现代大模型事实标准，是架构工程「稳定优先」的典型体现。
