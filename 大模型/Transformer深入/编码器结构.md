# Transformer 编码器结构

> 对应 Vaswani et al. 2017 与 annotated-transformer (Harvard NLP)「Encoder」。

## 一、背景与挑战

编码器（Encoder）的任务，是把输入序列（如一句话）映射为上下文化的向量表示，供下游理解任务（分类、抽取、检索）或解码器使用。一个编码器层由**多头自注意力**与**前馈网络（FFN）**两个子层堆叠而成，每层外包**残差连接 + 层归一化（Add & Norm）**。如何让深层编码器既稳定训练又能充分捕捉序列内依赖，是结构设计的核心。

## 二、核心原理

单层前向（以现代 Pre-Norm 约定为例）：

```
x = x + SelfAttn(LayerNorm(x))
x = x + FFN(LayerNorm(x))
```

$N$ 个这样的层堆叠成编码器（原论文 $N=6$）。输入先叠加位置编码再进入首层。自注意力让每个位置聚合全序列信息；FFN 做逐位置非线性变换；残差+归一化保证深层可训练。编码器使用**双向**注意力（无因果掩码），因为每个词可看到上下文两侧。

## 三、形式化与数学基础

多头自注意力把 $Q,K,V$ 沿头维拆成 $h$ 份并行计算再拼接：

$$
\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1,\dots,\text{head}_h)W^O
$$
$$
\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)
$$

FFN 通常是两层线性夹激活（现代多用 SwiGLU，经典为 ReLU）：

$$
\text{FFN}(x) = \max(0,\ xW_1 + b_1)\,W_2 + b_2
$$

经典设定 $d_{ff}=4\,d_{model}$，提供逐位置的非线性容量。

## 四、代码实现

```python
import torch.nn as nn

class EncoderLayer(nn.Module):
    def __init__(self, d_model, h, d_ff):
        super().__init__()
        self.self_attn = nn.MultiheadAttention(d_model, h, batch_first=True)
        self.ff = nn.Sequential(
            nn.Linear(d_model, d_ff), nn.ReLU(), nn.Linear(d_ff, d_model))
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
    def forward(self, x, mask=None):
        # 双向自注意力（无 causal mask）
        a, _ = self.self_attn(self.norm1(x), self.norm1(x),
                              self.norm1(x), attn_mask=mask)
        x = x + a
        x = x + self.ff(self.norm2(x))
        return x
```

## 五、与其他技术对比

| 子层 | 作用 | 备注 |
|------|------|------|
| 双向自注意力 | 序列内全局交互 | 编码器特有权限 |
| FFN | 逐位非线性变换 | $d_{ff}=4d$ |
| 残差+LN | 稳定深层训练 | Pre/Post 之争 |
| 位置编码 | 注入顺序 | 加在输入 |

对比解码器：编码器无因果掩码、无交叉注意力；解码器二者皆有。

## 六、常见误区

- 认为编码器「只能做分类」；其实其输出表示也是检索、句子相似度等任务的 backbone。
- 误用因果掩码到编码器自注意力，反而丢失双向上下文信息。
- 以为 $d_{ff}=4d$ 是理论最优；它更多是经验约定，现代模型会调参甚至改用 SwiGLU 改变形式。

## 九、演进与趋势

编码器组件被持续替换：归一化从 Post 改 Pre、LayerNorm 改 RMSNorm、ReLU-FFN 改 SwiGLU、绝对位置改 RoPE；但「自注意力+FFN+残差」的骨架不变。在 multilingual/多模态场景下，编码器常作为共享表示骨干复用。

## 十、小结

编码器以「双向自注意力 + FFN + 残差归一化」的层叠结构，把输入序列转化为上下文化表示。其骨架稳定、组件不断现代化，是理解/检索类任务的基石，也是整个 Transformer 家族的「前半身」。
