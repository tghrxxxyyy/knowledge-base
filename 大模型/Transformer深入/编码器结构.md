# Transformer 编码器结构

> 对应 annotated-transformer「Encoder」。编码器把输入序列映射为上下文化表示。

## 一、核心概念

一个编码器层由**多头自注意力** + **前馈网络(FFN)** 两个子层组成，每个子层外包**残差连接 + 层归一化(Add & Norm)**：

```
x = x + SelfAttn(LayerNorm(x))
x = x + FFN(LayerNorm(x))
```

`N` 个这样的层堆叠成编码器（原论文 `N=6`）。输入先加位置编码再进入。

## 二、前馈网络 FFN

```
FFN(x) = max(0, x W_1 + b_1) W_2 + b_2
```

通常隐层维度 `d_ff = 4·d_model`，提供逐位置的非线性变换。

## 三、代码实现（单 encoder 层）

```python
class EncoderLayer(nn.Module):
    def __init__(self, d_model, h, d_ff):
        super().__init__()
        self.self_attn = MultiHeadAttention(d_model, h)
        self.ff = nn.Sequential(
            nn.Linear(d_model, d_ff), nn.ReLU(), nn.Linear(d_ff, d_model))
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
    def forward(self, x, mask=None):
        x = x + self.self_attn(self.norm1(x), self.norm1(x), self.norm1(x), mask)
        x = x + self.ff(self.norm2(x))
        return x
```

## 四、关键要点

| 子层 | 作用 |
|------|------|
| 自注意力 | 序列内交互 |
| FFN | 逐位非线性 |
| 残差+LN | 稳定深层训练 |
