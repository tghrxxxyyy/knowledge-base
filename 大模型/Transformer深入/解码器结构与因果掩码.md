# 解码器结构与因果掩码

> 对应 annotated-transformer「Decoder」。解码器在自回归生成中只能看到已生成 token。

## 一、核心概念

解码器层有**两个**注意力子层：

1. **带掩码的自注意力(Masked Self-Attention)**：用因果掩码(causal mask)确保位置 `i` 只能关注 `≤i` 的位置，防止信息从未来泄漏。
2. **交叉注意力(Cross-Attention)**：query 来自解码器、key/value 来自编码器输出，实现「源-目标」对齐。

```
x = x + MaskedSelfAttn(LN(x))
x = x + CrossAttn(LN(x), enc_out, enc_out)
x = x + FFN(LN(x))
```

## 二、因果掩码

```python
def causal_mask(T):
    return torch.triu(torch.ones(T, T), diagonal=1).bool()  # 上三角为 future
# 在 scaled_dot_product_attention 中用 masked_fill(mask, -inf)
```

## 三、代码实现（单 decoder 层）

```python
class DecoderLayer(nn.Module):
    def __init__(self, d_model, h, d_ff):
        super().__init__()
        self.self_attn = MultiHeadAttention(d_model, h)
        self.cross_attn = MultiHeadAttention(d_model, h)
        self.ff = nn.Sequential(nn.Linear(d_model, d_ff), nn.ReLU(), nn.Linear(d_ff, d_model))
        self.n1, self.n2, self.n3 = [nn.LayerNorm(d_model) for _ in range(3)]
    def forward(self, x, enc, src_mask=None, tgt_mask=None):
        x = x + self.self_attn(self.n1(x), self.n1(x), self.n1(x), tgt_mask)
        x = x + self.cross_attn(self.n2(x), enc, enc, src_mask)
        x = x + self.ff(self.n3(x))
        return x
```

## 四、关键要点

| 注意力 | query | key/value | 掩码 |
|--------|-------|-----------|------|
| 解码自注意力 | 解码 | 解码 | 因果 |
| 交叉注意力 | 解码 | 编码 | 无 |
| 编码自注意力 | 编码 | 编码 | 双向 |

## 五、常见误区

- 推理时若用 KV Cache，仍需保证掩码逻辑与训练一致。
- 交叉注意力与自注意力用同一套 `W^O`/`W^K` 易混淆（通常各自独立）。
