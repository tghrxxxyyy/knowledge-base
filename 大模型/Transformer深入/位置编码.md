# 位置编码 Position Encoding

> 对应 Vaswani et al. 2017 与 d2l-zh / annotated-transformer「位置编码」。

## 一、背景与挑战

自注意力对输入顺序是**置换等变**的——打乱词序不会改变注意力权重的结构，因此模型本身「看不到」位置。
要让序列模型利用语序，必须显式注入位置信号。
如何编码位置，直接影响模型对长短序列、相对距离的感知能力，是 Transformer 架构最关键的组件之一。

## 二、核心原理

原始 Transformer 使用**正弦/余弦绝对位置编码**，把位置 $pos$ 映射为 $d_{model}$ 维向量，偶数维用 sin、奇数维用 cos：

$$
\text{PE}_{(pos,2i)} = \sin\!\left(\frac{pos}{10000^{2i/d_{model}}}\right), \quad
\text{PE}_{(pos,2i+1)} = \cos\!\left(\frac{pos}{10000^{2i/d_{model}}}\right)
$$

波长从 $2\pi$ 到 $10000\cdot 2\pi$ 呈几何级数分布，使不同频率携带不同尺度位置信息。
现代模型多改用 **RoPE（旋转位置编码）** 或 **ALiBi** 等相对/无参数方案，以提升长文本外推能力。
注入位置也需注意：有的实现把 PE 加到 token embedding 后再投影，有的在每层注意力前加，须保持训练/推理一致。

## 三、形式化与数学基础

正弦编码的关键性质：对任意固定偏移 $k$，有

$$
\text{PE}_{pos+k} = \mathbf{R}(k)\,\text{PE}_{pos}
$$

即 $\text{PE}_{pos+k}$ 可由 $\text{PE}_{pos}$ 经一个与 $pos$ 无关、只依赖 $k$ 的旋转矩阵 $\mathbf{R}(k)$ 得到（正余弦加法定理）。
这天然让模型能「线性地」感知相对距离，是后续相对/旋转位置编码的思想源头。

RoPE 则显式把位置编码写成对查询/键向量的旋转：

$$
q'_i = \mathbf{R}(\theta_i)\,q_i,\quad k'_j = \mathbf{R}(\theta_j)\,k_j
$$

从而内积 $\langle q'_i, k'_j\rangle$ 仅依赖相对位置 $i-j$，把相对性固化进注意力几何。
从实现角度看，RoPE 把旋转写为对角块形式，对 query/key 的奇偶维配对做二维旋转，由于旋转保内积，任意两位置的注意力只与其相对旋转差有关。

## 四、代码实现

```python
import torch
import math

def positional_encoding(max_len: int, d_model: int) -> torch.Tensor:
    pe = torch.zeros(max_len, d_model)
    pos = torch.arange(max_len).unsqueeze(1).float()
    div = torch.exp(torch.arange(0, d_model, 2).float() *
                    (-math.log(10000.0) / d_model))
    pe[:, 0::2] = torch.sin(pos * div)
    pe[:, 1::2] = torch.cos(pos * div)
    return pe  # (max_len, d_model)
```

## 五、与其他技术对比

| 编码 | 优点 | 缺点 |
|------|------|------|
| 正弦绝对 | 外推、无需学习 | 长序列外推仍有限 |
| 可学习绝对 | 灵活 | 难外推、长度固定 |
| 相对（XL/T5） | 天然相对 | 实现复杂 |
| RoPE | 相对、可外推 | 需改注意力计算 |
| ALiBi | 无参数、强外推 | 需改注意力偏置 |

## 六、常见误区

- 把位置编码加到 Q/K/V 投影之后而非加到 embedding（不同实现注入点不同，须保持一致）。
- 忽略外推：训练长度之外常需 NTK-aware scaling / 位置插值（PI）等技巧才能稳定。
- 认为正弦编码已「过时」——其线性相对性仍是理解 RoPE 的基础。

## 九、演进与趋势

从绝对（正弦/可学习）到相对（XL/T5），再到 RoPE 成为 decoder-only 主流；针对长上下文，发展出 NTK-aware scaling、位置插值（PI）、YaRN 等外推方法——其思想都是在推理时「压缩」位置索引，使训练长度之外的位置仍落在模型已见过的相对范围内。
ALiBi 则以无参数偏置在推理长度泛化上表现突出。
需要补充的是，位置编码与注意力掩码必须协同：因果掩码保证 decoder-only 只看左侧，位置编码在此之上叠加顺序几何，二者缺一则语序信息不完整。

## 十、小结

位置编码弥补了自注意力「无顺序感」的缺陷。
正弦编码以频率多样性与线性相对性奠定基础，现代 RoPE/ALiBi 则在相对位置与外推能力上更进一步。
选型的本质是「在表达力、实现成本与长程外推之间权衡」。
