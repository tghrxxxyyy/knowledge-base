# 位置编码 Position Encoding

> 对应 annotated-transformer 与 d2l-zh「位置编码」。注意力本身置换不变，需显式注入顺序信息。

## 一、核心概念

自注意力对输入顺序不敏感（置换等变），因此必须给每个位置加上位置信号。原始 Transformer 使用**正弦/余弦绝对位置编码**：

```
PE_{(pos, 2i)}   = sin(pos / 10000^{2i/d_model})
PE_{(pos, 2i+1)} = cos(pos / 10000^{2i/d_model})
```

波长从 `2π` 到 `10000·2π` 几何级数分布，使不同频率携带不同尺度位置信息，且便于模型学习「相对位置」(因 `PE_{pos+k}` 可由 `PE_{pos}` 线性表达)。

## 二、数学性质

对任意固定偏移 `k`，`PE_{pos+k}` 是 `PE_{pos}` 的线性函数（正余弦加法定理），便于注意力感知相对距离。

## 三、代码实现

```python
import torch
import math

def positional_encoding(max_len, d_model):
    pe = torch.zeros(max_len, d_model)
    pos = torch.arange(max_len).unsqueeze(1).float()
    div = torch.exp(torch.arange(0, d_model, 2).float() *
                    (-math.log(10000.0) / d_model))
    pe[:, 0::2] = torch.sin(pos * div)
    pe[:, 1::2] = torch.cos(pos * div)
    return pe  # (max_len, d_model)
```

## 四、关键要点

| 编码 | 优点 | 缺点 |
|------|------|------|
| 正弦绝对 | 外推、无需学习 | 长序列外推仍有限 |
| 可学习绝对 | 灵活 | 难外推 |
| 相对/RoPE | 天然相对 | 实现复杂 |
| ALiBi | 无参数、强外推 | 需改注意力 |

## 五、常见误区

- 把位置编码加到 Q/K/V 上而非加到 embedding 后再投影（不同实现位置不同，但需一致）。
- 忽略外推：训练长度外推常需 NTK/PI 等技巧。
