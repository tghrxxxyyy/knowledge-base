# 自注意力机制 Self-Attention

> 对应 annotated-transformer 与 d2l-zh「注意力池化」。自注意力让序列每个位置直接关注所有位置，突破 RNN 的时序瓶颈。

## 一、核心概念

给定输入序列，每个 token 映射为查询 `Q`、键 `K`、值 `V` 三个向量。注意力即：用 `Q` 与所有 `K` 算相似度，归一化为权重，再对 `V` 加权求和，得到每个位置融合全局信息的新表示。

```
Attention(Q, K, V) = softmax(Q K^T / √d_k) V
```

`√d_k` 缩放防止点积过大导致 softmax 梯度消失（当 `d_k` 较大时点积方差随维度线性增长）。

## 二、数学形式

```
score(i,j) = (Q_i · K_j) / √d_k
α_{i,j} = exp(score(i,j)) / Σ_{j'} exp(score(i,j'))
output_i = Σ_j α_{i,j} V_j
```

复杂度：每个 query 与所有 key 交互，为 `O(n²·d)`，序列长度 `n` 决定主要开销。

## 三、代码实现

```python
import torch
import torch.nn.functional as F

def scaled_dot_product_attention(q, k, v, mask=None):
    d_k = q.size(-1)
    scores = (q @ k.transpose(-2, -1)) / d_k ** 0.5
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float("-inf"))
    weights = F.softmax(scores, dim=-1)
    return weights @ v, weights
```

## 四、关键要点

| 项 | 说明 |
|----|------|
| Q/K/V | 同一序列的三类投影 |
| 缩放 | `√d_k` 稳定梯度 |
| 全局感受野 | 任意两位置一步可达 |
| 并行 | 不依赖时序 |

## 五、常见误区

- 忘记缩放导致 softmax 饱和、梯度趋零。
- 因果解码漏加 mask，造成未来信息泄漏。
- 把 `softmax` 维度搞错（应在 key 维度）。
