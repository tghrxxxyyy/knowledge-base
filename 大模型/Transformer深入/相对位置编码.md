# 相对位置编码 Relative Position

> 扩展自位置编码节，讲解 Transformer 变体中相对位置的建模方式。

## 一、核心概念

绝对位置编码把位置当作「位置 id」。但语言理解更依赖**相对距离**（"第 i 个词前两个词"）。相对位置编码在注意力分数中直接注入相对偏移 `i-j`：

- **Shaw et al. (2018)**：在 `score(q_i, k_j)` 中加入可学习相对位置表示 `a_{i-j}`。
- **Transformer-XL / XLNet**：用 `sin/cos` 相对编码 `R_{i-j}`，并通过 `u/v` 偏置项分离内容/位置贡献。
- **T5 Bias**：可学习相对位置桶(bucket)。

## 二、数学形式（Transformer-XL 风格）

```
score(i,j) = (q_i + u)^T k_j + (q_i + v)^T R_{i-j}
```

其中 `u,v` 为内容/位置偏置，`R_{i-j}` 为相对位置正弦向量。

## 三、关键要点

| 方法 | 注入点 | 特点 |
|------|--------|------|
| Shaw | 加性偏置 | 简单 |
| Transformer-XL | 拆分内容/位置 | 支持段循环 |
| T5 | 相对桶 | 长程压缩 |

## 四、与开源书的对应

- Shaw et al., *Self-Attention with Relative Position Representations*, 2018.
- Dai et al., *Transformer-XL*, 2019.
