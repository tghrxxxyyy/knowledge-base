# 归一化与训练稳定

> 对应 Xiong 2020 训练动态分析，以及 Nguyen & Salazar, *Transformers without Tears*, 2019 对 warmup 的讨论。

## 一、背景与挑战

深层 Transformer 初期梯度大易炸；归一化放置与学习率 warmup 共同决定能否稳定收敛。

## 二、核心原理

Post-LN 初期需 warmup 抑制大梯度；Pre-LN 梯度天然有界更鲁棒，warmup 可更短；归一化缩放幅度影响初始更新。

## 三、数学形式

梯度范数 $\|g_t\|\propto\frac1{\sqrt t}$（warmup 斜率），配合 Pre-LN 残差直连使 $\|g_t\|$ 不随深度指数增。

## 四、代码实现

```python
lr = base * min(step / warmup, 1.0)   # 线性 warmup
```

## 五、与其他对比

- 与 训练不稳定诊断深入 共享：归一化是首要稳定手段。
- 与 门控线性单元与激活变体深入 / 专家混合路由策略深入（损失稳定）互补。

## 六、常见误区

- 在 Pre-LN 上仍套用 Post-LN 的长 warmup，浪费步数。
- 忽视归一化增益初始化（常置 1）对初期尺度的影响。

## 八、面试题

- 归一化如何助稳定？答：约束每层激活尺度，配合 warmup 抑制初期大梯度，防爆炸。

## 九、演进

无 warmup 易炸 → warmup+Post-LN → Pre-LN 降低 warmup 依赖。

## 十、小结

归一化放置与 warmup 协同是深层训练稳定的核心，Pre-LN 显著放宽 warmup 需求。
