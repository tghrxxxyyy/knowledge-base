# 归一化实践选型

> 综合主流大模型配置（LLaMA、GPT、PaLM 等）的归一化实践。

## 一、背景与挑战

落地大模型需在稳定、质量、算力间取舍，归一化是高频调优点。

## 二、核心原理

默认 Pre-LN + RMSNorm + SwiGLU 组合；深层/大学习率场景坚持 Pre，避免 Post 的 warmup 脆弱；监控首层激活尺度。

## 三、数学形式

LayerNorm 含均值与方差两步：$\hat x_i=\frac{x_i-\mu}{\sigma}\cdot g_i$；RMSNorm 仅 $\hat x_i=\frac{x_i}{\mathrm{RMS}(x)}\cdot g_i$，少一次减均值，常数延迟更低。

## 四、代码实现

```python
class Block(nn.Module):
    def forward(self, x):
        return x + self.sub(self.norm(x))   # Pre-RMSNorm
```

## 五、与其他对比

- 与 门控线性单元与激活变体深入 必须联合调（SwiGLU 配 Pre-RMS 最佳）。
- 与 训练不稳定诊断深入 互为因果（归一化不当即不稳定源）。

## 六、常见误区

- 照搬小模型 Post-LN 配置到十亿级以上模型，训练崩。
- 在换归一化形式时未重调增益初始化与学习率。

## 八、面试题

- 大模型归一化怎么选？答：Pre-LN+RMSNorm+SwiGLU，稳且省，必要时短 warmup。

## 九、演进

Post-LN（原版）→ Pre-LN → Pre-RMSNorm（现代事实标准）。

## 十、小结

实践上 Pre-RMSNorm+SwiGLU 是兼顾稳定与效率的归一化选型。
