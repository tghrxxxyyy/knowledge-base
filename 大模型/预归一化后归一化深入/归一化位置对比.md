# 归一化位置对比

> 综合 Pre/Post-LN 与 RMSNorm/LayerNorm 文献，系统比较放置与形式。

## 一、背景与挑战

归一化有两个自由度：放在子层前/后、用 LN 还是 RMSNorm；需理解组合效果。

## 二、核心原理

位置影响梯度路径（Pre 保残差直连），形式影响算力与中心化（RMSNorm 更省）；组合成 Pre-RMSNorm 主流。

## 三、数学形式

对比四种 $(pos,type)\in\{\text{Pre,Post}\}\times\{\text{LN,RMS}\}$；Pre-RMS 兼具稳定与高效。

## 四、代码实现

```python
variants = {
    "pre-rms": lambda x,s: x + s(rms(x)),
    "post-ln": lambda x,s: ln(x + s(x)),
}
```

## 五、与其他对比

- 与 门控线性单元与激活变体深入 协同：归一化位置影响 SwiGLU 门输入分布。
- 与 训练不稳定诊断深入 互补（位置是稳定关键）。

## 六、常见误区

- 固定认为某组合最优；实际依赖深度、学习率与数据。
- 在不同组合间直接搬运超参（warmup 需求不同）。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh
- harvardnlp/annotated-transformer：https://github.com/harvardnlp/annotated-transformer

## 八、面试题

- 现代 LLM 为何用 Pre-RMSNorm？答：Pre 保残差直连稳训练，RMS 省算力，组合最优。

## 九、演进

Post-LN → Pre-LN → Pre-RMSNorm 收敛为默认。

## 十、小结

归一化位置与形式需联合选择，Pre-RMSNorm 是当前实践最优点。
