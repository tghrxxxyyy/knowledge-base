# 归一化总览

> 对应 Ba et al., *Layer Normalization*, 2016；以及 Xiong et al., *On Layer Normalization in NLP*, 2020 对 Pre/Post-LN 的分析。

## 一、背景与挑战

深层网络梯度易爆炸/消失；归一化稳定隐藏分布，但“放在子层前还是后”显著影响训练动态。

## 二、核心原理

Post-LN：子层输出归一化后再残差加；Pre-LN：先归一化输入再过子层，残差直连不被归一化截断。

## 三、数学形式

Post-LN：$h_{t+1}=h_t+\mathrm{Norm}(\text{Sub}(h_t))$；Pre-LN：$h_{t+1}=h_t+\text{Sub}(\mathrm{Norm}(h_t))$。

## 四、代码实现

```python
# Pre-LN
h = h + sub(norm(h))
# Post-LN
h = norm(h + sub(h))
```

## 五、与其他对比

- 与 门控线性单元与激活变体深入 协同：SwiGLU 常在 Pre-LN 下最稳。
- 与 训练不稳定诊断深入 共享稳定性主题。

## 六、常见误区

- 以为归一化位置无影响；它决定残差梯度路径。
- 把 LayerNorm 与 BatchNorm 混用场景混淆（NLP 用 LN）。

## 八、面试题

- 归一化作用？答：稳定每层输入分布，缓解梯度异常，加速并稳定深层训练。

## 九、演进

BatchNorm → LayerNorm → Pre-LN 成为大模型默认。

## 十、小结

归一化是深层训练基石，Pre/Post-LN 的位置选择影响稳定性与收敛。
