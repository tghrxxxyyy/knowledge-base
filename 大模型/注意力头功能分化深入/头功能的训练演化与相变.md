# 头功能的训练演化与相变

> 对应 Olsson et al., 2022（归纳头相变）；Nanda et al., *Progress Measures for Grokking via Mechanistic Interpretability*, ICLR 2023。

## 一、背景与挑战

功能不是从初始化就存在，而是在训练中逐步形成，且常伴随损失曲线上的小台阶。追踪这一过程能把能力与机制在时间轴上对齐。

## 二、核心原理

用「进展度量」在训练过程中持续测量某机制的强度，即可看到机制形成与能力跃升的同步性。

- 归纳头强度在某个训练窗口迅速上升，同期上下文学习指标出现拐点，损失曲线有可见台阶。
- grokking 研究进一步说明：泛化能力的突然出现对应内部算法结构的形成，而非损失的连续下降。

## 三、数学形式

定义机制强度 $s(t)$（如归纳分数）与能力指标 $c(t)$，考察时间对齐 $\rho\big(s(t),c(t)\big)$ 与拐点时刻差 $|t_s^\ast-t_c^\ast|$。

若两者高度同步且消融该机制使 $c$ 显著下降，则形成「机制导致能力」的时间序 + 干预双证据。

## 四、代码实现

```python
import numpy as np
def align_phase(s, c):
    s = np.asarray(s, float); c = np.asarray(c, float)
    return int(np.argmax(np.diff(s))), int(np.argmax(np.diff(c)))
print(align_phase([0.01, 0.02, 0.30, 0.55], [0.10, 0.11, 0.42, 0.60]))
```

## 五、与其他对比

- 与 涌现能力度量争议深入 对照：训练期相变提供了跳变的机制候选解释，独立于评测指标问题。
- 与 归纳头与复制回路 衔接：相变研究正是以归纳分数作为进展度量。

## 六、常见误区

- 用最终检查点做全部解释，错过机制形成期这一信息最丰富的窗口。
- 把损失台阶直接当作机制形成证据，缺少进展度量与消融的双重支持。

## 八、面试题

- 什么是进展度量？答：训练期可持续测量的机制强度指标，用于把内部结构与能力对齐。
- 相变证据需要哪些要素？答：时间同步 + 消融因果 + 可复现的度量定义。

## 九、演进

终态解释 → 训练期进展度量 → 相变与 grokking 机制对齐 → 训练动力学驱动的解释。

## 十、小结

把解释性从单一检查点扩展到训练时间轴，是理解能力如何出现的关键方法升级。
