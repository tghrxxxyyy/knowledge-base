# 位置头与句法头

> 对应 Clark et al., BlackboxNLP 2019；Voita et al., ACL 2019。

## 一、背景与挑战

早期分析在 BERT 与翻译模型上发现大量头具有稳定的、可用语言学术语描述的模式。这类发现是功能分化研究的起点，也需要注意其解释边界。

## 二、核心原理

按注意力目标可粗分为三类可复现模式，它们在不同层的分布也有规律。

- 位置头：注意力几乎固定指向相对偏移（前一位、后一位），常见于浅层。
- 句法与指代头：注意力对齐依存关系（如宾语指向动词）或共指链；另有大量头集中在分隔符等「无信息汇」上。

## 三、数学形式

位置性可用偏移分布的集中度衡量：$\Pr\big[\arg\max_j A_{tj}=t-\delta\big]$ 对某固定 $\delta$ 显著大。

句法对齐度可用与依存树边的一致率 $\mathrm{UAS}^{(h)}=\frac{1}{|E|}\sum_{(i,j)\in E}\mathbb{1}\big[\arg\max_{j'}A_{ij'}=j\big]$ 评估。

## 四、代码实现

```python
import torch
def offset_profile(A, max_off=4):                   # A: [T,T]
    T = A.shape[0]; prof = []
    top = A.argmax(-1)
    for d in range(1, max_off + 1):
        t = torch.arange(d, T)
        prof.append(float((top[t] == t - d).float().mean()))
    return prof
print(offset_profile(torch.softmax(torch.randn(10, 10).tril(), -1)))
```

## 五、与其他对比

- 与归纳头对照：位置头是单层局部模式，归纳头需要跨层组合，解释层级不同。
- 与 注意力头剪枝 衔接：分隔符汇聚型头往往是最先可剪的候选。

## 六、常见误区

- 把注意力对齐依存边解读为模型「显式做句法分析」；对齐只是相关性证据。
- 忽视注意力汇（attention sink）现象，把大量指向首 token 的权重误读为语义功能。

## 八、面试题

- 位置头如何识别？答：其注意力峰值稳定落在固定相对偏移上，偏移分布高度集中。
- 句法对齐能证明什么？答：只能证明信息可与句法结构对应，不能证明模型内部做显式解析。

## 九、演进

模式分类（2019）→ 头重要性排序（2019）→ 注意力汇与伪模式辨识 → 回路级功能归因。

## 十、小结

位置头与句法头是最易观察的分化证据，但语言学标签需与因果验证分开对待。
