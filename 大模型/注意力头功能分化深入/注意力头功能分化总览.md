# 注意力头功能分化总览

> 对应 Clark et al., *What Does BERT Look At?*, BlackboxNLP 2019；Voita et al., *Analyzing Multi-Head Self-Attention*, ACL 2019。

## 一、背景与挑战

多头注意力并非同质副本：不同头稳定承担不同功能。识别这些角色既能解释模型行为，也直接支撑剪枝、干预与调试。

## 二、核心原理

分化研究通常先用统计特征聚类头行为，再用消融确认功能，最后尝试给出机制解释。

- 常见角色：位置偏移头（固定看前/后一位）、分隔符与稀有词头、句法依存头、以及跨层组合的归纳头。
- 大量头是可剪的：少数头承担主要功能，其余在多数任务上冗余（Michel et al., NeurIPS 2019）。

## 三、数学形式

头 $h$ 的注意力矩阵 $A^{(h)}=\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)$；其行熵 $H^{(h)}_t=-\sum_j A^{(h)}_{tj}\log A^{(h)}_{tj}$ 刻画聚焦程度。

低熵且偏移集中的头多为位置头；高熵头常起平滑聚合作用，功能标签应以消融结果为准。

## 四、代码实现

```python
import torch
def head_stats(A):                                  # A: [H, T, T]
    ent = -(A.clamp_min(1e-9).log() * A).sum(-1).mean(-1)
    off = (A.argmax(-1) - torch.arange(A.shape[1])).float().mean(-1)
    return ent, off                                 # 熵与平均相对偏移
print([x.shape for x in head_stats(torch.softmax(torch.randn(4, 8, 8).tril(), -1))])
```

## 五、与其他对比

- 与 MLP 神经元归因对照：头承担跨位置搬运，MLP 承担位置内查表，两类单元功能互补。
- 与 残差流与贡献分解深入 衔接：头的输出以加性方式写入残差流，可被直接分解归因。

## 六、常见误区

- 只凭注意力图给头贴标签；注意力权重大不等于对输出贡献大，需消融或路径 patch。
- 把某任务上冗余的头当作全局无用，剪枝需覆盖多任务评测。

## 八、面试题

- 如何判断一个头的功能？答：统计其注意力模式后做消融与路径 patch，确认对输出的因果作用。
- 注意力权重能否作为解释？答：只能作为线索，权重与贡献之间还隔着值向量与后续层。

## 九、演进

注意力模式统计（2019）→ 头重要性与剪枝（2019）→ 归纳头等机制解释（2021-2022）→ 电路级角色分工（2023）。

## 十、小结

头功能分化是可测的经验规律，但标签必须由因果干预确立，而非注意力热图直觉。
