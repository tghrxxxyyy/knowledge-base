# 归纳头与复制回路

> 对应 Olsson et al., *In-context Learning and Induction Heads*, 2022；Elhage et al., *A Mathematical Framework for Transformer Circuits*, 2021。

## 一、背景与挑战

上下文中重复模式的续写是 ICL 最基础的形式。它由跨层的两头组合实现，是目前证据链最完整的注意力回路。

## 二、核心原理

回路由两步构成，缺一即失效，这也是它必须跨至少两层的原因。

- 第一步：前一层的 previous-token 头把「我的上一个 token 是什么」写入当前位置的残差流。
- 第二步：归纳头用该信息做键匹配，把注意力指向历史中相同前缀的位置，并通过 OV 通路复制其后继 token。

## 三、数学形式

设序列在位置 $j$ 有 $x_{j-1}=x_t$，归纳头使 $A_{t,j}$ 显著，输出方向近似 $W_U W_{OV}\,e_{x_j}$，从而提升 token $x_j$ 的 logit。

归纳分数可测为随机重复序列上注意力落在周期偏移位的比例 $\mathrm{IS}=\mathbb{E}_t\big[A_{t,\,t-T_{rep}+1}\big]$。

## 四、代码实现

```python
import torch
def rep_seq_induction(A, rep_len):                  # A: [T,T]，T=2*rep_len
    T = A.shape[0]; t = torch.arange(rep_len, T)
    return float(A[t, t - rep_len + 1].mean())
A = torch.softmax(torch.randn(16, 16).tril(), dim=-1)
print(round(rep_seq_induction(A, 8), 4))
```

## 五、与其他对比

- 与 KV 缓存对照：归纳头解释「为何模型能利用上下文」，缓存只是工程上的存储机制。
- 与 上下文学习理论深入 衔接：归纳头为 ICL 提供机制层面的因果证据。

## 六、常见误区

- 认为单个头即可完成归纳；至少需要 previous-token 头与匹配头的组合。
- 把归纳头当作所有 ICL 的解释；抽象任务映射并不能由复制机制覆盖。

## 八、面试题

- 归纳头为什么需要两层？答：需先把上一 token 信息写入残差流，再据此做键匹配复制后继。
- 如何度量归纳强度？答：在随机重复序列上计算注意力落在周期偏移位置的比例。

## 九、演进

复制现象观察 → 头组合数学框架 → 训练相变与消融验证 → 复杂回路（如 IOI）研究。

## 十、小结

归纳头是「组合两个简单头得到上下文学习」的经典范例，示范了回路级解释的方法论。
