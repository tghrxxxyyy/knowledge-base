# 头消融与因果干预

> 对应 Wang et al., *Interpretability in the Wild (IOI)*, ICLR 2023；Goldowsky-Dill et al., *Localizing Model Behavior with Path Patching*, 2023。

## 一、背景与挑战

要证明某头承担某功能，必须做干预：移除它、或切断它到特定下游位置的路径，观察目标行为是否消失。

## 二、核心原理

IOI 研究给出了完整范式：定义可控任务、用 logit 差作指标、逐头消融与路径 patch 定位分工。

- 角色分工可被识别，例如把正确姓名搬到末位的搬运头，以及抑制重复姓名的抑制头。
- 路径 patch 比整头消融更精细：它只替换「某头到某下游组件」的这条边，避免全局副作用。

## 三、数学形式

指标取 logit 差 $m(x)=\mathrm{logit}\big(y^\ast\big)-\mathrm{logit}\big(y^{alt}\big)$；头 $h$ 的消融效应 $\Delta_h=m(x)-m\big(x;\ z_h\leftarrow \bar z_h\big)$。

其中 $\bar z_h$ 常取对照分布的均值激活（mean ablation），比零消融更少引入分布外扰动。

## 四、代码实现

```python
import torch
def mean_ablate_head(z, head_idx, mean_z):          # z: [B,T,H,d_head]
    z = z.clone(); z[:, :, head_idx, :] = mean_z[head_idx]
    return z
def logit_diff(logits, tgt, alt):
    return float(logits[0, -1, tgt] - logits[0, -1, alt])
```

## 五、与其他对比

- 与零消融对照：均值消融保留分布统计，减少「破坏输入分布」带来的伪效应。
- 与 归因方法的评估与陷阱 衔接：消融方向与基线选择显著影响结论。

## 六、常见误区

- 用零向量消融并把性能崩塌当作功能证据；崩塌可能只是分布外扰动。
- 只做单头消融忽视冗余备份，导致重要头因可被替代而被判为不重要。

## 八、面试题

- 路径 patch 与整头消融差别？答：前者只改一条组件间的边，能定位分工；后者影响全部下游。
- 为何偏好均值消融？答：更贴近原分布，减少分布外扰动造成的假阳性。

## 九、演进

整头消融 → 均值消融规范 → 路径 patch 精细定位 → 自动电路发现与验证。

## 十、小结

头功能的因果证据来自干预设计，而消融基线与指标选择决定结论是否可信。
