# 分支课程与课程调度策略

> 对应 Bengio et al. 2009 "Curriculum Learning", ICML 2009。

## 一、背景与挑战

单一线性课程可能错过“多路径”学习机会。分支课程(Branching Curriculum)允许在不同训练阶段切换难度曲线，避免过早锁定。

## 二、核心原理

将课程视为状态机：每个状态对应一组难度区间，状态间按条件(损失平台、epoch)转移。调度 $\lambda(t)$ 可线性、指数或阶梯式增长。

## 三、数学形式

阶梯调度：

$$
\lambda(t) = \lambda_k \quad \text{if } t\in [t_k, t_{k+1})
$$

指数调度：

$$
\lambda(t) = \lambda_{\min} + (\lambda_{\max}-\lambda_{\min})(1-e^{-t/\tau})
$$

分支点选择在验证损失 plateau 处：当 $|\mathcal{L}_{val}(t)-\mathcal{L}_{val}(t-1)|<\epsilon$ 时提升难度。

## 四、代码实现

```python
def exp_schedule(t, lmin, lmax, tau):
    import math
    return lmin + (lmax - lmin) * (1 - math.exp(-t / tau))
```

## 五、与其他对比

相比固定线性课程，分支/指数调度更鲁棒，能在模型准备好时才提升难度。

## 六、常见误区

误区：难度提升过快导致训练崩溃；误区：在多任务下使用全局统一调度，忽略任务差异。

## 八、面试题

- Q：何时用指数而非线性调度？答：当早期需要更平缓过渡以避免冷启动崩溃时。
- Q：分支课程如何防过拟合？答：在 plateau 处提升难度，注入新信息打破过拟合。

## 九、演进

自动课程调度已用强化学习/贝叶斯优化搜索 $\lambda(t)$ 形状，减少人工调参。

## 十、小结

课程调度形状显著影响结果；分支与自适应调度比固定线性更稳。
