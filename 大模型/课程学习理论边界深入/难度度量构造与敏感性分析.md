# 难度度量构造与敏感性分析

> 对应 Bengio et al. 2009 "Curriculum Learning", ICML 2009。

## 一、背景与挑战

难度度量是课程学习的“地基”。不同度量(样本长度、词频、模型困惑度、损失)产生截然不同的课程，且对超参高度敏感。

## 二、核心原理

好的难度度量应(1) 稳定：不随随机种子剧烈变化；(2) 相关：与模型实际学习曲线相关；(3) 廉价：可离线批量计算。常见度量包括：序列长度、token 频率逆、教师模型困惑度。

## 三、数学形式

基于困惑度的难度：

$$
\rho(x) = \mathrm{PPL}(x) = \exp\left(-\frac{1}{|x|}\sum_{t}\log p_\phi(x_t\mid x_{<t})\right)
$$

敏感性可用度量方差刻画：

$$
\mathrm{Var}(\rho) = \mathbb{E}[(\rho(x)-\bar{\rho})^2]
$$

高方差度量需平滑(如分桶排序)后再使用。

## 四、代码实现

```python
import torch, math

def ppl(logits, labels):
    loss = torch.nn.functional.cross_entropy(logits, labels, reduction='mean')
    return math.exp(loss.item())
```

## 五、与其他对比

相比人工规则(长度)，困惑度度量更贴近模型真实难度但计算更贵；分桶排序可降低对度量的精确敏感性。

## 六、常见误区

误区：直接用原始损失排序而不过平滑，导致课程被噪声主导。另一误区：用目标模型自身困惑度，造成“自己教自己”的信息泄漏。

## 八、面试题

- Q：为什么困惑度是好的难度度量？答：它反映模型对样本的预测不确定性，与学习难度高度相关。
- Q：如何降低度量敏感性？答：分桶、移动平均、或用教师模型而非目标模型。

## 九、演进

从简单特征到基于预训练模型的难度估计，再到可学习难度打分器(用验证集表现反推)。

## 十、小结

难度度量的稳定性与相关性决定了课程上限；务必做敏感性分析再上线。
