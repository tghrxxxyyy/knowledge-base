# 课程何时有害失败条件与反例

> 对应 Weinshall et al. 2018 "Curriculum Learning by Transfer Learning", NeurIPS 2018 workshop。

## 一、背景与挑战

大量实验表明课程学习并非总是有益。理解“何时有害”是划定其理论边界的核心。反例对于避免盲目套用课程策略至关重要。

## 二、核心原理

课程有益的必要条件是“简单样本”所诱导的优化方向与最终目标一致。若该前置条件被破坏，早期偏差会锁定错误解。Weinshall 提出用预训练网络一致性作为课程有效性的判别准则。

## 三、数学形式

定义一个“教师”模型 $g$ 对样本 $x$ 的难度为：

$$
\rho_g(x) = \frac{1}{K}\sum_{k=1}^{K} \mathbb{1}\{g(x) \neq f_{S_k}(x)\}
$$

即用教师 $g$ 与 $K$ 个从子集 $S_k$ 训练的弱分类器的一致性度量难度。课程仅在难度排序与目标任务相关时才有效。

## 四、代码实现

```python
import torch

def teacher_agreement(teacher_logits, weak_preds):
    return (teacher_logits.argmax(-1) != weak_preds).float().mean()
```

## 五、与其他对比

与自步学习不同，课程的有效性在此框架下可被“预测”而非仅事后验证，是对理论边界的推进。

## 六、常见误区

误区：难度排序只要单调即可。实际上排序必须和目标分布对齐，否则有害。另一误区：用训练初期损失排序，而初期损失噪声极大不可靠。

## 八、面试题

- Q：什么情况下课程学习有害？答：简单样本引入错误归纳偏置、难度排序与任务无关、或问题本身近似凸且顺序无关时。
- Q：如何事先判断课程是否有用？答：用预训练/教师模型的一致性偏差度量。

## 九、演进

从“经验性有益”到“可判别有效性”，再到自动搜索课程调度(如用元学习决定 $\lambda(t)$)。

## 十、小结

课程学习有明确的失败边界，必须用与目标对齐的难度度量，否则应优先随机选择。
