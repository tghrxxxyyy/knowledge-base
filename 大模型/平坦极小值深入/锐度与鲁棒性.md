# 平坦性与鲁棒性

> 对应 Wu et al., *Adversarial Robustness vs. Flatness*, 2020 等相关研究。

## 一、背景与挑战

对抗鲁棒性与平坦性常被一起讨论，二者关系并非线性。

## 二、核心原理

平坦解对权重扰动鲁棒，但对输入对抗扰动鲁棒性取决于损失对输入的曲率，二者机制不同却常正关。

## 三、数学形式

对抗锐度可定义为输入邻域内最大损失 $\max_{\|\delta\|_p\le\epsilon}\mathcal L(f_\theta(x+\delta),y)$，与参数平坦度不同维。

## 四、代码实现

```python
adv = x + epsilon * delta.sign()   # FGSM 风格
rob_loss = loss(model(adv), y)
```

## 五、与其他对比

- 与 锐度感知深入（参数空间）对照输入空间鲁棒性。
- 与 损失景观深入 共享几何视角。

## 六、常见误区

- 参数平坦不保证对抗鲁棒。
- 鲁棒训练常使解更平坦，却降干净精度。

## 八、面试题

- 平坦性能否保证对抗鲁棒？答：参数平坦提升权重扰动鲁棒，但不直接等价于输入对抗鲁棒。

## 九、演进

参数平坦 → 输入鲁棒 → 二者联合优化。

## 十、小结

平坦性有益鲁棒但非充分条件，需区分参数与输入两个空间。
