# 平坦极小值实践

> 对应大模型与预训练中关于平坦/锐度的实证（如 LLM 训练末期的尖锐化现象）。

## 一、背景与挑战

大模型预训练后期常出现损失锐度上升，需手段维持平坦以提升下游。

## 二、核心原理

手段：SAM/ASAM、学习率预热与余弦退火、权重衰减、早停、以及锐度感知的微调策略。

## 三、数学形式

综合锐度 $\mathcal S=\alpha\,\mathcal S_{param}+\beta\,\mathcal S_{sharp}$ 可作监控指标。

## 四、代码实现

```python
sched = CosineAnnealingLR(opt, T_max=epochs)
for e in epochs: train(); sched.step()
```

## 五、与其他对比

- 与 自适应学习率深入 共用调度策略。
- 与 权重衰减深入 协同影响平坦。

## 六、常见误区

- 只盯训练损失忽略锐度演化。
- 过早大幅衰减致困于锐度。

## 八、面试题

- 如何实操获得平坦解？答：SAM/ASAM + 合适 LR 调度 + 权重衰减，并监控锐度。

## 九、演进

单技巧 → 组合 → 锐度感知训练监控。

## 十、小结

平坦性是可工程化的训练目标，需组合多种正则与调度手段。
