# 平坦度度量方法

> 对应 Keskar et al., 2017 的锐度定义；以及 Li et al. 损失景观可视化（滤波归一化）。

## 一、背景与挑战

不同平坦度度量对参数重缩放敏感，需可比的不变度量。

## 二、核心原理

常用：邻域最大损失差、Hessian 最大特征值、以及坐标无关（对每维按权重范数归一）的锐度。

## 三、数学形式

不变锐度 $\phi(\theta)=\frac{\mathcal L(\theta+\varepsilon^*)-\mathcal L(\theta)}{\mathcal L(\theta)}$，其中 $\varepsilon_i^*=\rho\,\text{sgn}(\nabla_i)\min(|\theta_i|,1)$。

## 四、代码实现

```python
eps = rho * torch.sign(g) * torch.min(theta.abs(), torch.ones_like(theta))
sharp = (loss_fn(theta+eps)-loss_fn(theta)) / loss_fn(theta)
```

## 五、与其他对比

- 与 锐度感知深入 的度量互证。
- 与 损失景观深入 可视化共用滤波归一。

## 六、常见误区

- 直接用 $\lambda_{\max}$ 比较不同规模网络会失真。
- 忽略 BN 统计量使度量非确定性。

## 八、面试题

- 为何要坐标无关平坦度？答：不同参数尺度会让同一几何被度量成不同锐度，需归一。

## 九、演进

简单曲率 → 不变度量 → 谱剖面分析。

## 十、小结

可靠度量需坐标无关，是公平比较与诊断平坦性的前提。
