# 平坦极小值总览

> 对应 Hochreiter & Schmidhuber, *Flat Minima*, 1997；Keskar et al., *On Large-Batch Training... Sharp Minima*, ICLR 2017。

## 一、背景与挑战

神经网络损失景观中存在众多极小值，其几何形状（尖锐 vs 平坦）与泛化能力显著相关。

## 二、核心原理

平坦极小值指损失在该点较大邻域内变化平缓，对参数与数据扰动更鲁棒，因而泛化更好。

## 三、数学形式

以 Hessian 迹近似平坦度：$\text{flat}(\theta)\propto \text{tr}(H),\ H=\nabla^2\mathcal L(\theta)$；迹小则更平坦。

## 四、代码实现

```python
flatness = torch.einsum('ii->', hessian)   # 近似 Hessian 迹
```

## 五、与其他对比

- 与 锐度感知深入 共享平坦=好泛化的直觉。
- 与 损失景观深入 共论几何结构。

## 六、常见误区

- 平坦度依赖参数化与模型族，非绝对量。
- 以为最平坦解一定最优，标签噪声下未必。
