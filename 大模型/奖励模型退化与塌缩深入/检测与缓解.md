# 奖励退化检测与缓解

> 对应 Gao et al., 2023；Casper et al., *Robust RLHF*, 2023；Islam et al., *PAS*, 2023。

## 一、背景与挑战

需在线监控 RM 是否被钻空子，并阻断塌缩。

## 二、核心原理

监控 RM 分数/真实质量背离、输出多样性、KL；缓解用保守 KL、RM 集成、周期性重标、best-of-N 校验。

## 三、数学形式

早停准则：当 $\frac{\partial J(\hat r)}{\partial step}>0$ 但真评分下降即停；用保留集真偏好做验证。

## 四、代码实现

```python
if gold_pref_acc(rm) < base - delta:
    stop_training()
```

## 五、与其他对比

- 与多目标偏好聚合深入：多维度监控更易发现局部退化。
- 与人类反馈噪声鲁棒深入共享验证集思路。

## 六、常见误区

- 仅离线评测漏掉在线分布漂移。
- 缓解措施同时上齐致训练过保守。
