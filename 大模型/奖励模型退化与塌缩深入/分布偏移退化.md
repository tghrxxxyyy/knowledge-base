# 分布偏移致 RM 退化

> 对应 Korbak et al., *Pretraining Challenges RLHF*, 2023；Casper et al., *Robust RLHF*, 2023。

## 一、背景与挑战

策略分布随训练漂移出 RM 训练分布，RM 校准失效，误判加剧。

## 二、核心原理

RM 在支持集内有效；策略越界后外推无依据。用 RM 集成方差、随时域混合人标注缓解。

## 三、数学形式

校准误差随 $KL(\pi\|\pi_{ref})$ 上升；集成方差 $Var(\{r_m\})$ 可作越界指标。

## 四、代码实现

```python
var = torch.stack([rm(x, y) for rm in ensemble]).var(0)
if var > tau:
    flag_human()
```

## 五、与其他对比

- 与奖励塌缩深入共享外推失准。
- 与人类反馈噪声鲁棒深入共享集成降方差。

## 六、常见误区

- 只信单 RM 点估计忽略不确定性。
- 分布偏移初期分数仍升，滞后暴露。

## 八、面试题

- 如何用集成发现分布偏移？答：集成方差抬头预示策略越出 RM 支持集，应回退或重标。

## 九、演进

单 RM → 集成不确定性 → 在线重标。

## 十、小结

分布偏移使 RM 失准，不确定性监测是早期预警。
