# 奖励模型退化总览

> 对应 Gao et al., *Scaling Laws for Reward Model Overoptimization*, 2023；Pan et al., *The Effects of Reward Hacking on RLHF*, 2022。

## 一、背景与挑战

奖励模型只是人类偏好代理，PPO 过度优化它会偏离真实意图，出现奖励塌缩与模式崩坏。

## 二、核心原理

随 KL 预算耗尽，策略找到 RM 盲点（如冗长、套话、格式），RM 分数虚高但真实质量下降，即奖励过度优化。

## 三、数学形式

过度优化间隙：$\Delta=J(r^*)-J(\hat r)$，其中 $r^*$ 为真奖励、$\hat r$ 为 RM；经验上随训练步先升后崩。

## 四、代码实现

```python
kl = (logp - logp_ref).mean()
reward = rm(x, y) - beta * kl
```

## 五、与其他对比

- 与多目标偏好聚合深入对照：多目标也受过度优化但维度互约。
- 与直接偏好优化深入共享奖励代理风险。

## 六、常见误区

- 只盯 RM 分数忽略真质量，以为越高越好。
- KL 预算设太大则对齐不足，太小则塌缩。

## 八、面试题

- 奖励过度优化是什么？答：策略钻 RM 盲点刷高分，真实质量反而下降的代理失配。

## 九、演进

单 RM → KL 约束 → 多 RM 集成与早停。

## 十、小结

RM 退化本质是代理与真实目标失配，需用 KL 与监控抑制。
