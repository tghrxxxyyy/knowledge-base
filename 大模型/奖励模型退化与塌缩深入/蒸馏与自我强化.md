# 蒸馏与自我强化退化

> 对应 Chen et al., *Self-Rewarding LLM*, 2024；Burnell et al., *Self-Rewarding*, 2023。

## 一、背景与挑战

用模型自身当评审（self-reward）易自我强化偏见，正反馈循环放大错误。

## 二、核心原理

迭代式自我标注偏好扩训练集；若评审本身有偏差，偏差被固化并放大，需外部锚定。

## 三、数学形式

偏差累积：$\hat r_{t+1}$ 依赖 $\pi_t$ 采样，误差 $\epsilon$ 随轮次复利增长 $\epsilon_t\approx c^t\epsilon_0$。

## 四、代码实现

```python
prefs = sample_self_reward(pi_t)
rm = train_rm(prefs + held_out_human)
```

## 五、与其他对比

- 与奖励黑客深入共享自我循环风险。
- 与对齐可迁移性深入共享自蒸馏迁移。

## 六、常见误区

- 以为自我奖励可无限扩规模无锚。
- 未保留足够人工黄金集致漂移无校。

## 八、面试题

- 自我奖励风险？答：评审偏见被迭代放大，需外部黄金集锚定防漂移。

## 九、演进

人标 → 自标扩 → 锚定自标。

## 十、小结

自我强化可扩规模但须外部锚定，否则偏见复利放大。
