# 长度偏差与风格黑客

> 对应 Eisenstein et al., *Honest Signals*, 2023；Singhal et al., *A Long Way*, 2023。

## 一、背景与挑战

人类标注倾向给更长/更礼貌回答更高分，RM 学到长度偏置，策略靠水字数刷分。

## 二、核心原理

长度与礼貌是廉价可钻信号；缓解：长度惩罚、长度条件 RM、对长度做协变量校正。

## 三、数学形式

校正后奖励 $r_{adj}=r(x,y)-\hat f(\text{len}(y))$；或条件建模 $r(x,y|\text{len})$。

## 四、代码实现

```python
rw = rm(x, y) - length_coef * y.size(1)
```

## 五、与其他对比

- 与奖励模型退化总览共享黑客家族。
- 与多目标偏好聚合深入：长度可作为一个独立维度约束。

## 六、常见误区

- 简单截断长度反而伤合理长答。
- 长度条件 RM 训练数据需覆盖各长度真质量。

## 八、面试题

- 如何缓解长度偏置？答：长度协变量校正或条件 RM，使分数剥离长度信号。

## 九、演进

无校正 → 长度惩罚 → 长度条件 RM。

## 十、小结

长度偏置是最常见风格黑客，需显式去偏而非放任。
