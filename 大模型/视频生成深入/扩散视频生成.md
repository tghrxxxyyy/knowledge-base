# 扩散视频生成

> 对应 Ho et al., 2022；Blattmann et al., *Stable Video Diffusion*, 2023。

## 一、背景与挑战

图像扩散直接扩展到视频需建模时间依赖，且保持帧间一致。

## 二、核心原理

在 3D（T×H×W）潜变量上做 U-Net 去噪，用时空卷积/注意力；可加条件（文本、首帧、动作）引导。

## 三、数学形式

加噪 $x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon$；训练预测噪声或 $x_0$：
$v_\theta(x_t,t)=\mathbb E[x_0]$。

## 四、代码实现

```python
model = UNet3D(in_ch=4, cond_dim=768)
loss = F.mse_loss(model(z_t, t, text_emb), noise)
```

## 五、与其他对比

- 比自回归更易保全局一致。
- 与 视频生成总览 / 长上下文 共享潜表示。

## 六、常见误区

- 帧数大时显存爆炸，需分块/级联。
- 忽视首帧条件时的运动幅度控制。

## 八、面试题

- 视频扩散如何保时序一致？答：时空 U-Net + 时间注意力，让去噪跨帧交换信息。

## 九、演进

2D 扩散→时空 U-Net→级联/潜扩散。

## 十、小结

扩散视频以时空去噪兼顾质量与一致，是主流路线。
