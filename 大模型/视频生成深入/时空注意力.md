# 时空注意力与架构

> 对应视频 Transformer（Vivit, TimeSformer）；扩散中的时空注意力。

## 一、背景与挑战

全时空注意力 $O(T^2H^2W^2)$ 不可承受，需分解与稀疏。

## 二、核心原理

分解注意力：空间注意力（帧内）+ 时间注意力（跨帧同位置），复杂度降为 $O(THW(H+W+T))$；或轴向/窗口注意力。

## 三、数学形式

空间 $A_{sp}=\text{Attn}(Q,K,V)$ 在每帧 patch；时间 $A_{tmp}=\text{Attn}$ 沿时间轴同 patch 索引。

## 四、代码实现

```python
sp = attn(x, dim=spatial)        # 帧内
tm = attn(sp, dim=temporal)       # 跨帧
```

## 五、与其他对比

- 比 3D 卷积更灵活捕捉长程；但算力高。
- 与 长上下文（注意力优化）共享稀疏化思想。

## 六、常见误区

- 纯空间注意力忽略运动建模。
- 时间注意力范围过短致长视频断裂。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh
- harvardnlp/annotated-transformer：https://github.com/harvardnlp/annotated-transformer

## 八、面试题

- 时空注意力如何降复杂度？答：分解为空间与 temporal 两条注意力，避免全 3D 两两计算。

## 九、演进

3D 卷积→分解注意力→高效窗口/状态空间。

## 十、小结

时空注意力是视频 Transformer 核心，分解策略决定可扩展性。
