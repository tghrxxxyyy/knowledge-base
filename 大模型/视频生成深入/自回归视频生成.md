# 自回归视频生成

> 对应 VideoPoet（Kondratyuk et al., 2023）；Sora 中 token 化思路。

## 一、背景与挑战

自回归逐段生成更可控/可流式，但需把视频变 token 且防漂移。

## 二、核心原理

用 VAE/Tokenizer 把视频压成离散/连续 token 序列，训练 Transformer 自回归预测下一段；可条件于文本/图像。

## 三、数学形式

似然分解 $p(x)=\prod_t p(x_t|x_{<t},c)$；训练交叉熵（离散）或回归（连续）。

## 四、代码实现

```python
tokens = vqvae.encode(video)        # [T, P]
logits = transformer(tokens[:, :-1])
```

## 五、与其他对比

- 比扩散易扩展长度、易条件化。
- 与 推理时计算（自回归）共享解码范式。

## 六、常见误区

- 长视频误差累积漂移；需周期性锚定。
- 忽视 tokenizer 压缩比影响质量。

## 八、面试题

- 自回归视频优缺点？答：可控流式，但长程漂移且需好 tokenizer。

## 九、演进

像素递归→VQ-VAE token→大模型自回归视频。

## 十、小结

自回归视频以 token 化+Transformer 实现可扩展生成，漂移是难点。
