# 视频生成总览

> 对应 Ho et al., *Video Diffusion Models*, 2022；Brooks et al., *Sora*, 2024。

## 一、背景与挑战

视频比图像多一维时间，需保证时序一致、运动连贯且高分辨率，数据与算力成本陡增。

## 二、核心原理

两大路线：扩散模型（在时空潜变量上去噪）与自回归（逐帧/块自回归）。常结合 VAE 压缩到潜空间再生成。

## 三、数学形式

扩散目标 $\mathcal L=\mathbb E_{t,x_0,\epsilon}[\|\epsilon-\epsilon_\theta(x_t,t)\|^2]$，其中 $x_0$ 为视频潜变量。

## 四、代码实现

```python
z = vae.encode(video)
noise = torch.randn_like(z)
pred = unet(z_noise, t, cond)
```

## 五、与其他对比

- 扩散质量高但慢；自回归快但易误差累积。
- 与 世界模型 / 神经渲染 共享时空建模。

## 六、常见误区

- 忽视时序一致性致闪烁/跳变。
- 误以为更多帧数线性增算力（实际近似平方）。

## 八、面试题

- 视频生成两大路线？答：扩散（时空去噪，质量高慢）与自回归（逐段生成，快但易漂）。

## 九、演进

GAN 视频→扩散视频→潜空间扩散+时空 patch。

## 十、小结

视频生成是时空联合建模高峰，一致性与效率是核心权衡。
