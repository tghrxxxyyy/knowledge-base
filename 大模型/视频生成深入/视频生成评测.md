# 视频生成评测

> 对应视频质量指标（FVD, IS）；人类对齐评测。

## 一、背景与挑战

视频质量含保真、时序一致、文本对齐，单一指标难覆盖。

## 二、核心原理

FVD 用 I3D 特征比较生成与真实分布；文本对齐用 CLIP/VQA；运动平滑用光流一致性；最终常加人工评。

## 三、数学形式

FVD $=\|\mu_r-\mu_g\|^2+\text{Tr}(\Sigma_r+\Sigma_g-2(\Sigma_r\Sigma_g)^{1/2})$（特征高斯距离）。

## 四、代码实现

```python
from torchmetrics.video import FrechetVideoDistance
fvd = FrechetVideoDistance()
score = fvd(pred, real)
```

## 五、与其他对比

- 与 模型评测指标深入 共享分布距离思路。
- 与 世界模型评测 互补。

## 六、常见误区

- FVD 对帧数/分辨率敏感，跨设置不可比。
- 仅信自动指标忽视主观质量。

## 八、面试题

- FVD 为何用视频特征而非像素？答：特征空间更贴语义/时序，像素距离对结构不敏感。

## 九、演进

IS→FVD→文本对齐+人类评。

## 十、小结

视频评测需多指标组合，自动与人工互补。
