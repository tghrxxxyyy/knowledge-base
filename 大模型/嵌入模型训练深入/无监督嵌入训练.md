# 无监督嵌入训练（SimCSE）

> 对应 Gao et al., *SimCSE*, 2021（ dropout 增广对比）。

## 一、背景与挑战

标注句对贵；如何用无标注语料训强句向量。

## 二、核心原理

同一句两次过 encoder（不同 dropout）得两视图作正例，批内其他句为负例；dropout 即最廉价的增广，使正例高度一致。

## 三、数学形式

$\mathcal L=-\log\frac{\exp(sim(h_i,h_i')/\tau)}{\sum_j\exp(sim(h_i,h_j)/\tau)}$，$h_i,h_i'$ 为同句两 dropout 视图。

## 四、代码实现

```python
h1 = model(sent, dropout=0.1); h2 = model(sent, dropout=0.1)
loss = infonce(h1, h2, others)
```

## 五、与其他对比

- 与 对比损失与InfoNCE 同框架、无需标注。
- 与 嵌入模型训练深入 总览衔接。

## 六、常见误区

- 两视图 dropout 相同致退化（须随机）。
- 批太小负例不足。

## 八、面试题

- SimCSE 正例从哪来？答：同句两次 dropout 输出作正例，无需标注。

## 九、演进

有监督对比 → SimCSE 无监督 → 大模型无监督嵌入。

## 十、小结

SimCSE 以 dropout 增广实现无监督句向量，是低成本强基线。
