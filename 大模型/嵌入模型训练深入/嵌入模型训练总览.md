# 嵌入模型训练总览

> 对应 Reimers & Gurevych, *Sentence-BERT*, 2019（句向量对比训练）；Wang et al., *SimCSE*, 2021。

## 一、背景与挑战

原生 BERT 句向量（CLS）各向异性、语义弱；需专门训练得各向同性可比较的句嵌入。

## 二、核心原理

以孪生/双塔编码句对，用对比/三元组损失拉相关句、推无关句；池化得定长向量；可在有标注或无标注数据上训练。

## 三、数学形式

对比目标 $\mathcal L=-\log\frac{\exp(sim(h_i,h_i^+)/\tau)}{\sum_{j}\exp(sim(h_i,h_j)/\tau)}$，$h$ 为句向量。

## 四、代码实现

```python
sim = F.cosine_similarity(e1, e2)
loss = F.cross_entropy(sim/tau, labels)
```

## 五、与其他对比

- 与 双塔模型深入（同架构）共享；与 稠密检索训练深入 衔接。
- 与 多向量检索深入（token 级）对照粒度。

## 六、常见误区

- 直接用 CLS 不微调致各向异性差。
- 未做白化/归一化排序不稳。

## 七、与开源书对应

## 八、面试题

- 为何需专门训练嵌入？答：原始 CLS 各向异性，对比训练得各向同性可比较向量。

## 九、演进

CBOW/平均 → SBERT 对比 → SimCSE/大模型嵌入。

## 十、小结

嵌入模型训练是语义表示基础，对比损失与池化决定质量。
