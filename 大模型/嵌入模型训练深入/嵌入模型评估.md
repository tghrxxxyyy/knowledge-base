# 嵌入模型评估（MTEB）

> 对应 Muennighoff et al., *MTEB*, 2022（大规模嵌入基准）；与 稠密检索评估 衔接。

## 一、背景与挑战

嵌入用途多样（检索/聚类/分类/句对），单一指标不够；需综合基准。

## 二、核心原理

MTEB 覆盖 8 类任务 56 数据集，报告平均分数；检索用 NDCG/Recall，聚类用 V-measure，句对用 Spearman。

## 三、数学形式

综合 $Score=\frac{1}{T}\sum_{t} \text{norm}(metric_t)$；跨任务归一化平均。

## 四、代码实现

```python
from mteb import MTEB
results = MTEB(tasks=["STS17","ArguAna"]).run(model)
```

## 五、与其他对比

- 与 稠密检索评估（BEIR）共享检索子集。
- 与 嵌入模型训练深入 闭环。

## 六、常见误区

- 只看总分忽略某任务短板（如聚类弱）。
- 基准污染（训练含测试分布）。

- MTEB 为何重要？答：综合多任务评嵌入通用性，避免单基准过拟合。

## 十、小结

MTEB 是嵌入通用性标尺，训练须以多任务验证。
