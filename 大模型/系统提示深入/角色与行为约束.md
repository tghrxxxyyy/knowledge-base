# 角色与行为约束

> 对应 Role Prompting（角色提示）；OpenAI Model Spec 行为准则。

## 一、背景与挑战

同一模型面对不同业务需切换专业角色与口吻，仅靠用户指令不稳定。

## 二、核心原理

在系统提示固定角色画像（身份、专业、语气、知识边界），用 few-shot 示例锚定风格；约束不越权、不虚构身份。

## 三、数学形式

角色先验 $P(y\mid x, r)$ 相对无角色 $P(y\mid x)$ 的 KL 差异衡量角色强度：$D_{KL}(P(\cdot\mid x,r)\|P(\cdot\mid x))$。

## 四、代码实现

```python
messages=[{"role":"system","content":"你是资深税务师，引用法规并标注年份。"},
          {"role":"user","content":"个人养老金如何抵税?"}]
```

## 五、与其他对比

- 与 系统提示总览 中“角色”项细化。
- 与 提示版本深入（按角色维护版本）衔接。

## 六、常见误区

- 角色与事实冲突（自称官方机构）致幻觉与信任风险。
- 角色口吻与输出格式要求冲突。

## 八、面试题

- 角色提示为何有效？答：激活模型对应风格/知识的子分布，稳定输出专业口吻。

## 九、演进

无角色 → 单一角色 → 多角色路由（按意图切系统提示）。

## 十、小结

角色约束是系统提示最常用的子能力，需防身份越权与幻觉。
