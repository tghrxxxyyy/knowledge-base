# 系统提示与对齐

> 对应 Ouyang et al., *InstructGPT*, 2022；RLHF 与指令对齐。

## 一、背景与挑战

对齐目标需在推理期由系统提示兜底（安全、有用、诚实），弥补训练对齐不足。

## 二、核心原理

系统提示承载对齐策略的可读层：声明价值观、拒答策略、纠错机制；与 RLHF 学到的内部偏好互补。

## 三、数学形式

对齐约束可写为带权重的正则：$\max_\theta \mathbb E[\log P_\theta(y\mid x,s)] - \lambda\, R_{harm}(y)$，系统提示强化 $R_{harm}$ 的先验。

## 四、代码实现

```python
system="你应有用、无害、诚实；涉及违法或隐私时明确拒答并说明理由。"
```

## 五、与其他对比

- 与 安全对齐深入 / 防御性提示深入 共享目标。
- 与 直接偏好优化深入 训练侧互补。

## 六、常见误区

- 认为系统提示可完全替代训练对齐（可被越狱绕过）。
- 安全声明与有用性冲突未给优先级。

## 八、面试题

- 系统提示能否替代对齐训练？答：不能，仅是推理期可读层，越狱可绕过，须与训练对齐协同。

## 九、演进

训练对齐 → 训练+系统提示 → 可配置对齐策略。

## 十、小结

系统提示是对齐的可读外层，须与训练侧对齐协同而非替代。
