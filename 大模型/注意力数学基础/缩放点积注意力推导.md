# 缩放点积注意力推导

> 见「注意力数学基础/注意力机制总览」；Vaswani et al., 2017。

## 一、背景与挑战

为何点积要除以 `√d_k`？不除会怎样？

## 二、核心原理

当 Q、K 各分量独立、均值 0、方差 1 时，点积 `Q·K` 的均值 0、方差 `d_k`。d_k 越大，点积方差越大，softmax 进入饱和区梯度趋零，训练困难。故除以 `√d_k` 将方差拉回 1。

## 三、数学形式

```
Attention(Q,K,V) = softmax(Q K^T / √d_k) V
```

## 四、代码实现

```python
import torch, torch.nn.functional as F
def scaled_dot(Q, K, V, mask=None):
    dk = Q.size(-1)
    s = Q @ K.transpose(-2, -1) / dk**0.5
    if mask is not None: s = s.masked_fill(mask == 0, -1e9)
    return F.softmax(s, -1) @ V
```

## 五、关键要点

- 缩放防止 softmax 饱和。
- 因果 mask 保证自回归只看见前文。
- softmax 对极大值敏感，故用 -1e9 屏蔽。

## 六、与其他对比

- 加性注意力（Bahdanau）不依赖维度缩放。

## 七、常见误区

- 忘记缩放——大模型训练不稳。
