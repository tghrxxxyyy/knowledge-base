# 多头注意力

> 见「注意力数学基础/缩放点积注意力推导」；Vaswani et al., 2017。

## 一、背景与挑战

单一注意力只能学一种关系视角，表达力有限。

## 二、核心原理

将 Q/K/V 线性投影到 h 个子空间，各自独立做缩放点积注意力，拼接后线性融合。每头关注不同类型依赖（句法/语义/位置）。

## 三、数学形式

```
MultiHead = Concat(head_1..head_h) W^O
head_i = Attention(Q W_i^Q, K W_i^K, V W_i^V)
```

## 四、代码实现

```python
# nn.MultiheadAttention 已实现；核心即多组投影
out = F.scaled_dot_product_attention(q, k, v)
```

## 五、关键要点

- 头数 h 常 8/12/16/32。
- 投影降维使总计算量与单头相近。
- 不同头确有专门化（ViT 等可视化证实）。

## 六、与其他对比

- 单头关注单一模式；多头多视角。

## 七、常见误区

- 头越多越好——过多收益递减甚至下降。
