# 注意力计算复杂度

> 见「高效注意力深入」与「注意力变体」；Dao et al., *FlashAttention*, 2022。

## 一、背景与挑战

标准注意力对序列长 N 复杂度 O(N²)，长上下文成本爆炸。

## 二、核心原理

- 时间复杂度：`O(N²·d)`（N² 个相似度 + 加权）。
- 显存：`O(N²)` 存注意力矩阵。
- **FlashAttention**（Dao et al., 2022）用分块与重计算，IO 感知将显存降至 O(N)，速度数倍提升，是当今训练标配。
- 高效变体（稀疏/线性）将复杂度降为 O(N) 或 O(N√N)。

## 三、数学形式

FLOPs ≈ `2·N²·d`；显存矩阵 `N×N`。

## 四、代码实现

```python
# PyTorch 2.x 原生融合
out = F.scaled_dot_product_attention(q, k, v)
```

## 五、关键要点

- N² 是长上下文主要瓶颈。
- FlashAttention 不改数学、只改实现顺序。

## 六、与其他对比

- 标准 O(N²)；线性注意力 O(N)。

## 七、常见误区

- 注意力慢在算力——其实更受显存带宽限制。
