# 注意力机制总览

> 对应 harvardnlp/annotated-transformer 与 d2l-zh「注意力」章；Vaswani et al., *Attention Is All You Need*, 2017。

## 一、背景与挑战

RNN 难以并行且长程依赖衰减；注意力让任意两位置直接交互，是 Transformer 基石。

## 二、核心原理

注意力用「查询 Q 与键 K 的相似度」对值 V 做加权求和：相似键获得更高权重，实现内容寻址的记忆读取。

## 三、数学形式

基础加性/点积注意力；见「缩放点积注意力推导」。

## 四、代码实现

```python
scores = Q @ K.T / sqrt(d_k)
attn = softmax(scores) @ V
```

## 五、关键要点

- 注意力是软查表，权重和为 1。
- 多头提供多子空间表示。
- 复杂度随序列长平方增长。

## 六、与其他对比

- RNN 串行、有遗忘；注意力全局、可并行。

## 七、常见误区

- 注意力=记忆——它只是加权聚合。
