# 反思记忆与经验复用

> 对应 Shinn et al., *Reflexion*, NeurIPS 2023；Zhao et al., *ExpeL: LLM Agents Are Experiential Learners*, AAAI 2024。

## 一、背景与挑战

单次反思的教训若随会话结束而丢失，智能体会在同类任务上重复同样的错误。
经验复用要解决三个问题：什么值得记、如何检索到相关经验、如何避免过时或错误经验被反复强化。

## 二、核心原理

- 抽取：从成功与失败轨迹中提炼可迁移规则（前置条件、常见坑、有效动作序列），而非保存原始长轨迹。
- 检索：以当前任务描述与状态为查询，从经验库召回少量高相关条目注入提示，等价于面向决策的 RAG。
- 治理：为经验条目记录来源、命中次数与成功率，低效或冲突条目降权淘汰，防止经验库退化为噪声堆。

## 三、数学形式

经验条目 $e$ 的效用可用命中后成功率的后验估计：$\hat u(e)=\frac{s_e+\alpha}{n_e+\alpha+\beta}$（Beta 先验平滑）。

检索排序综合相关性与效用：$\text{score}(e)=\lambda\,\text{sim}(q,e)+(1-\lambda)\hat u(e)$，避免只按语义相似召回无效经验。

## 四、代码实现

```python
def recall_experience(store, task, k=4, lam=0.7):
    scored = [(lam * cos(embed(task), e.vec) + (1 - lam) * e.utility(), e)
              for e in store]
    return [e for _, e in sorted(scored, reverse=True)[:k]]

def commit_experience(store, traj, reward, llm):
    rule = llm(f"从轨迹提炼一条可复用规则:\n{traj}\n结果奖励={reward}")
    store.append(Experience(rule, vec=embed(rule)))
```

## 五、与其他对比

- 与智能体记忆与状态管理：那里关注会话内状态与长期事实；此处关注策略性经验（怎么做更好）。
- 与参数化学习（微调）：经验库可解释可编辑、即时生效；微调泛化更强但迭代慢，成熟经验可回流成训练数据。

## 六、常见误区

- 只记失败教训不记成功套路，导致智能体保守但不高效。
- 经验条目写成具体实例（含具体 ID 与数值），无法迁移到新实例，应抽象成条件—动作规则。
- 无冲突消解机制，两条相反经验同时命中让模型摇摆。

## 八、面试题

- 经验库和向量记忆有何区别？答：经验库存的是策略性规则并带效用统计，检索需兼顾相关性与历史有效性，而非纯语义相似。
- 如何防止错误经验固化？答：记录命中后的成功率做后验估计，低效降权淘汰，并对来源不可靠的条目设置有效期。

## 九、演进

一次性反思 → 会话内记忆 → 跨任务经验库（ExpeL）→ 带效用统计的经验治理 → 经验回流微调。

## 十、小结

反思的长期价值来自复用：抽象成规则、按效用检索、按证据淘汰，智能体才会真正越用越好。
