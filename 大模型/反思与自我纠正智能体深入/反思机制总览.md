# 反思与自我纠正总览

> 对应 Shinn et al., *Reflexion*, NeurIPS 2023；Madaan et al., *Self-Refine*, NeurIPS 2023；Huang et al., *Large Language Models Cannot Self-Correct Reasoning Yet*, ICLR 2024。

## 一、背景与挑战

单次采样的智能体一旦在早期步骤出错，后续推理会沿错误分支自洽地走到底。
反思（reflection）试图引入「再看一遍并改」的能力，但学界同时给出了警示：缺乏外部信号时，自我纠正常常只是换个说法甚至把对的改错。

## 二、核心原理

- 三要素：生成器产出候选、评价器给出批评、修订器基于批评重写；三者可以是同一模型的不同提示，也可以异构。
- 反馈信号的来源决定天花板：单元测试、编译器、检索证据、环境奖励属于外部可验证信号；模型自评属于内部信号，噪声大。
- 反思应产生可执行的差异（改哪一步、为什么），把批评落成结构化条目比自由文本更有效。

## 三、数学形式

迭代修订可写作 $y^{(k+1)}=\mathcal R(x,y^{(k)},c^{(k)})$，其中 $c^{(k)}=\mathcal C(x,y^{(k)},o^{(k)})$ 为批评，$o$ 为外部观测。

期望收益 $\mathbb E[\Delta]=P(\text{检出真错})\cdot g-P(\text{误判对为错})\cdot h$：当评价器精度不足时 $\mathbb E[\Delta]$ 可为负，这正是自纠失效的量化解释。

## 四、代码实现

```python
def reflect_loop(gen, critic, verify, x, k=3):
    y = gen(x)
    for _ in range(k):
        ok, obs = verify(y)            # 外部可验证信号优先
        if ok:
            return y
        c = critic(x, y, obs)          # 结构化批评
        y = gen(x, prior=y, critique=c)
    return y
```

## 五、与其他对比

- 与自我一致性（多数投票）：投票靠采样多样性抵消随机错误，不需要评价器；反思靠定向修正，能改系统性错误但依赖反馈质量。
- 与 RLHF：RLHF 把偏好压进权重，推理期零开销；反思在推理期花算力换质量，无需训练。

## 六、常见误区

- 认为「让模型检查一遍」总能提升；无外部信号时在推理任务上常无提升甚至退化。
- 把反思轮数当旋钮无脑加大，实际多数收益集中在前一两轮，之后是成本线性增长与漂移风险。
- 批评与修订用同一段上下文且不隔离，模型倾向于为原答案辩护而非发现错误。

## 八、面试题

- 自我纠正何时可靠？答：存在外部可验证反馈（测试、编译、检索证据、环境奖励）时可靠；仅靠模型自评时收益不稳定。
- 如何降低把对答案改错的风险？答：设置修订门槛（批评需给出具体证据）、保留原答案并在最终做择优，而非无条件覆盖。

## 九、演进

单次采样 → 多样采样投票 → 自评式反思 → 外部反馈闭环（测试/检索）→ 反思记忆跨任务复用。

## 十、小结

反思不是免费的智力提升，而是把算力换成纠错概率；反馈越客观，这笔交易越划算。
