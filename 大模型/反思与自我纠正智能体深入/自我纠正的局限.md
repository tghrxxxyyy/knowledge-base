# 自我纠正的局限

> 对应 Huang et al., *Large Language Models Cannot Self-Correct Reasoning Yet*, ICLR 2024；Stechly et al., *GPT-4 Doesn't Know It's Wrong*, 2023（自评局限）。

## 一、背景与挑战

早期结果给人「让模型自查即可提升」的印象，但严格对照实验显示：在没有正确答案作为停止信号时，自我纠正在推理任务上常常无益。
理解失效机理，才能判断何时该投入反思算力、何时该改造反馈来源。

## 二、核心原理

- 检错能力与生成能力同源：模型不知道自己错在哪的原因与它生成错误的原因相同，二者误差高度相关。
- 存在信息泄漏陷阱：若实验用「答案错才继续改」的停止条件，实质引入了标签信息，收益并非来自自纠。
- 自评还受表面特征影响（长度、措辞自信度），导致把正确但简洁的答案判为需要修改。

## 三、数学形式

设检错概率为 $\alpha$（真错判错）、误报概率为 $\beta$（真对判错），修订成功率 $\gamma$，则一轮净收益近似 $\Delta=\alpha\gamma(1-p)-\beta\delta p$。

其中 $p$ 为初始正确率、$\delta$ 为改坏概率：当 $p$ 已较高时，$\beta\delta p$ 项主导，自纠期望为负。

## 四、代码实现

```python
def audit_self_correction(llm, dataset, k=1):
    stats = {"fixed": 0, "broken": 0}
    for x, gold in dataset:                 # 评测时不得用 gold 决定是否继续改
        y0 = llm(x)
        y1 = refine(llm, x, y0, k)
        ok0, ok1 = (answer_of(y0) == gold), (answer_of(y1) == gold)
        stats["fixed"] += (not ok0) and ok1
        stats["broken"] += ok0 and (not ok1)
    return stats
```

## 五、与其他对比

- 与外部反馈纠错（编译器、测试、检索）：外部信号与模型误差不相关，因此能带来稳定增益。
- 与多智能体互评：不同模型的误差相关性更低，互评比单模型自评更接近独立裁判，但成本更高。

## 六、常见误区

- 用「知道答案错才重试」的实验设计得出自纠有效的结论，属于评测泄漏。
- 把自评分数当作可信置信度用于路由或拒答，未做校准会系统性误判。
- 忽略改坏率：只报「修好了多少」不报「改坏了多少」，结论不成立。

## 八、面试题

- 为什么自评难以超越自身生成能力？答：检错与生成共享同一表示与偏差，误差高度相关，缺少独立信息源。
- 怎样正确评测自我纠正？答：停止条件不得使用金标签，同时同时报告修好率与改坏率及净收益。

## 九、演进

乐观自纠报告 → 严格对照实验揭示失效 → 强调外部可验证反馈 → 多模型互评与工具裁判 → 校准置信度驱动的选择性纠错。

## 十、小结

自我纠正不是能力涌现而是信息问题：没有独立反馈就没有稳定增益，评测设计必须排除标签泄漏。
