# 自我一致性与验证器

> 对应 Wang et al., *Self-Consistency Improves Chain of Thought Reasoning*, ICLR 2023；Cobbe et al., *Training Verifiers to Solve Math Word Problems*, 2021。

## 一、背景与挑战

链式推理的错误常来自采样随机性：同一问题多次采样，推理路径不同但正确路径往往占多数。
如何在无标签的推理时利用这种冗余，是自我一致性与验证器路线共同回答的问题。

## 二、核心原理

- 自我一致性：以较高温度采样多条推理链，只对最终答案做边缘化投票，路径不同但答案相同即互相印证。
- 验证器（verifier）：训练一个判别模型给候选解打分，推理时对 $N$ 个候选排序取最优，属于结果监督的判别式利用。
- 二者可组合：先投票聚合，再用验证器在票数接近时打破平局，或用验证器加权投票。

## 三、数学形式

自我一致性取 $\hat y=\arg\max_{a}\sum_{i=1}^{N}\mathbb{1}[\text{ans}(z_i)=a]$，即对隐变量推理链 $z$ 做蒙特卡洛边缘化 $P(a\mid x)=\sum_z P(a,z\mid x)$。

验证器排序取 $\hat y=\arg\max_i V_\phi(x, y_i)$；加权投票为 $\arg\max_a \sum_i V_\phi(x,y_i)\mathbb{1}[\text{ans}(y_i)=a]$。

## 四、代码实现

```python
from collections import Counter

def self_consistency(llm, x, n=16, temp=0.7, verifier=None):
    cands = [llm(x, temperature=temp) for _ in range(n)]
    if verifier is None:
        return Counter(answer_of(c) for c in cands).most_common(1)[0][0]
    votes = Counter()
    for c in cands:
        votes[answer_of(c)] += verifier(x, c)      # 验证器加权投票
    return votes.most_common(1)[0][0]
```

## 五、与其他对比

- 与反思：投票不需要评价器且不会把对的改错，风险低但只能纠随机错误；反思能纠系统性错误但可能反向。
- 与过程监督（PRM）：PRM 对中间步骤打分，可在生成中剪枝；结果验证器只在末端排序，信息更稀疏但标注更便宜。

## 六、常见误区

- 温度设过低导致采样同质化，投票失去意义；需要足够多样性才有互相印证价值。
- 对开放式生成任务硬做投票：答案不可归一化时无法计票，应改用成对比较或验证器打分。
- 只看准确率忽略成本：$N$ 倍采样意味着 $N$ 倍推理开销，需评估性价比拐点。

## 八、面试题

- 自我一致性为何有效？答：它对推理路径这一隐变量做边缘化，正确答案在多条路径上更容易重合，随机错误被稀释。
- 验证器与投票如何结合？答：用验证器分数作为投票权重，或在票数接近时以验证器打破平局，兼顾冗余与判别力。

## 九、演进

贪心解码 → 多样采样投票 → 训练结果验证器排序 → 过程验证器逐步剪枝 → 搜索与验证联合（树搜索加 PRM）。

## 十、小结

自我一致性用采样冗余换正确率，验证器把冗余变成可排序信号，两者是推理期最稳的质量杠杆。
