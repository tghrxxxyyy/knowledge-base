# 质量与 Schema 校验

> 见「数据治理血缘深入/数据治理总览」与「训练数据质量」；数据质量门禁。

## 一、背景与挑战

脏数据进训练，模型学歪且难排查。

## 二、核心原理

在入湖/入训练前设质量门禁：schema 校验（字段类型/必填）、分布校验（均值/缺失率漂移）、业务规则（范围/唯一）、重复检测。异常阻断或告警。大模型语料需语言/毒性/隐私过滤流水线。

## 三、关键要点

- 门禁前置省下游成本。
- 阈值需随数据分布更新。

## 四、代码实现

```python
from great_expectations import check
assert check(df, "col", "not_null") and check(df, "age", "between 0 120")
```

## 五、与其他对比

- 事后发现贵；事前门禁省。

## 六、常见误区

- 一次性校验够——分布会漂移。
