# 数据版本控制

> 见「数据治理血缘深入/数据治理总览」与「可复现性工程深入/数据与版本管理」；DVC/lakeFS。

## 一、背景与挑战

数据集不断演化，需回滚与比对。

## 二、核心原理

像 git 一样对数据做提交：每次变更生成版本（基于内容哈希），可 checkout 历史版本、做分支实验（lakeFS 支持数据分支）。大模型语料库常用此管理多版清洗/配比。

## 三、关键要点

- 版本=不可变快照。
- 分支实验隔离污染。

## 四、代码实现

```bash
lakectl branch create lakefs://repo@main repo@exp1
```

## 五、与其他对比

- 复制文件夹易乱；版本控制有序。

## 六、常见误区

- 靠日期命名版本——难追溯。
