# 图捕获与重放

> 对应 CUDA Graph capture/replay API 语义。

## 一、背景与挑战

捕获期需屏蔽非确定性/动态行为，重放期需仅改输入张量。

## 二、核心原理

在 `cudaStreamCaptureMode` 下执行前向，记录节点与依赖形成图；重放时通过 `graph.exec` 一次性下发。输入经 registered 张量原地更新，避免重建图。

## 三、数学形式

图节点集 $V=\{k_1..k_n\}$，边 $E$ 为数据流依赖；重放即拓扑序执行 $V$。

## 四、代码实现

```python
with torch.cuda.graph(static_graph):
    out = model(inp)   # 仅捕获一次
out = model(inp)       # 之后重放
```

## 五、与其他对比

- 与 推理CUDA图优化深入 总览衔接。
- 与 Triton内核自动调优深入（手工内核亦可用图）互补。

## 六、常见误区

- 捕获中调用 printf/同步致捕获失败。
- 重放时改形状未重捕获致越界。

- 重放为何快？答：跳过 CPU 端逐节点下发，一次提交整图给驱动。

## 九、演进

空捕获 → 流捕获 → 图实例化复用。

## 十、小结

捕获一次、重放多次是图优化的标准范式，正确性依赖固定控制流。
