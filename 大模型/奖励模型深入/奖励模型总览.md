# 奖励模型总览

> 对应 RLHF 奖励模型（Christiano et al., 2017；Ouyang et al., 2022）；RLHF与偏好优化实战（文件）衔接。

## 一、背景与挑战

强化学习需标量奖励指导；人工标注贵，奖励模型（RM）从偏好学习代理奖励。

## 二、核心原理

RM 在参考模型上加标量头，训为 Bradley-Terry 偏好概率；RLHF 中 PPO 用其给分。

## 三、数学形式

$r_\phi(x,y)=\text{RM}_\phi(x,y)$；偏好似然 $\sigma(r(x,y_w)-r(x,y_l))$；损失为交叉熵。

## 四、代码实现

```python
rw = rm(chosen) - rm(rejected)
loss = -F.logsigmoid(rw).mean()
```

## 五、与其他对比

- 与 直接偏好优化深入（DPO 消去 RM）对照。
- 与 PPO对齐深入（RM 被 PPO 用）衔接。

## 六、常见误区

- RM 过拟合标注偏见（reward hacking）。
- 忽视 RM 校准（分数尺度漂移）。

## 八、面试题

- 奖励模型作用？答：从人类偏好学标量奖励，供 PPO 优化策略。

## 九、演进

人工奖励 → 学习 RM → 多目标 RM / 宪法 RM。

## 十、小结

奖励模型是 RLHF 的偏好代理，质量直接决定对齐方向。
