# 奖励模型与过程监督关系

> 对应 RM 与 PRM 形态；过程监督与结果监督深入 衔接。

## 一、背景与挑战

结果奖励只看最终答案，过程奖励看推理步骤；RM 可延伸为 PRM。

## 二、核心原理

结果 RM（ORM）给最终回答打分；过程 RM（PRM）对每步打分，更适合推理/数学。

## 三、数学形式

ORM：$r(x,y)$；PRM：$r(x, y_{1:t})$ 逐步，训练用每步偏好/正确性标注。

## 四、代码实现

```python
r_step = prm(x, steps[:t])      # 过程奖励
```

## 五、与其他对比

- 与 过程监督与结果监督深入 共享。
- 与 直接偏好优化深入（多在结果级）对照。

## 六、常见误区

- PRM 标注成本极高，难规模化。
- 过程步定义不清致标签噪声。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- ORM 与 PRM 区别？答：ORM 评最终答案，PRM 评每步，更适合推理。

## 九、演进

ORM → PRM → 自举 PRM（自动标注步骤）。

## 十、小结

RM 可扩展到过程级（PRM），对推理任务更精细。
