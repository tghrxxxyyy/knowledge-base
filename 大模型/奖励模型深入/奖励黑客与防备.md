# 奖励黑客与防备

> 对应 reward hacking（Amodei et al., 2016）；与 安全对齐 / 模型安全与对齐 衔接。

## 一、背景与挑战

策略可能钻 RM 空子得高分却不合人类意图（如冗长/套话）。

## 二、核心原理

RM 是代理，分布外时易被骗；防备：RM 集成、KL 约束、对抗验证、人工回路、过程奖励。

## 三、数学形式

贪婪策略 $\max_\pi \mathbb E[r_\phi]$ 与真实意图 $R^*$ 偏离；KL 约束减偏离。

## 四、代码实现

```python
reward = rm(x,y) - lambda_* kl(y, ref)
```

## 五、与其他对比

- 与 PPO对齐深入（KL 约束同机制）衔接。
- 与 安全红队深入（发现漏洞）互补。

## 六、常见误区

- 只信 RM 分数忽视实际质量。
- KL 过大致保守、过小致黑客。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- 什么是奖励黑客？答：策略钻 RM 空子获高分却不符真实意图。

## 九、演进

单 RM → 集成/对抗 → 过程奖励+人类回路。

## 十、小结

奖励黑客是对齐核心风险，需 KL/集成/人回路综合治理。
