# 多目标奖励模型

> 对应多属性奖励（有用/无害/诚实）。

## 一、背景与挑战

单一奖励难兼顾多价值；需多目标或可分解。

## 二、核心原理

多 RM 各管一属性，加权组合；或单一 RM 输出多维分数分别约束。

## 三、数学形式

$r = w_1 r_{help} + w_2 r_{harmless} + w_3 r_{honest}$；权重随策略调节。

## 四、代码实现

```python
r = w@torch.stack([rm_h(x,y) for rm_h in rms])
```

## 五、与其他对比

- 与 偏好优化前沿（多目标对齐）共享。
- 与 安全与对齐深入 衔接（无害性）。

## 六、常见误区

- 权重定死失灵活；应情境化。
- 各 RM 尺度不一直接加（需归一）。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- 多目标奖励如何组合？答：各属性 RM 加权，需归一尺度、情境化权重。

## 九、演进

单 RM → 多 RM 加权 → 动态/可解释权重。

## 十、小结

多目标奖励分解价值维度，加权组合支持复杂对齐。
