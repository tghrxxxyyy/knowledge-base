# 矩阵半可分结构

> 对应 Mamba2 2024 中对 SSM 的半可分（semi-separable）矩阵刻画。

## 一、背景与挑战

要理解 SSD 高效性的本质，需把 SSM 输出写成矩阵乘并刻画该矩阵的结构约束。

## 二、核心原理

选择性 SSM 的关联矩阵是半可分矩阵：下三角部分可因子为低秩（状态维 $N$）乘积，上三角为零（因果），据此可高效乘。

## 三、数学形式

$M_{ij}=C_i^\top A_{i:j} B_j$（$i\ge j$），秩至多 $N$；整矩阵乘可用低秩因子链计算，复杂度随 $N$ 线性。

## 四、代码实现

```python
# 半可分乘：因果前缀累积低秩因子
h = zeros(N)
for i in range(L):
    h = A[i] @ h + B[i] * u[i]
    y[i] = C[i] @ h
```

## 五、与其他对比

- 与 线性注意力近似方法深入 共享“低秩/半可分”数学本质，但 SSM 带状态递推解释。
- 与 Mamba1 扫描等价，只是改写视角。

## 六、常见误区

- 把半可分当一般低秩；它还有因果三角与因子链式结构。
- 忽略 $N$（状态维）决定半可分秩，是效率与表达的核心旋钮。
