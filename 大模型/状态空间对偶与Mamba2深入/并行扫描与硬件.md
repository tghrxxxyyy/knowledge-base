# 并行扫描与硬件感知

> 对应 Blelloch, *Prefix Sums and Their Applications*, 1990（并行扫描）与 Mamba/Mamba2 硬件实现。

## 一、背景与挑战

递归本串行；要在 GPU 上万级序列高效计算，需并行化前缀（扫描）并减少 HBM 访存。

## 二、核心原理

用 work-efficient 并行扫描做前缀积，并把状态保持在 SRAM 分块计算，避免反复读写 HBM，类似 FlashAttention 的 IO 思想。

## 三、数学形式

前缀积 $P_k=A_k A_{k-1}\cdots A_1$ 可在 $O(\log n)$ 并行深度算出；再与输入结合得输出，总工作 $O(n)$。

## 四、代码实现

```python
# 两趟扫描（up-sweep / down-sweep）求前缀积
for d in range(log2(L)):
    P = P + shift(P, 2**d) @ A[d]
```

## 五、与其他对比

- 与 FlashAttention 的“分块减 IO”同源异构：一个为注意力、一个为扫描。
- 与 稀疏注意力算法深入 都旨在把 $O(n^2)$ 操作变可扩。

## 六、常见误区

- 朴素递归在 GPU 被串行拖累；必须并行扫描或 SSD 分块。
- 忽视 SRAM/HBM 带宽瓶颈，仅优化 FLOPs 无效。

## 八、面试题

- 为何 SSM 需并行扫描？答：递归串行受限 GPU，并行前缀扫描把 $O(n)$ 工作摊到多线程。

## 九、演进

串行递归 → 并行扫描 → SSD 分块内核（更优 IO）。

## 十、小结

并行扫描与硬件感知 IO 是 SSM 实用的关键，与 FlashAttention 思想共振。
