# 状态空间对偶（SSD）总览

> 对应 Dao & Gu, *Transformers are SSMs: Generalized Models and Efficient Parallel Inference for SSMs (Mamba2)*, 2024。

## 一、背景与挑战

选择性 SSM 虽强，但实现依赖串行扫描、张量并行不友好；需一个既保留选择性又利于硬件并行的统一视角。

## 二、核心原理

SSD 证明选择性 SSM 可重述为“半可分矩阵”的线性注意力形式，从而用矩阵乘法 + 分块递归高效计算，并与注意力对偶。

## 三、数学形式

输出可写为 $Y=(L\odot M) V$，其中 $L$ 为半可分低秩矩阵，等价于结构化线性注意力，从而与 softmax 注意力共享框架。

## 四、代码实现

```python
# SSD 分块：块内矩阵乘，块间状态传递
Y_block = L_local @ V_block + state_h @ V_prefix
```

## 五、与其他对比

- 与 Mamba1 的选择性 SSM 是同一模型的不同计算视图。
- 与 选择性状态空间模型深入 互补：本篇侧重算法/对偶而非动机。

## 六、常见误区

- 认为 SSD 是新架构；它是对 Mamba 的统一重述，换更优计算。
- 忽略半可分结构才是高效性的数学来源。
