# 层归一化总览

> 对应 Ba, Kiros, Hinton, *Layer Normalization*, 2016；以及 Vaswani et al., 2017 在 Transformer 中的采用。

## 一、背景与挑战

Batch Normalization 依赖 batch 维度统计，在序列/小 batch/变长输入下不稳定；RNN/Transformer 需要跨特征维度归一化。

## 二、核心原理

LayerNorm 在单个样本的特征维度上做标准化：减均值除标准差，再线性缩放平移（$\gamma,\beta$），使每样本各隐藏单元分布稳定，与 batch 大小无关。

## 三、数学形式

$\hat x_i = \frac{x_i - \mu}{\sqrt{\sigma^2+\epsilon}}$，$\mu=\frac1H\sum x_j$，$\sigma^2=\frac1H\sum(x_j-\mu)^2$；$y_i=\gamma_i\hat x_i+\beta_i$。

## 四、代码实现

```python
import torch.nn as nn
ln = nn.LayerNorm(d_model)
out = ln(x)                      # 沿最后一维归一化
```

## 五、与其他对比

- 与 BatchNorm 相比不依赖 batch 统计，更适合 NLP/生成。
- 与 RMSNorm（见下）相比多算均值，略贵。

## 六、常见误区

- 把 LayerNorm 误当 BatchNorm 在 batch 维归一，导致训练异常。
- 忽略 $\epsilon$ 防除零，极端值下不稳。

## 八、面试题

- 为何 Transformer 用 LayerNorm 而非 BatchNorm？答：序列任务 batch 维不稳定，LayerNorm 沿特征维归一、与 batch 无关。

## 九、演进

BatchNorm → LayerNorm → RMSNorm/Pre-LN 变体。

## 十、小结

LayerNorm 是 Transformer 稳定性的基石，沿特征维归一、摆脱 batch 依赖。
