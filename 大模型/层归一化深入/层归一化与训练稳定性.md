# 层归一化与训练稳定性

> 对应 Xiong et al., 2020；以及 Liu et al., *Understanding and Improving Transformer From a Multi-Particle Dynamic System View*, 2020。

## 一、背景与挑战

深层 Transformer 训练常遇梯度消失/爆炸、损失尖峰（loss spike），归一化位置与初始化是关键。

## 二、核心原理

LayerNorm 约束每样本激活尺度，使残差叠加不会无界增长；Pre-LN 进一步让恒等路径占优，缓解深层梯度衰减；配合缩放初始化（如 $1/\sqrt{2N}$）可消除 loss spike。

## 三、数学形式

深层残差 $x^{(L)} = x^{(0)} + \sum_l Sublayer_l(\cdot)$；LN 使每项方差有界，避免 $\|x^{(L)}\|$ 随 $L$ 线性膨胀。

## 四、代码实现

```python
# 深层稳定初始化：缩放残差分支
h = x + (attn(ln1(x)) * (1.0 / math.sqrt(2 * n_layers)))
```

## 五、与其他对比

- 与 相对位置编码深入 同属训练稳定性要素。
- 与 RMSNorm 结合进一步降方差。

## 六、常见误区

- 仅加 LN 不调初始化，极深模型仍可能 loss spike。
- 把训练不稳全归咎 LR，忽视归一/初始化耦合。

## 八、面试题

- LN 如何帮助深层训练？答：约束激活尺度、稳定残差方差，防止梯度随深度衰减或爆炸。

## 九、演进

无归一 → Post-LN → Pre-LN → 缩放初始化消 spike。

## 十、小结

层归一化与初始化协同决定深层稳定，是训练大模型的前提。
