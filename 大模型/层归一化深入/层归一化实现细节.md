# 层归一化实现细节

> 对应主流框架 `nn.LayerNorm` 的 `elementwise_affine` 与 `eps` 设计；LLaMA 用 RMSNorm 替代。

## 一、背景与挑战

工程上需处理归一化维度选择（最后一维 vs 所有非 batch 维）、融合 kernel、精度（fp16/bf16）与 affine 参数。

## 二、核心原理

要点：`normalized_shape` 指定归一维度；`elementwise_affine` 控制是否学 $\gamma,\beta$；`eps` 防除零；大模型常融合 LN+RMSNorm 到注意力 kernel 以省显存带宽。

## 三、数学形式

$y = \gamma \odot \frac{x-\mu}{\sqrt{\sigma^2+\epsilon}} + \beta$；融合实现把减均值/除标准差与相邻矩阵乘合并。

## 四、代码实现

```python
ln = nn.LayerNorm(d, eps=1e-5, elementwise_affine=True)
y = ln(x)                              # 沿 d 维；affine 默认 True
# 大模型常自定义 fused RMSNorm 减少 HBM 读写
```

## 五、与其他对比

- 与 FlashAttention深入 的融合思想一致：减少中间激活读写。
- 与 RMSNorm 实现近乎相同，仅少一步减均值。

## 六、常见误区

- `normalized_shape` 设错维度导致形状不匹配。
- fp16 下 $\epsilon$ 过小致溢出，宜用 bf16。

## 八、面试题

- 实现 LN 要注意什么？答：归一维度、affine、eps 与精度，融合可省带宽。

## 九、演进

原生 LN → 融合 kernel → RMSNorm 替代。

## 十、小结

层归一化的工程价值在融合与精度控制，大模型下常以 RMSNorm 融合实现。
