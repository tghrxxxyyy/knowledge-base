# 快照集成（Snapshot Ensembles）

> 对应 Huang et al., *Snapshot Ensembles*, ICLR 2017；与 周期性学习率深入 衔接。

## 一、背景与挑战

集成需训多个模型成本高；快照集成借周期 lr 在单次训练中采多个局部极小。

## 二、核心原理

用带重启的余弦退火（SGDR），每个周期末损失盆地给出一“快照”，多个快照集成提升泛化。

## 三、数学形式

每个周期 $T_i$ 用 cosine 退火，重启 $\eta$ 回到高值，得到 $M$ 个权重快照 ensemble。

## 四、代码实现

```python
for cyc in range(M):
    train_cosine_restart(); snapshots.append(copy(model))
```

## 五、与其他对比

- 与 周期性学习率深入 同用振荡，但目标在“采多个模型”。
- 与 余弦退火深入（单次收敛）形成对照。

## 六、常见误区

- 周期过短快照间相关性高，集成增益低。
- 误把中途快照当最终模型。

## 八、面试题

- 快照集成省在哪？答：单次训练靠周期 lr 采多个局部极小，免去多次独立训练。

## 九、演进

多模型集成 → SGDR 快照 → 自由集成。

## 十、小结

快照集成用周期 lr 在单训中得多模型，性价比高。
