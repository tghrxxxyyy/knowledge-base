# 退火三角策略

> 对应 Smith, 2017 的 exp_range；与 学习率与批大小缩放深入 衔接。

## 一、背景与挑战

希望周期性探索同时整体趋稳；退火三角即在振荡上叠加缓慢衰减。

## 二、核心原理

exp_range：每步在上界乘衰减因子 $\gamma^t$，使振荡包络整体下降，末段接近收敛。

## 三、数学形式

$\eta_t^{upper}=\eta_{high}\gamma^t$；实际 $\eta_t=\eta_{low}+(\eta_t^{upper}-\eta_{low})\cdot\text{tri}$。

## 四、代码实现

```python
CyclicLR(opt, base_lr=1e-4, max_lr=1e-3, mode="exp_range", gamma=0.999)
```

## 五、与其他对比

- 介于纯周期与单调衰减之间，融合二者优点。
- 与 余弦退火深入 都最终收敛但路径不同。

## 六、常见误区

- $\gamma$ 过小振荡过早消失。
- 与 warmup 重复导致初期过慢。
