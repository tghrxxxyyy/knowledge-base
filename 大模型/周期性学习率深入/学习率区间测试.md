# 学习率区间测试（LR Range Test）

> 对应 Smith, 2017；与 调度调参经验深入 衔接。

## 一、背景与挑战

CLR 的上下界需先确定；LR range test 以单次实验定位合理区间。

## 二、核心原理

学习率从极低指数升到极高，记录 loss；取 loss 下降最快且平稳的区段作上下界。

## 三、数学形式

$\eta$ 按 $\eta_{t+1}=\eta_t\cdot\alpha$ 指数增长；最优界取 loss 曲线拐点附近。

## 四、代码实现

```python
lr_finder(model, data, end_lr=10, num_iter=200)
```

## 五、与其他对比

- 与 预热与退火组合深入 互补：先 range test 定界再定配方。
- 与 周期性学习率总览深入 同属 Smith 体系。

## 六、常见误区

- 测试步数太少曲线不可信。
- 直接取最小 loss 点而非平稳下降段。
