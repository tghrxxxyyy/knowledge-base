# 三角与三角2策略

> 对应 Smith, 2017 的 triangular / triangular2；与 周期性学习率总览深入 衔接。

## 一、背景与挑战

振荡形状决定探索-利用平衡；需选合适波形。

## 二、核心原理

triangular：每半周期线性升/降回原界；triangular2：每周期峰值减半，逐步收窄探索。

## 三、数学形式

triangular2 峰值 $\eta_{high}^{(k)}=\eta_{high}/2^k$（$k$ 为周期序号），幅度逐周期收缩。

## 四、代码实现

```python
CyclicLR(opt, base_lr=1e-4, max_lr=1e-3, mode="triangular2")
```

## 五、与其他对比

- triangular 全程探索，triangular2 后期收敛。
- 与 余弦退火深入 相比更强调探索阶段。

## 六、常见误区

- triangular 跑太久不收敛。
- 上下界过窄退化成近似常数。

## 八、面试题

- triangular2 与 triangular 区别？答：后者峰值恒定，前者每周期减半、逐步收敛。

## 九、演进

triangular → triangular2 → exp_range。

## 十、小结

三角策略以形状控制探索强度，triangular2 兼顾探索与收敛。
