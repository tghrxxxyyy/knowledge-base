# 周期性学习率总览

> 对应 Smith, *Cyclical Learning Rates*, 2017；与 学习率调度总览深入 衔接。

## 一、背景与挑战

固定/单调衰减易陷局部极小；周期性在边界间振荡，帮助跳出并探索更好吸引盆。

## 二、核心原理

学习率在预设上下界间按周期循环变化，而非单调下降；配合短 warmup 即可。

## 三、数学形式

$\eta_t = \eta_{low} + (\eta_{high}-\eta_{low})\cdot\text{cycle}(t)$；cycle 为三角等形状。

## 四、代码实现

```python
sched = CyclicLR(opt, base_lr=1e-4, max_lr=1e-3, step_size_up=2000)
```

## 五、与其他对比

- 与 余弦退火深入 相反：后者单调收敛，CLR 持续振荡探索。
- 与 预热与退火组合深入 哲学不同。

## 六、常见误区

- 振幅过小无探索效果，过大破坏收敛。
- 误当最终收敛策略。

## 八、面试题

- 周期性 lr 为何有助训练？答：在上下界间振荡跳出局部极小、平均化吸引盆。

## 九、演进

固定 → step → cyclical → 带退火 cyclical。

## 十、小结

周期性学习率以有界振荡探索损失面，是反单调的收敛辅助手段。
