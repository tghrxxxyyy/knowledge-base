# 周期性学习率实践与局限

> 对应 工程经验；与 学习率调度总览深入 / 训练不稳定诊断深入 衔接。

## 一、背景与挑战

CLR 并非万能，需权衡其与标准收敛配方的取舍。

## 二、核心原理

CLR 适合调参探索、短训、快照；长训大模型仍以 warmup+cosine 为主，CLR 易干扰收敛。

## 三、数学形式

周期步长 $2\times step\_size$ 须远小于总步数才有多个周期；否则退化为普通调度。

## 四、代码实现

if use_clr:
    sched = CyclicLR(opt, base_lr, max_lr, step_size_up=total//6)

## 五、与其他对比

- 与 预热与退火组合深入 是“探索式”vs“收敛式”对立。
- 与 学习率区间测试深入 配合定界。

## 六、常见误区

- 在大模型长训滥用 CLR 致不收敛。
- 周期与总步数不匹配。
