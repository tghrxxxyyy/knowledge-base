# 文化评测基准

> 对应 AlKhamissi et al., 2024；Nguyen et al., *ChatGPT Beyond English*, 2023。

## 一、背景与挑战

缺文化基准则无法验证对齐，需多维文化评测。

## 二、核心原理

建跨文化遗产/规范/常识题集，多语多国标注；分维度报文化契合度与一致性。

## 三、数学形式

契合 $F_c=\mathbb E[\text{correct}_c]$；一致 $K=agree(model, ref_c)$。

## 四、代码实现

```python
for c in cultures: score(c, eval(bench_c))
```

## 五、与其他对比

- 与 价值对齐深入（评测）衔接。
- 与 偏见与去偏深入（刻板度量）相关。

## 六、常见误区

- 标注者同质（仍西方）。
- 题目翻译失文化义。

## 八、面试题

- 好文化基准特征？答：多语多国标注、覆盖规范与常识、防翻译失真。

## 九、演进

英语基准 → 翻译基准 → 原生文化基准。

## 十、小结

文化基准需本土标注与原生题，方能量对齐。
