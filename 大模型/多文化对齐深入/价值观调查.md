# 价值观调查与World Values Survey

> 对应 Atari et al., *Which Humans?*, 2023；World Values Survey 对齐实验。

## 一、背景与挑战

用人类价值观调查（WVS）测模型价值取向，看其代表谁。

## 二、核心原理

把 WVS 题项喂模型，比较其回答分布与各国人群分布；揭示模型更接近哪国/群体价值。

## 三、数学形式

代表度 $R_c=corr(P_{model}, P_{WVS,c})$；最高者即代表文化。

## 四、代码实现

```python
for item in wvs: dist[item] = model_choice(item)
```

## 五、与其他对比

- 与 价值对齐深入（价值评测）衔接。
- 与 多文化对齐深入 总览互补。

## 六、常见误区

- 调查题项含文化预设。
- 模型“选择”未必反映真实取向。
