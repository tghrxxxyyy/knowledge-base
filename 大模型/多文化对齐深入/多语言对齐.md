# 多语言对齐

> 对应 Lai et al., *BLOOM*, 2022；多语公平研究。

## 一、背景与挑战

非英语能力弱、价值观随语言漂移（language effect），需多语对齐。

## 二、核心原理

多语 SFT/偏好数据、翻译对齐、跨语一致约束；避免“英语思考、外语输出”的价值漂移。

## 三、数学形式

跨语一致 $C=1-KL(P(\cdot|x)\|P(\cdot|translate(x)))$。

## 四、代码实现

```python
for lang in langs: sft(culture_data[lang])
```

## 五、与其他对比

- 与 多文化对齐深入（文化）互补。
- 与 偏见与去偏深入（语言偏）相关。

## 六、常见误区

- 机器翻译引入偏。
- 低资源语料不足致对齐差。

## 七、与开源书对应

## 八、面试题

- 语言效应？答：同义不同语输出价值漂移，需跨语一致约束。

## 九、演进

英语独尊 → 多语 SFT → 跨语价值观对齐。

## 十、小结

多语对齐减语言漂移，是文化对齐的语言基础。
