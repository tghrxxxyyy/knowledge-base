# 多文化对齐总览

> 对应 Durmus et al., *Towards Culturally Aware LLMs*, 2023；AlKhamissi et al., *Investigating Cultural Alignment of LLMs*, ACL 2024。

## 一、背景与挑战

主流 LLM 偏西方/英语价值，对非西方文化存在系统偏差，需文化感知对齐。

## 二、核心原理

评估并适配模型到不同文化规范（个体/集体、权力距离、时间观）；训练与评测纳入多文化语料与价值观问卷。

## 三、数学形式

文化距离 $d_c=KL(P_{model}(\cdot|c)\|P_{culture_c}(\cdot))$；越小越对齐。

## 四、代码实现

```python
ans = llm(q, culture_prompt=user_culture)
```

## 五、与其他对比

- 与 价值对齐深入（价值多元）衔接。
- 与 偏见与去偏深入（文化偏见）相关。

## 六、常见误区

- 把英语价值当普世。
- 文化适配沦为迎合刻板。

## 八、面试题

- 为何多文化对齐？答：模型偏西方，需感知并适配多元文化规范。

## 九、演进

英语中心 → 多语 → 文化感知。

## 十、小结

多文化对齐纠正西方中心，需评测与适配并举。
