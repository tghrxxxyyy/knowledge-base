# 文化维度理论

> 对应 Hofstede, *Culture's Consequences*, 1980；Schwartz 价值模型。

## 一、背景与挑战

需结构化框架刻画文化差异，方能量化对齐。

## 二、核心原理

Hofstede 六维（权力距离、个人/集体主义、男性化、不确定性规避、长期导向、 indulgence）提供可测轴；模型在各维上定位并比对文化均值。

## 三、数学形式

文化向量 $c=(c_1..c_6)\in[0,100]^6$；对齐差 $\|c_{model}-c_{ref}\|$。

## 四、代码实现

```python
vec = hofstede_survey(model_answers)
```

## 五、与其他对比

- 与 价值对齐深入（价值维度）衔接。
- 与 多文化对齐深入 总览互补。

## 六、常见误区

- 维度静态忽略代际变化。
- 用国家代文化（忽视内部异质）。

## 九、演进

单维 → 六维 → 动态文化模型。

## 十、小结

文化维度把文化变成可测轴，支撑对齐度量。
