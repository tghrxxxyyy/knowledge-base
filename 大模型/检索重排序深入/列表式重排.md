# 列表式重排（Listwise Rerank）

> 对应 Qin et al., *RankT5/Listwise*, 2023；LLM-as-ranker 趋势。

## 一、背景与挑战

 pointwise/pairwise 忽略文档间相对关系；listwise 直接优化整列顺序。

## 二、核心原理

用排序模型（如 RankT5 或 LLM）一次对候选列表输出排序；LLM 以指令直接重排（permutation/generation）。

## 三、数学形式

列表损失（如 ListNet/ListMLE）对齐预测与真实分布；$P(\pi)\propto\prod_i s_{\pi(i)}$。

## 四、代码实现

```python
prompt = f"给文档按相关性排序:\n{docs}"
order = llm(prompt)
```

## 五、与其他对比

- 比 cross-encoder 更能用全局信息，但成本更高（LLM）。
- 与 LLM-as-judge深入 共享“用 LLM 评估”范式。

## 六、常见误区

- LLM 重排位置偏置（首位偏好），需校准。
- 长列表超出上下文致截断。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- listwise 相对 pointwise 优势？答：建模文档间相对顺序，更贴排序目标。

## 九、演进

pointwise → pairwise → listwise → LLM 重排。

## 十、小结

列表式重排用全局顺序信息，LLM 化是新兴强手段但需控偏置。
