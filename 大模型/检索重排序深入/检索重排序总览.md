# 检索重排序总览

> 对应 Nogueira & Cho, *MS MARCO*, 2019（cross-encoder reranker）；RAG评估与离线评测体系（目录）衔接。

## 一、背景与挑战

向量召回召回广但精度有限；重排序用更强模型对候选精排，提升 RAG 上下文质量。

## 二、核心原理

两阶段：召回（bi-encoder 快、粗） → 重排（cross-encoder 慢、精，对(query,doc)联合编码）。

## 三、数学形式

bi-encoder 相似度 $s=sim(E_q(q),E_d(d))$；cross-encoder 分数 $s'=C(q,d)\in\mathbb R$（直接分类）。

## 四、代码实现

```python
hits = bi_encoder.search(q, top_k=100)
re_ranked = cross_encoder.predict([(q,d) for d in hits])[:10]
```

## 五、与其他对比

- 与 混合检索深入（召回侧）互补；重排在召回后精筛。
- 与 检索增强生成前沿 / RAG深入 衔接。

## 六、常见误区

- 重排候选数过少致漏召回；过多致延迟高。
- 忽视重排模型与生成模型的语言匹配。

## 八、面试题

- 为何两阶段？答：召回保召回率与速度，重排保精度，权衡成本质量。

## 九、演进

词法排序(BM25) → 向量召回 → cross-encoder 重排 → 列表式重排。

## 十、小结

重排序是 RAG 质量的关键精筛层，以更强模型换精度。
