# 重排评估指标

> 对应 IR 指标（NDCG/MRR/Recall@k）；RAG评估与离线评测体系（目录）衔接。

## 一、背景与挑战

重排好坏需可量化，且指标需对齐下游 RAG 质量。

## 二、核心原理

召回侧看 Recall@k；排序看 NDCG@k（位置加权）、MRR（首相关位置倒数）；RAG 下游看答案faithfulness。

## 三、数学形式

$NDCG@k=\frac{DCG@k}{IDCG@k}$，$DCG=\sum_i \frac{2^{rel_i}-1}{\log_2(i+1)}$。

## 四、代码实现

```python
from sklearn.metrics import ndcg_score
ndcg = ndcg_score([y_true], [scores], k=10)
```

## 五、与其他对比

- 与 模型评测指标深入 共享评估方法论。
- 与 RAG评估与离线评测体系 衔接。

## 六、常见误区

- 只看 Recall 忽略排序位置（NDCG 更贴体验）。
- 离线指标与生成质量弱相关，需端到端评。

## 八、面试题

- NDCG 为何考虑位置？答：用户对靠前结果更敏感，位置加权更贴效用。

## 九、演进

Recall → MRR → NDCG → 端到端 RAG 指标。

## 十、小结

重排评估需位置敏感指标，并与 RAG 下游质量对齐。
