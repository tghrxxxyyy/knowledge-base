# 价值对齐总览

> 对应 Gabriel, *Artificial Intelligence, Value, and Alignment*, 2020（Ethics and Information Technology）。

## 一、背景与挑战

模型行为应契合人类价值与意图；但“价值”本身多元、冲突且难形式化，存在对齐（alignment）与价值加载（value loading）难题。

## 二、核心原理

区分“对齐”（行为与意图一致）与“价值”（应优化什么）；价值可经原则主义（原则列表）或良构功能（well-being 函数）表达；需兼顾多元主体。

## 三、数学形式

效用目标 $U(a)=\sum_i w_i V_i(a)$，$V_i$ 为群体 $i$ 的价值函数，$w_i$ 为权重（社会选择）。

## 四、代码实现

```python
reward = sum(w[i]*value_fn[i](action) for i in groups)
```

## 五、与其他对比

- 与 宪法AI深入 / 伦理对齐深入 共享价值表达。
- 与 公平性深入（群体权重）衔接。

## 六、常见误区

- 把“对齐”等同于“听话”（忽略应优化价值）。
- 单一价值函数忽略多元冲突。
