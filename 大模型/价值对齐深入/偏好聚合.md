# 偏好聚合与社会选择

> 对应 Christiano et al., *RLHF*, 2017；社会选择理论（Arrow 不可能定理）。

## 一、背景与挑战

不同人偏好冲突，单一奖励难代表全体；聚合方式影响公平性。

## 二、核心原理

把众包偏好视作社会选择问题：可对偏好对平均、按群体加权、或训统一 RM；Arrow 定理提醒无完美聚合。

## 三、数学形式

群体奖励 $\bar r(x,y)=\frac1N\sum_j r_j(x,y)$；或最大最小 $\min_j r_j$ 保弱群体。

## 四、代码实现

```python
group_rm = {g: train(prefs[g]) for g in groups}
agg = weighted_mean([group_rm[g](x,y) for g in groups], w)
```

## 五、与其他对比

- 与 公平性深入（群体公平）同源。
- 与 多文化对齐深入（跨文化聚合）衔接。

## 六、常见误区

- 忽视少数群体被多数偏好淹没。
- 假设偏好可传递（现实常不满足）。
