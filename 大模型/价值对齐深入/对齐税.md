# 对齐税（Alignment Tax）

> 对应 RLHF 实践中“对齐降低能力”的现象；与 模型能力保持 衔接。

## 一、背景与挑战

对齐训练有时牺牲有用性/性能（对齐税），用户与能力间需权衡。

## 二、核心原理

强 KL 约束或仅优化无害会抑制能力；需容量足够的基础模型与多目标（有用+无害+诚实）平衡。

## 三、数学形式

目标 $\max_\pi \mathbb E[r_{help}] - \lambda KL(\pi,\pi_{ref})$；$\lambda$ 大则能力税高。

## 四、代码实现

```python
loss = help_loss - lam*kl(policy, ref) + beta*safety_loss
```

## 五、与其他对比

- 与 直接偏好优化深入（$\beta$ 控偏离）对照。
- 与 奖励模型深入（多目标 RM）衔接。

## 六、常见误区

- 为能力放弃安全致越狱。
- 误把对齐税当必然（大模型可降税）。

## 八、面试题

- 如何减对齐税？答：强基础模型+多目标奖励+适度 KL。

## 九、演进

能力-安全二选一 → 多目标 → 能力-safe 共提升。

## 十、小结

对齐税是权衡而非宿命，靠容量与多目标缓解。
