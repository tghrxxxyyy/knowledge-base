# 稀疏量化总览

> 对应 Frantar et al., *GPTQ*, 2022（ICLR）；Dettmers et al., *LLM.int8()*, 2022（NeurIPS）。

## 一、背景与挑战

LLM 参数量巨大，FP16 推理显存与带宽成本高；训练后量化（PTQ）把权重压到 4/3/2 比特是部署关键。

## 二、核心原理

量化分 PTQ（训练后，无需重训）与 QAT（量化感知训练）。PTQ 用校准集统计尺度，最小化量化误差；稀疏（pruning）置零权重进一步压缩。

## 三、数学形式

均匀量化：$q = \text{round}(W/s + z)$，$s = (W_{max}-W_{min})/(2^b-1)$；重建误差 $\|W - \hat W\|_2$。

## 四、代码实现

```python
s = (w.max()-w.min())/(2**b-1)
q = torch.round(w/s).clamp(-2**(b-1), 2**(b-1)-1)
w_hat = q*s
```

## 五、与其他对比

- 与 低比特训练与推理深入（训练侧量化）互补，PTQ 更省算力。
- 与 边缘设备部署优化深入（部署载体）衔接。

## 六、常见误区

- 直接按层独立量化忽略层间误差累积。
- 比特过低（<2.5）致严重退化，需混合精度。

## 八、面试题

- PTQ 与 QAT 区别？答：PTQ 训练后无重训，快但低比特损失大；QAT 训练中模拟量化，精度高但贵。

## 九、演进

FP16 → INT8 PTQ → INT4(GPTQ/AWQ) → 混合精度+稀疏。

## 十、小结

稀疏量化是 LLM 落地刚需，PTQ 以校准换低成本，低比特需精细方法。
