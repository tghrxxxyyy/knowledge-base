# 投机解码局限与适用

> 对应投机解码适用边界与陷阱。

## 一、背景与挑战

并非所有场景都适合投机，误用反而变慢或增显存。

## 二、核心原理

适合：target 带宽界、草稿廉价且接近 target（如代码/模板）。不适合：草稿远差致接受率低、或 target 本就算力界（prefill 主导）。多草稿/树投机可提接受但增验证成本。

## 三、数学形式

收益条件 $E[\tau]>1+k\cdot r$；否则不加速。

## 四、代码实现

```python
if target_is_bandwidth_bound and draft_cheap:
    use_speculative()
```

## 五、与其他对比

- 与 迭代级批处理调度深入：批内可并行多序列投机。
- 与 推理CUDA图优化深入：验证段可入图但长度多变需图池。

## 六、常见误区

- 在算力界负载（长 prefill）用投机无效。
- 草稿模型占额外显存未计入。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course
- LLMs-from-scratch：https://github.com/rasbt/LLMs-from-scratch

## 八、面试题

- 何时不用投机？答：target 算力界或草稿差致接受低、或显存紧张时。

## 九、演进

单草稿 → 树投机 → 自适应开关。

## 十、小结

投机解码在带宽界且草稿近 target 时收益最大，否则谨慎。
