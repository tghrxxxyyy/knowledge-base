# 接受率与加速比

> 对应投机解码加速理论（Leviathan et al., 2023）。

## 一、背景与挑战

实际加速由接受长度与草稿/验证成本共同决定，需建模预估。

## 二、核心原理

当草稿接近 target，单循环平均接受 $\tau$ 接近 $k$，期望步数趋 1；加速比上界约 $\tau$，受草稿成本与验证长度折旧。

## 三、数学形式

期望接受长度 $E[\tau]\approx \sum_{i=1}^k \prod_{j<i} a_j$；加速 $\approx E[\tau]/(1+k\cdot r)$，$r=c_{draft}/c_{target}$。

## 四、代码实现

```python
accept = mean([sum(ok[:i]) for ok in batches])
```

## 五、与其他对比

- 与 推理延迟剖析与火焰图深入：实测加速须剖析验证段。
- 与 权重内存分页与卸载深入：卸载下草稿/target 协调更复。

## 六、常见误区

- 只看草稿速度忽略 $k$ 长验证摊薄。
- 在低接受场景（强分布偏移）用投机反慢。
