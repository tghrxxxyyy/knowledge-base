# 投机解码总览

> 对应 Leviathan et al., *Fast Inference from Transformers via Speculative Decoding*, 2023；Chen et al., 2023 同期工作。

## 一、背景与挑战

自回归 decode 每步仅出一 token，受限于内存带宽而非算力；大模型每步要读全权重，吞吐低。

## 二、核心原理

用小草稿模型（draft）一次预测若干 token，再用大模型（target）并行验证整段；接受的多 token 一次性提交，等价于自回归分布，提速来自并行验证。

## 三、数学形式

target 分布 $p$，draft 分布 $q$；接受概率约 $\min(1, p_t/q_t)$；期望接受长度随 $q$ 近似 $p$ 增大。

## 四、代码实现

```python
draft_tokens = draft(model_s, x, k)
full = target(model_l, x, draft_tokens)   # 并行验证
```

## 五、与其他对比

- 与 迭代级批处理调度深入：可叠加，批内各序列投机。
- 与 张量核心与混合精度推理深入：验证走 TC。

## 六、常见误区

- 误以为投机改变输出分布（无损，等价于 target）。
- 草稿太慢抵消并行收益。

## 八、面试题

- 投机解码为何无损？答：用接受/拒绝重采样，输出分布严格等于 target。

## 九、演进

独立 draft → EAGLE 自回归草稿 → 树状投机。

## 十、小结

投机解码以草稿+并行验证把多步压成一步，无损提速 decode。
