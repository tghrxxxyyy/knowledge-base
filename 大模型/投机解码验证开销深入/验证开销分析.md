# 投机解码验证开销分析

> 对应投机解码成本模型（验证步的算力/带宽组成）。

## 一、背景与挑战

加速不是免费：验证需 target 对 $k$ 个位置前向，须算净收益。

## 二、核心原理

每次投机循环成本 = 草稿 $k$ 步小模型 + target 一次 $k$ 长前向（近似单步带宽读权重 + $k$ 倍算力）；净加速取决于接受长度 $\tau$，期望省 $(\tau-1)$ 次自回归读权重。

## 三、数学形式

等效步数 $E\approx 1 + k - \tau$（每循环出 $\tau$ token）；加速比 $\approx \frac{\tau}{1+k\cdot c_{draft}/c_{target}}$。

## 四、代码实现

```python
speedup = accepted_len / (1 + k * draft_cost / target_cost)
```

## 五、与其他对比

- 与 张量核心与混合精度推理深入：验证是 TC 带宽界 GEMM。
- 与 推理延迟剖析与火焰图深入：可量化草稿/验证占比。

## 六、常见误区

- 草稿步数 $k$ 过大致验证 $k$ 长前向超自回归收益。
- 忽视草稿模型本身算力（小但非零）。

## 八、面试题

- 验证为何仍要读权重？答：target 前向需全权重，长度 $k$ 一次读完，靠并行摊薄。

## 九、演进

经验 k → 代价模型选 k → 自适应长度。

## 十、小结

验证开销由 $k$ 长前向决定，净收益取决于平均接受长度。
