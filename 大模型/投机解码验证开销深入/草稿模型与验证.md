# 草稿模型与验证机制

> 对应 Leviathan et al., 2023 的验证接受规则。

## 一、背景与挑战

如何既快又高接受率地起草，且验证保持正确分布。

## 二、核心原理

草稿模型自回归出 $k$ 个候选；target 对位置 $1..k$ 并行算概率，按 $p/q$ 接受或拒绝首个不符处并重采样；保证整体为 target 分布。

## 三、数学形式

第 $i$ 位接受概率 $a_i=\min(1, p(x_i|c)/q(x_i|c))$；首个拒绝后从该位置按修正分布重采样。

## 四、代码实现

```python
for i in range(k):
    if rand() > p_i/q_i:
        break
```

## 五、与其他对比

- 与 投机解码验证开销深入/验证开销分析：本节为机制，下节算开销。
- 与 EAGLE 对比（见后）：EAGLE 改草稿方式。

## 六、常见误区

- 草稿分布与 target 差太远致接受率低。
- 验证未在单前向完成（应并行）。

## 八、面试题

- 如何保证分布不变？答：按 min(1,p/q) 接受，拒绝处用修正分布重采样。

## 九、演进

固定小模型 → 同族小模型 → 特征级草稿(EAGLE)。

## 十、小结

草稿+修正重采样是投机无损的核心，草稿质量决定收益。
