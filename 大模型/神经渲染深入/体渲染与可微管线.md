# 体渲染与可微管线

> 对应 Max et al., 体渲染与可微渲染综述；神经场景表示基础。

## 一、背景与挑战

神经渲染要可微地把 3D 场投影到 2D，才能用图像反传优化网络。

## 二、核心原理

数值化体渲染：在 $[t_n,t_f]$ 上用分层/分层抽样取点，按透射率 $T$ 加权颜色，整条管线对 $\Theta$ 可微。

## 三、数学形式

离散近似 $C(r)\approx\sum_{i=1}^N T_i(1-\exp(-\sigma_i\delta_i))c_i$，其中
$T_i=\exp(-\sum_{j<i}\sigma_j\delta_j)$。

## 四、代码实现

```python
T = 1.0; acc = 0.0
for sigma_i, c_i, delta in zip(sigmas, colors, deltas):
    alpha = 1 - torch.exp(-sigma_i * delta)
    acc += T * alpha * c_i
    T *= (1 - alpha)
```

## 五、与其他对比

- 与光栅化不同，体渲染天然支持半透明与连续场。
- 与 NeRF原理 共享渲染核心。

## 六、常见误区

- 分段常数近似过粗产生条带；需足够采样。
- 忽视梯度在空区域消失，致未覆盖区域不更新。

## 八、面试题

- 透射率 T 含义？答：光线到达某点仍未被吸收的概率，决定该点颜色权重。

## 九、演进

解析积分→分层采样→重要性采样+空域跳过。

## 十、小结

可微体渲染是神经渲染的梯度桥梁，采样策略决定质量与效率。
