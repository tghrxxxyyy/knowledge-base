# 神经渲染总览

> 对应 Mildenhall et al., *NeRF: Representing Scenes as Neural Radiance Fields for View Synthesis*, ECCV 2020。

## 一、背景与挑战

传统渲染依赖显式几何与材质；神经渲染用神经网络隐式表示场景，从多视角图像中学习连续 3D 表示，降低手工建模成本。

## 二、核心原理

以 MLP 把空间坐标与视角映射到颜色与体积密度，通过可微体渲染合成新视角图像；训练仅需多视角 RGB 与相机参数。

## 三、数学形式

沿光线 $r(t)=o+td$ 累积颜色：
$C(r)=\int_{t_n}^{t_f} T(t)\,\sigma(r(t))\,c(r(t),d)\,dt$，其中 $T(t)=\exp(-\int_{t_n}^{t}\sigma(r(s))\,ds)$。

## 四、代码实现

```python
import torch
def render_rays(mlp, rays_o, rays_d, tn, tf, N=64):
    t = torch.linspace(tn, tf, N)
    pts = rays_o[:, None] + rays_d[:, None] * t[:, None]
    sigma, color = mlp(pts)
    return volume_render(sigma, color, t)
```

## 五、与其他对比

- 与显式网格渲染相比，无需手工几何但训练慢、推理逐光线。
- 与 NeRF原理深入 互为总览与细节。

## 六、常见误区

- 误以为需要深度监督；NeRF 仅靠 RGB 即可训练。
- 忽视相机标定误差对收敛的影响。

## 八、面试题

- 神经渲染为何只需 RGB？答：体渲染把 2D 像素监督反传到 3D 密度/颜色场，端到端可微。

## 九、演进

体素→点云→神经隐式（NeRF）→动态与生成式神经渲染。

## 十、小结

神经渲染以可微管线桥接图像与 3D，是生成式 3D 与仿真的基础。
