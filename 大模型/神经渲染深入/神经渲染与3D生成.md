# 神经渲染与3D生成

> 对应 Poole et al., *DreamFusion*, 2022；SJC；文本到 3D 扩散。

## 一、背景与挑战

如何从文本/单图生成可渲染的 3D 资产，而不需 3D 训练集。

## 二、核心原理

用预训练 2D 扩散模型作评分先验，通过 SDS（Score Distillation Sampling）反传把 NeRF/高斯表示朝文本对齐；优化 NeRF 参数使渲染图符合扩散先验。

## 三、数学形式

SDS 梯度近似
$\nabla_\Theta \mathcal L_{SDS}\approx \mathbb E[\omega(t)(\epsilon_\phi(x_t;t,c)-\epsilon)]$，其中 $x=render(\Theta)$。

## 四、代码实现

```python
render_img = render(nerf, Theta)
loss = sds_loss(render_img, text_prompt)
loss.backward(); opt.step()
```

## 五、与其他对比

- 与直接 3D 扩散相比，绕开 3D 数据稀缺。
- 与 NeRF原理 / 视频生成 共享生成范式。

## 六、常见误区

- SDS 易过饱和、缺乏多样性（Janus 多面问题）。
- 忽视多视角一致性约束。

## 八、面试题
