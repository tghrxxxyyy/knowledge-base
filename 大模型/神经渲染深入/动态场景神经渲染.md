# 动态场景神经渲染

> 对应 Pumarola et al., *D-NeRF*, 2021；Park et al., *HyperNeRF*, 2021。

## 一、背景与挑战

静态 NeRF 无法表达运动；动态场景需建模随时间变化的几何与外观。

## 二、核心原理

引入时间维与形变场：D-NeRF 用 MLP 将 $(x,t)$ 映射到规范空间坐标；或采用 4D 体素/变形网络直接回归时变密度与颜色。

## 三、数学形式

规范映射 $\Phi_t:(x,t)\mapsto x'$；渲染仍用静态体渲染：
$C(r,t)=\int T(t')\sigma(\Phi_t(x'))c(\Phi_t(x'),d)\,dt'$。

## 四、代码实现

```python
canon = deform_mlp(x, t)          # 形变到规范空间
sigma, color = scene_mlp(canon)
```

## 五、与其他对比

- 比多帧独立 NeRF 省参数、跨时序一致。
- 与 神经渲染总览 / 视频生成 衔接（时序建模）。

## 六、常见误区

- 大运动致形变场难学、产生拖影。
- 忽视相机与时间同步标定。

## 八、面试题

- D-NeRF 如何解决动态？答：加时间相关形变场把观测映射到规范空间再渲染。

## 九、演进

逐帧 NeRF→D-NeRF→4D 高斯泼溅（4D Gaussians）。

## 十、小结

动态神经渲染以时间形变或 4D 表示扩展 NeRF，支撑视频与仿真。
