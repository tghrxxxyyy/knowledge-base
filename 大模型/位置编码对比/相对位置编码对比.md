# 相对位置编码对比

> 对应相对位置编码研究：Shaw et al. 2018 (Self-Attention with Relative Pos); Dai et al. 2019 (Transformer-XL); Raffel et al. 2020 (T5)。亦见 Vaswani et al. 2017。

## 一、背景与挑战

语言理解任务（翻译、问答、指代消解）更依赖**相对距离**——「两个词隔多远」比「各自在第几位」更影响语义。绝对位置编码把顺序当绝对坐标，对移位、变长敏感，且难以表达「相距 k 个词」这种通用关系。

相对位置编码把偏移 $i-j$ 直接纳入注意力分数，提升平移不变性与泛化。其挑战在于：如何高效表示相对偏置、如何与多头/长序列兼容、以及如何不引入过多参数。

## 二、核心原理

三类代表性相对编码：

1. **Shaw et al. (2018)**：在注意力中加基于相对距离的键偏置 $a_{i-j}^K$ 与值偏置 $a_{i-j}^V$，截断最大距离 $k$ 控参。
2. **Transformer-XL (2019)**：用正弦式相对位置正弦编码 $R_{i-j}$，并做段级递归复用历史，支持超长依赖。
3. **T5 (2020)**：用可学习「相对桶（bucket）」偏置，把距离分桶（含对数桶）映射到偏置，参数少且覆盖任意长度。

三者都把「相对距离」作为注意力的一阶信号，区别在偏置形式（可学习 vs 正弦 vs 分桶）。

## 三、形式化与数学基础

Shaw 的注意力：

$$
e_{ij} = \frac{q_i^\top k_j}{\sqrt{d}} + a_{i-j}^K,\quad \alpha_{ij} = \text{softmax}(e_{ij})_j
$$

输出加入值偏置：

$$
o_i = \sum_j \alpha_{ij}\,(v_j + a_{i-j}^V)
$$

Transformer-XL 用正弦相对编码：

$$
R_{i-j} = 
\begin{cases}
\text{func}_{\text{sin}}(i-j), & i-j \le 0 \\
0, & i-j > 0
\end{cases}
$$

T5 分桶偏置 $B_{i-j}$ 对远近用线性/对数桶映射，距离越远桶越粗，参数量仅 $2L_{bucket}$。

## 四、代码实现

T5 风格分桶偏置的精简示意：

```python
def rel_bucket(dist, num_buckets=32, max_dist=128):
    ret = 0
    n = -dist if dist < 0 else dist + num_buckets // 2
    dist = min(abs(dist), max_dist)
    ret = (dist - 1) // (max_dist // (num_buckets // 2))
    return ret + (0 if dist < 0 else num_buckets // 2)
# 偏置: bias = lookup[rel_bucket(i-j)]
```

## 五、与其他技术对比

| 方案 | 偏置形式 | 参数 | 外推 | 代表任务 |
|------|----------|------|------|----------|
| Shaw 2018 | 可学习(截断) | 中 | 中 | 解析 |
| Transformer-XL | 正弦 | 无 | 强 | 长依赖 |
| T5 bucket | 可学习分桶 | 少 | 强 | 通用 NLU |
| RoPE | 旋转(相对) | 无 | 强(调参) | 生成 LLM |

## 六、常见误区

- **「相对编码=RoPE」**：RoPE 是旋转式相对编码，与 T5/Shaw 偏置式机制不同。
- **「相对编码更复杂没必要」**：理解型任务受益明显，平移不变性提升泛化。
- **「距离无上限」**：Shaw 截断控参，T5 分桶粗化远处，均有界处理。
- **混淆相对与绝对目标**：相对编码建模「间距」，绝对编码建模「坐标」。

## 九、演进与趋势

相对偏置思想被 RoPE 以旋转形式吸收进生成模型，T5 分桶成为编码器事实标准。趋势是把相对性作为注意力基础属性，并与长度外推（NTK/YaRN）统一到频域视角——相对距离即低频信号的相位差。

## 十、小结

相对位置编码把「间距」直接注入注意力，提升平移不变与泛化：Shaw 可学习、XL 正弦递归、T5 分桶。它是现代变体（含 RoPE）的基础理念，理解相对性方能掌握位置编码全局。
