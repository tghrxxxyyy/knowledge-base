# 绝对位置编码

> 对应 Vaswani et al. (2017) Attention Is All You Need；亦见正弦位置编码与可学习位置嵌入。

## 一、背景与挑战

Transformer 的自注意力对输入序列做集合级运算，本身是**置换不变**的：打乱 token 顺序，输出只是对应重排，模型读不出「谁在谁前面」。要理解语言顺序，必须显式注入位置信息。

绝对位置编码给每个位置 $i$ 一个固定向量 $p_i$，与词嵌入相加后送入模型，告诉注意力「这是第 $i$ 个词」。其挑战在于：可学习版长度固定难外推，正弦版可外推但有限，且二者都只编码「绝对坐标」而非「相对间距」，对变长与移位敏感。

## 二、核心原理

两种经典绝对编码：

1. **可学习绝对（Learned）**：随机初始化 $P\in\mathbb{R}^{L_{max}\times d}$，随训练学出，简单直接，但位置索引超出 $L_{max}$ 即越界，几乎不可外推。
2. **正弦绝对（Sinusoidal）**：用固定三角函数按维度交替注入频率：

$$
PE_{(i,2k)} = \sin\!\left(\frac{i}{10000^{2k/d}}\right),\quad PE_{(i,2k+1)} = \cos\!\left(\frac{i}{10000^{2k/d}}\right)
$$

任意长度可算、含相对距离的线性可表达性（因 $\sin(a+b)$ 可线性组合），但长距高频仍过密、外推有限。

## 三、形式化与数学基础

输入表示为词嵌入与位置编码之和：

$$
h_i^{(0)} = x_i + PE_i
$$

正弦编码的高频维度周期短、低频维度周期长，使不同维度承载不同尺度位置信号。其对相对距离的线性性质：存在线性变换 $T$ 使

$$
PE_{i+\delta} = T_\delta\, PE_i
$$

即平移可由固定矩阵表达，理论上支持相对关系，但仅近似且长距衰减。可学习版则无此闭式性质，纯靠记忆训练区间位置。

## 四、代码实现

正弦位置编码构造：

```python
import torch, math

def sinusoidal_pe(seq_len, d, base=10000.0):
    pos = torch.arange(seq_len)[:, None]
    div = base ** (torch.arange(0, d, 2) / d)[None, :]
    pe = torch.zeros(seq_len, d)
    pe[:, 0::2] = torch.sin(pos / div)
    pe[:, 1::2] = torch.cos(pos / div)
    return pe                                    # 与 x 相加
```

可学习版仅需 `nn.Embedding(seq_len, d)` 并随训练更新。

## 五、与其他技术对比

| 编码 | 外推 | 参数 | 相对性 | 适用 |
|------|------|------|--------|------|
| 可学习绝对 | 弱 | 有 | 否 | 固定长度 NLU |
| 正弦绝对 | 有限 | 无 | 近似 | 原始 Transformer |
| 相对偏置 | 强 | 可选 | 是 | T5/XL |
| RoPE/ALiBi | 强 | 无 | 是 | 现代 LLM |

## 六、常见误区

- **「绝对编码能外推」**：可学习版严格不可、正弦版有限，远超训练长度即失效。
- **「位置加在哪都行」**：标准加在输入层，加错层会破坏相对性质。
- **「正弦已够用」**：现代长上下文需 RoPE/NTK，正弦外推不足。
- **混淆坐标与间距**：绝对编码建模坐标，理解型任务更需相对间距。

## 九、演进与趋势

绝对编码是位置注入的起点，后被相对偏置（T5/XL）与旋转编码（RoPE）、线性偏置（ALiBi）取代。其思想仍活在现代方案里：正弦的频率分解启发了 NTK 外推的频域重分配。位置编码整体从「绝对坐标」走向「相对+可外推」。

## 十、小结

绝对位置编码用位置向量打破注意力置换不变，可学习版简单但难外推、正弦版可算但有限。它是位置编码的起点，价值在于确立「顺序必须显式注入」，后被相对/RoPE 路线超越。
