# 位置外推技术综述

> 整合 RoPE / ALiBi / Position Interpolation (PI) / NTK-aware / YaRN 等长度外推方案；综述视角参考 Chen et al. 2023 (Extending Context)、Peng et al. 2023 (YaRN)。

## 一、背景与挑战

「长度外推」指模型在训练长度 $L_{train}$ 之外、$L_{test}\gg L_{train}$ 仍能保持性能。这是长文档、长程检索、agent 记忆的前提。原始 Transformer 的绝对/正弦编码在此几乎失效：位置向量越界或高频过密导致注意力错位。

外推难题本质是**频率分配**：位置编码用若干频率刻画相对距离，若训练时只覆盖短距，长距对应的高频分量在推理期被「压缩」到未训练区间，信息失真。各方案围绕「如何重分配频率/偏置」展开。

## 二、核心原理

主流外推路线：

1. **ALiBi（免训练）**：线性距离偏置天然对任意长度成立，无需处理即可外推。
2. **RoPE + Position Interpolation (PI)**：把位置索引从 $[0,L_{train}]$ 线性插值到 $[0,L_{test}]$，使推理位置落入训练分布，但牺牲部分分辨率。
3. **RoPE + NTK-aware**：不改位置索引，而是缩放 base（基频），重分配各维度频率，高维高频、低维低频，保留分辨率更优。
4. **YaRN**：在 NTK 基础上对注意力 logits 做温度缩放（维度加权），需少量微调，长上下文表现最强。

## 三、形式化与数学基础

PI 把位置重映射：

$$
m' = \frac{L_{train}}{L_{test}}\, m
$$

NTK-aware 缩放 base：

$$
\theta_i' = \text{base}'^{-2i/d},\quad \text{base}' = \text{base}\cdot \lambda^{\frac{d}{d-2}}
$$

YaRN 引入维度温度 $t_i$：

$$
\text{score}_i \leftarrow \frac{\text{score}_i}{t_i},\quad t_i = 0.1\cdot \min(1, \lambda) \cdot \frac{i}{d/2} + 1
$$

使低频（远距离）注意力不过度衰减。三者关系：ALiBi 免训练、PI 最简单、NTK 保真、YaRN 最强但需微调。

## 四、代码实现

NTK-aware base 计算的精简实现：

```python
def ntk_base(orig_base, train_len, test_len, d):
    lam = test_len / train_len
    return orig_base * (lam ** (d / (d - 2)))

def yarn_temperature(d, lam):
    t = [0.1 * min(1.0, lam) * (i / (d/2)) + 1.0 for i in range(d//2)]
    return t                                   # 喂入注意力 logits 缩放
```

## 五、与其他技术对比

| 方法 | 训练时改动 | 外推强度 | 需微调 | 代表 |
|------|------------|----------|--------|------|
| 正弦绝对 | 否 | 弱 | 否 | 原始 |
| RoPE+NTK | 轻量 | 强 | 否/可选 | NTK-aware |
| Position Interp | 轻量 | 中 | 否 | kaiokendev |
| YaRN | 轻量 | 很强 | 是(少量) | Peng et al. |

## 六、常见误区

- **「外推可完全白嫖」**：PI/NTK 免微调但有损，YaRN 需少量数据。
- **「base 越大越好」**：过大高频过疏，需按目标长度匹配。
- **「ALiBi 万能」**：ALiBi 强在免训练外推，但表达容量与 RoPE 不同，并非处处更优。
- **混淆 PI 与 NTK**：PI 改索引、NTK 改频率，后者保分辨率。

## 九、演进与趋势

从 PI 的简单插值，到 NTK 的频率重分配，再到 YaRN 的温度缩放，外推技术快速收敛到「频域重分配 + 注意力校准」。前沿探索动态 NTK（推理期按需缩放）与训练期长度课程，使外推不再依赖后处理补丁。

## 十、小结

长度外推本质是位置编码频率重分配：ALiBi 免训练、RoPE+NTK 保真、YaRN 最强需微调。RoPE+NTK/YaRN 与 ALiBi 是当前两大路线，选型取决于是否接受微调与长度目标。
