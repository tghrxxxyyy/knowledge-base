# 投机解码 Speculative Decoding

> 对应 Leviathan et al.(2023) 与 Chen et al.(2023)。不改模型质量前提下的加速生成。

## 一、核心概念

自回归逐 token 生成受限于大模型单次前向的串行性。投机解码用一个**小草稿模型(draft)** 快速预测若干 token，再用大模型**并行验证**这串 token 是否正确接受，大幅减少大模型串行步数。

```
草稿模型生成 k 个候选 → 大模型一次前向并行验证 → 接受前缀 → 自行纠正首个错处
```

若草稿接受率高，加速比接近 `k` 倍，且输出分布与原始大模型完全一致（无损）。

## 二、关键要点

| 组件 | 作用 |
|------|------|
| 草稿模型 | 快、近似 |
| 大模型 | 验证、保真 |
| 接受准则 | 按概率接受 |
