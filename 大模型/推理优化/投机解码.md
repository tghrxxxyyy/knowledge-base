# 投机解码 Speculative Decoding

> 对应 Leviathan et al., *Fast Inference from Transformers via Speculative Decoding*, 2023 与 Chen et al., *Accelerating Large Language Model Decoding with Draft Model*, 2023。

## 一、背景与挑战

自回归生成每产出一个 token 都要跑一次完整大模型前向，且**严格串行**——第 $t$ 个 token 必须等第 $t-1$ 个算完。大模型前向受限于显存带宽（memory-bound），单步算力利用率低。若能让「多次串行小步」合并成「一次并行大步」，就能在不改输出分布的前提下提速。投机解码正是这一思想。

## 二、核心原理

投机解码引入一个**草稿模型（draft / proposal model）** $p_{\text{small}}$ 与待加速的**目标模型（target）** $p_{\text{large}}$：

1. 草稿模型基于当前上下文快速自回归生成 $k$ 个候选 token $(x_1,\dots,x_k)$；
2. 把这 $k$ 个 token 连同原上下文拼成长度为 $k$ 的序列，交给目标模型**一次并行前向**算出每个位置对应的真值分布；
3. 按概率**接受准则**逐位校验：接受与草稿一致的前缀，在遇到首个分歧处，以修正概率采样一个 token 替换，并丢弃其后候选；
4. 若前 $n$ 位全接受，则本步净推进 $n+1$ 个 token（最后一位由目标模型自采样补充）。

草稿模型远小于目标模型，生成 $k$ 个候选的成本远低于目标模型 $k$ 次串行前向。

## 三、形式化与数学基础

设目标分布 $p$、草稿分布 $q$。接受第 $i$ 位的条件是：若 $q(x_i)\le p(x_i)$，则必接受，概率 $p(x_i)/q(x_i)$；若 $q(x_i)> p(x_i)$，则以概率 $1-q(x_i)/p(x_i)$ 拒绝并改采样。由此构造的接受分布可证明与 $p$ 完全一致。单次投机期望推进长度约为：

$$\mathbb{E}[n] = \sum_{i=1}^{k} \prod_{j=1}^{i} \min\!\left(1,\frac{p(x_j)}{q(x_j)}\right).$$

当草稿与目标分布接近（接受率高）时，$\mathbb{E}[n]\to k+1$，加速比接近 $k$ 倍；且**输出严格服从目标模型分布（无损）**。

## 四、代码实现

伪代码骨架（基于 vLLM / HuggingFace 风格）：

```python
def speculative_decode(target, draft, ctx, k=5):
    candidates = []
    x = ctx
    for _ in range(k):
        nxt = draft.sample(x)          # 草稿自回归
        candidates.append(nxt); x = x + nxt
    # 目标模型一次并行验证
    logits = target.forward(ctx + candidates)   # 长度 k+1
    accepted = []
    for i in range(k):
        p = softmax(logits[i])[candidates[i]]
        q = draft_prob(draft, ctx, i)
        if random() < min(1, p / q):
            accepted.append(candidates[i])
        else:
            # 用目标分布修正采样并结束本步
            return ctx + accepted + [target.resample(logits[i])]
    return ctx + accepted + [target.sample(logits[k])]
```

## 五、与其他技术对比

| 技术 | 是否无损 | 加速来源 | 额外资源 |
|------|---------|---------|---------|
| 投机解码 | 是 | 减少目标模型串行步 | 需草稿模型 |
| 量化（INT8/FP8） | 近似 | 降带宽/算力 | 精度略损 |
| 蒸馏小模型 | 否（分布变） | 直接换小模型 | 需训练 |
|  Medusa / EAGLE | 是 | 多头并行预测 | 需训练头 |

## 六、常见误区

- **以为投机解码会改答案**：只要接受准则正确，输出分布与目标模型完全一致。
- **草稿模型越像目标越好**：训练成本与存储需权衡；也可用目标模型自身浅层或自蒸馏草稿。
- **盲目增大 $k$**：接受率随 $k$ 指数衰减，过大反而增加被拒候选的浪费。
- **任何草稿都能加速**：当草稿与目标分布差异大（如任务域偏移），接受率骤降，加速比可能小于 1，即反而变慢。
- **忽略草稿模型成本**：草稿每步也要前向，若草稿相对目标并不「足够小」，净收益被吃掉。

## 九、演进与趋势

从独立草稿模型走向**同一模型内部预测**：EAGLE 用目标模型最后一层特征训练轻量自回归头；Medusa 用多个解码头并行产出候选位置。还有**自投机（self-speculative）**用目标模型浅层做草稿。与连续批处理、量化可叠加使用，是多卡部署下提升解码吞吐的主流手段。

## 十、小结

投机解码用「小模型起草、大模型并行验」把多次串行前向压缩为一次并行前向，在严格不改变目标模型输出分布的前提下获得近 $k$ 倍解码加速；其收益取决于草稿接受率，现已成为生产推理引擎的标准加速组件之一。
