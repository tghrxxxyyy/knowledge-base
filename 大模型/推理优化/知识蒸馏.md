# 知识蒸馏 Knowledge Distillation

> 对应 Hinton et al.(2015, *Distilling the Knowledge*) 与 LLM 小模型化实践。

## 一、背景与挑战

大模型（教师）能力强但部署贵，小模型（学生）快但能力弱。知识蒸馏（KD）让小模型「师从」大模型，以更小体积逼近教师表现，是模型压缩与端侧部署的核心手段。经典 KD 由 Hinton 等人（2015）提出：不仅用硬标签，更用教师输出的**软标签（softmax 温度分布）**，因为软标签蕴含「类间相似性」等暗知识（dark knowledge）。LLM 时代蒸馏扩展到「用教师生成数据训练学生」「对齐中间表示」「步骤蒸馏（CoT）」等多种形式。难点是学生容量有限，且软标签可能传递教师偏见与错误。

## 二、核心原理

三类蒸馏：

- **白盒蒸馏**：直接访问教师 logits/隐状态，对齐分布或表示。
- **黑盒蒸馏**：只调用教师 API，用其生成文本/数据训练学生（如蒸馏出小模型、指令数据蒸馏）。
- **步骤蒸馏**：把教师的长思维链（CoT）作为学生的监督目标，使其学会推理行为（见「思维链蒸馏」）。

核心思想：软标签比 one-hot 硬标签信息更丰富。例如图像分类中「猫 0.7、狗 0.2」告诉学生两类相似，而硬标签丢失此信息，学生只能学到「非黑即白」的脆弱边界。

### 工程落地要点

- **温度调参**：软标签蒸馏先扫 T（如 2–6），看验证集最优；过大则信号过平、过小则接近硬标签。
- **容量匹配**：学生过小学生难以承载，可按任务选 1/2~1/4 教师规模起步。
- **黑盒更常用**：LLM 场景多直接用教师生成文本做 SFT，无需访问 logits，工程最简单。
- **数据去偏**：筛掉教师错误/偏见样本，必要时多教师投票降单点错误。
- **表示对齐加成**：白盒场景可加隐状态 MSE 损失，比仅对齐输出更强。
- **组合压缩**：蒸馏后再量化/剪枝，形成「蒸馏→压缩」流水线，进一步降本。

## 三、形式化与数学基础

经典蒸馏损失混合硬标签交叉熵与软标签 KL 散度：

$$
\mathcal{L} = \alpha\, T^2 \cdot \mathrm{KL}\!\left(\sigma(z_t/T)\,\|\,\sigma(z_s/T)\right) + (1-\alpha)\,\mathrm{CE}(y,\, z_s)
$$

其中 $T$ 为温度，软化教师分布 $\sigma(z/T)$；乘 $T^2$ 抵消梯度缩放。温度越高，分布越平滑，类间相似性越突出。LLM 生成式蒸馏则常用序列 NLL：

$$
\mathcal{L}_{\text{gen}} = -\sum_t \log p_{\text{student}}(y_t\mid x, y_{<t}),\quad y\sim \text{Teacher}
$$

## 四、代码实现

用教师软标签训练学生（图像分类示意，概念可迁移到 LLM 头）：

```python
import torch, torch.nn.functional as F
T, alpha = 4.0, 0.7
for x, y in loader:
    logits_s = student(x); logits_t = teacher(x).detach()
    soft = alpha * T*T * F.kl_div(
        F.log_softmax(logits_s/T, 1), F.softmax(logits_t/T, 1), reduction="batchmean")
    hard = (1-alpha) * F.cross_entropy(logits_s, y)
    (soft + hard).backward(); opt.step()
```

LLM 场景更常见「直接 SFT 教师生成文本」，无需访问 logits，黑盒即可。

## 五、与其他技术对比

| 维度 | 硬标签训练 | 软标签 KD | 生成式蒸馏 |
|------|-----------|-----------|-----------|
| 信息量 | 低 | 高（暗知识） | 高（行为） |
| 需教师访问 | 否 | 是（logits） | 否（文本即可） |
| 适用 | 有标注 | 同任务 | 跨任务/推理 |

## 六、常见误区

- **蒸馏一定能超越教师**：学生容量受限，通常逼近而非超越（除非数据/训练更优）。
- **温度越高越好**：$T$ 过大使分布过平、信号变弱；需调。
- **软标签含偏见**：教师错误/偏见会被学生继承，需筛数据。
- **只看最终输出对齐**：对齐中间表示（隐状态）常能更好传递能力。
- **蒸馏可无视容量**：过小学生无法承载教师知识，应匹配规模。

## 九、演进与趋势

从 logits 对齐走向「序列级生成蒸馏」「步骤蒸馏（CoT）」「多教师集成蒸馏」；并用拒绝采样、PRM 筛选高质量教师轨迹。与量化、剪枝组合成「压缩流水线」。趋势是「自蒸馏」与「蒸馏 + RL」混合，让小模型在有限容量下最大化继承大模型能力，并扩展到多模态与 agent 行为蒸馏。

## 十、小结

知识蒸馏用教师的软标签/生成/中间表示指导学生，传递硬标签缺失的暗知识，是模型压缩与端侧部署的关键。经典 KD 靠温度软化的 KL 对齐分布；LLM 时代更常用「黑盒生成式蒸馏」与「CoT 步骤蒸馏」。其上限受学生容量与教师数据质量约束，落地应筛除教师偏见、合理设温度，并常与量化剪枝组合成完整压缩方案。
