# 模型并行：张量并行与流水线并行

> 对应 llm-course 与 Megatron-LM / Pipeline 经典。

## 一、核心概念

单卡放不下大模型时，需并行切分：

- **数据并行(DP)**：多卡各持全模型副本，分数据。通信梯度。
- **张量并行(TP)**：把每层权重按行/列切到多卡，前向中 all-reduce 拼接（Megatron 风格）。适合层内。
- **流水线并行(PP)**：按层切到不同卡，微批次流水执行（GPipe/ PipeDream）。引入气泡(bubble)需调度优化。
- **ZeRO/FSDP**：优化器状态、梯度、参数分片，显存均摊。

## 二、关键要点

| 并行 | 切什么 | 通信 |
|------|--------|------|
| DP | 数据 | 梯度 |
| TP | 层内权重 | 激活 |
| PP | 层 | 激活(层间) |
| ZeRO | 状态 | 分片 |

## 三、面试题

- 流水线并行的「气泡」是什么？
