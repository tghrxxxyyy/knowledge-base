# 量化基础：精度与标定

> 对应 llm-course「Quantization」与 GPTQ/AWQ/QLoRA 等论文。量化是推理降本的核心手段。

## 一、背景与挑战

大模型推理的成本主要由**显存带宽**与**显存容量**决定：权重需从显存搬到计算单元，参数量越大、每次搬运越贵。FP16 下 70B 模型仅权重就约 140GB，远超单卡。量化（quantization）用更低比特表示权重与激活，直接压缩体积、提升访存效率。核心挑战是：低比特会引入舍入误差，且权重/激活分布不均匀（存在离群值），粗暴量化会严重掉点。如何在 4-bit 甚至更低精度下保持精度，是工程落地的关键。

## 二、核心原理

精度阶梯（每参数字节）：

- **FP32**（4B）→ **FP16/BF16**（2B）→ **INT8**（1B）→ **INT4/NF4**（0.5B）。

两类量化：

- **训练后量化（PTQ）**：训练完直接把 FP16 权重映射到低位，无需重训，最常用。
- **量化感知训练（QAT）**：训练中就模拟量化误差，精度更好但成本高。

**标定（Calibration）**：PTQ 用一小批代表性数据估计量化参数（scale/zero-point），决定映射质量。仅权重量化（W4）与权重+激活量化（W4A8/W8A8）收益不同。

### 工程落地要点

- **先选精度再选算法**：端侧/单卡优先 4-bit（NF4/AWQ/GPTQ），服务器高吞吐优先 W8A8。
- **标定集要代表**：用真实业务分布的小样本（数百条）做 calibration，忌用无关语料。
- **激活不能忘**：要端到端提速必须量化激活（W4A8/W8A8），仅权重量化只省显存。
- **内核匹配**：确认推理框架（vLLM/llama.cpp/TensorRT-LLM）支持目标格式，否则不加速。
- **评测闭环**：量化后跑任务基准，掉点超阈值就换算法或回退到更高比特。
- **混合精度**：对敏感层（如 layernorm、输出头）保留高比特，平衡精度与体积。

## 三、形式化与数学基础

均匀量化把实数 $x$ 映射到整数 $q\in[0, 2^b-1]$：

$$
q = \text{clip}\left(\left\lfloor \frac{x}{\text{scale}} \right\rceil + z,\ 0,\ 2^b-1\right),\qquad
x \approx (q - z)\cdot \text{scale}
$$

对称量化取 $z=0$、范围 $[-|x|_{\max}, |x|_{\max}]$。误差来源为舍入与截断：

$$
\epsilon = |x - \hat x|,\qquad \text{SNR} \propto 2^{-b}
$$

激活量化需处理离群值：SmoothQuant 引入平滑系数 $s$，把激活离群迁移到权重：

$$
\tilde X = X \cdot \text{diag}(s)^{-1},\qquad \tilde W = W \cdot \text{diag}(s)
$$

保持 $XW = \tilde X \tilde W$，使两者均适合低比特。

## 四、代码实现

用 bitsandbytes 做 4-bit 加载（NF4）：

```python
from transformers import AutoModelForCausalLM, BitsAndBytesConfig
cfg = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_compute_dtype="bfloat16",
)
model = AutoModelForCausalLM.from_pretrained("meta-llama/Llama-3-8B",
                                             quantization_config=cfg)
```

PTQ 标定（以 GPTQ 为例）需先跑少量样本收集激活统计，再逐层量化。

## 五、与其他技术对比

| 精度 | 显存/权重 | 是否需标定 | 质量 |
|------|-----------|-----------|------|
| FP16 | 2B/param | 否 | 基准 |
| INT8(W8A8) | 1B | 是 | 几乎无损 |
| INT4/NF4(W4) | 0.5B | 是 | 好算法接近无损 |
| 2-bit | 0.25B | 是 | 明显掉点 |

## 六、常见误区

- **4-bit 一定崩**：QLoRA/GPTQ/AWQ 已能在多数任务接近 FP16，崩多因算法或标定不当。
- **只量化权重就够**：忽略激活量化时，W4A16 仍受激活带宽限制，收益有限。
- **标定数据随意**：标定集与真实分布偏差大，量化参数会失准。

## 九、演进与趋势

从均匀 INT 量化走向「非均匀 + 混合精度」：NF4 贴合正态权重、AWQ 保护重要通道、GPTQ 做逐层二阶补偿；更低比特（2-3 bit）借助「旋转/混合专家量化」逼近可用区。趋势是「硬件感知量化」——算法与 GPU 张量核心协同设计，让低比特真正提速而非仅省显存。

## 十、小结

量化通过降低权重/激活比特数压缩显存与带宽，是推理降本首选。PTQ 无需重训最实用，其质量依赖标定与算法（NF4/AWQ/GPTQ）。需同时关注权重量化与激活量化，并警惕离群值。选型按「精度-质量-硬件」三角权衡，4-bit 在好算法下已可接近 FP16。
