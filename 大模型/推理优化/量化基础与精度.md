# 量化基础：精度与标定

> 对应 llm-course「Quantization」与 GPTQ/AWQ/QLoRA 论文。量化是推理降本的核心手段。

## 一、核心概念

量化用更低比特表示权重/激活：FP32(4B) → FP16/BF16(2B) → INT8(1B) → INT4/NF4(0.5B)，成比例降低显存与带宽（算力也常受益）。两类：

- **训练后量化(PTQ)**：不重训，直接把训练好的 FP16 权重映射到低位。
- **量化感知训练(QAT)**：训练中就模拟量化误差。

**标定(Calibration)**：PTQ 用一小批代表数据估计量化参数(scale/zero-point)，决定映射质量。

## 二、数学形式（均匀量化）

```
quant(x) = round(x / scale) + zero_point
dequant(q) = (q - zero_point) * scale
```

对称量化 zero_point=0，范围 `[-|max|, |max|]`。

## 三、关键要点

| 精度 | 显存/权重 | 质量 |
|------|-----------|------|
| FP16 | 2B/param | 基准 |
| INT8 | 1B | 几乎无损 |
| INT4/NF4 | 0.5B | 需好算法 |

## 四、常见误区

- 认为 4-bit 一定崩——QLoRA/GPTQ 已能在多数任务接近 FP16。
- 忽略激活量化，仅权重量化收益有限。
