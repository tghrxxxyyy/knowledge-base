# 连续批处理 Continuous Batching

> 对应 vLLM / Orca 论文。推理吞吐的关键优化。

## 一、核心概念

传统静态批处理要等批次内最长序列结束才能释放整批，短请求被长请求拖住。连续批处理(又称 in-flight batching)在**每个生成步**动态地把完成的请求移出、新请求移入，按 token 步调度，极大提升 GPU 利用率与吞吐。

## 二、关键要点

- 与 PagedAttention 配合效果最佳（vLLM）。
- 是生产推理服务的标配。

## 三、与开源书的对应

- Yu et al., *Orca: A Distributed Serving System for Transformer-Based Generative Models*, 2022.
- vLLM 实现。
