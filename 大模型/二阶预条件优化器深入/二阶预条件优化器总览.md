# 二阶预条件优化器总览

> 对应 二阶优化与预条件综述；与 AdamW深入 / 学习率调度总览深入 衔接。

## 一、背景与挑战

一阶优化（SGD/Adam）忽略参数间曲率；二阶预条件用逆 Fisher/Hessian 近似加速收敛。

## 二、核心原理

预条件器 $P$ 将梯度变换 $P^{-1}g$ 使不同参数方向步长一致，等效做各向异性缩放。

## 三、数学形式

更新 $\Delta\theta = -\eta\,P^{-1}\nabla\mathcal L$；理想 $P=\mathcal H$（Hessian）得牛顿步。

## 四、代码实现

```python
precond = compute_precondition(P, grad)
step = lr * precond
```

## 五、与其他对比

- 与 Adam 的逐元素自适应不同，二阶预条件做矩阵级（层/张量）校正。
- 与 学习率预热深入 配合避免初期不稳。

## 六、常见误区

- 误以为二阶一定更快，受近似误差与开销抵消。
- 忽略预条件器的低秩/分块结构假设。

## 八、面试题

- 二阶预条件为何加速？答：校正参数间曲率各向异性，使更新方向更贴近牛顿方向。

## 九、演进

牛顿 → 拟牛顿 → 矩阵/张量预条件（Shampoo/KFAC）。

## 十、小结

二阶预条件以近似曲率做矩阵级校正，理论上加速但受实现成本制约。
