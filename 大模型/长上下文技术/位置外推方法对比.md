# 位置外推方法对比

> 对应旋转位置编码 RoPE（Su et al., 2021）、ALiBi（Press et al., 2021）、位置插值 PI（Chen et al., 2023）与 YaRN（Peng et al., 2023）等原始工作，并在 llm-course 中横向比较。详见本系列「旋转位置编码 RoPE」「上下文窗口扩展」。

## 一、背景与挑战

预训练时位置编码只在 $[0,L)$ 上见过样本。推理时若直接把位置推到 $[0,L')$（$L'>L$），许多编码会落入训练分布之外的区域，导致注意力退化、困惑度飙升。如何在不（或仅少量）重训的情况下让模型「外推」到更长位置，是长上下文工程的第一道关。

不同位置编码对外推的友好度差异巨大：有的天然支持任意长度（ALiBi），有的需插值改造（RoPE），有的几乎不可外推（可学习绝对编码）。本篇横向对比主流方案。

## 二、核心原理

- **正弦绝对编码**：位置 $pos$ 映射到固定频率的正弦/余弦向量，频率固定、无参数。外推时新位置频率仍在合理范围，但训练未见过，效果弱。
- **可学习绝对编码**：位置向量为可学习参数，超出词表索引直接越界，几乎不可外推。
- **ALiBi**：不显式编码位置，而在注意力分数上施加随距离线性衰减的偏置 $m\cdot(-d)$，近处加得多、远处加得少，使模型对距离敏感且天然支持更长序列。
- **RoPE + 缩放**：把位置先旋转再缩放频率。直接外推（NTK 之前）易崩；位置插值 PI 把位置线性压缩回训练区间；NTK-aware 在各频率维度做非均匀缩放；YaRN 进一步结合注意力温度与高频保护。

## 三、形式化与数学基础

ALiBi 的偏置（$i$ 为查询位置，$j$ 为键位置，$m$ 为 heads 共享的斜率）：

$$
\text{score}_{i,j}= \frac{q_i^\top k_j}{\sqrt{d}} - m\cdot(i-j)
$$

位置插值（PI）对 RoPE 角度做线性压缩，使目标长度 $L'$ 下的位置映射回 $[0,L)$：

$$
\theta' = \theta \cdot \frac{L}{L'}
$$

NTK-aware 不整体缩放，而是按频率维度分配缩放系数 $\alpha$，使低频（捕获全局结构）基本不变、高频（捕获局部细节）被压缩，缓解高频外推崩坏。YaRN 在此基础上引入缩放因子 $s$ 与注意力温度 $t$：

$$
t = 0.1 \ln s + 1
$$

## 四、代码实现

以 HuggingFace 启用不同 RoPE 缩放为例：

```python
from transformers import AutoConfig

# 位置插值（线性压缩）
cfg_pi = AutoConfig.from_pretrained("model", rope_scaling={"type": "linear", "factor": 4.0})

# NTK-aware 动态缩放
cfg_ntk = AutoConfig.from_pretrained("model", rope_scaling={"type": "dynamic", "factor": 4.0})

# YaRN
cfg_yarn = AutoConfig.from_pretrained(
    "model", rope_scaling={"type": "yarn", "factor": 4.0, "original_max_position_embeddings": 4096}
)
```

ALiBi 一般在模型架构层面支持，无需 `rope_scaling`，直接修改注意力偏置实现即可。

## 五、与其他技术对比

| 方法 | 机制 | 免训练外推 | 需继续训练 | 备注 |
|------|------|-----------|-----------|------|
| 正弦绝对 | 固定频率 | 弱 | 否 | 频率固定但分布外 |
| 可学习绝对 | 查表向量 | 几乎不可 | 否 | 越界即失效 |
| ALiBi | 距离线性偏置 | 强 | 否 | 推理天然外推 |
| RoPE 直接外推 | 旋转 | 弱 | 否 | 易崩 |
| RoPE + PI | 线性压缩 | 中 | 轻量 | 简单有效 |
| RoPE + NTK/YaRN | 频率/温度缩放 | 强 | 轻量 | 当前主流 |

## 六、常见误区

- **「RoPE 直接外推即可」**：超出训练位置后旋转角度落在未训练区间，长程检索准确率骤降。
- **「外推倍数越大越好」**：超过数十倍后即使 YaRN 也需继续训练巩固，否则远端信息丢失。
- **混淆 ALiBi 与 RoPE 缩放**：二者机制不同，不能简单套用同一缩放因子。
- **以为免训练方案可替代长训练**：免训练适合快速验证，真长上下文能力仍靠长序列继续训练。

## 九、演进与趋势

- **从单点缩放走向组合**：NTK + 温度 + 高频保护（YaRN）成为 RoPE 系事实标准。
- **免训练 → 轻量继续训练**：先缩放验证，再以长序列语料做「long pretraining」固化能力。
- **架构层外推**：如 ALiBi 在训练期就埋入外推性，测试期直接拉长。
- **与 KV 压缩协同**：外推解决「能否看」，KV 压缩解决「能否装下」。

## 十、小结

位置外推没有银弹：ALiBi 天生外推但需架构支持，RoPE 系靠 PI/NTK/YaRN 缩放实现免训练扩容，但其能力随倍数增大而衰减，终需继续训练兜底。选型应结合「是否可改架构、目标倍数、能否继续训练」三要素，具体参数与上限以官方最新文档为准。
