# 注意力稀疏化

> 对应 Beltagy et al., *Longformer*（2020）；Wang et al., *Linformer*（2020）；Choromanski et al., *Performer*（2021, 线性注意力）；Dao et al., *FlashAttention*（2022）；参考 Vaswani et al., 2017。

## 一、背景与挑战

标准自注意力对序列长度 $n$ 的复杂度为 $O(n^2)$（时间与显存），且 $O(n^2)$ 的注意力矩阵在长序列下不可承受：128K token 时单序列注意力分数矩阵达 $1.6\times10^{10}$ 项。稀疏化目标是在**尽量保留模型能力**的前提下，把计算/显存降到近线性。核心权衡是：稀疏模式越激进、省得越多，但越可能丢失全局交互信息。

## 二、核心原理

稀疏化按模式分：(1) **局部窗口**（Longformer）：每个 token 只看邻近窗口 + 少量全局 token，复杂度 $O(n\cdot w)$；(2) **块状/低秩**（Linformer）：把键/值投影到固定 $k$ 维，$O(n\cdot k)$；(3) **线性注意力**（Performer / Linear Transformer）：用核函数 $\phi(Q)\phi(K)^T$ 近似 softmax，把 $O(n^2d)$ 降为 $O(n d^2)$，可流式；(4) **滑动窗口 + 全局**（BigBird）。注意 **FlashAttention 并非稀疏**：它通过 tiling 与重算把 IO 降到 $O(n^2)$ 但数学不变，是长序列推理的基石加速器。

## 三、形式化与数学基础

标准注意力：

$$\text{Attn}(Q,K,V)=\text{softmax}\!\left(\frac{QK^\top}{\sqrt{d}}\right)V$$

局部窗口（窗口宽 $w$）只算近邻：

$$\text{Attn}_i = \sum_{j\in[i-w,i+w]} \alpha_{ij} V_j,\quad \alpha_{ij}\propto \exp(q_i k_j^\top/\sqrt{d})$$

线性注意力用核 $\phi$ 重写（无 softmax）：

$$\text{LinearAttn} = \phi(Q)\big(\phi(K)^\top V\big) = \phi(Q)\,S,\quad S\in\mathbb{R}^{d\times d}$$

因 $S$ 与 $n$ 无关，先算 $\phi(K)^\top V$ 得 $O(nd^2)$，整体 $O(nd^2)$。误差来自核近似：$\|\text{Attn}-\text{LinearAttn}\| \approx O(1/\sqrt{m})$（$m$ 为映射维度）。

## 四、代码实现

```python
import torch
from torch.nn.functional import scaled_dot_product_attention as sdpa

# 局部窗口稀疏：构造因果+窗口 mask
def window_mask(n, w):
    m = torch.full((n, n), float("-inf"))
    for i in range(n):
        m[i, max(0, i-w):i+1] = 0.0
    return m

attn = sdpa(q, k, v, attn_mask=window_mask(n, w=512))
# FlashAttention（丢弃 mask、IO 优化）由 backend 自动选，或：
# attn = sdpa(q, k, v, is_causal=True)   # 底层走 FlashAttention-2
```

线性注意力需自定义 $\phi$（如 ReLU/elu 映射）并维护 $S$ 增量更新以流式。

## 五、与其他优化对比

| 方法 | 复杂度 | 改数学 | 全局 |
|---|---|---|---|
| 全注意力 | $O(n^2)$ | 否 | 强 |
| Longformer | $O(nw)$ | 否(稀疏) | 弱(需全局tok) |
| Linformer | $O(nk)$ | 近似 | 中 |
| 线性注意力 | $O(nd^2)$ | 近似 | 弱 |
| FlashAttention | $O(n^2)$ | 否 | 强(快) |

## 六、常见误区

- 认为 FlashAttention 是稀疏：它只优化 IO、数学等价，仍 $O(n^2)$。
- 局部窗口无需全局 token：会丢失跨段信息，长程推理崩。
- 线性注意力无损：核近似有误差，难复现全注意力精度。
- 稀疏模式一刀切：不同层需不同稀疏度，深层更需全局。

## 八、面试题

1. 局部窗口稀疏为何还需全局 token？答：窗口阻断跨段交互，全局 token 提供全序列信息通道。
2. FlashAttention 是否降低复杂度？答：不降，数学等价全注意力，只降 IO 显存/时间。
3. 线性注意力快在哪？答：先算 $d\times d$ 统计量，复杂度与 $n$ 线性。

## 九、演进与趋势

稀疏从静态窗口走向可学习/动态稀疏（如 Routing/BigBird、长期记忆压缩），并与 FlashAttention 的 IO 优化互补；推理侧更常用「滑动窗口 + 全局 + KV 量化」组合而非改变数学。

## 十、小结

注意力稀疏化用窗口/块状/线性核近似把 $O(n^2)$ 降到近线性，代价是可能损失全局交互（需全局 token 补偿）。FlashAttention 虽不改数学，却是长上下文推理的 IO 基石——稀疏与 IO 优化应协同而非混淆。
