# 注意力稀疏化

> 见「注意力复杂度与优化」。聚焦长上下文场景。

## 一、核心概念

长序列下全注意力 `O(n²)` 不可行，稀疏化只计算重要位置对：

- **局部窗口**(Longformer)：每个 token 只看邻近窗口 + 全局 token。
- **块状(blockwise)**：分块计算。
- **线性注意力**：核近似 `O(n·d²)`(Performer/Linear Transformer)。

## 二、关键要点

- 稀疏会损失全局交互，需配合全局 token。
- FlashAttention 不改数学但降 IO，是长上下文推理基石。
