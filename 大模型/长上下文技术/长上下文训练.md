# 长上下文继续训练

> 对应 Chen et al., *Extending Context Window of LLMs via Positional Interpolation* (NTK / PI, 2023)；kaiokendev、Meta *RoPE scaling*；参考 HuggingFace `rope_scaling` 文档。

## 一、背景与挑战

预训练模型的上下文窗口（如 4K/8K）常不足以覆盖长文档、长对话、代码库。直接把窗口扩到 32K/128K 而不调整，位置编码会落到训练时未见的远端，导致注意力失效。挑战在于：如何以较低成本（继续训练而非从头训）把「短上下文能力」迁移到长上下文，同时不破坏已有短程能力，并控制算力与数据需求。

## 二、核心原理

核心思路是在更长序列上**继续预训练（或 SFT）**，并配合位置编码调整：(1) **NTK-aware / Positional Interpolation（PI）**——把 RoPE 的旋转基频下调，使长位置被「插值」进原训练范围，而非外推到未知区；(2) **学习率调小 + warmup**——避免破坏已学权重；(3) **序列打包（packing）**——把多个短文档拼成长样本，提升长序列数据利用率；(4) **数据配比**——训练数据需含足够长程依赖文档，否则学不会长距离。YaRN 等进一步分段缩放，兼顾长短位置。

## 三、形式化与数学基础

RoPE 中位置 $m$ 的旋转角由基频 $\theta$ 决定：$f(m,d)=\theta^{-2d/D} m$，远距离 $m$ 角差大。Positional Interpolation（PI）把最大位置 $L$ 压缩到原 $L'$：

$$\tilde m = \frac{L'}{L}\, m,\qquad \text{等效缩放基频}\ \theta'=\theta^{L'/L}$$

NTK-aware 则按比例缩放各维度频率而非线性插值：

$$\theta' = \theta \cdot \alpha^{-1/(D/2)},\quad \alpha = \frac{L}{L'}$$

YaRN 引入维度加权 $\lambda_d\in[0,1]$，只对高频维度缩放，保留低频（长距离）信息：

$$\text{RoPE}'(m,d)=\lambda_d\cdot f(m,d)$$

## 四、代码实现

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model = AutoModelForCausalLM.from_pretrained("base-8k")
# 把窗口扩到 32K：线性插值 RoPE
model.config.rope_scaling = {"type": "linear", "factor": 4.0}
model.config.max_position_embeddings = 32768
tokenizer.model_max_length = 32768

# 继续训练：小 LR + warmup，长文档 packing 成 32K 样本
trainer = Trainer(
    model, args=TrainingArguments(
        learning_rate=2e-5,          # 远小于预训练
        lr_scheduler_type="cosine", warmup_ratio=0.03,
        per_device_train_batch_size=1, gradient_accumulation_steps=64,
    ), train_dataset=long_packed_dataset,
)
trainer.train()
```

## 五、与其他扩展方法对比

| 方法 | 改什么 | 成本 | 风险 |
|---|---|---|---|
| 从头长训 | 全部 | 极高 | 低 |
| PI/NTK 继续训 | RoPE | 中 | 短程略损 |
| 外推(不调) | 无 | 低 | 远端失效 |
| 窗口注意力 | 结构 | 中 | 跨窗弱 |

## 六、常见误区

- 直接改 max_position 不调 RoPE：远端位置外推到未知区，注意力崩。
- 训练数据全是短文本：学不会长程依赖，扩展无效。
- 用原预训练 LR：破坏短程能力，灾难性遗忘。
- 忽略 packing 边界：拼接处跨文档污染，需特殊分隔符/attn mask。

## 八、面试题

1. 长上下文继续训练为何要序列打包？答：把多短文档拼成长样本，提升长序列数据利用率与显存效率。
2. 为何要调 RoPE 而非直接扩窗口？答：不调则远端位置外推到训练未见区，注意力失效；PI/NTK 插值使其落入已知范围。
3. 为何 LR 要更小？答：避免覆盖已学短程能力，防灾难性遗忘。

## 九、演进与趋势

从 PI/NTK 到 YaRN、LongRoPE（非均匀缩放聚焦重要维度）、以及「训练时动态位置」方法，扩展倍数从 4× 提升到 32×+。配合长上下文数据合成（如 BookQA 长链），成本和风险持续下降。

## 十、小结

长上下文扩展 = 位置编码缩放（PI/NTK/YaRN）+ 小 LR 继续训练 + 长文档 packing。核心是让远端位置「插值」进已知范围而非外推，并配以含长程依赖的数据，方能在不重训的前提下安全拉长窗口。
