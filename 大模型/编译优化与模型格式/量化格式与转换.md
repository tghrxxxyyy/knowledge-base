# 量化格式与转换

> 见「模型量化部署实战」与「编译优化与模型格式/模型格式对比」。

## 一、背景与挑战

量化权重需统一格式以便引擎加载（如 GPTQ/AWQ/FP8）。

## 二、核心原理

各量化法产出不同张量布局（分组/缩放），引擎需对应 kernel 读取；转换工具（如 AutoAWQ→GGUF）做桥接。

## 三、关键要点

- 格式与 kernel 强绑定。
- 混精度需引擎支持。

## 四、代码实现

```python
# 量化权重存为专用格式
qweight, scales = awq_quantize(w, bits=4)
```

## 五、与其他对比

- 训练后格式多样；需互转生态。

## 六、常见误区

- 任意引擎都能读任意量化——需匹配。
