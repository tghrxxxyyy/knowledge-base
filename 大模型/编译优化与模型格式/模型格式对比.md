# 模型格式对比

> 对应 llm-course 部署章与 safetensors 文档。

## 一、背景与挑战

模型需跨框架/跨设备存储与加载，格式影响安全、速度与兼容。

## 二、核心原理

- **PyTorch(.pth/.bin)**：易用但有 pickle 安全风险。
- **Safetensors**：纯张量、无执行、加载快安全。
- **GGUF**：llama.cpp 单文件，含分词/配置。
- **ONNX**：跨框架中间表示。

## 三、关键要点

| 格式 | 安全 | 跨框架 | 场景 |
|------|------|--------|------|
| .bin | 否(pickle) | 否 | 研究 |
| safetensors | 是 | 否 | HF 标准 |
| GGUF | 是 | 否 | 端侧 |
| ONNX | 是 | 是 | 部署 |

## 四、代码实现

```python
from safetensors.torch import save_model
save_model(model, "m.safetensors")
```

## 五、与其他对比

- safetensors 取代 pickle 成 HF 默认。

## 六、常见误区

- .bin 绝对安全——pickle 可执行代码。

## 七、与开源书对应

- safetensors: https://github.com/huggingface/safetensors
- llm-course: https://github.com/mlabonne/llm-course

## 八、面试题

- 为何 safetensors 比 pickle 安全？

## 九、演进

pickle → safetensors → GGUF/MLC。

## 十、小结

格式选型关乎安全与可移植。
