# 算子融合与内核

> 见「推理引擎TensorRT」与「编译优化与模型格式/TVM编译栈」。

## 一、背景与挑战

逐算子调用有内存来回开销，融合可减延迟增吞吐。

## 二、核心原理

把相邻算子（如 LayerNorm+MatMul、激活）融合为单内核，减少 kernel 启动与中间读写；FlashAttention 即注意力融合范例。

## 三、数学形式

融合后访存：

```
mem_access_fused < Σ mem_access_sep
```

## 四、代码实现

```python
# 伪：融合 LayerNorm+Linear
y = fused_layernorm_linear(x, w, gamma, beta)
```

## 五、关键要点

- 访存受限场景收益大。
- 需硬件友好实现。

## 六、与其他对比

- 图优化在 IR 层；内核融合在算子层。

## 七、常见误区

- 融合总更快——小算子融合收益有限。
