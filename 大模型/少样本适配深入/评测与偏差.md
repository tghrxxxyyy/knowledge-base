# 少样本评测与偏差

> 对应 Zhao et al., 《Calibrate Before Use》, 2021；少样本标签/顺序偏置。

## 一、背景与挑战

ICL 对示例顺序、标签词、格式极度敏感，评测结果不稳定。

## 二、核心原理

存在位置偏置（末位偏好）、先验偏置（多数类）、格式偏置；需多排列取平均并校准。

## 三、数学形式

校准 $P_{cal}(y) = \frac{P(y|x)}{\sum_{y'}P(y'|x)} \cdot \frac{1}{P_{prior}(y)}$ 抵消先验。

## 四、代码实现

```python
accs = [eval_with_order(demos, perm) for perm in permutations]
report(mean(accs), std(accs))
```

## 五、与其他对比

- 与 提示工程与模板深入（格式敏感）共享。
- 与 面试题/模型评测指标深入 衔接。

## 六、常见误区

- 单次随机顺序报结果不可靠。
- 忽略标签词选择致虚假高分。
