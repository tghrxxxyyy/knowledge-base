# 少样本适配总览

> 对应 Brown et al., 《Language Models are Few-Shot Learners》(GPT-3), 2020；上下文学习范式。

## 一、背景与挑战

新任务标注少；传统微调需大量数据，少样本适配追求以极少样本或纯提示完成任务。

## 二、核心原理

两类：(1) 上下文学习 ICL，把若干示例拼入提示让模型推断；(2) 参数高效微调（LoRA/适配器）用小数据更新少量参数。

## 三、数学形式

ICL 条件概率 $P(y|x, \{(x_i,y_i)\}_{i=1}^k) \approx P(y|\text{concat}(demos, x))$。

## 四、代码实现

```python
prompt = demos + f"\n问题: {x}\n回答:"
out = llm(prompt)
```

## 五、与其他对比

- 与 提示工程与模板深入（ICL 靠提示）共享。
- 与 参数高效微调深入（小样本训参）衔接。

## 六、常见误区

- 示例顺序/格式强烈影响结果。
- 少样本仍可能过拟合到示例风格。

## 八、面试题

- 少样本适配两条路？答：ICL 用提示内示例推断；参数微调用小数据更新少量参数。

## 九、演进

全量微调 → ICL → 参数高效少样本微调。

## 十、小结

少样本适配兼顾提示与轻量微调，降低新任务数据门槛。
