# 上下文学习机制（ICL）

> 对应 Olsson et al., 《In-Context Learning via Induction Heads》, 2022；机制解释。

## 一、背景与挑战

ICL 不需梯度更新却能从示例中学习，机制成谜；需理解其如何工作。

## 二、核心原理

归纳头（induction heads）复制上下文模式；模型把示例视为隐式任务说明，通过注意力检索并套用。

## 三、数学形式

注意力复制概率近似 $P(y|x,demos) \propto \sum_i \text{match}(x, x_i)\cdot P(y_i)$。

## 四、代码实现

```python
# 示例顺序影响归纳头复制效果
prompt = reorder(demos, by="similarity_to", x) + x
```

## 五、与其他对比

- 与 提示工程与模板深入（格式敏感）共享。
- 与 检索增强少样本深入（检索示例）衔接。

## 六、常见误区

- 以为 ICL 真在做梯度学习（实为模式匹配）。
- 示例标签随机翻转仍有一定性能（任务识别）。

## 八、面试题

- ICL 为何有效？答：大模型经预训练学会从上下文复制/归纳模式，由注意力检索示例套用。

## 九、演进

现象观察 → 归纳头机制 → 理论（贝叶斯/隐变量）。

## 十、小结

ICL 依赖预训练习得的能力，机制近似上下文模式归纳而非真学习。
