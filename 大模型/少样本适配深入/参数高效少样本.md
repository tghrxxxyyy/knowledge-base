# 参数高效少样本适配

> 对应 Houlsby et al., 《Adapter》, 2019；以及 Hu et al., 《LoRA》, 2021。

## 一、背景与挑战

全量微调小数据易过拟合；参数高效方法只训少量参数适配新任务。

## 二、核心原理

在 Transformer 层插适配器（瓶颈 MLP）或低秩矩阵（LoRA），冻结主干，仅更新新增参数。

## 三、数学形式

LoRA：$W = W_0 + \Delta W = W_0 + BA$，$A\in\mathbb R^{d\times r}, B\in\mathbb R^{r\times k}$，$r\ll d$。

## 四、代码实现

```python
for p in model.parameters(): p.requires_grad = False
lora = LoRALinear(model.linear, r=8)
loss = train(lora, small_data)
```

## 五、与其他对比

- 与 少样本适配总览（ICL 对照）互补。
- 与 灾难性遗忘缓解深入（LoRA 也用于持续学习）衔接。

## 六、常见误区

- 秩 r 过大失去参数高效。
- 学习率相对全量微调需更大。

## 七、与开源书对应

## 八、面试题

- LoRA 为何高效？答：低秩分解增量权重，仅训小矩阵，参数少、不易过拟合、易切换。

## 九、演进

Adapter → Prefix/Prompt Tuning → LoRA/QLoRA。

## 十、小结

参数高效微调以少量可训参数完成少样本适配，省资源且稳。
