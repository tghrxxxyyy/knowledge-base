# 提示工程与模板

> 对应 Liu et al., 《Pretrain, Prompt, and Predict》综述, 2021；以及 Prompt Engineering Guide。

## 一、背景与挑战

提示格式/措辞显著改变输出；需系统化设计少样本模板。

## 二、核心原理

用占位符模板拼示例与查询；可选思维链（CoT）促推理；模板搜索/自动提示（AutoPrompt）提效。

## 三、数学形式

模板化 $x_{prompt} = T(x; \{x_i,y_i\})$；CoT 使 $P(y) = \prod_t P(step_t|steps_{<t},x)$。

## 四、代码实现

```python
template = "示例:\n{q1} -> {a1}\n{q2} -> {a2}\n问题: {q}\n回答:"
prompt = template.format(q1=.., a1=.., q=q)
```

## 五、与其他对比

- 与 上下文学习机制深入（模板影响归纳）共享。
- 与 查询改写与扩展深入（提示改写）衔接。

## 六、常见误区

- 模板中示例标签错误仍被学（需真标注）。
- 过多示例超出上下文。

## 八、面试题

- 思维链对少样本作用？答：显式中间步骤分解推理，显著提升复杂任务少样本表现。

## 九、演进

手工模板 → 自动提示搜索 → 自动 CoT/自洽。

## 十、小结

提示工程系统化模板与 CoT 是少样本关键，格式与示例质量决定成败。
