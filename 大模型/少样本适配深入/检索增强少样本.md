# 检索增强少样本适配

> 对应 Rubin et al., 《Retrieval-Augmented Few-Shot》, 2022（检索最相关示例）。

## 一、背景与挑战

固定示例未必贴合查询；检索与查询相似的示例可显著提升 ICL。

## 二、核心原理

用查询的嵌入从训练库检索最相似样本作演示（kNN prompt），比随机示例更有效。

## 三、数学形式

演示集 $D_q = \text{topk}_{x_i} \cos(E(q), E(x_i))$；再以 $D_q$ 构造提示。

## 四、代码实现

```python
demo_idx = knn(E(q), E(train_x), k=4)
prompt = build_prompt([train[d] for d in demo_idx], q)
```

## 五、与其他对比

- 与 向量检索算法深入（检索底座）衔接。
- 与 上下文学习机制深入（示例质量）共享。

## 六、常见误区

- 检索相似但标签错的示例害大于利。
- 检索库与任务分布不一致。

## 八、面试题

- 检索示例为何更好？答：与查询语义相近的演示更贴合任务模式，ICL 效果更好。

## 九、演进

随机示例 → 检索相似示例 → 检索+重排示例。

## 十、小结

检索增强让少样本示例动态贴合查询，是 ICL 的实用增强。
