# 群体公平与个体公平

> 对应 Dwork et al., *Fairness through Awareness*, 2012（个体公平）。

## 一、背景与挑战

群体层面公平不保证个体间公正；个体公平要求相似个体获相似对待。

## 二、核心原理

个体公平用度量 $d(x,x')$ 约束 $|h(x)-h(x')|\le d$；群体公平看分布；二者张力需在应用中平衡。

## 三、数学形式

个体公平：$\forall x,x',\,|h(x)-h(x')|\le L\cdot d(x,x')$（Lipschitz 约束）。

## 四、代码实现

```python
viol = max(abs(h(x)-h(xp)) for x,xp in pairs if d(x,xp)<eps)
```

## 五、与其他对比

- 与 偏见与去偏深入（个体层面刻板印象）衔接。
- 与 公平性深入 总览互补。

## 六、常见误区

- 仅靠群体指标忽略个体不公。
- 个体度量难定义（相似度主观）。
