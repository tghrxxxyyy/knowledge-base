# 公平性总览

> 对应 Barocas, Hardt & Narayanan, *Fairness and Machine Learning*, 2019。

## 一、背景与挑战

模型对受保护群体（性别、种族）可能产生歧视性结果；公平需在数学上被定义与度量。

## 二、核心原理

公平性研究定义群体/个体层面的公平准则，并量化其与准确率的权衡；LLM 中表现为生成偏见与机会不均。

## 三、数学形式

群体公平性常以条件独立 $\hat Y \perp A \mid Y$（equalized odds），$A$ 为敏感属性。

## 四、代码实现

```python
gap = abs(recall(sub_a) - recall(sub_b))
```

## 五、与其他对比

- 与 偏见与去偏深入（来源与修正）衔接。
- 与 价值对齐深入（群体权重）相关。

## 六、常见误区

- 以为单一指标即公平。
- 混淆无歧视输入与公平输出。

## 八、面试题

- 为何公平性难定义？答：多种准则不可兼得，需按场景取舍。

## 九、演进

个体无偏 → 群体公平 → 因果公平。

## 十、小结

公平性是形式化伦理，需明确定义与度量。
