# 公平性的数学定义

> 对应 Kleinberg et al., 2017；Hardt et al., *Equality of Opportunity*, 2016。

## 一、背景与挑战

不同公平定义彼此冲突，选错会误导治理。

## 二、核心原理

常用：人口均等（demographic parity）$\hat Y\perp A$；机会均等（equal opportunity）$Y=\hat Y$ 下 $P(\hat Y=1|A=0)=P(\hat Y=1|A=1)$；预测均等（equalized odds）更强。

## 三、数学形式

机会均等：$P(\hat Y=1|A=a,Y=1)=const$；人口均等：$P(\hat Y=1|A=a)=const$。

## 四、代码实现

```python
def equal_opportunity(pred, y, a):
    return [recall(pred[y==1], a==g) for g in groups]
```

## 五、与其他对比

- 与 偏见与去偏深入（修正目标）衔接。
- 与 价值对齐深入（群体权重）相关。

## 六、常见误区

- 人口均等忽略基础率差异。
- 假设敏感属性可得（常不可得）。

## 八、面试题

- 机会均等 vs 人口均等？答：前者只在正类上均衡，后者无条件，常不可兼得。

## 九、演进

单一定义 → 多定义对比 → 因果公平。

## 十、小结

公平定义需按场景选，且认识其不可兼得。
