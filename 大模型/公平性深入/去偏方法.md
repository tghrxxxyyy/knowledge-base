# 公平性去偏方法

> 对应 Hardt et al., 2016 后处理；Kamiran & Calders 重加权。

## 一、背景与挑战

偏差来自数据、表示、决策；需分阶干预。

## 二、核心原理

预处理（重加权/重采样）、训练中（公平约束/对抗去偏）、后处理（阈值调平）。LLM 中加去偏 SFT 数据。

## 三、数学形式

重加权：$w_i\propto \frac{P_{ideal}(a)}{P_{obs}(a)}$；对抗：$ \min_h\max_g \mathcal L_{task}-\lambda \mathcal L_{adv} $。

## 四、代码实现

```python
sample_w = ideal_rate[a] / obs_rate[a]
train(weights=sample_w)
```

## 五、与其他对比

- 与 偏见与去偏深入（具体去偏术）衔接。
- 与 公平性深入 总览互补。

## 六、常见误区

- 只在后处理掩盖偏差。
- 去偏损某群体反而更不公。
