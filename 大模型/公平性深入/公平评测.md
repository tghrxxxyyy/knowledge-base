# 公平性评测

> 对应 Holstein et al., *Improving Fairness in ML Practice*, 2019。

## 一、背景与挑战

公平需持续度量，否则回归。

## 二、核心原理

在切片（子群体）上报告指标差异，做偏差审计与回归测试；用公平性仪表盘监控。

## 三、数学形式

差异 $\Delta_k = m_k - m_{ref}$；告警当 $|\Delta_k|>\tau$。

## 四、代码实现

```python
for g in slices: assert gap(metric(g)) < tau
```

## 五、与其他对比

- 与 偏见与去偏深入（刻板印象度量）共享。
- 与 价值对齐深入（评测）相关。

## 六、常见误区

- 只在总体指标看公平。
- 切片缺失（未覆盖小群体）。

## 八、面试题

- 公平评测关键？答：子群体切片报告+审计+回归守护。

## 九、演进

总体指标 → 切片审计 → 持续监控。

## 十、小结

公平评测靠切片与守护，持续而非一次性。
