# 输出解析与校验

> 把非结构化生成转为可用数据。

## 一、核心概念

模型输出常需解析为 JSON/结构化对象。手段：prompt 约束 + 输出解析器(Pydantic/JSON parser) + 校验(类型/范围) + 失败重试 + 约束解码(见提示工程)。

```python
from pydantic import BaseModel
class Result(BaseModel):
    sentiment: str
    confidence: float
# 用 function calling 或 JSON 模式保证结构
```

## 二、关键要点

- 校验失败应重试或降级，勿直接崩溃。
- 约束解码最稳，prompt 约束次之。
