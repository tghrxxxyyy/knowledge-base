# 输出解析与校验

> 对应把非结构化生成转为可用数据；约束生成思想参考 Guidance / Outlines / JSON mode 与函数调用（OpenAI function calling）。

## 一、背景与挑战

模型输出是自由文本，但应用常需要结构化数据：分类标签、抽取字段、JSON 配置、工具参数。直接 `json.loads(model_output)` 极易因多余解释、格式漂移、截断而失败。生产需要「稳健地把生成结果解析并校验为可信对象」。

挑战：(1) 模型偶尔输出前言后语而非纯 JSON；(2) 字段类型/范围不符（如置信度 >1）；(3) 长输出被 `max_tokens` 截断导致 JSON 不完整；(4) 需失败可重试/降级而非崩溃；(5) 高可靠场景要求「约束解码」而非事后解析。

## 二、核心原理

手段按稳健性递增：

- Prompt 约束：在提示里写明输出格式并给示例（few-shot），最弱但零成本。
- 输出解析器：用 Pydantic/JSON schema 描述结构，解析并做类型/范围校验。
- 模式强制（JSON mode / function calling）：让模型按 schema 输出，大幅降低格式错误。
- 约束解码（Guidance/Outlines）：在生成时按语法/正则限制 token，从源头保证结构合法，最稳。
- 失败处理：校验不通过则重试或降级返回，不把异常抛给用户。

## 三、形式化与数学基础

设目标结构由 schema $\mathcal{S}$ 定义（字段名、类型、约束）。解析器 $\Phi$ 把生成文本映射：

$$\Phi: \text{text} \to \hat o \in \mathcal{S} \cup \{\text{fail}\}$$

校验函数 $V(\hat o)$ 检查类型与约束（如 $0\le \text{confidence}\le 1$）。约束解码把生成限制为合法语言 $\mathcal{L}(\mathcal{S})$，使得：

$$\forall y\sim P_\theta(\cdot\mid x,\text{constrained}),\quad \Phi(y)\neq\text{fail}$$

即从分布层面消除格式失败，而非事后修补。

## 四、代码实现

用 Pydantic 定义结构并由解析器校验（示意）：

```python
from pydantic import BaseModel, Field
from openai import OpenAI

class Result(BaseModel):
    sentiment: str = Field(pattern="^(正面|中性|负面)$")
    confidence: float = Field(ge=0, le=1)

# 用 JSON mode / function calling 让模型按 schema 输出，再校验
resp = client.chat.completions.create(
    model="gpt-4o-mini",
    response_format={"type": "json_object"},
    messages=[{"role":"user","content":"评价情感: 这部手机很棒"}])
obj = Result.model_validate_json(resp.choices[0].message.content)
```

## 五、与其他技术对比

| 方式 | 稳健性 | 成本/复杂度 |
|------|--------|-------------|
| Prompt 约束 | 低 | 零 |
| 解析器+校验 | 中 | 低 |
| JSON mode | 高 | 低 |
| 约束解码 | 最高 | 中（需特殊引擎） |

生产优先 JSON mode/函数调用，极致可靠再上约束解码。

## 六、常见误区

- 直接 `json.loads` 不校验，模型多说一句就崩溃。
- 只用 prompt 约束，格式仍随机漂移。
- 截断导致 JSON 不完整却不检测。
- 校验失败直接抛异常，未重试或降级。
- 用正则硬抠 JSON 而忽略嵌套与转义，边界 case 频错。

## 九、演进与趋势

从「生成后解析」到「生成即结构化」：约束解码走向主流；函数调用成为工具参数标准；多模态输出（图表/表格）的结构化解析；以及把输出 schema 与评测驱动绑定，自动检测字段漂移。

## 十、小结

输出解析与校验是「模型到系统」的接口层。用 JSON mode/函数调用保证格式，用 schema 校验保证语义，用重试/降级保证稳健，约束解码则在最可靠场景从源头消除格式错误。
