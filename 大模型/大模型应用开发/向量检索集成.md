# 向量检索集成

> 对应 llm-universe 与 RAG 基础设施；向量检索思想参考 RAG（Lewis et al. 2020）与近似最近邻（ANN）索引（如 FAISS、Milvus）。

## 一、背景与挑战

RAG 与语义搜索依赖「把文本变成向量，再按相似度找相关内容」。但把 embedding 与向量库接入应用有不少坑：查询文本与建库文本若用不同模型或不同预处理，语义空间错位，召回全废；库规模大时需 ANN 索引而非暴力扫描；还需处理元数据过滤与结果重排。

挑战：(1) 查询/建库必须用同一嵌入模型；(2) 预处理（标点、空格、语言）要一致；(3) 大规模需索引与分片；(4) 向量召回后常需与关键词/元数据混合；(5) 召回 top-k 的相关性需重排提升。

## 二、核心原理

向量检索分两段：

- 离线建库：文档切分 → 用 embedding 模型编码 → 写入向量库（FAISS/Milvus/PGVector 等），可选附带元数据。
- 在线查询：查询句用同一模型编码 → 向量库做 ANN 召回 top-k → （可选）重排 → 返回片段。

相似度常用余弦相似度；ANN 用 HNSW / IVF 等结构在精度与速度间权衡。生产常「向量召回 + 元数据过滤 + 重排（cross-encoder）」三段式。

## 三、形式化与数学基础

文档片段 $d_i$ 与查询 $q$ 经同一编码器 $E$ 得向量 $\mathbf{d}_i=E(d_i),\ \mathbf{q}=E(q)$。余弦相似度：

$$\text{sim}(\mathbf{q},\mathbf{d}_i)=\frac{\mathbf{q}\cdot\mathbf{d}_i}{\|\mathbf{q}\|\|\mathbf{d}_i\|}$$

召回集合：

$$\mathcal{H}_q = \text{TopK}_i\, \text{sim}(\mathbf{q},\mathbf{d}_i)$$

对大规模库，暴力扫描 $O(N)$ 不可行，ANN 以近似换取 $O(\log N)$ 级查询，代价是少量召回损失，由重排补偿。混合检索可结合 BM25 关键词得分：

$$\text{score} = \lambda\, \text{sim}_{vec} + (1-\lambda)\, \text{score}_{bm25}$$

## 四、代码实现

用 FAISS 建库与查询（示意）：

```python
from langchain_community.embeddings import HuggingFaceBgeEmbeddings
from langchain_community.vectorstores import FAISS

emb = HuggingFaceBgeEmbeddings(model_name="BAAI/bge-large-zh")
db = FAISS.from_documents(chunks, emb)          # 离线建库
hits = db.similarity_search(query, k=4)         # 在线召回 top-4
for doc in hits:
    print(doc.page_content, doc.metadata)
```

进阶：对 `hits` 用 cross-encoder 重排，`rerank(query, [d.page_content for d in hits])[:top_k]`。

## 五、与其他技术对比

| 方案 | 适用规模 | 特点 |
|------|----------|------|
| 暴力扫描 | 小 | 精确但慢 |
| FAISS (本地) | 中 | 快、易部署 |
| Milvus/PGVector | 大/生产 | 分布式、元数据 |
| 混合检索 | 生产 | 向量+关键词 |

生产推荐「向量库 + 元数据过滤 + 重排」。

## 六、常见误区

- 查询与建库用不同嵌入模型或不同版本，语义空间错位，召回崩塌。
- 预处理不一致（一端去标点一端不去），相似度失真。
- 只靠向量召回忽略元数据过滤（如按时间/权限）。
- 不做重排，top-k 里最相关片段排不到最前。
- 索引未随数据更新重建，召回覆盖率下降。

## 九、演进与趋势

从单一向量到「混合检索（向量+BM25）+ 重排」；嵌入模型向更长上下文、多语言、领域微调演进；向量库原生支持过滤与量化；以及把「查询改写」「多向量（ColBERT）」纳入检索链路提升召回。

## 十、小结

向量检索集成 = 同一模型编码 + 索引召回 + 重排。最核心的纪律是「查询与建库语义空间一致」，再结合元数据过滤与重排，才能稳定支撑 RAG 与语义搜索。
