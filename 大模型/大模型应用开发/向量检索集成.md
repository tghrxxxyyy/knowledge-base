# 向量检索集成

> 对应 llm-universe。把 embedding + 向量库接入应用。

## 一、核心概念

离线建库 + 在线查询两段。注意：查询文本与建库文本用**同一嵌入模型**，且预处理(标点/空格)一致，否则语义错位。

## 二、代码实现

```python
from langchain_community.embeddings import HuggingFaceBgeEmbeddings
emb = HuggingFaceBgeEmbeddings(model_name="BAAI/bge-large-zh")
db = FAISS.from_documents(chunks, emb)
hits = db.similarity_search(query, k=4)
```
