# Agent 应用开发实战

> 对应 llm-universe「Agent 与工具调用」与 LangChain Agents。

## 一、核心概念

Agent 应用 = 模型 + 工具 + 循环 + 记忆。开发要点：定义工具 schema、实现执行器、设计系统提示(角色+规则+格式)、加最大步数、记录轨迹便于调试。

## 二、关键要点

| 模块 | 实现 |
|------|------|
| 工具 | schema + 执行函数 |
| 循环 | ReAct/Plan |
| 记忆 | 上下文+向量库 |
| 防护 | 步数/权限 |
