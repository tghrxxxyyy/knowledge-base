# 模型版本管理总览

> 对应模型注册表（MLflow Model Registry / Hugging Face Hub）；语义化版本。MLflow 提供注册表。

## 一、背景与挑战

模型迭代频繁，需可追溯、可复现、可回退的版本管理，避免线上权重混乱。

## 二、核心原理

每次训练产出带版本号与元数据的制品（权重、配置、分词器），注册入库；服务按版本引用。

## 三、数学形式

版本 $v$ 映射 $(W_v, cfg_v, metrics_v)$；路由 $r(x)\to W_{v^*}$，$v^*$ 由策略定。

## 四、代码实现

```python
reg = mlflow.register("llm", model_uri="runs:/abc/weights")
client.transition_stage(reg, "Production")
```

## 五、与其他对比

- 与 蓝绿部署实践（切版本）衔接。
- 与 回退与版本分支（版本树）共享。

## 六、常见误区

- 登记缺失配置致无法复现。
- 版本号手工易冲突。

## 七、与开源书对应

- mlabonne/llm-course：https://github.com/mlabonne/llm-course
- rasbt/LLMs-from-scratch：https://github.com/rasbt/LLMs-from-scratch

## 八、面试题

- 为何需注册表？答：集中管理版本与元数据，保证可追溯、可回退、可复现。

## 九、演进

文件系统 → Git LFS → 专用注册表（MLflow、HF）。

## 十、小结

版本管理是模型生命周期的脊梁，蓝绿与回退皆依赖它。
