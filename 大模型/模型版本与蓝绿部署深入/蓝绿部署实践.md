# 蓝绿部署实践（Blue-Green）

> 对应 blue-green deployment（K8s service 切换）；Istio 权重 0/100。blue-green 是经典部署模式。

## 一、背景与挑战

需零停机切换模型且可瞬间回退，蓝绿用两套环境达成。

## 二、核心原理

蓝（当前）绿（新）两环境同时运行，流量在网关层从蓝切到绿；异常即切回蓝。

## 三、数学形式

切换权重 $(w_{blue},w_{green})=(100,0)\to(0,100)$；回退为逆操作，耗时约 $0$。

## 四、代码实现

```python
svc.set_route(primary="green")   # 瞬时切换
if health("green") != ok:
    svc.set_route(primary="blue")
```

## 五、与其他对比

- 与 灰度发布总览（渐进）对照：蓝绿瞬时。
- 与 模型版本与蓝绿部署深入（版本切换）衔接。

## 六、常见误区

- 双环境资源翻倍成本高。
- 切前未充分预热 green 致冷启动超时。
