# 归一化与初始化协同

> 综合 《动手学深度学习》训练稳定性章节、He/Kaiming 初始化（He et al. 2015）、Xavier 初始化（Glorot & Bengio 2010）及残差网络（He et al. 2016）相关文献。

## 一、背景与挑战

深层网络训练不稳定的根源不是单一因素，而是「梯度消失/爆炸」「激活尺度漂移」「首层方差失控」共同作用的结果。单靠归一化无法解决全部问题：归一化稳定了层内激活尺度，但梯度能否健康地回传到浅层、首层输出方差是否合理，还需**初始化**与**残差连接**协同。这三者的配合，是训练百层乃至千亿参数网络的工程基础。

## 二、核心原理

三者各司其职：

- **初始化**：控制前向传播首层输出与反向梯度方差在合理范围（如 Xavier 保激活/梯度方差恒定，He 初始化针对 ReLU 族）。
- **归一化（LN/BN）**：每层把激活拉回稳定统计量，抑制逐层尺度累积。
- **残差连接**：提供梯度「高速通道」，使深层梯度可直接回传浅层，缓解消失。

三者叠加形成「首层可控 + 每层稳定 + 梯度直连」的稳健系统。此外，学习率 warmup 常与 Pre-Norm 搭配，避免初期大梯度震荡。

## 三、形式化与数学基础

以线性层 $y = Wx$ 为例，若 $x$ 各分量独立、方差 $\sigma_x^2$，权重 $W_{ij}$ 独立同分布零均值方差 $\sigma_w^2$，则：

$$\mathrm{Var}(y_j) = n_{\mathrm{in}}\,\sigma_w^2\,\sigma_x^2$$

Xavier 令前向方差守恒需 $\sigma_w^2 = 1/n_{\mathrm{in}}$；He 初始化针对 ReLU 半激活，取 $\sigma_w^2 = 2/n_{\mathrm{in}}$。残差块 $y = x + F(x)$ 的梯度：

$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y}\left(I + \frac{\partial F}{\partial x}\right)$$

恒等项 $I$ 保证梯度至少不衰减，是深层可训的关键。

## 四、代码实现

```python
import torch.nn as nn

def init_weights(m):
    if isinstance(m, nn.Linear):
        # He 初始化，适用于 ReLU 族
        nn.init.kaiming_normal_(m.weight, nonlinearity="relu")
        if m.bias is not None:
            nn.init.zeros_(m.bias)

model = nn.Transformer(...)          # 内部已含 LayerNorm
model.apply(init_weights)

# 训练常用 warmup 配合 Pre-Norm
optimizer = torch.optim.AdamW(model.parameters(), lr=3e-4)
scheduler = torch.optim.lr_scheduler.LinearLR(optimizer, total_iters=2000)
```

## 五、与其他技术对比

| 稳定手段 | 解决什么 | 单独够吗 | 协同对象 |
|----------|----------|----------|----------|
| 初始化 | 首层方差/梯度爆炸 | 否 | 归一化、残差 |
| 归一化 | 逐层尺度漂移 | 否 | 初始化、残差 |
| 残差 | 梯度消失 | 否 | 归一化、初始化 |
| warmup | 初期震荡 | 否 | Pre-Norm |

## 六、常见误区

- 误区一：加了归一化就稳。极深网络仍需合理初始化与残差，缺一不可。
- 误区二：初始化随便。错误方差会造成首层即饱和/爆炸，后续难救。
- 误区三：warmup 可省。大模型初期大学习率 + Pre-Norm 易震荡，warmup 几乎必需。

## 九、演进与趋势

(1) 现代大模型以「Pre-Norm + RMSNorm + 残差 + warmup + 学习计划」为标准配方。(2) 研究探索「无归一化」架构（如归一化-free Transformer），用初始化与缩放替代。(3) 初始化与缩放因子（如深度缩放 $1/\sqrt{L}$）被精细调参。(4) 分布式训练下，初始化的确定性（fixed seed）对复现愈发重要。

## 十、小结

训练稳定性是系统工程：归一化稳定层内尺度、初始化控制首层方差、残差提供梯度直连，三者协同缺一不可；再辅以学习率 warmup 与合理的残差放置（Pre-Norm），方能训练极深网络。理解它们的分工与耦合，是读懂大模型训练配方的关键。
