# 无位置编码的语言建模

> 对应 Haviv et al., *Transformer Language Models without Positional Encodings*, 2022。

## 一、背景与挑战

语言建模强依赖词序，移除位置编码是否真能训出可用 LM？

## 二、核心原理

Haviv 等训练了不加任何位置编码的 Transformer LM，发现：仅靠注意力与 token 顺序仍能学到相当语言知识；且在某种设定下对长度外推更鲁棒，但绝对困惑度通常略逊于带位置模型。

## 三、数学形式

无位置 LM：$P(x_t|x_{<t}) = softmax(W\cdot Attn_{noPE}(E_{x_{<t}}))$，预测分布经由无位置注意力的最后隐状态。

## 四、代码实现

```python
h = self.tok_emb(x)                 # 无 pos_emb
for layer in layers: h = layer(h)   # 仍自注意力，靠顺序聚合
return lm_head(h)
```

## 五、与其他对比

- 与 绝对位置编码深入 形成对照实验。
- 与 相对位置编码深入 相比，无位置更激进。

## 六、常见误区

- 认为无位置 LM 完全顺序盲；注意力仍捕顺序。
- 直接用于强语序任务（翻译）会明显退化。

## 八、面试题

- 无位置 LM 能学到语言知识吗？答：能，注意力与顺序聚合足以捕捉相当语言结构，但困惑度略逊。

## 九、演进

带位置 LM → 消融无位置 → 理解位置必要度。

## 十、小结

无位置 LM 证明语言知识可在无显式位置下被部分习得，深化了位置必要性认知。
