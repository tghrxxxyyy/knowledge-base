# 重排列等变与组合性

> 对应理论分析（置换等变性质）与 Haviv et al., 2022 对无位置语言模型的讨论。

## 一、背景与挑战

若不加位置编码，自注意力对输入排列是等变的：重排输入会重排输出。这在某些集合/组合任务反而是优点，但在语序任务成缺点。

## 二、核心原理

无位置 Transformer 是置换等变的集合函数；这利于集合型任务（如点云、集合预测），但会丢失词序。要既保组合性又捕顺序，需在等变骨架上注入受控的位置偏置（如 ALiBi）。

## 三、数学形式

若 $P$ 为置换矩阵，$Attn(PX)P = Attn(X)$ 在等变下成立；位置偏置打破此对称：$Attn_{bias}(PX)\neq P\,Attn_{bias}(X)$。

## 四、代码实现

```python
def is_equivariant(model, x, perm):
    return torch.allclose(model(x)[perm], model(x[perm]), atol=1e-4)  # 无位置时应近等变
```

## 五、与其他对比

- 与 绝对位置编码深入 对照：绝对 PE 直接打破等变性。
- 与 稀疏注意力深入 无关。

## 六、常见误区

- 把等变当缺陷；集合任务中等变恰是归纳偏置优势。
- 误以为加任何偏置都破坏组合性；可控偏置可折中。

## 八、面试题

- 无位置 Transformer 有什么性质？答：对输入排列等变，利于集合任务但丢失词序。

## 九、演进

强制位置 → 发现等变性 → 集合/组合任务利用等变。

## 十、小结

无位置编码揭示 Transformer 的等变本质，对集合与组合场景有独特价值。
