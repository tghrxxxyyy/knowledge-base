# 无位置编码实现

> 对应实践：构建去掉位置嵌入的 Transformer 并做对照实验。

## 一、背景与挑战

工程上如何干净地移除位置编码，并避免训练崩溃或评估偏差。

## 二、核心原理

实现要点：删除 pos_embedding 与 RoPE 调用；保住注意力中的相对偏置（如 ALiBi）或完全不加；注意 padding mask 仍带来顺序信号；评估需含强语序任务以体现差异。

## 三、数学形式

$h = tok\_emb(x)$（无 $+p_i$）；若用 ALiBi 则加偏置 $bias=-m|i-j|$，否则纯无位置。

## 四、代码实现

```python
class NoPosTransformer(nn.Module):
    def forward(self, x, use_alibi=False):
        h = self.tok_emb(x)                      # 无位置嵌入
        for L in self.layers:
            h = L(h, alibi=bias if use_alibi else None)
        return h
```

## 五、与其他对比

- 与 层归一化深入 同属模块级开关实现。
- 与 绝对位置编码深入 的“实现细节”互为反面。

## 六、常见误区

- 移除位置却保留 padding 序号，实验不纯。
- 仅在弱语序任务评测，误认为位置无用。

- 实现无位置模型注意什么？答：彻底去掉位置嵌入、控制 padding 信号、用强语序任务评测。

## 九、演进

全位置 → 可切换位置模块 → 系统消融。

## 十、小结

无位置编码实现是验证位置冗余性的实验基础，需严格控制变量。
