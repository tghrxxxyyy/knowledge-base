# 无位置编码总览

> 对应 Htut et al., *Do Transformers Really Learn Position?*, 2019；Ying et al., *Position, Padding and Predictions*, 2021；Haviv et al., *Transformer Language Models without Positional Encodings*, 2022。

## 一、背景与挑战

位置编码被视为 Transformer 必需，但多项研究发现：绝对位置信息对许多任务并非不可或缺，甚至移除后性能仅小幅下降。

## 二、核心原理

注意力机制本身通过计算 $QK^T$ 隐含了位置线索（token 在序列中的相对顺序影响聚合），再配合 padding/排序等结构信号，可部分替代显式位置编码；某些任务靠内容顺序即可。

## 三、数学形式

去掉 $p_i$ 后 $h_i=x_i$；注意力 $A_{ij}=softmax(q_i k_j^T/\sqrt d)$ 仍对输入排列敏感，因为不同的 $i$ 对应不同 $q_i$，聚合结果随位置变化。

## 四、代码实现

```python
h = tok_emb(x)                 # 不加任何位置编码
out = attention(h, h, h)       # 仅靠内容与注意力顺序
```

## 五、与其他对比

- 与 绝对位置编码深入 直接对立（此处主动移除）。
- 与 ALiBi（见 无限上下文深入）相似：都弱化显式绝对位置。

## 六、常见误区

- 以为完全无位置就顺序盲；注意力本身仍编码部分顺序。
- 在强语序任务（如翻译）移除位置会明显退化。

## 八、面试题

- 为什么有时去掉位置编码仍可工作？答：注意力对排列敏感且 padding/排序提供结构信号，部分替代显式位置。

## 九、演进

必需绝对位置 → 发现冗余 → 去位置/弱位置探索。

## 十、小结

无位置编码研究揭示位置信息的冗余性，推动了对“最少位置归纳偏置”的思考。
