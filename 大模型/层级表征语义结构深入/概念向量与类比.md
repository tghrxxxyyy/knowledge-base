# 概念向量与类比

> 对应 Mikolov et al., *Linguistic Regularities in Continuous Space*, 2013；king-man+woman=queen。

## 一、背景与挑战

词向量中语义关系是否以线性方向存在？这是"概念向量"假设的源头。

## 二、核心原理

很多关系可被单一方向近似：$v_{\text{queen}} \approx v_{\text{king}} - v_{\text{man}} + v_{\text{woman}}$。在上下文模型中该性质随层与上下文变弱但仍在抽象层可见。

## 三、数学形式

关系方向 $r = v_a - v_b$；预测 $v_{b'} = v_{a'} + r$，近邻检索得目标词。

## 四、代码实现

```python
analogy = vk - vm + vw
top = cosine_topk(analogy, vocab_vecs, k=5)
print(top)  # 期望含 queen
```

## 五、与其他对比

- 与 探针与线性表示 共享线性方向假设。
- 与 稀疏自编码器特征深入 衔接（SAE 特征即单义方向）。

## 六、常见误区

- 类比只在无上下文词向量中稳健；上下文模型中被叠加稀释。
- 并非所有关系都有干净线性方向。

## 八、面试题

- 类比向量为何成立？答：某些语义关系在向量空间近似为平移方向，加减速得目标。

## 九、演进

Word2Vec 类比 → 上下文表示弱化 → SAE 重建清晰方向。

## 十、小结

概念向量以线性方向编码关系，是表示几何最直观证据。
