# 探针与线性表示

> 对应 Conneau et al., *What you can cram into a single vector*, 2018；Alain & Bengio, 2016。

## 一、背景与挑战

如何判断模型"内部是否编码了某属性"？探针（probe）用简单分类器测表示的可分性。

## 二、核心原理

在冻结表示上训练线性/浅网探针预测属性；高准确率暗示该属性被线性编码。线性探针因"最小归纳偏置"最受青睐，可区分"信息存在"与"模型使用"。

## 三、数学形式

探针损失 $\min_{W_p} \mathbb E[-\log p_\theta(y\mid W_p h)]$；常用线性逻辑回归。

## 四、代码实现

```python
from sklearn.linear_model import LogisticRegression
probe = LogisticRegression().fit(H_train, y_train)
print(probe.score(H_test, y_test))
```

## 五、与其他对比

- 与 稀疏自编码器特征深入 互补：探针用现成方向，SAE 构造单义方向。
- 与 词典特征与单义性深入 衔接（多义性干扰探针）。

## 六、常见误区

- 探针高 acc 不代表模型用该信息做预测（相关性≠因果）。
- 复杂探针可能"学会"任务而非读表示。

## 八、面试题

- 探针说明什么？答：表示中某属性是否线性可分，但不证明模型在推理中使用了它。

## 九、演进

复杂探针 → 线性探针 → 控制容量/选择性探针。

## 十、小结

探针量化表示结构，但须分清"可读"与"被用"。
