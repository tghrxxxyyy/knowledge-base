# 语义空间几何

> 对应 Ethayarajh, *How Contextual are Contextualized Representations?*, 2019；Mu et al., *All but the Top*, 2017。

## 一、背景与挑战

表示向量常呈各向异性（anisotropy）：高频词聚拢、整体偏向少数方向，损害几何直觉。

## 二、核心原理

未处理的高层表示方差集中在少数主方向，导致余弦相似度趋同。中心化/白化/PCA 可缓解，使语义邻居关系更清晰。

## 三、数学形式

各向异性度量 $\frac{\lambda_1}{\sum_i \lambda_i}$（第一主成分占比）；理想各向同性应接近 $1/d$。

## 四、代码实现

```python
X = reps - X.mean(0)
u, s, _ = torch.pca_lowrank(X, q=d)
whitened = X @ (u / s.sqrt()).T
```

## 五、与其他对比

- 与 词典特征与单义性深入（叠加）相关：各向异性是叠加的表象。
- 与 稀疏自编码器特征深入 衔接（SAE 亦缓解各向异性）。

## 六、常见误区

- 直接用原始向量算相似度而忽略各向异性偏差。
- 以为几何性质跨层一致。

## 八、面试题

- 什么是各向异性？答：表示方差集中在少数主方向，使相似度失真，需中心化/白化修正。

## 九、演进

原始向量 → 中心化 → 白化/SAE 解耦。

## 十、小结

语义空间几何需校正各向异性，方能可靠解读方向语义。
