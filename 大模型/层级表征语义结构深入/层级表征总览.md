# 层级表征语义结构总览

> 对应 Tenney et al., *BERT Rediscovers the Classical NLP Pipeline*, 2019；Mikolov et al., *Linguistic Regularities*, 2013。

## 一、背景与挑战

词/句表征的语义是否以几何方式组织？层级上信息如何由浅入深？这是表征可解释性的核心。

## 二、核心原理

Transformer 各层形成不同抽象层级的表示；浅层编码句法/表层，深层编码语义/世界知识。线性探针可量化各层对各类任务的可分性。

## 三、数学形式

探针分类器 $y = \text{softmax}(W_p h^{(l)})$；层能力以验证集准确率衡量，得"探针曲线"。

## 四、代码实现

```python
for l in layers:
    h = get_activation(model, input, layer=l)
    acc[l] = linear_probe(h, labels).score()
plot(acc)  # 句法先升后平，语义持续上升
```

## 五、与其他对比

- 与 前馈传播特征演化深入 共享层演化视角。
- 与 稀疏自编码器特征深入 衔接（线性方向 vs SAE 特征）。

## 六、常见误区

- 探针好=该层"含"此信息；实际只是线性可读，因果未定。
- 把表征几何当绝对真相。
