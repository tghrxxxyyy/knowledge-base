# 参数量与算力关系

> 对应 Kaplan et al., 2020；Hoffmann et al., 2022（Chinchilla）.

## 一、背景与挑战

给定算力 C，参数 N 与数据 D 如何分配才最优？这是训练规划的核心 trade-off。

## 二、核心原理

在 $6ND\approx C$ 约束下，Kaplan 早期偏重 N；Chinchilla 证明最优为 $N\propto C^{0.5}, D\propto C^{0.5}$ 且二者近似相等（以 token 计）。

## 三、数学形式

由 $L(N,D)=E+(N_c/N)^\alpha+(D_c/D)^\beta$ 与 $6ND=C$ 求极小，得 $N_{opt}\approx 20C^{0.5}$。

## 四、代码实现

```python
C = 1e24
N_opt = 20 * C**0.5
D_opt = C / (6 * N_opt)      # tokens
```

## 五、与其他对比

- 与 数据缩放定律深入（Chinchilla 最优）同主题。
- 与 训练算力估算总览（6ND 公式）衔接。

## 六、常见误区

- 把 $N_{opt}$ 当成“最佳模型大小”忽略下游需求。
- 数据受限时硬套平衡公式失效。

## 八、面试题

- 给定算力如何分 N 与 D？答：Chinchilla 下 N≈D（token）且都随 C^0.5 增长，平衡分配最优。

## 九、演进

Kaplan 偏 N → Chinchilla 平衡 → 数据受限再权衡。

## 十、小结
