# 训练算力估算总览

> 对应 Kaplan et al., 2020；Shazeer, *Mesh-TensorFlow*, 2019（FLOPs 分析）；Narayanan et al., *Efficient Large-Scale Training*, 2021.

## 一、背景与挑战

训练 LLM 前需预估总 FLOPs、所需 GPU 时长与成本，以做预算与集群规划。

## 二、核心原理

Transformer 训练算力主要来自矩阵乘；总 FLOPs 近似与参数量 N、训练 token 数 D 成正比：$C\approx 6ND$。

## 三、数学形式

前向每 token $\approx 2N$ FLOPs，反向约 2 倍，合计 $C=6ND$（忽略嵌入/归一化小幅项）。

## 四、代码实现

```python
def train_flops(params, tokens):
    return 6 * params * tokens
C = train_flops(7e9, 1.4e12)      # FLOPs
```

## 五、与其他对比

- 与 数据缩放定律深入（C、N、D 三元）直接衔接。
- 与 推理算力估算（仅前向）对比。

## 六、常见误区

- 忽略并行/重算导致实际 GPU 小时高于理论 FLOPs/利用率。
- 把参数量当唯一成本因子（漏掉 D）。

## 八、面试题

- 为何 C≈6ND？答：前向 2N/token、反向 4N/token，合计 6N 每 token 乘 D。

## 九、演进

经验估算 → 6ND 公式 → 含并行因子细化。

## 十、小结

训练算力估算以 6ND 为核心，是预算与集群规划的起点。
