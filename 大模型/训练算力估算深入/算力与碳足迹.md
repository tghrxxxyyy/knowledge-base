# 算力与碳足迹

> 对应 Patterson et al., *Carbon Emissions and Large Neural Network Training*, 2021；Strubell et al., *Energy and Policy Considerations*, 2019.

## 一、背景与挑战

大模型训练耗电巨大，碳足迹成为伦理与合规考量，需量化并优化能耗。

## 二、核心原理

能耗 $E=C\times PUE / (\text{能效})$；碳排放 $=E\times$ 电网碳强度；选址（绿电）、利用率、模型复用可显著降低。

## 三、数学形式

$CO_2 = \frac{C}{FLOPs\_per\_Joule}\times carbon_{intensity}\times PUE$；$C=6ND$。

## 四、代码实现

```python
C = 6 * 7e9 * 1.4e12
energy_kwh = C / (gpu_efficiency * 3.6e12) * PUE
co2 = energy_kwh * grid_carbon_kg_per_kwh
```

## 五、与其他对比

- 与 训练算力估算实践（同 C 但加能耗折算）衔接。
- 与 大模型与可持续发展（目录）共享主题。

## 六、常见误区

- 只算 GPU 忽略数据中心 PUE 与制冷。
- 忽略电网碳强度差异（选址影响巨大）。

## 八、面试题

- 如何降低训练碳足迹？答：选绿电区域、提 MFU、复用模型与蒸馏，减少重复训练。

## 九、演进

忽略能耗 → 报告碳排 → 绿电+高效训练。

## 十、小结

算力碳足迹把技术估算延伸到环境与伦理，绿色选址与高效训练是关键。
