# 分离式与混合并发模式

> 对应 Kwon 2023 vLLM; Ainslie 2023 GQA; Shoeybi 2019 Megatron。

## 一、背景与挑战
纯分离部署对短请求收益有限且运维复杂，纯耦合尾延迟不稳，需按流量形态选择模式。

## 二、核心原理
提供三种模式：纯耦合（小流量）、纯分离（大流量低延迟要求）、混合（关键请求走分离，普通请求耦合）。网关按 SLA 路由。

## 三、形式化与数学基础
选择函数：
$ \text{mode} = \arg\min_m \text{cost}_m + \lambda \cdot \text{violation}_m(SLA) $

## 四、代码实现
```python
def route(req):
    if req.sla_strict:
        return disaggregated_pipeline(req)
    return coupled_pipeline(req)
```

## 五、与其他技术对比
模式选择本质是成本-延迟权衡，没有单一最优，需依负载切换。

## 六、常见误区
误区：一律上分离。小流量下运维与传输开销得不偿失。

## 七、与开源书/权威来源对应
DistServe 论文讨论分离收益边界。见 vllm-project/vllm、NVIDIA/TensorRT-LLM。

## 八、面试题
问：何时不该用分离式？
答：短 prompt、低并发、同节点资源充足时，耦合更简更省。

## 九、演进与趋势
自适应路由在请求级动态选模式，成为高级网关能力。

## 十、小结
分离与耦合并非互斥，按 SLA 与流量混合部署最实际。
