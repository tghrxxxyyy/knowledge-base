# 弹性调度与实例池

> 对应 Zhao 2023 FSDP; Rasley 2020 DeepSpeed ZeRO; Kwon 2023 vLLM。

## 一、背景与挑战
负载日内波动大，固定实例池在低谷浪费、高峰排队。需按阶段独立弹性伸缩。

## 二、核心原理
维护 prefill 池与 decode 池，监控队列长度与 SLA 违规率，自动增减实例；新实例加载权重（或从检查点分片）后注册进调度。

## 三、形式化与数学基础
伸缩决策基于队列积压 Q 与阈值：
$ \text{scale} = \begin{cases} +1 & Q > H_{high} \\ -1 & Q < H_{low} \\ 0 & \text{else} \end{cases} $

## 四、代码实现
```python
def autoscale(pool, qlen):
    if qlen > pool.high:
        pool.add(replica())
    elif qlen < pool.low:
        pool.remove(idle_replica())
```

## 五、与其他技术对比
整体伸缩粒度粗；分两池独立伸缩更贴合两阶段异构需求。

## 六、常见误区
误区：秒级伸缩无代价。权重加载与冷启动引入数十秒延迟，需预热。

## 七、与开源书/权威来源对应
Kubernetes 自定义伸缩 + vLLM。见 vllm-project/vllm、pytorch/pytorch。

## 八、面试题
问：冷启动延迟如何缓解？
答：保留热备实例、权重缓存、或共享存储快速挂载。

## 九、演进与趋势
预测式伸缩结合流量预测，提前预热。

## 十、小结
弹性分池把成本与 SLA 同时优化，是云推理经济性的关键。
