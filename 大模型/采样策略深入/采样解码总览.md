# 采样解码总览

> 对应 Holtzman et al., *The Curious Case of Neural Text Degeneration*, 2020；与 温度与解码深入 衔接。

## 一、背景与挑战

纯随机采样输出退化（重复、不通顺）；需截断分布再采样以平衡质量与多样。

## 二、核心原理

先对 softmax 分布做截断（top-k / top-p）再重归一采样，滤掉低概率噪声尾，保留高质量候选。

## 三、数学形式

截断集 $V^{(p)}=\{v: P(v)\ge 1-p\}$ 排序累计；$y\sim \text{softmax}(z_V/\tau)|_V$。

## 四、代码实现

```python
gen = model.generate(input_ids, do_sample=True, top_p=0.9, temperature=0.8)
```

## 五、与其他对比

- 与 波束搜索深入 互补：采样重多样、束搜索重确定。
- 与 温度与解码深入 共享 $\tau$ 缩放。

## 六、常见误区

- 不设截断直接采样 → 退化文本。
- top_p 与 top_k 同时用需理解交互。

## 九、演进

全采样 → top-k → top-p → 典型解码。

## 十、小结

截断采样是现代开放生成标配，防退化且保多样。
