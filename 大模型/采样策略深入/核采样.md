# 核采样（Top-p / Nucleus）

> 对应 Holtzman et al., 2020。

## 一、背景与挑战

top-k 固定候选数不适应不同不确定度；核采样按累计概率动态定候选集。

## 二、核心原理

取累计概率达 $p$ 的最小词集，重归一采样；分布越平候选越多，越尖候选越少，自适应。

## 三、数学形式

$V^{(p)}=\min\{V': \sum_{v\in V'}P(v)\ge p\}$；常取 $p\in[0.9,0.95]$。

## 四、代码实现

```python
gen = model.generate(input_ids, do_sample=True, top_p=0.92, top_k=0)
```

## 五、与其他对比

- 与 top-k 比更自适应分布形态。
- 与 典型解码深入 同为分布裁剪思路。

## 六、常见误区

- p 过近 1 退化为全采样退化。
- 与 top_k 同时设易误判交互。

## 九、演进

top-k → top-p → 自适应 p。

## 十、小结

核采样按概率质量裁剪，是现代生成默认。
