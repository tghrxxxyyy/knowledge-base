# 采样策略选型

> 对应解码策略实践；与 温度与解码深入 / 波束搜索深入 衔接。

## 一、背景与挑战

不同任务需不同多样-质量配比，需系统选型。

## 二、核心原理

事实→低温+可能束搜索；创意→核采样/典型+temperature≈0.8；代码→top-p 高且低温。

## 三、数学形式

期望效用 $\max_{\theta\in\{k,p,\tau\}} \mathbb E[\text{quality}-\lambda\cdot\text{repetition}]$。

## 四、代码实现

```python
cfg = {"creative": (0.95, 0.85), "fact": (0.3, None)}
top_p, tau = cfg[mode]
```

## 五、与其他对比

- 与 格式化输出深入 / 结构化输出深入 共同决定可控生成。
- 与 自回归生成深入 衔接。

## 六、常见误区

- 一套参数通吃所有任务。
- 忽视重复惩罚（repetition_penalty）。

## 八、面试题

- 如何选采样策略？答：按任务可预测性定多样度，创意用核/典型采样、事实用低温或束。

## 九、演进

经验选 → 自动调参 → 在线自适应。

## 十、小结

采样策略应随任务定性选型，无全局最优。
