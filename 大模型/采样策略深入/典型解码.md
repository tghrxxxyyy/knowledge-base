# 典型解码（Typical Decoding）

> 对应 Meister et al., *Typical Decoding for Natural Text Generation*, 2022。

## 一、背景与挑战

top-p 在极平/极尖分布仍不稳；典型解码以熵匹配选“典型”词。

## 二、核心原理

选出与分布熵接近的词（信息量≈期望），过滤过于意外或过于可预测者，使生成信息率贴近人类文本。

## 三、数学形式

选 $v$ 使 $|-\log P(v)-\mathbb H(P)|<\tau$；$\mathbb H(P)=-\sum P(v)\log P(v)$。

## 四、代码实现

```python
gen = model.generate(input_ids, do_sample=True, typical_p=0.95)
```

## 五、与其他对比

- 与 核采样深入 同为裁剪，但用熵距离而非累计概率。
- 与 温度与解码深入 配合。

## 六、常见误区

- 误以为典型解码总是更优；某些任务核采样更好。
- $\tau$ 设错仍退化。
