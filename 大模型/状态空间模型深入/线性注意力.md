# 线性注意力

> 见「注意力变体」与「状态空间模型深入/SSM基本原理」。

## 一、背景与挑战

标准注意力 O(N^2)，线性注意力用核技巧降至 O(N)。

## 二、核心原理

把 softmax(QK^T) 近似为 φ(Q)φ(K)^T，重排为 (φ(Q)(φ(K)^T V))，先聚合 KV，复杂度线性。

## 三、数学形式

```
Attn ≈ φ(Q)(φ(K)^T V) / (φ(Q) φ(K)^T 1)
```

## 四、代码实现

```python
kv = phi(K).T @ V; out = phi(Q) @ kv
```

## 五、关键要点

- 表达力弱于 softmax 注意。
- 适合长序列。

## 六、与其他对比

- softmax 注意强但贵；线性注意便宜但弱。

## 七、常见误区

- 线性注意=等价——有近似误差。
