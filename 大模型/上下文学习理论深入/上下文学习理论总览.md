# 上下文学习理论总览

> 对应 Brown et al., *Language Models are Few-Shot Learners*, NeurIPS 2020；Min et al., *Rethinking the Role of Demonstrations*, EMNLP 2022。

## 一、背景与挑战

上下文学习（ICL）指模型不更新参数，仅凭提示中的示例完成新任务。挑战在于解释：为什么前向传播能实现「学习」，以及示例究竟提供了什么信息。

## 二、核心原理

主流解释可归纳为三类，彼此并非互斥，而是在不同任务与规模区间各自成立。

- 任务定位：示例主要激活预训练中已有的任务先验，标签正确性影响有限（Min et al., EMNLP 2022）。
- 隐式算法：注意力层在前向中实现了类似梯度下降或贝叶斯后验更新的计算（von Oswald et al., ICML 2023；Xie et al., ICLR 2022）。

## 三、数学形式

把示例集记作 $S=\{(x_i,y_i)\}_{i=1}^{k}$，ICL 预测为 $p(y\mid x,S)=\int p(y\mid x,\theta)\,p(\theta\mid S)\,d\theta$。

若 $p(\theta\mid S)$ 随 $k$ 增大集中于某潜在任务 $\theta^\ast$，则预测收敛到该任务的条件分布——这就是「不改参数也能学」的概率解释。

## 四、代码实现

```python
import torch
def icl_prompt(demos, query):
    lines = [f"输入: {x}\n输出: {y}" for x, y in demos]
    return "\n\n".join(lines) + f"\n\n输入: {query}\n输出:"
demos = [("好评", "正面"), ("很差", "负面")]
print(icl_prompt(demos, "还不错"))
```

## 五、与其他对比

- 与微调对照：ICL 零参数更新、即时生效，但受上下文长度限制且不积累。
- 与 涌现能力度量争议深入 对照：Lu et al., ACL 2024 认为多数涌现现象可由 ICL 强度解释。

## 六、常见误区

- 认为示例必须标签正确才有效；研究显示输入分布与标签空间的作用常大于标签正确性。
- 把 ICL 当成真正的参数学习；它不改变权重，跨会话不保留。

## 八、面试题

- ICL 与微调本质差异？答：ICL 在激活空间条件化，微调在参数空间更新，前者临时后者持久。
- 示例数量为何常有收益递减？答：后验集中很快饱和，且长上下文引入位置与噪声干扰。

## 九、演进

少样本现象（2020）→ 示例作用解构（2022）→ 隐式算法理论（2022-2023）→ 与涌现争议合流（2024）。

## 十、小结

ICL 的理论图景是「先验定位 + 前向隐式更新」的叠加，理解它能直接指导提示设计。
