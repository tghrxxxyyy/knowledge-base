# 示例选择与顺序敏感性

> 对应 Liu et al., *What Makes Good In-Context Examples for GPT-3?*, DeeLIO 2022；Lu et al., *Fantastically Ordered Prompts*, ACL 2022。

## 一、背景与挑战

同一组示例换个顺序，准确率可能从接近随机跳到接近上限。这种脆弱性使 ICL 的评测与部署都需要显式的示例治理策略。

## 二、核心原理

示例的作用可拆为分布锚定、标签空间界定与位置偏置三部分，选择与排序分别影响前两者与第三者。

- 选择：用查询的语义近邻作示例（kNN 检索）通常优于随机采样，因其提高后验可分性。
- 排序：位置靠后的示例权重更大，且存在近期偏置；可用小验证集做熵/一致性准则挑选顺序。

## 三、数学形式

顺序打分可用预测熵最小化：$\pi^\ast=\arg\min_{\pi}\ \mathbb{E}_{x\in D_{val}}\big[H\big(p(\cdot\mid x, S_\pi)\big)\big]$，$H$ 为熵。

也可用标签分布均衡度作正则，避免某类标签在末位过度重复而放大偏置。

## 四、代码实现

```python
import numpy as np
def rank_orders(orders, entropies):                  # entropies: 每种顺序在验证集上的平均熵
    order = np.argsort(entropies)
    return [orders[i] for i in order[:3]]
orders = ["ABC", "BCA", "CAB", "ACB"]
print(rank_orders(orders, np.array([1.2, 0.7, 1.5, 0.9])))
```

## 五、与其他对比

- 与检索增强对照：示例检索优化「任务身份」，文档检索优化「事实证据」。
- 与 上下文学习理论总览 衔接：可分性与位置偏置正是后验集中与注意力偏置的行为表现。

## 六、常见误区

- 固定单一顺序汇报结果，把顺序运气当作方法收益。
- 只做语义近邻检索却不控标签均衡，导致模型退化为多数类预测。

## 八、面试题

- 为什么顺序会显著影响结果？答：位置偏置与近期效应改变有效权重，进而改变标签先验。
- 如何降低顺序方差？答：多顺序平均、熵准则选序、标签均衡与校准后处理并用。

## 九、演进

随机示例 → kNN 检索选例 → 顺序搜索与熵准则 → 校准与多序集成。

## 十、小结

示例选择与排序是 ICL 中收益最高、成本最低的杠杆，也必须纳入评测方差报告。
