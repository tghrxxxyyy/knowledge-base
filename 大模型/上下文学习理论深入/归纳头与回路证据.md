# 归纳头与回路证据

> 对应 Olsson et al., *In-context Learning and Induction Heads*, 2022；Elhage et al., *A Mathematical Framework for Transformer Circuits*, 2021。

## 一、背景与挑战

理论解释需要机制证据落地。归纳头提供了可测量、可干预的具体电路：模型如何在上下文中复制此前出现过的模式。

## 二、核心原理

归纳头执行「找到上文中与当前 token 相同的位置，输出其后继」的操作，由两层头组合实现。

- 组合结构：前一层的 previous-token 头把上一个 token 信息写入残差流，后一层头据此做键匹配并复制后继。
- 因果证据：归纳头出现的训练阶段与 ICL 能力的损失曲线拐点同时发生，且消融归纳头会显著削弱上下文复制能力。

## 三、数学形式

模式匹配可写为注意力从位置 $t$ 指向 $j$ 满足 $x_{j-1}=x_t$，输出 $\hat y_{t+1}\approx x_{j}$。

归纳分数常定义为在随机重复序列上，注意力质量落在偏移 $-(T/2-1)$ 位置的比例：$\mathrm{IS}=\mathbb{E}\big[A_{t,\,t-T/2+1}\big]$。

## 四、代码实现

```python
import torch
def induction_score(attn, half):                     # attn: [T,T] 因果注意力
    T = attn.shape[0]; idx = torch.arange(half, T)
    return float(attn[idx, idx - half + 1].mean())
A = torch.softmax(torch.randn(8, 8).tril(), dim=-1)
print(induction_score(A, half=4))
```

## 五、与其他对比

- 与 隐式梯度下降假说 对照：归纳头解释「复制型」ICL，梯度视角解释「回归型」ICL。
- 与 注意力头功能分化深入 衔接：归纳头是功能分化研究中最被反复验证的一类头。

## 六、常见误区

- 把归纳头当作 ICL 的唯一机制；它主要解释重复模式复制，不能覆盖抽象任务泛化。
- 只看注意力图不做消融；相关性不等于因果，需干预实验确认。

## 八、面试题

- 归纳头如何工作？答：借前一层的上一 token 信息做键匹配，复制历史匹配位的后继 token。
- 为什么它是 ICL 的重要证据？答：出现时间与 ICL 拐点吻合，且消融后能力下降，具备因果支持。

## 九、演进

注意力模式观察 → 数学框架下的头组合 → 训练相变与消融验证 → 扩展到更复杂回路（如 IOI）。

## 十、小结

归纳头把抽象的 ICL 讨论落到可测电路，是机制可解释性与 ICL 理论的交汇点。
