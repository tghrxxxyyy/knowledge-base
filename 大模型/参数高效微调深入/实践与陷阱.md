# PEFT实践与陷阱

> 对应 peft 库实践与社区经验；与 训练不稳定诊断深入 / 数值稳定性深入 衔接。

## 一、背景与挑战

PEFT 看似简单，工程细节决定成败：学习率、秩、初始化、数据配比。

## 二、核心原理

- LoRA 学习率常为全微调 10× 量级（因低秩梯度尺度不同）。
- $B$ 零初始化、$A$ 随机小初始化，保证起点=原模型。
- 合并权重前注意 dtype 与缩放 $\alpha/r$。

## 三、数学形式

有效缩放：$h = Wx + \frac{\alpha}{r} B A x$，$\alpha$ 控制更新幅度。

## 四、代码实现

```python
# 合并 LoRA 回权重
with model.disable_adapter(): y0 = model(x)
y = model(x); delta = y - y0   # 验证适配器影响
```

## 五、与其他对比

- PEFT 更易过拟合小数据（参少）；需更强正则/早停。
- 与全微调相比对学习率更敏感。

## 六、常见误区

- 直接套用全微调学习率（太小不收敛）。
- 忘记把 LoRA 合并导致部署仍是原模型。
- 多 LoRA 混合时缩放未归一。

## 八、面试题

- LoRA 学习率为何常比全微调大？答：低秩更新尺度小，需更大步长补偿。

## 九、演进

经验调参 → 自动搜索 → 训练稳定化工具链。

## 十、小结

PEFT 成功依赖学习率、秩、初始化与合并细节，工程经验与理论同样重要。
