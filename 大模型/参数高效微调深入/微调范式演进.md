# 微调范式演进

> 对应 Houlsby et al., *Adapter*, 2019；Hu et al., *LoRA*, 2021；llm-course PEFT 部分。

## 一、背景与挑战

全参数微调大模型算力/存储昂贵，且多任务需多份权重；参数高效微调（PEFT）只训少量参数。

## 二、核心原理

在冻结预训练权重上插入/调整少量可训练参数，兼顾适配性与效率。主流：Adapter、Prefix/Prompt Tuning、LoRA。

## 三、数学形式

全微调更新 $\Delta W$ 直接改 $W$（参数量 $=|W|$）；PEFT 仅训 $P\ll|W|$ 参数。

## 四、代码实现

```python
for n, p in model.named_parameters():
    p.requires_grad = ("lora" in n)  # 仅 LoRA 可训
```

## 五、与其他对比

- 全微调质量上限高但贵；PEFT 便宜、易多任务复用底座。
- 与 指令数据构建深入 / 微调与对齐 衔接（数据侧）。

## 六、常见误区

- 以为 PEFT 永远不如全微调；多数任务差距很小。
- 忽视学习率与秩的调参（PEFT 对学习率更敏感）。

## 八、面试题

- 为何 PEFT 兴起？答：降本、多任务共享底座、避免灾难性遗忘。

## 九、演进

全微调 → Adapter → Prompt/Prefix Tuning → LoRA → QLoRA。

## 十、小结

PEFT 把适配成本从全量降到千分之一级，是私有化/多任务部署的基石。
