# 函数调用与工具提示

> 对应 Prompt-Engineering-Guide「Function Calling」与 OpenAI tool-calling。

## 一、核心概念

把可用函数/工具的 schema（名、参数、描述）放进 prompt 或专用 API，模型输出结构化调用请求，由外部执行后结果回填模型继续生成。是 Agent 的工具使用基础（见「智能体」系列）。

```json
{"name": "get_weather", "arguments": {"city": "北京", "date": "2026-09-01"}}
```

## 二、关键要点

- schema 描述越清晰，调用越准。
- 需处理参数校验与失败重试。
