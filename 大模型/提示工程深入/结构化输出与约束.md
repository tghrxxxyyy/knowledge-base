# 结构化输出与约束解码

> 对应 Prompt-Engineering-Guide「Formatting」与工程实践。

## 一、核心概念

让模型输出可机器解析的结构（JSON/XML/CSV）常用：明确 schema 描述 + 示例 + 约束。更强的做法是**约束解码**(constrained decoding)，用语法(如 JSON schema / 正则)在采样时限制 token 空间，保证格式合法（如 guidance / outlines / lm-format-enforcer）。

```json
请输出 JSON：{"sentiment": "正面|负面|中性", "confidence": 0.0-1.0}
```

## 二、关键要点

| 方法 | 可靠性 |
|------|--------|
| 自然语言约束 | 中（可能不守法） |
| 约束解码 | 高（硬保证） |
