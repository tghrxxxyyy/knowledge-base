# 少样本提示 Few-Shot

> 对应 Prompt-Engineering-Guide「Few-Shot」。Brown et al., *GPT-3*, 2020 提出 in-context learning。

## 一、核心概念

在 prompt 中提供若干「输入-输出」示例，模型通过**上下文学习(in-context learning)** 模仿模式，无需更新权重。示例质量与一致性比数量更重要；通常 3~8 个足矣。

```
情感分类示例：
文本："服务态度好" → 正面
文本："物流太慢"   → 负面
文本："价格一般"   → 中性
文本："{input}"   →
```

## 二、关键要点

| 项 | 建议 |
|----|------|
| 示例数 | 3~8 |
| 顺序 | 随机化防偏差 |
| 格式 | 与测试一致 |

## 三、常见误区

- 示例标签噪声大，模型学到错误模式。
- 示例与真实分布不匹配。
