# 提示工程基础与原则

> 对应 dair-ai/Prompt-Engineering-Guide（promptingguide.ai）。提示工程是「用自然语言编程大模型」的学科。

## 一、核心概念

提示(prompt)是给模型的输入文本，包含任务描述、上下文、示例与格式约束。好的提示遵循：

1. **清晰具体**：避免歧义，明确角色、任务、输出格式。
2. **结构化**：用分隔符(`###` / 三引号 / `<tag>`)隔离段落。
3. **给示例**：少样本显著提升稳定性。
4. **分步**：复杂任务拆步骤（Chain-of-Thought）。
5. **迭代**：像写代码一样调 prompt。

## 二、基础模板

```
你是一名资深{角色}。请完成{任务}。
输入：{input}
要求：1)... 2)... 输出 JSON：{schema}
```

## 三、关键要点

| 原则 | 作用 |
|------|------|
| 清晰 | 减少误解 |
| 分隔符 | 防注入/混淆 |
| 示例 | 锚定格式 |
| 迭代 | 提质 |

## 四、常见误区

- 把 prompt 当「咒语」堆砌无用词（"请你务必..."）。
- 忽略输出格式约束导致解析失败。
