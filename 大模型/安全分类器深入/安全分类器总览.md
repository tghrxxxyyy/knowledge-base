# 安全分类器总览

> 对应内容安全审核模型（如 OpenAI Moderation / Perspective API）；前置过滤与后置检测。

## 一、背景与挑战

模型可能产出有害内容；需自动分类器实时判别违规类别（暴力/色情/仇恨/自残）。

## 二、核心原理

训练文本多标签分类器，对输入/输出打分；超阈值则拦截/告警/改写。

## 三、数学形式

多标签概率 $p_k=\sigma(W h(x))_k$，阈值判定 $y_k=\mathbb 1(p_k>\tau_k)$。

## 四、代码实现

```python
labels = moderator(text)
if labels["violence"] > 0.9: block()
```

## 五、与其他对比

- 与 角色与人格对齐深入（角色越界判否）衔接。
- 与 红队攻击模拟深入（攻击绕过检测）对照。

## 六、常见误区

- 单阈值一刀切致误杀。
- 仅后置不前置，成本高。
