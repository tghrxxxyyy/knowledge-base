# 误判与漏判（False Positive/Negative）

> 对应分类器误差分析；模型评测指标深入 衔接。

## 一、背景与挑战

误杀（FP）伤体验、漏放（FN）致风险，二者需权衡。

## 二、核心原理

按风险偏好设阈值：高风险类偏严（降 FN），低风险类偏宽（降 FP）；用代价矩阵优化。

## 三、数学形式

期望代价 $C=\text{cost}_{FP}P(FP)+\text{cost}_{FN}P(FN)$，调 $\tau$ 最小化。

## 四、代码实现

```python
for tau in linspace(0.3,0.95,20):
    evaluate(cls, tau)
```

## 五、与其他对比

- 与 红队攻击模拟深入（FN 被攻击利用）对照。
- 与 安全分类器部署深入（线上阈值）衔接。

## 六、常见误区

- 只优化准确率忽略代价不对称。
- 阈值不随业务更新。

## 八、面试题

- FP/FN 如何权衡？答：按风险代价设阈值，高风险降 FN、低风险降 FP。

## 九、演进

固定阈值 → 代价敏感 → 动态阈值。

## 十、小结

安全分类须在误杀与漏放间按代价调阈值。
