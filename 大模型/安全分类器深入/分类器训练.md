# 安全分类器训练

> 对应偏好/安全标注训练；d2l-zh 分类章节 衔接。

## 一、背景与挑战

安全标签稀缺、类别不平衡、边界样本难标。

## 二、核心原理

在底座上加分类头，用不平衡采样/ focal loss 处理长尾；标签平滑缓解噪声。

## 三、数学形式

Focal loss $FL=-\alpha(1-p_t)^\gamma\log p_t$，抑制易分样本权重。

## 四、代码实现

```python
head = nn.Linear(H, n_classes)
loss = FocalLoss()(head(h), y)
```

## 五、与其他对比

- 与 奖励模型深入（同为偏好/分数头）共享。
- 与 数据投毒防御深入（训练数据洁净）对照。

## 六、常见误区

- 类别极度不平衡未处理致偏类。
- 标签噪声未平滑致过自信。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- 为何用 focal loss？答：降易分样本权重，聚焦难分/边界样本，缓解不平衡。

## 九、演进

CE → 加权CE → Focal/类别重采样。

## 十、小结

安全分类器训练需处理不平衡与噪声，focal loss 等常用。
