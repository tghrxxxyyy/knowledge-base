# 内容安全审核

> 对应生产内容审核流程；安全分类器深入 总览延伸。

## 一、背景与挑战

违规类型多、边界模糊（讽刺/隐喻），需分层审核。

## 二、核心原理

分层：快筛（轻量）→ 精判（重模型）→ 人工复核争议；按风险分级处置。

## 三、数学形式

处置 $a=\text{policy}(p)=\begin{cases}block&p>\tau_h\\flag&p\in[\tau_l,\tau_h]\\pass&p<\tau_l\end{cases}$。

## 四、代码实现

```python
p = cls(text)
action = "block" if p>0.9 else "flag" if p>0.5 else "pass"
```

## 五、与其他对比

- 与 模型评测指标深入（误杀率指标）共享。
- 与 隐私推理深入（敏感内容）交叉。

## 六、常见误区

- 阈值全局固定忽略语境。
- 忽视多语言/方言覆盖。

## 八、面试题

- 为何分层审核？答：轻量快筛降成本，重模型精判减误杀，争议交人工。

## 九、演进

单模型 → 分层 → 人机协同。

## 十、小结

分层审核平衡成本与精度，是内容安全工程核心。
