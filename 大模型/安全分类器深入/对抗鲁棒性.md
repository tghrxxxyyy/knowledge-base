# 安全分类器对抗鲁棒性

> 对应对抗样本对分类器；与 红队攻击模拟深入 共享威胁模型。

## 一、背景与挑战

攻击者对文本做同义替换/插入扰乱，使分类器误判。

## 二、核心原理

对抗训练（在扰动样本上重训）、文本净化（去噪/规范化）、集成多模型降单点脆弱。

## 三、数学形式

min-max：$\min_\theta \max_{\delta\in\Delta} \mathcal L(f_\theta(x+\delta),y)$。

## 四、代码实现

```python
for adv in pgd_text(x): train(cls, adv, y)
```

## 五、与其他对比

- 与 数据投毒防御深入（训练期攻击不同）对照。
- 与 模型提取攻击深入（不同威胁）区分。

## 六、常见误区

- 仅干净样本训练致线上被扰崩溃。
- 净化引入语义改变。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course
- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 文本对抗训练为何难？答：离散空间扰动不可微，需用同义替换/字符扰动近似。

## 九、演进

无防御 → 对抗训练 → 净化+集成。

## 十、小结

安全分类器需对抗训练与净化，抵御文本扰动绕过。
