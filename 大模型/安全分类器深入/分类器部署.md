# 安全分类器部署

> 对应线上内容安全工程；安全分类器深入 总览落地。

## 一、背景与挑战

每请求加分类器增延迟与成本，需与生成流水并行。

## 二、核心原理

输入前置筛+输出后置检，轻量模型并行跑；高风险再交重模型；缓存高频判定。

## 三、数学形式

端到端延迟 $L=L_{gen}+\max(L_{in},L_{out})$（并行）。

## 四、代码实现

```python
async with gather(pre(text), gen(text)) as (pre_r, out):
    if pre_r.block: return refuse()
```

## 五、与其他对比

- 与 推理调度深入（并行分类与生成）衔接。
- 与 角色与人格对齐深入（越界检测）共享。

## 六、常见误区

- 串行部署致延迟翻倍。
- 只检输入不检输出（生成越狱）。

## 七、与开源书对应

## 八、面试题

- 如何降分类延迟？答：前后置并行，轻量快筛，重模型仅高风险，命中缓存。

## 九、演进

串行 → 并行 → 边缘轻量+云重。

## 十、小结

安全分类部署靠并行与分层，最小化对生成延迟影响。
