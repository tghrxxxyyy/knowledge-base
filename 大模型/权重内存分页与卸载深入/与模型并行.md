# 权重卸载与模型并行

> 对应张量并行/流水线并行与卸载的分工。

## 一、背景与挑战

多卡可用并行分摊权重，单卡不足才卸载；二者常组合。

## 二、核心原理

张量并行把大矩阵切多卡（NVLink 快）；流水线并行按层切卡；卸载把溢出部分放 CPU。组合：并行优先（快），再卸载最冷层。

## 三、数学形式

显存需求 $\frac{M}{P_{tp}}+M_{offload}$；P 为并行度，权衡通信与传输。

## 四、代码实现

```python
# 张量并行 + 末层卸载
shard = colwise_split(w, world); offload(rest)
```

## 五、与其他对比

- 与 张量核心与混合精度推理深入：并行提升算力利用。
- 与 权重内存分页与卸载深入 总览：卸载为并行补充。

## 六、常见误区

- 并行通信开销未计入致预期偏差。
- 卸载与并行混用致数据流复杂难调。

## 八、面试题

- 并行还是卸载？答：有多卡先并行（快），显存仍不足再卸载冷层。

## 九、演进

纯卸载 → 并行+卸载 → 分层自适应。

## 十、小结

并行与卸载互补，优先用快互连并行，溢出再卸载。
