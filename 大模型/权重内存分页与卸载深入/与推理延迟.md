# 权重卸载与推理延迟

> 对应 offloading 对 TTFT/TPOT 的影响分析。

## 一、背景与挑战

卸载增每层延迟，需量化对首 token（prefill）与每 token（decode）的影响。

## 二、核心原理

prefill 读全权重，卸载使其首包延迟高；decode 每层也需权重，TPOT 受传输/计算重叠度影响；重叠好则接近 compute 上界。

## 三、数学形式

TPOT $\approx \max(t_{load\_layer}, t_{compute\_layer})$（重叠理想）；否则为二者和。

## 四、代码实现

```python
# 理想重叠：load 与 compute 错峰
torch.cuda.synchronize()   # 仅在必要时
```

## 五、与其他对比

- 与 推理延迟剖析与火焰图深入：火焰图可分解 load/compute。
- 与 迭代级批处理调度深入：调度批影响 compute 占比。

## 六、常见误区

- 认为重叠总能完全隐藏传输（带宽/算力比决定上限）。
- 忽略多卡时 NVLink 与 PCIe 混用。
