# 权重卸载工具与框架

> 对应 llama.cpp（mmap）、DeepSpeed-Inference、Accelerate 等卸载能力。

## 一、背景与挑战

不同框架卸载实现差异大，选型需看易用与性能。

## 二、核心原理

llama.cpp 用 mmap 按需映射权重页到内存/GPU；HuggingFace Accelerate 支持 `device_map` 自动分层放置；DeepSpeed-Inference 支持 ZeRO-offload 式权重卸载。

## 三、数学形式

放置即求解 $\min \sum \text{cost}$ s.t. 每层落在 device，约束显存预算。

## 四、代码实现

```python
model = load_in_8bit(device_map="auto")   # 自动分层卸载
```

## 五、与其他对比

- 与 分页注意力与PagedAttention深入：KV 与权重两套显存管理。
- 与 张量核心与混合精度推理深入：框架多结合量化。

## 六、常见误区

- 认为 device_map=auto 总最优（需看互连）。
- mmap 不等同零延迟（缺页仍 IO）。
