# 权重内存分页与卸载总览

> 对应模型权重分层/分块管理（与 vLLM KV 分页思想相通）；DeepSpeed-ZeRO 卸载思路延伸。

## 一、背景与挑战

大模型权重超出单卡显存，需把权重分块管理，按需从 CPU/磁盘调入，避免一次性占满。

## 二、核心原理

将权重按层/张量分页，推理时仅把当前要计算的页驻留 GPU，计算完释放或保留热点；冷层留 CPU，跨设备传输填补。

## 三、数学形式

驻留显存 $M_{res}=\sum_{l\in active}\text{size}(l)$；需 $M_{res}<M_{GPU}$，其余在 CPU。

## 四、代码实现

```python
layer = load_to_gpu(weights[layer_id])   # 按需
out = layer(x); free(layer)
```

## 五、与其他对比

- 与 分页注意力与PagedAttention深入：对象分别为权重与 KV。
- 与 张量核心与混合精度推理深入：量化可减少页字节。

## 六、常见误区

- 忽视传输与计算重叠，致串行瓶颈。
- 频繁换层致 PCIe 饱和。

## 八、面试题

- 权重卸载解决什么？答：单卡显存放不下全模型，按需驻留当前层。

## 九、演进

全驻留 → 层卸载 → 分块流水卸载。

## 十、小结

权重分页/卸载以时延换显存，使超大模型可单卡/少卡推理。
