# 分层卸载

> 对应逐层权重卸载（与 offloading 推理相关实践）。

## 一、背景与挑战

Transformer 层序计算，天然适合一层算完释放再加载下一层。

## 二、核心原理

按层为粒度：把第 $l$ 层权重从 CPU 拷入，计算其前向，结果传给下一层；可配合计算/拷贝流重叠，使传输隐藏于上一层计算后。

## 三、数学形式

层延迟 $t_l\approx t_{load}(l)+t_{compute}(l)-t_{overlap}$；总延迟 $\sum_l t_l$。

## 四、代码实现

```python
for l in model.layers:
    w = cpu_w[l].to('cuda', non_blocking=True)
    x = l(x, kv_cache)
```

## 五、与其他对比

- 与 迭代级批处理调度深入：调度决定批，卸载决定层驻留。
- 与 推理延迟剖析与火焰图深入：可看到传输 Gap。

## 六、常见误区

- 未用双流重叠，传输串行暴露。
- 层粒度太细致传输次数过多。

## 八、面试题

- 分层卸载如何隐藏传输？答：计算当前层时异步拷下一层，双流重叠。

## 九、演进

同步拷 → 双流重叠 → 分块预取。

## 十、小结

分层卸载是超大模型推理的实用手段，重叠是关键。
