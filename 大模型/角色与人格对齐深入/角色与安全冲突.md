# 角色与安全冲突

> 对应角色扮演中的安全边界问题；安全分类器深入 / 安全对齐 衔接。

## 一、背景与挑战

被要求扮演“无限制助手/反派”时，角色设定与安全准则冲突。

## 二、核心原理

安全应始终为硬约束，高于角色；仅在人设内作答，越界请求一律拒绝，不因角色而破防。

## 三、数学形式

输出约束 $r\in \text{Safe}\cap \text{Persona}$；当冲突取 $r\in\text{Safe}$。

## 四、代码实现

```python
if not safety_ok(resp): resp = refuse()
```

- 与 角色注入攻击深入（攻击即制造冲突）对照。
- 与 安全分类器深入（边界判定）衔接。

## 六、常见误区

- 为角色真实感牺牲安全。
- 安全规则与角色提示分离易被忽视。

## 八、面试题

- 角色与安全冲突怎么办？答：安全为硬约束优先，角色请求越界即拒，不被人设绑架。

## 九、演进

## 十、小结
