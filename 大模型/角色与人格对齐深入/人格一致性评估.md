# 人格一致性评估

> 对应角色一致性自动评测；模型评测指标深入 衔接。

## 一、背景与挑战

人设是否在多轮/多话题保持稳定，需可量化评估。

## 二、核心原理

构造探针问题（关于身份/偏好/能力），比较模型回答与档案的一致性；用矛盾检测与风格相似度。

## 三、数学形式

一致率 $C=\frac{1}{M}\sum_j \mathbb 1(r_j\text{ consistent with }P)$，风格距离用嵌入余弦。

## 四、代码实现

```python
probe = ask_about(persona_keys)
consistency = all(matches(p, persona) for p in probe)
```

## 五、与其他对比

- 与 多轮角色一致性深入（多轮维度）共享。
- 与 红队攻击模拟深入（探测越界）交叉。

## 六、常见误区

- 仅看风格忽略事实一致性。
- 探针过简单被模型识别套路。

## 八、面试题

- 如何评人设一致？答：用探针问身份/偏好，比对档案一致率并测风格相似度。

## 九、演进

人工评 → 探针自动 → 对抗式一致性评测。

## 十、小结

人格一致性评估靠探针与矛盾检测，量化身份稳定。
