# 角色与人格对齐总览

> 对应 Zhang et al., *Personalizing Dialogue Agents (PersonaChat)*, 2018；让模型扮演给定人设。

## 一、背景与挑战

通用助手无稳定人格；用户期望模型以特定身份/风格持续作答（客服、虚拟人）。

## 二、核心原理

以角色档案（persona profile）作为条件，训练/提示模型生成符合该身份、语气、知识边界的回复。

## 三、数学形式

条件生成 $p_\theta(r|u, P)$，$P$ 为角色档案；对齐目标含风格一致性项。

## 四、代码实现

```python
sys = f"你是{P['name']}，性格{P['trait']}"
resp = model(sys + user_turn)
```

## 五、与其他对比

- 与 多轮对话建模深入（人设在多轮保持）衔接。
- 与 指令微调范式深入（角色即特殊指令）对照。

## 六、常见误区

- 人设与系统能力矛盾（自称做不到的）。
- 角色提示被越狱覆盖。

## 八、面试题

- 角色对齐是什么？答：以人设档案为条件，使模型稳定以特定身份/风格/边界作答。

## 九、演进

硬编码人设 → 提示人设 → 人设微调（persona SFT）。

## 十、小结

角色对齐赋予模型稳定身份，是虚拟人/客服场景基础。
