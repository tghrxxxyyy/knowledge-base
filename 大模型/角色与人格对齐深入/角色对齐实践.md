# 角色对齐实践

> 对应生产角色模型落地；datawhalechina/llm-universe 实践 衔接。

## 一、背景与挑战

真实业务需多角色、可切换、可控边界。

## 二、核心原理

用（角色档案, 对话）做 persona SFT；推理时系统提示+检索角色知识；安全层独立拦截。

## 三、数学形式

训练目标 $\mathcal L=\mathcal L_{SFT}+\lambda \mathcal L_{persona\_consist}$。

## 四、代码实现

```python
model.load_adapter(persona_lora)
resp = safe_layer(model(system+turn))
```

## 五、与其他对比

- 与 参数高效微调深入（persona LoRA）衔接。
- 与 多轮对话建模深入（角色对话）共享。

## 六、常见误区

- 角色知识幻觉（编造人设细节）。
- 切换角色未清上下文致串台。

## 七、与开源书对应

## 八、面试题

- 如何做可切换角色？答：persona LoRA+系统提示，切换时清上下文并独立安全层。

## 九、演进

提示角色 → LoRA 角色 → 角色路由多专家。

## 十、小结

角色对齐实践靠 SFT+提示+独立安全，平衡真实与可控。
