# 工具学习训练方法

> 对应 Toolformer 自监督；ToolLLM 指令对齐。

## 一、背景与挑战

如何让模型学会"恰当调用"而非仅会格式。

## 二、核心原理

Toolformer：用 LLM 自标注"是否调用有益"造训练样本，仅在调用提升似然处保留；ToolLLM：用 ChatGPT 蒸馏轨迹+拒绝采样对齐。

## 三、数学形式

自监督损失仅在调用片段：
$\mathcal L=\sum_{i\in call}-\log p(x_i|\text{prefix})$，其余掩蔽。

## 四、代码实现

```python
for sample in self_label():
    if helpful(sample): train_on(sample)
```

## 五、与其他对比

- 与 指令遵循微调 共享 SFT 范式。
- 与 直接偏好优化 可接偏好对齐。

## 六、常见误区

- 自标注噪声致错误调用被学。
- 忽视失败回退（无工具时退化）。

## 八、面试题

## 九、演进

人工标注→自监督→蒸馏对齐。

## 十、小结

工具学习训练靠"有益性"信号，自监督与对齐结合最佳。
