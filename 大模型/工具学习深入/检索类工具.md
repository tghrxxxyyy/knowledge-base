# 检索类工具

> 对应 RAG-as-tool；知识增强工具学习。

## 一、背景与挑战

事实性/时效性问题需在线检索而非靠参数记忆。

## 二、核心原理

把检索封装为工具，模型决定何时查、查什么、如何融合结果；与 RAG 管线结合可提升可信度。

## 三、数学形式

融合 $c=\text{rerank}(q,\text{retrieve}(q))$；证据用于约束生成 $p(y|c,q)$。

## 四、代码实现

```python
docs = search_tool(query)
answer = llm(query, context=docs)
```

## 五、与其他对比

- 与 检索重排序 / 混合检索 共享检索能力。
- 与 指令遵循（引用）衔接。

## 六、常见误区

- 检索结果未筛选直接喂入致噪声。
- 忽视引用溯源致幻觉仍存。

## 八、面试题

- 检索工具何时优于参数记忆？答：时效/长尾/可溯源问题，需在线证据而非静态参数。

## 九、演进

全参数→RAG→工具化按需检索。

## 十、小结

检索工具补足时效与可信，是知识型 agent 标配。
