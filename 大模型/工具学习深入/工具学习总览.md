# 工具学习总览

> 对应 Schick et al., *Toolformer*, 2023；Qin et al., *ToolLLM*, 2023。

## 一、背景与挑战

LLM 内嵌知识有时效/计算局限；工具学习让模型自主调用外部 API/计算器/检索以补不足。

## 二、核心原理

把工具抽象为可调用函数，模型学会"何时用、用哪个、传何参、读结果"；训练可用自监督（Toolformer）或指令对齐。

## 三、数学形式

条件概率 $p(a_t|x,o_{<t})=\text{Softmax}(W h_t)$，动作含 `call(tool,args)`；自监督用片段似然。

## 四、代码实现

```python
if "<API>" in gen:
    name, args = parse_call(gen)
    result = dispatch(name, args)
```

## 五、与其他对比

- 与 智能体规划（行动）共享调用。
- 与 指令遵循（格式）强相关。

## 六、常见误区

- 模型编造参数致调用失败。
- 忽视工具结果的安全过滤。

## 七、与开源书对应

## 八、面试题

- 工具学习价值？答：弥补 LLM 时效/计算短板，把外部能力变成可组合动作。

## 九、演进

提示调用→Toolformer 自监督→ToolLLM 对齐。

## 十、小结

工具学习把 LLM 接入外部世界，是 agent 能力的放大器。
