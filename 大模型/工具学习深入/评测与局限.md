# 工具学习评测与局限

> 对应 ToolBench/ToolLLM 评测；工具失败分析。

## 一、背景与挑战

评测需覆盖"选对工具、参数正确、结果利用"全链路。

## 二、核心原理

指标：工具选择准确率、参数 F1、端到端任务成功率；局限：长尾 API 覆盖、错误传播、安全风险。

## 三、数学形式

参数匹配 $F1=\frac{2PR}{P+R}$；端到端 $SR=\frac{\#correct\_final}{\#tasks}$。

## 四、代码实现

```python
score = f1(parse_args(pred), gold_args)
```

## 五、与其他对比

- 与 模型评测指标深入 共享。
- 与 智能体规划评测 重叠。

## 六、常见误区

- 只看格式正确忽略语义正确。
- 忽视写类工具的安全评测。

## 八、面试题

- 工具学习最大局限？答：长尾/私有 API 覆盖弱，且错误调用会沿链路放大。

## 九、演进

单工具→多工具→自纠错与安全护栏。

## 十、小结

工具学习评测要端到端，安全与覆盖是落地瓶颈。
