# 数据缩放定律总览

> 对应 Kaplan et al., *Scaling Laws for Neural Language Models*, 2020；Hoffmann et al., *Chinchilla*, 2022.

## 一、背景与挑战

训练大模型前需预估：给多少数据、多少算力、多大模型最优？缩放定律提供幂律经验规律指导决策。

## 二、核心原理

损失随算力/数据/参数量呈幂律下降；但三者需协同缩放，数据不足时加大模型边际收益递减（Chinchilla 修正）。

## 三、数学形式

$L(N)=(\frac{N_c}{N})^\alpha+\text{const}$；$L(D)\propto D^{-\beta}$；$L(C)\propto C^{-\gamma}$。

## 四、代码实现

```python
import numpy as np
loss = (Nc / N)**alpha + const          # 参数量缩放
loss_d = (Dc / D)**beta                 # 数据缩放
```

## 五、与其他对比

- 与 训练算力估算深入（算力-数据-参数三元）衔接。
- 与 大模型训练范式（目录）共享决策依据。

## 六、常见误区

- 只按参数量缩放忽略数据（Chinchilla 前常见错）。
- 把经验幂律外推到远超观测区间。
