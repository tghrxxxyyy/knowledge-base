# 数据规模与能力涌现

> 对应 Srivastava et al., *Beyond the Imitation Game*, 2022（BIG-bench）；Wei et al., *Emergent Abilities*, 2022.

## 一、背景与挑战

某些能力（如多步推理）在中小模型上近乎随机，超过规模阈值后突然显现，给规划带来不确定性。

## 二、核心原理

涌现常被视为评测指标非线性跃迁；部分被归因于指标不连续（如精确匹配），连续指标下更平滑，但仍反映量级跃迁。

## 三、数学形式

能力 $A(C)\approx\sigma(\frac{C-C_0}{w})$（sigmoid 跃迁）或分段幂律；阈值 $C_0$ 随任务而异。

## 四、代码实现

```python
import numpy as np
ability = 1/(1+np.exp(-(np.log(C)-np.log(C0))/w))   # 涌现 sigmoid
```

## 五、与其他对比

- 与 数据缩放定律深入（平滑幂律）并存：涌现多针对离散指标。
- 与 数据混合（提关键能力）互补。

## 六、常见误区

- 把指标不连续误当真实突变。
- 以为涌现能力无法预测（连续视角下可外推）。

## 八、面试题

- 涌现能力是真实突变吗？答：部分源于评测指标不连续，连续指标下更接近平滑跃迁，但仍存量级门槛。

## 九、演进

观察涌现 → 指标连续性批判 → 连续可预测视角。

## 十、小结

能力涌现提醒我们规模阈值现象，但需用连续指标冷静评估可预测性。
