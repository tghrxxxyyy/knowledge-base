# 数据质量与去重

> 对应 Lee et al., *Deduplicating Training Data*, 2021；Hernandez et al., *Scaling Data-Constrained*, 2022.

## 一、背景与挑战

数据量固然重要，但重复/低质数据边际收益低甚至有害；去重与提质往往比单纯加量更有效。

## 二、核心原理

对训练语料做近似去重（MinHash/后缀数组），去除高重复与低质样本；实验显示去重可显著提升同算力下性能。

## 三、数学形式

有效数据量 $D_{eff}=D\cdot(1-r_{dup})$；$r$ 为重复率；去重后等效 epoch 信息密度提升。

## 四、代码实现

```python
from datasketch import MinHash, MinHashLSH
lsh = MinHashLSH(threshold=0.8)
for i,doc in enumerate(docs):
    m = MinHash(); [m.update(w.encode()) for w in doc]
    if lsh.query(m): drop(i) else lsh.insert(i, m)
```

## 五、与其他对比

- 与 数据混合与领域权重（配比）互补。
- 与 训练数据质量（目录）共享治理主题。

## 六、常见误区

- 过度去重误删必要重复（如模板）。
- 只去 exact 重复忽略近似重复。

## 八、面试题

- 去重为何提升性能？答：减少冗余样本使每 step 信息密度更高，等效更多有效数据。

## 九、演进

不去重 → exact 去重 → 近似去重 + 质量过滤。

## 十、小结

数据质量与去重是缩放定律之外的关键杠杆，常比单纯加量更划算。
