# 数据混合与领域权重

> 对应 Xie et al., *DoReMi*, 2023；Ye et al., *Data Mixture Cloning*, 2024；Gao et al., *Data Selection*, 2020.

## 一、背景与挑战

不同领域（网页/代码/数学/书籍）对目标能力贡献不同；均匀混合常非最优，需按比例加权。

## 二、核心原理

用小型代理模型做域权重搜索（DoReMi 以学生模型 KL 最小化为目标），或按领域损失下降率动态调整混合比例。

## 三、数学形式

混合损失 $L=\sum_d w_d L_d$，约束 $\sum_d w_d=1$；$w^*$ 使各域边际收益均衡（类似经济学等边际）。

## 四、代码实现

```python
# DoReMi: 用参考模型指导域权重
ref_logits = ref(input_ids)
for d in domains: w[d] = optimize_kl(student(d), ref_logits)
```

## 五、与其他对比

- 与 数据质量与去重（先提质再配比）顺序衔接。
- 与 训练数据质量（目录）共享。

## 六、常见误区

- 固定权重忽略训练阶段变化（后期应调整）。
- 过度偏向某域致其他能力塌缩。
