# 预训练中的难度重加权

> 对应 Mindermann et al. 2022 "Prioritized Training on Points that are Learnable, Worth Learning" 相关工作。

## 一、背景与挑战

LLM 预训练损失主要由少数高频模式主导，长尾难样本(罕见事实、复杂推理)信号被淹没。难度重加权可提升难样本学习效率。

## 二、核心原理

基于“可学习性”对样本加权：模型快速学会的样本降权，长期学不会(可能噪声)的样本也降权，聚焦“值得学且正在学”的中间带。

## 三、数学形式

样本权重随学习进度更新：

$$
w_i^{(t+1)} = w_i^{(t)} \cdot \exp(\eta \cdot \tilde{\ell}_i^{(t)})
$$

其中 $\tilde{\ell}_i$ 为损失归一化后的“意外度”，过高(噪声)或过低(已会)均不增益。

## 四、代码实现

```python
import torch

def reweight(losses, w, lr=0.1):
    norm = (losses - losses.mean()) / (losses.std() + 1e-8)
    return w * torch.exp(lr * torch.tanh(norm))
```

## 五、与其他对比

与 Focal Loss 类似但作用于整个预训练序列，且权重跨步持续演化。

## 六、常见误区

误区：对持续高损失样本一直加权。可能是在学噪声，应设上限。

## 八、面试题

- Q：难样本重加权目标？答：聚焦“可学且未学会”的样本，避噪声与已会。
- Q：与课程学习区别？答：动态按学习进度而非固定难度。

难度重加权让预训练集中在信息量最高的样本带，是难例思想在 LLM 的延伸。
