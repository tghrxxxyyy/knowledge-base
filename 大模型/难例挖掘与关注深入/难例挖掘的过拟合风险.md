# 难例挖掘的过拟合风险

> 对应 Lin et al. 2017 "Focal Loss" 与难例挖掘鲁棒性讨论。

## 一、背景与挑战

过度聚焦难例会把模型推向训练集的极端样本，包括标注错误、对抗样本与分布外点，导致验证集泛化下降。

## 二、核心原理

难例密度高的区域往往与噪声边界重叠。一旦重加权过度，模型在难例上过拟合，平滑区域欠拟合，整体鲁棒性下降。

## 三、数学形式

经验风险被重加权后近似：

$$
\hat{\mathcal{L}}_w = \sum_i w_i \ell_i \approx \int w(x)\ell(x)p(x)dx
$$

当 $w(x)$ 在难例区过尖，估计方差增大，泛化界变宽：

$$
\mathrm{GenGap} \propto \frac{\mathrm{Var}_w(\ell)}{\sqrt{n}}
$$

## 四、代码实现

```python
import torch

def weighted_gen_gap(losses, w):
    weighted = (w * losses)
    return weighted.var().item() / (len(losses) ** 0.5)
```

## 五、与其他对比

相比均匀训练，难例挖掘降低偏差但增大方差，需正则(早停、权重上限)平衡。

## 六、常见误区

误区：难例权重无上限。应设裁剪与温度控制，避免极端样本主导。

## 八、面试题

- Q：难例挖掘为何可能过拟合？答：难例区常与噪声重叠，重加权放大噪声。
- Q：如何缓解？答：权重裁剪、温度、早停、配合易样本复盘。

## 九、演进

提出难例置信过滤(先去噪再挖掘)与课程式渐进暴露。

## 十、小结

难例挖掘须设护栏，偏差-方差权衡是其工程落地的核心。
