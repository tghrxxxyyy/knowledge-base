# 难负样本挖掘

> 对应 Schroff et al. 2015 "FaceNet" 与对比学习中的难负样本研究。

## 一、背景与挑战

在度量学习/检索/对比学习中，大量易负样本提供微弱信号。难负样本(与锚点相近却不同类)才是提升判别力的关键，但过难负样本可能是标签错误或跨类模糊。

## 二、核心原理

三元组损失中，仅当负样本比正样本更“近”锚点时才产生非零梯度。难负挖掘即主动挑选这类样本。

## 三、数学形式

三元组损失：

$$
\mathcal{L} = \sum_{i,j,k} \max(0,\, d(a_i,p_i)^2 - d(a_i,n_i)^2 + m)
$$

难负 $n_i$ 使 $d(a_i,n_i)$ 小但不小于 $d(a_i,p_i)-m$，即“半硬”区间最具信息量。

## 四、代码实现

```python
import torch

def triplet_loss(a, p, n, m=0.2):
    dpos = (a - p).pow(2).sum(-1)
    dneg = (a - n).pow(2).sum(-1)
    return torch.clamp(dpos - dneg + m, min=0).mean()
```

## 五、与其他对比

与分类难例挖掘不同，难负关注表示空间距离结构，常配合 InfoNCE 使用。

## 六、常见误区

误区：用最难的负样本(最近异类)会引入噪声。半硬负样本更稳。

## 八、面试题

- Q：为何用半硬负样本？答：最硬负常是噪声，半硬信息量最高且干净。
- Q：难负在 LLM 对比学习？答：同义/近义句作为难负提升语义判别。

## 九、演进

从离线难负挖掘到在线大规模难负(如 MoCo 记忆库)，再到 LLM 嵌入对比。

## 十、小结

难负样本是表示学习的核心驱动力，挖掘需平衡难度与噪声。
