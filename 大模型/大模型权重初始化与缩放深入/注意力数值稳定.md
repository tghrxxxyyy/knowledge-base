# 注意力数值稳定

> 对应 Vaswani 2017 缩放点积注意力 与 Su 2021 RoPE、Zhang & Sennrich 2019 RMSNorm。

## 一、背景与挑战
softmax 在 large logits 下梯度趋零、数值溢出；深层注意力需归一化与位置编码协同保证稳定。

## 二、核心原理
缩放点积 $QK^\\top/\\sqrt d_k$ 防止维度大时方差过大导致 softmax 饱和；RMSNorm 替代 LayerNorm 减少计算并稳定；RoPE 以旋转注入位置信息不改变范数。

## 三、形式化与数学基础
注意力：
$ \\mathrm{Attn}(Q,K,V) = \\mathrm{softmax}(QK^\\top/\\sqrt{d_k})V $，
logit 方差约 $d_k\\cdot \\sigma^2_q\\sigma^2_k$，除以 $\\sqrt{d_k}$ 使其回到 $O(1)$，softmax 不过早饱和。

## 四、代码实现
```python
import torch
def scaled_dot_product(q, k, v):
    d = q.size(-1)
    scores = q @ k.transpose(-2, -1) / d ** 0.5
    attn = torch.softmax(scores, dim=-1)
    return attn @ v
```

## 五、与其他技术对比
无缩放注意力在 $d_k$ 大时退化；RoPE/ALiBi 改变位置偏置但不解决饱和，仍需缩放。RMSNorm 比 LayerNorm 更省算力。

## 六、常见误区
误区一：缩放可省——大 $d_k$ 必饱和。误区二：softmax 数值稳——需减最大值防溢出(flash-attn 内处理)。误区三：RMSNorm 等价 LayerNorm，实为去均值。

## 七、与开源书/权威来源对应
Vaswani 2017；Su 2021 RoPE；Zhang & Sennrich 2019 RMSNorm；Dao 2022 FlashAttention。

## 八、面试题
问：为何除 $\\sqrt{d_k}$？答：控 logit 方差防 softmax 饱和。问：RMSNorm 优势？答：去均值更省、稳定。

## 九、演进与趋势
flash-attention 重排计算提数值与显存；QK-Norm 进一步稳深注意力。

## 十、小结
注意力数值稳定依赖缩放、归一化与内核实现三层保障，是深层 transformer 训练基石。
