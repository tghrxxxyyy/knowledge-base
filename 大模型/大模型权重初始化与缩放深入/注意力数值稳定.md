# 注意力数值稳定

> 对应 Vaswani 2017 缩放点积注意力 与 Su 2021 RoPE、Zhang & Sennrich 2019 RMSNorm。

## 一、背景与挑战

缩放点积注意力（scaled dot-product attention）的 softmax 对大 logit 高度敏感：logit 过大时 softmax 趋近 one-hot，梯度趋零（饱和）、数值溢出；过大维度 $d_k$ 下 $QK^\top$ 方差随 $d_k$ 线性增长，更易饱和。深层 Transformer 还需归一化与位置编码协同，保证注意力数值稳定与训练不发散。

挑战在于：如何在任意 $d_k$、任意深度下都把 logit 方差控制在 $O(1)$，且实现上避免 softmax 的 exp 溢出（需减最大值）。这是深层注意力训练基石。

## 二、核心原理

缩放点积 $QK^\top/\sqrt{d_k}$ 防止维度大时方差过大导致 softmax 饱和。RMSNorm 替代 LayerNorm 去均值、更省算力且稳定。RoPE（旋转位置编码）以旋转矩阵注入位置信息，保持向量范数不变，不改变注意力数值尺度。FlashAttention 重排计算（tiling + 在线 softmax）在数值稳定同时降显存、提速度。三者分别作用于「logit 尺度」「激活归一」「位置编码」「内核实现」四层保障。

还需注意 Q/K 的尺度：若不经归一，随深度累积 QKᵀ 方差仍可能漂移，故 QK-Norm（先对 Q、K 做层归一）被引入进一步稳深注意力。FlashAttention 的「在线 softmax」边分块计算边维护最大值与指数和，既避免存完整注意力矩阵（降显存），又保证数值与标准 softmax 一致。位置编码如 RoPE 保持范数，不改变注意力尺度。

## 三、形式化与数学基础

注意力：

$$ \mathrm{Attn}(Q,K,V) = \mathrm{softmax}\!\left( \frac{QK^\top}{\sqrt{d_k}} \right) V $$

若 $q,k$ 各元素方差 $\sigma_q^2,\sigma_k^2$，则单元素 logit 方差约：

$$ \mathrm{Var}(q \cdot k) \approx d_k \cdot \sigma_q^2 \sigma_k^2 $$

除以 $\sqrt{d_k}$ 使其回到 $O(1)$，softmax 不过早饱和。RoPE 用旋转矩阵 $R(\theta)$ 满足 $\|R(\theta)x\| = \|x\|$，故不改变向量范数，位置信息以夹角注入。softmax 数值稳定实现需减最大值：

$$ \mathrm{softmax}(z)_i = \frac{\exp(z_i - m)}{\sum_j \exp(z_j - m)},\quad m = \max_j z_j $$

避免 $\exp$ 溢出。

## 四、代码实现

```python
import torch
import torch.nn.functional as F

def scaled_dot_product(q, k, v):
    d = q.size(-1)
    scores = q @ k.transpose(-2, -1) / d ** 0.5   # 缩放防饱和
    # 减最大值防 exp 溢出（在线 softmax 由 FlashAttention 内部处理）
    attn = F.softmax(scores, dim=-1)
    return attn @ v

def rms_norm(x, dim, eps=1e-6):
    # RMSNorm：去均方根归一化，更省算力
    rms = torch.sqrt(x.pow(2).mean(dim=-1, keepdim=True) + eps)
    return x / rms

# RoPE：把位置旋转注入 q,k，保持范数不变
def apply_rope(x, cos, sin):
    x1, x2 = x.chunk(2, dim=-1)
    return torch.cat([x1 * cos - x2 * sin, x2 * cos + x1 * sin], dim=-1)
```

## 五、与其他技术对比

| 技术 | 作用 | 备注 |
|------|------|------|
| 缩放 $1/\sqrt{d_k}$ | 控 logit 方差 | 必需 |
| RoPE / ALiBi | 位置偏置 | 不解决饱和，仍需缩放 |
| RMSNorm | 激活归一 | 比 LayerNorm 省算力 |
| FlashAttention | 内核重排 | 数值+显存+速度 |

无缩放注意力在 $d_k$ 大时退化；RoPE/ALiBi 改变位置偏置但不解决饱和，仍需缩放。RMSNorm 比 LayerNorm 更省且不依赖均值统计。

## 六、常见误区

误区一：缩放可省——大 $d_k$ 必饱和，gradient 消失。误区二：softmax 数值稳——需减最大值防 exp 溢出（FlashAttention 内处理）。误区三：RMSNorm 等价 LayerNorm——实为去均值，统计与行为不同。误区四：位置编码影响数值尺度——RoPE 保持范数，ALiBi 加偏置但需配合缩放。

## 八、面试题

1. 为何除 $\sqrt{d_k}$？控 logit 方差（$d_k\sigma_q^2\sigma_k^2 \to O(1)$），防 softmax 饱和与梯度消失。
2. softmax 为何减最大值？避免 exp 上溢，数学等价且数值安全。
3. RoPE 优势？以旋转注入位置、保持范数不变，不改注意力尺度。
4. RMSNorm 与 LayerNorm 区别？去均值 vs 减均值除标准差，RMSNorm 更省且稳。

QK-Norm 把「logit 方差受控」从缩放推广到归一化，使深注意力更稳。FlashAttention-2/3 进一步优化分块与并行，数值一致且显存更省。可观测上，监控注意力权重熵（是否过早变 one-hot）是判断饱和与数值风险的前兆指标，优于训练炸裂后再排查。

## 十、小结

注意力数值稳定依赖「缩放 + 归一化 + 位置编码 + 内核实现」四层保障：除以 $\sqrt{d_k}$ 控方差、RMSNorm/QK-Norm 稳激活、RoPE 保持范数、FlashAttention 在线 softmax 防溢出。这是深层 Transformer 训练的基石。
