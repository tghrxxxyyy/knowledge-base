# 深度缩放初始化

> 对应 Huang 2020 (Fixup/ReZero) 与 Vaswani 2017 深度稳定。

## 一、背景与挑战

极深网络即便用 Pre-LN，也可能出现「末层信号过大、浅层信号被淹没」或训练初期 spike。原因在于残差叠加下，信号方差随层数 $L$ 累积，若残差分支增益不随深度缩放，深层输出尺度会失控。深度缩放初始化（deep-scale initialization）显式引入残差增益 $\alpha$ 与深度相关缩放，使信号方差随层数受控、各层更新均衡。

挑战在于：缩放系数如何随 $L$ 取值？过小致更新停滞（退化网络），过大仍发散。需把经验 warmup 替换为可证明的初始化约束。

## 二、核心原理

两类代表：**Fixup**（Huang 2020）对每个残差分支权重乘 $L^{-1/4}$，使 $L$ 层累积后方差有界；**ReZero**（Bachlechner 2021）令残差分支可学习增益 $\alpha$ 初始化为 0，使网络初始为「恒等映射」，逐层平滑加深。二者都把「深度」显式编入初始化，免去长 warmup。DeepNorm 则统一 Post-LN 的稳定（见「Pre-LN 与 Post-LN 初始化」）。

核心思想：模型初始应接近恒等（什么都没学），残差分支从近零开始、随训练逐步获得表达力，避免首步大更新炸裂。

核心直觉是「模型初始应接近恒等映射」：残差分支从近零开始，随训练逐步获得表达力，避免首步大更新炸裂。Fixup 从权重尺度入手（L^{-1/4}），ReZero 从可学习增益入手（alpha=0），DeepNorm 从残差/初始化双缩放入手，殊途同归——都让深度以可控方式逐步「打开」，免去长 warmup。

## 三、形式化与数学基础

Fixup 对残差分支权重缩放：

$$ w \leftarrow w \cdot L^{-1/4} $$

整体残差叠加：

$$ h_L = h_0 + \sum_{l=1}^{L} \alpha_l F_l(h_{l-1}),\quad \alpha_l = L^{-1/4} $$

保证 $\mathrm{Var}(h_L)$ 有界且各层更新均衡。ReZero 令初始增益：

$$ \alpha = 0 \implies h_{l+1} = h_l + 0 \cdot F_l(h_l) = h_l $$

即初始为恒等映射，训练逐步「打开」残差分支。DeepNorm 给出（见前节）：

$$ \alpha = (2N)^{1/4},\; \beta = (8N)^{-1/3} $$

统一 Pre/Post-LN 的稳定缩放。

## 四、代码实现

```python
import torch, math

def fixup_init(model, depth):
    # 残差分支权重按 L^{-1/4} 缩放，非残差分支正常初始化
    scale = math.pow(depth, -0.25)
    for m in model.residual_branches():
        if isinstance(m, torch.nn.Linear):
            torch.nn.init.normal_(m.weight, 0, scale)
            if m.bias is not None:
                torch.nn.init.zeros_(m.bias)

class ReZeroBlock(torch.nn.Module):
    def __init__(self, d):
        super().__init__()
        self.alpha = torch.nn.Parameter(torch.zeros(1))   # 初始 0 = 恒等
        self.sub = torch.nn.Linear(d, d)

    def forward(self, x):
        return x + self.alpha * self.sub(x)               # 平滑加深
```

## 五、与其他技术对比

| 方法 | 机制 | 是否免 warmup | 备注 |
|------|------|----------------|------|
| Post-LN + warmup | 靠 lr 控 | 否 | 原始 |
| Fixup | 初始化缩放 $L^{-1/4}$ | 近似 | 权重级 |
| ReZero | 增益 $\alpha=0$ | 近似 | 参数级 |
| DeepNorm | $\alpha,\beta$ 深度缩放 | 近似 | 统一 Pre/Post |

Post-LN + warmup 靠学习率控；Fixup/ReZero/DeepNorm 靠初始化控，免去长 warmup。DeepNorm 兼得稳定与表达。

## 六、常见误区

误区一：缩放越小越稳——过小致更新停滞，网络退化。误区二：与 LN 冲突——可叠加，LN 管激活、深度缩放管信号传播。误区三：深层才需——百层起就显著，浅层也受益。误区四：ReZero 的 $\alpha$ 固定——它是可学习参数，训练中会增长。

## 八、面试题

1. Fixup 缩放？残差分支权重乘 $L^{-1/4}$，使 $L$ 层累积方差有界。
2. ReZero 作用？初始增益 $\alpha=0$ 使网络初始恒等，平滑加深、免长 warmup。
3. 为何要深度缩放？防止残差叠加使深层信号方差失控、首步大更新炸裂。
4. DeepNorm 与 Fixup 关系？DeepNorm 给出可证明的 $\alpha,\beta$ 深度缩放，统一 Pre/Post-LN 稳定。

μP 把深度缩放与宽度可迁移统一，使深层配置可从小模型外推。ReZero/Fixup 的思想延伸到归一化无关架构，降低对 LayerNorm 的依赖。可观测上，监控「残差分支增益 alpha 的训练轨迹」可判断网络是否健康地从恒等逐步「打开」，是诊断深度不稳的新视角。

## 十、小结

深度缩放初始化以显式增益约束信号传播：Fixup 用 $L^{-1/4}$、ReZero 用初始 $\alpha=0$、DeepNorm 用深度相关缩放，使超深模型稳定训练、免去长 warmup。理解「初始接近恒等、残差逐步打开」是掌握深度稳定的关键。
