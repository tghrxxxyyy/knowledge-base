# 深度缩放初始化

> 对应 Huang 2020 (Fixup/ReZero) 与 Vaswani 2017 深度稳定。

## 一、背景与挑战
极深网络即便 Pre-LN 也可能末层信号过大。深度缩放初始化显式引入残差增益 $\\alpha$ 与深度缩放，使信号方差随层数受控。

## 二、核心原理
对残差分支乘缩放系数(如 $1/\\sqrt{L}$ 或 Fixup 的 $L^{-1/4}$)，使 $L$ 层累积后方差不爆炸；ReZero 令初始增益 $\\alpha=0$ 使网络初始为恒等。

## 三、形式化与数学基础
Fixup：残差分支权重缩放 $w \\leftarrow w \\cdot L^{-1/4}$；整体：
$ h_{L} = h_0 + \\sum_{l=1}^{L} \\alpha_l F_l(h_{l-1}),\\quad \\alpha_l = L^{-1/4} $，
保证 $\\mathrm{Var}(h_L)$ 有界且各层更新均衡。

## 四、代码实现
```python
import torch, math
L = depth
for m in residual_branch_modules:
    torch.nn.init.normal_(m.weight, 0, math.pow(L, -0.25))
# ReZero: 可学习标量 alpha 初始化为 0
alpha = torch.nn.Parameter(torch.zeros(1))
h = x + alpha * F(x)
```

## 五、与其他技术对比
Post-LN+warmup 靠学习率控；Fixup/ReZero 靠初始化控，免去长 warmup。DeepNorm 统一二者。

## 六、常见误区
误区一：缩放越小越稳——过小致更新停滞。误区二：与 LN 冲突——可叠加。误区三：深层才需，实际百层起就显著。

## 七、与开源书/权威来源对应
Huang 2020 Fixup；Bachlechner 2021 ReZero；Vaswani 2017 深度分析。

## 八、面试题
问：Fixup 缩放？答：残差分支 $L^{-1/4}$。问：ReZero 作用？答：初始恒等、平滑加深。

## 九、演进与趋势
DeepNorm 兼得稳定与表达；与 RMSNorm 组合。

## 十、小结
深度缩放初始化以显式增益约束信号传播，是超深模型稳定训练的关键技巧。
