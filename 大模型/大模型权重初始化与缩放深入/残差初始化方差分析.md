# 残差初始化方差分析

> 对应 He 2015 (Kaiming 初始化) 与 Vaswani 2017 (Pre-LN 分析)。

## 一、背景与挑战

深层网络中，前向信号方差与反向梯度方差会随层数指数漂移：方差膨胀→激活饱和（梯度消失/爆炸），方差收缩→信号湮灭。残差连接（ResNet 式 $h_{l+1}=h_l+F_l(h_l)$）改变了方差传播规律——它让深层方差不再简单连乘，但仍需正确初始化残差分支 $F_l$，否则深层方差仍会累积或衰减。

挑战在于：如何用方差分析定量给出初始化标准差，使信号「跨层方差稳定」，进而决定能否训练。这是从 He/Xavier 到 Pre-LN 深层分析的统一线索。

## 二、核心原理

对线性层 $y = Wx$，若 $W$ 各元素方差 $\sigma_w^2$、输入各元素独立同分布且方差 $\sigma_x^2$，则输出方差：

$$ \sigma_y^2 = n_{\mathrm{in}} \cdot \sigma_w^2 \cdot \sigma_x^2 $$

令 $n_{\mathrm{in}} \sigma_w^2 = 1$（即 $\sigma_w^2 = 1/n_{\mathrm{in}}$）可保前向方差不变——这就是 Xavier 的思想。残差 $h_{l+1}=h_l+F_l(h_l)$ 要求分支 $F_l$ 初始化接近零，使深层方差不累积，近似有 $\mathrm{Var}(h_L) \approx \mathrm{Var}(h_0)$。

更严格地，残差前向方差满足：Var(h_{l+1}) ≈ Var(h_l) + Var(F_l(h_l))。若分支近零初始化使 Var(F_l)≈0，深层方差不漂移。反向同理：残差直连让梯度可传到任意浅层，各层梯度方差受控，避免层数越深梯度越小（消失）或越大（爆炸）。这正是 Kaiming/Xavier 与残差分析的统一线索。

## 三、形式化与数学基础

- **Xavier / Glorot**（线性、tanh 对称）：$$\sigma_w^2 = \frac{1}{n_{\mathrm{in}}}$$
- **Kaiming / He**（ReLU 族，半区置零，方差减半需补偿 2）：$$\sigma_w^2 = \frac{2}{n_{\mathrm{in}}}$$

残差网络前向方差递推（忽略分支协方差交叉项）：

$$ \mathrm{Var}(h_{l+1}) \approx \mathrm{Var}(h_l) + \mathrm{Var}(F_l(h_l)) $$

若 $\mathrm{Var}(F_l) \approx 0$（分支近零初始化），则 $\mathrm{Var}(h_L) \approx \mathrm{Var}(h_0)$，深层不漂移。反向梯度同理：各层梯度方差受残差直连保持一致，避免层数越深梯度越小（消失）或越大（爆炸）。

## 四、代码实现

```python
import torch

def init_for_nonlinearity(model, nonlinearity="relu"):
    # 按非线性选择初始化，保持前向方差稳定
    for m in model.modules():
        if isinstance(m, (torch.nn.Linear, torch.nn.Conv2d)):
            if nonlinearity in ("relu", "gelu", "silu"):
                torch.nn.init.kaiming_normal_(m.weight, nonlinearity=nonlinearity)
            else:
                torch.nn.init.xavier_normal_(m.weight)
            if m.bias is not None:
                torch.nn.init.zeros_(m.bias)

def near_zero_residual(branch):
    # 残差分支近零初始化，防止深层方差累积
    for m in branch.modules():
        if isinstance(m, torch.nn.Linear):
            torch.nn.init.normal_(m.weight, 0, 1e-2)
```

## 五、与其他技术对比

| 初始化 | 假设 | 适用 | 公式 |
|--------|------|------|------|
| Xavier | 线性 / tanh 对称 | 浅层、RNN | $1/n_{\mathrm{in}}$ |
| Kaiming | ReLU 族 | CNN/深层 | $2/n_{\mathrm{in}}$ |
| Pre-LN 缩放 | 残差近零分支 | Transformer | 额外残差增益 |

Xavier 假设线性/对称激活；Kaiming 针对 ReLU 族补偿半区置零。Transformer 用 Pre-LN，初始化更稳但仍需缩放残差分支（见「Pre-LN 与 Post-LN 初始化」）。

## 六、常见误区

误区一：默认初始化够用——深模型需按非线性选 Kaiming/Xavier，否则方差漂移。误区二：残差免初始化——分支仍需近零初始化，否则深层方差累积。误区三：方差分析无用——它直接决定能否训练，是初始化公式的来源。误区四：Xavier 与 Kaiming 可混用——激活不同应匹配不同公式。

## 八、面试题

1. Kaiming 为何用 $2/n_{\mathrm{in}}$？补偿 ReLU 半区置零导致的方差减半，保持前向方差稳定。
2. 残差为何需近零分支？避免深层方差累积，使 $\mathrm{Var}(h_L)\approx\mathrm{Var}(h_0)$。
3. Xavier 假设是什么？线性或对称激活（tanh），方差 $1/n_{\mathrm{in}}$。
4. 方差分析如何指导初始化？由 $\sigma_y^2=n_{\mathrm{in}}\sigma_w^2\sigma_x^2$ 反解 $\sigma_w$ 使方差不变。

μP 把方差/更新分析推广到「最大更新」框架，使初始化、lr、宽度三者关系可推导。深度缩放（DeepNorm）从近似稳定提升为可证明稳定，与 Pre-LN 分析衔接。可观测上，用「信号方差随层曲线」验证初始化是否达标，是深层模型上线前的常规检查，而非事后补救。

## 九、演进与趋势

深度缩放初始化（DeepNorm）显式控制残差增益，把方差分析从「近似」提升为「可证明稳定」（见「深度缩放初始化」）。μP 把方差/更新分析推广到「宽度可迁移」，使窄模型上调出的 lr 可直接用于宽模型。趋势是初始化理论与优化器、归一化统一建模。

## 十、小结

初始化方差分析保障信号跨层稳定，是大模型可训练的前提。从 Xavier/Kaiming 的前向方差不变，到残差分支近零初始化，核心都是控制方差漂移。理解 $\sigma_y^2=n_{\mathrm{in}}\sigma_w^2\sigma_x^2$ 与残差递推，是掌握深层初始化设计的钥匙。
