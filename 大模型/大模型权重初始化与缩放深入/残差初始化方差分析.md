# 残差初始化方差分析

> 对应 He 2015 (Kaiming 初始化) 与 Vaswani 2017 (Pre-LN 分析)。

## 一、背景与挑战
深层网络前向/反向信号方差随层数指数漂移会导致梯度消失/爆炸。残差连接改变方差传播，需重新分析初始化方差。

## 二、核心原理
对线性层 $y=Wx$，若 $W$ 各元素方差 $\\sigma^2_w$、输入方差 $\\sigma^2_x$，则输出方差 $\\sigma^2_y = n_{\\mathrm{in}}\\sigma^2_w\\sigma^2_x$。令 $n_{\\mathrm{in}}\\sigma^2_w=1$ 保方差稳定(即 Kaiming/Xavier)。

## 三、形式化与数学基础
Xavier：$\\sigma^2_w = 1/n_{\\mathrm{in}}$；Kaiming(ReLU)：$\\sigma^2_w = 2/n_{\\mathrm{in}}$。残差 $h_{l+1}=h_l + F_l(h_l)$ 要求 $F$ 初始化接近零，使深层方差不累积：
$ \\mathrm{Var}(h_{L}) \\approx \\mathrm{Var}(h_0) $。

## 四、代码实现
```python
import torch
# Kaiming 初始化(适用于 ReLU 类)
for m in model.modules():
    if isinstance(m, torch.nn.Linear):
        torch.nn.init.kaiming_normal_(m.weight, nonlinearity="relu")
```

## 五、与其他技术对比
Xavier 假设线性/tanh；Kaiming 针对 ReLU 族。Transformer 用 Pre-LN，初始化更稳但仍需缩放残差分支。

## 六、常见误区
误区一：默认初始化够用——深模型需按非线性选。误区二：残差免初始化——分支仍需近零初始化。误区三：方差分析无用，实际决定能否训练。

## 七、与开源书/权威来源对应
He 2015 Kaiming；Glorot 2010 Xavier；Vaswani 2017 残差分析。

## 八、面试题
问：Kaiming 为何用 2/fan_in？答：补偿 ReLU 半区置零。问：残差为何需近零分支？答：避免深层方差累积。

## 九、演进与趋势
深度缩放初始化(deepnorm)显式控制残差增益。

## 十、小结
初始化方差分析保障信号跨层稳定，是大模型可训练的前提。
