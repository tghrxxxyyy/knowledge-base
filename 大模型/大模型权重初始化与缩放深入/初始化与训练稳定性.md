# 初始化与训练稳定性

> 对应 Shazeer 2020 (GLU) 与 Vaswani 2017 训练动态。

## 一、背景与挑战
大模型训练初期 loss 尖峰(spike)常见，常源于初始化方差不当或注意力饱和。需综合初始化、归一化、激活选择提升稳定。

## 二、核心原理
采用 Pre-LN + RMSNorm + 残差缩放降低方差漂移；GLU 类激活(如 SwiGLU)提供门控使信息流更可控；输出层近零初始化防首步大更新。

## 三、形式化与数学基础
SwiGLU：$ \\mathrm{SwiGLU}(x) = \\mathrm{Swish}(xW_1)\\odot xW_2 $，
门控使有效秩与梯度流更稳定；配合残差缩放使首步 $\\|\\Delta\\theta\\|\\propto \\eta\\cdot\\sigma_w$ 可控。

## 四、代码实现
```python
import torch
def swiglu(x, w1, w2):
    return torch.nn.functional.silu(x @ w1) * (x @ w2)
```

## 五、与其他技术对比
ReLU 类易死神经元、方差漂移大；GLU/SwiGLU 更稳但参数增倍。Tanh 早期用、深层不稳已弃。

## 六、常见误区
误区一：激活不影响初始化——GLU 改变方差需重调。误区二：spike 必是 lr 大——常是初始化/归一化。误区三：输出层随意初始化，实际近零更稳。

## 七、与开源书/权威来源对应
Shazeer 2020 GLU；Vaswani 2017；Zhang & Sennrich 2019 RMSNorm；Touvron 2023 LLaMA 用 SwiGLU。

## 八、面试题
问：loss spike 来源？答：初始化/归一化/注意力饱和。问：SwiGLU 作用？答：门控稳信息流，参数翻倍。

## 九、演进与趋势
QK-Norm、muP 进一步提升超深稳定；混合激活搜索。

## 十、小结
训练稳定性是初始化、归一化、激活与优化的系统结果，大模型依赖 Pre-LN+GLU+RMSNorm 组合。
