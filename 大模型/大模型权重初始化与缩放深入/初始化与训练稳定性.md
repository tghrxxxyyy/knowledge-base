# 初始化与训练稳定性

> 对应 Shazeer 2020 (GLU) 与 Vaswani 2017 训练动态。

## 一、背景与挑战

大模型训练初期常出现 loss 尖峰（spike）：训练平稳进行数百步后 loss 突然暴涨，随后可能收敛也可能不回。根源通常不是学习率本身，而是初始化方差不当、归一化位置、注意力饱和与激活选择的耦合失衡。深层 Transformer 因为残差叠加，信号方差随层数累积漂移，一旦某层激活饱和或梯度爆炸，整轮训练就废。

稳定性是系统性结果，需从初始化、归一化（LayerNorm/RMSNorm）、激活（ReLU/SwiGLU）、残差缩放与学习率 warmup 五方面协同设计，而非单点修补。

## 二、核心原理

主流稳定组合：**Pre-LN + RMSNorm + 残差缩放 + GLU 类激活**。Pre-LN 让梯度直连下层、各层梯度范数相近；RMSNorm 去均值、计算更省且稳定；残差缩放（如 DeepNorm）约束残差分支增益，防止深层方差累积；GLU 类激活（SwiGLU）用门控使信息流更可控、有效秩更高；输出投影近零初始化防止首步大更新。该组合使超深模型在较小 warmup 下即可稳定。

这套组合不是任意拼凑：Pre-LN 管梯度直连、RMSNorm 管激活尺度、残差缩放管信号传播、GLU 管信息流门控、近零输出初始化管首步更新。任一缺失都可能让深层训练在数百步后 spike。诊断时常用「各层激活方差随层曲线」「各层梯度范数」可视化，定位是初始化、归一化还是注意力饱和导致的不稳。

## 三、形式化与数学基础

SwiGLU 定义：

$$ \mathrm{SwiGLU}(x) = \mathrm{Swish}(xW_1) \odot (xW_2),\quad \mathrm{Swish}(z) = z \odot \sigma(z) $$

门控使有效秩与梯度流更稳定。配合残差缩放，首步参数更新范数受控：

$$ \|\Delta \theta\| \propto \eta \cdot \sigma_w $$

其中 $\eta$ 为学习率、$\sigma_w$ 为初始化标准差。若 $\sigma_w$ 过大，首步更新炸裂触发 spike；过小则收敛停滞。注意力 logit 方差约 $d_k \sigma_q^2 \sigma_k^2$，需除以 $\sqrt{d_k}$ 回到 $O(1)$（见「注意力数值稳定」）。

## 四、代码实现

```python
import torch
import torch.nn.functional as F

def swiglu(x, w1, w2):
    # x: [*, d_in]；w1,w2: [d_in, d_ff]
    return F.silu(x @ w1) * (x @ w2)     # 门控：Swish 与线性支路逐元素乘

class PreLNBlock(torch.nn.Module):
    def __init__(self, d, alpha=0.5):
        super().__init__()
        self.norm = torch.nn.RMSNorm(d)          # 去均值归一化
        self.attn = torch.nn.Linear(d, d)
        self.alpha = alpha                        # 残差缩放增益

    def forward(self, x):
        h = x + self.alpha * self.attn(self.norm(x))
        return h
```

## 五、与其他技术对比

| 激活 | 稳定性 | 参数 | 备注 |
|------|--------|------|------|
| ReLU / GELU | 易死神经元、方差漂移 | 1x | 经典 |
| SwiGLU (GLU) | 门控更稳、有效秩高 | 2x | 大模型主流（LLaMA） |
| Tanh | 深层不稳 | 1x | 早期，已弃于深模型 |

ReLU 类易死神经元、方差漂移大；GLU/SwiGLU 更稳但参数增倍。Tanh 在深层易饱和已弃用。归一化位置（Pre/Post-LN）见「Pre-LN 与 Post-LN 初始化」。

## 六、常见误区

误区一：激活不影响初始化——GLU 改变方差需重调缩放，否则首步更新范数失控。误区二：spike 必是 lr 大——常是初始化/归一化不当，降 lr 只是掩盖。误区三：输出层随意初始化——输出投影近零初始化更稳，避免首步大更新炸裂。误区四：Pre-LN 无需 warmup——仍建议，深层仍需对齐初始化与 lr。

## 八、面试题

1. loss spike 来源？初始化方差不当 + 注意力饱和 + 归一化位置，常非单纯 lr。
2. SwiGLU 作用？门控稳定信息流、提升有效秩，代价是参数翻倍。
3. 为何输出投影近零初始化？防首步大更新导致激活饱和与 spike。
4. 稳定训练靠什么组合？Pre-LN + RMSNorm + 残差缩放 + GLU + warmup 协同。

QK-Norm 与 μP 把稳定与「宽度可迁移」结合，使窄模型上调出的配置直接用于宽模型，大幅降低大模型调参成本。混合激活搜索（如 SwiGLU vs GeGLU）在稳定性与算力间权衡。可观测上，训练初期「各层激活方差曲线 / 梯度范数曲线」是定位不稳根因的标准手段，优于盲目降 lr。

## 九、演进与趋势

QK-Norm（对 Q、K 先归一化）、μP（最大更新参数化使 lr 跨宽度可迁移）、深度缩放初始化（DeepNorm）进一步提升超深稳定；混合激活搜索与「初始化 + 归一化 + 优化器」联合理论正在完善。趋势是把稳定设计从经验配方变为可推导的参数化。

稳定靠组合：Pre-LN + RMSNorm + 残差缩放 + GLU + 近零输出初始化 + warmup。
缺任一都可能数百步后 spike，别只降 lr 掩盖。
诊断看各层激活方差与梯度范数曲线，定位不稳根因。
QK-Norm、μP 把稳定与宽度可迁移结合，降调参成本。
训练初期曲线是上线前必查，而非事后补救。
loss spike 常源于初始化/归一化/注意力饱和，非单纯 lr。
SwiGLU 门控稳信息流、提有效秩，代价参数翻倍。
输出投影近零初始化防首步大更新炸裂。
ResNet 式残差让深层方差不简单连乘。
归一化位置（Pre/Post）决定梯度流，见相关章节。
激活选择影响方差漂移，GLU 比 ReLU 更稳。
warmup 对齐初始化尺度与 lr，防早期发散。
可观测是定位 spike 的根本，而非盲目调参。
大模型靠组合方案而非单点修补获得稳定。

## 十、小结

训练稳定性是初始化、归一化、激活与优化的系统结果，非单点问题。大模型依赖 Pre-LN + GLU + RMSNorm + 残差缩放的组合，并以 warmup 对齐初始化尺度。理解各组件对信号方差的影响，是稳定训练超深模型的前提。
