# 交叉熵与标签平滑

> 对应 d2l-zh；Szegedy et al., *Rethinking Inception*, 2015（label smoothing）；Pereyra et al., *Confidence Penalty*, 2017。

## 一、背景与挑战

标准 one-hot CE 鼓励模型对正确类输出概率 1、其余 0，易导致过自信与过拟合。

## 二、核心原理

**标签平滑（Label Smoothing）**将硬标签 `y` 软化：
```
ỹ_c = (1-ε)·1{c=y} + ε/K
```
即把 ε 概率均匀分给所有类，抑制过度自信、提升校准与泛化（Szegedy et al., 2015）。

## 三、数学形式

平滑后 CE：`L = - Σ_c ỹ_c log p_c`，K 为类数。

## 四、代码实现

```python
criterion = nn.CrossEntropyLoss(label_smoothing=0.1)
```

## 五、关键要点

- 平滑系数 ε 常取 0.1。
- 自蒸馏也可视作一种软标签。
- 在知识蒸馏中教师软标签提供更多信息。

## 六、与其他对比

- one-hot CE 过自信；平滑更校准。
- 温度 softmax（蒸馏）也是软标签思想。

## 七、常见误区

- 平滑总有益——少类任务可能损边际。

## 八、与开源书对应

- d2l-zh: https://github.com/d2l-ai/d2l-zh
- vaswani 等《Attention Is All You Need》用平滑 0.1。
