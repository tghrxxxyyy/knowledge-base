# 损失函数总览

> 对应 d2l-zh「深度学习计算」章；Goodfellow《Deep Learning》第 5 章。

## 一、背景与挑战

损失函数定义「什么是好预测」，是模型优化的目标；选错损失，再强架构也学偏。

## 二、核心原理

按任务分：回归用距离类（MSE/MAE），分类用概率类（CE/focal），生成用重构/对抗，排序用对比/度量。大模型预训练核心损失是**交叉熵**（next-token prediction）。

## 三、数学形式

分类交叉熵：
```
L = - Σ_c y_c log p_c,  y 为 one-hot 标签
```

## 四、代码实现

```python
import torch.nn as nn
criterion = nn.CrossEntropyLoss()  # 内部含 log_softmax
loss = criterion(logits, target)
```

## 五、关键要点

- 损失须可微（除极个别）。
- 标签平滑、focal 等是 CE 的稳健变体。
- 多任务需加权组合多个损失。

## 六、与其他对比

| 任务 | 常用损失 |
|------|----------|
| 分类 | CE / focal |
| 回归 | MSE / MAE |
| 生成 | BCE / 对抗 |

## 七、常见误区

- CE 要求 logits 未过 softmax——`CrossEntropyLoss` 自带。
