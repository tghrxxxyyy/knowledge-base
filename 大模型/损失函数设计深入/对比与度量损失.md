# 对比与度量损失

> 见「对比学习深入/对比损失变体」与「嵌入几何深入/度量学习几何」；Schroff et al., *Triplet*, 2015。

## 一、背景与挑战

分类 CE 不约束嵌入空间几何；度量损失直接优化「相似近、不相似远」。

## 二、核心原理

- **Triplet**：`L = max(0, d(a,p) - d(a,n) + m)`，推远锚-负、拉近锚-正。
- **InfoNCE / NT-Xent**：对比式，见对比学习章。
- **Circle Loss**：统一相似度视角，更灵活。

## 三、数学形式

Triplet margin loss 见上；InfoNCE 见自监督章。

## 四、代码实现

```python
triplet = nn.TripletMarginLoss(margin=0.3)
loss = triplet(anc, pos, neg)
```

## 五、关键要点

- 难负例挖掘决定对比损失效果。
- 温度 τ 控制分布锐度。

## 六、与其他对比

- CE 学决策边界；度量损失学几何。

## 七、常见误区

- 负例随机即可——难负例更重要。
