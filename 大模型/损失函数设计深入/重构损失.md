# 重构损失

> 对应 d2l-zh 生成模型章；Kingma & Welling, *VAE*, 2013；Zhang et al., *Perceptual Loss*, 2018。

## 一、背景与挑战

生成/自编码任务需衡量「重建得像不像」，不能只用像素差。

## 二、核心原理

- **MSE（L2）**：均值平方误差，平滑但易模糊。
- **MAE（L1）**：对离群更稳健，边界更锐。
- **BCE**：用于二值/概率重建（如 VAE 像素似然）。
- **Perceptual Loss**：在预训练特征空间比较，保语义与纹理（Johnson et al., 2016）。
- **SSIM**：结构相似性，贴合人眼。

## 三、数学形式

MSE: `L = (1/n) Σ (x_i - x̂_i)^2`。

## 四、代码实现

```python
mse = F.mse_loss(recon, x)
perc = F.mse_loss(vgg(recon), vgg(x))
```

## 五、关键要点

- MSE 易模糊因最小化均值。
- 感知损失常组合像素损失使用。

## 六、与其他对比

- 像素损失保数值；感知损失保语义。

## 七、常见误区

- MSE 低=像——可能细节糊。
