# 结构化损失

> 对应 d2l-zh；Lafferty et al., *CRF*, 2001；任务序列标注与翻译常用。

## 一、背景与挑战

序列/图输出需考虑标签间依赖，逐点 CE 忽略结构。

## 二、核心原理

- **CRF（条件随机场）**：在序列顶层建模标签转移概率，全局归一化求最优序列。
- **CTC**：处理无对齐的序列到序列（语音/手写）。
- **结构化感知机 / hinge**：直接优化正确结构与次优结构的间隔。

## 三、数学形式

线性链 CRF 分数：
```
s(x,y) = Σ_t [emit(y_t) + trans(y_{t-1}, y_t)];  P(y|x) = softmax 全局
```

## 四、代码实现

```python
import torch.nn as nn
crf = nn.CRF(num_tags)  # 需 torchcrf 或自行实现
```

## 五、关键要点

- CRF 用维特比解码求最优路径。
- 训练需全局归一化（前向-后向）。

## 六、与其他对比

- 逐点 softmax 忽略转移；CRF 建模全局。

## 七、常见误区

- CRF 必好——数据少时可能过拟合转移。
