# 仿真环境与世界模型

> 对应 Hao et al., *Reasoning with Language Model is Planning with World Model (RAP)*, EMNLP 2023；Shridhar et al., *ALFWorld*, ICLR 2021。

## 一、背景与挑战

真实交互昂贵且有副作用，若能在「脑内」预演动作后果，就能在低成本下筛掉糟糕方案。
问题是语言模型作为世界模型不够精确，误差会在多步推演中累积，导致自信的错误预测。

## 二、核心原理

- 世界模型即状态转移预测器：给定状态描述与动作，预测下一状态与可能奖励，用于搜索时的前瞻。
- 与搜索结合：把语言模型同时当策略（提议动作）与世界模型（预测后果），用蒙特卡洛树搜索在推演空间里选优。
- 校准与截断：限制推演深度、对不确定分支要求真实验证，避免虚构状态污染决策。

## 三、数学形式

推演价值用回溯估计：$Q(s,a)=\mathbb E_{s'\sim \hat T(\cdot\mid s,a)}\big[r(s,a)+\gamma\max_{a'}Q(s',a')\big]$，$\hat T$ 由语言模型近似。

若单步状态预测误差为 $\epsilon$，深度 $d$ 的推演偏差在最坏情况下按 $O(d\epsilon)$ 甚至更快累积，故深度必须受限。

## 四、代码实现

```python
def rollout(llm, state, depth=3, branch=3):
    if depth == 0:
        return llm.value(state), []
    best = (-1e9, [])
    for a in llm.propose_actions(state, n=branch):
        s2 = llm.predict_next_state(state, a)      # 语言世界模型
        v, tail = rollout(llm, s2, depth - 1, branch)
        v += llm.step_reward(state, a)
        if v > best[0]:
            best = (v, [a] + tail)
    return best
```

## 五、与其他对比

- 与真实环境试错：预演零副作用、成本仅算力，但受世界模型精度限制；真实交互准确但慢且有风险。
- 与程序化仿真器：仿真器状态精确可回放，是首选；语言世界模型适用于难以形式化的开放域。

## 六、常见误区

- 无限深度推演：误差累积让深层估值失去意义，甚至不如浅层。
- 把预演结果当既成事实写入记忆，污染后续真实状态判断。
- 忽略仿真与真实的分布差异，仿真里成功的策略在真实环境失效。

## 八、面试题

- 语言模型当世界模型的主要风险？答：状态预测误差随深度累积且模型对自身错误无感知，导致自信的错误规划。
- 如何缓解仿真到真实的差距？答：限制推演深度、对关键分支做真实验证、在仿真中加入噪声与失败注入以提升鲁棒性。

## 九、演进

纯真实试错 → 程序化仿真环境 → 语言世界模型预演 → 搜索与世界模型结合（RAP）→ 混合真实验证的分层规划。

## 十、小结

世界模型让智能体在低成本空间里试错，但必须限深并用真实观测校正，否则误差会自我放大。
