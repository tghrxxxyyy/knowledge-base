# 视频时序建模

> 见「视频理解深入/视频理解总览」；3D CNN / 时序注意力。

## 一、背景与挑战

动作/事件跨帧，需捕捉时序依赖。

## 二、核心原理

- **3D CNN（I3D）**：卷积同时作用于时空。
- **时序注意力**：用 Transformer 在帧序列上做注意力（如 ViViT、TimeSformer）。
- **SlowFast**：双路（慢路径语义、快路径动作）。
时序聚合决定能否理解「顺序/因果」。

## 三、数学形式

TimeSformer：`Attention over space then time`（分轴注意力）。

## 四、代码实现

```python
# 帧序列过时空 Transformer
tok = patch_embed(frames); out = transformer(tok)
```

## 五、关键要点

- 分轴注意力降算力。
- 长视频需分段/记忆。

## 六、与其他对比

- 2D 每帧独立丢时序；3D/注意力保时序。

## 七、常见误区

- 取关键帧足够——动作顺序仍重要。
