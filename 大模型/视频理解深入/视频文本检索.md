# 视频文本检索

> 见「视频理解深入/视频理解总览」与「嵌入几何深入/嵌入检索几何」；视频-文本对齐。

## 一、背景与挑战

用自然语言搜视频片段，需跨模态对齐。

## 二、核心原理

把视频与文本编码到共享嵌入空间（类似 CLIP 但扩展到视频），训练用对比损失使相关视频-文本靠近。检索时文本嵌入近邻搜视频（可到片段级）。

## 三、数学形式

对比：`L = -log exp(s(v,t)/τ) / Σ exp(s(v,t')/τ)`。

## 四、代码实现

```python
v_emb = video_encoder(clips); t_emb = text_encoder(query)
idx = faiss.search(t_emb, v_emb)
```

## 五、关键要点

- 片段级检索更实用。
- 时序对齐是难点。
