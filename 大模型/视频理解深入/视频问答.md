# 视频问答 VideoQA

> 见「视频理解深入/视频理解总览」与「多模态」；视频对话。

## 一、背景与挑战

回答关于视频内容的问题，需时空定位+推理。

## 二、核心原理

VideoQA 把视频特征（帧/视频 token）与问题文本一起送入多模态模型，输出答案。难点在时空定位（哪帧哪区域）与多步推理（事件因果）。Video-LLM 直接视觉-语言对话。

## 三、关键要点

- 时空定位难。
- 长视频需检索相关片段再答。

## 四、代码实现

```python
ans = video_llm(frames, question)
```

## 五、与其他对比

- VQA（图像）无时序；VideoQA 含时序。

## 六、常见误区

- 只看首帧——漏事件。
