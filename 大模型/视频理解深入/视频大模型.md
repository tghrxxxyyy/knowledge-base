# 视频大模型

> 见「视频理解深入/视频理解总览」；统一视频-语言模型。

## 一、背景与挑战

让一个模型既懂视频又会对答、检索、描述。

## 二、核心原理

Video-LLM：视觉编码器（ ViT/视频编码器）将视频转为 token，与文本 token 拼接进 LLM，统一做理解/生成/对话。训练分阶段：对齐视觉-语言、指令微调、视频对话数据。

## 三、关键要点

- token 压缩降低序列长度。
- 需大量视频-文本对。

## 四、代码实现

```python
v_tok = video_proj(video_encoder(frames))
out = llm(inputs_embeds=cat(text_tok, v_tok))
```

## 五、与其他对比

- 专用模型单任务；Video-LLM 通用。
