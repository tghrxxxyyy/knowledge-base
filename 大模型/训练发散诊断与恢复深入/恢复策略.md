# 训练发散的恢复策略

> 对应 训练工程实践（checkpoint 回退、LR reset）；与梯度裁剪/溢出检测 协同。

## 一、背景与挑战

一旦确认发散，需恢复而非从头重训：回退到最近健康检查点、跳过坏批、降 LR 或重初始化问题层。

策略要自动化，减少人工介入。

## 二、核心原理

保存周期检查点；检测异常时载入上一检查点，apply 缓解（降 LR、跳过当前批、收紧裁剪），再续训。

若反复发散，需排查数据/初始化/混合精度配置，而非仅靠回退。

## 三、数学形式

恢复：从 $\theta_{ckpt}$ 重启，设 $\eta\leftarrow\eta\cdot\rho\ (\rho<1)$ 或裁剪阈值 $c\leftarrow c/2$。

## 四、代码实现

```python
if diverged:
    load_checkpoint(model, opt, last_good)
    for g in opt.param_groups:
        g["lr"] *= 0.5
```

## 五、与其他对比

- 与 梯度裁剪 衔接，回退同时收紧裁剪。
- 与 混合精度溢出检测深入 衔接，溢出后降缩放并回退。
- 与 损失突刺 呼应，自愈失败才回退。

## 六、常见误区

- 回退不降 LR，同样错误重复发生。
- 检查点过稀，回退丢大量进度。
- 只回退不查根因，反复发散。

## 八、面试题

- 发散后如何恢复？答：回退最近检查点 + 降 LR/收紧裁剪 + 跳坏批，并查根因。
- 为何回退要降 LR？答：原 LR 在当前状态越界，降低才跳出发散区。

## 九、演进

人工重启 → 自动回退 → 回退+自适应缓解。

## 十、小结

恢复靠检查点回退加参数缓解，自动化可大幅减少重训成本。
