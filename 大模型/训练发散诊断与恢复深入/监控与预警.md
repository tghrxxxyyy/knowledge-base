# 训练监控与预警体系

> 对应 训练可观测性（logging、W&B 等）；与前述各诊断信号 集成。

## 一、背景与挑战

单点监控易漏。需把 loss、梯度、权重、LR、数值有限性统一采集，形成可预警的仪表盘。

目标是“在 NaN 前若干步就预警”。

## 二、核心原理

集中日志：每步记录标量（loss、gnorm、lr、是否 finite），按滑动窗口算基线；超阈值发报警并可自动干预。

对混合精度额外记缩放因子与 amax，捕捉接近溢界。

## 三、数学形式

预警：若连续 $k$ 步 $z_t>K$（z 为标准分）或 finite=False，触发告警/干预。

## 四、代码实现

```python
log = {"loss": loss.item(), "gnorm": gn, "lr": lr, "finite": finite}
wandb.log(log); 
if not finite: alert_and_rollback()
```

## 五、与其他对比

- 与 发散诊断总览 衔接，本篇是集成层。
- 与 梯度范数监控 / 损失突刺 互补，汇总各信号。
- 与 混合精度溢出检测深入 衔接，记缩放/amax。

## 六、常见误区

- 记太多无效标量，淹没关键信号。
- 阈值不随阶段校准，误报疲劳。
- 有报警无自动干预，仍靠人盯。

## 八、面试题

- 预警体系应包含哪些信号？答：loss、gnorm、lr、finite，及混合精度的缩放/amax。
- 为何要滑动基线？答：训练各阶段量级不同，相对基线才能稳定识别异常。

## 九、演进

print 日志 → 集中仪表盘 → 自动预警+干预。

## 十、小结

监控预警把分散信号汇聚，实现 NaN 前的主动干预。
