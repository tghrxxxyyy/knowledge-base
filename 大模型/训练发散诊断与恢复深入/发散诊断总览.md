# 训练发散诊断总览

> 对应 训练稳定性工程实践；与梯度裁剪（Pascanu13）、混合精度溢出检测 衔接。

## 一、背景与挑战

训练发散表现为 loss 突刺、梯度 NaN/Inf、权重变为非有限。及时诊断可在污染扩散前干预。

诊断需覆盖前向（loss/激活）、反向（梯度范数/有限性）、参数（权重范数）三层信号。

## 二、核心原理

建立监控：每步记录 loss、梯度总范数、梯度有限性、学习率；异常（NaN 或范数跳涨若干数量级）即触发报警或回退。

区分“软发散”（loss 缓慢漂移）与“硬发散”（NaN）。

## 三、数学形式

异常判据：$\neg\mathrm{isfinite}(\nabla L)$ 或 $\|\nabla L\|_2>\tau_{hist}\cdot 10^k$（$k$ 为历史倍数阈值）。

## 四、代码实现

```python
finite = torch.isfinite(loss).all()
gnorm = grad_norm(model)
if not finite or gnorm > threshold:
    print("DIVERGENCE at step", step); raise SystemExit
```

## 五、与其他对比

- 与 梯度爆炸机理 衔接，爆炸是发散典型前兆。
- 与 混合精度溢出检测深入 互补，溢出即硬发散。
- 与 优化器状态数值误差深入 相关，状态误差累积也可致发散。

## 六、常见误区

- 只在 epoch 末检查，错误已扩散。
- 把正常 loss 波动误判为发散。
- 忽略 NaN 的静默传播（0*Inf→NaN）。

## 八、面试题

- 发散有哪些信号？答：loss 突刺、梯度 NaN/Inf、权重范数爆炸。
- 为何要分层监控？答：前向/反向/参数各自先坏，分层定位更快。

## 九、演进

无监控 → 末步检查 → 逐步多层监控 + 自动回退。

## 十、小结

发散诊断靠逐步多层信号，早期拦截避免权重污染。
