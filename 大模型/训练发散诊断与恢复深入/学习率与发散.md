# 学习率与发散关系

> 对应 LR 稳定性（如 LR range test, Smith, 2018）；warmup 实践（Vaswani17）。

## 一、背景与挑战

学习率是发散最常见的人为诱因：过大使更新越过损失谷底、震荡发散；过小则训练停滞但安全。

理解“稳定 LR 上界”对选参至关重要。

## 二、核心原理

稳定 LR 上界与梯度幅值、损失曲率相关：过大时一步更新使 loss 不降反升。warmup 与衰减把 LR 控制在稳定区。

经验：稳定峰值 LR 随 batch size 近似线性缩放（linear scaling rule）。

## 三、数学形式

粗略稳定条件：$\eta<\frac{2}{\lambda_{max}(\nabla^2 L)}$（$\lambda_{max}$ 为最大曲率）；过大即发散。

## 四、代码实现

```python
# LR range test：线性升 LR 观察 loss 最低点
for lr in torch.linspace(1e-7, 1e-2, 100):
    set_lr(opt, lr); step(); record(loss)
```

## 五、与其他对比

- 与 优化器状态数值误差深入 衔接，LR 放大状态误差。
- 与 梯度爆炸机理 互补，大 LR 加剧爆炸。
- 与 损失突刺 衔接，LR 瞬态致 spike。

## 六、常见误区

- 盲目套用别处 LR，忽略本任务曲率/批量。
- 无 warmup 直接峰值 LR，初期发散。
- 以为 LR 越小越稳（过小仅停滞非发散，但浪费）。

## 八、面试题

- 为何 LR 过大会发散？答：更新步长超过损失谷底，loss 不降反升，震荡发散。
- 如何定稳定 LR？答：LR range test 找 loss 最低区间，warmup 平滑进入。

## 九、演进

固定 LR → range test → warmup+调度。

## 十、小结

学习率决定更新步长是否越界，warmup 与 range test 是防发散的调度基础。
