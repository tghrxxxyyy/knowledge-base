# 梯度范数监控

> 对应 梯度裁剪（Pascanu13）；训练可观测性实践。

## 一、背景与挑战

梯度范数是最直接的数值健康指标：突涨预示爆炸、趋零预示消失。监控其分布可早于 loss 发现问题。

配合裁剪，可把范数控制在安全带内。

## 二、核心原理

逐参数组统计梯度总范数，绘制随时间曲线；对异常跳涨设阈值并报警或自动裁剪。

也监控各层梯度比（首层/末层），定位消失发生在哪段。

## 三、数学形式

$g_{tot}=\sqrt{\sum_i\|g_i\|_2^2}$；相对历史 $r=g_{tot}/\mathrm{median}(g_{hist})$；$|r|>10^k$ 异常。

## 四、代码实现

total = torch.norm(torch.stack([p.grad.norm() for p in model.parameters()]))
torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)

## 五、与其他对比

- 与 梯度爆炸机理 衔接，范数监控即其实时度量。
- 与 梯度裁剪 互补，监控驱动裁剪阈值。
- 与 发散诊断总览 呼应，范数是核心信号。

## 六、常见误区

- 只监控末层，漏掉前层消失。
- 阈值固定不随训练阶段调整（初期本就大）。
- 用范数而不是相对变化，误报常态波动。

## 八、面试题

- 梯度范数监控看什么？答：总范数趋势与层间比，早于 loss 发现爆炸/消失。
- 为何用相对而非绝对值？答：训练各阶段范数量级不同，相对变化才反映异常。

## 九、演进

末步检查 → 总范数曲线 → 分层 + 相对阈值。

## 十、小结

梯度范数监控以实时量度捕捉爆炸/消失，是发散预警的第一线。
