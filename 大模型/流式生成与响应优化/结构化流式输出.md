# 结构化流式输出

> 见「提示工程深入/结构化输出与约束」与「流式生成与响应优化/流式生成原理」。

## 一、背景与挑战

流式返回 JSON/表格需保证最终可解析，且边流边校验。

## 二、核心原理

用流式 JSON 解析器（如 ijson）增量解析；或用约束解码（grammar-constrained）保证 token 符合 schema。

## 三、代码实现

```python
parser = ijson.parse(token_stream)
for prefix, event, value in parser: accumulate(prefix, value)
```

## 四、关键要点

- 约束解码（如 outlines）边生成边保证合法。
- 前端可逐步填表。

## 五、与其他对比

- 普通流式给文本；结构化需 schema 保证。

## 六、常见误区

- 流式 JSON 不用解析器——易半截报错。

## 七、与开源书对应

- outlines: https://github.com/dottxt-ai/outlines
- llm-universe: https://github.com/datawhalechina/llm-universe

## 十、小结
