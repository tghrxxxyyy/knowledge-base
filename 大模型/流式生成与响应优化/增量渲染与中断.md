# 增量渲染与中断

> 见「流式生成与响应优化/流式生成原理」。

## 一、背景与挑战

前端需边收边渲染，并支持用户中途取消。

## 二、核心原理

客户端按 chunk 追加 DOM，维护光标；取消时发信号，服务端停止生成释放资源。

## 三、代码实现

```javascript
const es = new EventSource("/stream"); es.onmessage = e => box.append(e.data);
```

## 四、关键要点

- 取消要传播到推理端。
- 需处理乱序/重连。

## 五、与其他对比

- 整段渲染简单但卡；增量复杂但顺。

## 六、常见误区

- 前端停了后端就停——需显式取消。

## 七、与开源书对应

- llm-universe: https://github.com/datawhalechina/llm-universe
- SSE 规范。
