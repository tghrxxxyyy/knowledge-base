# 流式生成原理

> 对应 llm-universe 部署章与 vLLM/推理优化。

## 一、背景与挑战

用户等待整段生成体验差，需逐 token 流式返回（类似打字机）。

## 二、核心原理

推理循环每产生一个 token 即推送到客户端（SSE/WebSocket），前端增量渲染。服务端仍需完整前向，只是输出分段。

## 三、代码实现

```python
def stream(prompt):
    for tok in model.generate(prompt, stream=True):
        yield tok
```

## 四、关键要点

- 首 token 延迟（TTFT）影响体感。
- 需处理断连与取消。

## 五、与其他对比

- 非流式简单但卡顿；流式体验好但需协议支持。

## 六、常见误区

- 流式更快——总耗时不变，仅体感好。
