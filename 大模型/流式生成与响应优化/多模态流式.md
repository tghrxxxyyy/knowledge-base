# 多模态流式

> 见「多模态深入」与「流式生成与响应优化/流式生成原理」。

## 一、背景与挑战

图文/语音助手需边理解边回应，甚至实时语音流。

## 二、核心原理

音频流经 ASR 转文本（或端到端语音模型），增量理解并生成，TTS 再流式播报，形成全双工体验。

## 三、关键要点

- 语音打断（barge-in）需检测。
- 视觉帧可抽帧流式理解。

## 四、代码实现

```python
for frame in audio_stream: text = asr(frame); if should_reply(text): speak(llm(text))
```

## 五、与其他对比

- 文本流简单；多模态流需同步多通道。

## 六、常见误区

- 多模态=串行处理——实时需管道并行。

## 七、与开源书对应

- llm-universe 多模态: https://github.com/datawhalechina/llm-universe
- Whisper 流式。

## 八、面试题

- 实时语音助手如何支持打断？

## 九、演进

文本流 → 语音流 → 全双工多模态。

## 十、小结

多模态流式是「自然交互」的终局体验。
