# 激活重计算 Checkpointing

> 见「梯度累积重计算深入/梯度累积总览」；用算力换显存。

## 一、背景与挑战

反向需前向激活，全存显存爆。

## 二、核心原理

**Gradient Checkpointing（激活重计算）**：前向不保存全部激活，只在若干「检查点」层存激活；反向到该段时重新前向计算中间激活。牺牲约 33% 算力，显存从 O(N) 降到 O(√N) 规模，使超大模型可训。

## 三、数学形式

显存 ≈ 检查点层数相关，而非全部层。

## 四、代码实现

```python
from torch.utils.checkpoint import checkpoint
h = checkpoint(block, h)   # 不存中间激活
```

## 五、关键要点

- 典型换 30% 速度换数倍显存。
- 与流水线并行互补。

## 六、与其他对比

- 全存快但爆；重算省但慢。

## 七、常见误区

- 重计算免费——有算力代价。
