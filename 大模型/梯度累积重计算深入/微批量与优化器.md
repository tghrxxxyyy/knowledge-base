# 微批量与优化器状态

> 见「梯度累积重计算深入/梯度累积总览」与「优化理论深入」；优化器状态显存。

## 一、背景与挑战

Adam 优化器状态（m,v）是显存大户。

## 二、核心原理

Adam 每参数存 fp32 主权重 + m + v（约 12-16 字节/参数）；SGD 仅 8 字节。ZeRO 把优化器状态分片到各卡省显存（见分布式训练）。选择轻量优化器（如 8-bit Adam、SGD）也可降显存。

## 三、数学形式

Adam 状态 ≈ `4×fp32 + 2×(fp32 m,v)` 每参数。

## 四、代码实现

```python
opt = bnb.optim.Adam8bit(params, lr=2e-5)   # 8-bit 优化器
```

## 五、关键要点

- 优化器状态常占总显存一半。
- 分片/offload 解此瓶颈。

## 六、与其他对比

- SGD 省；Adam 贵但好用。

## 七、常见误区

- 只管权重——优化器状态更占。
