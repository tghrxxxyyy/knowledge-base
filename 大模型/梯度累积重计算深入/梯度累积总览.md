# 梯度累积总览

> 对应 d2l-zh 与「分布式训练」；小显存跑大 batch。

## 一、背景与挑战

显存装不下目标 batch，但大 batch 训练更稳。

## 二、核心原理

**梯度累积**：把大 batch 拆成多个 micro-batch，逐次前向反向，梯度累加到一定步数再统一更新。等效大 batch 但显存仅按 micro-batch 占。公式上 `effective_batch = micro × accum_steps`。

## 三、数学形式

`g = Σ_{i=1}^{k} g_i`，每 k 步 `θ -= η g`。

## 四、代码实现

```python
for i, (x,y) in enumerate(loader):
    loss = model(x,y)/k; loss.backward()
    if (i+1)%k==0: opt.step(); opt.zero_grad()
```

## 五、关键要点

- 学习率应按有效 batch 调。
- BN 统计仍按 micro batch（略偏）。

## 六、与其他对比

- 大 batch 显存爆；累积显存省。

## 七、常见误区

- 累积=大 batch 完全等价——BN 统计有差。
