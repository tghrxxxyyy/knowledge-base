# 显存优化组合

> 见「梯度累积重计算深入/梯度累积总览」与「模型量化部署实战」；训练期显存。

## 一、背景与挑战

大模型训练显存由权重+梯度+优化器状态+激活构成（见 ZeRO）。

## 二、核心原理

组合拳：1) 混合精度（减半权重/梯度）；2) 激活重计算（降激活）；3) 梯度累积（降 batch 显存）；4) 优化器状态分片（ZeRO，见分布式训练）；5) CPU offload（卸载到内存）。依瓶颈选组合。

## 三、关键要点

- 先定位瓶颈（权重/激活/优化器）。
- 组合优于单用。
