# 请求调度与排队

> 对应推理调度（FCFS/优先级/SJF）；服务队列理论。

## 一、背景与挑战

请求到达不均，需调度策略平衡公平、延迟与吞吐。

## 二、核心原理

策略：FCFS（公平）、优先级（VIP 先）、SJF（短请求先降平均等待）、抢占（长请求让位）。

## 三、数学形式

平均等待 $W = \frac{\lambda \bar{x}^2}{2(1-\rho)}$（M/M/1，$\rho=\lambda/\mu$ 利用率）。

## 四、代码实现

```python
q = PriorityQueue()
q.put((priority(req), req))     # 优先级调度
```

## 五、与其他对比

- 与 连续批处理深入（组批）互补。
- 与 API网关与限流策略深入（入口控流）衔接。

## 六、常见误区

- 纯 FCFS 长尾拖垮 P99。
- 优先级饥饿低优请求。

## 八、面试题

- SJF 利弊？答：降平均等待，但长请求易饿死，需老化/优先级配合。

## 九、演进

FCFS → 优先级 → 抢占+老化。

## 十、小结

调度策略权衡公平与延迟，常结合批处理。
