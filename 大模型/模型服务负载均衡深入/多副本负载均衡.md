# 多副本负载均衡

> 对应 Triton 模型集成/负载均衡；K8s 服务路由。

## 一、背景与挑战

单实例吞吐有限，需多副本横向扩展并均匀分配请求。

## 二、核心原理

入口用轮询/最少连接/一致性哈希分发；GPU 副本间无状态（KV 不共享），按负载选目标。

## 三、数学形式

均衡度 $\sigma = \sqrt{\frac1n\sum (L_i-\bar L)^2}$；越小越均；最少连接选 $\min_j C_j$。

## 四、代码实现

```python
target = min(replicas, key=lambda r: r.inflight)   # 最少连接
```

## 五、与其他对比

- 与 API网关与限流策略深入（网关层分发）衔接。
- 与 模型服务负载均衡深入 总览互补。

## 六、常见误区

- 轮询忽略请求长度差异致不均。
- 副本 KV 不共享却用哈希黏滞（没必要）。
