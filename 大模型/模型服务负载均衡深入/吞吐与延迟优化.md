# 吞吐与延迟优化

> 对应 LLM 服务优化（batching/KV/内核）；vLLM 实测。

## 一、背景与挑战

吞吐（总 token/s）与延迟（首 token TTFT、逐 token ITL）常互相掣肘。

## 二、核心原理

提吞吐：大批量+连续批+内核融合；降延迟：限批大小、前缀缓存、流式输出。

## 三、数学形式

TTFT $\approx t_{prefill} + t_{queue}$；ITL $\approx t_{decode}/B$（批大小 B 越大 ITL 越高）。

## 四、代码实现

```python
# 流式降感知延迟
for tok in llm.generate(stream=True):
    yield tok
```

## 五、与其他对比

- 与 推理缓存与命中优化深入（降 prefill）衔接。
- 与 成本优化与资源调度深入 共享指标。

## 六、常见误区

- 只追吞吐牺牲 ITL 致卡顿。
- 批过大致 TTFT 飙升。

## 八、面试题

- 吞吐与延迟矛盾点？答：大批量提吞吐但增排队与 ITL，需按场景折中。

## 九、演进

单请求 → 批处理 → 连续批+缓存 → 分级 SLA。

## 十、小结

吞吐与延迟需按 SLA 平衡，缓存与批处理是关键杠杆。
