# 选择性上下文（Selective Context）

> 对应 Xu et al., *Selective Context: Enhancing Abilities of LLMs*, 2023。

## 一、背景与挑战

上下文含冗余/无关单元，拖累推理且占 token；按信息量筛选单元。

## 二、核心原理

把文本切成单元（词/句），用小模型算自信息，删低信息单元，保留高信息骨架，再喂给 LLM。

## 三、数学形式

单元信息 $I(u) = -\log P(u | \text{ctx})$；保留集 $S=\{u: I(u)>\tau\}$，$\tau$ 控压缩率。

## 四、代码实现

```python
scores = [-logp(u) for u in units]          # 自信息
keep = [u for u,s in zip(units,scores) if s > thr]
```

## 五、与其他对比

- 与 LLMLingua 同用自信息，但更粗（不重写只删）。
- 与 检索重排序深入（选相关块）互补。

## 六、常见误区

- 单元切分不当致语义割裂。
- 阈值全局固定忽视任务差异。

## 八、面试题

- 问：为何按自信息删？答：低自信息单元可预测、冗余，删后对任务影响小。

## 九、演进

句删 → 单元级 → 任务感知筛选。

## 十、小结

选择性上下文以自信息筛冗余，简单有效提升性价比。
