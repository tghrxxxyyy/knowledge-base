# 检索式上下文压缩

> 对应 Liu et al., *RECOMP*, 2023（压缩器+摘要器）；与 检索重排序深入 衔接。

## 一、背景与挑战

RAG 取多文档整段进上下文，冗长；只取必要证据更优。

## 二、核心原理

RECOMP 训“抽取式”压缩器（选关键句）或“生成式”摘要器（生成证据摘要），把多文档压成紧凑证据集喂给 LLM。

## 三、数学形式

抽取：选句集 $E\subset D$ 使 $\text{ans}(E)\approx\text{ans}(D)$；摘要：$E=\text{Gen}(D)$ 固定长度。

## 四、代码实现

```python
ev = recomp.compress(documents, question, max_tokens=300)
answer = llm(question, ev)
```

## 五、与其他对比

- 与 提示压缩深入 总览（通用压缩）互补，这里是检索专用。
- 与 混合检索深入（取哪些文档）衔接。

## 六、常见误区

- 压缩器只学似然忽略下游正确性。
- 摘要引入幻觉（生成式）。

## 八、面试题

- 问：RECOMP 两类压缩？答：抽取关键句（可溯）与生成摘要（更短但可能幻觉）。

## 九、演进

整文档 → 抽取式 → 摘要式 → 端到端。

## 十、小结

检索式压缩把多文档压成证据集，提效且常提准确。
