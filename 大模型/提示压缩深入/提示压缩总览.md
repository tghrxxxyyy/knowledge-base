# 提示压缩总览

> 对应 Jiang et al., *LLMLingua*, 2023；Xu et al., *Selective Context*, 2023。

## 一、背景与挑战

长上下文（RAG/多文档）塞满 prompt，浪费 token 与延迟；压缩在保任务效下缩短提示。

## 二、核心原理

两类：1) 粗粒度删冗余句（Self-Information 低则删）；2) 细粒度用小模型重写为更短语（LLMLingua）。压缩比常 2-5x 而无损效。

## 三、数学形式

句子重要性 $I(s)=-\log P(s)$（自信息高更保留）；目标 $\min |C'|\ s.t.\ \text{perf}(C')\approx\text{perf}(C)$。

## 四、代码实现

```python
from llmlingua import PromptCompressor
c = PromptCompressor(model="microsoft/llmlingua-2")
out = c.compress_prompt(prompt, target_token=500)
```

## 五、与其他对比

- 与 长文档切分深入（选哪些块）互补，压缩进一步缩已选块。
- 与 上下文窗口扩展深入（扩窗口 vs 缩提示）对照。

## 六、常见误区

- 误压缩关键约束句致任务失败。
- 压缩率过高致信息丢、答案错。

## 八、面试题

- 问：压缩为何能无损？答：自然语言中冗余多，低自信息片段对任务贡献小。

## 九、演进

截断 → 句级过滤 → 细粒度重写（LLMLingua-2）。

## 十、小结

提示压缩以冗余消除换 token/延迟，是长上下文经济关键。
