# 生成对抗网络

> 见「生成式模型深入/生成模型总览」。

## 一、背景与挑战

如何生成逼真样本？GAN 用博弈。

## 二、核心原理

生成器造假、判别器辨真，minimax 博弈达纳什均衡；训练需平衡防模式崩塌。

## 三、数学形式

```
min_G max_D E[log D(x)] + E[log(1-D(G(z)))]
```

## 四、代码实现

```python
loss_d = bce(D(x),1) + bce(D(G(z)),0)
loss_g = bce(D(G(z)),1)
```

## 五、关键要点

- 模式崩塌是顽疾。
- 训练不稳定。

## 六、与其他对比

- VAE 稳模糊；GAN 锐利不稳。

## 七、常见误区

- GAN 易训——最难训之一。
