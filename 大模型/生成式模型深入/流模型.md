## 二、核心原理

归一化流用一系列可逆变换把简单分布映成复杂分布，似然可精确计算。

## 三、数学形式

```
log p(x) = log p_z(f(x)) + log |det J_f(x)|
```

## 四、代码实现

```python
z, logdet = coupling(x); nll = -logp_z(z) - logdet
```

## 五、关键要点

- 可逆且行列式易算（耦合层）。
- 大模型少见。
