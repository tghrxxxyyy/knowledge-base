# 扩散模型

> 见「生成式模型深入/生成模型总览」与「多模态生成模型深入」。

## 一、背景与挑战

如何在高维生成高质量样本？

## 二、核心原理

前向逐步加噪至纯噪声，反向网络学去噪；采样时从噪声迭代去噪得样本（DDPM）。

## 三、数学形式

```
x_t = √(ᾱ_t) x_0 + √(1-ᾱ_t) ε
```

训练预测噪声 ε_θ(x_t,t)。

## 四、代码实现

```python
noise = model(x_t, t); loss = mse(noise, eps)
```

## 五、关键要点

- 采样慢（多步）。
- 质量高、覆盖好。

## 六、与其他对比

- GAN 快但崩；扩散稳但慢。

## 七、常见误区

- 扩散只图像——也用于音频/视频。
