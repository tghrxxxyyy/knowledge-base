# 自回归生成

> 见「生成式模型深入/生成模型总览」与「自监督学习深入/自回归语言建模」。

## 一、背景与挑战

序列数据如何逐元素生成？

## 二、核心原理

按链式法则分解联合概率，逐 token 条件生成；LLM/PixelCNN 均此范式。

## 三、数学形式

```
P(x) = Π_t P(x_t | x_{<t})
```

## 四、代码实现

```python
for _ in range(L): tok = model(x).argmax(-1); x = cat(x, tok)
```

## 五、关键要点

- 可控但串行慢。
- 易暴露偏差。

## 六、与其他对比

- 扩散并行采样；AR 串行。

## 七、常见误区

- AR 仅文本——也用于图像像素。
