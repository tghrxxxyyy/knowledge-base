## 二、核心原理

VAE 把输入编码为潜变量分布，采样后解码；用 KL 约束潜空间接近标准正态，支持插值生成。

## 三、数学形式

见总览 ELBO。

## 四、代码实现

```python
z = mu + eps*std; recon = decoder(z); loss = recon_loss + kl(mu,std)
```

## 五、关键要点

- 重参数化使可训练。
- 生成偏模糊。

## 六、与其他对比

- GAN 锐但训练不稳；VAE 稳但糊。

## 七、常见误区

- VAE 生成清晰——常模糊。
