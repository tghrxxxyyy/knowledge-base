# 生成模型总览

> 对应 d2l-zh 与 Goodfellow, *GAN*, 2014；Kingma, *VAE*, 2013；Ho, *DDPM*, 2020。

## 一、背景与挑战

学习数据分布并采样新样本，是生成式 AI 基础。

## 二、核心原理

三大族：**VAE**（变分下界重构）、**GAN**（对抗博弈）、**扩散**（逐步去噪）、**自回归**（逐 token）。LLM 属自回归。

## 三、数学形式

VAE 证据下界：

```
ELBO = E_q[log p(x|z)] - KL(q(z|x) || p(z))
```

## 四、代码实现

```python
# 自回归生成
for _ in range(n): x = cat(x, model(x).argmax(-1))
```

## 五、关键要点

- 各模型权衡质量/多样/速度。
- LLM 是文本自回归代表。

## 六、与其他对比

| 模型 | 优势 |
|------|------|
| VAE | 稳 |
| GAN | 锐利 |
| 扩散 | 高质量 |
| AR | 可控 |

## 七、常见误区

- 生成模型=GAN——LLM 也是生成模型。
