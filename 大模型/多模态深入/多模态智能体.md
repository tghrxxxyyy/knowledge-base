# 多模态智能体

> 对应 LLaVA（Liu et al. 2023）、Visual Programming（Gupta & Kembhavi 2023）与 Toolformer（Schick et al. 2023）。多模态智能体把「看懂」与「行动」连起来。

## 一、背景与挑战

纯文本智能体只能处理符号世界的信息，但真实任务（看图排障、读表决策、操作 GUI、看监控视频告警）输入天然是多模态的。多模态智能体 = 多模态感知 + 语言推理 + 工具/动作执行。挑战在于：视觉信息经编码器压缩后细节损失；长视频/多图的状态难以在有限上下文里维护；视觉与文本的时间对齐困难；以及幻觉在多模态下更隐蔽（模型会「看见」不存在的物体）。

## 二、核心原理

典型架构是 **MLLM 骨干 + 工具集 + 控制器**：

1. **感知层**：视觉编码器（ViT/CLIP）把图像/视频帧编码成视觉 token，经投影层（MLP 或 Q-Former）对齐到 LLM 的嵌入空间。
2. **推理层**：LLM 接收「视觉 token + 文本指令」的混合序列，做链式推理。
3. **行动层**：输出结构化动作（调用 API、点击、检索、生成代码），执行结果回灌上下文形成闭环。

关键设计是 **视觉 token 预算**：一张 224×224 图经 ViT patch 16 得 $14\times14=196$ 个 patch；高分辨率需切图，token 数爆炸。常用 AnyRes / 动态切分把 token 控制在一两千内。

## 三、形式化与数学基础

视觉投影把视觉特征 $v\in\mathbb{R}^{d_v}$ 映射到语言空间 $d$：

$$z = W_2\,\sigma(W_1 v),\qquad W_1\in\mathbb{R}^{h\times d_v},\ W_2\in\mathbb{R}^{d\times h}$$

LLM 在拼接序列上自回归：

$$P(a_t\mid a_{<t}, z_{1:K}, q)=\text{softmax}(W\,h_t)$$

其中 $z_{1:K}$ 是 $K$ 个视觉 token，$q$ 是文本指令。智能体的目标是最大化任务回报而非似然：

$$\pi^*=\arg\max_\pi \mathbb{E}_{\tau\sim\pi}\Big[\sum_t r(s_t,a_t)\Big]$$

## 四、代码实现

把图像与工具调用串成一次请求（概念示例）：

```python
messages = [
    {"role": "user", "content": [
        {"type": "image", "image": "/data/dashboard.png"},
        {"type": "text", "text": "这个监控面板里哪一项指标异常？给出判断依据。"}
    ]}
]
# 模型返回结构化动作
action = llm.chat(messages, response_format={"type": "json_object"})
# {"metric": "p99_latency", "evidence": "曲线在 14:00 后从 80ms 跃升至 900ms"}
```

动作执行后把结果回灌，形成感知-推理-行动闭环：

```python
obs = run_tool(action["tool"], action["args"])
messages.append({"role": "tool", "content": obs})
final = llm.chat(messages)
```

## 五、与其他技术对比

| 方案 | 感知 | 推理 | 行动 | 适用 |
|------|------|------|------|------|
| 纯文本 Agent | 无 | 强 | 强 | 文档/API 流程 |
| 多模态 Agent | 有 | 强 | 强 | GUI/图表/监控 |
| 传统 CV 流水线 | 有 | 弱 | 固定 | 单一检测任务 |
| 端到端机器人模型 | 有 | 中 | 连续动作 | 具身操作 |

## 六、常见误区

- 认为「接个视觉编码器就是多模态智能体」：没有工具闭环与状态管理，只是看图说话。
- 忽视视觉 token 成本：高分辨率多图会瞬间吃满上下文。
- 不做视觉幻觉校验：模型对图中不存在的文字/物体同样自信。
- 把 OCR 结果直接信任：应保留原始图像区域坐标以便溯源。

## 九、演进与趋势

从「单图问答」走向「长视频 + 多图 + GUI 操作」；视觉 token 压缩（Perceiver/token merging）降低成本；OSWorld、WebArena 等真实环境基准成为评测主战场；端侧多模态（手机/眼镜）推动低延迟小模型。

## 十、小结

多模态智能体 = 视觉编码对齐 + 语言推理 + 工具闭环。工程关键是 token 预算、状态管理与幻觉校验；它是从「会聊天的模型」走向「能干活的系统」的关键形态。
