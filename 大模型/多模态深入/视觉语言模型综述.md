# 视觉语言模型综述 VLM

> 综合 CLIP / BLIP / LLaVA 等经典工作，建立多模态大模型认知框架。

## 一、核心概念

视觉语言模型(VLM)把图像与文本映射到统一语义空间，支持图文理解、视觉问答、图文生成等。两条主线：

- **双塔对齐(CLIP)**：图像编码器(ViT)与文本编码器分别编码，对比学习对齐。
- **多模态指令模型(LLaVA)**：用预训练 LLM + 视觉编码器 + 投影层，把图像特征投影进词嵌入空间，用语言模型统一处理。

## 二、架构范式

```
图像 --ViT--> 图像特征 --Projector--> 视觉token --拼接--> LLM
文本 -----------------------------------------------> LLM
```

视觉 token 当作「特殊词」接入 LLM 的词序列，实现统一生成。

## 三、关键要点

| 类型 | 代表 | 任务 |
|------|------|------|
| 对齐 | CLIP | 检索/分类 |
| 生成理解 | LLaVA | VQA/对话 |
| 扩散 | SD | 文生图 |
