# 扩散模型基础 Diffusion Models

> 对应 Ho et al.(DDPM, 2020) 与文生图基础。

## 一、核心概念

扩散模型通过「前向加噪 + 反向去噪」生成数据。前向过程逐步往数据加高斯噪声(固定马尔可夫链)，模型学习反向每一步去噪，从纯噪声恢复样本。

前向：

```
q(x_t | x_{t-1}) = N(x_t; √(1-β_t) x_{t-1}, β_t I)
```

反向(学习)：

```
p_θ(x_{t-1} | x_t) = N(x_{t-1}; μ_θ(x_t,t), Σ_θ)
```

训练目标简化为预测噪声 `ε`：

```
L = E_{t,x0,ε} [ ‖ε - ε_θ(x_t, t)‖² ]
```

## 二、关键要点

- 采样需多步迭代(慢)，加速用 DDIM/LCM。
- 引导(Classifier-free guidance)提升文本贴合度。
