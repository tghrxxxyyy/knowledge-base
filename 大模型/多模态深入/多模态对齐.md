# 多模态对齐

> 对应 CLIP（Radford et al. 2021）、BLIP-2（Li et al. 2023）与 LLaVA（Liu et al. 2023）。对齐决定多模态模型能否「看懂并说对」。

## 一、背景与挑战

视觉编码器与语言模型各自在单模态上预训练，二者的表示空间互不相通。多模态对齐的目标是让「一张猫的图」与「a cat」在模型内部靠近，从而使 LLM 能消费视觉信息。挑战：模态间粒度不匹配（图像 patch 是连续的、文本 token 是离散的）；对齐数据噪声大（网络图文对常常文不对图）；以及对齐后不能损害 LLM 原有的语言能力。

## 二、核心原理

三条主流路线：

1. **对比对齐（CLIP）**：双编码器分别编码图文，用 InfoNCE 拉近配对样本、推远非配对样本。
2. **生成式桥接（BLIP-2 Q-Former）**：用一组可学习的 query token 从冻结的视觉编码器里「提炼」信息，再送入冻结的 LLM。好处是两塔都冻结，训练便宜且保留原能力。
3. **投影对齐（LLaVA）**：最简单的可学习 MLP（两层）把视觉特征映射到 LLM 嵌入维度，端到端指令微调。

工程共识：**视觉塔与 LLM 先冻结、只训桥接层**，再视算力放开部分参数做指令微调。

## 三、形式化与数学基础

对比目标（batch 内 $N$ 对）：

$$\mathcal{L}_{\text{contrast}}=-\frac{1}{N}\sum_{i}\log\frac{\exp(\cos(v_i,t_i)/\tau)}{\sum_{j=1}^{N}\exp(\cos(v_i,t_j)/\tau)}$$

Q-Former 用交叉注意力从视觉特征 $V$ 提炼 $K$ 个 query：

$$Q' = \text{CrossAttn}(Q, V, V),\quad Q\in\mathbb{R}^{K\times d}$$

投影对齐（LLaVA）：

$$z = W_2\,\text{GELU}(W_1 v),\quad z\in\mathbb{R}^{d_{\text{llm}}}$$

## 四、代码实现

LLaVA 风格的两层 MLP 投影（概念实现）：

```python
import torch.nn as nn
class VisionProjector(nn.Module):
    def __init__(self, d_vit=1024, d_llm=4096, h=4096):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(d_vit, h), nn.GELU(),
            nn.Linear(h, d_llm),
        )
    def forward(self, v):      # v: [B, N_patch, d_vit]
        return self.net(v)     # [B, N_patch, d_llm]
```

训练时冻结视觉塔与 LLM，只更新投影层与（可选）LLM 的 LoRA。

## 五、与其他技术对比

| 方案 | 可训参数 | 效果 | 成本 |
|------|---------|------|------|
| CLIP 对比 | 双塔全训 | 检索强 | 高 |
| Q-Former | 桥接层 | 生成强 | 中 |
| MLP 投影 | 极小 | 指令跟随好 | 低 |
| 全量端到端 | 全部 | 上限高 | 很高 |

## 六、常见误区

- 对齐层越复杂越好：LLaVA 证明两层 MLP 配合好数据即可很强。
- 忽略数据质量：噪声图文对会直接导致幻觉。
- 训练时放开全部参数导致灾难性遗忘：应优先冻结 + 桥接。
- 只看检索指标：生成型任务更看重指令跟随与事实一致性。

## 九、演进与趋势

从「两塔 + 桥接」走向**单一统一骨干**（原生多模态预训练）；动态分辨率与 AnyRes 提升细节；对齐数据从网络爬取转向合成高质量描述；视频/音频对齐扩展到更多模态。

## 十、小结

多模态对齐的本质是让视觉表示进入 LLM 的语义空间。工程上最实用的是「冻结双塔 + 训桥接 + 指令微调」，成本可控且能保留原有能力。
