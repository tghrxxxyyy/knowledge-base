# 图文生成与理解

> 对应 Stable Diffusion（Rombach et al., CVPR 2022）、DALL·E 2（Ramesh et al. 2022）与 Imagen（Saharia et al. 2022）。理解与生成正在被统一建模。

## 一、背景与挑战

图文任务分两个方向：**理解**（图 → 文，如 VQA、图像描述）与**生成**（文 → 图，如文生图、编辑）。历史上两者模型割裂，近年被统一到「序列建模」或「扩散 + 条件」框架。挑战包括：文本与图像的语义鸿沟；生成的可控性（构图、风格、文字渲染）；以及评估困难（FID/CLIPScore 与人类偏好不完全一致）。

## 二、核心原理

**理解侧**：CLIP 用对比学习把图文对拉到同一空间：

$$\mathcal{L}=-\frac12\Big(\log\frac{e^{s_{ii}/\tau}}{\sum_j e^{s_{ij}/\tau}}+\log\frac{e^{s_{ii}/\tau}}{\sum_j e^{s_{ji}/\tau}}\Big)$$

**生成侧**：扩散模型先把图像加噪到纯高斯噪声，再学去噪：

$$x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon,\qquad \epsilon_\theta(x_t,t,c)\to\epsilon$$

其中 $c$ 是文本条件（来自 CLIP/T5 编码器）。Stable Diffusion 的关键创新是在 **VAE 压缩的潜空间**做扩散，而非像素空间，算力降低一个量级：

$$z = \mathcal{E}(x),\quad \text{去噪 } z,\quad \hat x = \mathcal{D}(z)$$

## 三、形式化与数学基础

训练目标（简化噪声预测损失）：

$$\mathcal{L}=\mathbb{E}_{x_0,\epsilon,t}\big[\|\epsilon-\epsilon_\theta(x_t,t,c)\|_2^2\big]$$

采样时从 $x_T\sim\mathcal{N}(0,I)$ 迭代去噪到 $x_0$。Classifier-free guidance 用空条件与文本条件的差放大条件信号：

$$\tilde\epsilon = \epsilon_\theta(x_t,t,\varnothing) + w\big(\epsilon_\theta(x_t,t,c)-\epsilon_\theta(x_t,t,\varnothing)\big)$$

$w$ 越大越贴合文本、越牺牲多样性。

## 四、代码实现

文生图的基本调用（伪代码，具体参数以所用库版本为准）：

```python
from diffusers import StableDiffusionPipeline
pipe = StableDiffusionPipeline.from_pretrained("runwayml/stable-diffusion-v1-5")
pipe = pipe.to("cuda")
image = pipe(
    prompt="a minimalist desk setup, soft morning light, product photography",
    negative_prompt="blurry, lowres, watermark",
    num_inference_steps=30,
    guidance_scale=7.5,
).images[0]
image.save("out.png")
```

## 五、与其他技术对比

| 范式 | 生成质量 | 速度 | 可控性 |
|------|---------|------|--------|
| GAN | 高（单域） | 快 | 弱 |
| VAE | 中 | 快 | 中 |
| 自回归（token） | 高 | 慢 | 强 |
| 扩散（潜空间） | 很高 | 中 | 强（ControlNet/LoRA） |

## 六、常见误区

- guidance_scale 越高越好：过高会过饱和、失真。
- 步数越多越好：30–50 步后收益递减。
- 认为 FID 低=人眼好看：需结合人工评测。
- 忽视负向提示：它能显著抑制常见瑕疵（多手指、水印感）。

## 九、演进与趋势

从 UNet 骨干走向 DiT（Diffusion Transformer）；从文生图到**统一理解与生成**的单一模型；可控生成（ControlNet、IP-Adapter、LoRA）成为生产标配；一步/少步蒸馏让实时生成成为可能。

## 十、小结

图文生成与理解正被统一到「条件扩散 + 对比对齐」的框架：理解靠 CLIP 类对齐，生成靠潜空间扩散加引导。工程落地的关键是步数/guidance 调优与可控插件。
