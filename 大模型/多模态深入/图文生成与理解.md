# 图文生成与理解

> 多模态任务的统一视角。

## 一、核心概念

- **图像理解→文本**：VLM(LLaVA) 看图问答、描述、OCR 推理。
- **文本→图像生成**：扩散模型(文生图)。
- **统一模型**：Emu/Fuyu 等尝试用单一模型处理多模态生成与理解。
- **视频/音频**：扩展模态对齐思路一致。

## 二、关键要点

| 方向 | 代表 |
|------|------|
| 图生文 | LLaVA/InternVL |
| 文生图 | SD/DALL·E |
| 文生视频 | Sora 类 |
