# 视频理解基础

> 对应 VideoMAE（Tong et al. 2022）、Timesformer（Bertasius et al. 2021）与 Video-LLaVA（Lin et al. 2023）。视频 = 空间 + 时间两个维度的建模。

## 一、背景与挑战

视频理解需在图像理解之上额外建模**时间维度**，任务涵盖动作识别、时序定位、视频问答、异常检测。相比图像，视频的挑战是：数据量爆炸（1 分钟 30fps ≈ 1800 帧）；时间冗余极高（相邻帧几乎相同）；长程依赖（一个动作跨数秒到数分钟）；以及标注成本远高于图像。

## 二、核心原理

主流范式有三：

1. **3D 卷积**（如 I3D）：把 2D 卷积核扩展到时空，直接学时空特征，参数与算力大。
2. **双流网络**：一路 RGB 帧学外观，一路光流学运动，后期融合，精度好但光流计算昂贵。
3. **时空注意力 / ViT 扩展**（Timesformer、ViViT）：把 ViT 的 patch 从二维扩到三维（$2\times16\times16$），或分离时间与空间注意力以省算力。

**VideoMAE** 用极高的掩码率（约 90%）做自监督预训练——因为视频时间冗余大，遮掉大部分像素后重建仍能学到语义，训练效率反而高。

## 三、形式化与数学基础

视频片段 $V\in\mathbb{R}^{T\times H\times W\times 3}$，切成时空 patch 后 token 数为：

$$N = \frac{T}{t_p}\times\frac{H}{h_p}\times\frac{W}{w_p}$$

分离注意力（Timesformer 的 divided attention）先时间后空间：

$$\text{Attn}_t = \text{softmax}\!\left(\frac{Q_tK_t^\top}{\sqrt d}\right)V_t,\qquad
\text{Attn}_s = \text{softmax}\!\left(\frac{Q_sK_s^\top}{\sqrt d}\right)V_s$$

相比联合注意力的 $O((N)^2)$，分离后复杂度降为 $O(N_t^2 + N_s^2)$。掩码自监督目标：

$$\mathcal{L}=\big\| V - f_\theta(\text{mask}(V))\big\|_2^2$$

## 四、代码实现

均匀抽帧喂给多模态模型（控制 token 预算）：

```python
import cv2
def sample_frames(path, n=8):
    cap = cv2.VideoCapture(path)
    total = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
    idxs = [int(i * total / n) for i in range(n)]
    frames = []
    for i in range(total):
        ok, f = cap.read()
        if ok and i in idxs:
            frames.append(cv2.cvtColor(f, cv2.COLOR_BGR2RGB))
    cap.release()
    return frames
```

把抽到的帧与问题一起送入模型；帧数越多越准但 token 越贵，通常 8–32 帧是性价比区间。

## 五、与其他技术对比

| 方法 | 时间建模 | 算力 | 长视频 |
|------|---------|------|--------|
| 2D CNN + 池化 | 弱 | 低 | 差 |
| 3D CNN | 强 | 高 | 差 |
| 双流（光流） | 强 | 很高 | 差 |
| 时空 ViT | 强 | 中高 | 受 token 限制 |
| 抽帧 + MLLM | 中 | 中 | 较好 |

## 六、常见误区

- 帧率越高越好：冗余帧徒增 token，8 帧常已够回答多数问题。
- 忽略时间顺序：把帧乱序输入会破坏动作识别。
- 认为长视频必须全量输入：应先用检索/关键帧定位再精读。
- 用图像指标（如单帧 top-1）衡量视频任务：应看时序定位与问答准确率。

## 九、演进与趋势

从「分类短视频」走向「长视频问答与叙事理解」；关键帧检索 + 记忆压缩成为长视频标配；视频生成与理解逐步统一到同一骨干；端侧实时视频理解推动高效架构。

## 十、小结

视频理解的核心是时间建模与 token 经济性的权衡。抽帧 + 多模态大模型是当前性价比最高的落地路径，长视频则依赖检索与记忆压缩。
