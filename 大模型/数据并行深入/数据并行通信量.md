# 数据并行通信量

> 对应通信分析；Patarasuk & Yuan, 2009。

## 一、背景与挑战

数据并行每步通信全部梯度，带宽成扩展瓶颈。

## 二、核心原理

每步 all-reduce 通信量正比于参数量；可通过通信压缩、梯度累积（少同步）、与计算重叠来降有效开销。

## 三、数学形式

每步通信 $C\approx 2\frac{K-1}{K}\cdot 2\phi\cdot 2$ 字节（fp16 梯度）；梯度累积 $N$ 步同步一次省 $N\times$。

## 四、代码实现

```python
for i, (x, y) in enumerate(loader):
    loss = model(x, y) / accum
    loss.backward()
    if i % accum == 0: opt.step(); opt.zero_grad()
```

## 五、与其他对比

- 与 通信压缩深入 直接降 $C$。
- 与 异步训练深入 用延迟容忍替代频繁同步。

## 六、常见误区

- 梯度累积改小了有效 batch 语义需调学习率。
- 忽视小参数层通信占比。

## 八、面试题

- 如何降 DP 通信？答：压缩梯度、梯度累积少同步、与计算重叠。

## 九、演进

全同步 → 累积 → 压缩。

## 十、小结

数据并行通信量正比参数，压缩与累积是主要降本手段。
