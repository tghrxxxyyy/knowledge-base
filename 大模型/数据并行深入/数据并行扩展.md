# 数据并行大规模扩展

> 对应 Goyal et al., 《Accurate, Large Minibatch SGD》, 2017（线性缩放律）。

## 一、背景与挑战

卡数增多时 batch 增大，需保持收敛与加速比。

## 二、核心原理

线性缩放律：batch 乘 $K$ 则学习率乘 $K$，前几步预热；梯度噪声随 $K$ 减，需调 schedule；扩展效率受通信占比限。

## 三、数学形式

有效 lr $\eta' = K\eta$；warmup 步数随 $K$ 增；加速比 $\approx \frac{K}{1+\alpha K}$（$\alpha$ 通信占比）。

## 四、代码实现

```python
lr = base_lr * world_size
sched = LinearWarmupCosine(optimizer, warmup=warmup_steps)
```

## 五、与其他对比

- 与 混合并行深入 协同到万卡。
- 与 异步训练深入 用异步放宽同步约束。

## 六、常见误区

- 直接放大 lr 不预热致训练崩。
- 忽视大 batch 泛化下降。

## 十、小结

数据并行扩展靠线性缩放律与通信优化，受通信占比限。
