# 数据并行总览

> 对应 Li et al., 《PyTorch Distributed: Experiences on Accelerating Data Parallel Training》, 2020；DDP 实践。

## 一、背景与挑战

多卡各持完整模型副本，处理不同数据子集，需聚合梯度保持一致。

## 二、核心原理

每张卡前向反向得本地梯度，经 all-reduce 求平均后同步更新；PyTorch DDP 用梯度桶（bucket）重叠通信与反向计算。

## 三、数学形式

同步更新 $\theta \leftarrow \theta - \eta \frac{1}{K}\sum_{k=1}^K g_k$（$K$ 卡数，$g_k$ 本卡梯度）。

## 四、代码实现

```python
model = DDP(model, device_ids=[rank])
out = model(x); loss = crit(out, y)
loss.backward()          # 自动 all-reduce
opt.step()
```

## 五、与其他对比

- 与 张量并行深入 / 流水线并行深入 在 3D 并行中常叠加。
- DP 显存随模型复制，需 ZeRO 辅助。

## 六、常见误区

- 未设相同随机种子致各卡数据不同分布。
- 忽视梯度桶大小影响重叠效率。

## 八、面试题

- 数据并行如何保持一致？答：各卡算梯度后 all-reduce 平均再同步更新。

## 九、演进

单卡 → 朴素 DP → DDP 桶重叠 → ZeRO。

## 十、小结

数据并行复制完整模型、聚合梯度，是最易用的并行方式。
