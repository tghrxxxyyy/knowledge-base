# 数据并行显存分析

> 对应 Rajbhandari et al., 《ZeRO》, 2020。

## 一、背景与挑战

标准 DP 每卡存完整参数+梯度+优化器状态，超大模型放不下。

## 二、核心原理

参数 fp16 约 $2\phi$、梯度 $2\phi$、Adam 状态 $12\phi$；ZeRO 分区后单卡近似 $(2+2+12)\phi/K$。

## 三、数学形式

标准 DP 显存 $\approx 16\phi$ 字节；ZeRO-3 约 $16\phi/K$（忽略碎片）。

## 四、代码实现

```python
mem_gb = (2 + 2 + 12) * phi / 1e9      # 标准 DP 单卡
zero3_gb = mem_gb / world_size
```

## 五、与其他对比

- 与 张量并行深入（切权重）互补。
- 与 混合并行深入 组合到极致。

## 六、常见误区

- 以为 DP 天然省显存（实际复制）。
- 忽略激活仍随 batch/序列增。

## 八、面试题

- 标准 DP 显存组成？答：参数+梯度+优化器状态约 16ϕ，随卡不降。

## 九、演进

复制 → ZeRO 分区 → Offload 到 CPU。

## 十、小结

DP 显存靠复制，需 ZeRO 分区或 Offload 才放得下大模型。
