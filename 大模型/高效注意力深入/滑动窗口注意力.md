# 滑动窗口注意力

> 见「长上下文技术」与「高效注意力深入/FlashAttention原理」。

## 一、背景与挑战

超长序列全注意贵，但许多任务只需局部上下文。

## 二、核心原理

每 token 仅注意窗口内邻居，复杂度线性；配合全局 token 或分层窗口（Longformer）兼顾局部与全局。

## 三、关键要点

- 局部强、全局弱。
- 需全局令牌补。

## 四、代码实现

```python
mask = causal_mask & (abs(i-j) <= w)
```

## 五、与其他对比

- 全注意全局；窗口局部高效。

## 六、常见误区

- 窗口能处理任意长依赖——跨窗口需机制。

## 七、与开源书对应

- Longformer; Mistral 滑动窗口.
- llm-course: https://github.com/mlabonne/llm-course

## 八、面试题

- 滑动窗口如何兼顾长依赖？

## 九、演进

全注意 → 窗口 → 层次窗口。

## 十、小结

窗口注意是长序列廉价解。
