# 稀疏与低秩近似

> 见「注意力变体」与「高效注意力深入/线性注意力」。

## 一、背景与挑战

注意力矩阵可近似为稀疏或低秩以省算力。

## 二、核心原理

只计算重要 token 对（稀疏）、或用低秩分解（如 Linformer 的投影压缩 K/V 到固定维度）。

## 三、数学形式

Linformer：K,V 投影到 k 维：

```
K' = K W_k,  W_k ∈ R^{N×k}, k << N
```

## 四、代码实现

```python
Kp = K @ Wk  # 压缩
```

## 五、关键要点

- 近似有损，需任务验证。
- 适合长序列。

## 六、与其他对比

- 稀疏保结构；低秩压维度。

## 七、常见误区

- 近似无损——通常略降质。

## 八、与开源书对应

- Linformer; Performer.

## 十、演进
