# 多查询注意力

> 见「注意力变体」与「高效注意力深入/FlashAttention原理」。

## 一、背景与挑战

自回归推理时 KV 缓存随头数线性增长，成瓶颈。

## 二、核心原理

MQA 让所有头共享一组 K/V，GQA 折中（分组共享），大幅减 KV 缓存与访存，提速解码。

## 三、数学形式

```
K_shared = K (单组); 每头 Q_i 与共享 K/V 算注意力
```

## 四、代码实现

```python
# GQA: 头分组共享 kv
kv = repeat_kv(kv, n_rep)
```

## 五、关键要点

- MQA 快但质量略降；GQA 均衡。
- 现代模型（Llama2+）多用 GQA。

## 六、与其他对比

- MHA 质量高但慢；MQA 快；GQA 折中。

## 七、常见误区

- 共享 KV 必降质——GQA 影响很小。
