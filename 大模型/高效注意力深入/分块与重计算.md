# 分块与重计算

> 见「高效注意力深入/FlashAttention原理」与「训练技巧与稳定性」。

## 一、背景与挑战

大矩阵放不下 HBM，需分块并避免存中间。

## 二、核心原理

把 Q/K/V 切块在快速 SRAM 算，反向时重算而非存，省显存换算力。

## 三、关键要点

- SRAM 快但小，块大小需配硬件。
- 重计算增算力但降显存。

## 四、代码实现

```python
for qi in tiles(Q): for ki in tiles(K): acc += tile_attn(qi, ki, vi)
```

## 五、与其他对比

- 存中间省算力；重计算省显存。

## 六、常见误区

- 重计算总慢——显存换时间常值得。
