# 注意力内核融合

> 见「编译优化与模型格式/算子融合与内核」与「高效注意力深入/FlashAttention原理」。

## 一、背景与挑战

注意力的多步（QK、softmax、AV）分开执行访存重。

## 二、核心原理

把多步融合为单内核（如 FlashAttention），减少 HBM 往返；TVM/ Triton 可自动/手写融合。

## 三、关键要点

- 融合降访存是提速主因。
- Triton 易写融合核。

## 四、代码实现

```python
@triton.jit
def fused_attn(Q,K,V,Out): ...  # 单核完成
```

## 五、与其他对比

- 分步实现慢；融合快。

## 六、常见误区

- 算法对就行——内核实现决定速度。

## 七、与开源书对应
