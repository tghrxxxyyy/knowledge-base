# 偏好优化理论总览

> 对应 Rafailov et al., *DPO*, NeurIPS 2023；Azar et al., *A General Theoretical Paradigm to Understand Learning from Human Preferences*, AISTATS 2024。

## 一、背景与挑战

偏好优化的工程实践跑得比理论快：我们知道 DPO 能用，却不总清楚它在什么假设下逼近什么解、误差从哪里来。理论视角要回答三问：目标函数的最优解是什么形态；从有限偏好样本估计它的统计误差有多大；离线数据分布不覆盖时会发生什么。

## 二、核心原理

主链条是：KL 正则的奖励最大化问题有闭式最优解（Boltzmann 形式）→ 该闭式解可反解出奖励与策略的一一对应（重参数化）→ 把它代入 Bradley-Terry 偏好似然，就得到只含策略的 DPO 目标。因此 DPO 的「收敛」有两层含义：优化层面能否收敛到目标的极小点；统计层面该极小点是否接近真实偏好下的最优策略。前者受损失有界性与条件数影响，后者受偏好模型正确性与数据覆盖影响。

## 三、数学形式

KL 正则目标与其闭式解：

$$\max_\pi\ \mathbb E_{x,\;y\sim\pi}[r(x,y)]-\beta\,\mathrm{KL}\big(\pi(\cdot|x)\,\|\,\pi_{ref}(\cdot|x)\big)
\quad\Longrightarrow\quad
\pi^*(y|x)=\frac{1}{Z(x)}\pi_{ref}(y|x)\exp\!\Big(\frac{r(x,y)}{\beta}\Big)$$

反解得 $r(x,y)=\beta\log\frac{\pi^*(y|x)}{\pi_{ref}(y|x)}+\beta\log Z(x)$，代入 BT 似然时 $\log Z(x)$ 在配对差中抵消。

## 四、代码实现

```python
import torch

def kl_regularized_optimal(ref_logits, reward, beta=0.1):
    # 离散动作上的闭式最优策略：pi* ∝ pi_ref * exp(r / beta)
    log_pi = torch.log_softmax(ref_logits, dim=-1) + reward / beta
    return torch.softmax(log_pi, dim=-1)          # 归一化即除以 Z(x)

def implied_reward(pi_logp, ref_logp, beta=0.1):
    # 由策略反解隐式奖励（差一个与 y 无关的 beta*logZ(x)）
    return beta * (pi_logp - ref_logp)
```

## 五、与其他对比

- 与 直接偏好优化变体深入：变体的设计动机基本都能在本目录的理论缺口上定位。
- 与 奖励模型深入：显式 RM 路线把误差集中在 RM 估计，DPO 路线把误差集中在策略参数化与覆盖。
- 与 奖励模型过优化与奖励黑客深入：过优化在理论上正是「在覆盖不足区域外推代理奖励」。

## 六、常见误区

- 把「DPO 与 RLHF 等价」当作无条件结论。等价性依赖 BT 偏好模型成立、$\pi_{ref}$ 固定、以及最优解可被参数族表达。
- 忽略 $\log Z(x)$ 抵消的前提是同一 prompt 内比较；跨 prompt 直接比较隐式奖励是没有意义的。
- 把训练损失下降等同于对齐变好。损失下降只说明在给定数据分布上拟合更好。

## 八、面试题

- DPO 与 KL 正则 RLHF 的等价性需要哪些假设？答：BT 偏好模型、固定参考策略、策略族能表达 Boltzmann 最优解、以及同 prompt 内配对比较。
- 为什么 $\log Z(x)$ 可以不显式估计？答：它只依赖 $x$，在同一 prompt 的偏好对奖励差中被消去。

## 九、演进

BT 偏好建模 → KL 正则强化学习 → 闭式重参数化（DPO） → ΨPO 通用范式 → 覆盖与在线探索的理论刻画。

## 十、小结

偏好优化的理论主干是「KL 正则最优解 + 偏好似然」两块拼图；把它拆清楚，才能判断某个变体到底修补了哪一处误差来源。
