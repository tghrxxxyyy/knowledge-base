# 离线覆盖与外推

> 对应离线强化学习中的分布覆盖理论；语言模型语境见 Azar et al., AISTATS 2024 与 Gao et al., *Scaling Laws for Reward Model Overoptimization*, ICML 2023。

## 一、背景与挑战

DPO 是纯离线方法：它只见过数据集里出现的回答。可优化后的策略会生成新的、数据集中没有的回答，此时隐式奖励是「外推」得来的，没有任何数据支撑。这就是离线偏好优化最根本的风险来源——不是拟合不够好，而是在没有数据的地方过度自信。

## 二、核心原理

离线学习的可靠性由「行为分布对目标分布的覆盖」决定：若偏好数据由某行为策略 $\mu$ 采样，而优化后的策略 $\pi_\theta$ 把质量转移到 $\mu$ 几乎不产生的区域，那里的隐式奖励是模型自由外推的产物。控制手段有三：一是保持 $\pi_{ref}$ 与数据采样策略一致（用同一 SFT 模型采样偏好对，即 on-policy 偏好数据），二是加强 KL / 有界约束限制转移幅度，三是迭代式在线补数据，把新策略生成的区域纳入覆盖。

## 三、数学形式

用密度比刻画覆盖，定义集中系数

$$C_\mu(\pi)=\sup_{x,y:\ \mu(y|x)>0}\frac{\pi(y|x)}{\mu(y|x)},\qquad \text{或}\quad \chi^2\text{-型}\ \ \mathbb E_\mu\Big[\big(\tfrac{\pi}{\mu}\big)^2\Big]$$

离线方法的次优性上界通常形如 $\mathrm{SubOpt}(\pi)\lesssim\sqrt{\dfrac{C_\mu(\pi)\cdot \mathrm{complexity}}{N}}$：覆盖越差（$C_\mu$ 越大）、样本越少（$N$ 越小），保证越弱。

## 四、代码实现

```python
import torch

@torch.no_grad()
def coverage_diagnostics(policy_logp, ref_logp, kl_budget=10.0):
    # 用序列级对数密度比近似监控分布转移
    log_ratio = policy_logp - ref_logp
    kl_hat = log_ratio.mean()                     # 反向 KL 的单样本估计
    ess = torch.exp(2 * torch.logsumexp(log_ratio, 0) - torch.logsumexp(2 * log_ratio, 0))
    return {
        "kl_hat": kl_hat.item(),
        "max_log_ratio": log_ratio.max().item(),  # 外推最严重的样本
        "eff_sample_size": ess.item(),            # ESS 过低说明覆盖不足
        "over_budget": bool(kl_hat.item() > kl_budget),
    }
```

## 五、与其他对比

- 相对在线 RLHF：PPO 每步用当前策略采样并由 RM 打分，覆盖问题被在线采样部分缓解，但代价是 RM 自身的分布外误差。
- 与 奖励模型过优化与奖励黑客深入：过优化曲线的下行段本质就是覆盖耗尽后的外推失败。
- 与 直接偏好优化变体深入：IPO 的有界性、SimPO 的间隔都在间接限制外推幅度。

## 六、常见误区

- 用与 $\pi_{ref}$ 无关的第三方数据做 DPO，却期待 KL 项能兜住。数据分布与参考分布错位时，$\beta$ 再大也补不回覆盖。
- 只看平均 KL。均值可能很小而少数样本 log-ratio 极大，退化往往由这些尾部样本引发。
- 认为多训几轮能弥补覆盖不足。轮数增加只会加深在无数据区域的外推。

## 八、面试题

- 为什么 on-policy 偏好数据通常优于现成公开偏好集？答：采样策略与参考策略一致，覆盖更好，隐式奖励的外推区域更小。
- 覆盖不足会以什么现象暴露？答：KL 尾部样本 log-ratio 异常大、有效样本量下降、生成出现风格漂移或退化重复。

## 九、演进

纯离线单轮 DPO → on-policy 偏好数据 → 多轮迭代（生成—标注—训练）→ 带覆盖约束的悲观式偏好优化。

## 十、小结

离线偏好优化的天花板由数据覆盖决定；把偏好对采样在参考策略上、并按 KL 尾部监控外推，比反复调 $\beta$ 更有效。
