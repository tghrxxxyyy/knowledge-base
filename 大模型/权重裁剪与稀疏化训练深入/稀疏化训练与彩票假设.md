# 稀疏化训练与彩票假设

> 对应 Frankle & Carbin, *The Lottery Ticket Hypothesis*, 2019；与 训练不稳定诊断深入 衔接。

## 一、背景与挑战

训练后裁剪需额外微调；稀疏化训练在训练初期即引入掩码，使稠密与稀疏联合优化。

## 二、核心原理

彩票假设认为随机初始化网络中存在子网络（中奖票），单独训练即可达原精度；实践中用迭代裁剪+重初始化。

## 三、数学形式

掩码演变 $M^{(t+1)} = \text{topk}(|W^{(t)}|, k_t)$；稀疏度随 $t$ 递增至目标 $s^*$。

## 四、代码实现

```python
for t in range(T):
    train_step(); M = prune_by_magnitude(W, rate_t)
```

## 五、与其他对比

- 比训练后裁剪省一次全量微调，但训练更复杂。
- 与 梯度累积深入 可组合（稀疏+小批量）。

## 六、常见误区

- 中奖票需在原始初始化下重训，随意重初始化失效。
- 过高初始稀疏度致无法收敛。

## 八、面试题

## 九、演进

训练后裁剪 → 迭代裁剪 → 中奖票 → 动态稀疏训练。

## 十、小结

稀疏化训练将剪枝融入优化，中奖票揭示稀疏子结构存在性。
