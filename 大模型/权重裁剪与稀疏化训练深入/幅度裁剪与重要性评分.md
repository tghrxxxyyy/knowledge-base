# 幅度裁剪与重要性评分

> 对应 Han et al., 2015；与 训练数据质量 / 数值稳定性深入 衔接。

## 一、背景与挑战

裁剪需度量“哪些权重冗余”，简单幅度法高效但可能误删结构化重要权重。

## 二、核心原理

幅度裁剪按 $|W_{ij}|$ 排序，低于阈值的置零；更优方法用梯度/ fisher/激活等一阶重要性评分。

## 三、数学形式

重要性 $I_{ij}=|W_{ij}|\cdot|\nabla_{W_{ij}}\mathcal L|$ 近似（Taylor 一阶），阈值选为分位数 $q$。

## 四、代码实现

```python
imp = (W * W.grad).abs()
mask = imp > torch.quantile(imp, q)
```

## 五、与其他对比

- 幅度法最便宜但偏保守；一阶/二阶重要性更准但需梯度或 Hessian。
- 与 彩票假设深入 共用重要性排序思想。

## 六、常见误区

- 全局统一阈值忽略不同层尺度差异，宜分层设定。
- 仅看幅度忽略权重对损失的耦合贡献。

## 八、面试题

- 为何分层阈值优于全局？答：各层权重尺度与冗余度不同，全局阈值易伤关键层。

## 九、演进

幅度 → 梯度一阶 → Taylor 二阶 → 自适应重要性。

## 十、小结

重要性评分决定裁剪质量，分层与一阶信息可显著提升保留精度。
