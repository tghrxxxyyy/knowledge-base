# 权重裁剪总览

> 对应 Han et al., *Deep Compression*, ICLR 2016；与 模型压缩与量化深入 / 推理加速深入 衔接。

## 一、背景与挑战

大模型参数量巨大，推理与存储成本高；权重裁剪通过移除冗余连接/通道降低规模，是结构化压缩主干之一。

## 二、核心原理

裁剪本质是对权重施加稀疏掩码 $M$，保留重要连接；分训练后裁剪（prune-then-finetune）与训练时稀疏化两类范式。

## 三、数学形式

裁剪后权重 $W' = W \odot M$，其中 $M_{ij}\in\{0,1\}$；目标是在 $\|M\|_0$ 很小下最小化 $\mathcal L(W\odot M)$。

## 四、代码实现

```python
mask = (torch.abs(W) > threshold)
W_pruned = W * mask
```

## 五、与其他对比

- 与 量化深入（低比特）互补，二者可叠加获得更高压缩比。
- 与 知识蒸馏深入 同为压缩手段，但机制是掩码而非师生迁移。

## 六、常见误区

- 裁剪率过高直接崩精度，需渐进裁剪加重训练。
- 非结构化裁剪难获真实加速，依赖专用硬件或稀疏库。

## 八、面试题

- 裁剪为何常需重训练？答：移除权重破坏已学表示，微调可恢复大部分精度。

## 九、演进

非结构化幅度裁剪 → 结构化裁剪 → 训练时稀疏化 → 自动稀疏结构搜索。

## 十、小结

权重裁剪以稀疏掩码压缩模型，须在稀疏率与重训练恢复间权衡。
