# 结构化与非结构化裁剪

> 对应 Han et al., *Learning both Weights and Connections*, 2015；与 模型压缩与量化深入 衔接。

## 一、背景与挑战

非结构化裁剪随机移除单个权重，硬件难加速；结构化裁剪移除整通道/整头，更易落地。

## 二、核心原理

非结构化：逐元素掩码，任意稀疏；结构化：按通道/滤波器/注意力头为单位裁剪，保持规则张量形状。

## 三、数学形式

通道裁剪 $W'_{:,j,:} = 0$ 当通道 $j$ 被移除；非结构化为逐元素 $M_{ij}=0$。

## 四、代码实现

```python
keep = channel_importance > thr
W = W[:, keep, :, :]   # 结构化通道裁剪
```

## 五、与其他对比

- 结构化更易被 BLAS/算子加速，但精度损失通常更大。
- 与非结构化裁剪在压缩-精度 Pareto 前沿上互补。

## 六、常见误区

- 误以为任何稀疏都能加速；非结构化需稀疏张量内核。
- 结构粒度过粗（如整层）易大幅掉点。

## 八、面试题

- 为何结构化裁剪更易加速？答：保留规则形状，可被标准密集算子直接执行。

## 九、演进

非结构化 → 通道/滤波器级 → 注意力头级 → 动态结构化。

## 十、小结

结构化裁剪以规则形状换取真实加速，是生产部署首选粒度。
