# 裁剪后重训练与微调

> 对应 Han et al., 2015 的 prune-retrain；与 参数高效微调深入 衔接。

## 一、背景与挑战

裁剪破坏优化景观，需重训练恢复精度；一次性高比率裁剪常不可逆。

## 二、核心原理

采用迭代裁剪：小幅裁剪-微调循环，逐步逼近目标稀疏度，避免一次性损伤。

## 三、数学形式

每轮最小化 $\mathcal L(W\odot M^{(k)})$，学习率常衰减；总步数 $K$ 控制恢复程度。

## 四、代码实现

```python
for k in range(K):
    M = prune(W, rate); finetune(W*M, epochs=e)
```

## 五、与其他对比

- 与 量化感知训练 类似，都是压缩-重训闭环。
- 与 知识蒸馏深入 可联合（蒸馏补偿裁剪损失）。

## 六、常见误区

- 裁完直接用、不复训，精度断崖。
- 重训学习率沿用原值，易震荡。

## 八、面试题

- 为何迭代裁剪优于一次性？答：逐步缩容给优化留出恢复余地，避免不可恢复的信息丢失。

## 九、演进

一次性裁剪 → 迭代裁剪 → 训练时稀疏化。

## 十、小结

裁剪后重训练是精度保障，迭代策略显著优于一次性高比率。
