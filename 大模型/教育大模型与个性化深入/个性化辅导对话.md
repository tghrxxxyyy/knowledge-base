# 个性化辅导对话

> 对应 Ouyang 2022 的 InstructGPT 论文与 github huggingface/trl 项目。

## 一、背景与挑战
有效辅导需保持耐心、循循善诱而非直接给答案。需通过偏好对齐让模型采用苏格拉底式提问风格。

## 二、核心原理
用师生对话数据 SFT，再以「引导式 vs 直接给答案」的人类偏好训练奖励模型，使模型倾向于提示而非代劳。

## 三、形式化与数学基础
对话策略偏好优化：
$ \max_\theta \mathbb{E}[\,r(x,y)-\beta\,\mathrm{KL}(\pi_\theta\\|\pi_{\text{ref}})\,] $
奖励偏向启发式回应。

## 四、代码实现
```python
def tutor_reply(model, hist, student_q):
    prompt = hist + '\n学生: ' + student_q + '\n教师(请引导而非直接给答案):'
    return model.generate(prompt)

def reward_style(resp):
    if '答案是' in resp and '为什么' not in resp:
        return -1.0
    if '你能想到' in resp or '试一试' in resp:
        return 1.0
    return 0.0
```

## 五、与其他技术对比
相比问答机器人，辅导对话强调过程；相比固定脚本，模型可即兴调整语术。

## 六、常见误区
直接给答案剥夺思考机会。语气过于严厉打击学习动机。

## 八、面试题
问：辅导对话为何避免直接答案？答：元认知研究表明自我推导比接收答案留存更高。

## 九、演进与趋势
情绪感知、长期记忆与协作解题。

## 十、小结
对齐后的对话风格决定大模型是「代写」还是「良师」。
