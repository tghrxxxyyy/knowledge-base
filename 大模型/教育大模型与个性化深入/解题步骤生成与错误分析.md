# 解题步骤生成与错误分析

> 对应 Wei 2022 的 chain-of-thought 论文与 github karpathy/nanoGPT 项目。

## 一、背景与挑战
学生需要的不只是答案，而是可理解的解题路径与错因分析。逐步生成推导并识别错误步骤，是有效辅导的关键。

## 二、核心原理
以 CoT 生成标准解法步骤，再用对照模型比较学生解答，定位首个错误步骤并解释正确思路。

## 三、形式化与数学基础
逐步正确概率：
$ p(\text{正确}|x)=\prod_t p(s_t\text{ 正确}|x, s_{<t}) $
错误定位取首个不满足的 $ t $。

## 四、代码实现
```python
def solve(model, problem):
    return model.generate(problem + '\n分步解答:\n1.')

def find_error(model, student_steps):
    for i, st in enumerate(student_steps):
        if not model.is_valid(st, prev=student_steps[:i]):
            return i, model.explain(st)
    return -1, '全部正确'

def explain(model, wrong_step):
    return model.generate('步骤错在哪: ' + wrong_step)
```

## 五、与其他技术对比
相比只给答案，步骤级反馈更利于学习迁移；相比规则判卷，模型可处理自由表述。

## 六、常见误区
把计算笔误与概念错误混为一谈。步骤编号错乱导致定位偏差。
