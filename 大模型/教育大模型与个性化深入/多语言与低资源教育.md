# 多语言与低资源教育

> 对应 github huggingface/transformers 项目与 Sennrich 2016 的 BPE 论文。

## 一、背景与挑战
许多地区缺乏母语教材与标注数据。多语言模型与子词切分可在低资源语言上迁移知识，实现跨语言辅导。

## 二、核心原理
用共享 BPE 词表让高资源语言监督信号迁移到冷门语言；必要时以翻译桥接或跨语言对齐表征做零样本教学。

## 三、形式化与数学基础
BPE 合并频率：
$ (a,b)=\arg\max_{(x,y)} \text{count}(xy) $
迭代合并高频相邻符号，构建跨语言子词表。

## 四、代码实现
```python
from collections import Counter

def merge_once(vocab, pairs):
    best = max(pairs.items(), key=lambda kv: kv[1])[0]
    new_vocab = {}
    for w, c in vocab.items():
        new_vocab[w.replace(best[0] + best[1], ''.join(best))] = c
    return new_vocab
```

## 五、与其他技术对比
相比单语模型，多语言共享表征提升低资源泛化；相比全量翻译，共享词表更省算力。

## 六、常见误区
盲目跨语言迁移忽视文化差异。词表覆盖不足导致未登录词爆炸。

## 七、与开源书/权威来源对应
- Sennrich 2016 BPE
- github huggingface/transformers 的 tokenizer
- Kudo & Richardson 2018 SentencePiece

## 八、面试题
问：BPE 为何利于低资源？答：子词在语言间共享，缓解罕见词与未登录词问题。

## 九、演进与趋势
多语言指令对齐、母语生成与本地知识融合。

## 十、小结
共享子词与跨语言迁移让教育普惠到资源匮乏地区。
