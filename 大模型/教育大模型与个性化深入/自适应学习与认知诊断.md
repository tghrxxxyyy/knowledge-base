# 自适应学习与认知诊断

> 对应 github huggingface/transformers 项目与 Kaplan 2020 的 scaling laws 论文。

## 一、背景与挑战
学生知识状态异质，统一教学效率低。认知诊断估计每个知识点的掌握度，据此动态调整题目难度与讲解深度。

## 二、核心原理
用习题交互序列预测掌握向量，掌握度低的知识点触发补习内容生成。大模型据诊断结果生成个性化讲解与练习。

## 三、形式化与数学基础
掌握度建模为：
$ p(\text{正确}|s,k)=\sigma(\alpha_s - \beta_k + \gamma) $
其中 $ \alpha_s $ 为学生能力，$ \beta_k $ 为题目难度。

## 四、代码实现
```python
import math

def mastery(alpha, beta, gamma=0.0):
    return 1.0 / (1.0 + math.exp(-(alpha - beta + gamma)))

def select_next(mastery_vec, difficulties, theta=0.6):
    # 选掌握度接近阈值且略高于难度者
    best, bi = -1, 0
    for i, m in enumerate(mastery_vec):
        score = -abs(m - theta) + (1 - difficulties[i])
        if score > best:
            best, bi = score, i
    return bi
```

## 五、与其他技术对比
相比固定题库顺序，自适应提升学习效率；相比纯人工诊断，模型可规模化但需防刻板标签。

## 六、常见误区
把一次错误当成永久不会。诊断噪声未建模导致难度错配。
