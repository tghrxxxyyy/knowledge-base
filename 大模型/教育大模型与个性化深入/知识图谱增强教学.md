# 知识图谱增强教学

> 对应 github microsoft/graphrag 项目与 Lewis 2020 的 RAG 论文。

## 一、背景与挑战
知识点间存在先修与依赖关系，孤立讲解易致理解断层。知识图谱可显式表达概念网络，引导有序教学。

## 二、核心原理
构建学科知识图谱，根据学生薄弱点沿依赖边回溯先修概念，生成补学路径；讲解时检索相关子图作为依据。

## 三、形式化与数学基础
先修可达性：
$ \text{prereq}(a,b)=1 \iff \text{路径 } a\to \cdots \to b \text{ 存在} $
学习顺序需满足拓扑排序。

## 四、代码实现
```python
def prereq_path(graph, weak, root):
    # BFS 找从 root 到 weak 的依赖链
    from collections import deque
    q = deque([root]); prev = {root: None}
    while q:
        u = q.popleft()
        if u == weak:
            break
        for v in graph.get(u, []):
            if v not in prev:
                prev[v] = u; q.append(v)
    path = []; c = weak
    while c is not None:
        path.append(c); c = prev[c]
    return path[::-1]

def lesson(model, subgraph, topic):
    ctx = ' -> '.join(subgraph)
    return model.generate('知识链: ' + ctx + '\n讲解: ' + topic)
```

## 五、与其他技术对比
相比线性课件，图谱支持个性化路径；相比纯文本检索，结构化依赖更利于查漏补缺。

## 六、常见误区
图谱错误依赖会误导先修顺序。忽略知识版本差异。
