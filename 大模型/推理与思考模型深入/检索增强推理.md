# 检索增强推理 RAG + Reasoning

> 对应 Search-o1(2025) 与 RAG + 推理模型结合的研究。

## 一、背景与挑战

纯推理模型在长链推理中容易「事实遗忘」或「幻觉」——它靠参数记忆知识，遇到罕见事实、最新信息或精确数字时会编造。检索增强生成（RAG）能补事实，但传统 RAG 是「先检索、再生成」一次性拼入上下文，无法应对长推理中**逐步浮现的信息需求**：模型思考到某步才发现缺某个事实，却已错过检索时机。检索增强推理（如 Search-o1）让模型在思考过程中**自主决定何时检索、检索什么**，把外部知识阶段性注入思维链。

## 二、核心原理

核心范式是「边想边查」：

1. 模型展开思维链，当遇到不确定事实/数据，自主生成检索查询（query）。
2. 检索器返回相关片段，模型将其作为「观察」插入当前思考。
3. 基于新证据继续推理，可多轮检索直至证据充分。
4. 最终整合所有证据给出答案，并标注来源。

相比静态 RAG，检索时机由模型动态决定，更贴合推理的信息需求曲线；检索结果需带出处，便于验证与防注入。

### 工程落地要点

- **检索触发判定**：用轻量分类器或模型自判断「我是否缺信息」，仅在需要时检索，省成本。
- **查询构造**：让模型基于当前思考生成精准 query，而非用原问题直接搜，召回更准。
- **证据溯源**：检索片段带 doc_id 与片段位置，最终答案标注引用，便于核查与防投毒。
- **重排与去噪**：多路召回后用重排模型取 top-k，过滤无关片段，防噪声干扰推理。
- **增量注入**：每轮检索结果作为新观察插入思维链，而非一次性拼长上下文，省 token。
- **失败处理**：检索为空或冲突时，模型应声明「信息不足」而非编造，提升可信度。

## 三、形式化与数学基础

把推理看作带检索动作的轨迹，状态在每步可转移为「检索」：

$$
y_t \sim p_\theta(\cdot \mid x, y_{<t}, \text{retrieve}(q_t))
$$

其中检索在模型判定需要时触发：

$$
q_t = \begin{cases}
\text{query}(y_{<t}) & \text{if } p_{\text{retrieve}}(y_{<t}) > \tau \\
\emptyset & \text{otherwise}
\end{cases}
$$

检索片段经重排后取 top-$k$，拼入上下文。最终答案质量受检索召回与推理整合共同约束：

$$
\text{准确率} \le \min(\text{检索覆盖},\ \text{整合能力})
$$

## 四、代码实现

简化的「思考中按需检索」循环（示意）：

```python
def reason_with_search(model, retriever, question, max_steps=8):
    ctx = question
    for _ in range(max_steps):
        out = model.generate(ctx, stop=["<search>", "<answer>"])
        if "<search>" in out:
            q = parse_query(out)
            docs = retriever.search(q, top_k=3)
            ctx += f"\n检索[{q}]：{docs}\n"     # 注入证据
        else:
            return parse_answer(out)
    return model.generate(ctx)
```

## 五、与其他技术对比

| 方式 | 检索时机 | 事实性 | 成本 |
|------|----------|--------|------|
| 静态 RAG | 生成前一次 | 中 | 低 |
| 推理模型无 RAG | 无 | 易幻觉 | 中 |
| 检索增强推理 | 思考中动态 | 高 | 高（多轮） |

## 六、常见误区

- **RAG 能根治幻觉**：检索错了或整合不当仍会出错，且多轮检索放大噪声。
- **检索越多越好**：无关片段会干扰推理、撑爆上下文。
- **忽略来源标注**：不溯源易被恶意文档注入（检索投毒）。

## 九、演进与趋势

从「思考结束再补检索」到「推理内原生检索」：模型把检索当工具调用融入思维链（见「多步工具推理」）。结合 PRM 对检索质量打分、用路由器决定是否需要检索。未来推理模型将内置「检索-推理-验证」闭环，并支持多模态检索（图表/代码库）。

## 十、小结

检索增强推理把 RAG 从「前置一次性检索」升级为「思考中动态检索」，让外部知识随推理需求分阶段注入，有效缓解长链事实遗忘与幻觉。其效果取决于检索时机判断、召回质量与来源可信度。落地需注意检索噪声与投毒风险，并以来源标注保障可验证性。
