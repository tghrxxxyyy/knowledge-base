# 思维链蒸馏 Chain-of-Thought Distillation

> 对应 Wei et al.(2022, FLAN/CoT) 与 DeepSeek 蒸馏、Gemini 蒸馏等大模型小模型化实践。

## 一、背景与挑战

推理模型（如 R1、o1）参数量大、推理成本高，难以部署到端侧或高并发场景。直接训练小模型做复杂推理又缺乏优质长链数据。思维链蒸馏（CoT distillation）的思路是：**用强推理模型生成「问题 → 长思考 → 答案」三元组数据，再监督微调（SFT）小模型**，让小模型学会「先想再答」的推理行为。挑战在于：蒸馏数据质量直接决定上限；小模型容量有限，过长的思维链可能学不稳甚至退化；且「思考风格」需要和目标模型的格式对齐，否则推理时解析失败。

## 二、核心原理

流程分三步：

1. **生成**：用教师推理模型对大量问题采样出带长思维链的解答（含自我验证、回溯）。
2. **筛选**：保留答案正确、推理连贯的样本，过滤幻觉与格式错乱；可用拒绝采样扩大覆盖。
3. **蒸馏训练**：以 $(x, \text{CoT}, a)$ 为监督目标，对小模型做 SFT，损失为标准的自回归负对数似然。

蒸馏学的是教师的「行为分布」而非仅最终答案，因此小模型能涌现出类似的长思考能力。DeepSeek 将 R1 蒸馏到 Qwen/Llama 系列（1.5B–70B）即此法；也可结合拒绝采样与多教师集成提升多样性。

### 工程落地要点

- **数据来源多样化**：用多道难题、多领域（数学/代码/科学）采样，避免学生只学会某类题型。
- **质量筛三层**：先留答案正确、再留推理连贯、最后用 verifier/PRM 去「过程错答案对」的毒样本。
- **长度匹配**：学生容量小，过长的教师思维链应适度裁剪或分段，防止过拟合格式。
- **拒绝采样增强**：对同一题采样多条链，挑最优链作监督，提升数据上限。
- **多教师集成**：融合多个推理模型的解答，提升覆盖与鲁棒，减少单一教师偏见。
- **后训练补强**：蒸馏后可用少量 RL 或指令微调补齐分布，缓解容量不足带来的短板。

## 三、形式化与数学基础

若教师输出分布为 $q(y\mid x)$（含 CoT），学生最小化与教师序列的 KL：

$$
\mathcal{L}_{\text{distill}} = \mathbb{E}_{x}\Big[ -\sum_{t=1}^{|y|} \log p_\theta(y_t\mid x,y_{<t}) \Big],\quad y\sim q(\cdot\mid x)
$$

与经典知识蒸馏不同，此处教师提供的是**完整推理轨迹**而非软标签；学生容量 $C$ 限制可拟合的轨迹复杂度：

$$
\text{可迁移能力} \le f(C,\ \text{数据质量},\ \text{CoT 长度})
$$

过长 CoT 在容量 $C$ 不足时反而损害泛化（过拟合教师风格），需在长度与容量间匹配。

## 四、代码实现

把教师产出转成 SFT 数据集后训练：

```python
from datasets import load_dataset
from trl import SFTConfig, SFTTrainer

data = load_dataset("json", data_files="r1_distill.jsonl")["train"]
# 每条样本: {"prompt": x, "completion": "<think>...</think>answer"}

cfg = SFTConfig(max_length=4096, per_device_train_batch_size=4,
                learning_rate=2e-5, num_train_epochs=3)
trainer = SFTTrainer(model="Qwen2.5-7B", train_dataset=data, args=cfg)
trainer.train()
```

## 五、与其他技术对比

| 方式 | 数据来源 | 小模型推理 | 成本 |
|------|----------|-----------|------|
| 直接 SFT（短答） | 人工标注 | 弱 | 中 |
| CoT 蒸馏 | 教师长链 | 强 | 低（推理时） |
| RL 后训练小模型 | 奖励信号 | 强但贵 | 训练贵 |
| 纯提示 CoT | 无训练 | 依赖底座 | 无 |

## 六、常见误区

- **蒸馏≈复制教师**：学生学的是分布，容量不足时只能学「表象」，未必真懂。
- **CoT 越长越好**：超出学生容量会过拟合格式、损害泛化。
- **只看答案正确率筛数据**：推理过程错误但答案碰对的样本会教坏学生。
- **蒸馏可无视格式**：格式与教师不一致会导致推理时标记解析失败。
- **小模型必弱于教师**：在中等难度上蒸馏小模型常逼近甚至超教师 SFT 版。

## 九、演进与趋势

从「整条 CoT 全监督」演进到「选择性蒸馏」：只蒸馏关键推理步骤、用 PRM 给步骤加权、或结合少量 RL 微调补齐分布。多教师集成蒸馏、以及「先蒸馏推理、再蒸馏工具调用」的分阶段方案也在兴起，目标是让 7B 级模型逼近 70B 的推理表现，并降低对教师单一风格的过拟合。

## 十、小结

思维链蒸馏用强推理教师的完整长链数据监督微调小模型，使其获得「先想再答」的能力，是低成本获得强推理小模型的主路径。其上限由数据质量与学生容量共同决定：需筛掉「答案对但过程错」的样本，并控制 CoT 长度匹配模型能力。DeepSeek 蒸馏实践已验证该路线对 1.5B–70B 均有效，是端侧强推理的关键技术。
