# 测试时计算 Test-Time Compute

> 对应 Snell et al.(2024) 与 o1 类工作。

## 一、核心概念

测试时计算指推理阶段通过**更多采样/搜索/验证**提升质量。经典结论(Snell et al.)：在困难任务上，增大 test-time compute 的收益可能超过增大模型参数。形式：

```
质量 = f(模型能力, 推理计算量, 验证器质量)
```

验证器(verifier)质量是关键——没有好的「判断对错」机制，更多采样只是浪费。

## 二、关键要点

- 需要可靠的 verifier(如代码执行、数学检查、奖励模型)。
- best-of-n / 搜索/自我验证是主要手段。

## 三、面试题

- 为何 test-time compute 的效果依赖验证器？
