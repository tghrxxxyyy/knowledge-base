# 低资源语言增强

> 对应多语继续预训练、LoRA 语言适配器（AdapterHub）、合成数据增强，及 llm-course（mlabonne）、d2l-zh。

## 一、背景与挑战

低资源语言（如豪萨语、约鲁巴语）面临「数据少、标注少、基准少」三重匮乏，直接训练或简单混入预训练都难以获得可用能力。挑战在于：

- **数据稀缺**：原生语料可能仅有数 MB 到数 GB，远不足以独立训练。
- **机器翻译噪声**：用英→小语翻译扩充会引入错译、语序异常。
- **灾难性遗忘**：在小语种上训练可能损害已具备的强语言能力。
- **评估困难**：缺乏母语基准，难以判断增强是否有效。

## 二、核心原理

低资源语言增强是「在有限数据下以最小代价提升能力」的工程，常用组合拳：

1. **翻译增强（translate-train）**：将英语高质量语料机翻成目标语言，扩充训练数据；需配合翻译质量过滤（如置信度阈值、回译一致性）。
2. **继续预训练（continued pretraining）**：在通用多语基座上，用小语种语料做第二轮预训练，注入语言知识。
3. **参数高效微调（LoRA / Adapter）**：为每种语言挂独立低秩适配器，只训新增参数，隔离防遗忘、便于热插拔。
4. **数据合成（self-instruct / 跨语蒸馏）**：用强模型生成小语种指令与推理链，作为监督信号。

增强流程强调「先过滤再训练、用适配器隔离、用探针评测」。

落地时建议按「数据可得性」分级：有平行语料优先继续预训练 + 适配器；仅有单语语料则靠翻译增强 + 合成指令；几乎无数据则纯借跨语言迁移。无论哪级，都应配套母语探针（见多语言能力 / 跨语言迁移章节）验证增强是否真正生效，而非只看困惑度下降。成本上，适配器方案参数量增量极小，可在同一基座上热插拔多语言适配器，是多语言服务常用的工程形态。

## 三、形式化与数学基础

LoRA 把权重更新约束为低秩分解：

$$
W = W_0 + \Delta W = W_0 + B A, \quad B \in \mathbb{R}^{d\times r}, A \in \mathbb{R}^{r\times k}, r \ll d
$$

训练时仅优化 A、B，参数量从 d·k 降为 r·(d+k)，极大降低小语种训练成本，并因参数隔离避免影响其他语言（W_0 冻结）。

继续预训练的语料配比可用温度采样（见多语言能力章节）放大低资源曝光。合成数据质量用「强模型打分 / 回译一致性」过滤，保留高分样本。

## 四、代码实现

```python
# 为低资源语言训练独立 LoRA 适配器（示意，API 以 PEFT 文档为准）
from peft import LoraConfig, get_peft_model
from transformers import AutoModelForCausalLM

base = AutoModelForCausalLM.from_pretrained("multilingual-base")
cfg = LoraConfig(r=16, lora_alpha=32, target_modules=["q_proj", "v_proj"])
adapter = get_peft_model(base, cfg)
adapter.train(small_lang_dataset)        # 只训 LoRA 参数
adapter.save_pretrained("lora-sw")       # 隔离保存，可热插拔
```

```python
# 翻译增强的噪声过滤（回译一致性）
def keep_if_consistent(src_en, mt_sw):
    back = translate(mt_sw, "en")
    return similarity(src_en, back) > 0.8   # 一致性高才保留
```

## 五、与其他技术对比

- **全量多语继续训练**：效果扎实但贵，且易遗忘。
- **LoRA / Adapter**：便宜、可插拔、隔离防遗忘，是当前主流。
- **纯翻译数据**：扩展快但噪声大，需过滤。
- **零样本借迁移**：零成本但有性能上限（见跨语言迁移章节）。

## 六、常见误区

- **误区一：翻译数据即真数据**——含错译、语序偏移，需过滤。
- **误区二：全量微调最好**——小数据下全量微调极易过拟合与遗忘。
- **误区三：适配器越多越乱**——需路由或显式选择，避免误用。
- **误区四：无需评测**——低资源更需母语探针验证增强效果。

## 八、面试题

- 低资源语言如何低成本增强？LoRA 为何适合？
- 翻译增强的噪声如何过滤？
- 继续预训练如何避免灾难性遗忘？
- 适配器与全量微调如何取舍？

增强效果必须用可量化指标持续监控：除母语基准得分外，还应跟踪「相对英语退化率」与「跨语言一致性」，防止适配器在补强小语种时悄悄损害其他语言（负迁移）。生产环境建议对低资源语言单独配置告警阈值，并在每次基座升级后回归测试，避免增强效果随版本漂移。数据侧则建议建立「低资源语料看板」，监控语料质量与覆盖，从源头保障增强可持续。这样，低资源语言增强才能从一次性实验变为可运营的长期能力。

## 九、演进与趋势

从「翻译 + 全量训练」走向「基座 + 语言适配器 + 合成数据」的分层增强；跨语蒸馏与自我博弈生成高质量小语种数据成为热点。具体配比与收益以官方最新实验为准。

## 十、小结

低资源语言增强以「翻译扩充 + 继续预训练 + 适配器隔离 + 合成补强」组合实现低成本可用能力。核心是在有限数据下最大化增益、最小化遗忘与噪声。
