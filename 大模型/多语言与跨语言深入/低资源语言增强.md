# 低资源语言增强

> 见「多语言与跨语言深入/跨语言迁移」与「合成数据与课程学习」。

## 一、背景与挑战

小语种数据少，需增强与适配。

## 二、核心原理

翻译增强（英→小语）、继续预训练、LoRA 适配器按语微调、数据合成扩充。

## 三、关键要点

- 机器翻译噪声需过滤。
- 适配器隔离防遗忘。

## 四、代码实现

```python
adapter = lora_train(model, small_lang_data)
```

## 五、与其他对比

- 全量多语训练贵；适配器便宜。

## 六、常见误区

- 翻译数据即真——含错译。

## 七、与开源书对应

- d2l-zh: https://github.com/d2l-ai/d2l-zh
