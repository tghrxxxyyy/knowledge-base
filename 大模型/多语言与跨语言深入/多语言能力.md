# 多语言能力

> 对应 d2l-zh 与 BLOOM/LLaMA 多语工作；综述见 Workshop et al., *BBQ/多语*, 2023。

## 一、背景与挑战

模型对英语强、低资源语言弱，存在能力鸿沟。

## 二、核心原理

预训练语料语言占比决定能力；多语共享子词（SentencePiece）与跨语迁移使小语种受益，但长尾仍弱。

## 三、关键要点

- 语料配比影响均衡。
- 跨语迁移可补低资源。

## 四、代码实现

```python
for lang in langs: perf[lang] = eval(model, lang)
```

## 五、与其他对比

- 单语模型强但窄；多语广但不均。

## 六、常见误区

- 多语=各语平等——实际悬殊。
