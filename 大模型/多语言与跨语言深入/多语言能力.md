# 多语言能力

> 对应 BLOOM（BigScience）、LLaMA 多语工作，llm-course（mlabonne），及 d2l-zh 多语 NLP 章节。

## 一、背景与挑战

大语言模型在训练语料中「所见即所得」：英语、中文等高资源语言语料充足，能力强劲；而低资源语言（如斯瓦希里语、阿姆哈拉语）语料稀少，能力显著落后，形成明显的「多语言能力鸿沟」。核心挑战包括：

- **语料不均衡**：预训练语料中高资源语言占比极高，低资源语言被边缘化。
- **容量分配倾斜**：共享词表与参数更偏向高频语言，小语种表征空间被压缩。
- **评测缺失**：低资源语言缺乏基准，能力难以量化与监控。
- **文化隔阂**：即便语言相通，常识与价值观差异仍导致表现退化。

## 二、核心原理

多语言能力的来源可拆成三层：

1. **语料配比**：预训练数据中各语言占比直接决定模型对该语言的熟悉度。常用「温度采样（temperature sampling）」降低高资源语言权重、相对提升低资源语言曝光。
2. **共享子词与跨语迁移**：基于 SentencePiece 的共享词表让不同语言复用子词片段，编码器在语义空间形成跨语对齐；英语的推理能力经对齐可迁移到小语种。
3. **对齐训练**：通过平行语料、多语指令数据显式拉近跨语表征，使「同一概念」在不同语言下激活相近的向量。

实践上，多语模型常采用「先大规模多语预训练 → 多语指令微调 → 针对性补强低资源语言」的范式。

## 三、形式化与数学基础

设语言 l 的语料占比为 p_l，模型对该语言的能力 s_l 随曝光近似单调。为平衡，温度采样对原始频率 q_l 做幂次调整：

$$
p_l \propto q_l^{\alpha}, \quad \alpha \in (0, 1)
$$

α 越小越偏向均匀（低资源语言曝光提升）。跨语迁移可视为表征空间中语言的靠近程度，用平行句对 (x_l, x_{en}) 的余弦相似度衡量对齐质量：

$$
A = \frac{1}{N}\sum_{i=1}^{N} \cos\big(Enc(x_{l,i}), Enc(x_{en,i})\big)
$$

A 越高，跨语迁移越顺。能力鸿沟可量化为相对英语的退化率 ρ_l（见多语评测章节）。

## 四、代码实现

```python
# 多语语料温度采样（示意）
import math

raw_freq = {"en": 0.6, "zh": 0.2, "sw": 0.01, "am": 0.005}
alpha = 0.3  # 越小越均衡
weighted = {k: v ** alpha for k, v in raw_freq.items()}
total = sum(weighted.values())
sampled = {k: w / total for k, w in weighted.items()}
print(sampled)  # 低资源语言占比被显著放大
```

```python
# 用多语句向量检查跨语对齐
from sentence_transformers import SentenceTransformer
model = SentenceTransformer("sentence-transformers/LaBSE")  # 多语对齐模型
v_en = model.encode("Hello world")
v_zh = model.encode("你好世界")
print((v_en * v_zh).sum())  # 余弦相似度应接近 1
```

## 五、与其他技术对比

- **单语模型**：特定语言能力强但无法跨语，部署成本高。
- **多语共享模型**：一个权重服务多语，广覆盖但单语峰值弱于专门模型。
- **逐语言适配器（LoRA / language adapter）**：在共享底座上挂语言专属参数，兼顾广覆盖与单语质量，且隔离防遗忘。

## 六、常见误区

- **误区一：多语 = 各语平等**——实际能力悬殊，低资源语言常崩溃。
- **误区二：堆数据就能补齐**——若不加配比纠偏，高资源语言仍占主导。
- **误区三：翻译数据等同母语数据**——翻译文本分布偏移，补强有限。
- **误区四：语言通了文化就通了**——常识与价值观仍需本地化对齐。

## 九、演进与趋势

从「单一英语模型」到「统一多语基座」，再到「基座 + 语言适配器」的分层架构；训练策略上更强调配比纠偏、课程式逐步增加低资源曝光，以及用合成数据补强长尾语言。具体配比与收益以官方最新实验为准。

## 十、小结

多语言能力由语料配比、共享表征与对齐训练共同决定。通过温度采样纠偏、共享子词复用与适配器隔离，可在单一模型内兼顾广覆盖与低资源补强，是 LLM 普惠的关键。
