# 多语分词

> 见「词元化深入/子词切分算法对比」与「多语言与跨语言深入/多语言能力」。

## 一、背景与挑战

多语混合文本分词易失衡，小语种 token 膨胀。

## 二、核心原理

SentencePiece 免预分词、统一处理多语空白与字符；字节级 BPE 进一步消除 OOV，但非英文本更长。

## 三、关键要点

- 小语种字符多→token 多→成本高。
- 词表需多语均衡。

## 四、代码实现

```python
sp = SentencePieceProcessor(); sp.load("multi.model")
```

## 五、与其他对比

- WordPiece 偏英文；SentencePiece 多语友好。

## 六、常见误区

- 同一种模型对所有语言等价——token 数差异大。

## 七、与开源书对应
