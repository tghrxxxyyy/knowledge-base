# 多语评测

> 对应 MGSM、XNLI、FLORES-200 等基准，EleutherAI lm-evaluation-harness，以及 llm-course（mlabonne）。

## 一、背景与挑战

大语言模型的能力评估若只看英语，会掩盖其在其他语言上的真实表现。多语评测的核心挑战在于：

- **公平性盲区**：平均分高可能只是被英语拉高，低资源语言实际远低于基线。
- **翻译偏差**：把英文基准机翻成小语种再评测，会引入翻译噪声并偏离真实母语分布。
- **脚本与形态差异**：同一任务在不同语言上的难度并不一致（如屈折语、无标点语言）。
- **评测覆盖缺口**：很多低资源语言缺乏高质量、母语者撰写的基准集。

因此，多语评测的目标不是「得到一个总分」，而是刻画模型在语言维度上的能力分布与公平缺口。

## 二、核心原理

多语评测通常沿三条轴展开：

1. **能力轴**：用多语基准衡量各语言表现，如 MGSM（多语数学链式推理）、XNLI（跨语言自然语言推理）、FLORES-200（多语翻译）、MMLU 的多语变体等。
2. **一致性轴**：同一问题用不同语言表达，模型是否给出语义一致的答案（cross-lingual consistency）。
3. **公平性轴**：报告「语言间最大落差」「低资源语言相对英语的退化比例」，而非只报均值。

评测流程一般是「固定 prompt 模板 → 多语样本采样 → 按语言分别打分 → 聚合为语言维度报告」。为避免翻译污染，优先使用母语者构建或经回译校验的数据集。

## 三、形式化与数学基础

设语言集合 L，模型在语言 l 上的得分为 s_l。常用公平性度量包括：

**语言间落差（gap）**：

$$
\Delta = \max_{l \in L} s_l - \min_{l \in L} s_l
$$

**相对退化率（相对英语）**：

$$
\rho_l = \frac{s_{en} - s_l}{s_{en}}
$$

**跨语言一致性**：对同义多语问题集合 Q_l，用答案等价函数 eq 计算一致比例：

$$
C = \frac{1}{|Q|} \sum_{q \in Q} \mathbb{1}\left[ eq\big(ans(q_{l_i}), ans(q_{l_j})\big) \right]
$$

评测聚合应同时报告均值、各语言散点图与按语系分组的箱线图，避免单一标量掩盖分布。

```python
from collections import defaultdict

def evaluate_multilingual(model, tasks, langs):
    score = defaultdict(dict)
    for lang in langs:
        for task in tasks:
            # 母语样本优先，机翻样本需标记
            items = load_benchmark(task, lang, native_only=True)
            score[lang][task] = mean(model.score(item) for item in items)
    return score

def report_fairness(score, ref="en"):
    vals = list(score.values())
    gap = max(vals) - min(vals)
    rho = {l: (score["en"] - v) / max(1e-9, score["en"]) for l, v in score.items()}
    return gap, rho  # 同时输出落差与退化率
```

## 五、与其他技术对比

- **单语评测**：只看英语，掩盖语言鸿沟，无法指导多语产品落地。
- **机翻评测**：成本低但引入翻译噪声，评的是「翻译 + 推理」的复合能力。
- **母语基准**：最贴近真实分布，但构建成本高、覆盖有限。
- **lm-evaluation-harness**：把上述流程标准化、可复现，支持多任务批量评测。

## 六、常见误区

- **误区一：平均高 = 公平**——均值掩盖长尾崩溃，必须报告语言维度分布。
- **误区二：机翻基准可信**——翻译错误会被误算为模型错误。
- **误区三：一次评测定优劣**——评测集偏差、prompt 语言敏感都会显著影响结果。
- **误区四：忽略脚本差异**——同一模型在拉丁字母与阿拉伯字母语言上表现可能差异巨大。

## 九、演进与趋势

从「英语为主 + 少量翻译集」走向「覆盖数百语言的母语基准」（如 FLORES-200、多语 MMLU）；评测维度从准确率扩展到推理链一致性、文化适配度与安全性差异。自动化多语评测（以 LLM 为评判）与社区共建母语集是主要方向，具体基准版本与覆盖以官方最新文档为准。

## 十、小结

多语评测的本质是「用语言维度揭示能力分布」。只有同时报告各语言得分、落差与一致性，才能真实判断一个模型是否具备普惠的多语言能力。
