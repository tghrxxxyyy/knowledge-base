# 多语评测

> 见「模型评测指标深入」与「多语言与跨语言深入/多语言能力」。

## 一、背景与挑战

需跨语言统一评测衡量公平性。

## 二、核心原理

用多语基准（如 MGSM、XNLI）评各语表现，看差距与一致性。

## 三、代码实现

```python
for lang in langs: score[lang] = eval(model, task, lang)
```

## 四、关键要点

- 翻译评测需防机翻偏差。
- 需报告语言差距。

## 五、与其他对比

- 单语评测掩盖不公平。

## 六、常见误区

- 平均高=公平。

## 七、与开源书对应

- MGSM; XNLI; llm-course: https://github.com/mlabonne/llm-course

## 九、演进

单语 → 多语 → 公平性报告。

## 十、小结

评测揭示语言鸿沟。
