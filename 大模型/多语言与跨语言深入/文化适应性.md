# 文化适应性

> 对应多语本地化对齐研究、LLaMA / BLOOM 区域化工作，及 llm-course（mlabonne）本地化章节。

## 一、背景与挑战

即便模型学会了某种语言的「词句」，其常识、价值观与行为模式仍常以英语 / 西方文化为默认基底。直接把英语模型用于其他文化语境会出现：

- **常识错位**：节日、饮食、礼仪、家庭观念等文化特定常识缺失或被错误泛化。
- **价值冲突**：对敏感社会议题的立场不符合目标文化的主流价值观与法规。
- **表达习惯违和**：敬语、称呼、正式 / 非正式语气与本地习惯不符。
- **合规性风险**：部分内容在本土监管框架下不被允许。

因此，「语言本地化」只是第一步，「文化适应性」才是本地化落地的深层要求。

## 二、核心原理

文化适应性的提升路径分为三层：

1. **数据层**：用本地母语者撰写的指令数据、本地常识语料与本地评测集替换或补充英语数据，使模型接触真实文化分布。
2. **对齐层**：以本地价值观为目标的监督微调（SFT）与偏好对齐（RLHF / DPO），让模型输出符合本地习俗与规范。
3. **评测层**：构建文化探针（cultural probe）——针对特定文化情境设计问答，检验模型是否给出符合本地预期的回答。

关键是「翻译文本不够，必须文化微调」：机翻文本保留的是源文化语境，无法教会模型目标文化的隐含常识。

## 三、形式化与数学基础

可将文化适应建模为对齐目标。设本地偏好数据为 (x, y_w, y_l)，其中 y_w 符合本地文化、y_l 不符合。DPO 风格目标为最大化符合本地偏好的概率：

$$
\mathcal{L} = -\log \sigma\Big(\beta \log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}\Big)
$$

文化适应度可用文化探针通过率衡量：

$$
C_{cult} = \frac{1}{N}\sum_{i=1}^{N} \mathbb{1}[ans(x_i) \in Acceptable_i]
$$

其中 Acceptable_i 为该文化下可接受的答案集合，需由本地母语者界定。

## 四、代码实现

```python
# 文化自适应：用本地指令数据做偏好对齐（示意）
from datasets import load_dataset

local_sft = load_dataset("local_culture_sft")     # 母语者撰写
local_pref = load_dataset("local_prefs")          # (prompt, chosen, rejected)

# 先做 SFT 注入文化常识
model.train(local_sft)
# 再用本地偏好做对齐，避免价值冲突
model.align(prefs=local_pref, method="dpo")
```

```python
# 文化探针评测
probes = [
    {"q": "春节最重要的家庭活动是什么？", "acceptable": ["团圆饭", "守岁"]},
]
score = mean(1 if ans(p["q"]) in p["acceptable"] else 0 for p in probes)
```

## 五、与其他技术对比

- **仅翻译文本**：保留源文化语境，无法解决常识与价值错位。
- **通用对齐（英语偏好）**：以西方价值观为准，可能与本地冲突。
- **本地文化微调 + 本地对齐**：最贴合，但需本地数据与红队投入。
- **区域化独立模型**：隔离彻底但维护成本高，适合监管要求强的场景。

## 六、常见误区

- **误区一：语言对了 = 文化对了**——语言是外壳，常识与价值是内核。
- **误区二：机翻评测集可信**——翻译改写会掩盖文化偏差。
- **误区三：一次对齐永久有效**——社会规范随时间演变，需持续更新。
- **误区四：忽略本地红队**——未经过本土安全测试易踩合规雷区。

## 九、演进与趋势

从「翻译 + 通用对齐」走向「母语数据 + 本地偏好对齐 + 文化红队」的完整本地化链路；多文化 MoE（不同专家路由到不同文化）是前沿探索。监管驱动下的区域合规对齐将更受重视，具体框架以官方最新文档为准。

## 十、小结

文化适应性是本地化落地的深层维度。它要求用母语数据、本地偏好对齐与文化探针持续校准，使模型不仅「说本地话」，更「懂本地事」。
