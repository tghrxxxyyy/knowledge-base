# 跨语言迁移

> 见「多语言与跨语言深入/多语言能力」与「预训练/持续预训练」。

## 一、背景与挑战

高资源语言的知识能否迁移到低资源语言？

## 二、核心原理

编码器共享语义空间，英语推理能力经对齐迁移到小语种；指令/思维链可跨语泛化。

## 三、关键要点

- 对齐质量决定迁移。
- 某些任务迁移强（逻辑）、某些弱（文化）。

## 四、代码实现

```python
# 英语 CoT 示例提升小语种表现
prompt = translate(exemplar_en, target_lang)
```

## 五、与其他对比

- 直接小语种训练弱；借英语迁移更强。

## 六、常见误区

- 迁移万能——文化特定任务仍弱。

## 七、与开源书对应
