# 特征分裂与规模

> 对应 Templeton et al., *Scaling Monosemanticity*, 2024（Anthropic）。

## 一、背景与挑战

随模型与字典规模增大，特征如何变化？是否出现更细粒度的"特征分裂"？

## 二、核心原理

实证表明：规模增大后，原本粗特征会分裂为更具体的子特征（如"颜色"→具体色）；同时出现跨语言/跨模态的抽象特征。单义性随规模与字典维提升。

## 三、数学形式

设特征粒度随字典维 $k$ 增大：单义率 $M(k)$ 单调递增，特征数 $N \propto k^\alpha$。

## 四、代码实现

```python
for k in [16,64,256]*d:
    sae = train_sae(acts, dict_mult=k)
    print(k, monosemanticity(sae))
```

## 六、常见误区

- 认为更大字典一定更好；边际收益递减且成本陡增。
- 忽略特征分裂带来的解释目录膨胀。

## 八、面试题

## 九、演进
