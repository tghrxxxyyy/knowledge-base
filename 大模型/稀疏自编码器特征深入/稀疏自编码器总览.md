# 稀疏自编码器总览

> 对应 Cunningham et al., *Sparse Autoencoders Find Highly Interpretable Features in Language Models*, ICLR 2024。

## 一、背景与挑战

叠加（superposition）使神经元多义，难以解读；稀疏自编码器（SAE）试图从叠加中解耦出单义特征。

## 二、核心原理

SAE 在激活 $x$ 上训练：编码器映射到高维稀疏隐码 $f=\sigma(W_{enc}x+b)$，解码器重建 $\hat x = W_{dec} f$。高维+稀疏迫使每个隐单元学习一个单义方向。

## 三、数学形式

损失 $\mathcal L = \|x - W_{dec}f\|_2^2 + \lambda \|f\|_1$，其中 $f_i \ge 0$ 为稀疏特征；$\lambda$ 控稀疏度。

## 四、代码实现

```python
def sae_loss(x, enc, dec, lam=1e-3):
    f = relu(enc(x))
    recon = dec(f)
    return ((x - recon)**2).mean() + lam * f.mean()
```

## 五、与其他对比

- 与 词典特征与单义性深入 同源：SAE 是解耦叠加的工程化手段。
- 与 层级表征语义结构深入 衔接（重建单义方向）。

## 六、常见误区

- 误以为 SAE 特征就是"真"特征；实为可解释近似，可能分裂/合并。
- 过高字典维度爆炸成本。

- SAE 为何能解耦特征？答：高维稀疏隐空间给每特征独立方向，L1 促单义，重建保信息。

## 九、演进

叠加理论 → Toy模型 → 大模型 SAE（Cunningham 24）。

## 十、小结

SAE 是当下最主流的可解释特征提取器，把叠加拆为单义方向。
