# 字典学习与叠加

> 对应 Elhage et al., *Toy Models of Superposition*, 2022。

## 一、背景与挑战

特征数常超过维度，模型被迫以叠加表示多特征，SAE 是其逆过程（字典学习）。

## 二、核心原理

Toy 模型显示：当特征数 $n$ 大于维度 $d$ 且特征稀疏时，模型用叠加把多个特征压入同空间，使单个神经元多义；字典学习可近似恢复原始特征。

## 三、数学形式

叠加表示 $x = \sum_i a_i f_i + \epsilon$，SAE 学 $f_i$ 与系数 $a_i$；恢复误差随稀疏度上升而降。

## 四、代码实现

```python
# toy superposition: n>d 个特征随机方向叠加
F = randn(d, n); F /= F.norm(0)  # 特征方向
x = (A @ F.T) if sparse(A) else ...
```

## 五、与其他对比

- 与 词典特征与单义性深入 同根（叠加理论）。
- 与 稀疏自编码器总览 衔接（SAE 为解耦器）。

## 六、常见误区

- 以为神经元=特征；叠加下二者不等。
- 字典维度不足则无法解耦全部特征。
