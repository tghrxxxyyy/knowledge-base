# SAE特征可解释性

> 对应 Cunningham et al., ICLR 2024；Templeton et al., *Scaling Monosemanticity*, 2024。

## 一、背景与挑战

解耦出的特征是否人类可解读？需定量与定性评估。

## 二、核心原理

人工检查显示 SAE 特征常对应清晰概念（如" DNA 序列""负面情绪""HTTP 协议"）；用特征激活最大值样本、自动解释器（用 LLM 描述）规模化标注。

## 三、数学形式

可解释性可用"激活最大值文本一致性"或自动解释器打分；单义性随字典增大与模型规模提升。

## 四、代码实现

```python
top_tokens = activations[:, fi].topk(20).indices
descriptions = [llm_describe(tok) for tok in top_tokens]
print(cluster(descriptions))  # 应聚成单一概念
```

## 五、与其他对比

- 与 词典特征与单义性深入 衔接（目标即单义）。
- 与 规模与可解释性关系深入 共享 Templeton 24 结论。

## 六、常见误区

- 把自动解释器描述当真理；可能幻觉。
- 认为所有特征都单义，仍有噪声特征。
