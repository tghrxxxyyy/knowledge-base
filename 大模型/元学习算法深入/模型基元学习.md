# 模型基元学习

> 见「元学习算法深入/元学习算法总览」；Santoro et al., *MANN*, 2016；记忆增强。

## 一、背景与挑战

能否让模型用「记忆」直接条件化新任务？

## 二、核心原理

模型基（model-based）元学习用一个能读外部记忆/注意历史样本的元模型（如 MANN、记忆增强网络），在前向时直接利用支撑集，无需显式梯度更新。本质把「学习」压缩进一次前向。

## 三、关键要点

- 推理快（无内循环）。
- 记忆容量与寻址是关键。

## 四、代码实现

```python
out = meta_net(x, support_mem)  # 读记忆
```

## 五、与其他对比

- 优化/度量需任务内计算；模型基一次前向。

## 六、常见误区

- 模型基不需训练——仍需元训练。
