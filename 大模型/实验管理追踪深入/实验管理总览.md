# 实验管理总览

> 对应 d2l-zh 工程章；MLflow / Weights & Biases 实践。

## 一、背景与挑战

实验多、超参杂、结果散，难以比较与回溯。

## 二、核心原理

实验管理平台统一记录：配置（超参）、指标（loss/acc）、产物（模型/图）、代码版本、环境。支持对比、可视化、复现。MLflow 开源轻量；W&B 云协作强。

## 三、关键要点

- 每次运行唯一 ID 便于溯源。
- 指标需统一命名便于对比。

## 四、代码实现

```python
import mlflow
mlflow.start_run(); mlflow.log_param("lr", 1e-3)
mlflow.log_metric("loss", loss)
```
