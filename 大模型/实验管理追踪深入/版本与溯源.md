# 版本与溯源

> 见「实验管理追踪深入/实验管理总览」与「可复现性工程深入/数据与版本管理」。

## 一、背景与挑战

实验对应哪份代码/数据/配置，需可溯。

## 二、核心原理

每次运行绑定 git commit、数据版本、依赖锁、随机种子，形成「实验谱系」。产物（模型权重）存对象存储并打 tag，可回滚到任意实验状态。

## 三、关键要点

- 四要素（代码/数据/配置/种子）齐备才可逆。
- 模型 artifact 带实验 ID。

## 四、代码实现

```python
mlflow.log_artifact("model.pt")
mlflow.set_tag("git_sha", sha)
```

## 五、与其他对比

- 无溯源=黑箱；有溯源=白盒。

## 六、常见误区

- 只存模型——不知怎么来的。

## 十、小结
