# 梯度检查点总览（Gradient Checkpointing）

> 对应 Chen et al., *Training Deep Nets with Sublinear Memory Cost*, 2016（checkpointing）；NeurIPS。

## 一、背景与挑战

反向传播需保存每层激活，显存随层数线性增长；超深网络单卡放不下；检查点以重计算换显存。

## 二、核心原理

前向只保存部分"检查点"激活，其余丢弃；反向时从最近检查点重新前向计算到所需层，得到被丢弃的激活。牺牲约 33% 计算换显存从 $O(N)$ 降到 $O(\sqrt N)$。

## 三、数学形式

显存峰值约从 $N$ 个激活降到 $\approx 2\sqrt{N}$（最优 checkpoint 间隔）；重计算增加一次前向成本。

## 四、代码实现

```python
from torch.utils.checkpoint import checkpoint
out = checkpoint(layer, x)   # 不存中间激活，反向时重算
```

## 五、与其他对比

- 与 显存最优调度深入（整体显存治理）是子集关系。
- 与 分布式优化器深入（ZeRO 减状态）互补减不同部分。

## 六、常见误区

- 误以为零成本（实际增计算）。
- 在已显存充足的层检查点反而拖慢。

## 八、面试题

- 检查点为何省显存？答：只存少量锚点激活，反向时局部重算其余，把显存换计算。

## 九、演进

全存激活 → 均匀检查点 → 最优间隔/选择性。

## 十、小结

梯度检查点以可控重计算大幅降显存，是深模型训练标配。
