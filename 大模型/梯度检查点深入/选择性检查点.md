# 选择性检查点（Selective Checkpointing）

> 对应 现代框架的自定义检查点（如 Transformer 只对注意力/大激活层查点）；与 显存最优调度深入 衔接。

## 一、背景与挑战

并非所有层激活都贵；对关键大激活（如注意力 softmax、大矩阵乘结果）定点检查点，收益最高。

## 二、核心原理

按每字节激活的"反向重算成本"排序，优先对高体积/高重算比的张量做检查点；其余正常保存。

## 三、数学形式

性价比 $\rho_i = a_i / t_i^{recomp}$（体积/重算时）；优先查点高 $\rho$ 者直至显存达标。

## 四、代码实现

```python
def attn(x):
    s = checkpoint(lambda h: softmax(h@Wq@Wk.T), x)  # 仅查点注意力
    return s @ Wv
```

## 五、与其他对比

- 与 重计算策略（均匀）比更精细高效。
- 与 显存最优调度深入（整体调度）互补。

## 六、常见误区

- 选错层（小激活）致省显存少却增计算。
- 破坏计算图依赖致反向异常。

## 八、面试题

- 选择性检查点挑哪些层？答：优先体积大、重算成本相对低的激活，单位代价省显存最多。

## 九、演进

均匀 → 体积优先 → 性价比驱动。

## 十、小结

选择性检查点把预算花在刀刃上，是精细显存优化手段。
