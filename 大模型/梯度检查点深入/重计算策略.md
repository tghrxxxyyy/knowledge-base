# 重计算策略（Recomputation）

> 对应 检查点间隔选择；与 梯度检查点深入 总览衔接。

## 一、背景与挑战

检查点越多越省显存但越慢；需平衡间隔以匹配显存预算与吞吐。

## 二、核心原理

把网络分段，每段首层输入做检查点；间隔 $k$ 决定每 $k$ 层存一次。等显存预算下，最优间隔使峰值最小（约 $\sqrt N$）。

## 三、数学形式

设层数 $N$、检查点数 $m$，峰值激活数 $\approx \frac{N}{m}+m$；最小化得 $m\approx\sqrt N$。

## 四、代码实现

```python
def block(x):
    for layer in layers: x = layer(x)
    return x
x = checkpoint(block, x)    # 每块仅存输入
```

## 五、与其他对比

- 与 选择性检查点（只查贵层）互补。
- 与 显存最优调度深入（整体规划）配合。

## 六、常见误区

- 间隔过小省显存有限，过大重算过多。
- 跨不可微操作检查点致反向失败。
