# 深度早退机制

> 对应 Depth-Adaptive Transformer（Elbayad et al., 2020）。

## 一、背景与挑战

如何在层间安全插入决策点并保训练稳定。

## 二、核心原理

每层后接轻量输出头，训练时对所有早退点加损失（加权），推理依阈值择首个达标层；用尺缩使各层分布可比。

## 三、数学形式

总损 $\mathcal L=\sum_{l=1}^L w_l \mathcal L_l$；尺度 $h_l = \frac{1}{\sqrt{l}} h_l$ 类归一。

## 四、代码实现

```python
losses = [criterion(head_l(h_l), y) * w[l] for l in range(L)]
loss = sum(losses)
```

## 五、与其他对比

- 与 FastBERT/DeeBERT 同思想不同头结构。
- 与 动态层数深入 衔接。

## 六、常见误区

- 仅训末层头，早退点弱。
- 权重未随层调。

## 八、面试题

- 如何训多早退点？答：对各层头加权联合损失，使每层都能独立输出。

## 九、演进

单头 → 多头联合 → 自适应权重。

## 十、小结

深度早退靠层间多头联合训练，实现任意层可停。
