# 早退推理实现（DeeBERT/FastBERT）

> 对应 Xin et al., 2020；Liu et al., 2020。

## 一、背景与挑战

在现有 Transformer 注入早退头并高效推理。

## 二、核心原理

DeeBERT 在 BERT 层间插分类头+信心；FastBERT 用分支器（branch）替头；推理逐层判停。

## 三、数学形式

分支器输出 $b_l(h)$ 置信；停当 $b_l\ge\tau$；否则继续。

## 四、代码实现

```python
class EarlyExitBERT(nn.Module):
    def forward(self, x, tau=0.8):
        for l, blk in enumerate(self.blocks):
            h = blk(h)
            if self.branch[l](h) >= tau: return self.cls[l](h)
```

## 五、与其他对比

- 与 动态层数深入 实现相近。
- 与 约束解码深入 同为推理期控制。

## 六、常见误区

- 分支器与分类头未协同训。
- 推理未缓存中间激活。
