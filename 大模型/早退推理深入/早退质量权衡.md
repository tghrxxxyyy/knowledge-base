# 早退质量权衡

> 对应精度-延迟折中；与 模型评测指标深入 衔接。

## 一、背景与挑战

早退省算力但可能伤难样本精度，需权衡。

## 二、核心原理

调阈值沿帕累托前沿移动；或用“难样本不早退”策略（路由）保精度。

## 三、数学形式

帕累托点 $(\Delta(\tau), 1/S(\tau))$；选满足 $\Delta\le\epsilon$ 的最大 $S$。

## 四、代码实现

```python
for tau in linspace(0.5, 0.99, 10):
    plot(eval(tau))
```

## 五、与其他对比

- 与 动态计算实践深入 共享权衡。
- 与 推理经济成本深入 衔接。

## 六、常见误区

- 阈值一味低求快掉点。
- 忽视不同类难度差异。
