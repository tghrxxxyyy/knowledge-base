# 早退推理总览

> 对应 Elbayad et al., *Depth-Adaptive Transformer*, 2020；Xin et al., *DeeBERT*, 2020；Liu et al., *FastBERT*, 2020。

## 一、背景与挑战

深层模型对简单样本也走满全部层，算力浪费；早退在置信足够时提前输出。

## 二、核心原理

在若干层后插入分类/输出头，达置信阈值即停，困难样本走更深，实现样本自适应深度。

## 三、数学形式

早退层 $l^*=\min\{l: \max P_l(y) \ge \tau\}$；样本算力 $\approx l^*$。

## 四、代码实现

```python
for l in range(L):
    h = layer_l(h)
    if conf(head_l(h)) >= tau: return head_l(h)
```

## 五、与其他对比

- 与 动态计算深入 同属自适应算力。
- 与 推理成本深入 直接降延迟。

## 六、常见误区

- 阈值过低致质量崩。
- 早退头未联合训致偏。

## 八、面试题

- 早退为何省算力？答：简单样本提前停，仅难样本用深层，平均层数下降。

## 九、演进

固定深 → 层间头早退 → 联合训练。

## 十、小结

早退以置信阈值实现样本自适应深度，显著降平均算力。
