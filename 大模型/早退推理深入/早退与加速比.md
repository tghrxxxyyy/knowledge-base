# 早退与加速比

> 对应早退加速实测；与 推理成本深入 衔接。

## 一、背景与挑战

需量化早退带来的真实延迟/能耗收益。

## 二、核心原理

平均退出层 $\bar l = \frac{1}{N}\sum l^*_i$；加速比 $\approx L/\bar l$，受简单样本占比影响。

## 三、数学形式

加速 $S = L / \mathbb E[l^*]$；质量损失 $\Delta = \text{acc}_{full}-\text{acc}_{early}$。

## 四、代码实现

```python
avg_layer = mean(exit_layers)
speedup = L / avg_layer
```

## 五、与其他对比

- 与 动态计算深入 共享加速度量。
- 与 KV缓存优化深入 可叠加。

## 六、常见误区

- 仅看平均层忽略尾延迟。
- 难样本比例高时收益小。
