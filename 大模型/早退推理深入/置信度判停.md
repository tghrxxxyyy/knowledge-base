# 置信度判停

> 对应早退置信度设计；与 早退推理总览 衔接。

## 一、背景与挑战

阈值定得不慎，要么省不下来要么掉精度。

## 二、核心原理

以 softmax 最大概率或熵作置信；高概率/低熵即停；可用校准（temperature scaling）使置信可信。

## 三、数学形式

置信 $c=1-\mathbb H(P)$ 或 $c=\max P$；停当 $c\ge \tau$。

## 四、代码实现

```python
p = F.softmax(head(h), -1)
if p.max() >= tau: return p.argmax()
```

## 五、与其他对比

- 与 模型校准深入（若新增）共享校准。
- 与 动态计算深入 同用置信。

## 六、常见误区

- 未校准的 max-prob 不可信。
- 固定阈值跨分布失效。

## 八、面试题

- 如何设早退阈值？答：在验证集按目标精度/延迟曲线选 $\tau$，并先校准置信。

## 九、演进

固定 τ → 校准后 τ → 自适应 τ。

## 十、小结

置信判停是早退开关，需校准与按曲线调参。
