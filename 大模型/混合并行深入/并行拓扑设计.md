# 混合并行拓扑设计

> 对应 Megatron-LM 进程组设计；Narayanan et al., 2022。

## 一、背景与挑战

如何把三维映射到物理集群，使通信走最快链路。

## 二、核心原理

TP 放同节点 NVLink（高带宽），PP 沿节点内/间层序，DP 跨节点聚合；进程组嵌套：先 TP 组内、再 PP、最后 DP，使高频通信局部化。

## 三、数学形式

节点数 $N$、每节点 $G$ 卡；令 $TP\le G$（机内），$PP$ 沿节点，$DP$ 跨节点。

## 四、代码实现

```python
tp_g  = init_group(range(tp))            # 机内 NVLink
pp_g  = init_group(range(pp))            # 层序
dp_g  = init_group(range(dp))            # 跨节点
```

## 五、与其他对比

- 与 通信压缩深入 配合降 DP 跨节点量。
- 与 序列并行深入 同属布局优化。

## 六、常见误区

- TP 跨节点致带宽崩。
- 进程组重叠混乱。

## 八、面试题

- 为何 TP 放机内？答：TP 通信最频繁，需 NVLink 高带宽低延迟。

## 九、演进

无拓扑 → 按带宽分层 → 自动搜索。

## 十、小结

拓扑设计让高频通信走快链路，是混合效率关键。
