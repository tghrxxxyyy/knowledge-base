# 混合并行总览

> 对应 Narayanan et al., 《Efficient Large-Scale Language Model Training on GPU Clusters Using Megatron-LM》, 2022（3D 并行）。

## 一、背景与挑战

单一并行维度无法同时解决显存、算力、通信，需三维组合。

## 二、核心原理

3D 并行 = 数据并行(DP) × 张量并行(TP) × 流水线并行(PP)：TP 切层内、PP 切层间、DP 复制并聚合；总卡数 $=DP\cdot TP\cdot PP$。

## 三、数学形式

进程网格 $(DP, PP, TP)$；每卡模型片 $\approx \frac{\phi}{TP\cdot(\text{ZeRO})}$；总算力随卡近线性。

## 五、与其他对比

## 六、常见误区

- 三维乘积不等于物理卡数配置错。
- 维度分配未考虑通信拓扑。

## 八、面试题

- 3D 并行三维各切什么？答：TP 切层内权重、PP 切层间、DP 复制聚合并行。

## 九、演进

DP → DP+TP → DP+TP+PP(3D)。

## 十、小结

混合并行组合三维，是万卡训大模型的通用方案。
