# 混合并行部署实践

> 对应大模型训练集群实践；Narayanan et al., 2022。

## 一、背景与挑战

从配置到稳定训千亿模型，需工程调优。

## 二、核心原理

先按显存定 TP/PP，再按卡数定 DP；调微批使 PP 气泡小；开重计算与 ZeRO；监控 MFU 与 OOM；逐步放大。

## 三、数学形式

约束 $DP\cdot TP\cdot PP = W$（总卡）；显存 $< $ 单卡容量；MFU 目标阈值。

## 四、代码实现

```python
assert tp*pp*dp == world_size
while oom: pp += 1; reconfigure()
```

## 五、与其他对比

- 与 异步训练深入（同步 vs 异步）是不同范式。
- 与 专家并行深入 可加 MoE。

## 六、常见误区

- 一步到位配大模型致难调试。
- 忽视故障恢复（checkpoint 频繁）。

## 八、面试题

- 如何定三维配置？答：显存定 TP/PP、卡数定 DP，调微批降气泡。

## 九、演进

手工 → 搜索工具 → 自动并行。

## 十、小结

混合并行部署需按显存/拓扑逐步调优，监控 MFU 与稳定。
