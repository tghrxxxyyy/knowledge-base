# 混合并行通信重叠

> 对应通信计算重叠；Narayanan et al., 2022。

## 一、背景与挑战

三维并行通信种类多（all-reduce/all-gather/all-to-all），需隐藏。

## 二、核心原理

把梯度桶/激活分块，计算同时异步通信；TP 的 all-reduce 与 GEMM 重叠、PP 的激活传输与计算重叠、DP 梯度桶与反向重叠。

## 三、数学形式

有效通信时间 $\approx \max(计算, 通信)$ 当重叠完美；气泡降至接近 0。

## 四、代码实现

```python
work = dist.all_reduce(bucket, async_op=True)
compute_next_layer()                      # 重叠
work.wait()
```

## 五、与其他对比

- 与 通信压缩深入 正交（压缩降量、重叠降延迟）。
- 是 混合并行深入 效率核心。

## 六、常见误区

- 桶太大致重叠窗口短。
- 同步点未消除仍空等。

## 八、面试题

- 如何隐藏三维通信？答：分块异步通信，与 GEMM/反向计算重叠。

## 九、演进

无重叠 → 桶重叠 → 全分块重叠。

## 十、小结

通信重叠把三维通信隐藏于计算，是达成高 MFU 的关键。
