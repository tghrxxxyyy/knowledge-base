# 轴向与窗口注意力对比

> 对应两种局部/分解稀疏方案。

## 一、背景与挑战

二者都降复杂度，但分解方式不同，需按数据形状选型。

## 二、核心原理

窗口：局部块内注意，块间需移位/层次打通。轴向：沿整条线注意，天然长程但仅单维。

## 三、数学形式

窗口感受野 $m^2$（局部）；轴向感受野一整轴（长但单向）。

## 四、代码实现

```python
x = window_attn(x) if local else axial_attn(x)
```

## 五、与其他对比

- 窗口更适合需局部性的视觉任务；轴向适合细长/高维网格。
- 二者可组合（轴向窗口）。

## 六、常见误区

- 混用时不匹配感受野导致训练不稳。
- 忽视轴向顺序的语义影响。

## 八、面试题

- 选轴向还是窗口？答：高维/需长轴向依赖选轴向；强局部性选窗口。

## 九、演进

二者独立 → 组合（轴向窗口注意力）。

## 十、小结

轴向与窗口是稀疏注意力的两条路线，可互补组合。
