# 轴向分解原理

> 对应 Axial Attention 理论。

## 一、背景与挑战

多维张量展平后序列过长，需保持结构地降复杂度。

## 二、核心原理

在每一轴独立做注意力，保持其他轴不变；多头可在不同轴分配以捕获不同方向依赖。

## 三、数学形式

沿轴 $d$：$A^{(d)}_{ij}=\text{softmax}(Q_i K_j^\top/\sqrt c)V_j$，对固定其他索引 $i_{\neq d}$ 计算。

## 四、代码实现

```python
q = x.transpose(d, -1)        # 把轴 d 放末位
out = attn(q)                  # 对该轴
x = out.transpose(d, -1)
```

## 五、与其他对比

- 比全连接全局省；比窗口更长程（整轴）。
- 与 旋转位置编码深入 兼容（可加轴向位置）。

## 六、常见误区

- 轴向分解顺序影响结果；需实验或固定。
- 高维下轴数多，层数需足够覆盖交叉。

## 八、面试题

- 为什么轴向分解能近似全局？答：多轴连续作用使任意两位置经若干轴间接相连。

## 九、演进

两轴 → 多轴（视频三维）→ 可学习分解。

## 十、小结

轴向分解是结构化稀疏注意力的优雅实现，天然匹配网格数据。
