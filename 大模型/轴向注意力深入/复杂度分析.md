# 轴向注意力复杂度

> 对应量化分析。

## 一、背景与挑战

证明轴向相对全局的节省，指导高维任务。

## 二、核心原理

单轴注意力复杂度 $O(L \cdot N)$（$L$ 为轴长，$N$ 总 token）；多轴叠加仍远小于 $O(N^2)$。

## 三、数学形式

2-D：$O(H W (H+W))$ 近似 $O(N\sqrt N)$；3-D：$O(N\cdot L_{max})$。

## 四、代码实现

```python
cost = sum(L_d * N for L_d in (H, W))   # 远小于 N*N
```

## 五、与其他对比

- 与 窗口注意力深入 同线性级但感受野更长（整轴）。
- 与 稀疏注意力深入（若新增）互补。

## 六、常见误区

- 误以为轴向完全等价全局；只是近似。
- 高维下多轴叠加仍需管理层数。

## 七、与开源书对应

## 八、面试题

- 轴向 vs 窗口复杂度差异？答：轴向整轴 $O(N\sqrt N)$，窗口 $O(N m^2)$，前者感受野更长。

## 九、演进

两轴 → 多轴 → 混合稀疏。

## 十、小结

轴向注意力复杂度随维数线性增长，是高分/高维数据的可扩展选择。
