# 轴向注意力实践与变体

> 对应工程实现经验。

## 一、背景与挑战

实现需处理轴选择、内存布局与位置编码。

## 二、核心原理

关键：把目标轴移到连续维度以用高效注意力 kernel；配合轴向位置编码。

## 三、数学形式

轴向位置可对每个轴独立编码（如高轴/宽轴各自 1-D RoPE）。

## 四、代码实现

```python
x = x.permute(d, *others)      # 轴置前
x = axial_attn_over_seq(x)
```

## 五、与其他对比

- 与 注意力数学基础 共享 Q/K/V 投影。
- 与 混合精度训练深入 交叉（长序列精度）。

## 六、常见误区

- 频繁 transpose 致内存碎片；应规划布局。
- 轴向位置编码缺失致方向混淆。
