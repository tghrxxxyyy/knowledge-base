# 轴向注意力总览

> 对应 Ho et al., *Axial Attention*, 2019；Wang et al., *Axial-DeepLab*, 2020。

## 一、背景与挑战

高维数据（图像/视频/体素）token 数巨大，全局注意力不可行；轴向注意力沿单维度计算。

## 二、核心原理

把多维注意力分解为沿各轴的 1-D 注意力（如高轴、宽轴），每步只在一维上做，复杂度由 $O(N^2)$ 降至 $O(N\sqrt N)$ 级。

## 三、数学形式

对 2-D 特征 $X\in\mathbb R^{H\times W}$，先沿高轴行注意、再沿宽轴列注意，组合近似全局。

## 四、代码实现

```python
x = x + attn_dim(x, dim=1)   # 沿高
x = x + attn_dim(x, dim=2)   # 沿宽
```

## 五、与其他对比

- 与 窗口注意力深入 比，轴向沿整条线而非局部块，感受野更长。
- 与 高效注意力深入 同属分解式稀疏注意力。

## 六、常见误区

- 以为两次 1-D 注意力等价于一次 2-D 全局；仅为近似。
- 轴向顺序可能影响表达。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 轴向注意力复杂度？答：各轴 $O(N\cdot L)$（L 为该轴长），远低于全局 $O(N^2)$。

## 九、演进

全局 → 轴向分解 → 与窗口/稀疏结合。

## 十、小结

轴向注意力以维度分解获得近似全局且线性级复杂度，适合高维数据。
