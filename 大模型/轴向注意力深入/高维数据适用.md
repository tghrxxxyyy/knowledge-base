# 轴向注意力高维适用

> 对应视频/医学影像/遥感等。

## 一、背景与挑战

3-D 及以上数据 token 爆炸，普通注意力不可用。

## 二、核心原理

扩展到时间/深度轴：沿 (T,H,W) 三维分别做 1-D 注意，复杂度 $O(N\cdot L)$ 每轴。

## 三、数学形式

体素 $X\in\mathbb R^{T\times H\times W}$，三轴注意力叠加重建长程时空依赖。

## 四、代码实现

```python
for d in (1,2,3):
    x = axial_attn(x, dim=d)
```

## 五、与其他对比

- 与 窗口注意力深入 比，轴向覆盖整条线（更长程）。
- 与 视频生成深入（若新增）衔接。

## 六、常见误区

- 直接对 3-D 展平；应轴向分解。
- 忽视轴向顺序对时序建模的影响。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 视频为何适合轴向注意力？答：时空维度可分别降维，避免立方级复杂度。

## 九、演进

图像轴向 → 视频时空轴向 → 可变形轴向。

## 十、小结

轴向注意力天然扩展到高维，是体素/视频建模的实用方案。
