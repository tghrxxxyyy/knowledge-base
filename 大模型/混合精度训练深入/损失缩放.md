# 损失缩放 Loss Scaling

> 见「混合精度训练深入/混合精度总览」与「FP16与BF16区别」；fp16 专用。

## 一、背景与挑战

fp16 梯度太小会下溢为 0。

## 二、核心原理

**Loss Scaling**：反向前把 loss 乘大常数 S，使梯度同比例放大避免下溢；反向后再除 S 还原。可用固定或动态缩放（监测溢出自动调 S）。bf16 因范围大通常不需。

## 三、数学形式

`g' = S·g`，更新前 `g = g'/S`。

## 四、代码实现

```python
scaler.scale(loss).backward(); scaler.step(opt); scaler.update()
```

## 五、关键要点

- 仅 fp16 需要；bf16 免。
- 动态缩放自适应。

## 六、与其他对比

- bf16 无此步骤；fp16 必做。

## 七、常见误区

- bf16 也要 scaling——不必。
