# 混合精度与通信

> 见「混合精度训练深入/混合精度总览」与「分布式训练」；通信也省。

## 一、背景与挑战

分布式训练通信量大，能否用低精度通信？

## 二、核心原理

梯度/激活可用 fp16/bf16 在节点间传输，省一半以上带宽；优化器状态可 fp32。梯度压缩（如 1-bit Adam、Top-k）进一步省通信。需注意低精度通信的误差累积。

## 三、关键要点

- 通信常是分布式瓶颈。
- 梯度压缩需防误差。

## 四、代码实现

```python
grad_fp16 = grad.half(); dist.all_reduce(grad_fp16)
```

## 五、与其他对比

- fp32 通信准但慢；低精度快。
