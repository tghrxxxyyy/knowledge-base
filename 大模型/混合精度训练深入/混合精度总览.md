# 混合精度训练总览

> 对应 d2l-zh 与 Micikevicius et al., *Mixed Precision*, 2018；提速省显存关键。

## 一、背景与挑战

fp32 训练慢且吃显存，能否用低精度？

## 二、核心原理

混合精度：权重/梯度用 **fp16/bf16** 做计算（快、省显存），但保留 **fp32 主权重（master weights）** 做更新，避免舍入误差累积。bf16 动态范围同 fp32，比 fp16 更不易溢出，大模型首选。

## 三、关键要点

- 主权重 fp32 防漂移。
- bf16 比 fp16 稳（范围大）。

## 四、代码实现

```python
scaler = torch.cuda.amp.GradScaler()   # fp16 需
with autocast(dtype=torch.bfloat16): out = model(x)
```

## 五、与其他对比

| 精度 | 范围 | 用途 |
|------|------|------|
| fp32 | 大 | 主权重 |
| bf16 | 大 | 计算 |
| fp16 | 小 | 需 scaler |

## 六、常见误区

- 全 fp16 无代价——易溢出/舍入。
