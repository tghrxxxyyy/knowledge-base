# 精度与收敛

> 见「混合精度训练深入/混合精度总览」；低精度是否伤收敛？

## 一、背景与挑战

用低精度会不会训不出好模型？

## 二、核心原理

正确混合精度（主权重 fp32、bf16 计算）几乎不损最终精度，甚至因正则效应略提升。错误使用（fp16 全链路、无 scaling）会发散或精度掉。关键是「算低位、存高位」。

## 三、关键要点

- bf16 经验上等价 fp32 收敛。
- 数值敏感层可强制 fp32。

## 四、代码实现

```python
emb = emb.float()   # 数值敏感层保持高精度
```

## 五、与其他对比

- 正确混合无损；错误用伤。

## 六、常见误区

- 低精度必掉点——正确用法不会。
