# 缓存命中率优化

> 对应缓存调优经验；命中率提升实践。

## 一、背景与挑战

命中率低则收益小；需从 key 设计、归一化、阈值、分层提升。

## 二、核心原理

归一化 prompt（去空白/时间戳）、语义聚类、热度分层（热数据常驻）、写回策略、协同前缀。

## 三、数学形式

$h = 1 - \prod_i (1-p_i)^{n_i}$（按请求分布）；提升靠增相似度与降基。

## 四、代码实现

```python
key = normalize(q)                 # 去时间戳/空白
hit = semantic_lookup(key, tau=0.92)
```

## 五、与其他对比

- 与 语义缓存深入（机制）衔接（本节调优）。
- 与 API网关与限流策略深入 共享 key 设计。

## 六、常见误区

- 不归一化致几乎不命中。
- 只追命中率忽视答案时效/错答。
