# 缓存成本收益

> 对应缓存 ROI 分析；与 成本优化与资源调度深入 衔接。

## 一、背景与挑战

缓存占内存/嵌入算力，需证明 ROI 正。

## 二、核心原理

收益=命中省的生成成本；成本=存储+嵌入查询+维护；仅当命中率×单价超成本才值。

## 三、数学形式

净收益 $R = h\cdot C_{gen} - (C_{store}+C_{embed})$；阈值 $h^* = C_{cost}/C_{gen}$。

## 四、代码实现

```python
roi = hit_rate*gen_cost - (store_cost+embed_cost)
if roi > 0: enable_cache()
```

- 与 成本优化与资源调度深入 共享成本视角。
- 与 推理缓存与命中优化深入 总览互补。

## 六、常见误区

- 低命中率仍常开缓存（赔本）。
- 忽略嵌入查询本身成本。
