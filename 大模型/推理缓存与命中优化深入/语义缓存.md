# 语义缓存

> 对应 GPTCache（Bang et al., 2023）；语义检索缓存。

## 一、背景与挑战

用户提问措辞不同但语义相同，精确缓存命中低，需语义匹配。

## 二、核心原理

query 嵌入→向量库近邻检索；相似度超阈值则返回历史答案；可加召回重排防错答。

## 三、数学形式

命中若 $\cos(e(q), e(q')) > \tau$；否则写入新 $(e(q), ans)$。

## 四、代码实现

```python
sim = cos(embed(q), cache_vecs).max()
if sim > 0.95: return cache_ans[argmax]
```

## 五、与其他对比

- 与 前缀缓存深入（精确 vs 语义）互补。
- 与 检索重排序深入（若新增，语义检索）同源。

## 六、常见误区

- 阈值过低返错答；过高退化为精确缓存。
- 嵌入模型与问答域不匹配致误判。

## 八、面试题

- 语义缓存风险？答：措辞异义同致误返，需阈值+重排+时效控制。

## 九、演进

精确 → 向量语义 → 语义+重排+时效。

## 十、小结

语义缓存提命中率，但要控误答与时效。
