# 推理缓存总览

> 对应 GPTCache（Bang 等, 2023）；语义缓存实践。

## 一、背景与挑战

相同/相似 prompt 重复推理浪费算力；缓存命中可降延迟与成本。

## 二、核心原理

两类：前缀缓存（同系统提示/KV 复用）与语义缓存（相似问题返回历史答案）。命中则跳过/复用生成。

## 三、数学形式

命中率 $h = \frac{N_{hit}}{N_{total}}$；节省 $\approx h \times \text{cost}_{gen}$。

## 四、代码实现

```python
if (ans := cache.get(embed(q))) is not None: return ans
ans = llm(q); cache.put(embed(q), ans)
```

## 五、与其他对比

- 与 模型服务负载均衡深入（降 prefill）互补。
- 与 API网关与限流策略深入（网关层缓存）衔接。

## 六、常见误区

- 缓存所有请求致内存爆。
- 语义相似误判返回错答（阈值松）。

## 八、面试题

- 缓存为何省成本？答：命中跳过生成/复用 KV，省 token 与算力。

## 九、演进

无缓存 → 精确缓存 → 语义缓存 → 分层缓存。

## 十、小结

推理缓存以命中复用降本提速，分精确与语义两类。
