# 分块与重计算

> 对应 Dao et al., *FlashAttention*, 2022（在线 softmax 与 tiling）。

## 一、背景与挑战

SRAM 容量远小于 HBM，无法直接放下整张注意力矩阵；同时要在不保存中间大矩阵的情况下正确归一化。

## 二、核心原理

把 Q/K/V 切成块状，逐块读入 SRAM；用在线 softmax（running max/sum）边读边更新输出，避免存全矩阵；反向时按块重计算（checkpointing），用少量重算换大量显存节省。

## 三、数学形式

在线 softmax 维护 $m^{(t)}=\max(m^{(t-1)}, \max_j s_{ij}^{(t)})$，$l^{(t)}=e^{m^{(t-1)}-m^{(t)}}l^{(t-1)}+e^{-m^{(t)}}\sum_j e^{s_{ij}^{(t)}}$，增量更新 $O$。

## 四、代码实现

```python
# 在线 softmax 伪核心
m_new = max(m, block_max); l = exp(m-m_new)*l + exp(block_max-m_new)*block_sum
acc = exp(m-m_new)*acc + exp(block_scores-m_new) @ V_block
```

## 五、与其他对比

- 与 层归一化深入 都涉及归一化数值稳定技巧。
- 与 稀疏注意力深入 都不改算法，只改实现/模式。

## 六、常见误区

- 反向重算若缓存不当反而更慢；需平衡重算与存储。
- 分块大小不适配 SRAM 致未达最优带宽。

## 八、面试题

- 为何 FlashAttention 能不存 $n\times n$ 矩阵？答：在线 softmax 增量更新输出，反向靠块重计算恢复，无需物化全矩阵。

## 九、演进

朴素物化 → tiling+在线softmax → 反向重计算。

## 十、小结

分块与在线 softmax 是 FlashAttention 的核心技巧，以重算换显存、以 SRAM 带宽换速度。
