# 神经声码器

> 对应 Kong et al., *HiFi-GAN*, 2020；Oord et al., *WaveNet*, 2016。

## 一、背景与挑战

把梅尔谱还原为高质量波形，传统 Griffin-Lim 音质差；神经声码器以生成模型提升自然度与速度。

## 二、核心原理

WaveNet 用自回归 WaveNet 逐样本生成，质量高但慢；HiFi-GAN 用 GAN + 多周期/多尺度判别器，实时且高保真，成为事实标准。

## 三、数学形式

GAN 对抗目标：

$$\min_G \max_D \mathbb E[\log D(x)] + \mathbb E[\log(1-D(G(\text{mel})))] + \lambda\mathcal L_{fm}$$

加特征匹配损失 $\mathcal L_{fm}$ 稳定训练。

## 四、代码实现

```python
wav = hifigan(mel)
# 推理单 forward，无需自回归
```

## 五、与其他对比

- 与 语音合成TTS基础 衔接为后端。
- 与 流式与低延迟 对照实时性。

## 六、常见误区

- 忽视谱与声码器匹配（训练分布漂移致伪影）。
- 以为任意声码器可互换。

## 九、演进

Griffin-Lim → WaveNet → Parallel WaveGAN → HiFi-GAN。
