# 大模型语音统一

> 对应 AudioPaLM / USM / Whisper 等“一个大模型覆盖识别/合成/翻译”趋势。

## 一、背景与挑战

语音任务零碎（ASR/TTS/ST/SE），能否用统一大模型框架替代多专用模型？

## 二、核心原理

两种统一思路：(1) 把语音离散化为 token，与文本 token 同处一个 LLM 做 seq2seq（语音理解与生成一体）；(2) 多任务前缀 Transformer（如 Whisper 的任务 token）。后者工程更成熟。

## 三、数学形式

统一似然：

$$p(output | input, task) = \prod_i p_\theta(o_i | o_{<i}, input, task)$$

task 控制识别/翻译/合成等行为。

## 四、代码实现

```python
out = model(audio_or_text, task_token="translate_en")
```

## 五、与其他对比

- 与 Whisper弱监督 / 语音合成TTS基础 对照单任务模型。
- 与 多模态指令微调深入 共享“统一指令”思想。

## 六、常见误区

- 强行统一忽视任务差异致互相拖累。
- 离散 token 语音损失信息致音质降。

## 八、面试题

- 语音统一两条路线？答：离散 token 进 LLM，或多任务前缀 Transformer；各有权衡。

## 九、演进

单任务 → 多任务前缀 → token 统一大模型。

## 十、小结

语音大模型以统一框架收敛多任务，是语音研究的前沿方向。
