# 语音识别总览

> 对应 Graves et al., *Connectionist Temporal Classification (CTC)*, 2006；Graves, *Sequence Transduction with Recurrent Networks (RNN-T)*, 2012。

## 一、背景与挑战

语音是变长序列，且与文本无严格对齐；传统 HMM 工艺复杂，端到端模型直接学声学→文本映射。

## 二、核心原理

两条端到端路线：CTC 在输出插入 blank 并对齐求和，适合非自回归；Transducer（RNN-T）在 CTC 上加预测网络，自回归生成，更适合流式。二者均需处理长度不匹配。

## 三、数学形式

CTC 目标对全部对齐求和：

$$p(y|x)=\sum_{\pi\in\mathcal B^{-1}(y)}\prod_t p(\pi_t|x)$$

$\mathcal B$ 去 blank 与重复，得到标签序列。

## 四、代码实现

```python
log_probs = encoder(waveform)          # [T, V]
loss = CTCLoss(log_probs, targets, input_lengths, target_lengths)
```

## 五、与其他对比

- 与 Whisper弱监督 对照“弱监督预训练 vs 建模对齐”。
- 与 大模型语音统一 共享端到端趋势。

## 六、常见误区

- 误以为 CTC 需要帧级对齐标注；其实不需要。
- 忽视长度不匹配导致 CTC 路径爆炸。

## 八、面试题

- CTC 如何解对齐？答：引入 blank 并对所有映射到标签的对齐路径求和，免人工对齐。

## 九、演进

HMM → CTC → RNN-T → 流式 Transformer。

## 十、小结

端到端语音识别以 CTC/Transducer 消除对齐工程，是现代化 ASR 基础。
