# 流式与低延迟语音

> 对应流式 ASR（chunk/triggered attention）；RNN-T 天然流式优势。

## 一、背景与挑战

实时对话/字幕要求低延迟，离线整句识别不可用；需边听边出结果。

## 二、核心原理

流式策略：固定分块（chunk）编码、触发式注意力（限未来窗）、以及 RNN-T 自回归天然适配流式。延迟-准确权衡用 ALSD（平均延迟）度量。

## 三、数学形式

流式条件下输出延迟：

$$\Delta_i = t^{emit}_i - t^{arrive}_i$$

整体用平均或分位延迟评估，并与 WER 权衡。

## 四、代码实现

```python
for chunk in stream(audio):
    hyp = transducer.encode_chunk(chunk)   # 增量输出
```

## 五、与其他对比

- 与 语音识别总览（RNN-T）天然契合。
- 与 Whisper弱监督 对照（Whisper 默认非流式）。

## 六、常见误区

- 为降延迟把 chunk 设太小致上下文不足、WER 升。
- 忽视端点检测（VAD）对延迟的影响。

## 八、面试题

## 九、演进

整句 → 分块 → 触发注意力 → 端到端流式大模型。

## 十、小结

流式语音靠分块/触发与 RNN-T，在延迟与准确间求平衡。
