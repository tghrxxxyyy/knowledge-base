# 动态层数与路由

> 对应样本自适应深度；与 早退推理深入 衔接。

## 一、背景与挑战

不同样本难度不同，应分配不同层数。

## 二、核心原理

用路由器（基于浅层表征）预测所需层数或选专家子网络，简单样本走浅/小子网。

## 三、数学形式

路由 $r(x)=\arg\max_k g_k(E_{shallow}(x))$；算力 $\propto \sum r_k d_k$。

## 四、代码实现

```python
k = router(shallow_emb).argmax()
out = layers[:depths[k]](x)
```

## 五、与其他对比

- 与 早退推理深入 都调深度，路由更显式。
- 与 MoE路由深入 共享门控。

## 六、常见误区

- 路由偏置致某些层永不训。
- 路由误差大伤难样本。

## 八、面试题

- 动态层数如何路由？答：用浅层表征经门控预测所需层数/专家，分配算力。

## 九、演进

早退 → 显式路由 → 可微路由。

## 十、小结

动态层数以路由显式分配深度，可控且易训练。
