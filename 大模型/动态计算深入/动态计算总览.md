# 动态计算总览

> 对应 Graves, *Adaptive Computation Time (ACT)*, 2016；Dehghani et al., *Universal Transformer*, 2018。

## 一、背景与挑战

固定层数/步数对易样本过算、对难样本欠算；动态计算按需分配算力。

## 二、核心原理

模型自决“算多久”：每层/每位置可早停或循环多步，以 ponder/置信控制，实现样本/位置自适应。

## 三、数学形式

ACT 停概率 $p_t=\sigma(W h_t)$；累计 $c=\sum_{t}p_t$ 达 $1-\epsilon$ 停，加 ponder 代价 $\rho\sum (1-p_t)$。

## 四、代码实现

```python
while cum < 1 - eps:
    h = step(h); p = sigma(h); cum += p
```

## 五、与其他对比

- 与 早退推理深入 同属自适应深度，ACT 更连续。
- 与 推理成本深入 直接节算。

## 六、常见误区

- 无 ponder 惩罚致无限循环。
- 动态路由未训练稳。
