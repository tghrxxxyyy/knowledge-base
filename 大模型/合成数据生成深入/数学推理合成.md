# 数学推理数据合成

> 对应 Luo et al., 《WizardMath》, 2023；以及 Yu et al., 《MetaMath》, 2023 数据增强。

## 一、背景与挑战

数学需精确多步推理，纯蒸馏样本覆盖有限；需针对性合成提升泛化。

## 二、核心原理

用提示（如 Evol-Instruct 的指令演化、问题重写/反向构造）生成变体与多步解答；MetaMath 通过改写问题扩充语义覆盖。

## 三、数学形式

问题增强 $q' = augment(q)$ 保持答案 $a$ 不变，使 $(q',a)$ 覆盖更多表述。

## 四、代码实现

```python
q_prime = llm(f"在不改变答案下重写问题:\n{q}")
chain = llm(f"逐步解:\n{q_prime}")
```

## 五、与其他对比

- 与 标签噪声纠正深入（增强也带错需筛）衔接。
- 与 少样本适配深入（数学少样本）共享任务。

## 六、常见误区

- 重写改变原答案致标签错。
- 只增问题不增过程，推理仍弱。

## 八、面试题

- MetaMath 思路？答：保持答案不变重写问题，扩充语义覆盖提升数学泛化。

## 九、演进

蒸馏解答 → 指令演化 → 问题重写/反向构造。

## 十、小结

数学合成靠问题增强与多步解答，扩大覆盖而不改标签是关键。
