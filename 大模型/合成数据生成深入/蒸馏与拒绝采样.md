# 蒸馏与拒绝采样合成

> 对应 Taori et al., 《Alpaca》, 2023；以及 Yuan et al., 《RRHF》, 2023 拒绝采样思想。

## 一、背景与挑战

直接用强模型（如 GPT-4）蒸馏，可得高质量(指令,回答)；但需筛选最优回答避免劣质样本。

## 二、核心原理

以强教师生成多候选回答，用奖励/排序模型或规则拒绝采样挑最优；也可按 Self-Instruct 指令直接蒸馏。

## 三、数学形式

拒绝采样 $y^* = \arg\max_{y\in Y} R(x,y)$，其中 $R$ 为奖励模型或质量分。

## 四、代码实现

```python
cands = [teacher.generate(x) for _ in range(k)]
best = max(cands, key=lambda y: reward_model(x, y))
```

## 五、与其他对比

- 与 奖励模型深入（提供 R）共享。
- 与 直接偏好优化深入（需偏好对）互补数据源。

## 六、常见误区

- 教师模型偏见被完整继承到学生。
- 拒绝采样阈值过高致数据稀少。

## 八、面试题

- 拒绝采样在合成中的作用？答：从多候选中挑最优回答，提升单样本质量、降噪。

## 九、演进

单样本蒸馏 → 多候选拒绝采样 → 结合奖励模型规模化。

## 十、小结

蒸馏+拒绝采样兼顾质量与规模，是主流合成范式，但需控教师偏见。
