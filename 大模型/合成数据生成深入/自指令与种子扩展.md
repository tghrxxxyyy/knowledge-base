# 自指令与种子扩展（Self-Instruct）

> 对应 Wang et al., 《Self-Instruct》, 2022；用模型自举生成指令数据。

## 一、背景与挑战

指令数据标注成本高；少量人工种子即可让模型自我扩展出海量多样指令。

## 二、核心原理

先以少量种子指令为示范，让 LLM 生成新指令（去重、过滤可行性），再对新指令生成回答，形成自举循环。

## 三、数学形式

多样性约束 $P(ins_{new}) \propto \exp(-sim(ins_{new}, I_{pool}))$ 抑制与已有指令相似者。

## 四、代码实现

```python
seed = random.sample(human_seed, 8)
new_ins = llm(f"生成不同于以下的新指令:\n{seed}")
ins_pool = dedupe(seed + new_ins)
```

## 五、与其他对比

- 与 少样本适配深入（用指令做上下文）共享指令范式。
- 与 合成数据质量评估深入（需过滤）衔接。

## 六、常见误区

- 自举循环使错误/偏见被放大固化。
- 指令去重不足致高度同质。

## 七、与开源书对应

## 八、面试题

- 自指令为何能扩量？答：少量种子引导模型生成新指令与回答，自举循环低成本扩指令覆盖。

## 九、演进

人工种子 → Self-Instruct → 多轮自举 + 自动过滤。

## 十、小结

自指令以模型自举扩指令，关键在去重与质量过滤防偏见放大。
