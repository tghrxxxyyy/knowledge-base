# 多模态合成数据

> 对应 Liu et al., 《LLaVA》, 2023（GPT-4 生成图文指令）；多模态对齐数据合成。

## 一、背景与挑战

图文对稀缺且标注贵；需以 LLM/VLM 合成多模态指令提升视觉对话能力。

## 二、核心原理

把图像caption/边界框喂给强 VLM，生成(问题,回答)对；或文本生图再反标描述，形成闭环。

## 三、数学形式

对齐损失 $\mathcal L_{align} = -\log p_\theta(a|v,q)$，$v$ 为视觉编码，训练用合成(图,问,答)。

## 四、代码实现

```python
captions = vit_caption(image)
qa_pairs = vlm(f"基于描述生成问答:\n{captions}")
```

## 五、与其他对比

- 与 合成数据生成总览（单模态扩展）共享范式。
- 与 度量学习深入（视觉表征）衔接。

## 六、常见误区

- 合成问答与图像事实不符（幻觉）。
- 文本生图引入偏差分布。

## 七、与开源书对应

- mlabonne/llm-course：https://github.com/mlabonne/llm-course
- datawhalechina/llm-universe：https://github.com/datawhalechina/llm-universe

## 八、面试题

- 多模态合成难点？答：须保证问答与图像事实一致，防视觉幻觉与分布偏差。

## 九、演进

人工图文 → VLM 生成问答 → 文本生图反标闭环。

## 十、小结

多模态合成以 VLM 桥接图文，核心在事实一致性与去偏。
