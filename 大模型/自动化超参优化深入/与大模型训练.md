# 超参优化与大模型训练

> 对应 LLM 训练超参搜索实践；与 学习率调度深入 / 训练不稳定诊断深入 衔接。

## 一、背景与挑战

大模型单训极贵，HPO 必须少 trial、强早停、复用。

## 二、核心原理

用小规模代理实验（小模型/短步）预测大模型最优超参，再迁移；结合 warm-start。

## 三、数学形式

代理损失 $\hat f_{big}(\lambda)\approx g(f_{small}(\lambda))$；选 $\lambda^*$ 在小规模验证后上大模型。

## 四、代码实现

```python
best = hpo_on_small(model_scale=0.1)
train_large(**best)
```

## 五、与其他对比

- 与 自动化机器学习深入 共享 AutoML 思想。
- 与 神经架构搜索深入 共享搜索成本问题。

## 六、常见误区

- 小规模结论不迁移到大规模（规模效应）。
- 忽视超参间耦合（如 LR-batch）。

## 八、面试题

- 大模型 HPO 为何用代理？答：全规模搜太贵，用小规模预测再迁移。

## 九、演进

全规模搜 → 代理迁移 → 元学习超参。

## 十、小结

大模型 HPO 靠代理与迁移化解成本，是训练经济性关键。
