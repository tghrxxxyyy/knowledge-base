# 自动化超参优化总览

> 对应 Bergstra & Bengio, *Random Search*, 2012；Snoek et al., *BayesOpt*, 2012；HPO 综述。

## 一、背景与挑战

学习率/批次/正则等超参极多，人工调参慢且次优；需自动化搜索。

## 二、核心原理

网格/随机/贝叶斯（高斯过程、TPE）、进化、Bandit（Hyperband/ASHA）等策略搜最优配置。

## 三、数学形式

目标 $f(\lambda)$（验证误差），在 $\lambda\in\Lambda$ 上最小化；$f$ 评估贵，需少样本高效。

## 四、代码实现

```python
study = optuna.create_study(direction="minimize")
study.optimize(objective, n_trials=100)
```

## 五、与其他对比

- 与 学习率调度深入（单参数）互补（HPO 是多参数联合）。
- 与 神经架构搜索深入 共享搜索范式。

## 六、常见误区

- 网格搜索在高维低效（维度灾难）。
- 忽略早停致搜索成本爆炸。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 为何随机搜索优于网格？答：高维下随机更易覆盖重要维度组合。

## 九、演进

网格 → 随机 → 贝叶斯 → 进化/Bandit。

## 十、小结

自动化 HPO 用少样本搜索替代人工，是训练性价比的关键。
