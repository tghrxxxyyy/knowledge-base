# 指令数据多样性与规模（LIMA）

> 对应 Zhou et al., *LIMA: Less Is More for Alignment*, 2023。

## 一、背景与挑战

大量弱指令数据未必优于少量精标；多样性与风格覆盖可能比数量更决定泛化。

## 二、核心原理

LIMA 用约 1000 条精选、风格多样、深度回答的示范，即可媲美大模型对齐效果，表明“对齐主要是风格/格式学习”。

## 三、数学形式

效果随 $N$ 呈对数饱和：$E(N) \approx a\log N + b$；越过拐点增样增益小。

## 四、代码实现

```python
demo = select_diverse(human_data, n=1000, by="topic+style")
model.sft(demo)        # 千级即强
```

## 五、与其他对比

- 与 指令微调数据质量总览 的“少而精”呼应。
- 与 直接偏好优化深入（后续对齐）衔接。

## 六、常见误区

- 以量代质，堆低质指令。
- 忽视风格多样性致输出刻板。

## 八、面试题

- LIMA 核心结论？答：千级高质量多样示范即可强对齐，暗示对齐重在风格而非知识量。

## 九、演进

大规模弱数据 → 精选千级 → 质量优先范式。

## 十、小结

多样性与质量的千级数据常胜海量弱数据。
