# 自动合成指令（Self-Instruct）

> 对应 Wang et al., *Self-Instruct: Aligning LLMs with Bootstrapped Instructions*, 2022。

## 一、背景与挑战

人工写指令昂贵且覆盖有限；需模型自举生成大量多样指令-回答对。

## 二、核心原理

用少量种子指令，让模型生成新指令（去重）、再生成回答；经启发式过滤（可执行、非重复、格式对）得训练集。

## 三、数学形式

生成循环 $\mathcal D_{new} = \{(I_i, A_i)\}_{i=1}^N$，$I_i\sim G_\theta(I_{seed})$；用 ROUGE/嵌入去重。

## 四、代码实现

```python
for seed in seeds:
    ins = llm(f"生成不同于以下的指令:\n{used}")
    ans = llm(ins)
    if valid(ins, ans): data.append((ins, ans))
```

## 五、与其他对比

- 与 指令复杂度（Evol）互补升级。
- 与 预训练数据流水线深入（合成数据）共享理念。

## 六、常见误区

- 自举放大模型已有偏见。
- 不校验致脏数据入训。

## 七、与开源书对应

- datawhalechina/llm-universe：https://github.com/datawhalechina/llm-universe
- llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- Self-Instruct 如何防重复？答：用相似度/ROUGE 去重，并约束生成“不同于已用”的指令。

## 九、演进

种子引导 → 自举扩量 → 复杂度进化。

## 十、小结

自举合成以少量种子扩大量指令，是低成本对齐主流。
