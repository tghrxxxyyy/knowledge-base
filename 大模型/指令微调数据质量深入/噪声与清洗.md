# 指令数据噪声与清洗

> 对应指令数据质量过滤研究；与 模型水印深入（溯源）无直接关。

## 一、背景与挑战

合成指令含错误回答、格式错、重复与偏见；脏数据直接拉低对齐质量。

## 二、核心原理

用强模型/规则做多轮过滤：去重、格式校验、事实核验、有用性打分；可训练轻量质量分类器筛劣。

## 三、数学形式

保留概率 $p_{keep}=q_{format}\cdot q_{correct}\cdot q_{useful}$；低于阈值丢弃。

## 四、代码实现

```python
for ins, ans in synthetic:
    if not fmt_ok(ans): continue
    if judge(ans) < 0.6: continue
    clean.append((ins, ans))
```

## 五、与其他对比

- 与 预训练数据流水线深入（质量过滤）同法。
- 与 直接偏好优化深入（偏好对质量）共享“数据质量决定上限”。

## 六、常见误区

- 仅格式过滤不查事实错。
- 强模型自判自数据过拟合偏好。

## 八、面试题

- 合成指令为何要清洗？答：含事实错/格式错/偏见，脏数据直接伤对齐，需多轮过滤。

## 九、演进

人工筛 → 规则过滤 → 模型质量分类器。

## 十、小结

清洗是合成指令落地的必要守门，多维度把关。
