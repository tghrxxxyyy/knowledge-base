# 指令复杂度与难度（Evol-Instruct）

> 对应 Xu et al., *WizardLM: Empowering LLMs with Complex Instructions*, 2023。

## 一、背景与挑战

简单指令难提升模型处理复杂任务能力；需逐步提升指令深度/广度。

## 二、核心原理

Evol-Instruct 用 LLM 把简单指令“进化”为更复杂版本（加深推理、扩约束、加多步），形成课程式难度梯度训练。

## 三、数学形式

复杂度 $c_{t+1} = \text{Evol}(c_t)$ 单调升；训练分布覆盖 $c\in[c_{min},c_{max}]$ 提升难任务表现。

## 四、代码实现

```python
hard = llm(f"把下面指令变得更难更复杂:\n{easy_inst}")
data.append((hard, llm(hard)))    # 生成对应回答
```

## 五、与其他对比

- 是 Self-Instruct 的难度增强版。
- 与 多智能体协同深入（复杂任务分解）相关。

## 六、常见误区

- 过度进化致指令不自然/不可解。
- 只难不难易，分布失衡。
