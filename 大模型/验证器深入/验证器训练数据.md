# 验证器训练数据

> 对应 Lightman et al., 2023（逐步标注）；自动标注法。

## 一、背景与挑战

高质量验证标签稀缺，尤其 PRM 逐步标签。

## 二、核心原理

来源：人工标注逐步正确、用强模型/多次采样一致性自动标（含噪）、或 ORM 蒸馏到 PRM；需去噪与平衡。

## 三、数学形式

标签 $l_t\in\{0,1\}$ 由 $\text{majority}(\text{samples reach correct})$ 估计。

## 四、代码实现

```python
def auto_label(step):
    return 1 if reach_correct_ratio(step) > 0.5 else 0
```

## 五、与其他对比

- 与 偏好数据构建深入（若新增）共享标注。
- 与 可验证奖励深入（自动校验）衔接。

## 六、常见误区

- 自动标签噪声致 PRM 偏。
- 标签仅终对错误传步。

## 八、面试题

- PRM 标签如何来？答：人工或强模型一致性自动标，需去噪。

## 九、演进

人工 → 自动一致 → 自训练。

## 十、小结

验证器数据靠自动标注规模化，但需控噪。
