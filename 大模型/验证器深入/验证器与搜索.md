# 验证器与搜索解码

> 对应 Yao et al., *Tree of Thoughts*, 2023（验证引导搜索）。

## 一、背景与挑战

单次 greedy 解码易错；用验证器引导搜索可显式纠错。

## 二、核心原理

在 beam/MCTS 中每步用 PRM 评分扩展；best-of-n 用 ORM 选；验证器把搜索变“可规划推理”。

## 三、数学形式

节点值 $Q(s)=\max_{a} v_\phi(x, path(s,a))$；选最优路径。

## 四、代码实现

```python
for node in expand(): node.v = prm(x, node.path)
pick = best(node for node in frontier)
```

## 五、与其他对比

- 与 过程监督与结果监督深入（若新增）衔接。
- 与 可验证奖励深入（验证即信号）相关。

## 六、常见误区

- 搜索过宽致成本高。
- 验证器错引搜偏。

## 八、面试题

- 验证器如何提推理？答：逐步评分引导 beam/MCTS，显式探索纠错。

## 九、演进

greedy → best-of-n → 树搜索。

## 十、小结

验证器使搜索式推理可行，显著提升难任务。
