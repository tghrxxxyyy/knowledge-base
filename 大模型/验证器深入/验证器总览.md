# 验证器总览

> 对应 Cobbe et al., *Training Verifiers to Solve Math Word Problems*, 2021；Lightman et al., *Let's Verify Step by Step*, 2023。

## 一、背景与挑战

LLM 自评不可靠；需独立验证器判答案对错，尤在推理任务。

## 二、核心原理

验证器（Verifier）给定问题与解答输出正确性分数；分结果验证器（ORM，看终答）与过程验证器（PRM，看每步）。强验证器可引导搜索提精度。

## 三、数学形式

ORM 分数 $v_\phi(x,y)\in[0,1]$；PRM 逐步 $v_\phi(x,y_{1:t})$；最终 $V=\prod_t v_t$。

## 四、代码实现

```python
score = verifier(x, y_steps)
```

## 五、与其他对比

- 与 可验证奖励深入（校验即奖励）衔接。
- 与 奖励模型深入（偏好）对照。

## 六、常见误区

- 误用生成器自评当验证器（不准）。
- 验证器过拟合训练分布。

## 七、与开源书对应

## 八、面试题

- 验证器为何独立？答：生成器自评偏高，独立判别更可靠。

## 九、演进

规则校验 → ORM → PRM → 树搜索。

## 十、小结

验证器是推理质量的独立判官，ORM/PRM 两形态。
