# 束搜索与采样对比

> 对应 Holtzman et al., *The Curious Case of Neural Text Degeneration*, 2020。

## 一、背景与挑战

何时应确定解码、何时随机采样，需按任务定性。

## 二、核心原理

事实/翻译需确定→束搜索；创意/对话需多样→采样；二者在“可预测性”上权衡。

## 三、数学形式

确定性 $\mathbb E[\text{entropy}(P(\cdot|h))]$ 低处束搜索优，高处采样优。

if task == "translate": gen = beam(4)

## 五、与其他对比

- 与 采样策略深入 / 温度与解码深入 共同构成解码族。
- 与 自回归生成深入 衔接。

## 六、常见误区

- 开放生成用大 B 反而重复死板。
- 事实任务用采样引入幻觉。

## 八、面试题

- 何时用束搜索何时采样？答：高确定任务束搜索，高多样任务采样。

## 九、演进

二选一 → 混合（采样+重排）→ 自适应。

## 十、小结

解码策略随任务可预测性而定，无万能解。
