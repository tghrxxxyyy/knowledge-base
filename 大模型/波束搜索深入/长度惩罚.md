# 束搜索与长度惩罚

> 对应 Murray & Chiang, *Correcting Length Bias in Beam Search*, 2018。

## 一、背景与挑战

概率连乘使长序列得分天然偏低，束搜索偏向过短译文/摘要。

## 二、核心原理

对序列对数概率除以长度幂函数做归一，鼓励合理长度；$\alpha$ 调偏置强度。

## 三、数学形式

长度惩罚 $LP(y)=\frac{(5+|y|)^\alpha}{(5+1)^\alpha}$；得分 $\frac{\log P(y|x)}{LP(y)}$。

## 四、代码实现

```python
gen = model.generate(input_ids, num_beams=4, length_penalty=0.8)
```

## 五、与其他对比

- 与 采样策略深入 不同，束搜索需显式长度归一。
- 与 自回归生成深入 共享长度动力学。

## 六、常见误区

- $\alpha$ 过大促超长、过小偏短。
- 不同任务最优 $\alpha$ 差异大。

## 八、面试题

- 为何要长度惩罚？答：抵消连乘对长序列的概率惩罚，避免过短输出。

## 九、演进

无惩罚 → 长度归一 → 覆盖度感知。

## 十、小结

长度惩罚纠正概率缺陷，是束搜索质量关键。
