# 多样束搜索（Diverse Beam Search）

> 对应 Vijayakumar et al., *Diverse Beam Search*, 2018。

## 一、背景与挑战

标准束搜索候选间高度相似，缺乏多样性，不利摘要/对话多解。

## 二、核心原理

把束分成若干组，组间加以往组为条件的相似度惩罚，迫使各组探索不同语义区域。

## 三、数学形式

组间惩罚 $\Delta(y_g)=\sum_{g'<g}\lambda \cdot sim(y_g,y_{g'})$；每步在组内择优并减交叉相似。

## 四、代码实现

```python
gen = model.generate(input_ids, num_beams=6, num_beam_groups=3, diversity_penalty=0.5)
```

## 五、与其他对比

- 与 采样策略深入 都能提多样，但束搜索仍控质量。
- 与 束搜索总览 同框架扩展。

## 六、常见误区

- 组数过多致单组质量崩。
- 相似度度量不当（如仅用末隐态）。

## 八、面试题

- 多样束如何保证差异？答：组间加相似惩罚，强制不同语义簇。

## 九、演进

标准束 → 分组多样 → 簇多样。

## 十、小结

多样束搜索在质量与多样间平衡，适合多解场景。
