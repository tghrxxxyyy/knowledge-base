# 束搜索在生成中的应用

> 对应机器翻译/摘要解码实践；与 自回归生成深入 衔接。

## 一、背景与挑战

束搜索在翻译、摘要、OCR 等近确定任务仍是主力。

## 二、核心原理

配合长度惩罚与早停，在可接受延迟内取近最优序列；常作为评估基线。

## 三、数学形式

早停：当束内最优已完成且次优分差超阈值则停；$stop$ if $\max_{y\in B, done} s(y) \ge \max_{y'} s(y')$。

## 四、代码实现

```python
gen = model.generate(input_ids, num_beams=5, early_stopping="always",
                      length_penalty=1.0, no_repeat_ngram_size=3)
```

## 五、与其他对比

- 与 约束解码深入 可叠加（约束束）。
- 与 采样策略深入 互为基线对照。

## 六、常见误区

- 仅靠束搜索难控格式，需结合约束。
- 忘记 no_repeat_ngram 致复制。

## 八、面试题

- 束搜索为何仍是翻译主力？答：翻译高确定，近最优序列即质量，确定解码最稳。

## 九、演进

纯束 → 束+约束 → 束+重排。

## 十、小结

束搜索是确定生成基石，配合惩罚与早停实用。
