# 贪心解码与束宽

> 对应 seq2seq 解码基础；与 自回归生成深入 衔接。

## 一、背景与挑战

束宽 B 是质量与算力的主要旋钮，需理解其缩放规律。

## 二、核心原理

B=1 即贪心；增大 B 提升覆盖但边际收益递减，且延迟近似线性增长；实践中 B∈[4,8] 常足够。

## 三、数学形式

复杂度约 $O(B\cdot V\cdot T)$（$V$ 词表、$T$ 长度）；期望增益 $\Delta Q(B)\propto \log B$ 后饱和。

## 四、代码实现

```python
for B in [1, 4, 8, 16]:
    gen = model.generate(input_ids, num_beams=B)
```

## 五、与其他对比

- 与 采样策略深入（随机多样性）相对：束搜索偏确定、低多样。
- 与 多样束搜索深入 衔接（同宽不同目标）。

## 六、常见误区

- 盲目加大 B 致延迟爆炸而质量不升。
- 在开放生成用大 B 反更死板。

## 七、与开源书对应

## 八、面试题

- 束宽如何影响质量/延迟？答：质量随 log B 饱和，延迟随 B 近线性，需折中。

## 九、演进

固定 B → 自适应 B → 早停束。

## 十、小结

束宽是核心权衡旋钮，过大收益递减且昂贵。
