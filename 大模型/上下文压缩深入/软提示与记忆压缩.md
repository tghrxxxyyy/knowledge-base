# 软提示与记忆压缩（GIST / AutoCompressor）

> 对应 Mu et al., *GIST*, 2023；Chevalier et al., *AutoCompressors*, 2023。

## 一、背景与挑战

硬文本压缩仍可丢细节；用少量可学习软 token 把长上下文编码为紧凑向量记忆，兼顾信息保真与长度。

## 二、核心原理

GIST 用少量 GIST token 归纳/压缩后续上下文的注意力影响；AutoCompressor 把前缀递归压缩成 summary vector，供后续复用，实现无限上下文近似。

## 三、数学形式

压缩记忆 $m = \text{Compress}_\phi(x_{1:n}) \in \mathbb R^{k\times d}$；后续注意力以 $m$ 替代原始 $n$ 个 token，复杂度由 $O(n)$ 降至 $O(k)$。

## 四、代码实现

```python
summary = auto_compressor.encode(prefix)        # 得到 k 个压缩向量
logits = model(next_token, past=[summary])      # 以压缩记忆续写
```

## 五、与其他对比

- 比文本压缩更保信息但不可读、难调试。
- 与 KV缓存优化深入 共享“压缩历史”思路。

## 六、常见误区

- 压缩 token 数 $k$ 过小成信息瓶颈。
- 训练与推理分布不一致致记忆失效。

## 八、面试题

- GIST token 作用？答：作为可学习归纳符，压缩其后续上下文的注意力贡献，缩短有效序列。

## 九、演进

硬压缩 → 软提示归纳 → 递归自动压缩器。

## 十、小结

软提示压缩以可学习向量保留信息，是文本压缩之外的高保真路线。
