# 提示词级压缩（LLMLingua）

> 对应 Jiang et al., *LLMLingua* / *LongLLMLingua*, 2023。

## 一、背景与挑战

句级删除仍留冗余词；词级压缩进一步缩 token，且需对齐压缩前后分布以免语义漂移。

## 二、核心原理

训练一个小语言模型（如 GPT2-small）做分布对齐，逐词评估重要性并删除/重排；LongLLMLingua 进一步按问题相关性加权，并支持迭代压缩。

## 三、数学形式

保留概率 $p_{keep}(w)=\sigma(\alpha\cdot (-\log p_\theta(w)) + \beta\cdot \text{rel}(w,q))$；按预算采样保留词。

## 四、代码实现

```python
from llmlingua import PromptCompressor
c = PromptCompressor()
r = c.compress_prompt(ctx, instruction=question, rate=0.3, use_longllmlingua=True)
```

## 五、与其他对比

- 细于 Selective Context，但可能切断句法连贯。
- 与 检索增强失效分析深入 共同服务于 RAG 上下文净化。

## 六、常见误区

- 压缩率过高破坏句法致生成退化。
- 忽略问题相关性（LongLLMLingua 才引入 $q$）。

## 八、面试题

- LLMLingua 与 Selective Context 区别？答：前者词级+分布对齐+可结合问题，后者句级自信息。

## 九、演进

句级 → 词级分布对齐 → 问题感知长上下文压缩。

## 十、小结

词级提示压缩在更细粒度上降本，问题感知显著提升保真度。
