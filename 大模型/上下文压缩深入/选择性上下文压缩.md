# 选择性上下文压缩（Selective Context）

> 对应 Li et al., *Selective Context: Compressing Prompts*, 2023。

## 一、背景与挑战

并非所有句子对回答同等重要；逐句评估信息量、丢弃低自信息句，可在语义层面无损压缩。

## 二、核心原理

用语言模型对文本单元（句/词组）计算自信息（perplexity 越低信息量越小），按信息量排序保留高信息单元，拼接成压缩上下文。

## 三、数学形式

单元 $x_i$ 自信息 $I(x_i)=-\log p_\theta(x_i\mid x_{<i})$；保留 $\arg\top_k\{I(x_i)\}$，阈值或预算截断。

## 四、代码实现

```python
def self_info(tokens, model):
    return -model.log_likelihood(tokens)   # 低困惑度=低信息
keep = [t for t in units if self_info(t) > tau]
```

## 五、与其他对比

- 比摘要式更保原文、可解释，但丢不掉跨句冗余。
- 与 LLMLingua 协作：先选择性删句，再词级压缩。

## 六、常见误区

- 单元切分过粗（整段）致粒度不足。
- 仅用单向自信息忽略后续依赖信息。

## 八、面试题

- 选择性上下文依据什么删句？答：用 LLM 自信息，保留高信息量单元、丢低信息冗余。

## 九、演进

词级剪枝 → 句级选择 → 与提示压缩联合优化。

## 十、小结

选择性上下文以自信息为尺做语义剪枝，是保真压缩的代表方法。
