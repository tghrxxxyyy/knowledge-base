# 损失塑形与知识蒸馏

> 对应 Hinton 2015 知识蒸馏 (Distilling the Knowledge in a Neural Network)。

## 一、背景与挑战
大模型（教师）学到的类间相似性信息，希望迁移到小模型（学生）。硬标签丢失了这种软知识。

## 二、核心原理
用教师 softmax 的软化概率 `q = softmax(z_T/τ)` 作目标，学生最小化与 q 的 KL；温度 τ 放大暗知识，低温逼近硬标签。

## 三、形式化与数学基础
$ q_i = \frac{\exp(z_i/τ)}{\sum_j \exp(z_j/τ)} $

学生损失：`L = α·τ²·KL(q||p_student) + (1-α)·CE(y)`。

## 四、代码实现
```python
def distill_loss(s_logits, t_logits, T=4.0, alpha=0.7):
    t = F.softmax(t_logits / T, -1)
    s = F.log_softmax(s_logits / T, -1)
    kd = F.kl_div(s, t, reduction="batchmean") * (T * T)
    return alpha * kd
```

## 五、与其他技术对比
标签平滑提供均匀背景；蒸馏提供教师专属软目标，信息更丰富。

## 六、常见误区
忘记乘 `τ²` 补偿梯度尺度，导致蒸馏信号过弱。

## 七、与开源书/权威来源对应
Hinton 2015 蒸馏论文；huggingface/transformers 的 `DistilBert` 应用该思想。

## 八、面试题
问：温度 τ 的作用？答：软化分布、放大类间暗知识，过大则趋均匀。

## 九、演进与趋势
与 LoRA、量化结合，蒸馏正用于压缩大模型。

## 十、小结
损失塑形通过软目标把教师知识高效转移给学生。
