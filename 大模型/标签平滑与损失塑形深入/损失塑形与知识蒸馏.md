# 损失塑形与知识蒸馏

> 对应 Hinton 2015 知识蒸馏 (Distilling the Knowledge in a Neural Network)。

## 一、背景与挑战
大模型（教师）在训练中不仅学到「哪个类是对的」，还学到「哪些类彼此相似」。这种类间相似性以 softmax 概率向量的形式存储，被称为暗知识（dark knowledge）。
硬标签（one-hot）是 0/1 的极端分布，几乎不携带类间结构；用它训练小模型（学生）时，学生只会被反复告知正确答案，学不到教师的泛化偏好。
蒸馏（knowledge distillation）的目标就是把这部分软知识迁移给学生：学生在同等参数量下获得更好的泛化与校准，或在更小参数量下逼近教师精度。
在大模型场景中，蒸馏从「分类器压缩」扩展为「能力搬迁」：既用于产出小尺寸对话模型，也用于把大模型在特定任务上的行为固化为可部署的轻量模型。
核心挑战有三：其一，软目标的信息量随温度变化，选择不当会退化为硬标签或均匀噪声；其二，学生容量有限，过强的软约束会引发欠拟合；其三，蒸馏损失与真值损失的相对权重需要精细平衡，否则一方主导优化方向。

## 二、核心原理
教师先以温度 $\tau$ 对 logits 做软化：$\tau > 1$ 时分布被拉平，原本极小的负类概率被放大，这些被放大的负类概率正是暗知识所在。
学生同时输出软化分布，并最小化与教师软化分布的 KL 散度；由于软化后概率量级约为 $1/\tau$，反传梯度随之缩小约 $1/\tau^2$，所以要在软损失上乘 $\tau^2$ 做补偿。
除软目标外，通常还保留学生与真实标签的交叉熵：软目标负责迁移类间结构，硬标签负责锚定任务正确性，两者按权重 $\alpha$ 混合。
温度 $\tau \to 1$ 时蒸馏退化为对教师 argmax 的模仿；$\tau \to \infty$ 时分布趋近均匀，暗知识被稀释成噪声。实践中分类任务常用 $\tau = 3 \sim 5$，生成式任务常用更小的 $\tau$。
学生的容量决定了它「能吃下多少」软信息：容量过小则软约束难以拟合，此时应提高硬标签权重或减少蒸馏层数。

## 三、形式化与数学基础
温度软化后的教师分布：

$$ q_i^{(\tau)} = \frac{\exp(z_i^{T}/\tau)}{\sum_{j} \exp(z_j^{T}/\tau)} $$

学生软化分布记为 $p_i^{(\tau)}$。软目标损失为 KL 散度：

$$ \mathcal{L}_{KD} = \tau^2 \cdot \mathrm{KL}\big(q^{(\tau)} \,\|\, p^{(\tau)}\big) = \tau^2 \sum_i q_i^{(\tau)} \log \frac{q_i^{(\tau)}}{p_i^{(\tau)}} $$

总损失按权重 $\alpha$ 混合软目标与硬标签：

$$ \mathcal{L} = \alpha \cdot \mathcal{L}_{KD} + (1-\alpha) \cdot \mathrm{CE}\big(y,\, p^{(1)}\big) $$

对 logits 求导可看出补偿的必要性。KL 对学生的梯度带 $1/\tau$：

$$ \frac{\partial \mathcal{L}_{KD}}{\partial z_i^{S}} = \tau^2 \cdot \frac{1}{\tau}\big(p_i^{(\tau)} - q_i^{(\tau)}\big) = \tau\big(p_i^{(\tau)} - q_i^{(\tau)}\big) $$

乘以 $\tau^2$ 后梯度量级重新回到 $O(1)$，使软目标与硬标签的梯度可比。

## 四、代码实现
```python
import torch
import torch.nn.functional as F

def distillation_loss(student_logits, teacher_logits, targets,
                      tau=4.0, alpha=0.7):
    # 教师软目标与学生软分布
    t_soft = F.softmax(teacher_logits / tau, dim=-1)
    s_log_soft = F.log_softmax(student_logits / tau, dim=-1)
    # KL 散度需乘 tau^2 补偿梯度尺度
    kd = F.kl_div(s_log_soft, t_soft, reduction="batchmean") * (tau * tau)
    ce = F.cross_entropy(student_logits, targets)
    return alpha * kd + (1.0 - alpha) * ce

# 训练循环片段

    t_logits = teacher(batch)
```

## 五、与其他技术对比
| 维度 | 知识蒸馏 | 标签平滑 | 直接微调 |
|---|---|---|---|
| 监督信号 | 教师软分布 + 真值 | 均匀化真值 | 硬标签 |
| 信息量 | 高，含类间相似结构 | 中，仅均匀先验 | 低 |
| 是否依赖教师 | 是 | 否 | 否 |
| 主要收益 | 迁移泛化、压缩模型 | 改善校准 | 任务适配 |
| 关键超参 | 温度 $\tau$、权重 $\alpha$ | 平滑系数 $\epsilon$ | 学习率等 |
| 额外成本 | 需教师前向 | 无 | 无 |

## 六、常见误区
- 忘记乘 $\tau^2$：软化使梯度缩小约 $1/\tau^2$，不补偿会导致蒸馏信号被真值损失淹没。
- 在 LLM 中逐 token 强制全分布匹配：自回归存在多个合理续写，逐 token 全分布约束会压制多样性，序列级或 top-k 蒸馏更合适。
- 认为温度越高越好：$\tau$ 过大会让负类概率趋同，暗知识退化为均匀噪声。
- 训练与推理温度混用：软化只用于提取训练信号，推理应使用 $\tau = 1$。
- 忽略教师噪声：教师本身的错误会被软目标放大，通常需要置信度筛选或只对 top-k 分布做蒸馏。

## 八、面试题
1. 问：温度 $\tau$ 的作用是什么？
   答：拉平 softmax 分布、放大类间暗知识；$\tau \to \infty$ 趋均匀，$\tau \to 1$ 退化为硬标签。
2. 问：为什么蒸馏损失要乘 $\tau^2$？
   答：软化后梯度量级约为 $1/\tau^2$，需补偿以保持软目标与真值损失量级可比，避免蒸馏信号过弱。
3. 问：蒸馏与标签平滑有何区别？
   答：标签平滑对所有非真类给相同小概率；蒸馏给的是教师专属分布，携带类间相似结构。
4. 问：LLM 蒸馏为何常用序列级损失？
   答：自回归生成存在多个合理续写，逐 token 强制匹配会压制多样性，序列级或 top-k 蒸馏更贴合生成任务。
5. 问：学生容量不足时如何调整？
   答：提高硬标签权重、降低蒸馏温度或只蒸馏中间层，必要时增大隐藏维或层数。

## 十、小结
损失塑形通过软目标把教师的类间知识高效转移给学生。温度 $\tau$、权重 $\alpha$ 与 $\tau^2$ 补偿是三个必须理解的旋钮：温度决定暗知识强度，权重决定软硬信号的相对话语权，补偿决定梯度尺度是否可比。掌握蒸馏有助于在压缩模型的同时保住泛化与校准。
