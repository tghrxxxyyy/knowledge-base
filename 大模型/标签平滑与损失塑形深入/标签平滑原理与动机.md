# 标签平滑原理与动机

> 对应 Szegedy 2016 标签平滑、Müller 2019 与 huggingface/transformers 的 `label_smoothing_factor`。

## 一、背景与挑战
硬标签（one-hot）把监督信号定为「正确类概率 1、其余为 0」。在交叉熵下，这等价于要求对应 logit 相对其他 logit 趋于无穷大。
模型于是不断增大置信度，训练损失可以降到接近零，但预测概率与真实正确率脱节——这就是过度自信与校准失准。
当训练标签含噪声时，硬标签更危险：模型会以极大梯度去拟合错误标注，把噪声记进参数，泛化随之恶化。
正则化手段很多作用于参数或激活，却少有作用在目标分布上的工具。标签平滑正是填补这一空白的简单做法。
动机很直接：既然无法保证标签绝对正确，就不要要求模型输出绝对自信；给非真类分配一点概率质量，等于承认「我可能错了」。

## 二、核心原理
标签平滑把目标分布从 one-hot 拉向均匀分布：真类保留大部分概率质量 $1-\epsilon$，剩余 $\epsilon$ 平均分给所有类。
这带来三个直接效果：其一对 logits 的惩罚有界，最优解不再是无穷大置信度；其二等价于引入对均匀分布的 KL 惩罚，抑制输出尖峰；其三在有噪声标签时降低错误样本的梯度冲击。
从贝叶斯视角，平滑相当于在标签上放置一个对称先验，使模型对「标签可能错」保持一定容忍度，天然具备抗噪性。
平滑系数 $\epsilon$ 控制这种容忍度：$\epsilon = 0$ 退化为硬标签；$\epsilon \to 1$ 时目标趋于均匀，模型丧失判别能力。
实践中 $\epsilon$ 常取 $0.05 \sim 0.15$，图像分类、机器翻译、语音识别等任务广泛采用，是成本极低却常有效的正则手段。

## 三、形式化与数学基础
平滑目标分布（$K$ 为类别数）：

$$ q_k = \begin{cases} 1 - \epsilon + \epsilon/K, & k = y \\ \epsilon/K, & k \neq y \end{cases} $$

损失为对平滑目标的交叉熵，可分解为硬标签项与均匀项：

$$ L = -\sum_{k} q_k \log p_k = (1-\epsilon)\big(-\log p_y\big) + \epsilon \cdot \frac{1}{K}\sum_{k} -\log p_k $$

第二项正是均匀分布 $u_k = 1/K$ 与 $p$ 的交叉熵，可写成熵与 KL 之和：

$$ \mathrm{CE}(u, p) = H(u) + \mathrm{KL}(u \,\|\, p) = \log K + \mathrm{KL}(u \,\|\, p) $$

因此平滑等价于「最小化 $\mathrm{KL}(u\|p)$」，即鼓励 $p$ 靠近均匀、保持较高熵，这就是「隐式熵正则」的含义。对正确类 logits 的最优点满足：

$$ p_y^{*} = 1 - \epsilon + \epsilon/K < 1 $$

即模型被引导输出一个「留有余地」的置信度，使 softmax 输出更贴近真实频率，改善可靠性图与期望校准误差。

## 四、代码实现
```python
import torch
import torch.nn.functional as F

def smooth_label_loss(logits, target, eps=0.1):
    # 直接调用框架内置的标签平滑，实现高效
    return F.cross_entropy(logits, target, label_smoothing=eps)

# 手写实现：显式构造平滑目标，便于调试与自定义
def smooth_label_loss_manual(logits, target, eps=0.1):
    K = logits.size(-1)
    logp = F.log_softmax(logits, dim=-1)
    nll = -logp.gather(1, target.unsqueeze(1)).squeeze(1)
    uniform_ce = -logp.mean(dim=-1)
    loss = (1.0 - eps) * nll + eps * uniform_ce
    return loss.mean()

# 训练片段
logits = model(inputs)
loss = smooth_label_loss(logits, targets, eps=0.1)
loss.backward()
optimizer.step()
```

## 五、与其他技术对比
| 方案 | 关注点 | 与标签平滑的关系 |
|---|---|---|
| 硬标签交叉熵 | 判别正确性 | 平滑是其推广，$\epsilon=0$ 时等价 |
| 温度标定 | 后处理校准 | 都调分布锐度，但一个改目标、一个改 logits |
| 知识蒸馏 | 迁移类间知识 | 软目标信息更丰富，平滑是其特例（均匀教师） |
| Focal Loss | 难例聚焦 | 关注难度而非置信度，可与平滑组合 |
| mixup | 样本插值 | 在输入与标签上同时插值，平滑目标的推广 |

## 六、常见误区
- 认为平滑总是提升精度：它主要改善校准，对细粒度分类可能压缩类间距离反而降点。
- 在蒸馏中再用平滑：学生已获教师软目标，平滑会稀释真值信号，通常不叠加。
- 把 $\epsilon$ 设得过大：目标趋近均匀，模型学不到判别结构。
- 认为平滑能治噪声标签的一切问题：它只是降低冲击，强噪声仍需样本筛选或鲁棒损失。
- 与温度混用却当作同一旋钮：两者作用对象不同，调参应分别搜索。

## 七、与开源书·权威来源对应

## 八、面试题
1. 问：标签平滑为何改善校准？
   答：它阻止 logits 无限增大，使最优预测概率不再是 1，从而让输出置信度更贴近真实正确率。
2. 问：平滑与均匀分布的关系？
   答：平滑目标可视为 one-hot 与均匀分布的凸组合，$\epsilon$ 是混合比例。
3. 问：$\epsilon$ 过大有什么后果？
   答：目标接近均匀，模型丧失判别力，精度与收敛速度都下降。
4. 问：标签平滑对噪声标签有何作用？
   答：降低错误样本的梯度冲击，提供类似对称先验的容忍度，但不能替代样本清洗。
5. 问：什么时候不该用标签平滑？
   答：蒸馏学生训练、极度细粒度分类或需要高置信度输出的场景需谨慎。

## 九、演进与趋势
- 自适应平滑：按样本置信度或类别频率调整 $\epsilon$，兼顾校准与判别。
- 与温度、mixup、Focal 等结合，形成统一的损失塑形框架。
- 在大模型预训练中，平滑与数据质量、去噪目标共同影响下游校准。
- 具体实现与推荐值以官方最新文档与论文为准。

## 十、小结
标签平滑是成本极低、效果稳定的目标端正则与校准工具：它把 one-hot 拉向均匀，等价于隐式熵正则，抑制过度自信并提升抗噪性。理解其与蒸馏、温度、mixup 的异同，是正确使用它的前提。
