# 标签平滑原理与动机

> 对应 huggingface/transformers 的 `label_smoothing_factor` 与 d2l-ai/d2l-zh。

## 一、背景与挑战
硬标签（one-hot）强迫模型对正确类输出 1、其余为 0，过度自信会致过拟合与校准差，且在有噪声标签时放大错误。

## 二、核心原理
标签平滑把目标分布从 one-hot 拉向均匀：`q_k = 1-ε (k=y)，ε/K (否则)`，让模型不过度自信，提升校准与泛化。

## 三、形式化与数学基础
$ q_k = \begin{cases} 1-\epsilon + \epsilon/K, & k=y \\ \epsilon/K, & k\neq y \end{cases} $

交叉熵损失改为对平滑目标 `q` 求 KL，等价于原 CE 减去与均匀分布的熵正则。

## 四、代码实现
```python
import torch.nn.functional as F
def smooth_label(logits, target, eps=0.1):
    K = logits.size(-1)
    smooth = torch.full_like(logits, eps / (K - 1))
    smooth.scatter_(-1, target.unsqueeze(-1), 1.0 - eps)
    logp = F.log_softmax(logits, -1)
    return (-smooth * logp).sum(-1).mean()
```

## 五、与其他技术对比
硬标签追求零熵目标；Focal Loss 关注难样本；标签平滑关注置信度校准，二者可组合。

## 六、常见误区
在蒸馏场景下再用标签平滑会削弱真值信号；通常蒸馏用硬标签或温度软化。

## 七、与开源书/权威来源对应
huggingface/transformers 提供 `label_smoothing_factor`；d2l-ai/d2l-zh 有专门讲解。

## 八、面试题
问：标签平滑为何改善校准？答：阻止 logits 无限增大，使预测概率更贴近真实置信。

## 九、演进与趋势
自适应平滑、按样本置信度调整 ε 是进阶方向。

## 十、小结
标签平滑是低成本的正则与校准工具，广泛用于大模型预训练。
