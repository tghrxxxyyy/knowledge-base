# 温度软化与对比式损失

> 对应 Hinton 2015 蒸馏温度与 d2l-ai/d2l-zh 对比学习章节。

## 一、背景与挑战
对比学习（如 InfoNCE）依赖温度系数调节样本间区分度；温度同样是损失塑形的关键旋钮。

## 二、核心原理
温度 τ 缩放 logits：`exp(sim/τ)`。高 τ 使分布平滑、关注难负例；低 τ 强化硬区分。本质与蒸馏温度同源。

## 三、形式化与数学基础
$ \mathcal L_{nce} = -\log \frac{\exp(s_+/τ)}{\exp(s_+/τ) + \sum_i \exp(s_i^-/τ)} $

τ 控制对比锐度，影响表征几何结构。

## 四、代码实现
```python
def info_nce(z, labels, tau=0.07):
    z = F.normalize(z, dim=-1)
    sim = z @ z.t() / tau
    sim = sim - sim.max(dim=-1, keepdim=True).values  # 稳定
    return F.cross_entropy(sim, labels)
```

## 五、与其他技术对比
蒸馏温度服务监督信号；对比温度服务表征学习，但都通过缩放 logit 塑形分布。

## 六、常见误区

## 八、面试题
问：对比损失温度过大后果？答：分布过平，难负例贡献被稀释，表征崩塌。
