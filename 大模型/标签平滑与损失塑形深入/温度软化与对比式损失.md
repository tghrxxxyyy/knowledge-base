# 温度软化与对比式损失

> 对应 Hinton 2015 蒸馏温度、Oord 2018 InfoNCE 与 d2l-ai/d2l-zh 对比学习章节。

## 一、背景与挑战
对比学习（如 InfoNCE、SimCLR、CLIP）通过拉近正样本对、推远负样本对来学习表征，其损失中几乎总有一个温度系数 $\tau$ 调节样本间区分度。
温度看似只是一个小超参，却直接决定表征几何：$\tau$ 过大时分布过平、难负例贡献被稀释，$\tau$ 过小则梯度尖锐、训练不稳定甚至表征崩塌。
与此同时，知识蒸馏也用温度软化 logits——两者形式不同，本质却同源：都是用 $\exp(\cdot/\tau)$ 缩放相似度或 logits，改变分布的锐度。
核心挑战在于：温度与批量大小、负例数量、学习率强耦合；在一个配置上调好的温度，换到另一个配置往往失效，需要重新搜索。
理解温度的统一视角，才能在设计对比损失、蒸馏损失乃至推荐系统采样时做出有依据的取舍。

## 二、核心原理
对比损失把「相似度」转成「概率」。给定锚点与正样本相似度 $s_+$、与第 $i$ 个负样本相似度 $s_i^-$，温度为 $\tau$ 时：

$$ P(\text{正样本} \mid \text{锚点}) = \frac{\exp(s_+/\tau)}{\exp(s_+/\tau) + \sum_i \exp(s_i^-/\tau)} $$

最小化其负对数即 InfoNCE。温度 $\tau$ 的倒数 $1/\tau$ 相当于对相似度做增益：$\tau$ 越小，softmax 越尖锐，模型越专注于把最难的负例分开。
在蒸馏中，同样的 $\exp(z/\tau)$ 用于软化教师 logits，$\tau > 1$ 放大暗知识；在对比学习中 $\tau$ 通常远小于 1（如 0.07），起「锐化」作用。二者方向相反，机制一致。
温度还隐式控制梯度的「硬度分配」：较小 $\tau$ 会给难负例更大权重，因此对难负例挖掘与批量大小非常敏感。批量过小时，可用负例不足，温度需相应调大以稳定训练。
本质上，温度是对相似度尺度做重标定的手段，它决定了模型把「区分度预算」花在哪些样本对上。

## 三、形式化与数学基础
InfoNCE 损失的标准形式如下，其中 $z$ 为归一化后的表征，$\mathrm{sim}(\cdot,\cdot)$ 常用余弦相似度：

$$ \mathcal{L}_{\mathrm{nce}} = -\log \frac{\exp(\mathrm{sim}(z, z_+)/\tau)}{\exp(\mathrm{sim}(z, z_+)/\tau) + \sum_{i=1}^{K} \exp(\mathrm{sim}(z, z_i^-)/\tau)} $$

对相似度求偏导，可见难负例获得更大梯度：

$$ \frac{\partial \mathcal{L}_{\mathrm{nce}}}{\partial s_i^-} = \frac{1}{\tau} \cdot P_i^-,\qquad P_i^- = \frac{\exp(s_i^-/\tau)}{\sum_j \exp(s_j^-/\tau)} $$

温度与熵的关系：设 logits 为 $u = s/\tau$，其 softmax 分布的熵 $H(p) = -\sum p_i \log p_i$ 随 $\tau$ 增大而单调增大。温度越低，分布熵越低、越确定。
这解释了为什么温度过大会「坍缩」对比信号：负例概率趋同，正样本与负例的区分被抹平，梯度方向信息减少。
在蒸馏中，$\tau^2$ 补偿也是同一机制：软化使梯度的尺度变化，需显式还原才能与其他损失量级对齐。

## 四、代码实现
```python
import torch
import torch.nn.functional as F

def info_nce(z, labels, tau=0.07):
    # z: [B, D] 表征，labels: 正样本所在的下标
    z = F.normalize(z, dim=-1)
    sim = z @ z.t() / tau
    # 数值稳定：减去每行最大值
    sim = sim - sim.max(dim=-1, keepdim=True).values
    return F.cross_entropy(sim, labels)

# 可学习温度（CLIP 风格）：以 logit scale 参数化，避免温度取负
class LearnableTemp(torch.nn.Module):
    def __init__(self, init=0.07):
        super().__init__()
        self.log_scale = torch.nn.Parameter(torch.log(torch.tensor(1.0 / init)))

    def forward(self):
        return torch.exp(self.log_scale).clamp(max=100.0)

tau_fn = LearnableTemp()
loss = info_nce(z, labels, tau=tau_fn())
```

## 五、与其他技术对比
| 维度 | 对比学习温度 | 蒸馏温度 | 采样温度（生成） |
|---|---|---|---|
| 典型取值 | $\tau \approx 0.07$ | $\tau \in [1, 5]$ | $\tau \in [0.7, 1.5]$ |
| 作用方向 | 锐化分布 | 软化分布 | 软化分布 |
| 服务目标 | 表征区分度 | 迁移暗知识 | 控制生成多样性 |
| 耦合因素 | 批量、负例数、lr | 教师质量、学生容量 | 任务与解码策略 |
| 典型损失 | InfoNCE | KL + CE | 无显式损失 |

## 六、常见误区
- 认为温度与学习率独立：调温度会改变梯度尺度，通常需要同步重搜学习率与其他超参。
- 温度过大：分布过平，难负例贡献被稀释，表征趋于崩塌或学到平凡解。
- 温度过小：梯度尖锐，易被噪声样本主导，训练震荡且对异常值敏感。
- 忽视批量大小：负例越多，温度需要越小的倾向，否则区分度不足。
- 把生成采样温度与对比温度混为一谈：前者作用于解码分布，后者作用于表征损失，调参逻辑完全不同。

## 七、与开源书·权威来源对应
- Hinton, Vinyals, Dean, 2015, *Distilling the Knowledge in a Neural Network*，提出温度软化概念。
- Oord, Li, Vinyals, 2018, *Representation Learning with Contrastive Predictive Coding*，提出 InfoNCE。
- d2l-ai/d2l-zh 对比学习章节讨论相似度、温度与负采样。
- `huggingface/transformers`、`openai/CLIP` 等实现中温度常以 logit scale 形式参数化，具体取值以官方最新文档为准。

## 八、面试题
1. 问：对比损失中温度过大会有什么后果？
   答：分布过平，难负例贡献被稀释，区分度下降，表征可能崩塌。
2. 问：为什么温度要和学习率一起调？
   答：温度改变 softmax 与梯度的尺度，进而改变有效学习率，单独调温度会导致优化不稳。
3. 问：蒸馏温度与对比温度有何异同？
   答：同源（都由 $\exp(\cdot/\tau)$ 缩放）；蒸馏用 $\tau > 1$ 软化，对比用 $\tau < 1$ 锐化。
4. 问：可学习温度有什么好处与风险？
   答：好处是自动适配数据与批量；风险是训练初期温度失稳，需要 clamp 与合理初始化。
5. 问：批量小的时候温度怎么调？
   答：负例不足时通常需要调大温度以稳定分布，或引入队列/记忆库扩充负例。

## 九、演进与趋势
- 可学习温度、逐头温度（per-head temperature）在多头对比表征中被探索。
- 温度与硬负例挖掘、去偏损失结合，缓解假负例带来的错误惩罚。
- 在生成与检索联合模型中，温度成为统一的「相似度标定器」，跨模态对齐尤其依赖它。
- 具体最佳实践随模型与数据变化，以官方最新文档与论文为准。

## 十、小结
温度是对比学习与知识蒸馏共用的损失塑形杠杆：它通过缩放相似度或 logits 改变分布锐度，从而决定模型把区分度预算花在哪些样本上。理解温度、负例数量与学习率的耦合关系，是训练稳定表征与高效蒸馏的前提。
