# 标签平滑与正则化关系

> 对应 Szegedy 2016 Inception-v3 标签平滑、Müller 2019 与 d2l-ai/d2l-zh 训练配置。

## 一、背景与挑战
正则化旨在控制模型容量、缓解过拟合。常见手段分布在三个位置：输入端（数据增强）、激活端（Dropout）、参数端（权重衰减），而标签平滑作用在目标端。
目标端正则长期被忽视：硬标签要求模型对正确类输出概率 1，这等价于要求 logits 无穷大，训练中模型只能不断增大置信度，导致过度自信与校准变差。
标签平滑（label smoothing）通过把目标分布从 one-hot 拉向均匀，抑制无限增大 logits 的动机，从而起到隐式正则作用。
核心挑战是理解它与显式正则（权重衰减、Dropout）的关系：它们是互补还是冗余？在什么场景下平滑会伤害性能？
实践中的困惑还包括平滑系数 $\epsilon$ 如何选、是否与蒸馏/温度冲突、以及在知识蒸馏的教师-学生设定中该用硬标签还是软标签。

## 二、核心原理
硬标签可看作目标分布 $q = \delta_y$，平滑后目标变为在真类与均匀分布之间的凸组合：

$$ q_k = (1-\epsilon)\,\mathbb{1}[k=y] + \frac{\epsilon}{K} $$

从损失角度，对平滑目标求交叉熵等价于原交叉熵加上一项对均匀分布的惩罚：

$$ L = (1-\epsilon)\,\mathrm{CE}(p, y) + \epsilon \cdot \mathrm{KL}(u \,\|\, p) + \text{const} $$

其中 $u$ 为均匀分布。第二项鼓励输出分布保持一定熵，等价于对输出熵施加下界约束，抑制极端尖峰。
权重衰减约束参数范数、Dropout 扰动激活、数据增强扩展输入分布，而标签平滑约束输出分布——四者作用位置不同，理论上正交，可叠加使用。
Müller 等的研究指出：标签平滑能改善校准、提升对某些分布偏移的鲁棒性，但也可能损害类间距离，使相似类更难区分，其效果依赖任务。

## 三、形式化与数学基础
平滑目标的定义（$K$ 为类别数）：

$$ q_k = \begin{cases} 1 - \epsilon + \epsilon/K, & k = y \\ \epsilon/K, & k \neq y \end{cases} $$

交叉熵对平滑目标展开，常数项与 $p$ 无关：

$$ L = -\sum_k q_k \log p_k = (1-\epsilon)\big(-\log p_y\big) + \epsilon \Big(-\frac{1}{K}\sum_k \log p_k\Big) $$

括号内第二项即均匀分布下的交叉熵，等价于最大化输出熵。对 logits 求导可得最优解不再是无穷大：

$$ \frac{\partial L}{\partial z_y} = p_y - (1-\epsilon) - \frac{\epsilon}{K} \cdot K \cdot p_y \;\Rightarrow\; p_y^{*} = 1-\epsilon + \frac{\epsilon}{K} $$

即模型被引导输出「刚好对应平滑目标」的置信度，而非 1。这把校准误差压到更低水平，也是平滑改善可靠性图的机理。

## 四、代码实现
```python
import torch
import torch.nn.functional as F

def smooth_label_loss(logits, target, eps=0.1):
    # 用交叉熵实现标签平滑，避免显式构造 q 的额外显存
    return F.cross_entropy(logits, target, label_smoothing=eps)

# 手写版本：显式构造平滑目标，便于自定义
def smooth_label_loss_manual(logits, target, eps=0.1):
    K = logits.size(-1)
    logp = F.log_softmax(logits, dim=-1)
    nll = -logp.gather(1, target.unsqueeze(1)).squeeze(1)
    smooth = -logp.mean(dim=-1)
    return ((1.0 - eps) * nll + eps * smooth).mean()

# 与权重衰减组合（示意）：正则作用于参数，平滑作用于目标
opt = torch.optim.AdamW(model.parameters(), lr=3e-4, weight_decay=0.1)
loss = smooth_label_loss(logits, targets, eps=0.1)
loss.backward()
opt.step()
```

| 标签平滑 | 目标分布 | 拉向均匀、限熵 | —— |

## 六、常见误区
- 认为平滑越大越好：$\epsilon$ 过大时目标接近均匀，模型丧失判别力，典型取值范围在 $0.05 \sim 0.15$。
- 在蒸馏场景再用标签平滑：学生已从教师软目标获得类间信息，再平滑会削弱真值信号，通常蒸馏用硬标签或温度软化。
- 混淆平滑与温度：两者都改变分布锐度，但平滑改变目标，温度改变 logits 尺度，作用对象不同。
- 忽视校准的双刃性：平滑改善校准却可能压缩类间距离，相似类任务上需谨慎。
- 只调平滑不调其他正则：应把 $\epsilon$ 与权重衰减、Dropout 一起搜索，避免相互抵消或叠加过强。

## 八、面试题
1. 问：标签平滑如何等价于熵正则？
   答：对均匀分布的交叉熵项等价于鼓励输出保持熵，压制尖峰分布。
2. 问：标签平滑与权重衰减的关系？
   答：一个作用于目标分布、一个作用于参数范数，机制不同、可叠加。
3. 问：为什么蒸馏时通常不再用标签平滑？
   答：教师软目标已含类间信息，平滑会进一步削弱真值信号，可能降低学生精度。
4. 问：平滑是否会损害性能？
   答：可能压缩类间距离、影响相似类区分，在细粒度任务上需实测调整 $\epsilon$。
5. 问：$\epsilon$ 一般取多少？
   答：图像分类与 seq2seq 常用 0.1 左右，最终以验证集结果为准。

## 九、演进与趋势
- 自适应平滑、按样本置信度调整 $\epsilon$，与温度、mixup 等结合形成统一塑形框架。
- 在 LLM 预训练与微调中，平滑与蒸馏、偏好优化的交互成为研究点。
- 校准研究推动平滑与后处理温度标定、可靠性图评估的联合使用。
- 具体实现与推荐取值以官方最新文档与论文为准。

## 十、小结
标签平滑是目标端的隐式正则：它把 one-hot 拉向均匀，等价于对输出熵施加下界，从而抑制过度自信、改善校准。它与权重衰减、Dropout、数据增强正交，可组合使用，但需注意与蒸馏的冲突以及对类间距离的潜在损害。
