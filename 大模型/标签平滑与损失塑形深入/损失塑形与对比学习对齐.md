# 损失塑形与对比学习对齐

> 对应 Kendall 2018 不确定性加权、Chen 2018 GradNorm 与 d2l-ai/d2l-zh 多任务章节。

## 一、背景与挑战
现代模型常同时优化多个目标：语言建模 + 对比对齐、主任务 + 辅助任务、生成损失 + 偏好损失。这些损失量纲不同、尺度差异可达数个数量级。
若直接相加，尺度大的分支会主导梯度方向，尺度小的分支几乎不更新，模型看似在训练，实则只优化了其中一项。
对比学习尤其突出：InfoNCE 的数值范围与交叉熵、均方误差都不同，且随负例数量变化，固定权重很难在全流程都合适。
核心挑战是让各分支「同步学习」——既不牺牲主任务，又不让辅助任务沦为装饰；这需要在损失层面做显式的尺度对齐与梯度平衡。
对齐的目标不是让损失数值相等，而是让各分支对参数更新的贡献处于可控、可比、可解释的范围。

## 二、核心原理
最直接的做法是线性加权：总损失 $L = \sum_i \lambda_i L_i$，通过系数 $\lambda_i$ 调节各分支话语权。系数可以是常数，也可以随训练动态变化。
常数权重简单但脆弱：训练早期主导分支可能变化，后期原本合适的权重又可能失衡，需要反复实验。
更稳的思路是基于梯度做平衡。GradNorm 观察到真正决定更新方向的是梯度而非损失数值，于是让各分支的梯度范数按目标比例调整。
另一个思路是让模型自己学权重。Kendall 等把每个任务的权重与其同方差不确定性绑定，用可学习参数自动权衡，无需手工搜索。
还可以对温度做逐分支设置：对比分支用较小温度锐化，生成分支用标准温度，避免同一温度在不同损失上产生不同有效尺度。
实践中常组合使用：先按经验设定初始权重，再引入梯度或不确定性机制做微调，兼顾稳定与效率。

## 三、形式化与数学基础
线性加权多任务损失，其中 $\lambda_i$ 为第 $i$ 个分支的权重：

$$ L = \sum_{i=1}^{K} \lambda_i L_i $$

固定权重下，第 $i$ 个分支的有效步长被其梯度范数放大：

$$ \Delta \theta_i \propto \lambda_i \, \lVert \nabla_\theta L_i \rVert $$

若 $\lambda_i \lVert \nabla L_i \rVert$ 在分支间严重失衡，小者几乎不更新。梯度平衡的朴素形式是令 $\lambda_i \propto 1 / \lVert \nabla L_i \rVert$：

$$ \lambda_i = \frac{1}{\lVert \nabla_\theta L_i \rVert} \cdot c,\qquad c \text{ 为常数} $$

Kendall 不确定性加权的目标函数（$\sigma_i$ 为可学习同方差不确定性）：

$$ L = \sum_i \frac{1}{2\sigma_i^2} L_i + \log \sigma_i $$

其直观含义：不确定性大的分支自动降权，$\log \sigma_i$ 防止权重无界增长。GradNorm 则显式约束各分支梯度范数向目标值 $\bar{G}$ 靠拢。

## 四、代码实现
```python
import torch

def weighted_sum(losses, lams):
    # losses/lams 为同 key 的字典
    total = torch.zeros((), device=next(iter(losses.values())).device)
    for k in losses:
        total = total + lams[k] * losses[k]
    return total

losses = {"lm": lm_loss, "cl": cl_loss}
lams = {"lm": 1.0, "cl": 0.1}
total = weighted_sum(losses, lams)

# 梯度归一化（示意）：按各分支梯度范数反比设定权重
def grad_balanced_weights(losses, model):
    norms = {}
    for k, loss in losses.items():
        grads = torch.autograd.grad(loss, model.parameters(),
                                    retain_graph=True, allow_unused=True)
        sq = sum((g.pow(2).sum() for g in grads if g is not None), torch.zeros(()))
        norms[k] = sq.sqrt().item()
    inv = {k: 1.0 / (v + 1e-8) for k, v in norms.items()}
    s = sum(inv.values())
    return {k: v / s * len(inv) for k, v in inv.items()}
```

## 五、与其他技术对比
| 方案 | 权重来源 | 优点 | 缺点 |
|---|---|---|---|
| 固定权重 | 人工设定 | 简单、可复现 | 脆，需反复调参 |
| 梯度归一化 | 梯度范数 | 自动平衡、直观 | 需额外反传，开销高 |
| 不确定性加权 | 可学习 $\sigma_i$ | 端到端、少调参 | 初期不稳定，可能退化 |
| 损失裁剪/缩放 | 数值归一 | 实现简单 | 不保证梯度平衡 |

## 六、常见误区
- 直接相加忽略量级：主任务被辅任务带偏，或辅任务完全学不动。
- 只对齐损失数值，不对齐梯度：数值接近不代表更新贡献接近。
- 权重一成不变：训练不同阶段各分支难度变化，理想权重应随之调整。
- 过度增加平衡机制：自适应权重引入额外反传与超参，小规模任务上得不偿失。
- 用验证集指标单向调权：容易过拟合并破坏主任务，应关注各分支收敛曲线再调。

## 八、面试题
1. 问：为什么多损失要对齐尺度？
   答：防止单分支梯度主导，保证各目标同步学习，避免辅助任务形同虚设。
2. 问：损失数值相等是否意味着平衡？
   答：不是，梯度范数才决定参数更新量，数值与梯度尺度并不一致。
3. 问：不确定性加权的直觉是什么？
   答：不确定性大的分支降权，$\log \sigma_i$ 正则防止权重发散，实现端到端权衡。
4. 问：梯度平衡的主要代价？
   答：需要额外反传各分支梯度，显存与计算开销上升，且对 reduction 方式敏感。
5. 问：对比分支权重通常如何设？
   答：常从比主任务小一到两个量级起步，再依收敛情况调整，并使温度与该权重联合搜索。

## 九、演进与趋势
- 可学习权重、不确定性加权与梯度手术（PCGrad）等成为多任务主流方案。
- 大模型对齐中，SFT 损失、偏好损失与 KL 正则的组合也属于多损失塑形问题。
- 自动化权重搜索与元学习（如把权重作为外层优化变量）在持续学习中得到探索。
- 具体方案随模型规模与任务结构变化，以官方最新文档与论文为准。

## 十、小结
损失塑形在多目标训练中决定各信号的相对话语权。真正的对齐发生在梯度层而非数值层：固定权重简单但脆，梯度归一化与不确定性加权更稳但引入开销。合理做法是先按经验设初值，再用轻量机制动态校正。
