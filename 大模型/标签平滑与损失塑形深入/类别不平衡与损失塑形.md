# 类别不平衡与损失塑形

> 对应 Lin 2017 Focal Loss、Cui 2019 Class-Balanced Loss 与 d2l-ai/d2l-zh 训练技巧。

## 一、背景与挑战
真实数据往往呈长尾分布：少数头部类占据绝大多数样本，大量尾部类样本稀少。默认的交叉熵对所有样本等权，梯度被多数类主导。
结果是模型对多数类过拟合、对少数类欠拟合，整体准确率虚高但在稀有类上表现糟糕，且预测概率严重校准失准。
类别不平衡的解决路径有三条：数据层（重采样、增强）、算法层（损失加权、Focal 类）、以及后处理（阈值调整、logit 调整）。
其中损失塑形属于算法层，优点是低侵入——不改数据管道、不动模型结构，只调整每个样本对损失的贡献权重。
核心挑战是：加权会引入对稀有类的偏差，权重过大又会让模型拟合稀有类中的噪声，需要在「平衡」与「过拟合」之间找平衡点。

## 二、核心原理
最直接的塑形是按类别频率加权。类别 $c$ 的样本越少，权重 $w_c$ 越大，使其梯度贡献与多数类可比。
朴素的逆频率权重 $w_c \propto 1/N_c$ 过于激进，会让极稀有类权重爆炸。Cui 等提出「有效样本数」$1-\beta^{N_c}$ 的倒数作为权重，随样本数增长而饱和。
Focal Loss 从「难度」而非「频率」入手：对已分对的易样本降权，把梯度集中到难样本上，天然缓解多数类易样本的压制。
样本级重加权与类别级加权可以叠加：先按频率平衡类别，再按预测置信度聚焦难例，形成复合塑形。
常与标签平滑联合使用：平滑目标避免模型对稀有类的少量噪声样本过度自信，进一步改善泛化与校准。

## 三、形式化与数学基础
加权交叉熵，$w_c$ 为类别 $c$ 的权重：

$$ L = -\sum_{c=1}^{K} w_c \cdot \mathbb{1}[y=c] \cdot \log p_c $$

逆频率权重的一种常见归一化形式（$N$ 为总样本数）：

$$ w_c = \frac{N}{K \cdot N_c} $$

有效样本数权重（$\beta \in [0,1)$ 控制饱和速度）：

$$ w_c \propto \frac{1 - \beta}{1 - \beta^{N_c}} $$

Focal Loss 引入调制因子 $(1-p_t)^{\gamma}$，$\gamma > 0$ 时易样本被降权：

$$ L_{\mathrm{focal}} = -\alpha_t (1 - p_t)^{\gamma} \log p_t $$

当 $\gamma = 0$ 时退化为加权交叉熵；$\gamma$ 越大，对难样本的聚焦越强，但过大易被离群噪声主导。

## 四、代码实现
```python
import torch

class_counts = torch.tensor([5000.0, 500.0, 50.0])
# 逆频率权重并归一化到均值为 1
w = 1.0 / class_counts
w = w / w.sum() * len(class_counts)
criterion = torch.nn.CrossEntropyLoss(weight=w)

# 有效样本数权重（Class-Balanced Loss 思路）
def effective_number_weights(counts, beta=0.999):
    eff = 1.0 - torch.pow(beta, counts)
    w = (1.0 - beta) / eff
    return w / w.sum() * len(counts)

# Focal Loss 核心计算
def focal_loss(logits, targets, gamma=2.0, alpha=None):
    logp = torch.log_softmax(logits, dim=-1)
    logpt = logp.gather(1, targets.unsqueeze(1)).squeeze(1)
    pt = logpt.exp()
    loss = -((1.0 - pt) ** gamma) * logpt
    if alpha is not None:
        loss = loss * alpha.gather(0, targets)
    return loss.mean()
```

## 五、与其他技术对比
| 方案 | 作用层 | 优点 | 缺点 |
|---|---|---|---|
| 损失加权 | 梯度 | 低侵入、易实现 | 引入偏差、权重重则拟合噪声 |
| 重采样 | 数据分布 | 直观、无偏倾向 | 改管道、可能过采样稀有噪声 |
| Focal Loss | 样本难度 | 自动聚焦难例 | 对离群噪声敏感 |
| 阈值/logit 调整 | 后处理 | 无需重训 | 只改决策边界不改表征 |
| 标签平滑 | 目标分布 | 改善校准 | 过强会削弱判别力 |

这三类手段并不互斥：损失加权改变梯度分布，重采样改变数据分布，标签平滑改善校准，实践中常组合使用。

## 六、常见误区
- 权重越大越好：稀有类权重过大会让模型拟合其中的噪声，泛化反而变差，需配合早停或强正则。
- 只看整体准确率：不平衡场景下整体准确率会掩盖稀有类的失败，应看宏平均、每类召回或 F1。
- 忽略校准：重加权后模型对稀有类往往过度自信，应结合标签平滑或温度标定。
- 把 Focal 当万能：$\gamma$ 过大会被离群样本主导，且对某些任务收益有限。
- 不做权重归一化：不同批次权重尺度变化会改变有效学习率，应在固定集合上归一化。

## 八、面试题
1. 问：损失加权与重采样如何取舍？
   答：加权不改数据管道但引入偏差；重采样更接近无偏但实现复杂、可能重复稀有噪声。
2. 问：为什么逆频率权重可能过激？
   答：极稀有类权重会爆炸，使训练被个别样本主导，需要用有效样本数等形式饱和。
3. 问：Focal Loss 与类别加权有何不同？
   答：Focal 按样本难度降权易例，类别加权按频率提升稀有类，二者可叠加。
4. 问：不平衡时该看什么指标？
   答：宏平均 F1、每类召回、混淆矩阵与校准误差，而非单一整体准确率。
5. 问：如何避免稀有类过拟合？
   答：限制权重上限、标签平滑、早停、数据增强与强正则组合使用。

## 九、演进与趋势
- 自适应重加权（按损失难度、按梯度贡献）正逐步替代固定频率权重。
- 与长尾表征学习、解耦训练（表征/分类器分开平衡）结合，成为长尾研究主流。
- 大模型场景下，类别不平衡转为「数据配比」问题，损失塑形与数据混合策略协同。
- 具体方案与超参以官方最新文档与论文为准。

## 十、小结
损失塑形是处理类别不平衡的有效且低侵入手段：逆频率加权提升稀有类、Focal 聚焦难例、标签平滑改善校准。三者可叠加，但必须警惕权重过大带来的噪声过拟合，并用宏平均等指标而非整体准确率来评估真实效果。
