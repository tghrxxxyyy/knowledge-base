# 类别不平衡与损失塑形

> 对应 huggingface/transformers 损失配置与 d2l-ai/d2l-zh 训练技巧。

## 一、背景与挑战
长尾分布下多数类主导梯度，少数类学不好。需在损失层面重新加权以平衡贡献。

## 二、核心原理
对类别 c 施加权重 `w_c = N / (K·N_c)` 或按频率 `1/freq^α` 缩放，使稀有类获得更大梯度信号。

## 三、形式化与数学基础
加权 CE：`L = -Σ_c w_c · 1[y=c] · log p_c`。配合标签平滑可进一步软化目标，避免对稀有类过度自信。

## 四、代码实现
```python
class_counts = torch.tensor([5000, 500, 50])
w = 1.0 / class_counts.float()
w = w / w.sum() * len(class_counts)
criterion = torch.nn.CrossEntropyLoss(weight=w)
```

## 五、与其他技术对比
上采样改变数据分布；损失加权改变梯度分布；标签平滑独立地改善校准，三者可叠加。

## 六、常见误区
权重过大会让稀有类过拟合噪声；需配合早期停止或强正则。

## 七、与开源书/权威来源对应
d2l-ai/d2l-zh 讲解类别加权；huggingface/transformers 支持 `weight` 参数传递。

## 八、面试题
问：损失加权与采样如何取舍？答：加权不需改数据管道但引入偏差，采样更无偏但实现复杂。

## 九、演进与趋势
自适应重加权（如按损失难度）正替代固定权重。

## 十、小结
损失塑形是处理不平衡的有效且低侵入手段。
