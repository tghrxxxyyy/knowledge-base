# 模型卡与文档

> 见「安全合规审计深入/合规审计总览」；Mitchell et al., *Model Cards*, 2019。

## 一、背景与挑战

模型能力/局限/风险若不透明，难被问责。

## 二、核心原理

**模型卡（Model Card）**标准化记录：用途、训练数据、评估指标、已知局限、伦理考量、偏见结果。类似地有**数据卡（Datasheet）**记录数据来源与处理。提升透明度与可问责。

## 三、关键要点

- 透明是信任前提。
- 需随版本更新。

## 四、代码实现

```python
model_card = {
  "intended_use": "...", "risks": [...], "evaluation": {...}
}
```

## 五、与其他对比

- 代码注释局部；模型卡全局。
