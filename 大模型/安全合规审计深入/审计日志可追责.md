# 审计日志与可追责

> 见「安全合规审计深入/合规审计总览」与「数据治理血缘深入」；可追溯。

## 一、背景与挑战

出事后需追到「谁、用什么数据、生成了什么」。

## 二、核心原理

记录：请求/响应对、模型版本、提示模板、检索来源（RAG）、用户/时间、过滤动作。日志需防篡改、可检索，支撑事件复盘与监管取证。结合数据血缘（见数据治理章）形成全链路溯源。

## 三、关键要点

- 不可篡改是信任基础。
- 隐私数据需脱敏存储。

## 四、代码实现

```python
log = {"req": q, "resp": a, "model": ver, "rag": src, "ts": now}
audit_store.append(hash_chain(log))
```

## 五、与其他对比

- 普通日志易改；审计需防篡改。

## 六、常见误区

- 记录即合规——需可检索防篡改。
