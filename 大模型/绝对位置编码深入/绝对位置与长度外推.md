# 绝对位置与长度外推

> 对应 Chen et al., *Extending Context Window via Positional Interpolation*, 2023；Press et al., *ALiBi*, 2022。

## 一、背景与挑战

绝对位置编码把位置绑死到固定索引，序列一旦超过训练长度，模型遇到从未见过的绝对位置，性能骤降。

## 二、核心原理

两类解法：(1) 对位置索引做插值/缩放，使其落入训练区间（PI 思路同样适用于绝对位置）；(2) 干脆不用绝对位置，改用在分数上加随距离线性增长的偏置（ALiBi），天然随长度线性外推。

## 三、数学形式

绝对位置外推需满足 $PE'_{i}=f(PE_{i})$ 落在训练分布；ALiBi：$score_{ij}=q_i k_j^T/\sqrt d - m\cdot|i-j|$，偏置随距离线性、与位置绝对值无关。

## 四、代码实现

```python
# 绝对位置插值扩展
pe_ext = torch.nn.functional.interpolate(pe[:L].T, L2).T
# ALiBi 偏置
bias = -m * torch.abs(i[:, None] - j[None, :])
```

## 五、与其他对比

- 与 相对位置编码深入 的外推（PI/NTK）共享主题。
- ALiBi 属“无绝对位置”思路，见 无位置编码深入。

## 六、常见误区

- 直接外推绝对位置索引而不缩放，困惑度暴增。
- 以为可学习位置表能自动外推（不能）。

## 八、面试题

- 绝对位置为何难外推？答：测试位置超出训练索引范围，查表/编码落在未训练区域。

## 九、演进

固定长度 → 位置插值 → 改用相对/ALiBi 免外推。

## 十、小结

绝对位置外推困难，是其在现代长上下文模型中逐步被相对编码取代的主因。
