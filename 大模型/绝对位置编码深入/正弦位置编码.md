# 正弦位置编码

> 对应 Vaswani et al., *Attention Is All You Need*, 2017。

## 一、背景与挑战

希望位置编码能外推到比训练更长的序列，且不同维度编码不同频率以便模型学相对位置。

## 二、核心原理

用不同频率的正弦/余弦构造确定性位置向量：偶数维用 $\sin$、奇数维用 $\cos$，频率按维度几何递减。它是固定的、无需学习的，且对任意偏移具线性可表达的相对性。

## 三、数学形式

$p_{i,2k}=\sin(i/10000^{2k/d})$，$p_{i,2k+1}=\cos(i/10000^{2k/d})$；关键点：$PE_{i+\delta}$ 可由 $PE_i$ 线性变换得到，利于学相对位置。

## 四、代码实现

```python
def sinusoidal(n, d, base=10000.0):
    i = torch.arange(n)[:, None]; k = torch.arange(0, d, 2)[None, :]
    ang = i / (base ** (k / d))
    pe = torch.zeros(n, d); pe[:, 0::2] = torch.sin(ang); pe[:, 1::2] = torch.cos(ang)
    return pe
```

## 五、与其他对比

- 与可学习绝对位置相比，正弦无需训练且理论上可外推。
- 与 RoPE 相比，正弦是加性、RoPE 是旋转乘法。

## 六、常见误区

- 实践表明正弦外推能力有限，常不如可学习+重训。
- 维度奇偶分配写错会破坏频率结构。

## 八、面试题

- 正弦编码为何用不同频率？答：多频率让模型同时感知局部与全局位置，且相对偏移可线性表示。

## 九、演进

固定正弦 → 可学习绝对 → 各类相对编码。

## 十、小结

正弦编码是经典确定性方案，理论优雅但因外推与表达力问题，实际常被可学习或 RoPE 取代。
