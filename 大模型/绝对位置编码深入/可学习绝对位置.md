# 可学习绝对位置编码

> 对应 Devlin et al., *BERT: Pre-training of Deep Bidirectional Transformers*, 2018。

## 一、背景与挑战

固定正弦在下游未必最优；能否让模型从数据中自己学位置表示？

## 二、核心原理

用一个大小为 $[max\_len, d]$ 的嵌入表，每个位置对应一个可训练向量，随模型一起优化；推理超出 $max\_len$ 的位置无法查表，故长度受限。

## 三、数学形式

$h_i = x_i + E_{pos}[i]$，$E_{pos}\in \mathbb R^{L_{max}\times d}$ 为可学习参数；损失反向传播更新 $E_{pos}$。

## 四、代码实现

```python
self.pe = nn.Embedding(512, d_model)
pos = torch.arange(seq_len, device=x.device)
h = x + self.pe(pos)
```

## 五、与其他对比

- 与正弦编码相比更灵活但无外推、有长度上限。
- 与 相对位置编码深入 相比，位置仍加在输入层。

## 六、常见误区

- 推理序列超过 $L_{max}$ 会索引越界；需裁剪或插值。
- 预训练长度固定后扩展上下文须重训或插值位置表。

## 八、面试题

- 可学习绝对位置缺点？答：无外推能力，超出训练长度即失效，且占用参数。

## 九、演进

正弦 → 可学习绝对(BERT) → 相对/RoPE。

## 十、小结

可学习绝对位置简单有效但受限于训练长度，是 BERT 类模型的经典选择。
