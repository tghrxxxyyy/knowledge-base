# 绝对位置编码总览

> 对应 Vaswani et al., *Attention Is All You Need*, 2017；Devlin et al., *BERT*, 2018。

## 一、背景与挑战

自注意力本身对输入顺序置换等变，无位置信息则“猫吃鱼”与“鱼吃猫”无法区分，必须显式注入词序。

## 二、核心原理

绝对位置编码在词嵌入上逐位置加一个位置向量（正弦或可学习），使每个位置有固定表示；位置信息随残差流贯穿各层。

## 三、数学形式

输入 $h_i = x_i + p_i$，$p_i$ 为第 $i$ 个位置的编码；注意力对 $(h_i,h_j)$ 运算，位置通过加性进入表征。

## 四、代码实现

```python
import torch.nn as nn
self.pos = nn.Embedding(max_len, d_model)      # 可学习绝对位置
h = tok_emb + self.pos(torch.arange(n))
```

## 五、与其他对比

- 与 相对位置编码深入 对照：一个加在输入、一个加在注意力分数。
- 与 无位置编码深入 对照：此处主动注入绝对位置。

## 六、常见误区

- 认为位置编码可有可无；无位置则模型顺序盲。
- 训练/推理长度不一致时超出表范围的可学习位置失效。

## 八、面试题

- 为何自注意力需要位置编码？答：注意力对置换等变，无位置则丢失词序信息。

## 九、演进

正弦固定 → 可学习绝对 → 相对/RoPE 取代主流。

## 十、小结

绝对位置编码是 Transformer 注入词序的最早方案，简单但外推受限，今天多被相对方案取代。
