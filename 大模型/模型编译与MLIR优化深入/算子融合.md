# 算子融合

> 对应 kernel 融合优化；与 内存高效注意力深入 共属减少 IO。

## 一、背景与挑战

多个小算子各自读写 HBM，带宽浪费；融合为单 kernel 在寄存器/共享内存完成。

## 二、核心原理

元素级链（LayerNorm+激活+matmul 偏置）融合；减少中间张量物化；需分析数据依赖与内存生命周期。

## 三、数学形式

融合降 IO 量：原 $\sum_i |O_i|$ 中间张量读写 → 融合后仅首尾张量，省 $\sum_{i=1}^{k-1}|O_i|$。

# 伪：fused layernorm + gelu

## 五、与其他对比

- 与 FlashAttention（注意力内融合）同思路；
- 与 量化内核深入 可叠加。

## 六、常见误区

- 过度融合致寄存器溢出反慢；
- 融合后数值精度与原算子累积序不同。
