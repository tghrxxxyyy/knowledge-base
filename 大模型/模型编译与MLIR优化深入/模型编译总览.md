# 模型编译总览

> 对应 TVM/MLIR 体系；与 算子融合深入 / 推理引擎深入 衔接。

## 一、背景与挑战

逐算子调用框架（eager）开销大、kernel Launch 多；编译把图优化为高效可执行，降延迟提吞吐。

## 二、核心原理

捕获计算图 → 多层 IR 优化（常量折叠、算子融合、布局改写） →  lowering 到设备后端（CUDA/CPU）生成 kernel。

## 三、数学形式

计算图 $G=(V,E)$；融合把子图 $S\subset V$ 合成单一 kernel，减少中间张量 IO 次数 $|E|$。

## 四、代码实现

```python
mod = torch.export.export(model, args)
opt = torch.compile(mod, backend="inductor")
```

## 五、与其他对比

- 与 推理引擎（TensorRT/llama.cpp）目标重叠但层级不同；
- 与 张量程序深入 互补（编译期可做 μP 形状推导）。

## 六、常见误区

- 以为编译总更快（小图/动态形状编译开销大）；
- 忽略动态控制流难捕获。
