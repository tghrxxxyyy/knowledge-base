# 对比损失与三元组损失

> 对应 Hadsell et al., 《Dimensionality Reduction by Learning...》, 2006（对比损失）；Schroff et al., FaceNet, 2015（三元组）。

## 一、背景与挑战

成对相似标签需转为嵌入距离约束；三元组引入锚-正-负关系更细。

## 二、核心原理

对比损失对正负对分别用不同项；三元组损失要求 $d(a,p)+\alpha < d(a,n)$，推远负例。

## 三、数学形式

三元组损失 $\mathcal L = \max(0, \|f(a)-f(p)\|^2 - \|f(a)-f(n)\|^2 + \alpha)$。

## 四、代码实现

```python
d_pos = ((emb_a - emb_p)**2).sum(-1)
d_neg = ((emb_a - emb_n)**2).sum(-1)
loss = relu(d_pos - d_neg + margin)
```

## 五、与其他对比

- 与 难负样本挖掘深入（三元组需选难负）共享。
- 与 InfoNCE深入（对比变体）衔接。

## 六、常见误区

- margin 过大难收敛、过小无约束。
- 随机三元组大量平凡样本无梯度。

## 八、面试题

- 三元组损失为何需难例？答：随机三元组大多已满足约束得零梯度，难例才提供有效信号。

## 九、演进

对比损失 → 三元组 → 难三元组/batch hard。

## 十、小结

对比与三元组以成对/三元约束塑嵌入，难例选择是关键。
