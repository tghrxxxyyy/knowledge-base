# 中心损失与角度边际

> 对应 Wen et al., 《Center Loss》, 2016；以及 Deng et al., 《ArcFace》, 2019。

## 一、背景与挑战

softmax 类内分散；需同时压缩类内、增大类间，尤其人脸/细粒度。

## 二、核心原理

中心损失为每个类学一个中心，惩罚样本到类中心距离；ArcFace 在角度空间加加性边际 $m$。

## 三、数学形式

中心损失 $\mathcal L_c = \frac12 \sum \|x_i - c_{y_i}\|^2$；ArcFace $\cos(\theta_{y_i}+m)$ 增大决策边界。

## 四、代码实现

```python
center = centers[y]
loss = ce + lambda_c * ((x - center)**2).sum()
```

## 五、与其他对比

- 与 度量学习总览（马氏度量）互补。
- 与 分类边距/对齐损失深入 共享。

## 六、常见误区

- 中心更新不稳需小学习率。
- ArcFace 的 m 过大类不可分。
