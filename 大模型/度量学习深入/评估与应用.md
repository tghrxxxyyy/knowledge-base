# 度量学习评估与应用

> 对应 嵌入评估指标（Recall@k、MAP）；检索与聚类应用。

## 一、背景与挑战

嵌入质量需可量化；不同任务指标侧重不同（检索看 Recall，聚类看 NMI）。

## 二、核心原理

用留一法或查询集测 Recall@k；用 NMI/ARI 评聚类；用检索命中评排序质量。

## 三、数学形式

$Recall@k = \frac{1}{N}\sum \mathbf 1[gt \in topk(\text{neighbors}(q)]$。

## 四、代码实现

```python
hits = sum(gt in topk(neighbors(q), k) for q, gt in queries)
recall = hits / len(queries)
```

## 五、与其他对比

- 与 少样本适配深入（原型距离分类）共享度量。
- 与 向量检索算法深入（用嵌入检索）衔接。

## 六、常见误区

- 只用分类准确率忽略嵌入结构。
- 评测集与训练分布不一致。

## 八、面试题

- 如何评估嵌入？答：用检索 Recall@k 与聚类 NMI，看距离结构是否对应语义。

## 九、演进

分类精度 → 检索/聚类指标 → 下游任务迁移。

## 十、小结

度量学习评估须看嵌入结构指标，Recall@k 与 NMI 是常用标尺。
