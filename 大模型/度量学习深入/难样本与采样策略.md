# 度量学习中的难样本与采样

> 对应 Wu et al., 《Sampling Matters》, 2017（对度量学习负采样的研究）。

## 一、背景与挑战

负样本/三元组选择决定嵌入质量；不当采样使训练无效或塌缩。

## 二、核心原理

半难负（距离正例但不至于太难）常最优；距离加权采样按 $P\propto d$ 取负，提升信息量。

## 三、数学形式

距离加权采样 $P(n)\propto d(a,n)^\alpha$，$\alpha$ 控难度偏好。

## 四、代码实现

```python
weights = (dists ** alpha)
neg = random.choices(cands, weights=weights)
```

## 五、与其他对比

- 与 难负样本挖掘深入（度量学习中应用）共享。
- 与 负采样策略深入总览 衔接。

## 六、常见误区

- 全用最难负致训练崩。
- 忽略正对质量（增强不当）。

## 八、面试题

- 为何半难负好？答：太难是噪声、太易零梯度，半难提供稳定有效信号。

## 九、演进

随机三元组 → 半难 → 距离加权采样。

## 十、小结

度量学习采样策略决定信号质量，半难与距离加权更稳更有效。
