# 度量学习总览

> 对应 Kulis et al., 《Metric Learning》综述, 2012；学习嵌入空间的距离度量。

## 一、背景与挑战

固定度量（欧氏）未必适合任务；度量学习从数据中学习使相似样本近、不相似远。

## 二、核心原理

学习映射 $f_\theta$ 把样本映入嵌入空间，以对比/三元组/分类边距等目标优化距离结构。

## 三、数学形式

马氏距离 $d_M(x,y)=\sqrt{(x-y)^\top M (x-y)}$，$M\succ 0$ 为待学度量矩阵。

## 四、代码实现

```python
emb_a, emb_b = enc(a), enc(b)
dist = ((emb_a - emb_b)**2).sum(-1)
```

## 五、与其他对比

- 与 负采样策略深入（对比学习用负样本）共享。
- 与 少样本适配深入（原型距离）衔接。

## 六、常见误区

- 只拉近距离不推远致坍缩。
- 度量过拟合训练对。

## 八、面试题

- 度量学习目标？答：学映射使同类近、异类远，等价于学好嵌入空间的距离结构。

## 九、演进

马氏距离 → 深度度量 → 对比/三元组表征。

## 十、小结

度量学习以数据驱动距离，是表征学习与检索的基础。
