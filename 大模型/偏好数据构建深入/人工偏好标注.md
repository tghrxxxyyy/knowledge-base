# 人工偏好标注

> 对应 InstructGPT 标注流程（Ouyang et al., 2022）。

## 一、背景与挑战

人工标注最可靠但贵、慢、易不一致；需规范与质量控制。

## 二、核心原理

给标注者清晰指南（有用/真实/无害），同 prompt 多标注取多数；用一致性筛选合格标注者。

## 三、数学形式

一致性 $a = \frac{1}{N}\sum \mathbb I[y_i=y_j]$；用 Krippendorff's $\alpha$ 控质量。

## 四、代码实现

```python
from statsmodels.stats.inter_rater import cohens_kappa
kappa = cohens_kappa(table)        # 标注者一致性
```

## 五、与其他对比

- 与 RLAIF（省成本）对照，人工更准。
- 与 安全与对齐深入（无害标注）共享。

## 六、常见误区

- 标注指南模糊致主观偏差。
- 忽略标注者疲劳/偏见。

## 八、面试题

- 问：如何控标注质量？答：多标注取多数、算一致性系数、筛不合格标注者、清晰指南。

## 九、演进

单标注 → 多标注共识 → 主动学习挑难例。

## 十、小结

人工标注贵但可信，流程规范与一致性校验不可少。
