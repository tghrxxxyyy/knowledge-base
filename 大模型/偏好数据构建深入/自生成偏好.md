# 自生成偏好数据

> 对应模型自采样构造偏好；与 合成数据质量深入 衔接。

## 一、背景与挑战

人工/外部评委仍受限；用模型自身多采样自然产生优劣对。

## 二、核心原理

同一 prompt 采样多个回答，用规则（可执行性/长度/正确）或强模型挑优劣构成偏好对；适用于可验证任务。

## 三、数学形式

$\{y_1..y_k\}\sim\pi(\cdot|x)$，偏好 $(y_w,y_l)=\text{rank}(\{y_i\})$ 按验证器分。

## 四、代码实现

```python
samples = [model(x) for _ in range(k)]
scored = sorted(samples, key=verifier, reverse=True)
pair = (x, scored[0], scored[-1])
```

## 五、与其他对比

- 与 RLAIF 互补（这里用验证器而非评委）。
- 与 过程监督与结果监督深入（验证器）共享。

## 六、常见误区

- 验证器弱致错误标偏好。
- 采样温度不当致差异失真。

## 七、与开源书对应

- datawhalechina/llm-universe：https://github.com/datawhalechina/llm-universe
- mlabonne/llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- 问：自生成偏好如何保证质量？答：用可靠验证器/规则排序，而非模型自评，避免自我偏好。

## 九、演进

人工 → 评委模型 → 验证器驱动自生成。

## 十、小结

自生成偏好可规模化，但依赖可信验证器，适合可验证域。
