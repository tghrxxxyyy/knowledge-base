# 偏好数据构建总览

> 对应 Ouyang et al., *InstructGPT*, 2022；Christiano et al., *Deep RLHF*, 2017。

## 一、背景与挑战

对齐质量取决于偏好数据：覆盖、一致性、无偏。构造方式多样但各有权衡。

## 二、核心原理

主要来源：人工标注（贵、准）、AI 反馈 RLAIF（省、规模化）、模型自生成对（同 prompt 多采样选优劣）、规则/奖励合成。

## 三、数学形式

偏好集 $D=\{(x, y_w, y_l)\}$，需 $y_w\succ y_l$；质量由一致性 $P(agree)$ 与覆盖衡量。

## 四、代码实现

```python
pairs = [(x, pick(better(a,b)), pick(worse(a,b)))
         for x,a,b in sampled]
```

## 五、与其他对比

- 与 直接偏好优化深入 / 奖励模型深入（同依赖偏好）衔接。
- 与 指令数据构建深入（SFT 数据）对照。

## 六、常见误区

- 偏好差异太小模型难学、太大易被捷径。
- 标注者偏见未校正致对齐偏移。

## 八、面试题

- 问：偏好对差异多大合适？答：中等差异——太近无信号、太远偏离真实偏好分布。

## 九、演进

人工 → AI 反馈 → 合成偏好规模化。

## 十、小结

偏好数据是 RLHF/DPO 上限，构造需质量、覆盖、无偏并重。
