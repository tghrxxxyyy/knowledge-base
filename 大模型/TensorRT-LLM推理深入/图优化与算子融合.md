# 图优化与算子融合

> 对应 NVIDIA/TensorRT-LLM; Dao 2022 FlashAttention; Shazeer 2020 GLU。

## 一、背景与挑战
Transformer 层含大量小算子（LayerNorm、Silu、MatMul），逐个启动内核开销大。

## 二、核心原理
构建期把相邻算子融合为单一 CUDA 核（如 RMSNorm+MatMul、GLU 融合），减少访存与启动；常量折叠与布局优化进一步提速。

## 三、形式化与数学基础
GLU 门控：
$ \text{GLU}(x) = (xW_1) \otimes \text{silu}(xW_2) $
融合后单次遍历完成两矩阵乘与激活。

## 四、代码实现
```python
# 伪代码：融合 RMSNorm + QKV 投影
fused = tensorrt_llm.functional.rmsnorm(x, weight, eps)
qkv = fused @ w_qkv                       # 融合内核内完成
```

## 五、与其他技术对比
eager 模式逐个算子执行；图模式融合大幅降内核启动与中间张量读写。

## 六、常见误区
误区：融合总有益。过小算子融合收益有限，需构建器启发式决定。

## 七、与开源书/权威来源对应
TensorRT 优化器文档；Shazeer 2020 GLU。见 NVIDIA/TensorRT-LLM。

## 八、面试题
问：算子融合为何省时？
答：减少内核启动数与中间显存读写，提升算术强度。

## 九、演进与趋势
自动 kernel 生成（如 CUTLASS）让融合更通用。

## 十、小结
图优化与融合是 TRT-LLM 性能的根基，把 Python 开销转移到编译期。
