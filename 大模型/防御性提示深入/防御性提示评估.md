# 防御性提示评估

> 对应红队评估与安全基准；模型评测指标深入 衔接。

## 一、背景与挑战

防御效果需量化，否则不知是否真安全。

## 二、核心原理

用注入/越狱基准（如 AdvBench）测攻破率；做红队对抗；跟踪误拦率（可用性）。

## 三、数学形式

攻破率 $ASR=\frac{\#success}{\#attack}$；目标 $ASR\downarrow$ 且误拦率 $\downarrow$。

## 四、代码实现

```python
asr = sum(attack_succeeds(m, p) for p in jailbreaks)/len(jailbreaks)
```

## 五、与其他对比

- 与 安全红队深入（发现漏洞）互补。
- 与 提示版本评估（安全维度）衔接。

## 六、常见误区

- 只看 ASR 忽略误拦伤体验。
- 基准过窄，真实分布未覆盖。
