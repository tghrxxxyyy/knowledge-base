# 越狱与对抗攻击

> 对应 Wei et al., *Jailbreak*, 2023；Zou et al., *GCG 对抗后缀*, 2023。

## 一、背景与挑战

越狱绕过安全策略生成有害内容；对抗后缀自动搜索可迁移。

## 二、核心原理

用角色扮演、虚构场景、编码混淆或梯度优化对抗后缀（GCG）迫使模型越界。

## 三、数学形式

GCG 优化 $\delta^*=\arg\max_\delta \log P_\theta(harmful\mid x\oplus\delta)$；离散 token 梯度近似。

## 五、与其他对比

- 与 提示注入攻击（输入劫持）对照（越狱破策略）。
- 与 模型安全与对齐（加固）互补。

## 六、常见误区

- 认为改系统提示即可挡所有越狱。
- 忽视对抗后缀可跨模型迁移。

## 八、面试题

- GCG 是什么？答：用梯度近似搜索离散对抗后缀，强制模型输出有害内容，可迁移。

## 九、演进

手工越狱 → 模板 → 自动对抗后缀(GCG)。

## 十、小结

越狱含手工与自动对抗，防御需训练与推理双层。
