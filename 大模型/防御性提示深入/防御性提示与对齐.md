# 防御性提示与对齐

> 对应训练对齐+推理防御协同；Ouyang et al., InstructGPT, 2022。

## 一、背景与挑战

单靠推理防御不够，需与训练期对齐协同形成纵深。

## 二、核心原理

训练期 RLHF/DPO 内化安全偏好；推理期防御性提示与过滤兜底，二者互补降低攻破率。

## 三、数学形式

总安全 $S = S_{train} + (1-S_{train})S_{infer}$；任一层挡住即安全。

## 四、代码实现

```python
# 训练已对齐 + 推理加防御性系统提示
resp = guarded_generate(system=DEFENSIVE, user=u)
```

## 五、与其他对比

- 与 直接偏好优化深入（训练侧）衔接。
- 与 模型安全与对齐 共享。

## 六、常见误区

- 用防御性提示替代对齐训练（易被破）。
- 两层目标冲突未协调。

## 九、演进

仅训练 → 仅推理 → 训练+推理协同。

## 十、小结

防御性提示与对齐训练协同，构成应用安全纵深。
