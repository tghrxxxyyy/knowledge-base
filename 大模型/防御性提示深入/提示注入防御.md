# 提示注入防御

> 对应防御手段综述；与 提示注入攻击 衔接。

## 一、背景与挑战

需平衡可用性与安全性，过度防御伤体验。

## 二、核心原理

分层：分隔符/结构化信道隔离指令与数据；输入分类器检注入；输出过滤器检违规；权限最小化（工具调用需确认）。

## 三、数学形式

防御组合 $R_{def}=1-(1-R_{sep})(1-R_{cls})(1-R_{filt})$；多层降残留风险。

## 四、代码实现

```python
if inj_clf(user) > tau: block()
out = model(...)
if leak_clf(out): redact(out)
```

## 五、与其他对比

- 与 系统提示注入防护（实现）互补。
- 与 模型安全与对齐（训练侧）协同。

## 六、常见误区

- 单层防御即满信任（应纵深）。
- 分类器阈值死板，误拦误放。

## 八、面试题

- 为何要纵深防御？答：单层有漏，分层（隔离+检测+过滤）降残留风险。

## 九、演进

声明 → 隔离 → 检测+过滤+权限。

## 十、小结

提示注入防御靠纵深（隔离+检测+过滤+权限），非单点。
