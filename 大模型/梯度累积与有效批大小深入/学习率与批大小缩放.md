# 学习率与批大小缩放

> 对应 Goyal et al., 2017 线性缩放；与 学习率预热与退火深入 衔接。

## 一、背景与挑战

增大有效批通常需同步调学习率，否则收敛变慢或震荡。

## 二、核心原理

线性缩放规则：批扩大 $k$ 倍，学习率也扩大 $k$ 倍（直至临界批）；小批区可用 $\sqrt{k}$ 缩放。

## 三、数学形式

$\eta' = k\eta$（线性）或 $\eta'=\sqrt{k}\eta$（平方根，小批区）；$k=B_{eff}/B_{base}$。

## 四、代码实现

```python
lr = base_lr * (eff_bs / base_bs)
```

## 五、与其他对比

- 与 预热深入 配合：大有效批常配更长 warmup。
- 与 周期性学习率深入 在批缩放下需重设边界。

## 六、常见误区

- 超过临界批仍线性缩放，收益递减甚至退化。
- 仅缩放不预热，初期不稳定。

## 八、面试题

- 为何大批量要加学习率？答：梯度噪声减小，需更大步长补偿，否则有效学习率过低。

## 九、演进

固定 lr → 线性缩放 → 平方根 + warmup 组合。

## 十、小结

批大小缩放须与学习率协同，临界批后收益递减需谨慎。
