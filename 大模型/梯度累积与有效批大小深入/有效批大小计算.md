# 有效批大小计算

> 对应 分布式训练有效批公式；与 优化器状态分片深入 / 数据并行深入 衔接。

## 一、背景与挑战

多卡+累积下，“真实 batch”不再等于单卡 micro-batch，调度易算错。

## 二、核心原理

有效批 = micro-batch × 累积步数 × 数据并行度；是衡量优化动态与学习率缩放的基准。

## 三、数学形式

$B_{eff}=b_{micro}\cdot K_{accum}\cdot D_{dp}$；各维度独立可调。

## 四、代码实现

```python
B_eff = micro_bs * accum_steps * world_size
print("effective batch =", B_eff)
```

## 五、与其他对比

- 与 学习率缩放深入 直接耦合：缩放按 $B_{eff}$ 而非 micro。
- 与 ZeRO深入 在显存预算上相互制约。

## 六、常见误区

- 按 micro-batch 设学习率，导致大有效批下欠拟合。
- 忽略丢弃的尾部不足 batch 影响统计。

## 八、面试题

- 三卡、micro=8、累积4，有效批？答：8×4×3=96。

## 九、演进

单卡 batch → 数据并行 → 累积×并行复合。

## 十、小结

有效批大小是跨卡跨步的统一度量，调度与缩放皆以其为准。
