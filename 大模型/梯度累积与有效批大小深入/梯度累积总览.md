# 梯度累积总览

> 对应 Goyal et al., *Accurate, Large Minibatch SGD*, 2017；与 学习率与批大小缩放深入 衔接。

## 一、背景与挑战

单卡显存有限，无法容纳大 batch；梯度累积以时间换空间，模拟大 batch 训练。

## 二、核心原理

把大 batch 拆成多个 micro-batch，每步只前向/反向一个小批，梯度累加 K 次后再统一更新。

## 三、数学形式

有效批大小 $B_{eff}=B_{micro}\times K\times N_{gpu}$；更新频率降为 $1/K$。

## 四、代码实现

```python
for x in micro_batches:
    loss = model(x) / K
    loss.backward()
optimizer.step(); optimizer.zero_grad()
```

## 五、与其他对比

- 与 数据并行深入 正交，可叠加（累积×并行=更大有效批）。
- 与 混合精度深入 兼容，共同省显存。

## 六、常见误区

- 忘记 loss 除以 K，导致梯度量级翻倍。
- 与 BatchNorm 统计量在小批下失真混淆。

## 八、面试题

- 梯度累积为何等效大 batch？答：梯度是期望估计，多小批平均近似大批量梯度。

## 九、演进

全批 → 小批 SGD → 梯度累积 → 与并行融合。

## 十、小结

梯度累积以多次小反向模拟大批量，是显存受限下的标配技巧。
