# 梯度累积的局限与陷阱

> 对应 实践经验；与 数值稳定性深入 / BatchNorm行为 衔接。

## 一、背景与挑战

累积并非免费，存在 BatchNorm、RNG、评估与数值方面的隐性代价。

## 二、核心原理

BN 在小 micro-batch 下统计量噪声大；dropout/RNG 在不同步间状态不同；长累积增加显存峰值外的风险。

## 三、数学形式

BN 估计 $\hat\mu = \frac1{b}\sum x$，micro 过小使 $\hat\mu,\hat\sigma$ 方差大，影响收敛稳定。

## 四、代码实现

if use_bn:
    assert micro_bs >= 8   # 避免 BN 统计失真

## 五、与其他对比

- 与 学习率预热深入 同属训练稳定性因素。
- 与 混合精度深入 叠加时数值更敏感。

## 六、常见误区

- micro-batch=1 配 BN 直接训崩。
- 累积步数过大拉长反馈、内存虽省但易 OOM 在激活。

## 八、面试题

- 累积对 BatchNorm 有何影响？答：等效批变小，统计量噪声上升，需足够 micro-batch 或换 LN。

## 九、演进

忽视 → 同步 BN → 改用 LN/RMSNorm。

## 十、小结

累积有 BN/RNG/数值代价，需配合归一化选择与步数控制。
