# 梯度累积实现细节

> 对应 训练循环实现；与 混合精度深入 / 数值稳定性深入 衔接。

## 一、背景与挑战

实现细节决定累积是否真等效大批，常见 loss 缩放与梯度清零时机错误。

## 二、核心原理

关键：loss 除以 K 后反向，使梯度天然平均；仅末步 step+zero_grad；中间步只 backward。

## 三、数学形式

$\nabla = \frac1K\sum_{i=1}^K \nabla\mathcal L(x_i)$；等价为 batch $K$ 的平均梯度。

## 四、代码实现

```python
opt.zero_grad()
for i, x in enumerate(micros):
    (model(x)/K).backward()
    if (i+1) % K == 0:
        opt.step(); opt.zero_grad()
```

## 五、与其他对比

- 与 梯度检查点深入（省显存另一手段）可叠加。
- 与 DDP 下需保证各卡同步步数一致。

## 六、常见误区

- 每步都 zero_grad 丢失累积；或不清零致梯度叠加爆炸。
- 在 non-leaf 上除 K 引起图问题。

## 八、面试题

- 累积时 loss 为何除以 K？答：使各 micro 贡献平权，求和得大批量平均梯度。

## 九、演进

手写循环 → Trainer 封装 → 编译优化。

## 十、小结

累积实现核心是平均梯度与清零时机，错一处即不等效大批。
