# 梯度累积与混合并行

> 对应 3D 并行中的累积；与 优化器状态分片深入 / 数据并行深入 衔接。

## 一、背景与挑战

在张量/流水/数据并行组合下，累积需与各类通信语义协调，否则死锁或错配。

## 二、核心原理

累积发生在 micro-batch 维度，与数据并行的 all-reduce 正交；流水并行下常配合 1F1B 调度。

## 三、数学形式

流水：每个 micro-batch 占一个 stage 槽；累积 K 个后再优化器 step。等效微批总数 $M = K \times D_{dp}$。

## 四、代码实现

```python
for mb in microbatches:
    loss = pipeline_step(mb) / K
    loss.backward()
if last: opt.step()
```

## 五、与其他对比

- 与 ZeRO深入 在显存预算上互补（分片省状态、累积省激活）。
- 与 FSDP深入 同属显存优化工具箱。

## 六、常见误区

- 流水与数据并行步数耦合错，导致卡死。
- 跨节点累积未同步梯度，结果不一致。
