# 去污染流水线工程实践

> 对应 Lee et al. 2021 与各大模型数据清洗工程实践。

## 一、背景与挑战

去污染要在 TB 级语料上运行，需兼顾效率、召回与误删控制。单机内存无法容纳全部指纹，需分布式与近似算法。

## 二、核心原理

流水线：(1) 规范化为 canonical 文本；(2) 生成 MinHash/后缀数组指纹；(3) 用 LSH 分桶近似去重；(4) 对基准做 n-gram 重叠扫描并剔除/隔离；(5) 记录审计日志供复现。

## 三、数学形式

MinHash 估计 Jaccard：

$$
\mathbb{E}[\text{MinHash}(A,B)] = J(A,B)
$$

用 $k$ 个哈希函数降低方差。LSH 分桶：

$$
\mathbb{P}(\text{同桶}) = 1-(1-J^b)^r
$$

$b$ 桶数、$r$ 每桶带数控制精度。

## 四、代码实现

```python
import datasketch

def minhash(text, num_perm=128):
    m = datasketch.MinHash(num_perm=num_perm)
    for g in ngrams(text):
        m.update(" ".join(g).encode('utf8'))
    return m
```

## 五、与其他对比

相比朴素两两比对 $O(N^2)$，LSH 近似将复杂度降到近线性，适合工业级语料。

## 六、常见误区

误区：只用精确去重。超大规模下不可行，需近似+LSH。

## 八、面试题

- Q：为何用 LSH？答：把近似去重降到近线性，可扩展。
- Q：误删如何防范？答：阈值保守 + 审计日志 + 抽样人工校验。
