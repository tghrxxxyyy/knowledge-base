# 基准泄漏检测

> 对应 GPT-4 Technical Report (OpenAI 2023) 与 Brown et al. 2020 对污染的讨论。

## 一、背景与挑战

公开基准常被爬入训练语料，导致模型在不知情下“见过答案”。需对常用基准做系统化泄漏扫描并报告。

## 二、核心原理

对每个基准样本，计算其与训练语料的 n-gram 重叠；若超过阈值记为泄漏。按泄漏程度分桶，并报告清洗前后分数差异以估计真实能力。

## 三、数学形式

基准 $B$ 的污染率：

$$
c(B) = \frac{1}{|B|}\sum_{x\in B} \mathbb{1}[\max_{y\in D_{train}} o(x,y) \ge \tau]
$$

泄漏导致的虚高：

$$
\Delta = \mathrm{Acc}_{raw} - \mathrm{Acc}_{clean}
$$

## 四、代码实现

```python
def contamination_rate(test_set, train_ngrams, tau=0.8):
    cnt = 0
    for x in test_set:
        g = ngrams(x)
        if any(len(g & t) / len(g) >= tau for t in train_ngrams):
            cnt += 1
    return cnt / len(test_set)
```

## 五、与其他对比

与通用去重不同，基准泄漏检测聚焦评测公平性，目标是可信评测而非训练清洗。

## 六、常见误区

误区：分数高即能力强。需先排除污染再看分数。

## 八、面试题

- Q：如何证明分数非污染？答：报告清洗前后差异，做消融对比。
- Q：为何用 n-gram 而非整题？答：评测常片段出现在训练文本中。

## 九、演进

从手动扫描到自动化污染报告工具，及封闭基准/held-out 测试集。

## 十、小结

基准泄漏检测是评测可信度的守门员，必须成为发布模型的常规步骤。
