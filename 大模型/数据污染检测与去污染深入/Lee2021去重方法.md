# Lee2021去重方法

> 对应 Lee et al. 2021 "Deduplicating Training Data Makes Language Models Better", NeurIPS 2021。

## 一、背景与挑战

大规模爬取语料含大量近似重复文档，既浪费算力又放大某些内容影响。Lee 等人系统证明去重能提升模型质量与下游表现。

## 二、核心原理

采用后缀数组做精确/近似子串去重，文档按 13-gram 指纹分桶，桶内相似度高的合并或删除。实验显示去重后困惑度更低、罕见 token 更准确。

## 三、数学形式

文档 $x$ 的重复度：

$$
r(x) = \max_{y\neq x} J(H(x), H(y))
$$

若 $r(x)\ge \tau_{dup}$ 则删除或降权。整体语料规模由 $N$ 降到 $N'$。

## 四、代码实现

```python
def deduplicate(docs, min_hash, threshold=0.8):
    keep = []
    for d in docs:
        if all(jaccard(min_hash(d), h) < threshold for h in keep):
            keep.append(min_hash(d))
    return keep
```

## 五、与其他对比

相比仅污染检测(针对评测集)，去重是训练前全局清洗，收益更广泛。

## 六、常见误区

误区：去重越彻底越好。过度去重可能丢失多样性与长尾知识。

## 八、面试题

- Q：去重为何提升质量？答：减少重复学习、降低记忆、提升数据效率。
- Q：代价？答：可能损失多样性，需控制阈值。

## 九、演进

从文档级到片段级去重，及与污染检测统一的清洗流水线。

## 十、小结

去重是预训练数据工程的标准步骤，对质量与效率双收益。
