# 队列监控与容量

> 对应 Prometheus 队列指标；Grafana 看板。Prometheus 提供直方图与计数指标。

## 一、背景与挑战

队列是黑盒，不监控则不知拥堵点与容量瓶颈，难以做容量规划。

## 二、核心原理

暴露队列长度、等待时间、拒绝数、批大小分布；设告警阈值，定位慢环节。

## 三、数学形式

平均等待 $\bar W_q = \frac{1}{N}\sum_i wait_i$；饱和度 $U=\frac{\lambda}{\mu_{max}}$。

## 四、代码实现

```python
prom.gauge("queue_len", q.qsize())
prom.histogram("wait_ms", wait)
```

## 五、与其他对比

- 与 推理可观测与追踪深入（指标）衔接。
- 与 背压机制设计（阈值来源）共享。

## 六、常见误区

- 只看长度忽略等待分布（长尾）。
- 无历史基线难判异常。

## 八、面试题

- 队列监控看什么？答：长度、等待、拒绝数、批分布，重点看长尾与饱和度。

## 九、演进

无 → 基础计数 → 直方图与 SLO 告警。

## 十、小结

队列监控把隐形拥塞显性化，是容量规划依据。
