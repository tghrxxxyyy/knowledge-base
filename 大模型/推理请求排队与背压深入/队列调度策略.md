# 队列调度策略

> 对应 FIFO / 优先级队列 / 公平调度；Triton dynamic batcher。Triton 支持动态批处理。

## 一、背景与挑战

单纯 FIFO 在混合负载下小请求被大请求拖垮，需调度策略兼顾公平与吞吐。

## 二、核心原理

常用 FIFO、优先级（按 SLA、付费）、公平队列（每租户轮转）；调度决定取哪些请求成批。

## 三、数学形式

公平队列加权轮转：$P_i \propto w_i$，保证 $\sum_i \frac{served_i}{w_i}$ 近似相等。

## 六、常见误区

- 优先级反转致低优请求饿死。
- 批内请求长度差异大降 GPU 利用率。
