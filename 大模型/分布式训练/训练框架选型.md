# 训练框架选型

> 主流工具对比。

## 一、核心概念

| 框架 | 定位 |
|------|------|
| Megatron-LM | TP/PP 极致优化，超大规模 |
| DeepSpeed | ZeRO，易用 |
| FSDP | PyTorch 原生，灵活 |
| Accelerate | 上层封装，快速 |
| Colossal-AI | 多种并行 |

选型看规模、硬件、团队熟悉度。

## 二、关键要点

- 中小规模 FSDP/DeepSpeed 足够。
- 超大规模常 Megatron + DeepSpeed 结合。
