# 梯度累积与激活重计算

> 小显存下模拟大 batch 与省激活。

## 一、核心概念

- **梯度累积**：多个 micro-batch 的梯度累加后再更新，等效大 batch 但显存只够小 batch。
- **激活重计算(Checkpointing)**：前向不存全部激活，反向时重算，用算力换显存(典型省 30-50% 激活显存)。

```python
acc = 0
for i, (x,y) in enumerate(loader):
    loss = model(x); (loss/accum_steps).backward()
    if (i+1) % accum_steps == 0:
        opt.step(); opt.zero_grad()
```

## 二、关键要点

- 累积步数与 batch 乘积=等效 batch。
- 重计算增算力约 30%。
