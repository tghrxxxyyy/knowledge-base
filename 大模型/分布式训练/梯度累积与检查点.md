# 梯度累积与激活重计算

> 对应 Chen et al. 2016（Training Deep Nets with Sublinear Memory Cost，激活重计算）、混合精度与分布式训练实践。

## 一、背景与挑战

大模型训练受两大约束：① **显存**——不仅存参数/优化器，还要存前向激活供反向用，激活随 batch 与序列长度线性增长；② **有效 batch**——大 batch 利于稳定与吞吐，但单卡显存只够小 batch。两项技术应运而生：**梯度累积（Gradient Accumulation）**用小 batch 多次前向/反向、累加梯度后统一更新，等效大 batch 而显存不增；**激活重计算（Activation Checkpointing / Gradient Checkpointing）**前向不存全部激活、反向时重算，用约 30% 额外算力换显著显存节省。二者常组合使用。

## 二、核心原理

- **梯度累积**：把大 batch 切成 `accum_steps` 个 micro-batch，每个 micro-batch 前向+反向得梯度，**不更新**，累加进主梯度；每 `accum_steps` 次做一次 `optimizer.step()` 并清零。等效 batch = `micro_batch × accum_steps × DP 度`。代价：每步多算几次前向（但显存只够一个 micro-batch 的激活）。
- **激活重计算**：前向只保存「检查点层」的输出，丢弃中间激活；反向时从最近检查点重新跑前向得到激活再算梯度。典型省 30–50% 激活显存，代价是约多 33% 前向算力（反向里重算）。

二者互补：累积解决「等效大 batch」，重计算解决「激活显存」，组合后可在极小显存下训大模型。

## 三、形式化与数学基础

设 micro-batch 梯度为 $g^{(i)} = \nabla \mathcal{L}(x^{(i)}; W)$。累积 $K$ 步后更新：

$$g = \frac{1}{K}\sum_{i=1}^{K} g^{(i)},\quad W \leftarrow \text{optimizer}(W, g)$$

等效 batch 大小 $B_{\text{eff}} = K \cdot b_{\text{micro}} \cdot N_{\text{DP}}$。激活显存：

$$\text{标准}: M_{\text{act}},\qquad \text{重计算}: M_{\text{act}}^{\text{(ckpt)}} \approx \frac{M_{\text{act}}}{2} \sim \frac{M_{\text{act}}}{3}$$

因只存检查点层输出。重计算引入前向重算成本约 $+1\times$ 前向（实际因仅部分层故约 +30%）。

## 四、代码实现

梯度累积 + 激活重计算（PyTorch）：

```python
accum_steps = 4
optimizer.zero_grad()
for i, (x, y) in enumerate(loader):
    loss = model(x, y)                 # 前向
    (loss / accum_steps).backward()    # 梯度累加（归一化）
    if (i + 1) % accum_steps == 0:
        optimizer.step()
        optimizer.zero_grad()

# 激活重计算：用 checkpoint 包裹子模块
from torch.utils.checkpoint import checkpoint
out = checkpoint(layer_block, x)       # 反向时重算该块前向
```

## 五、与其他技术对比

| 技术 | 解决 | 代价 | 省什么 |
|------|------|------|--------|
| 梯度累积 | 等效大 batch | 多前向（同算力） | 显存（batch） |
| 激活重计算 | 激活显存 | +约30%算力 | 激活显存 |
| ZeRO | 优化器/参数 | 通信 | 冗余显存 |

## 六、常见误区

- 累积时忘了把 loss 除以 `accum_steps`，等效 LR 被放大 $K$ 倍。
- 累积步数与 micro-batch 乘积算错，等效 batch 偏离预期。
- 重计算包裹过细，重算开销抵消收益；过粗则省显存不够。
- 以为累积能省激活显存（其实只省 batch 维度，激活仍需重计算配合）。

## 九、演进与趋势

重计算与序列并行、选择性重计算（只重算显存大/算力小的层）结合，进一步精细化显存-算力权衡；并与 ZeRO、TP/PP 组成完整显存优化栈，是训超大模型的标配组合。

## 十、小结

梯度累积用「多次小步累加」模拟大 batch 而不增显存；激活重计算用「反向重算前向」以约 30% 算力换 30–50% 激活显存。二者是显存受限下训大模型的左膀右臂，常与 ZeRO 并用。
