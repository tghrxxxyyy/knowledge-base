# 自回归语言建模

> 见「自监督学习深入/自监督学习总览」与「预训练/语言建模目标」。

## 一、背景与挑战

GPT 系列用左到右预测下一个 token 统一预训练与生成。

## 二、核心原理

最大化似然：

```
L = Σ_t log P(x_t | x_{<t})
```

因果掩码保证第 t 步只见前文。

## 三、数学形式

见上，链式法则分解。

## 四、代码实现

```python
logits = model(input_ids).logits
loss = F.cross_entropy(logits[:,:-1], input_ids[:,1:])
```

## 五、关键要点

- 天然适合生成。
- 需大量数据学分布。

## 六、与其他对比

- MLM 强表征；AR 强生成。

## 七、常见误区

- 自回归只能文本——也可用于像素/音频(如 PixelCNN)。
