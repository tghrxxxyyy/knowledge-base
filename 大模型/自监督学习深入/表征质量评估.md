# 表征质量评估

> 见「自监督学习深入/自监督学习总览」与「词嵌入与表示学习」。

## 一、背景与挑战

无标签下如何知表征好坏？

## 二、核心原理

线性探针（冻结表征训线性分类器）、kNN 分类、下游微调对比、对齐-均匀性(Alignment-Uniformity)指标。

## 三、数学形式

均匀性：

```
U = log E_{x,y}[e^{-2||f(x)-f(y)||}]
```

## 四、代码实现

```python
acc = logistic_probe(embeddings, labels)  # 冻结编码
```

## 五、关键要点

- 线性探针最常用。
- 下游任务才最终说明。

## 六、与其他对比

- 生成质量看重建；表征质量看迁移。

## 七、常见误区

- 重建好=表征好——未必。
