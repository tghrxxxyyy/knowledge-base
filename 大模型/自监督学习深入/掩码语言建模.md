# 掩码语言建模

> 见「自监督学习深入/自监督学习总览」与「编码器与BERT」。

## 一、背景与挑战

如何用无标注文本训练双向表征？BERT 用掩码预测。

## 二、核心原理

随机遮盖 15% token，模型预测被盖 token；下游接分类/抽取任务。MLM 迫使模型利用上下文双向信息。

## 三、数学形式

```
L = - Σ_{i∈masked} log P(x_i | x_{\i})
```

## 四、代码实现

```python
from transformers import BertForMaskedLM
out = BertForMaskedLM.from_pretrained("bert-base-chinese")(**inputs).logits
```

## 五、关键要点

- 80% 盖 [MASK]、10% 随机、10% 原词，缓解预训练-微调差异。
- 仅盖少量避免长程依赖难学。

## 六、与其他对比

- AR（GPT）单向；MLM 双向但生成弱。

## 七、常见误区

- 推断时也用 [MASK]——MLM 仅训练用。
