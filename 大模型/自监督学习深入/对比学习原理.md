# 对比学习原理

> 见「自监督学习深入/自监督学习总览」与「多模态对齐深入/CLIP对比对齐」。

## 一、背景与挑战

同类样本应靠近、异类远离，无需标注。

## 二、核心原理

构造正例对（同图增强/同句不同视图），经编码器得表征，用 InfoNCE 拉近正例、推远负例。

## 三、数学形式

```
L = -log exp(s(z_i,z_j)/τ) / Σ_k exp(s(z_i,z_k)/τ)
```

## 四、代码实现

```python
z1, z2 = enc(aug(x)), enc(aug(x))
loss = nt_xent(z1, z2, tau=0.1)
```

## 五、关键要点

- 负例数越多越好（大 batch / 字典）。
- 温度 τ 调分布锐度。

## 六、与其他对比

- 生成式重建像素；对比式学不变性。

## 七、常见误区

- 随便增强都行——增强需保语义。
