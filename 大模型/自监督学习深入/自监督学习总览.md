# 自监督学习总览

> 对应 d2l-zh 与 llm-course；综述见 Liu et al., *Self-Supervised Learning*, 2021。

## 一、背景与挑战

标注昂贵，自监督用数据自身构造监督信号，是大模型预训练主流范式。

## 二、核心原理

两类：**生成式**（重构/掩码预测，如 MLM/AR）与**对比式**（拉近正例、推远负例，如 SimCLR）。LLM 主要靠生成式语言建模。

## 三、数学形式

对比损失 InfoNCE：

```
L = -log exp(s(z_i,z_j)/τ) / Σ_k exp(s(z_i,z_k)/τ)
```

## 五、关键要点

- 数据量大时自监督逼近监督。
- 表征质量决定下游上限。

## 六、与其他对比

| 范式 | 信号 | 代表 |
|------|------|------|
| 生成式 | 重构 | BERT/GPT |
| 对比式 | 相似度 | SimCLR |

## 七、常见误区

- 自监督=无监督——仍有人工设计 pretext task。
