# 隐式与显式推理对比

> 对应 Wei 2022 chain-of-thought prompting 与 Devlin 2018 BERT。

## 一、背景与挑战
模型是否必须显式输出链才能推理？隐式推理在_latent_空间完成，难以观测。

## 二、核心原理
显式 CoT 把推理外化便于校验；隐式推理直接给答案，速度快但不可解释。

## 三、形式化与数学基础
信息量差异：
$ I(y; z|x) \ge 0 $
显式链 z 提供额外监督信号。

## 四、代码实现
```python
def implicit_vs_explicit(model, q):
    a1 = model.generate(q, max_new_tokens=16)
    a2 = model.generate(q + '\nThink step by step.', 512)
    return a1, a2
```

## 五、与其他技术对比
显式更安全可调试，隐式更省 token，二者在强模型上差距收窄。

## 六、常见误区
假设无 CoT 即无推理；忽视解码温度对隐式推理的影响。

## 七、与开源书/权威来源对应
Wei 2022 讨论显式链的作用；Devlin 2018 展示表征隐式编码。

## 八、面试题
何时选用隐式推理？

## 九、演进与趋势
潜变量推理与可微分验证器结合。

## 十、小结
显隐权衡在于可解释性与成本的平衡。
