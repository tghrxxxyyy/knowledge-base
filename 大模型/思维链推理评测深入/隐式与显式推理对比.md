# 隐式与显式推理对比

> 对应 Wei 2022 chain-of-thought prompting 与 Devlin 2018 BERT。

## 一、背景与挑战

一个自然问题：模型是否必须显式输出文字推理链才能「推理」？实证显示，大模型在隐空间（latent space）也能完成推理并直接给答案，但过程不可观测、不可校验。显式 CoT 把推理外化为文字，便于调试与问责，却消耗更多 token。二者权衡关乎可解释性、成本与在强模型上的必要性。近年还出现「隐式 CoT」「latent CoT」等变体，让模型在 embedding 空间完成多步思考再输出，模糊了显隐边界，也带来新的评测难题——我们更难判断模型是否真的「想清楚了」。

## 二、核心原理

- 显式推理（CoT）：模型生成中间步骤 $z$ 再给答案 $y$，链 $z$ 提供可验证监督与可解释性。
- 隐式推理：模型不经文字链，直接由 $P(y\mid x)$ 输出，推理在激活/表征中完成（Devlin 2018 等展示表征隐式编码语义关系）。
- 在强模型上，二者差距收窄：大模型常在无 CoT 时也答对，但显式链仍对困难题与可调试性有价值。隐式推理相当于一次前向完成「压缩后的多步」，但缺乏中间监督，错误难以定位，且无法被过程评测（见「思维链推理评测深入/CoT 推理正确性评测」）校验。

## 三、形式化与数学基础

显式链引入额外随机变量 $z$，答案与链的条件互信息非负：

$$
I(y;z\mid x)\ge 0
$$

显式链提供额外监督信号，使训练目标含 $\log P(z,y\mid x)$；隐式仅优化 $\log P(y\mid x)$。对困难题，链降低搜索难度：

$$
P(y\mid x)\approx\sum_z P(z\mid x)P(y\mid x,z)
$$

显式地构造 $z$ 相当于用先验引导解码。隐式则近似为在 $z$ 上做 argmax 的内部搜索：

$$
\hat y_{\text{implicit}}\approx f_\theta(x)
$$

## 四、代码实现

```python
def implicit_vs_explicit(model, q, max_implicit=16, max_explicit=512):
    # 同一问题分别走隐式(短)与显式(长链)路径
    a1 = model.generate(q, max_new_tokens=max_implicit)
    a2 = model.generate(q + "\nThink step by step.", max_new_tokens=max_explicit)
    return {"implicit": a1, "explicit": a2}

def need_explicit(q, difficulty, thr=0.6):
    # 困难题才用显式链, 简单题走隐式省成本
    return difficulty(q) > thr

def latent_cot(model, q, think_tokens=8):
    # 隐式/latent CoT 示意: 在 embedding 空间多步思考
    return model.generate_with_latent_steps(q, steps=think_tokens)
```

## 五、与其他技术对比

| 方式 | 显式 CoT | 隐式 |
| --- | --- | --- |
| 可解释 | 强 | 弱 |
| token 成本 | 高 | 低 |
| 困难题 | 更稳 | 易错 |
| 强模型差距 | 收窄 | 收窄 |
| 错误定位 | 易 | 难 |

## 六、常见误区

- 假设无 CoT 即无推理：强模型隐空间仍可推理。
- 忽视解码温度对隐式推理影响：低温更利隐式稳定。
- 认为显式总优于隐式：简单题上额外链可能引入噪声。
- 把隐式当黑盒放弃评测：仍可用探针评估其内部表征。
- 以为 latent CoT 可完全替代显式：审计场景仍需外化链。

## 九、演进与趋势

从「必显式」到「潜变量推理 + 可微分验证器」，用 latent CoT 兼顾效率与可控，仅在需要时外化链。训练时可用显式链作监督蒸馏出隐式能力，实现「训练显式、推理隐式」，并在评测时按需外化以做过程校验。

（补充续）评测隐式推理时，可借助「探针分类器」在隐藏状态上预测中间结论，间接检验其是否真的完成了逐步推导，而非仅靠终态拟合。若探针能还原推理步骤，说明隐式链具备可解释性残留，可用于高风险场景的部分审计。

工程权衡上还有两点常被忽略：一是显式链会暴露模型「思维」，在对抗场景下可能泄露提示或系统设定，此时隐式反而更安全；二是显式链占用输出位置，限制了自回归的上下文预算，长链会压缩最终答案空间。

- 隐私敏感场景：优先隐式，避免思维外泄。
- 强监管场景：优先显式，保留可审计证据。
- 成本敏感场景：用小模型显式蒸馏、大模型隐式推理。

## 十、小结

显隐权衡在于可解释性与成本的平衡：显式链可调试可验证但费 token，隐式快但不可观测；按任务难度与审计需求选择，并可在训练中把显式能力蒸馏进隐式。latent CoT 正试图兼得二者之长。
