# 复杂推理基准与评测设计

> 对应 Wei 2022 chain-of-thought prompting 与 Brown 2020 in-context learning。

## 一、背景与挑战

评估大模型推理能力的关键，是构建能区分「真实推理」与「记忆答案」的题集。若题目答案已被模型在预训练中记忆（contamination），则高分来自记忆而非推理，会夸大模型能力。因此基准设计要兼顾难度（需多步推理）、可验证（中间步骤可判定）与防污染（未泄漏到训练集）。实践中还有两类陷阱：一是「题面污染」——题干出现过的模式被记住；二是「答案泄漏」——选项或格式泄露了正确解，使模型无需推理即可命中。此外，基准若只覆盖单一领域（如算术），会掩盖模型在符号、空间、常识推理上的短板，导致评测结论片面。

## 二、核心原理

复杂推理基准采用需要多步算术、符号操作或逻辑演绎的题目，并要求模型给出可验证的中间步骤。设计原则：（1）难度随推理步数增长，使能力差异在困难题上放大；（2）答案可程序化校验（如数学题有确定解）；（3）动态生成或对抗过滤以防训练集泄漏；（4）覆盖多种推理类型（数学、常识、符号、空间）。Wei 2022 用多步题展示 CoT 收益随难度上升，正是依赖这类可验证基准。设计上应记录每题的「最小推理步数」与「标准解法」，便于过程评测（见「思维链推理评测深入/CoT 推理正确性评测」），并建议建立题面哈希库以快速做污染自查。

## 三、形式化与数学基础

题 $q$ 的推理深度定义为所需推理步数：

$$
\mathrm{depth}(q)=\big|\{ \text{required reasoning steps} \}\big|
$$

CoT 相对直接回答的增益随深度上升，可建模为：

$$
\Delta\mathrm{Acc}(q)=\mathrm{Acc}_{\mathrm{CoT}}(q)-\mathrm{Acc}_{\mathrm{direct}}(q)\propto \mathrm{depth}(q)
$$

污染度衡量题 $q$ 在训练语料中的出现概率 $\rho(q)$，应选基准使 $\rho(q)\approx 0$。对污染可用 n-gram 重叠或检索召回近似估计：

$$
\widehat{\rho}(q)=|\{c\in\mathcal{C}: \text{ngram}(q)\cap\text{ngram}(c)\neq\varnothing\}|/|\mathcal{C}|
$$

## 四、代码实现

```python
def grade_with_trace(pred, gold_steps, gold_ans):
    # 同时比对最终答案与关键中间步
    ans_ok = pred["ans"] == gold_ans
    steps_ok = set(pred["steps"]) >= set(gold_steps)
    return ans_ok and steps_ok

def contamination_check(q, known_train_hashes):
    # 用题面哈希判断是否在已知训练集中
    return hash(q) in known_train_hashes

def gen_problem(depth, rng):
    # 按深度动态生成多步算术题(示意), 天然防泄漏
    x = rng.randint(2, 9)
    for _ in range(depth):
        x = x * rng.randint(2, 9) + rng.randint(1, 9)
    return x

def difficulty_report(dataset):
    # 统计各深度题量, 验证难度覆盖
    return {d: sum(1 for q in dataset if q.depth == d) for d in range(1, 6)}
```

| 覆盖题型 | 窄 | 广 |

## 六、常见误区

- 用训练集已污染的题夸大 CoT 提升：应做 contamination 检测。
- 忽略题目表述敏感性：同义改写可能大幅改变难度。
- 只看最终答案：忽略中间步可验证性，易被格式正确蒙混。
- 难度单一：全简单或全部超难都拉不开模型差距。
- 只测算术：掩盖符号/空间/常识推理的真实短板。

## 九、演进与趋势

从静态公开基准到动态生成题、对抗过滤与去重；方向是用合成数据构造无限难度可调的题集，并把过程校验（见「思维链推理评测深入/CoT 推理正确性评测」）纳入评分。基准正从「固定题库」走向「可证明未污染」的构造范式，并引入对抗样本过滤训练集重叠。

## 十、小结

推理基准设计要兼顾难度、可验证与防污染：只有未被记忆、需多步且可校验的题，才能真实区分模型推理能力。记录最小推理步与标准解法，并把污染自查纳入流程，是把基准用好的前提。
