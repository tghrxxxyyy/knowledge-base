# 复杂推理基准与评测设计

> 对应 Wei 2022 chain-of-thought prompting 与 Brown 2020 in-context learning。

## 一、背景与挑战
需要能区分模型真实推理能力的题集，而非靠记忆答案。

## 二、核心原理
采用需多步算术或符号操作的题目，并要求给出可验证的中间步骤。

## 三、形式化与数学基础
难度随步数增长：
$ \text{depth}(q) = |\{ \text{required reasoning steps} \}| $

## 四、代码实现
```python
def grade_with_trace(pred, gold_steps, gold_ans):
    # 比对答案同时检查关键步
    return pred['ans'] == gold_ans and set(pred['steps']) >= gold_steps
```

## 五、与其他技术对比
可验证题优于开放题，但构造成本高、易泄漏到训练集。

## 六、常见误区
用训练集 contamination 题目夸大提升；忽略题目表述敏感性。

## 七、与开源书/权威来源对应
Wei 2022 用多步题展示 CoT 收益随难度上升。

## 八、面试题
如何检测评测集已被模型记忆？

## 九、演进与趋势
动态生成题与对抗过滤成为防泄漏手段。

## 十、小结
推理基准设计要兼顾难度、可验证与防污染。
