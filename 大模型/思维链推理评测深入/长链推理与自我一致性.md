# 长链推理与自我一致性

> 对应 Wei 2022 chain-of-thought prompting 与 Brown 2020 in-context learning。

## 一、背景与挑战

单条推理链易在某一分支走错（一步错全错），且不同采样路径质量参差。自我一致性（self-consistency）通过对同题采样多条推理链、以答案多数决聚合，提升鲁棒性，但代价是 M 倍推理成本。如何在增益与成本间权衡，并正确合并语义等价答案是关键。此外，长链本身增加了每条采样的时延与出错概率，M 越大越需配合早停与验证器，否则纯多数决的边际收益会随 M 递减，且对「答案稀疏正确」的难题，平等投票可能反被多数错误路径带偏。

## 二、核心原理

核心思想：对问题 $x$ 用较高温度采样 M 条不同推理链，各自得到答案 $\{y_j\}$，再以答案的多数投票作为最终输出。直觉上，正确推理路径往往收敛到同一答案，而错误路径分散，故多数决可抑制偶发错误。该方式等价于对推理路径做边际化（marginalization）。实践中常先采 M 条，再用验证器/过程奖励对每条打分，做加权投票以减少需采样的 M，并对语义等价答案（如「3」与「three」）先归一化再计票。

## 三、形式化与数学基础

自我一致性输出为答案众数：

$$
\hat y=\arg\max_y\sum_{j=1}^{M}\mathbb{1}[y_j=y]
$$

其期望误差随 M 增大而下降（在单链准确率 $p>0.5$ 时）：

$$
P(\text{majority wrong})\le \binom{M}{\lfloor M/2\rfloor}(1-p)^{\lceil M/2\rceil}p^{\lfloor M/2\rfloor}
$$

与验证器结合可改为加权投票：$\hat y=\arg\max_y\sum_j w_j\mathbb{1}[y_j=y]$，权重 $w_j$ 为路径质量分。该式在 $p>0.5$ 时随 M 指数级压低错误率。

## 四、代码实现

```python
from collections import Counter

def self_consistency(answers, weights=None):
    # answers: M 条链的答案; weights 可选验证器分数
    if weights is None:
        return Counter(answers).most_common(1)[0][0]
    score = {}
    for a, w in zip(answers, weights):
        score[a] = score.get(a, 0.0) + w
    return max(score, key=score.get)

def dedupe_semantic(answers, eq_fn):
    # 合并语义等价答案后再投票, 避免同义分裂票
    groups = []
    for a in answers:
        hit = next((g for g in groups if eq_fn(g[0], a)), None)
        if hit:
            hit.append(a)
        else:
            groups.append([a])
    return [g[0] for g in groups]

def early_stop(answers, k=5, thr=0.8):
    # 某答案占比超阈值即早停(示意), 省算力
    c = Counter(answers)
    top, n = c.most_common(1)[0]
    return top if n / len(answers) >= thr and len(answers) >= k else None
```

## 六、常见误区

- 简单题用大 M：浪费算力，答案已稳定无需多采样。
- 未去重语义等价答案：把「3」和「three」当不同票，破坏投票。
- 忽略采样温度：温度过低路径趋同，丧失一致性收益。
- 不设早停：M 固定导致长尾高成本。
- 假设 M 越大越好：边际收益递减，需配合验证器。

## 九、演进与趋势

用验证器/过程奖励加权投票替代平等多数；与束搜索、best-of-N 选择结合，在更低 M 下达到同等鲁棒。早停与预算感知采样进一步压低成本，使自我一致性在预算约束下仍有效。

## 十、小结

多链聚合是提升推理可靠性的实用手段：以多数决抑制偶发错误，配合语义去重、验证器加权与早停，在成本与鲁棒间取优。一致性收益以单链准确率 >0.5 为前提，否则多数决会放大错误。
