# 长链推理与自我一致性

> 对应 Wei 2022 chain-of-thought prompting 与 Brown 2020 in-context learning。

## 一、背景与挑战
单条链易走错分支，多条链投票可提升鲁棒性但放大成本。

## 二、核心原理
采样多条推理链，以答案多数决作为最终输出，等价于边际化推理路径。

## 三、形式化与数学基础
自我一致性：
$ \hat{y} = \arg\max_y \sum_{j=1}^{M} \mathbb{1}[y_j = y] $

## 四、代码实现
```python
from collections import Counter
def self_consistency(answers):
    return Counter(answers).most_common(1)[0][0]
```

## 五、与其他技术对比
比单链稳，但需 M 倍推理；与验证器结合可降采样数。

## 六、常见误区
在简单题上用大 M 浪费算力；未去重语义等价答案。

## 七、与开源书/权威来源对应
Wei 2022 展示链式生成；Brown 2020 提供采样基础。

## 八、面试题
M 取多少合适？如何合并语义相同答案？

## 九、演进与趋势
用验证器加权投票替代平等多数。

## 十、小结
多链聚合是提升推理可靠性的实用手段。
