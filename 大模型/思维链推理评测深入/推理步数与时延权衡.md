# 推理步数与时延权衡

> 对应 Wei 2022 chain-of-thought prompting 与 Kwon 2023 vLLM。

## 一、背景与挑战

CoT 通过生成更长的中间步骤提升准确率，但长链显著拉长生成长度，直接转化为更高的时延与推理成本（按 token 计费）。在生产中必须量化「每多一步推理带来的准确率收益」与「对应的时延/成本开销」，并按任务难度与 SLA 设定链长度预算，否则要么过度推理浪费资源，要么推理不足导致错误。大模型服务里，时延不仅影响体验，还触发超时与重试；成本则直接决定单位经济（unit economics），二者共同约束 CoT 的可用性。尤其对长尾困难题，盲目拉满长度会让 p99 时延失控。

## 二、核心原理

核心是把推理长度当作可调超参：对每个请求度量步数 $L$ 与耗时/成本，计算单位收益成本比 $\eta$。简单题用短链即可，困难题值得长链。服务层（如 Kwon 2023 vLLM 的 PagedAttention）通过高效 KV-cache 管理摊薄长序列的显存与时延，使长链更可行。治理上应把链长度上限写入成本预算，并结合批处理（batching）进一步摊薄单位请求开销。实践中可先离线测出「准确率—长度」曲线，再按预算选最优 $L^*$，并区分训练/推理两阶段分别定预算。

## 三、形式化与数学基础

设引入 CoT 带来的准确率增益为 $\Delta\mathrm{Acc}$，生成长度为 $L$，单位 token 价为 $c$，则单位收益成本：

$$
\eta=\frac{\Delta\mathrm{Acc}}{c\cdot L}
$$

当边际增益递减时存在最优长度 $L^*$：

$$
L^*=\arg\max_L \big(\mathrm{Acc}(L)-\lambda\, c\, L\big)
$$

其中 $\lambda$ 为成本权重。引入批处理规模 $B$ 后，单位请求时延近似：

$$
t(L)\approx \frac{L}{B}\cdot t_{\text{step}}
$$

即大批次显著摊薄长链时延。

## 四、代码实现

```python
def efficiency(acc_gain, tokens, cost_per_k=0.01):
    # 返回单位成本收益; tokens 为生成总 token 数
    if tokens == 0:
        return 0.0
    return acc_gain / (tokens / 1000.0 * cost_per_k)

def choose_budget(acc_curve, cost_per_k, lam=1.0):
    # acc_curve: 长度->准确率; 选净收益最大长度
    best, best_l = -1e9, 1
    for L, acc in acc_curve.items():
        net = acc - lam * cost_per_k * L / 1000.0
        if net > best:
            best, best_l = net, L
    return best_l

def latency_per_req(L, batch, t_step=5e-3):
    # 批处理摊薄后的单位时延(秒, 示意)
    return L * t_step / batch
```

## 五、与其他技术对比

| 链长 | 短链 | 长链 |
| --- | --- | --- |
| 速度 | 快 | 慢 |
| 准确率 | 低 | 高 |
| 成本 | 低 | 高 |
| 批处理收益 | 小 | 大 |

## 六、常见误区

- 对所有请求用相同长链：简单题浪费算力。
- 忽略批处理对时延的摊薄：批量下长链边际成本更低。
- 只算钱不算 SLA：时延超限同样不可接受。
- 用平均长度估算成本：长尾分布下应看分位数。
- 认为更长的链一定更准：超过某点后边际收益趋零甚至下降。

## 九、演进与趋势

从固定长链到自适应步数控制与早停（confidence 触发）、以及用验证器决定何时停止展开，实现「按需推理」。推理引擎在 KV-cache 复用、continuous batching 上持续优化，进一步压低长链的边际成本，使长链在成本上更可承受。

（补充续）在线上推理系统里，长度预算还应与 SLO 绑定：把 p99 时延换算为最大可接受 token 数，再反推允许的推理步数。当模型升级导致单步变慢时，预算需同步收紧。

工程上可把「长链熔断」做成服务侧策略：超过阈值即回退到短链或附加答案校验，避免个别难题拖垮整批吞吐。同时按业务 ROI 分层——高价值请求允许更长链，低价值批量任务强制短链，把有限算力投向边际收益最高的地方。

## 十、小结

推理长度应作为可调超参纳入成本治理：以单位收益成本比驱动长度预算，配合高效推理服务与批处理，在准确率与开销间取平衡。最优长度随成本权重与批处理规模动态变化，且应以分位数而非均值评估时延风险。
