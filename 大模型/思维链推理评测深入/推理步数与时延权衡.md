# 推理步数与时延权衡

> 对应 Wei 2022 chain-of-thought prompting 与 Kwon 2023 vLLM。

## 一、背景与挑战
CoT 显著提升时延与成本，需量化收益与开销的关系。

## 二、核心原理
对每个请求度量步数与耗时，按任务难度决定链长度预算。

## 三、形式化与数学基础
单位收益成本：
$ \eta = \frac{\Delta \text{Acc}}{c \cdot L} $
L 为生成长度，c 为单位价。

## 四、代码实现
```python
def efficiency(acc_gain, tokens, cost_per_k):
    return acc_gain / (tokens / 1000 * cost_per_k)
```

## 五、与其他技术对比
短链快但不准，长链准但贵，需按 SLA 设定上限。

## 六、常见误区
对所有请求用相同长链；忽略批处理对时延的摊薄。

## 七、与开源书/权威来源对应
Wei 2022 强调链长度；Kwon 2023 提供高效服务降低时延。

## 八、面试题
如何为生产设定 CoT 长度预算？

## 九、演进与趋势
自适应步数控制与早停机制。

## 十、小结
推理长度应作为可调超参纳入成本治理。
