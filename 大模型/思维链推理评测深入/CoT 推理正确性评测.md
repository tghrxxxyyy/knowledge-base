# CoT 推理正确性评测

> 对应 Wei 2022 chain-of-thought prompting。

## 一、背景与挑战

CoT 生成的推理链常「格式正确但结论错误」——即幻觉式推理：步骤看起来合理、语言流畅，却在某一步偷换概念或算错，最终答案错误。仅比对最终答案会高估模型，因为碰巧答对的链过程可能全错；仅看过程又可能放过正确直觉。因此需要同时评测「结果正确性」与「过程正确性」。此外，链中还可能「正确步骤 + 错误跳步但蒙对答案」，这种错位同样难以用单一指标捕捉，且在高风险场景危害更大——用户看到完整链会误以为可信。

## 二、核心原理

评测分两类：（1）结果评测——最终答案匹配标准答案，可用精确匹配或数值近似；（2）过程评测——逐步逻辑校验，由人工或强模型（verifier）判断每步是否有效。二者结合得到「过程准确率」PAcc。过程校验更严格但成本高；实践中常用答案匹配做初筛，对边界样本做过程评测，或用训练好的验证器对推理路径打分。关键边界情形包括：过程对答案错、过程错答案对、过程与答案皆对/皆错，四态需分别计数才能定位失败模式，指导后续对齐或提示优化。

## 三、形式化与数学基础

过程准确率定义为所有步骤均有效的样本比例：

$$
\mathrm{PAcc}=\frac{1}{N}\sum_{i=1}^{N}\mathbb{1}\big[\text{all steps valid in }z_i\big]
$$

其中 $z_i$ 为样本 $i$ 的推理链。综合质量可结合答案正确率 $\mathrm{AAcc}$：

$$
Q=\alpha\,\mathrm{AAcc}+(1-\alpha)\,\mathrm{PAcc}
$$

当验证器给出逐步分数 $v_s\in[0,1]$ 时，链得分 $V(z)=\frac{1}{|z|}\sum_s v_s$。四态分解：

$$
N=N_{++}+N_{+-}+N_{-+}+N_{--}
$$

## 四、代码实现

```python
def step_check(chain, verifier):
    # 逐步验证推理链, 返回每步是否有效及过程准确率
    steps = [s for s in chain.split("\n") if s.strip()]
    flags = [bool(verifier(s)) for s in steps]
    pacc = sum(flags) / len(flags) if steps else 0.0
    return flags, pacc

def answer_ok(pred, gold):
    try:
        return float(pred) == float(gold)
    except ValueError:
        return pred.strip() == gold.strip()

def quad_state(ans_ok, proc_ok):
    # 四态计数辅助: 区分「蒙对答案」等危险模式
    if ans_ok and proc_ok:
        return "++"
    if ans_ok:
        return "+-"   # 过程错但答案对
    if proc_ok:
        return "-+"   # 过程对但答案错
    return "--"
```

## 六、常见误区

- 把格式正确的链当作逻辑正确：流畅≠有效。
- 忽略数值计算错误：一步算错即整链无效。
- 验证器过拟合：用同分布弱模型判过程会漏检。
- 只看平均准确率：不区分四态会掩盖「蒙对答案」的隐患。
- 用单一 verifier 当真理：验证器本身也有错误，需人工抽检校准。

## 九、演进与趋势

从人工过程校验到训练过程奖励模型（process reward model）对路径打分，并用于搜索/投票（见「思维链推理评测深入/长链推理与自我一致性」），把正确性评测自动化。评测正从「看答案」升级为「看路径质量」，并发展出对验证器自身的可信度估计。

## 十、小结

正确性评测应同时覆盖结果与过程：仅靠最终答案会高估能力，逐步逻辑校验才能识别幻觉式推理。四态分解能进一步定位「蒙对答案」等危险模式，为对齐与提示优化提供方向。
