# CoT 推理正确性评测

> 对应 Wei 2022 chain-of-thought prompting。

## 一、背景与挑战
推理链看似合理但结论错误（幻觉式推理）常见，需区分过程与结果正确性。

## 二、核心原理
评测分为最终答案匹配与逐步逻辑校验两类，后者需人工或强模型判定。

## 三、形式化与数学基础
过程准确率：
$ \text{PAcc} = \frac{1}{N}\sum_i \mathbb{1}[\text{all steps valid in } z_i] $

## 四、代码实现
```python
def step_check(chain, verifier):
    # 逐步验证推理链
    return all(verifier(s) for s in chain.split('\n') if s.strip())
```

## 五、与其他技术对比
仅看答案会高估能力，过程校验更严格但成本高。

## 六、常见误区
把格式正确的链当作逻辑正确；忽略数值计算错误。

## 七、与开源书/权威来源对应
Wei 2022 展示大模型可生成可用推理链。

## 八、面试题
如何在不依赖标准答案时评估推理链质量？

## 九、演进与趋势
用验证器对推理路径打分并搜索最优链。

## 十、小结
正确性评测应同时覆盖结果与过程。
