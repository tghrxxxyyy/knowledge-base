# 视觉语言动作模型 VLA

> 见「具身智能深入/具身智能总览」；Brohan et al., *RT-2*, 2023；Driess et al., *PaLM-E*, 2023。

## 一、背景与挑战

如何让模型从「看和说」到「动手做」？

## 二、核心原理

**VLA** 把视觉、语言、动作统一进一个模型：用 VL 预训练底座，把机器人动作也离散化为 token，与视觉/语言同处词表，端到端预测动作 token（RT-2）。PaLM-E 把多模态嵌入直连 PaLM 做 embodied 推理。优势：可零样本泛化、语言指令即控制。

## 三、数学形式

`a = argmax P(action_tok | vision, language, state)`。

## 四、代码实现

```python
action_tok = vla(vision_feat, text_goal)   # 输出动作 token
robot.execute(decode(action_tok))
```

## 五、关键要点

- 动作离散化是关键一步。
- 需真实机器人数据（稀缺）。

## 六、与其他对比

- 传统分层（LLM规划+控制）；VLA 端到端。

## 七、常见误区

- VLA 无需控制——底层执行仍必要。
