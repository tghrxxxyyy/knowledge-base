# 具身智能总览

> 对应 llm-course 与机器人学习综述；具身 AI = 智能体在物理/虚拟环境中感知-行动。

## 一、背景与挑战

让模型不仅「懂」，还能在环境中「做」——感知、决策、执行。

## 二、核心原理

闭环：感知（视觉/语言）→ 决策（策略/规划）→ 执行（动作）→ 观察反馈。大模型用作「大脑」（高级推理/指令理解），下游控制策略执行。关键是把语言/视觉对齐到动作空间。

## 三、关键要点

- 仿真器（Isaac/Mujoco）是训练场。
- 世界模型助力规划。

## 四、代码实现

```python
obs = env.step(action); plan = llm(obs, goal); action = policy(plan)
```
