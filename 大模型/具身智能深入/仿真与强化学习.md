# 仿真与强化学习

> 见「具身智能深入/具身智能总览」与「强化学习基础深入」；机器人靠仿真练。

## 一、背景与挑战

真实机器人采样慢且危险，需仿真实练。

## 二、核心原理

在仿真器（MuJoCo/Isaac Gym）中用 RL（PPO/SAC）训练控制策略，再** sim-to-real** 迁移（域随机化：随机光照/摩擦力/质量，提升鲁棒性）。大模型提供高层目标分解。

## 三、关键要点

- 域随机化缓解仿真-现实差距。
- 样本效率是 RL 痛点。

## 四、代码实现

```python
for step in sim:
    a = policy(obs); obs, r, done = env.step(a)   # PPO 更新
```

## 五、与其他对比

- 真实采集贵；仿真便宜但需迁移。

## 六、常见误区

- 仿真训好即部署——sim-to-real 差距。
