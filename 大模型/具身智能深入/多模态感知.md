# 多模态感知

> 见「具身智能深入/具身智能总览」与「多模态」；感知融合。

## 一、背景与挑战

环境信息多元（视觉/语音/触觉/ proprioception），需融合。

## 二、核心原理

多模态感知把不同传感器编码到统一表示，供决策。具身场景常需实时、鲁棒（遮挡/噪声）；大模型做高层语义整合，底层用专用网络处理原始信号。

## 三、关键要点

- 时空对齐是关键。
- 冗余传感提升鲁棒。

## 四、代码实现

```python
feat = fuse(vision_emb, audio_emb, proprio_emb)
```

## 五、与其他对比

- 单模态局限；多模态互补。

## 六、常见误区

- 多模态必好——对齐错则误。
