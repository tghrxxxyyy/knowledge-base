# 机器人操作

> 见「具身智能深入/具身智能总览」与「视觉语言动作模型」；操纵物体是核心能力。

## 一、背景与挑战

抓取、堆叠、装配等精细操作需力控与视觉闭环。

## 二、核心原理

操作策略输入感知（深度/RGB/触觉），输出末端执行器动作（位姿/夹爪）。可用模仿学习（人类示教）、RL、或 VLA 直接语言指令驱动。抓取常先检测可抓区域（grasp pose）。

## 三、关键要点

- 触觉反馈补视觉盲区。
- 长程任务需分层规划。

## 四、代码实现

```python
pose = detect_grasp(rgbd); robot.move(pose); gripper.close()
```

## 五、与其他对比

- 固定程序脆弱；学习策略泛化。

## 六、常见误区

- 视觉足够——力控/触觉不可少。
