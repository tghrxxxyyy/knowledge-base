# 自然梯度实践

> 对应自然梯度在 RL（TRPO/PPO）与大规模训练中的应用。

## 一、背景与挑战

精确自然梯度难落地，但其在策略优化中价值突出。

## 二、核心原理

TRPO 用 Fisher 约束步长保单调改进；K-FAC 用于监督训练近似自然梯度；常配自适应阻尼。

## 三、数学形式

TRPO 约束 $\mathbb E_{s}[KL(\pi_{\theta_{old}},\pi_\theta)]\le\delta$，自然梯度给出可信域步。

## 四、代码实现

```python
kl = (F.logp_old - F.logp).mean()
if kl > delta: lr *= 0.5   # 回退
```

## 五、与其他对比

- 与 自适应学习率深入 相比更稳但更贵。
- 与 二阶优化深入 共享预条件。

## 六、常见误区

- 忽略 Fisher 估计方差致约束失效。
- 阻尼固定不调参易过早停止。

## 八、面试题

## 九、演进

理论 → TRPO → K-FAC 监督训练。

## 十、小结

自然梯度在可信域优化中尤为关键，工程以近似与阻尼实现。
