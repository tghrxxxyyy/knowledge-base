# 自然梯度总览

> 对应 Amari, *Natural Gradient Works Efficiently in Learning*, Neural Computation 1998。

## 一、背景与挑战

普通梯度下降在参数空间中沿欧氏距离下降，但参数微小变化对分布影响非均匀。

## 二、核心原理

自然梯度沿 KL 散度（黎曼度量）定义的最速下降方向更新，使每步对模型分布的改动更"公平"。

## 三、数学形式

自然梯度 $\tilde\nabla\mathcal L = G^{-1}\nabla\mathcal L$，其中 $G$ 为 Fisher 信息矩阵。

## 四、代码实现

```python
ng = torch.linalg.solve(Fisher, grad)   # 白化梯度
theta = theta - lr * ng
```

## 五、与其他对比

- 与 二阶优化深入 同用矩阵预条件，但度量不同（Fisher vs Hessian）。
- 与 K-FAC 实现自然梯度。

## 六、常见误区

- 认为自然梯度等于牛顿法；二者度量不同（KL vs 损失曲率）。
- 忽视 Fisher 估计噪声。

## 八、面试题

- 自然梯度为何优于普通梯度？答：以 KL 度量方向，使更新对输出分布影响一致，收敛更稳。

## 九、演进

欧氏梯度 → 自然梯度 → K-FAC 近似。

## 十、小结

自然梯度用信息几何度量修正更新方向，是二阶思想的分布视角。
