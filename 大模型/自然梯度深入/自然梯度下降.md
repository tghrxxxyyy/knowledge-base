# 自然梯度下降

> 对应 Pascanu & Bengio, *Revisiting Natural Gradients for Deep Networks*, 2013。

## 一、背景与挑战

高维下精确自然梯度不可算，需可扩展实现。

## 二、核心原理

以 Fisher 逆白化梯度，等价于在分布的黎曼流形上最速下降；常配阻尼 $(G+\lambda I)^{-1}$。

## 三、数学形式

更新 $\theta\leftarrow\theta-\eta(G+\lambda I)^{-1}\nabla\mathcal L$；阻尼保证正定并稳定。

## 四、代码实现

```python
update = solve(Fisher + lam*I, grad)
opt.step(theta - lr * update)
```

## 五、与其他对比

- 与 自适应学习率深入 的 Adam 是标量近似自然梯度。
- 与 K-FAC 配合得高效近似。

## 六、常见误区

- 无阻尼下 Fisher 近奇异致更新爆炸。
- 误把自然梯度当银弹，忽略估计开销。

## 八、面试题

- 为何自然梯度要加阻尼？答：Fisher 可能近奇异/估计不准，阻尼保证正定与数值稳定。

## 九、演进

精确 → 阻尼 → 近似（K-FAC）自然梯度。

## 十、小结

自然梯度下降以白化梯度达到几何最优步，需近似与阻尼落地。
