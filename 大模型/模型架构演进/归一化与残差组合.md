# 归一化与残差组合演进

> 对应 Vaswani et al., *Attention Is All You Need*, 2017（Post-Norm）；以及 Xiong et al., *On Layer Normalization in the Transformer Architecture*, 2020（Pre-Norm 分析）等后续研究。

## 一、背景与挑战

深层 Transformer 训练极易不稳定：梯度消失/爆炸、激活幅度逐层漂移。残差连接（Residual Connection）与归一化（LayerNorm / RMSNorm）是支撑「深到上百层」的两大支柱，但二者「谁先谁后、放在哪」并非小事，直接决定训练难度、收敛速度与最终性能。

早期 Transformer 用 Post-Norm（先子层、再加残差、再归一化），而现代大模型（GPT-2 之后、以及 LLaMA、PaLM 等）几乎一致采用 Pre-Norm（先归一化、再子层、再加残差）。这一看似微小的顺序变化，背后是对梯度流与激活尺度的深刻权衡。

## 二、核心原理

- **残差连接**：令子层输出 $F(x)$ 与输入相加，整体映射为 $x + F(x)$。它保证即使 $F$ 接近零，信息也能恒等通过，缓解深层梯度衰减。
- **层归一化（LayerNorm）**：对单个样本的特征维做均值方差归一化，使激活尺度稳定，降低层间耦合。
- **组合顺序**：
  - Post-Norm：$y = \text{Norm}(x + \text{Sublayer}(x))$
  - Pre-Norm：$y = x + \text{Sublayer}(\text{Norm}(x))$

Pre-Norm 下，残差分支始终携带未归一化的「原始 shortcut」，$x$ 直接透传到最深层，梯度回流路径极短，因此训练极其稳定、对学习率不敏感；但代价是表达上子层输出被「稀释」，深层有效深度略降。Post-Norm 把归一化放在最外层，残差信息被归一化「压缩」，**深层表达力更强**，但梯度需穿过归一化，训练更脆、需 warmup。

## 三、形式化与数学基础

设第 $l$ 层输入 $x^l$：

$$
\text{Post-Norm:} \quad x^{l+1} = \text{LayerNorm}\big(x^l + F^l(x^l)\big)
$$
$$
\text{Pre-Norm:} \quad x^{l+1} = x^l + F^l\big(\text{LayerNorm}(x^l)\big)
$$

RMSNorm（LLaMA 等采用）省略均值中心化，仅按均方根缩放：

$$
\text{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d}\sum_{i=1}^{d} x_i^2 + \epsilon}}\,\gamma
$$

其计算更轻、与 Pre-Norm 组合在大规模训练中成为事实标准。对深层网络，研究还提出「sandwich normalization」（在残差分支内外都加 Norm）或「deep norm」（特殊初始化 + 缩放）以兼顾稳定与表达。

## 四、代码实现

PyTorch 手写一个 Pre-Norm Transformer 块：

```python
import torch.nn as nn

class PreNormBlock(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        self.norm1 = nn.LayerNorm(d_model)
        self.attn  = nn.MultiheadAttention(d_model, n_heads, batch_first=True)
        self.norm2 = nn.LayerNorm(d_model)
        self.ffn   = nn.Sequential(
            nn.Linear(d_model, 4*d_model), nn.GELU(), nn.Linear(4*d_model, d_model))

    def forward(self, x):
        # Pre-Norm：先归一化再子层，再加残差
        h = x + self.attn(self.norm1(x), self.norm1(x), self.norm1(x))[0]
        y = h + self.ffn(self.norm2(h))
        return y
```

切换为 Post-Norm 只需把 `self.norm` 移到 `return` 最外层即可。

## 五、与其他技术对比

| 方案 | 训练稳定性 | 表达力 | 对学习率敏感度 | 代表模型 |
|------|-----------|--------|----------------|----------|
| Post-Norm | 中（需 warmup） | 强 | 高 | 原始 Transformer、BERT |
| Pre-Norm | 强 | 中 | 低 | GPT-2/3、LLaMA、PaLM |
| DeepNorm | 强 | 强 | 低 | DeepNet |
| Sandwich-Norm | 很强 | 中 | 低 | 部分深层变体 |

经验法则：层数越多越偏向 Pre-Norm 或其稳定化变体；Post-Norm 在较浅、重表达的模型（如 BERT 类编码器）中仍可用。

## 六、常见误区

- 「归一化位置无关紧要」：错误，Post/Pre 对深层训练稳定性影响巨大。
- 「Pre-Norm 一定更好」：不一定，Post-Norm 表达力更强，只是训练更难。
- 「BatchNorm 可替代 LayerNorm」：在变长序列、小 batch、自回归场景下 LayerNorm/RMSNorm 更稳，BatchNorm 在 NLP 中基本被弃用。
- 「深层只需残差即可」：残差缓解梯度衰减，但激活尺度漂移仍需归一化配合。

## 九、演进与趋势

归一化从 BatchNorm（CV 主导）转向 LayerNorm（序列主导），再到 RMSNorm（去均值、更省算力）成为 LLM 标配。组合顺序从原始 Post-Norm 演进到 Pre-Norm 及其稳定化变体（DeepNorm 特殊初始化、sandwich norm）。与注意力/FFN 子层、以及归一化 fused kernel 的协同优化，是大规模训练工程的关键细节之一。

## 十、小结

残差连接与归一化是深层 Transformer 稳定的双支柱，二者顺序（Pre/Post-Norm）在「训练稳定性」与「表达力」之间权衡。现代大模型以 Pre-Norm + RMSNorm 为事实标准，极深网络再辅以 DeepNorm/sandwich 等技巧。具体默认值（归一化类型、层数、初始化）以各模型官方配置为准。
