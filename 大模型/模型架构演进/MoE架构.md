# 混合专家 MoE

> 对应 Shazeer(MoE, 2017) 与 Mixtral。

## 一、背景与挑战

稠密模型增参即增算力。MoE 用多个专家 FFN + 路由，每 token 只激活部分专家，参数量大但算力省。

## 二、核心原理

```
y = Σ_k g_k(x) · E_k(x),  g = softmax(top-k router)
```

仅 top-k 专家参与。

## 三、关键要点

| 维度 | 稠密 | MoE |
|------|------|-----|
| 参数量 | 全用 | 大 |
| 算力 | 全用 | 部分 |
| 训练 | 稳 | 路由不均 |

## 四、与开源书对应

- Shazeer, *MoE*, 2017; Jiang et al., *Mixtral*, 2024.

## 六、小结

MoE 是 scaling 的高效路线，挑战在路由均衡。
