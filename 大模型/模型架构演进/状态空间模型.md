# 状态空间模型 SSM (Mamba)

> 对应 Gu & Dao, *Mamba: Linear-Time Sequence Modeling with Selective State Spaces*, 2023。

## 一、背景与挑战

Transformer 的自注意力在序列长度 $n$ 上呈 $O(n^2)$ 的时间与显存复杂度，长文档、高分辨率音频/视频、基因组等场景面临「上下文窗口越扩越贵」的困境。循环神经网络（RNN）虽为 $O(n)$ 且推理内存恒定，但其串行递推难以并行训练、长期记忆随状态维度固定而受限，且无法针对输入内容动态分配记忆。

状态空间模型（State Space Model, SSM）把序列建模重新形式化为连续/离散线性动力系统，天然兼具 $O(n)$ 推理与可并行训练两种特性。其核心难题在于：经典 SSM（如 S4）的状态转移与输入无关，对所有 token「一视同仁」，无法像注意力那样对关键内容「选择性记忆」。Mamba 提出的「选择性状态空间」（selective SSM）正是为解决这个问题而生。

## 二、核心原理

SSM 把一维输入信号 $x(t)$ 通过隐状态 $h(t)\in\mathbb{R}^{N}$ 映射到输出 $y(t)$：

- 连续形式：状态由参数矩阵 $A\in\mathbb{R}^{N\times N}$（状态转移）、$B\in\mathbb{R}^{N\times1}$（输入投影）、$C\in\mathbb{R}^{1\times N}$（输出投影）决定。
- 离散化：用零阶保持（zero-order hold）配合时间步 $\Delta$ 把连续系统转为递归，得到可在 GPU 上高效扫描（scan）的离散参数 $\bar{A},\bar{B}$。

Mamba 的关键创新是让 $B,C,\Delta$ 成为输入 $x$ 的函数（通过一个小线性投影 + 激活），从而每个 token 都能决定「记住什么、遗忘什么」。当 $\Delta$ 很大时该 token 被强烈写入状态，很小时则被忽略——这正是注意力的「内容感知路由」在线性递归上的等价物。

## 三、形式化与数学基础

连续 SSM：

$$
h'(t) = A\,h(t) + B\,x(t), \qquad y(t) = C\,h(t)
$$

离散化（零阶保持，给定步长 $\Delta$）：

$$
\bar{A} = \exp(\Delta A), \qquad \bar{B} = (\Delta A)^{-1}(\exp(\Delta A) - I)\cdot \Delta B
$$
$$
h_t = \bar{A}\,h_{t-1} + \bar{B}\,x_t, \qquad y_t = C\,h_t
$$

选择性机制即 $\Delta_t = \text{softplus}(W_\Delta x_t + b_\Delta)$，同理 $B_t,C_t$ 由输入投影得到。整体计算可写为线性递归，训练时用并行前缀和（parallel scan）在序列维度并行，推理时逐 token 递推，内存仅与状态维度 $N$ 相关，与序列长度无关。

## 四、代码实现

以 HuggingFace `transformers` 加载 Mamba 为例：

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_id = "state-spaces/mamba-130m-hf"
tok = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(model_id)

txt = "深度学习的核心是"
ids = tok(txt, return_tensors="pt")
out = model.generate(**ids, max_new_tokens=64)
print(tok.decode(out[0], skip_special_tokens=True))
```

递归推理无需 KV Cache，内存恒定：

```python
# 伪代码：逐 token 递推
h = torch.zeros(N)                      # 隐状态恒定大小
for x_t in stream():
    h = A_bar @ h + B_bar_t(x_t)        # 更新状态
    y_t = C_t(x_t) @ h                  # 输出
```

## 五、与其他技术对比

| 维度 | Transformer | 经典 SSM (S4) | Mamba (选择性 SSM) |
|------|-------------|---------------|--------------------|
| 训练复杂度 | $O(n^2)$ | $O(n)$ | $O(n)$ |
| 推理内存 | 随 $n$ 膨胀 (KV Cache) | 恒定 | 恒定 |
| 内容选择性 | 强（注意力） | 弱（参数固定） | 强 |
| 并行训练 | 易 | 易（scan） | 易（scan） |
| 长程依赖 | 受限于窗口 | 优 | 优 |

Mamba 在长序列吞吐与显存上优势明显，但在需要「显式全局重关注」（如复杂检索式推理）时，注意力仍更有利；因此出现 Mamba-2、混合并行（如 Jamba、Samba）等把 SSM 与注意力层交替的方案。

## 六、常见误区

- 「SSM 没有注意力就学不会长程依赖」：错误，线性递归本身可建模任意长程，难点在「选择性」而非「距离」。
- 「Mamba 训练无法并行」：错误，离散递归可用 parallel scan 在序列维并行，只是比注意力的矩阵乘更不规整。
- 「状态维度 $N$ 越大越好」：过大显存与计算上升，需权衡；Mamba 用「扩展状态维度 + 投影压缩」缓解。

## 九、演进与趋势

从 S4 的参数固定状态，到 Mamba 的输入依赖选择性状态，再到 Mamba-2 用「状态空间对偶（State Space Duality, SSD）」把 SSM 重新表达为类注意力分块计算、提升硬件利用率，SSM 正快速逼近注意力的工程成熟度。同时，Jamba、Samba、RWKV、RetNet 等把线性递归与门控/注意力混合，试图兼顾长上下文效率与复杂推理能力，是「后 Transformer 架构」最活跃的方向之一。

## 十、小结

状态空间模型把序列建模重构为线性动力系统，以 $O(n)$ 训练/推理复杂度与恒定推理内存突破注意力的二次瓶颈。Mamba 通过「选择性状态」赋予模型内容感知的记忆写入能力，是当前最具代表性的高效序列建模路线；与注意力的混合部署正成为长上下文大模型的重要趋势。具体实现细节与最新版本以官方文档（Mamba 论文、HuggingFace Transformers）为准。
