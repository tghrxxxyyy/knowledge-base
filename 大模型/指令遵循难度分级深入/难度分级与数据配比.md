# 难度分级与数据配比

> 对应 指令数据课程与配比联合优化研究。

## 一、背景与挑战

仅排序不够，还需决定各难度层在训练中的占比。配比不当(如难样本过多)会拖垮训练。

## 二、核心原理

按难度分层后，对各层分配采样权重。初期高权重易层，后期提升难层；总体保持易层为主干、难层为增强。

## 三、数学形式

难度层 $k$ 权重：

$$
q_k(t) = \frac{e^{a_k(t)}}{\sum_{k'} e^{a_{k'}(t)}}, \quad a_k(t) = \alpha_k + \beta\cdot k\cdot \frac{t}{T}
$$

即随训练推进，高层($k$ 大)权重线性抬升。

## 四、代码实现

```python
import torch

def layer_weight(k, t, T, alpha, beta):
    return torch.softmax(torch.tensor([alpha + beta*k*i/T for i in range(5)]), 0)[k]
```

## 五、与其他对比

与领域配比互补：领域管“内容”，难度管“顺序与比例”，二者正交可联合。

## 六、常见误区

误区：难层越多越好。过多难样本导致梯度不稳定与遗忘。
