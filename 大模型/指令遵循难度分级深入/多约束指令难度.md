# 多约束指令难度

> 对应 dair-ai/Prompt-Engineering-Guide 指令约束与遵循研究。

## 一、背景与挑战

真实指令常含多个相互制约的约束(长度+格式+风格+内容)，约束间冲突显著提升遵循难度，单看数量会低估。

## 二、核心原理

难度来自约束数量与冲突度。冲突可用约束图建模：节点为约束，边为冲突强度。图越密越难同时满足。

## 三、数学形式

约束图 $G=(C,E)$，难度：

$$
D = |C| + \beta \sum_{(i,j)\in E} w_{ij}
$$

设满足概率近似随难度指数下降：

$$
P(\text{satisfy}) \approx e^{-\gamma D}
$$

## 四、代码实现

```python
def multi_constraint_diff(n_constraints, conflicts, beta=0.5, gamma=0.1):
    D = n_constraints + beta * sum(conflicts)
    return D, float(__import__('math').exp(-gamma * D))
```

## 五、与其他对比

相比单约束难度，多约束强调交互效应，更贴近真实指令遵循。

## 六、常见误区

误区：约束独立可加。实际冲突使难度超线性。

## 八、面试题

- Q：为什么多约束难超线性？答：约束冲突需权衡，满足一个常破坏另一个。
- Q：如何降难度？答：拆解约束、先满足硬约束再软约束。

## 九、演进

## 十、小结

多约束难度由数量与冲突共同决定，是难度分级的关键维度。
