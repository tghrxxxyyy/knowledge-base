# 多目标奖励模型

> 对应 Touvron et al., *Llama 2*, 2023（多奖励头）；Parisa et al., 2024。

## 一、背景与挑战

单奖励头难以隔离不同价值信号，多目标奖励用共享底座+多线性头同时输出各维度标量。

## 二、核心原理

在 SFT 底座上接 $k$ 个独立奖励头，各自用对应偏好数据训 Bradley-Terry 损失；推理时可单独评估某维度分数。

## 三、数学形式

$r_i(x,y)=h_i^\top f_\phi(x,y)$，其中 $f_\phi$ 为共享表征；$i=1..k$ 对应 $k$ 个目标。

## 四、代码实现

```python
heads = nn.ModuleList([nn.Linear(H, 1) for _ in range(k)])
r = torch.cat([h(f) for h in heads], -1)
```

## 五、与其他对比

- 与单 RM 对比：多头防价值相互掩盖，但需更多标注预算。
- 与奖励模型退化深入共享训练细节。

## 六、常见误区

- 头间共享表征泄露导致维度耦合。
- 某维度数据少致该头欠拟合、权重失效。

## 八、面试题

- 多目标奖励如何避免维度耦合？答：各头独立监督信号+解耦正则，保证维度可分离。

## 九、演进

单头 → 多头独立 → 解耦表征多头。

## 十、小结

多目标奖励模型把价值信号结构化，是聚合与权衡的底座。
