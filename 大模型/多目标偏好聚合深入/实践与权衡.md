# 多目标偏好聚合实践与权衡

> 对应 Bai et al., *Constitutional AI*, 2022；Ouyang et al., *InstructGPT*, 2022。

## 一、背景与挑战

权重设定牵扯产品定位与合规；需可解释、可审计地选定当前部署权重。

## 二、核心原理

以红队/用户研究定默认权重，保留调权接口；监控在线各维度指标，越界即回退权重。

## 三、数学形式

部署权重 $w^*$ 由约束 $\min_w \max_i \text{viol}_i(w)$ 选择，使最差维度达标。

## 四、代码实现

```python
if safety_viol > thr:

```

## 六、常见误区

- 权重一次性定死，未随风险演化调整。
- 只优化平均分忽视最差维度越界。
