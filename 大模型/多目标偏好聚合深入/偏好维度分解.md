# 偏好维度分解

> 对应 Casper et al., *Exploring the Pareto Front*, 2023；Jang et al., *Token-level RLHF*, 2023。

## 一、背景与挑战

聚合前需先明确把偏好拆成哪些正交维度，否则加权组合会出现目标纠缠、互相抵消。

## 二、核心原理

把总偏好分解为有用性、安全性、真实性、风格等可独立标注/打分的维度；每维度可用独立奖励模型或独立偏好数据集学习，形成多目标奖励向量。

## 三、数学形式

偏好向量 $R(x,y)=[r_1,r_2,\dots,r_k]^\top$；任意两点比较按加权差 $\langle w, R(x,y_a)-R(x,y_b)\rangle$ 决定优劣。

## 四、代码实现

```python
def pref_gt(w, ra, rb):
    return torch.sign((w * (ra - rb)).sum())
```

## 五、与其他对比

- 与奖励模型深入（单头 RM）对照：维度分解换可解释与可调。
- 与价值观冲突消解共享维度划分方法。

## 六、常见误区

- 维度非正交致重复奖励、放大同一信号。
- 维度遗漏使隐含价值无法被约束。

## 八、面试题

- 为何先分解维度再聚合？答：独立维度可分别标注与加权，避免目标纠缠与不可解释。

## 九、演进

整体打分 → 多维标注 → 自动化维度发现。

## 十、小结

维度分解是可控多目标对齐的前提，决定后续聚合的可解释性。
