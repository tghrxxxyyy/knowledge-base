# 多目标偏好聚合总览

> 对应 Rame et al., *MORLHF: Multi-Objective RLHF*, 2024；Parisa et al., *More than One Objective*, 2024。

## 一、背景与挑战

人类偏好并非单一维度，常同时要求有用、无害、诚实、简洁；单标量奖励被迫把多目标压成一维，难以表达真实权衡。

## 二、核心原理

多目标 RLHF 用多个奖励头分别刻画各属性，策略优化在帕累托前沿上搜索，由权重向量控制不同目标侧重，得到一组非支配策略而非单一解。

## 三、数学形式

最大化各目标期望并控制 KL：$J_i(\pi)=\mathbb E_{x,y\sim\pi}[r_i(x,y)]-\beta\,KL(\pi\|\pi_{ref})$；偏好解由权重 $w$ 线性组合 $r_w=\sum_i w_i r_i$。

## 四、代码实现

```python
rw = torch.stack([rm_i(x, y) for rm_i in rms], dim=-1)
combined = (w * rw).sum(-1)
```

## 五、与其他对比

- 相较单目标 RLHF，多目标保留维度独立性与可解释性，但训练与推理成本更高。
- 与 DPO 单目标对齐互补：可把多目标奖励做加权后走 DPO 近似。

## 六、常见误区

- 以为线性加权即足够；目标冲突时需帕累托而非固定权重。
- 各奖励头尺度不一直接相加会掩盖弱目标。

## 八、面试题

- 多目标 RLHF 相比单目标优势？答：保留各价值维度独立信号，可沿帕累托前沿权衡而非硬压成一维。

## 九、演进

单标量奖励 → 多奖励头 → 偏好条件策略（一模型覆盖整条前沿）。

## 十、小结

多目标偏好聚合把对齐从单点解扩展为可解释的前沿，是复杂价值权衡的基础。
