# 帕累托前沿对齐实践

> 对应 Rame et al., *MORLHF*, 2024；指令微调与对齐权衡前沿。

## 一、背景与挑战

如何把前沿上一个策略稳定产出并部署，且能在线调权重。

## 二、核心原理

用单一偏好条件策略 $\pi_\theta(y|x,w)$ 把所有前沿点压进一个网络，推理时给定 $w$ 即采样对应权衡策略，避免存储多个模型。

## 三、数学形式

$\pi_\theta(y|x,w)\propto\pi_{ref}(y|x)\exp(\frac1\beta\langle w,R(x,y)\rangle)$，权重仅改指数偏好项。

## 四、代码实现

```python
logp = logp_ref + (w * rw).sum(-1) / beta
```

## 五、与其他对比

- 与多模型部署对照：条件策略省存储、易插值。
- 与 DPO 对照：可看作权重条件化的分类损失。

## 六、常见误区

- 条件维度不充分致前沿塌缩到少数点。
- 推理权重未归一致偏好方向偏移。

## 八、面试题

- 偏好条件策略优点？答：单模型覆盖整条前沿，按权重即时切换，省存储易插值。

## 九、演进

多模型 → 条件策略 → 自适应权重路由。

## 十、小结

条件策略把帕累托前沿压进单一网络，是落地多目标对齐的实用形态。
