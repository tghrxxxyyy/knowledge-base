# 聚合加权与帕累托前沿

> 对应 Rame et al., *MORLHF*, 2024；多目标优化经典帕累托理论。

## 一、背景与挑战

固定权重会掩盖目标间冲突；需要展示权衡曲线而非单点，便于下游按场景选策略。

## 二、核心原理

沿不同权重方向优化得到一组策略，这些策略在目标空间中构成帕累托前沿；前沿上的点互不支配，移动需牺牲另一目标。

## 三、数学形式

帕累托支配：$a\succ b$ 当 $\forall i\, J_i(a)\ge J_i(b)$ 且至少一项严格大；前沿为所有非支配解的像。

## 四、代码实现

```python
front = []
for w in grid(8):
    front.append(optimize(w))
```

## 五、与其他对比

- 与单模型部署对照：前沿允许运行时按场景切换策略。
- 与 DPO 对比：DPO 单目标，需外挂多目标权重。

## 六、常见误区

- 误把帕累托前沿当线性可插值；前沿可能非凸。
- 权重采样不均致前沿稀疏、难选点。
