# 学习率调度总览

> 对应 Loshchilov & Hutter, *Cosine*, 2016（SGDR/CosineAnnealing）；深度学习优化基础。

## 一、背景与挑战

学习率是最敏感超参；固定 LR 易陷局部极小或震荡，需随训练调度。

## 二、核心原理

常见策略：阶梯衰减、指数衰减、余弦退火、warmup、循环（cyclic）、带重启余弦（SGDR）。

## 三、数学形式

余弦退火：$\eta_t = \eta_{min} + \frac12(\eta_{max}-\eta_{min})(1+\cos(\frac{t}{T}\pi))$。

## 四、代码实现

```python
sched = torch.optim.lr_scheduler.CosineAnnealingLR(opt, T_max=T)
```

## 五、与其他对比

- 余弦平滑降，泛化好；阶梯简单但突变。
- 与 优化理论深入 / 训练不稳定诊断深入 衔接。

## 六、常见误区

- 无 warmup 大模型训练易不稳（梯度爆炸）。
- 余弦末段 LR 过低拖慢收敛尾。

## 七、与开源书对应

- d2l-zh 优化章：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 为什么需要 warmup？答：初期梯度大，小 LR 稳定训练、避免早期崩。

## 九、演进

固定 → 阶梯 → 指数 → 余弦 → 带重启。

## 十、小结

学习率调度是大模型训练稳定与收敛质量的关键旋钮。
