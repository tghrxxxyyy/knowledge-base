# 学习率调度实践选型

> 对应大模型训练实战；与 自动化超参优化深入 衔接。

## 一、背景与挑战

不同规模/任务需不同调度，且 LR 与 batch、warmup 强耦合。

## 二、核心原理

经验法则：预训练用 cosine+warmup；微调用小 LR 或 const；大 batch 配大 LR（linear scaling）。

## 三、数学形式

linear scaling：$\eta \propto B/B_{ref}$；warmup 步数随 batch 增。

## 四、代码实现

```python
lr = base_lr * (batch / 256)
sched = WarmupCosine(opt, warmup=max(1000, batch), T=T)
```

## 五、与其他对比

- 与 正则化与Dropout深入 / 梯度裁剪深入 共同构成训练稳定套件。
- 与 超参优化深入 交叉（自动搜调度）。

## 六、常见误区

- 忽略 LR-batch 联动致大 batch 训练崩。
- 直接套用别人 LR 不按自己规模缩放。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 大 batch 为何要同步调大 LR？答：每步看的样本多，需更大步长维持更新幅度。

## 九、演进

手工设 → 规则缩放 → 自动搜索调度。

## 十、小结

LR 调度需与 batch/warmup 协同，按规模与任务经验化选型。
