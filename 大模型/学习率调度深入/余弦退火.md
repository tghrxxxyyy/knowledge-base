# 余弦退火

> 对应 CosineAnnealingLR / SGDR。

## 一、背景与挑战

希望 LR 平滑下降、末期精细收敛，且可周期性重启跳出局部极小。

## 二、核心原理

LR 沿余弦曲线从最大降到最小；SGDR 在周期末重启回最大，逐步缩短周期。

## 三、数学形式

带重启：$\eta_t = \eta_{min} + \frac12(\eta_{max}-\eta_{min})(1+\cos(\frac{T_{cur}}{T_i}\pi))$，重启时 $T_{cur}$ 归零、$T_i$ 倍增。

## 四、代码实现

```python
sched = CosineAnnealingWarmRestarts(opt, T_0=10, T_mult=2)
```

## 五、与其他对比

- 比阶梯平滑；重启助逃离尖锐极小。
- 与 优化理论深入 中损失地形衔接。

## 六、常见误区

- 周期 $T_0$ 过短致震荡；过长失重启益处。
- 末周期仍重启会破坏收敛。

## 七、与开源书对应

## 八、面试题

- SGDR 重启的好处？答：周期性回大 LR 跳出局部极小，探索更好解。

## 九、演进

单周期余弦 → 多重启（SGDR）→ 与 warmup 组合。

## 十、小结

余弦退火+重启兼顾平滑收敛与跳出局部极小，是大模型常用调度。
