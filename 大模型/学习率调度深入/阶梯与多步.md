# 阶梯与多步衰减

> 对应 StepLR / MultiStepLR。

## 一、背景与挑战

简单可解释、实现易，但衰减突变可能扰动训练。

## 二、核心原理

每隔固定 epoch（或指定里程碑）LR 乘衰减因子 $\gamma$。

## 三、数学形式

$\eta_t = \eta_0 \gamma^{\lfloor t/\tau\rfloor}$（阶梯）或里程碑处乘 $\gamma$（多步）。

## 四、代码实现

```python
sched = MultiStepLR(opt, milestones=[30,60,90], gamma=0.1)
```

## 五、与其他对比

- 比余弦突变明显；适合小数据集/经典 CV。
- 大模型更偏余弦+warmup。

## 六、常见误区

- 里程碑设错致过早/过晚衰减。
- 突变致短暂 loss 抖动。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 阶梯 vs 余弦怎么选？答：追求平滑收敛选余弦，要简单可控选阶梯。

## 九、演进

手动阶梯 → 自适应（如 ReduceLROnPlateau）。

## 十、小结

阶梯/多步衰减简单实用，适合可控场景，渐被余弦取代于大模型。
