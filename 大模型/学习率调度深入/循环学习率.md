# 循环学习率

> 对应 Smith, *Cyclical LR*, 2017；Leslie Smith。

## 一、背景与挑战

固定调度未必找到好邻域；循环可在训练中以探索+利用平衡。

## 二、核心原理

LR 在 $[lr_{min},lr_{max}]$ 间三角/余弦周期摆动，帮助逃离鞍点、快速找好学习率区间。

## 三、数学形式

三角循环：$\eta_t = lr_{min} + (lr_{max}-lr_{min})\cdot\max(0,1-|\frac{t\,mod\,(2T)}{T}-1|)$。

## 四、代码实现

```python
sched = CyclicLR(opt, base_lr=1e-4, max_lr=1e-3, step_size_up=2000)
```

## 五、与其他对比

- 与余弦退火方向相反（上下摆动）。
- 常用于 lr range test 找上下界。

## 六、常见误区

- 幅度/周期设错反伤收敛。
- 与 warmup 叠加需谨慎。

## 七、与开源书对应

## 八、面试题

- 循环 LR 用途？答：探索损失地形、辅助 lr 范围测试、逃离鞍点。

## 九、演进

三角形 → 余弦循环 → 与快照集成（Snapshot Ensembles）。

## 十、小结

循环 LR 以有界摆动增强探索，亦可用于确定最佳 LR 区间。
