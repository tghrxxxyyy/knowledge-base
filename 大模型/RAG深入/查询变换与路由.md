# 查询变换与路由

> 对应 llm-course。提升检索召回的工程技巧。

## 一、核心概念

用户问题常模糊/口语化/多跳。查询变换用 LLM 改写/扩展查询：

- **Query Rewriting**：改写更利于检索。
- **Query Expansion**：生成多个子查询分别检索。
- **Step-back Prompting**：先问更抽象的问题。
- **Routing**：根据问题类型路由到不同知识库/索引（如 FAQ 用向量、表格用 SQL）。

## 二、关键要点

| 技巧 | 解决 |
|------|------|
| 改写 | 口语化 |
| 扩展 | 多跳 |
| 路由 | 多源 |

- 多跳问题为何需要查询扩展？
- 路由机制如何避免检索错误知识库？
