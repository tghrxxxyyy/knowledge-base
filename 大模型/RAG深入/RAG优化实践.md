# RAG 优化实践

> 综合 llm-universe 与 llm-course 的工程经验。

## 一、核心清单

1. **检索召回不足** → 换更强嵌入、加混合检索、查询扩展。
2. **上下文噪声** → 父子文档、重排、收紧 Top-k。
3. **答案不忠实** → 强化 prompt「仅基于上下文」、加忠实度评估。
4. **长上下文浪费** → 压缩/摘要检索片段。
5. **元数据过滤** → 按时间/来源/权限预筛。
6. **缓存** → 高频查询缓存结果降本。

## 二、关键要点

- 先定位瓶颈在哪一层（检索 or 生成），再对症优化。
- 评估驱动迭代，避免拍脑袋。
