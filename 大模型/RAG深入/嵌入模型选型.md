# 嵌入模型选型

> 对应 llm-course「Embeddings」与 MTEB 榜单。

## 一、核心概念

嵌入模型把文本映射为稠密向量，其质量决定语义检索上限。选型看：

- **领域适配**：通用模型 vs 代码/医疗专用。
- **维度与速度**：高维更准但慢。
- **多语言**：跨语言检索需多语嵌入。
- **MTEB 分数**：权威综合榜。

主流：OpenAI text-embedding-3、BGE(baichuan)、M3E、E5、GTE、BGE-M3(多向量) 等。

## 二、代码实现

```python
from sentence_transformers import SentenceTransformer
model = SentenceTransformer("BAAI/bge-large-zh")
vec = model.encode("大模型检索增强生成")
```

## 三、关键要点

| 考虑 | 说明 |
|------|------|
| 维度 | 768~4096 |
| 归一化 | 余弦相似度前需 L2 归一 |
| 领域 | 专用模型更优 |

## 四、常见误区

- 检索与重排用不同嵌入空间，未对齐。
- 未归一化导致余弦/点积结果异常。
