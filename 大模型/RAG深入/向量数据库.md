# 向量数据库

> 对应 llm-universe 与 llm-course。存储与高效检索嵌入。

## 一、核心概念

向量库核心是**近似最近邻(ANN)** 检索。主流：

| 系统 | 特点 |
|------|------|
| FAISS | 本地、快、工程化 |
| Milvus | 分布式、生产级 |
| Qdrant | Rust、易用 |
| Chroma | 轻量、原型友好 |
| Weaviate | 混合检索、内置 |
| pgvector | 复用 Postgres |

索引算法：IVF(倒排)、HNSW(图)、PQ(量化压缩)。

## 二、代码实现（FAISS 示意）

```python
import faiss, numpy as np
idx = faiss.IndexFlatL2(768)          # 精确
# 或 faiss.IndexHNSWFlat(768, 32)     # 近似
idx.add(np.array(vectors, dtype="float32"))
D, I = idx.search(q_vec, k=5)
```

## 三、关键要点

- HNSW 召回率高、内存占用大。
- 大规模用 IVFPQ 平衡速度与精度。
