# 文档加载与解析

> 对应 llm-universe「文档加载与切割」。多格式解析是 RAG 数据管线第一步。

## 一、核心概念

知识源多样：PDF、Word、Markdown、网页、数据库、表格。需统一解析为纯文本。常见工具：

- **LangChain Document Loaders**：Unstructured/PyPDF/WebBase 等。
- **LlamaIndex**：面向 RAG 的加载与索引。
- ** unstructured**：复杂版式 PDF/扫描件解析。

解析需保留结构（标题层级、表格）以便后续切分时保持语义完整。

## 二、代码实现（LangChain 示意）

```python
from langchain_community.document_loaders import PyPDFLoader, WebBaseLoader
docs = PyPDFLoader("manual.pdf").load()
web = WebBaseLoader("https://example.com").load()
```

## 三、关键要点

| 源 | 挑战 |
|----|------|
| PDF | 版式/表格/扫描 |
| 网页 | 噪声清洗 |
| 表格 | 结构保持 |

## 四、常见误区

- 忽略表格，导致结构化知识丢失。
- 网页抓取未去导航/广告噪声。
