# 混合检索 Hybrid Search

> 对应 llm-course。关键词 + 向量互补。

## 一、核心概念

纯向量检索对**专有名词、ID、精确短语**不敏感（语义模糊）。混合检索 = 稀疏检索(BM25/关键词) + 稠密向量检索，融合两路得分：

```
score = α · dense_score + (1-α) · bm25_score    # Reciprocal Rank Fusion 也常用
```

BM25 擅长精确匹配，向量擅长语义泛化，互补提升召回。

## 二、代码实现（RRF 融合示意）

```python
def rrf(rank_lists, k=60):
    scores = {}
    for ranks in rank_lists:           # 每路返回有序 doc_id 列表
        for i, doc in enumerate(ranks):
            scores[doc] = scores.get(doc, 0) + 1.0 / (k + i + 1)
    return sorted(scores, key=scores.get, reverse=True)
```

## 三、关键要点

- BM25 对 rare term 加权高，弥补向量短板。
- RRF 无需归一化各路分数，鲁棒。
