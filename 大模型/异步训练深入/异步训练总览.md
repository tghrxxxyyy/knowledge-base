# 异步训练总览

> 对应 Niu et al., 《Hogwild!: A Lock-Free Approach to Parallelizing SGD》, 2011。

## 一、背景与挑战

同步 SGD 每步等最慢卡，设备利用率低；异步允许各卡用过期参数更新。

## 二、核心原理

各 worker 独立读参数、算梯度、写回，无全局屏障；参数服务器或共享内存持有最新参数；用陈旧梯度换吞吐。

## 三、数学形式

worker 用参数 $\theta_{t-\tau}$（陈旧度 $\tau$）算梯度，更新 $\theta\leftarrow\theta-\eta g(\theta_{t-\tau})$。

## 四、代码实现

```python
theta = ps.pull()                          # 读最新（可能旧）
g = grad(model, theta, batch)
ps.push(theta - lr * g)                    # 写回
```

## 五、与其他对比

- 与 数据并行深入（同步 all-reduce）相反。
- 与 通信压缩深入 常组合降写回量。

## 六、常见误区

- 陈旧度过大致发散。
- 无锁更新遇非凸易不稳。

## 八、面试题

- 异步为何快？答：无全局屏障，各卡持续计算，用陈旧梯度换吞吐。

## 九、演进

同步 → Hogwild 无锁 → 参数服务器。

## 十、小结

异步训练以陈旧梯度换设备利用率，适合异构/慢网络。
