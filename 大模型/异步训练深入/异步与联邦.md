# 异步训练与联邦学习

> 对应 McMahan et al., 《Federated Learning》, 2017；异步 FL。

## 一、背景与挑战

海量边缘设备网络慢、异构，同步聚合难。

## 二、核心原理

各设备本地多步 SGD 后异步上传差分/参数；服务器聚合（FedAvg 或异步版本）；用陈旧度与压缩适配弱网。

## 三、数学形式

本地更新 $\theta_i\leftarrow\theta_i-\eta\sum g$；聚合 $\theta\leftarrow\theta+\frac{n_i}{N}\Delta_i$（异步加权）。

## 四、代码实现

```python
delta = local_train(theta, epochs=k)       # 设备本地多步
server.apply_async(client_id, delta)
```

## 五、与其他对比

- 与 数据并行深入 中心化同步对照（去中心、隐私）。
- 与 通信压缩深入 必用（弱网）。

## 六、常见误区

- 设备掉线致聚合偏。
- 无差分隐私泄露数据。

## 八、面试题

- 联邦为何常异步？答：设备异构慢、易掉线，异步聚合更鲁棒。

## 九、演进

同步 FedAvg → 异步 FL → 压缩+隐私。

## 十、小结

异步适配联邦学习的弱网异构，是端侧训练范式。
