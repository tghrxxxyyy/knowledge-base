# 异步与梯度压缩结合

> 对应通信高效异步 SGD；Lin et al., 2018。

## 一、背景与挑战

异步写回频繁，通信仍是瓶颈，需压后再推。

## 二、核心原理

worker 算梯度后先量化/稀疏再 push 到 PS；PS 端误差补偿聚合；既降通信又保异步吞吐。

## 三、数学形式

通信量降 $r\times$，陈旧度在压缩省时下进一步降；更新 $\theta\leftarrow\theta-\eta\, decompress(\tilde g)$。

## 四、代码实现

```python
g_q = compress_1bit(grad)                  # 压后推
ps.push(g_q); e = update_error(e, grad, g_q)
```

## 五、与其他对比

- 与 通信压缩深入 机制一致、用于异步。
- 与 参数服务器 配合。

## 六、常见误区

- 压缩+异步双误差叠加需统一补偿。
- 推送频率过高仍占带宽。

## 八、面试题

- 异步为何配压缩？答：写回频繁，压缩降通信同时保持无屏障吞吐。

## 九、演进

异步 → +压缩 → +误差补偿。

## 十、小结

异步与压缩结合降通信且保吞吐，需统一误差补偿。
