# 异步训练稳定性

> 对应异步 SGD 收敛；Lian et al., 《Asynchronous Parallel SGD》, 2015。

## 一、背景与挑战

非凸大模型异步易震荡、不收敛。

## 二、核心原理

减小学习率随陈旧度、用动量/Adam 稳梯度、梯度裁剪、延迟补偿；理论表明在衰减 lr 下异步 SGD 可收敛。

## 三、数学形式

有效 lr $\eta_t = \eta_0/(1+\tau)^{\alpha}$；梯度裁剪 $\hat g=g/\max(1,\|g\|/c)$。

## 四、代码实现

```python
lr_eff = lr0 / (1 + staleness) ** 0.5
g = clip(g, c); opt.step(g * lr_eff)
```

## 五、与其他对比

- 与 数据并行深入 同步更稳但慢。
- 与 通信压缩深入 误差补偿思路相通。

## 六、常见误区

- 固定 lr 致异步发散。
- 忽视梯度尖峰。

## 八、面试题

- 如何稳异步训练？答：随陈旧度衰减 lr、裁剪梯度、用动量，理论可收敛。

## 九、演进

固定 lr → 衰减 lr → 延迟补偿。

## 十、小结

异步稳定靠 lr 衰减与梯度控制，理论保证收敛。
