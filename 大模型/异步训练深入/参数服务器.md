# 异步与参数服务器

> 对应 Li et al., 《Scaling Distributed Machine Learning with the Parameter Server》, 2014。

## 一、背景与挑战

万卡同步通信树难扩展，需解耦计算与参数管理。

## 二、核心原理

参数服务器（PS）分片存参数，worker 拉/推梯度；server 可多副本、异步聚合；支持同步/异步/SSP 多种一致性。

## 三、数学形式

server 聚合 $\theta\leftarrow\theta-\eta\frac{1}{n}\sum push_i$；一致性模型决定可见陈旧度。

## 四、代码实现

```python
for _ in range(workers):
    grad = recv(); theta -= lr * grad       # server 异步聚合
```

## 五、与其他对比

- 与 数据并行深入 all-reduce 是去中心化对照。
- 与 混合并行深入 不同范式。

## 六、常见误区

- server 成单点瓶颈（需分片+多 server）。
- 一致性过松致不收敛。

## 八、面试题

- 参数服务器优点？答：解耦计算与参数，弹性扩展、支持异步与多种一致性。

## 九、演进

单机 → PS 分片 → 分层 PS。

## 十、小结

参数服务器以中心化参数管理支撑异步大规模训练。
