# 异步训练与陈旧度

> 对应 Ho et al., 《Stale Synchronous Parallel (SSP)》, 2013；异步收敛分析。

## 一、背景与挑战

陈旧梯度偏差随 worker 慢增，需界定可接受范围。

## 二、核心原理

SSP 限制最大陈旧度 $s$：快 worker 等到与最慢差距 $\le s$ 再继续，兼顾异步吞吐与收敛；理论给陈旧度上界保证。

## 三、数学形式

陈旧度 $\tau_i = t - t_{read}^{(i)}$；SSP 约束 $\max_i \tau_i \le s$；收敛率随 $s$ 退化。

## 四、代码实现

```python
while global_clock - my_clock > staleness_bound:
    sleep()                                 # 等慢 worker
push_grad(g)
```

## 五、与其他对比

- 与 通信压缩深入 都放宽同步约束。
- 与 数据并行深入 全同步对照。

## 六、常见误区

- 陈旧界设太大失收敛、太小退化为同步。
- 忽视慢 worker 拖界。
