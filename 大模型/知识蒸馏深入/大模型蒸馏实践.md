# 大模型蒸馏实践

> 见「知识蒸馏深入/知识蒸馏总览」与「模型量化部署实战」；Touvron et al., *DistilBERT/Llama*, 2019/2023。

## 一、背景与挑战

把 7B/70B 能力压到 1B/3B 供端侧部署。

## 二、核心原理

- **白盒蒸馏**：用教师 logits 软标签训练学生（需教师权重）。
- **黑盒蒸馏**：用强 API 模型生成数据/答案训练学生（如仿指令数据）。
- **分步蒸馏**：先蒸馏预训练语言建模，再蒸馏指令能力。
DistilBERT 用三重损失（soft+hard+cosine）把 BERT 压 40% 体积保 97% 性能。

## 三、关键要点

- 数据分布决定蒸馏质量。
- 学生容量过小会丢失能力。

## 四、代码实现

```python
student = train(student, teacher_logits=teacher(big_x))
```

## 五、与其他对比

- 量化不改能力仅压体积；蒸馏改架构/容量。

## 六、常见误区

- 蒸馏必保能力——容量不足会掉点。
