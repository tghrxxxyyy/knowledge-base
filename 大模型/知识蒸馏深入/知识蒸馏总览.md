# 知识蒸馏总览

> 对应 d2l-zh 与 Hinton et al., *Distilling the Knowledge in a Neural Network*, 2015；大模型压缩核心手段。

## 一、背景与挑战

大模型强但贵，小模型快但弱。能否把大「教师」的能力迁移给小「学生」？

## 二、核心原理

蒸馏让学生不仅学硬标签，更学教师的**软标签（软化概率）**——其中蕴含类间相似结构（如「2」像「3」多于像「7」）。软标签经高温 softmax 暴露暗知识。

## 三、数学形式

蒸馏损失（温度 T）：
```
L = α·KL( softmax(z_T/T), softmax(z_S/T) ) + (1-α)·CE(y, z_S)
```

## 四、代码实现

```python
soft = F.kl_div(F.log_softmax(s/T), F.softmax(t/T, dim=-1), reduction='batchmean')
```

## 五、关键要点

- 温度 T 越高分布越软、信息越多。
- 学生可远小于教师仍保性能。
- 大模型→小模型部署必经之路。

## 六、与其他对比

| 方法 | 学生学什么 |
|------|------------|
| 微调 | 硬标签 |
| 蒸馏 | 软标签+硬 |

## 七、常见误区

- 蒸馏只是小模型——也可同构提精度。
