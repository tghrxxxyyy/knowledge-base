# 自蒸馏与无教师蒸馏

> 见「知识蒸馏深入/知识蒸馏总览」；Bertinetto et al., *Self-Sup Distillation*, 2019；DINO (Caron et al., 2021)。

## 一、背景与挑战

没有更强教师时，能否自我提升？

## 二、核心原理

- **自蒸馏**：用模型前阶段/自身集成作教师教自己（如早期 epoch 权重），或同一模型不同增强互为师生（DINO 中学生对齐学生，EMA 教师）。
- **无标签自监督蒸馏**：用自监督表征作监督信号。
本质是用「自身或结构的另一视图」当教师。

## 三、关键要点

- 自蒸馏常提升鲁棒性与校准。
- DINO 的 EMA 教师是经典无教师范式。

## 四、代码实现

```python
teacher = ema_update(student)         # 教师=学生滑动平均
loss = kl(student(x), teacher(x).detach())
```

## 五、与其他对比

- 传统需强教师；自蒸馏用自己。

## 六、常见误区

- 自蒸馏无效——实证常提升。
