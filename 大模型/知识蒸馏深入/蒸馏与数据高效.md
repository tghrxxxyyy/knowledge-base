# 蒸馏与数据高效

> 见「知识蒸馏深入/大模型蒸馏实践」与「数据高效学习深入/数据高效学习总览」。

## 一、背景与挑战

标注少时，蒸馏能否替代部分标注？

## 二、核心原理

教师可在**大量无标签**数据上产软标签，学生用这些「免费」软标签训练，等价于半监督（见半监督章）。这也降低对学生端标注的依赖，是数据高效的强手段。

## 三、关键要点

- 教师生成伪标签即用半监督流水线。
- 软标签比硬伪标签信息更丰富。

## 四、代码实现

```python
soft = teacher(unlabeled).softmax(-1)
student.train_on(soft)
```

## 五、与其他对比

- 纯标注贵；蒸馏用教师免费标。

## 六、常见误区

- 蒸馏需大量标注——反用无标数据。
