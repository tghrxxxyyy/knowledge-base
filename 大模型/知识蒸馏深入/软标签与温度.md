# 软标签与温度

> 见「知识蒸馏深入/知识蒸馏总览」；Hinton et al., 2015。

## 一、背景与挑战

硬标签 one-hot 信息量低，学生只知「对/错」。

## 二、核心原理

高温 softmax `p_i = exp(z_i/T) / Σ` 平滑分布，把教师对其他类的相对置信暴露给学生，提供类间结构的「暗知识」。蒸馏时学生/教师都用同 T，推理时 T=1。

## 三、数学形式

见总览温度公式；T 通常 2~8。

## 四、代码实现

```python
T = 4
t_soft = F.softmax(teacher_logits / T, -1)
s_soft = F.log_softmax(student_logits / T, -1)
loss = F.kl_div(s_soft, t_soft, reduction='batchmean') * T*T
```

## 五、关键要点

- KL 项常乘 T² 抵消梯度缩放（原论文做法）。
- 温度过低退化为硬标签。

## 六、与其他对比

- 硬标签无类间信息；软标签有。

## 七、常见误区

- 忘记 T² 缩放——梯度偏小。
