# 指令数据质量控制

> 见「指令数据构建深入/指令数据总览」与「训练数据质量」。

## 一、背景与挑战

海量指令含重复、低质、格式错，需清洗过滤。

## 二、核心原理

多层过滤：去重（语义/精确）、格式校验、长度与语言过滤、质量打分（奖励模型/规则）、难度分层。

## 三、代码实现

```python
def keep(s): return (len(s["output"])>20) and (not is_duplicate(s))
```

## 四、关键要点

- 去重显著提升训练效率。
- 质量模型比规则更稳。

## 五、与其他对比

- 预训练数据量大重在去重/毒性；指令数据重在格式与正确性。

## 六、常见误区

- 过滤越狠越好——可能丢掉有用长尾。

## 七、与开源书对应

- llm-universe: https://github.com/datawhalechina/llm-universe
- Pyserini/数据清洗实践。

## 八、面试题

## 九、演进

规则过滤 → 模型打分 → 课程式分层。

## 十、小结

质量控制决定 SFT 数据「净含量」。
