# Evol-Instruct 复杂化

> 见「指令数据构建深入/指令数据总览」。

## 一、背景与挑战

简单指令练不出强推理。Evol-Instruct 主动把指令「变难」。

## 二、核心原理

深度进化（加约束/推理步）与广度进化（换主题/技能）迭代改写指令，生成更难样本，训练 WizardLM 系列。

## 三、代码实现

```python
harder = llm(f"重写以下指令使其更难并保留原意:\n{q}")
```

## 四、关键要点

- 进化需「保留可答性」，避免无解。
- 淘汰机制去掉退化样本。

## 五、与其他对比

- Self-Instruct 扩量；Evol-Instruct 提质（难度）。

## 六、常见误区

- 越难越好——过难样本模型学不会反伤训练。

## 七、与开源书对应

- WizardLM: https://github.com/nl86927342/WizardLM
- Xu et al., *Evol-Instruct*, 2023.
