# 指令数据总览

> 对应 llm-universe 与 rasbt/LLMs-from-scratch SFT 章；综述见 Wang et al., *Self-Instruct*, 2022。

## 一、背景与挑战

SFT 质量决定模型「听懂指令、按格式输出」的能力。指令数据从哪来、如何保质是关键。

## 二、核心原理

来源三类：**人工标注**（高质量小量）、**蒸馏**（强模型生成）、**自举**（Self-Instruct 从种子任务扩写）。每条含指令、输入（可选）、输出。

## 三、数学形式

SFT 损失：

```
L = - Σ_t log P(token_t | token_{<t}, instruction)
```

## 四、代码实现

```python
sample = {"instruction":"翻译为英文","input":"你好","output":"Hello"}
```

## 五、关键要点

- 多样性 > 数量（早期 FLAN/Alpaca 验证）。
- 格式一致性利于后续解析。

## 六、与其他对比

| 来源 | 质量 | 成本 |
|------|------|------|
| 人工 | 高 | 高 |
| 蒸馏 | 中高 | 中 |
| 自举 | 中 | 低 |

## 七、常见误区

- 数据越多越好——劣质指令引入噪声。

## 八、与开源书对应

## 十、演进

人工 → 自举(Self-Instruct) → 蒸馏(Alpaca) → 多源混合 + 质量过滤。

## 十一、小结

指令数据是「让模型听话」的基石。
