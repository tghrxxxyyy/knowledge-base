# Self-Instruct 自举

> 见「指令数据构建深入/指令数据总览」。

## 一、背景与挑战

人工写海量指令不现实。Self-Instruct 用模型自己扩写任务。

## 二、核心原理

流程：种子任务 → LLM 生成新指令 → 过滤重复/无效 → 生成对应输入输出 → 迭代扩充。引入多样性控制与淘汰机制。

## 三、关键要点

- 用「指令聚类」避免同质化。
- ROOT 任务保证覆盖面。

## 四、代码实现

```python
new_inst = llm(f"基于这些示例生成新任务:\n{seed_samples}")
```

## 五、与其他对比

- 蒸馏依赖强教师；自举更自主。

## 六、常见误区

- 自举会放大模型已有偏见与错误。
