# 多轮对话数据

> 见「指令数据构建深入/指令数据总览」与「从零实现GPT/指令数据集与格式化」。

## 一、背景与挑战

助手需理解上下文连续交互，单轮指令不够。

## 二、核心原理

构造多轮样本：每轮含用户/助手消息，训练时以对话历史为上下文预测助手回复，mask 掉用户 token 损失。

## 三、代码实现

```python
conv = [{"role":"user","content":q1},{"role":"assistant","content":a1},
        {"role":"user","content":q2},{"role":"assistant","content":a2}]
```

## 四、关键要点

- 需避免角色混淆与上下文泄露。
- ShareGPT 格式社区常用。

## 五、与其他对比

- 单轮练指令遵循；多轮练记忆与连贯。

## 六、常见误区

- 多轮 = 拼接单轮——需真实交互轨迹。

## 七、与开源书对应

- ShareGPT / Vicuna 数据: https://github.com/lm-sys/FastChat
- llm-universe: https://github.com/datawhalechina/llm-universe

## 九、演进
