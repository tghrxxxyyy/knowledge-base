# 基于能力的路由

> 对应 Cai et al., *RouterBench: A Benchmark for Multi-LLM Routing System*, 2024（arXiv:2403.12031）；与 多模型路由深入 衔接。

## 一、背景与挑战

不同模型在不同能力维度（推理/代码/多语）强弱不同，需据能力路由。

## 二、核心原理

用模型能力画像（在基准上的表现）建立路由规则或回归器，按请求类型/难度选择最优模型。

## 三、数学形式

选模型 $m^*=\arg\max_m \text{capability}_m(t)$ 约束 $\text{cost}(m)\le B$，其中 $t$ 为任务类型。

## 四、代码实现

```python
cap = capability_matrix[task_type]      # 各模型在该任务得分
m = min(cap[cap >= q_thr], key=cost)    # 达质量门槛最便宜
```

## 五、与其他对比

- 与 成本质量权衡路由（多目标）互补。
- 与 路由器训练（学习画像）相关。

## 六、常见误区

- 能力画像静态过时，模型更新后失效。
- 仅看平均分忽略长尾能力缺口。

## 八、面试题

- 如何按能力路由？答：建立模型能力画像，按任务类型/难度选择达标且最省成本的模型。

## 九、演进

人工规则 → 能力矩阵 → 在线更新画像。

## 十、小结

能力路由把任务与模型专长匹配，提升整体质量与成本比。
