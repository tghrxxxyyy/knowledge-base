# 路由评估与回退

> 对应 Cai et al., *RouterBench*, 2024；与 多模型路由深入 / 服务框架深入 衔接。

## 一、背景与挑战

路由策略需量化收益，且失败要能安全回退到强模型。

## 二、核心原理

在基准上对比“全用强模型”与“路由”的成本/质量；设回退：低置信度即升级，保证质量下限。

## 三、数学形式

节省 $S=1-\frac{\text{cost}_{route}}{\text{cost}_{all\_strong}}$；质量维持 $\Delta Q=Q_{route}-Q_{strong}\ge -\epsilon$。

## 四、代码实现

```python
if router.conf(req) < fallback_thr:
    return strong_model(req)
```

## 五、与其他对比

- 与 成本质量权衡路由（回退即级联）衔接。
- 与 网关限流深入（降级策略）呼应。

## 六、常见误区

- 无回退致差请求直接出错。
- 评估只看均值忽略质量塌方样本。

## 八、面试题

- 路由如何保底？答：设回退阈值，低置信度请求升级到强模型，保证质量下限。

## 九、演进

无评估 → 离线基准 → 在线回退+监控。

## 十、小结

路由需以评估验证收益，并以回退守住质量底线。
