# 路由器训练

> 对应 Hu et al., *FrugalGPT: How to Use LLMs While Reducing Cost and Improving Performance*, 2023（arXiv:2305.05176）；与 多模型路由深入 衔接。

## 一、背景与挑战

手工规则难覆盖复杂请求分布，需数据驱动的路由器。

## 二、核心原理

用标注（哪模型更好/成本）训练轻量分类器或排序模型作路由；或 LLM 作评分器决定升级。

## 三、数学形式

路由损失 $\mathcal L=\mathbb E[\mathbb I(m(x)\ne m^*)]$ 或 $\mathcal L=\text{cost}(m(x))+\lambda\ell(m(x),y)$。

## 四、代码实现

```python
router = train(classifier_on_features(x), target=best_model_label(x))
pred = router.predict(req_features)
```

## 五、与其他对比

- 与 基于能力的路由（画像即训练目标）衔接。
- 与 优先级调度深入（路由后可优先）协同。

## 六、常见误区

- 路由标签噪声使分类器偏差。
- 路由器过重抵消节省。

## 八、面试题

- 路由器怎么训？答：用“最佳模型/成本”标签训轻量分类器，或训排序器决定模型选择。

## 九、演进

规则 → 监督分类器 → 强化/在线学习路由。

## 十、小结

数据驱动的路由器能适配真实分布，但须轻量且标签可靠。
