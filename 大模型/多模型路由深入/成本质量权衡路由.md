# 成本质量权衡路由

> 对应 Ong et al., *Mélange: Cost Efficient LLM Serving by Exploiting LLM Taxonomy*, 2024（arXiv:2407.00622）；与 多模型路由深入 衔接。

## 一、背景与挑战

强模型贵、弱模型廉价但质量低，需在预算内取得最优质量。

## 二、核心原理

以探索（先小模型，置信度不足升级）或优化框架在预算约束下选模型组合，显式权衡成本与质量。

## 三、数学形式

$\max_{a} Q(a)$ s.t. $C(a)\le B$，用拉格朗日 $\max_a Q(a)-\lambda C(a)$ 求路由策略。

for req in stream:

## 五、与其他对比

- 与 基于能力的路由（质量维度）互补。
- 与 网关限流深入（预算/配额）呼应。

## 六、常见误区

- 预算设过紧牺牲必要质量。
- 级联升级阈值未校准致频繁调用强模型。

## 八、面试题
