# 多语种与低资源语音

> 见「语音大模型深入/语音大模型总览」与「多语言与跨语言深入」；多语种 ASR 挑战。

## 一、背景与挑战

数千语言，多数低资源，模型覆盖不均。

## 二、核心原理

多语种共享编码器 + 语言适配；用高资源语言辅助低资源（跨语言迁移）。Whisper 用多语种弱监督统一建模。低资源可自监督预训练（wav2vec2）再少样本微调。

## 三、关键要点

- 高资源带低资源提升有限（语种差异）。
- 自监督大幅降标注需求。

## 四、代码实现

```python
model = wav2vec2_pretrain(); finetune(model, low_resource)
```

## 五、与其他对比

- 单语简单；多语需适配。

## 六、常见误区

- 多语一模型通吃——低资源仍弱。
