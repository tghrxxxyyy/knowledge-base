# 语音大模型总览

> 对应 llm-course；语音与语言模型融合综述；Radford et al., *Whisper*, 2022。

## 一、背景与挑战

语音是重要交互模态，传统 ASR/TTS 与 LLM 割裂。

## 二、核心原理

三类融合：1) **音频→文本→LLM**（ASR 接 LLM，级联）；2) **语音作为 token**（如 AudioPaLM 把语音离散化进 LLM）；3) **端到端语音对话**（如 GPT-4o 原生多模态）。趋势是统一语音-文本空间。

## 三、关键要点

- 级联简单但有误差传播。
- 端到端更自然但有数据/延迟挑战。

## 四、代码实现

```python
text = whisper(audio); ans = llm(text); speech = tts(ans)
```

## 五、与其他对比

| 方式 | 特点 |
|------|------|
| 级联 | 易部署 |
| 端到端 | 自然 |

## 六、常见误区

- 语音=先转文本——丢韵律/情感。
