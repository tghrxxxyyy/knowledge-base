# 可信 AI 维度

> 对应 EU AI Act 与 NIST AI RMF 1.0 可信特征（公平、可靠、隐私、安全、透明、责任）。

## 一、背景与挑战

当大模型进入医疗、金融、司法等关键决策，仅看能力（benchmark 分数）远远不够。一个准确但歧视、泄露隐私、不可解释的模型仍不可信，无法落地。可信 AI 要求从多个维度系统建设，使模型在真实社会约束下既有效又可控。不同框架的维度表述略有差异，但共性包含：公平、可靠/稳健、隐私、安全、透明/可解释、责任。实际落地时，维度常被「默认忽略」：团队只优化能力指标，等到监管或事故才补维度，成本极高。因此维度建设应前置于产品设计，而非事后补丁，并以评分卡形式纳入上线准入。

## 二、核心原理

可信 AI 是多维度的体系工程，各维度相互独立又彼此权衡：

- 公平：无歧视、群体均衡（见「可信AI与治理深入/公平与偏见」）。
- 可靠：在分布偏移与对抗下保持稳定性能。
- 隐私：训练数据与用户对话不被泄露（见隐私相关章节）。
- 安全：抗越狱、抗提示注入（见安全红队章节）。
- 透明：可解释、可审计（见「可信AI与治理深入/可解释性治理」）。
- 责任：出错可定责（见「可信AI与治理深入/责任与问责」）。

维度间存在张力（如安全 vs 有用、隐私 vs 个性），需用治理框架（见「可信AI与治理深入/AI治理框架」）做制度化平衡。建议为每个上线模型维护一张「维度评分卡」，随持续监控更新，使抽象可信落到实处、可比较、可审计。

## 三、形式化与数学基础

把可信度建模为各维度得分的向量与加权聚合：

$$
\mathbf{s}=(s_{\text{fair}},s_{\text{rel}},s_{\text{priv}},s_{\text{safe}},s_{\text{trans}},s_{\text{resp}})\in[0,1]^6
$$

综合可信度：

$$
\mathrm{Trust}=\sum_{d} w_d\, s_d,\quad \sum_d w_d=1
$$

由于维度间约束冲突，可行域受 Pareto 前沿限制：

$$
\mathcal{F}=\{ \mathbf{s}: \nexists\,\mathbf{s}'\text{ 使所有维度不降且至少一项升} \}
$$

这意味着不存在「全 1」的可信向量，任何上线都是权重下的权衡结果，权重应按场景设定。

## 四、代码实现

```python
def assess_trust(model, dims, weights):
    # dims: 各维度评测函数; weights: 维度权重, 和为 1
    report = {d: assess(model, d) for d in dims}
    score = sum(weights[d] * report[d] for d in dims)
    return {"per_dim": report, "trust": score}

def scorecard(model):
    # 维度评分卡, 供产品/合规共读, 纳为上线准入
    return assess_trust(model,
                        ["fair", "rel", "priv", "safe", "trans", "resp"],
                        {"fair": 0.2, "rel": 0.2, "priv": 0.15,
                         "safe": 0.2, "trans": 0.15, "resp": 0.1})

def gate(scorecard, min_trust=0.7):
    # 评分卡门槛: 未达可信基线则拦截
    return scorecard["trust"] >= min_trust
```

## 五、与其他技术对比

| 维度 | 性能工程 | 可信工程 |
| --- | --- | --- |
| 关注 | 平均分 | 风险/最坏情况 |
| 指标 | acc/loss | 公平/安全/隐私 |
| 优化 | 单目标 | 多目标权衡 |
| 验收 | 分数 | 阈值+审计 |

## 六、常见误区

- 能力强即可信：高分模型仍可能歧视或泄密。
- 追求单维度满分：忽视维度间权衡，反而损害整体可用性。
- 缺少制度化：维度评估停留于点状检查，未形成体系。
- 权重拍脑袋：不按场景定权，导致错配管控重点，如客服场景重安全轻隐私。

## 七、与开源书·权威来源对应

## 九、演进与趋势

从「单点检查」到「体系化多维评估」，再到「实时多维监控」。趋势是把各维度指标纳入持续治理闭环（见「可信AI与治理深入/持续监控治理」），并由监管把可信维度写入强制要求。评分卡正成为模型上线的硬性准入门槛，使多目标权衡从口头讨论变为可审计决策。

## 十、小结

可信是落地的综合要求：公平、可靠、隐私、安全、透明、责任六个维度相互权衡、需制度化平衡，才能支撑大模型在关键场景的稳妥应用。维度评分卡是把抽象可信落到工程准入的有效载体，而 Pareto 约束提醒我们任何上线都是场景化权衡。
