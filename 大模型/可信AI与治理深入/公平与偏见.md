# 公平与偏见

> 对应 EU AI Act 高风险公平义务 与 Barocas 2019《Fairness and Machine Learning》。

## 一、背景与挑战

大模型在训练语料中继承了社会历史偏见，可能在招聘、信贷、司法等场景对特定群体（性别、种族、年龄、地域）产生系统性不利输出，既违背伦理也触碰监管红线（EU AI Act 对高风险系统规定公平性义务）。偏见常常隐式存在：模型未必输出显式偏见词，却通过关联、拒答率、推荐排序等微妙方式放大不公。因此公平不是「无脏话」那么简单，而需从指标、数据、训练、输出多环节度量与缓解。值得注意的是，公平问题在「代理变量」上尤其隐蔽：例如用邮编代理种族、用用词风格代理性别，模型即使看不到敏感属性也能通过相关特征复现偏见。

## 二、核心原理

公平治理分三步：（1）度量——用群体统计指标量化差异；（2）定位——区分偏见来自数据分布、标注偏好还是模型归纳；（3）缓解——在预训练（均衡语料、去偏 embeddings）、微调（公平约束损失）、推理（输出审查、重排序）三个阶段介入。需注意公平与效用（accuracy）常存在权衡，过度去偏可能损害整体能力，须按场景设定可接受边界。落地时建议先建立「敏感属性清单」与「代理变量清单」，再针对性选指标与缓解手段，并在评测集上量化差距而非凭感觉。

## 三、形式化与数学基础

常用群体公平定义：

- 人口均等差：$\Delta=|P(\hat y=1\mid G_1)-P(\hat y=1\mid G_2)|$
- 机会均等：$\Delta_{\text{TPR}}=|\mathrm{TPR}_{G_1}-\mathrm{TPR}_{G_2}|$
- 均等赔率：同时约束 TPR 与 FPR 差距

模型输出的群体分布偏移可写为：

$$
\mathrm{Disparity}=\max_{g,g'}\big|P_\theta(y\mid G=g)-P_\theta(y\mid G=g')\big|
$$

缓解目标常设为在满足效用阈值下最小化 $\mathrm{Disparity}$，即带约束优化：

$$
\min_\theta\, \mathrm{Disparity}(\theta)\quad \text{s.t.}\quad \mathrm{Acc}(\theta)\ge a_0
$$

## 四、代码实现

```python
import numpy as np

def group_rates(preds, groups, labels):
    # preds/labels: 数组; groups: 各样本群体标记
    out = {}
    for g in np.unique(groups):
        mask = groups == g
        out[g] = {
            "positive_rate": preds[mask].mean(),
            "tpr": ((preds[mask] == 1) & (labels[mask] == 1)).sum()
                    / max(1, (labels[mask] == 1).sum()),
        }
    return out

def max_disparity(rates):
    pr = [v["positive_rate"] for v in rates.values()]
    return max(pr) - min(pr)

def proxy_scan(features, sensitive):
    # 检测与敏感属性高度相关的代理变量(示意)
    return {f: corr(features[f], sensitive) for f in features}
```

## 五、与其他技术对比

| 维度 | 能力评测 | 公平评测 |
| --- | --- | --- |
| 关注 | 均值正确率 | 群体差异 |
| 指标 | acc/f1 | Δ/TPR/FPR |
| 失败形态 | 整体差 | 特定群体差 |
| 缓解 | 调参 | 去偏+约束 |
| 监管 | 弱 | 强（EU AI Act） |

## 六、常见误区

- 认为「无显式偏见词即公平」：隐式关联偏见更常见且更难发现。
- 用单一指标代表公平：人口均等与机会均等可能冲突，需按场景选择。
- 去偏不顾效用：强约束下整体能力下滑，需权衡报告。
- 忽略代理变量：删掉敏感属性列不代表模型学不到它。

## 八、面试题

- 如何度量并缓解大模型输出偏见？人口均等与机会均等有何冲突？
- 去偏训练可能损害整体效用，如何设定可接受边界？
- 隐式偏见如何检测？仅看生成文本是否足够？
- 删除敏感属性列能否消除偏见？为什么？

## 九、演进与趋势

从「检测偏见」到「训练期去偏」，再到「红队+评测集+输出约束」的多层防护。方向上包括：细粒度群体评测集、因果公平、以及把公平指标纳入持续监控（见「可信AI与治理深入/持续监控治理」）。监管正把公平性从软倡议变为高风险系统的硬义务。

## 十、小结

公平是可信 AI 的伦理基石：通过可量化指标度量、在数据与训练阶段缓解、并对效用权衡做透明报告，才能把「无偏」从口号落到可验证结果。代理变量与隐式偏见是工程落地中最易遗漏的盲区。
