# 公平与偏见

> 见「可信AI与治理深入/可信AI维度」与「模型评测指标深入」。

## 一、背景与挑战

模型可能放大数据偏见，造成不公。

## 二、核心原理

检测不同群体表现/输出差异，用均衡数据、去偏训练、输出审查降低偏见，评估公平指标。

## 三、数学形式

群体均等差：

```
Δ = |P(fair|G1) - P(fair|G2)|
```

## 四、代码实现

```python
for g in groups: fair[g] = evaluate(model, g)
```

## 五、关键要点

- 偏见常隐式。
- 去偏需防损效。

## 六、与其他对比

- 能力评测看均；公平看差。

## 七、常见误区

- 无显式偏见词即公平——隐式偏见在。
