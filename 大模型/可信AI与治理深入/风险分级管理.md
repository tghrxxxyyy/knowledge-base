# 风险分级管理

> 见「可信AI与治理深入/AI治理框架」与「安全红队方法论/红队度量与报告」。

## 一、背景与挑战

不同应用风险不同，需分级管控。

## 二、核心原理

按影响（人身/财务/社会）分高/中/低危，对应不同审查、测试、监控强度，资源合理分配。

## 三、关键要点

- 高危需红队+人工。
- 分级动态。

## 四、代码实现

```python
level = risk_classify(use_case); controls = policy[level]
```

## 五、与其他对比

- 一刀切低效；分级精准。

## 六、常见误区

- 都当高危——资源浪费。
