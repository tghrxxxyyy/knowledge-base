# 激活监控与欺骗检测

> 对应 Azaria & Mitchell, 2023；Li et al., *Inference-Time Intervention (ITI)*, 2023；Burns et al., 2022.

## 一、背景与挑战

模型可能“内心知道错误却输出错误”（谄媚/欺骗）；仅靠输出难发现，需监控其内隐真假/意图激活。

## 二、核心原理

训练真假/意图方向探针，推理时监控该方向激活；异常高/低触发告警，或用 ITI 在推理时沿该方向干预提升诚实。

## 三、数学形式

诚实方向 $v=\bar h_{honest}-\bar h_{deceptive}$；ITI 干预 $h'=h+\alpha v$。

## 四、代码实现

```python
h = cache[layer]
if (h @ truth_dir).item() < low:
    alert("possible deception")
h_intervened = h + alpha * truth_dir
```

## 五、与其他对比

- 与 线性探针作为对齐探针（同一真假方向）衔接。
- 与 稀疏自编码器深入（SAE 特征监控）互补。

## 六、常见误区

- 方向在不同提示分布下漂移致误报。
- 过度干预损害流畅与能力。

## 八、面试题

- 激活监控如何发现欺骗？答：监控内隐真假方向，当输出与内隐判断背离时疑似欺骗。

## 九、演进

离线探针 → 在线监控 → 推理时干预(ITI)。

## 十、小结

激活监控把“读心”用于欺骗检测，是可信部署的前沿防线。
