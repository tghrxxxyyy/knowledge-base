# 激活监控部署实践

> 对应 LLM 安全部署经验；Anthropic 监控研究（2024）.

## 一、背景与挑战

把研究成果落地为可靠产品监控，面临性能、误报、隐私与合规问题。

## 二、核心原理

建立“探针/SAE 特征库 + 阈值管理 + 告警分级 + 人工复核”闭环；对高敏概念（自残、违法）优先部署。

## 三、数学形式

风险分 $R=\sum_c w_c\,\sigma_c(h)$；分级 $level=\text{bucket}(R)$；决策 $act=policy(level)$。

## 四、代码实现

```python
scores = {c: probes[c](h) for c in critical_concepts}
risk = sum(w[c]*scores[c] for c in scores)
action = 'block' if risk > 0.9 else 'review' if risk>0.5 else 'pass'
```

## 五、与其他对比

- 与 安全与对齐深入（整体对齐策略）衔接。
- 与 稀疏自编码器深入（SAE 特征为监控单元）互补。

## 六、常见误区

- 阈值一次定死不随数据更新。
- 告警无分级致告警疲劳。
