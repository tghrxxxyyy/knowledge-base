# 流式激活监控

> 对应 Representation Engineering（Zou et al., 2023）；LLM 生产监控实践.

## 一、背景与挑战

在线服务需低开销、实时地监控海量请求激活，不能每次全量分析。

## 二、核心原理

只对关键层/关键探针做轻量前向钩子，维护滑动窗口统计（均值、分位数），阈值自适应；异常聚合上报。

## 三、数学形式

滑动统计量 $\hat\mu_t=(1-\gamma)\hat\mu_{t-1}+\gamma h_t$；告警当 $|h_t-\hat\mu_t|>k\sigma_t$。

## 四、代码实现

```python
mu = ema.update(h)
sigma = ema_std.update(h)
if abs(h - mu) > 3*sigma: queue_alert()
```

## 五、与其他对比

- 与 激活异常检测（离线/批式）对应在线流式版。
- 与 推理调度深入（钩子开销）相关。

## 六、常见误区

- 钩子未异步致延迟上升。
- 滑动窗口过长致无法捕捉突变。

## 八、面试题

- 流式监控如何控开销？答：仅钩关键层/探针、EMA 增量统计、异步告警，避免阻塞主推理。

## 九、演进

批式分析 → 流式 EMA → 自适应阈值。

## 十、小结

流式激活监控在开销与覆盖间平衡，是生产级安全监控的关键。
