# 激活监控总览

> 对应 Kim et al., *Interpretability Beyond Feature Attribution*, 2018（TCAV）；Zou et al., *Representation Engineering*, 2023.

## 一、背景与挑战

模型部署后其行为需被持续观测；监控内部激活（而非仅输出）可更早捕获异常、欺骗与分布偏移。

## 二、核心原理

在推理时提取关键层激活，用探针/SAE 特征/方向向量检测关注概念是否出现或异常，触发告警或干预。

## 三、数学形式

监控信号 $s(x)=g(h_\theta(x))$；$g$ 为预训练探针或方向投影；告警 $\mathbb I(s>\tau)$。

## 四、代码实现

```python
with torch.no_grad():
    h = model.hidden(layer, input_ids)
    score = probe(h).item()
if score > threshold: alert("target concept active")
```

## 五、与其他对比

- 与 线性探针深入（监控所用探针即线性读出）衔接。
- 与 稀疏自编码器深入（以 SAE 特征为监控单元）互补。

## 六、常见误区

- 仅监控输出文本漏掉隐蔽激活。
- 阈值静态致分布偏移后大量误报。

## 八、面试题

- 为何监控激活优于仅监控输出？答：危险/欺骗概念可能在激活层出现而输出被对齐掩盖，激活更早发现。

## 九、演进

输出过滤 → 激活探针 → SAE 特征告警。

## 十、小结

激活监控把可解释性用于在线安全，是部署阶段的重要防线。
