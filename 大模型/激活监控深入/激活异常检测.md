# 激活异常检测

> 对应 Ren et al., *Out-of-Distribution Detection*, 2019；Hendrycks & Gimpel, *Baseline for OOD Detection*, 2017.

## 一、背景与挑战

输入分布偏移或对抗样本会改变激活统计；需自动检测异常激活以防不可预期行为。

## 二、核心原理

在正常激活上拟合分布（均值/协方差或简单阈值），推理时计算激活离群度（如 Mahalanobis 距离）判异常。

## 三、数学形式

$d(x)=(h-\mu)^\top\Sigma^{-1}(h-\mu)$；若 $d>\tau$ 判 OOD；或马氏距离近似。

## 四、代码实现

```python
mu, cov = train_stats(H_normal)
d = ((h-mu) @ inv(cov) * (h-mu)).sum(-1)
is_ood = d > tau
```

## 五、与其他对比

- 与 数据缩放定律深入（训练数据分布）相关（偏移来自数据）。
- 与 激活监控深入 总览同框架。

## 六、常见误区

- 协方差估计在高维不准（需正则/降维）。
- 仅用单维阈值漏掉联合异常。

## 八、面试题

- 为何用马氏距离而非欧氏？答：马氏距离按特征协方差归一，能捕获相关维度上的联合离群。

## 九、演进

单维阈值 → 马氏距离 → 流形/自编码重建误差。

## 十、小结

激活异常检测是抵御分布偏移与对抗输入的在线哨兵。
