# 检索阶段失效

> 对应检索质量与 RAG 答案关系研究；与 混合检索深入 / 检索重排序深入 衔接。

## 一、背景与挑战

检索返回无关/缺关键文档，后续再强也难补；常见因切分、嵌入、查询表述不匹配。

## 二、核心原理

失效源：块粒度不当、嵌入语义偏差、查询口语化无改写、索引覆盖不足、top-k 截断过早丢关键。

## 三、数学形式

检索精度 $P = |D_{rel}\cap D_{ret}|/|D_{ret}|$；若关键文档未入 $D_{ret}$，下游上限被锁。

## 四、代码实现

```python
hits = retrieve(q, k=5)
if not any(relevant(h) for h in hits):
    hits = hybrid_retrieve(rewrite(q), k=10)   # 改写+混合补救
```

## 五、与其他对比

- 与 查询改写与扩展深入（改写补救）相关。
- 与 长文档切分深入（块质量）相关。

## 六、常见误区

- 默认 top-k 足够，忽视关键文档排第 6。
- 检索评估只看召回不看下游。

## 八、面试题

- 检索召回高但答案错，可能？答：关键文档被截断或噪声淹没，需调 k/重排/改写。

## 九、演进

单向量 → 混合+改写+重排 降检索失效。

## 十、小结

检索失效是 RAG 根因之一，需多手段提升召回与精度。
