# 生成阶段失效（不忠实）

> 对应 hallucination / faithfulness 研究（Maynez et al., 2020；RAG 忠实性）。

## 一、背景与挑战

即使上下文含答案，模型仍可能生成未见于上下文的内容（幻觉）或忽略证据。

## 二、核心原理

失效因：参数记忆压过上下文、指令未强约束引用、上下文与先验冲突；需 faithfulness 约束与引用机制。

## 三、数学形式

忠实度 $F = \Pr[\text{每陈述}\in C]$；生成分布 $p(y)\propto p_{param}(y)\cdot p_{ctx}(y)$ 偏 param 则失真。

## 四、代码实现

```python
answer = llm(f"仅依据以下上下文回答并标注引用:\n{ctx}\n问题:{q}")
# 后校验每句是否可溯到 ctx
```

## 五、与其他对比

- 与 检索增强失效分析总览 的生成段对应。
- 与 模型水印深入 无直接关。

## 六、常见误区

- 信任流畅文本而忽视无据陈述。
- 不用引用机制难定位幻觉。

## 八、面试题

- 为何有上下文仍幻觉？答：参数先验压过上下文，或指令未约束引用，致未据证据生成。

## 九、演进

无约束 → 引用/忠实提示 → 生成后校验。

## 十、小结

生成不忠实是 RAG 末端风险，靠约束与引用机制缓解。
