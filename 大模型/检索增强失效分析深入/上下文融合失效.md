# 上下文融合失效（Lost in the Middle）

> 对应 Liu et al., *Lost in the Middle: LLMs and the Middle of Long Contexts*, 2023。

## 一、背景与挑战

即使检索正确，模型也未必“用上”上下文：关键信息放中部常被忽略，放首尾更易被用。

## 二、核心原理

LLM 对长上下文存在位置偏置，中间信息利用率低；多文档拥挤时注意力被稀释，致答案脱离证据。

## 三、数学形式

使用率 $U(pos) = \Pr[\text{答案引用该位置}]$，常呈 U 形：$U(head),U(tail) > U(mid)$。

## 四、代码实现

```python
ctx = reorder(ctx, put_key_to="edges")   # 关键文档置首尾
answer = llm(q, ctx)
```

## 五、与其他对比

- 与 上下文压缩深入（减噪提利用率）相关。
- 与 检索重排序深入（排序影响位置）相关。

## 六、常见误区

- 以为塞越多上下文越好（实际稀释）。
- 忽视位置偏置直接堆文档。

## 八、面试题

- 为何信息会被“中间丢失”？答：注意力位置偏置，中部信息被首尾与噪声稀释，利用率低。

## 九、演进

无处理 → 重排置关键于首尾 → 压缩减干扰。

## 十、小结

融合失效源于位置偏置与注意力稀释，需重排与压缩协同。
