# 检索增强失效评估与诊断

> 对应 RAG 评估体系（faithfulness/answer relevance）；与 模型评测指标深入 衔接。

## 一、背景与挑战

需量化各段失败率，否则优化无方向；端到端指标掩盖根因。

## 二、核心原理

分三段指标：检索召回/精度、上下文利用率（探针）、忠实度（引用对齐）；用归因框架定位主要失效段。

## 三、数学形式

综合得分 $S = w_r R + w_u U + w_f F$；段贡献 $\Delta S_i$ 指示优先级。

## 四、代码实现

```python
report = {
  "recall": recall_at_k(q, docs),
  "usage": context_utilization(answer, ctx),
  "faith": faithfulness(answer, ctx),
}
```

## 五、与其他对比

- 与 检索重排序深入（评估侧）共享指标。
- 与 模型评测指标深入 共用方法论。

## 六、常见误区

- 只看答案准确率不分段。
- 探针本身不准致误判。

## 八、面试题

- 如何诊断 RAG 失败段？答：分段测检索/使用/忠实，定位最大缺口优先修。

## 九、演进

端到端 → 分段指标 → 自动归因。

## 十、小结

诊断以分段指标量化失效，指导精准优化。
