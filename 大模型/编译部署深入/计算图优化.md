# 计算图优化

> 对应 Abadi et al., *TensorFlow: A System for Large-Scale Machine Learning*, OSDI 2016（图优化）；与 编译部署深入 衔接。

## 一、背景与挑战

原始训练图含大量冗余（常量、恒等、重复子图），直接执行低效。

## 二、核心原理

Pass 集合：constant folding、dead code elimination、算子融合、布局转换（NHWC↔NCHW）、公共子表达式消除。

## 三、数学形式

等价变换 $G\to G'$ 满足 $\forall x,\, \text{exec}(G,x)=\text{exec}(G',x)$ 且 $\text{cost}(G')<\text{cost}(G)$。

## 四、代码实现

```python
with tf.graph_util优化_pass():
    graph = constant_fold(graph)
    graph = dead_code_elimination(graph)
```

## 五、与其他对比

- 与 算子融合深入（融合是其中一类 pass）包含关系。
- 与 模型导出ONNX深入（ONNX 图也做同款优化）相关。

## 六、常见误区

- 过度常量折叠破坏动态控制流。
- 布局转换插入大量 transpose 反而变慢。

## 七、与开源书对应

- rasbt/LLMs-from-scratch：https://github.com/rasbt/LLMs-from-scratch

## 八、面试题

- 常量折叠作用？答：把可静态求值的子图提前算成常量，删减运行期计算。

## 九、演进

手写 pass → 声明式 pass 管理 → MLIR 通用 pass 框架。

## 十、小结

计算图优化以等价变换去冗余，是编译部署的标准前处理。
