# 端侧与边缘部署

> 对应 Google, *TensorFlow Lite*, 2017；与 编译部署深入 / 模型导出ONNX深入 衔接。

## 一、背景与挑战

手机/嵌入式算力内存受限、无独立 GPU，需极致压缩与专用运行时。

## 二、核心原理

经量化+剪枝+算子融合生成轻量图，由 TFLite/NNAPI/ONNX Runtime Mobile 在端侧执行，必要时委托 NPU。

## 三、数学形式

端侧约束 $\text{FLOPs}(m)\le C_{flop},\ \text{size}(m)\le C_{mem}$；在此下最小化精度损失。

## 四、代码实现

```python
converter = tf.lite.TFLiteConverter.from_saved_model(m)
converter.optimizations = [tf.lite.Optimize.DEFAULT]
tflite = converter.convert()
```

## 五、与其他对比

- 与 量化编译流水线（量化是核心手段）共享。
- 与 模型导出ONNX深入（可转 TFLite）衔接。

## 六、常见误区

- 端侧 NPU 算子支持不全，回退 CPU 反而慢。
- 忽略电池/发热对持续算力限制。

## 七、与开源书对应

- rasbt/LLMs-from-scratch：https://github.com/rasbt/LLMs-from-scratch
- mlabonne/llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- 端侧部署难点？答：算力/内存严苛、NPU 算子不全、需量化与压缩同时满足精度。

## 九、演进

云端 → 轻量运行时（TFLite） → 异构委托（NPU/DSP）。

## 十、小结

端侧部署以压缩+专用运行时在受限硬件上落地模型。
