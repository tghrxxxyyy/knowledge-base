# 算子库与代码生成

> 对应 Vasilache et al., *Tensor Comprehensions*, 2018（半自动代码生成）；与 内核调优深入 衔接。

## 一、背景与挑战

手写高性能算子库（cuDNN/CUTLASS/MKL）覆盖有限，新算子需快速生成高效实现。

## 二、核心原理

用 polyhedral 或模板（CUTLASS）把高层算子描述映射为分块/向量化/流水线的底层代码，无需手写 CUDA。

## 三、数学形式

循环嵌套经仿射变换 $T: \vec i\mapsto A\vec i+\vec b$，优化数据局部性与并行度。

## 四、代码实现

```cpp
// CUTLASS 2.x GEMM 模板实例化
using Gemm = cutlass::gemm::device::Gemm<f16,f16,f16,f32>;
```

## 五、与其他对比

- 与 内核调优深入（调优生成后的代码）接力。
- 与 编译部署深入（作为后端）协同。

## 六、常见误区

- 模板默认配置未必最优，需按 shape 特化。
- 代码生成结果仍需 profiling 验证。

## 七、与开源书对应

- rasbt/LLMs-from-scratch：https://github.com/rasbt/LLMs-from-scratch
- mlabonne/llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- 为何需要代码生成？答：手写算子库覆盖有限且难维护，生成可快速产出特化高效实现。

## 九、演进

手写库 → 模板库 → polyhedral/学习式生成。

## 十、小结

算子库与代码生成把高性能实现从手工劳动转为可扩展的工程。
