# ViT位置编码与训练

> 对应 ViT 与 DeiT 训练策略；旋转位置编码深入 提供数学细节。

## 一、背景与挑战

Transformer 本身位置无关，需注入空间位置；且 ViT 训练稳定性依赖强正则。

## 二、核心原理

ViT 用可学习 1-D 位置嵌入（按 patch 序列索引）；DeiT 用蒸馏 token + 强增强（RandAugment、Mixup、EMA）提升小数据表现。

## 三、数学形式

含位置输入 $z_0^i = x_p^i E + E_{pos}^i$；训练损失为交叉熵，配标签平滑与随机深度。

## 四、代码实现

```python
pos = nn.Parameter(torch.zeros(1, N+1, D))
z = tokens + pos
```

## 五、与其他对比

- 可学习 1-D 位置对 2-D 结构建模弱于显式 2-D 编码；但足够。
- 与 旋转位置编码深入 的 RoPE（相对、可外推）形成对照。

## 六、常见误区

- 预训练分辨率与微调分辨率不一致需重插值位置。
- 忽视强增强导致小数据训练崩。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 分辨率变化如何处理位置编码？答：对位置嵌入做双线性插值或重学。

## 九、演进

可学习位置 → 2-D 感知位置 → 层次相对位置（Swin）。

## 十、小结

位置编码与强正则共同决定 ViT 能否在数据有限时收敛。
