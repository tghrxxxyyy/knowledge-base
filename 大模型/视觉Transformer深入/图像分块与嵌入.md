# 图像分块与嵌入

> 对应 ViT 分块投影；与 卷积神经网络深入 的局部性对比。

## 一、背景与挑战

原始像素序列过长（$HWC$），需压缩为粗粒度 token 以控复杂度。

## 二、核心原理

卷积 stem（$16\times16$ stride 16）或等价线性投影把每个 patch 映射到 $D$ 维；也可用 $2\times2$ 卷积做层次下采样（如 Swin）。

## 三、数学形式

分块数 $N=HW/s^2$（$s$ 为 patch 边长）；投影参数 $=P^2C\times D$（$P$ 为 patch 像素边长）。

## 四、代码实现

```python
proj = nn.Conv2d(C, D, kernel_size=s, stride=s)   # 等价于分块线性
tokens = proj(img).flatten(2).transpose(1, 2)
```

## 五、与其他对比

- 大 patch 省计算但丢细节；小 patch 精但 $N$ 大。
- 卷积 stem 引入局部性，训练更稳。

## 六、常见误区

- 忽视 patch 大小对分辨率外推的影响。
- 把 [cls] 当作唯一聚合，实际也可用平均池化。

## 七、与开源书对应

- d2l-zh 卷积章：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 为什么用 [cls] token 分类？答：提供全局聚合位置，避免对 patch 平均的强假设。

## 九、演进

固定大 patch → 卷积 stem → 层次多尺度 patch。

## 十、小结

分块嵌入是 ViT 把图像转为序列的关键一步，平衡分辨率与计算。
