# 视觉Transformer在大模型中的应用

> 对应多模态与视觉大模型；视觉语言模型深入 衔接。

## 一、背景与挑战

多模态大模型需把图像编码为 token 与大语言模型对齐。

## 二、核心原理

视觉编码器（ViT/Swin）输出图像 token，经投影/交叉注意力接入 LLM；如 CLIP 对比预训练、LLaVA 投影对齐。

## 三、数学形式

对齐损失（CLIP）：$\mathcal L = -\log \frac{\exp(\text{sim}(I,T)/\tau)}{\sum_j \exp(\text{sim}(I,T_j)/\tau)}$。

## 四、代码实现

```python
img_tokens = vision_encoder(img)
emb = projector(img_tokens)
text = llm(emb, prompt_tokens)   # 多模态融合
```

## 五、与其他对比

- 视觉编码器可冻结（参数高效），仅训投影（参数高效微调深入）。
- 与 多模态深入 / 视觉语言模型深入 衔接。

## 六、常见误区

- 忽视视觉编码器分辨率与 LLM 上下文长度匹配。
- 对齐投影训不好则多模态退化。

## 七、与开源书对应

- llm-course 多模态：https://github.com/mlabonne/llm-course

## 八、面试题

- 图像 token 如何接入 LLM？答：视觉编码器输出经投影/交叉注意力对齐到文本空间。

## 九、演进

CLIP → Flamingo → LLaVA → 统一多模态大模型。

## 十、小结

ViT 作为多模态大模型的视觉骨干，是图文融合的关键组件。
