# 大模型与数据库总览

> 对应 llm-course 与 datawhalechina/llm-universe；NL2SQL 综述（用户工作流核心场景）。

## 一、背景与挑战

企业数据多存于关系数据库，自然语言问答需把「人话」转成可执行 SQL。这正是 NL-to-SQL 智能问数的核心。

## 二、核心原理

用大模型理解自然语言意图，结合**数据库 schema（表/列/类型/外键）**与**示例查询**，生成正确 SQL。关键难点：相对时间（最近几天/去年/上个月）翻译、关联表/字典表映射、多表 JOIN、聚合语义。

## 三、关键要点

- schema 上下文是生成质量的命根。
- 相对时间需转精确区间（见 NL2SQL 章）。
- 复杂表结构（关系/字典表）需特殊解析。

## 四、代码实现

```python
sql = llm.generate(f"schema:{schema}\nquestion:{q}\nSQL:")
```

## 五、与其他对比

| 方式 | 适用 |
