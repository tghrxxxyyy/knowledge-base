# 数据库智能运维

> 见「大模型与数据库深入/大模型与数据库总览」；DBA Copilot 场景。

## 一、背景与挑战

运维人员需写优化 SQL、诊断慢查询、理解执行计划。

## 二、核心原理

用大模型做：慢查询诊断（分析 `EXPLAIN` 输出给建议）、索引推荐、SQL 改写优化、自然语言生成监控告警查询。结合向量库检索历史 case 提升建议质量。

## 三、关键要点

- 需真实执行计划佐证建议。
- 改写不能改语义。

## 四、代码实现

```python
plan = run("EXPLAIN " + sql)
advice = llm(f"plan:{plan}\n给出优化建议")
```

## 五、与其他对比

- 规则引擎死板；LLM 灵活但需校验。

## 六、常见误区

- 直接执行 LLM 建议——需人工/灰度。
