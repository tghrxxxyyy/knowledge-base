# 大模型与图数据库

> 见「大模型与数据库深入/大模型与数据库总览」与「大模型与知识图谱」；图查询语言（Cypher/Gremlin）。

## 一、背景与挑战

知识以图存于 Neo4j 等，自然语言需转图查询。

## 二、核心原理

把自然语言转 Cypher/Gremlin，结合图 schema（节点标签/关系类型/属性）。图遍历语义（多跳关系）比 SQL JOIN 更直观，但需模型理解关系方向。可结合 KG 检索增强。

## 三、关键要点

- 关系方向易错（A-[:FRIEND]->B vs 反向）。
- 图 schema 比关系 schema 小，易注入。

## 四、代码实现

```cypher
MATCH (u:User)-[:FRIEND]->(f) WHERE u.name='x' RETURN f
```

## 五、与其他对比

- SQL 套表；Cypher 套图。

## 六、常见误区

- 忽略关系方向——结果错。
