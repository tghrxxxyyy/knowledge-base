# 复杂表结构解析

> 见「大模型与数据库深入/大模型与数据库总览」；关系表/字典表映射难点。

## 一、背景与挑战

真实库含关联表、字典表、码值表，自然语言常隐含「状态=1 表示生效」这类映射。

## 二、核心原理

需把领域字典（code→含义）注入提示，让模型知道 `status=1` 对应「已支付」；关联表需给出外键路径，模型才能写对 JOIN。可用 RAG 检索相关表注释/字典辅助生成。

## 三、关键要点

- 字典表是「语义黑洞」，必须显式给。
- 外键缺失时模型易乱 JOIN。

## 四、代码实现

```python
ctx = retrieve_dict_tables(question)
prompt = f"{schema}\n字典:{ctx}\nQ:{q}"
```

## 五、与其他对比

- 单表简单；多表+字典复杂。

## 六、常见误区

- 不给字典让模型猜——必错。
