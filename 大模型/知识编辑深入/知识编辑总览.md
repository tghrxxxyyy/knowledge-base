# 知识编辑总览

> 对应 Cao et al., *Knowledge Editor*, 2021；Meng et al., *ROME*, 2022。

## 一、背景与挑战

大模型固化海量知识，改一条事实需全量重训（贵）；知识编辑局部精确修改某事实而不扰其余。

## 二、核心原理

定位知识在模型中的表示（如 MLP 层），用最小改动注入/改/删特定事实；要求局部性（不改无关）与泛化（改写后问法变仍能答）。

## 三、数学形式

编辑目标：$f(\text{edit}) = y_{new}$ 且 $\forall x\notin\text{locality}: f(x)\approx f_{orig}(x)$。

## 四、代码实现

```python
from easyeditor import ROME
editor = ROME(model, hparams)
edited = editor.edit(prompts=["The capital of X is"], target="Y")
```

## 五、与其他对比

- 与 持续预训练数据深入（重训注入）比，编辑更省更精准。
- 与 参数高效微调深入（局部改权重）思路近。

## 六、常见误区

- 误以为编辑永久不退化；后续训练可能覆盖。
- 只测编辑句不测泛化/局部性。

## 八、面试题

- 问：知识编辑两大指标？答：泛化性（改写后变体仍对）与局部性（无关知识不被改）。

## 九、演进

全量重训 → 元学习编辑 → ROME/MEND/SERAC 路线。

## 十、小结

知识编辑以最小代价精准改事实，是模型纠错与时效更新的利器。
