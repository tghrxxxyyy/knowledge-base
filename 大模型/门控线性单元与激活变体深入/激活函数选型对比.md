# 激活函数选型对比

> 对应 Shazeer 2020 门控变体实验，以及 Hendrycks & Gimpel, *GELU*, 2016 的激活对比。

## 一、背景与挑战

FFN 中激活/门控选择影响收敛、质量与推理速度，需在预算内选型。

## 二、核心原理

无门控类（ReLU/GELU/SiLU）直接变换；门控类（GLU/SwiGLU 族）用乘法门，表达更强但参数更多，需调中间维以保持计算量。

## 三、数学形式

计算量近似：$C\approx 2\cdot d\cdot d_{ff}$ 无门控；门控类 $d_{ff}$ 常取无门控的 $2/3$ 以对齐 $C$。

## 四、代码实现

```python
ffn_dim = int(2 * 4 * d / 3)  # SwiGLU 常用 2/3 倍中间维
```

## 五、与其他对比

- 门控类质量通常优于无门控，但推理略慢；GELU 是无门控中的稳健默认。
- 与 预归一化后归一化深入 共享：归一化与激活常协同影响稳定。

## 六、常见误区

- 直接比较不同 $d_{ff}$ 下的质量，忽略计算预算差异。
- 在小模型上套用大模型结论，门控增益随规模变化。

## 八、面试题

- 为何门控 FFN 常用更小中间维？答：门控使单投影扩到 2 份，缩维以对齐总计算预算。

## 九、演进

ReLU → GELU → SwiGLU 门控化，质量与稳定性同步提升。

## 十、小结

激活选型应结合计算预算；现代 LLM 普遍采用 SwiGLU 门控 FFN。
