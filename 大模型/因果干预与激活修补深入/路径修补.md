# 路径修补（Path Patching）

> 对应 Wang et al., 2022（IOI 论文）提出；后续成为标准工具。

## 一、背景与挑战

节点级修补忽略"信息沿哪些路径流动"；路径修补刻画边级因果。

## 二、核心原理

路径修补冻结某节点的输入来自特定上游节点的贡献，仅把该上游路径在 clean 下的激活补入，验证"这条边"是否因果必要。可揭示头-to-头的因果依赖。

## 三、数学形式

路径效应 $P(e) = \text{perf}(M_{patch(e)}) - \text{perf}(M_{zero(e)})$，其中 $e$ 为从节点 $u$ 到 $v$ 的信息边。

## 四、代码实现

```python
for edge in head_edges:
    with patch_path(model, edge, clean_act=clean[edge]):
        s = metric(model, data)
    path_score[edge] = s
```

## 五、与其他对比

- 与 回路通用性（ACDC 边归因）同源。
- 与 激活修补 衔接（边级细化）。

## 六、常见误区

- 路径数组合爆炸，需先裁剪候选。
- 忽略多头内部子路径。

## 八、面试题

- 路径修补解决什么？答：节点修补不够，路径修补定位头-to-头的具体因果边。

## 九、演进

节点修补 → 边/路径修补 → 自动电路发现。

## 十、小结

路径修补把因果细化到边，是构建回路图的关键手段。
