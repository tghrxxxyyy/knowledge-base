# 因果干预的局限

> 对应 多项可解释性方法论批判（如 LCG/Basicallynocausal 讨论）；Jacot et al. 视角。

## 一、背景与挑战

因果干预虽强，但存在方法论陷阱，误用会得出错误因果结论。

## 二、核心原理

局限包括：残差流非独立变量，修补会引入分布外激活；上下游补偿使单点效应被抵消；归因-干预不一致（归因高但干预无果或反之）；离散 token 下对照构造困难。

## 三、数学形式

不一致度 $U = \text{corr}(\text{attr}, \text{intervention}) \ll 1$ 时，仅凭归因会误判；需用干预校准。

## 四、代码实现

```python
for n in nodes:
    a = attribution(n); i = intervention_effect(n)
    if sign(a) != sign(i): flag(n)  # 归因与干预矛盾
```

## 五、与其他对比

- 与 因果干预总览 互补（方法+边界）。
- 与 回路可解释性实证深入 共享但需谨慎。

## 六、常见误区

- 把一次成功干预当全局因果。
- 忽视 OOD 激活带来的伪效应。
