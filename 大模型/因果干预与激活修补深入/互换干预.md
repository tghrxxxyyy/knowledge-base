# 互换干预（Interchange Intervention）

> 对应 Geiger et al., *Causal Abstractions*, 2021；可解释性中的因果抽象。

## 一、背景与挑战

如何判断一个高维内部表示是否真的实现了某个抽象变量（如"语法数"）？

## 二、核心原理

互换干预在两个输入间交换某中间激活：若交换后输出随该抽象变量切换，则该表示"实现"了该变量。用于验证"因果抽象"——神经网络内部计算是否对应给定算法。

## 三、数学形式

若 $y(M_{swap(i)}(x_a,x_b))$ 的输出类别与 $x_b$ 在变量 $v$ 上一致，则位置 $i$ 实现 $v$。

## 四、代码实现

```python
for i in candidates:
    out = model_swap(model, i, x_a, x_b)
    if predicts_var(out, var_b):
        print(i, "implements variable", var_name)
```

## 五、与其他对比

- 与 因果干预总览 共享干预范式。
- 与 层级表征语义结构深入（探针）对照：更强因果断言。

## 六、常见误区

- 误把单一成功互换当充分证明；需多样例稳健。
- 抽象变量定义不清致无法验证。
