# 因果追踪（Causal Tracing）

> 对应 Meng et al., 2022（ROME 原文方法）。

## 一、背景与挑战

定位"事实信息最早在哪一层的哪个位置被写入"需精细因果分析。

## 二、核心原理

因果追踪是激活修补的变体：在 corrupted 输入上运行，逐步把 clean 的某层某位置激活"修补"回去，测量目标 logit 恢复程度，从而绘出信息沿层的因果流（间接效应）。

## 三、数学形式

间接效应 $IE(h_i) = \text{logit}_{clean}(o \mid \text{patch } h_i) - \text{logit}_{corr}(o)$；峰值层即信息写入处。

## 四、代码实现

```python
for l in layers:
    for pos in range(seq_len):
        ie = trace_point(model, corr, clean, l, pos, target)
        grid[l, pos] = ie
plot(grid)  # 峰值显示在关键层
```

## 五、与其他对比

- 与 激活修补 同源，更侧重"时间/层"定位。
- 与 事实关联回路 衔接（定位编辑点）。

## 六、常见误区

- 把峰值层当唯一存储点；可能有多个贡献峰。
- 修补破坏注意力依赖（位置语义改变）。

## 八、面试题

- 因果追踪与修补区别？答：追踪逐层逐位绘间接效应图以定位写入点，修补聚焦验证候选节点。

## 九、演进

修补 → 网格化追踪 → 与编辑结合（ROME）。

## 十、小结

因果追踪把"在哪改"可视化，是事实编辑的前置定位步骤。
