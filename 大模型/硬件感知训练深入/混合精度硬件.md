# 混合精度硬件收益

> 对应 Tensor Core 与低精度；混合精度训练深入 衔接。

## 一、背景与挑战

低精度既省显存又提算力（TC 在 FP16/INT8 更快），但需防溢出。

## 二、核心原理

FP16/BF16 提算力与带宽（半字节），TF32 在 A100 默认；Loss scaling 防下溢。

## 三、数学形式

带宽减半→有效吞吐翻倍（同算密下）；算力屋顶在 FP16 常为 FP32 数倍。

## 四、代码实现

```python
with torch.cuda.amp.autocast(dtype=torch.bfloat16):
    out = model(x)
```

## 五、与其他对比

- 与 数值稳定性深入（溢出/下溢）紧耦合。
- 与 梯度累积重计算深入 共享省显存。

## 六、常见误区

- 无 loss scaling 致 FP16 梯度下溢（BF16 较少）。
- 部分算子不支持半精度致回退。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- BF16 相对 FP16 优势？答：动态范围大不易溢出，省 loss scaling。

## 九、演进

FP32 → FP16+scale → BF16 → FP8。

## 十、小结

混合精度借硬件低精度单元翻倍吞吐、减半显存，是现代训练标配。
