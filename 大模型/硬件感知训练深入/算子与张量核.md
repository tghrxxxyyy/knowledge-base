# 算子与张量核对齐

> 对应 Tensor Core / 融合算子。

## 一、背景与挑战

维度不整除、碎片化算子使专用单元（Tensor Core）失效，掉速。

## 二、核心原理

矩阵维对齐到 8/16/64 倍数，启用 TF32/INT8 单元；算子融合减中间访存。

## 三、数学形式

Tensor Core 要求 $K,M,N$ 对齐 $8$（FP16）或 $16$（INT8）；未对齐回退慢路径。

## 四、代码实现

```python
hidden = ((hidden + 63)//64)*64     # 对齐
y = torch.nn.functional.linear(x, W)  # 自动用 TC
```

## 五、与其他对比

- 与 混合精度训练深入（TF32/FP16）协同启用 TC。
- 与 编译优化与模型格式 衔接（融合）。

## 六、常见误区

- 维度随意致 TC 不启用。
- 过度融合致显存峰值升。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 为什么维度要对齐？答：Tensor Core 要求对齐维度，否则回退慢路径。

## 九、演进

无对齐 → 手动对齐 → 编译器自动。

## 十、小结

算子与张量核对齐释放硬件峰值，是训练提速的硬指标。
