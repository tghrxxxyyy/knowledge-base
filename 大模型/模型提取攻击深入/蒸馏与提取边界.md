# 蒸馏与提取的合法边界

> 对应知识蒸馏的正当使用；rasbt/LLMs-from-scratch 教学 衔接。

## 一、背景与挑战

同样的蒸馏技术，合法（授权）与攻击（未授权）仅一线之隔。

## 二、核心原理

合法：教师方授权、用于压缩/对齐；非法：未授权克隆竞品功能获利。边界在授权与用途。

## 三、数学形式

合规判定 $Legal \iff \text{Authored}(teacher)\land \text{AllowedUse}$。

## 四、代码实现

```python
assert license.allows_distill(teacher)
student = distill(teacher, data)
```

## 五、与其他对比

- 与 查询盗版深入（未授权即攻击）对照。
- 与 开源模型合规深入（许可）衔接。

## 六、常见误区

- 以为“开源即可任意蒸馏”（看许可条款）。
- 把竞品输出当训练集商用侵权。

## 八、面试题

- 蒸馏合规边界？答：须获教师授权且用途合法，否则构成未授权提取。

## 九、演进

无许可意识 → 许可审查 → 合规蒸馏流水线。

## 十、小结

蒸馏与提取技术同构，合规靠授权与用途界定。
