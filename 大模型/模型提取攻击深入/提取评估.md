# 模型提取评估

> 对应替代模型保真度度量；模型评测指标深入 衔接。

## 一、背景与挑战

如何衡量提取的替代模型与原模型多接近。

## 二、核心原理

在测试集比输出分布相似度（KL/准确率一致性）、功能一致性；隐私提取看可识别样本数。

## 三、数学形式

保真 $F=1-\frac{1}{N}\sum_i KL(p_t(x_i)||p_s(x_i))$ 或一致率。

## 四、代码实现

```python
fid = mean(kl(teacher(x), student(x)) for x in test)
```

## 五、与其他对比

- 与 训练数据提取深入（泄漏计数）共享。
- 与 模型评测指标深入（一致率）共享。

## 六、常见误区

- 只比准确率忽略分布（高风险场景）。
- 测试集与攻击集重叠致虚高。

## 九、演进

准确率 → 分布 KL → 多维保真。

## 十、小结

提取评估靠分布与功能一致性，量化克隆程度。
