# 模型提取攻击总览

> 对应 Tramèr et al., *Stealing Machine Learning Models via Prediction APIs*, 2016；通过查询复制模型。

## 一、背景与挑战

攻击者仅能访问模型 API（输入→输出），想重建等价/替代模型或窃功能。

## 二、核心原理

用大量查询及返回（logits/标签）训练替代模型（surrogate），逼近目标行为。

## 三、数学形式

替代训练 $\min_{\theta'}\mathbb E_{x\sim D}[\ell(f_{\theta'}(x),f_\theta(x))]$。

## 四、代码实现

```python
for x in sample_queries(n): D.append((x, api(x)))
surrogate.fit(D)
```

## 五、与其他对比

- 与 模型提取评估深入（衡量相似度）衔接。
- 与 数据投毒防御深入（不同威胁）区分。

## 六、常见误区

- 以为只返回标签不可提取（仍可训练）。
- 忽视查询预算即成本。

## 八、面试题

- 模型提取是什么？答：用查询与返回训练替代模型，复制目标功能或知识。

## 九、演进

标签查询 → logits 查询 → 自然语言蒸馏克隆。

## 十、小结

模型提取借查询复制能力，是 API 经济核心威胁。
