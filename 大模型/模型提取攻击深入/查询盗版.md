# 查询盗版（Query-Based Extraction）

> 对应基于 API 返回的克隆；rasbt/LLMs-from-scratch 知识蒸馏 对照。

## 一、背景与挑战

如何用最少查询、最高保真复制目标 LLM 行为。

## 二、核心原理

主动学习选高价值查询（边界/多样性），用目标输出作教师信号蒸馏小模型。

## 三、数学形式

蒸馏损失 $\mathcal L=KL(p_{teacher}||p_{student})+\alpha\mathcal L_{task}$。

## 四、代码实现

```python
soft = teacher(input, return_logits=True)
loss = kl(student(input), soft)
```

## 五、与其他对比

- 与 指令微调范式深入（合成数据蒸馏）共享技术。
- 与 知识蒸馏深入（合法场景）对照边界。

## 六、常见误区

- 合法蒸馏与攻击盗版边界模糊（看授权）。
- 查询覆盖不足致分布偏移。

## 八、面试题

- 蒸馏与提取区别？答：技术同，区别在于是否获授权；未授权即攻击。

## 九、演进

随机查询 → 主动查询 → 课程式蒸馏。

## 十、小结

查询盗版本质是未授权蒸馏，授权是合法边界。
