# 模型提取防御

> 对应 API 防提取；与 隐私推理深入（DP）共享缓解。

## 一、背景与挑战

需在不影响正常用户下，提高提取成本与降保真。

## 二、核心原理

限制返回精细度（只 top-1/截断 logits）、查询节流、去重检测异常、加噪输出、差分隐私训练。

## 三、数学形式

输出扰动 $y'=y+\text{clip}(z,\epsilon)$ 或仅返 $\arg\max$。

## 四、代码实现

```python
if rate_limit(ip): deny()
return top1(logits)   # 不返全分布
```

## 五、与其他对比

- 与 安全分类器深入（异常查询检测）衔接。
- 与 隐私推理深入（DP 训练）对照。

## 六、常见误区

- 只返标签仍可被蒸馏。
- 限流误伤正常批量用户。

## 八、面试题

- 如何防提取？答：降返回精度、查询节流、异常检测、DP 训练多管齐下。

## 九、演进

无防御 → 限流 → 返回降精+DP。

## 十、小结

提取防御靠降精度+检测+隐私训练组合。
