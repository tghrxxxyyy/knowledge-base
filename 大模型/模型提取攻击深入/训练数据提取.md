# 训练数据提取攻击

> 对应 Carlini et al., *Extracting Training Data from Large Language Models*, 2021；从生成中复原隐私样本。

## 一、背景与挑战

LLM 可能记忆训练数据，攻击者可诱导其逐字吐出敏感样本。

## 二、核心原理

用前缀/提示工程触发记忆样本输出；按可识别（如含邮箱/身份证）判定成功提取。

## 三、数学形式

提取成功若 $\exists s\in D_{train}: s \subseteq f(x)$ 且可核验。

## 四、代码实现

```python
for p in crafted_prefixes:
    if looks_like_pii(model(p)): log_leak(p)
```

## 五、与其他对比

- 与 隐私推理深入（成员推断/DP）共享隐私威胁。
- 与 模型提取评估深入（泄漏度量）衔接。

## 六、常见误区

- 误以为大模型不会记忆（会记忆罕见样本）。
- 忽略间接泄漏（拼接还原）。
