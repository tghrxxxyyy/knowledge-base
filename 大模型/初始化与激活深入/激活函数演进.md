# 激活函数演进

> 见「初始化与激活深入/初始化与激活总览」；从饱和到非饱和。

## 一、背景与挑战

sigmoid/tanh 易饱和致梯度消失；ReLU 有死亡问题。

## 二、核心原理

- **ReLU**：`max(0,x)`，计算简单、缓解消失，但负区死神经元。
- **Leaky/Parametric ReLU**：负区给小斜率。
- **ELU**：负区指数趋近，均值近零。
- **GELU/SiLU**：平滑、概率式门控，Transformer 标配。

## 三、数学形式

GELU ≈ `x·Φ(x)`（Φ 为标准正态 CDF）；SiLU=`x·σ(x)`。

## 四、代码实现

```python
act = nn.GELU() if transformer else nn.ReLU()
```

## 五、关键要点

- 大模型偏好平滑激活（GELU/SiLU）。
- 激活影响梯度流与收敛。

## 六、与其他对比

- 硬 ReLU 快；GELU 平滑更准。

## 七、常见误区

- ReLU 永远好——死亡与均值偏移。
