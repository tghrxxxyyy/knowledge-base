# 大模型激活选择

> 见「初始化与激活深入/初始化与激活总览」与「模型架构演进」；架构级选择。

## 一、背景与挑战

现代大模型（GPT/LLaMA）对激活有固定偏好。

## 二、核心原理

主流 Transformer 用 **GELU**（GPT-2/BERT）或 **SwiGLU/SiLU**（LLaMA/PaLM 用 SwiGLU，即 SiLU 做门控的 FFN）。SwiGLU 在 FFN 中以 SiLU 门控提升表达，已成为大模型事实标准。

## 三、数学形式

SwiGLU(x) = `SiLU(W1 x) ⊙ (W2 x)`，替代原 ReLU 两层 FFN。

## 四、代码实现

```python
class SwiGLU(nn.Module):
    def forward(self, x): return F.silu(W1(x)) * W2(x)
```

## 五、关键要点

- SwiGLU 略增参数换性能。
- 与 RMSNorm 搭配常见。

## 六、与其他对比

- ReLU FFN 简单；SwiGLU 更强。

## 七、常见误区

- 激活随意换——影响收敛与性能。
