# 初始化与激活总览

> 对应 d2l-zh 数值稳定性章与 Glorot & Bengio, *Understanding Init*, 2010；Hendrycks & Gimpel, *GELU*, 2016。

## 一、背景与挑战

错误的初始化会让梯度消失/爆炸；激活函数决定非线性与梯度流。二者共同决定训练能否启动与收敛。

## 二、核心原理

初始化目标：各层激活/梯度方差在传播中保持稳定（见权重初始化理论章）。激活从 sigmoid/tanh 演进到 ReLU 家族（Leaky/ELU/GELU/SiLU），缓解死亡神经元与梯度消失。大模型多用 GELU/SiLU。

## 三、关键要点

- 初始化与激活需配合（如 ReLU 配 He 初始化）。
- 深层网络对二者极敏感。

## 四、代码实现

```python
nn.init.xavier_uniform_(w); act = nn.GELU()
```

## 五、与其他对比

| 激活 | 问题 |
|------|------|
| sigmoid | 饱和消失 |
| ReLU | 死亡 |
| GELU | 平滑 |

## 六、常见误区

- 默认初始化即可——深层需专门初始化。
