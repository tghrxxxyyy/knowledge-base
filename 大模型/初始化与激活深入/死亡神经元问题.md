# 死亡神经元问题

> 见「初始化与激活深入/初始化与激活总览」与「激活函数演进」。

## 一、背景与挑战

ReLU 下部分神经元输出恒为 0，永久失活，降低容量。

## 二、核心原理

大负偏置或高学习率使神经元输入恒负→输出0→梯度0→不再更新（死亡）。缓解：Leaky/ELU 给负区梯度、合理初始化、学习率控制、BatchNorm（中心化）。

## 三、关键要点

- 少量死亡可接受；大量损害容量。
- 监控激活分布可诊断。

## 四、代码实现

```python
dead = (act == 0).all(dim=0).sum()   # 统计死神经元
```

## 五、与其他对比

- ReLU 有死亡；GELU 基本无。

## 六、常见误区

- 死亡无害——大量则损。
