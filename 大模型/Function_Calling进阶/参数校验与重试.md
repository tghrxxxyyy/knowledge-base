# 参数校验与重试

> 见「Function_Calling进阶/工具调用协议」。

## 一、背景与挑战

模型可能输出非法参数（类型错、缺字段、越界），直接执行会报错。

## 二、核心原理

在回填前用 Schema/类型系统校验；失败时构造「错误反馈」让模型修正（self-correction loop），或回退到澄清提问。

## 三、代码实现

```python
import jsonschema
try: jsonschema.validate(args, schema)
except Exception as e: feedback = f"参数错误:{e}"
```

## 四、关键要点

- 校验失败反馈要具体，便于模型改。
- 设最大重试次数防死循环。

## 五、与其他对比

- 前端表单校验防用户；这里防模型输出漂移。

## 六、常见误区

- 无限重试——固定上限 + 降级。

## 九、演进

无校验 → schema 校验 → 自检循环 → 人类澄清。

## 十、小结

校验与重试决定工具调用的鲁棒性。
