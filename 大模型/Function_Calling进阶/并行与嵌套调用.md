# 并行与嵌套调用

> 见「Function_Calling进阶/工具调用协议」。

## 一、背景与挑战

单轮多次取数或子任务拆解需并行/嵌套调用以提升效率。

## 二、核心原理

模型可在一次回复中请求多个独立工具（并行）；也可在工具执行中再触发子 Agent（嵌套）。运行时需支持并发执行与结果聚合。

## 三、代码实现

```python
# 并行：收集所有 tool_calls 并发执行
import concurrent.futures
with concurrent.futures.ThreadPoolExecutor() as ex:
    res = list(ex.map(run_tool, calls))
```

## 四、关键要点

- 并行调用需工具无副作用依赖。
- 嵌套需防止无限递归（设最大深度）。

## 五、与其他对比

- 串行慢但可控；并行快但需依赖分析。

## 六、常见误区

- 盲目并行有依赖的工具——结果互相覆盖。
