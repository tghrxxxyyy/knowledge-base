# 工具调用协议

> 对应 llm-universe 工具调用章与 OpenAI function calling。

## 一、背景与挑战

让 LLM 调用外部 API/函数，需规范「能力声明-调用-结果回填」的协议。

## 二、核心原理

向模型提供 JSON Schema 描述的函数清单；模型输出结构化调用请求（name + arguments）；运行时执行并回填结果，模型据此续答。

## 三、数学形式

调用表示为：

```
call = {name: f, arguments: {k_i: v_i}}
```

## 四、代码实现

```python
tools = [{"type":"function","function":{"name":"get_weather","parameters":{...}}}]
resp = llm(messages, tools=tools)
```

## 五、关键要点

- Schema 越清晰，参数越准。
- 模型决定「是否调用」与「调用哪个」。

## 六、与其他对比

- 提示工程硬塞 JSON 易错；原生 function calling 由模型结构化输出。

## 七、常见误区

- 以为模型总调对参数——需校验与重试。

## 八、与开源书对应

- llm-universe: https://github.com/datawhalechina/llm-universe
- OpenAI Cookbook: https://github.com/openai/openai-cookbook

## 九、面试题

- 模型如何在多个工具中选择并填充参数？

## 十、演进

文本约定 → JSON mode → 原生 function calling → 并行调用。

## 十一、小结

工具调用协议是 Agent 连接世界的接口。
