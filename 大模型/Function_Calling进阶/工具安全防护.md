# 工具安全防护

> 见「安全与对齐深入/提示注入」与「大模型安全与对齐」。

## 一、背景与挑战

工具可写库、发邮件、执行命令，恶意提示可能诱导危险操作。

## 二、核心原理

分层防护：沙箱执行、权限最小化、敏感操作人工确认、输入输出过滤、调用审计。

## 三、代码实现

```python
SENSITIVE = {"send_email","delete_file"}
if call.name in SENSITIVE: require_human_approval(call)
```

## 四、关键要点

- 默认拒绝高危工具自动执行。
- 提示注入可劫持工具调用链。

## 五、与其他对比

- 普通应用防 XSS；这里防「模型被诱导调危险工具」。

## 六、常见误区

- 认为沙箱万能——需结合权限与确认。

## 七、与开源书对应

- llm-universe 安全章: https://github.com/datawhalechina/llm-universe
- OWASP LLM Top 10.

## 九、演进

无防护 → 沙箱 → 权限分级 → 人类确认关键动作。

## 十、小结

工具安全是 Agent 上线的硬门槛。
