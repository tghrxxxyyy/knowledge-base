# 语法/CFG 约束

> 对应合成与受控生成（CFG 解码）；与 结构化输出深入 衔接。

## 一、背景与挑战

需输出符合语法（如 SQL、配方步骤）的文本，自由生成易语法错。

## 二、核心原理

以上下文无关文法（CFG）定义合法序列，解码时仅展开当前非终结符可产生的 token，保证全程语法合法。

## 三、数学形式

合法前缀集 $L(G)=\{w: S\Rightarrow^* w\}$；每步 $A_t=\{y_t: y_{<t}y_t\in \text{prefix}(L)\}$。

## 四、代码实现

```python
parser = IncrementalCFG(grammar)
for t in range(T):
    toks = parser.valid_next(logits)
```

## 五、与其他对比

- 与 结构化输出深入（JSON 模式）同目标不同表达。
- 与 波束搜索深入 可结合。

## 六、常见误区

- 文法过严限制表达。
- 增量解析开销大。
