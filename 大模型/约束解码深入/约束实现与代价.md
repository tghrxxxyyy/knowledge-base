# 约束解码实现与代价

> 对应约束解码工程；与 推理成本深入 衔接。

## 一、背景与挑战

约束引入额外状态追踪与掩码，带来延迟与内存成本。

## 二、核心原理

状态矩阵/FSM 随步更新并作用于 logits；并行束可共享约束状态以降本。

## 三、数学形式

额外开销 $O(B\cdot m)$ 状态或 $O(|FSM|)$ 掩码；缓存前缀树可省重复。

## 四、代码实现

```python
mask = fsm.mask(state)              # 合法 token 布尔
logits = logits.masked_fill(~mask, -inf)
```

## 五、与其他对比

- 与 早退推理深入（加速）可能冲突需协调。
- 与 动态计算深入 同为推理期优化。

## 六、常见误区

- 约束状态未随束复制致错。
- 忽视掩码 -inf 数值溢出。

## 八、面试题

- 约束解码代价？答：每步状态追踪+logits 掩码，束间共享与缓存可降本。

## 九、演进

串行状态 → 并行共享 → 编译优化。

## 十、小结

约束解码以少量开销换强可控，工程上需状态与掩码细心实现。
