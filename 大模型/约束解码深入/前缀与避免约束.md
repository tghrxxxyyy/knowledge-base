# 前缀与避免约束

> 对应约束解码变体（强制开头/禁词）。

## 一、背景与挑战

需固定开头模板或禁止敏感词，普通解码不可控。

## 二、核心原理

前缀约束：前若干 token 锁定；避免约束：屏蔽禁词或其子串续写，用负面状态约束。

## 三、数学形式

前缀 $y_{1:k}=p^*$；避免集 $F$，若 $y_t\in F$ 则 $A_t\leftarrow A_t\setminus\{y_t\}$。

## 四、代码实现

```python
gen = model.generate(input_ids, prefix_allowed_tokens_fn=lambda s,t: allow[t])
```

## 五、与其他对比

- 与 词汇约束深入 互补（锁头 vs 含词）。
- 与 格式化输出深入 可共保格式。

## 六、常见误区

- 前缀与模型分布冲突致低质。
- 禁词仅屏蔽整词忽略子串。

## 八、面试题

- 如何强制前缀？答：用 prefix_allowed_tokens_fn 限定每步合法 token 为前缀序列。

## 九、演进

硬锁 → 软偏好 → 正则化约束。
