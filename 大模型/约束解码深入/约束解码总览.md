# 约束解码总览

> 对应 Hokamp & Liu, *Lexically Constrained Decoding*, 2017（Grid Beam Search）；与 结构化输出深入 衔接。

## 一、背景与挑战

开放采样难保证特定词/格式出现，约束解码在解码期强制满足硬/软约束。

## 二、核心原理

在束搜索中追踪未满足约束，只允许能最终满足约束的续写；分词汇、前缀、语法、模式等约束。

## 三、数学形式

约束状态 $c\in\{0,1\}^m$ 随步更新；合法集 $A_t=\{y_t: \text{feasible}(c, y_t)\}$。

## 四、代码实现

```python
gen = model.generate(input_ids, constraints=[["必须", "出现"]],
                      constraint_method="grid")
```

## 五、与其他对比

- 与 波束搜索深入 同框架加约束。
- 与 结构化输出深入 重叠但约束更通用。

## 六、常见误区

- 约束间互斥致无解死循环。
- 约束过紧牺牲流畅。
