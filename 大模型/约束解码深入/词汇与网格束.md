# 词汇约束与网格束搜索

> 对应 Hokamp & Liu, 2017。

## 一、背景与挑战

需输出含指定关键词（如实体名）的句子，普通解码难保证。

## 二、核心原理

Grid Beam Search 为每个约束分配束列，逐词推进时标记约束已覆盖，优先保留未满足约束的候选。

## 三、数学形式

状态矩阵 $S\in\{0,1\}^{B\times m}$；得分加未满足惩罚 $-\gamma\cdot\sum (1-S_{b})$。

## 四、代码实现

```python
from transformers import LexicallyConstrainedBeamSearch
bs = LexicallyConstrainedBeamSearch(forcing_tokens=[tok_ids])
```

## 五、与其他对比

- 与 前缀约束深入 同属硬约束。
- 与 采样策略深入 难直接合（需约束采样）。

## 六、常见误区

- 约束词不在词表致无法命中。
- 多约束互相排斥。

## 七、与开源书对应

- rasbt/LLMs-from-scratch：https://github.com/rasbt/LLMs-from-scratch
- harvardnlp/annotated-transformer：https://github.com/harvardnlp/annotated-transformer

## 八、面试题

- Grid Beam 如何保证关键词？答：束分列追踪约束覆盖，保留可满足路径。

## 九、演进

单约束 → 多约束网格 → 软约束。

## 十、小结

词汇约束以网格束强制关键词出现，实用可控。
