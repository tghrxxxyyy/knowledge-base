# 模式引导生成（Outlines/ Guidance）

> 对应 Willard & Louf, *Efficient Guided Generation*, 2023（Outlines）。

## 一、背景与挑战

正则/JSON 模式引导需高效且对模型无训练改动。

## 二、核心原理

用有限状态机（regex/JSON schema）增量约束每步 logits 掩码，前缀树缓存加速，等价于约束采样。

## 三、数学形式

约束分布 $P_c(v)\propto P(v)\cdot \mathbb 1[v\in\text{fsm}(state)]$；状态随 token 转移。

## 四、代码实现

```python
from outlines import models, generate
model = models.transformers("meta-llama/Llama-2-7b")
gen = generate.regex(model, r"[A-Z][a-z]+@[a-z]+\.com")
```

## 五、与其他对比

- 与 结构化输出深入 重叠，常同一工具。
- 与 词汇约束深入 更通用（任意 regex）。

## 六、常见误区

- 误以为需微调；实际仅掩码。
- 复杂 schema 状态爆炸。

## 八、面试题

- 引导生成如何零训练控格式？答：用 FSM 对每步 logits 掩码，仅留合法 token。

## 九、演进

Grid → FSM 引导 → 缓存加速。

## 十、小结

模式引导以 FSM 掩码实现高效可控生成，无需训练。
