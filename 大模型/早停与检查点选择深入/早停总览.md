# 早停总览（Early Stopping）

> 对应 Prechelt, *Early Stopping – but when?*, 1998（神经网络早停经典）；Langley。

## 一、背景与挑战

训练过久易过拟合训练集、泛化下降；早停在验证性能拐点前停，是隐式正则且省算力。

## 二、核心原理

监控验证集指标（损失/准确率），当其在若干轮内不再改善即停止；同时可保存"最优验证"检查点供后续使用。

## 三、数学形式

设验证损失序列 $v_t$，早停准则：当 $t-\arg\min_{s\le t}v_s > p$ 时停止（$p$ 为耐心）；最优检查点 $\theta^*=\theta_{\arg\min v_t}$。

## 四、代码实现

```python
if val_loss < best:
    best = val_loss; wait = 0; save(model)
else:
    wait += 1
    if wait >= patience: break
```

## 五、与其他对比

- 与 权重平均与模型融合深入（平均也求平坦解）异曲同工。
- 与 检查点选择深入 共享"何时存/用哪份权重"。

## 六、常见误区

- 耐心过小致欠拟合、过大浪费算力。
- 仅看训练损失误判（应看验证）。

## 八、面试题

- 早停为何是正则？答：限制迭代步数限制模型容量，等价于权重衰减式约束，防过拟合。

## 九、演进

固定轮数 → 验证早停 → 结合检查点平均。

## 十、小结

早停以验证监控换取泛化与算力双赢，是最常用隐式正则。
