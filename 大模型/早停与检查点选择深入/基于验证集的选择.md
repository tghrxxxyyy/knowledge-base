# 基于验证集的选择

> 对应 模型选择（model selection）理论；与 模型评测指标深入 衔接。

## 一、背景与挑战

验证集代表性强弱直接影响选择偏差；小验证集噪声大，选择不稳定。

## 二、核心原理

用足够大且与测试同分布的验证集评估候选；可做 k 折交叉验证或多次随机划分求均值降噪，再选最优。

## 三、数学形式

选择 $\theta^*=\arg\min_\theta \mathbb E_{D_{val}}\,\mathcal L(\theta;D_{val})$；交叉验证以均值 $\bar{\mathcal L}$ 与方差筛选。

## 四、代码实现

```python
scores = [eval_ck(ck, fold) for fold in k_folds]
best = cks[argmin(mean(scores))]
```

## 五、与其他对比

- 与 提示的数据效率评估（同样依赖验证集）呼应。
- 与 训练容错与弹性深入（恢复后需重选）衔接。

## 六、常见误区

- 验证集与训练集泄漏（数据重叠）致乐观偏差。
- 过度依赖单点验证致选择方差大。

## 八、面试题

- 验证集选择为何要同分布？答：选择偏差来自分布偏移，同分布才能代表测试表现，避免错选。

## 九、演进

单验证集 → k 折 → 嵌套交叉验证。

## 十、小结

基于验证集的选择质量取决于验证集代表性与评估稳健性。
