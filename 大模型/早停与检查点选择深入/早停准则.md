# 早停准则设计

> 对应 Prechelt, 1998 的多准则对比（GL/NR/QP 等）。

## 一、背景与挑战

何时"真停止"难定：验证指标抖动会误触发；需稳健准则避免过早或过晚。

## 二、核心原理

常用准则：相对增益阈值（Generalized Loss，GL）、验证误差超历史最优比例（NR）、二次加权和（QP）；辅以平滑（指数滑动）减少抖动误判。

## 三、数学形式

GL 准则：$\frac{v_t-v_{min}}{v_{min}} > \alpha$ 触发停止；NR：$\frac{v_t-v_{min}}{v_0} > \beta$；$\alpha,\beta$ 为容忍度。

## 四、代码实现

```python
gl = (val_loss - best) / best
if gl > alpha: stop()
```

## 五、与其他对比

- 与 检查点选择深入（停后选哪份）配合。
- 与 训练不稳定诊断深入（抖动识别）共享平滑技术。

## 六、常见误区

- 未平滑验证曲线致频繁误停。
- 准则阈值照搬他任务（应依数据调）。

## 八、面试题

- 如何避免早停误触发？答：对验证指标做滑动平滑，并用相对阈值（GL/NR）而非绝对波动。

## 九、演进

单一耐心 → 多准则 → 平滑+自适应阈值。

## 十、小结

早停准则需在敏感与稳健间平衡，平滑与相对阈值是关键。
