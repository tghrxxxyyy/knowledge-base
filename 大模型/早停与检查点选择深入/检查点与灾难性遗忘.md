# 检查点与灾难性遗忘

> 对应 Kirkpatrick et al., *EWC*, 2017；持续学习中的遗忘。

## 一、背景与挑战

顺序多阶段训练（如先预训后对齐）时，后期可能覆盖前期能力；检查点可回滚到遗忘前状态。

## 二、核心原理

监控各能力指标，若某能力在后期明显下降，可从早期检查点恢复并采用更温和的学习率或正则（EWC/L2 锚定）防止遗忘。

## 三、数学形式

EWC 惩罚：$\mathcal L_{EWC}=\mathcal L + \frac{\lambda}{2}\sum_i F_i(\theta_i-\theta_{anchor,i})^2$，$F_i$ 为 Fisher 重要性。

if probe_score(drop=True):

## 五、与其他对比

- 与 早停与检查点选择深入（保存关键节点）配合防遗忘。
- 与 训练不稳定诊断深入（能力退化诊断）衔接。

## 六、常见误区

- 只在主指标看遗忘，忽略次要能力。
- 回滚后未调整学习率致再次遗忘。

## 八、面试题

## 九、演进

无保护训练 → 回滚 → 正则锚定(EWC)。

## 十、小结

检查点是遗忘的"安全网"，配合正则可稳定多阶段能力。
