# 检查点选择策略

> 对应 训练工程实践（checkpoint selection）；与 早停与检查点选择深入 总览衔接。

## 一、背景与挑战

训练产出多份检查点，仅保留末份或用最优验证份都未必最好；需系统选择/聚合策略。

## 二、核心原理

策略包括：保留最优验证权重、保留最后若干做平均、按多指标（损失+特定任务指标）加权选择、用留出测试集二次筛选。

## 三、数学形式

综合分 $s(\theta)=w_1\,f_{val}(\theta)+w_2\,f_{task}(\theta)$；选取 $\theta^*=\arg\max_\theta s(\theta)$ 或取 top-k 平均。

## 四、代码实现

```python
scores = {ck: 0.7*val_acc(ck) + 0.3*task_f1(ck) for ck in cks}
best = max(scores, key=scores.get)
```

## 五、与其他对比

- 与 权重平均与模型融合深入（top-k 平均）直接结合。
- 与 早停与检查点选择深入（早停决定存哪些）接力。

## 六、常见误区

- 用测试集选检查点致测试泄漏（应留独立集）。
- 单一指标选致偏科（需多指标）。

## 八、面试题

- 如何选最终检查点？答：以验证/多指标综合分择优，或取末段 top-k 平均，禁在测试集上选。

## 九、演进

末份 → 最优验证份 → 多指标+平均。

## 十、小结

检查点选择决定最终交付质量，应多指标评估并可结合平均。
