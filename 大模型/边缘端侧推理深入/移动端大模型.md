# 移动端大模型

> 见「边缘端侧推理深入/边缘推理总览」与「端侧与边缘大模型」；手机上跑 LLM。

## 一、背景与挑战

手机是最大端侧载体，但 SoC/NPU 各异。

## 二、核心原理

利用 NPU（高通/苹果/华为）加速量化算子；用 GGUF/专用格式；做模型瘦身（≤3B）适配内存。系统级集成（如手机助手）需常驻低资源。

## 三、关键要点

- NPU 加速需厂商适配。
- 常驻需极致轻量。

## 四、代码实现

```python
# 移动端用 NPU delegate
interpreter = make_interpreter(model, "gpu")  # 或 npu
```

## 五、与其他对比

- PC 端自由；移动端受 NPU 限制。

## 六、常见误区

- 手机能跑大模型——需 NPU+量化。
