# 端云协同

> 见「边缘端侧推理深入/边缘推理总览」；混合部署。

## 一、背景与挑战

端侧能力有限，全上云损隐私/延迟。

## 二、核心原理

简单/隐私请求端侧处理；复杂/超长上下文请求上云；或端侧「草稿」+云端「校验」（投机解码的端云版）。根据网络/电量动态路由。

## 三、关键要点

- 路由策略是核心。
- 隐私分级决定上云与否。

## 四、代码实现

```python
route = "edge" if (privacy_ok(q) and simple(q)) else "cloud"
```

## 五、与其他对比

- 纯端能力弱；纯云隐私弱；协同折中。

## 六、常见误区

- 全端或全云——协同最优。
