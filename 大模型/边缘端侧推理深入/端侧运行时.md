# 端侧运行时

> 见「边缘端侧推理深入/边缘推理总览」；运行时决定速度。

## 一、背景与挑战

同一量化模型，不同运行时速度差数倍。

## 二、核心原理

- **llama.cpp**：纯 C++，GGUF 格式，CPU/GPU(Metal/CUDA) 通吃，端侧事实标准。
- **MNN / NCNN**：移动端优化推理引擎。
- **ONNX Runtime / ExecuTorch**：跨平台。
关键优化：内存映射权重、算子融合、低精度内核。

## 三、关键要点

- GGUF 是生态核心格式。
- Metal/CUDA 后端显著提速。

## 四、代码实现

```python
from llama_cpp import Llama
llm = Llama(model_path="m.Q4_K.gguf", n_gpu_layers=30)
```

## 五、与其他对比

- 通用框架慢；专用运行时快。

## 六、常见误区

- 模型小就快——运行时优化更关键。
