# 端侧量化与剪枝

> 见「边缘端侧推理深入/边缘推理总览」与「模型量化部署实战」；端侧压缩。

## 一、背景与挑战

端侧内存/算力严酷，必须极致压缩。

## 二、核心原理

- **量化**：权重/激活从 fp16 降到 int8/int4/int2，GGUF 提供多档（Q2/Q4/Q8）。
- **剪枝**：去冗余通道/注意力头。
- **结构化压缩**：保证硬件友好（如 4-bit 分组）。
端侧常用 GGUF + llama.cpp 的 k-quant 系列。

## 三、数学形式

int4 权重：每权重 0.5 字节，相对 fp16 压缩 4 倍。

## 四、代码实现

```bash
./quantize model.f16.bin model.Q4_K.gguf Q4_K
```

## 五、关键要点

- 极低比特（2-3bit）质量损失大。
- 需实测端侧精度。

## 六、与其他对比

- 服务端可 fp8；端侧常 int4。

## 七、常见误区

- 量化无代价——低比特掉点。

## 十、演进

fp16 → int8 → int4 → 混合比特。

## 十一、小结
