# 边缘推理总览

> 对应 llm-course 与「端侧与边缘大模型」；在手机/PC/嵌入式跑大模型。

## 一、背景与挑战

云端推理有延迟、断网、隐私问题；端侧推理需极小资源。

## 二、核心原理

端侧大模型靠：量化到 int4/int2（见量化章）、剪枝、小架构（如 0.5-3B）、高效运行时（llama.cpp/GGUF、MNN、ONNX Runtime）。目标：在数 GB 内存内跑通、低功耗、离线可用。

## 三、关键要点

- int4 量化是端侧标配。
- 运行时效率决定实际速度。
- 离线/隐私是核心卖点。

## 四、代码实现

```bash
./llama-cli -m model.Q4_K.gguf -p "你好"
```

## 五、与其他对比

| 形态 | 资源 | 隐私 |
|------|------|------|
| 云 | 充足 | 弱 |
| 端侧 | 紧张 | 强 |

## 六、常见误区
