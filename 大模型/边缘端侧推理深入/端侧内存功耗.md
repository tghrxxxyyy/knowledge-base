# 端侧内存与功耗

> 见「边缘端侧推理深入/边缘推理总览」；资源硬约束。

## 一、背景与挑战

手机/嵌入式内存数 GB、电池有限，大模型易超。

## 二、核心原理

内存占用 = 模型权重（量化后）+ KV-cache + 运行时开销。功耗来自访存与计算；量化既降内存也降功耗。需控制峰值内存防 OOM，控制持续功耗防过热降频。

## 三、关键要点

- 峰值内存决定能否加载。
- 功耗影响持续可用。

## 四、代码实现

```bash
# 监控峰值内存
/usr/bin/time -v ./llama-cli -m m.gguf
```

## 五、与其他对比

- 服务端不看功耗；端侧强约束。

## 六、常见误区

- 能加载即能用——功耗/发热限制。
