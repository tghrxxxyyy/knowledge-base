## 二、核心原理

测旧任务在新任务后准确率下降（遗忘量）、平均准确率、前向/后向迁移，用矩阵记录。

## 三、数学形式

```
Forgetting = 1/T Σ_t (max_{t'≤t} A_t(t') - A_t(T))
```

## 四、代码实现

```python
forget = old_acc_peak - old_acc_now
```

## 五、关键要点

- 需保留旧任务测试集。
- 平均准确率综合看。

## 六、与其他对比

- 单任务看准；持续看遗忘。

## 七、常见误区

- 只看新任务——忽略遗忘。
