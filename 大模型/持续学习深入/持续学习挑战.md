# 持续学习挑战

> 对应 d2l-zh 与 Parisi et al., *Catastrophic Forgetting*, 1989；综述见 De Lange et al., 2021。

## 一、背景与挑战

模型学新任务后忘旧任务，称灾难性遗忘。

## 二、核心原理

新梯度覆盖旧知识表征；持续学习目标是顺序学多任务且保旧能力。

## 三、关键要点

- 遗忘是神经网络固有。
- 评测需看前向/后向迁移。

## 四、代码实现

```python
for task in tasks: train(model, task)  # 朴素顺序训练易忘
```

## 五、与其他对比

- 多任务联合需全数据；持续学习流式。

## 六、常见误区

- 越多任务越聪明——会忘。
