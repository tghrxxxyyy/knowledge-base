# 参数隔离

> 见「持续学习深入/持续学习挑战」。

## 一、背景与挑战

能否每任务用不同参数避免干扰？

## 二、核心原理

动态扩展（如 Progressive Networks）、掩码（如 PackNet）或子网络分配，使任务间参数不冲突。

## 三、关键要点

- 参数随任务增长。
- 推理需任务标识。

## 四、代码实现

```python
mask = learn_task_mask(model, task_id)
```

## 五、与其他对比

- 隔离无遗忘但扩展参数。

## 六、常见误区

- 无限扩展——需上限。
