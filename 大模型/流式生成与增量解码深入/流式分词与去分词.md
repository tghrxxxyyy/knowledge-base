# 流式分词与去分词

> 对应 tokenizer 流式解码（SentencePiece / tiktoken streaming）。

## 一、背景与挑战

token 与字符非一一对应，流式输出需把不完整 token 缓冲到可解码再吐字，否则出现半字乱码。

## 二、核心原理

生成端产出 token id 流；去分词器按 BPE/Unigram 合并规则增量拼回文本，遇到跨边界不完整片段先缓存，待补全再输出。

## 三、数学形式

文本恢复 $T = \text{Detokenize}(x_1,\dots,x_t)$；需满足前缀闭合 $\text{Detokenize}(x_{<t})$ 是最终前缀。

## 四、代码实现

```python
for tok in gen_stream:
    text = tok.decode(tok_id, skip_special=True)
    if not tok.is_complete(): continue   # 不完整则缓存
    emit(text)
```

## 五、与其他对比

- 与 增量解码 协同：token 流即增量输出。
- 与 模型水印深入（token 级水印）共享 token 流。

## 六、常见误区

- 直接按 id 转字符串致多字节截断乱码。
- 特殊 token（如 <｜end｜>）未过滤。

## 八、面试题

- 为何流式要去分词缓冲？答：token 与字符非对齐，不完整片段需缓存待补全，避免半字。

## 九、演进

整段解码 → 逐 token 缓冲 → 增量 BPE 合并。

## 十、小结

流式分词/去分词保证吐字完整，是用户体验底层细节。
