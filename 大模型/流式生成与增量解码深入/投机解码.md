# 投机解码（Speculative Decoding）

> 对应 Leviathan & Matias, *Speculative Decoding*, 2023；Chen et al., *Accelerating LLM Decoding*, 2023。

## 一、背景与挑战

大模型每步仅产一 token、受限于内存带宽；小草稿模型可一次猜多 token，由大模型并行校验提速。

## 二、核心原理

用轻量草稿模型自回归生成 $\gamma$ 个候选，大模型一次前向并行验证并校正；接受序列后缀，拒绝处重采样，保证与原式分布一致。

## 三、数学形式

接受概率 $\min(1, p_{target}(x)/p_{draft}(x))$；期望加速约 $\gamma$ 倍（草稿准时）；输出分布严格不变。

## 四、代码实现

```python
draft = small_model.generate(x, gamma=5)
logits = big_model(x + draft)
accepted = verify(draft, logits)   # 按接受概率裁剪
```

## 五、与其他对比

- 与 增量解码 互补：投机减少串行步数。
- 与 前缀缓存 可叠加（草稿共享前缀）。

## 六、常见误区

- 草稿模型与靶模型分布差太大致接受率低。
- 误以为改变输出分布（实际无偏）。

## 八、面试题

- 投机解码为何无损？答：用接受/重采样规则，保证边缘分布等于目标模型分布。

## 九、演进

单草稿 → 自投机（同模型浅层）→ 树状投机（EAGLE）。

## 十、小结

投机解码以草稿并行猜、靶模型校验，显著提速且不改分布。
