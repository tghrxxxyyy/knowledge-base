# 奖励塑形成成本与约束平衡

> 对应 Ng 1999 奖励塑造 与 Rasley 2020 DeepSpeed 大规模 RL 训练实践。

## 一、背景与挑战

在强化学习（含 RLHF）中，奖励塑造（reward shaping）通过附加中间信号加速收敛，但它并非「免费午餐」：每一项塑形奖励都带来额外的计算、标注与调参成本。更棘手的是约束平衡——塑形项权重过重会压过真实任务目标，使策略「为塑造而塑造」；过轻则起不到引导作用。这一问题在大模型对齐中尤为突出：格式奖励、长度惩罚、连贯性奖励等塑形项易实现，却需要在「加速对齐」与「不偏离真实目标」之间精细权衡。挑战还包括成本的可扩展性：在千卡级 RL 训练中，塑形项的实时计算与多奖励聚合会显著增加通信与存储开销。

## 二、核心原理

塑形项通常是对「过程质量」的廉价代理：格式是否规范、长度是否适中、是否重复。总奖励是任务奖励与若干塑形项的加权和：

$$R_{tot} = R_{task} + \sum_i w_i R_i$$

权重 $w_i$ 决定塑形主导程度。平衡的关键原则是「任务目标不可牺牲」：塑形项只应加速通往 $R_{task}$ 最优的路径，而非定义新的最优。实践中常用验证集扫描权重，寻找使任务指标不被牺牲且收敛加速的配置；也可采用自适应权重，在训练早期多用塑形引导、后期逐渐退火（anneal）以回归真实目标。

## 三、形式化与数学基础

设任务奖励 $R_{task}$ 与塑形项集合 $\{R_i\}$，总奖励：

$$R_{tot}(s,a) = R_{task}(s,a) + \sum_i w_i R_i(s,a)$$

在策略不变性视角下（Ng 1999），只有基于势函数的塑形才保证不改变最优策略。若塑形项非势函数形式，则会改变最优解，其偏移量取决于 $w_i$ 与 $R_i$ 和目标的对齐度。成本侧可建模为：每步计算塑形项的开销 $c_i$（含标注/推理），总训练成本：

$$C = T \cdot \left(c_{task} + \sum_i c_i\right) \cdot N_{step}$$

平衡即在约束 $R_{task}$ 不降下最小化 $C$ 或最大化加速比。

## 四、代码实现

```python
# 组合奖励 + 权重退火（示意）
def total_reward(r_task, shaped: dict, weights: dict, step, total_steps):
    # 后期塑形权重退火，回归真实目标
    decay = max(0.0, 1.0 - step / (0.8 * total_steps))
    r = r_task
    for name, val in shaped.items():
        r += weights[name] * val * decay
    return r

def scan_weights(valid_loader, model, w_grid):
    best, best_w = -1e9, None

        score = evaluate_with_weights(model, valid_loader, w)
        if score["task"] > best:   # 任务指标不被牺牲
            best, best_w = score["task"], w
    return best_w
```

## 五、与其他技术对比

| 方式 | 成本 | 风险 | 适用 |
|------|------|------|------|
| 纯可验证奖励 | 低（规则） | 低 | 任务明确 |
| 奖励塑造 | 中 | 中（偏移） | 需加速 |
| 学习型奖励模型 | 高 | 高（黑客） | 主观任务 |

塑形是低成本引导手段，但需与约束平衡并用。

## 六、常见误区

- 所有任务套同一权重：不同任务对长度/格式的敏感度差异巨大。
- 塑形项与目标冲突未察觉：如鼓励短输出却伤害需详述的推理任务。
- 只加不减：塑形项永久保留致分布偏移，应随训练退火。
- 忽视计算成本：多奖励聚合在大规模训练中放大通信开销。

## 七、与开源书·权威来源对应

## 十、小结

奖励塑造是低成本引导收敛的手段，但其计算与偏移成本不可忽视。平衡之道在于：以势函数形式保持策略不变性、用验证集扫描与退火控制权重、确保任务目标不被牺牲，并在大规模训练中核算塑形带来的真实开销。
