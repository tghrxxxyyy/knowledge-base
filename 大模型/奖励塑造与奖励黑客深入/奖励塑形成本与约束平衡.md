# 奖励塑造成成本与约束平衡

> 对应 Ng 1999 奖励塑造 与 Rasley 2020 DeepSpeed。

## 一、背景与挑战
塑形项引入额外计算与调参成本，需与对齐收益权衡。

## 二、核心原理
格式奖励、长度惩罚等塑形项易实现但需标定权重，过重会压过真实目标，过轻无引导效果。

## 三、形式化与数学基础
总奖励 $R_{tot}=R_{task}+w_f R_{fmt}+w_l R_{len}$，权重 $w$ 决定塑形主导程度。

## 四、代码实现
# 组合奖励
def total_reward(r_task, r_fmt, r_len, w_f=0.1, w_l=0.05):
    return r_task + w_f * r_fmt + w_l * r_len

## 五、与其他技术对比
纯可验证奖励无需塑形；学习型奖励常需塑形辅助收敛。

## 六、常见误区
所有任务套同一权重；塑形项与目标冲突未察觉。

## 七、与开源书/权威来源对应
Ng 1999 讨论塑形代价；Rasley 2020 DeepSpeed 支持大规模 RL 训练。

## 八、面试题
问：如何标定塑形权重？答：在验证集扫描权重，使任务目标不被牺牲且收敛加速。

## 九、演进与趋势
自适应权重、基于梯度的塑形重要性估计。

## 十、小结
塑形是低成本引导手段，权重标定决定成败。
