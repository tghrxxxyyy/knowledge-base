# 奖励塑造基本原理

> 对应 Ng 1999 奖励塑造 与 Ouyang 2022 InstructGPT 中格式/长度奖励实践。

## 一、背景与挑战

在强化学习中，稀疏奖励（sparse reward）是常见难题：智能体只在任务终点才收到反馈，中间过程无任何信号，导致探索效率极低、难以收敛。奖励塑造（reward shaping）通过设计稠密的中间奖励信号，为策略提供沿途梯度，引导其更快找到高回报路径。但在大模型对齐（RLHF）场景中，塑形若设计不当会引入偏差——把策略引向「看起来对、实则偏」的次优行为（例如只追求格式漂亮而忽略内容质量）。核心挑战是：如何在不改变任务真正最优解的前提下加速学习。

## 二、核心原理

势函数塑形之所以能保持策略不变，本质是在「单步回报」上叠加了一个保守场（conservative field），类似物理中的势能差——只影响路径的「即时收益感」，不改变终点的相对优劣。理解这一点，就能区分「安全的势函数塑形」与「危险的逐点奖励篡改」。经典解法是「基于势函数（potential-based）的奖励塑造」：在原始奖励 $R$ 上叠加一个只依赖状态势函数 $\Phi$ 的塑形项，使新奖励为：

$$F(s,a,s') = R(s,a,s') + \gamma\Phi(s') - \Phi(s)$$

其中 $\gamma$ 为折扣因子。这一项衡量「从状态 $s$ 到 $s'$ 势的提升」。在 RLHF 中，格式奖励、长度惩罚等常被用作塑形项，与可验证奖励互补，帮助模型更快学会符合人类偏好的输出结构，但塑形项必须服务于、而非替代真实任务目标。

## 三、形式化与数学基础

设原 MDP 奖励为 $R$，势函数 $\Phi:\mathcal{S}\to\mathbb{R}$。塑形奖励：

$$F(s,a,s') = R(s,a,s') + \gamma\Phi(s') - \Phi(s)$$

Ng 证明：对任意势函数 $\Phi$，策略 $\pi^*$ 在 $R$ 下最优当且仅当它在 $F$ 下最优。直观上，塑形项在「轨迹层面」相互抵消：一条完整轨迹上 $\sum_t[\gamma\Phi(s_{t+1})-\Phi(s_t)] = \gamma\Phi(s_{final})-\Phi(s_0)$，仅依赖端点，不改变各动作的相对优劣。若塑形项不是势函数形式（如直接加 $\Phi(s')$ 而无 $-\Phi(s)$），则会改变最优解，须谨慎。

## 四、代码实现

```python
# 势函数奖励塑造
def shaped_reward(r, s, s_next, phi, gamma=0.99):
    return r + gamma * phi(s_next) - phi(s)

# RLHF 中常见塑形：格式 + 长度
def rlhf_shaped(r_task, text, w_fmt=0.1, w_len=0.001, max_len=2048):
    fmt = 1.0 if has_valid_format(text) else 0.0
    length_penalty = max(0, len(text) - max_len) * w_len
    return r_task + w_fmt * fmt - length_penalty
```

## 五、与其他技术对比

| 技术 | 是否改最优 | 成本 | 作用 |
|------|-----------|------|------|
| 势函数塑形 | 否 | 低 | 加速收敛 |
| 直接加奖励 | 是 | 低 | 易偏 |
| 可验证奖励 | 否（若准确） | 中 | 强约束 |
| 奖励模型 | 近似 | 高 | 主观任务 |

势函数塑形是安全加速；直接加奖励则危险，可能悄悄重定向最优策略。

## 六、常见误区

- 把塑形项永久保留：即使势函数形式，若目标变化，残留塑形会导致分布偏移，应适时退火。
- 误用非势函数塑形：缺少 $-\Phi(s)$ 项会改变最优策略，造成隐蔽次优。
- 势函数与最终目标冲突：例如势函数鼓励「长输出」，与目标「简洁准确」相悖。
- 认为塑形可替代真实奖励：它只是引导，最终质量仍由 $R$ 决定。
- 所有任务套同一权重：不同任务对格式/长度的敏感度差异巨大。

## 七、与开源书·权威来源对应

- Ng et al., *Policy Invariance under Reward Transformations* (1999) 证明势函数塑形的策略不变性。
- Ouyang et al., *InstructGPT* (2022) 在 RLHF 中使用格式与长度相关的塑形式信号。
- 相关亦见 Sutton & Barto《Reinforcement Learning》奖励设计章节，以官方最新文档为准。

## 八、面试题

问：何种塑造不改变最优策略？
答：基于势函数的塑造，只要满足 $F=R+\gamma\Phi(s')-\Phi(s)$，对任意 $\Phi$ 均保持最优策略不变。

问：势函数塑形与直接加奖励有何本质区别？
答：前者是相邻状态势差，在轨迹端点抵消；后者直接偏移每步回报，改变最优解。

问：若势函数选错（与任务目标冲突）会怎样？
答：塑形项虽保持「策略不变性」形式，但最优轨迹被势函数牵引，最终收敛到势函数定义的次优解，而非真实任务最优。

## 九、演进与趋势

- 学习型势函数：用网络拟合 $\Phi$，自适应地为不同状态提供塑形。
- 自适应塑形权重：根据训练进度与验证表现动态调整，避免过强引导。
- 与课程学习结合：先强塑形引导结构，后弱化以回归真实目标。
- 将塑形项与 KL 约束联合优化，避免塑形把策略推离参考分布。
- 在多目标对齐中，用帕累托塑形平衡「有用、无害、诚实」三者。

- 势函数可从人类反馈中离线学习，减少手工设计。
- 在多智能体对齐中，塑形可协调子目标避免相互掣肘。
- 元学习（meta-learning）用于快速适配新任务的塑形策略。
- 塑形与安全约束联合：把「无害」作为势函数的一部分。
- 理论前沿探讨「非平稳势函数」下策略不变性的边界条件。

## 十、小结

奖励塑造以势函数加速训练且不改最优性，是 RLHF 中常用的低成本引导技巧。其精髓在于「只提供沿途梯度、不重定义目标」，核心公式是相邻状态势差 $F=R+\gamma\Phi(s')-\Phi(s)$。实践中须避免非势函数偏移与永久残留，确保任务目标始终主导，并以退火与 KL 约束收尾。
