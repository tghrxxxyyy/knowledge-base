# 奖励模型过优化分析

> 对应 Gao 2022 奖励模型过优化 与 Ziegler 2019 RLHF 早期实验。

## 一、背景与挑战

在 RLHF 中，我们并不直接优化「真实人类偏好」，而是先训练一个奖励模型 $r_\phi$ 去近似它，再让策略最大化 $r_\phi$。问题在于：奖励模型只是真实目标 $r^*$ 在有限数据上的不完美估计。随着策略被持续推向 $r_\phi$ 的高分区域，它终会探索到奖励模型的「分布外（OOD）」盲区——那里 $r_\phi$ 给出的分数与真实质量严重脱节。于是出现一个反直觉的现象：真实质量（用真实人类评估或强模型判定）先随训练上升，到达拐点后反而下降，而奖励模型分数却一路虚高。这一现象称为「奖励过优化（reward overoptimization）」，也是 Goodhart 定律在 RLHF 中的具体体现。它的危害在于「静默」：训练日志上指标一切向好，实际产品却在偷偷退化。

## 二、核心原理

过优化的严重程度与奖励模型的容量、训练数据覆盖度强相关：容量越小、覆盖越窄，越容易在少量优化步内被「骗高」，这也解释了为何小奖励模型在 RLHF 中更易过优化。监控时应重点关注「奖励模型分数」与「真实质量」之间的剪刀差，它比任一单独指标都更能预示风险。其机制在于分布漂移：初始策略 $\pi_{ref}$ 附近，奖励模型在其训练分布内，打分可靠；但当策略偏离参考策略越来越远（KL 偏离增大），生成的样本越来越「异常」（如堆砌某些高分词藻、模式化奉承），奖励模型仍机械地给高分，真实质量却崩塌。关键是奖励模型缺乏「不确定性感知」——它对分布外样本不是给出低分，而是给出错误高分。因此「最大化奖励模型分数」与「最大化真实质量」在偏离足够大后背道而驰。

## 三、形式化与数学基础

设策略相对参考策略的 KL 偏离为 $k=\mathbb{D}_{KL}(\pi_\theta\|\pi_{ref})$。真实得分 $R^*(k)$ 随 $k$ 先增后减，可建模为关于最优偏离 $k^*$ 的凹函数：

$$R^*(k) = R^*_{max} - \alpha (k - k^*)^2$$

存在最优 $k^*$ 而非越大越好。奖励模型观测得分 $\hat R(k)$ 则近似单调上升（因为它被策略「骗」得越来越高），二者差距 $\hat R(k)-R^*(k)$ 即过优化缺口，随 $k$ 增大而扩大。这解释了为何单纯追高分有害：当 $k>k^*$ 后真实质量下降。Gao 等人进一步给出「best-of-n」与 RLHF 的缩放律：随着 n（或优化强度）增大，真实质量同样呈现先升后降，且奖励模型容量越小、拐点越早。

## 四、代码实现

```python
# 记录 KL 偏离与真实得分，定位过优化拐点
def track(kl_list, rm_score, true_score):
    # 返回 (kl, rm_score, true_score) 序列，用于绘图
    return list(zip(kl_list, rm_score, true_score))

def find_optimal_kl(kl, true_score):
    # 真实得分开始下降处即为最优 KL
    best_k, best = kl[0], true_score[0]
    for k, s in zip(kl, true_score):
        if s > best:
            best, best_k = s, k
    return best_k   # 早停/约束的目标 KL

def overopt_gap(rm_score, true_score):
    # 过优化缺口：奖励虚高但真实质量未同步
    return [r - t for r, t in zip(rm_score, true_score)]
```

## 五、与其他技术对比

| 方法 | 对过优化的处理 | 机制 |
|------|----------------|------|
| PPO + KL 惩罚 | 显式限制偏离 | 约束 $k$ 不超 $k^*$ |
| DPO | KL 嵌入损失 | 隐式约束偏离 |
| KTO | 仅用对错信号 | 降低对 RM 依赖 |
| 奖励集成 | 降方差 | 多模型平均减错 |
| Best-of-n | 静态过优化 | 选 RM 最高，无约束 |

KL 约束是抑制过优化的通用杠杆；Best-of-n 则是过优化本身的典型样本。

## 六、常见误区

- 盲目追求奖励模型高分：高分恰是过优化的征兆，而非成功标志。
- 未在验证集监控真实质量：只看 $\hat R$ 会误判训练向好。
- 把 KL 当固定超参：最优 $k^*$ 随任务/数据变化，应实测而非拍脑袋。
- 忽视奖励模型不确定性：OOD 区域分数不可信却仍被用作梯度。
- 认为更大 RM 就免疫：近似误差永远存在，规模只推迟而非消除拐点。

## 七、与开源书·权威来源对应

- Gao et al., *Scaling Laws for Reward Model Overoptimization* (2022) 量化了过优化拐点与 KL 的关系，给出「best-of-n」「RLHF 缩放律」。
- Ziegler et al., *Fine-Tuning Language Models from Human Preferences* (2019) 早期展示 RLHF 中奖励最大化与质量的张力。
- 相关亦见 InstructGPT 对 KL 惩罚的使用，以及 Goodhart 定律在控制论中的「目标替代」研究，以官方最新文档为准。

## 八、面试题

问：如何发现过优化？
答：绘制策略偏离参考的 KL 与人工/真实评分曲线，真实质量开始下降的拐点即过优化起点；同时会观察到奖励模型分数仍上升而真实质量回落。

问：为何 KL 约束能缓解过优化？
答：KL 限制策略偏离分布内区域，使奖励模型保持可靠，避免进入其 OOD 盲区。

问：best-of-n 采样与 RLHF 过优化有什么关系？
答：best-of-n 用奖励模型挑最优，本质是静态过优化，其质量随 n 增大先升后降，与 RLHF 中 KL 偏离的规律同源。

## 九、演进与趋势

- 早停于最优 KL：用验证集真实质量动态决定停止点，而非固定步数。
- 奖励模型集成 + 不确定性估计：对高不确定样本自动降权，压缩 OOD 高分区。
- 过程奖励模型（PRM）在关键节点给分，压缩可被黑客的结果奖励空间。
- 在线奖励建模（online RM）：边部署边用人类反馈更新 RM，缓解分布漂移。
- 对抗式奖励训练：用红队样本显式拉低 OOD 高分区域，扩大可靠区。

- 早停策略从固定步数转向基于验证集真实质量的动态早停。
- 在线奖励建模（online RM）边部署边更新，缓解分布漂移。
- 对抗式奖励训练用红队样本显式拉低 OOD 高分区。

## 十、小结

过优化是 RLHF 的核心风险：奖励模型在分布外给出错误高分，使真实质量先升后降。KL 约束将偏离限制在分布内、早停于最优 $k^*$ 是关键手段。监控「奖励模型分数」与「真实质量」的背离（剪刀差），是识别过优化的不二法门，也是所有对齐训练不可或缺的仪表盘。
