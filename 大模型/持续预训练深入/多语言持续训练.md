# 多语言持续训练

> 对应 Conneau et al., *Unsupervised Cross-lingual Representations (XLM-R)*, 2019–2020 与多语言数据采样策略实践。

## 一、背景与挑战

多语言模型在持续训练中加入低资源语言数据时面临「数据失衡」难题：高资源语言（如英语）语料规模常是低资源语言的成千上万倍，若按原始比例混合，低资源语言信号会被完全淹没，模型几乎学不到该语言。此外，共享词表对低频语言覆盖不足，新语言 token 缺失会切碎语义。多语言持续训练的核心目标是在不牺牲高资源语言性能的前提下，提升低资源语言的表征与下游能力。

## 二、核心原理

关键技术是**温度采样（temperature / temperature sampling）**：各语言不再按原始数据量均匀抽样，而是对每语言样本数 $n_l$ 做幂次缩放：

$$
q_l \propto n_l^{\alpha},\qquad \alpha\in(0,1]
$$

其中 $\alpha$ 为采样温度（常见 0.3~0.7）。$\alpha=1$ 退化为原始比例（高资源主导），$\alpha\to 0$ 趋近均匀采样。通过调小 $\alpha$，低资源语言被提权，从而获得更多更新机会。实践中还要配合**词表扩展**：为新增语言合并 tokenizer 词表并随机初始化新嵌入，再用适度训练使其收敛。

## 三、形式化与数学基础

设语言集合 $\mathcal{L}$，各语言原始样本数 $n_l$，温度采样下第 $l$ 语言被选中的概率为：

$$
p_l = \frac{n_l^{\alpha}}{\sum_{l'\in\mathcal{L}} n_{l'}^{\alpha}}
$$

训练时每个 batch 按 $\{p_l\}$ 构造多语言 mini-batch。另一种常用策略是「温度 + 上限封顶」：先对单语言每 epoch 采样量做封顶，避免高资源过度主导。语言间迁移还受益于**脚本共享**：同语系语言（如罗曼语族）在共享子词空间上互相正迁移，而差异大的语言（如中文 vs 阿拉伯语）则需更大词表容量。

## 四、代码实现

```python
import math

def temperature_sample_weights(counts, alpha=0.5):
    # counts: dict {lang: num_samples}
    weights = {l: math.pow(n, alpha) for l, n in counts.items()}
    total = sum(weights.values())
    return {l: w / total for l, w in weights.items()}

# 构造采样器：按权重为每个语言分配 batch 配额
weights = temperature_sample_weights({"en": 1e9, "sw": 1e5, "cy": 5e4}, alpha=0.5)
```

## 五、与其他技术对比

| 策略 | 低资源提升 | 高资源保持 | 实现复杂度 |
|------|------------|------------|------------|
| 均匀采样 | 差（被淹没） | 好 | 低 |
| 温度采样 | 好 | 较好 | 中 |
| 上限封顶 + 温度 | 好 | 好 | 中高 |
| 逐语言独立模型 | 最优单语 | 无共享 | 高 |

## 六、常见误区

- 直接用原始比例混合：低资源语言几乎学不到，是最常见的失败模式。
- 只加数据不扩词表：新语言 token 被切成字符/字节，语义破碎。
- $\alpha$ 过小：低资源过度提权反而损害高资源与整体稳定性，需调参。
- 忽视脚本与语系差异：把所有低资源语言等权可能无效的语对占用预算。

## 九、演进与趋势

从 XLM-R 的静态多语言平衡，到「按需持续扩容」新语言、结合语言 ID 嵌入、以及用平行语料做跨语言对齐增强。前沿还探索「语言无关子空间」与零样本跨语言迁移的更稳配方。以官方最新文档为准。

**实践要点：**

- 温度 $\alpha$ 建议从 0.3 起网格搜索，过低损害高资源、过高低资源学不透，需双轨评估确定。
- 新语言词表扩展后，新 token 嵌入可用同语系已有 token 嵌入均值初始化，加速收敛。
- 可在高资源语言上做「回译/数据增强」扩充低资源平行信号，缓解语料稀缺。
- 持续监控各语言验证 PPL，发现某语言异常升高及时回退或调整采样权重。

## 十、小结

多语言持续训练靠温度采样平衡资源差距、靠词表扩展补齐表示，方能在不牺牲高资源性能的同时提升低资源语言；$\alpha$ 与词表策略是落地的两大旋钮。
