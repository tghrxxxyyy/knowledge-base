# 长程持续训练

> 对应 Rae et al., *Scaling Language Models (Gopher)*, 2021 与多阶段预训练数据课程实践（如 Llama、DeepSeek 训练配方）。

## 一、背景与挑战

现代大模型很少「一次性」训完，而是经历**多阶段、长程持续训练**：先通用语料打基础，再逐步引入代码、数学推理、长上下文、最后对齐。这种课程式（curriculum）调度能在有限算力下把能力提升到单阶段难以达到的水平。难点在于：阶段间数据分布差异大，若突变易导致训练不稳、损失突跳；学习率与数据配比需平滑过渡，否则已学能力会塌缩或遗忘。

## 二、核心原理

长程持续训练把训练划分为若干阶段 $S_1\to S_2\to\cdots\to S_k$，每阶段有独立的数据配比 $\mathcal{D}_s$、序列长度 $L_s$ 与学习率 $lr_s$。核心原则：

- **数据分布渐变**：相邻阶段的数据域不应突变，常用「重叠过渡桶」混合两阶段比例，避免损失尖峰。
- **学习率阶梯递减**：随训练推进整体 LR 下降，长上下文阶段可小幅回升以适配更长序列。
- **序列长度递增**：早期短序列（如 2k）提吞吐，后期逐步拉长到 8k/32k/128k 以学长程依赖。
- **两阶段后再对齐**：基础能力到位后再做 SFT / RLHF，避免对齐税过高。

## 三、形式化与数学基础

设总训练 token 预算 $T$，分 $k$ 阶段各占比例 $\rho_s$，$\sum_s\rho_s=1$。第 $s$ 阶段数据分布为 $\mathcal{D}_s$，其混合权重可在过渡区间与上一阶段插值：对边界附近 step $t$，混合系数 $\lambda_t$ 从 1 线性过渡到 0：

$$
\mathcal{D}(t) = (1-\lambda_t)\mathcal{D}_{s-1} + \lambda_t \mathcal{D}_{s},\quad \lambda_t\in[0,1]
$$

学习率随阶段递减：

$$
lr_s = lr_0 \cdot \gamma^{s-1},\qquad \gamma\in(0,1]
$$

序列长度随阶段提升 $L_s = L_{s-1}\cdot \eta$，但长序列下 batch token 数需相应调整以控显存。

## 四、代码实现

```python
# 阶段调度：根据已训练 token 数切换数据配比与序列长度
def stage_schedule(tokens_seen, plan):
    # plan: [(until_tokens, datamix, seq_len, lr)]
    for until, mix, seq, lr in plan:
        if tokens_seen < until:
            return mix, seq, lr
    return plan[-1][1:]

# 过渡混合：相邻阶段按比例插值 datamix
mix_prev, mix_next = plan[s-1].mix, plan[s].mix
lam = (tokens_seen - plan[s].start) / plan[s].length
current_mix = interpolate(mix_prev, mix_next, lam)
```

## 六、常见误区

- 阶段间数据突变：损失尖峰、训练发散，必须渐变过渡。
- 长上下文一步拉满：显存与注意力不稳定，应分阶段递增序列长度。
- 对齐前置：过早 RLHF 再继续预训练会抬高对齐税、遗忘对齐。
- 忽略阶段间学习率衔接：突变 LR 同样引发不稳定。

## 九、演进与趋势

从「数据一次性混合」到「课程式多阶段 + 长上下文退火」，再到「退火阶段注入高质量数据提升收尾质量」（如重要度采样退火）。前沿还研究自动阶段搜索与动态数据配比。以官方最新文档为准。

**实践要点：**

- 阶段边界用「重叠过渡桶」混合相邻阶段数据，避免损失尖峰；过渡长度常取该阶段 5%~10% 步数。
- 长上下文阶段可单独做「位置插值（RoPE scaling）」再续训，确保外推到目标长度稳定。
- 退火阶段（训练末尾）提高高质量数据比例，常能显著提升收尾表现，称为数据退火。
- 各阶段学习率应平滑衔接，长上下文阶段可小幅回升以适配更长序列的优化地形。

## 十、小结

长程持续训练以分阶段、渐变调度的课程式方案，在固定算力下最大化模型能力；平滑过渡、LR 递减、序列递增与「对齐置后」是其稳定与高效的关键。
