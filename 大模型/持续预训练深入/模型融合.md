# 模型融合 Model Merging

> 合并多个模型的实践能力。

## 一、核心概念

- **SLERP/线性插值**：两模型权重按系数混合。
- **Task Arithmetic / TIES / DARE**：先对任务向量(task vector)做稀疏化/符号一致再合并，支持多任务合并而不互相抵消。
- **MergeKit**：开源合并工具箱。

## 二、关键要点

- 直接平均常劣化，需符号对齐(TIES)。
- 合并可免重新训练组合能力。

## 三、与开源书的对应

- Yadav et al., *TIES-Merging*, 2023; Yu et al., *DARE*, 2024.
