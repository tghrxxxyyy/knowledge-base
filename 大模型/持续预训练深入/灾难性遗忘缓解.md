# 灾难性遗忘缓解

> 对应 Kirkpatrick et al.(2017, EWC)、 continual pretraining 实践与 Hugging Face PEFT 文档。

## 一、背景与挑战

大模型完成预训练后，常需在新领域语料上继续训练（领域自适应、持续预训练 continual pretraining），让模型吸收新知识而不丢失通用能力。但神经网络在分布偏移的数据上继续优化时，会覆盖旧任务权重，导致已掌握的知识急剧退化，这就是「灾难性遗忘（catastrophic forgetting）」。在 LLM 场景下遗忘尤为隐蔽：模型不会显式报错，而是悄悄丢失某些语言现象、事实或指令遵循能力。持续预训练通常数据量大、训练步数多，若全参数继续训练，遗忘几乎不可避免。工程上还面临两难：回放旧数据可能触及版权或隐私，冻结全部参数又学不到新东西，因此需要在「学新」与「守旧」之间取得平衡。

## 二、核心原理

主流缓解思路可归为四类：

- **经验回放（Replay）**：在继续训练时混入一部分旧数据或生成的「回放样本」，让优化目标同时包含新旧分布。
- **正则约束（Regularization）**：对重要参数施加惩罚，使其偏离旧值成本更高，代表方法 EWC、L2（冻结部分）、SI。
- **参数高效微调（PEFT）**：只训练新增的 adapter / LoRA 等少量参数，基座权重冻结，从根本上隔离新旧知识。
- **模型融合（Model Merging）**：分别训练新旧模型再对权重做插值/合并（如 model soup、TIES-merging），保留两侧能力。

实践中常组合使用，例如「LoRA 续训 + 少量旧数据回放」。

### 典型实践配方

- **LoRA 续训 + 5%~10% 旧数据回放**：最常用落地组合，冻结基座、仅训 adapter，旧数据按小比例混入防分布漂移。
- **EWC 仅作用于关键层**：对 embedding 与浅层加正则、深层放开，兼顾抗遗忘与学新能力。
- **阶段式数据混合（annealing）**：训练初期旧数据多、后期新数据多，平滑遗忘曲线。
- **双模型合并**：分别训新旧后做 TIES-merging 方向对齐再平均，避免直接平均互相抵消。
- **监控旧任务指标**：训练中用少量旧样本做验证集，早停或回灌当指标跌破阈值。
- **容量分配**：新领域差异大时增大 LoRA rank 或增加可训层，差异小时保持小容量防过拟合旧数据。

## 三、形式化与数学基础

以 EWC 为例，它用 Fisher 信息矩阵近似参数重要性，在损失中加入二次惩罚：

$$
\mathcal{L}_{\text{EWC}} = \mathcal{L}_{\text{new}}(\theta) + \frac{\lambda}{2} \sum_i F_i (\theta_i - \theta_i^*)^2
$$

其中 $\theta_i^*$ 是旧任务收敛参数，$F_i = \mathbb{E}\left[\left(\frac{\partial \log p_{\theta}(x)}{\partial \theta_i}\right)^2\right]$ 为对角 Fisher 信息，衡量参数对旧数据似然的重要性。权重更新受约束：

$$
\Delta \theta_i \propto -\frac{\partial \mathcal{L}_{\text{new}}}{\partial \theta_i} - \lambda F_i (\theta_i - \theta_i^*)
$$

PEFT 则可视为把优化限制在低秩子空间 $\theta = \theta_0 + \Delta W = \theta_0 + BA^\top$，其中 $B\in\mathbb{R}^{d\times r}, A\in\mathbb{R}^{r\times k}$，$r\ll d$，可训练参数量骤降。

## 四、代码实现

用 PEFT 做「冻结基座 + LoRA 续训」，天然抗遗忘：

```python
from peft import LoraConfig, get_peft_model
from transformers import AutoModelForCausalLM, TrainingArguments

model = AutoModelForCausalLM.from_pretrained("base-model")
cfg = LoraConfig(
    r=8, lora_alpha=16, lora_dropout=0.05,
    target_modules=["q_proj", "v_proj"], task_type="CAUSAL_LM",
)
model = get_peft_model(model, cfg)          # 仅 LoRA 参数可训
model.print_trainable_parameters()          # 通常 <1% 参数

# TrainingArguments + Trainer 在标准语料上续训
# 可选：DataLoader 中按 9:1 混入旧数据做轻量 replay
```

若用回放，可在数据集构造时把旧样本按一定比例拼入新 batch。

## 五、与其他技术对比

| 方法 | 额外数据 | 显存开销 | 抗遗忘 | 学新知识 |
|------|----------|----------|--------|----------|
| 全参数续训 | 无需 | 高 | 弱 | 强 |
| Replay | 需旧数据 | 高 | 中 | 强 |
| EWC 正则 | 无需 | 高 | 中 | 中 |
| LoRA/Adapter | 无需 | 低 | 强 | 中 |
| 模型融合 | 需双模型 | 中 | 强 | 中 |

可见 PEFT 在「低成本 + 强抗遗忘」上最均衡，但表达上限受限于新参数容量。

## 六、常见误区

- **误以为 LoRA 完全不遗忘**：LoRA 仍可能通过注意力偏移间接影响旧行为，且容量过小时学不进新知识。
- **回放比例越高越好**：过高会压低新领域学习速度，需按分布差距调参。
- **EWC 一定优于 L2**：在小模型上差异有限，且 Fisher 估计有噪声，大模型下 PEFT 更稳。
- **融合能无代价叠加能力**：不同训练轨迹的权重直接平均常互相抵消，需做方向对齐（TIES）。

## 九、演进与趋势

早期以正则与回放为主，近年开始转向「参数隔离 + 模型编辑」：如用 LoRA 阵列为每个领域分配一组适配器，推理时按路由激活；或采用 model merging 把多个续训模型能力合并到单一权重。另一条线是「持续预训练 + 课程式数据混合」，通过逐步调整新旧数据比例（annealing）平滑遗忘曲线。未来趋势是把遗忘缓解做成训练框架的一等公民，而非事后补救。

## 十、小结

灾难性遗忘是 LLM 持续预训练的核心难题。工程上最实用的是「PEFT（LoRA/Adapter）+ 轻量回放」组合：以极小可训参数隔离新旧知识，用少量旧数据稳住分布。EWC 等正则方法提供理论保障但落地成本较高。选型时应按「数据可得性、显存预算、领域差距」三要素权衡，并配合混合权重或模型融合兜底。
