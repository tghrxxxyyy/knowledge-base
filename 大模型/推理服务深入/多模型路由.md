# 多模型路由

> 见「推理服务深入/推理服务架构」与「大模型网关与流量管控实战」(顶层)。

## 一、背景与挑战

不同任务适配不同模型/尺寸，需路由降本提效。

## 二、核心原理

按任务类型/复杂度/成本，把请求路由到合适模型（小模型兜底、大模型攻坚），配合缓存与降级。

## 三、关键要点

- 路由策略可基于规则或学习。
- 需监控各模型负载。

## 四、代码实现

```python
model = router.select(task=type, cost_budget=user.tier)
```

## 五、与其他对比

- 单一大模型简单但贵；路由省成本。

## 六、常见误区

- 路由必省钱——误路由反而更差。
