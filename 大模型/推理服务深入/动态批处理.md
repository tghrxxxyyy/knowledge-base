# 动态批处理

> 见「推理优化/连续批处理」与「推理服务深入/推理服务架构」。

## 一、背景与挑战

静态批处理浪费（等长填充、空等），GPU 利用率低。

## 二、核心原理

continuous batching：每步动态把就绪请求组批，完成即退出、新请求随时加入，最大化吞吐、降排队。

## 三、数学形式

吞吐 ≈ (batch_size × seq_len) / step_time，dynamic 逼近理论上限。

## 四、代码实现

```python
# vLLM 自动 continuous batching
llm = LLM(model="x"); out = llm.generate(prompts)
```

## 五、关键要点

- 需 PagedAttention 支撑变长。
- 延迟与吞吐需平衡配置。

## 六、与其他对比

- 静态批：固定组、等长；动态：随时进出。

## 七、常见误区

- 批越大越好——延迟上升、OOM。
