# 视觉常识推理

> 对应 Zellers et al., *VCR*, 2019；需要常识的视觉推理。

## 一、背景与挑战

仅看图像不足以回答“为何/下一步会怎样”，需外部常识与社会关系知识。

## 二、核心原理

VCR 等任务要求模型在选项外还给出理由（rationale），迫使模型结合视觉与社会常识推理。方法常引入外部知识或大模型常识。

## 三、数学形式

联合答案与理由：

$$p(a,r|I,q) = p(a|I,q)\,p(r|I,q,a)$$

(r 为理由)。

## 四、代码实现

```python
logits_a = model(I, q, candidates="answer")
logits_r = model(I, q, candidates="rationale")
```

## 五、与其他对比

- 与 视觉推理方法 共享推理，更重常识。
- 与 多模态链式推理 可用链式引入常识。

## 六、常见误区

- 用视觉线索猜答案忽略常识必要。
- 理由与答案不一致。

## 八、面试题

- 视觉常识推理特别在哪？答：需超越像素的社会/物理常识，单纯视觉特征不足。

## 九、演进

感知 QA → 理由标注 → 常识大模型。

## 十、小结

视觉常识推理引入外部知识需求，是迈向真正理解的一步。
