# 多模态链式推理

> 对应 Chain-of-Thought 在多模态的延伸（如 CoT / rationale 生成）；思维链。

## 一、背景与挑战

复杂多模态问题直接给答案易错，分步思考可提升准确率与可解释性。

## 二、核心原理

让模型先输出中间推理步骤（描述所见、定位、子结论），再给最终答案；可用“先推理再答”的提示或训练数据显式含 rationale。视觉链式常结合 OCR/检测中间结果。

## 三、数学形式

链式分解：

$$p(a|I,q)=\sum_{z}p(a|z,I,q)\,p(z|I,q)$$

对中间推理 $z$ 边际化（训练时显式监督 $z$）。

## 四、代码实现

```python
prompt = "先逐步观察图像再回答："
chain = model.generate(I, prompt)
answer = extract_final(chain)
```

## 五、与其他对比

- 与 视觉推理方法 共享分步思想（软提示版）。
- 与 多模态指令微调深入 共享训练范式。

## 六、常见误区

- 链式步骤空泛无依据，反而误导。
- 把链式当万能，简单题也强制多步致慢。
