# 视觉推理方法

> 对应 Hudson & Manning, *GQA: Compositionality in Visual QA*, CVPR 2019；组合推理。

## 一、背景与挑战

真实问题常需多步推理（如“左侧红杯右边的物体”），单跳模型易错，需结构化组合能力。

## 二、核心原理

方法：组合推理数据集（GQA 提供场景图与程序标注）、模块化网络（各子函数组合）、以及用 LLM/链式提示把问题拆为子步骤再逐步回答。

## 三、数学形式

组合推理可写为程序执行：

$$a = \text{exec}\big(\pi(q), \text{scene}(I)\big),\quad \pi(q)=\text{parse}(q)$$

$\pi$ 把问题解析为操作序列。

## 四、代码实现

```python
steps = planner(question)            # 分解子问题
for s in steps:
    ans = reason_step(I, s)
```

## 五、与其他对比

- 与 多模态链式推理 共享分步思想。
- 与 模块化与神经符号 衔接符号执行。

## 六、常见误区

- 把组合问题当整体分类，缺乏可解释性。
- 子步骤错误累积无校验。

## 八、面试题

- 组合推理为何难？答：需把问题拆为依赖子操作并在图上顺序执行，任一步错则最终错。

## 九、演进

整体分类 → 程序执行 → LLM 链式分解。

## 十、小结

视觉推理要求组合与多步能力，数据集与模块化是关键支撑。
