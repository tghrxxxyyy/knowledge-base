# 视觉问答评测基准

> 对应 VQA / GQA / CLEVR / TextVQA / OK-VQA 等基准体系。

## 一、背景与挑战

不同基准考察不同能力（感知/组合/计数/OCR/知识），单一榜单无法全面评估。

## 二、核心原理

分类：感知类（VQA v2）、组合类（GQA/CLEVR）、OCR 类（TextVQA）、知识类（OK-VQA）、文档类（DocVQA）。指标常用准确率（VQA 软准确率）与组合分项。

## 三、数学形式

VQA 软准确率：

$$\text{Acc}=\min\big(1, \frac{\#\text{humans said }a}{3}\big)$$

对多人标注答案取软匹配。

## 四、代码实现

```python
def vqa_acc(pred, humans):
    return min(1.0, sum(1 for h in humans if h==pred)/3)
```

## 五、与其他对比

- 与 评测与失败模式 共享评测主题。
- 与 文档图像理解深入 的 DocVQA 衔接。

## 六、常见误区

- 在一个基准强就声称通用，忽视能力偏斜。
- 软准确率对近义答案不敏感。

## 八、面试题

- 各 VQA 基准区别？答：分别考察感知/组合/OCR/外部知识，需针对性能力。

## 九、演进

单基准 → 多能力套件 → 综合排行榜。

## 十、小结

VQA 评测需多基准组合，分项揭示模型真实能力结构。
