# 模块化与神经符号

> 对应 Andreas et al., *Neural Module Networks*, 2016；神经符号结合。

## 一、背景与挑战

端到端黑盒难解释、难组合；模块化把推理分解为可组合神经模块，兼顾学习与符号可控。

## 二、核心原理

用解析器把问题转为模块布局（如 find/relocate/compare），每个模块是独立神经网络在特征图上操作，按布局组合得答案。符号结构提供可解释与泛化。

## 三、数学形式

布局组合：

$$a = M_k\big(\dots M_2(M_1(I, q_1), q_2)\dots, q_k\big)$$

$M_i$ 为对应子操作的模块。

## 四、代码实现

```python
layout = parser(question)            # 模块序列
feat = I
for mod, arg in layout:
    feat = MODULES[mod](feat, arg)
```

## 五、与其他对比

- 与 视觉推理方法 共享组合推理。
- 与 多模态链式推理 对照“符号布局 vs 软提示”。

## 六、常见误区

- 模块接口不统一致组合失败。
- 解析器错误直接破坏整条推理。
