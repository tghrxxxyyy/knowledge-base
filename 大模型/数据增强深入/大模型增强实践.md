# 大模型数据增强实践

> 对应 LLM 预训练/微调数据增广；与 指令数据构建深入 / 合成数据质量深入 衔接。

## 一、背景与挑战

大模型数据海量，传统样本级增强意义小；更重去重/合成/质量过滤。

## 二、核心原理

预训练：去重+质量过滤为主；微调/SFT：指令改写/自生成扩展、回译、模板多样。

## 三、数学形式

有效数据量 $N_{eff}$ 经去重/质量加权；增强主要用于小场景 SFT。

## 四、代码实现

```python
# SFT 指令多样化
aug = llm_rephrase(instruction, n=3)
dataset += [(a, same_out) for a in aug]
```

## 五、与其他对比

- 与 训练数据质量 / 指令数据构建深入 共享数据治理。
- 与 数据高效学习深入 互补。

## 六、常见误区

- 预训练盲目增广致噪声放大。
- 合成增强不校验质量致退化。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course
- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 大模型为何少用样本级增强？答：数据已海量，重点在质量/去重，增广多用于小 SFT。

## 九、演进

样本增强 → 质量过滤/去重 → 合成增强。

## 十、小结

大模型增强重心从样本变换转向质量治理与合成扩展。
