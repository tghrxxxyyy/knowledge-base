# 自然语言数据增强

> 对应 EDA / 回译 / 同义替换；与 指令数据构建深入 衔接。

## 一、背景与挑战

文本离散、增强易改语义；需保留标签的轻量变换。

## 二、核心原理

EDA（同义替换/随机插入删除交换）、回译（翻译往返）、模板填充、上下文增广（PLM 掩码填充）。

## 三、数学形式

回译：$x'\sim p_{back}(x)$ 经目标语再译回；保留 $y$ 的概率高但非绝对。

## 四、代码实现

```python
x_en = translate(x, "en"); x_back = translate(x_en, src_lang)
```

## 五、与其他对比

- 与 合成数据质量深入（生成式增广）互补。
- 与 训练数据质量 共享清洗。

## 六、常见误区

- 同义替换改关键实体致标签错。
- 回译引入分布偏移。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- NLP 增强为何谨慎？答：离散文本易改语义/标签，须保任务一致性。

## 九、演进

EDA → 回译 → PLM 上下文增广。

## 十、小结

NLP 增强以保语义为前提，回译与 PLM 填充为主流。
