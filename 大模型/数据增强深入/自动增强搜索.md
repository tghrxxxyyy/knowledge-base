# 自动增强搜索

> 对应 AutoAugment（Cubuk et al., 2018）/ RandAugment。

## 一、背景与挑战

手工策略次优且费时；自动搜最佳增强策略。

## 二、核心原理

把增强策略参数化（子策略/幅度/概率），用强化学习/进化或简化随机（RandAugment）搜索。

## 三、数学形式

策略 $\pi$ 在验证集上最优：$ \pi^*=\arg\max_\pi \text{acc}(A_\pi)$。

## 四、代码实现

```python
policy = search_augment(train, val, n_ops=14)   # AutoAugment
```

## 五、与其他对比

- 与 自动化超参优化深入（搜索范式）共享。
- 与 神经架构搜索深入 共享搜索成本。

## 六、常见误区

- AutoAugment 搜成本高，常直接迁移公开策略。
- 策略过拟合验证集。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- RandAugment 相对 AutoAugment 简化？答：用统一幅度+随机子策略，免昂贵搜索。

## 九、演进

AutoAugment → RandAugment → 学习增强网络。

## 十、小结

自动增强搜索出最优策略，RandAugment 以简化逼近其效果。
