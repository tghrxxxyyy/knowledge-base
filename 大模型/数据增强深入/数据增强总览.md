# 数据增强总览

> 对应 CV/NLP 增强综述；与 训练数据质量 / 数据高效学习深入 衔接。

## 一、背景与挑战

数据不足/分布偏致过拟合；增强以变换扩样、提鲁棒。

## 二、核心原理

CV：几何/色彩/混合（Mixup/CutMix）；NLP：同义词、回译、EDA、模板；音频：加噪/pitch。

## 三、数学形式

Mixup：训练样本 $(\tilde x,\tilde y)=\lambda(x_i,y_i)+(1-\lambda)(x_j,y_j)$，$\lambda\sim Beta$。

## 四、代码实现

```python
lam = beta(0.4,0.4)
x = lam*x1 + (1-lam)*x2
y = lam*y1 + (1-lam)*y2
```

## 五、与其他对比

- 与 正则化与Dropout深入（标签平滑常配合 Mixup）互补。
- 与 数据合成与增强（若新增 合成数据质量深入）衔接。

## 六、常见误区

- 增强过强扭曲语义（尤其文本回译失真）。
- 测试时不增强却训练过强致分布偏移。

## 七、与开源书对应

- d2l-zh 数据增广大章：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- Mixup 为何有效？答：软化标签+邻域插值，隐式正则、提校准与鲁棒。

## 九、演进

几何变换 → 混合样本(Mixup) → 自动增强(AutoAugment)。

## 十、小结

数据增强是低成本正则与鲁棒性来源，需控强度保语义。
