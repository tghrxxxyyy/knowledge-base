# 数据增强与正则关系

> 对应增强作为隐式正则。

## 一、背景与挑战

增强与显式正则（Dropout/权重衰减）如何协同。

## 二、核心原理

增强扩大有效数据分布，等价于对输入施加不变性先验，是数据空间的正则。

## 三、数学形式

期望风险在增强分布上近似：$\mathbb E_{\tilde x\sim A(x)}\mathcal L(f(\tilde x),y)$。

## 四、代码实现

```python
for x,y in loader:
    x_aug = augment(x)        # 在线增强
    loss = crit(f(x_aug), y)
```

## 五、与其他对比

- 与 正则化与Dropout深入 互补（输入空间 vs 参数空间正则）。
- 与 泛化理论深入 共享不变性先验。

## 六、常见误区

- 增强强度与 Dropout 同时过大致欠拟合。
- 测试增强不一致。

## 八、面试题

- 增强为何像正则？答：对输入加不变性先验，等效约束假设空间。

## 九、演进

单增强 → 组合 → 课程式增强（由易到难）。

## 十、小结

增强是数据空间的正则，与参数正则互补控过拟合。
