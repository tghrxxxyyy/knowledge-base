# 去偏技术

> 对应 Bolukbasi 2016 中和/均衡；Dev et al., *Debiasing Tests*, 2020。

## 一、背景与挑战

如何在保能力下去偏。

## 二、核心原理

 Hard 去偏：中性词去偏方向、定义词保留、均衡词对间距；训练侧用反事实数据增强与去偏 SFT/DPO。

## 三、数学形式

中性化：$\tilde v = v - proj_g(v)$；均衡：$\|v_a-g\|=\|v_b-g\|$。

## 四、代码实现

```python
v = v - (v@g)*g   # 去偏方向
```

## 五、与其他对比

- 与 公平性深入（去偏方法）衔接。
- 与 直接偏好优化深入（去偏偏好）相关。

## 六、常见误区

- 嵌入去偏不保证生成去偏。
- 过度去偏损语义。
