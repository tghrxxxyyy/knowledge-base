# 提示去偏（Prompt Debiasing）

> 对应 Si et al., *Prompting for Fairness*, 2022；自我反思去偏。

## 一、背景与挑战

不改模型权重也能减偏，适合黑箱 API。

## 二、核心原理

系统提示声明中立、要求多角度、或让模型先识别自身偏见再答；链式反思降刻板。

## 三、数学形式

去偏后分布 $P_{deb}(a|x)\approx P(a|x, c_{fair})$；$c_{fair}$ 为中立指令。

## 四、代码实现

```python
ans = llm(f"保持中立、避免刻板，先反思再答:\n{q}")
```

## 五、与其他对比

- 与 伦理对齐深入（原则提示）衔接。
- 与 宪法AI深入（条款提示）相关。

## 六、常见误区

- 提示被越狱绕过。
- 中立指令降信息量。
