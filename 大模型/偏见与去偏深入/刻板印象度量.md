# 刻板印象度量

> 对应 Nadeem et al., *StereoSet*, 2020；Nangia et al., *CrowS-Pairs*, 2020。

## 一、背景与挑战

需可量化基准测模型刻板印象强度。

## 二、核心原理

StereoSet 给刻板/反刻板选项测语言模型偏好；CrowS-Pairs 成对最小差异句测相对偏见；指标为偏向率。

## 三、数学形式

刻板得分 $SS=\frac{\#偏向刻板}{\#总数}$；越接近 0.5 越无偏。

## 四、代码实现

```python
for s in stereoset: pref = argmax(p(s.stereo), p(s.anti))
```
