# 偏见来源分析

> 对应 Bender et al., *On the Dangers of Stochastic Parrots*, 2021（数据偏见）。

## 一、背景与挑战

定位偏见根因才能对症；偏见可来自数据、采样、对齐目标。

## 二、核心原理

数据偏见（语料分布）、表示偏见（几何）、标注偏见（人类标注）、反馈偏见（RLHF 讨好多数）。

## 三、数学形式

输出偏 $P(a|g)=\frac{P_{data}(a|g)P_{align}(a|g)}{\sum}$。

## 四、代码实现

```python
for src in [data, annot, align]: probe(src)
```

## 五、与其他对比

- 与 价值对齐深入（反馈偏见）衔接。
- 与 公平性深入（来源）相关。

## 六、常见误区

- 把所有偏差归数据。
- 忽略对齐阶段引入的新偏。

## 十、小结

偏见多源，对齐阶段也会新增，需全链路归因。
