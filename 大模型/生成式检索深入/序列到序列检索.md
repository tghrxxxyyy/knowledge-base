# 序列到序列检索

> 对应 生成式检索的 seq2seq 形式；与 自回归生成深入 共享解码。

## 一、背景与挑战

检索可作为生成任务，需合适解码与约束。

## 二、核心原理

用 encoder-decoder（如 T5）把 query 编码、自回归解码出文档 ID；束搜索取高分；可加前缀约束保证合法 ID。

## 三、数学形式

$p(y|q)=\prod_{t=1}^m p_\theta(y_t|q,y_{<t})$；束搜索 $\hat y=\arg\max_{|y|\le m}\log p(y|q)$。

## 四、代码实现

```python
out = model.generate(**enc, num_beams=4,
                     prefix_allowed_tokens_fn=valid_id)
```

## 五、与其他对比

- 与 迟交互深入（索引式）对比范式。
- 与 检索器训练深入（端到端）衔接。

## 六、常见误区

- 束搜索不产生合法 ID（须约束）。
- 长 ID 解码慢、易截断。

## 七、与开源书对应

- harvardnlp/annotated-transformer：https://github.com/harvardnlp/annotated-transformer
- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 生成式检索如何解码？答：自回归束搜索生成 ID 序列，加约束保证合法映射。

## 九、演进

贪婪 → 束搜索 → 约束/规划解码。

## 十、小结

seq2seq 检索借生成范式去索引，但需约束解码与效率优化。
