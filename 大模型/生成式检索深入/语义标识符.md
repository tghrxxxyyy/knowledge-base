# 语义标识符（Semantic IDs）

> 对应 Rajarshi Das et al., *NCI: Natural Language Index*, 2021；后续语义 ID 工作（TIGER, 2023）。

## 一、背景与挑战

随机原子 ID 无语义，难泛化；语义 ID 由内容聚类生成，带含义可推理。

## 二、核心原理

用文档嵌入做层次聚类（如 RQ-VAE），每文档得一串聚类码作 ID；查询时模型生成语义码再映射到文档，相似文档共享前缀。

## 三、数学形式

$\text{ID}(d)=(\text{cluster}_1(d),..,\text{cluster}_L(d))$；生成概率链式分解 $p=\prod_l p(c_l|q,c_{<l})$。

## 四、代码实现

```python
codes = rqvae.encode(emb)           # 层次聚类码
sem_id = "-".join(map(str, codes))
```

## 五、与其他对比

- 与 DSI 结构化 ID 同源但更语义化。
- 与 嵌入模型训练深入（嵌入聚类）衔接。

## 六、常见误区

- 聚类数/层不当致码冲突或过长。
- 语义 ID 漂移（分布变）需重聚类。

## 八、面试题

- 语义 ID 优势？答：由内容聚类，相似文档共享前缀，助泛化与层次检索。

## 九、演进

原子 ID → 结构化 ID → RQ-VAE 语义 ID。

## 十、小结

语义 ID 把文档内容编码进标识，提升生成式检索泛化与可解释。
