# 生成式检索前沿

> 对应 近期工作：TIGER（语义 ID + 生成）、生成式与稠密混合检索。

## 一、背景与挑战

如何把生成式优势（端到端、可推理）与传统检索互补。

## 二、核心原理

混合：生成式出候选 ID + 稠密检索重排；或用检索增强的生成式（先召回再生成 ID）；统一框架端到端。

## 三、数学形式

混合分 $s=\alpha\cdot s_{gen}(q,id)+(1-\alpha)\cdot s_{dense}(q,d)$。

## 四、代码实现

```python
cands = generative_retriever(q, 20)
fused = rerank(q, [doc_store[i] for i in cands], 5)
```

## 五、与其他对比

- 与 混合检索深入（融合两路）共享思想。
- 与 嵌入模型训练深入 互补。
