# 生成式检索（Generative Retrieval）总览

> 对应 Tay et al., *DSI: Transformer Indexes for Sequence*, 2022；Metzler et al., 生成式检索综述。

## 一、背景与挑战

传统检索靠外部索引；生成式检索让模型直接生成目标文档标识符，去索引化、可端到端训练。

## 二、核心原理

把检索建模为 seq2seq：输入 query，输出文档 ID（如原子 ID、数值 ID 或语义 ID）；模型在参内记忆文档表示。

## 三、数学形式

目标 $p_{\theta}(y^*|q)$，其中 $y^*$ 为目标文档标识符序列；训练最大似然 $\sum\log p_{\theta}(y_t^*|q,y_{<t}^*)$。

## 四、代码实现

```python
out = seq2seq.generate(query, max_new_tokens=8)   # 直接生成 doc id
doc = id_map[out]
```

## 五、与其他对比

- 与 双塔模型深入（需外部索引）根本不同。
- 与 稠密检索训练深入（索引式）对照范式。

## 六、常见误区

- 长尾/新文档难生成（覆盖问题）。
- 幻觉生成不存在的 ID；需约束解码。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh
- rasbt/LLMs-from-scratch：https://github.com/rasbt/LLMs-from-scratch

## 八、面试题

- 生成式检索为何去索引？答：模型参数内记忆文档，query 直接解码 ID，无外部索引。

## 九、演进

索引检索 → DSI → 语义 ID 生成式。

## 十、小结

生成式检索以 seq2seq 去索引化，但受覆盖与幻觉挑战。
