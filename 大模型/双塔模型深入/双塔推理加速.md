# 双塔推理加速

> 对应 Johnson et al., *FAISS*, 2019；Ni et al., *Large Dual Encoders*, 2021（Mega-byte 压缩）。

## 一、背景与挑战

全库逐文档编码不可行；需离线建索引+量化压缩以低延迟高吞吐服务。

## 二、核心原理

文档向量离线用 PQ/OPQ 压缩，query 在线编码后在压缩索引上做距离查表；配合 GPU 索引进一步提速。

## 三、数学形式

压缩后向量 $c=Q(d)\in\{0..K\}^m$；距离 $s(q,d)\approx\sum_j \text{LUT}_j(c_j)$。

## 四、代码实现

```python
import faiss
idx = faiss.index_factory(D, "OPQ16,IVF4096,PQ16")
idx.add(docs_emb)
```

## 五、与其他对比

- 与 向量检索算法深入（IVF/PQ/HNSW）共用索引。
- 与 双塔模型深入 总览衔接。

## 六、常见误区

- 压缩比过高致召回崩；须按精度预算选 m。
- query 未与文档同量化空间致距离失真。

## 八、面试题

- 双塔在线为何快？答：仅编码 query 一次，文档侧用预建压缩索引查表。

## 九、演进

精确内积 → PQ 压缩 → GPU/磁盘索引。

## 十、小结

双塔推理靠离线压缩索引，将在线成本压到一次 query 编码+查表。
