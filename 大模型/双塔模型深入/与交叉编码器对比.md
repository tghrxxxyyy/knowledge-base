# 双塔与交叉编码器对比

> 对应 Humeau et al., *Poly-Encoder*, 2019；Humeau 对比 bi/cross-encoder 速度-质量。

## 一、背景与挑战

检索需在速度与质量间取舍；双塔快但弱交互，交叉编码器强交互但慢。

## 二、核心原理

双塔分别编码后内积，无 token 级交互；交叉编码器拼接 [q;d] 联合编码捕捉细粒度交互，精度高但每对需前向。

## 三、数学形式

双塔 $s=q^\top d$；交叉 $s=C([q;\text{SEP};d])\in\mathbb R$；后者表达力强但 $O(N)$ 次编码。

## 四、代码实现

```python
ce_score = cross_encoder.predict([(q,d) for d in top100])   # 仅小候选
```

## 五、与其他对比

- 与 检索重排序深入（交叉编码器即重排器）共享。
- 与 迟交互深入（折中方案）衔接。

## 六、常见误区

- 对全库跑交叉编码器不可行；须先双塔召回缩候选。
- 误以为双塔总够用，长难 query 需重排补。

## 八、面试题

- 双塔 vs 交叉编码器？答：双塔快适召回、交叉准适精排，常两阶段组合。

## 九、演进

双塔 → 交叉编码器 → 迟交互(折中)。

## 十、小结

双塔与交叉编码器互补：前者召回、后者精排，构成检索两阶段。
