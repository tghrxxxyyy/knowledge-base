# 双塔模型训练技巧

> 对应 Reimers & Gurevych, 2019（SBERT 训练）；Henderson et al., *Poly triplets*, 2017。

## 一、背景与挑战

双塔对比训练易坍缩（所有向量趋同）或过拟合；需正则与采样技巧。

## 二、核心原理

用 triplet/对比损失，加温度缩放、难负例、梯度裁剪；可加 MLP 池化头；学习率 warmup 稳定。

## 三、数学形式

三元组损失 $\mathcal L=\max(0, s(q,p^-)-s(q,p^+)+m)$，$m$ 为边界间隔。

## 四、代码实现

```python
loss = F.triplet_margin_loss(anc, pos, neg, margin=0.2)
```

## 五、与其他对比

- 与 嵌入模型训练深入（对比损失/池化）共享。
- 与 稠密检索训练深入（难负例）衔接。

## 六、常见误区

- 学习率过大致向量崩；warmup 不可省。
- 只用易负例致表征坍缩。

## 七、与开源书对应

## 八、面试题

- 双塔训练如何防坍缩？答：难负例+温度+边界损失，保持表征分散有区分。

## 九、演进

triplet → InfoNCE → 去偏批内负例。

## 十、小结

双塔训练靠负例质量与正则稳表征，技巧决定召回上限。
