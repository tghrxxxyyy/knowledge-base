# 双塔模型在推荐系统

> 对应 Covington et al., *YouTube DNN*, 2016（工业级双塔召回）；后续两塔召回范式。

## 一、背景与挑战

推荐需从百万物品实时召回候选；双塔把用户与物品映射到同空间按内积排序。

## 二、核心原理

用户塔编码用户特征（行为/画像），物品塔编码物品特征；离线建物品向量索引，在线编码用户向量检索 top-k 作召回。

## 三、数学形式

$u=E_u(\text{user}), v=E_v(\text{item})$；排序分 $s=u^\top v$；负采样训练。

## 四、代码实现

```python
user_emb = user_tower(features)
cands = item_index.search(user_emb, k=200)
```

## 六、常见误区

- 两塔无交互致无法用交叉特征；需特征交叉前置。
- 热门物品负采样偏置未纠。
