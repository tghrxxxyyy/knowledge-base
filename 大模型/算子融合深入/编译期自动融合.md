# 编译期自动融合

> 对应 Chen et al., *TVM: An Automated End-to-End Optimizing Compiler for Deep Learning*, OSDI 2018；与 编译部署深入 衔接。

## 一、背景与挑战

手工融合难覆盖组合爆炸，需要编译器在图层面自动识别融合机会。

## 二、核心原理

TVM 在计算图阶段做 fusion pass：将 element-wise 链合并，对 reduction 算子采用“fuse into compute”策略，再由 schedule 决定 tile 与绑定。

## 三、数学形式

融合判定基于数据流：$v$ 是单一生产者且消费者为 element-wise，则可 inline：$s = \text{inline}(s, v)$。

## 四、代码实现

```python
s = te.create_schedule(out.op)
s[conv].compute_inline()         # 将 conv 融进后续
s[bn].compute_inline()
```

## 五、与其他对比

- 与 算子融合总览（手动融合）对照自动化优势。
- 与 内核调优深入（AutoTVM 调该融合后的 kernel）接力。

## 六、常见误区

- 图融合后仍需调度调优，否则默认 schedule 未必最优。
- 跨设备（如 embedding 在 CPU）无法融合。

## 八、面试题

- 编译器如何决定融合？答：基于数据流单一生产者、element-wise 消费、无跨设备约束等规则自动 inline。

## 九、演进

规则融合 → AutoTVM 调参 → Ansor 全自动生成。

## 十、小结

编译期自动融合把人工经验转为图 pass，是规模化推理优化的关键。
