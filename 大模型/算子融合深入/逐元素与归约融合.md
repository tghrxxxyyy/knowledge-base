# 逐元素与归约融合

> 对应 NVIDIA, *CUTLASS/epilogue fusion*, 2020；与 内核调优深入 衔接。

## 一、背景与挑战

Transformer 中 LayerNorm、Softmax、残差加法都是逐元素/归约，频繁落盘极慢。

## 二、核心原理

将归约（reduce）与逐元素（epilogue）融合进 GEMM 的 epilogue 阶段：在写出累加结果的同时完成归一化，避免二次全局读写。

## 三、数学形式

Softmax 融合：$\text{out}_i=\frac{e^{x_i-\max_j x_j}}{\sum_k e^{x_k-\max_j x_j}}$，max/sum 两趟归约与除法在 GEMM 写回时一并完成。

## 四、代码实现

```python
# CUTLASS epilogue 融合 Linear+Softmax
epilogue = SoftmaxEpilogue(scale=1.0/temperature)
gemm.run(epilogue=epilogue)
```

## 五、与其他对比

- 与 MHA/注意力融合共享“归约即输出”思想。
- 与 服务框架深入（PagedAttention 内核）在 kernel 层呼应。

## 六、常见误区

- 在线 softmax 需两趟扫描或稳定技巧，错误实现会数值溢出。
- epilogue 过复杂超出寄存器预算。
