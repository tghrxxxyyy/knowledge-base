# 预训练数据配比

> 对应 Xie et al., *DoReMi*, 2023；数据域权重优化研究。

## 一、背景与挑战

不同域（网页/代码/图书/科学）混合比例显著影响能力；手工配比次优。

## 二、核心原理

用小型参考模型与域分布，学习各域最优采样权重（如 DoReMi 用组分布鲁棒优化），再按比例重采样大规模训练。

## 三、数学形式

域权重 $w_i$ 使 $\max_i \mathcal L_i(\theta)$ 最小（GRW）；或 KL 对齐参考域分布：$\min \sum_i w_i \text{KL}_i$。

## 四、代码实现

```python
from dataloader import resample
weights = doremi(reference_model, domains)   # 学域权重
train = resample(corpus, weights)
```

## 五、与其他对比

- 与 指令微调数据质量深入（阶段配比）互补。
- 与 预训练数据流水线总览 为其中一环。

## 六、常见误区

- 代码/数学占比过低伤推理。
- 静态配比不随训练阶段调（课程式更优）。
