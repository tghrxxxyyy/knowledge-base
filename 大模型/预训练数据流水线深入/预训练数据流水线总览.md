# 预训练数据流水线总览

> 对应 Penedo et al., *RefinedWeb* / *FineWeb*, 2023/2024；Soldaini et al., *Dolma*, 2024。

## 一、背景与挑战

模型能力上限很大程度由数据决定；需从原始网页/代码/书籍构建大规模、高质量、去重、合规的预训练语料。

## 二、核心原理

流水线含：采集 → 语言/质量过滤 → 去重 → 毒性/PII 处理 → 分词 → 配比打包；各环节可度量、可回放。

## 三、数学形式

语料效用近似 $U \approx f(\text{quality}, \text{diversity}) - \lambda \cdot \text{redundancy}$；目标在固定 token 预算下最大化。

ds = load_commoncrawl()

## 五、与其他对比

- 与 指令微调数据质量深入 同属“数据决定上限”理念。
- 与 多模态预训练深入 共享管线思想（换模态）。

## 六、常见误区

- 只堆量不控质致“垃圾进垃圾出”。
- 去重过度伤多样性。

## 八、面试题

- 预训练数据为何要去重？答：重复样本放大偏见/过拟合，去重提效与多样性。

## 九、演进

原始爬取 → 启发式过滤 → 模型过滤+语义去重。

## 十、小结

预训练流水线以质量/多样/合规三角构建语料，是能力地基。
