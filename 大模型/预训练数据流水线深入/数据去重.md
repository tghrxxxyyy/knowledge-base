# 预训练数据去重

> 对应 Lee et al., *Deduplicating Training Data*, 2021；SemDeDup（Abbas et al., 2023）。

## 一、背景与挑战

网页高度重复（转载/模板），重复样本浪费算力并放大内容偏见与隐私泄露风险。

## 二、核心原理

精确去重（URL/文档哈希）；近似去重用语义嵌入或 MinHash/LSH 找近重复；SemDeDup 在嵌入空间按簇内相似度删冗余。

## 三、数学形式

MinHash 相似度 $J(A,B)\approx |\text{set}_A\cap\text{set}_B|/|\text{set}_A\cup\text{set}_B|$；超阈值判重复。

## 四、代码实现

```python
from datasketch import MinHashLSH
lsh = MinHashLSH(threshold=0.9)
for doc in docs: lsh.insert(id, minhash(doc))
dup = [c for c in lsh.query(m) if c != id]
```

## 五、与其他对比

- 与 指令微调数据质量深入（去重提升微调效率）同源。
- 与 多模态预训练深入（图文去重）共享。

## 六、常见误区

- 阈值过高漏去重、过低删近义有用文。
- 只做精确去重忽略近重复。

## 八、面试题

- MinHash 为何适合去重？答：以低维签名近似 Jaccard 相似，可扩展近重复检测。

## 九、演进

URL 去重 → MinHash → 语义嵌入去重（SemDeDup）。

## 十、小结

分层去重（精确+近似+语义）是高质量语料必需。
