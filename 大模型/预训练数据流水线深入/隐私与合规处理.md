# 预训练数据隐私与合规

> 对应 PII 脱敏与成员推断研究（Carlini et al., 2021）。

## 一、背景与挑战

爬取语料含姓名/邮箱/密钥等敏感信息；模型可能记忆并泄露训练数据。

## 二、核心原理

用正则/NER 检测 PII 并替换或删除；对高记忆风险样本降权；合规过滤（版权/许可）；可加差分隐私训练降泄露。

## 三、数学形式

差分隐私目标 $\min_\theta \mathcal L$ s.t. 任意相邻数据集输出差异 $<\epsilon$；记忆度量 $M(x)=\Pr[\text{复原}x]$。

## 四、代码实现

```python
text = redact_pii(text, ents=["PERSON","EMAIL","PHONE"])
if has_license(text, "noncommercial"): drop(text)
```

## 五、与其他对比

- 与 模型水印深入（溯源）互补治理。
- 与 检索增强失效分析深入 无直接关。

## 六、常见误区

- 仅正则漏掉非常规格式 PII。
- 忽略许可证导致合规风险。

## 八、面试题

- 模型为何会泄密？答：过拟合记忆罕见样本，可通过提示提取，需脱敏+DP 防护。

## 九、演进

无处理 → 规则脱敏 → 差分隐私训练。

## 十、小结

隐私合规是预训练不可省的一环，脱敏与 DP 并重。
