# 预训练数据质量过滤

> 对应 Rae et al., *Gopher*, 2021（质量启发式）；Wenzek et al., *CCNet*, 2019。

## 一、背景与挑战

原始网页含大量低质/垃圾内容；需自动区分高信息密度文本与噪声。

## 二、核心原理

启发式：语言识别、符号比、停用词比、句长；模型法：用小分类器（如 fastText 质量/毒性）打分，按阈值保留。

## 三、数学形式

质量分 $q = \text{Classifier}_\phi(d)\in[0,1]$；保留条件 $q>\tau$ 或按分位截断至预算 $B$。

## 四、代码实现

```python
scores = quality_model(batch_texts)
keep = [t for t,s in zip(texts,scores) if s > 0.7]
```

## 五、与其他对比

- 与 指令微调数据质量深入（质量优先）理念一致。
- 与 预训练数据流水线总览 为上下环节。

## 六、常见误区

- 分类器偏见致某域被系统性丢弃。
- 阈值静态不随语料分布调。

## 八、面试题

- 质量过滤过严会怎样？答：丢多样性与长尾知识，模型变“窄”。

## 九、演进

规则过滤 → 分类器 → 多指标联合筛选。

## 十、小结

质量过滤以模型打分替代纯规则，是语料净化的核心。
