# 自蒸馏与大模型作为教师

> 对应 Hinton 2015 自蒸馏思想与 huggingface/trl 的大模型蒸馏流程。

## 一、背景与挑战

大模型本身也可作为教师，把能力蒸馏给更小的"学生"用于部署；此外模型可对自身做自蒸馏（用自身软标签监督自己）以提升泛化。

## 二、核心原理

大模型教师生成软标签 / 思维链样本，学生在这些信号上训练。自蒸馏则是同一模型用高温 softmax 的软标签回灌训练，相当于正则。LLM 场景下常见"教师生成数据 -> 学生 SFT"。

## 三、形式化与数学基础

数据蒸馏：

$ \\mathcal D_{syn}=\\{x_i,\\tau(x_i)\\}_{i=1}^N,\\quad \\tau=\\text{Teacher} $

学生训练：

$ \\min_\\theta\\mathbb E_{(x,y)\\in\\mathcal D_{syn}}\\mathcal L_{SFT}(f_\\theta(x),y) $

## 四、代码实现

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

teacher = AutoModelForCausalLM.from_pretrained("big-model")
tok = AutoTokenizer.from_pretrained("big-model")
prompts = ["解释量子纠缠:", "写一首诗:"]
syn = [tok.decode(teacher.generate(tok(p, return_tensors="pt").input_ids)[0]) for p in prompts]
# syn 作为学生 SFT 数据
```

## 五、与其他技术对比

- 相比人类标注，教师生成数据规模大、成本低。
- 与 RLAIF 类似用模型生成监督信号，但蒸馏更关注能力迁移。

## 六、常见误区

- 学生盲目模仿教师错误（幻觉被传导）。
- 自蒸馏当正则用过度，导致模型自信但脆弱。
