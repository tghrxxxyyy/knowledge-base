# 知识蒸馏基本原理

> 对应 Hinton 2015 Distilling the Knowledge in a Neural Network 与 huggingface/trl 的蒸馏支持。

## 一、背景与挑战

大模型（教师）效果好但贵，小模型（学生）部署友好但精度不足。蒸馏让小模型从大模型的"软标签"中学习隐含知识，而非仅从硬标签。

## 二、核心原理

教师对样本输出软化概率（温度 T 升高后 softmax 更平滑），包含类间相似性信息（如"2 像 3"）。学生同时拟合硬标签与教师软标签，迁移泛化能力。

## 三、形式化与数学基础

软化概率：

$ q_i=\\frac{\\exp(z_i/T)}{\\sum_j\\exp(z_j/T)} $

蒸馏损失为教师/学生软化输出的 KL 散度：

$ \\mathcal L_{KD}=T^2\\cdot \\text{KL}(q^T\\|p^T) $

## 四、代码实现

```python
import torch, torch.nn.functional as F

def kd_loss(student_logits, teacher_logits, T=4.0, alpha=0.7):
    soft_s = F.log_softmax(student_logits / T, dim=-1)
    soft_t = F.softmax(teacher_logits / T, dim=-1)
    kd = F.kl_div(soft_s, soft_t, reduction="batchmean") * (T * T)
    return alpha * kd
# 与真实标签的 CE 相加得到总损失
```

## 五、与其他技术对比

- 相比仅用硬标签训练，蒸馏提供类间结构信号。
- 与剪枝/量化不同，蒸馏改变训练目标而非结构。

## 六、常见误区

- 温度 T 随便设；过大噪声多，过小退化为硬标签。
- 只用软标签丢了真实标签的确定性信号。

## 十、小结

蒸馏通过温度软化的 KL 损失，把教师的概率分布知识迁移到学生，是模型压缩经典手段。
