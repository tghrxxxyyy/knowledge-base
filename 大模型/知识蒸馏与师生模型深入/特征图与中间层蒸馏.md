# 特征图与中间层蒸馏

> 对应 huggingface/trl 的特征蒸馏与经典 FitNets / TinyBERT 思路。

## 一、背景与挑战

仅对齐输出 logits 信息有限，尤其大模型中间层编码了丰富语义。特征蒸馏让学生中间表示逼近教师对应层，迁移更充分。

## 二、核心原理

在教师/学生选定层之间加回归损失（如 MSE 或余弦），必要时用可学习投影把维度对齐。配合注意力图蒸馏（学生注意力分布对齐教师）效果更好。

## 三、形式化与数学基础

特征损失：

$ \\mathcal L_{feat}=\\|\\phi_s(H_s)-\\phi_t(H_t)\\|_2^2 $

注意力蒸馏：

$ \\mathcal L_{att}=\\text{MSE}(A_s,A_t),\\quad A=\\text{softmax}(QK^\\top/\\sqrt d) $

## 四、代码实现

```python
import torch, torch.nn.functional as F

class ProjMatch(torch.nn.Module):
    def __init__(self, d_s, d_t):
        super().__init__()
        self.proj = torch.nn.Linear(d_s, d_t, bias=False)

    def forward(self, hs, ht):
        return F.mse_loss(self.proj(hs), ht.detach())
# 在 forward hook 中收集 hs/ht 后计算
```

## 五、与其他技术对比

- logits 蒸馏最简单；特征蒸馏更强但需对齐结构。
- TinyBERT 同时用特征 + 注意力蒸馏，是 NLP 小模型典范。

## 六、常见误区

- 学生教师层不对齐直接算 MSE，维度/语义错配。
- 忽略投影导致容量瓶颈。
