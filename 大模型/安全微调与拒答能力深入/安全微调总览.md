# 安全微调总览

> 对应 Bai et al., *Training a Helpful and Harmless Assistant with RLHF*, 2022；Ouyang et al., *InstructGPT*, NeurIPS 2022。

## 一、背景与挑战

安全微调要同时满足两个互相拉扯的目标：对真实有害请求可靠拒答（harmlessness），对正常请求保持有用（helpfulness）。任何只优化一侧的方案都会立刻在另一侧崩塌——只压有害就得到「什么都不敢答」的模型，只追有用就得到「什么都敢答」的模型。这个张力是安全对齐的核心难点，而不是调参细节。

## 二、核心原理

主流做法是三段式。第一段是安全 SFT：用高质量的「拒答 + 解释 + 安全替代方案」示范教会模型拒答的形式与边界。第二段是安全偏好优化：构造同一有害请求下「恰当拒答」优于「照做」、以及同一无害请求下「正常回答」优于「过度拒答」的偏好对，用 DPO/RLHF 把边界拉正。第三段是系统层防护：输入输出分类器、策略提示、工具调用白名单，作为模型层之外的纵深防御。关键认识是：安全不是一个二分类头，而是分布在数据、目标与系统三层的联合属性。

## 三、数学形式

把安全微调写成受约束优化：在拒答率不超过阈值的前提下最大化有用性，

$$\max_\theta\ \mathbb E_{x\sim D_{\text{benign}}}\big[U(\pi_\theta,x)\big]\quad\text{s.t.}\quad \mathbb E_{x\sim D_{\text{harm}}}\big[\mathbb 1\{\text{comply}\}\big]\le\epsilon_h,\ \ \mathbb E_{x\sim D_{\text{benign}}}\big[\mathbb 1\{\text{refuse}\}\big]\le\epsilon_b$$

拉格朗日化后即为「有用性奖励 + 安全惩罚 + 过度拒答惩罚」的多目标标量化，$\epsilon_h,\epsilon_b$ 分别对应有害顺从率与良性误拒率的容忍上限。

## 四、代码实现

```python
import torch.nn.functional as F

def safety_dpo_loss(batch, model, ref, beta=0.1, w_harm=1.0, w_benign=1.0):
    # batch 同时含两类偏好对：有害样本(拒答优先) 与 良性样本(正常回答优先)
    def pair_loss(sub):
        lp_w, lp_l = seq_logp(model, sub["chosen"]), seq_logp(model, sub["rejected"])
        rf_w, rf_l = seq_logp(ref, sub["chosen"]), seq_logp(ref, sub["rejected"])
        delta = beta * ((lp_w - rf_w) - (lp_l - rf_l))
        return -F.logsigmoid(delta).mean()

    l_h = pair_loss(batch["harmful"])    # chosen = 恰当拒答
    l_b = pair_loss(batch["benign"])     # chosen = 正常有用回答
    return w_harm * l_h + w_benign * l_b, {"harm": l_h.item(), "benign": l_b.item()}
```

## 五、与其他对比

- 与 对齐税与能力保持深入：安全微调是对齐税的主要来源之一，需同步测通用能力。
- 与 多模态安全与越狱深入：文本安全训练不会自动迁移到图像输入路径。
- 与 提示注入形式化分析深入：安全微调管「不该做的事」，注入防御管「不该听的指令」，二者正交。

## 六、常见误区

- 只用有害样本做安全训练。缺少良性对照会直接把误拒率推高，这是最常见的翻车方式。
- 把拒答写成固定模板。模板化拒答易被前缀注入绕过，且用户体验差；应包含理由与可行替代。
- 认为安全微调一次做完就稳定。后续任何下游微调都可能削弱它（见微调破坏安全对齐一节）。

## 八、面试题

- 安全微调为什么必须同时用良性样本？答：只优化拒答会把决策边界整体左移，导致大量正常请求被误拒，有用性大幅下降。
- 安全应该放在模型层还是系统层？答：两层都要。模型层负责默认行为与泛化，系统层提供可审计、可快速更新的兜底。

## 九、演进

规则过滤 → 安全 SFT → 安全 RLHF（HH 双目标） → 宪法 AI / RLAIF 规模化 → 模型层与系统层纵深防御。

## 十、小结

安全微调的本质是在有用性与无害性之间刻画一条可控边界；成败取决于是否用双向数据把边界的两侧都钉住。
