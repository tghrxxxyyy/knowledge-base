# 安全偏好数据构建

> 对应 Bai et al., *Training a Helpful and Harmless Assistant with RLHF*（HH 数据集）, 2022；Bai et al., *Constitutional AI*, 2022。

## 一、背景与挑战

安全能力几乎完全由数据决定：模型不会自发知道哪些请求越界、拒答该说到什么程度。难点是有害数据本身难以大规模人工标注（伦理与心理成本高），且风险类目在不断变化，需要一套可持续生产、可审计的构建流程。

## 二、核心原理

四条数据来源互补。一是红队产出：由人或模型主动构造攻击性提示，覆盖直接请求、角色扮演、分步拆解、编码混淆等手法。二是最小对比对：对每个有害提示生成一个仅意图不同的良性孪生提示，成对入库。三是 AI 反馈（RLAIF）：用宪法原则让模型自评并改写自己的回答，得到 (原答案, 修订答案) 偏好对，大幅降低人工成本。四是线上回流：把实际发生的误拒与漏拒案例定期补入训练集。所有样本必须带风险类目、严重度与来源标签，这样才能做覆盖分析与分层评测，而不是一堆无结构的黑样本。

## 三、数学形式

用类目覆盖与难度分布刻画数据质量。设风险类目集合 $\mathcal C$，覆盖度

$$\mathrm{Cov}=\frac{|\{c\in\mathcal C:\ n_c\ge n_{\min}\}|}{|\mathcal C|},\qquad \text{类目不均衡}\ \ H=-\sum_{c}p_c\log p_c$$

难度上按当前模型的失败率分桶：$\mathrm{diff}(x)=1-\mathbb 1\{\text{模型对 }x\text{ 正确处理}\}$，优先补充失败率高且样本量少的类目（主动学习式采样）。

## 四、代码实现

```python
from collections import Counter

def build_safety_pairs(harm_prompts, model, constitution, judge):
    pairs = []
    for x in harm_prompts:
        raw = model(x)                                  # 初始回答，可能顺从
        critique = model(f"依据以下原则批评上述回答：{constitution}\n回答：{raw}")
        revised = model(f"根据批评重写为安全且有帮助的回答。批评：{critique}")
        if judge.safer(revised, raw):                   # 仅保留方向明确的对
            pairs.append({"prompt": x, "chosen": revised, "rejected": raw,
                          "category": judge.category(x), "source": "rlaif"})
    return pairs

def coverage_report(pairs, all_categories, n_min=50):
    cnt = Counter(p["category"] for p in pairs)
    covered = [c for c in all_categories if cnt[c] >= n_min]
    return {"coverage": len(covered) / len(all_categories),
            "thin_categories": [c for c in all_categories if cnt[c] < n_min]}
```

## 五、与其他对比

- 与 偏好数据构建（通用）：流程相同，但安全数据额外需要类目标注、严重度分级与访问控制。
- 与 宪法 AI 与 RLAIF：那是本节第三条来源的方法论展开。
- 与 拒答边界与过度拒答：最小对比对是连接两节的关键数据形态。

## 六、常见误区

- 只收集「明显有害」的极端样本，缺少边界模糊样本。真实风险恰恰集中在模糊带。
- 拒答样本的 chosen 全部写成同一句模板，导致模型学到固定串而非判断逻辑。
- 有害样本未做访问隔离与脱敏管理，数据本身成为新的风险面。

## 八、面试题

- 安全偏好数据为什么必须带类目标签？答：用于覆盖度分析、分层评测与按类目定制严重度策略，否则无法定位薄弱面。
- RLAIF 在安全数据上的优势与风险？答：优势是可规模化生产修订对；风险是继承裁判模型自身的盲区与偏好，需人工抽检校准。

## 九、演进

人工黑样本收集 → 红队规模化 → 最小对比对与类目化 → RLAIF 自我批评修订 → 线上回流驱动的持续补充。

## 十、小结

安全能力的上限写在数据里：类目覆盖、边界样本、成对对照与持续回流，四者缺一，安全表现就会在真实分布上露出缺口。
