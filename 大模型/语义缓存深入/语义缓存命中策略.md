# 语义缓存命中策略

> 对应命中判定与回退；与 语义缓存总览 衔接。

## 一、背景与挑战

命中阈值与回退策略决定质量与成本平衡。

## 二、核心原理

固定阈值、自适应阈值（按分布）、Top-k 投票；未命中再调 LLM 并回填，可并行探测。

## 三、数学形式

自适应阈值 $\tau_t = \mu_t - k\sigma_t$（基于近期相似度分布），降低误命中。

## 四、代码实现

```python
sim = max_sim(q)
if sim >= tau: return cached[best]
else: return fill_cache(q, llm(q))
```

## 五、与其他对比

- 与 提示缓存深入（确定命中）对照。
- 与 检索重排序深入（精排候选）互补。

## 六、常见误区

- 固定阈值不适应查询分布漂移。
- 命中即返回未做答案新鲜度检查。

## 八、面试题

- 为何用自适应阈值？答：查询分布漂移时固定阈值易误命中，自适应更稳。

## 九、演进

固定阈值 → 自适应 → 上下文感知命中。

## 十、小结

语义缓存命中策略在成本与正确间权衡，自适应阈值更鲁棒。
