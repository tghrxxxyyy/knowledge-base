# 语义相似度检索

> 对应句嵌入与近似检索；向量检索算法深入 衔接。

## 一、背景与挑战

语义命中质量依赖嵌入与检索精度。

## 二、核心原理

查询经句嵌入模型得向量，ANN（HNSW/IVF）检索近邻；相似度用余弦，融合重排提升精度。

## 三、数学形式

余弦 $\cos(e(q),e(q_j))=\frac{e(q)\cdot e(q_j)}{\|e(q)\|\|e(q_j)\|}$；取 Top-1 判阈值。

## 四、代码实现

```python
vec = embed_model.encode(q)
idx, dist = faiss_index.search(vec.reshape(1,-1), k=1)
```

## 五、与其他对比

- 与 向量检索算法深入 共享引擎。
- 与 语义缓存总览 构成检索层。

## 六、常见误区

- 用对话模型做嵌入，语义不匹配。
- 未归一化致余弦失真。
