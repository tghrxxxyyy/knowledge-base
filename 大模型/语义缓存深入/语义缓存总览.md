# 语义缓存总览

> 对应 Zill et al., *GPTCache*, 2024；语义缓存用于 LLM 降本。

## 一、背景与挑战

相似问题繁多，逐字缓存命中率低；语义相近请求可复用答案，省去 LLM 调用。

## 二、核心原理

把查询嵌入，用向量检索找语义近邻；若相似度超阈值则复用缓存答案，否则调用 LLM 并回填。

## 三、数学形式

命中判定 $hit=\mathbf 1[\max_j \cos(e(q),e(q_j)) \ge \tau]$；命中即返回 $a_j$。

## 四、代码实现

```python
from gptcache import Cache
cache = Cache(); cache.init(pre_func=lambda q: embed(q))
ans = cache.get(q) or llm(q)
```

## 五、与其他对比

- 与 提示缓存深入（逐字 KV）不同，语义缓存按意义。
- 与 向量检索算法深入（检索底座）共享向量库。

## 六、常见误区

- 阈值过高失缓存价值、过低致答非所问。
- 忽略答案时效性（复用过期信息）。

## 八、面试题

- 语义缓存相对逐字缓存优势？答：按语义召回近邻，命中率高，适合问法多样场景。

## 九、演进

逐字缓存 → 语义缓存 → 语义+上下文缓存。

## 十、小结

语义缓存以向量近邻复用答案，显著提升命中、降调用成本。
