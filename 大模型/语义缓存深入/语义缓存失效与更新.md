# 语义缓存失效与更新

> 对应缓存一致性；与 语义缓存与向量库 衔接。

## 一、背景与挑战

知识更新、模型换版后旧答案可能错，需失效。

## 二、核心原理

按 TTL 过期、按数据源版本号失效、按语义聚类批量刷新；支持写穿透（更新即回填）。

## 三、数学形式

有效 $valid = (t_{now}-t_{write}<TTL)\wedge (ver_{src}=ver_{cache})$；否则失效。

## 四、代码实现

```python
if cache.version(q) != kb.version:
    cache.evict(q); cache.fill(q, llm(q))
```

## 五、与其他对比

- 与 提示缓存深入（TTL）同概念不同层。
- 与 长文档切分深入（文档更新）联动。

## 六、常见误区

- 只靠 TTL 忽略知识已变。
- 刷新风暴（批量失效致 LLM 打满）。

## 八、面试题

- 语义缓存如何防过期答案？答：TTL+数据源版本号失效，必要时写穿透刷新。

## 九、演进

TTL → 版本失效 → 事件驱动刷新。

## 十、小结

语义缓存需显式失效策略，避免复用过期或错误答案。
