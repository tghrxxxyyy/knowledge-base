# 显存最优调度总览

> 对应 训练显存管理综述（激活/参数/状态 三方）；与 梯度检查点深入 衔接。

## 一、背景与挑战

训练显存 = 参数 + 梯度 + 优化器状态 + 激活；任一部分失控都会 OOM，需系统级调度。

## 二、核心原理

按生命周期对张量做复用与换出：优化器状态用 ZeRO 分片、激活用检查点、临时张量池化复用、溢出者 offload 到 CPU/NVMe。

## 三、数学形式

总显存 $M = M_{param}+M_{grad}+M_{opt}+M_{act}$；调度目标 $\min M$ 且 $\max$ 吞吐，常做 Pareto 权衡。

## 五、与其他对比

- 与 梯度检查点深入（仅激活）是子集。
- 与 分布式优化器深入（状态分片）协同覆盖其余部分。

## 六、常见误区

- 只优化一处（如只检查点）忽略其他致仍 OOM。
- offload 过度致 PCIe 成瓶颈。
