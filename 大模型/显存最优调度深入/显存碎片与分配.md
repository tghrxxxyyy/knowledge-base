# 显存碎片与分配器

> 对应 深度学习显存分配（pytorch caching allocator / 碎片问题）；与 显存最优调度深入 总览衔接。

## 一、背景与挑战

即使总空闲足够，频繁分配/释放不同尺寸张量会产生碎片，致使连续大块申请失败（OOM）。

## 二、核心原理

框架用缓存分配器（caching allocator）复用同尺寸块以减少碎片；但不规则生命周期仍会外部碎片化；可预分配池或定期 empty_cache 缓解。

## 三、数学形式

碎片率 $f = 1 - \frac{\max\_contiguous}{total\_free}$；高 $f$ 时即便 $total\_free$ 充足也可能分配失败。

## 四、代码实现

```python
torch.cuda.empty_cache()          # 释放未用缓存
# 或预分配固定尺寸池减少碎片
```

## 五、与其他对比

- 与 激活重计算调度（减少峰值）配合降碎片压力。
- 与 分布式优化器深入（分片使单卡块更小）间接改善。

## 六、常见误区

- 频繁 empty_cache 反而降吞吐。
- 误把碎片 OOM 当成总量不足盲目降批量。

## 十、小结

显存碎片是隐蔽 OOM 源，需分配器与生命周期管理协同。
