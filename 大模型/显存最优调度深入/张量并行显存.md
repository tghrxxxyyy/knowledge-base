# 张量并行显存

> 对应 Shoeybi et al., *Megatron-LM*, 2019；与 分布式优化器深入 衔接。

## 一、背景与挑战

单层权重过大单卡放不下；张量并行把权重矩阵按行/列切到多卡，每层显存随卡数下降。

## 二、核心原理

列并行切输出维度、行并行切输入维度，配合 G 算子（如 all-reduce/gather）拼接；与流水线并行、数据并行组成 3D 并行。

## 三、数学形式

设权重 $A\in\mathbb R^{m\times n}$ 切为 $A_i$（按列），每卡存 $1/P$；计算 $Y=\sum_i X A_i^T$ 经 all-reduce 合并。

## 四、代码实现

```python
y = ColumnParallelLinear(d, d)(x)     # Megatron 风格列并行
z = RowParallelLinear(d, d)(y)        # 行并行，内含 all-reduce
```

## 五、与其他对比

- 与 ZeRO（优化器状态分片）互补，张量并行切的是单层参数与激活。
- 与 显存最优调度深入 总览共同构成显存治理。

## 六、常见误区

- 切分不当致通信量翻倍（需 G 算子配对）。
- 与流水线并行耦合增加调度复杂度。

## 八、面试题

- 张量并行如何省显存？答：单层权重按维切分至多卡，每卡仅持分片并配通信算子还原。

## 九、演进

数据并行 → 流水线 → 张量 → 3D 并行。

## 十、小结

张量并行以层内切分降低单卡峰值，是超大模型必备的维度之一。
