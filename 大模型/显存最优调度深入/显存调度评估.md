# 显存调度评估

> 对应 训练系统 profiling（显存/吞吐测量）；与 模型评测指标深入 衔接。

## 一、背景与挑战

调度策略优劣需量化：峰值显存、吞吐量（tokens/s）、端到端时延，避免"省了显存却拖垮速度"。

## 二、核心原理

在固定模型/批量下扫不同调度组合（检查点比例、offload、分片），画显存-吞吐 Pareto 曲线选均衡点。

## 三、数学形式

效率 $\eta = \frac{throughput}{M_{peak}}$ 或 Pareto 前沿 $(\min M, \max TPS)$；选不劣于他者的配置。

## 四、代码实现

```python
for cfg in grid:
    tps, mem = profile(train_step, cfg)
    pareto.add(cfg, mem, tps)
```

## 五、与其他对比

- 与 分布式优化与收敛（批量影响收敛）需联合看。
- 与 显存最优调度深入 各节为评估对象。

## 六、常见误区

- 只看峰值显存忽略吞吐崩塌。
- 评测批量与线上不一致致误判。
