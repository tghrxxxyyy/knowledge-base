# 参数共享策略

> 见「多任务学习深入/多任务学习总览」；Hard/Soft 共享；MMoE (Ma et al., 2018)。

## 一、背景与挑战

如何既共享又不互相干扰？

## 二、核心原理

- **硬共享**：底层完全共用，仅顶层分任务——简单但易冲突。
- **软共享**：各任务独立网络，加正则/知识蒸馏让参数接近。
- **MMoE**：专家网络 + 每任务门控，动态组合专家，缓解任务差异。

## 三、数学形式

MMoE：`f^k(x) = Σ_g g^k_g(x)·E_g(x)`，g 为门控、E 为专家。

## 四、代码实现

```python
gate = softmax(w_k(x)); out = sum(g * expert_i(x))
```

## 五、关键要点

- 门控让任务自取所需专家。
- 专家数需调。

## 六、与其他对比

- 硬共享强耦合；软/门控松耦合。

## 七、常见误区

- 硬共享总好——冲突时差。
