# 多任务学习总览

> 对应 d2l-zh 多任务章；Caruana, *Multitask Learning*, 1997；Ruder, *An Overview*, 2017。

## 一、背景与挑战

多个相关任务共享表示可互助，但任务冲突会互相拖累。

## 二、核心原理

共享底层、任务特定上层。关键：**负迁移**（任务冲突使彼此变差）与**任务权重**（平衡多损失）。方法含硬/软参数共享、任务专属门控（MMoE）、梯度冲突解决（PCGrad）。

## 三、关键要点

- 任务相关性决定共享收益。
- 损失加权影响主导任务。

## 四、代码实现

```python
loss = w1*l1 + w2*l2   # 任务权重
```
