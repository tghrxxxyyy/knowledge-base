# 梯度冲突解决

> 见「多任务学习深入/多任务学习总览」；Yu et al., *PCGrad*, 2020；梯度手术。

## 一、背景与挑战

多任务梯度方向相反时会互相抵消/伤害。

## 二、核心原理

**PCGrad（梯度投影）**：若任务梯度 `g_i` 与 `g_j` 夹角 >90°（冲突），把 `g_i` 投影到 `g_j` 正交方向，去除冲突分量，保留一致分量。缓解负迁移。

## 三、数学形式

`g_i ← g_i - (g_i·g_j/||g_j||²) g_j`（当 `g_i·g_j<0`）。

## 四、代码实现

```python
if (gi @ gj) < 0:
    gi = gi - (gi@gj)/(gj@gj) * gj
```

## 五、关键要点

- 冲突时才投影，否则不扰。
- 任务多时两两投影 O(k²)。

## 六、与其他对比

- 加权改幅度；PCGrad 改方向。

## 七、常见误区

- 只加权可解冲突——方向冲突需投影。
