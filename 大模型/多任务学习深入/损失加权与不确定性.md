# 损失加权与不确定性

> 见「多任务学习深入/多任务学习总览」；Kendall et al., *Multi-Task Learning Using Uncertainty*, 2018。

## 一、背景与挑战

多任务损失量级/单位不同，手工加权难。

## 二、核心原理

用**任务不确定性**自动学权重：同质任务用可学习 `σ²` 缩放，目标 `L = Σ 1/(2σ_i²) L_i + log σ_i`；异质（如回归+分类）用不同形式。自动平衡避免某任务主导。

## 三、数学形式

`L_total = Σ_i [ 1/(2σ_i²) L_i + log σ_i ]`。

## 四、代码实现

```python
logvar = nn.Parameter(torch.zeros(n_tasks))
loss = sum((li / (2*exp(v))) + v for li, v in zip(losses, logvar))
```

## 五、关键要点

- 自动适配任务噪声尺度。
- 需防止 σ 趋零（某损失被压）。

## 六、与其他对比

- 手工权重静态；不确定性动态。

## 七、常见误区

- 直接求和——量级失衡。
