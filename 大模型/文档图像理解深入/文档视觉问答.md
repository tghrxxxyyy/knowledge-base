# 文档视觉问答（DocVQA）

> 对应 Mathew et al., *DocVQA: A Dataset for VQA on Document Images*, ICDAR 2021。

## 一、背景与挑战

文档图像上的问答需同时读 OCR 文本、理解版面位置与视觉线索，远超自然图像 VQA。

## 二、核心原理

DocVQA 给定文档图与问题，答案常在文本中但需定位（如“总额是多少”）。方法联合 OCR 词、其 2D 位置与图像特征，用布局感知模型或先抽取文本再用 QA 模型。

## 三、数学形式

文档 QA 条件概率：

$$p(a|D,q)=\text{Model}\big(\{(w_i, box_i)\}_{i=1}^N, I, q\big)$$

$w_i$ 为 OCR 词，$box_i$ 为其坐标。

## 四、代码实现

```python
words, boxes = ocr_with_box(image)
ans = layoutqa(words, boxes, image, question)
```

## 五、与其他对比

- 与 视觉问答与推理深入 对照自然图像 VQA。
- 与 文档图像总览 构成端到端。

## 六、常见误区

- 仅用 OCR 文本忽略位置，跨栏答案错。
- 低质 OCR 直接拖累 QA。

## 八、面试题

- DocVQA 与自然 VQA 区别？答：依赖 OCR+版面定位，答案多为文档内抽取而非语义推断。

## 九、演进

OCR+QA → LayoutLM → 多页文档 VQA。

## 十、小结

DocVQA 把版面位置纳入问答，是文档智能的核心评测任务。
