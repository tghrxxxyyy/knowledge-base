# 文档图像理解总览

> 对应文档智能（Document AI）领域；多模态文档理解综述。

## 一、背景与挑战

文档（发票/论文/表单/截图）含文本、版面、表格、图表，纯 OCR 丢结构；需联合视觉与文本理解。

## 二、核心原理

文档理解管线：检测（布局/目标）→ OCR（文本行）→ 结构建模（序列化 token 含位置）→ 任务头（分类/抽取/问答）。现代模型用视觉-语言预训练（如 LayoutLM）联合学习。

## 三、数学形式

文档 token 联合表示：

$$h_i = f\big(\text{text}_i, \text{visual}_i, (x_i,y_i,w_i,h_i)\big)$$

位置特征编码 2D 坐标。

## 四、代码实现

```python
tokens = ocr(image)
boxes = detect_layout(image)
emb = model(tokens, boxes, image_features)
```

## 五、与其他对比

- 与 OCR与布局分析 衔接（前置）。
- 与 文档视觉问答 构成端到端。

## 六、常见误区

- 只做 OCR 忽略版面，抽取字段错位。
- 忽视扫描噪声/旋转致检测失败。

## 八、面试题

- 文档理解为何要视觉？答：版面/表格/印章等视觉信息是抽取关键，纯文本丢结构。

## 九、演进

OCR → OCR+版面 → 视觉语言预训练。

## 十、小结

文档理解联合文本、视觉与位置，是比通用 VQA 更结构化的任务族。
