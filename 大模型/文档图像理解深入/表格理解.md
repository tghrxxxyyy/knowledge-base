# 表格理解

> 对应表格检测/结构识别/表格 QA；PubTabNet 等数据集。

## 一、背景与挑战

表格有复杂行列结构、合并单元格、跨页，纯文本无法表达，需结构还原。

## 二、核心原理

三步：检测表格区域 → 结构识别（行列逻辑，常输出 HTML/ LaTeX 树）→ 单元格内容识别与问答。也可端到端用图像直接生成结构化表示。

## 三、数学形式

表格结构常表示为树/序列：

$$T = \text{serialize}\big(\{cell_{ij}, span_{ij}\}\big)$$

如 HTML <table> 序列。

## 四、代码实现

```python
html = table_model(image)        # 生成 HTML 表格
df = pd.read_html(html)[0]
```

## 五、与其他对比

- 与 OCR与布局分析 共享检测。
- 与 版面与图表 共享结构建模。

## 六、常见误区

- 合并单元格未建模致行列错位。
- 把表当普通文本行读取丢关系。

## 八、面试题

- 表格为何难？答：需还原行列与合并结构，纯文本序列丢失二维关系。

## 九、演进

规则解析 → 检测+结构识别 → 端到端生成。

## 十、小结

表格理解以结构序列化表达二维关系，是文档智能难点之一。
