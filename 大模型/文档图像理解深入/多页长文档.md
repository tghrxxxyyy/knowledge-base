# 多页长文档理解

> 对应多页文档 QA（MPDocVQA）；长文档预训练（Longformer/层级）。

## 一、背景与挑战

合同/论文常多页，跨页信息分散，单页模型无法回答需综合多页的问题。

## 二、核心原理

策略：逐页编码后用跨页注意力/检索定位相关页，再综合；或用层次模型（页内 token → 页级表示 → 文档级）。长上下文模型也可直接喂多页拼接。

## 三、数学形式

层次聚合：

$$h_{doc}=\text{Attn}\big(\{h_{page_1},\dots,h_{page_M}\}\big)$$

$h_{page}$ 为单页表示。

## 四、代码实现

```python
page_reps = [encode(p) for p in pages]
doc_rep = transformer(page_reps)
ans = qa_head(doc_rep, question)
```

## 五、与其他对比

- 与 长视频理解 共享长序列层次思路。
- 与 多页长文档 同主题延伸。

## 六、常见误区

- 跨页证据被分页截断致漏答。
- 直接拼所有页超上下文。

## 七、与开源书对应

- mlabonne/llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- 多页如何找证据？答：先检索/注意力定位相关页与段落，再综合作答。

## 九、演进

单页 → 页级检索 → 层次跨页注意力。

## 十、小结

多页长文档靠层次与检索跨越分页，是文档智能的实用挑战。
