# 版面与图表理解

> 对应图表 QA（ChartQA）；版面感知预训练（LayoutLMv3 等）。

## 一、背景与挑战

图表（折线/柱状/饼）信息藏在视觉编码中，需“读图”而非读文本；版面决定内容归属。

## 二、核心原理

图表理解：检测图元（轴/柱/点/图例）→ 提取数据绑定 → 回答数值/趋势问题。版面理解：识别区域类型与层级，服务抽取与导航。

## 三、数学形式

图表数据提取可视为结构化抽取：

$$\hat D = \arg\max_D p(D | \text{elements}(I))$$

$D$ 为提取的数据表。

## 四、代码实现

```python
elems = chart_parser(image)        # 图元+数值
table = bind_values(elems)
ans = answer_on_table(table, q)
```

## 五、与其他对比

- 与 表格理解 共享结构抽取。
- 与 OCR与布局分析 共享检测。

## 六、常见误区

- 直接 OCR 图表文字忽略视觉数值编码。
- 图例映射错致数据绑定反。
