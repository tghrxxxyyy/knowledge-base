# 文档智能应用

> 见「文档智能深入/文档智能总览」；落地场景。

## 一、背景与挑战

合同/票据/财报/简历等需自动化处理。

## 二、核心原理

典型应用：票据抽取（金额/税号）、合同条款抽取与比对、财报关键指标抽取、简历解析。结合 RAG 做企业知识库问答。落地的关键是**准确率+SLA**，常以「模型+人工复核」闭环。

## 三、关键要点

- 高准确场景需置信度阈值+人工。
- 模板多变需泛化。

## 四、代码实现

```python
fields = extract(invoice, schema=["金额","税号","日期"])
```

## 五、与其他对比

- 人工慢贵；智能快但需校验。

## 六、常见误区

- 全自动无复核——高风险领域不可。
