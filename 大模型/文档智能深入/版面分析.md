# 版面分析

> 见「文档智能深入/文档智能总览」；LayoutLM 系列（Xu et al., 2020）。

## 一、背景与挑战

文档元素位置/层级复杂，需理解空间布局。

## 二、核心原理

**LayoutLM** 把文本、视觉、布局（bbox 坐标）三模态融合，预训练于扫描文档，用于分类/抽取/问答。版面分析输出区块类型（标题/段落/表格/图）与阅读顺序，是后续结构化的基础。

## 三、数学形式

联合损失：文本 MLM + 图像 + 位置（`[x0,y0,x1,y1]` 归一化）。

## 四、代码实现

```python
# LayoutLM 输入含 token + bbox
inputs = tokenizer(text, boxes=bboxes, ...)
```

## 五、关键要点

- bbox 归一化很重要。
- 阅读顺序非简单从上到下（多栏）。

## 六、与其他对比

- 纯文本丢布局；LayoutLM 用坐标。

## 七、常见误区

- 按坐标排序即阅读序——多栏错。
