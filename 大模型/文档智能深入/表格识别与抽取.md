# 表格识别与抽取

> 见「文档智能深入/文档智能总览」；表格结构识别难点。

## 一、背景与挑战

表格有合并单元格、跨页、无边框，结构化极难。

## 二、核心原理

先检测表格区域，再识别**逻辑结构**（行/列/单元格归属），转 HTML/DataFrame。深度模型用图神经网络或 Transformer 建模单元格关系；大模型可直接把表格图转为 Markdown/CSV。

## 三、关键要点

- 逻辑结构 > 视觉外观。
- 跨页表格需拼接。

## 四、代码实现

```python
table_md = vlm(image, "把表格转为Markdown")
df = pd.read_csv(StringIO(table_md))
```

## 五、与其他对比

- 规则脆弱；模型鲁棒。

## 六、常见误区

- 看到线就有结构——无线表格更难。
