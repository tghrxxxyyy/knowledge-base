# 算子融合与内核优化

> 对应算子融合（kernel fusion）、FlashAttention（Dao et al., 2022）。

## 一、背景与挑战

逐算子读写显存（HBM）开销大；小算子多造成带宽浪费。

## 二、核心原理

融合相邻算子（如 LayerNorm+RMSNorm+MatMul）于单 kernel，复用 SRAM；FlashAttention 分块计算注意，不物化大 N×N 矩阵。

## 三、数学形式

注意 $O = \text{softmax}(QK^\top/\sqrt d)V$；FlashAttention 按块算 online softmax，显存 $O(N)$ 而非 $O(N^2)$。

## 四、代码实现

```python
y = torch.compile(model)            # 自动融合算子
# 或 flash_attn_func(q,k,v)
```

## 五、与其他对比

- 与 低比特推理内核深入 同属工程优化。
- 与 模型服务负载均衡深入（吞吐）相关。

## 六、常见误区

- 盲目融合致寄存器溢出反降速。
- 忽视 SRAM 容量上限。

## 八、面试题

- FlashAttention 省在哪？答：分块避免物化 N×N 注意矩阵，显存与带宽双降。

## 九、演进

朴素注意 → 融合 → FlashAttention/FlashDecoding。

## 十、小结

算子融合与 FlashAttention 以 SRAM 复用降带宽，提端侧/云吞吐。
