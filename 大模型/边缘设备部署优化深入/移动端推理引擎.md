# 移动端推理引擎

> 对应 NCNN、MNN、TensorFlow Lite、ONNX Runtime Mobile。

## 一、背景与挑战

移动端 ARM/NPU 多样，需轻量引擎支持异构执行与低延迟。

## 二、核心原理

引擎做图优化（常量折叠/算子融合）、后端抽象（CPU Neon/NPU）、内存复用；模型转 ONNX/TFLite 后部署。

## 三、数学形式

延迟 $L = \sum_k t_k^{op} + t_{mem}$（算子+访存）；内存复用降峰值。

## 四、代码实现

# ONNX Runtime Mobile 推理
sess = ort.InferenceSession("model.onnx", providers=["CPUExecutionProvider"])

## 六、常见误区

- 直接跑 PyTorch 移动端（体积大、慢）。
- 忽略 NPU 算子覆盖不全退 CPU。

## 八、面试题

- 移动端为何用专用引擎？答：图优化+后端抽象+内存复用，远胜直接框架推理。

## 九、演进

框架直跑 → TFLite/NCNN → NPU 委托。

## 十、小结

移动端靠专用引擎做图优化与异构后端，方达低延迟。
