# 张量并行与卸载

> 对应模型并行（Shoeybi et al., 2019）；llama.cpp CPU 卸载。

## 一、背景与挑战

单设备放不下大模型；张量并行切矩阵到多设备，卸载把部分层放 CPU/磁盘。

## 二、核心原理

列/行并行切线性层权重；Megatron 式：前馈列切、注意头切；卸载按层或按张量把不活跃部分移到慢存储，用时取回。

## 三、数学形式

$Y = [W_1;W_2]X = W_1 X + W_2 X$（列并行，各设备算部分）；$\sum$ 经 all-reduce 聚合。

## 四、代码实现

```python
# 卸载部分层到 CPU
layer.to('cpu') if offload else layer.to('cuda')
```

## 五、与其他对比

- 与 模型服务负载均衡深入（多副本）不同，这里是单模型切分。
- 与 边缘设备部署优化深入 总览衔接。

## 六、常见误区

- 卸载过度致 PCIe 带宽成瓶颈，反比纯 CPU 慢。
- 张量并行通信开销在低速互联下抵消收益。

## 八、面试题

- 何时用卸载而非并行？答：无多卡或互联慢时，用 CPU/磁盘卸载换时间。

## 九、演进

单卡 → 张量并行 → 卸载+分层调度。

## 十、小结

并行与卸载解决单设备容量限制，瓶颈在互联带宽。
