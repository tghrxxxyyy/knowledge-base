# 边缘部署总览

> 对应 llama.cpp（GGUF）、TensorRT-LLM；端侧推理综述。

## 一、背景与挑战

手机/笔记本/嵌入式显存小、无独立 GPU，需把大模型压缩并高效跑在 CPU/NPU。

## 二、核心原理

流程：量化（4bit）→ 格式转换（GGUF/ONNX）→ 推理引擎（llama.cpp/NCNN/MNN）→ 内存映射与 KV 卸载。

## 三、数学形式

显存需求 $\approx 1.1\times P\times \frac{b}{8}$ 字节（P 参数量，b 比特）；4bit-7B 约 3.9GB。

## 四、代码实现

```python
# 用 llama.cpp 加载 GGUF
from llama_cpp import Llama
llm = Llama(model_path="llama-7b.Q4_K.gguf", n_ctx=4096)
```

## 五、与其他对比

- 与 模型压缩与稀疏量化深入（产出量化权重）衔接。
- 与 模型服务负载均衡深入（云端服务）对照。

## 六、常见误区

- 忽视 CPU 内存带宽成瓶颈（非算力）。
- 上下文过长致 KV 溢出内存。

## 七、与开源书对应

## 八、面试题

- 端侧为何先量化？答：显存/带宽受限，4bit 把 7B 压到 4GB 内，且访存量决定速度。

## 九、演进

云端 → 量化+GGUF 端侧 → NPU 加速。

## 十、小结

边缘部署是量化+格式+引擎的协同，内存带宽常是瓶颈。
