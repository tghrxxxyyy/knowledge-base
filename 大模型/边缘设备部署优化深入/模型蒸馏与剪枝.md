# 模型蒸馏与剪枝

> 对应 Hinton et al., *Distillation*, 2015；模型压缩综述。

## 一、背景与挑战

大模型端侧难跑；蒸馏出小模型、剪枝减参数是常用降规模手段。

## 二、核心原理

蒸馏：小模型（学生）匹配大模型（教师）软标签/隐含表示；剪枝：去冗余连接（结构化/非结构化）。

## 三、数学形式

蒸馏损失 $\mathcal L = \alpha\, \text{KL}(\sigma(z_t/T), \sigma(z_s/T)) + (1-\alpha)\mathcal L_{ce}$；温度 T 软化。

## 四、代码实现

```python
loss = 0.7*KL(soft_t, soft_s) + 0.3*ce(s_logits, y)
```

## 五、与其他对比

- 与 模型压缩与稀疏量化深入（量化）互补，可串联。
- 与 数据高效学习深入（若新增）共享。

## 六、常见误区

- 蒸馏温度过低退化为硬标签。
- 非结构化剪枝需硬件支持才真加速。

## 八、面试题

- 蒸馏为何用温度？答：软化教师概率，暴露类间相似性，学生学得更好。

## 九、演进

剪枝 → 蒸馏 → 量化蒸馏联合。

## 十、小结

蒸馏/剪枝是端侧小模型来源，常与量化串联压缩。
