# 对比视觉语言预训练（CLIP）

> 对应 Radford et al., *Learning Transferable Visual Models (CLIP)*, 2021。

## 一、背景与挑战

图像分类标签昂贵且封闭；需从图文对自监督学开放语义表征。

## 二、核心原理

图像编码器（ViT/CNN）与文本编码器分别编码，对比损失拉近正图文对、推远负对，形成跨模态共享空间。

## 三、数学形式

对称 InfoNCE：$\mathcal L = \frac12(\mathcal L_I + \mathcal L_T)$；相似度用余弦 $\langle I,T\rangle = I^\top T / (\|I\|\|T\|)$。

## 四、代码实现

```python
logits = (img_f @ txt_f.t()) / tau
labels = arange(len(img_f))     # 对角线为正对
loss = cross_entropy(logits, labels)
```

## 五、与其他对比

- 是 多模态对齐架构 的表征基础。
- 与 检索增强失效分析深入 同用嵌入相似度。

## 六、常见误区

- batch 过小负样本不足致表征塌缩。
- 直接 zero-shot 分类需合适 prompt 工程。

## 七、与开源书对应

## 八、面试题

- CLIP 能做检索吗？答：能，图文共享嵌入，直接按余弦召回最相近跨模态样本。

## 九、演进

Word2Vec 类比 → VSE → CLIP/ALIGN → 大规模对比。

## 十、小结

CLIP 用对比学习建立图文共享空间，是多模态基石。
