# 多模态对齐架构

> 对应 LLaVA（Liu et al., 2023）的投影器；Flamingo 交叉注意力。

## 一、背景与挑战

如何让预训练 LLM“读懂”视觉特征，又不破坏语言能力。

## 二、核心原理

两种主流：轻量投影器（MLP/LoRA 把 ViT 输出映射到词嵌入空间，接 LLM，如 LLaVA）；交叉注意力（在 LLM 层插入视觉交叉注意力，如 Flamingo）。

## 三、数学形式

投影 $h_v = W\cdot \text{ViT}(x_{img}) \in \mathbb R^{n\times d_{llm}}$；交叉注意力 $A=\text{softmax}(QK_v^\top)V_v$。

## 四、代码实现

```python
feat = vit(image)                  # (p, d_v)
tokens = proj(feat)                # 映射到 LLM 词空间
out = llm(inputs_embeds=cat(text_emb, tokens))
```

## 五、与其他对比

- 投影器简单省钱，交叉注意力更灵活但重。
- 与 指令微调数据质量深入（多模态指令）衔接。

## 六、常见误区

- 视觉编码器与 LLM 分辨率/语义错位。
- 冻 LLM 时投影器容量不足。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh
- llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- LLaVA 投影器作用？答：把 ViT 视觉特征线性映射到 LLM 词嵌入空间，使其可被语言模型理解。

## 九、演进

交叉注意力 → 投影器 → 统一 tokenizer（如视觉 token）。

## 十、小结

对齐架构决定多模态信息如何流入 LLM，投影/交叉各有权衡。
