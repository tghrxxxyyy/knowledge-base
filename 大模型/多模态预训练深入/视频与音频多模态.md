# 视频与音频多模态

> 对应视频语言模型（如 FrozenBiLM、Video-LLaVA）与音频（Whisper/audio-LLM）。

## 一、背景与挑战

视频/音频是时序多帧/多通道信号，需时序建模并跨模态对齐文本。

## 二、核心原理

视频：采样帧→ViT→时序聚合（池化/时序注意力）得视频 token；音频：波形→编码器（如 HuBERT/Whisper）→token，再接 LLM。

## 三、数学形式

视频表征 $V = \text{Agg}(\{ \text{ViT}(f_t) \}_{t=1}^T)$；音频帧 $A_t=\text{Enc}_{audio}(w_t)$。

## 四、代码实现

```python
frames = sample(video, T=8)
v_tokens = temporal_pool(vit(frames))
out = llm(concat(text_emb, v_tokens))
```

## 五、与其他对比

- 是 多模态预训练总览 的扩展模态。
- 与 流式生成与增量解码深入 同用 LLM 后端。

## 六、常见误区

- 帧采样过疏丢动作语义。
- 音频与文本对齐错位致幻觉。

## 七、与开源书对应

## 八、面试题

- 视频多模态难点？答：帧间时序与跨模态对齐，且算力随帧数线性增。

## 九、演进

图像→视频帧→音频/统一时空 token。

## 十、小结

视频/音频把多模态推向时序，需时序聚合与跨模态对齐。
