# 视觉编码器（ViT）

> 对应 Dosovitskiy et al., *An Image is Worth 16x16 Words (ViT)*, 2021。

## 一、背景与挑战

CNN 归纳偏置强但难规模化；需可扩展、与 Transformer 同源的视觉表征供多模态使用。

## 二、核心原理

把图像切成 patch 序列，加位置嵌入，过 Transformer 编码；CLS 或池化得图像表征，适配对比/生成任务。

## 三、数学形式

patch 数 $N = (H/p)(W/p)$；输入 $X = [x_{patch_1},\dots,x_{patch_N}] + E_{pos}$；输出 $Z = \text{Transformer}(X)$。

## 四、代码实现

```python
from timm import create_model
vit = create_model("vit_base_patch16_224", pretrained=True)
feat = vit.forward_features(image)
```

## 五、与其他对比

- 是多模态对齐架构 的视觉前端。
- 与 多模态预训练数据（需配图像）关联。

## 六、常见误区

- 分辨率与预训练不一致致性能掉。
- 直接取最后层未必最优（可用多层）。

## 八、面试题

- ViT 为何可规模化？答：去 CNN 偏置、纯注意力随数据与算力稳定提升，契合 Transformer 栈。

## 九、演进

CNN → ViT → 更大规模/自监督（DINO/Mae）。

## 十、小结

ViT 提供与语言同构的视觉表征，是多模态的关键前端。
