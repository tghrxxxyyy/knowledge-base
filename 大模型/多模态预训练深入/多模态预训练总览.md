# 多模态预训练总览

> 对应 Radford et al., *CLIP*, 2021；Alayrac et al., *Flamingo*, 2022；Liu et al., *LLaVA*, 2023。

## 一、背景与挑战

文本大模型需理解图像/视频/音频；多模态预训练要建跨模态对齐表征并接入语言模型。

## 二、核心原理

两路线：对比式（图文对齐，如 CLIP）学会“图-文”共享嵌入；生成式（视觉编码+语言模型解码，如 LLaVA/Flamingo）做多模态指令。

## 三、数学形式

对比损失 $\mathcal L_{CLIP} = -\log \frac{e^{\langle I,T_+\rangle/\tau}}{\sum_j e^{\langle I,T_j\rangle/\tau}}$；跨模态对齐温度 $\tau$。

## 四、代码实现

```python
img_emb = vision_encoder(image)
txt_emb = text_encoder(text)
loss = clip_loss(img_emb, txt_emb, temperature=0.07)
```

## 五、与其他对比

- 与 预训练数据流水线深入（数据侧）共享管线。
- 与 检索增强失效分析深入 无关但同需对齐质量。

## 六、常见误区

- 只对齐表象忽略细粒度语义。
- 视觉编码器冻错导致语言模型学不到视觉。

## 八、面试题

- CLIP 为何强？答：大规模图文对比学到可迁移的共享语义嵌入，零样本泛化好。

## 九、演进

双塔对比 → 交叉注意力 → 视觉+LLM 生成式。

## 十、小结

多模态预训练以对齐/生成两范式，把语言模型扩展至多感官。
