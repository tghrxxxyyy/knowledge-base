# 多模态预训练数据

> 对应 Schuhmann et al., *LAION-5B*, 2022；图像-文本对规模研究。

## 一、背景与挑战

对比/生成式多模态需海量图文对；数据质量与多样决定泛化与偏见。

## 二、核心原理

从网页 alt 文本抓取图文对（LAION），经 CLIP 打分过滤低质对；视频/音频需转帧/转写配对。

## 三、数学形式

数据效用随规模近似幂律；过滤阈值 $s_{CLIP}(img,txt)>\tau$ 保质量。

## 四、代码实现

```python
pairs = crawl_alt_text(pages)
pairs = [p for p in pairs if clip_score(p.img,p.txt) > 0.3]
```

## 五、与其他对比

- 与 预训练数据流水线深入（清洗）同源。
- 与 指令微调数据质量深入（多模态指令）衔接。

## 六、常见误区

- 噪声图文对引入错误关联。
- 西方中心数据致文化偏见。

## 八、面试题

- 图文对质量如何影响模型？答：低质对学错关联、降零样本能力，需 CLIP 过滤。

## 九、演进

人工标注 → 网页抓取 → CLIP 过滤大规模。

## 十、小结

多模态数据规模与质量是能力上限，清洗不可省。
