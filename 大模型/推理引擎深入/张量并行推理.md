# 张量并行推理

> 对应 llm-course（mlabonne）并行推理章节；Megatron-LM 张量并行（Shoeybi et al., 2020）；TensorRT-LLM、DeepSpeed-Inference 并行实现（以官方最新文档为准）。

## 一、背景与挑战

单张加速卡显存与算力有限，超大模型（数十到数百 B 参数）单卡放不下、算不动。并行推理要把模型「切开」分布到多卡，常见切法：

- 数据并行（DP）：同模型多副本，切数据——不适合单模型放不下。
- 张量并行（TP）：层内权重切分，单卡只持有一部分。
- 流水线并行（PP）：按层切到不同卡，串行流水。

张量并行的核心难题是「如何在切分权重的同时，保证计算结果与单卡一致，且通信开销可控」。

## 二、核心原理

以 Transformer 的线性层 $Y = XA$ 为例，按输出维度把权重 $A$ 列切成 $[A_1, A_2]$（列并行），每张卡算 $Y_i = X A_i$，再 all-gather 拼回 $Y$；或按输入维度行切（行并行），各卡算局部后用 all-reduce 求和。Megatron 风格把「列并行 + 行并行」配对，使矩阵乘的切分与通信自然衔接：

- 每个 Transformer 块内，QKV 投影用列并行，输出投影用行并行，行并行的 all-reduce 正好与下一层输入衔接，减少额外通信。
- 注意力头的维度也可并行切到多卡。

KV 缓存与激活同样需分布，且每步 decode 都触发一次 all-reduce。

## 三、形式化与数学基础

设权重按列切 $A=[A_1\mid A_2]$，$A_i\in\mathbb{R}^{d\times d/2}$，输入 $X\in\mathbb{R}^{n\times d}$，则

$$ Y = XA = [X A_1 \mid X A_2] = [Y_1\mid Y_2] $$

各卡持有 $A_i$ 只算 $Y_i$，无需通信即可局部完成；需要完整 $Y$ 时 all-gather。对于 $Y=(XA)B$ 的行并行，先列并行得 $XA$ 局部，再做 $Z_i=(XA)B_i$ 并 all-reduce：

$$ Z = \sum_i Z_i = (XA)\sum_i B_i = (XA)B $$

保证数值等价于单卡。

## 四、代码实现

```python
# 列并行线性层示意（伪代码）
import torch.distributed as dist

class ColumnParallelLinear:
    def __init__(self, weight_full):
        # 按列切分权重到各 rank
        self.local = split_columns(weight_full, dist.get_rank(),
                                   dist.get_world_size())
    def forward(self, x):
        y_local = x @ self.local          # 本卡只算一部分
        return y_local                     # 下游 all-gather 拼回

# 行并行后需 all-reduce 求和
def row_parallel(x, local_w):
    z = x @ local_w
    dist.all_reduce(z)                     # 各卡局部和 -> 全局和
    return z
```

## 五、与其他技术对比

| 并行 | 切分对象 | 通信 | 适用 |
|------|----------|------|------|
| 数据并行 | 数据 | 梯度 | 模型能放下 |
| 张量并行 | 层内权重 | 高（每步） | 单卡放不下 |
| 流水线并行 | 层 | 中（边界） | 超深模型 |

TP 通信最密，需 NVLink 级互联。

## 六、常见误区

- 多卡一定快：TP 每步 all-reduce，通信成瓶颈时反而更慢。
- TP 可无限扩展：通信开销随卡数上升，存在收益拐点。
- 忽视互联带宽：TP 强依赖 NVLink，跨节点 PCIe/网络会崩性能。

## 九、演进与趋势

单卡 → 纯 TP → TP+PP 混合并行 → 序列并行（SP）/ 上下文并行进一步切长序列 → 与量化、专家并行（MoE）结合。趋势是「多维并行自动搜索」以适配任意硬件拓扑。

当模型同时用 TP 与 PP，形成「二维网格」，需设计「流水线气泡（bubble）」最小化策略，例如 1F1B 调度让前向与反向重叠，提升设备利用率。

专家并行（MoE）可视为 TP 在专家维度上的特例：各专家分布到不同卡，路由 token 时产生 all-to-all 通信，是另一种需高速互联的切分方式。

## 十、小结

张量并行是超大模型推理的基础：用「层内权重切分 + 配对通信（all-reduce/all-gather）」在数值等价前提下把模型铺到多卡，但性能高度依赖高速互联，需与 PP、量化协同。
