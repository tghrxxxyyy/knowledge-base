# 张量并行推理

> 见「推理优化/张量并行与流水线并行」与「推理引擎深入/推理引擎选型」。

## 一、背景与挑战

单卡放不下大模型，需多卡切分推理。

## 二、核心原理

层内权重按维度切到多卡（Megatron 式），前向各卡算部分再 all-reduce 合并；KV 也可并行。

## 三、关键要点

- 通信量随层数增长。
- 需高速互联（NVLink）。

## 四、代码实现

```python
# 伪：按列切线性
y = all_reduce(frag0(x) + frag1(x))
```

## 五、与其他对比

- 数据并行不适单模型；张量并行切层内。

## 六、常见误区

- 多卡一定快——通信可能成瓶颈。

## 七、与开源书对应

- Megatron-LM; TensorRT-LLM.
- llm-course: https://github.com/mlabonne/llm-course
