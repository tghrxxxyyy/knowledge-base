# 连续批处理深入

> 见「推理优化/连续批处理」与「推理引擎深入/推理引擎选型」。

## 一、背景与挑战

静态批处理空等、浪费 GPU，动态批需精细调度。

## 二、核心原理

每步把就绪请求组批，完成的立即退出、新请求随时加入，配合 PagedAttention 实现高 GPU 利用率。

## 三、关键要点

- 调度与内存分配耦合。
- 需防长请求饿死短请求。

## 四、代码实现

```python
while running: batch = scheduler.step(); out = model(batch)
```

## 五、与其他对比

- 静态批等长填充；连续批灵活。

## 六、常见误区

- 批越大越好——延迟升、OOM。

## 七、与开源书对应
