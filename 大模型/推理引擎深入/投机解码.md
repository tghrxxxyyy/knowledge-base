# 投机解码

> 对应 llm-course（mlabonne）推理优化章节；Leviathan et al., 2023（Speculative Decoding）；Chen et al., 2023（加速自回归解码）；自投机（Self-Speculative）、MEDUSA 等变体（以官方最新文档为准）。

## 一、背景与挑战

自回归解码「每步只产一个 token」，单步延迟受限于内存带宽（memory-bound）：大模型参数巨大，每生成一个 token 都要把权重从显存搬进计算单元，计算本身很快，瓶颈在搬运。结果：

- 延迟高：尤其长文本生成，步数线性累积。
- 算力浪费：每步只算一个 token，大矩阵乘法未被填满。
- 难靠堆卡提速：单序列解码本质串行。

投机解码（Speculative Decoding）在「不损失目标模型分布」的前提下并行验证，加速生成。

## 二、核心原理

核心思路：用小而快的「草稿模型（draft model）」一次贪心/采样猜出 $k$ 个候选 token，再让目标大模型「一次前向」并行验证这 $k$ 个位置：

1. 草稿阶段：draft 模型自回归产出候选序列 $y_1,\dots,y_k$。
2. 验证阶段：目标模型对前缀 $[x, y_1,\dots,y_k]$ 做一次前向，得到各位置分布。
3. 接受：按「目标分布/草稿分布」的修正拒绝采样，从第一个分歧处截断，保留前缀中接受的部分。
4. 残差：被拒位置由目标模型重采样一个 token，保证输出分布严格等于目标模型。

接受率高时，每步等效产出多个 token，速度接近草稿模型，质量等同大模型。

## 三、形式化与数学基础

设草稿分布 $q$、目标分布 $p$。位置 $i$ 接受概率：

$$ P_{\text{accept}}(i) = \min\!\left(1,\; \frac{p(y_i\mid x_{<i})}{q(y_i\mid x_{<i})}\right) $$

当 $p=q$ 时接受率为 1。期望每轮接受长度

$$ \mathbb{E}[n_{\text{acc}}] = \sum_{i=1}^{k} \prod_{j=1}^{i} P_{\text{accept}}(j) $$

总产出分布由「修正拒绝采样」保证与 $p$ 一致，即无损（lossless）。

## 四、代码实现

```python
# 投机解码示意（伪代码）
def speculative_decode(big, small, x, k=5):
    draft = [x]
    for _ in range(k):                  # 草稿模型连猜 k 个
        nxt = small.sample(draft)
        draft.append(nxt)
    # 大模型一次前向并行验证
    probs = big.dist(draft)
    out, accepted = x[:], 0
    for i in range(1, len(draft)):
        q = small.p(draft[i])
        p = probs[i]
        if rand() < min(1, p / q):      # 接受
            out.append(draft[i]); accepted += 1
        else:                           # 拒绝，目标模型重采样
            out.append(big.sample(probs[i:]))
            break
    return out
```

## 五、与其他技术对比

| 方法 | 质量 | 速度 | 代价 |
|------|------|------|------|
| 纯小模型 | 降 | 快 | 质量损 |
| 纯大模型 | 高 | 慢 | 慢 |
| 投机解码 | 等同大模型 | 接近小模型 | 需 draft |

投机解码「既要又要」：保质量提速度。

## 六、常见误区

- 草稿越大越好：草稿太慢会反拖整体，需与验证开销平衡。
- 必有损：标准算法经拒绝采样后无损，分布等同目标模型。
- 只靠独立小模型：自投机（用大模型浅层/早期退出）也可，无需额外模型。

## 九、演进与趋势

草稿-验证（独立小模型）→ 自投机（浅层/early-exit）→ 多头草案（MEDUSA、EAGLE 并行出多 token）→ 与前缀缓存、量化协同。趋势是把「草案」做成大模型自身的一部分，降低额外模型负担。

## 十、小结

投机解码是推理加速利器：用「小模型草拟 + 大模型并行验证 + 拒绝采样保无损」，在质量零损失前提下显著逼近小模型速度，是内存带宽瓶颈下的优雅解法。
