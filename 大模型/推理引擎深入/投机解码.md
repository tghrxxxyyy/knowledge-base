# 投机解码

> 见「推理优化/投机解码」与「推理引擎深入/推理引擎选型」。

## 一、背景与挑战

大模型逐 token 自回归慢（受限于单步延迟），需加速。

## 二、核心原理

用小草稿模型快速猜多 token，大模型一次验证（并行接受正确前缀），接受率高时接近小模型速度、保大模型质量。

## 三、数学形式

接受概率 ~ 草稿与模型分布接近度。

## 四、代码实现

```python
draft = small.generate(x, k=5); verified = big.verify(x, draft)
```

## 五、关键要点

- 草稿模型需与主力分布近。
- 自投机（同一模型浅层）亦可。

## 六、与其他对比

- 单纯小模型质量降；投机保质量提速度。

## 七、常见误区

- 草稿越大越好——反拖慢。
