# 推理引擎选型

> 对应 llm-course 部署章；引擎含 vLLM、TGI、TensorRT-LLM、llama.cpp、SGLang。

## 一、背景与挑战

不同引擎在吞吐、延迟、硬件、特性上差异大，需取舍。

## 二、核心原理

vLLM（高吞吐 Python）、TGI（生产级）、TensorRT-LLM（NVIDIA 极致）、llama.cpp（端侧）、SGLang（结构化/吞吐）各有侧重。

## 三、关键要点

| 引擎 | 强项 | 场景 |
|------|------|------|
| vLLM | 吞吐 | 服务端 |
| TRT-LLM | NVIDIA 性能 | 高并发 |
| llama.cpp | 端侧 | CPU/手机 |
| SGLang | RadixAttention | 复用前缀 |

## 四、代码实现

```python
# vLLM 启动
from vllm import LLM; LLM(model="x")
```

## 五、与其他对比

- 通用 vs 专用；Python 易用 vs C++ 性能。

## 六、常见误区

- 最快引擎通用——需匹配硬件。

## 七、与开源书对应

- vLLM/TGI/SGLang 官方文档.
- llm-course: https://github.com/mlabonne/llm-course
