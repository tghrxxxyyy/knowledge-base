# 大模型少样本选择性标注

> 对应 Margatina et al. 2023 "Distilled Generative Retrieval", 及选择性标注实践综述。

## 一、背景与挑战

LLM 标注成本高昂。选择性标注(Selective Annotation)用少量人工标注 + 模型自动筛选，最大化下游任务表现，同时控制预算。

## 二、核心原理

利用 LLM 生成 embedding 或自评置信度，对候选指令/样本排序，优先标注“高信息量且多样”的子集。典型流程：聚类→每簇选代表→人工标注→微调。

## 三、数学形式

设嵌入 $\phi(x)$，用 k-Medoids 选 $k$ 个代表：

$$
\min_{S} \sum_{x\in U} \min_{s\in S} \|\phi(x)-\phi(s)\|_2
$$

再对代表做不确定性加权：

$$
score(x) = \mathrm{Unc}(x) + \lambda \cdot \mathrm{Div}(x)
$$

## 四、代码实现

```python
import torch

def select_annotate(embs, unc, k, lam=0.5):
    # 简化：先按多样性聚类中心，再乘不确定性
    return (unc + lam * embs.norm(dim=-1)).topk(k).indices
```

## 五、与其他对比

与经典池式 AL 不同，LLM 时代用模型自身表征做多样性，且标注对象常为“指令”而非分类样本。

## 六、常见误区

误区：直接选模型最不确定的指令。指令空间高噪声，应先用聚类降冗余。

## 八、面试题

- Q：选择性标注与主动学习关系？答：是 AL 在 LLM 指令数据筛选的特例。
- Q：为何先聚类后标注？答：降低冗余、保证覆盖、节省预算。

## 九、演进

从人工规则到 LLM 自评(LLM-as-annotator)与自动难度排序结合。

## 十、小结

大模型选择性标注把 AL 的“不确定性+多样性”思想迁移到指令空间，是划算的数据策略。
