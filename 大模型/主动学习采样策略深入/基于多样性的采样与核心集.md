# 基于多样性的采样与核心集

> 对应 Sener & Savarese 2018 "Active Learning for Convolutional Neural Networks", ICRA 2018。

## 一、背景与挑战

仅按不确定性采样会导致选出的样本高度相似(如全是同一类难样本)。需引入多样性，使所选子集覆盖整个特征空间。

## 二、核心原理

核心集(Core-set)方法：在未标注池中选最小子集，使其特征覆盖逼近全集。常用 k-中心(k-Center)贪心：每次选离已选集合最远的样本。

## 三、数学形式

k-Center 目标：

$$
\min_{S\subset U, |S|=k} \max_{x\in U} \min_{s\in S} d(\phi(x), \phi(s))
$$

其中 $\phi$ 为特征映射，$d$ 为欧氏距离。也常用行列式点过程(DPP)建模多样性。

## 四、代码实现

```python
import torch

def kcenter_greedy(feats, budget):
    selected = [0]
    for _ in range(budget - 1):
        dist = torch.cdist(feats, feats[selected]).min(1).values
        selected.append(dist.argmax().item())
    return selected
```

## 五、与其他对比

不确定性关注“信息量”，多样性关注“覆盖度”，二者常结合(如 BADGE 用梯度嵌入的 k-Medoids)。

## 六、常见误区

误区：多样性仅看原始输入空间。应在语义特征空间度量才有效。

## 八、面试题

- Q：为何要多样性采样？答：避免冗余，覆盖特征空间提升标注效率。
- Q：k-Center 复杂度？答：贪心 $O(nk)$，可用特征降维提速。

## 十、小结

多样性是主动学习可扩展性的关键，应与不确定性联合优化。
