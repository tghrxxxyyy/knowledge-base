# 主动学习在指令数据筛选中的实践

> 对应 datawhalechina/llm-universe 实战教程与 dair-ai/Prompt-Engineering-Guide。

## 一、背景与挑战

指令微调数据常冗余且质量参差。用主动学习筛选子集，可在更小数据下达到接近全量微调的效果，显著降低训练成本。

## 二、核心原理

实践流程：(1) 用 LLM 对所有指令生成 embedding；(2) 聚类分桶；(3) 每桶内用不确定性/困惑度选代表；(4) 人工校验后微调；(5) 用验证集表现迭代扩充。

## 三、数学形式

每轮新增样本集 $A_t$ 使验证损失下降最大：

$$
A_t = \arg\max_{A\subset U,|A|=b} \Delta \mathcal{L}_{val}(\theta_t, A)
$$

实际以代理指标(困惑度下降、聚类覆盖)近似。

## 四、代码实现

```python
def active_round(embs, ppl, budget):
    import torch
    scores = ppl / (embs.var(0).sum() + 1e-8)
    return scores.topk(budget).indices.tolist()
```

## 五、与其他对比

相比全量指令微调，主动筛选省数据；相比随机采样，主动筛选收敛更快、上限更高。

## 六、常见误区

误区：一次选定不再迭代，错过难样本。应多轮迭代扩充。

## 八、面试题

- Q：指令数据筛选为何用聚类？答：去冗余、保多样、控预算。
- Q：如何评估筛选质量？答：下游验证集表现 + 数据覆盖率。

## 十、小结

主动学习是低成本构建高质量指令集的实用框架，核心是迭代+多样性+不确定性。
