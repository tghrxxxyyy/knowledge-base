# 基于不确定性的采样熵边际最小置信度

> 对应 Settles 2009 "Active Learning Literature Survey", University of Wisconsin TR 1648。

## 一、背景与挑战

池式主动学习(pool-based AL)从大量未标注数据中挑选“最值得标注”的样本以降低标注成本。核心难点是定义“信息量最大”的样本。

## 二、核心原理

三类经典不确定性采样：(1) 最小置信度(Least Confidence)选预测概率最低的样本；(2) 边际采样(Margin)选 top-1 与 top-2 概率差最小者；(3) 熵采样(Entropy)选预测分布最平坦者。

## 三、数学形式

最小置信度：

$$
x^\star = \arg\min_x \max_k p_\theta(y=k\mid x)
$$

边际采样：

$$
x^\star = \arg\min_x \left(p_{\theta}(y_1\mid x)-p_{\theta}(y_2\mid x)\right)
$$

熵采样：

$$
x^\star = \arg\max_x -\sum_k p_\theta(y=k\mid x)\log p_\theta(y=k\mid x)
$$

## 四、代码实现

```python
import torch

def entropy(probs):
    return -(probs * probs.log()).sum(-1)

def margin(probs):
    top2 = probs.topk(2, dim=-1).values
    return -(top2[...,0] - top2[...,1])
```

## 五、与其他对比

熵考虑全部分布，边际更关注决策边界，最小置信度计算最简。对类别不均衡问题边际通常更稳。

## 六、常见误区

误区：高熵样本一定有用，实际上噪声样本也高熵。需结合代表性(diversity)过滤异常点。

## 八、面试题

- Q：三种不确定性采样差异？答：置信度看最高类概率，边际看前两类差，熵看整体分布平坦度。
- Q：高熵样本一定该标吗？答：不一定，噪声也会高熵，应结合多样性。

## 九、演进

从单模型不确定性到集成/贝叶斯不确定性(BALD)，再到 LLM 时代的选择性标注。

## 十、小结

不确定性采样是主动学习基石，但需配合去噪与多样性约束才鲁棒。
