# 多语种分词总览

> 对应 Kudo & Richardson, *SentencePiece*, 2018；Xue et al., *ByT5*, 2022（字节模型）；Touvron et al., *LLaMA*, 2023（单分词器多语）。

## 一、背景与挑战

单一分词器服务多语言时，资源不平衡致低资源语言被切成大量子词，序列长、效率低、欠表示。

## 二、核心原理

用统一 SentencePiece 在混合语料上训练，字节级 BPE 可部分缓解；但共享词表仍被高资源语言主导。

## 三、数学形式

语言 $\ell$ 平均 token 数 $T_\ell\propto 1/\text{coverage}_\ell$；资源越少 $T_\ell$ 越大，训练步等效权重越低。

## 四、代码实现

```python
sp = sentencepiece.SentencePieceProcessor()
sp.load("multilingual.model")
print(len(sp.encode("こんにちは")), "tokens-ja")
```

## 五、与其他对比

- 与 分词器训练与词表构建深入（训练方法）共用。
- 与 数据混合比例课程深入（语料配比影响词表）相关。

## 六、常见误区

- 以为统一分词器即公平；实际被高资源主导。
- 中文/日文未加空白，子词切分偏碎。

## 八、面试题

- 多语统一分词问题？答：高资源语言占词表，低资源被过度切分、效率低。

## 九、演进

每语分词 → 统一 BPE → 字节/字符模型。

## 十、小结

多语分词的核心矛盾是共享词表与资源公平。
