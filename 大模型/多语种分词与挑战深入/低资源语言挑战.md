# 低资源语言挑战

> 对应 NLLB/No Language Left Behind 团队分析；Costa-jussà et al., 2022（多语公平）；分词公平研究。

## 一、背景与挑战

低资源语言在共享词表中占比极小，被切得极碎，训练信号弱，评测也少。

## 二、核心原理

词表容量有限，高频语言占满；低资源子词少，平均 token 数高，相当于每字符信息密度低、训练步等效更少。

## 三、数学形式

等效训练量 $\propto \frac{N_\ell}{T_\ell}$；低资源 $T_\ell$ 大，需上采样 $w_\ell$ 补偿：$w_\ell\propto T_\ell$。

## 四、代码实现

```python
weights = {lang: base_tok_per_char[l] for lang in langs}
sampler = Multinomial(weights)
```

## 五、与其他对比

- 与 数据混合比例课程深入（上采样补救）衔接。
- 与 数据质量过滤与困惑度过滤深入（低资源语料更脏）相关。

## 六、常见误区

- 仅增数据不调词表，仍被切碎。
- 用英语 tokenizer 直接套低资源语言。

## 八、面试题

- 如何帮低资源语言？答：上采样 + 更大的多语词表或专用子词空间。

## 九、演进

忽略 → 上采样 → 专用词表/脚本感知。

## 十、小结

低资源语言需词表与上采样双管齐下。
