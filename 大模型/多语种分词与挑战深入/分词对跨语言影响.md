# 分词对跨语言影响

> 对应 分词一致性与跨语迁移研究；Rust et al., *Tokenization Impact*, 2021（分词影响跨语性能）。

## 一、背景与挑战

分词差异使同一概念在不同语言 token 数不同，影响多语迁移与翻译质量。

## 二、核心原理

高资源语言 token 少、低资源多，跨语对齐信号不对称；一致的分词可提升多语表示对齐。

## 三、数学形式

跨语对齐损失随 $|T_{src}-T_{tgt}|$ 增大；需 $\min \text{Var}(T_\ell)$ 以均衡。

## 四、代码实现

```python
for lang in langs:
    print(lang, len(tok.encode(sample[lang])))
```

- 与 多语种分词总览（公平主题）一致。

## 六、常见误区

- 以英语长度推断其他语言算力需求。
