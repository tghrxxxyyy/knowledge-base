# 事实关联回路

> 对应 Meng et al., *Locating and Editing Factual Associations*, 2022（ROME）。

## 一、背景与挑战

模型如何存储并检索"巴黎-法国"这类事实？因果追踪定位其回路节点。

## 二、核心原理

因果追踪显示：事实的"主语"表示在早期层经注意力写入，中上层 FFN 存储属性值；编辑关键 FFN 键值即可改事实。回路即"读主语→查属性→生成"。

## 三、数学形式

因果中介 $m_i = \text{indirect}(h_i \to o)$；对事实 $(s,r,o)$，关键层 $l^*$ 满足 $\|m_{l^*}\| \gg \|m_{l<l^*}\|$。

## 四、代码实现

```python
for l in layers:
    h = causal_trace(model, prompt, layer=l)
    print(l, attribution(h, target))
```

## 五、与其他对比

- 与 前馈传播特征演化深入（FFN 记忆）衔接。
- 与 因果干预与激活修补深入 共享因果追踪。

## 六、常见误区

- 以为事实只在单层；实为跨层写入+读取。
- 编辑可能牵连共享主语的其他事实。
