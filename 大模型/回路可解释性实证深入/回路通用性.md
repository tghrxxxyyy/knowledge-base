# 回路通用性

> 对应 Conmy et al., *Automatic Circuit Discovery*, 2023；跨模型研究。

## 一、背景与挑战

同一回路在不同模型/规模间是否一致？通用性决定是否可迁移解释。

## 二、核心原理

部分回路（如归纳头、复制头）在不同模型稳定出现，被视为"通用计算原语"；但节点身份、层位置随架构/规模变化。自动回路发现（ACDC）用边归因规模化定位。

## 三、数学形式

边归因 $A_{e} = \text{perf}(G) - \text{perf}(G\setminus\{e\})$；保留高归因边构成最小回路。

## 四、代码实现

```python
edges = all_edges(model)
kept = [e for e in edges if edge_attr(model, e, metric) > thr]
circuit = build_graph(kept)
```

## 五、与其他对比

- 与 因果干预与激活修补深入（路径修补）衔接。
- 与 规模与可解释性关系深入 衔接（规模改位置）。

## 六、常见误区

- 假设跨模型节点一一对应；实际需重定位。
- 自动发现仍漏边/含噪声。

## 八、面试题

- 回路通用吗？答：核心原语（归纳/复制）跨模型稳定，但节点身份与位置随架构规模变。

## 九、演进

人工回路 → 自动发现(ACDC) → 跨模型通用性图谱。

## 十、小结

回路具部分通用性，自动发现正把可解释性推向规模化。
