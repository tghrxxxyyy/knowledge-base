# 归纳回路

> 对应 Olsson et al., *In-Context Learning and Induction Heads*, 2022。

## 一、背景与挑战

ICL 的完整机制可由归纳头构成的回路刻画，需实证其组成与因果。

## 二、核心原理

归纳回路至少含：previous-token 头（搬运前一 token 到当前位置）+ 归纳头（匹配重复前缀、复制续写）。二者在残差流协作，把 few-shot 演示转化为模式补全。

## 三、数学形式

设 $h_t^{(prev)}$ 搬入 $x_{t-1}$，$h_t^{(ind)}$ 利用之定位副本，输出 $x_{p^+}$；回路效应用消融增益量化。

## 四、代码实现

```python
for node in [prev_head, induction_head]:
    print(node, circuit_effect(model, node, icl_acc))
```

## 五、与其他对比

- 与 注意力模式类型学深入（归纳头）衔接。
- 与 因果干预与激活修补深入 共享消融法。

## 六、常见误区

- 只归因归纳头而忽略 preceding-token 头贡献。
- 以为单模型回路跨架构一致。

## 八、面试题

- 归纳回路组成？答：previous-token 头搬运 + induction 头匹配复制，共同实现 ICL。

## 九、演进

归纳头发现 → 双头回路 → 跨层归纳电路全景。

## 十、小结

归纳回路是首个被因果刻画的 ICL 机制，验证回路方法可行。
