# 回路可解释性总览

> 对应 Olah et al., *Zoom In*, 2020；Transformer Circuits 系列（Anthropic）。

## 一、背景与挑战

理解"模型如何计算"需要超越静态表示，定位跨层、跨头的因果子图——即回路（circuit）。

## 二、核心原理

回路是执行某子任务的最小计算图（节点=注意力头/FFN/神经元，边=激活流）。方法：用归因找出相关节点，再用干预验证因果，最后抽象为算法描述。

## 三、数学形式

回路因果效应 $E = \mathbb E_{x\sim D}[\text{metric}(M(x)) - \text{metric}(M_{ablate}(x))]$，度量节点对任务的贡献。

## 四、代码实现

```python
def circuit_effect(model, node, metric):
    base = mean(metric(model, data))
    with ablate(model, node):
        abl = mean(metric(model, data))
    return base - abl
```

## 五、与其他对比

- 与 因果干预与激活修补深入 共享干预验证。
- 与 注意力模式类型学深入 衔接（头是回路节点）。

## 六、常见误区

- 把相关性节点当回路；须经因果验证。
- 以为一套回路跨任务通用；常任务特异。

## 八、面试题

- 什么是回路？答：执行某子任务的最小因果计算图，由头/FFN/神经元及其激活流组成。

## 九、演进

单头功能 → 多节点回路 → 跨模型通用性研究。

## 十、小结

回路可解释性从"有什么表示"走向"如何计算"，是机制解释的核心。
