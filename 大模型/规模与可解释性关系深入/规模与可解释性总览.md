# 规模与可解释性关系总览

> 对应 Templeton et al., *Scaling Monosemanticity*, 2024；Wei et al., *Emergent Abilities*, 2022。

## 一、背景与挑战

模型越大是否越可解释？还是更复杂、更难理解？需实证权衡。

## 二、核心原理

两方面并存：规模带来更单义、更细粒度的 SAE 特征（更易逐个解读），但也带来海量特征、涌现能力与更难全局理解的回路，整体可解释性成本上升。

## 三、数学形式

单义率 $M(S)$ 随参数量 $S$ 上升；但特征总数 $N(S)$ 与理解成本近似超线性增长。

## 四、代码实现

```python
for S in sizes:
    sae = train_sae(acts_of(S), k=64)
    print(S, monosemanticity(sae), n_features(sae))
```

## 五、与其他对比

- 与 稀疏自编码器特征深入（特征分裂）衔接。
- 与 词典特征与单义性深入（单义实证）共享证据。

## 六、常见误区

- 以为"更大=更可解释"无条件成立；仅单义性维度成立。
- 忽略理解总成本随规模陡增。

## 八、面试题

- 规模如何影响可解释性？答：单义特征更多更易解，但特征总量与回路复杂度令整体理解成本激增。

## 九、演进

小模型全解 → 中模型部分解 → 前沿模型 SAE 规模化。

## 十、小结

规模对可解释性是双刃剑：单义化提升，但理解成本超线性上升。
