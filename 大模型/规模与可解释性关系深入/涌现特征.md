# 涌现特征

> 对应 Templeton et al., *Scaling Monosemanticity*, 2024；Wei et al., *Emergent Abilities of LLMs*, 2022。

## 一、背景与挑战

大模型是否出现小模型完全没有的"新特征/能力"？SAE 提供可观测窗口。

## 二、核心原理

实证发现：随规模增大，出现专门编码罕见概念、跨语言抽象、甚至"安全相关"的特征，这些在小模型 SAE 中不存在或高度混合。规模催生特征细化与分工。

## 三、数学形式

设特征出现阈值 $S_c$，$S>S_c$ 时特征 $f_c$ 才单义涌现；可用 SAE 字典维放大其可见性。

## 四、代码实现

```python
for f in features_small, features_large:
    if only_in(f, features_large):
        print("emergent feature:", describe(f))
```

## 五、与其他对比

- 与 特征分裂与规模 衔接（细化即新特征来源）。
- 与 规模与可解释性关系深入 总览呼应。

## 六、常见误区

- 把"涌现"神秘化；常是可量化阈值现象。
- 忽略数据/训练也有贡献，非纯规模。

## 八、面试题

- 涌现特征是什么？答：规模超阈值后出现的专门/抽象特征，小模型中没有或高度混合。

## 九、演进

能力涌现 → 特征涌现（SAE 可见） → 安全特征监测。

## 十、小结

涌现特征使大模型兼具新风险与新可观测性，是规模研究焦点。
