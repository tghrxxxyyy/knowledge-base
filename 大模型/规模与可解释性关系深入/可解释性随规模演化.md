# 可解释性随规模演化

> 综合 Templeton 2024、Elhage 2022、Olah 系列；对"可解释性是否随规模变易/变难"的综述性回答。

## 一、背景与挑战

需要一张整体图景：随规模增长，可解释性方法是变强还是变弱？

## 二、核心原理

趋势：单特征更单义（易）、但总数爆炸（难）；回路更复杂但可用自动发现（ACDC）规模化；涌现能力带来新风险也带来新可观测特征。总体是"工具随规模进化、成本随规模上升"。

## 三、数学形式

可解释性收益/成本比 $R(S) = \frac{M(S)}{C(S)}$，其中 $C(S)\sim N(S)^\gamma$，$\gamma>1$，长期成本占优需自动化。

def interpretability_roi(S):
    return monosemanticity_gain(S) / understanding_cost(S)

- 非简单"更大更易/更难"二选一；是分维度不同。

## 八、面试题

- 可解释性随规模怎么变？答：单义特征更易、但总数与回路复杂度使成本超线性升，靠自动化对冲。

## 九、演进

人工小模型 → 半自动中模型 → 自动化前沿模型。

## 十、小结

规模使可解释性"更易逐点、更难全局"，自动化是必然方向。
