# 规模对单义性的影响

> 对应 Templeton et al., *Scaling Monosemanticity*, 2024（Anthropic，对 Claude 3.0 Sonnet 训练 SAE）。

## 一、背景与挑战

单义性是否随规模单调提升？前沿模型实证给出定量答案。

## 二、核心原理

在 7B 到数百 B 模型上，SAE 单义率随模型规模与字典倍数上升；同时出现"特征分裂"（粗概念拆细）与跨语言/跨模态共享特征，支持"规模改善单义"假说。

## 三、数学形式

单义率 $M(S,k) = a \log S + b \log k + c$，经验上随 $S,k$ 正增长。

## 四、代码实现

```python
import pandas as pd
df = pd.DataFrame([(S,k,mono) for S in Ss for k in ks])
print(df.groupby("S").mean())  # 规模越大单义越高
```

## 六、常见误区

- 认为单义率已近 100%；实际仍有大量噪声特征。
- 忽略 SAE 自身超参对单义率的强影响。

## 八、面试题

- 规模怎样影响单义性？答：更大模型+更大 SAE 字典使特征更细更单义，但仍有噪声特征。

## 九、演进

假设 → 中小模型验证 → 前沿模型规模化实证。

## 十、小结

规模对单义性呈正向经验关系，是"大模型更可逐个解读"的依据。
