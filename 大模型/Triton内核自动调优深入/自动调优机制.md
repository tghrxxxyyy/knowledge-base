# Triton自动调优机制

> 对应 `@triton.autotune` 多配置搜索。

## 一、背景与挑战

内核性能高度依赖 BLOCK、num_warps、num_stages 等参数，手工调优费时。

## 二、核心原理

`@triton.autotune` 给定候选配置，在首次调用基准各配置、缓存最优；常以输入形状为键选择，实现自动寻优。

## 三、数学形式

最优配置 $c^*=\arg\min_c \text{time}(c, \text{shape})$；缓存映射 $\text{shape}\to c^*$。

## 四、代码实现

```python
@triton.autotune(configs=[triton.Config({'BLOCK':128})], key=['n'])
@triton.jit
def ker(...): ...
```

## 五、与其他对比

- 与 推理CUDA图优化深入：调优结果可封入图重放。
- 与 张量核心与混合精度推理深入：调优影响 TC 占用。

## 六、常见误区

- 自动调优首次调用慢（基准开销）。
- 配置空间太小错过最优、太大耗时。

## 八、面试题

- autotune 怎么选配置？答：按 key（如形状）基准候选配置，缓存最快者。

## 九、演进

手动 → autotune → 学习型调优。

## 十、小结

Triton autotune 把内核参数搜索自动化，是性能与易用兼得的机制。
