# 梯度累积与学习率缩放

> 对应 huggingface/transformers `gradient_accumulation_steps` 与 pytorch/pytorch。

## 一、背景与挑战
linear scaling rule 要求 batch 翻倍 lr 翻倍；当用累积模拟大 batch 时，lr 应如何调整？

## 二、核心原理
累积把逻辑 batch 从 B 增至 K·B，按 linear scaling 应把 lr 乘 K（前期），但需配合 warmup；后期仍按调度衰减。

## 三、形式化与数学基础
有效 batch `B_eff = K·B`，建议 `lr_eff = lr_base · (B_eff / B_ref)`，与真实大 batch 训练一致。

## 四、代码实现
```python
base_lr, base_bs, micro_bs, K = 3e-4, 256, 8, 32
bs_eff = micro_bs * K          # 256
lr = base_lr * (bs_eff / base_bs)   # 3e-4 * 1 = 3e-4
```

## 五、与其他技术对比
真实大 batch 与累积大 batch 在优化动力学上等价，仅每步耗时不同（累积更慢）。

## 六、常见误区
只加累积却不调 lr，可能欠优化；或过度放大 lr 引发不稳定。

## 七、与开源书/权威来源对应
huggingface/transformers 文档说明累积与 lr 关系；pytorch/pytorch 训练示例。

## 八、面试题
问：累积 K 步，lr 要不要乘 K？答：若要复现大 batch 动力学，前期应乘 K 并 warmup。

## 九、演进与趋势
自动 batch-lr 校准工具减少手工换算。

## 十、小结
累积改变逻辑 batch，lr 须按 scaling rule 协同调整。
