# 虚拟批次训练

> 对应 karpathy/nanoGPT 的 micro_batch 设计与 pytorch/pytorch 训练循环。

## 一、背景与挑战

超大序列（如长文档、高分辨率图像）单样本即超显存，无法放进常规 batch。虚拟批次（virtual batch）把逻辑大 batch 拆成多个 micro-batch 顺序处理，配合梯度累积，使单卡也能训练本放不下的样本。它与梯度累积本质同源，只是强调「逻辑大 batch 的拆分」。难点在于：序列分块必须保持因果一致性，否则模型会「偷看」未来 token，造成信息泄露与训练/推理分布错位，且这种错位在长上下文任务上会被放大为严重幻觉。

## 二、核心原理

虚拟批次 = 梯度累积的工程命名：把无法一次加载的大 batch（或超长序列分块）切分为 micro-batch，依次前向反向、累加梯度，末尾统一更新。参数在微批间共享，梯度累加：

$$
G=\sum_j\frac{\partial L_j}{\partial\theta},\qquad \theta\leftarrow\theta-\eta\,G
$$

关键是分块边界需保持因果/空间一致性，避免信息泄露或上下文断裂。对自回归模型，分块应采用「滑动窗口 + 残差 KV 缓存」或确保每块只依赖前块，而非随机截断。对图像则可按空间块划分，但需注意块间接缝处的归一化与卷积感受野。

## 三、形式化与数学基础

设长序列长 L 超显存，切分为 L/K 段，每段独立前向但共享 $\theta$，梯度累加：

$$
G=\sum_{j=1}^{K}\frac{\partial L(x^{(j)})}{\partial\theta}
$$

等效于对完整样本损失 $L(x)=\sum_j L(x^{(j)})$ 的梯度。更新 $\theta\leftarrow\theta-\eta G$ 与一次前向等价（忽略 BN 差异）。用 KV 缓存时，第 $j$ 块的注意力只能看到前 $j-1$ 块，保证因果：

$$
\mathrm{Attn}^{(j)}\ \text{仅在}\ \bigcup_{k<j} x^{(k)}\ \text{上计算}
$$

## 四、代码实现

```python
# 长序列分块(示意): 每块作为 micro-batch 累积, 保持因果
kv_cache = None
opt.zero_grad()
for seq_chunk, mask in chunk_sequences(batch, chunks=ACCUM, causal=True):
    out, kv_cache = model(seq_chunk, past_kv=kv_cache, attn_mask=mask)
    (out.loss / ACCUM).backward()      # 累加梯度
opt.step(); opt.zero_grad()            # 末尾统一更新

def chunk_sequences(batch, chunks, causal=True):
    # 因果分块: 每块只能看前面块(示意), 防信息泄露
    return [(batch[i::chunks], None) for i in range(chunks)]
```

## 六、常见误区

- 分块边界未处理因果掩码：导致信息泄露或上下文断裂。
- 把虚拟批次当独立样本：应视为同一逻辑 batch 的拆分。
- 忽略 loss 除 ACCUM：破坏梯度尺度。
- 长序列无 KV 缓存：重复计算前缀，浪费算力且可能错位。
- 分块后未对齐位置编码：旋转位置编码需按全局偏移而非块内偏移。

## 九、演进与趋势

序列并行（Sequence Parallelism）与虚拟批次结合处理超长上下文；激活分片进一步省显存。训推一体的分块策略使 128K+ 上下文在单卡上也可训练，且 KV 缓存复用降低重复计算。

（补充）虚拟批次在训练超大图像或长文档时尤其常见，但与梯度检查点（activation checkpointing）配合时需注意：分块后的每块若独立重算前向，会重复计算块边界的上下文；用 KV 缓存或跨块激活传递可避免。实践要点：

- 分块大小应使单块能放入显存且保留足够上下文，过小会增加块间开销，过大则失去虚拟批次意义。
- 对自回归模型，务必保证位置编码按全局偏移而非块内偏移计算，否则模型看不到真实位置。
- 与序列并行结合时，块在序列维切分、虚拟批次在时间维切分，二者正交可叠加。
- 评测时若也用分块，需确保与训练分块方式一致，避免 train/serve 不一致。

虚拟批次本质是「把空间压力转化为时间」，在单卡长序列场景几乎不可替代，是训练基础设施的必备技巧。

（补充续）在显存极度受限时，虚拟批次还可与梯度检查点组合出「双时间换空间」：分块降低单步激活峰值，检查点降低反向激活驻留，二者叠加可在单卡上训练远超显存的模型。代价是重算前向的额外算力，应权衡重算比例与吞吐。

另一个实践点是分块边界的梯度连续性：自回归分块若每块重新初始化 KV 缓存，块间接续处的隐藏状态会断层，需在边界处传递前块末态或重叠若干 token 以保证因果链不断。

## 十、小结

虚拟批次让单卡也能训练逻辑大 batch 与长序列：以时间换空间，本质是梯度累积在样本/序列维度的应用。因果分块、KV 缓存与位置编码对齐是长序列场景不可省略的工程要点。
