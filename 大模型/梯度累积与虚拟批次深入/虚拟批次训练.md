# 虚拟批次训练

> 对应 karpathy/nanoGPT 的 micro_batch 设计与 pytorch/pytorch 训练循环。

## 一、背景与挑战
超大序列（如长文档）单样本即超显存，无法放进常规 batch。虚拟批次把逻辑 batch 拆成微批顺序处理。

## 二、核心原理
虚拟 batch 是梯度累积的工程命名：把无法一次加载的大 batch 切分为多个 micro-batch，依次前向反向累积梯度，统一更新。

## 三、形式化与数学基础
设序列长 L 超显存，切分为 L/K 段，每段独立前向但共享参数，梯度累加：`G = Σ_{j} ∂L_j/∂θ`，更新 `θ-ηG`。

## 四、代码实现
```python
# 长序列分块（示意）
for seq_chunk in chunk_sequences(batch, chunks=ACCUM):
    out = model(seq_chunk)
    (out.loss / ACCUM).backward()
opt.step(); opt.zero_grad()
```

## 五、与其他技术对比
梯度检查点（checkpointing）省显存但增计算；虚拟批次省显存且不增计算，但需多步时间。

## 六、常见误区
分块边界未处理因果掩码，导致信息泄露或上下文断裂。

## 七、与开源书/权威来源对应
karpathy/nanoGPT 用 micro_batch 控制显存；pytorch/pytorch 手册说明累积语义。

## 八、面试题
问：虚拟批次与累积区别？答：基本相同，虚拟批次强调逻辑大 batch 的拆分。

## 十、小结
虚拟批次让单卡也能训练逻辑大 batch 与长序列。
