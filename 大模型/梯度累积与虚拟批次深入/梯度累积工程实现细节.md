# 梯度累积工程实现细节

> 对应 pytorch/pytorch 训练循环与 karpathy/nanoGPT 实现。

## 一、背景与挑战
正确实现累积涉及梯度清零时机、scaler 交互、梯度裁剪位置等细节，易出错。

## 二、核心原理
关键约定：仅在累积末尾 `opt.step()` 并 `zero_grad()`；中间步骤只 `backward()`；裁剪与 scaler 应在 step 前对累积梯度作用。

## 三、形式化与数学基础
累积梯度 `G = Σ_k g_k`（已除 K），裁剪：`G ← G·min(1, C/||G||)`，再 `θ ← θ - ηG`。

## 四、代码实现
```python
scaler = torch.cuda.amp.GradScaler()
for i, (x, y) in enumerate(loader):
    with torch.autocast(dtype=torch.bfloat16):
        loss = model(x, y).loss / ACCUM
    scaler.scale(loss).backward()
    if (i + 1) % ACCUM == 0:
        scaler.unscale_(opt)
        torch.nn.utils.clip_grad_norm_(params, 1.0)
        scaler.step(opt); scaler.update(); opt.zero_grad()
```

## 五、与其他技术对比
无累积时每步清零；有累积时必须延后清零，否则梯度丢失。

## 六、常见误区
在每微批后都 `zero_grad()`，使累积失效；或在 scaler.step 前未 unscale 就裁剪。

## 七、与开源书/权威来源对应
pytorch/pytorch AMP + 累积示例；karpathy/nanoGPT 的 `train.py` 循环。

## 八、面试题
问：裁剪应在何时做？答：累积完毕、step 之前，对全部累积梯度统一裁剪。

## 九、演进与趋势
高阶 API（Trainer、DeepSpeed engine）已封装这些细节。

## 十、小结
精确控制清零/裁剪/缩放时机，是累积正确性的核心。
