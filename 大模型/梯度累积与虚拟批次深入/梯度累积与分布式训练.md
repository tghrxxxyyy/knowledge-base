# 梯度累积与分布式训练

> 对应 microsoft/DeepSpeed 与 pytorch/pytorch DDP/FSDP。

## 一、背景与挑战
在 DDP/FSDP 多卡下，数据并行已增大全局 batch；再叠加梯度累积可进一步突破显存上限。

## 二、核心原理
每张卡内部做 K 步 micro-batch 累积，卡间通过 all-reduce 同步梯度。全局有效 batch = 卡数 × micro_bs × K。

## 三、形式化与数学基础
$ B_{global} = N_{gpu} \times B_{micro} \times K $，梯度同步频率降为每 K 步一次，通信开销减少。

## 四、代码实现
```python
for i, (x, y) in enumerate(loader):     # 每卡独立 micro-batch
    loss = model(x, y).loss / ACCUM
    loss.backward()                      # DDP 在 step 时 all-reduce
    if (i + 1) % ACCUM == 0:
        opt.step(); opt.zero_grad()
```

## 五、与其他技术对比
纯数据并行通信频繁；累积减少同步次数；FSDP 再切分参数进一步省显存。

## 六、常见误区
认为累积可替代跨卡同步；二者解决不同维度（时间 vs 空间），须并用。

## 七、与开源书/权威来源对应
microsoft/DeepSpeed ZeRO 文档；pytorch/pytorch `DistributedDataParallel`。

## 八、面试题
问：全局 batch 怎么算？答：gpu数 × micro_bs × 累积步数。

## 九、演进与趋势
梯度累积与序列并行、张量并行组合支撑万亿参数训练。

## 十、小结
累积在分布式下叠加显存与通信收益，是扩展训练的关键。
