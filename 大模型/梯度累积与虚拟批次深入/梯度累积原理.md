# 梯度累积原理

> 对应 huggingface/transformers 的 `gradient_accumulation_steps` 与 pytorch/pytorch。

## 一、背景与挑战

显存限制使单卡 micro-batch 很小，而大 batch 对训练稳定与泛化有益（大 batch 梯度噪声小、收敛更稳）。梯度累积在不增大显存的前提下，通过多步累加梯度模拟大 batch，是显存受限时最常用的技巧。其代价是更长的 wall-clock：等效大 batch 的每一步需 K 次串行前向反向。因此累积是「以时间换空间」的典型权衡，常用于单卡训大模型或把超大逻辑 batch 拆到多步完成。

## 二、核心原理

每个 micro-batch 只做一次前向反向、累加梯度（不更新参数），累积 K 步后做一次优化器 step。等效 batch = K × micro_bs。实现上把每步 loss 除以 K 后反传，末尾统一更新，使累积梯度是 K 个微批的平均，等价于大 batch 一次更新的梯度（忽略 BN 差异）。直观理解：把「一次算大 batch」拆成「K 次算小 batch 再平均」，结果与一次性计算在期望上一致。注意除 K 与末尾更新二者缺一不可，否则等效学习率或 batch 语义会错。

## 三、形式化与数学基础

设第 k 步微批梯度为 $g_k$，累积平均梯度：

$$
g=\frac{1}{K}\sum_{k=1}^{K}g_k
$$

参数更新：

$$
\theta\leftarrow\theta-\eta\, g
$$

若把 loss 除以 K 再 `backward()`，则每次反传已贡献 $g_k/K$，K 步后梯度恰为 $g$。这与一次性大 batch 的 $\frac{1}{KB}\sum$ 在期望上一致。方差上，累积梯度方差约为单微批的 $1/K$，接近真实大 batch 的降噪效果（假设同分布采样），这也是大 batch 更稳定、更易泛化的来源。

## 四、代码实现

```python
ACCUM = 4
opt.zero_grad()
for i, (x, y) in enumerate(loader):
    loss = model(x, y).loss / ACCUM      # 关键: 除 ACCUM
    loss.backward()                       # 累加, 不更新
    if (i + 1) % ACCUM == 0:
        opt.step(); opt.zero_grad()       # 累积末尾更新

def simulate_big_batch(model, loader, K):
    # 等价视角: 累积 K 步 == 逻辑大 batch
    opt.zero_grad()
    for _ in range(K):
        x, y = next(loader)
        (model(x, y).loss / K).backward()
    opt.step()
```

## 五、与其他技术对比

| 维度 | 数据并行 | 梯度累积 |
| --- | --- | --- |
| 维度 | 空间(多卡) | 时间(多步) |
| 显存 | 每卡独立 | 单卡更省 |
| 加速 | 是 | 否(更慢) |
| 通信 | 需同步 | 无 |

二者可叠加：并行提速、累积补 batch。

## 六、常见误区

- 忘记 loss/K：有效学习率随 K 放大，训练不稳。
- 忘记清零梯度：旧梯度混入，batch 语义错。
- 以为累积等同真实大 batch 的 BN：BN 仍只看 micro-batch（见 BatchNorm 文档）。
- 累积步数与 lr 缩放割裂：只加 K 不调 lr 会欠优化。
- 忽略 wall-clock 代价：累积省显存但线性增加每步耗时。

## 九、演进与趋势

与 ZeRO/FSDP 结合，在极小显存上训练超大模型；编译器融合累积循环、异步通信 overlap。框架把累积做成一等公民，使「逻辑大 batch」配置与物理显存解耦，开发者只需声明目标 batch 与 micro-batch。

（补充）一个有用的心智模型：把梯度累积看作「时间上的大 batch」——它在 K 个时间步内收集梯度，等价于在空间上同时摆出 K 个样本。代价是这 K 步必须串行执行，所以总计算量不变，只是显存峰值被摊薄。实践要点：

- 若显存充足，直接用大 batch 更快；仅在显存不足或需超大逻辑 batch 时才用累积。
- 累积不改变收敛所需的「总样本见过的量」，因此总步数应按逻辑 batch 重新估算。
- 调试时先关掉累积（K=1）跑通流程，再逐步调大 K，避免多变量同时出错。
- 把 `gradient_accumulation_steps` 与 `per_device_train_batch_size` 一起记入实验配置，保证可复现。

理解这一等价关系，就能在显存、吞吐、收敛三者间做出有依据的工程取舍，而不是凭感觉设超参。

## 十、小结

梯度累积是显存受限时模拟大 batch 的标准技巧：以时间换空间，靠 loss/K 与末尾更新保持梯度等价。它与并行正交，是组合式扩展训练规模的基石之一，配合 lr 缩放与合适归一化方才稳妥。
