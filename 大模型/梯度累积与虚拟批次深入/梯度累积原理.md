# 梯度累积原理

> 对应 huggingface/transformers 的 `gradient_accumulation_steps` 与 pytorch/pytorch。

## 一、背景与挑战
显存限制单卡 micro-batch 很小，而大 batch 对稳定与泛化有益。梯度累积在不增大显存的前提下模拟大 batch。

## 二、核心原理
每步只对 micro-batch 求梯度并累加（不更新参数），累积 K 步后做一次优化器 step，等效 batch = K × micro_bs。

## 三、形式化与数学基础
$ g = \frac{1}{K}\sum_{k=1}^{K} g_k $，$ \theta \leftarrow \theta - \eta g $

等价于把 loss 除以 K 后逐微批反向，最后一步更新。

## 四、代码实现
```python
ACCUM = 4
opt.zero_grad()
for i, (x, y) in enumerate(loader):
    loss = model(x, y).loss / ACCUM
    loss.backward()
    if (i + 1) % ACCUM == 0:
        opt.step(); opt.zero_grad()
```

## 五、与其他技术对比
数据并行靠多卡增大 batch；梯度累积靠时间换空间，单卡即可，二者可叠加。

## 六、常见误区
忘记 loss/K 或忘记清零梯度，导致有效 lr 或 batch 错误。

## 七、与开源书/权威来源对应
huggingface/transformers `TrainingArguments.gradient_accumulation_steps`；pytorch/pytorch 示例。

## 八、面试题
问：累积为何要除 K？答：保持梯度是 K 个微批的平均，等价于大 batch 梯度。

## 九、演进与趋势
与 ZeRO、FSDP 结合可在极小显存上训练超大模型。

## 十、小结
梯度累积是显存受限时模拟大 batch 的标准技巧。
