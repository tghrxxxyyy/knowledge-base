# 金融情感与事件

> 对应 FinBERT（ProsusAI）、金融事件抽取与情绪-收益关联研究；参考 llm-course (mlabonne) 与 HuggingFace Transformers 文档。

## 一、背景与挑战

新闻、财报电话会、社媒、研报中的情绪与事件会显著影响资产价格。机构投资者需要把海量非结构化文本转化为可交易信号，但金融文本有独特难点：

- 领域语义：同一词在通用与金融语境含义不同（如「bear」「position」）。
- 细粒度需求：不仅正负，还要强度、对象（标的）、事件类型（并购/财报/政策）。
- 噪声与操纵：水军、反向喊单、讽刺反语干扰判断。
- 时效：信号半衰期短，需低延迟抽取。

## 二、核心原理

金融情感与事件分析通常分两步：

1. 情感判别：在金融语料上微调的模型（如 FinBERT）输出句子/段落级情感极性 $(-1,0,+1)$ 与强度，支持方面级（aspect-level）情感，即针对特定标的而非全文。
2. 事件抽取：识别事件触发词、类型、涉及实体与时间，结构化后供下游策略消费。

LLM 的优势在于零样本/少样本下做细粒度抽取与跨源对齐，把「谁、发生了什么、影响哪只标的、程度多大」一次性结构化。

（落地补充：）
- 细粒度抽取常与事件知识图谱联动，把（标的,事件,情感,强度）写入图库。
- 下游策略可按标的订阅信号，情感/事件从一次性判断转为可累积资产。
- 聚合前需做去噪与确权，剔除水军与反向喊单的干扰样本。

## 三、形式化与数学基础

方面级情感可建模为条件概率：给定文本 $T$ 与标的 $a$，情感分布

$$ P(y \mid T, a) = \text{softmax}\big(W \cdot \text{Enc}(T, a)\big),\quad y\in\{-1,0,+1\} $$

事件抽取视为序列标注与分类联合任务，触发词得分：

$$ s_e = \text{Enc}(T)_\text{trigger}^\top w_e $$

组合成 $(e, a, y, \text{intensity})$ 四元组，再映射为信号权重 $w_{\text{sig}}$。

## 四、代码实现

```python
# 用金融情感模型抽取信号，越界则告警
from transformers import pipeline

fin_sent = pipeline("text-classification",
                    model="ProsusAI/finbert")  # 金融微调的 BERT

def signal_from_text(text, ticker, neg_thr=-0.6):
    out = fin_sent(text)[0]          # 返回 label 与 score
    label, score = out["label"], out["score"]
    s = {"positive": score, "neutral": 0.0, "negative": -score}[label]
    if s < neg_thr:
        alert(ticker, reason=text)  # 强负面触发告警
    return s

s = signal_from_text("公司下调全年指引，需求明显走弱", "AAPL")
```

## 六、常见误区

- 「情绪分高 = 涨」：情绪仅是弱信号，需结合量价与事件验证。
- 「忽略反语/讽刺」：金融文本常见反向表述，易误判。
- 「不祛噪」：水军与营销内容会污染聚合信号。
- 「只看全文」：方面级情感才是可交易粒度。
