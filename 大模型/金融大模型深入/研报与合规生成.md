# 研报与合规生成

> 见「金融大模型深入/金融应用场景」与「提示工程深入」。

## 一、背景与挑战

研报需数据准确、引用规范、措辞合规。

## 二、核心原理

接行情/财报数据，按模板生成初稿，强制引用来源与风险提示，人工复核后发布。

## 三、关键要点

- 免责声明必带。
- 数据需实时且可核。

## 四、代码实现

```python
draft = llm(f"基于数据{data}生成研报初稿,附来源与风险")
```

## 五、与其他对比

- 通用写作泛；研报需合规框架。

## 六、常见误区

- 自动生成即发布——必人工复核。
