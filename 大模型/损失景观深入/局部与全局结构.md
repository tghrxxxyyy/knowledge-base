# 局部与全局结构

> 对应 Dauphin et al., *Identifying and Attacking the Saddle Point Problem*, NeurIPS 2014。

## 一、背景与挑战

高维景观中全局极小值难寻，但局部结构（saddle、平坦谷）主导训练动态。

## 二、核心原理

实证表明大量 critical points 是 saddle 而非局部极小；一阶方法配合噪声易逃离 saddle。

## 三、数学形式

saddle 处 Hessian 有负特征值；逃离速率随负曲率方向梯度 $\sim t^{-1}$ 下降。

## 四、代码实现

```python
eigvals = torch.linalg.eigvalsh(hessian)
has_saddle = (eigvals < 0).any()
```

## 五、与其他对比

- 与 二阶优化深入 用负曲率加速。
- 与 梯度噪声深入 噪声助逃离 saddle。

## 六、常见误区

- 以为陷入局部极小，实为 saddle。
- 纯 SGD 在极平坦 saddle 区可能极慢。

## 八、面试题

- 高维景观多为 saddle 还是局部极小？答：高精度网络多为 saddle，负曲率方向提供逃离路径。

## 九、演进

局部极小假设 → saddle 主导 → 负曲率利用。

## 十、小结

理解 saddle 主导结构，是设计逃离机制与二阶方法的基础。
