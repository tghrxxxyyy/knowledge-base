# 损失景观总览

> 对应 Goodfellow et al., *Qualitatively Characterizing Neural Network Optimization Problems*, ICLR 2015；Li et al., *Visualizing the Loss Landscape*, NeurIPS 2018。

## 一、背景与挑战

高维非凸损失曲面难以直观理解，但其结构深刻影响优化与泛化。

## 二、核心原理

景观由大量 saddle 与极小值构成；现代架构（残差、BN）使景观更平、梯度更易流动，减少病态。

## 三、数学形式

沿方向 $(\alpha,\beta)$ 切片：$\mathcal L(\theta+\alpha u+\beta v)$，其二维等高线即景观可视化。

## 四、代码实现

```python
grid = [[loss_at(theta + a*u + b*v) for a in alphas] for b in betas]
```

## 五、与其他对比

- 与 平坦极小值深入 描述局部形状。
- 与 二阶优化深入 用曲率刻画景观。

## 六、常见误区

- 二维切片不能完全代表高维景观。
- 忽视滤波归一化会画出误导性的陡坡。

## 八、面试题

- 为什么残差网络景观更平？答：恒等捷径降低条件数，使梯度通路更平滑、saddle 更易逃离。

## 九、演进

理论分析 → 可视化 → 模式连通性。

## 十、小结

损失景观是理解优化的几何语言，残差/归一化显著改善其形状。
