# 模式连通性与解连通

> 对应 Garipov et al., *Loss Surfaces, Mode Connectivity...*, NeurIPS 2018；Draxler et al., 2018。

## 一、背景与挑战

不同随机种子得到的解看似分离，但是否存在低损失通路连接它们？

## 二、核心原理

实证发现许多极小值间存在"低损失走廊"（通过曲线或多边形连接），意味着它们属同一平坦 basin。

## 三、数学形式

求曲线 $c(\alpha):[0,1]\to\Theta$ 使 $\max_\alpha\mathcal L(c(\alpha))$ 最小；训练端点间连线参数。

## 四、代码实现

```python
c = lambda a: (1-a)*w1 + a*w2 + a*(1-a)*v  # 带修正项 v
```

## 五、与其他对比

- 与 平坦极小值深入 的 basin 概念相连。
- 与 损失景观深入 可视化对照。

## 六、常见误区

- 直线连接常穿过高损失区，误判为不连通。
- 连通性对模型族（如有无 BN）敏感。

## 八、面试题

- 什么是模式连通性？答：不同极小值间存在低损失通路，说明它们属同一宽 basin。

## 九、演进

直线 → 曲线 → 多边形连通。

## 十、小结

模式连通性表明 minima 非孤立，解释集成与微调的几何基础。
