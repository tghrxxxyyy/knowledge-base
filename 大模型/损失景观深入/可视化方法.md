# 损失景观可视化

> 对应 Li et al., NeurIPS 2018 的滤波归一化（filter normalization）。

## 一、背景与挑战

直接对权重加扰动会因 BN/卷积尺度自由度而画出虚假陡坡。

## 二、核心原理

对每滤波器按其范数归一后再插值，消除尺度自由度，得到可比较的景观图。

## 三、数学形式

归一化方向 $\tilde u_i = u_i/\|u_i\|$；插值点 $\theta+\alpha\tilde u+\beta\tilde v$，使对比公平。

## 四、代码实现

```python
def filter_norm(w): return w / (w.norm() + 1e-12)
u = filter_norm(direction_u)
```

## 五、与其他对比

- 与 平坦极小值深入 的不变度量同思想。
- 与 锐度度量方法 互补。

## 六、常见误区

- 未归一化直接可视化会夸大锐度。
- 随机方向选择影响观感，需多次采样。

- 为何要滤波归一化？答：消除卷积/BN 的尺度自由度，避免虚假陡峭、公平比较模型。
