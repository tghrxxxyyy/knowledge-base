# 模板与占位符

> 对应模板化生成（Jinja 等）；与 结构化输出深入 衔接。

## 一、背景与挑战

需将模型产出填入固定报告/邮件模板，自由文本难对齐。

## 二、核心原理

先让模型生成键值/结构化片段，再用模板渲染；或让模型直接填占位符 {{var}}。

## 三、数学形式

渲染 $R(\text{tpl}, m)=\text{tpl}.render(\{k_i: m[k_i]\})$；需 $keys(m)\supseteq required$。

## 四、代码实现

```python
from jinja2 import Template
tpl = Template("结论：{{conclusion}}\n依据：{{evidence}}")
print(tpl.render(**json.loads(out)))
```

## 五、与其他对比

- 与 模式引导生成深入 共享模板思想。
- 与 JSON模式深入 配合填值。

## 六、常见误区

- 模板与生成键不匹配致缺值。
- 未转义致注入。

## 七、与开源书对应

## 八、面试题

- 模板为何可靠？答：先生成字段再渲染，版面固定、易校验。

## 九、演进

字符串拼 → 模板引擎 → 流式渲染。

## 十、小结

模板+占位符把生成与版面解耦，稳定可控。
