# 格式化后处理与校验

> 对应输出解析与修复；与 格式化输出评估深入 衔接。

## 一、背景与挑战

模型偶发微破版，需鲁棒解析与自动修复。

## 二、核心原理

用容错解析器（如 markdown 库）、正则提取、缺失补默认；严重则重生成或降级。

## 三、数学形式

修复函数 $y' = \text{fix}(y)$ 使 $y'\in L(F)$；失败率 $f=1-\Pr(\text{parse}(y)\neq\bot)$。

## 四、代码实现

```python
try:
    doc = markdown.parse(out)
except: out = fix_and_retry(prompt)
```

## 五、与其他对比

- 与 结构化输出可靠性深入 共享校验。
- 与 约束解码深入 互补（前约束+后修复）。

## 六、常见误区

- 过度依赖正则脆弱解析。
- 修复引入新错。

## 八、面试题

- 破版如何兜底？答：容错解析+正则提取+失败重生成，监控失败率。

## 九、演进

硬解析 → 容错 → 自愈。

## 十、小结

格式化需后处理校验兜底，提升工程鲁棒。
