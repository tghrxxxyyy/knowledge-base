# 表格与列表输出

> 对应表格/列表格式化；与 Markdown格式化深入 衔接。

## 一、背景与挑战

对比/汇总常用表格，模型易列数不齐、对齐错。

## 二、核心原理

约束列数与表头，或用 CSV/Markdown 表；列表用统一项目符；生成后做列校验。

## 三、数学形式

表 $M\in \text{cells}^{r\times c}$；校验 $\forall j, |col_j|=r$。

## 四、代码实现

```python
import pandas as pd

```

- 与 格式化输出评估深入 共享校验。

## 六、常见误区

- 用 Markdown 表但列不齐致解析失败。
- 列表嵌套层级乱。
