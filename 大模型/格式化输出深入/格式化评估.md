# 格式化输出评估

> 对应格式合规评测；与 模型评测指标深入 衔接。

## 一、背景与挑战

需量化格式合规率与可读性，而非仅看内容。

## 二、核心原理

定义格式规则（标题存在、列表闭合、表列齐），用解析成功率+结构匹配率度量。

## 三、数学形式

合规率 $C=\frac{1}{n}\sum \mathbb 1[\text{valid}(y_i)]$；结构相似度用树编辑距。

## 四、代码实现

```python
score = mean(parse_ok(y) for y in batch)
```

## 五、与其他对比

- 与 结构化输出实践深入 共享指标。
- 与 提示工程深入 可 A/B 格式指令。

## 六、常见误区

- 只看内容分忽略格式分。
- 规则过严虚低。
