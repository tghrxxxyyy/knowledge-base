# 格式化输出总览

> 对应提示工程中的输出格式约定；与 结构化输出深入 / 提示工程深入 衔接。

## 一、背景与挑战

人类或系统需稳定版面（标题、列表、表格），自由文本易漂移，难解析与展示。

## 二、核心原理

通过明确格式指令+示例（few-shot）或约束解码，固定输出版面结构，提升可读与可解析性。

## 三、数学形式

格式约束集合 $F=\{f_1..f_k\}$；输出满足 $y\in L(F)$ 语言。

## 四、代码实现

```python
sys = "用 Markdown 输出：## 标题、无序列表、代码块。"
resp = llm(system=sys, user=q)
```

## 五、与其他对比

- 与 结构化输出深入 偏语义字段，本篇偏版面。
- 与 约束解码深入 可叠加硬格式。

## 六、常见误区

- 仅靠提示无兜底，偶发破版。
- 格式指令与内容冲突。

## 八、面试题

- 为何要固定格式？答：稳定版面提升可读与下游可解析，减少漂移。

## 九、演进

无约定 → 提示约定 → 约束格式化。

## 十、小结

格式化输出以约定/约束稳定版面，是可读与可解析基础。
