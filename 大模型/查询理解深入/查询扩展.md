# 查询扩展（Query Expansion）

> 对应 query expansion（伪相关反馈 PRF；LLM 扩展）；与 查询改写与扩展深入 衔接。

## 一、背景与挑战

短查询词少、歧义大；扩展加相关词提升召回覆盖。

## 二、核心原理

伪相关反馈（RM3）用首检 top 文档词扩查询；或 LLM/词向量生成同义与上下位词；与原始查询加权融合。

## 三、数学形式

扩后向量 $q'=\alpha q+(1-\alpha)\frac{1}{k}\sum_{d\in topk}E(d)$（RM3 式）。

## 四、代码实现

```python
top = retrieve(q, 10); qe = (1-a)*q + a*mean([emb(d) for d in top])
```

## 五、与其他对比

- 与 查询改写与扩展深入（多查询/假设文档）共享扩展思想。
- 与 混合检索深入（扩展后双路）衔接。

## 六、常见误区

- 伪相关反馈引入噪声词（top 含不相关）。
- 扩展过度稀释原意图。
