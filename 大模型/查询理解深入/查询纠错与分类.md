# 查询纠错与分类

> 对应 query spelling correction（噪声信道模型）；查询分类（长度/语言/实体）。

## 一、背景与挑战

拼写错误与非常规表达致字面匹配失败；需纠错与规范化。

## 二、核心原理

纠错用编辑距离/噪声信道或神经 seq2seq 改正；分类标查询属性（如是否含专名、语言、长/短）；二者前置提升召回。

## 三、数学形式

纠错后验 $p(c|q)\propto p(q|c)p(c)$（噪声信道）；取 $\hat c=\arg\max_c p(c|q)$。

## 四、代码实现

```python
corrected = corrector(q)             # 拼写纠错
lang = detect(corrected)             # 语言分类
```

## 五、与其他对比

- 与 混合检索深入（BM25 对错误敏感）互补。
- 与 查询理解总览（子任务）共享。

## 六、常见误区

- 过度纠错改对为错（应置信阈值）。
- 未做语言/专名分类致跨语误召。
