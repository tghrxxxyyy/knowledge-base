# 实体与槽位抽取

> 对应 NER（Lample et al., 2016）；slot filling（口语理解）；与 查询理解深入 衔接。

## 一、背景与挑战

查询常含关键实体（人名/产品/时间），抽取后可用结构化过滤与精确匹配。

## 二、核心原理

用 NER/序列标注抽实体，用槽位填充抽属性（时间/地点/类型）；结合知识库做实体链接消歧。

## 三、数学形式

标注序列 $y=(y_1..y_n)$；条件概率 $p(y|x)=\prod_t p(y_t|y_{<t},x)$（CRF/BERT）。

## 四、代码实现

```python
ents = ner(q)                  # [("北京","LOC"), ("iPhone","PROD")]
filtered = filter_by(ents)
```

## 五、与其他对比

- 与 查询理解总览（结构化子任务）共享。
- 与 双塔在推荐（属性召回）对照。

## 六、常见误区

- 未做实体链接致同名歧义。
- 抽取错误传播到过滤致漏召。
