# 查询理解（Query Understanding）总览

> 对应 search query understanding 综述；与 查询改写与扩展深入 / 混合检索深入 衔接。

## 一、背景与挑战

用户查询常简短、歧义、口语化，直接检索召回差；需先理解意图与结构。

## 二、核心原理

查询理解包括意图分类、实体/槽位抽取、纠错、扩展、消歧；在大模型时代常以 LLM 统一解析为结构化查询。

## 三、数学形式

解析 $u=\text{QU}(q)=(\text{intent},\text{entities},\text{slots},\text{expanded})$；检索用 $u$ 而非原 $q$。

## 四、代码实现

```python
u = llm(f"解析查询意图与槽位: {q}")   # 结构化 JSON
hits = retrieve_with(u)
```

## 五、与其他对比

- 与 查询改写与扩展深入（同属查询前处理）共享。
- 与 检索器训练深入（理解影响召回）衔接。

## 六、常见误区

- 过度解析改变原意致偏题。
- 未处理歧义查询（多意图）致漏召。
