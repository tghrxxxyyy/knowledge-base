# 查询意图识别

> 对应 intent classification（搜索引擎意图分类：导航/信息/交易）；与 查询理解深入 总览衔接。

## 一、背景与挑战

不同意图应走不同检索/生成策略（如交易意图偏商品、信息意图偏文档）。

## 二、核心原理

把 query 分类为预设意图（导航/信息/交易，或细粒度垂直意图）；可用监督分类或 LLM 零样本；意图路由检索器。

## 三、数学形式

意图分布 $p(i|q)=\text{softmax}(W\cdot E(q))$；路由取 $\arg\max_i p(i|q)$。

## 四、代码实现

```python
intent = clf.predict(emb(q))          # 或 llm 零样本
docs = router[intent].retrieve(q)
```

## 五、与其他对比

- 与 查询理解总览（意图是子任务）共享。
- 与 检索器训练深入（按意图训检索器）衔接。

## 六、常见误区

- 意图体系过粗/过细致误分。
- 未处理多意图（应多路检索）。

## 八、面试题

- 为何分意图？答：不同意图检索源与排序不同，路由提升相关与体验。

## 十、小结

意图识别是查询理解入口，决定检索路由与策略。
