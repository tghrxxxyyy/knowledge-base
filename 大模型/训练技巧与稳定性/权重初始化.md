# 权重初始化

> 对应 Glorot & Bengio, *Understanding the Difficulty of Training Deep Feedforward Neural Networks* (Xavier), 2010；He et al., *Delving Deep into Rectifiers* (Kaiming), 2015；参考 Vaswani et al., 2017 的 scaled init。

## 一、背景与挑战

深度网络训练能否顺利「启动」，在第一步就已注定。错误初始化会导致：梯度消失（信号逐层衰减至 0，深层学不动）或梯度爆炸（信号放大发散），以及对称权重（同一层神经元学到相同特征，浪费容量）。大模型层数极深、残差与注意力交错，对初始尺度的敏感度更高。良好初始化的目标是让**前向激活方差**与**反向梯度方差**在每层大致守恒，使信号能顺畅流过上百层而不衰减或爆炸。

## 二、核心原理

经典方法按输入输出维度缩放权重方差：Xavier（tanh/sigmoid 等对称激活）令 $\text{Var}(W)=\frac{2}{n_{in}+n_{out}}$；Kaiming 针对 ReLU 类非负激活修正为 $\text{Var}(W)=\frac{2}{n_{in}}$。Transformer 常用**缩放初始化（scaled initialization）**：把权重按 $1/\sqrt{d_{model}}$ 缩放，残差分支（如注意力输出投影、MLP 输出）进一步乘小于 1 的系数（如 $1/\sqrt{2N}$）使其初始接近零，保证残差流「稳固」。位置/词嵌入通常不缩放，LayerNorm 的 gain 初始化为 1、bias 为 0。

## 三、形式化与数学基础

对一层 $y = Wx$（$x$ 零均值、方差 $\sigma_x^2$，权重零均值方差 $\sigma_w^2$），输出方差：

$$\text{Var}(y) = n_{in}\,\sigma_w^2\,\sigma_x^2$$

前向守恒要求 $\text{Var}(y)=\text{Var}(x)$，得 Xavier：

$$\sigma_w^2 = \frac{1}{n_{in}} \quad\text{或对称形式}\quad \frac{2}{n_{in}+n_{out}}$$

反向同理用 $n_{out}$。Kaiming（ReLU 后保留约一半方差）：

$$\sigma_w^2 = \frac{2}{n_{in}}$$

Transformer 注意力缩放初始化（见 Vaswani et al.）：

$$W_{out}^{\text{attn}} \sim \mathcal{N}\!\left(0,\ \frac{1}{d_{model}}\right),\qquad \text{残差分支乘}\ \frac{1}{\sqrt{2L}}$$

其中 $L$ 为层数，确保深层残差贡献初始近零、随训练增长。

## 四、代码实现

```python
import torch
import math

def init_weights(module, d_model=4096, n_layers=32):
    if isinstance(module, torch.nn.Linear):
        # 类 scaled init：按 1/sqrt(d_model)
        std = 1.0 / math.sqrt(d_model)
        torch.nn.init.normal_(module.weight, mean=0.0, std=std)
        if module.bias is not None:
            torch.nn.init.zeros_(module.bias)
    elif isinstance(module, torch.nn.LayerNorm):
        torch.nn.init.ones_(module.weight)
        torch.nn.init.zeros_(module.bias)

model.apply(lambda m: init_weights(m))
# 残差分支（注意力/MLP 输出）额外缩放，使其初始近零
for layer in model.layers:
    layer.attn.proj.weight.data.mul_(1.0 / math.sqrt(2 * n_layers))
```

## 五、与其他稳定技巧对比

| 手段 | 作用时机 | 解决 | 关联 |
|---|---|---|---|
| Xavier/Kaiming | 初始化 | 方差失衡 | 激活函数 |
| scaled init | 初始化 | 深层残差流 | 残差 |
| 学习率 warmup | 训练初 | 早期大梯度 | LR |
| LayerNorm 初始化 | 初始化 | 尺度漂移 | 归一化 |

初始化与归一化、warmup 共同构成训练稳定三件套。

## 六、常见误区

- 残差分支不缩放：初始贡献过大，深层信号失衡、易 spike。
- 对所有层用同一 std 不顾 $d_{model}$：注意力 logits 尺度失配。
- 给 bias 也加随机初始化：bias 通常置 0 最稳。
- 忽略激活函数选 Xavier：ReLU 用 Xavier 会偏保守、收敛慢，应 Kaiming。

## 八、面试题

1. 残差分支为何常初始化为近零？答：保证初始信息主要走恒等路径，深层稳定，随训练逐步引入变换。
2. Xavier 与 Kaiming 区别？答：前者面向对称激活，后者修正 ReLU 的方差减半。
3. 注意力输出为何要 $1/\sqrt{d_{model}}$ 缩放？答：控制 logits 与残差流尺度，防止 softmax 饱和。

## 九、演进与趋势

现代 LLM 初始化日趋「保守且可证明」：如 DeepNorm（把残差与归一化合并、给出理论不爆炸界）、Fixup / T-Fixup 免去 LayerNorm 也能深训。趋势是用理论界约束初始化方差，使上百层网络训练起点即稳定。

## 十、小结

权重初始化决定训练能否「启动」：通过 Xavier/Kaiming 与 Transformer 的 scaled init 维持前向/反向方差守恒，并把残差分支初始置近零，才能在大深度下让信号顺畅流动。它与归一化、warmup 共同撑起训练稳定的地基。
