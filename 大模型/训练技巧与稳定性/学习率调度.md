# 学习率调度

> 对应 Goyal et al., *Accurate, Large Minibatch SGD: Training ImageNet in 1 Hour*, 2017；Loshchilov & Hutter, *SGDR*, 2017；参考 HuggingFace `get_linear_schedule_with_warmup`。

## 一、背景与挑战

学习率是深度学习最敏感的超参。大模型训练初期，权重接近随机、梯度方向噪声大，若一上来就用大 LR，参数会被甩到损失面的坏区域，引发 loss spike 甚至 NaN。随训练推进，又需逐步降低 LR 以精细收敛。挑战在于：在「快收敛」与「稳启动」之间折中，且不同并行规模（大 batch）需线性缩放 LR。业界形成了「warmup + 余弦衰减」的默认组合。

## 二、核心原理

学习率调度按阶段分：(1) **Warmup（预热）**——前若干步（如总步数 0.1%–3%）从极小值线性升到峰值 $\eta_{max}$，让优化器动量、二阶矩先稳定、权重先「就位」；(2) **衰减**——到峰值后按 cosine / linear / step 下降。Cosine decay 在中期保持较高速率、末期平缓贴近 0，兼顾探索与收敛；末段常留极小 $\eta_{min}$（如 $\eta_{max}/10$）。大 batch 训练常按 **linear scaling rule**：$\eta \propto \text{batch\_size}$。

## 三、形式化与数学基础

Warmup（线性）阶段，第 $t$ 步（$t\le T_{wu}$）：

$$\eta_t = \eta_{min} + (\eta_{max}-\eta_{min})\frac{t}{T_{wu}}$$

Cosine decay 阶段（$T_{wu}<t\le T$）：

$$\eta_t = \eta_{min} + \tfrac{1}{2}(\eta_{max}-\eta_{min})\left(1+\cos\!\left(\pi\frac{t-T_{wu}}{T-T_{wu}}\right)\right)$$

Linear scaling rule（Goyal et al.）：

$$\eta = \eta_{base}\cdot\frac{B}{B_{base}}$$

其中 $B$ 为全局 batch size。配合 warmup 时，常先 warmup 再按比例放大，避免大 batch 初期发散。

## 四、代码实现

```python
from transformers import get_cosine_schedule_with_warmup
import torch

optimizer = torch.optim.AdamW(model.parameters(), lr=3e-4)
total_steps = 100_000
scheduler = get_cosine_schedule_with_warmup(
    optimizer,
    num_warmup_steps=2_000,        # 约 2%
    num_training_steps=total_steps,
)

for step, (x, y) in enumerate(loader):
    loss = model(x, y).loss
    loss.backward(); optimizer.step(); scheduler.step()
    if step % 100 == 0:
        print(step, scheduler.get_last_lr())
```

也可手动用 `LambdaLR` 拼接 warmup 与 cosine 两段函数，或末段接 `linear` 收尾。

## 五、与其他调度策略对比

| 策略 | 形状 | 特点 | 适用 |
|---|---|---|---|
| 常数 | 平 | 不稳 | 微调 |
| step/余弦阶梯 | 台阶 | 粗 | 旧 CV |
| linear decay | 直线 | 简单 | 中小模型 |
| cosine+warmup | 平滑 | 收敛好 | 大模型默认 |
| 余弦重启(SGDR) | 多重 | 逃局部 | 研究 |

## 六、常见误区

- 不用 warmup：大模型初期必 spike，常见灾难性发散。
- warmup 步数过长：等效降低有效 LR、拖慢收敛。
- 峰值 LR 与大 batch 不成比例：违反 linear scaling，训练不稳。
- 末期 LR 直接归零：不如留 $\eta_{min}$ 平滑，易在收尾震荡。

## 八、面试题

1. 为何大模型训练必须 warmup？答：初期权重随机、梯度噪声大，warmup 让动量/方差与权重先稳定，防 spike/NaN。
2. 大 batch 如何调 LR？答：按 linear scaling $\eta\propto B$，并配合 warmup。
3. cosine 比 linear 好在何处？答：中期保持高速率、末期平缓，收敛更充分。

## 九、演进与趋势

调度策略持续精细化：Warmup-Decay（如 1-cycle、Cosine with restart）、末段「尾段微调（cooldown）」、以及根据 loss 曲线自适应调整（如 learning rate range test）。但 cosine + warmup 仍是大模型预训练最稳健的默认。

## 十、小结

学习率调度是训练稳定的第一道保险：warmup 防止初期灾难，余弦衰减兼顾探索与收敛，大 batch 下遵循 linear scaling。掌握它的节奏，比纠结优化器种类更能直接改善大模型训练结果。
