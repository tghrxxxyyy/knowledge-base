# 梯度裁剪

> 对应 Pascanu et al., *On the difficulty of training Recurrent Neural Networks*, 2013；参考 PyTorch `torch.nn.utils.clip_grad_norm_` 文档、llm-course 训练稳定性章节。

## 一、背景与挑战

循环网络与深层 Transformer 训练初期，梯度可能因长程链式法则累积而指数级放大，出现**梯度爆炸**：参数更新一步跨越大片损失面，loss 瞬间 NaN，训练崩溃。RNN 时代该问题尤为突出（Hidden 到 Hidden 反复乘同矩阵），Transformer 虽靠残差与 LayerNorm 缓解，但在大模型 warmup 阶段、bad batch 出现时仍会爆。梯度裁剪（Gradient Clipping）通过对梯度范数设上限，约束单步更新幅度，成为训练稳定的标配。

## 二、核心原理

梯度裁剪有两种：(1) **按范数裁剪（clip by norm）**——计算全部梯度拼接向量的 L2 范数，若超过阈值 $c$ 则整体等比缩放；(2) **按值裁剪（clip by value）**——逐元素截断到 $[-c, c]$。大模型几乎都用按范数裁剪，因为它保留梯度方向、不破坏不同参数间的相对比例。裁剪只在「范数超限时」生效，正常步不受影响，因此不会拖慢收敛。

## 三、形式化与数学基础

设第 $t$ 步各参数梯度拼成向量 $g_t=\{g_{t,i}\}$，全局 L2 范数

$$\|g_t\|_2 = \sqrt{\sum_i g_{t,i}^2}$$

按范数裁剪规则：

$$g_t \leftarrow \begin{cases} g_t \cdot \dfrac{c}{\|g_t\|_2}, & \|g_t\|_2 > c \\[6pt] g_t, & \|g_t\|_2 \le c \end{cases}$$

等价于 $g_t \leftarrow g_t \cdot \min\!\left(1,\ \dfrac{c}{\|g_t\|_2}\right)$。阈值 $c$ 常用 1.0（Llama、GPT 系列）。按值裁剪为 $g_{t,i}\leftarrow\text{clip}(g_{t,i},-c,c)$。注意裁剪作用在**累积完所有参数梯度之后、optimizer.step 之前**。

## 四、代码实现

```python
import torch
from torch.nn.utils import clip_grad_norm_, clip_grad_value_

optimizer.zero_grad()
loss = model(x, y).loss
loss.backward()

# 按范数裁剪（大模型默认）
total_norm = clip_grad_norm_(model.parameters(), max_norm=1.0)

# 或按值裁剪
# clip_grad_value_(model.parameters(), clip_value=1.0)

optimizer.step()
```

在多卡 DDP 下，梯度已在反向时 AllReduce 同步，裁剪作用于同步后的梯度，各卡一致。`max_norm` 也可设为范数上限（L2），框架内部自动算 $\|g\|_2$ 并缩放。

## 五、与其他稳定技巧对比

| 技巧 | 作用层 | 是否改方向 | 代价 |
|---|---|---|---|
| 梯度裁剪 | 梯度 | 否（仅缩放） | 几乎无 |
| 学习率 warmup | LR | 否 | 早期慢 |
| 混合精度 BF16 | 计算 | 否 | 精度略降 |
| 权重初始化 | 起点 | 否 | 一次性 |

裁剪与 warmup 最常搭配：warmup 防早期大梯度，裁剪兜底极端 step。

## 六、常见误区

- 裁剪会改变梯度方向：不会，它只等比重缩，方向不变，这正是优于按值裁剪之处。
- 阈值设得越小越稳：过小会持续压低有效 LR，拖慢甚至阻碍收敛。
- 每参数分别裁剪范数：破坏参数间比例，通常不用。
- 在 `zero_grad` 后裁剪：此时梯度已被清空，无效。

## 八、面试题

1. 梯度裁剪为何不影响正确方向？答：按范数裁剪是整体等比缩放，方向向量不变。
2. 阈值 $c$ 怎么选？答：常用 1.0，结合 grad norm 监控，过大失去保护作用、过小限制学习。
3. DDP 下裁剪是否一致？答：梯度已同步，裁剪后各卡更新一致。

## 九、演进与趋势

裁剪从 RNN 的救命稻草变成 Transformer 训练标配；近年出现**自适应裁剪**（如 `global_grad_clip` 随训练衰减）与逐层/逐张量裁剪，更精细地平衡稳定与收敛。但固定阈值 1.0 仍是最广泛可靠的默认。

## 十、小结

梯度裁剪通过对梯度范数封顶、保留方向地等比重缩，是训练稳定的低成本保险。配合 warmup 与监控，能在不牺牲收敛速度的前提下，兜住 every-step 的极端梯度，是现代大模型训练循环的标准一环。
