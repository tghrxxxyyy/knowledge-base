# 损失函数设计

> 对应 Vaswani et al., *Attention Is All You Need*, 2017（交叉熵训练）；Ouyang et al., *InstructGPT*, 2022（SFT loss mask）；以及 Kaplan et al., *Scaling Laws*, 2020（损失与能力关系）。

## 一、背景与挑战

「损失函数定义模型在学什么」。同一个 Transformer，配不同的训练目标会得到完全不同能力的模型：因果语言建模（CLM）学会生成，掩码语言建模（MLM）学会理解，序列到序列（seq2seq）学会转换。在指令微调（SFT）与偏好对齐阶段，损失该如何只对「回答部分」计算、如何加权多任务、如何用偏好损失塑造行为，直接决定模型「有用、无害、诚实」的程度。核心挑战：① 错误地对 prompt 算 loss 会学偏；② 多任务/多阶段损失需平衡；③ 对齐阶段需把人类偏好转为可优化目标。

## 二、核心原理

- **CLM（生成预训练）**：标准交叉熵，对所有 token 位置求负对数似然。
- **MLM（理解预训练）**：仅对遮盖位置算交叉熵（见掩码语言建模章节）。
- **SFT loss mask**：监督微调时，只对「回答/补全」token 计算损失，prompt 与历史部分 mask 掉，避免模型去「模仿提问风格」或浪费梯度。
- **偏好损失（RLHF/DPO）**：用成对偏好数据塑造回答质量（见人类偏好评测章节）。
- **多任务加权**：不同任务损失按权重或不确定度加权，防某任务主导。

## 三、形式化与数学基础

CLM 对序列 $x=(x_1,\dots,x_T)$ 的负对数似然：

$$
\mathcal{L}_{\text{CLM}} = -\sum_{t=1}^{T}\log P(x_t\mid x_{<t})
$$

SFT 引入掩码 $m_t\in\{0,1\}$（1 表示回答 token），仅对回答求均值：

$$
\mathcal{L}_{\text{SFT}} = -\frac{1}{\sum_t m_t}\sum_{t=1}^{T} m_t\,\log P(x_t\mid x_{<t})
$$

多任务加权（固定权重 $w_k$ 或基于不确定度 $\sigma_k^2$）：

$$
\mathcal{L} = \sum_k w_k\,\mathcal{L}_k \quad \text{或} \quad \mathcal{L} = \sum_k \frac{1}{2\sigma_k^2}\mathcal{L}_k + \log\sigma_k
$$

DPO 直接以偏好数据优化策略（省略显式奖励模型）：

$$
\mathcal{L}_{\text{DPO}} = -\mathbb{E}\Big[\log\sigma\big(\beta\log\tfrac{\pi_\theta(y_w\mid x)}{\pi_{\text{ref}}(y_w\mid x)} - \beta\log\tfrac{\pi_\theta(y_l\mid x)}{\pi_{\text{ref}}(y_l\mid x)}\big)\Big]
$$

## 四、代码实现

SFT 中构造 loss mask（仅回答部分算损失）：

```python
import torch.nn as nn

loss_fct = nn.CrossEntropyLoss(ignore_index=-100)
logits = model(input_ids).logits[..., :-1, :]      # 预测下一 token
shift_labels = labels[..., 1:].clone()
# 把 prompt 部分标为 -100（被忽略），只保留回答 token
shift_labels[prompt_mask[..., 1:]] = -100
loss = loss_fct(logits.reshape(-1, V), shift_labels.reshape(-1))
```

```python

```

## 五、与其他技术对比

| 目标 | 学什么 | 适用阶段 |
|------|--------|----------|
| CLM | 自回归生成 | 预训练 |
| MLM | 双向理解 | 编码器预训练 |
| SFT (masked) | 按指令回答 | 监督微调 |
| 偏好损失(DPO/PPO) | 对齐人类偏好 | 对齐 |
| 多任务加权 | 平衡多能力 | 全阶段 |

## 六、常见误区

- 「SFT 应对所有 token 算 loss」：对 prompt 算 loss 会强迫模型模仿输入风格，浪费梯度且可能退化。
- 「多任务直接求和即可」：未加权时大数据任务主导，需平衡或不确定度加权。
- 「损失越低能力越强」：过拟合训练分布会刷低 loss 却损泛化；Scaling Laws 只说明整体趋势。
- 「对齐只需一个奖励损失」：需配合 SFT 与 KL 约束，否则奖励黑客（reward hacking）。

## 九、演进与趋势

损失设计从「单一 CLM/MLM」走向「多阶段复合」：预训练 CLM → SFT（带 mask）→ 偏好对齐（PPO/DPO）。趋势包括：更长上下文的分段损失、课程学习（由易到难调权）、在线偏好学习、以及对「推理过程（CoT）」的针对性损失。同时关注「奖励黑客」与 KL 正则，防止对齐崩溃。

## 十、小结

损失函数定义模型「学什么」：CLM/MLM 决定基础能力，SFT 的 loss mask 决定对齐指令，偏好损失决定行为合意性，多任务加权决定能力平衡。设计时应避免对 prompt 误算损失、忽视任务权重。具体目标与权重以 InstructGPT、DPO 等论文及官方训练脚本为准。
