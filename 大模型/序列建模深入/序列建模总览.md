# 序列建模总览

> 对应 d2l-zh 序列模型章；Goodfellow《Deep Learning》第 10 章。

## 一、背景与挑战

文本、语音、时序信号是变长有序数据，需建模元素间顺序依赖。

## 二、核心原理

三代范式：**RNN/LSTM**（递归状态）、**CNN**（局部卷积、可并行）、**Transformer/SSM**（注意力/状态空间、长程强）。选择取决于长程依赖长度与并行需求。

## 三、关键要点

- RNN 串行难并行、易梯度消失。
- Transformer 并行强但 O(N²)。
- SSM 兼顾长程与线性复杂度。

## 四、代码实现

```python
# Transformer 序列
out = transformer(src, tgt)
```

## 五、与其他对比

| 模型 | 并行 | 长程 | 复杂度 |
|------|------|------|--------|
| RNN | 否 | 弱 | O(N) |
| CNN | 是 | 中 | O(N·k) |
| Attn | 是 | 强 | O(N²) |

## 六、常见误区

- 注意力取代一切——特定场景 RNN/SSM 更优。
