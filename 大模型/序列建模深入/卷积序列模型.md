# 卷积序列模型

> 对应 d2l-zh；Kalchbrenner et al., *WaveNet/TCN*, 2016；Bai et al., *TCN*, 2018。

## 一、背景与挑战

RNN 串行慢，能否用 CNN 并行建模序列？

## 二、核心原理

**时间卷积网络（TCN）**用因果膨胀卷积（dilated causal conv）扩大感受野并保持因果性，可并行、稳定。WaveNet 用此生成音频。

## 三、数学形式

膨胀卷积：`(f *d g)(t) = Σ f(i) g(t - d·i)`，d 为膨胀率，逐层翻倍扩大感受野。

## 四、代码实现

```python
nn.Conv1d(c, c, kernel=3, dilation=2**l, padding=...)
```

## 五、关键要点

- 并行、内存友好。
- 需多层才覆盖长程。

## 六、与其他对比

- CNN 并行优；RNN 序列建模自然。

## 七、常见误区

- 卷积只看局部——膨胀可覆盖长程。
