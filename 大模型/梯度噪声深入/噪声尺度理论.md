# 噪声尺度理论

> 对应 Jastrzebski et al., *Three Factors... Noise, Batch, and Learning Rate*, ICLR 2018。

## 一、背景与挑战

哪些因素决定 SGD 噪声，且如何共同影响泛化，需要统一公式。

## 二、核心原理

噪声尺度由学习率、批量、每样本梯度方差三者共同决定；固定噪声尺度可等价不同 (B,η) 组合。

## 三、数学形式

有效噪声 $\gamma=\frac{\eta}{B}\cdot\mathbb E\|\nabla\mathcal L_i-\nabla\mathcal L\|$；保持 $\eta/B$ 比可迁移泛化行为。

## 四、代码实现

```python
def noise_scale(lr, B, gvar): return lr * gvar / B
```

## 五、与其他对比

- 与 自适应学习率深入 的 LR 选择直接相关。
- 与 梯度噪声总览 同源。

## 六、常见误区

- 仅调批量不调 LR 改变噪声尺度破坏泛化。
- 以为大批量必差，可通过 LR 缩放补偿。

## 八、面试题

- 如何保持噪声尺度不变地增大批量？答：按线性缩放 LR 使 η/B 不变，从而保持泛化行为。

## 九、演进

三因素观察 → 噪声尺度不变性 → 批量-LR 联动法则。

## 十、小结

噪声尺度理论统一了批量/LR/方差的影响，指导大批量训练。
