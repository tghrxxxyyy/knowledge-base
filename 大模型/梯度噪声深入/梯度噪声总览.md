# 梯度噪声总览

> 对应 Smith & Le, *A Bayesian Perspective on Generalization and SGD*, 2017；Jastrzebski et al., 2017。

## 一、背景与挑战

SGD 用小批量引入噪声，既是收敛阻碍也是泛化助力，需量化理解。

## 二、核心原理

小批量梯度是真实梯度的带噪估计；该噪声在连续时间极限下等价于 Langevin 扩散，助 escaping 尖锐极小。

## 三、数学形式

噪声尺度 $\gamma\approx\frac{\eta\epsilon}{B}\|\nabla\mathcal L\|$，其中 $\eta$ 学习率、$\epsilon$ 每样本梯度方差、$B$ 批量。

## 四、代码实现

```python
noise_scale = lr * grad_var_per_sample / batch_size * grad.norm()
```

## 五、与其他对比

- 与 平坦极小值深入 共享"噪声→平坦"机制。
- 与 损失景观深入（saddle 逃离）相关。

## 六、常见误区

- 以为噪声纯有害；合适噪声助泛化。
- 混淆 batch 与 LR 对噪声的独立作用。

## 十、小结

梯度噪声是 SGD 泛化的隐性来源，由批量与 LR 共同控制。
