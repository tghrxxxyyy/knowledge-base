# 学习率退火与噪声

> 对应 Klein et al., *Fast Bayesian Inference...*, 2015；以及 LR 退火使 SGD 收敛到尖解的研究。

## 一、背景与挑战

训练末段学习率策略决定最终解的锐度与泛化。

## 二、核心原理

高 LR 维持大噪声助探索平坦区；末段衰减降噪使解收敛；过快衰减困于尖锐局部。

## 三、数学形式

退火温度 $T(t)=\frac{\eta(t)\epsilon}{B}$；余弦/阶梯下降使 $T\to0$，分布收窄。

## 四、代码实现

```python
sched = CosineAnnealingLR(opt, T_max=epochs, eta_min=1e-5)
```

## 五、与其他对比

- 与 自适应学习率深入 的调度一致。
- 与 损失景观深入（批量）协同。

## 六、常见误区

- 过早衰减使解停在 sharp 区。
- 一直高 LR 不收敛。

## 八、面试题

- 为何要学习率退火？答：逐步降低噪声温度，使探索后收敛到选定 basin，平衡探索与收敛。

## 九、演进

固定 → step → 余弦/循环退火。

## 十、小结

退火通过控制噪声温度塑造最终解，是泛化调控的关键旋钮。
