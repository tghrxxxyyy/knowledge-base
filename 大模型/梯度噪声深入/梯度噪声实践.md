# 梯度噪声实践

> 对应大模型训练中的批量/LR 缩放法则（如 linear scaling rule）。

## 一、背景与挑战

分布式训练增大批量，需保持泛化不退化。

## 二、核心原理

线性缩放规则：批量乘 $k$ 则 LR 乘 $k$ 以保持噪声尺度；warmup 稳定初期大 LR。

## 三、数学形式

$B'=kB\Rightarrow\eta'=k\eta$；保持 $\eta/B$ 不变，噪声尺度近似保持。

## 四、代码实现

```python
lr = base_lr * world_size   # 线性缩放
sched = LinearWarmup(...)
```

## 五、与其他对比

- 与 自适应学习率深入 调度协同。
- 与 权重衰减深入（ηλ 积）联动。

## 六、常见误区

- 超大批量仅线性缩放仍泛化降（需更优 LR 策略）。
- 忽略 warmup 致初期不稳定。

## 八、面试题

- 大批量如何保泛化？答：线性缩放 LR 维持噪声尺度，并配 warmup 与合适衰减。

## 九、演进

线性缩放 → warmup → 分层噪声策略。

## 十、小结

梯度噪声可通过批量-LR 法则工程化控制，是大模型扩展基础。
