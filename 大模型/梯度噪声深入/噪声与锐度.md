# 随机梯度与锐度

> 对应 Keskar et al., ICLR 2017（批量大小影响锐度）；与 SAM 相互作用研究。

## 一、背景与挑战

梯度噪声与锐度互相塑造：噪声推离尖锐、但也可能阻止收敛到最优点。

## 二、核心原理

小批量噪声提供逃离尖锐区的动力；SAM 主动锐度正则可与噪声协同进一步平坦化。

## 三、数学形式

噪声驱动位移 $\Delta\theta\sim\sqrt{2D\Delta t}$；在尖锐区梯度曲率大，位移更易越出盆地。

## 五、与其他对比

- 与 锐度感知深入 可叠加但可能冗余。
- 与 平坦极小值深入 共享机制。

## 六、常见误区

- 以为加 SAM 就不需要噪声，二者目标重叠但角度不同。
- 噪声过大时 SAM 扰动被淹没。
