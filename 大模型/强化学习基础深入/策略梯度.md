# 策略梯度

> 见「强化学习基础深入/强化学习总览」与「微调与对齐/PPO算法」。

## 一、背景与挑战

直接优化策略参数使回报最大。

## 二、核心原理

REINFORCE：对轨迹回报求梯度升策略概率；减基线降方差。

## 三、数学形式

```
∇_θ J = E[ Σ_t ∇ log π(a_t|s_t) · G_t ]
```

## 四、代码实现

```python
loss = -(logp * (returns - baseline)).mean()
```

## 五、关键要点

- 高方差需基线。
- on-policy。

## 六、与其他对比

- 值方法间接；策略梯度直接。

## 七、常见误区

- 无基线也行——方差大不稳。
