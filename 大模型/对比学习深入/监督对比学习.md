## 一、背景与挑战

有标签时如何更好利用标签对比？

## 二、核心原理

SupCon：同标签样本互为正例，异标签为负例，比 CE 更鲁棒、可学更紧表征。

## 三、数学形式

```
L = Σ_i -1/|P(i)| Σ_{p∈P(i)} log exp(s_i,p/τ)/Σ_{a∈A(i)} exp(s_i,a/τ)
```

## 四、代码实现

```python
loss = supcon(features, labels)
```

## 五、关键要点

- 同标签全正例提升判别。
- 对噪声标签更稳。

## 六、与其他对比

- CE 仅分界面；SupCon 拉聚集类。

## 七、常见误区

- 有标签就不用对比——SupCon 常更优。
