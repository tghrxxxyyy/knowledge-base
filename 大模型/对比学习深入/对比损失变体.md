# 对比损失变体

> 对应 SimCLR（Chen et al., 2020，https://github.com/google-research/simclr）、SupCon（Khosla et al., 2020，https://github.com/HobbitLong/SupContrast）、CLIP（Radford et al., 2021，https://github.com/openai/CLIP）、InfoNCE/CPC（van den Oord et al., 2018，arXiv:1811.03703）、Triplet Loss（Schroff et al., FaceNet, 2015）；并见本库「对比学习深入/对比学习总览」「多模态对齐深入/CLIP对比对齐」篇章。

## 一、背景与挑战

监督分类用交叉熵在固定标签集合上学习，而对比学习的目标是学一个**度量空间**：相近的样本拉近、无关的样本推远，标签只用来定义"谁和谁算正例"。这带来三个挑战。第一，负例定义决定几何：自监督场景（SimCLR）把同批内其他样本全当负例，标签场景（SupCon）把异类当负例，多模态场景（CLIP）把批内不配对的图文对当负例——同一个公式换个负例集合，语义完全不同。第二，负例数量与质量的矛盾：负例越多估计越准，但简单负例贡献趋零，需要难负例挖掘或大 batch。第三，训练稳定性：softmax 结构的对比损失对温度 $\tau$ 极其敏感，$\tau$ 偏大表征欠分离，偏小梯度爆炸或全部塌缩到少数 hard negative 上。此外还有与 BCE、三元组损失的路线之争：前者把每个（正/负）对当独立二分类，后者只看单个三元组，信息利用率依次递减。

## 二、核心原理

### 2.1 InfoNCE：统一的母形式

InfoNCE 源自噪声对比估计（NCE）：给定锚点 $z_i$ 与一个正例 $z_i^+$ 和 $K$ 个负例，把"识别出正例"建模为 $K+1$ 类分类，模型输出为相似度 $\mathrm{sim}(z_i, z_j)/\tau$ 上的 softmax。直觉上，最小化 InfoNCE 等价于最大化正例的互信息下界——这正是 CPC 用它做时序预测的原因。之后的 NT-Xent、CLIP 损失都是它在不同负例集合上的实例化。

### 2.2 NT-Xent（SimCLR 的规范化温度缩放交叉熵）

SimCLR 对每个样本 $x_i$ 做两次增广得到 $z_i, z_j$，批内 $2N$ 个样本互为候选：$z_i$ 的正例是对偶增广 $z_j$，其余 $2N-2$ 个全是负例。相似度用余弦并除以 $\tau$，在批内做对称的两方向 softmax。关键设计是大 batch（4096+）+ 强增广 + 投影头（projection head，预训练表征 $h$ 映射到 $z$ 再算损失，下游用 $h$），三者缺一性能显著掉点。

### 2.3 SupCon：监督对比

SupCon 把标签引入正例集合：锚点的正例是**同类的所有其他样本**（含不同增广），负例是所有异类。相比分类式 softmax（每个类只有一个可学习原型），SupCon 让一个锚点同时对齐多个正例、排斥多个负例，通常在长尾与迁移任务上更稳。温度同样控制排斥强度。

### 2.4 CLIP 对称损失与多负样本

CLIP 把批内 $N$ 个图文对组成 $N\times N$ 相似度矩阵 $S_{ij} = \langle f(I_i), g(T_j)\rangle / \tau$，做两个方向的交叉熵：行方向"给图找对文"（label 为对角线），列方向"给文找图"。对称结构使两个编码器被同等约束，这是 CLIP 零样本能力的基础。批内所有非对角项即天然负例，等价于 InfoNCE 双向实例化；大 batch 就是它的负例来源。

### 2.5 温度 $\tau$ 的作用

$\tau$ 出现在 softmax 分母：小 $\tau$ 放大相似度差异，分布更尖锐，模型被迫区分细微差别，对 hard negative 更敏感，但梯度方差大、易数值不稳定（故常加可学习温度或 logit clamp）；大 $\tau$ 平滑分布，训练稳但表征分离度不足。经验上自监督单模态取 $0.07$–$0.2$，CLIP 取 $0.07$ 左右且作为可学习参数。

### 2.6 与 BCE、三元组的对比

Triplet loss 只用 $(a, p, n)$ 一个三元组的相对约束 $\max(0, d(a,p) - d(a,n) + m)$，信息量最小且依赖挖掘；BCE 把每个（锚,候选）对独立过 sigmoid，正负例解耦、可加权处理不均衡，但丢掉了批内"相对排序"的竞争结构；InfoNCE 系列把所有负例放进同一个归一化分母，天然实现批内排序，样本效率最高，代价是对 batch 构成敏感。

## 三、形式化与数学基础

设批大小 $N$（样本数 $B=2N$），归一化表征 $z_i = g(x_i)/\|g(x_i)\|_2$，相似度 $s(i,j) = z_i^\top z_j$。

**InfoNCE（锚 $i$，正例 $p(i)$，负例集合 $\mathcal{N}(i)$）：**

$$\mathcal{L}_i = -\log \frac{\exp\big(s(i, p(i)) / \tau\big)}{\exp\big(s(i, p(i)) / \tau\big) + \sum_{n \in \mathcal{N}(i)} \exp\big(s(i, n) / \tau\big)}$$

**NT-Xent（SimCLR，互为正例的对称形式）：**

$$\mathcal{L}_{i} = -\log \frac{\exp(s_{ij}/\tau)}{\sum_{k=1}^{2N} \mathbf{1}[k \neq i]\,\exp(s_{ik}/\tau)}, \qquad \mathcal{L} = \frac{1}{2N}\sum_{i=1}^{2N} \mathcal{L}_i$$

**SupCon（标签 $y$，正例 $\mathcal{P}(i) = \{p : y_p = y_i,\ p \neq i\}$）：**

$$\mathcal{L}_i = -\frac{1}{|\mathcal{P}(i)|} \sum_{p \in \mathcal{P}(i)} \log \frac{\exp(s_{ip}/\tau)}{\sum_{a \neq i} \exp(s_{ia}/\tau)}$$

**CLIP 对称损失（批内 $N$ 对）：**

$$\mathcal{L} = \frac{1}{2}\Big( \underbrace{-\tfrac{1}{N}\textstyle\sum_i \log \frac{e^{S_{ii}}}{\sum_j e^{S_{ij}}}}_{\text{image-to-text}} - \tfrac{1}{N}\textstyle\sum_i \log \frac{e^{S_{ii}}}{\sum_j e^{S_{ji}}}\Big)$$

**Triplet 与 BCE 对照：**

$$\mathcal{L}_{tri} = \max\big(0,\ d(a,p) - d(a,n) + m\big), \qquad \mathcal{L}_{BCE} = -\sum_k \big[y_k\log\sigma(s_k) + (1-y_k)\log(1-\sigma(s_k))\big]$$

温度的解析意义：$\frac{\partial \mathcal{L}_i}{\partial s_{in}} = \frac{1}{\tau}\big(\mathbf{1}[n{=}p] - \mathrm{softmax}_n\big)$，故 $\tau$ 直接线性缩放梯度并决定 softmax 的熵——$\tau \to 0$ 时梯度集中到最大 logit 项，$\tau \to \infty$ 时梯度均匀趋零。批大小 $N$ 与 $\tau$ 存在耦合：负例增多会压低正例的 softmax 概率，常需随 $N$ 微调 $\tau$。

## 四、代码实现

```python
import torch
import torch.nn.functional as F


def info_nce(z_anchor, z_positive, temperature=0.1):
    """批内 InfoNCE：z_anchor 与 z_positive 为已归一化的 (N, d) 表征，
    其余样本作为负例，返回标量损失。"""
    N = z_anchor.size(0)
    logits = z_anchor @ z_positive.t() / temperature       # (N, N) 相似度矩阵
    labels = torch.arange(N, device=z_anchor.device)       # 对角线为正例
    return F.cross_entropy(logits, labels)


def nt_xent(z, temperature=0.1):
    """SimCLR NT-Xent：z 为 2N 个增广样本的表征，第 i 与第 i+N 互为正例。"""
    B = z.size(0)
    sim = (z @ z.t()) / temperature
    sim.fill_diagonal_(-float("inf"))                      # 屏蔽自身
    pos = torch.cat([torch.arange(B // 2, B), torch.arange(0, B // 2)], 0)
    # 对每个锚点，正例在 pos[i]，分母为其余所有样本
    return F.cross_entropy(sim, pos.to(z.device))


def supcon(z, labels, temperature=0.1):
    """SupCon：同标签互为正例，异类为负例；z 已归一化。"""
    B = z.size(0)
    sim = (z @ z.t()) / temperature
    logits = sim.masked_fill(sim == 0, -1e9) if False else sim
    logits = logits - logits.max(dim=1, keepdim=True).values.detach()  # 数值稳定
    labels = labels.view(B, 1)
    pos_mask = (labels == labels.t()).fill_diagonal_(False)            # 去掉自身
    exp_logits = logits.exp()
    log_prob = logits - exp_logits.sum(1, keepdim=True).log()
    # 对每个锚点：正例 log-prob 的均值的负平均
    mean_log_prob = (pos_mask * log_prob).sum(1) / pos_mask.sum(1).clamp(min=1)
    return -mean_log_prob.mean()


def clip_loss(image_feats, text_feats, learnable_temp=0.07):
    """CLIP 对称损失：image_feats/text_feats 为 (N, d) 且已归一化。"""
    logit_scale = (1.0 / learnable_temp).exp().clamp(max=100.0)
    logits = logit_scale * image_feats @ text_feats.t()     # (N, N)
    targets = torch.arange(len(image_feats), device=logits.device)
    i2t = F.cross_entropy(logits, targets)                  # 给图配文
    t2i = F.cross_entropy(logits.t(), targets)              # 给文配图
    return (i2t + t2i) / 2


def triplet_loss(anchor, positive, negatives, margin=0.2):
    """三元组损失：negatives 为 (N, K, d)，对每个 hard negative 求最大间隔惩罚。"""
    d_pos = (anchor - positive).pow(2).sum(-1)              # 正例距离
    d_neg = (anchor.unsqueeze(1) - negatives).pow(2).sum(-1)  # (N, K)
    return F.relu(d_pos.unsqueeze(1) - d_neg + margin).mean()
```

## 五、与其他技术对比

| 损失 | 正例来源 | 负例范围 | 温度/间隔 | 信息利用 | 典型应用 |
| --- | --- | --- | --- | --- | --- |
| InfoNCE | 显式正例对 | 批内指定集合 | $\tau$ | 高（批内竞争） | CPC、通用对比框架 |
| NT-Xent | 同样本另一增广 | 批内其余全部 | $\tau$（常 0.1） | 高 | SimCLR 图像自监督 |
| SupCon | 同类全部样本 | 所有异类 | $\tau$ | 高 | 有标签表征、细粒度检索 |
| CLIP 对称损失 | 配对图文 | 批内非配对项 | 可学习 $\tau$ | 高（双向） | 文图零样本、多模态对齐 |
| Triplet | 单个锚-正对 | 挖掘/随机单负例 | 间隔 $m$ | 低（单三元组） | 人脸检索（FaceNet） |
| N-pair / Multi-sim | 单正例 | 批内多负例 | $m$ 或 $\tau$ | 中 | 检索基线 |
| BCE（成对） | 显式正对 | 独立负对（可加权） | 无（可调权重） | 中（无批内竞争） | 相关性判定、不均衡负例 |

| batch 规模敏感度 | 高 | 低 | 低 |

## 六、常见误区

1. **损失可以随意互换**——损失隐含正负例定义；把 NT-Xent 用到标签数据却不合并同类正例，会把同類样本当负例推开，直接学错几何。
2. **温度只是数值细节**——$\tau$ 决定分布锐度与梯度尺度，换数据集或 batch 后不重调 $\tau$，往往比换模型影响更大。
3. **负例越多越好**——大量重复/易负例贡献趋零，还可能因 batch 过大挤占其他增广的算力；难负例挖掘与加权往往更有效。
4. **对比表征与 logits 直接可分类**——对比学习输出要配投影头，评估与下游分类应使用投影前的 $h$；直接拿 $z$ 掉点是常见坑。
5. **batch 内不归一化也行**——不归一化时相似度会被向量模长主导，模型学会放大模长而非对齐方向；余弦 + 归一化是标准做法。
6. **BCE 与 InfoNCE 数值不同只是写法问题**——BCE 缺少批内归一化的竞争结构，不等价；在检索任务上二者排序行为不同。
7. **hard negative 挖掘总是有益**——批内错配（如数据标注噪声）会造成 false negative，盲目推远会伤表征，需要去重或软标签缓解。

## 八、面试题

1. **NT-Xent 与 InfoNCE 的关系？SimCLR 做了哪些额外设计？**
   要点：NT-Xent 是 InfoNCE 在"双增广互为正例、批内其余为负"上的实例化；SimCLR 的增广组合、大 batch、投影头与温度缺一不可。
2. **温度 $\tau$ 调大调小各发生什么？**
   要点：调小分布更尖锐、对 hard negative 敏感但梯度方差大；调大训练稳但分离度不足。梯度含 $1/\tau$ 因子，须与数值稳定措施配合。
3. **SupCon 比分类交叉熵好在哪？什么时候不如？**
   要点：一个锚点对齐多个正例、排斥多个负例，迁移与长尾更稳；类别极少且干净时，分类损失更简单高效。
4. **CLIP 为什么要对称损失？单向行吗？**
   要点：单向只约束一个方向的配对分布，另一模态编码器约束弱；对称损失使图文两塔对批内负例同等竞争，零样本检索才均衡。
5. **三元组损失的缺点？为什么被 InfoNCE 取代？**
   要点：单三元组信息量小、依赖挖掘、易局部最优；InfoNCE 把批内所有负例放进归一化分母，样本效率与排序目标更直接。
6. **训练中出现 false negative（语义相同却被当负例）怎么办？**
   要点：去重、基于标签/聚类过滤负例、用软标签降权，或换 SupCon 式正例集合；这是自监督大 batch 的固有风险。

## 九、演进与趋势

演进主线是三元组/成对 BCE → NCE/InfoNCE → NT-Xent（标准化增广与大 batch）→ SupCon（注入标签）→ CLIP 对称损失（跨模态、双向、可学习温度）。趋势上，纯负例对比正在与聚类式方法（SwAV、bootstrap 类 BYOL/SimSiam 弱化负例）、蒸馏与掩码建模（MAE）融合，负例需求被部分替代；多模态侧则走向更大批与跨批负例缓存（queue/memory bank 的现代变体）、更稳的温度参数化，以及把对比目标作为大模型表示对齐（对齐阶段 alignment）的核心损失。面试与实践中，掌握"一个母公式 + 负例集合 + 温度"的分析框架即可推演几乎所有变体。

## 十、小结

对比损失家族共享 InfoNCE 母形式，差别集中在三点：正负例的定义（增广、标签、图文配对）、批内归一化带来的竞争结构、温度对锐度与梯度的控制。NT-Xent、SupCon、CLIP 对称损失分别是自监督、监督、跨模态的实例化；Triplet 与 BCE 则是信息利用率更低的前身。工程实现的抓手是——严格归一化表征、稳定且可调的温度、正例 mask 正确（勿把自身或同类似为负例）、以及难负例与 false negative 的治理。
