# 对比学习总览

> 对应 d2l-zh 与 llm-course；见「自监督学习深入/对比学习原理」。

## 一、背景与挑战

需在无标注下学可迁移表征，对比学习是关键路径。

## 二、核心原理

以相似度为核心：正例拉近、负例推远；框架含数据增强、编码器、投影头、对比损失。

## 三、数学形式

InfoNCE（见自监督章）。

## 四、代码实现

```python
proj = MLP(encoder(x)); loss = nt_xent(proj, proj_aug)
```

## 五、关键要点

- 增强策略决定学习不变性。
- 投影头训练后丢弃。

## 六、与其他对比

- 监督对比也可（SupCon）。

## 七、常见误区

- 负例=不同类——自监督无类标，靠增强区分。

## 八、与开源书对应

- Oord et al., 2018.
