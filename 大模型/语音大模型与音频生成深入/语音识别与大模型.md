# 语音识别与大模型

> 对应 github huggingface/transformers 项目与 Vaswani 2017 的 Transformer 论文。

## 一、背景与挑战
语音识别需把声学信号转为文字，受口音、噪声、语速影响。大模型化 ASR 用统一序列建模提升鲁棒性。

## 二、核心原理
将语音特征序列编码，用 Transformer 解码为子词文本，配合 CTC 或注意力对齐，实现端到端识别。

## 三、形式化与数学基础
CTC 路径求和：
$ p(y|x)=\sum_{\pi\in\mathcal{B}^{-1}(y)} \prod_t p(\pi_t|x) $
$ \mathcal{B} $ 去除重复与空白。

## 四、代码实现
```python
import torch

def ctc_loss(logits, targets, blank=0):
    # logits: (T,V) ; targets: (U,)
    lp = torch.nn.functional.log_softmax(logits, -1)
    # 动态规划(示意)
    return -lp.mean()

def decode_greedy(logits, blank=0):
    best = logits.argmax(-1)
    out = []
    for t in range(len(best)):
        if best[t] != blank and (t == 0 or best[t] != best[t-1]):
            out.append(int(best[t]))
    return out
```

## 五、与其他技术对比
相比混合 HMM-GMM，端到端更简洁且数据驱动；相比 RNN-T，CTC 解码简单但需独立语言模型。

## 六、常见误区
把方言当噪声处理。长静音未分段导致对齐失败。

## 七、与开源书/权威来源对应
- Vaswani 2017 Transformer
- github huggingface/transformers 的 ASR 模型
- github pytorch/pytorch

## 八、面试题
问：CTC 为何需要 blank？答：允许输出与输入帧数不对齐，吸收重复与间隔。

## 九、演进与趋势
流式识别、多语言与大模型统一。

## 十、小结
序列建模把 ASR 推向端到端与大模型化。
