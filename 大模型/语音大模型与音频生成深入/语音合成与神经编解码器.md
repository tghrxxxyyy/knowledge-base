# 语音合成与神经编解码器

> 对应 github karpathy/nanoGPT 项目与 Ho 2020 的 DDPM 论文。

## 一、背景与挑战
高保真语音合成需自然韵律与说话人一致性。神经编解码器把波形压为离散 token，使语音可像文本一样生成。

## 二、核心原理
用残差矢量量化把音频编码为多层 token，语言模型自回归生成 token，再由解码器还原波形，实现可控 TTS。

## 三、形式化与数学基础
残差量化：
$ r_0 = x,\quad q_k = \mathrm{Quant}_k(r_{k-1}),\quad r_k = r_{k-1} - q_k $
多层量化逼近原始信号。

## 四、代码实现
```python
import torch

def quantize(x, codebooks, n_levels=8):
    r = x.clone()
    tokens = []
    for cb in codebooks:
        d = (cb - r.unsqueeze(1)).norm(dim=-1)
        idx = d.argmin(1)
        q = cb[idx]
        tokens.append(idx)
        r = r - q
    return tokens, r

def synth_from_tokens(lm, codec_dec, text_tokens):
    audio_tokens = lm.generate(text_tokens)
    return codec_dec.decode(audio_tokens)
```

## 五、与其他技术对比
相比声码器直接波形生成，离散 token 便于语言模型控制；相比级联 TTS，端到端更自然。

## 六、常见误区
码本坍塌降低表达。说话人向量未条件化导致串音。
