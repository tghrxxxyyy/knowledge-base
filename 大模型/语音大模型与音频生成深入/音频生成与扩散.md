# 音频生成与扩散

> 对应 Ho 2020 的 DDPM 论文与 github huggingface/transformers 项目。

## 一、背景与挑战
音效、音乐生成需时序结构与频谱真实。扩散模型在谱或波形域去噪，能产出高质音频。

## 二、核心原理
在梅尔谱或潜表示上加噪训练去噪网络，条件可为文本或类别，推理时迭代去噪生成音频表征再转波形。

## 三、形式化与数学基础
去噪匹配目标：
$ \mathcal{L}=\mathbb{E}_{t,x_0,\epsilon}\| \epsilon - \epsilon_\theta(x_t,t,c) \|^2 $
$ c $ 为条件。

```python
import torch

def audio_train(model, spec, cond, t, noise):
    xt = noise_sched.forward(spec, noise, t)
    pred = model(xt, t, cond)
    return ((pred - noise) ** 2).mean()

def generate(model, cond, steps=50):
    x = torch.randn_like(cond.shape_and_spec())
    for t in reversed(range(steps)):
        x = model.step(x, t, cond)
    return x
```

## 五、与其他技术对比
相比自回归逐样本，扩散并行性好且高频细节佳；代价是采样步数多。

## 六、常见误区
条件过弱导致内容失控。步数不足噪声残留。
