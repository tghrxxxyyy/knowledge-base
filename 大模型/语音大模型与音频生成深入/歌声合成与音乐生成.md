# 歌声合成与音乐生成

> 对应 github karpathy/llama2.c 项目与 Radford 2019 的 GPT 论文。

## 一、背景与挑战
歌声合成需同时控音高、节奏与音色，音乐生成需长程结构与和声一致。序列化建模可统一处理。

## 二、核心原理
把乐谱或 MIDI 编码为 token，自回归生成序列；歌声则用声码器条件于音高与文本，保证旋律准确。

## 三、形式化与数学基础
自回归音乐生成：
$ p(S)=\prod_t p(s_t | s_{<t}, c) $
$ c $ 为风格或和弦条件。

## 四、代码实现
```python
def music_step(lm, seq, cond):
    logits = lm(seq, cond=cond)[-1]
    return int(logits.argmax())

def sing(tts, notes, lyrics):
    out = []
    for n, w in zip(notes, lyrics):
        out.append(tts.synthesize(w, pitch=n))
    return out
```

## 五、与其他技术对比
相比采样拼接，序列生成结构更连贯；相比规则合成，模型更具表现力。

## 六、常见误区
忽视和声约束导致不协和。节奏 token 不规整致失拍。

## 八、面试题
问：为何音乐要 token 化？答：统一时序与符号，便于自回归与条件控制。

## 九、演进与趋势

## 十、小结
序列化把歌声与音乐纳入统一生成框架。
