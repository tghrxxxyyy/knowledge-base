# 音频理解与表征学习

> 对应 github huggingface/transformers 项目与 Devlin 2018 的 BERT 论文。

## 一、背景与挑战
音频任务多样（分类、事件检测、字幕），标注稀缺。自监督表征可从大量无标注音频迁移。

## 二、核心原理
用掩码声学建模：遮盖频段或时间块，让模型重建，学到可用于下游的通用音频表征。

## 三、形式化与数学基础
掩码重建目标：
$ \mathcal{L}=\sum_{m\in M}\| a_m - \hat a_m \|^2 $
$ M $ 为被掩区域。

## 四、代码实现
```python
import torch

def mask_spec(spec, p=0.3):
    mask = torch.rand(spec.shape[:2]) < p
    masked = spec.clone()
    masked[mask] = 0
    return masked, mask

def pretrain(model, spec):
    m, mask = mask_spec(spec)
    pred = model(m)
    return ((pred[mask] - spec[mask]) ** 2).mean()
```

## 五、与其他技术对比
相比监督训练，自监督利用无标注数据；相比手工特征，表征更适配下游。

## 六、常见误区
掩码过重在时域丢结构。下游微调遗忘通用特征。

## 八、面试题
问：音频自监督为何有效？答：重建任务迫使模型捕获频率与时间结构先验。

## 十、小结
自监督表征是音频任务通用的起跳板。
