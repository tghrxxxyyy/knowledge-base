# 线性可分性与表示质量

> 对应 Kumar et al., *Does Progress on MNIST Transfer?*, 2020（linear probing accuracy 作为表示质量指标）.

## 一、背景与挑战

如何用单一指标比较不同模型/训练策略的表示质量？线性可分性提供可比较的代理指标。

## 二、核心原理

在固定探针任务上，线性探针准确率越高，说明表示把相关属性分得更开（更“好”的几何结构）；常用于对比预训练方法。

## 三、数学形式

表示质量 $Q(M)=\frac1T\sum_t acc_{lin}^{(M)}(task_t)$；对比 $Q(M_A)$ 与 $Q(M_B)$ 判断优劣。

## 四、代码实现

```python
def probe_quality(model, tasks):
    return mean(linear_probe(model.layer(l), t) for t in tasks)
```

## 五、与其他对比

- 与 稀疏自编码器深入（特征单义性也是质量指标）互补。
- 与 模型评测指标深入 共享评估思想。

## 六、常见误区

- 线性可分性高 ≠ 下游任务好（仅几何代理）。
- 不同任务权重影响总指标。

## 八、面试题

- 线性可分性为何能度量表示质量？答：好表示把语义相近输入聚拢、相远分开，线性可分性直接反映该几何。

## 九、演进

单任务探针 → 多任务聚合 → 与下游相关度校准。

## 十、小结

线性可分性是易比较的表示质量代理，但需结合下游验证。
