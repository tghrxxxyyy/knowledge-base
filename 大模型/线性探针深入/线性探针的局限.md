# 线性探针的局限

> 对应 Hewitt & Liang, 2019；Voita & Titov, 2020（信息论探针）.

## 一、背景与挑战

线性探针结论常被过度解读；理解其边界才能正确使用。

## 二、核心原理

线性探针只探测线性可恢复信息，遗漏非线性编码；且“可恢复”≠“推理时使用”；容量虽小仍可能拟合标签伪结构。

## 三、数学形式

信息上界：$I(Y;H)\ge I(Y;\hat Y_{lin})$；真实使用信息 $U$ 可能 $U\not\propto acc_{lin}$。

```python
from sklearn.metrics import mutual_info_score

```

## 五、与其他对比

- 与 稀疏自编码器深入（非线性、更细粒度）互补局限。
- 与 探针可靠性批判 同主题。

## 六、常见误区

- 把线性探针当成因果/使用证据。
- 忽略 control task 校正。

## 八、面试题

- 线性探针最大局限？答：只能证明信息线性可恢复，不能证明模型使用它，且漏掉非线性编码。

## 九、演进

准确率 → 控制基线 → 信息论指标。

## 十、小结

认识线性探针的边界（可恢复≠使用、线性≠全部），方能避免误读。
