# 线性探针作为对齐探针

> 对应 Burns et al., *Discovering Latent Knowledge*, 2022；Azaria & Mitchell, *Internal State of Truth*, 2023.

## 一、背景与挑战

模型可能在内部“知道”答案真假，但生成未必反映；线性探针可从其内部状态读出真假而不依赖输出。

## 二、核心原理

在陈述句表示上训练线性探针区分真/假（或用对比方向），对新陈述预测其内隐真假判断，用于诚实性监控。

## 三、数学形式

真相方向 $v=\bar h_{true}-\bar h_{false}$；预测 $\hat y=\sigma(v^\top h+\beta)$。

## 四、代码实现

```python
v = H_true.mean(0) - H_false.mean(0)
probs = torch.sigmoid(H_test @ v + b)
```

## 五、与其他对比

- 与 激活监控深入（监控该真假方向）衔接。
- 与 探针与知识定位（同技术）呼应。

## 六、常见误区

- 探针真假 ≠ 模型会说出真话（行为受对齐影响）。
- 方向在不同分布下漂移。
