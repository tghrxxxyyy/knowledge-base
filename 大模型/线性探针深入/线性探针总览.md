# 线性探针总览

> 对应 Alain & Bengio, *Understanding intermediate layers using linear classifiers*, 2016；Hewitt & Liang, *Designing and Interpreting Probes*, 2019.

## 一、背景与挑战

最简洁地探测“某信息是否在表示中线性可恢复”，是用一个线性分类器在冻结表示上预测属性。

## 二、核心原理

冻结 LLM 某层表示 $h$，训练逻辑回归/线性层 $y=Wh+b$ 预测属性；其准确率（经控制基线）反映该信息的线性可分离程度。

## 三、数学形式

$\hat y=\sigma(Wh+b)$；损失 $\mathcal L=-\sum_i y_i\log\hat y_i+(1-y_i)\log(1-\hat y_i)$。

## 四、代码实现

```python
from sklearn.linear_model import LogisticRegression
clf = LogisticRegression(max_iter=1000).fit(H.cpu(), Y)
acc = clf.score(H.cpu(), Y)
```

## 五、与其他对比

- 是 探针分析深入 的线性特例，最常作为基线。
- 与 稀疏自编码器深入（非线性分解）对照。

## 六、常见误区

- 线性高准确率即推断“被使用”（需因果验证）。
- 不报告控制基线致结论虚高。

## 八、面试题

- 线性探针为何最常用？答：容量受限、难过拟合、便于作为“信息可恢复”的下界与控制基线。

## 九、演进

单层线性 → 分层扫描 → 与因果干预结合。

## 十、小结

线性探针以最小偏置探测表示内容，是解读 LLM 内部信息的基础工具。
