# 权重低秩分解的误差分析

> 对应 pytorch/pytorch 的 SVD 误差理论与 mlabonne/llm-course 的低秩讨论。

## 一、背景与挑战

低秩近似必然有误差，需理解误差来源以选择秩 r。误差主要来自被丢弃的较小奇异值，但某些层的小奇异值仍可能携带任务关键信息。

## 二、核心原理

截断误差等于被丢弃奇异值平方和。实践中按"能量保留率"（如保留 99% 能量）选 r，并对每层独立评估，避免统一阈值。

## 三、形式化与数学基础

相对误差：

$ \\epsilon(r)=\\frac{\\|W-W_r\\|_F^2}{\\|W\\|_F^2}=\\frac{\\sum_{i>r}\\sigma_i^2}{\\sum_i\\sigma_i^2} $

能量保留率 $ \\eta=1-\\epsilon(r) $，选最小 r 使 $ \\eta\\ge\\eta_0 $。

## 四、代码实现

```python
import torch

def choose_rank(W, eta0=0.99):
    s = torch.svd(W).S
    total = (s ** 2).sum()
    cum = torch.cumsum(s ** 2, 0) / total
    r = int((cum >= eta0).nonzero()[0]) + 1
    return r
# 逐层调用, 得到每层最优秩
```

## 五、与其他技术对比

- 与量化误差叠加时需重新评估总精度预算。
- 相比剪枝的逐元素误差，低秩误差更全局平滑。

## 六、常见误区

- 只看平均能量忽略个别重要奇异方向。
- 用训练前权重谱决策，忽略微调后变化。
