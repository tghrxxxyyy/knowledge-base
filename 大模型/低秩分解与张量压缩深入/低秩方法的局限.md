# 低秩方法的局限

> 对应 Hu 2021 LoRA 讨论与 pytorch/pytorch 低秩实践反馈。

## 一、背景与挑战

低秩假设并非总是成立：某些权重矩阵（尤其注意力 QK）谱分布平坦，需要很大 r 才能逼近，低秩压缩收益骤减。

## 二、核心原理

低秩有效的前提是权重更新/权重本身近似低秩。若奇异值衰减缓慢，保留 99% 能量需 r 接近完整秩，压缩失效。此外 LoRA 推理合并后不减小体积。

## 三、形式化与数学基础

若奇异值谱平坦：

$ \\sigma_i\\approx \\text{const}\\Rightarrow \\epsilon(r)\\approx 1-r/\\min(m,n) $

需很大 r 才能使 $ \\epsilon(r) $ 小，压缩比 $ \\frac{r(m+n)}{mn} $ 接近 1，无收益。

## 四、代码实现

```python
import torch

def spectrum_flatness(W):
    s = torch.svd(W).S
    s = s / s.sum()
    ent = -(s * (s + 1e-12).log()).sum()   # 熵高=谱平坦=难低秩
    return ent.item()
# ent 高 -> 低秩收益低
```

## 五、与其他技术对比

- 对平坦谱层，量化/剪枝可能比低秩更有效。
- LoRA 训练低秩但部署不压缩，与 SVD 压缩目的不同。

## 六、常见误区

- 对所有层统一低秩，忽略谱差异。
- 用 LoRA 期望部署体积下降（实际需合并才同大）。

## 十、小结

低秩依赖谱衰减，平坦谱层收益低；需按层选方法，必要时与量化/剪枝组合。
