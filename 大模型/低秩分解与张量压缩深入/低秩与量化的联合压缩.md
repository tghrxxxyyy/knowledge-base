# 低秩与量化的联合压缩

> 对应 Hu 2021 LoRA、Dettmers 2023 QLoRA 与 NVIDIA/TensorRT-LLM 的联合压缩。

## 一、背景与挑战

低秩减少参数量，量化减少每参位宽，二者互补。联合可在同显存预算下获得更高压缩率，QLoRA 即代表：4bit 基座 + LoRA。

## 二、核心原理

先用低秩分解减参（或冻结基座只训低秩），再把基座权重量化到 4bit。训练时梯度只流过低秩分支，反向通过量化权重用 STE 近似。

## 三、形式化与数学基础

模型 $ W\\approx Q(W_{base})+BA $，损失：

$ \\mathcal L=\\mathcal L_{task}((Q(W_{base})+BA)x,y) $

其中 $ Q $ 为量化算子，梯度 $ \\partial Q/\\partial W_{base}\\approx 1 $（STE）。

## 四、代码实现

```python
import torch

# QLoRA 思路: 4bit 基座冻结 + LoRA 训练
base_4bit = quantize_4bit(pretrained_weight)   # 见 GPTQ/AWQ
lora = LoRA(torch.zeros_like(base_4bit), r=8)   # 仅训 A,B
out = dequant(base_4bit) @ x + lora.scale * (x @ lora.A @ lora.B.t())
loss = task_loss(out, y)
loss.backward()   # 梯度只更新 A,B
```

## 五、与其他技术对比

- 单纯量化不降参；单纯低秩不降位宽；联合叠加。
- 与剪枝组合可形成三维压缩（秩/位宽/稀疏）。

## 六、常见误区

- 量化后再低秩分解原 FP 权重，与训练流程错配。
- 忽略 4bit 基座误差对 LoRA 收敛的影响。
