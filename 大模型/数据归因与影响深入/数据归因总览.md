# 数据归因总览

> 对应 influence functions（Koh & Liang, 2017）；数据归因（Data Attribution）综述。

## 一、背景与挑战

大模型行为由海量训练数据决定；需回答“哪些训练样本促成了某预测/能力”。

## 二、核心原理

数据归因把模型输出/行为反推到训练样本贡献；影响函数用二阶近似估计留一法影响。

## 三、数学形式

影响函数：$\mathcal I(x_{test}, x_{train}) \approx -\nabla_\theta \ell(x_{test})^\top H_{\theta}^{-1} \nabla_\theta \ell(x_{train})$，$H$ 为 Hessian。

## 四、代码实现

```python
# 影响近似（需 Hessian 逆）
inf = - grad_test @ H_inv @ grad_train
```

## 五、与其他对比

- 影响函数快但近似（二次型、凸假设）；重训留一法准但不可扩展。
- 与 数据治理血缘深入 / 训练数据质量 衔接（数据侧）。

## 六、常见误区

- 以为影响函数精确；深度学习非凸下仅为近似。
- 忽略 Hessian 计算成本（需近似逆）。

## 八、面试题

- 影响函数估计什么？答：某训练样本对测试损失的留一法影响近似。

## 九、演进

留一重训 → 影响函数 → 梯度相似度/TracIn → 数据归因竞赛。

## 十、小结

数据归因把模型行为溯源到数据，是调试、公平与合规的强大工具。
