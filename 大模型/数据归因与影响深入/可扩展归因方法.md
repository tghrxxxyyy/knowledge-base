# 可扩展归因方法

> 对应 TracIn（Pruthi et al., 2020）；Grad-Dot；Datamodels（Ilyas et al., 2022）。

## 一、背景与挑战

影响函数 Hessian 逆在大模型不可算；需更低成本归因。

## 二、核心原理

- TracIn：用训练过程中检查点梯度与学习率累计近似影响。
- Grad-Dot：以梯度内积近似相似度（省 Hessian）。
- Datamodels：学线性模型预测“某样本是否在训练集决定输出”。

## 三、数学形式

TracIn 影响：$\sum_{c} \eta_c \nabla \ell(z_{test},\theta_c)^\top \nabla \ell(z,\theta_c)$ 跨检查点累计。

## 四、代码实现

```python
infl = sum(eta_c * grad_test_c @ grad_z_c for c in checkpoints)
```

## 五、与其他对比

- TracIn 不需 Hessian，但需存检查点梯度。
- 与 实验管理追踪深入 共享检查点使用。

## 六、常见误区

- 检查点太少致归因噪声大。
- 梯度内积仅反映相似，非因果影响。

## 八、面试题

- TracIn 为何省计算？答：用检查点梯度累计替代 Hessian 逆。

## 九、演进

影响函数 → TracIn → Datamodels → 归因竞赛（NeurIPS Data Attribution）。

## 十、小结

可扩展归因把影响估计从不可算推向实用，支撑大模型数据审计。
