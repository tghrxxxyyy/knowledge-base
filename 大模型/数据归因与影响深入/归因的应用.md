# 数据归因的应用

> 对应数据清洗、版权溯源、错误调试；与 训练数据质量 / 数据治理血缘深入 衔接。

## 一、背景与挑战

归因结果可用于挑选高价值数据、定位错误来源、证明训练数据贡献。

## 二、核心原理

- 数据清洗：找出对错误贡献大的脏样本剔除。
- 版权溯源：证明某受版权样本对生成内容的贡献。
- 能力归因：哪些数据造就某能力（数据高效学习深入 互补）。

## 三、数学形式

按 $|\mathcal I|$ 排序训练样本，高正影响=关键支持样本，高负影响=潜在脏数据。

## 四、代码实现

```python
order = sorted(train, key=lambda z: -abs(infl(z, target)))
```

## 五、与其他对比

- 与 主动学习深入 互补（归因选重要、主动学习选信息量）。
- 与 模型版权许可深入 共享版权溯源需求。

## 六、常见误区

- 高影响≠应删除；可能恰是关键正样本。
- 归因受近似误差影响，需交叉验证。

## 八、面试题

- 如何用归因清洗数据？答：按负影响排序剔除疑似脏样本并验证精度变化。

## 九、演进

人工筛选 → 归因驱动筛选 → 自动化数据飞轮。

## 十、小结

数据归因把“数据价值”量化，驱动数据工程从经验走向数据驱动。
