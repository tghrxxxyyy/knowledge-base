# 稀疏注意力 Sparse Attention

> 见「注意力复杂度与优化」。深入。

## 一、背景与挑战

全注意力成本高，但多数 token 对间交互稀疏。稀疏注意力只计算重要位置对(局部窗口、全局 token、随机)。

## 二、核心原理

Longformer：每 token 看局部窗口 `w` 个邻居 + 少量全局 token，复杂度 `O(n·w)`。BigBird 再加随机连接，理论上可近似全注意力。

## 三、关键要点

- 全局 token 弥补局部信息缺口。
- 实现复杂、训练需特化 kernel。

## 四、与开源书对应

- Beltagy et al., *Longformer*, 2020; Zaheer et al., *BigBird*, 2020.

## 五、面试题

- 为何稀疏注意力仍需全局 token？

## 六、小结

稀疏是长序列的经典解法，但被后来的 FlashAttention+RoPE 外推部分替代。
