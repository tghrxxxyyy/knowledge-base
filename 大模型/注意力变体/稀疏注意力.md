# 稀疏注意力

> 对应 Sparse Transformer（Child et al., 2019）、Longformer（Beltagy et al., 2020）与 BigBird（Zaheer et al., 2020）。只算重要的连接，其余置零。

## 一、背景与挑战

注意力矩阵通常是稀疏的——大多数位置对之间的权重接近零，但标准注意力仍为它们付出 $O(n^2)$ 的计算与显存。稀疏注意力通过**结构化地**只计算部分连接来降本。挑战：稀疏模式若与真实依赖不匹配会掉点；不规则稀疏在 GPU 上难以高效执行；以及如何保证任意两位置间仍有信息通路。

## 二、核心原理

三类常见稀疏模式：

1. **局部窗口**（band）：每个 token 看邻近 $w$ 个。
2. **全局 token**：少量 token 对所有位置可见并可被所有位置看到，作为信息枢纽。
3. **随机连接**：每个 token 随机关注 $r$ 个位置。

BigBird 组合三者（window + global + random），并从理论上证明：该稀疏注意力是**序列函数的通用逼近器**且图灵完备，同时把复杂度降到 $O(n)$。

理论要点：信息在 $O(\log n)$ 跳内可从任意位置传到任意位置（小世界图性质）。

## 三、形式化与数学基础

稀疏掩码 $M\in\{0,1\}^{n\times n}$：

$$A_{ij} = \frac{M_{ij}\exp(q_i^\top k_j/\sqrt d)}{\sum_{j'} M_{ij'}\exp(q_i^\top k_{j'}/\sqrt d)}$$

非零连接数为 $|\{M_{ij}=1\}| = O(n(w+g+r))$，故复杂度：

$$O(n^2)\to O\big(n(w+g+r)\big)$$

其中 $w$ 窗口、$g$ 全局 token 数、$r$ 随机连接数，均为常数或远小于 $n$。

## 四、代码实现

组合稀疏掩码：

```python
import torch
def bigbird_like_mask(n, w=64, g=2, r=3):
    idx = torch.arange(n)
    band = (idx[:, None] - idx[None, :]).abs() <= w // 2
    band |= (idx[None, :] < g) | (idx[:, None] < g)      # 全局 token
    ridx = torch.randint(0, n, (n, r))                    # 随机连接
    band.scatter_(1, ridx, True)
    return band
```

实际部署应优先使用内核级支持（如块稀疏），避免先物化稠密矩阵再掩码。

## 五、与其他技术对比

| 方法 | 复杂度 | 是否需专用内核 | 掉点风险 |
|------|--------|--------------|---------|
| 全注意力 | O(n²) | 否 | 无 |
| 固定稀疏模式 | O(n) | 建议 | 中 |
| 局部窗口 | O(nw) | 建议 | 中 |
| LSH/可学习稀疏 | O(n log n) | 是 | 中 |

## 六、常见误区

- 先算稠密再掩码：只省了显存带宽，没省算力。
- 只用局部窗口就说「稀疏注意力」：缺全局/随机通路会断长程依赖。
- 随机连接每次重采样：训练与推理行为不一致。
- 忽略内核支持：不规则稀疏在 GPU 上可能比稠密更慢。

## 九、演进与趋势

块稀疏（block-sparse）更适配 GPU；与 FlashAttention 融合的变长/带状内核成为主流；可学习稀疏（路由式）在特定任务上取得更好取舍；长上下文更多转向「局部 + 全局层交替」。

## 十、小结

稀疏注意力通过「局部 + 全局 + 随机」三类连接把复杂度降到 $O(n)$，同时保留通用逼近能力。落地关键是内核支持，否则理论收益无法兑现。
