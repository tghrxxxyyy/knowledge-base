# 交叉注意力 Cross-Attention

> 见「Transformer深入/解码器结构与因果掩码」。

## 一、背景与挑战

解码器需“读懂”编码器输出以对齐源信息(翻译/多模态)。交叉注意力让解码 query 关注编码器 key/value。

## 二、核心原理

```
CrossAttn(q=解码隐态, k=v=编码器输出)
```

query 来自解码器，key/value 来自编码器，实现跨序列信息流。

## 三、关键要点

- 机器翻译中实现对齐。
- 多模态中连接视觉与语言。

## 四、面试题

- 交叉注意力与自注意力的 query 来源有何不同？

## 五、小结

交叉注意力是 encoder-decoder 与多模态融合的桥梁。
