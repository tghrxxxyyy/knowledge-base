# 滑动窗口注意力

> 对应 Longformer（Beltagy et al., 2020）与 Mistral 的 Sliding Window Attention（Jiang et al., 2023）。用局部性换复杂度。

## 一、背景与挑战

许多序列（文本、代码、语音）的依赖以局部为主，但标准注意力对所有位置两两计算，浪费严重。滑动窗口注意力让每个 token 只关注固定大小 $w$ 的邻近窗口，把复杂度从 $O(n^2)$ 降到 $O(nw)$。挑战：纯局部会切断长程依赖；窗口边界的信息流动受限；以及固定窗口无法适应不同层/头的需求。

## 二、核心原理

设窗口 $w$，token $i$ 只关注 $[i-w/2,\, i+w/2]$（或因果场景下的前 $w$ 个）：

$$A_{ij} = 0 \quad \text{if } |i-j| > w/2$$

复杂度：

$$O(n^2)\to O(nw),\qquad w\ll n$$

补救长程依赖的两种做法：

1. **全局 token**（Longformer）：选少量 token（如 `[CLS]` 或任务 token）对全部位置可见，作为信息枢纽。
2. **层间堆叠**（Mistral 的 SWA）：单层窗口是局部的，但堆叠 $L$ 层后感受野扩展到 $L\times w$，配合缓存可覆盖很长的历史。

## 三、形式化与数学基础

单层窗口下，第 $l$ 层 token $i$ 的可达范围：

$$\text{range}(i, l) = [i - l\cdot w,\ i + l\cdot w]$$

因此 $L$ 层模型的理论感受野为 $L w$（实际受注意力是否有效利用影响）。

显存：注意力矩阵从 $n\times n$ 降为 $n\times w$，KV Cache 也可只保留最近 $w$ 个：

$$M_{\text{kv}} \propto w \ \text{（而非 } n\text{）}$$

## 四、代码实现

构造带状（banded）掩码：

```python
import torch
def sliding_mask(n, w, causal=True):
    idx = torch.arange(n)
    dist = idx[:, None] - idx[None, :]
    if causal:
        return (dist >= 0) & (dist < w)      # 只看前 w 个
    return dist.abs() <= w // 2
```

生成时配合 KV 缓存只保留最近 `w` 个位置，显存不随生成长度增长。

## 五、与其他技术对比

| 方法 | 复杂度 | 长程依赖 | 实现难度 |
|------|--------|---------|---------|
| 全注意力 | O(n²) | 强 | 低 |
| 滑动窗口 | O(nw) | 弱（靠堆叠） | 低 |
| 窗口 + 全局 token | O(nw + ng) | 中 | 中 |
| 稀疏（BigBird） | O(n) | 强 | 中 |

## 六、常见误区

- 认为单层窗口就能覆盖长程：需靠层数堆叠或全局 token。
- 窗口设得过小：局部语法依赖（如主谓一致）可能被切断。
- 忽略 KV 缓存收益：窗口化的最大价值之一是显存可控。
- 对所有头用同一窗口：不同头可设不同感受野（局部+全局混合）。

## 九、演进与趋势

局部窗口 + 少量全局层成为长上下文模型的标配（如 Mistral 交替层）；窗口大小按层递增；与 FlashAttention 结合后，带状掩码也能高效执行。

## 十、小结

滑动窗口用局部性把复杂度和 KV 显存都降到 $O(nw)$，靠层间堆叠与全局 token 补回长程能力。是长上下文最实用的工程手段之一。
