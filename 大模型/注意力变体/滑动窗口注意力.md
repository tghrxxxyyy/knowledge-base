# 滑动窗口注意力 Sliding Window

> Mistral 采用的核心长上下文技巧。

## 一、背景与挑战

每个 token 只关注固定窗口 `w` 内的邻近 token，复杂度 `O(n·w)`，配合 KV Cache 滚动，可高效处理超长序列。

## 二、核心原理

Mistral 用滑动窗口 + 全局 token，使每层感受野随层数线性增长(第 `L` 层看 `L·w` 范围)，兼具效率与长程。

## 三、关键要点

- 深层天然获得更大有效上下文。
- 需配合位置编码外推。

## 四、与开源书对应

- Mistral 技术报告, 2023; Beltagy et al., *Longformer*(类似思想).

## 五、面试题

- 滑动窗口为何在深层能获得更大感受野？

## 六、小结

滑动窗口是用局部性换效率的经典方案，适合流式长文本。
