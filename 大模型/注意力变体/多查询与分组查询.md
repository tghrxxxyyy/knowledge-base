# 多查询与分组查询注意力 MQA/GQA

> 见「推理引擎TensorRT/多查询注意力优化」。

## 一、背景与挑战

MHA 每头独立 K/V，解码时 KV Cache 巨大。MQA 所有头共享一组 K/V，GQA 分组共享，大幅减小 KV Cache 与带宽。

## 二、核心原理

```
MHA: h 组 (Q_i, K_i, V_i)
MQA: h 组 Q_i，1 组 (K, V)
GQA: h 组 Q_i，g 组 (K, V), g < h
```

## 三、关键要点

- GQA 是质量/效率最佳折中，LLaMA-2/3 采用。
- 转换 MHA 权重到 GQA 可用均值切分。

## 四、与开源书对应
