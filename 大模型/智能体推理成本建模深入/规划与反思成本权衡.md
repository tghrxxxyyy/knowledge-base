# 规划与反思成本权衡

> 对应 Yao et al., *ReAct*, 2022；Shinn et al., *Reflexion*, 2023。

## 一、背景与挑战

更长的规划链、更多反思轮次能提升质量，但代价是步数 $N$ 与反思调用数线性增长。需要帕累托前沿上的权衡。

## 二、核心原理

引入“思考预算”概念：每步反思消耗一次 LLM 调用。用边际收益递减规律决定何时停止反思——当反思带来的质量提升小于其成本时即停。

## 三、数学形式

停止准则：

$$\Delta Q(\text{reflect}_k) < \frac{c_{reflect}}{\lambda}$$

即反思边际质量增益小于折算成本时停止。

## 四、代码实现

```python
while quality_gain(last_reflect) > cost_reflect / LAMBDA:
    reflect()
```

## 五、与其他对比

- 与 智能体轨迹自我进化深入 共享“何时停止探索”的决策。
- 与 智能体可靠性与失败模式深入 共担过度循环导致的成本爆炸。

## 六、常见误区

- 无限反思追求完美，成本失控。
- 完全不反思，质量不足反复重试更贵。

## 八、面试题

- 如何决定反思轮数？答：比较反思边际质量增益与其折算成本，低于阈值即停。

## 九、演进

固定轮数 → 质量阈值 → 边际成本感知停止。

## 十、小结

规划与反思需以边际成本为准绳，避免“为思考而思考”。
