# 成本预算与早停

> 对应 推理预算控制（budget forcing）与 agent 早停。

## 一、背景与挑战

没有上限的智能体可能因循环或低效规划耗尽预算。需要把“成本上限”作为一等约束。

## 二、核心原理

为任务设定 token/步数/金钱三重预算。运行时累计消耗，临近上限时强制简化策略或提前交卷。预算强制（budget forcing）也用于推理时约束思考步数。

## 三、数学形式

剩余预算约束：

$$B_{rem} = B_0 - \sum_{i\le t} c_i > 0 \implies \text{continue else stop}$$

并在截止时输出当前最佳部分解。

## 四、代码实现

```python
if spent + estimate_next() > BUDGET:
    return best_so_far()
spent += step()
```

## 五、与其他对比

- 与 规划与反思成本权衡 共用停止逻辑。
- 与 智能体可靠性与失败模式深入 防止“死循环烧钱”。

## 六、常见误区

- 预算过紧致任务频繁半途放弃。
- 估计不准，早停误判。

## 八、面试题

- 预算不足时为何交“部分解”？答：保留已得成果优于崩溃，且可人工续作。

## 九、演进

无预算 → 硬性截断 → 预算感知降级输出。

## 十、小结

成本预算把“无限探索”关进财务围栏，是生产级智能体的安全阀。
