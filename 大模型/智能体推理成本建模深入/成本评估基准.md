# 智能体成本评估基准

> 对应 Liu et al., *AgentBench*, 2023 的效率维度。

## 一、背景与挑战

不同智能体架构宣称更优，但常忽略成本。需在同基准下比较“质量/美元”而非仅质量。

## 二、核心原理

建立成本-质量二维评价：横轴为每任务成本，纵轴为完成率，越靠左上越优。报告均值与长尾分位（p95 成本），避免被平均掩盖。

## 三、数学形式

性价比指标：

$$V = \frac{\text{SuccessRate}}{C_{mean} + \alpha C_{p95}}$$

兼顾均值与长尾，防止偶发昂贵任务。

## 四、代码实现

```python
v = success_rate / (mean_cost + 0.2 * p95_cost)
```

## 五、与其他对比

- 与 错误恢复评估基准 共用基准骨架。
- 与 智能体可靠性与失败模式深入 共担长尾度量。

## 六、常见误区

- 只报成功率不报成本，误导选型。
- 忽略不同模型单价的不可比性。

## 八、面试题

- 为什么看 p95 成本而非均值？答：长尾昂贵任务决定生产预算上限，均值会掩盖风险。

## 九、演进

质量单维 → 质量/成本 → 长尾感知的性价比。

## 十、小结

成本评估让“更聪明”与“更便宜”可同时比较，驱动务实选型。
