# 检索器训练总览

> 对应 Karpukhin et al., *DPR*, 2020（开放域检索器训练）；Lee et al., *ORQA*, 2019（检索增强训练）。

## 一、背景与挑战

检索器需与下游任务（问答/生成）对齐；独立检索训练常偏离使用场景。

## 二、核心原理

检索器可用标注 (q,d) 对比训练，或在端到端系统中随生成器联合训练；目标使检索出的文档助下游成功。

## 三、数学形式

检索概率 $p(d|q;\theta)\propto\exp(E_q(q)^\top E_d(d))$；训练最大化下游相关文档概率。

## 四、代码实现

```python
scores = enc_q(q) @ enc_d(docs).T
loss = -scores.log_softmax(1)[:, gold_idx].mean()
```

## 五、与其他对比

- 与 稠密检索训练深入（训练目标）共享；与 双塔模型深入（结构）衔接。
- 与 检索器与LLM对齐 对照端到端。

## 六、常见误区

- 检索训练分布与推理分布不一致。
- 仅用静态负例缺乏难度。

## 八、面试题

- 检索器训练目标？答：拉相关文档近、无关远，使其助下游任务成功。

## 九、演进

静态训练 → 迭代训练 → 端到端联合。

## 十、小结

检索器训练以对比/端到端对齐下游，是检索质量根本。
