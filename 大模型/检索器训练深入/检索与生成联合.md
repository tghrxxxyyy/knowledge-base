# 检索与生成联合训练（RAG）

> 对应 Lewis et al., *RAG*, 2020（检索增强生成联合训练）。

## 一、背景与挑战

检索与生成分离致检索不为生成优化；RAG 把二者统一概率模型联合训练。

## 二、核心原理

RAG 用 DPR 检索器 + seq2seq 生成器，对检索文档边缘化后最大似然；检索器与生成器可同时微调。

## 三、数学形式

$p(y|x)=\sum_{z\in \mathcal Z} p_{\eta}(z|x)\,p_{\theta}(y|x,z)$；联合训 $\eta,\theta$。

## 四、代码实现

```python
docs = retriever(x, k=5)
loss = rag_loss(generator, docs, target=y)
```

## 五、与其他对比

- 与 检索器训练深入 总览（联合版）共享。
- 与 生成式检索深入（不同范式）对照。

## 六、常见误区

- 只训生成不训检索致检索僵化。
- 边缘化 topk 截断致漏关键文档。

## 八、面试题

- RAG 如何联合训练？答：对检索文档边缘化最大似然，检索器与生成器同优。

## 九、演进

固定检索+生成 → RAG 联合 → 可更新检索。

## 十、小结

RAG 联合训练使检索服务于生成，是知识增强核心范式。
