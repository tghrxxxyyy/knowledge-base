# 端到端检索训练（ORQA / REALM）

> 对应 Lee et al., *ORQA*, 2019；Guu et al., *REALM*, 2020（检索增强表征训练）。

## 一、背景与挑战

固定检索器不参与梯度，难随知识更新；端到端让检索器可被训练。

## 二、核心原理

用最大内积搜索（MIPS）取 top-k 文档近似不可导检索，以边沿/近似梯度反传；REALM 用 masked LM 目标联合训检索与阅读。

## 三、数学形式

$\mathcal L=-\log\sum_{z\in topk} p(z|q)p(a|q,z)$；对 $z$ 边缘化，梯度经 MIPS 近似。

## 四、代码实现

```python
topk = mips(q, corpus, k=8)
loss = reader_loss(topk)            # 边缘化近似
```

## 五、与其他对比

- 与 检索器与LLM对齐（RAG 联合）共享端到端。
- 与 稠密检索训练深入（静态负例）对照。

## 六、常见误区

- MIPS 近似致梯度有偏（topk 截断）。
- 检索器与阅读器学习率不匹配。

## 九、演进

## 十、小结

端到端检索训练让检索器随任务优化，但需近似梯度。
