# 迭代检索训练（RocketQA）

> 对应 Qu et al., *RocketQA*, 2021；Ren et al., *RocketQAv2/PAIR*, 2021（跨批次与去噪）。

## 一、背景与挑战

单轮检索训练负例质量有限；迭代用模型自身召回提升难负例并去噪。

## 二、核心原理

RocketQA 用跨批次负例（更大负例集）+ 去噪交叉训练（用检索器为生成器提供伪标签、再训检索器）；PAIR 联合对齐。

## 三、数学形式

交叉训练 $\mathcal L=\mathcal L_{ret}(\theta)+\lambda\mathcal L_{gen}(\theta,\phi)$；伪标签 $y^{pl}=\text{topk}(E_\theta)$。

## 四、代码实现

```python
for step:
    pl = retriever.hard_neg(model)     # 去噪伪标签
    theta = train_ret(theta, pl)
```

## 五、与其他对比

- 与 稠密检索训练深入（难负例）同思路迭代版。
- 与 检索与生成联合 共享联合训练。

## 六、常见误区

- 伪标签含错未校验致错误放大。
- 迭代过拟合难负例分布。
