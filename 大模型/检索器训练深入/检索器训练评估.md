# 检索器训练评估

> 对应 MS MARCO / BEIR / MTEB 评测；与 稠密检索评估 衔接。

## 一、背景与挑战

训练好坏须多维度验证：召回、排序、下游答案、泛化。

## 二、核心原理

离线用 Recall@k/NDCG@k 看检索；端到端用生成答案 faithfulness/准确；跨域用 BEIR 看泛化；消融看各组件贡献。

## 三、数学形式

综合 $\text{Score}=\alpha\cdot NDCG+\beta\cdot AnswerAcc+\gamma\cdot BEIR$。

## 四、代码实现

```python
for ds in [marco, beir, mteb]:
    report(ds, evaluate(retriever, ds))
```

## 五、与其他对比

- 与 嵌入模型评估（MTEB）共享基准。
- 与 检索重排序深入（评估指标）衔接。

## 六、常见误区

- 只看检索指标忽略端到端答案。
- 训练/测试分布重叠致虚高。

## 七、与开源书对应

## 八、面试题

- 检索器如何评估？答：检索指标+端到端答案+跨域泛化三位一体。

## 九、演进

单指标 → 端到端 → 自动化评测。

## 十、小结

检索器训练评估须召回、下游、泛化并重，避免单指标虚高。
