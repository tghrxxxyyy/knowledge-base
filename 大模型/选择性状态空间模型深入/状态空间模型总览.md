# 状态空间模型总览

> 对应 Gu et al., *Efficiently Modeling Long Sequences with Structured State Spaces (S4)*, NeurIPS 2021。

## 一、背景与挑战

序列建模需线性时间且能捕长程依赖；RNN 难并行、注意力 $O(n^2)$，SSM 以连续系统线性递推提供新路线。

## 二、核心原理

SSM 把输入 $u(t)$ 经状态 $x(t)\in\mathbb R^N$ 线性映射到输出 $y(t)$，离散化后在序列上扫描，复杂度近线性。

## 三、数学形式

连续形式 $\dot x(t)=A x(t)+B u(t),\ y(t)=C x(t)$；离散化后 $x_k=\bar A x_{k-1}+\bar B u_k$。

## 四、代码实现

```python
x = A @ x + B * u  # 单步线性递推
y = C @ x
```

## 五、与其他对比

- 与 稀疏注意力算法深入 都解决长序列，SSM 走线性递推而非稀疏。
- 与 状态空间对偶与Mamba2深入 是同一族的前后演进。

## 六、常见误区

- 把 SSM 当成普通 RNN；其 $A,B,C$ 常结构化（对角+低秩）以可高效卷积。
- 忽略离散化步长 $\Delta$ 对建模时间尺度的影响。

## 八、面试题

- SSM 为何能线性复杂度？答：状态以固定维 $N$ 递推，每步 $O(N^2)$，总 $O(nN)$ 近线性。

## 九、演进

连续 LTI 系统 → S4 结构化 → 选择性 SSM（Mamba）→ SSD（Mamba2）。

## 十、小结

SSM 以线性状态递推建模序列，是注意力的近线性时间替代。
