# 连续时间状态空间模型

> 对应 Gu et al., S4, 2021；理论基础源自线性时不变系统控制理论。

## 一、背景与挑战

离散序列可视为连续信号采样；用连续系统描述可在任意分辨率处理，且具良好长程性质。

## 二、核心原理

用线性时不变（LTI）微分方程建模；参数 $A,B,C$ 不随步变化，离散化后等价于因果卷积。

## 三、数学形式

$\dot x=Ax+Bu,\ y=Cx$；$A\in\mathbb R^{N\times N}$ 常取对角（HiPPO）以稳定长程记忆。

## 四、代码实现

```python
def ssm_step(x, u, A, B, C):
    x = A @ x + B * u
    return C @ x, x
```

## 五、与其他对比

- LTI 使 SSM 等价于卷积，可训练期卷积、推理期递归。
- 与 选择性状态空间模型深入 中“选择性”相对：LTI 无输入依赖。

## 六、常见误区

- 以为 SSM 一定快于注意力；短序列下常数因子可能反超。
- 忽视 $A$ 的结构化假设是效率关键。

## 八、面试题

- 为何 SSM 可用卷积实现？答：LTI 系统对任意输入响应由冲激响应决定，等价于因果卷积。

## 九、演进

一般 LTI → HiPPO 结构化 A → S4 可高效计算。

## 十、小结

连续时间 LTI-SSM 把序列建模转为可卷积的线性系统，奠定效率基础。
