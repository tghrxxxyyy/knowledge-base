# 选择性机制

> 对应 Gu & Dao, *Mamba: Linear-Time Sequence Modeling with Selective State Spaces*, 2023。

## 一、背景与挑战

S4 是 LTI（参数不随输入变），无法做内容相关的推理（如复制、关联回忆）；需让 SSM 对输入选择性。

## 二、核心原理

让 $\Delta,B,C$ 由输入计算得到（输入依赖），使模型按内容决定“记住/忘记”什么，牺牲纯卷积等价换表达力。

## 三、数学形式

$\Delta,B,C = \text{Linear}(u)$；离散化步长 $\Delta=\text{softplus}(uW_\Delta)$，使不同 token 时间尺度不同。

## 四、代码实现

```python
dt = F.softplus(u @ Wdt)        # 输入依赖步长
Abar = (dt[:, :, None] * A).exp()
```

## 五、与其他对比

- 与 S4 的 LTI 相对：选择性 SSM 是 LTV（时变），失去卷积等价但获内容感知。
- 与 专家混合路由策略深入 不同：选择性是连续门控而非离散专家选择。

## 六、常见误区

- 认为 Mamba 仍可简单卷积训练；选择性使其必须串行扫描。
- 忽略 $\Delta$ 的 softplus 约束，导致数值不稳。

## 八、面试题

- Mamba 选择性解决了什么？答：让 SSM 参数依赖输入，获得内容感知的回忆与推理能力。

## 九、演进

LTI-S4 → 输入依赖 $\Delta,B,C$ → Mamba 选择性 SSM。

## 十、小结

选择性机制把 SSM 从固定系统升级为内容感知，是 Mamba 的核心创新。
