# 稀疏自编码器（SAE）总览

> 对应 Cunningham et al., *Sparse Autoencoders Find Highly Interpretable Features*, 2023；Bricken et al., *Towards Monosemanticity*, 2023.

## 一、背景与挑战

叠加假设下，单个神经元编码多义特征，难以解释；SAE 把稠密残差流分解为大量稀疏、单义的可解释特征。

## 二、核心原理

在残差流激活上训练自编码器，瓶颈维度远大于输入（过完备），用稀疏惩罚迫使每输入仅少数特征激活，得到 monosemantic features。

## 三、数学形式

重构 $x\approx \sum_i f_i(x)\,d_i$；$L=\|x-\hat x\|^2+\lambda\sum_i |f_i(x)|$（或 TopK 稀疏）。

## 四、代码实现

```python
sae = SparseAutoencoder(d_in=1024, d_hidden=16384)
loss = ((x - sae(x))**2).mean() + sae.l1()
```

## 五、与其他对比

- 与 线性探针深入（读已有表示）不同：SAE 重构并分解表示。
- 与 回路分析深入（特征为单元重述回路）互补。

## 六、常见误区

- 以为 SAE 特征就是“真”特征（仍是近似分解）。
- 稀疏度设错致特征退化或冗余。

## 八、面试题

- 为何 SAE 能得单义特征？答：过完备+稀疏迫使每个特征对应少量可分离概念，降低多义叠加。

## 九、演进

PCA → 字典学习 → SAE → TopK SAE。

## 十、小结

SAE 是目前最具前景的“拆解”叠加表示、获得单义特征的方法。
