# 分词器训练实践与评估

> 对应 Kudo & Richardson, *SentencePiece*, 2018；Penedo et al., *FineWeb*, 2024（分词效率指标）。

## 一、背景与挑战

如何判断分词器好坏？需压缩率与公平性指标。

## 二、核心原理

用“每词/每字符平均 token 数”“压缩率”“跨语料归一化序列长度”评估；多语看低资源语言是否被过度切分。

## 三、数学形式

压缩率 $c=\frac{\text{bytes}}{\text{tokens}}$；越低表示编码越经济（但需同语料比较）。

## 四、代码实现

```python
toks = tok.encode(text)
print(len(toks) / len(text.encode("utf-8")), "tok/byte")
```

## 五、与其他对比

- 与 多语种分词与挑战深入（公平性评估）直接重叠。
- 与 数据质量过滤与困惑度过滤深入（训练集质量）相关。

## 六、常见误区

- 只用英文压缩率评判多语分词器。
- 词表含大量未出现子词（训练语料不足）。

## 八、面试题

- 怎么评分词器？答：看压缩率与跨语言公平性，而非单一语料。

## 九、演进

主观 → 压缩率 → 公平性与下游耦合。

## 十、小结

分词器评估以压缩率与公平性为准，需跨语料。
