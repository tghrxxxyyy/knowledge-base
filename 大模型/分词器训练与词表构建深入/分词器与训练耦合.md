# 分词器与训练耦合

> 对应 Llama 系列实践；Rae et al., *Gopher/MassiveText*, 2021（分词影响评估）；Touvron et al., 2023。

## 一、背景与挑战

分词器与模型权重强耦合：换分词器需重训 embedding/proj，且影响已有评测可比性。

## 二、核心原理

embedding 与 LM head 的行数等于词表大小；分词分布决定位置编码长度与注意力成本。训练后改分词器成本高。

## 三、数学形式

重构代价 $\approx 2|V|d$ 参数重初始化 + 全量重训；评测序列长度变化使指标不可比。

## 四、代码实现

```python
# 分词器必须固定后再训练
tok = load_tokenizer("spm.model")
model.resize_token_embeddings(len(tok))
```

## 五、与其他对比

- 与 多语种分词与挑战深入（多语需一致分词）强相关。
- 与 合成数据陷阱与评估深入（评测可比性）相关。

## 六、常见误区

- 中途换分词器不重训 head 致维度错。
- 对比实验用不同分词器致结论失真。

## 八、面试题

- 为何分词器要尽早定？答：与 embedding/LM head 耦合，后期更换需重训且破坏可比性。

## 九、演进

后训分词 → 早期联合 → 分词感知缩放律。

## 十、小结

分词器与模型紧耦合，是训练前必须锁定的设计。
