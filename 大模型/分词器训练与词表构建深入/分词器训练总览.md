# 分词器训练总览

> 对应 Sennrich et al., *BPE*, 2016；Kudo & Richardson, *SentencePiece*, 2018；Touvron et al., *LLaMA*, 2023（SentencePiece BPE）。

## 一、背景与挑战

文本需离散为 token 才能进模型；分词策略影响序列长度、信息密度与跨语言公平。

## 二、核心原理

分词器在语料上统计学习合并规则（BPE/Unigram/WordPiece），形成词表与编码表；训练目标是最小化压缩后的总 token 数或最大化似然。

## 三、数学形式

BPE 贪心合并频率最高相邻对 $(a,b)$ 为 $ab$；目标 $\min\sum_x |\text{enc}(x)|$ 在词表大小约束 $|V|\le K$ 下。

## 四、代码实现

```python
from sentencepiece import SentencePieceTrainer
SentencePieceTrainer.train(input="corpus.txt", vocab_size=32000,
                            model_type="bpe")
```

## 五、与其他对比

- 与 多语种分词与挑战深入（多语训练需平衡）衔接。
- 与 数据质量过滤与困惑度过滤深入（过滤影响训练语料分布）相关。

## 六、常见误区

- 复用他人分词器而语料分布不同，致压缩率低。
- 忽略特殊 token（<pad>, <unk>）预留。

## 八、面试题

- 为何要自训分词器？答：匹配语料分布可降序列长度、提训练效率。

## 九、演进

Word2vec 词表 → BPE → SentencePiece 多模态。

## 十、小结

分词器是模型入口，需在目标语料上训练以平衡长度与覆盖。
