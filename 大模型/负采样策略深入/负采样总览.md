# 负采样策略总览

> 对应 Mikolov et al., 《word2vec》, 2013 的 Negative Sampling；以及 Gutmann & Hyvärinen, NCE, 2010。

## 一、背景与挑战

softmax 在全词表/全实体上归一代价高；需以少量负样本近似归一化。

## 二、核心原理

对正样本配 k 个随机（或加权）负样本，用二分类区分正负，避免全量归一；NCE 则理论近似噪声分布。

## 三、数学形式

NEG 损失 $\log\sigma(v_c\cdot v_o)+\sum_{i=1}^k \mathbb E_{n_i\sim P_n}[\log\sigma(-v_c\cdot v_{n_i})]$。

## 四、代码实现

```python
pos = score(anchor, pos_item)
neg = score(anchor, sample_negatives(k))
loss = -logsigmoid(pos) - logsigmoid(-neg).sum()
```

## 五、与其他对比

- 与 度量学习深入（对比损失用负样本）共享范式。
- 与 难负样本挖掘深入（负样本选择）衔接。

## 六、常见误区

- 负样本数 k 过小近似差，过大成本高。
- 均匀采样忽略低频重要性。

## 八、面试题

- 负采样为何高效？答：用少量负样本近似归一化，将 softmax 化简二分类，降复杂度。

## 九、演进

全 softmax → NCE → NEG → 难负采样。

## 十、小结

负采样以少量样本近似归一化，是表示学习的高效训练基石。
