# 负采样偏差与评估

> 对应 采样偏差研究（Krichene & Rendle, 2020, 《On the Difficulty of Evaluating...》）。

## 一、背景与挑战

负采样方式影响训练，也污染离线评测（测试负样本若太易，指标虚高）。

## 二、核心原理

评测时应用同分布或全库排序而非抽样负；训练偏差需在测试时匹配，否则指标不可比。

## 三、数学形式

排序质量 $rank = 1 + |\{j: \hat r_{uj} > \hat r_{ui}\}|$；抽样测试使 rank 失真。

## 四、代码实现

```python
full_scores = model(user, all_items)          # 全库而非抽样
rank = (full_scores > full_scores[pos]).sum() + 1
```

## 五、与其他对比

- 与 难负样本挖掘深入（训练/测试偏差一致）衔接。
- 与 模型评测指标深入（指标可信）共享。

## 六、常见误区

- 训练用难负、测试用随机负致错配。
- 抽样测试低估真实 rank。

## 八、面试题

- 评测负采样为何要全库？答：抽样负太易使指标虚高，全库排序才反映真实性能。

## 九、演进

抽样测试 → 全库排序 → 偏差校正评测。

## 十、小结

负采样偏差同时存在于训练与评测，评测须全库保可比。
