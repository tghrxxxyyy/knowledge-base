# 难负样本挖掘（Hard Negative Mining）

> 对应 Schroff et al., 《FaceNet》三元组难例, 2015；以及 He et al., MoCo, 2019。

## 一、背景与挑战

随机负样本太易，模型无梯度信号；需选与正样本相近的难负样本促学习。

## 二、核心原理

每批内选距离正样本最近（或得分最高）的负样本作难负；MoCo 用动量队列扩大负样本库。

## 三、数学形式

难负集合 $N_{hard} = \{n: d(a,n) < d(a,p)+\alpha\}$，即比正样本还近的负例。

## 四、代码实现

```python
dists = pairwise_dist(anchor, candidates)
hard = candidates[argmin(dists)]          # 选最近负例
```

## 五、与其他对比

- 与 度量学习深入（三元组/对比损失）共享难例思想。
- 与 负采样偏差纠正深入（难负也引入偏）衔接。

## 六、常见误区

- 过难负样本可能是标注错误或噪声。
- 全部用难负致训练震荡。

## 八、面试题

- 为何要难负样本？答：随机负太易无梯度，难负提供强信号促表征区分。

## 九、演进

随机负 → 批内难负 → 队列/记忆库扩负。

## 十、小结

难负样本提供强监督信号，但须防误标与训练不稳。
