# 噪声对比估计（NCE）

> 对应 Gutmann & Hyvärinen, 《Noise-contrastive estimation》, 2010。

## 一、背景与挑战

概率密度估计难；NCE 把密度估计转为二分类：区分数据样本与噪声样本。

## 二、核心原理

用噪声分布 $P_n$ 生成负样本，学习对数密度比 $\log p/p_n$；当噪声样本足够多，估计趋近真实密度。

## 三、数学形式

$\mathcal L_{NCE} = -\mathbb E_{x\sim p}[\log \frac{p_\theta(x)}{p_\theta(x)+k p_n(x)}] - k\mathbb E_{x\sim p_n}[\log\frac{k p_n(x)}{p_\theta(x)+k p_n(x)}]$。

## 四、代码实现

```python
pos_term = logsigmoid(logp - logp_n)            # 数据为正
neg_term = logsigmoid(logp_n - logp)            # 噪声为负
```

## 五、与其他对比

- 与 NEG（NCE 的简化版，k=1 时等价）对照。
- 与 InfoNCE深入（对比学习中的 NCE）衔接。

## 六、常见误区

- 噪声分布选错致估计偏。
- 忽略 $k$ 比例使分类过易。

## 八、面试题

- NCE 与 NEG 区别？答：NCE 基于噪声分布理论估计密度比，NEG 是其实用简化（常数偏置）。

## 九、演进

密度估计 → NCE → NEG/InfoNCE 应用化。

## 十、小结

NCE 以分类代密度估计，是负采样与对比学习的理论根基。
