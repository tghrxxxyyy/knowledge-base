# 知识图谱与推荐负采样

> 对应 Wang et al., 《RippleNet》, 2018；以及 Rendle et al., BPR, 2009。

## 一、背景与挑战

推荐/图谱只有正反馈（点击/边），需构造负样本训练排序；构造方式显著影响效果。

## 二、核心原理

随机负采样（从未交互项抽）；流行度偏置采样；或基于图邻居的硬负；BPR 用成对（正>负）损失。

## 三、数学形式

BPR 损失 $\mathcal L = -\sum_{(u,i,j)} \log\sigma(\hat r_{ui} - \hat r_{uj})$，$i$ 正、$j$ 负。

## 四、代码实现

```python
pos = score(user, item_i)
neg = score(user, sample_negative(user))
loss = -logsigmoid(pos - neg)
```

## 五、与其他对比

- 与 难负样本挖掘深入（图谱硬负）共享。
- 与 负采样偏差纠正深入（流行度偏）衔接。

## 六、常见误区

- 均匀负采样引入流行度偏。
- 把未见项全当真负（可能未来交互）。

## 八、面试题

- 推荐负采样难点？答：只有正反馈，负样本是假设，构造方式（随机/流行度/硬负）影响偏置。

## 九、演进

随机负 → 流行度采样 → 硬负/图感知负。

## 十、小结

图谱与推荐的负采样需谨慎构造，偏置控制决定排序质量。
