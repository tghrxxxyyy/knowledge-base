# 表示空间几何

> 对应 Ethayarajh 2019（上下文向量各向异性）与 Mikolov 2013 分布式假设。

## 一、背景与挑战

「为什么向量能编码语义」是表示学习的理论核心。分布式假设给出直觉：出现在相似上下文的词，语义相近、向量相近。但向量空间并非理想球面——实际训练出的表示常呈现各向异性（anisotropy）：向量在方向上分布不均，多数点挤在某个狭窄锥形里，且高频词向量范数偏大、低频词偏小。这会削弱余弦相似度的区分度，直接影响检索、聚类与类比任务的可靠性。

挑战在于：如何用几何语言刻画这种现象？它从何而来（训练目标、词频偏斜、层归一化）？以及如何矫正（归一化、白化、对比损失）以提升下游效果。

## 二、核心原理

表示空间的几个关键几何性质：

- **各向异性**：向量非均匀覆盖单位球面，而是偏向少数主方向。后果是即使语义无关的句子，其向量也可能因「都落在同一锥区」而余弦相似度虚高。
- **词频-范数相关**：在词嵌入中，高频词（如「的」「the」）向量范数常更大，污染相似度计算。
- **各向同性理想态**：理想情况下向量在单位球面均匀分布（各向同性），余弦相似度才有判别力。

缓解这个现象的常见手段：对句向量做 L2 归一化（消除范数偏斜）、用主成分白化（去除主方向冗余，如 BERT-flow / whitening）、以及用对比损失把语义相近点拉到邻近、相远点推远（见「对比学习表示」）。

进一步看，层归一化（LayerNorm/RMSNorm）本身也会影响几何：它把向量压到固定范数附近，缓解范数偏斜但可能强化方向偏斜。BERT 各层表示呈现「各向异性随层加深而加剧」的现象（Ethayarajh 2019），底层更各向同性、顶层更聚集。因此白化等后处理常在最后一层表示上做，且需保留适当维度以免抹掉任务相关结构。

## 三、形式化与数学基础

各向异性可用平均余弦相似度或主成分能量占比刻画。设句向量集合 $\{\mathbf{u}_i\}$，其均值 $\boldsymbol{\mu}$，协方差 $\Sigma = \frac{1}{N}\sum_i (\mathbf{u}_i-\boldsymbol{\mu})(\mathbf{u}_i-\boldsymbol{\mu})^\top$。各向同性要求 $\Sigma \propto I$；实际中 $\Sigma$ 的特征值长尾分布，最大特征值占比高即各向异性强。

白化变换将协方差化为单位阵：

$$ \tilde{\mathbf{u}}_i = W (\mathbf{u}_i - \boldsymbol{\mu}),\quad W = \Lambda^{-1/2} U^\top $$

其中 $U\Lambda U^\top = \Sigma$ 为特征值分解。白化后向量各方向能量均匀，余弦相似度更可信。归一化则简单令 $\hat{\mathbf{u}} = \mathbf{u}/\|\mathbf{u}\|$，把点压到单位球面。

## 四、代码实现

```python
import numpy as np
from sklearn.decomposition import PCA

def whitening_transform(vecs):
    # vecs: [N, d] 句向量
    mu = vecs.mean(axis=0)
    centered = vecs - mu
    # PCA 白化：去相关 + 单位方差
    pca = PCA(n_components=vecs.shape[1])
    pca.fit(centered)
    W = np.diag(1.0 / np.sqrt(pca.explained_variance_ + 1e-8))
    basis = pca.components_.T
    white = (centered @ basis) @ W        # [N, d] 白化后向量
    return mu, basis, W, white

def l2_normalize(vecs):
    norms = np.linalg.norm(vecs, axis=-1, keepdims=True)
    return vecs / np.clip(norms, 1e-8, None)
```

## 五、与其他技术对比

| 方法 | 作用 | 是否丢信息 | 适用 |
|------|------|------------|------|
| L2 归一化 | 消除范数偏斜 | 丢范数 | 检索快速 |
| PCA 白化 | 去相关、各向同性 | 可降维 | 句向量精修 |
| 对比损失训练 | 直接学可判别空间 | 否 | 端到端 |
| 不做处理 | — | 否 | 仅粗略 |

## 六、常见误区

误区一：余弦相似度永远可靠——各向异性下余弦虚高，需先归一化或白化。误区二：向量范数无意义——词嵌入中范数常携词频信息，直接比较会偏。误区三：白化万能——过度白化会抹掉任务相关结构，需保留适当维度。误区四：几何性质只影响检索——聚类、类比、探针（probe）任务同样敏感。

## 八、面试题

1. 为何表示空间常各向异性？训练目标与词频偏斜使向量偏向少数主方向，未均匀覆盖球面。
2. 各向异性对检索有何害？语义无关句因同处锥区而余弦虚高，召回被噪声淹没。
3. 白化与归一化区别？归一化只压到球面、保留方向偏斜；白化还去相关、均化各方向能量。
4. 如何用主成分判断各向异性？看协方差最大特征值占比，占比高即各向异性强。

近年工作把几何分析用于解释「大模型为何某些任务退化」：表示各向异性与任务难度相关，白化/各向同性正则可缓解。指令微调会改变表示几何（不同指令把同一输入映射到不同子空间），催生「按指令对齐表示」的研究。探针（probe）任务则把几何性质与语言属性定量关联。

## 九、演进与趋势

从「发现各向异性现象」（Ethayarajh 2019），到 BERT-flow、 whitening 等后处理矫正，再到把几何性质直接纳入训练目标（对比损失、各向同性正则）。趋势是用流式白化与在线均值/协方差估计，适配大模型动态表示；并把几何分析与检索、指令微调效果定量挂钩。

工程上，句向量入库前先做 L2 归一化，消除词频带来的范数偏斜。
若检索召回被噪声淹没，尝试 PCA 白化（保留 0.9+ 方差）改善各向同性。
监控表示各向异性指标（如最大主成分能量占比），异常上升预示分布漂移。
对比损失训练本身把空间推向更判别，但需配合温度与难负例调好。
探针（probe）任务可量化几何性质与语言属性的关联，辅助诊断。
BERT 各层各向异性随层加深加剧，后处理多在最后一层做。
各向同性正则（如白化损失）可直接写进训练目标，无需后处理。
余弦相似度在各向异性下虚高，需先归一化或白化再比较。
表示空间的「语义轴」可分解、可干预，是对比可解释研究的方向。
词频-范数相关使高频词（停用词）污染相似度，归一化可缓解。
句向量聚类前务必白化，否则簇会被主方向牵引而失真。
检索重排阶段用表示几何做过滤，可降误召回。
分布假设（相似上下文→相似向量）是几何性质的根源。
监控训练/推理表示分布差异，防止推理期表示偏移。

## 十、小结

表示空间的几何性质（各向异性、范数偏斜）决定了余弦相似度的可信度。理解其来源与矫正（归一化、白化、对比训练），是把「向量」真正用于检索、聚类与类比的前提。几何视角是连接「词嵌入 / 句向量」与下游效果的关键理论桥梁。
