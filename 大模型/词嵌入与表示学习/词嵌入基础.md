# 词嵌入基础

> 对应 Mikolov 2013 Word2Vec 与 Pennington 2014 GloVe（d2l-zh「词嵌入」）。

## 一、背景与挑战

独热编码（one-hot）把每个词表示为一个超长、稀疏、几乎全零的向量，维度等于词表大小，且任意两词向量正交——完全丢失「语义相近」信息，也无法支撑下游相似度计算。词嵌入的目标是把词映射为低维、稠密、可计算的连续向量，使「语义相近的词向量相近、可四则运算」。

挑战在于：如何用无标注语料高效学到这种分布式表示？如何兼顾全局统计（词共现频率）与局部上下文（邻居词预测）？以及如何处理未登录词（OOV）与一词多义。

## 二、核心原理

三条经典路线：

- **Word2Vec**（Mikolov 2013）：含两种架构。Skip-gram 用中心词预测上下文词；CBOW 用上下文词平均预测中心词。通过负采样（negative sampling）或层序 softmax 把 softmax 计算从 $O(|V|)$ 降到 $O(K)$。学到的向量满足「国王 - 男人 + 女人 ≈ 女王」这类类比关系。
- **GloVe**（Pennington 2014）：基于全局词共现矩阵，用加权最小二乘直接拟合共现对数的对数概率差，显式建模全局统计。
- **FastText**（Bojanowski 2017）：把词表示为字符 n-gram 子向量的和，天然处理未登录词与形态变化（如复数、词缀）。

分布式假设是共同基础：出现在相似上下文的词，语义相近，表示也相近。

需要注意的是，三类模型学到的向量空间彼此不可直接比较：Word2Vec 与 GloVe 的向量不在同一坐标系，混用会出错。类比关系（king - man + woman ≈ queen）只在语义规则性强的关系上成立，隐喻、领域术语易失效。现代用法中，静态嵌入更多作为轻量检索、冷启动与可解释分析的基础，深层语义交由上下文模型承担。

## 三、形式化与数学基础

Skip-gram 负采样目标（对每个中心词 $o$、上下文词 $c$）：

$$ \max \sum \left( \log \sigma(\mathbf{v}_c^\top \mathbf{v}_o) + \sum_{k \sim P_n} \log \sigma(-\mathbf{v}_k^\top \mathbf{v}_o) \right) $$

其中 $\sigma$ 为 sigmoid，$P_n$ 为负样本分布（通常取词频的 $3/4$ 次方）。GloVe 拟合：

$$ \mathbf{w}_i^\top \tilde{\mathbf{w}}_j + b_i + \tilde{b}_j = \log X_{ij} $$

对共现计数 $X_{ij}$ 做加权回归，权重随共现次数递增再饱和，避免高频对主导。

## 四、代码实现

```python
import torch
import torch.nn as nn

class SkipGramNeg(nn.Module):
    def __init__(self, vocab, dim):
        super().__init__()
        self.in_emb = nn.Embedding(vocab, dim)   # 中心词
        self.out_emb = nn.Embedding(vocab, dim)  # 上下文词

    def forward(self, center, context, neg):
        # center/context/neg: [B] / [B] / [B, K]
        v = self.in_emb(center)                  # [B, dim]
        u = self.out_emb(context)                # [B, dim]
        pos = torch.sigmoid((v * u).sum(-1))     # [B]
        neg_v = self.out_emb(neg)                # [B, K, dim]
        neg_score = torch.sigmoid((v.unsqueeze(1) * neg_v).sum(-1))
        return -torch.log(pos).mean() - torch.log(1 - neg_score).mean()
```

## 五、与其他技术对比

| 模型 | 特点 | 未登录词 | 统计利用 |
|------|------|----------|----------|
| Word2Vec | 快、局部上下文、经典 | 不支持 | 局部 |
| GloVe | 全局共现矩阵分解 | 不支持 | 全局 |
| FastText | 子词 n-gram、表示可加 | 支持 | 局部+子词 |
| 上下文嵌入（ELMo/BERT） | 一词多义、动态 | 支持 | 深层 |

## 六、常见误区

误区一：不同模型向量空间可直接比较——Word2Vec 与 GloVe 的向量不在同一空间，不可混用。误区二：静态嵌入能处理一词多义——不能，同一词只有固定向量（见「上下文表示 ELMo」）。误区三：维度越大越好——过大易过拟合且稀疏信号不足，常取 100–300。误区四：类比运算万能——只在语义规则性强的关系上成立，隐喻、领域术语易失效。

## 八、面试题

1. 为何静态词嵌入难处理一词多义？每个词只有固定向量，无法随上下文变化；需上下文表示（ELMo/BERT）解决。
2. Skip-gram 与 CBOW 区别？前者用中心词预测上下文、后者反之；Skip-gram 在小语料上对低频词更友好。
3. 负采样为何有效？把多分类转为二分类，把 $O(|V|)$ 降到 $O(K)$，聚焦区分真假上下文。
4. GloVe 与 Word2Vec 本质差异？GloVe 基于全局共现矩阵的最小二乘，Word2Vec 基于局部预测。

FastText 的子词思想延续到现代 tokenizer（BPE/SentencePiece），「子词嵌入」实质是词嵌入的泛化。检索增强生成（RAG）的文档块仍常以词/子词统计做轻量召回初筛。可解释性研究中，词向量的几何方向常被解释为语义轴（性别、时态等）。总体上，词嵌入是通往上下文与多模态表示的基石。

## 九、演进与趋势

从静态词嵌入到上下文表示（ELMo、BERT、LLM），「词嵌入」概念被「子词/ token 嵌入 + 深层上下文编码」取代。但静态嵌入在轻量检索、冷启动、可解释性上仍有价值。趋势是把词级嵌入与检索增强、对比学习结合，并融入多语言、多模态统一空间。

选用上：通用语义用 Word2Vec/GloVe 快且够用；需未登录词/形态用 FastText；深层语义交上下文模型。
静态向量空间不可跨模型混用，迁移或拼接需重新对齐（如 Procrustes 正交映射）。
类比运算只用于强规则关系（king-man+woman≈queen），隐喻与领域术语易失效。
RAG 初筛、冷启动、可解释分析是静态嵌入仍常用的场景。
教学上 d2l-zh 的「词嵌入」章节适合入门其数学与实现细节。
FastText 子词思想延续到现代 BPE/SentencePiece tokenizer，是词嵌入的泛化。
共现矩阵分解（GloVe）显式利用全局统计，与 Word2Vec 局部预测互补。
负采样把多分类化简为二分类，把 O(|V|) 降到 O(K)，重心选对难负例。
未登录词处理：FastText 用子词拼接，Word2Vec/GloVe 则需 fallback 或扩展词表。
维度选择常取 100–300，过大易过拟合且稀疏信号不足。
词向量几何方向常被解释为社会/语义轴（性别、时态），用于可解释分析。
下游任务可用词向量初始化 embedding 层，比随机初始化收敛更快。
多语言词向量可用对齐矩阵映射到共享空间，支撑跨语检索。
评估用词相似度基准（Wordsim）与类比任务，而非只看 loss。

## 十、小结

词嵌入把离散词映射为低维稠密向量，是自然语言分布式表示的起点。Word2Vec 抓局部上下文、GloVe 抓全局共现、FastText 用子词解决未登录词。理解其假设边界（无上下文、空间不可跨模型比），是进一步学习上下文与对比表示的基础。
