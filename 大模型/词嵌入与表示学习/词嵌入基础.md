# 词嵌入基础

> 对应 d2l-zh「词嵌入」与 Word2Vec。

## 一、背景与挑战

独热编码稀疏高维。词嵌入把词映射为低维稠密向量，语义相近词向量相近。

## 二、核心原理

Word2Vec：Skip-gram 预测上下文、CBOW 反之。GloVe：基于共现矩阵分解。FastText：用子词字符 n-gram 表示，处理未登录词。

## 三、数学形式

Skip-gram 目标(负采样)：

```
max Σ log σ(v_c·v_o) + Σ_{k~neg} log σ(-v_k·v_o)
```

## 四、关键要点

| 模型 | 特点 |
|------|------|
| Word2Vec | 快、经典 |
| GloVe | 全局共现 |
| FastText | 子词、未登录词 |

## 五、常见误区

- 静态嵌入不含上下文(一词多义难题)。
- 不同模型向量空间不可比。

## 八、演进

静态→上下文(ELMo/BERT)→任务适配(SBERT)。

## 九、小结

词嵌入是自然语言分布式表示的起点。
