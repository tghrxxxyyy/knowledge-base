# 模型出处与水印

> 见「模型版权深入/模型版权总览」与「模型水印与溯源」；证明来源与生成。

## 一、背景与挑战

如何证明模型/内容来自某来源、某次生成？

## 二、核心原理

- **模型出处（provenance）**：记录训练数据/版本/配方，形成可验证 lineage（见数据治理血缘）。
- **生成水印**：在输出嵌入可检测标记（见模型水印章），标识 AI 生成，辅助版权与溯源。
二者支撑问责与合规。

## 三、关键要点

- lineage 防「模型洗白」。
- 水印需鲁棒可检测。

## 四、代码实现

```python
lineage = record(model, data_version, recipe)
```

## 五、与其他对比

- 出处证模型；水印证内容。

## 六、常见误区

- 无记录可溯源——不可。
