# 物理仿真与神经算子

> 对应 github pytorch/pytorch 项目与 Vaswani 2017 的 Transformer 论文。

## 一、背景与挑战
传统数值求解偏微分方程代价高昂。神经算子旨在学习从边界条件到解的映射，提供可微、可并行的近似仿真器，加速科学计算。

## 二、核心原理
把网格或点云状态编码为 token，用注意力或图卷积在状态间传递信息，迭代更新逼近 PDE 解。训练目标是预测下一时刻或稳态场。

## 三、形式化与数学基础
神经算子近似：
$ u_{t+1} = \mathcal{G}_\theta(u_t, \nabla u_t) $
其中 $ \mathcal{G}_\theta $ 为可学习算子，$ \nabla u_t $ 为空间导数特征。

## 四、代码实现
```python
import torch

def step(model, u, dx):
    grad = torch.gradient(u, spacing=(dx,))
    feat = torch.stack([u] + list(grad), dim=-1)
    return model(feat)

def rollout(model, u0, steps, dx):
    u = u0
    for _ in range(steps):
        u = step(model, u, dx)
    return u
```

## 五、与其他技术对比
相比有限元，神经算子推理快但精度依赖训练分布；相比纯数据驱动，引入导数特征提升物理一致性。

## 六、常见误区
在训练分布外外推会失稳。忽略守恒量会导致非物理解。

## 七、与开源书/权威来源对应
- Vaswani 2017 注意力
- github pytorch/pytorch 自动微分
- github huggingface/transformers 序列建模

## 八、面试题
问：神经算子相比标准 ML 有何特殊？答：学习函数空间映射，对网格分辨率具一定泛化性。

## 九、演进与趋势
物理信息损失、守恒约束与多尺度耦合。

## 十、小结
神经算子把仿真变为可学习映射，是科学机器学习的重要方向。
