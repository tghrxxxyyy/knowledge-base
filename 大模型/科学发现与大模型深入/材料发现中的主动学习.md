# 材料发现中的主动学习

> 对应 github EleutherAI/lm-evaluation-harness 项目与 Kaplan 2020 的 scaling laws 论文。

## 一、背景与挑战
材料组合空间巨大，每次实验或高精仿真都昂贵。主动学习用模型不确定性指导采样，把有限预算投向信息量最大的候选。

## 二、核心原理
训练代理模型预测性质与方差，以采集函数（如期望改进）挑选下一批实验。大模型可生成候选配方并预估属性，形成生成-评估闭环。

## 三、形式化与数学基础
期望改进：
$ \mathrm{EI}(x)=\mathbb{E}[\max(0, y(x)-y^*) ] $
其中 $ y^* $ 为当前最优，模型给出 $ y(x) $ 的分布。

## 四、代码实现
```python
import numpy as np

def expected_improvement(mu, sigma, best):
    z = (mu - best) / (sigma + 1e-9)
    return (mu - best) * norm_cdf(z) + sigma * norm_pdf(z)

def norm_cdf(z):
    return 0.5 * (1 + np.math.erf(z / 2 ** 0.5))
```

## 五、与其他技术对比
相比随机筛选，主动学习缩短发现周期；相比纯模拟，它融合真实实验纠正模型偏差。

## 六、常见误区
代理模型置信度不可靠时采集函数失效。实验噪声未建模会误选。

## 七、与开源书/权威来源对应

## 八、面试题
问：主动学习为何节省实验？答：把样本预算集中在降低模型不确定性的点。

## 九、演进与趋势
贝叶斯优化与大模型生成候选结合，向全自动实验室演进。

## 十、小结
主动学习让大模型在材料发现中成为高效采样器。
