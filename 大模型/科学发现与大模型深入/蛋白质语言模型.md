# 蛋白质语言模型

> 对应 github huggingface/transformers 项目与 Devlin 2018 的 BERT 论文。

## 一、背景与挑战
蛋白质功能由氨基酸序列决定，但实验标注稀少。把氨基酸当作词、把蛋白质当作句子，掩码语言建模可学习序列空间的进化约束与结构先验。

## 二、核心原理
在海量未标注序列上做 masked LM：随机掩盖若干残基，让模型据上下文预测，迫使模型捕获共进化与折叠约束。得到的表征可迁移至突变效应预测等任务。

## 三、形式化与数学基础
掩码建模目标：
$ \mathcal{L}_{\text{MLM}}=-\sum_{i\in M}\log p(x_i | x_{\setminus M}) $
其中 $ M $ 为被掩残基集合。

## 四、代码实现
```python
import torch

def mask_seq(seq_ids, mask_id, p=0.15):
    masked = list(seq_ids)
    labels = [-100] * len(seq_ids)
    for i, v in enumerate(seq_ids):
        if torch.rand(1) < p:
            masked[i] = mask_id
            labels[i] = v
    return masked, labels

def embed(model, seq_ids):
    return model(seq_ids).last_hidden_state
```

## 五、与其他技术对比
相比多序列比对，PLM 无需同源簇且可处理孤儿蛋白；相比结构模型，它更轻量但缺乏显式三维信息。

## 六、常见误区
把表征直接当结构坐标。小数据集上微调易过拟合序列偏置。

## 七、与开源书/权威来源对应
- Devlin 2018 BERT 掩码语言建模
- github huggingface/transformers 的 BertModel
- github pytorch/pytorch 训练

## 八、面试题
问：PLM 为何能预测突变效应？答：MLM 隐式编码了共进化约束，突变破坏隐式模式则表征异常。

## 九、演进与趋势
结合结构预测与条件生成的蛋白设计。

## 十、小结
蛋白质语言模型把进化信息压缩进表征，是计算生物学的通用底座。
