# 科学文献挖掘与假设生成

> 对应 Brown 2020 的 in-context learning 论文与 github microsoft/graphrag 项目。

## 一、背景与挑战
每年新增论文海量，研究者难以跨领域发现关联。大模型可从文献中抽取实体关系，构建科学知识图谱，并基于上下文推理提出可检验假设。

## 二、核心原理
先用信息抽取从摘要得到 (实体, 关系, 实体) 三元组，构建图谱；再用检索增强把相关子图喂给模型，提示其综合出新颖假设或实验设计。

## 三、形式化与数学基础
子图检索得分：
$ R(q)=\arg\max_{g\subset G} \text{sim}(q, \text{agg}(g)) $
假设生成概率 $ p(H|q,g) $ 由模型在子图上下文下给出。

## 四、代码实现
```python
def build_graph(triples):
    g = {}
    for s, r, o in triples:
        g.setdefault(s, []).append((r, o))
    return g

def hypothesize(model, subgraph, question):
    ctx = '; '.join('%s %s %s' % (s, r, o) for s, r, o in subgraph)
    prompt = '已知: ' + ctx + '\n问题: ' + question + '\n假设:'
    return model.generate(prompt)
```

## 五、与其他技术对比
相比关键词检索，图谱支持多跳关系推理；相比纯文本问答，结构化子图降低幻觉并提升可追溯性。

## 六、常见误区
抽取错误会沿图谱传播污染假设。假设新颖不等于正确，仍需实验验证。
