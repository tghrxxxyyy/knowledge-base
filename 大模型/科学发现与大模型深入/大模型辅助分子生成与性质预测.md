# 大模型辅助分子生成与性质预测

> 对应 github huggingface/transformers 项目与 Vaswani 2017 的 Transformer 论文。

## 一、背景与挑战
新药与材料研发周期长、成本高。把分子表示为 SMILES 或图序列后，可用自回归模型生成候选分子并预测活性、毒性等性质，从而缩小实验范围。

## 二、核心原理
将分子线性化为 token 序列，用 Transformer 做无条件或有条件生成；性质预测可视为序列回归头。条件生成通过前缀提示约束靶点或对活性区间。

## 三、形式化与数学基础
自回归分子生成概率：
$ p(S)=\prod_{t=1}^{T} p(s_t | s_{<t}) $
性质预测 $ \hat{y}=f_\phi(\text{enc}(S)) $ 与实验值最小化 MSE。

## 四、代码实现
```python
import torch

def mol_score(enc, head, smiles_ids):
    # enc: transformer; head: regression
    h = enc(smiles_ids).last_hidden_state[:, 0]
    return head(h)

def sample_mol(enc, dec, prefix, steps=80):
    ids = list(prefix)
    for _ in range(steps):
        logits = dec(ids)[-1]
        nxt = int(logits.argmax())
        if nxt == 1:
            break
        ids.append(nxt)
    return ids
```

## 五、与其他技术对比
相比图神经网络直接操作分子图，序列模型复用成熟语言建模范式、易条件化；但可能生成语法非法 SMILES，需要校验。

## 六、常见误区
忽视价键合法性导致无效分子。用有偏数据集训练会放大化学空间盲区。

## 七、与开源书/权威来源对应
- Vaswani 2017 Attention Is All You Need
- github huggingface/transformers 的 Seq2Seq 建模
- github pytorch/pytorch 训练底座

## 八、面试题
问：为何分子生成要做合法性校验？答：自回归采样可能产出无法解析的 SMILES，需化学校验器过滤。

## 九、演进与趋势
从 SMILES 走向 SELFIES 与扩散式分子生成，结合主动实验闭环。

## 十、小结
大模型把分子设计转为序列建模问题，为高通量虚拟筛选提供新引擎。
