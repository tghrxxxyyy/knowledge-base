# 数学推理与形式化证明

> 对应 Wei 2022 的 chain-of-thought 论文与 github karpathy/nanoGPT 项目。

## 一、背景与挑战
数学要求严格的多步演绎，朴素生成容易在中间步骤出错。CoT 与形式化证明系统把推理显式化，使其可被机器校验。

## 二、核心原理
CoT 提示模型逐步写出推导，把复杂问题拆解为可验证子目标。形式化路线则把自然语言题翻译为 Lean/Isabelle 等定理证明器语言，由证明器判定正确性。

## 三、形式化与数学基础
Transformer 对长度为 $ n $ 序列的注意力成本为：
$ O(n^2 d) $
其中 $ d $ 为隐藏维。证明搜索常结合蒙特卡洛树或最佳优先搜索。

## 四、代码实现
```python
def cot_solve(model, problem):
    prompt = problem + '\n请逐步推理:\n1.'
    return model.generate(prompt, max_new=512)

def verify(prover_cli, formal_stmt):
    out = prover_cli.run('check ' + formal_stmt)
    return 'no errors' in out.lower()
```

## 五、与其他技术对比
CoT 易读但不保证正确；形式化证明正确但翻译成本高。二者常结合：CoT 探索、形式化确认。

## 六、常见误区
把中间数值近似当作严格证明。忽略前提假设导致错用定理。

## 八、面试题
问：CoT 为何显著提升数学？答：把复合推理分解为可监督的中间步骤，降低每步难度。

## 九、演进与趋势
形式化证明器与大模型协同、自动题面到证明翻译。

## 十、小结
显式推理链与机器可校验证明是大模型攻克数学的两条主线。
