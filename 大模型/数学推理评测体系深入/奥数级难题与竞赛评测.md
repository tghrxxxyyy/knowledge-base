# 奥数级难题与竞赛评测

> 对应 Hendrycks et al. 2021 "MATH" 中 AIME/AMC 子集与竞赛数学评测实践。

## 一、背景与挑战

AIME/AMC/ Olympiad 题目需要多步非平凡推理与巧妙构造，强模型仍远低于人类顶尖水平。评测挑战是答案稀疏（正确率近 0 时难以区分模型）、题目少易过拟合。

## 二、核心原理

竞赛评测常报分层准确率、pass@k（多次采样至少一次对）、与人类百分位对照。由于答案空间小（AIME 为 0-999 整数），可用答案分布分析模型置信。

## 三、数学形式

pass@k 估计：

$$
\mathrm{pass@k}=1-\binom{n-c}{k}\big/\binom{n}{k}
$$

人类百分位映射：

$$
r=\mathrm{Percentile}(\mathrm{Acc}_{\mathrm{model}},\mathcal{H})
$$

## 四、代码实现

```python
from math import comb

def pass_at_k(n, c, k):
    if n - c < k:
        return 1.0
    return 1 - comb(n - c, k) / comb(n, k)

print(round(pass_at_k(100, 20, 8), 4))
```

## 五、与其他对比

相较 GSM8K（饱和），竞赛题区分度更高；相较 MiniF2F（形式化），竞赛题更贴近真实奥数但不可机器判证明。

## 六、常见误区

误区一：AIME 低分即无推理力（可能接近）。误区二：用训练竞赛题直接评测。误区三：忽略答案范围导致的巧合正确。

## 八、面试题

- Q：竞赛评测为何用 pass@k？答：单次难中，多次采样至少一次正确更能反映能力上限。
- Q：AIME 答案范围的意义？答：缩小搜索空间，可用分布分析置信。

## 九、演进

竞赛题成为前沿模型（如 Gemini/o1）的核心区分基准，并驱动推理时搜索与反思训练。

## 十、小结

奥数级评测以高区分度与稀疏正确答案，成为检验顶尖推理能力的标尺。
