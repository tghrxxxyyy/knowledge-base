# 数推评测的数据污染与防泄漏

> 对应 Golchin & Surdeanu 2023 "Data Contamination Quiz" 与数学基准污染检测实践。

## 一、背景与挑战

GSM8K/MATH 等已广泛见于训练语料，直接评测分数虚高。污染检测需区分"真推理提升"与"记忆答案"，并保证基准时效性。

## 二、核心原理

方法包括：n-gram 重叠检测、canary 字符串、同义改写重测（若改写后骤降说明记忆）、以及用未公开新题（如最新竞赛）做时序泄漏测试。

## 三、数学形式

n-gram 重叠率：

$$
o=\frac{|\mathrm{ngram}(q_{\mathrm{test}})\cap\mathrm{ngram}(D_{\mathrm{train}})|}{|\mathrm{ngram}(q_{\mathrm{test}})|}
$$

改写一致性差：

$$
\delta=\mathrm{Acc}(q)-\mathrm{Acc}(q')
$$

## 四、代码实现

```python
def overlap(test_ngrams, train_ngrams):
    inter = set(test_ngrams) & set(train_ngrams)
    return len(inter) / len(set(test_ngrams)) if test_ngrams else 0.0

print(round(overlap(["a","b","c"], ["b","c","d"]), 3))
```

## 五、与其他对比

相比单纯报分，污染检测解释分数来源；相比闭源新题，开源检测更可复现但需持续更新。

## 六、常见误区

误区一：低重叠即无污染（语义级记忆仍存在）。误区二：改写掉点就一定是污染（也可能是改写引入歧义）。误区三：用训练 loss 反推可靠。

## 八、面试题

- Q：如何检测数学基准污染？答：n-gram 重叠、canary、同义改写重测与未公开新题。
- Q：为何改写重测有效？答：记忆答案者在改写后骤降，真推理者保持稳定。

## 九、演进

从静态基准到持续更新的竞赛题与污染审计工具，评测可信度依赖防泄漏机制。

## 十、小结

数据污染是数推评测的可信度基石，需组合检测与时效新题共同保障。
