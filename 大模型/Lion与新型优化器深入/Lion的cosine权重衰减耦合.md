# Lion的cosine权重衰减耦合

> 对应 Chen et al. 2023《Lion》(arXiv:2302.06675) 与 d2l-ai/d2l-zh 学习率调度讲解。

## 一、背景与挑战

大模型训练几乎必然配合 cosine 学习率衰减：学习率从峰值平滑降到接近零。一个随之而来的问题是：**权重衰减 $\lambda$ 是否也该随训练进度衰减？** 若 $\lambda$ 固定，在 lr 已很小时，参数仍按固定比例收缩，可能末期过度正则、损害已学到的容量。

Lion 因更新幅度恒定，这个问题尤为线性、可预测，也更容易被显式调度。

## 二、核心原理

Lion 的参数更新为 $\theta\leftarrow\theta-\eta(\mathrm{sign}(m)+\lambda\theta)$。注意收缩项是 $\eta\lambda\theta$——它的大小取决于**当前 lr $\eta$**。因此即便 $\lambda$ 固定，随着 cosine 把 $\eta$ 降到接近 0，末期收缩自然变弱。这已隐含「自动衰减」。

部分实践进一步把 $\lambda$ 本身也做 cosine 调度，使其与 $\eta$ 同步衰减，保证 $\eta\lambda$ 乘积平滑下降，避免末期收缩过强或过弱。直觉是：训练后期模型已收敛，应减少参数收缩，保留容量。

## 三、形式化与数学基础（含 LaTeX）

标准 cosine 学习率：

$$
\eta(t) = \eta_{\min} + \tfrac{1}{2}(\eta_{\max}-\eta_{\min})\big(1+\cos(\pi t/T)\big)
$$

令权重衰减同步衰减：

$$
\lambda(t)=\lambda\cdot\frac{\eta(t)}{\eta_{\max}}
$$

则收缩系数 $\eta(t)\lambda(t)=\lambda\cdot\frac{\eta(t)^2}{\eta_{\max}}$，随 $t$ 二次衰减，比单纯固定 $\lambda$（线性衰减）更平滑地收尾。若不做耦合，固定 $\lambda$ 下收缩仅随 $\eta(t)$ 线性下降。

## 四、代码实现（围栏配平）

```python
import math

# cosine 联合调度 lr 与权重衰减
def cosine_lr_wd(t, T, lr_max, wd_max, lr_min=0.0):
    coef = 0.5 * (1 + math.cos(math.pi * t / T))
    lr = lr_max * coef
    wd = wd_max * coef                  # 同步衰减，保持耦合
    return lr, wd
```

## 五、与其他技术对比

- 与 **AdamW** 相比：AdamW 同样适用该耦合；Lion 因步长恒定，$\lambda$ 调度影响更线性、更易预测。
- 与 **固定衰减** 相比：耦合使末期收缩更平滑，减少过正则风险。
- 与 **warmup 后不变** 相比：cosine 收尾更符合训练损失后期的平缓特性。

## 六、常见误区

- 「把 $\lambda$ 衰减到 0」——会完全解除正则，末期可能过拟合，应保留最小 $\lambda$。
- 「lr 衰减就够了，wd 不用动」——虽已隐式减弱，但显式耦合更可控、更易复现。
- 「所有任务都该耦合」——小模型/短训练可能无感，需按验证集表现决定。

## 七、与开源书·权威来源对应

- d2l-ai/d2l-zh 在优化章节系统讲解 cosine 调度与 warmup 的原理。
- Loshchilov & Hutter 2019 的 AdamW 论文奠定解耦衰减与调度搭配的范式。

## 八、面试题

- 问：Lion 后期为何收缩变弱？答：收缩项为 $\eta\lambda\theta$，cosine 把 $\eta$ 降到近 0，收缩随之自然减弱。
- 问：为何耦合 $\lambda$ 与 lr？答：让 $\eta\lambda$ 平滑收尾，避免末期过度正则、保留已学容量。
- 问：耦合到 0 有什么问题？答：完全解除正则，训练末期易过拟合。

## 九、演进与趋势

联合调度 lr 与 wd 正成为大模型训练标准做法；更精细的方案用**验证损失反馈动态调 wd**，或在不同参数组设不同衰减曲线。

### 关键要点速查

- Lion 收缩项为 $\eta\lambda\theta$，lr 经 cosine 下降时收缩自然减弱。
- 把 $\lambda$ 也做 cosine 调度，使 $\eta\lambda$ 平滑收尾，避免末期过正则。
- 耦合到 0 会完全解除正则，末期易过拟合，应保留最小 $\lambda$。
- 固定 $\lambda$ 时收缩随 $\eta$ 线性下降，显式耦合则近似二次衰减更平滑。
- 小模型/短训练可能无感，需按验证集表现决定是否耦合。
- 不同参数组可设不同衰减曲线，适配层特性（如 embedding/head）。
- 联合调度 lr 与 wd 正成为大模型训练标准做法。
- 进阶方案用验证损失反馈动态调 wd，而非固定曲线。

- warmup 阶段建议先不衰减 wd，避免早期过度约束。
- 长训练（数周）对耦合更敏感，短实验可忽略。
- 可用线性预热 wd 再接 cosine，平滑起步。
- 不同层（如 LN 与线性层）对衰减敏感度不同，可分组。
- 监控末段参数范数，异常增长提示衰减不足。
- 与 layernorm 的零中心特性结合，衰减影响更温和。
- 多阶段训练可在阶段切换处重置衰减曲线。
- 把 lr/wd 曲线可视化纳入训练看板，便于复盘。

## 十、小结

把权重衰减与学习率协同调度，能更精细地控制训练末期的容量与正则强度，是大模型稳定收尾的实用技巧。
