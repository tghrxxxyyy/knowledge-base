# 新型优化器综述与符号范式

> 对应 Chen et al. 2023《Lion》(arXiv:2302.06675)、Liu et al. 2023《Sophia》(arXiv:2305.14342)、Loshchilov & Hutter 2019《AdamW》(arXiv:1711.05101)。

## 一、背景与挑战

大模型训练推动优化器持续演进，主线是**低状态、低精度、高稳定性**。除 AdamW、Lion 外，Adan、Sophia、Shampoo 等也尝试不同路径：有的用因式分解近似二阶信息，有的引入曲率估计。理解它们的统一结构，比记住各自公式更重要。

## 二、核心原理

可以把现代优化器统一写成「**方向函数 D + 解耦衰减**」的范式：

$$
\theta_{t+1} = \theta_t - \eta\cdot D(g_t, state_t) - \eta\lambda\theta_t
$$

其中 $D$ 决定更新方向，$state$ 是优化器维护的状态。不同优化器的本质区别就在 $D$：

- **AdamW**：$D=\hat m/\sqrt{\hat v}$，用一阶与二阶矩做逐元素自适应。
- **Lion**：$D=\mathrm{sign}(m)$，只用一阶动量取符号，幅度恒定。
- **Sophia**：$D=m/\mathrm{diag}(H)$，引入 Hessian 对角近似作为曲率预条件，方向更准但需额外状态与计算。
- **Adan**：结合 Nesterov 动量与自适应，状态更多但理论收敛性好。

共同趋势是**解耦权重衰减（decoupled weight decay）成为标配**——它让正则强度 $\lambda$ 与学习率 $\eta$ 解绑，强度可解释、易调。

## 三、形式化与数学基础（含 LaTeX）

统一更新式：

$$
\theta_{t+1} = \theta_t - \eta\, D(g_t, state_t) - \eta\lambda\theta_t
$$

各方法的状态成本：AdamW 需 $2P$ 状态（一阶+二阶），Lion 需 $P$，Sophia 需 $P$ 动量 + 近似 Hessian 状态（常摊销估计）。设每参数状态字节 $s$，显存状态项 $\propto s\cdot P$。状态越少，可训练规模 $P$ 在同一显存预算下越大。

符号范式的特殊处在于 $D$ 只取 $\{-1,0,+1\}$，更新能量被 $\eta$ 完全决定，故对 $\eta$ 高度敏感。

## 四、代码实现（围栏配平）

```python
import torch

# 抽象优化器方向函数：统一视角对比各方法
def direction(name, g, state):
    if name == "adamw":
        return state["mhat"] / (state["vhat"].sqrt() + 1e-8)
    if name == "lion":
        return state["m"].sign()              # 符号范式
    if name == "sophia":
        return state["m"] / (state["h"].clamp(min=1e-8))  # 曲率预条件
    raise NotImplementedError(name)
```

## 五、与其他技术对比

- **符号类（Lion）**：省显存、需细调 lr，适合超大模型。
- **曲率类（Sophia）**：方向信息更丰富、收敛更省 step，但状态/计算更贵。
- **自适应类（AdamW）**：最稳健、最易复现，长期是默认选择。

没有绝对赢家——收益高度依赖任务规模、数据量与调参预算。

## 六、常见误区

- 「新优化器必然全面优于 AdamW」——实际收益受规模与调参影响，常只是特定区间占优。
- 「符号=粗糙」——符号只压缩幅度，方向由动量保留，信息是结构化的。
- 「状态少就一定快」——每步计算相近，省的是显存而非算力。

## 七、与开源书·权威来源对应

- Chen et al. 2023 Lion 提出符号优化并由程序搜索发现。
- Liu et al. 2023 Sophia 用 Hessian 对角近似做轻量二阶预条件。
- Loshchilov & Hutter 2019 AdamW 确立解耦权重衰减范式，是后续方法的基准。
- mlabonne/llm-course 对现代优化器有系统梳理。

## 八、面试题

- 问：解耦衰减为何成标配？答：让正则强度 $\lambda$ 独立于 $\eta$，强度可解释、易调，利于大模型稳定训练。
- 问：Lion 与 Sophia 的本质区别？答：Lion 用符号方向省状态，Sophia 用曲率预条件换方向精度，代价是更多状态。
- 问：如何按任务选型？答：显存受限选 Lion，求收敛效率且算力足选 Sophia，求稳健默认 AdamW。

## 九、演进与趋势

低精度状态 + 自动化超参（按规模/数据选优化器）+ 任务自适应方向函数，是前沿方向；符号与曲率也可能被组合。

### 关键要点速查

- 现代优化器可统一为 $\theta\leftarrow\theta-\eta D(g,state)-\eta\lambda\theta$，差异在方向函数 $D$。
- AdamW 的 $D=\hat m/\sqrt{\hat v}$，Lion 的 $D=\mathrm{sign}(m)$，Sophia 用曲率预条件。
- 解耦权重衰减已成标配，让正则强度 $\lambda$ 与 lr 解绑、可解释易调。
- 符号类（Lion）省显存但需细调 lr；曲率类（Sophia）方向更准但更贵。
- 没有绝对赢家，收益高度依赖规模、数据与调参预算。
- 状态成本决定可训练规模：AdamW 2P、Lion 1P、Sophia 含近似 Hessian。
- 低精度状态 + 自动选优化器 + 任务自适应方向函数是前沿。
- 选型应按「显存、速度、稳定性」三角权衡，而非盲从新潮。

## 十、小结

理解各优化器的方向函数 $D$ 与状态成本，才能在「显存、速度、稳定性」三角中按需选型，而非盲从新潮。
