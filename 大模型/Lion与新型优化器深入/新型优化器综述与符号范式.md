# 新型优化器综述与符号范式

> 对应 Chen 2023 Lion (arXiv:2302.06675) 与 Loshchilov & Hutter 2019 AdamW。

## 一、背景与挑战
大模型训练推动优化器向低状态、低精度、高稳定性演进。除 AdamW、Lion 外，Adan、Sophia 等也尝试不同路径。

## 二、核心原理
符号范式（sign-based）以恒定步长换取低状态；另一些方法引入曲率估计（如 Sophia 的 Hessian 对角近似）以获得更优方向。共同趋势是解耦衰减成为标配。

## 三、形式化与数学基础
统一视角：更新 `θ ← θ - η·D(g, state) - ηλθ`，其中 D 为方向函数。AdamW 的 D 用 `mhat/√vhat`，Lion 的 D 用 `sign(m)`，Sophia 的 D 用 `m/diag(H)`。

## 四、代码实现
```python
# 抽象优化器方向函数
def direction(name, g, state):
    if name == "adamw": return state["mhat"] / (state["vhat"].sqrt() + 1e-8)
    if name == "lion":  return state["m"].sign()
    raise NotImplementedError
```

## 五、与其他技术对比
符号类省显存但需细调 lr；曲率类信息更丰富但状态/计算更贵；没有绝对赢家。

## 六、常见误区
认为新优化器必然全面优于 AdamW。实际收益高度依赖任务规模与调参预算。

## 七、与开源书/权威来源对应
Chen 2023 Lion 与 mlabonne/llm-course 对现代优化器有系统梳理；Loshchilov & Hutter 2019 AdamW 为基准。

## 八、面试题
问：解耦衰减为何成标配？答：它让正则强度可解释、易调，且利于大模型稳定训练。

## 九、演进与趋势
低精度状态 + 自动化超参 + 任务自适应优化器是前沿。

## 十、小结
理解各优化器的方向函数与状态成本，才能按需选型。
