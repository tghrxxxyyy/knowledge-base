# 大模型与广告

> 见「搜索推荐大模型深入/搜索推荐总览」；广告是搜推的商业延伸。

## 一、背景与挑战

广告需精准匹配用户意图与创意生成。

## 二、核心原理

大模型用于：广告文案/创意自动生成（多版本 A/B）、用户意图理解优化投放、受众语义圈选、广告相关性排序（LLM-as-ranker）。生成式创意显著提升点击率测试效率。

## 三、关键要点

- 创意生成需合规与品牌约束。
- 投放决策仍靠轻量模型实时。

## 四、代码实现

```python
creatives = llm(f"为{product}生成5条广告文案,风格{style}")
```

## 五、与其他对比

- 传统 A/B 慢；LLM 批量生成快。
