# 推荐系统大模型

> 见「搜索推荐大模型深入/搜索推荐总览」；LLM4Rec 综述（Wu et al., 2023）。

## 一、背景与挑战

推荐需个性化与冷启动，传统模型难泛化。

## 二、核心原理

- **特征增强**：LLM 把用户/物品文本转为 richer embedding 喂传统推荐。
- **生成式推荐**：直接由 LLM 生成推荐理由/列表。
- **对话推荐**：多轮对话澄清偏好。
LLM 的语义理解缓解冷启动与长尾。

## 三、关键要点

- 在线延迟限制 LLM 实时性。
- 常 LLM 离线产特征，轻模型在线。

## 四、代码实现

```python
item_emb = llm_encoder(item_text)   # 离线
score = dot(user_emb, item_emb)
```

## 五、与其他对比

- 传统靠 ID 特征；LLM 靠语义。

## 六、常见误区

- 全量 LLM 推荐——延迟不可行。

## 七、与开源书对应

- Wu et al., *LLM4Rec*, 2023.
- llm-course: https://github.com/mlabonne/llm-course

## 八、面试题

- 大模型如何缓解推荐冷启动？

## 九、演进

ID 特征 → 语义特征 → 生成式推荐。

## 十、小结

推荐，被语义「唤醒」。
