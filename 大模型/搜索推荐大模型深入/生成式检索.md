# 生成式检索

> 见「搜索推荐大模型深入/搜索推荐总览」；Tay et al., *DSI (Decoder-Only Index)*, 2022。

## 一、背景与挑战

传统检索靠索引+召回，能否直接用模型「生成」文档 ID？

## 二、核心原理

**生成式检索（Generative Retrieval）**把文档赋予结构化 ID（如语义树路径），训练模型直接由 query 生成该 ID，省去外部索引。DSI 用「先记忆后生成」；后续用语义 ID（如以文中句子作 ID）。挑战：ID 碰撞与长尾。

## 三、数学形式

`P(doc_id | query) = Π_t P(id_t | id_<t, query)`。

## 四、代码实现

```python
doc_id = llm.generate(f"query: {q} -> doc_id:")
```

## 五、关键要点

- 语义 ID 比随机 ID 更易学。
- 尚难替代大规模向量检索。

## 六、与其他对比

- 传统索引外置；生成式内置。

## 七、常见误区

- 生成式取代一切检索——规模受限。
