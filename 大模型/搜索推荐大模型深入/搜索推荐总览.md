# 搜索推荐总览

> 对应 llm-course；搜索/推荐系统与大模型融合综述。

## 一、背景与挑战

传统搜推靠召回+排序双塔/特征工程；大模型带来语义理解与生成式新范式。

## 二、核心原理

搜推链路：召回（从海量取候选）→ 粗排 → 精排 → 重排。大模型可增强：语义召回（embedding）、查询理解/改写、生成式召回、列表重排（LLM-as-ranker）、个性化生成。

## 三、关键要点

- 延迟约束严，大模型多用在离线/重排。
- 双塔仍是召回主力（可并行）。

## 四、代码实现

```python
q_emb = encoder(query); docs = faiss.search(q_emb, k)
```

## 五、与其他对比

| 环节 | LLM 角色 |
|------|----------|
| 召回 | 语义编码 |
| 排序 | 重排/打分 |
