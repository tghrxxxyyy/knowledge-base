# 可观测性与容量规划

> 对应 Kwon 2023 vLLM; Gao 2021 lm-eval-harness; Zhao 2023 FSDP。

## 一、背景与挑战
没有指标就无法定位延迟瓶颈与容量不足，需系统性可观测与规划。

## 二、核心原理
采集 TTFT、TPOT、队列长度、GPU 利用率、KV 使用率、错误率；用 dashboards/告警监控，并据历史做容量规划。

## 三、形式化与数学基础
容量需求：
$ C = \frac{\lambda \cdot (\text{TTFT}_{prefill} + N \cdot \text{TPOT})}{U_{target}} $
U_target 为目标利用率。

## 四、代码实现
```python
metrics = {
    "ttft": hist(), "tpot": hist(),
    "gpu_util": gauge(), "kv_used": gauge(),
}
alert if p99(ttft) > sla_ttft
```

## 五、与其他技术对比
仅看 QPS 不够；需看延迟分布与资源饱和度，否则盲区。

## 六、常见误区
误区：平均延迟达标即可。须看 p99/p999，尾延迟才是体验。

## 七、与开源书/权威来源对应
Prometheus/Grafana 监控；vLLM 指标。见 vllm-project/vllm、EleutherAI/lm-evaluation-harness。

## 八、面试题
问：容量规划看哪些指标？
答：到达率、TTFT/TPOT 分布、GPU 与 KV 饱和度，反推副本数。

## 九、演进与趋势
基于 SLO 的自动容量与成本优化。

## 十、小结
可观测性是推理服务的眼睛，容量规划据此从经验走向数据驱动。
