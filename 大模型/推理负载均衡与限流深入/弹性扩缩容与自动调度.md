# 弹性扩缩容与自动调度

> 对应 Zhao 2023 FSDP; Rasley 2020 DeepSpeed ZeRO; Kwon 2023 vLLM。

## 一、背景与挑战
流量波动大，固定副本数在高峰排队、低谷浪费，需自动扩缩。

## 二、核心原理
监控队列长度、GPU 利用率、SLA 违规率，按策略增减副本；新副本预热权重后接入，缩容先排空。

## 三、形式化与数学基础
目标副本数：
$ N = \lceil \frac{\lambda \cdot \bar{T}}{SLA_{util}} \rceil $
λ 到达率，\bar{T} 平均处理时长。

## 四、代码实现
```python
def desired_replicas(lambda_, T, sla):
    return max(1, ceil(lambda_ * T / sla))
# HPA 据指标调用 desired_replicas
```

## 五、与其他技术对比
手动扩缩响应慢；自动 HPA 结合预测更稳，但冷启动需预案。

## 六、常见误区
误区：扩缩即时生效。权重加载有延迟，需预热与缓冲。

## 七、与开源书/权威来源对应
Kubernetes HPA；vLLM 多副本。见 vllm-project/vllm、pytorch/pytorch。

## 八、面试题
问：如何避免扩缩抖动？
答：设冷却时间与滞回阈值，结合预测平滑。

## 九、演进与趋势
预测式弹性 + 分离式实例池联动。

## 十、小结
弹性扩缩在成本与 SLA 间动态平衡，是云推理经济性核心。
