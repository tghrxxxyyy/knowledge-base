# 少样本与元学习

> 见「迁移与元学习深入/迁移学习原理」与「提示工程深入/少样本提示」。

## 一、背景与挑战

每任务仅几个样本也要学会。

## 二、核心原理

元学习「学会学习」：在大量任务上训练，使模型快速适应新任务（如 MAML 的内外循环）。

## 三、数学形式

MAML 内循环：

```
θ' = θ - α ∇_θ L_task(θ);  外循环 min_θ Σ L_task(θ')
```

## 四、代码实现

```python
for t in tasks:
    fast = theta - alpha*grad(L_t(theta))
    meta_loss += L_t(fast)
```

## 五、关键要点

- 关注初始化可迁移。
- 少样本 prompt 也属元能力。
