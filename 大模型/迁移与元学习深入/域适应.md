# 域适应

> 见「迁移与元学习深入/迁移学习原理」。

## 一、背景与挑战

源/目标数据分布不同（如合成→真实）。

## 二、核心原理

对齐特征分布：对抗（DANN）、MMD、对比对齐，使分类器域不变。

## 三、数学形式

域对抗：

```
min_G max_D L_task - λ L_adv(D(G(x)))
```

## 四、代码实现

```python
loss = task_loss + adv_loss(disc(feat))
```

## 五、关键要点

- 无目标标签→无监督域适应。
- 对齐需适度。

## 六、与其他对比

- 微调需目标标签；域适应可无。

## 七、常见误区

- 对齐越强越好——可能丢判别信息。
