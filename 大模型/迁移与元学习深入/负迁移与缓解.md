# 负迁移与缓解

> 对应 Wang et al., *Characterizing and Avoiding Negative Transfer* (CVPR 2019, arXiv:1811.09060)、Pan & Yang, *A Survey on Transfer Learning* (TKDE 2010)、Ganin et al., DANN (arXiv:1505.07818)、Rosenfeld & Ben-David, *On the Mathematics of Transfer Learning* (arXiv:2102.11013)，以及综述与代码仓库 github.com/jindongwang/transferlearning、github.com/huggingface/peft；关联篇章「迁移学习原理」「领域自适应」「元学习」。

## 一、背景与挑战

迁移学习的默认假设是「源域知识对目标域有用」，但这个假设会系统性失效：用纯代码语料去帮助法律文本分类、用英文情感数据去初始化中文医学意图识别、用通用网页对话 SFT 去微调金融风控客服——这些场景里源域不仅没帮忙，反而把目标域性能**拉到比从头训练还低**，这就是负迁移（negative transfer）。

负迁移在工业界被长期低估，原因有三。第一，基线不诚实：很多团队只对比「迁移 vs 不迁移」中的迁移结果，缺少 from-scratch 对照，负迁移发生而无人察觉。第二，大模型时代的负迁移形态更隐蔽：基座模型携带的先验与垂直领域冲突时，微调后模型可能在通用 benchmark 上掉点、或在目标域出现「看似合理实则错」的幻觉，而不是直接崩掉。第三，多源/混合数据是常态，噪声源与不相关源混在训练集里，负贡献被平均分摊后难以归因。因此核心挑战是：**如何量化迁移贡献、在训练前预测负迁移、在训练中自动止损**。

## 二、核心原理

### 2.1 何时源域伤害目标域

把源域 $P_S(X,Y)$ 与目标域 $P_T(X,Y)$ 的差异拆成两部分：协变量偏移 $\|P_S(X)-P_T(X)\|$ 与概念/条件偏移 $\|P_S(Y|X)-P_T(Y|X)\|$。经验规律：

- **特征可对齐但标签语义冲突**最危险：输入分布相似、但 $Y|X$ 不同（例如源域「评论→情感」、目标域「评论→工单类别」，文本域一样但监督信号完全不同），此时高层分类头被源域监督带偏，微调初期就收敛到错误盆地。
- **源域过小或过噪**：源域本身学到的表征带有伪相关（spurious correlation），迁移后目标域小样本不足以洗掉。
- **分布差异过大且模型容量有限**：表征空间被源域占满，目标域没有自由度重新组织，这在全参微调大模型、学习率偏大时尤其明显。
- **负迁移随任务数放大**：多任务/混合训练中，梯度方向冲突（余弦相似度为负）的任务互相抵消，等价于注入噪声梯度。

### 2.2 检测指标

- **迁移增益差**：$\Delta = \mathrm{Perf}(T \mid \text{pretrain on } S) - \mathrm{Perf}(T \mid \text{from scratch})$，$\Delta < 0$ 即负迁移。这是金标准，但要多随机种子才可信（方差可掩盖 1-2 个点的真实倒退）。
- **源目标相似度代理**：任务聚类（在同一组源任务上训 probe 后比较表征）、线性探测（frozen feature probing）、域分类器准确率——若一个分类器能轻易区分源/目标的特征，域间隙大，迁移风险高。
- **梯度/损失信号**：目标任务损失在微调初期不降反升、或源-目标梯度余弦长期为负，是训练中的在线告警。
- **对抗验证（adversarial validation）**：训一个域判别器区分源/目标样本，AUC 接近 0.5 说明同分布、可放心迁移；AUC 接近 1 说明分布严重脱节。

### 2.3 缓解手段

1. **选择性迁移（择源）**：按相似度对源域打分，低于阈值就弃用或降权——「宁可少迁，不可乱迁」。
2. **再加权（re-weighting）**：对源样本按其与目标分布的密度比 $w(x) = p_T(x)/p_S(x)$ 或按梯度对齐度加权，让相关样本主导。
3. **领域对抗（domain-adversarial）**：DANN 在特征提取器上加域判别器并梯度反转（GRL），逼出域不变表征，压缩 $P_S(X)$ 与 $P_T(X)$ 的差距。
4. **混合/门控（gating）**：训练一个迁移门控 $g(x)\in[0,1]$ 决定每个输入走源域先验还是走目标域独立路径；或用 adapter 路由，把源域知识隔离在可关闭的分支里。
5. **正则与约束**：EWC/LwF 式的参数锚定、或直接冻结与目标任务无关的层（只微调顶层/LoRA），限制源域先验的破坏半径。
6. **LLM 垂直微调中的实践**：混入适量通用回放数据（5-15%）、使用较小学习率与更少 epoch、对通用 benchmark 做回归测试；发现通用能力掉点即说明基座先验被过度覆盖，属另一种形式的负迁移。

## 三、形式化与数学基础

迁移风险的理论刻画（Rosenfeld et al. 风格）：设 $h$ 为在源风险 $R_S(h)$ 上优化得到的假设，目标风险可被界为

$$R_T(h) \le R_S(h) + \mathrm{div}(P_S, P_T) + \lambda$$

其中 $\lambda = \min_h (R_S(h) + R_T(h))$ 是「最优联合假设」的代价。当源任务与目标任务的最优假设不相容时，$\lambda$ 很大：**强行迁移会把 $R_S$ 压到很低，却把 $R_T$ 顶得更高**，这就是负迁移的偏差-方差式来源。

再加权的密度比目标写作：

$$\min_{h \in \mathcal{H}} \; \mathbb{E}_{x \sim P_S}\!\left[\frac{p_T(x)}{p_S(x)}\, \ell(h(x), y)\right] \;\approx\; \mathbb{E}_{x \sim P_T}[\ell(h(x), y)]$$

DANN 的极小极大目标：

$$\min_{G, F} \; \mathbb{E}_{(x_S,y)} \ell(F(G(x_S)), y) \;-\; \lambda\, \mathbb{E}_{x_S} \ell(D(G(x_S)), S) \;+\; \mathbb{E}_{x_T} \ell(D(G(x_T)), T)$$

其中域判别器 $D$ 被最小化、特征生成器 $G$ 被最大化域损失（通过 GRL 实现），收敛时 $D$ 的 AUC 趋近 0.5，即特征已域不变。多任务梯度冲突用余弦度量：

$$\cos(g_i, g_j) = \frac{g_i^\top g_j}{\|g_i\|\,\|g_j\|} < 0 \implies \text{任务 } i,j \text{ 在互相拖后腿}$$

## 四、代码实现

```python
import torch
import torch.nn as nn

# ---------- 1) 对抗验证：AUC 高 => 源目标分布脱节，迁移风险高 ----------
def adversarial_validation(feats_s, feats_t, epochs=300):
    """训一个域判别器区分源/目标特征；返回 AUC 近似的准确率。"""
    xs = torch.cat([feats_s, feats_t])
    ys = torch.cat([torch.zeros(len(feats_s)), torch.ones(len(feats_t))])
    d = nn.Sequential(nn.Linear(xs.shape[1], 64), nn.ReLU(), nn.Linear(64, 2))
    opt = torch.optim.Adam(d.parameters(), lr=1e-3)
    for _ in range(epochs):
        opt.zero_grad()
        loss = nn.functional.cross_entropy(d(xs), ys.long())
        loss.backward(); opt.step()
    acc = (d(xs).argmax(1) == ys.long()).float().mean().item()
    # acc ~ 0.5: 同分布可迁；acc > 0.8: 显著域间隙，先做域对齐或弃用该源域
    return acc

# ---------- 2) 迁移门控：相似度低于阈值则放弃源域预训练 ----------
def gated_transfer(task_sim, thr=0.3, scratch_fn=None, pretrain_fn=None):
    """task_sim: 源目标相似度（如线性探测准确率 / 域判别 AUC 反转值）。"""
    if task_sim is None or task_sim < thr:
        return scratch_fn()      # 负迁移高风险：从头训练目标域
    return pretrain_fn()         # 相似度足够，才享受迁移收益

# ---------- 3) 梯度级再加权：按目标域损失对源域样本在线降权 ----------
def reweight_source_batch(src_loss_per_sample, tau=1.0):
    """损失极低（源域太容易/不相关）或极高的样本被衰减，相关样本主导。"""
    w = torch.softmax(-src_loss_per_sample / tau, dim=0)   # 相关性启发式权重
    return w

# 生产经验：垂直 LLM 微调前先跑对抗验证 + 小规模 from-scratch 对照，
# 两者都通过再全量开跑；否则混入通用回放数据或改用 LoRA 隔离源域先验。
```

## 五、与其他技术对比

| 方案 | 检测/预防负迁移 | 训练成本 | 适用阶段 | 主要风险 |
|------|----------------|----------|----------|----------|
| from-scratch 对照实验 | 金标准，直接量化 $\Delta$ | 高（需完整训练） | 决策前 | 小目标域上 scratch 方差大 |
| 对抗验证 | 强（分布层面预警） | 低（只训判别器） | 训练前 | 只测 $P(X)$ 差异，测不到概念偏移 |
| 梯度/损失监控 | 中（训练中在线告警） | 近零 | 训练中 | 损失下降也可能掩盖表征污染 |
| 领域对抗训练（DANN） | 预防型，压域间隙 | 中（加 GRL 分支） | 训练中 | 过强的域不变约束伤害判别力 |
| 再加权/密度比 | 预防型 | 低-中 | 训练中 | 密度比估计在高维不稳 |
| 混合数据 + 通用回放 | LLM 场景最实用 | 低（只调配比） | 微调期 | 配比不当则两头不讨好 |
| 适配器隔离（adapter/LoRA 路由） | 结构性预防 | 低 | 架构设计 | 需要路由或显式开关 |

## 六、常见误区

1. **「多源迁移总比单源好」**：无关或噪声源会摊薄梯度方向，多源必须先做源筛选或贡献度加权，否则负迁移随源数量线性累积。
2. **「迁移涨不了点但也没掉点，就不算负迁移」**：机会成本也是负迁移——被源域先验锁进错误盆地后，目标域可用上限被压低，需与 from-scratch 上限对比才能发现。
3. **「域间隙大就一定负迁移」**：间隙大是风险而非判决，概念对齐（$Y|X$ 一致）时跨域迁移依然有效；真正致命的是标签语义冲突，光看 $P(X)$ 差异会误判。
4. **「加了 DANN 就免疫负迁移」**：对抗对齐只处理协变量偏移，处理不了任务方向相反的梯度冲突；且判别器训练不稳时会把有用特征一起抹掉。
5. **「垂直微调掉了通用能力不是负迁移」**：这属于**反向负迁移**——目标域训练伤害了保留任务（通用能力作为旧任务被遗忘），必须把通用 benchmark 一并纳入回归测试。
6. **「相似度阈值是通用常数」**：阈值依赖模型规模、学习率与目标任务数据量，必须在自己的任务集上用对照实验校准，不能照搬论文数值。

## 八、面试题

1. **什么是负迁移？如何定义「源域伤害了目标域」？**
   要点：给出对照定义 $\Delta = \mathrm{Perf}(\text{迁移}) - \mathrm{Perf}(\text{从头}) < 0$；强调必须有 from-scratch 基线与多随机种子，否则方差会掩盖真实倒退；补充机会成本型负迁移。
2. **训练前有哪些低成本手段预测负迁移？**
   要点：对抗验证（域判别 AUC）、线性探测/frozen-feature probe、任务聚类与梯度相似度、源域质量与配比审查。说明每种手段测的是 $P(X)$ 还是 $Y|X$ 层面的差异。
3. **DANN 是怎么缓解负迁移的？它的局限？**
   要点：特征提取器 + 域判别器 + 梯度反转，极小极大目标压域间隙；局限是只对付协变量偏移、对概念偏移无效，且强域不变约束可能损失判别特征。
4. **LLM 垂直微调（如医疗/法律）中，负迁移有哪些具体表现？**
   要点：与源域标签语义冲突导致模板化错误、通用 benchmark 回退（反向负迁移）、混入不相关语料导致指令跟随能力退化；缓解靠回放配比、小学习率、LoRA 隔离、逐任务回归测试。
5. **多任务训练中如何在线检测任务互相拖累？**
   要点：监控两两任务梯度余弦相似度，长期为负即冲突；PCGrad/GradVac 等梯度手术做投影，或对冲突任务降权、拆分训练。
6. **什么时候应该干脆不用预训练源、直接从头训？**
   要点：对抗验证 AUC 高 + 概念语义冲突 + 目标域数据充足（足以自举）+ from-scratch 对照不输迁移时；反之数据稀缺则优先迁移并配套域对齐。

## 九、演进与趋势

早期迁移学习（2010 年代）默认正收益，研究重心是「怎么迁得更快」（预训练 + 微调范式）。2016 年 DANN 把域对抗做成标准组件，2019 年 Wang et al. 首次系统刻画负迁移并提出任务聚类式选源，把问题从「是否迁移」推进到「**选择性迁移**」。2020 年后理论侧给出迁移风险界的更精细分析，揭示 $\lambda$（任务不相容度）的决定性作用。大模型时代重心再次转移：预训练基座的先验极强，负迁移更多以「**垂直微调中的能力回退**」形态出现——社区转向参数高效微调（LoRA/adapter 天然限制破坏半径）、数据配比调优（DoReMi 式 mixture weighting 即源数据再加权）、以及持续学习式的回放防遗忘。当前趋势是把负迁移检测做成**训练管线的自动门控**：训练前对抗验证与小规模对照，训练中梯度冲突监控与损失告警，训练后通用 + 垂直双评测回归；迁移决策从经验直觉变成可观测、可止损的工程流程。

## 十、小结

负迁移的本质是源域先验与目标任务的最优假设不相容，却被强行写入参数。理论上看，它由迁移风险界中的任务不相容项 $\lambda$ 决定；工程上看，它在标签语义冲突、源域噪声、配比失衡与概念偏移四类场景中集中爆发。防线应当分三层：**训练前**用对抗验证、线性探测与 from-scratch 对照做源筛选；**训练中**用梯度余弦、损失轨迹做在线告警与再加权；**训练后**用垂直 + 通用双评测确认没有「按下葫芦浮起瓢」。对 LLM 垂直微调，最实用的组合是「相关源数据 + 少量通用回放 + LoRA 隔离 + 回归测试」。一句话记住：**迁移的价值不在于用了多少源数据，而在于淘汰了多少错误的源数据**。
