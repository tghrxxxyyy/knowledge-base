# 提示作为适配

> 见「迁移与元学习深入/少样本与元学习」与「提示工程深入/少样本提示」。

## 一、背景与挑战

不改权重如何让模型适配新任务？

## 二、核心原理

用 few-shot 示例或可学习 soft prompt（Prompt Tuning）引导模型，权重冻结，实现轻量迁移。

## 三、关键要点

- soft prompt 可训练、参数量小。
- 硬示例即上下文迁移。

## 四、代码实现

```python
soft_prompt = nn.Parameter(randn(k, d)); emb = cat(soft_prompt, x_emb)
```

## 五、与其他对比

- 微调动权重；prompt 动输入。

## 六、常见误区

- prompt 总有效——小模型难学。

## 七、与开源书对应

- Lester et al., *Prompt Tuning*, 2021.
- llm-course: https://github.com/mlabonne/llm-course

## 十、小结

提示是零权重迁移。
