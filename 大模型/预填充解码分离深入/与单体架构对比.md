# 分离与单体架构对比

> 对应 Zhong et al., DistServe, 2024（分离收益实证）。

## 一、背景与挑战

单体把 prefill/decode 同实例时分复用，简单但互相拖累 SLO。

## 二、核心原理

单体：请求混跑，prefill 大块占算致 decode TPOT 抖动；分离：各池纯负载、互不干扰、分别扩缩。

## 三、数学形式

单体 TPOT 方差大（被 prefill 抢占）；分离 TPOT 稳定，吞吐常更高（同 SLO 下）。分离有效吞吐 $U_{sep}=\frac{B_{tok}}{L_{decode}+L_{kv}}$。

## 四、代码实现

```python
# 单体：同一 engine 混跑
out = engine.generate(prompt, stream=True)
# 分离：见前两节
```

## 五、与其他对比

- 分离增 KV 传输成本但换 SLO；
- 与 弹性推理自动伸缩深入 协同扩缩。

## 六、常见误区

- 小流量上分离收益不抵传输开销；
- 忽略网络拓扑（KV 走慢链路）。

## 八、面试题

- 何时选分离？答：高并发、强 SLO、prefill/decode 负载差异大时。

## 九、演进

单体 → 伪分离（队列） → 物理分离。

## 十、小结

分离以 KV 传输换 SLO 稳定性，适合大规模服务。
