# 解码阶段特性

> 对应 decode 自回归剖析；与 KV缓存优化深入 衔接。

## 一、背景与挑战

decode 每步仅算一个 token，矩阵乘小、受 KV/权重 HBM 带宽限制，吞吐靠并发。

## 二、核心原理

每步 $Q\in\mathbb R^{1\times d}$ 与全 KV 相乘，计算少但带宽大；靠大 batch 提升 MFU；受 KV 缓存容量约束。

## 三、数学形式

每步 FLOPs $O(d^2)$ 但读 $O(L\cdot d)$ KV；算术强度低 → 带宽瓶颈。

## 四、代码实现

```python
for _ in range(steps):
    logits, kv = model.step(last_id, kv)   # 增量
```

## 五、与其他对比

- 与 prefill（算密集）互补；
- 与 连续批处理深入 共提吞吐。

## 六、常见误区

- 小 batch decode 极浪费带宽；
- 忽视 KV 增长致 OOM 截断。

## 八、面试题

- decode 为何带宽密集？答：每步读全部 KV 而计算极少，算术强度低。

## 九、演进

自回归 → 连续批 → 分离 decode 池。

## 十、小结

decode 受带宽与 KV 容量限制，靠并发提效。
