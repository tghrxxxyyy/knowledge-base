# 两阶段调度

> 对应 DistServe 两池调度；与 弹性推理自动伸缩深入 衔接。

## 一、背景与挑战

分离后需分别按 TTFT 与 TPOT 目标调度两池资源。

## 二、核心原理

请求先入 prefill 队列（按 prompt 长排队），完成后 KV 入 decode 池（按算力/KV 容量）；可弹性增减各池 GPU 数。

## 三、数学形式

目标：$P(TTFT<\tau_1)$ 与 $P(TPOT<\tau_2)$ 同时满足；两池容量独立优化。

## 四、代码实现

```python
prefill_q.push(req); kv = prefill_q.pop().run()
decode_pool.dispatch(kv)
```

## 五、与其他对比

- 优于混合调度对 SLO 的耦合；
- 与 树形投机解码深入 在 decode 侧叠加。

## 六、常见误区

- 两池比例静态失配负载；
- KV 传输阻塞挤占 decode 带宽。

- 两阶段如何调度？答：按 TTFT/TPOT 双目标分别排队与扩缩两池。

## 九、演进

全局队列 → 双队列 → 弹性双池。

## 十、小结

两阶段调度以双目标独立优化提升整体 SLO 达成。
