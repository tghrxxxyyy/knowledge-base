# 继续预训练数据去重与过滤

> 对应 Lee et al., *Deduplicating Training Data*, 2021；数据高效学习深入 衔接。

## 一、背景与挑战

重复数据放大偏见/过拟合，低质噪声拉低继续预训；需去重与过滤。

## 二、核心原理

用后缀数组/MinHash 做精确与近似去重；用分类器/困惑度滤低质；按任务目标保留高相关。

## 三、数学形式

文档相似 $J(A,B)=|A\cap B|/|A\cup B|$；去重阈值 $J>\tau$ 合并；困惑度 $PPL<D$ 保留。

## 四、代码实现

```python
from datasketch import MinHashLSH
lsh.insert(key, minhash(doc))      # 近似去重
```

## 五、与其他对比

- 与 合成数据质量深入（质量过滤）共享。
- 与 训练数据质量（去重增益）对照。

## 六、常见误区

- 去重过严丢必要多样。
- 用模型自身 PPL 过滤致分布偏置。

## 八、面试题

- 问：去重为何重要？答：重复样本加权偏见、过拟合、浪费算力，去重提效且降偏。

## 九、演进
