# 持续预训练总览

> 对应 Gururangan et al., *Don't Stop Pretraining*, 2020；持续预训练数据深入。

## 一、背景与挑战

通用预训练知识滞后/缺领域；继续在领域或新语料上预训练可提领域能力。

## 二、核心原理

在已训模型上用领域/新数据继续自监督（MLM/CLM）；关键是数据配比、学习率热身与灾难遗忘防控。

## 三、数学形式

继续损失 $\mathcal L_{CPT} = \sum_{x\in D_{new}} -\log p_\theta(x)$；常混合旧数据比例 $\lambda$ 防遗忘。

## 四、代码实现

```python
trainer = Trainer(model=model, train_dataset=domain_data,
                  args=TrainingArguments(learning_rate=2e-5, num_train_epochs=1))
trainer.train()
```

## 五、与其他对比

- 比从头训省算力；比 SFT 更底层（改知识而非指令）。
- 与 知识编辑深入（局部改）对照（此处整体注入）。

## 六、常见误区

- 学习率沿用预训练致灾难遗忘。
- 只喂领域数据丢通用能力。

## 七、与开源书对应

- rasbt/LLMs-from-scratch：https://github.com/rasbt/LLMs-from-scratch

## 八、面试题

- 问：继续预训练为何降学习率？答：模型已接近最优，大学习率破坏已有知识（灾难遗忘）。

## 九、演进

静态预训 → 领域继续预训 → 数据配比自适应。

## 十、小结

持续预训练是注入新知识/领域能力的高效手段，须配比防遗忘。
