# 继续预训练实践与陷阱

> 对应工程经验（学习率/优化器/检查点）；训练不稳定诊断深入 衔接。

## 一、背景与挑战

继续预训易训崩或退化，需稳训策略。

## 二、核心原理

用较小学习率、warmup+余弦衰减、保持优化器状态（如 Adam 动量）从检查点续训；混合 replay 旧数据。

## 三、数学形式

学习率 $\eta_{cpt} \ll \eta_{pt}$；replay 比例 $r$ 控遗忘：$D_{mix}=(1-r)D_{new}+r D_{old}$。

## 四、代码实现

```python
args = TrainingArguments(lr_scheduler_type="cosine", learning_rate=1e-5,
                         warmup_ratio=0.03, resume_from_checkpoint=True)
```

## 五、与其他对比

- 与 SFT 训练（更大 lr）对照，继续预训更保守。
- 与 训练不稳定诊断深入 共享稳训法。

## 六、常见误区

- 从头初始化优化器状态致不稳。
- 不 replay 旧数据致灾难遗忘。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh
- rasbt/LLMs-from-scratch：https://github.com/rasbt/LLMs-from-scratch

## 八、面试题

- 问：为何从检查点续优化器状态？答：保留动量/二阶估计，避免训练动力学突变致不稳。

## 九、演进

固定 lr → warmup 衰减 → replay 自适应。

## 十、小结

继续预训稳训靠小 lr+状态续训+replay，工程细节决定成败。
