# 领域自适应继续预训练

> 对应医学/法律领域 CPT（如 PubMedBERT, Legal-BERT）；领域适配深入 衔接。

## 一、背景与挑战

通用模型在专域词表/术语/分布上弱；需专域继续预训提下游。

## 二、核心原理

在专域语料（论文/法条/代码）继续预训，常配合专域词表扩展与两阶段（领域→任务）策略。

## 三、数学形式

领域困惑度下降 $\Delta PPL = PPL_{gen}-PPL_{dom}$；下游指标随领域继续预训升。

## 四、代码实现

```python
model.resize_token_embeddings(len(new_vocab))
trainer.train(domain_corpus)        # 专域继续预训
```

## 五、与其他对比

- 比领域 SFT 更底层地吸收术语分布。
- 与 词表与分词深入（词表扩展）配合。

## 六、常见误区

- 专域过训丢通用推理。
- 忽略专域数据质量（噪声多）。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh
- rasbt/LLMs-from-scratch：https://github.com/rasbt/LLMs-from-scratch

## 八、面试题

- 问：领域 CPT 为何常两阶段？答：先领域语料吸分布，再任务数据对齐，避免直接任务过拟合。

## 九、演进

通用 → 单域 → 多域混合 CPT。

## 十、小结

领域自适应 CPT 是专域落地的关键，须配词表与防退化。
