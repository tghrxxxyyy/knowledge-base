# 伪量化节点与模拟量化

> 对应 pytorch/pytorch 的 FakeQuant 节点与 NVIDIA/TensorRT-LLM 的 QAT 流程。

## 一、背景与挑战

要在训练中模拟部署时的量化效果，需要在计算图插入伪量化节点，覆盖权重与激活，使前向数值与推理一致。

## 二、核心原理

伪量化节点在前向做 quant-dequant（引入舍入误差与截断），反向用 STE。训练框架（如 PyTorch FX 量化）自动在合适位置插入这些节点，训练后导出真实量化图。

## 三、形式化与数学基础

对激活 $ a $：

$ \\tilde a=s_a\\cdot \\text{round}(\\text{clip}(a/s_a, -L, L)) $

权重同理 $ \\tilde w $。前向用 $ \\tilde w,\\tilde a $ 计算，损失回传经 STE。

## 四、代码实现

```python
import torch

def insert_fakequant(module, bits=4):
    # 概念: 对 Linear 权重与输入包一层伪量化
    orig = module.forward
    def f(x):
        wq = fake_quant(module.weight, bits)
        xq = fake_quant(x, bits)
        return torch.functional.linear(xq, wq, module.bias)
    module.forward = f
    return module
# 训练若干步后导出真实量化
```

## 五、与其他技术对比

- 伪量化只训练用，导出的推理图不再含 STE。
- 与 PTQ 不同，QAT 的量化参数（scale）可在训练中学习（LSQ）。

## 六、常见误区

- 训练与推理量化配置不一致，导致精度掉点。
- 忘记对激活也做伪量化，只量化权重。
