# 组合生成与属性绑定

> 对应 组合文生图研究（如 Rassin et al. 2022 「Latent Diffusion」组合性、及属性绑定问题）。

## 一、背景与挑战

文本到图像常把属性错误绑定（「红杯蓝书」生成为「蓝杯红书」），即组合性失败。根因在于训练目标对全局匹配友好、对局部属性-实体绑定弱。挑战是评测与训练纠偏。

## 二、核心原理

方法包括：布局引导（先生成物体框再填内容）、注意力约束（把特定词 attention 聚焦对应区域）、组合损失（对比不同属性组合）、以及用结构化 prompt（实体-属性对）增强。CFG 也可分属性分别引导。

## 三、数学形式

属性绑定可建模为约束：区域 r_k 的特征应与属性词 a_k 对齐。以注意力图 A_{t,k} 表示词 t 在区域 k 权重，期望：
\max_{k} A_{a_k,k} > \max_{j\neq k} A_{a_k,j}
组合对比损失拉大正确组合与错误组合的得分差。

## 四、代码实现

```python
def attr_contrast(logits_correct, logits_swap, margin=0.5):
    # 正确属性组合得分应高于置换组合
    return torch.relu(margin - (logits_correct - logits_swap)).mean()
```

## 五、与其他对比

相比纯文本引导，布局/注意力约束更精确；相比 ControlNet 需结构图，属性法只改文本；组合损失训练更对齐但需配对数据。

## 六、常见误区

以为长 prompt 自动解绑定；忽略注意力泄漏；混淆组合性与保真度；未用量化评测（如 attr. accuracy）。

## 八、面试题

- Q：组合性失败表现？答：属性错绑，如颜色物体错位。
- Q：缓解方法？答：布局引导、注意力约束、组合对比损失。
- Q：如何评测？答：属性准确率、swap 一致性。

## 九、演进

从提示工程到训练期组合损失；结构化布局扩散；与 LLM 先生成布局再生成图。

## 十、小结

组合生成暴露了扩散模型属性绑定的弱点，布局引导与注意力/损失约束是提升可控组合的主流路径。
