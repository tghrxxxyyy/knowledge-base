# 投机解码调度与收益

> 对应在线服务加速分析；与 推理调度深入 / 连续批处理深入 衔接。

## 一、背景与挑战

实际加速受草稿质量、序列长度、批大小影响，需合理调度。

## 二、核心原理

加速比 $\approx \frac{k\cdot R}{1+c_{verify}/c_{draft}}$，其中 $R$ 接受率；小批/长序列收益大。

## 三、数学形式

每步产出 $E[N]\approx \frac{1-\gamma^k}{1-\gamma}$（$\gamma$ 为单步接受率）token/验证。

## 四、代码实现

```python
# 自适应草稿长度
k = clamp(int(target_latency/draft_latency), 1, K)
```

## 五、与其他对比

- 与 KV缓存优化、连续批处理共同决定端到端延迟。
- 与 推理经济成本深入 衔接（省算力）。

## 六、常见误区

- 大批量时加速被批并行摊薄。
- 忽视草稿模型显存占用。
