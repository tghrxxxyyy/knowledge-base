# 验证与接受准则

> 对应无损接受采样数学。

## 一、背景与挑战

需保证投机生成与自回归目标分布完全相同（无损）。

## 二、核心原理

对每个位置用接受准则 $a_t=\min(1,p_t/q_t)$ 决定采纳草稿 token；拒绝处从修正分布采样，保证边际等于 $p$。

## 三、数学形式

修正分布：$p'(x)=p(x)-q(x)$ 归一化（当 $p>q$），否则沿用草稿；整体等价于从 $p$ 采样。

## 四、代码实现

```python
r = torch.rand_like(p)
accept = r <= p / q
x = where(accept, draft, sample((p-q).clampmin(0)))
```

## 五、与其他对比

- 与 自回归生成深入 采样策略共享（最终分布=目标）。
- 与 推理服务深入 衔接（延迟）。

## 六、常见误区

- 实现接受准则忽略归一化致分布偏移。
- 树投机未正确聚合分支概率。
