# 树状投机解码

> 对应 Tree-based Speculative Decoding（如 EAGLE-2, DeepMind）。

## 一、背景与挑战

线性草稿只猜一条链，树状并行猜多分支提升接受期望。

## 二、核心原理

草稿生成候选树（多可能续写），目标一次验证整棵树，按接受路径选最长正确前缀。

## 三、数学形式

树节点带概率，验证后沿接受边取最长链；期望接受长度随分支数提升。

## 四、代码实现

```python
tree = draft_tree(x, depth, width)
logits = target(x, tree.flatten())
path = select_accepted_path(tree, logits)
```

## 五、与其他对比

- 比线性投机接受更多 token/步，但验证计算更高。
- 与 自回归生成深入 共享结构。

## 六、常见误区

- 分支过多致验证开销超过收益。
- 树结构需与 KV 缓存兼容（见 KV缓存优化深入）。

## 八、面试题

- 树状投机为何更快？答：一次验证多分支，提高每步接受 token 数期望。

## 九、演进

线性 → 树状 → 自适应宽度树。

## 十、小结

树状投机以分支并行提升吞吐，是投机解码的高效变体。
