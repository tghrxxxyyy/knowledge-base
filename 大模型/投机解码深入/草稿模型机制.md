# 草稿模型机制

> 对应 draft-target 框架。

## 一、背景与挑战

草稿质量决定接受率与提速；需又快又准。

## 二、核心原理

草稿可为更小模型、同模型浅层、或额外预测头（Medusa：多头并行猜未来若干位置）。

## 三、数学形式

草稿分布 $q$，目标 $p$；接受 $a_t=\min(1, p_t/q_t)$；若拒绝，从修正分布 $(p-q)^+$ 采样。

## 四、代码实现

```python
# 同模型浅层作草稿
draft_out = shallow(x)       # 前几层
target_out = full(x)
```

## 五、与其他对比

- Medusa 头比独立草稿更易对齐（同 backbone）。
- 与 自回归生成深入 共享解码循环。

## 六、常见误区

- 草稿大模型反而慢（验证成本盖过收益）。
- 忽视草稿与目标温度/采样设置一致性。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- 草稿模型如何选？答：比目标小且分布相近，接受率高、单次廉价。

## 九、演进

独立小模型 → 浅层草稿 → 多头/树投机。

## 十、小结

草稿机制是投机解码效率核心，质量与速度须平衡。
