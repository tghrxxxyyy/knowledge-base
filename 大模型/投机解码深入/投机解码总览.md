# 投机解码总览

> 对应 Leviathan et al., *Speculative Decoding*, 2023；Chen et al., *Medusa*, 2023。

## 一、背景与挑战

自回归逐 token 生成串行、GPU 利用率低；投机解码用草稿模型并行猜多 token 再验证。

## 二、核心原理

小草稿模型（draft）并行出 $k$ 个候选，大目标模型一次前向验证全部；接受正确前缀，拒绝处重采样。

## 三、数学形式

接受概率 $p_{accept}=\min(1, p_{target}(x)/p_{draft}(x))$；期望加速取决于接受率与模型速度比。

## 四、代码实现

```python
drafts = draft_model(x, k)        # 并行猜 k
logits = target_model(x, drafts)  # 一次验证
n = sample_accept(logits, drafts)
```

## 五、与其他对比

- 不改输出分布（无损），区别于蒸馏/小模型。
- 与 KV缓存优化深入 / 连续批处理深入 互补加速。

## 六、常见误区

- 草稿模型太弱致接受率低、反拖慢。
- 误以为投机解码改变分布（它是无损的）。

## 八、面试题

- 投机解码为何无损？答：用接受准则保证与目标模型分布一致。

## 九、演进

草稿模型 → 自草稿头（Medusa/EAGLE）→ 树状投机。

## 十、小结

投机解码以草稿+验证并行生成多 token，无损且显著提速。
