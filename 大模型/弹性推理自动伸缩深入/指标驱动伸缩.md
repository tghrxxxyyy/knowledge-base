# 指标驱动伸缩

> 对应 KEDA 自定义指标伸缩；与 推理服务可观测性深入 衔接。

## 一、背景与挑战

默认 CPU 指标不适配推理；需用领域指标（队列、并发、TPOT）驱动。

## 二、核心原理

从 Prometheus/队列暴露自定义指标，HPA/KEDA 据目标值算副本；支持多指标取最大。

## 三、数学形式

$R=\max_k \lceil \frac{m_k}{\text{target}_k}\rceil$；多指标取上界防任一饱和。

## 四、代码实现

```python
# KEDA ScaledObject 读 Prometheus 查询
metric: avg_queue_len target: 8
```

## 五、与其他对比

- 与 推理服务可观测性深入（指标来源）闭环；
- 与 与K8sHPA对比深入 衔接。

## 六、常见误区

- 指标周期滞后致抖动；
- 目标值设错致频繁伸缩。
