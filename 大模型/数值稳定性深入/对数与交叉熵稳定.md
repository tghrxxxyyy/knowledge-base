# 对数与交叉熵稳定

> 见「数值稳定性深入/数值稳定性总览」与「损失函数设计深入」；log(0) 之坑。

## 一、背景与挑战

交叉熵含 log(softmax)，易 log(0) 或数值不稳。

## 二、核心原理

用 **log_softmax** 直接计算（融合 softmax 与 log，数值更稳）或 `CrossEntropyLoss`（内部融合）。避免先算 softmax 再取 log 的两步误差/溢出。PyTorch 的 CrossEntropyLoss 已对 logits 做稳定处理。

## 三、数学形式

`CE = -log(softmax(z)_y)`；用 log_softmax 防溢出。

## 四、代码实现

```python
loss = F.cross_entropy(logits, y)   # 内部稳定
# 不要手动: -log(softmax(logits))
```

## 五、关键要点

- 用融合实现而非两步。
- 标签平滑也要配稳定实现。

## 六、与其他对比

- 两步易溢；融合稳。

## 七、常见误区

- 手动 softmax+log——不稳且慢。
