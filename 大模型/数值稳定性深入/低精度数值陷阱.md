# 低精度数值陷阱

> 见「数值稳定性深入/数值稳定性总览」与「混合精度训练深入」；低位宽放大问题。

## 一、背景与挑战

fp16/bf16 下舍入误差被放大。

## 二、核心原理

低精度下：小梯度下溢、累加顺序误差、softmax/exp 更易溢出、归一化统计量失真。对策：主权重/统计量/敏感层保持 fp32（见混合精度章）、用 bf16（范围大）、监控 NaN。突加混合精度常先出 NaN 即此因。

## 三、关键要点

- 敏感算子强制 fp32。
- bf16 比 fp16 省心。

## 四、代码实现

```python
with torch.autocast('cuda', dtype=torch.bfloat16): ...
# 归一化/softmax 内部 fp32
```

## 五、与其他对比

- fp32 稳但慢；低精度快但坑。

## 六、常见误区

- 低精度无脑——敏感层必 fp32。
