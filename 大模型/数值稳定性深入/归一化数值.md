# 归一化数值稳定

> 见「数值稳定性深入/数值稳定性总览」与「批归一化深入」；除零与方差。

## 一、背景与挑战

归一化中方差近 0 致除零/放大。

## 二、核心原理

加 `ε`（小常数）到方差防止除零：`(x-μ)/√(σ²+ε)`。ε 需合理（过大使归一化失效、过小仍不稳）。LayerNorm/RMSNorm 同理。混合精度下建议 EPS 用 fp32 计算防下溢。

## 三、数学形式

`y = (x-μ)/√(σ²+ε)·γ+β`。

## 四、代码实现

```python
var = var.float() + eps    # fp32 下 eps 更稳
```

## 五、关键要点

- ε 防除零也防放大。
- 混合精度 eps 用 fp32。

## 六、与其他对比

- 无 ε 危险；ε 保稳。

## 七、常见误区

- ε 随便设——影响幅度。
