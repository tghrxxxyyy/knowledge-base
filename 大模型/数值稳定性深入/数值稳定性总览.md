# 数值稳定性总览

> 对应 d2l-zh 数值稳定性章；浮点计算中的隐坑。

## 一、背景与挑战

浮点有限精度使某些运算结果失真甚至爆炸/归零。

## 二、核心原理

关键现象：**上溢**（超大→Inf）、**下溢**（趋零→0）、** catastrophic cancellation**（相近数相减丢有效数字）、**灾难性舍入积累**。深度学习需在每个数值敏感处做稳定化（见 softmax/归一化章节）。

## 三、关键要点

- fp32 也非万能，bf16 范围更大。
- 稳定技巧处处可用。

## 四、代码实现

```python
x = x - x.max()          # softmax 防上溢
```

## 五、与其他对比

| 问题 | 表现 |
|------|------|
| 上溢 | Inf |
| 下溢 | 0 |
| 相消 | 精度失 |

## 六、常见误区

- 浮点精确——有限精度有坑。
