# 噪声鲁棒偏好优化

> 对应 Chowdhury et al., *Provably Robust DPO: Aligning Language Models with Noisy Feedback*, ICML 2024；标签平滑式保守 DPO 亦见于 DPO 作者的后续讨论。

## 一、背景与挑战

真实偏好标注的一致率通常远低于 100%：主观题上人类之间就会分歧，AI 反馈还会带系统性偏好（偏长、偏格式化）。DPO 的 logistic 损失对翻转标签极不友好——一个被标反的对会持续推动策略朝错误方向，且由于损失无界，错误方向的梯度不会自动衰减。

## 二、核心原理

两条主线。第一条是标签平滑（保守 DPO）：假设标签以概率 $\epsilon$ 被翻转，于是把损失写成两个方向的凸组合，使最优解不再把概率比推向无穷。第二条是去偏估计（rDPO）：在已知或可估计翻转率 $\epsilon$ 的前提下，构造对干净分布无偏的损失估计量，从而给出可证明的次优性上界。工程上还常配合数据侧治理：多标注投票、置信度过滤、丢弃差异过小的对。

## 三、数学形式

记 $\ell(x,y_w,y_l)=-\log\sigma(\beta h_\theta)$ 为标准 DPO 损失。保守（标签平滑）版本：

$$\mathcal L_{cDPO}=(1-\epsilon)\,\ell(x,y_w,y_l)+\epsilon\,\ell(x,y_l,y_w)$$

去偏（rDPO）版本用 $\dfrac{1}{1-2\epsilon}$ 做重标定，得到对干净损失的无偏估计：

$$\mathcal L_{rDPO}=\frac{(1-\epsilon)\,\ell(x,y_w,y_l)-\epsilon\,\ell(x,y_l,y_w)}{1-2\epsilon}$$

要求 $\epsilon<1/2$，否则偏好信号本身失去方向性。

## 四、代码实现

```python
import torch.nn.functional as F

def dpo_terms(lp_w, lp_l, ref_w, ref_l, beta=0.1):
    h = (lp_w - ref_w) - (lp_l - ref_l)
    fwd = -F.logsigmoid(beta * h)      # 正向：认为 w 更优
    rev = -F.logsigmoid(-beta * h)     # 反向：认为 l 更优
    return fwd, rev

def cdpo_loss(lp_w, lp_l, ref_w, ref_l, beta=0.1, eps=0.1):
    fwd, rev = dpo_terms(lp_w, lp_l, ref_w, ref_l, beta)
    return ((1 - eps) * fwd + eps * rev).mean()

def rdpo_loss(lp_w, lp_l, ref_w, ref_l, beta=0.1, eps=0.1):
    assert 0 <= eps < 0.5
    fwd, rev = dpo_terms(lp_w, lp_l, ref_w, ref_l, beta)
    return (((1 - eps) * fwd - eps * rev) / (1 - 2 * eps)).mean()
```

## 五、与其他对比

- 相对 IPO：IPO 治损失无界，噪声鲁棒方法治标签错误；二者正交，可叠加使用。
- 相对「数据清洗」：清洗降低 $\epsilon$，鲁棒损失容忍残余 $\epsilon$，生产上通常两者并用。
- 与 奖励模型过优化与奖励黑客深入：标注噪声会被过优化放大，鲁棒损失同时降低了被噪声方向黑客化的风险。

## 六、常见误区

- 把 $\epsilon$ 当作可随意调的正则强度。它应来自标注一致率的实测（如双标注不一致比例），估偏会引入新偏差。
- rDPO 在 $\epsilon$ 接近 0.5 时方差爆炸，此时应回退到清洗与重标注，而不是硬套公式。
- 只在训练侧做鲁棒化，却不监控验证集上的偏好准确率，无法判断噪声是否真被抑制。

## 八、面试题

- 为什么 DPO 对标签噪声敏感？答：logistic 损失无界，错误方向的梯度不会自动衰减，且确定性偏好上会无限外推。
- cDPO 与 rDPO 的差别？答：前者是凸组合形式的标签平滑，得到有界保守解；后者是带 $1/(1-2\epsilon)$ 重标定的无偏估计，可给出理论保证但方差更大。

## 九、演进

假设标签干净的 DPO → 标签平滑保守化 → 已知翻转率的无偏去偏估计 → 与主动学习、置信度加权的联合治理。

## 十、小结

偏好噪声是对齐工程中最被低估的误差源；用实测一致率驱动的鲁棒损失，配合数据侧清洗与监控，才能让偏好优化的收益真实落地。
