# 张量并行与结构约束

> 对应 Megatron-LM 切分约束；Shoeybi et al., 2019。

## 一、背景与挑战

并非任意层都能随意切分，需满足线性代数恒等式以保持数值等价。

## 二、核心原理

只有满足 $g(f(X)A)$ 可分解为逐卡独立 $f$ 再加和的算子链才能切；LayerNorm、Dropout、残差加法需先聚合或改由序列并行处理，否则破坏语义。

## 三、数学形式

要求 $Y=\sum_i f_i(X)A_i$ 且 $f_i$ 在分片上可算；归一化 $Norm(X)$ 不在该形式，需 all_gather 输入。

## 四、代码实现

```python
# LayerNorm 前需先聚合序列分片
x_full = gather_along_seq(x_shard, sp_group)
h = layer_norm(x_full)
```

## 五、与其他对比

- 与 序列并行深入 协作处理归一化/ dropout 的切分。
- 与 专家并行深入 在 MLP 处替换结构。

## 六、常见误区

- 在归一化前直接切序列维导致统计量错误。
- 忽略残差连接需两端同形。

## 八、面试题

- 哪些算子不能直接张量并行？答：LayerNorm/Dropout/softmax 需先聚合或交由序列并行。

## 九、演进

权重合切 → 归一化改序列并行 → 自动切分搜索。

## 十、小结

张量并行受结构约束，归一化类算子需序列并行协作才完整。
