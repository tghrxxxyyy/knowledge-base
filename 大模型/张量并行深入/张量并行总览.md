# 张量并行总览

> 对应 Shoeybi et al., 《Megatron-LM: Training Multi-Billion Parameter Language Models Using Model Parallelism》, 2019。

## 一、背景与挑战

单卡显存放不下超大模型权重、优化器状态与激活；张量并行（模型并行）把单层权重沿行列切到多卡，单卡只持有一部分。

## 二、核心原理

把一个大矩阵乘法 $Y=XA$ 按 $A$ 的列或行切分，使每张卡计算局部结果再通信合并；Transformer 的注意力与 MLP 均可如此切分，且能把恒等变换的通信合并。

## 三、数学形式

列并行：$A=[A_1,A_2]$，$Y=[XA_1,XA_2]$；行并行输入先需 $all\_gather$ 或直接接列并行输出做 $all\_reduce$：$Y=\sum_i X_i A_i$。

## 四、代码实现

```python
import torch.distributed as dist
# 列并行：每张卡持有 A 的一部分
y_i = torch.matmul(x, a_shard)        # 局部
y = torch.empty_like(y_i)
dist.all_reduce(y_i, op=dist.ReduceOp.SUM, group=tp_group)
```

## 五、与其他对比

- 与 数据并行深入（复制完整参数）互补；张量并行切单层、通信频繁但单卡显存小。
- 与 流水线并行深入（切层）组合构成 3D 并行。

## 六、常见误区

- 切分违反计算依赖（如 LayerNorm 前切序列维）会破坏数值等价。
- 张量并行通信密度高，跨节点带宽不足时成瓶颈。

## 八、面试题

- 张量并行如何减少单卡显存？答：单层权重被切分，每卡仅存部分权重与对应激活。

## 九、演进

朴素模型并行 → Megatron 行列并行 → 与序列并行组合。

## 十、小结

张量并行按矩阵维度切分单层，是突破单卡显存上限的基础手段，但通信密集。
