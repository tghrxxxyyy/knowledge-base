# 张量并行显存分析

> 对应 ZeRO/Megatron 显存分解；Rajbhandari et al., 《ZeRO》, 2020。

## 一、背景与挑战

需量化张量并行省下的显存，判断能否放下模型。

## 二、核心原理

参数量随并行度 $t$ 降为 $1/t$；激活因切分也降；优化器状态若不切仍占主导，故 TP 常与 ZeRO/TP 组合进一步省优化器显存。

## 三、数学形式

单卡参数显存 $\approx \frac{\phi}{t}\cdot(2\sim4)$ 字节（$\phi$ 总参数）；优化器（Adam）约 $12\phi/t$ 若随 TP 切。

## 四、代码实现

```python
param_gb = phi * 2 / tp_size / 1e9          # bf16 权重
optim_gb = phi * 12 / tp_size / 1e9         # 若优化器状态也切
```

## 五、与其他对比

- 与 数据并行深入（参数复制、优化器复制）相反，TP 切参数。
- 与 ZeRO（切优化器状态）互补省显存。

## 六、常见误区

- 只切权重不切优化器，显存仍爆。
- 并行度过高致通信开销超过收益。

## 八、面试题

- 张量并行省哪些显存？答：权重、梯度、激活按并行度降，优化器状态需额外切分才省。

## 九、演进

仅切权重 → 权重+激活 → 与 ZeRO 组合。

## 十、小结

张量并行主要省权重与激活，优化器显存需配合分区策略。
