# 过程监督在推理中的应用

> 对应 best-of-N / beam + PRM / 树搜索；自回归生成深入 / 推理优化（目录）衔接。

## 一、背景与挑战

如何把 PRM 用于实际生成选优。

## 二、核心原理

采样多解，用 PRM 对每解步骤打分选最优；或 beam 中每步扩展按 PRM 剪枝。

## 三、数学形式

best-of-N：$y^*=\arg\max_y \sum_t \log P_{PRM}(correct|s_t)$。

## 四、代码实现

```python
cands = [generate(x) for _ in range(N)]
best = max(cands, key=lambda y: prm_path(x,y))
```

## 五、与其他对比

- 与 推理优化（best-of-N/beam）共享解码策略。
- 与 大模型数学深入（推理任务）衔接。

## 六、常见误区

- 仅 PRM 不配合最终验证，仍可能错。
- 推理时 PRM 打分显著增成本。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- PRM 如何选解？答：对每个候选按步骤分求和/乘积，选最高路径。

## 九、演进

best-of-N → beam+PRM → 树搜索(MCTS)+PRM。

## 十、小结

PRM 在解码阶段选优，显著提升推理准确率。
