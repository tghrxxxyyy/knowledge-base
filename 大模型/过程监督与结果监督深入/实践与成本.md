# 过程监督实践与成本

> 对应生产落地权衡；与 训练数据质量 / 模型评测指标深入 衔接。

## 一、背景与挑战

PRM 标注/推理成本需与收益权衡。

## 二、核心原理

仅在关键推理任务（数学/代码）用 PRM；其他用 ORM/DPO 更划算。

## 三、数学形式

净收益 $= \text{acc}_{PRM}-\text{acc}_{ORM} - \text{cost}_{label+infer}$。

## 四、代码实现

```python
if task in ("math","code"): use_prm=True
```

## 五、与其他对比

- 与 偏好优化前沿（ORM 化对齐）对照成本。
- 与 直接偏好优化深入（省 RM）对照。

## 六、常见误区

- 全任务上 PRM 致成本爆炸。
- 忽视 PRM 推理延迟。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- 何时用过程监督？答：数学/代码等可逐步验证且价值高的任务，才值标注与推理成本。

## 九、演进

全 ORM → 关键任务 PRM → 自适应监督选择。

## 十、小结

过程监督收益在推理任务最明显，须按成本谨慎部署。
