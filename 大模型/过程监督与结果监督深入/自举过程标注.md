# 自举过程标注（Bootstrap PRM）

> 对应 Lightman 2023 自举法；与 数据高效学习深入 衔接。

## 一、背景与挑战

人工标每步贵；自举用模型生成大量步骤标签降成本。

## 二、核心原理

用强模型/多数投票给中间步骤打标，训练 PRM，再迭代改进；显著降低人工量。

## 三、数学形式

标签 $y_{t}^{auto} = \text{majority}(\{M(x,s_{:t})\})$；用自动标签训 PRM。

## 四、代码实现

```python
for prob in samples_step(s): auto_label += vote(M(prob))
```

## 五、与其他对比

- 与 合成数据质量深入（自动标注质量）共享。
- 与 过程监督与结果监督深入 总览衔接。

## 六、常见误区

- 自举标签含系统错，PRM 学错；需抽样人工校验。
- 投票一致性低处仍要人工。

## 七、与开源书对应

## 八、面试题

- 为何自举 PRM？答：人工标步太贵，用模型投票批量标，降成本。

## 九、演进

全人工 → 多数投票自举 → 主动学习补难例。

## 十、小结

自举以自动标注大幅降 PRM 成本，是实用关键。
