# 长序列注意力的溢出与精度

> 对应 Dao et al., 2022（FlashAttention）；序列长度对数值与显存的影响。

## 一、背景与挑战

序列越长，分数矩阵越大，softmax 累计指数和可能超出低精度范围；同时显存与计算随 $N^2$ 增长。

长上下文训练对数值稳定性要求更高。

## 二、核心原理

分块计算 + 高精（FP32）累加中间指数和与输出，避免长序列下低精度舍入；序列并行/分片进一步降显存。

 rotary/位置编码若幅值大，也会推高 scores，需与缩放协同。

## 三、数学形式

输出精度受累加位宽影响：$\hat o=\sum_i e^{s_i-m} v_i/\ell$；FP32 累加使相对误差不随 $N$ 放大。

## 四、代码实现

with torch.amp.autocast(device_type="cuda", dtype=torch.bfloat16):
    out = flash_attn_func(q, k, v)   # 内部 FP32 累加

## 五、与其他对比

- 与 注意力稳定实现 衔接，分块是长序列解法。
- 与 混合精度溢出检测深入 衔接，长序列更需高精累加。
- 与 注意力数值稳定与溢界深入 总览呼应。

## 六、常见误区

- 长序列直接朴素 softmax，显存爆炸。
- 在 FP16 下累加长序列指数和，误差放大。
- 忽视位置编码幅值对 scores 的推高。

## 八、面试题

- 长序列为何更易溢出？答：分数矩阵大、累加项多，低精度下指数和与输出误差放大。
- 如何兼顾稳定与显存？答：分块 + FP32 累加（如 FlashAttention）。

## 九、演进

朴素 O(N^2) → FlashAttention → 线性注意力（近似）。

## 十、小结

长序列注意力须分块并以高精累加，方能在稳定与显存间兼得。
