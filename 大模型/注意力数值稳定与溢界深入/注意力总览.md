# 注意力机制数值稳定总览

> 对应 Vaswani et al., *Attention Is All You Need*, 2017（Scaled Dot-Product Attention）。

## 一、背景与挑战

注意力核心是 softmax 作用于查询-键点积。点积随维度增长幅值变大，softmax 易进入饱和区（梯度趋零）或直接 exp 上溢。

数值稳定是长序列/混合精度训练的关键。

## 二、核心原理

缩放点积：$QK^\top/\sqrt{d_k}$ 把幅值压回稳定区；softmax 再做最大值平移防 exp 溢出。

因果/掩码用加性 $-\infty$ 屏蔽未来位置，实现需小心 -inf 与数值。

## 三、数学形式

$\mathrm{Attention}=\mathrm{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$；softmax 内部需减行最大值防上溢。

## 四、代码实现

```python
scores = Q @ K.transpose(-1, -2) / d_k**0.5
attn = torch.softmax(scores, dim=-1)
out = attn @ V
```

## 五、与其他对比

- 与 损失函数数值鲁棒深入 共用 softmax 稳定技巧。
- 与 RMSNorm 数值 衔接，注意力前后常接 RMSNorm。
- 与 混合精度溢出检测深入 衔接，FP16 下 scores 更易溢。

## 六、常见误区

- 忽略缩放 $\sqrt{d_k}$，大 $d_k$ 使 softmax 饱和、梯度消失。
- 手算 softmax 不设最大值平移，溢界。
- 掩码用 0 而非 -inf，未来位置仍有微弱贡献。

## 八、面试题

- 为何除以 sqrt(d_k)？答：点积方差随 d_k 增大，缩放维持 softmax 输入方差恒定。
- 注意力数值稳定的关键？答：缩放 + softmax 最大值平移，防饱和与上溢。

## 九、演进

点积注意力 → 缩放点积 → FlashAttention（分块稳定）。

## 十、小结

注意力稳定靠缩放与 softmax 最大值平移，是 Transformer 可训的底线。
