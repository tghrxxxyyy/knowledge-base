# 缩放点积注意力

> 对应 Vaswani et al., 2017（Scaled Dot-Product Attention 的 $\sqrt{d_k}$ 缩放）。

## 一、背景与挑战

$Q,K$ 若各分量零均值单位方差且独立，点积 $q\cdot k$ 方差约为 $d_k$，随维度线性增长。

幅值过大使 softmax 进入饱和区（输出近 one-hot），梯度趋零，训练困难。

## 二、核心原理

除以 $\sqrt{d_k}$ 把点积方差拉回 1，softmax 输入分布稳定，梯度健康。该缩放不改变最大项相对顺序，仅控幅值。

维度越大，缩放越必要。

## 三、数学形式

$\mathrm{Var}(q\cdot k)\approx d_k$（独立零均值单位方差）；缩放后 $\mathrm{Var}((q\cdot k)/\sqrt{d_k})\approx 1$。

## 四、代码实现

```python
scale = d_k ** -0.5
scores = (Q @ K.transpose(-1, -2)) * scale
```

## 五、与其他对比

- 与 注意力数值稳定与溢界深入 总览衔接，缩放是第一道防线。
- 与 初始化尺度与方差传播深入 同理（控方差）。
- 与 对比损失与温度 同源（温度缩放）。

## 六、常见误区

- 用 $d_k$ 而非 $\sqrt{d_k}$ 缩放过度，致注意力过平滑。
- 多头各自维度算错，缩放因子不匹配。
- 认为缩放只影响稳定不影响表达（幅值影响熵）。

## 八、面试题

- 缩放为何用 sqrt(d_k)？答：点积方差随 d_k 线性增，sqrt 将其拉回 1。
- 不缩放会怎样？答：softmax 饱和、梯度消失，训练停滞。

## 九、演进

无缩放 → sqrt(d_k) → 可学习温度（如 softmax 温度）。

## 十、小结

缩放点积是注意力稳定的第一性原理，把幅值控回单位方差。
