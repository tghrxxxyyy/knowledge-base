# 注意力数值稳定实现

> 对应 Dao et al., *FlashAttention*, 2022（分块、在线 softmax）；框架稳定实现。

## 一、背景与挑战

朴素注意力需物化 $N\times N$ 分数矩阵并做全局 softmax，既占显存又在大 N 时数值敏感。

稳定实现需在线（流式）softmax，无需完整矩阵也能正确归一。

## 二、核心原理

在线 softmax 维护运行最大值 $m$ 与指数和 $\ell$，逐块更新：$m^{(new)}=\max(m,\mathrm{rowmax})$；用修正因子重缩放已累加项。

这样在大序列下也能数值稳定，且省显存（不物化全矩阵）。

## 三、数学形式

分块更新：$\ell^{(new)}=e^{m-m^{(new)}}\ell+\sum_j e^{s_j-m^{(new)}}$；输出累加同步重缩放。

## 四、代码实现

```python
# 简化的在线 softmax 思路（实际 FlashAttention 更细）
m = -inf; l = 0.0; o = 0.0
for blk in blocks(scores):
    m_new = max(m, blk.max())
    l = exp(m-m_new)*l + exp(blk-m_new).sum()
    o = exp(m-m_new)*o + (exp(blk-m_new) @ V_blk)
```

## 五、与其他对比

- 与 softmax溢界 衔接，在线版是其分块推广。
- 与 长序列与溢出 直接相关，分块降显存与溢界风险。
- 与 混合精度溢出检测深入 衔接，FlashAttention 内部用高精累加。

## 六、常见误区

- 以为稳定只需全局减最大值（大矩阵物化代价高）。
- 分块时忘记重缩放已累加项，结果偏。
- 在低精度下做累加，长序列误差放大。

## 八、面试题

- 在线 softmax 为何稳且省？答：流式维护 max/sum，无需物化全矩阵即可正确归一。
- 分块为何要重缩放？答：新最大值改变归一基准，旧累加项须按 exp(m-m_new) 修正。

## 九、演进

全局 softmax → 在线 softmax → FlashAttention 分块。

## 十、小结

稳定注意力靠在线/分块 softmax，兼顾数值正确与显存效率。
