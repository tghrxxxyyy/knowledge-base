# 不确定性评估基准

> 对应不确定质量度量（AUROC/NLL）；模型评测指标深入 衔接。

## 一、背景与挑战

不确定估计本身需评：它能否正确区分对错/分布外？

## 二、核心原理

用选择性预测（覆盖率-风险曲线）、OOD 检测 AUROC、预期校准误差联合评；好不确定应“错=不确定”。

## 三、数学形式

选择性风险 $R(q)=\frac{1}{|S_q|}\sum_{i\in S_q}\mathcal L_i$，$S_q$ 为置信>q 集合；曲线越下越好。

## 四、代码实现

```python
from sklearn.metrics import roc_auc_score
auc = roc_auc_score(y_wrong, uncertainty)    # 高不确定=错
```

## 五、与其他对比

- 与 模型校准深入（ECE）共享评测。
- 与 模型评测指标深入（不止准确率）对照。

## 六、常见误区

- 只看均值不确定忽略分布。
- 未测 OOD（分布内好 OOD 崩）。

## 八、面试题

- 问：如何评不确定质量？答：看它能否区分对错/OOD（AUROC）与选择性风险曲线。

## 九、演进

直观 → 选择性预测 → OOD+校准联合。

## 十、小结

不确定估计须以区分力指标评，否则不可信。
