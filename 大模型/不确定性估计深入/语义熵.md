# 语义熵（Semantic Entropy）

> 对应 Kuhn et al., *Semantic Uncertainty*, 2023。

## 一、背景与挑战

词级熵高估不确定（同义多表述）；语义熵按“含义”聚类更准。

## 二、核心原理

多次采样答案，按语义等价聚类，计算簇间分布熵；高语义熵=模型真正不确定（非措辞差异）。

## 三、数学形式

语义熵 $H_{sem}=-\sum_{c} P(c)\log P(c)$，$P(c)=\sum_{y\in c} P(y)$ 簇内合并。

## 四、代码实现


## 五、与其他对比

- 比 token 熵更贴“知不知道”。
- 与 语言模型校准深入（自估）互补。

## 六、常见误区

- 用词级熵误判（同义多表述→假高不确定）。
- 聚类靠模型易错（同义误并/异义误分）。
