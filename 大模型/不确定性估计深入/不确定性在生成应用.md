# 不确定性在生成中的应用

> 对应不确定驱动拒答/自检；模型安全与对齐 衔接。

## 一、背景与挑战

把不确定估计用到实际：何时拒答、何时求助、何时高亮。

## 二、核心原理

高语义熵/认知不确定→拒答或声明“不确定”；低不确定→自信作答；可用于 RAG 是否检索、Agent 是否行动。

## 三、数学形式

动作 $a = \begin{cases}\text{answer} & H_{sem}<\tau\\\text{abstain} & H_{sem}\ge\tau\end{cases}$。

## 四、代码实现

```python
if semantic_entropy(answers) > thr:
    return "我不确定，建议查证"
```

## 五、与其他对比

- 与 模型校准深入（拒答阈值）同源。
- 与 安全红队深入（边界不自知）互补。

## 六、常见误区

- 阈值固定忽视任务风险等级。
- 不确定误当错误（偶然噪声也高）。

## 八、面试题

- 问：不确定如何提升安全？答：高不确定时拒答/查证，避免编造，边界自知。

## 九、演进

被动报告 → 主动拒答 → 风险自适应。

## 十、小结

不确定性驱动拒答与查证，是可信与安全的实用杠杆。
