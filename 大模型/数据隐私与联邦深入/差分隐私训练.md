# 差分隐私训练

> 对应 Abadi et al. 2016（DP-SGD）、Opacus 差分隐私训练库；参考 llm-course (mlabonne) 与 Micikevicius et al. 2018（混合精度训练）。

## 一、背景与挑战

在「保护个体数据」的前提下训练模型，是医疗、金融等敏感领域的硬需求。若直接拿含个人数据训练，成员推断攻击可判断某人是否在训练集，进而泄露其信息。核心挑战：

- 个体不可区分：单条样本不应显著影响模型。
- 效用-隐私权衡：加噪会损害性能，需找到可接受的折中。
- 组合性：多步训练累积隐私开销，需严密记账。
- 大模型开销：逐样本裁剪与噪声在 LLM 规模下成本高。

## 二、核心原理

差分隐私训练的主流算法是 DP-SGD：在普通 SGD 的每步，先对每个样本的梯度做「裁剪」（限制单样本影响），再向批梯度加高斯噪声，最后用「矩 accountant（moment accountant）」严密累计隐私预算 $(\varepsilon,\delta)$。其保证是：相邻数据集（差一条样本）训练出的模型分布几乎不可区分。

关键超参：裁剪阈值 $C$、噪声乘子 $\sigma$、采样率 $q$。$\sigma$ 越大越隐私但效用越差；$(\varepsilon,\delta)$ 越小越严格。

## 三、形式化与数学基础

对每步梯度先按 $L_2$ 范数裁剪：

$$ \bar{g}_i = g_i / \max\!\left(1,\, \frac{\|g_i\|_2}{C}\right) $$

再对批平均加噪：

$$ \tilde{g} = \frac{1}{n}\left(\sum_{i=1}^{n} \bar{g}_i\right) + \mathcal{N}(0, \sigma^2 C^2 I) $$

差分隐私定义：对任意相邻数据集 $D,D'$ 与事件 $S$，

$$ P[M(D)\in S] \le e^\varepsilon P[M(D')\in S] + \delta $$

矩 accountant 将 $T$ 步的累积开销收紧到 $(\varepsilon,\delta)$。

## 四、代码实现

```python
# 用 Opacus 做差分隐私微调（示意）
from opacus import PrivacyEngine
from torch.optim import Adam

optimizer = Adam(model.parameters(), lr=1e-4)
privacy_engine = PrivacyEngine(
    model,
    sample_rate=0.01,        # 每步采样比例
    noise_multiplier=1.2,    # 噪声乘子，越大越隐私
    max_grad_norm=1.0,       # 梯度裁剪阈值 C
)
privacy_engine.attach(optimizer)   # 包装优化器即可获得 DP 保证

for x, y in loader:
    loss = model(x).loss(y)
    loss.backward()
    optimizer.step()         # 内部自动裁剪+加噪
    optimizer.zero_grad()

eps = privacy_engine.get_epsilon(delta=1e-5)  # 查询当前隐私预算
```

## 五、与其他技术对比

| 维度 | 普通 SGD | DP-SGD |
| --- | --- | --- |
| 隐私保证 | 无 | 有 $(\varepsilon,\delta)$ 界 |
| 单样本影响 | 无界 | 裁剪+噪声有界 |
| 效用 | 高 | 略降（噪声权衡） |
| 开销 | 低 | 裁剪/记账较高 |

## 六、常见误区

- 「DP 完美匿名」：它只是概率保证，且 $\varepsilon$ 过大时保护很弱。
- 「噪声越大越好」：过度加噪模型不可用，需权衡。
- 「只加噪不裁剪」：未裁剪时单样本影响无界，DP 失效。
- 「忽略组合」：多轮训练需 accountant 记账，否则预算虚低。

## 九、演进与趋势

从「无 DP」到「DP-SGD」再到「大模型 DP 微调」；趋势是更紧的 accountant（如 Rényi DP）、与 LoRA/PEFT 结合的低成本 DP 微调、以及 DP 与联邦学习的融合。

## 十、小结

差分隐私训练以「梯度裁剪 + 高斯加噪 + 隐私记账」提供可证明的个体不可区分保证，是隐私训练的黄金标准。代价是效用与开销的权衡，需在 $(\varepsilon,\delta)$ 预算内谨慎设计。
