# 差分隐私训练

> 见「数据隐私与联邦深入/隐私风险面」与「训练技巧与稳定性」。

## 一、背景与挑战

在保护个体数据前提下训练，防成员推断。

## 二、核心原理

DP-SGD 在梯度加噪并裁剪，提供 (ε,δ)-DP 保证，限制单样本影响。

## 三、数学形式

```
clip(g_i); g̃ = (1/n)Σ clip(g_i) + N(0,σ²C²I)
```

## 四、代码实现

```python
from opacus import PrivacyEngine
engine = PrivacyEngine(model, sample_rate, noise_multiplier=1.2)
```

## 五、关键要点

- 噪声降效用，需平衡。
- ε 越小越隐私越弱模型。

## 六、与其他对比

- 普通 SGD 无保证；DP 有界但损效。

## 七、常见误区

- DP 完美匿名——仅概率保证。
