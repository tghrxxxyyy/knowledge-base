# 隐私风险面

> 对应 llm-course 安全章与 Carlini 提取研究；见「模型水印与溯源/输出去记忆化」。

## 一、背景与挑战

LLM 可能泄露训练数据中的 PII 与机密。

## 二、核心原理

风险来源：训练数据含 PII、记忆化导致逐字泄露、成员推断攻击判断某数据是否在训练集。

## 三、关键要点

- 记忆化是主因。
- 长尾数据更易被记。

## 四、代码实现

```python
if pii_detect(output): redact(output)
```

## 五、与其他对比

- 传统软件泄露在库；LLM 泄露在生成。

## 六、常见误区

- 不输出原文就无风险——风格/事实也敏感。

## 七、与开源书对应
