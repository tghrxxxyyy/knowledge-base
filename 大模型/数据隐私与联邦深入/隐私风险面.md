# 隐私风险面

> 对应 Carlini et al. 2021（训练数据提取）、模型记忆化研究；参考 llm-course (mlabonne) 与 OWASP LLM Top 10（LLM02 敏感信息泄露）。

## 一、背景与挑战

大模型的隐私风险贯穿「训练」与「生成」两条线。训练阶段，语料中的 PII、机密文本可能被模型「记住」；生成阶段，模型又可能逐字吐出这些内容，或泄露可反推训练群体的信息。核心挑战：

- 记忆化：模型对长尾/重复样本会逐字记忆，易被提取。
- 成员推断：攻击者判断某数据是否在训练集。
- 属性推断：从行为反推群体敏感属性。
- 风格/事实泄露：即便不输出原文，相关事实或风格也可能敏感。
- 多模态扩散：文本之外，图像/语音同样有隐私面。

## 二、核心原理

隐私风险来源可归为三类：

1. 训练数据含敏感信息：语料清洗不彻底，PII/机密进入模型。
2. 记忆化（memorization）：尤其是高频或长尾样本，模型在参数中「硬编码」了原文，可通过提示复现。
3. 推断攻击：利用输出分布差异做成员/属性推断。

缓解在两端：训练前做数据脱敏与去重、训练中用差分隐私/机器遗忘、生成时做输出检测与去记忆化（unlearning/memorization mitigation）。

## 三、形式化与数学基础

记忆化可用「逐字复现概率」衡量。对某训练串 $s$，给定前缀 $s_{<k}$ 模型补全出 $s_k$ 的概率：

$$ M(s) = P_\theta(s_k \mid s_{<k}) $$

若显著高于随机基线与未见过样本，则判定为已记忆。成员推断基于输出分布差异：训练样本 $x$ 的置信度往往高于分布外样本，

$$ \Delta(x) = \text{conf}_\theta(x) - \mathbb{E}_{x'\sim D_{\text{out}}}\text{conf}_\theta(x') $$

$\Delta$ 越大，越易被推断为成员。

```python
# 推理侧：检测并脱敏可能的 PII 泄露输出
from presidio_analyzer import AnalyzerEngine

analyzer = AnalyzerEngine()

def safe_output(raw):
    results = analyzer.analyze(text=raw, language="zh")
    if results:
        # 命中敏感实体，触发脱敏或拒绝
        return redact(raw, results), "flagged"
    return raw, "clean"

out, status = safe_output(model.generate(prompt))
```

## 五、与其他技术对比

| 维度 | 传统软件泄露 | LLM 泄露 |
| --- | --- | --- |
| 位置 | 数据库/接口 | 生成内容 |
| 形式 | 结构化记录 | 文本/风格/事实 |
| 触发 | 越权访问 | 提示诱导 |
| 防御 | 访问控制 | 脱敏+对齐+去记忆 |

## 六、常见误区

- 「不输出原文就无风险」：风格、事实、统计同样可能敏感。
- 「去重即可」：仅去重无法消除长尾记忆与推断风险。
- 「小模型无隐私问题」：任何规模都可能记忆训练数据。
- 「对齐即隐私」：对齐减有害输出，不等于防泄露。

## 九、演进与趋势

从「无意识」到「提取研究揭示风险」再到「系统防御」；趋势是机器遗忘（machine unlearning）、去记忆化对齐、以及把隐私风险面纳入红队评测。

## 十、小结

隐私是训练与生成的「双线风险」。理解记忆化与推断攻击的来源，在训练侧脱敏/去重/差分隐私、生成侧检测/去记忆，才能把泄露面真正收敛到可控范围。
