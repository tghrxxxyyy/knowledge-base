# 联邦学习

> 对应 McMahan et al. 2017（FedAvg）、Flower 联邦框架；参考 llm-course (mlabonne) 与分布式训练实践。

## 一、背景与挑战

数据分散在多家机构（银行、医院、运营商）且受隐私与合规约束，无法直接汇聚集中训练。联邦学习让各方「数据不出域」地协同训练共享模型。核心挑战：

- 通信开销：频繁上传/下发参数，带宽成为瓶颈。
- 异构数据：各方数据分布（Non-IID）差异大，聚合后性能下降。
- 系统异质：客户端算力/在线时长不一，掉线常见。
- 安全威胁：上传的梯度可能泄露训练样本（梯度反演）。
- 投毒风险：恶意客户端上传污染梯度破坏全局模型。

## 二、核心原理

联邦学习基本范式：中心服务器维护全局模型 $w$，每轮挑选部分客户端做本地训练，仅上传参数/梯度，服务器聚合后下发。最经典的是 FedAvg（联邦平均）：

1. 下发：服务器把当前全局模型发给选中的客户端。
2. 本地训练：客户端用本地数据做若干步 SGD，得到更新后的 $w^k$。
3. 上传：客户端仅回传参数（可加噪/加密）。
4. 聚合：服务器按样本量加权平均得到新全局模型。

数据始终留在本地，实现「数据可用不可见」。

（落地补充：）
- 工程上常用「中心协调 + 异步聚合」缓解掉线：允许客户端错峰上传，服务器按到达聚合，兼顾效率与容错。

## 三、形式化与数学基础

设共 $K$ 个客户端，客户端 $k$ 本地样本数 $n_k$，总样本 $n=\sum_k n_k$。FedAvg 的全局更新为按样本量加权：

$$ w_{t+1} = \sum_{k=1}^{K} \frac{n_k}{n}\, w_t^{(k)} $$

本地目标为最小化经验风险：

$$ \min_{w} F_k(w) = \frac{1}{n_k}\sum_{i\in \mathcal{D}_k} \ell\big(f_w(x_i), y_i\big) $$

全局目标 $F(w)=\sum_k \frac{n_k}{n}F_k(w)$。Non-IID 下各 $F_k$ 差异大，需用 FedProx 等加近端正则约束本地偏移。

## 四、代码实现

```python
# 联邦平均（FedAvg）聚合示意
def federated_round(server_model, clients, epochs=1):
    grads = []
    weights = []
    for c in clients:
        w_local = c.local_train(server_model, epochs)  # 数据不出域
        grads.append(w_local)
        weights.append(c.num_samples)
    total = sum(weights)
    # 按样本量加权平均
    new_w = sum(w * (n / total) for w, n in zip(grads, weights))
    server_model.load_state_dict(new_w)
    return server_model

agg = federated_round(global_model, selected_clients)
```

## 五、与其他技术对比

| 维度 | 集中训练 | 联邦学习 |
| --- | --- | --- |
| 数据位置 | 汇聚到中心 | 留本地 |
| 隐私 | 弱（集中存储） | 强（仅传参数） |
| 通信 | 低 | 高（多轮同步） |
| 数据异构 | 无 | Non-IID 挑战 |

## 六、常见误区

- 「梯度无信息」：梯度反演攻击可重建训练样本，需加噪/加密/安全聚合。
- 「联邦天然安全」：仍面临投毒与成员推断，需异常检测。
- 「通信不是问题」：大规模客户端下通信常是主要成本。
- 「Non-IID 无影响」：直接聚合会严重掉点，需特殊处理。

## 九、演进与趋势

从「FedAvg」到「安全聚合 + 差分隐私」再到「联邦 + 密态计算」；趋势是横向/纵向/联邦迁移学习、个性化联邦（pFL）、以及把大模型微调搬进联邦框架。

## 十、小结

联邦学习通过「本地训练、仅传参数、按样本聚合」实现数据不出域的协同建模。它保住了数据隐私，却引入通信、异构与安全的新课题，是隐私计算的核心范式之一。
