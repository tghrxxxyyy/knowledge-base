# 联邦学习

> 见「数据隐私与联邦深入/差分隐私训练」与「分布式训练」。

## 一、背景与挑战

数据分散在多方不愿集中，需协同训练。

## 二、核心原理

各方本地训练，仅上传梯度/参数（可加噪/加密），中心聚合（FedAvg）更新全局模型，数据不出域。

## 三、数学形式

```
w_{t+1} = Σ_k (n_k/n) w_t^k
```

## 四、代码实现

```python
agg = sum(client_weights) / len(clients); broadcast(agg)
```

## 五、关键要点

- 通信成本高。
- 需防梯度泄露（可反推数据）。

## 六、与其他对比

- 集中训练强但需数据汇聚；联邦保隐私。

## 七、常见误区

- 梯度无信息——可重建样本。
