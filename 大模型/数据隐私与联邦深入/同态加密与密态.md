# 同态加密与密态

> 见「数据隐私与联邦深入/联邦学习」与「安全与对齐深入」。

## 一、背景与挑战

推理/训练时数据需保密（如医疗跨机构）。

## 二、核心原理

同态加密允许在密文上计算，结果解密后等价明文计算；虽慢但保隐私，适合高敏场景。

## 三、关键要点

- 计算开销大。
- 适合特定高价值任务。

## 四、代码实现

```python
ct = enc(x); ct_y = eval_model(ct); y = dec(ct_y)
```

## 五、与其他对比

- 联邦仍传梯度；密态连计算都密。

## 六、常见误区

- 密态通用快——实际很慢。
