# 多模态 RAG 实战进阶

> 板块：大模型 　|　 返回：[README](README.md)
> 适用：图文混排文档、图片/表格问答、视频检索、跨模态检索增强生成。

传统 RAG 处理纯文本，但企业知识大量是**图文、表格、扫描件、视频**。多模态 RAG 把这些非文本模态纳入检索与生成闭环，是落地"企业知识库"的关键。

## 一、多模态数据形态

| 模态 | 例子 | 处理要点 |
|------|------|----------|
| 图片 | 产品图、图表、扫描件 | OCR/视觉理解/向量化 |
| 表格 | Excel、报表 | 结构化解析、表格问答 |
| 文档版式 | PDF 图文混排 | 版式分析、图注关联 |
| 视频 | 培训录像 | 抽帧+ASR+摘要 |
| 音频 | 客服录音 | 转写+说话人 |

## 二、架构

```
多模态文档 → 解析(版式/OCR/抽帧) → 切块(图/文/表分离)
   → 多路向量化(文本embedding + 视觉embedding)
   → 统一向量库(可混合检索)
   → 检索 → 拼入多模态上下文 → 多模态LLM生成
```

## 三、关键组件

### 3.1 文档解析

- **版式分析**：识别标题/段落/图片/表格区域及阅读顺序。
- **OCR**：扫描件/图片转文字（PaddleOCR、云 OCR）。
- **表格解析**：表格结构还原为 Markdown/HTML，保留行列关系。
- **图注关联**：图片与其上下文/说明文字绑定，避免孤立。

### 3.2 多模态向量化

- **文本**：text embedding（BGE、OpenAI、Cohere）。
- **图片**：CLIP 类视觉 embedding，图文同空间（支持以文搜图、以图搜文）。
- **混合存储**：文本向量与图片向量可同库，附元数据（类型、来源、页码）。

### 3.3 多模态大模型

- 生成阶段用支持图文输入的模型（GPT-4V、Qwen-VL、GLM-4V）。
- 把检索到的图片/表格直接作为多模态上下文输入。

## 四、检索策略

- **混合检索**：文本 BM25 + 向量 + 视觉向量。
- **模态路由**：问题偏图 → 侧重图片检索；偏表 → 表格检索。
- **重排**：多路结果统一 rerank（可多模态 reranker）。

## 五、典型场景

| 场景 | 做法 |
|------|------|
| 图纸/合同问答 | OCR+版式 → 文本+图块向量 → 多模态生成 |
| 财报分析 | 表格解析 → 表级检索 → 表格问答 |
| 培训视频检索 | 抽帧+ASR → 片段检索 → 定位+总结 |
| 产品手册 | 图文块关联 → 以图问图 → 多模态答 |

## 六、质量与评测

- **解析准确率**：OCR/版式错误会传导到检索。
- **检索召回**：多模态 query 能否命中正确图/表。
- **生成正确性**：答案是否基于检索内容（防幻觉）。
- **端到端基准**：构建图文问答测试集。

## 七、常见坑

1. **OCR 错误** → 检索/生成全错；选强 OCR + 校验。
2. **图文割裂** → 图无上下文；图注关联 + 块级绑定。
3. **表格丢失结构** → 答非所问；结构化解析保留行列。
4. **只文本检索** → 图问题答不出；加视觉向量。
5. **大图直接塞 prompt** → token 爆炸；裁剪/压缩/摘要。
6. **无版式顺序** → 阅读错乱；版式分析保顺序。
