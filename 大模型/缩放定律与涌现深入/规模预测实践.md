# 规模预测实践

> 对应 Kaplan et al., *Scaling Laws for Neural Language Models*（arXiv:2001.08361）、Hoffmann et al., *Training Compute-Optimal Large Language Models*（Chinchilla, arXiv:2203.15556）、Wei et al., *Emergent Abilities of Large Language Models*（arXiv:2206.07682）、Schaeffer et al., *Are Emergent Abilities a Mirage?*（arXiv:2304.15004）、Rosenfeld et al., *Scaling Laws for Transfer*（arXiv:1912.02292）；仓库参考 Epoch AI（https://github.com/EpochAI）与 llm-course（https://github.com/mlabonne/llm-course），并见本库「缩放定律与涌现深入/缩放定律」篇章。

## 一、背景与挑战

一次前沿模型训练的算力开销可达 $10^{23}$–$10^{26}$ FLOPs，试错预算几乎为零：不能靠"训完再看"来决定模型该多大、数据该多少、训到什么时候停。规模预测（scaling prediction）的任务是在**训练前**用便宜的小规模实验，拟合损失/指标随参数量 $N$、数据量 $D$、算力 $C$ 变化的规律，回答三个生产问题：给定预算该分配多少参数与 token？目标 loss 或下游分数能否达到上线门槛？训练曲线走势是否异常（数据、超参或基础设施出了问题）？难点在于外推本质是外推：拟合区间与目标规模常差 1–2 个数量级，幂律在拐点（数据耗尽、去重瓶颈、上下文长度切换、架构改动）附近会系统性失真；下游指标还存在离散跳变与饱和，不能直接对 loss 的连续外推套用。此外涌现能力（emergence）是否存在，决定了"预测 loss 就够了"这一假设是否成立——这本身是一场未决的学术争论。

## 二、核心原理

### 2.1 幂律骨架

经验规律表明，充分训练的模型交叉熵损失随算力呈幂律下降：$L(C) = L_\infty + A\,C^{-\alpha}$，其中 $L_\infty$ 是不可约损失（数据熵下界），$\alpha$ 在 LLM 上约 $0.05$ 量级（随预算与 token 比例变化）。参数化形式为 $L(N, D) = E + \frac{A}{N^\beta} + \frac{B}{D^\gamma}$（Kaplan 形式；Chinchilla 用非嵌入参数重述）。在 log-log 坐标下幂律是直线，最小二乘拟合即可读出斜率与截距，这也是"小实验外推大模型"的全部数学基础。

### 2.2 Compute-optimal 拟合（Chinchilla 方法）

给定算力 $C \approx 6ND$，求使 $L$ 最小的 $(N, D)$：对每组候选比率先训一族小模型扫出等算力点，发现 Kaplan 时代"N 尽量大、数据固定"的结论是未充分训练导致的偏差；Chinchilla 给出更均衡的配比——最优时 $N$ 与 $D$ 随 $C$ 近似线性同增（约每参数 20 token 量级，实际随方法与数据质量浮动）。工程上由此派生两条用法：一是"目标模型的最优 token 预算"，二是"token 富余时该缩模型还是缩数据"。

### 2.3 拟合流程与多头验证

标准流程：固定数据配方与超参（或按小模型最优调度），在对数间隔的网格上训一族小模型（如 4 到千级参数、多档 token 数）→ 记录 $(N, D, C, L)$ → 拟合幂律并留出"中等规模"做外推验证（fit 小、predict 中，再比对真值）→ 用残差评估外推置信度 → 换 tokenizer、数据集、上下文长度时**重新拟合**（常数 $A, B$ 不可跨配方迁移）。损失之外必须多头看：下游任务分数、校准误差、代码/数学等分域能力分别拟合，因为它们对 loss 的映射不是单一线性的。

### 2.4 外推失效的常见来源

其一，拟合点未充分训练（Chinchilla 校正的动机）；其二，结构性断点：滑窗注意力换 RoPE、上下文从 2k 切 8k、数据去重导致有效数据增速变缓，都会让常数漂移；其三，小模型处于不同优化区（大 batch、学习率 warmup 比例在小规模未调优），小模型损失被人为抬高，外推偏悲观；其四，loss 已逼近 $L_\infty$，log-log 直线弯曲，线性外推严重低估。对策是拟合带曲率的修正形式、只用接近目标规模的点加权、并给出预测区间而非单点。

### 2.5 涌现与连续指标之争

Wei 等报告部分任务在某规模阈值上"突然"达标，主张涌现是规模的质变；Schaeffer 等则论证许多跳变来自**离散指标**（exact match 等）对连续潜在量（log-prob、Brier 分数）的量化——换用连续指标后性能随规模平滑提升，即"海市蜃楼"。工程含义很直接：预测连续量（loss、log-prob、校准）远比预测离散阈值可靠；对确实存在阈值行为的能力（如多位数进位、特定 CoT 任务），要单独建"能力出现"的分类预测，而不是外推分数曲线。

### 2.6 训练前预算分配

拿到预测器后的决策链条：确定目标（loss 还是能力门槛）→ 反解所需的 $C$ → 在 $(N, D)$ 等算力曲线上选点（考虑部署成本，倾向更小模型 + 更多数据，除非带宽受限）→ 把总预算切成"探索性小实验 + 正式训练 + 安全余量（通常 10%–20% 用于数据补采与重启）" → 设定训练中的检查点决策（何时基于实测曲线缩配或中止）。此时规模预测不仅是效果预估，也是止损机制。

## 三、形式化与数学基础

**幂律与可约损失**。以算力为自变量：

$$L(C) = L_\infty + A\,C^{-\alpha}, \qquad C \approx 6ND$$

取对数得 $\ln(L - L_\infty) = \ln A - \alpha \ln C$，故在固定 $L_\infty$ 时 log-log 线性；实践中以非线性最小二乘同时估计 $(L_\infty, A, \alpha)$，或扫描 $L_\infty$ 网格做线性化回归。

**参数-数据联合形式**：

$$L(N, D) = E + \frac{A}{N^{\beta}} + \frac{B}{D^{\gamma}}$$

Kaplan 报告 $\beta \approx 0.076$、$\gamma \approx 0.095$（其设定下），并主张固定 $D$ 时算力最优偏大 $N$；Chinchilla 重拟合后修正为 $N^\star, D^\star \propto C^{a,b}$ 且 $a \approx b$（近线性），对应每参数 token 数近似常数 $D/N \approx \kappa$。由 $C = 6ND$ 与 $D = \kappa N$ 反解目标模型：

$$N^\star \approx \Big(\frac{C}{6\kappa}\Big)^{1/2}, \qquad D^\star = \kappa N^\star$$

**目标 loss 反解预算**：给定门限 $L_{target}$，由 $L(C)$ 解出

$$C_{req} = \Big(\frac{A}{L_{target} - L_\infty}\Big)^{1/\alpha}$$

当 $L_{target} \le L_\infty$ 时无解——这是"当前数据配方下不可能达标"的数学判据。**外推不确定性**可用留出误差与参数协方差合成预测区间 $\hat{L} \pm \delta(\log C)$，$\delta$ 随 $\log(C_{target}/C_{max}^{fit})$ 增大，故必须报告区间而非点估计。**涌现的度量视角**：设潜在连续量 $u(N)$ 平滑，离散指标 $M = \mathbf{1}[u > t]$ 或取整，其对 $\log N$ 的曲线必然呈阶跃——阶跃是度量函数的性质而非 $u$ 的性质。

## 四、代码实现

```python
import numpy as np
from scipy.optimize import curve_fit


def scaling_law(C, L_inf, A, alpha):
    """算力-损失幂律：L(C) = L_inf + A * C**(-alpha)。
    C 为训练 FLOPs（可用 6*N*D 估算），L_inf 为不可约损失。"""
    return L_inf + A * np.power(C, -alpha)


def fit_scaling(C_runs, L_runs):
    """对小规模扫描结果拟合幂律；返回参数与留一验证误差。"""
    C_runs = np.asarray(C_runs, dtype=np.float64)
    L_runs = np.asarray(L_runs, dtype=np.float64)
    p0 = [L_runs.min() * 0.9, 1e3, 0.05]           # 初值：L_inf 略低于观测最小值
    popt, pcov = curve_fit(
        scaling_law, C_runs, L_runs, p0=p0,
        bounds=([0, 0, 0.001], [L_runs.min(), 1e18, 1.0]),
        maxfev=20000,
    )
    # 留出最近端点做外推自检：fit 前 80%，predict 后 20%
    k = max(2, int(len(C_runs) * 0.8))
    p_opt, _ = curve_fit(scaling_law, C_runs[:k], L_runs[:k], p0=p0, maxfev=20000)
    holdout_err = float(np.mean(np.abs(scaling_law(C_runs[k:], *p_opt) - L_runs[k:])))
    return popt, holdout_err


def predict_loss(C_target, popt):
    """外推目标算力下的损失；同时返回经验预测区间宽度。"""
    L_inf, A, alpha = popt
    return float(scaling_law(C_target, L_inf, A, alpha))


def budget_for_target(L_target, popt, safety=0.15):
    """反解达到目标损失所需算力，并叠加数据补采/重启的安全余量。"""
    L_inf, A, alpha = popt
    if L_target <= L_inf:
        raise ValueError("目标损失低于不可约损失：需换数据配方或改进 tokenizer")
    C_req = (A / (L_target - L_inf)) ** (1.0 / alpha)
    return C_req * (1 + safety)


def chinchilla_alloc(C_total, kappa=20.0):
    """compute-optimal 配比：D = kappa * N，C ≈ 6ND，返回参数量与 token 数。"""
    N = np.sqrt(C_total / (6 * kappa))
    D = kappa * N
    return int(N), int(D)


# ---- 典型用法 ----
# 1) 小规模扫描：记录每个 (N, D) 的实测 loss（此处为演示数据）
C_runs = np.array([1e18, 3e18, 1e19, 3e19, 1e20])
L_runs = np.array([3.9, 3.7, 3.45, 3.3, 3.18])

# 2) 拟合 + 留出自检（holdout_err 大说明外推不可信，需补实验点）
popt, err = fit_scaling(C_runs, L_runs)
print("拟合参数 L_inf, A, alpha =", popt, "留出误差 =", err)

# 3) 预算决策：目标 loss → 所需算力 → (N, D) 配比
C_req = budget_for_target(3.0, popt)
N_star, D_star = chinchilla_alloc(C_req, kappa=20)
print(f"预计需要 C={C_req:.3e} FLOPs，建议 N={N_star}, D={D_star}")
```

## 五、与其他技术对比

| 方法 | 输入 | 输出 | 适用阶段 | 主要风险 |
| --- | --- | --- | --- | --- |
| 盲训（无预测） | 直觉 | 无 | 预算极小、探索期 | 失败成本全额承担 |
| Kaplan 幂律外推 | 小模型 loss 曲线 | $L(C)$ 曲线 | 早期预算估计 | 高估大 $N$ 收益（未充分训练偏差） |
| Chinchilla compute-optimal | 多点 $(N, D, L)$ | 最优 $N$–$D$ 配比 | 正式训练前分配 | $\kappa$ 随配方/方法漂移 |
| 学习率/损失曲线内插（如 extrapolation of training dynamics） | 中途训练日志 | 最终 loss 区间 | 训练中监控 | 对基础设施故障不敏感 |
| 下游指标回归 | 分任务分数 | 各能力达标规模 | 上线决策 | 离散指标的阶跃假象 |
| 涌现阈值预测 | 任务级曲线 | 出现能力的 $N$ | 能力规划 | 阈值可能随度量方式消失 |

| 决策点 | 朴素做法 | 规模预测做法 |
| --- | --- | --- |
| 参数 vs 数据 | 参数越大越好（旧 Kaplan 误解） | 沿等算力曲线按 $\kappa$ 平衡，倾向小模型多数据 |
| 是否达标 | 训完看 | 由 $C_{req}$ 与 $L_\infty$ 预判，无解即换配方 |
| 训练中止损 | 靠感觉 | 实测曲线 vs 预测带，偏离即缩配或中止 |
| 指标选择 | exact match | 优先连续指标（loss、log-prob、Brier） |

## 六、常见误区

1. **预测即精确**——外推误差随距离指数放大，必须给出预测区间与留出自检；单点数字是自欺。
2. **照搬论文的 $\alpha, \beta, \gamma$**——这些常数依赖 tokenizer、数据分布、架构与优化器，换配方必须用自产小实验重拟合。
3. **沿用旧 Kaplan 结论"N 尽量大"**——其结论源于小模型未充分训练；Chinchilla 后预算分配应优先保证数据量随参数同增。
4. **loss 能预测一切能力**——loss 是连续可外推的代理量，具体能力（尤其离散阈值型）需单独验证，多头指标各自拟合。
5. **把涌现当神秘不可预测**——部分"涌现"是离散度量的伪影；改用连续指标后多数曲线平滑，可纳入常规外推。
6. **小实验不调优化超参**——小模型若沿用大模型的 lr/batch/warmup，损失被抬高，拟合出的曲线整体偏悲观，外推必然失真。
7. **预测一次、终身有效**——上下文长度切换、数据去重、架构改动都会破坏可比性；断点处需重新校准预测器。

## 八、面试题

1. **训练前如何预测目标模型的 loss？完整流程是什么？**
   要点：对数网格训小模型族 → 拟合 $L(N,D)$ 或 $L(C)$ 幂律 → 留出中等规模做外推自检 → 给出带区间的预测；换配方需重拟合。
2. **Kaplan 与 Chinchilla 在预算分配上的分歧？现在怎么做？**
   要点：Kaplan 高估大参数收益，Chinchilla 用等算力扫描证明 $N$、$D$ 应近线性同增（约每参数 20 token 量级，按配方校准）；实际倾向更小模型 + 更多高质量数据。
3. **什么是外推失效？列举三个来源与对策。**
   要点：未充分训练的小点、结构性断点（上下文/架构/数据变化）、逼近 $L_\infty$ 的弯曲；对策是充分训练网格、断点重校准、带曲率模型与预测区间。
4. **涌现是真的吗？对预测实践意味着什么？**
   要点：争论未决——Wei 主张阈值质变，Schaeffer 论证多数是离散指标伪影；工程上优先预测连续量，对真阈值任务做单独的分类式预测。
5. **给定算力 $C$，如何做 $(N, D)$ 配比？**
   要点：$C \approx 6ND$，沿 $D = \kappa N$ 解出 $N = \sqrt{C/6\kappa}$；再按部署成本与数据可用性微调，留安全余量。
6. **什么情况下预测器会给出"无解"？怎么处理？**
   要点：目标 loss $\le L_\infty$ 时无算力可满足，说明数据熵/tokenizer/配方不行——换数据或改进表示，而不是加算力。

## 九、演进与趋势

规模预测从"经验直觉 + 单一幂律"起步（Kaplan 2020），经 Chinchilla（2022）进入 compute-optimal 的双变量拟合，随后与涌现之争（2022–2023）交织出"连续量预测 + 能力阈值单独建模"的双轨实践。当前趋势包括：把数据质量、去重率与课程学习纳入 scaling 变量（不只 $N$、$D$，还有数据"信息密度"）；训练中在线校准（用前段曲线修正后段预测并动态止损）；推理阶段的 test-time scaling（采样/思考长度与参数规模的预算互换）成为新的预测维度；以及开源工具与公开算力数据集让跨项目的幂律参数可对照复用。核心方法论不变——用便宜的多点实验换取昂贵决策的先验，并诚实报告不确定性。

## 十、小结

规模预测实践把"训多大、喂多少、值不值"从赌博变成工程问题：以幂律为骨架、以 compute-optimal 扫描定配比、以留出实验校准外推、以多头连续指标覆盖能力维度、以 $L_\infty$ 与预测区间暴露不可行与不确定性。两个纪律贯穿始终：常数必须自产重拟合，外推必须带区间与自检；在此基础上再叠加涌现的度量视角与训练中在线校准，才能让大规模训练的预算分配与止损决策真正可靠。
