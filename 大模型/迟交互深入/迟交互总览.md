# 迟交互（Late Interaction）总览

> 对应 Khattab & Zaharia, *ColBERT*, 2020（提出迟交互范式）。

## 一、背景与挑战

早交互（双塔）在编码后只做一次内积，丢词级信息；迟交互把交互推迟到检索阶段，保留 token 级匹配。

## 二、核心原理

文档 token 向量离线计算，查询时再与 query token 向量做细粒度匹配（MaxSim），在精度与可索引间取折中。

## 三、数学形式

迟交互分数 $S=\sum_{i}\max_j E_q(q_i)^\top E_d(d_j)$；与早交互 $q^\top d$ 相比保留内部最大。

## 四、代码实现

```python
s = colbert.late_interaction(Q_emb, D_emb)   # MaxSim 累积
```

## 五、与其他对比

- 介于 双塔模型深入（早交互）与 交叉编码器（早融合）之间。
- 与 多向量检索深入（MaxSim）同源。

## 六、常见误区

- 迟交互非免费，存储与计算高于双塔。
- 误把迟交互当重排；它仍属召回级。

## 八、面试题

- 迟交互为何折中？答：文档向量离线存（似双塔），查询时细匹配（似交叉）提质。

## 九、演进

早交互(DPR) → 迟交互(ColBERT) → 压缩迟交互(PLAID)。

## 十、小结

迟交互把交互推到检索时，是精度-效率的优雅折中。
