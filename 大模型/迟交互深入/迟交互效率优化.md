# 迟交互效率优化

> 对应 Santhanam et al., *PLAID*, 2022；Khattab et al., *XTR*, 2021（可解释 token 路由）。

## 一、背景与挑战

迟交互朴素需每 query token 对全文档 token 比对，慢且费存。

## 二、核心原理

质心分桶（PLAID）只比命中质心桶；XTR 让文档 token 仅响应少数 query token（可解释路由），减少无效计算；残差压缩降存储。

## 三、数学形式

候选计算量由 $O(|Q||D|)$ 降到 $O(|Q|\cdot|\text{命中桶}|)$；残差量化降存储比。

## 四、代码实现

```python
for qi in Q:
    for dj in buckets[nearest_centroid(qi)]:
        acc += qi @ dj
```

## 五、与其他对比

- 与 多向量压缩 同用残差/质心。
- 与 向量检索算法深入（IVF）同源。

## 六、常见误区

- 桶太粗漏召回；太细失加速。
- 残差压缩未验证召回跌。

- PLAID 如何加速？答：质心分桶使 query token 只比命中桶文档 token，残差量化省存。

## 十、小结

迟交互效率靠分桶与压缩，达近双塔速度而保精度。
