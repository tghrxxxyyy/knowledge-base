# 迟交互变体（ColBERTv2 / XTR）

> 对应 Santhanam et al., 2021（ColBERTv2）；Khattab et al., 2021（XTR 可解释检索）。

## 一、背景与挑战

基础迟交互存储大、可解释弱；变体在压缩与路由上改进。

## 二、核心原理

ColBERTv2 加残差压缩与蒸馏；XTR 让每个文档 token 仅匹配少量 query token 并输出命中关系，提升可解释与效率。

## 三、数学形式

XTR 路由 $R(d_j)=\{q_i: \arg\max_k q_i^\top d_k = j\}$；用命中数辅助排序。

## 四、代码实现

```python
matches = xtr.match(Q, D)   # 返回 token 级对齐
score = colbert_score + lam * len(matches)
```

## 五、与其他对比

- 与 多向量压缩 同属 ColBERT 系改进。
- 与 迟交互与早交互对比 共享范式。

## 六、常见误区

- 路由过严致召回降；需调阈值。
- 蒸馏教师若弱，学生上限低。

## 七、与开源书对应

## 八、面试题

- XTR 创新点？答：token 级可解释路由，文档 token 仅响应少数 query token 提效可解释。

## 九、演进

ColBERT → ColBERTv2 → XTR/PLAID。

## 十、小结

迟交互变体以压缩与路由推进生产可用与可解释。
