# 限流与熔断

> 对应令牌桶与漏桶；circuit breaker（resilience4j 思路）。resilience4j 提供熔断实现。

## 一、背景与挑战

单租户异常流量或下游故障会拖垮全系统，需限流与熔断隔离故障。

## 二、核心原理

限流按速率放请求；熔断在错误率超阈时快速失败（open），半开探测恢复。

## 三、数学形式

熔断状态机：$closed \xrightarrow{err>\theta} open \xrightarrow{timeout} half\_open \xrightarrow{ok} closed$。

## 四、代码实现

```python
if breaker.state == "open":
    raise HTTPError(503)
try:
    r = call()
    breaker.record(True)
except Exception:
    breaker.record(False)
```

## 五、与其他对比

- 与 背压机制设计（拒绝语义）共享。
- 与 多租户总览（每租户限流）衔接。

## 六、常见误区

- 熔断阈值过灵敏感抖。
- 半开探测流量过大二次击穿。

## 八、面试题

- 熔断三状态？答：closed 正常、open 快速失败、half-open 探测恢复。

## 九、演进

限流 → 熔断 → 自适应熔断。

## 十、小结

限流与熔断把单点故障限制在租户内，保全局可用。
