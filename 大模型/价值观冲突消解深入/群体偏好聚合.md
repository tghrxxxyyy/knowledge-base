# 群体偏好聚合

> 对应 Chakraborty et al., *MaxMin RLHF*, 2024；Fish et al., *Pluralistic Alignment*, 2023。

## 一、背景与挑战

群体偏好不一致时平均会讨好多数、伤少数；需公平聚合。

## 二、核心原理

MaxMin RLHF 在最差群体效用上最大化，保少数群体不被牺牲；或多模型路由到子群体。

## 三、数学形式

$\max_\pi \min_g \mathbb E_{x,y\sim\pi_g}[r_g(x,y)]-\beta KL$，保最弱群体下限。

## 四、代码实现

```python
loss = -min([group_reward(g) for g in groups])
```

## 五、与其他对比

- 与多目标偏好聚合深入共享最坏约束。
- 与价值观冲突总览共享少数保护。

## 六、常见误区

- 平均聚合掩盖少数受损。
- 群体划分过细致数据稀疏。

## 九、演进

平均 → 最坏最大化 → 群体路由。

## 十、小结

公平聚合需显式保护最弱群体，而非隐式平均。
