# 宪法式对齐

> 对应 Bai et al., *Constitutional AI*, 2022；Askell et al., 2021（HHH）。

## 一、背景与挑战

人工逐条标有害费且难覆盖；宪法用一组原则自生成 critiques 与修正，减少人标。

## 二、核心原理

用自然语言原则（宪法）让模型自评回答违规并改写，再据修正后数据训偏好，原则可审计可调。

## 三、数学形式

Critique 概率 $P(c|x,y)\propto\exp(s(x,y,c))$；修正 $y'=f(x,y,c)$ 用于偏好对。

## 四、代码实现

```python
crit = model(f"按原则检查:{x}{y}")
y2 = model(f"按{crit}改写:{y}")
```

## 五、与其他对比

- 与多目标偏好聚合深入：原则可作多维度。
- 与指令层级与越权防御深入共享原则不可越。

## 六、常见误区

- 原则过泛致无约束力。
- 模型自评偏见被固化进宪法。
