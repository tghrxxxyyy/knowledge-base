# 大模型记忆与回忆机制总览

> 对应 Petroni et al., *Language Models as Knowledge Bases?*, EMNLP 2019；Carlini et al., *Quantifying Memorization Across Neural Language Models*, ICLR 2023。

## 一、背景与挑战

大模型既要泛化又不可避免地记住训练数据。区分「有用的知识记忆」与「有害的逐字记忆」，并解释回忆为何时成时败，是安全与可靠性的共同前提。

## 二、核心原理

记忆可按存储位置与提取方式分层理解，不同层次对应不同的失效与治理手段。

- 参数化记忆：知识以权重形式分布存储，前馈层扮演键值查表角色，提取依赖提示能否构造出正确的键。
- 上下文记忆：由 KV 缓存与注意力提供，短期精确但随会话消失；外部记忆（检索库）则可审计可更新。

## 三、数学形式

回忆成功可写作 $\mathrm{Recall}(q)=\mathbb{1}\big[\arg\max_y p_\theta(y\mid \mathrm{prompt}(q))=y^\ast\big]$，其失败可分解为存储缺失与键构造失败两类。

因此存在「模型知道但提示问不出」的情形：$p_\theta(y^\ast\mid q_1)\ll p_\theta(y^\ast\mid q_2)$ 而两者语义等价。

## 四、代码实现

```python
import torch
def recall_prob(model, tok, prompt, answer):
    ids = tok(prompt + answer, return_tensors="pt").input_ids
    n_ans = len(tok(answer).input_ids)
    with torch.no_grad():
        lp = torch.log_softmax(model(ids).logits[0, :-1], dim=-1)
    tgt = ids[0, 1:]
    return float(lp.gather(-1, tgt[:, None])[-n_ans:].sum())
```

## 五、与其他对比

- 与检索增强对照：参数化记忆快但不可审计，外部记忆可溯源可更新，二者互补。
- 与 知识定位与神经元归因深入 衔接：定位方法试图回答「这条记忆存在哪些层与哪些参数」。

## 六、常见误区

- 把回忆失败一律当作「模型不知道」；很多是提示未命中键，改写提问即可恢复。
- 认为记忆只在过拟合时出现；Tirumala et al., NeurIPS 2022 显示未过拟合也会产生显著记忆。

## 八、面试题

- 参数化记忆与上下文记忆差异？答：前者在权重中持久但难更新，后者在激活中临时但可控。
- 为何同义提问结果差异大？答：提取依赖键匹配，表述改变会改变检索路径与竞争答案分布。

## 九、演进

探针式知识问答（2019）→ 逐字记忆量化（2021-2023）→ 记忆定位与编辑 → 记忆治理与遗忘。

## 十、小结

记忆问题的正确框架是「存储在哪、如何提取、能否更新」，三者分开分析才能定位失效。
