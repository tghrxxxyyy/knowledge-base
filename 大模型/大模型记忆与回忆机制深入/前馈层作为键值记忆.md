# 前馈层作为键值记忆

> 对应 Geva et al., *Transformer Feed-Forward Layers Are Key-Value Memories*, EMNLP 2021；Geva et al., EMNLP 2022（词表空间促进视角）。

## 一、背景与挑战

若知识存在参数里，则需要指出承载它的结构。前馈层占参数量约三分之二，其两层线性结构天然可解释为「键匹配 + 值读出」。

## 二、核心原理

第一层权重的每一行是一个键，与残差流做内积后经激活得到匹配强度；第二层对应行则是被写回残差流的值向量。

- 键侧对应人类可识别的输入模式（如某类短语、某种句法上下文）。
- 值侧可投影到词表空间解释为「提升哪些 token 的 logit」，从而把记忆读出视作词表分布的加性修改。

## 三、数学形式

$$\mathrm{FFN}(x)=\sum_{i=1}^{d_{ff}} \sigma\!\left(k_i^\top x\right)\, v_i,\quad k_i=W_{in}[i,:],\ v_i=W_{out}[:,i]$$

其中 $\sigma(k_i^\top x)$ 是第 $i$ 条记忆的激活系数；投影 $W_U v_i$ 给出该记忆对词表 logit 的贡献方向。

## 四、代码实现

```python
import torch
def ffn_memory_readout(W_in, W_out, W_U, x, topk=5):
    coef = torch.relu(x @ W_in.t())                 # 各记忆槽激活强度
    slot = int(coef.argmax())
    logit_dir = W_U @ W_out[:, slot]                # 该槽在词表上的推动方向
    return slot, torch.topk(logit_dir, topk).indices
```

## 五、与其他对比

- 与注意力对照：注意力做跨位置搬运，前馈做位置内查表，二者交替构成读写循环。
- 与 知识定位与神经元归因深入 衔接：ROME 正是把事实写入某层前馈的 $W_{out}$。

## 六、常见误区

- 认为一条事实只对应一个神经元；实际是多槽叠加，单槽解释常不完整。
- 忽略残差流中的其他写入项，只看单层读出会高估该层作用。

## 八、面试题

- 为何说 FFN 是键值记忆？答：第一层内积做键匹配，第二层按匹配强度加权写回值向量。
- 值向量如何解释？答：用去嵌入矩阵投影到词表，看它提升哪些 token 的 logit。

## 九、演进

FFN 键值假说（2021）→ 词表空间解释（2022）→ 支撑 ROME/MEMIT 定点编辑 → 与稀疏特征分解结合。

## 十、小结

把前馈层读成键值记忆，是连接「参数存储」与「可编辑知识」的关键抽象。
