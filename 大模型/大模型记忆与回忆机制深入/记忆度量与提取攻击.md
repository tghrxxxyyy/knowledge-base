# 记忆度量与提取攻击

> 对应 Carlini et al., USENIX Security 2021；Carlini et al., ICLR 2023；Jang et al., *Knowledge Unlearning*, ACL 2023。

## 一、背景与挑战

要治理记忆风险，需要能复现的度量与攻击流程：给定模型，量化有多少训练数据可被提取，以及缓解措施是否真的有效。

## 二、核心原理

评估流程通常是「候选生成 + 成员判定」：先大量采样候选串，再用统计信号筛出高可能性的训练片段。

- 候选生成：多温度采样、不同前缀长度、以及带有真实前缀的条件生成。
- 成员判定：用困惑度比值等信号（与小模型或压缩基线对比）过滤掉普通高频文本。

## 三、数学形式

判定分数常用比值形式 $s(x)=\dfrac{\log p_{\theta}(x)}{\log p_{ref}(x)}$ 或 $s(x)=\log p_\theta(x)-\log p_{small}(x)$，取阈值判正。

评估指标为提取精确率与召回率：$\mathrm{P}=\frac{|\hat M\cap M|}{|\hat M|}$，$\mathrm{R}=\frac{|\hat M\cap M|}{|M|}$。

## 四、代码实现

```python
import math
def membership_score(logp_target, logp_ref, n_tokens):
    return round((logp_target - logp_ref) / max(n_tokens, 1), 4)
cands = [(-12.0, -30.0, 20), (-25.0, -26.0, 20)]
print([membership_score(a, b, n) for a, b, n in cands])
```

## 五、与其他对比

- 与成员推断攻击对照：记忆提取要求还原内容，成员推断只判断是否在训练集中。
- 与 参数化记忆与逐字记忆 衔接：可提取性定义为该评估提供判定标准。

## 六、常见误区

- 只用绝对困惑度低作为记忆证据；常见文本本身困惑度就低，需参考基线做比值。
- 用少量样例证明「已修复」；缓解评估必须在同一攻击预算下前后对比。

## 八、面试题

- 为何用似然比而非似然？答：比值消除文本自身的通用可预测性，只保留模型特异的记忆信号。
- 如何评估缓解有效性？答：固定攻击预算前后对比提取精确率与召回率。

## 九、演进

个案提取 → 规模化度量与规模律 → 似然比与参考模型判定 → 与遗忘方法联合评估。

## 十、小结

记忆治理必须建立在可复现的攻击与度量之上，否则无法证明缓解真实有效。
