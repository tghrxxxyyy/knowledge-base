# 记忆编辑与遗忘

> 对应 Mitchell et al., *MEND: Fast Model Editing at Scale*, ICLR 2022；Jang et al., ACL 2023；Cohen et al., *Ripple Effects of Knowledge Editing*, TACL 2024。

## 一、背景与挑战

事实会过期、隐私要删除、错误要纠正。全量重训成本不可接受，因此需要局部编辑与定向遗忘，同时不破坏其余能力。

## 二、核心原理

编辑与遗忘共享同一评估三元组：目标是否改动、等价问法是否一致、无关知识是否保持。

- 编辑路径：定点权重更新（ROME/MEMIT）、超网络生成更新（MEND）、外部适配器与缓存式覆盖（如 GRACE 类）。
- 遗忘路径：在目标样本上做梯度上升或加入反向目标，配合保持集正则约束回归。

## 三、数学形式

遗忘目标可写作 $\min_\theta\ -\lambda\,\mathbb{E}_{x\in\mathcal{F}}\log p_\theta(x) + \mathbb{E}_{x\in\mathcal{R}}\mathrm{KL}\big(p_{\theta_0}(\cdot\mid x)\,\Vert\,p_\theta(\cdot\mid x)\big)$。

第一项推低遗忘集 $\mathcal{F}$ 的似然，第二项在保持集 $\mathcal{R}$ 上锚定原分布，避免灾难性退化。

## 四、代码实现

```python
import torch
def unlearn_step(model, forget_batch, retain_batch, lam=1.0, beta=1.0):
    l_f = model(**forget_batch).loss
    l_r = model(**retain_batch).loss
    loss = -lam * l_f + beta * l_r                  # 上升遗忘 + 下降保持
    loss.backward()
    return float(l_f), float(l_r)
```

## 五、与其他对比

- 与检索式更新对照：改库最安全可回滚，改权重更彻底但风险与评估成本高。
- 与 知识定位与神经元归因深入 衔接：编辑效果依赖定位质量，而定位与编辑的因果关系本身存在争议。

## 六、常见误区

- 只测目标问法成功率，忽视等价改写与派生推理的涟漪效应（Cohen et al., TACL 2024）。
- 遗忘只压低目标串似然却不校验模型在保持集上的整体退化。

## 八、面试题

- 编辑评估应包含哪些维度？答：有效性、泛化性（等价问法）、局部性（无关知识不变）与流畅度。
- 遗忘为何容易伤及无辜？答：梯度上升会波及共享表示，必须用保持集 KL 约束。

## 九、演进

单点权重改写 → 超网络与批量编辑 → 涟漪效应评估 → 遗忘与合规审计一体化。

## 十、小结

记忆编辑与遗忘的难点不在「改得动」，而在「只改该改的」，评估维度决定方法可用性。
