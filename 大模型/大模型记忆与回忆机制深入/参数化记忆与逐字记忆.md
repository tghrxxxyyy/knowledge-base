# 参数化记忆与逐字记忆

> 对应 Carlini et al., *Extracting Training Data from Large Language Models*, USENIX Security 2021；Carlini et al., ICLR 2023；Tirumala et al., NeurIPS 2022。

## 一、背景与挑战

逐字记忆意味着训练语料中的原文可被提示重建，直接带来隐私与版权风险。需要可操作的定义与度量，而非笼统的「模型记住了」。

## 二、核心原理

主流定义是可提取性：若给定长度为 $k$ 的前缀，模型贪婪解码能续出训练集中原本紧随其后的字符串，则该串被判为可提取记忆。

- 记忆量随模型规模、样本在语料中的重复次数、以及提示前缀长度单调上升。
- 重复是最强驱动因素：去重可显著降低逐字记忆而对困惑度影响有限。

## 三、数学形式

$k$-可提取记忆：存在前缀 $p$ 使 $|p|=k$ 且 $\mathrm{greedy}_\theta(p)=s$，其中 $(p\Vert s)\subseteq \mathcal{D}_{train}$。

记忆率经验上近似 $M \propto \log(\text{重复次数})\cdot N^{\beta}$，$N$ 为参数量，$\beta>0$。

## 四、代码实现

```python
def k_extractable(model, tok, prefix, suffix, max_new=64):
    ids = tok(prefix, return_tensors="pt").input_ids
    out = model.generate(ids, max_new_tokens=max_new, do_sample=False)
    gen = tok.decode(out[0, ids.shape[1]:], skip_special_tokens=True)
    return gen.strip().startswith(suffix.strip())
```

## 五、与其他对比

- 与知识记忆对照：逐字记忆是表层串复制，知识记忆是可泛化的关系映射，治理策略不同。
- 与 记忆度量与提取攻击 衔接：可提取性定义直接支撑攻击评估流程。

## 六、常见误区

- 认为只有小数据集才会记忆；大规模语料中的高重复片段同样被逐字记住。
- 用采样解码测试记忆却不固定随机性，导致结论不可复现。

## 八、面试题

- 如何定义逐字记忆？答：给定 $k$ 长前缀能贪婪续出训练集原文，即 $k$-可提取。
- 最有效的缓解手段？答：训练数据去重，其次是差分隐私与输出侧过滤。

## 九、演进

个案抽取（2021）→ 规模化量化与规模律（2023）→ 去重与隐私训练 → 输出侧检测与遗忘。

## 十、小结

逐字记忆有清晰可测的定义，其主因是数据重复，治理应优先在数据侧。
