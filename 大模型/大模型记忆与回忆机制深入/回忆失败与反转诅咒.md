# 回忆失败与反转诅咒

> 对应 Berglund et al., *The Reversal Curse*, ICLR 2024；Kandpal et al., *LLMs Struggle to Learn Long-Tail Knowledge*, ICML 2023。

## 一、背景与挑战

模型能答「A 的配偶是 B」却答不出「B 的配偶是 A」，也常在长尾实体上失败。这说明参数化记忆是有向的、频次驱动的，而非对称知识图。

## 二、核心原理

自回归训练只优化「给定左侧预测右侧」，因此学到的是方向性条件分布，反向映射并不自动获得。

- 反转诅咒：仅以 A→B 形式训练的事实，其 B→A 的对数似然几乎不提升。
- 长尾效应：某实体相关问答准确率与该实体在预训练语料中的出现频次强相关，低频实体回忆率显著下降。

## 三、数学形式

训练目标只最大化 $\log p_\theta(B\mid A)$，不含 $\log p_\theta(A\mid B)$ 项，故梯度不驱动反向映射。

即使贝叶斯上 $p(A\mid B)=\frac{p(B\mid A)p(A)}{p(B)}$，模型并不显式做这一推断，除非上下文中给出可组合线索。

## 四、代码实现

```python
def reversal_gap(model, tok, a, b, rel="的配偶是"):
    fwd = recall_prob(model, tok, f"{a}{rel}", b)
    bwd = recall_prob(model, tok, f"{b}{rel}", a)
    return round(fwd - bwd, 3)                       # 显著为正即反向缺失
```

## 五、与其他对比

- 与检索增强对照：RAG 在检索侧对称索引，可绕过反转诅咒。
- 与 知识定位与神经元归因深入 衔接：编辑一条事实通常不会自动修好其反向与派生问法。

## 六、常见误区

- 把反转失败当作推理能力缺失；这是训练目标方向性造成的记忆结构问题。
- 认为增大规模自然解决；实验显示反转差距在多种规模下持续存在。

## 八、面试题

- 什么是反转诅咒？答：单向训练的事实无法自动支持反向提问，反向似然几乎不提升。
- 工程上如何缓解？答：数据增强双向表述、引入检索、或在微调中显式加入反向样本。

## 九、演进

长尾频次效应（2023）→ 反转诅咒系统化（2024）→ 双向数据增强 → 检索与参数记忆混合。

## 十、小结

回忆失败常源于记忆的方向性与频次依赖，解法在数据构造与外部检索，而非单纯扩规模。
