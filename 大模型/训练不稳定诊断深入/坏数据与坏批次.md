# 坏数据与坏批次

> 见「训练不稳定诊断深入/训练不稳定总览」与「训练数据质量」；数据致不稳定。

## 一、背景与挑战

个别极长/损坏样本引发 spike。

## 二、核心原理

坏 batch（如超长序列、损坏 token、极端重复）使单步 loss 飙升。缓解：序列长度截断/分桶、数据质量过滤（见训练数据质量）、丢弃异常 batch、动态掩码。预训练常对超长样本做 pack/split。

## 三、关键要点

- 长序列是 spike 常见源。
- 过滤优于硬训。

## 四、代码实现

```python
if seq_len > MAX: sample = truncate_or_split(sample)
```

## 五、与其他对比

- 硬训崩；过滤稳。

## 六、常见误区

- 数据都干净——长尾样本惹祸。
