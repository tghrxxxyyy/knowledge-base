# 注意力数值问题

> 见「训练不稳定诊断深入/训练不稳定总览」与「注意力数学基础」；softmax 数值。

## 一、背景与挑战

注意力 logits 过大/过小致 softmax 数值不稳。

## 二、核心原理

长序列/大 logits 使 softmax 入参极端，引发溢出或梯度消失。解决：缩放点积（除以 √d_k，见注意力章）、在线 softmax（稳定累加）、fp32 计算 softmax（混合精度陷阱章）、FlashAttention 的在线归一化避免存大矩阵。

## 三、关键要点

- √d_k 缩放不可省。
- softmax 内部宜 fp32。

## 四、代码实现

```python
s = (Q@K.T)/sqrt(d)          # 缩放
s = s - s.max(-1, keepdim=True)   # 数值稳定
p = softmax(s)
```

## 五、与其他对比

- 无缩放易爆；缩放稳。

## 六、常见误区

- softmax 数值安全——极端值仍溢。
