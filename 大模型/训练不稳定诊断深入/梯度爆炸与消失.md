# 梯度爆炸与消失

> 见「训练不稳定诊断深入/训练不稳定总览」与「残差连接深入」；老问题新规模。

## 一、背景与挑战

梯度异常使训练无效或崩。

## 二、核心原理

- **爆炸**：梯度范数剧增→参数跳飞→NaN。缓解：梯度裁剪（clip）、合理初始化、归一化。
- **消失**：梯度趋零→浅层不更新。缓解：残差、非饱和激活、归一化。大模型靠 Pre-LN+残差+好初始化基本化解。

## 三、数学形式

裁剪：`g ← g·min(1, θ/||g||)`。

## 四、代码实现

```python
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

## 五、关键要点

- 裁剪防爆炸，不解决消失。
- 监控梯度范数趋势。

## 六、与其他对比

- 爆炸需裁；消失需结构。

## 七、常见误区

- 裁剪治百病——只防爆炸。
