# 训练不稳定总览

> 对应 d2l-zh 与「训练技巧与稳定性」；大模型训练易崩。

## 一、背景与挑战

大模型训练动辄数周，loss 突刺/Nan 即浪费巨资。

## 二、核心原理

不稳定表现：loss spike（尖刺）、NaN/Inf、发散。原因：学习率过大、数值溢出（见数值稳定性）、bad batch、初始化不当、激活爆炸、注意力 logits 过大。需监控与快速定位。

## 三、关键要点

- spike 在大模型预训练中较常见，可回滚。
- 监控 loss/梯度/激活分布。

## 四、代码实现

```python
if not torch.isfinite(loss): rollback_to_last_ckpt()
```

## 五、与其他对比

| 现象 | 可能原因 |
|------|----------|
| NaN | 除零/溢出 |
| spike | 坏 batch/学习率 |

## 六、常见误区

- spike 必崩——常可恢复。
