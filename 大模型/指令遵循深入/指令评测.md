# 指令遵循评测

> 对应 FLAN/HHH；MT-Bench（Zheng et al., 2023）。

## 一、背景与挑战

评测需覆盖遵循度、帮助性、约束合规，而非仅流畅。

## 二、核心原理

用多轮对话基准与 LLM 评委打分；约束类用程序化校验（正则/解析）判定履约。

## 三、数学形式

遵循率 $CR=\frac{\#constraints\_met}{\#constraints}$；整体用成对胜率。

## 四、代码实现

```python
ok = all(check(c) for c in constraints(resp))
```

## 五、与其他对比

- 与 模型评测指标深入 共享。
- 与 工具学习评测 交叉。

## 六、常见误区

- 仅用人工流畅度忽略约束违约。
- 评委 LLM 有偏需校准。

## 八、面试题

- MT-Bench 评什么？答：多轮对话的能力与遵循度，用 LLM 评委近似人类判断。

## 九、演进

单轮→多轮→约束程序化评测。

## 十、小结

指令评测要程序化校验约束，避免主观偏差。
