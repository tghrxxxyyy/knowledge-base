# 指令遵循总览

> 对应 Ouyang et al., *InstructGPT*, 2022；Wei et al., *FLAN*, 2021。

## 一、背景与挑战

预训练模型懂语言但不按指令办事；指令遵循让模型把能力对齐到用户意图。

## 二、核心原理

通过大规模（指令, 回答）微调（SFT）+ 偏好对齐，使模型理解并遵循多样自然语言指令，含格式/约束。

## 三、数学形式

SFT 最大似然 $\mathcal L_{SFT}=-\sum_t\log p_\theta(y_t|x,y_{<t})$；对齐用 RLHF/DPO 提升遵循度。

## 四、代码实现

```python
loss = model(input_ids, labels=labels).loss
loss.backward(); opt.step()
```

## 五、与其他对比

- 与 工具学习（结构化输出）强相关。
- 与 直接偏好优化 共享对齐目标。

## 六、常见误区

- 以为指令微调=更多数据，忽视多样性。
- 忽视约束类指令（长度/格式）易违约。

## 八、面试题

- 指令微调为何有效？答：用多样（指令,输出）对齐训练分布到"按指令响应"，激发已有能力。

## 九、演进

零样本→FLAN 多任务→InstructGPT 对齐。

## 十、小结

指令遵循是把 LLM 变成可用助手的关键对齐环节。
