# 约束与格式遵循

> 对应格式约束生成（JSON/YAML）；约束解码研究。

## 一、背景与挑战

用户常要求长度、结构、禁忌等硬约束，违约即不可用。

## 二、核心原理

软约束靠指令+示例；硬约束用约束解码（如 Guidance/Outlines）在生成时强制语法/模式，保证可解析。

## 三、数学形式

约束集 $\mathcal C$；解码约束 $p(y_t)\propto p_\theta(y_t)\cdot \mathbb I[y_{<t}y_t\in\text{prefix}(\mathcal C)]$。

## 四、代码实现

```python
from outlines import models, generate
schema = '{"name": str, "age": int}'
gen = generate.json(models.llama(), schema)
```

## 五、与其他对比

- 与 工具学习（JSON 调用）共享结构化。
- 与 长上下文（长约束）互补。

## 六、常见误区

- 仅指令要求 JSON 仍可能非法（需约束解码）。
- 过度约束限制表达致质量降。

## 八、面试题

- 如何保证 JSON 合法？答：用约束解码/语法引导，在每一步仅允许符合 schema 的 token。

## 九、演进

提示要求→正则后处理→约束解码。

## 十、小结

硬约束需解码期强制，约束解码是可靠输出基石。
