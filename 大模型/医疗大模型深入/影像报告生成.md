# 影像报告生成

> 对应 MIMIC-CXR 数据集（Johnson et al. 2019）、医学多模态综述与「多模态生成深入」相关章节。

## 一、背景与挑战

放射科医师需为 X 光、CT、MRI 等影像撰写结构化报告（含「检查所见」「印象/诊断」），工作量大且依赖经验。影像报告自动生成旨在减轻负担，但挑战严峻：一是医学术语必须精确，错一字可能误导临床；二是「漏诊」（未报告关键病灶）比「误报」更危险；三是需将影像定位与文本描述对齐，避免「张冠李戴」。

## 二、核心原理

典型架构为视觉-语言模型：视觉编码器（如 ViT、CNN 或 Rad-DINO）将影像编码为视觉特征，再通过跨模态注意力送入语言解码器生成报告。训练数据来自配对数据集（如 MIMIC-CXR：胸部 X 光 + 放射报告）。为降低漏诊，常引入「异常检测先验」或「部位引导生成」，并对关键发现施加更高的召回权重。推理时可采用检索增强（检索相似既往报告作模板）。

## 三、形式化与数学基础

设影像 $I$ 经编码器得特征 $V = E_{\text{vis}}(I)$，报告 token 序列 $y=(y_1,\dots,y_T)$ 自回归生成，条件于 $V$ 与已生成前缀：

$$
p(y \mid I) = \prod_{t=1}^{T} p_\theta(y_t \mid y_{<t}, V)
$$

跨模态注意力在第 $l$ 层计算文本查询 $Q$ 对视觉键 $K=V$ 的加权：

$$
\text{Attn}(Q,K,V) = \text{Softmax}\left(\frac{QK^\top}{\sqrt{d}}\right) V
$$

为抑制漏诊，可对关键病灶类别 $c$ 引入召回敏感损失，提升 $p(\text{mention}(c)\mid I)$ 的下界。

## 四、代码实现

```python
from transformers import VisionEncoderDecoderModel

model = VisionEncoderDecoderModel.from_pretrained("microsoft/biomedclip-pretrained")

def generate_report(image):
    pixel = preprocess(image).unsqueeze(0)
    features = model.encoder(pixel)          # 视觉编码
    out = model.decoder.generate(
        inputs_embeds=features,
        max_length=256,
        num_beams=4,
    )
    report = decode(out[0])
    # 临床核对：关键发现召回校验
    if not mention_key_findings(report, image):
        report += "\n[注意] 部分关键征象未明，请医师复核。"
    return report
```

## 五、与其他技术对比

| 任务 | 深度 | 风险 | 评价 |
|------|------|------|------|
| 通用图像描述 | 浅 | 低 | 流畅即可 |
| 医学影像报告 | 深 | 高 | 须精确+召回 |
| 检测框标注 | 中 | 中 | 定位优先 |

通用 captioning 只需语义合理，医学报告要求术语精确且不可漏诊。

## 六、常见误区

- 误区一：报告流畅=正确。语言流畅掩盖不了临床错误，须医师核对。
- 误区二：把生成当最终诊断。报告仅辅助，需放射科医师签发。
- 误区三：忽略漏诊代价。漏报关键病灶比误报危害更大。
- 误区四：直接套用通用多模态模型。缺医学对齐会产出幻觉术语。

## 九、演进与趋势

从模板填充、检索式生成，到端到端多模态大模型（视觉编码器 + LLM 解码器），再到「定位—描述—追问」一体化与多模态 Agent。趋势是引入分割先验提升定位一致性，以及可解释注意力可视化辅助医师信任。

评测除 BLEU/ROUGE 外，更应关注临床指标：病灶召回率（漏诊率）、描述与影像定位一致性、放射科医师偏好评分。仅靠文本相似度会掩盖流畅但漏诊的风险，故临床终点评测不可或缺。

- 召回优先：漏诊率是最关键的安全指标。
- 一致性：描述须对齐影像定位区域。
- 医师评分：以专家偏好作为临床终点。
- 分割先验：引入检测框提升定位一致。
- 失败兜底：低置信报告强制医师复核。

## 十、小结

影像报告生成是医学多模态的重要落地场景，核心难点是术语精确与漏诊防控。应以视觉-语言架构为基础、以召回敏感训练与医师复核为保障，定位为减轻负担的辅助工具而非自动诊断。
