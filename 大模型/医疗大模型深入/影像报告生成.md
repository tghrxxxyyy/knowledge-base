# 影像报告生成

> 见「多模态生成深入」与「医疗大模型深入/医疗应用概况」。

## 一、背景与挑战

从 X 光/CT/MRI 自动生成放射科报告，减轻医生负担。

## 二、核心原理

视觉编码器读影像，语言模型生成结构化报告（发现/印象），需与放射知识对齐并避免漏诊。

## 三、关键要点

- 漏诊比误报更危险。
- 需定位与描述一致。

## 四、代码实现

```python
report = medlm.generate(encode_image(xray))
```

## 五、与其他对比

- 通用 captioning 浅；医学需术语精确。

## 六、常见误区

- 报告流畅=正确——需临床核对。
