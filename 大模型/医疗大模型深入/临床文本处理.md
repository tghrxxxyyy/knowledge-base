# 临床文本处理

> 见「医疗大模型深入/医疗应用概况」与「自然语言处理」基础。

## 一、背景与挑战

电子病历含缩写、非标准表述、隐私信息，处理复杂。

## 二、核心原理

NER 抽取实体（疾病/药物/症状）、去标识化（脱敏 PII）、结构化（ICD 编码），再供模型使用。

## 三、代码实现

```python
entities = clinical_ner(note); note_anon = deid(note)
```

## 四、关键要点

- 脱敏合规（HIPAA/国内规范）必做。
- 缩写消歧难。

## 五、与其他对比

- 通用 NER 弱；临床 NER 需领域字典。

## 六、常见误区
