# 临床文本处理

> 对应 scispaCy（allenai）、ClinicalBERT/BioBERT 与 llm-course mlabonne；基础见自然语言处理相关章节。

## 一、背景与挑战

电子病历（EMR/EHR）是自然语言写成、充满缩写、非标准表述、错别字与领域术语的自由文本，例如「BP 140/90，pt c/o HA，rule out MI」。直接用于模型存在三大挑战：一是实体歧义（同一缩写多义、口语化表述）；二是隐私合规（含大量 PII，须去标识化）；三是结构化缺失（需映射到 ICD/LOINC/SNOMED 等标准编码）。临床文本处理是医疗 AI 的前置工程，质量直接决定下游任务上限。

## 二、核心原理

处理流水线通常为：文本清洗 → 临床命名实体识别（Clinical NER，抽取疾病、药物、症状、解剖部位、检查）→ 去标识化（de-identification，脱敏姓名/日期/联系方式等 PII）→ 实体正则化（链接到标准术语库）→ 结构化（ICD 编码、表格化）。传统方法依赖规则与领域字典（如 cTAKES、MetaMap）；现代方法用临床语料微调的 BERT（如 ClinicalBERT、BioBERT）或 LLM 零样本抽取。

## 三、形式化与数学基础

Clinical NER 建模为序列标注，对每个 token $x_i$ 预测标签 $y_i \in \mathcal{Y}$。以 BIO 体系，条件随机场（CRF）解码最大化联合概率：

$$
\hat{y} = \arg\max_{y \in \mathcal{Y}^n} \sum_{i=1}^n \big[\phi(x_i, y_i) + \psi(y_{i-1}, y_i)\big]
$$

其中 $\phi$ 为发射特征，$\psi$ 为相邻标签转移约束（保证 B-疾病 后接 I-疾病 而非 O）。去标识化可视为二分类：

$$
p(\text{PII} \mid x_i) = \sigma(W h_i + b), \quad h_i = \text{Encoder}(x)_{i}
$$

## 四、代码实现

```python
import spacy

nlp = spacy.load("en_core_sci_sm")  # scispaCy 临床模型

def process_note(note: str):
    doc = nlp(note)
    entities = [(e.text, e.label_) for e in doc.ents]  # 实体抽取
    # 去标识化：替换 PII 实体
    anon = note
    for e in doc.ents:
        if e.label_ in {"PERSON", "DATE", "PHONE", "EMAIL"}:
            anon = anon.replace(e.text, f"[{e.label_}]")
    return entities, anon

entities, note_anon = process_note("Patient John, DOB 1980-05-12, c/o chest pain.")
```

## 五、与其他技术对比

| 方法 | 准确率 | 领域适配 | 成本 |
|------|--------|----------|------|
| 规则/字典 | 中 | 高（需维护） | 低 |
| 监督 NER | 高 | 中 | 中（需标注） |
| LLM 零样本 | 中高 | 高 | 高 |

通用 NER（如 spaCy 英文模型）对临床缩写与术语识别弱，必须用临床专用模型或字典增强。

## 六、常见误区

- 误区一：直接把病历喂给通用大模型。隐私风险极高，且通用模型不懂临床缩写。
- 误区二：去标识化即绝对安全。准标识符（年龄+性别+zip）仍可重识别。
- 误区三：缩写消歧靠词典即可。上下文依赖强，常需模型级理解。
- 误区四：结构化编码可全自动。ICD 编码复杂，仍须医生复核。

## 九、演进与趋势

从规则系统（cTAKES/MetaMap）到监督式临床 NER（ClinicalBERT），再到 LLM 零样本/少样本抽取与「抽取—编码—生成」一体化。趋势是端到端结构化、多语言临床处理，以及与 RAG 结合的知识增强抽取。

中文医疗场景还面临分词与术语标准差异（ICD-10 国标版 vs 国际版）、方言与口语化挑战，常需中英双语字典与本地化标注。LLM 正被用于病历结构化抽取与术语归一，降低人工标注依赖，但关键诊断编码仍须医师复核。脱敏须兼顾去标识与保留临床语义，避免过度脱敏致下游任务失效。

- 标准对齐：编码映射需权威字典与版本管理。
- 语义保留：脱敏不破坏关键临床信息。
- 医师复核：关键诊断编码不可全自动。
- 本地化：中文术语与方言需专项处理。
- 抽取增强：LLM 零样本降低标注成本。

## 十、小结

临床文本处理是医疗 AI 的前置工程，涵盖实体抽取、去标识化与标准编码。须以领域模型与合规脱敏为基础，避免直接暴露隐私，并为下游问诊、报告、RAG 提供结构化、可信的输入。
