# 医疗应用概况

> 对应 llm-course 与医疗 LLM 综述；基准见 Jin et al., *MedQA*, 2021。

## 一、背景与挑战

医疗对准确性、安全、合规要求极高，幻觉可能致命。

## 二、核心原理

在医学语料（文献/指南/电子病历）预训练/微调，支持问诊辅助、文献问答、报告生成，需强循证与合规。

## 三、关键要点

- 必须引用证据与指南。
- 定位辅助而非替代医生。

## 四、代码实现

```python
ans = rag_over_guidelines(q, med_rag, with_citation=True)
```

## 五、与其他对比

- 通用模型缺医学深度；医疗模型更专。

## 六、常见误区

- 医疗模型可直接诊断——需医生把关。
