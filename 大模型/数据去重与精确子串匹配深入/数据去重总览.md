# 数据去重总览

> 对应 Lee et al., *Deduplicating Training Data Makes Language Models Better*, 2022（去重提升困惑度与下游）；Brown et al., *GPT-3*, 2020（去除重复网页）。

## 一、背景与挑战

预训练语料多来自网络爬取，同一内容（新闻转载、模板页、许可证文本）高度重复；重复样本使模型过拟合、放大偏见、浪费算力。

## 二、核心原理

去重分两层：精确去重（完全相同或归一化后相同）与近似去重（子串/语义相似）。主流以文档或子片段的 $n$-gram 集合做重叠判定，删除高重叠样本。

## 三、数学形式

文档 $D$ 的 $n$-gram 集合记为 $G_n(D)$；两文档重叠率常用 Jaccard：
$J(D_1,D_2)=\frac{|G_n(D_1)\cap G_n(D_2)|}{|G_n(D_1)\cup G_n(D_2)|}$，超过阈值 $\tau$ 视为重复。

## 四、代码实现

```python
def jaccard(a, b):
    a, b = set(a), set(b)
    return len(a & b) / len(a | b)

def is_dup(d1, d2, n=13, tau=0.8):
    return jaccard(ngrams(d1, n), ngrams(d2, n)) >= tau
```

## 五、与其他对比

- 与 数据质量过滤与困惑度过滤深入（规则过滤）互补：先去重再过滤。
- 与 多语种分词与挑战深入 不同，去重关注样本间重叠而非 token 切分。

## 六、常见误区

- 阈值 $\tau$ 过高漏去重、过低误删非重复；需按语料验证。
- 仅在文档级去重而忽略跨文档长片段复制（如 Boilerplate）。

## 八、面试题

- 为何去重能提升模型？答：去除重复降低过拟合与偏见放大，等价于有效数据量提升。

## 九、演进

精确哈希 → n-gram 重叠 → MinHash/LSH 近似 → 语义去重。

## 十、小结

去重是预训练数据管线基础步骤，以 n-gram 重叠判定为主，需谨慎设阈值。
