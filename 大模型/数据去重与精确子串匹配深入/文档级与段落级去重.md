# 文档级与段落级去重

> 对应 Lee et al., 2022（文档与子串两级）；Gao et al., *The Pile*, 2020（重复样本处理）。

## 一、背景与挑战

仅文档级去重会漏掉“文档 A 复制 B 的某段落”的场景；段落级去重更细但更贵。

## 二、核心原理

文档级：整篇指纹比对删除重复整篇。段落级：把文档切成段落/滑动窗口，对片段指纹做重叠，删除高重叠片段并保留独立片段。

## 三、数学形式

片段集合 $\{s_i\}$；若 $\max_j J(s_i, s_j)>\tau$ 则删 $s_i$。保留的片段再拼回训练样本。

## 四、代码实现

```python
def dedupe_paragraphs(paras, tau=0.7):
    keep = []
    for p in paras:
        if not any(jaccard(p, k) > tau for k in keep):
            keep.append(p)
    return keep
```

## 五、与其他对比

- 段落级更省误删，但需切分且计算更繁。
- 与 数据质量过滤与困惑度过滤深入（先去重后质量过滤）管线顺序。

## 六、常见误区

- 段落切分破坏上下文，过度切碎致样本不可用。
- 片段阈值与文档阈值混用。

## 八、面试题

- 段落级去重意义？答：去除跨文档长片段复制，避免整篇去重的漏删。

## 九、演进

文档级 → 段落级 → 句子级 → 语义片段。

## 十、小结

段落级去重补文档级之漏，按成本选择性启用。
