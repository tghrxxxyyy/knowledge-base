# 优化理论总览

> 对应 d2l-zh「优化算法」章与 Goodfellow《Deep Learning》第 8 章；Sutskever et al., *On the importance of initialization and momentum*, 2013。

## 一、背景与挑战

深度模型训练即在一个高维非凸损失地形上寻找使损失最小的参数。优化算法的选择直接决定收敛速度、最终精度与训练稳定性。

## 二、核心原理

训练目标是最小化经验风险 `L(θ)=E_{(x,y)}[ℓ(fθ(x),y)]`。梯度下降沿负梯度方向更新；现代训练几乎都用**小批量随机梯度下降（mini-batch SGD）**，用噪声梯度近似真实梯度以兼顾效率与泛化。

## 三、数学形式

```
θ_{t+1} = θ_t - η·g_t,   g_t = ∇_θ (1/|B|) Σ_{i∈B} ℓ(fθ(x_i), y_i)
```

其中 η 为学习率，B 为 batch。批量越大梯度越准但每步代价越高；小批量引入噪声，常有助于逃离尖锐极小值。

## 四、代码实现

```python
import torch
opt = torch.optim.SGD(model.parameters(), lr=0.1, momentum=0.9)
for x, y in loader:
    opt.zero_grad()
    loss = criterion(model(x), y)
    loss.backward()
    opt.step()
```

## 五、关键要点

- 学习率是最重要超参，过大发散、过小收敛慢。
- 动量累积历史梯度方向，加速收敛并抑制震荡。
- 非凸地形存在大量鞍点，高维中鞍点比局部极小更常见（Dauphin et al., 2014）。

## 六、与其他对比

| 方法 | 每步代价 | 收敛 | 泛化 |
|------|----------|------|------|
| 全批量 GD | 高 | 稳 | 易过拟合 |
| mini-batch SGD | 中 | 噪声 | 常更好 |

## 七、常见误区

- 认为「收敛到全局最小」——非凸问题只保证到临界点。
- 学习率越小越好——过小会卡在尖锐极小、收敛极慢。

## 十一、小结

优化是「在混沌地形中找好解」的艺术，学习率与批量是关键旋钮。
