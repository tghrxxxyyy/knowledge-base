# 学习率调度

> 对应 d2l-zh 优化章；Goyal et al., *Accurate, Large Minibatch SGD*, 2017（warmup）；Loshchilov & Hutter, *SGDR*, 2016。

## 一、背景与挑战

恒定学习率难以兼顾「前期快速下降」与「后期精细收敛」，需随训练动态调整。

## 二、核心原理

- **Warmup（预热）**：前若干步从极小 lr 线性升到目标值，避免初期大梯度破坏随机初始化（Goyal et al., 2017）。
- **Cosine Decay**：lr 按余弦平滑下降到接近 0，是大模型主流。
- **Step/Exponential**：分阶段阶跃或指数衰减。
- **Linear+Linear**：上升再线性下降，常见于 BERT。

## 三、数学形式

Cosine decay：
```
η_t = η_min + 0.5(η_max - η_min)(1 + cos(π t / T))
```

## 四、代码实现

```python
from torch.optim.lr_scheduler import CosineAnnealingLR, LinearLR
sched = CosineAnnealingLR(opt, T_max=total_steps)
```

## 五、关键要点

- Warmup 步数需与 batch 大小成正比（大 batch 需更长 warmup）。
- 学习率重启（SGDR）可跳出局部极小。
- 末段 lr 过小可能拖慢；可保留最小 lr。

## 六、与其他对比

- 恒定 lr 简单但不稳；余弦更平滑、终值低。
- 阶梯衰减需手动定里程碑。

## 七、常见误区

- 无视 warmup——大学习率+大 batch 直接发散。
- 调度比优化器更重要——两者都关键。
