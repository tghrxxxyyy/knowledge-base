# 梯度下降变体

> 对应 d2l-zh 优化章；Kingma & Ba, *Adam*, 2014；Loshchilov & Hutter, *AdamW*, 2019。

## 一、背景与挑战

不同梯度下降变体在收敛速度、对超参的敏感度与内存占用上差异巨大，需按任务选择。

## 二、核心原理

- **SGD+Momentum**：`v_t = βv_{t-1} + g_t; θ -= ηv_t`，用指数滑动平均平滑梯度。
- **RMSProp**：对每个参数按历史梯度平方自适应缩放学习率。
- **Adam**：结合动量（一阶矩）与 RMSProp（二阶矩）：
```
m_t = β1 m_{t-1} + (1-β1) g_t
v_t = β2 v_{t-1} + (1-β2) g_t^2
θ -= η·m̂_t / (√v̂_t + ε)
```
- **AdamW**：将权重衰减从梯度中解耦，单独施加 L2，效果显著更好（Loshchilov & Hutter, 2019）。

## 三、数学形式

见上 Adam 更新；AdamW 的衰减项为 `θ -= η·λ·θ`，与梯度无关。

## 四、代码实现

```python
torch.optim.AdamW(model.parameters(), lr=2e-5, weight_decay=0.01, betas=(0.9, 0.95))
```

## 五、关键要点

- Adam 收敛快但泛化有时弱于调好的 SGD（Wilson et al., 2017）。
- Transformer 类大模型几乎都用 AdamW + 预热。
- β2 取 0.95 在 LLM 预训练中更稳（如 PaLM）。

## 六、与其他对比

- SGD 泛化好但难调；Adam 易调但可能过拟合。
- AdamW 优于 Adam 的关键在解耦衰减。

## 七、常见误区

- 把 Adam 的 weight_decay 当普通 L2——AdamW 才正确解耦。
- 默认可用默认 β——大模型需调 β2。
