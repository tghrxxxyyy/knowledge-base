# 尖锐与平坦极小值

> 对应 Keskar et al., *On Large-Batch Training*, 2016；Hochreiter & Schmidhuber, *Flat Minima*, 1997；Foret et al., *SAM*, 2020。

## 一、背景与挑战

损失地形中不同极小值泛化能力差异巨大：平坦（low-curvature）区域常泛化更好。

## 二、核心原理

- **Sharp vs Flat**：在参数邻域内损失变化小的「平坦」极小值更鲁棒，对数据扰动不敏感，泛化优（Hochreiter & Schmidhuber, 1997）。
- **大批量训练**倾向于收敛到尖锐极小，泛化变差（Keskar et al., 2016），故需 warmup/小批量噪声。
- **SAM（Sharpness-Aware Minimization）**：显式寻找既低损又平坦的点，在每步同时最小化邻域最大损失：
```
min_θ max_{||ε||≤ρ} L(θ+ε)
```

## 三、数学形式

平坦度可用 Hessian 最大特征值（sharpness）度量；SAM 用梯度上升求 ε 再更新。

## 四、代码实现

```python
# SAM 需双反向；示意
eps = rho * grad / grad.norm()
loss_adv = loss_fn(params + eps)
```

## 五、关键要点

- 平坦 ≠ 低训练 loss，而是低损且邻域平缓。
- 学习率、批量、扰动噪声都影响最终平坦度。
- 权重衰减与 SAM 都倾向平坦解。

## 六、与其他对比

- 普通 SGD 不显式约束平坦；SAM 显式优化。

## 七、常见误区

- 训练 loss 最低即最好——可能尖锐过拟合。
