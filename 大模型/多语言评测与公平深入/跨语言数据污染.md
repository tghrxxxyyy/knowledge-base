# 跨语言数据污染

> 对应多语言基准污染与跨语言泄漏（cross-lingual contamination）研究。

## 一、背景与挑战

多语基准（如翻译版 MMLU）可能其英源已进训练集，模型借跨语言对齐"作弊"答对非英语题。污染在跨语言场景更隐蔽。

## 二、核心原理

检测：英源 n-gram 重叠、跨语言同题重测一致性、以及用未公开原生多语新题对照。关键证明"非英语分来自对齐而非能力"。

## 三、数学形式

跨语言泄漏增益：

$$
G=\mathrm{Acc}_l-\mathrm{Acc}_l^{\mathrm{heldout}}
$$

对齐归因：

$$
A=\mathrm{Acc}_l-\mathrm{Acc}_l^{\mathrm{no-align}}
$$

## 四、代码实现

```python
def leak_gain(contam, clean):
    return contam - clean

print(round(leak_gain(0.75, 0.55), 3))
```

## 五、与其他对比

相比单语污染，跨语言污染借对齐传播；相比能力评测，它解释分数来源。

## 六、常见误区

误区一：非英语高分即原生能力（可能借英源）。误区二：以为翻译题未泄漏（英源已泄漏）。误区三：忽略对齐通道。

## 八、面试题

- Q：跨语言污染特殊在哪？答：借英源 + 对齐通道，非英语题也能被泄漏。
- Q：如何证明原生能力？答：用未公开原生多语新题对照。

## 九、演进

从单语污染审计到跨语言泄漏检测，多语评测可信度依赖此诊断。

## 十、小结

跨语言污染借对齐隐秘传播，是 multilingual 评测必须排除的混淆。
