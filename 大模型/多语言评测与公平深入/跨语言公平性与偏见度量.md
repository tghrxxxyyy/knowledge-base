# 跨语言公平性与偏见度量

> 对应多语言公平评测与社会偏见跨语言传播研究。

## 一、背景与挑战

模型在英语上表现好却在同任务其他语言上带更强偏见（如性别、宗教刻板）。公平性需跨语言一致，而非仅英语公平。

## 二、核心原理

在每种语言跑社会偏见探针（如职业-性别关联），比较跨语言偏见幅度差异。公平度量包括群体均等（demographic parity）与跨语言偏见方差。

## 三、数学形式

群体均等差：

$$
\Delta_{\mathrm{dp}}=|P(\hat{y}=1\mid g_1)-P(\hat{y}=1\mid g_2)|
$$

跨语言偏见方差：

$$
\mathrm{Var}_l=\mathrm{Var}\big(\mathrm{Bias}_l\big)
$$

## 四、代码实现

```python
def dp_diff(p1, p2):
    return abs(p1 - p2)

print(round(dp_diff(0.7, 0.4), 3))
```

## 五、与其他对比

相比能力评测，公平性关注分布而非均值；相比单语公平，跨语言要求一致。

## 六、常见误区

误区一：英语公平即全局公平。误区二：低分语言偏见小即安全（可能只是噪声）。误区三：忽略翻译放大偏见。

## 八、面试题

- Q：为何要跨语言看公平性？答：偏见可能仅在非英语放大，单语检测遗漏。
- Q：群体均等含义？答：不同群体获得正类概率应相近。

## 九、演进

从单语偏见到多语公平审计，推动跨语言对齐去偏。

## 十、小结

跨语言公平性以一致无偏为目标，是多语评测不可或缺的社会维度。
