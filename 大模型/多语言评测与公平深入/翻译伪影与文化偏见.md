# 翻译伪影与文化偏见

> 对应多语言评测中的 translation artifacts 研究与文化偏向分析。

## 一、背景与挑战

把英题机翻为多语再评测，会引入翻译伪影（语法异常、语义偏移），且题目常承载英语文化假设（节日、地名、常识），使非英语者处于不公地位。

## 二、核心原理

伪影检测：比较原生多语题与翻译题难度差异；文化偏见：用文化中立题集对照，量化模型对英语文化的偏向。评测应区分语言能力与文化的耦合。

## 三、数学形式

伪影偏移：

$$
\Delta_{\mathrm{art}}=\mathrm{Acc}_{\mathrm{native}}-\mathrm{Acc}_{\mathrm{translated}}
$$

文化偏向指数：

$$
B=\mathrm{Acc}_{\mathrm{en-culture}}-\mathrm{Acc}_{\mathrm{neutral}}
$$

## 四、代码实现

```python
def artifact_shift(native, translated):
    return native - translated

print(round(artifact_shift(0.6, 0.45), 3))
```

## 五、与其他对比

相比纯准确率，伪影/文化分析解释分数差异来源；相比单语，多语更需此诊断。

## 六、常见误区

误区一：把文化偏向当语言能力差。误区二：机翻题当原生题。误区三：忽略低资源语言评测噪声更大。

## 八、面试题

- Q：翻译伪影如何影响评测？答：机翻引入语法/语义异常，扭曲真实能力对比。
- Q：文化偏见为何不公平？答：题面承载英语文化常识，非母语者天然劣势。

## 九、演进

从翻译测试到原生多语 + 文化中立题集，评测公平性细化。

## 十、小结

翻译伪影与文化偏见是多语评测的隐藏混淆因子，需与语言能力解耦。
