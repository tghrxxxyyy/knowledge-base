# 与静态批处理对比

> 对应 Orca 对静态批处理的对比实验（Yu et al., 2022）。

## 一、背景与挑战

静态批处理实现简单但浪费严重，需量化其差距。

## 二、核心原理

静态批须等 batch 内最长序列生成完才返回并接新请求；迭代级批在每序列完成后即释放槽，新请求可插入，设备空转更少。

## 三、数学形式

静态尾延迟 $\approx \max_s \ell_s\cdot t_{step}$；迭代级尾延迟受插队影响显著降低。

## 四、代码实现

```python
# 静态：等长等待
out = [generate(req) for req in batch]  # 全完成才返回
```

## 五、与其他对比

- 与 推理延迟剖析与火焰图深入 配合可观测两类调度 Gap。
- 与 张量核心与混合精度推理深入 同属提效维度。

## 六、常见误区

- 把吞吐提升全归功于调度（也需分页/内核）。
- 忽视调度对 P99 延迟的改善。

## 八、面试题

- 静态批最大问题？答：快序列空等最慢序列，GPU 利用率与尾延迟差。

## 九、演进

整批 → 微批 → 迭代级。

## 十、小结

相比静态批，迭代级调度在吞吐与尾延迟上全面占优，代价是调度复杂度。
