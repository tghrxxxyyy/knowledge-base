# 重规划与动态调整

> 对应 Sun et al., *AdaPlanner*, NeurIPS 2023（闭环自适应规划）；Huang et al., *Inner Monologue*, CoRL 2022（环境反馈闭环）。

## 一、背景与挑战

开环计划遇到环境变化即失效：工具不可用、数据与假设不符、前置条件被破坏。
重规划要解决何时触发、改多少、以及如何避免在旧计划与新计划间反复震荡。

## 二、核心原理

- 触发条件：子目标判据失败、连续无进展、观测与计划假设冲突、预算即将耗尽。
- 修复粒度：优先局部修补（换工具、改参数、插入一步），其次替换子树，最后全局重规划，代价递增。
- 反震荡：记录已尝试方案指纹与失败原因，禁止在无新信息时回到已失败方案。

## 三、数学形式

设剩余预算 $B$、局部修补成本 $c_l$ 与期望成功率 $p_l$、全局重规划成本 $c_g$ 与 $p_g$。

选择准则可取期望效用最大：$\max\{p_l V-c_l,\ p_g V-c_g\}$，其中 $V$ 为任务价值；这解释了为何小偏差应局部修补。

## 四、代码实现

```python
def adaptive_run(llm, tools, plan, budget):
    tried = set()
    while plan and budget > 0:
        step = plan[0]
        out, cost = execute(tools, step); budget -= cost
        if check(step["done_when"], out):
            plan.pop(0); continue
        sig = fingerprint(step, out)
        if sig in tried:                       # 同一失败不重复尝试
            plan = llm.replan(step, out, plan, forbid=tried)
        else:
            tried.add(sig); plan[0] = llm.patch_step(step, out)
    return budget > 0
```

## 五、与其他对比

- 与模型预测控制（MPC）：思想一致，都是滚动优化加重规划；差别是这里状态与动力学由语言描述而非解析模型。
- 与纯 ReAct：ReAct 隐式重规划但无显式计划表征，难以判断偏离程度；显式计划便于定位与局部修补。

## 六、常见误区

- 任何失败都全局重规划，成本高且丢失已完成成果。
- 重规划不携带失败原因，新计划重复同样错误。
- 无预算约束，智能体在重规划循环中耗尽配额。

## 八、面试题

- 何时该局部修补而非全局重规划？答：偏差局限于单步且前置条件仍成立时，局部修补期望效用更高，因为成本远低。
- 如何避免重规划震荡？答：维护失败方案指纹与原因集合，无新信息时禁止回退到已失败方案，并设置预算上限。

## 九、演进

开环执行 → 失败即重试 → 显式判据触发重规划 → 分级修复（修补/子树/全局）→ 带预算与效用权衡的自适应规划。

## 十、小结

重规划是长任务鲁棒性的关键，核心是分级修复与失败记忆，避免高成本的全量重来与震荡。
