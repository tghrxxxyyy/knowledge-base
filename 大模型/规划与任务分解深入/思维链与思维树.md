# 思维链与思维树

> 对应 Wei et al., *Chain-of-Thought Prompting*, NeurIPS 2022；Yao et al., *Tree of Thoughts*, NeurIPS 2023；Besta et al., *Graph of Thoughts*, AAAI 2024。

## 一、背景与挑战

单步直答把多步推理压缩进一次前向，容量与串行深度不足导致复杂问题失败。
思维链把中间步骤显式写出，但仍是单一线性路径，一旦早期分叉走错就无法回头。

## 二、核心原理

- 思维链（CoT）：显式生成中间推理，等于用输出长度换取更多串行计算步数。
- 思维树（ToT）：把「思维」作为节点做搜索，配合状态评估与回溯，支持广度搜索、剪枝与多路径比较。
- 思维图（GoT）：允许节点聚合与复用，适合可分解再合并的任务（如多来源汇总）。

## 三、数学形式

CoT 是对隐变量的一次采样：$P(y\mid x)=\sum_z P(z\mid x)P(y\mid x,z)$，贪心解码只取单条 $z$。

ToT 在思维状态图上做搜索，目标 $\max_{z_{1:T}}\ V(z_{1:T})$，其中 $V$ 为模型自评的状态价值；搜索代价随分支因子 $b$ 与深度 $d$ 呈 $O(b^d)$，需剪枝控制。

## 四、代码实现

```python
def tree_of_thoughts(llm, x, b=3, d=3, keep=2):
    frontier = [""]
    for _ in range(d):
        cands = [f + "\n" + t for f in frontier
                 for t in llm.sample_thoughts(x, f, n=b)]
        scored = [(llm.value(x, c), c) for c in cands]      # 状态价值自评
        frontier = [c for _, c in sorted(scored, reverse=True)[:keep]]
    return llm.finalize(x, frontier[0])
```

## 五、与其他对比

- 与自我一致性：投票是无结构的并行采样；ToT 是有结构的搜索，能共享前缀并定向剪枝，但需要可用的状态评估器。
- 与过程奖励模型：PRM 可替代自评作为更可靠的价值函数，二者结合是当前推理增强的主流组合。

## 六、常见误区

- 认为 CoT 一定提升：小模型或简单任务上 CoT 可能引入无关推理反而降分。
- ToT 分支与深度设置过大导致成本爆炸，收益却因价值评估噪声被抵消。
- 用同一模型自评价值却不做校准，剪枝把正确分支剪掉。

## 八、面试题

- 为什么 CoT 能提升复杂推理？答：把并行不可及的多步计算展开为串行 token 计算，等价于增加有效计算深度与工作记忆。
- ToT 的关键瓶颈是什么？答：状态价值评估的可靠性与搜索成本，价值噪声会让剪枝伤害正确路径。

## 九、演进

直答 → CoT → 自我一致性投票 → 思维树搜索 → 思维图与外部价值函数（PRM）引导搜索。

## 十、小结

从链到树到图，本质是给推理引入结构与回溯能力，代价是搜索成本与对价值评估的依赖。
