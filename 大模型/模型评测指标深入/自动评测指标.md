# 自动评测指标

> 对应 llm-course 评估章与 d2l-zh；经典见 Papineni et al., *BLEU*, 2002。

## 一、背景与挑战

需客观比较模型生成质量，自动指标提供可复现分数。

## 二、核心原理

**BLEU** 看 n-gram 精度；**ROUGE** 看召回（摘要友好）；**METEOR** 引入语义对齐；**BERTScore** 用语义向量相似。

## 三、数学形式

BLEU 修正精度：

```
BLEU = BP · exp(Σ_n w_n log p_n)
```

## 四、代码实现

```python
from rouge import Rouge
r = Rouge(); print(r.get_scores(hyp, ref))
```

## 五、关键要点

- 这些指标与「人类感知」相关性有限。
- BERTScore 更贴近语义但计算重。

## 六、与其他对比

| 指标 | 侧重 |
|------|------|
| BLEU | n-gram 精度 |
| ROUGE | 召回 |
| BERTScore | 语义 |

## 七、常见误区

- BLEU 高=翻译好——常与现实不符。
