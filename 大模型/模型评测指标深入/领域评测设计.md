# 领域评测设计

> 见「大模型行业应用」与「模型评测深入」。

## 一、背景与挑战

通用基准不代表业务效果，需自建领域评测。

## 二、核心原理

从真实场景抽样例，定义指标（准确率/时延/合规），构造题集与 rubric，定期回归。

## 三、代码实现

```python
cases = load_domain_cases("finance")
for c in cases: assert run(c) == c.expect
```

## 四、关键要点

- 题集需持续更新防过拟合。
- 指标要结合业务目标。

## 五、与其他对比

- 公开基准横向比；领域评测纵向看业务。

## 六、常见误区

- 用公开分替代业务验收。

## 七、与开源书对应

- OpenCompass: https://github.com/open-compass/opencompass

## 九、演进

手工题 → 自动化生成 → 在线评测闭环。

## 十、小结

领域评测是模型上线的「验收标准」。
