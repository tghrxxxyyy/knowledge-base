# 评测集污染检测

> 见「模型评测指标深入/能力基准MMLU」与「训练数据质量」。

## 一、背景与挑战

若测试题混入训练数据，分虚高不可信。

## 二、核心原理

方法：n-gram 重叠检测、困惑度异常（记忆题更低）、canary 字符串追踪、留出私有测试集。

## 三、代码实现

```python
def overlap(test_q, train_text, n=13):
    return any(ng in train_text for ng in ngrams(test_q, n))
```

## 四、关键要点

- 污染常呈「某子集异常高分」。
- 需报告检测方法与结论。

## 五、与其他对比

- 普通去重防训练冗余；污染检测防评测失真。

## 六、常见误区

- 闭源模型声称高分却无法验证污染。
