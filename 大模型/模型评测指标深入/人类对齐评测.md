# 人类对齐评测

> 见「微调与对齐/RLHF概述」与「模型评测深入」。

## 一、背景与挑战

有用、诚实、无害（HHH）需专门评测，不能只看任务分。

## 二、核心原理

用人类偏好数据（如 HH-RLHF）评估对齐度；用 TruthfulQA 测诚实；用红队测安全。

## 三、关键要点

- 有用与无害可能冲突（拒答过多）。
- 对齐税：对齐后任务分可能略降。

## 四、代码实现

```python
# 用偏好数据集计算胜率
win = sum(1 for p in prefs if judge(p.chosen) > judge(p.rejected))
```

## 五、与其他对比

- 能力基准测智力；对齐评测测「人品」。

## 六、常见误区

- 对齐分高=安全——仍可被越狱。
