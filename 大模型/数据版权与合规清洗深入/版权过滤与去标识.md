# 版权过滤与去标识

> 对应 受版权文本识别（Books3 剔除）；Penedo et al., *RefinedWeb*, 2023（严格过滤）；去标识实践。

## 一、背景与挑战

需从海量语料移除明确受保护长文（如整本书），并去除可识别个人/机构信息。

## 二、核心原理

用已知受保护语料指纹（n-gram/哈希）比对剔除；去标识用正则/NER 掩蔽邮箱、电话、身份证等。

## 三、数学形式

若 $J(\text{book}_i, x)>\tau_c$ 则删 $x$；PII 掩蔽 $x\leftarrow \text{mask}_{NER}(x)$。

## 四、代码实现

```python
if any(jaccard(book, doc) > 0.85 for book in banned):
    drop(doc)
```

## 五、与其他对比

- 与 数据去重与精确子串匹配深入（指纹剔除同理）衔接。
- 与 数据版权与合规清洗深入 总览互补。

## 六、常见误区

- 仅按书名删，漏改书名/拆分的盗版。
- 去标识过度抹掉正常文本（如普通数字）。
