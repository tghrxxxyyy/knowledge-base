# 许可证与爬取合规

> 对应 Common Crawl 使用规范；HuggingFace *The Stack*（代码许可分层）；LAION 下架实践。

## 一、背景与挑战

不同许可证（CC-BY/BY-SA/专有/GPL）对训练与再分发要求不同；爬取须遵守 robots 与 ToS。

## 二、核心原理

建立许可证白/黑名单；对代码按仓库 LICENSE 分层（ permissive vs copyleft）；对网页尊重 robots.txt 与退出声明。

## 三、数学形式

可用性 $U(x)=I(\text{lic}(x)\in W)-I(\text{lic}(x)\in B)$；保留 $U(x)=1$。

## 四、代码实现

```python
from ScanCode import scan
lic = scan(repo)
if lic.family == "copyleft":
    flag_for_review(repo)
```

## 五、与其他对比

- 与 数据质量过滤与困惑度过滤深入（规则过滤）共享规则框架。
- 与 数据版权总览 衔接。

## 六、常见误区

- 把 CC-BY-SA 当可随意商用（需署名/共享）。
- 仅看文件头忽略仓库级 LICENSE。
