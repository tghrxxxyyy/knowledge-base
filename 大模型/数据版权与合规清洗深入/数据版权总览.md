# 数据版权总览

> 对应 大规模爬取语料版权争议（Books3/Stable Diffusion 诉讼背景）；Gao et al., *The Pile*, 2020（来源许可梳理）；Common Crawl 实践。

## 一、背景与挑战

预训练语料多含受版权保护的书籍、新闻、代码；爬取与训练引发授权与公平使用争议。

## 二、核心原理

需识别数据源许可（CC、开源、专有）、去除明确禁止训练的数据、记录来源以便合规响应；部分项目用公开可训练集。

## 三、数学形式

合规集 $D_{ok}=\{x: \text{license}(x)\in L_{permissive}\}$；剔除 $D_{deny}$（禁止训练/含保留声明）。

## 四、代码实现

```python
if license_of(url) in DENY_LIST:
    drop(doc)
```

## 五、与其他对比

- 与 数据质量过滤与困惑度过滤深入（合规可作一级过滤）合并。
- 与 数据去重与精确子串匹配深入（去重也减版权表面积）相关。

## 六、常见误区

- 误以为爬到即可用；需看 robots/许可。
- 忽视代码仓库许可证（GPL 等）差异。

## 八、面试题

## 九、演进

无处理 → 许可过滤 → 来源可追溯。

## 十、小结

版权清洗是合规底线，须许可识别与来源记录。
