# 合规清洗流水线

> 对应 Soldaini et al., *Dolma*, 2024（合规与去标识模块）；Penedo et al., *FineWeb*, 2024（可复现管线）。

## 一、背景与挑战

合规步骤多且需可审计；须与质量/去重管线集成并记录决策。

## 二、核心原理

将许可过滤、受保护指纹剔除、PII 去标识、退出机制串成可配置阶段，输出来源清单与处理日志以便监管响应。

## 三、数学形式

$D_{safe}= \text{PII}(\text{dedup}(\text{license}(D_{raw})))$；每步记 $\log$ 通过率。

## 四、代码实现

```python
for doc in stream:
    doc = license_filter(doc)
    doc = copyright_filter(doc)
    doc = pii_mask(doc)
    sink(doc)
```

## 五、与其他对比

- 与 数据质量过滤与困惑度过滤深入（共用流式管线）共享。
- 与 数据去重与精确子串匹配深入 顺序协调。

## 六、常见误区

- 合规阶段无日志，无法溯源应答。
- 退出机制未生效致重复爬取。
