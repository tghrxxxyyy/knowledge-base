# 法律风险与应对

> 对应 训练数据诉讼趋势（作者集体诉讼、图像模型案例）；合规响应框架；可溯源实践。

## 一、背景与挑战

各地法律对训练使用受保护作品界定不一；需准备来源证据与退出响应。

## 二、核心原理

建立数据卡（datasheet）记录来源/许可/处理；保留爬取快照与退出清单；对高争议源可降权或剔除。

## 三、数学形式

法律风险评分 $R=\sum_x w_x I(\text{lic}(x)\notin L_{clear})$；优先降 $R$ 高源。

## 四、代码实现

```python
risk = sum(weight[x] for x in docs if not clear_license(x))
```

## 五、与其他对比

- 与 数据版权总览/许可证与爬取合规 构成完整合规链。
- 与 数据混合比例课程深入（降权高风险源）相关。

## 六、常见误区

- 无数据卡致无法举证来源。
- 退出请求无流程，反复触法。

## 七、与开源书对应

## 八、面试题

- 法律风险怎么应对？答：数据卡溯源 + 退出机制 + 高争议源降权。

## 九、演进

无准备 → 数据卡 → 可溯源+退出闭环。

## 十、小结

版权合规需证据化与流程化，方可持续应对争议。
