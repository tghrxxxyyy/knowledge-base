# 线性表示假设

> 对应 Gurnee & Tegmark 2023《Language Models Represent Latent State》以及 Mikolov 2013 词向量几何研究成果。

## 一、背景与挑战

大模型的内部表示（activation）是几千维的连续向量，人无法直接解读。一个自然的问题是：模型是否把「概念」以某种结构化方式编码在向量空间中？如果语义概念能对应一个稳定的方向（direction），我们就获得了在不重新训练模型的前提下读取甚至改写其语义的「接口」。否则，可解释性与可控性都无从谈起。

早期证据来自词向量：Mikolov 等发现「king − man + woman ≈ queen」这类线性类比成立，暗示语义关系在向量空间中表现为方向。类似地，Bolukbasi 等发现 gender 方向可被显式移除。这些现象催生了「线性表示假设」（Linear Representation Hypothesis）：高维激活空间中的语义概念近似由一个线性子空间（常是单一方向）表示。

核心挑战在于：并非所有概念都线性可分；同一神经元常同时响应多个概念（多义性）；方向是否稳定、是否跨提示一致、是否真的语义而非相关性，都需要严格验证。

## 二、核心原理

线性表示假设认为，对于某个概念 $c$（如「positive sentiment」「truthfulness」「country」），存在一个方向向量 $\vec{v}_c \in \mathbb{R}^d$，使得「某文本/位置的激活在该方向上的投影」可预测/控制该概念的存在与否。

最典型的验证手段是「方向干预」（direction intervention / activation editing）：在残差流（residual stream）中对激活 $\vec{h}$ 加上或减去某个概念方向 $k\vec{v}_c$，观察生成文本是否相应改变。例如减去 gender 方向、加上 honesty 方向。若生成语义随之切换，说明该方向确实编码了概念。

这类方法属于「representation engineering」而非权重编辑：它不改模型参数，只在前向传播时修改激活，因此可逆、廉价、可按层与按 token 位置精细控制。

## 三、形式化与数学基础

设某 transformer 在第 $l$ 层、token 位置 $i$ 的残差流激活为 $\vec{h}^{(l)}_i \in \mathbb{R}^d$。定义概念 $c$ 的方向 $\vec{v}_c$（通常通过探针或 SAE 特征得到，单位化）。

方向得分（线性探测器输出）写作点积：

$$s_c(\vec{h}) = \vec{w}_c^\top \vec{h} + b_c$$

当 $s_c > 0$ 判定概念出现。干预操作在某一层注入：

$$\vec{h}'^{(l)}_i = \vec{h}^{(l)}_i + \alpha \cdot \vec{v}_c$$

其中 $\alpha$ 为干预强度（可正可负）。若概念方向已归一并用余弦相似度衡量：

$$\cos(\vec{h}, \vec{v}_c) = \frac{\vec{h}^\top \vec{v}_c}{\|\vec{h}\| \|\vec{v}_c\|}$$

高余弦相似意味着该激活「朝向」该概念。多个概念可叠加为线性组合 $\sum_j \alpha_j \vec{v}_{c_j}$，前提是概念方向近似正交（低互相关），这也是为何需要稀疏、单义的特征基。

## 四、代码实现

下面用线性探针在某一层激活上训练一个逻辑回归分类器来提取「truthful」方向，并演示激活干预。

```python
import torch
from sklearn.linear_model import LogisticRegression

# acts: 形状 [N, d] 的某一层残差流激活；labels: [N] 二分类概念标签
def train_probe(acts, labels):
    clf = LogisticRegression(max_iter=1000)
    clf.fit(acts, labels)
    # 决策边界法向量即概念方向
    v = torch.tensor(clf.coef_[0], dtype=torch.float32)
    v = v / v.norm()
    return v

# 在指定层注入方向干预
def intervene(hidden, v, alpha):
    # hidden: [seq, d] 该层残差流
    return hidden + alpha * v.unsqueeze(0)

# 示例：向 honesty 方向偏移
honesty_dir = train_probe(probe_acts, probe_labels)
patched = intervene(residual_layer12, honesty_dir, alpha=3.0)
# 用 patched 替换原激活继续前向，观察生成变化
```

注意：探针只「读」方向，干预才「写」；两者应分开评估，避免把相关性误当因果性。

## 五、与其他技术对比

| 方法 | 是否改权重 | 粒度 | 主要用途 | 可逆性 |
|------|-----------|------|----------|--------|
| 线性探针 | 否 | 方向 | 读取概念 | 仅读取 |
| 方向干预 | 否 | 层/token | 控制生成 | 前向内可逆 |
| SAE 特征 | 否 | 单义特征 | 解构多义 | 可逆 |
| ROME/模型编辑 | 是 | 事实 | 改写知识 | 永久 |
| LoRA/微调 | 是 | 全局 | 行为适应 | 永久 |

## 六、常见误区

- 误以为「方向 = 因果」：探针高准确率只说明相关性，需用干预或因果中介（causal mediation）验证是否真正驱动行为。
- 误以为所有概念都线性可分：抽象、情境依赖的概念往往没有干净方向。
- 忽略层选择：概念常在特定层最显著，跨层平均会稀释信号。
- 把多义神经元当单义：单个神经元常响应多个概念，方向视角比神经元视角更稳健。

## 七、与开源书·权威来源对应

## 九、演进与趋势

从词向量方向到 LLM 残差流方向，研究正从「是否存在」走向「如何度量与对齐方向语义」。与稀疏自编码器（SAE）结合可得到更单义、可组合的方向基；与因果中介分析结合可区分相关与因果；与对齐监控结合则用于检测危险内部状态。具体边界以官方最新论文为准。

## 十、小结

线性表示假设把语义概念映射到向量方向，为读取与改写模型内部状态提供了统一、廉价、可逆的接口。它是探针、干预、SAE 与对齐监控的共同基石，但必须辅以因果验证，避免把相关性误读为语义因果。
