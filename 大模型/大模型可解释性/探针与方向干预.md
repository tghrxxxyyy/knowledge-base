# 探针与方向干预

> 对应 Alain & Bengio 2016《Understanding intermediate layers using linear classifiers》与 Turner 2023《Activation Addition》等表示工程研究。

## 一、背景与挑战

我们需要理解模型「内部在想什么」：既想读取（探测某概念是否存在），也想改写（让模型更诚实/更安全）。探针（probe）解决「读」，方向干预（direction intervention）解决「写」。二者共享同一基础——线性表示假设：概念对应向量方向。

挑战：探针高准确率未必等于因果；干预强度难调，过强会破坏语法/流畅；方向间可能相互纠缠，单独干预引入副作用。

## 二、核心原理

线性探针：在某一层激活上训练一个线性分类器（逻辑回归/线性 SVM），其权重向量 $\vec{w}$ 即「概念方向」。探针廉价、可不改模型，用于检测内部状态（如是否浮现欺骗意图）。

方向干预：在前向时对该层残差流激活加/减概念方向 $\alpha \vec{v}_c$：

$$\vec{h}' = \vec{h} + \alpha \vec{v}_c$$

正 $\alpha$ 增强概念，负 $\alpha$ 抑制。它属于 representation engineering，不改权重、按层与 token 可控、前向内可逆。

探针的训练数据质量决定方向可靠性，标签应来自可复现的标注而非启发式猜测。
对抽象概念（如「truthfulness」），可用对比样本对（真值句与谣言句）训练线性可分方向。
探针可在多层并行训练，再比较哪层得分最高，从而定位概念最显著的表示层。
除逻辑回归外，也可用稀疏探针或 Liu probe 控制表示复杂度，避免过拟合。
探针只是读工具，要验证因果需配合方向干预：仅当干预改变行为，方向才算成立。
在工业实践中，探针常作为回归测试：模型升级后重跑，捕捉概念表示的漂移。
多个探针可组成监控面板，实时展示内部概念激活，辅助调试与对齐。

## 三、形式化与数学基础

设激活矩阵 $H \in \mathbb{R}^{N \times d}$，标签 $y \in \{0,1\}^N$。线性探针最小化：

$$\min_{\vec{w}, b} \frac{1}{N}\sum_i \log\left(1+\exp(-y_i(\vec{w}^\top \vec{h}_i + b))\right) + \lambda \|\vec{w}\|^2$$

学到的 $\vec{w}$ 经归一化得方向 $\vec{v} = \vec{w}/\|\vec{w}\|$。干预后概念得分为：

$$s' = \vec{v}^\top \vec{h}' = \vec{v}^\top \vec{h} + \alpha \|\vec{v}\|^2 = s + \alpha$$

即得分线性平移 $\alpha$。多概念叠加需方向近似正交，否则会出现串扰：

$$\vec{h}' = \vec{h} + \sum_k \alpha_k \vec{v}_k$$

## 四、代码实现

```python
import torch
from sklearn.linear_model import LogisticRegression

# 训练探针得到方向
def fit_direction(acts, labels):
    clf = LogisticRegression(C=1.0, max_iter=2000)
    clf.fit(acts, labels)
    v = torch.tensor(clf.coef_[0], dtype=torch.float32)
    return v / v.norm(p=2)

# 在生成时按层注入方向干预
def steer(layer_acts, v, alpha):
    # acts: [seq, d]
    return layer_acts + alpha * v.unsqueeze(0)

# 评估：用真实标签计算探针 AUC，再用干预前后生成对比语义变化
```

提示：探针训练集应与干预评估集分布一致，避免标签泄漏导致虚高准确率。

## 六、常见误区

- 探针准=因果：仅相关性，需干预验证。
- 干预强度随意：过大破坏流畅度或引发分布偏移。
- 忽略层选择：概念仅在特定层显著。
- 把干预当对齐手段：它是临时缓解，不等于模型真正「认同」该价值。

## 九、演进与趋势

从单一探针到 representation engineering 系统框架，再到与 SAE 特征融合实现更单义、可组合的 steering；与对齐监控结合用于实时检测与干预危险内部状态。具体以官方最新论文为准。

## 十、小结

探针提供廉价的「读取」接口，方向干预提供可逆的「写入」接口，二者构成机制分析的双工具。但任何结论都须以因果验证收尾，避免把相关性误读为可控性。
