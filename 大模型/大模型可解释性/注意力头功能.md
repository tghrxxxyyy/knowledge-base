# 注意力头功能

> 对应 Olsson et al. 2022《In-context Learning and Induction Heads》以及 Anthropic《Transformer Circuits》系列。

## 一、背景与挑战

多头注意力把一个表示分解成多个「头」，直觉上每个头可能负责不同语言学或算法功能。但头功能并不一一对应人类语义角色，需要先验假设再实证定位。挑战：(1) 头高度冗余、可彼此补偿；(2) 功能常依赖具体层与数据分布；(3) 单看权重难以判断功能，须看其在前向中的因果作用。

## 二、核心原理

经典发现是 induction heads（归纳头）：当序列出现「A B ... A」时，该头把「A」之后的下一个 token「B」复制到当前位置，从而完成模式复制，是 few-shot in-context learning 的关键机制之一。其他已定位的头包括 previous-token heads、duplicate-token heads、translation heads、检索/复制类头等。

定位头功能的标准方法是激活修补（activation patching）：在「有/无某行为」的两组输入间交换某头激活，若行为随之切换，则该头对该功能因果负责。残差流是信息主通道，头通过向残差流写入增量来发挥作用。

定位头功能的标准实验是「头消融（head ablation）」：将该头输出置零或替换为均值后重跑，比较行为指标下降量；下降越多该头越关键。更精细的激活修补只在特定位置替换该头激活，可区分头是「写入信息」还是「读取信息」。由于头高度冗余，单个头消融常被其他头补偿，因此需报告联合消融与逐步移除曲线，避免把可补偿的头误判为无用。头功能还存在明显的层分布规律：浅层多负责局部语法与复制，深层负责语义与推理。同一 head 在不同 prompt 分布下可能切换角色（multi-task heads），因此解读头功能必须固定数据与层，并对多种子取平均，否则结论不稳定。工程中常用归因分数（如 integrated gradients 沿残差流对头输出求偏导）给出每个头对输出的贡献排序。结合自动电路发现（ACDC）可从头枚举对目标行为必要的边，把单个头上升到头间子图的功能定位。需要强调，头的因果重要性必须经干预验证，单纯看消融下降可能是相关性假象。

头功能的发现高度依赖「任务探针」的设计质量。
好的探针应覆盖正例与负例，且负例要与正例仅差一个语义维度，避免头被无关因素激活。
例如研究复制能力时，正例为「A B … A」，负例为「A B … C」，仅末位不同。
激活修补的粒度可到「单个 token 位置」，从而定位头是在哪一步写入了关键信息。
这在分析 induction heads 时尤为关键：它是在「第二次出现 A」之后才生效。
头之间也存在协作：某些 head 负责「写入复制目标」，另一些负责「读取并输出」。
这种分工意味着单独看一个头会低估整体电路的作用。
大规模分析中可用聚类把功能相近的头分组，降低人工解读成本。
自动化工具（如 transformer-lens）已能可视化头贡献，但结论仍需人工因果验证。
解读头功能时应区分「充分条件」与「必要条件」，消融下降只说明必要，不说明充分。

## 三、形式化与数学基础

第 $l$ 层第 $h$ 个头的输出作用于残差流：

$$\Delta \vec{h}^{(l)}_i = \mathrm{Attn}^{(l,h)}(\vec{h}^{(l)})_i = \sum_j A_{ij}^{(h)} W_V^{(h)} \vec{h}^{(l)}_j$$

induction head 的 query/key 模式可抽象为：对当前位置 $i$，寻找前面最近一次出现相同 token 的位置 $j$，并复制其后续 token：

$$A_{ij}^{(h)} \approx \mathbb{1}[\text{tok}_j = \text{tok}_i] \cdot \text{且 } j \text{ 为最近匹配}$$

整体残差更新为各头输出之和：

$$\vec{h}^{(l+1)} = \vec{h}^{(l)} + \sum_h \Delta \vec{h}^{(l,h)} + \mathrm{MLP}^{(l)}(\vec{h}^{(l)})$$

## 四、代码实现

用 activation patching 验证某个头是否负责「复制前一个 token」：

```python
import torch

def patch_head(model, src_acts, dst_run, layer, head):
    # src_acts: 来自「触发复制」输入的该头激活 [seq, head_dim]
    # 在 dst_run 前向到该层该头时替换激活
    def hook(mod, inp, out):
        out = out.clone()
        out[:, head, :] = src_acts  # 仅替换目标头
        return out
    h = model.layers[layer].self_attn.register_forward_hook(hook)
    logits = model(dst_run)
    h.remove()
    return logits

# 比较替换前后在复制任务上的准确率变化，变化越大该头越关键
```

注意：直接修改 `out` 张量需先 `out.clone()`，避免原地写回共享缓存导致其它分支受影响。

## 五、与其他技术对比

| 神经元 | 单维 | 消融 | 常多义 |
| SAE 特征 | 单义方向 | 字典学习 | 更细 |

## 六、常见误区

- 认为头功能「语义命名」固定：同一头在不同任务可切换角色。
- 仅靠注意力图判断功能：权重≠因果。
- 忽略冗余：单个头被 ablate 后其它头可能补偿，准确率不掉易误判为「无用」。
- 把层数当功能分层：功能分布并非严格按层递进。

## 九、演进与趋势

从手工定位少数头，到用自动化（如 automatic circuit discovery、ACDC）大规模发现电路；从「头」到「头内子电路/SAE 特征」更细粒度。与对齐监控结合可定位危险行为对应的头。具体以官方最新研究为准。

## 十、小结

注意力头是可解释性分析的基本功能单元，induction heads 是其中最著名的案例。定位头功能必须依赖因果式的激活修补，而非权重观察；其冗余特性也提醒我们谨慎解读 ablation 结果。
