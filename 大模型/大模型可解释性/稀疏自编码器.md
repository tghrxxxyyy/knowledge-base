# 稀疏自编码器解构特征

> 对应 Cunningham et al. 2023《Sparse Autoencoders (SAEs) for Superposition》与 Huben et al. 2023 大规模 SAE 训练研究。

## 一、背景与挑战

在叠加（superposition）假设下，模型为用有限维度表示远超维度的特征，把多个特征「压缩」进同一神经元，导致单个神经元多义（polysemantic）：一个神经元可能同时响应「法语」「法律」「括号」。这使得「神经元=概念」的直觉失效，难以解释。

稀疏自编码器（SAE）目标是学习一个「过完备、稀疏」的字典，把叠加激活分解为大量单义（monosemantic）特征，恢复人类可理解的特征基。挑战：字典过大、训练不稳定、特征可解释性需人工或自动评估、计算成本高。

## 二、核心原理

SAE 在某一层激活 $\vec{h}$ 上训练：编码器把 $d$ 维激活映射到 $m \gg d$ 维的稀疏隐变量 $\vec{f}$，解码器尽量重建原激活：

$$\vec{f} = \mathrm{Encoder}(\vec{h}), \quad \hat{\vec{h}} = \mathrm{Decoder}(\vec{f})$$

关键约束是 $\vec{f}$ 稀疏（多数分量为 0），迫使每个特征只响应单一语义。训练后用 $\vec{f}$ 的活跃维度作为「单义特征」，其解码器方向即为该特征在激活空间的表示，可像探针方向一样被读取或干预。

SAE 的训练数据来自对目标层激活的采样，需覆盖模型真实分布的多样 prompt。
解码器列建议 L2 归一化，使特征方向可直接用余弦相似度比较与检索。
特征可解释性要靠「最大化激活样本」反查：找出使该特征最亮的输入，人工归纳语义。
自动特征解释可用一个 LLM 给每个特征打标签，再人工抽检，形成特征字典。
死特征（长期不激活）浪费容量，可用 resampling 或正则让其重新被使用。
SAE 与探针互补：探针读已知概念，SAE 发现未知单义特征，两者可交叉验证。

## 三、形式化与数学基础

标准 SAE 采用 ReLU/TopK 编码器与 $L_1$ 或 TopK 稀疏惩罚。重建损失加稀疏项：

$$\mathcal{L} = \|\vec{h} - \hat{\vec{h}}\|^2 + \lambda \|\vec{f}\|_1, \quad \vec{f} = \mathrm{ReLU}(W_{\mathrm{enc}}\vec{h} + \vec{b}_{\mathrm{enc}})$$

现代做法常用 TopK 稀疏（只保留最大 $k$ 个）：

$$\vec{f} = \mathrm{TopK}(W_{\mathrm{enc}}\vec{h} + \vec{b}_{\mathrm{enc}}, k)$$

重建为 $\hat{\vec{h}} = W_{\mathrm{dec}} \vec{f} + \vec{b}_{\mathrm{dec}}$。解码器列 $\vec{d}_i = W_{\mathrm{dec}}[:,i]$ 即第 $i$ 个特征方向；特征 $i$ 的「激活」$\vec{f}_i$ 越大，表示该概念越强。L1 系数 $\lambda$ 控制稀疏度与重建精度的权衡。

## 四、代码实现

```python
import torch
import torch.nn as nn

class SAE(nn.Module):
    def __init__(self, d, m, k):
        super().__init__()
        self.enc = nn.Linear(d, m, bias=True)
        self.dec = nn.Linear(m, d, bias=True)
        self.k = k

    def forward(self, h):
        pre = self.enc(h)
        f = torch.zeros_like(pre)
        # TopK 稀疏：仅保留每样本最大的 k 个
        vals, idx = torch.topk(pre, self.k, dim=-1)
        f.scatter_(-1, idx, vals.clamp(min=0))
        recon = self.dec(f)
        loss = (h - recon).pow(2).mean()  # 稀疏由 TopK 隐式提供
        return recon, f, loss

# 训练后在某层 hook 中取出 f，分析非零维度的语义
```

提示：解码器列建议归一化以便用余弦相似度比较特征方向；过大 $m$ 需分批训练与死特征（dead feature）处理。

## 五、与其他技术对比

| 方法 | 特征数 | 单义性 | 训练 | 用途 |
|------|--------|--------|------|------|
| 直接看神经元 | $d$ | 低 | 否 | 粗 |
| 线性探针 | 1/类 | 中 | 是 | 读单概念 |
| SAE | $m\gg d$ | 高 | 是 | 解构全部 |
| PCA | $d$ | 低 | 否 | 降维 |

## 六、常见误区

- 认为 SAE 特征=真因：它只是更好的基，仍可能重组/近似。
- 忽略死特征：长期不激活的特征浪费容量，需 resampling 或正则。
- 稀疏度随意：过高重建差（丢信息），过低又多义。
- 把 SAE 当对齐：它提供可解释特征，但控制仍需干预验证。

## 九、演进与趋势

SAE 正从玩具模型走向百亿参数模型的实层训练，并与自动化特征解释（用 LLM 给特征打分）、跨层特征一致性研究结合。更高效的训练（如 Gated SAE）与更低成本的监控集成是方向。具体以官方最新论文为准。

## 十、小结

稀疏自编码器通过过完备稀疏字典把叠加激活拆成单义特征，是特征级可解释性的核心工具。它补上了「神经元多义」留下的解释空白，为读取与干预提供了更干净的特征基。
