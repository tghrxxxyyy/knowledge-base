# 温度解码总览

> 对应 softmax 温度缩放（Ackley et al., 1985 Boltzmann 思想）；与 采样策略深入 衔接。

## 一、背景与挑战

softmax 原始分布常过锐或过平，需统一旋钮控制确定性-随机性。

## 二、核心原理

解码前以 $\tau$ 缩放 logits 再 softmax；$\tau<1$ 更确定、$\tau>1$ 更随机，是采样/贪心统一接口。

## 三、数学形式

$P_\tau(v)=\frac{\exp(z_v/\tau)}{\sum_u \exp(z_u/\tau)}$；$\tau=1$ 等价原分布。

## 四、代码实现

```python
logits = model(input_ids).logits / temperature
next_id = torch.multinomial(F.softmax(logits[-1], -1), 1)
```

## 五、与其他对比

- 与 波束搜索深入：低温极限趋贪心/束。
- 与 top-p/top-k 叠加调多样。

## 六、常见误区

- 高温不等于高智能，只增随机。
- 不同层/头对温度敏感度不同。

## 八、面试题

- 温度的极限行为？答：$\tau\to0$ 趋 argmax，$\tau\to\infty$ 趋均匀。

## 九、演进

固定温度 → 逐层/逐步 → 自适应温度。

## 十、小结

温度是 logits 缩放的总闸，统一确定与随机。
