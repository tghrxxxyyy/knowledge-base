# 温度与分布熵

> 对应分布熵与生成多样性；与 采样策略深入 衔接。

## 一、背景与挑战

需量化温度对输出不确定度的具体影响。

## 二、核心原理

高温提升分布熵→更多低概率词被采→多样但易退化；低温降熵→集中于高概率词→流畅但重复。

## 三、数学形式

熵 $\mathbb H(P_\tau)=-\sum P_\tau(v)\log P_\tau(v)$；$\frac{\partial \mathbb H}{\partial \tau}>0$ 一般成立。

## 四、代码实现

```python
h = -(p * p.log()).sum(-1)   # p = softmax(z/tau)
```

## 五、与其他对比

- 与 典型解码深入（控熵）思想相通。
- 与 波束搜索深入 熵极低相对。

## 六、常见误区

- 以为熵高即质量高；高熵可对应退化。
- 忽视任务最优熵点不同。
