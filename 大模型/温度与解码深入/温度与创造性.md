# 温度与创造性

> 对应生成多样性研究；与 采样策略深入 衔接。

## 一、背景与挑战

“创造性”需要跳出高概率套路，但不能退化为乱码。

## 二、核心原理

适度升温引入低概率但合理词，激发新颖组合；过高则语义崩坏，故称“甜区”温度。

## 三、数学形式

新颖度 $N(\tau)=\sum_{v\notin top1}P_\tau(v)\cdot \text{rel}(v)$；在 $\tau^*$ 取最大有效新颖。

## 四、代码实现

```python
for tau in [0.7, 0.9, 1.1]:
    samples = [generate(temp=tau) for _ in range(10)]
```

## 五、与其他对比

- 与 典型解码深入 都以信息率控新颖。
- 与 波束搜索深入 新颖度低相对。

## 六、常见误区

- 把高温当创造力万能钥匙。
- 忽视重复惩罚协同。
