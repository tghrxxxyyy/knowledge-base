# 温度调参实践

> 对应解码超参经验；与 采样策略选型深入 衔接。

## 一、背景与挑战

温度取值需按任务与模型定，缺经验易失调。

## 二、核心原理

代码/事实 0.0–0.3；问答 0.3–0.5；对话 0.6–0.8；创意 0.8–1.2；过高 >1.5 退化风险大。

## 三、数学形式

质量模型 $Q(\tau)\approx 1-\alpha|\tau-\tau^*|$ 在 $\tau^*$ 峰；需验证集找峰。

## 四、代码实现

```python
tau = grid_search(lambda t: eval_gen(temp=t), [0.2,0.5,0.8,1.0])
```

## 五、与其他对比

- 与 top-p 协同：温度控形状、top-p 控裁剪。
- 与 格式化输出深入 联合调参。

## 六、常见误区

- 默认 1.0 直接用；常非最优。
- 不同基座模型最优温度不同。
