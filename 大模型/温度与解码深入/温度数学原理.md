# 温度数学原理

> 对应信息论与玻尔兹曼分布；与 采样策略深入 共享。

## 一、背景与挑战

理解温度如何映射 logits 到概率，及其对熵的影响。

## 二、核心原理

缩放改变 logit 间差值相对幅度；低温放大差距（尖锐）、高温压缩差距（平滑），几何上即分布“温度”。

## 三、数学形式

两词比 $\frac{P_\tau(a)}{P_\tau(b)}=\exp((z_a-z_b)/\tau)$；$\tau$ 反比于差值敏感度。

## 四、代码实现

```python
def apply_temp(z, tau=1.0):
    return F.softmax(z / tau, dim=-1)
```

## 五、与其他对比

- 与 核采样深入（裁剪）正交，可叠加。
- 与 典型解码深入（熵匹配）互补视角。

## 六、常见误区

- 认为温度改变 logits 大小不变比值（错，比值变）。
- 混淆温度与 top-p 的作用域。

- 温度如何改变词间比值？答：比值按 $(z_a-z_b)/\tau$ 指数化，低温放大、高温压缩差距。
