# 生成式对齐与对比式对齐

> 对应 Alayrac et al. 2022 「Flamingo: a Visual Language Model for Few-Shot Learning」及 Yu et al. 2022 「CM3」等生成式多模态工作。

## 一、背景与挑战

多模态对齐有两条路线：对比式（CLIP/SigLIP）将图文映射到同一空间做匹配；生成式则训练模型以图像为条件生成文本（或反之）。二者目标、表征与用途不同。如何取舍、能否统一，是构建 MLLM 的核心设计问题。

## 二、核心原理

对比式对齐优化相似度排序，擅长检索与 zero-shot，但对细粒度生成无直接帮助。生成式对齐把视觉特征送入 LM 做 next-token 预测，直接学习图像条件下的语言分布，天然支持描述、推理与对话。Flamingo 以 gated cross-attention 注入视觉，保持 LM 生成能力。

## 三、数学形式

生成式目标为条件语言建模：
L = -\sum_{t=1}^T \log p_\theta(x_t \mid x_{<t}, z^I)
对比式为 \max \mathrm{sim}(z^I,z^T)。二者可联合：总损失 L = L_{gen} + \lambda L_{clip}，兼顾生成与对齐判别。

## 四、代码实现

```python
import torch.nn as nn

class GatedXATTN(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.attn = nn.MultiheadAttention(dim, 8, batch_first=True)
        self.gate = nn.Parameter(torch.zeros(1))
    def forward(self, txt, img):
        out, _ = self.attn(txt, img, img)
        return txt + self.gate * out      # 门控残差注入
```

## 五、与其他对比

对比式训练稳定、数据效率好但弱于生成；生成式更贴近 MLLM 推理却需强 LM 与对齐桥。Flamingo 用感知器重采样 + 门控 cross-attn 兼顾二者；BLIP-2 用 Q-Former 同时做对比 ITM 与生成。

## 六、常见误区

以为生成式已包含对齐，其实仍需显式对齐避免幻觉；以为对比式能直接生成；忽略门控系数初始化为 0 对稳定训练的重要性；混淆冻结 LM 与全微调的注入方式。

## 八、面试题

- Q：对比式与生成式对齐差异？答：前者优化相似度排序，后者优化条件生成分布。
- Q：Flamingo 如何保留 LM 能力？答：门控 cross-attn 初始为 0，视觉为残差注入。
- Q：能否联合？答：可加对比损失正则生成，减少幻觉。

## 九、演进

从单目标到组合目标；从独立双塔到统一多任务（检索+生成+ITM）；VQA 与对话统一在生成框架内。

## 十、小结

对比式与生成式对齐各有优劣，现代 MLLM 多以生成式为主、对比式为辅，用组合损失与门控注入实现既会对话又能检索的统一多模态模型。
