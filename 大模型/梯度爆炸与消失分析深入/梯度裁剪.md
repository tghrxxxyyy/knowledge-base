# 梯度裁剪

> 对应 Pascanu et al., 2013（梯度爆炸的裁剪解法）；亦见 Goodfellow et al., *Deep Learning*, 2016。

## 一、背景与挑战

梯度爆炸使参数更新步长失控。裁剪在更新前把梯度总体范数限制在上界内，保留方向、压缩幅值，避免发散。

它是 RNN/深层训练的标准稳定组件，对 Transformer 大学习率训练同样有效。

## 二、核心原理

按范数裁剪（最常用）：计算全部参数梯度总范数，若超过阈值 $c$ 则整体缩放 $g\leftarrow g\cdot c/\|g\|$。

也可按值裁剪（clip each element），但范数裁剪保留梯度方向，更受青睐。

## 三、数学形式

$g\leftarrow\begin{cases}g,& \|g\|_2\le c\\ \frac{c}{\|g\|_2}g,& \|g\|_2>c\end{cases}$，阈值 $c$ 常取 0.5–5（随任务）。

## 四、代码实现

```python
import torch
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
optimizer.step()
```

## 五、与其他对比

- 与 梯度爆炸机理 成对：爆炸是症，裁剪是药。
- 与 学习率与发散 衔接，裁剪不改变方向只限幅。
- 与 混合精度溢出检测深入 不同层：裁剪管梯度、溢出检测管数值范围。

## 六、常见误区

- 阈值过小致梯度长期被压、欠拟合。
- 阈值过大等于没裁，仍会爆。
- 只对部分参数裁剪，致其余参数仍发散。

## 八、面试题

- 梯度裁剪为何不破坏方向？答：范数裁剪是整体等比缩放，仅压缩幅值保留方向。
- 阈值怎么选？答：先观察未裁剪梯度范数分布，取略低于常见峰值的值。

## 九、演进

按值裁剪 → 按范数裁剪 → 与自适应优化器/混合精度协同。

## 十、小结

梯度裁剪以最小代价换取训练稳定，是爆炸问题的标准防线。
