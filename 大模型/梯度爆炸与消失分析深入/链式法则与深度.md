# 链式法则与深度对梯度的影响

> 对应 Bengio et al., 1994；Hochreiter, 1991（深度网络梯度传播理论）。

## 一、背景与挑战

理解梯度如何随网络深度传播，是诊断消失/爆炸的前提。深度既放大信号也放大误差，需量化其传播规律。

实践中“多深算深”取决于每层的有效增益，而非层数本身。

## 二、核心原理

反向传播即反复应用链式法则：每一层贡献一个线性映射（雅可比），其条件数与谱范数决定梯度幅值的伸缩。

若各层增益独立同分布，深度 $L$ 后梯度方差约随 $(\mathbb E[\lambda^2])^L$ 缩放，单一层增益期望偏离 1 即指数效应。

## 三、数学形式

记第 $l$ 层增益 $\lambda_l=\|\partial h_l/\partial h_{l-1}\|_2$，则 $\|\nabla_{W_1}\|\approx\prod_l\lambda_l\cdot C$。

当 $\mathbb E[\lambda_l^2]=\alpha$：方差 $\mathrm{Var}\propto\alpha^L$，$\alpha<1$ 消失、$\alpha>1$ 爆炸。

## 四、代码实现

```python
import numpy as np
gains = [np.linalg.norm(J, 2) for J in jacobians]   # 各层谱范数
log_gain = np.log(gains).sum()
print("cumulative log gain (per layer mean):", log_gain / len(gains))
```

## 五、与其他对比

- 与 初始化尺度与方差传播深入 直接衔接，初始化目标即让各层增益均值为 1。
- 与 归一化层数值稳定性深入 互补，归一化把每层增益稳定到 1 附近。
- 与 残差结构（缓解）相关，残差提供恒等短接路径。

## 六、常见误区

- 只看层数忽略每层增益，误判消失风险。
- 把梯度幅值等同于梯度方向质量。
- 忽视激活导数对增益的乘性抑制。

## 八、面试题

- 深度如何影响梯度方差？答：每层增益乘积，若均方增益偏离 1 则梯度方差随深度指数缩放。
- 何为“有效深度”？答：由每层增益决定的等效连乘长度，而非物理层数。

## 十、小结

链式法则是消失/爆炸的统一解释框架，控增益为 1 是稳定训练的核心。
