# 梯度消失机理

> 对应 Hochreiter, *Untersuchungen zu dynamischen neuronalen Netzen*, 1991；Bengio et al., 1994（梯度消失的实证分析）。

## 一、背景与挑战

深层网络反向传播时，梯度沿层向后逐层传递。若每层雅可比的谱范数乘积持续小于 1，前层梯度将指数衰减，参数几乎不更新，训练停滞。

这与网络深度强相关，也是早期深层 MLP/CNN 难以训练的核心原因之一，直至归一化与残差结构普及才缓解。

## 二、核心原理

梯度是损失对各层权重的偏导。链式法则使其等于后续各层变换雅可比之积，再乘以本层输入，因此模长受每层谱范数沿深度乘积累积的影响。

饱和激活（sigmoid/tanh）的导数上界小于 1，是梯度消失的经典放大器；非饱和激活与归一化可显著改善梯度幅值。

## 三、数学形式

$\frac{\partial L}{\partial W_1}=\frac{\partial L}{\partial h_L}\prod_{l=2}^{L}\left(\frac{\partial h_l}{\partial h_{l-1}}\right)\frac{\partial h_1}{\partial W_1}$，连乘积模长随 $L$ 指数衰减或增长。

深层梯度范数近似满足 $\|\nabla_{W_1}L\|\sim\prod_l\|\partial h_l/\partial h_{l-1}\|\cdot C$，因子持续小于 1 即消失。

## 四、代码实现

```python
def grad_norm_by_layer(grads):
    return [g.norm().item() for g in grads]   # 逐层梯度范数，观察是否前层趋零

norms = grad_norm_by_layer([p.grad for p in model.parameters()])
print("first-layer grad norm:", norms[0], "last-layer:", norms[-1])
```

## 五、与其他对比

- 与 梯度爆炸机理（连乘因子大于 1）是同一链条的两端，诊断方向相反。
- 与 初始化与激活协同 共享缓解手段（Kaiming/Glorot、ReLU）。
- 与 归一化层数值稳定性深入 互补，归一化直接稳定每层输入尺度。

## 六、常见误区

- 认为加深必然消失；残差连接与 LayerNorm 已能大幅缓解。
- 以为换 ReLU 就万事大吉；未归一化时仍可能因权重尺度而衰减。
- 只监控最后一层 loss，忽略前层梯度已趋零的诊断信号。

## 八、面试题

- 为何深层前层梯度更小？答：链式法则使梯度为多层雅可比连乘，模长随深度指数衰减。
- 如何定量判断消失？答：对比首层与末层梯度范数，差距达若干数量级即显著。

## 九、演进

sigmoid/tanh → ReLU → 归一化+残差 → Pre-LN Transformer，梯度流持续改善。

## 十、小结

梯度消失源于链式法则的连乘衰减，激活选择与结构（残差/归一化）共同决定其严重程度。
