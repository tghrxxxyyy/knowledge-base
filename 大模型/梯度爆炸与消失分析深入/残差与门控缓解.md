# 残差与门控对梯度的缓解

> 对应 He et al., *Deep Residual Learning*, 2016（ResNet）；Hochreiter & Schmidhuber, *LSTM*, 1997（门控）。

## 一、背景与挑战

单纯加深带来消失/爆炸。残差与门控通过改变信息通路，提供近似恒等的反向梯度短接，显著缓解退化。

二者思路不同：残差加恒等支路，门控用 sigmoid 学习性调节信息流。

## 二、核心原理

残差：$h_l=h_{l-1}+F(h_{l-1})$；反向时 $\partial h_L/\partial h_l$ 含恒等项 $+1$，梯度可不经 $F$ 直接回传。

LSTM 门控（输入/遗忘/输出门）让单元状态 $c_t=c_{t-1}\odot f_t+\dots$，遗忘门接近 1 时梯度沿 $c$ 长程近似恒等回传。

## 三、数学形式

残差反向：$\frac{\partial L}{\partial h_{l-1}}=\frac{\partial L}{\partial h_l}\left(I+\frac{\partial F}{\partial h_{l-1}}\right)$，恒等项保证不消失。

LSTM：$\partial c_t/\partial c_{k}\approx\prod_{i=k}^{t-1}f_i$，遗忘门全 1 时恒等。

## 四、代码实现

```python
class ResBlock(torch.nn.Module):
    def forward(self, x):
        return x + self.f(x)          # 恒等短接
```

## 五、与其他对比

- 与 归一化层数值稳定性深入 协同：Pre-LN 把每层增益稳到 1，残差提供跨层通路。
- 与 梯度消失机理 对应，残差是结构性解。
- 与 Transformer（Vaswani17）中二者并用相关。

## 六、常见误区

- 残差块初始化不当（$F$ 初始过大）仍会不稳。
- 门控遗忘门全 0 反而截断长程梯度。
- 以为加了残差就无需归一化。

## 八、面试题

- 残差为何缓解消失？答：反向含恒等项 +1，梯度可不经变换直接跨层回传。
- LSTM 门控如何帮长程？答：遗忘门接近 1 时单元状态梯度近似恒等回传。

## 十、小结

残差与门控从结构层面保证梯度通路，是现代深网稳定训练基石。
