# 初始化与激活的协同

> 对应 Glorot & Bengio, 2010（Xavier）；He et al., 2015（Kaiming）；配合 ReLU 非饱和激活。

## 一、背景与挑战

即使有归一化，初始化仍决定训练起点是否落入健康梯度区。错误初始化会让首层就消失/爆炸。

激活选择决定导数为零的区域大小，与初始化尺度必须协同设计。

## 二、核心原理

目标：前向方差在各层间保持恒定（信号不衰减/不爆），反向梯度方差同样保持恒定。

对线性层+Xavier：权重方差 $\sigma^2=1/n_{in}$；对 ReLU+Kaiming：$\sigma^2=2/n_{in}$，补偿 ReLU 半区置零。

## 三、数学形式

前向：$\mathrm{Var}(y)=\mathrm{Var}(x)\cdot n\cdot\sigma_w^2$（忽略偏置）；均衡要求 $\sigma_w^2=1/n_{in}$ 或 $2/n_{in}$。

反向对称条件给出 $n_{in}\sigma^2=n_{out}\sigma^2$，Xavier 取调和平均 $(2/(n_{in}+n_{out}))$。

## 四、代码实现

```python
import torch
torch.nn.init.kaiming_normal_(w, nonlinearity="relu")   # He 初始化
torch.nn.init.xavier_uniform_(w)                        # Glorot 初始化
```

## 五、与其他对比

- 与 初始化尺度与方差传播深入 是同一主题的展开。
- 与 梯度消失机理 衔接，坏初始化直接导致消失。
- 与 归一化层数值稳定性深入 互补，归一化放宽初始化敏感度。

## 六、常见误区

- ReLU 网络误用 Xavier 致前向方差偏小。
- 用 Kaiming 但激活是 tanh（应为 Xavier）。
- 偏置也随机初始化，无故引入偏移。

## 八、面试题

- 为何 ReLU 用 Kaiming？答：ReLU 将一半输入置零，需把权重方差翻倍补偿以保持前向方差恒定。
- 初始化与激活为何要匹配？答：不同激活的导数分布不同，方差守恒要求不同尺度。

## 九、演进

全零/小随机 → Xavier → Kaiming → 与归一化协同放宽。

## 十、小结

初始化与激活协同维持方差守恒，是训练起点的第一道稳定保障。
