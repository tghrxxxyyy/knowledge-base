# 线性注意力总览

> 对应 Katharopoulos et al., *Transformers are RNNs: Fast Autoregressive Transformers with Linear Attention*, 2020；以及 Choromanski et al., *Rethinking Attention with Performers*, 2020。

## 一、背景与挑战

标准 softmax 注意力对序列长度 $n$ 的时间与显存复杂度均为 $O(n^2)$，在长文档、高分辨率图像、基因组等场景下不可承受，推理时还无法像 RNN 那样以固定状态增量计算。

## 二、核心原理

线性注意力把 softmax 分解为核特征映射 $\phi(\cdot)$ 的近似：$softmax(QK^T)V \approx \phi(Q)\phi(K)^T V / Z$。先算 $\phi(K)^T V$（一个 $d\times d_v$ 的全局统计量），再与 $\phi(Q)$ 相乘，复杂度降为 $O(n d^2)$，且可递推累积。

## 三、数学形式

近似注意力 $A = \frac{\phi(Q)(\phi(K)^T V)}{\phi(Q)(\phi(K)^T\mathbf 1)}$，其中 $\phi(x)=elu(x)+1$（Linear Transformer）或 $\phi(x)=\exp(\omega^T x)$（Performer 的 FAVOR+ 正随机特征）。

## 四、代码实现

```python
import torch
def linear_attn(q, k, v, phi=torch.nn.functional.elu):
    q, k = phi(q) + 1, phi(k) + 1
    kv = k.transpose(-1, -2) @ v            # (d, d_v) 全局统计量
    denom = q @ k.sum(-2, keepdim=True).transpose(-1, -2)
    return q @ kv / (denom + 1e-6)
```

## 五、与其他对比

- 相比稀疏注意力（Longformer/BigBird），线性注意力无需手工设计稀疏模式，天然近似全局感受野。
- 相比 FlashAttention，线性注意力以精度换取亚二次复杂度，长序列更省显存。

## 六、常见误区

- 核函数须保证非负性；用裸 $elu$ 不加 1 会破坏分母的非负假设。
- 线性注意力在需要精确逐对相似度（如检索、复制）时精度明显弱于 softmax。

## 八、面试题

- 线性注意力为何是 $O(n)$？答：先聚合 $\phi(K)^TV$ 为固定的 $d\times d_v$ 矩阵，再与 $Q$ 相乘，计算量与 $n$ 无关。

## 九、演进

精确 softmax → 核近似（Linear/Performer） → 线性 RNN 化（RWKV、Mamba 的快权记忆思路）。

## 十、小结

线性注意力以核映射把注意力改写成可递推的形式，是长序列与高效推理的重要路线，代价是近似误差。
