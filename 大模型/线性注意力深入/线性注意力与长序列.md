# 线性注意力与长序列

> 对应 Tay et al., *Long Range Arena*, 2020（评测长程依赖）；Sun et al., *Linear Transformers are Secretly Fast Weight Memory Systems*, 2022。

## 一、背景与挑战

处理百万级 token 时即使是 $O(n^2)$ 的优化实现仍昂贵；线性注意力因 $O(n)$ 成为长序列候选。

## 二、核心原理

线性注意力可被重写为循环：维护状态 $S=\sum_t \phi(k_t)v_t^T$，每步 $o_t=\phi(q_t)S$，等价于一个快权记忆（Fast Weight）RNN，推理时显存恒定，可流式处理无限长度。

## 三、数学形式

递推 $S_t = S_{t-1} + \phi(k_t)v_t^T$，$o_t = S_t^T\phi(q_t)$；状态大小 $O(d\,d_v)$ 与序列长无关。

## 四、代码实现

```python
S = torch.zeros(d, dv)
out = []
for qt, kt, vt in zip(qs, ks, vs):
    S = S + phi(kt).outer(vt)
    out.append(phi(qt) @ S)
```

## 五、与其他对比

- 与 无限上下文深入（分块/记忆压缩）目标一致但机制不同。
- 与 FlashAttention深入 对照：Flash 仍 $O(n^2)$ 但精确，线性注意力靠近似换长度。

## 六、常见误区

- 认为线性注意力天然无损长程；低秩近似会模糊远距离细粒度依赖。
- 流式状态累积误差随步数增长。

## 八、面试题

- 线性注意力如何做流式推理？答：维护 $O(d\,d_v)$ 的快权状态，逐 token 更新，显存恒定。

## 九、演进

全序列重算 → 递推状态 → 门控快权记忆。

## 十、小结

线性注意力借递推把长序列成本压到恒定，是流式与超长上下文的算法基石。
