# 线性注意力的代表模型

> 对应 Choromanski et al., *Performer*, 2020；Wang et al., *Linformer*, 2020；以及 Peng et al., *RWKV*, 2023。

## 一、背景与挑战

不同线性化方案在质量、速度、生态上差异大，需了解代表实现以选型。

## 二、核心原理

- Linear Transformer：elu+1 确定性核，可递推。
- Performer：随机特征 FAVOR+，近似无偏。
- Linformer：低秩投影把 $K/V$ 压到固定 $k$ 列，属低秩而非核法。
- RWKV：把线性注意力写成带时间衰减的 RNN，纯递归推理。

## 三、数学形式

Linformer：$K' = W_K K \in \mathbb R^{k\times d}$，复杂度 $O(n k d)$；$k\ll n$ 时近线性。RWKV：$o_t=\sum_{i\le t} w^{t-i} k_i v_i^T$。

## 四、代码实现

```python
# Linformer: 把序列维投影到 k
K_low = torch.einsum('bnd,nk->bkd', K, proj)   # n->k
attn = (Q @ K_low.transpose(-1,-2)) @ V_low
```

## 五、与其他对比

- 与 稀疏注意力深入 相比，低秩/核法不依赖位置局部性假设。
- 与 softmax 注意力相比，RWKV 类可完全去掉注意力矩阵。

## 六、常见误区

- 把 Linformer 低秩当作核法；二者近似来源不同。
- 直接套用 softmax 超参到线性注意力，忽视核稳定需求。

## 八、面试题

- Linformer 与 Performer 近似方式差异？答：前者对 K/V 做低秩投影，后者用随机特征近似 softmax 核。

## 九、演进

Linear/Performer → Linformer → RWKV/Mamba 纯线性递归。

## 十、小结

线性注意力家族从核近似到低秩再到纯递归，逐步逼近高效且长程的建模范式。
