# 线性注意力训练稳定性

> 对应 Katharopoulos et al., 2020；以及后续对线性注意力梯度稳定性的分析（如 cosine 相似度注意力）。

## 一、背景与挑战

线性注意力去掉 softmax 后失去其饱和归一化特性，分母趋零或特征过大时梯度易爆炸/消失。

## 二、核心原理

常见稳定手段：核函数非负化（elu+1）、分母加小常数、对 $Q/K$ 做层归一或 L2 归一（cosine 注意力）、用可学习的温度系数控制相似度锐度。

## 三、数学形式

余弦线性注意力 $A=\frac{(Q/\|Q\|)(K/\|K\|)^TV}{(Q/\|Q\|)(K/\|K\|)^T\mathbf1}$，把向量归一化后核恒非负且数值集中。

## 四、代码实现

```python
def cos_linear_attn(q, k, v, eps=1e-6):
    q = torch.nn.functional.normalize(q, dim=-1)
    k = torch.nn.functional.normalize(k, dim=-1)
    kv = k.transpose(-1, -2) @ v
    return q @ kv / (q @ k.sum(-2, keepdim=True).transpose(-1, -2) + eps)
```

## 五、与其他对比

- 与 层归一化深入 共享“归一化换稳定”的思想。
- 与 softmax 自带的归一化不同，线性注意力需显式稳定。

## 六、常见误区

- 忘记分母加 eps 致除零（尤其空键集合）。
- 特征映射未归一致训练初期梯度爆炸。

## 八、面试题

- 线性注意力为何要归一化 Q/K？答：避免核值无界与分母趋零，提升训练稳定与收敛。

## 九、演进

裸核 → 归一化核 → 可学习温度 → 门控线性注意力。

## 十、小结

稳定是线性注意力落地的关键，归一化与分母正则不可或缺。
