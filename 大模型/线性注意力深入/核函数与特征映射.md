# 核函数与特征映射

> 对应 Choromanski et al., *Rethinking Attention with Performers (FAVOR+)*, 2020；Katharopoulos et al., 2020；Shen et al., *Efficient Attention*, 2018。

## 一、背景与挑战

softmax 不是正定核的直接表达，需用可计算的特征映射 $\phi$ 近似 $exp(q\cdot k)$，且要可控误差与数值稳定。

## 二、核心原理

两类主流：确定性映射（如 $\phi(x)=elu(x)+1$ 近似 $exp$）与随机特征（Performer 用 $\phi(x)=\frac{1}{\sqrt{m}}[exp(\omega^T x)]$ 中正负随机投影逼近高斯核），后者以概率保证无偏估计。

## 三、数学形式

高斯核近似 $k(x,y)=e^{x^Ty}\approx \phi(x)^T\phi(y)$，其中 $\phi(x)\propto [e^{\omega_1^T x},\dots,e^{\omega_m^T x}]$ 配正负频率；$\mathbb E[\phi(x)^T\phi(y)]=e^{x^Ty}$。

## 四、代码实现

```python
import torch, math
def favor_phi(x, m=256, seed=0):
    g = torch.Generator().manual_seed(seed)
    omega = torch.randn(x.shape[-1], m, generator=g)
    signs = torch.randint(0, 2, (m,), generator=g) * 2 - 1
    h = x @ omega * math.sqrt(2.0 / m)
    return torch.cat([torch.exp(h), torch.exp(-h)], dim=-1) * signs
```

## 五、与其他对比

- $\phi=elu+1$ 简单确定但对长尾相似度近似粗糙；随机特征近似更准但需多特征维度 $m$。
- 与 绝对位置编码深入 无直接关系，属注意力内部近似技术。

## 六、常见误区

- $m$ 太小近似偏差大；太大则失去线性收益。
- 随机特征未固定 seed 致训练/推理不一致。

## 八、面试题

- Performer 如何无偏近似 softmax 核？答：用正负随机投影构造特征映射，其期望等于 $e^{x^Ty}$。

## 九、演进

确定性核 → 随机特征(FAVOR+) → 正交随机特征降方差。

## 十、小结

核映射是线性注意力的数学核心，确定性 vs 随机特征在稳定与精度间权衡。
