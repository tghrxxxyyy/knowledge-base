# 多轮对话评估

> 对应对话评估指标；模型评测指标深入 / RAG评估与离线评测体系 衔接。

## 一、背景与挑战

对话质量含相关性、一致性、任务完成率、安全，单轮指标不足。

## 二、核心原理

用任务成功率（Goal Success）、一致性检查、LLM-as-judge 打分；端到端看多轮轨迹。

## 三、数学形式

成功率 $S=\frac{1}{N}\sum_i \mathbb 1(\text{goal}_i\text{ achieved})$，结合人工/LLM 评分。

## 四、代码实现

```python
score = judge.evaluate(trajectory, rubric=["相关","一致","完成"])
```

## 五、与其他对比

- 与 模型评测指标深入（通用方法论）共享。
- 与 红队攻击模拟深入（安全维度）交叉。

## 六、常见误区

- 仅看末轮忽略累积错误。
- LLM 评判带位置/长度偏置。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course
- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 多轮评估难点？答：需综合一致性/完成率/安全，且错误会累积，单轮指标不反映。

## 九、演进

单轮准确率 → 任务成功率 → LLM 多维度评判。

## 十、小结

多轮对话评估需轨迹级多维指标，方能量真实体验。
