# 对话上下文管理

> 对应 LLM 对话上下文工程；长上下文技术深入（目录）衔接。

## 一、背景与挑战

历史无限增长触顶上下文窗口，且冗余信息稀释注意力。

## 二、核心原理

策略：滑动窗口、摘要压缩、关键记忆抽取、分层缓存；按重要性保留最近与关键轮。

## 三、数学形式

保留集 $K_t=\text{top}_k(\text{score}(h_i|q_t))$ 或摘要 $S_t=\text{Summ}(H_t)$。

## 四、代码实现

```python
ctx = summarize(hist) + recent_turns[-3:]
resp = model(ctx + user_u)
```

## 五、与其他对比

- 与 长文档切分深入（上下文亦需切分）共享。
- 与 KV缓存优化深入（缓存历史 KV）衔接。

## 六、常见误区

- 过度摘要丢关键槽位。
- 全量历史致成本与延迟翻倍。

## 八、面试题

- 如何管理长对话？答：滑动窗口+摘要/记忆抽取，仅保留相关与最近轮控长度。

## 九、演进

全量拼入 → 滑动窗口 → 摘要+记忆。

## 十、小结

上下文管理在长度与相关性间权衡，是长对话可用性的关键。
