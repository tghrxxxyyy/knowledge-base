# 多轮偏好对齐

> 对应 Wu et al., *Fine-Grained Human Feedback for RLHF*, 2024；把反馈标注到对话轮/片段。

## 一、背景与挑战

标准偏好对常是整个对话级，难定位错误轮；多轮需更细粒度反馈。

## 二、核心原理

对单轮或片段给好坏标注，训练奖励/偏好模型，再用 PPO/DPO 优化，使每轮都更符合意图。

## 三、数学形式

分段偏好 $\mathcal L=-\log\sigma(r(x,h_{good})-r(x,h_{bad}))$，按轮聚合。

## 四、代码实现

```python
for turn_pair in dialogue_segments:
    dpo_step(model, ref, turn_pair)
```

## 五、与其他对比

- 与 直接偏好优化深入（分段 DPO）衔接。
- 与 过程监督与结果监督深入（细粒度反馈）共享。

## 六、常见误区

- 轮级奖励误归因（好轮被坏轮连累）。
- 多轮分布偏移致策略漂移。

## 八、面试题

- 多轮偏好为何要细粒度？答：整轮反馈难定位错轮，细粒度可精准纠正特定回复。

## 九、演进

对话级偏好 → 轮级 → 片段级（span）反馈。

## 十、小结

多轮偏好对齐依赖细粒度反馈，使每轮更可控。
