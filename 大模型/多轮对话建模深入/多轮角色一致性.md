# 多轮角色一致性

> 对应角色对话一致性；与 角色与人格对齐深入 共享。

## 一、背景与挑战

角色设定下，多轮易跑题、人设漂移或与先前声明矛盾。

## 二、核心原理

用系统提示固定角色，并在每轮注入角色约束；检测矛盾（自称/能力/偏好）并纠正。

## 三、数学形式

一致性得分 $C=1-\max_t \text{contradict}(r_t, R\cup H_{<t})$，$R$ 为角色设定。

## 四、代码实现

```python
for r in turns:
    assert persona_consistent(r, system_persona)
```

## 五、与其他对比

- 与 角色与人格对齐深入（单轮设定）延伸。
- 与 安全分类器深入（角色越界检测）衔接。

## 六、常见误区

- 系统提示过长被后续轮稀释。
- 矛盾检测滞后（已在多轮后）。

## 八、面试题

- 如何保持多轮人设？答：系统提示固定+每轮约束+矛盾检测，必要时用记忆存设定。

## 九、演进

提示约束 → 记忆+检测 → 角色专属微调。

## 十、小结

多轮角色一致性靠约束与检测双保险，防止人设漂移。
