# 对话记忆机制

> 对应 LLM 记忆/检索式对话；RAG深入 / 长上下文技术深入 衔接。

## 一、背景与挑战

超长会话需长期记忆，且用户事实需跨会话一致。

## 二、核心原理

显式记忆：把事实写入外部存储（向量库/键值），需要时检索；或周期性写用户档案摘要。

## 三、数学形式

检索记忆 $m^*=\arg\max_m sim(E(q),E(m))$；写入 $M\leftarrow M\cup\text{extract}(turn)$。

## 四、代码实现

```python
facts = extract(user_msg); memory.add(facts)
recall = memory.search(current_q, k=5)
```

## 五、与其他对比

- 与 隐私推理深入（记忆含敏感信息）对照风险。
- 与 混合检索深入（记忆即检索源）共享。

## 六、常见误区

- 记忆写入噪声致后续被误引。
- 跨会话记忆未隔离致串号隐私泄露。

## 八、面试题

- 对话记忆如何一致？答：外存抽取事实+检索，且跨会话隔离与权限控制防泄露。

## 九、演进

上下文内记忆 → 外存检索 → 用户档案持久化。

## 十、小结

记忆机制突破上下文上限，但带来隐私与一致性挑战。
