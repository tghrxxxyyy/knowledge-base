# 自洽性与采样投票

> 对应 Wang et al., *Self-Consistency*, 2022。

## 一、背景与挑战

单条 CoT 可能走错分支；多条采样可互校。

## 二、核心原理

对同一问题采样多条推理路径，用最终答案多数投票；正确路径更易一致出现，提升鲁棒。

## 三、数学形式

边际 $\hat y=\arg\max_y \sum_{i:ans(z_i)=y} 1$；等价于近似 $p(y|x)=\frac1K\sum_i \mathbb I[ans(z_i)=y]$。

## 四、代码实现

```python
paths = [cot(q) for _ in range(10)]
answer = Counter([extract(a) for a in paths]).most_common(1)[0][0]
```

## 五、与其他对比

- 与 多智能体（投票）共享思想。
- 与 推理时计算总览 衔接（N 采样）。

## 六、常见误区

- 采样温度过低致路径雷同、投票失效。
- 忽视抽取答案不稳致计票错。

## 八、面试题

- 自洽性为何强于单链？答：多路径投票降低单分支错误，正确答案更可能一致出现。

## 九、演进

单链→多数投票→加权/聚合。

## 十、小结

自洽性以多采样换稳健，是性价比高的推理时策略。
