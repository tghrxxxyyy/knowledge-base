# 推理时计算优化与部署

> 对应推理加速与成本工程；与 推理调度 / 连续批处理 衔接。

## 一、背景与挑战

多采样/长思维显著增加延迟与成本，需优化才可用。

## 二、核心原理

并行采样共用前缀 KV；早停（一致即返）；预算控制（max tokens/搜索宽度）；结果与训练协同（用推理轨迹做 RL/蒸馏）。

## 三、数学形式

成本 $Cost = N\cdot L\cdot price_{tok}$；并行共享前缀降重复。

## 四、代码实现

```python
out = model.generate(q, num_return_sequences=N, shared_prefix=True)
```

## 五、与其他对比

- 与 KV缓存优化 / 推理调度 共享系统。
- 与 直接偏好优化（用轨迹）衔接。

## 六、常见误区

- 无预算控制致成本失控。
- 忽视把优质推理轨迹回收训练。

## 七、与开源书对应

- mlabonne/llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- 如何降推理成本？答：共享前缀并行、提前收敛早停、按难度设预算，并回收轨迹训练。

## 九、演进

串行采样→并行+早停→预算自适应+蒸馏。

## 十、小结

推理时计算需系统优化与预算控制，并与训练闭环才可持续。
