# 推理时计算总览

> 对应 OpenAI, *Learning to Reason with LLMs (o1)*, 2024；Snell et al., *Scaling LLM Test-Time Compute*, 2024。

## 一、背景与挑战

训练后固定模型能力受限；推理时（test-time）投入更多计算可显著提升困难任务表现。

## 二、核心原理

在解码阶段用更多算力：更长思维链、多采样自洽、搜索（树/束）、以及训练"思考"策略；与训练算力互补。

## 三、数学形式

测试算力 $C_{test}=N\cdot L$（$N$ 采样数，$L$ 思维长度）；收益随任务难度与 $C_{test}$ 增。

## 四、代码实现

```python
samples = [model.generate(q, max_new=2048) for _ in range(N)]
answer = vote(samples)
```

## 五、与其他对比

- 与 智能体规划（推理-行动）互补。
- 与 长上下文（长思维）衔接。

## 六、常见误区

- 认为推理时计算万能，忽视训练不足根基。
- 过度采样致成本爆炸无收益。

## 八、面试题

- 推理时计算是什么？答：在生成阶段额外投入采样/搜索/长思考等算力，提升困难任务准确率。

## 九、演进

贪心→CoT→自洽→搜索/可学习思考。

## 十、小结

推理时计算把"思考更久"变成可扩展能力，与训练互补。
