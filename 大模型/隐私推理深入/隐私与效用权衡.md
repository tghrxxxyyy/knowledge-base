# 隐私与效用权衡

> 对应隐私-效用折中；模型评测指标深入 衔接。

## 一、背景与挑战

隐私越强往往精度越低/延迟越高，需按场景定级。

## 二、核心原理

以隐私预算、密态开销换安全；用任务敏感度分级：高敏用密态+DP，低敏用轻量。

## 三、数学形式

帕累托最优：在约束 $\epsilon\le\epsilon_0$ 下 $\max Acc$，或控延迟界。

## 四、代码实现

```python
if sensitivity(x) == "high": out = dp_he_infer(x)
else: out = plain_infer(x)
```

## 五、与其他对比

- 与 模型提取防御深入（降返回精度也损效用）共享权衡。
- 与 隐私推理部署深入（成本）衔接。

## 六、常见误区

- 一刀切高强度隐私致体验崩。
- 忽略延迟不可接受场景。
