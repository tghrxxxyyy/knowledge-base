# 隐私推理部署

> 对应生产隐私推理工程；datawhalechina/llm-universe 部署 衔接。

## 一、背景与挑战

隐私技术在真实系统需可扩展且合规。

## 二、核心原理

敏感输入本地预处理、推理走可信执行环境（TEE）/密态、输出做 DP 后处理、全链路审计。

## 三、数学形式

端到端风险 $\approx \text{risk}_{local}+\text{risk}_{tee}+\text{risk}_{dp}$，逐段控。

## 四、代码实现

```python
with tee_session() as s:
    out = s.run(model, dp_clip(x))
```
