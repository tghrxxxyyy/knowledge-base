# 同态加密与安全多方计算

> 对应 Gilad-Bachrach et al., *CryptoNets*, 2016；密文上做推理。

## 一、背景与挑战

云端推理不愿暴露输入/模型，需密态计算。

## 二、核心原理

同态加密（HE）允许密文上运算；安全多方（MPC）多方联合计算不暴露各自输入。

## 三、数学形式

HE：$E(a)\oplus E(b)=E(a+b)$，$E(a)\otimes E(b)=E(ab)$；解密得结果。

## 四、代码实现

```python
ct = he.encrypt(x)
ct_out = model_on_cipher(ct)   # 密态推理
y = he.decrypt(ct_out)
```

## 五、与其他对比

- 与 隐私推理总览深入（密态手段）衔接。
- 与 模型提取防御深入（模型不暴露）对照。

## 六、常见误区

- 密态推理极慢（HE 乘法深度受限）。
- 非线性层需近似/多项式化。

## 九、演进

CryptoNets → 更深层近似 → MPC 混合。

## 十、小结

密态推理最强隐私但代价高，适合高敏场景。
