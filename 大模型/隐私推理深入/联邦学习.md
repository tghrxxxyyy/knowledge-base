# 联邦学习（Federated Learning）

> 对应 McMahan et al., *Communication-Efficient FL (FedAvg)*, 2017；数据不出本地。

## 一、背景与挑战

多方可贡献模型能力但不愿共享原始数据（医疗/金融）。

## 二、核心原理

各客户端本地训练，仅上传梯度/参数，中心聚合（FedAvg）更新全局模型。

## 三、数学形式

聚合 $w_{t+1}=\sum_k \frac{n_k}{N} w_t^k$；本地步 $w^k\leftarrow w-\eta\nabla\mathcal L_k$。

## 四、代码实现

```python
for c in clients:
    g = c.local_train(global_w)
w = avg([g for g in grads], by_size)
```

## 五、与其他对比

- 与 隐私推理总览深入（本地数据）衔接。
- 与 数据投毒防御深入（客户端可能投毒）对照。

## 六、常见误区

- 梯度亦可能泄漏数据（需 DP）。
- 非独立同分布（Non-IID）致收敛差。

## 八、面试题

- 联邦学习为何隐私？答：原始数据不出端，仅传参数，但仍需 DP 防梯度泄漏。

## 九、演进

FedAvg → FedProx → 安全聚合+DP。

## 十、小结

联邦学习以参数聚合保数据本地，常配 DP 强化。
