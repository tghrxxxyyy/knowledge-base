# 差分隐私训练与推理

> 对应 Abadi et al., *Deep Learning with Differential Privacy*, 2016；可证伪泄露界。

## 一、背景与挑战

需给出“单个样本是否在训练集”的严格不可区分保证。

## 二、核心原理

逐样本梯度裁剪后加高斯噪，按累计隐私预算 $(\epsilon,\delta)$ 给出保证。

## 三、数学形式

机制 $M$ 满足 $(\epsilon,\delta)$-DP 若 $\Pr[M(D)\in S]\le e^\epsilon\Pr[M(D')\in S]+\delta$。

## 四、代码实现

```python
from opacus import PrivacyEngine
engine = PrivacyEngine(model, sample_rate, noise_multiplier=1.1)
```

## 五、与其他对比

- 与 训练数据提取深入（DP 降记忆）共享缓解。
- 与 鲁棒训练深入（梯度裁剪）技术交叠。

## 六、常见误区

- $\epsilon$ 过大保证弱。
- 噪声致效用下降需权衡。

## 八、面试题

- DP 保证什么？答：单样本在否训练集对输出影响有界，给出 $(\epsilon,\delta)$ 不可区分。

## 九、演进

## 十、小结

差分隐私提供可量化隐私界，代价是一定效用损失。
