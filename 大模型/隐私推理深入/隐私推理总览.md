# 隐私推理总览

> 对应隐私保护机器学习推理；与 模型提取攻击深入（数据泄漏）对照威胁。

## 一、背景与挑战

推理阶段模型可能泄漏训练成员/敏感属性，且云端推理暴露用户输入。

## 二、核心原理

手段组合：联邦学习（数据不出端）、差分隐私（输出加噪）、密态推理（HE/MPC）、最小化采集。

## 三、数学形式

隐私预算 $\epsilon$ 量化泄露上界；成员推断优势 $Adv=|\Pr[\hat m=1|mem]-\Pr[\hat m=1|non]|$。

## 四、代码实现

```python
out = model(x)            # 本地/密态
out = clip_noise(out, eps)
```

## 五、与其他对比

- 与 训练数据提取深入（记忆泄漏）共享威胁。
- 与 安全分类器深入（敏感内容）交叉。

## 六、常见误区

- 以为不返回原始即隐私安全（成员推断仍可）。
- 隐私技术盲目堆致不可用。
