# 短期与长期记忆

> 对应 Packer et al., *MemGPT: Towards LLMs as Operating Systems*, 2023；Wu et al., *Recurrent Memory Transformer* 系列（长程记忆机制）。

## 一、背景与挑战

上下文窗口相当于内存，容量有限且每 token 都要付费；长期存储相当于磁盘，容量大但需显式换入换出。
如何在两者间调度，使当前推理拿到最相关信息而不超预算，是智能体运行时的核心资源管理问题。

## 二、核心原理

- 虚拟上下文思路：模型可通过工具主动读写外部存储（分页换入换出），把有限窗口当缓存管理。
- 短期记忆内容：当前目标、最近若干轮对话、未完成的子任务、临时变量；长期记忆内容：稳定事实、偏好、历史结论、经验规则。
- 溢出策略：滚动摘要（把旧轮压缩）、要点提取（只留决策与约束）、外置指针（存全文、上下文里只留引用）。

## 三、数学形式

上下文预算约束下的装配是背包问题：$\max\sum_i v_i x_i$ s.t. $\sum_i \ell_i x_i\le B,\ x_i\in\{0,1\}$。

其中 $v_i$ 为条目预期价值、$\ell_i$ 为 token 长度；实践中用价值密度 $v_i/\ell_i$ 贪心近似，因此摘要能提高整体收益。

## 四、代码实现

```python
def assemble_context(system, goal, recent, mem_hits, budget):
    parts, used = [system, goal], tok(system) + tok(goal)
    for item in sorted(mem_hits + recent, key=lambda m: m.value / max(1, tok(m.text)),
                       reverse=True):
        if used + tok(item.text) > budget:
            continue                       # 装不下则跳过，保留高价值密度条目
        parts.append(item.text); used += tok(item.text)
    return "\n".join(parts)
```

## 五、与其他对比

- 与操作系统分页：思想同构（局部性、换页、缓存命中率），但换入决策由模型语义判断而非硬件访问模式。
- 与纯长上下文：长上下文减少调度复杂度，但长程有效性衰减且成本随长度增长，分层记忆更省。

## 六、常见误区

- 只做尾部截断，丢掉最早的系统约束与任务目标，导致行为漂移。
- 摘要不保留可执行细节（ID、参数、约束），后续步骤无法继续。
- 把长期记忆全量注入以求稳妥，反而挤掉当前关键信息并放大干扰。

## 八、面试题

- 为什么把上下文装配看成背包问题？答：预算固定、条目有长度与价值，最优解是价值密度排序下的取舍，摘要相当于提升价值密度。
- 截断为什么优先保留系统约束与目标？答：它们决定全局行为，一旦丢失后续所有步骤都会偏，属于不可替代信息。

## 九、演进

全历史拼接 → 尾部截断 → 滚动摘要 → 虚拟上下文与分页换入换出 → 价值驱动的上下文装配。

## 十、小结

短期与长期记忆是缓存与磁盘的关系，调度目标是在固定 token 预算下最大化信息价值。
