# 智能体记忆总览

> 对应 Park et al., *Generative Agents*, UIST 2023；Packer et al., *MemGPT*, 2023。

## 一、背景与挑战

上下文窗口是易失且有限的工作记忆，长期任务与长期关系需要跨会话保留信息。
难点不在于「存」，而在于写什么、何时写、如何在需要时精确召回，以及如何处理过时与冲突的记忆。

## 二、核心原理

- 分层：上下文内的工作记忆（当前对话与状态）、可检索的长期记忆（事实、事件、经验）、参数化记忆（权重内的知识）。
- 写路径：从原始交互中抽取值得长期保留的条目（事实、偏好、结论），做去重与归并后落库。
- 读路径：按当前查询与状态检索候选，按相关性、时新性、重要性排序注入，形成有限预算下的最优上下文装配。

## 三、数学形式

Generative Agents 的检索打分是三项线性组合：$s(m)=\alpha_r\,\text{rel}(q,m)+\alpha_t\,\text{rec}(m)+\alpha_i\,\text{imp}(m)$。

其中时新性常取指数衰减 $\text{rec}(m)=\gamma^{\Delta t}$（$0<\gamma<1$），重要性由模型对条目打分给出，三项需先各自归一再加权。

## 四、代码实现

```python
def retrieve(mem_store, q, now, k=6, a=(1.0, 0.5, 0.5), gamma=0.995):
    def score(m):
        rel = cos(embed(q), m.vec)
        rec = gamma ** ((now - m.ts).total_seconds() / 3600)
        return a[0] * rel + a[1] * rec + a[2] * m.importance
    return sorted(mem_store, key=score, reverse=True)[:k]
```

## 五、与其他对比

- 与 RAG：RAG 检索静态语料，记忆检索自身交互产物，需要写入策略、时效管理与冲突消解。
- 与长上下文：长上下文省去检索但成本高且有效注意力衰减；记忆用检索换成本，但引入召回失败风险。

## 六、常见误区

- 把整段对话原文全存：检索噪声大、隐私风险高，应抽取结构化条目。
- 只按语义相似检索，忽略时新性，导致用旧偏好覆盖新决定。
- 无遗忘与合并机制，记忆库随时间线性膨胀而召回精度下降。

## 八、面试题

- 记忆检索为何要加时新性与重要性？答：语义相似不等于当下有用，时新性处理偏好变更，重要性避免琐碎条目挤占预算。
- 记忆系统的最大工程风险？答：无治理导致膨胀与冲突，进而召回精度下降，需要合并、淘汰与冲突消解策略。

## 九、演进

纯上下文历史 → 摘要压缩 → 向量长期记忆 → 分层记忆与虚拟上下文管理（MemGPT）→ 带治理与冲突消解的记忆库。

## 十、小结

智能体记忆是有预算的信息装配问题：写要抽取、读要多因子排序、库要持续治理。
