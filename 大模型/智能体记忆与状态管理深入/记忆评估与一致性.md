# 记忆评估与一致性

> 对应 Bae et al., *LoCoMo* 类长期对话记忆评测（长期一致性评估）；Packer et al., *MemGPT*, 2023。

## 一、背景与挑战

记忆系统很容易「看起来有用」：召回了相关条目却未改善最终行为，或在长期对话中自相矛盾。
需要可量化的评估：召回质量、行为收益、以及跨时间的一致性。

## 二、核心原理

- 分层评估：检索层（召回率、精确率）、装配层（关键条目是否进上下文）、行为层（任务成功率、偏好遵守率）。
- 一致性测试：构造时间跨度长的多轮场景，注入偏好变更与事实更新，检查后续回答是否遵循最新状态且不矛盾。
- 反事实探针：删除某条记忆看行为是否变化，用于验证该条目是否真正被使用（归因）。

## 三、数学形式

记忆有效性可用带删除的反事实差异衡量：$\text{Attr}(m)=\mathbb E[\,Q(y\mid M)\,]-\mathbb E[\,Q(y\mid M\setminus\{m\})\,]$。

一致性可用矛盾率 $\text{CR}=\frac{\#\{(i,j): y_i \text{与} y_j \text{冲突}\}}{\binom{n}{2}}$ 统计跨轮回答对的逻辑冲突比例。

## 四、代码实现

```python
def eval_memory(agent, scenarios):
    m = {"recall": [], "obey": [], "contradict": 0}
    for sc in scenarios:
        hits = agent.retrieve(sc.query)
        m["recall"].append(len(set(hits) & set(sc.gold_mem)) / len(sc.gold_mem))
        ans = agent.answer(sc.query)
        m["obey"].append(follows_latest_preference(ans, sc.latest_pref))
        m["contradict"] += is_contradictory(ans, sc.prior_answers)
    return {k: (sum(v) / len(v) if isinstance(v, list) else v) for k, v in m.items()}
```

## 五、与其他对比

- 与 RAG 评估：同样看召回与忠实度，但记忆评估必须覆盖时间维度与更新语义。
- 与人工体验评测：主观评测能捕捉「像不像记得我」，但难以定位是检索、装配还是模型使用环节的问题。

## 六、常见误区

- 只看检索指标，不看行为是否改变；召回正确却未被模型采纳同样是失败。
- 评测场景时间跨度太短，无法暴露过期与冲突问题。
- 用同一批交互既写记忆又评测，等于自我泄漏，评测集应独立构造。

## 八、面试题

- 如何证明某条记忆真的起作用？答：做删除式反事实对比，观察任务指标变化，即记忆归因。
- 长期一致性怎么量化？答：构造含偏好变更的长跨度场景，统计矛盾率与最新偏好遵守率。

## 九、演进

主观体验判断 → 检索指标 → 行为层任务指标 → 长期一致性与冲突率 → 反事实归因驱动的记忆优化。

## 十、小结

记忆系统必须端到端评估：召回、装配、行为、一致性四层缺一不可，归因靠反事实删除。
