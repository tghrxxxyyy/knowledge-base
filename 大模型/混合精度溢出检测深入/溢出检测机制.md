# 溢出检测机制

> 对应 Micikevicius et al., 2018（溢出检测与缩放调整）；框架 GradScaler 实现。

## 一、背景与挑战

混合精度训练中必须及时发现 Inf/NaN，否则错误会污染权重且难以回溯。检测需在反向后立即进行，并决定跳过或回退。

## 二、核心原理

常见做法：反向后用 `torch.isfinite` 检查梯度；若含非有限值，本轮 step 跳过（不更新），并把缩放因子减半。

也可检测权重/激活的振幅（amax）直方图，提前预警接近溢界。

## 三、数学形式

$\text{overflow}=\neg\bigwedge_i \mathrm{isfinite}(g_i)$；若 overflow 则 $s\leftarrow s/2$，丢弃本步更新。

## 四、代码实现

```python
found_inf = torch.zeros(1, device="cuda")
torch._amp_foreach_non_finite_check_and_unscale_(
    [p.grad for p in model.parameters()], found_inf, scaler.get_scale())
if found_inf.item():
    scaler.update(); continue    # 跳过本步
```

## 五、与其他对比

- 与 训练发散诊断与恢复深入 衔接，溢出是发散的硬信号。
- 与 损失缩放 配套，检测驱动缩放调整。
- 与 梯度范数监控 互补（幅度 vs 有限性）。

## 六、常见误区

- 检测到溢出仍更新，污染权重。
- 只在训练末检查，错误已扩散。
- 忽略 NaN 的“静默传播”（经 0*Inf 变 NaN）。

## 八、面试题

- 溢出后为何跳过更新？答：含 Inf/NaN 的梯度会污染权重，宁可丢弃本步。
- 如何早期发现溢出风险？答：监控梯度 amax/范数，逼近 FP16 上限即预警。

## 九、演进

无检测 → isfinite 检查 → amax 直方图预警。

## 十、小结

溢出检测在反向后立即拦截非有限梯度，并驱动缩放回退，防止污染。
