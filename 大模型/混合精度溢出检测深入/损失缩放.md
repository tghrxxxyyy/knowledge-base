# 损失缩放（Loss Scaling）

> 对应 Micikevicius et al., 2018（动态损失缩放）。

## 一、背景与挑战

FP16 下小梯度（如 1e-7）被下溢为 0，更新失效。损失缩放把整条计算图乘以大因子 $s$，使梯度同步放大 $s$ 倍进入 FP16 可表示区。

更新前再除以 $s$ 还原真实梯度。

## 二、核心原理

反向传播的线性性保证 $g_{scaled}=s\cdot g$；只要 $s\cdot g$ 落在 FP16 范围，信息不丢。缩放因子可静态设定或动态根据溢出调整。

动态策略：若检测到 Inf/NaN，把 $s$ 减半并重来；否则偶尔翻倍以用更大范围。

## 三、数学形式

$g_{fp16}=s\cdot\nabla L$；$W\leftarrow W-\eta\cdot(g_{fp16}/s)$，缩放仅影响表示不影响数学。

## 四、代码实现

```python
scaler = torch.amp.GradScaler()
with torch.amp.autocast(device_type="cuda", dtype=torch.float16):
    out = model(x); loss = crit(out, y)
scaler.scale(loss).backward()
scaler.step(optimizer); scaler.update()   # 内部检测溢出并调 s
```

## 五、与其他对比

- 与 FP16与BF16表示 衔接，缩放是 FP16 的补丁。
- 与 混合精度溢出检测深入 总览互补。
- 与 数值下溢与防御 同目标（防下溢）。

## 六、常见误区

- 缩放过大致乘积上溢，反引入 Inf。
- 静态缩放不随突刺调整，仍溢。
- 在 BF16 上无谓缩放，徒增复杂度。

## 八、面试题

- 损失缩放为何能防下溢？答：梯度整体放大 s 倍进 FP16 可表示区，更新前除回。
- 动态缩放如何工作？答：溢出则 s 减半重算，稳定则逐步增大范围。

## 九、演进

静态缩放 → 动态缩放 → BF16 免缩放。

## 十、小结

损失缩放把 FP16 梯度抬进可表示区，是 FP16 混合精度的关键补丁。
