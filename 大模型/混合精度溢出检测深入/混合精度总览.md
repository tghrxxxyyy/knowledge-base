# 混合精度训练总览

> 对应 Micikevicius et al., *Mixed Precision Training*, 2018（混合精度训练与损失缩放）。

## 一、背景与挑战

用 FP16/BF16 存激活与梯度可省显存、提速，但其动态范围远小于 FP32，易出现上溢（Inf）与下溢（0），破坏训练。

混合精度以 FP32 主权重（master weights）保持精度，前向/反向用低精度，再汇回高精度。

## 二、核心原理

核心三件：① FP32 主权重参与更新；② 低精度做矩阵乘与激活；③ 损失缩放把梯度幅值抬进 FP16 可表示区。

BF16 指数位与 FP32 相同，几乎不上溢，常无需缩放；FP16 范围小，必须缩放。

## 三、数学形式

更新：$W_{fp32}\leftarrow W_{fp32}-\eta\,\mathrm{cast}_{fp32}(g_{fp16}\cdot s)/s$，缩放因子 $s$ 在上溢时减半。

## 四、代码实现

```python
from torch.amp import autocast, GradScaler
scaler = GradScaler()
with autocast(device_type="cuda", dtype=torch.float16):
    loss = model(x)
scaler.scale(loss).backward(); scaler.step(opt); scaler.update()
```

## 五、与其他对比

- 与 损失函数数值鲁棒深入 衔接，低精度放大损失溢界风险。
- 与 优化器状态数值误差深入 衔接，master 权重属优化器状态。
- 与 注意力数值稳定与溢界深入 同源，都怕 exp 上溢。

## 六、常见误区

- 以为 BF16 也需缩放（通常不必）。
- 缩放因子固定不变，遇突刺仍溢。
- 把整个优化器状态放 FP16，累积误差放大。

## 八、面试题

- 为何要 FP32 主权重？答：低精度更新步长被舍入，长期漂移，FP32 保精度。
- BF16 与 FP16 混合精度差别？答：BF16 指数位同 FP32，基本不上溢，常免缩放。

## 九、演进

FP32 → FP16+缩放 → BF16 → 8-bit 训练（FP8）。

## 十、小结

混合精度以低精度提速、FP32 主权重保精度，损失缩放是 FP16 的关键。
