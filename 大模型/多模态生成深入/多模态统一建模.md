# 多模态统一建模

> 对应统一多模态模型研究（Chameleon, Meta 2024；Emu, 2023；Janus, DeepSeek 2024 等）；亦见 VQ-VAE/码本离散化与自回归建模。

## 一、背景与挑战

传统多模态系统多为「多塔拼接」：视觉编码器（ViT）、语言模型、音频编码器各自独立，再用桥接层对齐。这种架构模块耦合、扩展新模态需重新设计，且生成与理解常被拆成两个模型。

统一建模（Unified Multimodal Modeling）的野心是：把图像、文本、音频乃至视频都离散化为统一 token，用**单一 Transformer** 自回归建模，实现「任意模态进、任意模态出」（any-to-any）。核心挑战有三：模态间表征干扰（一种模态拖累另一种）、训练稳定性（离散化重建损失与语言损失冲突）、以及跨模态对齐难。

## 二、核心原理

统一建模的关键技术栈：

1. **统一 token 空间**：用 VQ-VAE / 码本把图像块、音频段编码为离散码，与文本词表拼成共享词表。
2. **单一自回归**：Transformer 在拼接后的 token 序列上做 next-token 预测，图像生成等价于「预测图像码」。
3. **模态平衡训练**：对视觉、语言、音频损失加权，防止某模态主导梯度。
4. **解耦变体**：Janus 等把「理解编码器」与「生成编码器」分离但共享 LLM，缓解生成-理解互相掣肘。

训练编排上，统一模型常采用「多阶段」：先各自预训练各模态 tokenizer（VQ-VAE / 音频 codec），再在统一序列上做大规模自回归预训练，最后用指令数据做对齐。阶段间需小心「模态失衡」——若某模态数据过多，共享注意力会被其主导，需用采样权重或损失掩码平衡，否则出现「会画图但忘了说话」的退化。

## 三、形式化与数学基础

设多模态序列由文本 token $t$ 与图像码 $v$ 组成，统一词表 $V=V_{text}\cup V_{img}$。自回归目标：

$$
\mathcal{L} = -\sum_{i=1}^{N} \log p_\theta(z_i \mid z_{<i}),\quad z_i\in V
$$

图像离散化由 VQ-VAE 码本 $E=\{e_1,\dots,e_K\}$ 给出：

$$
v = \arg\min_{k} \| \text{enc}(x_{patch}) - e_k \|_2
$$

训练稳定性常引入模态损失加权 $\mathcal{L} = \lambda_t \mathcal{L}_{text} + \lambda_v \mathcal{L}_{img}$，调 $\lambda$ 平衡表征。

## 四、代码实现

统一自回归生成的精简示意：

```python
def unified_generate(model, tokenizer, img_tokenizer, prompt_tokens):
    seq = prompt_tokens
    for _ in range(max_len):
        z = model(seq)                       # 单一 Transformer
        nxt = z.argmax(-1)[-1]
        seq = seq + [nxt]
        if nxt in img_tokenizer.codes:        # 图像码→解码出图块
            yield img_tokenizer.decode(nxt)
    return tokenizer.decode_text(seq)
```

## 五、与其他技术对比

| 架构 | 模态耦合 | 生成/理解 | 扩展新模态 | 代表 |
|------|----------|-----------|------------|------|
| 多塔拼接 | 松 | 分模型 | 中 | CLIP+LLM |
| 统一 token | 紧 | 同一模型 | 易 | Chameleon |
| 解耦统一 | 中 | 同 LLM | 易 | Janus |
| 扩散生成 | 紧(图像) | 仅生成 | 难 | SD 系 |

## 六、常见误区

- **「统一即最优」**：模态干扰与训练不稳定是真实代价，解耦常更稳。
- **「离散化无损」**：VQ 码本有损，细节重建受码本容量限制。
- **「加模态只需拼词表」**：对齐与平衡训练才是难点，否则互相拖累。
- **混淆理解与生成**：统一模型需同时优化两类目标，单目标易偏科。

## 九、演进与趋势

从 Chameleon 的早期融合，到 Janus 的解耦统一，再到支持音频/视频的任意进任意出。前沿聚焦：更大码本与保真重建、模态平衡的课程化训练、以及统一模型在 agent 多模态交互中的落地。趋势是「一个模型贯通感知与生成」。

## 十、小结

多模态统一建模用统一 token + 单一 Transformer 追求 any-to-any，技术核心在离散化与模态平衡。其价值是架构简洁与可扩展，代价是训练稳定与模态干扰——解耦变体正成为务实主流。
