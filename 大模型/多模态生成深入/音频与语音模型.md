# 音频与语音模型

> 对应语音多模态研究（Whisper, Radford et al. 2022；GPT-4o 端到端语音；VALL-E, 2023；音频 token 化基础）。

## 一、背景与挑战

语音是大模型多模态的听觉维度，包含三条主线：语音识别（ASR，语音→文本）、语音合成（TTS，文本→语音）、语音对话（端到端语音理解与生成）。传统方案用级联管线（ASR→LLM→TTS），每环独立、延迟累积、且丢失韵律、情感、副语言信息（笑声、停顿、语气）。

核心挑战：音频信号高采样、时序长，直接建模算力巨大；离散化保真与韵律保留trade-off；端到端流式低延迟难；多语种与噪声鲁棒性。

## 二、核心原理

音频建模主流路径：

1. **表示**：连续侧用梅尔频谱（Mel-spectrogram）；离散侧把音频编为离散 token（如 EnCodec、SoundStream 的残差向量量化 RVQ），纳入统一词表。
2. **识别（ASR）**：Whisper 用大规模弱监督音频-文本对训练编码器-解码器，强鲁棒、零样本多语。
3. **合成（TTS）**：VALL-E 用离散音频 token + 自回归（或扩散）从文本生成 token，再解码为波形，可克隆音色。
4. **端到端对话**：GPT-4o 类直接在音频流上做 next-token，统一理解与生成，保留韵律、低延迟。

## 三、形式化与数学基础

离散音频编码用残差向量量化（RVQ），第 $l$ 层量化残差：

$$
r_0 = x,\quad r_l = r_{l-1} - e^{(l)}_{k_l},\quad k_l = \arg\min_k \|r_{l-1}-e^{(l)}_k\|_2
$$

得到码序列 $c = (k_1,\dots,k_L)$，自回归语音生成：

$$
\mathcal{L}_{TTS} = -\sum_{i} \log p_\theta(c_i \mid c_{<i}, \text{text})
$$

端到端语音模型在音频 token 与文本 token 共享序列上联合训练，损失为两者交叉熵之和。

## 四、代码实现

音频离散化与合成的精简示意：

```python
import torch
encoder = EncodecEncoder()              # 连续→离散
codes = encoder.encode(waveform)        # RVQ 码序列 (L, B)
# 自回归 TTS
for i in range(max_len):
    logits = tts_model(text_emb, codes[:, :i])
    codes = torch.cat([codes, logits.argmax(-1)], dim=1)
waveform = decoder.decode(codes)        # 离散→波形
```

训练数据上，ASR 依赖弱监督音频-文本对（如 Whisper 用上万小时多语数据）；TTS 需高质量朗读语料，且音色克隆面临授权与伦理边界；端到端语音还需「带副语言的对话」数据（含语气、打断、笑声），这类数据极稀缺，常以合成与蒸馏补足。噪声鲁棒性则靠数据增广（加噪、混响、变速）提升。

## 五、与其他技术对比

| 方案 | 延迟 | 韵律保留 | 复杂度 | 代表 |
|------|------|----------|--------|------|
| ASR+LLM+TTS 级联 | 高 | 差 | 中 | 传统对话 |
| 离散 token 自回归 | 中 | 好 | 中 | VALL-E |
| 端到端语音 | 低 | 好 | 高 | GPT-4o |
| 扩散声码器 TTS | 中 | 好 | 中 | 现代 TTS |

## 六、常见误区

- **「语音只是文本载体」**：韵律、情感、副语言信息在级联中被丢弃。
- **「级联足够好」**：延迟累积与错误传播使对话生硬。
- **「离散化无损」**：RVQ 有损，高保真需多层码与高码本。
- **混淆 ASR 与语音理解**：识别不等于语义理解，端到端才统管。

## 九、演进与趋势

从级联到离散 token 自回归，再到端到端统一语音（音频进、音频出）。趋势：与统一多模态模型（见「多模态统一建模」）融合，让语音成为 agent 的自然交互通道；RVQ 码本扩大与流式推理降低延迟。

## 十、小结

音频与语音模型以离散 token 化为统一建模前提，Whisper 解决鲁棒识别、VALL-E 解决音色克隆、端到端语音解决低延迟与韵律保留。它是多模态听觉维度的核心支柱。
