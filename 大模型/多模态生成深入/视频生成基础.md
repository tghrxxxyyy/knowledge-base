# 视频生成基础

> 对应视频扩散研究（Sora / DiT, OpenAI 2024；AnimateDiff, 2023；亦见扩散模型基础）。

## 一、背景与挑战

视频生成在图像生成之上叠加了**时间维度**：不仅要每帧美观，还要帧间连贯、物体运动一致、长时序不崩坏。直接逐帧生成会得到闪烁、跳变的不连贯片段；延长视频更面临显存与时长平方级增长的算力灾难。

核心挑战：时序一致性（物体不凭空出现/消失）、运动合理性（符合物理与语义）、长视频连贯（全局叙事不漂移）、以及实时性。2024 年起，以 DiT（Diffusion Transformer）在时空 patch 上扩散成为主流路线，Sora 即代表。

## 二、核心原理

视频扩散在图像扩散基础上扩展时间轴，主要范式：

1. **时空 patch 化**：把视频切为时空立方体 patch（如 $2\times16\times16$），用 ViT 类 tokenizer 映射为 token，统一进 Transformer。
2. **时序建模**：在 U-Net 加时序注意力（或 DiT 原生时空注意力），让相邻帧交换信息保一致。
3. **条件控制**：文本/图像/动作作为条件引导，支持文生视频、图生视频、视频续写。
4. **长视频策略**：分段生成 + 一致性约束（重叠帧、光流对齐）拼接。

## 三、形式化与数学基础

设视频张量 $V\in\mathbb{R}^{F\times H\times W\times 3}$，$F$ 为帧数。时空 patch 化为：

$$
P = \text{Patchify}(V) \in \mathbb{R}^{N\times d},\quad N = \frac{F}{f}\cdot\frac{H}{p}\cdot\frac{W}{p}
$$

去噪 Transformer 在 patch token 上做含时序位置的注意力：

$$
\mathcal{L} = \mathbb{E}_{V_0,t,\epsilon,c}\big[\|\epsilon - \epsilon_\theta(V_t, t, c)\|^2\big]
$$

时序注意力对帧维 $f$ 做 self-attention，使第 $i$ 帧特征聚合邻帧上下文，约束运动连续性。

## 四、代码实现

时空注意力融合的精简示意：

```python
def video_denoise_block(x, c, t):
    # x: (B, F, H, W, C) 视频潜变量
    h = spatial_attn(x)                 # 帧内空间注意力
    h = temporal_attn(h.permute(0,2,1,3,4))  # 帧间时序注意力
    h = cross_attn(h, c)                # 文本条件
    return h
```

训练需大规模视频-文本对与高带宽存储。

数据侧还面临「时间一致性监督」稀缺的问题：图像有海量配对文本，视频-文本对相对少且标注粗。常见做法是先用图像数据训空间先验、再喂视频学时序，或在潜空间用光流、深度等派生信号作自监督一致性正则。推理期则常用「首帧锚定 + 滑动窗口」降低长视频漂移。

## 五、与其他技术对比

| 图像扩散+插帧 | 弱 | 中 | 差 | 早期 |
| 3D U-Net | 中 | 中 | 中 | AnimateDiff |
| 时空 DiT | 强 | 高 | 好 | Sora |

## 六、常见误区

- **「视频=图像序列」**：忽略时序一致性会闪烁跳变，必须显式时序建模。
- **「分辨率越高越好」**：帧数×分辨率使算力立方增长，需折中。
- **「长视频一次生成」**：常需分段+约束，单模型难保全局连贯。
- **混淆图生视频与文生视频**：前者有首帧锚定，一致性更易。

## 九、演进与趋势

从 AnimateDiff 的插件式时序层，到 Sora 的原生时空 DiT，再到世界模型视角（视频生成即物理模拟）。趋势：更长时长、更高分辨率、更强可控（相机/动作/物理），以及与统一多模态模型（见「多模态统一建模」）融合。

## 十、小结

视频生成是图像扩散加时间维，核心是时空 patch 化与时序注意力保一致。DiT 路线在可扩展性与长视频表现上领先，分段生成+约束是落地长视频的务实策略。
