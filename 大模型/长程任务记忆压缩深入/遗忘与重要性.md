# 遗忘与重要性评估

> 对应 记忆衰退（memory decay）与重要性打分。

## 一、背景与挑战

无限累积记忆既贵又稀释。需要像人一样“遗忘”低价值信息、强化高价值信息。

## 二、核心原理

给每条记忆维护重要性分数（由访问频率、任务相关性、复述次数决定），低分且过期者淘汰或归档。重要性可用模型对“该信息对未来是否有用”的评分近似。

## 三、数学形式

保留概率随分数与时间衰减：

$$P_{keep}(m) = \sigma\big(s(m) - \gamma\cdot t_{age}(m)\big)$$

$\gamma$ 为遗忘速率。

## 四、代码实现

```python
score = importance(m) - GAMMA * age(m)
if score < LOW: archive(m)
```

## 五、与其他对比

- 与 轨迹摘要压缩 共同控制记忆规模。
- 与 智能体轨迹自我进化深入 的高价值经验筛选一致。

## 六、常见误区

- 统一 TTL 忽略信息价值差异。
- 遗忘后无法恢复，需先归档再淘汰。

## 八、面试题

- 为何要区分重要性而非统一过期？答：高价值信息应长留，低价值应早弃以省成本。

## 九、演进

永久存储 → 固定 TTL → 重要性驱动遗忘。

## 十、小结

遗忘不是缺陷而是优化：用重要性驱动淘汰，保住记忆的性价比。
