# 长程任务记忆压缩总览

> 对应 Wang et al., *Voyager*, 2023；Park et al., *Generative Agents*, 2023。

## 一、背景与挑战

长程任务（如开放世界探索、多轮项目）产生远超上下文窗口的轨迹。原始记录直接塞入上下文既超长又稀释注意力。需要压缩式记忆。

## 二、核心原理

记忆分三层：原始交互流（短期）、压缩摘要（中期）、可检索知识/技能（长期）。压缩即把长轨迹映射为信息密度更高的表示，同时保留任务相关性与可追溯性。

## 三、数学形式

压缩率与信息损失权衡：

$$\min_{\hat M} \mathcal L_{task}(\hat M) + \beta\cdot I(M;\hat M)$$

$\hat M$ 为压缩记忆，$I$ 约束保留信息量。

## 四、代码实现

```python
summary = llm(f"压缩以下轨迹保留关键决策:\n{trace}")
memory.store(summary, ttl=long)
```

## 六、常见误区

- 压缩过狠丢失关键约束，导致任务偏离。
- 摘要本身增长无界，未二级压缩。

## 八、面试题

- 为何不能直接把全文放上下文？答：超窗口且噪声稀释注意力，压缩提密度降成本。

## 九、演进

全量上下文 → 滑动窗口 → 分层压缩记忆。

## 十、小结

记忆压缩是长程智能体可行的基石，分层与可检索是关键。
