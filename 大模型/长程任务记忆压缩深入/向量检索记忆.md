# 向量检索记忆

> 对应 外部记忆检索（retrieval-augmented memory）。

## 一、背景与挑战

线性摘要无法应对“只用到很久以前某一细节”的场景。需要按需检索而非全量加载。

## 二、核心原理

把记忆切片编码为向量存入库，查询时用当前状态检索 top-k 相关片段注入上下文。类似 RAG 但记忆源是自身轨迹，支持精确召回分散信息。

## 三、数学形式

检索相关度：

$$m^* = \arg\max_{m\in M} \cos(E(q_t),\, E(m))$$

$q_t$ 为当前查询/状态嵌入。

## 四、代码实现

```python
q = embed(state); hits = mem_index.search(q, k=5)
ctx = assemble(hits)
```

## 五、与其他对比

- 与 轨迹摘要压缩 互补：摘要给全局、检索给局部。
- 与 智能体推理成本建模深入 共担检索开销。

## 六、常见误区

- 切片过粗致检索噪声，过细致碎片化。
- 未随时间重排重要性，旧片段永远平等。

## 八、面试题

- 检索记忆相比摘要的优势？答：按需精确召回分散细节，不受摘要泛化损失。

## 九、演进

全量 → 摘要 → 摘要+向量检索混合。

## 十、小结

向量检索记忆补齐了摘要“易丢细节”的短板，实现精准长程回溯。
