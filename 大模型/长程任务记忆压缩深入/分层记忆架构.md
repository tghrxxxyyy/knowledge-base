# 分层记忆架构

> 对应 Park et al., *Generative Agents*, 2023 的三层记忆。

## 一、背景与挑战

单一存储难以同时满足“近期细节”“中段摘要”“长期知识”的不同访问模式。需分层。

## 二、核心原理

借鉴生成式智能体：观察（observation）原始流 → 近期记忆（recent，短期） → 反思记忆（reflection，抽象高层洞察，长期）。高层反思由低层聚合而来，提供跨事件规律。

## 三、数学形式

层级聚合：

$$R = \text{Reflect}\big(\{m_i : \text{rel}(m_i, q) > \tau\}\big)$$

$R$ 为高层洞察，覆盖低层细节的共性。

## 四、代码实现

```python
recent = buffer[-N:]
reflections = llm(f"从以下提炼规律:\n{recent}")
```

## 五、与其他对比

- 与 Voyager 技能库（最高层可复用）同构。
- 与 多智能体通信协议深入 的“共享黑板”可类比。

## 六、常见误区

- 层级间无同步，反思基于陈旧近期记忆。
- 反思过抽象脱离可执行细节。

## 八、面试题

- 反思记忆相对近期记忆的价值？答：提炼跨事件规律，提供全局策略而非单点细节。

## 九、演进

单缓冲 → 双级 → 观察/近期/反思三层。

## 十、小结

分层记忆以不同粒度服务不同决策，是长程智能体的记忆骨架。
