# 记忆压缩评估

> 对应 长程任务基准（如 Voyager/生成式智能体评测）。

## 一、背景与挑战

压缩是否“保真且降本”必须量化，否则无法选策略。

## 二、核心原理

在长程任务上对比：完整记忆 vs 压缩记忆的完成率差异（保真度），以及 token 节省比（压缩率）。理想是完成率几乎不变而成本大幅下降。

## 三、数学形式

保真损失与压缩收益：

$$\text{Loss} = 1 - \frac{\text{SR}_{cmp}}{\text{SR}_{full}},\quad \text{Save} = 1 - \frac{T_{cmp}}{T_{full}}$$

目标 $\text{Loss}\approx 0,\text{Save}\gg 0$。

## 四、代码实现

```python
base = run(task, full_memory)
cmp = run(task, compressed)
```

## 五、与其他对比

- 与 成本评估基准 共担 token 节省度量。
- 与 智能体可靠性与失败模式深入 共担长程失败归因。

## 六、常见误区

- 只在短任务验证，压缩收益未显现。
- 用单一指标（如字符数）代替任务保真。

## 八、面试题

- 如何判断压缩是否过度？答：看完成率下降幅度，损失超阈值即过度。

## 九、演进

人工观感 → 完成率对比 → 保真-压缩二维评估。

## 十、小结

记忆压缩评估需在“省钱”与“保真”间量化平衡，长程任务方见真章。
