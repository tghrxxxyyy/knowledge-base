# 协同教学（Co-teaching）

> 对应 Han et al., 《Co-teaching》, 2018；双网络互选干净样本。

## 一、背景与挑战

单网络难分辨自身错标；双网络可互相提供干净样本信号。

## 二、核心原理

两个网络各用对方认为小损失的样本训练（小损失更可能为干净），逐步互教，配合遗忘率控样本比。

## 三、数学形式

每轮选损失最小的 $R(t)$ 比例样本，$R(t)$ 随训练衰减（从多到少）。

## 四、代码实现

```python
loss_a = criterion(net_a(x), y)
mask = loss_a < percentile(loss_a, R)     # 选小损失
loss_b = criterion(net_b(x[mask]), y[mask])
```

## 五、与其他对比

- 与 样本选择深入（小损失=干净假设）共享。
- 与 标签噪声总览（选择类）衔接。

## 六、常见误区

- 两网络趋同失去互补。
- 遗忘率不当选入噪声。

## 九、演进

## 十、小结

协同教学以双网络互选干净样本，缓解单网自证偏差。
