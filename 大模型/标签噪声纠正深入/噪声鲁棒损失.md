# 噪声鲁棒损失函数

> 对应 Zhang & Sabuncu, 《Generalized Cross Entropy》, 2018；以及 MAE（Ghosh et al., 2017）。

## 一、背景与挑战

交叉熵对噪声敏感（过度拟合错标）；需对离群/错标更稳健的损失。

## 二、核心原理

MAE 对噪声稳健但收敛慢；GCE 调和 CE 与 MAE；对称损失（SL）在噪声对称下一致。

## 三、数学形式

GCE: $\mathcal L_q = \frac{1-q}{q}(1 - p_y^q)$；当 $q\to0$ 趋近 CE，$q\to1$ 趋近 MAE。

## 四、代码实现

```python
p = probs[label]
loss = (1 - p**q) / q             # GCE，q 控制稳健度
```

## 五、与其他对比

- 与 标签噪声总览（属鲁棒损失类）衔接。
- 与 样本选择深入（互补）共享。

## 六、常见误区

- GCE 的 q 需调，过大欠拟合。
- 鲁棒损失仍可能被极端噪声破。

## 八、面试题

- GCE 为何鲁棒？答：用 $p^q$ 降低高损失（错标）样本权重，较 CE 更抗噪声。

## 九、演进

CE → MAE → GCE/对称损失。

## 十、小结

鲁棒损失从形式上降权错标，是噪声下的直接对策。
