# 前向校正与噪声建模

> 对应 Patrini et al., 《Making Deep Nets Robust to Label Noise》, 2017（损失/标签转移校正）。

## 一、背景与挑战

已知/可估噪声转移矩阵时，可在训练或推断阶段显式校正。

## 二、核心原理

前向校正：用转移矩阵 $T$ 把预测概率投影回真实分布 $p_{true}=T^{-1}p_{obs}$；也可在损失层施加。

## 三、数学形式

校正预测 $p_{true} = T^{-1} p_{obs}$；或用 $\mathcal L_{corr} = \mathcal L(T^\top p_\theta)$。

## 四、代码实现

```python
p_true = torch.inverse(T) @ p_obs
loss = cross_entropy(p_true, y_true)
```

## 五、与其他对比

- 与 置信学习深入（估 T）共享转移矩阵。
- 与 噪声鲁棒损失深入（免估 T）对照。

## 六、常见误区

- T 估计误差被逆矩阵放大。
- 不可逆 T 致校正失败。
