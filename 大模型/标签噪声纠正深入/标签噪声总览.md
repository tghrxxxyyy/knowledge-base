# 标签噪声纠正总览

> 对应 Frénay & Verleysen, 《Classification with Label Noise》, 2014 综述。

## 一、背景与挑战

真实标注常含错标（人工疏漏、众包、合成数据幻觉），直接训练损害泛化。

## 二、核心原理

分为：鲁棒损失、样本选择（挑干净样本）、损失校正（建模噪声转移）、置信学习四类。

## 三、数学形式

噪声转移 $T_{ij}=P(\tilde y=j|y=i)$；观测分布 $P(\tilde y)=T^\top P(y)$。

## 四、代码实现

```python
probs = model(x)
loss = robust_loss(probs, noisy_y)        # 而非普通交叉熵
```

## 五、与其他对比

- 与 合成数据生成深入（合成也带噪）衔接。
- 与 标签噪声在LLM数据深入 共享。

## 六、常见误区

- 以为大样本下噪声无害（仍偏）。
- 直接删低置信样本可能丢难样本。

## 八、面试题

- 标签噪声为何有害？答：错标提供错误监督，使决策边界偏移、泛化下降。

## 九、演进

清洗数据 → 鲁棒损失 → 损失校正/置信学习。

## 十、小结

标签噪声普遍，需从损失、选择到校正多层次应对。
