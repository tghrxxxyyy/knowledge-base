# 图检索查询与全局局部搜索

> 对应 microsoft/graphrag 开源仓库与 run-llama/llama_index 图谱检索。

## 一、背景与挑战
GraphRAG 支持两类查询：局部搜索针对具体实体/事实，沿图邻居取证据；全局搜索针对整体趋势，聚合社区摘要。二者检索路径不同。

## 二、核心原理
局部搜索：给定实体，取 k 跳邻域子图与相连文本块，喂给 LLM 作答。全局搜索：把社区摘要分块，逐块 map 出部分答案，再 reduce 汇总，适合无明确实体的宏观问题。

## 三、形式化与数学基础
局部邻域：$N_k(v) = \{u \mid \text{dist}_G(v,u) \le k\}$。全局聚合：
$A = \text{reduce}\left(\{ \text{map}(S_{C_i}) \mid C_i \in C \}\right)$
map 对各社区摘要生成带证据的部分答，reduce 综合去重。

## 四、代码实现
```python
def local_search(graph, v, llm, k=2):
    sub = k_hop_subgraph(graph, v, k)
    return llm.answer(neighborhood_text(sub))
def global_search(comms, llm):
    parts = [llm.map(comm) for comm in comms]
    return llm.reduce(parts)
```

## 五、与其他技术对比
相比向量块检索只取相似文本，图检索能沿关系跳转（多跳），利于复杂推理；但局部搜索依赖实体识别准确，全局搜索依赖社区摘要质量。

## 六、常见误区
误区一：所有问题都用全局搜索，简单事实类问题用局部更快更准。误区二：忽略 k 跳范围，过大邻域引入噪声。

## 七、与开源书/权威来源对应
- microsoft/graphrag 定义 local/global 查询模式。
- run-llama/llama_index 提供 KnowledgeGraphIndex。
- facebookresearch/faiss 可用于图谱节点的向量辅助。

## 九、演进与趋势
混合检索：先图定位实体再向量取细粒度块，形成「图路由 + 向量精读」。

## 十、小结
图检索以局部与全局双模式覆盖事实与洞察，是 GraphRAG 落地的关键接口。
