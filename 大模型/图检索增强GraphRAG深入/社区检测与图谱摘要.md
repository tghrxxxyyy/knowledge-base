# 社区检测与图谱摘要

> 对应 microsoft/graphrag 开源仓库（Leiden 社区检测 + 分层摘要）。

## 一、背景与挑战
图规模大时难以整体理解。社区检测把图划分为语义内聚的子群，对每个子群生成自然语言摘要，作为全局检索的「索引节点」。

## 二、核心原理
用 Leiden 算法在实体图上做模块度最大化的社区划分，得到层次化社区。自底向上对每个社区用 LLM 生成摘要，形成「社区-摘要」树，便于 map-reduce 式全局问答。

## 三、形式化与数学基础
模块度目标：
$Q = \frac{1}{2m}\sum_{ij}\left(A_{ij}-\frac{k_i k_j}{2m}\right)\delta(c_i,c_j)$
其中 A 为邻接矩阵，$k_i$ 为度，c 为社区标签。摘要则对各社区节点与边文本做 LLM 归约。

## 四、代码实现
```python
from networkx.algorithms.community import louvain_communities
def community_summaries(graph, llm):
    comms = louvain_communities(graph, weight="weight")
    return {i: llm.summarize(nodes_of(c)) for i, c in enumerate(comms)}
```

## 五、与其他技术对比
相比平铺的块摘要，社区摘要保留结构内聚性，更适合「主题/趋势」类问题；但摘要本身可能遗漏细节，需与局部检索配合。

## 六、常见误区
误区一：社区数越多越好，过多社区使全局答案碎片化。误区二：只看顶层摘要，忽略下层细节导致空泛。

## 九、演进与趋势

社区检测与摘要把图压缩为可检索的结构化知识，是 GraphRAG 全局能力的核心。
