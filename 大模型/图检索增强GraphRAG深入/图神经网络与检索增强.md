# 图神经网络与检索增强

> 对应 huggingface/transformers 表征能力与 microsoft/graphrag 图结构思路。

## 一、背景与挑战
图谱中的实体关系蕴含结构信号，纯文本检索难以利用。图神经网络（GNN）可把结构信息编码进节点向量，提升检索与排名。

## 二、核心原理
对实体图跑 GNN（如 GCN/GAT），节点表征聚合邻居信息，得到结构感知嵌入。该嵌入可与文本嵌入拼接，用于向量检索或作为重排特征，使「结构邻近」成为相关性信号。

## 三、形式化与数学基础
单层图卷积：
$h_i^{(l+1)} = \sigma\left(\sum_{j \in \mathcal{N}(i)} \frac{1}{\sqrt{d_i d_j}} W^{(l)} h_j^{(l)}\right)$
其中 $\mathcal{N}(i)$ 为邻居，$d_i$ 为度。最终节点向量 $z_i = h_i^{(L)}$ 融合结构与文本。

## 四、代码实现
```python
import torch
def gnn_layer(x, edge_index, w):
    # x: (N, f), edge_index: (2, E)
    src, dst = edge_index
    msg = x[src] @ w
    out = torch.zeros_like(x)
    out.index_add_(0, dst, msg)
    return torch.relu(out)
```

## 五、与其他技术对比
相比仅用词/句嵌入，GNN 表征含拓扑，利于同义实体聚类与关系推理；但需图质量高，且训练 GNN 增加复杂度，常与预训练文本向量结合而非替代。

## 六、常见误区
误区一：GNN 自动修复噪声图，实则噪声会随聚合扩散。误区二：层数越深越好，过深导致过平滑（所有节点向量趋同）。

## 七、与开源书/权威来源对应
- huggingface/transformers 提供图相关模型生态。
- microsoft/graphrag 强调图结构价值。
- run-llama/llama_index 支持图索引。

## 九、演进与趋势
与大模型结合：用 LLM 生成节点初始特征，GNN 做结构精炼，再用向量库检索，形成图-向量联合索引。

## 十、小结
GNN 把图结构转化为可检索的连续信号，是图谱检索增强的有力补充。
