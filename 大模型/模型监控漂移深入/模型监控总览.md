# 模型监控总览

> 对应 llm-course 与 MLOps 实践；模型上线后需持续看护。

## 一、背景与挑战

模型上线后数据分布/用户行为会变，性能悄悄退化，需监控。

## 二、核心原理

监控三件套：**数据漂移**（输入分布变）、**概念漂移**（输入-输出关系变）、**性能衰减**（指标降）。结合告警与反馈闭环回流数据再训练。

## 三、关键要点

- 漂移不等于坏，但需预警。
- 需业务指标联动（非仅统计）。

## 四、代码实现

```python
psi = compute_psi(ref_dist, cur_dist)   # 群体稳定性指数
if psi > 0.2: alert()
```

## 五、与其他对比

| 漂移 | 含义 |
|------|------|
| 数据 | 输入变 |
| 概念 | 关系变 |

## 六、常见误区

- 训练好即一劳永逸——会退化。

## 七、与开源书对应

## 九、演进
