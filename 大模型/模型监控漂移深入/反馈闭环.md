# 反馈闭环

> 见「模型监控深入/模型监控总览」与「持续学习深入」；监控后要行动。

## 一、背景与挑战

监控发现问题，不回流等于白监控。

## 二、核心原理

闭环：监控告警 → 标注/收集难样本 → 触发再训练/微调/数据更新 → 评估上线。大模型可用用户反馈（点踩/修正）做 SFT/对齐更新，形成「数据飞轮」。

## 三、关键要点

- 闭环需自动化管道。
- 重训需防回归。

## 四、代码实现

```python
if drift: data = collect_hard(); retrain(model, data)
```

## 五、与其他对比

- 开环只看；闭环行动。

## 六、常见误区

- 监控不处置——无效。
