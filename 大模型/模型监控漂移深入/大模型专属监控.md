# 大模型专属监控

> 见「模型监控深入/模型监控总览」与「幻觉与缓解深入」；LLM 特有风险。

## 一、背景与挑战

LLM 输出自由文本，传统指标（准确率）难直接套。

## 二、核心原理

专项监控：幻觉率（事实不符）、毒性/安全率、拒答率、指令遵循率、输出长度分布、重复/退化（如 "..." 循环）、提示注入未遂。用 LLM-as-judge 或分类器批量打分采样输出。

## 三、关键要点

- 需采样评测（非全量）。
- 安全指标是红线。

## 四、代码实现

```python
sample = sample_outputs(traffic, k=1000)
halluc_rate = judge_halluc(sample)
```

## 五、与其他对比

- 传统看数值；LLM 看语义质量。
