# 概念漂移检测

> 见「模型监控深入/模型监控总览」与「数据漂移检测」；关系变化。

## 一、背景与挑战

输入分布没变，但「输入→输出」的映射变了（如政策改了标准）。

## 二、核心原理

概念漂移需看**性能**或**条件分布**变化：监控线上准确率/打分分布；用「延迟标签」对比历史；或训练漂移检测器（预测某样本分布来自新/旧机制）。大模型场景如用户偏好迁移。

## 三、关键要点

- 需标签或代理指标。
- 比数据漂移更难发现。

## 四、代码实现

```python
if online_acc < baseline - delta: flag_concept_drift()
```

## 五、与其他对比

- 数据漂移看 X；概念漂移看 X→Y。
