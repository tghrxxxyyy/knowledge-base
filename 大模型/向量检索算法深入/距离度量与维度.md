# 距离度量与维度灾难

> 对应嵌入相似度与高维检索；嵌入几何深入 衔接。

## 一、背景与挑战

不同度量（内积/余弦/L2）影响检索语义；高维下距离区分度下降。

## 二、核心原理

归一化后用内积≈余弦；高维下所有点距离趋近，需靠质量嵌入+近似索引缓解。

## 三、数学形式

余弦 $\cos(q,d)=\frac{q\cdot d}{\|q\|\|d\|}$；内积 $q\cdot d$（需归一化对齐）。

## 四、代码实现

```python
q = q/norm(q); d = d/norm(d)
sim = q @ d.T
```

## 五、与其他对比

- 与 嵌入几何深入（方向/范数语义）共享。
- 与 词嵌入与表示学习（目录）衔接。

## 六、常见误区

- 未归一化混用内积/余弦致排序偏。
- 忽视高维距离塌缩对召回影响。
