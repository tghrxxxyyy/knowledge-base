# 向量检索算法总览

> 对应 ANN 综述（Wang et al., 2021）；与 向量数据库选型与调优实战（文件）衔接。

## 一、背景与挑战

亿级向量精确最近邻（Exact NN）太慢；近似最近邻（ANN）在精度/速度间权衡。

## 二、核心原理

主流：IVF（倒排聚类）、PQ（乘积量化压缩）、HNSW（图）、LSH（哈希）。常组合（IVF+PQ）。

## 三、数学形式

查询 $q$ 找 $k$ 个近邻：$\arg\min_{i} \|q-x_i\|$；ANN 允许近似误差 $\epsilon$。

## 四、代码实现

```python
import faiss
index = faiss.index_factory(d, "IVF1024,PQ64")
index.search(q, k=10)
```

## 五、与其他对比

- HNSW 快但内存大；IVF+PQ 省内存但略慢。
- 与 混合检索深入（向量召回侧）衔接。

## 六、常见误区

- 维度高时 LSH 效果差；图/量化更稳。
- 索引未训练致召回崩。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- ANN 为何近似可接受？答：嵌入空间近邻稠密，小误差不影响 top-k 质量。

## 九、演进

暴力 → LSH → IVF → HNSW/PQ → 混合索引。

## 十、小结

向量检索算法以近似换速度，IVF/PQ/HNSW 是 RAG 召回底座。
