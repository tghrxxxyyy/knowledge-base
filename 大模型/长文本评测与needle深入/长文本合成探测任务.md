# 长文本合成探测任务

> 对应长上下文合成评测（synthetic probing）任务设计，如 RULER 中的聚合与多跳追踪。

## 一、背景与挑战

真实长文档评测贵且 noisy。合成探测用可控生成的长文本隔离具体能力（检索、计数、排序、多跳），便于诊断。

## 二、核心原理

任务族：needle 检索、多 needle 聚合（如求和）、变量追踪、多跳推理。长度可程序化缩放，标签确定可验证。

## 三、数学形式

聚合探测（求和）：

$$
\hat{s}=\sum_{i=1}^{k}v_i,\quad \mathrm{Acc}=\mathbf{1}[\hat{s}=s^*]
$$

多跳准确率：

$$
M=\mathbf{1}[\mathrm{path}(x)=\mathrm{path}^*]
$$

## 四、代码实现

```python
def aggregate(needles):
    return sum(v for _,v in needles)

print(aggregate([("a",3),("b",7),("c",1)]))
```

## 五、与其他对比

相比真实文档 QA，合成任务可控、标签干净；相比单 needle，多任务覆盖更广能力。

## 六、常见误区

误区一：合成即简单（多跳/聚合可很难）。误区二：忽略分布偏移到真实文本。误区三：仅用检索任务。

## 八、面试题

- Q：合成探测优势？答：可控长度、干净标签、可隔离能力。
- Q：常见合成任务？答：检索、聚合、变量追踪、多跳。

## 九、演进

合成探测从检索扩展到推理型任务，成为长上下文诊断主力。

## 十、小结

合成探测以可控与可验证，把长文本能力拆解为可诊断的子技能。
