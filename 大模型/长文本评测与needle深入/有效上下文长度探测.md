# 有效上下文长度探测

> 对应 Hsieh et al. 2024 RULER 中 effective context length 的探测方法论。

## 一、背景与挑战

厂商标称上下文长度（如 200k）常以空注意力或检索式近似达成，真实"可用"长度常更短。需系统探测而非看标称。

## 二、核心原理

在递增长度上跑多任务，定义分数降至阈值的长度为有效长度。还需区分"能放入"与"能利用"：后者需任务驱动探测。

## 三、数学形式

线性插值有效长度：

$$
L_{\mathrm{eff}}=L_i+\frac{\tau-S_i}{S_{i+1}-S_i}(L_{i+1}-L_i)
$$

利用比：

$$
U=\frac{L_{\mathrm{eff}}}{L_{\mathrm{claim}}}
$$

## 四、代码实现

```python
def interp_eff(L, S, tau=0.5):
    for i in range(len(L)-1):
        if S[i]>=tau>=S[i+1]:
            return L[i]+(tau-S[i])/(S[i+1]-S[i])*(L[i+1]-L[i])
    return L[-1]

print(round(interp_eff([4,32,128,200],[0.95,0.8,0.55,0.3]),1))
```

## 五、与其他对比

相比标称长度，有效长度更诚实；相比单 needle，多任务探测更稳健。

## 六、常见误区

误区一：标称即有效。误区二：单点探测定上限。误区三：忽略任务类型差异。

## 八、面试题

- Q：为何标称长度≠有效长度？答：可能仅能放入而无法真正利用。
- Q：有效长度如何定？答：多任务得分跌至阈值对应的长度。

## 九、演进

有效长度成为模型卡必报指标，促成长上下文训练目标对齐。

## 十、小结

有效上下文长度探测把"能放多少"转化为"能用多少"，是长文本评测核心度量。
