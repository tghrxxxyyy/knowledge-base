# 多任务混合与目标冲突

> 对应 multitask learning 与 LLM 多任务预训练/微调研究。

## 一、背景与挑战

多任务混合训练时，任务梯度可能相互冲突(余弦相似度为负)，导致某些任务被压制或遗忘。需理解并缓解冲突。

## 二、核心原理

任务 $i$ 梯度 $g_i$，冲突用梯度夹角衡量。负夹角表示更新方向相反。混合权重直接影响各任务对学习信号的主导权。

## 三、数学形式

任务间冲突：

$$
\cos(g_i,g_j) = \frac{g_i\cdot g_j}{\|g_i\|\|g_j\|}
$$

若为负需干预。多任务损失：

$$
\mathcal{L} = \sum_i w_i \mathcal{L}_i
$$

梯度为 $\sum_i w_i g_i$，权重决定主导任务。

## 四、代码实现

```python
import torch

def grad_cos(g1, g2):
    g1 = torch.cat([p.flatten() for p in g1])
    g2 = torch.cat([p.flatten() for p in g2])
    return torch.nn.functional.cosine_similarity(g1, g2, 0).item()
```

## 五、与其他对比

与单任务配比不同，多任务须处理梯度级冲突，而非仅样本分布。

## 六、常见误区

误区：均匀权重最公平。实际任务梯度量级与方向差异巨大，需归一化或 PCGrad。

## 八、面试题

- Q：多任务冲突怎么发现？答：算任务梯度余弦，负则冲突。
- Q：缓解方法？答：PCGrad 投影、梯度归一、动态权重。

## 九、演进

从固定权重到梯度 surgery(PCGrad)、到任务自适应权重退火。

## 十、小结

多任务混合的核心是管理梯度冲突，权重退火是调控手段之一。
