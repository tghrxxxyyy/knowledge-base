# 采样权重温度退火

> 对应 大模型多任务混合训练中的数据采样温度调度研究。

## 一、背景与挑战

直接用 softmax 对任务对数权重采样，温度 $T$ 控制分布的“陡峭度”。固定温度可能早期被单一任务主导，需退火调节。

## 二、核心原理

温度高时分布趋均匀(探索多任务)，温度低时趋尖锐(聚焦少数任务)。训练早期用高温保多样性，后期降温强化关键任务。

## 三、数学形式

任务对数权重 $a_i$，采样概率：

$$
P(i) = \frac{\exp(a_i/T)}{\sum_j \exp(a_j/T)}
$$

退火：$T(t)$ 从 $T_0$ 降到 $T_f$：

$$
T(t) = T_f + (T_0-T_f)e^{-t/\tau}
$$

## 四、代码实现

```python
import torch, math

def sample_weights(logw, T):
    return torch.softmax(torch.tensor(logw)/T, 0)

def anneal_T(t, T0, Tf, tau):
    return Tf + (T0 - Tf) * math.exp(-t / tau)
```

## 五、与其他对比

温度退火调节“分布形状”，与直接改权重 $a_i$ 互补；前者平滑、后者绝对。

## 六、常见误区

误区：低温一定好。过低导致灾难性遗忘其他任务。

## 八、面试题

- Q：温度在采样中作用？答：控制任务分布陡峭度，高均匀低聚焦。
- Q：退火方向？答：早期高温保多样，后期降温聚焦。

## 九、演进

从指数退火到基于任务损失的动态温度(难任务温度更高)。

## 十、小结

温度退火是多任务混合的柔性调控旋钮，平衡多样性与聚焦。
