# 课程式任务混合

> 对应 课程学习思想在多任务训练中的迁移。

## 一、背景与挑战

多任务同时开训易导致难任务拖累易任务。课程式混合按任务难度先后引入，先易后难稳定训练。

## 二、核心原理

先训练“简单/基础”任务建立共享表征，再逐步引入复杂任务，避免早期梯度被难任务破坏。

## 三、数学形式

任务引入阈值 $\lambda(t)$ 递增，任务 $i$ 参与条件：

$$
\mathbb{1}[D_i \le \lambda(t)]
$$

有效损失：

$$
\mathcal{L}(t) = \sum_{i: D_i\le\lambda(t)} w_i \mathcal{L}_i
$$

## 四、代码实现

```python
def active_tasks(difficulties, lam):
    return [i for i, d in enumerate(difficulties) if d <= lam]
```

## 五、与其他对比

与温度退火不同，课程式是“硬开关”引入任务，退火是“软调权”。

## 六、常见误区

误区：难任务越晚引入越好。过晚导致训练末期任务过多难收敛。

- Q：课程式任务混合好处？答：先建基础表征，稳定难任务学习。
- Q：与退火区别？答：硬引入 vs 软调权。

## 十、小结

课程式混合用“分阶段引入”化解多任务早期冲突。
