# 比例调度策略

> 对应 数据混合比例随训练演化的调度研究。

## 一、背景与挑战

任务/领域最优比例并非恒定，随训练阶段变化。固定比例错过阶段性重点，需设计调度曲线。

## 二、核心原理

常见调度：阶梯式(阶段性切换)、线性(平滑过渡)、反课程(先难后易)、课程(先易后难)。选择取决于任务成熟度。

## 三、数学形式

线性调度下任务 $i$ 比例：

$$
q_i(t) = q_i^{start} + (q_i^{end}-q_i^{start})\frac{t}{T}
$$

阶梯式在断点 $t_k$ 切换：

$$
q_i(t) = q_i^{(k)} \quad t\in[t_k,t_{k+1})
$$

## 四、代码实现

```python
def linear_ratio(start, end, t, T):
    return start + (end - start) * t / T

def step_ratio(breaks, values, t):
    for b, v in zip(breaks, values):
        if t >= b:
            return v
    return values[0]
```

## 五、与其他对比

调度是“时间维配比”，与“内容维配比”正交，可叠加。

## 六、常见误区

误区：频繁切换比例。抖动会破坏训练稳定性，宜平滑或少量断点。

## 八、面试题

- Q：比例调度有哪几种？答：线性、阶梯、课程、反课程。
- Q：为何要调度？答：不同阶段任务成熟度不同，需不同重点。

## 十、小结

比例调度把静态配比变为动态过程，贴合训练动力学。
