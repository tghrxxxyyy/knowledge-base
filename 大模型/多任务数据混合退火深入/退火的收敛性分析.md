# 退火的收敛性分析

> 对应 模拟退火与学习率/权重退火的收敛理论。

## 一、背景与挑战

退火(温度、权重、比例)能否保证收敛，依赖退火速率。过快或过慢都影响最终解质量。

## 二、核心原理

类比模拟退火：温度需以特定速率下降才能保证渐近收敛到全局最优。训练中的权重退火也需匹配优化器动态。

## 三、数学形式

对数冷却 schedule：

$$
T(t) = \frac{T_0}{\log(1+t)}
$$

保证收敛的经典条件：$\sum_t \alpha_t=\infty,\ \sum_t \alpha_t^2<\infty$，且退火速率慢于学习率衰减。

## 四、代码实现

```python
import math

def log_cool(T0, t):
    return T0 / math.log(1 + t + 1e-8)
```

## 五、与其他对比

训练退火比物理退火更宽容，因有 SGD 噪声与早停兜底，无需严格对数冷却。

## 六、常见误区

误区：退火越快越好。过快相当于硬切换，丧失平滑过渡收益。
