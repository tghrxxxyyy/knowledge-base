# 工程实现与稳定性

> 对应 大规模多任务训练数据采样工程实践。

## 一、背景与挑战

多任务混合退火需在分布式训练下精确控制每步采样比例，且不能因调度引入额外通信开销或抖动。

## 二、核心原理

用全局步数 $t$ 推导各任务采样概率，在数据加载器层做加权采样(WeightedRandomSampler)或分桶交替，保证每步比例近似目标。

## 三、数学形式

目标比例 $q_i(t)$，每步采样 $B$ 个样本，任务 $i$ 数量：

$$
b_i(t) = \mathrm{round}(B \cdot q_i(t))
$$

满足 $\sum_i b_i(t)=B$。用缓冲池平滑跨步波动。

## 四、代码实现

```python
import torch

def per_task_count(q, B):
    counts = (torch.tensor(q) * B).round().long()
    diff = B - counts.sum().item()
    counts[0] += diff
    return counts
```

## 五、与其他对比

采样器层实现比训练时动态拼 batch 更简单稳定，且易复现。

## 六、常见误区

误区：每步严格按比例。微小抖动可接受，过度精确反而增加开销。

## 八、面试题

- Q：分布式下如何控比例？答：全局步数推导目标，加载器加权采样。
- Q：稳定性要点？答：缓冲池平滑、避免每步硬精确。

## 九、演进

从单机采样器到跨节点一致性采样与弹性比例。

## 十、小结

工程上用加权采样器+缓冲池即可稳定落地多任务混合退火。
