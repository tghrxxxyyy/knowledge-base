# 对比学习总览

> 对应 van den Oord et al., *Contrastive Predictive Coding (CPC)*, 2018；Chen et al., *SimCLR*, 2020。视觉语言对齐常以对比学习为底座。

## 一、背景与挑战

视觉与语言分属异质模态，直接回归对齐困难；对比学习把“配对样本拉近、非配对推远”，避免逐像素/逐词重建，更适合海量弱监督图文对。

## 二、核心原理

给定图文对 (v, t)，用视觉编码器与文本编码器分别得到表示，在嵌入空间做对比：正样本对（同图文本或同一对）相似度高，负样本（batch 内其他图/文）相似度低。训练信号来自“哪条是正配对”的判别。

## 三、数学形式

InfoNCE 损失把对比转化为分类：

$$\mathcal L = -\log\frac{\exp(s(v,t^+)/\tau)}{\sum_{k=1}^K\exp(s(v,t_k)/\tau)}$$

其中 $s$ 为相似度（常取余弦），$t^+$ 为正文本，$K$ 含 1 正 + $K-1$ 负，$\tau$ 为温度。

## 四、代码实现

```python
# 简化 CLIP 风格对比
logits = (v @ t.T) / tau            # [B, B]
labels = torch.arange(B)
loss = F.cross_entropy(logits, labels)
```

## 五、与其他对比

- 与 图文检索与CLIP训练深入 共享对比范式，本篇偏理论。
- 与 自监督视觉（SimCLR）同源，区别在跨模态正样本构造。

## 六、常见误区

- 把“负样本”误当作无关图文，忽视 batch 内隐含难负例。
- 温度 $\tau$ 设置过小致梯度集中于少数难对。

## 八、面试题

- 为何用对比而非重建？答：重建需建模像素分布过难，对比只需区分正负配对，信号更稠密。

## 九、演进

度量学习 → InfoNCE → SimCLR/CLIP 跨模态 → 层次化对比。

## 十、小结

对比学习以“判别正配对”为目标，是视觉语言对齐最通用的训练范式。
