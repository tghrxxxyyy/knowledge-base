# 负样本构造策略

> 对应 Chen et al., *SimCLR*, 2020（batch 内负样本）；Kalantidis et al., *momentum contrast*, 2020。

## 一、背景与挑战

负样本质量决定对比上限：太易则无梯度，太难则噪声大；构造策略直接影响对齐质量。

## 二、核心原理

常见策略：(1) In-batch negatives（同 batch 其他样本作负）；(2) Memory bank / queue 扩充负样本；（3）难负例挖掘（语义相近但非配对）；（4）去重避免假负例（false negative）。

## 三、数学形式

带难负例加权的损失：

$$\mathcal L = -\log\frac{\exp(s^+/\tau)}{\exp(s^+/\tau) + \sum_j w_j\exp(s_j^-/\tau)}$$

其中 $w_j$ 为难例权重，需防假负例（同语义却被判负）。

## 四、代码实现

# 去重假负例：排除与正样本同类的索引

logits = (v @ t.T) / tau * mask

## 六、常见误区

- 假负例（同一实体不同图）被当负例，拉低表征质量。
- 负样本数过小致训练不稳定。

## 八、面试题

- 为何要难负例？答：易负例区分度低无梯度，难负例提供有效信号，但需防假负例。

## 九、演进

batch 内 → memory bank → 难负例挖掘 → 去假负例。

## 十、小结

负样本构造是对比训练的工程核心，平衡难例与假负例是关键。
