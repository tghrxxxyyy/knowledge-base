# 对齐评估指标

> 对应 Wang & Isola, 2020（alignment & uniformity）；多模态检索/零样本评测。

## 一、背景与挑战

对比训练损失下降不等于对齐好，需独立指标衡量跨模态一致性与下游迁移。

## 二、核心原理

常用：检索 Recall@k（图文互检）、零样本分类准确率、对齐性（正对距离）、均匀性（特征分布）、线性探针。多指标联合判断过拟合。

## 三、数学形式

对齐性与均匀性：

$$\text{align}=\mathbb E_{(v,t)}\|z_v-z_t\|^2,\quad \text{unif}=\log\mathbb E_{z\sim p}\ e^{-2\|z\|}$$

二者越低越好（理想分布）。

## 四、代码实现

```python
recall = recall_at_k(sim_matrix, k=5)
align = ((zv - zt)**2).mean()
unif = torch.log((torch.exp(-2*zt.norm(dim=-1))).mean())
```

## 五、与其他对比

- 与 图文检索与CLIP训练深入 共享检索指标。
- 与 跨模态生成扩散深入 对照“理解 vs 生成”评测。

## 六、常见误区

- 只看训练损失忽略均匀性塌缩。
- 仅看零样本忽略检索泛化。

## 八、面试题

- 为何看均匀性？答：均匀性塌缩表示退化，所有样本挤一点，泛化差。

## 九、演进

损失 → 对齐/均匀 → 下游探针 → 综合榜单。

## 十、小结

对齐评估需多指标联合，对齐性与均匀性是核心诊断工具。
