# 投影头与对齐空间

> 对应 Chen et al., 2020（投影头 projection head）；视觉语言对齐的表示几何。

## 一、背景与挑战

对比损失作用于“投影空间”而非原始编码器输出；投影头设计与对齐空间结构直接影响下游迁移。

## 二、核心原理

编码器输出经 MLP 投影头映射到对比空间做损失；推理时可丢弃投影头用主干表示。多模态常各自投影到共享空间后对比。

## 三、数学形式

设编码器 $f,g$ 输出 $h_v,h_t$，投影头 $p,q$：

$$z_v = p(h_v),\quad z_t = q(h_t),\quad \mathcal L = \text{Contrast}(z_v, z_t)$$

对齐质量可用 $z_v,z_t$ 夹角分布衡量。

## 四、代码实现

```python
zv = proj_v(encoder_v(v))     # 投影到共享维度
zt = proj_t(encoder_t(t))
loss = contrast(zv, zt)
```

## 五、与其他对比

- 与 视觉语言对齐对比学习深入 总览配合。
- 与 对齐评估指标 看投影空间线性可分性。

## 六、常见误区

- 在投影空间训练却直接用其做检索，应区分“对比空间”与“表征空间”。
- 投影头过深致编码器欠训。

- 为何要投影头？答：解耦对比目标与表征目标，投影空间更易优化，主干保留通用性。
