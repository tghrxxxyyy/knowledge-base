# 稀疏注意力的模式

> 对应 Child et al., *Sparse Transformer*, 2019；Beltagy et al., *Longformer*, 2020。

## 一、背景与挑战

长序列下全注意力 $O(n^2)$ 不可行；稀疏/结构化注意力形成固定模式（局部窗口、跨步、全局令牌）。

## 二、核心原理

稀疏模式限制每个 query 只关注子集（局部窗口 + 跨步 + 少量全局 token），在保持长程能力的同时降复杂度。这些模式本身是可解释的结构先验。

## 三、数学形式

局部窗口注意力复杂度 $O(n \cdot w)$；结合跨步使感受野随层指数扩张，近似覆盖全局。

## 四、代码实现

```python
def sliding_window_mask(n, w):
    m = torch.zeros(n, n)
    for i in range(n):
        m[i, max(0,i-w):i+1] = 1
    return m.bool()
```

## 六、常见误区

- 以为稀疏一定无损；跨步/窗口漏掉关键长程依赖会掉点。
- 全局 token 选取不当成信息瓶颈。

## 八、面试题

- 稀疏注意力如何降本？答：限制每 query 关注子集，把 $O(n^2)$ 降到 $O(nw)$ 或 $O(n\log n)$。

## 九、演进

全注意力 → 局部窗口 → 局部+跨步+全局（Longformer/BigBird）。

## 十、小结

稀疏注意力以结构化模式换效率，其模式本身是可解释先验。
