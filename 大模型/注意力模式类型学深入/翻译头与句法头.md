# 翻译头与句法头

> 对应 Clark et al., *What Does BERT Look At?*, 2019；Tenney et al., *BERT Rediscovers the Classical NLP Pipeline*, 2019。

## 一、背景与挑战

多语模型中存在跨语言翻译头；句法头则关注主谓/依存关系。二者揭示注意力对语言结构的编码。

## 二、核心原理

在翻译模型中，部分头系统性把源语 token 对齐到目标语对应词；句法头关注依存中心或相邻句法成分，可用探针验证。

## 三、数学形式

对齐头使 $A_{ij}$ 在平行句对上逼近真对齐分布 $P_{align}(i,j)$；句法头使 $A$ 近似依存树邻接。

## 四、代码实现

```python
def syntax_probe(attn, dep_heads, parse):
    heads = attn[:, dep_heads].mean(1)
    pred = heads.argmax(-1)  # 预测依存父节点
    return (pred == parse.head).float().mean()
```

## 五、与其他对比

- 与 层级表征语义结构深入（探针）共享线性探针方法。
- 与 稀疏自编码器特征深入 对照：头是粗粒度，SAE 可更细。

## 六、常见误区

- 把注意力图直接当句法树；实际只是弱相关，需探针量化。
- 认为所有头都有明确句法角色。

## 八、面试题

- 注意力图等于句法树吗？答：仅弱相关，需用探针/对齐分数量化，不能等同。

## 九、演进

可视化猜测 → 探针量化 → 头功能因果定位。

## 十、小结

翻译头与句法头显示注意力对语言结构的编码，但需量化而非肉眼判断。
