# 注意力模式类型学总览

> 对应 Olsson et al., *In-Context Learning and Induction Heads*, 2022；Elhage et al., *A Mathematical Framework for Transformer Circuits*, 2021。

## 一、背景与挑战

Transformer 的注意力头并非均质单元；不同头承担可辨识的离散功能（复制、前一词、归纳、翻译、句法）。把头按功能分类，是机制可解释性的起点。

## 二、核心原理

通过掩码/消融单个头并观察行为变化，可将头归入功能类型；归纳头（induction heads）是最早被发现并充分研究的类型，其余类型需结合任务探针识别。

## 三、数学形式

归纳头近似实现复制-粘贴：对位置 $t$ 关注前一个出现 $x_t$ 的副本位置 $p$，复制其后 token，即 $a_t \approx x_{p+1}$。

## 四、代码实现

```python
def induction_score(attn, seq):
    # 统计关注"重复前一词之后"位置的头比例
    same = (seq[:-2] == seq[1:]).float()
    return (attn[:-1].argmax(-1) == same.nonzero()).float().mean()
```

## 五、与其他对比

- 与 稀疏自编码器特征深入 对照：头是粗粒度电路单元，SAE 特征更细。
- 与 回路可解释性实证深入 共享"定位功能单元"范式。

## 六、常见误区

- 认为每个头单义；实际多数头多义、需组合才显功能。
- 把注意力权重直接当因果，忽略残差流叠加效应。

## 八、面试题

- 什么是归纳头？答：在序列重复处关注首个副本之后位置、复制下一 token，是实现少样本 ICL 的关键电路。

## 九、演进

注意力可视化（Vig 2019） → 头功能分类（Clark 2019） → 归纳头与 ICL 因果证明（Olsson 2022）。

## 十、小结

注意力模式类型学把"黑箱头"拆为可命名功能单元，是机制可解释性的地基。
