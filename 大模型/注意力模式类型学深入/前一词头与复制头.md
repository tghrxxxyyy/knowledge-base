# 前一词头与复制头

> 对应 Elhage et al., *Transformer Circuits*, 2021；Voita et al., *Analyzing Multi-Head Self-Attention*, 2019。

## 一、背景与挑战

除归纳头外，模型依赖更基础的前一词（previous-token）头与复制头来维持局部结构与复制输入。

## 二、核心原理

前一词头几乎总是关注位置 $t-1$，把前一 token 信息搬入当前残差；复制头把输入某处内容直接复现到输出（如复制实体名）。二者是更高层电路的构件。

## 三、数学形式

前一词头近似恒等搬运：$a_t \approx x_{t-1}$，其注意力近似 one-hot 在 $t-1$。

## 四、代码实现

```python
prev_ratio = (attn.diagonal(offset=-1).argmax(-1) == arange()).float().mean()
print("previous-token head ratio:", prev_ratio.item())
```

## 五、与其他对比

- 与 归纳头与上下文学习 互补：前一词头是"搬运工"，归纳头是"匹配器"。
- 与 回路可解释性实证深入 共享头分类方法。

## 六、常见误区

- 混淆前一词头与归纳头；前者固定看 $t-1$，后者看重复副本之后。
- 忽视其在生成（自回归）中的基础作用。
