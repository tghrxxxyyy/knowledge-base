# 归纳头与上下文学习

> 对应 Olsson et al., *In-Context Learning and Induction Heads*, 2022。

## 一、背景与挑战

大模型少样本学习（ICL）的能力来源不明；归纳头提供了其机制的因果解释。

## 二、核心原理

归纳头在许多模型中随规模稳定出现，负责"复制上一个相同上下文之后的内容"。在 few-shot 演示中，它把查询前缀匹配到示例，复制示例标签，从而完成 ICL。

## 三、数学形式

对重复模式 $A B A$，归纳头在第二个 $A$ 处关注第一个 $A$ 后位置，输出 $B$，即 $h_t \propto \text{copy}(x_{p^+})$。

## 四、代码实现

```python
def ablation_induction(model, tok, prompt):
    # 消融 top-induction 头后 ICL 准确率
    baseline = evaluate(model, prompt)
    with patch_heads(model, induction_heads, zero=True):
        ablated = evaluate(model, prompt)
    return baseline - ablated
```

## 五、与其他对比

- 与 因果干预与激活修补深入 共享消融/修补方法。
- 与 回路可解释性实证深入（归纳回路）衔接。

## 六、常见误区

- 以为单一头完成 ICL；实际常由多个归纳头与 preceding-token 头协作。
- 小模型无归纳头时 ICL 能力弱。
