# 分布式链路跟踪

> 对应 OpenTelemetry Tracing；与 预填充解码分离深入（跨实例）衔接。

## 一、背景与挑战

请求跨 prefill/decode 实例与多 GPU，需串联 trace 看全貌。

## 二、核心原理

用 trace_id 串联各 span（接收、prefill、KV 传、decode、返回）；采样降开销；展示 waterfall 定位跨实例耗时。

## 三、数学形式

一个 trace 由 span 树组成，每 span 有起止与父指针；总耗时=根 span 跨度。跨度 $D=\sum_i (t_{end,i}-t_{start,i})$ 覆盖关键路径。

## 四、代码实现

```python
with tracer.start_as_current_span("prefill") as sp:
    sp.set_attribute("len", L)
```

## 五、与其他对比

- 与 指标 互补（指标看聚合、链路看个案）；
- 与 弹性推理自动伸缩深入 定位热点实例。

## 六、常见误区

- 全量采样致开销大；
- trace 跨实例丢失 context。
