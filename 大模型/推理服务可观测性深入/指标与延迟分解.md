# 指标与延迟分解

> 对应 LLM 推理指标剖析；与 预填充解码分离深入 衔接。

## 一、背景与挑战

端到端延迟需拆成排队/prefill/decode/KV 传输以定位瓶颈。

## 二、核心原理

埋点记录各阶段时间戳；以直方图记录分布（p50/p95/p99）而非均值；区分队列等待与计算耗时。

## 三、数学形式

$L_{e2e}=L_{queue}+L_{prefill}+L_{decode}+L_{kv}$；$p99$ 反映尾部体验。

## 四、代码实现

```python
hist.observe(L_queue); hist.observe(L_prefill)
```

## 五、与其他对比

- 与 内存高效注意力深入（决定 prefill/decode 耗时）相关；
- 与 树形投机解码深入（影响 TPOT）相关。

## 六、常见误区

- 用均值掩盖长尾；
- 不区分排队与计算致误优化。

## 八、面试题

- 为何看 p99 而非均值？答：尾部延迟决定最差用户体验与 SLO 违约。

## 九、演进

单时延 → 分阶段 → 分布化。

## 十、小结

延迟分解以分位与分阶段定位真实瓶颈。
