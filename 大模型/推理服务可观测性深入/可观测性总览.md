# 推理服务可观测性总览

> 对应 SRE 三大支柱（指标/日志/链路）；与 弹性推理自动伸缩深入 衔接。

## 一、背景与挑战

LLM 服务延迟构成复杂（TTFT/TPOT/排队），需可观测才能调优与排障。

## 二、核心原理

三大支柱：Metrics（时延/吞吐/队列/GPU 利用）、Tracing（请求跨实例链路）、Logging（结构化请求级）。辅以 Profiling。

## 三、数学形式

SLO 指标：$TTFT$、$TPOT=\frac{\text{decode 时长}}{\text{生成 token}}$、吞吐 $=\frac{tokens}{s}$ 与 GPU 利用率。

## 四、代码实现

```python
RECORDED_TTFT.observe(t_start - t_recv)
RECORDED_TPOT.observe(decode_s / n_gen)
```

## 五、与其他对比

- 与 弹性推理自动伸缩深入（指标驱动）闭环；
- 与 预填充解码分离深入（分阶段指标）相关。

## 六、常见误区

- 只监控 QPS 忽略 TPOT/排队；
- 指标维度爆炸致存储贵。
