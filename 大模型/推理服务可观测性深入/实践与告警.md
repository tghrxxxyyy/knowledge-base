# 可观测性实践与告警

> 对应生产告警与 SLO；与 弹性推理自动伸缩深入 / 推理服务可观测性总览 衔接。

## 一、背景与挑战

告警过多致疲劳、过少致事故；需基于 SLO 设有效告警。

## 二、核心原理

按 SLI（TTFT p99、TPOT p99、错误率）设 SLO 与错误预算；多级告警（warn/critical）；与自动伸缩联动。

## 三、数学形式

错误预算消耗率 $B=\frac{\text{违约时长}}{\text{预算}}$；超阈值触发页。

## 四、代码实现

```python
if tp99 > SLO_TPOT: alert.fire("TPOT SLO breach")
```

## 五、与其他对比

- 与 弹性推理自动伸缩深入 联动扩缩；
- 与 树形投机解码深入（保 TPOT）相关。

## 六、常见误区

- 告警无分级致疲劳；
- 仅 CPU 告警忽视 TPOT。
