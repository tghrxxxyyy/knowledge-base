# 开源模型格局

> 对应 llm-course 与 HuggingFace 生态；代表 Llama、Qwen、Mistral、DeepSeek。

## 一、背景与挑战

开源权重降低门槛，形成繁荣生态，但需选对模型。

## 二、核心原理

社区模型覆盖不同尺寸/语言/能力，配 HF Hub、评测榜（OpenCompass/LMSYS）、微调工具链，形成闭环。

## 三、关键要点

- 许可差异大（开源/商用限制）。
- 尺寸适配场景。

## 四、代码实现

```python
from transformers import AutoModelForCausalLM
m = AutoModelForCausalLM.from_pretrained("Qwen/Qwen2.5-7B")
```
