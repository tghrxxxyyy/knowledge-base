# 学习率调度总览

> 对应 优化器章节（d2l）；与 梯度累积深入 / 周期性学习率深入 衔接。

## 一、背景与挑战

固定学习率难兼顾早期稳定与末期收敛；调度（schedule）按训练阶段动态调节。

## 二、核心原理

调度分两阶段语义：warmup（由小到大，稳定开局）与 decay（由大到小，精细收敛）。

## 三、数学形式

$\eta_t = f(t)\cdot\eta_{peak}$；常见 $f$ 为 constant/step/cosine/linear 组合。

## 四、代码实现

```python
sched = torch.optim.lr_scheduler.CosineAnnealingLR(opt, T_max=T)
```

## 五、与其他对比

- 与 周期性学习率深入 是“收敛式”与“循环式”两类哲学。
- 与 梯度累积深入 共同决定有效训练动态。

## 六、常见误区

- 无 warmup 直接大 lr，初期权重破坏。
- 衰减过早，末段欠拟合。

## 八、面试题

- 为何需要调度而非固定 lr？答：早期要稳、末期要细，单一 lr 难兼顾二者。

## 九、演进

固定 → step → cosine → warmup+decay 组合。

## 十、小结

学习率调度以分阶段调节平衡稳定与收敛，是现代训练基石。
