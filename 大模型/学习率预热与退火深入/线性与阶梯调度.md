# 线性与阶梯调度

> 对应 经典调度策略；与 学习率调度总览深入 衔接。

## 一、背景与挑战

不同任务对衰减形状敏感度不同；需理解线性/阶梯的适用场景。

## 二、核心原理

阶梯：在预设里程碑乘固定衰减因子（如 0.1），简单但跳变；线性：随步数线性下降，平滑可控。

## 三、数学形式

阶梯 $\eta_t=\eta_0\gamma^{\lfloor t/m\rfloor}$；线性 $\eta_t=\eta_0(1-t/T)$。

## 四、代码实现

```python
sched = MultiStepLR(opt, milestones=[60,80], gamma=0.1)
```

## 五、与其他对比

- 阶梯易实现但有跳变，可能破坏收敛连续性。
- 与 余弦退火深入 相比缺乏末段平缓。

## 六、常见误区

- 里程碑设错致过早衰减。
- 阶梯跳变引发 Loss 突跳。

## 八、面试题

- 阶梯与线性衰减取舍？答：阶梯实现简单、适合阶段式任务；线性平滑、超参少。

## 九、演进

常数 → 阶梯 → 线性/余弦。

## 十、小结

线性与阶梯是衰减基础形态，按任务对跳变的容忍度选用。
