# 学习率调度调参经验

> 对应 工程实践；与 训练不稳定诊断深入 / 数值稳定性深入 衔接。

## 一、背景与挑战

调度超参（warmup 步数、峰值、最小 lr）需按数据/模型规模调整。

## 二、核心原理

经验：warmup 步数随模型与有效批增大；最小 lr 取峰值的 1/10~1/100；总步数决定曲线形状。

## 三、数学形式

$\eta_{min}\approx \eta_{max}/10$；warmup 比例 $\approx 0.01\sim0.03$ 总步数。

## 四、代码实现

```python
warmup = int(0.03 * total_steps)
min_lr = max_lr / 10
```

## 五、与其他对比

- 与 周期性学习率深入 的区间测试（LR range test）是另一找边界思路。
- 与 批量缩放深入 共同决定峰值。

## 六、常见误区

- 照搬小模型配方到大模型失效。
- 最小 lr 设为 0 致末段停滞。

- 最小 lr 设多少合适？答：常取峰值的 1/10~1/100，保留末段微更新能力。
