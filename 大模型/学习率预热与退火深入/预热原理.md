# 学习率预热原理

> 对应 Goyal et al., 2017（大批量 warmup）；与 训练不稳定诊断深入 衔接。

## 一、背景与挑战

大模型/大批量开局，大学习率易把权重推入坏区域；预热逐步升温保稳定。

## 二、核心原理

前若干步线性（或常数）把 lr 从近 0 升到峰值，待权重/ batch 统计稳定后再进入衰减。

## 三、数学形式

线性预热 $\eta_t = \eta_{max}\cdot\frac{t}{T_{warm}}$（$t\le T_{warm}$）；常数预热则保持 $\eta_{init}$。

## 四、代码实现

```python
sched = LinearWarmup(optimizer, warmup_steps=2000)
```

## 五、与其他对比

- 与 余弦退火深入 常组合为 warmup+cosine。
- 与 梯度累积深入（大有效批）强相关，大有效批更需 warmup。

## 六、常见误区

- warmup 过短仍不稳，过长拖慢进度。
- 仅在 lr 大时才需，小 lr 可省略。

## 八、面试题

- 为何大模型几乎必有 warmup？答：初始权重随机、批量统计不稳，小 lr 开局避免灾难性更新。

## 九、演进

无 → 常数预热 → 线性预热 → 余弦预热。

## 十、小结

预热以渐进升温保护训练初期，是大模型训练标配。
