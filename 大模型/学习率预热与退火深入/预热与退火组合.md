# 预热与退火组合

> 对应 训练配方（warmup + cosine）；与 学习率与批大小缩放深入 衔接。

## 一、背景与挑战

单独 warmup 或衰减都不够；组合配方成为大模型事实标准。

## 二、核心原理

先线性 warmup 到峰值，再 cosine 衰减到最小 lr；峰值常由批大小缩放规则决定。

## 三、数学形式

$\eta_t = \begin{cases}\eta_{max}\frac{t}{T_w}, & t\le T_w \\ \text{cosine}(t), & t>T_w\end{cases}$。

## 四、代码实现

```python
sched = get_cosine_schedule_with_warmup(opt, T_w, T_total)
```

## 五、与其他对比

- 与 周期性学习率深入（带重启）不同，本组合只收敛一次。
- 与 梯度累积深入 通过有效批决定峰值 lr。

## 六、常见误区

- warmup 占比过大，衰减段过短。
- 峰值 lr 未随有效批缩放。

## 九、演进

warmup → warmup+step → warmup+cosine。

## 十、小结

预热+余弦组合兼顾开局稳定与末期收敛，是大模型默认配方。
