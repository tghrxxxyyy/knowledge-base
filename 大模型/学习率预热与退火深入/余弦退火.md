# 余弦退火

> 对应 Loshchilov & Hutter, *SGDR*, ICLR 2017；与 周期性学习率深入 衔接。

## 一、背景与挑战

阶梯/指数衰减需手调断点；余弦退火平滑且对总步数鲁棒。

## 二、核心原理

学习率随训练进度按余弦从峰值降至最小，形状在中期下降快、末期平缓，利于收敛。

## 三、数学形式

$\eta_t = \eta_{min}+\frac12(\eta_{max}-\eta_{min})(1+\cos\frac{t\pi}{T})$。

## 四、代码实现

```python
frac = t / T_max
lr = min_lr + 0.5*(max_lr-min_lr)*(1+math.cos(math.pi*frac))
```

## 五、与其他对比

- 比 step decay 更平滑，少超参。
- 与 周期性学习率深入 的三角策略形似但目的不同（收敛 vs 探索）。

## 六、常见误区

- 最小 lr 设 0 致末段更新停滞。
- 总步数 T 估计错，曲线未走完。

## 九、演进

step → exp → cosine → cosine with restarts。

## 十、小结

余弦退火以平滑曲线平衡收敛速度与末期精细度，应用最广。
