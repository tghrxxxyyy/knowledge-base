# 假设性文档嵌入（HyDE）

> 对应 Gao et al., *HYDE*, 2022。

## 一、背景与挑战

查询短而文档长，语义空间不匹配；直接向量检索差。

## 二、核心原理

先让 LLM 生成“假设性答案文档”，用其嵌入检索（因假设文档与真实文档更近），再取真实文档。

## 三、数学形式

$h = E(\text{LLM}(q))$（假设文档嵌入），检索 $\arg\max sim(h, E(d))$；返回真实 $d$ 而非 $h$。

## 四、代码实现

```python
hypo = llm(f"写一段可能回答: {q}")
docs = vec.search(E(hypo), k=5)
```

## 五、与其他对比

- 与 向量检索算法深入（嵌入空间）相关。
- 与 检索增强生成前沿 衔接。

## 六、常见误区

- 假设文档可能含幻觉，但其嵌入仍有效（只用其嵌入）。
- 增加一次 LLM 调用延迟。

## 八、面试题

- HyDE 为何有效？答：假设答案嵌入比短查询更接近真实文档嵌入空间。

HyDE 用假设文档桥接查询-文档嵌入鸿沟，常提召回。
