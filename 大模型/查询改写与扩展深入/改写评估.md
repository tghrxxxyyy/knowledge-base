# 查询改写评估

> 对应改写质量评估；RAG评估与离线评测体系（目录）衔接。

## 一、背景与挑战

改写好坏需量化，否则盲目改动。

## 二、核心原理

以改写后检索 Recall@k 与最终答案质量对比原查询；可用 LLM 评改写保真度。

## 三、数学形式

$\Delta = \text{Recall}_{q'} - \text{Recall}_q$；保真度 $F = \text{sim}(q', q_{intent})$。

## 四、代码实现

```python
base = eval_rag(q); rw = eval_rag(q_prime)
```

## 五、与其他对比

- 与 模型评测指标深入 共享。
- 与 检索增强生成失效深入（若新增）衔接（失效时改写诊断）。

## 六、常见误区

- 只看召回忽略保真（改写偏题）。
- 未做 A/B 直接上线。

## 七、与开源书对应

## 八、面试题

- 如何评估改写？答：对比改写前后召回与答案质量，并查保真度。

## 九、演进

人工 → 自动指标 → 端到端 A/B。

## 十、小结

改写评估需兼顾召回增益与意图保真，避免偏题。
