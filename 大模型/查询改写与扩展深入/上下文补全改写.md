# 上下文补全改写

> 对应多轮对话 RAG 改写（指代消解）。

## 一、背景与挑战

多轮对话中“它/这个”指前文，单轮检索失败。

## 二、核心原理

结合对话历史把指代补全为独立可检索查询（query rewriter with history）。

## 三、数学形式

$q' = \text{Rewrite}(q_t | q_{<t}, C)$；使 $q'$ 自包含。

## 四、代码实现

```python
q_prime = llm(f"历史:{hist}\n当前:{q}\n改写为独立查询:")
```

## 五、与其他对比

- 与 对话系统深入（指代消解）共享。
- 与 长上下文技术（保留历史）对照。

## 六、常见误区

- 改写引入历史噪声致偏题。
- 忽视隐私（历史含敏感信息）。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- 多轮 RAG 为何要补全？答：当前 query 指代前文，补全为独立查询才能正确检索。

## 九、演进

规则指代 → 模型改写 → 检索-生成联合。

## 十、小结

上下文补全改写解决多轮指代，是对话 RAG 的必需组件。
