# 多查询扩展（Multi-Query）

> 对应 Multi-Query Retrieval（LangChain 实践）；检索增强生成前沿 衔接。

## 一、背景与挑战

单查询视角有限，复杂问题需多子问题覆盖。

## 二、核心原理

LLM 生成多个不同角度查询，分别检索后合并去重，提升覆盖与鲁棒。

## 三、数学形式

$\{q_i\}_{i=1}^m = \text{Expand}(q)$；最终文档 $= \text{Union}(\text{retrieve}(q_i))$ 去重。

## 四、代码实现

```python
qs = llm(f"生成{3}个不同角度查询: {q}").split("\n")
docs = dedupe([retrieve(qi) for qi in qs])
```

## 五、与其他对比

- 与 混合检索深入（也可多查询）互补。
- 与 检索重排序深入（合并后重排）衔接。

## 六、常见误区

- 查询过多致延迟与冗余。
- 未去重使上下文重复。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- 多查询为何提升召回？答：不同角度覆盖语义/子问题，减少单视角遗漏。

## 九、演进

单查询 → 固定扩展 → 自适应数量。

## 十、小结

多查询扩展以多视角提升覆盖，是复杂问题 RAG 的利器。
