# 综合成本优化

> 对应降本手段（量化、蒸馏、批、缓存）；llm-course 推理优化。llm-course 覆盖推理优化。

## 一、背景与挑战

推理账单高企，需在质量可接受下系统降本。

## 二、核心原理

组合：权重量化（INT8、FP8）、KV 缓存复用、连续批、提示缓存、小模型路由、闲置缩容。

## 三、数学形式

降本比 $\frac{C_{before}-C_{after}}{C_{before}}$；约束质量 $\Delta Q < \epsilon$。

## 四、代码实现

```python
if complexity(req) < low:
    route("small-model")     # 小模型省成本
```

## 五、与其他对比

- 与 GPU利用率核算（提利用率）共享。
- 与 模型加密与权重量化保护深入（量化）交叉。

## 六、常见误区

- 量化过度致质量崩。
- 只缩容忽略突发扩容延迟。

## 八、面试题

## 九、演进

## 十、小结
