# 成本归因与计费总览

> 对应 LLM 成本治理（litellm 成本追踪）；FinOps 分摊。FinOps 基金会定义云成本分摊。

## 一、背景与挑战

推理 GPU 昂贵，需把开销精确归因到业务、模型、租户，才能优化与结算。

## 二、核心原理

采集每请求 token、GPU 秒、型号单价，按维度聚合；区分固定（常驻）与可变（按需）成本。

## 三、数学形式

总成本 $C = \sum_m p_m \cdot (tok_m + gpu\_sec_m \cdot r_{gpu})$；多维下钻。

## 四、代码实现

```python
rec = {"model": m, "tok": n, "gpu_s": g, "tenant": t}
cost_db.insert(rec)
```

## 五、与其他对比

- 与 租户成本隔离（租户维度）衔接。
- 与 Token计费模型 / GPU利用率核算 分述。

## 六、常见误区

- 只算 token 忽略常驻卡成本。
- 维度缺失致归因空白。
