# 成本分摊模型

> 对应共享成本分摊（FinOps 标签法）；固定与可变分离。FinOps 推荐标签化分摊。

## 一、背景与挑战

常驻网关、监控、共享缓存等公共成本需合理摊到业务线，否则账不准。

## 二、核心原理

可变成本按用量直接归因；固定成本按权重（请求占比、峰值）分摊；用标签聚合。

## 三、数学形式

分摊 $share_i = \frac{u_i}{\sum u}\cdot F_{common}$；用量 $u_i$ 可为 token 或 GPU 秒。

## 四、代码实现

```python
for t in tenants:
    bill[t] = direct[t] + F_common * usage[t] / sum(usage)
```

## 五、与其他对比

- 与 成本归因总览（聚合）衔接。
- 与 租户成本隔离（租户账单）共享。

## 六、常见误区

- 固定成本乱摊致小业务亏、大业务沾光。
- 权重口径不固定致月度不可比。

## 八、面试题

- 固定成本如何摊？答：按用量权重（token、GPU秒）摊公共开销，口径需稳定。

## 九、演进

不分摊 → 比例摊 → 作业级精确分摊。

## 十、小结

分摊模型让共享成本落到具体业务，账实相符。
