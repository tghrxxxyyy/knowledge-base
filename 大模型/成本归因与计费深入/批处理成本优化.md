# 批处理成本优化

> 对应连续批处理降本（vLLM）；批越大单位成本越低。vLLM 通过连续批提吞吐。

## 一、背景与挑战

相同 token 量下，批处理摊薄固定开销，单位成本显著下降。

## 二、核心原理

一次前向同时处理多请求，显存与 kernel 启动固定成本被摊薄；但过大增尾延迟。

## 三、数学形式

单位成本 $c(B)=\frac{C_{fixed}+B\cdot c_{var}}{B}\approx \frac{C_{fixed}}{B}+c_{var}$，随 $B$ 降。

## 四、代码实现

```python
out = model.generate(batched_prompts)   # 摊薄固定开销
```

## 五、与其他对比

- 与 连续批处理与排队（吞吐）共享。
- 与 综合成本优化（提批）衔接。

## 六、常见误区

- 盲目大批发尾延迟不可接受。
- 忽略变长致短请求被长请求拖累成本。

## 八、面试题

- 批处理如何降本？答：固定开销（kernel、显存）被多请求摊薄，单位 token 成本降。

## 九、演进

逐条 → 静态批 → 连续批。

## 十、小结

批处理是推理降本首要手段，在延迟与成本间取平衡。
