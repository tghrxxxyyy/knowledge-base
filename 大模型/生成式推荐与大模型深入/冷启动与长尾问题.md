# 冷启动与长尾问题

> 对应 github huggingface/peft 项目与 Hu 2021 的 LoRA 论文。

## 一、背景与挑战
新用户、新物品缺乏交互，长尾内容曝光不足。需用内容语义与轻量适配缓解数据稀疏。

## 二、核心原理
用大模型把物品描述编码为语义表征参与召回；对新域用 LoRA 等参数高效微调快速适配，避免从零训练。

## 三、形式化与数学基础
LoRA 低秩更新：
$ W = W_0 + \Delta W = W_0 + B A,\quad B\in\mathbb{R}^{d\times r}, A\in\mathbb{R}^{r\times k} $
参数量由 $ dk $ 降为 $ r(d+k) $。

## 四、代码实现
```python
import torch

class LoRA(torch.nn.Module):
    def __init__(self, base, r=8):
        super().__init__()
        self.base = base
        for n, p in base.named_parameters():
            if 'weight' in n:
                p.requires_grad = False
        self.B = torch.nn.Parameter(torch.zeros(base.out, r))
        self.A = torch.nn.Parameter(torch.zeros(r, base.in))

    def forward(self, x):
        return self.base(x) + (x @ self.A.T @ self.B.T)

def cold_embed(text_encoder, desc):
    return text_encoder(desc).mean(0)
```

## 五、与其他技术对比
相比全量微调，LoRA 快且省显存；相比纯协同，语义表征解决零交互。

## 六、常见误区
低秩秩数过小丢信息。冷启动只用 ID  embedding 无效。

## 八、面试题
问：LoRA 为何适合冷启动？答：冻结主干只训小矩阵，新域少量数据即可适配。

## 十、小结
语义 + 参数高效适配是冷启动与长尾的有效解药。
