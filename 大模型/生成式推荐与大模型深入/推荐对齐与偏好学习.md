# 推荐对齐与偏好学习

> 对应 Rafailov 2023 的 DPO 论文与 github huggingface/trl 项目。

## 一、背景与挑战
推荐不仅要点击率，还要满足多样性、新鲜感与长期满意。需把隐式偏好转化为可优化目标，避免只刷短期指标。

## 二、核心原理
把 (被选中, 被拒绝) 的曝光对当作偏好数据，用 DPO 直接优化生成策略，使更合意物品排序更靠前，免去独立奖励模型。

## 三、形式化与数学基础
DPO 损失：
$ \mathcal{L}=-\log\sigma\big(\beta\log\frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)}-\beta\log\frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)}\big) $

## 四、代码实现
```python
import torch

def dpo_loss(pi_theta, pi_ref, x, y_w, y_l, beta=0.1):
    lw = pi_theta(x, y_w) - pi_ref(x, y_w)
    ll = pi_theta(x, y_l) - pi_ref(x, y_l)
    return -torch.log(torch.sigmoid(beta * (lw - ll)))

def rank_after(model, items, user):
    return sorted(items, key=lambda i: model.score(user, i), reverse=True)
```

## 五、与其他技术对比
相比 pointwise 交叉熵，DPO 直接建模相对偏好；相比 PPO，省去奖励模型与采样稳定性更好。

## 六、常见误区
曝光偏差使拒绝样本不具代表性。beta 过大退化为参考策略。

## 七、与开源书/权威来源对应
- Rafailov 2023 DPO
- github huggingface/trl
- Ouyang 2022 RLHF

## 八、面试题
问：DPO 为何比 PPO 简单？答：用偏好对构造分类式损失，不需要在线采样与奖励模型。

## 九、演进与趋势
KTO、ORPO、SimPO 等无配对偏好方法及多目标对齐。

## 十、小结
偏好优化把推荐目标从单点指标扩展为整体满意。
