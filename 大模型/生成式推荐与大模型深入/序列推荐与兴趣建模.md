# 序列推荐与兴趣建模

> 对应 github facebookresearch/llama 项目与 Brown 2020 的 in-context learning 论文。

## 一、背景与挑战
用户兴趣随时序演变，短期意图与长期偏好需分离建模。序列推荐捕捉顺序依赖以预测下一步交互。

## 二、核心原理
把交互序列当作上下文，利用注意力建模物品间转移；大模型可借此做 in-context 兴趣推断，无需重训即适配新行为。

## 三、形式化与数学基础
注意力聚合兴趣：
$ h = \sum_{t} \alpha_t v_t,\quad \alpha_t=\mathrm{softmax}(q^\top v_t) $
其中 $ v_t $ 为第 $ t $ 步物品表征。

## 四、代码实现
```python
import torch

def interest(model, seq_ids):
    h = model(seq_ids).last_hidden_state
    q = h[:, -1]
    scores = (q @ h.transpose(1, 2))
    w = torch.softmax(scores, -1)
    return (w @ h).squeeze(1)

def next_item(model, seq, cand):
    h = interest(model, seq)
    return int((h @ cand.T).argmax())
```

## 五、与其他技术对比
相比矩阵分解，序列模型捕捉动态；相比纯 RNN，注意力可并行且长程更稳。

## 六、常见误区
历史过长未截断引入噪声。把会话内随机点击当偏好。

## 七、与开源书/权威来源对应

## 八、面试题
问：短期与长期兴趣如何权衡？答：用不同时间窗或门控融合，近期权重高但保留长期画像。

## 九、演进与趋势
多行为序列、跨域兴趣与生成式序列建模。

## 十、小结
序列建模是捕捉动态兴趣的核心手段。
