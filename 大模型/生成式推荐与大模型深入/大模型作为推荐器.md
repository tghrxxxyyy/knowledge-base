# 大模型作为推荐器

> 对应 github run-llama/llama_index 项目与 Lewis 2020 的 RAG 论文。

## 一、背景与挑战
把推荐当作语言任务，可利用大模型的世界知识与语义理解，直接基于物品描述与用户画像生成推荐理由与候选。

## 二、核心原理
将用户画像与候选物品文本组织为提示，让模型排序或生成最匹配项，并输出可解释理由，弥合协同信号与语义鸿沟。

## 三、形式化与数学基础
语言化匹配得分：
$ s(u,i)=\text{LLM}(P(u,i)) \in \mathbb{R} $
经校准后用于排序。

## 四、代码实现
```python
def llm_rank(model, profile, items, k=5):
    scored = []
    for it in items:
        prompt = '用户: ' + profile + '\n物品: ' + it.desc + '\n相关度1-5:'
        rating = float(model.generate(prompt).strip()[0])
        scored.append((rating, it))
    scored.sort(reverse=True)
    return [it for _, it in scored[:k]]

def reason(model, profile, item):
    return model.generate('为什么推荐: ' + profile + ' | ' + item.desc)
```

## 五、与其他技术对比
相比协同过滤，大模型理解语义与冷启动友好；相比传统排序，推理慢、成本高，需缓存与蒸馏。

## 六、常见误区
把生成文本当精确排序分数。忽视位置偏差导致前项偏好。

## 七、与开源书/权威来源对应

## 八、面试题
问：LLM 推荐冷启动优势来源？答：语义理解使其不依赖历史交互即可匹配描述。

## 九、演进与趋势
语义 ID、蒸馏小模型与混合召回。

## 十、小结
大模型把推荐从 ID 匹配升维到语义理解。
