# 专家并行负载均衡

> 对应 Fedus et al., 《Switch Transformers》, 2021；负载辅助损失。

## 一、背景与挑战

无约束路由易塌缩到少数专家，多数专家闲置。

## 二、核心原理

加辅助负载损失使各专家分配率均匀；容量因子限制每专家 token 数，溢出 token 走残差或多专家；可加 router z-loss 稳训练。

## 三、数学形式

$L_{aux}=\alpha N\sum_{i=1}^N f_i P_i$；容量 $C=\frac{k\cdot T}{E}\cdot cap\_factor$（$T$ token 数）。

## 四、代码实现

```python
aux = alpha * E * (frac * prob).sum()      # 负载均衡项
if dispatched > capacity:
    dropped = tokens[capacity:]             # 溢出丢弃或残差
```

## 五、与其他对比

- 与 混合并行深入 中专家放置相关。
- 与 通信压缩深入 不冲突。

## 六、常见误区

- 容量过大浪费显存、过小丢 token。
- 辅助损失权重不当致路由乱。

## 八、面试题

- 容量因子作用？答：限制每专家 token 数，平衡显存与溢出。

## 九、演进

无约束 → 辅助损失 → 容量+丢弃策略。

## 十、小结

负载均衡靠辅助损失与容量控制，防专家塌缩。
