# 专家并行总览

> 对应 Shazeer et al., 《Outrageously Large Neural Networks: The Sparsely-Gated Mixture-of-Experts Layer》, 2017。

## 一、背景与挑战

稠密模型参数全激活，算力随参数线性增；MoE 用稀疏激活在同等算力下放大参数。

## 二、核心原理

把 MLP 换成 $E$ 个专家，门控网络按 token 选 top-k 专家；专家分布到不同卡（专家并行），每 token 只算被选专家，算力近常数、参数随专家数增。

## 三、数学形式

$y=\sum_{i\in topk(g(x))} G_i(x)\,E_i(x)$，$G_i$ 门控权重；激活专家数 $k\ll E$。

## 四、代码实现

```python
gates = softmax(gate(x), dim=-1)
idx = gates.topk(k, dim=-1).indices
y = sum(experts[i](x) for i in idx)        # 仅 k 个专家
```

## 五、与其他对比

- 与 张量并行深入 在 MLP 处可叠加（专家内再 TP）。
- 与 数据并行深入 正交。

## 六、常见误区

- 专家数过多而路由集中致部分专家饿死。
- 忽略 all-to-all 通信。

## 八、面试题

- MoE 为何省算力？答：每 token 只激活 top-k 专家，算力近常数、参数可放大。

## 九、演进

稠密 → 稀疏门控 MoE → 大规模专家并行。

## 十、小结

专家并行以稀疏激活在固定算力下放大数据量，是超大模型关键。
