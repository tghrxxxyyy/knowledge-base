# 专家并行显存与扩展

> 对应 Rajbhandari et al., 《MoQE》思路；Du et al., 《ST-MoE》, 2022。

## 一、背景与挑战

专家参数量巨大，需分布到多卡且训练稳。

## 二、核心原理

专家并行把专家权重分卡，单卡只存 $1/E$ 专家；非专家层仍可 TP/DP；用 ZeRO/TP 进一步省；ST-MoE 指出 MoE 对精度/路由更敏感。

## 三、数学形式

单卡专家显存 $\approx \frac{E}{ep}\cdot(2+12)\phi_{expert}$（若优化器也分）；总参随 $E$ 增但算力近常。

## 四、代码实现

```python
experts = shard(experts, ep_group)        # 专家分到各卡
non_expert = DDP(non_expert)              # 非专家层数据并行
```

## 五、与其他对比

- 与 数据并行深入、张量并行深入 组合成 MoE 训练。
- 与 混合并行深入 是子问题。

## 六、常见误区

- 专家全放单卡显存爆。
- 忽视 MoE 微调不稳定（router z-loss）。

## 八、面试题

- 专家并行如何省显存？答：专家权重分卡，每卡只持部分专家，参数量可放大。

## 九、演进

单卡 MoE → 专家并行 → 3D+MoE。

## 十、小结

专家并行分布专家权重，使参数可远超单卡显存。
