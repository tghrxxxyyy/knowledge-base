# 混合精度量化

> 对应 AWQ（Lin et al. 2023）重要通道保护思想与混合精度量化实践。

## 一、背景与挑战

量化把高比特权重压到低比特（如 FP16→INT4）以省显存、提速，但并非所有权重对量化误差同样敏感。若「一刀切」统一定为 4-bit，少数敏感层（如部分注意力投影、归一化相关参数）会因精度骤降而严重拖累整体质量；而把全部层都保留高比特，又浪费了压缩收益。混合精度量化（Mixed-Precision Quantization）的核心思想，就是按层/通道/组的敏感度差异化分配比特，在「精度」与「体积」的全局约束下达到最优平衡。混合精度也可作用于「权重 vs 激活」分别定精度：权重常可压到 4-bit，而激活因动态范围大、含离群值，往往保留 8-bit 更稳，二者比特预算应联合搜索而非独立决定。

## 二、核心原理

混合精度的前提是对每层做灵敏度分析（sensitivity analysis）：把某层单独量化，观察验证集困惑度或任务指标的变化，变化越大说明该层越敏感，应保留更高比特（INT8/FP16），反之可压到 INT4。AWQ 提出的「重要通道保护（Activation-aware Weight Quantization）」是混合精度思想的典型体现：它发现权重中一小部分对应大激活的通道对量化极敏感，应予以保护（放大后再量化），而非简单统一降位。决策通常在「总比特预算」约束下，用搜索或贪心为每层的比特数赋值。其本质是在精度损失与压缩体积之间求解一个受限优化问题。

## 三、形式化与数学基础

设第 $l$ 层权重 $W_l$，分配比特 $b_l\in\{2,3,4,8,16\}$，总比特预算 $B$。优化目标：

$$\min_{\{b_l\}} \sum_l \text{Err}_l(b_l) \quad \text{s.t.}\quad \sum_l |W_l|\cdot b_l \le B$$

其中 $\text{Err}_l(b_l)$ 为第 $l$ 层在比特 $b_l$ 下的误差代理（如量化后困惑度增量）。AWQ 的通道重要性由激活规模 $X$ 决定，量化误差近似：

$$\Delta \approx \sum_i \left(\frac{\partial \mathcal{L}}{\partial W_i}\right)^2 \cdot \sigma_q^2(W_i),\quad \sigma_q^2 \propto \frac{\max(|W|)}{2^{b}}$$

即误差与权重幅度及比特位数相关，重要通道需更细粒度或更高比特。

## 四、代码实现

```python
# 基于灵敏度的贪心比特分配（示意）
def sensitivity(layer, val_loader):
    base = evaluate(layer, val_loader)
    errs = {}
    for b in [4, 8, 16]:
        q = quantize(layer, bits=b)
        errs[b] = evaluate(q, val_loader) - base   # 越大越敏感
    return errs

def allocate(layers, budget_bits):
    # 简单贪心：敏感层先给高比特，直到预算用尽
    assign = {l: 4 for l in layers}
    for l in sorted(layers, key=lambda x: -layers[x].sens):
        while assign[l] < 16 and cost(assign) < budget_bits:
            assign[l] += 4
    return assign
```

## 五、与其他技术对比

| 方案 | 精度 | 压缩比 | 复杂度 |
|------|------|--------|--------|
| 统一 INT4 | 中 | 高 | 低 |
| 混合精度 | 高 | 中高 | 中 |
| AWQ 通道保护 | 高 | 高 | 中 |
| 全 FP16 | 最高 | 1 | 无 |

混合精度与通道保护可在高压缩下保精度。

## 六、常见误区

- 以为所有层统一 4-bit 最省：敏感层崩坏导致整体质量断崖。
- 灵敏度分析只看困惑度：任务级指标更能反映真实敏感度。
- 混合精度粒度过细：per-group 虽准但 kernel 与调度开销大。
- 忽视激活量化：权重混合精度但激活仍高比特，收益打折。

## 九、演进与趋势

- 从「逐层比特搜索」走向「可微分比特分配」，端到端学习每层的精度。
- 权重与激活混合精度联合搜索，进一步逼近无损压缩点。
- 硬件对混合精度（如 INT4/INT8 混布）的原生支持逐步完善。
- 自动化工具根据任务预算直接输出每层的比特方案。

- 可微分比特分配：让网络端到端学习每层的最优精度，超越贪心搜索。
- 训练期联合量化感知（QAT）+ 混合精度，进一步压低 4-bit 损失。
- 硬件（如 FP8/INT4 混布）原生支持，使混合精度真正落地加速。
- 稀疏与混合精度组合（稀疏混合精度）探索更高压缩比。
- 自动化工具根据任务预算直接输出逐层比特方案。

## 十、小结

混合精度量化承认「权重敏感度不均」，通过逐层/逐通道差异化比特在总预算下最小化精度损失。AWQ 的重要通道保护是其典型代表。实践上需先做灵敏度分析，再在精度—体积约束下决策，并联合考虑激活量化，避免「一刀切」带来的质量断崖。
