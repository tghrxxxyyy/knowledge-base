# 低秩分解 Low-Rank Factorization

> 对应 SVD 矩阵压缩经典方法与 LoRA（Hu et al. 2021）的数学同构思想。

## 一、背景与挑战

现代大模型的参数量主要来自巨大的稠密权重矩阵（如注意力的 $W_Q,W_K,W_V,W_O$ 与 FFN 的升/降维矩阵）。这些矩阵虽然维度高，但其「有效秩（effective rank）」往往远低于名义维度——即信息可被少数主成分捕捉。低秩分解（Low-Rank Factorization）正是利用这一冗余，将大矩阵近似为两个小矩阵的乘积，从而压缩存储与计算。挑战在于：过度压缩会牺牲表达能力，且并非所有层都同样低秩，需要按层灵敏度决定保留的秩。

## 二、核心原理

值得注意的是，低秩分解对「近似误差」敏感：若某层有效秩接近其维度，强制低秩会损失关键信息。因此实践中常先用 SVD 能量比例预估各层可压缩空间，再决定保留秩，而非全局统一秩。给定权重矩阵 $W\in\mathbb{R}^{m\times n}$，低秩分解将其近似为 $A\in\mathbb{R}^{m\times r}$ 与 $B\in\mathbb{R}^{r\times n}$ 的乘积，其中 $r\ll\min(m,n)$：

$$W \approx A\cdot B$$

典型做法是对 $W$ 做截断奇异值分解（Truncated SVD），保留前 $r$ 个奇异值与对应向量。前向计算由 $x\mapsto Wx$ 变为 $x\mapsto A(Bx)$，计算量从 $O(mn)$ 降为 $O(r(m+n))$。值得强调的是：这与 LoRA（Hu et al. 2021）在数学上同构——都是「低秩增量」，但目的不同：LoRA 在微调时注入可训练低秩适配器，低秩分解在压缩时把已有权重拆成小矩阵以减少体积。

## 三、形式化与数学基础

对 $W$ 做 SVD：$W = U\Sigma V^\top$，取前 $r$ 列得 $U_r\in\mathbb{R}^{m\times r},\Sigma_r\in\mathbb{R}^{r\times r},V_r\in\mathbb{R}^{n\times r}$，则：

$$A = U_r\Sigma_r^{1/2},\quad B = \Sigma_r^{1/2}V_r^\top,\quad W_r = AB$$

近似误差由被丢弃的奇异值平方和度量：

$$\|W - W_r\|_F^2 = \sum_{i=r+1}^{\min(m,n)}\sigma_i^2$$

选 $r$ 使累计能量 $\sum_{i=1}^r\sigma_i^2/\sum\sigma_i^2 \ge 1-\epsilon$ 即满足精度预算 $\epsilon$。

## 四、代码实现

```python
import numpy as np

def low_rank_factorize(W: np.ndarray, r: int):
    # 截断 SVD
    U, S, Vt = np.linalg.svd(W, full_matrices=False)
    U_r, S_r, Vt_r = U[:, :r], S[:r], Vt[:r, :]
    A = U_r * np.sqrt(S_r)          # (m, r)
    B = (np.sqrt(S_r)[:, None] * Vt_r)  # (r, n)
    W_r = A @ B
    err = np.linalg.norm(W - W_r, 'fro') ** 2
    return A, B, err

# 按能量比例自动选秩
def auto_rank(W, eps=0.01):
    S = np.linalg.svd(W, compute_uv=False)
    total = (S ** 2).sum()
    return int(np.searchsorted((S ** 2).cumsum(), (1 - eps) * total)) + 1
```

## 五、与其他技术对比

| 技术 | 压缩对象 | 是否需训练 | 加速来源 |
|------|----------|------------|----------|
| 低秩分解 | 权重矩阵 | 否（分解即可） | 降矩阵乘维度 |
| 量化 | 数值精度 | 否/少量 | 降位宽 |
| 剪枝 | 结构/元素 | 常需微调 | 降参数量 |
| LoRA | 增量权重 | 是（微调） | 不改原前向 |

低秩分解常与量化组合，先降秩再降位宽。

## 六、常见误区

- 以为所有矩阵都适合低秩：注意力投影常低秩，但某些层接近满秩，强行压会掉点。
- 混淆低秩分解与 LoRA：前者压缩、后者微调，目的不同但数学同构。
- 仅看参数量压缩比：还需验证下游任务与困惑度是否可接受。
- 分解后不微调：SVD 是一步近似，必要时用小学习率微调可恢复精度。

## 七、与开源书·权威来源对应

- 截断 SVD 是经典数值线性代数方法，广泛用于矩阵压缩。
- Hu et al., *LoRA: Low-Rank Adaptation* (2021) 与低秩分解共享低秩思想。
- 实践可结合 SageMaker/PyTorch 的 SVD 与压缩工具链，以官方最新文档为准。

## 十、小结

低秩分解以截断 SVD 把高维权重近似为小矩阵乘积，利用权重的有效低秩性压缩体积与计算。它与 LoRA 数学同构但用途不同，实践中常与量化组合，并需按层灵敏度决定秩大小以平衡精度与压缩比。
