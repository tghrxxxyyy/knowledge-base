# 结构化与非结构化剪枝

> 对应 Han et al. 2015 深度网络剪枝与 NVIDIA 2:4 稀疏结构化稀疏实践。

## 一、背景与挑战

剪枝（Pruning）通过移除模型中「不重要」的权重或结构来减小规模、提升速度。按粒度可分为非结构化与结构化两大类，二者的根本差异不在于「剪什么」，而在于「剪完之后通用硬件能否直接加速」。非结构化剪枝删除任意单个权重，产生随机稀疏矩阵，必须依赖稀疏算子才能真正提速，否则只是把非零值压缩存储而计算量不变；结构化剪枝删除整个通道、注意力头或层，生成规整的子网络，通用硬件与推理库可直接加速，但压缩更「粗暴」、精度损失更大。半结构化（如 2:4 稀疏）则在二者间折中。

## 二、核心原理

- **非结构化剪枝**：以权重幅值（或一阶/二阶敏感度）为判据，删掉接近零的个体元素，得到不规则稀疏模式。优点是保精度好，缺点是需稀疏矩阵乘法（SpMM）与专用库/硬件才能转化为加速，且在现代稠密 tensor core 上常因不规则访存而「剪了不快」。
- **结构化剪枝**：移除通道（channel）/ 滤波器（filter）/ 注意力头（head）/ 整层，得到稠密但更小的网络。优点是即插即用地被现有框架加速，缺点是粒度粗，移除一个通道影响面大、易掉点，常需后续微调恢复。
- **半结构化（2:4）**：规定每连续 4 个元素保留 2 个，形成规则稀疏模式，NVIDIA Ampere+ 张量核心原生支持，兼顾加速与精度。

## 三、形式化与数学基础

非结构化剪枝用二值掩码 $M\in\{0,1\}^{m\times n}$ 乘权重：$W' = M\odot W$，$\|M\|_0 = k$。目标是最小化性能损失：

$$\min_{M:\|M\|_0\le k} \mathcal{L}(M\odot W)$$

结构化剪枝的掩码是「块对齐」的——对整个通道置零：

$$M_{:,j} \in \{0,1\}^{m}\ \text{（整列为 0 或 1）}$$

2:4 约束更强：对每个长度为 4 的块 $\mathcal{B}$，$\|M_{\mathcal{B}}\|_0 = 2$。硬件可由此做「跳过零元素」的固定步长加载，实现确定加速比。

## 四、代码实现

```python
import torch, torch.nn as nn

def prune_unstructured(module: nn.Linear, amount=0.5):
    w = module.weight.data
    thr = torch.quantile(w.abs().flatten(), amount)
    mask = (w.abs() > thr).float()
    module.weight.data *= mask          # 非结构化：不规则稀疏
    return mask

def prune_channels(conv: nn.Conv2d, keep_ratio=0.7):
    # 结构化：按通道 L1 范数保留重要通道
    norms = conv.weight.data.norm(1, dim=(1,2,3))
    k = int(keep_ratio * norms.numel())
    keep = norms.topk(k).indices
    conv.weight.data = conv.weight.data[keep]
    if conv.bias is not None:
        conv.bias.data = conv.bias.data[keep]
```

## 五、与其他技术对比

| 类型 | 加速 | 精度 | 硬件要求 |
|------|------|------|----------|
| 非结构化 | 需稀疏库 | 高 | 高（SpMM） |
| 结构化 | 通用 | 中 | 低 |
| 2:4 半结构化 | 硬件原生 | 中高 | Ampere+ |

结构化易加速但伤精度，非结构化反之，2:4 取中间。

## 六、常见误区

- 以为剪枝一定加速：非结构化若无稀疏 kernel，仅省存储不省时延。
- 结构化一次剪太多：粗粒度导致精度断崖，应渐进 + 微调。
- 忽视后续训练：剪后微调（或彩票假设重训）对恢复精度至关重要。
- 混淆稀疏模式：2:4 与随机稀疏在硬件支持上完全不同。

## 九、演进与趋势

- 从「幅值阈值」走向「基于 Hessian/敏感度」的更优判据。

## 十、小结

剪枝的核心权衡是「精度保持」与「实际加速」。非结构化保精度但需稀疏算子，结构化即插即用地加速但更伤精度，2:4 半结构化在硬件支持下折中。选型应结合目标硬件与是否具备稀疏推理能力，并以剪后微调恢复质量。
