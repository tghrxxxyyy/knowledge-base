# 混合检索总览

> 对应 BM25 + 稠密混合；RAG深入 / 检索增强生成前沿 衔接。

## 一、背景与挑战

纯向量召回缺关键词精确匹配；纯词法缺语义；混合互补。

## 二、核心原理

并行跑稀疏（BM25/关键词）与稠密（向量）检索，再融合（RRF/加权）得最终候选。

## 三、数学形式

RRF：$score_i=\sum_{r} \frac{1}{k+\text{rank}_r(i)}$（$k$ 常数，如 60），融合各列表排名。

## 四、代码实现

```python
sparse = bm25.search(q, 100); dense = vec.search(q, 100)
fused = rrf([sparse, dense], k=60)
```

## 五、与其他对比

- 与 向量检索算法深入（稠密侧）互补。
- 与 检索重排序深入（融合后精排）衔接。

## 六、常见误区

- 两路分数尺度不同直接相加无效，须用排名融合(RRF)。
- 忽视稀疏/稠密覆盖差异。

## 八、面试题

- 为何混合优于单路？答：词法保精确匹配、稠密保语义，互补提召回。

## 九、演进

稠密单路 → 稀疏+稠密 → RRF 融合 → 学习融合。

## 十、小结

混合检索融合词法与语义，是 RAG 召回质量的基础提升。
