# 混合检索融合策略

> 对应 Reciprocal Rank Fusion（Cormack et al., 2009）。

## 一、背景与挑战

两路分数不可直接比，需鲁棒融合。

## 二、核心原理

RRF 只用排名不用分数，抗尺度差异；或学习融合（训练小模型权重）更优但需标签。

## 三、数学形式

RRF 分数 $R(i)=\sum_r 1/(k+rank_r(i))$；亦可线性 $w_s s_s + w_d s_d$（需归一）。

## 四、代码实现

```python
def rrf(lists, k=60):
    s={}
    for lst in lists:
        for r,doc in enumerate(lst): s[doc]=s.get(doc,0)+1/(k+r+1)
    return sorted(s, key=s.get, reverse=True)
```

## 五、与其他对比

- RRF 免归一化、简单稳；学习融合更准但需标注。
- 与 检索重排序深入（融合后精排）衔接。

## 六、常见误区

- 直接加权原始分数（未归一）致一路主导。
- k 过小致排名差异被放大。

## 七、与开源书对应

## 八、面试题

- RRF 为何优于分数加权？答：只用排名不受尺度影响，鲁棒免归一。

## 九、演进

分数加权 → RRF → 学习融合（LamdaMART 等）。

## 十、小结

融合策略决定混合检索能否真正互补，RRF 是稳健默认。
