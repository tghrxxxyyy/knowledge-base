# 混合检索与重排衔接

> 对应 RAG 多阶段流水线；检索增强生成前沿 衔接。

## 一、背景与挑战

混合召回产出候选，仍需重排精筛入上下文。

## 二、核心原理

混合（粗）→ 重排（精）→ 截断 top-k 入 LLM；两阶段分工明确。

## 三、数学形式

候选集 $C = \text{HybridRecall}(q)$；最终 $C'=\text{Rerank}(q,C)[:k]$。

## 四、代码实现

```python
cands = hybrid_recall(q, 200)
top = cross_encoder.rerank(q, cands, 8)
```

## 五、与其他对比

- 与 检索重排序深入 / 向量检索算法深入 构成完整链路。
- 与 检索增强生成失效深入（若新增）衔接。

## 六、常见误区

- 混合候选数不当致重排瓶颈或漏召。
- 阶段间度量不一致。

## 八、面试题

- 混合与重排如何分工？答：混合广召回，重排精排序，截断入上下文。

## 九、演进

单路 → 混合 → 混合+重排端到端。

## 十、小结

混合检索与重排是 RAG 召回到精排的两段式核心。
