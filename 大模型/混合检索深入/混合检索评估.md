# 混合检索评估

> 对应 RAG 召回评估；RAG评估与离线评测体系（目录）衔接。

## 一、背景与挑战

需量化混合相对单路的提升，避免无效叠加。

## 二、核心原理

在开发集上对比单路/混合的 Recall@k 与下游答案质量；做消融定权重。

## 三、数学形式

增益 $\Delta = \text{Recall}_{hybrid} - \max(\text{Recall}_{sparse},\text{Recall}_{dense})$。

## 四、代码实现

```python
for w in linspace(0,1,11):
    eval(hybrid(w))
```

## 五、与其他对比

- 与 模型评测指标深入 共享评估法。
- 与 检索重排序深入 共构 RAG 评测链。

## 六、常见误区

- 只看向量指标忽略端到端答案。
- 未做消融致权重凭感觉。
