# BM25与稀疏检索

> 对应 Robertson & Zaragoza, 2009；经典 IR。

## 一、背景与挑战

关键词/专名/ID 精确匹配是稠密弱点；BM25 擅长。

## 二、核心原理

BM25 用词频/逆文档频/文档长度归一打分：$score=\sum \text{IDF}(t)\frac{f(t)(k+1)}{f(t)+k(1-b+bL_{avg}/L)}$。

## 三、数学形式

IDF 项惩罚常见词；长度归一 $b$ 抑制长文档偏好；饱和参数 $k$ 控词频影响。

## 四、代码实现

```python
from rank_bm25 import BM25Okapi
bm = BM25Okapi(corpus); s = bm.get_scores(query)
```

## 五、与其他对比

- 与 向量检索算法深入（稠密）互补为混合两路。
- 与 查询改写与扩展深入 配合（改写后再 BM25）。

## 六、常见误区

- 中文未分词致 BM25 失效（需分词）。
- 忽略停用词/大小写归一。
