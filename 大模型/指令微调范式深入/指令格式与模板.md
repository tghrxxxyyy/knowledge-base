# 指令格式与模板

> 对应 Bach et al., *PromptSource*, 2022；模板定义指令的措辞与槽位。

## 一、背景与挑战

同一任务不同措辞影响模型表现；需系统化模板设计。

## 二、核心原理

模板 = 指令前缀 + 输入槽位 + 输出格式；一份数据集可有多模板，增数据多样性与鲁棒性。

## 三、数学形式

模板函数 $T(q,i)=(p_{instr}\oplus i\oplus p_{out})$，多模板构成集合 $\{T_j\}$。

## 四、代码实现

```python
tmpl = "把下面的句子分类为{POS,NEG}: {text}"
prompt = tmpl.format(text=doc)
```

## 五、与其他对比

- 与 角色与人格对齐深入（系统提示即一种模板）相近。
- 与 多轮对话建模深入（对话模板）共享。

## 六、常见误区

- 模板与推理时措辞不一致致掉点。
- 模板歧义使输出难以解析。

## 七、与开源书对应

- dair-ai/Prompt-Engineering-Guide：https://github.com/dair-ai/Prompt-Engineering-Guide

## 八、面试题

- 多模板有何用？答：一份数据多措辞增多样性、抗模板过拟合、提升鲁棒与泛化。

## 九、演进

单模板 → 多模板 → 自动模板搜索。

## 十、小结

指令模板决定任务呈现，设计一致性直接影响微调与推理效果。
