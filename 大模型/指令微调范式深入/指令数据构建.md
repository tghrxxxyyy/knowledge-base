# 指令数据构建

> 对应 Wang et al., *Self-Instruct*, 2022；用种子任务让 LLM 自举生成指令数据。

## 一、背景与挑战

高质量人工指令数据稀缺昂贵；需低成本规模化构造多样指令。

## 二、核心原理

以少量种子指令为示范，让强模型生成新指令与对应输入/输出；再经过滤（去重、可执行性、质量）入库。

## 三、数学形式

自举循环：$D_{new}=\{g_\phi(x)|x\in D_{seed}\cup D_{gen}\}$，经启发式过滤 $f$ 得可用集。

## 四、代码实现

```python
for seed in seeds:
    inst = llm(f"生成新指令与样例: {seed}")
    if qa_filter(inst): dataset.append(inst)
```

## 五、与其他对比

- 与 训练数据质量深入（数据筛选）共享。
- 与 数据投毒防御深入（合成数据可能含毒）对照。

## 六、常见误区

- 自举数据分布漂移（模型只生成自己擅长类）。
- 未过滤导致脏指令污染训练。
