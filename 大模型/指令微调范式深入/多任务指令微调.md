# 多任务指令微调

> 对应 Sanh et al., *T0 / FLAN*, 2021；把上百数据集转成统一指令格式混合训练。

## 一、背景与挑战

单任务微调泛化差；需在一处混合多任务提升迁移与零样本。

## 二、核心原理

将分类/生成/抽取等任务统一模板化为（指令+输入→输出），混合批训练，任务间共享表示。

## 三、数学形式

混合损失 $\mathcal L=\sum_{k=1}^K w_k \mathcal L_k$，模板化映射 $t_k:D_k\mapsto(x_{instr},y)$。

## 四、代码实现

```python
for batch in mixture_loader:    # 各任务按比例采样
    model.train_step(batch)
```

## 五、与其他对比

- 与 指令微调总览（单视角）互为规模扩展。
- 与 模型评测指标深入（多任务基准）衔接。

## 六、常见误区

- 任务采样比例失衡致大类主导。
- 模板过多样致模型困惑。

## 八、面试题

- 多任务指令微调为何泛化好？答：多任务共享表征、互作正则，激发对未见指令的迁移。

## 九、演进

单任务 → 多任务混合 → 指令提示模板库（PromptSource）。

## 十、小结

多任务统一模板化混合训练，是零样本泛化的重要来源。
