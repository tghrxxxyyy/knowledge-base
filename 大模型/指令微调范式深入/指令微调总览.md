# 指令微调总览

> 对应 Wei et al., *Finetuned Language Models Are Zero-Shot Learners (FLAN)*, 2021；指令微调把预训练语言模型转为能遵循自然语言指令的通用模型。

## 一、背景与挑战

预训练模型仅靠下一词预测，无法直接理解“帮我翻译/分类/总结”等指令；需要微调使其对齐人类指令格式。

## 二、核心原理

用大量（指令, 输出）对监督微调（SFT），让模型学会把任务描述映射为期望输出，激发零样本/少样本泛化。

## 三、数学形式

最大化指令似然：$\mathcal L_{SFT}=-\sum_{t}\log p_\theta(y_t|x,y_{<t})$，其中 $x$ 为含指令的提示。

## 四、代码实现

```python
from trl import SFTTrainer
trainer = SFTTrainer(model, train_dataset=instr_data, max_seq_length=2048)
trainer.train()
```

## 五、与其他对比

- 与 多轮对话建模深入（对话形式指令）互补。
- 与 角色与人格对齐深入（在指令中注入角色）衔接。

## 六、常见误区

- 指令数据单一导致过拟合某类任务。
- 误以为指令微调可替代偏好对齐（仍需 RLHF/DPO）。

## 八、面试题

- 指令微调为何提升零样本？答：把多样任务统一为自然语言指令格式，激活预训练已学的任务模式。

## 九、演进

提示工程 → SFT → 指令+偏好对齐 → 指令数据规模化。

## 十、小结

指令微调是用（指令,输出）对把语言模型对齐到人类任务接口的基石步骤。
