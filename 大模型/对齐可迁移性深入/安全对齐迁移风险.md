# 安全对齐迁移风险

> 对应 Qi et al., 2023；Yang et al., *Shadow Alignment*, 2024（逆向迁移/剥离）。

## 一、背景与挑战

对齐可被后续微调剥离，也可被恶意利用做影子对齐绕过。

## 二、核心原理

少样本有害微调即破安全；影子对齐用对齐模型自身生成看似安全实则违规的训练数据。

## 三、数学形式

剥离速度 $v=-\frac{d SafeRate}{d n_{adv}}$；越大越易被攻破。

## 四、代码实现

```python
if safety_rate(pi_ft) < thr:
    flag_attack()
```

## 五、与其他对比

- 与安全能力遗忘共享剥离。
- 与对齐可迁移性总览共享风险面。

## 六、常见误区

- 认为已对齐即免疫。
- 忽视微调接口即攻击面。
