# 跨模型规模对齐迁移

> 对应 Askell et al., 2021；Ouyang et al., 2022（同族缩放）。

## 一、背景与挑战

大模型对齐能否蒸馏到小模型？规模差带来行为漂移。

## 二、核心原理

小模型容量有限，安全与能力争容量；用大模型生成安全数据训小模型可部分迁移。

## 三、数学形式

迁移效率 $\eta = \frac{S_{small}^{aligned}-S_{small}^{base}}{S_{large}^{aligned}-S_{large}^{base}}$。

## 四、代码实现

```python
small = distill(big_aligned, small_base, safe_data)
```

## 五、与其他对比

- 与容量与表达假说共享受限。
- 与对齐可迁移性总览共享迁移。

## 六、常见误区

- 假设蒸馏无损对齐。
- 小模型容量不足致税重。

## 八、面试题

- 大小模型对齐可互迁吗？答：大模型可生成安全数据训小模型，但容量限制税。

## 九、演进

同规模 → 蒸馏 → 容量感知。

## 十、小结

跨规模迁移受容量约束，需数据增强。
