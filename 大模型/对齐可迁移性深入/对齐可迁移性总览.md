# 对齐可迁移性总览

> 对应 Hendrycks et al., *Unsolved Problems*, 2021；Qi et al., *Fine-tuning Aligned LLMs Compromises Safety*, 2023。

## 一、背景与挑战

在某个任务/语言/规模学到的对齐，能否迁移到新设定？迁移失败是安全风险。

## 二、核心原理

对齐可视为可迁移的行为模式（拒绝、诚实），但易被后续训练覆盖；研究跨任务/语言/规模迁移规律。

## 三、数学形式

迁移增益 $\Delta_{trans}=J_{target}(\pi_{aligned})-J_{target}(\pi_{base})$；正即迁移成功。

## 四、代码实现

```python
gain = eval(aligned, tgt) - eval(base, tgt)
```

## 五、与其他对比

- 与微调灾难性遗忘安全深入共享保留。
- 与多目标偏好聚合深入共享目标侧重。

## 六、常见误区

- 以为对齐自动全迁移。
- 忽视目标域分布差。

- 对齐可迁移吗？答：通用安全行为可迁移，但任务特定与跨语常失败。
