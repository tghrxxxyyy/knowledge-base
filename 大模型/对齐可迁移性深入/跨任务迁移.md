# 跨任务对齐迁移

> 对应 Lin et al., *Unsupervised*, 2023；Yang et al., *Shadow Alignment*, 2024。

## 一、背景与挑战

在数学任务学得谨慎，能否迁移到代码/对话？任务差异影响泛化。

## 二、核心原理

通用安全行为（拒绝对抗、承认不知）易迁移；任务特定风格难迁移，需目标域少量校准。

## 三、数学形式

迁移率 $\rho=\frac{\Delta_{trans}}{\Delta_{src}}$ 衡量从源到目标保有多少。

## 四、代码实现

```python
rho = (eval_tgt(al) - eval_tgt(base)) / (eval_src(al) - eval_src(base))
```

## 五、与其他对比

- 与对齐可迁移性总览共享度量。
- 与微调灾难性遗忘安全深入共享保留。

## 六、常见误区

- 高估安全行为跨任务保持。
- 目标域无校准致错位。

## 八、面试题

- 哪些行为易迁移？答：通用拒绝/诚实易迁移，任务风格难迁移需校准。

## 九、演进

同域 → 跨域 → 校准增强。

## 十、小结

跨任务迁移看行为通用性。
