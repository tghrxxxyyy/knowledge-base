# 跨语言对齐迁移

> 对应 Deng et al., *Multilingual Jailbreak*, 2023；Yong et al., *Low-Resource Languages*, 2023。

## 一、背景与挑战

英对齐在低资源语言常失效，攻击易借翻译绕过。

## 二、核心原理

安全行为依赖语言表征对齐；跨语用平行安全数据或多语 RLHF 提升迁移，否则弱语成短板。

## 三、数学形式

安全差距 $G_{lang}=SafeRate(en)-SafeRate(lo)$；越大跨语迁移越差。

## 四、代码实现

```python
for lg in langs:
    eval_safety(pi, lg)
```

## 五、与其他对比

- 与价值观冲突消解深入共享文化语。
- 与对齐可迁移性总览共享迁移。

## 六、常见误区

- 翻译测试即可代表多语安全。
- 忽视低资源语无数据。
