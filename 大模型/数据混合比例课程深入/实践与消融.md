# 数据混合实践与消融

> 对应 生产预训练配比实践；Rae et al., *Gopher*, 2021（配比消融）；Penedo et al., *FineWeb*, 2024。

## 一、背景与挑战

如何落地配比？需可复现的消融与监控。

## 二、核心原理

在 1%-5% 规模做配比网格，选下游加权最优；上线后持续监控各源贡献与能力漂移。

## 三、数学形式

选择 $\hat\lambda=\arg\max_\lambda \sum_j w_j A_j(\lambda)$；约束 $\lambda\in\Delta^{k-1}$。

## 四、代码实现

```python
best = max(grid, key=lambda lam: weighted_score(lam))
```

## 五、与其他对比

- 与 数据质量过滤与困惑度过滤深入（过滤后体量变）联动。
- 与 数据版权与合规清洗深入（合规限制可用源）约束。

## 六、常见误区

- 消融规模太小结论不稳。
- 上线后不再监控配比漂移。

## 八、面试题

- 怎么定生产配比？答：小规模化网格消融 + 多基准加权，上线监控。

## 九、演进

拍脑袋 → 网格消融 → 自动持续优化。

## 十、小结

配比落地靠小规模消融与持续监控，非一次性决定。
