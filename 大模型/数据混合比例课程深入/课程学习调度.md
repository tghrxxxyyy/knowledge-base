# 课程学习调度

> 对应 预训练课程（先易后难）研究；Kocetkov et al., *The Stack*, 2022（阶段侧重）；多阶段训练实践。

## 一、背景与挑战

全程固定比例可能非最优；可随训练推进调整源权重（如先通用后代码/数学）。

## 二、核心原理

按训练步数分阶段改变 $\lambda(t)$：早期多通用语料打基础，后期增代码/指令/难例，类似课程学习。

## 三、数学形式

$\lambda_i(t)$ 为步 $t$ 的权重；可用退火 $\lambda_i(t)=\lambda_i^{end} + (\lambda_i^{start}-\lambda_i^{end})e^{-t/T}$。

## 四、代码实现

```python
def lambda_t(t, start, end, T):
    return end + (start - end) * math.exp(-t / T)
```

## 五、与其他对比

- 与 数据质量过滤与困惑度过滤深入（质量随阶段变）配合。
- 与 合成数据陷阱与评估深入（后期合成精调）相关。

## 六、常见误区

- 阶段切换点无验证支撑。
