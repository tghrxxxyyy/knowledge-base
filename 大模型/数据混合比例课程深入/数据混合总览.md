# 数据混合总览

> 对应 Xie et al., *DoReMi*, 2023（参考模型优化混合）；Hoffmann et al., *Chinchilla*, 2022（数据量最优）；Ye et al., *Data Mixing Laws*, 2024。

## 一、背景与挑战

预训练语料来自多源（网页、书、代码、论文），混合比例显著影响能力与成本。

## 二、核心原理

混合比例决定各能力来源权重；常用经验比例（如 The Pile 的源权重），也可用小型实验或优化算法搜比例。

## 三、数学形式

混合 $\lambda=(\lambda_1..\lambda_k),\sum\lambda_i=1$；训练损失 $L(\lambda)$；目标 $\min_\lambda L$ 或最大化下游加权。

## 四、代码实现

```python
from torch.utils.data import WeightedRandomSampler
sampler = WeightedRandomSampler(weights=lambda_, num_samples=N)
```

## 五、与其他对比

- 与 数据质量过滤与困惑度过滤深入（先滤后混）顺序。
- 与 分词器训练与词表构建深入（混合影响词表）相关。

## 六、常见误区

- 照搬他人比例忽略语料差异。
- 仅看 loss 忽略下游能力失衡。
