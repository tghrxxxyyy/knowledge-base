# 静态混合比例

> 对应 Gao et al., *The Pile*, 2020（固定源权重）；Rae et al., *Gopher/MassiveText*, 2021（静态配比）。

## 一、背景与挑战

最简单做法：训练全程固定各源权重，但需先验设定。

## 二、核心原理

按源质量与体量给固定比例（如网页 60%、书 15%、代码 10%……），采样时按权重抽。比例常来自经验与小规模验证。

## 三、数学形式

采样概率 $P(src=i)=\lambda_i$；期望每步看到源 $i$ 的样本数 $=B\lambda_i$（$B$ 为 batch）。

## 四、代码实现

```python
probs = [0.6, 0.15, 0.1, 0.15]
src = random.choices(sources, weights=probs)
```

## 五、与其他对比

- 与 课程学习调度（动态变化）对照。
- 与 合成数据陷阱与评估深入（合成占比）相关。

## 六、常见误区

- 比例偏离真实分布过远致域偏移。
- 忽视各源去重后体量变化。
