# 绿色列表水印（Green-List）

> 对应 Kirchenbauer et al., 2023 的 green/red list 方案。

## 一、背景与挑战

需在不显著改质量下，让生成文本带可验统计特征；关键在于“随机但可复现”的词汇划分。

## 二、核心原理

每步以密钥+上下文派生 PRNG，把词表按比例 $\gamma$ 划为绿名单；对绿名单 logit 加 $\delta$，鼓励多采绿词；检测端查绿词占比。

## 三、数学形式

绿名单 $G_t \sim \text{PRNG}(k, c_t)$；偏置后 $p(w)\propto e^{z_w + \delta \mathbb 1[w\in G_t]}$；绿占比期望升。

## 四、代码实现

```python
rng = seeded_rng(key, hash(context))
green = set(pick(rng, vocab, gamma=0.5))
logits[list(green)] += delta
```

## 五、与其他对比

- 最简单的水印，但对改写脆弱。
- 与 鲁棒水印 形成基线对照。

## 六、常见误区

- $\gamma$ 过大易被察觉、过小不可检。
- 固定种子不随上下文变致可预测。

## 八、面试题

- 绿名单为何靠上下文派生？答：保证同一上下文可复现划分，检测端能用相同密钥还原。

## 九、演进

静态划分 → 上下文派生 → 多层密钥。

## 十、小结

绿名单是最基础水印，简洁但需权衡可检性与鲁棒性。
