# 水印检测统计（z-test）

> 对应 Kirchenbauer et al., 2023 的检测检验。

## 一、背景与挑战

如何以统计显著性判断一段文本是否含某水印，避免误报/漏报。

## 二、核心原理

统计生成文本中绿名单 token 数；在零假设（无水印、随机均匀）下其服从二项分布，用 z 检验得 p 值，低于阈值判为含水印。

## 三、数学形式

$z = \frac{n_g - \gamma n}{\sqrt{n\gamma(1-\gamma)}}$；其中 $n_g$ 绿词数、$n$ 总长、$\gamma$ 绿比例；p 值由正态近似得。

## 四、代码实现

```python
n_g = count_green(tokens, key)
z = (n_g - gamma*N) / sqrt(N*gamma*(1-gamma))
p = 2*(1 - norm.cdf(abs(z)))
```

## 五、与其他对比

- 与 模型水印总览 的检测端对应。
- 与 检索增强失效分析深入 无关但同用统计检验思路。

## 六、常见误区

- 文本过短统计功效低（z 不稳）。
- 阈值设太低致漏报、太高致误报。

## 八、面试题

- 检测为何用 z 检验？答：绿词数在零假设下近似二项，z 值衡量偏离、p 值判显著性。

## 九、演进

比例检验 → 信息论检验 → 多假设联合。

## 十、小结

水印检测以统计检验量化置信，短文本需谨慎。
