# 鲁棒水印（抗改写）

> 对应 Kuditipudi et al., *Robust Watermarks*, 2023；Aaronson 的树状水印。

## 一、背景与挑战

绿名单水印易被释义/翻译/改写移除；鲁棒水印需在文本变动后仍能检测。

## 二、核心原理

将生成视为在共享密钥的随机树上行走，把整段文本的“绿路径”累积成可校验信号；局部改写只破坏少量节点，整体仍显著。

## 三、数学形式

路径得分 $S = \sum_{t} \mathbb 1[\text{step}_t \in \text{green}_{t}] - \gamma t$；阈值检验整体偏离，抗局部扰动。

## 四、代码实现

```python
key = derive_key(seed, doc_hash)
score = sum(step_in_green(path, key) for path in walk(text))
```

## 五、与其他对比

- 比绿名单更抗改写但实现复杂、略损质量。
- 与 语义水印 互补（语义级更抗重写）。

## 六、常见误区

- 误以为完全抗改写（强改写仍可去）。
- 树深度设错致检测不稳。

## 八、面试题

- 鲁棒水印如何抗改写？答：把信号分布到整段随机路径，局部改动不淹没整体统计偏离。

## 九、演进

绿名单 → 树路径 → 语义不变性水印。

## 十、小结

鲁棒水印以全局信号抵御局部改写，是实用化关键。
