# 模型水印总览

> 对应 Kirchenbauer et al., *A Watermark for Large Language Models*, 2023。

## 一、背景与挑战

AI 生成文本泛滥，需可检测、可溯源且基本不影响质量的标记，区分机器与人类内容。

## 二、核心原理

在生成时以密钥种子对词汇表做随机“绿名单”偏置，使生成文本在绿名单 token 上统计异常；检测端用同样密钥检验偏置强度。

## 三、数学形式

生成概率 $p'(w)\propto p(w)\cdot (1+\delta\cdot \mathbb 1[w\in G])$；检测统计绿名单占比偏离基线。

## 四、代码实现

```python
logits = model(next_ids)
green = seed_partition(vocab, prng)      # 密钥划分绿/红名单
logits[green] += delta
```

## 五、与其他对比

- 与 指令微调数据质量深入 无直接关系但共享“生成可追溯”。
- 与 流式生成与增量解码深入 兼容（token 级注入）。

## 六、常见误区

- 误以为水印绝对不可去除（实可受改写攻击）。
- $\delta$ 过大损文本质量。

## 八、面试题

- 水印基本思想？答：以密钥随机偏置绿名单 token，使生成文本在统计上可检但难察。

## 九、演进

无 → 绿名单偏置 → 鲁棒/语义水印。

## 十、小结

模型水印以统计偏置实现可溯源，是 AI 内容治理基础工具。
