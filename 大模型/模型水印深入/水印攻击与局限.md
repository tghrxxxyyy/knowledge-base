# 水印攻击与局限

> 对应水印去除与欺骗研究（释义攻击、 spoofing）。

## 一、背景与挑战

攻击者可能去水印（释义/翻译）或伪造水印（用密钥生成带印文本嫁祸），需认清边界。

## 二、核心原理

去印：释义/重写削弱统计信号；欺骗：获密钥后可批量造“带印但非本模型”文本。局限还来自短文本功效低、多模型交叉污染。

## 三、数学形式

去印后绿占比 $n_g/n \to \gamma$（趋基线），z 值坍缩至不可检；伪造文本 $z\gg$ 阈值。

## 四、代码实现

```python
paraphrased = llm(f"改写且不改意: {text}")   # 去印攻击
z2 = detect(paraphrased, key)                 # 期望下降
```

## 五、与其他对比

- 与 鲁棒水印 形成攻防闭环。
- 与 模型安全与对齐深入 共享对抗视角。

## 六、常见误区

- 以为水印可证明 authorship（仅作弱证据）。
- 密钥泄露后无任何保障。

- 水印能证明作者吗？答：不能，仅统计弱证据；密钥泄露可被伪造，须配合其他溯源。

## 九、演进

无防护 → 抗释义 → 密钥管理与可证安全。

## 十、小结

水印有现实价值但非银弹，须理解攻击面与局限。
