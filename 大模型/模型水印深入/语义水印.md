# 语义水印

> 对应语义不变水印思路（如基于释义不变的签名）。

## 一、背景与挑战

token 级水印在重写后失效；语义水印希望“意思相同的改写仍带同一标记”。

## 二、核心原理

把水印嵌在语义层：如固定若干语义槽位（主题/结构）或用嵌入空间的稳定信号；检测时重编码比对语义指纹。

## 三、数学形式

语义指纹 $f = \text{Enc}_{key}(\text{meaning}(T))\in\mathbb R^d$；相似度 $s=\cos(f, f_{ref})>\tau$ 判同源。

## 四、代码实现

```python
emb = embed(mean_pool(text))
sig = project_with_key(emb, key)      # 密钥投影得语义指纹
match = cos(sig, registered[key]) > tau
```

## 五、与其他对比

- 比 token 级更抗重写，但需稳定语义表征。
- 与 检索增强失效分析深入 共享嵌入相似度。

## 六、常见误区

- 语义表示受模型差异影响致指纹漂移。
- 阈值难定（语义近≠同源）。

## 八、面试题

- 语义水印难点？答：需在释义不变下稳定表征，且区分“同源改写”与“语义相近他文”。

## 九、演进

token 级 → 句级 → 嵌入语义指纹。

## 十、小结

语义水印面向抗重写，依赖稳定语义表征与可验证指纹。
