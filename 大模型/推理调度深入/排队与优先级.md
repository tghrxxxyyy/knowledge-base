# 排队与优先级调度

> 对应 LLM 服务队列管理。

## 一、背景与挑战

请求价值/紧急度不同，需优先级与超时控制。

## 二、核心原理

多级队列 + 优先级抢占（在连续批层）+ 超时丢弃，保障关键请求 SLO。

## 三、数学形式

等待时间 $W_i$ 受优先级权重影响；SLO 违约率作目标。

## 四、代码实现

```python
q.put(req, priority=req.tier)
batch = q.pop(max_tokens, policy="priority")
```

## 五、与其他对比

- 与 连续批处理深入（抢占）协同。
- 与 多租户与资源隔离深入 共享优先级。

## 六、常见误区

- 优先级反转致低优饿死。
- 队列无界致内存爆。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- 如何避免优先级反转？答：老化(aging)提升等待久的低优请求优先级。

## 九、演进

FIFO → 优先级 → 老化+抢占。

## 十、小结

排队与优先级保障 SLO 与公平，需防饿死。
