# 推理调度成本与SLO

> 对应成本-延迟权衡；推理经济成本深入 衔接。

## 一、背景与挑战

低成本与低延迟常冲突，需量化权衡。

## 二、核心原理

以 p99 延迟与每千 token 成本为双目标，调度在预算内优化 SLO 达标率。

## 三、数学形式

单位成本 $c = \text{GPU}\_\text{cost} / \text{tokens}$；SLO 违约罚分入目标。

## 四、代码实现

```python
if cost/token > budget: downgrade_model(req)
```

## 五、与其他对比

- 与 大模型与数据库深入 / 搜索推荐大模型深入 的线上服务共享。
- 与 推理经济成本深入 共享指标。

## 六、常见误区

- 只看均值延迟忽略 p99。
- 成本优化损及关键业务 SLO。

## 八、面试题
