# 门控与路由

> 见「稀疏专家混合深入/MoE原理」与「模型架构演进」。

## 一、背景与挑战

路由决定 token 去哪，影响质量与均衡。

## 二、核心原理

门控=线性投影+softmax/top-k；可加噪声（Noisy Top-k）、专家容量限制防超载；细粒度路由（如 DeepSeek）提升利用。

## 三、关键要点

- 容量上限防单专家爆。
- 细粒度路由更灵活。

## 四、代码实现

```python
logits = gate(x); logits += noise; idx = logits.topk(k).indices
```

## 五、与其他对比

- 粗路由简单；细粒度更强但复杂。

## 六、常见误区

- 路由越复杂越好——需稳。
