# 负载均衡

> 见「稀疏专家混合深入/门控与路由」与「训练技巧与稳定性」。

## 一、背景与挑战

门控易塌缩到少数专家，其余闲置。

## 二、核心原理

加辅助负载损失（让专家分配均匀），或用辅助损失 + 随机路由缓解；重要性采样校正偏差。

## 三、数学形式

辅助损失：

```
L_aux = α · Σ_i f_i · P_i,  f_i=分配占比, P_i=路由概率均值
```

## 四、代码实现

```python
aux = alpha * (freq * prob).sum()
loss = task_loss + aux
```

## 五、关键要点

- 失衡降效且显存浪费。
- α 需调。

## 六、与其他对比

- 无均衡→塌缩；均衡→全用。

## 七、常见误区

- 均衡损失越大越好——伤主任务。
