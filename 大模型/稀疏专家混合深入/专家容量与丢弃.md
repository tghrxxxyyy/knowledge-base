# 专家容量与丢弃

> 见「稀疏专家混合深入/门控与路由」与「推理优化」。

## 一、背景与挑战

某些专家过载会拖慢并丢 token。

## 二、核心原理

设每专家容量（token 上限），超容 token 被丢弃或走残差（残差路由），保吞吐。

## 三、关键要点

- 容量小→丢 token；大→浪费。
- 残差路由减损。

## 四、代码实现

```python
if expert_count[i] >= capacity: route_to_residual(x)
```

## 五、与其他对比

- 无容量→阻塞；容量→稳。

## 六、常见误区

- 容量越大越好——显存/算力浪费。
