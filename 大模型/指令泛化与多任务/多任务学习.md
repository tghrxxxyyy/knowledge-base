# 多任务学习

> 对应 Natural Instructions（Mishra et al., 2022）与 FLAN 多任务微调（Wei et al., 2021）。多任务混合是提升泛化最直接的手段。

## 一、背景与挑战

单任务微调容易过拟合且泛化差；多任务学习把多个相关任务混合训练，让模型学到更通用的表示。在大模型语境下，多任务主要指**指令微调阶段的任务混合**。挑战在于任务间的**负迁移**（某些任务互相干扰）、**规模失衡**（大数据集淹没小数据集）以及**灾难性遗忘**（新任务覆盖旧能力）。

## 二、核心原理

混合策略：

1. **均匀采样**：每个任务等概率，简单但会让小任务被过度采样。
2. **按规模采样**：与数据量成正比，大数据集主导。
3. **温度采样**（FLAN 做法）：设任务 $k$ 的样本数为 $n_k$，采样权重

$$w_k \propto n_k^{1/\tau},\quad \tau>1$$

$\tau$ 越大越接近均匀，能避免大数据集垄断。

缓解遗忘的常用手段：混入一定比例的通用预训练语料；降低学习率与 epoch；或用参数高效微调（LoRA）限制更新幅度。

## 三、形式化与数学基础

多任务目标：

$$\mathcal{L}=\sum_{k=1}^{K} w_k \mathcal{L}_k(\theta)$$

梯度冲突（负迁移）可用梯度余弦相似度刻画：

$$\cos(g_i,g_j)=\frac{g_i^\top g_j}{\|g_i\|\|g_j\|} < 0 \Rightarrow \text{冲突}$$

缓解方法（如 PCGrad/GradNorm）通过投影或重加权让梯度尽量不冲突。

## 四、代码实现

带温度的任务采样：

```python
import random, math
def sample_tasks(task_sizes, tau=2.0, n=1000):
    weights = [s ** (1.0 / tau) for s in task_sizes.values()]
    total = sum(weights)
    probs = [w / total for w in weights]
    return random.choices(list(task_sizes), weights=probs, k=n)
```

调大 `tau` 会让小任务获得更多采样机会，实践中需在验证集上确定。

## 五、与其他技术对比

| 策略 | 泛化 | 风险 | 适用 |
|------|------|------|------|
| 单任务微调 | 弱 | 过拟合 | 单一固定场景 |
| 多任务均匀 | 强 | 小数据重复 | 任务量适中 |
| 温度采样 | 强 | 需调参 | 规模差异大 |
| 顺序微调 | 弱 | 灾难性遗忘 | 不推荐 |

## 六、常见误区

- 任务越多越好：低质量或冲突任务会负迁移。
- 直接按数据量混合：大数据集会淹没小任务。
- 多轮微调不做遗忘检查：应在旧任务上回归测试。
- 忽略任务格式统一：格式不一致会让模型学偏。

## 九、演进与趋势

从「堆任务数量」转向「精选任务 + 难度分层」；任务路由与专家混合（MoE）让不同任务走不同通路；持续学习技术缓解顺序训练的遗忘。

## 十、小结

多任务学习的关键是采样权重（温度采样）、格式统一与遗忘防护。任务质量与配比，比单纯堆数量更能决定最终泛化水平。
