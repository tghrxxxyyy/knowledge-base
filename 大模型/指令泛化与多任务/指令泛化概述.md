# 指令泛化概述

> 对应 FLAN / T0 / llm-course「Instruction tuning」。

## 一、背景与挑战

预训练模型学会「预测下一个词」，但不懂「按指令做事」。指令微调让模型学会遵循多样指令格式，获得零样本泛化(未见过的任务也能做)。

## 二、核心原理

用大量「(指令, 输出)」对微调，模型学到「指令→行为」的映射，而非记忆特定任务。FLAN 证明把 NLU 任务用自然语言模板改写为指令，统一微调可显著提升泛化。

## 三、数学形式

与 SFT 同损失(见指令微调SFT)，区别在于数据覆盖极多任务类型。

## 四、关键要点

| 要素 | 作用 |
|------|------|
| 任务多样 | 泛化 |
| 模板丰富 | 鲁棒 |
| 难例 | 提质 |

## 五、常见误区

- 单一任务 SFT 不等于指令泛化。
- 模板单一易过拟合格式。

## 六、与开源书对应

- Wei et al., *FLAN*, 2022; Sanh et al., *T0*, 2022.
- llm-course「Instruction fine-tuning」。

## 七、面试题

- 为何多任务指令微调能提升零样本泛化？

## 八、演进

FLAN → FLAN-T5(扩大任务) → 与 RLHF 结合成对话模型。

## 九、小结

指令泛化是「预训练→通用助手」的关键桥接。
