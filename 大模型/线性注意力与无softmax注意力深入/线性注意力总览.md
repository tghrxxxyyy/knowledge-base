# 线性注意力总览

> 对应 Katharopoulos et al., 2020 (Linear Attention); Choromanski 2021 (Performer); d2l-ai/d2l-zh 第11章。

## 一、背景与挑战
标准 softmax 注意力 $O(L^2 d)$ 的复杂度随序列长度平方增长，长上下文与高分辨率输入下成为瓶颈。线性注意力用核函数 $\phi$ 将 softmax 分解，使注意力矩阵可结合律重排为 $\phi(Q)(\phi(K)^\top V)$，把 $O(L^2 d)$ 降到 $O(L d^2)$。

## 二、核心原理
令 $\phi$ 为逐元素的特征映射，将 $\text{sim}(q_i, k_j) = \exp(q_i^\top k_j / \sqrt d)$ 近似为 $\phi(q_i)^\top \phi(k_j)$。这样 $\text{Attn}(Q,K,V)_i = \phi(q_i)^\top \sum_j \phi(k_j) v_j^\top$，可预计算 $S = \sum_j \phi(k_j) v_j^\top \in \mathbb{R}^{d \times d}$。

## 三、形式化与数学基础
$ \phi(q_i)^\top \sum_j \phi(k_j) v_j^\top = \phi(q_i)^\top \cdot S$，其中 $S = \phi(K)^\top V$。因果版本需在递推中维护 $S_t = S_{t-1} + \phi(k_t) v_t^\top$。

## 四、代码实现
```python
# 线性注意力前向
phi = lambda x: torch.nn.functional.elu(x) + 1  # 正特征映射
K_phi = phi(K)            # (L, d)
V_ = V                     # (L, d)
S = K_phi.transpose(0,1) @ V_  # (d, d)
out = phi(Q) @ S          # (L, d)
```

## 五、与其他技术对比
- vs 标准注意力：复杂度 $O(Ld^2)$ vs $O(L^2 d)$，但核近似有误差。
- vs FlashAttention：后者保持 softmax 精确，仅优化 IO；线性注意力牺牲一定精度换复杂度。
- vs 状态空间模型（Mamba）：两者均线性复杂度，线性注意力基于核近似，Mamba 基于选择性状态。

## 六、常见误区
- 误以为所有 $\phi$ 都能逼近 softmax；elu+1 等正特征映射在低秩处偏差大。
- 忽略归一化：$\phi(Q)(\phi(K)^\top \mathbf{1})$ 作为分母，未做数值稳定。
- 因果掩码未在递推 $S_t$ 中正确维护会致信息泄漏。

## 八、面试题
- 线性注意力的复杂度是多少？答：$O(Ld^2)$，与 $L$ 线性相关。
- 为什么能用结合律？答：softmax 不可拆，但用核 $\phi$ 把 $\exp$ 拆为 $\phi(q)\phi(k)$ 后 $\phi(K)^\top V$ 可预计算。

## 九、演进与趋势
softmax 注意力 → 核近似（Performer/Linear Transformer）→ 状态空间（Mamba/RWKV）→ 线性+稀疏混合。

## 十、小结
线性注意力以核近似打破 softmax 的 $O(L^2)$ 瓶颈，是长上下文建模的重要技术路线之一。
