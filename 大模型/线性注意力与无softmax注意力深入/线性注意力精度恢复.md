# 线性注意力精度恢复

> 对应 Han et al., 2023 *FLatten Transformer*; Chen et al., 2024 *Gated Linear Attention*。

## 一、背景与挑战
线性注意力相对标准 softmax 注意力通常精度低 1-3 个点。如何在保持线性复杂度的同时恢复精度是核心问题。

## 二、核心原理
两个代表方向：(1) 门控机制（GLA、Mamba 类似），用输入依赖的门控调节信息流；(2) 局部-全局混合（FLatten、Mamba），短程用局部卷积/RWKV 风格，长程用线性注意力。

## 三、形式化与数学基础
门控线性注意力：$ S_t = g_t \odot S_{t-1} + \phi(k_t) v_t^\top $，$ g_t = \sigma(W_g x_t) \in (0,1)^d $。门控 $g_t$ 让模型自适应地遗忘/保留。

## 四、代码实现
```python
# 门控线性注意力递推
S = torch.zeros(d, d)
for t in range(L):
    g = torch.sigmoid(Wg @ x[t])
    S = g[:,None] * S + phi(K[t])[:,None] * V[t][None,:]
    out[t] = phi(Q[t]) @ S
```

## 五、与其他技术对比
- vs Mamba：GLA 是逐通道门控，Mamba 是逐通道状态转移矩阵。
- vs 纯线性注意力：精度显著提升，复杂度仍 $O(Ld^2)$。

## 六、常见误区
- 门控初始化为 0 会导致初期信息全丢；应初始化接近 1。
- 局部与全局分支权重需仔细调节，避免一者压倒另一者。

## 七、与开源书/权威来源对应
- bojone/bert4keras 中 GLA 讨论。
- iclr2024 GLA 论文仓库。

## 八、面试题
- 门控为什么能恢复精度？答：让模型自适应地选择保留/丢弃历史，避免固定衰减的过衰减或欠衰减。

## 九、演进与趋势
线性注意力 → 门控线性注意力 → 选择性状态空间 → 局部-全局混合。

## 十、小结
门控与混合是线性注意力恢复精度的两条主要路径，与 SSM 思路殊途同归。
