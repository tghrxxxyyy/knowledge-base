# 核特征映射与正定性

> 对应 Katharopoulos 2020; Choromanski 2021 (FAVOR+)。

## 一、背景与挑战
线性注意力的核心是 $\phi$ 的设计。$\phi$ 需要把 $q_i^\top k_j$ 的 softmax 行为近似出来，同时保持正定性以保证 $\phi(q)^\top \phi(k) \ge 0$。

## 二、核心原理
正特征映射满足 $\phi(x) \ge 0$（逐元素），保证注意力权重非负。常用：$\phi(x) = \text{elu}(x)+1$、$\phi(x) = \text{relu}(x)$、或随机特征（FAVOR+）$\phi(x) = \exp(-\|x\|^2/2)/\sqrt{m} \cdot [\exp(\omega_r^\top x); \cos(\omega_r^\top x); \sin(\omega_r^\top x)]$。

## 三、形式化与数学基础
FAVOR+ 用正定核 $K(x,y) = \exp(-\|x-y\|^2/2) = \mathbb{E}[\phi_\omega(x) \phi_\omega(y)]$，随机 $\omega \sim \mathcal{N}(0,I)$，$m$ 个采样做蒙特卡洛近似。

## 四、代码实现
```python
# FAVOR+ 随机特征
omega = torch.randn(m, d) / math.sqrt(d)
phi = torch.cat([torch.exp(-0.5*Q.pow(2).sum(-1,keepdim=True))*torch.cos(Q @ omega.T),
                 torch.exp(-0.5*Q.pow(2).sum(-1,keepdim=True))*torch.sin(Q @ omega.T)], dim=-1) / math.sqrt(m)
```

## 五、与其他技术对比
- elu+1 简单但偏差大；FAVOR+ 理论无偏但需更多特征 $m$。
- 相比精确 softmax，核方法总引入方差，需多次采样或大 $m$ 才能稳定。

## 六、常见误区
- 用 $\phi(x)=\text{relu}(x)$ 直接代替 $\phi$ 而不处理零值，造成大量 $\phi=0$。
- 随机特征维数 $m$ 选太小致方差爆炸。

## 八、面试题
- 为什么要正特征映射？答：保证 $\phi(q)^\top \phi(k)\ge 0$，使注意力权重可解释为概率。

## 九、演进与趋势
手工 $\phi$ → 随机特征 → 学习 $\phi$（Performers 后续、cosFormer）→ 与 SSM 融合。

## 十、小结
核特征映射是线性注意力精度的关键，FAVOR+ 等正定核在理论无偏与工程高效间取得平衡。
