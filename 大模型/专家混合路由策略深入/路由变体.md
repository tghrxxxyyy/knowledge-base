# 路由变体

> 对应 Fedus et al., *Switch Transformers*, 2021；以及 GShard 的专家分组、ST-MoE 等。

## 一、背景与挑战

朴素 Top-k 路由有不均与通信开销；衍生多种变体改善专业化、稳定与分布式效率。

## 二、核心原理

包括 Switch(Top-1)、分组路由（每组内选专家）、噪声路由（训练加噪助探索）、专家选择（专家挑 token，省 padding）等。

## 三、数学形式

分组路由：仅在第 $g(x)$ 组内做 Top-k；专家选择：专家 $e$ 选其 Top-$c$ token，密度 $c\cdot E/T$ 恒定。

## 四、代码实现

```python
group = x.device_group
local_idx = router(x_in_group).topk(k)
```

## 五、与其他对比

- 专家选择路由反向分配，避免 token 丢弃、利于密度恒定。
- 与 专家混合路由策略深入 总览/负载均衡互补。

## 六、常见误区

- 把分组路由当全局路由，限制专家组合灵活性。
- 噪声路由只在训练用，推理须关。

## 八、面试题

- 专家选择路由优点？答：专家主动挑固定量 token，密度恒定、无丢弃、并行规整。

## 九、演进

Top-k → Switch → 分组/专家选择 → 细粒度（细专家数更多）。

## 十、小结

路由变体围绕均衡、专业化与分布式效率演进，细粒度是近期趋势。
