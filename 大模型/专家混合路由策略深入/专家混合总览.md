# 专家混合总览

> 对应 Shazeer et al., *Outrageously Large Neural Networks: The Sparsely-Gated MoE*, ICLR 2017。

## 一、背景与挑战

模型增大提升质量但算力线性增；MoE 用多个专家 FFN + 路由，仅激活部分专家，实现参数与计算解耦。

## 二、核心原理

每层含 $E$ 个专家 FFN，路由器按 token 选 Top-k 专家计算并加权聚合，使参数量大而每 token 计算小。

## 三、数学形式

$y=\sum_{e\in \text{TopK}(r(x))} g_e(x)\,E_e(x)$，$r$ 为路由 logits，$g_e$ 为门权重（softmax over 选中专家）。

## 四、代码实现

```python
scores = router(x)            # [E]
idx = scores.topk(k).indices
y = sum(g[i] * experts[i](x) for i in idx)
```

## 五、与其他对比

- 与 门控线性单元与激活变体深入 的门不同：MoE 是离散专家选择而非连续通道门。
- 与 稀疏注意力算法深入 都“稀疏”但作用于不同维度（专家 vs 注意力对）。

## 六、常见误区

- 认为 MoE 总省算力；参数与显存随专家数线性增，仅 FLOPs/token 降。
- 忽略路由不均导致部分专家饿死。

## 八、面试题

- MoE 为何参数大却快？答：每 token 只激活 Top-k 专家，参数量与计算量解耦。

## 九、演进

稠密 → 软专家（Mixture of Experts）→ 稀疏 Top-k 路由（Shazeer 2017）。

## 十、小结

MoE 以稀疏专家激活换取参数规模扩大而控制单 token 计算，是大模型扩容关键。
