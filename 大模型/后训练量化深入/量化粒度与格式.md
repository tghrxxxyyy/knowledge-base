# 量化粒度与数值格式

> 对应 Dettmers et al., *QLoRA*, 2023（NF4）；权重/激活格式谱系。

## 一、背景与挑战

不同位宽与粒度组合在精度/速度/显存间权衡；需按硬件选格式。

## 二、核心原理

常见：W8A8（推理快）、W4A16（省显存）、W4A4（极致压缩）；格式有 INT4/INT8、NF4（对正态分布最优的信息论 4bit）。

## 三、数学形式

NF4 在区间 $[-v,v]$ 取 $2^4$ 个分位数点，使 $\mathbb E[\text{quant\_err}]$ 最小；group_size $g$ 控制每 $g$ 权重共享缩放。

## 四、代码实现

```python
cfg = BitsAndBytesConfig(load_in_4bit=True, bnb_4bit_compute_dtype=torch.float16,
                         bnb_4bit_quant_type="nf4", bnb_4bit_use_double_quant=True)
```

## 五、与其他对比

- 双重量化（double quant）进一步压缩放因子显存。
- 与 参数高效微调深入（QLoRA）直接结合。

## 六、常见误区

- 误用 INT4 当 NF4 处理正态分布权重，误差更大。
- group_size 太小增开销、太大降精度。

## 八、面试题

- 问：NF4 相比 INT4 优势？答：NF4 依权重正态分位划分，信息论最优，4bit 下误差更小。

## 九、演进

INT8 → INT4 → NF4 → 混合格式（MoE 专家分精度）。

## 十、小结

量化粒度与格式是精度/效率旋钮，NF4+group 是当前 4bit 标配。
