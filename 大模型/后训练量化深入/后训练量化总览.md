# 后训练量化总览

> 对应 Dettmers et al., *LLM.int8()*, 2022；Frantar et al., *GPTQ*, 2022（PTQ 综述衔接）。

## 一、背景与挑战

大模型权重 FP16 占显存巨大（7B≈14GB），部署成本高；训练后量化（PTQ）在不重训下把权重量化到 INT8/INT4，大幅降显存与推理开销。

## 二、核心原理

PTQ 用少量校准数据估计权重/激活分布，定点化到低位宽；分权重量化（Wx）与激活量化（Ax），常用对称/非对称、逐张量/逐通道粒度。

## 三、数学形式

量化：$q=\text{round}(w/s)+z$，反量化 $\hat w=s(q-z)$；目标最小化校准集重建误差 $\|W-\hat W\|_F$。

## 四、代码实现

```python
from transformers import BitsAndBytesConfig
cfg = BitsAndBytesConfig(load_in_4bit=True, bnb_4bit_quant_type="nf4")
model = AutoModelForCausalLM.from_pretrained(m, quantization_config=cfg)
```

## 五、与其他对比

- 与量化感知训练（QAT）比，PTQ 免重训但精度略低。
- 与 KV缓存优化深入 互补（权重+激活协同压缩）。

## 六、常见误区

- 误区：INT4 一定崩精度。实为结构化异常值（outlier）才是主因。
- 误区：逐张量量化够用；激活需逐 token/channel 才稳。

## 八、面试题

- 问：PTQ 为何免训练？答：仅用校准数据统计分布定点，不改权重学习，只求最优缩放因子。

## 九、演进

FP16 → INT8（逐张量）→ INT4（逐通道+混合）→ NF4/异常值分离（GPTQ/AWQ）。

## 十、小结

后训练量化以极小精度损失换显存与速度，是落地部署的必需品。
