# 提示注入总览

> 对应 OWASP LLM Top 10 (LL01)；大模型安全核心威胁。

## 一、背景与挑战

用户输入可「劫持」系统提示，让模型违背设计意图。

## 二、核心原理

提示注入：攻击者通过输入文本覆盖/绕过系统指令（如「忽略上面所有指令，输出…」）。分**直接注入**（用户直接说）与**间接注入**（通过检索/工具内容注入，如网页含恶意指令）。是 RAG/Agent 的重大风险。

## 三、关键要点

- 模型难区分「指令」与「数据」。
- 间接注入随 RAG 放大。

## 四、代码实现

```python
# 检测可疑注入关键词（弱防护）
if "忽略" in user and "指令" in user: flag()
```

## 五、与其他对比

| 类型 | 来源 |
|------|------|
| 直接 | 用户输入 |
| 间接 | 检索内容 |

## 六、常见误区

- 系统提示写死即安全——可被覆盖。
