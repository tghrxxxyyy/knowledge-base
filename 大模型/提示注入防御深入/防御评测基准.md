# 防御评测基准

> 见「提示注入防御深入/提示注入总览」与「模型评测深入」；以攻促防。

## 一、背景与挑战

防御是否有效，需量化。

## 二、核心原理

用攻击基准（如 InjecAgent、PromptBench、红队数据集）测防御下的攻击成功率（ASR）。指标：ASR 越低越好；也测**过度拒答率**（防御过强误伤正常）。权衡安全与可用。

## 三、关键要点

- 看 ASR 而非有无用例。
- 防误伤（假阳性）同样重要。

## 四、代码实现

```python
asr = attacked_success / total_attacks
far = false_refuse / benign
```
