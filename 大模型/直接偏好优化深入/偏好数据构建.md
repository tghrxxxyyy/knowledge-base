# DPO偏好数据构建

> 对应偏好数据集构建；指令数据构建深入 / 训练数据质量 衔接。

## 一、背景与挑战

DPO 质量高度依赖偏好对（chosen/rejected）质量与覆盖。

## 二、核心原理

来源：人工标注、AI 反馈（RLAIF）、模型自生成对（同一 prompt 多采样选优劣）、规则构造。

## 三、数学形式

数据 $D=\{(x,y_w,y_l)\}$；需 $y_w\succ y_l$ 一致且覆盖多样指令。

## 四、代码实现

```python
pairs = [(x, better(r1,r2), worse(r1,r2)) for x,r1,r2 in samples]
```

## 五、与其他对比

- 与 奖励模型深入（同依赖偏好数据）共享。
- 与 数据高效学习深入（数据质量）衔接。

## 六、常见误区

- 偏好对差异太小（模型难学）或太大（易被捷径）。
- 标注偏见致对齐偏移。

## 八、面试题

- 偏好对如何构造？答：AI反馈/自生成多采样/人工，需差异适中且覆盖多样。

## 九、演进

人工 → AI 反馈(RLAIF) → 合成偏好规模化。

## 十、小结

偏好数据质量决定 DPO 上限，构建需差异适中且多样。
