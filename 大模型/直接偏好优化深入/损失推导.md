# DPO损失推导

> 对应 DPO 原文理论。

## 一、背景与挑战

理解 DPO 为何等价于 RLHF 但形式简单。

## 二、核心原理

从 KL 约束奖励最大化出发，将最优策略表为奖励的 Boltzmann 形式，消去奖励得仅含策略比的损失。

## 三、数学形式

奖励重参数：$r(x,y)=\beta\log\frac{\pi^*(y|x)}{\pi_{ref}(y|x)}+\beta\log Z(x)$；代入 Bradley-Terry 得 DPO 损失。

## 四、代码实现

```python
# 实践中直接优化如下
logits = beta*(logp_w - logp_ref_w - logp_l + logp_ref_l)
loss = -F.logsigmoid(logits).mean()
```

## 五、与其他对比

- 与 PPO对齐深入（RLHF 视角）对照理论。
- 与 奖励模型深入（被消去的对象）对照。

## 六、常见误区

- 误以为 DPO 完全不需参考模型；$\pi_{ref}$ 必不可缺。
- 忽视 $\beta$ 与 RLHF 中 KL 系数对应关系。

## 八、面试题

- DPO 中参考模型作用？答：提供分布锚点，约束策略不偏离过多（等效 KL）。

## 九、演进

理论推导 → 实用实现 → 去参考变体（ORPO）。

## 十、小结

DPO 借重参数化把奖励消去，理论优雅、实现简洁。
