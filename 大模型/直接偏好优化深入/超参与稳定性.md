# DPO超参与稳定性

> 对应训练经验；与 训练不稳定诊断深入 / 数值稳定性深入 衔接。

## 一、背景与挑战

DPO 对 $\beta$、学习率、参考模型同步敏感，易训崩。

## 二、核心原理

$\beta$ 控 KL 强度；参考模型冻结为旧权重；学习率较 SFT 小；梯度易因概率比大而不稳。

## 三、数学形式

$\beta$ 小→强偏偏好数据、易过拟合；大→接近参考、保守。

## 四、代码实现

```python
loss = dpo_loss(beta=0.1, lr=1e-6)
```

## 五、与其他对比

- 与 PPO对齐深入（同属对齐，超参不同）对照。
- 与 参数高效微调深入（可 LoRA 做 DPO）衔接。

## 六、常见误区

- $\beta$ 误设致答案质量与偏好失衡。
- 参考模型与策略未同设备致数值差。

## 八、面试题

- $\beta$ 作用？答：控制与参考模型的偏离度，等效 RLHF 的 KL 系数。

## 九、演进

经验调 → 自动化搜索 → 自适应 $\beta$。

## 十、小结

DPO 稳定性靠 $\beta$ 与参考锚定，需谨慎调参。
