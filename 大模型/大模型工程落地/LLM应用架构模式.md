# LLM 应用架构模式

> 从原型到生产的架构演进。

## 一、核心概念

典型分层：接入层(API/网关) → 编排层(Chain/Agent) → 模型层(推理服务) → 数据层(向量库/缓存) → 观测层(日志/追踪/评测)。模式：检索增强、工具调用、多 agent、human-in-the-loop。

## 二、关键要点

| 层 | 关注 |
|----|------|
| 接入 | 限流/鉴权 |
| 编排 | 可控/可观测 |
| 模型 | 高可用 |
| 数据 | 质量/权限 |
| 观测 | 评测/追踪 |
