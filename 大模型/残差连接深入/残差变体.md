# 残差变体

> 见「残差连接深入/残差连接总览」；不同残差设计。

## 一、背景与挑战

基础残差并非唯一形式。

## 二、核心原理

- **DenseNet**：所有层互连（特征复用）。
- **Highway/Skip**：带门控的残差。
- **Transformer Pre/Post-LN**：归一化变体。
- **ReZero**：可学习残差缩放初始为 0，渐进开启。
各变体在稳定/容量/效率间取舍。

## 三、关键要点

- ReZero 免 warmup。
- DenseNet 参数/显存高。

## 四、代码实现

```python
out = alpha * sublayer(x) + x   # ReZero 中 alpha 可学
```
