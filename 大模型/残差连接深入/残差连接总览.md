# 残差连接总览

> 对应 d2l-zh 与 He et al., *ResNet*, 2016；是深层网络的基石。

## 一、背景与挑战

网络越深越难训：梯度消失/退化（深层精度反降）。

## 二、核心原理

残差块：`y = F(x) + x`（跳跃连接）。使网络只需学残差 F(x)=y-x，恒等映射易学；反向梯度可直接经 skip 回流，缓解消失。是 ResNet/Transformer（每子层后残差）的核心。

## 三、数学形式

`h_l = f_l(h_{l-1}) + h_{l-1}`（Transformer 风格）。

## 四、代码实现

```python
out = sublayer(x) + x; out = norm(out)   # Pre-LN 风格
```

## 五、关键要点

- 残差让深层可训。
- 现代 Transformer 几乎全用。

## 六、与其他对比

- plain 深层退化；残差不退化。

## 七、常见误区

- 残差万能——仍需归一化配合。
