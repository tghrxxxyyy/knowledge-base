# 残差与表征传播

> 见「残差连接深入/残差连接总览」与「注意力数学基础/注意力低秩与秩崩溃」。

## 一、背景与挑战

残差不仅稳训练，还影响表征质量。

## 二、核心原理

残差使各层表征可「绕过」直接传递，形成多尺度特征融合；也缓解深层表征趋同（秩崩溃）。研究表明残差路径保住了浅层信息，使深层仍含多样特征。

## 三、关键要点

- 残差=信息高速公路。
- 与 MLP/注意力互补。

## 四、代码实现

```python
feats = []; h = x
for blk in blocks: h = blk(h); feats.append(h)
```

## 五、与其他对比

- plain 信息逐层压缩；残差保真。

## 六、常见误区

- 残差只稳训练——也利表征。
