# 残差缩放与 DeepNorm

> 见「残差连接深入/残差连接总览」与「Pre-LN与Post-LN」；稳定极深网络。

## 一、背景与挑战

千层以上网络即便 Pre-LN 也可能不稳。

## 二、核心原理

**DeepNorm**（Wang et al., 2022）对残差分支做 `α` 缩放、对输出做 `β` 缩放，使深层梯度范数有界，可稳定训练 1000 层。本质是平衡残差与恒等路径的幅度，防激活爆炸/消失。

## 三、数学形式

`x_{l+1} = LN(α x_l + F(x_l)) · β^{-1}`（简化），α,β 依深度设。

## 四、代码实现

```python
x = LN(alpha * x + F(x)) / beta
```

## 五、关键要点

- 极深模型（>100 层）才必要。
- 缩放系数依深度推导。

## 六、与其他对比

- Pre-LN 一般深够用；DeepNorm 为超深。

## 七、常见误区

- 浅模型也需 DeepNorm——过度。
