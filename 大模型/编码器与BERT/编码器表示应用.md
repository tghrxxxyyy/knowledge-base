# 编码器表示的工程应用

> 对应 Reimers & Gurevych, *Sentence-BERT (SBERT)*, 2019；以及 BERT 表示各向异性研究（Ethayarajh, 2019）。

## 一、背景与挑战

BERT 预训练产出的 token 级表示质量高，但「如何得到好句向量」并非天然解决。直接用 `[CLS]` 或全序列均值得到的句向量存在严重**各向异性（anisotropy）**——向量聚集在狭窄锥体内、余弦相似度区分度低，直接用于语义检索/聚类效果远差于朴素词袋。工程上需要「高质量、可快速比对」的句子/文档嵌入，支撑检索、去重、分类、聚类等场景。

## 二、核心原理

核心思路是把「句向量质量」交还给一个**有监督/对比式微调**阶段：

- **池化（pooling）**：对 token 表示做 mean-pooling（通常优于 `[CLS]`）或 max-pooling 得到句向量。
- **对比微调（SBERT）**：用孪生（siamese）或三元（triplet）网络，在「句对相似度」数据上用余弦相似 + 边际损失训练，使语义相近句向量靠近、相远句向量远离。
- **各向异性缓解**：可通过后处理（如白化 Whitening、PromptBERT）或训练中约束改善向量分布。

由此得到的句向量可直接用余弦相似度做大规模近邻检索（ANN）。

## 三、形式化与数学基础

余弦相似度：

$$
\cos(u,v) = \frac{u^\top v}{\|u\|\,\|v\|}
$$

SBERT 三元组损失（triplet loss）以锚 $a$、正例 $p$、负例 $n$ 与边际 $\epsilon$：

$$
\mathcal{L}_{\text{triplet}} = \max\!\big(0,\; \|f(a)-f(p)\|^2 - \|f(a)-f(n)\|^2 + \epsilon\big)
$$

池化（mean-pooling）对长度 $T$ 的隐藏序列 $H\in\mathbb{R}^{T\times d}$：

$$
v = \frac{1}{T}\sum_{t=1}^{T} H_t
$$

白化后处理用协方差 $C$ 与特征值分解做线性变换，缓解各向异性（突现词频主导方向）。

## 四、代码实现

用 `sentence-transformers` 做句向量与检索：

```python
from sentence_transformers import SentenceTransformer, util

model = SentenceTransformer("BAAI/bge-large-zh-v1.5")
queries = ["如何训练语言模型？", "深度学习是什么？"]
corpus  = ["语言模型预训练方法综述", "神经网络基础教程", ...]

q_emb = model.encode(queries, normalize_embeddings=True)
c_emb = model.encode(corpus, normalize_embeddings=True)

# 余弦近邻（用 faiss 可扩展到百万级）
scores = util.cos_sim(q_emb[0], c_emb)[0]
topk = scores.topk(5)
print("最相关文档:", [corpus[i] for i in topk.indices])
```

## 五、与其他技术对比

| 方法 | 句向量质量 | 是否需微调 | 适用 |
|------|-----------|------------|------|
| BERT `[CLS]` 直接取 | 差（各向异性） | 否 | 不推荐检索 |
| BERT mean-pooling | 中 | 否 | 弱检索 |
| SBERT/句向量模型 | 优 | 是 | 检索/聚类 |
| 交叉编码器 | 最优 | 是 | 重排 |

## 六、常见误区

- 「BERT 原生 `[CLS]` 可直接做语义检索」：错误，各向异性导致区分度低。
- 「mean-pooling 一定优于 `[CLS]`」：通常是，但长文档需分段/加权。
- 「句向量无需训练」：无监督池化远不如对比微调的 SBERT/bge。
- 「向量维度越高越好」：高维未必信息更丰富，还需配合索引与归一化。

## 九、演进与趋势

从 SBERT 到大规模句向量模型（SimCSE 对比学习、BGE、E5、GTE），并引入「指令式检索（instruction-tuned embedding）」；与 RAG 深度绑定成为检索器标配。后处理（Whitening、归一化）与训练（难负例挖掘、动量对比）持续提升区分度；多语言、长文档、代码检索是活跃方向。

## 十、小结

编码器表示落地需把「句向量质量」交还对比微调：mean-pooling + SBERT 式训练得到可检索的高质量嵌入，原生 `[CLS]` 因各向异性不宜直接用于检索。最新模型（BGE 等）与 MTEB 基准以官方仓库为准。
