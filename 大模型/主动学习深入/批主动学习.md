# 批主动学习

> 见「主动学习深入/主动学习总览」；异步标注需一次选一批。

## 一、背景与挑战

实时标注慢，需每轮选一**批**而非单点。

## 二、核心原理

批内须**去冗余**：在不确定性基础上加多样性约束（聚类/行列式点过程 DPP/ K-means++ 式）。避免一批都来自同一难簇。

## 三、关键要点

- 批越大，多样性越重要。
- 可用贪心+边际效用下降。

## 四、代码实现

```python
selected = []
while len(selected) < B:
    cand = argmax(uncert - max_sim(selected))
    selected.append(cand)
```

## 五、与其他对比

- 单点简单；批需去冗余。

## 六、常见误区

- 批内直接取 Top-K 不确定——高度冗余。
