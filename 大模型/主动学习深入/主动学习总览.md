# 主动学习总览

> 对应 d2l-zh 与 Settles, *Active Learning*, 2009；综述。

## 一、背景与挑战

标注预算有限，应标哪些样本价值最高？

## 二、核心原理

循环：模型在已标数据训练 → 用**采样策略**挑「最有信息量」未标样本 → 专家标注 → 加入。目标：用最少标注达到目标性能。

## 三、关键要点

- 选样策略决定效率。
- 需人机协作闭环。

## 四、代码实现

```python
for _ in range(budget):
    idx = query_strategy(model, pool)
    label(idx); update(model)
```

## 五、与其他对比

| 策略 | 选什么 |
|------|--------|
| 不确定性 | 模型最不确定 |
| 多样性 | 覆盖分布 |
| 期望增益 | 降泛化误差最多 |

## 六、常见误区

- 随机标注最优——主动选样省 30~50% 标注。
