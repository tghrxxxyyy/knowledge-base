# 不确定性采样

> 见「主动学习深入/主动学习总览」；Lewis & Catlett, *Query by Committee*, 1994。

## 一、背景与挑战

如何量化「模型最不确定」的样本？

## 二、核心原理

- **Least Confidence**：选预测置信度最低者。
- **Margin**：选 top-2 概率差最小者（最犹豫）。
- **Entropy**：选预测熵最高者。
- **委员会（QBC）**：多模型投票最不一致者。
适用于分类；回归可用预测方差。

## 三、数学形式

熵 `H = -Σ p_i log p_i`，取最大。

## 四、代码实现

```python
p = softmax(model(xu))
score = -p.max(1)          # least confidence
idx = score.argmax()
```

## 五、关键要点

- 需模型已较好校准（否则不确定不可信）。
- 高不确定≠高价值（可能离群噪声）。

## 六、与其他对比

- 不确定性看单点；多样性看整体覆盖。

## 七、常见误区

- 最不确定必最值——可能离群。
