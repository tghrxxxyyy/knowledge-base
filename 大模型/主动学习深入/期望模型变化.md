# 期望模型变化采样

> 见「主动学习深入/主动学习总览」；知识预期（Expected Model Change）。

## 一、背景与挑战

不确定 ≠ 对模型提升最大。

## 二、核心原理

**Expected Gradient Length (EGL)**：选标注后使梯度范数期望最大（即最能改变模型）的样本。直觉：标注后模型「学得最多」。变体：预期误差下降（ELU）、方差降低。

## 三、数学形式

`score(x) = E_{y}[ ||∇_θ L(θ; x, y)|| ]`，取最大。

## 四、代码实现

```python
# 对可能的 y 加权梯度长度
g = sum_y p(y|x) * grad(loss(x,y))
score = g.norm()
```
