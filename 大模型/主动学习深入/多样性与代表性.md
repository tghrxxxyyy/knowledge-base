# 多样性与代表性采样

> 见「主动学习深入/主动学习总览」；代表性：仅不确定性会聚同一区域，需兼顾覆盖。

## 一、背景与挑战

只选不确定样本会扎堆，浪费预算。

## 二、核心原理

**核心集（Core-set）/ 代表性**：选能代表整个未标池分布的样本（如 k-center、最大覆盖）。**多样性 + 不确定性**组合（如 BADGE）兼顾二者：用梯度嵌入做聚类选多样且高影响样本。

## 三、数学形式

k-center：`min_S max_x min_{s∈S} d(x,s)`，S 为所选。

## 四、代码实现

```python
# 用表征聚类的代表性采样
centers = kcenter(embs_pool, budget)
```

## 五、关键要点

- 单一不确定性易冗余。
- 批主动学习需多样性避免重复。

## 六、与其他对比

- 不确定重信息量；多样重覆盖。

## 七、常见误区

- 只追不确定——样本趋同。
