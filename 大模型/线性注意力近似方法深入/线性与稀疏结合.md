# 线性与稀疏结合

> 综合现代高效 Transformer 设计；探讨线性近似与结构化稀疏互补。

## 一、背景与挑战

纯线性损质量、纯稀疏有 IO 瓶颈；结合二者取长补短是实用方向。

## 二、核心原理

部分层用线性注意力降长序列开销，部分层用稀疏/softmax 保留关键聚焦；或在同一层把二者输出门控融合。

## 三、数学形式

$y=(1-\lambda)\,\text{SparseAttn}(Q,K,V)+\lambda\,\text{LinAttn}(Q,K,V)$，门 $\lambda$ 可学或按层固定。

## 四、代码实现

```python
y = (1 - lam) * sparse_attn(q, k, v) + lam * linear_attn(q, k, v)
```

## 五、与其他对比

- 与 稀疏注意力算法深入、状态空间对偶与Mamba2深入 同属高效序列建模，可级联。
- 与 专家混合路由策略深入 的路由思想可类比（选哪条路径）。

## 六、常见误区

- 简单加权未必最优，需按层/头分配角色。
- 融合增实现复杂度，需验证收益覆盖成本。

## 七、与开源书对应

## 八、面试题

- 为何线性与稀疏结合？答：线性管长程低成本、稀疏管聚焦高质量，互补覆盖不同尺度。

## 九、演进

单一近似 → 混合头 → 分层/门控融合架构。

## 十、小结

线性与稀疏结合在效率-质量 Pareto 前沿上取得更好平衡，是工程常用范式。
