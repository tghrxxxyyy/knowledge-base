# 线性注意力总览

> 对应 Katharopoulos et al., *Transformers are RNNs: Fast Autoregressive Transformers with Linear Attention*, 2020。

## 一、背景与挑战

标准 softmax 注意力 $O(n^2)$；线性注意力用核特征映射把注意力重排为可结合律计算，降到 $O(n)$。

## 二、核心原理

把 $\mathrm{softmax}(QK^\top)V$ 近似为 $\phi(Q)(\phi(K)^\top V)$；先算 $S=\phi(K)^\top V$（与 $n$ 无关），再乘 $\phi(Q)$，复杂度线性。

## 三、数学形式

$\text{LinAttn}(Q,K,V)=\phi(Q)\big((\phi(K)^\top V)\big)$，其中 $\phi$ 为正定核映射，如 $\phi(x)=\mathrm{elu}(x)+1$。

## 四、代码实现

```python
Q, K, V = phi(q), phi(k), v
S = K.transpose(-2,-1) @ V      # [d, d]，与序列长无关
y = (Q @ S)
```

## 五、与其他对比

- 与 稀疏注意力算法深入 都降复杂度，但线性注意力改数学形式而非掩码。
- 与 状态空间对偶与Mamba2深入 共享低秩/半可分本质。

## 六、常见误区

- 以为线性注意力质量等同 softmax；核近似会损精细两两交互。
- 忘记 $\phi$ 必须非负，否则 “注意力” 失去归一化语义。

## 八、面试题

- 线性注意力为何线性？答：核映射使 $K^\top V$ 先聚合成 $d\times d$，再乘 $Q$，与 $n$ 无关。

## 九、演进

softmax 注意力 → 核线性注意力 → 与 SSM/状态空间对偶融合。

## 十、小结

线性注意力用核技巧把 $O(n^2)$ 降为 $O(n)$，是高效注意力的代表路线。
