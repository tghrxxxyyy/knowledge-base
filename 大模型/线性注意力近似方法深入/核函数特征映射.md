# 核函数特征映射

> 对应 Choromanski et al., *Performer: Random Feature Attention (FAVOR+)*, 2020 与 Katharopoulos 2020。

## 一、背景与挑战

线性注意力依赖核 $\phi$；选差则近似差，需可保证逼近 softmax 的映射。

## 二、核心原理

用随机特征（FAVOR+）无偏估计 $\exp(q^\top k)$；或用确定性正映射（elu+1）得到有偏但稳的线性注意力。

## 三、数学形式

softmax 核 $\exp(q^\top k)\approx \phi(q)^\top\phi(k)$；FAVOR+ 用 $\phi(x)=\frac{1}{\sqrt m}[e^{w_i^\top x},e^{-w_i^\top x}]$，$w_i\sim\mathcal N(0,I)$。

## 四、代码实现

```python
W = torch.randn(d, m)
phi = lambda x: exp(x @ W) / sqrt(m)
attn = phi(q) @ (phi(k).T @ v)
```

## 五、与其他对比

- 随机特征无偏但需大 $m$ 降方差；确定性映射更省但偏。
- 与 线性注意力近似方法深入 总览衔接（核是核心组件）。

## 六、常见误区

- 随机特征数 $m$ 太小方差大、不稳定。
- 用非正映射致“注意力”可负，破坏归一化直觉。

## 八、面试题

- 为何要随机特征？答：用有限维特征无偏估计指数核，使线性注意力逼近 softmax。

## 九、演进

elu 映射 → FAVOR+ 随机特征 → 可学习/改进核。

## 十、小结

核映射决定线性注意力近似质量，随机特征提供对 softmax 的无偏估计。
