# 线性注意力局限

> 综合线性注意力文献的经验结论；用于理性选型而非盲目追捧。

## 一、背景与挑战

线性注意力并非万能，在若干任务上明显逊于 softmax/稀疏，需知晓边界。

## 二、核心原理

低秩近似难表达强稀疏模式，核映射引入方差/偏差；长程且需精确聚焦的任务质量下降，训练也可能不稳。

## 三、数学形式

秩受限：$|\text{softmax}- \phi\phi^\top|\ge \epsilon(d)$ 随特征维 $m$ 反比下降，但 $m$ 增则失线性优势。

## 四、代码实现

```python
# 监控近似误差
err = (softmax(q@k.T) - phi(q)@phi(k).T).norm()
```

## 五、与其他对比

- 与 稀疏注意力算法深入 相比保留 softmax 质量但更高复杂度。
- 与 专家混合路由策略深入 不同维度优化，可组合。

## 六、常见误区

- 用极小特征维追求速度致质量崩。
- 在需要精确检索/复制的任务上误用线性注意力。

## 八、面试题

- 线性注意力何时不可用？答：需强稀疏聚焦或精确复制/检索时，低秩近似会显著掉质量。

## 九、演进

纯线性 → 混合头（部分线性）→ 与 SSM/注意力混合架构。

## 十、小结

线性注意力在效率与质量间有明确边界，常需混合或分层使用。
