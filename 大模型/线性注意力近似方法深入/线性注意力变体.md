# 线性注意力变体

> 对应 RetNet（Sun et al., 2023）、RWKV、Linear Transformer 等线性/递推变体。

## 一、背景与挑战

不同线性/递推模型在表达、训练并行、推理效率上各有取舍，需了解谱系。

## 二、核心原理

RetNet 用门控多尺度衰减保留指数衰减记忆；RWKV 用时间混合将注意力改写为 RNN；均具线性训练/推理潜力。

## 三、数学形式

RetNet 的递归：$s_t=\alpha s_{t-1}+k_t v_t^\top$，$o_t=q_t^\top s_t$，衰减 $\alpha$ 控制记忆长度。

## 四、代码实现

```python
s = alpha * s + k * v.unsqueeze(-1)
o = q @ s
```

## 五、与其他对比

- 与 状态空间对偶与Mamba2深入 同具递推，但 SSM 状态维结构更复杂。
- 与 Mamba 共享“线性时间”目标，路线不同（核 vs 状态方程）。

## 六、常见误区

- 把所有线性模型混为一谈；衰减机制与训练策略差异大。
- 忽略 RetNet/RWKV 的位置/衰减需与任务长度匹配。

## 八、面试题

- RetNet 如何线性推理？答：维护衰减状态 $s_t$，每步 $O(d^2)$ 更新，无需重算历史。

## 九、演进

线性 Transformer → RetNet/RWKV → 与 SSM 融合探索。

## 十、小结

线性注意力变体以不同记忆机制实现线性复杂度，构成非注意力序列建模谱系。
