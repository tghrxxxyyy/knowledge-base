# 矩阵列切分列并行

> 对应 Shoeybi 2019 (Megatron-LM) 与 Vaswani 2017 多头注意力。

## 一、背景与挑战
列并行将权重按列分块、输入完整复制，各卡算部分输出。它常作为 MLP/注意力第一层，使输出天然按列切分供后续行并行消费。

## 二、核心原理
$Y = X A$，$A=[A_1, A_2]$。每卡持 $A_i$，用完整 $X$ 算 $Y_i = X A_i$，结果按列拼成 $Y=[Y_1,Y_2]$。需 $X$ 在每张卡复制。

## 三、形式化与数学基础
$ Y_i = X A_i,\\quad Y = [Y_1 \\; Y_2] $，
输入复制一次，权重与激活按列分；与行并行衔接时无需 all-reduce，仅切分传递。

## 四、代码实现
```python
import torch
# x 完整复制到本卡
A_col = A_shard           # 本卡持有的列分片
Y_local = x @ A_col       # 局部输出(列分片)
# Y_local 直接作为下一个行并行层的切分输入，无通信
```

## 五、与其他技术对比
列并行需复制输入(显存略增)但产出切分结果；行并行消费该结果零通信。Megatron MLP 即 列->行 两层的组合。

## 六、常见误区
误区一：列并行省输入显存——输入仍每卡复制。误区二：列并行输出需 gather——仅当下游非行并行时才 gather。误区三：切分比例任意，实际按头数对齐更优。

## 七、与开源书/权威来源对应
Shoeybi 2019 Megatron；Vaswani 2017 多头注意力按头切分类似列并行。

## 八、面试题
问：列并行输出形态？答：按列切分，供行并行直接消费。问：为何 MLP 用列+行？答：实现无通信切分且保持数学等价。

## 九、演进与趋势
列并行与序列并行组合处理长序列；与 MoE 专家维切分正交。

## 十、小结
列并行产生切分输出，是张量并行链的第一环，与行并行无缝衔接。
