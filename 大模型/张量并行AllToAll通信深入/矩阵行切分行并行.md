# 矩阵行切分行并行

> 对应 Shoeybi 2019 (Megatron-LM) 与 Vaswani 2017 (Transformer) 数学基础。

## 一、背景与挑战
张量并行沿隐藏维切分权重矩阵，使单卡只持部分参数。行并行将输入按列分块、权重按行分块，计算局部结果后拼接或求和。

## 二、核心原理
设 $Y = X A$，$A$ 按行分为 $[A_1; A_2]$。若 $X$ 已按列对齐(列并行输出)则各卡用本地 $X_i$ 与 $A_i$ 得 $Y_i$，无需通信直接拼接成 $Y$。

## 三、形式化与数学基础
$ Y = [X_1 A_1,\\; X_2 A_2] = [Y_1,\\; Y_2] $，
列维输入 + 行维权重 使 GEMM 完全局部，通信 0 次，但要求上游提供按列切分的 $X$。

## 四、代码实现
```python
import torch
# 假设 x 已按列切分到本卡 (列并行输出)
A_local = A_shard          # 本卡持有的行分片
Y_local = x @ A_local      # 局部 GEMM，无通信
# 拼接由各卡结果组成完整 Y (由调用方 gather 语义)
```

## 五、与其他技术对比
行并行常作 MLP 第二层(输入已列切)；列并行作第一层。二者配对实现无额外通信的 MLP 切分，与 Megatron 一致。

## 六、常见误区
误区一：行并行总无通信——前提是输入已切分，否则需先 all-gather。误区二：切分任意维等价——需配对才能保证 GEMM 局部。误区三：行并行改变数值，实际数学等价。

## 七、与开源书/权威来源对应
Shoeybi 2019 Megatron 行/列并行；Vaswani 2017 注意力与 MLP 矩阵形式。

## 八、面试题
问：行并行何时零通信？答：输入按列切且权重按行切时。问：与列并行如何配对？答：列并行产切分输入供行并行消费。

## 九、演进与趋势
与序列并行、专家并行组合；fp8 GEMM 降低切分后单卡算力压力。

## 十、小结
行并行是张量并行基本单元，配对列并行可实现 MLP 无通信切分。
