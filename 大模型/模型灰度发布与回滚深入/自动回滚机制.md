# 自动回滚机制

> 对应 Kubernetes rollout undo / Argo Rollouts abort；Triton 模型热切换。Argo Rollouts 支持自动 abort。

## 一、背景与挑战

新版本劣化时人工回滚太慢，损失随时间累积，需要秒级自动回退以减小影响面。

## 二、核心原理

监控系统检测到异常（错误率、延迟、质量）即触发回滚，把路由权重切回 stable，并保留现场供诊断。

## 三、数学形式

触发条件：$\exists m: \frac{v_{canary}(m)-v_{base}(m)}{v_{base}(m)} > \theta_m$ 且持续 $T$ 秒，则执行回滚。

## 四、代码实现

```python
if prom.alert("error_rate>0.05", for_="60s"):
    rollout.abort()
    rollout.promote("v1", weight=100)
```

## 六、常见误区

- 回滚阈值过灵敏，感抖动误回滚。
- 回滚后未止血（根因仍在 stable 之外依赖）。
