# 影子流量验证（Shadow Traffic）

> 对应 shadow deployment / traffic mirroring（Istio mirror）。Istio 支持镜像流量到影子服务。

## 一、背景与挑战

想用真实流量验证新模型却不敢影响用户，需要旁路镜像的方式做无风险验证。

## 二、核心原理

把生产流量复制一份发给 canary（shadow），canary 的响应丢弃不返回用户；只比对两者结果用于评估。

## 三、数学形式

镜像代价 $C_{shadow}=C_{canary}$ 为额外算力；覆盖率 $=\frac{\text{shadow 收到请求}}{\text{总请求}}$。

## 四、代码实现

```python
mirror("prod", to="v2-shadow")   # 镜像而非切分
diff = compare_logs("v1", "v2-shadow")
```

## 五、与其他对比

- 与 流量切分策略 对照：影子不影响用户、无风险。
- 与 灰度评估指标（结果比对）衔接。

## 六、常见误区

- 影子实例未隔离，挤占生产资源。
- 下游写操作被影子触发（需封写）。
