# 金丝雀分析与自动判定

> 对应 Kayenta / Argo Analysis（canary analysis）；Istio 流量切分。Kayenta 提供自动化金丝雀评分。

## 一、背景与挑战

仅放量不够，还需客观判据决定继续放量还是回滚；人工判断慢且易错，难以应对高吞吐线上服务。

## 二、核心原理

金丝雀分析在放量过程中对新老版本做指标对比（延迟、错误率、业务指标），用统计检验判定新版本是否劣化。

## 三、数学形式

设指标均值 $\mu_c,\mu_b$，判定 $H_0:\mu_c\le\mu_b$；当 $\frac{\mu_b-\mu_c}{\sigma/\sqrt n}>z_\alpha$ 时判为劣化并触发回滚。

## 四、代码实现

```python
ok = analyzer.compare(
    baseline="v1", canary="v2",
    metrics=["p99_latency", "error_rate"],
    tolerance=0.05,
)
if not ok:
    rollback("v2")
```

## 五、与其他对比

- 与 自动回滚机制 衔接，分析结论驱动回滚。

## 六、常见误区

- 单看延迟忽略业务指标（如答案质量）。
- 样本不足即下结论导致误判。
