# 视觉对抗越狱

> 对应 Qi et al., AAAI 2024（视觉对抗样本越狱）；Shayegani et al., *Jailbreak in Pieces: Compositional Adversarial Attacks on Multi-Modal Language Models*, ICLR 2024。

## 一、背景与挑战

对抗样本在分类器时代就已成熟，但在视觉语言模型上它的危害升级了：目标不再是让分类标签出错，而是让整个语言模型的行为策略被改写。一张人眼看来完全正常的图片，可以让模型对随后的任何有害请求都保持顺从，且这种效果往往跨提示通用。

## 二、核心原理

两种范式。第一种是端到端似然攻击：在图像上做投影梯度优化，直接最大化有害回答（或其肯定性前缀）的生成似然，相当于在连续空间里找一个「万能越狱前缀」。第二种是嵌入空间组合攻击（jailbreak in pieces）：不针对最终输出，而是让图像的视觉嵌入靠近某个恶意文本的嵌入，于是有害语义通过视觉通道注入，而文本侧只需给出看似无害的引导。后者更隐蔽，因为攻击目标定义在中间表示上，输入输出两端都不含明显恶意信号。攻击的通用性来自于优化目标选择：以「肯定性开头」或「拒答概率最小化」为目标时，得到的扰动往往能跨多个有害请求复用。

## 三、数学形式

似然型攻击目标（含跨提示通用化）：

$$\min_{\|\delta\|_\infty\le\epsilon}\ \ \mathbb E_{t\sim\mathcal T_{\text{harm}}}\Big[-\log\pi_\theta\big(y^{+}\mid \mathrm{Enc}(I+\delta),t\big)\Big]$$

其中 $y^{+}$ 为肯定性前缀（如「好的，步骤如下」），$\mathcal T_{\text{harm}}$ 为一批有害提示，对其求期望即得到跨提示通用扰动。嵌入型攻击目标为

$$\min_{\|\delta\|_\infty\le\epsilon}\ \big\|\mathrm{Enc}_v(I+\delta)-\mathrm{Enc}_t(s_{\text{harm}})\big\|_2^2$$

即把视觉嵌入拉向恶意文本 $s_{\text{harm}}$ 的嵌入。

## 四、代码实现

```python
import torch

def universal_visual_suffix(model, image, harm_prompts, affirm_ids, eps=16 / 255, steps=500, lr=1e-2):
    # 红队用途：搜索跨提示通用的图像扰动，使模型倾向以肯定性前缀开头
    delta = torch.zeros_like(image, requires_grad=True)
    for step in range(steps):
        t = harm_prompts[step % len(harm_prompts)]          # 轮换提示以求通用性
        out = model(images=(image + delta).clamp(0, 1), text=t, labels=affirm_ids)
        out.loss.backward()
        with torch.no_grad():
            delta -= lr * delta.grad.sign()
            delta.clamp_(-eps, eps)
        delta.grad = None
    return delta.detach()

def embedding_space_attack(vis_enc, txt_enc, image, harm_text, eps=16 / 255, steps=300, lr=1e-2):
    target = txt_enc(harm_text).detach()
    delta = torch.zeros_like(image, requires_grad=True)
    for _ in range(steps):
        loss = torch.nn.functional.mse_loss(vis_enc((image + delta).clamp(0, 1)), target)
        loss.backward()
        with torch.no_grad():
            delta -= lr * delta.grad.sign()
            delta.clamp_(-eps, eps)
        delta.grad = None
    return delta.detach()
```

## 五、与其他对比

- 相对文本越狱（如梯度后缀搜索）：视觉攻击优化更容易（连续可微），且扰动对人不可见，检测更难。
- 相对排版类攻击：对抗扰动需要白盒或可迁移代理模型，排版攻击则完全黑盒可用。
- 与 奖励黑客：都是「在训练分布外寻找目标函数漏洞」，只是介质不同。

## 六、常见误区

- 认为 JPEG 压缩、缩放等预处理能彻底防御。这些能削弱部分扰动，但存在针对预处理鲁棒的攻击构造。
- 只测单张固定图像。应报告跨图像、跨提示的迁移成功率，否则低估风险。
- 把嵌入空间攻击当作理论玩具。它的隐蔽性恰恰使其在输入审核体系下更具威胁。

## 八、面试题

- 视觉对抗越狱的两类目标函数是什么？答：最大化有害回答（或肯定性前缀）的似然；以及把视觉嵌入拉向恶意文本嵌入的表示级攻击。
- 为什么这类扰动常具跨提示通用性？答：优化目标以「压低拒答、抬高肯定前缀」为主，学到的是通用的策略偏移而非特定内容。

## 九、演进

分类器对抗样本 → 视觉语言模型端到端似然攻击 → 跨提示通用扰动 → 嵌入空间组合攻击 → 面向预处理鲁棒的攻击与相应防御。

## 十、小结

视觉对抗越狱把对抗样本从「让分类出错」升级为「让策略失效」，其连续可优化与不可见性使它成为多模态安全中最硬的攻击面。
