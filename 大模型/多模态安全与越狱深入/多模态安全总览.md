# 多模态安全总览

> 对应 Qi et al., *Visual Adversarial Examples Jailbreak Aligned Large Language Models*, AAAI 2024；Liu et al., *Query-Relevant Images Jailbreak Large Multi-Modal Models*（MM-SafetyBench）, ECCV 2024。

## 一、背景与挑战

视觉语言模型的典型构建方式是「已对齐的语言模型 + 视觉编码器 + 连接层」，安全训练几乎全部发生在纯文本阶段。这带来一个结构性缺口：图像通道是一条几乎没有经过安全训练的输入路径，却能直接影响语言模型的隐状态。结果是许多在文本上被稳定拒答的请求，换成图文组合就能通过。

## 二、核心原理

三类根因。第一是训练覆盖缺口：视觉指令微调数据以描述、问答、OCR 为主，几乎不含安全对抗样本，安全行为无法从文本模态自动迁移。第二是连续输入空间：图像是高维连续张量，攻击者可在其中做梯度优化，搜索空间远大于离散 token，且不受词表与流畅度约束。第三是意图分散：有害意图可拆分到图像与文本两侧，各自看均无害，组合后才成立，从而绕过单模态过滤器。相应的防御必须在三处补：多模态安全数据、跨模态一致的拒答策略、以及对图像通道的独立检测与预处理。

## 三、数学形式

把攻击写成在图像上的约束优化：给定有害目标响应 $y^{\text{harm}}$ 与文本提示 $t$，

$$\delta^\star=\arg\max_{\|\delta\|_p\le\epsilon}\ \log \pi_\theta\big(y^{\text{harm}}\,\big|\,\mathrm{Enc}(I+\delta),\,t\big)$$

由于 $\delta$ 在连续空间且可微，梯度攻击可高效求解；相比之下文本攻击需在离散词表上搜索。安全性评估则用组合攻击成功率 $\mathrm{ASR}(\epsilon,B)$，同时标注扰动预算 $\epsilon$ 与查询预算 $B$。

## 四、代码实现

```python
import torch

def visual_jailbreak_objective(model, image, text, target_ids, eps=8 / 255, steps=200, lr=1e-2):
    # 说明性代码：在图像上做投影梯度上升以最大化有害目标序列的似然（仅用于红队评估）
    delta = torch.zeros_like(image, requires_grad=True)
    for _ in range(steps):
        out = model(images=(image + delta).clamp(0, 1), text=text, labels=target_ids)
        loss = out.loss                        # 目标序列的负对数似然
        loss.backward()
        with torch.no_grad():
            delta -= lr * delta.grad.sign()    # 符号梯度步
            delta.clamp_(-eps, eps)            # 投影回 L_inf 球
        delta.grad = None
    return delta.detach()
```

## 五、与其他对比

- 与 安全微调与拒答能力深入：那里的双侧错误率框架同样适用，只是输入空间扩展到图像。
- 与 提示注入形式化分析深入：图像中的文字指令属于跨模态的间接注入。
- 与 多模态对齐：安全缺口本质是对齐训练分布未覆盖攻击分布。

## 六、常见误区

- 认为语言模型已对齐则多模态自然安全。公开研究反复表明安全性不跨模态自动迁移。
- 只在输入端加图像内容审核。审核模型与主模型的判断边界不同，且对抗扰动可同时绕过两者。
- 用文本安全基准评估多模态模型。攻击面不重叠，结论无效。

## 八、面试题

- 为什么图像通道更容易被攻击？答：输入连续可微、扰动预算内搜索空间巨大、且不受语言流畅度与词表离散性约束。
- 多模态安全为何不能靠文本安全训练解决？答：视觉指令数据缺乏安全对抗样本，跨模态泛化不成立，需专门的多模态安全数据与评测。

## 九、演进

纯文本安全对齐 → 发现视觉通道绕过 → 视觉对抗与排版类攻击系统化 → 多模态安全数据与基准建设 → 跨模态一致的安全策略。

## 十、小结

多模态安全的核心事实是：安全性不随模态自动迁移；每新增一条输入通道，就必须为它单独补数据、补评测、补防护。
