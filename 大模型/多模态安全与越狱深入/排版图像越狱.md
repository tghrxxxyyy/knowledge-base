# 排版图像越狱

> 对应 Gong et al., *FigStep: Jailbreaking Large Vision-language Models via Typographic Visual Prompts*, 2023；Liu et al., MM-SafetyBench, ECCV 2024。

## 一、背景与挑战

不需要任何梯度，只要把有害请求排版成图片里的文字，再配一句无害的文本指令（如「请按图中步骤逐条展开」），许多视觉语言模型就会照做。这类攻击完全黑盒、零成本、可批量生成，是实际部署中最先遇到的多模态越狱形式。

## 二、核心原理

机制有三层。第一，安全过滤主要作用于文本输入通道：有害字符串没有出现在文本里，输入侧的关键词与分类器审核全部失效。第二，OCR 能力与安全策略解耦：模型被训练成尽力理解图中文字（这是视觉指令微调的主要目标之一），但没有被训练成对图中文字施加与文本同等的安全审查。第三，指令来源混淆：模型无法区分「图像中的文字」是用户指令还是待处理数据，于是把它当作要执行的指令——这与提示注入是同一类失效。变体包括把请求拆成图中编号步骤（诱导逐条补全）、用图片承载敏感名词而文本只给动词、以及利用低对比度或手写体规避 OCR 审核但仍被主模型识别。

## 三、数学形式

把攻击看作模态搬移算子 $\mathcal M$：将文本请求 $x_{\text{harm}}$ 渲染为图像 $\mathcal M(x_{\text{harm}})$，配以无害文本 $t_0$。若安全策略只对文本通道生效，则

$$\Pr\big[\text{unsafe}\mid \pi_\theta(t_0,\ \mathcal M(x_{\text{harm}}))\big]\ \gg\ \Pr\big[\text{unsafe}\mid \pi_\theta(x_{\text{harm}})\big]$$

该差值即「模态迁移增益」，可作为衡量跨模态安全一致性的指标：理想的对齐应使二者近似相等。

## 四、代码实现

```python
from PIL import Image, ImageDraw, ImageFont

def render_text_to_image(text, size=(768, 768), font_path=None, font_size=28):
    # 红队评估用：把请求渲染为图片，检验模型是否对图中文字施加同等安全策略
    img = Image.new("RGB", size, "white")
    draw = ImageDraw.Draw(img)
    font = ImageFont.truetype(font_path, font_size) if font_path else ImageFont.load_default()
    y = 20
    for line in text.split("\n"):
        draw.text((20, y), line, fill="black", font=font)
        y += font_size + 8
    return img

def modality_transfer_gain(model, harmful_texts, benign_instruction, unsafe_judge):
    text_asr = sum(unsafe_judge(model(text=x)) for x in harmful_texts) / len(harmful_texts)
    img_asr = sum(unsafe_judge(model(text=benign_instruction,
                                     image=render_text_to_image(x))) for x in harmful_texts) / len(harmful_texts)
    return {"text_asr": text_asr, "typographic_asr": img_asr, "gain": img_asr - text_asr}
```

## 五、与其他对比

- 相对视觉对抗越狱：无需梯度与白盒访问，成本极低，但可被 OCR 审核部分拦截。
- 与 提示注入形式化分析深入：本质是把注入载荷放进图像，属于跨模态间接注入。
- 与 安全评估：模态迁移增益应作为多模态安全报告的标准项。

## 六、常见误区

- 以为加一个 OCR 前置审核就解决了。手写体、艺术字、拆字、低对比度都能规避 OCR 而仍被主模型理解。
- 只测「图片里整句有害请求」。实际更有效的是分步骤编号诱导与图文分工承载。
- 把它当作低级攻击忽视。它是零成本可批量的，实际线上占比通常最高。

## 八、面试题

- 排版越狱为何有效？答：安全过滤集中在文本通道，而模型被训练成尽力读懂图中文字且未对其施加同等安全审查，同时无法区分图中文字是指令还是数据。
- 如何量化跨模态安全一致性？答：对同一批有害请求分别以文本与渲染图像输入，比较两者的攻击成功率差（模态迁移增益）。

## 九、演进

纯文本越狱 → 图中整句请求 → 分步骤编号与图文分工 → 规避 OCR 的字体与版式变换 → 跨模态一致的安全训练与检测。

## 十、小结

排版越狱以最低成本暴露了多模态安全最本质的问题：模型对不同输入通道的安全标准不一致，必须靠训练与评测把标准统一。
