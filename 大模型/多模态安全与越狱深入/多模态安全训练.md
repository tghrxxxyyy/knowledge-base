# 多模态安全训练

> 对应 Bai et al., *Constitutional AI*, 2022（原则驱动的安全数据生产）；Qi et al., AAAI 2024 与 Liu et al., ECCV 2024 提供的攻击样本形态。

## 一、背景与挑战

既然安全不跨模态迁移，就必须直接在图文输入上做安全训练。难点在于数据：多模态有害样本的构造成本高于文本（需渲染、配图、构造跨模态组合），且必须同时覆盖「图中含指令」「图文分工承载意图」「对抗扰动」等形态，还要配足够的良性对照防止误拒率飙升。

## 二、核心原理

训练配方分四块。第一块是安全视觉指令数据：对有害图文组合给出恰当拒答与安全替代，形式上与文本安全 SFT 一致但输入含图像。第二块是最小对比对的多模态版本：同一张图配有害与良性两种文本指令，或同一文本配敏感与正常两张图，迫使模型基于组合意图判断而非单侧特征。第三块是对抗增强：把红队搜到的对抗扰动图与排版攻击图纳入训练集（类似对抗训练），提升鲁棒性。第四块是安全重放：在视觉指令微调的每个批次里混入文本安全样本与多模态安全样本，防止遗忘。目标函数上通常直接用安全偏好优化（DPO 类）而非纯 SFT，因为需要同时表达「拒答优于顺从」与「正常回答优于过度拒答」。

## 三、数学形式

多目标安全微调目标：

$$\mathcal L=\mathcal L_{\text{vis-instruct}}+\lambda_1\mathcal L^{\text{harm}}_{\text{DPO}}+\lambda_2\mathcal L^{\text{benign}}_{\text{DPO}}+\lambda_3\,\mathbb E_{\|\delta\|\le\epsilon}\big[\mathcal L_{\text{safe}}(I+\delta,t)\big]$$

第二、三项分别对应有害与良性偏好对（钉住双侧边界），第四项为对抗鲁棒项（对扰动图像仍要求安全行为），等价于安全场景下的对抗训练。$\lambda$ 组需通过误拒率与任务指标联合扫描确定。

## 四、代码实现

```python
def multimodal_safety_batch(vis_ds, harm_pairs, benign_pairs, adv_samples,
                            w=(1.0, 0.5, 0.5, 0.3)):
    # 组批：视觉指令 + 有害偏好对 + 良性对照对 + 对抗增强样本
    return {"vis": vis_ds.sample(int(100 * w[0])),
            "harm": harm_pairs.sample(int(100 * w[1])),
            "benign": benign_pairs.sample(int(100 * w[2])),
            "adv": adv_samples.sample(int(100 * w[3]))}

def multimodal_safety_loss(model, ref, batch, beta=0.1, lam=(1.0, 1.0, 0.3)):
    l_task = sft_loss(model, batch["vis"])
    l_harm = dpo_loss_mm(model, ref, batch["harm"], beta)      # chosen = 恰当拒答
    l_benign = dpo_loss_mm(model, ref, batch["benign"], beta)   # chosen = 正常回答
    l_adv = sft_loss(model, batch["adv"])                       # 对抗图上的安全示范
    return l_task + lam[0] * l_harm + lam[1] * l_benign + lam[2] * l_adv
```

## 五、与其他对比

- 与 安全偏好数据构建：方法论一致，本节补上图像渲染、图文组合与对抗增强三类特有样本。
- 与 视觉对抗越狱：红队产出直接作为训练集输入，形成攻防闭环。
- 与 对齐税与能力保持深入：安全项过重会损害描述与 OCR 等基础视觉能力，需联合监控。

## 六、常见误区

- 只加「图中含有害文字」一类样本，模型学成「见到图里有字就警惕」，OCR 类正常任务被大面积误拒。
- 不做对抗增强就宣称鲁棒。未见过扰动分布的模型在梯度攻击下仍会失效。
- 良性对照集不含视觉输入。那样多模态误拒问题无法被训练信号纠正。

## 八、面试题

- 多模态安全训练至少需要哪几类数据？答：多模态有害拒答样本、良性对照（含视觉的最小对比对）、对抗增强样本、以及文本安全重放样本。
- 为什么要用偏好优化而非纯 SFT？答：需要同时表达「拒答优于顺从」与「正常回答优于过度拒答」两个方向，偏好目标能直接钉住双侧边界。

## 九、演进

纯文本安全对齐 → 事后加输入审核 → 多模态安全 SFT → 多模态安全偏好优化 + 对抗增强 → 攻防闭环持续迭代。

## 十、小结

多模态安全训练的要点是「双侧钉边界 + 对抗增强 + 安全重放」；缺少良性对照会误拒，缺少对抗样本则不堪一击。
