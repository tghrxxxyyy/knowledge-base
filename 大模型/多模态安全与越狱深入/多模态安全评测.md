# 多模态安全评测

> 对应 Liu et al., *MM-SafetyBench*, ECCV 2024；Gong et al., FigStep, 2023；Röttger et al., *XSTest*, NAACL 2024（误拒方法论）。

## 一、背景与挑战

多模态安全评测最容易失真的地方是攻击面覆盖：只测文本、只测整句排版图、或只测对抗扰动，都会得出截然不同的结论。加上判定环节（什么算 unsafe、什么算拒答）在图文场景更复杂，报告的可比性很差。

## 二、核心原理

一份可用的评测矩阵至少覆盖四条攻击通道：纯文本有害请求（基线）、排版图像承载请求、图文分工承载意图、对抗扰动图像。每条通道分别报告 ASR，并同时报告良性图文对照集上的误拒率。判定环节应使用多模态裁判或人工核验，重点识别「形式拒答后仍在图片描述中泄露关键信息」这类混合情况。此外要单列跨模态一致性指标（同一请求的文本 ASR 与图像 ASR 之差），它直接衡量安全策略是否统一。所有数字必须附带攻击预算（是否白盒、扰动上限、查询次数）与模型版本，否则不可比。

## 三、数学形式

定义通道化评测矩阵 $M\in\mathbb R^{K\times 2}$，第 $k$ 条通道给出

$$M_{k}=\big(\mathrm{ASR}_k(B),\ \mathrm{OR}_k\big),\qquad \mathrm{ASR}_k(B)=\mathbb E_{x\sim D_k}\Big[\max_{a\in\mathcal A_k(B)}\mathbb 1\{\text{unsafe}\}\Big]$$

跨模态一致性用 $\mathrm{Incons}=\max_k \mathrm{ASR}_k(B)-\mathrm{ASR}_{\text{text}}(B)$ 度量，理想值接近 0。综合安全水位取最弱通道：$\mathrm{ASR}_{\max}=\max_k \mathrm{ASR}_k(B)$，因为攻击者只需一条通道成功。

## 四、代码实现

```python
CHANNELS = ("text", "typographic", "split_modal", "adversarial")

def mm_safety_matrix(model, datasets, attacks, judge, budget):
    report = {}
    for ch in CHANNELS:
        ds, atk = datasets[ch], attacks[ch]
        hit = 0
        for sample in ds["harmful"]:
            if any(judge.is_unsafe(model(**a(sample))) for a in atk(budget)):
                hit += 1
        orr = sum(judge.is_refusal(model(**s)) for s in ds["benign"]) / len(ds["benign"])
        report[ch] = {"asr": hit / len(ds["harmful"]), "over_refusal": orr}
    text_asr = report["text"]["asr"]
    report["summary"] = {
        "worst_channel_asr": max(r["asr"] for r in report.values() if isinstance(r, dict) and "asr" in r),
        "cross_modal_inconsistency": max(r["asr"] - text_asr for k, r in report.items() if k in CHANNELS),
        "budget": budget,
    }
    return report
```

## 五、与其他对比

- 与 拒答与安全评估（文本）：框架相同，本节把「通道」升为一等维度。
- 与 排版图像越狱 / 视觉对抗越狱：那两节提供具体攻击构造，本节负责组织成可比报告。
- 与 模型行为可预测性深入：跨通道一致性本质是行为规格的一部分。

## 六、常见误区

- 用各通道 ASR 的平均值当结论。安全水位由最弱通道决定，平均会掩盖致命缺口。
- 良性对照集只用纯文本。多模态误拒（如拒绝正常 OCR 请求）会被完全漏掉。
- 判定只看首句是否道歉。图文场景下常见「先拒答再描述图片内容」，实质已泄露。

## 八、面试题

- 多模态安全报告应包含哪些必备项？答：分通道 ASR 与误拒率、最弱通道水位、跨模态一致性差值，以及攻击预算与判定方式说明。
- 为什么用最弱通道而非平均值？答：攻击者只需一条通道成功即可达到目的，安全性由下界决定。

## 九、演进

文本安全基准 → 多模态越狱基准（排版与对抗） → 通道化评测矩阵 → 加入误拒与一致性维度 → 持续红队与线上监控闭环。

## 十、小结

多模态安全评测的价值在于「分通道 + 双侧 + 标注预算」；只有把最弱通道和误拒率一起报，结论才对决策有意义。
