# 智能体规划总览

> 对应 Yao et al., *ReAct: Synergizing Reasoning and Acting*, 2022；Wang et al., *Voyager*, 2023。

## 一、背景与挑战

LLM 单体能力有限，需把任务拆为可执行的规划并与环境/工具交互达成目标。

## 二、核心原理

规划=任务分解+行动选择+环境反馈+反思。ReAct 交错思考与行动；Voyager 用技能库累积可复用能力。

## 三、数学形式

轨迹 $\tau=(t_1,a_1,o_1,\dots)$；策略 $\pi(a_t|s_t)=\text{LLM}(\text{prompt}(t_{<t},o_{<t}))$。

## 四、代码实现

```python
for step in range(max_steps):
    thought, action = llm.plan(state)
    obs = env.step(action)
    state = update(state, obs)
```

## 五、与其他对比

- 与 工具学习 / 推理时计算 共享"思考+执行"范式。
- 与 世界模型（内部模拟）对照外部交互。

## 六、常见误区

- 无反馈的死板规划，遇异常不修正。
- 忽视上下文长度限制长任务。

## 八、面试题

- ReAct 核心？答：交错生成思考链与行动，用环境观察驱动下一步，实现推理-行动协同。

## 九、演进

固定提示→ReAct→反思(Reflexion)→技能库自举。

## 十、小结

智能体规划把 LLM 变成可行动系统，反馈与反思是可靠性关键。
