# 任务分解与子目标

> 对应 Kojima et al. 零样本推理；Plan-and-Solve（Wang et al., 2023）。

## 一、背景与挑战

复杂任务直接求解易遗漏步骤；需显式拆分并逐步验证。

## 二、核心原理

先生成总体计划（子目标列表），再逐子目标执行并校验；Plan-and-Solve 强调"先计划后求解"降低错误累积。

## 三、数学形式

目标分解 $G=\{g_1,\dots,g_k\}$；满足条件 $pre(g_i)\subseteq done(g_{<i})$ 方可执行。

## 四、代码实现

```python
plan = llm(f"把任务拆为子目标: {task}")
for g in plan:
    result = execute(g); assert check(g, result)
```

## 五、与其他对比

- 与 推理时计算（CoT）共享分步思想。
- 与 指令遵循（约束）协调。

## 六、常见误区

- 计划过细致僵化、过粗致失控。
- 忽视子目标间依赖导致顺序错。

## 八、面试题

- 为何先计划后执行？答：显式结构降低长任务错误累积，且易插入校验与回溯。

## 九、演进

无计划→CoT→Plan-and-Solve→动态重规划。

## 十、小结

任务分解让复杂目标可控，依赖管理与校验是重点。
