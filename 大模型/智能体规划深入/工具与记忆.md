# 智能体工具与记忆

> 对应 Schick et al., *Toolformer*, 2023；记忆增强智能体（MemGPT）。

## 一、背景与挑战

LLM 知识静态、无实时/计算能力；需工具扩展与长期记忆。

## 二、核心原理

工具：把 API/函数作为可调用动作；记忆：分工作/长期/外部存储，按容量调度（如 MemGPT 分层）。

## 三、数学形式

动作空间 $A=A_{text}\cup A_{tool}$；检索记忆 $m^*=\arg\max \text{sim}(q, M)$。

## 四、代码实现

```python
if plan.tool_call:
    out = call_tool(plan.fn, plan.args)
memory.store(out)
```

## 五、与其他对比

- 与 工具学习 共享调用机制。
- 与 长上下文（记忆压缩）互补。

## 六、常见误区

- 工具返回未校验直接信任致错误传播。
- 记忆无淘汰致噪声淹没。

## 八、面试题

- 记忆如何分层？答：工作记忆快但小、长期/外部慢但大，按重要性与容量调度。

## 九、演进

无记忆→RAG 记忆→分层自我管理记忆。

## 十、小结

工具与记忆把 LLM 变成可持续、可操作的智能体底座。
