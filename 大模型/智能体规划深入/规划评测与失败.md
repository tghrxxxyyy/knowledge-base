# 智能体规划评测与失败模式

> 对应 agent benchmark（WebArena, AgentBench）；失败分析文献。

## 一、背景与挑战

规划成功不仅看最终答案，还要看效率、鲁棒与可恢复性。

## 二、核心原理

评测：任务成功率、步骤效率、幻觉率、恢复率；失败模式：循环、幻觉动作、工具误用、上下文丢失。

## 三、数学形式

成功率 $SR=\frac{\#success}{\#tasks}$；效率 $E=1-\frac{steps}{steps_{optimal}}$。

## 四、代码实现

metrics = {"sr": success/total, "steps": mean(steps)}
