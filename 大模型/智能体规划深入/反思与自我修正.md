# 反思与自我修正

> 对应 Shinn et al., *Reflexion*, 2023；自反思智能体。

## 一、背景与挑战

一次执行常失败；需基于反馈反思并改进策略，而非简单重试。

## 二、核心原理

Reflexion 把失败轨迹与自我批评写入记忆，下一轮 LLM 读取后调整行动；形成"试错-反思-改进"循环。

## 三、数学形式

策略更新 $\pi_{t+1}=\text{LLM}(\pi_t, \tau_{fail}, \text{reflect}(\tau_{fail}))$；无需梯度。

## 四、代码实现

```python
reflection = llm(f"反思失败: {traj}")
memory.append(reflection)
action = llm(state, memory)
```

## 五、与其他对比

- 与 工具学习（失败重试）相关但更重"总结"。
- 与 推理时计算（搜索）对照。

## 六、常见误区

- 反思空泛无具体改进点。
- 记忆无限增长致上下文溢出。

## 八、面试题

- Reflexion 为何有效？答：把失败经验抽象为可复用反思，避免重复错误、定向改进。

## 九、演进

重试→带反馈重试→反思记忆→元反思。

## 十、小结

自我修正是智能体从失败中学习的低成本途径，反思质量是核心。
