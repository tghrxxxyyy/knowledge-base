# 多智能体协作

> 对应 Wu et al., *AutoGen*, 2023；Qian et al., *ChatDev*, 2023。

## 一、背景与挑战

单智能体能力/视角有限；多角色协作可分工提升复杂任务质量。

## 二、核心原理

多 agent 扮演不同角色（规划/执行/审核），通过对话/消息传递协作；可用主持人或图结构编排。

## 三、数学形式

消息传递 $m_{ij}=A_i(\{m_{ji'}\}_{i'})$；全局状态 $S=\text{aggregate}(\{m\})$。

## 四、代码实现

```python
for agent in team:
    msg = agent.act(history)
    history.append(msg)
```

## 五、与其他对比

- 与 智能体规划总览 互补（多体 vs 单体）。
- 与 推理时计算（多样本）共享"多样投票"思想。

## 六、常见误区

- 无明确角色致重复/冲突。
- 通信成本随 agent 数平方增长。

## 八、面试题

- 多智能体为何可能更强？答：角色分工+交叉审视，减少单点盲区，提升鲁棒与质量。

## 九、演进

单体→固定协作→动态角色与编排。

## 十、小结

多智能体以协作放大能力，编排与通信效率是工程关键。
