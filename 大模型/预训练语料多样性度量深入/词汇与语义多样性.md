# 词汇与语义多样性

> 对应 数据多样性在 LLM 预训练中的实证研究。

## 一、背景与挑战

词汇多样性(用词丰富)与语义多样性(话题广泛)并不等价。高词汇多样但语义重复，仍算低质窄数据。

## 二、核心原理

词汇多样性用 type-token 比、词汇熵；语义多样性用句/文档嵌入在空间中的 spread(如平均成对距离、核密度熵)。

## 三、数学形式

Type-Token Ratio：

$$
\mathrm{TTR} = \frac{|\{v: \text{count}(v)>0\}|}{N_{tok}}
$$

语义 spread(基于嵌入)：

$$
\mathrm{Spread} = \frac{1}{n^2}\sum_{i,j}\|\phi_i-\phi_j\|_2
$$

## 四、代码实现

```python
def ttr(tokens):
    return len(set(tokens)) / max(1, len(tokens))

def semantic_spread(embs):
    import torch
    d = torch.cdist(embs, embs)
    return d.mean().item()
```

## 五、与其他对比

词汇指标廉价但浅；语义指标深但依赖嵌入质量，二者互补。

## 六、常见误区

误区：TTR 高即好。长文档 TTR 自然偏低，需按长度归一。

## 八、面试题

- Q：词汇与语义多样性差异？答：用词丰富 vs 话题广泛，二者不等价。

## 九、演进

用语义 spread 指导去冗余与领域补采，提升有效多样性。

## 十、小结

词汇与语义多样性须分别度量，共同决定语料广度。
