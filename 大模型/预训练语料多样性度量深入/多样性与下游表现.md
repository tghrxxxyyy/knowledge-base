# 多样性与下游表现

> 对应 预训练数据多样性对模型能力影响的实证研究。

## 一、背景与挑战

直觉上更高多样性更好，但过度多样(引入噪声/离群域)可能稀释核心能力。需找到多样性与表现的拐点。

## 二、核心原理

适度多样性提升泛化与鲁棒性；当混入低质量异质数据，下游表现下降。存在“黄金区间”。

## 三、数学形式

设多样性 $d$，下游表现：

$$
\mathrm{Perf}(d) = a\cdot \mathrm{tanh}(b(d-d_0)) + c
$$

在 $d^\star$ 处饱和/转折，超过后边际下降。

## 四、代码实现

```python
import math

def perf(d, a=1.0, b=0.5, d0=0.3, c=0.5):
    return a * math.tanh(b * (d - d0)) + c
```

## 五、与其他对比

多样性不是单调增益，需配合质量门控，否则“广而杂”劣于“窄而精”。

## 六、常见误区

误区：多样性越高分越高。噪声域会拉低均值。

## 八、面试题

- Q：多样性与表现关系？答：先增后平甚至降，存在黄金区间。
- Q：如何找拐点？答：配比消融 + 下游基准扫描。

## 十、小结

多样性是双刃剑，须与质量共同优化而非单向最大化。
