# 数据受限下的多样性

> 对应 Muennighoff et al. 2023 "Scaling Data-Constrained Language Models", NeurIPS 2023。

## 一、背景与挑战

数据受限时，重复数据能提升表现但会牺牲多样性，增加过拟合风险。需量化“重复-多样性”权衡。

## 二、核心原理

在固定语料上重复 $r$ 次，有效多样性近似按 $\log r$ 增长(因去重后唯一样本数不变，只是频次变)，但过拟合随 $r$ 上升。

## 三、数学形式

唯一样本集大小 $U$，重复后训练量 $N=r|U|$。有效多样性增益：

$$
\Delta \mathrm{Div} \approx \log r
$$

过拟合风险：

$$
\mathrm{Risk}(r) = c\cdot\max(0, r-r^\star)
$$

## 四、代码实现

```python
import math

def eff_diversity_gain(r):
    return math.log(max(1, r))

def overfit_risk(r, rstar, c=0.1):
    return c * max(0, r - rstar)
```

## 五、与其他对比

数据丰富时优先广覆盖；数据受限时优先重复高质量并控频防过拟合。

## 六、常见误区

误区：重复不影响多样性。重复不改变唯一集，但会改变学习侧重与过拟合。

## 八、面试题

- Q：受限下重复的策略？答：重复高质量子集，设上限防过拟合。
- Q：多样性怎么变？答：唯一集不变，靠质量筛选提升有效多样。

## 九、演进

从经验重复到数据混合定律预测多样-性能曲面。

## 十、小结

数据受限时多样性靠“选得准”而非“采得广”，重复需量化风险。
