# 多样性覆盖度冗余度定义

> 对应 Lee et al. 2021 与预训练数据质量/多样性研究。

## 一、背景与挑战

语料“多样性”是模糊概念。需区分三个相关但不同的量：多样性(差异度)、覆盖度(对目标分布覆盖)、冗余度(重复程度)，否则无法指导配比。

## 二、核心原理

多样性衡量样本间差异；覆盖度衡量对真实分布支撑集的触及；冗余度衡量重复/近似重复占比。三者共同刻画数据“形态”。

## 三、数学形式

以集合 $S$ 与核相似度 $k(x,y)$ 定义：

$$
\mathrm{Div}(S) = \frac{1}{|S|^2}\sum_{x,y\in S} (1-k(x,y))
$$

$$
\mathrm{Red}(S) = \frac{1}{|S|^2}\sum_{x,y\in S} k(x,y)
$$

覆盖度用与目标分布 $p^\star$ 的 Jensen-Shannon 距离衡量。

## 四、代码实现

```python
import torch

def diversity(embs):
    sim = torch.nn.functional.cosine_similarity(embs[:,None], embs[None,:], -1)
    return 1 - sim.mean().item()
```

## 五、与其他对比

相比单纯去重(降冗余)，多样性还强调“差异广度”，覆盖度强调“目标对齐”。

## 六、常见误区

误区：去重即多样。去重只降冗余，不保证覆盖广。
