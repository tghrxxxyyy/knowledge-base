# 多样性度量工具与实践

> 对应 数据质量/多样性评估工具与预训练数据审计实践。

## 一、背景与挑战

大规模语料多样性无法人工评估，需要可复现、可规模化的度量工具与持续监控。

## 二、核心原理

实践流程：嵌入采样→聚类→算簇分布熵/覆盖率→监控训练过程指标(tok 熵、领域占比)→异常告警。形成数据看板。

## 三、数学形式

领域分布熵(越高越均衡多样)：

$$
H_{dom} = -\sum_d p_d \log p_d
$$

覆盖率(簇被触及比例)：

$$
\mathrm{Cov} = \frac{|\{k: n_k>0\}|}{K}
$$

## 四、代码实现

```python
import torch

def domain_entropy(counts):
    p = torch.tensor(counts).float(); p = p / p.sum()
    return -(p * p.log()).sum().item()

def coverage(cluster_sizes):
    return sum(1 for n in cluster_sizes if n > 0) / len(cluster_sizes)
```

## 五、与其他对比

相比一次性报告，持续监控能捕捉数据漂移与配比失衡。

## 六、常见误区

误区：只算一次。数据管道变化会使多样性漂移，需定期复查。
