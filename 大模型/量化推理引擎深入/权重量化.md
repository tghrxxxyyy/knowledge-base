# 权重量化

> 对应线性层权重量化；与 GPTQ/AWQ深入 衔接。

## 一、背景与挑战

权重静态、易量化；但 per-tensor 粗糙，per-channel/group 更精；低比特（INT4）需好校准。

## 二、核心原理

按组（group，如 128）设缩放，捕捉列间幅度差；推理用 INT4 权重乘 FP16 激活（mixed）或全低比特。

## 三、数学形式

分组缩放：$s_g=\max(|W_g|)/2^{b-1}$；量化误差按组独立最小化。

## 四、代码实现

```python
Wq, scales = quantize_group(W, bits=4, group=128)
```

## 五、与其他对比

- 比 激活量化 易（权重确定）；
- 与 llama.cpp深入 的 GGML 量化对照。

## 六、常见误区

- group 过小致缩放开销大；
- 忽略反量化在热路径的性能。

## 八、面试题

- 为何按组量化？答：组内幅度更均，缩放更准、误差更小。

## 九、演进

per-tensor → per-channel → per-group。

## 十、小结

权重量化以分组缩放保精度，是 INT4 落地基础。
