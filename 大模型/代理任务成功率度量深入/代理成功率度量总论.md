# 代理成功率度量总论

> 对应 AgentBench (Liu et al. 2023) 与代理任务评测的方法论总览。

## 一、背景与挑战

LLM 代理需多步决策、调用工具、与环境交互。评测不能只看单轮，要度量大轨迹成功率、部分进度与鲁棒性。

## 二、核心原理

核心指标：任务成功率（最终是否达成）、步骤准确率、轨迹级奖励、与人工基线对比。需区分"碰巧完成"与"稳健策略"。

## 三、数学形式

成功率：

$$
\mathrm{SR}=\frac{1}{N}\sum_{i}\mathbf{1}[\mathrm{done}(i)]
$$

平均进度：

$$
P=\frac{1}{N}\sum_{i}\frac{|\mathrm{completed\_steps}_i|}{|\mathrm{total}_i|}
$$

## 四、代码实现

```python
def success_rate(trajs):
    return sum(1 for t in trajs if t["done"])/len(trajs)

print(success_rate([{"done":True},{"done":False},{"done":True}]))
```

## 五、与其他对比

相比静态 QA，代理评测含状态与环境；相比代码 pass@k，代理更连续且非二元。

## 六、常见误区

误区一：成功率即全部（忽略进度）。误区二：单次运行定论（环境随机）。误区三：忽略步数成本。

## 八、面试题

- Q：代理评测核心指标？答：成功率、平均进度、轨迹奖励。
- Q：为何多次运行？答：环境随机需统计稳定性。

## 九、演进

从单任务到 AgentBench 多环境统一评测，代理度量走向标准化。

## 十、小结

代理成功率度量需结合最终达成与过程进度，是动态评测的核心。
