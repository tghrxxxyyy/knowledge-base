# 轨迹级指标与部分奖励

> 对应代理评测中的轨迹级（trajectory-level）度量与过程奖励研究。

## 一、背景与挑战

二元成功率忽略"差一步完成"与"全错"的区别。轨迹级指标与部分奖励能更细腻反映策略质量，也利于训练。

## 二、核心原理

指标包括：步级准确率、进度加权分、子目标达成率、效率（步数惩罚）。部分奖励用过程奖励模型给轨迹中间分。

## 三、数学形式

进度加权：

$$
R=\sum_{t=1}^{T}\gamma^{t}\cdot r_t,\quad r_t\in[0,1]
$$

子目标达成：

$$
G=\frac{|\mathrm{subgoals\ met}|}{|\mathrm{subgoals}|}
$$

## 四、代码实现

```python
def discounted(rewards, gamma=0.9):
    return sum(gamma**t*r for t,r in enumerate(rewards))

print(round(discounted([1,0,1,0.5]),3))
```

## 五、与其他对比

相比二元 SR，轨迹指标更细；相比最终分，部分奖励利于过程训练与诊断。

## 六、常见误区

误区一：进度满即成功（可能方向错）。误区二：忽略折扣导致短视。误区三：部分奖励不等同最终达成。

## 八、面试题

- Q：为何要轨迹级指标？答：二元成功率丢失接近完成的有用信号。
- Q：部分奖励作用？答：给中间步骤信用，助训练与诊断。

## 九、演进

从成功率到轨迹折扣奖励与子目标度量，代理评测与训练协同细化。

## 十、小结

轨迹级指标与部分奖励把代理度量从二元推向连续，更利于诊断与训练。
