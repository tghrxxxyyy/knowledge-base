# 多模态数据管线

> 对应 LLaVA (Liu et al. 2023)、CLIP (Radford et al. 2021) 数据实践与 mlabonne 多模态训练资料。

## 一、背景与挑战

多模态大模型（视觉-语言为主）的能力上限由训练数据质量而非单纯规模决定。与纯文本不同，多模态数据面临「对齐」难题：图文对必须语义相关，否则模型学到的是错误的图像-文本映射。原始网络图文（如爬取的 alt-text）充斥噪声——图注与图片无关、乱配图、低信息量描述。管线需完成：收集 → 图文相关性过滤 → 清洗 → 描述生成（captioning）→ 格式化。视频/音频更需切帧、转录、时序对齐。挑战在于：高质量人工标注昂贵且稀缺，合成 caption（用强 captioner 重新描述图像）虽能扩充多样性但可能引入模型偏见；跨语言、跨模态的噪声分布差异大。

## 二、核心原理

标准多模态数据管线分阶段：
1. **采集**：从网页、数据仓库（LAION、COYO、DataComp）拉取图文对，或从视频抽帧。
2. **相关性过滤**：用 CLIP 等对比模型计算图像-文本相似度，剔除低于阈值（如 cosine<0.2）的错配对。
3. **清洗**：去水印、去成人/暴力、去重复（近似图+近似文）。
4. **描述生成**：用 BLIP/LLaVA 类 captioner 对图像生成更丰富、更准确的训练文本，缓解原 alt-text 过短或错误。
5. **指令化**：将数据转成对话/指令格式（如「描述这张图」「图中发生了什么」），供 SFT 使用。

关键是「质量 > 数量」：许多工作证明，用强 captioner 重写后的高质量子集训练，效果优于同等规模原始噪声数据。

管线还需处理「质量-多样性」张力：强 captioner 重写能提升相关性，但单一 captioner 会引入模型自身偏见；实践中常用多个异构 captioner 混合，并对重写后描述再做一次相关性过滤。视频模态要额外做时序对齐——抽帧需配合 ASR 转录与时间戳，否则模型学不到动作与语言的因果顺序。跨语言图文对还需语言对齐，避免「图英文中译」造成的语义错位。

## 三、形式化与数学基础

图文相关性用对比模型编码后的余弦相似度度量。设图像编码 $v=I(x)$、文本编码 $t=T(y)$，归一化后：

$$ s(x,y) = \frac{v^\top t}{\|v\|\|t\|} $$

过滤规则：$s(x,y) \ge \tau$ 保留，否则丢弃。 captioner 生成新文本 $y'=\text{Captioner}(x)$，再以 $y'$ 替换原 $y$ 参与训练，目标分布更逼近「标准描述」：

$$ \mathcal{D}_{\text{train}} = \{(x, y') : s(x,y')\ge \tau'\} $$

其中 $\tau'$ 通常高于原始对阈值，确保重写后描述与图高度一致。

## 四、代码实现

```python
import clip
model, preprocess = clip.load("ViT-L/14")

def image_text_score(img, text):
    v = model.encode_image(preprocess(img)).float()
    t = model.encode_text(clip.tokenize([text])).float()
    return (v @ t.T).item() / (v.norm() * t.norm())

# 相关性过滤
```

## 五、与纯文本管线对比

| 维度 | 文本管线 | 多模态管线 |
|------|----------|------------|
| 核心噪声 | 低质文本、重复 | 图文错配、无关 |
| 过滤手段 | 困惑度、分类器 | CLIP 相似度 |
| 增强 | 重写/回译 | captioner 重描述 |
| 成本 | 低 | 高（需视觉编码） |

多模态多了「跨模态对齐」这一独有环节，是质量门控的核心。

## 六、常见误区

- **以为数量压倒质量**：噪声图文对会教错映射，相关过滤不可或缺。
- **过度依赖原 alt-text**：网络 alt-text 常过短或误导，应用 captioner 重写。
- **忽视合成 caption 的偏见**：强 captioner 自带分布偏见，需多样模型混合。
- **视频直接当图**：缺时序对齐会丢失动作语义，需抽帧+转录配对。

## 九、演进与趋势

- **原生多模态数据**：直接从视频/音频端到端对齐，弱化「图+文」拼装。
- **自动化管线**：用大模型自动过滤、重写、评分，形成数据飞轮。
- **跨模态去重**：图像指纹 + 文本哈希联合去重。
- **合成数据占比提升**：用生成模型造难例与多样描述。
- **原生多模态端到端**：弱化「图+文」拼装，直接从视频/音频对齐。
- **自动化数据飞轮**：大模型自动过滤、重写、评分，形成闭环。

## 十、小结

多模态数据管线的灵魂是「跨模态对齐」：用 CLIP 相似度过滤错配、用 captioner 重写低质描述，质量优先于数量。落地需兼顾过滤阈值、合成偏见与视频时序，方能逼近模型能力上限。
