# 训练数据质量总览

> 对应 llm-course「LLM Scientist / Data」与数据工程实践。「数据质量 > 模型结构」已成共识。

## 一、核心概念

大模型能力上限很大程度由训练数据决定。质量维度：准确性、多样性、去重、去毒、去隐私、配比均衡、去污染。数据管线：采集→去重→过滤→配比→去污染→格式化。

## 二、关键要点

| 维度 | 手段 |
|------|------|
| 准确性 | 可信源、事实校验 |
| 多样性 | 多域覆盖 |
| 去重 | n-gram/语义 |
| 去毒 | 分类器过滤 |
| 配比 | 域权重调度 |

## 三、与开源书的对应

- 见「预训练/大规模语料」「合成数据/数据去污染」文档。
