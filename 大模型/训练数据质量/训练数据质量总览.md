# 训练数据质量总览

> 对应书目：mlabonne《llm-course》Prepare the dataset 章（https://github.com/mlabonne/llm-course）｜ 仓库：https://github.com/HuggingFace/dataspeech ｜ 参考：DataComp-LM（DCLM）、FineWeb 技术报告等公开数据工程实践

## 一、背景与挑战

很多人以为大模型 = 更大的网络 + 更多的卡。但业界共识恰恰相反：**模型结构趋同之后，拉开差距的主要是训练数据**。同样 7B 的模型，用“网上随便爬的脏数据”训出来会胡言乱语，用精心清洗的数据训出来就更聪明、更听话。人们常打比方：模型是学生，数据是教材——教材错漏百出、题型重复，学生再刻苦也学不好。

挑战在于数据有“三多”：**脏东西多**（乱码、抓取残页、机器翻译腔）、**重复内容多**（同一篇新闻被转载一百遍）、**敏感内容多**（隐私、仇恨言论）。而且这些问题不训练前修，训完才在模型身上爆发——幻觉、复读、答敏感题翻车，回头补救要重训，成本极高。所以数据工作必须“**前置**”：在按下训练键之前把质量关把住。本文给出两条主线：**质量的评估维度有哪些**，以及**一条标准数据管线长什么样**。

## 二、核心原理

### 质量 > 数量

早期靠“堆语料”堆性能的路子已经触顶。公开实验反复显示：用 1/10 的高质量数据，可能比全量脏数据训得更好。直觉解释是——**梯度是被数据驱动的**，一条错误样本教给模型错误规律，十条重复样本浪费十次学习机会。质量工作本质上是在提高“每一条样本的有效信息量”。

### 六个关键维度

1. **准确性（Correctness）**：内容事实对不对、代码能不能跑、答案是不是文不对题。靠可信源白名单、规则过滤、小模型打分。
2. **多样性（Diversity）**：领域、语言、文体、难度要覆盖够广。全是新闻会让模型不会写代码，全是英文会让中文变差。用分类器统计领域分布，再按需补采。
3. **去重（Deduplication）**：完全重复与近似重复都要去。手段有两档——**精确去重**用哈希（对归一化后的整篇文本取 MD5/SHA）；**模糊去重**用 5-gram MinHash 或句向量聚类，能抓出“改了三个字的转载”。重复的危害是模型对某类分布过拟合，还会背诵（memorize）训练原文导致隐私泄漏。
4. **去污染（Decontamination）**：训练集和评测集（如 MMLU、GSM8K）撞题。模型“考前看过卷子”，分数虚高却不代表能力。做法是把评测题的 n-gram 拿去训练语料里匹配，命中就删。
5. **配比（Mixing）**：各领域按什么比例喂。代码数据被证明能提升推理能力，适当上调有帮助；但某一类刷太多会挤占其它能力。常见做法是先按自然分布做基线，再像调菜谱一样加权调度。
6. **脱敏与安全（Safety & Privacy）**：用分类器/正则清洗个人信息（手机号、身份证、邮箱）、毒性内容、NSFW。常见做法是毒性分类器与隐私识别器各扫一遍。

### 标准管线（顺序很重要）

**采集 → 格式归一 → 精确去重 → 质量过滤 → 模糊去重 → 去污染 → 脱敏去毒 → 配比混合 → 格式化打包（如 jsonl）**。

顺序的讲究：先去重再过滤能省算力（重复内容只需判一次质量）；配比放最后，因为过滤会改变各领域占比，过滤完要重新称重。

## 三、要点形式化

- 有效数据量 ≈ 原始数据量 ×（1 − 重复率）×（1 − 脏数据率）× 质量权重。三个系数里，**重复率往往高达 30%–60%**（网络文本常见统计），所以第一步去重收益最大。
- 评估一条数据可打综合分：`S = w₁·准确性 + w₂·流畅度 + w₃·信息密度 − w₄·毒性`，低于阈值即丢弃——这正是主流“模型过滤”（用小模型打分再截断）的简化形式。

## 四、代码实现（操作步骤）

以 HuggingFace `datasets` 为例，跑通“读入 → 精确去重 → 规则过滤 → 去污染 → 打包”最小管线：

```python
# pip install datasets
from datasets import load_dataset
import hashlib

ds = load_dataset("json", data_files="raw/*.jsonl", split="train")

# 1. 精确去重：对归一化文本取哈希，保留首次出现
def norm(t):  # 统一空白与大小写
    return " ".join(t.lower().split())

seen = set()
def keep_dedup(x):
    h = hashlib.md5(norm(x["text"]).encode()).hexdigest()
    if h in seen:
        return False
    seen.add(h)
    return True

ds = ds.filter(keep_dedup)

# 2. 基础质量规则：过短、含乱码的丢掉
def quality(x):
    t = x["text"]
    # 统计替换字符 U+FFFD，过滤明显乱码行
    return len(t) > 200 and t.count("\ufffd") < 3 and "javascript is disabled" not in t.lower()

ds = ds.filter(quality)

# 3. 去污染：剔除与评测集 n-gram 重合的样本
mmlu = load_dataset("cais/mmlu", "all", split="test")
grams = {" ".join(q.lower().split()[:8]) for q in mmlu["question"]}  # 取题干前 8 词做指纹

def decontam(x):
    t = x["text"].lower()
    return not any(g in t for g in list(grams)[:2000])   # 实际工程用倒排索引加速

ds = ds.filter(decontam)
ds.to_json("cleaned.jsonl")   # 之后再按比例混合各域子集
```

真实项目里第 2、3 步会换成训练好的质量分类器（如 FastText 或小 LLM 打分），规则版只是帮你理解管线骨架。

## 五、与其他方案对比

| 维度 | 脏数据直接训 | 纯规则清洗 | 规则 + 模型打分（主流） |
|------|------------|-----------|----------------------|
| 成本 | 最低 | 中 | 较高（要训过滤模型） |
| 质量上限 | 低（幻觉、复读） | 中（抓得住格式，抓不住语义） | 高 |
| 典型做法 | 早期堆量 | 正则 + 白名单 | 打分截断 + 人工抽检 |
| 适用 | 基线实验 | 小语料起步 | 正式预训练/SFT 数据 |

SFT（指令微调）数据与预训练数据侧重不同：预训练重“海量+干净”，SFT 重“多样性+答案质量+格式统一”，几百到几万条精品即可。

## 六、常见误区

1. **数据越多越好**：重复和低质数据不仅不加分，还会拖累（过拟合、背题泄漏），去重后往往剩不到一半。
2. **只做精确去重**：转载、模板化页面是近似重复，MD5 抓不到，必须上 MinHash/向量模糊去重。
3. **忘了去污染**：评测分数涨了其实是“考前泄题”，上线后能力对不上。
4. **过滤完不看分布**：质量阈值一收，长尾领域（小语种、古文）被误杀，配比失衡，模型偏科。
5. **以为质量纯靠自动化**：分类器也有盲区，主流做法都是“自动打分 + 人工抽检”双保险。
6. **忽视许可与隐私**：版权、PII 脱敏不是可选项，合规问题会直接卡住开源发布。

## 八、面试题/上手题

1. **为什么说“数据质量 > 模型结构”？** 要点：结构趋同后，数据决定能力上限与幻觉水平；高质量小数据可胜过海量脏数据；数据错误在训练后修复代价极高。
2. **精确去重和模糊去重分别怎么做？** 要点：归一化+哈希抓完全重复；MinHash/LSH 或句向量聚类抓近似重复（改写、转载）。
3. **什么是数据污染？怎么防？** 要点：训练集混入评测题导致分数虚高；用评测题 n-gram 回扫训练语料并剔除。
4. **动手题：取 1 万条爬虫语料，统计去重前后条数与平均长度变化，并画领域分布饼图。** 要点：感受“重复率有多高、过滤后分布怎么变”。

## 九、演进与趋势

数据工程的演进有四条线：**其一，从规则到模型**——早期靠正则黑名单，现在主流是用小模型/LLM 给每条数据打分筛选。**其二，合成数据崛起**——用强模型生成推理链、代码题来补短板，但合成数据同样要走去重和质量关。**其三，数据选择成为显学**——按“对训练损失的影响”挑样本，用 5% 数据达到 90% 效果的研究不断出现。**其四，可追溯与合规**——来源、许可、脱敏记录成为开源发布的硬要求。可以预期：**未来的模型卡里，数据报告会和参数量一样重要**。

## 十、小结

训练数据质量的工作可以浓缩成一张清单：**先去重，再过滤，后去污染，末配比，全程脱敏**。评估维度抓六个——准确、多样、去重、去毒、配比、去污染。入门者最好的练习不是背概念，而是亲手跑：拿一万条脏语料，做完去重和规则过滤，看数字掉多少、分布怎么变；再对一下评测集，体会污染。记住那句行话：**模型的天花板是数据画的**——调网络结构之前，先看看你喂进去的教材配不配得上你想考的分数。
