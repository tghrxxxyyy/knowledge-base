# 质量过滤 Quality Filtering

> 对应 Common Crawl 处理（GPT-3/LLaMA 方法）、Gopher (Rae et al. 2021) 与 C4 (Raffel et al. 2020) 质量分类实践。

## 一、背景与挑战

开放网络语料（如 Common Crawl）占比高但质量极差：充斥垃圾站、机器翻译乱码、重复模板、低信息短文本。直接用原始数据训练会得到「学得满嘴废话」的模型。质量过滤（Quality Filtering）旨在从海量原始网页中筛出「值得学」的文本，是预训练数据管线中最影響最终能力的一步。经验上，Common Crawl 原始数据通常只有不到 30% 能通过严格过滤。挑战在于：质量定义主观且不统一（信息量、可读性、语言纯度、事实性），纯规则易误杀、纯分类器需高质量种子、过度过滤又会损害多样性与低资源语言覆盖。

## 二、核心原理

质量过滤分两类方法，常组合使用：
1. **启发式规则（基于统计特征）**：
   - 语言识别（fastText langid）剔除非目标语言。
   - 符号/标点比、大写比异常过滤。
   - 停用词比、平均句长、困惑度（用小语言模型算 PPL）阈值。
   - 行重复率、短行占比（垃圾模板特征）。
   代表：C4 用「含脏词、无终止标点、重复行」等规则；Gopher 用更细的统计阈值。
2. **分类器方法（基于模型）**：
   - 用少量高质量语料（如 Wikipedia、书籍）作正例，低质作负例，训二分类器（如线性模型、fastText、小型 BERT）对文本打分。
   - 代表：GPT-3 用 WebText 风格高质量文本训练分类器过滤 CC；LLaMA 用分类器区分高质量与低质量。
   分类器能捕捉语义级质量，优于纯规则，但依赖种子质量与领域适配。

## 三、形式化与数学基础

用参考语言模型计算困惑度（PPL）：

$$ \text{PPL}(x) = \exp\!\Big({-\frac{1}{N}\sum_{i=1}^{N}\log p_\theta(x_i\mid x_{<i})}\Big) $$

过滤规则常为：$ \text{PPL}(x) \le \tau $ 保留（困惑度越低越「自然」）。分类器给出质量分 $q_\phi(x)\in[0,1]$，阈值：

$$ \text{keep}(x)=\mathbf{1}[q_\phi(x)\ge \tau_q]\ \land\ \mathbf{1}[\text{PPL}(x)\le \tau_p] $$

二者常取交集或加权。通过率 $r = \frac{|\{x:\text{keep}\}|}{|\mathcal{D}|}$ 即为质量门控的筛选比例。

## 四、代码实现

```python
from fasttext import train_supervised
import fasttext, kenlm

# 1) 启发式：困惑度过滤（kenlm 语言模型）
arpa = kenlm.Model("news.arpa")
def ppl(text):
    return arpa.perplexity(text)

# 2) 分类器：用高质量/低质量种子训练
train_supervised(input="quality.train.txt", epoch=5, lr=0.5,
                 dim=100, output="quality.bin")
clf = fasttext.load_model("quality.bin")

def is_quality(text, tau_p=1e3, tau_q=0.6):
    if ppl(text) > tau_p:          # 困惑度过高=乱码/低质
        return False
    return float(clf.predict(text)[1][0]) >= tau_q
```

## 五、规则 vs 分类器对比

| 方法 | 速度 | 质量捕捉 | 需种子 | 误杀风险 |
|------|------|----------|--------|----------|
| 启发式规则 | 快 | 浅（统计） | 否 | 中 |
| PPL 阈值 | 快 | 中 | 需 LM | 中 |
| 分类器 | 中 | 深（语义） | 是 | 低-中 |
| 规则+分类器 | 中 | 深 | 部分 | 低 |

## 六、常见误区

- **分类器一定优于规则**：分类器依赖种子，种子偏则筛选偏；规则在异常模式（乱码）上更稳。
- **过度过滤**：把低资源语言、口语、专业术语误杀，损多样性。
- **单一阈值全局用**：不同域合理质量分布不同，应分域调参。
- **只看通过率**：通过率过高可能说明阈值太松，需下游验证。

## 九、演进与趋势

- **语义质量模型**：用强 LLM 给文本打「教育价值」分。
- **分域自适应阈值**：不同语料域用不同质量门控。
- **合成数据补充**：用高质量合成文本弥补过滤后缺口。
- **可学习过滤**：把过滤作为可微模块与训练联合优化。

## 十、小结

质量过滤是预训练数据管线的关键闸门，通常「规则/困惑度初筛 + 分类器精筛」组合，Common Crawl 通过率常低于 30%。核心是平衡质量与多样性：阈值过松留噪声、过严损覆盖，需按域调参并以下游能力验证。
