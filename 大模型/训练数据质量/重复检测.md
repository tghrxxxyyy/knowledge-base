# 重复检测与去重

> 对应 Lee et al. 2022「Deduplicating Training Data」、MinHash+LSH (Broder 1997) 与 Google 数据去污染实践。

## 一、背景与挑战

大规模网络语料存在海量重复：同一篇文章被数百个网站转载、模板页（导航/页脚）反复出现、近似改写互相抄袭。若不去重直接训练，模型会对高频样本「过拟合」——记住而非泛化，表现为在重复内容上困惑度虚低、但真实泛化与下游任务反而下降；更严重的是，测试集若与训练集有重叠（数据污染），评测分数会严重失真。Lee et al. (2022) 在 C4 上去重后，模型困惑度下降、下游任务提升，且所需训练步数更少。挑战在于：精确重复易处理，但「近似重复」（同义改写、小幅改动、跨语言翻译）需近似算法；数据量达 TB 级时，两两比较不可行，需可扩展的近重复检测。

## 二、核心原理

去重分两层：
1. **文档级精确去重**：对文档算哈希（如 SHA256），相同即删。简单但只能抓逐字复制。
2. **近似重复检测（Near-duplicate）**：用 **MinHash + LSH** 估计集合（如 n-gram 集合）的 Jaccard 相似度，把相似度高于阈值（如 0.8）的判为重。流程：
   - 把文档表示为词/字符 n-gram 集合。
   - 用 $k$ 个 MinHash 函数得文档签名（signature）。
   - 用 LSH 按签名分桶，同桶大概率相似，只在桶内精确比 Jaccard。
   - 相似度 $\ge \tau$ 则去重（保留其一）。
3. **语义/嵌入去重**：用句向量聚类找语义重复，但成本高、常用于小规模精修。

此外「数据去污染」（decontamination）专门检测训练集与评测集（如 GSM8K、MMLU）的 n-gram 重叠，防泄漏。

## 三、形式化与数学基础

文档表示为 n-gram 集合 $S_x$。Jaccard 相似度：

$$ J(x,y)=\frac{|S_x\cap S_y|}{|S_x\cup S_y|} $$

MinHash 用 $k$ 个哈希函数估计：$ \hat{J}\approx \frac{1}{k}\sum_{i=1}^k \mathbf{1}[h_i(S_x)=h_i(S_y)] $，误差随 $k$ 增大减小。LSH 将签名分 $b$ 个 band、每 band $r$ 行（$b\cdot r=k$），同 band 全相等则该对被候选，碰撞概率：

$$ P_{\text{cand}} = 1 - (1 - J^r)^b $$

调 $b,r$ 控制召回/精度。去重决策：$\text{drop}(y\mid x)=J(x,y)\ge\tau$。

## 四、代码实现

```python
from datasketch import MinHash, MinHashLSH

def minhash(text, num_perm=128):
    m = MinHash(num_perm=num_perm)
    for ng in ngrams(text, 5):          # 5-gram 集合
        m.update(ng.encode("utf8"))
    return m

lsh = MinHashLSH(threshold=0.8, num_perm=128)
seen = set()
for i, doc in enumerate(corpus):
    mh = minhash(doc)
    if lsh.query(mh):                   # 已存在近似重复
        continue
    lsh.insert(f"d{i}", mh)
    seen.add(i)                         # 保留代表
deduped = [corpus[i] for i in seen]
```

```python
# 去污染：检测评测集 n-gram 是否出现在训练文本
def contaminated(train_ngrams, eval_text, n=13):
    return any(gram in train_ngrams for gram in ngrams(eval_text, n))
```

## 五、去重方法对比

| 方法 | 捕捉 | 成本 | 适用 |
|------|------|------|------|
| 精确哈希 | 逐字复制 | 极低 | 基础 |
| MinHash+LSH | 近似重复 | 低-中 | 大规模 |
| 嵌入聚类 | 语义重复 | 高 | 小规模精修 |
| n-gram 污染检测 | 评测泄漏 | 中 | 防作弊 |

## 六、常见误区

- **只做精确去重**：漏掉改写/转载，过拟合仍在。
- **阈值设太高**：近似重复逃逸，污染评测。
- **忽略跨源重复**：不同网站同文最该去，却常被分域处理遗漏。
- **去重后不复检污染**：评测集重叠需单独检测，通用去重不覆盖。

## 九、演进与趋势

- **语义去重**：用嵌入聚类替代 n-gram，捕捉改写与翻译重复。
- **跨语言去重**：同源多语译文识别。
- **在线去重**：流式训练中增量去重。
- **污染自动报告**：训练前自动扫描评测集重叠并告警。

## 十、小结

重复检测与去重防止模型记忆高频样本、避免评测污染。工程上「精确哈希 + MinHash/LSH 近似去重 + 评测集 n-gram 去污染」三层配合，Jaccard 阈值需权衡召回与精度。Lee et al. 证明去重能降困惑度、提下游、省步数。
