# 幻觉与事实错误

> 对应 LLM 幻觉（hallucination）与事实一致性研究。

## 一、背景与挑战

agent 在推理或总结中会编造事实、引用不存在的工具返回、张冠李戴。在开放域尤甚。

## 二、核心原理

根因：模型先验盖过观测、检索结果未被真正使用、生成时未对齐证据。加固：强制“言之有据”（引用工具/检索结果）、对关键事实做事实性校验、用 self-consistency 交叉验证。

## 三、数学形式

事实一致性：

$$F = \frac{|\{claim_i: supported_i\}|}{|\{claim_i\}|}$$

$F$ 低则需回溯证据。

## 四、代码实现

```python
for claim in extract_claims(answer):
    if not grounded(claim, evidence):
        flag_or_fix(claim)
```

## 五、与其他对比

- 与 可解释与信任 共享“有据可依”。
- 与 多智能体通信协议深入 的辩论可交叉证伪。

## 六、常见误区

- 把检索到的当真，未验证检索本身错误。
- 仅靠模型自检，仍可能自洽地错。

## 八、面试题

- 为何检索不能根除幻觉？答：检索可能错或不被真正使用，需强制证据绑定与校验。

## 九、演进

无校验 → 检索增强 → 事实校验+交叉验证。

## 十、小结

幻觉靠“证据绑定+独立校验”压制，让每个主张可溯源。
