# 规划与分解失败

> 对应 任务规划（planning）研究（如思维树/计划-执行分离）。

## 一、背景与挑战

复杂任务需正确分解为子目标与顺序。智能体常出现漏步、顺序错、循环依赖、目标漂移。

## 二、核心原理

失败多因：上下文丢失全局目标、子任务间依赖未建模、过早乐观宣告完成。加固：显式维护目标栈与完成检查表，规划与执行分离并相互校验。

## 三、数学形式

目标完成度：

$$g = \frac{|\{sub_i: done_i\}|}{N},\quad g=1 \implies finish$$

未完成子目标即不可宣告成功。

## 四、代码实现

```python
checklist = decompose(goal)
for sub in checklist:
    if not verify(execute(sub)): replan(sub)
```

## 五、与其他对比

- 与 工具调用错误恢复深入 的“反思纠正”配合修计划。
- 与 长程任务记忆压缩深入 共担目标追踪。

## 六、常见误区

- 无完成检查，模型自说“完成”即停。
- 分解过粗，单步仍不可执行。

## 八、面试题

- 如何防“假完成”？答：用可验证检查表而非模型自述判定完成。

## 九、演进

无计划 → 单链计划 → 计划-执行分离+校验。

## 十、小结

规划失败靠“可验证分解”治愈，把模糊目标变成可勾选清单。
