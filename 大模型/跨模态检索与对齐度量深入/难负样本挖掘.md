# 难负样本挖掘

> 对应 跨模态检索与对齐中 hard negative mining（如 ALBEF 中 momentum 模型挖掘难负）研究。

## 一、背景与挑战

随机负样本太易，模型学不到细粒度区分。难负样本（与正样本相似却错误）迫使模型关注语义细节。挑战是挖掘代价、误挖（把真相关当负）与训练不稳定。

## 二、核心原理

用 momentum encoder 维护特征队列，按相似度挑最像正对的负样本作为难负。ALBEF 以对比得分排序取 top 非配对为负，提升 ITM/ITC 难度。需权衡难度，过难致训练崩溃。

## 三、数学形式

对查询 i，候选负集合 \mathcal{N}_i，难负：
n_i^* = \arg\max_{j\in\mathcal{N}_i, j\neq i} s_{i,j}
对比损失对难负加权或重采样。InfoNCE 中分母含难负使梯度更强：
L = -\log\frac{e^{s_{i,i}/\tau}}{\sum_{j} e^{s_{i,j}/\tau}},\ j 含难负。

## 四、代码实现

```python
def mine_hard_negative(sim_row, pos_idx, k=1):
    mask = torch.ones_like(sim_row, dtype=bool)
    mask[pos_idx] = False
    negs = sim_row[mask]
    return negs.topk(k).indices      # 最相似的负样本
```

## 五、与其他对比

相比随机负，难负提升表征判别力；相比全部负，控制计算；momentum 队列提供大量难负且低耦。过难负需温度/权重调节。

## 六、常见误区

误挖真相关为负面；负过难致 loss 不降；忽略队列更新 stale 问题；未与温度协同。

## 八、面试题

- Q：难负作用？答：迫使模型学细粒度区分。
- Q：ALBEF 如何挖？答：momentum 队列按相似度选最像负。
- Q：风险？答：误挖、过难致不稳定。

## 九、演进

从离线挖掘到在线队列；从单负到多负加权；与损失重加权结合。

## 十、小结

难负样本挖掘是提升跨模态对齐判别力的关键技巧，需在难度与稳定性间精细权衡。
