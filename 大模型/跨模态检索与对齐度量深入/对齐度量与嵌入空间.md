# 对齐度量与嵌入空间

> 对应 Wang & Isola 2020 「Understanding Contrastive Representation Learning」对齐-均匀性度量框架。

## 一、背景与挑战

如何定量刻画嵌入空间质量？Wang & Isola 提出对齐性（alignment）与均匀性（uniformity）两个维度，解释对比学习为何有效，并指导多模态嵌入评估。

## 二、核心原理

对齐性衡量正对特征距离应小；均匀性衡量特征在球面上应均匀分布、不坍塌。二者平衡决定表征既语义紧凑又具区分度。多模态对齐同样可借这两指标诊断图像/文本空间。

## 三、数学形式

对齐性：
\mathcal{L}_{align}=\mathbb{E}_{(x,x^+)\sim p_{pos}}\|f(x)-f(x^+)\|^2
均匀性：
\mathcal{L}_{uniform}=\log\mathbb{E}_{x,y\stackrel{iid}{\sim}p_{data}} e^{-2\|f(x)-f(y)\|^2}
好嵌入应同时最小化二者。

## 四、代码实现

```python
import torch

def alignment(z1, z2):
    return (z1 - z2).pow(2).sum(1).mean()

def uniformity(z):
    z = torch.nn.functional.normalize(z, dim=-1)
    pdist = (z.unsqueeze(0)-z.unsqueeze(1)).pow(2).sum(-1)
    return torch.log(torch.exp(-2*pdist).mean())
```

## 五、与其他对比

相比单一 recall，对齐-均匀从几何解释表征；可诊断 mode collapse（均匀性差）与语义混叠（对齐性差）。指导温度、负样本等超参。

## 六、常见误区

只看 recall 忽略空间几何；均匀性差仍判可用；混淆对齐与聚类；未对嵌入归一化再算。

## 八、面试题

- Q：对齐与均匀？答：正对近、分布均匀两目标。
- Q：坍塌表现？答：均匀性差，特征堆一起。
- Q：如何诊断嵌入？答：算 align/uniform 双指标。
