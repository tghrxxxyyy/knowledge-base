# 相似度校准

> 对应 多模态嵌入校准研究（如 scaling cosine similarity、temperature 校准与置信度估计）。

## 一、背景与挑战

CLIP 类相似度未归一化为可靠概率，阈值难设、跨分布不稳定。校准使相似度反映真实匹配概率，对检索阈值、拒绝策略与不确定性估计至关重要。

## 二、核心原理

常用温度缩放（temperature scaling）或 Platt scaling 把 logits 映射到校准概率。对检索，可用验证集拟合阈值使 precision 达标。也可学习每类/每模态偏置校正分布偏移。

## 三、数学形式

温度缩放：\hat{p}=\sigma(s/\tau)，\tau 由验证集最小负对数似然得到。对于二分类 ITM 概率，Platt：
\hat{p}=\sigma(a\cdot s + b)
校准质量用期望校准误差 ECE：
\mathrm{ECE}=\sum_{m=1}^M \frac{|B_m|}{n}| \mathrm{acc}(B_m)-\mathrm{conf}(B_m)|

## 四、代码实现

```python
import torch.nn.functional as F

def temperature_scale(logits, tau=0.07):
    return F.sigmoid(logits / tau)

def ece(conf, correct, bins=10):
    e = 0.0
    for b in range(bins):
        m = (conf >= b/bins) & (conf < (b+1)/bins)
        if m.sum() == 0: continue
        e += m.sum()*abs(correct[m].float().mean()-conf[m].mean())
    return e / len(conf)
```

## 五、与其他对比

相比原始余弦，校准后阈值可解释；相比重训，scaling 廉价；对安全拒绝（低置信不答）尤其重要。

## 六、常见误区

把相似度当概率用；忽略分布偏移致校准失效；只用训练集拟合 tau；混淆校准与归一化。

## 八、面试题

- Q：为何校准？答：使相似度成可靠概率，便于阈值。
- Q：常用方法？答：温度缩放、Platt scaling。
- Q：ECE 衡量？答：分组置信与准确率偏差。

## 九、演进

从固定 tau 到可学习每模态缩放；与不确定性结合；分布鲁棒校准。

## 十、小结

相似度校准把嵌入距离转化为可信概率，是检索阈值、拒绝回答与跨分布鲁棒性的基础一步。
