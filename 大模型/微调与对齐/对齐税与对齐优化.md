# 对齐税与对齐优化

> 对应 llm-course 与「Alignment Tax」讨论。

## 一、核心概念

**对齐税(Alignment Tax)**：对齐(RLHF/DPO)后模型在某些能力(如预训练学到的知识、推理)上可能下降。优化方向：

- **高质量 SFT 数据**减少税。
- **参考模型保留**防止遗忘（DPO 的 `π_ref`）。
- **迭代式 DPO / 拒绝采样**提升。
- **DPO 与 SFT 比例平衡**。

## 二、关键要点

| 策略 | 效果 |
|------|------|
| 强 SFT 基座 | 降低税 |
| 控制 β | 平衡能力/对齐 |
| 拒绝采样 | 提质 |
