# 奖励模型 Reward Model

> 对应 InstructGPT（Ouyang et al., 2022）与 llm-course「Reward Model」。

## 一、背景与挑战

在 RLHF 中，强化学习需要「奖励」来指导策略优化，但人类无法为每一个可能回答标注绝对分数。实践中采用**成对偏好数据**：对同一提示给出两个回答 $(y_w, y_l)$，仅标注「哪个更好」。奖励模型（Reward Model, RM）的任务就是从这个弱监督信号中学习一个标量打分函数 $r_\phi(x,y)$，使其在被选回答上的得分高于被拒回答。RM 的质量直接决定后续 PPO 对齐的上限，所谓「垃圾进垃圾出」。

## 二、核心原理

RM 通常基于 SFT 模型初始化，移除其语言建模头，接一个标量输出头（输出维度为 1）。训练目标采用 Bradley–Terry 概率模型：假设人类在 $y_w$ 与 $y_l$ 间选择 $y_w$ 的概率由两者得分差经 sigmoid 决定，于是最大化该概率等价于最小化以下负对数似然：

$$
\mathcal{L}(\phi) = -\,\mathbb{E}_{(x,y_w,y_l)}\Big[\log\sigma\big(r_\phi(x,y_w)-r_\phi(x,y_l)\big)\Big]
$$

直观上，只要 $r(x,y_w) > r(x,y_l)$，损失就下降；差距越大损失越小。训练时主干常部分冻结或全量微调，但需警惕「表征漂移」——因此常从 SFT 模型共享初始化以保持表征一致。

## 三、形式化与数学基础

Bradley–Terry 模型下，给定提示 $x$，人类偏好 $y_w\succ y_l$ 的概率为：

$$
P(y_w\succ y_l\mid x) = \sigma\big(r(x,y_w) - r(x,y_l)\big)
$$

RM 训练即最大化该似然。为避免 RM 对长回答过奖（长度偏差），常在奖励中减去长度惩罚项 $r_{\text{penalty}} = c\cdot |y|$，或在损失中对长度做归一九。训练稳定性上还常用「同一提示多对比较」构造批内对比，提升数据利用效率。RM 的校准（calibration）亦很重要：过度自信的 RM 会放大奖励黑客。

## 四、代码实现

```python
import torch.nn.functional as F

def reward_loss(r_w, r_l):
    # r_w, r_l: 奖励模型对选/拒回答的标量打分，形状 [batch]
    return -F.logsigmoid(r_w - r_l).mean()

# 前向：共享基座 + 标量头
score_w = rm_score(model, x, y_w)   # [B,1]
score_l = rm_score(model, x, y_l)
loss = reward_loss(score_w, score_l)
loss.backward()
```

```python
# 长度偏差校正（可选）
loss = reward_loss(score_w - c*len(y_w), score_l - c*len(y_l))
```

## 六、常见误区

- 奖励模型过强导致策略「讨好 RM」：即 reward hacking，模型用格式化、冗长、套话骗取高分而非真正有用，称为 RM 过优化。
- 偏好数据噪声大：标注者不一致会让 RM 难以收敛，偏好一致性比规模更重要。
- 忽略长度偏向：人类常偏好更长回答，RM 易学会「越长分越高」，需显式校正。
- 用 RM 当绝对质量指标：RM 只反映「相对偏好」，跨分布外泛化弱，不能当客观评分器。

## 九、演进与趋势

RM 研究聚焦降低奖励黑客：包括奖励建模的集成与不确定性估计、多目标 RM（分别建模有用性/安全性）、直接偏好优化（DPO）以隐式奖励替代显式 RM、以及 Constitutional AI 用规则生成偏好减少人工标注。以官方最新文档为准。

**实践要点：**

- 偏好数据一致性远比规模重要：标注者间一致性低的配对应剔除或加权，否则 RM 学到噪声。
- 训练时可加「同一提示多对」批内对比，提升数据利用效率并缓解位置偏差。
- RM 上线前应做「奖励黑客红队测试」：构造易套话回答，看 RM 是否 Abnormal 高分。
- 可将 RM 与策略同族初始化以保证表征一致，并定期用新偏好数据迭代刷新 RM。

## 十、小结

奖励模型是把人类偏好转化为可优化信号的桥梁，其质量决定 RLHF 上限；成对 Bradley–Terry 训练、长度校正与防过优化是工程重点，而 DPO 等新方法正逐步弱化对显式 RM 的依赖。
