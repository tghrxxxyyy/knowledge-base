# 奖励模型 Reward Model

> 对应 InstructGPT 与 llm-course「Reward Model」。

## 一、核心概念

奖励模型从**成对偏好数据** `(x, y_w, y_l)`（y_w 优于 y_l）学习标量打分。训练目标为 Bradley-Terry 模型下的最大似然：

```
L(φ) = - E[ log σ( r_φ(x,y_w) - r_φ(x,y_l) ) ]
```

常用 SFT 模型去掉最后一层，加标量头，共享基座初始化以避免表征漂移。

## 二、数学形式

```
P(y_w ≻ y_l | x) = σ(r(x,y_w) - r(x,y_l))
```

## 三、关键要点

| 要点 | 说明 |
|------|------|
| 数据质量 | 标注一致性关键 |
| 过优化 | RM 被黑客攻击 |
| 长度偏向 | 需校正 |

## 四、常见误区

- 奖励模型过强导致策略为「讨好 RM」而失真（reward hacking）。
- 偏好数据噪声大时 RM 难以收敛。
