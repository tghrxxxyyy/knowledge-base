# 全参数微调 Full Fine-Tuning

> 对应 rasbt/LLMs-from-scratch 第6章与 llm-course「Model Fine-tuning」。

## 一、核心概念

全参数微调(Full FT)更新模型**所有**权重以适配下游任务。优点：表达力最强；缺点：显存/存储开销大（每任务一份完整权重）、易过拟合小数据、灾难性遗忘。

适用：数据充足(数万+样本)、任务与预训练分布差异大。

## 二、数学形式

与预训练同目标，但在任务数据 `D_task` 上：

```
θ* = argmin_θ  (1/|D|) Σ L_task(f_θ(x), y)
```

## 三、代码实现（HF Trainer 示意）

```python
from transformers import Trainer, TrainingArguments
args = TrainingArguments(
    output_dir="./ft", per_device_train_batch_size=4,
    num_train_epochs=3, learning_rate=2e-5,
    gradient_accumulation_steps=8, fp16=True)
trainer = Trainer(model=model, args=args, train_dataset=ds)
trainer.train()
```

## 四、关键要点

| 维度 | 全参数 FT | PEFT |
|------|-----------|------|
| 显存 | 高 | 低 |
| 存储 | 每任务全量 | 仅增量 |
| 过拟合风险 | 中高 | 低 |

## 五、常见误区

- 小数据集直接全参数 FT 易过拟合，应优先 PEFT。
- LR 直接套用预训练值过大，FT 通常 1e-5~5e-5。
