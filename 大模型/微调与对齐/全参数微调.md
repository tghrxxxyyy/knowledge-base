# 全参数微调 Full Fine-Tuning

> 对应 rasbt/LLMs-from-scratch 第 6 章与 llm-course「Model Fine-tuning」。

## 一、背景与挑战

全参数微调（Full Fine-Tuning，FFT）更新模型的**所有**权重以适配下游任务，表达力最强、不引入任何结构假设。但它的代价同样显著：其一，训练显存约为推理的 12–16 倍（需存梯度与 Adam 的动量/方差）；其二，每任务一份完整权重，多任务服务存储爆炸；其三，小数据上极易过拟合与灾难性遗忘；其四，学习率、步数等超参比 PEFT 更敏感。因此何时用 FFT、何时用 PEFT 是工程关键决策。

## 二、核心原理

FFT 与预训练使用完全相同的目标（通常是自回归或掩码语言建模的交叉熵），只是数据与规模不同：在任务数据 $\mathcal{D}_{\text{task}}$ 上最小化经验风险：

$$
\theta^* = \arg\min_{\theta}\ \frac{1}{|\mathcal{D}|}\sum_{(x,y)\in\mathcal{D}} \mathcal{L}\big(f_\theta(x),\, y\big)
$$

关键差异在超参与数据量：预训练用大 batch、高 LR、海量数据；FFT 用极小 LR（常 $1e-5\sim5e-5$）、少 epoch、有限数据，以免破坏预训练已学到的表征。优化器多为 AdamW，配合线性 warmup 与余弦衰减。

## 三、形式化与数学基础

对自回归语言模型，FFT 在回答 token 上计算负对数似然（同 SFT 的 loss mask 思路）：

$$
\mathcal{L}_{\text{FT}} = -\sum_{t\in \text{answer}} \log p_\theta(x_t\mid x_{<t})
$$

显存占用可粗略估计为：权重 $2\Phi$（FP16 参数+梯度）+ 优化器状态 $12\Phi$（Adam 的 $m,v$ 各 $4\Phi$ 加参数 $4\Phi$）。因此 7B 模型 FFT 约需 $7\text{B}\times14\,\text{byte}\approx 98\text{GB}$ 训练显存（不计入激活），需多卡或 ZeRO 切分。

## 四、代码实现

```python
from transformers import Trainer, TrainingArguments, AutoModelForCausalLM

args = TrainingArguments(
    output_dir="./ft",
    per_device_train_batch_size=4,
    gradient_accumulation_steps=8,      # 等效 batch 32
    num_train_epochs=3,
    learning_rate=2e-5,                 # FFT 典型 LR，远小于预训练
    warmup_ratio=0.03,
    lr_scheduler_type="cosine",
    fp16=True,
    logging_steps=10,
)
model = AutoModelForCausalLM.from_pretrained("base-model")
trainer = Trainer(model=model, args=args, train_dataset=ds)
trainer.train()
```

## 六、常见误区

- 小数据集直接全参数 FT：极易过拟合，应优先 PEFT 或强数据增强。
- LR 直接套用预训练值：预训练 LR（如 3e-4）对 FT 过大，会破坏已有表征，FT 通常 $1e-5\sim5e-5$。
- 忽略梯度检查点/混合精度：不开启会显存翻倍，多卡需配合 DeepSpeed ZeRO。
- 以为 FFT 一定优于 PEFT：多数下游任务 PEFT 已接近 FFT，且更稳。

## 九、演进与趋势

随着 ZeRO、梯度检查点、FlashAttention 与 8/4-bit 优化器状态（如 Adam 8-bit）的成熟，FFT 的单卡门槛持续下降。但在超大模型上，行业主流已转向「FFT 仅用于继续预训练/对齐前 SFT，下游适配用 PEFT」的混合策略。以官方最新文档为准。

**实践要点：**

- 显存紧张时务必开启梯度检查点（`gradient_checkpointing=True`）与混合精度，可省约 30%~50% 激活显存。
- 多卡训练优先用 DeepSpeed ZeRO-2/3 切分优化器与参数状态，单卡可用 CPU offload 但会降速。
- 学习率热身（warmup）不可省，避免初始大梯度破坏预训练表征。
- 训练前冻结 embedding 或 LayerNorm 有时可进一步稳训练，但需按任务验证是否影响表达力。

## 十、小结

全参数微调表达力最强，却受显存、存储与过拟合制约；它是继续预训练与数据充足场景的必选项，但在下游轻量适配中应让位于 PEFT。
