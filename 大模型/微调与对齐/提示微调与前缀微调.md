# 提示微调与前缀微调

> 对应 llm-course 与 Prompt Tuning / Prefix Tuning 论文。

## 一、核心概念

- **Prompt Tuning**(Lester et al., 2021)：在输入前拼接可学习的**软提示(soft prompt)**向量 `P ∈ ℝ^{k×d}`，仅训练 `P`，冻结主干。
- **Prefix Tuning**(Li & Liang, 2021)：在每层注意力前加可学习前缀键/值，控制生成。
- **P-Tuning v2**：将 prompt 应用于每层，接近 Adapter 效果。

## 二、数学形式

Prompt Tuning 输入变为 `[P; x]`，损失：

```
L = -log P(y | [P; x]; θ_frozen, P_trainable)
```

## 三、关键要点

| 方法 | 训练参数 | 位置 |
|------|----------|------|
| Prompt Tuning | 软提示 | 输入嵌入 |
| Prefix Tuning | 前缀 K/V | 每层注意力 |
| P-Tuning v2 | 多层提示 | 深层 |

## 四、与开源书的对应

- Lester et al., *The Power of Scale for Parameter-Efficient Prompt Tuning*, 2021.
- Li & Liang, *Prefix-Tuning*, 2021.
