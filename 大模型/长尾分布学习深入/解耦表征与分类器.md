# 解耦表征与分类器

> 见「长尾分布学习深入/长尾分布总览」；Kang et al., *Decoupling*, 2019；cRT/LWS。

## 一、背景与挑战

联合训表征+分类器时，二者为头部妥协，尾类表征也受影响。

## 二、核心原理

**解耦**：先在正常分布上学表征（backbone），然后**冻结表征**，仅用重采样/重加权训练分类器（cRT：分类器重训练；LWS：学习层缩放权重）。这样表征不被尾类噪声破坏，分类边界可专门针对长尾调整。

## 三、关键要点

- 表征学「通用」、分类器学「均衡」。
- 两步法常优于一步联合。

## 四、代码实现

```python
backbone.eval()
clf = train_classifier(backbone.features, reweighted=True)
```

## 五、与其他对比

- 联合训练被头部主导；解耦保护表征。

## 六、常见误区

- 解耦必优——表征本身也需够好。
