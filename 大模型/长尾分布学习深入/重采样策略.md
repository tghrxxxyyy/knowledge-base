# 重采样策略

> 见「长尾分布学习深入/长尾分布总览」；SMOTE 为经典过采样。

## 一、背景与挑战

直接按原始分布采样，尾类几乎学不到。

## 二、核心原理

- **过采样尾类**：重复/插值（SMOTE 在特征空间合成近邻样本）。
- **欠采样头类**：减少头类样本平衡。
- **两阶段采样**：训练不同轮次不同分布（课程式）。
问题在于过采样易过拟合、欠采样丢信息。

## 三、数学形式

采样概率 `p_i ∝ 1/n_i^α`（α∈[0,1] 控制均衡度）。

## 四、代码实现

```python
sampler = WeightedRandomSampler(weights, num_samples=N)
```

## 五、关键要点

- α=0 原始，α=1 完全均衡。
- SMOTE 对高维文本/图像需适配。

## 六、与其他对比

- 重采样改数据；重加权改损失。

## 七、常见误区

- 完全均衡最好——过头伤头类。
