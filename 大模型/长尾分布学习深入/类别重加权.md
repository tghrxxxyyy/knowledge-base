# 类别重加权

> 见「长尾分布学习深入/长尾分布总览」；Cui et al., *Class-Balanced Loss*, 2019。

## 一、背景与挑战

能否不改数据、只调损失？

## 二、核心原理

按类有效样本数反比为每类分配权重。Class-Balanced 用**有效样本数** `E_n = (1-β^n)/(1-β)` 估计「新增样本的信息量递减」，权重 `w_i = (1-β)/(1-β^{n_i})`。

## 三、数学形式

见上；β 接近 1 时尾类权重显著上升。

## 四、代码实现

```python
def cb_weight(n, beta=0.999):
    return (1-beta) / (1 - beta**n)
```

## 五、关键要点

- 比简单 1/n 更平滑。
- 可与 focal 组合。

## 六、与其他对比

- 重采样改分布；重加权改目标。

## 七、常见误区

- 权重越大越好——过加权尾类不稳。
