# 分布偏移与尾部

> 见「长尾分布学习深入/长尾分布总览」与「泛化理论深入/分布外泛化」。

## 一、背景与挑战

训练分布与真实分布不同，尾部在测试时比重可能更高（OOD）。

## 二、核心原理

长尾训练 + 测试分布偏移，尾类更易崩。需结合**域泛化/不变风险**与重加权，使模型在偏移下仍保尾类能力；评测须包含尾部子集准确率。

## 三、关键要点

- 仅看总体 acc 会掩盖尾类崩塌。
- 需分组/尾类单独评测。

## 四、代码实现

```python
acc_tail = accuracy(pred[tail_mask], y[tail_mask])
```

## 五、与其他对比

- 同分布看总体；偏移需分组。

## 六、常见误区

- 总体高即好——尾类可能很差。
