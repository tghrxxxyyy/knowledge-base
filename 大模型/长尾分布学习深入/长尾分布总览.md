# 长尾分布学习总览

> 对应 d2l-zh；Liu et al., *Long-Tail*, 2019 综述；Cui et al., *Class-Balanced*, 2019。

## 一、背景与挑战

真实类别频率呈长尾：少数头部类样本多，海量尾类样本极少，模型偏向头部。

## 二、核心原理

四大类解法：1) **重采样**（过采样尾类/欠采样头类）；2) **重加权**（按类频反比为损失加权）；3) **解耦表征/分类器**（先学通用表征再调分类器）；4) **增广/迁移**（为尾类合成或借头部知识）。

## 三、关键要点

- 头类易过拟合、尾类欠拟合。
- 单纯重采样会损头类、过拟合尾类。

## 四、代码实现

```python
weight = 1. / class_freq
criterion = nn.CrossEntropyLoss(weight=weight)
```

## 五、与其他对比

| 法 | 代价 |
|----|------|
| 重采样 | 尾过拟合 |
| 重加权 | 训练不稳 |
| 解耦 | 两阶段 |

## 六、常见误区

- 均衡采样即解——可能损头类。
