# 长尾与大模型

> 见「长尾分布学习深入/长尾分布总览」；大模型也有「知识长尾」。

## 一、背景与挑战

预训练数据本身长尾（高频词/主题多，长尾知识少），导致尾类/长尾事实召回差。

## 二、核心原理

- **知识长尾**：罕见实体/语言/技能样本少，需过采样或检索增强补（RAG 缓解事实长尾）。
- **能力长尾**：复杂推理等稀有能力难学，靠合成数据/课程增强。
- **指令长尾**：长尾任务需专门指令覆盖。

## 三、关键要点

- RAG 是事实长尾的有效补丁。
- 合成数据可人工制造尾类样本。

## 四、代码实现

```python
# 检索补长尾事实
ctx = retrieve(query); ans = llm(query, ctx)
```

## 五、与其他对比

- 传统长尾在类频；LLM 在知识/能力频。

## 六、常见误区

- 大模型无长尾——知识长尾显著。
