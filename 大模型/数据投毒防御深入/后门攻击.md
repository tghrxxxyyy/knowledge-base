# 后门攻击（Backdoor）

> 对应 Gu et al., *BadNets*, 2017；植入触发器使模型特定输入误判。

## 一、背景与挑战

模型正常时表现好，但遇特定触发（词/图案）则输出攻击者目标。

## 二、核心原理

在训练样本加触发器并改标签为目标类；模型学“触发器→目标”强关联。

## 三、数学形式

损失 $\mathcal L=(1-\alpha)\mathcal L_{clean}+\alpha\mathcal L(x\oplus\Delta,y_t)$。

## 四、代码实现

```python
poisoned = [(add_trigger(x), tgt) for x in samples]
train(model, clean + poisoned)
```

## 五、与其他对比

- 与 数据投毒总览深入（后门是一类）包含。
- 与 红队攻击模拟深入（触发测试）衔接。

## 六、常见误区

- 触发器太显眼易被检测。
- 后门在干净集不易发现。

## 七、与开源书对应

## 八、面试题

- 后门为何隐蔽？答：仅在触发输入生效，干净输入正常，难从整体指标发现。

## 九、演进

固定触发 → 动态触发 → 语义触发。

## 十、小结

后门以隐藏触发控制模型，是投毒最危险形态。
