# 鲁棒训练与缓解

> 对应抗投毒训练；d2l-zh 鲁棒性 衔接。

## 一、背景与挑战

即使有少量毒数据混入，也需训练过程本身抗扰。

## 二、核心原理

差分隐私训练降记忆、梯度裁剪/截断降单样本影响、稳健聚合（中位数）、数据重加权。

## 三、数学形式

稳健聚合 $g=\text{median}(\{g_i\})$ 或 $\text{trim\_mean}$，抑制极端梯度。

## 四、代码实现

```python
grad = robust_aggregate(grads, method="trim_mean")
opt.step(grad)
```

## 五、与其他对比

- 与 隐私推理深入（DP 训练共享）衔接。
- 与 训练不稳定诊断深入（梯度处理）共享。

## 六、常见误区

- 以为 DP 完全防投毒（仅缓解记忆）。
- 鲁棒聚合增计算成本。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course
- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 鲁棒训练如何抗毒？答：稳健聚合/裁剪降单样本影响，DP 降记忆，多手段缓解。

## 九、演进

普通 SGD → 裁剪 → 稳健聚合+DP。

## 十、小结

鲁棒训练在过程层降投毒影响，是纵深防御一环。
