# 数据投毒防御实践

> 对应生产数据治理；训练数据质量 衔接。

## 一、背景与挑战

防御需嵌入数据流水线，而非事后补救。

## 二、核心原理

数据源白名单、入湖前清洗检测、训练期鲁棒、上线后监控异常行为回灌。

## 三、数学形式

流水线可靠度 $R=\prod_{stage}(1-p_{breach,stage})$。

## 四、代码实现

```python
data = ingest(src); data = clean_and_scan(data)
model = robust_train(data); monitor(model)
```

## 五、与其他对比

- 与 红队攻击模拟深入（后门触发测试）衔接。
- 与 安全分类器深入（异常输出监控）共享。

## 六、常见误区

- 只在采集端防，训练端无鲁棒。
- 上线后无监控致后门漏网。

## 八、面试题

- 投毒防御如何落地？答：白名单+入湖检测+鲁棒训练+上线监控，全链路闭环。

## 九、演进

事后检测 → 流水线内建 → 全链路闭环。

## 十、小结

投毒防御须全链路内建，并持续监控回灌。
