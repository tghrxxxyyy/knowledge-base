# 投毒检测与过滤

> 对应数据清洗/异常检测；训练数据质量 衔接。

## 一、背景与挑战

海量数据难逐条审，需自动识别可疑样本。

## 二、核心原理

用表征聚类找离群、用小型净模型打分筛低置信、用影响函数估单样本对参数的影响。

## 三、数学形式

影响近似 $I(x_i)\approx -\nabla_\theta\mathcal L(x_i)^\top H^{-1}\nabla\mathcal L_{val}$。

## 四、代码实现

```python
scores = clean_model.score(dataset)
suspect = [s for s in dataset if scores[s] < low]
```

## 五、与其他对比

- 与 安全分类器深入（异常判定）共享。
- 与 指令数据构建深入（过滤合成数据）衔接。

## 六、常见误区

- 聚类阈值误删正常长尾。
- 仅用单模型打分有偏。

## 八、面试题

- 如何检测投毒？答：离群聚类+净模型置信+影响函数，多信号交叉定位。

## 九、演进

人工审 → 聚类 → 影响函数。

## 十、小结

投毒检测靠多信号交叉，降低误删与漏检。
