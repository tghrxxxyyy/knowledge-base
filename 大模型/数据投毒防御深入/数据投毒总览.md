# 数据投毒防御总览

> 对应 Biggio et al., *Poisoning Attacks*, 2012；在训练数据注入恶意样本改变模型。

## 一、背景与挑战

当训练数据来源不可信（爬取/众包/第三方），攻击者可掺毒使模型学错行为。

## 二、核心原理

投毒在训练集中植入触发样本，使模型在特定输入触发错误/后门；防御在数据与训练期去毒。

## 三、数学形式

毒样本 $x_p=(x\oplus t, y_{target})$，目标 $\min_\theta \mathcal L_{clean}+\mathcal L_{poison}$。

## 四、代码实现

```python
for s in dataset:
    if poison_score(s) > thr: quarantine(s)
```

## 五、与其他对比

- 与 指令数据构建深入（合成数据亦可能含毒）衔接。
- 与 模型提取攻击深入（不同威胁）区分。

## 六、常见误区

- 以为只影响小模型（大模型亦可被微调投毒）。
- 忽视供应链数据来源。

## 八、面试题

- 数据投毒是什么？答：在训练集掺恶意样本，使模型学错/留后门。

## 九、演进

标签翻转 → 后门触发 → 微调期注入。

## 十、小结

数据投毒威胁训练完整性，需全链路防御。
