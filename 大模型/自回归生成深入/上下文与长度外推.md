# 上下文与长度外推

> 对应 Press et al., *ALiBi*, 2021；Chen et al., *RoPE 外推/NTK*, 2023；长上下文技术 对照。

## 一、背景与挑战

训练上下文有限，推理时输入可能更长；位置编码决定能否外推。

## 二、核心原理

- 绝对位置：训练长度外推差。
- ALiBi：bias 随距离线性衰减，无需位置嵌入，利于外推。
- RoPE + NTK 缩放：旋转频率插值，使更长位置可被近似。

## 三、数学形式

ALiBi bias：$m_{ij} = -s\cdot|i-j|$，直接加到注意力分数；NTK 缩放改基频 $\theta_k$ 使高频信息细分。

## 四、代码实现

```python
bias = -torch.abs(i - j) * slope  # 加到 scores
scores = Q @ K.T / d + bias
```

## 五、与其他对比

- 位置插值（PI）直接拉伸位置索引；NTK 更保高频。
- 与 注意力数学基础 衔接（位置编码数学）。

## 六、常见误区

- 以为简单拉长上下文就外推；位置编码机制决定成败。
- 外推后长程注意力可能退化（Lost in the middle）。

## 八、面试题

- ALiBi 为何利于长度外推？答：线性距离偏置不依赖绝对位置嵌入。

## 九、演进

绝对位置 → 相对位置 → ALiBi/RoPE → NTK/PI 外推 → 长上下文训练。

## 十、小结

长度外推取决于位置编码设计，是长文档/长对话大模型的关键能力。
