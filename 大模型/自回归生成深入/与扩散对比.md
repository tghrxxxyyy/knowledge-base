# 自回归与扩散对比

> 对应多模态生成综述；自回归生成深入 与 扩散模型深入 综合。

## 一、背景与挑战

离散 token（文本）与连续信号（图像/音频）性质不同，需选合适生成范式。

## 二、核心原理

- 自回归：逐元 $p(x_i|x_{<i})$，天然序列、易对齐语言、强组合性。
- 扩散：并行去噪连续场，保真高、无曝光偏差、但需条件桥接文本。

## 三、数学形式

自回归 NLL 可解析评估（perplexity）；扩散用 FID/IS 等感知指标，NLL 难算。

## 四、代码实现

```python
# 文本自回归
next_tok = sample(model(x))
# 图像扩散
img = diffusion_step_loop(noise, cond)
```

## 五、与其他对比

- 文本多用自回归（离散、组合强）；图像/视频多用扩散（连续、保真）。
- 统一多模态尝试混合两范式（如扩散语言模型）。

## 六、常见误区

- 认为二者互斥；实际常级联（LLM 出布局→扩散出图）。
- 用文本指标评图像扩散不敏感（需 FID/人工）。

## 八、面试题

- 何时选自回归 vs 扩散？答：离散组合选自回归，连续保真选扩散。

## 九、演进

各自独立 → 级联（LLM+扩散）→ 统一多模态生成。

## 十、小结

自回归与扩散互补，分别主导离散与连续生成，构成现代多模态系统两端。
