# 自回归评测

> 对应 模型评测指标深入 / 模型评测基准实战；llm-course 评测部分。

## 一、背景与挑战

生成质量多面，单一指标偏颇；需结合自动与人工、参考与无参考指标。

## 二、核心原理

- 困惑度（PPL）：基于 NLL，$PPL=\exp(-\frac1N\sum\log p)$ 衡量似然。
- 无参考：Self-BLEU、distinct-n 衡量多样；有参考：BLEU/ROUGE。
- 指令/对齐：MT-Bench、IFEval、HumanEval（代码）。

## 三、数学形式

$PPL = \exp\left(\frac1N\sum_{t=1}^N -\log p(x_t|x_{<t})\right)$。

## 四、代码实现

```python
ppl = torch.exp(loss)  # loss 为平均 NLL
```

## 五、与其他对比

- PPL 与真实质量弱相关（尤其经 RLHF 后）。
- 人评最可靠但贵；LLM-as-judge 渐成标准但需防偏。

## 六、常见误区

- 唯 PPL 论；RLHF 后低 PPL 不一定更好。
- BLEU 难评语义等价；需语义指标补充。

## 七、与开源书对应

- llm-course：https://github.com/mlabonne/llm-course
- 模型评测指标深入 提供细节。

## 八、面试题

- 为什么 PPL 不等于生成质量？答：似然与对齐/有用性非单调相关。

## 九、演进

PPL/BLEU → 多参考/语义指标 → LLM-as-judge → 多维度基准。

## 十、小结

自回归评测需组合似然、参考与无参考、自动与人工指标，避免单一偏颇。
