# 自回归建模原理

> 对应 Oord et al., *PixelCNN*, 2016；Radford et al., *GPT*, 2018。

## 一、背景与挑战

用链式法则把高维分布分解为条件分布乘积：$p(x)=\prod_{i=1}^n p(x_i|x_{<i})$，逐元生成。

## 二、核心原理

语言模型以 token 序列为例：$p(x)=\prod_t p_\theta(x_t|x_{1:t-1})$；训练最大化对数似然（交叉熵）。

## 三、数学形式

负对数似然：$\mathcal L = -\sum_t \log p_\theta(x_t|x_{<t})$；$T$ 步生成每步采样一个 token。

## 四、代码实现

```python
logits = model(x[:, :-1])
loss = F.cross_entropy(logits.reshape(-1, V), x[:, 1:].reshape(-1))
```

## 五、与其他对比

- 自回归天然适合离散 token（文本/代码）；扩散适合连续（图像）。
- 自回归顺序生成长序列慢（需 $T$ 步）。

## 六、常见误区

- 误以为自回归只能文本；PixelCNN/RALLM 用于图像/音频。
- 混淆自回归与自监督（前者是生成分解，后者是表征学习）。

## 八、面试题

- 自回归的核心假设？答：数据联合分布可分解为条件分布乘积。

## 九、演进

n-gram → RNN LM → Transformer LM → 大规模 GPT 自回归。

## 十、小结

自回归以链式法则把生成变为序列预测，是文本大模型最主流的生成范式。
