# 采样策略

> 对应 Holtzman et al., *Top-p (nucleus)*, 2019；Fan et al., *top-k*, 2018。

## 一、背景与挑战

贪心/最大似然易重复或平淡；需平衡多样性与连贯性的解码策略。

## 二、核心原理

- 温度 $T$：软化分布 $p_i\propto \exp(z_i/T)$。
- Top-k：仅保留概率最高 $k$ 个并重归一化。
- Top-p（核）：取累计概率达 $p$ 的最小集合，动态截断。

## 三、数学形式

核采样：$\mathcal V^{(p)}=\min\{V'\subseteq V: \sum_{x\in V'}p(x)\ge p\}$，在此子集重采样。

## 四、代码实现

```python
logits = logits / T
k = max(1, int(p * vocab))
vals, idx = torch.topk(logits, k)
probs = softmax(vals); next_tok = torch.multinomial(probs, 1)
```

## 五、与其他对比

- 贪心/beam 保质量但易退化；采样增多样但可能离题。
- 与 RLHF（强化学习基础深入）后训练目标互补。

## 六、常见误区

- 温度过低仍重复、过高乱码；需依任务调。
- 误用 top-k 固定值忽视长尾分布形态。

## 八、面试题

- top-p 相对 top-k 的优点？答：按分布动态截断，自适应长尾。

## 九、演进

贪心 → beam → top-k → top-p → 对比解码/自洽。

## 十、小结

采样策略是控制生成质量与多样性的旋钮，生产常结合温度与核采样。
