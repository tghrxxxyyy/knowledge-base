# 多模态记忆

> 对应 LangChain / LlamaIndex 记忆机制文档、FAISS / Milvus 向量库实践、多模态检索增强（Multimodal RAG）相关论文。

## 一、背景与挑战

纯文本 Agent 的记忆是「字符串 + 文本向量」；多模态 Agent 还需记住图像、视频帧、界面截图。难点在于：(1) 图像原始像素体积大、直接存向量昂贵；(2) 图像与文本语义需在同一空间可检索；(3) 长程任务中哪些画面值得长期保留、哪些可丢弃；(4) 回忆时需跨模态——用文字查图、用图查文。记忆设计直接决定 Agent 的上下文连贯性与成本。

## 二、核心原理

多模态记忆通常采用「分层 + 多表示」策略：

- **原始图**：存对象存储（如 S3/本地），仅保留引用与元信息，避免占用上下文。
- **语义向量**：图像经 CLIP/ViT 编码为向量，存入向量库，支持相似检索。
- **文本摘要**：VLM 把关键帧转成文字描述，进入文本记忆，便于 LLM 推理。
- **时序索引**：按任务步骤标注画面顺序，支持「回到第 3 步的界面」。

检索时做多模态混合召回：文本查询可命中图像向量与文本摘要，图像查询亦可反查。

## 三、形式化与数学基础

图像 $x_v$ 与文本 $x_t$ 经各自编码器投影到共享嵌入空间：

$$e_v = E_v(x_v), \quad e_t = E_t(x_t), \qquad e_v, e_t \in \mathbb{R}^d$$

跨模态相似度（如 CLIP）最大化匹配对、最小化非匹配对，对齐后可用统一余弦距离检索：

$$\mathrm{sim}(q, m) = \frac{E(q)\cdot E(m)}{\|E(q)\|\,\|E(m)\|}$$

记忆库 $\mathcal{M}$ 的检索返回 top-$k$：

$$\{m_1,\dots,m_k\} = \mathrm{TopK}_{m\in\mathcal{M}}\ \mathrm{sim}(q, m)$$

为控成本，可设保留阈值：仅当 $|e_v|$ 信息量高或摘要差异大时入长期记忆。

## 四、代码实现

示意多模态记忆的存与取：

```python
class MultimodalMemory:
    def __init__(self, encoder, vector_db):
        self.enc, self.db = encoder, vector_db

    def add_image(self, img, step_id):
        vec = self.enc.encode_image(img)
        summary = self.enc.caption(img)          # VLM 文字摘要
        self.db.upsert({"vec": vec, "summary": summary, "step": step_id})

    def recall(self, query_text, k=3):
        q = self.enc.encode_text(query_text)
        hits = self.db.search(q, k)
        return [h["summary"] for h in hits]      # 返回摘要供 LLM
```

## 五、与其他技术对比

| 记忆类型 | 存什么 | 检索方式 | 成本 | 适用 |
|----------|--------|----------|------|------|
| 文本记忆 | 字符串 | 文本向量 | 低 | 对话 |
| 图像向量 | 视觉嵌入 | 跨模态 | 中 | 图库检索 |
| 关键帧摘要 | 文字 | 文本 | 低 | 长任务 |
| 原始图 | 像素 | 引用 | 存储高 | 需回看 |

## 六、常见误区

- 误区一：所有画面都存向量。图向量贵且冗余，应只存关键帧+摘要。
- 误区二：图文各存各的。不做共享空间会导致无法跨模态召回。
- 误区三：记忆无限增长。需淘汰/压缩旧画面，否则成本与噪声双升。

## 九、演进与趋势

(1) 统一多模态嵌入（图文音共享空间）让召回更自然。(2) 分层记忆：工作记忆+长期记忆+情景记忆三层。(3) 关键帧自动抽取：VLM 判断「信息增量」决定是否保留。(4) 与多模态 RAG 融合：记忆即检索语料。(5) 端侧轻量记忆：小模型本地缓存摘要。

## 十、小结

多模态记忆的核心是「分层表示 + 跨模态对齐」：原始图存对象存储、语义存向量、关键帧存文本摘要，检索时混合召回。它解决了纯文本记忆无法承载像素信息、且直接存图成本过高的矛盾，是多模态 Agent 长期任务连贯性的基石。
