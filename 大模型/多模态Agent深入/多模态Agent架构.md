# 多模态 Agent 架构

> 见「智能体工程深入」与「多模态深入」。

## 一、核心概念

多模态 Agent 以 VLM 为认知核心，能「看」图像/界面/文档，结合工具(搜索/生成/编辑)完成视觉任务。典型：GUI Agent(截图→理解→点击)、视觉问答 Agent(检索图库→答)、文档理解 Agent(读 PDF→抽取)。

## 二、关键要点

| 组件 | 作用 |
|------|------|
| VLM | 视觉理解 |
| 工具 | 操作/检索 |
| 记忆 | 历史画面 |
