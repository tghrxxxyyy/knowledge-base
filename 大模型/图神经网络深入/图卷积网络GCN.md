## 二、核心原理

GCN 用对称归一化邻接矩阵做一阶邻居聚合：
```
H^{(l+1)} = σ( D^{-1/2} Ã D^{-1/2} H^{(l)} W^{(l)} )
```
Ã=A+I，D 为度矩阵。每层混合自身与邻居，等价于图上的低通滤波。
