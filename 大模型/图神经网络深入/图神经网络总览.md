# 图神经网络总览

> 对应 d2l-zh 图神经网络章；Kipf & Welling, *GCN*, 2017；Wu et al., *GNN Survey*, 2020。

## 一、背景与挑战

图（社交/分子/知识图谱）是非欧结构，CNN/RNN 无法直接处理，需能聚合邻居信息的模型。

## 二、核心原理

GNN 核心是**消息传递（message passing）**：每节点迭代聚合邻居表征，更新自身。多层后节点含多跳邻域信息。

## 三、数学形式

```
h_v^{(l+1)} = σ( W·AGG({h_u^{(l)} : u∈N(v)}) )
```

## 四、代码实现

```python
import torch_geometric
out = gnn(x, edge_index)  # 消息传递自动完成
```

## 五、关键要点

- 层数过多会过平滑（over-smoothing）：所有节点趋同。
- 可处理变长邻居。

## 六、与其他对比

- CNN 规整网格；GNN 任意拓扑。

## 七、常见误区

- 层越深越好——过平滑。
