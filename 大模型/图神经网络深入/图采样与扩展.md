# 图采样与扩展

> 见「图神经网络深入/图神经网络总览」；Hamilton et al., *GraphSAGE*, 2017；Chen et al., *FastGCN*, 2018。

## 一、背景与挑战

全图训练显存随层数指数增长（邻居爆炸），工业大图不可行。

## 二、核心原理

- **GraphSAGE**：采样固定数邻居做聚合，支持归纳与大图。
- **邻居采样（PinSage/Cluster-GCN）**：按层采样或图聚类分批，控显存。
- **控制过平滑**：限制层数或加残差。

## 三、数学形式

每节点采样 k 邻居：`Ã` 变为采样邻接，近似全邻居。

## 四、代码实现

```python
loader = NeighborLoader(data, num_neighbors=[10,10])
batch = next(iter(loader))
```

## 五、关键要点

- 采样数平衡质量与显存。
- 大图必须用采样/聚类。

## 六、与其他对比

- 全图精确；采样近似但可扩展。

## 七、常见误区

- 大图可全批次——显存爆。
