# 局部窗口注意力

> 对应局部/滑动窗口注意力（如 Longformer、以及 Swin Transformer 的窗口思想）。

## 一、背景与挑战

许多序列（文本、图像块）的强依赖集中在邻近位置，远距离交互稀疏。

## 二、核心原理

每个 token 只与前后 $w$ 个邻居做注意力（滑动窗口），复杂度 $O(nw)$；配合多层叠加，感受野随层数线性增长，可覆盖较长距离。

## 三、数学形式

$o_i=\sum_{j=\max(0,i-w)}^{\min(n,i+w)}\alpha_{ij}v_j$；无全局 token 时最大覆盖距离约 $L\cdot w$（$L$ 层）。

## 四、代码实现

```python
def window_mask(n, w):
    idx = torch.arange(n)
    return (idx[:, None] - idx[None, :]).abs() <= w     # 带状掩码
```

## 五、与其他对比

- 与 稀疏注意力深入 其他模式（全局/块）互补。
- 与 FlashAttention深入 配合：窗口内用 FA 高效实现。

## 六、常见误区

- 单层窗口感受野太小，需足够层数或配合全局 token。
- 边界 token 邻居少，信息可能不足。

## 八、面试题

- 窗口注意力如何看到远距离？答：多层叠加使感受野随层数线性扩大，再辅以全局 token。

## 九、演进

固定窗口 → 滑动窗口+膨胀 → 层级窗口(Swin)。

## 十、小结

局部窗口以最低成本覆盖近邻依赖，是稀疏注意力的基础构件。
