# 稀疏注意力实现

> 对应各开源实现（Longformer/BigBird 的 `attention_mask` 与 `block_sparse` 实现）。

## 一、背景与挑战

稀疏模式需高效落地，避免 mask 开销抵消收益，并兼容现有框架。

## 二、核心原理

实现要点：把稀疏模式编码为 bool 掩码或块索引；局部窗口可用滑动/分块矩阵乘；全局/随机用 gather/scatter；与 FlashAttention 的变体（块稀疏 FA）结合可进一步提速。

## 三、数学形式

掩码 $M\in\{0,1\}^{n\times n}$，$scores_{ij}=s_{ij}$ if $M_{ij}=1$ else $-\infty$；块稀疏则按块 $B\times B$ 决定是否计算。

## 四、代码实现

```python
scores = q @ k.transpose(-1,-2)
scores = scores + (1 - mask.float()) * (-1e9)   # 稀疏掩码
out = torch.softmax(scores, -1) @ v
```

## 五、与其他对比

- 与 FlashAttention深入 可叠加（块稀疏 FA）。
- 与 层归一化深入 同属性能相关模块。

## 六、常见误区

- mask 用加法而非 mul 时数值溢出需 $-\infty$ 兜底。
- 未用融合 kernel，mask 物化反而更慢。

## 八、面试题

- 实现稀疏注意力注意什么？答：掩码编码、块化计算、与融合 kernel 结合避免额外开销。

## 九、演进

朴素 mask → 块稀疏 kernel → 与 FlashAttention 融合。

## 十、小结

稀疏注意力的工程价值取决于高效掩码与融合实现，否则难兑现理论加速。
