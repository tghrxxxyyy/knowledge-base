# 稀疏注意力与效率

> 对应 Child et al., 2019；以及 Longformer/BigBird 的效率评测（长序列吞吐与显存）。

## 一、背景与挑战

需量化稀疏注意力在真实硬件上相对稠密的加速与质量折中。

## 二、核心原理

当 $n\gg w$ 时稀疏把 $O(n^2)$ 降到 $O(nw)$，显存与延迟近线性；但稀疏模式固定可能略损需全局长程依赖的任务，须按任务调窗口/全局比例。

## 三、数学形式

加速比约 $\frac{n^2}{n w}=n/w$；质量损失 $\Delta = \mathrm{perf}_{dense}-\mathrm{perf}_{sparse}$，随模式覆盖度减小。

## 四、代码实现

```python
# 粗略测算
flops_dense, flops_sparse = n*n*d, n*w*d
speedup = flops_dense / flops_sparse      # ~ n/w
```

## 五、与其他对比

- 与 线性注意力深入 相比，稀疏保精确局部、线性更激进。
- 与 FlashAttention深入 互补：稀疏定模式，FA 定实现。

## 六、常见误区

- 短序列上稀疏反而更慢（kernel 开销）。
- 盲目增大窗口致失掉稀疏收益。

## 八、面试题

- 何时稀疏注意力不划算？答：短序列或需稠密全局依赖、且 FA 已足够快时，稀疏收益有限。

## 九、演进

理论稀疏 → 硬件友好实现 → 稀疏+FA 融合。

## 十、小结

稀疏注意力的效率收益在长序列显著，但需按任务平衡模式与质量。
