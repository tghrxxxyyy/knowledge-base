# 稀疏注意力总览

> 对应 Child et al., *Generating Long Sequences with Sparse Transformers*, 2019；Beltagy et al., *Longformer*, 2020；Zaheer et al., *Big Bird*, 2020。

## 一、背景与挑战

稠密注意力 $O(n^2)$ 限制长序列；但多数任务只需局部与少量全局交互，大量成对计算冗余。

## 二、核心原理

稀疏注意力把全连接注意力图替换为结构化稀疏模式（局部窗口、跨步/空洞、全局 token、随机连接），在保留关键依赖的同时把复杂度降到近线性。

## 三、数学形式

注意力只在边集合 $E$ 上计算：$o_i=\sum_{j:(i,j)\in E}\alpha_{ij}v_j$；$|E|=O(n\cdot w)$（$w$ 为窗口/连接数），复杂度 $O(nw)$。

## 四、代码实现

```python
mask = local_window_mask(n, w) | global_mask(n, g)
scores = (q @ k.transpose(-1,-2)) / d**0.5
scores = scores.masked_fill(~mask, float("-inf"))
out = torch.softmax(scores, -1) @ v
```

## 五、与其他对比

- 与 线性注意力深入 都降复杂度，但稀疏保持精确局部交互。
- 与 FlashAttention深入 可叠加：稀疏模式 + 分块高效实现。

## 六、常见误区

- 稀疏模式设计不当丢全局依赖（需全局 token）。
- 误以为稀疏注意力一定更快；mask 实现差反而慢。

## 八、面试题

- 稀疏注意力为何能降复杂度？答：只在结构化边集上计算注意力，边数随 $n$ 近线性。

## 九、演进

稠密 → 局部窗口 → 全局+局部 → 块稀疏(BigBird) → 与 FA 融合。

## 十、小结

稀疏注意力用结构化模式逼近全注意力，是长序列的可控近似路线。
