# 因果推理与 LLM

> 见「大模型与知识图谱/KG增强大模型」。

## 一、背景与挑战

LLM 学到相关性，未必理解因果，易在干预/反事实问题出错。

## 二、核心原理

把因果图（DAG）与 LLM 结合：用因果结构约束生成、做反事实推理、避免伪相关。

## 三、关键要点

- 因果图提供变量关系先验。
- 反事实问题需 do-calculus 视角。
