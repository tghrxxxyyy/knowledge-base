# 知识图谱问答

> 见「大模型与知识图谱/KG增强大模型」与「大模型与NL2SQL/大纲」。

## 一、背景与挑战

用自然语言查 KG 需把问题转成图查询（Cypher/SPARQL）。

## 二、核心原理

NL2Cypher：实体识别→意图→模板/LLM 生成查询→执行→自然语言回答。类似 Text2SQL 但面向图。

## 三、代码实现

```python
cypher = llm(f"依据 schema {schema} 生成 Cypher:\n{q}")
res = neo4j.run(cypher)
```

## 四、关键要点

- schema 提示很关键。
- 需校验查询语法与安全。

## 五、与其他对比

- NL2SQL 面向关系表；NL2Cypher 面向图。

## 六、常见误区

- 直接执行模型生成的查询——需权限与校验。

## 七、与开源书对应

- llm-universe: https://github.com/datawhalechina/llm-universe
- Neo4j LLM 示例。

## 八、面试题

- NL2Cypher 与 NL2SQL 异同？

## 九、演进

模板 → 语义解析 → LLM 生成查询。

## 十、小结

KGQA 把图数据库接入自然语言。
