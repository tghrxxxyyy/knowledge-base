# 行业知识图谱落地

> 见「大模型行业应用」与「大模型与知识图谱/KG增强大模型」。

## 一、背景与挑战

金融/医疗/制造有强结构化知识，KG+LLM 可提升专业问答可信度。

## 二、核心原理

先建领域 KG（本体+实例），再接 RAG/ Agents 做检索与推理，回答带出处、可审计。

## 三、关键要点

- 本体设计决定上限。
- 需持续更新保持时效。

## 四、代码实现

```python
ans = rag_over_kg(query, kg, llm, with_citation=True)
```

## 五、与其他对比

- 通用 LLM 泛化；领域 KG 精准。

## 六、常见误区

- KG 建好就一劳永逸——需运营更新。
