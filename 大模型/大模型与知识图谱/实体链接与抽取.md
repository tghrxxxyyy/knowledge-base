# 实体链接与抽取

> 见「大模型与知识图谱/KG增强大模型」。

## 一、背景与挑战

文本要接入 KG，先得识别实体并链到正确节点。

## 二、核心原理

**抽取**：NER/关系抽取得到（实体,关系,实体）。**链接**：把提及映射到 KG 节点（消歧）。LLM 可零样本完成两者。

## 三、代码实现

```python
triplets = llm(f"从文本抽取三元组:\n{text}")
```

## 四、关键要点

- 同名实体消歧是难点。
- 低资源实体易链错。

## 五、与其他对比

- 传统 pipeline 模块多；LLM 端到端更简。

## 六、常见误区

- 抽取即准确——需置信度与人工抽检。

## 七、与开源书对应
