# 图文检索指标

> 对应 CLIP / 图文检索基准（MS-COCO, Flickr30k）评测惯例。

## 一、背景与挑战

图文检索需双向评测：以文检图（TR）与以图检文（IR），单方向无法反映对齐质量。

## 二、核心原理

常用 Recall@k（R@1/R@5/R@10）：正确匹配是否进入前 k。此外有 mAP、中位排名（median rank）。报告时区分 I2T 与 T2I。

## 三、数学形式

$$R@k = \frac{1}{N}\sum_{i=1}^N \mathbb 1[\text{rank}_i \le k]$$

$\text{rank}_i$ 为正确配对在相似度排序中的位置。

## 四、代码实现

```python
def recall_at_k(sim, k=5):
    order = sim.argsort(1, descending=True)
    hits = (order[:, :k] == torch.arange(len(sim)).unsqueeze(1)).any(1)
    return hits.float().mean().item()
```

## 五、与其他对比

- 与 对齐评估指标 共享检索度量。
- 与 视觉问答与推理深入 对照任务差异。

## 六、常见误区

- 只报 R@1 忽略长尾召回。
- 测试集与预训练分布重叠致指标虚高。

## 八、面试题

- 为何双向检索？答：图像到文本与文本到图像难度不同，需分别看以暴露模态偏置。

## 九、演进

R@k → mAP → 细粒度组合检索。

## 十、小结

图文检索以双向 Recall@k 为核心指标，是检验对齐质量的直接手段。
