# 零样本分类与提示

> 对应 Radford et al., 2021（prompt ensembling for zero-shot）。

## 一、背景与挑战

CLIP 预训练无显式类别；做分类需把类别名构造成文本提示，提示措辞显著影响准确率。

## 二、核心原理

把候选类别填充到模板（如 "a photo of a {class}"），编码后与图像算相似度取最高。提示集成（多模板平均）与上下文类别（candidate set 联合）可提升稳健性。

## 三、数学形式

零样本预测：

$$\hat y = \arg\max_{c\in C}\, s\big(I, T(\text{prompt}(c))\big)$$

$s$ 为对齐相似度。

## 四、代码实现

```python
texts = [f"a photo of a {c}" for c in classes]
probs = (image_emb @ text_encoder(texts).T).softmax(0)
pred = classes[probs.argmax()]
```

## 五、与其他对比

- 与 图文检索指标 同用相似度打分。
- 与 多模态指令微调深入 对照“提示 vs 指令”范式。

## 六、常见误区

- 单一模板波动大却不集成。
- 把零样本当真实理解，忽视词面偏见。

## 八、面试题

- 提示为何重要？答：文本编码器对措辞敏感，好提示更贴合训练分布，提升零样本一致。

## 九、演进

单模板 → 提示集成 → 可学习软提示。

## 十、小结

零样本分类靠文本提示桥接，提示工程是 CLIP 实用化的必要步骤。
