# 检索与生成联合

> 对应 BLIP（Li et al., ICML 2022，用检索增强做caption）；检索-生成联合训练趋势。

## 一、背景与挑战

纯检索只能匹配现成文本，纯生成可能幻觉；检索增强生成（RAG）或多任务联合可兼得。

## 二、核心原理

思路：用 CLIP 类检索器召回相关图文/文本，作为生成器（如 captioning/问答）的上下文；或在同一框架内联合优化对比与生成目标，使检索服务生成。

## 三、数学形式

联合目标：

$$\mathcal L = \mathcal L_{contrastive} + \lambda \mathcal L_{generation}$$

生成器条件于检索到的 $k$ 个上下文 $c$：$p(y|x,c_1..c_k)$。

## 四、代码实现

```python
ctx = clip_retrieve(image, topk=4)      # 召回相关文本
caption = generator(image, ctx)
```

## 五、与其他对比

- 与 跨模态生成扩散深入 对照“检索条件 vs 扩散条件”。
- 与 多模态指令微调深入 共享多任务框架。

## 六、常见误区

- 检索噪声直接进生成放大幻觉。
- 联合权重 $\lambda$ 不当致一项塌陷。

## 八、面试题

- 检索如何助生成？答：提供事实上下文减少幻觉，并给生成器可溯来源。

## 九、演进

独立检索 → 检索增强 → 端到端联合。

## 十、小结

检索与生成联合兼顾事实性与流畅性，是多模态系统的实用路线。
