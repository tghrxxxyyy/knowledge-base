# 无分类器引导（Classifier-Free Guidance）

> 对应 Ho & Salimans, *Classifier-Free Diffusion Guidance*, 2022。

## 一、背景与挑战

Classifier guidance 需额外训练分类器提供梯度；无分类器引导免去它，仅靠训练时随机丢弃条件即可。

## 二、核心原理

训练时以一定概率把条件 $y$ 置为空（null），使模型同时学会有条件与无条件去噪；推理时线性组合两者，放大条件信号。

## 三、数学形式

$$\hat\epsilon = \epsilon_\theta(x_t,t,\varnothing) + w\big(\epsilon_\theta(x_t,t,y)-\epsilon_\theta(x_t,t,\varnothing)\big)$$

$w>1$ 增强依从，$w=1$ 退化为纯条件。

## 四、代码实现

```python
eps_uncond = model(xt, t, null_cond)
eps_cond  = model(xt, t, text_cond)
eps = eps_uncond + w * (eps_cond - eps_uncond)
```

## 五、与其他对比

- 与 文本条件扩散 互补的条件增强技术。
- 与 潜在扩散与SD 常联合使用。

## 六、常见误区

- $w$ 过大致过饱和、对比过高。
- 训练未充分随机丢条件，引导失效。

## 八、面试题

## 九、演进

Classifier guidance → CFG → 自适应引导尺度。
