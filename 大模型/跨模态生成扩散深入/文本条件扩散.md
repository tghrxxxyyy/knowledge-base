# 文本条件扩散

> 对应 Ramesh et al., *DALL-E 2 (unCLIP)*, 2022；Nichol et al., *GLIDE*, 2021。

## 一、背景与挑战

如何让扩散“听懂”文本？需把文本语义注入去噪过程作为条件。

## 二、核心原理

常用条件机制：把文本嵌入拼接到 U-Net 的注意力/卷积（cross-attention），或在每一步以 classifier guidance 用文本分类器梯度引导。训练时随机丢弃条件实现无分类器引导。

## 三、数学形式

条件去噪得分：

$$\tilde\epsilon_\theta(x_t,t,y) = \epsilon_\theta(x_t,t,\varnothing) + w\big(\epsilon_\theta(x_t,t,y)-\epsilon_\theta(x_t,t,\varnothing)\big)$$

$w$ 为引导强度，$y$ 为文本条件。

## 四、代码实现

```python
cond = text_encoder(prompt)
noise_pred = unet(xt, t, encoder_hidden_states=cond)
```

## 五、与其他对比

- 与 无分类器引导 共享条件注入。
- 与 CLIP架构与训练 衔接（用 CLIP 文本作条件）。

## 六、常见误区

- 引导权重 $w$ 过大致过饱和、伪影。
- 文本编码器与扩散训练分布不一致。

## 八、面试题

- 文本如何控制生成？答：文本嵌入经 cross-attention 进入 U-Net，引导每步去噪朝向语义。

## 九、演进

无条件 → classifier guidance → cross-attention 条件。

## 十、小结

文本条件扩散把语言语义注入去噪网络，是文生图的核心机制。
