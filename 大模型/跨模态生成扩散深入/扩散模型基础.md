# 扩散模型基础

> 对应 Ho et al., *Denoising Diffusion Probabilistic Models (DDPM)*, NeurIPS 2020；Song et al., *DDIM*, 2021。

## 一、背景与挑战

如何从噪声逐步去噪生成图像？扩散模型以可学习的逐步去噪替代 GAN 的对抗训练，稳定性更好。

## 二、核心原理

前向过程对数据逐步加高斯噪声至纯噪；反向过程训练网络 $\epsilon_\theta$ 预测所加噪声并逐步去噪。训练目标是简单的噪声回归，推理为马尔可夫采样。

## 三、数学形式

前向：$x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon$，$\epsilon\sim\mathcal N(0,I)$。训练目标：

$$\mathcal L_{simple}=\mathbb E_{t,x_0,\epsilon}\big\|\epsilon-\epsilon_\theta(x_t,t)\big\|^2$$

## 四、代码实现

```python
noise = torch.randn_like(x0)
xt = sqrt_alphas[t] * x0 + sqrt_one_minus[t] * noise
pred = model(xt, t)
loss = F.mse_loss(pred, noise)
```

## 五、与其他对比

- 与 GAN 比：扩散训练稳但采样慢。
- 与 跨模态生成扩散深入 其余篇构成完整链条。

## 六、常见误区

- 混淆前向加噪与反向去噪的角色。
- 采样步数盲目设很大，忽视 DDIM 加速。

## 八、面试题

- 扩散为何比 GAN 稳？答：目标是简单 MSE 回归，无对抗零和博弈，梯度稳定。

## 九、演进

DDPM → DDIM（加速）→ 分数匹配统一视角。

## 十、小结

扩散模型以“加噪-去噪”回归为目标，提供稳定可控的生成范式。
