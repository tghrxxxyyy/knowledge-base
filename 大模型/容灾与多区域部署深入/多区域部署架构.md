# 多区域部署架构

> 对应多区域主动被动与主动主动；全局流量管理（Anycast、GSLB）。GSLB 做全局调度。

## 一、背景与挑战

如何在多个地理区域部署推理服务，兼顾延迟、成本与一致性是架构难点。

## 二、核心原理

按用户就近路由到最近区域；区域间异步复制权重与缓存；控制面集中、数据面分散。

## 三、数学形式

就近延迟 $L = \min_r L_{r}(u)$；全局延迟取各区域加权最小。

## 四、代码实现

```python
region = geo.route(user_ip)   # 就近
serve(region, req)
```

## 五、与其他对比

- 与 双活与多活（模式选择）衔接。
- 与 容灾总览（目标）共享。

## 六、常见误区

- 跨区域强一致致延迟飙升。
- 区域间权重不同步致结果漂移。
