# 双活与多活

> 对应 active-active 与 active-passive；多活是终极形态。CAP 定理约束一致性（Brewer, 2000）。

## 一、背景与挑战

主备（active-passive）资源闲置、切换有损；双活多活提利用率但带来一致性难题。

## 二、核心原理

双活两区域同时接流量、互备；多活多区域同时服务。需处理脑裂与数据冲突。

## 三、数学形式

CAP 下分区时取舍：选 $C$ 或 $A$；推理服务常偏向 $A$ 加最终一致。

## 四、代码实现

```python
if partition:
    prefer_availability()   # 分区时保可用
else:
    sync_state()
```

## 五、与其他对比

- 与 多区域部署架构（结构）衔接。
- 与 RTO与RPO设计（目标）共享。

## 六、常见误区

- 多活未处理脑裂致双写冲突。
- 强一致跨区拖慢全局。

## 八、面试题

- 双活 vs 主备？答：双活两区同时服务、资源不闲置、需处理冲突；主备省心但有闲置。

## 九、演进

主备 → 双活 → 全球多活。

## 十、小结

双活多活提升资源利用率与可用性，代价是一致性与冲突处理。
