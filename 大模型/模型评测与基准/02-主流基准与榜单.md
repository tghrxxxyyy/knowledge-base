# 模型评测与基准 · 02 主流基准与榜单

> 本篇盘点 2025–2026 最常用的 LLM 基准与榜单，讲清「每个测什么、哪些已饱和、怎么按任务选型」。分数为公开结果快照，会快速过时——**以你任务上的真实评测为准**。

## 一、通用知识与学术基准

### 1.1 MMLU（Massive Multitask Language Understanding）

- **结构**：57 学科、15,908 道四选一，STEM/人文/社科/专业考试。
- **方式**：4-choice，5-shot；指标 Accuracy。
- **里程碑**：GPT-3 ~43% → GPT-4 ~86% → Claude 3.5/4o ~88%。
- **现状**：**已高度饱和**（前沿模型集群 88%+），区分度低，但仍适合测知识广度。
- **衍生**：MMLU-Pro（更难、更多选项）、MMLU-Redux、CMMLU/C-Eval（中文）。

### 1.2 GPQA（Graduate-Level Google-Proof Q&A）

- **结构**：448 道生物/物理/化学，领域专家设计、**谷歌搜不到答案**。
- **定位**：比 MMLU 更好的前沿区分度。
- **公开结果**：Gemini 3 Pro 92.6%（2025-12）；o3 87.7%（高算）；GPT-5.1 91.9%。
- **适用**：研究生级科学推理，测深度专业知识。

### 1.3 中文 / 文化公平基准

- **C-Eval / CMMLU**：中文与中国文化背景，弥补早期评测英语/西方偏向。
- **KoLA**：知识分层（记忆/理解/应用），区分背答案 vs 真理解。

## 二、数学与推理基准

| 基准 | 测什么 | 现状/代表分 |
|------|--------|-------------|
| **GSM8K** | 小学应用题（链式） | 已饱和，前沿 >90% |
| **MATH** | 高中竞赛 | 强模型高分段 |
| **AIME** | 美邀数学（15 题/年，公开旧题） | GPT-4o 13% → o1 83% → o3-mini 96.4%；R1 79.8%（约 o1 价 5%） |
| **Omni-MATH / FrontierMath** | 数学研究前沿 | 极难，区分顶尖模型 |
| **ARC-AGI** | 抽象推理（防训练数据） | o3 高算 96.7%，专为难住模型设计 |
| **HellaSwag** | 常识续写（干扰项反直觉） | 测真实理解，防统计作弊 |
| **LiveBench** | **实时更新题**防污染 | 动态基准代表，缓解数据污染 |

> 推理类基准是推理模型（见「推理与思考模型」模块）的主战场；AIME/GPQA/ARC-AGI 的跃升基本来自 test-time compute。

## 三、代码与软件工程基准

### 3.1 HumanEval

- OpenAI 提出，164 道 Python 函数级题，跑单测验证。
- 前沿模型多 >85%；衍生 HumanEval+（更严测试）。
- **局限**：只测独立函数，不测复杂代码库/多语言/集成。

### 3.2 SWE-bench（软件工程基准）

- 测**解决真实 GitHub issue** 的能力，多版本：Standard / Verified / Pro。
- **公开结果（2026）**：多数模型 Verified 版 70%+；**Pro 私有子集骤降**——GPT-5 23.1%→14.9%，Claude Opus 4.1 22.7%→17.8%。
- **洞察**：真实软件工程任务仍极难，是 Agent coding 的核心评测。

### 3.3 其他

- **LiveCodeBench**：实时编程竞赛，防污染。
- **VerilogEval / RTLLM**：硬件设计，专业工程导向。

## 四、事实性与多模态

- **SimpleQA**：短事实问答，测事实准确率（Gemini 2.5 Pro SOTA F1 55.6；SimpleQA Verified 更可靠）。
- **TruthfulQA**：38 学科测「拒绝错误前提、给准确答」。
- **MMMU**：多模态研究生级（o3 SOTA）；多模态评测随多模态模型兴起。

## 五、对话与综合榜单

### 5.1 MT-Bench

- 多轮对话能力（模拟客服等），需跟踪上下文。
- 常用 **GPT-4 当 judge** 打分（LLM-as-Judge 早期范式）。

### 5.2 Chatbot Arena（LMSYS）

- **机制**：匿名 pairwise 对比同一 prompt 的两响应，投票聚成 **Elo 排名**（带不确定性带）。
- **规模**：~499 万票 / 296 模型（2026-01）；覆盖文本/图像/视频/搜索/代码域。
- **优势**：真实偏好 + 盲测消品牌偏 + 持续活基准。
- **局限**：用户群体偏差、成本、仍有策略性刷分可能。
- **代表领先**（2025）：Gemini-2.5-Pro 系列 Arena 1446。

### 5.3 Humanity's Last Exam（人类最后考试）

- 极难、跨领域，测「人类级」上限；o3 / Gemini 2.5 Pro / o4-mini 居前。
- 定位：逼近当前模型能力天花板的前沿基准。

## 六、基准饱和趋势与选型

```
已饱和（区分度低）:  MMLU, GSM8K, 原 HumanEval
当前区分度:          GPQA, SWE-bench Pro, MMMU, LiveBench, Hella's Last Exam
未来方向:            更难、领域专属、抗污染（动态/私有题）
```

**按任务维度选型速查**：

| 想测的能力 | 首选基准 |
|-----------|----------|
| 通用知识广度 | MMLU / CMMLU / C-Eval |
| 深度科学推理 | GPQA / Humanity's Last Exam |
| 数学/竞赛 | AIME / MATH / Omni-MATH |
| 抽象推理 | ARC-AGI / LiveBench |
| 代码生成 | HumanEval(+) / LiveCodeBench |
| 真实软件工程 | SWE-bench（Verified / Pro） |
| 事实准确性 | SimpleQA / TruthfulQA |
| 多模态 | MMMU |
| 对话/综合排名 | MT-Bench / Chatbot Arena |

## 七、评测框架与平台

| 框架 | 用途 |
|------|------|
| **lm-eval-harness**（EleutherAI） | 开源、可复现的主流基准实现，跨模型一致比较 |
| **OpenAI Evals** | 任务特异评测 + 持续评测哲学，开发全程积累 case |
| **DeepEval** | LLM-as-Judge 落地（G-Eval / Arena），5 行接入 |
| **RAGAS** | RAG 专属四指标评测 |
| **Chatbot Arena / lmarena.ai** | 人类偏好 Elo 排名 |
| **HELM（Stanford）** | 多维度系统化评测 |

## 八、小结

- MMLU/GSM8K/HumanEval 已饱和，前沿模型挤在 88%+；新区分度看 GPQA / SWE-bench Pro / LiveBench / Hella's Last Exam。
- 选基准按**任务维度**：知识→MMLU、科学→GPQA、数学→AIME、代码→HumanEval/SWE-bench、综合→Arena。
- 动态/私有题（LiveBench 思路）是抗数据污染的关键。
- 落地用 lm-eval-harness / OpenAI Evals / DeepEval / RAGAS，把评测做成流水线。

> 评测模块与「推理与思考模型」「RAG」「智能体」深度联动：推理模型靠 GPQA/AIME 验证跃迁，RAG/Agent 靠 RAGAS + 任务 eval 做回归。
