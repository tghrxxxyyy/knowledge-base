# 长尾与对抗行为

> 对应 Zou et al., *Universal and Transferable Adversarial Attacks on Aligned Language Models*, 2023；Wei et al., *Jailbroken: How Does LLM Safety Training Fail?*, NeurIPS 2023。

## 一、背景与挑战

平均指标对长尾几乎不敏感：万分之一的输入触发严重失败，在准确率上看不出来，但在真实部署里就是事故。更棘手的是这些输入可以被主动搜索出来（对抗攻击），意味着攻击者面对的不是随机长尾，而是可优化的最坏情形。

## 二、核心原理

两类不可预测行为需分开处理。自然长尾：罕见但真实出现的输入（极长文本、混排语言、格式畸形、罕见领域），可通过线上日志采样与聚类主动挖掘。对抗长尾：由优化过程构造的输入，如基于梯度的通用后缀搜索——在离散 token 空间用坐标上升选择使目标响应似然最大的替换，得到可跨提示甚至跨模型迁移的后缀。这类攻击的存在说明：安全训练建立的是概率意义上的边界，在最坏情形下仍可被突破。工程上应把「最坏情形」纳入常规监控：定期跑对抗搜索、把发现的样本加入训练与回归集，形成攻防闭环，而不是等事故出现。

## 三、数学形式

通用对抗后缀搜索可写为离散优化：

$$\min_{s\in\mathcal V^{m}}\ \sum_{i=1}^{n}-\log \pi_\theta\big(y^{+}\ \big|\ x_i\oplus s\big)$$

其中 $x_i$ 为多条有害请求（求和以获得通用性），$y^{+}$ 为肯定性前缀，$\oplus$ 为拼接。由于 $\mathcal V^m$ 离散，常用基于梯度的候选打分 + 逐位置替换的坐标上升近似求解。可预测性的评估应报告尾部风险，例如条件风险价值

$$\mathrm{CVaR}_\alpha=\mathbb E\big[\text{损失}\ \big|\ \text{损失}\ \ge\ \text{分位数}_{1-\alpha}\big]$$

而不仅是均值。

## 四、代码实现

```python
import torch

def greedy_token_swap(model, prompts, target_ids, suffix_ids, vocab_size, steps=100, topk=64):
    # 说明性实现：坐标上升式离散搜索（红队用途），逐位置挑选最优替换 token
    for _ in range(steps):
        pos = int(torch.randint(len(suffix_ids), (1,)))
        losses = []
        cand = torch.randint(vocab_size, (topk,))
        for c in cand:
            trial = suffix_ids.clone(); trial[pos] = c
            tot = 0.0
            for p in prompts:                       # 对多条提示求和以获得通用性
                out = model(input_ids=torch.cat([p, trial]), labels=target_ids)
                tot += out.loss.item()
            losses.append(tot)
        best = int(torch.tensor(losses).argmin())
        suffix_ids[pos] = cand[best]
    return suffix_ids

def cvar(losses, alpha=0.05):
    s = sorted(losses, reverse=True)
    k = max(1, int(len(s) * alpha))
    return sum(s[:k]) / k                            # 尾部平均损失
```

## 五、与其他对比

- 与 视觉对抗越狱：同为最坏情形搜索，只是搜索空间从连续图像变为离散 token，后者更难优化但同样有效。
- 与 分布偏移鲁棒性：自然长尾是随机偏移，对抗长尾是最坏情形偏移，评估方法互补。
- 与 安全评估：对抗搜索预算必须写入报告，否则 ASR 不可比。

## 六、常见误区

- 只看平均指标就判断模型安全。长尾风险在均值上不可见，需报告尾部指标。
- 认为对抗后缀是可以被单点修补的字符串。它是可重新搜索的，封堵具体串只能延缓攻击。
- 把红队当一次性验收活动。攻防是持续过程，需固化为周期性流程并回流到训练集。

## 八、面试题

- 为什么通用对抗后缀能跨提示迁移？答：优化目标对多条有害提示求和，学到的是压低拒答、抬高肯定前缀的通用方向，而非针对单条请求的特化解。
- 评估长尾风险该用什么指标？答：尾部指标如最差情形分数或 CVaR，而非均值；同时报告攻击搜索预算。

## 九、演进

平均指标评估 → 人工红队发现长尾 → 基于优化的通用对抗搜索 → 尾部风险指标与攻防闭环 → 持续红队与自动化回归。

## 十、小结

长尾与对抗行为是可预测性的下界问题；只有把最坏情形搜索与尾部指标制度化，才能把「偶发事故」变成可管理的风险。
