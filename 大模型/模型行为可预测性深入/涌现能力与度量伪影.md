# 涌现能力与度量伪影

> 对应 Wei et al., *Emergent Abilities of Large Language Models*, TMLR 2022；Schaeffer et al., *Are Emergent Abilities of Large Language Models a Mirage?*, NeurIPS 2023。

## 一、背景与挑战

「某能力在参数量跨过某个门槛后突然出现」这一叙事影响了大量研发决策。但后续工作指出，跳变很大程度上是度量选择的产物：把连续改进经过阈值化或全序列精确匹配放大，就会在图上看到断崖。这个争论直接关系到「是否值得赌规模」这类高成本判断。

## 二、核心原理

关键机制是非线性度量的放大效应。以多步算术为例，若模型每个 token 正确概率为 $p$ 且随规模平滑上升，长度为 $k$ 的答案要全对，概率是 $p^k$——当 $p$ 从 0.9 平滑升到 0.99 时，$p^{10}$ 从约 0.35 跳到约 0.90，视觉上呈突现。换用 token 级准确率或对数概率等连续度量，曲线则平滑。Schaeffer 等的结论不是「涌现不存在」，而是「许多被报道的涌现可由度量与样本量解释」。仍存在一部分现象（如上下文学习的定性变化）不易被这一解释完全覆盖，因此正确态度是：报告涌现时必须同时给出连续度量与足够样本量，否则结论不可信。

## 三、数学形式

设 token 级正确概率 $p(N)$ 随规模平滑增长，则序列精确匹配准确率

$$\mathrm{EM}(N)=p(N)^{k}\quad\Longrightarrow\quad \frac{d\log \mathrm{EM}}{d\log N}=k\cdot\frac{d\log p}{d\log N}$$

即离散度量把对数斜率放大 $k$ 倍，长答案（大 $k$）任务最容易呈现「突现」。此外小样本量下的估计方差 $\sqrt{p(1-p)/n}$ 也会掩盖低分区的缓慢改善，使曲线看似长期贴地后突然抬升。

## 四、代码实现

```python
import numpy as np

def emergence_illusion(scales, k=10, p0=0.5, p1=0.99):
    # 平滑上升的 token 级正确率，经全序列精确匹配后呈“突现”
    p = np.linspace(p0, p1, len(scales))
    return {"scale": np.asarray(scales),
            "token_acc": p,                       # 连续度量：平滑
            "exact_match": p ** k}                # 离散度量：断崖式

def required_samples(p_hat, half_width=0.02, z=1.96):
    # 低分区要看清缓慢改善，需要的最小样本量
    return int(np.ceil((z ** 2) * p_hat * (1 - p_hat) / half_width ** 2))
```

## 五、与其他对比

- 与 行为可预测性总览：本节是第二层（能力可预测性）的核心机制。
- 与 模型评测指标：度量选择的影响在这里被最大化体现。
- 与 缩放律：连续度量下的平滑曲线才可用于外推与预算规划。

## 六、常见误区

- 用精确匹配画能力—规模曲线并据此断言存在能力门槛。应先换连续度量复核。
- 小样本（几十条）上报告低分区差异。估计方差足以制造或掩盖跳变。
- 从「涌现是伪影」跳到「规模无用」。规模确实带来平滑改善，只是改善形态被度量扭曲了。

## 八、面试题

- 为什么精确匹配容易制造涌现假象？答：全序列正确概率是 token 正确率的高次幂，把对数斜率放大约 $k$ 倍，平滑改善被放大成跳变。
- 如何判断某个涌现是否为度量伪影？答：换用连续度量（token 级准确率、对数概率、编辑距离）复核，并保证样本量足以分辨低分区差异。

## 九、演进

报道涌现能力 → 指出度量与样本量的伪影效应 → 规范用连续度量与置信区间报告 → 更细粒度的能力预测研究。

## 十、小结

涌现讨论的真正教训是评测方法论：度量的非线性会重塑曲线形状，任何关于能力门槛的结论都必须先经过度量与样本量的稳健性检验。
