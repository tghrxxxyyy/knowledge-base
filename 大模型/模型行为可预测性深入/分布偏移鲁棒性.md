# 分布偏移鲁棒性

> 对应 Hendrycks & Dietterich, *Benchmarking Neural Network Robustness to Common Corruptions and Perturbations*, ICLR 2019（方法论）；Ganguli et al., FAccT 2022（部署意外）。

## 一、背景与挑战

评测集上的分数不能预测线上表现，因为线上输入分布与评测分布不同：语言风格、领域术语、提示格式、输入长度、噪声（错别字、混排语言）全都会变。行为可预测性在实践中主要败在这一点——不是模型能力不足，而是能力在偏移后的分布上没有被测过。

## 二、核心原理

把偏移拆成可操作的几类：格式偏移（提示模板、选项顺序、系统提示变化）、风格偏移（口语、方言、行业术语）、噪声偏移（错别字、OCR 噪声、中英混排）、长度偏移（远超训练常见长度）、语义偏移（新领域、新时效知识）。对每类构造扰动算子，在同一语义样本上批量施加，报告分数分布而非单点值。核心指标是「最差情形」与「方差」，因为线上体验由尾部决定。特别要注意提示敏感性：同义改写导致的分数波动常常大于模型之间的差距，这意味着任何模型对比都必须在多模板下取平均并报告方差，否则结论不稳。

## 三、数学形式

设扰动族 $\mathcal G$（保持语义的变换），定义鲁棒性指标

$$\mathrm{Acc}_{\text{avg}}=\mathbb E_{g\sim\mathcal G}\big[\mathrm{Acc}(g(D))\big],\qquad \mathrm{Acc}_{\text{worst}}=\min_{g\in\mathcal G}\mathrm{Acc}(g(D)),\qquad \mathrm{Gap}=\mathrm{Acc}(D)-\mathrm{Acc}_{\text{worst}}$$

其中 $\mathrm{Gap}$ 即「评测分数的虚高部分」。若要在训练中优化最差情形，可采用分布鲁棒优化形式：$\min_\theta\max_{g\in\mathcal G}\ \mathbb E_{x\sim g(D)}[\ell(\theta;x)]$，实践中用扰动增强近似。

## 四、代码实现

```python
import random, re

def perturb_typo(text, rate=0.03):
    chars = list(text)
    for i in range(len(chars)):
        if random.random() < rate and chars[i].strip():
            chars[i] = random.choice("aeiou")          # 简化的错别字扰动
    return "".join(chars)

def perturb_template(prompt, templates):
    return random.choice(templates).format(q=prompt)

def robustness_report(model, dataset, judge, perturbations, templates):
    scores = {}
    for name, g in perturbations.items():
        acc = np.mean([judge(model(g(s["q"])), s["a"]) for s in dataset])
        scores[name] = float(acc)
    tmpl_accs = [np.mean([judge(model(perturb_template(s["q"], [t])), s["a"]) for s in dataset])
                 for t in templates]
    return {"per_perturbation": scores,
            "worst": min(scores.values()),
            "template_std": float(np.std(tmpl_accs)),   # 提示敏感性
            "gap": scores.get("identity", 0) - min(scores.values())}
```

## 五、与其他对比

- 与 涌现能力与度量伪影：一个是度量导致的失真，一个是分布导致的失真，都会让单点分数误导决策。
- 与 安全评估：攻击可视为最坏情形的分布偏移，方法论一致。
- 与 校准：偏移后校准通常首先失效，两项需一起监控。

## 六、常见误区

- 只用一个提示模板评测并据此排名模型。模板方差常大于模型差异。
- 把扰动做成语义改变的变换（如改错答案选项内容）。扰动必须保语义，否则测的是别的东西。
- 只报平均鲁健分。线上体验由最差情形决定，必须报 worst 与方差。

## 八、面试题

- 为什么模型对比必须用多个提示模板？答：提示敏感性带来的分数波动常大于模型间差异，单模板结论不稳定且可被选择性报告操纵。
- 鲁棒性报告应包含哪些量？答：各扰动下的分数、最差情形、相对原始分数的落差，以及模板方差。

## 九、演进

单一评测集单点分数 → 引入语义保持扰动族 → 报告最差情形与方差 → 扰动增强训练与分布鲁棒优化 → 线上分布持续采样回流评测。

## 十、小结

分布偏移是评测分数与线上表现之间最大的裂缝；用保语义扰动族测最差情形，是把行为可预测性落到实处的最直接办法。
