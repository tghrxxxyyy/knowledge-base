# 置信度校准

> 对应 Guo et al., *On Calibration of Modern Neural Networks*, ICML 2017；Kadavath et al., *Language Models (Mostly) Know What They Know*, 2022。

## 一、背景与挑战

可预测性的一个实用侧面是：模型能否告诉我们它什么时候不可靠。如果置信度校准良好，就可以按阈值路由到人工或检索；如果模型在错误答案上同样自信，任何基于置信度的风控都失效。已有工作还观察到偏好优化后的模型校准可能变差——对齐让输出更自信、更模板化，而不必然更正确。

## 二、核心原理

三条要点。其一，校准与准确率是两个独立维度：一个准确率 60% 的模型若能稳定输出 0.6 附近的置信度就是良好校准的，可用；一个准确率 80% 但总输出 0.99 的模型反而危险。其二，语言模型可通过多种途径给出置信度：答案 token 的归一化概率、自评（让模型输出对自身答案正确性的概率）、多次采样的一致性（自一致性投票比例）。后两者在长文本任务上往往比 token 概率更实用。其三，校准可后处理修正：温度缩放在验证集上拟合单一温度参数即可显著降低 ECE，成本极低且不改变排序。

## 三、数学形式

期望校准误差（ECE）把预测按置信度分箱后比较置信度与实际准确率：

$$\mathrm{ECE}=\sum_{m=1}^{M}\frac{|B_m|}{n}\Big|\ \mathrm{acc}(B_m)-\overline{\mathrm{conf}}(B_m)\Big|$$

温度缩放在验证集上求解 $T^\star=\arg\min_T \mathrm{NLL}\big(\mathrm{softmax}(z/T)\big)$，$T>1$ 表示原模型过度自信。注意 ECE 依赖分箱方式，报告时须说明箱数并辅以可靠性图。

## 四、代码实现

```python
import numpy as np, torch

def ece(confidences, correctness, n_bins=15):
    conf = np.asarray(confidences); corr = np.asarray(correctness, dtype=float)
    bins = np.linspace(0, 1, n_bins + 1)
    e = 0.0
    for lo, hi in zip(bins[:-1], bins[1:]):
        m = (conf > lo) & (conf <= hi)
        if m.sum() == 0:
            continue
        e += m.mean() * abs(corr[m].mean() - conf[m].mean())
    return float(e)

def fit_temperature(logits, labels, iters=200):
    logT = torch.zeros(1, requires_grad=True)
    opt = torch.optim.LBFGS([logT], max_iter=iters)
    def closure():
        opt.zero_grad()
        loss = torch.nn.functional.cross_entropy(logits / logT.exp(), labels)
        loss.backward(); return loss
    opt.step(closure)
    return float(logT.exp().item())

def selfconsistency_confidence(model, prompt, k=8):
    answers = [normalize(model(prompt, temperature=0.8)) for _ in range(k)]
    top = max(set(answers), key=answers.count)
    return top, answers.count(top) / k        # 一致性比例作为置信度
```

## 五、与其他对比

- 与 幻觉相关主题：良好校准是拒答与检索触发策略的前提。
- 与 奖励模型集成与不确定性：集成分歧也是一种不确定性来源，思路一致。
- 与 对齐税与能力保持深入：对齐后校准变差是需要纳入监控的副作用之一。

## 六、常见误区

- 用 ECE 单一数字下结论。ECE 对分箱敏感，且不反映在哪个置信区间失准，需配可靠性图。
- 把长文本生成的首 token 概率当整体置信度。它只反映开头选择，与整体正确性关联弱。
- 只在同分布验证集上校准。分布偏移后温度参数失效，需按场景重新拟合。

## 八、面试题

- 校准与准确率的关系？答：相互独立。校准衡量置信度是否匹配真实正确率，是风控与路由决策的基础，与绝对准确率高低无关。
- 长文本任务上如何估计置信度？答：优先用多次采样的自一致性比例或模型自评概率，而非单个 token 的概率。

## 九、演进

只看准确率 → 引入 ECE 与可靠性图 → 温度缩放等后处理校准 → 自评与自一致性置信度 → 面向对齐副作用的校准监控。

## 十、小结

校准把「模型有多可靠」变成可用的运行时信号；它便宜、可后处理修正，是把不可预测性转化为可控风险的关键一环。
