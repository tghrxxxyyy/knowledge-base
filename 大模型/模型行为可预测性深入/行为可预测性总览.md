# 行为可预测性总览

> 对应 Ganguli et al., *Predictability and Surprise in Large Generative Models*, FAccT 2022；Kaplan et al., *Scaling Laws*, 2020。

## 一、背景与挑战

大模型呈现一种矛盾：宏观高度可预测（训练损失随规模与数据量呈平滑幂律），微观高度不可预测（具体能力何时出现、在哪些输入上失败，难以事前判断）。这个「可预测的整体 + 不可预测的细节」结构，是部署风险评估的核心难题——损失曲线漂亮不代表你知道模型会在什么场景做出什么行为。

## 二、核心原理

把可预测性拆成三个层次会清晰得多。第一层是缩放可预测性：交叉熵损失随参数量、数据量、算力呈幂律，可靠外推。第二层是能力可预测性：下游任务分数与损失的关系依赖度量形式；用离散的精确匹配度量会看到「突现」，用连续度量则常呈平滑改善。第三层是行为可预测性：在给定输入分布上模型的具体反应（是否拒答、是否幻觉、是否被越狱），这一层几乎无法从损失外推，只能通过评测直接测量。工程含义是：预算规划靠第一层，能力路线靠第二层，安全与产品决策必须靠第三层的实测与规格化。

## 三、数学形式

缩放律给出可外推的部分：

$$L(N,D)\approx L_\infty+\Big(\frac{N_c}{N}\Big)^{\alpha_N}+\Big(\frac{D_c}{D}\Big)^{\alpha_D}$$

而下游行为是损失的复合函数：$\text{Metric}=\Phi\big(L\big)$。若 $\Phi$ 含阈值或不连续（如精确匹配），即使 $L$ 平滑变化，$\text{Metric}$ 也会呈跳变；若 $\Phi$ 平滑（如 token 级编辑距离、对数概率），则曲线平滑。因此「是否可预测」很大程度上是 $\Phi$ 的性质，而非模型的性质。

## 四、代码实现

```python
import numpy as np

def fit_scaling(N, L, L_inf=1.5):
    # 拟合 L(N) = L_inf + (Nc/N)^alpha，用对数线性回归
    y = np.log(np.asarray(L) - L_inf)
    x = np.log(np.asarray(N))
    alpha, c = np.polyfit(x, y, 1)
    return {"alpha": -alpha, "log_Nc": c / max(-alpha, 1e-9)}

def metric_transform_effect(loss_curve, threshold=0.35):
    # 同一损失曲线，离散度量出现跳变，连续度量平滑
    loss = np.asarray(loss_curve)
    continuous = np.exp(-loss)                       # 平滑代理（如平均正确概率）
    discrete = (continuous > threshold).astype(float) # 阈值化后产生“突现”
    return {"continuous": continuous, "discrete": discrete}
```

## 六、常见误区

- 用验证损失下降来承诺下游能力。两者之间隔着一个可能不连续的度量映射。
- 把「不可预测」当作神秘性质。很多不可预测性来自度量选择与评测样本不足，可通过方法改进消除。
- 只报点估计不报方差。同一模型在提示改写下的分数波动往往大于模型间差异。

## 八、面试题

- 大模型的可预测性体现在哪、不可预测性体现在哪？答：损失随规模的幂律高度可预测；具体下游能力与行为（拒答、幻觉、越狱）难以外推，需实测。
- 为什么同一模型在不同度量下可预测性不同？答：下游指标是损失的复合函数，度量若含阈值或离散化，会把平滑变化放大成跳变。

## 九、演进

经验试错 → 缩放律定量外推 → 涌现现象与度量伪影之争 → 行为层规格化与系统性评测 → 部署前的能力与风险预测框架。

## 十、小结

可预测性要分层讨论：损失可外推、能力看度量、行为必须测；把三层混为一谈是评估失真的主要来源。
