# 对话评测

> 见「对话系统深入/对话系统总览」与「模型评测深入」；对话质量多维。

## 一、背景与挑战

对话好坏难用单一指标衡量。

## 二、核心原理

维度：相关性、连贯性、事实性、安全性、任务成功率（任务型）。自动评测用 LLM-as-judge 或参考指标（BLEU/ROUGE 弱）；人工评测仍金标准。任务型还看 **Goal Completion Rate**。

## 三、关键要点

- 自动指标与人类偏好相关性弱。
- LLM judge 需防位置/长度偏置。

## 四、代码实现

```python
score = llm_judge(f"评测对话质量(1-5): {dialog}")
```

## 五、与其他对比

- 任务型有客观成功率；开放域主观。

## 六、常见误区

- BLEU 高即好——对话不适用。
