# 检索增强对话

> 见「对话系统深入/对话系统总览」与「RAG深入」；RAG + 对话。

## 一、背景与挑战

对话需基于私域/最新知识，纯 LLM 易幻觉。

## 二、核心原理

每轮把用户问题+历史检索相关文档，注入上下文生成，保证有据可依。需处理多轮 query 改写（用历史补全省略指代）以提升检索准确。

## 三、关键要点

- query 改写解决指代省略。
- 多轮需重新检索当前意图。

## 四、代码实现

```python
q = rewrite(history, user_q)        # 补全指代
ctx = retrieve(q); ans = llm(q, ctx)
```

## 五、与其他对比

- 纯生成自由但易错；RAG 有据。

## 六、常见误区

- 只用当前句检索——丢上下文。

## 七、与开源书对应

- llm-universe: https://github.com/datawhalechina/llm-universe
- d2l-zh: https://github.com/d2l-ai/d2l-zh

## 九、演进

单轮 RAG → 多轮改写 → 对话智能体。
