# 对话系统总览

> 对应 d2l-zh 与 datawhalechina/llm-universe；对话系统综述。

## 一、背景与挑战

让机器与人多轮自然交流，需理解意图、维护状态、生成妥当回复。

## 二、核心原理

两类：**任务型（TOD）**完成特定目标（订票/查库），靠对话状态跟踪（DST）+ 策略；**开放域**闲聊/知识问答，靠大模型生成。现代大模型对话系统以 LLM 为中枢，配工具/RAG/记忆。

## 三、关键要点

- 多轮上下文管理是核心。
- 安全与一致性格外重要。

## 四、代码实现

```python
history = []; history.append({"role":"user","content":q})
resp = llm(messages=history)
```

## 五、与其他对比

| 类型 | 目标 |
|------|------|
| 任务型 | 完成动作 |
| 开放域 | 自然交流 |

## 六、常见误区

- 对话=单轮问答——多轮状态易丢。
