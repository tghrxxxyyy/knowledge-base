# 多轮与记忆

> 见「对话系统深入/对话系统总览」与「记忆」；对话长程管理。

## 一、背景与挑战

超长对话超出上下文窗口，且需跨轮引用。

## 二、核心原理

**记忆机制**：短期（当前上下文窗口）+ 长期（向量库存历史摘要/事实）。每轮检索相关记忆注入；或用摘要压缩旧轮次（buffer/summary memory）。见「记忆」章节的读写策略。

## 三、关键要点

- 摘要压缩防窗口溢出。
- 长期记忆需可检索。

## 四、代码实现

```python
mem = retrieve_relevant(history); 
ctx = summarize(old) + mem + current
```

## 五、与其他对比

- 全上下文贵；记忆检索省。

## 六、常见误区

- 窗口够大不用记忆——成本与噪声。
