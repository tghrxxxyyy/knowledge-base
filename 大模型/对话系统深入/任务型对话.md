# 任务型对话

> 见「对话系统深入/对话系统总览」；Dialog State Tracking 综述。

## 一、背景与挑战

完成订票/查询需填槽（slot filling）与状态跟踪。

## 二、核心原理

经典流程：NLU（意图+槽位）→ **DST**（维护累积状态 `belief state`）→ 策略（决定问哪个槽/调哪动作）→ NLG（生成回复）。大模型可直接端到端做 DST 与策略，用函数调用取动作。

## 三、关键要点

- 状态正确才有正确动作。
- 大模型可省去多模块拼接。

## 四、代码实现

```python
# 用 function calling 取动作
tools = [book_flight]; action = llm(messages, tools)
```

## 五、与其他对比

- 模块化可控但碎；端到端简但难调。

## 六、常见误区

- 忽略状态累积——多轮必错。
