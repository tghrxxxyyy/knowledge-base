# 多提示投票

> 对应 Self-Consistency（多采样投票）；提示集成总览 衔接。

## 一、背景与挑战

同一提示多次采样成本高；不同提示投票更省且多样。

## 二、核心原理

构造 k 个语义等价但表述不同的提示，各取答案，对离散答案多数投票，对连续答案平均。

## 三、数学形式

置信度 $c(y)=\frac1k\sum_i \mathbf 1[y_i=y]$；取最大 $\hat y=\arg\max_y c(y)$。

## 四、代码实现

```python
from collections import Counter
vote = Counter(answers)
final = vote.most_common(1)[0][0]
```

## 五、与其他对比

- 与 自洽（单提示多采样）对照，多提示多样性更强。
- 与 提示集成数学 共享聚合。

## 六、常见误区

- 提示仅换同义词，未换推理角度。
- 票数平局无 tie-break 策略。

## 八、面试题

- 多提示投票相对自洽？答：换提示角度更省采样且多样，自洽换采样路径。

## 九、演进

单提示 → 自洽采样 → 多提示投票。

## 十、小结

多提示投票用表述多样性聚合，提质且可控成本。
