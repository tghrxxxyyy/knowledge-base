# 提示集成与模型集成

> 对应两类集成对比；模型集成深入 衔接。

## 一、背景与挑战

提示集成（同模型多提示）与模型集成（多模型）收益来源不同。

## 二、核心原理

提示集成改输入分布、成本低；模型集成改参数集合、成本高但覆盖偏置更全；可叠加。

## 三、数学形式

模型集成 $\bar y=\frac1M\sum_m f_m(p,q)$；提示集成在其内再对 $k$ 提示聚。

## 四、代码实现

```python
preds = [ensemble_prompts(model_m, q) for model_m in models]
final = mean(preds)
```

## 五、与其他对比

- 与 模型集成深入（多权重）对照成本。
- 与 提示集成总览 可组合。

## 六、常见误区

- 误以为提示集成可替代模型集成（偏置覆盖有限）。
- 叠加成本爆炸未权衡。

## 八、面试题

- 提示 vs 模型集成？答：前者改输入、廉价；后者改参数、覆盖更全但贵，可叠。

## 九、演进

单模型单提示 → 提示集成 → 提示+模型集成。

## 十、小结

提示集成廉价改输入分布，模型集成覆盖参数偏置，可组合。
