# 提示集成实践

> 对应生产落地权衡；推理经济成本深入 衔接。

## 一、背景与挑战

k 倍调用成本高，需按任务价值选 k 与方式。

## 二、核心原理

高价值/高风险任务（医疗、代码、数学）用较大 k；低风险用单提示；并行调用降延迟。

## 三、数学形式

净收益 $B = acc_k-acc_1 - k\cdot c_{call}$；超过阈值才集成。

## 四、代码实现

```python
if task.risk == "high":
    final = ensemble(prompts, q, k=5, parallel=True)
```

## 五、与其他对比

- 与 推理调度深入（并行批）降延迟。
- 与 提示集成总览 闭环。

## 六、常见误区

- 全任务大 k 致成本爆炸。
- 串行集成增延迟未并行。

## 八、面试题

- 何时用提示集成？答：高风险/高价值任务且收益覆盖 k 倍成本时，并行控延迟。

## 九、演进

串行单路 → 并行多提示 → 自适应 k。

## 十、小结

提示集成按风险与成本权衡 k，并行调用控制延迟。
