# 提示集成与采样

> 对应 temperature 与采样策略；自回归生成深入 衔接。

## 一、背景与挑战

采样温度影响多样性，集成需足够多样性才有效。

## 二、核心原理

高温度/多提示产生多样路径；过低温度各路趋同，集成失效；温度与提示多样性协同。

## 三、数学形式

路径熵 $H=-\sum_y P(y)\log P(y)$；集成增益随路径熵增而增。

```python
final = vote(outs)
```

## 五、与其他对比

- 与 模型评测指标深入（稳定性）互补。
- 与 提示集成总览 构成采样层。

## 六、常见误区

- 温度过低致各路相同，集成无意义。
- 温度过高致乱答增多。

## 八、面试题

- 为何温度影响集成？答：低温度路径趋同无多样性，高温度才有可聚合的差异。

## 九、演进

贪心 → 单温度采样 → 多温度+多提示。

## 十、小结

提示集成需足够采样多样性，温度与提示协同调。
