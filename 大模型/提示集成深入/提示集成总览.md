# 提示集成总览

> 对应 Wang et al., *Self-Consistency*, 2022；提示集成（Prompt Ensemble）。

## 一、背景与挑战

单提示单采样方差大、易错；多提示/多采样集成可提稳与准。

## 二、核心原理

用多个不同表述或视角的提示分别问模型，聚合答案（投票/加权/再生成），降低偶然错误。

## 三、数学形式

集成预测 $\hat y = \arg\max_y \sum_{i=1}^k \mathbf 1[y_i=y]$ 或平均概率 $\frac1k\sum_i P_i(y)$。

## 四、代码实现

```python
answers = [model(p_i, q) for p_i in prompts]
final = majority_vote(answers)
```

## 五、与其他对比

- 与 提示搜索深入（搜索多提示）衔接。
- 与 模型集成深入（集成权重）对照（这里集成提示非模型）。

## 六、常见误区

- 多提示高度相似，集成无增益。
- 忽略集成成本（k 倍调用）。

## 八、面试题

- 提示集成为何有效？答：多视角降单提示方差，聚合抵消偶然错误，提稳提准。

## 九、演进

单提示 → 多采样 → 多提示+多采样集成。

## 十、小结

提示集成以多样性聚合降方差，是廉价提质的常用法。
