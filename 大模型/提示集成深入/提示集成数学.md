# 提示集成数学原理

> 对应集成学习偏差-方差；自洽理论 衔接。

## 一、背景与挑战

为何聚合能降错误，需从统计解释。

## 二、核心原理

多独立近似的期望接近真值，方差随 k 降；若错误相互独立，集成错误率随 k 指数降。

## 三、数学形式

设单路错误率 $e$，独立时集成错误 $\approx \sum_{j>\lfloor k/2\rfloor} \binom{k}{j}e^j(1-e)^{k-j}$；随 $k$ 降。

## 四、代码实现

```python
err_ensemble = sum(combinations(k,j)*e**j*(1-e)**(k-j) for j in range(k//2+1,k+1))
```

## 五、与其他对比

- 与 多提示投票（离散）共享理论。
- 与 提示集成与采样（多样性）衔接。

## 六、常见误区

- 假设各路独立，实际相关致增益有限。
- 忽视偏差项（系统错）不随 k 消失。
