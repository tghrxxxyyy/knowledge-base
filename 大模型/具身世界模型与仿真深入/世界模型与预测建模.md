# 世界模型与预测建模

> 对应 github karpathy/nanoGPT 项目与 Vaswani 2017 的 Transformer 论文。

## 一、背景与挑战
智能体需在内部模拟未来以规划行动。世界模型学习环境动态，使 agent 可在脑内试错而无需真实交互。

## 二、核心原理
用序列模型在 latent 状态上预测下一观测与奖励，agent 借其做 rollout 规划，再选最优动作执行。

## 三、形式化与数学基础
动态预测：
$ \hat s_{t+1}, \hat r_t = \mathcal{M}_\theta(s_t, a_t) $
规划选择 $ a^*=\arg\max_a \sum \hat r $。

## 四、代码实现
```python
import torch

def world_step(model, s, a):
    s_next, r = model(s, a)
    return s_next, r

def plan(model, s0, actions, horizon=10):
    best, ba = -1e9, None
    for a_seq in actions:
        s, ret = s0, 0.0
        for a in a_seq[:horizon]:
            s, r = world_step(model, s, a)
            ret += r
        if ret > best:
            best, ba = ret, a_seq
    return ba
```

## 五、与其他技术对比
相比无模型 RL，世界模型可内省规划省真实样本；相比真实仿真，速度更快但具近似误差。

## 六、常见误区
模型误差随 rollout 累积致规划崩溃。状态空间设计不当难以学习。

## 八、面试题
问：世界模型为何加速学习？答：在内部预测替代昂贵真实交互，提升样本效率。

## 九、演进与趋势

## 十、小结
世界模型把规划从环境搬到内部模拟。
