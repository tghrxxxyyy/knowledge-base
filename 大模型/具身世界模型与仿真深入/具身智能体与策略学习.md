# 具身智能体与策略学习

> 对应 github pytorch/pytorch 项目与 Schulman 2017 的 PPO 论文。

## 一、背景与挑战
具身 agent 需把感知映射为连续/离散动作并获环境奖励，样本效率低、探索难。

## 二、核心原理
策略网络输出动作分布，用 PPO 在环境交互的轨迹上优化，兼顾稳定与样本利用，适配机器人控制。

## 三、形式化与数学基础
PPO 裁剪目标：
$ \mathcal{L}=\mathbb{E}[\min(\rho_t A_t, \mathrm{clip}(\rho_t,1-\epsilon,1+\epsilon)A_t)] $
$ \rho_t $ 为概率比。

## 四、代码实现
```python
import torch

def ppo_loss(ratio, adv, eps=0.2):
    unclipped = ratio * adv
    clipped = torch.clamp(ratio, 1 - eps, 1 + eps) * adv
    return -torch.min(unclipped, clipped).mean()

def act(policy, obs):
    dist = policy(obs)
    return dist.sample()
```

## 五、与其他技术对比
相比 DQN，PPO 适用连续动作；相比 SAC，PPO 实现简单但需调参。

## 六、常见误区
奖励尺度不当致策略震荡。观测未归一化影响收敛。
