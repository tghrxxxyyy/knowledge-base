# 多模态感知与导航

> 对应 github huggingface/transformers 项目与 Lewis 2020 的 RAG 论文。

## 一、背景与挑战
室内导航需融合视觉、语言指令与地图记忆，在未知环境找目标。

## 二、核心原理
将语言指令与视觉观测编码，结合地图检索过往经验（RAG 式），输出导航动作序列直至到达目标。

## 三、形式化与数学基础
策略条件于多模态：
$ a_t = \pi_\theta(v_t, l, m) $
$ m $ 为地图记忆，可检索更新。

## 四、代码实现
```python
def navigate(policy, vision, lang, memory, goal, max_steps=200):
    traj = []
    for _ in range(max_steps):
        ctx = memory.retrieve(vision, k=4)
        a = policy(vision, lang, ctx)
        traj.append(a)
        if a == 'arrive':
            break
        vision = env.step(a)
    return traj

def update_map(memory, obs, pose):
    memory.add(obs, pose)
```

## 五、与其他技术对比
相比纯视觉导航，语言指令更灵活；相比无记忆，地图检索提升效率与复用。

## 六、常见误区
指令歧义未消歧致走错。地图污染致定位漂移。

## 八、面试题
问：导航为何需记忆？答：大环境无法单帧覆盖，记忆支撑全局规划。

## 九、演进与趋势
端到端 VLN、零样本目标导航与仿真迁移。

## 十、小结
多模态加记忆让 agent 在物理空间自主行动。
