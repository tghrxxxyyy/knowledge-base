# 视觉运动策略

> 对应 github pytorch/pytorch 项目与 Dao 2022 的 FlashAttention 论文。

## 一、背景与挑战
直接用图像控制机器人需把高维视觉映射为动作，对实时性与鲁棒性要求高。

## 二、核心原理
用视觉骨干提取特征，经注意力融合多视角或时序帧，输出动作。FlashAttention 加速长序列处理以满足实时。

## 三、形式化与数学基础
动作回归：
$ a_t = \pi_\theta(\phi(o_t)) $
$ \phi $ 为视觉编码器，$ \theta $ 为策略参数。

import torch

class VisuoMotor(torch.nn.Module):

        self.backbone = backbone
        self.head = head

    def forward(self, frames):

## 五、与其他技术对比
相比状态输入策略，端到端视觉更通用但需更多数据；相比 CNN-LSTM，注意力对长程更敏感。

## 六、常见误区
训练与部署视角不一致致失败。帧率不稳影响控制。

## 八、面试题
问：为何视觉策略要时序聚合？答：单帧噪声大，多帧融合稳定动作估计。

## 九、演进与趋势
多模态感知、闭环纠错与高效部署。

## 十、小结
视觉运动策略把感知直接接为控制。
