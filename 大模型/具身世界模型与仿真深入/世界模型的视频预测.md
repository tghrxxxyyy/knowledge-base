# 世界模型的视频预测

> 对应 Ho 2020 的 DDPM 论文与 github facebookresearch/llama 项目。

## 一、背景与挑战
用视频作为世界模型的隐式表征，可生成未来画面供规划，但需保证时序一致与可控。

## 二、核心原理
以扩散模型在视频潜空间预测未来帧，条件为当前帧与动作，agent 借此评估动作后果而规划。

## 三、形式化与数学基础
视频预测损失：
$ \mathcal{L}=\mathbb{E}\| \epsilon - \epsilon_\theta(x_t^{future}, x^{past}, a) \|^2 $
条件含历史与动作。

## 四、代码实现
```python
import torch

def predict_future(diffuser, past, action, steps=20):
    noise = torch.randn_like(past[:, -1:])
    for t in reversed(range(steps)):
        noise = diffuser.step(noise, t, cond=(past, action))
    return noise

def evaluate(diffuser, policy, past, horizon=5):
    best, ba = -1e9, None
    for a in policy.actions:
        fut = predict_future(diffuser, past, a)
        if score(fut) > best:
            best, ba = score(fut), a
    return ba
```

## 五、与其他技术对比
相比状态世界模型，视频预测更直观但成本高；相比 GAN 预测，扩散更稳。

## 六、常见误区
长程预测漂移失真。动作条件弱致不可控。
