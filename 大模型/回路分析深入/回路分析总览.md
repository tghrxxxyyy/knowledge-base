# 回路分析总览

> 对应 Olsson et al., *In-context Learning and Induction Heads*, 2022；Wang et al., *Interpretability in the Wild*, 2022（IOI）.

## 一、背景与挑战

单个神经元难解释；更可行的是把模型能力分解为“回路”——若干注意力头/MLP 组成的可解释子图，协同完成子任务。

## 二、核心原理

用归因+修补定位负责某行为的组件集合，再绘出其数据流（QKV 交互、残差叠加），得到可解释的 causal graph。

## 三、数学形式

残差流叠加 $x^{(l+1)}=x^{(l)}+A^{(l)}(x^{(l)})+M^{(l)}(x^{(l)})$；回路即子集 $S\subset$ 头/MLP 使 $\text{Model}_S\approx\text{Model}$。

## 四、代码实现

```python
logits_full = model(x)
logits_sub  = model(x, ablate=all_except(S))
faith = (logits_sub.argmax()==logits_full.argmax())
```

## 五、与其他对比

- 与 特征归因深入（更细的因果干预）同范式。
- 与 稀疏自编码器深入（以特征而非组件为单元）互补。

## 六、常见误区

- 假设单头单功能（实际常叠加多义）。
- 忽略残差流中多组件并行叠加。

## 八、面试题

- 为何说神经元不等于功能？答：叠加假设下多个特征共享神经元，功能是分布式回路而非单神经元。

## 九、演进

单神经元 → 注意力头 → 因果回路图。

## 十、小结

回路分析把可解释性从单点推向子图，是 mechanism 解释的核心范式。
