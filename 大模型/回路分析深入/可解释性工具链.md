# 可解释性工具链

> 对应 TransformerLens（Nanda et al.）；Neel Nanda 的 mechanistic interpretability 教程；Olah et al., *Zoom In*, 2020.

## 一、背景与挑战

回路研究需统一工具做钩子、缓存激活、消融与可视化，否则实验不可复现。

## 二、核心原理

用 TransformerLens 等库把模型拆成可干预模块（hook 残差流/头），配合激活缓存与归因图，实现可复现回路实验。

## 三、数学形式

钩子替换 $h^{(l)}\leftarrow h^{(l)}+\delta$；缓存 $C=\{(l,p,h^{(l)}_p)\}$ 供离线分析。

## 四、代码实现

```python
import transformer_lens as tl
model = tl.HookedTransformer.from_pretrained("gpt2-small")
logits, cache = model.run_with_cache(input_ids)
```

## 五、与其他对比

- 是前述所有回路/归因实验的支撑基础设施。
- 与 稀疏自编码器深入（在缓存激活上训练 SAE）衔接。

## 六、常见误区

- 钩子修改后未恢复致后续推理污染。
- 不同库层索引不一致致错位。

## 八、面试题

- 为何需要统一工具链？答：回路实验依赖可复现的钩子/缓存/消融，工具统一方能对比结论。
