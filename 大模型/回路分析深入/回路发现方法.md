# 回路发现方法

> 对应 Conmy et al., *Automatic Circuit Discovery*, 2023（ACDC）；Cunningham et al., *Automated Circuit Discovery*, 2023（EAP）.

## 一、背景与挑战

手工定位回路费时；需自动发现“对任务必要且充分”的组件子集。

## 二、核心原理

ACDC 用因果消融逐步剪枝，保留不影响性能的边；EAP（Edges Activation Patching）用激活修补快速估计边重要性并排序。

## 三、数学形式

边重要性 $I_e=\Delta \text{perf}$ 当冻结/替换该边输出；保留 $\{e:I_e>\tau\}$ 构成最小忠实回路。

## 四、代码实现

```python
edges = all_attn_and_mlp_edges(model)
scores = {e: activation_patch_effect(model, task, e) for e in edges}
circuit = [e for e,s in scores.items() if s > threshold]
```

## 五、与其他对比

- 与 特征归因深入（重要性估计）共用修补技术。
- 与 稀疏自编码器深入（特征为单元）形成不同粒度。

## 六、常见误区

- 自动回路仍可能漏掉分布式贡献。
- 阈值选择影响回路规模与忠实度。

## 八、面试题

- ACDC 与 EAP 区别？答：ACDC 迭代因果消融剪枝，EAP 用激活修补快速近似边重要性。

## 九、演进

手工 → 激活修补排序 → 因果消融剪枝。

## 十、小结

自动回路发现使可解释性规模化，从个案走向系统方法。
