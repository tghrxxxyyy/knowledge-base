# 归纳头（Induction Heads）

> 对应 Olsson et al., *In-context Learning and Induction Heads*, 2022.

## 一、背景与挑战

少样本上下文学习（ICL）如何工作？归纳头揭示了“复制前文模式”的基础机制，是 ICL 的 building block。

## 二、核心原理

归纳头在前文出现 “A B ... A” 时，把 “B” 的的信息复制到当前位置；由两个头组成：一个 previous-token 头 + 一个复制头协作。

## 三、数学形式

复制头在位置 $i$ 查询与 $token_{i-1}$ 匹配的 earlier key，取对应 value 输出；形式化 $h_i\propto\sum_j \mathbb I(t_j=t_{i-1})v_j$。

## 四、代码实现

```python
# 检测归纳头：构造 A B ... A 序列，看是否提升 B 的概率
seq = tok("A B C A")   # 期望在最后一个位置提升 B 概率
```

## 五、与其他对比

- 是 回路分析深入 中最经典可复现的回路。
- 与 线性探针深入（探测是否形成复制特征）互补。

## 六、常见误区

- 以为归纳头等于全部 ICL（仅是基础模式复制）。
- 忽略头之间的组合依赖。

## 八、面试题

- 归纳头如何支持 ICL？答：通过复制前文重复模式，为更抽象的演示学习提供基础机制。

## 九、演进

单一归纳头 → 组合归纳回路 → 通用 ICL 回路。

## 十、小结

归纳头是首个被清晰刻画的因果回路，为理解 ICL 奠定基础。
