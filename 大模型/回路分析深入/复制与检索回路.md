# 复制与检索回路

> 对应 Elhage et al., *A Mathematical Framework for Transformer Circuits*, 2021；Geva et al., *Transformer Feed-Forward Layers*, 2021.

## 一、背景与挑战

模型如何“复述”输入中的实体/事实？复制回路与 early-restriction 机制解释信息如何从上下文流向输出。

## 二、核心原理

复制头把某 token 的 positional/内容信息复制到输出；FFN 被解释为 key-value 记忆，检索回路从 FFN 中读出事实。

## 三、数学形式

FFN 近似 $W_2\phi(W_1 x)\approx\sum_k m_k\cdot\mathbb I(\text{pattern}_k(x))$；即若干键值记忆的检索叠加。

## 四、代码实现

```python
# 比较有/无上下文时实体复述概率
p_with_ctx  = model("Name: Alice. Q: name?").prob("Alice")
p_no_ctx    = model("Q: name?").prob("Alice")
```

## 五、与其他对比

- 与 归纳头（模式复制）同属复制族回路。
- 与 特征归因深入（定位复述来源激活）衔接。

## 六、常见误区

- 把 FFN 当纯非线性而忽略其 KV 记忆解释。
- 复制回路与事实检索混淆。
