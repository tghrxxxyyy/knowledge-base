# 直接/间接对象识别（IOI）回路

> 对应 Wang et al., *Interpretability in the Wild: a Circuit for Indirect Object Identification*, 2022.

## 一、背景与挑战

在 “John 和 Mary 去公园，John 给...” 类句子，模型需识别间接宾语 Mary；IOI 回路给出可解释实现。

## 二、核心原理

由 name mover heads（移动正确名字）、subject inhibition heads（抑制直接宾语）、duplicate token heads（检测重复名）等组成的多组件回路。

## 三、数学形式

输出 logit 受 $\sum_{h\in\text{NM}} a_h - \sum_{h\in\text{SI}} a_h$ 影响；各 head 在残差流中可加性叠加。

## 四、代码实现

```python
logit_full = model(sentence)
for h in name_mover_heads:
    logit_ablate = model(sentence, ablate=[h])
    contrib[h] = logit_full - logit_ablate
```

## 五、与其他对比

- 是 回路分析深入 中组件最多的经典案例。
- 与 稀疏自编码器深入（用特征而非 head 重述该回路）互补。

## 六、常见误区

- 把 IOI 当作唯一消歧机制（实际有多种）。
- 忽略 head 间正负贡献抵消。

## 八、面试题

- IOI 回路由哪些关键头构成？答：name mover、subject inhibition、duplicate token heads 协同实现间接宾语识别。

## 九、演进

IOI 手工回路 → 自动回路发现 → 特征级重述。

## 十、小结

IOI 是迄今最完整的多组件因果回路，证明 Transformer 行为可由可解释子图解释。
