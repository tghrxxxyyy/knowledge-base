# 数学数据与课程

> 对应 Bengio et al., *Curriculum Learning* (2009)；Loshchilov & Hutter 等关于数据排序与训练策略的实践；以官方最新文档为准。

## 一、背景与挑战

高质量数学自然语料在预训练数据中占比极低且分布偏易，直接用随机混洗的数据训练，模型难以学到深层推理。更棘手的是：数学题「难样本」的梯度信号复杂，过早大量投放会让训练不稳定甚至崩溃。如何构造、筛选与排序数学训练数据，决定了模型推理上限，也是各开源大模型数学能力提升的关键工程。

## 二、核心原理

核心思路两条。其一是合成数据：用强模型（或形式化验证器）批量生成多步解题过程，并通过「正确性过滤」（答案校验、PRM 评分、交叉验证）剔除错误样本。其二是课程学习（Curriculum Learning）：按难度由易到难编排训练顺序，让模型先掌握基础模式，再逐步挑战复杂结构，模拟人类「循序渐进」的学习曲线，提升收敛速度与最终性能。二者常结合：合成扩量、过滤保真、课程排序。

## 三、形式化与数学基础

课程学习把训练样本按难度函数 $d(x)$ 排序，得到序列 $x_{(1)},\dots,x_{(N)}$，并定义阶段权重。设第 $k$ 阶段数据为 $\mathcal{D}_k$，训练目标分阶段最小化：

$$\min_{\theta}\ \mathbb{E}_{x\sim \mathcal{D}_k}\big[\mathcal{L}(f_\theta(x), y)\big],\quad k=1,\dots,K$$

难度可用「解题所需步数」「错误率」「PRM 最低步分」等估计。Bengio 等人以课程调度 $\lambda(t)$ 控制难样本混入比例：

$$\mathcal{D}(t) = \{(x,y): d(x) \le \lambda(t)\},\quad \lambda \text{ 随 } t \text{ 单调增}$$

合成数据的正确性过滤可写为保留集合：

$$\mathcal{D}_{\text{clean}}=\{(x,y)\mid \text{verify}(x,y) \text{ 通过且 } \text{PRM}_{\min}>\tau\}$$

## 四、代码实现

```python
# 课程式训练（示意）
def difficulty_of(item):
    return item.step_count * (1.0 - item.prm_min_score)

def curriculum(dataset, stages=5):
    ranked = sorted(dataset, key=difficulty_of)
    n = len(ranked)
    for k in range(stages):
        lo, hi = int(n * k / stages), int(n * (k + 1) / stages)
        yield ranked[lo:hi]          # 由易到难分批

# 合成数据正确性过滤
def clean_synthetic(items, verifier, tau=0.8):
    out = []
    for it in items:
        if verifier.check(it) and min_prm(it) > tau:
            out.append(it)
    return out
```

## 六、常见误区

误区一：难题越多越好——过早喂难样本会破坏早期表征。误区二：合成数据无需过滤——错误样本会污染模型。误区三：课程顺序无关紧要——排序不当反而会拖慢收敛。误区四：一次排好序就固定——自适应课程往往更优。

## 九、演进与趋势

从静态课程到「自适应课程」（按验证损失动态调整难度）；形式化验证器为合成数据提供零噪声金标；多阶段（预训练→领域→指令）数据配比成为大模型标配。数据配方（data recipe）本身正成为核心竞争力。

### 实践速查

- 合成：用强模型生成多步题解，配合答案校验与 PRM 过滤保真。
- 课程：按步数、错误率、PRM 最低步分定义难度，由易到难分批。
- 配比：预训练语料中数学占比需兼顾通用性，避免过度偏置。
- 去重：合成题与真实题都需去重，防止重复样本主导梯度。
- 阶段：预训练打底、继续预训练加深、指令微调对齐解题风格。
- 自适应：验证损失上升即放慢难度推进，下降则可提速。

### 常见问题

- 问：合成数据越多越好吗？答：否，错误样本会污染，过滤比数量更重要。
- 问：课程顺序错了会怎样？答：可能拖慢收敛甚至让早期训练不稳定。

## 十、小结

数据与课程决定数学上限：合成扩量、过滤保真、由易到难编排，三者共同支撑推理能力跃迁。
