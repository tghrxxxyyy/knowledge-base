# 数学数据与课程

> 见「合成数据与课程学习」与「数学大模型深入/数学推理挑战」。

## 一、背景与挑战

高质量数学语料稀缺，需合成与课程式训练。

## 二、核心原理

用强模型生成多步解题数据，按难度编排课程（易→难）逐步训练，避免难样本过早压垮。

## 三、关键要点

- 合成数据需正确性过滤。
- 课程顺序影响收敛。

## 四、代码实现

```python
for stage in sorted_by_difficulty(data): train(stage)
```

## 五、与其他对比

- 随机训练易卡；课程更稳。

## 六、常见误区

- 越多难题越好——需循序渐进。
