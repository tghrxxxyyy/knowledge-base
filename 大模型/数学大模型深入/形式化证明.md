# 形式化证明

> 见「数学大模型深入/数学推理挑战」与「代码大模型深入」。

## 一、背景与挑战

数学证明需绝对严谨，自然语言证明有漏洞风险。

## 二、核心原理

让 LLM 生成形式化语言（如 Lean/Isabelle）证明，由证明助手验证，实现「机器可证」。

## 三、关键要点

- 形式化门槛高、数据少。
- 验证器保证正确。

## 四、代码实现

```lean
theorem add_comm (a b : Nat) : a + b = b + a := by
  induction a <;> simp_all
```

## 五、与其他对比

- 自然语言证明易错；形式化可验证但难写。

## 六、常见误区

- 模型能写证明=正确——需验证器确认。

## 七、与开源书对应

- Lean: https://github.com/leanprover/lean4
- llm-course: https://github.com/mlabonne/llm-course
