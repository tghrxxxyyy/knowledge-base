# 数学推理挑战

> 对应 Hendrycks et al., *MATH: Measuring Mathematical Problem Solving with the MATH Dataset* (2021)；Cobbe et al., *Training Verifiers to Solve Math Word Problems* (GSM8K, 2021)；Lewkowycz et al., *Minerva* (2022)。

## 一、背景与挑战

数学是检验大模型推理能力的「试金石」：它要求严格的多步逻辑、精确的符号操作与稳定的中间计算，任何一步出错都会使最终答案错误。早期 LLM 在算术、代数、几何题上表现脆弱，问题集中爆发在长链推理的中间步骤——而非仅在末尾。更隐蔽的是，模型常能给出「看似合理」的错误推导，欺骗人类评估者。

## 二、核心原理

数学推理的难点可拆为四类：长链错误累积（步数越多越易错位）、符号与语义混淆（变量、运算符、单位）、缺乏可验证中间信号（只有答案对错太稀疏）、以及分布外泛化（题型稍变即失效）。当前主流解决思路是组合拳：CoT 显式化推理、过程监督（PRM）提供稠密信号、工具（计算器/符号库）保证算术正确、强化微调（RFT）提升解题策略。这四者分别对应「显式化、可监督、可计算、可优化」。

## 三、形式化与数学基础

把解题建模为策略 $\pi$ 在状态空间上的搜索。给定问题 $x$，模型生成推理轨迹 $\tau=(a_1,\dots,a_T)$，目标是最大化到达正确终态 $y^*$ 的概率：

$$\max_{\pi}\ \mathbb{E}_{x\sim\mathcal{D}}\big[ P_{\pi}(y^* \mid x) \big]$$

引入过程奖励后，目标变为对轨迹的逐步期望回报：

$$\mathcal{J}(\pi)=\mathbb{E}_{x,\tau\sim\pi}\Big[\sum_{t=1}^{T} \gamma^{T-t}\, r_t\Big],\quad r_t\approx P(\text{第 }t\text{ 步正确})$$

工具调用则可视为把某步 $a_k$ 外包给确定性函数 $f$，使算术误差 $\epsilon\to 0$，从而把「计算错误」从误差预算中剔除。

## 四、代码实现

```python
# 多信号协同的数学解题（示意）
def solve_math(problem, llm, prm, tool):
    chain = llm.chain_of_thought(problem)        # 1. CoT 生成
    steps = split_steps(chain)
    scored = [(s, prm.score(problem, s)) for s in steps]
    for s, score in scored:
        if needs_compute(s):
            res = tool.run(extract_expr(s))       # 2. 工具保证计算
            chain = chain.replace(s, s + f" [{res}]")
    return chain

# 用 PRM 在多条候选链中选最优
def best_of_n(problem, llm, prm, n=8):
    candidates = [solve_math(problem, llm, prm, tool) for _ in range(n)]
    return max(candidates, key=lambda c: sum(prm.score(problem, s) for s in c))
```

## 六、常见误区

误区一：答案对等于会做——中间可能错且无法泛化。误区二：堆参数就能解决数学——数据与训练信号（PRM、工具）更关键。误区三：忽视数据污染——测试集混入训练语料会虚高指标。误区四：把验证集上的提升直接等同于真实推理能力跃迁。

## 九、演进与趋势

从「直接作答」走向「CoT + PRM + 工具 + 强化」的复合流水线；形式化证明（Lean）开始进入竞赛级题目；多模态题目（图、表）成为新前沿；自我博弈与递归自我改进也在探索中。

### 实践速查

- 优先级：先把 CoT 跑通，再加工具保计算，最后上 PRM 与强化提上限。
- 评测：除答案准确率外，记录过程正确率与逐步 PRM 分，避免虚高。
- 防污染：训练前用 n-gram/嵌入去重，排除与测试集重叠的题。
- 数据：用课程学习由易到难，先 GSM8K 级再 MATH/AIME 级。
- 工具：计算密集步骤一律外包代码执行，仅保留逻辑在模型侧。
- 失败诊断：若答案错，先看哪一步 PRM 分骤降，定位错误阶段。

### 常见问题

- 问：小模型数学差，加 CoT 有用吗？答：收益有限，先扩参或蒸馏更强模型。
- 问：过程对但答案错常见吗？答：常见，多因末步计算或单位疏漏，工具可解。

### 关键记忆点

- 数学推理四大难点：长链累积、符号混淆、缺中间信号、分布外。
- 解法是 CoT + PRM + 工具 + 强化的组合拳，没有单一银弹。
- 评测必须区分答案正确与过程正确，否则指标失真。

## 十、小结

数学推理靠显式推理、稠密监督与工具闭环共同攻克，是衡量大模型智能上限的核心战场，没有单一银弹。
