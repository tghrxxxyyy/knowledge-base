# 数学推理挑战

> 对应 llm-course 推理章与 d2l-zh；基准见 Cobbe et al., *GSM8K*, 2021。

## 一、背景与挑战

数学要求严格多步逻辑与符号操作，早期 LLM 易在中间步出错。

## 二、核心原理

难点：长链推理易累积错误、符号运算难、缺乏可验证中间信号。解决靠 CoT、过程监督、工具（计算器/符号库）、强化微调。

## 三、关键要点

- 过程正确性比答案更重要（PRM）。
- 工具辅助显著降低算术错。

## 四、代码实现

```python
ans = llm(f"逐步推理并验算:\n{q}\n用工具检查计算")
```

## 五、与其他对比

- 通用对话模型弱；数学竞赛模型（如 Minerva）专项强。

## 六、常见误区

- 答案对=会做——中间可能错。
