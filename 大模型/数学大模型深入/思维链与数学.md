# 思维链与数学

> 对应 Wei et al., *Chain-of-Thought Prompting Elicits Reasoning in Large Language Models* (2022)；Wang et al., *Self-Consistency Improves Chain of Thought Reasoning* (2022)。

## 一、背景与挑战

早期大模型面对多步算术与应用题时，常直接吐出答案却错得离谱。根本原因在于：自回归生成把整个推理压缩进一次隐式「思维」，既无法对中间步骤纠错，也缺乏可被监督的显式依据。随着模型规模增大，这种「快思考」式作答在数学、符号操作、多跳逻辑上的瓶颈越发明显，成为衡量大模型推理能力的关键短板。更现实的是，评测中「答案错但过程有理」与「答案对但过程瞎蒙」长期难以区分，直至 CoT 把过程暴露出来。

## 二、核心原理

思维链（Chain-of-Thought, CoT）要求模型在给出最终答案前，先输出一段自然语言的中间推理步骤：把「问题→答案」的隐式映射，改写为「问题→步骤1→步骤2→…→答案」的显式序列。其价值有三：一是把隐式计算显式化，使错误可被定位；二是为后续过程监督与自洽投票提供载体；三是契合自回归模型「逐 token 预测」的归纳偏好，降低长程组合难度。

CoT 主要形式包括：少样本 CoT（在提示里放几个带推理过程的示例）、零样本 CoT（仅加「让我们一步步思考」这类触发句）、以及自洽性 CoT（采样多条链再做多数投票）。三者可由弱到强组合使用。

## 三、形式化与数学基础

设问题为 $x$，答案为 $y$，推理链为 $z$。标准自回归直接计算条件概率：

$$P(y\mid x)=\prod_{i}P(y_i\mid x, y_{<i})$$

引入 CoT 后，建模目标变为联合概率：

$$P(y,z\mid x)=P(z\mid x)\,P(y\mid x,z)\approx \prod_{j}P(z_j\mid x,z_{<j})\cdot P(y\mid x,z)$$

自洽性（Self-Consistency）用边际近似取代贪心解码：

$$\hat{y}=\operatorname{argmax}_{y}\sum_{z\in\mathcal{Z}}\mathbb{1}\!\left[\text{parse}(z)=y\right]$$

即在多条采样链 $z$ 上做多数投票，等价于求解 $y=\operatorname{argmax}_y \sum_z P(z\mid x)\,\mathbb{1}[\text{answer}(z)=y]$。当采样数足够大，该近似逼近对 $z$ 的边缘积分。

## 四、代码实现

```python
import openai

# 少样本 CoT：在 prompt 中给出带推理的示例（用普通字符串，避免 docstring）
few_shot_cot = (
    "Q: 小明有5个苹果，吃掉2个，又买3个，共几个？\n"
    "A: 先有5个，吃掉2个剩3个，再买3个，共6个。答案：6。\n\n"
    "Q: {question}\n"
    "A: 让我们一步步思考。"
)

def chain_of_thought(question):
    resp = openai.ChatCompletion.create(
        model="gpt-4",
        messages=[{"role": "user", "content": few_shot_cot.format(question=question)}],
        temperature=0.7,
    )
    return resp.choices[0].message.content

# 自洽性：采样多条链再投票
def self_consistency(question, n=5):
    chains = [chain_of_thought(question) for _ in range(n)]
    answers = [extract_answer(c) for c in chains]  # 提取末尾数字答案
    return max(set(answers), key=answers.count)
```

| 少样本 CoT | 是 | 是 | 陡增 | 是 | 长上下文 |

| 工具增强 | 是（外部） | 否 | 各规模 | 部分 | 执行器 |

## 六、常见误区

误区一：CoT 能自动让小模型变聪明——实证表明 CoT 收益随参数量陡增，小模型提升有限。误区二：推理链自洽即正确——多条链可能一致地犯同一概念错误（系统性偏差）。误区三：把 CoT 当作真实「思维」——它仍是统计生成的文本，不是可执行的规划。误区四：示例越多越好——无关示例反而扰乱分布。

## 九、演进与趋势

CoT 已衍生出树状搜索（ToT）、图状搜索（GoT），以及把推理过程交给验证器或奖励模型筛选。与过程奖励模型（PRM）、工具调用（PAL/ToRA）的结合，是当前数学推理的主流范式；更前沿的方向是让模型自我反思并修正推理链。

### 实践速查

- CoT 三形式：少样本、零样本、自洽，规模越大收益越明显。
- 自洽投票数通常取 5–40，越多越稳但推理成本线性上升。
- 评测数学务必区分「答案对」与「过程对」，避免被错误链蒙蔽。
- 触发句「让我们一步步思考」对零样本 CoT 往往足够有效。

## 十、小结

CoT 把隐式推理显式化，是释放大模型多步推理能力的基石；配合自洽与过程监督，构成现代数学推理流水线的第一环，但其正确性仍需外部验证而非盲目信任。
