# 思维链与数学

> 见「提示工程深入/思维链CoT」与「数学大模型深入/数学推理挑战」。

## 一、背景与挑战

不显式推理直接给答案，LLM 数学极差；CoT 显著提升。

## 二、核心原理

让模型输出中间推理步骤再给答案，把隐式计算显式化，便于纠错与监督。

## 三、数学形式

答案概率分解：

```
P(ans|x) ≈ P(ans|x, reasoning chain)
```

## 四、代码实现

```python
out = llm("请一步步思考:\n" + q)
```

## 五、关键要点

- 少样本 CoT 即可见效。
- 自洽性（多链投票）进一步提升。

## 六、与其他对比

- 普通提示弱；CoT 强但更长。

## 七、常见误区

- CoT 一定对——链可能自洽但错。
