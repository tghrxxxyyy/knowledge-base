# 工具增强推理

> 见「Function_Calling进阶/工具调用协议」与「数学大模型深入/数学推理挑战」。

## 一、背景与挑战

大模型心算易错，但可调用计算器/Python 保证准确。

## 二、核心原理

模型在推理中输出可执行代码（如 Python 算式），运行后把结果回填继续推理（Program-Aided/ToRA 思路）。

## 三、代码实现

```python
code = llm("写代码计算:\n" + expr); res = exec(code)
```

## 四、关键要点

- 沙箱执行防风险。
- 代码比自然语言更精确。

## 五、与其他对比

- 纯语言推理易错；代码工具稳。

## 六、常见误区

- 工具调用慢不值得——准确率提升通常值得。

## 七、与开源书对应

- Gao et al., *PAL*, 2022; Chen et al., *ToRA*, 2023.
- llm-course: https://github.com/mlabonne/llm-course

## 九、演进

心算 → 计算器 → 代码执行。

## 十、小结

工具让数学推理「可验证」。
