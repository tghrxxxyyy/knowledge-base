# 数学竞赛基准

> 对应 Hendrycks et al., *MATH: Measuring Mathematical Problem Solving with the MATH Dataset* (2021)；Cobbe et al., *GSM8K* (2021)；AIME（American Invitational Mathematics Examination）。

## 一、背景与挑战

通用知识基准（如 MMLU）难以区分模型的「真实推理上限」与「记忆性知识」。衡量数学推理需要高难度、有过程、难记忆的基准。竞赛题因题型新颖、步骤深、答案唯一且可机检，成为最权威的推理标尺，典型包括 GSM8K、MATH、AIME，以及更高阶的 Olympiad 级题集。缺乏这些基准，就无法客观比较不同训练方法的推理增益。

## 二、核心原理

各基准定位不同：GSM8K 为小学至初中文字应用题，单步到少步；MATH 为高中竞赛题，按难度 1–5 级标注并附分步解答；AIME 为美国数学邀请赛，每题整数答案、极难；Olympiad 级（如 IMO）则需创造性证明。评测不仅看最终答案准确率，还看步骤正确率与可验证性，越来越多采用 LLM 评判或 PRM 辅助评分，以缓解「答案对但过程错」的误判。

## 三、形式化与数学基础

设基准 $\mathcal{B}$ 含 $N$ 道题，模型对题 $i$ 输出 $\hat{y}_i$。答案准确率定义为：

$$\text{Acc}=\frac{1}{N}\sum_{i=1}^{N}\mathbb{1}[\hat{y}_i = y_i^*]$$

MATH 还引入难度加权或步骤级匹配。为衡量「过程质量」，可用 PRM 对生成轨迹打分：

$$\text{ProcessScore}=\frac{1}{T}\sum_{t=1}^{T} r_t,\quad r_t\in[0,1]$$

污染检测常通过 n-gram 重叠或题目改写一致性来判断训练/测试泄漏，泄漏会显著虚高指标。

## 四、代码实现

```python
# 竞赛基准评测极简框架（示意）
def evaluate(model, dataset):
    correct = 0
    for item in dataset:
        pred = model.solve(item.question)          # 含 CoT
        ans = extract_final_answer(pred)
        if normalize(ans) == normalize(item.answer):
            correct += 1
    return correct / len(dataset)

# 难度分层统计
def acc_by_level(dataset, model):
    table = {}
    for item in dataset:
        level = item.level
        table.setdefault(level, [0, 0])
        table[level][1] += 1
        if model.solve(item) == item.answer:
            table[level][0] += 1
    return {lv: v[0] / v[1] for lv, v in table.items()}
```

## 六、常见误区

误区一：GSM8K 高分即数学强——它仅小学级，区分度低。误区二：单一基准定高下——不同基准测不同能力。误区三：忽视数据污染——竞赛题若进入预训练语料，指标失真。误区四：只看答案准确率——过程质量同样重要。

## 九、演进与趋势

从自动抽取答案，到用 LLM/PRM 评过程；从单答案到要求完整证明（形式化基准如 MiniF2F）；Olympiad 级基准成为新天花板，且与工具调用结合考察真实解题能力。

### 实践速查

- 选型：小学应用题用 GSM8K；高中竞赛用 MATH（按 level 细分）；高难用 AIME。
- 评测：答案归一化后比对，MATH 还需校验分步解答的步骤正确性。
- 防污染：竞赛题易泄漏进预训练，需做训练集去重与 leakage 检测。
- 分层：务必按难度 level 报数，单看总体准确率会掩盖短板。
- 过程评估：用 PRM 或 LLM 评委给步骤打分，得到过程质量分。
- 趋势：Olympiad 级（IMO 风格）正成为新基准，要求完整证明。

### 常见问题

- 问：GSM8K 满分是否说明数学很强？答：否，仅小学级，需看 MATH/AIME。
- 问：如何检测数据污染？答：题目改写一致性 + n-gram 重叠 + 留一验证。

## 十、小结

竞赛基准以难度、过程与抗污染三特性，丈量大模型数学推理的真实天花板，是方法比较的必备标尺。
