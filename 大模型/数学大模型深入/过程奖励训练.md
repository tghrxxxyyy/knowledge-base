# 过程奖励训练

> 见「偏好优化前沿/过程监督PRM」与「数学大模型深入/数学推理挑战」。

## 一、背景与挑战

只有答案对错难激励正确推理路径，PRM 对每步打分。

## 二、核心原理

训练 PRM 判定每步正确性，训练时用步骤奖励引导搜索/强化，显著提升竞赛题（如 MATH）表现（OpenAI 实证）。

## 三、关键要点

- 逐步标注昂贵。
- 可自举（模型标模型）。

## 四、代码实现

```python
score = prm(step); if score < 0.5: backtrack()
```

## 五、与其他对比

- ORM 看结果；PRM 看过程。

## 六、常见误区

- PRM 标注错则更差。
