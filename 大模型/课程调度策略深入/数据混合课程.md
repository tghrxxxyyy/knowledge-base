# 预训练数据混合课程

> 对应 Xie et al., 《DoReMi》, 2023；以及 GPT-4 技术报告中的数据课程。

## 一、背景与挑战

LLM 预训练多源数据（网页/书/代码）比例影响能力；固定混合未必最优。

## 二、核心原理

先训小参考模型，用各域损失反推域权重，再按权重重采样训练大模型（DoReMi 域重加权）。

## 三、数学形式

目标 $\max_\lambda \mathbb E_{x\sim mix_\lambda}[-\log p_\theta(x)]$，由参考模型损失计算最优 $\lambda$。

## 四、代码实现

```python
domain_loss = {d: compute_loss(ref, data[d]) for d in domains}
weights = softmax(-domain_loss)
```

## 五、与其他对比

- 与 课程调度策略深入（宏观数据课程）共享。
- 与 合成数据生成深入（域配比）衔接。

## 六、常见误区

- 域权重过偏致某些能力塌缩。
- 只在小模型算权重外推失真。
