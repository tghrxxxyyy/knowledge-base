# 难度度量与排序

> 对应 Graves et al., 《Automated Curriculum》, 2017；用损失/置信度量难度。

## 一、背景与挑战

难度难定义；需可计算、稳定的样本难度信号驱动课程。

## 二、核心原理

用当前模型损失（高损失=难）、预测熵、或教师置信作难度分；也可按样本长度/稀有度启发式。

## 三、数学形式

难度 $d(x) = \mathcal L(\theta;x)$ 或 $d(x)=H(p_\theta(\cdot|x))$；按升序排课。

## 四、代码实现

```python
losses = [cross_entropy(model(x), y) for x, y in pool]
order = sorted(range(len(pool)), key=lambda i: losses[i])
```

## 五、与其他对比

- 与 标签噪声纠正深入（高损失也可能是噪声）需区分。
- 与 少样本适配深入（难样本也重要）对照。

## 六、常见误区

- 把标注噪声当难度，错误排课。
- 难度静态计算未随训练更新。

## 八、面试题

- 如何度量样本难度？答：用模型损失、预测熵或置信度近似，损失高/熵高者更难。

## 九、演进

启发式长度 → 损失/置信 → 动态重算难度。

## 十、小结

难度度量是课程核心，需区分真难样本与噪声样本。
