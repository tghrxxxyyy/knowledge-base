# 学习率课程调度

> 对应 Vaswani et al., 《Attention Is All You Need》, 2017 的 warmup+余弦衰减。

## 一、背景与挑战

训练初期大学习率致不稳定；需 warmup 平稳起步再以调度降温。

## 二、核心原理

前若干步线性 warmup 升学习率，之后余弦或阶梯衰减；Transformer 常用 Noam 调度。

## 三、数学形式

$lr = d_{model}^{-0.5} \cdot \min(t^{-0.5}, t\cdot warmup^{-1.5})$（Noam 调度）。

## 四、代码实现

```python
lr = d_model**-0.5 * min(step**-0.5, step * warmup_steps**-1.5)
optimizer.set_lr(lr)
```

## 五、与其他对比

- 与 课程调度策略深入（样本课程并列的调度维度）共享。
- 与 灾难性遗忘缓解深入（续训学习率）衔接。

## 六、常见误区

- warmup 过长拖慢收敛。
- 衰减过快致欠拟合。

## 七、与开源书对应

- harvardnlp/annotated-transformer：https://github.com/harvardnlp/annotated-transformer
- d2l-zh：https://github.com/d2l-ai/d2l-zh

## 八、面试题

- 为何要 warmup？答：训练初参数随机，大 lr 易发散，warmup 逐步升 lr 稳起步。

## 九、演进

固定 lr → step decay → warmup+余弦/Noam。

## 十、小结

学习率课程是训练稳定的基础调度，warmup 与衰减缺一不可。
