# 课程调度策略总览

> 对应 Bengio et al., 《Curriculum Learning》, 2009；由易到难组织训练样本。

## 一、背景与挑战

随机打乱训练易陷入难样本噪声；课程学习按难度排序，先易后难助收敛与泛化。

## 二、核心原理

定义样本难度度量，按序（或 pacing 函数逐步加入）呈现；难度可来自样本长度、损失或模型置信。

## 三、数学形式

课程序列 $D_1 \subset D_2 \subset \dots \subset D_T$，各阶段只用前 $t$ 步数据子集。

## 四、代码实现

```python
order = sorted(dataset, key=lambda x: difficulty(x))
for epoch in range(T):
    subset = order[: int(len(order) * p[epoch])]
```

## 五、与其他对比

- 与 合成数据生成深入（课程可用合成数据）互补。
- 与 多任务梯度平衡深入（都是训练调度）共享。

## 六、常见误区

- 难度度量错致课程失效。
- 课程过慢致后期数据未充分见。

## 八、面试题

- 课程学习为何有效？答：由易到难降低早期优化难度，避噪声难样本，提升收敛与泛化。

## 九、演进

固定课程 → pacing 函数 → 自定步调/自适应课程。

## 十、小结

课程调度以难度排序组织训练，是低成本泛化增益手段。
