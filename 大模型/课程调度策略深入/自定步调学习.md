# 自定步调学习（Self-Paced Learning）

> 对应 Kumar et al., 《Self-Paced Learning》, 2010；模型自主选择易样本。

## 一、背景与挑战

预定义课程不随模型状态；自定步调让模型按当前能力挑样本。

## 二、核心原理

每轮只训练当前损失低于阈值（即模型已会/易）的样本，逐步降低阈值纳入更难样本，类似课程但由模型驱动。

## 三、数学形式

$\min_{w,v} \sum_i v_i \ell_i(w) - \frac{\lambda}{2}\|v\|^2$，$v_i\in[0,1]$ 为样本入选权。

## 四、代码实现

```python
v = (losses < threshold).float()
loss = (v * losses).mean()
threshold = max(0.0, threshold - decay)
```

## 五、与其他对比

- 与 课程调度策略深入（定义课程 vs 自适应）对照。
- 与 标签噪声纠正深入（自步可避噪声）互补。

## 六、常见误区

- 阈值衰减过快又引入噪声。
- 与异常值混淆致选样偏。

## 八、面试题

- 自定步调与课程区别？答：课程由外部难度定序，自定步调由模型当前能力自适应选样。

## 九、演进

专家课程 → 自定步调 → 课程+自步融合。

## 十、小结

自定步调以模型状态驱动选样，比静态课程更贴合训练动态。
