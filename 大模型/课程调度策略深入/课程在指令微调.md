# 课程在指令微调中的应用

> 对应 Wei et al., 《FLAN》, 2021；多任务由易到难与提示模板课程。

## 一、背景与挑战

指令微调多任务混合，任务难度/格式差异大，需排序或混合比例调度。

## 二、核心原理

按任务难度或数据量排课；也可按模板复杂度渐进（简单指令→链式思维）；混合比动态调节。

## 三、数学形式

任务权重 $w_t$ 随训练步变化，$p(t) \propto w_t$，课程早期偏易任务。

## 四、代码实现

```python
probs = softmax([w[t] for t in tasks])
batch_task = random.choices(tasks, weights=probs)
```

## 五、与其他对比

- 与 多任务梯度平衡深入（权重维度互补）共享。
- 与 合成数据生成深入（合成指令入课）衔接。

## 六、常见误区

- 任务权重固定忽略阶段需求。
- 难任务过早引入致不稳。

## 八、面试题

- 指令微调也要课程？答：任务难度不一，由易到难与动态权重可稳训练、提泛化。

## 九、演进

混合全量 → 任务排课 → 模板复杂度渐进。

## 十、小结

指令微调中课程体现在任务与模板维度，动态权重提升训练质量。
