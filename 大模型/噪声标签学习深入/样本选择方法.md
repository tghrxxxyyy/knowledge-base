# 样本选择方法

> 见「噪声标签学习深入/噪声标签学习总览」；Han et al., *Co-teaching*, 2018。

## 一、背景与挑战

能否只学「看起来干净」的样本？

## 二、核心原理

**Co-teaching**：两个网络互相挑对方小损失样本（小损失更可能为干净）给对方训练，过滤噪声。进阶 Co-teaching+、MentorNet（用课程网络教主网络挑样本）。

## 三、数学形式

每轮以损失阈值 `R(t)`（随训练下降）选前 R% 小损失样本。

## 四、代码实现

```python
clean = loss < quantile(loss, R)
loss_peer = peer_loss[clean].mean()
```

## 五、关键要点

- 两网络需足够差异（不同初始化）。
- 阈值策略关键。

## 六、与其他对比

- 鲁棒损失全用；样本选择只信部分。

## 七、常见误区

- 小损失=干净——也可能易样本。
