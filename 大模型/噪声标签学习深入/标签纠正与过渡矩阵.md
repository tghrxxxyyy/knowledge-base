# 标签纠正与过渡矩阵

> 见「噪声标签学习深入/噪声标签学习总览」；Hendrycks et al., *Using TRACH*, 2018。

## 一、背景与挑战

能否直接修正错标签或建模噪声？

## 二、核心原理

- **过渡矩阵 T**：建模 `P(观测标签|真实标签)`，用锚点（可信样本）或交叉验证估计，训练中按 T 校正损失（Forward/Backward correction）。
- **标签纠正**：用模型预测替换原标签（需谨慎防误差累积）。
- **置信学习（Confident Learning）**：估计噪声率并剪枝/重标。

## 三、数学形式

校正损失：`L = ℓ(T^T p_model, y_obs)`。

## 四、代码实现

```python
loss = ce(T.T @ p_model, y_obs)   # 前向校正
```

## 五、关键要点

- 过渡矩阵估计难，需锚点。
- 纠标易正反馈错误。

## 六、与其他对比

- 样本选择剔除；纠正直接改标。

## 七、常见误区

- 纠标必好——可能固化错。
