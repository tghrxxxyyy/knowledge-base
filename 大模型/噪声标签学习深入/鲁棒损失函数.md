# 鲁棒损失函数

> 见「噪声标签学习深入/噪声标签学习总览」；Wang et al., *Symmetric CE*, 2019；Zhang et al., *Generalized CE*, 2018。

## 一、背景与挑战

标准 CE 在错标签上过拟合噪声。

## 二、核心原理

- **对称交叉熵（SCE）**：结合 CE 与反向 KL，对噪声鲁棒。
- **广义交叉熵（GCE）**：介于 MAE 与 CE 之间，小损失权重低，减轻错标影响。
- **MAE 损失**：对异常不敏感但收敛慢。

## 三、数学形式

GCE: `L_q = (1-p_y^q)/q`，q→1 趋 MAE。

## 四、代码实现

```python
def gce(logits, y, q=0.7):
    p = F.softmax(logits, -1)
    return ((1 - p[range(len(y)), y])**q / q).mean()
```

## 五、关键要点

- 鲁棒损失常需配合早期停止。
- 过度鲁棒会欠拟合。

## 六、与其他对比

- CE 敏感；MAE 鲁棒但慢。

## 七、常见误区

- 鲁棒损失万能——高噪声仍需纠标。
