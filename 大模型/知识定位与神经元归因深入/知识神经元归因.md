# 知识神经元归因

> 对应 Dai et al., *Knowledge Neurons in Pretrained Transformers*, ACL 2022；Sundararajan et al., *Integrated Gradients*, ICML 2017。

## 一、背景与挑战

除层级定位外，人们希望细到「哪些前馈神经元承载这条事实」。归因方法需要既有理论基础（完备性），又能通过消融验证。

## 二、核心原理

知识神经元用积分梯度对前馈中间激活做归因，再以抑制/放大该神经元后的概率变化作为验证。

- 归因分数沿激活从 0 到实际值的路径积分梯度，满足完备性（各分量之和等于总输出差）。
- 验证方式是双向消融：抑制高分神经元应显著降低目标事实概率，放大应提升，且对无关事实影响小。

## 三、数学形式

$$\mathrm{Attr}(w_i)=\bar w_i\int_{0}^{1}\frac{\partial\, p_\theta\big(y^\ast\mid x,\ w_i=\alpha\bar w_i\big)}{\partial\, w_i}\,d\alpha$$

实践中用黎曼和近似：$\mathrm{Attr}\approx \frac{\bar w_i}{m}\sum_{j=1}^{m}\frac{\partial p(y^\ast\mid w_i=\frac{j}{m}\bar w_i)}{\partial w_i}$。

## 四、代码实现

```python
import torch
def integrated_grad(forward_fn, act, steps=20):
    total = torch.zeros_like(act)
    for j in range(1, steps + 1):
        a = (act * j / steps).detach().requires_grad_(True)
        forward_fn(a).backward()
        total += a.grad
    return act * total / steps
```

## 五、与其他对比

- 与因果追踪对照：归因给出细粒度分数，追踪给出层-位置粒度的因果强度，常配合使用。
- 与 注意力头功能分化深入 对照：一者归因到 MLP 神经元，一者归因到注意力头。

## 六、常见误区

- 只报归因分数不做消融验证；梯度类归因对基线选择与饱和区敏感。
- 认为少数神经元「独占」事实；多数事实由分布式神经元集合共同支持，冗余明显。

## 八、面试题

- 积分梯度为何优于原始梯度？答：满足完备性与实现不变性，缓解饱和导致的梯度消失误判。
- 如何验证知识神经元？答：抑制与放大双向消融，并检查对无关事实的局部性影响。

## 九、演进

梯度显著性 → 积分梯度归因 → 神经元级消融验证 → 与稀疏特征分解结合的可解释单元。

## 十、小结

知识神经元提供细粒度归因，但必须以双向消融与局部性检验为证据链闭环。
