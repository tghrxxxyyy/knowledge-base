# 知识定位总览

> 对应 Meng et al., *Locating and Editing Factual Associations in GPT (ROME)*, NeurIPS 2022；Vig et al., *Causal Mediation Analysis*, NeurIPS 2020。

## 一、背景与挑战

「这条事实存在模型的哪里」不是修辞问题，而是可以用干预实验回答的因果问题。定位结果直接决定编辑、遗忘与审计的落点。

## 二、核心原理

定位的标准工具是因果中介分析：破坏输入、逐步恢复中间激活，观察哪些位置的恢复能把正确答案的概率救回来。

- 关键量是间接效应：某层某位置的激活被恢复后目标概率的回升幅度。
- 结果通常呈现两个高效应区：主体 token 上的中间层前馈，以及末位 token 上的后期注意力。

## 三、数学形式

$$\mathrm{IE}(l,t)=p_{\text{corrupt},\ h^{(l)}_t \leftarrow h^{(l),\text{clean}}_t}\!\left(y^\ast\right)-p_{\text{corrupt}}\!\left(y^\ast\right)$$

$\mathrm{IE}$ 越大说明该激活对预测的因果贡献越强；对全层全位置扫描即得到因果追踪热力图。

## 四、代码实现

```python
import torch
def patch_hook(store, layer, pos):
    def hook(module, inp, out):
        out[0][:, pos, :] = store[layer][:, pos, :]   # 用干净激活覆盖被污染激活
        return out
    return hook
handles = [model.blocks[l].register_forward_hook(patch_hook(clean, l, pos))
           for l in [12]]
```

## 五、与其他对比

- 与探针对照：探针只证明信息可解码（相关），因果追踪证明信息被使用（因果）。
- 与 残差流与贡献分解深入 衔接：patching 的对象正是残差流上的读写位置。

## 六、常见误区

- 把高效应层等同于「知识唯一存储处」；效应是分布式的，峰值只是相对集中。
- 忽略污染方式（加噪 vs 换主体）对结论的影响，不同破坏方式给出不同热图。

## 八、面试题

- 因果追踪如何工作？答：污染输入后逐个恢复中间激活，用目标概率回升度量因果贡献。
- 为什么定位不等于唯一存储？答：表示分布式冗余，多处激活可部分替代彼此。

## 九、演进

因果中介分析（2020）→ 事实定位与 ROME（2022）→ 批量编辑与争议（2023）→ patching 方法学规范（2024）。

## 十、小结

知识定位的可信版本是因果干预而非相关解码，其结论必须标注干预方式与评估指标。
