# 归因方法的评估与陷阱

> 对应 Zhang & Nanda, *Towards Best Practices of Activation Patching*, ICLR 2024；Conmy et al., *Towards Automated Circuit Discovery*, NeurIPS 2023。

## 一、背景与挑战

同一模型同一任务，改变污染方式、指标或方向，就可能得到不同的「关键组件」。归因研究因此必须报告方法学细节。

## 二、核心原理

关键区分是加噪（noising，从干净出发破坏）与去噪（denoising，从破坏出发恢复），二者回答的是不同反事实问题。

- 指标选择：用 logit 差比用概率或准确率更线性、更少饱和，便于横比。
- 破坏基线：随机噪声、均值替换、对照样本替换会给出不同热图，需与研究问题匹配并明示。

## 三、数学形式

去噪效应 $\mathrm{IE}^{den}=m\big(x_{corr};h\leftarrow h^{clean}\big)-m\big(x_{corr}\big)$，加噪效应 $\mathrm{IE}^{noi}=m\big(x_{clean}\big)-m\big(x_{clean};h\leftarrow h^{corr}\big)$。

常用指标 $m=\log p(y^\ast)-\log p(y^{alt})$，即目标与对照答案的 logit 差，避免 softmax 饱和带来的压缩。

## 四、代码实现

```python
def patch_effect(metric_fn, run_clean, run_corr, run_patched):
    ie_den = metric_fn(run_patched) - metric_fn(run_corr)
    ie_noi = metric_fn(run_clean) - metric_fn(run_patched)
    return round(ie_den, 4), round(ie_noi, 4)
print(patch_effect(lambda v: v, 3.0, -1.0, 2.0))
```

## 五、与其他对比

- 与自动电路发现（ACDC）对照：手工 patching 精细但费力，自动搜索覆盖广但依赖阈值设定。
- 与 定位是否指导编辑的争议 衔接：方法学差异是解释性结论不一致的重要来源。

## 六、常见误区

- 混用加噪与去噪结果做同一张热图，结论不可比。
- 用概率作为指标却在饱和区比较，导致重要组件被系统性低估。

## 八、面试题

- 加噪与去噪差异？答：前者问「移除它是否必要」，后者问「恢复它是否充分」，结论可不同。
- 为何推荐 logit 差指标？答：线性度好、避免概率饱和，跨样本可加性更强。

## 九、演进

单一 patching 实践 → 指标与基线敏感性研究 → 自动电路发现 → 报告规范与可复现清单。

## 十、小结

归因结论的可信度取决于方法学披露：污染方式、指标、方向三者缺一不可。
