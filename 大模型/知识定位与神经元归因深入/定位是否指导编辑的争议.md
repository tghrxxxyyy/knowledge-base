# 定位是否指导编辑的争议

> 对应 Hase et al., *Does Localization Inform Editing?*, NeurIPS 2023。

## 一、背景与挑战

流行叙事是「先定位再编辑」。但若在因果追踪认定的低效应层做编辑同样有效，则定位结论与编辑落点之间的因果链条就被削弱。

## 二、核心原理

该工作系统比较了因果追踪给出的层与实际编辑成功率的相关性，发现两者关联远弱于预期。

- 在多数层上做秩一编辑都能达到较高的目标改写成功率，编辑效果对层选择不敏感。
- 结论并非否定追踪的因果性，而是指出「存储位置」与「可有效写入位置」是两个不同概念。

## 三、数学形式

设追踪效应 $\mathrm{IE}(l)$ 与编辑成功率 $\mathrm{ES}(l)$，争议核心是相关系数 $\rho\big(\mathrm{IE},\mathrm{ES}\big)$ 是否显著大于 0。

实证显示 $\rho$ 接近弱相关，说明 $\arg\max_l \mathrm{IE}(l)$ 并不必然是最优编辑层。

## 四、代码实现

```python
import numpy as np
def corr_ie_es(ie, es):
    ie = np.asarray(ie, float); es = np.asarray(es, float)
    return round(float(np.corrcoef(ie, es)[0, 1]), 3)
print(corr_ie_es([0.9, 0.5, 0.1, 0.05], [0.92, 0.90, 0.88, 0.86]))
```

## 五、与其他对比

- 与 因果追踪与ROME 对照：追踪回答「信息在哪被使用」，编辑回答「在哪写入代价最低」。
- 与 归因方法的评估与陷阱 衔接：这是解释性结论需要独立验证的经典案例。

## 六、常见误区

- 把该结论读成「因果追踪无效」；追踪的因果度量本身有效，被质疑的是它对编辑落点的指导性。
- 用单一编辑方法的结果否定全部定位工作；不同编辑算子对层敏感性不同。

## 八、面试题

- 定位与编辑为何可以脱钩？答：分布式冗余表示下，多层都能承载足以改变输出的写入。
- 该争议的实践启示？答：编辑层选择应以编辑成功率与局部性实测为准，而非只看追踪热图。

## 九、演进

定位驱动编辑叙事 → 相关性实证质疑 → 区分存储与可写入 → 以实测指标驱动落点选择。

## 十、小结

定位与编辑是两个问题：前者关乎机制理解，后者关乎干预工程，不可直接互推。
