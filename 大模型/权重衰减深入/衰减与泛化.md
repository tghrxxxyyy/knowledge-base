# 权重衰减与泛化

> 对应 Zhang et al., *Three Mechanisms of Weight Decay... Fixing Adam*, 2018（分析衰减三机制）。

## 一、背景与挑战

权重衰减如何具体改善泛化，机制需厘清以正确调参。

## 二、核心原理

三机制：L2 正则偏好小解、与 LR 协同影响有效步长、影响解在损失景观中的位置（偏向平坦）。

## 三、数学形式

有效衰减强度 $\approx \lambda\cdot\eta$（每次乘性衰减的累积效应），故需与 LR 联动。

## 四、代码实现

```python
eff_wd = wd * lr   # 调参时锁定此积
```

## 五、与其他对比

- 与 平坦极小值深入 共享几何影响。
- 与 梯度噪声深入 协同决定收敛解。

## 六、常见误区

- 只调 wd 忽略与 LR 乘积。
- 以为衰减越大泛化越好，过大会欠拟合。

## 八、面试题

- 衰减与学习率关系？答：每次乘性衰减量为 λη，二者乘积决定有效强度，需联合调。

## 九、演进

单一正则 → 机制分析 → LR-衰减联动调度。

## 十、小结

权重衰减通过正则与几何双机制影响泛化，需与 LR 联动调优。
