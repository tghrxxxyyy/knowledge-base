# L2正则与权重衰减区别

> 对应 Loshchilov & Hutter, ICLR 2019（Fixing Weight Decay in Adam）。

## 一、背景与挑战

在 SGD 中 L2 惩罚等价于权重衰减，但在 Adam 中二者不同，误用损效果。

## 二、核心原理

SGD 下 $\eta\lambda\theta$ 项一致；Adam 因自适应缩放，把 L2 混进动量/二阶矩会使衰减被各参数学习率扭曲。

## 三、数学形式

Adam 中 L2：$m\leftarrow\beta_1 m+\nabla+\lambda\theta$ 被 $\hat v$ 缩放；解耦衰减直接 $w\leftarrow w-\eta\lambda w$。

## 四、代码实现

```python
# AdamW：衰减在参数上，不在梯度上
p.data.mul_(1 - lr*wd); p.grad = p.grad  # 无 L2 项
```

## 五、与其他对比

- 与 自适应学习率深入 的 AdamW 实现一致。
- 与 权重衰减实践 衔接。

## 六、常见误区

- 在 Adam 中加 weight_decay 参数却以为是 L2，效果有偏。
- 忽略不同层应不同衰减。

## 八、面试题

- 为何 Adam 中 L2≠权重衰减？答：自适应学习率缩放使混入梯度的 L2 项被扭曲，需解耦衰减。

## 九、演进

混用 → 区分 → AdamW 标准化。

## 十、小结

理解 L2 与衰减区别是正确用 Adam 的前提，AdamW 即解耦方案。
