# 解耦权重衰减

> 对应 Loshchilov & Hutter 2019 的解耦视角；以及分层衰减实践。

## 一、背景与挑战

不同层（如 embedding、head、LN）对衰减敏感度不同，需精细控制。

## 二、核心原理

对参数分组施加不同 weight_decay；normalize 与 bias 常设 0，主体权重设非零，提升稳定与泛化。

## 三、数学形式

分组衰减 $w^{(g)}\leftarrow w^{(g)}-\eta\lambda_g w^{(g)}$，$\lambda_g$ 按组定。

## 四、代码实现

```python
param_groups = [{'params': no_decay, 'weight_decay':0.0},
                {'params': decay, 'weight_decay':0.01}]
opt = AdamW(param_groups, lr=3e-4)
```

## 五、与其他对比

- 与 自适应学习率深入 的分组学习率协同。
- 与 权重衰减总览 衔接。

## 六、常见误区

- 对所有参数统一衰减致 LN/bias 失真。
- 衰减过大使 embedding 塌缩。

## 八、面试题

- 哪些参数不应衰减？答：归一化层缩放/偏置、bias、部分 embedding，避免无谓约束。

## 九、演进

统一衰减 → 分组 → 自适应分层。

## 十、小结

解耦+分组衰减充分发挥正则，是现代训练标配。
