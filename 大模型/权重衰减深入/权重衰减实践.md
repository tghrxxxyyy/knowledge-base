# 权重衰减实践

> 对应大模型预训练（如 BERT/GPT）的 AdamW 衰减设置经验。

## 一、背景与挑战

大模型对衰减系数敏感，设错伤收敛或泛化。

## 二、核心原理

常用 0.01~0.1 量级 AdamW 衰减；warmup 后配合余弦衰减；分组衰减；监控权重范数。

## 三、数学形式

权重范数演变 $\|w_t\|$ 应随训练缓降；异常增长提示衰减不足或 LR 过大。

## 四、代码实现

```python
opt = AdamW(params, lr=1e-3, weight_decay=0.01,
            betas=(0.9,0.95))
```

## 五、与其他对比

- 与 自适应学习率深入 共用调度。
- 与 二阶优化深入 不需衰减但可叠加。

## 六、常见误区

- 衰减固定不随 LR 调度调整致末段过正则。
- 忽略权重范数监控。

## 七、与开源书对应

## 八、面试题

- 大模型衰减怎么设？答：AdamW 0.01 左右，分组（LN/bias 为0），与 LR 调度联动。

## 九、演进

经验值 → 分组 → 自动搜索衰减。

## 十、小结

权重衰减实践需分组与调度协同，是现代训练稳定关键。
