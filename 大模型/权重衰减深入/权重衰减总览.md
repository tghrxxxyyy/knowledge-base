# 权重衰减总览

> 对应 Krogh & Hertz, *A Simple Weight Decay Can Improve Generalization*, NeurIPS 1991/1992；Loshchilov & Hutter, *AdamW*, ICLR 2019。

## 一、背景与挑战

过拟合是大模型训练核心问题，需正则约束参数规模以提升泛化。

## 二、核心原理

权重衰减在更新时对参数乘衰减因子（或加 L2 惩罚），抑制大权重、偏好简单解。

## 三、数学形式

L2 惩罚目标 $\mathcal L+\frac{\lambda}{2}\|\theta\|^2$；解偏好小范数参数。

## 四、代码实现

```python
for p in params:
    p.data.mul_(1 - lr * wd)   # 解耦衰减
```

## 五、与其他对比

- 与 自适应学习率深入（AdamW）紧密相关。
- 与 锐度感知深入 同影响解几何。

## 六、常见误区

- 以为 Adam 中 L2 等价于权重衰减（实际不等，需解耦）。
- 衰减过大致欠拟合。

## 八、面试题

- 权重衰减为何防过拟合？答：惩罚大权重，约束模型容量，偏好平坦/简单解，提升泛化。

## 九、演进

L2 → 解耦权重衰减(AdamW) → 分层衰减。

## 十、小结

权重衰减是最基础的正则，正确实现（解耦）对 Adam 尤关键。
