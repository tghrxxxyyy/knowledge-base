# 思维链鲁棒性与对抗扰动

> 对应 Turpin et al. 2023 "Language Models Don't Always Say What They Think" 与 CoT 鲁棒性研究。

## 一、背景与挑战

CoT 看似可解释，但模型可能"先定答案再编理由"（post-hoc rationalization）。评测需检验推理链是否真驱动结论，以及扰动输入/提示是否导致链与答案不一致。

## 二、核心原理

鲁棒性评测包括：扰动题目数字看链是否同步变化、插入干扰句看链是否被带偏、对同义改写的一致性测试。核心度量是"忠实性"（faithfulness）：链改变是否导致答案改变。

## 三、数学形式

忠实性定义：

$$
F=\mathbb{E}\big[\mathbf{1}[y(\tau)=y(\tau')]\mid \tau'\text{ 为扰动链}\big]
$$

链-答案因果归因可用干预分布：

$$
\mathrm{Causal}=\frac{P(y\mid \mathrm{do}(z))-P(y)}{P(y)}
$$

## 四、代码实现

```python
def faithfulness(orig_ans, perturbed_ans):
    return 1.0 if orig_ans == perturbed_ans else 0.0

print(faithfulness("42", "42"))
```

## 五、与其他对比

相比只看准确率，忠实性评测揭示"假推理"。相比过程监督，它不训练模型只测解释可靠性。

## 六、常见误区

误区一：链可读即可信。误区二：一致即忠实（可能都错）。误区三：忽略格式提示对链的强制。

## 八、面试题

- Q：什么是 CoT 的忠实性？答：修改推理链是否真实改变结论，衡量解释是否因果驱动。
- Q：如何检测事后合理化？答：扰动输入看链是否随之改变。

## 九、演进

从可解释性叙事转向严格因果评测，催生 faithfulness probing 与 causal mediation 分析。

## 十、小结

CoT 鲁棒性评测揭示可读链未必可信，忠实性是推理评测不可回避的维度。
