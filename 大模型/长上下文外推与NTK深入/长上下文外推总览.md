# 长上下文外推总览

> 对应 Press 2022 ALiBi; Chen 2023 *Extending Context Window of Large Language Models via Positional Interpolation*; bloc97 NTK-aware。

## 一、背景与挑战
LLM 通常在固定上下文长度（如 4k）训练，但应用需要更长（32k、128k）。如何在不重新训练的情况下扩展上下文窗口？

## 二、核心原理
三大类方法：
1. 位置插值（PI）：把位置 $m$ 缩放为 $m/s$，在 $L_\text{target} = s \cdot L_\text{train}$ 内插值。
2. NTK-aware：调整 RoPE 频率 $\theta_i$，保持高频不变。
3. 注意力温度调整（YaRN）：缩放位置同时调节 softmax 温度。

## 三、形式化与数学基础
PI：$m \to m/s$ 等价于把 RoPE 的 $\cos(m\theta)$ 替换为 $\cos(m\theta/s)$。NTK：$\theta_i \to \theta_i \cdot s^{d/(d-2)}$（近似）。

## 四、代码实现
```python
# PI
def scale_position(m, s): return m / s
# NTK-aware
base = 10000 * (s ** (d/(d-2)))
inv_freq = 1.0 / (base ** (torch.arange(0,d,2).float()/d))
```

## 五、与其他技术对比
- PI：均匀缩放所有频率，简单但高频受压。
- NTK：保持高频，低频外推。
- YaRN：缩放+温度，工业级。

## 六、常见误区
- 直接把 $s$ 设很大但未做微调会致精度崩溃。
- 不同模型架构需不同策略。

## 八、面试题
- PI 与 NTK 区别？答：PI 缩位置，NTK 缩频率。

## 九、演进与趋势
训练短测试长 → PI → NTK → YaRN → 持续预训练（Code Llama、Llama-2-32k）。

## 十、小结
长上下文外推是 LLM 部署的关键能力，PI、NTK、YaRN 是主流方案。
