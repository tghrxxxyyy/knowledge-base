# 持续预训练长上下文

> 对应 Rozière et al., 2023 *Code Llama: Open Foundation Models for Code*; Xiong et al., 2023 *Effective Long-Context Scaling of Foundation Models*。

## 一、背景与挑战
仅靠推理侧缩放（PI/NTK/YaRN）通常只能扩到 2-4 倍训练长度。要扩到 8-32 倍需持续预训练。

## 二、核心原理
步骤：
1. 把训练长度从 $L_\text{train}$ 提升到 $L_\text{target}$。
2. 用 RoPE 缩放（NTK 或 YaRN）初始化新位置编码。
3. 在新长度上继续预训练（千亿 token）。
4. 渐进式扩展（先 8k，再 32k，再 128k）。

## 三、形式化与数学基础
学习率调度：通常降低 10-50%，避免灾难性遗忘。数据混合：原预训练数据 + 部分新长度数据。

## 四、代码实现
```python
# 渐进式训练
for stage, L in enumerate([8192, 32768, 131072]):
    config.max_seq = L
    model = resize_rope(model, L)  # NTK/YaRN 缩放
    train(model, data, L)
```

## 五、与其他技术对比
- vs 推理侧外推：持续预训练效果更好但需计算。
- vs 从头训练：持续预训练保留原能力。

## 六、常见误区
- 学习率过高会灾难性遗忘。
- 数据分布与原训练差异大时需更多微调。

## 七、与开源书/权威来源对应

- togethercomputer/RedPajama 长上下文。

## 八、面试题
- 为何需要持续预训练？答：推理侧外推有限，需真实长序列梯度信号。

## 九、演进与趋势
推理侧 → 持续预训练 → 课程学习（逐步扩长）。

## 十、小结
持续预训练是长上下文扩展的工业级方法，效果优于纯推理侧方案。
