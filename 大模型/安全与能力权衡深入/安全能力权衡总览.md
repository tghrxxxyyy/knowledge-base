# 安全与能力权衡总览

> 对应 Bai et al., *Training a Helpful and Harmless Assistant*, 2022；Ouyang et al., 2022。

## 一、背景与挑战

强化安全常伴随通用能力或有用性下降，即所谓对齐税，需要量化并最小化。

## 二、核心原理

安全微调（拒绝有害请求、谨慎措辞）改变分布，可能伤及正常任务表现；权衡靠数据配比与强度控制。

## 三、数学形式

两目标：$U(\pi)$ 有用性、$S(\pi)$ 安全性；前沿上 $\frac{\partial U}{\partial S}$ 给出能力代价斜率。

## 四、代码实现

```python
loss = ce_useful + lam * safety_loss
```

## 五、与其他对比

- 与多目标偏好聚合深入共享双目标权衡框架。
- 与价值观冲突消解共享安全维度定义。

## 六、常见误区

- 把评测下降全归为对齐税，忽略数据/超参问题。
- 安全与能力零和假设，忽视大模型容量冗余。
