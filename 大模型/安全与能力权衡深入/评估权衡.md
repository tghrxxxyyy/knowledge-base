# 安全能力权衡评估

> 对应 Li et al., *DecodingTrust*, 2023；Sourabh et al., *Safety Bench*。

## 一、背景与挑战

单看安全或能力都会误判，需联合评测与帕累托呈现。

## 二、核心原理

在有害请求集测安全率、在有用性基准测能力，画二维散点；报告二者同时达标的比例。

## 三、数学形式

联合得分 $J = \alpha\cdot SafeRate + (1-\alpha)\cdot UsefulRate$，扫 $\alpha$ 看稳健区。

## 四、代码实现

```python
for a in linspace(0, 1, 10):
    report(a, safe, useful)
```

## 五、与其他对比

- 与多目标偏好聚合深入共享帕累托呈现。
- 与安全与能力权衡总览共享指标。

## 六、常见误区

- 安全基准只测攻击忽略过度拒绝。
- 能力基准不含安全相关任务。
