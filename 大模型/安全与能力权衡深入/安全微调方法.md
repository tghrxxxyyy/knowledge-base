# 安全微调方法对比

> 对应 Qi et al., *Fine-tuning Aligned LLMs Compromises Safety*, 2023；Bianchi et al., *Safety-Tuned LLaMAs*, 2023。

## 一、背景与挑战

不同安全微调法对能力税影响不同，需选型。

## 二、核心原理

对比 RLHF、DPO 安全偏好、安全 SFT、红队拒绝数据；混合安全/有用数据减税。

## 三、数学形式

安全 DPO 损失同标准 DPO，仅偏好对替换为安全胜负对（拒绝 vs 顺从）。

## 四、代码实现

```python
loss = dpo_loss(beta, pi, ref, safe_prefs)
```

## 五、与其他对比

- 与直接偏好优化深入共享 DPO 机制。
- 与多目标偏好聚合深入：安全可作一个目标维度。

## 六、常见误区

- 只做安全 SFT 忽略偏好细粒度。
- 红队数据分布窄致泛化差。

## 七、与开源书对应

- datawhalechina/llm-universe：https://github.com/datawhalechina/llm-universe

## 八、面试题

- 安全 DPO 与 RLHF 差异？答：安全 DPO 用拒绝/顺从偏好对，无显式 RM，更简单稳。

## 九、演进

RLHF → 安全 DPO → 混合安全 SFT。

## 十、小结

安全微调法各有税，混合数据最稳。
