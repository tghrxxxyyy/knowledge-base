# 拒绝行为与有用性张力

> 对应 Bai et al., 2022；Inan et al., *Llama Guard*, 2023。

## 一、背景与挑战

过度拒绝使正常请求失败，欠拒绝放有害物质；二者张力需平衡。

## 二、核心原理

用安全分类器分请求风险，仅高风险拒绝；对灰区做安全改写而非硬拒，保有用性。

## 三、数学形式

期望效用 $\mathbb E[\mathbb 1_{safe}\cdot U - c\cdot \mathbb 1_{over-refuse}]$；最小化误拒率同时控漏放。

## 四、代码实现

```python
if guard(x) == "safe":
    y = model(x)
else:
    y = safe_refusal(x)
```

## 五、与其他对比

- 与指令层级与越权防御深入共享拒绝控制。
- 与价值观冲突消解共享灰区处理。

## 六、常见误区

- 用拒答率代理安全率，忽视过度拒绝。
- 灰区一刀切硬拒损体验。
