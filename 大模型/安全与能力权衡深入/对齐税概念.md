# 对齐税概念

> 对应 Bai et al., 2022；Askell et al., *A General Language Assistant*, 2021（HHH）。

## 一、背景与挑战

RLHF 后模型在基准上常小幅掉点，被称对齐税，需区分真实退化与评测偏差。

## 二、核心原理

税来自分布偏移与过度拒绝；用同分布 SFT 对照、控制 KL 可减税、用安全无关任务测纯能力。

## 三、数学形式

税 $\tau = score(\pi_{sft})-score(\pi_{rlhf})$；若 $\tau>0$ 且不来自评测噪声即真退化。

## 四、代码实现

```python
tax = eval(sft) - eval(rlhf)
```

## 五、与其他对比

- 与安全能力权衡总览共享度量。
- 与微调灾难性遗忘安全共享能力保留。

## 六、常见误区

- 评测集污染致税被高估。
- 用单一基准衡量全部能力。

## 八、面试题

- 如何判断税是真退化？答：同分布对照+安全无关任务，排除评测噪声与分布偏移。

## 九、演进

现象描述 → 对照归因 → 容量减税。

## 十、小结

对齐税需严谨归因，避免误判真实能力损失。
