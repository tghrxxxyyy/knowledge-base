# 反思与自我纠正

> 对应 Shinn et al., *Reflexion*, 2023；Yao et al., *ReAct*, 2022。

## 一、背景与挑战

重试只能缓解随机故障，无法修正“计划本身错了”这类系统性问题。需要让智能体从失败中总结经验。

## 二、核心原理

Reflexion 在 episodes 结束后，用语言模型生成自然语言“反思”（reflection），写入记忆，下一轮据此调整策略。这相当于用文本梯度下降替代数值梯度，使纠正可解释、可累积。

## 三、数学形式

用语言反馈近似策略梯度方向：

$$\theta_{t+1} = \theta_t + \eta \cdot \text{Refine}\big(\theta_t,\, \text{Reflect}(\text{trajectory}_t)\big)$$

其中 $\text{Reflect}$ 产出文本改进建议。

## 四、代码实现

```python
reflection = llm(f"上次失败原因与改进:\n{trace}")
memory.append(reflection)
plan = llm(f"基于反思重做:\n{memory}")
```

## 五、与其他对比

- 比纯重试更擅长系统性错误，但增加一次 LLM 推理成本。
- 与 智能体轨迹自我进化深入 共享经验累积思想。

## 六、常见误区

- 反思空洞（“下次注意”）无信息量，需具体可执行。
- 反思无限累积致上下文溢出，需压缩。

## 八、面试题

- Reflexion 为什么用文本而非数值梯度？答：文本反思可解释且能跨任务迁移，近似策略改进方向。

## 九、演进

重试 → 单轮反思 → 反思记忆累积的长期进化。

## 十、小结

反思把失败转化为可复用经验，是错误恢复从“重试”走向“智能纠正”的关键。
