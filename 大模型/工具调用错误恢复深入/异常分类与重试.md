# 异常分类与重试

> 对应 Ruan et al., *ToolEmu*, 2023；Schick et al., *Toolformer*, 2023。

## 一、背景与挑战

并非所有异常都该重试。把“瞬时网络抖动”和“参数永远非法”混为一谈，会导致无限重试或过早放弃。需要先分类再决策。

## 二、核心原理

将异常分为：瞬时型（超时/限流/5xx）、输入型（参数校验失败）、语义型（工具返回但结果无效）、灾难型（权限/越权）。前两类可重试，后两类需反思或降级。重试配合指数退避与抖动（jitter）避免惊群。

## 三、数学形式

指数退避等待时间：

$$t_i=\min(t_{max},\,t_{base}\cdot 2^{i})\cdot(1+\epsilon)$$

其中 $\epsilon$ 为随机抖动，防止多智能体同步重试。

## 四、代码实现

```python
import random, time
def backoff(i, base=1.0, cap=30.0):
    return min(cap, base * (2 ** i)) * (1 + random.random() * 0.3)
```

## 五、与其他对比

- 与 智能体安全与权限沙箱深入 配合，灾难型错误直接转人工而非重试。
- 与 Reflexion 的反思机制互补。

## 六、常见误区

- 把 4xx 当瞬时错误重试，必然失败。
- 退避无上限，长任务被拖死。

## 八、面试题

- 如何区分可重试与不可重试异常？答：看故障是否随重试概率下降，输入/权限类不可重试。

## 九、演进

统一重试 → 分类重试 → 带退避与抖动的自适应重试。

## 十、小结

异常分类是重试有效性的前提，退避与抖动防止故障放大。
