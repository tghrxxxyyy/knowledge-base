# 忠实性幻觉与上下文冲突

> 见「幻觉与缓解深入/大模型幻觉概述」。

## 一、背景与挑战

即使提供正确上下文，模型仍可能忽略或曲解输入，生成与上下文矛盾的内容。

## 二、核心原理

原因包括：上下文过长导致注意力稀释、指令与上下文冲突时模型偏向先验、复制-生成权衡失衡（过度依赖参数化知识）。

## 三、数学形式

可用上下文利用率衡量：

```
CtxUtil = |GenTokens aligned with Ctx| / |GenTokens|
```

## 四、代码实现

```python
# 简单检查生成是否引用了给定上下文片段
def cites_context(gen, ctx_spans):
    return any(span in gen for span in ctx_spans)
```

## 五、关键要点

- 长上下文下「lost in the middle」现象显著。
- 强指令模型更易忠实，但也可能过度拒绝。

## 六、与其他对比

- 事实性幻觉靠外部知识补；忠实性幻觉靠更好的上下文利用与对齐。

## 七、常见误区

- 认为「给够上下文就不会错」——注意力机制并不保证完全利用。

## 十、演进
