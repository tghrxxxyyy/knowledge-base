# 对齐阶段降低编造

> 见「微调与对齐/RLHF概述」与「DPO原理与实现」。

## 一、背景与挑战

仅靠 RAG 不够，还需在对齐阶段让模型学会「知之为知之，不知为不知」。

## 二、核心原理

在 SFT/RLHF/DPO 中引入「拒绝回答」「引用证据」「承认不确定」的偏好数据，使模型在知识边界外倾向保守而非编造。

## 三、关键要点

- 奖励模型需对「编造但流畅」打低分。
- DPO 可直接用偏好对（诚实 vs 编造）训练。

## 四、代码实现

```python
# 构造偏好对：chosen=承认不知，rejected=编造
pref = {"prompt": q, "chosen": honest, "rejected": hallucinated}
```

## 五、与其他对比

- 对齐降低编造倾向；RAG 提供事实依据；二者互补。

## 六、常见误区

- 过度对齐致「拒答」增多，需平衡有帮助与诚实。
