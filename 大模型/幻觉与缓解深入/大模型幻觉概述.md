# 大模型幻觉概述

> 对应 llm-course「Hallucinations」与 d2l-zh 可靠性讨论；综述见 Ji et al., *Survey of Hallucination in NLP*, 2023。

## 一、背景与挑战

大模型在生成流畅文本时，可能输出与事实不符、与上下文矛盾、或无依据的内容，称为「幻觉」。它破坏可信度，是落地高风险场景（医疗、法律、金融）的主要障碍。

## 二、核心原理

幻觉分两类：**事实性幻觉**（与真实世界知识冲突）与**忠实性幻觉**（与给定上下文冲突）。根因包括：训练数据噪声、暴露偏差（训练目标鼓励续写而非查证）、解码随机性、知识边界模糊。

## 三、数学形式

可用忠实度分数衡量：给定生成 y 与证据 e，定义

```
Faithfulness(y, e) = 1 - |Claims(y) \ Supported(e)| / |Claims(y)|
```

## 四、代码实现

```python
def faithfulness(gen_claims, evi_supported):
    unsupp = [c for c in gen_claims if c not in evi_supported]
    return 1 - len(unsupp) / max(1, len(gen_claims))
```

## 五、关键要点

- 幻觉 ≠ 错误：错误可能源于知识缺失，幻觉强调「无依据地编造」。
- 参数化知识（存在权重中） vs 上下文知识（来自 RAG）。

## 六、与其他对比

- 小模型幻觉少但能力弱；大模型能力强但易过度生成。
- RAG 缓解事实性幻觉，但不解决忠实性幻觉。

## 七、常见误区

- 「模型知道答案只是表达不清」——多数幻觉是模型在知识边界外强行生成。
- 温度=0 仍会幻觉（贪婪解码也选错 token）。

## 十、演进

从「后处理检测」→「RAG 注入知识」→「对齐阶段降低编造倾向（RLHF/DPO 引入事实性奖励）」→「推理时自我校验（Self-Consistency / Self-Reflection）」。

## 十一、小结

幻觉是大模型可信落地的核心难题，需数据、检索、对齐、推理多管齐下。
