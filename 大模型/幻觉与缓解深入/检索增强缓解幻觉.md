# 检索增强缓解幻觉

> 见「RAG深入/总体架构」与「幻觉与缓解深入/大模型幻觉概述」。

## 一、背景与挑战

将外部知识注入生成过程，减少参数化记忆的编造。

## 二、核心原理

RAG 在生成前检索相关文档，将证据拼入上下文，使模型「有据可依」。对事实性幻觉缓解显著，尤其长尾与时效知识。

## 三、数学形式

生成概率分解为：

```
P(y|x) = Σ_{c∈R(x)} P(c|x) · P(y|x,c)
```

其中 R(x) 为检索到的上下文集合。

## 四、代码实现

```python
def rag_generate(query, retriever, llm):
    ctx = retriever.search(query, k=5)
    prompt = f"依据:\n{ctx}\n\n问题:{query}"
    return llm(prompt)
```

## 五、关键要点

- 检索质量决定上限，生成利用决定下限。
- 需引用归因以防「检索了但没用」。

## 六、与其他对比

- 持续预训练更新知识但贵；RAG 即插即用、可溯源。

## 七、常见误区

- 检索到就一定能答对——模型可能忽略或曲解证据。

## 十、演进

Naive RAG → 重排/混合检索 → Self-RAG（自适应检索）→ 图谱 RAG。

## 十一、小结

RAG 是工业界缓解事实性幻觉的主流手段，但非银弹。
