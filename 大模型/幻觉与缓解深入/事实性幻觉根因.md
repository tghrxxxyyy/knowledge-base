# 事实性幻觉根因

> 见「幻觉与缓解深入/大模型幻觉概述」。

## 一、背景与挑战

理解事实性幻觉来源是设计缓解方案的前提。

## 二、核心原理

四大根因：**(1) 数据层**：训练语料含错误/过时/偏见信息；**(2) 训练层**：next-token 目标不强制事实一致性；**(3) 推理层**：解码在知识边界外自由采样；**(4) 知识时效层**：模型权重固化，无法感知训练后事件。

## 三、关键要点

- 暴露偏差：训练时见过「问题-答案」对，推理时倾向编造流畅但错误答案。
- 长尾知识稀疏，模型对该类实体记忆弱。

## 四、代码实现

```python
# 检测生成中是否含训练截止后可证伪的实体
def check_recency(entity_date, cutoff="2023-10"):
    return entity_date > cutoff  # 超截止，需外部检索核实
```

## 五、与其他对比

| 根因 | 典型缓解 |
|------|----------|
| 数据噪声 | 数据清洗、去重 |
| 知识时效 | RAG、持续预训练 |
| 解码编造 | 降低温度、self-consistency |
