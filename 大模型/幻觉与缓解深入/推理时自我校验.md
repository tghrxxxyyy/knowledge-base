# 推理时自我校验

> 见「提示工程深入/自洽性Self_Consistency」与「思维树ToT」。

## 一、背景与挑战

不改动模型权重，在推理阶段通过多采样与自我批评降低幻觉。

## 二、核心原理

**Self-Consistency**：对同问题采样多条推理链，多数投票降低随机编造。**Self-Reflection**：生成后让模型自我审查事实一致性，必要时检索核实。

## 三、数学形式

```
y* = argmax_y Σ_{i=1}^k 1[y_i = y]
```

## 四、代码实现

```python
import collections
ans = collections.Counter([generate(q) for _ in range(5)]).most_common(1)[0][0]
```

## 五、关键要点

- 自洽性对数学/事实题有效，对开放生成有限。
- 自我审查依赖模型自身判别力，可能「盲审」。

## 六、与其他对比

- 训练时缓解治本；推理时缓解即插即用、零成本改动。

## 七、常见误区

- 自我校验 100% 可靠——模型可能坚持错误。
