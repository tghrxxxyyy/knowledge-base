# 函数调用结构化

> 对应 Tool/Function Calling（OpenAI/Anthropic）；与 结构化输出深入 衔接。

## 一、背景与挑战

Agent 需调用外部 API，须输出合法函数名与参数，错误即执行失败。

## 二、核心原理

定义函数 schema（名、参数类型），模型在专用 token 间生成结构化调用；解码约束参数 JSON 合法。

## 三、数学形式

调用 $c=(f, \{p_i:v_i\})$，$f\in\mathcal F$；参数满足 $\text{schema}(f)$。

## 四、代码实现

```python
tools = [{"type":"function","function":{ "name":"search",
        "parameters": {"type":"object","properties":{"q":{"type":"string"}}}}}
resp = client.chat.completions.create(model="gpt-4o", tools=tools, ...)
```

## 五、与其他对比

- 与 JSON模式深入 共享 schema 约束。
- 与 约束解码深入 同机制。

## 六、常见误区

- 参数类型声明错致解析失败。
- 未处理模型“不调用”分支。

## 八、面试题

- 函数调用为何需 schema？答：约束生成合法函数名与参数类型，供执行器安全调用。

## 九、演进

文本约定 → 专用 token → 并行多调用。

## 十、小结

函数调用以 schema 约束实现可靠工具使用，是 Agent 核心。
