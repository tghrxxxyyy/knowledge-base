# 结构化输出实践

> 对应生产落地；与 推理成本深入 衔接。

## 一、背景与挑战

大规模结构化输出需兼顾正确率与吞吐。

## 二、核心原理

优先用原生 JSON mode/工具调用；复杂用引导库；批处理+校验+失败重试，监控字段缺失率。

## 三、数学形式

成本 $C = n\cdot(c_{gen}+c_{validate}) + c_{retry}\cdot\Pr(fail)\cdot n$。

## 四、代码实现

```python
batch = [build_req(p) for p in prompts]
outs = client.batch_completions(batch, response_format="json_object")
```

## 五、与其他对比

- 与 格式化输出实践深入 协同。
- 与 动态计算深入 同为推理优化。

## 六、常见误区

- 大 schema 一次塞满易失败。
- 忽视流式 JSON 解析。

## 八、面试题

- 大规模结构化如何降本？答：原生模式+批处理+校验重试，监控缺失率。

## 九、演进

单条 → 批量 → 流式校验。

## 十、小结
