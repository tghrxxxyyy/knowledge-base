# 模式引导生成（Schema-Guided）

> 对应 Guidance / Outlines 模式引导；与 约束解码深入 衔接。

## 一、背景与挑战

除 JSON 外还需模板中穿插自然语言，纯 JSON mode 不够灵活。

## 二、核心原理

用 DSL 描述“文本{{gen}}与结构{{select}}”混合模板，运行时按模板逐步约束生成，兼顾自然与结构。

## 三、数学形式

模板 $T=\text{seq of (text | gen|schema)}$；每段约束对应子空间 $Y_i$。

## 四、代码实现

```python
import guidance
prog = guidance("分析: {{gen 'analysis'}}\n标签: {{select options}}")
out = prog(model=lm)
```

## 五、与其他对比

- 与 JSON模式深入 比更灵活混排。
- 与 格式化输出深入 共享模板思想。

## 六、常见误区

- 模板与模型能力错配。
- 嵌套生成难调试。

## 七、与开源书对应

- mlabonne/llm-course：https://github.com/mlabonne/llm-course
- rasbt/LLMs-from-scratch：https://github.com/rasbt/LLMs-from-scratch

## 八、面试题

- 模式引导相对 JSON mode 优势？答：模板可混自然语言与结构，表达更丰富。

## 九、演进

纯 JSON → 模板 DSL → 程序化生成。

## 十、小结

模式引导以模板混合自然与结构，适合复合输出。
