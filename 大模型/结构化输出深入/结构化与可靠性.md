# 结构化输出与可靠性

> 对应可解析性与校验；与 模型安全与对齐 衔接。

## 一、背景与挑战

即使约束生成，语义仍可能错（字段对但值错），需校验闭环。

## 二、核心原理

生成后做 schema 校验+语义校验（范围/枚举/引用），失败则重试或修正；必要时人工回路。

## 三、数学形式

可靠性 $R=1-\Pr(\text{invalid}(y))$；retry 提升 $R$ 但增成本。

## 四、代码实现

```python
for _ in range(3):
    y = gen(); 
    if validate(y): break
```

## 五、与其他对比

- 与 格式化输出评估深入 共享验证。
- 与 约束解码深入 互补（生成+校验）。

## 六、常见误区

- 以为约束即正确，忽略语义校验。
- 无限重试致延迟。

## 八、面试题

- 为何结构化仍需校验？答：约束保语法合法，语义值仍可能错，需 schema+语义校验。

## 九、演进

无校验 → 语法校验 → 语义+重试。

## 十、小结

结构化输出须配校验闭环，方达工程可靠。
