# S4与对角结构化状态空间

> 对应 Gu 2021 *Efficiently Modeling Long Sequences with Structured State Spaces*。

## 一、背景与挑战
通用状态空间 $A \in \mathbb{R}^{N \times N}$ 参数过大、计算 $O(N^2 L)$，不可用。S4 用对角 + 低秩（HiPPO）初始化，复杂度降至 $O(N L \log L)$。

## 二、核心原理
S4 把 $A$ 限制为对角 + 低秩（Diagonal Plus Low-Rank, DPLR），利用 Cauchy 核的对角化在频域 $O(N \log L)$ 计算卷积。HiPPO 结构给出对长程依赖良好的初始化。

## 三、形式化与数学基础
$ A = \Lambda + P Q^\top $，$\Lambda$ 对角，$P, Q$ 低秩。卷积核 $K(t) = C e^{tA} B$ 可用 Woodbury 恒等式与 Cauchy 核高效计算。

## 四、代码实现
```python
# S4 对角化
A_diag = torch.complex(Lambda_real, Lambda_imag)  # 复数对角
# 频域卷积: K 与 x 的 FFT
K = (C * (B[...,None] * exp(A_diag * t))).sum(...)
y = fft_conv(K, x)
```

## 五、与其他技术对比
- vs 通用 SSM：S4 复杂度大幅降低。
- vs Transformer：S4 长程依赖建模强。

## 六、常见误区
- 对角化在复数域，需小心数值稳定。
- HiPPO 初始化对性能至关重要。
