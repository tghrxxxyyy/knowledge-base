# 长上下文总览

> 对应 Beltagy et al., *Longformer*, 2020；Dao et al., *FlashAttention*, 2022。

## 一、背景与挑战

标准 Transformer 注意力 $O(n^2)$ 随序列长度爆炸，限制文档/多轮/多模态处理。

## 二、核心原理

从位置编码（RoPE/ALiBi）、注意力稀疏化（窗口/线性）、高效实现（FlashAttention）、到长度外推与检索四路突破。

## 三、数学形式

全注意力复杂度 $O(n^2d)$；线性注意力约 $O(nd^2)$；推理 KV 缓存随 $n$ 线性增长。

## 四、代码实现

```python
from flash_attn import flash_attention_qkv
out = flash_attention_qkv(q, k, v)
```

## 五、与其他对比

- 与 智能体记忆 / 检索类工具 共享"长信息"处理。
- 与 推理时计算（长思维）衔接。

## 六、常见误区

- 误以为加大上限即会用好（需训练分布匹配）。
- 忽视 KV 缓存显存随长度线性。

## 七、与开源书对应

## 八、面试题

- 长上下文主要瓶颈？答：注意力 $O(n^2)$ 算力与 KV 缓存显存，二者随长度快速增长。

## 九、演进

全注意力→稀疏→高效内核→长度外推。

## 十、小结

长上下文是多文档与 agent 的基础，算法+系统协同突破。
