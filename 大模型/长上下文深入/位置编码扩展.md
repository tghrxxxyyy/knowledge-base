# 位置编码与长度外推

> 对应 Su et al., *RoPE*, 2021；Press et al., *ALiBi*, 2021；NTK-aware 缩放。

## 一、背景与挑战

训练长度有限，推理超长时位置编码失效致混乱。

## 二、核心原理

RoPE 把位置编码为旋转，外推可借 NTK/PI 缩放基频；ALiBi 用距离偏置无需学位置，天然外推。

## 三、数学形式

RoPE：$q'=R_{\Theta,m}q,\ k'=R_{\Theta,n}k$，注意力含旋转角度差；NTK 缩放基 $b'=b^\frac{d}{d-2}$。

## 四、代码实现

```python
def rope(x, pos):
    return x * cos(pos) + rotate_half(x) * sin(pos)
```

## 六、常见误区

- 直接外推不缩放致位置混淆。
- 忽视训推长度差引发的分布偏移。

## 八、面试题

- NTK 缩放为何有用？答：在频率维度非均匀扩展，保留高频细节同时容纳更长位置。

绝对→相对→RoPE→NTK/PI 外推。

## 十、小结

位置编码决定外推能力，旋转/偏置类更易超长泛化。
