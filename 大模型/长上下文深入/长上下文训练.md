# 长上下文训练策略

> 对应长度课程/打包训练；序列并行。

## 一、背景与挑战

直接训超长序列算力不可承受；需渐进与并行。

## 二、核心原理

长度课程：先短后长渐进增大；数据打包（packing）去 pad；序列并行切分长序列跨设备；配合 RoPE 外推。

## 三、数学形式

训练步复杂度随 $L$ 增；课程用 $L_t$ 递增，使前期低成本覆盖多样本。

## 四、代码实现

```python
seqs = pack(samples, max_len=L)
loss = model(seqs).loss
```

## 五、与其他对比

- 与 注意力优化（系统）配合。
- 与 训练数据质量 共享。

## 六、常见误区

- 跳课程直接超长致不稳、贵。
- 忽视位置分布与推理匹配。

## 七、与开源书对应

- harvardnlp/annotated-transformer：https://github.com/harvardnlp/annotated-transformer
- rasbt/LLMs-from-scratch：https://github.com/rasbt/LLMs-from-scratch

## 八、面试题

- 长度课程为何稳？答：先短序列低成本学基础，再渐进拉长，分布平滑易收敛。

## 九、演进

固定长→课程→序列并行+打包。

## 十、小结

长上下文训练靠课程与并行，匹配推理分布是核心。
