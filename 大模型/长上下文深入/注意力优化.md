# 注意力机制优化

> 对应 Dao et al., FlashAttention-2, 2023；窗口/线性注意力。

## 一、背景与挑战

注意力既吃算力又吃显存带宽，长序列下成主要瓶颈。

## 二、核心原理

FlashAttention 用分块+重算把注意力变 IO 感知，省 HBM 且不存大 $n\times n$ 矩阵；稀疏注意力限制每 token 关注局部+全局。

## 三、数学形式

标准需存 $S\in\mathbb R^{n\times n}$；FlashAttention 分块算 softmax 不物化 $S$，显存 $O(n)$。

## 四、代码实现

```python
out = flash_attn_func(q, k, v, causal=True)
```

## 六、常见误区

- 误以为只是提速，实则降显存才放长。
- 稀疏模式不当损全局依赖。
