# 流水线气泡分析

> 对应 Narayanan et al., 《Memory-Efficient Pipeline-Parallel DNN Training》, 2021。

## 一、背景与挑战

气泡（设备空闲）直接拉低吞吐，需量化并最小化。

## 二、核心原理

气泡来自流水填充与排空段；理论最优气泡比随阶段数 $d$ 增、随微批 $m$ 减；调度（1F1B/交错）与微批数决定实际值。

## 三、数学形式

理想加速 $S\approx \frac{d\cdot m}{m+d-1}$；气泡占比 $1-S/d\approx \frac{d-1}{m+d-1}$。

## 四、代码实现

```python
bubble = (d - 1) / (micro_batches + d - 1)
throughput = d / (1 + bubble)
```

## 五、与其他对比

- 与 数据并行深入（无气泡但通信大）权衡。
- 与 通信压缩深入 不同目标（此处降空转）。

## 六、常见误区

- 只加阶段数不增微批，气泡反升。
- 用理论最优忽略重计算开销。

## 八、面试题

- 如何减小流水线气泡？答：增微批数、用 1F1B/交错调度、均衡阶段负载。

## 九、演进

理论分析 → 调度优化 → 自动微批搜索。

## 十、小结

气泡由填充排空产生，靠微批数与调度压缩，是流水吞吐核心。
