# 流水线并行总览

> 对应 Huang et al., 《GPipe: Efficient Training of Giant Neural Networks using Pipeline Parallelism》, 2018。

## 一、背景与挑战

把模型按层切到多卡（模型并行），但朴素串行执行设备利用率低，需流水重叠。

## 二、核心原理

把输入切成若干微批次（micro-batch）沿层流水；各卡在不同微批次上工作，提升设备占用；通信只传相邻层激活。

## 三、数学形式

单卡持层 $L_i$；前向 $a_{i+1}=L_i(a_i)$；微批次数 $m$ 决定流水深度；总 step 时间受最慢阶段约束。

## 四、代码实现

```python
for mb in split(batch, micro_batches):
    a = pipeline_stage[rank](mb)      # 仅本层
    a = send_recv(a, rank+1)          # 传相邻卡
```

## 五、与其他对比

- 与 张量并行深入（层内切）互补，构成 3D 并行。
- 与 数据并行深入 在阶段间可叠加。

## 六、常见误区

- 微批次过少导致气泡大、设备空转。
- 阶段负载不均致长尾。

## 八、面试题

- 流水线并行为何要微批次？答：用微批次流水重叠各层计算，降低设备空闲气泡。

## 九、演进

朴素层并行 → GPipe 微批 → 1F1B 调度。

## 十、小结

流水线并行按层切分并用微批次流水，缓解设备空闲、扩层间并行。
