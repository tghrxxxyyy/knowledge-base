# 流水线调度算法对比

> 对应 Narayanan et al., 《Efficient Large-Scale Language Model Training on GPU Clusters Using Megatron-LM》, 2022（交错调度）。

## 一、背景与挑战

不同调度在气泡、显存、实现复杂度间权衡。

## 二、核心原理

GPipe（全前向后全反向）简单；1F1B 降气泡；交错 1F1B 把每层再切成多虚拟阶段交替，进一步降气泡但增通信。

## 三、数学形式

交错后等效阶段数升为 $d\cdot k$，气泡比 $\frac{dk-1}{m+dk-1}$ 更小（需 $m$ 足够）。

## 四、代码实现

```python
# 交错：每张卡持多不相邻层块
for virtual in virtual_stages(rank):
    run_1f1b(virtual, micro_batches)
```

## 五、与其他对比

- 与 混合并行深入 中 3D 调度组合。
- 气泡更小的代价是更多阶段间通信。

## 六、常见误区

- 交错未配足够微批反致更差。
- 忽视虚拟阶段通信开销。

## 八、面试题

- 交错 1F1B 优缺？答：气泡更小，但虚拟阶段增通信、实现更复杂。

## 九、演进

GPipe → 1F1B → 交错 1F1B。

## 十、小结

调度从 GPipe 到交错逐步降气泡，按通信预算选型。
