# 流水线并行与激活检查点

> 对应 Chen et al., 《Training Deep Nets with Sublinear Memory》, 2016（重计算）；Narayanan et al., 2021。

## 一、背景与挑战

流水各阶段需保存微批次激活用于反向，显存随微批数线性增。

## 二、核心原理

激活重计算（checkpointing）：前向只存阶段边界激活，反向时重算内部；以算力换显存，使微批数可加大、气泡减小。

## 三、数学形式

显存 $M\approx c\cdot m + const$，重计算后 $c$ 降为边界激活；重算增约 $1/3$ 计算。

## 四、代码实现

```python
def stage_forward(inp, save=False):
    return checkpoint(lambda x: block(x), inp, use_reentrant=False) if save else block(inp)
```

## 五、与其他对比

- 与 张量并行深入 显存互补（TP 切激活、PP 重计算）。
- 与 序列并行深入 同属显存优化。

## 六、常见误区

- 重计算省显存但增时间，需权衡。
- 边界激活未存导致无法重算。

## 八、面试题

- 重计算如何助流水线？答：降每微批激活显存，可增微批数减气泡。

## 九、演进

全存 → 边界检查点 → 选择性重算。

## 十、小结

激活重计算用算力换显存，是流水大规模训练标配。
