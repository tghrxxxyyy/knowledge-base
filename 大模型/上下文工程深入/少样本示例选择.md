# 少样本示例选择

> 对应 Brown et al. 2020（GPT-3 少样本学习）、LlamaIndex 检索式 few-shot、mlabonne LLM Course。

## 一、背景与挑战

少样本（few-shot）提示通过在上下文里放若干「输入-输出」示例，引导模型学习任务格式与风格，无需微调。但示例**怎么选**比「选几个」更关键：随机示例可能引入噪声、格式不一的示例会误导、覆盖不到边界的示例在难样本上失效。挑战是：在固定示例预算内，选出「语义相近、格式一致、覆盖边界」的一组示例，最大化泛化。

## 二、核心原理

三条选择原则：

- **语义相近**：示例输入应与当前 query 在语义空间接近，模型更易迁移同类模式（检索式 few-shot）。
- **格式一致**：所有示例严格同构（同字段、同顺序、同风格），避免模型学到混乱模板。
- **覆盖边界**：包含若干难样本/边界样本，提升鲁棒性，而非全是易例。

检索式 few-shot（retrieval-based）优于固定 few-shot：维护一个示例库，对当前 query 做近邻检索取 Top-k 作为示例，能动态适配不同输入分布。代价是需Embedding与检索开销，但效果通常更稳更鲁棒。

检索式 few-shot 的工程落地有几个细节。其一是「示例库怎么建」：不应随机采样，而应从真实流量里挑出有代表性、覆盖难边界的样本，并为每条标注任务类型与关键特征，便于检索时对齐。其二是「检索的键用什么」：可直接用 query 的 embedding，也可用 query 经改写后的 embedding（先让模型把口语化问题改写成规范问法再检索，召回更稳）。其三是「示例数量 k 的选取」：k 太小迁移不足，太大稀释注意力且抬高成本，常用 3-5，并结合评测确定。

格式一致性的含义比「长得像」更深：不仅字段顺序一致，连措辞风格、详细程度、是否带思考链都应一致。若示例一半带推理过程一半不带，模型会困惑该不该展示推理。对于需要推理链的任务，建议所有示例统一带 CoT，且链的长度与风格相近，避免「有的示例想三步、有的想一步」造成模式冲突。

还有一个进阶技巧是「基于难度的示例调度」：对简单 query 给简单示例、对困难 query 给含相似难点的示例，能让示例的「教学信号」更精准。这与课程学习（curriculum）思想一脉相承。

## 三、形式化与数学基础

设示例库 $\mathcal{E} = \{e_1,\dots,e_M\}$，当前输入 $x$。检索式选择：

$$\mathcal{E}_x = \text{TopK}_{e\in\mathcal{E}}\ \text{sim}\big(\text{emb}(x),\ \text{emb}(e_{\text{in}})\big)$$

其中 $\text{sim}$ 通常为余弦相似度。期望误差随示例相关度提升而下降：

$$\mathbb{E}_{x}\big[\text{err}(x)\big] \approx f\big(\,\text{avg-sim}(x, \mathcal{E}_x),\ \text{format-consistency}(\mathcal{E}_x)\,\big)$$

即平均相似度越高、格式越一致，错误率越低。固定 few-shot 的 $\mathcal{E}$ 与 $x$ 无关，故在分布漂移时 $\text{sim}$ 偏低、误差上升。

## 四、代码实现

检索式 few-shot 示意（基于向量检索）：

```python
import numpy as np
def select_fewshot(x_emb, ex_embs, examples, k=3):
    sims = x_emb @ ex_embs.T            # 余弦相似（已归一化）
    idx = np.argsort(-sims)[:k]
    return [examples[i] for i in idx]    # 近邻示例作为上下文

# 把选出的示例拼接：示例1\n示例2\n示例3\n当前输入
```

## 五、与其他技术对比

| 选法 | 稳定性 | 泛化 | 成本 |
|------|--------|------|------|
| 随机固定 | 低 | 差 | 低 |
| 相似固定 | 中 | 中 | 低 |
| 多样+边界 | 中 | 较好 | 低 |
| 检索式 | 高 | 好 | 中（需检索） |

## 六、常见误区

- 示例格式不统一，模型学到错误模板。
- 全用易例，边界样本上失效。
- 示例与任务分布脱节（如用英文示例做中文任务）。
- 示例过多稀释注意力、抬高成本，并非越多越好。

## 九、演进与趋势

从「静态示例库」走向「自动示例挖掘与合成」：用模型生成难例、用评测筛选最优示例集，甚至对示例做自动优化搜索，形成「示例即超参」的调优范式。

## 十、小结

少样本示例选择的核心是「选对而非选多」：语义相近保证迁移、格式一致保证可学、覆盖边界保证鲁棒。检索式 few-shot 动态适配输入分布，是工程首选；固定示例适合分布稳定的简单任务。
