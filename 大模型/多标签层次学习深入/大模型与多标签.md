# 大模型与多标签

> 见「多标签层次学习深入/多标签学习总览」；LLM 以生成式天然多标签。

## 一、背景与挑战

传统多标签需固定标签集；LLM 可开放生成任意标签/分类体系。

## 二、核心原理

- 把多标签当作**序列生成**：模型输出标签列表（如 "标签: A, B, C"）。
- 零样本多标签：给标签体系描述让模型判属。
- 层次分类：让模型按层次输出路径。
生成式统一了多标签/层次/开放分类。

## 三、关键要点

- 需约束输出格式可解析。
- 可开放标签（无预定义集）。

## 四、代码实现

```python
out = llm(f"从{labels}中选适用的: {text}")
labels_pred = parse_list(out)
```

## 五、与其他对比

- 判别式固定集；生成式开放。

## 六、常见误区

- 多标签必须预定义集——LLM 可开放。
