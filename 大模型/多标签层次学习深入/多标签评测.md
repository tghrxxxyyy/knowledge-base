# 多标签评测

> 见「多标签层次学习深入/多标签学习总览」；评测需考虑多标签特性。

## 一、背景与挑战

单标签 acc 不适用于多标签。

## 二、核心原理

- **Subset accuracy**：预测集合完全匹配才算对，严苛。
- **Hamming loss**：标签级错分率。
- **micro/macro-F1**：micro 全局、macro 各类平均（关注稀有标签）。
- **mAP**：排序质量（检索场景）。

## 三、数学形式

macro-F1 = `(1/L) Σ_i F1_i`，对标签平均。

## 四、代码实现

```python
from sklearn.metrics import f1_score
f1 = f1_score(y, pred, average="macro")
```

## 五、关键要点

- 稀有标签需 macro 才可见。
- subset accuracy 常过低失真。

## 六、与其他对比

- 单标签 acc；多标签多指标。

## 七、常见误区

- 只看 subset accuracy——过严。
