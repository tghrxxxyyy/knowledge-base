# 标签关联建模

> 见「多标签层次学习深入/多标签学习总览」；Chen et al., *ML-GCN*, 2019。

## 一、背景与挑战

独立预测各标签忽略共现（如「海边」与「日落」常同现）。

## 二、核心原理

用图卷积在标签图上传播信息：节点=标签，边=共现/语义关系，标签表征经 GCN 更新后辅助分类；或序列生成标签（RNN/LSTM 按条件概率生成标签序列）。

## 三、数学形式

`Z_label = GCN(A_label, X_label)`，`ŷ = σ(W·[x; Z_label])`。

## 四、代码实现

```python
label_emb = gcn(label_adj, label_feat)
logits = head(cat(img_feat, label_emb))
```

## 五、关键要点

- 标签图可来自共现统计或知识库。
- 关联建模提升稀有标签。

## 六、与其他对比

- 独立预测无关联；图建模有。

## 七、常见误区

- 各标签独立——丢失结构。
