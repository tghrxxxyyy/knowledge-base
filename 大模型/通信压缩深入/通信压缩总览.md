# 通信压缩总览

> 对应 Lin et al., 《Deep Gradient Compression》, 2018；分布式训练通信压缩。

## 一、背景与挑战

数据/专家并行每步通信梯度/激活，跨节点带宽成扩展瓶颈。

## 二、核心原理

压缩分两类：量化（低比特表示，如 1-bit）与稀疏化（只传大梯度，如 top-k）；配合误差补偿保持收敛；可降通信量 10-100×。

## 三、数学形式

压缩比 $r=\frac{\|g\|_0\cdot b_{low}}{\|g\|_0\cdot 32}$ 或稀疏率 $s=\frac{|topk|}{|g|}$；通信量降为 $1/r$。

## 四、代码实现

```python
g_q = quantize(g, bits=1)                 # 1-bit 量化
send(g_q); g = dequantize(g_q)
```

## 五、与其他对比

- 与 数据并行深入 all-reduce 正交（先压后聚）。
- 与 混合并行深入 重叠互补。

## 六、常见误区

- 直接量化无误差补偿致漂移。
- 压缩比过高损收敛。

## 八、面试题

- 通信压缩两类？答：量化（低比特）与稀疏化（传大梯度），常配误差补偿。

## 九、演进

无压 → 量化 → 稀疏+误差补偿。

## 十、小结

通信压缩以量化/稀疏降量，是跨节点扩展利器。
