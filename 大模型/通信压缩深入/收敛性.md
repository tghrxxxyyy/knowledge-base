# 通信压缩与收敛性

> 对应 Alistarh et al., 《QSGD》, 2017；收敛理论。

## 一、背景与挑战

压缩引入噪声，需保证不慢于全精度 SGD。

## 二、核心原理

QSGD 证明量化梯度是无偏/有界方差估计，收敛率与 SGD 同阶（仅常数差）；稀疏化需配合补偿否则有偏。

## 三、数学形式

$\mathbb E[\tilde g]=g$，$\mathrm{Var}(\tilde g)\le \frac{d}{s}\|g\|^2$（量化级数 $s$）；收敛率 $O(1/\sqrt{T})$。

## 四、代码实现

```python
# QSGD 随机量化
level = rand_round(g / norm, s) * norm / s
```

## 五、与其他对比

- 与 异步训练深入 陈旧度分析同属收敛理论。
- 与 数据并行深入 全精度对照。

## 六、常见误区

- 以为有偏压缩也保同收敛（需补偿）。
- 忽略方差随压缩级增。
