# 梯度稀疏化

> 对应 Lin et al., 《Deep Gradient Compression》, 2018（Top-k/Momentum）。

## 一、背景与挑战

全梯度通信浪费，多数小梯度贡献有限。

## 二、核心原理

只传绝对值最大的 top-k% 梯度，其余累积到残差；接收方用残差更新本地；配合动量加速；可降通信 100-1000×。

## 三、数学形式

掩码 $M=topk(|g|, k\%)$；发送 $M\odot g$，残差 $r\leftarrow r+(1-M)\odot g$。

## 四、代码实现

```python
mask = torch.topk(grad.abs(), k).indices
send(grad[mask]); residual += grad.clone().mul_(~mask)
```

## 五、与其他对比

- 与 梯度量化 可组合（先稀疏后量化）。
- 与 异步训练深入 常用于异步 SGD。

## 六、常见误区

- 稀疏率过高丢重要梯度。
- 残差未累积致信息丢。

## 八、面试题

- 稀疏化为何配残差？答：未传梯度累积到残差，下步补传防信息丢。

## 九、演进

随机稀疏 → top-k → top-k+动量。

## 十、小结

梯度稀疏化只传大梯度，配合残差保信息、降通信。
