# 通信压缩与误差补偿

> 对应 Seide et al., 《1-bit Stochastic Gradient Descent》, 2014；误差反馈理论。

## 一、背景与挑战

压缩有损， naive 压缩致梯度漂移、收敛慢。

## 二、核心原理

误差反馈（error feedback）把本次压缩误差累积进下次梯度再压，使长期压缩等效全精度；理论上保证收敛。

## 三、数学形式

$\tilde g_t = compress(g_t + e_{t-1})$；$e_t = g_t + e_{t-1} - \tilde g_t$（残差）。

## 四、代码实现

```python
e = g + e_prev
g_hat = compress(e)
e = e - g_hat                              # 更新误差
send(g_hat)
```

## 五、与其他对比

- 与 梯度量化/稀疏化 都依赖此机制。
- 是压缩可用的理论基础。

## 六、常见误区

- 忘记更新误差致补偿失效。
- 误差无限增长（需裁剪）。

## 八、面试题

- 误差反馈为何必要？答：补偿压缩损失，使长期等效全精度、保收敛。

## 九、演进

无补偿 → 误差反馈 → 随机补偿。

## 十、小结

误差反馈是通信压缩收敛保障，几乎所有压缩方案必备。
