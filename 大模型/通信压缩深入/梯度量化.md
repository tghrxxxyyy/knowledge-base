# 梯度量化

> 对应 Tang et al., 《1-bit Adam》, 2021；Bernstein et al., 《SignSGD》, 2018。

## 一、背景与挑战

32 位梯度通信昂贵，低比特是否保收敛。

## 二、核心原理

1-bit Adam 在预热后把梯度压缩为符号位 + 缩放，仅传 1 bit/参数；SignSGD 用符号梯度方向；需误差补偿累积未传信息。

## 三、数学形式

$\tilde g = sign(g)\cdot \|g\|_1/n$（缩放）；压缩比 32×；更新方向近似。

## 四、代码实现

```python
comp = compress_1bit(grad)                # 1 bit
grad = decompress(comp) * scaler
opt.step()
```

## 五、与其他对比

- 与 梯度稀疏化 是不同压缩轴。
- 与 数据并行深入 直接降 all-reduce 量。

## 六、常见误区

- 预热不足直接压缩致发散。
- 缩放估计不准致方向偏。

## 八、面试题

- 1-bit Adam 为何能收敛？答：预热后用符号梯度+缩放，配合误差补偿保留方向。

## 九、演进

32bit → 8bit → 1bit(符号)。

## 十、小结

梯度量化到 1-bit 可大幅降通信，靠误差补偿保方向。
