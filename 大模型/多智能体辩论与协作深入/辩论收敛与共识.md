# 辩论收敛与共识

> 对应 Liang et al., *Encouraging Divergent Thinking in LLMs through Multi-Agent Debate*, EMNLP 2024；Du et al., ICML 2024。

## 一、背景与挑战

辩论若过早收敛，等于没有辩论；若始终不收敛，则无法产出确定结论且成本失控。
更隐蔽的风险是「退化共识」：智能体倾向于附和先发言者或语气更自信者，最终共识与真值无关。

## 二、核心原理

- 收敛判据：连续两轮答案分布不变、或达到多数阈值即停止，避免固定轮数的浪费与震荡。
- 反从众设计：引入固定的反方角色（devil's advocate）、隐藏发言顺序、限制引用他人措辞、要求给出独立证据。
- 裁决机制：设置独立裁判（judge）在共识失败时依据论据质量而非票数裁定，减少多数误导。

## 三、数学形式

把答案分布 $q_t$ 的演化视为意见动力学：$q_{t+1}=(1-\eta)q_t+\eta\,\mathcal T(q_t)$，$\eta$ 为对他人观点的采纳强度。

$\eta$ 过大导致快速塌缩到初始多数（从众），过小导致轨迹几乎不动；收敛可用熵 $H(q_t)$ 的单调下降与阈值判定。

## 四、代码实现

```python
def debate_until_consensus(agents, q, max_rounds=4, thresh=0.75):
    hist = []
    answers = [a(q) for a in agents]
    for r in range(max_rounds):
        dist = normalize(Counter(map(answer_of, answers)))
        top, p = dist.most_common(1)[0]
        hist.append(dist)
        if p >= thresh or (r > 0 and dist == hist[-2]):
            return top, r + 1
        answers = one_round(agents, q, answers)
    return top, max_rounds
```

## 五、与其他对比

- 与人类评审：人类会议同样存在锚定与从众，缓解手段（匿名、独立先写后议）可直接借用。
- 与集成学习：集成通过训练多样性去相关；辩论通过交互补信息，但交互本身会引入相关性，需刻意保持分歧。

## 六、常见误区

- 把「大家意见一致」当作正确性证据；一致性只是稳定性指标，需与独立验证分开看。
- 允许智能体看到完整历史长文本，导致后发者被前文风格同化。
- 用固定轮数不看分布变化，既浪费也可能在震荡中随机截断。

## 八、面试题

- 如何判断辩论已收敛？答：答案分布连续两轮不变或多数比例超过阈值，同时熵下降到设定水平，而非简单跑满轮数。
- 如何抑制从众？答：引入固定反方、匿名并打乱顺序、要求引用独立证据、由裁判按论据质量而非票数裁决。

## 九、演进

固定轮数辩论 → 收敛判据早停 → 反从众与分歧激励 → 独立裁判裁决 → 面向成本的自适应辩论深度。

## 十、小结

辩论的质量在于「有分歧地收敛」：既要终止判据，也要制度化保护少数正确意见。
