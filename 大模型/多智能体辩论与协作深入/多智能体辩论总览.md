# 多智能体辩论与协作总览

> 对应 Du et al., *Improving Factuality and Reasoning in Language Models through Multiagent Debate*, ICML 2024；Li et al., *CAMEL*, NeurIPS 2023。

## 一、背景与挑战

单模型单次推理的错误无处对冲；投票只能利用采样冗余，无法让不同视角互相质询。
多智能体让若干实例分别作答、互相阅读并反驳，把「独立采样」升级为「交互式互评」，但也带来成本、收敛与从众等新问题。

## 二、核心原理

- 基本回合制：每个智能体给出答案与理由，然后读取其他智能体的答案并修订，重复若干轮直至趋同或到轮数上限。
- 有效性前提是误差不完全相关：不同角色提示、不同模型、不同证据来源都能降低相关性，从而使互评带来新信息。
- 协作模式谱系：辩论（对抗质询）、分工（角色流水线）、审阅（生成者加评审者）、混合（分工内嵌辩论）。

## 三、数学形式

若 $m$ 个判断的错误两两相关系数为 $\rho$，多数投票的等效独立样本数约为 $m_{\text{eff}}=\frac{m}{1+(m-1)\rho}$。

这解释了为何同模型同提示的多副本收益迅速饱和：$\rho\to1$ 时 $m_{\text{eff}}\to1$，必须靠角色/模型/证据差异化把 $\rho$ 压低。

## 四、代码实现

```python
def debate(agents, question, rounds=3):
    answers = [a(question) for a in agents]
    for _ in range(rounds - 1):
        new = []
        for i, a in enumerate(agents):
            others = "\n".join(f"观点{j}: {ans}" for j, ans in enumerate(answers) if j != i)
            new.append(a(f"问题: {question}\n我的上轮: {answers[i]}\n{others}\n"
                         f"若他人论据更强则修正，否则给出反驳"))
        answers = new
    return majority(answers)
```

## 五、与其他对比

- 与自我一致性：投票不交互、成本低、无从众风险；辩论能纠系统性错误但可能集体收敛到错误共识。
- 与单体反思：辩论的批评来自异构主体，与自身误差相关性更低，接近独立裁判。

## 六、常见误区

- 用同一模型同一提示复制多份就叫多智能体：误差高度相关，几乎等于加大采样。
- 轮数越多越好：多数收益在前两轮，之后成本线性增长且易出现相互附和。
- 不设终止判据，导致答案在两个选项间震荡不收敛。

## 八、面试题

- 多智能体辩论何时优于投票？答：当错误是系统性的（如共同的推理盲点）且存在异构视角或证据可引入时，交互能带来新信息。
- 如何量化多智能体的有效冗余？答：用错误相关性估计等效独立样本数，差异化角色与模型以降低相关系数。

## 九、演进

单体采样 → 多数投票 → 多智能体辩论 → 角色分工流水线（MetaGPT）→ 可编程多智能体框架与图式通信。

## 十、小结

多智能体的收益本质来自误差去相关，异构性是设计核心，成本与收敛控制是工程核心。
