# 角色扮演与自动协商

> 对应 Li et al., *CAMEL: Communicative Agents for Mind Exploration*, NeurIPS 2023；Park et al., *Generative Agents*, UIST 2023。

## 一、背景与挑战

让两个模型自由对话完成任务时，常见退化包括角色互换、无限客套、任务漂移和过早宣布完成。
角色扮演协作需要用机制而非祈祷来维持角色一致性与任务推进。

## 二、核心原理

- 角色提示固化：明确身份、目标、禁止行为（如不得替对方作答、不得跳过验证），并在每轮重申关键约束。
- 任务规格先行：把任务转成可判定的完成条件，协商围绕规格推进而非围绕语气。
- 终止与仲裁：设置最大轮数、显式完成标记与外部验收，避免双方互相认可的虚假完工。

## 三、数学形式

把协商建模为在共同任务约束下的交替最优响应：$a^{(k+1)}_A=\arg\max_a U_A(a\mid a^{(k)}_B)$，$a^{(k+1)}_B$ 同理。

若 $U_A,U_B$ 与真实任务效用不一致（如都偏好尽快结束），均衡点会落在低质量解上，这正是虚假完工的博弈解释。

## 四、代码实现

```python
def role_play(user_agent, assistant_agent, task, max_turns=10):
    spec = user_agent(f"把任务转成可判定完成条件: {task}")
    msg = spec
    for _ in range(max_turns):
        reply = assistant_agent(msg, role_guard="你只执行，不得代替提问方定义需求")
        if "TASK_DONE" in reply and accept(spec, reply):   # 外部验收
            return reply
        msg = user_agent(reply, role_guard="你只提需求与验收，不得代写方案")
    return reply
```

## 五、与其他对比

- 与 SOP 分工：角色扮演更灵活、适合需求不明确的探索期；SOP 更可控，适合可标准化的交付流程。
- 与单体自问自答：双智能体的角色隔离更强，减少自我附和，但仍需外部验收防止合谋。

## 六、常见误区

- 只在开场设定角色，后续轮次不重申约束，角色随对话漂移。
- 把「双方都说完成」当成完成，缺少客观验收条件。
- 允许提问方直接给出完整方案，退化为独角戏，协作价值消失。

## 八、面试题

- 角色互换问题如何治理？答：每轮注入角色守卫约束、限制可执行动作集合，并在解析层拒绝越权发言。
- 为什么需要外部验收？答：双方效用都偏向尽快结束，容易达成低质量均衡，客观验收打破这一合谋。

## 九、演进

自由双人对话 → 角色守卫与任务规格 → 引入验收与仲裁 → 多角色社会模拟（Generative Agents）→ 面向目标的协商协议化。

## 十、小结

角色扮演要靠机制维持：规格可判定、角色有守卫、完成需外部验收。
