# 分布式优化与收敛性

> 对应 大批量训练收敛性（Goyal et al., *Accurate, Large Minibatch*, 2017）；与 学习率调度 衔接。

## 一、背景与挑战

有效批量随卡数线性增大，朴素增大易损收敛与泛化；需调学习率与暖启动策略。

## 二、核心原理

线性缩放规则：批量乘 $k$ 则学习率乘 $k$（在热区前）；配合热身（warmup）避免初期大 lr 破坏；晚期可衰减。理论保证在凸/弱凸下近似等价。

## 三、数学形式

学习率 $\eta_{new}=k\eta_{base}$（$k=B_{eff}/B_{base}$）；warmup 步长线性增至目标再余弦衰减。

## 四、代码实现

```python
sched = LinearWarmupCosineDecay(eta_max=k*lr0, warmup=2000, total=steps)
```

## 五、与其他对比

- 与 梯度压缩与通信（通信约束）共同决定扩展效率。
- 与 分布式优化器深入 总览（同步机制）配合定批量。

## 六、常见误区

- 批量过大超出线性区致泛化下降。
- 缺 warmup 致初期不稳定。

## 八、面试题

- 大批量为何需线性缩放 lr？答：大批量梯度更准，需更大步长维持更新幅度与收敛速度。

## 九、演进

单卡小批 → 线性缩放+warmup → LARS/LAMB 自适应。

## 十、小结

分布式优化的收敛依赖批量-lr-warmup 协同，是规模化训练的稳定基石。
