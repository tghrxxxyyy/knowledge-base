# 异步优化器（Async SGD）

> 对应 Recht et al., *Hogwild!*, 2011；异步分布式 SGD 实践。

## 一、背景与挑战

同步 AllReduce 受最慢节点（掉队者）拖累；异步更新可隐藏延迟但引入陈旧梯度（stale gradient）。

## 二、核心原理

各 worker 异步拉取参数、算梯度、回写，无全局屏障；用陈旧度 $k$ 调节步长或补偿，缓解梯度过期带来的收敛劣化。

## 三、数学形式

陈旧梯度更新 $\theta_{t+k}\leftarrow\theta_t-\eta_k g(\theta_t)$；步长常取 $\eta_k\propto 1/\sqrt{k}$ 或延迟补偿以减少偏差。

## 四、代码实现

```python
with param_server.lock_optional():    # Hogwild 甚至无锁
    grad = compute_grad(local_data)
    ps.apply_grad(grad)
```

## 五、与其他对比

- 与同步 DDP/ZeRO 比，异步延迟低但可能发散。
- 与 分布式优化与收敛深入（收敛性）直接相关。

## 六、常见误区

- 高陈旧度致训练发散（需限延迟或降 lr）。
- 无锁更新在强相关参数下结果不确定。

## 八、面试题

- 异步优化风险？答：陈旧梯度使更新基于过期参数，收敛慢甚至发散，需步长/延迟补偿。

## 九、演进

同步屏障 → Hogwild 无锁 → 延迟补偿异步。

## 十、小结

异步优化以陈旧梯度换延迟隐藏，适合异构/高延迟集群但需谨慎调参。
