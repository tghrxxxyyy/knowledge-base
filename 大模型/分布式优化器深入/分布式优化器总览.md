# 分布式优化器总览

> 对应 Li et al., *PyTorch Distributed*, 2020；Rajbhandari et al., *ZeRO*, 2020；与 分布式训练 衔接。

## 一、背景与挑战

单卡显存放不下大模型的参数/梯度/优化器状态；分布式优化器把状态与计算切分到多卡，平衡通信与显存。

## 二、核心原理

数据并行（DP）在各卡复制模型、分数据；优化器状态可在卡间复制（DDP）或分片（ZeRO）。参数服务器（PS）与全规约（AllReduce）是两种同步范式。

## 三、数学形式

梯度同步 $\bar g = \frac1N\sum_{i=1}^N g_i$（AllReduce 均值）；有效批量 $B=N\times b$，学习率常随 $B$ 线性缩放。

## 四、代码实现

```python
model = DistributedDataParallel(model, device_ids=[rank])
loss.backward(); optimizer.step()   # 梯度在反向时自动 AllReduce
```

## 五、与其他对比

- 与 显存最优调度深入（显存切分伙伴）配合。
- 与 梯度检查点深入（减激活显存）共同放大模型。

## 六、常见误区

- 有效批量增大未调学习率致收敛差。
- 误以为 DDP 已分片优化器状态（实际 ZeRO 才分）。

## 八、面试题

- DDP 与 ZeRO 区别？答：DDP 各卡冗余存全状态，ZeRO 把参数/梯度/优化器状态分片以省显存。

## 九、演进

单卡 → DP → DDP → ZeRO 分片。

## 十、小结

分布式优化器以切分与同步在显存与通信间权衡，是大模型训练底座。
