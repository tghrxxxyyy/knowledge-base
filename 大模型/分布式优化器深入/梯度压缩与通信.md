# 梯度压缩与通信优化

> 对应 Alistarh et al., *QSGD*, 2017；Bernstein et al., *SignSGD*, 2018。

## 一、背景与挑战

多卡/多机训练受通信带宽限制；梯度含大量冗余，可压缩以降低同步开销。

## 二、核心原理

量化（QSGD 把梯度量级化为若干比特）、稀疏化（仅传大值 Top-k）、或符号化（SignSGD 只传符号）；配合误差补偿（error feedback）保收敛。

## 三、数学形式

QSGD：$Q(g)=\|g\|\cdot q(\frac{g}{\|g\|})$，$q$ 为 $s$ 位随机量化；方差可控、收敛近似无损。

## 四、代码实现

```python
sign = g.sign()
comm.all_reduce(sign)            # SignSGD
# 误差补偿
error += g - dequant(quant(g)); comm(error)
```

## 五、与其他对比

- 与 分布式优化器深入 总览（通信是同步核心）互补。
- 与 显存最优调度深入（省显存另一维度）并列优化目标。

## 六、常见误区

- 过度压缩致收敛慢/偏差（需误差补偿）。
- 稀疏化未处理剩余梯度致信息丢。

## 八、面试题

- 梯度压缩为何需误差补偿？答：压缩丢的残差若丢弃会累积偏差，补偿把残差顺延到下轮保收敛。

## 九、演进

全精度 AllReduce → 量化/稀疏 → 误差补偿压缩。

## 十、小结

梯度压缩以可控精度损失换通信带宽，是大规模训练扩展关键。
