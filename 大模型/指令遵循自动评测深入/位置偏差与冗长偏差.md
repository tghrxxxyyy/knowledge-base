# 位置偏差与冗长偏差

> 对应 LLM-as-Judge 中的位置偏差（position bias）与冗长偏差（verbosity bias）研究。

## 一、背景与挑战

裁判模型并非中立：在 pairwise 比较中倾向选第一个（位置偏差），在打分时倾向给更长回答高分（冗长偏差）。二者系统性扭曲排行。

## 二、核心原理

位置偏差检测：交换 A/B 顺序看胜者是否翻转；冗长偏差：控制长度看评分变化。缓解用双向比较取平均或长度归一。

## 三、数学形式

位置翻转率：

$$
F=\frac{1}{N}\sum\mathbf{1}[\hat{y}_{\mathrm{AB}}\neq\hat{y}_{\mathrm{BA}}]
$$

长度偏斜率：

$$
\beta=\frac{\partial \mathrm{score}}{\partial \mathrm{len}}
$$

## 四、代码实现

```python
def position_flip(a_b, b_a):
    return sum(1 for x,y in zip(a_b,b_a) if x!=y)/len(a_b)

print(position_flip(["A","B","A"], ["A","A","B"]))
```

## 五、与其他对比

相比无偏人工，自动裁判必须显式度量并校正这两类偏差；相比单点打分，pairwise 更易暴露位置偏差。

## 六、常见误区

误区一：一次比较即结论（应双向）。误区二：长=好（冗长偏差）。误区三：忽略裁判自偏好。

## 八、面试题

- Q：位置偏差如何检测与缓解？答：交换顺序看翻转率，双向比较取平均。
- Q：冗长偏差危害？答：使信息密度低的冗长回答虚高。

## 九、演进

从发现偏差到标准化双向评估与长度去偏，裁判可靠性持续提升。

## 十、小结

位置与冗长偏差是 LLM 裁判的系统性缺陷，必须经双向与长度校正。
