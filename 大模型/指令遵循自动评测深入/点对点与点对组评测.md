# 点对点与点对组评测

> 对应 pairwise 与 pointwise LLM 评测协议对比研究。

## 一、背景与挑战

指令遵循评测可选 pointwise（独立打分）或 pairwise（二选一）。两者方差、偏差、可解释性不同，选择影响排行稳定性。

## 二、核心原理

pointwise 给绝对分，易受评分尺度漂移影响；pairwise 给相对序，更稳定但丢失绝对水平。常结合：pairwise 排位 + pointwise 校准。

## 三、数学形式

pairwise 期望胜率：

$$
P(A\succ B)=\sigma(w_A-w_B)
$$

pointwise 分差：

$$
\Delta=s_A-s_B
$$

## 四、代码实现

```python
import math

def p_win(wa, wb):
    return 1/(1+math.exp(-(wa-wb)))

print(round(p_win(1.2, 0.8), 3))
```

## 五、与其他对比

相比 pointwise，pairwise 更抗尺度漂移；相比人工绝对分，自动 pairwise 更易规模化。

## 六、常见误区

误区一：pairwise 无偏差（仍有位置偏差）。误区二：pointwise 分可跨模型比较（尺度不同）。误区三：忽略标注者间方差。

## 八、面试题

- Q：pointwise 与 pairwise 取舍？答：pairwise 稳序，pointwise 给绝对分，常结合。
- Q：pairwise 局限？答：仍有位置偏差且丢绝对水平。

## 九、演进

从单一协议到混合（pairwise 排位 + pointwise 校准），评测更稳健。

## 十、小结

点对点与点对组各有偏差谱，混合协议是当前最优实践。
