# 多向量检索（Multi-Vector）总览

> 对应 Khattab & Zaharia, *ColBERT*, 2020（token 级多向量与迟交互）。

## 一、背景与挑战

双塔单向量把整段压成一点，丢失词级信息；多向量保留每个 token 的向量，匹配更细粒度。

## 二、核心原理

query 与 document 各输出一组 token 向量，文档向量离线存储；检索时用迟交互（token 间 MaxSim）累积相似度，兼顾表达力与离线索引。

## 三、数学形式

文档表示 $D=\{d_1..d_{|D|}\}$，query $Q=\{q_1..q_{|Q|}\}$；相似度 $S(Q,D)=\sum_{i}\max_j q_i^\top d_j$。

## 四、代码实现

```python
Q = colbert.encode(query); D = colbert.encode(doc)
score = sum(max(Q[i] @ D.t()) for i in range(len(Q)))
```

## 五、与其他对比

- 比 双塔 表达强、比 交叉编码器 快（可离线索引）。
- 与 迟交互深入（MaxSim）共享核心。

## 六、常见误区

- 存储膨胀（每 token 一向量），需压缩（ColBERTv2）。
- 未做查询端裁剪（只保留非停用 token）增成本。

## 八、面试题

- 多向量相对单向量优势？答：保留 token 级信息，迟交互捕捉细粒度匹配。

## 九、演进

单向量(DPR) → 多向量(ColBERT) → 压缩多向量(ColBERTv2/PLAID)。

## 十、小结

多向量以 token 级表示提升精度，靠压缩与迟交互保持可检索。
