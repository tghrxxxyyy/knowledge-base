# 多向量压缩（ColBERTv2 / PLAID）

> 对应 Santhanam et al., *ColBERTv2*, 2021；Santhanam et al., *PLAID*, 2022（残差压缩索引）。

## 一、背景与挑战

多向量存储开销巨大（每 token 一向量）；需压缩同时保迟交互精度。

## 二、核心原理

ColBERTv2 用残差编码：token 向量量化为中心+残差，仅存码本与残差；PLAID 进一步用聚类与质心选择加速，并做维度残差压缩。

## 三、数学形式

残差 $r_t = d_t - c_{k(t)}$；近似 $S\approx\sum_i\max_j (q_i^\top c_{k(j)} + q_i^\top r_j)$，以码本近似省存储。

## 四、代码实现

```python
from colbert.modeling.colbert import ColBERT
index = colbert_indexer.encode_residual(corpus)   # 残差压缩
```

## 五、与其他对比

- 与 双塔推理加速（PQ 压缩）思路相似但保 token 级。
- 与 多向量检索深入 总览衔接。

## 六、常见误区

- 压缩过狠致迟交互精度掉；需验证召回。
- 仅压缩文档未压查询致不对称。

- ColBERTv2 如何压缩？答：token 向量残差量化，存码本+残差，省存储保迟交互。

## 九、演进

原始多向量 → 残差压缩 → PLAID 集群加速。

## 十、小结

多向量压缩以残差量化把存储降到近双塔级，是生产可用关键。
