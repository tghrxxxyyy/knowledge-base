# 有向无向图基础

> 对应 d2l-zh 概率与图模型基础；Koller & Friedman, *Probabilistic Graphical Models*, 2009。

## 一、背景与挑战

高维分布 $p(x_1,\dots,x_n)$ 参数爆炸；图模型用条件独立结构分解，降参且可解释。

## 二、核心原理

有向（贝叶斯网络）：用有向无环图表示 $p(x)=\prod_i p(x_i|Pa(x_i))$。
无向（马尔可夫随机场）：势函数 $\phi$ 定义在团上，$p(x)=\frac{1}{Z}\prod_C \phi_C(x_C)$，$Z$ 为配分函数。

## 三、数学形式

马尔可夫性：节点条件独立于其非邻居给定邻居（Markov blanket）。

## 四、代码实现

```python
# 势函数示例（无向）
phi = torch.exp(-energy(clique)); p = phi / phi.sum()
```

## 五、与其他对比

- 有向擅长因果/生成叙事；无向擅长对称约束（如图像像素邻域）。
- 神经网络以隐变量隐式建模分布，图模型显式结构。

## 六、常见误区

- 混淆条件独立与边际独立；图结构决定前者。
- 忽视配分函数 $Z$ 难算（无向模型推断难点）。

## 七、与开源书对应

- d2l-zh 概率基础：https://github.com/d2l-ai/d2l-zh
- 贝叶斯深度学习深入 提供神经网络侧衔接。

## 八、面试题

- 有向与无向图的最大区别？答：分解形式与条件独立语义不同，无向需配分函数。

## 九、演进

朴素贝叶斯 → 贝叶斯网络 → 马尔可夫随机场 → 深度生成模型（融合）。

## 十、小结

图模型用图结构编码条件独立，是结构化概率推理与可解释分布建模基础。
