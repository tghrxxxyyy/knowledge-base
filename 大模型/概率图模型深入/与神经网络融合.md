# 概率图模型与神经网络融合

> 对应NN & GNN 章节；图神经网络深入 衔接；贝叶斯深度学习深入。

## 一、背景与挑战

纯图模型难拟合复杂非线性；纯神经网络缺结构化不确定性与可解释。

## 二、核心原理

- 神经网络定义势函数/条件概率（如 CRF 输出层、神经 MRF）。
- 图神经网络（GNN）在图结构上做消息传递，等价于特定 PGM 近似推断。
- 贝叶斯神经网络以分布代替点权重，输出不确定性。

## 三、数学形式

GNN 层：$h_v^{(l+1)} = \phi\left(h_v^{(l)}, \bigoplus_{u\in\mathcal N(v)} \psi(h_u^{(l)})\right)$，聚合邻居。

## 四、代码实现

```python
msg = edge_encoder(h_u); h_v = update(h_v, aggregate(msg))
```

## 五、与其他对比

- GNN 是图结构上的可微推断；传统 PGM 靠手工消息调度。
- 贝叶斯深度学习给确定性网络加不确定性。

## 六、常见误区

- 误以为 GNN 总能胜过扁平 MLP；同质图/无结构数据上未必。
- 过度层数导致过平滑（over-smoothing）。

## 八、面试题

- GNN 与 PGM 的关系？答：消息传递可视为可微近似信念传播。

## 九、演进

手工 PGM → 神经势函数 → GNN → 图 Transformer。

## 十、小结

图模型提供结构与不确定性框架，神经网络提供拟合力，二者融合是大模型之外的重要范式。
