# 变分推断

> 对应 Jordan et al., 1999；Kingma & Welling, *VAE*, 2013（ amortized VI）。

## 一、背景与挑战

精确边际化不可行时，用可解分布族 $q_\phi(z)$ 逼近真后验 $p(z|x)$。

## 二、核心原理

最小化 KL：$q^* = \arg\min_q KL(q(z)\|p(z|x))$，等价于最大化证据下界 ELBO：
$\mathcal L = \mathbb E_q[\log p(x|z)] - KL(q(z)\|p(z))$。

## 三、数学形式

ELBO 梯度经重参数化（reparameterization）可低方差估计：$z = \mu_\phi(x) + \sigma_\phi(x)\odot\epsilon,\ \epsilon\sim\mathcal N(0,I)$。

## 四、代码实现

```python
z = mu + sigma * torch.randn_like(sigma)
loss = recon_loss(x, decoder(z)) + kl(mu, sigma)
```

## 五、与其他对比

- 变分快但 mode-seeking（低估散布）；MCMC 无偏但慢。
- 摊销变分用神经网络共享 $q_\phi$，适合大数据。

## 六、常见误区

- 误用 KL 方向：$KL(q\|p)$ 与 $KL(p\|q)$ 性质相反。
- 后验坍塌：解码器忽略 $z$ 致 $q$ 退化为先验。

## 八、面试题

- ELBO 两项各是什么？答：重建项 + 后验先验 KL 正则。

## 九、演进

平均场 VI → 摊销 VI（VAE）→ 层次 VI → 扩散模型的变分视角。

## 十、小结

变分推断把推断转成优化，配合重参数化支撑 VAE 与现代生成模型。
