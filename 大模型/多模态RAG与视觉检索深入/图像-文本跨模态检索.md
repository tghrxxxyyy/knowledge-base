# 图像-文本跨模态检索

> 对应 huggingface/transformers 多模态编码器与 facebookresearch/faiss 向量检索。

## 一、背景与挑战
用户可能用文字找图，也可能用图找相关文字说明。跨模态检索要求两模态在同一空间可比，且处理大规模图库的延迟与存储。

## 二、核心原理
统一编码器把图像与文本投影到 d 维共享空间，离线为图库建向量索引。查询可来自任一模态，检索返回另一模态近邻。常用 FAISS 的 IVF/PQ 压缩图向量以降本。

## 三、形式化与数学基础
给定图库 $\{I_j\}$ 与文本 $\{T_k\}$，索引向量 $V = \{E_I(I_j)\} \cup \{E_T(T_k)\}$。查询 $q$（任意模态）：
$\text{NN}(q) = \arg\max_{v \in V} \text{sim}(E(q), v)$
跨模态成立依赖对齐损失使 $\|E_I(I)-E_T(T)\|$ 在配对时小。

## 四、代码实现
```python
def build_mm_index(imgs, texts, enc, index):
    for im in imgs:
        index.add(enc.image(im))
    for tx in texts:
        index.add(enc.text(tx))
    return index
```

## 五、与其他技术对比
相比单模态检索，跨模态覆盖更自然的人机交互；难点在模态鸿沟与大规模索引成本，需量化压缩。

## 六、常见误区
误区一：图像与文本向量可直接平均，应分别编码器。误区二：忽略索引压缩导致内存爆炸。

## 七、与开源书/权威来源对应
- huggingface/transformers 提供 CLIP/BLIP 等跨模态模型。
- facebookresearch/faiss 支持大规模向量索引与量化。
- Lewis et al. 2020 检索思想延伸。

## 九、演进与趋势
区域级跨模态检索（以图像 patch 匹配文本片段）提升细粒度，并与生成模型形成「检索-生成」闭环。

## 十、小结
跨模态检索把 RAG 从纯文本拓展到图文互搜，是多模态知识库的核心。
