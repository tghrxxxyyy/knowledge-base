# 二阶优化实践与对比

> 对应大模型训练二阶方法的工程权衡（如 K-FAC/Shampoo 在 ResNet、Transformer 的实测）。

## 一、背景与挑战

二阶法理论快但工程复杂，需对比一阶法性价比。

## 二、核心原理

在凸/微调场景二阶更快收敛；预训练大模型常因近似与通信成本而仍用 AdamW。

## 三、数学形式

效率比 $\frac{\text{iter}_{1st}}{\text{iter}_{2nd}}$ vs 单步成本比 $\frac{\text{cost}_{2nd}}{\text{cost}_{1st}}$。

## 四、代码实现

```python
opt = Shampoo(params, lr=0.001) if use_second else AdamW(params)
```

## 五、与其他对比

- 与 自适应学习率深入 大面积使用的一阶法对照。
- 与 自然梯度深入 共享预条件思想。

## 六、常见误区

- 以为二阶必收敛更快，通信/近似常使其落后。
- 忽略二阶对超参（阻尼）更敏感。

## 七、与开源书对应

- d2l-zh：https://github.com/d2l-ai/d2l-zh
- mlabonne/llm-course：https://github.com/mlabonne/llm-course

## 八、面试题

- 何时用二阶？答：中小规模/凸、微调或需少步收敛时；大模型预训练多仍选一阶。

## 九、演进

理论二阶 → 近似二阶 → 分布式二阶。

## 十、小结

二阶法价值在场景选择，工程成熟度仍落后于 AdamW。
