# 牛顿法与近似

> 对应 Martens, 2010 的 Hessian-free（共轭梯度近似求解牛顿步）。

## 一、背景与挑战

精确 Hessian 与逆对百万参数不可用，需无显式矩阵求逆的方法。

## 二、核心原理

用共轭梯度（CG）迭代求解 $H\delta=-g$ 而不求 $H^{-1}$；通过 R-算子 高效算 Hessian-向量积。

## 三、数学形式

CG 解 $\delta^*=\arg\min_\delta \frac12\delta^\top H\delta+g^\top\delta$；迭代 $O(k)$ 次逼近。

## 四、代码实现

```python
def hvp(v): return torch.autograd.grad(grad.dot(v), theta)[0]
delta = conjugate_gradient(hvp, -g, nsteps=100)
```

## 五、与其他对比

- 与 自然梯度深入 的 K-FAC 同属近似二阶。
- 与 梯度噪声深入 牛顿步可结合噪声。

## 六、常见误区

- CG 步数过少得近似差、过多浪费。
- Hessian 负曲率需加阻尼或截尾。

## 八、面试题

- 如何无矩阵求牛顿步？答：用 CG 迭代解线性方程，配合 HVP 只在需要时算矩阵-向量积。

## 九、演进

直接求逆 → CG 求解 → 随机 HVP。

## 十、小结

Hessian-free 让二阶思想在大模型可行，核心是 HVP+CG。
