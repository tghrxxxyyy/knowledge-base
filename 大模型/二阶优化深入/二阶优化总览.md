# 二阶优化总览

> 对应 Nocedal & Wright, *Numerical Optimization*, 2006；Martens, *Deep Learning via Hessian-free Optimization*, 2010。

## 一、背景与挑战

一阶方法（SGD）忽略曲率信息，收敛慢且对学习率敏感；二阶法利用 Hessian 加速。

## 二、核心原理

牛顿法用 Hessian 逆预条件梯度，使各方向步长自适应曲率；深度学习中直接求逆不可行，需近似。

## 三、数学形式

牛顿更新 $\theta_{t+1}=\theta_t-H^{-1}g_t$，其中 $H=\nabla^2\mathcal L$；阻尼牛顿加 $(\!H+\lambda I)^{-1}$。

## 四、代码实现

```python
update = torch.linalg.solve(H + lam*I, g)
theta = theta - update
```

## 五、与其他对比

- 与 自然梯度深入 同用曲率/信息矩阵预条件。
- 与 自适应学习率深入 是廉价近似版。

## 六、常见误区

- 以为二阶必快，近似误差与逆成本常抵消收益。
- 忽略 Hessian 非正定需阻尼。

## 八、面试题

- 二阶法相对 SGD 优势？答：用曲率预条件，各方向步长自适应，收敛阶更高但需近似与正定处理。

## 九、演进

牛顿 → 阻尼牛顿 → 拟牛顿(L-BFGS) → 深度学习近似。

## 十、小结

二阶优化提供曲率感知更新，关键在可扩展的正定近似。
