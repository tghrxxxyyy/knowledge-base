# 大模型集成的取舍

> 见「模型集成提升深入/集成学习总览」与「模型服务化进阶」；大模型集成成本高。

## 一、背景与挑战

7B×N 集成推理成本线性增长，落地难。

## 二、核心原理

大模型集成（多采样投票/多模型平均）可提精度与校准，但推理成本与延迟大增。实践中常用：多次采样+自一致性（self-consistency，见推理与思考模型章）替代多权重集成；或用 MoE（见稀疏专家混合）在单前向内「集成」专家。

## 三、关键要点

- 采样集成便宜（同权重多跑）。
- 权重集成贵（多份参数）。

## 四、代码实现

```python
votes = [generate(p) for _ in range(k)]
ans = majority(votes)
```

## 五、与其他对比

- MoE 是参数内集成；多模型是参数外。

## 六、常见误区

- 大模型必集成——成本压死。
