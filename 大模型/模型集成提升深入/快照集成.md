# 快照集成

> 见「模型集成提升深入/集成学习总览」；Huang et al., *Snapshot Ensemble*, 2017。

## 一、背景与挑战

训练多模型成本高。

## 二、核心原理

同一网络在一次训练中，用**周期性学习率（余弦退火）**让优化器在损失地形多个局部极小间「跳跃」，在每次最低点快照一份权重，最后集成这些快照。几乎零额外成本得多个多样解。

## 三、数学形式

学习率按 `η(t)=η_min+0.5(η_max-η_min)(1+cos(π·(t mod T)/T))` 周期变化。

## 四、代码实现

```python
sched = CosineAnnealingLR(opt, T_max=epochs//M)
# 每个周期末 save snapshot
```

## 五、关键要点

- 快照间需足够分离（不同极小）。
- 单训练多模型。

## 六、与其他对比

- 常规集成多训练；快照单训练。

## 七、常见误区

- 快照=同模型——其实不同极小点。
