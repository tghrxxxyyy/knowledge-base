# 集成与校准

> 见「模型集成提升深入/集成学习总览」与「贝叶斯深度学习深入/不确定性校准」。

## 一、背景与挑战

集成提升准确率，也影响置信校准。

## 二、核心原理

平均多个模型预测可降低方差，常改善校准（预测置信更可信）；深度集成（见贝叶斯章）同时给出不确定性。但 bagging 也可能使置信过度平滑，需温度再校准。

## 三、关键要点

- 集成通常比单模型更校准。
- 结合温度缩放更佳。

```python
mean_p = stack([m(x) for m in ens]).mean(0)
```

## 五、与其他对比

- 单模型或过自信；集成更稳。

## 六、常见误区

- 集成必校准——仍需检查。
