# 质量过滤总览

> 对应 Wenzek et al., *CCNet*, 2020（基于困惑度与分类器过滤）；Raffel et al., *C4/T5*, 2020（启发式清洗）；Gao et al., *The Pile*, 2020。

## 一、背景与挑战

原始 Common Crawl 含大量低质（垃圾、模板、重复、机器翻译）文本；直接训练损害模型质量。

## 二、核心原理

质量过滤分两类：启发式规则（长度、符号比、行结构、黑名单词）与基于模型的方法（困惑度阈值、质量分类器）。常多阶段级联。

## 三、数学形式

保留概率 $P(\text{keep}|x)=I(f_{rule}(x)\wedge ppl(x)<\tau_q \wedge c(x)>\tau_c)$；各条件可加权组合。

## 四、代码实现

```python
def keep(doc, tau_ppl=14.0, tau_c=0.5):
    if doc_ppl(doc) > tau_ppl:
        return False
    return quality_clf(doc) > tau_c
```

## 五、与其他对比

- 与 数据去重与精确子串匹配深入 顺序：先去重或先过滤均可，常先粗过滤再去重。
- 与 数据混合比例课程深入（过滤后配比）衔接。

## 六、常见误区

- 单一阈值全局适用；不同语料分布需分别标定。
- 用强模型训的分类器对分布外数据失效。

## 八、面试题

- 为何要质量过滤？答：剔除噪声提升信噪比，直接改善下游与困惑度。

## 九、演进

手工规则 → 困惑度 → 质量分类器 → 多信号融合。

## 十、小结

质量过滤是语料清洗核心，规则与模型方法互补。
