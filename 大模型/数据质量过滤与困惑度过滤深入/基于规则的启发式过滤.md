# 基于规则的启发式过滤

> 对应 Raffel et al., *C4*, 2020（去脏话、保留含句号行）；Penedo et al., *RefinedWeb*, 2023（严格启发式）。

## 一、背景与挑战

模型方法贵；可用廉价规则快速剔除明显垃圾。

## 二、核心原理

统计符号占比、平均行长、停用词比、语言标识、重复行率、黑名单词；设定阈值过滤。C4 还做“仅保留结尾有标点行”等。

## 三、数学形式

规则得分 $s(x)=\sum_j w_j I(r_j(x))$；当 $s(x)<\theta$ 丢弃。各 $r_j$ 为布尔启发式。

## 四、代码实现

```python
def heuristic_keep(text):
    if symbol_ratio(text) > 0.3:
        return False
    if avg_line_len(text) < 40:
        return False
    return True
```

## 五、与其他对比

- 与 多语种分词与挑战深入（语言识别）前置依赖。
- 与 数据版权与合规清洗深入（黑名单）共享规则思路。

## 六、常见误区

- 规则过严删掉合法短文本（如代码）。
- 阈值为英文语料调，直接套中文失效。
