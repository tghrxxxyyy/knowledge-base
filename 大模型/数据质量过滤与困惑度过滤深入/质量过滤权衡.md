# 质量过滤权衡

> 对应 Hoffmann et al., *Chinchilla*, 2022（数据量与质量权衡）；Penedo et al., *FineWeb*, 2024（严格过滤收益）。

## 一、背景与挑战

过滤越严质量越高但数据越少，需在“质”与“量”间找最优。

## 二、核心原理

Chinchilla 表明在固定算力下数据量与模型需同时缩放；过度过滤减少 token 可能反伤。需以小规模训练实验定阈值。

## 三、数学形式

目标 $\max_\tau \text{loss}(D_\tau, C)$ 约束 $N_\tau\ge N_{min}$；$\tau$ 为综合过滤阈值。

## 四、代码实现

```python
for tau in linspace(0.3, 0.9, 7):
    run_small(keep_rate=tau)
```

## 八、面试题

- 质与量如何取舍？答：先小实验定阈值，使质量达标同时保留足够 token。

## 九、演进
