# 多阶段过滤流水线

> 对应 Penedo et al., *RefinedWeb*, 2023（严格多阶段）；Soldaini et al., *Dolma*, 2024（可配置管线）。

## 一、背景与挑战

单一过滤器难覆盖所有噪声；需级联多种过滤器。

## 二、核心原理

典型顺序：语言识别 → 启发式规则 → 去重 → 困惑度 → 质量分类器。每阶段可配置并统计通过率，便于诊断。

## 三、数学形式

最终保留 $D_{out}=\bigcap_s \{x: f_s(x)\}$，各阶段通过率 $r_s=|f_s|/|input|$。

## 四、代码实现

```python
for stage in [lang_id, heuristic, dedup, ppl, clf]:
    docs = [d for d in docs if stage(d)]
```

## 五、与其他对比

- 与 数据去重与精确子串匹配深入、多语种分词深入 同属预处理。
- 与 数据版权与合规清洗深入（合规亦为一级）合并设计。

## 六、常见误区

- 阶段顺序不当（如先分类再分词致 PPL 错）。
- 不记录各阶段通过率，难定位瓶颈。
