# 困惑度过滤原理

> 对应 Wenzek et al., *CCNet*, 2020（用 KenLM 困惑度过滤）；Penedo et al., *FineWeb*, 2024（困惑度指导）。

## 一、背景与挑战

规则难辨“流畅但无意义”文本；用语言模型困惑度衡量自然度。

## 二、核心原理

以一个小 n-gram/神经 LM 对文档打分困惑度（PPL）；PPL 过高说明文本不自然（机器翻译腔、乱码），过低可能是模板或高重复，取中间区间。

## 三、数学形式

困惑度 $PPL(x)=\exp(-\frac1N\sum_i\log p(x_i|x_{<i}))$；$p$ 来自参考 LM；保留 $\tau_{lo}<PPL<\tau_{hi}$。

## 四、代码实现

```python
import kenlm
model = kenlm.Model("cc.en.1e9.kenlm")
ppl = model.perplexity(text)
```

## 五、与其他对比

- 与 数据质量过滤总览（模型法之一）衔接。
- 与 分词器训练与词表构建深入（PPL 依赖分词）相关。

## 六、常见误区

- 用目标大模型算 PPL 太贵；用小型 KenLM 近似。
- 只砍高 PPL 忽略过低 PPL 的模板噪声。

## 八、面试题

- 为何两端截 PPL？答：过高不自然、过低多为模板/重复，取中段保质量。

## 九、演进

n-gram PPL → 神经 PPL → 结合分类器。

## 十、小结

困惑度过滤以语言自然度筛文本，需双向阈值。
