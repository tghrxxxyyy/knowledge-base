# 分类器质量过滤

> 对应 Wenzek et al., *CCNet*, 2020（CC 与 Wikipedia 训练二分类）；Brown et al., *GPT-3*, 2020（高质量参考构造）。

## 一、背景与挑战

困惑度仍偏“流畅”而非“有用”；需直接学“是否高质量”。

## 二、核心原理

用高质量语料（维基、书籍、新闻）为正、低质网页为负训二分类器；对候选打分过滤。亦可训回归预测下游效用。

## 三、数学形式

质量分 $q(x)=\sigma(g_\phi(x))\in[0,1]$；保留 $\{x:q(x)>\tau_c\}$，$\tau_c$ 由目标保留率定。

## 四、代码实现

```python
from transformers import pipeline
clf = pipeline("text-classification", "quality-bert")
if clf(doc)["score"] < 0.6:
    drop(doc)
```

## 五、与其他对比

- 比困惑度更贴“有用性”，但需标注且易分布偏移。
- 与 数据混合比例课程深入（按质量分层混合）衔接。

## 六、常见误区

- 正类仅维基使分类器偏“百科风”，伤多样性。
- 阈值定太高致数据量骤减。

## 十、小结

分类器过滤贴近质量目标，需防风格偏见与数据锐减。
