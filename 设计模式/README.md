> 常用设计模式总结与示例，覆盖创建型（5 种）、结构型（7 种）、行为型（11 种）共 23 种经典设计模式，附速查表与面试口诀。

## 设计模式分类总览

- 📝 [设计模式分类](设计模式分类.md) — 三类（创建/结构/行为）总览 + 关系图

## 创建型模式（5 种）

| 模式 | 文档 | 一句话 |
|------|------|--------|
| **单例模式** | [单例模式](创建型/单例模式.md) | 全局唯一实例，饿汉/懒汉/双检锁/枚举 |
| **工厂方法模式** | [工厂方法模式](创建型/工厂方法模式.md) | 子类决定实例化哪个类，解耦创建与使用 |
| **抽象工厂模式** | [抽象工厂模式](创建型/抽象工厂模式.md) | 创建一系列相关对象的接口，无需指定具体类 |
| **建造者模式** | [建造者模式](创建型/建造者模式.md) | 分步骤构建复杂对象，构造过程与表示分离 |
| **原型模式** | [原型模式](创建型/原型模式.md) | 通过复制现有对象创建新对象，避免重复初始化 |

## 结构型模式（7 种）

| 模式 | 文档 | 一句话 |
|------|------|--------|
| **代理模式** | [代理模式](结构型/代理模式.md) | 为其他对象提供代理以控制访问，增强/延迟/保护 |
| **适配器模式** | [适配器模式](结构型/适配器模式.md) | 将一个类的接口转换成客户希望的另一个接口 |
| **桥接模式** | [桥接模式](结构型/桥接模式.md) | 将抽象与实现分离，使它们可以独立变化 |
| **装饰器模式** | [装饰器模式](结构型/装饰器模式.md) | 动态给对象添加职责，比继承更灵活 |
| **外观模式** | [外观模式](结构型/外观模式.md) | 为子系统中一组接口提供统一的高层接口 |
| **组合模式** | [组合模式](结构型/组合模式.md) | 将对象组合成树形结构表示"部分-整体"层次 |
| **享元模式** | [享元模式](结构型/享元模式.md) | 运用共享技术有效地支持大量细粒度对象 |

## 行为型模式（11 种）

| 模式 | 文档 | 一句话 |
|------|------|--------|
| **策略模式** | [策略模式](行为型/策略模式.md) | 定义一系列算法并封装，使它们可以相互替换 |
| **观察者模式** | [观察者模式](行为型/观察者模式.md) | 对象状态变化时自动通知依赖者，发布-订阅 |
| **责任链模式** | [责任链模式](行为型/责任链模式.md) | 将请求沿处理链传递，直到有对象处理它 |
| **模板方法模式** | [模板方法模式](行为型/模板方法模式.md) | 定义算法骨架，子类重写特定步骤 |
| **状态模式** | [状态模式](行为型/状态模式.md) | 对象内部状态改变时改变其行为 |
| **命令模式** | [命令模式](行为型/命令模式.md) | 将请求封装为对象，支持撤销/排队/日志 |
| **迭代器模式** | [迭代器模式](行为型/迭代器模式.md) | 顺序访问聚合对象元素而不暴露其内部 |
| **中介者模式** | [中介者模式](行为型/中介者模式.md) | 用一个中介对象封装一系列对象交互 |
| **备忘录模式** | [备忘录模式](行为型/备忘录模式.md) | 在不破坏封装的前提下捕获并恢复对象状态 |
| **访问者模式** | [访问者模式](行为型/访问者模式.md) | 将算法与对象结构分离，新增操作不改结构 |
| **解释器模式** | [解释器模式](行为型/解释器模式.md) | 定义语言的文法表示及解释器 |

## 面试口诀

> **创建型：** 单例全局唯一，工厂子类决定，抽象家族创建，建造者分步走，原型克隆省事。
>
> **结构型：** 代理控制访问，适配器转接口，桥接解耦实现，装饰器加职责，外观统一门面，组合树形结构，享元共享复用。
>
> **行为型：** 策略算法可换，观察者通知链，责任链传请求，模板定骨架，状态改行为，命令能撤销，迭代器遍历，中介者解耦，备忘录回退，访问者加操作，解释器解语法。

## 与其他板块的关系

- **场景设计/分布式锁** — 单例在分布式场景的演化（Redisson/ ZooKeeper 分布式锁）
- **场景设计/幂等设计** — 命令模式 + 幂等键的思想同源
- **源码系列/Spring** — Spring 大量使用工厂/代理/模板方法/观察者
- **源码系列/Netty** — Netty 的 Pipeline 是责任链的典型应用
- **Java虚拟机** — 类加载器双亲委派是责任链的 JVM 实现
- **云原生/可观测性** — 发布-订阅与事件驱动架构
- **DDD/上下文映射** — 防腐层（ACL）本质是适配器模式
