# 行为型设计模式实战

> 行为型模式关注"对象之间如何通信与职责分配"。本文覆盖策略、观察者、责任链、命令、状态、迭代器、模板方法、中介者八种高频模式，含示例与选型。

## 1. 策略（Strategy）

封装可互换算法，运行时切换。

```java
interface Discount { double calc(double p); }
class FullReduction implements Discount { public double calc(double p){ return p>200? p-30:p; } }
class Context {
    Discount d;
    double price(double p){ return d.calc(p); }
}
```

- 替代大量 if-else 分支。
- 配合工厂/配置注入具体策略。

## 2. 观察者（Observer）

一对多通知，状态变更自动推送给订阅者。

```java
class Subject {
    List<Observer> obs = new ArrayList<>();
    void notifyAll(){ for(Observer o: obs) o.update(); }
}
```

- 事件总线、监听器、Reactive 都基于它。
- 坑：通知链循环、内存泄漏（未注销）。

## 3. 责任链（Chain of Responsibility）

请求沿链传递，直到被处理。

```java
abstract class Handler {
    Handler next;
    void handle(Request r){
        if (canHandle(r)) doHandle(r);
        else if (next != null) next.handle(r);
    }
    abstract boolean canHandle(Request r);
}
```

- 适用：审批流、过滤器、中间件。
- 坑：链过长性能差、请求无人处理。

## 4. 命令（Command）

把请求封装成对象，支持撤销/队列。

```java
interface Command { void execute(); void undo(); }
class LightOn implements Command {
    Light l; public void execute(){ l.on(); }
    public void undo(){ l.off(); }
}
```

- 支持操作日志、事务、宏命令。
- GUI 撤销、任务队列常用。

## 5. 状态（State）

对象行为随内部状态改变，消除状态分支。

```java
interface State { void handle(Order o); }
class PaidState implements State { public void handle(Order o){ /*已支付逻辑*/ } }
class Order {
    State s;
    void process(){ s.handle(this); }
}
```

- 状态多且转换复杂时优于 if-else。
- 与策略区别：状态自己感知转换，策略由外部切换。

## 6. 模板方法（Template Method）

父类定骨架，子类填步骤。

```java
abstract class Brew {
    final void make(){
        boil(); brew(); pour(); // 固定流程
    }
    abstract void brew();
}
```

- 保证流程一致，开放步骤定制。
- 坑：父类依赖子类实现，需注意抽象方法契约。

## 7. 迭代器（Iterator）

统一遍历集合，不暴露内部结构。

```java
for (Item i : collection) { ... }  // 内部即迭代器
```

- Java 集合、Stream 都基于它。

## 8. 中介者（Mediator）

用中介对象封装对象间交互，降低耦合。

```java
class ChatRoom {
    void send(User u, String m){ /* 转发给其他人 */ }
}
```

- 适用：组件间复杂通信（如 UI 控件联动）。
- 坑：中介者变上帝类。

## 9. 选型对比

| 模式 | 关键 | 场景 |
| --- | --- | --- |
| 策略 | 算法互换 | 多算法 |
| 观察者 | 状态通知 | 事件 |
| 责任链 | 链式处理 | 审批/过滤 |
| 命令 | 请求对象化 | 撤销/队列 |
| 状态 | 行为随状态 | 状态机 |
| 模板 | 骨架固定 | 流程一致 |
| 迭代器 | 统一遍历 | 集合 |
| 中介者 | 交互集中 | 复杂通信 |

## 11. 小结

行为型模式管理对象协作：策略换算法、观察者做通知、责任链分压、命令可撤销、状态管转换、模板定骨架。理解"对象间职责如何流动"是掌握的关键。
